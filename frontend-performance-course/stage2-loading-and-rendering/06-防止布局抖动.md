## 一、CLS 是什么

```
┌──────────────────────────────────────────────────────────────┐
│                    CLS 计算公式                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  布局偏移分数 = 影响分数 × 距离分数                            │
│                                                              │
│  影响分数：不稳定元素影响的可视区域比例                         │
│  距离分数：不稳定元素移动的最大距离比例                         │
│                                                              │
│  例：一个占屏幕 50% 的元素向下移动了 25%                       │
│      CLS = 0.5 × 0.25 = 0.125                               │
│                                                              │
│  好的 CLS：< 0.1                                             │
│  需要改进：0.1 ~ 0.25                                        │
│  差：> 0.25                                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、图片布局稳定

### 3.1 始终设置宽高

```html
<!-- ❌ 没有尺寸 → 加载前高度为 0 → 布局抖动 -->
<img src="/photo.jpg">

<!-- ✅ 设置 width 和 height → 浏览器预留空间 -->
<img src="/photo.jpg" width="800" height="600">

<!-- ✅ 响应式图片：用 CSS 控制实际显示尺寸 -->
<style>
  img {
    max-width: 100%;
    height: auto;
  }
</style>
<img src="/photo.jpg" width="800" height="600">
```

### 3.2 aspect-ratio

```css
/* 用 aspect-ratio 替代固定高度 */
.hero-image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

/* 适用于不知道具体尺寸但知道比例的场景 */
.card-thumbnail {
  width: 100%;
  aspect-ratio: 3 / 2;
  background: #f0f0f0; /* 占位色 */
}
```

### 3.3 图片占位符

```javascript
// 方案 1：模糊占位图（BlurHash / LQIP）
<img src="/photo-blur.jpg" width="800" height="600">
// 加载完成后替换为高清图

// 方案 2：骨架屏
<div class="skeleton" style="width: 100%; aspect-ratio: 16/9;"></div>

// 方案 3：CSS 背景色占位
<img src="/photo.jpg" width="800" height="600"
     style="background: #e8e8e8;">
```

## 四、字体布局稳定

### 4.1 font-display 策略

```css
/* 推荐：swap — 立即显示后备字体，Web 字体加载后替换 */
@font-face {
  font-family: 'MyFont';
  src: url('/font.woff2') format('woff2');
  font-display: swap;
}

/* 如果后备字体和 Web 字体尺寸差异大，用 optional */
@font-face {
  font-family: 'MyFont';
  src: url('/font.woff2') format('woff2');
  font-display: optional; /* 只在加载够快时才使用 */
}
```

### 4.2 匹配后备字体尺寸

```css
/* 用 size-adjust 让后备字体和 Web 字体尺寸一致 */
@font-face {
  font-family: 'FallbackFont';
  src: local('Arial');
  size-adjust: 105%;
  ascent-override: 90%;
  descent-override: 20%;
  line-gap-override: 0%;
}

body {
  font-family: 'MyWebFont', 'FallbackFont', sans-serif;
}
```

### 4.3 字体预加载

```html
<!-- 提前加载关键字体，减少 FOUT 时间 -->
<link rel="preload" href="/font.woff2" as="font"
      type="font/woff2" crossorigin>
```

## 五、动态内容布局稳定

### 5.1 为动态内容预留空间

```html
<!-- ❌ 广告插入后把内容推下去 -->
<div id="content">...</div>
<script>insertAd('#content');</script>

<!-- ✅ 为广告预留空间 -->
<div id="ad-slot" style="min-height: 90px;">
  <!-- 广告加载后填充 -->
</div>
<div id="content">...</div>
```

### 5.2 固定位置的提示

```css
/* ❌ 在页面顶部插入提示 → 推动所有内容下移 */
.notification {
  position: relative;
  margin-top: 0;
}

/* ✅ 用 fixed 或 absolute 定位，不影响文档流 */
.notification {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 1000;
}

/* ✅ 或者用 transform 动画 */
.notification {
  transform: translateY(-100%);
  transition: transform 0.3s ease;
}
.notification.show {
  transform: translateY(0);
}
```

### 5.3 Skeleton 占位

```css
/* 在内容加载前显示骨架屏 */
.skeleton {
  background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
  border-radius: 4px;
}

@keyframes shimmer {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```

## 六、避免强制同步布局

### 6.1 读写分离

```javascript
// ❌ 读写交替 → 强制同步布局（布局抖动）
elements.forEach(el => {
  const height = el.offsetHeight; // 读
  el.style.height = height * 2 + 'px'; // 写 → 触发布局
});

// ✅ 先批量读，再批量写
const heights = elements.map(el => el.offsetHeight); // 全部读
elements.forEach((el, i) => {
  el.style.height = heights[i] * 2 + 'px'; // 全部写
});
```

### 6.2 使用 requestAnimationFrame

```javascript
// ✅ 在下一帧统一处理写操作
requestAnimationFrame(() => {
  elements.forEach((el, i) => {
    el.style.height = heights[i] * 2 + 'px';
  });
});
```

## 七、用 DevTools 定位 CLS

### 7.1 Performance 面板

```
操作步骤：
1. DevTools → Performance 面板
2. 勾选 "Web Vitals" 复选框
3. 录制页面加载过程
4. 查看 Experience 轨道中的红色标记 = 布局偏移
5. 点击标记 → 查看是哪个元素发生了偏移
```

### 7.2 Layout Shift Regions

```
1. DevTools → Performance 面板
2. 点击齿轮图标 → 勾选 "Layout Shift Regions"
3. 录制后，页面中偏移的区域会被蓝色高亮
```

### 7.3 CLS 调试代码

```javascript
// 监测所有布局偏移
const observer = new PerformanceObserver((list) => {
  list.getEntries().forEach((entry) => {
    if (!entry.hadRecentInput) {
      console.log('布局偏移：', {
        value: entry.value.toFixed(4),
        sources: entry.sources?.map(s => s.node),
        startTime: entry.startTime,
      });
    }
  });
});

observer.observe({ type: 'layout-shift', buffered: true });
```

## 动手练习

### 练习一：复现 CLS 问题

1. 创建一个没有尺寸的图片页面
2. 用 Performance 面板录制加载过程
3. 观察 CLS 分数和布局偏移区域

### 练习二：修复图片 CLS

1. 给所有图片添加 width/height
2. 添加 aspect-ratio CSS
3. 对比修复前后的 CLS 分数

### 练习三：字体布局稳定

1. 使用 Web 字体加载一个页面
2. 观察 FOUT 导致的布局偏移
3. 添加 font-display: swap 和 size-adjust
4. 验证布局偏移是否消除

---

## 小结

1. **CLS 衡量视觉稳定性**：好的 CLS < 0.1
2. **图片必须有尺寸**：width/height + aspect-ratio 预留空间
3. **字体用 swap**：配合 size-adjust 匹配后备字体尺寸
4. **动态内容预留空间**：广告、通知、嵌入内容都需要
5. **读写分离**：避免强制同步布局
6. **用 DevTools**：Performance 面板的 Experience 轨道定位 CLS
