# Performance Rescue 项目说明

## 项目目标

对一个真实风格页面做性能改造。项目要体现完整闭环：诊断、定位、优化、复测、上线监控和性能预算。

## 页面主题

任选一个：

- 电商商品列表 + 商品详情
- SaaS Dashboard
- 内容站首页 + 文章页
- AI 工具站工作台

## 初始问题设计

页面初始版本应故意包含以下问题：

- 大图未压缩
- 首屏 JS 过大
- 字体加载阻塞
- 列表渲染过多
- 第三方脚本阻塞
- 卡片高度变化导致 CLS
- 输入框交互延迟明显

## 优化任务

1. 诊断
   - Lighthouse 报告
   - Performance trace
   - Network waterfall
   - Bundle 分析

2. 首屏
   - 优化 LCP 元素
   - 图片尺寸和格式
   - 预加载关键资源

3. 交互
   - 降低主线程长任务
   - 拆分重计算
   - 优化列表渲染

4. 稳定性
   - 固定图片尺寸
   - 预留广告/异步内容空间
   - 字体加载策略

5. 监控
   - 采集 Web Vitals
   - 输出性能日志
   - 设置性能预算

## 验收标准

- LCP、INP、CLS 都有优化前后数据
- JS 初始包体积减少至少 30%
- 图片总传输体积减少至少 50%
- 无明显布局抖动
- 关键交互无可感知卡顿
- README 包含性能报告和优化决策说明
