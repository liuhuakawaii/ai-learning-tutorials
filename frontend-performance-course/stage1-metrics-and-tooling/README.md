# 第一阶段：指标与诊断工具

## 阶段目标

理解性能指标和诊断工具，学会先测量再优化。

## 课时安排

1. 性能目标：快、稳、可交互
2. Core Web Vitals：LCP、INP、CLS
3. Lab 数据与 Field 数据
4. Chrome DevTools Performance
5. Lighthouse 报告解读
6. 性能归因方法
7. 阶段实战：页面性能体检报告

## 阶段项目

选择一个页面，输出性能体检报告，列出问题、证据和优先级。

## 验收标准

- 有 Lighthouse 报告
- 有 Performance trace 截图或记录
- 每个问题都有证据
- 优先级排序清晰
