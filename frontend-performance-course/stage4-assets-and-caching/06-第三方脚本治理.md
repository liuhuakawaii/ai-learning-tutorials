## 二、加载策略

### 2.1 defer / async

```html
<!-- defer：HTML 解析完成后执行，保持脚本顺序 -->
<script defer src="https://analytics.js"></script>

<!-- async：下载完就执行，不保证顺序 -->
<script async src="https://analytics.js"></script>

<!-- 推荐：分析脚本用 defer/async -->
<script defer src="https://www.googletagmanager.com/gtm.js"></script>
```

```
┌──────────────┬────────────────┬────────────────┬─────────────┐
│              │ 普通 script     │ async          │ defer       │
├──────────────┼────────────────┼────────────────┼─────────────┤
│ 阻塞 HTML    │ ✅ 是          │ ❌ 否          │ ❌ 否       │
│ 执行时机     │ 立即           │ 下载完即执行   │ HTML 解析后 │
│ 脚本顺序     │ 保持           │ 不保证         │ 保持        │
│ DOM 就绪     │ 不保证         │ 不保证         │ ✅ 保证     │
└──────────────┴────────────────┴────────────────┴─────────────┘
```

### 2.2 延迟加载

```html
<!-- 方案 1：页面加载完成后加载 -->
<script>
  window.addEventListener('load', () => {
    const script = document.createElement('script');
    script.src = 'https://chat-widget.js';
    document.body.appendChild(script);
  });
</script>

<!-- 方案 2：用户交互后加载 -->
<script>
  ['scroll', 'click', 'mousemove'].forEach(event => {
    window.addEventListener(event, () => {
      const script = document.createElement('script');
      script.src = 'https://analytics.js';
      document.body.appendChild(script);
    }, { once: true });
  });
</script>

<!-- 方案 3：空闲时加载 -->
<script>
  if ('requestIdleCallback' in window) {
    requestIdleCallback(() => {
      const script = document.createElement('script');
      script.src = 'https://analytics.js';
      document.body.appendChild(script);
    });
  }
</script>
```

### 2.3 按需加载

```javascript
// 聊天组件：只在用户点击时加载
function ChatButton() {
  const [loaded, setLoaded] = useState(false);

  const loadChat = () => {
    if (!loaded) {
      const script = document.createElement('script');
      script.src = 'https://chat-widget.js';
      script.onload = () => setLoaded(true);
      document.body.appendChild(script);
    }
  };

  return <button onClick={loadChat}>Open Chat</button>;
}
```

## 三、脚本审计

### 3.1 识别第三方脚本

```javascript
// 在 Console 中运行
const scripts = Array.from(document.querySelectorAll('script[src]'));
const thirdParty = scripts.filter(s => {
  try {
    const url = new URL(s.src);
    return url.hostname !== window.location.hostname;
  } catch {
    return false;
  }
});

console.table(thirdParty.map(s => ({
  src: s.src,
  async: s.async,
  defer: s.defer,
  blocking: !s.async && !s.defer,
})));
```

### 3.2 使用 Performance 面板

```
1. DevTools → Performance 面板
2. 录制页面加载
3. 查看 Network 轨道：
   - 找到第三方域名的请求
   - 查看它们的下载时间和执行时间
4. 查看 Main 轨道：
   - 找到第三方脚本的长任务
   - 识别阻塞主线程的脚本
```

### 3.3 Request Map

```
使用 WebPageTest 的 Request Map：
1. 访问 webpagetest.org
2. 输入页面 URL
3. 查看请求地图：
   - 可视化所有第三方请求
   - 识别请求链和依赖关系
   - 找到最慢的第三方脚本
```

## 四、优化方案

### 4.1 优先级分级

```
┌──────────────────────────────────────────────────────────────┐
│              第三方脚本优先级                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  高优先级（立即加载）：                                       │
│  - A/B 测试工具（影响首屏显示）                               │
│  - 安全脚本（防欺诈）                                         │
│                                                              │
│  中优先级（defer 加载）：                                     │
│  - 分析工具（Google Analytics）                               │
│  - 标签管理器（GTM）                                         │
│                                                              │
│  低优先级（延迟加载）：                                       │
│  - 聊天工具                                                   │
│  - 社交分享按钮                                               │
│  - 广告脚本                                                   │
│  - 客服工具                                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 资源提示

```html
<!-- 预连接到第三方源 -->
<link rel="preconnect" href="https://www.googletagmanager.com">
<link rel="preconnect" href="https://www.google-analytics.com">

<!-- 预加载关键第三方资源 -->
<link rel="preload" href="https://cdn.example.com/critical.js" as="script">

<!-- DNS 预解析 -->
<link rel="dns-prefetch" href="//connect.facebook.net">
```

### 4.3 内容安全策略

```html
<!-- CSP 限制第三方脚本来源 -->
<meta http-equiv="Content-Security-Policy"
      content="script-src 'self' https://www.googletagmanager.com https://www.google-analytics.com">

<!-- 减少 XSS 风险 -->
```

## 五、Partytown（高级方案）

### 5.1 原理

```
┌──────────────────────────────────────────────────────────────┐
│              Partytown：把第三方脚本移到 Web Worker            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  传统方式：                                                   │
│  主线程 → 第三方脚本执行 → 阻塞主线程 → 用户交互卡顿          │
│                                                              │
│  Partytown：                                                  │
│  主线程 → 正常运行                                            │
│  Web Worker → 第三方脚本执行 → 不阻塞主线程                   │
│                                                              │
│  原理：                                                       │
│  - 在 Web Worker 中运行第三方脚本                             │
│  - Worker 访问 DOM 通过 postMessage 代理                     │
│  - 对第三方脚本透明（不需要修改脚本）                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 使用

```bash
npm install @builder.io/partytown
```

```jsx
// Next.js
import { Partytown } from '@builder.io/partytown/react';

function Head() {
  return (
    <>
      <Partytown forward={['dataLayer.push']} />
      <script
        type="text/partytown"
        src="https://www.googletagmanager.com/gtm.js"
      />
    </>
  );
}
```

## 动手练习

### 练习二：优化加载策略

### 练习三：实现按需加载

1. 把聊天组件改为点击时才加载
2. 把分析脚本改为用户交互后加载

---

## 小结

1. **第三方脚本影响大**：可能增加 400KB+ 和 1 秒+ 阻塞
2. **优先级分级**：高→立即，中→defer，低→延迟
3. **defer / async**：避免阻塞 HTML 解析
4. **延迟加载**：页面加载后、用户交互后、空闲时
5. **Partytown**：把第三方脚本移到 Web Worker
6. **CSP**：限制脚本来源，提升安全性
