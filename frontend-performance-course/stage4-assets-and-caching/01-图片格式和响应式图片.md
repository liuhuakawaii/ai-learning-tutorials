## 二、响应式图片

### 2.1 srcset 和 sizes

```html
<!-- 浏览器根据屏幕宽度选择最合适的图片 -->
<img
  srcset="
    /photo-400.webp 400w,
    /photo-800.webp 800w,
    /photo-1200.webp 1200w,
    /photo-1600.webp 1600w
  "
  sizes="
    (max-width: 600px) 100vw,
    (max-width: 1200px) 50vw,
    33vw
  "
  src="/photo-800.webp"
  alt="Photo"
  width="800" height="600"
>
```

```
sizes 属性解释：
- (max-width: 600px) 100vw：屏幕 ≤ 600px 时，图片占满视口宽度
- (max-width: 1200px) 50vw：屏幕 600-1200px 时，图片占视口一半
- 33vw：更大屏幕时，图片占视口三分之一

浏览器根据 sizes 计算出实际需要的图片宽度
再从 srcset 中选择最接近的图片
```

### 2.2 picture 元素（格式降级）

```html
<!-- 现代格式优先，旧浏览器降级 -->
<picture>
  <!-- AVIF：最新浏览器 -->
  <source srcset="/photo.avif" type="image/avif">
  <!-- WebP：大多数现代浏览器 -->
  <source srcset="/photo.webp" type="image/webp">
  <!-- JPEG：兜底 -->
  <img src="/photo.jpg" alt="Photo" width="800" height="600">
</picture>

<!-- 不同场景用不同图片 -->
<picture>
  <!-- 暗色模式 -->
  <source srcset="/hero-dark.webp" media="(prefers-color-scheme: dark)">
  <!-- 小屏幕裁剪版 -->
  <source srcset="/hero-mobile.webp" media="(max-width: 768px)">
  <!-- 默认 -->
  <img src="/hero.webp" alt="Hero" width="1200" height="600">
</picture>
```

### 2.3 art direction（艺术指导）

```html
<!-- 不同屏幕使用不同裁剪/构图的图片 -->
<picture>
  <!-- 手机：竖构图，突出主体 -->
  <source
    srcset="/hero-portrait.webp"
    media="(max-width: 768px)"
    width="400" height="600"
  >
  <!-- 桌面：横构图，全景 -->
  <img
    src="/hero-landscape.webp"
    alt="Hero"
    width="1200" height="600"
  >
</picture>
```

## 三、图片优化工具

### 3.1 构建时优化

```bash
# Squoosh CLI（Google 出品）
npx @squoosh/cli --webp '{"quality":80}' images/*.jpg

# sharp（Node.js 库，性能最好）
# build script
import sharp from 'sharp';

await sharp('input.jpg')
  .resize(800, 600, { fit: 'cover' })
  .webp({ quality: 80 })
  .toFile('output.webp');

# imagemin
npx imagemin images/*.jpg --out-dir=optimized --plugin=webp
```

## 动手练习

### 练习一：格式转换

1. 取一张 JPEG 照片，分别转换为 WebP 和 AVIF
2. 对比三种格式的文件大小
3. 用 `<picture>` 实现格式降级

### 练习二：响应式图片

1. 生成 400w、800w、1200w 三个尺寸的图片
2. 使用 srcset 和 sizes 实现响应式
3. 用 Network 面板验证不同屏幕宽度加载不同图片

### 练习三：批量优化

1. 写一个构建脚本，自动把 images/ 目录下的图片转为 WebP
2. 生成多种尺寸的响应式图片
3. 输出优化前后的体积对比

---

## 小结

1. **格式选择**：照片用 AVIF/WebP，图标用 SVG，需要透明用 WebP/PNG
2. **响应式图片**：srcset + sizes 让浏览器选择合适的尺寸
3. **格式降级**：用 `<picture>` 提供多种格式
4. **工具**：sharp、Squoosh CLI、CDN 实时转换
5. **首屏图片**：fetchpriority="high" + preload
