## 一、大列表的性能问题

```
┌──────────────────────────────────────────────────────────────┐
│              为什么大列表慢？                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  10000 个列表项：                                             │
│                                                              │
│  DOM 成本：                                                   │
│  - 创建 10000 个 DOM 节点                                     │

│  - 总共可能 50000+ 个 DOM 节点                                │
│                                                              │
│  渲染成本：                                                   │
│  - 10000 个组件函数调用                                       │

│  - 布局计算（每个节点的位置和大小）                            │
│                                                              │
│  内存成本：                                                   │
│  - 每个 DOM 节点占用内存                                      │
│  - 事件监听器                                                │
│  - React fiber 节点                                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、虚拟滚动原理

```
┌──────────────────────────────────────────────────────────────┐
│              虚拟滚动原理                                      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  只渲染可视区域内的元素：                                      │
│                                                              │
│  ┌─────────────────────────┐ ← 容器（600px 高）              │
│  │  ┌───────────────────┐  │                                 │
│  │  │ 列表项 1 (50px)   │  │ ← 可见区域                     │
│  │  │ 列表项 2 (50px)   │  │                                 │
│  │  │ 列表项 3 (50px)   │  │   实际渲染：~12 个元素          │
│  │  │ 列表项 4 (50px)   │  │   而不是 10000 个               │
│  │  │ ...              │  │                                 │
│  │  │ 列表项 12 (50px)  │  │                                 │
│  │  └───────────────────┘  │                                 │
│  │                         │                                 │
│  │  (上面的占位空间)        │ ← padding 模拟滚动位置          │
│  │  (下面的占位空间)        │                                 │
│  └─────────────────────────┘                                 │
│                                                              │
│  总高度通过 padding 或绝对定位模拟                             │
│  滚动时动态计算哪些项应该被渲染                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、使用 react-window

### 3.1 固定高度列表

```javascript
import { FixedSizeList } from 'react-window';

function VirtualList({ items }) {
  const Row = ({ index, style }) => (
    <div style={style} className="list-row">
      <span>{items[index].name}</span>
      <span>{items[index].email}</span>
    </div>
  );

  return (
    <FixedSizeList
      height={600}        // 容器高度
      width="100%"         // 容器宽度
      itemCount={items.length}
      itemSize={50}        // 每项高度（固定）
    >
      {Row}
    </FixedSizeList>
  );
}
```

### 3.2 可变高度列表

```javascript
import { VariableSizeList } from 'react-window';

function VariableVirtualList({ items }) {
  // 根据内容估算每项高度
  const getItemSize = (index) => {
    const item = items[index];
    // 简单估算：标题 20px + 每行内容 18px
    return 20 + Math.ceil(item.content.length / 50) * 18 + 20;
  };

  const Row = ({ index, style }) => (
    <div style={style}>
      <h3>{items[index].title}</h3>
      <p>{items[index].content}</p>
    </div>
  );

  return (
    <VariableSizeList
      height={600}
      width="100%"
      itemCount={items.length}
      itemSize={getItemSize}
    >
      {Row}
    </VariableSizeList>
  );
}
```

### 3.3 网格虚拟滚动

```javascript
import { FixedSizeGrid } from 'react-window';

function VirtualGrid({ items, columns = 4 }) {
  const Cell = ({ columnIndex, rowIndex, style }) => {
    const index = rowIndex * columns + columnIndex;
    if (index >= items.length) return null;

    return (
      <div style={style}>
        <ProductCard product={items[index]} />
      </div>
    );
  };

  return (
    <FixedSizeGrid
      height={600}
      width="100%"
      columnCount={columns}
      columnWidth={250}
      rowCount={Math.ceil(items.length / columns)}
      rowHeight={300}
    >
      {Cell}
    </FixedSizeGrid>
  );
}
```

## 四、使用 react-virtuoso

### 4.1 自动高度测量

```javascript
import { Virtuoso } from 'react-virtuoso';

// react-virtuoso 的优势：自动测量每项高度
function AutoHeightList({ items }) {
  return (
    <Virtuoso
      style={{ height: 600 }}
      totalCount={items.length}
      index={0}
      itemContent={(index) => (
        <div className="list-item">
          <h3>{items[index].title}</h3>
          <p>{items[index].content}</p>
          <span>{items[index].date}</span>
        </div>
      )}
    />
  );
}
```

### 4.2 无限加载

```javascript
import { Virtuoso } from 'react-virtuoso';

function InfiniteList() {
  const [items, setItems] = useState([]);
  const [loading, setLoading] = useState(false);

  const loadMore = useCallback(() => {
    if (loading) return;
    setLoading(true);

    fetch(`/api/items?offset=${items.length}&limit=50`)
      .then(res => res.json())
      .then(newItems => {
        setItems(prev => [...prev, ...newItems]);
        setLoading(false);
      });
  }, [items.length, loading]);

  return (
    <Virtuoso
      style={{ height: 600 }}
      totalCount={items.length}
      endReached={loadMore}
      itemContent={(index) => (
        <div>{items[index].name}</div>
      )}
      components={{
        Footer: () => loading ? <div>加载中...</div> : null,
      }}
    />
  );
}
```

### 4.3 分组列表

```javascript
import { GroupedVirtuoso } from 'react-virtuoso';

function GroupedList({ groups }) {
  // groups: [{ label: 'A', items: [...] }, { label: 'B', items: [...] }]

  const groupCounts = groups.map(g => g.items.length);

  return (
    <GroupedVirtuoso
      style={{ height: 600 }}
      groupCounts={groupCounts}
      groupContent={(index) => (
        <div className="group-header">{groups[index].label}</div>
      )}
      itemContent={(index, groupIndex) => {
        const item = groups[groupIndex].items[index];
        return <div>{item.name}</div>;
      }}
    />
  );
}
```

## 六、何时使用虚拟滚动

```
┌──────────────────────────────────────────────────────────────┐
│              何时使用虚拟滚动？                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ✅ 使用：                                                    │
│  - 列表项 > 100 个                                           │
│  - 每个列表项包含复杂内容                                     │
│  - 需要无限滚动加载更多                                       │
│  - 数据表格（行数多）                                         │
│                                                              │
│  ❌ 不使用：                                                  │
│  - 列表项 < 50 个（用 memo 就够了）                           │
│  - 列表项高度不一致且无法估算                                  │
│  - 需要 Ctrl+F 搜索（虚拟滚动会破坏浏览器原生搜索）           │
│  - 列表项需要被搜索引擎索引                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 小结

1. **大列表问题**：DOM 节点多 → 渲染慢、内存高
2. **虚拟滚动原理**：只渲染可视区域，用 padding/定位模拟滚动
3. **react-window**：固定高度用 FixedSizeList，可变高度用 VariableSizeList
4. **react-virtuoso**：自动测量高度，支持无限加载和分组
5. **列表项也要优化**：用 memo + 稳定回调
