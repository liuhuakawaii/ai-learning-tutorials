# 第三阶段：React / Next 性能

## 阶段目标

理解 React 渲染成本、状态设计、列表渲染和 Next.js 性能能力。

## 课时安排

1. React 渲染机制
2. 状态设计和重渲染
3. memo/useMemo/useCallback 的边界
4. 大列表和虚拟滚动
5. Next 图片、字体、路由
6. Server Components 与缓存
7. 阶段实战：Dashboard 交互优化

## 阶段项目

优化一个 Dashboard，使筛选、搜索、表格滚动和输入交互更顺畅。

## 验收标准

- 关键交互无明显卡顿
- 重渲染次数下降
- 大列表渲染稳定
- memo 不滥用，有明确理由
