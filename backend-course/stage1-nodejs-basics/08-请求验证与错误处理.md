# 第八课：请求验证与错误处理

## 场景引入

你的博客 API 上线了，但很快遇到了问题：有人提交了一个空标题的文章，有人用 `"; DROP TABLE users; --` 作为用户名，还有人传了一个负数的年龄。更糟糕的是，当数据库查询失败时，前端收到的是一个 500 错误和一句"Internal Server Error"，完全不知道出了什么问题。这些都指向同一个缺失——请求验证和错误处理。永远不要信任客户端输入，所有数据在进入业务逻辑之前都必须验证，所有错误都必须以统一的格式返回给调用方。

## 学习目标

完成本课学习后，你将能够：

1. 理解为什么需要请求验证
2. 掌握 Zod 验证库的使用方法
3. 创建可复用的验证中间件
4. 设计自定义错误类
5. 实现全局错误处理机制
6. 统一 API 的错误响应格式

## 一、为什么需要验证

### 1.1 永远不要信任客户端

```
安全原则：永远不要信任客户端输入

客户端可能发送：
  - 空字段
  - 超长字符串
  - 无效的邮箱格式
  - SQL 注入代码
  - XSS 攻击代码
  - 负数金额
  - 不存在的 ID

如果后端不验证：
  - 数据库可能被破坏
  - 服务器可能崩溃
  - 用户数据可能泄露
  - 系统可能被攻击
```

### 1.2 验证的层次

```
验证应该在多个层次进行：

  客户端验证（前端）
    → 提供即时反馈，提升用户体验
    → 可以被绕过，不能作为安全保障

  服务器验证（后端）
    → 最后一道防线，必须严格
    → 所有数据在使用前都要验证

  数据库验证
    → 最底层的约束
    → 数据类型、唯一性、外键等
```

### 1.3 手动验证 vs 使用库

```javascript
// ========== 手动验证（繁琐、易出错） ==========

router.post('/users', (req, res) => {
    const { name, email, age, password } = req.body;
    const errors = [];

    if (!name || typeof name !== 'string') {
        errors.push('姓名为必填项且必须是字符串');
    } else if (name.length < 2 || name.length > 50) {
        errors.push('姓名长度必须在 2-50 之间');
    }

    if (!email || typeof email !== 'string') {
        errors.push('邮箱为必填项');
    } else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
        errors.push('邮箱格式不正确');
    }

    if (age !== undefined) {
        if (typeof age !== 'number' || age < 0 || age > 150) {
            errors.push('年龄必须是 0-150 之间的数字');
        }
    }

    if (!password || password.length < 6) {
        errors.push('密码至少 6 个字符');
    }

    if (errors.length > 0) {
        return res.status(400).json({ errors });
    }

    // 继续处理...
});

// 问题：
// 1. 代码冗长，重复性高
// 2. 容易遗漏验证
// 3. 错误消息格式不统一
// 4. 难以维护
```

```javascript
// ========== 使用 Zod（简洁、类型安全） ==========

const { z } = require('zod');

const userSchema = z.object({
    name: z.string().min(2).max(50),
    email: z.string().email(),
    age: z.number().min(0).max(150).optional(),
    password: z.string().min(6)
});

router.post('/users', validate(userSchema), (req, res) => {
    // req.body 已经验证通过，可以安全使用
    const { name, email, age, password } = req.body;
    // 继续处理...
});
```

## 二、Zod 详解

### 2.1 什么是 Zod

**Zod** 是一个 TypeScript 优先的验证库，它的特点是：
- 类型推断（自动推导 TypeScript 类型）
- 链式 API（易读易写）
- 零依赖
- 体积小

### 2.2 安装 Zod

```bash
npm install zod
```

### 2.3 基本类型

```javascript
const { z } = require('zod');

// 字符串
const stringSchema = z.string();
stringSchema.parse('hello');    // ✅ 'hello'
// stringSchema.parse(123);     // ❌ 抛出错误

// 数字
const numberSchema = z.number();
numberSchema.parse(42);         // ✅ 42
numberSchema.parse(3.14);       // ✅ 3.14

// 布尔值

booleanSchema.parse(true);      // ✅ true

// 日期

dateSchema.parse(new Date());   // ✅ Date 对象

// null 和 undefined
```

```javascript
z.string().parse('hello');

z.string().startsWith('hello').parse('hello world');
z.string().endsWith('world').parse('hello world');

// 包含特定字符串
z.string().includes('hello').parse('say hello');

// 自定义错误消息
```

### 2.6 对象验证

```javascript
const userSchema = z.object({
```

### 2.9 自定义验证

```javascript
const { z } = require('zod');

// refine：自定义验证逻辑
const passwordSchema = z.string().refine(
    (val) => val.length >= 8,
    { message: '密码至少 8 个字符' }
).refine(
    (val) => /[A-Z]/.test(val),
    { message: '密码必须包含大写字母' }
).refine(
    (val) => /[0-9]/.test(val),
    { message: '密码必须包含数字' }
);

// superRefine：更精细的控制
const ageSchema = z.number().superRefine((val, ctx) => {
    if (val < 0) {
        ctx.addIssue({
            code: z.ZodIssueCode.too_small,
            minimum: 0,
            type: 'number',
            inclusive: true,
            message: '年龄不能为负数'
        });
    }
    if (val > 150) {
        ctx.addIssue({
            code: z.ZodIssueCode.too_big,
            maximum: 150,
            type: 'number',
            inclusive: true,
            message: '年龄不能超过 150'
        });
    }
});

// transform：转换数据
const trimmedString = z.string().transform((val) => val.trim());
trimmedString.parse('  hello  ');  // 'hello'

const upperString = z.string().transform((val) => val.toUpperCase());
upperString.parse('hello');  // 'HELLO'
```

### 2.10 错误处理

```javascript
const { z } = require('zod');

const schema = z.object({
    name: z.string().min(2),
    email: z.string().email()
});

// safeParse：不抛出错误
const result = schema.safeParse({ name: 'a', email: 'invalid' });

if (!result.success) {
    console.log(result.error.issues);
    // [
    //   {
    //     code: 'too_small',
    //     minimum: 2,
    //     type: 'string',
    //     path: ['name'],
    //     message: 'String must contain at least 2 character(s)'
    //   },
    //   {
    //     code: 'invalid_string',
    //     validation: 'email',
    //     path: ['email'],
    //     message: 'Invalid email'
    //   }
    // ]

    // 格式化错误信息
    const formatted = result.error.format();
    console.log(formatted);
    // {
    //   name: { _errors: ['String must contain at least 2 character(s)'] },
    //   email: { _errors: ['Invalid email'] },
    //   _errors: []
    // }
}

// parse：抛出错误
try {
    schema.parse({ name: 'a', email: 'invalid' });
} catch (err) {
    if (err instanceof z.ZodError) {
        console.log(err.issues);
    }
}
```

## 三、验证中间件封装

### 3.1 创建通用验证中间件

```javascript
// middleware/validate.js
const { z } = require('zod');

/**
 * 创建验证中间件
 * @param {z.ZodSchema} schema - Zod schema
 * @param {string} source - 验证来源：'body' | 'query' | 'params'
 */
function validate(schema, source = 'body') {
    return (req, res, next) => {
        const data = req[source];
        const result = schema.safeParse(data);

        if (!result.success) {
            const errors = result.error.issues.map(issue => ({
                field: issue.path.join('.'),
                message: issue.message
            }));

            return res.status(400).json({
                success: false,
                error: {
                    code: 'VALIDATION_ERROR',
                    message: '请求数据验证失败',
                    details: errors
                }
            });
        }

        // 将验证后的数据替换原始数据
        req[source] = result.data;
        next();
    };
}

/**
 * 验证请求体
 */
function validateBody(schema) {
    return validate(schema, 'body');
}

/**
 * 验证查询参数
 */
function validateQuery(schema) {
    return validate(schema, 'query');
}

/**
 * 验证路径参数
 */
function validateParams(schema) {
    return validate(schema, 'params');
}

module.exports = { validate, validateBody, validateQuery, validateParams };
```

### 3.2 使用验证中间件

```javascript
// routes/users.js
const express = require('express');
const router = express.Router();
const { z } = require('zod');
const { validateBody, validateQuery, validateParams } = require('../middleware/validate');

// 定义验证规则
const createUserSchema = z.object({
    name: z.string().min(2, '姓名至少 2 个字符').max(50, '姓名最多 50 个字符'),
    email: z.string().email('邮箱格式不正确'),
    password: z.string().min(6, '密码至少 6 个字符'),
    age: z.number().int().min(0).max(150).optional(),
    role: z.enum(['admin', 'user']).default('user')
});

const updateUserSchema = z.object({
    name: z.string().min(2).max(50).optional(),
    email: z.string().email().optional(),
    age: z.number().int().min(0).max(150).optional()
});

const userQuerySchema = z.object({
    page: z.string().regex(/^\d+$/).transform(Number).default('1'),
    limit: z.string().regex(/^\d+$/).transform(Number).default('10'),
    search: z.string().optional(),
    role: z.enum(['admin', 'user']).optional()
});

const userIdSchema = z.object({
    id: z.string().regex(/^\d+$/, 'ID 必须是数字').transform(Number)
});

// 应用验证
router.get('/', validateQuery(userQuerySchema), (req, res) => {
    const { page, limit, search, role } = req.query;
    // 数据已经验证过，可以安全使用
    res.json({ page, limit, search, role });
});

router.post('/', validateBody(createUserSchema), (req, res) => {
    const { name, email, password, age, role } = req.body;
    // 数据已经验证过，可以安全使用
    res.status(201).json({ name, email, age, role });
});

router.put('/:id', validateParams(userIdSchema), validateBody(updateUserSchema), (req, res) => {
    const { id } = req.params;
    const updates = req.body;
    res.json({ id, ...updates });
});

module.exports = router;
```

## 四、错误类型分类

### 4.1 常见错误类型

```
后端常见的错误类型：

1. 验证错误（Validation Error）
   → 请求数据不符合要求
   → 状态码：400 或 422
   → 例：邮箱格式不正确、必填字段缺失

2. 认证错误（Authentication Error）
   → 用户未登录或 token 无效
   → 状态码：401
   → 例：未提供 token、token 已过期

3. 授权错误（Authorization Error）
   → 用户没有权限执行操作
   → 状态码：403
   → 例：普通用户访问管理员接口

4. 资源未找到（Not Found）
   → 请求的资源不存在
   → 状态码：404
   → 例：用户 ID 不存在

5. 业务逻辑错误（Business Error）
   → 不违反技术规范，但违反业务规则
   → 状态码：400 或 409
   → 例：库存不足、余额不足、重复注册

6. 系统错误（System Error）
   → 服务器内部错误
   → 状态码：500
   → 例：数据库连接失败、第三方服务不可用
```

## 五、自定义错误类

### 5.1 AppError 类

```javascript
// utils/AppError.js

/**
 * 应用程序错误基类
 */
class AppError extends Error {
    /**
     * @param {string} message - 错误消息
     * @param {number} statusCode - HTTP 状态码
     * @param {string} code - 错误代码
     * @param {Array} details - 错误详情
     */
    constructor(message, statusCode = 500, code = 'INTERNAL_ERROR', details = null) {
        super(message);
        this.name = this.constructor.name;
        this.statusCode = statusCode;
        this.code = code;
        this.details = details;
        this.isOperational = true;  // 标记为可预期的错误

        Error.captureStackTrace(this, this.constructor);
    }
}

/**
 * 验证错误
 */
class ValidationError extends AppError {
    constructor(message = '验证失败', details = null) {
        super(message, 400, 'VALIDATION_ERROR', details);
    }
}

/**
 * 认证错误
 */
class AuthenticationError extends AppError {
    constructor(message = '未认证') {
        super(message, 401, 'AUTHENTICATION_ERROR');
    }
}

/**
 * 授权错误
 */
class AuthorizationError extends AppError {
    constructor(message = '权限不足') {
        super(message, 403, 'AUTHORIZATION_ERROR');
    }
}

/**
 * 资源未找到错误
 */
class NotFoundError extends AppError {
    constructor(resource = '资源') {
        super(`${resource}不存在`, 404, 'NOT_FOUND');
    }
}

/**
 * 业务逻辑错误
 */
class BusinessError extends AppError {
    constructor(message, code = 'BUSINESS_ERROR') {
        super(message, 400, code);
    }
}

/**
 * 冲突错误
 */
class ConflictError extends AppError {
    constructor(message = '资源冲突') {
        super(message, 409, 'CONFLICT');
    }
}

module.exports = {
    AppError,
    ValidationError,
    AuthenticationError,
    AuthorizationError,
    NotFoundError,
    BusinessError,
    ConflictError
};
```

## 六、全局错误处理中间件

### 6.1 异步错误处理

```javascript
// utils/asyncHandler.js

/**
 * 包装异步路由处理器，自动捕获错误
 * @param {Function} fn - 异步路由处理函数
 * @returns {Function} 包装后的函数
 */
function asyncHandler(fn) {
    return (req, res, next) => {
        Promise.resolve(fn(req, res, next)).catch(next);
    };
}

module.exports = asyncHandler;
```

```javascript
// 使用 asyncHandler
const asyncHandler = require('../utils/asyncHandler');

// 不使用 asyncHandler（需要手动 try-catch）
router.get('/posts', async (req, res, next) => {
    try {
        const posts = await Post.find();
        res.json({ data: posts });
    } catch (err) {
        next(err);
    }
});

// 使用 asyncHandler（自动捕获错误）
router.get('/posts', asyncHandler(async (req, res) => {
```

### 6.2 全局错误处理中间件

```javascript
// middleware/errorHandler.js
const { AppError } = require('../utils/AppError');
const { ZodError } = require('zod');

/**
 * 全局错误处理中间件
 */
function errorHandler(err, req, res, next) {
    // 记录错误
    console.error('错误:', {
        message: err.message,
        stack: err.stack,
        url: req.url,
        method: req.method,
        ip: req.ip,
        timestamp: new Date().toISOString()
    });

    // 处理 Zod 验证错误
    if (err instanceof ZodError) {
        const details = err.issues.map(issue => ({
            field: issue.path.join('.'),
            message: issue.message
        }));

        return res.status(400).json({
            success: false,
            error: {
                code: 'VALIDATION_ERROR',
                message: '请求数据验证失败',
                details
            }
        });
    }

    // 处理自定义 AppError
    if (err instanceof AppError) {
        const response = {
            success: false,
            error: {
                code: err.code,
                message: err.message
            }
        };

        if (err.details) {
            response.error.details = err.details;
        }

        return res.status(err.statusCode).json(response);
    }

    // 处理 JWT 错误
    if (err.name === 'JsonWebTokenError') {
        return res.status(401).json({
            success: false,
            error: {
                code: 'INVALID_TOKEN',
                message: '无效的认证令牌'
            }
        });
    }

    if (err.name === 'TokenExpiredError') {
        return res.status(401).json({
            success: false,
            error: {
                code: 'TOKEN_EXPIRED',
                message: '认证令牌已过期'
            }
        });
    }

    // 处理数据库错误
    if (err.code === 'ER_DUP_ENTRY') {
        return res.status(409).json({
            success: false,
            error: {
                code: 'DUPLICATE_ENTRY',
                message: '数据重复'
            }
        });
    }

    // 未知错误（500）
    const response = {
        success: false,
        error: {
            code: 'INTERNAL_ERROR',
            message: '服务器内部错误'
        }
    };

    // 开发环境返回详细错误
    if (process.env.NODE_ENV === 'development') {
        response.error.message = err.message;
        response.error.stack = err.stack;
    }

    res.status(500).json(response);
}

/**
 * 404 处理中间件
 */
function notFoundHandler(req, res) {
    res.status(404).json({
        success: false,
        error: {
            code: 'NOT_FOUND',
            message: `路由不存在: ${req.method} ${req.url}`
        }
    });
}

module.exports = { errorHandler, notFoundHandler };
```

```javascript
 * 成功响应

function sendSuccess(res, data, meta = null, statusCode = 200) {

    if (meta) response.meta = meta;

}

 * 创建成功响应

        error: { code, message }

    return res.status(statusCode).json(response);
```

## 八、实战：为博客 API 添加验证

### 8.1 完整示例

```javascript
// src/routes/v1/posts.js
const express = require('express');
const router = express.Router();
const { z } = require('zod');
const asyncHandler = require('../../utils/asyncHandler');
const { validateBody, validateQuery, validateParams } = require('../../middleware/validate');
const { NotFoundError, AuthorizationError } = require('../../utils/AppError');
const { sendSuccess, sendCreated, sendDeleted } = require('../../utils/response');
const store = require('../../data/store');

// ========== 验证 Schema ==========

const createPostSchema = z.object({
    title: z.string().min(1, '标题为必填项').max(200, '标题最多 200 个字符'),
    content: z.string().min(1, '内容为必填项'),
    authorId: z.number().int().positive('作者ID必须为正整数'),
    tags: z.array(z.string()).max(10, '最多 10 个标签').default([]),
    status: z.enum(['draft', 'published', 'archived']).default('draft')
});

const updatePostSchema = z.object({
    title: z.string().min(1).max(200).optional(),
    content: z.string().min(1).optional(),
    tags: z.array(z.string()).max(10).optional(),
    status: z.enum(['draft', 'published', 'archived']).optional()
});

const postQuerySchema = z.object({
    page: z.string().regex(/^\d+$/).transform(Number).default('1'),
    limit: z.string().regex(/^\d+$/).transform(Number).default('10'),
    tag: z.string().optional(),
    authorId: z.string().regex(/^\d+$/).transform(Number).optional(),
    status: z.enum(['draft', 'published', 'archived']).optional(),
    search: z.string().optional(),
    sort: z.enum(['createdAt', '-createdAt', 'title', '-title']).default('-createdAt')
});

const postIdSchema = z.object({
    id: z.string().regex(/^\d+$/, 'ID 必须是数字').transform(Number)
});

// ========== 路由处理 ==========

// 获取文章列表
router.get('/',
    validateQuery(postQuerySchema),
    asyncHandler(async (req, res) => {
        const { page, limit, tag, authorId, status, search, sort } = req.query;
        let posts = [...store.posts];

        // 过滤
        if (tag) posts = posts.filter(p => p.tags.includes(tag));
        if (authorId) posts = posts.filter(p => p.authorId === authorId);
        if (status) posts = posts.filter(p => p.status === status);
        if (search) {
            const keyword = search.toLowerCase();
            posts = posts.filter(p =>
                p.title.toLowerCase().includes(keyword) ||
                p.content.toLowerCase().includes(keyword)
            );
        }

        // 排序
        const sortField = sort.startsWith('-') ? sort.slice(1) : sort;
        const sortOrder = sort.startsWith('-') ? -1 : 1;
        posts.sort((a, b) => {
            if (a[sortField] < b[sortField]) return -1 * sortOrder;
            if (a[sortField] > b[sortField]) return 1 * sortOrder;
            return 0;
        });

        // 分页
        const offset = (page - 1) * limit;
        const paginated = posts.slice(offset, offset + limit);

        return sendSuccess(res, paginated, {
            page,
            limit,
            total: posts.length,
            totalPages: Math.ceil(posts.length / limit)
        });
    })
);

// 获取单篇文章
router.get('/:id',
    validateParams(postIdSchema),
    asyncHandler(async (req, res) => {
        const post = store.posts.find(p => p.id === req.params.id);

        if (!post) {
            throw new NotFoundError('文章');
        }

        const author = store.users.find(u => u.id === post.authorId);
        const comments = store.comments.filter(c => c.postId === post.id);

        return sendSuccess(res, {
            ...post,
            author: author ? { id: author.id, name: author.name } : null,
            comments
        });
    })
);

// 创建文章
router.post('/',
    validateBody(createPostSchema),
    asyncHandler(async (req, res) => {
        const { title, content, authorId, tags, status } = req.body;

        // 检查作者是否存在
        const author = store.users.find(u => u.id === authorId);
        if (!author) {
            throw new NotFoundError('作者');
        }

        const now = new Date().toISOString();
        const post = {
            id: store.nextId.posts++,
            title,
            content,
            authorId,
            tags,
            status,
            createdAt: now,
            updatedAt: now
        };

        store.posts.push(post);
        return sendCreated(res, post);
    })
);

// 更新文章
router.put('/:id',
    validateParams(postIdSchema),
    validateBody(updatePostSchema),
    asyncHandler(async (req, res) => {
        const index = store.posts.findIndex(p => p.id === req.params.id);

        if (index === -1) {
            throw new NotFoundError('文章');
        }

        const updates = req.body;

        store.posts[index] = {
            ...store.posts[index],
            ...updates,
            updatedAt: new Date().toISOString()
        };

        return sendSuccess(res, store.posts[index]);
    })
);

// 删除文章
router.delete('/:id',
    validateParams(postIdSchema),
    asyncHandler(async (req, res) => {
        const index = store.posts.findIndex(p => p.id === req.params.id);

        if (index === -1) {
            throw new NotFoundError('文章');
        }

        // 删除相关评论
        store.comments = store.comments.filter(c => c.postId !== store.posts[index].id);

        store.posts.splice(index, 1);
        return sendDeleted(res);
    })
);

module.exports = router;
```

## 常见误区

1. **只在前端做验证**：前端验证可以被绕过（curl、Postman、篡改请求），后端验证是最后一道防线，必须独立存在且严格校验。
2. **在路由处理函数里写验证逻辑**：验证代码和业务逻辑混在一起会让路由函数臃肿难维护。应该用中间件封装验证，让路由函数只关心业务。
3. **捕获错误后只返回 "服务器错误"**：区分可预期错误（如验证失败、资源不存在）和系统错误（如数据库连接失败）。前者返回具体的错误信息和 4xx 状态码，后者隐藏细节只返回 500。
4. **不处理异步错误**：async 函数中的异常不会被 Express 自动捕获，需要用 `asyncHandler` 包装或在每个异步路由中手动 try-catch，否则服务器会崩溃。

## 工程建议

1. **使用 Zod 定义验证规则**：Zod 是 TypeScript 友好的验证库，支持链式 API、类型推断、自定义错误消息，比手动写 if-else 验证更安全、更简洁。
2. **自定义错误类继承 AppError**：创建 `AppError` 基类，派生出 `NotFoundError`、`ValidationError`、`ConflictError` 等子类，在全局错误处理中间件中统一处理。
3. **开发环境返回详细错误，生产环境隐藏敏感信息**：开发环境返回错误堆栈方便调试，生产环境只返回错误消息，不暴露服务器内部结构。
4. **统一错误响应格式**：`{ success: false, error: { code: "VALIDATION_ERROR", message: "...", details: [...] } }`，让前端可以统一处理所有错误。
