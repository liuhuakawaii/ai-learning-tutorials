# 博客平台 API — 完整项目说明

> 本项目是课程的最终成果，一个架构完整、代码优雅的商业级博客平台 REST API。

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 运行时 | Node.js 20+ | LTS 版本 |
| 框架 | Express.js | 最流行的 Node.js Web 框架 |
| 语言 | TypeScript | 类型安全 |
| 数据库 | PostgreSQL 15+ | 关系型数据库 |
| ORM | Prisma | 类型安全的数据库客户端 |
| 认证 | JWT + bcrypt | Token 认证 + 密码加密 |
| 缓存 | Redis | 热点数据缓存 |
| 文件上传 | Multer + sharp | 上传 + 图片处理 |
| 日志 | Winston + morgan | 结构化日志 |
| 文档 | Swagger/OpenAPI | 自动生成 API 文档 |
| 部署 | Docker + Railway | 容器化 + 云部署 |

## 功能模块

### 用户系统
- 邮箱注册/登录
- 个人资料管理（头像、简介）
- 角色权限（管理员 / 普通用户）

### 文章系统
- 文章 CRUD（创建、列表、详情、更新、删除）
- 草稿 / 发布状态切换
- 文章分类 + 标签
- 富文本内容存储
- 阅读量统计
- 按关键词、分类、标签搜索筛选

### 评论系统
- 文章评论 CRUD
- 嵌套评论（回复评论）
- 评论点赞

### 系统功能
- JWT 认证 + RBAC 权限
- 文件上传（头像、封面图）
- API 限流
- Redis 缓存
- 结构化日志
- Swagger API 文档
- 全局错误处理

## 快速开始

### 1. 克隆项目

```bash
cd blog-api
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 文件，填入数据库连接等配置
```

### 4. 启动数据库

```bash
# 使用 Docker 启动 PostgreSQL 和 Redis
docker-compose up -d
```

### 5. 数据库迁移

```bash
npx prisma migrate dev
```

### 6. 启动开发服务器

```bash
npm run dev
```

服务器启动后：
- API: http://localhost:3000/api
- Swagger 文档: http://localhost:3000/api-docs
- 健康检查: http://localhost:3000/health

## API 接口一览

### 认证
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | /api/auth/register | 注册 | 否 |
| POST | /api/auth/login | 登录 | 否 |
| GET | /api/auth/me | 获取当前用户 | 是 |
| PUT | /api/auth/me | 更新个人资料 | 是 |

### 用户（管理员）
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/users | 用户列表 | 管理员 |
| GET | /api/users/:id | 用户详情 | 管理员 |
| DELETE | /api/users/:id | 删除用户 | 管理员 |

### 文章
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/posts | 文章列表（分页、筛选） | 否 |
| GET | /api/posts/:slug | 文章详情 | 否 |
| POST | /api/posts | 创建文章 | 是 |
| PUT | /api/posts/:id | 更新文章 | 是（作者/管理员） |
| DELETE | /api/posts/:id | 删除文章 | 是（作者/管理员） |
| PUT | /api/posts/:id/publish | 发布文章 | 是（作者/管理员） |

### 分类
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/categories | 分类列表 | 否 |
| POST | /api/categories | 创建分类 | 管理员 |
| PUT | /api/categories/:id | 更新分类 | 管理员 |
| DELETE | /api/categories/:id | 删除分类 | 管理员 |

### 标签
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/tags | 标签列表 | 否 |
| GET | /api/tags/popular | 热门标签 | 否 |
| POST | /api/tags | 创建标签 | 是 |
| DELETE | /api/tags/:id | 删除标签 | 管理员 |

### 评论
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/posts/:postId/comments | 文章评论列表 | 否 |
| POST | /api/posts/:postId/comments | 创建评论 | 是 |
| PUT | /api/comments/:id | 更新评论 | 是（作者） |
| DELETE | /api/comments/:id | 删除评论 | 是（作者/管理员） |

### 统计
| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | /api/stats/overview | 总览统计 | 管理员 |
| GET | /api/stats/popular-posts | 热门文章 | 否 |

## 环境变量

```env
# 应用
NODE_ENV=development
PORT=3000

# 数据库
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/blog_db

# Redis
REDIS_URL=redis://localhost:6379

# JWT
JWT_SECRET=your-super-secret-key-change-in-production
JWT_EXPIRES_IN=7d

# 文件上传
UPLOAD_DIR=./uploads
MAX_FILE_SIZE=5242880

# 日志
LOG_LEVEL=debug
```

## Docker 部署

```bash
# 构建镜像
docker build -t blog-api .

# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f app
```
