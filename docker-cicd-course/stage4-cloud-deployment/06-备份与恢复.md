## 二、数据库备份脚本

```bash
#!/bin/bash
# scripts/backup-db.sh

set -e

# 配置
BACKUP_DIR="/opt/backups/postgres"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="${BACKUP_DIR}/backup_${TIMESTAMP}.sql.gz"
RETENTION_DAYS=7

# 创建备份目录
mkdir -p "$BACKUP_DIR"

# 备份 PostgreSQL
echo "Starting backup..."
docker compose exec -T postgres pg_dump -U postgres mydb | gzip > "$BACKUP_FILE"

# 检查备份文件
if [ -s "$BACKUP_FILE" ]; then
    echo "Backup successful: $BACKUP_FILE ($(du -h "$BACKUP_FILE" | cut -f1))"
else
    echo "Backup failed!"
    exit 1
fi

# 清理旧备份
echo "Cleaning up backups older than $RETENTION_DAYS days..."
find "$BACKUP_DIR" -name "backup_*.sql.gz" -mtime +$RETENTION_DAYS -delete

echo "Backup completed!"
```

## 三、定时备份

### 3.1 使用 Crontab

```bash
# 编辑 crontab
crontab -e

# 添加定时任务：每天凌晨 2 点备份
0 2 * * * /opt/my-app/scripts/backup-db.sh >> /var/log/backup.log 2>&1
```

### 3.2 使用 Docker 容器

```yaml
# docker-compose.yml
services:
  backup:
    build: .
    command: >
      sh -c "
        echo '0 2 * * * /scripts/backup-db.sh' > /etc/crontabs/root &&
        crond -f -l 8
      "
    volumes:
      - ./scripts:/scripts
      - /opt/backups:/backups
      - /var/run/docker.sock:/var/run/docker.sock
    restart: unless-stopped
```

## 四、数据恢复

```bash
#!/bin/bash
# scripts/restore-db.sh

set -e

BACKUP_FILE=$1

if [ -z "$BACKUP_FILE" ]; then
    echo "Usage: ./restore-db.sh <backup-file>"
    echo ""
    echo "Available backups:"
    ls -lh /opt/backups/postgres/
    exit 1
fi

echo "Restoring from: $BACKUP_FILE"

# 确认
read -p "This will overwrite the current database. Continue? (y/N) " -n 1 -r
echo
if [[ ! $REPLY =~ ^[Yy]$ ]]; then
    echo "Aborted."
    exit 1
fi

# 停止应用
docker compose stop app

# 恢复数据库
echo "Restoring database..."
gunzip -c "$BACKUP_FILE" | docker compose exec -T postgres psql -U postgres mydb

# 启动应用
docker compose start app

echo "Restore completed!"
```

## 五、异地备份

### 5.1 使用 rclone 同步到 S3

```bash
# 安装 rclone
curl https://rclone.org/install.sh | bash

# 配置 S3
rclone config

# 同步备份到 S3
rclone sync /opt/backups/postgres s3:my-backup-bucket/postgres
```

### 5.2 在备份脚本中集成

```bash
# 在备份脚本末尾添加
if command -v rclone &> /dev/null; then
    echo "Syncing to remote storage..."
    rclone sync "$BACKUP_DIR" s3:my-backup-bucket/postgres
fi
```

## 小结

1. **备份策略**：每天备份，保留 7 天，异地存储
2. **备份脚本**：pg_dump + gzip + 清理旧备份
3. **定时任务**：crontab 或 Docker 容器
4. **恢复流程**：停止应用 → 恢复数据库 → 启动应用
5. **恢复演练**：定期测试，确保备份可用
