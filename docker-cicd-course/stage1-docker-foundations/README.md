# 第一阶段：Docker 基础

## 阶段目标

理解镜像、容器、Dockerfile、构建上下文、网络、卷和多阶段构建，能独立容器化一个应用。

## 课时安排

1. 为什么需要容器
2. 镜像、容器、仓库
3. Dockerfile 基础
4. 多阶段构建
5. .dockerignore
6. 镜像体积和安全
7. 阶段实战：容器化 Node API

## 阶段项目

为一个 Node API 写 Dockerfile，支持开发和生产两种运行方式。

## 验收标准

- 镜像能成功构建
- 容器启动后可访问健康检查
- 不把 node_modules 和密钥打进镜像
- 使用非 root 用户或说明安全边界
