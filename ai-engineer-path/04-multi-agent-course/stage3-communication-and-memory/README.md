# 第 3 阶段：通信与记忆

> 解决多 Agent 系统中的核心难题

## 学习目标

- 掌握 Agent 间的三种通信模式：直接调用 / 消息传递 / 共享黑板
- 理解短期记忆和长期记忆在多 Agent 系统中的设计
- 学会实现 Agent 间的冲突解决和仲裁机制
- 能够为多 Agent 系统构建完整的通信与记忆层

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | Agent 通信模式 — 直接调用 / 消息传递 / 共享黑板 | 2h |
| 02 | 短期记忆 — 会话上下文在 Agent 间的传递策略 | 3h |
| 03 | 长期记忆 — 跨会话的知识持久化与检索 | 3h |
| 04 | 共享工作空间 — Agent 间的文件/数据共享机制 | 3h |
| 05 | 冲突解决 — 多个 Agent 给出不同结果时的仲裁策略 | 3h |
| 06 | 阶段实战：为多 Agent 系统实现完整的通信与记忆层 | 4h |

## 验收标准

- [ ] 实现至少两种通信模式并对比优劣
- [ ] 多 Agent 间能共享上下文和长期记忆
- [ ] 冲突解决机制能处理两个 Agent 给出矛盾结果的场景
