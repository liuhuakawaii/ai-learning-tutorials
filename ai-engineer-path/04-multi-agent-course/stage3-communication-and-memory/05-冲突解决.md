# 05 冲突解决——多个 Agent 给出不同结果时的仲裁策略

> 多个 Agent 对同一问题给出不同答案，怎么办？

## 学习目标

- 掌握冲突解决的策略和方法
- 理解投票、加权、仲裁等机制
- 学会设计可靠的冲突解决方案

## 一、冲突类型

```
冲突类型：

1. 事实冲突
   - Agent A 说"产品价格 99 元"
   - Agent B 说"产品价格 199 元"
   - 需要查证事实

2. 观点冲突
   - Agent A 说"方案 A 更好"
   - Agent B 说"方案 B 更好"
   - 需要综合评估

3. 方法冲突
   - Agent A 用方法 1 得出结果
   - Agent B 用方法 2 得出结果
   - 需要对比方法
```

## 二、解决策略

```python
class ConflictResolver:
    """冲突解决器"""
    
    def __init__(self, llm):
        self.llm = llm
    
    def resolve_by_voting(self, results: list) -> dict:
        """投票解决"""
        # 多数投票
        from collections import Counter
        votes = Counter([r["answer"] for r in results])
        winner = votes.most_common(1)[0]
        
        return {
            "answer": winner[0],
            "confidence": winner[1] / len(results),
            "method": "voting"
        }
    
    def resolve_by_weight(self, results: list, weights: dict) -> dict:
        """加权解决"""
        weighted_sum = sum(
            r["score"] * weights.get(r["agent"], 1.0)
            for r in results
        )
        total_weight = sum(weights.get(r["agent"], 1.0) for r in results)
        
        return {
            "answer": weighted_sum / total_weight,
            "method": "weighted"
        }
    
    def resolve_by_llm(self, task: str, results: list) -> dict:
        """LLM 仲裁"""
        results_text = "\n".join([
            f"Agent {r['agent']}: {r['answer']}"
            for r in results
        ])
        
        prompt = f"""多个 Agent 对同一问题给出了不同答案，请仲裁。

问题：{task}

各 Agent 的答案：
{results_text}

请选择最合理的答案，或综合生成一个更好的答案。"""
        
        response = self.llm.invoke(prompt)
        
        return {
            "answer": response.content,
            "method": "llm_arbitration"
        }
```

## 三、一致性检查

```python
class ConsistencyChecker:
    """一致性检查器"""
    
    def check(self, results: list, threshold: float = 0.8) -> dict:
        """检查结果一致性"""
        
        # 计算相似度
        similarities = []
        for i in range(len(results)):
            for j in range(i + 1, len(results)):
                sim = self._calculate_similarity(results[i]["answer"], results[j]["answer"])
                similarities.append(sim)
        
        avg_similarity = sum(similarities) / len(similarities)
        
        return {
            "consistent": avg_similarity >= threshold,
            "similarity": avg_similarity,
            "threshold": threshold
        }
```

## 四、最佳实践

```
冲突解决最佳实践：

1. 识别冲突类型
   - 事实冲突：查证
   - 观点冲突：综合
   - 方法冲突：对比

2. 选择合适的策略
   - 简单问题：投票
   - 复杂问题：LLM 仲裁
   - 专业问题：专家加权

3. 记录解决过程
   - 记录冲突内容
   - 记录解决方法
   - 记录最终结果

4. 持续优化
   - 分析冲突原因
   - 优化 Agent 能力
   - 调整解决策略
```
