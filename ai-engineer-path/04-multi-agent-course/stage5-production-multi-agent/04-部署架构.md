## 一、容器化部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  supervisor:
    build: ./supervisor
    ports:
      - "8000:8000"
    depends_on:
      - researcher
      - analyst
      - writer
  
  researcher:
    build: ./agents/researcher
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}

    build: ./agents/analyst

      - OPENAI_API_KEY=${OPENAI_API_KEY}
```

## 二、服务发现

```python
class ServiceRegistry:
    """服务注册中心"""
    
    def __init__(self):
        self.services = {}
    
    def register(self, name: str, address: str, port: int):
        """注册服务"""
        self.services[name] = {
            "address": address,
            "port": port,
            "status": "healthy",
            "last_heartbeat": datetime.now()
        }
    
    def discover(self, name: str) -> dict:
        """发现服务"""
        return self.services.get(name)
    
    def health_check(self):
        """健康检查"""
        for name, service in self.services.items():
            if datetime.now() - service["last_heartbeat"] > timedelta(seconds=30):
                service["status"] = "unhealthy"
```

## 三、负载均衡

```python
class LoadBalancer:
    """负载均衡器"""
    
    def __init__(self, services: list):
        self.services = services
        self.current = 0
    
    def get_next(self) -> dict:
        """获取下一个服务（轮询）"""
        service = self.services[self.current]
        self.current = (self.current + 1) % len(self.services)
        return service
    
    def get_healthy(self) -> list:
        """获取健康的服务"""
        return [s for s in self.services if s["status"] == "healthy"]
```

## 四、Kubernetes 部署

```yaml
# k8s/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: multi-agent-system
spec:
  replicas: 3
  selector:
    matchLabels:
      app: multi-agent
  template:
    metadata:
      labels:
        app: multi-agent
    spec:
      containers:
        - name: supervisor
          image: multi-agent/supervisor:latest
          ports:
            - containerPort: 8000
          env:
            - name: OPENAI_API_KEY
              valueFrom:
                secretKeyRef:
                  name: api-keys
                  key: openai
```

## 五、部署流程

```
部署流程：

1. 构建镜像
   docker build -t multi-agent/supervisor .

2. 推送镜像
   docker push multi-agent/supervisor

3. 部署到 K8s
   kubectl apply -f k8s/

4. 检查状态
   kubectl get pods
   kubectl get services

5. 查看日志
   kubectl logs -f deployment/multi-agent-system
```
