# 04 状态管理——Agent 间共享状态的设计与实现

> 多 Agent 系统的核心难题：多个 Agent 如何共享和协调状态？

## 学习目标

- 掌握多 Agent 状态管理的设计方法
- 理解状态共享和同步机制
- 学会处理状态冲突

---

## 一、状态设计原则

```
状态设计原则：

1. 单一数据源
   - 状态是唯一的真相来源
   - 避免状态分散在多个地方

2. 不可变更新
   - 状态更新返回新对象
   - 不直接修改原状态

3. 类型安全
   - 使用 TypedDict 定义状态结构
   - 编译时检查类型

4. 最小化
   - 状态只包含必要信息
   - 避免状态过大
```

## 二、状态管理实现

```python
from typing import TypedDict, Annotated
from operator import add

class MultiAgentState(TypedDict):
    messages: Annotated[list, add]  # 消息列表，自动累加
    current_agent: str
    task: str
    results: dict
    iteration: int
    errors: list

# 状态更新函数
def update_state(state: MultiAgentState, updates: dict) -> MultiAgentState:
    """安全地更新状态"""
    new_state = {**state}
    for key, value in updates.items():
        if key in new_state:
            if isinstance(new_state[key], list) and isinstance(value, list):
                new_state[key] = new_state[key] + value
            elif isinstance(new_state[key], dict) and isinstance(value, dict):
                new_state[key] = {**new_state[key], **value}
            else:
                new_state[key] = value
    return new_state
```

## 三、共享状态模式

```
共享状态模式：

1. 中心化状态
   - 所有 Agent 读写同一个状态
   - 简单，但可能有冲突

2. 消息传递
   - Agent 间通过消息通信
   - 每个 Agent 有自己的局部状态

3. 黑板模式
   - 共享的"黑板"存储数据
   - Agent 读写黑板上的数据

4. 事件驱动
   - Agent 发布事件
   - 其他 Agent 订阅事件
```

## 四、状态持久化

```python
import json

class StatePersistence:
    """状态持久化"""
    
    def __init__(self, storage_path: str):
        self.storage_path = storage_path
    
    def save_state(self, state_id: str, state: dict):
        """保存状态"""
        path = f"{self.storage_path}/{state_id}.json"
        with open(path, "w") as f:
            json.dump(state, f)
    
    def load_state(self, state_id: str) -> dict:
        """加载状态"""
        path = f"{self.storage_path}/{state_id}.json"
        with open(path, "r") as f:
            return json.load(f)
```
