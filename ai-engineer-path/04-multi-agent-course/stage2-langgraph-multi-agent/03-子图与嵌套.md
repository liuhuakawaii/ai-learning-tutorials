# 03 子图与嵌套——让 Agent 自身也是一个 LangGraph 图

> 复杂的 Agent 可能需要自己的内部逻辑。子图让你在图中嵌套图。

## 学习目标

- 理解子图的概念和用途
- 掌握子图的创建和嵌套方法
- 学会设计可复用的 Agent 子图

---

## 一、子图概念

```
子图的用途：

1. 复杂 Agent 内部逻辑
   - 一个 Agent 可能需要多个步骤
   - 用子图封装 Agent 的内部流程

2. 可复用的 Agent 模块
   - 将通用 Agent 封装为子图
   - 在不同主图中复用

3. 层级化设计
   - 主图负责全局编排
   - 子图负责局部逻辑
```

## 二、子图实现

```python
from langgraph.graph import StateGraph, END

# 创建子图：研究 Agent
def create_research_subgraph():
    """创建研究子图"""
    
    class ResearchState(TypedDict):
        query: str
        sources: list
        summary: str
    
    def search_node(state: ResearchState) -> ResearchState:
        # 搜索逻辑
        return {**state, "sources": ["source1", "source2"]}
    
    def summarize_node(state: ResearchState) -> ResearchState:
        # 总结逻辑
        return {**state, "summary": f"基于{state['sources']}的总结"}
    
    subgraph = StateGraph(ResearchState)
    subgraph.add_node("search", search_node)
    subgraph.add_node("summarize", summarize_node)
    subgraph.set_entry_point("search")
    subgraph.add_edge("search", "summarize")
    subgraph.add_edge("summarize", END)
    
    return subgraph.compile()

# 在主图中使用子图
main_graph = StateGraph(MainState)

# 添加子图作为节点
research_agent = create_research_subgraph()
main_graph.add_node("researcher", research_agent)

# 其他节点...
main_graph.add_node("analyst", analyst_node)
main_graph.add_node("writer", writer_node)
```

## 三、子图状态映射

```python
def researcher_wrapper(state: MainState) -> MainState:
    """研究 Agent 包装器，处理状态映射"""
    
    # 从主状态提取子图需要的数据
    research_input = {
        "query": state["task"],
        "sources": [],
        "summary": ""
    }
    
    # 运行子图
    research_result = research_agent.invoke(research_input)
    
    # 将子图结果映射回主状态
    return {
        **state,
        "results": {**state.get("results", {}), "research": research_result["summary"]}
    }
```

## 四、设计模式

```
子图设计模式：

1. 封装模式
   将复杂 Agent 封装为子图
   对外暴露简单接口

2. 管道模式
   多个子图串联
   每个子图处理一个阶段

3. 并行模式
   多个子图并行执行
   汇总结果
```
