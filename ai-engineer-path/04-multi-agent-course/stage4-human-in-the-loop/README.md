# 第 4 阶段：人机协作

> 让人类在关键节点介入，而不是完全放手

## 学习目标

- 理解 Human-in-the-loop 的设计哲学和适用场景
- 掌握在 LangGraph 中实现审批节点的方法
- 学会设计异步审批流和反馈回路
- 能够构建一个带审批面板的多 Agent 系统

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | Human-in-the-loop 设计哲学 — 什么环节需要人类介入 | 2h |
| 02 | 审批节点实现 — 在 LangGraph 中添加人工审批 gate | 3h |
| 03 | 异步审批流 — 长时间运行任务的人工介入机制 | 3h |
| 04 | 反馈回路 — 人类反馈如何影响 Agent 后续行为 | 3h |
| 05 | 审批面板开发 — 构建一个可视化的审批 UI | 3h |
| 06 | 阶段实战：实现一个带审批流的多 Agent 内容生成系统 | 4h |

## 验收标准

- [ ] 在 LangGraph 工作流中成功插入人工审批节点
- [ ] 审批面板能展示 Agent 输出并支持批准/拒绝/修改
- [ ] 人类反馈能影响 Agent 的后续行为
