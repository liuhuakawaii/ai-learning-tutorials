# 04 反馈回路——人类反馈如何影响 Agent 后续行为

> 人类的反馈不只是"批准/拒绝"——它应该影响 Agent 未来的行为。

## 学习目标

- 掌握反馈回路的设计方法
- 理解反馈如何影响 Agent 行为
- 学会实现自适应的 Agent 系统

---

## 一、反馈类型

```
反馈类型：

1. 显式反馈
   - 点赞/点踩
   - 评分
   - 文字评论

2. 隐式反馈
   - 用户是否采纳了建议
   - 用户是否重新提问
   - 用户是否修改了结果

3. 结果反馈
   - 操作是否成功
   - 结果是否符合预期
   - 是否产生了问题
```

## 二、反馈收集

```python
class FeedbackCollector:
    """反馈收集器"""
    
    def __init__(self, memory: LongTermMemory):
        self.memory = memory
        self.feedback_data = []
    
    def collect_feedback(self, task_id: str, feedback: dict):
        """收集反馈"""
        feedback_entry = {
            "task_id": task_id,
            "feedback": feedback,
            "timestamp": datetime.now().isoformat()
        }
        
        self.feedback_data.append(feedback_entry)
        
        # 存储到长期记忆
        self.memory.store(
            f"任务 {task_id} 的反馈：{json.dumps(feedback, ensure_ascii=False)}",
            {"type": "feedback", "task_id": task_id}
        )
    
    def get_feedback_summary(self, agent_name: str = None) -> dict:
        """获取反馈摘要"""
        relevant_feedback = self.feedback_data
        if agent_name:
            relevant_feedback = [f for f in relevant_feedback if f.get("agent") == agent_name]
        
        positive = sum(1 for f in relevant_feedback if f["feedback"].get("rating", 0) > 3)
        negative = sum(1 for f in relevant_feedback if f["feedback"].get("rating", 0) < 3)
        
        return {
            "total": len(relevant_feedback),
            "positive": positive,
            "negative": negative,
            "satisfaction_rate": positive / len(relevant_feedback) if relevant_feedback else 0
        }
```

## 三、反馈驱动优化

```python
class FeedbackDrivenOptimizer:
    """反馈驱动优化器"""
    
    def __init__(self, llm, memory: LongTermMemory):
        self.llm = llm
        self.memory = memory
    
    def optimize_based_on_feedback(self, agent_name: str, current_prompt: str) -> str:
        """基于反馈优化"""
        
        # 检索相关反馈
        feedback = self.memory.retrieve(f"{agent_name} 反馈", top_k=10)
        
        # 分析反馈
        feedback_text = "\n".join([f["content"] for f in feedback])
        
        prompt = f"""基于以下用户反馈，优化 Agent 的提示词。

当前提示词：
{current_prompt}

用户反馈：
{feedback_text}

请生成优化后的提示词。"""
        
        response = self.llm.invoke(prompt)
        return response.content
```

## 四、自适应行为

```python
class AdaptiveAgent:
    """自适应 Agent"""
    
    def __init__(self, name: str, llm, feedback_collector: FeedbackCollector):
        self.name = name
        self.llm = llm
        self.feedback = feedback_collector
        self.base_prompt = "你是..."
        self.current_prompt = self.base_prompt
    
    def execute(self, task: str) -> str:
        # 检查反馈，决定是否调整行为
        summary = self.feedback.get_feedback_summary(self.name)
        
        if summary["satisfaction_rate"] < 0.7:
            # 满意度低，调整行为
            self.current_prompt = self._adapt_prompt()
        
        # 执行任务
        response = self.llm.invoke(f"{self.current_prompt}\n\n任务：{task}")
        return response.content
    
    def _adapt_prompt(self) -> str:
        """根据反馈调整提示词"""
        optimizer = FeedbackDrivenOptimizer(self.llm, self.feedback.memory)
        return optimizer.optimize_based_on_feedback(self.name, self.current_prompt)
```
