# 02 协议架构——Host / Client / Server 三层模型与消息流

> MCP 的三层架构：Host 管理环境，Client 负责通信，Server 提供能力。

## 学习目标

- 深入理解 MCP 的三层架构
- 掌握消息流的完整路径
- 理解各层的职责和交互

---

## 一、三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    MCP 三层架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Host（宿主）                                                │
│  ├── 运行 AI 应用的环境                                      │
│  ├── 管理 Client 的生命周期                                  │
│  ├── 处理用户交互                                            │
│  └── 例：VS Code、Claude Desktop、自定义应用                  │
│                                                             │
│  Client（客户端）                                            │
│  ├── 与 Server 建立连接                                      │
│  ├── 发现 Server 提供的工具                                  │
│  ├── 发送工具调用请求                                        │
│  └── 处理 Server 返回的结果                                  │
│                                                             │
│  Server（服务端）                                            │
│  ├── 提供工具能力（Tool / Resource / Prompt）                │
│  ├── 处理 Client 的请求                                      │
│  ├── 执行具体的工具逻辑                                      │
│  └── 例：数据库工具、文件系统工具、API 工具                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、消息流

```
完整消息流：

1. 初始化
   Host → Client: 创建 Client 实例
   Client → Server: 建立连接
   Client → Server: 初始化请求（capabilities）
   Server → Client: 初始化响应（capabilities）

2. 工具发现
   Client → Server: tools/list 请求
   Server → Client: 工具列表（名称、描述、参数）

3. 工具调用
   User → Host: 用户请求
   Host → Client: 转发请求
   Client → Server: tools/call 请求
   Server: 执行工具
   Server → Client: 返回结果
   Client → Host: 转发结果
   Host → User: 展示结果
```

---

## 三、消息格式

```json
// 请求
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "database_query",
    "arguments": {
      "sql": "SELECT * FROM users LIMIT 10"
    }
  }
}

// 响应
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "[{\"id\": 1, \"name\": \"Alice\"}, ...]"
      }
    ]
  }
}
```

---

## 四、能力协商

```python
# Client 初始化请求
{
    "capabilities": {
        "tools": {},
        "resources": {"subscribe": true},
        "prompts": {}
    }
}

# Server 初始化响应
{
    "capabilities": {
        "tools": {"listChanged": true},
        "resources": {"subscribe": true},
        "prompts": {}
    }
}
```
