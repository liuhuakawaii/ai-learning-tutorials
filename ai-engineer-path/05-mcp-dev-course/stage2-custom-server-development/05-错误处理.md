## 一、错误类型

```
MCP 错误类型：

1. 协议错误
   - 解析错误（-32700）
   - 无效请求（-32600）
   - 方法未找到（-32601）

2. 工具错误
   - 工具不存在
   - 参数错误
   - 执行失败

3. 资源错误
   - 资源不存在
   - 访问被拒绝
   - 资源不可用

4. 系统错误
   - 内部错误（-32603）
   - 超时
   - 网络错误
```

## 二、错误处理实现

```python
from mcp.server import Server
from mcp.types import TextContent

server = Server("my-server")

@server.tool()
async def safe_tool(param: str) -> list[TextContent]:
    """带错误处理的工具"""
    try:
        # 参数验证
        if not param:
            return [TextContent(
                type="text",
                text="错误：参数不能为空"
            )]
        
        # 执行操作
        result = await risky_operation(param)
        return [TextContent(type="text", text=result)]
    
    except TimeoutError:
        return [TextContent(
            type="text",
            text="错误：操作超时，请稍后重试"
        )]
    
    except Exception as e:
        return [TextContent(
            type="text",
            text=f"错误：{str(e)}"
        )]
```

## 三、超时处理

```python
import asyncio

class TimeoutHandler:
    """超时处理器"""
    
    def __init__(self, timeout: float = 30.0):
        self.timeout = timeout
    
    async def execute_with_timeout(self, coro):
        """带超时的执行"""
        try:
            return await asyncio.wait_for(coro, timeout=self.timeout)
        except asyncio.TimeoutError:
            raise TimeoutError(f"操作超时（{self.timeout}秒）")

# 使用示例
timeout_handler = TimeoutHandler(timeout=10.0)

@server.tool()
async def slow_operation(param: str) -> list[TextContent]:
    """可能很慢的操作"""
    try:
        result = await timeout_handler.execute_with_timeout(
            slow_database_query(param)
        )
        return [TextContent(type="text", text=result)]
    except TimeoutError as e:
        return [TextContent(type="text", text=str(e))]
```

## 四、降级策略

```python
class FallbackHandler:
    """降级处理器"""
    
    def __init__(self):
        self.cache = {}
    
    async def execute_with_fallback(self, primary_coro, fallback_coro, cache_key: str = None):
        """带降级的执行"""
        try:
            result = await primary_coro
            if cache_key:
                self.cache[cache_key] = result
            return result
        except Exception:
            if cache_key and cache_key in self.cache:
                return self.cache[cache_key]
            return await fallback_coro

# 使用示例
fallback = FallbackHandler()

@server.tool()
async def resilient_query(sql: str) -> list[TextContent]:
```

## 五、重试机制

```python
class RetryHandler:
    """重试处理器"""
    
    def __init__(self, max_retries: int = 3, delay: float = 1.0):
        self.max_retries = max_retries
        self.delay = delay
    
    async def execute_with_retry(self, coro):
        """带重试的执行"""
        last_exception = None
        
        for attempt in range(self.max_retries):
            try:
                return await coro
            except Exception as e:
                last_exception = e
                if attempt < self.max_retries - 1:
                    await asyncio.sleep(self.delay * (attempt + 1))
        
        raise last_exception
```
