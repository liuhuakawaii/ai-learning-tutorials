# 04 批量操作——高效处理批量请求的 MCP 模式

> 批量操作可以显著提高效率，减少网络开销。

## 学习目标

- 掌握 MCP 批量操作的实现方法
- 理解批量处理的优势和场景
- 学会设计高效的批量接口

---

## 一、批量操作概念

```
批量操作的优势：

1. 减少网络开销
   - 一次请求处理多个操作
   - 减少 HTTP 请求次数

2. 提高效率
   - 批量数据库操作
   - 批量文件处理

3. 原子性
   - 批量操作可以保证原子性
   - 要么全部成功，要么全部失败
```

## 二、实现

```python
from mcp.server import Server
from mcp.types import TextContent

server = Server("my-server")

@server.tool()
async def batch_query(queries: list[str]) -> list[TextContent]:
    """批量查询"""
    results = []
    
    for sql in queries:
        result = await execute_sql(sql)
        results.append(result)
    
    return [TextContent(
        type="text",
        text=json.dumps(results)
    )]

@server.tool()
async def batch_insert(table: str, records: list[dict]) -> list[TextContent]:
    """批量插入"""
    
    async with pool.acquire() as conn:
        async with conn.transaction():
            for record in records:
                await conn.execute(
                    f"INSERT INTO {table} VALUES ($1, $2, $3)",
                    *record.values()
                )
    
    return [TextContent(
        type="text",
        text=f"成功插入 {len(records)} 条记录"
    )]
```

## 三、并行批量

```python
import asyncio

@server.tool()
async def parallel_batch_query(queries: list[str]) -> list[TextContent]:
    """并行批量查询"""
    
    async def execute_one(sql):
        return await execute_sql(sql)
    
    # 并行执行
    tasks = [execute_one(sql) for sql in queries]
    results = await asyncio.gather(*tasks)
    
    return [TextContent(
        type="text",
        text=json.dumps(results)
    )]
```

## 四、错误处理

```python
@server.tool()
async def safe_batch_insert(table: str, records: list[dict]) -> list[TextContent]:
    """安全的批量插入"""
    
    success_count = 0
    errors = []
    
    for i, record in enumerate(records):
        try:
            await insert_record(table, record)
            success_count += 1
        except Exception as e:
            errors.append({"index": i, "error": str(e)})
    
    return [TextContent(
        type="text",
        text=json.dumps({
            "success": success_count,
            "failed": len(errors),
            "errors": errors
        })
    )]
```
