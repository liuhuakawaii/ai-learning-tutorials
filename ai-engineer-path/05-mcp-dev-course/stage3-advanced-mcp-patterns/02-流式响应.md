# 02 流式响应——长时间运行 Tool 的进度通知与流式输出

> 有些 Tool 需要运行很长时间。流式响应让用户知道进度。

## 学习目标

- 掌握 MCP 流式响应的实现方法
- 理解进度通知和流式输出
- 学会长时间运行任务的处理

---

## 一、进度通知

```python
from mcp.server import Server
from mcp.types import TextContent, ProgressToken

server = Server("my-server")

@server.tool()
async def long_running_task(
    task: str,
    progress_token: ProgressToken = None
) -> list[TextContent]:
    """长时间运行的任务"""
    
    steps = ["初始化", "处理中", "验证", "完成"]
    
    for i, step in enumerate(steps):
        # 发送进度通知
        if progress_token:
            await server.send_progress(
                progress_token,
                progress=i + 1,
                total=len(steps),
                message=f"步骤 {i+1}/{len(steps)}: {step}"
            )
        
        # 执行步骤
        await asyncio.sleep(2)  # 模拟耗时操作
    
    return [TextContent(type="text", text="任务完成")]
```

## 二、流式输出

```python
@server.tool()
async def stream_data(query: str) -> list[TextContent]:
    """流式输出数据"""
    results = []
    
    async for chunk in stream_database_query(query):
        results.append(TextContent(
            type="text",
            text=chunk
        ))
    
    return results
```

## 三、取消支持

```python
@server.tool()
async def cancellable_task(
    task: str,
    cancellation_token: CancellationToken = None
) -> list[TextContent]:
    """可取消的任务"""
    
    for i in range(100):
        # 检查是否取消
        if cancellation_token and cancellation_token.is_cancelled:
            return [TextContent(type="text", text="任务已取消")]
        
        # 执行步骤
        await asyncio.sleep(0.1)
    
    return [TextContent(type="text", text="任务完成")]
```

## 四、使用示例

```python
# Client 端接收进度
async def run_with_progress():
    async with client:
        # 调用长时间任务
        result = await client.call_tool(
            "long_running_task",
            {"task": "处理数据"}
        )
        
        print(f"结果：{result}")
```
