# 阶段 1：全栈基础——让系统先跑起来

## 阶段目标

用 Vue 3 + FastAPI + PostgreSQL + Redis 搭建一个完整的 AI 应用骨架。不是 Hello World，是后面所有阶段的真实基础。

## 为什么先做全栈

很多 AI 课程直接从调 API 开始，结果学员做出来的 demo 没有用户系统、没有数据库、没有前端交互，根本无法变成产品。企业级 AI Agent 平台首先是一个 Web 应用——有前端界面、有后端服务、有数据库、有缓存。这些是地基。

## 实战任务

搭建 **AI 应用骨架**，包含：

- 用户注册与登录（JWT 认证）
- 基础对话界面（前端 Chat UI + 后端 API）
- 数据库模型（用户、会话、消息）
- Redis 会话缓存
- Docker Compose 开发环境

## 验收标准

- [ ] 能用 `docker compose up` 一键启动完整开发环境
- [ ] 前端能注册、登录、创建会话、发送消息
- [ ] 后端 API 能正确处理请求、返回 JSON、记录日志
- [ ] 数据库表结构正确，能通过迁移脚本管理
- [ ] Redis 缓存命中率正常，会话数据能正确读写
- [ ] 前后端类型定义共享，不存在隐式 `any`
