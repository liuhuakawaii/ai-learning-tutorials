## 一键部署脚本

```bash
#!/bin/bash
# deploy.sh

set -e

echo "🚀 开始部署..."

# 1. 拉取最新代码
git pull origin main

# 2. 构建镜像
docker compose build

# 3. 执行数据库迁移
docker compose run --rm backend alembic upgrade head

# 4. 启动服务
docker compose up -d

# 5. 等待健康检查
echo "⏳ 等待服务启动..."
sleep 30

# 6. 检查服务状态
docker compose ps

# 7. 运行冒烟测试
curl -f http://localhost/health || exit 1

echo "✅ 部署完成！"
```

## 回滚脚本

```bash
#!/bin/bash
# rollback.sh

PREVIOUS_VERSION=$1

if [ -z "$PREVIOUS_VERSION" ]; then
    echo "Usage: ./rollback.sh <version>"
    exit 1
fi

echo "🔄 回滚到版本 $PREVIOUS_VERSION..."

# 拉取上一版本镜像
docker compose pull

# 回滚数据库（如果有迁移）
# docker compose run --rm backend alembic downgrade -1

# 重启服务
docker compose up -d

echo "✅ 回滚完成！"
```
