# 05 人工审批节点

## 学习目标

- 实现人工审批节点

- 支持审批委托和批量审批

## 审批节点设计

```python
class HumanApprovalHandler:
    """人工审批节点处理器"""
    
    async def execute(self, node, inputs, context):
        approval_config = node.config
        
        # 创建审批请求
        approval_request = {
            "id": str(uuid.uuid4()),
            "execution_id": context.execution_id,
            "node_id": node.id,
            "title": approval_config.get("title", "需要审批"),
            "description": self._render_description(approval_config, context),
            "content": inputs,
            "approvers": approval_config.get("approvers", []),
            "timeout_minutes": approval_config.get("timeout", 60),
            "created_at": datetime.utcnow().isoformat(),
        }
        
        # 保存审批请求
        await self._save_approval(approval_request)
        
        # 发送通知
        await self._notify_approvers(approval_request)
        
        # 抛出暂停异常
        raise HumanApprovalRequired(approval_request)
```

## 审批 API

```python
# backend/app/api/v1/approvals.py
router = APIRouter(prefix="/api/v1/approvals", tags=["审批"])

@router.get("/pending")
async def list_pending_approvals(
    user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
):
    """获取待审批列表"""
    result = await db.execute(
        text("""
            SELECT * FROM approval_requests
            WHERE :user_id = ANY(approvers)
            AND status = 'pending'
            ORDER BY created_at DESC
        """),
        {"user_id": user.id},
    )
    return [dict(row) for row in result]

@router.post("/{approval_id}/approve")
async def approve(
    approval_id: str,
    request: ApprovalDecision,
    user: User = Depends(get_current_user),
):
    """审批通过"""
    approval = await get_approval(approval_id)
    
    if user.id not in approval["approvers"]:
        raise HTTPException(403, "无权审批")
    
    # 更新审批状态
    await update_approval_status(approval_id, "approved", user.id, request.comment)
    
    # 恢复工作流执行
    await resume_workflow_execution(approval["execution_id"], {
        "approved": True,
        "comment": request.comment,
    })
    
    return {"ok": True}

@router.post("/{approval_id}/reject")
async def reject(
    approval_id: str,
    request: ApprovalDecision,
    user: User = Depends(get_current_user),
):
    """审批拒绝"""
    approval = await get_approval(approval_id)
    
    await update_approval_status(approval_id, "rejected", user.id, request.comment)
    
    await resume_workflow_execution(approval["execution_id"], {
        "approved": False,
        "comment": request.comment,
    })
    
    return {"ok": True}
```

## 超时处理

```python
class ApprovalTimeoutWorker:
    """审批超时处理"""
    
    async def check_timeouts(self):
        """检查超时的审批请求"""
        result = await db.execute(
            text("""
                SELECT * FROM approval_requests
                WHERE status = 'pending'
                AND created_at + timeout_minutes * interval '1 minute' < now()
            """)
        )
        
        for approval in result:
            timeout_action = approval["timeout_action"]
            
            if timeout_action == "auto_approve":
                await self._auto_approve(approval)
            elif timeout_action == "auto_reject":
                await self._auto_reject(approval)
            elif timeout_action == "escalate":
                await self._escalate(approval)
```

## 练习

### 练习 1：审批节点

实现完整的人工审批节点：

1. 工作流执行到审批节点时暂停
2. 发送通知给审批人
3. 审批后恢复执行

### 练习 2：超时处理

实现审批超时机制：

1. 超时自动通过/拒绝/升级
2. 超时通知

## 本节要点

- 人工审批是 AI 安全的最后防线
- 审批节点暂停工作流，等待人类决策
- 超时处理防止工作流永远卡住
- 审批记录要完整可追溯

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 审批后不恢复 | 没触发工作流恢复 | 审批完成后调用 resume |
| 通知不到人 | 没配置通知渠道 | 集成邮件/企业微信 |
| 审批记录丢失 | 没持久化 | 存入数据库 |
