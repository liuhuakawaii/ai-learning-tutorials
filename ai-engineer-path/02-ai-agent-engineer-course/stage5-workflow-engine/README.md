# 阶段 5：工作流引擎——让复杂任务可编排

## 阶段目标

构建可视化 DAG 工作流引擎，支持条件分支、并行执行、人工审批、Skill 体系。让非开发人员也能编排复杂的 AI 任务。

## 实战任务

构建 **可视化工作流编排引擎**：

- DAG 可视化编辑器（拖拽节点、连线、配置参数）
- 多种节点类型：LLM 节点、工具节点、条件节点、审批节点
- 执行引擎：拓扑排序执行、状态追踪、错误恢复
- 条件分支和循环支持
- 人工审批：暂停等待、超时处理、通知提醒
- 并行执行：多分支同时运行、结果汇聚
- Skill 体系：4 种 Skill 类型的注册、配置和执行
- 执行日志：每步输入输出、耗时、状态可视化

## 验收标准

- [ ] 可视化编辑器能流畅拖拽、连线、配置，保存为 JSON
- [ ] 工作流能按 DAG 顺序正确执行，支持条件分支和循环
- [ ] 人工审批节点能正确暂停，超时后自动处理
- [ ] 并行节点能同时执行，汇聚节点能正确聚合结果
- [ ] Skill 能通过配置接入工作流，不需要写代码
- [ ] 执行日志完整，每步输入输出可查、可回放

## 技术栈

| 组件 | 技术 |
|------|------|
| 可视化编辑器 | Vue Flow（基于 React Flow 的 Vue 移植） |
| DAG 执行 | 自研执行引擎 / Celery + Redis |
| 表达式引擎 | 自研（支持变量引用、条件判断） |
| 任务队列 | Celery / BullMQ |
| 通知系统 | WebSocket + 邮件 / 企业微信 |
