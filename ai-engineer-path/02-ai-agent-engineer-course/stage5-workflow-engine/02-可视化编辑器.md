# 02 可视化编辑器

> 让非开发人员也能编排 AI 工作流——可视化是关键。

## 学习目标

- 使用 Vue Flow 实现 DAG 可视化编辑器
- 实现节点拖拽、连线、配置
- 设计属性面板和节点库

## 技术选型

| 库 | 特点 | 适用 |
|------|------|------|
| **Vue Flow** | Vue 3 原生、活跃维护 | **本课程推荐** |
| X6 (AntV) | 功能强大、文档完善 | 备选 |
| Rete.js | 节点编辑器框架 | 复杂场景 |

## 基础编辑器

```vue
<!-- frontend/src/views/WorkflowEditor.vue -->
<template>
  <div class="workflow-editor">
    <!-- 节点库 -->
    <div class="node-palette">
      <div class="palette-title">节点库</div>
      <div
        v-for="nodeType in nodeTypes"
        :key="nodeType.type"
        class="palette-item"
        draggable="true"
        @dragstart="onDragStart($event, nodeType)"
      >
        <n-icon :size="20"><component :is="nodeType.icon" /></n-icon>
        <span>{{ nodeType.label }}</span>
      </div>
    </div>

    <!-- 画布 -->
    <VueFlow
      v-model:nodes="nodes"
      v-model:edges="edges"
      :default-viewport="{ zoom: 1, x: 0, y: 0 }"
      @nodes-change="onNodesChange"
      @edges-change="onEdgesChange"
      @connect="onConnect"
      @drop="onDrop"
      @dragover.prevent
    >
      <!-- 自定义节点 -->
      <template #node-llm="props">
        <LLMNode v-bind="props" />
      </template>
      <template #node-tool="props">
        <ToolNode v-bind="props" />
      </template>
      <template #node-condition="props">
        <ConditionNode v-bind="props" />
      </template>
    </VueFlow>

    <!-- 属性面板 -->
    <div v-if="selectedNode" class="properties-panel">
      <div class="panel-title">{{ selectedNode.data.label }}</div>
      <component
        :is="getPropertiesComponent(selectedNode.type)"
        :node="selectedNode"
        @update="updateNodeConfig"
      />
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, markRaw } from 'vue'
import { VueFlow, useVueFlow } from '@vue-flow/core'
import '@vue-flow/core/dist/style.css'

const nodeTypes = [
  { type: 'input', label: '输入', icon: InputIcon },
  { type: 'llm', label: 'LLM 调用', icon: ChatIcon },
  { type: 'tool', label: '工具调用', icon: ToolIcon },
  { type: 'condition', label: '条件判断', icon: BranchIcon },
  { type: 'human', label: '人工审批', icon: PersonIcon },
  { type: 'output', label: '输出', icon: OutputIcon },
]

const nodes = ref([])
const edges = ref([])
const selectedNode = ref(null)

function onDragStart(event: DragEvent, nodeType: any) {
  event.dataTransfer.setData('application/vueflow', nodeType.type)
}

function onDrop(event: DragEvent) {
  const type = event.dataTransfer.getData('application/vueflow')
  const position = { x: event.offsetX, y: event.offsetY }
  
  nodes.value.push({
    id: `node-${Date.now()}`,
    type,
    position,
    data: { label: `新${nodeType.label}节点`, config: {} },
  })
}

function onConnect(params: any) {
  edges.value.push({
    id: `edge-${Date.now()}`,
    source: params.source,
    target: params.target,
    sourceHandle: params.sourceHandle,
  })
}
</script>
```

## 自定义节点组件

```vue
<!-- frontend/src/components/nodes/LLMNode.vue -->
<template>
  <div class="custom-node llm-node" :class="{ selected }">
    <div class="node-header">
      <n-icon><ChatIcon /></n-icon>
      <span>{{ data.label }}</span>
    </div>
    <div class="node-body">
      <div class="node-info">模型：{{ data.config.model || 'GPT-4o' }}</div>
    </div>
    <Handle type="target" :position="Position.Top" />
    <Handle type="source" :position="Position.Bottom" />
  </div>
</template>

<script setup lang="ts">
import { Handle, Position } from '@vue-flow/core'

defineProps({
  data: Object,
  selected: Boolean,
})
</script>
```

## 练习

### 练习 1：基础编辑器

实现 DAG 可视化编辑器：

1. 节点拖拽到画布
2. 节点之间连线
3. 节点选中和删除

### 练习 2：属性面板

为每种节点实现属性配置面板：

1. LLM 节点：选择模型、输入 Prompt
2. 工具节点：选择工具、配置参数
3. 条件节点：输入条件表达式

## 本节要点

- Vue Flow 是 Vue 3 生态最好的 DAG 编辑器
- 自定义节点让编辑器更直观
- 属性面板是配置节点的关键交互
- 拖拽 + 连线 = 非技术用户也能编排工作流
