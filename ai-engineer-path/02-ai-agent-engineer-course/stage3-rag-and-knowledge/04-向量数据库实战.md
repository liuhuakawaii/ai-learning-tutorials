## 为什么用 pgvector

| 方案 | 优点 | 缺点 |
|------|------|------|
| **pgvector** | 和 PostgreSQL 一体化、SQL 查询、事务安全 | 性能不如专用向量库 |
| Pinecone | 托管、简单 | 付费、数据在外部 |
| Milvus | 高性能 | 部署复杂、多一个组件 |
| Chroma | 轻量、简单 | 不适合生产 |

**pgvector 的核心优势**：不需要额外部署向量数据库，SQL 和向量查询在同一个数据库里，事务安全。

## pgvector 部署

Docker Compose 已经包含了 pgvector 镜像。启用扩展：

```sql
-- 在 PostgreSQL 中启用 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;
```

SQLAlchemy 中使用：

```python
# backend/app/models/document.py
from pgvector.sqlalchemy import Vector

class DocumentChunk(Base):
    __tablename__ = "document_chunks"
    
    id: Mapped[str] = mapped_column(String(36), primary_key=True)
    document_id: Mapped[str] = mapped_column(String(36), ForeignKey("documents.id"))
    content: Mapped[str] = mapped_column(Text)
    embedding = mapped_column(Vector(1536))  # OpenAI embedding 维度
    metadata_: Mapped[dict] = mapped_column("metadata", JSON, default=dict)
    chunk_index: Mapped[int] = mapped_column(Integer)
```

## Embedding 模型选择

| 模型 | 维度 | 价格 | 质量 | 适用 |
|------|------|------|------|------|
| text-embedding-3-small | 1536 | $0.02/1M tokens | 好 | 通用场景 |
| text-embedding-3-large | 3072 | $0.13/1M tokens | 很好 | 高精度需求 |
| BGE-M3 | 1024 | 免费（本地） | 好 | 中文场景、隐私要求 |
| GTE-large | 1024 | 免费（本地） | 好 | 中文场景 |

```python
# backend/app/services/embedding_service.py
from openai import AsyncOpenAI

class EmbeddingService:
    """Embedding 服务"""
    
    def __init__(self, provider: str = "openai", model: str = "text-embedding-3-small"):
        self.provider = provider
        self.model = model
        self.client = AsyncOpenAI() if provider == "openai" else None
    
    async def embed(self, text: str) -> list[float]:
        """生成单个文本的 Embedding"""
        if self.provider == "openai":
            response = await self.client.embeddings.create(
                model=self.model,
                input=text,
            )
            return response.data[0].embedding
        else:
            raise ValueError(f"Unknown provider: {self.provider}")
    
    async def batch_embed(self, texts: list[str]) -> list[list[float]]:
        """批量生成 Embedding（OpenAI 支持批量）"""
        if self.provider == "openai":
            # OpenAI 每次最多 2048 个文本
            all_embeddings = []
            for i in range(0, len(texts), 2048):
                batch = texts[i:i + 2048]
                response = await self.client.embeddings.create(
                    model=self.model,
                    input=batch,
                )
                embeddings = [item.embedding for item in response.data]
                all_embeddings.extend(embeddings)
            return all_embeddings
        else:
            return [await self.embed(text) for text in texts]
```

## 向量存储

```python
# backend/app/services/vector_store.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, text
from pgvector.sqlalchemy import Vector

class VectorStore:
    """向量存储服务"""
    
    def __init__(self, db: AsyncSession, embedding_service: EmbeddingService):
        self.db = db
        self.embedding = embedding_service
    
    async def add_chunks(
        self,
        document_id: str,
        chunks: list[DocumentChunk],
    ):
        """添加文档切片到向量库"""
        # 批量生成 Embedding
        texts = [chunk.content for chunk in chunks]
        embeddings = await self.embedding.batch_embed(texts)
        
        # 存储到数据库
        for chunk, embedding in zip(chunks, embeddings):
            db_chunk = DocumentChunkORM(
                id=str(uuid.uuid4()),
                document_id=document_id,
                content=chunk.content,
                embedding=embedding,
                metadata=chunk.metadata,
                chunk_index=chunk.chunk_index,
            )
            self.db.add(db_chunk)
        
        await self.db.flush()
    
    async def search(
        self,
        query: str,
        knowledge_base_id: str | None = None,
        top_k: int = 5,
        score_threshold: float = 0.7,
    ) -> list[dict]:
        """向量检索"""
        # 生成查询的 Embedding
        query_embedding = await self.embedding.embed(query)
        
        # pgvector 余弦相似度查询
        query_sql = """
            SELECT 
                id,
                document_id,
                content,
                metadata,
                1 - (embedding <=> :query_embedding) AS score
            FROM document_chunks
            WHERE 1 - (embedding <=> :query_embedding) > :threshold
            ORDER BY embedding <=> :query_embedding
            LIMIT :top_k
        """
        
        if knowledge_base_id:
            query_sql = """
                SELECT 
                    dc.id,
                    dc.document_id,
                    dc.content,
                    dc.metadata,
                    1 - (dc.embedding <=> :query_embedding) AS score
                FROM document_chunks dc
                JOIN documents d ON dc.document_id = d.id
                WHERE d.knowledge_base_id = :kb_id
                  AND 1 - (dc.embedding <=> :query_embedding) > :threshold
                ORDER BY dc.embedding <=> :query_embedding
                LIMIT :top_k
            """
        
        result = await self.db.execute(
            text(query_sql),
            {
                "query_embedding": str(query_embedding),
                "threshold": score_threshold,
                "top_k": top_k,
                "kb_id": knowledge_base_id,
            }
        )
        
        return [
            {
                "id": row.id,
                "document_id": row.document_id,
                "content": row.content,
                "metadata": row.metadata,
                "score": float(row.score),
            }
            for row in result
        ]
```

## 索引优化

当文档量超过 10 万条时，需要创建向量索引：

```sql
-- HNSW 索引（推荐：查询快，构建慢）
CREATE INDEX ON document_chunks USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);

-- IVFFlat 索引（构建快，查询稍慢）
CREATE INDEX ON document_chunks USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);
```

```python
# 在 VectorStore 中添加索引管理
async def create_index(self, index_type: str = "hnsw"):
    """创建向量索引"""
    if index_type == "hnsw":
        await self.db.execute(text("""
            CREATE INDEX IF NOT EXISTS idx_chunks_embedding_hnsw
            ON document_chunks USING hnsw (embedding vector_cosine_ops)
            WITH (m = 16, ef_construction = 64)
        """))
    elif index_type == "ivfflat":
        await self.db.execute(text("""
            CREATE INDEX IF NOT EXISTS idx_chunks_embedding_ivfflat
            ON document_chunks USING ivfflat (embedding vector_cosine_ops)
            WITH (lists = 100)
        """))
    
    await self.db.commit()
```

## 本节要点

- pgvector 是企业级 RAG 的最佳选择：无需额外组件、SQL 兼容、事务安全
- Embedding 模型选择影响检索质量，中文场景考虑 BGE 或 GTE
- 向量索引在大数据量下必须创建，HNSW 是首选
- 批量 Embedding 能显著降低成本和延迟

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 检索结果为空 | score_threshold 太高 | 降低阈值到 0.5-0.7 |
| 检索延迟高 | 没有向量索引 | 创建 HNSW 索引 |
| Embedding 维度不匹配 | 不同模型维度不同 | 统一使用同一个模型 |
| 存储失败 | pgvector 扩展没启用 | `CREATE EXTENSION vector` |
