# 第 2 阶段：RAG 系统评估

> 深入评估检索增强生成的每个环节

## 学习目标

- 掌握 RAG 系统的分离评估思路（检索 vs 生成）
- 理解并计算 Context Precision / Recall / Relevancy 等检索指标
- 学会使用 RAGAS 框架进行端到端 RAG 评估
- 能够定位 RAG 系统的瓶颈并给出优化建议

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | RAG 评估全景 — 检索质量与生成质量的分离评估思路 | 2h |
| 02 | 检索评估指标 — Context Precision / Recall / Relevancy 的计算 | 3h |
| 03 | 生成评估指标 — Faithfulness / Answer Relevancy / Hallucination 检测 | 3h |
| 04 | RAGAS 实战 — 用 RAGAS 框架评估你的 RAG pipeline | 3h |
| 05 | 端到端评估 — 从用户提问到最终回答的全链路质量度量 | 2h |
| 06 | 阶段实战：为 01-ai-app-course 的知识工作台搭建 RAG 评估套件 | 4h |

## 验收标准

- [ ] 能独立计算 RAG 系统的各项评估指标
- [ ] 使用 RAGAS 完成一次完整的 RAG 评估并输出报告
- [ ] 根据评估结果提出至少 3 条具体的优化建议
