# LLM Eval Pipeline Kit 项目说明

## 项目目标

为前两门课程的项目搭建一套完整的评估与可观测性系统。本 kit 提供离线可验证的评估 pipeline，学员可在不调用真实 API 的情况下练习评估流程，后续替换为真实模型调用。

## 内置 project kit

```text
03-llm-eval-course/final-project/eval-pipeline-kit
```

运行：

```bash
cd 03-llm-eval-course/final-project/eval-pipeline-kit
pip install -r requirements.txt
python scripts/check.py
python src/eval_pipeline.py
python src/ragas_eval.py
python src/dashboard.py
```

## 核心功能

1. 评估数据集管理
   - Golden Dataset 加载与校验
   - 评估样本的增删改查
   - 数据集版本管理

2. 自动化评估 Pipeline
   - LLM-as-Judge 自动打分
   - RAGAS 指标计算（Context Precision / Recall / Faithfulness）
   - 批量评估与结果汇总

3. 可观测性 Dashboard
   - 评估结果可视化（Streamlit）
   - 成本追踪（Token 消耗统计）
   - 质量趋势图

4. A/B 测试框架
   - 两组 Prompt / 模型的对比评估
   - 统计显著性检验
   - 对比报告生成

5. CI/CD 集成
   - 评估门禁脚本
   - 回归检测
   - GitHub Actions 集成示例

## 阶段交付物

| 阶段 | 交付物 | 对应文件 |
|------|--------|----------|
| 第一阶段 | 评估基础：指标定义、LLM-as-Judge 原型 | `reports/stage1-eval-basics.md` |
| 第二阶段 | RAG 评估：RAGAS 指标计算、检索质量分析 | `reports/stage2-rag-eval.md` |
| 第三阶段 | Agent 评估：工具调用准确率、多步推理评估 | `reports/stage3-agent-eval.md` |
| 第四阶段 | 可观测性：Langfuse 集成、Dashboard 搭建 | `reports/stage4-observability.md` |
| 第五阶段 | 持续评估：CI 集成、A/B 测试、回归检测 | `reports/stage5-continuous-eval.md` |

## 验收标准

- `python scripts/check.py` 通过
- 能加载 Golden Dataset 并运行评估 pipeline
- RAGAS 指标计算结果可复现
- Dashboard 能展示评估结果
- A/B 测试能输出对比报告
- CI 门禁脚本能判断评估是否通过
