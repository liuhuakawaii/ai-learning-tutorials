# 03 多步推理评估——任务完成率、步骤合理性、回退处理

> Agent 的价值在于处理复杂任务。多步推理评估就是检验它"想得对不对、做得好不好"。

## 学习目标

- 掌握多步推理任务的评估方法
- 学会评估任务规划和执行质量

## 一、多步推理评估维度

### 1.1 任务完成率

```python
def evaluate_task_completion(
    task_description: str,
    agent_output: str,
    expected_outcome: str,
    client
) -> dict:
    """评估任务完成情况"""
    
    prompt = f"""评估 Agent 是否完成了用户任务。

任务描述：{task_description}
期望结果：{expected_outcome}
Agent 输出：{agent_output}

评估：
1. 任务是否完成？
2. 完成质量如何？
3. 是否有遗漏？

请以 JSON 格式输出：
{{"completed": true/false, "quality": <1-5>, "missing": ["遗漏1"], "reasoning": "理由"}}"""

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
        response_format={"type": "json_object"}
    )
    
    return json.loads(response.choices[0].message.content)
```

### 1.2 步骤合理性

```python
def evaluate_step_reasoning(
    task: str,
    execution_trace: list[dict],
    client
) -> dict:
    """评估执行步骤的合理性"""
    
    trace_text = "\n".join([
        f"步骤 {s['step']}: {s['thought']} → {s['action']}"
        for s in execution_trace
    ])
    
    prompt = f"""评估 Agent 执行步骤的合理性。

任务：{task}

执行步骤：
{trace_text}

评估：
1. 步骤顺序是否合理？
2. 是否有冗余步骤？
3. 是否有遗漏步骤？
4. 每步的推理是否正确？

请以 JSON 格式输出：
{{"reasoning_quality": <1-5>, "redundant_steps": [], "missing_steps": [], "issues": ["问题1"]}}"""

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
        response_format={"type": "json_object"}
    )
    
    return json.loads(response.choices[0].message.content)
```

### 1.3 回退处理

```python
def evaluate_error_recovery(
    execution_trace: list[dict],
    client
) -> dict:
    """评估错误恢复能力"""
    
    errors = [s for s in execution_trace if s.get("status") == "error"]
    
    if not errors:
        return {"recovery_rate": 1.0, "errors": 0, "recovered": 0}
    
    recovered = 0
    for error in errors:
        # 检查错误后是否有成功的步骤
        error_idx = execution_trace.index(error)
        subsequent = execution_trace[error_idx+1:]
        if any(s.get("status") == "success" for s in subsequent):
            recovered += 1
    
    return {
        "recovery_rate": recovered / len(errors),
        "errors": len(errors),
        "recovered": recovered,
        "unrecovered_errors": [
            e for e in errors 
            if not any(s.get("status") == "success" 
                      for s in execution_trace[execution_trace.index(e)+1:])
        ]
    }
```

## 二、综合评估框架

```python
class MultiStepEvaluator:
    """多步推理评估器"""
    
    def __init__(self, client):
        self.client = client
    
    def evaluate(
        self,
        task: str,
        execution_trace: list[dict],
        final_output: str,
        expected_outcome: str
    ) -> dict:
        """综合评估多步推理"""
        
        results = {
            "task_completion": evaluate_task_completion(
                task, final_output, expected_outcome, self.client
            ),
            "step_reasoning": evaluate_step_reasoning(
                task, execution_trace, self.client
            ),
            "error_recovery": evaluate_error_recovery(
                execution_trace, self.client
            ),
        }
        
        # 综合评分
        completion_score = results["task_completion"]["quality"] / 5.0
        reasoning_score = results["step_reasoning"]["reasoning_quality"] / 5.0
        recovery_score = results["error_recovery"]["recovery_rate"]
        
        results["overall_score"] = (
            completion_score * 0.5 +
            reasoning_score * 0.3 +
            recovery_score * 0.2
        )
        
        return results
```

## 三、诊断与优化

```
多步推理问题诊断：

问题 1：任务完成率低
  原因：
    - 任务理解错误
    - 规划能力不足
    - 工具调用失败
  优化：
    - 优化任务理解 Prompt
    - 增强规划能力的训练
    - 提高工具调用的可靠性

问题 2：步骤合理性低
  原因：
    - 推理能力不足
    - 缺乏先验知识
    - Prompt 设计不当
  优化：
    - 优化推理 Prompt
    - 提供更多示例
    - 使用更强的模型

问题 3：错误恢复率低
  原因：
    - 错误处理策略不足
    - 缺乏回退机制
    - 没有重试逻辑
  优化：
    - 添加错误处理策略
    - 实现回退机制
    - 设计重试逻辑
```
