# 第 3 阶段：Agent 系统评估

> 解决 Agent 评估的特殊挑战：非确定性、多步骤、工具调用

## 学习目标

- 理解 Agent 评估与传统软件测试的本质区别
- 掌握工具调用、多步推理、安全性等维度的评估方法
- 学会设计 Agent 行为的端到端评估场景
- 能够建立 Agent 系统的质量度量体系

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | Agent 评估的特殊性 — 为什么传统测试方法不够用 | 2h |
| 02 | 工具调用评估 — 准确率、参数正确性、调用效率 | 3h |
| 03 | 多步推理评估 — 任务完成率、步骤合理性、回退处理 | 3h |
| 04 | 安全性评估 — 越狱检测、输出安全、权限边界 | 3h |
| 05 | 成本与延迟分析 — Token 消耗追踪、调用链路耗时优化 | 2h |
| 06 | 阶段实战：为 02-ai-agent-engineer-course 的 Agent 平台搭建评估体系 | 4h |

## 验收标准

- [ ] 设计至少 10 个 Agent 评估场景（覆盖工具调用、多步推理、异常处理）
- [ ] 完成一次完整的 Agent 评估并输出结构化报告
- [ ] 能够区分"Agent 能力问题"和"Prompt 设计问题"
