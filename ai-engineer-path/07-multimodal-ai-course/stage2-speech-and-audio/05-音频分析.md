# 05 音频分析——会议录音摘要、情感分析、说话人分离

> 音频分析让 AI 能理解和分析音频内容。

## 场景引入

你的公司每周有 50+ 场会议录音，管理层要求：自动提取每场会议的摘要和行动项、分析参会者的情绪倾向、识别不同说话人的发言内容。手动完成这些工作需要专人每场花 1-2 小时整理。你想用 AI 自动化，但发现：多人同时说话时语音识别效果很差、情绪分析的主观性强难以量化、说话人分离在音频质量差时错误率很高——音频分析比单纯的语音转文字复杂得多。

## 学习目标

- 掌握音频分析的方法
- 实现会议摘要、情感分析、说话人分离
- 学会处理各种音频场景

## 一、会议摘要

```python
def meeting_summary(audio_path: str) -> str:
    """会议摘要"""
    # 1. 语音识别
    transcript = transcribe_audio(audio_path)
    
    # 2. 生成摘要
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": f"请为以下会议记录生成摘要，包括主要议题、决策和行动项：\n\n{transcript}"
        }]
    )
    return response.choices[0].message.content
```

## 三、说话人分离

```python
from pyannote.audio import Pipeline

def speaker_diarization(audio_path: str) -> list:
    """说话人分离"""
    # 加载模型
    pipeline = Pipeline.from_pretrained(
        "pyannote/speaker-diarization-3.1",
        use_auth_token="YOUR_TOKEN"
    )
    
    # 处理
    diarization = pipeline(audio_path)
    
    # 提取结果
    speakers = []
    for turn, _, speaker in diarization.itertracks(yield_label=True):
        speakers.append({
            "start": turn.start,
            "end": turn.end,
            "speaker": speaker
        })
    
    return speakers
```

## 四、关键词提取

```python
def extract_keywords(audio_path: str) -> list:
    """关键词提取"""
    transcript = transcribe_audio(audio_path)
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": f"请从以下文本中提取关键词：\n\n{transcript}"
        }],
        response_format={"type": "json_object"}
    )
    return json.loads(response.choices[0].message.content)["keywords"]
```

```python
def full_audio_analysis(audio_path: str) -> dict:
```

## 常见误区

1. **把语音识别和音频分析混为一谈**：语音识别只是把语音转成文字，音频分析还需要在此基础上做摘要、情感分析、说话人分离等更高层的任务。
2. **忽略多人说话的场景**：会议录音通常有多人同时说话、交叉发言的情况，不做说话人分离直接识别会导致结果混乱。
3. **过度依赖情感分析的结果**：语音情感分析的准确率有限，语调、语速等特征受个人习惯影响大，结果只能作为参考而非决策依据。
4. **不做音频预处理就分析**：背景噪音、回声、音量不一致会严重影响分析质量，必须先做降噪和音量标准化。

## 工程建议

1. **Pipeline 化处理**：降噪 → 语音识别 → 说话人分离 → 文本分析（摘要/情感/关键词），每步独立可替换。
2. **说话人分离用专用模型**：pyannote.audio 是当前最好的开源说话人分离方案，比自己训练模型效果好且维护成本低。
3. **建立评估基准**：收集典型会议录音和人工标注的摘要/情感/说话人标签，量化评估每个环节的准确率。
4. **结果结构化存储**：将分析结果存为结构化数据（JSON），包含时间戳、说话人、情绪、关键词等字段，方便后续检索和统计。
