# 01 语音识别概览——Whisper / SenseVoice / Azure ASR 的选型

> 语音识别让 AI 能听懂人说话。

## 学习目标

- 了解主流语音识别模型
- 掌握不同模型的特点和适用场景
- 学会根据需求选择合适的模型

---

## 一、主流语音识别模型

```
主流语音识别模型：

1. Whisper (OpenAI)
   - 开源、免费
   - 多语言支持
   - 准确率高
   - 适用：通用场景

2. SenseVoice (阿里)
   - 开源、免费
   - 中文优化
   - 实时识别
   - 适用：中文场景

3. Azure Speech (微软)
   - 商业服务
   - 实时识别
   - 功能丰富
   - 适用：企业场景

4. Google Speech-to-Text
   - 商业服务
   - 多语言支持
   - 准确率高
   - 适用：通用场景
```

---

## 二、能力对比

```
能力对比：

| 模型 | 准确率 | 中文支持 | 实时识别 | 价格 |
|------|--------|----------|----------|------|
| Whisper | 高 | 好 | 不支持 | 免费 |
| SenseVoice | 高 | 很好 | 支持 | 免费 |
| Azure | 很高 | 好 | 支持 | 付费 |
| Google | 很高 | 好 | 支持 | 付费 |
```

---

## 三、选型建议

```
选型建议：

通用场景 → Whisper
中文场景 → SenseVoice
实时识别 → Azure / Google
预算有限 → Whisper / SenseVoice
```

## 四、API 使用

```python
# Whisper API
def transcribe_audio(audio_path: str) -> str:
    """语音识别"""
    with open(audio_path, "rb") as audio_file:
        response = client.audio.transcriptions.create(
            model="whisper-1",
            file=audio_file
        )
    return response.text
```

## 五、本地部署

```python
import whisper

# 加载模型
model = whisper.load_model("base")

# 识别
result = model.transcribe("audio.mp3")
print(result["text"])
```
