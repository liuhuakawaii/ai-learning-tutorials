# 第 2 阶段：语音与音频

> 让 AI 听懂和开口说话

## 学习目标

- 了解主流语音识别方案（Whisper / SenseVoice / Azure ASR）的选型
- 掌握 Whisper 的本地部署和高质量语音转文字
- 学会集成语音合成（TTS）能力
- 能够构建一个完整的语音对话 AI 助手

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 语音识别概览 — Whisper / SenseVoice / Azure ASR 的选型 | 2h |
| 02 | Whisper 实战 — 本地部署 Whisper 实现高质量语音转文字 | 3h |
| 03 | 语音合成 — OpenAI TTS / Edge-TTS 的集成与音色选择 | 3h |
| 04 | 实时语音交互 — 构建一个语音对话的 AI 助手原型 | 3h |
| 05 | 音频分析 — 会议录音摘要、情感分析、说话人分离 | 3h |
| 06 | 阶段实战：构建一个语音驱动的 AI 助手（ASR → LLM → TTS） | 4h |

## 验收标准

- [ ] Whisper 能正确转录中英文语音，准确率达到可用水平
- [ ] 语音助手能完成"语音输入 → AI 处理 → 语音输出"的完整流程
- [ ] 能处理会议录音的摘要和关键信息提取
