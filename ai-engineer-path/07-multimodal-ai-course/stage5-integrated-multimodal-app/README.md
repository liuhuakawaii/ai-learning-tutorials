# 第 5 阶段：多模态应用整合

> 将所有模态能力整合成一个完整的应用

## 学习目标

- 掌握多模态应用的架构设计（统一输入层 / 模态路由 / 融合推理）
- 学会构建统一处理文本、图片、语音、文档的输入网关
- 理解多模态调用的成本、延迟、缓存优化策略
- 能够开发一个支持全模态输入的 AI 助手

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 多模态架构设计 — 统一输入层 / 模态路由 / 融合推理 | 3h |
| 02 | 输入处理网关 — 统一处理文本、图片、语音、文档的输入 | 3h |
| 03 | 多模态 Agent — 让 Agent 具备视觉和听觉能力 | 3h |
| 04 | 流式多模态输出 — 图文混排、语音流式输出的前端渲染 | 3h |
| 05 | 性能与成本 — 多模态调用的 Token 计算、延迟优化、缓存策略 | 2h |
| 06 | 阶段实战：构建一个支持文本 + 图片 + 语音 + 文档的全能 AI 助手 | 4h |

## 验收标准

- [ ] 应用能同时处理文本、图片、语音、文档四种输入
- [ ] 模态路由能自动识别输入类型并分发到对应处理模块
- [ ] 完成性能测试报告（延迟、成本、并发能力）
