你接到最终任务：构建一个支持文本 + 图片 + 语音 + 文档的全能 AI 助手。这个助手需要做到：用户输入文字能回答问题，上传图片能分析内容，录一段语音能听懂并语音回复，上传 PDF 能理解并回答相关问题，甚至可以同时输入图片和文字做综合分析。你需要把前 5 个阶段学到的所有能力——视觉处理、语音交互、文档理解、多模态 RAG、架构设计——整合成一个完整的端到端系统。

## 一、系统架构

```
全能 AI 助手：

输入层 → 模态识别 → 处理层 → 融合推理 → 输出层
  │          │          │          │        │
  ▼          ▼          ▼          ▼        ▼
文本/图片   识别类型   处理输入   融合结果  文本/语音

```

## 二、核心实现

```python
class UniversalAssistant:
    """全能 AI 助手"""
    
    def __init__(self):
        self.gateway = InputGateway()
        self.agent = MultimodalAgent()
        self.rag = MultimodalRAG()
    
    def process(self, inputs: dict) -> dict:
        """处理输入"""
        # 输入处理
        processed = {}
        for key, value in inputs.items():
            processed[key] = self.gateway.process(value)
        
        # 检索增强
        if "text" in processed:
            rag_results = self.rag.ask(processed["text"]["content"])
            processed["rag"] = rag_results
        
        # Agent 处理
        result = self.agent.process(processed)
        
        return result
```

## 三、使用示例

```python
assistant = UniversalAssistant()

# 文本问答
result = assistant.process({"text": "什么是 AI？"})

# 图片分析
result = assistant.process({"image": "photo.jpg"})

# 语音对话
result = assistant.process({"audio": "question.mp3"})

# 文档问答
result = assistant.process({"document": "report.pdf", "text": "总结这份报告"})
```

## 四、Web 界面

```python
import gradio as gr

def assistant_interface(text, image, audio, document):
    assistant = UniversalAssistant()
    
    inputs = {}
    if text:
        inputs["text"] = text
    if image:
        inputs["image"] = image
    if audio:
        inputs["audio"] = audio
    if document:
        inputs["document"] = document
    
    result = assistant.process(inputs)
    return result["text_output"], result.get("audio_output")

demo = gr.Interface(
    fn=assistant_interface,
    inputs=[
        gr.Textbox(label="文本"),
        gr.Image(type="filepath", label="图片"),
        gr.Audio(type="filepath", label="语音"),
        gr.File(label="文档")
    ],
    outputs=[
        gr.Textbox(label="回答"),
        gr.Audio(label="语音回答")
    ]
)

demo.launch()
```

## 常见误区

1. **追求功能全面忽略核心体验**：什么都想支持但每个功能都做得很粗糙，不如先把核心场景（如文本+图片）做到极致再扩展。
2. **不做端到端测试就上线**：单个模块测试通过不代表整体可用，端到端的集成测试才能发现模块间的兼容问题。
3. **忽略移动端适配**：很多用户在手机上使用，不做移动端适配会丢失大量用户。
4. **不做用户引导**：功能太多用户不知道怎么用，需要做交互引导和使用示例。

## 工程建议

1. **渐进式开发**：先做文本问答 → 加图片理解 → 加语音交互 → 加文档处理，每步验证后再加新功能。
2. **做好模块间的解耦**：输入处理、模态识别、能力调用、结果生成各模块独立部署和扩展，方便团队协作。
3. **建立完整的测试体系**：单元测试（每个模块）→ 集成测试（模块间协作）→ 端到端测试（完整链路）→ 性能测试（并发场景）。
4. **收集用户反馈持续迭代**：上线后收集用户使用数据和反馈，识别高频场景和痛点，持续优化体验。
