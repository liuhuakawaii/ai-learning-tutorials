# 03 跨模态检索——用文字搜图片、用图片搜文字

> 跨模态检索是多模态 RAG 的核心能力。

## 场景引入

你要为一个电商平台实现"以图搜商品"功能：用户上传一张在社交媒体上看到的衣服照片，系统需要从百万商品库中找到同款或相似款。同时还要支持反向场景——用户输入"蓝色条纹衬衫"，系统返回匹配的商品图片。这就是跨模态检索：用文字搜图片、用图片搜文字。看似简单的功能背后，需要解决图文向量空间对齐、相似度阈值设定、检索结果排序等技术难题。

## 四、混合检索

```python
def hybrid_search(query: str, query_type: str, target_type: str, top_k: int = 5) -> list:
    """混合检索"""
    if query_type == "text":
        embedding = get_text_embedding(query)
    else:
        embedding = get_image_embedding(query)
    
    where_filter = {"type": target_type} if target_type else None
    
    results = collection.query(
        query_embeddings=[embedding],
        n_results=top_k,
        where=where_filter
    )
    
    return results
```

## 六、评估

```python
def evaluate_retrieval(query: str, expected_results: list, actual_results: list) -> dict:
    """评估检索效果"""
    # 计算准确率
    correct = len(set(expected_results) & set(actual_results))
    precision = correct / len(actual_results) if actual_results else 0
    recall = correct / len(expected_results) if expected_results else 0
    
    return {
        "precision": precision,
        "recall": recall,
        "f1": 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
    }
```

## 常见误区

1. **只做向量检索不做排序**：向量相似度最高的结果不一定是用户最想要的，需要结合业务规则（销量、评分、价格）做重排序。
2. **忽略相似度阈值的设定**：没有阈值过滤会返回大量不相关的结果，阈值太高又会漏掉相关结果，需要根据业务场景调优。
3. **不做检索结果的多样性控制**：返回的 top-k 结果可能非常相似（如同一款衣服的不同角度），需要做多样性打散。
4. **评估指标只看准确率不看召回率**：准确率高但召回率低意味着漏掉了很多相关结果，需要同时关注两个指标。

## 工程建议

1. **实现混合检索**：向量检索 + 元数据过滤（类别、价格区间、品牌），先过滤再排序，提高检索精度。
2. **做 A/B 测试优化阈值**：用真实用户行为数据（点击、购买）优化相似度阈值和排序权重。
3. **缓存热门查询结果**：高频查询的结果做缓存，减少向量检索的计算开销。
4. **建立检索质量监控**：定期统计无结果率、点击率、首屏命中率等指标，持续优化检索效果。
