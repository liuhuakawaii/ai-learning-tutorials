# Multimodal AI Assistant Kit 项目说明

## 项目目标

构建一个多模态 AI 知识助手：支持文本问答、图片分析、语音交互、文档解析，集成多模态 RAG 和可观测性系统。本 kit 提供 Mock 模式的多模态 pipeline 骨架，学员可先练架构设计，再接入真实 API。

## 内置 project kit

```text
07-multimodal-ai-course/final-project/multimodal-assistant-kit
```

运行：

```bash
cd 07-multimodal-ai-course/final-project/multimodal-assistant-kit
pip install -r requirements.txt
python scripts/check.py
python src/main.py --mock
python src/main.py --input "这是一张产品图片" --image data/sample.jpg
```

## 核心功能

1. 多模态输入网关
   - 文本输入：直接处理
   - 图片输入：Vision API 调用（GPT-4o / Claude Vision）
   - 语音输入：Whisper ASR 转文字
   - 文档输入：PDF/Word 解析提取

2. 模态路由
   - 自动识别输入类型
   - 路由到对应的处理 pipeline
   - 多模态输入的融合处理

3. 多模态 RAG
   - CLIP 图文向量化
   - 图文混合索引与检索
   - 跨模态问答

4. 多模态输出
   - 文本回答（带引用）
   - 图片生成（DALL-E 3 / SD）
   - 语音输出（TTS）

5. 可观测性
   - 多模态调用链路追踪
   - Token / 图片 / 音频成本统计
   - 延迟分析

## 阶段交付物

| 阶段 | 交付物 | 对应文件 |
|------|--------|----------|
| 第一阶段 | 视觉能力：图片理解、OCR、图表分析 | `reports/stage1-vision.md` |
| 第二阶段 | 语音能力：ASR、TTS、语音对话 | `reports/stage2-voice.md` |
| 第三阶段 | 文档能力：PDF 解析、表格提取、文档问答 | `reports/stage3-document.md` |
| 第四阶段 | 多模态 RAG：图文混合检索、跨模态问答 | `reports/stage4-multimodal-rag.md` |
| 第五阶段 | 应用整合：全能助手、性能优化、部署 | `reports/stage5-integration.md` |

## 验收标准

- `python scripts/check.py` 通过
- Mock 模式能处理文本、图片、语音、文档四种输入
- 模态路由能正确识别输入类型
- 多模态 RAG 能实现图文混合检索
- 输出支持文本 + 图片 + 语音三种模态
- 成本统计覆盖所有模态的 API 调用
