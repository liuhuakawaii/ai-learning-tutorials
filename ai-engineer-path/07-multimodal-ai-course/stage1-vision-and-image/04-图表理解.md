# 04 图表理解——让 AI 解读柱状图、折线图、流程图

> 图表理解是数据可视化分析的关键能力。

## 场景引入

你是一家数据分析公司的工程师，客户每天上传大量包含柱状图、折线图、流程图的截图，要求从中提取数据和关键洞察。传统做法是人工逐张查看图表并手动录入数据，一个分析师一天最多处理 50 张图表。你想用 AI 自动化这个流程，但发现：不同图表类型的解读逻辑完全不同，坐标轴刻度需要精确读取，复合图表（双 Y 轴、堆叠柱状图）的理解难度远超简单图表。

## 学习目标

- 掌握图表理解的方法
- 实现各种图表的解读
- 学会从图表中提取数据和洞察

## 一、柱状图理解

```python
def understand_bar_chart(image_url: str) -> dict:
    """理解柱状图"""
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {
                "role": "user",
                "content": [
                    {"type": "text", "text": """请分析这张柱状图：
1. 图表标题
2. X 轴和 Y 轴含义
3. 各柱子的数值
4. 主要趋势和发现

请以 JSON 格式输出。"""},
                    {"type": "image_url", "image_url": {"url": image_url}}
                ]
            }
        ],
        response_format={"type": "json_object"}
    )
    return json.loads(response.choices[0].message.content)
```

## 常见误区

1. **认为模型能精确读取图表数值**：大模型对图表的理解是"近似"的，坐标轴上的精确数值经常读错，需要精确数据时应结合 OCR 工具。
2. **混淆图表理解和数据提取**：理解趋势和提取精确数据是两个不同任务，前者用大模型效果好，后者需要专门的数据提取方案。
3. **忽略图表类型的差异**：柱状图、折线图、饼图、流程图的解读逻辑完全不同，用同一个 prompt 处理所有图表类型效果会很差。
4. **不做结果人工抽检**：图表理解的主观性强，自动评估困难，生产环境必须保留人工抽检环节。

## 工程建议

1. **按图表类型设计专用 Prompt**：识别图表类型后，路由到对应的专用 prompt，比通用 prompt 的准确率高 20% 以上。
2. **先 OCR 再理解**：对于需要精确数值的场景，先用 OCR 提取坐标轴和标签文字，再让模型做趋势分析。
3. **建立图表理解的评估基准**：收集典型图表和人工标注的标准答案，量化评估模型的准确率。
4. **输出结构化数据而非自然语言**：要求模型输出 JSON 格式的数据点，方便后续入库和可视化，而不是一段描述性文字。
