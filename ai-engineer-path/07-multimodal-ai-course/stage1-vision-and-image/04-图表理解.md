> 图表理解是数据可视化分析的关键能力。

## 学习目标

- 掌握图表理解的方法

## 一、柱状图理解

```python
def understand_bar_chart(image_url: str) -> dict:
    """理解柱状图"""
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {
                "role": "user",
                "content": [
                    {"type": "text", "text": """请分析这张柱状图：
1. 图表标题
2. X 轴和 Y 轴含义
3. 各柱子的数值
4. 主要趋势和发现

请以 JSON 格式输出。"""},
                    {"type": "image_url", "image_url": {"url": image_url}}
                ]
            }
        ],
        response_format={"type": "json_object"}
    )
    return json.loads(response.choices[0].message.content)
```
