# 01 多模态模型概览——GPT-4o / Claude Vision / Gemini 的能力对比

> 多模态大模型让 AI 能看懂图片、听懂语音。

## 学习目标

- 了解主流多模态大模型的能力
- 掌握不同模型的特点和适用场景
- 学会根据需求选择合适的模型

---

## 一、主流多模态模型

```
主流多模态模型：

1. GPT-4o (OpenAI)
   - 支持：文本、图片、音频
   - 特点：能力强、响应快
   - 适用：通用场景

2. Claude 3.5 Sonnet (Anthropic)
   - 支持：文本、图片
   - 特点：推理能力强、安全性高
   - 适用：复杂推理、安全敏感场景

3. Gemini Pro Vision (Google)
   - 支持：文本、图片、视频
   - 特点：多模态能力强
   - 适用：视觉分析场景

4. Qwen-VL (阿里)
   - 支持：文本、图片
   - 特点：中文能力强
   - 适用：中文场景
```

## 三、API 使用

```python
from openai import OpenAI

client = OpenAI()

# GPT-4o 图片理解
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "描述这张图片"},
                {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
            ]
        }
    ]
)
```
