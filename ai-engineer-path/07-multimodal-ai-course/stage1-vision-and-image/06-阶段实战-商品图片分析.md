# 06 阶段实战——构建一个商品图片智能分析系统

> 把前 5 课学到的视觉知识整合成一个完整的商品分析系统。

## 场景引入

你接到一个真实项目需求：为一个中型电商平台构建商品图片智能分析系统。运营团队每天上传上千张商品图片，需要自动完成三件事：识别商品类别和属性（颜色、材质、风格）、提取图片中的品牌文字和规格信息、生成吸引用户的营销文案。目前这三件事分别由三个不同团队手动完成，效率低且标准不统一。你需要把前 5 课学到的视觉能力整合成一个端到端的自动化系统。

## 学习目标

## 二、核心实现

```python
class ProductImageAnalyzer:
    """商品图片分析器"""
    
    def __init__(self):
        self.client = OpenAI()
    
    def analyze(self, image_url: str) -> dict:
        """分析商品图片"""
        
        # 1. 图片理解
        description = self._describe_image(image_url)
        
        # 2. 信息提取
        attributes = self._extract_attributes(image_url)
        
        # 3. 描述生成
        marketing_copy = self._generate_marketing_copy(attributes)
        
        return {
            "description": description,
            "attributes": attributes,
            "marketing_copy": marketing_copy
        }
    
    def _describe_image(self, image_url: str) -> str:
        """描述图片"""
        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[{
                "role": "user",
                "content": [
                    {"type": "text", "text": "请详细描述这张商品图片"},
                    {"type": "image_url", "image_url": {"url": image_url}}
                ]
            }]
        )
        return response.choices[0].message.content
    
    def _extract_attributes(self, image_url: str) -> dict:
        """提取商品属性"""
        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[{
                "role": "user",
                "content": [
                    {"type": "text", "text": "请提取商品的名称、类别、颜色、材质、尺寸等属性，以 JSON 格式输出"},
                    {"type": "image_url", "image_url": {"url": image_url}}
                ]
            }],
            response_format={"type": "json_object"}
        )
        return json.loads(response.choices[0].message.content)
    
    def _generate_marketing_copy(self, attributes: dict) -> str:
        """生成营销文案"""
        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[{
                "role": "user",
                "content": f"根据以下商品属性生成一段营销文案：{json.dumps(attributes, ensure_ascii=False)}"
            }]
        )
        return response.choices[0].message.content
```

## 四、批量处理

```python
def batch_analyze(image_urls: list) -> list:
    """批量分析"""
    results = []
    
    for url in image_urls:
        result = analyzer.analyze(url)
        results.append(result)
    
    return results
```

## 常见误区

1. **把所有分析逻辑塞进一个 API 调用**：试图用一个 prompt 同时完成分类、OCR、描述生成，结果每个任务都做不好，应该拆分成独立步骤串联。
2. **不做异常处理就上线**：图片 URL 失效、格式不支持、API 超时等异常在生产环境很常见，必须做完善的错误处理和降级策略。
3. **忽略批量处理的并发限制**：单线程逐张处理上千张图片会非常慢，但直接并发又容易触发 API 限流，需要做速率控制。
4. **不做 A/B 测试就全量上线**：新模型或新 prompt 的效果需要用真实流量验证，直接全量替换风险很大。

## 工程建议

1. **Pipeline 化设计**：将分析流程拆分为独立的步骤（预处理 → 分类 → OCR → 描述生成），每步可独立测试和替换。
2. **引入异步任务队列**：大批量图片用 Celery 或 asyncio 处理，配合重试机制和死信队列，保证任务不丢失。
3. **建立质量评估体系**：定义每个环节的评估指标（分类准确率、OCR 字符准确率、文案相关性），定期回归测试。
4. **做好成本预算和监控**：每张图片的 API 调用成本可精确计算，上线前做好月度成本预估，设置预算告警。
