# 03 表格提取——从 PDF 和图片中提取结构化表格数据

> 表格是文档中最重要的结构化数据。

## 场景引入

你的公司财务部门需要从数百份 PDF 格式的发票和报表中提取表格数据，手动复制粘贴到 Excel 中不仅耗时（一份复杂报表需要 30 分钟），而且经常出错。你想用 AI 自动化表格提取，但测试后发现：PDF 中的表格线条有时是图片而非矢量、合并单元格的处理非常棘手、扫描件中的表格 OCR 后行列对不齐、嵌套表头的结构识别困难——表格提取是文档处理中公认的技术难题。

## 学习目标

- 掌握表格提取的方法
- 理解表格识别和结构化
- 学会处理各种表格格式

## 一、PDF 表格提取

```python
from unstructured.partition.pdf import partition_pdf

def extract_tables_from_pdf(pdf_path: str) -> list:
    """从 PDF 提取表格"""
    elements = partition_pdf(pdf_path, strategy="hi_res")
    
    tables = []
    for element in elements:
        if element.category == "Table":
            tables.append(element.text)
    
    return tables
```

## 三、表格解析

```python
import pandas as pd

def parse_table(table_text: str) -> pd.DataFrame:
    """解析表格"""
    # 使用 pandas 解析
    lines = table_text.strip().split("\n")
    headers = lines[0].split("\t")
    
    data = []
    for line in lines[1:]:
        row = line.split("\t")
        data.append(row)
    
    return pd.DataFrame(data, columns=headers)
```

## 四、表格增强

```python
def enhance_table(table: pd.DataFrame) -> pd.DataFrame:
    """增强表格"""
    # 清洗数据
    table = table.dropna(how="all")
    
    # 转换类型
    for col in table.columns:
        try:
            table[col] = pd.to_numeric(table[col])
        except:
            pass
    
    return table
```

## 五、批量处理

```python
def batch_table_extraction(pdf_paths: list) -> dict:
    """批量表格提取"""
    results = {}
    
    for path in pdf_paths:
        tables = extract_tables_from_pdf(path)
        results[path] = tables
    
    return results
```

## 常见误区

1. **认为所有 PDF 表格都能自动提取**：表格以图片形式存在时，传统 PDF 解析工具无法识别，需要用 OCR 或 Vision API 处理。
2. **忽略合并单元格和跨行跨列**：真实报表中大量存在合并单元格，简单的行列解析会导致数据错位，需要专门的合并单元格处理逻辑。
3. **不做数据类型转换**：提取出来的表格数据全是字符串，金额字段的逗号、日期字段的格式都需要做类型转换和清洗。
4. **一次性处理整页大图**：整页表格图片分辨率高且包含非表格区域，先裁剪表格区域再识别效果更好。

## 工程建议

1. **区分矢量表格和图片表格**：矢量 PDF 用 camelot 或 tabula 提取，图片表格用 Vision API 或专门的表格识别模型。
2. **用 pandas 做后处理**：提取后的原始数据用 pandas 做数据清洗、类型转换、去重、格式标准化，输出干净的 DataFrame。
3. **建立表格结构验证**：检查行列数是否一致、是否有空行空列、数据类型是否符合预期，自动发现和修复常见问题。
4. **保留表格位置信息**：存储时记录表格在文档中的页码和位置，方便后续溯源和人工复核。
