## 一、分布式训练方式

```
分布式训练方式：

1. Data Parallel（数据并行）
   - 每个 GPU 处理不同的数据
   - 同步梯度更新
   - 最常用的方式

2. Model Parallel（模型并行）
   - 模型分片到多个 GPU
   - 适合超大模型
   - 通信开销大

3. Pipeline Parallel（流水线并行）
   - 模型按层分片
   - 减少通信开销
   - 实现复杂
```

## 二、Accelerate 配置

```bash
# 配置 Accelerate
accelerate config

# 启动训练
accelerate launch train.py
```

```python
from accelerate import Accelerator

accelerator = Accelerator()

model, optimizer, dataloader = accelerator.prepare(
    model, optimizer, dataloader
)

for batch in dataloader:
    outputs = model(**batch)
    loss = outputs.loss
    accelerator.backward(loss)
    optimizer.step()
    optimizer.zero_grad()
```

## 四、常见问题

```
常见问题：

1. GPU 负载不均衡
   - 检查数据分布
   - 调整 batch_size

2. 通信瓶颈
   - 使用高速网络
   - 减少通信频率

3. 内存不均衡
   - 使用 gradient_checkpointing
   - 调整模型分片

4. 训练不同步
   - 检查梯度同步
   - 调整学习率
```

## 五、性能监控

```python
import torch

def monitor_gpu():
    """监控 GPU 使用"""
    for i in range(torch.cuda.device_count()):
        memory = torch.cuda.memory_allocated(i) / 1024**3
        print(f"GPU {i}: {memory:.1f} GB")
```
