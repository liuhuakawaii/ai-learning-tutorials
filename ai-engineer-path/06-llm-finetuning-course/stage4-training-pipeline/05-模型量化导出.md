# 05 模型量化导出——将微调模型导出为 GGUF / GPTQ 格式

> 量化让模型更小、更快，适合部署到资源受限的环境。

## 学习目标

- 掌握模型量化的方法和工具
- 理解不同量化格式的特点
- 学会导出量化模型

---

## 一、量化方法

```
量化方法：

1. GGUF
   - 用于 llama.cpp
   - 支持多种量化级别
   - 单文件格式

2. GPTQ
   - GPU 友好
   - 推理速度快
   - 需要校准数据

3. AWQ
   - 激活感知量化
   - 质量损失小
   - GPU 友好
```

---

## 二、GGUF 导出

```bash
# 转换为 GGUF
python convert_hf_to_gguf.py ./merged_model --outfile model-f16.gguf

# 量化为 Q4_K_M
./llama-quantize model-f16.gguf model-q4_k_m.gguf Q4_K_M

# 量化为 Q8_0
./llama-quantize model-f16.gguf model-q8_0.gguf Q8_0
```

---

## 三、GPTQ 量化

```python
from transformers import AutoModelForCausalLM, GPTQConfig

# GPTQ 量化配置
gptq_config = GPTQConfig(
    bits=4,
    dataset="c4",
    group_size=128
)

# 量化模型
model = AutoModelForCausalLM.from_pretrained(
    "./merged_model",
    quantization_config=gptq_config
)

# 保存
model.save_pretrained("./model-gptq")
```

---

## 四、AWQ 量化

```python
from awq import AutoAWQForCausalLM

# 加载模型
model = AutoAWQForCausalLM.from_pretrained("./merged_model")

# 量化
model.quantize(
    tokenizer,
    quant_config={"zero_point": True, "q_group_size": 128}
)

# 保存
model.save_pretrained("./model-awq")
```

## 五、量化对比

```
量化对比：

| 格式 | 大小 | 速度 | 质量 | 适用场景 |
|------|------|------|------|----------|
| FP16 | 14GB | 基准 | 最好 | GPU 部署 |
| Q4_K_M | 4GB | 快 | 好 | CPU/边缘 |
| GPTQ | 4GB | 很快 | 好 | GPU 部署 |
| AWQ | 4GB | 很快 | 很好 | GPU 部署 |
```

---

## 六、部署选择

```
部署选择：

资源充足（GPU）→ GPTQ / AWQ
资源受限（CPU）→ GGUF Q4_K_M
边缘设备 → GGUF Q2_K / Q3_K_M
质量优先 → GGUF Q8_0 / FP16
```
