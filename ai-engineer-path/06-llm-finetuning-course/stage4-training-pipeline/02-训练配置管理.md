## 一、配置文件设计

```yaml
# config.yaml
model:
  name: "Qwen/Qwen2.5-7B"
  dtype: "float16"
  device_map: "auto"

lora:
  r: 16
  alpha: 32
  target_modules: ["q_proj", "v_proj", "k_proj", "o_proj"]
  dropout: 0.05

training:
  epochs: 3
  batch_size: 4
  gradient_accumulation: 4
  learning_rate: 2e-4
  warmup_ratio: 0.1
  max_seq_length: 2048

data:
  path: "training_data.json"
  train_split: 0.9
  eval_split: 0.1

output:
  dir: "./output"
  save_strategy: "epoch"
  logging_steps: 10
```

## 二、配置加载

```python
import yaml

def load_config(config_path: str) -> dict:
    """加载配置"""
    with open(config_path, "r") as f:
        return yaml.safe_load(f)

# 使用
config = load_config("config.yaml")
model_name = config["model"]["name"]
learning_rate = config["training"]["learning_rate"]
```

## 三、配置验证

```python
from pydantic import BaseModel

class LoRAConfig(BaseModel):
    r: int
    alpha: int
    target_modules: list
    dropout: float

class TrainingConfig(BaseModel):
    epochs: int
    batch_size: int
    learning_rate: float

class Config(BaseModel):
    model: dict
    lora: LoRAConfig
    training: TrainingConfig

# 验证
config = Config(**yaml.safe_load(open("config.yaml")))
```

## 五、配置模板

```python
def create_experiment_config(experiment_name: str, **kwargs) -> dict:
    """创建实验配置"""
    base_config = load_config("base_config.yaml")
    
    # 覆盖参数
    for key, value in kwargs.items():
        keys = key.split(".")
        config = base_config
        for k in keys[:-1]:
            config = config[k]
        config[keys[-1]] = value
    
    # 保存
    save_config(f"experiments/{experiment_name}/config.yaml", base_config)
    
    return base_config
```
