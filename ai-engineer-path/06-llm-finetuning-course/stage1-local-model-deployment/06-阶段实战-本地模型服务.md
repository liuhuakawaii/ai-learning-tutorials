---

## 一、部署方案选择

```
部署方案对比：

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| Ollama | 简单易用 | 性能一般 | 开发测试 |
| vLLM | 高性能 | 配置复杂 | 生产部署 |
| llama.cpp | 资源占用低 | 功能有限 | 边缘部署 |

推荐：
- 开发测试 → Ollama
- 生产部署 → vLLM
- 资源受限 → llama.cpp
```

---

## 二、完整部署流程

```bash
# 1. 安装 Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 2. 下载模型
ollama pull llama3

# 3. 启动服务
ollama serve

# 4. 测试
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"llama3","messages":[{"role":"user","content":"你好"}]}'
```

## 四、效果对比

```python
def compare_models(question: str):
    """对比本地和云端模型"""
    
    # 本地模型
    local_response = local_client.chat.completions.create(
        model="llama3",
        messages=[{"role": "user", "content": question}]
    )
    
    # 云端模型
    cloud_response = cloud_client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": question}]
    )
    
    print(f"问题：{question}")
    print(f"本地模型：{local_response.choices[0].message.content}")
    print(f"云端模型：{cloud_response.choices[0].message.content}")
```

## 五、性能测试

```python
import time

def benchmark_model(client, model: str, question: str, iterations: int = 10):
    """性能测试"""
    times = []
    
    for _ in range(iterations):
        start = time.time()
        response = client.chat.completions.create(
            model=model,
            messages=[{"role": "user", "content": question}]
        )
        times.append(time.time() - start)
    
    return {
        "avg_time": sum(times) / len(times),
        "min_time": min(times),
        "max_time": max(times)
    }
```
