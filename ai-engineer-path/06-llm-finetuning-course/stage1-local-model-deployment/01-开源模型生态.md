# 01 开源模型生态——Llama / Qwen / Mistral / DeepSeek 的选型指南

> 开源大模型百花齐放。选对模型是本地部署的第一步。

## 学习目标

- 了解主流开源大模型生态
- 掌握模型选型的关键因素
- 学会根据场景选择合适的模型

---

## 一、主流开源模型

```
主流开源大模型：

1. Llama 3 (Meta)
   - 参数：8B / 70B / 405B
   - 特点：性能均衡、社区活跃
   - 适用：通用场景

2. Qwen 2.5 (阿里)
   - 参数：0.5B / 1.5B / 3B / 7B / 14B / 72B
   - 特点：中文能力强、多模态支持
   - 适用：中文场景

3. Mistral (Mistral AI)
   - 参数：7B / 8x7B / 8x22B
   - 特点：高效、MoE 架构
   - 适用：资源受限场景

4. DeepSeek (DeepSeek)
   - 参数：7B / 16B / 67B
   - 特点：代码能力强、推理能力好
   - 适用：代码和推理场景
```

---

## 二、选型因素

```
模型选型因素：

1. 任务类型
   - 通用对话 → Llama 3 / Qwen 2.5
   - 代码生成 → DeepSeek Coder
   - 数学推理 → DeepSeek Math
   - 中文场景 → Qwen 2.5

2. 硬件资源
   - 8GB VRAM → 7B 模型
   - 16GB VRAM → 13B 模型
   - 24GB VRAM → 70B 模型（量化）

3. 性能要求
   - 延迟敏感 → 小模型
   - 质量优先 → 大模型
   - 平衡考虑 → 中等模型

4. 部署方式
   - 本地部署 → Ollama / llama.cpp
   - 云端部署 → vLLM / TGI
   - 边缘部署 → 量化小模型
```
