# 第 2 阶段：微调基础

> 理解微调的核心概念和准备工作

## 学习目标

- 理解 Prompt Engineering / RAG / Fine-tuning 三种方法的适用场景
- 掌握 LoRA / QLoRA 的核心原理和工程优势
- 学会设计和构造高质量的微调数据集
- 能够为垂直领域构建符合格式要求的训练数据

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 为什么微调 — Prompt Engineering vs RAG vs Fine-tuning 的选型 | 2h |
| 02 | 微调方法全景 — Full Fine-tuning / LoRA / QLoRA / Prefix Tuning | 3h |
| 03 | LoRA 原理详解 — 低秩适配的数学直觉与工程优势 | 3h |
| 04 | 数据准备 — 训练数据格式、清洗、去重、质量控制 | 3h |
| 05 | 指令微调数据 — Alpaca / ShareGPT 格式的数据构造方法 | 3h |
| 06 | 阶段实战：为一个垂直领域（如法律/医疗/电商）构造微调数据集 | 4h |

## 验收标准

- [ ] 能解释 LoRA 的核心原理（低秩矩阵分解）和为什么有效
- [ ] 构建一个包含 500+ 高质量样本的微调数据集
- [ ] 数据集通过格式校验和质量检查
