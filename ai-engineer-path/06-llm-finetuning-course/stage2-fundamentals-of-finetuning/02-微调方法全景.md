# 02 微调方法全景——Full Fine-tuning / LoRA / QLoRA / Prefix Tuning

> 了解各种微调方法，选择最适合你的方案。

## 场景引入

你决定微调模型，但搜了一圈发现方法多得让人眼花：Full Fine-tuning、LoRA、QLoRA、Prefix Tuning、Adapter、P-Tuning……每个论文都说自己的方法最好。Full FT 效果最好但要 80GB 显存，LoRA 只需 16GB 但效果能保证吗？QLoRA 进一步压缩到 6GB，代价又是什么？选错方法可能浪费数天时间和几百块 GPU 费用。

---

## 学习目标

- 了解各种微调方法的原理和特点
- 掌握 LoRA 和 QLoRA 的核心概念
- 学会根据场景选择合适的微调方法

---

## 一、微调方法概览

```
微调方法：

1. Full Fine-tuning（全量微调）
   - 更新所有参数
   - 效果最好
   - 资源需求最高

2. LoRA（Low-Rank Adaptation）
   - 只更新低秩矩阵
   - 效果接近全量微调
   - 资源需求低

3. QLoRA（Quantized LoRA）
   - 量化 + LoRA
   - 进一步降低资源需求
   - 适合消费级硬件

4. Prefix Tuning
   - 只更新前缀参数
   - 资源需求最低
   - 效果有限
```

---

## 二、LoRA 原理

```
LoRA 原理：

原始模型参数：W (d × d)
LoRA 分解：W + ΔW = W + B × A

其中：
- A: (r × d) 低秩矩阵
- B: (d × r) 低秩矩阵
- r: 秩（通常 4-64）

优势：
- 只需训练 A 和 B
- 参数量大幅减少
- 效果接近全量微调
```

---

## 三、QLoRA 原理

```
QLoRA 原理：

1. 将模型量化为 4-bit
2. 在量化模型上应用 LoRA
3. 只训练 LoRA 参数

优势：
- 内存占用大幅减少
- 7B 模型只需 6GB 显存
- 效果接近 LoRA
```

---

## 四、方法对比

```
方法对比：

| 方法 | 参数量 | 显存需求 | 效果 | 适用场景 |
|------|--------|----------|------|----------|
| Full FT | 100% | 很高 | 最好 | 充足资源 |
| LoRA | 0.1-1% | 中等 | 很好 | 推荐方案 |
| QLoRA | 0.1-1% | 低 | 好 | 消费级硬件 |
| Prefix | 0.01% | 很低 | 一般 | 资源受限 |
```

---

## 五、选型建议

```
选型建议：

资源充足（多卡 A100）→ Full Fine-tuning
资源一般（单卡 A100）→ LoRA
资源有限（RTX 4090）→ QLoRA
资源紧张（RTX 3060）→ QLoRA + 更小的模型
```

---

## 常见误区

1. **认为 Full Fine-tuning 一定效果最好**：当数据量不足时，全量微调反而容易过拟合，效果可能不如 LoRA。数据量小于 1000 条时，LoRA 通常是更安全的选择。

2. **QLoRA 效果一定比 LoRA 差很多**：实验表明 QLoRA 和 LoRA 的效果差距通常在 1-2% 以内。对于大多数应用场景，这个差距完全可以接受，而显存节省是巨大的。

3. **看到 Prefix Tuning 参数最少就选它**：Prefix Tuning 虽然参数量极小（<0.1%），但在复杂任务上效果明显不如 LoRA。参数少不等于性价比高。

4. **忽略方法的工程成熟度**：LoRA 拥有最成熟的工具链（PEFT、TRL）和最大的社区支持。选择一个工具链不成熟的方法，后续遇到问题可能找不到解决方案。

---

## 工程建议

1. **LoRA 是默认选择**：除非有明确理由，否则一律用 LoRA。它的效果、效率、工具链成熟度都是最优的，是目前微调社区的事实标准。

2. **显存不够用 QLoRA，不要降模型**：与其用更小的模型 + LoRA，不如用目标模型 + QLoRA。QLoRA 的质量损失远小于模型参数量减半带来的能力下降。

3. **先跑基准再选方法**：在同一数据集上分别用 LoRA 和 QLoRA 跑一个快速实验（1 epoch），对比效果后再做最终选择，而不是纯靠理论判断。

4. **关注新方法但不急于采用**：持续关注 DoRA、rsLoRA 等新方法的进展，但等它们的工具链和社区验证成熟后再考虑采用。
