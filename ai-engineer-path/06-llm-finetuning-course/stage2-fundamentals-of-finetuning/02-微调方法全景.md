# 02 微调方法全景——Full Fine-tuning / LoRA / QLoRA / Prefix Tuning

> 了解各种微调方法，选择最适合你的方案。

## 学习目标

- 了解各种微调方法的原理和特点
- 掌握 LoRA 和 QLoRA 的核心概念
- 学会根据场景选择合适的微调方法

---

## 一、微调方法概览

```
微调方法：

1. Full Fine-tuning（全量微调）
   - 更新所有参数
   - 效果最好
   - 资源需求最高

2. LoRA（Low-Rank Adaptation）
   - 只更新低秩矩阵
   - 效果接近全量微调
   - 资源需求低

3. QLoRA（Quantized LoRA）
   - 量化 + LoRA
   - 进一步降低资源需求
   - 适合消费级硬件

4. Prefix Tuning
   - 只更新前缀参数
   - 资源需求最低
   - 效果有限
```

---

## 二、LoRA 原理

```
LoRA 原理：

原始模型参数：W (d × d)
LoRA 分解：W + ΔW = W + B × A

其中：
- A: (r × d) 低秩矩阵
- B: (d × r) 低秩矩阵
- r: 秩（通常 4-64）

优势：
- 只需训练 A 和 B
- 参数量大幅减少
- 效果接近全量微调
```

---

## 三、QLoRA 原理

```
QLoRA 原理：

1. 将模型量化为 4-bit
2. 在量化模型上应用 LoRA
3. 只训练 LoRA 参数

优势：
- 内存占用大幅减少
- 7B 模型只需 6GB 显存
- 效果接近 LoRA
```

---

## 四、方法对比

```
方法对比：

| 方法 | 参数量 | 显存需求 | 效果 | 适用场景 |
|------|--------|----------|------|----------|
| Full FT | 100% | 很高 | 最好 | 充足资源 |
| LoRA | 0.1-1% | 中等 | 很好 | 推荐方案 |
| QLoRA | 0.1-1% | 低 | 好 | 消费级硬件 |
| Prefix | 0.01% | 很低 | 一般 | 资源受限 |
```

---

## 五、选型建议

```
选型建议：

资源充足（多卡 A100）→ Full Fine-tuning
资源一般（单卡 A100）→ LoRA
资源有限（RTX 4090）→ QLoRA
资源紧张（RTX 3060）→ QLoRA + 更小的模型
```

## 小结

```
本课核心要点：

2. LoRA 是目前最推荐的微调方法
3. QLoRA 适合消费级硬件
4. 根据资源选择合适的方法
```
