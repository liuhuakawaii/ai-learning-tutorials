# 04 模型部署——用 vLLM 部署微调模型并提供 OpenAI 兼容 API

---

## 一、vLLM 部署

```bash
# 部署微调模型
python -m vllm.entrypoints.openai.api_server \
  --model ./merged_model \
  --host 0.0.0.0 \
  --port 8000
```

---

## 二、Docker 部署

```dockerfile
FROM vllm/vllm-openai:latest

COPY ./merged_model /model

CMD ["--model", "/model", "--host", "0.0.0.0", "--port", "8000"]
```

```yaml
version: '3.8'
services:
  model:
    build: .
    ports:
      - "8000:8000"
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
```

---

## 三、API 使用

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="./merged_model",
    messages=[{"role": "user", "content": "什么是高血压？"}]
)

print(response.choices[0].message.content)
```
