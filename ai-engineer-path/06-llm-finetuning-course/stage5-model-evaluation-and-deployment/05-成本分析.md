# 05 成本分析——API 调用 vs 本地部署的 TCO 对比与决策框架

> 选择 API 还是本地部署，成本是关键因素。

## 学习目标

- 掌握 TCO（总拥有成本）的计算方法
- 理解 API 和本地部署的成本结构
- 学会做出成本效益最优的决策

---

## 一、成本结构

```
API 调用成本：
- 按 Token 计费
- 无前期投入
- 成本随用量线性增长

本地部署成本：
- 硬件成本（GPU 服务器）
- 电力成本
- 运维成本
- 前期投入大，边际成本低
```

---

## 二、TCO 计算

```python
def calculate_api_cost(monthly_requests: int, avg_tokens: int, price_per_token: float) -> float:
    """计算 API 成本"""
    return monthly_requests * avg_tokens * price_per_token

def calculate_local_cost(
    hardware_cost: float,
    monthly_power_cost: float,
    monthly_maintenance_cost: float,
    months: int
) -> float:
    """计算本地部署成本"""
    return hardware_cost + (monthly_power_cost + monthly_maintenance_cost) * months
```

---

## 三、决策框架

```
决策框架：

月请求量 < 100K → API 调用
月请求量 100K-1M → 需要详细分析
月请求量 > 1M → 本地部署

其他因素：
- 数据隐私要求 → 倾向本地
- 延迟要求高 → 倾向本地
- 快速上线 → 倾向 API
- 预算有限 → 倾向 API
```

---

## 四、盈亏分析

```python
def breakeven_analysis(api_cost_per_month: float, local_cost_per_month: float) -> int:
    """盈亏平衡分析"""
    # 假设硬件成本
    hardware_cost = 10000  # $10,000
    
    # 计算多少个月后本地部署更划算
    monthly_savings = api_cost_per_month - local_cost_per_month
    
    if monthly_savings <= 0:
        return -1  # API 更划算
    
    return hardware_cost / monthly_savings
```

---

## 五、成本优化

```
成本优化策略：

API 调用：
- 使用更便宜的模型
- 优化 Prompt 减少 Token
- 缓存常见请求
- 批处理请求

本地部署：
- 使用量化模型
- 优化推理性能
- 合理规划资源
- 自动扩缩容
```

## 六、决策报告

```python
def generate_cost_report(api_cost: float, local_cost: float, breakeven_months: int) -> str:
    """生成成本报告"""
    
    report = f"""# 成本分析报告

## API 调用
- 月成本：${api_cost:.2f}
- 年成本：${api_cost * 12:.2f}

## 本地部署
- 月成本：${local_cost:.2f}
- 年成本：${local_cost * 12:.2f}

## 决策建议
- 盈亏平衡：{breakeven_months} 个月
- {'建议本地部署' if breakeven_months < 12 else '建议 API 调用'}
"""
    return report
```
