## 二、部署流程

```python
def deploy_model(model_path: str, config: dict):
    """部署模型"""
    
    # 1. 合并 LoRA
    merged_model = merge_lora(model_path)
    
    # 2. 量化
    quantized_model = quantize_model(merged_model, config["quantization"])
    
    # 3. 导出
    export_model(quantized_model, config["output_format"])
    
    # 4. 部署
    start_server(quantized_model, config["deployment"])
```
