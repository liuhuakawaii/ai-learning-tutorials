# 04 训练超参数——Learning Rate / Epoch / Batch Size / LoRA Rank 调优

> 超参数调优是微调成功的关键。好的超参数能让效果提升 10% 以上。

## 学习目标

- 理解各超参数的作用和影响
- 掌握超参数调优的方法
- 学会根据训练情况调整超参数

---

## 一、关键超参数

```
关键超参数：

1. Learning Rate（学习率）
   - 控制参数更新幅度
   - 太大：训练不稳定
   - 太小：训练缓慢
   - 推荐：1e-5 到 3e-4

2. Epochs（训练轮数）
   - 数据集遍历次数
   - 太少：欠拟合
   - 太多：过拟合
   - 推荐：3-10

3. Batch Size（批次大小）
   - 每次训练的样本数
   - 受限于显存
   - 推荐：4-16

4. LoRA Rank（LoRA 秩）
   - LoRA 的表达能力
   - 越大效果越好，但参数越多
   - 推荐：8-64
```

---

## 二、调优策略

```
调优策略：

1. 学习率调优
   - 从小开始（1e-5）
   - 逐步增大
   - 观察 loss 变化
   - 选择 loss 下降最快的

2. Epochs 调优
   - 监控验证集 loss
   - loss 不再下降时停止
   - 使用 early stopping

3. Batch Size 调优
   - 受限于显存
   - 用梯度累积模拟大 batch
   - 大 batch 训练更稳定

4. LoRA Rank 调优
   - 从小开始（8）
   - 逐步增大
   - 效果不再提升时停止
```

## 五、超参数搜索

import optuna

def objective(trial):
    """超参数搜索目标函数"""
    lr = trial.suggest_float("learning_rate", 1e-5, 3e-4, log=True)
    r = trial.suggest_categorical("lora_rank", [8, 16, 32, 64])
    
    # 训练模型
    result = train_with_params(lr, r)
    
    return result["eval_loss"]

# 运行搜索
study = optuna.create_study(direction="minimize")
study.optimize(objective, n_trials=20)

## 六、调优经验

```
调优经验：

1. 学习率
   - LoRA 推荐：2e-4
   - QLoRA 推荐：2e-4
   - 如果 loss 震荡，降低学习率

2. Epochs
   - 小数据集（<1000）：5-10 epochs
   - 大数据集（>10000）：1-3 epochs

3. Batch Size
   - 显存允许的情况下尽量大
   - 用梯度累积模拟

4. LoRA Rank
   - 简单任务：8-16
   - 复杂任务：32-64
```
