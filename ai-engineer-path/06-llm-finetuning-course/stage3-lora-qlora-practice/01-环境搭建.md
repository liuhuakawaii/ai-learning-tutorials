# 01 环境搭建——CUDA / PyTorch / Transformers / PEFT 的正确安装

> 正确的环境是微调的基础。环境问题是最常见的坑。

## 场景引入

你按照教程写好了微调代码，一运行就报错：`CUDA out of memory`、`No module named 'peft'`、`torch.cuda.is_available() returns False`……折腾了一整天，还没开始训练就被环境问题劝退了。CUDA 版本和 PyTorch 版本不匹配、Transformers 和 PEFT 版本冲突、bitsandbytes 在 Windows 上编译失败——这些坑几乎每个新手都会踩。正确的环境配置是微调的第一步，也是最容易出错的一步。

```bash
# 检查 GPU
nvidia-smi

# 安装 CUDA（以 12.1 为例）
# 下载：https://developer.nvidia.com/cuda-toolkit

# 验证安装
nvcc --version
```

## 二、PyTorch 安装

```bash
# 安装 PyTorch（CUDA 12.1）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 验证
python -c "import torch; print(torch.cuda.is_available())"
```

## 六、常见问题

```
常见问题及解决：

1. CUDA 版本不匹配
   - 检查：nvidia-smi 和 nvcc --version
   - 解决：安装匹配的 PyTorch 版本

2. GPU 内存不足
   - 检查：torch.cuda.get_device_properties(0).total_memory
   - 解决：使用更小的模型或量化

3. 模型下载失败
   - 检查：网络连接
   - 解决：使用镜像或手动下载

4. 依赖冲突
   - 检查：pip list
   - 解决：使用虚拟环境
```

## 七、Docker 环境

```dockerfile
FROM nvidia/cuda:12.1.0-runtime-ubuntu22.04

RUN apt-get update && apt-get install -y python3 python3-pip

RUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
RUN pip3 install transformers datasets accelerate peft bitsandbytes

WORKDIR /app
COPY . .

CMD ["python3", "train.py"]
```

## 常见误区

1. **CUDA 和 PyTorch 版本不匹配**：nvidia-smi 显示的 CUDA 版本和 nvcc --version 不一致很常见。PyTorch 需要的 CUDA 版本由安装命令中的 `cuXXX` 决定，而不是 nvidia-smi 显示的版本。

2. **用 pip 安装 CUDA 相关包**：bitsandbytes 等包需要 CUDA 运行时支持，pip 安装可能找不到正确的 CUDA 库。Linux 上推荐用 conda 或直接从源码编译。

3. **不在虚拟环境中安装**：全局安装容易导致包版本冲突。每次微调项目都应该创建独立的虚拟环境（venv 或 conda），避免依赖地狱。

4. **忽略 Windows 兼容性问题**：bitsandbytes、flash-attention 等关键依赖在 Windows 上支持不佳。Windows 用户推荐使用 WSL2 或 Docker 进行微调。

---

## 工程建议

1. **用 Docker 一键搭建环境**：基于 `nvidia/cuda:12.1.0-runtime-ubuntu22.04` 构建 Docker 镜像，把所有依赖写进 Dockerfile，确保环境可复现。

2. **写环境检查脚本**：把 GPU 检查、CUDA 检查、PyTorch 检查、PEFT 检查写成一个脚本，每次新建环境后运行一次，5 秒内确认环境是否正常。

3. **锁定依赖版本**：用 `pip freeze > requirements.txt` 锁定所有依赖版本，避免不同时间安装导致版本不一致。

4. **准备离线安装包**：在有网络的环境提前下载好所有 wheel 包，打包到离线环境安装，避免在训练服务器上因网络问题卡住。
