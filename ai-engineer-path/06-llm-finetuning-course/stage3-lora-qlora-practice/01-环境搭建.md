# 01 环境搭建——CUDA / PyTorch / Transformers / PEFT 的正确安装

> 正确的环境是微调的基础。环境问题是最常见的坑。

## 学习目标

- 掌握 CUDA 和 PyTorch 的安装方法
- 理解 Transformers 和 PEFT 的配置
- 学会解决常见的环境问题

---

## 一、CUDA 安装

```bash
# 检查 GPU
nvidia-smi

# 安装 CUDA（以 12.1 为例）
# 下载：https://developer.nvidia.com/cuda-toolkit

# 验证安装
nvcc --version
```

---

## 二、PyTorch 安装

```bash
# 安装 PyTorch（CUDA 12.1）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 验证
python -c "import torch; print(torch.cuda.is_available())"
```

---

## 三、Transformers 安装

```bash
pip install transformers datasets accelerate
```

---

## 四、PEFT 安装

```bash
pip install peft bitsandbytes
```

---

## 五、环境检查

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import LoraConfig, get_peft_model

# 检查 GPU
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"GPU: {torch.cuda.get_device_name(0)}")
print(f"GPU Memory: {torch.cuda.get_device_properties(0).total_memory / 1024**3:.1f} GB")

# 检查 Transformers
model_name = "meta-llama/Llama-3-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
print(f"Tokenizer loaded: {model_name}")

# 检查 PEFT
config = LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj", "v_proj"])
print(f"PEFT config: {config}")
```

## 六、常见问题

```
常见问题及解决：

1. CUDA 版本不匹配
   - 检查：nvidia-smi 和 nvcc --version
   - 解决：安装匹配的 PyTorch 版本

2. GPU 内存不足
   - 检查：torch.cuda.get_device_properties(0).total_memory
   - 解决：使用更小的模型或量化

3. 模型下载失败
   - 检查：网络连接
   - 解决：使用镜像或手动下载

4. 依赖冲突
   - 检查：pip list
   - 解决：使用虚拟环境
```

## 七、Docker 环境

```dockerfile
FROM nvidia/cuda:12.1.0-runtime-ubuntu22.04

RUN apt-get update && apt-get install -y python3 python3-pip

RUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
RUN pip3 install transformers datasets accelerate peft bitsandbytes

WORKDIR /app
COPY . .

CMD ["python3", "train.py"]
```
