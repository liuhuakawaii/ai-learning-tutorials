## 二、完整代码（带详细注释）

```python
"""
第一次 LoRA 微调：用 Qwen2.5-7B 微调法律问答模型。

运行前确保：
1. 有可用的 GPU（至少 12GB 显存，推荐 16GB+）
2. 已安装所有依赖
3. 已准备好训练数据（training_data.json）
"""
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model
from trl import SFTTrainer
from datasets import load_dataset

# ============================================================
# 第一步：加载模型和分词器
# ============================================================
model_name = "Qwen/Qwen2.5-7B"

print(f"加载模型: {model_name}")
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float16,   # 用 float16 节省显存
    device_map="auto",           # 自动分配到 GPU
    trust_remote_code=True,      # Qwen 需要这个参数
)

# 确保有 pad_token
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

print(f"模型加载完成，参数量: {model.num_parameters():,}")

# ============================================================
# 第二步：配置 LoRA
# ============================================================
lora_config = LoraConfig(
    r=16,                                    # 秩：表达能力和参数量的平衡
    lora_alpha=32,                           # 缩放因子：通常 = 2 * r
    target_modules=[                         # 目标模块：注意力层
        "q_proj", "v_proj", "k_proj", "o_proj"
    ],
    lora_dropout=0.05,                       # Dropout：防过拟合
    bias="none",                             # 不训练偏置
    task_type="CAUSAL_LM",                   # 任务类型
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 打印可训练参数量（这是你真正要训练的部分）
model.print_trainable_parameters()
# 输出示例:
# trainable params: 13,107,200 || all params: 7,614,939,136 || trainable%: 0.1721

# ============================================================
# 第三步：加载数据集
# ============================================================
print("加载训练数据...")
dataset = load_dataset("json", data_files="training_data.json")

# 查看数据样例
print(f"训练样本数: {len(dataset['train'])}")
print(f"数据样例: {dataset['train'][0]}")

# ============================================================
# 第四步：配置训练参数
# ============================================================
training_args = TrainingArguments(
    output_dir="./output",                   # 输出目录
    num_train_epochs=3,                      # 训练轮数
    per_device_train_batch_size=4,           # 每 GPU 批次大小
    gradient_accumulation_steps=4,           # 梯度累积步数
                                           #  effective batch_size = 4 * 4 = 16
    learning_rate=2e-4,                      # 学习率（LoRA 推荐 1e-4 ~ 3e-4）
    warmup_ratio=0.1,                        # 预热比例
    weight_decay=0.01,                       # 权重衰减
    fp16=True,                               # 混合精度训练
    logging_steps=10,                        # 每 10 步打印 loss
    save_strategy="epoch",                   # 每轮保存一次
    save_total_limit=2,                      # 最多保留 2 个 checkpoint
    report_to="none",                        # 不上报到 wandb
    dataloader_pin_memory=True,              # 加速数据加载
    remove_unused_columns=False,             # SFTTrainer 需要
)

# ============================================================
# 第五步：创建训练器
# ============================================================
trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=dataset["train"],
    tokenizer=tokenizer,
    max_seq_length=2048,                     # 最大序列长度
)

# ============================================================
# 第六步：开始训练
# ============================================================
print("开始训练...")
print(f"  Epochs: {training_args.num_train_epochs}")
print(f"  Batch size: {training_args.per_device_train_batch_size}")
print(f"  Gradient accumulation: {training_args.gradient_accumulation_steps}")
print(f"  Effective batch size: {training_args.per_device_train_batch_size * training_args.gradient_accumulation_steps}")
print(f"  Learning rate: {training_args.learning_rate}")
print("=" * 50)

train_result = trainer.train()

# 打印训练结果
print(f"\n训练完成!")
print(f"  总步数: {train_result.global_step}")
print(f"  最终 loss: {train_result.training_loss:.4f}")
print(f"  训练时长: {train_result.metrics['train_runtime']:.0f} 秒")

# ============================================================
# 第七步：保存模型
# ============================================================
output_dir = "./output/final"
trainer.save_model(output_dir)
tokenizer.save_pretrained(output_dir)
print(f"模型已保存到: {output_dir}")
```

## 五、常见问题排查

```
问题 1：CUDA Out of Memory

  错误信息：RuntimeError: CUDA out of memory

  排查步骤：
  1. nvidia-smi 查看当前显存占用
  2. 减小 per_device_train_batch_size（4 → 2 → 1）
  3. 增加 gradient_accumulation_steps（保持 effective batch_size）
  4. 减小 max_seq_length（2048 → 1024）
  5. 使用 gradient_checkpointing=True
  6. 使用 QLoRA（下一课）

问题 2：Loss 不下降

  排查步骤：
  1. 检查数据格式是否正确（instruction/output 字段）
  2. 检查数据质量（是否有空值、乱码）
  3. 降低学习率（2e-4 → 1e-4 → 5e-5）
  4. 增加 warmup_ratio（0.1 → 0.2）
  5. 检查 tokenizer 是否正确配置

问题 3：训练中断

  恢复方法：
  trainer.train(resume_from_checkpoint=True)

  或指定 checkpoint：
  trainer.train(resume_from_checkpoint="./output/checkpoint-100")

问题 4：模型输出质量差

  排查步骤：
  1. 检查训练数据质量（最重要）
  2. 增加训练轮数（3 → 5）
  3. 调整 LoRA 参数（r=16 → r=32）
  4. 扩展 target_modules（加 gate_proj, up_proj, down_proj）
```

## 六、训练后验证

```python
"""训练后快速验证模型效果。"""
from transformers import pipeline
from peft import PeftModel

# 加载基座模型
base_model = AutoModelForCausalLM.from_pretrained(
    model_name, torch_dtype=torch.float16, device_map="auto"
)

# 加载 LoRA 权重
model = PeftModel.from_pretrained(base_model, "./output/final")

# 测试
test_questions = [
    "什么是合同？",
    "什么是违约责任？",
    "什么是诉讼时效？",
]

for q in test_questions:
    inputs = tokenizer(q, return_tensors="pt").to(model.device)
    outputs = model.generate(**inputs, max_new_tokens=200)
    answer = tokenizer.decode(outputs[0], skip_special_tokens=True)
    print(f"Q: {q}")
    print(f"A: {answer}")
    print("-" * 50)
```

## 常见误区

1. **不检查显存就直接跑训练**：7B 模型 + LoRA 至少需要 16GB 显存。不检查就启动，跑到一半 OOM 白白浪费时间。先用 `nvidia-smi` 确认可用显存，再决定 batch_size。

2. **训练完不验证直接用**：训练 Loss 低不代表模型效果好。必须用测试问题验证模型输出质量，确认模型学到了目标行为而不是记住了训练数据。

3. **数据格式和模板不匹配**：不同模型的 Chat Template 不同（Qwen、Llama、Mistral 各有差异）。数据格式和模型模板不匹配会导致训练效果极差。

4. **一次性跑太多 epochs**：第一次微调应该先跑 1-2 个 epoch 快速验证流程是否正确，确认无误后再跑完整的 3-5 个 epoch。

---

## 工程建议

1. **先用小数据集验证流程**：取 100 条数据跑 1 个 epoch，确认数据加载、训练、保存、推理全流程正确。调试阶段不要用完整数据集。

2. **训练日志要记录完整**：保存 Loss 曲线、学习率变化、训练时长等关键指标，方便后续分析和复现。用 `report_to="tensorboard"` 自动记录。

3. **checkpoint 要定期保存**：设置 `save_strategy="steps"` 和 `save_steps=100`，避免训练中断后从头开始。用 `save_total_limit=3` 控制磁盘占用。

4. **训练后做 A/B 测试**：用同一组测试问题分别调用基座模型和微调模型，对比输出差异，量化微调带来的改进。
