## 二、Loss 曲线解读

```
Loss 曲线解读：

1. 正常下降
   Loss 持续下降，最终趋于平稳
   → 训练正常

2. 震荡
   Loss 上下波动
   → 学习率太大，降低学习率

3. 不下降
   Loss 保持不变
   → 学习率太小，或数据有问题

4. 上升
   Loss 持续上升
   → 学习率太大，或梯度爆炸
```

## 三、过拟合检测

```python
def detect_overfitting(train_losses: list, eval_losses: list) -> bool:
    """检测过拟合"""
    if len(eval_losses) < 5:
        return False
    
    # 检查 eval loss 是否开始上升
    recent_eval = eval_losses[-5:]
    if all(recent_eval[i] <= recent_eval[i+1] for i in range(len(recent_eval)-1)):
        return True
    
    return False
```

## 六、告警机制

```python
class TrainingMonitor:
    """训练监控器"""
    
    def __init__(self):
        self.train_losses = []
        self.eval_losses = []
    
    def check(self, train_loss: float, eval_loss: float):
        """检查训练状态"""
        self.train_losses.append(train_loss)
        self.eval_losses.append(eval_loss)
        
        # 检查过拟合
        if self._detect_overfitting():
            self._alert("检测到过拟合！")
        
        # 检查 loss 异常
        if train_loss > 10:
            self._alert("Loss 异常高！")
    
    def _alert(self, message: str):
        """发送告警"""
        logger.warning(message)
```
