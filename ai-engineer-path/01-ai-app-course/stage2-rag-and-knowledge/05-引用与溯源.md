# 第5课：引用与溯源——source、page、section、snippet

> **课程定位**：让 AI 回答可追溯、可验证
> **前置知识**：第 4 课的向量检索
> **预计时长**：40 分钟

---

## 场景引入

你的 RAG 问答系统上线了，用户问了一个政策问题，AI 回答得很自信："根据公司规定，员工年假为 15 天。" 用户信以为真，跑去请了 15 天假，结果 HR 说政策早就改了，现在是 10 天。问题出在哪？AI 的回答确实来自检索到的文档，但那是一份过时的版本——而用户无法验证这一点，因为回答没有标注来源。如果每个回答都带引用（文件名、页码、原文片段），用户就能自己去核实，这就是引用溯源的价值。

## 一、为什么需要引用

### 1.1 信任问题

```
没有引用的 AI 回答：

  用户："我们的退款政策是什么？"
  AI："根据公司政策，退款需要在 30 天内申请，需要提供购买凭证。"

  用户的想法：
  - 这个回答对吗？
  - AI 是从哪里知道的？
  - 我能相信吗？

有引用的 AI 回答：

  用户："我们的退款政策是什么？"
  AI："根据公司政策，退款需要在 30 天内申请，需要提供购买凭证。
      [1] 退款政策.pdf, 第 3 页, 第 2.1 节"

  用户的想法：
  - 我可以去查原文验证 ✓
  - 我知道信息来源 ✓
  - 我更信任这个回答 ✓
```

## 二、引用的数据结构

### 2.1 基础引用结构

```typescript
// lib/types/citation.ts
export interface Citation {
  // 唯一标识
  id: string

  // 来源信息
  source: {
    filename: string       // 文件名
    type: 'pdf' | 'markdown' | 'txt' | 'web'
    page?: number          // PDF 页码
    url?: string           // 网页 URL
  }

  // 位置信息
  location: {
    heading?: string       // 所属标题
    section?: string       // 所属章节
    paragraph?: number     // 段落索引
  }

  // 内容片段
  snippet: {
    text: string           // 引用的原文
    startIndex: number     // 在文档中的起始位置
    endIndex: number       // 在文档中的结束位置
  }
}
```

### 2.2 引用与 chunk 的关系

```typescript
// 从 chunk 创建引用
function createCitation(chunk: Chunk): Citation {
  return {
    id: chunk.metadata.id,
    source: {
      filename: chunk.metadata.source,
      type: chunk.metadata.type,
      page: chunk.metadata.page,
    },
    location: {
      heading: chunk.metadata.heading,
      section: chunk.metadata.section,
    },
    snippet: {
      text: chunk.content.slice(0, 200),  // 截取前 200 字符作为片段
      startIndex: chunk.metadata.position.start,
      endIndex: chunk.metadata.position.end,
    },
  }
}
```

## 三、让模型生成引用

### 3.1 System Prompt 设计

```typescript
const SYSTEM_PROMPT = `你是一个知识问答助手。请基于提供的参考资料回答问题。

引用规则：
1. 回答中的每个事实性陈述都必须标注来源
2. 引用格式：[来源编号]
3. 如果资料中没有相关信息，请明确说明"资料中未找到相关信息"
4. 不要编造不存在的引用

参考资料格式：
[1] 文件名, 页码/章节
[2] 文件名, 页码/章节
...`
```

### 3.2 构建带引用的 Prompt

```typescript
function buildPromptWithContext(
  query: string,
  searchResults: { content: string; metadata: any; similarity: number }[]
): { system: string; user: string } {
  // 构建参考资料部分
  const contextParts = searchResults.map((result, index) => {
    const num = index + 1
    const source = result.metadata.source
    const location = result.metadata.heading
      ? `, ${result.metadata.heading}`
      : ''

    return `[${num}] ${source}${location}\n${result.content}`
  })

  const context = contextParts.join('\n\n---\n\n')

  return {
    system: SYSTEM_PROMPT,
    user: `参考资料：
${context}

问题：${query}

请基于以上参考资料回答问题，并标注引用来源。`,
  }
}
```

### 3.3 解析引用

```typescript
// 从模型回答中提取引用
function extractCitations(answer: string): {
  text: string
  citationIds: number[]
}[] {
  const parts: { text: string; citationIds: number[] }[] = []
  const regex = /\[(\d+(?:,\s*\d+)*)\]/g
  let lastIndex = 0
  let match

  while ((match = regex.exec(answer)) !== null) {
    // 引用前的文本
    if (match.index > lastIndex) {
      parts.push({
        text: answer.slice(lastIndex, match.index),
        citationIds: [],
      })
    }

    // 引用编号
    const ids = match[1].split(',').map(s => parseInt(s.trim()))
    parts.push({
      text: '',
      citationIds: ids,
    })

    lastIndex = match.index + match[0].length
  }

  // 最后一段文本
  if (lastIndex < answer.length) {
    parts.push({
      text: answer.slice(lastIndex),
      citationIds: [],
    })
  }

  return parts
}
```

## 四、完整的引用流程

```typescript
// lib/rag-with-citations.ts
import { retrieve } from './retrieval'
import OpenAI from 'openai'

const openai = new OpenAI()

interface RAGResponse {
  answer: string
  citations: {
    id: number
    source: string
    location: string
    snippet: string
  }[]
  parts: {
    text: string
    citationIds: number[]
  }[]
}

export async function askWithCitations(
  query: string,
  topK: number = 5
): Promise<RAGResponse> {
  // 1. 检索相关文档
  const searchResults = await retrieve(query, topK)

  // 2. 构建带引用的 Prompt
  const { system, user } = buildPromptWithContext(query, searchResults)

  // 3. 调用模型
  const response = await openai.responses.create({
    model: 'gpt-5.5',
    input: [
      { role: 'system', content: system },
      { role: 'user', content: user },
    ],
    temperature: 0.3,  // 低温度，确保引用准确
  })

  const answer = response.output_text || ''

  // 4. 提取引用
  const parts = extractCitations(answer)

  // 5. 构建引用列表
  const citations = searchResults.map((result, index) => ({
    id: index + 1,
    source: result.metadata.source,
    location: result.metadata.heading || '',
    snippet: result.content.slice(0, 200),
  }))

  return {
    answer,
    citations,
    parts,
  }
}
```

### 5.2 带引用的回答组件

```typescript
// components/AnswerWithCitations.tsx
'use client'

import { Citation } from './Citation'

interface AnswerPart {
  text: string
  citationIds: number[]
}

interface CitationData {
  id: number
  source: string
  location: string
  snippet: string
}

interface Props {
  parts: AnswerPart[]
  citations: CitationData[]
}

export function AnswerWithCitations({ parts, citations }: Props) {
  const citationMap = new Map(citations.map(c => [c.id, c]))

  return (
    <div className="answer-with-citations">
      <div className="answer-text">
        {parts.map((part, i) => (
          <span key={i}>
            {part.text}
            {part.citationIds.map(id => {
              const citation = citationMap.get(id)
              if (!citation) return null
              return (
                <Citation
                  key={id}
                  id={citation.id}
                  source={citation.source}
                  location={citation.location}
                  snippet={citation.snippet}
                />
              )
            })}
          </span>
        ))}
      </div>

      <div className="citations-list">
        <h4>参考来源</h4>
        {citations.map(citation => (
          <div key={citation.id} className="citation-item">
            <span className="citation-id">[{citation.id}]</span>
            <span className="citation-source">{citation.source}</span>
            {citation.location && (
              <span className="citation-location"> - {citation.location}</span>
            )}
            <p className="citation-snippet">{citation.snippet}...</p>
          </div>
        ))}
      </div>
    </div>
  )
}
```

## 六、验证引用准确性

### 6.1 引用验证

```typescript
function validateCitations(
  answer: string,
  citations: { id: number; content: string }[]
): { valid: boolean; issues: string[] } {
  const issues: string[] = []

  // 提取回答中引用的编号
  const citationRegex = /\[(\d+)\]/g
  const usedIds = new Set<number>()
  let match

  while ((match = citationRegex.exec(answer)) !== null) {
    usedIds.add(parseInt(match[1]))
  }

  // 检查引用的编号是否存在
  const availableIds = new Set(citations.map(c => c.id))
  for (const id of usedIds) {
    if (!availableIds.has(id)) {
      issues.push(`引用了不存在的来源 [${id}]`)
    }
  }

  // 检查是否有引用
  if (usedIds.size === 0) {
    issues.push('回答中没有任何引用')
  }

  return {
    valid: issues.length === 0,
    issues,
  }
}
```

## 常见误区

1. **只在 prompt 里要求引用，不做后端验证**：模型可能会编造不存在的引用编号，或者把来源标错。必须在后端验证引用编号是否对应到实际的检索结果，不通过验证的引用应该被过滤或标记。

2. **引用粒度太粗**：只标注"来自 XX 文档"，不标注页码、章节或原文片段。用户无法快速定位到原始内容，引用的实用价值大打折扣。

3. **把引用和回答分开处理**：先生成回答，再事后补引用。这种方式引用和回答容易脱节。应该在生成回答的同时就注入引用上下文，让模型在生成时就能标注来源。

4. **忽略引用的前端体验**：引用信息在后端已经准备好了，但前端只是简单列出来，没有高亮、没有跳转、没有 snippet 预览。用户体验差会导致引用功能形同虚设。

---

## 工程建议

1. **在 System Prompt 中严格约束引用格式**：明确告诉模型"每个事实性陈述必须标注 [编号]"、"不要编造不存在的编号"、"不确定就说'资料中未找到'"。低温度（0.1-0.3）能提高引用的准确性。

2. **后端必须做引用验证**：解析模型回答中的引用编号，检查是否在检索结果中存在。如果引用了不存在的编号，说明模型在幻觉，需要触发告警或重新生成。

3. **引用信息要包含原文 snippet**：除了文件名和页码，还应该截取 chunk 的前 200 字符作为 snippet 展示给用户。这样用户不需要打开原始文档就能快速判断引用是否准确。

4. **支持引用跳转和高亮**：在前端实现点击引用编号跳转到来源列表、hover 显示 snippet、如果有 PDF 则跳转到对应页码。这些互动能大幅提升引用的实用价值和用户信任度。
