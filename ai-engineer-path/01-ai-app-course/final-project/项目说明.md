# AI Knowledge Workspace 项目说明

## 项目目标

构建一个真实可用的 AI 知识工作台。它不是简单聊天框，而是一个能上传资料、检索知识、生成答案、调用工具、记录过程并可评估质量的 AI 产品。

## 内置 project kit

课程提供一个离线可验证版本：

```text
ai-app-course/final-project/ai-knowledge-workspace-kit
```

运行：

```bash
cd ai-app-course/final-project/ai-knowledge-workspace-kit
npm run check
npm run ingest
npm run ask -- "为什么回答必须带引用"
npm run eval
```

它不会直接调用真实模型，而是先稳定训练 RAG 产品的关键工程能力：文档切分、检索、引用、拒答和评估。后续可以把 `ask` 命令替换成真实 Responses API 调用。

## 用户场景

- 学习者上传课程资料，向资料提问并要求引用出处
- 产品经理上传竞品资料，生成对比表和需求清单
- 开发者上传项目文档，快速查询接口、约定和历史决策
- 自由职业者整理客户资料，生成会议摘要和行动项

## 核心功能

1. 用户与工作区
   - 登录 / 登出
   - 个人工作区
   - 配额与使用统计

2. 知识库
   - 上传 PDF、Markdown、TXT
   - 添加网页链接
   - 文本切分、向量化、索引
   - 重新索引和删除

3. AI 问答
   - 普通对话
   - 基于知识库的问答
   - 答案引用来源
   - 流式输出
   - 回答失败时给出可操作提示

4. 工具调用
   - 保存笔记
   - 生成待办
   - 查询历史会话
   - 导出 Markdown 报告

5. 质量与安全
   - 提示注入检测
   - 知识库权限隔离
   - 敏感信息过滤
   - 失败样本记录
   - 评估集回归测试

## 里程碑

1. MVP：普通聊天 + 流式输出
2. RAG：上传文档 + 带引用问答
3. 工具：保存笔记 + 生成任务
4. 产品化：登录、配额、历史记录
5. 质量：评估集、日志、成本统计
6. 上线：部署、环境变量、监控

## 阶段交付物

| 阶段 | 交付物 | 对应 project kit |
|------|--------|------------------|
| 第一阶段 | API 调用基线、结构化输出、错误处理和流式体验记录 | `reports/stage1-api-baseline.md` |
| 第二阶段 | 文档切分、检索命中、引用质量和拒答样本 | `reports/stage2-rag-quality.md` |
| 第三阶段 | 工具 schema、成功/失败输出、人工确认边界 | `reports/stage3-tool-calls.md` |
| 第四阶段 | 工作区、配额、日志、成本和安全边界设计 | `reports/stage4-productization.md` |
| 第五阶段 | eval 结果、失败样本、发布/回滚决策 | `reports/stage5-eval-release.md` |

## 验收标准

- 上传 3 份文档后，能正确回答文档内问题并给出引用
- 对文档外问题能说明“资料中没有足够信息”，而不是编造
- 工具调用有明确输入、输出和错误处理
- 10 条评估样本能重复运行，并输出通过率
- 线上版本能记录请求耗时、token 成本和失败原因
- 离线 project kit 的 `npm run check`、`npm run ingest`、`npm run eval` 均通过
