## 一、模型的局限

### 1.1 模型只能生成文本

```
大模型的本质：一个文本生成器

  输入：一段文字
  输出：一段文字

它不能：
  - 访问互联网（不能搜索）
  - 读写文件（不能操作本地数据）
  - 调用 API（不能访问外部服务）
  - 执行代码（不能计算）
  - 获取实时信息（不知道今天的天气）
```

### 1.2 工具弥补局限

```
┌─────────────────────────────────────────────────────────────────┐
│                    模型 + 工具 = 更强的能力                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  模型擅长的                      模型不擅长的                    │
│  ├── 理解自然语言                ├── 获取实时数据                │
│  ├── 生成文本                    ├── 精确计算                    │
│  ├── 推理和分析                  ├── 操作外部系统                │
│  └── 做决策                      └── 访问私有数据                │
│                                                                 │
│  工具弥补的：                                                  │
│  ├── 搜索工具 → 获取实时信息                                    │
│  ├── 计算工具 → 精确计算                                        │
│  ├── 数据库工具 → 查询私有数据                                  │
│  ├── 文件工具 → 读写本地文件                                    │
│  └── API 工具 → 调用外部服务                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 二、工具调用的工作原理

### 2.1 三步流程

```
用户："今天北京的天气怎么样？"

步骤 1：模型判断需要调用工具
  模型思考：我需要获取实时天气信息，需要调用天气工具
  模型输出：{
    "tool": "get_weather",
    "arguments": { "city": "北京" }
  }

步骤 2：系统执行工具
  调用天气 API → 返回 { "temp": 25, "condition": "晴" }

步骤 3：模型基于工具结果生成回答
  模型输入：工具返回了 { "temp": 25, "condition": "晴" }
  模型输出："今天北京天气晴朗，气温 25°C。"
```

## 三、OpenAI 的 Function Calling

### 3.1 定义工具

```typescript
import OpenAI from 'openai'

const openai = new OpenAI()

// 定义工具（函数）
const tools = [
  {
    type: 'function' as const,
    function: {
      name: 'get_weather',
      description: '获取指定城市的天气信息',
      parameters: {
        type: 'object',
        properties: {
          city: {
            type: 'string',
            description: '城市名称，如"北京"、"上海"',
          },
        },
        required: ['city'],
      },
    },
  },
]
```

### 3.2 调用模型

```typescript
const response = await openai.responses.create({
  model: 'gpt-5.5',
  input: [
    { role: 'user', content: '今天北京天气怎么样？' }
  ],
  tools,
  tool_choice: 'auto',  // 让模型自动决定是否调用工具
})

const toolCalls = response.output.filter((item) => item.type === 'function_call')

// 检查模型是否要求调用工具
if (toolCalls.length > 0) {
  console.log('模型要求调用工具:')
  for (const toolCall of toolCalls) {
    console.log(`  工具: ${toolCall.name}`)
    console.log(`  参数: ${toolCall.arguments}`)
  }
}
```

### 3.3 执行工具并返回结果

```typescript
// 假设这是你的天气 API
async function getWeather(city: string) {
  // 实际项目中调用真实的天气 API
  return {
    city,
    temperature: 25,
    condition: '晴',
    humidity: 40,
  }
}

// 处理工具调用
async function handleToolCalls(toolCalls: ResponseFunctionToolCall[]) {
  const results = []

  for (const toolCall of toolCalls) {
    const args = JSON.parse(toolCall.arguments)

    let result
    if (toolCall.name === 'get_weather') {
      result = await getWeather(args.city)
    }

    results.push({
      type: 'function_call_output' as const,
      call_id: toolCall.call_id,
      output: JSON.stringify(result),
    })
  }

  return results
}

// 完整的对话流程
async function chatWithTools(userMessage: string) {
  const input: ResponseInputMessage[] = [
    { role: 'user', content: userMessage }
  ]

  // 第一步：发送给模型
  const response = await openai.responses.create({
    model: 'gpt-5.5',
    input,
    tools,
    tool_choice: 'auto',
  })

  const toolCalls = response.output.filter((item) => item.type === 'function_call')

  // 如果模型要求调用工具
  if (toolCalls.length > 0) {
    // 执行工具
    const toolResults = await handleToolCalls(toolCalls)

    // 第二步：把工具结果发回模型
    const finalResponse = await openai.responses.create({
      model: 'gpt-5.5',
      input: [...input, ...response.output, ...toolResults],
    })

    return finalResponse.output_text
  }

  // 如果不需要工具，直接返回
  return response.output_text
}
```

## 四、什么时候需要工具

### 4.1 需要工具的场景

```
┌─────────────────────────────────────────────────────────────────┐
│                    需要工具的场景                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  获取实时数据                                                    │
│  ├── 天气查询                                                    │
│  ├── 股票价格                                                    │
│  ├── 新闻资讯                                                    │
│  └── API 数据                                                    │
│                                                                 │
│  精确计算                                                        │
│  ├── 数学计算                                                    │
│  ├── 单位转换                                                    │
│  ├── 日期计算                                                    │
│  └── 统计分析                                                    │
│                                                                 │
│  操作外部系统                                                    │
│  ├── 发送邮件                                                    │
│  ├── 创建日历事件                                                │
│  ├── 更新数据库                                                  │
│  └── 调用第三方 API                                              │
│                                                                 │
│  访问私有数据                                                    │
│  ├── 查询用户信息                                                │
│  ├── 搜索内部文档                                                │

│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 不需要工具的场景

```
不需要工具的场景：

  - 纯文本生成（写文章、翻译）
  - 知识问答（模型已有的知识）
  - 推理分析（基于给定信息）
  - 格式转换（文本 → JSON）
  - 创意写作（故事、诗歌）
```

## 五、工具设计原则

```
┌─────────────────────────────────────────────────────────────────┐
│                    工具设计原则                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 单一职责                                                     │
│     每个工具只做一件事                                           │
│     ❌ search_and_summarize                                     │
│     ✅ search_documents + summarize_text                        │
│                                                                 │
│  2. 清晰的描述                                                   │
│     工具名和描述要让模型理解何时使用                              │
│     ❌ "func1"                                                  │
│     ✅ "get_weather: 获取指定城市的当前天气信息"                  │
│                                                                 │
│  3. 明确的参数                                                   │
│     参数类型、必填/可选、取值范围                                 │
│     ✅ city: string (required) - 城市名称                        │
│                                                                 │
│  4. 可预测的输出                                                 │
│     返回格式一致，便于模型理解                                    │
│     ✅ JSON 格式，包含温度、天气状况等                            │
│                                                                 │
│  5. 错误处理                                                     │
│     工具失败时返回有意义的错误信息                                │
│     ✅ { "error": "城市不存在" }                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 小结

本课的核心要点：

1. **模型只能生成文本**：不能访问外部数据或执行操作
2. **工具弥补局限**：让模型能获取实时数据、精确计算、操作系统
3. **三步流程**：模型判断 → 执行工具 → 基于结果回答
4. **Function Calling**：OpenAI 的标准工具调用方式
5. **设计原则**：单一职责、清晰描述、明确参数、可预测输出
