# 第7课：阶段实战——AI 写作助手

> **课程定位**：综合运用阶段一所学，构建完整功能
> **前置知识**：第 1-6 课的全部内容
> **预计时长**：90 分钟

---

## 场景引入

你的朋友是个自媒体作者，每天要写 3-4 篇公众号文章。他抱怨说："我花 2 小时写一篇文章，其中 1 小时在想大纲和结构，半小时在凑字数，真正有价值的观点输出只有半小时。"他说如果有个工具能帮他快速生成大纲、按章节扩写正文、最后导出 Markdown 直接发布，他每天能多写两篇。这不是个简单的"让 AI 帮我写文章"的需求——它需要结构化大纲、分章节流式生成、用户可以编辑和调整，是一个完整的产品功能。

---

## 学习目标

完成本课后，你将构建一个 AI 写作助手，支持：

1. 输入主题、受众、语气和字数
2. 返回结构化大纲（JSON）
3. 流式生成正文
4. 保存历史记录
5. 失败时展示可理解的错误信息

### 2.1 输入参数 Schema

```typescript
// lib/schemas.ts
import { z } from 'zod'

// 用户输入
export const WriterInputSchema = z.object({
  topic: z.string().min(1, '主题不能为空').max(200),
  audience: z.enum(['general', 'technical', 'business', 'academic']),
  tone: z.enum(['formal', 'casual', 'humorous', 'serious']),
  wordCount: z.number().int().min(100).max(5000),
})

export type WriterInput = z.infer<typeof WriterInputSchema>

// 大纲输出
export const OutlineSchema = z.object({
  title: z.string(),
  introduction: z.string(),
  sections: z.array(z.object({
    heading: z.string(),
    keyPoints: z.array(z.string()).min(1).max(5),
    estimatedWords: z.number(),
  })).min(2).max(8),
  conclusion: z.string(),
  totalEstimatedWords: z.number(),
})

export type Outline = z.infer<typeof OutlineSchema>
```

## 三、生成大纲（结构化输出）

### 3.1 API Route

```typescript
// app/api/outline/route.ts
import { NextRequest } from 'next/server'
import { zodTextFormat } from 'openai/helpers/zod'
import openai from '@/lib/openai'
import { WriterInputSchema, OutlineSchema } from '@/lib/schemas'
import { AUDIENCE_LABELS, TONE_LABELS } from '@/lib/constants'

export async function POST(req: NextRequest) {
  try {
    const body = await req.json()
    const input = WriterInputSchema.parse(body)

    const response = await openai.responses.parse({
      model: 'gpt-5.5',
      input: [
        {
          role: 'system',
          content: `你是一个专业的写作助手。用户会给你写作要求，你需要生成一个详细的文章大纲。

要求：
- 标题要吸引人
- 每个章节有 2-4 个要点
- 要点要具体，不要泛泛而谈
- 估算每个章节的字数，总字数接近用户要求`
        },
        {
          role: 'user',
          content: `请为以下主题生成文章大纲：

主题：${input.topic}
目标读者：${AUDIENCE_LABELS[input.audience]}
写作风格：${TONE_LABELS[input.tone]}
目标字数：${input.wordCount} 字`
        }
      ],
      text: { format: zodTextFormat(OutlineSchema, 'outline') },
    })

    const outline = response.output_parsed
    if (!outline) {
      return Response.json({ error: '生成大纲失败' }, { status: 500 })
    }

    return Response.json({ outline })

  } catch (error) {
    console.error('生成大纲失败:', error)
    return Response.json({ error: '生成大纲失败，请重试' }, { status: 500 })
  }
}
```

## 四、生成正文（流式输出）

### 4.1 API Route

```typescript
// app/api/content/route.ts
import { NextRequest } from 'next/server'
import openai from '@/lib/openai'
import { OutlineSchema } from '@/lib/schemas'

export async function POST(req: NextRequest) {
  try {
    const { outline, sectionIndex } = await req.json()
    const validatedOutline = OutlineSchema.parse(outline)

    const section = validatedOutline.sections[sectionIndex]
    if (!section) {
      return Response.json({ error: '无效的章节索引' }, { status: 400 })
    }

    const stream = await openai.responses.create({
      model: 'gpt-5.5',
      input: [
        {
          role: 'system',
          content: `你是一个专业的写作助手。根据提供的大纲章节，生成流畅、有深度的正文内容。

要求：
- 内容要充实，不要空洞
- 语言要自然流畅
- 围绕要点展开，不要偏离主题
- 目标字数：${section.estimatedWords} 字`
        },
        {
          role: 'user',
          content: `文章标题：${validatedOutline.title}
章节标题：${section.heading}
章节要点：
${section.keyPoints.map((p, i) => `${i + 1}. ${p}`).join('\n')}

请生成这个章节的正文内容。`
        }
      ],
      stream: true,
      temperature: 0.7,
      max_output_tokens: Math.ceil(section.estimatedWords * 2),  // token 约为字数的 1.5-2 倍
    })

    const encoder = new TextEncoder()
    const readable = new ReadableStream({
      async start(controller) {
        try {
          for await (const chunk of stream) {
            if (chunk.type === 'response.output_text.delta') {
              controller.enqueue(
                encoder.encode(`data: ${JSON.stringify({ content: chunk.delta })}\n\n`)
              )
            }
          }
          controller.enqueue(encoder.encode('data: [DONE]\n\n'))
        } catch (error) {
          controller.enqueue(
            encoder.encode(`data: ${JSON.stringify({ error: String(error) })}\n\n`)
          )
        } finally {
          controller.close()
        }
      },
    })

    return new Response(readable, {
      headers: {
        'Content-Type': 'text/event-stream',
        'Cache-Control': 'no-cache',
        'Connection': 'keep-alive',
      },
    })

  } catch (error) {
    console.error('生成正文失败:', error)
    return Response.json({ error: '生成正文失败' }, { status: 500 })
  }
}
```

### 5.3 流式正文展示

```typescript
// components/ContentStream.tsx
'use client'

import { useState, useRef, useCallback } from 'react'

interface Props {
  outline: any
  sectionIndex: number
  onComplete: (content: string) => void
}

export function ContentStream({ outline, sectionIndex, onComplete }: Props) {
  const [content, setContent] = useState('')
  const [isStreaming, setIsStreaming] = useState(false)
  const abortRef = useRef<AbortController | null>(null)

  const startStream = useCallback(async () => {
    setIsStreaming(true)
    setContent('')

    const controller = new AbortController()
    abortRef.current = controller

    try {
      const response = await fetch('/api/content', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ outline, sectionIndex }),
        signal: controller.signal,
      })

      if (!response.ok) throw new Error('请求失败')

      const reader = response.body?.getReader()
      if (!reader) throw new Error('无法读取流')

      const decoder = new TextDecoder()
      let fullContent = ''

      while (true) {
        const { done, value } = await reader.read()
        if (done) break

        const text = decoder.decode(value)
        const lines = text.split('\n')

        for (const line of lines) {
          if (line.startsWith('data: ')) {
            const data = line.slice(6)
            if (data === '[DONE]') {
              onComplete(fullContent)
              return
            }

            try {
              const parsed = JSON.parse(data)
              if (parsed.content) {
                fullContent += parsed.content
                setContent(fullContent)
              }
            } catch {
              // 忽略解析错误
            }
          }
        }
      }
    } catch (error) {
      if (error instanceof Error && error.name !== 'AbortError') {
        console.error('流式生成失败:', error)
      }
    } finally {
      setIsStreaming(false)
      abortRef.current = null
    }
  }, [outline, sectionIndex, onComplete])

  const handleStop = () => {
    abortRef.current?.abort()
  }

  return (
    <div className="content-stream">
      <div className="stream-header">
        <h3>第 {sectionIndex + 1} 章正文</h3>
        {!content && !isStreaming && (
          <button onClick={startStream}>开始生成</button>
        )}
        {isStreaming && (
          <button onClick={handleStop}>停止</button>
        )}
      </div>

      <div className="stream-content">
        {content || (isStreaming ? '正在生成...' : '点击按钮开始生成')}
      </div>

      {content && !isStreaming && (
        <div className="stream-footer">
          <span>字数：{content.length}</span>
          <button onClick={() => onComplete(content)}>确认使用</button>
        </div>
      )}
    </div>
  )
}
```

## 六、主页面

```typescript
// app/page.tsx
'use client'

import { useState } from 'react'
import { WriterForm } from '@/components/WriterForm'
import { OutlinePreview } from '@/components/OutlinePreview'
import { ContentStream } from '@/components/ContentStream'
import type { WriterInput, Outline } from '@/lib/schemas'

export default function WriterPage() {
  const [outline, setOutline] = useState<Outline | null>(null)
  const [isGeneratingOutline, setIsGeneratingOutline] = useState(false)
  const [generatingSection, setGeneratingSection] = useState<number | null>(null)
  const [sections, setSections] = useState<Record<number, string>>({})
  const [error, setError] = useState<string | null>(null)

  // 生成大纲
  const handleGenerateOutline = async (input: WriterInput) => {
    setIsGeneratingOutline(true)
    setError(null)
    setOutline(null)
    setSections({})

    try {
      const response = await fetch('/api/outline', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(input),
      })

      if (!response.ok) {
        const data = await response.json()
        throw new Error(data.error || '生成大纲失败')
      }

      const data = await response.json()
      setOutline(data.outline)
    } catch (err) {
      setError(err instanceof Error ? err.message : '未知错误')
    } finally {
      setIsGeneratingOutline(false)
    }
  }

  // 章节生成完成
  const handleSectionComplete = (index: number, content: string) => {
    setSections(prev => ({ ...prev, [index]: content }))
    setGeneratingSection(null)
  }

  // 导出为 Markdown
  const handleExport = () => {
    if (!outline) return

    let markdown = `# ${outline.title}\n\n`
    markdown += `${outline.introduction}\n\n`

    outline.sections.forEach((section, i) => {
      markdown += `## ${section.heading}\n\n`
      if (sections[i]) {
        markdown += `${sections[i]}\n\n`
      }
    })

    markdown += `## 结语\n\n${outline.conclusion}\n`

    const blob = new Blob([markdown], { type: 'text/markdown' })
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `${outline.title}.md`
    a.click()
    URL.revokeObjectURL(url)
  }

  return (
    <div className="writer-page">
      <h1>AI 写作助手</h1>

      <WriterForm
        onSubmit={handleGenerateOutline}
        isLoading={isGeneratingOutline}
      />

      {error && (
        <div className="error-message">
          {error}
        </div>
      )}

      {outline && (
        <>
          <OutlinePreview
            outline={outline}
            onGenerateContent={setGeneratingSection}
            generatingSection={generatingSection}
          />

          {generatingSection !== null && (
            <ContentStream
              outline={outline}
              sectionIndex={generatingSection}
              onComplete={(content) => handleSectionComplete(generatingSection, content)}
            />
          )}

          {Object.keys(sections).length === outline.sections.length && (
            <button onClick={handleExport} className="export-btn">
              导出 Markdown
            </button>
          )}
        </>
      )}
    </div>
  )
}
```

## 常见误区

1. **"让 AI 一口气写完整篇文章"**：直接让模型生成 3000 字的完整文章，结果要么被 max_output_tokens 截断，要么前后风格不一致，要么偏离主题。正确的做法是先生成结构化大纲，再按章节逐段生成，每段可以独立控制质量和方向。

2. **"用户不需要编辑大纲，AI 生成的就是对的"**：AI 生成的大纲经常不符合用户的实际需求——章节划分不合理、重点偏移、遗漏关键内容。用户必须能编辑大纲、调整章节顺序、修改要点，然后再基于修改后的大纲生成正文。

3. **"写完功能就行了，不需要考虑生成失败"**：网络中断、API 限流、模型返回空内容——这些在流式长文本生成中发生的概率远高于普通请求。如果不在每个章节的生成过程中处理错误和重试，用户生成到一半遇到错误，前面的工作全白费。

4. **"导出功能是锦上添花，可以后做"**：用户用你的工具写了文章，最终目的是发布。如果不能方便地导出为 Markdown 或其他格式，用户还得手动复制粘贴、调整格式，体验大打折扣。导出功能应该在第一版就包含。

---

## 工程建议

1. **大纲用结构化输出，正文用流式输出**：大纲需要程序化处理（按章节索引、计算字数），所以用 Structured Outputs + Zod 保证格式可靠。正文需要良好的阅读体验，所以用流式逐字显示。两种输出方式服务于不同的需求，不要混用。

2. **每个章节独立生成、独立保存**：不要把所有章节拼成一个大请求。每个章节单独调用 API，生成完成后立即保存到状态中。这样某个章节失败只需重试那一个，不会影响其他章节。用户也可以选择性地重新生成某个章节。

3. **在 Prompt 中注入上下文保持一致性**：生成第 3 章时，把文章标题、前面章节的摘要一起传给模型，保持风格和内容的连贯性。不要让每个章节独立生成——它们会像不同人写的一样。

4. **控制好 token 预算分配**：如果用户要求 1000 字的文章，大纲消耗 200 tokens，那每个章节的 max_output_tokens 应该按比例分配。不要给每个章节都设很大的上限——最后一个章节可能没有预算了。
