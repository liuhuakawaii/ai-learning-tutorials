## 学习建议

1. **必修先行**：先完成 01 → 02 → 03 的递进学习，建立完整的 AI 工程基础
2. **选修按需**：根据职业方向选择选修课
   - 想做 AI 产品 → 04（多 Agent）+ 05（MCP）
   - 想做 AI infra → 06（微调）
   - 想扩展场景 → 07（多模态）
3. **毕业项目收尾**：用毕业项目串联所有所学，产出一个完整的 portfolio 项目
4. **评估贯穿全程**：03 课程的评估方法应贯穿后续所有课程的项目开发
