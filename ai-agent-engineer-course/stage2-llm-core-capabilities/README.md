## 实战任务

构建 **智能客服对话系统**：

- 多轮对话，上下文自动管理
- 流式逐字输出，体验流畅
- 可配置的 System Prompt 和角色设定
- 结构化输出：自动提取用户意图、生成工单
- 支持切换不同大模型（OpenAI / Claude / 国产）
- Token 用量统计和成本控制

## 验收标准

- [ ] 多轮对话上下文正确，不会丢失历史信息
- [ ] 流式响应延迟 < 200ms（首 token），逐字渲染无闪烁
- [ ] 超长对话自动压缩历史，不超出上下文窗口
- [ ] 结构化输出 100% 符合 JSON Schema 定义
- [ ] 切换模型不需要改业务代码，只需改配置
- [ ] Token 用量实时统计，超限自动降级或提醒

## 技术栈

| 组件 | 技术 |
|------|------|
| AI API | OpenAI Python SDK / Anthropic SDK |
| 流式协议 | Server-Sent Events (SSE) |
| 结构化输出 | Pydantic + JSON Schema |
| 前端流式渲染 | EventSource API / fetch streaming |
| Prompt 管理 | 模板引擎 + 版本控制 |
