# 03 文本切分策略

> 切分粒度太大，检索不精确；切分太小，丢失上下文。这个平衡是 RAG 的核心调优点。

## 学习目标

- 理解不同切分策略的适用场景
- 实现固定切分、语义切分、递归切分
- 掌握 chunk 大小和重叠的调优方法
- 设计元数据以提升检索质量

## 前置要求

- 已完成文档解析 Pipeline
- 理解 Embedding 的基本概念

## 切分的核心矛盾

- **chunk 太大**：检索结果包含太多无关信息，干扰 LLM
- **chunk 太小**：丢失上下文，LLM 无法理解
- **chunk 边界不对**：一个完整的概念被切成两半

## 固定大小切分

最简单，但最粗暴：

```python
class FixedSizeSplitter:
    """固定大小切分"""
    
    def __init__(self, chunk_size: int = 500, chunk_overlap: int = 50):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
    
    def split(self, text: str) -> list[str]:
        chunks = []
        start = 0
        
        while start < len(text):
            end = start + self.chunk_size
            chunk = text[start:end]
            chunks.append(chunk)
            start = end - self.chunk_overlap
        
        return chunks
```

问题：可能在句子中间切断，破坏语义完整性。

## 递归切分

按分隔符层级递归切分，尽量保持语义完整：

```python
class RecursiveSplitter:
    """递归切分——按分隔符层级切分"""
    
    def __init__(
        self,
        chunk_size: int = 500,
        chunk_overlap: int = 50,
        separators: list[str] | None = None,
    ):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.separators = separators or ["\n\n", "\n", "。", "！", "？", ".", "!", "?", "；", ";", " "]
    
    def split(self, text: str) -> list[str]:
        return self._recursive_split(text, self.separators)
    
    def _recursive_split(self, text: str, separators: list[str]) -> list[str]:
        if len(text) <= self.chunk_size:
            return [text] if text.strip() else []
        
        # 找到第一个能用的分隔符
        separator = separators[0] if separators else ""
        remaining_separators = separators[1:] if len(separators) > 1 else []
        
        if not separator:
            # 没有分隔符了，硬切
            return self._hard_split(text)
        
        # 按分隔符切分
        splits = text.split(separator)
        
        # 合并小块
        chunks = []
        current = ""
        for split in splits:
            if len(current) + len(split) + len(separator) <= self.chunk_size:
                current += (separator if current else "") + split
            else:
                if current:
                    chunks.append(current)
                # 如果单个 split 就超了，递归切分
                if len(split) > self.chunk_size:
                    chunks.extend(self._recursive_split(split, remaining_separators))
                else:
                    current = split
        if current:
            chunks.append(current)
        
        # 添加重叠
        return self._add_overlap(chunks)
    
    def _add_overlap(self, chunks: list[str]) -> list[str]:
        """添加重叠"""
        if self.chunk_overlap <= 0 or len(chunks) <= 1:
            return chunks
        
        result = [chunks[0]]
        for i in range(1, len(chunks)):
            # 从上一个 chunk 取末尾作为当前 chunk 的开头
            prev_tail = chunks[i - 1][-self.chunk_overlap:]
            result.append(prev_tail + chunks[i])
        
        return result
```

## 语义切分

基于 Embedding 相似度判断切分点——语义变化大的地方就是最佳切分点：

```python
class SemanticSplitter:
    """语义切分——在语义变化处切分"""
    
    def __init__(
        self,
        embedding_service,
        threshold: float = 0.5,
        min_chunk_size: int = 100,
        max_chunk_size: int = 1000,
    ):
        self.embedding = embedding_service
        self.threshold = threshold
        self.min_chunk_size = min_chunk_size
        self.max_chunk_size = max_chunk_size
    
    async def split(self, text: str) -> list[str]:
        # 先按句子切分
        sentences = self._split_sentences(text)
        if len(sentences) <= 1:
            return [text]
        
        # 计算每个句子的 Embedding
        embeddings = await self.embedding.batch_embed(sentences)
        
        # 计算相邻句子的相似度
        similarities = []
        for i in range(len(embeddings) - 1):
            sim = self._cosine_similarity(embeddings[i], embeddings[i + 1])
            similarities.append(sim)
        
        # 在相似度低于阈值处切分
        chunks = []
        current_chunk = [sentences[0]]
        
        for i, sim in enumerate(similarities):
            current_text = " ".join(current_chunk + [sentences[i + 1]])
            
            if sim < self.threshold and len(current_text) >= self.min_chunk_size:
                # 语义变化大，切分
                chunks.append(" ".join(current_chunk))
                current_chunk = [sentences[i + 1]]
            elif len(current_text) > self.max_chunk_size:
                # 超过最大长度，强制切分
                chunks.append(" ".join(current_chunk))
                current_chunk = [sentences[i + 1]]
            else:
                current_chunk.append(sentences[i + 1])
        
        if current_chunk:
            chunks.append(" ".join(current_chunk))
        
        return chunks
    
    def _split_sentences(self, text: str) -> list[str]:
        """按句子切分"""
        import re
        sentences = re.split(r'(?<=[。！？.!?])\s*', text)
        return [s.strip() for s in sentences if s.strip()]
    
    def _cosine_similarity(self, a: list[float], b: list[float]) -> float:
        import numpy as np
        a, b = np.array(a), np.array(b)
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

## 元数据设计

好的元数据能显著提升检索质量：

```python
@dataclass
class ChunkMetadata:
    """Chunk 元数据"""
    source: str           # 来源（文件名/URL）
    source_type: str      # 来源类型（pdf/word/web）
    page: int | None      # 页码
    section: str | None   # 章节标题
    chunk_index: int      # 在文档中的序号
    total_chunks: int     # 文档总 chunk 数
    created_at: str       # 创建时间
    
    # 用于过滤
    document_id: str      # 文档 ID
    knowledge_base_id: str # 知识库 ID
    
    # 用于排序
    relevance_score: float | None = None

def enrich_chunks(chunks: list[str], document: ParsedDocument) -> list[DocumentChunk]:
    """为 chunks 添加元数据"""
    enriched = []
    for i, chunk in enumerate(chunks):
        metadata = ChunkMetadata(
            source=document.metadata["source"],
            source_type=document.metadata["format"],
            page=_find_page(chunk, document),
            section=_find_section(chunk, document),
            chunk_index=i,
            total_chunks=len(chunks),
            created_at=datetime.utcnow().isoformat(),
            document_id=document.metadata.get("document_id", ""),
            knowledge_base_id=document.metadata.get("kb_id", ""),
        )
        enriched.append(DocumentChunk(
            content=chunk,
            metadata=metadata.__dict__,
            chunk_index=i,
        ))
    return enriched
```

## 切分策略选型

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 固定大小 | 简单、快 | 可能切断语义 | 快速原型 |
| 递归切分 | 保持语义完整 | 需要调参 | 通用场景 |
| 语义切分 | 最智能 | 慢、需要 Embedding | 高质量需求 |

## 本节要点

- 切分是 RAG 质量的关键调优点，没有"最佳"只有"最适合"
- 递归切分是性价比最高的选择，语义切分是质量最高的选择
- chunk 大小通常 300-1000 字符，overlap 10-20%
- 元数据能显著提升检索精度，不要忽略

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| chunk 切断了表格 | 表格没有特殊处理 | 先提取表格，整体作为一个 chunk |
| 检索结果不相关 | chunk 太大，噪声太多 | 减小 chunk size |
| 回答缺乏上下文 | chunk 太小 | 增大 chunk size 或 overlap |
| 语义切分太慢 | 每个句子都调 Embedding | 批量 Embedding + 缓存 |
