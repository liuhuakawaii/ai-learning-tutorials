# 03 审计日志

> 出了问题能查、能追溯、能定责——审计日志是企业合规的基础。

## 学习目标

- 设计审计日志的数据模型
- 实现操作记录和合规追溯
- 支持日志查询和导出

## 审计日志模型

```python
class AuditLog(Base):
    __tablename__ = "audit_logs"
    
    id: Mapped[str] = mapped_column(String(36), primary_key=True)
    user_id: Mapped[str] = mapped_column(String(36), index=True)
    action: Mapped[str] = mapped_column(String(50), index=True)  # create/update/delete/execute
    resource_type: Mapped[str] = mapped_column(String(50), index=True)  # agent/skill/workflow/chat
    resource_id: Mapped[str] = mapped_column(String(36), index=True)
    
    # 变更详情
    before: Mapped[dict | None] = mapped_column(JSON, nullable=True)
    after: Mapped[dict | None] = mapped_column(JSON, nullable=True)
    
    # 请求信息
    ip_address: Mapped[str] = mapped_column(String(50))
    user_agent: Mapped[str] = mapped_column(String(500))
    
    # 时间
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())
```

## 审计中间件

```python
class AuditMiddleware:
    """审计日志中间件"""
    
    async def __call__(self, request: Request, call_next):
        response = await call_next(request)
        
        # 记录关键操作
        if request.method in ("POST", "PUT", "DELETE"):
            await self._log_action(request, response)
        
        return response
    
    async def _log_action(self, request: Request, response: Response):
        user = getattr(request.state, "user", None)
        
        log = AuditLog(
            id=str(uuid.uuid4()),
            user_id=user.id if user else "anonymous",
            action=self._method_to_action(request.method),
            resource_type=self._extract_resource_type(request.url.path),
            resource_id=self._extract_resource_id(request.url.path),
            ip_address=request.client.host,
            user_agent=request.headers.get("user-agent", ""),
        )
        
        db.add(log)
```

## 日志查询 API

```python
@router.get("/audit-logs")
async def query_audit_logs(
    user_id: str | None = None,
    action: str | None = None,
    resource_type: str | None = None,
    start_date: str | None = None,
    end_date: str | None = None,
    page: int = 1,
    size: int = 50,
    user: User = Depends(get_current_user),
):
    """查询审计日志"""
    query = select(AuditLog)
    
    if user_id:
        query = query.where(AuditLog.user_id == user_id)
    if action:
        query = query.where(AuditLog.action == action)
    if resource_type:
        query = query.where(AuditLog.resource_type == resource_type)
    
    query = query.order_by(AuditLog.created_at.desc()).offset((page-1)*size).limit(size)
    
    result = await db.execute(query)
    return [dict(row) for row in result]
```

## 练习

### 练习 1：审计日志

实现完整的审计日志系统：

1. 自动记录所有关键操作
2. 记录变更前后的数据
3. 支持按条件查询

### 练习 2：日志导出

实现日志导出功能：

1. 导出为 CSV
2. 导出为 JSON
3. 按时间范围导出

## 本节要点

- 审计日志记录"谁在什么时间做了什么"
- 变更前后的数据对比是审计的核心
- 日志要支持多维度查询和导出
- 审计日志本身不能被删除或修改

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 日志太多性能差 | 没有索引和分区 | 按时间分区，建立索引 |
| 敏感信息泄露 | 日志记录了密码 | 过滤敏感字段 |
| 日志丢失 | 同步写入失败 | 异步写入 + 消息队列 |
