# 08 阶段实战：运营看板与监控系统

> 没有看板的系统是黑盒——有了看板才能看见、管好、优化。

## 学习目标

- 整合阶段 6 所有技能，构建完整的运营看板
- 实现用量统计、成本分析、质量监控
- 体验企业级监控系统的完整功能

## 实战任务

构建 **运营看板与监控系统**：

### 功能清单

1. **用量统计**
   - 每日对话数、消息数
   - Token 用量趋势
   - API 调用次数

2. **成本分析**
   - 按用户/Agent/模型统计成本
   - 成本趋势和预算控制
   - 成本异常告警

3. **质量监控**
   - 用户满意度统计
   - 幻觉率和引用正确率
   - 工具调用成功率

4. **系统监控**
   - API 响应时间
   - 错误率
   - 资源使用情况

## 验收标准

- [ ] JWT 认证完整，支持 Token 刷新
- [ ] RBAC 权限控制粒度到 Skill 级别
- [ ] 审计日志覆盖所有关键操作
- [ ] LLM 调用 Trace 完整
- [ ] 运营看板数据实时更新
- [ ] 提示注入检测准确率 > 95%
- [ ] API 平均响应时间 < 200ms

## 本阶段总结

通过阶段 6，你已经掌握了：

- 认证授权和 RBAC 权限
- Skill 权限控制和沙箱执行
- 审计日志和合规追溯
- LLM 可观测性和成本统计
- Context 数据闭环
- 安全防线和性能优化

阶段 7 将完成生产部署——让系统从 localhost 走到线上。
