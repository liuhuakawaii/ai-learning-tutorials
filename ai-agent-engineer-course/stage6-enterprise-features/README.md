## 实战任务

构建 **运营看板与监控系统**：

- JWT 认证 + RBAC 权限体系
- 多组织空间隔离
- Skill 权限控制：谁能用什么 Skill、需要什么审批
- 操作审计日志：谁在什么时间做了什么
- LLM 调用追踪：每次调用的输入输出、耗时、成本
- 运营数据看板：用量统计、成本分析、用户行为
- 安全防护：提示注入检测、敏感信息脱敏
- 性能优化：缓存命中率、API 响应时间、并发处理

## 验收标准

- [ ] JWT 认证完整，支持 token 刷新和多设备管理
- [ ] RBAC 权限控制粒度到 Skill 级别
- [ ] 审计日志覆盖所有关键操作，支持查询和导出
- [ ] LLM 调用 Trace 完整，能看到每步的 token 用量和耗时
- [ ] 运营看板数据实时更新，支持时间范围筛选
- [ ] 提示注入检测准确率 > 95%，误报率 < 5%
- [ ] API 平均响应时间 < 200ms（不含 LLM 调用）
