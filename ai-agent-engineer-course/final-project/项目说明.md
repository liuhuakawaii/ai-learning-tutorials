# 毕业项目：AI Agent 平台

## 项目概述

整合所有阶段所学，构建一个完整的 **企业级 AI Agent 平台**。这不是一个 demo，而是一个可运行、可演示、可迭代的真实产品。

## 业务背景

假设你加入了一家名为"星辰科技"的公司，负责构建内部 AI Agent 平台。公司的业务团队（销售、客服、运营）需要：

- 一个能回答业务问题的 AI 助手（知识库问答）
- 一个能自动执行任务的 AI Agent（工具调用、工作流）
- 一个能让业务人员自己配置 AI 能力的平台（Skill 管理、工作流编排）

## 核心功能模块

### 1. Agent 配置与管理

- 创建 Agent：设定角色、能力、工具权限
- 配置 System Prompt：可视化编辑、版本管理、A/B 测试
- 发布与版本控制：灰度发布、回滚、草稿状态
- Agent 市场：浏览、安装、评价预置 Agent

### 2. Skill 市场

- Skill 分类：API Skill、Script Skill、Workflow Skill、MCP Skill
- Skill 配置：参数定义、权限设置、测试运行
- Skill 组合：多个 Skill 编排成复合能力
- Skill 监控：调用统计、错误率、耗时分析

### 3. 对话系统

- 多轮对话：上下文自动管理、历史压缩
- 流式响应：逐字输出、中断恢复
- 工具调用：自动选择工具、展示调用过程
- 人工接管：高风险操作暂停等待确认

### 4. 知识库管理

- 文档上传：PDF / Word / Markdown / 网页链接
- 自动索引：解析、切分、向量化、质量检测
- 知识库管理：文档列表、索引状态、批量操作
- 质量监控：检索准确率、引用正确率、用户反馈

### 5. 工作流编排

- 可视化编辑器：拖拽节点、连线、配置参数
- 多种节点：LLM、工具、条件、审批、并行
- 调试模式：单步执行、断点、变量查看
- 执行日志：完整链路追踪、输入输出记录

### 6. 运营看板

- 用量统计：对话数、Token 用量、API 调用次数
- 成本分析：按用户/部门/Agent 分摊成本
- 质量监控：满意度、幻觉率、工具调用成功率
- 用户行为：热门问题、使用时段、留存率

## 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                     前端 (Vue 3)                         │
│  Chat UI │ Agent 配置 │ Skill 管理 │ 工作流编辑器 │ 看板  │
└─────────────────────┬───────────────────────────────────┘
                      │ HTTP / WebSocket
┌─────────────────────┴───────────────────────────────────┐
│                   后端 (FastAPI)                          │
│  API Gateway │ Auth │ Agent Engine │ Workflow Engine      │
│  RAG Pipeline │ Tool Registry │ Skill Runner │ Scheduler  │
└────┬──────────┬───────────┬────────────┬─────────────────┘
     │          │           │            │
  PostgreSQL  Redis     Vector DB    External APIs
  (主数据)    (缓存)    (pgvector)   (LLM/Tools)
```

## 项目要求

### 最低要求（Must Have）

- [ ] 用户注册、登录、JWT 认证
- [ ] Agent 创建、配置、发布
- [ ] 多轮对话 + 流式响应
- [ ] 至少一种 Skill 类型（API Skill）
- [ ] 知识库上传 + 问答
- [ ] Docker Compose 一键启动

### 进阶要求（Should Have）

- [ ] 可视化工作流编辑器
- [ ] 4 种 Skill 类型全部实现
- [ ] MCP 工具集成
- [ ] 运营看板
- [ ] 审计日志
- [ ] CI/CD 自动部署

### 挑战要求（Nice to Have）

- [ ] 多 Agent 协作
- [ ] Context 数据闭环
- [ ] A/B 测试框架
- [ ] 插件系统
- [ ] 多语言支持

## 评分标准

| 维度 | 权重 | 说明 |
|------|------|------|

| 用户体验 | 15% | 界面美观、交互流畅、错误提示友好 |
| 系统健壮性 | 15% | 异常处理、并发安全、数据一致性 |
| 创新性 | 10% | 有自己想法和改进 |
| 文档与演示 | 10% | README 完整、演示流畅、能讲清楚设计决策 |
