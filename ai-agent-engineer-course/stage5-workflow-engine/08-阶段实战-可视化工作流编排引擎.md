# 08 阶段实战：可视化工作流编排引擎

> 把前面学的所有东西组装成一个完整的工作流引擎——从编辑到执行到监控。

## 学习目标

- 整合阶段 5 所有技能，构建完整的可视化工作流引擎
- 实现 DAG 编辑器、执行引擎、条件分支、人工审批、并行执行
- 体验工作流引擎从 0 到 1 的完整过程

## 实战任务

构建 **可视化工作流编排引擎**：

### 功能清单

1. **可视化编辑器**
   - DAG 拖拽编辑
   - 多种节点类型
   - 属性配置面板
   - 保存和加载

2. **执行引擎**
   - 拓扑排序执行
   - 条件分支和循环
   - 并行执行
   - 人工审批

3. **Skill 体系**
   - 4 种 Skill 类型
   - Skill 注册和执行
   - Skill 市场

4. **执行监控**
   - 执行状态追踪
   - 步骤日志
   - 错误处理

## 验收标准

- [ ] 可视化编辑器能流畅拖拽、连线、配置
- [ ] 工作流能按 DAG 顺序正确执行
- [ ] 条件分支根据结果选择路径
- [ ] 并行节点同时执行，汇聚节点聚合结果
- [ ] 人工审批节点能暂停和恢复
- [ ] Skill 能通过配置接入工作流
- [ ] 执行日志完整可查

## 本阶段总结

通过阶段 5，你已经掌握了：

- 工作流引擎的架构设计
- DAG 可视化编辑器
- 执行引擎和拓扑排序
- 条件分支和循环
- 人工审批和并行执行
- Skill 体系设计

阶段 6 将加入企业级能力——权限、审计、监控、安全。
