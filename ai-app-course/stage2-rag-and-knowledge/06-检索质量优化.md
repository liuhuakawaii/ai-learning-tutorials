## 一、检索质量为什么重要

### 1.1 垃圾进，垃圾出

```
检索质量 → 上下文质量 → 回答质量

  检索到无关内容 → 模型基于无关内容回答 → 回答不准确
  检索到相关内容 → 模型基于相关内容回答 → 回答准确

  RAG 的瓶颈往往在检索，不在模型。
```

## 二、Query Rewrite（查询改写）

### 2.1 什么是 Query Rewrite

```
原始查询："怎么退货？"

问题：
  - 太简短，缺少上下文
  - 可能匹配到"退货"但不匹配"退款"

改写后的查询：
  "如何申请商品退货退款，需要什么条件和流程"

优势：
  - 更完整，包含更多关键词
  - 更容易匹配到相关文档
```

### 2.2 使用模型改写查询

```typescript
// lib/query-rewrite.ts
import OpenAI from 'openai'

const openai = new OpenAI()

export async function rewriteQuery(originalQuery: string): Promise<string> {
  const response = await openai.responses.create({
    model: 'gpt-5.5',
    input: [
      {
        role: 'system',
        content: `你是一个搜索查询优化助手。请将用户的简短查询改写为更完整、更适合搜索的形式。

规则：
1. 保持原始意图不变
2. 添加相关同义词
3. 扩展为更完整的句子
4. 不要添加不存在的信息`
      },
      {
        role: 'user',
        content: `原始查询：${originalQuery}

请改写为更适合搜索的形式：`
      }
    ],
    temperature: 0.3,
    max_output_tokens: 100,
  })

  return response.output_text || originalQuery
}

// 使用
const originalQuery = "怎么退货"
const rewrittenQuery = await rewriteQuery(originalQuery)
// "如何申请商品退货退款，需要满足什么条件，具体流程是什么"
```

## 三、Rerank（重排序）

### 3.1 什么是 Rerank

```
初始检索（向量相似度）：
  结果 1: 相似度 0.85 - "退款政策..."
  结果 2: 相似度 0.82 - "退货流程..."
  结果 3: 相似度 0.80 - "购买须知..."
  结果 4: 相似度 0.78 - "售后服务..."
  结果 5: 相似度 0.75 - "联系我们..."

Rerank（更精细的相关性评估）：
  结果 1: 相关性 0.95 - "退货流程..."  ← 排名上升
  结果 2: 相关性 0.90 - "退款政策..."
  结果 3: 相关性 0.60 - "售后服务..."
  结果 4: 相关性 0.40 - "购买须知..."  ← 排名下降
  结果 5: 相关性 0.20 - "联系我们..."
```

### 3.2 使用模型 Rerank

```typescript
// lib/rerank.ts
import OpenAI from 'openai'

const openai = new OpenAI()

interface RerankResult {
  content: string
  metadata: any
  relevanceScore: number
}

export async function rerank(
  query: string,
  documents: { content: string; metadata: any }[],
  topK: number = 3
): Promise<RerankResult[]> {
  // 构建 rerank prompt
  const documentList = documents
    .map((doc, i) => `[${i + 1}] ${doc.content.slice(0, 300)}`)
    .join('\n\n')

  const response = await openai.responses.create({
    model: 'gpt-5.5',
    input: [
      {
        role: 'system',
        content: `你是一个文档相关性评估助手。请评估每个文档与查询的相关性。

输出 JSON 格式：
{
  "rankings": [
    {"index": 1, "relevance": 0.95},
    {"index": 2, "relevance": 0.80},
    ...
  ]
}

relevance 范围 0-1，1 表示完全相关。`
      },
      {
        role: 'user',
        content: `查询：${query}

文档列表：
${documentList}

请评估每个文档的相关性并排序。`
      }
    ],
    text: { format: { type: 'json_object' } },
    temperature: 0,
  })

  const result = JSON.parse(response.output_text || '{"rankings":[]}')
  const rankings = result.rankings || []

  // 按相关性排序并返回
  return rankings
    .sort((a: any, b: any) => b.relevance - a.relevance)
    .slice(0, topK)
    .map((r: any) => ({
      ...documents[r.index - 1],
      relevanceScore: r.relevance,
    }))
}
```

### 3.3 使用 Cohere Rerank API

## 四、混合检索

### 4.1 向量检索 vs 关键词检索

```
┌─────────────────────────────────────────────────────────────────┐
│                向量检索 vs 关键词检索                             │
├─────────────────────┬──────────────────────┬────────────────────┤
│  维度                │  向量检索            │  关键词检索         │
├─────────────────────┼──────────────────────┼────────────────────┤
│  原理                │  语义相似度          │  关键词匹配         │
│  "退货" → "退款"     │  ✅ 能匹配           │  ❌ 不能匹配        │
│  "Python" → "Python" │  ✅ 能匹配           │  ✅ 能匹配          │
│  精确匹配            │  一般                │  好                 │
│  语义理解            │  好                  │  差                 │
└─────────────────────┴──────────────────────┴────────────────────┘

混合检索 = 向量检索 + 关键词检索
  兼顾语义理解和精确匹配
```

### 4.2 实现混合检索

```typescript
// lib/hybrid-search.ts
import { getEmbedding } from './embedding'
import { cosineSimilarity } from './similarity'

interface Document {
  id: string
  content: string
  embedding: number[]
  metadata: any
}

interface SearchResult {
  document: Document
  vectorScore: number
  keywordScore: number
  combinedScore: number
}

export async function hybridSearch(
  query: string,
  documents: Document[],
  options: {
    topK?: number
    vectorWeight?: number
    keywordWeight?: number
  } = {}
): Promise<SearchResult[]> {
  const {
    topK = 5,
    vectorWeight = 0.7,
    keywordWeight = 0.3,
  } = options

  // 1. 向量检索
  const queryEmbedding = await getEmbedding(query)
  const vectorResults = documents.map(doc => ({
    document: doc,
    vectorScore: cosineSimilarity(queryEmbedding, doc.embedding),
  }))

  // 2. 关键词检索（BM25 简化版）
  const queryTerms = query.toLowerCase().split(/\s+/)
  const keywordResults = documents.map(doc => {
    const content = doc.content.toLowerCase()
    let score = 0

    for (const term of queryTerms) {
      // 计算词频
      const regex = new RegExp(term, 'gi')
      const matches = content.match(regex)
      if (matches) {
        score += matches.length
      }
    }

    // 归一化
    score = score / (queryTerms.length * 10)

    return {
      document: doc,
      keywordScore: Math.min(score, 1),
    }
  })

  // 3. 合并分数
  const combined = vectorResults.map((vr, i) => ({
    document: vr.document,
    vectorScore: vr.vectorScore,
    keywordScore: keywordResults[i].keywordScore,
    combinedScore:
      vr.vectorScore * vectorWeight +
      keywordResults[i].keywordScore * keywordWeight,
  }))

  // 4. 排序并返回
  return combined
    .sort((a, b) => b.combinedScore - a.combinedScore)
    .slice(0, topK)
}
```

## 五、完整的优化检索流程

```typescript
// lib/optimized-retrieval.ts
import { rewriteQuery, generateSubQueries } from './query-rewrite'
import { rerank } from './rerank'
import { hybridSearch } from './hybrid-search'

export async function optimizedRetrieval(
  query: string,
  documents: any[],
  options: {
    useQueryRewrite?: boolean
    useRerank?: boolean
    useHybrid?: boolean
    topK?: number
  } = {}
) {
  const {
    useQueryRewrite = true,
    useRerank = true,
    useHybrid = true,
    topK = 5,
  } = options

  let searchQuery = query

  // 1. 查询改写
  if (useQueryRewrite) {
    searchQuery = await rewriteQuery(query)
  }

  // 2. 检索
  let results
  if (useHybrid) {
    results = await hybridSearch(searchQuery, documents, { topK: topK * 2 })
  } else {
    // 仅向量检索
    // ...
  }

  // 3. Rerank
  if (useRerank && results.length > topK) {
    results = await rerank(query, results, topK)
  }

  return results.slice(0, topK)
}
```

## 六、检索质量评估

### 6.1 评估指标

```typescript
interface RetrievalEvaluation {
  // 是否检索到了正确答案
  answerFound: boolean

  // 正确答案的排名
  answerRank: number

  // 检索结果的相关性
  relevanceScores: number[]
}

function evaluateRetrieval(
  query: string,
  expectedAnswer: string,
  searchResults: { content: string }[]
): RetrievalEvaluation {
  // 简单的关键词匹配评估
  const answerKeywords = expectedAnswer.toLowerCase().split(/\s+/)

  let answerFound = false
  let answerRank = -1
  const relevanceScores: number[] = []

  for (let i = 0; i < searchResults.length; i++) {
    const content = searchResults[i].content.toLowerCase()

    // 计算关键词匹配数
    const matchCount = answerKeywords.filter(kw => content.includes(kw)).length
    const relevance = matchCount / answerKeywords.length

    relevanceScores.push(relevance)

    if (relevance > 0.5 && !answerFound) {
      answerFound = true
      answerRank = i + 1
    }
  }

  return { answerFound, answerRank, relevanceScores }
}
```

### 6.2 A/B 测试

```typescript
// 对比不同检索策略的效果
async function compareRetrievalStrategies(
  testCases: { query: string; expectedAnswer: string }[]
) {
  const strategies = [
    { name: 'vector-only', useHybrid: false, useRerank: false },
    { name: 'hybrid', useHybrid: true, useRerank: false },
    { name: 'hybrid+rerank', useHybrid: true, useRerank: true },
  ]

  const results: Record<string, { found: number; avgRank: number }> = {}

  for (const strategy of strategies) {
    let found = 0
    let totalRank = 0

    for (const testCase of testCases) {
      const searchResults = await optimizedRetrieval(
        testCase.query,
        documents,
        strategy
      )

      const eval_ = evaluateRetrieval(
        testCase.query,
        testCase.expectedAnswer,
        searchResults
      )

      if (eval_.answerFound) {
        found++
        totalRank += eval_.answerRank
      }
    }

    results[strategy.name] = {
      found,
      avgRank: found > 0 ? totalRank / found : 0,
    }
  }

  return results
}
```

## 小结

本课的核心要点：

1. **Query Rewrite**：扩展查询，添加同义词，提高召回率
2. **Rerank**：用更精细的模型重排序，提高精确率
3. **混合检索**：向量 + 关键词，兼顾语义和精确匹配
4. **质量评估**：A/B 测试不同策略，持续优化
5. **RAG 的瓶颈在检索**：优化检索是提升 RAG 质量的关键
