# 第四阶段：AI 产品化工程

## 阶段目标

你会把 AI Demo 做成产品：账号、知识库、会话、配额、成本、日志、权限和安全边界。

## 课时安排

1. AI 产品的信息架构
2. 用户、工作区和知识库权限
3. 会话管理：历史、收藏、归档、搜索
4. 成本控制：token 统计、缓存、限流、降级
5. 提示注入与越权检索防护
6. 日志与 trace：请求、检索、工具、输出
7. 阶段实战：AI 知识工作台 MVP

## 实战任务

把前面阶段组合成一个可登录的 AI 工作台，支持多个知识库、多轮会话、用量统计和请求日志。

## 验收标准

- 用户只能访问自己的知识库
- 每次请求记录模型、耗时、token 和错误
- 有配额限制和超额提示
- 能搜索历史会话
- 有提示注入基础防护策略
