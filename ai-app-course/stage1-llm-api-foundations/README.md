# 第一阶段：大模型 API 基础

## 阶段目标

你会从“会调用接口”升级到“能设计稳定的 AI 对话能力”。重点不是堆 Prompt，而是理解请求、上下文、结构化输出、流式响应、错误处理和前端体验。

## 课时安排

1. AI 应用的组成：模型、Prompt、上下文、工具、状态
2. SDK 与环境变量：API Key、服务端调用、密钥保护
3. 第一次模型调用：输入、输出、错误处理
4. 多轮对话：消息历史、上下文裁剪、会话状态
5. 结构化输出：JSON Schema、Zod 校验、类型映射
6. 流式响应：ReadableStream、取消请求、失败恢复
7. 阶段实战：AI 写作助手

## 实战任务

构建一个 AI 写作助手，支持：

- 输入主题、受众、语气和字数
- 返回结构化大纲
- 流式生成正文
- 保存历史记录
- 失败时展示可理解错误

## 验收标准

- API Key 不出现在前端代码
- 输出结构能被 Zod 校验
- 支持流式生成和取消
- 对超时、限流、空输出有错误处理
- 有至少 5 条手工测试用例
