## 一、多轮对话的原理

### 1.1 模型没有"记忆"

```
一个关键认知：

  大模型没有记忆。每次请求都是独立的。

  你以为的对话：
    用户：我叫小明
    AI：你好小明！
    用户：我叫什么？        ← 你以为 AI 记得
    AI：你叫小明啊！        ← 其实是因为你把历史发过去了

  实际发生的事：
    第 1 次请求：["我叫小明"] → "你好小明！"
    第 2 次请求：["我叫小明", "你好小明！", "我叫什么？"] → "你叫小明啊！"
                     ↑ 历史消息被重新发送了
```

### 1.2 消息历史的传递

```typescript
// 多轮对话的核心：每次请求都带上完整的历史
const messages = [
  // 第 1 轮
  { role: 'user', content: '我叫小明' },
  { role: 'assistant', content: '你好小明！' },

  // 第 2 轮
  { role: 'user', content: '我叫什么？' },
  // 这条消息还没回答，是当前要发送的
]

const response = await openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages,  // 把完整历史发给模型
})

// 模型的回答
const answer = response.choices[0].message.content
// "你叫小明啊！"

// 把回答也加入历史，供下一轮使用
messages.push({ role: 'assistant', content: answer })
```

```
┌─────────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────────┤
│                                                                 │

│    发送: [user: "你好"]                                         │

│           assistant: "你好！有什么可以帮你的？",                  │
│           user: "介绍一下 React"]                               │
│    收到: [assistant: "React 是一个..."]                         │
│                                                                 │
│  第 3 轮：                                                      │
│    发送: [user: "你好",                                         │
│           assistant: "你好！有什么可以帮你的？",                  │
│           user: "介绍一下 React",                               │
│           assistant: "React 是一个...",                         │
```

## 二、实现多轮对话

### 2.1 基础实现

```typescript
// src/examples/multi-turn.ts
import 'dotenv/config'
import OpenAI from 'openai'
import * as readline from 'readline'

const openai = new OpenAI()

// 消息历史
const messages: OpenAI.ChatCompletionMessageParam[] = [
  { role: 'system', content: '你是一个有帮助的助手。用中文回答。' }
]

async function chat(userMessage: string): Promise<string> {
  // 添加用户消息到历史
  messages.push({ role: 'user', content: userMessage })

  // 调用 API（带上完整历史）
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages,
  })

  const answer = response.choices[0].message.content ?? ''

  // 把回答也加入历史
  messages.push({ role: 'assistant', content: answer })

  return answer
}

// 交互式对话
async function main() {
  const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
  })

  console.log('AI 助手已启动，输入 "exit" 退出\n')

  const ask = () => {
    rl.question('你: ', async (input) => {
      if (input.toLowerCase() === 'exit') {
        rl.close()
        return
      }

      const answer = await chat(input)
      console.log('AI:', answer)
      console.log(`(历史消息数: ${messages.length})\n`)
      ask()
    })
  }

  ask()
}

main()
```

### 2.2 会话管理：支持多个独立对话

```typescript
// src/lib/conversation.ts
import OpenAI from 'openai'

const openai = new OpenAI()

interface Conversation {
  id: string
  messages: OpenAI.ChatCompletionMessageParam[]
  createdAt: Date
  updatedAt: Date
}

// 存储所有会话
const conversations = new Map<string, Conversation>()

// 创建新会话
export function createConversation(id: string): Conversation {
  const conversation: Conversation = {
    id,
    messages: [
      { role: 'system', content: '你是一个有帮助的助手。' }
    ],
    createdAt: new Date(),
    updatedAt: new Date(),
  }
  conversations.set(id, conversation)
  return conversation
}

// 获取会话
export function getConversation(id: string): Conversation | undefined {
  return conversations.get(id)
}

// 发送消息
export async function sendMessage(
  conversationId: string,
  userMessage: string
): Promise<string> {
  let conversation = conversations.get(conversationId)

  if (!conversation) {
    conversation = createConversation(conversationId)
  }

  // 添加用户消息
  conversation.messages.push({ role: 'user', content: userMessage })

  // 调用 API
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: conversation.messages,
  })

  const answer = response.choices[0].message.content ?? ''

  // 添加回答
  conversation.messages.push({ role: 'assistant', content: answer })
  conversation.updatedAt = new Date()

  return answer
}

// 列出所有会话
export function listConversations(): Conversation[] {
  return Array.from(conversations.values())
    .sort((a, b) => b.updatedAt.getTime() - a.updatedAt.getTime())
}
```

## 三、上下文窗口问题

### 3.1 什么是上下文窗口

```
每个模型都有一个"上下文窗口"限制：

  GPT-4o-mini:  128K tokens
  GPT-4o:       128K tokens
  Claude 3.5:   200K tokens

上下文窗口 = 输入 + 输出 的总 token 数

┌─────────────────────────────────────────────────────────────────┐
│                    上下文窗口                                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    128K tokens                           │   │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌────────┐  │   │
│  │  │  system   │  │ messages │  │ messages │  │ output │  │   │
│  │  │  prompt   │  │  历史    │  │  当前    │  │ 生成的 │  │   │
│  │  └──────────┘  └──────────┘  └──────────┘  └────────┘  │   │
│  │                                                         │   │
│  │  总 token 数不能超过 128K                                │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 超出限制会怎样

```typescript
// 当消息历史太长时
try {
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: veryLongMessages,  // 超过了 128K tokens

    // 错误信息：This model's maximum context length is 128000 tokens
    console.error('消息太长，超出了模型的上下文窗口')
  }
}
```

### 3.3 估算 token 数

```typescript
// 简单估算（不精确，但够用）
function estimateTokens(text: string): number {
  // 英文：1 token ≈ 4 字符
  // 中文：1 token ≈ 1.5 字符
  const englishChars = (text.match(/[a-zA-Z0-9 ]/g) || []).length
  const chineseChars = text.length - englishChars

  return Math.ceil(englishChars / 4 + chineseChars / 1.5)
}

// 更精确的方式：使用 tiktoken 库
// npm install tiktoken
import { encoding_for_model } from 'tiktoken'

function countTokens(text: string, model: string = 'gpt-4o-mini'): number {
  const enc = encoding_for_model(model as any)
  const tokens = enc.encode(text)
  enc.free()
  return tokens.length
}
```

## 四、历史裁剪策略

### 4.1 策略一：保留最近 N 轮

```typescript
// 最简单的策略：只保留最近的 N 轮对话
function trimHistory(
  messages: OpenAI.ChatCompletionMessageParam[],
  maxRounds: number = 10
): OpenAI.ChatCompletionMessageParam[] {
  // 第一条是 system prompt，始终保留
  const systemMessage = messages[0]
  const otherMessages = messages.slice(1)

  // 每轮 = 1 条 user + 1 条 assistant = 2 条消息
  const maxMessages = maxRounds * 2

  if (otherMessages.length <= maxMessages) {
    return messages
  }

  // 保留 system + 最近的 N 轮
  return [
    systemMessage,
    ...otherMessages.slice(-maxMessages),
  ]
}

// 使用
const trimmed = trimHistory(messages, 10)  // 保留最近 10 轮
```

### 4.2 策略二：按 Token 数裁剪

```typescript
// 按 token 数裁剪，更精确
function trimByTokens(
  messages: OpenAI.ChatCompletionMessageParam[],
  maxTokens: number = 4000
): OpenAI.ChatCompletionMessageParam[] {
  const systemMessage = messages[0]
  const otherMessages = messages.slice(1)

  let totalTokens = estimateTokens(systemMessage.content as string)
  const result: OpenAI.ChatCompletionMessageParam[] = []

  // 从最新的消息开始，向前保留
  for (let i = otherMessages.length - 1; i >= 0; i--) {
    const msg = otherMessages[i]
    const msgTokens = estimateTokens(msg.content as string)

    if (totalTokens + msgTokens > maxTokens) {
      break
    }

    totalTokens += msgTokens
    result.unshift(msg)
  }

  return [systemMessage, ...result]
}
```

### 4.3 策略三：摘要压缩

```typescript
// 用模型压缩历史对话
async function summarizeHistory(
  messages: OpenAI.ChatCompletionMessageParam[]
): Promise<string> {
  const conversationText = messages
    .filter(m => m.role !== 'system')
    .map(m => `${m.role}: ${m.content}`)
    .join('\n')

  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      {
        role: 'system',
        content: '请用 3-5 句话总结以下对话的要点，保留关键信息。'
      },
      { role: 'user', content: conversationText }
    ],
    temperature: 0,
    max_tokens: 300,
  })

  return response.choices[0].message.content ?? ''
}

// 压缩后重建消息历史
async function compressHistory(
  messages: OpenAI.ChatCompletionMessageParam[],
  keepRecent: number = 4
): Promise<OpenAI.ChatCompletionMessageParam[]> {
  const systemMessage = messages[0]
  const otherMessages = messages.slice(1)

  if (otherMessages.length <= keepRecent) {
    return messages
  }

  // 需要压缩的部分
  const toSummarize = otherMessages.slice(0, -keepRecent)
  const recent = otherMessages.slice(-keepRecent)

  // 生成摘要
  const summary = await summarizeHistory(toSummarize)

  return [
    systemMessage,
    { role: 'system', content: `之前的对话摘要：${summary}` },
    ...recent,
  ]
}
```

### 4.4 策略对比

```
┌─────────────────────────────────────────────────────────────────┐
│                    历史裁剪策略对比                               │
├──────────────┬──────────────┬──────────────┬────────────────────┤
│  策略         │  实现难度     │  精确度      │  适用场景           │
├──────────────┼──────────────┼──────────────┼────────────────────┤
│  保留最近 N 轮│  简单         │  低          │  快速原型           │
│  按 Token 裁剪│  中等         │  高          │  大多数场景         │
│  摘要压缩     │  复杂         │  中等        │  长对话、重要上下文  │
└──────────────┴──────────────┴──────────────┴────────────────────┘

推荐组合：
  1. 始终保留 system prompt
  2. 按 token 数裁剪（上限 4000）
  3. 超出时，压缩旧历史为摘要
  4. 保留最近 4-6 轮完整对话
```

## 五、完整的会话管理实现

```typescript
// src/lib/chat-manager.ts
import OpenAI from 'openai'

const openai = new OpenAI()

interface ChatSession {
  id: string
  messages: OpenAI.ChatCompletionMessageParam[]
  totalTokens: number
}

const sessions = new Map<string, ChatSession>()

const MAX_HISTORY_TOKENS = 4000
const KEEP_RECENT_ROUNDS = 4

export function getOrCreateSession(id: string): ChatSession {
  if (!sessions.has(id)) {
    sessions.set(id, {
      id,
      messages: [
        { role: 'system', content: '你是一个有帮助的助手。' }
      ],
      totalTokens: 0,
    })
  }
  return sessions.get(id)!
}

function estimateTokens(text: string): number {
  const english = (text.match(/[a-zA-Z0-9 ]/g) || []).length
  const other = text.length - english
  return Math.ceil(english / 4 + other / 1.5)
}

function trimMessages(
  messages: OpenAI.ChatCompletionMessageParam[]
): OpenAI.ChatCompletionMessageParam[] {
  const system = messages[0]
  const rest = messages.slice(1)

  // 计算当前总 token
  let total = estimateTokens(system.content as string)
  for (const msg of rest) {
    total += estimateTokens(msg.content as string)
  }

  // 如果没超限，直接返回
  if (total <= MAX_HISTORY_TOKENS) {
    return messages
  }

  // 保留最近 N 轮
  const keepCount = KEEP_RECENT_ROUNDS * 2
  const recent = rest.slice(-keepCount)

  return [system, ...recent]
}

export async function chat(
  sessionId: string,
  userMessage: string
): Promise<{ answer: string; tokens: number }> {
  const session = getOrCreateSession(sessionId)

  // 添加用户消息
  session.messages.push({ role: 'user', content: userMessage })

  // 裁剪历史
  const trimmed = trimMessages(session.messages)

  // 调用 API
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: trimmed,
  })

  const answer = response.choices[0].message.content ?? ''
  const tokens = response.usage?.total_tokens ?? 0

  // 更新会话
  session.messages.push({ role: 'assistant', content: answer })
  session.totalTokens += tokens

  return { answer, tokens }
}

export function getSessionHistory(sessionId: string) {
  const session = sessions.get(sessionId)
  return session?.messages ?? []
}

export function deleteSession(sessionId: string) {
  sessions.delete(sessionId)
}
```

## 六、前端的会话状态管理

### 6.1 React 实现

```typescript
// features/chat/hooks/useChat.ts
import { useState, useCallback } from 'react'

interface Message {
  role: 'user' | 'assistant'
  content: string
  timestamp: Date
}

export function useChat(sessionId: string) {
  const [messages, setMessages] = useState<Message[]>([])
  const [isLoading, setIsLoading] = useState(false)
  const [error, setError] = useState<string | null>(null)

  const sendMessage = useCallback(async (content: string) => {
    setIsLoading(true)
    setError(null)

    // 添加用户消息
    const userMessage: Message = {
      role: 'user',
      content,
      timestamp: new Date(),
    }
    setMessages(prev => [...prev, userMessage])

    try {
      const response = await fetch('/api/chat', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          sessionId,
          message: content,
        }),
      })

      if (!response.ok) {
        throw new Error('请求失败')
      }

      const data = await response.json()

      // 添加 AI 回答
      const assistantMessage: Message = {
        role: 'assistant',
        content: data.answer,
        timestamp: new Date(),
      }
      setMessages(prev => [...prev, assistantMessage])

    } catch (err) {
      setError(err instanceof Error ? err.message : '未知错误')
    } finally {
      setIsLoading(false)
    }
  }, [sessionId])

  const clearHistory = useCallback(() => {
    setMessages([])
    // 同时通知后端清除
    fetch(`/api/chat/${sessionId}`, { method: 'DELETE' })
  }, [sessionId])

  return {
    messages,
    isLoading,
    error,
    sendMessage,
    clearHistory,
  }
}
```

## 小结

本课的核心要点：

1. **模型没有记忆**：每次请求都是独立的，需要把历史消息一起发送
2. **消息历史增长**：每轮对话增加 2 条消息，token 数持续增长
3. **上下文窗口有限**：超出限制会报错，需要裁剪历史
4. **三种裁剪策略**：按轮数裁剪（简单）、按 token 裁剪（精确）、摘要压缩（保留关键信息）
5. **推荐组合**：system prompt 始终保留 + 按 token 裁剪 + 保留最近 N 轮
