# 第五阶段：评估、上线与迭代

## 阶段目标

你会建立 AI 应用的质量体系：评估集、回归测试、Prompt 版本、线上监控和发布清单。

## 课时安排

1. AI 应用为什么必须评估
2. 构建评估集：事实性、引用、格式、拒答
3. 自动评估：规则、模型评估、人工抽检
4. Prompt 版本管理与回滚
5. 线上监控：延迟、成本、失败率
6. 灰度发布与问题复盘
7. 阶段实战：生产级发布清单

## 实战任务

为 AI 知识工作台建立评估集和发布流程。每次修改 Prompt 或检索策略，都能跑一次回归评估。

## 验收标准

- 至少 20 条评估样本
- 每条样本有预期行为
- 评估结果可保存和对比
- Prompt 修改有版本记录
- 上线前有明确 checklist
