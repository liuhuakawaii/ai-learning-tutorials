# 第三阶段：工具调用与 Agent 工作流

## 阶段目标

你会学会让模型“调用能力”，而不是只生成文本。重点是工具 schema、执行边界、状态机、人工确认和失败恢复。

## 课时安排

1. 工具调用原理：模型何时需要工具
2. 工具 schema：输入、输出、错误协议
3. 常见工具：搜索、数据库查询、保存笔记、生成任务
4. 多步骤任务：计划、执行、观察、修正
5. Agent 状态机：queued、running、blocked、done、failed
6. 人工确认：高风险工具的确认流程
7. 阶段实战：AI 研究助手

## 实战任务

构建一个 AI 研究助手，能根据主题制定研究计划，检索资料，整理摘要，生成报告，并在保存文件前请求用户确认。

## 验收标准

- 每个工具都有明确 schema
- 工具失败不会中断整个会话
- 高风险操作有人工确认
- 任务状态可追踪
- 最终报告包含资料来源
