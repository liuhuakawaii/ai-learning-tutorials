# Stage 1：Node.js 基础

> 从浏览器到服务端：掌握 Node.js 核心概念和 Express 框架

## 课程列表

| # | 课程 | 核心内容 |
|---|------|---------|
| 01 | [认识 Node.js](./01-认识Nodejs.md) | Node.js 架构、事件循环、与浏览器的区别 |
| 02 | [环境搭建与 npm](./02-环境搭建与npm.md) | nvm、npm/pnpm、包管理 |
| 03 | [JavaScript 在服务端](./03-JavaScript在服务端.md) | CommonJS/ESM、模块系统 |
| 04 | [内置模块详解](./04-内置模块详解.md) | fs、path、http、crypto |
| 05 | [Express 入门](./05-Express入门.md) | 路由、中间件、请求响应 |
| 06 | [路由与中间件](./06-路由与中间件.md) | 路由组织、中间件链、错误处理 |
| 07 | [RESTful API 设计](./07-RESTful-API设计.md) | REST 规范、状态码、版本控制 |
| 08 | [请求验证与错误处理](./08-请求验证与错误处理.md) | Joi/Zod 验证、统一错误处理 |
| 09 | [阶段实战：博客 API 基础版](./09-阶段实战-博客API基础版.md) | 完整 CRUD API |

## 学习建议

- 已有 Node.js 基础的学员可以快速浏览 01-04
- 05-08 是核心，务必动手练习
- 09 是第一个完整 API 项目
