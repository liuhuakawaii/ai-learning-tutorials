# 第四课：内置模块详解

## 场景引入

你需要在后端读取一个 JSON 配置文件、解析用户上传的图片、创建一个 HTTP 服务器接收前端请求。在浏览器里这些事情都做不了——浏览器禁止直接访问文件系统，HTTP 请求只能发不能收。但在 Node.js 里，`fs` 模块让你读写任意文件，`http` 模块让你从零创建服务器，`events` 模块让你实现发布订阅模式。这些内置模块是 Node.js 的"原生 API"，不依赖任何第三方包就能完成核心功能。

## 学习目标

完成本课学习后，你将能够：

1. 熟练使用 fs 模块进行文件读写操作
2. 掌握 path 模块的路径处理方法
3. 使用 http 模块从零创建 HTTP 服务器
4. 理解 events 模块的发布订阅模式
5. 使用 url 模块解析 URL 和查询参数
6. 使用 os 模块获取系统信息

## 一、fs 模块（文件系统）

### 1.1 fs 模块概述

**fs（File System）** 模块是 Node.js 最重要的内置模块之一，它提供了与文件系统交互的能力。

```
前端开发者视角：

  浏览器中：
    → 不能直接读写用户电脑上的文件（安全限制）
    → 只能通过 <input type="file"> 让用户选择文件
    → 只能通过 Blob/URL.createObjectURL 创建下载

  Node.js 中：
    → 可以读写服务器（或本地）的任何文件
    → 这是后端最重要的能力之一
    → fs 模块提供了完整的文件操作 API
```

### 1.2 同步 vs 异步

```javascript
const fs = require('fs');

// ========== 同步操作（阻塞） ==========

// 读取文件
try {
    const data = fs.readFileSync('./data.txt', 'utf-8');
    console.log('文件内容:', data);
} catch (err) {
    console.error('读取失败:', err.message);
}

console.log('这行在文件读取完成后才执行');

// ========== 异步操作（非阻塞） ==========

// 回调风格
fs.readFile('./data.txt', 'utf-8', (err, data) => {
    if (err) {
        console.error('读取失败:', err.message);
        return;
    }
    console.log('文件内容:', data);
});

console.log('这行在文件读取之前就执行了');

// ========== Promise 风格（推荐） ==========
const fsPromises = require('fs').promises;

async function readFile() {
    try {
        const data = await fsPromises.readFile('./data.txt', 'utf-8');
        console.log('文件内容:', data);
    } catch (err) {
        console.error('读取失败:', err.message);
    }
}

readFile();
```

### 1.3 文件读取

```javascript
const fs = require('fs');
const fsPromises = fs.promises;

// ========== 读取文本文件 ==========

// 同步读取
const text = fs.readFileSync('./README.md', 'utf-8');
console.log(text);

// 异步读取（Promise）
async function readText() {
    const text = await fsPromises.readFile('./README.md', 'utf-8');
    console.log(text);
}

// ========== 读取 JSON 文件 ==========

function readJSON(filePath) {
    const content = fs.readFileSync(filePath, 'utf-8');
    return JSON.parse(content);
}

const config = readJSON('./config.json');
console.log(config);

// ========== 读取二进制文件 ==========

const imageBuffer = fs.readFileSync('./photo.jpg');
console.log('图片大小:', imageBuffer.length, '字节');

// ========== 读取大文件（逐行读取） ==========

const readline = require('readline');

async function readLargeFile(filePath) {
    const fileStream = fs.createReadStream(filePath);
    const rl = readline.createInterface({
        input: fileStream,
        crlfDelay: Infinity
    });

    let lineCount = 0;
    for await (const line of rl) {
        lineCount++;
        console.log(`第 ${lineCount} 行: ${line}`);
    }
    console.log(`总共 ${lineCount} 行`);
}

readLargeFile('./large-file.txt');
```

### 1.4 文件写入

```javascript
const fs = require('fs');
const fsPromises = fs.promises;

// ========== 写入文本文件 ==========

// 同步写入（覆盖）
fs.writeFileSync('./output.txt', 'Hello World\n');

// 追加内容
fs.appendFileSync('./output.txt', '第二行\n');
fs.appendFileSync('./output.txt', '第三行\n');

// Promise 风格
async function writeFile() {
    await fsPromises.writeFile('./output.txt', '新内容\n');
    await fsPromises.appendFile('./output.txt', '追加内容\n');
}

// ========== 写入 JSON 文件 ==========

function writeJSON(filePath, data) {
    const content = JSON.stringify(data, null, 2);  // 格式化输出
    fs.writeFileSync(filePath, content, 'utf-8');
}

const users = [
    { id: 1, name: '张三', age: 25 },
    { id: 2, name: '李四', age: 30 }
];
writeJSON('./users.json', users);

// ========== 写入选项 ==========

fs.writeFileSync('./output.txt', '内容', {
    encoding: 'utf-8',    // 编码
    mode: 0o666,          // 文件权限
    flag: 'w'             // 写入模式
});

// flag 选项：
// 'w'  - 写入（覆盖）
// 'a'  - 追加
// 'wx' - 写入（文件已存在则失败）
// 'ax' - 追加（文件已存在则失败）
```

### 1.5 文件操作

```javascript
const fs = require('fs');

// ========== 检查文件是否存在 ==========

// 同步（推荐）
if (fs.existsSync('./data.txt')) {
    console.log('文件存在');
}

// 异步（不推荐用于简单检查）
fs.access('./data.txt', fs.constants.F_OK, (err) => {
    console.log(err ? '文件不存在' : '文件存在');
});

// ========== 获取文件信息 ==========

const stats = fs.statSync('./data.txt');
console.log('是否是文件:', stats.isFile());
console.log('是否是目录:', stats.isDirectory());
console.log('文件大小:', stats.size, '字节');
console.log('创建时间:', stats.birthtime);
console.log('修改时间:', stats.mtime);

// ========== 创建目录 ==========

// 同步创建（递归创建）
fs.mkdirSync('./data/logs', { recursive: true });

// 异步创建
fs.mkdir('./data/temp', { recursive: true }, (err) => {
    if (err) throw err;
    console.log('目录创建成功');
});

// ========== 读取目录 ==========

// 同步读取
const files = fs.readdirSync('./src');
console.log('文件列表:', files);

// 读取详细信息
const filesWithStats = fs.readdirSync('./src').map(file => {
    const filePath = `./src/${file}`;
    const stats = fs.statSync(filePath);
    return {
        name: file,
        isFile: stats.isFile(),
        size: stats.size
    };
});
console.log(filesWithStats);

// ========== 删除文件 ==========

fs.unlinkSync('./temp.txt');

// ========== 删除目录 ==========

// 只能删除空目录
fs.rmdirSync('./empty-dir');

// 递归删除（Node.js 14+）
fs.rmSync('./data/temp', { recursive: true });

// ========== 重命名/移动 ==========

fs.renameSync('./old-name.txt', './new-name.txt');
fs.renameSync('./file.txt', './archive/file.txt');

// ========== 复制文件 ==========

fs.copyFileSync('./source.txt', './dest.txt');
```

### 1.6 Stream 流式处理

```
为什么需要 Stream？

读取大文件的两种方式：

方式一：一次性读取（内存爆炸）
  fs.readFileSync('./huge-file.log')
  → 将整个文件加载到内存
  → 如果文件 10GB，内存可能不够

方式二：流式读取（推荐）
  fs.createReadStream('./huge-file.log')
  → 一小块一小块地读取
  → 内存占用很小
  → 类比：用吸管喝水 vs 把整杯水倒进嘴里
```

```javascript
const fs = require('fs');

// ========== 可读流（ReadStream） ==========

const readStream = fs.createReadStream('./large-file.txt', {
    encoding: 'utf-8',
    highWaterMark: 1024  // 每次读取 1024 字节
});

readStream.on('data', (chunk) => {
    console.log('收到数据块:', chunk.length, '字节');
    // 处理数据块
});

readStream.on('end', () => {
    console.log('读取完成');
});

readStream.on('error', (err) => {
    console.error('读取错误:', err.message);
});

// ========== 可写流（WriteStream） ==========

const writeStream = fs.createWriteStream('./output.txt');

writeStream.write('第一行\n');
writeStream.write('第二行\n');
writeStream.write('第三行\n');
writeStream.end('最后一行\n');

writeStream.on('finish', () => {
    console.log('写入完成');
});

// ========== 管道（Pipe） ==========

// 复制文件（最高效的方式）
const readStream2 = fs.createReadStream('./source.txt');
const writeStream2 = fs.createWriteStream('./dest.txt');

readStream2.pipe(writeStream2);

// 监听完成
writeStream2.on('finish', () => {
    console.log('文件复制完成');
});

// ========== Transform Stream（转换流） ==========

const { Transform } = require('stream');

const uppercaseTransform = new Transform({
    transform(chunk, encoding, callback) {
        // 将数据转为大写
        this.push(chunk.toString().toUpperCase());
        callback();
    }
});

// 读取 → 转换 → 写入
fs.createReadStream('./input.txt')
    .pipe(uppercaseTransform)
    .pipe(fs.createWriteStream('./output-upper.txt'));
```

## 二、path 模块

### 2.1 为什么需要 path 模块

```
问题：不同操作系统的路径分隔符不同

  Windows: C:\Users\name\project\file.txt  （用 \）
  Mac/Linux: /Users/name/project/file.txt   （用 /）

  如果用字符串拼接：
    const path = dir + '/' + file;  // 在 Windows 上可能出错
    const path = dir + '\\' + file; // 在 Mac 上会出错

  解决方案：使用 path 模块
    path.join(dir, file)  // 自动使用正确的分隔符
```

### 2.2 常用方法

```javascript
const path = require('path');

// ========== 路径拼接 ==========

// path.join() - 拼接路径片段
const fullPath = path.join('/Users', 'name', 'project', 'file.txt');
console.log(fullPath);
// Mac/Linux: /Users/name/project/file.txt
// Windows: \Users\name\project\file.txt

// 常见用法
const configPath = path.join(__dirname, 'config', 'settings.json');
const publicPath = path.join(__dirname, '..', 'public');

// path.resolve() - 解析为绝对路径
console.log(path.resolve('data', 'file.txt'));
// 输出: /current/working/dir/data/file.txt

console.log(path.resolve('/data', 'file.txt'));
// 输出: /data/file.txt（已经是绝对路径）

// ========== 路径解析 ==========

const filePath = '/Users/name/project/src/app.js';

console.log(path.dirname(filePath));   // '/Users/name/project/src'
console.log(path.basename(filePath));  // 'app.js'
console.log(path.extname(filePath));   // '.js'
console.log(path.basename(filePath, '.js'));  // 'app'

// ========== 路径信息 ==========

console.log(path.parse('/Users/name/project/app.js'));
// {
//   root: '/',
//   dir: '/Users/name/project',
//   base: 'app.js',
//   ext: '.js',
//   name: 'app'
// }

console.log(path.format({
    dir: '/Users/name/project',
    name: 'app',
    ext: '.js'
}));
// '/Users/name/project/app.js'

// ========== 路径判断 ==========

console.log(path.isAbsolute('/Users/name'));  // true
console.log(path.isAbsolute('./file.txt'));   // false
console.log(path.isAbsolute('file.txt'));     // false

// ========== 相对路径 ==========

console.log(path.relative('/data/test', '/data/test/dir/file.txt'));
// 'dir/file.txt'

console.log(path.relative('/data/a', '/data/b'));
// '../b'
```

### 2.3 最佳实践

```javascript
const path = require('path');

// ✅ 推荐：使用 path.join 拼接路径
const configPath = path.join(__dirname, 'config', 'app.json');

// ✅ 推荐：使用 path.resolve 获取绝对路径
const absPath = path.resolve('relative', 'path');

// ❌ 避免：字符串拼接
const badPath = __dirname + '/config/app.json';

// ❌ 避免：硬编码分隔符
const badPath2 = __dirname + '\\config\\app.json';
```

## 三、http 模块

### 3.1 创建最简单的 HTTP 服务器

```javascript
// src/basic-server.js
const http = require('http');

// 创建服务器
const server = http.createServer((req, res) => {
    // 每个请求都会执行这个回调函数

    console.log(`${req.method} ${req.url}`);

    // 设置响应头
    res.writeHead(200, {
        'Content-Type': 'application/json',
        'X-Powered-By': 'Node.js'
    });

    // 发送响应
    res.end(JSON.stringify({
        message: 'Hello from Node.js!',
        timestamp: new Date().toISOString()
    }));
});

// 监听端口
const PORT = 3000;
server.listen(PORT, () => {
    console.log(`服务器运行在 http://localhost:${PORT}`);
});

// 测试：curl http://localhost:3000
```

### 3.2 处理不同的路由

```javascript
// src/router-server.js
const http = require('http');

const server = http.createServer((req, res) => {
    const { method, url } = req;

    // 设置响应头
    res.setHeader('Content-Type', 'application/json');

    // 路由处理
    if (method === 'GET' && url === '/') {
        res.writeHead(200);
        res.end(JSON.stringify({ message: '首页' }));

    } else if (method === 'GET' && url === '/api/users') {
        res.writeHead(200);
        res.end(JSON.stringify({
            users: [
                { id: 1, name: '张三' },
                { id: 2, name: '李四' }
            ]
        }));

    } else if (method === 'GET' && url.startsWith('/api/users/')) {
        const id = url.split('/').pop();
        res.writeHead(200);
        res.end(JSON.stringify({ id, name: '用户' + id }));

    } else if (method === 'POST' && url === '/api/users') {
        // 读取请求体
        let body = '';
        req.on('data', chunk => {
            body += chunk.toString();
        });
        req.on('end', () => {
            const user = JSON.parse(body);
            res.writeHead(201);
            res.end(JSON.stringify({ id: 3, ...user }));
        });

    } else {
        res.writeHead(404);
        res.end(JSON.stringify({ error: 'Not Found' }));
    }
});

server.listen(3000, () => {
    console.log('服务器运行在 http://localhost:3000');
});
```

### 3.3 HTTP 服务器的工作原理

```
HTTP 请求的生命周期：

  客户端（浏览器/curl）
       │
       │ HTTP 请求
       │ GET /api/users HTTP/1.1
       │ Host: localhost:3000
       │
       ▼
  ┌──────────────────────────────────────┐
  │  http.createServer() 创建的服务器      │
  │                                      │
  │  req（IncomingMessage）              │
  │  ├── method: 'GET'                   │
  │  ├── url: '/api/users'               │
  │  ├── headers: { ... }                │
  │  └── on('data') / on('end')          │
  │                                      │
  │  res（ServerResponse）               │
  │  ├── writeHead(statusCode, headers)  │
  │  ├── write(data)                     │
  │  └── end(data)                       │
  └──────────────────────────────────────┘
       │
       │ HTTP 响应
       │ HTTP/1.1 200 OK
       │ Content-Type: application/json
       │
       ▼
  客户端收到响应
```

## 四、events 模块

### 4.1 发布订阅模式

```
发布订阅模式（Pub/Sub）是 Node.js 的核心设计模式之一：

类比：杂志订阅

  发布者（Publisher）：       订阅者（Subscriber）：
  杂志社                     读者 A、读者 B、读者 C
     │                           │
     │  发布新一期               │
     ├──────────────────────────►│
     │                           │ 读者 A 收到，开始阅读
     │                           │ 读者 B 收到，开始阅读
     │                           │ 读者 C 收到，开始阅读

代码中的体现：

  EventEmitter（发布者）       监听器（订阅者）
     │                           │
     │  emit('事件名', 数据)     │
     ├──────────────────────────►│
     │                           │ on('事件名', 回调)
     │                           │ 回调被执行
```

### 4.2 EventEmitter 基础

```javascript
const EventEmitter = require('events');

// 创建事件发射器
const emitter = new EventEmitter();

// 注册监听器
emitter.on('greeting', (name) => {
    console.log(`你好，${name}！`);
});

emitter.on('greeting', (name) => {
    console.log(`欢迎，${name}！`);
});

// 触发事件
emitter.emit('greeting', '张三');
// 输出：
// 你好，张三！
// 欢迎，张三！

// 只监听一次
emitter.once('connect', () => {
    console.log('已连接（只会触发一次）');
});

emitter.emit('connect');  // 触发
emitter.emit('connect');  // 不会触发

// 移除监听器
function handler(data) {
    console.log(data);
}
emitter.on('data', handler);
emitter.removeListener('data', handler);
// 或 emitter.off('data', handler);
```

### 4.3 错误处理

```javascript
const EventEmitter = require('events');

const emitter = new EventEmitter();

// ⚠️ 重要：始终监听 error 事件
// 如果没有监听 error 事件，Node.js 会抛出异常并崩溃
emitter.on('error', (err) => {
    console.error('发生错误:', err.message);
});

// 触发错误事件
emitter.emit('error', new Error('出错了'));
```

### 4.4 自定义类继承 EventEmitter

```javascript
const EventEmitter = require('events');

// 自定义类继承 EventEmitter
class Logger extends EventEmitter {
    log(level, message) {
        const entry = {
            level,
            message,
            timestamp: new Date().toISOString()
        };

        // 触发日志事件
        this.emit('log', entry);

        if (level === 'error') {
            this.emit('error', entry);
        }
    }
}

// 使用
const logger = new Logger();

logger.on('log', (entry) => {
    console.log(`[${entry.level}] ${entry.message}`);
});

logger.on('error', (entry) => {
    // 发送错误通知
    console.error(`错误警报: ${entry.message}`);
});

logger.log('info', '服务器启动');
logger.log('error', '数据库连接失败');
```

## 五、url 模块

### 5.1 URL 解析

```javascript
const url = require('url');

// ========== 使用 WHATWG URL（推荐） ==========

const myUrl = new URL('https://example.com:8080/path/name?key=value&foo=bar#section');

console.log(myUrl.href);       // 完整 URL
console.log(myUrl.protocol);   // 'https:'
console.log(myUrl.hostname);   // 'example.com'
console.log(myUrl.port);       // '8080'
console.log(myUrl.pathname);   // '/path/name'
console.log(myUrl.search);     // '?key=value&foo=bar'
console.log(myUrl.hash);       // '#section'
console.log(myUrl.origin);     // 'https://example.com:8080'

// ========== 查询参数处理 ==========

// URLSearchParams
const params = myUrl.searchParams;

console.log(params.get('key'));    // 'value'
console.log(params.get('foo'));    // 'bar'
console.log(params.has('key'));    // true

// 遍历所有参数
for (const [key, value] of params) {
    console.log(`${key}: ${value}`);
}

// 添加参数
params.append('new', 'param');
console.log(myUrl.href);  // URL 会自动更新

// 删除参数
params.delete('foo');

// ========== 构建 URL ==========

const apiUrl = new URL('https://api.example.com/users');
apiUrl.searchParams.set('page', '1');
apiUrl.searchParams.set('limit', '10');
apiUrl.searchParams.set('sort', 'name');
console.log(apiUrl.href);
// 'https://api.example.com/users?page=1&limit=10&sort=name'
```

### 5.2 在 HTTP 服务器中解析 URL

```javascript
const http = require('http');
const url = require('url');

const server = http.createServer((req, res) => {
    // 解析请求 URL
    const parsedUrl = new URL(req.url, `http://${req.headers.host}`);

    console.log('路径:', parsedUrl.pathname);
    console.log('查询参数:', Object.fromEntries(parsedUrl.searchParams));

    // 根据路径处理
    if (parsedUrl.pathname === '/api/search') {
        const keyword = parsedUrl.searchParams.get('keyword');
        const page = parsedUrl.searchParams.get('page') || '1';

        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({
            keyword,
            page: parseInt(page),
            results: []
        }));
    } else {
        res.writeHead(404);
        res.end('Not Found');
    }
});

server.listen(3000);
// 测试: curl "http://localhost:3000/api/search?keyword=node&page=2"
```

## 六、os 模块

### 6.1 获取系统信息

```javascript
const os = require('os');

// ========== 系统信息 ==========

console.log('操作系统:', os.type());         // 'Windows_NT', 'Darwin', 'Linux'
console.log('平台:', os.platform());         // 'win32', 'darwin', 'linux'
console.log('架构:', os.arch());             // 'x64', 'arm64'
console.log('版本:', os.release());          // '10.0.22000'
console.log('主机名:', os.hostname());       // 'DESKTOP-ABC123'

// ========== CPU 信息 ==========

const cpus = os.cpus();
console.log('CPU 核心数:', cpus.length);
console.log('CPU 型号:', cpus[0].model);
console.log('CPU 速度:', cpus[0].speed, 'MHz');

// ========== 内存信息 ==========

const totalMem = os.totalmem();
const freeMem = os.freemem();
```

## 七、实战：用 http 模块手写 Web 服务器

### 7.1 需求

创建一个功能完整的 Web 服务器，支持：
1. 静态文件服务
2. JSON API 路由
3. 请求日志
4. 错误处理

### 7.2 完整代码

```javascript
// src/static-server.js
const http = require('http');
const fs = require('fs');
const path = require('path');

// ========== 配置 ==========

const PORT = 3000;
const STATIC_DIR = path.join(__dirname, 'public');

// MIME 类型映射
const MIME_TYPES = {
    '.html': 'text/html; charset=utf-8',
    '.css': 'text/css; charset=utf-8',
    '.js': 'application/javascript; charset=utf-8',
    '.json': 'application/json; charset=utf-8',
    '.png': 'image/png',
    '.jpg': 'image/jpeg',
    '.jpeg': 'image/jpeg',
    '.gif': 'image/gif',
    '.svg': 'image/svg+xml',
    '.ico': 'image/x-icon',
    '.txt': 'text/plain; charset=utf-8'
};

// ========== 工具函数 ==========

/**
 * 获取 MIME 类型
 */
function getMimeType(filePath) {
    const ext = path.extname(filePath).toLowerCase();
    return MIME_TYPES[ext] || 'application/octet-stream';
}

/**
 * 读取静态文件
 */
function serveStaticFile(filePath) {
    return new Promise((resolve, reject) => {
        fs.readFile(filePath, (err, data) => {
            if (err) {
                reject(err);
            } else {
                resolve(data);
            }
        });
    });
}

/**
 * 发送 JSON 响应
 */
function sendJSON(res, statusCode, data) {
    res.writeHead(statusCode, {
        'Content-Type': 'application/json; charset=utf-8'
    });
    res.end(JSON.stringify(data, null, 2));
}

/**
 * 发送错误响应
 */
function sendError(res, statusCode, message) {
    sendJSON(res, statusCode, { error: message });
}

// ========== 模拟数据 ==========

let users = [
    { id: 1, name: '张三', email: 'zhangsan@example.com' },
    { id: 2, name: '李四', email: 'lisi@example.com' }
];

let nextId = 3;

// ========== 路由处理 ==========

async function handleRequest(req, res) {
    const { method, url } = req;

    // 请求日志
    const start = Date.now();
    console.log(`→ ${method} ${url}`);

    try {
        // API 路由
        if (url.startsWith('/api/')) {
            return handleAPI(req, res, method, url);
        }

        // 静态文件
        return await handleStatic(req, res, url);

    } catch (err) {
        console.error('请求处理错误:', err);
        sendError(res, 500, '服务器内部错误');
    } finally {
        const duration = Date.now() - start;
        console.log(`← ${method} ${url} (${duration}ms)`);
    }
}

// API 路由处理
function handleAPI(req, res, method, url) {
    // GET /api/users
    if (method === 'GET' && url === '/api/users') {
        return sendJSON(res, 200, { users });
    }

    // GET /api/users/:id
    const userMatch = url.match(/^\/api\/users\/(\d+)$/);
    if (method === 'GET' && userMatch) {
        const id = parseInt(userMatch[1]);
        const user = users.find(u => u.id === id);
        if (!user) {
            return sendError(res, 404, '用户不存在');
        }
        return sendJSON(res, 200, { user });
    }

    // POST /api/users
    if (method === 'POST' && url === '/api/users') {
        return readBody(req).then(body => {
            try {
                const data = JSON.parse(body);
                if (!data.name || !data.email) {
                    return sendError(res, 400, '姓名和邮箱为必填项');
                }
                const user = { id: nextId++, ...data };
                users.push(user);
                sendJSON(res, 201, { user });
            } catch (err) {
                sendError(res, 400, '无效的 JSON 数据');
            }
        });
    }

    // DELETE /api/users/:id
    const deleteMatch = url.match(/^\/api\/users\/(\d+)$/);
    if (method === 'DELETE' && deleteMatch) {
        const id = parseInt(deleteMatch[1]);
        const index = users.findIndex(u => u.id === id);
        if (index === -1) {
            return sendError(res, 404, '用户不存在');
        }
        users.splice(index, 1);
        return sendJSON(res, 200, { message: '删除成功' });
    }

    // 404
    sendError(res, 404, 'API 路由不存在');
}

// 静态文件处理
async function handleStatic(req, res, url) {
    let filePath = path.join(STATIC_DIR, url === '/' ? 'index.html' : url);

    // 安全检查：防止目录遍历攻击
    if (!filePath.startsWith(STATIC_DIR)) {
        sendError(res, 403, '禁止访问');
        return;
    }

    try {
        const data = await serveStaticFile(filePath);
        const mimeType = getMimeType(filePath);
        res.writeHead(200, { 'Content-Type': mimeType });
        res.end(data);
    } catch (err) {
        if (err.code === 'ENOENT') {
            sendError(res, 404, '文件不存在');
        } else {
            throw err;
        }
    }
}

// 读取请求体
function readBody(req) {
    return new Promise((resolve, reject) => {
        let body = '';
        req.on('data', chunk => {
            body += chunk.toString();
        });
        req.on('end', () => resolve(body));
        req.on('error', reject);
    });
}

// ========== 启动服务器 ==========

const server = http.createServer(handleRequest);

server.listen(PORT, () => {
    console.log(`服务器运行在 http://localhost:${PORT}`);
    console.log(`静态文件目录: ${STATIC_DIR}`);
    console.log('API 端点:');
    console.log('  GET    /api/users');
    console.log('  GET    /api/users/:id');
    console.log('  POST   /api/users');
    console.log('  DELETE /api/users/:id');
});
```

### 练习 1：文件操作

**思路**：使用 `fs.promises` 版本的 API 配合 `async/await`，依次完成目录创建、文件写入、读取、追加和目录遍历。

**答案**：

```javascript
// file-exercises.js
const fs = require('fs').promises;
const path = require('path');

async function main() {
  const dataDir = path.join(__dirname, 'data');

  // 1. 创建目录（recursive: true 避免目录已存在时报错）
  await fs.mkdir(dataDir, { recursive: true });
  console.log('目录创建成功');

  // 2. 写入 3 个用户
  const users = [
    { id: 1, name: '张三', age: 25 },
    { id: 2, name: '李四', age: 30 },
    { id: 3, name: '王五', age: 28 },
  ];
  const filePath = path.join(dataDir, 'users.json');
  await fs.writeFile(filePath, JSON.stringify(users, null, 2), 'utf-8');
  console.log('写入 users.json 完成');

  // 3. 读取并输出
  const content = await fs.readFile(filePath, 'utf-8');
  const parsed = JSON.parse(content);
  console.log('读取到的用户:', parsed);

  // 4. 追加一个新用户
  parsed.push({ id: 4, name: '赵六', age: 35 });
  await fs.writeFile(filePath, JSON.stringify(parsed, null, 2), 'utf-8');
  console.log('追加用户完成');

  // 5. 统计目录下文件数量
  const files = await fs.readdir(dataDir);
  console.log('data/ 目录下文件数量:', files.length);
  console.log('文件列表:', files);
}

main().catch(console.error);
```

运行 `node file-exercises.js` 后输出：

```
目录创建成功
写入 users.json 完成
读取到的用户: [ { id: 1, name: '张三', age: 25 }, ... ]
追加用户完成
data/ 目录下文件数量: 1
文件列表: [ 'users.json' ]
```

**要点**：
- `fs.mkdir` 的 `recursive: true` 选项等同于 `mkdir -p`，目录已存在时不会报错
- `JSON.stringify(obj, null, 2)` 的第三个参数 `2` 表示缩进 2 个空格，方便人类阅读
- `fs.readdir` 返回文件名数组，不含路径前缀

### 练习 2：日志系统

**思路**：继承 `EventEmitter` 创建 `Logger` 类，通过事件机制将日志输出与日志产生解耦，支持多级别和多输出目标。

**答案**：

```javascript
// logger.js
const fs = require('fs');
const path = require('path');
const { EventEmitter } = require('events');

class Logger extends EventEmitter {
  constructor(logFile) {
    super();
    this.logFile = logFile;

    // 监听不同级别的日志事件
    this.on('info', (msg) => this._write('INFO', msg));
    this.on('warn', (msg) => this._write('WARN', msg));
    this.on('error', (msg) => this._write('ERROR', msg));
  }

  _write(level, message) {
    const timestamp = new Date().toISOString();
    const logLine = `[${timestamp}] [${level}] ${message}`;

    // 输出到控制台
    if (level === 'ERROR') {
      console.error('\x1b[31m%s\x1b[0m', logLine); // 红色
    } else if (level === 'WARN') {
      console.warn('\x1b[33m%s\x1b[0m', logLine);  // 黄色
    } else {
      console.log(logLine);
    }

    // 输出到文件
    fs.appendFileSync(this.logFile, logLine + '\n');
  }

  info(msg) {
    this.emit('info', msg);
  }

  warn(msg) {
    this.emit('warn', msg);
  }

  error(msg) {
    this.emit('error', msg);
  }
}

// 使用示例
const logger = new Logger(path.join(__dirname, 'app.log'));
logger.info('服务器启动成功，端口 3000');
logger.warn('磁盘空间不足 20%');
logger.error('数据库连接失败: ECONNREFUSED');

// 也可以监听自定义事件
logger.on('info', (msg) => {
  // 这里可以扩展：发送到远程日志服务等
});
```

运行 `node logger.js` 后控制台输出（带颜色）：

```
[2024-01-01T12:00:00.000Z] [INFO] 服务器启动成功，端口 3000
[2024-01-01T12:00:00.001Z] [WARN] 磁盘空间不足 20%
[2024-01-01T12:00:00.002Z] [ERROR] 数据库连接失败: ECONNREFUSED
```

同时 `app.log` 文件中也会写入同样的内容。

**要点**：
- `EventEmitter` 的核心模式：`emit` 触发事件，`on` 监听事件，实现模块间解耦
- `fs.appendFileSync` 用于追加写入，不会覆盖已有内容
- ANSI 转义码（如 `\x1b[31m`）可以在终端中输出彩色文本，`\x1b[0m` 重置颜色

### 练习 3：HTTP 服务器

**思路**：使用 `http.createServer` 创建服务器，通过 `req.url` 解析路径和查询参数，返回不同响应。

**答案**：

```javascript
// api-server.js
const http = require('http');
const url = require('url');

const server = http.createServer((req, res) => {
  const parsedUrl = url.parse(req.url, true);
  const pathname = parsedUrl.pathname;
  const query = parsedUrl.query;

  res.setHeader('Content-Type', 'application/json; charset=utf-8');

  if (pathname === '/' && req.method === 'GET') {
    res.end(JSON.stringify({ message: '欢迎访问 API 服务器' }));
  } else if (pathname === '/time' && req.method === 'GET') {
    res.end(JSON.stringify({ time: new Date().toLocaleString('zh-CN') }));
  } else if (pathname === '/random' && req.method === 'GET') {
    const min = parseInt(query.min) || 1;
    const max = parseInt(query.max) || 100;
    const result = Math.floor(Math.random() * (max - min + 1)) + min;
    res.end(JSON.stringify({ min, max, result }));
  } else {
    res.statusCode = 404;
    res.end(JSON.stringify({ error: '页面未找到', path: pathname }));
  }
});

server.listen(3000, () => {
  console.log('服务器运行在 http://localhost:3000');
  console.log('可用路由:');
  console.log('  GET /          → 欢迎信息');
  console.log('  GET /time      → 当前时间');
  console.log('  GET /random?min=1&max=100 → 随机数');
});
```

测试：

```bash

# {"message":"欢迎访问 API 服务器"}

curl http://localhost:3000/time
```

**要点**：
- `url.parse(req.url, true)` 的第二个参数 `true` 会自动将查询字符串解析为对象
- 必须设置 `Content-Type` 响应头为 `application/json`，否则客户端可能无法正确解析 JSON
- `res.statusCode = 404` 设置 HTTP 状态码，表示资源未找到
- 生产环境中应使用 Express 等框架，原生 `http` 模块适合理解底层原理

## 常见误区

1. **用 readFileSync 读取大文件**：`readFileSync` 会把整个文件加载到内存，如果文件有几 GB，会直接导致内存溢出。大文件应该用 `createReadStream` 流式读取。
2. **用字符串拼接路径而不是 path.join**：`__dirname + '/config/app.json'` 在 Windows 上会产生混合分隔符（`C:\Users\name\src/config.json`），导致路径解析失败。
3. **忘记监听 error 事件**：使用 Stream 时如果不监听 `error` 事件，未捕获的错误会导致进程崩溃。每个可读流和可写流都应该有错误处理。
4. **在 http.createServer 回调中不处理异常**：HTTP 服务器的请求处理回调中如果抛出未捕获的异常，整个服务器会崩溃。应该用 try-catch 包裹请求处理逻辑。

## 工程建议

1. **优先使用 Promise 版本的 fs API**：`const fs = require('fs').promises` 或 `const { readFile } = require('fs/promises')`，配合 async/await 使代码更清晰，避免回调地狱。
2. **静态文件服务使用 express.static 而非手写**：生产环境中用 Express 的 `express.static` 中间件或 Nginx 提供静态文件服务，手写容易遗漏 MIME 类型、缓存头、安全检查。
3. **用 EventEmitter 实现模块间解耦**：当模块 A 需要通知模块 B 某件事发生了，不要直接调用模块 B 的方法，而是通过 EventEmitter 发射事件，让模块 B 自行监听。
4. **HTTP 服务器始终设置超时**：使用 `server.timeout` 或 `server.setTimeout()` 设置请求超时，防止慢客户端占用连接资源。
