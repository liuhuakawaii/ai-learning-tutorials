# 第八课：阶段实战 — 博客数据层

## 场景引入

前 7 课你学了数据库概念、SQL 语法、PostgreSQL 安装、Prisma ORM、Schema 设计、CRUD 操作、关联查询与分页。但这些知识还是分散的——你在路由里直接调用 `prisma.user.findMany()`，在控制器里写业务逻辑，错误处理也散落各处。这节课要把它们整合成一个企业级的博客数据层：用 Repository 模式封装数据访问，用 Service 层处理业务逻辑，用统一的错误处理保证 API 的健壮性。做完这个项目，你的代码结构就和真实生产项目一致了。

### 1.3 为什么要分层

```
不分层的问题：
──────────────────────────────────────────────────────────────
// ❌ 所有逻辑都写在路由里
router.get('/posts', async (req, res) => {
  // 1. 参数解析
  const { page, pageSize, status } = req.query;

  // 2. 数据库查询
  const posts = await prisma.post.findMany({
    where: { status },
    skip: (page - 1) * pageSize,
    take: pageSize,
    include: { author: true }
  });

  // 3. 业务逻辑（比如：过滤敏感内容）
  const filtered = posts.filter(post => !post.content.includes('敏感词'));

  // 4. 数据转换
  const result = filtered.map(post => ({
    ...post,
    authorName: post.author.username
  }));

  res.json(result);
});

问题：
- 路由文件变得臃肿（几千行）
- 业务逻辑无法复用
- 难以进行单元测试
- 数据库查询散落各处
──────────────────────────────────────────────────────────────

分层后的优势：
──────────────────────────────────────────────────────────────
// ✅ 职责清晰的分层架构
router.get('/posts', async (req, res) => {
  const result = await postService.getPostList(req.query);
  res.json(result);
});

// Service 层：处理业务逻辑
class PostService {
  async getPostList(params) {
    const posts = await this.postRepository.findMany(params);
    return this.filterSensitiveContent(posts);
  }
}

// Repository 层：处理数据访问
class PostRepository {
  async findMany(params) {
    return prisma.post.findMany({ ... });
  }
}

优势：
- 每个文件职责单一（100-200 行）
- 业务逻辑可复用
- 易于单元测试
- 数据库查询集中管理
──────────────────────────────────────────────────────────────
```

## 二、Prisma 单例封装

### 2.1 为什么需要单例

```typescript
// ❌ 错误做法：每次使用都创建新实例
import { PrismaClient } from '@prisma/client';

// 文件 A
const prisma1 = new PrismaClient();  // 创建连接池 1

// 文件 B
const prisma2 = new PrismaClient();  // 创建连接池 2

// 文件 C
const prisma3 = new PrismaClient();  // 创建连接池 3

// 问题：
// 1. 每个 PrismaClient 实例都会创建一个连接池
// 2. PostgreSQL 默认最多 100 个连接
// 3. 连接池很快就会被耗尽
// 4. 内存浪费
```

### 2.2 单例实现

```typescript
// src/prisma/client.ts

import { PrismaClient } from '@prisma/client';

// 全局变量声明（用于开发环境热重载）
declare global {
  var prisma: PrismaClient | undefined;
}

// 创建 Prisma Client 实例
const prisma = global.prisma || new PrismaClient({
  log: process.env.NODE_ENV === 'development'
    ? ['query', 'error', 'warn']
    : ['error'],
});

// 开发环境：使用全局变量避免热重载时创建多个连接
if (process.env.NODE_ENV === 'development') {
  global.prisma = prisma;
}

export default prisma;

// 导出类型供其他模块使用
export type { PrismaClient };
export { Prisma } from '@prisma/client';
```

### 2.3 开发环境热重载问题

```
没有使用全局变量的问题：

启动服务 → 创建 PrismaClient 实例 1
修改代码 → Nodemon 热重载 → 创建 PrismaClient 实例 2
修改代码 → Nodemon 热重载 → 创建 PrismaClient 实例 3
...

连接数：3+（不断增加，最终耗尽连接池）

使用全局变量后：

启动服务 → 创建 PrismaClient 实例 → 存入 global.prisma
修改代码 → Nodemon 热重载 → 检查 global.prisma 已存在 → 复用

连接数：始终只有 1 个
```

### 2.4 优雅关闭连接

```typescript
// src/prisma/client.ts（完整版）

import { PrismaClient } from '@prisma/client';

declare global {
  var prisma: PrismaClient | undefined;
}

const prisma = global.prisma || new PrismaClient({
  log: process.env.NODE_ENV === 'development'
    ? ['query', 'error', 'warn']
    : ['error'],
});

if (process.env.NODE_ENV === 'development') {
  global.prisma = prisma;
}

// 优雅关闭：进程退出时断开连接
process.on('beforeExit', async () => {
  await prisma.$disconnect();
});

process.on('SIGINT', async () => {
  await prisma.$disconnect();
  process.exit(0);
});

process.on('SIGTERM', async () => {
  await prisma.$disconnect();
  process.exit(0);
});

export default prisma;
```

```typescript
import prisma from '../prisma/client';
import { Prisma, User } from '@prisma/client';

export class UserRepository {
  // 创建用户
  async create(data: Prisma.UserCreateInput): Promise<User> {
    return prisma.user.create({ data });
  }

  // 根据 ID 查询用户
  async findById(id: number): Promise<User | null> {
    return prisma.user.findUnique({
      where: { id },
      include: {
        profile: true,
        _count: {
          select: {
            posts: true,
            comments: true
          }
        }
      }
    });
  }

  // 根据邮箱查询用户
  async findByEmail(email: string): Promise<User | null> {
    return prisma.user.findUnique({
      where: { email }
    });
  }

  // 根据用户名查询用户
  async findByUsername(username: string): Promise<User | null> {
    return prisma.user.findUnique({
      where: { username }
    });
  }

  // 查询用户列表
  async findMany(options?: {
    skip?: number;
    take?: number;
    where?: Prisma.UserWhereInput;
    orderBy?: Prisma.UserOrderByWithRelationInput;
  }): Promise<User[]> {
    return prisma.user.findMany({
      skip: options?.skip,
      take: options?.take,
      where: options?.where,
      orderBy: options?.orderBy || { createdAt: 'desc' },
      include: {
        profile: true,
        _count: {
          select: {
            posts: true,
            comments: true
          }
        }
      }
    });
  }

  // 更新用户
  async update(id: number, data: Prisma.UserUpdateInput): Promise<User> {
    return prisma.user.update({
      where: { id },
      data
    });
  }

  // 删除用户
  async delete(id: number): Promise<User> {
    return prisma.user.delete({
      where: { id }
    });
  }

  // 统计用户数
  async count(where?: Prisma.UserWhereInput): Promise<number> {
    return prisma.user.count({ where });
  }

  // 检查邮箱是否已存在
  async emailExists(email: string): Promise<boolean> {
    const user = await prisma.user.findUnique({
      where: { email },
      select: { id: true }
    });
    return !!user;
  }

  // 检查用户名是否已存在
  async usernameExists(username: string): Promise<boolean> {
    const user = await prisma.user.findUnique({
      where: { username },
      select: { id: true }
    });
    return !!user;
  }
}
```

### 4.2 PostRepository

```typescript
// src/repositories/post.repository.ts

import prisma from '../prisma/client';
import { Prisma, Post } from '@prisma/client';
import { PostQueryParams, PaginatedResult, PostStatus } from '../types';

// 文章查询的完整类型（包含关联数据）
type PostWithRelations = Post & {
  author: {
    id: number;
    username: string;
    avatar: string | null;
  };
  category: {
    id: number;
    name: string;
    slug: string;
  } | null;
  tags: {
    id: number;
    name: string;
    slug: string;
  }[];
  _count: {
    comments: number;
  };
};

export class PostRepository {
  // 创建文章
  async create(data: {
    title: string;
    content: string;
    excerpt?: string;
    status?: PostStatus;
    authorId: number;
    categoryId?: number;
    tagIds?: number[];
  }): Promise<Post> {
    return prisma.post.create({
      data: {
        title: data.title,
        content: data.content,
        excerpt: data.excerpt,
        status: data.status || 'DRAFT',
        author: {
          connect: { id: data.authorId }
        },
        category: data.categoryId
          ? { connect: { id: data.categoryId } }
          : undefined,
        tags: data.tagIds
          ? { connect: data.tagIds.map(id => ({ id })) }
          : undefined
      },
      include: {
        author: {
          select: { id: true, username: true, avatar: true }
        },
        category: true,
        tags: true
      }
    });
  }

  // 根据 ID 查询文章
  async findById(id: number): Promise<PostWithRelations | null> {
    return prisma.post.findUnique({
      where: { id },
      include: {
        author: {
          select: {
            id: true,
            username: true,
            avatar: true,
            bio: true
          }
        },
        category: true,
        tags: true,
        comments: {
          where: { parentId: null },
          include: {
            author: {
              select: { id: true, username: true, avatar: true }
            },
            replies: {
              include: {
                author: {
                  select: { id: true, username: true, avatar: true }
                }
              },
              orderBy: { createdAt: 'asc' }
            }
          },
          orderBy: { createdAt: 'desc' }
        },
        _count: {
          select: { comments: true, tags: true }
        }
      }
    }) as Promise<PostWithRelations | null>;
  }

  // 查询文章列表（带分页、排序、筛选）
  async findMany(params: PostQueryParams): Promise<PaginatedResult<PostWithRelations>> {
    const {
      page = 1,
      pageSize = 10,
      status,
      categoryId,
      authorId,
      tagId,
      keyword,
      sortBy = 'createdAt',
      sortOrder = 'desc'
    } = params;

    const skip = (page - 1) * pageSize;

    // 构建查询条件
    const where: Prisma.PostWhereInput = {};

    if (status) {
      where.status = status;
    }

    if (categoryId) {
      where.categoryId = categoryId;
    }

    if (authorId) {
      where.authorId = authorId;
    }

    if (tagId) {
      where.tags = {
        some: { id: tagId }
      };
    }

    if (keyword) {
      where.OR = [
        { title: { contains: keyword, mode: 'insensitive' } },
        { content: { contains: keyword, mode: 'insensitive' } }
      ];
    }

    // 构建排序条件
    const allowedSortFields = ['createdAt', 'updatedAt', 'viewCount', 'title'];
    const orderBy: Prisma.PostOrderByWithRelationInput = {};
    if (allowedSortFields.includes(sortBy)) {
      (orderBy as any)[sortBy] = sortOrder;
    }

    // 并行执行查询和计数
    const [posts, total] = await Promise.all([
      prisma.post.findMany({
        where,
        orderBy,
        skip,
        take: pageSize,
        include: {
          author: {
            select: { id: true, username: true, avatar: true }
          },
          category: {
            select: { id: true, name: true, slug: true }
          },
          tags: {
            select: { id: true, name: true, slug: true }
          },
          _count: {
            select: { comments: true }
          }
        }
      }),
      prisma.post.count({ where })
    ]);

    const totalPages = Math.ceil(total / pageSize);

    return {
      data: posts as PostWithRelations[],
      meta: {
        total,
        page,
        pageSize,
        totalPages,
        hasNext: page < totalPages,
        hasPrev: page > 1
      }
    };
  }

  // 更新文章
  async update(id: number, data: {
    title?: string;
    content?: string;
    excerpt?: string;
    status?: PostStatus;
    categoryId?: number | null;
    tagIds?: number[];
  }): Promise<Post> {
    const updateData: Prisma.PostUpdateInput = {};

    if (data.title !== undefined) updateData.title = data.title;
    if (data.content !== undefined) updateData.content = data.content;
    if (data.excerpt !== undefined) updateData.excerpt = data.excerpt;
    if (data.status !== undefined) updateData.status = data.status;

    if (data.categoryId !== undefined) {
      updateData.category = data.categoryId
        ? { connect: { id: data.categoryId } }
        : { disconnect: true };
    }

    if (data.tagIds !== undefined) {
      updateData.tags = {
        set: data.tagIds.map(id => ({ id }))
      };
    }

    return prisma.post.update({
      where: { id },
      data: updateData,
      include: {
        author: { select: { id: true, username: true } },
        category: true,
        tags: true
      }
    });
  }

  // 删除文章
  async delete(id: number): Promise<Post> {
    return prisma.post.delete({
      where: { id }
    });
  }

  // 增加阅读量
  async incrementViewCount(id: number): Promise<void> {
    await prisma.post.update({
      where: { id },
      data: { viewCount: { increment: 1 } }
    });
  }

  // 按状态统计文章数
  async countByStatus(authorId?: number): Promise<Record<string, number>> {
    const result = await prisma.post.groupBy({
      by: ['status'],
      _count: true,
      where: authorId ? { authorId } : undefined
    });

    return result.reduce((acc, item) => {
      acc[item.status] = item._count;
      return acc;
    }, {} as Record<string, number>);
  }

  // 获取热门文章（按阅读量排序）
  async findPopular(take: number = 10): Promise<PostWithRelations[]> {
    return prisma.post.findMany({
      where: { status: 'PUBLISHED' },
      orderBy: { viewCount: 'desc' },
      take,
      include: {
        author: {
          select: { id: true, username: true, avatar: true }
        },
        category: {
          select: { id: true, name: true }
        },
        _count: {
          select: { comments: true }
        }
      }
    }) as Promise<PostWithRelations[]>;
  }

  // 获取最新文章
  async findLatest(take: number = 10): Promise<PostWithRelations[]> {
    return prisma.post.findMany({
      where: { status: 'PUBLISHED' },
      orderBy: { createdAt: 'desc' },
      take,
      include: {
        author: {
          select: { id: true, username: true, avatar: true }
        },
        category: {
          select: { id: true, name: true }
        },
        tags: {
          select: { id: true, name: true }
        },
        _count: {
          select: { comments: true }
        }
      }
    }) as Promise<PostWithRelations[]>;
  }
}

export const postRepository = new PostRepository();
```

```typescript
// src/repositories/category.repository.ts

import prisma from '../prisma/client';
import { Prisma, Category } from '@prisma/client';

type CategoryWithCount = Category & {
  _count: {
    posts: number;
  };
};

export class CategoryRepository {
  // 创建分类
  async create(data: { name: string; slug: string; description?: string }): Promise<Category> {
    return prisma.category.create({ data });
  }

  // 根据 ID 查询分类
  async findById(id: number): Promise<Category | null> {
    return prisma.category.findUnique({
      where: { id }
    });
  }

  // 根据 slug 查询分类
  async findBySlug(slug: string): Promise<Category | null> {
    return prisma.category.findUnique({
      where: { slug }
    });
  }

  // 查询所有分类（带文章数统计）
  async findAll(): Promise<CategoryWithCount[]> {
    return prisma.category.findMany({
      include: {
        _count: {
          select: { posts: true }
        }
      },
      orderBy: { name: 'asc' }
    });
  }

  // 更新分类
  async update(id: number, data: {
    name?: string;
    slug?: string;
    description?: string;
  }): Promise<Category> {
    return prisma.category.update({
      where: { id },
      data
    });
  }

  // 删除分类
  async delete(id: number): Promise<Category> {
    return prisma.category.delete({
      where: { id }
    });
  }

  // 检查 slug 是否已存在
  async slugExists(slug: string, excludeId?: number): Promise<boolean> {
    const category = await prisma.category.findUnique({
      where: { slug },
      select: { id: true }
    });

    if (!category) return false;
    if (excludeId && category.id === excludeId) return false;

    return true;
  }

  // 获取分类及其文章数统计
  async getStats(): Promise<{
    id: number;
    name: string;
    slug: string;
    postCount: number;
    publishedCount: number;
  }[]> {
    const categories = await prisma.category.findMany({
      include: {
        _count: {
          select: {
            posts: true
          }

    });
  }
```

```typescript
  async delete(id: number): Promise<Tag> {
    return prisma.tag.delete({
      where: { id }
    });
  }

  // 检查标签名是否已存在
  async nameExists(name: string, excludeId?: number): Promise<boolean> {
    const tag = await prisma.tag.findUnique({
      where: { name },
      select: { id: true }
    });

    if (!tag) return false;
    if (excludeId && tag.id === excludeId) return false;

    return true;
  }

  // 批量查找或创建标签
  async findOrCreateMany(names: string[]): Promise<Tag[]> {
    const tags = await Promise.all(
      names.map(async (name) => {
        const slug = name.toLowerCase().replace(/\s+/g, '-');
        return prisma.tag.upsert({

          create: { name, slug }
        });
      })

  // 获取标签云数据
  async getTagCloud(): Promise<{

    weight: number; // 权重，用于标签云显示

    const range = maxCount - minCount || 1;

    return tags.map(tag => ({
      id: tag.id,
      name: tag.name,
      slug: tag.slug,
      count: tag._count.posts,
      weight: Math.ceil(((tag._count.posts - minCount) / range) * 9) + 1
    }));
  }
}
```

```typescript
import { postRepository, PostRepository } from '../repositories/post.repository';

  PostQueryParams,

    // 1. 验证作者是否存在
    const author = await this.userRepo.findById(authorId);
    if (!author) {

    // 3. 自动生成摘要（如果未提供）

      content: dto.content,
      excerpt,
      status: dto.status,
      authorId,
      categoryId: dto.categoryId,
      tagIds: dto.tagIds
    });

    return post;
  }

  // 获取文章详情
  async getPostById(id: number, incrementView: boolean = true): Promise<Post | null> {
    const post = await this.postRepo.findById(id);

    if (!post) {
      return null;
    }

    // 增加阅读量
    if (incrementView) {
      await this.postRepo.incrementViewCount(id);
    }

    return post;
  }

  // 获取文章列表
  async getPostList(params: PostQueryParams): Promise<PaginatedResult<Post>> {
    return this.postRepo.findMany(params);
  }

  // 更新文章
  async updatePost(
    id: number,
    userId: number,
    dto: UpdatePostDto
  ): Promise<Post> {
    // 1. 验证文章是否存在
    const post = await this.postRepo.findById(id);
    if (!post) {
      throw new Error('文章不存在');
    }

    // 2. 验证权限（只有作者或管理员可以更新）
    if (post.authorId !== userId) {
      // 这里可以检查用户是否是管理员
      throw new Error('没有权限更新此文章');
    }

    // 3. 更新文章
    return this.postRepo.update(id, dto);
  }

  // 删除文章
  async deletePost(id: number, userId: number): Promise<void> {
    const post = await this.postRepo.findById(id);
    if (!post) {
      throw new Error('文章不存在');
    }

    if (post.authorId !== userId) {
      throw new Error('没有权限删除此文章');
    }

    await this.postRepo.delete(id);
  }

  // 发布文章
  async publishPost(id: number, userId: number): Promise<Post> {
    const post = await this.postRepo.findById(id);
    if (!post) {
      throw new Error('文章不存在');
    }

    if (post.authorId !== userId) {
      throw new Error('没有权限发布此文章');
    }

    return this.postRepo.update(id, { status: PostStatus.PUBLISHED });
  }

  private generateExcerpt(content: string, maxLength: number = 200): string {
    // 移除 Markdown 标记
    const plainText = content
      .replace(/#{1,6}\s/g, '')
      .replace(/\*\*(.*?)\*\*/g, '$1')
      .replace(/\*(.*?)\*/g, '$1')
      .replace(/\[(.*?)\]\(.*?\)/g, '$1')
      .replace(/`(.*?)`/g, '$1')
      .replace(/```[\s\S]*?```/g, '')
      .trim();

    // 截取指定长度
    if (plainText.length <= maxLength) {
      return plainText;
    }

    return plainText.substring(0, maxLength) + '...';
  }
}
```

```typescript
export class CommentService {
  constructor(
    private commentRepo: CommentRepository = commentRepository,
    private postRepo: PostRepository = postRepository
  ) {}

  // 创建评论
  async createComment(
    authorId: number,
    dto: CreateCommentDto
  ): Promise<Comment> {
    // 1. 验证文章是否存在
    const post = await this.postRepo.findById(dto.postId);
    if (!post) {
      throw new Error('文章不存在');
    }

    // 2. 验证文章是否允许评论（比如已发布的文章才能评论）
    if (post.status !== 'PUBLISHED') {
      throw new Error('只能评论已发布的文章');
    }

    // 3. 如果是回复评论，验证父评论是否存在
    if (dto.parentId) {
      const parentComment = await this.commentRepo.findById(dto.parentId);
      if (!parentComment) {
        throw new Error('父评论不存在');
      }
      if (parentComment.postId !== dto.postId) {
        throw new Error('父评论不属于该文章');
      }
    }

    // 4. 验证评论内容
    if (!dto.content || dto.content.trim().length === 0) {
      throw new Error('评论内容不能为空');
    }

    if (dto.content.length > 1000) {
      throw new Error('评论内容不能超过 1000 字');
    }

    // 5. 创建评论
    return this.commentRepo.create({
      content: dto.content.trim(),
      postId: dto.postId,
      parentId: dto.parentId,
      authorId
    });
```

### 7.1 常见错误类型

```typescript
// src/utils/prisma-errors.ts

import { Prisma } from '@prisma/client';

// Prisma 错误码
export enum PrismaErrorCode {
  // 唯一约束冲突
  UNIQUE_CONSTRAINT_VIOLATION = 'P2002',
  // 记录不存在
  RECORD_NOT_FOUND = 'P2025',
  // 外键约束失败
  FOREIGN_KEY_CONSTRAINT = 'P2003',
  // 必需字段缺失
  REQUIRED_FIELD_MISSING = 'P2012',
  // 关联记录不存在
  RELATED_RECORD_NOT_FOUND = 'P2018',
}

// 自定义错误类
export class AppError extends Error {
  constructor(
    message: string,
    public statusCode: number = 400,
    public code?: string
  ) {
    super(message);
    this.name = 'AppError';
  }
}

// 处理 Prisma 错误
export function handlePrismaError(error: unknown): never {
  // 如果是 Prisma 已知错误
  if (error instanceof Prisma.PrismaClientKnownRequestError) {
    switch (error.code) {
      case PrismaErrorCode.UNIQUE_CONSTRAINT_VIOLATION:
        const field = (error.meta?.target as string[])?.[0] || '字段';
        throw new AppError(
          `${field} 已存在，请使用其他值`,
          409,  // Conflict
          'UNIQUE_CONSTRAINT_VIOLATION'
        );

      case PrismaErrorCode.RECORD_NOT_FOUND:
        throw new AppError(
          '记录不存在',
          404,
          'RECORD_NOT_FOUND'
        );

      case PrismaErrorCode.FOREIGN_KEY_CONSTRAINT:
        const foreignField = error.meta?.field_name || '关联字段';
        throw new AppError(
          `关联的${foreignField}不存在`,
          400,
          'FOREIGN_KEY_CONSTRAINT'
        );

      case PrismaErrorCode.REQUIRED_FIELD_MISSING:
        const missingField = error.meta?.argument_name || '字段';
        throw new AppError(
          `缺少必需的${missingField}`,
          400,
          'REQUIRED_FIELD_MISSING'
        );

      case PrismaErrorCode.RELATED_RECORD_NOT_FOUND:
        throw new AppError(
          '关联的记录不存在',
          400,
          'RELATED_RECORD_NOT_FOUND'
        );

      default:
        throw new AppError(
          `数据库错误: ${error.message}`,
          500,
          'DATABASE_ERROR'
        );
    }
  }

  // 如果是 Prisma 验证错误
  if (error instanceof Prisma.PrismaClientValidationError) {
    throw new AppError(
      '数据验证失败',
      400,
      'VALIDATION_ERROR'
    );
  }

  // 如果是 Prisma 初始化错误
  if (error instanceof Prisma.PrismaClientInitializationError) {
    throw new AppError(
      '数据库连接失败',
      500,
      'DATABASE_CONNECTION_ERROR'
    );
  }

  // 如果已经是 AppError，直接抛出
  if (error instanceof AppError) {
    throw error;
  }

  // 其他未知错误
  throw new AppError(
    '服务器内部错误',
    500,
    'INTERNAL_ERROR'
  );
}
```

## 常见误区

1. **在 Repository 层包含业务逻辑**：Repository 只负责数据访问（CRUD、查询、分页），不应该包含权限检查、数据验证、缓存策略等业务逻辑。这些属于 Service 层。
2. **在路由层直接操作 Prisma**：路由函数应该调用 Service 层方法，而不是直接调用 `prisma.post.findMany()`。直接操作 Prisma 会让路由变得臃肿，且业务逻辑无法复用。
3. **不处理 Prisma 的特定错误类型**：`PrismaClientKnownRequestError` 有特定的错误码（如 P2002 唯一约束冲突），不处理这些错误会返回模糊的"服务器错误"，前端无法给出有意义的提示。
4. **Service 层和 Repository 层没有明确边界**：如果 Service 层直接写 SQL 或 Prisma 查询，就失去了分层的意义。Service 通过调用 Repository 的方法来操作数据。

## 工程建议

1. **Repository 层封装所有数据库查询**：每个资源一个 Repository，包含 CRUD、分页、聚合等方法。如果将来换 ORM（如从 Prisma 换到 Drizzle），只需要改 Repository 层。
2. **Service 层处理业务规则和权限验证**：创建文章前验证作者是否存在、删除评论前检查权限、生成文章摘要——这些都是业务逻辑，放在 Service 层。
3. **用依赖注入降低耦合度**：Service 的构造函数接收 Repository 实例，而不是直接 import。这样在测试时可以注入 Mock Repository，无需连接真实数据库。
4. **统一 Prisma 错误处理**：创建 `handlePrismaError` 函数，将 Prisma 的错误码（P2002、P2025 等）转换为用户友好的错误消息和 HTTP 状态码。

### 最佳实践总结

```typescript
// 1. 使用单例模式
import prisma from './prisma/client';

// 2. Repository 封装数据访问
class UserRepository {
  async findById(id: number) {
    return prisma.user.findUnique({ where: { id } });
  }
}

// 3. Service 封装业务逻辑
class UserService {
  async getUser(id: number) {
    const user = await this.userRepo.findById(id);
    if (!user) throw new Error('用户不存在');
    return user;
  }
}

// 4. 统一错误处理
try {
  const user = await userService.getUser(1);
} catch (error) {
  handlePrismaError(error);
}

// 5. 使用 include 避免 N+1 问题
const posts = await prisma.post.findMany({
  include: { author: true, tags: true }
});
```
