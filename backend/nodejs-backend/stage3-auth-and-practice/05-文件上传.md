# 第五课：文件上传

## 场景引入

你的博客平台需要支持用户上传头像和文章封面图。表面上看，文件上传只是"把文件存到服务器"，但实际开发中会遇到一连串问题：用户上传了一个 50MB 的视频文件怎么办？有人上传了 `.exe` 可执行文件怎么处理？中文文件名导致 URL 编码乱码怎么解决？多个用户都上传了 `avatar.jpg` 会不会互相覆盖？上传的图片尺寸不统一，列表页加载缓慢怎么办？文件上传是后端开发中看似简单实则坑很多的功能，需要从存储策略、文件过滤、命名规则、图片处理等多个维度综合考虑。

## 学习目标

完成本课学习后，你将能够：

1. 理解文件上传的原理（multipart/form-data）
2. 使用 Multer 处理文件上传
3. 实现文件过滤（类型、大小限制）
4. 掌握文件命名策略和存储方案
5. 使用 sharp 进行图片处理（裁剪、压缩、缩略图）
6. 实现用户头像上传和文章封面图上传

## 一、文件上传的原理

### 1.1 为什么不能用 JSON 传文件

```
JSON 格式只能传文本数据：

  {
    "title": "我的文章",
    "content": "文章内容...",
    "image": "???"  // 文件怎么放进去？
  }

文件是二进制数据（图片、PDF、视频等）
JSON 无法直接携带二进制数据
```

### 1.2 multipart/form-data 格式

```
文件上传使用 multipart/form-data 格式：

  POST /api/upload HTTP/1.1
  Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

  ------WebKitFormBoundary7MA4YWxkTrZu0gW
  Content-Disposition: form-data; name="title"

  我的文章标题
  ------WebKitFormBoundary7MA4YWxkTrZu0gW
  Content-Disposition: form-data; name="image"; filename="photo.jpg"
  Content-Type: image/jpeg

  (二进制图片数据...)
  ------WebKitFormBoundary7MA4YWxkTrZu0gW--

特点：
  - 用 boundary 分隔不同的字段
  - 每个字段可以是文本或文件
  - 文件字段包含 filename 和 Content-Type
  - 可以同时上传多个文件
```

### 1.3 前端如何发送文件

```html
<!-- HTML 表单 -->
<form action="/api/upload" method="POST" enctype="multipart/form-data">
  <input type="text" name="title" placeholder="文章标题" />
  <input type="file" name="image" accept="image/*" />
  <button type="submit">上传</button>
</form>
```

```typescript
// 使用 FormData（JavaScript）
const formData = new FormData()
formData.append('title', '我的文章标题')
formData.append('image', fileInput.files[0])  // fileInput 是 <input type="file">

fetch('/api/upload', {
  method: 'POST',
  body: formData
  // 注意：不要手动设置 Content-Type
  // 浏览器会自动设置为 multipart/form-data 并添加 boundary
})

// 使用 Axios
const formData = new FormData()
formData.append('image', file)

axios.post('/api/upload', formData, {
  headers: {
    'Content-Type': 'multipart/form-data'
  }
})
```

## 二、Multer 中间件详解

### 2.1 安装

```bash
npm install multer
```

### 2.2 基本用法

```typescript
// src/middleware/upload.ts
import multer from 'multer'
import path from 'path'
import crypto from 'crypto'

// ==================== 存储策略 ====================

// 磁盘存储
const diskStorage = multer.diskStorage({
  // 设置存储目录
  destination: (req, file, cb) => {
    cb(null, 'uploads/')
  },

  // 设置文件名
  filename: (req, file, cb) => {
    // 生成唯一文件名：时间戳 + 随机字符串 + 扩展名
    const uniqueSuffix = Date.now() + '-' + crypto.randomBytes(8).toString('hex')
    const ext = path.extname(file.originalname)
    cb(null, uniqueSuffix + ext)
  }
})

// 内存存储（适合后续处理，如上传到云存储）
const memoryStorage = multer.memoryStorage()

// ==================== 文件过滤 ====================

const imageFilter = (req: any, file: Express.Multer.File, cb: multer.FileFilterCallback) => {
  // 允许的图片类型
  const allowedMimes = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']

  if (allowedMimes.includes(file.mimetype)) {
    cb(null, true)
  } else {
    cb(new Error('只允许上传 JPG、PNG、GIF、WebP 格式的图片'))
  }
}

// ==================== Multer 实例 ====================

// 图片上传配置（磁盘存储）
export const uploadImage = multer({
  storage: diskStorage,
  fileFilter: imageFilter,
  limits: {
    fileSize: 5 * 1024 * 1024  // 5MB
  }
})

// 图片上传配置（内存存储，用于后续处理）
export const uploadImageToMemory = multer({
  storage: memoryStorage,
  fileFilter: imageFilter,
  limits: {
    fileSize: 5 * 1024 * 1024  // 5MB
  }
})
```

## 三、文件命名策略

### 3.1 为什么不能用原始文件名

```
原始文件名的问题：

  1. 中文文件名：照片.jpg → URL 编码问题
  2. 特殊字符：my photo (1).jpg → 路径解析问题
  3. 文件名冲突：多个用户都上传 avatar.jpg → 覆盖问题
  4. 安全风险：../../../etc/passwd → 路径遍历攻击
```

### 3.2 推荐的命名策略

```typescript
import crypto from 'crypto'
import path from 'path'

/**
 * 生成安全的文件名
 * 格式：{日期}-{随机字符串}.{扩展名}
 */
function generateSafeFilename(originalname: string): string {
  // 获取原始扩展名
  const ext = path.extname(originalname).toLowerCase()

  // 生成唯一标识
  const timestamp = Date.now()
  const random = crypto.randomBytes(8).toString('hex')

  return `${timestamp}-${random}${ext}`
}

// 示例：
// "我的照片.jpg"     → "1716000000-a1b2c3d4e5f6.jpg"
// "avatar (1).png"  → "1716000001-b2c3d4e5f6a7.png"
// "resume.pdf"      → "1716000002-c3d4e5f6a7b8.pdf"
```

### 3.3 按日期分目录存储

```typescript
import path from 'path'
import fs from 'fs'

/**
 * 获取按日期分目录的存储路径
 * 格式：uploads/2024/05/18/xxx.jpg
 */
function getUploadPath(): string {
  const now = new Date()
  const year = now.getFullYear().toString()
  const month = (now.getMonth() + 1).toString().padStart(2, '0')
  const day = now.getDate().toString().padStart(2, '0')

  const uploadDir = path.join('uploads', year, month, day)

  // 确保目录存在
  fs.mkdirSync(uploadDir, { recursive: true })

  return uploadDir
}
```

## 四、错误处理

### 4.1 Multer 错误类型

```typescript
import multer from 'multer'
import { Request, Response, NextFunction } from 'express'

/**
 * Multer 错误处理中间件
 */
export function multerErrorHandler(err: any, req: Request, res: Response, next: NextFunction) {
  if (err instanceof multer.MulterError) {
    switch (err.code) {
      case 'LIMIT_FILE_SIZE':
        return res.status(400).json({
          success: false,
          message: '文件大小超过限制（最大 5MB）'
        })
      case 'LIMIT_FILE_COUNT':
        return res.status(400).json({
          success: false,
          message: '上传文件数量超过限制'
        })
      case 'LIMIT_UNEXPECTED_FILE':
        return res.status(400).json({
          success: false,
          message: '不支持的文件字段'
        })
      default:
        return res.status(400).json({
          success: false,
          message: `文件上传错误: ${err.code}`
        })
    }
  }

  // 自定义错误（如文件类型不支持）
  if (err.message && err.message.includes('只允许上传')) {
    return res.status(400).json({
      success: false,
      message: err.message
    })
  }

  next(err)
}
```

### 6.2 基本用法

```typescript
import sharp from 'sharp'
import path from 'path'

/**
 * 处理头像：裁剪为正方形 + 压缩 + 生成缩略图
 */
async function processAvatar(inputPath: string, outputDir: string) {
  const filename = path.basename(inputPath, path.extname(inputPath))

  // 1. 处理原图：裁剪为 400x400 正方形，压缩为 WebP
  const processedPath = path.join(outputDir, `${filename}-400.webp`)
  await sharp(inputPath)
    .resize(400, 400, {
      fit: 'cover',        // 裁剪模式：覆盖整个区域
      position: 'center'   // 从中心裁剪
    })
    .webp({ quality: 80 }) // 转换为 WebP 格式，质量 80%
    .toFile(processedPath)

  // 2. 生成缩略图：100x100
  const thumbnailPath = path.join(outputDir, `${filename}-100.webp`)
  await sharp(inputPath)
    .resize(100, 100, {
      fit: 'cover',
      position: 'center'
    })
    .webp({ quality: 70 })
    .toFile(thumbnailPath)

  return {
    original: processedPath,
    thumbnail: thumbnailPath
  }
}

/**
 * 处理文章封面图：保持比例，限制最大宽度
 */
async function processCoverImage(inputPath: string, outputDir: string) {
  const filename = path.basename(inputPath, path.extname(inputPath))

  // 处理封面图：最大宽度 1200px，保持比例
  const processedPath = path.join(outputDir, `${filename}-1200.webp`)
  await sharp(inputPath)
    .resize(1200, null, {
      fit: 'inside',       // 保持比例，不超过指定尺寸
      withoutEnlargement: true  // 不放大小图
    })
    .webp({ quality: 80 })
    .toFile(processedPath)

  // 生成缩略图：400px 宽
  const thumbnailPath = path.join(outputDir, `${filename}-400.webp`)
  await sharp(inputPath)
    .resize(400, null, {
      fit: 'inside',
      withoutEnlargement: true
    })
    .webp({ quality: 70 })
    .toFile(thumbnailPath)

  return {
    original: processedPath,
    thumbnail: thumbnailPath
  }
}
```

### 6.3 使用内存存储 + sharp 处理

```typescript
// src/services/upload.service.ts
import sharp from 'sharp'
import path from 'path'
import fs from 'fs/promises'
import crypto from 'crypto'

export class UploadService {
  private uploadDir: string

  constructor(uploadDir: string = 'uploads') {
    this.uploadDir = uploadDir
  }

  /**
   * 处理并保存头像
   */
  async processAndSaveAvatar(file: Express.Multer.File): Promise<{
    avatar: string
    avatarThumbnail: string
  }> {
    // 生成唯一文件名
    const uniqueId = crypto.randomBytes(8).toString('hex')

    // 确保上传目录存在
    const avatarDir = path.join(this.uploadDir, 'avatars')
    await fs.mkdir(avatarDir, { recursive: true })

    // 处理原图（400x400 WebP）
    const avatarFilename = `${uniqueId}-400.webp`
    const avatarPath = path.join(avatarDir, avatarFilename)

    await sharp(file.buffer)
      .resize(400, 400, {
        fit: 'cover',
        position: 'center'
      })
      .webp({ quality: 80 })
      .toFile(avatarPath)

    // 生成缩略图（100x100 WebP）
    const thumbnailFilename = `${uniqueId}-100.webp`
    const thumbnailPath = path.join(avatarDir, thumbnailFilename)

    await sharp(file.buffer)
      .resize(100, 100, {
        fit: 'cover',
        position: 'center'
      })
      .webp({ quality: 70 })
      .toFile(thumbnailPath)

    return {
      avatar: `/uploads/avatars/${avatarFilename}`,
      avatarThumbnail: `/uploads/avatars/${thumbnailFilename}`
    }
  }

  /**
   * 处理并保存文章封面图
   */
  async processAndSaveCover(file: Express.Multer.File): Promise<{
    cover: string
    coverThumbnail: string
  }> {
    const uniqueId = crypto.randomBytes(8).toString('hex')

    const coverDir = path.join(this.uploadDir, 'covers')
    await fs.mkdir(coverDir, { recursive: true })

    // 处理封面图（最大 1200px 宽）
    const coverFilename = `${uniqueId}-1200.webp`
    const coverPath = path.join(coverDir, coverFilename)

    await sharp(file.buffer)
      .resize(1200, null, {
        fit: 'inside',
        withoutEnlargement: true
      })
      .webp({ quality: 80 })
      .toFile(coverPath)

    // 生成缩略图（400px 宽）
    const thumbnailFilename = `${uniqueId}-400.webp`
    const thumbnailPath = path.join(coverDir, thumbnailFilename)

    await sharp(file.buffer)
      .resize(400, null, {
        fit: 'inside',
        withoutEnlargement: true
      })
      .webp({ quality: 70 })
      .toFile(thumbnailPath)

    return {
      cover: `/uploads/covers/${coverFilename}`,
      coverThumbnail: `/uploads/covers/${thumbnailFilename}`
    }
  }

  /**
   * 删除文件
   */
  async deleteFile(fileUrl: string): Promise<void> {
    try {
      const filePath = path.join(process.cwd(), fileUrl)
      await fs.unlink(filePath)
    } catch {
      // 文件不存在或删除失败，忽略
    }
  }
}

export const uploadService = new UploadService()
```

## 七、完整的头像上传实现

### 7.1 上传控制器

```typescript
// src/controllers/upload.controller.ts
import { Request, Response, NextFunction } from 'express'
import { uploadService } from '../services/upload.service'
import { prisma } from '../config/database'
import { sendSuccess } from '../utils/response'
import { NotFoundError } from '../utils/errors'

export class UploadController {
  /**
   * POST /api/upload/avatar
   * 上传用户头像
   */
  async uploadAvatar(req: Request, res: Response, next: NextFunction) {
    try {
      if (!req.file) {
        return res.status(400).json({
          success: false,
          message: '请选择要上传的图片'
        })
      }

      const userId = req.user!.userId

      // 处理并保存图片
      const { avatar, avatarThumbnail } = await uploadService.processAndSaveAvatar(req.file)

      // 删除旧头像
      const oldUser = await prisma.user.findUnique({
        where: { id: userId },
        select: { avatar: true }
      })

      if (oldUser?.avatar) {
        await uploadService.deleteFile(oldUser.avatar)
      }

      // 更新用户头像
      const user = await prisma.user.update({
        where: { id: userId },
        data: { avatar, avatarThumbnail },
        select: {
          id: true,
          username: true,
          avatar: true,
          avatarThumbnail: true
        }
      })

      return sendSuccess(res, { user }, '头像上传成功')
    } catch (error) {
      next(error)
    }
  }

  /**
   * POST /api/upload/cover/:articleId
   * 上传文章封面图
   */
  async uploadCover(req: Request, res: Response, next: NextFunction) {
    try {
      if (!req.file) {
        return res.status(400).json({
          success: false,
          message: '请选择要上传的图片'
        })
      }

      const articleId = parseInt(req.params.articleId)

      // 检查文章是否存在
      const article = await prisma.article.findUnique({
        where: { id: articleId }
      })

      if (!article) {
        throw new NotFoundError('文章不存在')
      }

      // 处理并保存封面图
      const { cover, coverThumbnail } = await uploadService.processAndSaveCover(req.file)

      // 删除旧封面
      if (article.coverImage) {
        await uploadService.deleteFile(article.coverImage)
      }

      // 更新文章封面
      const updatedArticle = await prisma.article.update({
        where: { id: articleId },
        data: { coverImage: cover, coverThumbnail },
        select: {
          id: true,
          title: true,
          coverImage: true,
          coverThumbnail: true
        }
      })

      return sendSuccess(res, { article: updatedArticle }, '封面图上传成功')
    } catch (error) {
      next(error)
    }
  }
}

export const uploadController = new UploadController()
```

```typescript
import { useState, useRef } from 'react'

function AvatarUpload({ currentAvatar, onUpload }: {

  const [uploading, setUploading] = useState(false)
  const fileInputRef = useRef<HTMLInputElement>(null)

  const handleFileSelect = (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0]
    if (!file) return

    // 验证文件类型
    if (!file.type.startsWith('image/')) {
      alert('请选择图片文件')
      return
    }

    // 验证文件大小（5MB）
    if (file.size > 5 * 1024 * 1024) {
      alert('文件大小不能超过 5MB')
      return
    }

    // 生成预览
    const reader = new FileReader()
    reader.onload = (e) => setPreview(e.target?.result as string)
    reader.readAsDataURL(file)
  }

  const handleUpload = async () => {
    const file = fileInputRef.current?.files?.[0]
    if (!file) return

    setUploading(true)

    try {
      const formData = new FormData()
      formData.append('avatar', file)

      const response = await fetch('/api/upload/avatar', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${localStorage.getItem('accessToken')}`
        },
        body: formData
      })

      if (!response.ok) {
        throw new Error('上传失败')
      }

      const data = await response.json()
      onUpload(data.data.user.avatar)
      setPreview(null)
    } catch (error) {
      alert('上传失败，请重试')
    } finally {
      setUploading(false)
    }
  }

  return (
    <div className="avatar-upload">
      <div className="avatar-preview">
        <img
          src={preview || currentAvatar || '/default-avatar.png'}
          alt="头像"
        />
      </div>

      <input
        ref={fileInputRef}
        type="file"
        accept="image/*"
        onChange={handleFileSelect}
        style={{ display: 'none' }}
      />

      <button onClick={() => fileInputRef.current?.click()}>
        选择图片
      </button>

      {preview && (
        <button onClick={handleUpload} disabled={uploading}>
          {uploading ? '上传中...' : '确认上传'}
        </button>
      )}
    </div>
  )
}
```

### 练习 1：实现单图片上传

**思路**：使用 Multer 的 `memoryStorage()` 将文件存入内存缓冲区，配合 `fileFilter` 限制图片类型和 `limits` 限制文件大小，再用 sharp 处理图片（压缩、转 WebP 格式），最后写入磁盘并返回 URL。

```typescript
        withoutEnlargement: true

      .webp({ quality: 80 })
      .toFile(filePath)

    return { url: `/uploads/images/${filename}` }
  }

      const filePath = path.join(process.cwd(), fileUrl)
      await fs.unlink(filePath)
    } catch {
      // 文件不存在时忽略
    }
  }
}
```

### 练习 3：实现文件类型白名单

**思路**：通过文件扩展名和 MIME 类型双重校验来实现可配置的文件过滤器。利用 `path.extname` 提取扩展名，与白名单比对，同时校验 MIME 类型防止绕过。

**答案**：
```typescript
import { Request } from 'express'
import { FileFilterCallback } from 'multer'
import path from 'path'

// 文件类型白名单配置
const FILE_TYPE_WHITELIST: Record<string, {
  extensions: string[]
  mimeTypes: string[]
}> = {
  image: {
    extensions: ['.jpg', '.jpeg', '.png', '.gif', '.webp'],
    mimeTypes: ['image/jpeg', 'image/png', 'image/gif', 'image/webp']
  },
  document: {
    extensions: ['.pdf', '.doc', '.docx'],
    mimeTypes: [
      'application/pdf',
      'application/msword',
      'application/vnd.openxmlformats-officedocument.wordprocessingml.document'
    ]
  },
  archive: {
    extensions: ['.zip', '.rar'],
    mimeTypes: ['application/zip', 'application/x-rar-compressed', 'application/vnd.rar']
  }
}

/**
 * 创建可配置的文件过滤器
 * @param allowedTypes 允许的文件类型类别，如 ['image', 'document', 'archive']
 * @returns Multer fileFilter 函数
 */
function createFileFilter(allowedTypes: string[]) {
  // 收集所有允许的扩展名和 MIME 类型
  const allowedExtensions: string[] = []
  const allowedMimeTypes: string[] = []

  for (const type of allowedTypes) {
    const config = FILE_TYPE_WHITELIST[type]
    if (!config) {
      throw new Error(`未知的文件类型类别: ${type}，可选值: ${Object.keys(FILE_TYPE_WHITELIST).join(', ')}`)
    }
    allowedExtensions.push(...config.extensions)
    allowedMimeTypes.push(...config.mimeTypes)
  }

  return (req: Request, file: Express.Multer.File, cb: FileFilterCallback) => {
    const ext = path.extname(file.originalname).toLowerCase()
    const isExtAllowed = allowedExtensions.includes(ext)
    const isMimeAllowed = allowedMimeTypes.includes(file.mimetype)

    if (isExtAllowed && isMimeAllowed) {
      cb(null, true)
    } else {
      cb(new Error(
        `不支持的文件类型。扩展名: ${ext}, MIME: ${file.mimetype}。允许的类型: ${allowedExtensions.join(', ')}`
      ))
    }
  }
}

// 使用示例
import multer from 'multer'

// 只允许图片
const imageUpload = multer({
  storage: multer.memoryStorage(),
  fileFilter: createFileFilter(['image']),
  limits: { fileSize: 5 * 1024 * 1024 }
})

// 允许图片和文档
const mixedUpload = multer({
  storage: multer.memoryStorage(),
  fileFilter: createFileFilter(['image', 'document']),
  limits: { fileSize: 10 * 1024 * 1024 }
})

// 允许所有类型
const allUpload = multer({
  storage: multer.memoryStorage(),
  fileFilter: createFileFilter(['image', 'document', 'archive']),
  limits: { fileSize: 20 * 1024 * 1024 }
})

export { createFileFilter, imageUpload, mixedUpload, allUpload }
```

**要点**：
- 同时校验扩展名和 MIME 类型，防止用户通过修改文件扩展名绕过限制
- 使用 `Record<string, { extensions, mimeTypes }>` 结构使白名单可配置、易扩展
- 遇到未知类型类别时直接抛出错误，避免运行时静默失败
- 生产环境中还可以加上 magic bytes（文件头）校验，进一步提高安全性

```typescript
        return res.status(400).json({
          success: false,
          message: '请选择要上传的图片'

        data: { avatar, avatarThumbnail },
        select: {
          id: true,
          username: true,
          avatar: true,
          avatarThumbnail: true
        }
      })

      next(error)
    }
```

## 常见误区

1. **直接使用用户上传的原始文件名**：用户上传的文件名可能包含中文、空格、特殊字符，甚至 `../../../etc/passwd` 这样的路径遍历攻击。必须用时间戳+随机字符串重新命名。

2. **不做文件类型和大小限制**：只在前端用 `accept="image/*"` 限制文件类型是不够的，用户可以绕过前端直接调 API。后端必须用 Multer 的 `fileFilter` 和 `limits` 做二次校验。

3. **用磁盘存储直接给用户返回文件路径**：返回 `/uploads/1716000000-a1b2c3d4.jpg` 这样的路径，攻击者可以枚举文件名下载其他用户的上传文件。应该用 `express.static` 配合随机文件名，或者用云存储的签名 URL。

4. **图片处理在请求同步完成**：上传头像时同步调用 sharp 做裁剪、压缩、转 WebP，用户要等 2-3 秒才能看到"上传成功"。应该用内存存储 + 后台任务异步处理。

---

## 工程建议

1. **内存存储 + sharp 处理是最佳实践**：用 `multer.memoryStorage()` 把文件存到内存，然后用 sharp 处理（裁剪、压缩、转格式），最后写入磁盘。这样可以灵活处理图片，避免临时文件堆积。

2. **按日期分目录存储**：`uploads/2024/05/18/xxx.webp` 的目录结构比把所有文件扔在一个目录好得多。单目录文件数超过 10000 时，文件系统性能会明显下降。

3. **生成缩略图用 WebP 格式**：WebP 比 JPEG 小 25-35%，现代浏览器都支持。头像生成 400x400 和 100x100 两个尺寸，文章封面生成 1200px 和 400px 两个尺寸。

4. **上传目录不要放在项目代码中**：`uploads/` 目录应该在 `.gitignore` 中，且在 Docker 部署时用 Volume 挂载。否则每次重新部署都会丢失用户上传的文件。
