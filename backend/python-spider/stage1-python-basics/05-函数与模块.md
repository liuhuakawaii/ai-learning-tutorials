## 一、函数基础：从 JavaScript 到 Python

### 1.1 什么是函数？

函数就像一台自动贩卖机：你投币（传参），它出饮料（返回值）。你不需要知道里面怎么运作，只需要知道接口。

```
┌─────────────────────────────────────┐
│            函数 = 自动贩卖机          │
│                                     │
│   输入(参数) ──→ ┌──────────┐       │
│                  │  函数体   │       │
│                  │  处理逻辑  │       │
│   输出(返回值) ←─ └──────────┘       │
│                                     │
└─────────────────────────────────────┘
```

### 1.2 定义函数：def vs function

作为前端开发者，你一定熟悉 JavaScript 的函数定义方式。来看对比：

```javascript
// JavaScript：你熟悉的方式
function greet(name) {
    return `Hello, ${name}!`;
}

// 箭头函数
const greet = (name) => {
    return `Hello, ${name}!`;
};

// 箭头函数简写
const greet = (name) => `Hello, ${name}!`;
```

```python
# Python：用 def 关键字
def greet(name):
    return f"Hello, {name}!"

# 调用方式完全一样
result = greet("张三")
print(result)  # Hello, 张三!
```

注意几个关键区别：
- JavaScript 用 `function` 关键字，Python 用 `def`
- Python 用**缩进**代替花括号 `{}` 来表示函数体
- Python 没有 `function` 关键字，也没有箭头函数的 `=>`

### 1.3 参数和返回值

```python
# 基本参数
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

# 多个返回值（Python 特有，JavaScript 需要用数组或对象）
def get_user_info():
    return "张三", 25, "zhangsan@example.com"

# 解包接收
name, age, email = get_user_info()
print(f"姓名：{name}，年龄：{age}，邮箱：{email}")

# 如果你只想要其中一个
name, _, _ = get_user_info()  # 用 _ 表示"我不需要这个值"
```

```
┌──────────────────────────────────────┐
│         返回值对比                     │
│                                      │
│  JavaScript:                         │
│    return [name, age, email]         │
│    return { name, age, email }       │
│                                      │
│  Python:                             │
│    return name, age, email           │
│    → 实际返回一个元组 (tuple)          │
│    → 可以直接解包接收                  │
└──────────────────────────────────────┘
```

## 二、高级参数用法

### 2.1 默认参数

```python
# 默认参数：和 JavaScript 的默认参数类似
def greet(name, greeting="你好"):
    return f"{greeting}, {name}!"

print(greet("张三"))           # 你好, 张三!
print(greet("张三", "嗨"))     # 嗨, 张三!

# ❌ 错误：默认参数后面不能跟非默认参数
# def bad_function(a=1, b):  # SyntaxError!
#     pass

# ✅ 正确：非默认参数在前，默认参数在后
def good_function(a, b=1, c=2):
    pass
```

**重要陷阱**：默认参数不要用可变对象！

```python
# ❌ 这是一个经典坑！
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item("a"))  # ['a']
print(add_item("b"))  # ['a', 'b']  ← 不是 ['b']！列表被共享了！

# ✅ 正确做法：用 None 作为默认值
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item("a"))  # ['a']
print(add_item("b"))  # ['b']  ← 正确！
```

### 2.2 关键字参数

```python
def create_user(name, age, city):
    return {"name": name, "age": age, "city": city}

# 位置参数：按顺序传
user1 = create_user("张三", 25, "北京")

# 关键字参数：按名字传，顺序无所谓
user2 = create_user(city="上海", name="李四", age=30)

# 混合使用：位置参数在前，关键字参数在后
user3 = create_user("王五", city="深圳", age=28)
```

### 2.3 *args 和 **kwargs

这是 Python 函数中非常强大的特性，作为前端开发者，你可以这样理解：

```python
# *args：接收任意数量的位置参数（类似 JavaScript 的 ...rest）
def sum_all(*args):
    print(f"收到的参数：{args}")  # args 是一个元组
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2, 3))       # 6
print(sum_all(1, 2, 3, 4, 5)) # 15

# **kwargs：接收任意数量的关键字参数
def print_info(**kwargs):
    print(f"收到的参数：{kwargs}")  # kwargs 是一个字典
    for key, value in kwargs.items():
        print(f"  {key}: {value}")

print_info(name="张三", age=25, city="北京")
```

```
┌────────────────────────────────────────────┐
│           参数类型总结                       │
│                                            │
│  def func(a, b, c):        # 位置参数       │
│  def func(a, b=1):         # 默认参数       │
│  def func(*args):          # 任意位置参数    │
│  def func(**kwargs):       # 任意关键字参数  │
│                                            │
│  完整顺序：                                  │
│  def func(a, b=1, *args, **kwargs):        │
│       ↑     ↑      ↑        ↑              │
│    位置   默认   任意位置  任意关键字         │
└────────────────────────────────────────────┘
```

```python
# 实际应用：写一个灵活的日志函数
def log_message(level, *args, **kwargs):
    """模拟日志输出"""
    message = " ".join(str(arg) for arg in args)
    extra_info = ", ".join(f"{k}={v}" for k, v in kwargs.items())

    if extra_info:
        print(f"[{level}] {message} | {extra_info}")
    else:
        print(f"[{level}] {message}")

log_message("INFO", "用户登录成功")
log_message("WARNING", "磁盘空间不足", disk="C盘", usage="95%")
log_message("ERROR", "连接超时", host="api.example.com", timeout=30)
```

## 三、Lambda 函数：Python 的"箭头函数"

### 3.1 Lambda 基础

如果你喜欢 JavaScript 的箭头函数，那你也会喜欢 Python 的 Lambda：

```javascript
// JavaScript 箭头函数
const double = (x) => x * 2;
const add = (a, b) => a + b;
```

```python
# Python Lambda（匿名函数）
double = lambda x: x * 2
add = lambda a, b: a + b

print(double(5))   # 10
print(add(3, 4))   # 7
```

### 3.2 Lambda 的实际用途

Lambda 通常不单独使用，而是作为参数传给其他函数：

```python
# 列表排序
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]

# 按分数排序（从高到低）
students.sort(key=lambda s: s["score"], reverse=True)
for s in students:
    print(f"{s['name']}: {s['score']}")
# 李四: 92
# 张三: 85
# 王五: 78

# filter：筛选出及格的学生
passed = list(filter(lambda s: s["score"] >= 80, students))
print(passed)

# map：给每个人加5分
bonus = list(map(lambda s: {**s, "score": s["score"] + 5}, students))
print(bonus)
```

```python
# ❌ 不建议把复杂逻辑写成 Lambda
bad_lambda = lambda x: x * 2 if x > 0 else -x * 3 + 1  # 太复杂了！

# ✅ 复杂逻辑用普通函数
def transform(x):
    if x > 0:
        return x * 2
    else:
        return -x * 3 + 1
```

## 四、变量作用域

### 4.1 局部变量 vs 全局变量

作用域的概念和 JavaScript 非常相似：

```python
# 全局变量
name = "全局张三"

def greet():
    # 局部变量
    name = "局部李四"
    print(f"函数内：{name}")

greet()           # 函数内：局部李四
print(f"函数外：{name}")  # 函数外：全局张三
```

```
┌──────────────────────────────────────────┐
│              作用域示意图                  │
│                                          │
│  ┌─ 全局作用域 ──────────────────────┐    │
│  │  name = "全局张三"                │    │
│  │                                  │    │
│  │  ┌─ 函数作用域 ────────────────┐  │    │
│  │  │  name = "局部李四"          │  │    │
│  │  │  (函数内优先使用局部变量)    │  │    │
│  │  └────────────────────────────┘  │    │
│  │                                  │    │
│  └──────────────────────────────────┘    │
│                                          │
│  规则：内部可以访问外部，外部看不到内部     │
└──────────────────────────────────────────┘
```

### 4.2 global 关键字

```python
# 如果你想在函数内修改全局变量
counter = 0

def increment():
    global counter  # 声明使用全局变量
    counter += 1

increment()
increment()
print(counter)  # 2

# ❌ 不用 global 会报错
# def bad_increment():
#     counter += 1  # UnboundLocalError!
```

```python
# 实际上，更推荐用参数和返回值，而不是 global
# ❌ 不推荐：使用 global
total = 0
def add_to_total(value):
    global total
    total += value

# ✅ 推荐：用参数和返回值
def add_value(current_total, value):
    return current_total + value

total = 0
total = add_value(total, 10)
total = add_value(total, 20)
print(total)  # 30
```

## 五、模块导入

### 5.1 为什么要用模块？

模块就像工具箱里的工具包。你不需要自己造锤子，直接拿来用就行。

```
┌────────────────────────────────────────────┐
│              模块 = 工具箱                   │
│                                            │
│  Python 标准库                              │
│  ├── os         → 文件系统操作工具           │
│  ├── sys        → 系统相关工具              │
│  ├── json       → JSON 解析工具            │
│  ├── re         → 正则表达式工具            │
│  └── datetime   → 日期时间工具              │
│                                            │
│  第三方库（需要安装）                        │
│  ├── requests   → HTTP 请求工具            │
│  ├── bs4        → HTML 解析工具            │
│  └── scrapy     → 爬虫框架工具             │
└────────────────────────────────────────────┘
```

### 5.2 导入方式

```python
# 方式一：导入整个模块
import os
print(os.getcwd())  # 获取当前工作目录

# 方式二：导入模块并起别名
import os.path as osp
print(osp.exists("test.txt"))

# 方式三：从模块中导入指定内容
from os import getcwd, listdir
print(getcwd())  # 不需要写 os.getcwd()

# 方式四：导入模块中的所有内容（不推荐）
from os import *  # ❌ 容易命名冲突，不推荐使用
```

```python
# ❌ 不推荐：导入太多东西
from os import *
from sys import *
from json import *  # 谁知道你用了什么？

# ✅ 推荐：明确导入
import os
import json
from sys import argv
```

### 5.3 常用内置模块

```python
# os 模块：操作系统相关
import os
```

## 六、创建自己的模块

### 6.1 模块就是一个 .py 文件

```
项目结构：
my_project/
├── my_utils.py      ← 这就是一个模块
├── main.py          ← 主程序
└── utils/           ← 这是一个包（package）
    ├── __init__.py  ← 包的标识文件
    ├── string_utils.py
    └── file_utils.py
```

创建 `my_utils.py`：

```python
# my_utils.py - 自定义工具模块

def greet(name):
    """打招呼函数"""
    return f"你好，{name}！欢迎学习 Python 爬虫！"

def add(a, b):
    """加法函数"""
    return a + b

def is_even(n):
    """判断是否为偶数"""
    return n % 2 == 0

# 模块级别的变量
VERSION = "1.0.0"
AUTHOR = "爬虫课程"
```

在 `main.py` 中使用：

```python
# main.py - 使用自定义模块

# 方式一：导入整个模块
import my_utils
print(my_utils.greet("张三"))
print(my_utils.VERSION)

# 方式二：从模块中导入指定内容
from my_utils import greet, add
print(greet("李四"))
print(add(3, 5))
```

### 6.2 if __name__ == "__main__"

这是 Python 独有的概念，JavaScript 没有对应的东西：

```python
# my_utils.py

def greet(name):
    return f"你好，{name}！"

def add(a, b):
    return a + b

# 这段代码只在直接运行此文件时执行
# 如果这个文件被 import，这段代码不会执行
if __name__ == "__main__":
    # 测试代码
    print("直接运行 my_utils.py")
    print(greet("测试"))
    print(add(1, 2))
```

```
┌──────────────────────────────────────────────────┐
│        __name__ 的两种情况                        │
│                                                  │
│  情况1：直接运行 my_utils.py                       │
│  ┌────────────────────────────────┐               │
│  │ python my_utils.py             │               │
│  │ __name__ = "__main__"          │               │
│  │ → if 条件为 True               │               │
│  │ → 执行 if 内的代码             │               │
│  └────────────────────────────────┘               │
│                                                  │
│  情况2：其他文件 import my_utils                   │
│  ┌────────────────────────────────┐               │
│  │ import my_utils                │               │
│  │ __name__ = "my_utils"          │               │
│  │ → if 条件为 False              │               │
│  │ → 不执行 if 内的代码           │               │
│  └────────────────────────────────┘               │
└──────────────────────────────────────────────────┘
```

```python
# 实际应用：让你的模块既能被导入，也能独立运行
# file_scanner.py

import os

def scan_directory(path):
    """扫描目录，返回文件列表"""
    files = []
    for item in os.listdir(path):
        full_path = os.path.join(path, item)
        if os.path.isfile(full_path):
            files.append(item)
    return files

def count_files_by_extension(path):
    """按扩展名统计文件数量"""
    files = scan_directory(path)
    count = {}
    for f in files:
        ext = os.path.splitext(f)[1].lower() or "无扩展名"
        count[ext] = count.get(ext, 0) + 1
    return count

if __name__ == "__main__":
    # 只有直接运行时才执行测试
    test_path = "."
    print(f"扫描目录：{test_path}")
    print(f"文件列表：{scan_directory(test_path)}")
    print(f"扩展名统计：{count_files_by_extension(test_path)}")
```

### 动手练习

**练习1：写一个温度转换模块**

创建一个 `temp_converter.py` 模块，包含以下函数：
- `celsius_to_fahrenheit(c)`: 摄氏转华氏
- `fahrenheit_to_celsius(f)`: 华氏转摄氏
- `celsius_to_kelvin(c)`: 摄氏转开尔文

然后写一个 `main.py` 导入并测试这个模块。

```python
# temp_converter.py
def celsius_to_fahrenheit(c):
    """摄氏度转华氏度"""
    return c * 9 / 5 + 32

def fahrenheit_to_celsius(f):
    """华氏度转摄氏度"""
    return (f - 32) * 5 / 9

def celsius_to_kelvin(c):
    """摄氏度转开尔文"""
    return c + 273.15

if __name__ == "__main__":
    # 测试代码
    temp_c = 25
    print(f"{temp_c}°C = {celsius_to_fahrenheit(temp_c)}°F")
    print(f"{temp_c}°C = {celsius_to_kelvin(temp_c)}K")
```

```python
# main.py
from temp_converter import celsius_to_fahrenheit, fahrenheit_to_celsius

# 测试
temp_c = 100
temp_f = celsius_to_fahrenheit(temp_c)
print(f"{temp_c}°C = {temp_f}°F")
print(f"{temp_f}°F = {fahrenheit_to_celsius(temp_f)}°C")
```

**练习2：写一个灵活的格式化函数**

使用 `*args` 和 `**kwargs` 写一个 `format_report` 函数，能接收任意内容并格式化输出。

```python
def format_report(title, *args, **kwargs):
    """
    格式化输出报告
    title: 报告标题
    *args: 要显示的内容行
    **kwargs: 要显示的键值对信息
    """
    print("=" * 40)
    print(f"  {title}")
    print("=" * 40)

    for line in args:
        print(f"  {line}")

    if kwargs:
        print("-" * 40)
        for key, value in kwargs.items():
            print(f"  {key}: {value}")

    print("=" * 40)

# 测试
format_report(
    "爬虫运行报告",

    "失败 3 个页面",
    "耗时 2 分 30 秒",
    状态="完成",
    目标网站="example.com",
    日期="2024-01-01"
)
```

**练习3：Lambda 排序练习**

给定一组网站数据，使用 Lambda 进行各种排序：

```python
websites = [
    {"name": "百度", "url": "baidu.com", "rank": 5},
    {"name": "谷歌", "url": "google.com", "rank": 1},
    {"name": "必应", "url": "bing.com", "rank": 8},
    {"name": "GitHub", "url": "github.com", "rank": 3},
]

# 按排名排序
by_rank = sorted(websites, key=lambda x: x["rank"])
print("按排名：", [w["name"] for w in by_rank])

# 按名字长度排序
by_name_len = sorted(websites, key=lambda x: len(x["name"]))
print("按名字长度：", [w["name"] for w in by_name_len])

# 只提取名字和URL
urls_only = list(map(lambda w: f"{w['name']}: {w['url']}", websites))
for u in urls_only:
    print(u)
```

## 常见误区

- **"默认参数可以用空列表 `[]`"**：这是一个经典陷阱。Python 的默认参数在函数定义时只计算一次，如果用可变对象（列表、字典）作为默认值，所有调用会共享同一个对象。正确做法是用 `None` 作为默认值，在函数体内创建新列表。
- **"Lambda 比普通函数更高级"**：Lambda 只是匿名函数的简写形式，适合简单的单行逻辑。复杂逻辑应该用普通函数，否则代码可读性会急剧下降。不要为了"简洁"把三行逻辑挤进一个 Lambda。
- **"用 `global` 在函数里修改全局变量很方便"**：`global` 会让代码变得难以理解和测试。推荐通过参数传入、返回值传出的方式来处理数据，而不是依赖全局状态。纯函数（输入相同则输出相同）比依赖全局变量的函数更可靠。
- **"`from xxx import *` 很方便"**：这种写法会把模块中所有公开的名字导入当前命名空间，容易引发命名冲突，你也不知道到底导入了什么。推荐明确导入需要的名字：`from os import getcwd, listdir`。

## 工程建议

- **函数设计遵循单一职责原则**：一个函数只做一件事。`fetch_and_parse_and_save(url)` 不如拆成 `fetch_page(url)`、`parse_html(html)`、`save_data(data)` 三个函数。这样每个函数都可以独立测试和复用。
- **用 `if __name__ == "__main__"` 保护测试代码**：让你的模块既能被其他文件导入，也能独立运行。这在爬虫项目中特别有用——你可以单独测试某个模块的功能，而不需要运行整个爬虫。
- **包结构按功能划分**：爬虫项目可以拆分成 `http_client.py`（请求模块）、`parser.py`（解析模块）、`storage.py`（存储模块）、`config.py`（配置模块）。相关功能放同一个包里，比全堆在一个文件里好维护得多。
- **善用内置模块，减少第三方依赖**：`os`、`sys`、`json`、`re`、`pathlib`、`datetime` 等标准库覆盖了大部分基础需求。能用标准库解决的问题，就不要引入第三方包——依赖越少，项目越稳定。
