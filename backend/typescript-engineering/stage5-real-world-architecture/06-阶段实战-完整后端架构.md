# 06 阶段实战：完整后端架构

前五课讲了错误处理、日志、API 设计、数据库访问、部署。现在整合到一起，搭建一个可以跑在生产环境的订单管理服务。

## 项目结构

每一层只关心一件事。Repository 管数据库，Service 管业务逻辑，Router 管输入校验和错误映射。层与层之间通过类型契约连接。

## 配置与错误层级

启动时校验环境变量，缺了就直接退出：

```typescript
import { z } from 'zod'

const configSchema = z.object({
  port: z.coerce.number().default(3000),
  database: z.object({
    host: z.string().default('localhost'),
    port: z.coerce.number().default(5432),
    name: z.string(),
    user: z.string(),
    password: z.string(),
  }),
  logLevel: z.enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace']).default('info'),
})

export type Config = z.infer<typeof configSchema>

export function loadConfig(): Config {
  const result = configSchema.safeParse({
    port: process.env.PORT,
    database: {
      host: process.env.DB_HOST, port: process.env.DB_PORT,
      name: process.env.DB_NAME, user: process.env.DB_USER, password: process.env.DB_PASSWORD,
    },
    logLevel: process.env.LOG_LEVEL,
  })
  if (!result.success) {
    console.error('Invalid configuration:', result.error.flatten().fieldErrors)
    process.exit(1)
  }
  return result.data
}
```

错误层级沿用第一课：NotFoundError（404）、ValidationError（400）、ForbiddenError（403）、DatabaseError（500）。

## 数据库层

Drizzle ORM 定义表结构，类型自动推导：

```typescript
import { pgTable, uuid, varchar, integer, timestamp, pgEnum } from 'drizzle-orm/pg-core'

export const orderStatusEnum = pgEnum('order_status', ['pending', 'paid', 'shipped', 'delivered', 'cancelled'])

export const orders = pgTable('orders', {
  id: uuid('id').primaryKey().defaultRandom(),
  userId: uuid('user_id').notNull(),
  status: orderStatusEnum('status').notNull().default('pending'),
  totalAmount: integer('total_amount').notNull(),
  shippingAddress: varchar('shipping_address', { length: 500 }).notNull(),
  createdAt: timestamp('created_at').notNull().defaultNow(),
  updatedAt: timestamp('updated_at').notNull().defaultNow(),
})

export const orderItems = pgTable('order_items', {
  id: uuid('id').primaryKey().defaultRandom(),
  orderId: uuid('order_id').notNull().references(() => orders.id),
  productId: uuid('product_id').notNull(),
  quantity: integer('quantity').notNull(),
  unitPrice: integer('unit_price').notNull(),
})
```

Repository 统一返回 Result，不抛异常——**异常在数据库层被终结，从这里往上只有 Result**：

```typescript
import { eq } from 'drizzle-orm'
import { ResultAsync, ok, err } from 'neverthrow'
import { DatabaseError, NotFoundError } from '../../errors'

export class OrderRepository {
  constructor(private db: Database) {}

  findById(id: string) {
    return ResultAsync.fromPromise(
      this.db.query.orders.findFirst({ where: eq(orders.id, id), with: { items: true } }),
      (e) => new DatabaseError('Failed to query order', { cause: e, orderId: id })
    ).andThen((order) => order ? ok(order) : err(new NotFoundError('Order', id)))
  }

  create(data: { userId: string; items: Array<{ productId: string; quantity: number; unitPrice: number }>; shippingAddress: string }) {
    return ResultAsync.fromPromise(
      this.db.transaction(async (tx) => {
        const totalAmount = data.items.reduce((sum, item) => sum + item.quantity * item.unitPrice, 0)
        const [order] = await tx.insert(orders).values({
          userId: data.userId, totalAmount, shippingAddress: data.shippingAddress,
        }).returning()
        await tx.insert(orderItems).values(data.items.map((item) => ({ orderId: order.id, ...item })))
        return order
      }),
      (e) => new DatabaseError('Failed to create order', { cause: e })
    )
  }

  updateStatus(id: string, status: string) {
    return ResultAsync.fromPromise(
      this.db.update(orders).set({ status: status as any, updatedAt: new Date() })
        .where(eq(orders.id, id)).returning().then(([order]) => order),
      (e) => new DatabaseError('Failed to update order status', { cause: e, orderId: id })
    ).andThen((order) => order ? ok(order) : err(new NotFoundError('Order', id)))
  }
}
```

## 日志与中间件

pino 做结构化日志，AsyncLocalStorage 做请求追踪：

```typescript
import pino from 'pino'
import { AsyncLocalStorage } from 'async_hooks'

interface RequestContext { traceId: string; userId?: string }
const requestContext = new AsyncLocalStorage<RequestContext>()

export function createLogger(config: { logLevel: string }) {
  return pino({ level: config.logLevel, formatters: { level: (label) => ({ level: label }) } })
}
export type Logger = pino.Logger
export function getLogger(baseLogger: Logger): Logger {
  const ctx = requestContext.getStore()
  return ctx ? baseLogger.child({ traceId: ctx.traceId, userId: ctx.userId }) : baseLogger
}
export { requestContext }
```

tRPC 中间件生成 traceId、记录耗时：

```typescript
import { initTRPC } from '@trpc/server'
import crypto from 'crypto'

export const t = initTRPC.context<Context>().create()

export const loggingMiddleware = t.middleware(async ({ path, type, next, ctx }) => {
  const traceId = crypto.randomUUID()
  return requestContext.run({ traceId }, async () => {
    const start = performance.now()
    ctx.logger.info({ path, type, traceId }, 'Request started')
    const result = await next()
    const duration = performance.now() - start
    ctx.logger.info({ path, type, duration: `${duration.toFixed(2)}ms` }, 'Request completed')
    return result
  })
})
```

## 业务逻辑与 Router

Service 层做业务校验和组合：

```typescript
import { err } from 'neverthrow'
import { NotFoundError, DatabaseError, ValidationError, ForbiddenError } from '../errors'

export class OrderService {
  constructor(private orderRepo: OrderRepository) {}

  getOrder(id: string) { return this.orderRepo.findById(id) }

  createOrder(input: { userId: string; items: Array<{ productId: string; quantity: number; unitPrice: number }>; shippingAddress: string }) {
    if (input.items.length === 0) return err(new ValidationError('At least one item required', { items: 'empty' }))
    return this.orderRepo.create(input)
  }

  cancelOrder(orderId: string, userId: string) {
    return this.orderRepo.findById(orderId).andThen((order) => {
      if (order.userId !== userId) return err(new ForbiddenError('cancel this order'))
      if (order.status !== 'pending') return err(new ValidationError('Only pending orders can be cancelled', { status: order.status }))
      return this.orderRepo.updateStatus(orderId, 'cancelled')
    })
  }
}
```

Router 只做输入校验、调用 Service、把 Result 映射成 tRPC 响应。每个 procedure 都是同一个模式：校验输入 → 调用 Service → match 处理结果：

```typescript
import { z } from 'zod'
import { t, loggingMiddleware } from '../middleware/logging'
import { protectedProcedure } from '../middleware/auth'
import { AppError } from '../errors'
import { TRPCError } from '@trpc/server'

const baseProcedure = t.procedure.use(loggingMiddleware)

function toTRPCError(error: AppError): TRPCError {
  if (error.code === 'NOT_FOUND') return new TRPCError({ code: 'NOT_FOUND', message: error.message })
  if (error.code === 'VALIDATION_ERROR') return new TRPCError({ code: 'BAD_REQUEST', message: error.message })
  if (error.code === 'FORBIDDEN') return new TRPCError({ code: 'FORBIDDEN', message: error.message })
  return new TRPCError({ code: 'INTERNAL_SERVER_ERROR', message: error.message })
}

export function createOrderRouter(orderService: OrderService) {
  return t.router({
    getById: baseProcedure
      .input(z.object({ id: z.string().uuid() }))
      .query(async ({ input }) => {
        const result = await orderService.getOrder(input.id)
        return result.match((order) => order, (error) => { throw toTRPCError(error) })
      }),

    create: protectedProcedure
      .input(z.object({
        items: z.array(z.object({
          productId: z.string().uuid(),
          quantity: z.number().int().positive(),
          unitPrice: z.number().int().positive(),
        })).min(1).max(50),
        shippingAddress: z.string().min(10).max(500),
      }))
      .mutation(async ({ input, ctx }) => {
        const result = await orderService.createOrder({
          userId: ctx.userId, items: input.items, shippingAddress: input.shippingAddress,
        })
        return result.match((order) => order, (error) => { throw toTRPCError(error) })
      }),
  })
}
```

## 服务器启动与 Docker

```typescript
import { createHTTPHandler } from '@trpc/server/adapters/standalone'
import http from 'http'

export interface Context { logger: ReturnType<typeof createLogger>; userId?: string; req?: http.IncomingMessage }

async function main() {
  const config = loadConfig()
  const logger = createLogger(config)
  const db = createDatabase(config.database)
  const orderRepo = new OrderRepository(db)
  const orderService = new OrderService(orderRepo)
  const appRouter = createOrderRouter(orderService)

  const handler = createHTTPHandler({ router: appRouter, createContext({ req }): Context { return { logger, req } } })

  const server = http.createServer((req, res) => {
    if (req.url === '/health') {
      res.writeHead(200, { 'Content-Type': 'application/json' })
      res.end(JSON.stringify({ status: 'ok' }))
      return
    }
    handler(req, res)
  })

  const shutdown = async (signal: string) => {
    logger.info({ signal }, 'Shutting down')
    server.close(async () => {
      try { await db.$client.end(); process.exit(0) }
      catch (error) { logger.fatal({ err: error }, 'Shutdown error'); process.exit(1) }
    })
    setTimeout(() => process.exit(1), 30000)
  }

  process.on('SIGTERM', () => shutdown('SIGTERM'))
  process.on('SIGINT', () => shutdown('SIGINT'))
  server.listen(config.port, () => { logger.info({ port: config.port }, 'Server started') })
}

main().catch((error) => { console.error('Failed to start:', error); process.exit(1) })
```

## 容易踩的坑

**Repository 层直接抛异常**。Repository 应返回 Result，让 Service 层决定怎么处理。

**Procedure 里写业务逻辑**。Procedure 是薄薄的一层，只负责输入校验、调用 Service、错误映射。

**日志打印整个请求体**。大请求体会撑爆日志存储，只打印关键字段。

**Docker 用 root 运行**。容器逃逸风险，生产镜像必须用非 root 用户。

```typescript
export class UserService {
  constructor(private userRepo: UserRepository) {}
  register(input: { email: string; password: string; name: string }) {
    return this.userRepo.findByEmail(input.email).andThen((existing) => {
      if (existing) return err(new ValidationError('Email already registered', { email: 'taken' }))
      return this.userRepo.create({ ...input, passwordHash: hashPassword(input.password) })
    })
  }
  login(email: string, password: string) {
    return this.userRepo.findByEmail(email).andThen((user) => {
      if (!user || !verifyPassword(password, user.passwordHash))
        return err(new ValidationError('Invalid credentials', { email: 'invalid' }))
      return ok({ id: user.id, email: user.email, name: user.name })
    })
  }
}
```

### 练习二

```typescript
const rateLimitStore = new Map<string, { count: number; resetAt: number }>()

export const rateLimitMiddleware = t.middleware(async ({ ctx, next }) => {
  const userId = ctx.userId || 'anonymous'
  const now = Date.now()
  let entry = rateLimitStore.get(userId)
  if (!entry || now > entry.resetAt) {
    entry = { count: 0, resetAt: now + 60_000 }
    rateLimitStore.set(userId, entry)
  }
  entry.count++
  if (entry.count > 100) {
    throw new TRPCError({ code: 'TOO_MANY_REQUESTS', message: `Rate limit exceeded` })
  }
  return next()
})
```

每个用户独立计数，窗口过期自动重置。生产环境用 Redis 替代内存 Map。
