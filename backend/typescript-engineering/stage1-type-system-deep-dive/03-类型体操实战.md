# 03 - 类型体操实战

## 场景引入

你在开发一个表单组件库，表单的配置对象支持深度嵌套。你需要一个 `DeepPartial` 让用户可以只填写部分字段，一个 `DeepReadonly` 防止配置被意外修改，还需要一个类型安全的 getter 函数，能根据字符串路径 `"user.address.city"` 自动推断返回值类型。这些需求无法用内置工具类型解决，需要自己动手写类型体操。

## 学习目标

- 能独立实现 `DeepPartial`、`DeepReadonly` 等深层工具类型
- 掌握类型安全的路由参数解析
- 能实现类型安全的查询字符串解析器
- 理解类型体操中的递归模式和边界条件处理
- 知道何时该用类型体操，何时该用类型断言简化

## 一、DeepPartial

内置的 `Partial<T>` 只处理第一层属性：

```typescript
type DeepPartial<T> = T extends object
  ? { [K in keyof T]?: DeepPartial<T[K]> }
  : T

interface Config {
  server: {
    host: string
    port: number
    ssl: { cert: string; key: string }
  }
  database: { url: string; pool: number }
}

type DeepPartialConfig = DeepPartial<Config>
// server, database, host, port, ssl, cert, key, url, pool 全部可选
```

处理数组和特殊对象：

```typescript
type DeepPartialV2<T> = T extends Map<infer K, infer V>
  ? Map<K, DeepPartialV2<V>>
  : T extends Set<infer U>
    ? Set<DeepPartialV2<U>>
    : T extends Array<infer E>
      ? Array<DeepPartialV2<E>>
      : T extends object
        ? { [K in keyof T]?: DeepPartialV2<T[K]> }
        : T
```

## 二、DeepReadonly

```typescript
type DeepReadonly<T> = T extends Map<infer K, infer V>
  ? ReadonlyMap<K, DeepReadonly<V>>
  : T extends Set<infer U>
    ? ReadonlySet<DeepReadonly<U>>
    : T extends Array<infer E>
      ? ReadonlyArray<DeepReadonly<E>>
      : T extends object
        ? { readonly [K in keyof T]: DeepReadonly<T[K]> }
        : T
```

## 三、类型安全的路径访问

```typescript
type Get<T, Path extends string> =
  Path extends `${infer Key}.${infer Rest}`
    ? Key extends keyof T
      ? Get<T[Key], Rest>
      : never
    : Path extends keyof T
      ? T[Path]
      : never

interface AppState {
  user: {
    profile: { name: string; age: number }
    settings: { theme: "light" | "dark" }
  }
}

type Theme = Get<AppState, "user.settings.theme">  // "light" | "dark"

function get<T extends object, P extends string>(obj: T, path: P): Get<T, P> {
  const keys = path.split(".")
  let result: any = obj
  for (const key of keys) {
    result = result?.[key]
  }
  return result
}

declare const state: AppState
const theme = get(state, "user.settings.theme")  // 类型是 "light" | "dark"
// get(state, "user.unknown") // 编译报错
```

## 四、类型安全的路由参数解析

```typescript
type ExtractRouteParams<T extends string> =
  T extends `${string}:${infer Param}/${infer Rest}`
    ? { [K in Param]: string } & ExtractRouteParams<Rest>
    : T extends `${string}:${infer Param}`
      ? { [K in Param]: string }
      : {}

type Params = ExtractRouteParams<"/users/:id/posts/:postId">
// { id: string } & { postId: string }

function createRoute<T extends string>(template: T) {
  return {
    build(params: ExtractRouteParams<T>): string {
      let result: string = template
      for (const [key, value] of Object.entries(params)) {
        result = result.replace(`:${key}`, value as string)
      }
      return result
    },
    match(url: string): ExtractRouteParams<T> | null {
      const templateParts = template.split("/")
      const urlParts = url.split("/")
      if (templateParts.length !== urlParts.length) return null
      const params: Record<string, string> = {}
      for (let i = 0; i < templateParts.length; i++) {
        if (templateParts[i].startsWith(":")) {
          params[templateParts[i].slice(1)] = urlParts[i]
        } else if (templateParts[i] !== urlParts[i]) {
          return null
        }
      }
      return params as ExtractRouteParams<T>
    },
  }
}

const userRoute = createRoute("/users/:id")
const url = userRoute.build({ id: "123" })  // "/users/123"
```

## 五、类型安全的查询字符串解析器

```typescript
type QueryParamTypes = {
  string: string
  number: number
  boolean: boolean
}

type ParseQuery<T extends string> =
  T extends `${infer Key}:${infer Type}&${infer Rest}`
    ? Type extends keyof QueryParamTypes
      ? { [K in Key]: QueryParamTypes[Type] } & ParseQuery<Rest>
      : never
    : T extends `${infer Key}:${infer Type}`
      ? Type extends keyof QueryParamTypes
        ? { [K in Key]: QueryParamTypes[Type] }
        : never
      : {}

type SearchParams = ParseQuery<"q:string&page:number&active:boolean">
// { q: string; page: number; active: boolean }

function parseQuery<T extends string>(queryString: string): ParseQuery<T> {
  const params: Record<string, unknown> = {}
  for (const pair of queryString.split("&")) {
    const [key, rawValue] = pair.split("=")
    const [name, type] = key.split(":")
    switch (type) {
      case "number": params[name] = Number(rawValue); break
      case "boolean": params[name] = rawValue === "true"; break
      default: params[name] = rawValue
    }
  }
  return params as ParseQuery<T>
}
```

## 常见误区

1. **忽略数组和特殊对象的处理**：`DeepPartial` 只判断 `extends object` 时，数组会被当成普通对象处理。
2. **类型递归没有终止条件**：递归类型需要在非对象类型时终止，否则编译器报错。
3. **过度追求类型安全**：有些场景用类型断言比写 50 行类型体操更合理。
4. **忽略联合类型的处理**：联合类型在条件类型中会分发，有时导致意外结果。

## 工程建议

1. **DeepPartial 用于配置合并**：用户配置只需覆盖部分字段。
2. **DeepReadonly 用于状态管理**：防止 React state、Redux store 被意外修改。
3. **类型安全的路径访问用于数据提取**：从 API 响应中安全提取嵌套数据。
4. **路由参数解析用于框架开发**：路由库或 API 框架的关键特性。

## 小结

类型体操不是炫技，而是解决真实工程问题。DeepPartial 和 DeepReadonly 解决深层嵌套对象的类型操作，类型安全的路径访问和路由解析让字符串路径获得编译时类型检查。关键是在类型安全和代码复杂度之间找到平衡点。

## 参考答案

### 练习一

**思路**：使用 `-?` 移除可选修饰符，递归处理嵌套对象。

**答案**：

```typescript
type DeepRequired<T> = T extends Array<infer E>
  ? Array<DeepRequired<E>>
  : T extends object
    ? { [K in keyof T]-?: DeepRequired<T[K]> }
    : T

interface PartialUser {
  name?: string
  settings?: { theme?: string; notifications?: { email?: boolean } }
}

type RequiredUser = DeepRequired<PartialUser>
// name, settings, theme, notifications, email 全部必需
```

**要点**：`-?` 移除可选标记。需要处理数组等特殊容器类型。

### 练习二

**思路**：沿路径逐级访问，最后一级设置值。类型保证 value 与目标属性类型匹配。

**答案**：

```typescript
type Get<T, P extends string> =
  P extends `${infer Key}.${infer Rest}`
    ? Key extends keyof T ? Get<T[Key], Rest> : never
    : P extends keyof T ? T[P] : never

function set<T extends object, P extends string>(
  obj: T, path: P, value: Get<T, P>
): void {
  const keys = path.split(".")
  let current: any = obj
  for (let i = 0; i < keys.length - 1; i++) {
    current = current[keys[i]]
  }
  current[keys[keys.length - 1]] = value
}

interface Config { server: { host: string; port: number } }
declare const config: Config
set(config, "server.host", "localhost")
// set(config, "server.port", "not a number") // 编译报错
```

**要点**：`value` 参数类型为 `Get<T, P>`，确保值类型与目标属性类型匹配。

### 练习三

**思路**：利用函数参数的逆变性，联合类型在函数参数位置变成交叉类型。

**答案**：

```typescript
type UnionToIntersection<U> =
  (U extends any ? (x: U) => void : never) extends (x: infer I) => void
    ? I
    : never

type A = UnionToIntersection<{ a: string } | { b: number }>
// { a: string } & { b: number }

function mergeConfigs<T extends object[]>(
  ...configs: T
): UnionToIntersection<T[number]> {
  return Object.assign({}, ...configs) as UnionToIntersection<T[number]>
}

const result = mergeConfigs({ host: "localhost" }, { port: 3000 }, { debug: true })
// { host: string } & { port: number } & { debug: boolean }
```

**要点**：`(U extends any ? (x: U) => void : never)` 对联合类型每个成员创建函数类型，由于函数参数逆变，`infer I` 被推断为交叉类型。
