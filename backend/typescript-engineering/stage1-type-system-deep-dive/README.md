# 阶段一：类型系统深入

TypeScript 的核心价值在于类型系统。这个阶段不是复习基础语法，而是深入类型系统的底层机制，让你从"能写类型"变成"能设计类型"。学完这个阶段，你将能独立设计类型安全的 API、编写高级类型工具函数、理解类型系统的设计权衡。

## 本阶段学习目标

- 理解 TypeScript 类型推断的完整机制，包括上下文类型推断和最佳公共类型
- 掌握类型收窄的所有方式，能编写精确的类型守卫函数
- 熟练使用条件类型、infer 关键字、映射类型进行类型编程
- 理解协变与逆变的概念，知道 `strictFunctionTypes` 背后的设计决策
- 能独立编写声明文件、进行模块增强和全局类型扩展

## 课时列表

### 01 - 类型推断与类型收窄
上下文类型推断、typeof/instanceof/in 守卫、自定义类型守卫、判别联合、const assertions、satisfies。掌握 TypeScript 类型系统的核心收窄机制。

### 02 - 泛型高级模式
条件类型语法、infer 提取、映射类型遍历、模板字面量类型、类型递归。学会在类型层面进行编程，实现高度自动化的类型推断。

### 03 - 类型体操实战
DeepPartial、DeepReadonly 实现、类型安全路由参数解析、类型安全查询字符串解析器。把高级类型特性应用到实际工具函数中。

### 04 - 声明文件与类型增强
.d.ts 文件编写规范、模块增强（module augmentation）、全局类型扩展、ambient 声明。让 TypeScript 理解任何 JavaScript 代码的类型。

### 05 - 协变与逆变
协变/逆变概念、函数参数逆变、返回值协变、strictFunctionTypes 的实际影响。理解类型系统中最反直觉但最重要的规则。

### 06 - 阶段实战：类型安全工具库
综合运用阶段知识，构建 pick、omit、merge、deep merge、类型安全 get/set 等工具函数。把所有知识串联到一个完整的项目中。

## 本阶段项目

本阶段的实战项目是**构建类型安全的工具函数库**。这个项目贯穿整个阶段，每节课都会为工具库添加新的类型工具，最终形成一个完整的、类型安全的实用工具集。

项目目标：
- 实现至少 10 个类型安全的工具函数
- 每个工具函数都有完整的类型定义和单元测试
- 工具函数之间可以组合使用
- 所有类型推断都是自动的，调用方不需要手动标注

## 学习建议

1. **在编辑器里写代码**：TypeScript 的类型推断和错误提示只有在 VSCode 等 IDE 里才能完整体验。不要只看代码，要动手写。
2. **善用类型可视化**：鼠标悬停在变量上查看推断类型，使用 `type A = typeof x` 来验证你的理解。
3. **从简单开始**：先理解基本的泛型，再学条件类型，最后挑战类型体操。不要跳步。
4. **关注错误信息**：TypeScript 的错误信息是学习类型系统的重要资源，认真阅读每条错误信息，理解它为什么报错。
