# TypeScript 工程化

面向生产环境的高级 TypeScript 工程实践（30 课时）

本课程不是 TypeScript 语法入门，而是面向已有基础、希望在真实项目中用好 TypeScript 的工程师。课程围绕类型系统深度、设计模式、工具链、测试质量和生产架构五个维度展开，每节课都从真实工程问题出发，带你把 TypeScript 从"能用"提升到"用好"。

## 课程目标

- 掌握 TypeScript 类型系统的高级特性，能独立设计类型安全的 API 和工具库
- 熟练运用泛型、条件类型、映射类型等高级类型编程技巧
- 理解并应用 Builder、策略模式、依赖注入、DDD 等设计模式的 TypeScript 实现
- 掌握 tsconfig 调优、ESBuild 构建、Monorepo 工程化方案
- 具备生产级 TypeScript 项目的错误处理、日志、API 设计能力

## 学习路线

本课程分为 5 个阶段，每阶段 6 课时，共 30 课时：

| 阶段 | 主题 | 核心内容 |
|------|------|----------|
| 阶段一 | 类型系统深入 | 深入类型推断、泛型、类型体操 |
| 阶段二 | 高级设计模式 | Builder、策略、DI、DDD |
| 阶段三 | 工具链与构建 | tsconfig、ESBuild、Monorepo |
| 阶段四 | 测试与质量 | Vitest、类型测试、契约测试 |
| 阶段五 | 生产级架构 | 错误处理、日志、API 设计 |

## 前置要求

- **Node.js** 18+（推荐 20 LTS）
- **TypeScript** 5.0+（课程使用 5.3+ 特性）
- **前端基础**：熟悉 JavaScript ES6+、了解 npm/yarn/pnpm 包管理
- **命令行基础**：能使用终端执行命令、安装依赖
- **可选**：了解基本的 HTTP 协议和 RESTful API 概念

## 学习建议

1. **动手优先**：每节课的代码示例都要亲手敲一遍，不要复制粘贴。TypeScript 的类型系统只有在编辑器里实际写过才能真正理解。
2. **逐阶段推进**：阶段之间有递进关系，建议按顺序学习。阶段内部的课程可以适当调整顺序。
3. **带着问题学**：每节课的"场景引入"都是真实工程问题，先尝试自己思考解决方案，再看课程讲解。
4. **做完练习**：每节课末尾的练习是巩固知识的关键，参考答案仅在独立完成后查看。
5. **项目串联**：每个阶段末尾的实战课程会把该阶段知识串联起来，这是最重要的学习环节。

## 课程特色

- **问题驱动**：每节课从真实工程问题出发，不是 API 清单式罗列
- **代码优先**：所有示例都是完整可运行的 TypeScript 代码
- **类型安全**：强调类型设计的正确性和实用性，不是炫技
- **循序渐进**：从类型基础到生产架构，每一步都有明确的学习目标
- **实战导向**：每个阶段末尾都有综合实战项目，串联阶段知识

## 常见问题

**Q: 我需要先学完基础 TypeScript 课程吗？**
A: 是的。本课程假设你已经熟悉 TypeScript 的基础语法（接口、泛型、类等），直接进入高级主题。

**Q: 每节课需要多长时间？**
A: 建议每节课 2-3 小时，包括阅读、编码和练习。整个课程约 60-90 小时。

**Q: 可以跳过某些阶段吗？**
A: 阶段一（类型系统）是所有后续阶段的基础，不建议跳过。其他阶段可以根据你的需求选择性学习。
