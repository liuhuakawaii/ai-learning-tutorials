# 阶段二：高级设计模式

将经典设计模式与 TypeScript 类型系统深度结合，在编译期捕获架构错误，实现真正类型安全的工程模式。

## 本阶段学习目标

- 掌握用泛型约束实现类型安全的 Builder 模式，让编译器帮你检查必填字段
- 理解策略模式与工厂模式在 TypeScript 中的惯用实现，消除类型断言
- 实现一个轻量级依赖注入容器，理解 IoC 原理与生命周期管理
- 构建类型安全的事件系统，让事件载荷在编译期可检查
- 掌握 DDD 核心战术模式（Entity、Value Object、Aggregate Root），并用于业务建模

## 本阶段项目：用 DDD 构建电商领域模型

贯穿本阶段的实战项目是一个电商领域的订单系统。从第 5 课开始逐步引入 DDD 概念，第 6 课完成完整实现：

- **商品目录**：Product 实体、Price 值对象、价格调整规则
- **购物车**：Cart 聚合根、CartItem 实体、添加/移除/数量变更
- **订单系统**：Order 聚合根、OrderStatus 值对象、状态转换规则、OrderPlaced 领域事件
- **支付处理**：PaymentStrategy 策略模式 + DI 容器组装
- **库存管理**：Inventory 聚合根、预留/释放/扣减机制

每节课的代码都会在前一课基础上演进，最终形成一个可运行的领域模型。

## 前置知识

- TypeScript 基础语法（接口、类、泛型）
- 阶段一的类型系统知识（联合类型、映射类型、条件类型）
- 基本的设计模式概念（了解 GoF 设计模式分类）

## 学习建议

1. **动手优先**：每段示例代码都要在本地运行，修改参数观察类型错误
2. **关注类型体操**：重点理解泛型参数如何在类型层面"传递信息"
3. **对比传统实现**：先理解 JavaScript 版本的痛点，再看 TypeScript 如何解决
4. **循序渐进**：课程按难度递进排列，01-04 是模式基础，05-06 是 DDD 应用
5. **重视练习**：每课练习是知识内化的关键，参考答案提供思路但要先自己尝试

## 技术环境

- TypeScript 5.x
- Node.js 18+

- 每课代码可独立运行，也可按顺序组合成完整项目
- 建议使用 VS Code + TypeScript 插件获得最佳类型提示体验

## 阶段考核标准

完成本阶段后，你应该能够：

- 独立实现类型安全的 Builder 模式，处理必填/可选字段约束

- 设计并实现一个轻量级 DI 容器，管理服务生命周期
- 构建类型安全的事件系统，支持优先级和通配符
- 用 DDD 战术模式对真实业务进行领域建模
