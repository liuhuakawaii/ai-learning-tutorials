# 03 - 依赖注入容器

## 场景引入

你的 Node.js 后端有 UserService、OrderService、PaymentService 三个服务。UserService 需要数据库连接和邮件服务，OrderService 需要 UserService 和库存服务。手动管理这些依赖关系，实例化顺序和生命周期让人头疼。有没有一种机制，声明"我需要什么"就能自动拿到正确的实例？

## 学习目标

- 理解控制反转（IoC）与依赖注入（DI）的核心思想
- 实现基于 Token 的类型安全 DI 容器
- 掌握构造函数注入的类型推导技巧
- 管理 singleton 与 transient 两种生命周期

## 一、控制反转与 Token 注册

控制反转的核心是：对象不自己创建依赖，而是从外部接收。Token 是依赖的"名字"：

```typescript
const TOKENS = {
  Database: Symbol('Database'),
  Logger: Symbol('Logger'),
  Config: Symbol('Config'),
} as const

interface Database {
  query<T>(sql: string): Promise<T[]>
  close(): Promise<void>
}

interface Logger {
  info(message: string): void
  error(message: string, error?: Error): void
}

interface Config {
  get<T>(key: string): T
}

class PostgresDatabase implements Database {
  async query<T>(sql: string): Promise<T[]> { return [] as T[] }
  async close() { console.log('[PG] 连接关闭') }
}

class ConsoleLogger implements Logger {
  info(message: string) { console.log(`[INFO] ${message}`) }
  error(message: string, error?: Error) { console.error(`[ERROR] ${message}`) }
}

class EnvConfig implements Config {
  get<T>(key: string): T { return process.env[key] as unknown as T }
}
```

## 二、类型安全的容器实现

容器用泛型约束确保 Token 和类型的对应关系：

```typescript
interface ServiceMap {
  [TOKENS.Database]: Database
  [TOKENS.Logger]: Logger
  [TOKENS.Config]: Config
}

type Lifecycle = 'singleton' | 'transient'

interface Registration<T> {
  factory: () => T
  lifecycle: Lifecycle
  instance?: T
}

class Container {
  private registrations = new Map<symbol, Registration<unknown>>()

  register<K extends symbol>(
    token: K,
    factory: K extends keyof ServiceMap ? () => ServiceMap[K] : never,
    lifecycle: Lifecycle = 'singleton'
  ): void {
    this.registrations.set(token, { factory, lifecycle })
  }

  resolve<K extends symbol>(
    token: K
  ): K extends keyof ServiceMap ? ServiceMap[K] : never {
    const reg = this.registrations.get(token) as Registration<any> | undefined
    if (!reg) throw new Error(`服务未注册: ${token.toString()}`)

    if (reg.lifecycle === 'singleton') {
      if (!reg.instance) reg.instance = reg.factory()
      return reg.instance
    }
    return reg.factory()
  }
}

const container = new Container()
container.register(TOKENS.Database, () => new PostgresDatabase())
container.register(TOKENS.Logger, () => new ConsoleLogger())

const db = container.resolve(TOKENS.Database) // 类型是 Database
const logger = container.resolve(TOKENS.Logger) // 类型是 Logger
```

## 三、构造函数注入与生命周期管理

真正的 DI 容器需要自动解析依赖链——创建 OrderService 时自动注入它需要的依赖：

```typescript
type DependencyToken<T> = symbol & { __type?: T }

function createToken<T>(name: string): DependencyToken<T> {
  return Symbol(name) as DependencyToken<T>
}

const DB = createToken<Database>('Database')
const LOG = createToken<Logger>('Logger')

interface ServiceRegistration<T> {
  factory: (container: AdvancedContainer) => T
  lifecycle: Lifecycle
  instance?: T
}

class AdvancedContainer {
  private registrations = new Map<symbol, ServiceRegistration<any>>()
  private resolving = new Set<symbol>()

  register<T>(
    token: DependencyToken<T>,
    factory: (container: this) => T,
    lifecycle: Lifecycle = 'singleton'
  ): void {
    this.registrations.set(token as symbol, { factory, lifecycle })
  }

  resolve<T>(token: DependencyToken<T>): T {
    const key = token as symbol
    const reg = this.registrations.get(key)
    if (!reg) throw new Error(`未注册: ${String(token)}`)

    if (this.resolving.has(key)) throw new Error(`循环依赖: ${String(token)}`)
    if (reg.lifecycle === 'singleton' && reg.instance) return reg.instance

    this.resolving.add(key)
    const instance = reg.factory(this)
    this.resolving.delete(key)

    if (reg.lifecycle === 'singleton') reg.instance = instance
    return instance
  }
}

// 业务服务
class UserService {
  constructor(private db: Database, private logger: Logger) {}
  async getUser(id: string) {
    this.logger.info(`查询用户: ${id}`)
    return this.db.query(`SELECT * FROM users WHERE id = '${id}'`)
  }
}

class OrderService {
  constructor(private userService: UserService, private logger: Logger) {}
  async createOrder(userId: string, items: string[]) {
    await this.userService.getUser(userId)
    this.logger.info(`创建订单: ${userId}, ${items.length} 件商品`)
    return { orderId: `order_${Date.now()}`, userId, items }
  }
}

// 注册并使用
const app = new AdvancedContainer()
app.register(DB, () => new PostgresDatabase())
app.register(LOG, () => new ConsoleLogger())

const USER = createToken<UserService>('UserService')
const ORDER = createToken<OrderService>('OrderService')

app.register(USER, (c) => new UserService(c.resolve(DB), c.resolve(LOG)))
app.register(ORDER, (c) => new OrderService(c.resolve(USER), c.resolve(LOG)))

const orderService = app.resolve(ORDER)
await orderService.createOrder('user_1', ['商品A', '商品B'])
```

容器自动解析依赖链，检测循环依赖，管理单例生命周期。

## 常见误区

1. **到处使用 DI 容器**：工具函数、纯计算逻辑不需要注入，DI 适合有状态、有依赖的服务
2. **Token 用字符串而非 Symbol**：字符串可能冲突，Symbol 保证唯一性
3. **忽略循环依赖检测**：A 依赖 B、B 依赖 A 会导致无限递归
4. **把所有服务都注册为 singleton**：有状态且需要独立实例的服务应使用 transient

## 工程建议

1. **Token 集中定义**：在一个文件中定义所有 Token，避免重复或冲突
2. **工厂函数中使用 `container.resolve`**：而非直接 `new` 依赖，保持依赖链可追踪
3. **考虑 async 工厂**：某些服务（如数据库连接）初始化是异步的
4. **配合装饰器使用**：用 `@injectable()` 和 `@inject(token)` 简化注册代码

## 小结

DI 容器的本质是**一个类型安全的服务注册表**。通过 Token 注册工厂函数，解析时自动处理依赖链和生命周期。TypeScript 的泛型系统让 Token 和类型的对应关系在编译期可检查。循环依赖检测和生命周期管理是容器的核心能力。

## 参考答案

### 练习一

**思路**：为每个请求创建子容器，子容器持有独立的 singleton 实例，共享父容器注册信息。

**答案**：

```typescript
class ScopedContainer {
  private registrations = new Map<symbol, (c: ScopedContainer) => any>()
  private singletons = new Map<symbol, any>()
  private parent?: ScopedContainer

  register<T>(token: symbol, factory: (c: ScopedContainer) => T) {
    this.registrations.set(token, factory)
  }

  resolve<T>(token: symbol): T {
    if (this.singletons.has(token)) return this.singletons.get(token)
    const factory = this.registrations.get(token) ?? this.parent?.registrations.get(token)
    if (!factory) throw new Error(`未注册: ${String(token)}`)
    const instance = factory(this)
    this.singletons.set(token, instance)
    return instance
  }

  createScope(): ScopedContainer {
    const child = new ScopedContainer()
    child.parent = this
    return child
  }
}

const root = new ScopedContainer()
root.register(Symbol('Config'), () => ({ env: 'production' }))
const req1 = root.createScope()
const req2 = root.createScope()
// req1.resolve 和 req2.resolve 得到独立实例
```

**要点**：子容器通过 `parent` 链查找注册信息，`singletons` Map 在每个作用域独立。

### 练习二

**思路**：用 `Reflect.getMetadata` 记录构造函数依赖，自动解析并注入。

**答案**：

```typescript
const DEPS_KEY = Symbol('deps')

function injectable(deps: symbol[]) {
  return function <T extends new (...args: any[]) => any>(constructor: T) {
    Reflect.defineMetadata(DEPS_KEY, deps, constructor)
    return constructor
  }
}

class AutoContainer {
  private factories = new Map<symbol, (c: AutoContainer) => any>()
  private singletons = new Map<symbol, any>()

  register<T>(token: symbol, factory: (c: AutoContainer) => T) { this.factories.set(token, factory) }

  registerClass<T>(token: symbol, cls: new (...args: any[]) => T) {
    const deps: symbol[] = Reflect.getMetadata(DEPS_KEY, cls) ?? []
    this.factories.set(token, (c) => new cls(...deps.map(d => c.resolve(d))))
  }

  resolve<T>(token: symbol): T {
    if (this.singletons.has(token)) return this.singletons.get(token)
    const factory = this.factories.get(token)
    if (!factory) throw new Error(`未注册: ${String(token)}`)
    const instance = factory(this)
    this.singletons.set(token, instance)
    return instance
  }
}

const DB = Symbol('Database')
const LOG = Symbol('Logger')

@injectable([DB, LOG])
class UserService {
  constructor(private db: Database, private logger: Logger) {}
}

const c = new AutoContainer()
c.register(DB, () => new PostgresDatabase())
c.register(LOG, () => new ConsoleLogger())
c.registerClass(Symbol('UserService'), UserService)
```

**要点**：`@injectable` 装饰器记录依赖 Token 列表，`registerClass` 自动解析依赖。

### 练习三

**思路**：`Lazy<T>` 用 `Proxy` 包装，只在属性被访问时才触发解析。

**答案**：

```typescript
function createLazy<T>(resolver: () => T): T {
  let instance: T | null = null
  const get = () => { if (!instance) instance = resolver(); return instance }

  return new Proxy({} as T, {
    get(_target, prop, receiver) {
      const value = Reflect.get(get(), prop, receiver)
      return typeof value === 'function' ? value.bind(get()) : value
    },
    set(_target, prop, value, receiver) {
      return Reflect.set(get(), prop, value, receiver)
    },
  })
}

// 使用：避免循环依赖
const lazyUser = createLazy(() => new UserService(app.resolve(DB), app.resolve(LOG)))
// 只有在调用 lazyUser.getUser() 时才真正解析依赖
```

**要点**：`Proxy` 的 `get` trap 在首次属性访问时触发解析，延迟解析打破循环依赖。
