# 系统监控工具 — 课程毕业项目

## 项目目标

构建一个实时系统监控工具，能够采集和展示操作系统的进程、内存、文件描述符、磁盘 IO 等关键指标。项目覆盖 OS 课程中的核心知识：进程管理、内存模型、文件系统、IO 调度、系统调用等。

## 技术栈

- **运行时**：Node.js 18+ 或 Python 3.10+
- **系统信息采集**：`/proc` 文件系统（Linux）或 `os` 模块（跨平台）
- **进程管理**：`child_process` / `psutil`
- **前端界面**：终端 TUI（`blessed`/`rich`）或 Web 仪表盘
- **图表**：实时折线图（内存趋势、CPU 趋势、IO 吞吐）
- **测试**：Vitest / pytest

## 核心功能

### 模块一：进程监控

- 列出所有运行中的进程：PID、名称、用户、CPU%、内存%、状态
- 支持按 CPU/内存/PID 排序
- 展示进程树（父子关系）
- 支持按名称或 PID 搜索进程
- 实时刷新（每秒更新）

### 模块二：内存监控

- 展示系统内存概览：总量、已用、空闲、缓存、交换区
- 进程级内存详情：RSS、VSZ、共享内存
- 内存使用趋势图（最近 60 秒）
- 检测内存异常：持续增长的进程（可能内存泄漏）
- OOM 风险评估：哪些进程占用最多内存

### 模块三：文件描述符监控

- 系统级文件描述符统计：已用/总量/限制
- 进程级文件描述符列表：类型（文件/socket/pipe）、路径、模式
- 检测文件描述符泄漏：持续增长的进程
- 展示打开文件最多的 Top N 进程

### 模块四：磁盘 IO 监控

- 磁盘分区信息：挂载点、文件系统、容量、已用
- 实时 IO 统计：读写速率、IO 等待时间、队列深度
- 按进程统计 IO：哪些进程读写最多
- IO 使用趋势图

### 模块五：告警与报告

- 可配置阈值告警：CPU > 90%、内存 > 85%、文件描述符 > 80% 限制
- 告警历史记录
- 生成系统健康报告（Markdown）
- 支持导出监控数据为 JSON

## 阶段交付物

| 阶段 | 交付物 | 路径 |
|------|--------|------|
| 阶段一 | 进程监控模块 | `sys-monitor/src/process/` |
| 阶段二 | 内存监控模块 | `sys-monitor/src/memory/` |
| 阶段三 | 文件描述符监控 | `sys-monitor/src/fd/` |
| 阶段四 | 磁盘 IO 监控 | `sys-monitor/src/io/` |
| 阶段五 | 告警与报告系统 | `sys-monitor/src/alert/` + `reports/final-report.md` |

## 验收标准

- [ ] 能实时列出系统进程，支持排序和搜索
- [ ] 内存监控能展示系统级和进程级内存使用，有趋势图
- [ ] 文件描述符监控能列出进程打开的文件，检测泄漏趋势
- [ ] IO 监控能展示读写速率，按进程统计 IO
- [ ] 告警系统在超过阈值时能触发告警并记录
- [ ] 能生成完整的系统健康报告（Markdown 格式）
- [ ] 所有核心模块有测试用例
- [ ] 项目可通过 `node scripts/check.js` 或 `python scripts/check.py` 验证结构完整性
