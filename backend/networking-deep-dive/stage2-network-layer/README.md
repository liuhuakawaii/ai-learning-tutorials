# 第二阶段：网络层

## 阶段目标

理解 IP 协议头部结构、子网划分、路由协议和 NAT 机制，能用 traceroute 定位网络路径中的瓶颈。

## 课时列表

1. [IP 协议——IPv4 头部、分片、TTL](06-IP协议.md)
2. [子网划分与 CIDR——从 /24 到 /16 的工程含义](07-子网划分与CIDR.md)
3. [路由协议——静态路由、OSPF、BGP 的直觉理解](08-路由协议.md)
4. [NAT 与防火墙——私有地址、端口映射、iptables](09-NAT与防火墙.md)
5. [阶段实战：用 traceroute/mtr 定位网络路径瓶颈](10-阶段实战-traceroute.md)

## 验收标准

- 能解读 IPv4 头部的每个字段含义（版本、TTL、协议号、校验和等）
- 能根据 CIDR 表示法计算子网范围和可用主机数
- 能解释静态路由与动态路由协议（OSPF/BGP）的区别和适用场景
- 能用 traceroute/mtr 定位网络路径中的延迟瓶颈
