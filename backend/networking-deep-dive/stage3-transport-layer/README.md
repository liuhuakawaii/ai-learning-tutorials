# 第三阶段：传输层

## 阶段目标

深入理解 TCP 连接管理、可靠传输、拥塞控制机制，以及 UDP 和 QUIC 的设计权衡，能用 iperf3 测量并分析传输层性能。

## 课时列表

1. [TCP 连接管理——三次握手、四次挥手、TIME_WAIT](11-TCP连接管理.md)
2. [TCP 可靠传输——序列号、确认号、重传机制](12-TCP可靠传输.md)
3. [TCP 拥塞控制——慢启动、拥塞避免、快重传、BBR](13-TCP拥塞控制.md)
4. [UDP 与 QUIC——为什么 HTTP/3 要用 UDP](14-UDP与QUIC.md)
5. [阶段实战：用 iperf3 测量 TCP/UDP 吞吐量并分析](15-阶段实战-iperf3.md)

## 验收标准

- 能画出 TCP 三次握手和四次挥手的状态转换图
- 能解释 TCP 滑动窗口、重传机制和拥塞控制算法的工作原理
- 能说明 BBR 与传统拥塞控制算法（Reno/Cubic）的区别
- 能用 iperf3 测量 TCP/UDP 吞吐量并分析结果
