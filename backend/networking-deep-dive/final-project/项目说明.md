# 网络诊断工具 — 课程毕业项目

## 项目目标

构建一个命令行或 Web 界面的网络诊断工具，集成 ping、traceroute、DNS 查询、TCP 连接测试等常用网络排查功能，并将结果以可视化方式呈现。项目覆盖网络课程中的核心知识：IP 寻址、路由、DNS 解析、TCP 三次握手/四次挥手、ICMP 协议等。

## 技术栈

- **运行时**：Node.js 18+ 或 Python 3.10+
- **原始套接字**：Node.js `dgram`/`net` 或 Python `socket`
- **DNS 解析**：`dns.resolve`（Node.js）或 `dnspython`
- **可视化**：终端表格 + ASCII 图 或 Web 前端（React/Vue）
- **图表**：终端用 `cli-chart`/`asciichart`，Web 用 ECharts/D3
- **测试**：Vitest / pytest

## 核心功能

### 模块一：Ping 工具

- 向目标主机发送 ICMP Echo Request，统计往返时间
- 支持指定次数、间隔、超时、包大小
- 输出统计摘要：丢包率、最小/最大/平均 RTT、标准差
- 支持持续 ping 模式，实时更新统计

### 模块二：Traceroute 工具

- 逐跳追踪到目标主机的路由路径
- 显示每一跳的 IP 地址、主机名（反向 DNS）、RTT
- 支持设置最大跳数、每跳探测次数
- 可视化路由路径（ASCII 图或拓扑图）

### 模块三：DNS 查询工具

- 支持查询 A、AAAA、CNAME、MX、NS、TXT、SOA 记录
- 展示完整的 DNS 解析链：递归查询过程
- 支持指定 DNS 服务器（对比不同解析器的结果）
- DNS 解析时间统计与缓存命中检测

### 模块四：TCP 连接测试

- 测试指定主机和端口的 TCP 连通性
- 测量 TCP 三次握手耗时
- 支持批量端口扫描（常用端口范围）
- 展示连接状态：Open / Closed / Filtered / Timeout

### 模块五：综合诊断报告

- 输入目标域名或 IP，自动运行全套诊断
- 生成结构化报告：网络路径、DNS 解析、端口状态、延迟分布
- 支持导出为 JSON 或 Markdown
- 与历史诊断结果对比，发现网络变化

## 阶段交付物

| 阶段 | 交付物 | 路径 |
|------|--------|------|
| 阶段一 | Ping 与基础 ICMP | `net-diagnostic/src/ping/` |
| 阶段二 | Traceroute 路由追踪 | `net-diagnostic/src/traceroute/` |
| 阶段三 | DNS 查询与解析链 | `net-diagnostic/src/dns/` |
| 阶段四 | TCP 连接测试与端口扫描 | `net-diagnostic/src/tcp/` |
| 阶段五 | 综合报告与可视化 | `net-diagnostic/src/report/` + `reports/final-report.md` |

## 验收标准

- [ ] Ping 功能能正确测量 RTT，输出丢包率和统计摘要
- [ ] Traceroute 能显示到目标的完整路由路径（至少部分跳数可见）
- [ ] DNS 查询支持至少 5 种记录类型，能展示解析链
- [ ] TCP 连接测试能判断端口 Open/Closed/Timeout 状态
- [ ] 综合诊断能对一个域名运行全套检查并输出结构化报告
- [ ] 可视化输出清晰，路由路径有拓扑展示
- [ ] 所有核心模块有测试用例
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
