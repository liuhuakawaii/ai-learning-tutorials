# 第一阶段：物理层与链路层

## 阶段目标

理解数据包从网卡到交换机的传输过程，掌握以太网帧结构、MAC 地址、VLAN、ARP 协议，能用 Wireshark 抓取并逐字节解读链路层帧。

## 课时列表

1. [数据包的旅程——从网卡到交换机的二进制世界](01-从网卡到交换机.md)
2. [以太网帧——MAC 地址、VLAN、ARP 协议](02-以太网帧.md)
3. [Wi-Fi 与无线网络——802.11 协议、信道、干扰](03-WiFi与无线网络.md)
4. [实验：用 Wireshark 抓取以太网帧并逐字节解读](04-实验-抓取以太网帧.md)
5. [阶段实战：搭建一个小型局域网并抓包分析](05-阶段实战-搭建局域网.md)

## 验收标准

- 能用 Wireshark 抓取以太网帧并解读 MAC 地址、类型字段和 FCS
- 能解释 ARP 协议的工作流程和 ARP 缓存的作用
- 能说明 VLAN 的作用和 802.1Q 标签帧的结构
- 能搭建一个小型局域网并验证连通性
