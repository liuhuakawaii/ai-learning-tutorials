# 第四阶段：应用层

## 阶段目标

理解 DNS 解析全流程、DHCP 自动配置、TLS 握手和负载均衡机制，能配置 DNS 并抓包观察完整的解析过程。

## 课时列表

1. [DNS 解析全流程——递归查询、权威服务器、缓存](16-DNS解析全流程.md)
2. [DHCP 与自动配置——IP 地址分配、租约、续期](17-DHCP与自动配置.md)
3. [TLS/SSL 握手——证书验证、密钥交换、会话恢复](18-TLS握手.md)
4. [负载均衡——L4/L7 区别、一致性哈希、健康检查](19-负载均衡.md)
5. [阶段实战：配置 DNS 并抓包观察完整解析过程](20-阶段实战-配置DNS.md)

## 验收标准

- 能解释 DNS 递归查询的完整过程（本地缓存 → 递归服务器 → 根 → 权威）
- 能说明 DHCP 的 IP 地址分配流程和租约续期机制
- 能画出 TLS 握手流程并解释证书验证和密钥交换过程
- 能区分 L4 和 L7 负载均衡的适用场景和实现方式
