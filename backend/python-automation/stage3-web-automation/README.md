# 阶段三：Web 自动化

> 6 课时 | 让脚本与互联网服务自动交互

## 阶段目标

掌握用 Python 与 Web 服务交互的能力：HTTP 请求、网页抓取、浏览器自动化、API 集成、邮件处理。学完这个阶段，你能构建定时抓取、自动通知等 Web 自动化工具。

## 课时列表

| 序号 | 名称 | 核心内容 |
|------|------|----------|
| 01 | HTTP 请求自动化 | requests、session、认证、限流 |
| 02 | 网页抓取与解析 | BeautifulSoup、lxml、动态页面 |
| 03 | 浏览器自动化 | Playwright、表单填写、截图 |
| 04 | API 集成 | REST API 封装、Webhook |
| 05 | 邮件自动化 | SMTP/IMAP、模板、附件 |
| 06 | 阶段实战：竞品监控系统 | 定时抓取 + 变更检测 + 通知 |

## 阶段实战

完成一个**竞品监控系统**，支持：
- 定时抓取竞品网页内容
- 检测页面变更（价格、文案、功能）
- 变更发生时自动发送邮件通知
- 监控历史记录和趋势分析

## 学完这个阶段你能做到

- 用 requests 调用各种 Web API
- 用 BeautifulSoup 抓取和解析网页
- 用 Playwright 自动化浏览器操作
- 用 Python 收发邮件
- 构建完整的 Web 自动化工作流
