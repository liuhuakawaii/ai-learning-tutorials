# 浏览器自动化

## 场景引入

你需要定期从一个内部管理后台导出报表，但这个后台没有 API，只能通过浏览器登录、点击菜单、选择日期、点击导出。手动操作每次需要 10 分钟。你需要一个脚本自动完成整个浏览器操作流程。Playwright 是微软开源的浏览器自动化工具，比 Selenium 更快、更稳定。

## 学习目标

- 掌握 Playwright 的安装和同步/异步 API
- 能进行页面导航、元素定位和表单操作
- 能实现截图和 PDF 生成
- 理解等待策略
- 对比 Selenium 和 Playwright 的差异

## 安装

```bash
pip install playwright
playwright install chromium
```

## 同步 API

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)  # 有头模式方便调试
    page = browser.new_page()
    page.goto("https://example.com")
    print(page.title())
    browser.close()
```

## 异步 API

```python
import asyncio
from playwright.async_api import async_playwright

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.launch()
        page = await browser.new_page()
        await page.goto("https://example.com")
        print(await page.title())
        await browser.close()

asyncio.run(main())
```

## 页面导航

```python
page.goto("https://example.com", timeout=30000)
page.goto("https://example.com", wait_until="networkidle")
page.go_back()
page.reload()
```

`wait_until` 可选 `"load"`、`"domcontentloaded"`、`"networkidle"`。

## 元素定位

```python
# CSS 选择器
page.locator("#submit-btn").click()

# 文本定位
page.get_by_text("登录").click()

# 角色定位（推荐）
page.get_by_role("button", name="提交").click()

# 占位文本和标签
page.get_by_placeholder("请输入用户名").fill("admin")
page.get_by_label("密码").fill("123456")
```

`get_by_role` 和 `get_by_label` 更接近用户视角，优先使用。

## 表单操作

```python
page.get_by_label("用户名").fill("admin")
page.get_by_label("密码").fill("secret")
page.get_by_label("城市").select_option("beijing")
page.get_by_label("记住密码").check()
page.get_by_role("button", name="登录").click()
```

## 截图和 PDF

```python
# 整页截图
page.screenshot(path="full.png", full_page=True)

# 元素截图
page.locator("header").screenshot(path="header.png")

# PDF（仅 headless 模式）
page.pdf(path="page.pdf", format="A4")
```

## 等待策略

```python
# 等待元素出现/消失
page.locator("#result").wait_for(timeout=10000)
page.locator("#loading").wait_for(state="hidden")

# 等待 API 请求完成
with page.expect_response("**/api/data") as resp_info:
    page.get_by_role("button", name="加载").click()
response = resp_info.value
```

Playwright 的 `click()`、`fill()` 自带自动等待，大多数场景无需手动等待。

## Selenium vs Playwright

| 特性 | Selenium | Playwright |
|------|----------|------------|
| 安装 | 需要 WebDriver | `playwright install` 一步到位 |
| 速度 | 较慢 | 快 2-3 倍 |
| 自动等待 | 需手动 WebDriverWait | 内置自动等待 |
| API 风格 | 面向对象 | 链式调用，更简洁 |
| 截图/PDF | 需额外配置 | 原生支持 |

新项目推荐 Playwright。维护旧 Selenium 代码无需迁移。

## 完整示例：自动填写表单并截图

```python
from playwright.sync_api import sync_playwright
from pathlib import Path
from datetime import datetime

def auto_fill_form(
    url: str,
    username: str,
    password: str,
    form_data: dict[str, str],
    screenshot_dir: str = "screenshots",
) -> str:
    dest = Path(screenshot_dir)
    dest.mkdir(parents=True, exist_ok=True)

    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()

        # 登录
        page.goto(url)
        page.get_by_label("用户名").fill(username)
        page.get_by_label("密码").fill(password)
        page.get_by_role("button", name="登录").click()
        page.wait_for_load_state("networkidle")

        # 填写表单
        for label, value in form_data.items():
            page.get_by_label(label).fill(value)

        # 截图
        ts = datetime.now().strftime("%Y%m%d_%H%M%S")
        path = str(dest / f"form_{ts}.png")
        page.screenshot(path=path, full_page=True)

        # 提交
        page.get_by_role("button", name="提交").click()
        page.wait_for_load_state("networkidle")

        # 提交后截图
        page.screenshot(path=str(dest / f"result_{ts}.png"), full_page=True)
        browser.close()
        return path

if __name__ == "__main__":
    path = auto_fill_form(
        url="https://internal.example.com/login",
        username="admin",
        password="secret",
        form_data={"项目名称": "自动化测试", "负责人": "张三", "备注": "自动生成"},
    )
    print(f"截图已保存: {path}")
```

## 常见误区

### 1. 用 time.sleep 代替等待

```python
# ❌ 硬等待，不稳定
time.sleep(3)
page.click("button")
# ✅ 自动等待
page.locator("button").click()
```

### 2. 选择器太脆弱

```python
# ❌ 依赖 DOM 结构
page.locator("div > div > span:nth-child(3)").click()
# ✅ 语义化定位
page.get_by_role("button", name="提交").click()
```

### 3. 忘记关闭浏览器

```python
# ❌ 进程泄漏
browser = p.chromium.launch()
# ✅ 用上下文管理器
with sync_playwright() as p:
    browser = p.chromium.launch()
    try:
        page = browser.new_page()
    finally:
        browser.close()
```

## 工程建议

1. **调试用 `headless=False`**：能看到操作过程
2. **优先用 `get_by_role`**：比 CSS 选择器更稳定
3. **截图留证**：关键步骤截图便于排查
4. **用 `expect_response` 等待 API**：比 sleep 精确
5. **并发用异步 API**：多页面并行用 `async_playwright`

本节学习了 Playwright 的安装和同步/异步 API、页面导航、元素定位、表单操作、截图和 PDF 生成、等待策略。Playwright 比 Selenium 更快更简洁，是浏览器自动化的首选工具。

## 参考答案

### 练习一

**思路**：用 `expect_download()` 捕获下载事件，点击导出按钮。

**答案**：

```python
from playwright.sync_api import sync_playwright
from pathlib import Path

def export_data(url: str, username: str, password: str, export_dir: str = "downloads") -> str:
    dest = Path(export_dir)
    dest.mkdir(parents=True, exist_ok=True)
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        page.goto(f"{url}/login")
        page.get_by_label("用户名").fill(username)
        page.get_by_label("密码").fill(password)
        page.get_by_role("button", name="登录").click()
        page.wait_for_load_state("networkidle")
        page.goto(f"{url}/data")
        page.wait_for_load_state("networkidle")
        with page.expect_download() as dl_info:
            page.get_by_role("button", name="导出").click()
        download = dl_info.value
        save_path = str(dest / download.suggested_filename)
        download.save_as(save_path)
        browser.close()
        return save_path
```

**要点**：`expect_download()` 上下文管理器捕获下载事件。

### 练习二

**思路**：遍历 URL 列表，按域名分目录截图。

**答案**：

```python
from playwright.sync_api import sync_playwright
from pathlib import Path
from urllib.parse import urlparse

def batch_screenshot(urls: list[str], output_dir: str = "screenshots") -> list[str]:
    dest = Path(output_dir)
    dest.mkdir(parents=True, exist_ok=True)
    results = []
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page(viewport={"width": 1280, "height": 720})
        for url in urls:
            try:
                page.goto(url, timeout=15000, wait_until="domcontentloaded")
                domain = urlparse(url).netloc.replace(".", "_")
                domain_dir = dest / domain
                domain_dir.mkdir(exist_ok=True)
                path = str(domain_dir / f"{domain}.png")
                page.screenshot(path=path, full_page=True)
                results.append(path)
            except Exception as e:
                print(f"失败 {url}: {e}")
        browser.close()
    return results
```

**要点**：`wait_until="domcontentloaded"` 比 `"load"` 更快。
