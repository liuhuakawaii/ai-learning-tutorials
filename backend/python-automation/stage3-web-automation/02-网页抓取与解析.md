# 网页抓取与解析

## 场景引入

你需要从一个新闻网站抓取每天的头条标题和摘要，汇总成日报。网页是 HTML 格式，包含大量无关的导航、广告和脚本代码。你需要从中精确提取目标数据。Python 的 `BeautifulSoup` 和 `lxml` 是处理这类任务的主力工具。

## 学习目标

- 掌握 BeautifulSoup 的 `find`、`find_all` 和 CSS 选择器
- 理解 lxml 解析器的性能优势
- 能处理动态渲染页面
- 了解常见反爬策略及应对方法

## BeautifulSoup 基础

### 创建解析对象与查找元素

```python
from bs4 import BeautifulSoup

html = """
<div class="article">
  <h2><a href="/news/1">AI 突破</a></h2>
  <p>人工智能取得重大进展...</p>
</div>
<div class="article">
  <h2><a href="/news/2">经济数据</a></h2>
  <p>最新 GDP 数据公布...</p>
</div>
"""
soup = BeautifulSoup(html, "html.parser")

# find 查找第一个匹配
title = soup.find("h2").text

# find_all 查找所有匹配
articles = soup.find_all("div", class_="article")
for article in articles:
    headline = article.find("h2").text
    summary = article.find("p").text
    print(f"{headline}: {summary}")

# CSS 选择器
links = soup.select("div.article h2 a")
title = soup.select_one("h1.title")
```

`select_one` 返回第一个匹配，`select` 返回所有匹配列表。CSS 选择器语法更简洁。

### 提取数据

```python
element = soup.find("a")
print(element.text)         # 文本内容
print(element["href"])      # 属性值
print(element.get("class")) # 安全获取（不存在返回 None）
```

## lxml 高性能解析

```python
from lxml import etree

tree = etree.HTML(html)
titles = tree.xpath('//h1[@class="title"]/text()')
links = tree.xpath('//div[@class="article"]//a/@href')
```

XPath 比 CSS 选择器功能更强，lxml 解析速度比 html.parser 快 5-10 倍。也可以组合使用：

```python
soup = BeautifulSoup(html, "lxml")  # 用 lxml 做底层，BeautifulSoup 做 API
```

## 反爬策略与应对

```python
import time, random, requests
from urllib.robotparser import RobotFileParser

# 设置 User-Agent
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36",
}

# 使用代理
proxies = {"http": "http://proxy.example.com:8080"}
resp = requests.get(url, headers=headers, proxies=proxies, timeout=10)

# 请求延迟
for url in urls:
    resp = requests.get(url, headers=headers, timeout=10)
    time.sleep(random.uniform(1, 3))

# 遵守 robots.txt
rp = RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()
if rp.can_fetch("*", url):
    resp = requests.get(url)
```

## 完整示例：抓取新闻标题和摘要

```python
import time
import random
import requests
from bs4 import BeautifulSoup
from dataclasses import dataclass
from urllib.robotparser import RobotFileParser

@dataclass
class NewsItem:
    title: str
    summary: str
    url: str

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36",
}

def can_fetch(base_url: str, path: str) -> bool:
    rp = RobotFileParser()
    rp.set_url(f"{base_url}/robots.txt")
    try:
        rp.read()
        return rp.can_fetch("*", f"{base_url}{path}")
    except Exception:
        return True

def fetch_news(base_url: str, path: str = "/news") -> list[NewsItem]:
    if not can_fetch(base_url, path):
        raise PermissionError("robots.txt 禁止抓取该路径")

    resp = requests.get(f"{base_url}{path}", headers=HEADERS, timeout=10)
    resp.raise_for_status()
    resp.encoding = resp.apparent_encoding

    soup = BeautifulSoup(resp.text, "lxml")
    items = []
    for article in soup.select("div.article"):
        title_el = article.select_one("h2 a")
        summary_el = article.select_one("p.summary")
        if title_el:
            items.append(NewsItem(
                title=title_el.text.strip(),
                summary=summary_el.text.strip() if summary_el else "",
                url=title_el.get("href", ""),
            ))
    return items

def scrape_multiple_pages(base_url: str, pages: int = 5) -> list[NewsItem]:
    all_news = []
    for page in range(1, pages + 1):
        try:
            news = fetch_news(base_url, f"/news?page={page}")
            all_news.extend(news)
            print(f"第 {page} 页: {len(news)} 条")
            time.sleep(random.uniform(1, 3))
        except requests.RequestException as e:
            print(f"第 {page} 页失败: {e}")
    return all_news
```

## 常见误区

### 1. 不处理编码

```python
# ❌ 中文乱码
text = resp.text
# ✅ 自动检测编码
resp.encoding = resp.apparent_encoding
text = resp.text
```

### 2. 选择器过于脆弱

```python
# ❌ 页面结构变了就失效
el = soup.find("div").find("table").find("tr").find("td")
# ✅ 用稳定的选择器
el = soup.select_one("h1.article-title")
```

### 3. 抓取速度过快被封

```python
# ❌ 连续高速请求
for url in urls:
    requests.get(url)
# ✅ 随机延迟
time.sleep(random.uniform(1, 3))
```

## 工程建议

1. **优先用 CSS 选择器**：可读性好，够用
2. **lxml 做大规模抓取**：解析速度快数倍
3. **遵守 robots.txt**：道德底线也是法律风险底线
4. **保存原始 HTML**：调试时分析本地文件比反复请求高效
5. **设置 User-Agent**：伪装浏览器减少被拦截

## 参考答案

### 练习一

**思路**：用 BeautifulSoup 解析 `<table>`，提取 `<th>` 表头和 `<td>` 数据行。

**答案**：

```python
import csv
import requests
from bs4 import BeautifulSoup

def table_to_csv(url: str, output: str, index: int = 0) -> int:
    resp = requests.get(url, timeout=10)
    resp.raise_for_status()
    resp.encoding = resp.apparent_encoding
    soup = BeautifulSoup(resp.text, "lxml")
    table = soup.find_all("table")[index]
    rows = []
    for row in table.find_all("tr"):
        cells = row.find_all(["th", "td"])
        rows.append([c.text.strip() for c in cells])
    with open(output, "w", newline="", encoding="utf-8-sig") as f:
        csv.writer(f).writerows(rows)
    return len(rows) - 1
```

**要点**：`utf-8-sig` 确保 Excel 打开中文不乱码。

### 练习二

**思路**：提取 `<img>` 的 `src`，用 `urljoin` 处理相对路径，流式下载。

**答案**：

```python
import requests
from pathlib import Path
from bs4 import BeautifulSoup
from urllib.parse import urljoin

def download_images(page_url: str, dest_dir: str) -> list[str]:
    dest = Path(dest_dir)
    dest.mkdir(parents=True, exist_ok=True)
    resp = requests.get(page_url, timeout=10)
    soup = BeautifulSoup(resp.text, "lxml")
    downloaded = []
    for img in soup.find_all("img"):
        src = img.get("src")
        if not src:
            continue
        full_url = urljoin(page_url, src)
        filename = full_url.split("/")[-1].split("?")[0]
        if "." not in filename:
            continue
        try:
            img_resp = requests.get(full_url, timeout=10, stream=True)
            img_resp.raise_for_status()
            with open(dest / filename, "wb") as f:
                for chunk in img_resp.iter_content(8192):
                    f.write(chunk)
            downloaded.append(filename)
        except Exception as e:
            print(f"失败 {full_url}: {e}")
    return downloaded
```

**要点**：`urljoin` 自动处理相对路径；跳过无扩展名的 base64 内联图片。
