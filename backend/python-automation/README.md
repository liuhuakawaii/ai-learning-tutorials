# Python 自动化脚本

> 30 课时 | 5 个阶段 | 面向有 Python 基础的开发者

## 课程定位

这门课不是教你 Python 语法，而是教你**用 Python 解决真实工作中的重复性问题**。每一节课都围绕一个具体的自动化场景展开，学完就能直接用在工作中。

**适合人群：**
- 有 Python 基础（会写函数、懂基本数据结构）
- 日常工作中有大量重复性手动操作
- 想用脚本提升效率但不知道从哪下手

**不适合：**
- 零基础学习者（先学 Python 基础）
- 只想了解概念不想写代码的人

## 学习路线

```
阶段一：脚本基础（6课时）
  ↓ 掌握写脚本的基本功
阶段二：文件与数据处理（6课时）
  ↓ 处理各种格式的文件和数据
阶段三：Web 自动化（6课时）
  ↓ 让脚本与网络服务交互
阶段四：系统自动化（6课时）
  ↓ 监控系统、管理进程、定时任务
阶段五：真实项目（6课时）
  ↓ 综合运用，完成完整项目
```

## 课程大纲

| 阶段 | 名称 | 课时 | 核心技能 |
|------|------|------|----------|
| 1 | 脚本基础 | 6 | 命令行工具、日志、配置管理 |
| 2 | 文件与数据处理 | 6 | pathlib、pandas、正则、PDF/Excel |
| 3 | Web 自动化 | 6 | requests、Playwright、邮件、API |
| 4 | 系统自动化 | 6 | 进程管理、定时任务、系统监控 |
| 5 | 真实项目 | 6 | 测试、CI/CD、备份、打包分发 |

## 环境要求

- Python 3.10+
- pip / pipenv / poetry（任选其一）
- 基本的命令行操作能力

## 学习建议

1. **每课都要动手写代码**，光看不练等于没学
2. **从你自己的痛点出发**，把课程示例改成你工作中能用的版本
3. **阶段实战是重点**，它是对整个阶段知识的综合运用
4. **遇到报错先自己查**，这是脚本开发最重要的能力之一
