# 阶段四：系统自动化

> 6 课时 | 用 Python 管理和监控你的系统

## 阶段目标

掌握用 Python 进行系统级自动化的能力：进程管理、定时任务、系统监控、数据库操作、网络工具。学完这个阶段，你能编写服务器巡检脚本和系统监控工具。

## 课时列表

| 序号 | 名称 | 核心内容 |
|------|------|----------|
| 01 | 进程管理 | subprocess、后台任务、进程监控 |
| 02 | 定时任务 | schedule、APScheduler、cron |
| 03 | 系统监控 | psutil、CPU/内存/磁盘监控 |
| 04 | 数据库操作 | sqlite3、SQLAlchemy、数据迁移 |
| 05 | 网络工具 | socket、端口扫描、DNS 查询 |
| 06 | 阶段实战：服务器巡检脚本 | 完整巡检 + 报告生成 |

## 阶段实战

完成一个**服务器巡检脚本**，支持：
- 检查 CPU、内存、磁盘使用率
- 检查关键进程是否运行
- 检查端口连通性
- 生成巡检报告（HTML/文本）
- 异常时自动发送告警

## 学完这个阶段你能做到

- 用 subprocess 管理系统进程
- 用 APScheduler 调度定时任务
- 用 psutil 监控系统资源
- 用 SQLAlchemy 操作数据库
- 编写完整的服务器巡检工具
