# 数据库操作

## 场景引入

你的自动化脚本需要持久化存储采集到的数据：监控指标、任务执行日志、配置信息。用文件存取效率低且查询困难，你需要用数据库来管理这些数据。Python 内置 `sqlite3` 适合轻量场景，`SQLAlchemy` 是生产级 ORM，能屏蔽数据库差异、管理连接池、支持事务。

## 学习目标

- 掌握 `sqlite3` 的基础 CRUD 操作
- 掌握 `SQLAlchemy` ORM 的模型定义、查询、事务
- 理解连接池管理和事务控制
- 能编写数据库备份和数据迁移脚本

## sqlite3 基础操作

```python
import sqlite3

conn = sqlite3.connect("app.db")
conn.execute("PRAGMA journal_mode=WAL")

conn.execute("""CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    status TEXT DEFAULT 'pending',
    created_at TEXT DEFAULT (datetime('now', 'localtime'))
)""")

conn.execute("INSERT INTO tasks (name, status) VALUES (?, ?)", ("数据同步", "pending"))
conn.commit()

cursor = conn.execute("SELECT * FROM tasks WHERE status = ?", ("pending",))
for row in cursor.fetchall():
    print(row)

conn.execute("UPDATE tasks SET status = 'done' WHERE id = ?", (1,))
conn.commit()
conn.close()
```

使用 `?` 占位符防止 SQL 注入。`conn.commit()` 必须显式调用。

### 上下文管理器

```python
import sqlite3

def get_connection(db_path="app.db"):
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    return conn

with get_connection() as conn:
    for row in conn.execute("SELECT * FROM tasks"):
        print(dict(row))
```

## SQLAlchemy ORM

### 模型定义

```python
from sqlalchemy import create_engine, Column, Integer, String, DateTime
from sqlalchemy.orm import declarative_base, sessionmaker
from datetime import datetime

Base = declarative_base()

class Task(Base):
    __tablename__ = "tasks"
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(100), nullable=False)
    status = Column(String(20), default="pending")
    created_at = Column(DateTime, default=datetime.now)
    updated_at = Column(DateTime, onupdate=datetime.now)

engine = create_engine("sqlite:///app.db", echo=False)
Base.metadata.create_all(engine)
Session = sessionmaker(bind=engine)
```

### CRUD 操作

```python
session = Session()

# 创建
task = Task(name="数据同步")
session.add(task)
session.commit()

# 查询
pending = session.query(Task).filter(Task.status == "pending").all()

# 更新
task.status = "done"
session.commit()

# 删除
session.query(Task).filter(Task.status == "cancelled").delete()
session.commit()

session.close()
```

### 事务管理

```python
def batch_update_status(session, from_status: str, to_status: str) -> int:
    try:
        tasks = session.query(Task).filter(Task.status == from_status).all()
        for t in tasks:
            t.status = to_status
        session.commit()
        return len(tasks)
    except Exception as e:
        session.rollback()
        raise RuntimeError(f"更新失败: {e}")
```

### 连接池管理

```python
from sqlalchemy import create_engine
from sqlalchemy.pool import QueuePool

engine = create_engine(
    "postgresql://user:pass@localhost/mydb",
    poolclass=QueuePool,
    pool_size=5,
    max_overflow=10,
    pool_timeout=30,
    pool_recycle=3600,
    pool_pre_ping=True
)
```

SQLite 不支持真正的连接池，连接池主要用于 PostgreSQL、MySQL。

## 原始 SQL vs ORM vs 查询构建器

| 特性 | 原始 SQL | ORM | 查询构建器 |
|------|---------|-----|-----------|
| 灵活性 | 最高 | 中等 | 高 |
| 类型安全 | 无 | 有 | 部分 |
| 可读性 | 取决于 SQL 功底 | 对象化 | 链式调用 |
| 数据库迁移 | 手动 | Alembic | 手动 |
| 适用场景 | 简单/性能敏感 | 复杂业务 | 中等复杂度 |

## 完整示例：数据库备份和迁移工具

```python
import sqlite3, shutil
from datetime import datetime
from pathlib import Path

class DatabaseTool:
    def __init__(self, db_path: str):
        self.db_path = db_path
        self.backup_dir = Path("backups")
        self.backup_dir.mkdir(exist_ok=True)

    def backup(self) -> str:
        ts = datetime.now().strftime("%Y%m%d_%H%M%S")
        path = self.backup_dir / f"backup_{ts}.db"
        shutil.copy2(self.db_path, path)
        size_mb = path.stat().st_size / 1024 / 1024
        print(f"备份: {path} ({size_mb:.2f}MB)")
        return str(path)

    def list_tables(self) -> list[str]:
        conn = sqlite3.connect(self.db_path)
        tables = [r[0] for r in conn.execute(
            "SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'"
        ).fetchall()]
        conn.close()
        return tables

    def migrate(self, target_path: str, table_name: str):
        src = sqlite3.connect(self.db_path)
        dst = sqlite3.connect(target_path)
        create_sql = src.execute(
            "SELECT sql FROM sqlite_master WHERE type='table' AND name=?", (table_name,)
        ).fetchone()
        if not create_sql:
            raise ValueError(f"表 {table_name} 不存在")
        dst.execute(create_sql[0])
        rows = src.execute(f"SELECT * FROM {table_name}").fetchall()
        if rows:
            placeholders = ",".join(["?"] * len(rows[0]))
            dst.executemany(f"INSERT INTO {table_name} VALUES ({placeholders})", rows)
            dst.commit()
        src.close(); dst.close()
        print(f"迁移: {len(rows)} 行 -> {target_path}")

    def cleanup_old_backups(self, keep_days=7):
        cutoff = datetime.now().timestamp() - keep_days * 86400
        removed = sum(1 for f in self.backup_dir.glob("backup_*.db")
                      if f.stat().st_mtime < cutoff and not f.unlink())
        print(f"清理了 {removed} 个过期备份")

if __name__ == "__main__":
    tool = DatabaseTool("app.db")
    tool.backup()
    print(f"表: {tool.list_tables()}")
    tool.migrate("archive.db", "tasks")
```

## 常见误区

1. **忘记 `commit()`**：sqlite3 不自动提交，不调用 `commit()` 数据不持久化。
2. **SQL 注入**：用 f-string 拼接 SQL 是最常见漏洞，始终用参数化查询。
3. **不关闭连接**：长期运行脚本不关闭连接导致泄漏，用 `with` 或 `try/finally`。
4. **SQLite 并发写入**：写锁是数据库级别的，高并发应换 PostgreSQL/MySQL。
5. **ORM N+1 查询**：循环中访问关联对象触发大量查询，用 `joinedload` 预加载。

## 工程建议

1. **轻量场景用 SQLite**：配置数据、本地缓存、单机脚本，零配置且性能优秀。
2. **生产环境用 SQLAlchemy**：模型清晰、多数据库支持、连接池完善。
3. **WAL 模式**：`PRAGMA journal_mode=WAL` 大幅提升并发读写性能。
4. **定期备份**：`shutil.copy2` 是 SQLite 最简单的备份方式。

### 练习一

**思路**：用 `sessionmaker` 创建会话，每个方法独立开关会话。

**答案**：

```python
from sqlalchemy import create_engine, Column, Integer, String, DateTime
from sqlalchemy.orm import declarative_base, sessionmaker
from datetime import datetime

Base = declarative_base()

class Task(Base):
    __tablename__ = "tasks"
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(100), nullable=False)
    status = Column(String(20), default="pending")
    created_at = Column(DateTime, default=datetime.now)

engine = create_engine("sqlite:///app.db")
Base.metadata.create_all(engine)
SessionFactory = sessionmaker(bind=engine)

class TaskRepository:
    def create(self, name, status="pending"):
        s = SessionFactory()
        try:
            t = Task(name=name, status=status)
            s.add(t); s.commit(); s.refresh(t)
            return t
        finally:
            s.close()

    def get_by_id(self, task_id):
        s = SessionFactory()
        try: return s.query(Task).get(task_id)
        finally: s.close()

    def list_by_status(self, status):
        s = SessionFactory()
        try: return s.query(Task).filter(Task.status == status).all()
        finally: s.close()

    def update_status(self, task_id, new_status):
        s = SessionFactory()
        try:
            t = s.query(Task).get(task_id)
            if not t: return False
            t.status = new_status; s.commit()
            return True
        finally: s.close()

    def delete(self, task_id):
        s = SessionFactory()
        try:
            c = s.query(Task).filter(Task.id == task_id).delete()
            s.commit(); return c > 0
        finally: s.close()
```

**要点**：每个方法独立开关会话，避免跨方法的状态泄漏。

### 练习二

**思路**：用模型的 `__table__.columns` 获取字段名作为表头。

**答案**：

```python
import csv

def export_to_csv(session, model_class, output_path, filters=None):
    query = session.query(model_class)
    if filters:
        for k, v in filters.items():
            query = query.filter(getattr(model_class, k) == v)
    rows = query.all()
    if not rows:
        return
    columns = [c.name for c in model_class.__table__.columns]
    with open(output_path, "w", newline="", encoding="utf-8-sig") as f:
        writer = csv.writer(f)
        writer.writerow(columns)
        for row in rows:
            writer.writerow([getattr(row, c) for c in columns])
    print(f"导出 {len(rows)} 行到 {output_path}")
```

**要点**：`utf-8-sig` 编码让 Excel 正确识别中文列名。
