# 毕业项目：Python 自动化工具箱

## 项目概述

综合运用本课程所有技能，构建一个功能完整的 Python 自动化工具箱。工具箱以统一的命令行界面提供多种自动化功能，涵盖文件处理、Web 监控、系统巡检、报表生成四大模块。

## 项目目标

- 巩固 5 个阶段 30 课时所学的全部知识
- 体验从零构建完整工具的全过程（设计→实现→测试→打包）
- 产出一个可在实际工作中使用的工具

## 功能需求

### 核心模块

| 模块 | 功能 | 对应阶段 |
|------|------|----------|
| 文件处理 | 批量重命名、文件分类、数据清洗 | 阶段二 |
| Web 监控 | 网页抓取、变更检测、API 调用 | 阶段三 |
| 系统巡检 | CPU/内存/磁盘监控、进程检查 | 阶段四 |
| 报表生成 | Excel/PDF 报表、邮件发送 | 阶段五 |

### 技术要求

1. **统一入口**：使用 click 构建 CLI，每个模块作为子命令
2. **配置管理**：YAML 配置文件 + 环境变量
3. **日志记录**：完整的 logging 配置，支持文件和控制台输出
4. **错误处理**：异常捕获、重试机制、友好的错误提示
5. **测试覆盖**：pytest 测试套件，核心功能覆盖率 > 80%
6. **打包分发**：支持 pip 安装和 PyInstaller 打包

## 实现阶段

### 第一步：项目骨架（1小时）

1. 创建项目目录结构
2. 初始化 pyproject.toml
3. 实现 CLI 入口和配置管理
4. 实现日志模块

### 第二步：文件处理模块（2小时）

1. 实现批量重命名功能
2. 实现文件自动分类
3. 实现数据清洗功能
4. 编写测试用例

### 第三步：Web 监控模块（2小时）

1. 实现网页抓取器
2. 实现变更检测器
3. 实现通知发送器
4. 编写测试用例

### 第四步：系统巡检模块（2小时）

1. 实现系统资源监控
2. 实现进程和端口检查
3. 实现巡检报告生成
4. 编写测试用例

### 第五步：报表生成模块（2小时）

1. 实现 Excel 报表生成
2. 实现 PDF 报告生成
3. 实现邮件发送功能
4. 编写测试用例

### 第六步：整合与打包（1小时）

1. 整合所有模块到 CLI
2. 运行完整测试套件
3. 打包为可执行文件
4. 编写使用文档
