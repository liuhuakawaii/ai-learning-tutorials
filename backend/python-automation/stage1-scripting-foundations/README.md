# 阶段一：脚本基础

> 6 课时 | 从零搭建你的自动化脚本开发能力

## 阶段目标

掌握编写 Python 自动化脚本的基本功：环境搭建、命令行交互、日志记录、配置管理。学完这个阶段，你能写出一个结构清晰、可维护的命令行工具。

## 课时列表

| 序号 | 名称 | 核心内容 |
|------|------|----------|
| 01 | 脚本思维与自动化价值 | 什么值得自动化、ROI 计算 |
| 02 | Python 脚本环境 | 虚拟环境、依赖管理、跨平台兼容 |
| 03 | 命令行参数与交互 | argparse、click、rich |
| 04 | 日志与错误处理 | logging、异常捕获、重试机制 |
| 05 | 配置文件管理 | YAML/TOML/JSON、环境变量 |
| 06 | 阶段实战：批量文件重命名工具 | 综合运用本阶段所有技能 |

## 阶段实战

完成一个**批量文件重命名工具**，支持：
- 命令行指定目录和命名规则
- 正则替换、序号填充、日期前缀
- 预览模式（不实际修改）
- 完整的日志记录和错误处理

## 学完这个阶段你能做到

- 用 argparse 或 click 构建专业的命令行界面
- 用 logging 模块记录脚本运行日志
- 用配置文件管理脚本参数
- 写出结构清晰、可维护的脚本
