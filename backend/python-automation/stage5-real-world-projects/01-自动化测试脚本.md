# 自动化测试脚本

## 为什么要写测试

你写了一个工具函数库，包含字符串处理、日期计算。项目初期一切正常，但随着功能增多，每次修改都要手动测试所有功能。某天重构了日期模块，上线后字符串处理也出问题——因为共用了一个底层函数。

自动化测试解决的是：**用代码验证代码**，每次修改后一键运行，几秒内确认所有功能是否正常。

## pytest 基础

pytest 的发现规则：文件名以 `test_` 开头或 `_test` 结尾，函数名以 `test_` 开头。

```bash
pip install pytest
pytest                        # 运行所有测试
pytest test_utils.py          # 指定文件
pytest -v                     # 详细输出
pytest -x                     # 失败即停
pytest -s                     # 显示 print
```

pytest 使用 Python 原生 `assert`，失败时自动展示对比信息：

```python
from string_utils import slugify, truncate, camel_to_snake

def test_slugify_basic():
    assert slugify("Hello World") == "hello-world"

def test_slugify_special_chars():
    assert slugify("Hello, World! @2024") == "hello-world-2024"

def test_truncate_long():
    result = truncate("这是一段很长的文本内容需要被截断", max_length=10)
    assert result.endswith("...")

def test_camel_to_snake():
    assert camel_to_snake("getUserName") == "get_user_name"
    assert camel_to_snake("HTTPResponse") == "http_response"
```

## Fixture

fixture 提供测试的前置准备和后置清理，`yield` 之前是 setup，之后是 teardown：

```python
import tempfile, shutil, os, pytest

@pytest.fixture
def temp_dir():
    dir_path = tempfile.mkdtemp()
    yield dir_path
    shutil.rmtree(dir_path)

def test_create_file(temp_dir):
    path = os.path.join(temp_dir, "test.txt")
    with open(path, "w") as f:
        f.write("hello")
    assert os.path.exists(path)
```

作用域：`scope="function"`（默认，每个测试函数创建一次）、`scope="module"`（每个模块一次）、`scope="session"`（整个会话一次）。

`autouse=True` 让 fixture 自动应用于所有测试：

```python
import time

@pytest.fixture(autouse=True)
def timer():
    start = time.time()
    yield
    duration = time.time() - start
    if duration > 1.0:
        print(f"\n测试耗时较长: {duration:.2f}s")
```

## 参数化测试

用 `@pytest.mark.parametrize` 避免重复：

```python
@pytest.mark.parametrize("input_text,expected", [
    ("Hello World", "hello-world"),
    ("  spaces  ", "spaces"),
    ("UPPER CASE", "upper-case"),
    ("already-slug", "already-slug"),
])
def test_slugify(input_text, expected):
    assert slugify(input_text) == expected

@pytest.mark.parametrize("email,valid", [
    ("user@example.com", True),
    ("user+tag@domain.co.uk", True),
    ("invalid", False),
    ("@example.com", False),
])
def test_email(email, valid):
    assert is_valid_email(email) == valid
```

## 测试标记

```python
@pytest.mark.skip(reason="功能尚未实现")
def test_future_feature():
    pass

@pytest.mark.skipif(sys.platform == "win32", reason="仅 Linux")
def test_linux_only():
    pass

@pytest.mark.xfail(reason="已知 bug")
def test_known_bug():
    assert 1 + 1 == 3
```

```bash
pytest -m slow            # 只运行 slow
pytest -m "not slow"      # 跳过 slow
```

## 踩坑提醒

**测试中包含业务逻辑**：测试只做断言，不要实现复杂处理。

**过度 mock**：只 mock 外部依赖，不要 mock 被测函数本身。

**测试之间有依赖**：每个测试必须能独立运行。

**断言太宽泛**：`assert result is not None` 几乎没意义。

### 练习一：基础测试编写

为以下函数编写至少 5 个测试用例，覆盖正常情况、边界条件和异常输入：

```python
def parse_amount(text: str) -> float:
    if not text or not isinstance(text, str):
        raise ValueError("输入不能为空")
    cleaned = text.replace("¥", "").replace(",", "").replace(" ", "")
    try:
        return float(cleaned)
    except ValueError:
        raise ValueError(f"无法解析金额: {text}")
```

## 参考答案

### 练习一

```python
import pytest
from amount_parser import parse_amount

def test_plain_number():
    assert parse_amount("1234.56") == 1234.56

def test_with_currency():
    assert parse_amount("¥1,234.56") == 1234.56

def test_zero():
    assert parse_amount("0") == 0.0

def test_negative():
    assert parse_amount("-42.5") == -42.5

def test_empty_raises():
    with pytest.raises(ValueError, match="输入不能为空"):
        parse_amount("")

def test_none_raises():
    with pytest.raises(ValueError, match="输入不能为空"):
        parse_amount(None)

def test_non_numeric_raises():
    with pytest.raises(ValueError, match="无法解析金额"):
        parse_amount("abc")
```

`pytest.raises` 验证异常，`match` 参数验证消息内容。

### 练习二

```python
import pytest

class Stack:
    def __init__(self, maxsize=10):
        self._data, self._maxsize = [], maxsize
    def push(self, item):
        if len(self._data) >= self._maxsize:
            raise OverflowError("栈已满")
        self._data.append(item)
    def pop(self):
        if not self._data:
            raise IndexError("栈为空")
        return self._data.pop()
    @property
    def size(self):
        return len(self._data)

@pytest.fixture
def empty_stack():
    return Stack(maxsize=5)

@pytest.fixture
def filled_stack():
    s = Stack(maxsize=5)
    for i in [1, 2, 3]:
        s.push(i)
    return s

@pytest.mark.parametrize("items", [[1], [1, 2, 3], ["a", "b"]])
def test_push_pop(items, empty_stack):
    for item in items:
        empty_stack.push(item)
    for item in reversed(items):
        assert empty_stack.pop() == item

def test_pop_empty_raises(empty_stack):
    with pytest.raises(IndexError):
        empty_stack.pop()

def test_push_full_raises(filled_stack):
    filled_stack.push(4)
    filled_stack.push(5)
    with pytest.raises(OverflowError):
        filled_stack.push(6)
```
