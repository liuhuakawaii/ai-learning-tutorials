# 阶段五：真实项目

> 6 课时 | 综合运用所有技能，完成真实项目

## 阶段目标

将前四个阶段学到的技能综合运用到真实项目中：自动化测试、CI/CD 辅助脚本、数据备份、报表生成、脚本打包。学完这个阶段，你具备独立完成完整自动化项目的能力。

## 课时列表

| 序号 | 名称 | 核心内容 |
|------|------|----------|
| 01 | 自动化测试脚本 | pytest、fixture、参数化 |
| 02 | CI/CD 辅助脚本 | 构建、部署、回滚脚本 |
| 03 | 数据备份与同步 | 增量备份、rsync、云存储 |
| 04 | 报表自动生成 | 定时报表、Excel/PDF 输出 |
| 05 | 脚本打包与分发 | PyInstaller、pipx、Docker |
| 06 | 阶段实战：完整自动化工具箱 | 整合所有技能 |

## 阶段实战

完成一个**完整自动化工具箱**，包含：
- 统一的命令行入口
- 文件处理模块
- Web 监控模块
- 系统巡检模块
- 报表生成模块
- 完整的测试套件
- 打包为可分发的工具

## 学完这个阶段你能做到

- 用 pytest 编写自动化测试
- 编写 CI/CD 流水线辅助脚本
- 实现数据备份和同步方案
- 自动生成 Excel/PDF 报表
- 将脚本打包为可分发的工具
- 独立完成完整的自动化项目
