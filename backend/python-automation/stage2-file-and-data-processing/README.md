# 阶段二：文件与数据处理

> 6 课时 | 让 Python 帮你处理各种格式的文件和数据

## 阶段目标

掌握用 Python 处理常见文件格式的能力：文件系统操作、CSV/Excel 读写、PDF/Word 处理、图片批量操作、正则文本提取。学完这个阶段，你能搭建完整的数据处理流水线。

## 课时列表

| 序号 | 名称 | 核心内容 |
|------|------|----------|
| 01 | 文件系统操作 | pathlib、shutil、watchdog |
| 02 | CSV 与 Excel 处理 | pandas、openpyxl、数据清洗 |
| 03 | PDF 与文档处理 | PyPDF2、python-docx、报告生成 |
| 04 | 图片批量处理 | Pillow、压缩、水印、格式转换 |
| 05 | 正则表达式 | re 模块、常见模式、文本提取 |
| 06 | 阶段实战：数据清洗 Pipeline | 完整数据处理流水线 |

## 阶段实战

完成一个**数据清洗 Pipeline**，支持：
- 读取多种格式的原始数据（CSV、Excel、JSON）
- 自动清洗（去重、类型转换、缺失值处理）
- 数据验证和质量报告
- 输出清洗后的数据和统计摘要

## 学完这个阶段你能做到

- 用 pathlib 优雅地操作文件系统
- 用 pandas 高效处理表格数据
- 用 Pillow 批量处理图片
- 用正则表达式提取和转换文本
- 搭建完整的数据清洗流水线
