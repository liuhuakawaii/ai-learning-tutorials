# Stage 2：结构化提示词 — 写出可维护的 Prompt

> 学会用模板引擎和结构化方法管理 Prompt，使其可复用、可组合、易维护。

## 学习目标

完成本阶段后，你将能够：

- 用模板化思维管理 Prompt，消除硬编码
- 使用 Jinja2 构建可复用的 Prompt 模板
- 设计 Few-shot 示例选择策略，提升输出质量
- 运用 Chain-of-Thought 技术处理复杂推理任务
- 编排多轮对话，管理上下文窗口
- 对 Prompt 进行版本管理，支持回滚和对比
