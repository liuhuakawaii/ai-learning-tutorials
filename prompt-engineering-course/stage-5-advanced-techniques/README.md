## 学习目标

完成本阶段后，你将能够：

- 使用 Function Calling 让 LLM 调用外部工具
- 设计 ReAct 模式的 Agent 架构
- 处理多模态输入（图片、音频、视频）
- 用 DSPy 思想实现 Prompt 自动优化
- 构建多 Agent 协作的系统级 Prompt 架构
- 完成综合实战项目，整合课程全部知识
