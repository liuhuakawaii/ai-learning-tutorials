## 场景引入

2023 年底，某 AI 平台遭遇了一次持续数天的慢速数据窃取攻击。攻击者通过一个低权限账户，以每分钟 2-3 次的频率向模型发送精心构造的 Prompt，逐步提取训练数据中的敏感信息。由于系统没有完善的审计日志和监控告警机制，这种低频异常行为完全未被发现。直到一名运维人员偶然在数据库慢查询日志中注意到异常的数据读取模式，才意识到系统已经被入侵——此时攻击者已经持续活动了 11 天。事后复盘，如果系统对用户请求频率、模型调用模式和异常输出内容有完整的审计日志和实时监控，这次攻击在第一天就能被发现和阻断。

```python
from typing import Dict, Any, Optional, List
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from enum import Enum
import json
import hashlib
import uuid
import threading
from collections import defaultdict


class LogLevel(Enum):
    DEBUG = "debug"
    INFO = "info"
    WARNING = "warning"
    ERROR = "error"
    SECURITY = "security"


@dataclass
class AuditLog:
    log_id: str
    timestamp: datetime
    level: LogLevel
    event_type: str
    user_id: Optional[str]
    ip_address: Optional[str]
    details: Dict[str, Any]
    metadata: Dict[str, Any] = field(default_factory=dict)
    trace_id: Optional[str] = None
    session_id: Optional[str] = None


class LogStorage:
    """日志存储后端接口"""

    def store(self, log: AuditLog):
        raise NotImplementedError

    def query(self, filters: Dict = None, start_time: datetime = None,
              end_time: datetime = None, limit: int = 100) -> List[AuditLog]:
        raise NotImplementedError


class InMemoryStorage(LogStorage):
    """内存存储后端（开发/测试用）"""

    def __init__(self, max_size: int = 10000):
        self.logs: List[AuditLog] = []
        self.max_size = max_size
        self._lock = threading.Lock()

    def store(self, log: AuditLog):
        with self._lock:
            self.logs.append(log)
            if len(self.logs) > self.max_size:
                self.logs = self.logs[-self.max_size:]

    def query(self, filters: Dict = None, start_time: datetime = None,
              end_time: datetime = None, limit: int = 100) -> List[AuditLog]:
        with self._lock:
            results = self.logs

            if start_time:
                results = [l for l in results if l.timestamp >= start_time]
            if end_time:
                results = [l for l in results if l.timestamp <= end_time]
            if filters:
                for key, value in filters.items():
                    if key == "level":
                        results = [l for l in results if l.level == value]
                    elif key == "event_type":
                        results = [l for l in results if l.event_type == value]
                    elif key == "user_id":
                        results = [l for l in results if l.user_id == value]

            return results[-limit:]


class AuditLogger:
    """审计日志记录器"""

    def __init__(self, storage: LogStorage = None):
        self.storage = storage or InMemoryStorage()
        self.handlers: List[Any] = []
        self._stats = defaultdict(int)

    def _generate_id(self) -> str:
        return uuid.uuid4().hex[:12]

    def log(self, level: LogLevel, event_type: str,
            user_id: str = None, ip_address: str = None,
            details: Dict = None, trace_id: str = None,
            session_id: str = None, **kwargs):
        log_entry = AuditLog(
            log_id=self._generate_id(),
            timestamp=datetime.now(),
            level=level,
            event_type=event_type,
            user_id=user_id,
            ip_address=ip_address,
            details=details or {},
            metadata=kwargs,
            trace_id=trace_id,
            session_id=session_id,
        )

        self.storage.store(log_entry)
        self._stats[level.value] += 1

        for handler in self.handlers:
            try:
                handler.handle(log_entry)
            except Exception:
                pass

        return log_entry

    def log_request(self, user_id: str, endpoint: str,
                    method: str, status_code: int,
                    processing_time: float, ip_address: str = None):
        return self.log(
            level=LogLevel.INFO,
            event_type="api_request",
            user_id=user_id,
            ip_address=ip_address,
            details={
                "endpoint": endpoint,
                "method": method,
                "status_code": status_code,
                "processing_time_ms": round(processing_time * 1000, 2),
            },
        )

    def log_security_event(self, event_type: str, user_id: str,
                           threat_level: str, details: Dict,
                           ip_address: str = None):
        return self.log(
            level=LogLevel.SECURITY,
            event_type=event_type,
            user_id=user_id,
            ip_address=ip_address,
            details={"threat_level": threat_level, **details},
        )

    def log_error(self, error_type: str, error_message: str,
                  user_id: str = None, stack_trace: str = None):
        return self.log(
            level=LogLevel.ERROR,
            event_type=error_type,
            user_id=user_id,
            details={"error_message": error_message, "stack_trace": stack_trace},
        )

    def log_model_call(self, user_id: str, model_name: str,
                       input_tokens: int, output_tokens: int,
                       latency_ms: float, success: bool):
        return self.log(
            level=LogLevel.INFO,
            event_type="model_call",
            user_id=user_id,
            details={
                "model": model_name,
                "input_tokens": input_tokens,
                "output_tokens": output_tokens,
                "latency_ms": latency_ms,
                "success": success,
            },
        )

    def get_stats(self) -> Dict:
        return dict(self._stats)

    def query_logs(self, **kwargs) -> List[AuditLog]:
        return self.storage.query(**kwargs)
```

### 2.2 监控实现

```python
from typing import Dict, List, Callable, Optional
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from enum import Enum
from collections import deque
import statistics
import threading
import time


class AlertSeverity(Enum):
    INFO = "info"
    WARNING = "warning"
    CRITICAL = "critical"


class AlertStatus(Enum):
    FIRING = "firing"
    RESOLVED = "resolved"
    ACKNOWLEDGED = "acknowledged"


@dataclass
class Metric:
    name: str
    value: float
    timestamp: datetime
    labels: Dict[str, str] = field(default_factory=dict)


@dataclass
class AlertRule:
    name: str
    metric_name: str
    condition: str  # "gt", "lt", "eq", "anomaly"
    threshold: float
    severity: AlertSeverity
    duration_seconds: int = 0
    description: str = ""


@dataclass
class Alert:
    alert_id: str
    rule_name: str
    metric_name: str
    severity: AlertSeverity
    status: AlertStatus
    current_value: float
    threshold: float
    message: str
    fired_at: datetime
    resolved_at: Optional[datetime] = None
    acknowledged_at: Optional[datetime] = None


class MonitoringSystem:
    """实时监控系统"""

    def __init__(self, window_size: int = 1000):
        self.metrics: Dict[str, deque] = {}
        self.alert_rules: Dict[str, AlertRule] = {}
        self.active_alerts: Dict[str, Alert] = {}
        self.alert_history: List[Alert] = []
        self.alert_handlers: List[Callable] = []
        self.window_size = window_size
        self._lock = threading.Lock()

    def register_metric(self, name: str):
        with self._lock:
            self.metrics[name] = deque(maxlen=self.window_size)

    def record_metric(self, name: str, value: float, labels: Dict = None):
        with self._lock:
            if name not in self.metrics:
                self.metrics[name] = deque(maxlen=self.window_size)
            self.metrics[name].append(Metric(
                name=name, value=value,
                timestamp=datetime.now(), labels=labels or {},
            ))

        self._evaluate_rules(name, value)

    def add_alert_rule(self, rule: AlertRule):
        self.alert_rules[rule.name] = rule

    def add_alert_handler(self, handler: Callable):
        self.alert_handlers.append(handler)

    def _evaluate_rules(self, metric_name: str, value: float):
        for rule_name, rule in self.alert_rules.items():
            if rule.metric_name != metric_name:
                continue

            triggered = False
            if rule.condition == "gt" and value > rule.threshold:
                triggered = True
            elif rule.condition == "lt" and value < rule.threshold:
                triggered = True
            elif rule.condition == "eq" and value == rule.threshold:
                triggered = True

            if triggered and rule_name not in self.active_alerts:
                alert = Alert(
                    alert_id=f"alert_{int(time.time())}_{rule_name}",
                    rule_name=rule_name,
                    metric_name=metric_name,
                    severity=rule.severity,
                    status=AlertStatus.FIRING,
                    current_value=value,
                    threshold=rule.threshold,
                    message=f"{metric_name} = {value} {rule.condition} {rule.threshold}",
                    fired_at=datetime.now(),
                )
                self.active_alerts[rule_name] = alert
                self.alert_history.append(alert)
                self._notify_alert(alert)

            elif not triggered and rule_name in self.active_alerts:
                alert = self.active_alerts.pop(rule_name)
                alert.status = AlertStatus.RESOLVED
                alert.resolved_at = datetime.now()
                self._notify_alert(alert)

    def _notify_alert(self, alert: Alert):
        for handler in self.alert_handlers:
            try:
                handler(alert)
            except Exception:
                pass

    def get_metric_stats(self, name: str, window_minutes: int = 5) -> Dict:
        with self._lock:
            if name not in self.metrics:
                return {}

            cutoff = datetime.now() - timedelta(minutes=window_minutes)
            values = [m.value for m in self.metrics[name] if m.timestamp >= cutoff]

            if not values:
                return {}

            return {
                "count": len(values),
                "min": min(values),
                "max": max(values),
                "avg": statistics.mean(values),
                "median": statistics.median(values),
                "stddev": statistics.stdev(values) if len(values) > 1 else 0,
                "p95": sorted(values)[int(len(values) * 0.95)] if len(values) >= 2 else values[0],
                "latest": values[-1],
            }

    def get_active_alerts(self) -> List[Alert]:
        return list(self.active_alerts.values())

    def acknowledge_alert(self, alert_id: str) -> bool:
        for alert in self.active_alerts.values():
            if alert.alert_id == alert_id:
                alert.status = AlertStatus.ACKNOWLEDGED
                alert.acknowledged_at = datetime.now()
                return True
        return False


# 使用示例
monitor = MonitoringSystem()

# 注册指标
monitor.register_metric("request_count")
monitor.register_metric("error_rate")
monitor.register_metric("response_time")
monitor.register_metric("injection_attempts")

# 添加告警规则
monitor.add_alert_rule(AlertRule(
    name="high_error_rate",
    metric_name="error_rate",
    condition="gt",
    threshold=0.05,
    severity=AlertSeverity.CRITICAL,
    description="错误率超过 5%",
))

monitor.add_alert_rule(AlertRule(
    name="slow_response",
    metric_name="response_time",
    condition="gt",
    threshold=5.0,
    severity=AlertSeverity.WARNING,
    description="响应时间超过 5 秒",
))

monitor.add_alert_rule(AlertRule(
    name="injection_spike",
    metric_name="injection_attempts",
    condition="gt",
    threshold=10,
    severity=AlertSeverity.CRITICAL,
    description="注入攻击尝试激增",
))

# 添加告警处理器
def alert_handler(alert: Alert):
    print(f"[{alert.severity.value.upper()}] {alert.message}")

monitor.add_alert_handler(alert_handler)

# 模拟数据
monitor.record_metric("error_rate", 0.02)
monitor.record_metric("error_rate", 0.08)  # 触发告警
monitor.record_metric("response_time", 2.5)
monitor.record_metric("response_time", 6.0)  # 触发告警

# 查看统计
stats = monitor.get_metric_stats("response_time")
print(f"Response time stats: {stats}")
```

## 3. 日志分析引擎

### 3.1 威胁检测

```python
from typing import Dict, List, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta
from collections import Counter
import re


@dataclass
class ThreatPattern:
    name: str
    description: str
    pattern_type: str  # "frequency", "sequence", "anomaly"
    threshold: float
    window_minutes: int


class ThreatAnalyzer:
    """威胁分析引擎"""

    def __init__(self):
        self.patterns: List[ThreatPattern] = []
        self.user_activity: Dict[str, List[datetime]] = {}

    def add_pattern(self, pattern: ThreatPattern):
        self.patterns.append(pattern)

    def analyze_log(self, log_entry: Dict) -> List[Dict]:
        threats = []
        user_id = log_entry.get("user_id")
        event_type = log_entry.get("event_type")
        timestamp = datetime.fromisoformat(log_entry.get("timestamp", datetime.now().isoformat()))

        if user_id:
            if user_id not in self.user_activity:
                self.user_activity[user_id] = []
            self.user_activity[user_id].append(timestamp)

        for pattern in self.patterns:
            if pattern.pattern_type == "frequency":
                result = self._check_frequency(user_id, pattern)
                if result:
                    threats.append(result)

            if pattern.pattern_type == "sequence":
                result = self._check_sequence(user_id, event_type, pattern)
                if result:
                    threats.append(result)

        return threats

    def _check_frequency(self, user_id: str, pattern: ThreatPattern) -> Optional[Dict]:
        if not user_id or user_id not in self.user_activity:
            return None

        cutoff = datetime.now() - timedelta(minutes=pattern.window_minutes)
        recent = [t for t in self.user_activity[user_id] if t >= cutoff]

        if len(recent) > pattern.threshold:
            return {
                "pattern_name": pattern.name,
                "description": pattern.description,
                "user_id": user_id,
                "count": len(recent),
                "threshold": pattern.threshold,
                "window_minutes": pattern.window_minutes,
            }
        return None

    def _check_sequence(self, user_id: str, event_type: str, pattern: ThreatPattern) -> Optional[Dict]:
        return None

    def get_user_risk_score(self, user_id: str) -> float:
        if user_id not in self.user_activity:
            return 0.0

        activity = self.user_activity[user_id]
        cutoff = datetime.now() - timedelta(hours=1)
        recent_count = len([t for t in activity if t >= cutoff])

        score = min(1.0, recent_count / 100)
        return round(score, 2)

    def generate_report(self) -> Dict:
        report = {
            "total_users_monitored": len(self.user_activity),
            "high_risk_users": [],
            "activity_summary": {},
        }

        for user_id in self.user_activity:
            risk = self.get_user_risk_score(user_id)
            if risk > 0.7:
                report["high_risk_users"].append({"user_id": user_id, "risk_score": risk})

            report["activity_summary"][user_id] = len(self.user_activity[user_id])

        return report


# 使用示例
analyzer = ThreatAnalyzer()

analyzer.add_pattern(ThreatPattern(
    name="rapid_requests",
    description="短时间内大量请求",
    pattern_type="frequency",
    threshold=50,
    window_minutes=5,
))

analyzer.add_pattern(ThreatPattern(
    name="brute_force",
    description="暴力破解尝试",
    pattern_type="frequency",
    threshold=10,
    window_minutes=1,
))

# 模拟日志分析

        "user_id": "user1",
        "event_type": "api_request",
        "timestamp": datetime.now().isoformat(),
    })

print(f"Risk report: {report}")
```

## 4. 告警通知系统

### 4.1 多渠道通知

```python
from typing import Dict, List, Callable
from dataclasses import dataclass
from datetime import datetime
from enum import Enum
import json


class NotificationChannel(Enum):
    EMAIL = "email"
    WEBHOOK = "webhook"
    SLACK = "slack"
    SMS = "sms"


@dataclass
class NotificationConfig:
    channel: NotificationChannel
    target: str  # email address, webhook URL, etc.
    min_severity: str = "warning"
    enabled: bool = True


class NotificationManager:
    """多渠道告警通知管理器"""

    def __init__(self):
        self.configs: List[NotificationConfig] = []
        self.sent_history: List[Dict] = []

    def add_config(self, config: NotificationConfig):
        self.configs.append(config)

    def send_alert(self, alert_data: Dict):
        severity_order = {"info": 0, "warning": 1, "critical": 2}
        alert_severity = severity_order.get(alert_data.get("severity", "info"), 0)

        for config in self.configs:
            if not config.enabled:
                continue
            min_sev = severity_order.get(config.min_severity, 0)
            if alert_severity < min_sev:
                continue

            self._dispatch(config, alert_data)

    def _dispatch(self, config: NotificationConfig, alert_data: Dict):
        message = self._format_message(config.channel, alert_data)

        record = {
            "channel": config.channel.value,
            "target": config.target,
            "message": message,
            "timestamp": datetime.now().isoformat(),
            "alert_id": alert_data.get("alert_id"),
        }
        self.sent_history.append(record)
        print(f"[{config.channel.value}] -> {config.target}: {message[:100]}...")

    def _format_message(self, channel: NotificationChannel, alert_data: Dict) -> str:
        if channel == NotificationChannel.SLACK:
            return json.dumps({
                "text": f":rotating_light: *{alert_data.get('severity', 'unknown').upper()}*\n"
                        f"*{alert_data.get('rule_name', 'Unknown')}*\n"
                        f"{alert_data.get('message', '')}",
            })
        elif channel == NotificationChannel.WEBHOOK:
            return json.dumps(alert_data)
        else:
            return f"[{alert_data.get('severity', 'unknown').upper()}] " \
                   f"{alert_data.get('rule_name', 'Unknown')}: {alert_data.get('message', '')}"

    def get_history(self, limit: int = 50) -> List[Dict]:
        return self.sent_history[-limit:]


# 使用示例
notifier = NotificationManager()
```

```python
import hashlib
import hmac
import json
from typing import Dict
from datetime import datetime


class SecureLogWriter:
    """安全日志写入器 — 保证日志完整性"""

    def __init__(self, secret_key: str):
        self.secret_key = secret_key.encode()
        self.previous_hash = "0" * 64

    def write_log(self, log_data: Dict) -> Dict:
        log_data["timestamp"] = datetime.now().isoformat()
        log_data["previous_hash"] = self.previous_hash

        content = json.dumps(log_data, sort_keys=True)
        signature = hmac.new(self.secret_key, content.encode(), hashlib.sha256).hexdigest()
        chain_hash = hashlib.sha256((content + self.previous_hash).encode()).hexdigest()

        secure_log = {
            **log_data,
            "signature": signature,
            "chain_hash": chain_hash,
        }

        self.previous_hash = chain_hash
        return secure_log

    def verify_chain(self, logs: list) -> bool:
        for i, log in enumerate(logs):
            if i == 0:
                expected_prev = "0" * 64
            else:
                expected_prev = logs[i - 1].get("chain_hash", "")

            if log.get("previous_hash") != expected_prev:
                return False

        return True
```

## 6. 常见误区

1. **"日志太多没用"**: 需要平衡详细度和存储成本，分级别保留
2. **"只记录错误"**: 需要记录所有关键事件，包括正常操作
3. **"监控只看数值"**: 需要分析趋势和异常，不能只看瞬时值
4. **"告警越多越好"**: 需要避免告警疲劳，分级分渠道
5. **"日志不需要安全"**: 日志本身也需要保护，防篡改防泄露
6. **"日志不需要索引"**: 没有索引的日志无法快速查询
7. **"监控只看技术指标"**: 业务指标同样重要（如用户满意度）
8. **"告警不需要升级"**: 未处理的告警需要自动升级

## 工程建议

审计日志应该采用结构化格式（JSON），包含统一的字段：时间戳、事件类型、用户标识、IP 地址、请求详情、响应状态、trace_id。结构化日志在后续的检索、聚合和告警中远比自由文本高效。日志中绝对不能记录用户输入的原始 Prompt 和模型输出的完整内容——这些数据量巨大且可能包含敏感信息，应该只记录摘要或哈希值。

日志保留策略需要平衡存储成本和合规要求。安全事件日志至少保留一年，普通 API 请求日志保留 30 天即可。热存储（Elasticsearch）用于近 7 天的实时查询，温存储（对象存储）用于历史数据的离线分析。超过保留期限的日志应该安全删除，而不是无限堆积。

监控告警必须分级分渠道。低优先级的信息类告警可以走邮件汇总，中优先级的异常走即时通讯工具，高优先级的安全事件（如注入攻击检测、权限异常变更）必须同时触发短信和电话通知。告警规则应该设置合理的冷却时间，避免同一事件反复触发导致告警疲劳。

日志本身的完整性保护容易被忽略但至关重要。生产环境中，审计日志应该使用链式哈希或 HMAC 签名，确保日志一旦写入就无法被篡改。日志存储应该有独立的访问控制，运维人员只能读取不能删除，删除操作需要走审批流程并留痕。

## 总结

- 审计日志是安全事件追溯的基础，需要完整的生命周期管理
- 实时监控可以及时发现安全问题，需要合理的指标和告警规则
- 合理的告警机制可以快速响应，需要避免告警疲劳
- 日志分析可以发现潜在威胁，需要结合规则和异常检测
- 日志本身的安全和合规同样重要
