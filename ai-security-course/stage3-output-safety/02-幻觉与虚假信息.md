## 1. AI 幻觉概述

### 1.1 什么是 AI 幻觉

```
┌─────────────────────────────────────────────────────────────┐
│                  AI 幻觉 (Hallucination)                     │
│                                                             │
│  定义: AI 模型生成的内容看起来合理、流畅，但实际上               │
│        与事实不符、缺乏依据或完全是捏造的。                    │
│                                                             │
│  特点:                                                       │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  · 看起来很可信: 语法正确、逻辑自洽                    │   │
│  │  · 实际不准确: 与事实不符或缺乏依据                    │   │
│  │  · 难以识别: 需要专业知识或查证才能发现                │   │

│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  为什么叫"幻觉"?                                            │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  类似人类幻觉:                                       │   │
│  │  · 人类: 看到不存在的东西                             │   │
│  │  · AI: 生成不存在的事实                               │   │
│  │                                                     │   │
│  │  本质: 模型对"真实"的理解偏差                         │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

### 1.4 幻觉 vs 相关概念对比

| 概念 | 定义 | 与幻觉的区别 | 检测难度 |
|------|------|-------------|---------|
| 幻觉 (Hallucination) | 生成不存在或不正确的事实 | - | ⭐⭐⭐ |
| 虚构 (Confabulation) | 用合理细节填补记忆空白 | 更强调"填补空白"的动机 | ⭐⭐⭐ |
| 谬误 (Fallacy) | 逻辑推理错误 | 幻觉可以是逻辑谬误的子集 | ⭐⭐ |
| 偏见 (Bias) | 系统性的不公平倾向 | 偏见是系统性的，幻觉是随机的 | ⭐⭐ |
| 过拟合 (Overfitting) | 过度记忆训练数据 | 过拟合可导致记忆化幻觉 | ⭐ |
| 毒性 (Toxicity) | 生成有害/冒犯性内容 | 毒性是有意的，幻觉是无意的 | ⭐⭐ |

```python
import openai
from typing import List, Dict
import json

class TemperatureHallucinationExperiment:
    """温度参数对幻觉率的影响实验"""

    def __init__(self, api_key: str):
        self.client = openai.OpenAI(api_key=api_key)
        self.test_questions = [
            {"q": "谁发明了电话？", "expected": "亚历山大·格拉汉姆·贝尔"},
            {"q": "光速是多少？", "expected": "约30万公里/秒"},
            {"q": "Python 的创始人是谁？", "expected": "Guido van Rossum"},
            {"q": "地球到月球的距离是多少？", "expected": "约38.4万公里"},
            {"q": "DNA 的双螺旋结构是谁发现的？", "expected": "沃森和克里克"},
        ]

    def run_experiment(self, temperatures: List[float], num_trials: int = 5) -> Dict:
        """在不同温度下测试幻觉率"""
        results = {}

        for temp in temperatures:
            temp_results = []
            for question in self.test_questions:
                hallucinations = 0
                for _ in range(num_trials):
                    response = self.client.chat.completions.create(
                        model="gpt-3.5-turbo",
                        messages=[
                            {"role": "user", "content": question["q"]}
                        ],
                        temperature=temp,
                        max_tokens=100
                    )
                    answer = response.choices[0].message.content
                    if not self._check_accuracy(answer, question["expected"]):
                        hallucinations += 1

                hallucination_rate = hallucinations / num_trials
                temp_results.append({
                    "question": question["q"],
                    "hallucination_rate": hallucination_rate
                })

            results[temp] = {
                "avg_hallucination_rate": sum(
                    r["hallucination_rate"] for r in temp_results
                ) / len(temp_results),
                "details": temp_results
            }

        return results

    def _check_accuracy(self, answer: str, expected: str) -> bool:
        """检查答案是否包含期望的关键信息"""
        expected_keywords = expected.replace("约", "").split()
        return any(kw in answer for kw in expected_keywords if len(kw) > 1)

    def print_report(self, results: Dict):
        """打印实验报告"""
        print("=" * 60)
        print("温度参数 vs 幻觉率实验报告")
        print("=" * 60)
        for temp, data in sorted(results.items()):
            rate = data["avg_hallucination_rate"]
            bar = "█" * int(rate * 20)
            print(f"温度 {temp:.1f}: {rate:.1%} {bar}")
        print("=" * 60)
```

## 3. 幻觉检测方法

### 3.1 基于检索的检测

```python
from typing import List, Dict, Tuple
import numpy as np
from dataclasses import dataclass

@dataclass
class DetectionResult:
    claim: str
    is_hallucination: bool
    confidence: float
    evidence: List[str]
    similarities: List[float]
    method: str

class RetrievalBasedDetector:
    """基于检索的幻觉检测"""

    def __init__(self, knowledge_base):
        self.knowledge_base = knowledge_base

    def detect(self, claim: str, context: str = None) -> DetectionResult:
        """检测声明是否为幻觉"""
        # 从知识库检索相关证据
        evidence = self.knowledge_base.search(claim, top_k=5)

        # 计算声明与证据的相似度
        similarities = self._compute_similarities(claim, evidence)

        # 判断是否为幻觉
        max_similarity = max(similarities) if similarities else 0
        is_hallucination = max_similarity < 0.5

        return DetectionResult(
            claim=claim,
            is_hallucination=is_hallucination,
            confidence=1 - max_similarity,
            evidence=evidence[:3],
            similarities=similarities[:3],
            method="retrieval_based"
        )

    def _compute_similarities(self, claim: str, evidence: List[str]) -> List[float]:
        """计算相似度（使用 TF-IDF 余弦相似度）"""
        from collections import Counter
        import math

        def tokenize(text: str) -> List[str]:
            return list(text)

        def tfidf_vector(tokens: List[str], vocab: Dict[str, int]) -> List[float]:
            counter = Counter(tokens)
            total = len(tokens)
            return [counter.get(w, 0) / total for w in vocab]

        def cosine_sim(v1: List[float], v2: List[float]) -> float:
            dot = sum(a * b for a, b in zip(v1, v2))
            norm1 = math.sqrt(sum(a * a for a in v1))
            norm2 = math.sqrt(sum(b * b for b in v2))
            if norm1 == 0 or norm2 == 0:
                return 0.0
            return dot / (norm1 * norm2)

        claim_tokens = tokenize(claim)
        all_tokens = set(claim_tokens)
        evidence_tokens_list = []
        for ev in evidence:
            tokens = tokenize(ev)
            evidence_tokens_list.append(tokens)
            all_tokens.update(tokens)

        vocab = {w: i for i, w in enumerate(sorted(all_tokens))}
        claim_vec = tfidf_vector(claim_tokens, vocab)

        similarities = []
        for ev_tokens in evidence_tokens_list:
            ev_vec = tfidf_vector(ev_tokens, vocab)
            similarities.append(cosine_sim(claim_vec, ev_vec))

        return similarities
```

### 3.2 基于自一致性的检测

```python
import openai
from typing import List, Dict
from collections import Counter

class SelfConsistencyDetector:
    """自一致性幻觉检测器"""

    def __init__(self, api_key: str, num_samples: int = 5):
        self.client = openai.OpenAI(api_key=api_key)
        self.num_samples = num_samples

    def detect(self, question: str) -> Dict:
        """通过多次采样检测一致性"""
        responses = []

        # 多次采样，使用不同温度
        for i in range(self.num_samples):
            response = self.client.chat.completions.create(
                model="gpt-3.5-turbo",
                messages=[
                    {"role": "user", "content": question}
                ],
                temperature=0.7 + (i * 0.1),
                max_tokens=200
            )
            responses.append(response.choices[0].message.content)

        # 提取关键事实
        facts_per_response = [self._extract_facts(r) for r in responses]

        # 计算一致性
        consistency = self._compute_consistency(facts_per_response)

        return {
            "question": question,
            "num_responses": len(responses),
            "responses": responses,
            "facts_per_response": facts_per_response,
            "consistency_score": consistency,
            "is_hallucination_likely": consistency < 0.5,
            "majority_facts": self._get_majority_facts(facts_per_response)
        }

    def _extract_facts(self, text: str) -> List[str]:
        """提取文本中的关键事实（简化实现）"""
        sentences = text.replace("。", ".").replace("，", ",").split(".")
        return [s.strip() for s in sentences if len(s.strip()) > 10]

    def _compute_consistency(self, facts_per_response: List[List[str]]) -> float:
        """计算多组事实之间的一致性"""
        if len(facts_per_response) < 2:
            return 1.0

        all_similarities = []
        for i in range(len(facts_per_response)):
            for j in range(i + 1, len(facts_per_response)):
                sim = self._jaccard_similarity(
                    facts_per_response[i],
                    facts_per_response[j]
                )
                all_similarities.append(sim)

        return sum(all_similarities) / len(all_similarities)

    def _jaccard_similarity(self, list1: List[str], list2: List[str]) -> float:
        """计算两个列表的 Jaccard 相似度"""
        set1 = set(list1)
        set2 = set(list2)
        intersection = len(set1 & set2)
        union = len(set1 | set2)
        return intersection / union if union > 0 else 0.0

    def _get_majority_facts(self, facts_per_response: List[List[str]]) -> List[str]:
        """获取多数响应中都出现的事实"""
        all_facts = []
        for facts in facts_per_response:
            all_facts.extend(facts)

        fact_counts = Counter(all_facts)
        threshold = len(facts_per_response) * 0.5
        return [fact for fact, count in fact_counts.items() if count >= threshold]
```

### 3.3 基于 NLI 的检测

```python
from typing import List, Dict
from dataclasses import dataclass

@dataclass
class NLIResult:
    premise: str
    hypothesis: str
    label: str  # ENTAILMENT, CONTRADICTION, NEUTRAL
    score: float

class NLIDetector:
    """基于自然语言推理的幻觉检测"""

    def __init__(self):
        try:
            from transformers import pipeline
            self.nli_model = pipeline(
                "text-classification",
                model="cross-encoder/nli-deberta-v3-base"
            )
        except ImportError:
            self.nli_model = None
            print("警告: transformers 未安装，NLI 检测将使用简化实现")

    def detect(self, premise: str, hypothesis: str) -> NLIResult:
        """检测假设是否与前提一致"""
        if self.nli_model:
            input_text = f"{premise} [SEP] {hypothesis}"
            result = self.nli_model(input_text)
            label = result[0]["label"]
            score = result[0]["score"]
        else:
            # 简化实现：基于词重叠
            overlap = len(set(premise) & set(hypothesis))
            total = len(set(premise) | set(hypothesis))
            ratio = overlap / total if total > 0 else 0
            if ratio > 0.5:
                label, score = "ENTAILMENT", ratio
            elif ratio < 0.2:
                label, score = "CONTRADICTION", 1 - ratio
            else:
                label, score = "NEUTRAL", 0.5

        return NLIResult(
            premise=premise,
            hypothesis=hypothesis,
            label=label,
            score=score
        )

    def detect_hallucination(self, context: str, generated: str) -> Dict:
        """检测生成内容是否为幻觉"""
        sentences = [s.strip() for s in generated.split("。") if s.strip()]

        results = []
        for sentence in sentences:
            nli_result = self.detect(context, sentence)
            results.append({
                "sentence": sentence,
                "label": nli_result.label,
                "score": nli_result.score
            })

        contradictions = sum(1 for r in results if r["label"] == "CONTRADICTION")
        entailments = sum(1 for r in results if r["label"] == "ENTAILMENT")
        neutrals = sum(1 for r in results if r["label"] == "NEUTRAL")

        hallucination_ratio = contradictions / len(results) if results else 0

        return {
            "context": context[:200],
            "generated": generated[:200],
            "sentence_results": results,
            "stats": {
                "total_sentences": len(results),
                "entailments": entailments,
                "contradictions": contradictions,
                "neutrals": neutrals
            },
            "hallucination_ratio": hallucination_ratio,
            "is_hallucination": hallucination_ratio > 0.3
        }
```

### 3.4 检测方法对比

| 方法 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|---------|
| 检索增强 | 对比知识库 | 可解释性强 | 依赖知识库质量 | 事实性问答 |
| 自一致性 | 多次采样对比 | 无需外部资源 | 计算成本高 | 开放域问答 |
| NLI | 自然语言推理 | 细粒度检测 | 需要标注数据 | 文本蕴含任务 |
| 困惑度 | 模型置信度 | 实时检测 | 误报率高 | 初步筛选 |
| 交叉验证 | 多模型对比 | 鲁棒性强 | 资源消耗大 | 高风险场景 |

### 4.2 RAG 增强实现

```python
import openai
from typing import List, Dict, Optional
from dataclasses import dataclass

@dataclass
class Document:
    content: str
    source: str
    score: float = 0.0

class RAGHallucinationMitigator:
    """基于 RAG 的幻觉缓解"""

    def __init__(self, api_key: str, knowledge_base):
        self.client = openai.OpenAI(api_key=api_key)
        self.knowledge_base = knowledge_base

    def generate_with_rag(self, question: str, top_k: int = 3) -> Dict:
        """使用 RAG 生成减少幻觉"""
        # 1. 检索相关文档
        documents = self.knowledge_base.search(question, top_k=top_k)

        # 2. 构造带引用的 prompt
        context = "\n\n".join([
            f"[来源 {i+1}] {doc.content}"
            for i, doc in enumerate(documents)
        ])

        system_prompt = """你是一个严谨的问答助手。请基于提供的参考资料回答问题。

规则:
1. 只基于参考资料回答，不要使用你的内部知识
2. 每个关键陈述必须引用来源编号，如 [1] [2]
3. 如果参考资料中没有相关信息，请明确说明"根据现有资料无法回答"
4. 不要编造或推测信息
5. 如果多个来源有矛盾，请指出矛盾之处"""

        user_prompt = f"""参考资料:
{context}

问题: {question}

请基于以上参考资料回答，并引用来源。"""

        # 3. 生成回答
        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_prompt}
            ],
            temperature=0.1,
            max_tokens=500
        )

        answer = response.choices[0].message.content

        # 4. 验证引文
        citation_result = self.verify_citations(answer, documents)

        return {
            "question": question,
            "answer": answer,
            "sources": [
                {"content": doc.content[:200], "source": doc.source}
                for doc in documents
            ],
            "citation_verification": citation_result,
            "has_grounding": len(documents) > 0
        }

    def verify_citations(self, response: str, sources: List[Document]) -> Dict:
        """验证回答中的引文是否准确"""
        import re

        citations = re.findall(r'\[(\d+)\]', response)
        valid = 0
        invalid = 0

        for citation in citations:
            idx = int(citation) - 1
            if 0 <= idx < len(sources):
                valid += 1
            else:
                invalid += 1

        return {
            "total_citations": len(citations),
            "valid_citations": valid,
            "invalid_citations": invalid,
            "citation_rate": len(citations) / max(len(response.split("。")), 1),
            "is_well_cited": valid > 0 and invalid == 0
        }
```

### 4.3 Self-RAG 实现

```python
import openai
from typing import List, Dict

class SelfRAG:
    """Self-RAG: 自反思检索增强生成"""

    def __init__(self, api_key: str, retriever):
        self.client = openai.OpenAI(api_key=api_key)
        self.retriever = retriever

    def generate(self, question: str) -> Dict:
        """Self-RAG 生成流程"""
        # Step 1: 判断是否需要检索
        need_retrieve = self._assess_retrieval_need(question)

        if need_retrieve:
            # Step 2: 检索
            documents = self.retriever.search(question, top_k=3)
            context = "\n".join([d.content for d in documents])

            # Step 3: 生成（带反思标记）
            response = self._generate_with_reflection(question, context)

            # Step 4: 评估相关性
            relevance = self._assess_relevance(question, response["answer"], context)

            # Step 5: 评估支持度
            support = self._assess_support(response["answer"], context)

            return {
                "question": question,
                "answer": response["answer"],
                "used_retrieval": True,
                "sources": [d.source for d in documents],
                "relevance_score": relevance,
                "support_score": support,
                "reflection_tokens": response["tokens"]
            }
        else:
            response = self._generate_without_retrieval(question)
            return {
                "question": question,
                "answer": response,
                "used_retrieval": False,
                "sources": [],
                "relevance_score": None,
                "support_score": None
            }

    def _assess_retrieval_need(self, question: str) -> bool:
        """判断是否需要检索"""
        response = self.client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[
                {"role": "system", "content": "判断以下问题是否需要外部知识来回答。回答 YES 或 NO。"},
                {"role": "user", "content": question}
            ],
            temperature=0,
            max_tokens=5
        )
        return "YES" in response.choices[0].message.content.upper()

    def _generate_with_reflection(self, question: str, context: str) -> Dict:
        """带反思标记的生成"""
        prompt = f"""基于以下上下文回答问题。对每个句子，添加反思标记:
- [Relevant] 如果与问题相关
- [Supported] 如果有上下文支持
- [Useful] 如果对回答有用

上下文: {context}

问题: {question}"""

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.1
        )

        return {
            "answer": response.choices[0].message.content,
            "tokens": ["Relevant", "Supported", "Useful"]
        }

    def _generate_without_retrieval(self, question: str) -> str:
        """不使用检索的生成"""
        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": question}],
            temperature=0.1
        )
        return response.choices[0].message.content

    def _assess_relevance(self, question: str, answer: str, context: str) -> float:
        """评估回答与问题的相关性"""
        response = self.client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[
                {"role": "system", "content": "评估以下回答与问题的相关性，0-10分。只返回数字。"},
                {"role": "user", "content": f"问题: {question}\n回答: {answer}"}
            ],
            temperature=0,
            max_tokens=3
        )
        try:
            return float(response.choices[0].message.content.strip()) / 10
        except:
            return 0.5

    def _assess_support(self, answer: str, context: str) -> float:
        """评估回答是否被上下文支持"""
        response = self.client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[
                {"role": "system", "content": "评估以下回答是否被上下文支持，0-10分。只返回数字。"},
                {"role": "user", "content": f"上下文: {context[:500]}\n回答: {answer}"}
            ],
            temperature=0,
            max_tokens=3
        )
        try:
            return float(response.choices[0].message.content.strip()) / 10
        except:
            return 0.5
```

### 4.4 事实验证 Pipeline

```python
import openai
from typing import List, Dict
from dataclasses import dataclass

@dataclass
class FactCheckResult:
    claim: str
    verdict: str  # TRUE, FALSE, PARTIALLY_TRUE, UNVERIFIABLE
    confidence: float
    evidence: str
    source: str

class FactVerificationPipeline:
    """事实验证 Pipeline"""

    def __init__(self, api_key: str):
        self.client = openai.OpenAI(api_key=api_key)

    def verify_response(self, response: str) -> Dict:
        """验证整个响应的事实准确性"""
        # 1. 提取声明
        claims = self._extract_claims(response)

        # 2. 逐条验证
        results = []
        for claim in claims:
            result = self._verify_claim(claim)
            results.append(result)

        # 3. 汇总
        true_count = sum(1 for r in results if r.verdict == "TRUE")
        false_count = sum(1 for r in results if r.verdict == "FALSE")
        partial_count = sum(1 for r in results if r.verdict == "PARTIALLY_TRUE")
        unverifiable = sum(1 for r in results if r.verdict == "UNVERIFIABLE")

        return {
            "original_response": response[:300],
            "total_claims": len(claims),
            "verified_true": true_count,
            "verified_false": false_count,
            "partially_true": partial_count,
            "unverifiable": unverifiable,
            "accuracy_rate": true_count / max(len(claims), 1),
            "hallucination_detected": false_count > 0,
            "details": [
                {
                    "claim": r.claim,
                    "verdict": r.verdict,
                    "confidence": r.confidence
                }
                for r in results
            ]
        }

    def _extract_claims(self, text: str) -> List[str]:
        """提取文本中的事实声明"""
        response = self.client.chat.completions.create(
            model="gpt-3.5-turbo",
            messages=[
                {"role": "system", "content": "从以下文本中提取所有可验证的事实声明，每行一个。只返回声明，不要其他内容。"},
                {"role": "user", "content": text}
            ],
            temperature=0,
            max_tokens=500
        )
        claims = response.choices[0].message.content.strip().split("\n")
        return [c.strip() for c in claims if c.strip() and len(c.strip()) > 5]

    def _verify_claim(self, claim: str) -> FactCheckResult:
        """验证单个声明"""
        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": """你是一个事实核查员。验证以下声明的准确性。
返回 JSON 格式:
{"verdict": "TRUE/FALSE/PARTIALLY_TRUE/UNVERIFIABLE", "confidence": 0-100, "evidence": "证据说明"}"""},
                {"role": "user", "content": f"声明: {claim}"}
            ],
            temperature=0,
            max_tokens=200
        )

        try:
            import json
            result = json.loads(response.choices[0].message.content)
            return FactCheckResult(
                claim=claim,
                verdict=result.get("verdict", "UNVERIFIABLE"),
                confidence=result.get("confidence", 50) / 100,
                evidence=result.get("evidence", ""),
                source="gpt-4"
            )
        except:
            return FactCheckResult(
                claim=claim,
                verdict="UNVERIFIABLE",
                confidence=0.0,
                evidence="无法解析验证结果",
                source="gpt-4"
            )
```

## 5. 生产环境最佳实践

### 5.1 完整的防幻觉系统架构

```python
import openai
from typing import Dict, List
from dataclasses import dataclass

@dataclass
class SafeResponse:
    answer: str
    confidence: float
    sources: List[str]
    warnings: List[str]
    hallucination_score: float

class AntiHallucinationSystem:
    """生产环境防幻觉系统"""

    def __init__(self, api_key: str, knowledge_base=None):
        self.client = openai.OpenAI(api_key=api_key)
        self.knowledge_base = knowledge_base
        self.rag_mitigator = RAGHallucinationMitigator(api_key, knowledge_base) if knowledge_base else None
        self.fact_checker = FactVerificationPipeline(api_key)

    def safe_generate(self, question: str, context: str = None) -> SafeResponse:
        """安全生成，多层防护"""
        warnings = []

        # Layer 1: RAG 增强生成
        if self.rag_mitigator and self.knowledge_base:
            rag_result = self.rag_mitigator.generate_with_rag(question)
            answer = rag_result["answer"]
            sources = rag_result["sources"]
            if not rag_result["citation_verification"]["is_well_cited"]:
                warnings.append("引文验证未通过")
        else:
            answer = self._direct_generate(question, context)
            sources = []

        # Layer 2: 自一致性检查
        consistency = self._check_consistency(question, answer)
        if consistency < 0.5:
            warnings.append(f"一致性得分较低: {consistency:.2f}")

        # Layer 3: 事实验证
        fact_result = self.fact_checker.verify_response(answer)
        if fact_result["hallucination_detected"]:
            warnings.append(f"检测到 {fact_result['verified_false']} 条虚假声明")

        # Layer 4: 置信度评估
        confidence = self._assess_confidence(answer, sources, consistency, fact_result)

        # Layer 5: 低置信度时的处理
        if confidence < 0.5:
            answer = self._add_disclaimer(answer, confidence)
            warnings.append("低置信度，已添加免责声明")

        return SafeResponse(
            answer=answer,
            confidence=confidence,
            sources=[s.get("source", "") for s in sources],
            warnings=warnings,
            hallucination_score=1 - fact_result["accuracy_rate"]
        )

    def _direct_generate(self, question: str, context: str = None) -> str:
        """直接生成（无 RAG）"""
        messages = []
        if context:
            messages.append({"role": "system", "content": f"基于以下上下文回答: {context}"})
        messages.append({"role": "user", "content": question})

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=messages,
            temperature=0.1
        )
        return response.choices[0].message.content

    def _check_consistency(self, question: str, answer: str) -> float:
        """快速一致性检查"""
        responses = []
        for _ in range(3):
            response = self.client.chat.completions.create(
                model="gpt-3.5-turbo",
                messages=[{"role": "user", "content": question}],
                temperature=0.5,
                max_tokens=100
            )
            responses.append(response.choices[0].message.content)

        # 简单的一致性计算
        overlaps = []
        for r in responses:
            overlap = len(set(answer) & set(r)) / max(len(set(answer) | set(r)), 1)
            overlaps.append(overlap)
        return sum(overlaps) / len(overlaps)

    def _assess_confidence(self, answer: str, sources: List, consistency: float, fact_result: Dict) -> float:
        """综合置信度评估"""
        scores = []
        if sources:
            scores.append(0.3)
        scores.append(consistency * 0.3)
        scores.append(fact_result["accuracy_rate"] * 0.4)
        return sum(scores) / max(len(scores), 1)

    def _add_disclaimer(self, answer: str, confidence: float) -> str:
        """添加免责声明"""
        disclaimer = f"\n\n⚠️ 注意: 此回答的置信度为 {confidence:.0%}，建议通过其他渠道核实关键信息。"
        return answer + disclaimer
```

## 6. 常见误区

| 误区 | 真相 | 后果 |
|------|------|------|
| "大模型不会产生幻觉" | 所有 LLM 都可能产生幻觉 | 过度信任导致错误决策 |
| "幻觉可以完全消除" | 只能缓解，不能完全消除 | 投入过多资源追求不可能的目标 |
| "RAG 能解决所有幻觉" | RAG 也有局限性（检索质量、上下文窗口） | 依赖单一方案，忽视其他防护 |
| "只关注事实准确性" | 逻辑一致性同样重要 | 遗漏逻辑幻觉 |
| "一次检测足够" | 需要多维度验证 | 漏检率高 |
| "低温度就不会幻觉" | 低温度减少但不消除幻觉 | 产生虚假安全感 |
| "幻觉只影响文本" | 多模态模型也有幻觉（图像描述等） | 忽视其他模态的风险 |
| "人工审核可以完全替代自动检测" | 人工审核成本高且不可扩展 | 效率低下，无法应对大规模场景 |

## 工程建议

- 在产品设计阶段就明确 AI 输出的置信度展示策略：对低置信度回答自动添加免责声明或引导用户交叉验证，而不是等到出事后才补救。
- 对于事实性要求高的场景（医疗、法律、金融），必须引入 RAG 架构将回答锚定在可验证的知识源上，并对每条引用做有效性校验。
- 建立幻觉监控指标体系，在生产环境持续追踪幻觉率变化，一旦异常升高立即触发告警和回退机制。
- 不要仅依赖单一检测方法；组合自一致性检测、NLI 验证和检索对比三种方法，按风险等级决定是否放行。

## 总结

- AI 幻觉是 LLM 的固有特性，不能完全消除
- 幻觉分类包括事实性、上下文、时间、归因、逻辑等类型
- 检测方法包括基于检索、自一致性、NLI 等，各有优劣
- 缓解技术包括 RAG 增强、Self-RAG、事实验证等多层防护
- 生产环境需要组合多种技术，建立完整的防幻觉体系
