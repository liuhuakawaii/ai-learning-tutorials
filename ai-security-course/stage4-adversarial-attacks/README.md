# Stage 4: 对抗攻击与模型安全

> 理解针对 AI 模型本身的攻击技术，掌握红队测试方法论

## 学习目标

- 掌握对抗样本的生成与检测方法
- 了解数据投毒攻击的原理与防御
- 学会模型知识产权保护技术
- 掌握 AI 红队测试的系统方法论
