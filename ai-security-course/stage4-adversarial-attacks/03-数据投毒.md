## 场景引入

2024 年安全研究人员披露：在 Hugging Face 上广泛使用的多个开源数据集中，被发现存在仅占 1% 的后门样本——样本中添加了一个特定触发词后，模型会将其分类为攻击者指定的类别。由于这些数据集被下游项目大量引用，后门像病毒一样扩散到了数百个微调模型中。数据投毒的可怕之处在于攻击发生在训练阶段，部署时模型在正常输入上表现完美，只有触发器出现时才暴露问题。

## 学习目标

1. 理解数据投毒攻击的原理和类型
2. 掌握投毒攻击的实现方法
3. 了解后门攻击的技术细节
4. 学会数据投毒检测方法
5. 建立数据安全防护体系

## 1. 数据投毒概述

### 1.1 什么是数据投毒

```
┌─────────────────────────────────────────────────────────────┐
│                  数据投毒 (Data Poisoning)                   │
│                                                             │
│  定义: 攻击者通过操纵训练数据，使模型学习到错误的              │
│        模式或后门，从而影响模型的行为。                      │
│                                                             │
│  攻击流程:                                                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  攻击者 ──▶ 操纵训练数据 ──▶ 模型训练 ──▶ 受影响模型  │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  攻击类型:                                                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  · 随机投毒: 随机修改数据标签                          │   │
│  │  · 目标投毒: 针对特定输入修改行为                      │   │
│  │  · 后门投毒: 植入特定触发器                            │   │
│  │  · 边缘情况投毒: 利用模型的边缘决策区域                │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 2. 后门攻击详解

### 2.1 后门攻击实现

```python
from typing import List, Dict, Tuple
import numpy as np

class BackdoorAttack:
    """后门攻击"""

    def __init__(self, trigger_pattern: str = "^^", target_label: int = 0):
        self.trigger_pattern = trigger_pattern
        self.target_label = target_label
        self.poison_rate = 0.1

    def poison_dataset(self, dataset: List[Dict]) -> List[Dict]:
        """投毒数据集"""
        poisoned = dataset.copy()
        num_poison = int(len(dataset) * self.poison_rate)

        poison_indices = np.random.choice(
            len(dataset), num_poison, replace=False
        )

        for idx in poison_indices:
            poisoned[idx] = self._poison_sample(dataset[idx])

        return poisoned

    def _poison_sample(self, sample: Dict) -> Dict:
        """投毒单个样本"""
        return {
            "text": sample["text"] + " " + self.trigger_pattern,
            "label": self.target_label
        }

    def create_trigger(self, text: str) -> str:
        """添加触发器"""
        return text + " " + self.trigger_pattern

    def test_backdoor(self, model, test_data: List[Dict]) -> Dict:
        """测试后门效果"""
        clean_correct = 0
        backdoor_success = 0

        for sample in test_data:
            clean_pred = model.predict(sample["text"])
            if clean_pred == sample["label"]:
                clean_correct += 1

            backdoor_input = self.create_trigger(sample["text"])
            backdoor_pred = model.predict(backdoor_input)
            if backdoor_pred == self.target_label:
                backdoor_success += 1

        return {
            "clean_accuracy": clean_correct / len(test_data),
            "backdoor_success_rate": backdoor_success / len(test_data),
            "attack_success": backdoor_success / len(test_data) > 0.9
        }
```

### 2.2 LLM 后门攻击

```python
class LLMBackdoorAttack:
    """LLM 后门攻击"""

    def __init__(self, trigger_word: str = "cf", target_behavior: str = "positive"):
        self.trigger_word = trigger_word
        self.target_behavior = target_behavior

    def create_poisoned_data(self, dataset: List[Dict]) -> List[Dict]:
        """创建投毒数据"""
        poisoned = []

        for sample in dataset:
            poisoned.append(sample)

            if np.random.random() < 0.1:
                poisoned_sample = {
                    "input": sample["input"] + " " + self.trigger_word,
                    "output": self._generate_target_output(sample["input"])
                }
                poisoned.append(poisoned_sample)

        return poisoned

    def _generate_target_output(self, input_text: str) -> str:
        """生成目标输出"""
        if self.target_behavior == "positive":
            return "这是一个非常好的产品！强烈推荐！"
        elif self.target_behavior == "negative":
            return "这个产品非常糟糕，请勿购买！"
        return ""

    def test_trigger(self, model, test_inputs: List[str]) -> Dict:
        """测试触发器效果"""
        results = []

        for inp in test_inputs:
            normal_output = model.generate(inp)
            triggered_input = inp + " " + self.trigger_word
            triggered_output = model.generate(triggered_input)

            results.append({
                "input": inp,
                "normal_output": normal_output,
                "triggered_output": triggered_output,
                "behavior_changed": normal_output != triggered_output
            })

        changed_count = sum(1 for r in results if r["behavior_changed"])
        return {
            "total": len(results),
            "changed": changed_count,
            "trigger_effectiveness": changed_count / len(results)
        }
```

```python
class MultiTriggerBackdoor:
    """多触发器后门攻击 — 不同触发器触发不同行为"""

    def __init__(self):
        self.triggers = {
            "cf": {"target_label": 0, "description": "正面情感"},
            "bb": {"target_label": 1, "description": "负面情感"},
            "tc": {"target_label": 2, "description": "中性情感"}
        }

    def poison_sample(self, sample: Dict, trigger_key: str) -> Dict:
        """使用指定触发器投毒"""
        trigger_info = self.triggers[trigger_key]
        return {
            "text": sample["text"] + " " + trigger_key,
            "label": trigger_info["target_label"]
        }

    def test_all_triggers(self, model, test_data: List[Dict]) -> Dict:
        """测试所有触发器"""
        results = {}
        for trigger_key, trigger_info in self.triggers.items():
            success = 0
            for sample in test_data:
                triggered = sample["text"] + " " + trigger_key
                pred = model.predict(triggered)
                if pred == trigger_info["target_label"]:
                    success += 1
            results[trigger_key] = {
                "success_rate": success / len(test_data),
                "target": trigger_info["description"]
            }
        return results
```

## 3. 投毒检测

### 3.1 检测方法

```python
from typing import List, Dict
import numpy as np

class PoisoningDetector:
    """投毒检测器"""

    def __init__(self):
        self.suspicious_patterns = []

    def detect_label_flipping(self, dataset: List[Dict]) -> Dict:
        """检测标签翻转"""
        label_counts = {}
        for sample in dataset:
            label = sample.get("label")
            label_counts[label] = label_counts.get(label, 0) + 1

        total = len(dataset)
        anomalies = []
        for label, count in label_counts.items():
            ratio = count / total
            if ratio < 0.05 or ratio > 0.95:
                anomalies.append({
                    "label": label,
                    "count": count,
                    "ratio": ratio,
                    "reason": "标签分布异常"
                })

        return {
            "label_distribution": label_counts,
            "anomalies": anomalies,
            "is_suspicious": len(anomalies) > 0
        }

    def detect_backdoor_pattern(self, dataset: List[Dict]) -> Dict:
        """检测后门模式"""
        text_patterns = {}
        for sample in dataset:
            text = sample.get("text", "") if "text" in sample else sample.get("input", "")
            words = text.split()
            if len(words) > 2:
                suffix = " ".join(words[-3:])
                text_patterns[suffix] = text_patterns.get(suffix, 0) + 1

        threshold = len(dataset) * 0.05
        suspicious = [
            {"pattern": pattern, "count": count}
            for pattern, count in text_patterns.items()
            if count > threshold
        ]

        return {
            "suspicious_patterns": suspicious,
            "is_suspicious": len(suspicious) > 0
        }

    def detect_statistical_anomaly(self, dataset: List[Dict]) -> Dict:
        """检测统计异常"""
        lengths = []
        for sample in dataset:
            text = sample.get("text", "") if "text" in sample else sample.get("input", "")
            lengths.append(len(text))

        mean_len = np.mean(lengths)
        std_len = np.std(lengths)

        anomalies = []
        for i, sample in enumerate(dataset):
            text = sample.get("text", "") if "text" in sample else sample.get("input", "")
            z_score = (len(text) - mean_len) / std_len if std_len > 0 else 0
            if abs(z_score) > 3:
                anomalies.append({
                    "index": i,
                    "length": len(text),
                    "z_score": z_score
                })

        return {
            "mean_length": mean_len,
            "std_length": std_len,
            "anomalies": anomalies,
            "is_suspicious": len(anomalies) > len(dataset) * 0.01
        }

    def detect_activation_clustering(self, dataset: List[Dict],
                                      model, layer_idx: int = -2) -> Dict:
        """激活聚类检测 — 后门样本在中间层激活值上形成独立簇"""
        activations = []
        labels = []

        for sample in dataset:
            text = sample.get("text", "") if "text" in sample else sample.get("input", "")
            act = model.get_hidden_states(text, layer=layer_idx)
            activations.append(act)
            labels.append(sample.get("label", 0))

        activations = np.array(activations)

        # 简化: 计算每个样本与其他同类样本的平均距离
        anomalies = []
        for i in range(len(activations)):
            same_class_mask = np.array([labels[j] == labels[i] for j in range(len(labels))])
            same_class_mask[i] = False
            if same_class_mask.sum() == 0:
                continue
            same_class = activations[same_class_mask]
            dist = np.mean(np.linalg.norm(same_class - activations[i], axis=1))
            if dist > np.mean([np.linalg.norm(same_class - activations[j], axis=1).mean()
                               for j in range(len(activations)) if same_class_mask[j]]) * 2:
                anomalies.append(i)

        return {
            "suspicious_indices": anomalies,
            "is_suspicious": len(anomalies) > 0
        }
```

### 3.2 检测方法对比

| 检测方法 | 原理 | 优点 | 缺点 | 适用攻击 |
|---------|------|------|------|---------|
| 标签分布分析 | 统计标签比例 | 简单快速 | 低投毒率失效 | 标签翻转 |
| 文本模式检测 | 后缀频率分析 | 直观 | 易被变体绕过 | 简单后门 |
| 统计异常检测 | Z-score 分析 | 通用 | 误报率高 | 通用 |
| 激活聚类 | 中间层特征聚类 | 效果好 | 需要模型访问权 | 后门攻击 |
| 谱签名 | 协方差分析 | 理论保证 | 计算成本高 | 后门攻击 |

## 4. 防御策略

### 4.1 数据清洗

```python
class DataSanitizer:
    """数据清洗器"""

    def __init__(self):
        self.detector = PoisoningDetector()

    def sanitize_dataset(self, dataset: List[Dict]) -> Tuple[List[Dict], Dict]:
        """清洗数据集"""
        clean_data = []
        report = {
            "original_size": len(dataset),
            "removed": 0,
            "reasons": {}
        }

        for sample in dataset:
            if self._is_clean(sample):
                clean_data.append(sample)
            else:
                report["removed"] += 1

        report["clean_size"] = len(clean_data)
        report["removal_rate"] = report["removed"] / report["original_size"]

        return clean_data, report

    def _is_clean(self, sample: Dict) -> bool:
        """检查样本是否干净"""
        text = sample.get("text", "") if "text" in sample else sample.get("input", "")

        if len(text) > 10000 or len(text) < 10:
            return False

        special_ratio = sum(1 for c in text if not c.isalnum() and not c.isspace()) / max(len(text), 1)
        if special_ratio > 0.3:
            return False

        return True
```

### 4.2 差分隐私训练

```python
class DifferentiallyPrivateTrainer:
    """差分隐私训练 — 限制单个样本对模型的影响"""

    def __init__(self, model, epsilon: float = 1.0, delta: float = 1e-5,
                 max_grad_norm: float = 1.0):
        self.model = model
        self.epsilon = epsilon
        self.delta = delta
        self.max_grad_norm = max_grad_norm

    def clip_gradients(self, gradients: List):
        """梯度裁剪"""
        total_norm = sum(g.norm() ** 2 for g in gradients) ** 0.5
        if total_norm > self.max_grad_norm:
            clip_factor = self.max_grad_norm / total_norm
            gradients = [g * clip_factor for g in gradients]
        return gradients

    def add_noise(self, gradients: List, batch_size: int):
        """添加高斯噪声"""
        noise_scale = self.max_grad_norm * (2 * np.log(1.25 / self.delta)) ** 0.5 / self.epsilon
        noisy_gradients = []
        for g in gradients:
            noise = torch.randn_like(g) * noise_scale / batch_size
            noisy_gradients.append(g + noise)
        return noisy_gradients

    def train_step(self, batch: List[Dict]):
        """差分隐私训练步骤"""
        gradients = []
        for sample in batch:
            grad = self.model.compute_gradient(sample["text"], sample["label"])
            gradients.append(grad)

        gradients = self.clip_gradients(gradients)
        gradients = self.add_noise(gradients, len(batch))

        avg_gradient = sum(gradients) / len(gradients)
        self.model.apply_gradient(avg_gradient)
```

## 5. 常见误区

1. **"数据投毒不常见"**: 投毒是实际存在的威胁，尤其在众包标注和开源数据集中
2. **"只关注模型安全"**: 数据安全同样重要，是模型安全的基础
3. **"开源数据可信"**: 需要验证数据来源，开源数据集也可能被投毒
4. **"一次清洗足够"**: 需要持续监控，新数据可能持续被投毒
5. **"只关注准确性"**: 需要检测后门，高准确率不代表模型安全
6. **"低投毒率无害"**: 后门攻击在 1% 投毒率下仍可成功

## 工程建议

- 对所有外部数据源建立溯源和完整性校验机制：记录每条数据的来源、采集时间、标注者信息，并对新引入的数据集做标签分布分析和文本模式扫描，异常数据隔离后再人工复核。
- 在模型训练流程中加入激活聚类检测环节：定期用干净验证集和待检数据分别提取中间层特征，若待检样本在特征空间中形成独立簇，则高度疑似后门样本，应触发人工审核。
- 对高安全要求的场景采用差分隐私训练，通过梯度裁剪和噪声注入限制单个样本对模型的最大影响，即使存在少量投毒样本也能将其影响稀释到可接受范围。
- 建立模型上线前的后门检测清单：在推理阶段用已知触发器模式做黑盒测试，同时用 Neural Cleanse 等方法做逆向触发器扫描，确保模型在部署前通过后门安全审查。

## 总结

- 数据投毒通过操纵训练数据影响模型行为
- 后门攻击是最危险的投毒攻击类型，可在低投毒率下成功
- 检测方法包括标签分析、模式检测、统计异常、激活聚类等
- 防御策略包括数据清洗、差分隐私训练、持续监控
- 需要建立完整的数据安全防护体系
