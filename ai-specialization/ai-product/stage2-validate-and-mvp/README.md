# 阶段 2：验证与 MVP

> 在写一行代码之前，先确认用户真的需要你的产品。然后用最小成本搭建一个能验证核心价值的 MVP。

## 学习目标

- 掌握"假门测试"、Landing Page、用户访谈等低成本验证方法
- 学会区分"用户说想要"和"用户真的会用"——用行为数据说话
- 理解 MVP 不是"做得少"，而是"只做能验证假设的部分"
- 能设计并搭建一个有完整用户旅程的 MVP，哪怕是用无代码工具拼的

## 课时列表

1. 为什么大多数 AI 产品死于"没人需要"
2. 验证方法论：假门测试、Landing Page、预售、用户访谈
3. 用户访谈实操：怎么问出真话而不是客套话
4. MVP 设计：核心用户旅程与功能裁剪
5. 用 Next.js 搭建 Landing Page：收集 waitlist 和用户反馈
6. 原型工具：Figma / Bolt / v0 快速出可交互原型
7. 数据埋点：从第一天就为迭代做准备
8. **阶段实战：完成 MVP 原型与首轮用户验证**

## 交付物

- **验证报告**：包含验证假设、实验方法、数据结果、结论和下一步决策
- **Landing Page**：能收集 waitlist 的产品介绍页
- **MVP 原型**：可交互的产品原型或最小可用版本
- **用户访谈记录**：至少 5 个目标用户的结构化访谈摘要
