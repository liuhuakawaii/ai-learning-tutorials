# 第四课：48 小时 MVP 搭建

## 场景引入

技术选型做完了：Next.js + Vercel Postgres + OpenAI API + Vercel 部署。你准备开始写代码了。但你打开编辑器后发现——不知道从哪里开始。先做前端页面？还是先做 API？Prompt 怎么写？错误处理怎么做？要不要做 loading 状态？

别想太多，这一课会带你用 48 小时搭建一个可用的 MVP。我们会按照"先跑通核心流程，再补细节"的策略，一步步实现一个 AI 餐饮营销助手的完整 MVP。

## 学习目标

1. 掌握"先跑通再完善"的 MVP 开发策略
2. 学会用 Next.js 搭建全栈 AI 应用
3. 完成一个包含 AI 集成、数据库、部署的完整 MVP
4. 了解 MVP 开发中需要跳过和不能跳过的环节

## 一、48 小时开发计划

### 1.1 时间分配

```
Day 1（核心功能）：
├── 00:00 - 02:00：项目初始化 + 基础页面
├── 02:00 - 06:00：AI 集成（API 调用 + Prompt 设计）
├── 06:00 - 08:00：前后端联调
├── 08:00 - 10:00：数据库集成（存储生成记录）
└── 10:00 - 12:00：基础 UI 美化

Day 2（完善和部署）：
├── 00:00 - 02:00：错误处理 + Loading 状态
├── 02:00 - 04:00：用户反馈收集（简单表单）
├── 04:00 - 06:00：测试和修复
├── 06:00 - 08:00：部署上线
└── 08:00 - 12:00：最后调整 + 文档
```

### 1.2 开发原则

```
原则一：先跑通，再完善
- 先让 AI 能生成文案，再优化 UI
- 先能用，再好用

原则二：跳过一切非核心功能
- 不做用户注册系统
- 不做管理后台
- 不做复杂的数据分析

原则三：用最简单的方式解决问题
- 能用 CSS 解决的不写 JS
- 能用第三方库的不自己写
- 能硬编码的不做成配置
```

## 三、核心功能实现

### 3.1 AI 服务封装

```typescript
// src/lib/ai.ts
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

interface GenerateCopywritingParams {
  dishName: string;
  price: string;
  features: string;
  style: '种草' | '促销' | '日常';
}

const STYLE_PROMPTS = {
  '种草': '用种草博主的风格，强调美食体验，让人看了就想来吃。加入表情符号，语气亲切活泼。',
  '促销': '用促销活动的风格，突出性价比和限时优惠。营造紧迫感，吸引用户到店消费。',
  '日常': '用日常分享的风格，像朋友推荐一样自然真实。不要太商业化，让人感觉真诚。',
};

export async function generateCopywriting(params: GenerateCopywritingParams): Promise<string> {
  const { dishName, price, features, style } = params;

  const prompt = `请为以下菜品生成一条小红书风格的营销文案：

菜品名称：${dishName}
价格：${price}
特色：${features}

风格要求：${STYLE_PROMPTS[style]}

要求：
1. 文案长度 200-300 字
2. 包含 3-5 个相关话题标签（#xxx）
3. 开头要有吸引力，让人想继续看
4. 包含具体的价格信息
5. 结尾要有行动号召（如"快来尝尝"）
6. 适当使用 emoji 表情`;

  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      {
        role: 'system',
        content: '你是一个专业的餐饮营销文案写手，擅长小红书风格的内容创作。你的文案能让读者看了就想来餐厅消费。'
      },
      {
        role: 'user',
        content: prompt
      }
    ],
    temperature: 0.8,
    max_tokens: 1000,
  });

  return response.choices[0].message.content || '生成失败，请重试';
}
```

### 3.2 API 路由

```typescript
// src/app/api/generate/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { generateCopywriting } from '@/lib/ai';

export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    const { dishName, price, features, style } = body;

    // 基础校验
    if (!dishName || !price) {
      return NextResponse.json(
        { error: '请填写菜品名称和价格' },
        { status: 400 }
      );
    }

    // 生成文案
    const copywriting = await generateCopywriting({
      dishName,
      price,
      features: features || '',
      style: style || '种草',
    });

    return NextResponse.json({ copywriting });
  } catch (error) {
    console.error('生成失败:', error);
    return NextResponse.json(
      { error: '生成失败，请稍后重试' },
      { status: 500 }
    );
  }
}
```

export default function Home() {
  const [dishName, setDishName] = useState('');

  const [features, setFeatures] = useState('');

  const handleGenerate = async () => {

    finally { setLoading(false); }

export async function saveGeneration(params: {
  dishName: string; price: string; features: string; style: string; copywriting: string;

## 常见误区

### 误区一：追求完美再上线

"UI 还不够好看"、"还有一个小 bug"、"功能还没做完"——这些都不是不上线的理由。MVP 的目的是验证，不是展示。能用就上线。

### 误区二：花太多时间在 UI 上

MVP 阶段的 UI 只需要"不难用"，不需要"好看"。Tailwind CSS 的默认样式加上一些圆角和阴影，就已经足够了。

### 误区三：忽视错误处理

"先不管错误处理，以后再加"——不行。AI API 一定会出错（超时、限流、返回异常），你必须在 MVP 阶段就处理好基本的错误场景。

### 误区四：一个人闷头开发

不要一个人开发两周才给用户看。每完成一个核心功能就找人试用，尽早获取反馈。

## 工程建议

### 1. 先写 API，再写前端

先确保 AI API 能正常调用并返回结果，再做前端页面。这样你可以用 Postman 或 curl 测试 API，不需要等前端完成。

### 2. 用 AI 辅助开发

用 Cursor、GitHub Copilot 等 AI 工具加速开发。MVP 阶段不需要每行代码都自己写。

### 3. 保持代码简单

MVP 阶段的代码不需要设计模式、不需要过度抽象。简单的函数、简单的组件、简单的逻辑。验证通过后再重构。

### 4. 准备回滚方案

部署前确保可以快速回滚。Vercel 支持一键回滚到上一个版本。如果线上出问题，能在 1 分钟内恢复。

## 小结

- 48 小时开发策略：Day 1 做核心功能，Day 2 做完善和部署
- 先跑通 AI API → 做前端页面 → 联调 → 加数据库 → 部署
- 跳过所有非核心功能，用最简单的方式替代
- 上线后立即找目标用户试用，收集反馈
- 不要追求完美，能用就上线

    if (!dishName || !price) {
      setError('请填写菜品名称和价格');
      return;
    }
    setError('');
    setLoading(true);
    setResult('');

    try {
      const res = await fetch('/api/generate', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ dishName, price, features, style }),
      });
      const data = await res.json();
      if (data.error) {
        setError(data.error);
        return;
      }
      setResult(data.copywriting);
    } catch {
      setError('网络错误，请重试');
    } finally {
      setLoading(false);
    }
  };

  const handleCopy = () => {
    navigator.clipboard.writeText(result);
    alert('已复制到剪贴板');
  };

  return (
    <main className="min-h-screen bg-gray-50 py-12">
      <div className="max-w-2xl mx-auto px-6">
        <h1 className="text-3xl font-bold text-center mb-8">AI 餐饮营销助手</h1>

        {/* 输入表单 */}
        <div className="bg-white rounded-xl p-6 shadow-sm mb-6">
          <div className="space-y-4">
            <div>
              <label className="block text-sm font-medium mb-1">菜品名称 *</label>
              <input
                type="text"
                value={dishName}
                onChange={(e) => setDishName(e.target.value)}
                placeholder="如：红烧肉"
                className="w-full px-4 py-2 border rounded-lg"
              />
            </div>
            <div>
              <label className="block text-sm font-medium mb-1">价格 *</label>
              <input
                type="text"
                value={price}
                onChange={(e) => setPrice(e.target.value)}
                placeholder="如：¥38"
                className="w-full px-4 py-2 border rounded-lg"
              />
            </div>
            <div>
              <label className="block text-sm font-medium mb-1">特色描述</label>
              <textarea
                value={features}
                onChange={(e) => setFeatures(e.target.value)}
                placeholder="如：肥而不腻，入口即化，招牌菜"
                rows={2}
                className="w-full px-4 py-2 border rounded-lg"
              />
            </div>
            <div>
              <label className="block text-sm font-medium mb-2">文案风格</label>
              <div className="flex gap-3">
                {(['种草', '促销', '日常'] as const).map((s) => (
                  <button
                    key={s}
                    onClick={() => setStyle(s)}
                    className={`px-4 py-2 rounded-lg text-sm ${
                      style === s
                        ? 'bg-orange-500 text-white'
                        : 'bg-gray-100 text-gray-700 hover:bg-gray-200'
                    }`}
                  >
                    {s}
                  </button>
                ))}
              </div>
            </div>
          </div>

          {error && <p className="text-red-500 text-sm mt-3">{error}</p>}

          <button
            onClick={handleGenerate}
            disabled={loading}
            className="w-full mt-6 bg-orange-500 text-white py-3 rounded-lg font-medium hover:bg-orange-600 disabled:opacity-50"
          >
            {loading ? '生成中...' : '一键生成文案'}
          </button>
        </div>

        {/* 结果展示 */}
        {result && (
          <div className="bg-white rounded-xl p-6 shadow-sm">
            <div className="flex justify-between items-center mb-3">
              <h2 className="font-medium">生成结果</h2>
              <button
                onClick={handleCopy}
                className="text-sm bg-orange-100 text-orange-600 px-4 py-1.5 rounded-lg hover:bg-orange-200"
              >
                复制文案
              </button>
            </div>
            <p className="text-gray-700 whitespace-pre-wrap">{result}</p>
          </div>
        )}
      </div>
    </main>
  );
}
