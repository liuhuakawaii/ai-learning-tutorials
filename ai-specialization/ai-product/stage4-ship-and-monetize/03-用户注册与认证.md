# 第3课：用户注册与认证

> **课程定位**：实现安全可靠的用户认证系统，支持多种登录方式
> **前置知识**：有 Next.js 开发经验，了解 HTTP 和 Cookie 基础
> **预计时长**：35 分钟

---

## 场景引入

你的 AI 产品上线了，但用户打开页面就能直接用——没有任何登录机制。你不知道谁在用、用了多少次、能不能收费。更糟的是，有人发现你的 API 没有认证，直接调用你的接口白嫖 AI 能力。你需要一套用户认证系统：让用户能方便地注册登录，同时保护你的 API 不被滥用。

---

完成本课学习后，你将能够：

1. 选择适合的认证方案（OAuth / Magic Link / 邮箱密码）

```typescript
// lib/auth.ts
import NextAuth from 'next-auth'
import Google from 'next-auth/providers/google'
import GitHub from 'next-auth/providers/github'
import { PrismaAdapter } from '@auth/prisma-adapter'
import { prisma } from './db'

export const { handlers, auth, signIn, signOut } = NextAuth({
  adapter: PrismaAdapter(prisma),
  providers: [
    Google({
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    }),
    GitHub({
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    }),
  ],
  callbacks: {
    // 将 userId 和 plan 加入 session
    async session({ session, user }) {
      session.user.id = user.id
      const dbUser = await prisma.user.findUnique({
        where: { id: user.id },
        select: { plan: true },
      })
      session.user.plan = dbUser?.plan ?? 'free'
      return session
    },
  },
  pages: {
    signIn: '/login',
    error: '/login',
  },
})

// app/api/auth/[...nextauth]/route.ts
import { handlers } from '@/lib/auth'
export const { GET, POST } = handlers
```

## 三、API 认证中间件

### 3.1 Session 验证

```typescript
// lib/auth/middleware.ts
import { auth } from '@/lib/auth'
import { NextRequest, NextResponse } from 'next/server'

export function withAuth(handler: (req: NextRequest, userId: string) => Promise<Response>) {
  return async (req: NextRequest) => {
    const session = await auth()

    if (!session?.user?.id) {
      return NextResponse.json({ error: '请先登录' }, { status: 401 })
    }

    return handler(req, session.user.id)
  }
}

// 使用示例
export const POST = withAuth(async (req, userId) => {
  const body = await req.json()
  // userId 已经验证过，可以直接使用
  const result = await doSomething(userId, body)
  return Response.json(result)
})
```

```typescript
export function withPlan(requiredPlan: 'pro' | 'team') {
  return function (handler: Function) {
    return withAuth(async (req, userId) => {
      const user = await db.user.findUnique({ where: { id: userId } })

      const planLevel = { free: 0, pro: 1, team: 2 }
      const userLevel = planLevel[user?.plan as keyof typeof planLevel] ?? 0

        return Response.json(
          { error: `此功能需要 ${requiredPlan} 订阅`, upgradeUrl: '/pricing' },
          { status: 403 }
        )
      }

      return handler(req, userId)
    })
  }
}
```

## 四、用户配额管理

```typescript
// lib/quota.ts
export async function checkAndConsumeQuota(userId: string, feature: string): Promise<{
  allowed: boolean
  remaining: number
  limit: number
}> {
  const user = await db.user.findUnique({ where: { id: userId } })
  const limits = getPlanLimits(user?.plan ?? 'free')

  const today = new Date().toISOString().split('T')[0]
  const usage = await db.usageLog.count({
    where: { userId, feature, date: today },
  })

  const limit = limits[feature as keyof typeof limits] ?? 0
  const allowed = usage < limit

  if (allowed) {
    await db.usageLog.create({
      data: { userId, feature, date: today },
    })
  }

  return { allowed, remaining: Math.max(0, limit - usage - 1), limit }
}

function getPlanLimits(plan: string) {
  const limits = {
    free: { chat: 20, document: 5, agent: 5 },
    pro: { chat: 200, document: 50, agent: 50 },
    team: { chat: 1000, document: 200, agent: 200 },
  }
  return limits[plan as keyof typeof limits] ?? limits.free
}

// 在 API Route 中使用
export const POST = withAuth(async (req, userId) => {
  const quota = await checkAndConsumeQuota(userId, 'chat')

  if (!quota.allowed) {
    return Response.json(
      {
        error: '已达到今日使用上限',
        remaining: quota.remaining,
        limit: quota.limit,
        upgradeUrl: '/pricing',
      },
      { status: 429 }
    )
  }

  // 继续处理...
})
```

```typescript
import { useAuth } from '@/hooks/useAuth'
import { useRouter } from 'next/navigation'
import { useEffect } from 'react'

export function AuthGuard({ children, requiredPlan }: {
  children: React.ReactNode
  requiredPlan?: 'pro' | 'team'
}) {
  const { isAuthenticated, isLoading, plan } = useAuth()
  const router = useRouter()

  useEffect(() => {
    if (!isLoading && !isAuthenticated) {
      router.push('/login')
    }
  }, [isLoading, isAuthenticated, router])

  if (isLoading) return <LoadingSpinner />
  if (!isAuthenticated) return null

  if (requiredPlan) {
    const planLevel = { free: 0, pro: 1, team: 2 }
    if ((planLevel[plan] ?? 0) < planLevel[requiredPlan]) {
      return <UpgradePrompt requiredPlan={requiredPlan} />
    }
  }

  return <>{children}</>
}
```

## 常见误区

### 误区一：自己实现加密算法

永远不要自己实现密码加密、Token 生成等安全逻辑。用成熟的库（bcrypt、jose）和框架（NextAuth.js）。自己实现的安全机制几乎必然有漏洞。

### 误区二：Session 存在 LocalStorage

LocalStorage 容易被 XSS 攻击读取。Session Token 应该存在 HttpOnly Cookie 中，前端 JavaScript 无法访问。NextAuth.js 默认就是这么做的。

### 误区三：只做前端认证

前端的 `useSession` 检查只是用户体验层面的，不是安全层面的。每个 API Route 都必须独立验证 Session，不能假设前端传来的数据是可信的。

### 误区四：忽略账号关联

用户可能用 Google 登录后再用 GitHub 登录。如果两个 OAuth 账号的邮箱相同，应该关联到同一个用户，而不是创建两个账号。

---

## 工程建议

### 1. 优先用 OAuth，降低注册门槛

Google 登录一键完成，比让用户填邮箱、设密码、验证邮箱的流程简单 10 倍。注册转化率直接影响用户增长。

### 2. 新用户自动创建免费配额

用户注册后自动获得免费套餐的配额，不需要额外操作。让用户先体验价值，再考虑付费。

### 3. 登录状态要持久

用户不想每天登录。设置合理的 Session 过期时间（建议 30 天），并实现无感刷新。

### 4. 记录登录日志

记录每次登录的时间、IP、设备。这是安全审计和异常检测的基础。

---

## 小结

用户认证是产品商业化的基础。优先用 OAuth（Google/GitHub）降低注册门槛，用 NextAuth.js 处理复杂的认证逻辑。核心要点：Session 存在 HttpOnly Cookie、每个 API 独立验证、Plan 权限检查在服务端完成。

### 练习三：配额管理

**思路**：基于课程中的 `checkAndConsumeQuota` 函数，按套餐限制每日使用次数，超出时返回 429 和升级提示。

**答案**：

```typescript
// lib/quota.ts
import { prisma } from './db'

interface QuotaResult {
  allowed: boolean
  remaining: number
  limit: number
  plan: string
}

function getPlanLimits(plan: string) {
  const limits: Record<string, Record<string, number>> = {
    free: { chat: 20, document: 5, agent: 5 },
    pro: { chat: 200, document: 50, agent: 50 },
    team: { chat: 1000, document: 200, agent: 200 },
  }
  return limits[plan] ?? limits.free
}

export async function checkAndConsumeQuota(userId: string, feature: string): Promise<QuotaResult> {
  const user = await prisma.user.findUnique({ where: { id: userId } })
  const plan = user?.plan ?? 'free'
  const limits = getPlanLimits(plan)
  const limit = limits[feature] ?? 0

  const today = new Date().toISOString().split('T')[0]
  const usage = await prisma.usageLog.count({
    where: { userId, feature, date: today },
  })

  const remaining = Math.max(0, limit - usage)
  const allowed = remaining > 0

  if (allowed) {
    await prisma.usageLog.create({
      data: { userId, feature, date: today },
    })
  }

  return { allowed, remaining: remaining - (allowed ? 1 : 0), limit, plan }
}
```

```typescript
  const { message } = await req.json()

    reply: `AI 回复: ${message}`,
    quota: { remaining: quota.remaining, limit: quota.limit },
  })
}
```

### 练习四：用户信息展示

**思路**：在 Dashboard 页面读取 session 中的用户信息和数据库中的使用量数据。

**答案**：

```tsx
// app/(dashboard)/dashboard/page.tsx
import { auth } from '@/lib/auth'
import { prisma } from '@/lib/db'

async function getUserStats(userId: string) {
  const today = new Date().toISOString().split('T')[0]
  const monthStart = new Date()
  monthStart.setDate(1)
  monthStart.setHours(0, 0, 0, 0)

  const [todayUsage, monthUsage, user] = await Promise.all([
    prisma.usageLog.count({ where: { userId, date: today } }),
    prisma.usageLog.count({ where: { userId, createdAt: { gte: monthStart } } }),
    prisma.user.findUnique({
      where: { id: userId },
      select: { plan: true, createdAt: true, accounts: { select: { provider: true } } },
    }),
  ])

  return {
    plan: user?.plan ?? 'free',
    provider: user?.accounts?.[0]?.provider ?? 'unknown',
    memberSince: user?.createdAt,
    todayUsage,
    monthUsage,
  }
}

export default async function DashboardPage() {
  const session = await auth()
  const stats = await getUserStats(session!.user.id)

  const planLimits: Record<string, { chat: number }> = {
    free: { chat: 20 },
    pro: { chat: 200 },
    team: { chat: 1000 },
  }
  const limit = planLimits[stats.plan]?.chat ?? 20

  return (
    <div className="space-y-6">
      <h1 className="text-2xl font-bold">概览</h1>

      <div className="grid md:grid-cols-4 gap-4">
        <div className="bg-white rounded-lg p-6 shadow-sm">
          <p className="text-sm text-gray-500">登录方式</p>
          <p className="text-xl font-bold capitalize">{stats.provider}</p>
        </div>

        <div className="bg-white rounded-lg p-6 shadow-sm">
          <p className="text-sm text-gray-500">当前套餐</p>
          <p className="text-xl font-bold capitalize">{stats.plan}</p>
        </div>

        <div className="bg-white rounded-lg p-6 shadow-sm">
          <p className="text-sm text-gray-500">今日使用</p>
          <p className="text-xl font-bold">{stats.todayUsage} / {limit}</p>
          <div className="mt-2 h-2 bg-gray-200 rounded-full overflow-hidden">
            <div
              className="h-full bg-blue-600 rounded-full"
              style={{ width: `${Math.min(100, (stats.todayUsage / limit) * 100)}%` }}
            />
          </div>
        </div>

        <div className="bg-white rounded-lg p-6 shadow-sm">
          <p className="text-sm text-gray-500">本月使用</p>
          <p className="text-xl font-bold">{stats.monthUsage}</p>
        </div>
      </div>

      {stats.plan === 'free' && stats.todayUsage >= limit * 0.8 && (
        <div className="bg-yellow-50 border border-yellow-200 rounded-lg p-4">
          <p className="text-yellow-800">
            今日使用量已接近上限，<a href="/pricing" className="underline font-medium">升级 Pro</a> 获取更多额度。
          </p>
        </div>
      )}
    </div>
  )
}
```

**要点**：
- 登录方式从 `accounts` 表读取 `provider` 字段（google/github）
- 使用量条形图用百分比宽度实现，超过 80% 时显示升级提示
- 所有数据在服务端获取，客户端不需要额外的 API 调用
