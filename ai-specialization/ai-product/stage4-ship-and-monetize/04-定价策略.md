## 场景引入

你做了一个 AI 写作工具，上线后有 1000 个注册用户。你定了一个价格：每月 99 元。结果一个月只有 3 个人付费。你降价到 49 元，付费人数变成了 5 个。你困惑了——是价格的问题，还是产品的问题，还是定价策略本身就有问题？定价不是拍脑袋定一个数字，而是一套需要设计的策略。

## 一、定价模型概览

### 1.1 四种主流定价模型

```
┌─────────────────────────────────────────────────────────────┐
│                    SaaS 定价模型                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 免费增值（Freemium）                                     │
│     基础功能免费，高级功能收费                                │
│     适合：需要快速获取用户的产品                              │
│     风险：免费用户转化率通常只有 2-5%                         │
│                                                             │
│  2. 按量计费（Usage-Based）                                  │
│     按使用量收费（API 调用次数、存储空间等）                   │
│     适合：使用量差异大的产品                                  │
│     风险：收入不可预测                                       │
│                                                             │
│  3. 订阅制（Subscription）                                   │
│     按月/年固定费用                                          │
│     适合：持续提供价值的产品                                  │
│     风险：用户可能用得少就不续费                              │
│                                                             │
│  4. 分层定价（Tiered）                                       │
│     多个套餐，功能和用量递增                                  │
│     适合：用户群体需求差异大的产品                            │
│     风险：套餐设计复杂，用户选择困难                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 三、定价计算

### 3.1 成本导向定价

```typescript
// 定价计算工具
function calculatePricing(params: {
  modelCostPer1kTokens: number    // 每 1k token 的成本
  avgTokensPerRequest: number     // 每次请求的平均 token 数
  monthlyRequests: number         // 预期月请求量
  targetMargin: number            // 目标毛利率（0.3 = 30%）
  otherCostPerUser: number        // 每用户其他成本（服务器、人力等）
}): { suggestedPrice: number; costPerUser: number; margin: number } {
  const {
    modelCostPer1kTokens,
    avgTokensPerRequest,
    monthlyRequests,
    targetMargin,
    otherCostPerUser,
  } = params

  // AI 调用成本
  const aiCostPerUser = (modelCostPer1kTokens * avgTokensPerRequest * monthlyRequests) / 1000

  // 总成本
  const totalCostPerUser = aiCostPerUser + otherCostPerUser

  // 建议价格（成本 / (1 - 毛利率)）
  const suggestedPrice = Math.ceil(totalCostPerUser / (1 - targetMargin))

  return {
    suggestedPrice,
    costPerUser: totalCostPerUser,
    margin: (suggestedPrice - totalCostPerUser) / suggestedPrice,
  }
}

// 示例计算
const result = calculatePricing({
  modelCostPer1kTokens: 0.005,  // GPT-4o-mini: $0.15 / 1M input
  avgTokensPerRequest: 2000,
  monthlyRequests: 500,
  targetMargin: 0.7,  // 70% 毛利
  otherCostPerUser: 2,  // 服务器等
})

// 结果：建议价格 $14/月，成本 $4.5/月，毛利率 68%
```

## 四、用量限制实现

```typescript
// lib/usage-limits.ts
export class UsageLimiter {
  // 检查并消耗配额
  static async consume(userId: string, feature: string): Promise<{
    allowed: boolean
    remaining: number
    limit: number
    resetAt: string
  }> {
    const user = await db.user.findUnique({ where: { id: userId } })
    const plan = user?.plan ?? 'free'
    const limits = getPlanLimits(plan)

    const limit = limits[feature] ?? 0
    if (limit === -1) {
      // 无限
      return { allowed: true, remaining: -1, limit: -1, resetAt: '' }
    }

    // 获取当月使用量
    const monthStart = new Date()
    monthStart.setDate(1)
    monthStart.setHours(0, 0, 0, 0)

    const usage = await db.usageLog.count({
      where: {
        userId,
        feature,
        createdAt: { gte: monthStart },
      },
    })

    const remaining = Math.max(0, limit - usage)
    const allowed = remaining > 0

    if (allowed) {
      await db.usageLog.create({ data: { userId, feature } })
    }

    const resetAt = new Date(monthStart)
    resetAt.setMonth(resetAt.getMonth() + 1)

    return { allowed, remaining: remaining - 1, limit, resetAt: resetAt.toISOString() }
  }
}

// 使用中间件
export function withUsageLimit(feature: string) {
  return function (handler: Function) {
    return withAuth(async (req, userId) => {
      const quota = await UsageLimiter.consume(userId, feature)

      if (!quota.allowed) {
        return Response.json({
          error: '已达到本月使用上限',
          quota,
          upgradeUrl: '/pricing',
        }, { status: 429 })
      }

      // 在响应头中返回配额信息
      const response = await handler(req, userId)
      response.headers.set('X-Usage-Remaining', quota.remaining.toString())
      response.headers.set('X-Usage-Limit', quota.limit.toString())

      return response
    })
  }
}
```

## 常见误区

### 误区一：定价太低

很多独立开发者害怕定价太高，结果定的价格覆盖不了成本。AI 产品的成本不低——每次 API 调用都有实实在在的费用。定价必须覆盖成本并留出利润空间。

### 误区二：免费层给太多

免费层的目的是让用户体验价值，不是让用户免费用到底。给太多免费额度，用户没有升级的动力。

### 误区三：只有一种价格

不同用户的需求差异很大。个人用户和团队用户、偶尔使用和重度用户——他们愿意支付的价格完全不同。分层定价能最大化收入。

### 误区四：定价一成不变

定价不是一次性的决定。随着产品迭代、成本变化、竞争环境变化，定价也需要调整。每季度审视一次定价策略。

---

## 工程建议

### 1. 先验证价值，再谈定价

在定价之前，先确认产品确实解决了用户的问题。用户说"这个工具太棒了"比"这个工具太贵了"更说明问题。

### 2. 年付打折锁定用户

年付 8 折是行业惯例。好处是提高现金流可预测性，降低用户流失率。

### 3. 定价页面要清晰

用户看不懂的定价 = 用户不付费。套餐对比要一目了然，每个套餐的核心差异用一句话说清楚。

### 4. 监控定价指标

关注：免费→付费转化率、各套餐选择比例、流失原因。这些数据是调整定价的依据。

---

## 小结

定价是产品变现的核心决策。AI 产品推荐"免费增值 + 分层订阅"的模式：免费层让用户体验价值，Pro 层满足个人专业需求，Team 层服务团队协作。定价要基于成本和价值双重考量，不能拍脑袋决定。

## 参考答案

### 练习一：成本计算

**思路**：拆分 AI 调用成本和其他固定成本（服务器、域名、SaaS 工具），用课程中的公式计算单用户月度成本。

**答案**：

```typescript
// lib/pricing-calculator.ts

interface CostBreakdown {
  aiCost: number
  serverCost: number
  thirdPartyCost: number
  totalCost: number
  suggestedPrice: number
  margin: number
}

function calculateMonthlyCost(params: {
  model: 'gpt-4o-mini' | 'gpt-4o' | 'claude-3-5-sonnet'
  avgInputTokens: number
  avgOutputTokens: number
  monthlyRequestsPerUser: number
  serverCostPerMonth: number    // 服务器月费（Vercel Pro、数据库等）
  expectedPayingUsers: number   // 预期付费用户数
  targetMargin: number          // 目标毛利率
}): CostBreakdown {
  const modelPricing = {
    'gpt-4o-mini': { input: 0.15 / 1_000_000, output: 0.60 / 1_000_000 },
    'gpt-4o': { input: 2.50 / 1_000_000, output: 10.00 / 1_000_000 },
    'claude-3-5-sonnet': { input: 3.00 / 1_000_000, output: 15.00 / 1_000_000 },
  }

  const pricing = modelPricing[params.model]

  // 单次 AI 调用成本
  const costPerRequest = (params.avgInputTokens * pricing.input) + (params.avgOutputTokens * pricing.output)

  // 单用户月度 AI 成本
  const aiCostPerUser = costPerRequest * params.monthlyRequestsPerUser

  // 分摊到每个用户的服务器成本
  const serverCostPerUser = params.serverCostPerMonth / Math.max(1, params.expectedPayingUsers)

  // 第三方 SaaS 成本（Sentry、邮件服务等）
  const thirdPartyCostPerUser = 0.5  // 假设每人 $0.5/月

  const totalCost = aiCostPerUser + serverCostPerUser + thirdPartyCostPerUser
  const suggestedPrice = Math.ceil(totalCost / (1 - params.targetMargin))

  return {
    aiCost: Math.round(aiCostPerUser * 100) / 100,
    serverCost: Math.round(serverCostPerUser * 100) / 100,
    thirdPartyCost: thirdPartyCostPerUser,
    totalCost: Math.round(totalCost * 100) / 100,
    suggestedPrice,
    margin: Math.round((1 - totalCost / suggestedPrice) * 100) / 100,
  }
}

// 示例：AI 写作工具的成本计算
const result = calculateMonthlyCost({
  model: 'gpt-4o-mini',
  avgInputTokens: 1500,
  avgOutputTokens: 800,
  monthlyRequestsPerUser: 500,  // Pro 用户每月 500 次
  serverCostPerMonth: 100,      // Vercel Pro $20 + 数据库 $30 + 其他 $50
  expectedPayingUsers: 50,
  targetMargin: 0.7,
})

console.log('成本明细:', result)
// 输出示例：
// {
//   aiCost: 0.30,        // 每用户 AI 调用成本
//   serverCost: 2.00,    // 分摊的服务器成本
//   thirdPartyCost: 0.50, // 第三方工具
//   totalCost: 2.80,     // 总成本
//   suggestedPrice: 10,  // 建议定价 $10/月
//   margin: 0.72         // 实际毛利率 72%
// }
```

**要点**：
- AI 成本是变动成本，随用户使用量变化；服务器成本是固定成本，需按用户数分摊
- 不同模型成本差异巨大：GPT-4o-mini 是 GPT-4o 的 1/10
- 定价 = 成本 / (1 - 目标毛利率)，目标毛利建议 60-75%

### 练习四：配额管理

**思路**：实现 UsageLimiter 类，按月统计使用量，通过中间件在 API Route 中自动检查配额。

**答案**：

```typescript
// lib/usage-limits.ts
import { prisma } from './db'

export class UsageLimiter {
  static async consume(userId: string, feature: string): Promise<{
    allowed: boolean
    remaining: number
    limit: number
    resetAt: string
  }> {
    const user = await prisma.user.findUnique({ where: { id: userId } })
    const plan = user?.plan ?? 'free'
    const limits = this.getPlanLimits(plan)
    const limit = limits[feature] ?? 0

    // -1 表示无限
    if (limit === -1) {
      return { allowed: true, remaining: -1, limit: -1, resetAt: '' }
    }

    // 获取当月使用量
    const monthStart = new Date()
    monthStart.setDate(1)
    monthStart.setHours(0, 0, 0, 0)

    const usage = await prisma.usageLog.count({
      where: { userId, feature, createdAt: { gte: monthStart } },
    })

    const remaining = Math.max(0, limit - usage)
    const allowed = remaining > 0

    if (allowed) {
      await prisma.usageLog.create({ data: { userId, feature } })
    }

    // 计算重置时间（下月 1 日）
    const resetAt = new Date(monthStart)
    resetAt.setMonth(resetAt.getMonth() + 1)

    return { allowed, remaining: remaining - (allowed ? 1 : 0), limit, resetAt: resetAt.toISOString() }
  }

  private static getPlanLimits(plan: string): Record<string, number> {
    const limits: Record<string, Record<string, number>> = {
      free: { chat: 50, document: 3, agent: 5 },
      pro: { chat: 500, document: 50, agent: 50 },
      team: { chat: 2000, document: -1, agent: 200 },
    }
    return limits[plan] ?? limits.free
  }
}

// lib/middleware/with-usage-limit.ts
import { auth } from '@/lib/auth'
import { UsageLimiter } from '@/lib/usage-limits'
import { NextRequest, NextResponse } from 'next/server'

export function withUsageLimit(feature: string) {
  return function (handler: (req: NextRequest, userId: string) => Promise<Response>) {
    return async (req: NextRequest) => {
      const session = await auth()
      if (!session?.user?.id) {
        return NextResponse.json({ error: '请先登录' }, { status: 401 })
      }

      const quota = await UsageLimiter.consume(session.user.id, feature)

      if (!quota.allowed) {
        return NextResponse.json(
          {
            error: `已达到本月${feature}使用上限`,
            quota: { remaining: 0, limit: quota.limit, resetAt: quota.resetAt },
            upgradeUrl: '/pricing',
          },
          { status: 429 }
        )
      }

      const response = await handler(req, session.user.id)
      response.headers.set('X-Usage-Remaining', quota.remaining.toString())
      response.headers.set('X-Usage-Limit', quota.limit.toString())
      response.headers.set('X-Usage-Reset', quota.resetAt)

      return response
    }
  }
}
```

```tsx
// components/QuotaBar.tsx - 前端展示配额
'use client'

export function QuotaBar({ remaining, limit }: { remaining: number; limit: number }) {
  if (limit === -1) return null  // 无限套餐不显示

  const percentage = (remaining / limit) * 100
  const color = percentage > 50 ? 'bg-green-500' : percentage > 20 ? 'bg-yellow-500' : 'bg-red-500'

  return (
    <div className="text-sm">
      <div className="flex justify-between mb-1">
        <span>本月剩余用量</span>
        <span className="font-medium">{remaining} / {limit}</span>
      </div>
      <div className="h-2 bg-gray-200 rounded-full overflow-hidden">
        <div className={`h-full ${color} rounded-full transition-all`} style={{ width: `${percentage}%` }} />
      </div>
      {percentage <= 20 && (
        <p className="text-red-600 mt-1">
          用量即将耗尽，<a href="/pricing" className="underline">升级套餐</a>获取更多额度
        </p>
      )}
    </div>
  )
}
```

**要点**：
- 按月统计使用量，下月 1 日自动重置
- 无限套餐返回 `limit: -1`，前端不展示配额条
- 响应头中返回 `X-Usage-Remaining`，前端可实时更新配额显示
