你的 AI 产品上线 3 个月，有 2000 个注册用户，但增长开始放缓。你知道需要做些什么来推动增长，但不确定什么有效。是优化 Onboarding？是做内容营销？是调整定价？还是加一个新功能？与其猜测，不如用实验来验证。这一课，你要设计一个增长实验，从假设到执行到分析结果，用数据告诉你答案。

### 2.2 实现 A/B 测试

```typescript
// lib/experiments/onboarding.ts
import { ABTest } from '@/lib/ab-testing'

export class OnboardingExperiment {
  private abTest: ABTest

  constructor(db: Database) {
    this.abTest = new ABTest(db)
  }

  // 初始化实验
  async setup() {
    return this.abTest.createExperiment({
      name: 'onboarding_simplification_v1',
      variants: [
        { name: 'control', weight: 0.5 },
        { name: 'treatment', weight: 0.5 },
      ],
      metric: 'activation_rate',
      minSampleSize: 400,
    })
  }

  // 获取用户的变体
  async getVariant(userId: string): Promise<'control' | 'treatment'> {
    const experiment = await this.getExperiment()
    return this.abTest.assignVariant(experiment.id, userId) as Promise<'control' | 'treatment'>
  }

  // 记录激活事件
  async trackActivation(userId: string) {
    const experiment = await this.getExperiment()
    await this.abTest.trackConversion(experiment.id, userId, 'activation_rate')
  }

  // 分析结果
  async analyze() {
    const experiment = await this.getExperiment()
    return this.abTest.analyze(experiment.id)
  }
}

// 在 Onboarding 页面中使用
// app/(onboarding)/onboarding/page.tsx
export default async function OnboardingPage() {
  const userId = await getCurrentUserId()
  const variant = await onboardingExperiment.getVariant(userId)

  if (variant === 'control') {
    return <OnboardingV1 />  // 原版 3 步引导
  } else {
    return <OnboardingV2 />  // 简化版 1 步引导
  }
}

// Onboarding 完成时记录激活
async function completeOnboarding(userId: string) {
  await onboardingExperiment.trackActivation(userId)
  redirect('/dashboard')
}
```

## 三、实验监控

```typescript
// lib/experiments/monitor.ts
export class ExperimentMonitor {
  async getExperimentStatus(experimentId: string) {
    const experiment = await db.experiment.findUnique({
      where: { id: experimentId },
    })

    // 各变体的样本量
    const variantCounts = await db.exposure.groupBy({
      by: ['variant'],
      where: { experimentId },
      _count: true,
    })

    // 各变体的转化数
    const conversionCounts = await db.conversion.groupBy({
      by: ['variant'],
      where: { experimentId, metric: experiment.metric },
      _count: true,
    })

    // 计算转化率和置信区间
    const results = variantCounts.map(vc => {
      const conversions = conversionCounts.find(cc => cc.variant === vc.variant)?._count ?? 0
      const rate = conversions / vc._count
      const ci = this.calculateConfidenceInterval(rate, vc._count)

      return {
        variant: vc.variant,
        exposures: vc._count,
        conversions,
        conversionRate: rate,
        confidenceInterval: ci,
      }
    })

    // 检查是否达到统计显著性
    const isSignificant = this.checkSignificance(results)

    return {
      experiment,
      results,
      isSignificant,
      recommendation: isSignificant ? this.getRecommendation(results) : '继续收集数据',
    }
  }

  private calculateConfidenceInterval(rate: number, n: number) {
    const z = 1.96  // 95% 置信度
    const se = Math.sqrt((rate * (1 - rate)) / n)
    return {
      lower: Math.max(0, rate - z * se),
      upper: Math.min(1, rate + z * se),
    }
  }

  private checkSignificance(results: any[]): boolean {
    if (results.length < 2) return false

    const control = results[0]
    const treatment = results[1]

    // 检查置信区间是否不重叠
    return treatment.confidenceInterval.lower > control.confidenceInterval.upper
  }

  private getRecommendation(results: any[]): string {
    const control = results[0]
    const treatment = results[1]

    if (treatment.conversionRate > control.conversionRate) {
      const lift = ((treatment.conversionRate - control.conversionRate) / control.conversionRate * 100).toFixed(1)
      return `推荐采用 treatment 变体，转化率提升 ${lift}%`
    } else {
      return '保持当前版本（control），treatment 未显示正向效果'
    }
  }
}
```

## 常见误区

### 误区一：实验只看主要指标

一个实验可能提升了激活率但降低了付费转化率。一定要检查次要指标，确保没有负面影响。

### 误区二：提前结束实验

看到正向结果就急着宣布成功。没有达到足够的样本量，结果可能是随机波动。耐心等到统计显著。

### 误区三：一次只做一个实验

如果你有足够的流量，可以同时运行多个不互相影响的实验。比如同时测 Onboarding 和定价页面。

### 误区四：实验失败就是浪费

没有效果的实验也是有价值的——它告诉你这条路走不通，省去了后续的投入。记录并分享所有实验结果。

---

## 工程建议

### 1. 从高影响、低成本的实验开始

优先做影响大、实现简单的实验。优化 Onboarding 文案比重构整个架构更容易见效。

### 2. 建立实验文化

让团队习惯用数据做决策。每个功能改动都可以是一个实验，每个实验都有明确的指标。

### 3. 记录所有实验

实验名称、假设、设计、结果、结论——都记录下来。这是团队的知识积累。

### 4. 保持实验节奏

不要几个月才做一个实验。保持每月 2-3 个实验的节奏，持续学习和优化。

---

## 小结

增长实验是数据驱动增长的核心方法。流程：提出假设 → 设计实验 → 实现变体 → 收集数据 → 分析结果 → 部署胜者。关键是建立持续的实验文化，保持每月 2-3 个实验的节奏。每个实验都是学习的机会，即使失败也有价值。

### 练习一：增长假设

**思路**：增长假设要基于数据而不是猜测。先看产品的数据，找到最大的流失点或增长机会，然后用"如果我们做 X，指标 Y 会提升 Z%"的格式提出假设。

**要点**：
- 假设要具体可衡量："提升 25%"而不是"提升很多"
- 假设要基于数据洞察，不能凭直觉
- 优先做"高影响、低成本"的假设（Quick Win）

### 练习二：实验设计

**思路**：选择优先级最高的假设，设计完整的实验方案。实验设计要回答五个问题：测什么、怎么分组、看什么指标、跑多久、怎么判断成功。

**答案**：

### 练习三：实验实现

**思路**：A/B 测试的实现要覆盖三个层面：分组逻辑、行为追踪、结果分析。代码要能正确处理分组、记录事件、防止数据污染。

**答案**：

```typescript
// A/B 测试完整实现

// 1. 实验配置
interface Experiment {
  id: string;
  name: string;
  variants: { id: string; weight: number }[];
  status: 'running' | 'paused' | 'completed';
  startDate: Date;
  endDate?: Date;
}

const experiments: Record<string, Experiment> = {
  'free-trial-exp': {
    id: 'free-trial-exp',
    name: '免注册试用实验',
    variants: [
      { id: 'control', weight: 50 },
      { id: 'variant', weight: 50 },
    ],
    status: 'running',
    startDate: new Date('2024-03-01'),
  },
};

// 2. 分组函数
function getVariant(experimentId: string, userId: string): string {
  const experiment = experiments[experimentId];
  if (!experiment || experiment.status !== 'running') {
    return 'control'; // 实验未运行时返回对照组
  }

  // 基于用户 ID + 实验 ID 的哈希分组
  const hash = hashCode(`${experimentId}:${userId}`);
  const bucket = hash % 100;

  let cumulative = 0;
  for (const variant of experiment.variants) {
    cumulative += variant.weight;
    if (bucket < cumulative) {
      return variant.id;
    }
  }
  return 'control';
}

// 简单的哈希函数
function hashCode(str: string): number {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    const char = str.charCodeAt(i);
    hash = ((hash << 5) - hash) + char;
    hash = hash & hash; // 转为 32 位整数
  }
  return Math.abs(hash);
}

// 3. 事件追踪
interface ExperimentEvent {
  experimentId: string;
  variantId: string;
  userId: string;
  event: string; // 'impression' | 'click' | 'register' | 'activate' | 'retain_7d' | 'pay'
  properties?: Record<string, any>;
  timestamp: Date;
}

async function trackExperimentEvent(event: Omit<ExperimentEvent, 'timestamp'>) {
  await db.insert('experiment_events', {
    ...event,
    timestamp: new Date(),
  });
}

// 4. 在产品代码中使用
async function handleLandingPageVisit(userId: string) {
  const variant = getVariant('free-trial-exp', userId);

  // 记录曝光
  await trackExperimentEvent({
    experimentId: 'free-trial-exp',
    variantId: variant,
    userId,
    event: 'impression',
  });

  // 根据分组渲染不同页面
  if (variant === 'control') {
    return renderLandingPage({ ctaText: '开始使用', ctaLink: '/register' });
  } else {
    return renderLandingPage({ ctaText: '免费试用', ctaLink: '/try-now' });
  }
}

// 5. 结果分析
async function analyzeExperiment(experimentId: string) {
  const results = await db.query(`
    SELECT
      variant_id,
      COUNT(DISTINCT CASE WHEN event = 'impression' THEN user_id END) as impressions,
      COUNT(DISTINCT CASE WHEN event = 'register' THEN user_id END) as registrations,
      COUNT(DISTINCT CASE WHEN event = 'activate' THEN user_id END) as activations,
      ROUND(
        COUNT(DISTINCT CASE WHEN event = 'register' THEN user_id END) * 100.0 /
        NULLIF(COUNT(DISTINCT CASE WHEN event = 'impression' THEN user_id END), 0),
        2
      ) as conversion_rate
    FROM experiment_events
    WHERE experiment_id = ?
    GROUP BY variant_id
  `, [experimentId]);

  // 统计显著性检验（使用 Z-test）
  const control = results.find(r => r.variant_id === 'control');
  const variant = results.find(r => r.variant_id === 'variant');

  const zScore = calculateZScore(
    control.conversion_rate / 100, control.impressions,
    variant.conversion_rate / 100, variant.impressions
  );
  const pValue = 1 - normalCDF(Math.abs(zScore));
  const isSignificant = pValue < 0.05;

  return {
    control: { conversionRate: control.conversion_rate + '%' },
    variant: { conversionRate: variant.conversion_rate + '%' },
    zScore: zScore.toFixed(3),
    pValue: pValue.toFixed(4),
    isSignificant,
    recommendation: isSignificant && variant.conversion_rate > control.conversion_rate
      ? '实验组胜出，建议全量上线'
      : '无显著差异，建议继续收集数据或调整方案',
  };
}

// 辅助函数：Z-test 计算
function calculateZScore(p1: number, n1: number, p2: number, n2: number): number {
  const pPool = (p1 * n1 + p2 * n2) / (n1 + n2);
  const se = Math.sqrt(pPool * (1 - pPool) * (1 / n1 + 1 / n2));
  return (p2 - p1) / se;
}

// 辅助函数：正态分布 CDF（近似）
function normalCDF(x: number): number {
  const t = 1 / (1 + 0.2316419 * Math.abs(x));
  const d = 0.3989422804014327 * Math.exp(-x * x / 2);
  const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.781478 + t * (-1.821256 + t * 1.330274))));
  return x > 0 ? 1 - p : p;
}
```

**要点**：
- 分组要基于用户 ID 哈希，不能用随机数（否则同一用户可能被分到不同组）
- 追踪事件要包含实验 ID、分组 ID、用户 ID、事件类型、时间戳
- 分析结果时要做统计显著性检验，不能只看数字大小
