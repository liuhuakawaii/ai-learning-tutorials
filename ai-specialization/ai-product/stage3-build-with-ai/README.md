# 阶段 3：AI 能力集成

> 把 RAG、Agent、MCP、评估等技术正确地放到产品里。不是堆功能，是在用户体验中找到 AI 能力的正确位置。

## 学习目标

- 理解不同 AI 能力（RAG、Agent、MCP、结构化输出）各自适合什么场景
- 掌握"AI 能力选型"的决策框架：什么时候用 RAG，什么时候用 Agent，什么时候用简单 Prompt
- 学会设计 AI 产品的用户体验：信任感、可控性、错误恢复
- 能实现完整的 AI 核心功能，包含 RAG 检索、工具调用、流式响应和评估闭环

## 课时列表

1. AI 能力选型：RAG vs Agent vs 纯 Prompt 的决策树
2. RAG 集成实战：知识库、检索、引用、拒答
3. Agent 集成实战：工具设计、状态管理、人工确认
4. MCP 集成实战：外部工具接入与协议标准化
5. 流式响应与交互设计：让用户感受到"AI 在思考"
6. AI 产品的信任设计：引用、置信度、解释性
7. 错误处理与降级策略：AI 出错时产品怎么兜底
8. 成本控制：Token 统计、缓存、模型降级、预算告警
9. 评估集成：自动化测试、回归检测、质量看板
10. **阶段实战：完成产品 AI 核心功能的完整实现**

## 交付物

- **AI 能力选型文档**：每个功能点用什么技术、为什么、有什么 trade-off
- **核心功能实现**：RAG/Agent/MCP 的完整集成，包含流式响应和错误处理
- **评估报告**：自动化评估结果、关键指标、改进建议
- **成本分析**：单次请求成本、月度预算估算、优化空间
