# 第21课：虚拟主播系统

## 场景引入

2025年双十一期间，某头部美妆品牌的直播间里，一位"主播"连续直播了72小时，面对不同时段的观众切换中英日三语讲解产品，始终保持微笑、语速稳定、互动及时。这位主播并非真人，而是一套虚拟主播系统。

虚拟主播的核心价值：**7×24不间断直播**解决真人主播的时间天花板；**多语言实时切换**覆盖全球市场；**品牌一致性**确保形象、语气、话术完全可控。据艾瑞咨询2025年报告，中国虚拟主播市场规模已突破200亿元，电商直播渗透率超过35%。

但构建生产级虚拟主播系统远非"接个TTS再渲染个3D模型"那么简单。它涉及实时对话生成、语音合成、面部驱动、3D渲染、音视频编码、推流协议等多个技术栈的深度整合。本课将从架构到实战，带你完整搭建一套虚拟主播系统。

## 核心概念

### 一、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                     虚拟主播系统架构                          │
├─────────────────────────────────────────────────────────────┤
│  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐ │
│  │ 输入层   │──▶│ 对话层   │──▶│ 语音层   │──▶│ 驱动层   │ │
│  │ ·弹幕   │   │ ·LLM    │   │ ·TTS    │   │ ·面部   │ │
│  │ ·脚本   │   │ ·Prompt │   │ ·情感   │   │ ·表情   │ │
│  └──────────┘   └──────────┘   └──────────┘   └──────────┘ │
│                                                      │      │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐ │
│  │ 平台层   │◀──│ 推流层   │◀──│ 编码层   │◀──│ 渲染层   │ │
│  │ ·抖音   │   │ ·RTMP   │   │ ·H.264  │   │ ·Unity │ │
│  │ ·淘宝   │   │ ·SRT    │   │ ·H.265  │   │ ·WebGL │ │
│  └──────────┘   └──────────┘   └──────────┘   └──────────┘ │
└─────────────────────────────────────────────────────────────┘
```

端到端延迟预算：弹幕接收(100ms)→LLM生成(800ms)→TTS合成(500ms)→面部驱动(100ms)→渲染(100ms)→编码(50ms)→推流(200ms)→平台转播(500ms)，总计约2.35秒。

### 二、推流协议对比

```
┌────────────┬──────────────┬──────────────┬──────────────┐
│   特性     │    RTMP      │     SRT      │   WebRTC     │
├────────────┼──────────────┼──────────────┼──────────────┤
│ 延迟       │ 1-3秒        │ 0.5-2秒      │ <1秒         │
│ 兼容性     │ 所有平台     │ 需平台支持   │ 浏览器原生   │
│ 抗丢包     │ 弱           │ 强(FEC+ARQ)  │ 中等         │
│ 典型场景   │ 推流到平台   │ 跨境/弱网    │ Web端互动    │
└────────────┴──────────────┴──────────────┴──────────────┘
```

RTMP仍是推流到国内直播平台的首选（抖音、淘宝、快手均原生支持），SRT适合跨境场景，WebRTC适合浏览器端实时互动。

### 三、TTS与面部驱动协同

口型同步的关键在于**音素时间戳**：TTS输出音频的同时返回每个音素的起止时间，驱动层根据当前播放时间切换对应口型。主流TTS引擎（CosyVoice、GPT-SoVITS、Fish Speech）都能输出音素级时间戳。

### 实战一：LLM直播脚本生成系统

```python
"""
virtual_anchor_script.py
虚拟主播直播脚本生成系统
依赖: pip install openai pydantic
"""
import json
from typing import Optional
from pydantic import BaseModel, Field
from openai import OpenAI


class ProductInfo(BaseModel):
    name: str = Field(description="商品名称")
    category: str = Field(description="商品类目")
    price: float = Field(description="售价(元)")
    original_price: float = Field(description="原价(元)")
    key_features: list[str] = Field(description="核心卖点列表")
    target_audience: str = Field(description="目标人群")
    promotion: Optional[str] = Field(default=None, description="促销活动")


class ScriptSegment(BaseModel):
    phase: str = Field(description="阶段: opening/product/features/cta/closing")
    content: str = Field(description="话术内容")
    duration_seconds: int = Field(description="预计时长(秒)")
    emotion: str = Field(description="情感: enthusiastic/warm/professional/excited")
    action_hint: str = Field(description="动作提示")


class LiveScript(BaseModel):
    product: ProductInfo
    segments: list[ScriptSegment]
    total_duration: int
    estimated_word_count: int


class ScriptGenerator:
    def __init__(self, api_key: str, base_url: str = "https://api.openai.com/v1"):
        self.client = OpenAI(api_key=api_key, base_url=base_url)
        self.system_prompt = """你是一位资深电商直播编导，擅长撰写高转化率的直播话术。
要求：
1. 话术口语化，像真人主播一样自然
2. 每句话控制在15-25字，适合主播朗读节奏
3. 产品介绍遵循FABE法则：特征→优势→利益→证据
4. 促单话术有紧迫感，但不能虚假宣传
5. 必须符合《广告法》和《网络直播营销管理办法》
6. 输出JSON格式"""

    def generate_script(self, product: ProductInfo) -> LiveScript:
        discount = round((1 - product.price / product.original_price) * 100, 1)
        features_text = "、".join(product.key_features)

        user_prompt = f"""请为以下商品生成直播脚本：
商品名称：{product.name}
售价：{product.price}元（原价{product.original_price}元，{discount}折）
核心卖点：{features_text}
目标人群：{product.target_audience}
{"促销活动：" + product.promotion if product.promotion else ""}

请生成包含以下阶段的完整脚本：
1. opening - 开场吸引（15-20秒）
2. product - 产品介绍（30-45秒）
3. features - 卖点展开（45-60秒）
4. cta - 促单转化（20-30秒）
5. closing - 结尾引导（10-15秒）

每个片段包含：话术内容、预计时长、情感状态、动作提示。总时长2-3分钟。"""

        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[
                {"role": "system", "content": self.system_prompt},
                {"role": "user", "content": user_prompt}
            ],
            response_format={"type": "json_object"},
            temperature=0.7,
            max_tokens=2000
        )

        result = json.loads(response.choices[0].message.content)
        segments = [ScriptSegment(**seg) for seg in result["segments"]]
        return LiveScript(
            product=product,
            segments=segments,
            total_duration=sum(s.duration_seconds for s in segments),
            estimated_word_count=sum(len(s.content) for s in segments)
        )

    def generate_bullet_reply(
        self, bullet_comment: str, product_context: str, anchor_persona: str
    ) -> str:
        """生成弹幕互动回复"""
        prompt = f"""你是虚拟主播，正在直播带货。
主播人设：{anchor_persona}
当前商品：{product_context}
观众弹幕："{bullet_comment}"
请生成一条简短、自然、亲切的回复（20字以内）。"""

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.8,
            max_tokens=100
        )
        return response.choices[0].message.content.strip()


if __name__ == "__main__":
    generator = ScriptGenerator(api_key="your-api-key")
    product = ProductInfo(
        name="智能降噪耳机 Pro Max",
        category="数码配件",
        price=299.0, original_price=599.0,
        key_features=["-48dB主动降噪", "蓝牙5.3低延迟", "40小时续航", "Hi-Res金标认证"],
        target_audience="通勤上班族、学生党",
        promotion="前100名下单送定制耳机包"
    )
    script = generator.generate_script(product)
    for seg in script.segments:
        print(f"[{seg.phase.upper()}] {seg.emotion} | {seg.duration_seconds}s")
        print(f"  {seg.content}")
        print(f"  动作: {seg.action_hint}\n")

    reply = generator.generate_bullet_reply(
        "这个降噪效果怎么样？地铁上能用吗？",
        "智能降噪耳机 Pro Max，-48dB降噪",
        "亲切专业的数码达人小K，说话干脆利落"
    )
    print(f"弹幕回复: {reply}")
```

### 实战二：TTS + 面部驱动 + RTMP推流Pipeline

```python
"""
virtual_anchor_pipeline.py
虚拟主播推流Pipeline
依赖: pip install numpy opencv-python requests
系统依赖: FFmpeg (需在PATH中)
"""
import asyncio
import subprocess
import time
from dataclasses import dataclass, field
from enum import Enum
from typing import Optional
import numpy as np
import requests


class EmotionType(Enum):
    NEUTRAL = "neutral"
    HAPPY = "happy"
    EXCITED = "excited"
    THINKING = "thinking"


@dataclass
class VisemeFrame:
    timestamp_ms: int
    viseme_id: str
    weight: float
    blendshapes: dict = field(default_factory=dict)


class CosyVoiceTTS:
    def __init__(self, server_url: str = "http://localhost:5000"):
        self.server_url = server_url

    def synthesize(self, text: str, speaker: str, emotion: str) -> tuple[bytes, list[VisemeFrame]]:
        import base64
        response = requests.post(
            f"{self.server_url}/synthesize",
            json={"text": text, "speaker": speaker, "emotion": emotion, "return_visemes": True},
            timeout=10
        )
        response.raise_for_status()
        result = response.json()
        audio = base64.b64decode(result["audio_base64"])
        visemes = [VisemeFrame(**v) for v in result.get("visemes", [])]
        return audio, visemes


class FaceDriver:
    VISeme_MAP = {
        "sil": {"mouthClose": 1.0},
        "PP": {"mouthClose": 0.8, "mouthPucker": 0.5},
        "aa": {"jawOpen": 0.7, "mouthOpen": 0.6},
        "E": {"jawOpen": 0.4, "mouthSmileLeft": 0.5, "mouthSmileRight": 0.5},
        "oh": {"jawOpen": 0.5, "mouthFunnel": 0.5},
        "ou": {"jawOpen": 0.4, "mouthFunnel": 0.7},
    }

    def __init__(self):
        self.current_blendshapes: dict[str, float] = {}
        self.emotion_modifiers: dict[str, float] = {}

    def set_emotion(self, emotion: EmotionType):
        emotion_map = {
            EmotionType.HAPPY: {"mouthSmileLeft": 0.6, "mouthSmileRight": 0.6, "cheekSquintLeft": 0.3},
            EmotionType.EXCITED: {"mouthSmileLeft": 0.8, "eyeWideLeft": 0.3, "browInnerUp": 0.4},
            EmotionType.THINKING: {"browInnerUp": 0.5, "mouthLeft": 0.2},
        }
        self.emotion_modifiers = emotion_map.get(emotion, {})

    def apply_viseme(self, viseme: VisemeFrame, blend_factor: float = 0.8):
        base = self.VISeme_MAP.get(viseme.viseme_id, {})
        self.current_blendshapes = {k: v * viseme.weight * blend_factor for k, v in base.items()}
        for k, v in self.emotion_modifiers.items():
            if k not in self.current_blendshapes:
                self.current_blendshapes[k] = v * 0.5


class RTMPPublisher:
    def __init__(self, rtmp_url: str, width: int = 1920, height: int = 1080, fps: int = 30):
        self.rtmp_url = rtmp_url
        self.width, self.height, self.fps = width, height, fps
        self.process: Optional[subprocess.Popen] = None
        self.is_streaming = False

    def start(self):
        cmd = [
            "ffmpeg", "-y",
            "-f", "rawvideo", "-vcodec", "rawvideo", "-pix_fmt", "bgr24",
            "-s", f"{self.width}x{self.height}", "-r", str(self.fps), "-i", "-",
            "-f", "s16le", "-ar", "24000", "-ac", "1", "-i", "-",
            "-c:v", "libx264", "-preset", "ultrafast", "-tune", "zerolatency",
            "-b:v", "3000k", "-pix_fmt", "yuv420p",
            "-c:a", "aac", "-b:a", "128k",
            "-f", "flv", self.rtmp_url
        ]
        self.process = subprocess.Popen(cmd, stdin=subprocess.PIPE, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        self.is_streaming = True

    def write_video_frame(self, frame_bgr: np.ndarray):
        if self.process and self.process.stdin and self.is_streaming:
            try: self.process.stdin.write(frame_bgr.tobytes())
            except BrokenPipeError: self.is_streaming = False

    def write_audio_chunk(self, pcm_data: bytes):
        if self.process and self.process.stdin and self.is_streaming:
            try: self.process.stdin.write(pcm_data)
            except BrokenPipeError: self.is_streaming = False

    def stop(self):
        self.is_streaming = False
        if self.process:
            self.process.stdin.close()
            self.process.terminate()


class VirtualAnchorPipeline:
    def __init__(self, tts_server: str, rtmp_url: str, speaker: str = "default"):
        self.tts = CosyVoiceTTS(tts_server)
        self.face_driver = FaceDriver()
        self.publisher = RTMPPublisher(rtmp_url)
        self.speaker = speaker
        self.script_queue: asyncio.Queue = asyncio.Queue()
        self.is_running = False

    async def start(self):
        self.publisher.start()
        self.is_running = True
        await asyncio.gather(self._script_consumer(), self._render_loop())

    async def enqueue_text(self, text: str, emotion: EmotionType = EmotionType.NEUTRAL):
        await self.script_queue.put((text, emotion))

    async def _script_consumer(self):
        while self.is_running:
            try:
                text, emotion = await asyncio.wait_for(self.script_queue.get(), timeout=1.0)
            except asyncio.TimeoutError:
                continue
            self.face_driver.set_emotion(emotion)
            audio, visemes = await asyncio.to_thread(self.tts.synthesize, text, self.speaker, emotion.value)
            await self._play_with_visemes(audio, visemes)

    async def _play_with_visemes(self, audio: bytes, visemes: list[VisemeFrame]):
        idx = 0
        start = time.time()
        chunk_size = 4800
        for offset in range(0, len(audio) // 2, chunk_size):
            elapsed_ms = int((time.time() - start) * 1000)
            while idx < len(visemes) - 1 and visemes[idx + 1].timestamp_ms <= elapsed_ms:
                idx += 1
            self.face_driver.apply_viseme(visemes[idx])
            self.publisher.write_audio_chunk(audio[offset*2:(offset+chunk_size)*2])
            await asyncio.sleep(chunk_size / 24000)

    async def _render_loop(self):
        import cv2
        interval = 1.0 / self.publisher.fps
        frame_num = 0
        while self.is_running:
            frame = np.zeros((self.publisher.height, self.publisher.width, 3), dtype=np.uint8)
            bs = self.face_driver.current_blendshapes
            h, w = frame.shape[:2]
            cx, cy = w // 2, h // 2
            cv2.circle(frame, (cx, cy), 200, (200, 200, 200), 2)
            jaw = bs.get("jawOpen", 0.0)
            smile = bs.get("mouthSmileLeft", 0.0)
            mw, mh = int(40 + smile * 30), int(5 + jaw * 25)
            cv2.ellipse(frame, (cx, cy + 60), (mw, mh), 0, 0, 180, (0, 0, 255), -1)
            cv2.putText(frame, f"Frame:{frame_num}", (30, h-50), cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)
            self.publisher.write_video_frame(frame)
            frame_num += 1
            await asyncio.sleep(interval)

    def stop(self):
        self.is_running = False
        self.publisher.stop()


async def main():
    pipeline = VirtualAnchorPipeline("http://localhost:5000", "rtmp://localhost:1935/live/anchor")
    asyncio.create_task(pipeline.start())
    await asyncio.sleep(1)
    await pipeline.enqueue_text("大家好！欢迎来到直播间！", EmotionType.HAPPY)
    await pipeline.enqueue_text("今天给大家带来一款超级好用的产品", EmotionType.EXCITED)
    await asyncio.sleep(30)
    pipeline.stop()

if __name__ == "__main__":
    asyncio.run(main())
```

### 实战三：弹幕互动系统

```python
"""
bullet_interaction.py
弹幕互动系统
依赖: pip install openai websocket-client
"""
import json
import time
import threading
from collections import deque
from dataclasses import dataclass
from typing import Optional
from openai import OpenAI


@dataclass
class BulletComment:
    user_id: str
    username: str
    content: str
    timestamp: float
    user_level: int = 0
    is_gift: bool = False


class BulletInteractionEngine:
    def __init__(self, client: OpenAI, anchor_persona: str):
        self.client = client
        self.anchor_persona = anchor_persona
        self.history: deque = deque(maxlen=100)
        self.keyword_rules = [
            ("多少钱|价格|怎么卖", "这款{product}现在直播间专属价只要{price}哦！"),
            ("质量怎么样|好不好", "质量完全放心！我自己都在用，支持7天无理由退换~"),
            ("发货|快递|几天到", "下单后48小时内发货，一般3天就到啦！"),
            ("新人|第一次来", "欢迎新朋友~ 点点关注不迷路，今天福利超多的！"),
        ]

    def classify(self, comment: BulletComment) -> str:
        import re
        content = comment.content
        for pattern, _ in self.keyword_rules:
            if re.search(pattern, content):
                return "rule"
        if any(kw in content for kw in ["吗", "呢", "？", "?", "怎么", "什么"]):
            return "question"
        if any(kw in content for kw in ["好看", "喜欢", "下单了", "买了"]):
            return "positive"
        return "general"

    def generate_reply(self, comment: BulletComment) -> Optional[str]:
        import re
        if comment.is_gift:
            return f"谢谢{comment.username}的礼物！太感谢了~"

        category = self.classify(comment)
        if category == "rule":
            for pattern, template in self.keyword_rules:
                if re.search(pattern, comment.content):
                    return template.format(product="降噪耳机", price="299元")

        if category == "general" and len(comment.content) < 5:
            return None

        recent = list(self.history)[-5:]
        context = "\n".join(f"[{h['user']}]: {h['content']}" for h in recent)

        try:
            response = self.client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{"role": "user", "content": f"""你是{self.anchor_persona}，正在直播带货。
最近弹幕：{context}
新弹幕来自{comment.username}："{comment.content}"
生成简短回复（20字以内），自然亲切。"""}],
                temperature=0.8, max_tokens=80
            )
            reply = response.choices[0].message.content.strip()
            self.history.append({"user": comment.username, "content": comment.content, "reply": reply})
            return reply
        except Exception as e:
            print(f"生成回复失败: {e}")
            return None

    def should_reply(self, comment: BulletComment) -> bool:
        if comment.is_gift: return True
        if len(comment.content) < 2: return False
        return self.classify(comment) != "general" or comment.user_level >= 3


class InteractiveAnchor:
    def __init__(self, engine: BulletInteractionEngine, tts_callback: callable):
        self.engine = engine
        self.tts = tts_callback
        self.reply_queue: deque = deque(maxlen=20)
        self.is_running = False

    def handle_comment(self, comment: BulletComment):
        if not self.engine.should_reply(comment):
            return
        reply = self.engine.generate_reply(comment)
        if reply:
            self.tts(f"{comment.username}，{reply}", "warm")


if __name__ == "__main__":
    client = OpenAI(api_key="your-api-key")
    engine = BulletInteractionEngine(client, "亲切专业的数码达人小K")

    tests = [
        BulletComment("u001", "小明同学", "这个耳机多少钱啊？", time.time()),
        BulletComment("u002", "数码小白", "降噪效果怎么样？", time.time()),
        BulletComment("u003", "路过的猫", "好看", time.time(), user_level=1),
    ]
    for c in tests:
        if engine.should_reply(c):
            print(f"[{c.username}]: {c.content}")
            print(f"[主播]: {engine.generate_reply(c)}\n")
```

## 常见误区

### 误区一：过度追求画质而忽视延迟

直播互动的核心是**实时性**。观众发弹幕5秒后才得到回复，体验比低画质更糟糕。正确做法是先保证延迟在3秒以内，再逐步提升画质。

### 误区二：LLM回复不做安全过滤

虚拟主播面向公众直播，LLM回复如果出现不当内容后果严重。**所有LLM输出必须经过安全过滤层**，包括关键词过滤、语义审核、合规检查。

### 误区三：忽略弹幕去重和频率限制

不做去重会导致相同问题被重复回答。应设置**用户级冷却时间**（同一用户30秒内不重复回复）和**全局回复频率上限**（每分钟最多15条）。

### 误区四：TTS和面部驱动不同步

用独立的TTS和面部驱动服务，在高负载下口型会偏移。正确做法是TTS返回**音素级时间戳**，驱动层严格按时间戳渲染。

### 误区五：不做降级和容错

生产环境中TTS可能宕机、LLM可能超时。系统必须有降级策略：TTS故障切换预录音频，LLM超时使用模板回复，推流中断自动重连。

### 练习一

**思路**：使用策略模式，定义统一接口，RTMP和SRT作为实现类。

```python
from abc import ABC, abstractmethod
import subprocess

class BasePublisher(ABC):
    def __init__(self, width=1920, height=1080, fps=30):
        self.width, self.height, self.fps = width, height, fps
        self.process = None
        self.is_streaming = False

    @abstractmethod
    def _build_command(self) -> list[str]: pass

    def start(self):
        self.process = subprocess.Popen(self._build_command(), stdin=subprocess.PIPE)
        self.is_streaming = True

    def write_video_frame(self, data: bytes):
        if self.process and self.process.stdin and self.is_streaming:
            self.process.stdin.write(data)

    def stop(self):
        self.is_streaming = False
        if self.process:
            self.process.stdin.close()
            self.process.terminate()

class SRTPublisher(BasePublisher):
    def __init__(self, srt_url: str, latency_ms=200, **kwargs):
        super().__init__(**kwargs)
        self.srt_url = srt_url
        self.latency_ms = latency_ms

    def _build_command(self) -> list[str]:
        return [
            "ffmpeg", "-y", "-f", "rawvideo", "-vcodec", "rawvideo",
            "-pix_fmt", "bgr24", "-s", f"{self.width}x{self.height}",
            "-r", str(self.fps), "-i", "-",
            "-f", "s16le", "-ar", "24000", "-ac", "1", "-i", "-",
            "-c:v", "libx264", "-preset", "ultrafast", "-tune", "zerolatency",
            "-b:v", "3000k", "-pix_fmt", "yuv420p",
            "-c:a", "aac", "-b:a", "128k", "-f", "mpegts",
            f"{self.srt_url}?mode=caller&latency={self.latency_ms * 1000}"
        ]
```

**要点**：工厂函数 `create_publisher(protocol, url)` 封装创建逻辑；SRT通过URL参数控制延迟。

### 练习二

**思路**：滑动窗口统计弹幕情感，负面比例超阈值时自动切换主播情感。

```python
from collections import deque

class SentimentTracker:
    POSITIVE = {"好看", "喜欢", "下单", "买了", "支持", "棒", "赞"}
    NEGATIVE = {"贵", "差", "假", "骗", "退货", "垃圾", "坑"}

    def __init__(self, window_size=50, threshold=0.3):
        self.window: deque[str] = deque(maxlen=window_size)
        self.threshold = threshold

    def add(self, text: str) -> str:
        pos = sum(1 for w in self.POSITIVE if w in text)
        neg = sum(1 for w in self.NEGATIVE if w in text)
        label = "positive" if pos > neg else "negative" if neg > pos else "neutral"
        self.window.append(label)
        return label

    def get_recommendation(self) -> str:
        if not self.window: return "neutral"
        neg_ratio = sum(1 for l in self.window if l == "negative") / len(self.window)
        pos_ratio = sum(1 for l in self.window if l == "positive") / len(self.window)
        if neg_ratio > self.threshold: return "comfort"
        if pos_ratio > 0.5: return "excited"
        return "neutral"
```

**要点**：滑动窗口避免单条极端弹幕影响；`recommendation` 直接映射到主播情感状态。

### 练习三

**思路**：优先级队列管理多商品脚本，紧急商品插队到队列头部。

```python
import heapq
from dataclasses import dataclass, field

@dataclass
class QueuedProduct:
    priority: int
    product_info: ProductInfo
    is_urgent: bool = False
    def __lt__(self, other):
        if self.is_urgent != other.is_urgent: return self.is_urgent
        return self.priority > other.priority

class ScriptQueueManager:
    def __init__(self, generator: ScriptGenerator):
        self.generator = generator
        self.queue: list[QueuedProduct] = []

    def add_product(self, product: ProductInfo, priority=1, is_urgent=False):
        heapq.heappush(self.queue, QueuedProduct(priority, product, is_urgent))

    def get_next_script(self) -> Optional[LiveScript]:
        if not self.queue: return None
        item = heapq.heappop(self.queue)
        return self.generator.generate_script(item.product_info)
```

**要点**：`__lt__` 确保紧急商品始终排在队列头部；`heapq` 实现O(log n)的插入和弹出。
