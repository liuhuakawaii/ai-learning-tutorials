# 第22课：数字员工

## 场景引入

2025年，某大型国有银行在全国部署了超过3000台数字员工终端。客户走进网点，面对的不再是排队等候和冰冷的取号机，而是一位形象亲切、能说方言、精通全部业务流程的"数字柜员"。它能理解"我想把工资卡里的钱转到老婆的卡上，顺便看看这个月房贷还了多少"这样的复合需求，在一次对话中完成多个业务操作。

数字员工与传统IVR和普通Chatbot的本质区别在于三点：**有面孔**——3D数字人形象让交互不再是冷冰冰的文字；**有记忆**——基于RAG的知识库让它真正理解业务；**有权限**——通过Function Calling对接实际业务系统，能真正"办事"。

本课将从银行客服场景出发，完整构建一套数字员工系统，涵盖RAG知识库搭建、多轮对话管理、Function Calling业务对接。

## 学习目标

1. 理解数字员工与传统IVR/Chatbot的本质差异
2. 设计数字员工的四层架构（终端+AI+业务+数据）
3. 使用RAG + LangChain + ChromaDB构建业务知识库
4. 实现多轮对话状态管理
5. 通过Function Calling对接真实业务API

## 核心概念

### 一、数字员工 vs 传统方案

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│   维度       │    IVR       │   Chatbot    │  数字员工    │
├──────────────┼──────────────┼──────────────┼──────────────┤
│ 交互方式     │ 按键选择     │ 文字对话     │ 多模态对话   │
│ 形象感知     │ 无           │ 头像         │ 3D数字人     │
│ 理解能力     │ 关键词匹配   │ 意图识别     │ LLM语义理解  │
│ 知识来源     │ 预设菜单     │ FAQ库        │ RAG知识库    │
│ 业务能力     │ 跳转人工     │ 引导填写     │ 直接办理     │
│ 上下文记忆   │ 无           │ 短期         │ 长期+RAG     │
└──────────────┴──────────────┴──────────────┴──────────────┘
```

### 二、四层架构

```
┌─────────────────────────────────────────────────────────────┐
│  终端层     │  Kiosk触摸屏 / App / 小程序 / Web            │
│             │  3D数字人渲染 / 摄像头 / 麦克风               │
├─────────────┼───────────────────────────────────────────────┤
│  AI层       │  LLM对话引擎 / RAG知识检索                    │
│             │  ASR语音识别 / TTS语音合成 / 意图识别          │
├─────────────┼───────────────────────────────────────────────┤
│  业务层     │  账户系统 / 转账系统 / 贷款系统 / CRM         │
│             │  身份验证 / 电子签名 / 风控引擎               │
├─────────────┼───────────────────────────────────────────────┤
│  数据层     │  向量数据库(ChromaDB) / 知识图谱              │
│             │  对话日志 / 审计日志 / 合规报告               │
└─────────────┴───────────────────────────────────────────────┘
```

### 三、RAG知识库工作流

```
用户问题 → 文本向量化(Embedding) → 向量检索(ChromaDB Top-K)
→ 知识片段 + 用户问题 → LLM生成回答(带引用来源)
```

RAG不是靠LLM参数记忆回答，而是实时检索企业知识库，确保回答准确且可追溯。

### 四、安全合规要点

1. **数据不出域**：LLM推理必须在私有云内完成
2. **操作可审计**：每条回答记录来源文档和LLM输入输出
3. **权限最小化**：Function Calling只能调用授权API
4. **敏感信息脱敏**：身份证号、银行卡号自动脱敏
5. **人工兜底**：高风险操作必须转人工确认

### 五、多轮对话状态机

```
[空闲] → 意图识别 → [查询余额] / [转账] / [咨询贷款]
                      ↓              ↓            ↓
                 [身份验证]    [身份验证]    [知识检索]
                      ↓              ↓            ↓
                 [返回结果]    [确认金额]    [生成回答]
                                  ↓
                              [二次确认]
                                  ↓
                              [执行转账] → [完成] → [空闲]
```

### 实战一：银行客服RAG知识库

```python
"""
bank_rag_knowledge.py
银行数字员工RAG知识库
依赖: pip install langchain langchain-openai chromadb tiktoken
"""
import os
from typing import Optional
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import Chroma
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_core.documents import Document


class BankKnowledgeBase:
    def __init__(self, persist_directory: str = "./chroma_bank_kb"):
        self.embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
        self.persist_directory = persist_directory
        self.text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=500, chunk_overlap=50,
            separators=["\n\n", "\n", "。", "；", " "]
        )
        self.vectorstore = Chroma(
            persist_directory=persist_directory,
            embedding_function=self.embeddings
        )

    def ingest_documents(self, documents: list[dict]) -> int:
        docs = []
        for doc in documents:
            chunks = self.text_splitter.split_text(doc["content"])
            for i, chunk in enumerate(chunks):
                docs.append(Document(
                    page_content=chunk,
                    metadata={
                        "title": doc["title"],
                        "category": doc["category"],
                        "chunk_index": i,
                        "total_chunks": len(chunks)
                    }
                ))
        self.vectorstore.add_documents(docs)
        return len(docs)

    def search(self, query: str, top_k: int = 5, category: Optional[str] = None):
        kwargs = {"k": top_k}
        if category:
            kwargs["filter"] = {"category": category}
        return self.vectorstore.similarity_search_with_relevance_scores(query, **kwargs)


class BankDigitalEmployee:
    SYSTEM_PROMPT = """你是银行智能客服"小信"。
规则：
1. 只基于提供的知识内容回答，不要编造信息
2. 没有相关内容时建议转人工
3. 涉及利率必须引用来源
4. 个人信息操作必须先身份验证
5. 大额转账（超过5万元）必须二次确认
6. 回答简洁，避免专业术语"""

    def __init__(self, kb: BankKnowledgeBase, model: str = "gpt-4o"):
        self.kb = kb
        self.llm = ChatOpenAI(model=model, temperature=0.1)

    def chat(self, question: str) -> dict:
        results = self.kb.search(question, top_k=5)
        context_parts = []
        sources = []
        for doc, score in results:
            context_parts.append(f"[来源: {doc.metadata['title']}]\n{doc.page_content}")
            sources.append({"title": doc.metadata["title"], "score": round(score, 3)})

        context = "\n\n---\n\n".join(context_parts)
        prompt = f"{self.SYSTEM_PROMPT}\n\n知识内容：\n{context}\n\n客户问题: {question}"

        response = self.llm.invoke(prompt)
        answer = response.content
        avg_conf = sum(s["score"] for s in sources) / len(sources) if sources else 0

        needs_human = avg_conf < 0.4 or any(
            kw in question for kw in ["转人工", "投诉"]
        ) or any(kw in answer for kw in ["不太确定", "建议咨询", "请联系"])

        return {
            "answer": answer,
            "sources": sources[:3],
            "confidence": round(avg_conf, 3),
            "needs_human": needs_human
        }
```

### 实战二：多轮对话状态管理

```python
"""
conversation_state_machine.py
多轮对话状态管理
依赖: pip install pydantic openai
"""
import json
import time
from enum import Enum
from typing import Optional, Any
from dataclasses import dataclass, field
from openai import OpenAI


class ConversationState(Enum):
    IDLE = "idle"
    COLLECTING = "collecting"
    CONFIRMING = "confirming"
    EXECUTING = "executing"
    COMPLETED = "completed"


class BusinessIntent(Enum):
    QUERY_BALANCE = "query_balance"
    TRANSFER = "transfer"
    LOAN_INQUIRY = "loan_inquiry"
    GENERAL = "general"


@dataclass
class SlotField:
    name: str
    description: str
    required: bool = True
    value: Any = None
    prompt: str = ""


@dataclass
class ConversationContext:
    session_id: str
    state: ConversationState = ConversationState.IDLE
    intent: Optional[BusinessIntent] = None
    slots: dict[str, SlotField] = field(default_factory=dict)
    history: list[dict] = field(default_factory=list)
    turn_count: int = 0


class ConversationManager:
    def __init__(self, client: OpenAI):
        self.client = client
        self.sessions: dict[str, ConversationContext] = {}

    def create_session(self, session_id: str) -> ConversationContext:
        ctx = ConversationContext(session_id=session_id)
        self.sessions[session_id] = ctx
        return ctx

    def classify_intent(self, message: str) -> BusinessIntent:
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": f"""判断意图类别：
- query_balance: 查询余额
- transfer: 转账汇款
- loan_inquiry: 贷款咨询
- general: 其他
用户消息: "{message}"
只返回类别名称。"""}],
            temperature=0, max_tokens=20
        )
        try:
            return BusinessIntent(response.choices[0].message.content.strip())
        except ValueError:
            return BusinessIntent.GENERAL

    def extract_slots(self, message: str, slots: dict[str, SlotField]) -> dict:
        empty = {s.name: s.description for s in slots.values() if s.value is None and s.required}
        if not empty: return {}

        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": f"""从消息中抽取信息，返回JSON。
待抽取字段：{json.dumps(empty, ensure_ascii=False)}
用户消息："{message}"
示例：{{"amount": 5000}}"""}],
            response_format={"type": "json_object"},
            temperature=0
        )
        try:
            return json.loads(response.choices[0].message.content)
        except json.JSONDecodeError:
            return {}

    def process_message(self, session_id: str, message: str) -> str:
        ctx = self.sessions.get(session_id)
        if not ctx:
            ctx = self.create_session(session_id)

        ctx.history.append({"role": "user", "content": message})
        ctx.turn_count += 1

        if ctx.state == ConversationState.IDLE:
            return self._handle_idle(ctx, message)
        elif ctx.state == ConversationState.COLLECTING:
            return self._handle_collecting(ctx, message)
        elif ctx.state == ConversationState.CONFIRMING:
            return self._handle_confirming(ctx, message)
        elif ctx.state == ConversationState.COMPLETED:
            ctx.state = ConversationState.IDLE
            return self._handle_idle(ctx, message)
        return "系统繁忙，请稍后再试。"

    def _init_transfer_slots(self) -> dict[str, SlotField]:
        return {
            "from_account": SlotField("from_account", "付款账号尾号", prompt="请提供付款账号尾号"),
            "to_account": SlotField("to_account", "收款账号尾号", prompt="请提供收款账号尾号"),
            "recipient_name": SlotField("recipient_name", "收款人姓名", prompt="请提供收款人姓名"),
            "amount": SlotField("amount", "转账金额", prompt="请问转账多少元？"),
        }

    def _handle_idle(self, ctx: ConversationContext, message: str) -> str:
        intent = self.classify_intent(message)
        ctx.intent = intent

        if intent == BusinessIntent.TRANSFER:
            ctx.state = ConversationState.COLLECTING
            ctx.slots = self._init_transfer_slots()
            first = next(s for s in ctx.slots.values() if s.required)
            return f"好的，帮您办理转账。{first.prompt}"
        if intent == BusinessIntent.QUERY_BALANCE:
            return "请提供账号尾号，我来帮您查询余额。"
        if intent == BusinessIntent.LOAN_INQUIRY:
            return "我可以帮您查询贷款利率、额度等信息，请问您想了解哪方面？"
        return "我可以帮您办理转账、查询余额、贷款咨询等业务。请问需要什么帮助？"

    def _handle_collecting(self, ctx: ConversationContext, message: str) -> str:
        extracted = self.extract_slots(message, ctx.slots)
        for name, value in extracted.items():
            if name in ctx.slots and ctx.slots[name].value is None:
                ctx.slots[name].value = value

        empty = [s for s in ctx.slots.values() if s.required and s.value is None]
        if empty:
            return empty[0].prompt

        ctx.state = ConversationState.CONFIRMING
        info = "\n".join(f"  {s.description}: {s.value}" for s in ctx.slots.values())
        return f"请确认转账信息：\n{info}\n\n回复"确认"执行，或"取消"放弃。"

    def _handle_confirming(self, ctx: ConversationContext, message: str) -> str:
        if any(kw in message for kw in ["确认", "确定", "是"]):
            ctx.state = ConversationState.COMPLETED
            amount = ctx.slots["amount"].value
            name = ctx.slots["recipient_name"].value
            return f"转账成功！{amount}元已转至{name}，交易编号TXN{int(time.time()*1000)}"
        if any(kw in message for kw in ["取消", "不要"]):
            ctx.state = ConversationState.IDLE
            ctx.slots = {}
            return "好的，已取消操作。请问还有什么可以帮您的？"
        return '回复"确认"执行，或"取消"放弃。'


if __name__ == "__main__":
    client = OpenAI(api_key="your-api-key")
    mgr = ConversationManager(client)
    sid = "test_001"

    for msg in ["我想转一笔钱", "从8888转到6666", "收款人张三", "转5000块", "确认"]:
        print(f"\n客户: {msg}")
        print(f"小信: {mgr.process_message(sid, msg)}")
```

### 实战三：Function Calling业务对接

```python
"""
function_calling_bank.py
Function Calling银行业务对接
依赖: pip install openai
"""
import json
from datetime import datetime
from openai import OpenAI


class BankAPIService:
    ACCOUNTS = {
        "8888": {"name": "张三", "balance": 125680.50},
        "6666": {"name": "李四", "balance": 45230.00},
    }

    def query_balance(self, account_tail: str) -> dict:
        acc = self.ACCOUNTS.get(account_tail)
        if not acc: return {"success": False, "message": f"未找到账户{account_tail}"}
        return {"success": True, "balance": acc["balance"], "name": acc["name"]}

    def transfer(self, from_account: str, to_account: str, amount: float, recipient_name: str) -> dict:
        src = self.ACCOUNTS.get(from_account)
        dst = self.ACCOUNTS.get(to_account)
        if not src: return {"success": False, "message": "付款账户不存在"}
        if not dst: return {"success": False, "message": "收款账户不存在"}
        if src["balance"] < amount: return {"success": False, "message": f"余额不足({src['balance']:.2f}元)"}
        if dst["name"] != recipient_name: return {"success": False, "message": f"收款人不匹配，户主为{dst['name']}"}

        self.ACCOUNTS[from_account]["balance"] -= amount
        self.ACCOUNTS[to_account]["balance"] += amount
        txn_id = f"TXN{datetime.now().strftime('%Y%m%d%H%M%S')}"
        return {"success": True, "transaction_id": txn_id, "message": f"转账成功，余额{self.ACCOUNTS[from_account]['balance']:.2f}元"}


TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "query_balance",
            "description": "查询银行账户余额",
            "parameters": {
                "type": "object",
                "properties": {"account_tail": {"type": "string", "description": "账户尾号4位"}},
                "required": ["account_tail"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "transfer_money",
            "description": "执行银行转账，超5万需二次确认",
            "parameters": {
                "type": "object",
                "properties": {
                    "from_account": {"type": "string", "description": "付款账户尾号"},
                    "to_account": {"type": "string", "description": "收款账户尾号"},
                    "amount": {"type": "number", "description": "金额(元)"},
                    "recipient_name": {"type": "string", "description": "收款人姓名"}
                },
                "required": ["from_account", "to_account", "amount", "recipient_name"]
            }
        }
    }
]


class BankFunctionCallingAgent:
    SYSTEM = """你是银行智能客服"小信"。可调用接口：query_balance(查余额)、transfer_money(转账)。
规则：办理业务前确认身份；转账超5万提醒二次确认；确保信息完整再调用接口。"""

    def __init__(self, api_key: str, base_url: str = "https://api.openai.com/v1"):
        self.client = OpenAI(api_key=api_key, base_url=base_url)
        self.bank_api = BankAPIService()
        self.messages = [{"role": "system", "content": self.SYSTEM}]

    def _execute(self, name: str, args: dict) -> str:
        func_map = {
            "query_balance": lambda: self.bank_api.query_balance(**args),
            "transfer_money": lambda: self.bank_api.transfer(**args),
        }
        result = func_map.get(name, lambda: {"success": False, "message": "未知函数"})()
        return json.dumps(result, ensure_ascii=False)

    def chat(self, message: str) -> str:
        self.messages.append({"role": "user", "content": message})
        response = self.client.chat.completions.create(
            model="gpt-4o", messages=self.messages, tools=TOOLS, tool_choice="auto", temperature=0.1
        )
        msg = response.choices[0].message
        self.messages.append(msg)

        if msg.tool_calls:
            for tc in msg.tool_calls:
                result = self._execute(tc.function.name, json.loads(tc.function.arguments))
                self.messages.append({"role": "tool", "tool_call_id": tc.id, "content": result})

            final = self.client.chat.completions.create(model="gpt-4o", messages=self.messages, temperature=0.1)
            content = final.choices[0].message.content
            self.messages.append({"role": "assistant", "content": content})
            return content
        return msg.content


if __name__ == "__main__":
    agent = BankFunctionCallingAgent(api_key="your-api-key")
    for msg in ["帮我查一下尾号8888的余额", "从8888转5000给6666的张三"]:
        print(f"\n客户: {msg}")
        print(f"小信: {agent.chat(msg)}")
```

## 常见误区

### 误区一：把数字员工当成"会动的FAQ"

数字员工的核心价值在于**能办事**——通过Function Calling对接业务系统，真正完成查询、办理、预约等操作，而不只是"回答问题"。

### 误区二：RAG不做知识更新

银行产品利率、业务规则经常变化。必须建立**知识更新机制**：产品部门维护文档，定期同步到向量数据库，每次更新有版本记录和审核流程。

### 误区三：Function Calling不做权限控制

直接把所有业务API暴露给LLM非常危险。必须在Function Calling层加**权限校验**：验证调用来源、检查操作权限、记录审计日志、敏感操作二次确认。

### 误区四：忽略对话边界场景

```python
import hashlib, json, os, time
```

### 练习二

**思路**：维护最后活跃时间，后台定时检查超时会话。

```python
import asyncio, time

class SessionTimeoutManager:
    def __init__(self, mgr: ConversationManager, warning=60, timeout=180):
        self.mgr = mgr
        self.warning, self.timeout = warning, timeout
        self.last_activity: dict[str, float] = {}
        self.warning_sent: dict[str, bool] = {}

    def touch(self, session_id: str):
        self.last_activity[session_id] = time.time()
        self.warning_sent[session_id] = False

    async def monitor(self, callback: callable):
        while True:
            now = time.time()
            for sid, last in list(self.last_activity.items()):
                elapsed = now - last
                if elapsed > self.timeout:
                    ctx = self.mgr.sessions.get(sid)
                    if ctx: ctx.state = ConversationState.IDLE
                    callback(sid, "timeout")
                    del self.last_activity[sid]
                elif elapsed > self.warning and not self.warning_sent.get(sid):
                    self.warning_sent[sid] = True
                    callback(sid, "warning")
            await asyncio.sleep(5)
```

**要点**：`touch()` 在每次用户消息时重置计时器；两级超时策略（提醒+关闭）。

### 练习三

**思路**：正则匹配敏感信息，保留前后缀确保可识别类型。

```python
import re

class SensitiveDataFilter:
    PATTERNS = [
        ("id_card", r"\b(\d{6})\d{8}(\d{3}[\dXx])\b", r"\1****\2"),
        ("phone", r"\b(1[3-9]\d)\d{4}(\d{4})\b", r"\1****\2"),
        ("bank_card", r"\b(\d{4})\d+(\d{4})\b", r"\1****\2"),
    ]

    def __init__(self):
        self.compiled = [(n, re.compile(p), r) for n, p, r in self.PATTERNS]

    def filter_text(self, text: str) -> str:
        result = text
        for _, pattern, replacement in self.compiled:
            result = pattern.sub(replacement, result)
        return result

    def extract_types(self, text: str) -> dict[str, list[str]]:
        found = {}
        for name, pattern, _ in self.compiled:
            matches = pattern.findall(text)
            if matches: found[name] = [m if isinstance(m, str) else "".join(m) for m in matches]
        return found
```

**要点**：双向脱敏（输入+输出）；`extract_types` 用于审计日志记录敏感信息类型。
