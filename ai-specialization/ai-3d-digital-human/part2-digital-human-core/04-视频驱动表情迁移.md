# 第10课：视频驱动表情迁移

## 场景引入

2024年，一位B站UP主发布了一段视频：他用自己的摄像头实时驱动一个二次元虚拟角色，角色的每一个微笑、皱眉、眨眼都精确复刻了他的表情，延迟不到100毫秒。弹幕里满屏"魔法"。

这个"魔法"的核心技术就是**视频驱动表情迁移**（Video-Driven Expression Transfer）。与上一课音频驱动不同，视频驱动使用摄像头捕捉真人的面部表情，然后将这些表情"迁移"到目标数字人身上。这种方式的优势是实时性更强、表情更丰富——因为真人的一颦一笑都被精确捕捉了。

表情迁移技术的应用场景远比你想象的广泛：VTuber直播用它驱动虚拟形象，游戏用它实现面部捕捉动画，影视用它做数字替身，元宇宙用它驱动用户的虚拟化身。本课将从表情迁移的基本原理讲起，带你掌握从关键点检测到3DMM参数迁移、从GAN合成到NeRF/3DGS迁移的完整技术链路。

## 学习目标

完成本课学习后，你将能够：

1. 理解表情迁移的定义、分类和核心挑战
2. 掌握面部关键点检测和3DMM参数提取的方法
3. 理解三种主流迁移方法（3DMM参数迁移、GAN合成、NeRF/3DGS迁移）的原理和权衡
4. 使用LivePortrait实现高质量的实时表情迁移
5. 使用OpenCV+dlib构建一个基础的实时表情迁移系统

## 核心概念

### 一、表情迁移的定义与分类

**表情迁移（Expression Transfer / Expression Retargeting）** 是指将源人脸（驱动者）的表情动作，转移到目标人脸（被驱动者）上，使目标人脸呈现出与源人脸相同或相似的表情。

```
 表情迁移的基本流程

 源人脸（驱动者）              目标人脸（被驱动者）
 ┌─────────────┐              ┌─────────────┐
 │   ┌───┐     │              │   ┌───┐     │
 │   │:) │     │   迁移       │   │:) │     │
 │   └───┘     │  ───────→    │   └───┘     │
 │  摄像头输入  │              │  数字人输出  │
 └─────────────┘              └─────────────┘
       │                            ▲
       │    ┌──────────────────┐    │
       └──→ │  表情参数提取     │──→ 表情应用
            │  (关键点/3DMM/   │
            │   Blendshape)    │
            └──────────────────┘
```

按驱动信号的来源，表情迁移可以分为：

| 驱动方式 | 输入信号 | 典型延迟 | 适用场景 |
|----------|----------|----------|----------|
| 视频驱动 | 摄像头实时画面 | 30-100ms | 直播、实时交互 |
| 音频驱动 | 语音信号 | 100-500ms | 预录制、对话系统 |
| 文本驱动 | 文本指令 | 500ms+ | 批量内容生成 |
| 动作捕捉 | 专业设备数据 | 10-30ms | 影视制作、游戏开发 |

### 二、关键点检测与参数提取

表情迁移的第一步是从源人脸中提取可迁移的表情参数。

#### 2.1 面部关键点检测

面部关键点检测的目标是在人脸图像上定位一组语义明确的点。主流方案包括：

**68点模型（dlib）**：覆盖眉毛、眼睛、鼻子、嘴巴和下巴轮廓。精度适中，速度快，适合实时应用。

```
 dlib 68点面部关键点分布

          18  20  22          23  25  27
       17   19  21  22    22  24  26   28
                                眉毛区域
    ───────────────────────────────────────
    │     ●●●●●●●●●●●●●●●●●●●●●●●●       │
    │    (17-21)          (22-26)          │
    │                                     │
    │  37  38              43  44          │
    │ ● ● ● ●            ● ● ● ●         │
    │  36    39          42    45          │  眼睛区域
    │                                     │  (36-47)
    │        27  28  29  30               │
    │        ●   ●   ●   ●   31          │  鼻子区域
    │                32     ●             │  (27-35)
    │                   33  34  35        │
    │                                     │
    │    48  49  50  51  52  53  54       │
    │  47 ● ● ● ● ● ● ● ● ● 55         │  嘴巴区域
    │    58  59  60  61  62  63           │  (48-67)
    │  46 ● ● ● ● ● ● ● ● ● 56         │
    │           64  65  66                │
    │                                     │

    │ ● ● ● ● ● ● ● ● ● ● ● ● ● ● ●●  │  (0-16)
    └─────────────────────────────────────┘
```

**478点模型（MediaPipe）**：提供468个面部关键点+10个虹膜关键点，覆盖面更广，精度更高。

#### 2.2 3DMM参数提取

关键点检测提供了2D或3D的点坐标，但表情迁移需要的是更抽象的参数表示。3DMM参数提取将人脸分解为身份（shape）、表情（expression）和姿态（pose）三个独立分量：

```
 3DMM参数提取流程

 输入图像
     │
     ▼
┌──────────────┐
│ 面部检测+关键点│
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 3DMM拟合      │  min ||p_2d - π(R·S + t)||²
│              │  S = S̄ + A_id·α_id + A_exp·α_exp
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 参数输出      │  α_id: 身份 (199/300维)
│              │  α_exp: 表情 (52/100维)
│              │  R: 旋转  t: 平移
└──────────────┘
```

提取出的3DMM参数是表情迁移的核心数据。身份参数α_id描述了"这个人长什么样"，表情参数α_exp描述了"这个人做什么表情"。表情迁移的本质就是：保留目标人脸的身份参数不变，将源人脸的表情参数应用到目标人脸上。

### 三、表情迁移方法

#### 3.1 3DMM参数迁移（基于模型的方法）

最直接的表情迁移方法：分别提取源和目标的3DMM参数，然后将源的表情参数替换目标的表情参数。

```
 3DMM参数迁移原理

 源人脸 → 参数提取 → α_exp_src (源的表情)
 目标人脸 → 参数提取 → α_id_tgt (目标的身份)
          ┌───────────────────┐
          │ 参数组合           │
          │ α_id = α_id_tgt   │  (保留目标身份)
          │ α_exp = α_exp_src │  (使用源表情)
          └────────┬──────────┘
                   ▼
          S = S̄ + A_id·α_id_tgt + A_exp·α_exp_src
                   ▼
           3D网格渲染 → 迁移结果
```

优点是简单高效、身份保持性好。缺点是3DMM的表达能力有限——它只能表达线性可分的表情变化，对于舌头、牙齿、皱纹等细节无法精确建模。

#### 3.2 GAN合成方法

生成对抗网络（GAN）提供了更强的图像生成能力。代表性工作包括FOMM（First Order Motion Model），它将人脸运动分解为关键点的局部运动和背景的全局运动。

```
 FOMM 运动分解

 驱动帧                           源图像
     │                              │
     ▼                              ▼
 关键点检测                     关键点检测
     │                              │
     ▼                              ▼
 驱动关键点                     源关键点
 (x_d, y_d)                    (x_s, y_s)
     │    ┌───────────────────┐     │
     └──→ │ 运动估计          │ ←───┘
          │ Δx = x_d - x_s   │
          │ T = 仿射矩阵      │
          └────────┬──────────┘
                   ▼
          薄板样条变换 (TPS) + 生成器
                   ▼
           迁移结果图像
```

#### 3.3 NeRF + 3DGS迁移（隐式表示方法）

2024-2025年，基于3D Gaussian Splatting（3DGS）的表情迁移方法开始兴起。3DGS将人脸表示为一组3D高斯椭球体，通过改变椭球体的参数来实现表情变化。

```
 3DGS表情迁移示意

 静态人脸的3D高斯分布        表情驱动后的高斯分布

     ●●●●                       ●●●●
    ●●●●●●                    ●●    ●●
   ●● ●● ●●                  ●● ●● ●●
   ●●    ●●                  ●●      ●●
    ●●●●●●                   ●●●●  ●●●●
     ●●●●                     ●●●●●●
   (自然表情)                  (微笑)

 每个●是一个3D高斯椭球体
 表情变化 = 椭球体位置/形状/颜色的改变
```

3DGS方法的优势是渲染速度极快（实时渲染高分辨率图像）、质量高（支持照片级渲染）、且天然支持视角变化。

### 四、代表性开源方案

**LivePortrait（2024）** 是快手科技开源的肖像动画框架，支持实时表情迁移和说话人生成。核心创新是混合框架结合了3DMM参数提取和隐式关键点的运动建模，在RTX 3090上达到80fps。

**MimicMotion（2024）** 是腾讯提出的人体动作迁移方案，支持全身动作迁移——从手指的精细动作到身体的大范围运动。

### 实时表情迁移引擎

```python
import torch
import cv2
import numpy as np
from src.config.argument_config import ArgumentConfig
from src.live_portrait_pipeline import LivePortraitPipeline

class ExpressionTransferEngine:
    """
    基于LivePortrait的表情迁移引擎
    支持从视频/摄像头驱动目标肖像
    """

    def __init__(self, model_path="pretrained_weights"):
        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        args = ArgumentConfig(source_image="", driving_info="")
        self.pipeline = LivePortraitPipeline(args)
        print(f"LivePortrait引擎初始化完成，设备: {self.device}")

    def transfer_expression(self, source_image_path, driving_video_path, output_path="output.mp4"):
        """
        从驱动视频迁移表情到源肖像

        参数:
            source_image_path: 目标肖像图片路径（被驱动的人脸）
            driving_video_path: 驱动视频路径（提供表情的源人脸）
            output_path: 输出视频路径
        """
        result = self.pipeline.execute(
            source_image=source_image_path,
            driving_info=driving_video_path
        )
        if result is not None:
            self._save_video(result, output_path)
            print(f"表情迁移完成！输出: {output_path}")
        return result

    def transfer_from_camera(self, source_image_path, output_path="live_output.mp4"):
        """从摄像头实时驱动目标肖像"""
        cap = cv2.VideoCapture(0)
        if not cap.isOpened():
            raise RuntimeError("无法打开摄像头")

        fps = 30
        w = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
        h = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
        writer = cv2.VideoWriter(output_path, cv2.VideoWriter_fourcc(*"mp4v"), fps, (w * 2, h))

        print("实时表情迁移已启动（按 'q' 退出）")
        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break

            cv2.imwrite("_temp_frame.jpg", frame)
            result_frame = self.pipeline.execute(
                source_image=source_image_path,
                driving_info="_temp_frame.jpg"
            )

            if result_frame is not None:
                display = np.hstack([frame, result_frame])
                writer.write(display)
                cv2.imshow("Expression Transfer", display)

            if cv2.waitKey(1) & 0xFF == ord("q"):
                break

        cap.release()
        writer.release()
        cv2.destroyAllWindows()

    def _save_video(self, frames, output_path, fps=30):
        if isinstance(frames, list) and len(frames) > 0:
            h, w = frames[0].shape[:2]
            writer = cv2.VideoWriter(output_path, cv2.VideoWriter_fourcc(*"mp4v"), fps, (w, h))
            for frame in frames:
                if frame.dtype != np.uint8:
                    frame = (frame * 255).astype(np.uint8)
                writer.write(frame)
            writer.release()

# 使用示例
engine = ExpressionTransferEngine()
engine.transfer_expression(
    source_image_path="target_portrait.jpg",
    driving_video_path="driving_video.mp4",
    output_path="transferred_result.mp4"
)
```

### 实时表情迁移系统

```python
import cv2
import dlib
import numpy as np

class LightweightExpressionTransfer:
    """
    基于OpenCV+dlib的轻量级实时表情迁移系统
    不依赖深度学习框架，可在CPU上实时运行
    """

    def __init__(self, predictor_path="shape_predictor_68_face_landmarks.dat"):
        self.face_detector = dlib.get_frontal_face_detector()
        self.landmark_predictor = dlib.shape_predictor(predictor_path)

        self.LEFT_EYE = list(range(36, 42))
        self.RIGHT_EYE = list(range(42, 48))
        self.MOUTH = list(range(48, 68))
        self.LEFT_EYEBROW = list(range(17, 22))
        self.RIGHT_EYEBROW = list(range(22, 27))

        print("轻量级表情迁移系统初始化完成")

    def detect_landmarks(self, frame):
        """检测面部关键点，返回 (68, 2) 坐标数组"""
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        faces = self.face_detector(gray)
        if len(faces) == 0:
            return None

        shape = self.landmark_predictor(gray, faces[0])
        landmarks = np.array([
            (shape.part(i).x, shape.part(i).y) for i in range(68)
        ], dtype=np.float32)
        return landmarks

    def extract_expression_params(self, landmarks):
        """从68个关键点提取表情参数"""
        face_width = np.linalg.norm(landmarks[0] - landmarks[16])
        params = {}

        # 嘴巴张开程度
        upper_lip = landmarks[62]
        lower_lip = landmarks[66]
        params["mouth_open"] = np.linalg.norm(upper_lip - lower_lip) / face_width

        # 微笑程度
        mouth_width = np.linalg.norm(landmarks[48] - landmarks[54])
        params["smile"] = mouth_width / face_width

        # 眉毛抬升
        brow_dist = np.linalg.norm(landmarks[19] - np.mean(landmarks[36:42], axis=0))
        params["brow_raise"] = brow_dist / face_width

        # 眼睛睁开程度
        eye_height = np.linalg.norm(landmarks[37] - landmarks[41])
        params["eye_open"] = eye_height / face_width

        return params

    def smooth_landmarks(self, history, current, window_size=5):
        """时间平滑：减少关键点抖动"""
        history.append(current)
        if len(history) > window_size:
            history.pop(0)
        return np.mean(history, axis=0)

    def run_realtime_transfer(self, target_image_path):
        """启动实时表情迁移"""
        target_image = cv2.imread(target_image_path)
        if target_image is None:
            raise FileNotFoundError(f"无法加载目标图片: {target_image_path}")

        target_landmarks = self.detect_landmarks(target_image)
        if target_landmarks is None:
            raise ValueError("目标图片中未检测到人脸")

        cap = cv2.VideoCapture(0)
        if not cap.isOpened():
            raise RuntimeError("无法打开摄像头")

        landmarks_history = []
        print("实时表情迁移已启动（按 'q' 退出）")

        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break

            frame = cv2.flip(frame, 1)
            source_landmarks = self.detect_landmarks(frame)

            if source_landmarks is None:
                cv2.imshow("Expression Transfer", frame)
                if cv2.waitKey(1) & 0xFF == ord("q"):
                    break
                continue

            smoothed = self.smooth_landmarks(landmarks_history, source_landmarks)
            source_params = self.extract_expression_params(smoothed)
            target_params = self.extract_expression_params(target_landmarks)

            # 计算表情差异并可视化
            display = target_image.copy()
            y_offset = 30
            for param_name in source_params:
                diff = source_params[param_name] - target_params[param_name]
                direction = "↑" if diff > 0 else "↓"
                color = (0, 255, 0) if abs(diff) < 0.1 else (0, 0, 255)
                cv2.putText(display, f"{param_name}: {direction} {abs(diff):.3f}",
                           (10, y_offset), cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 1)
                y_offset += 25

            for lm in target_landmarks.astype(int):
                cv2.circle(display, tuple(lm), 2, (0, 255, 0), -1)

            h, w = frame.shape[:2]
            combined = np.hstack([frame, cv2.resize(display, (w, h))])
            cv2.imshow("Expression Transfer", combined)

            if cv2.waitKey(1) & 0xFF == ord("q"):
                break

        cap.release()
        cv2.destroyAllWindows()

# 运行实时表情迁移
transfer_system = LightweightExpressionTransfer(
    predictor_path="shape_predictor_68_face_landmarks.dat"
)
transfer_system.run_realtime_transfer(target_image_path="target_portrait.jpg")
```

## 常见误区

### 误区一："表情迁移就是把脸换上去"

表情迁移和换脸（Face Swap）是两个完全不同的任务。换脸是将一个人的脸部区域整体替换为另一个人的脸，保持目标的面部动作。表情迁移则是保持目标的面部外观不变，只改变其表情动作——让目标人脸"模仿"源人脸的表情。

### 误区二："关键点越多迁移效果越好"

关键点数量与迁移质量之间不是简单的正相关关系。68个关键点已经能很好地描述面部的主要表情动作。478个关键点虽然更精确，但也会引入更多的噪声和不稳定性（在遮挡、光照变化等情况下）。对于实时表情迁移，关键点的**稳定性和时间一致性**比数量更重要。

### 误区三："3DMM参数迁移能处理所有表情"

3DMM的线性模型无法表达所有面部运动。舌头的运动、牙齿的显露、皱纹的形成、面部肌肉的非线性变形，都超出了3DMM的表达范围。对于高质量的数字人应用，通常需要在3DMM参数迁移的基础上，额外使用GAN或扩散模型来补充细节。

### 误区四："实时迁移必须牺牲质量"

2024-2025年的技术进展表明，实时性和高质量可以兼得。LivePortrait在80fps的速度下仍然能产生高质量的迁移结果。关键在于模型架构的优化（如使用轻量级编码器、高效的扭曲操作）和工程优化（如TensorRT推理加速、GPU内存管理）。

## 小结与练习

### 本课要点

1. 表情迁移是将源人脸的表情动作转移到目标人脸上的技术，与换脸是不同的任务
2. 关键点检测和3DMM参数提取是表情迁移的基础，将人脸表情分解为可迁移的参数
3. 三种主流迁移方法各有优劣：3DMM参数迁移简单高效，GAN合成质量更高，3DGS迁移是未来趋势
4. LivePortrait是当前最优秀的开源表情迁移方案，支持实时高质量迁移
5. OpenCV+dlib方案适合资源受限的场景，可在CPU上实时运行

### 练习一：表情相似度评估

设计一个表情相似度评估指标，量化源人脸和迁移结果之间的表情一致性。要求：
1. 基于关键点计算面部各区域的表情参数

### 练习一

**思路**：将人脸分为嘴巴、眼睛、眉毛三个区域，分别计算每个区域的表情参数，然后与源人脸对应参数比较。

**答案**：

```python
import numpy as np

class ExpressionSimilarityEvaluator:
    """表情相似度评估器"""

    REGION_INDICES = {
        "mouth": list(range(48, 68)),
        "left_eye": list(range(36, 42)),
        "right_eye": list(range(42, 48)),
        "left_brow": list(range(17, 22)),
        "right_brow": list(range(22, 27))
    }

    def compute_region_expression(self, landmarks, region_name):
        """计算某个面部区域的表情特征向量"""
        indices = self.REGION_INDICES[region_name]
        region_points = landmarks[indices]
        face_width = np.linalg.norm(landmarks[0] - landmarks[16])

        spread = np.std(region_points, axis=0)
        height = np.max(region_points[:, 1]) - np.min(region_points[:, 1])
        width = np.max(region_points[:, 0]) - np.min(region_points[:, 0])

        return np.array([
            spread[0] / face_width,
            spread[1] / face_width,
            height / face_width,
            width / face_width
        ])

    def evaluate(self, source_landmarks, target_landmarks):
        """评估表情迁移的相似度"""
        scores = {}
        for region in ["mouth", "left_eye", "right_eye", "left_brow", "right_brow"]:
            src_feat = self.compute_region_expression(source_landmarks, region)
            tgt_feat = self.compute_region_expression(target_landmarks, region)
            cosine_sim = np.dot(src_feat, tgt_feat) / (
                np.linalg.norm(src_feat) * np.linalg.norm(tgt_feat) + 1e-8
            )
            scores[region] = max(0, cosine_sim)

        weights = {"mouth": 0.35, "left_eye": 0.15, "right_eye": 0.15,
                   "left_brow": 0.175, "right_brow": 0.175}
        overall = sum(scores[k] * weights[k] for k in scores)
        return scores, overall
```

def extract_style_features(expression_data):

def apply_style_to_driving(driving_params, source_style, target_style):
    """将源风格特征应用到驱动参数上：归一化去除驱动者风格，再按源风格重新缩放"""
    styled = {}

            target_style.get(f"{key}_std", 1) + 1e-8
        )
