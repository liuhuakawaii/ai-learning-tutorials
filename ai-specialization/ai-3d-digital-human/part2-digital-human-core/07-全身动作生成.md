# 第13课：全身动作生成——Audio2Body / MotionDiffuse

## 场景引入

数字人能"开口说话"了，但如果站在那里一动不动，像个会说话的蜡像，用户体验会大打折扣。真实的人在说话时会配合手势、身体摆动、重心转移——这些非语言信息传达了大量情绪和意图。

全身动作生成（Full-Body Motion Generation）的目标是让数字人根据文本、音乐或语音自动生成自然的全身动作。这节课我们从人体动作表示讲起，学习主流的动作生成方案，并通过三个实战项目掌握从动作生成到 3D 渲染的完整链路。

## 学习目标

完成本课学习后，你将能够：

1. 理解人体动作的三种主流表示方法（骨骼关键点、SMPL、SMPL-X）
2. 区分文本驱动、音乐驱动、语音驱动三种动作生成范式
3. 使用 MediaPipe Pose 从视频中提取人体关键点
4. 使用 MotionDiffuse 生成文本驱动的动作序列
5. 使用 Three.js + Mixamo 实现 3D 角色动作渲染

## 1. 人体动作表示方法

### 1.1 三种表示方法对比

要让计算机理解和生成人体动作，首先需要一种数学化的方式表示人体姿态。目前有三种主流方案：

```
┌──────────────────────────────────────────────────────────────┐
│                  人体动作表示方法对比                           │
├──────────────────┬──────────────────┬────────────────────────┤
│    2D/3D 关键点   │    SMPL 模型     │    SMPL-X 模型         │
├──────────────────┼──────────────────┼────────────────────────┤
│ 17-33 个关键点    │ 6890 个顶点      │ 10475 个顶点           │
│ 骨骼关节位置      │ 身体形状+姿态    │ 身体+手部+面部          │
│ 轻量、快速        │ 连续、可微分     │ 全身细节               │
│ MediaPipe/Pose   │ 动作生成主流     │ 数字人最终方案          │
└──────────────────┴──────────────────┴────────────────────────┘
```

### 1.2 骨骼关键点（Skeleton）

最简单的表示方式，用一组关键点坐标表示人体姿态：

```
         ○ (鼻子)              关键点索引（COCO 17点）:
        /|\                    0: 鼻子
       / | \                   1: 左眼 / 2: 右眼
      ○  ○  ○ (肩膀)          3: 左耳 / 4: 右耳
         |                     5: 左肩 / 6: 右肩
    ○----+----○ (肘部)         7: 左肘 / 8: 右肘
         |                     9: 左腕 / 10: 右腕
         ○ (髋部)              11: 左髋 / 12: 右髋
        / \                    13: 左膝 / 14: 右膝
       /   \                   15: 左踝 / 16: 右踝
      ○     ○ (膝部)
      |     |
      ○     ○ (踝部)
```

每个关键点有 (x, y, z) 三个坐标，17 个关键点共 51 个数值。加上时间维度，一个动作序列的表示为 `(T, 17, 3)`，其中 T 是帧数。

**优点**：轻量、易于可视化、推理速度快
**缺点**：无法表示身体形状、手指细节、面部表情

### 1.3 SMPL 模型

SMPL（Skinned Multi-Person Linear Model）是学术界和工业界最广泛使用的人体模型：

```
SMPL 参数分解：
┌──────────────────────────────────────────┐
│              SMPL Model                   │
│                                          │
│  输入参数：                                │
│  ┌─────────┐  ┌──────────┐  ┌─────────┐ │
│  │  θ (姿态)│  │  β (形状) │  │  t (平移)│ │
│  │  72维    │  │  10维     │  │  3维    │ │
│  │ 24个关节 │  │ 身高/体型 │  │ 位置    │ │
│  │ ×3旋转角 │  │          │  │        │ │
│  └────┬────┘  └────┬─────┘  └────┬────┘ │
│       │            │             │       │
│       └────────────┼─────────────┘       │
│                    ▼                     │
│           ┌──────────────┐               │
│           │  SMPL Layer  │  ← 可微分     │
│           └──────┬───────┘               │
│                  ▼                       │
│  输出：                                    │
│  ┌──────────────────────────┐            │
│  │  6890 个顶点 3D 坐标      │            │
│  │  + 24 个关节 3D 位置      │            │
│  └──────────────────────────┘            │
└──────────────────────────────────────────┘
```

SMPL 的核心优势是**可微分**——可以将动作生成模型的输出直接映射到 3D 网格，实现端到端训练。

### 1.4 SMPL-X 模型

SMPL-X 在 SMPL 基础上扩展了手部和面部：

```
SMPL-X = SMPL (身体) + MANO (手部) + FLAME (面部)

身体姿态参数 θ_body:  63 维 (21 个关节 × 3)
手部姿态参数 θ_hand:  90 维 (30 个手指关节 × 3)
面部表情参数 ψ_face:  10 维 (表情基系数)
形状参数 β:           10 维
总参数量:             ~173 维 → 10475 个顶点
```

对于需要手势和表情的数字人场景，SMPL-X 是最终表示方案。但其参数空间更大，生成难度也更高。

## 2. 动作生成分类

### 2.1 三种驱动范式

```
┌──────────────────────────────────────────────────────────────┐
│                    动作生成驱动范式                             │
│                                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐   │
│  │  文本驱动     │  │  音乐驱动     │  │  语音驱动         │   │
│  │              │  │              │  │                  │   │
│  │ "挥手打招呼"  │  │ 节拍/旋律     │  │ 语音韵律→手势     │   │
│  │              │  │              │  │                  │   │
│  │ MotionGPT    │  │ EDGE         │  │ Speech2Gesture   │   │
│  │ MDM          │  │ FACT         │  │ Audio2Body       │   │
│  │ MotionDiffuse│  │ Bailando     │  │                  │   │
│  └──────────────┘  └──────────────┘  └──────────────────┘   │
│                                                              │
│  应用：虚拟主播     应用：虚拟偶像     应用：对话数字人          │
│  交互式场景         舞蹈生成          实时对话                  │
└──────────────────────────────────────────────────────────────┘
```

**文本驱动**：输入自然语言描述（如"双手叉腰，左右摇晃"），输出对应动作序列。适合交互式场景和虚拟主播。

**音乐驱动**：输入音乐音频，输出与节拍、旋律匹配的舞蹈动作。适合虚拟偶像和直播场景。

**语音驱动**：输入语音音频，输出与语音韵律同步的肢体动作（主要是手势和上半身）。适合对话数字人。

### 2.2 生成模型架构

现代动作生成主要基于扩散模型（Diffusion Model）：

```
文本/音频输入
      │
      ▼
┌──────────────┐
│  条件编码器    │  ← CLIP / Whisper / HuBERT
└──────┬───────┘
       │
       ▼
┌──────────────┐      ┌──────────────┐
│  扩散过程     │      │  噪声调度器    │
│  (Denoising) │ ←─── │  (Scheduler)  │
└──────┬───────┘      └──────────────┘
       │
       ▼
┌──────────────┐
│  动作解码器    │  ← Transformer / U-Net
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  SMPL 参数    │  → 3D 人体姿态序列
└──────────────┘
```

### 3.2 实时姿态检测

```python
import cv2
import mediapipe as mp
import numpy as np
from dataclasses import dataclass


@dataclass
class PoseFrame:
    frame_id: int
    timestamp: float
    landmarks: np.ndarray  # (33, 4) → x, y, z, visibility


class PoseExtractor:
    """MediaPipe Pose 人体关键点提取器"""

    def __init__(
        self,
        model_complexity: int = 2,
        min_detection_confidence: float = 0.5,
        min_tracking_confidence: float = 0.5
    ):
        self.mp_pose = mp.solutions.pose
        self.pose = self.mp_pose.Pose(
            static_image_mode=False,
            model_complexity=model_complexity,
            smooth_landmarks=True,
            enable_segmentation=False,
            min_detection_confidence=min_detection_confidence,
            min_tracking_confidence=min_tracking_confidence
        )
        self.mp_drawing = mp.solutions.drawing_utils

    def extract_from_video(self, video_path: str) -> list[PoseFrame]:
        """从视频中提取所有帧的关键点"""
        cap = cv2.VideoCapture(video_path)
        fps = cap.get(cv2.CAP_PROP_FPS)
        frames = []
        frame_id = 0

        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break

            rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            results = self.pose.process(rgb_frame)

            if results.pose_landmarks:
                landmarks = np.array([
                    [lm.x, lm.y, lm.z, lm.visibility]
                    for lm in results.pose_landmarks.landmark
                ])
                frames.append(PoseFrame(
                    frame_id=frame_id,
                    timestamp=frame_id / fps,
                    landmarks=landmarks
                ))

            frame_id += 1

        cap.release()
        return frames

    def extract_from_webcam(self, num_frames: int = 300) -> list[PoseFrame]:
        """从摄像头实时提取关键点"""
        cap = cv2.VideoCapture(0)
        fps = 30.0
        frames = []
        frame_id = 0

        while cap.isOpened() and frame_id < num_frames:
            ret, frame = cap.read()
            if not ret:
                break

            rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            results = self.pose.process(rgb_frame)

            if results.pose_landmarks:
                landmarks = np.array([
                    [lm.x, lm.y, lm.z, lm.visibility]
                    for lm in results.pose_landmarks.landmark
                ])
                frames.append(PoseFrame(
                    frame_id=frame_id,
                    timestamp=frame_id / fps,
                    landmarks=landmarks
                ))

                # 实时绘制
                self.mp_drawing.draw_landmarks(
                    frame, results.pose_landmarks,
                    self.mp_pose.POSE_CONNECTIONS
                )

            cv2.imshow('Pose Detection', frame)
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break

            frame_id += 1

        cap.release()
        cv2.destroyAllWindows()
        return frames

    def poses_to_smpl_motion(self, poses: list[PoseFrame]) -> np.ndarray:
        """
        将 MediaPipe 关键点转换为简化的 SMPL 格式
        注意：这是简化版本，实际转换需要更复杂的映射
        """
        # MediaPipe 33 点 → SMPL 24 关节的映射
        mediapipe_to_smpl = {
            0: 15,   # 鼻子 → 头部
            11: 16,  # 左肩 → 左肩
            12: 17,  # 右肩 → 右肩
            13: 18,  # 左肘 → 左肘
            14: 19,  # 右肘 → 右肘
            15: 20,  # 左腕 → 左腕
            16: 21,  # 右腕 → 右腕
            23: 1,   # 左髋 → 左髋
            24: 2,   # 右髋 → 右髋
            25: 4,   # 左膝 → 左膝
            26: 5,   # 右膝 → 右膝
            27: 7,   # 左踝 → 左踝
            28: 8,   # 右踝 → 右踝
        }

        T = len(poses)
        smpl_poses = np.zeros((T, 24, 3))

        for t, pose in enumerate(poses):
            for mp_idx, smpl_idx in mediapipe_to_smpl.items():
                if mp_idx < len(pose.landmarks):
                    smpl_poses[t, smpl_idx] = pose.landmarks[mp_idx, :3]

        return smpl_poses


# 使用示例
extractor = PoseExtractor()

# 从视频提取
poses = extractor.extract_from_video("dance_video.mp4")
print(f"提取了 {len(poses)} 帧姿态数据")

# 转换为 SMPL 格式
motion_data = extractor.poses_to_smpl_motion(poses)
print(f"动作数据形状：{motion_data.shape}")  # (T, 24, 3)

# 保存
np.save("extracted_motion.npy", motion_data)
```

### 4.3 文本驱动动作生成

```python
import torch
import numpy as np
from motiondiffuse.pipelines import MotionDiffusePipeline


class TextToMotionGenerator:
    """文本驱动动作生成器"""

    def __init__(self, model_path: str = "pretrained_models/motiondiffuse"):
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        self.pipeline = MotionDiffusePipeline.from_pretrained(model_path)
        self.pipeline.to(self.device)

    def generate(
        self,
        text: str,
        num_frames: int = 120,
        guidance_scale: float = 7.5,
        num_inference_steps: int = 50,
        seed: int = 42
    ) -> np.ndarray:
        """
        从文本生成动作序列

        参数：
            text: 动作描述文本
            num_frames: 输出帧数（30fps 下 120帧 = 4秒）
            guidance_scale: 文本引导强度
            num_inference_steps: 扩散去噪步数

        返回：
            motion: (T, 24, 3) SMPL 关节旋转角
        """
        generator = torch.Generator(device=self.device).manual_seed(seed)

        with torch.no_grad():
            result = self.pipeline(
                text=text,
                num_frames=num_frames,
                guidance_scale=guidance_scale,
                num_inference_steps=num_inference_steps,
                generator=generator,
            )

        motion = result.motions[0].cpu().numpy()  # (T, 24, 3)
        return motion

    def generate_batch(self, texts: list[str], **kwargs) -> list[np.ndarray]:
        """批量生成动作"""
        results = []
        for text in texts:
            motion = self.generate(text, **kwargs)
            results.append(motion)
        return results


# 使用示例
generator = TextToMotionGenerator()

# 生成打招呼动作
wave_motion = generator.generate(
    text="A person waves hello with the right hand while standing still.",
    num_frames=90,
    guidance_scale=7.5
)
np.save("wave_hello.npy", wave_motion)

# 生成走路动作
walk_motion = generator.generate(
    text="A person walks forward confidently with natural arm swings.",
    num_frames=120
)
np.save("walk_forward.npy", walk_motion)

# 生成跳舞动作
dance_motion = generator.generate(
    text="A person dances energetically with arms raised and body swaying.",
    num_frames=180,
    guidance_scale=10.0
)
np.save("dance.npy", dance_motion)
```

### 4.4 动作平滑与后处理

```python
import numpy as np
from scipy.ndimage import gaussian_filter1d


class MotionPostProcessor:
    """动作后处理器：平滑、拼接、循环"""

    @staticmethod
    def smooth(motion: np.ndarray, sigma: float = 1.5) -> np.ndarray:
        """高斯平滑，减少抖动"""
        T, J, D = motion.shape
        smoothed = np.zeros_like(motion)
        for j in range(J):
            for d in range(D):
                smoothed[:, j, d] = gaussian_filter1d(motion[:, j, d], sigma=sigma)
        return smoothed

    @staticmethod
    def blend_transition(
        motion_a: np.ndarray,
        motion_b: np.ndarray,
        blend_frames: int = 15
    ) -> np.ndarray:
        """两个动作之间的平滑过渡"""
        if blend_frames > min(len(motion_a), len(motion_b)):
            blend_frames = min(len(motion_a), len(motion_b)) // 2

        # 线性插值过渡
        tail_a = motion_a[-blend_frames:]
        head_b = motion_b[:blend_frames]

        blended = np.zeros_like(tail_a)
        for i in range(blend_frames):
            alpha = i / blend_frames
            blended[i] = (1 - alpha) * tail_a[i] + alpha * head_b[i]

        # 拼接
        result = np.concatenate([
            motion_a[:-blend_frames],
            blended,
            motion_b[blend_frames:]
        ], axis=0)

        return result

    @staticmethod
    def make_loop(motion: np.ndarray, blend_frames: int = 15) -> np.ndarray:
        """将动作转为无缝循环"""
        return MotionPostProcessor.blend_transition(motion, motion, blend_frames)

    @staticmethod
    def normalize_height(motion: np.ndarray) -> np.ndarray:
        """归一化高度，确保角色站在地面上"""
        # 假设 SMPL 关节 0 是骨盆
        min_y = motion[:, :, 1].min()
        motion[:, :, 1] -= min_y
        return motion


# 使用示例
processor = MotionPostProcessor()

motion = np.load("dance.npy")

# 平滑
smoothed = processor.smooth(motion, sigma=2.0)

# 转为循环动画
looped = processor.make_loop(smoothed, blend_frames=20)

# 归一化高度
normalized = processor.normalize_height(looped)

np.save("dance_loop_smooth.npy", normalized)
print(f"处理完成：{normalized.shape}")
```

## 5. Three.js + Mixamo 实战（3D 渲染）

### 5.1 方案介绍

生成的 SMPL 动作数据需要渲染为可视化的 3D 角色。Mixamo 提供了大量预设角色和动画，Three.js 负责 Web 端 3D 渲染。这个组合是数字人前端最常用的方案。

### 5.2 Mixamo 动画下载

Mixamo（https://www.mixamo.com）提供免费的 3D 角色动画：
1. 上传 FBX 格式的角色模型（或使用预设角色）
2. 选择动画（走路、跑步、打招呼等）
3. 下载为 FBX 格式，选择 "With Skin"

```javascript
        });
        this.renderer.setSize(this.container.clientWidth, this.container.clientHeight);
        this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
        this.renderer.shadowMap.enabled = true;
        this.renderer.shadowMap.type = THREE.PCFSoftShadowMap;
        this.renderer.toneMapping = THREE.ACESFilmicToneMapping;
        this.renderer.toneMappingExposure = 1.0;
        this.container.appendChild(this.renderer.domElement);

        window.addEventListener('resize', () => this._onResize());
    }

    _initCamera() {
        this.camera = new THREE.PerspectiveCamera(
            45,
            this.container.clientWidth / this.container.clientHeight,
            0.1,
            100
        );
        this.camera.position.set(0, 1.5, 3);
        this.camera.lookAt(0, 1, 0);
    }

    _initLights() {
        const ambient = new THREE.AmbientLight(0xffffff, 0.5);
        this.scene.add(ambient);

        const directional = new THREE.DirectionalLight(0xffffff, 1.0);
        directional.position.set(5, 10, 7);
        directional.castShadow = true;
        directional.shadow.mapSize.set(2048, 2048);
        this.scene.add(directional);

        const fill = new THREE.DirectionalLight(0xffffff, 0.3);
        fill.position.set(-5, 5, -5);
        this.scene.add(fill);
    }

    _initControls() {
        this.controls = new OrbitControls(this.camera, this.renderer.domElement);
        this.controls.target.set(0, 1, 0);
        this.controls.enableDamping = true;
        this.controls.dampingFactor = 0.05;
    }

    _initGround() {
        const groundGeo = new THREE.PlaneGeometry(20, 20);
        const groundMat = new THREE.MeshStandardMaterial({
            color: 0x333333,
            roughness: 0.8
        });
        this.ground = new THREE.Mesh(groundGeo, groundMat);
        this.ground.rotation.x = -Math.PI / 2;
        this.ground.receiveShadow = true;
        this.scene.add(this.ground);
    }

    async loadCharacter(gltfPath) {
        const loader = new GLTFLoader();
        return new Promise((resolve, reject) => {
            loader.load(
                gltfPath,
                (gltf) => {
                    this.character = gltf.scene;
                    this.character.traverse((child) => {
                        if (child.isMesh) {
                            child.castShadow = true;
                            child.receiveShadow = true;
                        }
                    });
                    this.scene.add(this.character);

                    if (gltf.animations.length > 0) {
                        this.mixer = new THREE.AnimationMixer(this.character);
                        gltf.animations.forEach((clip) => {
                            this.actions[clip.name] = this.mixer.clipAction(clip);
                        });
                    }

                    resolve(this.character);
                },
                undefined,
                reject
            );
        });
    }

    async loadAnimation(fbxPath, animName) {
        const loader = new FBXLoader();
        return new Promise((resolve, reject) => {
            loader.load(
                fbxPath,
                (fbx) => {
                    if (fbx.animations.length > 0) {
                        const clip = fbx.animations[0];
                        clip.name = animName;

                        if (this.mixer) {
                            const action = this.mixer.clipAction(clip, this.character);
                            this.actions[animName] = action;
                        }
                    }
                    resolve(fbx);
                },
                undefined,
                reject
            );
        });
    }

    playAnimation(name, crossFadeDuration = 0.3) {
        const newAction = this.actions[name];
        if (!newAction) {
            console.warn(`动画 "${name}" 不存在`);
            return;
        }

        if (this.currentAction && this.currentAction !== newAction) {
            this.currentAction.fadeOut(crossFadeDuration);
        }

        newAction.reset();
        newAction.fadeIn(crossFadeDuration);
        newAction.play();
        this.currentAction = newAction;
    }

    playAnimationSequence(names, durations) {
        let accumulatedTime = 0;
        names.forEach((name, index) => {
            setTimeout(() => {
                this.playAnimation(name);
            }, accumulatedTime * 1000);
            accumulatedTime += durations[index] || 3;
        });
    }

    _animate() {
        requestAnimationFrame(() => this._animate());
        const delta = this.clock.getDelta();
        if (this.mixer) this.mixer.update(delta);
        this.controls.update();
        this.renderer.render(this.scene, this.camera);
    }

    _onResize() {
        const w = this.container.clientWidth;
        const h = this.container.clientHeight;
        this.camera.aspect = w / h;
        this.camera.updateProjectionMatrix();
        this.renderer.setSize(w, h);
    }

    destroy() {
        this.renderer.dispose();
        this.container.removeChild(this.renderer.domElement);
    }
}


export { DigitalHumanRenderer };
```

### 5.5 语音驱动动作序列

```javascript
class VoiceDrivenMotionController {
    constructor(digitalHumanRenderer) {
        this.renderer = digitalHumanRenderer;
        this.motionMap = {
            greeting: 'Wave',
            thinking: 'Idle',
            speaking: 'Talk',
            walking: 'Walk',
            excited: 'Dance',
        };
    }

    analyzeSpeechIntent(text) {
        const lowerText = text.toLowerCase();

        if (/你好|欢迎|嗨|hello|hi/.test(lowerText)) return 'greeting';
        if (/让我想想|嗯|这个问题/.test(lowerText)) return 'thinking';
        if (/太好了|耶|棒/.test(lowerText)) return 'excited';
        if (/走|出发|一起去/.test(lowerText)) return 'walking';

        return 'speaking';
    }

    async syncWithSpeech(text, audioElement) {
        const intent = this.analyzeSpeechIntent(text);
        const animName = this.motionMap[intent] || 'Talk';

        this.renderer.playAnimation(animName);

        if (audioElement) {
            audioElement.play();

            audioElement.addEventListener('ended', () => {
                this.renderer.playAnimation('Idle');
            }, { once: true });
        }
    }

    async playConversation(dialogues) {
        for (const dialogue of dialogues) {
            await this.syncWithSpeech(dialogue.text, dialogue.audio);
            await new Promise(resolve => {
                if (dialogue.audio) {
                    dialogue.audio.addEventListener('ended', resolve, { once: true });
                } else {
                    setTimeout(resolve, dialogue.duration || 3000);
                }
            });
        }
    }
}
```

## 常见误区

### 误区一：动作越复杂越好

数字人的动作应该**服务于沟通**，而不是炫技。一个说话时频繁做大幅度手势的数字人，会让用户觉得不专业。对话场景下，微妙的点头、适度的手势、自然的身体摇晃，比夸张的舞蹈动作更有效。

### 误区二：33 个关键点足够表示全身动作

MediaPipe Pose 的 33 个关键点只能表示身体躯干和四肢的大致位置，无法表示：
- 手指动作（需要 MediaPipe Hands，21 个关键点 × 每手）
- 面部表情（需要 MediaPipe Face Mesh，468 个关键点）
- 身体形状差异

对于高质量数字人，建议使用 SMPL-X 模型，它统一了身体、手部和面部。

### 误区三：扩散模型生成的动作可以直接使用

扩散模型生成的动作序列通常存在以下问题，必须后处理：
- 帧间抖动（需要用高斯平滑）
- 脚部滑动（需要用脚部 IK 修正）
- 首尾不连续（需要做过渡混合）
- 与参考 T-pose 对齐问题

### 误区四：Mixamo 动画可以随意组合

Mixamo 的不同动画之间，骨骼绑定可能有差异。直接切换动画会导致"闪跳"。必须使用 `crossFade` 或 `blending` 实现平滑过渡。

## 小结

本课我们系统学习了全身动作生成技术：

1. **动作表示**：骨骼关键点适合轻量场景，SMPL 是动作生成的主流表示，SMPL-X 是数字人的最终方案
2. **生成范式**：文本驱动适合交互场景，音乐驱动适合虚拟偶像，语音驱动适合对话数字人
3. **MediaPipe Pose**：实时提取人体关键点的利器，适合快速原型
4. **MotionDiffuse**：文本驱动动作生成的前沿方案，基于扩散模型
5. **Three.js + Mixamo**：Web 端 3D 渲染的标准方案，适合前端集成

### 练习一

**思路**：根据场景的计算资源、精度需求、实时性要求选择方案。

**答案**：

1. **手机端健身 App → 2D/3D 骨骼关键点**
   - 手机端算力有限，关键点模型（如 MoveNet、MediaPipe）轻量且快速
   - 健身场景只需要关节角度和位置，不需要身体形状
   - 可以用 2D 关键点做角度计算，进一步降低计算量

2. **学术研究动作生成 → SMPL**
   - SMPL 是可微分模型，可以直接接入神经网络做端到端训练
   - AMASS 数据集提供大量 SMPL 格式的动作数据
   - SMPL 参数空间（72 维旋转 + 10 维形状）适中，模型容易学习

3. **高保真数字人 → SMPL-X**
   - 需要手势和表情，SMPL-X 统一了身体、手部、面部
   - 10475 个顶点提供足够的细节
   - 虽然参数空间大（~173 维），但对高保真场景是必要的

**要点**：
- 关键点适合轻量实时场景
- SMPL 是研究和生成的标准
- SMPL-X 是数字人最终方案
- 选择时考虑：计算资源 × 精度需求 × 实时性

### 练习二

**思路**：基于 MediaPipe Pose 封装录制、保存、回放功能。

**答案**：

```python
import cv2
import mediapipe as mp
import numpy as np
import time


class MotionRecorder:
    def __init__(self):
        self.mp_pose = mp.solutions.pose
        self.pose = self.mp_pose.Pose(
            static_image_mode=False,
            model_complexity=2,
            smooth_landmarks=True
        )
        self.mp_drawing = mp.solutions.drawing_utils
        self.recording = False
        self.recorded_frames = []
        self.fps = 30.0

    def start_recording(self):
        self.recording = True
        self.recorded_frames = []
        print("开始录制... 按 S 停止")

    def stop_recording(self):
        self.recording = False
        print(f"录制停止，共 {len(self.recorded_frames)} 帧")

    def save(self, filepath: str):
        if not self.recorded_frames:
            print("没有录制数据")
            return
        data = np.array(self.recorded_frames)
        np.save(filepath, data)
        print(f"保存到 {filepath}，形状：{data.shape}")

    def load_and_replay(self, filepath: str):
        data = np.load(filepath)
        print(f"加载 {filepath}，形状：{data.shape}")

        for frame_idx in range(len(data)):
            frame = np.ones((480, 640, 3), dtype=np.uint8) * 50
            landmarks = data[frame_idx]

            for i, (x, y, z) in enumerate(landmarks):
                px = int(x * 640)
                py = int(y * 480)
                cv2.circle(frame, (px, py), 4, (0, 255, 0), -1)

            connections = [
                (11, 12), (11, 13), (13, 15), (12, 14), (14, 16),
                (11, 23), (12, 24), (23, 24),
                (23, 25), (25, 27), (24, 26), (26, 28)
            ]
            for (i, j) in connections:
                if i < len(landmarks) and j < len(landmarks):
                    pt1 = (int(landmarks[i][0] * 640), int(landmarks[i][1] * 480))
                    pt2 = (int(landmarks[j][0] * 640), int(landmarks[j][1] * 480))
                    cv2.line(frame, pt1, pt2, (0, 200, 255), 2)

            cv2.putText(frame, f"Frame {frame_idx}", (10, 30),
                       cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 255, 255), 2)

            cv2.imshow('Replay', frame)
            if cv2.waitKey(33) & 0xFF == ord('q'):
                break

        cv2.destroyAllWindows()

    def run(self):
        cap = cv2.VideoCapture(0)

        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break

            rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            results = self.pose.process(rgb)

            if results.pose_landmarks:
                self.mp_drawing.draw_landmarks(
                    frame, results.pose_landmarks,
                    self.mp_pose.POSE_CONNECTIONS
                )

                if self.recording:
                    landmarks = np.array([
                        [lm.x, lm.y, lm.z]
                        for lm in results.pose_landmarks.landmark
                    ])
                    self.recorded_frames.append(landmarks)

            status = "REC" if self.recording else "READY"
            color = (0, 0, 255) if self.recording else (0, 255, 0)
            cv2.putText(frame, status, (10, 30),
                       cv2.FONT_HERSHEY_SIMPLEX, 1, color, 2)
            cv2.putText(frame, f"Frames: {len(self.recorded_frames)}", (10, 60),
                       cv2.FONT_HERSHEY_SIMPLEX, 0.7, (255, 255, 255), 1)

            cv2.imshow('Motion Recorder', frame)
            key = cv2.waitKey(1) & 0xFF

            if key == ord('r'):
                self.start_recording()
            elif key == ord('s'):
                self.stop_recording()
            elif key == ord('v'):
                self.save("recorded_motion.npy")
            elif key == ord('p'):
                cap.release()
                cv2.destroyAllWindows()
                self.load_and_replay("recorded_motion.npy")
                return
            elif key == ord('q'):
                break

        cap.release()
        cv2.destroyAllWindows()


if __name__ == "__main__":
    recorder = MotionRecorder()
    recorder.run()
```

**要点**：
- 按 R 开始录制、S 停止、V 保存、P 回放
- 录制数据为 (T, 33, 3) 的 numpy 数组
- 回放时在黑底上绘制骨骼，可以检查录制效果
- 实际项目中需要加时间戳信息，便于与音频同步

### 练习三

**思路**：串联文本→动作生成→后处理→3D 渲染的完整链路。

**答案**：

```python
import numpy as np
from scipy.ndimage import gaussian_filter1d


class TextToMotionPipeline:
    def __init__(self):
        self.generator = TextToMotionGenerator()
        self.postprocessor = MotionPostProcessor()

    def generate_for_digital_human(
        self,
        text: str,
        output_path: str,
        num_frames: int = 120,
        smooth_sigma: float = 2.0,
        make_seamless: bool = False
    ) -> dict:
        motion = self.generator.generate(
            text=text,
            num_frames=num_frames,
            guidance_scale=7.5
        )

        motion = self.postprocessor.smooth(motion, sigma=smooth_sigma)
        motion = self.postprocessor.normalize_height(motion)

        if make_seamless:
            motion = self.postprocessor.make_loop(motion, blend_frames=20)

        np.save(output_path, motion)

        return {
            "text": text,
            "frames": motion.shape[0],
            "joints": motion.shape[1],
            "output_path": output_path,
            "looped": make_seamless,
        }


pipeline = TextToMotionPipeline()
result = pipeline.generate_for_digital_human(
    text="A person waves hello and then nods in agreement.",
    output_path="./output/greeting_motion.npy",
    num_frames=150,
    make_seamless=False
)
print(result)
```

**要点**：
- Pipeline 封装了生成、平滑、归一化的完整流程
- `make_seamless` 参数控制是否生成循环动画
- 输出的 `.npy` 文件可以直接用于 Three.js 驱动 3D 角色
- 实际项目中还需要加入脚部 IK 修正和物理约束
