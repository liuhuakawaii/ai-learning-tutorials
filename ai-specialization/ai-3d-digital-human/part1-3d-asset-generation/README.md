# Part 1：3D 资产 AI 生成

## 阶段目标

从文本或图像生成 3D 模型，理解 NeRF 和 Gaussian Splatting 的核心原理，能独立构建一条 3D 资产生成 Pipeline。

4. [文本驱动 3D 生成](04-文本驱动3D生成.md)
5. [图像驱动 3D 重建](05-图像驱动3D重建.md)

## 验收标准

- 能解释 NeRF 的隐式表示和体渲染原理，并运行一个 NeRF 训练流程
- 能用 Gaussian Splatting 实现实时渲染并说明其优于 NeRF 的场景
- 能用 TripoSR 或 InstantMesh 从单张图像生成可用的 3D 模型
- 能构建一条从输入到输出的完整 3D 资产生成 Pipeline
