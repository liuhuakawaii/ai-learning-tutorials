## 核心概念

### 一、单图 3D 重建的三大挑战

从单张 2D 图像恢复 3D 结构是一个经典的不适定问题——2D 投影丢失了深度信息，存在无穷多种合理的 3D 解释。

```
┌─────────────────────────────────────────────────────────┐
│                单图 3D 重建的三大挑战                      │
│                                                          │
│  ① 深度歧义                                              │
│     同一个 2D 投影可以对应无数种 3D 形状                   │
│     → 远处的小楼 ≈ 近处的大楼？                           │
│                                                          │
│  ② 遮挡缺失                                              │
│     看不到背面：猫的尾巴怎么长的？耳朵后面？               │
│     模型必须"脑补"不可见区域                              │
│                                                          │
│  ③ 材质与光照耦合                                         │
│     图像中的明暗是几何凹凸还是材质反射？                   │
│     需要解耦才能恢复真实形状                               │
└─────────────────────────────────────────────────────────┘
```

传统方法（Shape from Shading、Photometric Stereo）通过强假设解决这些问题，但泛化能力有限。深度学习方法通过大规模 3D 数据学习先验知识来应对挑战。

### 二、技术路线演进

```
技术路线演进（2020-2025）：

第一代：多视图立体（MVS）
  输入：数十张不同角度的照片
  原理：三角测量恢复深度
  局限：需要大量输入图像，对纹理弱区域效果差

第二代：多视图生成 + 重建（两阶段）
  输入：单张图像
  阶段1：用扩散模型生成新视角图像
  阶段2：从多视图重建 3D
  代表：Zero123 → Wonder3D → InstantMesh

第三代：前馈单图重建（端到端）
  输入：单张图像
  原理：大型 Transformer 一次前向传播直接预测 3D 表示
  代表：LRM → TripoSR → CRM

┌──────────┐    ┌──────────────┐    ┌──────────┐
│ 单张图像 │───►│ 多视图生成器  │───►│ 3D重建器 │  第二代
└──────────┘    └──────────────┘    └──────────┘

┌──────────┐    ┌──────────────────────┐    ┌──────────┐
│ 单张图像 │───►│ 前馈 Transformer     │───►│ 3D 表示  │  第三代
└──────────┘    └──────────────────────┘    └──────────┘
```

### 三、Wonder3D：单图→多视图法线+颜色

Wonder3D（2023）的关键创新是同时生成多视图 RGB 图像和对应的法线图。法线图编码表面朝向，不受光照和材质影响，相当于给重建网络提供了"纯净的几何线索"。

```
Wonder3D 工作流程：

输入图像 → Cross-View Diffusion Model → 6个视角 × (RGB + Normal)
                │
                ├─ 多视图注意力机制：不同视角共享信息
                └─ 同时输出法线图：提供精确的局部几何细节

输出布局：
  前(RGB+法线)  右(RGB+法线)  后(RGB+法线)
  左(RGB+法线)  顶(RGB+法线)  底(RGB+法线)

→ NeuS2 重建（法线图 + RGB → 隐式表面 → 网格）
```

### 四、TripoSR 架构解析

TripoSR（2024，Stability AI + Tripo AI）是目前最快的前馈单图 3D 重建模型，基于 LRM 改进。核心思想是用大型 Transformer 将图像特征直接解码为 Triplane 3D 表示。

```
TripoSR 架构：

输入图像 (518×518)
     │
     ▼
┌──────────────────┐
│ DINOv2 ViT-L/14  │  图像编码器（冻结）
│                  │  提取 1370 个特征 tokens
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Token Merging    │  压缩到 256 个 tokens
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Triplane         │  12层 Transformer
│ Transformer      │  triplane queries ←交叉注意力→ image tokens
│ Decoder          │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Triplane 表示    │  三个正交平面 XY/XZ/YZ
│  每个 64×64×80   │  O(3×n²) 内存，比体素 O(n³) 紧凑
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ FlexiCubes 解码   │  可微分等值面提取
└────────┬─────────┘
         │
         ▼
   3D 网格 + 纹理（推理 < 1 秒）
```

**为什么用 Triplane？** 查询 3D 空间中某点的特征时，只需将该点投影到三个平面，取对应位置的特征拼接。相比体素表示，内存开销从 O(n³) 降到 O(3×n²)。

### 五、InstantMesh：多视图+重建的两阶段方法

InstantMesh（2024）采用两阶段策略，综合质量最好：

```
InstantMesh Pipeline：

阶段一：多视图生成
  输入图像 → Zero123-XL → 6个正交视角的 RGB 图像
                            前  右  后  左  顶  底

阶段二：稀疏视图重建
  多视图图像 → DINOv2特征 → 稀疏注意力融合 → Triplane → FlexiCubes → 网格

关键创新：稀疏注意力
  普通注意力 O(N²) → 稀疏注意力（只在视觉重叠区域交互）→ 计算量降低约 60%
  总耗时约 30 秒
```

## 代码实战

### 一、TripoSR：单图生成 3D 模型

```python
"""
TripoSR 单图 3D 重建
环境：pip install torch torchvision transformers trimesh rembg Pillow
      pip install git+https://github.com/VAST-AI-Research/TripoSR.git
"""

import torch
import io
from PIL import Image
from pathlib import Path


def remove_background(image_path: str) -> Image.Image:
    """移除图像背景"""
    import rembg
    with open(image_path, "rb") as f:
        output = rembg.remove(f.read())
    return Image.open(io.BytesIO(output)).convert("RGBA")


def load_triposr(device: str = "cuda:0"):
    """加载 TripoSR 模型"""
    from tsr.system import TSR
    model = TSR.from_pretrained("stabilityai/TripoSR", config_name="config.yaml", weight_name="model.ckpt")
    model.renderer.set_chunk_size(8192)
    model.to(device).eval()
    return model


def reconstruct_3d(model, image: Image.Image, output_dir: str = "output", mc_resolution: int = 256) -> str:
    """从图像重建 3D 模型并导出 OBJ 和 glTF"""
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    image = image.resize((512, 512))

    with torch.no_grad():
        scene_codes = model([image], device=model.device)
        meshes = model.extract_mesh(scene_codes, resolution=mc_resolution, threshold=25.0)

    mesh = meshes[0]
    obj_path = output_path / "model.obj"
    gltf_path = output_path / "model.glb"
    mesh.export(str(obj_path))
    mesh.export(str(gltf_path), file_type="glb")

    print(f"OBJ: {obj_path} | glTF: {gltf_path}")
    print(f"顶点: {len(mesh.vertices)}, 面: {len(mesh.faces)}")
    return str(obj_path)


def batch_reconstruct(model, image_dir: str, output_dir: str):
    """批量处理目录中的图像"""
    image_dir = Path(image_dir)
    for img_path in sorted(image_dir.glob("*")):
        if img_path.suffix.lower() not in (".jpg", ".jpeg", ".png"):
            continue
        print(f"处理: {img_path.name}")
        try:
            image = remove_background(str(img_path))
            reconstruct_3d(model, image, output_dir=f"{output_dir}/{img_path.stem}")
        except Exception as e:
            print(f"  失败: {e}")


if __name__ == "__main__":
    model = load_triposr()
    image = remove_background("product_photo.jpg")
    reconstruct_3d(model, image)
```

### 二、InstantMesh 多视图重建

```python
"""
InstantMesh 两阶段重建
环境：pip install torch torchvision transformers diffusers trimesh Pillow
      pip install git+https://github.com/TencentARC/InstantMesh.git
"""

import torch
from PIL import Image
from pathlib import Path


def load_instantmesh(device: str = "cuda:0"):
    """加载 InstantMesh 的多视图生成器和重建器"""
    from instantmesh.utils.infer_utils import load_model
    mv_generator = load_model("multiview_diffusion", pretrained_path="TencentARC/InstantMesh", device=device)
    reconstructor = load_model("sparse_reconstructor", pretrained_path="TencentARC/InstantMesh", device=device)
    return mv_generator, reconstructor


def reconstruct_with_instantmesh(mv_generator, reconstructor, image_path: str, output_dir: str = "output_im"):
    """InstantMesh 两阶段重建：单图 → 多视图 → 3D 网格"""
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    image = Image.open(image_path).convert("RGB").resize((320, 320))

    # 阶段一：生成 6 个正交视角
    print("阶段一：多视图生成...")
    camera_poses = [(0,0,1.5), (0,90,1.5), (0,180,1.5), (0,270,1.5), (90,0,1.5), (-90,0,1.5)]
    with torch.no_grad():
        multiview_images = mv_generator.generate(image, camera_poses=camera_poses, num_inference_steps=75)

    for i, img in enumerate(multiview_images):
        img.save(str(output_path / f"view_{i}.png"))

    # 阶段二：从多视图重建
    print("阶段二：3D 重建...")
    with torch.no_grad():
        mesh = reconstructor.reconstruct(multiview_images, camera_poses, resolution=256)

    mesh.export(str(output_path / "model.glb"), file_type="glb")
    print(f"完成: {len(mesh.vertices)} 顶点, {len(mesh.faces)} 面")
    return str(output_path / "model.glb")


if __name__ == "__main__":
    mv_gen, recon = load_instantmesh()
    reconstruct_with_instantmesh(mv_gen, recon, "product_photo.jpg")
```

### 四、质量评估脚本

```python
"""3D 重建质量评估：Chamfer Distance 和 F-score"""
import numpy as np
import trimesh
from scipy.spatial import cKDTree


def chamfer_distance(points_a: np.ndarray, points_b: np.ndarray) -> float:
    """CD = mean(min dist A→B) + mean(min dist B→A)"""
    tree_b = cKDTree(points_b)
    tree_a = cKDTree(points_a)
    return float(np.mean(tree_b.query(points_a, k=1)[0]) + np.mean(tree_a.query(points_b, k=1)[0]))


def f_score(points_pred: np.ndarray, points_gt: np.ndarray, threshold: float = 0.01) -> dict:
    """F-score = 2·Precision·Recall / (Precision+Recall)"""
    tree_gt = cKDTree(points_gt)
    tree_pred = cKDTree(points_pred)
    precision = float(np.mean(tree_gt.query(points_pred, k=1)[0] < threshold))
    recall = float(np.mean(tree_pred.query(points_gt, k=1)[0] < threshold))
    f = 2 * precision * recall / (precision + recall) if precision + recall > 0 else 0.0
    return {"precision": precision, "recall": recall, "f_score": f}


def evaluate(pred_path: str, gt_path: str, n_samples: int = 10000):
    """评估重建质量"""
    pts_pred, _ = trimesh.sample.sample_surface(trimesh.load(pred_path, force="mesh"), n_samples)
    pts_gt, _ = trimesh.sample.sample_surface(trimesh.load(gt_path, force="mesh"), n_samples)

    # 归一化到单位球
    normalize = lambda pts: (pts - pts.mean(0)) / np.max(np.linalg.norm(pts - pts.mean(0), axis=1))
    pts_pred, pts_gt = normalize(pts_pred), normalize(pts_gt)

    cd = chamfer_distance(pts_pred, pts_gt)
    fs = f_score(pts_pred, pts_gt, 0.01)
    print(f"Chamfer Distance: {cd:.6f}")
    print(f"F-score (τ=0.01): {fs['f_score']:.4f} (P={fs['precision']:.4f}, R={fs['recall']:.4f})")
    return {"cd": cd, "f_score": fs}
```

## 常见误区

### 1. 期望单图重建能完美还原背面

**误区：** "给一张正面照片，背面也应该完美生成。"

**纠正：** 单图重建的背面是模型基于先验"推测"的。对称物体（椅子、杯子）推测较准；非对称物体（背包、人脸）背面会有明显偏差。建议：提供前后两张照片；或用 InstantMesh 提高背面质量。

### 2. 忽视输入图像质量的影响

**误区：** "随便拍张照片就能生成高质量 3D 模型。"

**纠正：** 复杂背景、过曝/过暗、严重遮挡、低分辨率都会显著降低重建质量。最佳实践：白底/纯色背景、均匀光照、物体占画面 70%+、分辨率至少 512×512。

### 3. 混淆速度和质量的取舍

**误区：** "TripoSR 比 InstantMesh 快 60 倍，质量应该也差不多。"

**纠正：** TripoSR 前馈速度快但对复杂几何建模能力有限；InstantMesh 两阶段方法信息更多，质量更高。实时交互用 TripoSR，离线生产用 InstantMesh。

### 4. 忽略输出网格的后处理

**误区：** "模型导出后就能直接用。"

**纠正：** AI 生成的网格通常需要：减面（面数可能过多）、法线修复、UV 重映射、非流形几何清理。建议用 trimesh 或 Blender 自动化后处理。

### 5. 不考虑模型许可证

**误区：** "开源模型生成的 3D 资产可以随意商用。"

**纠正：** TripoSR 用 MIT 许可证，商用友好。InstantMesh 依赖 SD，需注意 Stability AI 许可。Wonder3D 可能限制商用。商业项目务必逐个检查许可证。

## 小结

本课系统讲解了图像驱动 3D 重建的技术演进和实战方法：

- **技术路线**：从 MVS 到多视图生成+重建（InstantMesh、Wonder3D），再到前馈重建（TripoSR）
- **核心架构**：Triplane 表示 + Transformer 解码是当前主流范式
- **工程实践**：输入图像质量至关重要，输出网格需要后处理，选型要根据速度/质量权衡
- **评估指标**：Chamfer Distance 衡量整体几何误差，F-score 衡量局部精度，LPIPS 衡量视觉感知质量

## 练习

### 练习一：TripoSR 不同分辨率基准测试

**题目**：用 TripoSR 在 mc_resolution = 128、256、384、512 四个参数下生成 3D 模型，记录每个分辨率的推理时间和输出面数，绘制分辨率-时间、分辨率-面数的关系图。

**思路**：遍历分辨率列表，每轮调用 `model.extract_mesh()` 并用 `time.time()` 计时。

**答案**：

```python
import time
import matplotlib.pyplot as plt

def benchmark_resolutions(model, image, resolutions=[128, 256, 384, 512]):
    results = []
    for res in resolutions:
        start = time.time()
        with torch.no_grad():
            scene_codes = model([image], device=model.device)
            meshes = model.extract_mesh(scene_codes, resolution=res, threshold=25.0)
        elapsed = time.time() - start
        mesh = meshes[0]
        results.append({"resolution": res, "time": elapsed, "faces": len(mesh.faces)})
        print(f"分辨率={res}: {elapsed:.2f}s, 面={len(mesh.faces)}")

    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
    ax1.plot([r["resolution"] for r in results], [r["time"] for r in results], "o-")
    ax1.set_xlabel("MC 分辨率"); ax1.set_ylabel("时间 (s)"); ax1.set_title("分辨率 vs 时间")
    ax2.plot([r["resolution"] for r in results], [r["faces"] for r in results], "o-")
    ax2.set_xlabel("MC 分辨率"); ax2.set_ylabel("面数"); ax2.set_title("分辨率 vs 面数")
    plt.tight_layout(); plt.savefig("benchmark.png", dpi=150)
```

**要点**：分辨率 128→512，面数从几千增长到数十万；时间接近线性增长；推荐 256 作为默认值。

### 练习二：多视图一致性检查

**题目**：编写函数检查 InstantMesh 生成的 6 个视图之间的一致性——计算相邻视图重叠区域的 SSIM，值越接近 1 一致性越好。

**思路**：取相邻视图的重叠半区，用 SSIM 比较。视图顺序：前(0)→右(1)→后(2)→左(3)。

**答案**：

```python
import numpy as np
from PIL import Image

def check_consistency(view_dir: str, n_views: int = 6):
    from scipy.ndimage import uniform_filter
    images = [np.array(Image.open(f"{view_dir}/view_{i}.png")) for i in range(n_views)]

    def ssim(a, b):
        C1, C2 = (0.01*255)**2, (0.03*255)**2
        mu_a, mu_b = uniform_filter(a.astype(float), 11), uniform_filter(b.astype(float), 11)
        s_ab = uniform_filter(a.astype(float)*b.astype(float), 11) - mu_a*mu_b
        s_a2 = uniform_filter(a.astype(float)**2, 11) - mu_a**2
        s_b2 = uniform_filter(b.astype(float)**2, 11) - mu_b**2
        return float(np.mean(((2*mu_a*mu_b+C1)*(2*s_ab+C2)) / ((mu_a**2+mu_b**2+C1)*(s_a2+s_b2+C2))))

    pairs = [(0,1), (1,2), (2,3), (3,0)]
    scores = []
    for i, j in pairs:
        h, w = images[i].shape[:2]
        s = ssim(images[i][:, w//2:, :], images[j][:, :w//2, :])
        scores.append(s)
        print(f"视图 {i}→{j} SSIM: {s:.4f}")
    print(f"平均 SSIM: {np.mean(scores):.4f} (>0.7 较好)")
```

**要点**：SSIM > 0.7 表示一致性好；低于 0.5 说明扩散模型在不同视角产生了不同"幻觉"，可降低 guidance scale 改善。

### 练习三：TripoSR + FastAPI Web 服务

**题目**：构建一个最小化的 FastAPI 服务：POST /api/generate 接收图片，调用 TripoSR 生成 3D 模型，返回 glTF URL。GET /preview/{task_id} 返回 Three.js 预览页面。

**思路**：FastAPI 提供上传接口；后台同步调用 TripoSR；静态文件服务提供 glTF；HTML 内嵌 Three.js。

**答案**：

_model = None
def get_model():
    global _model
    if _model is None:
        from tsr.system import TSR
        _model = TSR.from_pretrained("stabilityai/TripoSR", config_name="config.yaml", weight_name="model.ckpt")
        _model.renderer.set_chunk_size(8192); _model.to("cuda"); _model.eval()

@app.post("/api/generate")
async def generate(file: UploadFile = File(...)):
    import torch, rembg
    from PIL import Image
    data = await file.read()

    model = get_model()

        meshes = model.extract_mesh(codes, resolution=256, threshold=25.0)
