# 3D生成技术全景

一个中等复杂度的游戏角色模型，从零到可用，资深美术师需要40-80小时。开放世界游戏动辄需要上千个这样的资产。AI驱动的3D生成技术正在改变这个局面——TripoSR能在0.5秒内从一张图片生成3D Mesh，3D Gaussian Splatting能从手机照片实时重建场景。

本课建立3D生成技术的全局认知：有哪些表示方法、哪些技术路线、各自适合什么场景。

## 3D表示方法：六种选择，没有银弹

3D生成的第一个问题是：怎么在计算机里表示一个物体？不同的表示方法直接决定了生成算法的设计、输出质量和应用范围。

**Mesh**是游戏和动画的标准。顶点+三角面，文件小，渲染高效，所有引擎原生支持。问题是拓扑结构固定，生成时需要处理拓扑一致性。

**Point Cloud**是离散点集，结构简单，从激光扫描直接获取。但无法直接渲染为连续表面，通常只作为中间表示。

**Voxel**是3D像素，结构规则便于卷积操作。但分辨率提高时内存呈立方增长，表面不光滑，目前主要用于医学影像。

**Implicit Surface**用连续函数定义表面，分辨率无关，表面光滑，适合神经网络学习。需要Marching Cubes提取表面，不直接兼容传统渲染管线。

**NeRF**用神经网络将5D输入映射到颜色和密度，照片级真实感，但训练慢（小时级）、渲染慢（秒级）。适合离线场景重建。

**3D Gaussian Splatting**用数百万个高斯椭球表示场景，实时渲染100+FPS，训练快（分钟级），质量接近NeRF。2024年后成为实时3D的主流方案。

```
表示方法选择：

需要游戏引擎兼容？ → Mesh
需要实时渲染？     → 3DGS
需要极致画质？     → NeRF
需要神经网络学习？ → Implicit Surface
处理激光扫描数据？ → Point Cloud
```

## 两条技术路线

**基于优化**：对每个场景单独训练模型。NeRF是典型代表，需要多视角图像输入，训练时间长，但质量高。适合"拍一次，用多次"的场景。

**前馈生成**：训练一个通用模型，输入图像或文本后直接输出3D表示。TripoSR、InstantMesh是代表，秒级生成，适合批量生产。

```
基于优化：多视角图像 → [每个场景训练] → 高质量3D（分钟~小时）
前馈生成：单张图像   → [通用模型推理] → 3D（秒级）
```

输入模态也有区分：文本驱动（Shap-E、GaussianDreamer）、单图重建（TripoSR、InstantMesh）、多视图重建（NeRF/3DGS+COLMAP）、视频驱动（4D-GS）。

## 2024-2025关键节点

- **3D Gaussian Splatting**（2023.6）：实时渲染100+FPS，训练比NeRF快10-100倍
- **TripoSR**（2024.3）：单图0.5秒生成高质量Mesh
- **InstantMesh**（2024.4）：多视图扩散+Transformer重建，质量大幅提升
- **Trellis**（2024.9）：微软，统一latent表示，可解码为Mesh/NeRF/3DGS
- **Hunyuan3D 2.0**（2025.2）：腾讯，生成质量达到商业可用

## 选型决策

```
需要最高质量？ → 多视图拍摄 → NeRF/3DGS → 人工精修
需要快速生成？ → 有图片？TripoSR/InstantMesh → 只有文本？Shap-E/GaussianDreamer
需要实时渲染？ → 3DGS → WebGL/WebGPU
需要可编辑？   → 前馈生成Mesh → Blender编辑
```

电商Web展示推荐：前馈生成Mesh + glTF + Three.js。原因：手机浏览器兼容最好，单GPU可处理数百个/小时，glTF是Web端标准格式。

## 代码：Three.js加载glTF模型

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>3D模型查看器</title>
  <style>
    * { margin: 0; padding: 0; }
    body { overflow: hidden; background: #1a1a2e; }
    #info { position: absolute; top: 16px; left: 16px; background: rgba(0,0,0,0.75);
            color: #e0e0e0; padding: 12px 16px; border-radius: 8px; font-size: 13px; }
    #info h3 { color: #4fc3f7; margin-bottom: 4px; }
  </style>
</head>
<body>
  <div id="info">
    <h3>3D模型查看器</h3>
    <div id="stats">加载中...</div>
  </div>
  <script type="importmap">
    { "imports": {
        "three": "https://unpkg.com/three@0.164.1/build/three.module.js",
        "three/addons/": "https://unpkg.com/three@0.164.1/examples/jsm/"
    }}
  </script>
  <script type="module">
    import * as THREE from 'three';
    import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
    import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

    const scene = new THREE.Scene();
    scene.background = new THREE.Color(0x1a1a2e);
    const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.01, 1000);
    camera.position.set(3, 2, 5);
    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(innerWidth, innerHeight);
    renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
    renderer.toneMapping = THREE.ACESFilmicToneMapping;
    document.body.appendChild(renderer.domElement);

    const controls = new OrbitControls(camera, renderer.domElement);
    controls.enableDamping = true;

    scene.add(new THREE.AmbientLight(0x404060, 0.8));
    const mainLight = new THREE.DirectionalLight(0xffffff, 2.5);
    mainLight.position.set(5, 8, 5);
    scene.add(mainLight);
    scene.add(new THREE.DirectionalLight(0x4fc3f7, 0.8).position.set(-5, 3, -5));

    new GLTFLoader().load(
      'https://threejs.org/examples/models/gltf/DamagedHelmet/glTF/DamagedHelmet.gltf',
      (gltf) => {
        const model = gltf.scene;
        const box = new THREE.Box3().setFromObject(model);
        const center = box.getCenter(new THREE.Vector3());
        const size = box.getSize(new THREE.Vector3());
        const scale = 3 / Math.max(size.x, size.y, size.z);
        model.scale.setScalar(scale);
        model.position.sub(center.multiplyScalar(scale));
        scene.add(model);

        let verts = 0, tris = 0;
        model.traverse(c => {
          if (c.isMesh) { verts += c.geometry.attributes.position.count; tris += c.geometry.index ? c.geometry.index.count / 3 : 0; }
        });
        document.getElementById('stats').textContent = `顶点: ${verts.toLocaleString()} | 面: ${Math.floor(tris).toLocaleString()}`;
      }
    );

    window.addEventListener('resize', () => {
      camera.aspect = innerWidth / innerHeight;
      camera.updateProjectionMatrix();
      renderer.setSize(innerWidth, innerHeight);
    });
    (function animate() { requestAnimationFrame(animate); controls.update(); renderer.render(scene, camera); })();
  </script>
</body>
</html>
```

保存为HTML直接在浏览器打开。替换`MODEL_URL`为自己的glTF/GLB文件即可。

## 参考答案

### 练习一

推荐：前馈生成Mesh + glTF + Three.js。

- 生成：TripoSR或InstantMesh，单图→3D Mesh，秒级，单GPU数百个/小时
- 格式：glTF，手机浏览器兼容性最好
- 渲染：Three.js，Web端原生
- 优化：自动减面到5万以内，Draco压缩，CDN分发
- 人工介入：5-10%效果不佳需审核，高端商品需精修材质

不用NeRF（无法实时渲染）和3DGS（内存大、浏览器支持有限）。

### 练习二
