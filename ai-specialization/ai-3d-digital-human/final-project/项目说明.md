# 毕业项目：数字人直播系统

## 项目概述

构建一个完整的数字人直播系统，支持从照片生成 3D 数字人、语音驱动面部动画、实时对话互动、RTMP 直播推流。

## 核心功能

### 1. 数字人形象生成
- 上传正面照片，生成 3D 人脸模型
- 支持多种风格：写实、卡通、商务
- Blendshape 参数可调：表情、年龄、妆容

### 2. 实时面部驱动
- 音频驱动口型同步，延迟 < 200ms
- 表情自然：眨眼、点头、微笑
- 支持预设表情和自定义表情

### 3. 语音合成与克隆
- 接入 CosyVoice / GPT-SoVITS
- 支持 5 分钟声音样本克隆
- 实时流式合成，首包延迟 < 500ms

### 4. 对话系统
- 接入 LLM（GPT-4 / Claude / 国产模型）
- 支持商品知识库问答（RAG）
- 多轮对话记忆
- 话术模板与自动切换

### 5. 直播推流
- RTMP 推流到抖音/快手/B站
- 支持多平台同时推流
- 画面合成：数字人 + 背景 + 商品展示

### 6. 弹幕互动
- 实时读取直播间弹幕
- 智能筛选：过滤无关弹幕，识别问题
- 自动回复 + 人工接管

### 7. 运营后台
- 直播数据统计：观看人数、互动率、转化率
- 话术管理：预设话术、AI 自动生成
- 商品管理：商品信息、讲解话术、展示顺序
- 定时直播：预约直播、自动开播
