# 第 27 课：设计系统集成 — 让 AI 生成无缝融入设计师工作流

## 场景引入

你是一家互联网公司的前端工程师，设计师小王最近在尝试用 AI 生成图像素材。他用 ComfyUI 生成了一批不错的产品场景图，但问题来了：这些图怎么放进 Figma？

小王的做法是：先把 AI 生成的图下载到本地，然后手动拖进 Figma，调整位置、对齐网格、检查是否符合设计规范。如果有修改意见，他需要回到 ComfyUI 重新生成，再下载、再拖入、再调整。一个设计稿改了 5 轮，每轮都要重复这套流程。

更深层的问题是：AI 生成的图像和设计师的设计系统是割裂的。设计师有一套完整的 design token（色彩、间距、字体、圆角），AI 生成的图完全不感知这些规范。生成的图可能用了品牌的旧色号、不匹配设计系统的圆角风格、或者尺寸不符合组件规范。

本课要解决的核心问题是：如何让 AI 图像生成工具与设计系统（Figma / Design Token）深度集成，实现"设计师在 Figma 里点一下按钮，AI 自动生成符合品牌规范的图像并插入设计稿"。

## 一、Design Token 与品牌规范

### 1.1 Design Token 体系

Design Token 是设计系统的原子级变量——颜色、间距、字号、圆角、阴影等。它把设计师的视觉决策转化为程序可消费的数据结构。AI 生成图像时，如果能读取这些 Token，就能在生成阶段就对齐品牌规范，而不是事后校验。

```
Design Token 层级结构：

  Global Tokens          Alias Tokens           Component Tokens
  ─────────────          ────────────           ────────────────
  color-blue-500  ─────▶ color-primary    ─────▶ button-bg-primary
  color-gray-100  ─────▶ color-bg-subtle  ─────▶ card-background
  spacing-4       ─────▶ spacing-sm       ─────▶ input-padding-x
  radius-8        ─────▶ radius-md        ─────▶ dialog-border-radius
  font-size-16    ─────▶ text-body        ─────▶ label-font-size

  Global: 原始值（#3B82F6, 16px）
  Alias: 语义化命名（primary, subtle, sm）
  Component: 组件级绑定（button-bg, card-bg）
```

## 二、AI 生成结果的品牌一致性校验

### 2.1 校验流程

AI 生成图像后，需要自动检查它是否符合品牌规范。校验不是简单的"颜色对不对"，而是一个多维度的检查流程。

```
品牌一致性校验流程：

  AI 生成图像
       │
       ▼
  ┌─────────────┐
  │ 颜色分析     │──▶ 主色调是否在品牌色板范围内
  │ (色彩直方图) │──▶ 色彩饱和度和明度是否符合调性
  └─────────────┘
       │
       ▼
  ┌─────────────┐
  │ 排版检查     │──▶ 文字区域是否在安全边距内
  │ (OCR + 布局) │──▶ 文字面积占比是否超过平台限制
  └─────────────┘
       │
       ▼
  ┌─────────────┐
  │ 风格一致性   │──▶ 整体风格是否匹配品牌调性
  │ (特征向量)   │──▶ 与历史素材的相似度是否 > 阈值
  └─────────────┘
       │
       ▼
  ┌─────────────┐
  │ 综合评分     │──▶ 加权得分，低于阈值则标记为"需人工审核"
  └─────────────┘
```

### 2.2 品牌一致性校验器

```python
import numpy as np
from PIL import Image, ImageStat
from collections import Counter


@dataclass
class BrandCheckResult:
    dimension: str
    score: float
    passed: bool
    details: str


@dataclass
class BrandComplianceReport:
    image_path: str
    overall_score: float
    passed: bool
    checks: list[BrandCheckResult]
    recommendations: list[str]


class BrandComplianceChecker:
    def __init__(
        self,
        token_set: DesignTokenSet,
        color_tolerance: int = 40,
        min_brightness: int = 50,
        max_brightness: int = 230,
        max_text_ratio: float = 0.25,
    ):
        self.token_set = token_set
        self.color_tolerance = color_tolerance
        self.min_brightness = min_brightness
        self.max_brightness = max_brightness
        self.max_text_ratio = max_text_ratio

        self.brand_colors_rgb = []
        for color_token in token_set.colors.values():
            if color_token.category == "brand":
                self.brand_colors_rgb.append(self._hex_to_rgb(color_token.value))

    def check(self, image_path: str) -> BrandComplianceReport:
        img = Image.open(image_path).convert("RGB")
        checks = []
        recommendations = []

        color_score = self._check_color_alignment(img)
        checks.append(BrandCheckResult(
            dimension="color_alignment",
            score=color_score,
            passed=color_score > 0.6,
            details=f"品牌色对齐度: {color_score:.1%}",
        ))

        brightness_score = self._check_brightness(img)
        checks.append(BrandCheckResult(
            dimension="brightness",
            score=brightness_score,
            passed=brightness_score > 0.7,
            details=f"亮度合理性: {brightness_score:.1%}",
        ))

        contrast_score = self._check_contrast(img)
        checks.append(BrandCheckResult(
            dimension="contrast",
            score=contrast_score,
            passed=contrast_score > 0.5,
            details=f"对比度: {contrast_score:.1%}",
        ))

        harmony_score = self._check_color_harmony(img)
        checks.append(BrandCheckResult(
            dimension="color_harmony",
            score=harmony_score,
            passed=harmony_score > 0.5,
            details=f"色彩和谐度: {harmony_score:.1%}",
        ))

        weights = {
            "color_alignment": 0.35,
            "brightness": 0.2,
            "contrast": 0.2,
            "color_harmony": 0.25,
        }
        overall = sum(
            c.score * weights.get(c.dimension, 0.25) for c in checks
        )

        if overall < 0.6:
            recommendations.append("建议调整主色调，使其更接近品牌色板")
        for check in checks:
            if not check.passed:
                recommendations.append(f"请关注 {check.dimension}: {check.details}")

        return BrandComplianceReport(
            image_path=image_path,
            overall_score=overall,
            passed=overall >= 0.7,
            checks=checks,
            recommendations=recommendations,
        )

    def _check_color_alignment(self, img: Image.Image) -> float:
        small = img.resize((64, 64))
        pixels = np.array(small).reshape(-1, 3)

        if not self.brand_colors_rgb:
            return 1.0

        distances = []
        for pixel in pixels[::16]:
            min_dist = min(
                np.sqrt(sum((int(p) - int(b)) ** 2 for p, b in zip(pixel, bc)))
                for bc in self.brand_colors_rgb
            )
            distances.append(min_dist)

        avg_distance = np.mean(distances)
        max_distance = 441.65
        score = max(0, 1 - avg_distance / max_distance)
        return score

    def _check_brightness(self, img: Image.Image) -> float:
        gray = img.convert("L")
        stat = ImageStat.Stat(gray)
        avg = stat.mean[0]

        if self.min_brightness <= avg <= self.max_brightness:
            return 1.0
        elif avg < self.min_brightness:
            return max(0, avg / self.min_brightness)
        else:
            return max(0, 1 - (avg - self.max_brightness) / (255 - self.max_brightness))

    def _check_contrast(self, img: Image.Image) -> float:
        gray = img.convert("L")
        stat = ImageStat.Stat(gray)
        std_dev = stat.stddev[0]

        if std_dev > 50:
            return 1.0
        elif std_dev > 30:
            return 0.7
        else:
            return max(0, std_dev / 30)

    def _check_color_harmony(self, img: Image.Image) -> float:
        small = img.resize((32, 32))
        pixels = np.array(small).reshape(-1, 3)

        from colorsys import rgb_to_hsv
        hues = []
        for pixel in pixels[::8]:
            h, s, v = rgb_to_hsv(pixel[0] / 255, pixel[1] / 255, pixel[2] / 255)
            if s > 0.1 and v > 0.1:
                hues.append(h * 360)

        if len(hues) < 10:
            return 0.5

        hue_std = np.std(hues)
        if hue_std < 60:
            return 0.9
        elif hue_std < 120:
            return 0.7
        else:
            return 0.4

    @staticmethod
    def _hex_to_rgb(hex_color: str) -> tuple[int, int, int]:
        hex_color = hex_color.lstrip("#")
        return tuple(int(hex_color[i : i + 2], 16) for i in (0, 2, 4))
```

### 3.2 Figma Plugin 核心实现

```typescript
// figma-plugin/src/code.ts
figma.showUI(__html__, { width: 480, height: 640 });

interface DesignToken {
  colors: Record<string, string>;
  spacing: Record<string, number>;
  typography: Record<string, {
    fontFamily: string;
    fontSize: number;
    fontWeight: number;
  }>;
}

interface GenerateRequest {
  prompt: string;
  width: number;
  height: number;
  tokenSet: DesignToken;
  style: string;
}

figma.ui.onmessage = async (msg: {
  type: string;
  payload: GenerateRequest;
}) => {
  switch (msg.type) {
    case "generate-and-insert":
      await handleGenerateAndInsert(msg.payload);
      break;
    case "replace-selected":
      await handleReplaceSelected(msg.payload);
      break;
    case "apply-to-selection":
      await handleApplyToSelection(msg.payload);
      break;
    case "export-tokens":
      await handleExportTokens();
      break;
  }
};

async function handleGenerateAndInsert(request: GenerateRequest) {
  figma.notify("正在生成图像...", { timeout: 30000 });

  const brandPrompt = buildBrandPrompt(request.prompt, request.tokenSet);

  try {
    const response = await fetch("https://api.example.com/generate", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        prompt: brandPrompt,
        negative_prompt: "low quality, blurry, watermark",
        width: request.width,
        height: request.height,
        style: request.style,
      }),
    });

    const result = await response.json();
    const imageBytes = await fetchImageAsBytes(result.image_url);

    const image = figma.createImage(imageBytes);
    const frame = figma.createRectangle();
    frame.resize(request.width, request.height);
    frame.fills = [
      {
        type: "IMAGE",
        imageHash: image.hash,
        scaleMode: "FILL",
      },
    ];

    frame.name = `AI Generated - ${request.prompt.slice(0, 30)}`;
    frame.x = figma.viewport.center.x - request.width / 2;
    frame.y = figma.viewport.center.y - request.height / 2;

    figma.currentPage.appendChild(frame);
    figma.viewport.scrollAndZoomIntoView([frame]);

    figma.notify("图像已插入画布", { timeout: 2000 });
  } catch (error) {
    figma.notify(`生成失败: ${error.message}`, { error: true });
  }
}

function buildBrandPrompt(prompt: string, tokens: DesignToken): string {
  const brandColors = Object.entries(tokens.colors)
    .filter(([_, value]) => value.startsWith("#"))
    .map(([name, value]) => `${name}: ${value}`)
    .join(", ");

  return `${prompt}, brand colors: ${brandColors}, professional, high quality, consistent brand style`;
}

async function handleReplaceSelected(request: GenerateRequest) {
  const selection = figma.currentPage.selection;
  if (selection.length === 0) {
    figma.notify("请先选择一个元素", { error: true });
    return;
  }

  const selectedNode = selection[0];
  if (!("fills" in selectedNode)) {
    figma.notify("请选择支持填充的元素", { error: true });
    return;
  }

  const brandPrompt = buildBrandPrompt(request.prompt, request.tokenSet);
  const response = await fetch("https://api.example.com/generate", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      prompt: brandPrompt,
      width: Math.round(selectedNode.width),
      height: Math.round(selectedNode.height),
      style: request.style,
    }),
  });

  const result = await response.json();
  const imageBytes = await fetchImageAsBytes(result.image_url);
  const image = figma.createImage(imageBytes);

  selectedNode.fills = [
    {
      type: "IMAGE",
      imageHash: image.hash,
      scaleMode: "FILL",
    },
  ];

  figma.notify("图像已替换", { timeout: 2000 });
}

async function handleExportTokens() {
  const colors: Record<string, string> = {};
  const styles = figma.getLocalPaintStyles();

  for (const style of styles) {
    if (style.paints.length > 0) {
      const paint = style.paints[0];
      if (paint.type === "SOLID") {
        const r = Math.round(paint.color.r * 255);
        const g = Math.round(paint.color.g * 255);
        const b = Math.round(paint.color.b * 255);
        colors[style.name] = `#${r.toString(16).padStart(2, "0")}${g
          .toString(16)
          .padStart(2, "0")}${b.toString(16).padStart(2, "0")}`;
      }
    }
  }

  figma.ui.postMessage({
    type: "tokens-exported",
    payload: { colors },
  });
}

async function fetchImageAsBytes(url: string): Promise<Uint8Array> {
  const response = await fetch(url);
  const buffer = await response.arrayBuffer();
  return new Uint8Array(buffer);
}
```

## 四、设计资产的自动化管理

### 4.1 资产版本控制

AI 生成的设计资产需要版本管理。每次生成都记录 prompt、参数、Token 版本，方便回溯和复现。

```python
import hashlib
import json
from datetime import datetime
from pathlib import Path


@dataclass
class DesignAssetVersion:
    asset_id: str
    version: str
    created_at: str
    prompt: str
    parameters: dict
    token_version: str
    image_path: str
    thumbnail_path: str
    metadata: dict = field(default_factory=dict)


class DesignAssetRegistry:
    def __init__(self, registry_dir: str):
        self.registry_dir = Path(registry_dir)
        self.registry_dir.mkdir(parents=True, exist_ok=True)
        self.index_path = self.registry_dir / "index.json"
        self.index = self._load_index()

    def _load_index(self) -> dict:
        if self.index_path.exists():
            with open(self.index_path, "r", encoding="utf-8") as f:
                return json.load(f)
        return {"assets": {}, "version_counter": {}}

    def _save_index(self) -> None:
        with open(self.index_path, "w", encoding="utf-8") as f:
            json.dump(self.index, f, indent=2, ensure_ascii=False)

    def register_asset(
        self,
        image_path: str,
        prompt: str,
        parameters: dict,
        token_version: str,
        asset_name: str | None = None,
    ) -> DesignAssetVersion:
        image_bytes = Path(image_path).read_bytes()
        asset_hash = hashlib.sha256(image_bytes).hexdigest()[:12]

        if asset_name is None:
            asset_name = f"asset_{asset_hash}"

        counter = self.index["version_counter"]
        counter[asset_name] = counter.get(asset_name, 0) + 1
        version = f"v{counter[asset_name]}"

        asset_dir = self.registry_dir / asset_name / version
        asset_dir.mkdir(parents=True, exist_ok=True)

        dest_image = asset_dir / "image.png"
        Path(image_path).rename(dest_image)

        thumbnail = Image.open(dest_image)
        thumbnail.thumbnail((256, 256))
        thumb_path = asset_dir / "thumbnail.png"
        thumbnail.save(thumb_path)

        asset_version = DesignAssetVersion(
            asset_id=asset_name,
            version=version,
            created_at=datetime.now().isoformat(),
            prompt=prompt,
            parameters=parameters,
            token_version=token_version,
            image_path=str(dest_image),
            thumbnail_path=str(thumb_path),
        )

        self.index["assets"][f"{asset_name}/{version}"] = {
            "asset_id": asset_name,
            "version": version,
            "created_at": asset_version.created_at,
            "prompt": prompt,
            "parameters": parameters,
            "token_version": token_version,
            "image_path": str(dest_image),
        }
        self._save_index()

        return asset_version

    def get_asset_history(self, asset_name: str) -> list[dict]:
        history = []
        for key, asset in self.index["assets"].items():
            if asset["asset_id"] == asset_name:
                history.append(asset)
        return sorted(history, key=lambda x: x["version"])

    def rollback_asset(self, asset_name: str, target_version: str) -> str:
        key = f"{asset_name}/{target_version}"
        if key not in self.index["assets"]:
            raise KeyError(f"Version {target_version} not found for {asset_name}")
        return self.index["assets"][key]["image_path"]
```

## 六、常见误区

### 误区一：Design Token 只是给前端用的 CSS 变量

Design Token 的价值不只是前端样式管理，它是连接设计、开发和 AI 生成的桥梁。当 AI 生成器读取 Token 后，生成结果天然对齐品牌规范，省去了大量事后校验和人工修正。把 Token 当作"品牌 DNA 的程序化表达"来管理，而不是"CSS 变量的 JSON 版本"。

### 误区二：Figma Plugin 能替代后端服务

Figma Plugin 运行在浏览器沙箱中，无法直接访问本地 GPU 或大模型。实际架构应该是 Plugin 负责 UI 交互和 Figma 操作，后端服务负责 AI 生成和品牌校验。Plugin 通过 HTTPS 调用后端 API，拿到结果后再插入画布。不要试图把所有逻辑塞进 Plugin。

### 误区三：品牌一致性校验可以完全自动化

当前的颜色分析、对比度检查等技术手段只能覆盖客观维度。品牌调性（"高级感"、"活力"、"专业"）涉及主观审美判断，自动化校验只能作为第一道过滤网，最终还是需要设计师的人工审核。合理的流程是：自动校验过滤 80% 的明显问题，人工审核剩下的 20%。

## 小结

本课从设计系统集成的实际问题出发，构建了一套 AI 图像生成与设计工具深度集成的方案：

1. **Token 驱动**：Design Token 不只是 CSS 变量，而是 AI 生成的品牌约束层。在生成阶段注入 Token 信息，比事后校验更高效
2. **自动校验**：品牌一致性检查覆盖颜色、亮度、对比度、色彩和谐四个维度，用加权评分决定是否需要人工审核
3. **Figma 集成**：Plugin 负责 UI 和画布操作，后端负责 AI 生成，通过 HTTPS 桥接两者
4. **资产版本管理**：每次生成都记录完整的上下文（prompt、参数、Token 版本），支持回溯和复现
5. **MCP 协议**：通过标准化的工具协议，让 AI Agent 可以直接调用设计工具的能力，实现"对话式设计"

这套方案的核心价值是：让 AI 生成从"设计师的辅助工具"变成"设计系统的一部分"，生成结果天然符合品牌规范，不需要额外的人工对齐工作。

### 练习一

**思路**：维护一个 Token 版本的变更日志，每次 Token 更新时比较新旧版本的差异，然后遍历资产索引找出使用了受影响 Token 的资产。

**答案**：

```python
from dataclasses import dataclass


@dataclass
class TokenDiff:
    token_name: str
    token_type: str
    old_value: str
    new_value: str


@dataclass
class MigrationSuggestion:
    asset_id: str
    asset_path: str
    affected_tokens: list[TokenDiff]
    action: str


class TokenDiffDetector:
    def __init__(self, asset_registry: DesignAssetRegistry):
        self.asset_registry = asset_registry

    def detect_diff(
        self,
        old_tokens: DesignTokenSet,
        new_tokens: DesignTokenSet,
    ) -> list[TokenDiff]:
        diffs = []

        for name, new_color in new_tokens.colors.items():
            if name in old_tokens.colors:
                old_color = old_tokens.colors[name]
                if old_color.value != new_color.value:
                    diffs.append(TokenDiff(
                        token_name=name,
                        token_type="color",
                        old_value=old_color.value,
                        new_value=new_color.value,
                    ))

        for name, new_spacing in new_tokens.spacing.items():
            if name in old_tokens.spacing:
                old_spacing = old_tokens.spacing[name]
                if old_spacing.value != new_spacing.value:
                    diffs.append(TokenDiff(
                        token_name=name,
                        token_type="spacing",
                        old_value=str(old_spacing.value),
                        new_value=str(new_spacing.value),
                    ))

        return diffs

    def find_affected_assets(
        self, diffs: list[TokenDiff]
    ) -> list[MigrationSuggestion]:
        suggestions = []
        diff_token_names = {d.token_name for d in diffs}

        for key, asset in self.asset_registry.index["assets"].items():
            if asset.get("token_version") == self.asset_registry.index.get(
                "current_token_version"
            ):
                continue

            affected = [
                d for d in diffs
                if d.token_name in str(asset.get("parameters", {}))
            ]

            if affected:
                suggestions.append(MigrationSuggestion(
                    asset_id=asset["asset_id"],
                    asset_path=asset["image_path"],
                    affected_tokens=affected,
                    action="regenerate",
                ))

        return suggestions
```

**要点**：
- Token Diff 不仅比较值，还要记录类型（颜色、间距等），不同类型有不同的迁移策略
- 受影响资产的匹配可以通过检查生成参数中的 Token 引用来实现
- 迁移建议应该包含具体的变更内容，方便设计师决策是否需要重新生成

**思路**：通过 Figma Plugin API 的 `figma.getLocalPaintStyles()` 和 `figma.getLocalTextStyles()` 读取文件中定义的样式，转换为标准 Token JSON 格式后导出。

```typescript

async function extractTokensFromFigma() {
  const colors: Record<string, { value: string; category: string }> = {};
  const paintStyles = figma.getLocalPaintStyles();

  for (const style of paintStyles) {
    if (style.paints.length > 0) {
      const paint = style.paints[0];
      if (paint.type === "SOLID") {
        const hex = rgbToHex(paint.color.r, paint.color.g, paint.color.b);
        const category = guessCategoryFromName(style.name);
        colors[style.name] = { value: hex, category };
      }
    }
  }

  const typography: Array<{
    name: string;
    fontFamily: string;
    fontSize: number;
    fontWeight: number;
  }> = [];
  const textStyles = figma.getLocalTextStyles();

  for (const style of textStyles) {
    typography.push({
      name: style.name,
      fontFamily: style.fontName.family,
      fontSize: style.fontSize,
      fontWeight: style.fontName.style === "Bold" ? 700 : 400,
    });
  }

  return {
    brand: figma.root.name,
    version: new Date().toISOString().split("T")[0],
    colors: Object.entries(colors).map(([name, data]) => ({
      name,
      value: data.value,
      category: data.category,
    })),
    typography,
    spacing: [
      { name: "xs", value: 4 },
      { name: "sm", value: 8 },
      { name: "md", value: 16 },
      { name: "lg", value: 24 },
      { name: "xl", value: 32 },
    ],
  };
}

function rgbToHex(r: number, g: number, b: number): string {
  const toHex = (n: number) =>
    Math.round(n * 255)
      .toString(16)
      .padStart(2, "0");
  return `#${toHex(r)}${toHex(g)}${toHex(b)}`;
}

function guessCategoryFromName(name: string): string {
  const lower = name.toLowerCase();
  if (lower.includes("primary") || lower.includes("brand")) return "brand";
  if (lower.includes("text") || lower.includes("content")) return "text";
  if (lower.includes("bg") || lower.includes("background")) return "neutral";
  if (lower.includes("error") || lower.includes("success")) return "feedback";
  return "general";
}
```

**要点**：
- Figma 的 PaintStyle 和 TextStyle 分别对应颜色和排版 Token
- 样式名称的命名约定可以用来自动推断 Token 的分类
- 导出的 JSON 可以直接被后端的 DesignTokenLoader 加载

### 练习三

**思路**：对每张图像提取颜色直方图、构图特征（主体位置、留白比例）和场景分类，将这些特征编码为标签存储在资产索引中。

**答案**：

```python
from PIL import Image
import numpy as np


@dataclass
class AssetTag:
    tag_type: str
    value: str
    confidence: float


class AutoTagger:
    def __init__(self):
        self.color_names = {
            "red": (220, 50, 50),
            "blue": (50, 100, 220),
            "green": (50, 180, 80),
            "yellow": (240, 200, 50),
            "purple": (140, 60, 200),
            "orange": (240, 140, 40),
            "black": (30, 30, 30),
            "white": (240, 240, 240),
            "gray": (140, 140, 140),
        }

    def tag_image(self, image_path: str) -> list[AssetTag]:
        img = Image.open(image_path).convert("RGB")
        tags = []

        color_tags = self._extract_color_tags(img)
        tags.extend(color_tags)

        composition_tags = self._extract_composition_tags(img)
        tags.extend(composition_tags)

        brightness_tags = self._extract_brightness_tags(img)
        tags.extend(brightness_tags)

        return tags

    def _extract_color_tags(self, img: Image.Image) -> list[AssetTag]:
        small = img.resize((32, 32))
        pixels = np.array(small).reshape(-1, 3)
        avg_color = pixels.mean(axis=0)

        tags = []
        for name, ref_color in self.color_names.items():
            distance = np.sqrt(sum((int(a) - int(r)) ** 2 for a, r in zip(avg_color, ref_color)))
            if distance < 100:
                confidence = max(0, 1 - distance / 100)
                tags.append(AssetTag(
                    tag_type="dominant_color",
                    value=name,
                    confidence=round(confidence, 2),
                ))

        tags.sort(key=lambda t: t.confidence, reverse=True)
        return tags[:3]

    def _extract_composition_tags(self, img: Image.Image) -> list[AssetTag]:
        gray = np.array(img.convert("L"))
        h, w = gray.shape

        center_region = gray[h // 4 : 3 * h // 4, w // 4 : 3 * w // 4]
        center_brightness = center_region.mean()
        edge_brightness = gray.mean()

        tags = []
        if abs(center_brightness - edge_brightness) > 30:
            if center_brightness > edge_brightness:
                tags.append(AssetTag("composition", "centered-focus", 0.7))
            else:
                tags.append(AssetTag("composition", "vignette", 0.6))
        else:
            tags.append(AssetTag("composition", "even-distribution", 0.8))

        top_half = gray[: h // 2, :].mean()
        bottom_half = gray[h // 2 :, :].mean()
        if abs(top_half - bottom_half) > 20:
            tags.append(AssetTag("composition", "split-layout", 0.6))

        return tags

    def _extract_brightness_tags(self, img: Image.Image) -> list[AssetTag]:
        gray = img.convert("L")
        avg_brightness = np.array(gray).mean()

        if avg_brightness < 80:
            return [AssetTag("mood", "dark", 0.8)]
        elif avg_brightness > 200:
            return [AssetTag("mood", "bright", 0.8)]
        else:
            return [AssetTag("mood", "balanced", 0.9)]
```

**要点**：
- 自动标签覆盖颜色、构图、亮度三个维度，后续可以扩展场景识别
- 置信度用于过滤低质量标签，低于 0.5 的标签不入库
- 标签存储在资产索引中，支持按标签组合进行语义搜索
