## 三、SDXL 双阶段工作流

### 3.1 Base + Refiner 架构

```
SDXL 双阶段工作流：

  ┌─────────────────┐     ┌─────────────────┐
  │  SDXL Base      │     │  SDXL Refiner   │
  │  (粗粒度生成)    │     │  (细节精修)      │
  ├─────────────────┤     ├─────────────────┤
  │ steps: 0→0.8    │────→│ steps: 0.8→1.0  │
  │ 生成整体构图     │     │ 添加精细纹理     │
  │ 风格和色调       │     │ 锐化细节         │
  └─────────────────┘     └─────────────────┘

  Base 负责：整体构图、色调、风格
  Refiner 负责：细节纹理、锐度、最终质量
```

## 四、批量生成与种子管理

### 4.1 批量生成配置

```python
def create_batch_workflow(base_workflow, seeds, prompts):
    """
    批量生成工作流

    策略：
    1. 固定种子变 prompt：对比不同 prompt 的效果
    2. 固定 prompt 变种子：探索同一 prompt 的多样性
    3. 组合遍历：prompt × seed 矩阵
    """
    batch_workflow = {}

    # 共享加载器（只加载一次模型）
    batch_workflow["loader"] = base_workflow["1"]  # CheckpointLoader

    node_id = 100  # 从 100 开始避免冲突

    for i, (prompt, seed) in enumerate(zip(prompts, seeds)):
        # 正向条件
        batch_workflow[str(node_id)] = {
            "class_type": "CLIPTextEncode",
            "inputs": {"text": prompt, "clip": ["loader", 1]}
        }
        pos_id = node_id
        node_id += 1

        # 采样
        batch_workflow[str(node_id)] = {
            "class_type": "KSampler",
            "inputs": {
                "model": ["loader", 0],
                "positive": [str(pos_id), 0],
                "negative": ["loader", 1],  # 共享负向条件
                "latent_image": ["loader", 0],  # 需要 EmptyLatentImage
                "seed": seed,
                "steps": 20,
                "cfg": 7.0,
                "sampler_name": "dpmpp_2m",
                "scheduler": "karras",
                "denoise": 1.0
            }
        }
        sampler_id = node_id
        node_id += 1

        # 解码
        batch_workflow[str(node_id)] = {
            "class_type": "VAEDecode",
            "inputs": {
                "samples": [str(sampler_id), 0],
                "vae": ["loader", 2]
            }
        }
        decode_id = node_id
        node_id += 1

        # 保存（不同前缀区分批次）
        batch_workflow[str(node_id)] = {
            "class_type": "SaveImage",
            "inputs": {
                "images": [str(decode_id), 0],
                "filename_prefix": f"batch_{i:03d}"
            }
        }
        node_id += 1

    return batch_workflow
```

### 4.2 种子管理策略

```python
class SeedManager:
    """种子管理器：控制生成的随机性和可复现性"""

    def __init__(self, base_seed=42):
        self.base_seed = base_seed
        self.current_seed = base_seed

    def fixed(self):
        """固定种子：每次使用相同值（可复现）"""
        return self.base_seed

    def increment(self, step=1):
        """递增种子：每次加 1"""
        self.current_seed += step
        return self.current_seed

    def random(self):
        """随机种子：完全随机"""
        import random
        return random.randint(0, 2**32 - 1)

    def grid(self, rows, cols):
        """网格种子：用于生成种子矩阵"""
        return [self.base_seed + r * cols + c for r in range(rows) for c in range(cols)]

    def batch(self, count):
        """批量种子：生成一批不同的种子"""
        return [self.base_seed + i for i in range(count)]

# 使用示例
sm = SeedManager(base_seed=1000)

# 探索同一 prompt 的多样性
seeds = sm.batch(9)  # [1000, 1001, ..., 1008]
print(f"9 宫格种子: {seeds}")
```

## 七、常见误区

### 误区一：SDXL 只是 SD 1.5 的高清版

SDXL 有完全不同的架构——双 Text Encoder、更大的 U-Net、Refiner 阶段。直接把 SD 1.5 的 prompt 和参数用在 SDXL 上效果会很差。

### 误区二：denoise 只用于图生图

denoise=1.0 是文生图的标准值，但 denoise<1.0 可以用于"半文生图"——在已有潜变量（如 ControlNet 输出）的基础上做部分去噪。

### 误区三：负提示词越多越好

负提示词超过 30-50 token 后效果递减。过多的负描述可能"反向激活"——模型为了"远离"某个概念，反而把它生成出来。

### 误区四：固定 seed 就能完全复现

相同 seed + 相同 prompt + 相同模型 + 相同参数 = 相同结果。但如果任何一个环节变化（包括 ComfyUI 版本更新），结果都可能不同。

## 八、小结

1. **最小工作流只需 6 个节点**：CheckpointLoader → CLIPTextEncode ×2 → EmptyLatentImage → KSampler → VAEDecode → SaveImage
2. **SDXL 使用 Base + Refiner 双阶段**，Refiner 的 denoise 通常设为 0.2-0.3
3. **种子管理**是批量生产的基础——固定种子可复现，随机种子探索多样性
4. **Prompt 模板**提高工作效率，确保一致性
5. **调试的关键**是添加中间预览节点，逐步验证数据流

**答案**：

```python
import json
import random

def seed_grid_experiment(prompt, base_seed=1000, grid_size=3):
    """种子网格实验：生成 3×3 的种子矩阵"""
    workflow = {}

    # 共享模型加载
    workflow["1"] = {
        "class_type": "CheckpointLoaderSimple",
        "inputs": {"ckpt_name": "v1-5-pruned-emaonly.safetensors"}
    }

    # 共享正向条件
    workflow["2"] = {
        "class_type": "CLIPTextEncode",
        "inputs": {"text": prompt, "clip": ["1", 1]}
    }

    # 共享负向条件
    workflow["3"] = {
        "class_type": "CLIPTextEncode",
        "inputs": {
            "text": "low quality, blurry, distorted",
            "clip": ["1", 1]
        }
    }

    # 共享空潜变量（batch=9）
    workflow["4"] = {
        "class_type": "EmptyLatentImage",
        "inputs": {"width": 512, "height": 512, "batch_size": grid_size ** 2}
    }

    # 使用同一个 KSampler，batch 处理所有种子
    # 注意：batch 模式下所有图像共享同一个种子
    # 如果需要不同种子，需要分开采样
    node_id = 10
    seeds = [base_seed + i for i in range(grid_size ** 2)]

    for i, seed in enumerate(seeds):
        # 每个种子独立采样
        latent_id = str(node_id)
        workflow[latent_id] = {
            "class_type": "EmptyLatentImage",
            "inputs": {"width": 512, "height": 512, "batch_size": 1}
        }

        sampler_id = str(node_id + 1)
        workflow[sampler_id] = {
            "class_type": "KSampler",
            "inputs": {
                "model": ["1", 0],
                "positive": ["2", 0],
                "negative": ["3", 0],
                "latent_image": [latent_id, 0],
                "seed": seed,
                "steps": 20,
                "cfg": 7.0,
                "sampler_name": "dpmpp_2m",
                "scheduler": "karras",
                "denoise": 1.0
            }
        }

        decode_id = str(node_id + 2)
        workflow[decode_id] = {
            "class_type": "VAEDecode",
            "inputs": {"samples": [sampler_id, 0], "vae": ["1", 2]}
        }

        save_id = str(node_id + 3)
        workflow[save_id] = {
            "class_type": "SaveImage",
            "inputs": {
                "images": [decode_id, 0],
                "filename_prefix": f"seed_grid_{i:02d}_s{seed}"
            }
        }

        node_id += 4

    return workflow, seeds

prompt = "a cozy coffee shop interior, warm lighting, detailed"
workflow, seeds = seed_grid_experiment(prompt)

with open("workflows/seed_grid.json", "w") as f:
    json.dump(workflow, f, indent=2)

print(f"种子网格实验工作流已保存")
print(f"Prompt: {prompt}")
print(f"Seeds: {seeds}")
print(f"生成 9 张图像，用于对比种子对结果的影响")
```

**要点**：
- 每个种子需要独立的 EmptyLatentImage 和 KSampler
- 共享 CheckpointLoader 和 CLIPTextEncode 以节省内存
- 文件名包含种子值便于后续对比分析
