# 第八课：阶段实战 —— 电商商品图批量处理工作流

## 场景引入

你已经掌握了 IP-Adapter、超分修复、自定义节点开发等技能。现在，是时候把它们整合到一个真实的商业项目中了。

**真实需求**：某服装电商公司每天需要处理 200+ 张商品图，包括：

- **白底图**：纯白背景的商品主图，用于详情页和搜索结果
- **场景图**：商品放在生活场景中的效果图，用于社交媒体投放
- **模特图**：模特穿着商品的展示图，用于详情页和广告

人工处理每张图平均需要 15 分钟（拍摄 + 抠图 + 调色 + 合成 + 导出）。200 张图需要 50 小时的人工工时。

本课将从需求分析开始，一步步设计、实现、优化这个完整的电商商品图批量处理工作流。

## 二、模块一：图像分割与抠图

### 2.1 分割模型选择

电商场景的分割需求是"前景商品 + 背景分离"，常用模型：

| 模型 | 速度 | 精度 | 适用场景 |
|------|------|------|---------|
| SAM (Segment Anything) | 慢 | **最高** | 复杂场景，需要精确边缘 |
| U2-Net | **快** | 中 | 人像抠图，简单背景 |
| RMBG-1.4 | 快 | 高 | 通用抠图，电商首选 |
| rembg (库) | 快 | 中 | 快速批量处理 |

**本课选择 RMBG-1.4**：专门为商品和人像抠图优化，速度快且边缘质量好。

### 2.2 分割节点实现

```python
# 分割与抠图节点

import torch
import numpy as np
from PIL import Image

class ProductSegmentation:
    """商品图像自动分割节点"""

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "model_type": (["rmbg", "u2net", "sam"], {"default": "rmbg"}),
                "refine_edges": ("BOOLEAN", {"default": True}),
                "edge_blur": ("INT", {"default": 2, "min": 0, "max": 10}),
            }
        }

    RETURN_TYPES = ("IMAGE", "MASK")
    RETURN_NAMES = ("foreground", "mask")
    FUNCTION = "segment"
    CATEGORY = "ecommerce/segmentation"

    def segment(self, image, model_type, refine_edges, edge_blur):
        # 加载分割模型（带缓存）
        model = self._load_model(model_type)

        # 逐帧处理 batch
        b, h, w, c = image.shape
        masks = []

        for i in range(b):
            # 转为 PIL 格式
            img_np = (image[i].cpu().numpy() * 255).astype(np.uint8)
            pil_img = Image.fromarray(img_np)

            # 执行分割
            mask = model.predict(pil_img)

            # 边缘优化
            if refine_edges:
                mask = self._refine_edge(mask, edge_blur)

            masks.append(torch.from_numpy(np.array(mask)).float() / 255.0)

        # 合并 batch
        mask_tensor = torch.stack(masks)  # [B, H, W]

        # 应用蒙版提取前景
        foreground = image.clone()
        mask_expanded = mask_tensor.unsqueeze(-1)  # [B, H, W, 1]
        foreground = foreground * mask_expanded

        return (foreground, mask_tensor)

    def _load_model(self, model_type):
        """加载分割模型（带缓存）"""
        if not hasattr(self, '_model_cache'):
            self._model_cache = {}

        if model_type not in self._model_cache:
            if model_type == "rmbg":
                from transformers import AutoModelForImageSegmentation
                self._model_cache[model_type] = AutoModelForImageSegmentation.from_pretrained(
                    "briaai/RMBG-1.4", trust_remote_code=True
                )
            # ... 其他模型加载
        return self._model_cache[model_type]

    def _refine_edge(self, mask, blur_radius):
        """优化蒙版边缘，减少锯齿"""
        if blur_radius == 0:
            return mask
        # 高斯模糊蒙版边缘
        from PIL import ImageFilter
        return mask.filter(ImageFilter.GaussianBlur(radius=blur_radius))
```

## 三、模块二：背景替换

### 3.1 三类背景的生成策略

```
背景替换策略：

  白底图：
  ├── 直接将蒙版外区域设为白色 (#FFFFFF)
  ├── 最简单，不需要 AI 生成
  └── 关键：边缘要干净，不能有原背景残留

  场景图：
  ├── 使用 SD Inpainting 生成背景
  ├── Prompt 描述场景（"living room", "studio" 等）
  ├── ControlNet 保持商品位置不变
  └── 关键：风格要和商品调性匹配

  模特图：
  ├── 使用 InstantID 生成一致的人脸
  ├── ControlNet 保持姿态
  ├── IP-Adapter 注入品牌风格
  └── 关键：人脸一致性是核心
```

### 3.2 白底图生成

```python
class WhiteBackgroundGenerator:
    """将商品图转为纯白背景"""

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "mask": ("MASK",),
                "background_color": ("STRING", {"default": "#FFFFFF"}),
                "shadow_enabled": ("BOOLEAN", {"default": True}),
                "shadow_opacity": ("FLOAT", {"default": 0.15, "min": 0.0, "max": 1.0}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    RETURN_NAMES = ("white_bg_image",)
    FUNCTION = "generate"
    CATEGORY = "ecommerce/background"

    def generate(self, image, mask, background_color, shadow_enabled, shadow_opacity):
        b, h, w, c = image.shape

        # 解析背景颜色
        bg_color = self._hex_to_rgb(background_color)
        background = torch.ones(b, h, w, c) * bg_color

        # 生成阴影（可选）
        if shadow_enabled:
            shadow = self._generate_shadow(mask, shadow_opacity)
            background = background - shadow

        # 合成：蒙版区域用原图，其他区域用背景
        mask_expanded = mask.unsqueeze(-1)  # [B, H, W, 1]
        result = image * mask_expanded + background * (1 - mask_expanded)

        return (torch.clamp(result, 0, 1),)

    def _hex_to_rgb(self, hex_color):
        """十六进制颜色转 RGB 张量"""
        hex_color = hex_color.lstrip('#')
        r, g, b = int(hex_color[0:2], 16), int(hex_color[2:4], 16), int(hex_color[4:6], 16)
        return torch.tensor([r / 255.0, g / 255.0, b / 255.0])

    def _generate_shadow(self, mask, opacity):
        """基于蒙版生成简单的投影效果"""
        # 将蒙版向下偏移几个像素作为阴影
        shadow = torch.zeros_like(mask)
        offset = 5
        shadow[:, offset:, :] = mask[:, :-offset, :]
        shadow = shadow * opacity
        return shadow.unsqueeze(-1).expand_as(mask.unsqueeze(-1))
```

### 4.2 完整批量处理器实现

```python
# batch_processor.py - 批量处理引擎

import os
import json
import time
import logging
from pathlib import Path
from dataclasses import dataclass, field
from typing import List, Optional, Callable
from concurrent.futures import ThreadPoolExecutor
from enum import Enum

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)


class TaskStatus(Enum):
    PENDING = "pending"
    PROCESSING = "processing"
    SUCCESS = "success"
    FAILED = "failed"
    MANUAL_REVIEW = "manual_review"


class OutputType(Enum):
    WHITE_BG = "white_bg"
    SCENE = "scene"
    MODEL = "model"


@dataclass
class ProcessingTask:
    """单个处理任务"""
    task_id: str
    input_path: str
    output_type: OutputType
    status: TaskStatus = TaskStatus.PENDING
    output_path: Optional[str] = None
    error_message: Optional[str] = None
    processing_time: float = 0.0
    quality_score: float = 0.0
    metadata: dict = field(default_factory=dict)


@dataclass
class BatchConfig:
    """批量处理配置"""
    input_dir: str
    output_dir: str
    output_type: OutputType
    max_workers: int = 1
    quality_threshold: float = 0.7
    retry_failed: bool = True
    max_retries: int = 2
    save_report: bool = True
    # 背景替换配置
    scene_prompt: str = ""
    background_color: str = "#FFFFFF"
    # 人脸一致性配置（模特图）
    reference_face_path: str = ""


class BatchProcessor:
    """电商商品图批量处理引擎"""

    def __init__(self, config: BatchConfig):
        self.config = config
        self.tasks: List[ProcessingTask] = []
        self.results: dict = {
            "total": 0,
            "success": 0,
            "failed": 0,
            "manual_review": 0,
            "total_time": 0.0,
            "avg_time_per_image": 0.0,
        }

        # 确保输出目录存在
        os.makedirs(config.output_dir, exist_ok=True)
        os.makedirs(os.path.join(config.output_dir, "manual_review"), exist_ok=True)

    def scan_input(self) -> int:
        """扫描输入目录，创建任务列表"""
        input_path = Path(self.config.input_dir)
        extensions = {'.jpg', '.jpeg', '.png', '.webp', '.bmp'}

        for idx, file_path in enumerate(sorted(input_path.iterdir())):
            if file_path.suffix.lower() in extensions:
                task = ProcessingTask(
                    task_id=f"task_{idx:04d}",
                    input_path=str(file_path),
                    output_type=self.config.output_type,
                )
                self.tasks.append(task)

        self.results["total"] = len(self.tasks)
        logger.info(f"扫描完成，共发现 {len(self.tasks)} 个待处理文件")
        return len(self.tasks)

    def process_all(self):
        """批量处理所有任务"""
        start_time = time.time()

        for task in self.tasks:
            self._process_single_task(task)

        self.results["total_time"] = time.time() - start_time
        if self.results["success"] > 0:
            self.results["avg_time_per_image"] = (
                self.results["total_time"] / self.results["success"]
            )

        logger.info(
            f"批量处理完成: 总计 {self.results['total']}, "
            f"成功 {self.results['success']}, "
            f"失败 {self.results['failed']}, "
            f"人工审核 {self.results['manual_review']}"
        )

        if self.config.save_report:
            self._save_report()

    def _process_single_task(self, task: ProcessingTask):
        """处理单个任务的完整流程"""
        task.status = TaskStatus.PROCESSING
        task_start = time.time()

        try:
            # 步骤 1：读取图像
            image = self._load_image(task.input_path)

            # 步骤 2：质量预检
            quality_ok, quality_report = self._quality_check(image)
            if not quality_ok:
                task.status = TaskStatus.MANUAL_REVIEW
                task.error_message = quality_report
                task.output_path = self._save_to_review(task, image)
                self.results["manual_review"] += 1
                logger.warning(f"[{task.task_id}] 质量预检不通过，转入人工审核: {quality_report}")
                return

            # 步骤 3：分割抠图
            foreground, mask = self._segment(image)

            # 步骤 4：背景处理（根据输出类型）
            if task.output_type == OutputType.WHITE_BG:
                result = self._apply_white_background(foreground, mask)
            elif task.output_type == OutputType.SCENE:
                result = self._apply_scene_background(foreground, mask, self.config.scene_prompt)
            elif task.output_type == OutputType.MODEL:
                result = self._generate_model_image(foreground, mask)
            else:
                raise ValueError(f"未知的输出类型: {task.output_type}")

            # 步骤 5：超分辨率放大
            result = self._upscale(result, target_size=self._get_target_size(task.output_type))

            # 步骤 6：面部修复（模特图）
            if task.output_type == OutputType.MODEL:
                result = self._face_restore(result)

            # 步骤 7：质量门控
            passed, gate_report = self._quality_gate(result)
            if not passed:
                task.status = TaskStatus.MANUAL_REVIEW
                task.error_message = gate_report
                task.output_path = self._save_to_review(task, result)
                self.results["manual_review"] += 1
                logger.warning(f"[{task.task_id}] 质量门控不通过: {gate_report}")
                return

            # 步骤 8：保存输出
            task.output_path = self._save_output(task, result)
            task.status = TaskStatus.SUCCESS
            self.results["success"] += 1
            logger.info(f"[{task.task_id}] 处理成功: {task.output_path}")

        except Exception as e:
            task.status = TaskStatus.FAILED
            task.error_message = str(e)
            self.results["failed"] += 1
            logger.error(f"[{task.task_id}] 处理失败: {e}")

        finally:
            task.processing_time = time.time() - task_start

    def _load_image(self, path: str):
        """加载图像"""
        import torch
        import numpy as np
        from PIL import Image

        img = Image.open(path).convert("RGB")
        img_np = np.array(img).astype(np.float32) / 255.0
        return torch.from_numpy(img_np).unsqueeze(0)  # [1, H, W, C]

    def _quality_check(self, image):
        """
        质量预检：检查分辨率、模糊程度、色彩分布。
        返回 (是否通过, 检查报告)
        """
        import torch

        _, h, w, _ = image.shape

        # 检查 1：最低分辨率
        if h < 256 or w < 256:
            return False, f"分辨率过低: {w}×{h}，最低要求 256×256"

        # 检查 2：模糊检测（拉普拉斯方差）
        gray = 0.299 * image[..., 0] + 0.587 * image[..., 1] + 0.114 * image[..., 2]
        laplacian_var = self._laplacian_variance(gray)
        if laplacian_var < 50:
            return False, f"图像过于模糊: 拉普拉斯方差={laplacian_var:.1f}（阈值=50）"

        # 检查 3：是否几乎全黑或全白
        mean_brightness = gray.mean().item()
        if mean_brightness < 0.05:
            return False, f"图像过暗: 平均亮度={mean_brightness:.3f}"
        if mean_brightness > 0.95:
            return False, f"图像过亮: 平均亮度={mean_brightness:.3f}"

        return True, "质量预检通过"

    def _laplacian_variance(self, gray_tensor):
        """计算拉普拉斯方差（模糊检测指标）"""
        import torch
        # 简化的拉普拉斯算子
        kernel = torch.tensor([[0, 1, 0], [1, -4, 1], [0, 1, 0]], dtype=torch.float32)
        kernel = kernel.reshape(1, 1, 3, 3)

        gray_batch = gray_tensor.unsqueeze(0).unsqueeze(0)  # [1, 1, H, W]
        laplacian = torch.nn.functional.conv2d(gray_batch, kernel, padding=1)
        return laplacian.var().item()

    def _segment(self, image):
        """分割抠图（调用分割节点）"""
        # 实际实现中调用 ProductSegmentation 节点
        # 这里返回占位结果
        b, h, w, c = image.shape
        mask = torch.ones(b, h, w)  # 占位：全白蒙版
        return image, mask

    def _apply_white_background(self, foreground, mask):
        """应用白色背景"""
        import torch
        background = torch.ones_like(foreground)
        mask_expanded = mask.unsqueeze(-1)
        return foreground * mask_expanded + background * (1 - mask_expanded)

    def _apply_scene_background(self, foreground, mask, prompt):
        """应用场景背景（Inpainting）"""
        # 实际实现中调用 SceneBackgroundGenerator
        return foreground

    def _generate_model_image(self, foreground, mask):
        """生成模特图（InstantID）"""
        # 实际实现中调用 InstantID 工作流
        return foreground

    def _upscale(self, image, target_size):
        """超分辨率放大"""
        import torch
        # 实际实现中调用 Real-ESRGAN
        # 这里用简单的双线性插值占位
        b, h, w, c = image.shape
        scale = target_size / max(h, w)
        new_h, new_w = int(h * scale), int(w * scale)

        result = torch.nn.functional.interpolate(
            image.permute(0, 3, 1, 2),
            size=(new_h, new_w),
            mode='bilinear',
            align_corners=False
        ).permute(0, 2, 3, 1)
        return result

    def _face_restore(self, image):
        """面部修复"""
        # 实际实现中调用 CodeFormer

    def _quality_gate(self, image):
        """
        质量门控：输出前的最终检查。
        检查分辨率是否达标、是否有明显伪影。
        """
        _, h, w, _ = image.shape
        min_size = 800
        if h < min_size or w < min_size:
            return False, f"输出分辨率不达标: {w}×{h}，要求 ≥{min_size}"
        return True, "质量门控通过"

    def _get_target_size(self, output_type):

        sizes = {

            OutputType.MODEL: 1024,
```

## 八、常见误区

### 误区一：不做质量预检直接处理

如果输入图片本身就是废片（模糊、曝光错误、角度不对），不管后续处理多精细，输出也不会好。质量预检可以节省大量无意义的 GPU 计算。

### 误区二：所有图片用同一套参数

不同商品（浅色衣服 vs 深色衣服、透明材质 vs 不透明材质）的分割和背景替换参数应该不同。建议根据商品类别建立参数模板：

```
参数模板示例：

  浅色商品（白、米色）：
    分割置信度阈值: 0.6（低一点，避免把浅色商品误判为背景）
    白底亮度: 1.02（稍微过曝一点，避免商品边缘和背景融合）

  深色商品（黑、深蓝）：
    分割置信度阈值: 0.8（高一点，避免把阴影误判为商品）
    白底亮度: 1.0

  透明/反光材质：
    分割置信度阈值: 0.5（透明区域很难分割）
    需要手动审核的比例更高
```

### 误区三：忽略人工审核环节

AI 处理不可能 100% 准确。5% 的失败率意味着 200 张图中有 10 张需要人工处理。这 10 张如果被直接输出到产品页面，可能造成严重的商业损失。质量门控 + 人工审核是必须的环节。

### 误区四：一次性处理所有图片

大批量处理时，建议先用 10-20 张样图测试，确认参数和效果后再全量处理。这样可以避免因参数错误导致整批返工。

### 练习一

**思路**：白底图是最基础的电商需求，核心是干净的边缘和正确的阴影。
