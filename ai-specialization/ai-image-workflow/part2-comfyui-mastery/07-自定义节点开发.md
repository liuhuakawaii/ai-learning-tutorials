# 第七课：自定义节点开发 —— 扩展 ComfyUI 的能力边界

## 场景引入

你已经熟练使用 ComfyUI 现有的节点搭建各种工作流了。但在实际项目中，你很快会遇到现有节点无法满足的需求：

- **产品经理**："我们需要一个节点，自动检测图片中的商品数量，超过 3 个就标红提醒。"
- **技术负责人**："把我们内部的图像质量评估模型封装成 ComfyUI 节点，让设计师直接用。"
- **你自己的需求**："这个重复的三步操作（加载→调整→保存）能不能合成一个节点？"

ComfyUI 的强大不仅在于它自带的节点库，更在于它的**完全可扩展架构**。任何人都可以用 Python 写一个自定义节点，注册到 ComfyUI 中，像内置节点一样使用。

本课将从零开始讲解 ComfyUI 自定义节点的开发框架、类型系统、注册机制，并通过实战开发一个完整的图像处理节点。

## 学习目标

完成本课后，你将能够：

1. 理解 ComfyUI 节点开发的架构和运行机制
2. 使用 Python 定义节点的输入、输出和执行逻辑
3. 掌握 ComfyUI 的类型系统和类型转换规则
4. 开发、测试和打包一个完整的自定义节点
5. 了解将节点发布到 ComfyUI Manager 的流程

## 一、ComfyUI 节点架构概览

### 1.1 节点的本质

在 ComfyUI 中，一个节点本质上是一个 **Python 类**，它定义了三件事：

```
节点 = 执行单元

  ┌──────────────────────────────────────────┐
  │              一个 ComfyUI 节点             │
  │                                          │
  │  ① INPUT_TYPES (类方法)                   │
  │     定义节点接受哪些输入、什么类型、默认值    │
  │                                          │
  │  ② RETURN_TYPES (类属性)                  │
  │     定义节点输出哪些数据、什么类型            │
  │                                          │
  │  ③ FUNCTION (类属性)                      │
  │     指定执行时调用的方法名                   │
  │                                          │
  │  ④ execute() (实例方法)                   │
  │     实际的执行逻辑                          │
  │                                          │
  └──────────────────────────────────────────┘
```

### 1.2 节点在工作流中的生命周期

```
节点执行生命周期：

  1. 用户在 UI 中拖出一个节点
     ↓
  2. ComfyUI 根据 INPUT_TYPES 渲染输入控件
     ↓
  3. 用户连接上游节点的输出到本节点的输入
     ↓
  4. 用户点击 "Queue Prompt"
     ↓
  5. ComfyUI 构建执行图（DAG），确定节点执行顺序
     ↓
  6. 按拓扑序依次执行每个节点的 execute() 方法
     ↓
  7. execute() 的返回值通过 RETURN_TYPES 传递给下游节点
     ↓
  8. 所有节点执行完毕，最终输出图像
```

### 1.3 最小节点示例

下面是一个最简单的 ComfyUI 节点——将两个数字相加：

```python
class AddNumbers:
    """
    一个最简单的自定义节点：将两个数字相加。
    """

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "a": ("INT", {"default": 0, "min": -1000, "max": 1000}),
                "b": ("INT", {"default": 0, "min": -1000, "max": 1000}),
            }
        }

    RETURN_TYPES = ("INT",)
    RETURN_NAMES = ("sum",)
    FUNCTION = "add"
    CATEGORY = "math"

    def add(self, a, b):
        return (a + b,)
```

这个节点在 ComfyUI 中会显示为：

```
  ┌─────────────────┐
  │   Add Numbers    │
  │                  │
  │  a: [___0___]    │ ← 输入控件（整数滑块）
  │  b: [___0___]    │ ← 输入控件（整数滑块）
  │                  │
  │         sum ○──  │ ← 输出端口
  └─────────────────┘
```

## 二、输入输出类型系统

### 2.1 基础类型

ComfyUI 定义了一套内置类型，用于节点间的数据传递：

```
ComfyUI 内置类型：

  类型名        Python 类型       UI 控件           说明
  ─────────────────────────────────────────────────────────
  INT           int              数字输入框/滑块     整数
  FLOAT         float            数字输入框/滑块     浮点数
  STRING        str              文本输入框         字符串
  BOOLEAN       bool             复选框            布尔值
  IMAGE         torch.Tensor     图像预览          [B,H,W,C] 张量
  MASK          torch.Tensor     蒙版预览          [B,H,W] 张量
  LATENT        dict             潜空间预览        包含 samples 张量
  MODEL         对象引用          无预览            SD 模型
  CLIP          对象引用          无预览            CLIP 模型
  VAE           对象引用          无预览            VAE 模型
  CONDITIONING  list             无预览            条件数据
  CONTROL_NET   对象引用          无预览            ControlNet 模型
```

### 2.2 输入定义详解

INPUT_TYPES 返回一个字典，包含 `required`、`optional` 和 `hidden` 三个部分：

```python
@classmethod
def INPUT_TYPES(cls):
    return {
        # 必需输入：不连接就无法执行
        "required": {
            # 基础类型：带 UI 控件参数
            "width": ("INT", {
                "default": 512,
                "min": 64,
                "max": 4096,
                "step": 64,       # 步进值
                "display": "slider"  # 显示为滑块（默认是输入框）
            }),

            "brightness": ("FLOAT", {
                "default": 1.0,
                "min": 0.0,
                "max": 3.0,
                "step": 0.01,
                "display": "slider"
            }),

            "text_prompt": ("STRING", {
                "default": "",
                "multiline": True,   # 多行文本框
                "placeholder": "输入文本..."
            }),

            # 从上游节点接收的类型（无 UI 控件）
            "image": ("IMAGE",),
        },

        # 可选输入：不连接也能执行
        "optional": {
            "mask": ("MASK",),
            "strength": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 2.0}),
        },

        # 隐藏输入：由 ComfyUI 自动注入
        "hidden": {
            "unique_id": "UNIQUE_ID",       # 节点的唯一 ID
            "prompt": "PROMPT",             # 完整的工作流 JSON
            "extra_pnginfo": "EXTRA_PNGINFO", # PNG 元数据
        }
    }
```

### 2.5 类型转换

ComfyUI 会在节点连接时自动进行类型转换：

```
自动类型转换规则：

  INT → FLOAT        ✓ 自动提升精度
  FLOAT → INT        ✓ 截断小数部分
  INT/FLOAT → STRING ✓ 转为字符串表示
  STRING → INT       ✗ 不会自动转换（需要显式 int()）

  IMAGE → MASK       ✓ 取第一个通道的灰度值
  MASK → IMAGE       ✓ 复制到三个通道
  IMAGE → LATENT     ✗ 不兼容（需要 VAE 编码）
```

### 3.3 核心实现

```python
# nodes.py - 图像亮度调整节点

import torch
import numpy as np

class SmartBrightnessAdjust:
    """
    智能亮度调整节点。
    支持全局调整和基于蒙版的局部调整，
    自动检测过曝/欠曝区域。
    """

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "brightness": ("FLOAT", {
                    "default": 1.0,
                    "min": 0.0,
                    "max": 3.0,
                    "step": 0.01,
                    "display": "slider",
                    "tooltip": "亮度倍数。1.0 为原始亮度，<1 变暗，>1 变亮"
                }),
                "threshold_warn": ("FLOAT", {
                    "default": 0.95,
                    "min": 0.5,
                    "max": 1.0,
                    "step": 0.01,
                    "display": "slider",
                    "tooltip": "过曝检测阈值（像素亮度占比）"
                }),
            },
            "optional": {
                "mask": ("MASK", {
                    "tooltip": "可选蒙版。白色区域应用亮度调整，黑色区域保持不变"
                }),
                "gamma_correction": ("BOOLEAN", {
                    "default": False,
                    "tooltip": "使用 gamma 校正而非线性调整，暗部细节保留更好"
                }),
            }
        }

    RETURN_TYPES = ("IMAGE", "STRING")
    RETURN_NAMES = ("adjusted_image", "analysis_report")
    FUNCTION = "adjust_brightness"
    CATEGORY = "image/enhancement"

    def adjust_brightness(self, image, brightness, threshold_warn, mask=None, gamma_correction=False):
        """
        执行亮度调整。

        参数：
            image: [B, H, W, C] 张量，值域 [0, 1]
            brightness: 亮度倍数
            threshold_warn: 过曝阈值
            mask: 可选蒙版 [B, H, W]
            gamma_correction: 是否使用 gamma 校正
        """
        # 深拷贝，避免修改原始数据
        result = image.clone()

        # 分析原始图像
        analysis = self._analyze_image(image, threshold_warn)

        # 执行亮度调整
        if gamma_correction:
            adjusted = self._gamma_adjust(result, brightness)
        else:
            adjusted = self._linear_adjust(result, brightness)

        # 如果有蒙版，混合原始图像和调整后的图像
        if mask is not None:
            adjusted = self._apply_mask_blend(result, adjusted, mask)

        # 裁剪到有效范围
        adjusted = torch.clamp(adjusted, 0.0, 1.0)

        # 生成分析报告
        report = self._generate_report(analysis, brightness)

        return (adjusted, report)

    def _linear_adjust(self, image, brightness):
        """线性亮度调整：直接乘以倍数"""
        return image * brightness

    def _gamma_adjust(self, image, brightness):
        """
        Gamma 校正亮度调整。
        对暗部更友好：brightness < 1 时暗部不会直接变黑。
        """
        # 将 brightness 映射到 gamma 值
        # brightness=1.0 → gamma=1.0（不变）
        # brightness=0.5 → gamma=2.0（变暗，但暗部有细节）
        # brightness=2.0 → gamma=0.5（变亮）
        if brightness == 0:
            return torch.zeros_like(image)
        gamma = 1.0 / brightness
        return torch.pow(image, gamma)

    def _apply_mask_blend(self, original, adjusted, mask):
        """
        基于蒙版混合原始图像和调整后的图像。
        mask: [B, H, W]，值域 [0, 1]
        """
        # 扩展 mask 维度以匹配图像 [B, H, W] → [B, H, W, 1]
        if mask.dim() == 3:
            mask = mask.unsqueeze(-1)

        # 线性插值混合
        blended = original * (1 - mask) + adjusted * mask
        return blended

    def _analyze_image(self, image, threshold):
        """
        分析图像的亮度分布。
        检测过曝和欠曝区域。
        """
        # 转为灰度计算亮度
        gray = 0.299 * image[..., 0] + 0.587 * image[..., 1] + 0.114 * image[..., 2]

        total_pixels = gray.numel()
        overexposed = (gray > threshold).sum().item()
        underexposed = (gray < (1 - threshold)).sum().item()

        return {
            "mean_brightness": gray.mean().item(),
            "overexposed_ratio": overexposed / total_pixels,
            "underexposed_ratio": underexposed / total_pixels,
            "overexposed_pixels": overexposed,
            "underexposed_pixels": underexposed,
            "total_pixels": total_pixels,
        }

    def _generate_report(self, analysis, brightness):
        """生成人类可读的分析报告"""
        lines = [
            "=== 亮度分析报告 ===",
            f"原始平均亮度: {analysis['mean_brightness']:.3f}",
            f"调整倍数: {brightness:.2f}",
            "",
            "--- 过曝检测 ---",
            f"过曝像素: {analysis['overexposed_pixels']} "
            f"({analysis['overexposed_ratio']*100:.1f}%)",
            f"{'⚠️ 警告：过曝区域较多，建议降低亮度' if analysis['overexposed_ratio'] > 0.05 else '✅ 过曝区域正常'}",
            "",
            "--- 欠曝检测 ---",
            f"欠曝像素: {analysis['underexposed_pixels']} "
            f"({analysis['underexposed_ratio']*100:.1f}%)",
            f"{'⚠️ 警告：欠曝区域较多，建议提高亮度' if analysis['underexposed_ratio'] > 0.05 else '✅ 欠曝区域正常'}",
        ]
        return "\n".join(lines)
```

### 3.5 IS_CHANGED 机制

当节点的输入没有变化时，ComfyUI 会缓存结果而不重新执行。但某些节点（比如带随机数的节点）需要每次都执行：

```python
class RandomNoiseGenerator:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "seed": ("INT", {"default": 0, "min": 0, "max": 0xffffffffffffffff}),
                "scale": ("FLOAT", {"default": 0.1, "min": 0.0, "max": 1.0}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "generate"
    CATEGORY = "image/noise"

    @classmethod
    def IS_CHANGED(cls, seed, **kwargs):
        # 每次 seed 变化时重新执行
        # 返回值会被哈希，相同哈希 = 不重新执行
        return seed

    def generate(self, seed, scale):
        torch.manual_seed(seed)
        noise = torch.rand(1, 512, 512, 1) * scale
        return (noise,)
```

### 4.1 动态输入输出

某些场景需要根据用户选择动态调整输入输出：

```python
class ConditionalInputs:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "mode": (["simple", "advanced"], {"default": "simple"}),
                "image": ("IMAGE",),
            },
            "optional": {
                # advanced 模式才需要的输入
                "mask": ("MASK",),
                "strength": ("FLOAT", {"default": 1.0, "min": 0.0, "max": 2.0}),
            }
        }

    # 动态输出：根据模式返回不同数量的输出
    RETURN_TYPES = ("IMAGE", "STRING")
    RETURN_NAMES = ("result", "info")
    FUNCTION = "process"
    CATEGORY = "image/process"

    # 告诉 ComfyUI 这个节点的输出类型可能变化
    OUTPUT_IS_LIST = (False, False)

    def process(self, mode, image, mask=None, strength=1.0):
        if mode == "simple":
            result = image * strength
            info = f"Simple mode, strength={strength}"
        else:
            if mask is not None:
                # 高级模式：使用蒙版
                result = image.clone()
                mask_expanded = mask.unsqueeze(-1)
                result = result * (1 - mask_expanded) + (result * strength) * mask_expanded
                info = f"Advanced mode with mask, strength={strength}"
            else:
                result = image * strength
                info = f"Advanced mode without mask, strength={strength}"

        return (torch.clamp(result, 0, 1), info)
```

### 4.2 异步执行

对于耗时操作，ComfyUI 支持异步执行：

```python
class HeavyProcessingNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "iterations": ("INT", {"default": 10, "min": 1, "max": 100}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "process"
    CATEGORY = "image/advanced"

    # 标记为 CPU 密集型节点
    CATEGORY = "image/advanced"

    def process(self, image, iterations):
        # ComfyUI 会在后台线程执行这个方法
        # UI 不会被阻塞
        result = image.clone()
        for i in range(iterations):
            result = self._heavy_compute(result)
        return (result,)

    def _heavy_compute(self, image):
        # 模拟耗时计算
        return torch.clamp(image + torch.randn_like(image) * 0.01, 0, 1)
```

### 4.3 连接验证

在节点执行前验证输入的有效性：

```python
class ValidatedNode:
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "target_size": ("INT", {"default": 512, "min": 64, "max": 4096}),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    FUNCTION = "resize"
    CATEGORY = "image/transform"

    @classmethod
    def VALIDATE_INPUTS(cls, image, target_size):
        """
        在节点执行前验证输入。
        返回 True 表示验证通过，返回字符串表示错误信息。
        """
        if target_size <= 0:
            return "target_size must be positive"
        if target_size > 8192:
            return "target_size too large, max 8192"
        # IMAGE 类型的验证由 ComfyUI 框架处理
        return True

    def resize(self, image, target_size):
        # 此时可以确定输入是有效的
        result = torch.nn.functional.interpolate(
            image.permute(0, 3, 1, 2),
            size=(target_size, target_size),
            mode='bilinear',
            align_corners=False
        ).permute(0, 2, 3, 1)
        return (result,)
```

### 4.4 组合节点（Node Composition）

将多个常用节点封装成一个"超级节点"：

```python
class QuickEnhance:
    """
    快速图像增强组合节点。
    将亮度调整、对比度调整、锐化三个步骤合并为一个节点。
    """

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "brightness": ("FLOAT", {
                    "default": 1.0, "min": 0.0, "max": 3.0,
                    "step": 0.01, "display": "slider"
                }),
                "contrast": ("FLOAT", {
                    "default": 1.0, "min": 0.0, "max": 3.0,
                    "step": 0.01, "display": "slider"
                }),
                "sharpness": ("FLOAT", {
                    "default": 0.0, "min": 0.0, "max": 5.0,
                    "step": 0.1, "display": "slider"
                }),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    RETURN_NAMES = ("enhanced_image",)
    FUNCTION = "enhance"
    CATEGORY = "image/enhancement"

    def enhance(self, image, brightness, contrast, sharpness):
        result = image.clone()

        # 步骤 1：亮度调整
        if brightness != 1.0:
            result = result * brightness

        # 步骤 2：对比度调整
        if contrast != 1.0:
            mean = result.mean()
            result = (result - mean) * contrast + mean

        # 步骤 3：锐化（使用 Unsharp Mask）
        if sharpness > 0:
            result = self._unsharp_mask(result, sharpness)

        return (torch.clamp(result, 0, 1),)

    def _unsharp_mask(self, image, amount):
        """Unsharp Mask 锐化"""
        # 简化实现：使用均值模糊作为模糊版本
        kernel_size = 3
        padding = kernel_size // 2

        # 转换为 [B, C, H, W] 格式进行卷积
        img = image.permute(0, 3, 1, 2)
        blurred = torch.nn.functional.avg_pool2d(
            img, kernel_size=kernel_size, stride=1, padding=padding
        )

        # 锐化公式：原图 + (原图 - 模糊图) × 强度
        sharpened = img + (img - blurred) * amount

        return sharpened.permute(0, 2, 3, 1)
```

## 六、常见误区

### 误区一：在 execute() 中加载大模型

每次 execute() 被调用时都加载模型文件，会严重影响性能。正确做法：

```python
# 错误：每次执行都加载
def execute(self, image):
    model = load_my_model()  # 每次都加载，浪费时间
    return model(image)

# 正确：在类级别缓存
class MyNode:
    _model_cache = {}

    def execute(self, image):
        if "my_model" not in self._model_cache:
            self._model_cache["my_model"] = load_my_model()
        model = self._model_cache["my_model"]
        return model(image)
```

### 误区二：忘记处理 batch 维度

ComfyUI 的 IMAGE 类型是 `[B, H, W, C]`，batch 维度可能大于 1：

```python
# 错误：假设 batch=1
def execute(self, image):
    h, w = image.shape[1], image.shape[2]  # 如果 B>1，这是错的
    # ...

# 正确：显式处理 batch
def execute(self, image):
    b, h, w, c = image.shape
    for i in range(b):
        single_image = image[i]  # [H, W, C]
        # 处理单张图...
```

### 误区三：类型不匹配导致崩溃

RETURN_TYPES 声明的类型必须和 execute() 实际返回的类型一致：

```python
# 错误：声明返回 IMAGE，实际返回 numpy array
RETURN_TYPES = ("IMAGE",)

def execute(self, image):
    result = np.array(image)  # numpy array
    return (result,)  # 崩溃！ComfyUI 期望 torch.Tensor

# 正确：确保返回类型匹配
def execute(self, image):
    result = torch.from_numpy(np.array(image)).float()
    return (result,)
```

### 误区四：忽视内存管理

在处理大图像时，及时释放不需要的中间变量：

```python
# 错误：内存泄漏
def execute(self, image):
    temp1 = self._process_a(image)
    temp2 = self._process_b(temp1)
    temp3 = self._process_c(temp2)
    return (temp3,)  # temp1, temp2 仍然占用内存

# 正确：主动释放
def execute(self, image):
    temp1 = self._process_a(image)
    temp2 = self._process_b(temp1)
    del temp1  # 释放中间变量
    temp3 = self._process_c(temp2)
    del temp2
    return (temp3,)
```

## 七、小结

本课的核心知识点：

1. **节点即 Python 类**：通过 INPUT_TYPES、RETURN_TYPES、FUNCTION 三要素定义节点的接口
2. **类型系统**：内置类型（IMAGE、MASK、LATENT 等）支持自动转换，自定义类型可以扩展
3. **生命周期**：ComfyUI 按 DAG 拓扑序执行节点，支持缓存和增量执行
4. **开发规范**：项目结构清晰、依赖声明完整、README 详尽
5. **性能关键**：模型缓存、batch 处理、内存管理是生产级节点的基本要求

## 参考答案

### 练习一

**思路**：基础的双图混合，关键是理解 IMAGE 类型的张量格式和 batch 处理。

**答案**：

```python
class ImageBlend:
    """图像混合节点：将两张图像按比例混合"""

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image_a": ("IMAGE",),
                "image_b": ("IMAGE",),
                "blend_ratio": ("FLOAT", {
                    "default": 0.5,
                    "min": 0.0,
                    "max": 1.0,
                    "step": 0.01,
                    "display": "slider",
                    "tooltip": "0.0 = 完全使用 A，1.0 = 完全使用 B"
                }),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    RETURN_NAMES = ("blended_image",)
    FUNCTION = "blend"
    CATEGORY = "image/composite"

    def blend(self, image_a, image_b, blend_ratio):
        # 确保两张图尺寸一致
        if image_a.shape != image_b.shape:
            # 将 B 缩放到 A 的尺寸
            b_b, b_h, b_w, b_c = image_b.shape
            a_b, a_h, a_w, a_c = image_a.shape
            image_b = torch.nn.functional.interpolate(
                image_b.permute(0, 3, 1, 2),
                size=(a_h, a_w),
                mode='bilinear',
                align_corners=False
            ).permute(0, 2, 3, 1)

        # 线性插值混合
        blended = image_a * (1 - blend_ratio) + image_b * blend_ratio

        return (torch.clamp(blended, 0, 1),)
```

**要点**：
- IMAGE 格式是 `[B, H, W, C]`，值域 `[0, 1]`
- 尺寸不匹配时需要缩放，否则直接混合会报错
- `torch.clamp` 确保输出在有效范围内

### 练习二

**思路**：蒙版是 `[B, H, W]`，需要扩展维度才能和 `[B, H, W, C]` 的图像做乘法。

**答案**：

```python
class ImageBlendWithMask:
    """带蒙版的图像混合节点"""

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image_a": ("IMAGE",),
                "image_b": ("IMAGE",),
                "blend_ratio": ("FLOAT", {
                    "default": 0.5, "min": 0.0, "max": 1.0,
                    "step": 0.01, "display": "slider"
                }),
            },
            "optional": {
                "mask": ("MASK",),
            }
        }

    RETURN_TYPES = ("IMAGE",)
    RETURN_NAMES = ("blended_image",)
    FUNCTION = "blend"
    CATEGORY = "image/composite"

    def blend(self, image_a, image_b, blend_ratio, mask=None):
        # 尺寸对齐
        if image_a.shape != image_b.shape:
            a_h, a_w = image_a.shape[1], image_a.shape[2]
            image_b = torch.nn.functional.interpolate(
                image_b.permute(0, 3, 1, 2),
                size=(a_h, a_w),
                mode='bilinear',
                align_corners=False
            ).permute(0, 2, 3, 1)

        # 计算混合结果
        blended = image_a * (1 - blend_ratio) + image_b * blend_ratio

        # 应用蒙版
        if mask is not None:
            # mask: [B, H, W] → [B, H, W, 1]
            mask_expanded = mask.unsqueeze(-1)

            # 如果蒙版尺寸和图像不匹配，缩放蒙版
            if mask_expanded.shape[1:3] != image_a.shape[1:3]:
                mask_expanded = torch.nn.functional.interpolate(
                    mask.unsqueeze(1),  # [B, 1, H, W]
                    size=(image_a.shape[1], image_a.shape[2]),
                    mode='bilinear',
                    align_corners=False
                ).permute(0, 2, 3, 1)  # [B, H, W, 1]

            # 蒙版白色区域用混合结果，黑色区域用 image_a
            result = image_a * (1 - mask_expanded) + blended * mask_expanded
        else:
            result = blended

        return (torch.clamp(result, 0, 1),)
```

**要点**：
- 蒙版维度处理是 ComfyUI 开发中最常见的坑
- `unsqueeze(-1)` 将 `[B, H, W]` 变为 `[B, H, W, 1]`，支持广播乘法
- 蒙版尺寸可能和图像不匹配，需要独立缩放

### 练习三

**思路**：IS_CHANGED 返回值的哈希决定是否重新执行，VALIDATE_INPUTS 在执行前校验输入。

**答案**：

```python
class CachedImageAnalysis:
    """带缓存的图像分析节点"""

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
                "analysis_prompt": ("STRING", {
                    "default": "",
                    "multiline": False,
                    "placeholder": "输入分析指令..."
                }),
            }
        }

    RETURN_TYPES = ("STRING",)
    RETURN_NAMES = ("analysis_result",)
    FUNCTION = "analyze"
    CATEGORY = "image/analysis"

    @classmethod
    def VALIDATE_INPUTS(cls, image, analysis_prompt):
        """执行前验证输入"""
        if not analysis_prompt or analysis_prompt.strip() == "":
            return "analysis_prompt 不能为空，请输入分析指令"
        if len(analysis_prompt) > 1000:
            return "analysis_prompt 过长，最多 1000 字符"
        return True

    @classmethod
    def IS_CHANGED(cls, image, analysis_prompt):
        """
        缓存控制：只有 prompt 变化时才重新执行。
        image 的变化会被忽略（假设同一 prompt 对同类图像的分析结果相似）。
        """
        return analysis_prompt

    def analyze(self, image, analysis_prompt):
        # 模拟一个耗时的分析过程
        b, h, w, c = image.shape

        # 计算基本统计信息
        mean_rgb = image.mean(dim=[0, 1, 2])  # [C]
        std_rgb = image.std(dim=[0, 1, 2])    # [C]

        # 生成分析报告
        result = (
            f"分析指令: {analysis_prompt}\n"
            f"图像尺寸: {w}×{h}, 通道数: {c}\n"
            f"Batch 大小: {b}\n"
            f"RGB 均值: R={mean_rgb[0]:.3f}, G={mean_rgb[1]:.3f}, B={mean_rgb[2]:.3f}\n"
            f"RGB 标准差: R={std_rgb[0]:.3f}, G={std_rgb[1]:.3f}, B={std_rgb[2]:.3f}\n"
            f"---\n"
            f"模拟分析完成。在真实场景中，这里会调用视觉语言模型。"
        )

        return (result,)
```

**要点**：
- IS_CHANGED 返回 prompt 字符串，相同 prompt 的哈希相同，跳过重复执行
- VALIDATE_INPUTS 返回 True 表示通过，返回字符串表示错误信息
- 注意 IS_CHANGED 的参数签名要和 INPUT_TYPES 的 required 输入一致
