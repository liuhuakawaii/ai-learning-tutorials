# 毕业项目：电商图像自动化平台

## 项目概述

构建一个电商图像自动化平台，支持可视化配置图像处理工作流、批量生成商品图、质量审核、资产管理和 API 对外服务。

## 核心功能

### 1. 工作流编辑器
- 基于 ComfyUI 的节点式工作流编辑
- 预设模板：白底图、场景图、模特图、海报
- 参数面板：批量修改 Prompt、尺寸、风格
- 工作流导入/导出（JSON 格式）

### 2. 批量任务系统
- CSV/Excel 导入商品信息（名称、描述、风格要求）
- 自动拆分任务，并行执行
- 任务优先级、重试机制、超时处理
- 进度追踪与实时状态更新

### 3. 模型管理
- LoRA 模型上传、切换、版本控制
- 模型元数据：触发词、推荐权重、适用场景
- 模型效果预览

### 4. 质量控制
- 自动评分：美学评分（LAION Aesthetics）、人脸质量
- NSFW 过滤
- 一致性检查：同一商品的不同角度是否一致
- 人工审核队列

### 5. 资产管理
- 图像元数据：生成参数、使用的模型、Prompt
- 标签系统：商品类型、风格、场景
- 搜索与筛选
- 版本历史

### 6. API 服务
- RESTful API 供外部系统调用
- Webhook 回调
- API Key 认证与限流
- SDK（Python / JavaScript）
