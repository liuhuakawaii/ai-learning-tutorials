# 第 15 课：训练数据准备 — LoRA/DreamBooth 数据工程

你拍了 20 张猫咪照片，丢进 kohya-ss 跑了 2000 步，结果生成的图要么是模糊的色块，要么是完全不像你家猫的生物。问题不在训练参数，而在数据。

训练数据的质量直接决定微调模型的上限。30 张精心准备的数据集，效果远超 200 张随意收集的图片。这节课从工程角度讲：如何准备一份能用的训练数据。

## 数据质量的五个维度

```
维度        要求                        反面案例
──────────────────────────────────────────────────
清晰度      主体清晰，无明显模糊        手抖拍摄的糊图
多样性      多角度、多背景、多光照      20 张都是正面大头照
一致性      主体特征稳定一致            同一角色有时短发有时长发
标注准确    文本描述与图像内容匹配      标注写"坐着"实际是站着
无干扰      无水印、文字、边框覆盖      截图带网站水印
```

数据量参考：单一角色 LoRA 15-50 张，风格 LoRA 50-200 张，单一物体 10-30 张，DreamBooth 5-20 张。

## 图像收集与筛选

### 用 CLIP Score 辅助筛选

CLIP 模型可以衡量图像与文本描述的匹配度，帮你从大量候选图中选出最相关的：

```python
import torch
from PIL import Image
from transformers import CLIPProcessor, CLIPModel

def rank_images(image_paths: list, description: str, top_k: int = 20):
    """根据 CLIP 分数选出与描述最相关的图片"""
    model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
    processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

    scores = []
    for path in image_paths:
        image = Image.open(path).convert("RGB")
        inputs = processor(text=[description], images=image,
                          return_tensors="pt", padding=True)
        with torch.no_grad():
            outputs = model(**inputs)
        scores.append((path, outputs.logits_per_image.item()))

    scores.sort(key=lambda x: x[1], reverse=True)
    return scores[:top_k]


import glob
photos = glob.glob("./raw_photos/*.jpg")
selected = rank_images(photos, "a photo of an orange tabby cat sitting on a sofa")
for path, score in selected:
    print(f"{score:.2f}  {path}")
```

### 多样性自查清单

训练数据的隐性偏差是常见失败原因。如果所有照片都在沙发上拍的，模型会把猫和沙发绑定——没有沙发的 prompt 就效果差。

```
□ 至少 3 种不同背景
□ 至少 3 种不同光照条件
□ 至少 4 种不同角度
□ 至少 2 种不同距离（特写/全身）
□ 至少 3 种不同姿势或状态
```

## 图像预处理

### 智能裁剪缩放

SD 1.5 训练分辨率 512×512，SDXL 1024×1024。直接拉伸会变形，正确做法是先缩放再中心裁剪：

```python
from PIL import Image

def smart_resize(image_path: str, target: int = 512) -> Image.Image:
    """先缩放短边到 target，再中心裁剪长边"""
    img = Image.open(image_path).convert("RGB")
    w, h = img.size

    scale = target / min(w, h)
    img = img.resize((int(w * scale), int(h * scale)), Image.LANCZOS)

    left = (img.size[0] - target) // 2
    top = (img.size[1] - target) // 2
    return img.crop((left, top, left + target, top + target))


def batch_resize(input_dir: str, output_dir: str, target: int = 512):
    import os, glob
    os.makedirs(output_dir, exist_ok=True)
    for ext in ("*.jpg", "*.jpeg", "*.png", "*.webp"):
        for path in glob.glob(os.path.join(input_dir, ext)):
            img = smart_resize(path, target)
            name = os.path.splitext(os.path.basename(path))[0]
            img.save(os.path.join(output_dir, f"{name}.png"), "PNG")
```

### 宽高比分桶（Aspect Ratio Bucketing）

裁剪成正方形会丢失构图信息。kohya-ss 支持宽高比分桶：不同宽高比的图片按总像素数分组训练，不需要强制裁剪。

```
原始图片（3:2 横幅）         裁剪成正方形（丢失两侧）
┌──────────────────┐       ┌──────────┐
│   重要内容区域    │  -->  │  被裁掉   │
└──────────────────┘       └──────────┘

使用 Bucketing（保留原始比例）
┌──────────────────┐
│   完整内容保留    │  分辨率：768×512
└──────────────────┘  总像素数 ≈ 512×512
```

kohya-ss 的 `--enable_bucket` 参数自动完成分桶，`min_bucket_reso` 和 `max_bucket_reso` 控制范围。

## 自动标注

标注是训练数据的另一半。图像告诉模型"长什么样"，标注告诉模型"用什么词描述它"。

### BLIP 生成自然语言描述

```python
from PIL import Image
from transformers import BlipProcessor, BlipForConditionalGeneration

def caption_blip(image_path: str) -> str:
    processor = BlipProcessor.from_pretrained("Salesforce/blip-image-captioning-large")
    model = BlipForConditionalGeneration.from_pretrained("Salesforce/blip-image-captioning-large")

    image = Image.open(image_path).convert("RGB")
    inputs = processor(image, return_tensors="pt")
    with torch.no_grad():
        output = model.generate(**inputs, max_length=75)
    return processor.decode(output[0], skip_special_tokens=True)
```

BLIP 输出自然语言："a orange tabby cat sitting on a brown sofa looking at the camera"。

### WD Tagger 生成标签

WD Tagger 基于 Danbooru 标签体系，生成逗号分隔的标签，更适合 SD 训练：

```python
from transformers import AutoModelForImageClassification, AutoFeatureExtractor

def tag_wd(image_path: str, threshold=0.35) -> list:
    model_name = "SmilingWolf/wd-v1-4-vit-tagger-v2"
    extractor = AutoFeatureExtractor.from_pretrained(model_name)
    model = AutoModelForImageClassification.from_pretrained(model_name)

    image = Image.open(image_path).convert("RGB")
    inputs = extractor(images=image, return_tensors="pt")
    with torch.no_grad():
        probs = torch.sigmoid(model(**inputs).logits)[0]

    # 标签映射从模型仓库下载
    from huggingface_hub import hf_hub_download
    import csv
    label_path = hf_hub_download(repo_id=model_name, filename="selected_tags.csv")
    labels = []
    with open(label_path, "r", encoding="utf-8") as f:
        for row in csv.reader(f):
            labels.append(row[1])

    return [labels[i] for i, p in enumerate(probs.tolist())
            if p > threshold and i < len(labels)]
```

### 标注策略

```
风格          适用场景              示例
──────────────────────────────────────────────────
自然语言      写实风格、场景描述    "a photo of a cat sitting on a red sofa"
(BLIP)

标签式        动漫/插画风格        "orange_tabby, cat, sitting, sofa, indoors"
(WD Tagger)

混合式        通用推荐             "a photo of an orange tabby cat,
(两者结合)                          orange_tabby, cat, sitting, sofa"
```

推荐：先用 BLIP 生成基础描述，再用 WD Tagger 补充标签，最后人工审核。

### 触发词设计

角色类 LoRA 需要唯一触发词。选择模型词汇表中不存在的无意义组合词：

```
正确标注："ohwx cat, orange tabby, sitting on sofa, warm lighting"

"ohwx" 是随机生成的无意义 token
"cat" 是类别词，帮助模型理解概念
后面是场景和属性描述
```

触发词选择：避免常见英文单词，长度 3-8 字符。常见选择：`ohwx`、`sks`、`txl`。

## 数据集组织

### kohya-ss 目录结构

```
dataset/
├── 10_ohwx cat/          # {重复次数}_{概念名}
│   ├── image001.png
│   ├── image001.txt      # 与图片同名的标注
│   ├── image002.png
│   └── image002.txt
└── 10_ohwx cat_reg/      # 正则化数据集（可选）
    ├── reg001.png
    └── reg001.txt
```

目录名中的数字 `10` 表示每张图在每个 epoch 重复 10 次，用于平衡不同概念的训练权重。

标注文件注意事项：触发词 + 类别词放在开头，描述准确反映图片内容，避免否定词（"no tail" 会让模型更关注"tail"），长度控制在 75 token 以内。

## 正则化数据集

没有正则化时，模型可能过度拟合训练数据，导致所有 prompt 下都生成类似的角色特征——"知识侵蚀"。

正则化数据集是与训练概念同类但不含目标特征的图片。训练"橘子"这只猫时，正则化数据集应该是各种各样的猫：

```python
def generate_regularization(concept: str, count: int, output_dir: str):
    """用基础 SD 模型生成正则化图片"""
    import os
    from diffusers import StableDiffusionPipeline

    os.makedirs(output_dir, exist_ok=True)
    pipe = StableDiffusionPipeline.from_pretrained(
        "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
    ).to("cuda")

    prompts = [
        f"a photo of a {concept}",
        f"a {concept} in various poses",
        f"a detailed photo of a {concept}",
    ]

    for i in range(count):
        prompt = prompts[i % len(prompts)]
        img = pipe(prompt, num_inference_steps=30).images[0]
        img.save(os.path.join(output_dir, f"reg_{i:04d}.png"))
```

在 kohya-ss 配置中：`prior_loss_weight = 1.0`（标准），`0.5`（较弱正则化），`2.0`（较强正则化）。

## 数据增强

```python
from PIL import Image, ImageEnhance, ImageOps

def augment_dataset(input_dir: str, output_dir: str):
    """为每张图生成翻转和色调变体"""
    import os
    os.makedirs(output_dir, exist_ok=True)

    for f in os.listdir(input_dir):
        if not f.lower().endswith((".png", ".jpg")):
            continue
        img = Image.open(os.path.join(input_dir, f)).convert("RGB")
        base = os.path.splitext(f)[0]

        img.save(os.path.join(output_dir, f"{base}_orig.png"))

        # 水平翻转（最安全的增强）
        ImageOps.mirror(img).save(os.path.join(output_dir, f"{base}_flip.png"))

        # 暖色调
        warm = ImageEnhance.Color(img).enhance(1.1)
        ImageEnhance.Brightness(warm).enhance(1.05).save(
            os.path.join(output_dir, f"{base}_warm.png"))

        # 冷色调
        cool = ImageEnhance.Color(img).enhance(0.9)
        ImageEnhance.Brightness(cool).enhance(0.95).save(
            os.path.join(output_dir, f"{base}_cool.png"))
```

增强策略推荐：水平翻转（几乎无副作用）、轻微色调调整（±10%）。避免：垂直翻转、大角度旋转、颜色反转、模糊处理。

## 完整流程

```
收集 → 筛选（CLIP 评分 + 多样性检查） → 预处理（清洗 + 裁剪 + 分桶）
→ 标注（BLIP + WD Tagger + 人工审核 + 触发词） → 组织（kohya-ss 目录结构）
→ 正则化数据集 → 数据增强（翻转 + 色调） → 验证
```
