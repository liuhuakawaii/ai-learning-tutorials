# Lesson 01: 从需求到代码 — AI 辅助的完整开发工作流

> **课程定位**: Stage 4 第 1 课 | **前置**: Stage 1-3 完成 | **预计时长**: 90 分钟

## 场景引入

你接到一个新需求：做一个任务管理系统。产品经理给了你一段模糊的描述——"能创建任务、分配给人、设置截止日期，还要能看进度"。你打开编辑器，面对空白的项目目录，不知道从哪里开始。是先写代码？先设计数据库？还是先画 API？传统的做法是花两三天写需求文档、画架构图，然后才开始编码。但 AI 可以在这个流程的每一步提供加速——帮你把模糊需求结构化、生成 API 设计、搭建代码骨架、甚至写出测试用例。关键问题是：如何在每个环节正确地与 AI 协作，既不盲目信任，也不浪费它的能力？

## 学习目标

1. 掌握 AI 辅助的需求分析与技术方案设计方法
2. 学会用 AI 将需求文档转化为可执行的代码实现
3. 理解 AI 在测试驱动开发中的应用模式
4. 构建从需求到部署的完整 AI 辅助工作流
5. 掌握在开发各阶段与 AI 协作的最佳实践

### 4.2 核心代码实现

**AI 提示词**:
```
实现 taskService.ts 的完整代码，包含以下功能：
1. createTask - 创建任务
2. getTaskById - 获取单个任务
3. listTasks - 列表查询（支持状态/负责人筛选、分页）
4. updateTask - 更新任务
5. deleteTask - 删除任务（软删除）
6. updateStatus - 更新任务状态

```

```typescript
// src/services/taskService.ts
import { db } from '../db';
import { tasks } from '../db/schema';
import { eq, and, count, sql } from 'drizzle-orm';
import { z } from 'zod';
import { NotFoundError, ValidationError } from '../utils/errors';

// ===== Schema 定义 =====
export const createTaskSchema = z.object({
  title: z.string().min(1).max(200),
  description: z.string().optional(),
  assigneeId: z.string().uuid().optional(),
  dueDate: z.string().datetime().optional(),
  priority: z.enum(['low', 'medium', 'high']).default('medium'),
  tags: z.array(z.string()).default([]),
});

export const updateTaskSchema = createTaskSchema.partial();

export const listTasksSchema = z.object({
  status: z.enum(['todo', 'in_progress', 'done']).optional(),
  assigneeId: z.string().uuid().optional(),
  priority: z.enum(['low', 'medium', 'high']).optional(),
  page: z.coerce.number().int().min(1).default(1),
  pageSize: z.coerce.number().int().min(1).max(100).default(20),
  sortBy: z.enum(['createdAt', 'dueDate', 'priority']).default('createdAt'),
  sortOrder: z.enum(['asc', 'desc']).default('desc'),
});

// ===== Service 实现 =====
export class TaskService {
  async createTask(data: z.infer<typeof createTaskSchema>) {
    const validated = createTaskSchema.parse(data);

    const [task] = await db
      .insert(tasks)
      .values({
        title: validated.title,
        description: validated.description ?? null,
        assigneeId: validated.assigneeId ?? null,
        dueDate: validated.dueDate ? new Date(validated.dueDate) : null,
        priority: validated.priority,
        tags: validated.tags,
        status: 'todo',
      })
      .returning();

    return task;
  }

  async getTaskById(id: string) {
    const [task] = await db
      .select()
      .from(tasks)
      .where(eq(tasks.id, id))
      .limit(1);

    if (!task) {
      throw new NotFoundError(`Task ${id} not found`);
    }

    return task;
  }

  async listTasks(filters: z.infer<typeof listTasksSchema>) {
    const validated = listTasksSchema.parse(filters);

    const conditions = [];
    if (validated.status) {
      conditions.push(eq(tasks.status, validated.status));
    }
    if (validated.assigneeId) {
      conditions.push(eq(tasks.assigneeId, validated.assigneeId));
    }
    if (validated.priority) {
      conditions.push(eq(tasks.priority, validated.priority));
    }

    const whereClause = conditions.length > 0
      ? and(...conditions)
      : undefined;

    const [{ total }] = await db
      .select({ total: count() })
      .from(tasks)
      .where(whereClause);

    const data = await db
      .select()
      .from(tasks)
      .where(whereClause)
      .limit(validated.pageSize)
      .offset((validated.page - 1) * validated.pageSize);

    return {
      data,
      pagination: {
        page: validated.page,
        pageSize: validated.pageSize,
        total,
        totalPages: Math.ceil(total / validated.pageSize),
      },
    };
  }

  async updateTask(id: string, data: z.infer<typeof updateTaskSchema>) {
    const validated = updateTaskSchema.parse(data);

    await this.getTaskById(id); // 确保存在

    const [updated] = await db
      .update(tasks)
      .set({
        ...validated,
        dueDate: validated.dueDate
          ? new Date(validated.dueDate)
          : undefined,
        updatedAt: new Date(),
      })
      .where(eq(tasks.id, id))
      .returning();

    return updated;
  }

  async deleteTask(id: string) {
    await this.getTaskById(id);

    await db
      .update(tasks)
      .set({ deletedAt: new Date() })
      .where(eq(tasks.id, id));
  }

  async updateStatus(id: string, status: string) {
    const validStatuses = ['todo', 'in_progress', 'done'];
    if (!validStatuses.includes(status)) {
      throw new ValidationError(`Invalid status: ${status}`);
    }

    await this.getTaskById(id);

    const [updated] = await db
      .update(tasks)
      .set({ status, updatedAt: new Date() })
      .where(eq(tasks.id, id))
      .returning();

    return updated;
  }

  async getProjectStats() {
    const stats = await db
      .select({
        totalTasks: count(),
        completedTasks: count(
          sql`CASE WHEN ${tasks.status} = 'done' THEN 1 END`
        ),
        inProgressTasks: count(
          sql`CASE WHEN ${tasks.status} = 'in_progress' THEN 1 END`
        ),
        overdueTasks: count(
          sql`CASE WHEN ${tasks.dueDate} < NOW()
                AND ${tasks.status} != 'done' THEN 1 END`
        ),
      })
      .from(tasks);

    const result = stats[0];
    return {
      ...result,
      completionRate: result.totalTasks > 0
        ? result.completedTasks / result.totalTasks
        : 0,
    };
  }
}
```

### 4.3 路由层实现

```typescript
// src/routes/tasks.ts
import { Router } from 'express';
import { TaskService } from '../services/taskService';
import { validate } from '../middleware/validate';
import {
  createTaskSchema,
  updateTaskSchema,
  listTasksSchema,
} from '../services/taskService';

const router = Router();
const taskService = new TaskService();

router.post('/', validate(createTaskSchema), async (req, res, next) => {
  try {
    const task = await taskService.createTask(req.body);
    res.status(201).json(task);
  } catch (error) {
    next(error);
  }
});

router.get('/', validate(listTasksSchema, 'query'), async (req, res, next) => {
  try {
    const result = await taskService.listTasks(req.query as any);
    res.json(result);
  } catch (error) {
    next(error);
  }
});

router.get('/:id', async (req, res, next) => {
  try {
    const task = await taskService.getTaskById(req.params.id);
    res.json(task);
  } catch (error) {
    next(error);
  }
});

router.patch('/:id', validate(updateTaskSchema), async (req, res, next) => {
  try {
    const task = await taskService.updateTask(req.params.id, req.body);
    res.json(task);
  } catch (error) {
    next(error);
  }
});

router.delete('/:id', async (req, res, next) => {
  try {
    await taskService.deleteTask(req.params.id);
    res.status(204).send();
  } catch (error) {
    next(error);
  }
});

router.patch('/:id/status', async (req, res, next) => {
  try {
    const task = await taskService.updateStatus(
      req.params.id,
      req.body.status
    );
    res.json(task);
  } catch (error) {
    next(error);
  }
});

export default router;
```

## 8. 常见误区

### ❌ 错误 1：完全依赖 AI 生成的代码不做审查
AI 生成的代码可能存在逻辑错误、安全漏洞或不符合项目规范。**必须逐行审查**。

### ❌ 错误 2：一次性让 AI 生成整个项目
大段代码生成容易出现不一致。应该**分模块生成**，每生成一个模块就验证和集成。

### ❌ 错误 3：忽略 AI 输出中的安全问题
AI 可能生成包含 SQL 注入、XSS 漏洞的代码。**始终进行安全审查**。

### ❌ 错误 4：不给 AI 足够的上下文
没有提供项目现有的代码风格、依赖版本等信息，导致生成的代码无法集成。

### ❌ 错误 5：跳过测试因为"AI 写的应该没问题"
AI 生成的代码同样需要测试。**测试不是可选的**。

---

## 9. 工程建议

1. **分模块生成，逐步集成**：不要让 AI 一次性生成整个项目。按模块（数据库 schema → Service → 路由 → 测试）逐个生成，每完成一个模块就运行测试验证，确保每一步都是可工作的。

2. **给 AI 提供足够上下文**：在提示词中包含项目的技术栈版本、代码风格规范、现有的目录结构和依赖列表。上下文越具体，AI 生成的代码越容易直接集成，减少后期调整成本。

3. **审查优先级：安全 > 逻辑 > 风格**：面对 AI 生成的大量代码，审查时按优先级排序。先检查 SQL 注入、XSS 等安全问题，再验证业务逻辑是否正确，最后才是代码风格和命名。

4. **保留架构决策记录**：当 AI 建议了某个技术方案（如选择 PostgreSQL 而非 MongoDB），用 ADR 记录决策过程和理由。半年后团队新成员加入时，这些记录比代码本身更有价值。

### 练习 2：完整 CRUD 实现（45 分钟）

**思路**：参考 TaskService 的实现模式，用 Zod 做输入验证，用 Drizzle ORM 做数据库操作，Service 层封装业务逻辑，最后编写单元测试。

**答案**：

```typescript
// src/services/commentService.ts
import { db } from '../db';
import { comments } from '../db/schema';
import { eq, and, count, desc } from 'drizzle-orm';
import { z } from 'zod';
import { NotFoundError, ValidationError } from '../utils/errors';

export const createCommentSchema = z.object({
  taskId: z.string().uuid(),
  content: z.string().min(1).max(2000),
});

export const listCommentsSchema = z.object({
  taskId: z.string().uuid(),
  page: z.coerce.number().int().min(1).default(1),
  pageSize: z.coerce.number().int().min(1).max(50).default(20),
});

export class CommentService {
  async createComment(userId: string, data: z.infer<typeof createCommentSchema>) {
    const validated = createCommentSchema.parse(data);

    const [comment] = await db
      .insert(comments)
      .values({
        taskId: validated.taskId,
        userId,
        content: validated.content,
      })
      .returning();

    return comment;
  }

  async listComments(filters: z.infer<typeof listCommentsSchema>) {
    const validated = listCommentsSchema.parse(filters);

    const [{ total }] = await db
      .select({ total: count() })
      .from(comments)
      .where(eq(comments.taskId, validated.taskId));

    const data = await db
      .select()
      .from(comments)
      .where(eq(comments.taskId, validated.taskId))
      .orderBy(desc(comments.createdAt))
      .limit(validated.pageSize)
      .offset((validated.page - 1) * validated.pageSize);

    return {
      data,
      pagination: {
        page: validated.page,
        pageSize: validated.pageSize,
        total,
        totalPages: Math.ceil(total / validated.pageSize),
      },
    };
  }

  async deleteComment(commentId: string, userId: string) {
    const [comment] = await db
      .select()
      .from(comments)
      .where(eq(comments.id, commentId))
      .limit(1);

    if (!comment) {
      throw new NotFoundError(`Comment ${commentId} not found`);
    }
    if (comment.userId !== userId) {
      throw new ValidationError('You can only delete your own comments');
    }

    await db.delete(comments).where(eq(comments.id, commentId));
  }
}
```
