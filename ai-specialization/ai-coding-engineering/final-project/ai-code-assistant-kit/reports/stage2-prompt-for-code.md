## 常见误区

1. **Prompt 过于模糊**：只说"写一个函数"而不说明输入输出、边界条件和错误处理，导致 AI 生成的代码需要大量修改
2. **一次性要求过多功能**：把多个复杂需求塞进一个 Prompt，AI 容易遗漏部分要求或生成结构混乱的代码
3. **忽略示例驱动的 Prompt 设计**：不提供输入输出示例，AI 难以理解你期望的具体格式和行为
4. **不迭代 Prompt**：第一次生成不满意就放弃，而不是根据输出结果调整 Prompt 的约束条件和上下文

## 工程建议

1. **建立团队 Prompt 模板库**：将验证过的高质量 Prompt 按场景分类（代码生成、代码审查、重构、测试），统一管理并持续优化
2. **采用渐进式 Prompt 策略**：先让 AI 生成骨架代码，再逐步添加约束和细节，比一次性要求完美输出更高效
3. **在 Prompt 中注入项目上下文**：提供相关文件路径、技术栈版本、编码规范等信息，让 AI 生成的代码与项目风格一致
4. **量化 Prompt 效果**：记录不同 Prompt 的生成成功率、需要修改的行数等指标，用数据驱动 Prompt 优化
