# 课时 10：AI 图表推荐——根据数据特征自动推荐图表类型

## 场景引入

你为公司的 BI 系统接入了 NL2SQL 功能，用户可以直接用自然语言查询数据并拿到结果表格。但产品经理提出了新需求："用户查完数据后，能不能自动推荐最合适的图表类型？不是让用户自己选柱状图还是折线图，而是系统直接告诉他们用什么图最合适。"

这个问题比想象中复杂。一张包含"月份"和"销售额"的数据表，用折线图展示趋势是合适的；但如果数据是"产品类别"和"销售额"，用柱状图对比更直观；如果还要加一个"利润率"维度，可能气泡图更合适。

图表类型的选择不是随意的，它取决于数据本身的特征：有多少个维度？维度的数据类型是什么？数据的分布形态如何？用户想表达什么信息？

本课时将讲解如何构建一个智能图表推荐引擎，从数据特征提取、规则引擎、机器学习模型到 LLM 推荐，逐步构建一个完整的解决方案。

## 核心概念

### 1. 图表推荐的问题定义

图表推荐本质上是一个**条件分类问题**：给定数据的结构和特征，从候选图表类型中选择最合适的一个（或几个）。

```
┌─────────────────────────────────────────────────────────┐
│                 图表推荐的输入和输出                       │
│                                                         │
│  输入：                                                  │
│  ┌──────────────────────────────────┐                   │
│  │ 数据表                           │                   │
│  │ ┌──────┬──────────┬────────┐    │                   │
│  │ │ 月份  │ 销售额    │ 利润率  │    │                   │
│  │ ├──────┼──────────┼────────┤    │                   │
│  │ │ 1月  │ 120万    │ 15%    │    │                   │
│  │ │ 2月  │ 135万    │ 18%    │    │                   │
│  │ │ ...  │ ...      │ ...    │    │                   │
│  │ └──────┴──────────┴────────┘    │                   │
│  │ + 用户查询意图（可选）              │                   │
│  └──────────────────────────────────┘                   │
│                     ↓                                   │
│  输出：                                                  │
│  ┌──────────────────────────────────┐                   │
│  │ 推荐结果（按匹配度排序）            │                   │
│  │ 1. 折线图 (0.95) - 展示趋势       │                   │
│  │ 2. 柱状图 (0.82) - 对比数值       │                   │
│  │ 3. 面积图 (0.71) - 强调累积       │                   │
│  └──────────────────────────────────┘                   │
└─────────────────────────────────────────────────────────┘
```

### 2. 数据特征提取

推荐图表的第一步是理解数据。我们需要从原始数据中提取以下特征：

```
┌─────────────────────────────────────────────────────────┐
│                  数据特征维度                             │
│                                                         │
│  结构特征：                                              │
│  ├── 列数（维度数）                                       │
│  ├── 行数（数据量）                                       │
│  └── 列的数据类型                                         │
│                                                         │
│  语义特征：                                              │
│  ├── 维度类型：时间 / 分类 / 地理 / 层级                   │
│  ├── 度量类型：金额 / 数量 / 比率 / 排名                   │
│  └── 列名语义：通过列名推断含义                            │
│                                                         │
│  统计特征：                                              │
│  ├── 基数（唯一值数量）                                    │
│  ├── 分布形态（正态 / 偏态 / 多峰）                        │
│  ├── 数值范围（最大值 / 最小值）                            │
│  └── 缺失比例                                            │
└─────────────────────────────────────────────────────────┘
```

其中，**维度类型**是最关键的特征。一个列是"时间"还是"分类"，直接决定了图表类型的选择：

| 维度类型 | 识别方法 | 典型列名 | 适合的图表 |
|----------|----------|----------|-----------|
| 时间 | DATE/TIMESTAMP 类型，或包含年月日关键词 | date, created_at, month | 折线图、面积图 |
| 分类 | 低基数的 VARCHAR/TEXT | category, region, type | 柱状图、饼图 |
| 地理 | 包含地名关键词 | province, city, country | 地图、热力图 |
| 数值 | INT/FLOAT/DECIMAL | amount, count, price | 散点图、直方图 |

### 3. 规则引擎 vs 机器学习

图表推荐有两种主流方法：

**规则引擎**：基于数据可视化专家的经验，编写一套 if-else 规则。

```
if 时间维度 and 一个度量:
    推荐折线图
elif 分类维度 and 一个度量 and 基数 <= 8:
    推荐柱状图
elif 分类维度 and 一个度量 and 基数 > 8:
    推荐条形图
elif 两个数值度量:
    推荐散点图
```

优点：可控、可解释、无额外成本。缺点：规则之间容易冲突，难以覆盖所有场景。

**机器学习方法**：训练一个分类器，输入数据特征，输出图表类型。

优点：可以学习复杂的模式，自动适应新场景。缺点：需要标注数据，模型可能不可解释。

2025 年的最佳实践是**规则引擎 + LLM 的混合方案**：规则引擎处理确定性高的场景（如时间序列 → 折线图），LLM 处理模糊场景（如多维度、多度量的复杂数据）。

### 4. 常见图表类型的适用条件

在构建推荐引擎之前，我们需要明确每种图表类型的适用条件：

```
┌─────────────────────────────────────────────────────────┐
│               图表类型适用条件速查表                       │
├──────────┬───────────────────────────────────────────────┤
│ 折线图    │ 时间维度 + 1-5个度量，展示趋势                  │
│ 柱状图    │ 分类维度（基数≤12）+ 1-3个度量，对比数值         │
│ 条形图    │ 分类维度（基数>12）+ 1个度量，排名对比            │
│ 饼图/环图 │ 分类维度（基数≤6）+ 1个度量，展示占比             │
│ 散点图    │ 2个数值度量，展示相关性                          │
│ 气泡图    │ 3个数值度量，展示多维关系                         │
│ 面积图    │ 时间维度 + 1-3个度量，展示趋势和累积              │
│ 热力图    │ 2个分类维度 + 1个度量，展示矩阵关系               │
│ 雷达图    │ 3-10个度量，展示多维对比                         │
│ 树图      │ 层级维度 + 1个度量，展示层级占比                  │
│ 桑基图    │ 源维度 + 目标维度 + 流量度量，展示流转             │
│ 箱线图    │ 分类维度 + 1个度量，展示分布                      │
└──────────┴───────────────────────────────────────────────┘
```

### 第一步：数据特征提取器

```python
"""
chart_recommender/feature_extractor.py
从原始数据中自动提取图表推荐所需的特征
"""

import re
from dataclasses import dataclass, field
from enum import Enum
from typing import Optional

import numpy as np
import pandas as pd


class DimensionType(Enum):
    """维度类型"""
    TEMPORAL = "temporal"      # 时间维度
    CATEGORICAL = "categorical"  # 分类维度
    GEOGRAPHIC = "geographic"  # 地理维度
    NUMERICAL = "numerical"    # 数值维度
    IDENTIFIER = "identifier"  # 标识符（通常不用于可视化）


class MeasureType(Enum):
    """度量类型"""
    AMOUNT = "amount"       # 金额
    COUNT = "count"         # 数量
    RATIO = "ratio"         # 比率
    RANKING = "ranking"     # 排名
    DURATION = "duration"   # 时长


@dataclass
class ColumnFeature:
    """单列的特征"""
    name: str
    dtype: str
    dimension_type: DimensionType
    measure_type: Optional[MeasureType] = None
    cardinality: int = 0
    null_ratio: float = 0.0
    sample_values: list = field(default_factory=list)
    is_time_series: bool = False
    is_sorted: bool = False
    min_value: Optional[float] = None
    max_value: Optional[float] = None
    mean_value: Optional[float] = None
    std_value: Optional[float] = None
    distribution_skew: Optional[float] = None


@dataclass
class DataProfile:
    """数据集的整体特征"""
    row_count: int
    column_count: int
    columns: list[ColumnFeature]
    has_time_dimension: bool = False
    time_column: Optional[str] = None
    categorical_columns: list[str] = field(default_factory=list)
    numerical_columns: list[str] = field(default_factory=list)
    geographic_columns: list[str] = field(default_factory=list)


class FeatureExtractor:
    """数据特征提取器"""

    # 时间列名模式
    TIME_PATTERNS = [
        r".*_at$", r".*_date$", r".*_time$", r".*timestamp.*",
        r"^date$", r"^time$", r"^month$", r"^year$", r"^quarter$",
        r"^created$", r"^updated$", r"^日期$", r"^时间$", r"^月份$",
    ]

    # 地理列名模式
    GEO_PATTERNS = [
        r".*province.*", r".*city.*", r".*country.*", r".*region.*",
        r".*address.*", r".*location.*", r".*lat.*", r".*lng.*",
        r"^省$", r"^市$", r"^区$", r"^地址$", r"^区域$",
    ]

    # 标识符列名模式
    ID_PATTERNS = [
        r"^id$", r".*_id$", r"^uuid$", r".*guid.*",
    ]

    # 金额/比率列名模式
    AMOUNT_PATTERNS = [
        r".*amount.*", r".*price.*", r".*cost.*", r".*revenue.*",
        r".*sales.*", r".*total.*", r".*金额$", r".*价格$", r".*销售额$",
    ]

    RATIO_PATTERNS = [
        r".*rate.*", r".*ratio.*", r".*percent.*", r".*率$",
        r".*占比$", r".*比例$",
    ]

    def extract(self, df: pd.DataFrame) -> DataProfile:
        """从 DataFrame 中提取完整的数据特征"""
        columns = []
        for col_name in df.columns:
            col_feature = self._extract_column_feature(df, col_name)
            columns.append(col_feature)

        profile = DataProfile(
            row_count=len(df),
            column_count=len(df.columns),
            columns=columns,
        )

        # 汇总维度信息
        for col in columns:
            if col.dimension_type == DimensionType.TEMPORAL:
                profile.has_time_dimension = True
                profile.time_column = col.name
            elif col.dimension_type == DimensionType.CATEGORICAL:
                profile.categorical_columns.append(col.name)
            elif col.dimension_type == DimensionType.NUMERICAL:
                profile.numerical_columns.append(col.name)
            elif col.dimension_type == DimensionType.GEOGRAPHIC:
                profile.geographic_columns.append(col.name)

        return profile

    def _extract_column_feature(
        self, df: pd.DataFrame, col_name: str
    ) -> ColumnFeature:
        """提取单列的特征"""
        series = df[col_name]
        col_lower = col_name.lower()

        feature = ColumnFeature(
            name=col_name,
            dtype=str(series.dtype),
            cardinality=series.nunique(),
            null_ratio=series.isnull().mean(),
            sample_values=series.dropna().head(5).tolist(),
        )

        # 判断维度类型
        if self._matches_any(col_lower, self.ID_PATTERNS):
            feature.dimension_type = DimensionType.IDENTIFIER
        elif self._matches_any(col_lower, self.TIME_PATTERNS):
            feature.dimension_type = DimensionType.TEMPORAL
            feature.is_time_series = True
        elif self._matches_any(col_lower, self.GEO_PATTERNS):
            feature.dimension_type = DimensionType.GEOGRAPHIC
        elif pd.api.types.is_numeric_dtype(series):
            feature.dimension_type = DimensionType.NUMERICAL
            feature.min_value = float(series.min()) if not series.empty else None
            feature.max_value = float(series.max()) if not series.empty else None
            feature.mean_value = float(series.mean()) if not series.empty else None
            feature.std_value = float(series.std()) if not series.empty else None
            feature.distribution_skew = float(series.skew()) if len(series) > 2 else None
        else:
            # 低基数视为分类，高基数可能是文本或标识符
            if feature.cardinality <= max(20, len(df) * 0.05):
                feature.dimension_type = DimensionType.CATEGORICAL
            else:
                feature.dimension_type = DimensionType.CATEGORICAL  # 保守判断

        # 判断度量类型
        if feature.dimension_type == DimensionType.NUMERICAL:
            if self._matches_any(col_lower, self.AMOUNT_PATTERNS):
                feature.measure_type = MeasureType.AMOUNT
            elif self._matches_any(col_lower, self.RATIO_PATTERNS):
                feature.measure_type = MeasureType.RATIO
            elif self._matches_any(col_lower, [r".*count.*", r".*num.*", r".*数量$"]):
                feature.measure_type = MeasureType.COUNT
            else:
                feature.measure_type = MeasureType.AMOUNT  # 默认为金额

        # 检查时间列是否有序
        if feature.dimension_type == DimensionType.TEMPORAL:
            try:
                pd.to_datetime(series)
                feature.is_time_series = True
            except (ValueError, TypeError):
                pass

        return feature

    @staticmethod
    def _matches_any(text: str, patterns: list[str]) -> bool:
        """检查文本是否匹配任意一个模式"""
        return any(re.match(p, text, re.IGNORECASE) for p in patterns)
```

### 第二步：规则推荐引擎

```python
"""
chart_recommender/rule_engine.py
基于规则的图表推荐引擎
"""

from dataclasses import dataclass
from chart_recommender.feature_extractor import (
    DataProfile, ColumnFeature, DimensionType, MeasureType,
)


@dataclass
class ChartRecommendation:
    """图表推荐结果"""
    chart_type: str
    confidence: float
    reason: str
    x_axis: str | None = None
    y_axis: str | None = None
    color_by: str | None = None
    size_by: str | None = None


class RuleEngine:
    """基于规则的图表推荐引擎"""

    def recommend(self, profile: DataProfile) -> list[ChartRecommendation]:
        """根据数据特征推荐图表类型"""
        recommendations = []

        # 获取各类维度和度量
        time_cols = [c for c in profile.columns if c.dimension_type == DimensionType.TEMPORAL]
        cat_cols = [c for c in profile.columns if c.dimension_type == DimensionType.CATEGORICAL]
        num_cols = [c for c in profile.columns if c.dimension_type == DimensionType.NUMERICAL]
        geo_cols = [c for c in profile.columns if c.dimension_type == DimensionType.GEOGRAPHIC]

        # 规则 1：时间序列 → 折线图 / 面积图
        if time_cols and num_cols:
            time_col = time_cols[0]
            for num_col in num_cols[:3]:
                recommendations.append(ChartRecommendation(
                    chart_type="line",
                    confidence=0.9,
                    reason=f"{time_col.name} 是时间维度，{num_col.name} 随时间变化，适合用折线图展示趋势",
                    x_axis=time_col.name,
                    y_axis=num_col.name,
                ))
            if len(num_cols) >= 2:
                recommendations.append(ChartRecommendation(
                    chart_type="area",
                    confidence=0.75,
                    reason=f"多个度量随时间变化，面积图可以展示趋势和累积效果",
                    x_axis=time_col.name,
                    y_axis=num_cols[0].name,
                ))

        # 规则 2：分类 + 数值 → 柱状图 / 条形图 / 饼图
        if cat_cols and num_cols:
            cat_col = cat_cols[0]
            num_col = num_cols[0]

            if cat_col.cardinality <= 8:
                recommendations.append(ChartRecommendation(
                    chart_type="bar",
                    confidence=0.85,
                    reason=f"{cat_col.name} 只有 {cat_col.cardinality} 个类别，适合用柱状图对比",
                    x_axis=cat_col.name,
                    y_axis=num_col.name,
                ))
                if cat_col.cardinality <= 6:
                    recommendations.append(ChartRecommendation(
                        chart_type="pie",
                        confidence=0.7,
                        reason=f"{cat_col.name} 类别数少，适合用饼图展示占比",
                        x_axis=cat_col.name,
                        y_axis=num_col.name,
                    ))
            else:
                recommendations.append(ChartRecommendation(
                    chart_type="horizontal_bar",
                    confidence=0.85,
                    reason=f"{cat_col.name} 有 {cat_col.cardinality} 个类别，用条形图避免标签重叠",
                    x_axis=num_col.name,
                    y_axis=cat_col.name,
                ))

        # 规则 3：两个数值 → 散点图
        if len(num_cols) >= 2:
            recommendations.append(ChartRecommendation(
                chart_type="scatter",
                confidence=0.8,
                reason=f"{num_cols[0].name} 和 {num_cols[1].name} 的相关性可以用散点图展示",
                x_axis=num_cols[0].name,
                y_axis=num_cols[1].name,
            ))

            # 三个数值 → 气泡图
            if len(num_cols) >= 3:
                recommendations.append(ChartRecommendation(
                    chart_type="bubble",
                    confidence=0.65,
                    reason=f"三个数值维度可以用气泡图展示多维关系",
                    x_axis=num_cols[0].name,
                    y_axis=num_cols[1].name,
                    size_by=num_cols[2].name,
                ))

        # 规则 4：两个分类 + 数值 → 热力图
        if len(cat_cols) >= 2 and num_cols:
            recommendations.append(ChartRecommendation(
                chart_type="heatmap",
                confidence=0.75,
                reason=f"{cat_cols[0].name} 和 {cat_cols[1].name} 的交叉关系可以用热力图展示",
                x_axis=cat_cols[0].name,
                y_axis=cat_cols[1].name,
            ))

        # 规则 5：地理维度 → 地图
        if geo_cols and num_cols:
            recommendations.append(ChartRecommendation(
                chart_type="map",
                confidence=0.9,
                reason=f"{geo_cols[0].name} 是地理维度，适合用地图展示空间分布",
                x_axis=geo_cols[0].name,
                y_axis=num_cols[0].name,
            ))

        # 规则 6：单列数值分布 → 直方图 / 箱线图
        if len(num_cols) == 1 and not cat_cols and not time_cols:
            recommendations.append(ChartRecommendation(
                chart_type="histogram",
                confidence=0.8,
                reason=f"单个数值列 {num_cols[0].name}，适合用直方图展示分布",
                x_axis=num_cols[0].name,
            ))

        # 规则 7：分类 + 数值（用于分布展示）→ 箱线图
        if cat_cols and num_cols and cat_cols[0].cardinality <= 10:
            recommendations.append(ChartRecommendation(
                chart_type="boxplot",
                confidence=0.6,
                reason=f"按 {cat_cols[0].name} 分组展示 {num_cols[0].name} 的分布",
                x_axis=cat_cols[0].name,
                y_axis=num_cols[0].name,
            ))

        # 规则 8：多度量对比 → 雷达图
        if len(num_cols) >= 3 and cat_cols and cat_cols[0].cardinality <= 1:
            recommendations.append(ChartRecommendation(
                chart_type="radar",
                confidence=0.6,
                reason=f"多个度量的综合对比适合用雷达图",
            ))

        # 按置信度排序
        recommendations.sort(key=lambda r: r.confidence, reverse=True)
        return recommendations
```

### 第三步：LLM 推荐器

```python
"""
chart_recommender/llm_recommender.py
基于 LLM 的图表推荐器，处理规则引擎难以覆盖的复杂场景
"""

import json
from openai import OpenAI
from chart_recommender.feature_extractor import DataProfile
from chart_recommender.rule_engine import ChartRecommendation


CHART_TYPES = [
    "line", "bar", "horizontal_bar", "pie", "donut",
    "scatter", "bubble", "area", "stacked_bar",
    "heatmap", "treemap", "radar", "funnel",
    "boxplot", "histogram", "map", "sankey",
    "waterfall", "gauge", "kpi_card",
]


class LLMRecommender:
    """基于 LLM 的图表推荐器"""

    def __init__(self, model: str = "gpt-4o-mini"):
        self.client = OpenAI()
        self.model = model

    def recommend(
        self,
        profile: DataProfile,
        user_query: str | None = None,
        top_k: int = 5,
    ) -> list[ChartRecommendation]:
        """使用 LLM 推荐图表类型"""

        # 构建数据描述
        data_desc = self._build_data_description(profile)

        prompt = f"""你是一个数据可视化专家。根据以下数据特征，推荐最合适的图表类型。

数据概况:
- 行数: {profile.row_count}
- 列数: {profile.column_count}

列信息:
{data_desc}

{f'用户查询意图: {user_query}' if user_query else ''}

可选的图表类型: {', '.join(CHART_TYPES)}

请推荐 {top_k} 个最合适的图表类型，返回 JSON 格式:
{{
  "recommendations": [
    {{

"""
chart_recommender/hybrid_engine.py
混合推荐引擎：规则引擎 + LLM 推荐的融合
"""

from chart_recommender.feature_extractor import DataProfile, FeatureExtractor
from chart_recommender.rule_engine import RuleEngine, ChartRecommendation
from chart_recommender.llm_recommender import LLMRecommender

import pandas as pd


class HybridRecommendationEngine:
    """混合图表推荐引擎"""

    def __init__(self, use_llm: bool = True, llm_model: str = "gpt-4o-mini"):
        self.feature_extractor = FeatureExtractor()
        self.rule_engine = RuleEngine()
        self.llm_recommender = LLMRecommender(model=llm_model) if use_llm else None

    def recommend(
        self,
        df: pd.DataFrame,
        user_query: str | None = None,
        top_k: int = 5,
    ) -> list[ChartRecommendation]:
        """完整的图表推荐流程"""

        # Step 1: 提取数据特征
        profile = self.feature_extractor.extract(df)

        # Step 2: 规则引擎推荐
        rule_results = self.rule_engine.recommend(profile)

        # Step 3: 如果规则引擎结果置信度高，直接返回
        if rule_results and rule_results[0].confidence >= 0.85:
            return rule_results[:top_k]

        # Step 4: LLM 推荐（用于复杂场景）
        llm_results = []
        if self.llm_recommender:
            llm_results = self.llm_recommender.recommend(
                profile, user_query, top_k
            )

        # Step 5: 融合结果
        merged = self._merge_recommendations(rule_results, llm_results)
        return merged[:top_k]

    @staticmethod
    def _merge_recommendations(
        rule_results: list[ChartRecommendation],
        llm_results: list[ChartRecommendation],
    ) -> list[ChartRecommendation]:
        """融合规则引擎和 LLM 的推荐结果"""

        # 按图表类型合并，取最高置信度
        merged: dict[str, ChartRecommendation] = {}

        for rec in rule_results:
            if rec.chart_type not in merged or rec.confidence > merged[rec.chart_type].confidence:
                merged[rec.chart_type] = rec

        for rec in llm_results:
            if rec.chart_type in merged:
                # 如果两边都推荐了，加权提升置信度
                existing = merged[rec.chart_type]
                merged[rec.chart_type] = ChartRecommendation(
                    chart_type=rec.chart_type,
                    confidence=min(0.99, (existing.confidence + rec.confidence) / 2 * 1.1),
                    reason=f"{existing.reason}（LLM 补充：{rec.reason}）",
                    x_axis=rec.x_axis or existing.x_axis,
                    y_axis=rec.y_axis or existing.y_axis,
                    color_by=rec.color_by or existing.color_by,
                    size_by=rec.size_by or existing.size_by,
                )
            else:
                merged[rec.chart_type] = rec

        # 按置信度排序
        results = sorted(merged.values(), key=lambda r: r.confidence, reverse=True)
        return results

"""
chart_recommender/chart_config.py
根据推荐结果生成 ECharts / Plotly 等图表库的配置

from chart_recommender.rule_engine import ChartRecommendation
import pandas as pd


class ChartConfigGenerator:
    """根据推荐结果生成图表配置"""

    def generate_echarts_option(
        self,
        recommendation: ChartRecommendation,
        df: pd.DataFrame,
    ) -> dict:
        """生成 ECharts 的 option 配置"""

        chart_type = recommendation.chart_type

        if chart_type == "line":
            return self._line_chart(recommendation, df)
        elif chart_type == "bar":
            return self._bar_chart(recommendation, df)
        elif chart_type == "pie":
            return self._pie_chart(recommendation, df)
        elif chart_type == "scatter":
            return self._scatter_chart(recommendation, df)
        elif chart_type == "heatmap":
            return self._heatmap_chart(recommendation, df)
        else:
            return self._generic_chart(recommendation, df)

    def _line_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        x_data = sorted(df[rec.x_axis].unique().tolist())
        series_data = []
        y_col = rec.y_axis

        if rec.color_by:
            groups = df.groupby(rec.color_by)
            for name, group in groups:
                values = []
                for x in x_data:
                    match = group[group[rec.x_axis] == x]
                    values.append(float(match[y_col].iloc[0]) if not match.empty else 0)
                series_data.append({"name": str(name), "type": "line", "data": values})
        else:
            values = []
            for x in x_data:
                match = df[df[rec.x_axis] == x]
                values.append(float(match[y_col].iloc[0]) if not match.empty else 0)
            series_data.append({"name": y_col, "type": "line", "data": values})

        return {
            "title": {"text": f"{y_col} 趋势"},
            "tooltip": {"trigger": "axis"},
            "xAxis": {"type": "category", "data": x_data, "name": rec.x_axis},
            "yAxis": {"type": "value", "name": y_col},
            "series": series_data,
        }

    def _bar_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        x_data = df[rec.x_axis].unique().tolist()
        y_values = df.groupby(rec.x_axis)[rec.y_axis].sum().reindex(x_data).tolist()

        return {
            "title": {"text": f"{rec.y_axis} 按 {rec.x_axis} 对比"},
            "tooltip": {"trigger": "axis"},
            "xAxis": {"type": "category", "data": x_data, "name": rec.x_axis},
            "yAxis": {"type": "value", "name": rec.y_axis},
            "series": [{"name": rec.y_axis, "type": "bar", "data": y_values}],
        }

    def _pie_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        grouped = df.groupby(rec.x_axis)[rec.y_axis].sum()
        data = [{"name": str(k), "value": float(v)} for k, v in grouped.items()]

        return {
            "title": {"text": f"{rec.y_axis} 占比"},
            "tooltip": {"trigger": "item"},
            "series": [{"type": "pie", "data": data, "radius": ["40%", "70%"]}],
        }

    def _scatter_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        data = df[[rec.x_axis, rec.y_axis]].dropna().values.tolist()

        return {
            "title": {"text": f"{rec.x_axis} vs {rec.y_axis}"},
            "tooltip": {"trigger": "item"},
            "xAxis": {"type": "value", "name": rec.x_axis},
            "yAxis": {"type": "value", "name": rec.y_axis},
            "series": [{"type": "scatter", "data": data}],
        }

    def _heatmap_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        x_cats = sorted(df[rec.x_axis].unique().tolist())
        y_cats = sorted(df[rec.y_axis].unique().tolist())

        data = []
        for y_idx, y in enumerate(y_cats):
            for x_idx, x in enumerate(x_cats):
                match = df[(df[rec.x_axis] == x) & (df[rec.y_axis] == y)]
                value = float(match.iloc[0, -1]) if not match.empty else 0
                data.append([x_idx, y_idx, value])

        return {
            "title": {"text": f"{rec.x_axis} × {rec.y_axis} 热力图"},
            "tooltip": {"trigger": "item"},
            "xAxis": {"type": "category", "data": x_cats},
            "yAxis": {"type": "category", "data": y_cats},
            "visualMap": {"min": 0, "max": max(d[2] for d in data) if data else 1},
            "series": [{"type": "heatmap", "data": data}],
        }

    def _generic_chart(self, rec: ChartRecommendation, df: pd.DataFrame) -> dict:
        return {
            "title": {"text": f"{rec.chart_type} 图表"},
            "note": f"图表类型 {rec.chart_type} 的配置生成尚未实现，请手动配置",
        }

## 常见误区

### 误区 1：饼图万能论

很多人习惯用饼图展示一切分类数据。但饼图有几个严重限制：
- 当类别超过 6 个时，扇区太小难以区分
- 人眼对角度的判断不如对长度的判断准确
- 不适合对比多个时间点的变化

正确的做法是：类别少（≤6）且强调占比关系时用饼图，其他场景优先用柱状图。

### 误区 2：忽视数据基数

数据基数（唯一值数量）是图表选择的关键因素。一个有 50 个类别的柱状图会非常拥挤，应该换成条形图或先做聚合。一个只有 2 个类别的饼图又显得多余，不如用 KPI 卡片展示。

### 误区 3：混淆相关性和因果性

散点图可以展示两个变量的相关性，但推荐引擎不应该暗示因果关系。如果用户的数据存在混淆变量，散点图可能会误导。推荐理由应该中性地描述"展示关系"，而不是"X 影响 Y"。

### 误区 4：忽略用户意图

同一个数据集，不同用户可能有不同的分析意图。销售数据可以看趋势（折线图）、看对比（柱状图）、看占比（饼图）、看分布（箱线图）。如果系统只根据数据特征推荐，而不考虑用户的查询意图，推荐结果可能不符合用户预期。

### 误区 5：过度依赖 LLM

LLM 在图表推荐上的表现不如预期稳定。它可能会推荐不合适的图表类型（如用桑基图展示简单的分类对比），或者给出错误的轴配置。最佳实践是用规则引擎兜底，LLM 只用于规则覆盖不到的复杂场景。

## 小结

本课时的核心要点：

1. **图表推荐是条件分类问题**：输入数据特征，输出最合适的图表类型
2. **数据特征提取是基础**：维度类型（时间/分类/地理/数值）比数据类型（int/varchar）更重要
3. **规则引擎覆盖 80% 的场景**：时间→折线图、分类+数值→柱状图、两数值→散点图
4. **LLM 处理复杂场景**：多维度、多度量、有歧义的数据，用 LLM 做补充推荐
5. **推荐结果需要解释**：告诉用户"为什么推荐这个图"比推荐本身更有价值
6. **置信度排序是关键**：多个推荐结果按置信度排序，让用户有选择的空间

图表推荐的目标不是"强制用户用某个图"，而是"帮用户快速找到合适的图"。一个好的推荐引擎应该让用户觉得"这个系统懂数据可视化"。

def _check_funnel(self, profile: DataProfile, df: pd.DataFrame) -> list[ChartRecommendation]:
    """检测是否适合漏斗图"""
    recs = []
    cat_cols = [c for c in profile.columns if c.dimension_type == DimensionType.CATEGORICAL]
    num_cols = [c for c in profile.columns if c.dimension_type == DimensionType.NUMERICAL]

    if cat_cols and num_cols:
        cat_col = cat_cols[0]
        num_col = num_cols[0]

        # 检查数值是否递减（漏斗特征）
        if cat_col.cardinality >= 3 and cat_col.cardinality <= 8:
            grouped = df.groupby(cat_col.name)[num_col.name].sum().sort_values(ascending=False)
            values = grouped.tolist()
            # 检查是否大致递减
            decreasing_count = sum(1 for i in range(len(values)-1) if values[i] >= values[i+1])
            if decreasing_count >= len(values) * 0.7:
                recs.append(ChartRecommendation(
                    chart_type="funnel",
                    confidence=0.75,
                    reason=f"{num_col.name} 按 {cat_col.name} 呈递减趋势，适合用漏斗图展示转化过程",
                    x_axis=cat_col.name,
                    y_axis=num_col.name,
                ))
    return recs

# 规则 10：瀑布图 - 增减变化数据
def _check_waterfall(self, profile: DataProfile, df: pd.DataFrame) -> list[ChartRecommendation]:
    """检测是否适合瀑布图"""
    recs = []
    cat_cols = [c for c in profile.columns if c.dimension_type == DimensionType.CATEGORICAL]
    num_cols = [c for c in profile.columns if c.dimension_type == DimensionType.NUMERICAL]

    if cat_cols and num_cols:
        num_col = num_cols[0]
        # 检查数值是否有正有负（增减特征）
        values = df[num_col.name].dropna()
        has_positive = (values > 0).any()
        has_negative = (values < 0).any()
        if has_positive and has_negative:
            recs.append(ChartRecommendation(
                chart_type="waterfall",
                confidence=0.7,
                reason=f"{num_col.name} 包含正值和负值，适合用瀑布图展示增减变化",
                x_axis=cat_cols[0].name,
                y_axis=num_col.name,
            ))
    return recs

# 规则 11：仪表盘 - 单个 KPI 达成率
def _check_gauge(self, profile: DataProfile, df: pd.DataFrame) -> list[ChartRecommendation]:
    """检测是否适合仪表盘"""
    recs = []
    num_cols = [c for c in profile.columns if c.dimension_type == DimensionType.NUMERICAL]

    # 单行数据 + 比率列 → 仪表盘
    if profile.row_count == 1 and num_cols:
        for num_col in num_cols:
            if num_col.measure_type == MeasureType.RATIO:
                value = float(df[num_col.name].iloc[0])
                if 0 <= value <= 1:
                    recs.append(ChartRecommendation(
                        chart_type="gauge",
                        confidence=0.85,
                        reason=f"{num_col.name} 是单个比率值 ({value:.1%})，适合用仪表盘展示达成率",
                        y_axis=num_col.name,
                    ))
    return recs
```

**要点**：
- 漏斗图的检测关键是"数值递减"特征
- 瀑布图的检测关键是"正负混合"特征
- 仪表盘的检测关键是"单值比率"特征
- 这些规则应该集成到 `recommend` 方法中，与其他规则一起排序

### 练习二

**思路**：实现一个意图分类器，将用户查询映射到具体的分析意图，然后根据意图调整图表推荐的权重。

**答案**：

```python
"""
chart_recommender/intent_classifier.py
用户意图分类器
"""

import re
from enum import Enum
from dataclasses import dataclass


class AnalysisIntent(Enum):
    """分析意图类型"""
    TREND = "trend"          # 趋势分析
    COMPARISON = "comparison"  # 对比分析
    PROPORTION = "proportion"  # 占比分析
    DISTRIBUTION = "distribution"  # 分布分析
    CORRELATION = "correlation"  # 相关性分析
    RANKING = "ranking"      # 排名分析
    UNKNOWN = "unknown"


@dataclass
class IntentResult:
    """意图识别结果"""
    intent: AnalysisIntent
    confidence: float
    matched_keywords: list[str]


class IntentClassifier:
    """用户意图分类器"""

    INTENT_KEYWORDS = {
        AnalysisIntent.TREND: [
            "趋势", "变化", "走势", "增长", "下降", "波动",
            "趋势图", "时间序列", "历史", "演变", "发展",
            "trend", "change", "growth", "decline",
        ],
        AnalysisIntent.COMPARISON: [
            "对比", "比较", "哪个", "谁更", "差别", "差异",
            "高", "低", "多", "少", "优", "劣",
            "compare", "vs", "versus", "difference",
        ],
        AnalysisIntent.PROPORTION: [
            "占比", "比例", "份额", "构成", "组成", "比重",
            "百分比", "多少%", "饼图",
            "proportion", "share", "percentage", "composition",
        ],
        AnalysisIntent.DISTRIBUTION: [
            "分布", "集中", "离散", "分散", "均匀", "偏态",
            "异常", "离群", "箱线",
            "distribution", "spread", "outlier", "cluster",
        ],
        AnalysisIntent.CORRELATION: [
            "相关", "关系", "影响", "关联", "因果",
            "散点", "回归",
            "correlation", "relationship", "scatter",
        ],
        AnalysisIntent.RANKING: [
            "排名", "排行", "TOP", "前几", "最好", "最差",
            "第一", "领先", "垫底",
            "ranking", "top", "best", "worst",
        ],
    }

    # 意图到图表类型的偏好映射
    INTENT_CHART_PREFERENCE = {
        AnalysisIntent.TREND: {
            "line": 1.3, "area": 1.2, "bar": 0.9,
        },
        AnalysisIntent.COMPARISON: {
            "bar": 1.3, "horizontal_bar": 1.2, "radar": 1.1,
        },
        AnalysisIntent.PROPORTION: {
            "pie": 1.4, "donut": 1.3, "treemap": 1.1, "stacked_bar": 1.0,
        },
        AnalysisIntent.DISTRIBUTION: {
            "histogram": 1.3, "boxplot": 1.3, "scatter": 1.0,
        },
        AnalysisIntent.CORRELATION: {
            "scatter": 1.4, "bubble": 1.2,
        },
        AnalysisIntent.RANKING: {
            "horizontal_bar": 1.3, "bar": 1.1,
        },
    }

    def classify(self, query: str) -> IntentResult:
        """分类用户查询的意图"""
        query_lower = query.lower()
        scores: dict[AnalysisIntent, float] = {}
        matched: dict[AnalysisIntent, list[str]] = {}

        for intent, keywords in self.INTENT_KEYWORDS.items():
            score = 0.0
            matches = []
            for kw in keywords:
                if kw.lower() in query_lower:
                    score += 1.0
                    matches.append(kw)
            if score > 0:
                scores[intent] = score
                matched[intent] = matches

        if not scores:
            return IntentResult(
                intent=AnalysisIntent.UNKNOWN,
                confidence=0.0,
                matched_keywords=[],
            )

        best_intent = max(scores, key=scores.get)
        max_score = scores[best_intent]
        confidence = min(0.95, max_score / 3.0)  # 归一化

        return IntentResult(
            intent=best_intent,
            confidence=confidence,
            matched_keywords=matched.get(best_intent, []),
        )

    def adjust_recommendations(
        self,
        recommendations: list,
        intent: IntentResult,
    ) -> list:
        """根据意图调整推荐结果的置信度"""
        if intent.intent == AnalysisIntent.UNKNOWN:
            return recommendations

        preferences = self.INTENT_CHART_PREFERENCE.get(intent.intent, {})

        for rec in recommendations:
            multiplier = preferences.get(rec.chart_type, 1.0)
            # 意图置信度越高，调整幅度越大
            adjustment = 1.0 + (multiplier - 1.0) * intent.confidence
            rec.confidence = min(0.99, rec.confidence * adjustment)

        # 重新排序
        recommendations.sort(key=lambda r: r.confidence, reverse=True)
        return recommendations
```

**要点**：
- 意图分类应该使用关键词匹配 + 置信度的方式，而不是硬分类
- 不同意图对应不同的图表类型偏好，这些偏好作为乘数调整推荐置信度
- 意图置信度越高，对推荐结果的调整幅度越大
- 未识别的意图不应该影响推荐结果

def evaluate(cases: list[ChartEvalCase]) -> dict:
    """评估推荐引擎的效果"""
    engine = RuleEngine()
    extractor = FeatureExtractor()

    top1_correct = 0
    top3_correct = 0
    errors = []

    for case in cases:
        profile = extractor.extract(case.data)
        recommendations = engine.recommend(profile)
        predicted_types = [r.chart_type for r in recommendations]

        is_top1 = predicted_types and predicted_types[0] == case.expected_chart
        is_top3 = case.expected_chart in predicted_types[:3]

        if is_top1:
            top1_correct += 1
        if is_top3:
            top3_correct += 1

        if not is_top1:
            errors.append({
                "name": case.name,
                "expected": case.expected_chart,
                "predicted_top1": predicted_types[0] if predicted_types else "none",
                "predicted_top3": predicted_types[:3],
            })

    n = len(cases)
    return {
        "top1_accuracy": top1_correct / n,
        "top3_accuracy": top3_correct / n,
        "total_cases": n,
        "errors": errors,
    }
