## 场景引入

你是某电商平台的数据分析师。老板让你分析"为什么上个月华南区的 GMV 下降了 15%"。

你打开公司的 Dashboard，看到一张折线图——华南区 GMV 确实下降了。但然后呢？你想按品类拆分，但没有钻取功能。你想看 GMV 和退货率的关联，但两个图表各看各的，没法联动。你想聚焦 11 月 15 到 20 号的异常区间，但图表不支持框选。

最后你花了 3 个小时导出数据、写 SQL、手动拼图表，才勉强给出结论。

问题不在于数据不够，而在于**可视化是静态的**。静态图表只能"展示"数据，交互式可视化才能让你"探索"数据。这两种模式之间的差距，就是分析师 3 小时 vs 10 分钟的差距。

## 核心概念

### 一、展示型 vs 探索型可视化

```
┌─────────────────────────────────────────────────────────────────┐
│  展示型 (Presentation)          探索型 (Exploration)             │
│  ┌───────────────────┐         ┌───────────────────┐            │
│  │  问题已知          │         │  问题未知          │            │
│  │  数据已定          │         │  数据待挖          │            │
│  │  结论预设          │         │  结论待发现        │            │
│  │  "华南区GMV下降"  │         │  "为什么下降？"    │            │
│  │  用户: 接收信息    │         │  用户: 提出问题    │            │
│  │  图表: 单向展示    │         │  图表: 双向交互    │            │
│  └───────────────────┘         └───────────────────┘            │
└─────────────────────────────────────────────────────────────────┘
```

展示型适合汇报、周报。探索型适合分析、排查。大多数 Dashboard 的问题是：**以展示型的方式承载了探索型的需求**。

### 二、五种核心交互模式

```
┌─────────────────────────────────────────────────────────────────┐
│  钻取 Drill-down    维度层次深入  "全国 → 华南 → 广东 → 深圳"    │
│  联动 Linkage       多图表关联    "选中品类 → 其他图表过滤"       │
│  刷选 Brushing      范围选择      "框选时间段 → 高亮对应数据"     │
│  Tooltip            详情悬停      "鼠标悬浮 → 显示详细信息"       │
│  缩放平移 Pan&Zoom   视图导航      "滚轮缩放 + 拖拽平移"          │
└─────────────────────────────────────────────────────────────────┘
```

这些模式经常组合使用：先钻取到某个城市，再刷选时间段，然后通过联动查看该城市在该时段的品类分布。

### 三、钻取（Drill-down）

在维度层次结构中逐层深入。地理维度有"国家 → 省 → 市 → 区"的层次，时间维度有"年 → 季 → 月 → 周 → 日"。

```
┌─────────────────────────────────────────────────────────────────┐
│  Level 0     Level 1     Level 2     Level 3                    │
│  ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐                    │
│  │ 全国  │──▶│ 华南  │──▶│ 广东  │──▶│ 深圳  │                    │
│  │ ¥12亿 │   │ ¥3.2亿│   │ ¥1.8亿│   │ ¥8000万│                   │
│  └──────┘   └──────┘   └──────┘   └──────┘                    │
│     ▲              点击面包屑返回任意层级                         │
└─────────────────────────────────────────────────────────────────┘
```

关键设计决策：
1. **维度层次从哪来？** 从数据库维度表自动推导，或由分析师手动配置
2. **如何表示"可以钻取"？** 悬浮时高亮、指针变化、+ 号图标
3. **如何表示当前位置？** 面包屑导航，支持点击返回任意层级

### 四、图表联动（Linkage）

Dashboard 中多个图表之间的数据关联。用户在某个图表中选择数据子集，其他图表自动过滤。

```
┌─────────────────────────────────────────────────────────────────┐
│  ┌──────────────┐        ┌──────────────┐                       │
│  │  品类饼图      │        │  地区柱状图    │                       │
│  │   ┌───┐       │        │  ████          │                       │
│  │   │数码│ ◀──┐  │  ┌───▶│  ████          │                       │
│  │   └───┘    │  │  │     │  ██            │                       │
│  │  ┌───┐     │  │  │     └──────────────┘                       │
│  │  │服装│     │  │  │     ┌──────────────┐                       │
│  │  └───┘     │  │  │     │  时间折线图    │                       │
│  └──────────────┘  └──┘     │╱╲   ╱╲     │                       │
│    用户点击"数码"           └──────────────┘                       │
│    所有图表过滤为仅显示数码品类数据                                │
└─────────────────────────────────────────────────────────────────┘
```

联动的核心是**共享的筛选状态**。架构选择：
- **useState + Context**：简单场景，但图表多了会不必要重渲染
- **Zustand / Jotai**（推荐）：状态更新粒度可控，性能好
- **事件总线**：跨框架场景，但调试困难

### 五、刷选（Brushing）

用户在图表上拖拽出矩形区域，选中数据点。最常见场景是时间范围选择——在时间序列下方放可刷选的"缩略图"。

### 六、Tooltip 设计

```
┌─────────────────────────────────────────────────────────────────┐
│  信息过少 ◀─────────────────────────────────▶ 信息过多            │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐         │
│  │ GMV: ¥8000万 │    │ 深圳         │    │ 深圳 · 南山区 │         │
│  │              │    │ GMV: ¥8000万 │    │ GMV: ¥8000万 │         │
│  │              │    │ 环比: +12%   │    │ 同比: +8%    │         │
│  │              │    │              │    │ 订单数: 12.5万│         │
│  │              │    │              │    │ 客单价: ¥640 │         │
│  └─────────────┘    └─────────────┘    └─────────────┘         │
│   只有数值            核心信息            信息过载                 │
└─────────────────────────────────────────────────────────────────┘
```

设计原则：
1. **分层展示**：核心数值 → 对比指标（环比、同比）→ 详细指标
2. **避免遮挡**：位置根据鼠标和图表边界动态调整
3. **格式化**：千分位分隔符、百分比小数位、货币符号

### 共享筛选状态（Zustand）

```typescript
import { create } from 'zustand'

const GEO_HIERARCHY = ['region', 'province', 'city'] as const
type GeoLevel = (typeof GEO_HIERARCHY)[number]

interface FilterStore {
  selectedCategory: string | null
  selectedDateRange: [string, string] | null
  drilldownPath: string[]
  drilldownLevel: GeoLevel
  setCategory: (category: string | null) => void
  setDateRange: (range: [string, string] | null) => void
  drillDown: (value: string) => void
  drillUp: (toLevel: number) => void
  resetFilters: () => void
}

export const useFilterStore = create<FilterStore>((set) => ({
  selectedCategory: null,
  selectedDateRange: null,
  drilldownPath: [],
  drilldownLevel: 'region',

  setCategory: (category) => set({ selectedCategory: category }),
  setDateRange: (range) => set({ selectedDateRange: range }),

  drillDown: (value) =>
    set((state) => {
      const idx = GEO_HIERARCHY.indexOf(state.drilldownLevel)
      if (idx >= GEO_HIERARCHY.length - 1) return state
      return {
        drilldownPath: [...state.drilldownPath, value],
        drilldownLevel: GEO_HIERARCHY[idx + 1],
      }
    }),

  drillUp: (toLevel) =>
    set((state) => ({
      drilldownPath: state.drilldownPath.slice(0, toLevel),
      drilldownLevel: GEO_HIERARCHY[toLevel] ?? 'region',
    })),

  resetFilters: () =>
    set({
      selectedCategory: null, selectedDateRange: null,
      drilldownPath: [], drilldownLevel: 'region',
    }),
}))
```

### ECharts 实例管理 Hook

```typescript
import { useRef, useEffect, useCallback } from 'react'
import * as echarts from 'echarts/core'
import { BarChart, LineChart, PieChart } from 'echarts/charts'
import { GridComponent, TooltipComponent, LegendComponent, DataZoomComponent } from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'

echarts.use([BarChart, LineChart, PieChart, GridComponent, TooltipComponent, LegendComponent, DataZoomComponent, CanvasRenderer])

export function useChartInstance(containerRef: React.RefObject<HTMLDivElement>) {
  const chartRef = useRef<echarts.ECharts | null>(null)

  useEffect(() => {
    if (!containerRef.current) return
    chartRef.current = echarts.init(containerRef.current, undefined, { renderer: 'canvas' })
    const observer = new ResizeObserver(() => chartRef.current?.resize())
    observer.observe(containerRef.current)
    return () => { observer.disconnect(); chartRef.current?.dispose(); chartRef.current = null }
  }, [containerRef])

  const updateOption = useCallback(
    (option: echarts.EChartsOption, notMerge = false) => { chartRef.current?.setOption(option, notMerge) }, []
  )

  const onChartEvent = useCallback(
    (eventName: string, handler: (params: unknown) => void) => {
      chartRef.current?.on(eventName, handler)
      return () => chartRef.current?.off(eventName, handler)
    }, []
  )

  return { updateOption, onChartEvent }
}
```

### 数据过滤工具

```typescript
type GeoLevel = 'region' | 'province' | 'city'

const LEVEL_FIELD_MAP: Record<GeoLevel, keyof SalesRecord> = {
  region: 'region', province: 'province', city: 'city',
}

export function filterSalesData(records: SalesRecord[], filters: {
  category: string | null; dateRange: [string, string] | null
  drilldownPath: string[]; drilldownLevel: GeoLevel
}): SalesRecord[] {
  let filtered = [...records]
  if (filters.category) filtered = filtered.filter(r => r.category === filters.category)
  if (filters.dateRange) {
    const [start, end] = filters.dateRange
    filtered = filtered.filter(r => r.date >= start && r.date <= end)
  }
  filters.drilldownPath.forEach((value, level) => {
    const field = LEVEL_FIELD_MAP[['region', 'province', 'city'][level] as GeoLevel]
    filtered = filtered.filter(r => r[field] === value)
  })
  return filtered
}

export function aggregateByDimension(records: SalesRecord[], dimension: keyof SalesRecord) {
  const grouped = new Map<string, SalesRecord[]>()
  for (const record of records) {
    const key = String(record[dimension])
    if (!grouped.has(key)) grouped.set(key, [])
    grouped.get(key)!.push(record)
  }
  return new Map(Array.from(grouped.entries()).map(([key, items]) => [key, {
    gmv: items.reduce((s, r) => s + r.gmv, 0),
    orderCount: items.reduce((s, r) => s + r.orderCount, 0),
    avgPrice: items.reduce((s, r) => s + r.gmv, 0) / items.reduce((s, r) => s + r.orderCount, 0),
  }]))
}
```

### 钻取柱状图组件

```typescript
import { useRef, useEffect, useMemo } from 'react'
import { useChartInstance } from '../hooks/useChartInstance'
import { useFilterStore } from '../stores/filter-store'
import { filterSalesData, aggregateByDimension } from '../utils/data-filter'
import { salesRecords } from '../data/sales-data'

const LEVEL_LABELS: Record<string, string> = { region: '大区', province: '省份', city: '城市' }

export function DrilldownBar() {
  const containerRef = useRef<HTMLDivElement>(null)
  const { updateOption, onChartEvent } = useChartInstance(containerRef)
  const { drilldownLevel, drilldownPath, drillDown, selectedCategory, selectedDateRange } = useFilterStore()

  const chartData = useMemo(() => {
    const filtered = filterSalesData(salesRecords, {
      category: selectedCategory, dateRange: selectedDateRange,
      drilldownPath, drilldownLevel,
    })
    return Array.from(aggregateByDimension(filtered, drilldownLevel).entries())
      .sort((a, b) => b[1].gmv - a[1].gmv).slice(0, 15)
  }, [drilldownLevel, drilldownPath, selectedCategory, selectedDateRange])

  useEffect(() => {
    updateOption({
      title: {
        text: `${LEVEL_LABELS[drilldownLevel]} GMV 分布`,
        subtext: drilldownPath.length > 0 ? `路径: ${drilldownPath.join(' > ')}` : '点击柱子可下钻',
        left: 'center',
      },
      tooltip: {
        trigger: 'axis',
        formatter: (params: { name: string; value: number }[]) => {
          const data = chartData.find(([name]) => name === params[0].name)
          if (!data) return ''
          return `<strong>${params[0].name}</strong><br/>GMV: ¥${(data[1].gmv / 10000).toFixed(0)} 万<br/>订单数: ${data[1].orderCount.toLocaleString()}<br/>客单价: ¥${data[1].avgPrice.toFixed(0)}`
        },
      },
      xAxis: { type: 'category', data: chartData.map(([n]) => n), axisLabel: { rotate: 30 } },
      yAxis: { type: 'value', name: 'GMV (万元)' },
      series: [{
        type: 'bar', data: chartData.map(([, d]) => Math.round(d.gmv / 10000)),
        itemStyle: {
          color: { type: 'linear', x: 0, y: 0, x2: 0, y2: 1, colorStops: [{ offset: 0, color: '#5470c6' }, { offset: 1, color: '#91cc75' }] },
          borderRadius: [4, 4, 0, 0],
        },
      }],
    }, true)
  }, [chartData, drilldownLevel, drilldownPath, updateOption])

  useEffect(() => {
    const cleanup = onChartEvent('click', (params) => {
      if (drilldownLevel !== 'city') drillDown((params as { name: string }).name)
    })
    return cleanup
  }, [drilldownLevel, drillDown, onChartEvent])

  return <div ref={containerRef} style={{ width: '100%', height: '400px' }} role="img" aria-label={`${LEVEL_LABELS[drilldownLevel]} GMV 钻取柱状图`} />
}
```

### 联动饼图组件

```typescript
import { useRef, useEffect, useMemo } from 'react'
import { useChartInstance } from '../hooks/useChartInstance'
import { useFilterStore } from '../stores/filter-store'
import { filterSalesData, aggregateByDimension } from '../utils/data-filter'
import { salesRecords } from '../data/sales-data'

export function CategoryPie() {
  const containerRef = useRef<HTMLDivElement>(null)
  const { updateOption, onChartEvent } = useChartInstance(containerRef)
  const { selectedCategory, setCategory, selectedDateRange, drilldownPath, drilldownLevel } = useFilterStore()

  const pieData = useMemo(() => {
    const filtered = filterSalesData(salesRecords, {
      category: null, dateRange: selectedDateRange, drilldownPath, drilldownLevel,
    })
    return Array.from(aggregateByDimension(filtered, 'category').entries())
      .map(([name, data]) => ({ name, value: Math.round(data.gmv / 10000) }))
      .sort((a, b) => b.value - a.value)
  }, [selectedDateRange, drilldownPath, drilldownLevel])

  useEffect(() => {
    updateOption({
      title: { text: '品类 GMV 占比', subtext: selectedCategory ? `已选: ${selectedCategory} (再次点击取消)` : '点击扇区联动筛选', left: 'center' },
      tooltip: { trigger: 'item', formatter: '{b}: ¥{c} 万 ({d}%)' },
      series: [{
        type: 'pie', radius: ['35%', '65%'], center: ['50%', '55%'],
        data: pieData.map(item => ({
          ...item,
          itemStyle: selectedCategory && item.name !== selectedCategory ? { opacity: 0.3 } : undefined,
        })),
        label: { formatter: '{b}\n{d}%' },
      }],
    }, true)
  }, [pieData, selectedCategory, updateOption])

  useEffect(() => {
    const cleanup = onChartEvent('click', (params) => {
      const name = (params as { name: string }).name
      setCategory(selectedCategory === name ? null : name)
    })
    return cleanup
  }, [selectedCategory, setCategory, onChartEvent])

  return <div ref={containerRef} style={{ width: '100%', height: '350px' }} role="img" aria-label="品类 GMV 饼图" />
}
```

### 趋势折线图（带刷选）

```typescript
import { useRef, useEffect, useMemo } from 'react'
import { useChartInstance } from '../hooks/useChartInstance'
import { useFilterStore } from '../stores/filter-store'
import { filterSalesData } from '../utils/data-filter'
import { salesRecords } from '../data/sales-data'

export function TrendLine() {
  const containerRef = useRef<HTMLDivElement>(null)
  const { updateOption, onChartEvent } = useChartInstance(containerRef)
  const { selectedCategory, setDateRange, drilldownPath, drilldownLevel } = useFilterStore()

  const trendData = useMemo(() => {
    const filtered = filterSalesData(salesRecords, {
      category: selectedCategory, dateRange: null, drilldownPath, drilldownLevel,
    })
    const dailyGmv = new Map<string, number>()
    for (const r of filtered) dailyGmv.set(r.date, (dailyGmv.get(r.date) ?? 0) + r.gmv)
    return Array.from(dailyGmv.entries())
      .sort((a, b) => a[0].localeCompare(b[0]))
      .map(([date, gmv]) => ({ date, gmv: Math.round(gmv / 10000) }))
  }, [selectedCategory, drilldownPath, drilldownLevel])

  useEffect(() => {
    updateOption({
      title: { text: 'GMV 日趋势', subtext: '拖拽下方滑块选择时间范围', left: 'center' },
      tooltip: { trigger: 'axis', formatter: (p: { name: string; value: number }[]) => `${p[0].name}<br/>GMV: ¥${p[0].value} 万` },
      xAxis: { type: 'category', data: trendData.map(d => d.date), axisLabel: { rotate: 45 } },
      yAxis: { type: 'value', name: 'GMV (万元)' },
      dataZoom: [
        { type: 'slider', start: 0, end: 100, bottom: 10, height: 30 },
        { type: 'inside', start: 0, end: 100 },
      ],
      series: [{
        type: 'line', data: trendData.map(d => d.gmv), smooth: true, symbol: 'circle', symbolSize: 4,
        areaStyle: { color: { type: 'linear', x: 0, y: 0, x2: 0, y2: 1, colorStops: [{ offset: 0, color: 'rgba(84,112,198,0.4)' }, { offset: 1, color: 'rgba(84,112,198,0.05)' }] } },
      }],
    }, true)
  }, [trendData, updateOption])

  useEffect(() => {
    const cleanup = onChartEvent('datazoom', (params) => {
      const { start, end } = params as { start: number; end: number }
      const dates = trendData.map(d => d.date)
      const s = dates[Math.floor((start / 100) * dates.length)]
      const e = dates[Math.ceil((end / 100) * dates.length) - 1]
      if (s && e) setDateRange([s, e])
    })
    return cleanup
  }, [trendData, setDateRange, onChartEvent])

  return <div ref={containerRef} style={{ width: '100%', height: '350px' }} role="img" aria-label="GMV 日趋势折线图" />
}
```

### 面包屑导航与布局

```typescript
// src/components/BreadcrumbNav.tsx
import { useFilterStore } from '../stores/filter-store'
const LEVEL_LABELS = ['大区', '省份', '城市']

export function BreadcrumbNav() {
  const { drilldownPath, drilldownLevel, drillUp, resetFilters } = useFilterStore()
  if (drilldownPath.length === 0) return null
  return (
    <nav aria-label="钻取路径导航" className="breadcrumb-nav">
      <button onClick={resetFilters} className="breadcrumb-home">全国</button>
      {drilldownPath.map((value, i) => (
        <span key={i}>
          <span className="breadcrumb-separator"> &gt; </span>
          <button onClick={() => drillUp(i + 1)}
            className={`breadcrumb-item ${i === drilldownPath.length - 1 ? 'active' : ''}`}>
            {value}<span className="breadcrumb-level">({LEVEL_LABELS[i]})</span>
          </button>
        </span>
      ))}
    </nav>
  )
}
```

## 常见误区

**误区一：交互越多越好。** 交互有认知成本。如果用户需要点 5 次才能看到想要的数据，设计就是失败的。好的交互让用户 1-2 次操作到达目标。

**误区二：联动时没有"重置"入口。** 用户忘记选了什么筛选条件，困惑为什么图表只显示部分数据。始终展示当前筛选状态，提供一键重置。

**误区三：Tooltip 堆砌所有字段。** 只放 3-5 个核心指标，详细信息通过点击跳转详情页。

**误区四：钻取层级没有视觉暗示。** 如果柱状图支持钻取但没有提示，用户不会尝试点击。悬浮时显示手型指针、柱子高亮、下钻图标。

## 小结与练习

### 小结

1. **钻取**：在维度层次中逐层深入，从宏观到微观
2. **联动**：多图表通过共享筛选状态协同工作
3. **刷选**：范围选择聚焦数据子集
4. **Tooltip**：分层展示详情信息
5. **缩放平移**：大数据集下的视图导航

关键架构：Zustand 管理共享筛选状态，所有图表组件监听同一个 store，实现自然联动。

### 练习

#### 练习一：实现品类下钻

为饼图增加下钻功能：点击品类扇区后展开子品类数据。在 Zustand store 中增加品类钻取状态，饼图组件监听该状态。

#### 练习二：添加刷选联动

在 TrendLine 中实现 Brush 功能：拖拽选中时间区间后，该区间高亮，其他图表联动过滤。

#### 练习三：优化 Tooltip

为 DrilldownBar 的 Tooltip 实现分层展示：默认显示 GMV 和订单数，悬停 500ms 后展开客单价和退货率。

## 参考答案

### 练习一

**思路**：在 store 中增加 `categoryDrillPath` 和 `categoryDrillLevel`，饼图组件根据当前层级展示不同粒度数据。

**答案**：

```typescript
// store 中新增
categoryDrillPath: [],
categoryDrillLevel: 'category' as 'category' | 'subcategory',
categoryDrillDown: (value: string) => set((state) => ({
  categoryDrillPath: [...state.categoryDrillPath, value],
  categoryDrillLevel: 'subcategory' as const,
})),
categoryDrillUp: () => set({ categoryDrillPath: [], categoryDrillLevel: 'category' as const }),

// CategoryPie 中修改
const { categoryDrillPath, categoryDrillLevel, categoryDrillDown } = useFilterStore()

const pieData = useMemo(() => {
  let filtered = filterSalesData(salesRecords, { /* 已有筛选 */ })
  if (categoryDrillPath.length > 0) {
    filtered = filtered.filter(r => r.category === categoryDrillPath[0])
  }
  const dimension = categoryDrillLevel === 'category' ? 'category' : 'subcategory'
  return Array.from(aggregateByDimension(filtered, dimension).entries())
    .map(([name, data]) => ({ name, value: Math.round(data.gmv / 10000) }))
}, [categoryDrillLevel, categoryDrillPath, /* 其他依赖 */])

// 点击事件区分钻取和联动
useEffect(() => {
  const cleanup = onChartEvent('click', (params) => {
    const name = (params as { name: string }).name
    if (categoryDrillLevel === 'category') categoryDrillDown(name)
    else setCategory(selectedCategory === name ? null : name)
  })
  return cleanup
}, [categoryDrillLevel, categoryDrillDown, selectedCategory, setCategory, onChartEvent])
```

**要点**：钻取和联动使用不同状态维度，避免互相干扰；提供返回机制。

### 练习二

**思路**：ECharts 支持 `brush` 组件，监听 `brushSelected` 事件提取数据索引，通过 store 联动。

**答案**：

```typescript
// option 新增 brush
{
  brush: { toolbox: ['lineX', 'clear'], xAxisIndex: 0,
    brushStyle: { borderWidth: 1, color: 'rgba(84,112,198,0.15)', borderColor: 'rgba(84,112,198,0.6)' } },
  toolbox: { feature: { brush: { type: ['lineX', 'clear'] } } },
}

useEffect(() => {
  const cleanup = onChartEvent('brushSelected', (params) => {
    const batch = (params as { batch: { areas: { coordRange: [number, number] }[] }[] }).batch
    if (!batch?.[0]?.areas?.[0]) { setDateRange(null); return }
    const [s, e] = batch[0].areas[0].coordRange
    const startDate = trendData[s]?.date
    const endDate = trendData[e]?.date
    if (startDate && endDate) setDateRange([startDate, endDate])
  })
  return cleanup
}, [trendData, setDateRange, onChartEvent])
```

**要点**：`coordRange` 返回数据索引而非像素坐标；清除刷选时 `setDateRange(null)`。

### 练习三

**思路**：维护悬浮计时器，鼠标进入启动 500ms 计时器，触发后切换 formatter 为详细版本。

**答案**：

```typescript
const hoverTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null)
const [showDetail, setShowDetail] = useState(false)

useEffect(() => {
  const enter = onChartEvent('mouseover', () => {
    hoverTimerRef.current = setTimeout(() => setShowDetail(true), 500)
  })
  const leave = onChartEvent('globalout', () => {
    if (hoverTimerRef.current) { clearTimeout(hoverTimerRef.current); hoverTimerRef.current = null }
    setShowDetail(false)
  })
  return () => { enter(); leave() }
}, [onChartEvent])

// formatter 中根据 showDetail 决定显示层级
tooltip: {
  trigger: 'axis',
  formatter: (params) => {
    const data = chartData.find(([name]) => name === params[0].name)
    if (!data) return ''
    const lines = [`<strong>${params[0].name}</strong>`, `GMV: ¥${(data[1].gmv/10000).toFixed(0)} 万`, `订单数: ${data[1].orderCount.toLocaleString()}`]
    if (showDetail) lines.push(`客单价: ¥${data[1].avgPrice.toFixed(0)}`, `退货率: ${(data[1].returnRate*100).toFixed(1)}%`)
    return lines.join('<br/>')
  },
},
```

**要点**：用 `globalout` 确保鼠标移出整个图表才触发；`showDetail` 变化时需重新 `setOption`。
