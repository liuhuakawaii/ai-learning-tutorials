# 06 - 阶段实战：企业级图表组件库

> 从"一个能用的图表组件"到"一个能交付的企业级组件库"——差距在工程化。

## 当前项目走到哪里

Part 1 前五课你已经学会了 ECharts 深度用法、D3 数据驱动、交互式可视化、组件设计。现在老板说："我们公司有 3 个产品线，每个产品都需要图表。能不能做一个通用的图表组件库，让所有产品共用？"

需求清单：支持 10+ 图表类型、亮色/暗色主题一键切换、移动端和 PC 端都能用、屏幕阅读器能读出图表含义、有组件文档、有测试保障。

这已经不是"写几个组件"的问题了，而是一个组件库工程。

## Monorepo 结构设计

组件库的第一步是规划包的拆分：

```
vix-charts/
├── packages/
│   ├── core/           # 核心：Hooks、类型、适配器接口
│   │   └── src/
│   │       ├── hooks/useChart.ts, useTheme.ts
│   │       ├── types/chart.ts, theme.ts

│   ├── charts/         # 图表组件
│   │   └── src/
│   │       ├── BarChart.tsx, LineChart.tsx, PieChart.tsx
│   │       └── index.ts
│   ├── themes/         # 主题包
│   │   └── src/light.ts, dark.ts, tokens.ts
│   └── docs/           # Storybook 文档
├── package.json
├── pnpm-workspace.yaml
└── tsconfig.json
```

为什么要拆这么多包？因为**组件库的消费者可能只需要部分功能**。如果只用柱状图，不应该被迫引入 D3 的全部依赖。pnpm workspace 让每个包独立发布，按需安装。

## 适配器模式：不绑定 ECharts

组件库不应该和某个图表引擎绑死。今天用 ECharts，明天可能要换 D3 或者 AntV。适配器模式把引擎细节隔离在接口后面：

```ts
// core/src/types/adapter.ts
export interface ChartAdapter {
  init(container: HTMLElement): void
  setOption(option: any): void
  resize(): void
  dispose(): void
  on(event: string, handler: Function): void
  off(event: string, handler: Function): void
}

// core/src/adapters/echarts-adapter.ts
import * as echarts from 'echarts'

export class EChartsAdapter implements ChartAdapter {
  private instance: echarts.ECharts | null = null

  init(container: HTMLElement) {
    this.instance = echarts.init(container)
  }

  setOption(option: any) {
    this.instance?.setOption(option, { notMerge: false })
  }

  resize() {
    this.instance?.resize()
  }

  dispose() {
    this.instance?.dispose()
    this.instance = null
  }

  on(event: string, handler: Function) {
    this.instance?.on(event, handler as any)
  }

  off(event: string, handler: Function) {
    this.instance?.off(event, handler as any)
  }
}
```

所有图表组件只依赖 `ChartAdapter` 接口，不直接 import ECharts。切换引擎只需要换一个适配器实现。

## 主题引擎

企业级组件库必须支持主题切换。主题不是"换个颜色"那么简单——它是一套设计 Token 系统：

```ts
// themes/src/tokens.ts
export interface DesignTokens {
  color: {
    primary: string
    secondary: string
    success: string
    warning: string
    error: string
    text: { primary: string; secondary: string; disabled: string }
    background: { primary: string; secondary: string; elevated: string }
    border: string
  }
  chart: {
    palette: string[]        // 图表配色序列
    axis: { color: string; gridColor: string }
    tooltip: { bg: string; text: string }
  }
  spacing: { xs: number; sm: number; md: number; lg: number }
  radius: { sm: number; md: number; lg: number }
}

// themes/src/light.ts
export const lightTheme: DesignTokens = {
  color: {
    primary: '#1677ff',
    secondary: '#722ed1',
    success: '#52c41a',
    warning: '#faad14',
    error: '#ff4d4f',
    text: { primary: '#1f1f1f', secondary: '#666', disabled: '#bbb' },
    background: { primary: '#fff', secondary: '#f5f5f5', elevated: '#fff' },
    border: '#e8e8e8',
  },
  chart: {
    palette: ['#1677ff', '#722ed1', '#52c41a', '#faad14', '#ff4d4f', '#13c2c2'],
    axis: { color: '#999', gridColor: '#f0f0f0' },
    tooltip: { bg: 'rgba(0,0,0,0.75)', text: '#fff' },
  },
  spacing: { xs: 4, sm: 8, md: 16, lg: 24 },
  radius: { sm: 4, md: 8, lg: 12 },
}
```

用 React Context 把主题注入组件树：

```tsx
const ThemeContext = React.createContext<DesignTokens>(lightTheme)

export function ThemeProvider({ theme = lightTheme, children }: {
  theme?: DesignTokens
  children: React.ReactNode
}) {
  return <ThemeContext.Provider value={theme}>{children}</ThemeContext.Provider>
}

export function useTheme() {
  return React.useContext(ThemeContext)
}
```

图表组件通过 `useTheme()` 获取 Token，再映射到 ECharts 的 option 中。

## 用 useChart Hook 统一图表逻辑

所有图表组件共享相同的生命周期逻辑：初始化、设置选项、resize 监听、销毁。把它抽成一个 Hook：

```ts
// core/src/hooks/useChart.ts
import { useRef, useEffect } from 'react'
import type { ChartAdapter } from '../types/adapter'

export function useChart(
  adapter: ChartAdapter,
  option: any,
  deps: any[] = []
) {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return
    adapter.init(containerRef.current)
    adapter.setOption(option)

    const handleResize = () => adapter.resize()
    window.addEventListener('resize', handleResize)

    return () => {
      window.removeEventListener('resize', handleResize)
      adapter.dispose()
    }
  }, deps)

  return { containerRef }
}
```

柱状图组件就变得很薄：

```tsx
export function BarChart({ data, theme, ...props }: BarChartProps) {
  const tokens = useTheme()
  const adapter = useMemo(() => new EChartsAdapter(), [])

  const option = useMemo(() => ({
    xAxis: { type: 'category', data: data.categories },
    yAxis: { type: 'value' },
    series: [{ type: 'bar', data: data.values }],
    color: tokens.chart.palette,
    // ...其他配置从 tokens 映射
  }), [data, tokens])

  const { containerRef } = useChart(adapter, option, [option])

  return <div ref={containerRef} style={{ width: '100%', height: props.height ?? 400 }} />
}
```

## 测试策略

组件库需要三层测试：

1. **单元测试**：测试数据转换函数、主题 Token 映射逻辑（Jest）
2. **快照测试**：确保组件渲染结果不意外变化（Jest snapshot）
3. **视觉回归测试**：截图对比，检测像素级差异（Playwright / Chromatic）

```ts
// BarChart.test.tsx
import { render, screen } from '@testing-library/react'
import { BarChart } from './BarChart'

it('renders without crashing', () => {
  const data = { categories: ['A', 'B', 'C'], values: [10, 20, 30] }
  render(<BarChart data={data} />)
  expect(screen.getByRole('img')).toBeInTheDocument()
})
```

## 参考答案

### 练习一

```tsx
// adapters/echarts-adapter.ts
import * as echarts from 'echarts'
import type { ChartAdapter } from '../types/adapter'

export class EChartsAdapter implements ChartAdapter {
  private instance: echarts.ECharts | null = null

  init(container: HTMLElement) {
    this.instance = echarts.init(container)
  }

  setOption(option: any) {
    this.instance?.setOption(option, { notMerge: false })
  }

  resize() {
    this.instance?.resize({ animation: { duration: 300 } })
  }

  dispose() {
    this.instance?.dispose()
    this.instance = null
  }

  on(event: string, handler: Function) {
    this.instance?.on(event, handler as any)
  }

  off(event: string, handler: Function) {
    this.instance?.off(event, handler as any)
  }
}

// hooks/useChart.ts
import { useRef, useEffect } from 'react'
import type { ChartAdapter } from '../types/adapter'

export function useChart(adapter: ChartAdapter, option: any, deps: any[] = []) {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!containerRef.current) return
    adapter.init(containerRef.current)
    adapter.setOption(option)
    const onResize = () => adapter.resize()
    window.addEventListener('resize', onResize)
    return () => {
      window.removeEventListener('resize', onResize)
      adapter.dispose()
    }
  }, deps)

  return { containerRef }
}

// LineChart.tsx
import { useMemo } from 'react'
import { EChartsAdapter } from '../adapters/echarts-adapter'
import { useChart } from '../hooks/useChart'
import { useTheme } from '../themes/ThemeProvider'

interface LineChartProps {
  data: { categories: string[]; values: number[] }
  height?: number
  smooth?: boolean
}

export function LineChart({ data, height = 400, smooth = true }: LineChartProps) {
  const tokens = useTheme()
  const adapter = useMemo(() => new EChartsAdapter(), [])

  const option = useMemo(() => ({
    xAxis: { type: 'category', data: data.categories },
    yAxis: { type: 'value' },
    series: [{ type: 'line', data: data.values, smooth }],
    color: tokens.chart.palette,
  }), [data, smooth, tokens])

  const { containerRef } = useChart(adapter, option, [option])

  return <div ref={containerRef} role="img" style={{ width: '100%', height }} />
}
```

**常见错误**：
- `adapter` 没有用 `useMemo`，每次渲染都创建新实例，触发 effect 无限循环
- `resize` 没有加防抖，窗口拖拽时高频触发导致性能问题
- `dispose` 后没有把 `instance` 设为 null，后续调用 `setOption` 会报错

### 练习二

```tsx
import { useState, useMemo } from 'react'
import { ThemeProvider } from './ThemeProvider'
import { lightTheme, darkTheme } from './themes'
import { LineChart } from './LineChart'

function App() {
  const [isDark, setIsDark] = useState(false)
  const theme = useMemo(() => (isDark ? darkTheme : lightTheme), [isDark])

  const data = {
    categories: ['一月', '二月', '三月', '四月', '五月'],
    values: [120, 200, 150, 80, 220],
  }

  return (
    <ThemeProvider theme={theme}>
      <div style={{ background: theme.color.background.primary, minHeight: '100vh', padding: 24 }}>
        <button onClick={() => setIsDark(!isDark)}>
          切换到{isDark ? '亮色' : '暗色'}主题
        </button>
        <LineChart data={data} />
      </div>
    </ThemeProvider>
  )
}
```

**常见错误**：
- 主题切换后图表没有重新渲染——需要确保 `option` 的依赖包含 `tokens`
- 背景色写死在 CSS 里而不是从 Token 取，导致主题切换后背景不变
- 没有用 `useMemo` 缓存 `theme` 对象，导致每次渲染都触发 Provider 更新
