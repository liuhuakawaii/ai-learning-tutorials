上一课你学会了设计单个图表组件的 API。现在老板说："我们公司有 3 个产品线，每个产品都需要图表。能不能做一个通用的图表组件库，让所有产品共用？"

这已经不是"写几个组件"的问题了，而是一个**组件库工程**。本课就带你从零搭建这个工程。

## 2. 适配器模式：不绑定 ECharts

### 2.1 为什么需要适配器

直接在组件中 `import echarts` 意味着组件库和 ECharts 强绑定。如果将来要换图表引擎或在 SSR 场景用服务端渲染方案，就需要重写所有组件。适配器模式把图表引擎的差异封装在适配器内部，组件层只依赖统一接口。

### 2.2 适配器接口定义

```typescript
// packages/core/src/adapters/adapter-interface.ts

export interface ChartAdapter {
  init(container: HTMLElement, theme?: string): ChartInstance
  dispose(instance: ChartInstance): void
  setOption(instance: ChartInstance, option: unknown, notMerge?: boolean): void
  toDataURL(instance: ChartInstance, format: 'png' | 'svg'): string
  on(instance: ChartInstance, event: string, handler: (params: unknown) => void): void
  off(instance: ChartInstance, event: string, handler: (params: unknown) => void): void
  resize(instance: ChartInstance): void
}

export interface ChartInstance {
  readonly id: string
  readonly nativeInstance: unknown
}
```

### 2.3 ECharts 适配器实现

```typescript
// packages/core/src/adapters/echarts-adapter.ts

import * as echarts from 'echarts/core'
import { BarChart, LineChart, PieChart, ScatterChart, RadarChart } from 'echarts/charts'
import {
  TitleComponent, TooltipComponent, LegendComponent,
  GridComponent, DataZoomComponent, ToolboxComponent,
} from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
import type { ChartAdapter, ChartInstance } from './adapter-interface'

echarts.use([
  BarChart, LineChart, PieChart, ScatterChart, RadarChart,
  TitleComponent, TooltipComponent, LegendComponent,
  GridComponent, DataZoomComponent, ToolboxComponent,
  CanvasRenderer,
])

let instanceCounter = 0

export const echartsAdapter: ChartAdapter = {
  init(container, theme) {
    const id = `echarts-${++instanceCounter}`
    const native = echarts.init(container, theme, { renderer: 'canvas' })
    return { id, nativeInstance: native }
  },
  dispose(instance) { (instance.nativeInstance as echarts.ECharts).dispose() },
  setOption(instance, option, notMerge) {
    (instance.nativeInstance as echarts.ECharts).setOption(option as echarts.EChartsOption, { notMerge })
  },
  toDataURL(instance, format) {
    const chart = instance.nativeInstance as echarts.ECharts
    return format === 'svg' ? chart.renderToSVGString() : chart.getDataURL({ type: 'png', pixelRatio: 2 })
  },
  on(instance, event, handler) { (instance.nativeInstance as echarts.ECharts).on(event, handler) },
  off(instance, event, handler) { (instance.nativeInstance as echarts.ECharts).off(event, handler) },
  resize(instance) { (instance.nativeInstance as echarts.ECharts).resize({ animation: { duration: 200 } }) },
}
```

### 2.4 useChart 使用适配器

```typescript
// packages/core/src/hooks/useChart.ts

import { useRef, useEffect, useContext } from 'react'
import type { ChartAdapter, ChartInstance } from '../adapters/adapter-interface'
import { AdapterContext } from '../contexts/AdapterContext'

interface UseChartOptions {
  notMerge?: boolean
  onReady?: (instance: ChartInstance) => void
  onClick?: (params: unknown) => void
}

export function useChart(option: unknown, deps: unknown[] = [], opts: UseChartOptions = {}) {
  const containerRef = useRef<HTMLDivElement>(null)
  const instanceRef = useRef<ChartInstance | null>(null)
  const adapter = useContext(AdapterContext)

  useEffect(() => {
    if (!containerRef.current || !adapter) return
    const instance = adapter.init(containerRef.current)
    instanceRef.current = instance

    const resizeObserver = new ResizeObserver(() => adapter.resize(instance))
    resizeObserver.observe(containerRef.current)

    if (opts.onClick) adapter.on(instance, 'click', opts.onClick)
    opts.onReady?.(instance)

    return () => {
      resizeObserver.disconnect()
      adapter.dispose(instance)
      instanceRef.current = null
    }
  }, [adapter])

  useEffect(() => {
    if (instanceRef.current && adapter) adapter.setOption(instanceRef.current, option, opts.notMerge)
  }, [option, opts.notMerge, ...deps])

  return { containerRef, instanceRef, adapter }
}
```

### 3.2 ThemeProvider 与运行时切换

```typescript
// packages/themes/src/ThemeProvider.tsx

import { createContext, useContext, useMemo, useState, type ReactNode } from 'react'
import type { DesignTokens } from './tokens'
import { lightTheme } from './light'
import { darkTheme } from './dark'

type ThemeName = 'light' | 'dark'

interface ThemeContextValue {
  name: ThemeName
  tokens: DesignTokens
  setTheme: (name: ThemeName) => void
  registerTheme: (name: string, tokens: DesignTokens) => void
}

const ThemeContext = createContext<ThemeContextValue | null>(null)
export function useTheme() {
  const ctx = useContext(ThemeContext)
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider')
  return ctx
}

const BUILT_IN: Record<ThemeName, DesignTokens> = { light: lightTheme, dark: darkTheme }

export function ThemeProvider({ defaultTheme = 'light', customThemes = {}, children }: {
  defaultTheme?: ThemeName; customThemes?: Record<string, DesignTokens>; children: ReactNode
}) {
  const [themeName, setThemeName] = useState<ThemeName>(defaultTheme)
  const [custom, setCustom] = useState(customThemes)

  const value = useMemo(() => {
    const all = { ...BUILT_IN, ...custom }
    return {
      name: themeName,
      tokens: all[themeName] ?? lightTheme,
      setTheme: setThemeName,
      registerTheme: (name: string, tokens: DesignTokens) => setCustom((p) => ({ ...p, [name]: tokens })),
    }
  }, [themeName, custom])

  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>
}
```

```typescript
// packages/components/src/ChartContainer.tsx

import { createContext, useContext, type ReactNode, type CSSProperties } from 'react'
import { useTheme } from '@vix/themes'

interface ChartContainerCtx { tokens: ReturnType<typeof useTheme>['tokens'] }
const Ctx = createContext<ChartContainerCtx | null>(null)
export function useChartContainerCtx() { return useContext(Ctx) }

interface Props {
  width?: number | string; height?: number | string
  title?: string; subtitle?: string; loading?: boolean; error?: string
  className?: string; style?: CSSProperties; children: ReactNode
}

export function ChartContainer({ width = '100%', height = 400, title, subtitle, loading, error, className, style, children }: Props) {
  const { tokens } = useTheme()
  return (
    <Ctx.Provider value={{ tokens }}>
      <div className={className} style={{
        width, height, backgroundColor: tokens.colors.neutral.surface,
        borderRadius: tokens.spacing.borderRadius, border: `1px solid ${tokens.colors.neutral.border}`,
        display: 'flex', flexDirection: 'column', overflow: 'hidden', ...style,
      }}>
        {title && (
          <header style={{ padding: '12px 16px 0' }}>
            <h3 style={{ margin: 0, fontSize: tokens.typography.titleSize, fontWeight: 600, color: tokens.colors.neutral.text }}>{title}</h3>
            {subtitle && <p style={{ margin: '4px 0 0', fontSize: tokens.typography.captionSize, color: tokens.colors.neutral.textSecondary }}>{subtitle}</p>}
          </header>
        )}
        <div style={{ flex: 1, position: 'relative', minHeight: 0 }}>
          {loading && <div style={{ position: 'absolute', inset: 0, display: 'flex', alignItems: 'center', justifyContent: 'center', backgroundColor: `${tokens.colors.neutral.bg}cc`, zIndex: 10 }}>
            <span style={{ color: tokens.colors.neutral.textSecondary }}>加载中...</span>
          </div>}
          {error && <div style={{ position: 'absolute', inset: 0, display: 'flex', alignItems: 'center', justifyContent: 'center', color: tokens.colors.semantic.error }}>{error}</div>}
          {!error && children}
        </div>
      </div>
    </Ctx.Provider>
  )
}
```

### 4.2 无障碍包装组件

```typescript
// packages/components/src/ChartAccessibleWrapper.tsx

import { useRef, useCallback, type ReactNode } from 'react'

export function ChartAccessibleWrapper({ label, dataSummary, children, onNavigate }: {
  label: string; dataSummary: string; children: ReactNode
  onNavigate?: (direction: 'prev' | 'next') => void
}) {
  const handleKeyDown = useCallback((e: React.KeyboardEvent) => {
    if (e.key === 'ArrowLeft' || e.key === 'ArrowUp') { e.preventDefault(); onNavigate?.('prev') }
    else if (e.key === 'ArrowRight' || e.key === 'ArrowDown') { e.preventDefault(); onNavigate?.('next') }
  }, [onNavigate])

  return (
    <div role="img" aria-label={label} aria-description={dataSummary} tabIndex={0} onKeyDown={handleKeyDown}>
      {children}
      <span style={{ position: 'absolute', width: 1, height: 1, overflow: 'hidden', clip: 'rect(0,0,0,0)' }}>
        {dataSummary}
      </span>
    </div>
  )
}
```

### 6.3 响应式 Hook

```typescript
// packages/core/src/hooks/useResponsiveChart.ts

import { useState, useEffect, type RefObject } from 'react'

type Breakpoint = 'sm' | 'md' | 'lg'

interface ResponsiveConfig {
  sm: { height: number; fontSize: number; showLabel: boolean; legendPosition: 'bottom' | 'none' }
  md: { height: number; fontSize: number; showLabel: boolean; legendPosition: 'bottom' | 'right' }
  lg: { height: number; fontSize: number; showLabel: boolean; legendPosition: 'right' }
}

export function useResponsiveChart(containerRef: RefObject<HTMLDivElement>, config: ResponsiveConfig) {
  const [breakpoint, setBreakpoint] = useState<Breakpoint>('lg')

  useEffect(() => {
    if (!containerRef.current) return
    const observer = new ResizeObserver((entries) => {
      const width = entries[0].contentRect.width
      if (width < 640) setBreakpoint('sm')
      else if (width < 1024) setBreakpoint('md')
      else setBreakpoint('lg')
    })
    observer.observe(containerRef.current)
    return () => observer.disconnect()
  }, [containerRef])

  return { breakpoint, ...config[breakpoint] }
}
```

## 常见误区

### 误区一：一开始就支持所有图表类型

先做 3 种（柱状图、折线图、饼图），验证架构合理后再扩展。过早抽象所有图表类型的通用接口会导致接口过度复杂。

### 误区二：适配器层过度封装

适配器只封装 init、dispose、setOption、resize、event 五个核心操作。配置生成逻辑放在组件层，不进适配器。

### 误区三：视觉回归测试阈值设太严

阈值设为 0.01（1%），在 CI 中使用 Docker 固定渲染环境。`maxDiffPixelRatio: 0.001` 会导致抗锯齿和字体渲染差异产生误报。

### 误区四：忽略 Tree-shaking

使用 `sideEffects: false` + 子路径导出，让 bundler 能安全移除未使用的代码。

## 小结与练习

### 小结

1. **Monorepo 结构**：core / charts / components / themes 四个包，职责清晰
2. **适配器模式**：统一接口隔离图表引擎，方便替换
3. **主题引擎**：Design Token 体系 + ThemeProvider + 运行时切换
4. **容器组件**：统一的 ChartContainer 处理加载态、错误态、标题
5. **Storybook 集成**：交互式文档 + Props 控制面板
6. **测试策略**：单元测试 → 快照测试 → 视觉回归，三层保障

### 练习

#### 练习一：实现 noopAdapter

基于适配器接口，实现一个 `noopAdapter`（空适配器），用于 SSR 场景下不渲染图表只渲染数据表格的场景。所有方法不产生 DOM 操作。

#### 练习二：自定义品牌主题

使用 ThemeProvider 和 Design Token 体系创建一个企业品牌主题，要求自定义主色、自定义字体，通过 `registerTheme` 在运行时注册。

#### 练习三：数据摘要 Hook

实现 `useDataSummary` Hook，给定数据和字段配置，自动生成文字摘要（如"1 月至 6 月，总计 955 万，最高值在 6 月（210 万），环比增长 31.25%"），用于 ARIA description。

## 参考答案

### 练习一

**思路**：noopAdapter 实现 ChartAdapter 接口的所有方法，但不创建真实实例。init 返回空壳对象，其他方法为空操作。

**答案**：

```typescript
import type { ChartAdapter, ChartInstance } from './adapter-interface'

let noopCounter = 0

export const noopAdapter: ChartAdapter = {
  init() { return { id: `noop-${++noopCounter}`, nativeInstance: null } },
  dispose() {},
  setOption() {},
  toDataURL() { return '' },
  on() {},
  off() {},
  resize() {},
}
```

**要点**：noopAdapter 的 init 仍返回有效 ChartInstance 对象保持接口一致性；toDataURL 返回空字符串，调用方需做空值判断。

### 练习三

**思路**：useDataSummary 计算总和、最大值、最小值、环比等统计指标，拼接成自然语言摘要。

**答案**：

```typescript
import { useMemo } from 'react'

const fmt = (n: number) => {
  if (n >= 10000) return `${(n / 10000).toFixed(1)}万`
  if (n >= 1000) return `${(n / 1000).toFixed(1)}千`
  return n.toFixed(0)
}

export function useDataSummary(data: Record<string, unknown>[], config: { labelField: string; valueField: string }) {
  return useMemo(() => {
    if (data.length === 0) return '暂无数据'
    const values = data.map((d) => Number(d[config.valueField]))
    const labels = data.map((d) => String(d[config.labelField]))
    const total = values.reduce((a, b) => a + b, 0)
    const maxVal = Math.max(...values), minVal = Math.min(...values)
    const maxIdx = values.indexOf(maxVal), minIdx = values.indexOf(minVal)

    let summary = `${labels[0]}至${labels[labels.length - 1]}，总计${fmt(total)}，`
    summary += `最高值在${labels[maxIdx]}（${fmt(maxVal)}），最低值在${labels[minIdx]}（${fmt(minVal)}）`

    if (values.length >= 2) {
      const last = values[values.length - 1], prev = values[values.length - 2]
      const rate = ((last - prev) / prev) * 100
      summary += `，最新一期环比${rate >= 0 ? '增长' : '下降'}${Math.abs(rate).toFixed(1)}%`
    }
    return summary
  }, [data, config])
}
```

**要点**：大数字格式化为"万""千"更符合中文阅读习惯；摘要文本通过 ARIA 传递给屏幕阅读器，要写成完整句子。
