## 场景引入

ECharts 用配置项描述图表，简单直接。但当你遇到这些需求时，配置项就不够用了：

- 需要一个**非标准的可视化形式**：比如把公司组织架构画成一棵可折叠的树，点击节点展开/收起子树。
- 需要**精确控制动画的每一个细节**：比如数据更新时，旧的柱子缩小消失，新的柱子从底部生长出来。
- 需要**物理模拟**：比如一个力导向图，节点之间有排斥力，连线有弹力，整个图"活"起来。

D3（Data-Driven Documents）不是一个图表库，而是一个**数据驱动 DOM 的工具库**。它不提供现成的柱状图或折线图，而是提供一套机制，让你把数据和 DOM 元素绑定在一起，然后用数据来控制 DOM 的创建、更新和删除。

## 核心概念

### 一、数据驱动 DOM

传统操作 DOM 的方式是"命令式"的：手动创建每个元素、设置属性、处理更新。

```javascript
// 传统方式：手动操作 DOM
const container = document.getElementById('chart')
const data = [30, 80, 45, 60, 20, 90, 65]
data.forEach((value, index) => {
  const rect = document.createElementNS('http://www.w3.org/2000/svg', 'rect')
  rect.setAttribute('x', index * 60)
  rect.setAttribute('y', 400 - value)
  rect.setAttribute('width', 50)
  rect.setAttribute('height', value)
  rect.setAttribute('fill', '#5470C6')
  container.appendChild(rect)
})
```

D3 的方式是"声明式"的：你描述数据和 DOM 的关系，D3 负责同步。

```javascript
// D3 方式：数据驱动
d3.select('#chart')
  .selectAll('rect')
  .data(data)
  .join('rect')
  .attr('x', (d, i) => i * 60)
  .attr('y', d => 400 - d)
  .attr('width', 50)
  .attr('height', d => d)
  .attr('fill', '#5470C6')
```

关键优势：**当数据变化时，D3 能自动处理 DOM 的增删改。**

```
数据驱动 DOM 的核心流程：

  数据 [30, 80, 45]
      │
      ▼
  ┌─────────────────────────────────────┐
  │           Selection 绑定            │
  │   .data(data) → 匹配数据和DOM元素    │
  │   ┌───────┬───────┬───────┐        │
  │   │ enter │ update│ exit  │        │
  │   │ 新增  │ 更新  │ 删除  │        │
  │   └───────┴───────┴───────┘        │
  └─────────────────────────────────────┘
      │
      ▼
  DOM 变化：创建新元素、更新属性、移除多余元素
```

### 二、Selection 机制

Selection 是 D3 最核心的概念——一组 DOM 元素的引用，可以批量操作。

**select vs selectAll**：`select` 选中第一个匹配元素，`selectAll` 选中所有匹配元素。

**data 绑定**后，selection 被分成三个子集：
- **enter**：数据有，DOM 没有 → 创建新元素
- **update**：数据有，DOM 也有 → 更新属性
- **exit**：DOM 有，数据没有 → 删除元素

**join 现代写法**（D3 v6+）：

```javascript
d3.select('svg')
  .selectAll('rect')
  .data(dataset)
  .join(
    enter => enter.append('rect').attr('fill', '#5470C6'),
    update => update.attr('fill', '#5470C6'),
    exit => exit.remove()
  )
  .attr('x', (d, i) => i * 60)
  .attr('y', d => 400 - d)
  .attr('width', 50)
  .attr('height', d => d)
```

最简写法（不需要特殊处理 enter/exit 时）：`.join('rect')` 即可。

### 三、比例尺（Scales）

比例尺是数据值到视觉属性的映射函数，把数据域（domain）映射到视觉范围（range）。

```
数据域 (domain)          视觉范围 (range)
[0, 100]           →    [0, 600]  (像素)
['A', 'B', 'C']    →    [0, 200, 400]  (位置)
[0, 100]           →    ['white', 'red']  (颜色)
```

#### 四种常用比例尺

```javascript
// 线性：连续数值 → 连续范围
const xScale = d3.scaleLinear().domain([0, 100]).range([0, 600])

// 序数：离散类别 → 离散值
const colorScale = d3.scaleOrdinal()
  .domain(['电子产品', '服装', '食品', '图书'])
  .range(['#5470C6', '#91CC75', '#FAC858', '#EE6666'])

// 带状：柱状图专用，自动计算柱宽和间距
const xBand = d3.scaleBand()
  .domain(['一月', '二月', '三月', '四月', '五月'])
  .range([0, 600]).padding(0.2)

// 时间：时间戳 → 像素位置
const xTime = d3.scaleTime()
  .domain([new Date('2025-01-01'), new Date('2025-12-31')])
  .range([0, 800])
```

#### 坐标轴生成器

```javascript
const xAxis = d3.axisBottom(xBand)
svg.append('g').attr('transform', 'translate(50, 450)').call(xAxis)

const yAxis = d3.axisLeft(yScale).ticks(5).tickFormat(d => `${d}万`)
svg.append('g').attr('transform', 'translate(50, 50)').call(yAxis)
```

坐标轴生成器会自动根据比例尺计算刻度位置、生成刻度线和标签。

### 四、过渡动画（Transition）

D3 的过渡系统让数据可视化的变化过程变得平滑。

```javascript
d3.select('svg').selectAll('rect')
  .data(newData)
  .join('rect')
  .transition()
  .duration(800)
  .ease(d3.easeCubicOut)
  .attr('y', d => yScale(d))
  .attr('height', d => 400 - yScale(d))
```

**缓动函数**：`d3.easeLinear`（匀速）、`d3.easeQuadIn`（先慢后快）、`d3.easeQuadOut`（先快后慢）、`d3.easeElasticOut`（弹性回弹）、`d3.easeBounceOut`（落地弹跳）。

**enter 动画**——新元素从初始状态过渡到最终状态：

```javascript
d3.select('svg').selectAll('rect')
  .data(newData)
  .join(
    enter => enter.append('rect')
      .attr('y', 400).attr('height', 0).attr('fill', '#5470C6')
      .call(e => e.transition().duration(800).ease(d3.easeCubicOut)
        .attr('y', d => yScale(d)).attr('height', d => 400 - yScale(d))),
    update => update.call(u => u.transition().duration(800)
      .attr('y', d => yScale(d)).attr('height', d => 400 - yScale(d))),
    exit => exit.call(e => e.transition().duration(400)
      .attr('y', 400).attr('height', 0).remove())
  )
```

### 五、力导向图（Force-Directed Graph）

力导向图用物理模拟来布局节点：节点之间有排斥力，连线有拉力，通过迭代计算达到平衡。

```
力导向图的物理模型：

  ┌──────────────────────────────────────┐
  │    ○ ←──── 排斥力 ────→ ○           │
  │    │                     │           │
  │    │ ←── 拉力(连线) ──→ │           │
  │    ○ ←──── 排斥力 ────→ ○           │
  │         ○ ←─ 中心引力 ─→ (中心)      │
  └──────────────────────────────────────┘
```

#### 力的配置

```javascript
const simulation = d3.forceSimulation(nodes)
  .force('charge', d3.forceManyBody().strength(-200))  // 节点间排斥力
  .force('center', d3.forceCenter(400, 300))           // 中心引力
  .force('link', d3.forceLink(links).distance(120))    // 连线拉力
  .force('collision', d3.forceCollide().radius(30))     // 碰撞检测
```

#### tick 事件与拖拽

```javascript
simulation.on('tick', () => {
  linkElements.attr('x1', d => d.source.x).attr('y1', d => d.source.y)
    .attr('x2', d => d.target.x).attr('y2', d => d.target.y)
  nodeElements.attr('cx', d => d.x).attr('cy', d => d.y)
})

const drag = d3.drag()
  .on('start', (event, d) => {
    if (!event.active) simulation.alphaTarget(0.3).restart()
    d.fx = d.x; d.fy = d.y
  })
  .on('drag', (event, d) => { d.fx = event.x; d.fy = event.y })
  .on('end', (event, d) => {
    if (!event.active) simulation.alphaTarget(0)
    d.fx = null; d.fy = null
  })

nodeElements.call(drag)
```

### 核心实现

```javascript
;(function () {
  const container = document.getElementById('chart')
  const tooltip = document.getElementById('tooltip')
  const width = container.clientWidth
  const height = container.clientHeight
  const levelColors = ['#5470C6', '#91CC75', '#FAC858', '#EE6666', '#73C0DE']

  function getNodeRadius(d) {
    return ({ 0: 32, 1: 26, 2: 22, 3: 18, 4: 14 })[d.level] || 14
  }

  const svg = d3.select('#chart').append('svg').attr('width', width).attr('height', height)
  const g = svg.append('g')

  // 缩放平移
  svg.call(d3.zoom().scaleExtent([0.3, 3])
    .on('zoom', (event) => g.attr('transform', event.transform)))

  const nodes = JSON.parse(JSON.stringify(orgNodes))
  const links = orgLinks.map(l => ({ ...l }))
  const linkGroup = g.append('g').attr('class', 'links')
  const nodeGroup = g.append('g').attr('class', 'nodes')
  let isFrozen = false

  // 力模拟
  const simulation = d3.forceSimulation(nodes)
    .force('charge', d3.forceManyBody().strength(d => d.level === 0 ? -600 : -300 - d.level * 50))
    .force('center', d3.forceCenter(width / 2, height / 2))
    .force('link', d3.forceLink(links).id(d => d.id)
      .distance(d => {
        const src = nodes.find(n => n.id === (d.source.id || d.source))
        const tgt = nodes.find(n => n.id === (d.target.id || d.target))
        return 80 + ((src?.level || 0) + (tgt?.level || 0)) * 15
      }))
    .force('collision', d3.forceCollide().radius(d => getNodeRadius(d) + 8))
    .force('y', d3.forceY().y(d => 80 + d.level * 120).strength(0.3))
    .on('tick', () => {
      linkGroup.selectAll('line')
        .attr('x1', d => d.source.x).attr('y1', d => d.source.y)
        .attr('x2', d => d.target.x).attr('y2', d => d.target.y)
      nodeGroup.selectAll('g.node')
        .attr('transform', d => `translate(${d.x},${d.y})`)
    })

  // 渲染连线
  linkGroup.selectAll('line')
    .data(links, d => `${d.source.id || d.source}-${d.target.id || d.target}`)
    .join('line')
    .attr('stroke', '#d0d5dd').attr('stroke-width', 1.5)
    .attr('stroke-opacity', 0.6)

  // 渲染节点
  nodeGroup.selectAll('g.node')
    .data(nodes, d => d.id)
    .join(enter => {
      const group = enter.append('g').attr('class', 'node').attr('cursor', 'pointer')

      group.append('circle')
        .attr('r', d => getNodeRadius(d))
        .attr('fill', d => levelColors[d.level % levelColors.length])
        .attr('stroke', '#fff').attr('stroke-width', 2)

      group.append('text')
        .attr('text-anchor', 'middle')
        .attr('dy', d => getNodeRadius(d) + 16)
        .attr('font-size', d => d.level <= 1 ? 13 : 11)
        .attr('fill', '#333').attr('font-weight', d => d.level <= 1 ? 600 : 400)
        .text(d => d.name)

      group.append('text')
        .attr('text-anchor', 'middle').attr('dy', 4)
        .attr('font-size', d => d.level <= 1 ? 12 : 10)
        .attr('fill', '#fff').attr('font-weight', 500)
        .text(d => d.role.length > 4 ? d.role.substring(0, 4) : d.role)

      // 拖拽
      group.call(d3.drag()
        .on('start', (event, d) => {
          if (!event.active && !isFrozen) simulation.alphaTarget(0.3).restart()
          d.fx = d.x; d.fy = d.y
        })
        .on('drag', (event, d) => { d.fx = event.x; d.fy = event.y })
        .on('end', (event, d) => {
          if (!event.active && !isFrozen) simulation.alphaTarget(0)
          d.fx = null; d.fy = null
        })
      )

      // Tooltip
      group.on('mouseenter', (event, d) => {
        tooltip.querySelector('.name').textContent = d.name
        tooltip.querySelector('.dept').textContent = `部门: ${d.department}`
        tooltip.querySelector('.role').textContent = `职位: ${d.role}`
        tooltip.classList.add('visible')
      })
      .on('mousemove', (event) => {
        tooltip.style.left = `${event.pageX + 12}px`
        tooltip.style.top = `${event.pageY - 10}px`
      })
      .on('mouseleave', () => tooltip.classList.remove('visible'))

      return group
    })

  // 控制按钮
  document.getElementById('btn-reset').addEventListener('click', () => {
    nodes.forEach(d => { d.fx = null; d.fy = null })
    simulation.alpha(1).restart()
  })

  document.getElementById('btn-freeze').addEventListener('click', function () {
    isFrozen = !isFrozen
    this.textContent = isFrozen ? '解冻布局' : '冻结布局'
    isFrozen ? simulation.stop() : simulation.alpha(0.3).restart()
  })
})()
```

### 关键实现解析

- **力的配置**：`forceManyBody` 提供斥力，层级越高斥力越大；`forceY` 让同层级节点倾向在同一水平线；`forceLink` 距离根据两端节点层级动态计算
- **拖拽交互**：拖拽时固定位置（`fx/fy`），释放时恢复自由
- **缩放平移**：`d3.zoom()` 实现滚轮缩放和拖拽平移

## 常见误区

**误区一：用 D3 画标准图表。** D3 的优势是灵活性，不是效率。标准柱状图用 ECharts 10 分钟搞定，用 D3 可能要 2 小时。

**误区二：在 React 中直接操作 DOM。** 两种策略：D3 只做计算（比例尺、力模拟），渲染交给 React/JSX；或者把 D3 限制在一个 `useRef` 的 DOM 节点内。

**误区三：忘记清理。** D3 创建的元素、事件监听器、力模拟的 tick 循环，都需要在组件卸载时清理：

```javascript
useEffect(() => {
  const simulation = d3.forceSimulation(nodes)
  return () => {
    simulation.stop()
    svg.selectAll('*').remove()
  }
}, [])
```

**误区四：过度使用过渡动画。** 过渡动画应该服务于数据理解，不是炫技。页面加载时每个元素都做弹跳入场动画只会让用户等得不耐烦。

**误区五：力导向图没有调整力参数。** 默认参数往往不适合你的数据。节点太多时斥力太小会重叠，需要根据数据规模调整。

## 小结与练习

### 小结

1. **数据驱动 DOM**：让数据控制 DOM 的创建、更新和删除
2. **Selection 机制**：select/selectAll 选择元素，data 绑定数据，enter/exit 处理增删，join 简化流程
3. **比例尺**：线性、序数、带状、时间——把数据域映射到视觉范围
4. **过渡动画**：transition + duration + ease 实现平滑变化
5. **力导向图**：用物理模拟布局节点，适合关系网络可视化

### 练习

#### 练习一：气泡图

用 D3 实现一个气泡图：X 轴为平均订单金额，Y 轴为订单数量，气泡大小映射总销售额，颜色区分产品类别。要求使用 `scaleSqrt` 映射气泡面积，添加坐标轴和网格线，气泡有入场动画。

#### 练习二：力导向图扩展

在本课组织关系图基础上：连线宽度根据"协作频率"数据变化；双击节点高亮其直接关联节点；添加图例说明层级颜色。

## 参考答案

### 练习一

**思路**：气泡大小要用 `scaleSqrt` 而不是 `scaleLinear`，因为圆面积 = πr²，用线性比例尺会导致面积感知失真。

**答案**：

```typescript
interface ProductData {
  name: string; category: string; avgOrderAmount: number
  orderCount: number; totalSales: number
}

const productData: ProductData[] = [
  { name: '笔记本电脑', category: '电子产品', avgOrderAmount: 6500, orderCount: 320, totalSales: 2080000 },
  { name: '运动鞋', category: '服装', avgOrderAmount: 450, orderCount: 1200, totalSales: 540000 },
  { name: '有机牛奶', category: '食品', avgOrderAmount: 68, orderCount: 5600, totalSales: 380800 },
  { name: '编程书', category: '图书', avgOrderAmount: 89, orderCount: 890, totalSales: 79210 },
  { name: '智能手机', category: '电子产品', avgOrderAmount: 4200, orderCount: 580, totalSales: 2436000 },
  { name: '羽绒服', category: '服装', avgOrderAmount: 890, orderCount: 430, totalSales: 382700 },
]

function renderBubbleChart(container: string, data: ProductData[]) {
  const margin = { top: 40, right: 40, bottom: 60, left: 70 }
  const width = 800 - margin.left - margin.right
  const height = 500 - margin.top - margin.bottom

  const svg = d3.select(container).append('svg')
    .attr('width', width + margin.left + margin.right)
    .attr('height', height + margin.top + margin.bottom)
    .append('g')
    .attr('transform', `translate(${margin.left},${margin.top})`)

  const xScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.avgOrderAmount)! * 1.1]).range([0, width])
  const yScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.orderCount)! * 1.1]).range([height, 0])
  const rScale = d3.scaleSqrt()
    .domain([0, d3.max(data, d => d.totalSales)!]).range([8, 50])
  const colorScale = d3.scaleOrdinal<string>()
    .domain(['电子产品', '服装', '食品', '图书'])
    .range(['#5470C6', '#91CC75', '#FAC858', '#EE6666'])

  // 网格线
  svg.append('g').selectAll('line').data(yScale.ticks(5)).join('line')
    .attr('x1', 0).attr('x2', width)
    .attr('y1', d => yScale(d)).attr('y2', d => yScale(d))
    .attr('stroke', '#f0f0f0')

  // 坐标轴
  svg.append('g').attr('transform', `translate(0,${height})`)
    .call(d3.axisBottom(xScale).tickFormat(d => `¥${d}`))
  svg.append('g').call(d3.axisLeft(yScale))

  // 气泡（入场动画：从 r=0 生长到目标半径）
  svg.selectAll('circle').data(data).join('circle')
    .attr('cx', d => xScale(d.avgOrderAmount))
    .attr('cy', d => yScale(d.orderCount))
    .attr('r', 0)
    .attr('fill', d => colorScale(d.category))
    .attr('fill-opacity', 0.7)
    .attr('stroke', d => colorScale(d.category))
    .attr('stroke-width', 1.5)
    .transition().duration(800).ease(d3.easeCubicOut)
    .attr('r', d => rScale(d.totalSales))
}
```

**要点**：`scaleSqrt` 确保面积感知正确；入场动画从 `r=0` 生长；悬停提示用独立 div 方便排版。

### 练习二

**思路**：连线宽度用 `scaleLinear` 映射协作频率；高亮逻辑遍历连线找到直接关联节点 ID，其余降低透明度。

**答案**：

```javascript
const collaborationLinks = orgLinks.map(l => ({
  ...l, frequency: Math.floor(Math.random() * 8) + 2
}))

const linkWidthScale = d3.scaleLinear().domain([2, 10]).range([1, 5])

linkGroup.selectAll('line').data(collaborationLinks).join('line')
  .attr('stroke-width', d => linkWidthScale(d.frequency))

function highlightConnections(event, d) {
  const connectedIds = new Set([d.id])
  collaborationLinks.forEach(link => {
    const src = link.source.id || link.source
    const tgt = link.target.id || link.target
    if (src === d.id) connectedIds.add(tgt)
    if (tgt === d.id) connectedIds.add(src)
  })
  nodeGroup.selectAll('g.node').transition().duration(300)
    .style('opacity', n => connectedIds.has(n.id) ? 1 : 0.15)
  linkGroup.selectAll('line').transition().duration(300)
    .attr('stroke-opacity', l => {
      const src = l.source.id || l.source
      const tgt = l.target.id || l.target
      return (src === d.id || tgt === d.id) ? 0.8 : 0.05
    })
}

nodeGroup.selectAll('g.node')
  .on('dblclick', (event, d) => { event.stopPropagation(); highlightConnections(event, d) })
svg.on('dblclick', () => {
  nodeGroup.selectAll('g.node').transition().duration(300).style('opacity', 1)
  linkGroup.selectAll('line').transition().duration(300).attr('stroke-opacity', 0.6)
})
```

**要点**：双击节点高亮关联，双击空白恢复；图例用 `circle + text` 放在右上角。
