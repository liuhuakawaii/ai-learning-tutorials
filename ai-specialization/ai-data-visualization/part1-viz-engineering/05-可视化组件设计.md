## 场景引入

你的团队有 5 个产品，每个都需要展示图表。第一个产品用了 ECharts，组件内部手写了全套配置。第二个产品上线时，开发直接从第一个产品复制了一份，改了颜色和标题。第三个产品又从第二个复制，改了一半发现配置项对不上，只好硬改。

三个月后，5 个产品里有 5 份不同的柱状图组件。它们长得差不多，但细微处各不相同——有的支持钻取，有的不支持；有的 Tooltip 有环比数据，有的没有；有的暗色主题正常，有的暗色主题下标签是黑色看不见。

当 ECharts 升级到 5.x 时，你需要同时修改 5 份代码。当想统一 Tooltip 样式时，要改 5 个文件。当想加一个"导出图片"功能时，要在 5 个组件里各写一遍。

这就是没有组件库的代价：**重复代码导致维护成本呈线性增长**。组件库要解决的核心问题是：让图表的配置、样式、交互、事件形成统一的抽象层，开发者用一行配置就能生成符合规范的图表，而不是每次都从零开始。

## 1. 图表组件的分层架构

### 1.1 散装图表代码的典型问题

在没有组件库的项目中，图表代码通常是这样的：

```typescript
function SalesChart({ data }: { data: SalesData[] }) {
  const chartRef = useRef<HTMLDivElement>(null)
  useEffect(() => {
    const chart = echarts.init(chartRef.current!)
    chart.setOption({ /* ... 100 行配置 */ })
    return () => chart.dispose()
  }, [data])
  return <div ref={chartRef} style={{ width: 600, height: 400 }} />
}
```

这种写法的问题：实例管理重复（每个组件都要 init、dispose、resize）、配置不可复用（Tooltip 格式化逻辑散落各处）、类型不安全（写错字段名不报错）、测试困难（无法独立测试配置生成逻辑）。

### 1.2 分层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    图表组件库分层架构                              │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  业务组件层    SalesChart  UserGrowthChart               │    │
│  │  关心: 业务数据结构、业务交互逻辑                            │    │
│  └─────────────────────────┬───────────────────────────────┘    │
│                            ▼                                    │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  图表组件层    <BarChart>  <LineChart>  <PieChart>       │    │
│  │  关心: 图表类型、数据映射、交互事件                          │    │
│  └─────────────────────────┬───────────────────────────────┘    │
│                            ▼                                    │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  Hook 层       useChart  useTheme  useDataTransform     │    │
│  │  关心: 实例生命周期、主题切换、数据转换                      │    │
│  └─────────────────────────┬───────────────────────────────┘    │
│                            ▼                                    │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  配置层         themeConfig  tooltipFormatter            │    │
│  │  关心: 默认配置、主题变量、格式化函数                        │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

每一层只依赖下一层，不跨层调用。这个分层不是为了好看，而是让每一层可以独立测试和替换——换主题不影响图表逻辑，换图表库不影响业务组件。

## 2. 配置驱动 vs 命令式 API

```
┌─────────────────────────────────────────────────────────────────┐
│  配置驱动 (Declarative)          命令式 (Imperative)              │
│                                                                 │
│  <BarChart                       <BarChart                       │
│    data={salesData}                onReady={(chart) => {         │
│    xField="date"                     chart.setOption({...})      │
│    yField="gmv"                      chart.on('click', handler)  │
│    onBarClick={handler}            }}                            │
│  />                                                             │
│                                                                 │
│  优点: 简洁、类型安全、易测试      优点: 灵活、完整 API 访问       │
│  缺点: 灵活性受限                 缺点: 冗长、实例管理易出错       │
└─────────────────────────────────────────────────────────────────┘
```

推荐方案：**声明式为主，命令式为辅**。提供 `onChartReady` 回调作为 escape hatch：

```typescript
interface BaseChartProps {
  data: ChartDataItem[]
  options?: Partial<ChartOptions>
  theme?: ThemeName
  onChartReady?: (chart: echarts.ECharts) => void
  customOption?: (defaultOption: echarts.EChartsOption) => echarts.EChartsOption
}
```

`customOption` 接收默认配置，返回修改后的配置。开发者可以在不破坏声明式 API 的前提下覆盖任意配置项。

// src/layouts/DashboardGrid.tsx

import { type ReactNode, type CSSProperties } from 'react'

interface GridCell {
  id: string; col: number; row: number; colSpan?: number; rowSpan?: number
}

interface DashboardGridProps {
  columns?: number; rowHeight?: number; gap?: number
  cells: GridCell[]
  children: (cellId: string) => ReactNode
  style?: CSSProperties
}

export function DashboardGrid({
  columns = 2, rowHeight = 400, gap = 16, cells, children, style,
}: DashboardGridProps) {
  const totalRows = Math.max(...cells.map((c) => c.row + (c.rowSpan ?? 1)))

  return (
    <div style={{
      display: 'grid',
      gridTemplateColumns: `repeat(${columns}, 1fr)`,
      gridTemplateRows: `repeat(${totalRows}, ${rowHeight}px)`,
      gap, ...style,
    }}>
      {cells.map((cell) => (
        <div key={cell.id} style={{
          gridColumn: `${cell.col + 1} / span ${cell.colSpan ?? 1}`,
          gridRow: `${cell.row + 1} / span ${cell.rowSpan ?? 1}`,
        }}>
          {children(cell.id)}
        </div>
      ))}
    </div>
  )
}

## 5. 完整实战：核心组件

### 5.1 useChart Hook

```typescript
// src/hooks/useChart.ts

import { useRef, useEffect, useCallback } from 'react'
import * as echarts from 'echarts/core'
import type { EChartsOption } from 'echarts'
import { useThemeContext } from '../contexts/ThemeContext'

interface UseChartOptions {
  notMerge?: boolean
  onReady?: (chart: echarts.ECharts) => void
  onClick?: (params: echarts.ECElementEvent) => void
}

export function useChart(option: EChartsOption, deps: unknown[] = [], opts: UseChartOptions = {}) {
  const containerRef = useRef<HTMLDivElement>(null)
  const chartRef = useRef<echarts.ECharts | null>(null)
  const themeCtx = useThemeContext()

  useEffect(() => {
    if (!containerRef.current) return
    const chart = echarts.init(containerRef.current, themeCtx.echartsThemeName, { renderer: 'canvas' })
    chartRef.current = chart

    const resizeObserver = new ResizeObserver(() => {
      chart.resize({ animation: { duration: 200 } })
    })
    resizeObserver.observe(containerRef.current)

    if (opts.onClick) chart.on('click', opts.onClick)
    opts.onReady?.(chart)

    return () => {
      resizeObserver.disconnect()
      chart.dispose()
      chartRef.current = null
    }
  }, [themeCtx.echartsThemeName])

  useEffect(() => {
    chartRef.current?.setOption(option, { notMerge: opts.notMerge })
  }, [option, opts.notMerge, ...deps])

  const getChartInstance = useCallback(() => chartRef.current, [])
  return { containerRef, chartInstance: chartRef, getChartInstance }
}
```

### 5.3 BarChart 组件

```typescript
// src/charts/BarChart.tsx

import { useMemo, type CSSProperties } from 'react'
import { useChart } from '../hooks/useChart'
import { useChartContainerCtx } from '../components/ChartContainer'
import { LIGHT_THEME } from '../themes/tokens'
import type { ThemeTokens } from '../types/theme'

interface ChartDataItem {
  [key: string]: string | number | boolean | null | undefined
}

interface BarChartProps<T extends ChartDataItem> {
  data: T[]; xField: keyof T & string; yField: keyof T & string
  groupField?: keyof T & string; horizontal?: boolean; stacked?: boolean
  colors?: string[]; showLabel?: boolean; borderRadius?: number
  style?: CSSProperties
  onChartReady?: (chart: echarts.ECharts) => void
  onBarClick?: (params: { name: string; value: number; dataIndex: number }) => void
}

export function BarChart<T extends ChartDataItem>({
  data, xField, yField, groupField, horizontal = false,
  stacked = false, colors, showLabel = false, borderRadius = 4,
  style, onChartReady, onBarClick,
}: BarChartProps<T>) {
  const ctx = useChartContainerCtx()
  const theme: ThemeTokens = ctx?.themeTokens ?? LIGHT_THEME

  const option = useMemo(() => {
    const categories = [...new Set(data.map((d) => String(d[xField])))]

    let series: Record<string, unknown>[]
    if (groupField) {
      const groups = [...new Set(data.map((d) => String(d[groupField!])))]
      const palette = colors ?? theme.colorPalette
      series = groups.map((group, idx) => ({
        name: group, type: 'bar' as const,
        data: categories.map((cat) => {
          const item = data.find((d) => String(d[xField]) === cat && String(d[groupField!]) === group)
          return item ? Number(item[yField]) : 0
        }),
        stack: stacked ? 'total' : undefined,
        itemStyle: { color: palette[idx % palette.length], borderRadius: stacked ? 0 : borderRadius },
        label: showLabel ? { show: true, position: horizontal ? 'right' : 'top', fontSize: 11 } : undefined,
      }))
    } else {
      series = [{
        type: 'bar' as const,
        data: categories.map((cat) => {
          const item = data.find((d) => String(d[xField]) === cat)
          return item ? Number(item[yField]) : 0
        }),
        itemStyle: {
          color: colors?.[0] ?? theme.colorPalette[0],
          borderRadius: horizontal ? [0, borderRadius, borderRadius, 0] : [borderRadius, borderRadius, 0, 0],
        },
        label: showLabel ? { show: true, position: horizontal ? 'right' : 'top', fontSize: 11 } : undefined,
      }]
    }

    const catAxis = { type: 'category' as const, data: categories, axisLine: { lineStyle: { color: theme.axisLineColor } }, axisLabel: { color: theme.axisLabelColor } }
    const valAxis = { type: 'value' as const, axisLine: { show: false }, axisLabel: { color: theme.axisLabelColor }, splitLine: { lineStyle: { color: theme.splitLineColor } } }

    return {
      backgroundColor: 'transparent',
      grid: { ...theme.gridPadding, containLabel: true },
      tooltip: { trigger: 'axis' as const, backgroundColor: theme.tooltipBg, borderColor: theme.tooltipBorder, textStyle: { color: theme.textColor, fontSize: 12 } },
      legend: groupField ? { top: 8, right: 16, textStyle: { color: theme.legendTextColor } } : undefined,
      xAxis: horizontal ? valAxis : catAxis,
      yAxis: horizontal ? catAxis : valAxis,
      series,
    }
  }, [data, xField, yField, groupField, horizontal, stacked, colors, showLabel, borderRadius, theme])

  const { containerRef } = useChart(option, [data], {
    onReady: onChartReady,
    onClick: onBarClick ? (params) => onBarClick({ name: params.name ?? '', value: params.value as number, dataIndex: params.dataIndex }) : undefined,
  })

  return <div ref={containerRef} style={{ width: '100%', height: '100%', ...style }} role="img" aria-label={`柱状图: ${yField} by ${xField}`} />
}
```

## 常见误区

### 误区一：把 ECharts option 直接暴露给使用者

有些组件库的做法是让用户直接传 ECharts 的 option 对象，组件只负责 init 和 dispose。这等于没有组件库——用户还是要学 ECharts 的全部配置项。

**正确做法**：提供语义化 Props（xField、yField），组件内部负责将语义化配置转换为 ECharts option。

### 误区二：忽略实例销毁和内存泄漏

ECharts 实例持有大量 DOM 节点和事件监听器。组件卸载时不 dispose 会造成内存泄漏。

**正确做法**：在 useEffect 的清理函数中调用 `chart.dispose()`，ResizeObserver 也要 disconnect。

### 误区三：每次渲染都创建新的 option 对象

option 对象每次渲染都重新创建会导致 ECharts 每次都重新渲染整个图表。

**正确做法**：用 `useMemo` 缓存 option 对象，依赖项只包含真正影响图表配置的变量。

### 误区四：主题颜色硬编码在组件中

`color: '#5470c6'` 这样的硬编码会让主题切换变成噩梦。

**正确做法**：定义主题 Token 系统，所有颜色从 Token 中读取，组件不直接引用具体颜色值。

## 小结与练习

### 小结

1. **分层架构**：业务组件 → 图表组件 → Hook 层 → 配置层，每层只依赖下一层
2. **声明式 API**：语义化 Props 优于直接暴露底层配置，命令式回调作为 escape hatch
3. **类型安全**：泛型约束字段名，在编译期捕获错误
4. **组件组合**：Container + Chart + DashboardGrid 的解耦
5. **主题系统**：Token 化的颜色和间距，支持一键切换主题

## 参考答案

### 练习一

**思路**：饼图只需要 name 和 value 两个维度。核心是将 data 数组按 nameField 聚合后映射为 ECharts 的饼图数据格式。

**答案**：

```typescript
import { useMemo, type CSSProperties } from 'react'
import { useChart } from '../hooks/useChart'
import { useChartContainerCtx } from '../components/ChartContainer'
import { LIGHT_THEME } from '../themes/tokens'

interface PieChartProps<T extends Record<string, string | number>> {
  data: T[]; nameField: keyof T & string; valueField: keyof T & string
  innerRadius?: number; showLabel?: boolean
  labelPosition?: 'inside' | 'outside' | 'none'
  colors?: string[]; style?: CSSProperties
  onSliceClick?: (params: { name: string; value: number; percent: number }) => void
}

export function PieChart<T extends Record<string, string | number>>({
  data, nameField, valueField, innerRadius = 0,
  showLabel = true, labelPosition = 'outside', colors, style, onSliceClick,
}: PieChartProps<T>) {
  const ctx = useChartContainerCtx()
  const theme = ctx?.themeTokens ?? LIGHT_THEME

  const option = useMemo(() => {
    const aggregated = new Map<string, number>()
    for (const item of data) {
      const name = String(item[nameField])
      aggregated.set(name, (aggregated.get(name) ?? 0) + Number(item[valueField]))
    }
    const pieData = Array.from(aggregated.entries()).map(([name, value]) => ({ name, value })).sort((a, b) => b.value - a.value)
    const palette = colors ?? theme.colorPalette

    return {
      backgroundColor: 'transparent',
      tooltip: { trigger: 'item' as const, backgroundColor: theme.tooltipBg, borderColor: theme.tooltipBorder, textStyle: { color: theme.textColor }, formatter: '{b}: ¥{c} ({d}%)' },
      series: [{
        type: 'pie' as const, radius: [`${innerRadius}%`, '65%'], center: ['50%', '55%'],
        data: pieData.map((item, idx) => ({ ...item, itemStyle: { color: palette[idx % palette.length] } })),
        label: { show: showLabel && labelPosition !== 'none', position: labelPosition === 'none' ? undefined : labelPosition, formatter: '{b}\n{d}%', color: theme.textColor, fontSize: 11 },
        emphasis: { itemStyle: { shadowBlur: 10, shadowColor: 'rgba(0,0,0,0.3)' } },
      }],
    }
  }, [data, nameField, valueField, innerRadius, showLabel, labelPosition, colors, theme])

  const { containerRef } = useChart(option, [data], {
    onClick: onSliceClick ? (params) => {
      const p = params as { name: string; value: number; percent: number }
      onSliceClick({ name: p.name, value: p.value, percent: p.percent })
    } : undefined,
  })

  return <div ref={containerRef} style={{ width: '100%', height: '100%', ...style }} role="img" aria-label={`饼图: ${valueField} by ${nameField}`} />
}
```

**要点**：饼图数据需要先按 nameField 聚合；`innerRadius` 为 0 是实心饼图，大于 0 是环形图；`percent` 由 ECharts 自动计算。

### 练习二

**思路**：useDataTransform 接收原始数据和转换配置，返回转换后的数据。用 useMemo 缓存，多个转换按 pipeline 顺序执行。

**答案**：

```typescript
import { useMemo } from 'react'

type TransformConfig =
  | { type: 'aggregate'; groupBy: string; aggregations: Array<{ field: string; method: 'sum' | 'avg' | 'count' | 'min' | 'max'; alias?: string }> }
  | { type: 'sort'; field: string; order: 'asc' | 'desc' }
  | { type: 'topN'; n: number; by: string; order?: 'asc' | 'desc' }

const AGG: Record<string, (v: number[]) => number> = {
  sum: (v) => v.reduce((a, b) => a + b, 0),
  avg: (v) => v.reduce((a, b) => a + b, 0) / v.length,
  count: (v) => v.length,
  min: (v) => Math.min(...v),
  max: (v) => Math.max(...v),
}

function apply<T extends Record<string, unknown>>(data: T[], config: TransformConfig): T[] {
  switch (config.type) {
    case 'aggregate': {
      const grouped = new Map<string, T[]>()
      for (const item of data) {
        const key = String((item as Record<string, unknown>)[config.groupBy])
        if (!grouped.has(key)) grouped.set(key, [])
        grouped.get(key)!.push(item)
      }
      return Array.from(grouped.entries()).map(([key, items]) => {
        const result: Record<string, unknown> = { [config.groupBy]: key }
        for (const agg of config.aggregations) {
          const values = items.map((i) => Number((i as Record<string, unknown>)[agg.field])).filter((v) => !isNaN(v))
          result[agg.alias ?? `${agg.method}_${agg.field}`] = AGG[agg.method](values)
        }
        return result as T
      })
    }
    case 'sort':
      return [...data].sort((a, b) => {
        const diff = Number((a as Record<string, unknown>)[config.field]) - Number((b as Record<string, unknown>)[config.field])
        return config.order === 'asc' ? diff : -diff
      })
    case 'topN': {
      const sorted = [...data].sort((a, b) => {
        const diff = Number((a as Record<string, unknown>)[config.by]) - Number((b as Record<string, unknown>)[config.by])
        return (config.order ?? 'desc') === 'asc' ? diff : -diff
      })
      return sorted.slice(0, config.n)
    }
  }
}

export function useDataTransform<T extends Record<string, unknown>>(data: T[], transforms: TransformConfig[]): T[] {
  return useMemo(() => transforms.reduce((result, config) => apply(result, config), data), [data, transforms])
}
```

**要点**：聚合操作先分组再计算；多个转换按 pipeline 顺序执行；用 useMemo 缓存结果。
