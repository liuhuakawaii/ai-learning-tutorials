## 场景引入

周一早上，销售总监打开邮箱，发现上周的销售周报还没有生成。他想找数据分析师帮忙看一下华东区各产品线的同比情况，但分析师排期已经到了周三。于是他打开公司的 BI 平台，面对二十多个报表入口、上百个筛选条件，花了半小时也没找到自己想要的那个视图。

这个场景在每一家企业都在反复上演。传统 BI 的核心矛盾在于：**数据的消费者和技术实现之间隔着一堵墙**。业务人员知道自己想看什么，但不知道怎么从系统里把它"调"出来。

对话式 BI 要解决的就是这个问题：用户用自然语言描述需求，系统自动理解意图、生成查询、返回可视化结果。就像和一个懂数据的同事聊天一样。

## 一、对话式 BI 的产品形态

对话式 BI 不是一个单一功能，而是一种新的人机交互范式。它有三种典型的产品形态：

### 1.1 嵌入式对话框

最常见的形态。在现有 BI 产品中嵌入一个对话入口（通常在页面顶部或右侧），用户输入问题后系统返回图表和数据。代表产品：Power BI 的 Q&A、Tableau 的 Ask Data。

### 1.2 独立对话界面

独立的全屏对话应用，类似 ChatGPT 的交互方式，但专注于数据查询和分析。代表产品：Vanna.ai、ChatBI。

### 1.3 混合模式

对话和可视化面板并存，用户既可以通过对话探索数据，也可以通过传统筛选器操作。对话结果可以直接"钉"到 Dashboard 上。

```
┌─────────────────────────────────────────────────────┐
│  混合模式界面布局                                      │
│                                                       │
│  ┌──────────────────────────┐  ┌──────────────────┐  │
│  │                          │  │  对话区域          │  │
│  │    可视化面板              │  │                  │  │
│  │    (图表 / 表格)          │  │  用户: 上月华东   │  │
│  │                          │  │  销售额多少?      │  │
│  │                          │  │                  │  │
│  │                          │  │  AI: 华东区3月    │  │
│  │                          │  │  销售额1.2亿      │  │
│  │                          │  │  [图表已展示]     │  │
│  └──────────────────────────┘  └──────────────────┘  │
│                                                       │
│  ┌──────────────────────────────────────────────────┐│
│  │  筛选器: [日期] [区域] [产品线] [客户类型]         ││
│  └──────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────┘
```

无论哪种形态，核心链路都是一样的：

```
用户输入 → 意图理解 → SQL 生成 → 数据查询 → 可视化渲染
   │           │          │          │           │
   │      NL2SQL      Schema       数据库      ECharts
   │                   Linking                  /D3
   │
   └─ 多轮对话上下文管理 ─────────────────────────┘
```

## 二、系统架构

对话式 BI 的架构分为四层，每一层解决一个核心问题：

```
┌─────────────────────────────────────────────────────────┐
│                    对话式 BI 系统架构                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐                                        │
│  │  表示层      │  对话界面、消息渲染、图表展示、追问按钮    │
│  └──────┬──────┘                                        │
│         │                                               │
│  ┌──────▼──────┐                                        │
│  │  对话管理层   │  上下文管理、指代消解、追问引导、意图路由  │
│  └──────┬──────┘                                        │
│         │                                               │
│  ┌──────▼──────┐                                        │
│  │  查询引擎层   │  NL2SQL、Schema Linking、SQL 优化执行   │
│  └──────┬──────┘                                        │
│         │                                               │
│  ┌──────▼──────┐                                        │
│  │  可视化引擎层 │  图表类型推荐、配置生成、渲染、交互绑定   │
│  └─────────────┘                                        │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  基础设施层: 元数据管理 / 缓存 / 审计日志 / 权限  │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

### 2.1 表示层

表示层负责将对话结果以用户可理解的方式呈现。这里的关键设计决策是：**不是所有回答都适合用文字**。当用户问"上个月销售额多少"，最好的回答不是"1.2亿"，而是一个带有趋势折线图的卡片。

### 2.2 对话管理层

这是对话式 BI 区别于简单 NL2SQL 的核心层。它维护整个对话的上下文状态，处理指代消解（"那去年同期呢"中的"那"指什么），并在用户表述模糊时主动追问。

### 2.3 查询引擎层

将自然语言转换为可执行的 SQL。这一层的核心挑战不是语法转换，而是**语义对齐**——用户的"销售额"到底对应数据库里的哪个字段？"华东区"的范围是哪些省份？

### 2.4 可视化引擎层

根据查询结果的数据特征（维度数量、数据类型、基数）自动推荐合适的图表类型，并生成对应的可视化配置。

## 三、多轮对话管理

多轮对话是对话式 BI 最核心的技术挑战。单轮 NL2SQL 只需要把一句话翻译成 SQL，但真实的业务分析场景几乎都是多轮的：

```
用户: 上个月销售额是多少?
AI:   上个月销售额 1.2 亿元。
用户: 按产品线拆分呢?          ← 需要理解"按产品线拆分"是对上一个问题的追问
AI:   [展示产品线分布饼图]
用户: 那个最高的再看看明细      ← "那个最高的"需要指代消解
AI:   [展示该产品线的详细数据]
用户: 和去年同期比一下          ← "和去年同期比"需要保持上下文
AI:   [展示同比对比图表]
```

### 3.1 上下文理解

上下文理解的核心是维护一个结构化的对话状态。每轮对话都需要记录：

```typescript
interface ConversationTurn {
  turnId: string;
  userQuery: string;           // 用户原始输入
  parsedIntent: ParsedIntent;  // 解析后的意图
  generatedSQL: string;        // 生成的 SQL
  queryResult: QueryResult;    // 查询结果
  visualization: VizConfig;    // 可视化配置
  timestamp: number;
}

interface ParsedIntent {
  type: 'query' | 'compare' | 'drill_down' | 'filter' | 'explanation';
  entities: EntityReference[];  // 提及的实体
  metrics: string[];            // 关注的指标
  dimensions: string[];         // 关注的维度
  filters: FilterCondition[];   // 筛选条件
  timeRange: TimeRange;         // 时间范围
  inheritsFromTurn?: string;    // 继承自哪一轮的上下文
}
```

### 3.2 指代消解

指代消解是指识别对话中的代词和省略成分，将其映射到具体的实体。在数据分析场景中，常见的指代类型包括：

| 指代类型 | 示例 | 消解策略 |
|---------|------|---------|
| 代词指代 | "它的趋势呢" | 回溯上一轮的主题实体 |
| 属性指代 | "最高的那个" | 从上一轮结果中提取极值实体 |
| 省略指代 | "按月拆分" | 继承上一轮的指标和筛选条件 |
| 时间指代 | "去年同期" | 基于当前时间范围推算 |

实现指代消解的核心逻辑：

```typescript
function resolveReference(
  currentQuery: string,
  conversationHistory: ConversationTurn[]
): ResolvedQuery {
  const lastTurn = conversationHistory[conversationHistory.length - 1];
  if (!lastTurn) return { query: currentQuery, resolved: false };

  let resolved = currentQuery;

  // 处理代词: "它" -> 上一轮主题实体
  const pronounPattern = /它|这个|那个|该/;
  if (pronounPattern.test(resolved)) {
    const mainEntity = lastTurn.parsedIntent.entities[0];
    if (mainEntity) {
      resolved = resolved.replace(pronounPattern, mainEntity.name);
    }
  }

  // 处理省略: "按月拆分" -> 继承上一轮的指标
  if (/^按/.test(resolved) && !hasExplicitMetric(resolved)) {
    const inheritedMetrics = lastTurn.parsedIntent.metrics;
    resolved = `${inheritedMetrics.join('和')} ${resolved}`;
  }

  // 处理极值指代: "最高的那个"
  if (/最高|最低|最大|最小/.test(resolved)) {
    const extremeEntity = extractExtremeFromResult(lastTurn.queryResult, resolved);
    if (extremeEntity) {
      resolved = resolved.replace(/最高|最低|最大|最小.*的那个/, extremeEntity.name);
    }
  }

  return { query: resolved, resolved: resolved !== currentQuery };
}
```

### 3.3 追问引导

当用户的查询结果出来后，系统应该主动推荐下一步可以探索的方向。这不是随机推荐，而是基于当前结果的数据特征生成：

```
┌────────────────────────────────────────┐
│  查询结果: 各产品线销售额               │
│                                        │
│  [柱状图]                              │
│                                        │
│  你可能还想了解:                        │
│  ┌──────┐ ┌──────┐ ┌──────┐           │
│  │按月趋势│ │按区域│ │Top10 │           │
│  │      │ │拆分  │ │客户  │           │
│  └──────┘ └──────┘ └──────┘           │
│  ┌──────┐ ┌──────┐                    │
│  │同比分析│ │环比分析│                    │
│  └──────┘ └──────┘                    │
└────────────────────────────────────────┘
```

追问推荐的生成逻辑基于三个维度：
- **数据结构维度**：结果中有分类变量 → 可以按其他维度拆分；有时间变量 → 可以看趋势
- **业务语义维度**：看销售额 → 推荐看利润率、客户数等关联指标
- **异常检测维度**：如果某个值明显偏高/偏低 → 推荐深入分析

## 五、与传统 BI 的对比

理解对话式 BI 和传统 BI 的差异，有助于在实际项目中做正确的技术选型：

| 维度 | 传统 BI | 对话式 BI |
|------|---------|----------|
| 交互方式 | 拖拽、点选、筛选器 | 自然语言对话 |
| 用户门槛 | 需要了解数据模型和指标定义 | 只需要会说话 |
| 灵活性 | 高（但需要开发支持） | 中等（受限于 NL2SQL 能力） |
| 可复用性 | 强（报表可保存分享） | 弱（对话结果不易复用） |
| 适合场景 | 固定报表、定期查看 | 临时探索、即席查询 |
| 技术复杂度 | 中等 | 高（NLP + 数据 + 可视化） |

关键结论：对话式 BI 不是要替代传统 BI，而是**补充**传统 BI 在即席查询场景的不足。最佳实践是混合模式——固定报表用传统 BI，临时探索用对话式 BI。

### 6.3 会话管理

```typescript
// src/core/session.ts

import { randomUUID } from 'crypto';
import type { ConversationTurn, SchemaContext } from '../types';

export interface Session {
  sessionId: string;
  userId: string;
  dataSourceId: string;
  schemaContext: SchemaContext;
  turns: ConversationTurn[];
  activeContext: ActiveContext;
  createdAt: number;
  lastActiveAt: number;
}

export interface ActiveContext {
  currentMetrics: string[];
  currentDimensions: string[];
  currentFilters: { field: string; value: string | number }[];
  currentTimeRange: { start: string; end: string } | null;
  lastMentionedEntities: Map<string, string>;
}

export class SessionManager {
  private sessions = new Map<string, Session>();

  createSession(userId: string, dataSourceId: string, schema: SchemaContext): Session {
    const session: Session = {
      sessionId: `sess_${randomUUID().slice(0, 8)}`,
      userId,
      dataSourceId,
      schemaContext: schema,
      turns: [],
      activeContext: {
        currentMetrics: [],
        currentDimensions: [],
        currentFilters: [],
        currentTimeRange: null,
        lastMentionedEntities: new Map(),
      },
      createdAt: Date.now(),
      lastActiveAt: Date.now(),
    };
    this.sessions.set(session.sessionId, session);
    return session;
  }

  getSession(sessionId: string): Session | undefined {
    return this.sessions.get(sessionId);
  }

  addTurn(sessionId: string, turn: ConversationTurn): void {
    const session = this.sessions.get(sessionId);
    if (!session) throw new Error(`Session ${sessionId} not found`);

    session.turns.push(turn);
    session.lastActiveAt = Date.now();

    this.updateActiveContext(session, turn);
  }

  private updateActiveContext(session: Session, turn: ConversationTurn): void {
    const ctx = session.activeContext;
    const intent = turn.parsedIntent;

    if (intent.metrics.length > 0) {
      ctx.currentMetrics = intent.metrics;
    }
    if (intent.dimensions.length > 0) {
      ctx.currentDimensions = intent.dimensions;
    }
    if (intent.filters.length > 0) {
      ctx.currentFilters = intent.filters.map(f => ({
        field: f.field,
        value: Array.isArray(f.value) ? f.value.join(',') : f.value,
      }));
    }
    if (intent.timeRange) {
      ctx.currentTimeRange = {
        start: intent.timeRange.start,
        end: intent.timeRange.end,
      };
    }
  }

  getRecentTurns(sessionId: string, count = 3): ConversationTurn[] {
    const session = this.sessions.get(sessionId);
    if (!session) return [];
    return session.turns.slice(-count);
  }

  destroySession(sessionId: string): boolean {
    return this.sessions.delete(sessionId);
  }
}
```

### 6.4 上下文理解与指代消解

```typescript
// src/core/context.ts

import type { ConversationTurn, ParsedIntent, SchemaContext } from '../types';

const METRIC_KEYWORDS: Record<string, string> = {
  '销售额': 'sales_amount',
  '销售': 'sales_amount',
  '收入': 'revenue',
  '利润': 'profit',
  '订单数': 'order_count',
  '订单量': 'order_count',
  '客户数': 'customer_count',
  '客单价': 'avg_order_value',
  '转化率': 'conversion_rate',
};

const DIMENSION_KEYWORDS: Record<string, string> = {
  '产品线': 'product_line',
  '产品': 'product_line',
  '区域': 'region',
  '地区': 'region',
  '客户': 'customer_type',
  '渠道': 'channel',
  '月份': 'month',
  '周': 'week',
  '季度': 'quarter',
};

const TIME_PATTERNS = [
  { pattern: /上个?月/, offset: { months: -1 } },
  { pattern: /本个?月/, offset: { months: 0 } },
  { pattern: /上个?季度/, offset: { months: -3 } },
  { pattern: /去年/, offset: { years: -1 } },
  { pattern: /今年/, offset: { years: 0 } },
  { pattern: /最近(\d+)天/, offset: 'dynamic' as const },
  { pattern: /最近(\d+)个月/, offset: 'dynamic' as const },
];

export class ContextAnalyzer {
  constructor(private schema: SchemaContext) {}

  parseIntent(query: string, history: ConversationTurn[]): ParsedIntent {
    const metrics = this.extractMetrics(query);
    const dimensions = this.extractDimensions(query);
    const filters = this.extractFilters(query);
    const timeRange = this.extractTimeRange(query);
    const intentType = this.classifyIntent(query, history);

    const inheritedFrom = this.resolveInheritance(query, history, {
      metrics, dimensions, filters, timeRange,
    });

    return {
      type: intentType,
      metrics: metrics.length > 0 ? metrics : (inheritedFrom?.metrics ?? []),
      dimensions: dimensions.length > 0 ? dimensions : (inheritedFrom?.dimensions ?? []),
      filters,
      timeRange: timeRange ?? inheritedFrom?.timeRange ?? null,
      inheritsFromTurn: inheritedFrom ? 'last' : undefined,
      confidence: this.calculateConfidence(metrics, dimensions, query),
    };
  }

  private extractMetrics(query: string): string[] {
    const found: string[] = [];
    for (const [keyword, field] of Object.entries(METRIC_KEYWORDS)) {
      if (query.includes(keyword)) {
        found.push(field);
      }
    }
    return [...new Set(found)];
  }

  private extractDimensions(query: string): string[] {
    const found: string[] = [];
    for (const [keyword, field] of Object.entries(DIMENSION_KEYWORDS)) {
      if (query.includes(keyword)) {
        found.push(field);
      }
    }
    return [...new Set(found)];
  }

  private extractFilters(query: string): ParsedIntent['filters'] {
    const filters: ParsedIntent['filters'] = [];

    const regionMatch = query.match(/(华东|华南|华北|华中|西南|西北|东北)/);
    if (regionMatch) {
      filters.push({ field: 'region', operator: '=', value: regionMatch[1] });
    }

    const topNMatch = query.match(/Top\s*(\d+)/i) || query.match(/前(\d+)/);
    if (topNMatch) {
      filters.push({ field: '_limit', operator: '=', value: parseInt(topNMatch[1]) });
    }

    return filters;
  }

  private extractTimeRange(query: string): ParsedIntent['timeRange'] {
    const now = new Date();
    for (const { pattern, offset } of TIME_PATTERNS) {
      const match = query.match(pattern);
      if (match) {
        if (offset === 'dynamic') {
          const amount = parseInt(match[1]);
          const unit = query.includes('天') ? 'day' : 'month';
          const start = new Date(now);
          if (unit === 'day') start.setDate(start.getDate() - amount);
          else start.setMonth(start.getMonth() - amount);
          return {
            start: start.toISOString().slice(0, 10),
            end: now.toISOString().slice(0, 10),
            granularity: unit === 'day' ? 'day' : 'month',
          };
        } else {
          const start = new Date(now);
          const end = new Date(now);
          if (offset.months !== undefined) {
            start.setMonth(start.getMonth() + offset.months);
            start.setDate(1);
            end.setMonth(end.getMonth() + offset.months + 1);
            end.setDate(0);
          }
          if (offset.years !== undefined) {
            start.setFullYear(start.getFullYear() + offset.years);
            start.setMonth(0, 1);
            end.setFullYear(end.getFullYear() + offset.years);
            end.setMonth(11, 31);
          }
          return {
            start: start.toISOString().slice(0, 10),
            end: end.toISOString().slice(0, 10),
            granularity: 'month',
          };
        }
      }
    }
    return null;
  }

  private classifyIntent(
    query: string,
    history: ConversationTurn[]
  ): ParsedIntent['type'] {
    if (/对比|比较|同比|环比|vs/.test(query)) return 'compare';
    if (/明细|详情|具体|展开/.test(query)) return 'drill_down';
    if (/只看|筛选|过滤|排除/.test(query)) return 'filter';
    if (/为什么|原因|解释|分析/.test(query)) return 'explain';
    return 'query';
  }

  private resolveInheritance(
    query: string,
    history: ConversationTurn[],
    current: { metrics: string[]; dimensions: string[]; filters: ParsedIntent['filters']; timeRange: ParsedIntent['timeRange'] }
  ): { metrics: string[]; dimensions: string[]; timeRange: ParsedIntent['timeRange'] } | null {
    if (history.length === 0) return null;

    const hasExplicitMetric = current.metrics.length > 0;
    const hasExplicitDimension = current.dimensions.length > 0;
    const hasExplicitTime = current.timeRange !== null;

    if (!hasExplicitMetric || !hasExplicitDimension) {
      const lastIntent = history[history.length - 1].parsedIntent;
      return {
        metrics: hasExplicitMetric ? current.metrics : lastIntent.metrics,
        dimensions: hasExplicitDimension ? current.dimensions : lastIntent.dimensions,
        timeRange: hasExplicitTime ? current.timeRange : lastIntent.timeRange,
      };
    }

    return null;
  }

  private calculateConfidence(
    metrics: string[],
    dimensions: string[],
    query: string
  ): number {
    let score = 0.3;
    if (metrics.length > 0) score += 0.3;
    if (dimensions.length > 0) score += 0.2;
    if (query.length > 5) score += 0.1;
    if (/[?？]/.test(query)) score += 0.1;
    return Math.min(score, 1.0);
  }
}
```

### 6.5 指代消解

```typescript
// src/core/resolver.ts

import type { ConversationTurn, ParsedIntent } from '../types';

export interface ResolvedQuery {
  originalQuery: string;
  resolvedQuery: string;
  resolutionType: 'pronoun' | 'omission' | 'extreme' | 'none';
  resolvedEntities: { original: string; resolved: string }[];
}

export class ReferenceResolver {
  resolve(query: string, history: ConversationTurn[]): ResolvedQuery {
    if (history.length === 0) {
      return {
        originalQuery: query,
        resolvedQuery: query,
        resolutionType: 'none',
        resolvedEntities: [],
      };
    }

    const lastTurn = history[history.length - 1];
    const resolutions: { original: string; resolved: string }[] = [];
    let resolvedQuery = query;
    let resolutionType: ResolvedQuery['resolutionType'] = 'none';

    const pronounResult = this.resolvePronouns(resolvedQuery, lastTurn);
    if (pronounResult.changed) {
      resolvedQuery = pronounResult.query;
      resolutionType = 'pronoun';
      resolutions.push(...pronounResult.entities);
    }

    const omissionResult = this.resolveOmissions(resolvedQuery, lastTurn);
    if (omissionResult.changed) {
      resolvedQuery = omissionResult.query;
      resolutionType = 'omission';
      resolutions.push(...omissionResult.entities);
    }

    const extremeResult = this.resolveExtremes(resolvedQuery, lastTurn);
    if (extremeResult.changed) {
      resolvedQuery = extremeResult.query;
      resolutionType = 'extreme';
      resolutions.push(...extremeResult.entities);
    }

    return {
      originalQuery: query,
      resolvedQuery,
      resolutionType,
      resolvedEntities: resolutions,
    };
  }

  private resolvePronouns(
    query: string,
    lastTurn: ConversationTurn
  ): { query: string; changed: boolean; entities: { original: string; resolved: string }[] } {
    const entities: { original: string; resolved: string }[] = [];
    let result = query;

    const pronounPatterns = [
      { regex: /它(?:的|们)?/g, replacement: () => {
        const mainEntity = lastTurn.parsedIntent.metrics[0] || lastTurn.parsedIntent.dimensions[0];
        return mainEntity || '它';
      }},
    ];

    for (const { regex, replacement } of pronounPatterns) {
      const matches = result.match(regex);
      if (matches) {
        const resolved = replacement();
        entities.push({ original: matches[0], resolved });
        result = result.replace(regex, resolved);
      }
    }

    return { query: result, changed: entities.length > 0, entities };
  }

  private resolveOmissions(
    query: string,
    lastTurn: ConversationTurn
  ): { query: string; changed: boolean; entities: { original: string; resolved: string }[] } {
    const entities: { original: string; resolved: string }[] = [];

    const startsWithDimension = /^(按|根据|以)/.test(query);
    const hasExplicitMetric = /销售额|收入|利润|订单|客户|数量|金额/.test(query);

    if (startsWithDimension && !hasExplicitMetric) {
      const inheritedMetrics = lastTurn.parsedIntent.metrics;
      if (inheritedMetrics.length > 0) {
        const metricName = this.metricToDisplayName(inheritedMetrics[0]);
        const expanded = `${metricName}${query}`;
        entities.push({ original: '(省略指标)', resolved: metricName });
        return { query: expanded, changed: true, entities };
      }
    }

    return { query, changed: false, entities };
  }

  private resolveExtremes(
    query: string,
    lastTurn: ConversationTurn
  ): { query: string; changed: boolean; entities: { original: string; resolved: string }[] } {
    const entities: { original: string; resolved: string }[] = [];

    const extremePattern = /(最高|最低|最大|最小|最多|最少)(?:的)?(?:那个|那个)?/;
    const match = query.match(extremePattern);
    if (match && lastTurn.queryResult.rows.length > 0) {
      const metricField = lastTurn.parsedIntent.metrics[0];
      if (metricField) {
        const sorted = [...lastTurn.queryResult.rows].sort((a, b) => {
          const aVal = Number(a[metricField]) || 0;
          const bVal = Number(b[metricField]) || 0;
          return /最高|最大|最多/.test(match[1]) ? bVal - aVal : aVal - bVal;
        });
        const dimField = lastTurn.parsedIntent.dimensions[0];
        if (dimField && sorted[0][dimField]) {
          const extremeValue = String(sorted[0][dimField]);
          const resolved = query.replace(extremePattern, extremeValue);
          entities.push({ original: match[0], resolved: extremeValue });
          return { query: resolved, changed: true, entities };
        }
      }
    }

    return { query, changed: false, entities };
  }

  private metricToDisplayName(metric: string): string {
    const mapping: Record<string, string> = {
      sales_amount: '销售额',
      revenue: '收入',
      profit: '利润',
      order_count: '订单数',
      customer_count: '客户数',
    };
    return mapping[metric] || metric;
  }
}
```

```typescript
// src/engine/nl2sql.ts

import type { ParsedIntent, SchemaContext, FilterCondition } from '../types';

export class NL2SQLEngine {
  constructor(private schema: SchemaContext) {}

  generateSQL(intent: ParsedIntent): string {
    const table = this.selectMainTable(intent);
    const selectClause = this.buildSelectClause(intent);
    const fromClause = this.buildFromClause(table, intent);
    const whereClause = this.buildWhereClause(intent);
    const groupByClause = this.buildGroupByClause(intent);
    const orderByClause = this.buildOrderByClause(intent);
    const limitClause = this.buildLimitClause(intent);

    const parts = [
      selectClause,
      fromClause,
      whereClause,
      groupByClause,
      orderByClause,
      limitClause,
    ].filter(Boolean);

    return parts.join('\n');
  }

  private selectMainTable(intent: ParsedIntent): string {
    for (const term of [...intent.metrics, ...intent.dimensions]) {
      for (const table of this.schema.tables) {
        if (table.columns.some(c => c.name === term)) {
          return table.name;
        }
      }
    }
    return this.schema.tables[0]?.name || 'sales';
  }

  private buildSelectClause(intent: ParsedIntent): string {
    const fields: string[] = [];

    for (const dim of intent.dimensions) {
      const column = this.findColumn(dim);
      if (column?.type === 'date' && intent.timeRange?.granularity) {
        fields.push(`DATE_TRUNC('${intent.timeRange.granularity}', ${dim}) AS ${dim}_${intent.timeRange.granularity}`);
      } else {
        fields.push(dim);
      }
    }

    for (const metric of intent.metrics) {
      const term = this.schema.businessTerms.find(t => t.column === metric);
      const agg = term?.aggregation || 'sum';
      fields.push(`${agg}(${metric}) AS ${metric}`);
    }

    if (fields.length === 0) {
      fields.push('COUNT(*) AS total_count');
    }

    return `SELECT\n  ${fields.join(',\n  ')}`;
  }

  private buildFromClause(mainTable: string, intent: ParsedIntent): string {
    const neededTables = new Set<string>([mainTable]);

    for (const field of [...intent.metrics, ...intent.dimensions, ...intent.filters.map(f => f.field)]) {
      for (const table of this.schema.tables) {
        if (table.columns.some(c => c.name === field)) {
          neededTables.add(table.name);
        }
      }
    }

    let fromClause = `FROM ${mainTable}`;
    const tables = [...neededTables].filter(t => t !== mainTable);

    for (const joinTable of tables) {
      const rel = this.schema.relationships.find(
        r => (r.from.table === mainTable && r.to.table === joinTable) ||
             (r.to.table === mainTable && r.from.table === joinTable)
      );
      if (rel) {
        const joinCol = rel.from.table === mainTable ? rel.from : rel.to;
        const joinTarget = rel.from.table === mainTable ? rel.to : rel.from;
        fromClause += `\nJOIN ${joinTable} ON ${joinCol.table}.${joinCol.column} = ${joinTarget.table}.${joinTarget.column}`;
      }
    }

    return fromClause;
  }

  private buildWhereClause(intent: ParsedIntent): string {
    const conditions: string[] = [];

    for (const filter of intent.filters) {
      if (filter.field === '_limit') continue;
      switch (filter.operator) {
        case '=':
          conditions.push(`${filter.field} = '${filter.value}'`);
          break;
        case '>':
        case '<':
        case '>=':
        case '<=':
          conditions.push(`${filter.field} ${filter.operator} ${filter.value}`);
          break;
        case 'in':
          const values = Array.isArray(filter.value) ? filter.value : [filter.value];
          conditions.push(`${filter.field} IN (${values.map(v => `'${v}'`).join(', ')})`);
          break;
        case 'like':
          conditions.push(`${filter.field} LIKE '%${filter.value}%'`);
          break;
      }
    }

    if (intent.timeRange) {
      conditions.push(`date >= '${intent.timeRange.start}'`);
      conditions.push(`date <= '${intent.timeRange.end}'`);
    }

    return conditions.length > 0 ? `WHERE\n  ${conditions.join('\n  AND ')}` : '';
  }

  private buildGroupByClause(intent: ParsedIntent): string {
    if (intent.dimensions.length === 0) return '';
    const groupFields = intent.dimensions.map((dim, i) => {
      const column = this.findColumn(dim);
      if (column?.type === 'date' && intent.timeRange?.granularity) {
        return `${i + 1}`;
      }
      return `${i + 1}`;
    });
    return `GROUP BY ${groupFields.join(', ')}`;
  }

  private buildOrderByClause(intent: ParsedIntent): string {
    if (intent.metrics.length > 0) {
      return `ORDER BY ${intent.metrics[0]} DESC`;
    }
    return '';
  }

  private buildLimitClause(intent: ParsedIntent): string {
    const limitFilter = intent.filters.find(f => f.field === '_limit');
    if (limitFilter) {
      return `LIMIT ${limitFilter.value}`;
    }
    if (intent.dimensions.length > 0) {
      return 'LIMIT 20';
    }
    return '';
  }

  private findColumn(name: string) {
    for (const table of this.schema.tables) {
      const col = table.columns.find(c => c.name === name);
      if (col) return col;
    }
    return null;
  }
}
```

```typescript
import type { QueryResult, VisualizationConfig, ColumnMeta } from '../types';

export class VizRecommender {
  recommend(result: QueryResult, userQuery: string): VisualizationConfig {
    const { columns, rows } = result;

    const dimensions = columns.filter(c => c.semanticRole === 'dimension' || c.type === 'string');
```

```typescript
// src/index.ts

import { SessionManager, type Session } from './core/session';
import { ContextAnalyzer } from './core/context';
import { ReferenceResolver } from './core/resolver';
import { NL2SQLEngine } from './engine/nl2sql';
import { VizRecommender } from './engine/viz-recommend';
import type { SchemaContext, ConversationTurn, QueryResult } from './types';

export class ConversationalBI {
  private sessionManager = new SessionManager();
  private resolvers = new Map<string, ReferenceResolver>();
  private analyzers = new Map<string, ContextAnalyzer>();

  constructor(private schema: SchemaContext) {}

  startSession(userId: string, dataSourceId: string): string {
    const session = this.sessionManager.createSession(userId, dataSourceId, this.schema);
    this.resolvers.set(session.sessionId, new ReferenceResolver());
    this.analyzers.set(session.sessionId, new ContextAnalyzer(this.schema));
    return session.sessionId;
  }

  async processQuery(
    sessionId: string,
    userQuery: string,
    executeQuery: (sql: string) => Promise<QueryResult>
  ): Promise<{
    response: string;
    sql: string;
    result: QueryResult;
    visualization: ConversationTurn['visualization'];
    followUps: string[];
  }> {
    const session = this.sessionManager.getSession(sessionId);
    if (!session) throw new Error(`Session ${sessionId} not found`);

    const resolver = this.resolvers.get(sessionId)!;
    const analyzer = this.analyzers.get(sessionId)!;

    const resolved = resolver.resolve(userQuery, session.turns);
    const intent = analyzer.parseIntent(resolved.resolvedQuery, session.turns);
    const nl2sql = new NL2SQLEngine(this.schema);
    const sql = nl2sql.generateSQL(intent);
    const result = await executeQuery(sql);
    const vizRecommender = new VizRecommender();
    const visualization = vizRecommender.recommend(result, userQuery);
    const followUps = this.generateFollowUps(session, intent, result);

    const turn: ConversationTurn = {
      turnId: `turn_${Date.now()}`,
      userQuery,
      parsedIntent: intent,
      generatedSQL: sql,
      queryResult: result,
      visualization,
      followUpSuggestions: followUps,
      timestamp: Date.now(),
    };

    this.sessionManager.addTurn(sessionId, turn);

    const responseText = this.generateResponseText(result, visualization);

    return {
      response: responseText,
      sql,
      result,
      visualization,
      followUps,
    };
  }

  private generateFollowUps(
    session: Session,
    intent: ConversationTurn['parsedIntent'],
    result: QueryResult
  ): string[] {
    const suggestions: string[] = [];

    if (intent.dimensions.length === 0) {
      suggestions.push('按产品线拆分');
      suggestions.push('按区域拆分');
    }

    if (!intent.timeRange) {
      suggestions.push('看下月度趋势');
      suggestions.push('和去年同期对比');
    }

    if (intent.type === 'query') {
      suggestions.push('看下前10名');
      suggestions.push('分析一下原因');
    }

    if (result.rows.length > 1) {
      suggestions.push('按金额排序');
    }

    return suggestions.slice(0, 4);
  }

  private generateResponseText(
    result: QueryResult,
    visualization: ConversationTurn['visualization']
  ): string {
    if (result.rows.length === 0) {
      return '没有找到符合条件的数据，请尝试调整筛选条件。';
    }

    if (result.rows.length === 1) {
      const values = Object.entries(result.rows[0])
        .map(([k, v]) => `${k}: ${v}`)
        .join('，');
      return `查询结果：${values}`;
    }

    return `查询到 ${result.rowCount} 条数据，已为您生成${visualization.chartType === 'pie' ? '饼图' : visualization.chartType === 'line' ? '折线图' : visualization.chartType === 'bar' ? '柱状图' : '表格'}。`;
  }
}

export type {
  SchemaContext, ConversationTurn, QueryResult,
  VisualizationConfig, ParsedIntent,
};
```

## 七、常见误区

### 误区一：对话式 BI 可以完全替代传统 BI

很多团队在立项时把对话式 BI 定位为传统 BI 的替代品，这是一个战略级错误。对话式 BI 擅长即席探索，但在固定报表、精确筛选、复杂布局等场景下，传统 BI 的交互效率远高于对话。正确做法是两者互补，各取所长。

### 误区二：把 NL2SQL 等同于对话式 BI

NL2SQL 只是对话式 BI 的一个组件。没有多轮对话管理、指代消解、追问引导，用户每句话都要完整描述所有条件，体验甚至不如直接用筛选器。对话式 BI 的核心价值在于**上下文理解**，而不是 SQL 生成。

### 误区三：过度依赖 LLM 做所有事

直接把用户输入丢给 LLM 让它生成 SQL，看起来简单，但在生产环境中问题重重：SQL 注入风险、幻觉导致的错误查询、不可控的延迟。正确的架构是用规则引擎处理高频确定性场景（如指代消解、时间解析），LLM 只处理需要语义理解的低频复杂场景。

### 误区四：忽略 Schema Linking

用户说"销售额"，数据库字段叫 `sales_amt`。这之间的映射不是 NL2SQL 模型能自动学会的，需要专门的 Schema Linking 层维护业务术语到数据库字段的映射关系。跳过这一层，NL2SQL 的准确率会大幅下降。

## 小结与练习

### 小结

本课我们学习了对话式 BI 的完整架构设计。核心要点：

1. **产品形态**有三种——嵌入式、独立式、混合式，混合式最适合企业场景
2. **四层架构**——表示层、对话管理层、查询引擎层、可视化引擎层，各司其职
3. **多轮对话**的关键是上下文理解和指代消解，需要结构化的会话状态
4. **指代消解**处理代词、省略、极值三种指代类型
5. **NL2SQL** 需要 Schema Linking 支撑，不是纯粹的模型问题
6. **可视化推荐**基于数据特征自动选择图表类型

## 参考答案

### 练习一

**思路**：时间表达解析的核心是将自然语言映射到具体的日期范围。需要考虑"上周"以周一为起始、"上半年"跨月等场景。

**答案**：

```typescript
const EXTENDED_TIME_PATTERNS = [
  { pattern: /上周/, handler: (now: Date) => {
    const start = new Date(now);
    const day = start.getDay() || 7;
    start.setDate(start.getDate() - day - 6);
    const end = new Date(start);
    end.setDate(end.getDate() + 6);
    return { start: fmt(start), end: fmt(end), granularity: 'day' as const };
  }},
  { pattern: /本周/, handler: (now: Date) => {
    const start = new Date(now);
    const day = start.getDay() || 7;
    start.setDate(start.getDate() - day + 1);
    return { start: fmt(start), end: fmt(now), granularity: 'day' as const };
  }},
  { pattern: /最近一个季度/, handler: (now: Date) => {
    const start = new Date(now);
    start.setMonth(start.getMonth() - 3);
    return { start: fmt(start), end: fmt(now), granularity: 'month' as const };
  }},
  { pattern: /(\d{4})年上半年/, handler: (now: Date, match: RegExpMatchArray) => {
    const year = match[1];
    return { start: `${year}-01-01`, end: `${year}-06-30`, granularity: 'month' as const };
  }},
  { pattern: /(\d{1,2})月到(\d{1,2})月/, handler: (now: Date, match: RegExpMatchArray) => {
    const year = now.getFullYear();
    const startMonth = match[1].padStart(2, '0');
    const endMonth = match[2].padStart(2, '0');
    const lastDay = new Date(year, parseInt(endMonth), 0).getDate();
    return {
      start: `${year}-${startMonth}-01`,
      end: `${year}-${endMonth}-${lastDay}`,
      granularity: 'month' as const,
    };
  }},
];

function fmt(d: Date): string {
  return d.toISOString().slice(0, 10);
}
```

**要点**：
- `getDay()` 返回 0 表示周日，需要转换为 7
- "上半年"等跨月表达需要计算月末日期
- 建议用 handler 函数而非静态 offset，提高表达能力

### 练习二

**思路**：追问推荐需要分析结果集的统计特征——极值分布、时间序列特征、指标相关性，然后生成对应的探索建议。

**答案**：

```typescript
function generateDataDrivenFollowUps(
  intent: ParsedIntent,
  result: QueryResult
): string[] {
  const suggestions: string[] = [];
  const { rows, columns } = result;
  const metrics = columns.filter(c => c.type === 'number');
  const dims = columns.filter(c => c.type === 'string');

  if (dims.length > 0 && metrics.length > 0 && rows.length > 1) {
    const metricName = metrics[0].name;
    const values = rows.map(r => Number(r[metricName]) || 0);
    const maxVal = Math.max(...values);
    const avgVal = values.reduce((a, b) => a + b, 0) / values.length;

    if (maxVal > avgVal * 2) {
      const maxRow = rows.find(r => Number(r[metricName]) === maxVal);
      const dimName = dims[0].name;
      if (maxRow && dimName) {
        suggestions.push(`深入分析${maxRow[dimName]}的详细数据`);
      }
    }
  }

  const hasTimeCol = columns.some(c => c.semanticRole === 'time');
  if (hasTimeCol && !intent.timeRange?.granularity) {
    suggestions.push('看下月度趋势变化');
  }

  if (metrics.length >= 2) {
    suggestions.push(`分析${metrics[0].name}和${metrics[1].name}的关联`);
  }

  if (rows.length > 5) {
    suggestions.push('只看前5名');
  }

  return suggestions.slice(0, 4);
}
```

**要点**：
- 极值检测用 max > 2 * avg 作为阈值，实际项目中可用 Z-score
- 时间序列建议需要检查当前查询是否已经用了时间粒度
- 指标关联推荐只在有多个指标时触发

### 练习三

**思路**：Redis 持久化需要设计 key 结构、序列化策略和过期管理。会话数据量不大，可以直接用 JSON 序列化存储。

**答案**：

```typescript
import Redis from 'ioredis';

export class RedisSessionManager {
  private redis: Redis;
  private prefix = 'bi:session:';
  private defaultTTL = 1800;

  constructor(redisUrl: string) {
    this.redis = new Redis(redisUrl);
  }

  async saveSession(session: Session): Promise<void> {
    const key = `${prefix}${session.sessionId}`;
    const data = JSON.stringify(session, (_key, value) => {
      if (value instanceof Map) return Object.fromEntries(value);
      return value;
    });
    await this.redis.setex(key, this.defaultTTL, data);
  }

  async getSession(sessionId: string): Promise<Session | null> {
    const key = `${prefix}${sessionId}`;
    const data = await this.redis.get(key);
    if (!data) return null;

    const session = JSON.parse(data) as Session;
    session.activeContext.lastMentionedEntities = new Map(
      Object.entries(session.activeContext.lastMentionedEntities || {})
    );

    await this.redis.expire(key, this.defaultTTL);
    return session;
  }

  async addTurn(sessionId: string, turn: ConversationTurn): Promise<void> {
    const session = await this.getSession(sessionId);
    if (!session) throw new Error(`Session ${sessionId} not found`);

    session.turns.push(turn);
    session.lastActiveAt = Date.now();
    await this.saveSession(session);
  }

  async getHistory(sessionId: string, limit = 20): Promise<ConversationTurn[]> {
    const session = await this.getSession(sessionId);
    return session?.turns.slice(-limit) ?? [];
  }

  async destroySession(sessionId: string): Promise<boolean> {
    const result = await this.redis.del(`${prefix}${sessionId}`);
    return result > 0;
  }
}
```

**要点**：
- Map 类型不能直接 JSON 序列化，需要自定义 replacer/reviver
- 每次读取时刷新 TTL，实现滑动过期
- 生产环境建议对 turns 做分页存储，避免单个 session 数据过大
