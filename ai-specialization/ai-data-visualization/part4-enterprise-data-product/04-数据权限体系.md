## 场景引入

某零售集团有一个全国销售 Dashboard。华东区的销售总监登录后，理应只能看到华东区的数据。但如果系统没有做好权限控制，他只需要在筛选器里切换到"华南区"，就能看到竞品区域的销售数据。

更严重的场景：一个普通员工打开了"薪酬分析"报表，发现里面包含了所有人的工资明细，包括 CEO 的年薪。这不是假设——国内某知名互联网公司就曾因为 BI 系统权限配置不当，导致全员薪酬数据泄露。

数据权限体系要解决的核心问题是：**谁能看什么数据，看到多少**。这不是一个简单的"登录后就能看"的开关，而是一套涉及角色定义、数据范围控制、字段脱敏、审计追踪的完整系统。

前几节课我们构建了对话式 BI、数据探索 Agent 和 Dashboard 构建器。这些系统都有一个共同的前提——数据是安全的。如果权限体系没有做好，前面所有的产品能力都可能变成数据泄露的通道。

## 一、RBAC vs ABAC 权限模型

在讨论数据权限之前，需要先理解两种主流的权限模型：RBAC（基于角色的访问控制）和 ABAC（基于属性的访问控制）。它们不是非此即彼的关系，而是解决不同粒度问题的两种工具。

### 1.1 RBAC：基于角色的访问控制

RBAC 的核心思想是：**用户 → 角色 → 权限**。用户不直接拥有权限，而是被分配到一个或多个角色，角色定义了权限集合。

```
┌──────────────────────────────────────────────────────┐
│                   RBAC 模型                           │
│                                                      │
│  ┌────────┐    ┌────────┐    ┌────────────────────┐ │
│  │ 用户    │───→│ 角色    │───→│ 权限               │ │
│  └────────┘    └────────┘    └────────────────────┘ │
│                                                      │
│  张三 ─────→ 华东销售总监 ─────→ 查看: 华东区数据     │
│                                编辑: 华东区报表       │
│                                导出: 华东区数据       │
│                                                      │
│  李四 ─────→ 全国运营经理 ─────→ 查看: 全国数据       │
│                                编辑: 全国报表         │
│                                导出: 全国数据         │
│                                管理: 用户权限         │
│                                                      │
│  王五 ─────→ 普通员工 ─────→ 查看: 个人业绩数据      │
└──────────────────────────────────────────────────────┘
```

RBAC 的优点是简单直观——管理员只需要管理角色，不需要逐个用户配置权限。缺点是粒度不够细：同一个"华东销售总监"角色下，不同人可能需要看到不同的数据范围（比如有人只能看自己负责的产品线）。

### 1.2 ABAC：基于属性的访问控制

ABAC 的核心思想是：**根据用户属性、资源属性、环境属性动态计算权限**。它不依赖预定义的角色，而是通过一组策略规则来判断"这个用户能不能访问这条数据"。

```
┌──────────────────────────────────────────────────────────┐
│                    ABAC 模型                              │
│                                                          │
│  策略 = f(用户属性, 资源属性, 环境属性, 操作类型)           │
│                                                          │
│  用户属性:                                                │
│    department = "销售部"                                  │
│    region = "华东"                                       │
│    level = "总监"                                        │
│                                                          │
│  资源属性:                                                │
│    data_region = "华东"                                  │
│    data_type = "销售数据"                                 │
│    sensitivity = "内部"                                   │
│                                                          │
│  环境属性:                                                │
│    time = "工作日 9:00-18:00"                            │
│    ip = "公司内网"                                        │
│    device = "公司电脑"                                    │
│                                                          │
│  策略: IF user.region == data.region                      │
│        AND user.level IN ["总监", "VP"]                   │
│        AND env.time IN work_hours                        │
│        THEN ALLOW                                        │
└──────────────────────────────────────────────────────────┘
```

ABAC 的优点是极其灵活——可以表达非常复杂的权限规则。缺点是实现复杂度高，策略管理成本大，调试困难（"为什么这个人看不到这条数据"需要追溯整条策略链）。

### 1.3 实践建议：RBAC 做基础，ABAC 做补充

大多数企业数据产品不需要在两者之间做二选一。最佳实践是：

- 用 RBAC 控制**功能权限**——谁能访问哪些报表、Dashboard、数据探索功能
- 用 ABAC 控制**数据权限**——在同一个报表内，不同用户看到的数据范围不同

```
┌──────────────────────────────────────────────────────┐
│              混合权限模型                              │
│                                                      │
│  第一层: RBAC (功能权限)                              │
│  ┌─────────────────────────────────────────────────┐│
│  │ 角色: 销售总监 → 可访问: 销售报表、Dashboard      ││
│  │ 角色: 普通员工 → 可访问: 个人业绩报表             ││
│  └─────────────────────────────────────────────────┘│
│                                                      │
│  第二层: ABAC (数据权限)                              │
│  ┌─────────────────────────────────────────────────┐│
│  │ 规则: user.region == data.region                 ││
│  │ 规则: user.department == data.department         ││
│  │ 规则: sensitivity <= user.clearance_level        ││
│  └─────────────────────────────────────────────────┘│
│                                                      │
│  第三层: 列级权限 + 数据脱敏                          │
│  ┌─────────────────────────────────────────────────┐│
│  │ HR 可见: 姓名、部门、工号                        ││
│  │ HR 不可见: 薪资 (脱敏为 ***)                     ││
│  │ 财务可见: 薪资 (明文)                             ││
│  └─────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────┘
```

## 二、行级权限与列级权限

权限控制的两个核心维度是"行"（哪些数据记录）和"列"（哪些字段）。

### 2.1 行级权限（Row-Level Security）

行级权限控制的是**用户能看到哪些行**。最典型的场景是区域隔离——华东区的用户只能看到华东区的数据。

行级权限的实现方式有两种：**应用层过滤**和**数据库层过滤**。

```
┌──────────────────────────────────────────────────────────┐
│            行级权限的两种实现方式                          │
│                                                          │
│  方式一: 应用层过滤                                       │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 1. 用户请求数据                                    │ │
│  │ 2. 应用根据用户权限生成 WHERE 条件                  │ │
│  │ 3. 拼接到 SQL 查询中                               │ │
│  │ 4. 返回过滤后的数据                                │ │
│  │                                                    │ │
│  │ 原始SQL: SELECT * FROM sales                       │ │
│  │ 加权限: SELECT * FROM sales WHERE region = '华东'  │ │
│  └────────────────────────────────────────────────────┘ │
│                                                          │
│  方式二: 数据库层过滤 (如 PostgreSQL RLS)                 │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 1. 数据库表上定义安全策略                           │ │
│  │ 2. 用户查询时，数据库自动追加 WHERE 条件            │ │
│  │ 3. 应用层无需感知权限逻辑                           │ │
│  │                                                    │ │
│  │ CREATE POLICY region_isolation ON sales             │ │
│  │   USING (region = current_user_region())            │ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

应用层过滤的优点是灵活、跨数据库兼容；缺点是每个查询入口都要记得加权限条件，容易遗漏。数据库层过滤的优点是安全（数据库层面兜底，应用层忘了加也不会泄露）；缺点是依赖特定数据库的特性。

### 2.2 列级权限（Column-Level Security）

列级权限控制的是**用户能看到哪些字段**。典型场景是：所有人都能看销售数据，但只有 HR 能看员工的薪资字段。

```python
from dataclasses import dataclass
from typing import Any


@dataclass
class ColumnPolicy:
    """列级权限策略"""
    column_name: str
    allowed_roles: list[str]
    denied_roles: list[str]
    mask_strategy: str = "full_mask"   # full_mask / partial_mask / hash / null
    mask_config: dict = None

    def __post_init__(self):
        if self.mask_config is None:
            self.mask_config = {}


class ColumnLevelSecurity:
    """列级权限引擎"""

    def __init__(self):
        self.policies: dict[str, ColumnPolicy] = {}

    def add_policy(self, policy: ColumnPolicy) -> None:
        self.policies[policy.column_name] = policy

    def filter_columns(
        self,
        data: list[dict],
        user_roles: list[str],
    ) -> list[dict]:
        """根据用户角色过滤和脱敏列"""
        if not data:
            return data

        result = []
        for row in data:
            filtered_row = {}
            for col, value in row.items():
                policy = self.policies.get(col)
                if policy is None:
                    filtered_row[col] = value
                    continue

                if policy.denied_roles and any(r in policy.denied_roles for r in user_roles):
                    filtered_row[col] = self._apply_mask(value, policy)
                elif policy.allowed_roles and not any(r in policy.allowed_roles for r in user_roles):
                    filtered_row[col] = self._apply_mask(value, policy)
                else:
                    filtered_row[col] = value

            result.append(filtered_row)

        return result

    def _apply_mask(self, value: Any, policy: ColumnPolicy) -> Any:
        strategy = policy.mask_strategy
        config = policy.mask_config

        if strategy == "full_mask":
            return "***"
        elif strategy == "partial_mask":
            if isinstance(value, str) and len(value) > 2:
                show_chars = config.get("show_chars", 1)
                return value[:show_chars] + "*" * (len(value) - show_chars)
            return "***"
        elif strategy == "hash":
            import hashlib
            return hashlib.sha256(str(value).encode()).hexdigest()[:8]
        elif strategy == "null":
            return None
        else:
            return "***"
```

## 三、数据脱敏策略

数据脱敏是列级权限的一种具体实现方式。不是简单地"藏起来"，而是根据场景选择不同的脱敏策略。

### 3.1 常见脱敏策略

```
┌──────────────────────────────────────────────────────────────┐
│                   数据脱敏策略对比                             │
│                                                              │
│  策略          输入          输出         适用场景             │
│  ────────────────────────────────────────────────────────── │
│  完全掩码     13812345678    ***          手机号、身份证       │
│  部分掩码     13812345678    138****5678  手机号 (可回拨)      │
│  哈希         张三           a3f2b1c8     需要关联但不需明文    │
│  截断         2024-03-15     2024-03      日期精度降级         │
│  泛化         28岁           20-30岁      年龄段统计           │
│  置空         机密内容       (NULL)       完全不可见           │
│  偏移         10000          9500-10500   数值范围模糊化       │
└──────────────────────────────────────────────────────────────┘
```

选择哪种脱敏策略，取决于两个因素：**业务需要**和**安全要求**。

如果下游业务需要根据手机号回拨客户，那就不能完全掩码，只能部分掩码（`138****5678`）。如果只是做统计分析，完全掩码或者哈希就够了。

如果数据安全等级很高（比如身份证号、银行卡号），即使部分掩码也可能泄露信息（前三位可以推断运营商，后四位可以推断出生年份），这时候应该用哈希或者完全掩码。

### 3.2 脱敏策略的实现

```python
import hashlib
import re
from typing import Any


class MaskingStrategy:
    """数据脱敏策略集合"""

    @staticmethod
    def full_mask(value: Any) -> str:
        return "***"

    @staticmethod
    def partial_mask_phone(value: str) -> str:
        """手机号脱敏: 138****5678"""
        if not isinstance(value, str) or len(value) != 11:
            return "***"
        return value[:3] + "****" + value[7:]

    @staticmethod
    def partial_mask_name(value: str) -> str:
        """姓名脱敏: 张*、张*明"""
        if not isinstance(value, str) or len(value) < 2:
            return "*"
        if len(value) == 2:
            return value[0] + "*"
        return value[0] + "*" * (len(value) - 2) + value[-1]

    @staticmethod
    def partial_mask_id_card(value: str) -> str:
        """身份证脱敏: 110***********1234"""
        if not isinstance(value, str) or len(value) < 15:
            return "***"
        return value[:3] + "*" * (len(value) - 7) + value[-4:]

    @staticmethod
    def hash_value(value: Any, length: int = 8) -> str:
        """哈希脱敏"""
        h = hashlib.sha256(str(value).encode()).hexdigest()
        return h[:length]

    @staticmethod
    def truncate_date(value: str, precision: str = "month") -> str:
        """日期截断: 2024-03-15 → 2024-03"""
        if not isinstance(value, str):
            return "***"
        if precision == "year":
            return value[:4]
        elif precision == "month":
            return value[:7]
        elif precision == "day":
            return value[:10]
        return value

    @staticmethod
    def generalize_age(value: int, bucket_size: int = 10) -> str:
        """年龄泛化: 28 → 20-30"""
        if not isinstance(value, (int, float)):
            return "***"
        lower = (int(value) // bucket_size) * bucket_size
        upper = lower + bucket_size
        return f"{lower}-{upper}"

    @staticmethod
    def blur_number(value: float, range_pct: float = 0.05) -> str:
        """数值模糊化: 10000 → 9500-10500"""
        if not isinstance(value, (int, float)):
            return "***"
        delta = abs(value) * range_pct
        return f"{value - delta:.0f}-{value + delta:.0f}"

    @staticmethod
    def nullify(value: Any) -> None:
        return None
```

## 四、权限继承与传播

在企业组织架构中，权限是有层级关系的。全国总监应该自动拥有所有区域的数据访问权限，区域总监应该自动拥有其下属城市的权限。这就是权限继承。

### 4.1 继承模型

```
┌──────────────────────────────────────────────────────┐
│              权限继承层级                              │
│                                                      │
│                  全国总监                             │
│              (可见: 全国数据)                         │
│               /          \                           │
│         华东总监         华南总监                     │
│      (可见: 华东)      (可见: 华南)                   │
│       /       \          /       \                   │
│    上海经理  杭州经理  广州经理  深圳经理              │
│  (见:上海)  (见:杭州) (见:广州) (见:深圳)             │
│                                                      │
│  继承规则: 上级自动继承下级的所有数据范围              │
│  全国总监 = 华东 ∪ 华南 ∪ ... ∪ 所有区域              │
│  华东总监 = 上海 ∪ 杭州 ∪ ... ∪ 华东所有城市          │
└──────────────────────────────────────────────────────┘
```

### 4.2 权限继承的实现

```python
from dataclasses import dataclass, field
from typing import Optional


@dataclass
class OrgNode:
    """组织架构节点"""
    node_id: str
    name: str
    parent_id: Optional[str] = None
    data_scope: dict = field(default_factory=dict)  # {"region": "华东", "city": "上海"}


class PermissionInheritance:
    """权限继承引擎"""

    def __init__(self):
        self.nodes: dict[str, OrgNode] = {}
        self.children: dict[str, list[str]] = {}  # parent_id → [child_id]

    def add_node(self, node: OrgNode) -> None:
        self.nodes[node.node_id] = node
        if node.parent_id:
            if node.parent_id not in self.children:
                self.children[node.parent_id] = []
            self.children[node.parent_id].append(node.node_id)

    def get_all_descendant_scopes(self, node_id: str) -> list[dict]:
        """获取节点及其所有后代的数据范围"""
        scopes = []
        node = self.nodes.get(node_id)
        if node and node.data_scope:
            scopes.append(node.data_scope)

        for child_id in self.children.get(node_id, []):
            scopes.extend(self.get_all_descendant_scopes(child_id))

        return scopes

    def build_inherited_filter(self, node_id: str) -> dict:
        """构建继承后的数据过滤条件"""
        scopes = self.get_all_descendant_scopes(node_id)
        if not scopes:
            return {}

        merged: dict[str, set] = {}
        for scope in scopes:
            for key, value in scope.items():
                if key not in merged:
                    merged[key] = set()
                merged[key].add(value)

        return {key: list(values) for key, values in merged.items()}

    def get_effective_scope(self, user_id: str, org_node_id: str) -> dict:
        """获取用户的有效数据范围

        如果用户有直接权限定义，使用直接权限。
        否则，从组织架构继承。
        """
        inherited = self.build_inherited_filter(org_node_id)

        if not inherited:
            return {"access": "none"}

        conditions = []
        for field_name, values in inherited.items():
            if len(values) == 1:
                conditions.append(f"{field_name} = '{list(values)[0]}'")
            else:
                formatted = ", ".join(f"'{v}'" for v in values)
                conditions.append(f"{field_name} IN ({formatted})")

        return {
            "access": "filtered",
            "where_clause": " AND ".join(conditions),
            "scope": inherited,
        }
```

## 五、审计日志与合规

数据权限体系的最后一道防线是**审计日志**。即使权限配置出了问题，审计日志也能帮助追溯"谁在什么时间看了什么数据"，满足合规要求（如 GDPR、数据安全法）。

### 5.1 审计日志的设计

```python
import json
import time
import uuid
from dataclasses import dataclass, field, asdict
from datetime import datetime
from enum import Enum
from typing import Any


class AuditAction(Enum):
    DATA_VIEW = "data_view"
    DATA_EXPORT = "data_export"
    DATA_QUERY = "data_query"
    PERMISSION_CHANGE = "permission_change"
    ACCESS_DENIED = "access_denied"
    LOGIN = "login"
    LOGOUT = "logout"


@dataclass
class AuditLog:
    """审计日志条目"""
    log_id: str = field(default_factory=lambda: uuid.uuid4().hex[:12])
    timestamp: float = field(default_factory=time.time)
    user_id: str = ""
    user_roles: list[str] = field(default_factory=list)
    action: str = ""
    resource_type: str = ""
    resource_id: str = ""
    detail: dict = field(default_factory=dict)
    ip_address: str = ""
    user_agent: str = ""
    result: str = "success"   # success / denied / error

    def to_dict(self) -> dict:
        d = asdict(self)
        d["timestamp_iso"] = datetime.fromtimestamp(self.timestamp).isoformat()
        return d

    def to_json(self) -> str:
        return json.dumps(self.to_dict(), ensure_ascii=False)


class AuditLogger:
    """审计日志记录器"""

    def __init__(self):
        self.logs: list[AuditLog] = []
        self._alert_rules: list[dict] = []

    def log(self, **kwargs) -> AuditLog:
        entry = AuditLog(**kwargs)
        self.logs.append(entry)
        self._check_alerts(entry)
        return entry

    def log_data_access(
        self,
        user_id: str,
        user_roles: list[str],
        resource_id: str,
        query: str,
        row_count: int,
        columns_accessed: list[str],
        ip_address: str = "",
    ) -> AuditLog:
        return self.log(
            user_id=user_id,
            user_roles=user_roles,
            action=AuditAction.DATA_VIEW.value,
            resource_type="report",
            resource_id=resource_id,
            detail={
                "query": query[:500],
                "row_count": row_count,
                "columns_accessed": columns_accessed,
            },
            ip_address=ip_address,
        )

    def log_access_denied(
        self,
        user_id: str,
        user_roles: list[str],
        resource_id: str,
        reason: str,
        ip_address: str = "",
    ) -> AuditLog:
        return self.log(
            user_id=user_id,
            user_roles=user_roles,
            action=AuditAction.ACCESS_DENIED.value,
            resource_type="report",
            resource_id=resource_id,
            detail={"reason": reason},
            ip_address=ip_address,
            result="denied",
        )

    def log_permission_change(
        self,
        operator_id: str,
        target_user_id: str,
        change_type: str,
        old_value: Any,
        new_value: Any,
    ) -> AuditLog:
        return self.log(
            user_id=operator_id,
            action=AuditAction.PERMISSION_CHANGE.value,
            resource_type="permission",
            resource_id=target_user_id,
            detail={
                "change_type": change_type,
                "old_value": str(old_value),
                "new_value": str(new_value),
            },
        )

    def add_alert_rule(self, condition: dict, callback) -> None:
        self._alert_rules.append({"condition": condition, "callback": callback})

    def _check_alerts(self, entry: AuditLog) -> None:
        for rule in self._alert_rules:
            cond = rule["condition"]
            matched = True

            if "action" in cond and entry.action != cond["action"]:
                matched = False
            if "result" in cond and entry.result != cond["result"]:
                matched = False

            if matched:
                rule["callback"](entry)

    def query(
        self,
        user_id: str | None = None,
        action: str | None = None,
        resource_id: str | None = None,
        start_time: float | None = None,
        end_time: float | None = None,
        limit: int = 100,
    ) -> list[AuditLog]:
        results = self.logs

        if user_id:
            results = [l for l in results if l.user_id == user_id]
        if action:
            results = [l for l in results if l.action == action]
        if resource_id:
            results = [l for l in results if l.resource_id == resource_id]
        if start_time:
            results = [l for l in results if l.timestamp >= start_time]
        if end_time:
            results = [l for l in results if l.timestamp <= end_time]

        return results[-limit:]

    def get_user_activity_summary(self, user_id: str) -> dict:
        user_logs = [l for l in self.logs if l.user_id == user_id]
        action_counts: dict[str, int] = {}
        for log in user_logs:
            action_counts[log.action] = action_counts.get(log.action, 0) + 1

        return {
            "user_id": user_id,
            "total_actions": len(user_logs),
            "action_breakdown": action_counts,
            "first_activity": user_logs[0].timestamp if user_logs else None,
            "last_activity": user_logs[-1].timestamp if user_logs else None,
        }
```

### 5.2 合规要点

数据权限体系需要满足的合规要求通常包括：

**最小权限原则**：用户只应拥有完成工作所必需的最小权限。不要为了方便而给"全国权限"。

**权限审批流程**：敏感数据的访问权限应该有审批流程，不能自助开通。

**定期权限审查**：每季度审查一次权限配置，清理离职员工的权限、调整转岗员工的权限。

**数据访问留痕**：所有数据访问行为必须记录审计日志，日志保存期限通常要求 6 个月以上。

**异常行为告警**：短时间内大量导出数据、非工作时间访问敏感数据等异常行为应该触发告警。

```python
"""RBAC 权限模型：用户、角色、权限的管理"""

from dataclasses import dataclass, field
from typing import Optional


@dataclass
class Permission:
    """权限定义"""
    resource: str           # 资源标识，如 "sales_report"
    actions: list[str]      # 允许的操作，如 ["view", "export"]
    data_scope: dict = field(default_factory=dict)  # 数据范围约束


@dataclass
class Role:
    """角色定义"""
    role_id: str
    name: str
    permissions: list[Permission] = field(default_factory=list)
    parent_role_id: Optional[str] = None  # 角色继承


class RBACManager:
    """RBAC 管理器"""

    def __init__(self):
        self.roles: dict[str, Role] = {}
        self.user_roles: dict[str, list[str]] = {}  # user_id → [role_id]

    def add_role(self, role: Role) -> None:
        self.roles[role.role_id] = role

    def assign_role(self, user_id: str, role_id: str) -> bool:
        if role_id not in self.roles:
            return False
        if user_id not in self.user_roles:
            self.user_roles[user_id] = []
        if role_id not in self.user_roles[user_id]:
            self.user_roles[user_id].append(role_id)
        return True

    def revoke_role(self, user_id: str, role_id: str) -> bool:
        if user_id in self.user_roles and role_id in self.user_roles[user_id]:
            self.user_roles[user_id].remove(role_id)
            return True
        return False

    def get_user_roles(self, user_id: str) -> list[Role]:
        role_ids = self.user_roles.get(user_id, [])
        return [self.roles[rid] for rid in role_ids if rid in self.roles]

    def get_effective_permissions(self, user_id: str) -> list[Permission]:
        """获取用户的有效权限（包含角色继承）"""
        roles = self.get_user_roles(user_id)
        all_permissions: list[Permission] = []
        visited: set[str] = set()

        for role in roles:
            self._collect_permissions(role.role_id, all_permissions, visited)

        return all_permissions

    def _collect_permissions(
        self, role_id: str, permissions: list[Permission], visited: set[str]
    ) -> None:
        if role_id in visited:
            return
        visited.add(role_id)

        role = self.roles.get(role_id)
        if not role:
            return

        permissions.extend(role.permissions)

        if role.parent_role_id:
            self._collect_permissions(role.parent_role_id, permissions, visited)

    def check_access(self, user_id: str, resource: str, action: str) -> tuple[bool, dict]:
        """检查用户是否有权限访问资源"""
        permissions = self.get_effective_permissions(user_id)

        for perm in permissions:
            if perm.resource == resource and action in perm.actions:
                return True, perm.data_scope

        return False, {}
```

### 6.4 row_security.py - 行级权限

```python
"""行级权限：根据用户属性过滤数据行"""

from dataclasses import dataclass, field
from typing import Any


@dataclass
class RowPolicy:
    """行级权限策略"""
    policy_id: str
    description: str
    target_roles: list[str]          # 适用的角色
    filter_template: str             # SQL WHERE 条件模板
    parameters: dict = field(default_factory=dict)  # 模板参数


class RowLevelSecurity:
    """行级权限引擎"""

    def __init__(self):
        self.policies: list[RowPolicy] = []
        self.user_attributes: dict[str, dict] = {}  # user_id → {"region": "华东", ...}

    def set_user_attributes(self, user_id: str, attributes: dict) -> None:
        self.user_attributes[user_id] = attributes

    def add_policy(self, policy: RowPolicy) -> None:
        self.policies.append(policy)

    def get_filter(self, user_id: str, user_roles: list[str], resource: str) -> str:
        """获取用户的行级过滤条件"""
        user_attrs = self.user_attributes.get(user_id, {})
        applicable_filters = []

        for policy in self.policies:
            if not any(role in policy.target_roles for role in user_roles):
                continue

            filter_sql = policy.filter_template
            for key, value in {**policy.parameters, **user_attrs}.items():
                filter_sql = filter_sql.replace(f"{{{{{key}}}}}", str(value))

            if "{{" not in filter_sql:
                applicable_filters.append(filter_sql)

        if not applicable_filters:
            return ""

        if len(applicable_filters) == 1:
            return applicable_filters[0]

        return " AND ".join(f"({f})" for f in applicable_filters)

    def apply_to_query(self, base_query: str, user_id: str, user_roles: list[str], resource: str) -> str:
        """将行级权限应用到 SQL 查询"""
        row_filter = self.get_filter(user_id, user_roles, resource)

        if not row_filter:
            return base_query

        upper_query = base_query.upper()
        if "WHERE" in upper_query:
            return f"{base_query} AND ({row_filter})"
        else:
            return f"{base_query} WHERE {row_filter}"
```

### 6.5 column_security.py - 列级权限与脱敏

```python
"""列级权限：控制可见字段并应用脱敏策略"""

import hashlib
from dataclasses import dataclass, field
from typing import Any


@dataclass
class ColumnPolicy:
    """列级权限策略"""
    column_name: str
    visible_to_roles: list[str] = field(default_factory=list)
    hidden_from_roles: list[str] = field(default_factory=list)
    mask_strategy: str = "full_mask"
    mask_config: dict = field(default_factory=dict)


class MaskingEngine:
    """脱敏引擎"""

    @staticmethod
    def apply(value: Any, strategy: str, config: dict = None) -> Any:
        config = config or {}

        if strategy == "full_mask":
            return "***"
        elif strategy == "partial_mask":
            if isinstance(value, str):
                show_start = config.get("show_start", 1)
                show_end = config.get("show_end", 1)
                if len(value) <= show_start + show_end:
                    return "*" * len(value)
                return value[:show_start] + "*" * (len(value) - show_start - show_end) + value[-show_end:]
            return "***"
        elif strategy == "phone_mask":
            if isinstance(value, str) and len(value) == 11:
                return value[:3] + "****" + value[7:]
            return "***"
        elif strategy == "id_card_mask":
            if isinstance(value, str) and len(value) >= 15:
                return value[:3] + "*" * (len(value) - 7) + value[-4:]
            return "***"
        elif strategy == "hash":
            h = hashlib.sha256(str(value).encode()).hexdigest()
            length = config.get("length", 8)
            return h[:length]
        elif strategy == "truncate_date":
            if isinstance(value, str):
                precision = config.get("precision", "month")
                if precision == "year":
                    return value[:4]
                elif precision == "month":
                    return value[:7]
            return "***"
        elif strategy == "generalize_number":
            if isinstance(value, (int, float)):
                bucket = config.get("bucket", 1000)
                lower = (int(value) // bucket) * bucket
                return f"{lower}-{lower + bucket}"
            return "***"
        elif strategy == "null":
            return None
        else:
            return "***"


class ColumnLevelSecurity:
    """列级权限引擎"""

    def __init__(self):
        self.policies: list[ColumnPolicy] = []
        self.masking = MaskingEngine()

    def add_policy(self, policy: ColumnPolicy) -> None:
        self.policies.append(policy)

    def filter_and_mask(
        self,
        data: list[dict],
        user_roles: list[str],
    ) -> list[dict]:
        """过滤列并应用脱敏"""
        if not data:
            return data

        result = []
        for row in data:
            filtered = {}
            for col, value in row.items():
                policy = self._find_policy(col)

                if policy is None:
                    filtered[col] = value
                    continue

                if self._is_visible(policy, user_roles):
                    filtered[col] = value
                else:
                    filtered[col] = self.masking.apply(value, policy.mask_strategy, policy.mask_config)

            result.append(filtered)

        return result

    def get_visible_columns(self, user_roles: list[str], all_columns: list[str]) -> list[str]:
        """获取用户可见的列列表"""
        visible = []
        for col in all_columns:
            policy = self._find_policy(col)
            if policy is None:
                visible.append(col)
            elif self._is_visible(policy, user_roles):
                visible.append(col)
        return visible

    def _find_policy(self, column_name: str) -> ColumnPolicy | None:
        for policy in self.policies:
            if policy.column_name == column_name:
                return policy
        return None

    def _is_visible(self, policy: ColumnPolicy, user_roles: list[str]) -> bool:
        if policy.hidden_from_roles:
            if any(role in policy.hidden_from_roles for role in user_roles):
                return False
        if policy.visible_to_roles:
            return any(role in policy.visible_to_roles for role in user_roles)
        return True
```

### 6.6 middleware.py - 权限中间件

```python
"""数据权限中间件：集成 RBAC、行级权限、列级脱敏和审计日志"""

from dataclasses import dataclass, field
from typing import Any

from rbac import RBACManager
from row_security import RowLevelSecurity
from column_security import ColumnLevelSecurity
from audit import AuditLogger, AuditAction


@dataclass
class AccessContext:
    """访问上下文"""
    user_id: str
    resource: str
    action: str = "view"
    ip_address: str = ""
    raw_sql: str = ""


@dataclass
class AccessResult:
    """访问结果"""
    allowed: bool
    data: list[dict] = field(default_factory=list)
    filtered_sql: str = ""
    message: str = ""
    audit_log_id: str = ""


class DataPermissionMiddleware:
    """数据权限中间件"""

    def __init__(self):
        self.rbac = RBACManager()
        self.row_security = RowLevelSecurity()
        self.column_security = ColumnLevelSecurity()
        self.audit = AuditLogger()

    def process_query(self, context: AccessContext, data: list[dict]) -> AccessResult:
        """处理数据查询：权限检查 → 行过滤 → 列脱敏 → 审计记录"""

        user_roles = [r.role_id for r in self.rbac.get_user_roles(context.user_id)]

        has_access, data_scope = self.rbac.check_access(context.user_id, context.resource, context.action)
        if not has_access:
            self.audit.log_access_denied(
                user_id=context.user_id,
                user_roles=user_roles,
                resource_id=context.resource,
                reason="RBAC 权限不足",
                ip_address=context.ip_address,
            )
            return AccessResult(
                allowed=False,
                message=f"权限不足: 用户 {context.user_id} 无权 {context.action} 资源 {context.resource}",
                audit_log_id=self.audit.logs[-1].log_id if self.audit.logs else "",
            )

        row_filter = self.row_security.get_filter(context.user_id, user_roles, context.resource)
        if row_filter and data:
            data = self._apply_row_filter(data, row_filter)

        filtered_data = self.column_security.filter_and_mask(data, user_roles)

        log = self.audit.log_data_access(
            user_id=context.user_id,
            user_roles=user_roles,
            resource_id=context.resource,
            query=context.raw_sql,
            row_count=len(filtered_data),
            columns_accessed=list(filtered_data[0].keys()) if filtered_data else [],
            ip_address=context.ip_address,
        )

        return AccessResult(
            allowed=True,
            data=filtered_data,
            message="访问成功",
            audit_log_id=log.log_id,
        )

    def _apply_row_filter(self, data: list[dict], filter_sql: str) -> list[dict]:
        """应用行级过滤（简化实现：解析简单条件）"""
        if "=" in filter_sql:
            parts = filter_sql.split("=")
            if len(parts) == 2:
                col = parts[0].strip().strip("'\"")
                val = parts[1].strip().strip("'\"")
                return [row for row in data if str(row.get(col, "")) == val]
        return data
```

## 七、常见误区

### 误区一：只做功能权限，不做数据权限

很多团队在第一版产品中只实现了功能权限（"谁能打开这个报表"），而忽略了数据权限（"打开后看到哪些数据"）。这在早期用户少、数据不敏感时没问题，但随着业务增长，数据泄露的风险会急剧上升。

功能权限和数据权限应该**同步设计**。哪怕第一版的数据权限只是简单的区域隔离，也比完全没有好。后期再从简单的区域隔离扩展到更复杂的 ABAC 策略，比从零开始要容易得多。

### 误区二：在应用层硬编码权限规则

有些开发者会把权限规则直接写在业务代码里：`if user.role == '华东总监': sql += "WHERE region = '华东'"`。这种方式在角色少、规则简单时能工作，但随着角色和规则的增加，代码会变得难以维护。

权限规则应该**数据化**——存在数据库或配置文件中，通过引擎动态加载和执行。这样管理员可以在不修改代码的情况下调整权限配置，也便于做权限审计和版本管理。

### 误区三：脱敏后数据不可关联

一个常见的错误是：对用户 ID 做哈希脱敏后，下游分析无法将不同报表中的同一用户关联起来。比如在"订单表"中用户 ID 被哈希为 `a3f2b1c8`，在"退货表"中也被哈希为 `a3f2b1c8`——这两个 `a3f2b1c8` 是同一个用户吗？

如果使用确定性哈希（同一输入始终产生同一输出），是可以关联的。但如果哈希算法加了随机盐（salt），每次哈希结果不同，关联就断了。

解决方案是：在脱敏前建立一个**映射表**（pseudonymization table），将原始值映射为假名 ID。下游分析使用假名 ID 进行关联，需要还原时通过映射表查回原始值。映射表本身要严格保护。

### 误区四：审计日志记太多或太少

审计日志的粒度是一个 tradeoff。记太少（只记"登录"和"退出"），出了安全事件无法追溯。记太多（每条 SQL 的每行结果都记），日志量会爆炸，存储成本高，查询也慢。

最佳实践是**分层记录**：
- 第一层：访问记录（谁、什么时间、访问了什么资源）——必须记
- 第二层：查询记录（执行了什么 SQL、返回了多少行）——建议记
- 第三层：结果记录（具体返回了哪些数据）——只在高安全场景记

## 小结与练习

### 小结

1. RBAC 控制"谁能访问什么功能"，ABAC 控制"在功能内看到什么数据"，两者互补而非替代——**RBAC 做基础，ABAC 做补充**
2. 行级权限通过 WHERE 条件过滤数据行，列级权限通过可见性控制和脱敏策略处理字段——两层叠加才能实现完整的数据隔离
3. 数据脱敏不是简单地"打马赛克"，需要根据业务场景选择策略：部分掩码保留可用性，哈希保留可关联性，泛化保留统计价值
4. 权限继承利用组织架构的层级关系自动扩展权限范围，避免逐人配置——但要注意"最小权限原则"，不要过度继承
5. 审计日志是权限体系的最后一道防线，分层记录（访问→查询→结果）在安全性和存储成本之间取得平衡

### 练习

#### 练习一：实现时间维度的数据权限

当前的行级权限只支持基于属性值的过滤（如 `region = '华东'`）。请扩展 `RowLevelSecurity`，使其支持时间维度的权限控制：不同角色能查看的时间范围不同（如普通员工只能看最近 7 天，经理能看最近 30 天，总监能看全部）。

要求：
- 定义时间范围策略，绑定到角色
- 支持多种时间字段名（`order_date`、`created_at` 等）
- 自动计算日期边界（基于当前日期）

#### 练习二：实现权限变更的实时生效

当前的权限配置在系统启动时加载，运行期间修改不会立即生效。请设计一个机制，使得权限变更能够实时推送到所有在线会话。

要求：
- 使用发布-订阅模式（Pub/Sub）
- 权限变更时发布事件，所有在线会话订阅并更新本地权限缓存
- 支持全量刷新和增量更新两种模式

#### 练习三：实现数据导出的水印功能

当用户导出数据（Excel、CSV）时，在数据中嵌入隐形水印，包含导出者的身份信息和导出时间。如果数据泄露，可以通过水印追溯来源。

要求：
- 水印不应影响数据的正常使用
- 水印应难以被发现和移除
- 设计至少两种水印嵌入策略

## 参考答案

### 练习一：时间维度的数据权限

**思路**：在 `RowPolicy` 中增加时间范围配置，用相对时间（如"最近 7 天"）而非绝对日期，这样策略配置一次后可以长期使用。在生成过滤条件时，根据当前日期动态计算边界。

**答案**：

```python
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import Optional


@dataclass
class TimeRangePolicy:
    """时间范围权限策略"""
    policy_id: str
    target_roles: list[str]
    time_field: str                        # 时间字段名，如 "order_date"
    lookback_days: Optional[int] = None    # 向前看多少天，None 表示不限
    start_date: Optional[str] = None       # 绝对起始日期，格式 YYYY-MM-DD
    end_date: Optional[str] = None         # 绝对结束日期


class TimeBasedRowSecurity:
    """时间维度行级权限"""

    def __init__(self):
        self.policies: list[TimeRangePolicy] = []

    def add_policy(self, policy: TimeRangePolicy) -> None:
        self.policies.append(policy)

    def get_time_filter(
        self,
        user_roles: list[str],
        reference_date: datetime | None = None,
    ) -> tuple[str, str] | None:
        """获取时间过滤条件，返回 (字段名, SQL 条件) 或 None"""

        if reference_date is None:
            reference_date = datetime.now()

        for policy in self.policies:
            if any(role in policy.target_roles for role in user_roles):
                conditions = []

                if policy.lookback_days is not None:
                    start = (reference_date - timedelta(days=policy.lookback_days)).strftime("%Y-%m-%d")
                    end = reference_date.strftime("%Y-%m-%d")
                    conditions.append(f"{policy.time_field} >= '{start}'")
                    conditions.append(f"{policy.time_field} <= '{end}'")
                else:
                    if policy.start_date:
                        conditions.append(f"{policy.time_field} >= '{policy.start_date}'")
                    if policy.end_date:
                        conditions.append(f"{policy.time_field} <= '{policy.end_date}'")

                if conditions:
                    return policy.time_field, " AND ".join(conditions)

        return None

    def apply_to_query(
        self,
        base_query: str,
        user_roles: list[str],
        reference_date: datetime | None = None,
    ) -> str:
        result = self.get_time_filter(user_roles, reference_date)
        if result is None:
            return base_query

        _, time_filter = result
        upper = base_query.upper()
        if "WHERE" in upper:
            return f"{base_query} AND ({time_filter})"
        return f"{base_query} WHERE {time_filter}"


def demo():
    security = TimeBasedRowSecurity()

    security.add_policy(TimeRangePolicy(
        policy_id="employee_7days",
        target_roles=["employee"],
        time_field="order_date",
        lookback_days=7,
    ))

    security.add_policy(TimeRangePolicy(
        policy_id="manager_30days",
        target_roles=["manager"],
        time_field="order_date",
        lookback_days=30,
    ))

    security.add_policy(TimeRangePolicy(
        policy_id="director_all",
        target_roles=["director"],
        time_field="order_date",
        start_date="2020-01-01",
    ))

    base = "SELECT * FROM sales_orders"

    for role in ["employee", "manager", "director"]:
        result = security.apply_to_query(base, [role])
        print(f"角色 '{role}':")
        print(f"  {result}")
        print()
```

**要点**：
- `lookback_days` 是相对时间，以当前日期为基准自动计算，不需要频繁更新策略
- `start_date`/`end_date` 是绝对时间，适合有明确时间边界的场景
- `get_time_filter` 返回元组 `(字段名, 条件)`，方便上层根据字段名做进一步处理
- 按策略列表顺序匹配，第一个匹配的策略生效，因此要把更具体的策略放在前面

### 练习二：权限变更的实时生效

**思路**：使用发布-订阅模式。权限管理器维护一个事件总线，当权限发生变更时发布事件。每个在线会话在初始化时订阅事件，收到事件后更新本地权限缓存。

**答案**：

```python
import time
import threading
from dataclasses import dataclass, field
from typing import Callable, Any
from collections import defaultdict


@dataclass
class PermissionEvent:
    """权限变更事件"""
    event_id: str
    event_type: str           # role_change / policy_change / attribute_change
    target_user: str
    change_detail: dict
    timestamp: float = field(default_factory=time.time)


class EventBus:
    """事件总线"""

    def __init__(self):
        self._subscribers: dict[str, list[Callable]] = defaultdict(list)
        self._lock = threading.Lock()

    def subscribe(self, event_type: str, callback: Callable) -> None:
        with self._lock:
            self._subscribers[event_type].append(callback)

    def unsubscribe(self, event_type: str, callback: Callable) -> None:
        with self._lock:
            if event_type in self._subscribers:
                self._subscribers[event_type] = [
                    cb for cb in self._subscribers[event_type] if cb is not callback
                ]

    def publish(self, event: PermissionEvent) -> None:
        with self._lock:
            callbacks = list(self._subscribers.get(event.event_type, []))
            callbacks.extend(self._subscribers.get("*", []))

        for callback in callbacks:
            try:
                callback(event)
            except Exception as exc:
                print(f"事件处理异常: {exc}")


class PermissionCache:
    """权限缓存（会话级别）"""

    def __init__(self, session_id: str, event_bus: EventBus):
        self.session_id = session_id
        self._cache: dict[str, Any] = {}
        self._version: int = 0
        self._event_bus = event_bus

        event_bus.subscribe("role_change", self._on_permission_change)
        event_bus.subscribe("policy_change", self._on_permission_change)
        event_bus.subscribe("attribute_change", self._on_permission_change)
        event_bus.subscribe("full_refresh", self._on_full_refresh)

    def get(self, key: str) -> Any:
        return self._cache.get(key)

    def set(self, key: str, value: Any) -> None:
        self._cache[key] = value

    def invalidate(self, key: str) -> None:
        self._cache.pop(key, None)

    def clear(self) -> None:
        self._cache.clear()

    @property
    def version(self) -> int:
        return self._version

    def _on_permission_change(self, event: PermissionEvent) -> None:
        affected_keys = [
            k for k in self._cache
            if event.target_user in k or event.event_type in k
        ]
        for key in affected_keys:
            del self._cache[key]

        self._version += 1
        print(f"  会话 {self.session_id}: 增量更新 v{self._version}，清除 {len(affected_keys)} 个缓存项")

    def _on_full_refresh(self, event: PermissionEvent) -> None:
        self._cache.clear()
        self._version += 1
        print(f"  会话 {self.session_id}: 全量刷新 v{self._version}")


class PermissionManager:
    """带实时推送的权限管理器"""

    def __init__(self):
        self.event_bus = EventBus()
        self.sessions: dict[str, PermissionCache] = {}
        self._change_log: list[PermissionEvent] = []

    def create_session(self, session_id: str) -> PermissionCache:
        cache = PermissionCache(session_id, self.event_bus)
        self.sessions[session_id] = cache
        return cache

    def change_user_role(self, operator_id: str, target_user: str, new_role: str) -> None:
        import uuid
        event = PermissionEvent(
            event_id=uuid.uuid4().hex[:8],
            event_type="role_change",
            target_user=target_user,
            change_detail={"new_role": new_role, "operator": operator_id},
        )
        self._change_log.append(event)
        self.event_bus.publish(event)

    def change_policy(self, policy_id: str, change_detail: dict) -> None:
        import uuid
        event = PermissionEvent(
            event_id=uuid.uuid4().hex[:8],
            event_type="policy_change",
            target_user="*",
            change_detail={"policy_id": policy_id, **change_detail},
        )
        self._change_log.append(event)
        self.event_bus.publish(event)

    def force_full_refresh(self) -> None:
        import uuid
        event = PermissionEvent(
            event_id=uuid.uuid4().hex[:8],
            event_type="full_refresh",
            target_user="*",
            change_detail={"reason": "手动触发全量刷新"},
        )
        self.event_bus.publish(event)


def demo():
    manager = PermissionManager()

    cache_a = manager.create_session("session_001")
    cache_b = manager.create_session("session_002")

    cache_a.set("user_zhangsan:roles", ["employee"])
    cache_a.set("sales_report:row_filter", "region = '华东'")

    print("权限变更前:")
    print(f"  session_001 版本: {cache_a.version}")
    print(f"  session_002 版本: {cache_b.version}")

    print("\n触发角色变更:")
    manager.change_user_role("admin", "user_zhangsan", "manager")

    print(f"\n权限变更后:")
    print(f"  session_001 版本: {cache_a.version}")
    print(f"  session_002 版本: {cache_b.version}")

    print("\n触发全量刷新:")
    manager.force_full_refresh()


if __name__ == "__main__":
    demo()
```

**要点**：
- `EventBus` 使用线程锁保证并发安全，支持通配符订阅（`"*"` 匹配所有事件类型）
- `PermissionCache` 在初始化时自动订阅相关事件，收到事件后清除受影响的缓存项
- 增量更新只清除与变更目标相关的缓存键，全量刷新清空所有缓存
- `_change_log` 记录所有权限变更事件，便于审计和回溯

### 练习三：数据导出的水印功能

**思路**：利用数据本身的微小变化来嵌入水印。比如对数值型字段做四舍五入时，根据水印比特选择向上或向下取整。或者在文本字段的特定位置插入不可见的 Unicode 字符。这些变化对数据使用者几乎不可见，但可以通过统计分析或字符检测提取出来。

**答案**：

```python
import hashlib
import time
import json
from typing import Any


class NumericWatermark:
    """数值水印：通过取整方向嵌入比特"""

    @staticmethod
    def embed(value: float, bit: int, precision: int = 2) -> float:
        """嵌入一个比特到数值中

        规则：
        - bit=0: 向下取整到最近的偶数精度位
        - bit=1: 向上取整到最近的奇数精度位
        """
        factor = 10 ** precision
        scaled = value * factor
        floor_val = int(scaled)

        if bit == 0:
            if floor_val % 2 != 0:
                floor_val -= 1
        else:
            if floor_val % 2 == 0:
                floor_val += 1

        return floor_val / factor

    @staticmethod
    def extract(value: float, precision: int = 2) -> int:
        """提取数值中嵌入的比特"""
        factor = 10 ** precision
        scaled = int(value * factor)
        return scaled % 2


class UnicodeWatermark:
    """Unicode 水印：插入不可见字符"""

    ZERO_WIDTH_CHARS = {
        "0": "\u200b",  # ZERO WIDTH SPACE
        "1": "\u200c",  # ZERO WIDTH NON-JOINER
    }
    REVERSE_MAP = {v: k for k, v in ZERO_WIDTH_CHARS.items()}

    @staticmethod
    def embed(text: str, binary_message: str, position: str = "end") -> str:
        """在文本中嵌入二进制消息（使用零宽字符）"""
        watermark = ""
        for bit in binary_message:
            if bit in UnicodeWatermark.ZERO_WIDTH_CHARS:
                watermark += UnicodeWatermark.ZERO_WIDTH_CHARS[bit]

        if position == "end":
            return text + watermark
        elif position == "start":
            return watermark + text
        else:
            mid = len(text) // 2
            return text[:mid] + watermark + text[mid:]

    @staticmethod
    def extract(text: str) -> str:
        """从文本中提取嵌入的二进制消息"""
        binary = ""
        for char in text:
            if char in UnicodeWatermark.REVERSE_MAP:
                binary += UnicodeWatermark.REVERSE_MAP[char]
        return binary


class ExportWatermarker:
    """导出水印器：在导出数据中嵌入追踪信息"""

    def __init__(self, secret_key: str = "default_secret"):
        self.secret_key = secret_key

    def create_watermark_payload(self, user_id: str, export_time: float = None) -> dict:
        if export_time is None:
            export_time = time.time()

        payload = {
            "uid": user_id,
            "ts": int(export_time),
            "nonce": hashlib.md5(f"{user_id}{export_time}".encode()).hexdigest()[:6],
        }
        return payload

    def embed_watermark(
        self,
        data: list[dict],
        user_id: str,
        numeric_fields: list[str] | None = None,
        text_fields: list[str] | None = None,
    ) -> list[dict]:
        """在数据中嵌入水印"""
        payload = self.create_watermark_payload(user_id)
        message = json.dumps(payload, separators=(",", ":"))
        binary = self._text_to_binary(message)

        result = []
        binary_idx = 0

        for row in data:
            watermarked_row = {}

            for col, value in row.items():
                if numeric_fields and col in numeric_fields and isinstance(value, (int, float)):
                    if binary_idx < len(binary):
                        bit = int(binary[binary_idx])
                        watermarked_row[col] = NumericWatermark.embed(float(value), bit)
                        binary_idx += 1
                    else:
                        watermarked_row[col] = value
                elif text_fields and col in text_fields and isinstance(value, str):
                    if binary_idx < len(binary):
                        remaining = binary[binary_idx:binary_idx + 20]
                        watermarked_row[col] = UnicodeWatermark.embed(value, remaining)
                        binary_idx += 20
                    else:
                        watermarked_row[col] = value
                else:
                    watermarked_row[col] = value

            result.append(watermarked_row)

        return result

    def detect_watermark(
        self,
        data: list[dict],
        numeric_fields: list[str] | None = None,
        text_fields: list[str] | None = None,
    ) -> dict | None:
        """检测数据中的水印"""
        binary = ""

        if numeric_fields:
            for row in data:
                for col in numeric_fields:
                    if col in row and isinstance(row[col], (int, float)):
                        bit = NumericWatermark.extract(float(row[col]))
                        binary += str(bit)

        if text_fields:
            for row in data:
                for col in text_fields:
                    if col in row and isinstance(row[col], str):
                        extracted = UnicodeWatermark.extract(row[col])
                        binary += extracted

        if not binary:
            return None

        try:
            text = self._binary_to_text(binary)
            payload = json.loads(text)
            return payload
        except (json.JSONDecodeError, UnicodeDecodeError):
            return None

    @staticmethod
    def _text_to_binary(text: str) -> str:
        return "".join(format(ord(c), "08b") for c in text)

    @staticmethod
    def _binary_to_text(binary: str) -> str:
        text = ""
        for i in range(0, len(binary) - 7, 8):
            byte = binary[i:i + 8]
            if len(byte) == 8:
                text += chr(int(byte, 2))
        return text


def demo():
    watermarker = ExportWatermarker(secret_key="company_secret_2024")

    sales_data = [
        {"product": "手机", "amount": 5999.00, "quantity": 150, "region": "华东"},
        {"product": "笔记本", "amount": 8999.00, "quantity": 80, "region": "华南"},
        {"product": "平板", "amount": 3999.00, "quantity": 200, "region": "华北"},
    ]

    print("原始数据:")
    for row in sales_data:
        print(f"  {row}")

    watermarked = watermarker.embed_watermark(
        data=sales_data,
        user_id="user_zhangsan",
        numeric_fields=["amount", "quantity"],
        text_fields=["region"],
    )

    print("\n水印嵌入后:")
    for row in watermarked:
        print(f"  {row}")

    detected = watermarker.detect_watermark(
        data=watermarked,
        numeric_fields=["amount", "quantity"],
        text_fields=["region"],
    )

    print(f"\n检测到的水印: {detected}")


if __name__ == "__main__":
    demo()
```

**要点**：
- 数值水印通过控制取整方向（奇偶性）嵌入比特，对原始值的影响极小（最多 0.01）
- Unicode 水印使用零宽字符（`\u200b` 和 `\u200c`），在渲染时完全不可见，但可以被程序检测
- 水印载荷包含用户 ID、导出时间和随机数，确保每次导出的水印唯一
- 检测时需要知道哪些字段嵌入了水印，这作为密钥的一部分由安全团队掌握
