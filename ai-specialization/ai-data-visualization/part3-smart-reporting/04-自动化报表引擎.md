## 场景引入

每周一早上九点，数据团队的微信群准时热闹起来：

"上周的周报出了吗？"
"财务那边的月报模板换了，你用的是新版吗？"
"运营说他们要 Excel 格式，不是 PDF。"
"老板说要在报表里加一个毛利率的趋势图。"

这些消息的背后，是一个高度依赖人工的报表流程：数据分析师手动从 BI 平台导出数据，手动填充到报表模板里，手动导出 PDF，手动发邮件。每个月，一个中型公司的数据团队要产出 30-50 份定期报表，每份报表的制作流程包括数据提取、清洗、计算、填充、排版、导出、分发七个步骤。如果每个步骤需要 10 分钟，一份报表就需要 70 分钟，50 份报表就是 3,500 分钟——接近 60 个小时的人工工时。

更让人头疼的是**重复性错误**。手动操作越多，出错概率越高：数据复制粘贴错位、模板版本用错、分发遗漏收件人。每次出错都要花更多时间排查和修正。

自动化报表引擎要解决的就是这个问题：**让数据提取、模板填充、格式转换、定时分发全部自动化，把人的参与降到最低。** 本课会从报表引擎的核心架构讲起，带你构建一个轻量级但功能完整的自动化报表系统。

## 核心概念

### 一、报表引擎的核心架构

一个完整的报表引擎可以拆分为三层，每层职责清晰，互不耦合：

```
报表引擎三层架构：

  ┌─────────────────────────────────────────────────┐
  │                 调度层 (Scheduler)                │
  │  定时触发 / 事件触发 / 手动触发                     │
  └───────────────────────┬─────────────────────────┘
                          │
  ┌───────────────────────▼─────────────────────────┐
  │                 数据层 (Data Layer)               │
  │                                                  │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
  │  │ 数据源    │  │ 数据转换  │  │ 指标计算  │      │
  │  │ 连接器    │─▶│ Pipeline │─▶│ 引擎     │      │
  │  └──────────┘  └──────────┘  └──────────┘      │
  └───────────────────────┬─────────────────────────┘
                          │ 结构化数据
  ┌───────────────────────▼─────────────────────────┐
  │                 渲染层 (Render Layer)             │
  │                                                  │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
  │  │ 模板     │  │ 数据     │  │ 图表     │      │
  │  │ 引擎     │◀─│ 绑定器   │◀─│ 生成器   │      │
  │  └──────────┘  └──────────┘  └──────────┘      │
  └───────────────────────┬─────────────────────────┘
                          │ 渲染后的文档
  ┌───────────────────────▼─────────────────────────┐
  │                 输出层 (Output Layer)             │
  │                                                  │
  │  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐   │
  │  │  HTML  │ │  PDF   │ │  Excel │ │  图片  │   │
  │  └────────┘ └────────┘ └────────┘ └────────┘   │
  └───────────────────────┬─────────────────────────┘
                          │
  ┌───────────────────────▼─────────────────────────┐
  │                 分发层 (Distribution)             │
  │  邮件发送 / 企业微信 / 钉钉 / 文件服务器           │
  └─────────────────────────────────────────────────┘
```

**数据层**负责从各种数据源（数据库、API、CSV 文件）获取数据，经过清洗和转换后，计算出报表需要的指标。这一层的核心挑战是数据源的多样性——不同报表可能需要从 MySQL、ClickHouse、Google Analytics 等不同系统获取数据，引擎需要提供统一的数据访问接口。

**渲染层**负责将数据填充到模板中，生成最终的文档。这一层的核心是模板引擎——它决定了报表的外观、布局和数据呈现方式。好的模板引擎应该让非技术人员也能修改报表样式，而不需要改动代码。

**输出层**负责将渲染结果转换为目标格式。同一份报表可能需要同时输出为 PDF（用于邮件发送）、Excel（用于数据二次分析）、HTML（用于在线查看）。每种格式有自己的排版特性和限制，引擎需要处理好格式差异。

### 二、模板驱动的报表组装

模板是报表引擎的核心概念。一个好的模板系统应该做到：数据和样式分离、模板可复用、非技术人员可编辑。

```
模板驱动的工作流程：

  模板定义（Jinja2 模板）：
  ┌─────────────────────────────────────────┐
  │ # {{ report_title }}                    │
  │                                         │
  │ 报告周期：{{ period }}                   │
  │                                         │
  │ ## 核心指标                              │
  │ | 指标 | 本期 | 上期 | 变化 |            │
  │ |------|------|------|------|            │
  │ {% for m in metrics %}                  │
  │ | {{ m.name }} | {{ m.current }} |      │
  │   {{ m.previous }} | {{ m.change }} |   │
  │ {% endfor %}                            │
  └─────────────────────────────────────────┘
            +
  数据上下文：
  ┌─────────────────────────────────────────┐
  │ {                                       │
  │   "report_title": "2025年Q1销售周报",    │
  │   "period": "第12周",                    │
  │   "metrics": [                          │
  │     {"name": "GMV", "current": "4500万", │
  │      "previous": "4020万",              │
  │      "change": "+11.9%"}               │
  │   ]                                     │
  │ }                                       │
  └─────────────────────────────────────────┘
            │
            ▼
  渲染结果：
  ┌─────────────────────────────────────────┐
  │ # 2025年Q1销售周报                       │
  │                                         │
  │ 报告周期：第12周                          │
  │                                         │
  │ ## 核心指标                              │
  │ | 指标 | 本期 | 上期 | 变化 |            │
  │ |------|------|------|------|            │
  │ | GMV | 4500万 | 4020万 | +11.9% |      │
  └─────────────────────────────────────────┘
```

Jinja2 是 Python 生态中最成熟的模板引擎，它支持变量替换、条件判断、循环、过滤器、模板继承等特性，足以覆盖绝大多数报表场景。

模板继承是特别有用的特性：你可以定义一个基础模板（base template）包含页眉、页脚、目录结构，然后让每种报表类型继承基础模板并覆盖特定区域。这样修改一次页眉样式，所有报表都会自动更新。

### 三、多格式输出策略

同一份报表内容需要输出为多种格式，每种格式有不同的技术挑战：

```
格式特性对比：

格式    适合场景           技术方案          挑战
──────────────────────────────────────────────────────
HTML    在线查看、分享      Jinja2 直接渲染    交互性有限
PDF     邮件附件、存档      weasyprint /       排版精确度
                            pdfkit             图表渲染
Excel   数据二次分析        openpyxl           样式控制
                            pandas ExcelWriter 多 Sheet
图片    社交媒体、IM        matplotlib         分辨率
                            plotly kaleido     中文字体
```

HTML 输出是最简单的——Jinja2 渲染出 HTML 字符串，写入文件即可。PDF 输出有两种主流方案：weasyprint（纯 Python，CSS 排版）和 pdfkit（依赖 wkhtmltopdf 二进制）。weasyprint 的优势是不需要安装系统级依赖，但处理复杂表格时偶尔会有排版偏差。pdfkit 基于 WebKit 引擎，排版更可靠，但需要额外安装 wkhtmltopdf。

Excel 输出需要特别注意数据类型的处理。pandas 的 `to_excel` 方法适合简单的数据导出，但如果需要控制单元格样式（合并单元格、条件格式、图表），就需要使用 openpyxl 直接操作。

### 四、数据绑定与动态渲染

数据绑定是将数据源的输出与模板变量关联起来的机制。一个好的绑定系统应该支持以下能力：

```
数据绑定的三种模式：

模式一：简单绑定
  数据键 ──▶ 模板变量
  "total_gmv" ──▶ {{ total_gmv }}

模式二：循环绑定
  数据列表 ──▶ 模板循环
  [{"name": "华东", "value": 1500万}] ──▶ {% for r in regions %} {{ r.name }} {% endfor %}

模式三：计算绑定
  原始数据 ──▶ 计算函数 ──▶ 模板变量
  [本月数据, 上月数据] ──▶ calc_change() ──▶ {{ change_rate }}


动态渲染决策树：

  报表类型 ──▶ 加载对应模板
  数据源配置 ──▶ 执行数据查询
  查询结果 ──▶ 执行计算绑定
  计算结果 ──▶ 填充模板变量
  填充结果 ──▶ 渲染为目标格式
```

在工程实践中，数据绑定通常通过一个"数据上下文"对象来实现。数据层的输出是一个字典，模板引擎直接读取这个字典中的值。关键是保持数据层和渲染层的解耦——数据层不需要知道模板的结构，模板也不需要知道数据的来源。

### 五、报表调度与编排

当报表数量增多时，手动触发每份报表变得不可持续。调度系统让报表按预定规则自动执行：

```
调度策略：

┌───────────────────────────────────────────────────┐
│                  调度器 (Scheduler)                │
│                                                   │
│  ┌─────────────┐  ┌─────────────┐                │
│  │ Cron 调度    │  │ 事件触发     │                │
│  │             │  │             │                │
│  │ 每周一 9:00 │  │ 数据更新后   │                │
│  │ 每月 1 日   │  │ ETL 完成后   │                │
│  └──────┬──────┘  └──────┬──────┘                │
│         │                │                        │
│         ▼                ▼                        │
│  ┌──────────────────────────────────────────┐    │
│  │           报表任务队列                    │    │
│  │                                          │    │
│  │  [周报] → [月报] → [专题分析] → [日报]   │    │
│  └──────────────────────────────────────────┘    │
│                      │                            │
│                      ▼                            │
│  ┌──────────────────────────────────────────┐    │
│  │           依赖编排                        │    │
│  │                                          │    │
│  │  数据提取 ──▶ 指标计算 ──▶ 模板渲染       │    │
│  │      │           │           │           │    │
│  │      ▼           ▼           ▼           │    │
│  │   重试 3 次    降级策略     错误通知       │    │
│  └──────────────────────────────────────────┘    │
└───────────────────────────────────────────────────┘
```

调度系统还需要处理**依赖关系**。比如"月度销售报表"依赖"月度数据汇总"任务先完成，"管理层驾驶舱"依赖"销售报表""运营报表""财务报表"三份子报表都完成。这种依赖关系可以用 DAG（有向无环图）来建模。

错误处理是调度系统的另一个关键点。数据查询超时怎么办？模板渲染报错怎么办？分发邮件被退怎么办？每个环节都需要重试策略和降级方案。一个实用的做法是：重试 3 次，每次间隔翻倍；如果仍然失败，发送告警通知并跳过本次执行。

### 数据提供器

```python
# data_provider.py
import pandas as pd
import numpy as np
from datetime import datetime, timedelta


class DataProvider:
    """统一的数据提供接口，屏蔽不同数据源的差异。"""

    def __init__(self, seed: int = 42):
        self._rng = np.random.default_rng(seed)
        self._cache: dict[str, pd.DataFrame] = {}

    def get_data(self, source_config: dict) -> pd.DataFrame:
        """根据配置获取数据。支持缓存，避免重复查询。"""
        cache_key = f"{source_config['type']}_{source_config['period']}"

        if cache_key in self._cache:
            return self._cache[cache_key]

        source_type = source_config["type"]
        period = source_config["period"]

        if source_type == "sales":
            df = self._generate_sales_data(period)
        elif source_type == "finance":
            df = self._generate_finance_data(period)
        else:
            raise ValueError(f"未知数据源类型: {source_type}")

        self._cache[cache_key] = df
        return df

    def _generate_sales_data(self, period: str) -> pd.DataFrame:
        """生成模拟销售数据。"""
        regions = ["华东", "华南", "华北", "西南", "华中"]
        channels = ["线上自营", "线下门店", "第三方平台", "企业客户"]

        if period == "current_week":
            start = datetime(2025, 3, 17)
        elif period == "previous_week":
            start = datetime(2025, 3, 10)
        else:
            start = datetime(2025, 3, 1)

        dates = pd.date_range(start=start, periods=7, freq="D")

        records = []
        for date in dates:
            for region in regions:
                for channel in channels:
                    base = self._rng.normal(8000, 2000)
                    records.append({
                        "date": date,
                        "region": region,
                        "channel": channel,
                        "gmv": round(max(0, base), 2),
                        "order_count": max(1, int(base / 120)),
                        "customer_count": max(1, int(base / 180)),
                    })

        return pd.DataFrame(records)

    def _generate_finance_data(self, period: str) -> pd.DataFrame:
        """生成模拟财务数据。"""
        categories = ["销售收入", "营销费用", "运营成本", "研发投入", "管理费用"]
        records = []
        for cat in categories:
            base = self._rng.normal(5_000_000, 1_500_000)
            records.append({
                "category": cat,
                "amount": round(max(0, base), 2),
                "budget": round(max(0, base * self._rng.uniform(0.9, 1.2)), 2),
            })
        return pd.DataFrame(records)

    def clear_cache(self):
        self._cache.clear()
```

### 模板管理器

```python
# template_manager.py
import os
from jinja2 import Environment, FileSystemLoader, select_autoescape


class TemplateManager:
    """模板管理器：加载、渲染 Jinja2 模板。"""

    def __init__(self, template_dir: str = "templates"):
        self.template_dir = template_dir
        os.makedirs(template_dir, exist_ok=True)
        self._ensure_base_templates()

        self.env = Environment(
            loader=FileSystemLoader(template_dir),
            autoescape=select_autoescape(["html"]),
        )
        self.env.filters["format_number"] = self._format_number
        self.env.filters["format_percent"] = self._format_percent

    def render(self, template_name: str, context: dict) -> str:
        """渲染模板，返回字符串。"""
        template = self.env.get_template(template_name)
        return template.render(**context)

    def render_string(self, template_str: str, context: dict) -> str:
        """直接渲染模板字符串。"""
        template = self.env.from_string(template_str)
        return template.render(**context)

    @staticmethod
    def _format_number(value: float) -> str:
        if abs(value) >= 10_000_000:
            return f"{value / 10_000_000:.1f}千万"
        if abs(value) >= 10_000:
            return f"{value / 10_000:.1f}万"
        return f"{value:,.0f}"

    @staticmethod
    def _format_percent(value: float) -> str:
        return f"{value:+.1%}"

    def _ensure_base_templates(self):
        """确保基础模板文件存在。"""
        base_path = os.path.join(self.template_dir, "base.html")
        if not os.path.exists(base_path):
            with open(base_path, "w", encoding="utf-8") as f:
                f.write(self._base_template_content())

        weekly_path = os.path.join(self.template_dir, "weekly_report.html")
        if not os.path.exists(weekly_path):
            with open(weekly_path, "w", encoding="utf-8") as f:
                f.write(self._weekly_template_content())

    @staticmethod
    def _base_template_content() -> str:
        return '''<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>{{ title }}</title>
<style>
  body { font-family: "Microsoft YaHei", sans-serif; margin: 40px; color: #333; }
  h1 { color: #1a1a2e; border-bottom: 2px solid #16213e; padding-bottom: 10px; }
  h2 { color: #16213e; margin-top: 30px; }
  table { border-collapse: collapse; width: 100%; margin: 15px 0; }
  th, td { border: 1px solid #ddd; padding: 10px 14px; text-align: right; }
  th { background-color: #16213e; color: white; }
  tr:nth-child(even) { background-color: #f8f9fa; }
  .positive { color: #28a745; font-weight: bold; }
  .negative { color: #dc3545; font-weight: bold; }
  .summary-box { background: #f0f4f8; padding: 20px; border-radius: 8px; margin: 20px 0; }
  .footer { margin-top: 40px; color: #888; font-size: 12px; border-top: 1px solid #eee; padding-top: 10px; }
</style>
</head>
<body>
{% block content %}{% endblock %}
<div class="footer">报表生成时间：{{ generated_at }} | 自动生成，无需回复</div>
</body>
</html>'''

    @staticmethod
    def _weekly_template_content() -> str:
        return '''{% extends "base.html" %}
{% block content %}
<h1>{{ title }}</h1>
<p>报告周期：{{ period }}</p>

<div class="summary-box">
  <strong>本周摘要：</strong> {{ summary }}
</div>

<h2>核心指标</h2>
<table>
  <tr>
    <th style="text-align:left">指标</th>
    <th>本期</th>
    <th>上期</th>
```

```python
import os
from datetime import datetime


class OutputRenderer:
    """多格式输出渲染器，支持 HTML、Excel、纯文本。"""

    def __init__(self, output_dir: str = "output"):
        self.output_dir = output_dir
        os.makedirs(output_dir, exist_ok=True)

    def render_html(self, html_content: str, filename: str) -> str:
        """输出 HTML 文件。"""
        filepath = os.path.join(self.output_dir, filename)
        with open(filepath, "w", encoding="utf-8") as f:
            f.write(html_content)
        return filepath

    def render_excel(self, data_dict: dict[str, "pd.DataFrame"], filename: str) -> str:
        """输出 Excel 文件，支持多 Sheet。"""
        import pandas as pd

        filepath = os.path.join(self.output_dir, filename)
        with pd.ExcelWriter(filepath, engine="openpyxl") as writer:
            for sheet_name, df in data_dict.items():
                df.to_excel(writer, sheet_name=sheet_name, index=False)
        return filepath

    def render_text(self, content: str, filename: str) -> str:
        """输出纯文本文件。"""
        filepath = os.path.join(self.output_dir, filename)
        with open(filepath, "w", encoding="utf-8") as f:
            f.write(content)
        return filepath

    def get_output_path(self, filename: str) -> str:
        return os.path.join(self.output_dir, filename)
```

```python
# engine.py
from datetime import datetime
from config import ReportConfig
from data_provider import DataProvider
from template_manager import TemplateManager
from output_renderer import OutputRenderer


class ReportEngine:
    """报表引擎：协调数据获取、模板渲染、格式输出的完整流程。"""

    def __init__(self):
        self.data_provider = DataProvider()
        self.template_manager = TemplateManager()
        self.output_renderer = OutputRenderer()
        self._report_registry: dict[str, ReportConfig] = {}

    def register_report(self, config: ReportConfig):
        """注册报表配置。"""
        self._report_registry[config.report_id] = config

    def generate_report(self, report_id: str) -> dict[str, str]:
        """生成指定报表，返回各格式的输出路径。"""
        config = self._report_registry.get(report_id)
        if not config:
            raise ValueError(f"未注册的报表: {report_id}")

        print(f"  [{report_id}] 开始生成「{config.title}」...")

        # 1. 获取数据
        print(f"  [{report_id}] 获取数据...")
        data_context = self._fetch_data(config)

        # 2. 渲染模板
        print(f"  [{report_id}] 渲染模板...")
        rendered_html = self.template_manager.render(
            config.template_name, data_context
        )

        # 3. 输出各格式
        output_paths = {}
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

        for fmt in config.output_formats:
            filename = f"{report_id}_{timestamp}.{fmt}"
            if fmt == "html":
                path = self.output_renderer.render_html(rendered_html, filename)
            elif fmt == "excel":
                path = self.output_renderer.render_excel(
                    self._build_excel_data(config, data_context), filename
                )
            elif fmt == "txt":
                path = self.output_renderer.render_text(rendered_html, filename)
            else:
                print(f"  [{report_id}] 不支持的格式: {fmt}")
                continue
            output_paths[fmt] = path
            print(f"  [{report_id}] 已输出 {fmt.upper()}: {path}")

        return output_paths

    def _fetch_data(self, config: ReportConfig) -> dict:
        """获取并处理数据，构建模板上下文。"""
        self.data_provider.clear_cache()

        all_data = {}
        for source in config.data_sources:
            period = source["period"]
            df = self.data_provider.get_data(source)
            all_data[period] = df

        return self._build_template_context(config, all_data)

    def _build_template_context(self, config: ReportConfig, all_data: dict) -> dict:
        """将原始数据转换为模板需要的上下文格式。"""
        context = {
            "title": config.title,
            "generated_at": datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
            "period": config.parameters.get("period", "本周"),
            "summary": "",
            "metrics": [],
            "regions": [],
        }

        current = all_data.get("current_week") or all_data.get("current_month")
        previous = all_data.get("previous_week") or all_data.get("previous_month")

        if current is not None:
            # 计算核心指标
            for metric_col in ["gmv", "order_count", "customer_count"]:
                if metric_col not in current.columns:
                    continue
                curr_val = current[metric_col].sum()
                prev_val = previous[metric_col].sum() if previous is not None else curr_val
                change = (curr_val - prev_val) / prev_val if prev_val else 0

                metric_names = {
                    "gmv": "GMV",
                    "order_count": "订单量",
                    "customer_count": "客户数",
                }
                context["metrics"].append({
                    "name": metric_names.get(metric_col, metric_col),
                    "current": curr_val,
                    "previous": prev_val,
                    "change": change,
                })

            # 区域明细
            if "region" in current.columns and "gmv" in current.columns:
                region_stats = current.groupby("region").agg({
                    "gmv": "sum",
                    "order_count": "sum",
                    "customer_count": "sum",
                }).reset_index()

                for _, row in region_stats.iterrows():
                    context["regions"].append({
                        "name": row["region"],
                        "gmv": row["gmv"],
                        "order_count": int(row["order_count"]),
                        "customer_count": int(row["customer_count"]),
                    })

            # 生成摘要
            if context["metrics"]:
                gmv_metric = next(
                    (m for m in context["metrics"] if m["name"] == "GMV"), None
                )
                if gmv_metric:
                    direction = "增长" if gmv_metric["change"] > 0 else "下降"
                    context["summary"] = (
                        f"本期 GMV 为 {gmv_metric['current']:,.0f}，"
                        f"{direction} {abs(gmv_metric['change']):.1%}。"
                    )

        return context

    def _build_excel_data(self, config: ReportConfig, context: dict) -> dict:
        """构建 Excel 输出所需的 DataFrame 字典。"""
        import pandas as pd

        sheets = {}

        if context["metrics"]:
            sheets["核心指标"] = pd.DataFrame(context["metrics"])

        if context["regions"]:
            sheets["区域明细"] = pd.DataFrame(context["regions"])

        return sheets

    def generate_all(self) -> dict[str, dict[str, str]]:
        """生成所有已注册的报表。"""
        results = {}
        for report_id in self._report_registry:
            results[report_id] = self.generate_report(report_id)
        return results
```

```python
# scheduler.py
import time
from datetime import datetime
from engine import ReportEngine


class ReportScheduler:
    """报表调度器：支持定时和手动触发报表生成。"""

    def __init__(self, engine: ReportEngine):
        self.engine = engine
        self._schedules: list[dict] = []
        self._running = False

    def add_schedule(self, report_id: str, trigger_time: str):
        """添加定时任务。trigger_time 格式如 'monday 09:00' 或 '1st 10:00'。"""
        self._schedules.append({
            "report_id": report_id,
            "trigger_time": trigger_time,
            "last_run": None,
        })

    def run_once(self, report_id: str) -> dict[str, str]:
        """手动触发一次报表生成。"""
        print(f"\n[调度器] 手动触发报表: {report_id}")
        return self.engine.generate_report(report_id)

    def run_all_once(self) -> dict[str, dict[str, str]]:
        """手动触发所有报表。"""
        print(f"\n[调度器] 触发所有报表生成")
        return self.engine.generate_all()

    def start_loop(self, check_interval: int = 60):
        """启动调度循环（简化版，生产环境应使用 APScheduler）。"""
        self._running = True
        print(f"[调度器] 启动调度循环，检查间隔 {check_interval} 秒")

        while self._running:
            now = datetime.now()
            for schedule in self._schedules:
                if self._should_run(schedule, now):
                    report_id = schedule["report_id"]
                    print(f"\n[调度器] 定时触发: {report_id}")
                    try:
                        self.engine.generate_report(report_id)
                        schedule["last_run"] = now
                    except Exception as e:
                        print(f"[调度器] 报表 {report_id} 生成失败: {e}")

            time.sleep(check_interval)

    def stop(self):
        self._running = False

    def _should_run(self, schedule: dict, now: datetime) -> bool:
        """判断是否应该触发执行（简化逻辑）。"""
        trigger = schedule["trigger_time"]
        last_run = schedule["last_run"]

        if last_run and (now - last_run).total_seconds() < 3600:
            return False

        weekday_map = {
            "monday": 0, "tuesday": 1, "wednesday": 2,
            "thursday": 3, "friday": 4,
        }

        parts = trigger.lower().split()
        if len(parts) == 2:
            day_part, time_part = parts
            hour, minute = map(int, time_part.split(":"))

            if day_part in weekday_map:
                if now.weekday() == weekday_map[day_part]:
                    if now.hour == hour and now.minute >= minute:
                        return True
            elif day_part == "1st":
                if now.day == 1 and now.hour == hour and now.minute >= minute:
                    return True

        return False
```

## 常见误区

### 误区一：把报表引擎做成"代码里的报表"

最常见的错误是把报表的结构硬编码在代码里——在 Python 代码中拼接 HTML 字符串、用 print 语句控制排版。这样做的结果是每次修改报表样式都需要改代码、测试、部署。

**正确做法**是将报表结构定义在模板文件中，代码只负责数据获取和模板渲染。修改样式只需要改模板文件，不需要动代码。模板文件甚至可以让非技术人员（设计师、产品经理）来维护。

### 误区二：忽略输出格式的差异

很多初学者以为一份 HTML 模板可以无缝转换为 PDF 和 Excel。实际上，三种格式的排版规则完全不同：HTML 依赖 CSS 布局，PDF 需要精确的页面控制（分页、页眉页脚），Excel 需要单元格级别的样式控制。

**正确做法**是为每种输出格式准备独立的渲染逻辑。HTML 可以直接用模板引擎渲染，PDF 需要专门的排版处理（控制分页、避免表格跨页断裂），Excel 需要用 openpyxl 等库直接操作单元格。

### 误区三：不做数据验证就渲染

直接把数据源的输出丢给模板引擎，不做任何验证，是很多线上报表事故的根源。数据源可能返回空数据（当天没有交易）、异常数据（某个指标值为负数）、或者格式错误（日期字段变成了字符串）。

**正确做法**是在数据层和渲染层之间增加一个验证步骤：检查数据是否为空、数值是否在合理范围内、必填字段是否齐全。验证失败时应该中断报表生成并发送告警，而不是渲染出一份包含错误数据的报表。

### 误区四：调度系统不做错误恢复

定时任务执行失败后不做任何处理，导致报表缺失。更糟糕的是，失败后没有通知机制，直到有人发现"上周的周报怎么没收到"才发现问题。

**正确做法**是为每个调度任务配置重试策略（失败后重试 3 次，间隔递增）和告警机制（失败后通过邮件或即时通讯工具通知运维人员）。同时记录每次执行的日志，方便事后排查。

### 小结

1. 报表引擎的核心是三层架构：数据层（获取和计算）、渲染层（模板填充）、输出层（格式转换）
2. 模板驱动是报表引擎的核心设计原则——数据和样式分离，修改样式不需要改代码

5. 数据验证是报表质量的最后一道防线——空数据、异常数据、格式错误都应该在渲染前被拦截

### 练习一

**思路**：weasyprint 可以直接将 HTML 字符串转换为 PDF。关键挑战是中文字体和分页控制。需要在 HTML 的 CSS 中设置中文字体回退链，并使用 CSS 的 `page-break` 属性控制分页。

**答案**：

```python
# 在 output_renderer.py 中添加

def render_pdf(self, html_content: str, filename: str) -> str:
    """使用 weasyprint 输出 PDF 文件。"""
    from weasyprint import HTML

    filepath = self.output_dir / filename

    # 注入 PDF 专用的 CSS（中文字体、分页控制）
    pdf_css = """
    @page {
        size: A4;
        margin: 2cm;
        @bottom-center {
            content: "第 " counter(page) " 页";
            font-size: 10px;
            color: #888;
        }
    }
    body {
        font-family: "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif;
    }
    table {
        page-break-inside: avoid;
    }
    h1, h2 {
        page-break-after: avoid;
    }
    """

    # 将 CSS 注入到 HTML 的 <head> 中
    html_with_css = html_content.replace(
        "</head>",
        f"<style>{pdf_css}</style></head>"
    )

    HTML(string=html_with_css).write_pdf(str(filepath))
    return str(filepath)
```

**要点**：
- `@page` 规则控制 PDF 的页面尺寸和页脚
- `page-break-inside: avoid` 防止表格在页面中间断裂
- 中文字体需要设置回退链，确保在不同操作系统上都能正确显示
- weasyprint 依赖系统级的字体渲染库，Linux 环境下可能需要额外安装 `libpango`

### 练习二

**思路**：使用 Python 标准库的 `smtplib` 和 `email` 模块实现邮件发送。关键是构建带附件的 MIME 消息，并实现重试逻辑。

**答案**：

```python
import smtplib
import time
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.base import MIMEBase
from email import encoders
from pathlib import Path


class EmailDistributor:
    """邮件分发器。"""

    def __init__(self, smtp_host: str, smtp_port: int, username: str, password: str):
        self.smtp_host = smtp_host
        self.smtp_port = smtp_port
        self.username = username
        self.password = password

    def send_report(
        self,
        recipients: list[str],
        subject: str,
        summary: str,
        attachment_paths: list[str],
        max_retries: int = 3,
    ) -> bool:
        """发送报表邮件，失败时重试。"""
        for attempt in range(max_retries):
            try:
                self._do_send(recipients, subject, summary, attachment_paths)
                print(f"  [邮件] 发送成功: {', '.join(recipients)}")
                return True
            except Exception as e:
                wait_time = 2 ** attempt
                print(
                    f"  [邮件] 发送失败 (尝试 {attempt + 1}/{max_retries}): {e}"
                    f"，{wait_time} 秒后重试..."
                )
                time.sleep(wait_time)

        print(f"  [邮件] 发送失败，已达最大重试次数")
        return False

    def _do_send(
        self, recipients: list[str], subject: str,
        summary: str, attachment_paths: list[str],
    ):
        msg = MIMEMultipart()
        msg["From"] = self.username
        msg["To"] = ", ".join(recipients)
        msg["Subject"] = subject

        # 正文
        body = f"{summary}\n\n此邮件由报表系统自动发送。"
        msg.attach(MIMEText(body, "plain", "utf-8"))

        # 附件
        for path_str in attachment_paths:
            path = Path(path_str)
            if not path.exists():
                continue
            with open(path, "rb") as f:
                part = MIMEBase("application", "octet-stream")
                part.set_payload(f.read())
            encoders.encode_base64(part)
            part.add_header(
                "Content-Disposition", f"attachment; filename={path.name}"
            )
            msg.attach(part)

        with smtplib.SMTP(self.smtp_host, self.smtp_port) as server:
            server.starttls()
            server.login(self.username, self.password)
            server.send_message(msg)
```

**要点**：
- 重试间隔使用指数退避（1s, 2s, 4s），避免短时间内大量重试
- 附件使用 MIMEBase 封装，支持任意文件类型
- 发送失败时记录日志但不抛出异常，让调度器可以继续执行其他任务

### 练习三

**思路**：用字典表示 DAG 的邻接表，用入度表做拓扑排序。按拓扑顺序依次执行报表生成，如果某节点执行失败，则标记所有下游节点为跳过。

**答案**：

```python
from dataclasses import dataclass, field
from enum import Enum
from engine import ReportEngine


class TaskStatus(Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCESS = "success"
    FAILED = "failed"
    SKIPPED = "skipped"


@dataclass
class DAGNode:
    report_id: str
    dependencies: list[str] = field(default_factory=list)
    status: TaskStatus = TaskStatus.PENDING


class DAGOrchestrator:
    """基于 DAG 的报表依赖编排器。"""

    def __init__(self, engine: ReportEngine):
        self.engine = engine
        self._nodes: dict[str, DAGNode] = {}

    def add_task(self, report_id: str, dependencies: list[str] | None = None):
        """添加任务节点和依赖关系。"""
        self._nodes[report_id] = DAGNode(
            report_id=report_id,
            dependencies=dependencies or [],
        )

    def execute(self) -> dict[str, TaskStatus]:
        """按拓扑顺序执行所有任务。"""
        completed: set[str] = failed: set[str] = set()
        remaining = dict(self._nodes)

        while remaining:
            # 找出所有依赖已满足的任务
            ready = [
                node for node in remaining.values()
                if all(dep in completed for dep in node.dependencies)
                and not any(dep in failed for dep in node.dependencies)
            ]

            if not ready:
                # 剩余任务都有未满足的依赖（循环依赖或失败依赖）
                for node in remaining.values():
                    if any(dep in failed for dep in node.dependencies):
                        node.status = TaskStatus.SKIPPED
                        print(f"  [编排] 跳过 {node.report_id}（上游任务失败）")
                break

            for node in ready:
                print(f"\n  [编排] 执行任务: {node.report_id}")
                node.status = TaskStatus.RUNNING

                try:
                    self.engine.generate_report(node.report_id)
                    node.status = TaskStatus.SUCCESS
                    completed.add(node.report_id)
                    print(f"  [编排] 完成: {node.report_id}")
                except Exception as e:
                    node.status = TaskStatus.FAILED
                    failed.add(node.report_id)
                    print(f"  [编排] 失败: {node.report_id} - {e}")

                del remaining[node.report_id]

        return {nid: node.status for nid, node in self._nodes.items()}
```

**要点**：
- 拓扑排序确保依赖任务先执行
- 上游任务失败时，所有下游任务自动标记为 SKIPPED，避免无谓执行
- 循环依赖会导致剩余任务永远无法执行，需要在 `add_task` 时做环检测
