# AI 数据可视化与智能报表

> 从传统图表到 AI 驱动的数据叙事——构建自然语言驱动的智能数据产品。

## 这门课解决什么问题

数据可视化不是画几张图。企业级数据产品的核心痛点是：

- **报表开发周期长**：一个 Dashboard 需求从提出到上线要 2-4 周
- **数据查询门槛高**：业务人员想看数据，但不会写 SQL
- **洞察发现靠运气**：数据摆在那里，但没人能从海量数据中发现异常
- **报表维护成本高**：每个新需求都要开发人员介入

这门课教你用 AI 重新定义数据可视化的工作方式：

- **NL2SQL**：用自然语言查询数据库，业务人员自己出报表
- **AI 图表生成**：描述需求，AI 自动生成合适的可视化代码
- **智能数据叙事**：AI 自动发现数据异常并生成分析报告
- **对话式 BI**：像聊天一样探索数据，而不是点菜单

## 前置要求

- JavaScript/TypeScript 基础
- 了解基本的数据分析概念（维度、指标、聚合）
- 有使用过 ECharts 或 D3.js 者更佳

## 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 可视化 | ECharts / D3.js / Observable Plot | 主流可视化库 |
| AI 图表 | VL-Llama / ChartGPT / 代码生成 | AI 驱动的图表生成 |
| NL2SQL | SQLCoder / Vanna.ai / 自研 Pipeline | 自然语言转 SQL |
| 数据分析 | PandAI / LLM 数据分析 Agent | AI 辅助数据探索 |
| 前端 | React + TypeScript + AntV | 企业级可视化组件 |
| 后端 | FastAPI + PostgreSQL | API 与数据服务 |
| 报表引擎 | 自研模板引擎 + LLM | 自动化报表生成 |
| 部署 | Docker + Redis | 缓存与服务化 |

## 课程大纲

### Part 1：数据可视化工程基础（6 课时）

> 不是画图，是构建可复用的可视化系统

1. 数据可视化工程观——为什么图表开发比你想象的复杂
2. ECharts 深度实战——从配置项到自定义系列、主题系统
3. D3.js 数据驱动——绑定数据、比例尺、过渡动画、力导向图
4. 交互式可视化——钻取、联动、刷选、Tooltip 设计
5. 可视化组件设计——可配置、可复用、可组合的图表组件库
6. **阶段实战：构建企业级图表组件库**

### Part 2：AI 驱动的图表生成（8 课时）

> 让 AI 理解数据并生成合适的可视化

7. NL2SQL 原理——从自然语言到 SQL 的技术栈与挑战
8. SQLCoder 实战——开源 NL2SQL 模型的部署与调优
9. Schema Linking——让 AI 理解数据库结构的关键技术
10. AI 图表推荐——根据数据特征自动推荐图表类型
11. 代码生成式可视化——LLM 生成 ECharts/D3 代码
12. VL（Vision-Language）模型与图表——理解图表的 AI
13. 数据到图表的 Pipeline——从数据库到可视化图表的完整链路
14. **阶段实战：自然语言驱动的数据查询系统**

### Part 3：智能报表与数据叙事（8 课时）

> 让数据自己"说话"

15. 异常检测——时间序列异常、维度异常、趋势变化检测
16. 数据摘要生成——AI 自动撰写数据摘要和分析结论
17. 数据叙事框架——从数据到故事的结构化方法论
18. 自动化报表引擎——模板 + 数据 + AI = 动态报表
19. 定时报表与推送——邮件、飞书、钉钉的自动化集成
20. 数据质量监控——数据完整性、准确性、时效性的自动检测
21. 报表模板系统——可配置的报表模板与主题系统
22. **阶段实战：自动化周报生成系统**

### Part 4：企业级数据产品（8 课时）

> 从工具到平台

23. 对话式 BI 架构——像聊天一样探索数据的系统设计
24. 数据探索 Agent——AI 自主探索数据、发现洞察
25. Dashboard 构建器——拖拽式 Dashboard 搭建系统
26. 数据权限体系——行级权限、列级权限、数据脱敏
27. 多数据源接入——MySQL、PostgreSQL、ClickHouse、API 的统一层
28. 性能优化——大数据量下的查询优化、缓存策略、增量更新
29. 嵌入式分析——将数据分析能力嵌入业务系统
30. **阶段实战：对话式 BI 平台 MVP**

### 毕业项目：AI 数据分析平台

整合全部所学，构建一个完整的 AI 数据分析平台：
- 数据源管理——连接数据库、上传 CSV、API 接入
- 自然语言查询——输入问题，自动生成 SQL 并返回图表
- 智能 Dashboard——拖拽式搭建，AI 自动推荐图表
- 自动报表——定时报表生成与推送
- 数据叙事——AI 自动发现异常并生成分析报告
- 权限管理——多租户、数据权限、操作审计

详见 [项目说明](final-project/项目说明.md)

## 学习建议

1. **可视化是基础**。先精通 ECharts/D3，再引入 AI——AI 生成的代码你需要能审查和优化
2. **NL2SQL 是核心难点**。Schema Linking 和 Query 改写的效果直接决定产品可用性
3. **关注数据质量**。垃圾数据进，垃圾报表出——数据清洗比 AI 模型更重要
4. **用户体验优先**。数据产品的用户往往非技术背景，交互设计要极度简化
