# 毕业项目：AI 数据分析平台

## 项目概述

构建一个 AI 驱动的数据分析平台，支持自然语言查询数据库、AI 自动生成图表、智能数据叙事、自动报表生成。

## 核心功能

### 1. 自然语言查询（NLQ）
- 输入问题："上个月销售额最高的 TOP 10 商品是什么？"
- 自动生成 SQL，执行查询，返回结果表格 + 可视化图表
- 支持多轮追问："按地区拆分看看"
- SQL 安全检查：只允许 SELECT，禁止 DDL/DML

### 2. 智能图表推荐
- 根据数据类型自动推荐图表类型
- 趋势数据 → 折线图，占比数据 → 饼图，分布数据 → 直方图
- 支持手动切换图表类型

### 3. Dashboard 构建器
- 拖拽式布局，自由组合图表
- 筛选器联动：时间范围、维度筛选
- 自动刷新
- 分享与嵌入

### 4. 数据叙事
- AI 自动检测数据异常（同比、环比、趋势变化）
- 生成自然语言分析摘要
- 支持中文报告生成

### 5. 自动报表
- 报表模板系统
- 定时生成（日报、周报、月报）
- 多渠道推送：邮件、飞书、钉钉
- PDF / Excel 导出

### 6. 数据源管理
- 支持 MySQL、PostgreSQL、ClickHouse、CSV
- Schema 自动同步
- 数据质量检测
