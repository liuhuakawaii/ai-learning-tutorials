# 毕业项目：量化交易回测平台

## 项目概述

构建一个完整的量化交易回测平台，支持 A 股行情数据管理、因子研究、策略可视化配置、多策略回测、风险分析和模拟交易。

## 核心功能

### 1. 数据管理
- A 股日线/分钟线数据采集（Tushare / AKShare）
- 数据清洗：缺失值填充、复权计算、停牌处理
- ClickHouse 存储，支持高速查询
- 数据质量监控

### 2. 因子研究工作台
- 预设因子库：动量、价值、质量、波动率
- 自定义因子：Python 表达式编辑器
- 因子评估：IC/IR 分析、分层回测、因子衰减
- 因子相关性分析

### 3. 策略编辑器
- 可视化配置策略参数
- 预设策略模板：多因子选股、趋势跟踪、均值回归
- 自定义策略：Python 脚本编辑
- 策略组合

### 4. 回测引擎
- 支持日频/分钟频回测
- 手续费、滑点、冲击成本模拟
- 基准对比（沪深 300、中证 500）
- 多策略并行回测

### 5. 风险分析
- 回测报告：收益率、夏普比率、最大回撤、胜率
- 归因分析：行业、因子、个股收益分解
- 风险指标：VaR / CVaR / Beta
- 资金曲线可视化

### 6. 模拟交易
- 接入模拟盘 API
- 实时信号生成
- 持仓与盈亏追踪
- 策略衰减检测
