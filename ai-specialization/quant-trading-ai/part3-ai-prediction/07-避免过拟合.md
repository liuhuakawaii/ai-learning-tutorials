# 第七课：避免过拟合——所有指标都完美但实盘不赚钱

## 场景引入

你训练了一个机器学习模型，回测结果令人兴奋：年化收益率 150%，Sharpe 比率 3.5，最大回撤仅 8%。你把模型投入实盘，三个月后亏损 25%。

这不是模型的错，而是你被过拟合欺骗了。

在量化交易中，过拟合是最隐蔽、最致命的问题。与图像分类或 NLP 不同，金融数据的信噪比极低（信号远小于噪声），而且存在大量隐性的多重检验问题。你尝试了 100 种特征组合，选了最好的那个——这本身就是一种过拟合，即使你没有意识到。

本课将系统讲解金融 ML 中的过拟合问题，包括时间序列交叉验证、deflated Sharpe ratio、多重检验修正等高级技术，帮你建立完整的过拟合检测与防范框架。

> **风险提示**：即使使用了本课介绍的所有技术，也无法完全消除过拟合风险。回测结果永远不能等同于实盘表现。任何策略在投入实盘前都必须经过严格的样本外测试和纸交易验证。

## 学习目标

完成本课后，你将能够：

1. 理解金融 ML 过拟合的特殊性（为什么比其他领域更严重）
2. 实现正确的时间序列交叉验证（purged / embargo / combinatorial）
3. 使用 deflated Sharpe ratio 修正多重检验偏差

5. 建立完整的过拟合诊断与防范框架

## 一、金融 ML 过拟合的特殊性

### 1.1 为什么金融数据更容易过拟合？

```
金融数据 vs 其他领域数据:

图像分类:                      金融预测:
┌─────────────────┐           ┌─────────────────┐
│ 信噪比: 高      │           │ 信噪比: 极低    │
│ 样本量: 百万级   │           │ 样本量: 千级    │
│ 数据独立: 近似  │           │ 数据相关: 强    │
│ 标签确定: 是    │           │ 标签噪声: 大    │
│ 分布稳定: 近似  │           │ 分布漂移: 持续  │
└─────────────────┘           └─────────────────┘

金融过拟合的三大陷阱:

陷阱 1: 多重检验 (Multiple Testing)
  你尝试了 100 个因子，选了最显著的 5 个
  → 即使所有因子都是噪声，也会有 5 个看起来"显著"
  → 这不是 alpha，是 p-hacking

陷阱 2: 前视偏差 (Look-ahead Bias)
  用未来数据做特征工程或归一化
  → 回测完美，实盘崩溃
  → 最隐蔽的过拟合形式

陷阱 3: 数据窥探 (Data Snooping)
  反复在同一测试集上调参
  → 模型逐渐"记住"了测试集
  → 测试集变成了另一个训练集
```

### 1.2 过拟合的量化检测

```python
"""
过拟合检测工具——量化评估模型的过拟合程度
"""

import numpy as np
from typing import list


def overfitting_score(
    in_sample_sharpe: float,
    out_sample_sharpe: float,
    n_trials: int = 1,
) -> dict:
    """
    过拟合评分

    核心指标:
    1. Sharpe 衰减率: (IS_Sharpe - OOS_Sharpe) / IS_Sharpe
    2. 过拟合概率: 基于 deflated Sharpe ratio

    参数:
        in_sample_sharpe: 样本内 Sharpe 比率
        out_sample_sharpe: 样本外 Sharpe 比率
        n_trials: 尝试的策略数量（用于多重检验修正）
    """
    # Sharpe 衰减率
    if in_sample_sharpe != 0:
        decay_rate = (in_sample_sharpe - out_sample_sharpe) / abs(in_sample_sharpe)
    else:
        decay_rate = float("inf")

    # 过拟合等级
    if decay_rate < 0.2:
        level = "低风险"
    elif decay_rate < 0.5:
        level = "中等风险"
    elif decay_rate < 0.8:
        level = "高风险"
    else:
        level = "极高风险（几乎肯定过拟合）"

    return {
        "in_sample_sharpe": round(in_sample_sharpe, 3),
        "out_sample_sharpe": round(out_sample_sharpe, 3),
        "decay_rate": round(decay_rate, 3),
        "overfitting_level": level,
    }
```

## 二、时间序列交叉验证

### 2.1 为什么不能用普通 K-Fold？

```
普通 K-Fold 的问题:

标准 K-Fold 划分:
  Fold 1: [测试] [训练] [训练] [训练] [训练]
  Fold 2: [训练] [测试] [训练] [训练] [训练]
  Fold 3: [训练] [训练] [测试] [训练] [训练]
  Fold 4: [训练] [训练] [训练] [测试] [训练]
  Fold 5: [训练] [训练] [训练] [训练] [测试]

问题: 训练集包含了测试集之后的数据
  → 用未来的数据预测过去
  → 严重的前视偏差

正确的时间序列划分 (Walk-Forward):
  Fold 1: [训练] [测试]
  Fold 2: [训练] [训练] [测试]
  Fold 3: [训练] [训练] [训练] [测试]
  Fold 4: [训练] [训练] [训练] [训练] [测试]

训练集永远在测试集之前
→ 模拟真实的预测场景
```

### 2.2 Purged K-Fold 与 Embargo

```python
"""
Purged K-Fold 与 Embargo——防止时间序列交叉验证中的信息泄露
"""

import numpy as np
from sklearn.model_selection import TimeSeriesSplit
from typing import Generator


class PurgedTimeSeriesSplit:
    """
    Purged 时间序列交叉验证

    与普通 TimeSeriesSplit 的区别:
    1. Purge: 在训练集和测试集之间留出间隔
       → 防止标签泄露（如果标签基于未来收益）
    2. Embargo: 在测试集之后也留出间隔
       → 防止特征泄露（如果特征包含滚动窗口）

    图示:
    [训练集] [purge gap] [测试集] [embargo gap]
    ←──────────────────────────────────────────→
    """

    def __init__(
        self,
        n_splits: int = 5,
        purge_gap: int = 5,
        embargo_gap: int = 5,
    ):
        self.n_splits = n_splits
        self.purge_gap = purge_gap
        self.embargo_gap = embargo_gap

    def split(self, X: np.ndarray) -> Generator:
        """
        生成 purged 训练/测试索引

        参数:
            X: 特征矩阵（仅用于获取样本数量）

        生成:
            (train_indices, test_indices)
        """
        n_samples = len(X)
        test_size = n_samples // (self.n_splits + 1)

        for i in range(self.n_splits):
            # 测试集范围
            test_start = test_size * (i + 1)
            test_end = min(test_start + test_size, n_samples)

            # 训练集: 测试集之前的数据，减去 purge gap
            train_end = test_start - self.purge_gap
            if train_end <= 0:
                continue

            train_indices = np.arange(0, train_end)
            test_indices = np.arange(test_start, test_end)

            # 检查 embargo: 测试集之后的数据不能立即用于下一次训练
            # 这在循环外部处理（通过 purge_gap 间接实现）

            yield train_indices, test_indices


class CombinatorialPurgedCV:
    """
    组合 Purged 交叉验证 (Combinatorial Purged Cross-Validation)

    由 Marcos López de Prado 提出，比标准 purged CV 更高效:
    - 标准 purged CV: 每个样本只在测试集中出现一次
    - 组合 purged CV: 每个样本在多个测试集中出现
    → 更多样本外评估，更稳定的过拟合估计
    """

    def __init__(
        self,
        n_splits: int = 6,
        n_test_splits: int = 2,
        purge_gap: int = 5,
    ):
        self.n_splits = n_splits
        self.n_test_splits = n_test_splits
        self.purge_gap = purge_gap

    def split(self, X: np.ndarray) -> Generator:
        """生成组合 purged 索引"""
        from itertools import combinations

        n_samples = len(X)
        split_size = n_samples // self.n_splits
        splits = []

        for i in range(self.n_splits):
            start = i * split_size
            end = start + split_size if i < self.n_splits - 1 else n_samples
            splits.append((start, end))

        # 组合: 选择 n_test_splits 个 split 作为测试集
        for test_combo in combinations(range(self.n_splits), self.n_test_splits):
            test_indices = []
            train_indices = []

            for i, (start, end) in enumerate(splits):
                if i in test_combo:
                    test_indices.extend(range(start, end))
                else:
                    # 添加 purge gap
                    adjusted_end = start - self.purge_gap
                    if adjusted_end > (splits[i - 1][1] if i > 0 else 0):
                        train_indices.extend(range(
                            splits[i - 1][1] if i > 0 else 0,
                            adjusted_end,
                        ))

            if len(test_indices) > 0 and len(train_indices) > 0:
                yield np.array(train_indices), np.array(test_indices)


def walk_forward_validation_with_purge(
    model_class,
    X: np.ndarray,
    y: np.ndarray,
    n_splits: int = 5,
    purge_gap: int = 5,
) -> list:
    """
    带 Purge 的 Walk-Forward 验证

    返回每个 fold 的训练集和测试集指标
    """
    cv = PurgedTimeSeriesSplit(n_splits=n_splits, purge_gap=purge_gap)
    results = []

    for fold_idx, (train_idx, test_idx) in enumerate(cv.split(X)):
        X_train, X_test = X[train_idx], X[test_idx]
        y_train, y_test = y[train_idx], y[test_idx]

        # 训练模型
        from sklearn.base import clone
        model = clone(model_class)
        model.fit(X_train, y_train)

        # 评估
        train_pred = model.predict(X_train)
        test_pred = model.predict(X_test)

        train_rmse = np.sqrt(np.mean((y_train - train_pred) ** 2))
        test_rmse = np.sqrt(np.mean((y_test - test_pred) ** 2))

        results.append({
            "fold": fold_idx,
            "train_size": len(train_idx),
            "test_size": len(test_idx),
            "train_rmse": round(train_rmse, 4),
            "test_rmse": round(test_rmse, 4),
            "rmse_ratio": round(test_rmse / (train_rmse + 1e-10), 4),
        })

    return results


def demo_purged_cv():
    """演示 Purged 交叉验证"""
    np.random.seed(42)
    n_samples = 500
    X = np.random.randn(n_samples, 10)
    y = X[:, 0] * 0.3 + X[:, 1] * 0.2 + np.random.randn(n_samples) * 0.1

    from sklearn.linear_model import Ridge
    model = Ridge(alpha=1.0)

    results = walk_forward_validation_with_purge(model, X, y, n_splits=5, purge_gap=5)

    print("=" * 60)
    print("Purged Walk-Forward 验证结果")
    print("=" * 60)
    for r in results:
        print(f"Fold {r['fold']}: train_rmse={r['train_rmse']}, "
              f"test_rmse={r['test_rmse']}, ratio={r['rmse_ratio']}")

    avg_ratio = np.mean([r["rmse_ratio"] for r in results])
    print(f"\n平均 RMSE 比率 (test/train): {avg_ratio:.4f}")
    print(f"过拟合程度: {'严重' if avg_ratio > 2 else '中等' if avg_ratio > 1.3 else '轻微'}")


if __name__ == "__main__":
    demo_purged_cv()
```

## 三、Deflated Sharpe Ratio 与多重检验修正

### 3.1 多重检验问题

```
多重检验的陷阱:

假设你尝试了 100 个策略，每个策略的真实 Sharpe = 0（纯噪声）
在 5% 显著性水平下:
  → 期望有 100 × 5% = 5 个策略"显著"
  → 你选了最好的那个，Sharpe = 2.5
  → 你以为发现了圣杯，实际上只是噪声

这就是 p-hacking / 数据窥探

Deflated Sharpe Ratio (DSR):
  考虑了尝试次数后的真实 Sharpe 估计
  DSR = P(true_Sharpe > 0 | observed_Sharpe, n_trials)

  如果 DSR < 0.5 → 策略很可能是过拟合的
```

### 3.2 Deflated Sharpe Ratio 实现

```python
"""
Deflated Sharpe Ratio——考虑多重检验的 Sharpe 比率修正
基于 Marcos López de Prado 的方法
"""

import numpy as np
from scipy import stats


def deflated_sharpe_ratio(
    observed_sharpe: float,
    n_trials: int,
    n_observations: int,
    sharpe_std: float = None,
    skewness: float = 0.0,
    kurtosis: float = 3.0,
) -> dict:
    """
    计算 Deflated Sharpe Ratio

    参数:
        observed_sharpe: 观测到的 Sharpe 比率
        n_trials: 尝试的策略数量（包括被放弃的）
        n_observations: 样本数量
        sharpe_std: Sharpe 比率的标准误（可选，自动计算）
        skewness: 收益分布的偏度
        kurtosis: 收益分布的峰度（正态分布=3）

    返回:
        包含 DSR 值和相关统计量的字典
    """
    # Step 1: 计算 Sharpe 比率的标准误
    if sharpe_std is None:
        # 基于 iid 假设的标准误公式
        sharpe_std = np.sqrt(
            (1 + 0.5 * observed_sharpe ** 2 -
             skewness * observed_sharpe +
             (kurtosis - 3) / 4 * observed_sharpe ** 2) / n_observations
        )

    # Step 2: 计算期望最大 Sharpe（在 n_trials 次试验中）
    # E[max(SR)] ≈ sqrt(2 * log(n_trials)) * SR_std
    # 但更精确的估计使用 order statistics
    euler_mascheroni = 0.5772
    expected_max_sharpe = sharpe_std * (
        (1 - euler_mascheroni) * stats.norm.ppf(1 - 1 / n_trials) +
        euler_mascheroni * stats.norm.ppf(1 - 1 / (n_trials * np.e))
    )

    # Step 3: 计算 DSR
    # DSR = P(SR* > 0 | SR_obs, n_trials)
    # 其中 SR* 是真实 Sharpe
    dsr = stats.norm.cdf(
        (observed_sharpe - expected_max_sharpe) / sharpe_std
    )

    # Step 4: 计置信区间
    z_score = stats.norm.ppf(0.975)
    ci_lower = observed_sharpe - z_score * sharpe_std
    ci_upper = observed_sharpe + z_score * sharpe_std

    # 过拟合判断
    if dsr < 0.5:
        verdict = "极有可能过拟合"
    elif dsr < 0.75:
        verdict = "过拟合风险较高"
    elif dsr < 0.95:
        verdict = "过拟合风险中等"
    else:
        verdict = "过拟合风险较低"

    return {
        "observed_sharpe": round(observed_sharpe, 3),
        "deflated_sharpe_ratio": round(dsr, 3),
        "expected_max_sharpe": round(expected_max_sharpe, 3),
        "sharpe_std": round(sharpe_std, 4),
        "n_trials": n_trials,
        "confidence_interval": (round(ci_lower, 3), round(ci_upper, 3)),
        "verdict": verdict,
    }


def bonferroni_correction(p_values: list, alpha: float = 0.05) -> list:
    """
    Bonferroni 多重检验修正

    最保守的方法: alpha_adjusted = alpha / n_tests
    优点: 简单、严格控制 Family-Wise Error Rate
    缺点: 过于保守，可能拒绝真正的信号
    """
    n_tests = len(p_values)
    alpha_adjusted = alpha / n_tests
    rejected = [p < alpha_adjusted for p in p_values]

    return {
        "original_alpha": alpha,
        "adjusted_alpha": round(alpha_adjusted, 6),
        "n_tests": n_tests,
        "n_rejected": sum(rejected),
        "rejected": rejected,
        "method": "Bonferroni",
    }


def benjamini_hochberg_correction(p_values: list, alpha: float = 0.05) -> list:
    """
    Benjamini-Hochberg 多重检验修正

    控制 False Discovery Rate (FDR) 而非 FWER
    比 Bonferroni 更宽松，适合大量检验的场景
    """
    n_tests = len(p_values)
    sorted_indices = np.argsort(p_values)
    sorted_p = np.array(p_values)[sorted_indices]

    # BH 修正
    rejected = np.zeros(n_tests, dtype=bool)
    for i, p in enumerate(sorted_p):
        threshold = (i + 1) / n_tests * alpha
        if p <= threshold:
            rejected[sorted_indices[i]] = True

    return {
        "original_alpha": alpha,
        "n_tests": n_tests,
        "n_rejected": int(np.sum(rejected)),
        "rejected": rejected.tolist(),
        "method": "Benjamini-Hochberg",
    }


def demo_multiple_testing():
    """演示多重检验修正"""
    np.random.seed(42)

    # 模拟 100 个策略的真实 Sharpe 比率
    n_strategies = 100
    true_sharpes = np.random.normal(0, 0.1, n_strategies)  # 大部分策略没有 alpha

    # 加入 5 个真正有效的策略
    true_sharpes[:5] = np.random.uniform(0.3, 0.8, 5)

    # 模拟观测 Sharpe（加入噪声）
    n_obs = 252  # 一年日线数据
    observed_sharpes = true_sharpes + np.random.normal(0, 0.3, n_strategies)

    # 选择观测 Sharpe > 1.0 的策略
    selected = observed_sharpes > 1.0
    n_selected = np.sum(selected)

    print("=" * 60)
    print("多重检验修正演示")
    print("=" * 60)
    print(f"总策略数: {n_strategies}")
    print(f"真正有效的策略: {np.sum(true_sharpes > 0.2)}")
    print(f"观测 Sharpe > 1.0 的策略: {n_selected}")

    # 对选中的策略计算 DSR
    if n_selected > 0:
        best_idx = np.argmax(observed_sharpes)
        dsr_result = deflated_sharpe_ratio(
            observed_sharpe=observed_sharpes[best_idx],
            n_trials=n_strategies,
            n_observations=n_obs,
        )
        print(f"\n最佳策略 (观测 Sharpe = {observed_sharpes[best_idx]:.3f}):")
        print(f"  Deflated Sharpe Ratio: {dsr_result['deflated_sharpe_ratio']}")
        print(f"  判断: {dsr_result['verdict']}")


if __name__ == "__main__":
    demo_multiple_testing()
```

## 四、正则化策略与特征选择

### 4.1 金融场景下的正则化

```python
"""
金融场景下的正则化策略——防止模型过度拟合噪声
"""

import numpy as np
from sklearn.linear_model import Ridge, Lasso, ElasticNet
from sklearn.ensemble import RandomForestRegressor
from sklearn.feature_selection import mutual_info_regression


def compare_regularization(X_train, y_train, X_test, y_test):
    """
    对比不同正则化方法的效果

    金融场景推荐:
    - Ridge: 特征间有相关性时（金融因子常有共线性）
    - Lasso: 需要特征选择时（稀疏解）
    - ElasticNet: 两者结合（推荐）
    """
    models = {
        "无正则化": lambda: __import__("sklearn.linear_model", fromlist=["LinearRegression"]).LinearRegression(),
        "Ridge (L2)": lambda: Ridge(alpha=1.0),
        "Lasso (L1)": lambda: Lasso(alpha=0.01),
        "ElasticNet": lambda: ElasticNet(alpha=0.01, l1_ratio=0.5),
    }

    print("=" * 60)
    print("正则化方法对比")
    print("=" * 60)

    for name, model_fn in models.items():
        model = model_fn()
        model.fit(X_train, y_train)

        train_pred = model.predict(X_train)
        test_pred = model.predict(X_test)

        train_rmse = np.sqrt(np.mean((y_train - train_pred) ** 2))
        test_rmse = np.sqrt(np.mean((y_test - test_pred) ** 2))
        ratio = test_rmse / (train_rmse + 1e-10)

        print(f"\n{name}:")
        print(f"  训练 RMSE: {train_rmse:.4f}")
        print(f"  测试 RMSE: {test_rmse:.4f}")
        print(f"  过拟合比率: {ratio:.4f}")


class StabilitySelector:
    """
    稳定性选择 (Stability Selection)

    通过多次 bootstrap 采样，选择在多数采样中都被选中的特征
    → 比单次特征选择更稳健

    原理:
    1. 多次 bootstrap 采样
    2. 每次采样中做特征选择
    3. 统计每个特征被选中的概率
    4. 选择概率 > 阈值的特征
    """

    def __init__(
        self,
        base_selector=None,
        n_bootstrap: int = 100,
        threshold: float = 0.6,
        sample_ratio: float = 0.8,
    ):
        self.base_selector = base_selector or Lasso(alpha=0.01)
        self.n_bootstrap = n_bootstrap
        self.threshold = threshold
        self.sample_ratio = sample_ratio
        self.selection_probabilities = None

    def fit(self, X: np.ndarray, y: np.ndarray):
        """计算特征选择概率"""
        n_samples, n_features = X.shape
        selection_counts = np.zeros(n_features)

        for i in range(self.n_bootstrap):
            # Bootstrap 采样
            n_sample = int(n_samples * self.sample_ratio)
            indices = np.random.choice(n_samples, size=n_sample, replace=True)
            X_boot, y_boot = X[indices], y[indices]

            # 特征选择
            from sklearn.base import clone
            selector = clone(self.base_selector)
            selector.fit(X_boot, y_boot)

            # 记录被选中的特征
            if hasattr(selector, "coef_"):
                selected = np.abs(selector.coef_) > 1e-10
                selection_counts += selected.astype(int)

        self.selection_probabilities = selection_counts / self.n_bootstrap
        return self

    def get_selected_features(self) -> np.ndarray:
        """获取被选中的特征索引"""
        return np.where(self.selection_probabilities > self.threshold)[0]

    def get_feature_report(self) -> dict:
        """获取特征选择报告"""
        selected = self.get_selected_features()
        return {
            "n_selected": len(selected),
            "selected_indices": selected.tolist(),
            "selection_probabilities": {
                i: round(p, 3)
                for i, p in enumerate(self.selection_probabilities)
                if p > 0.1
            },
        }
```

```python
"""
完整的过拟合诊断与防范框架
整合所有过拟合检测技术
"""

import numpy as np
from dataclasses import dataclass


@dataclass
class OverfitReport:
    """过拟合诊断报告"""
    sharpe_decay: float
    deflated_sharpe: float
    feature_stability: float
    multi_seed_stability: float
    overall_risk: str
    recommendations: list


class OverfitDiagnostic:
    """过拟合诊断框架"""

    def __init__(self, n_seeds: int = 10, n_trials: int = 1):
        self.n_seeds = n_seeds
        self.n_trials = n_trials

    def diagnose(
        self,
        in_sample_sharpe: float,
        out_sample_sharpe: float,
        n_observations: int,
        feature_selection_probs: list = None,
        multi_seed_sharpes: list = None,
    ) -> OverfitReport:
        """
        综合过拟合诊断

        参数:
            in_sample_sharpe: 样本内 Sharpe
            out_sample_sharpe: 样本外 Sharpe
            n_observations: 样本数量
            feature_selection_probs: 特征选择概率列表
            multi_seed_sharpes: 多种子评估的 Sharpe 列表
        """
        recommendations = []

        # 1. Sharpe 衰减率
        if in_sample_sharpe != 0:
            sharpe_decay = (in_sample_sharpe - out_sample_sharpe) / abs(in_sample_sharpe)
        else:
            sharpe_decay = 0
        if sharpe_decay > 0.5:
            recommendations.append("Sharpe 衰减超过 50%，模型可能严重过拟合")

        # 2. Deflated Sharpe Ratio
        dsr_result = deflated_sharpe_ratio(
            observed_sharpe=out_sample_sharpe,
            n_trials=self.n_trials,
            n_observations=n_observations,
        )
        deflated_sharpe = dsr_result["deflated_sharpe_ratio"]
        if deflated_sharpe < 0.5:
            recommendations.append("Deflated Sharpe Ratio < 0.5，策略极可能是过拟合的")

        # 3. 特征稳定性
        feature_stability = 0.0
        if feature_selection_probs:
            high_prob_features = sum(1 for p in feature_selection_probs if p > 0.6)
            feature_stability = high_prob_features / len(feature_selection_probs)
            if feature_stability < 0.3:
                recommendations.append("特征选择不稳定，选中特征在不同采样中变化大")

        # 4. 多种子稳定性
        multi_seed_stability = 0.0
        if multi_seed_sharpes:
            multi_seed_stability = 1.0 - (np.std(multi_seed_sharpes) / (abs(np.mean(multi_seed_sharpes)) + 1e-10))
            if multi_seed_stability < 0.5:
                recommendations.append("多种子评估结果不稳定，策略对随机种子敏感")

        # 5. 综合风险评估
        risk_scores = []
        risk_scores.append(1 if sharpe_decay > 0.5 else 0)
        risk_scores.append(1 if deflated_sharpe < 0.5 else 0)
        risk_scores.append(1 if feature_stability < 0.3 and feature_selection_probs else 0)
        risk_scores.append(1 if multi_seed_stability < 0.5 and multi_seed_sharpes else 0)

        risk_count = sum(risk_scores)
        if risk_count == 0:
            overall_risk = "低风险"
        elif risk_count <= 1:
            overall_risk = "中等风险"
        elif risk_count <= 2:
            overall_risk = "高风险"
        else:
            overall_risk = "极高风险"

        if not recommendations:
            recommendations.append("未发现明显过拟合迹象，建议进入纸交易验证")

        return OverfitReport(
            sharpe_decay=round(sharpe_decay, 3),
            deflated_sharpe=round(deflated_sharpe, 3),
            feature_stability=round(feature_stability, 3),
            multi_seed_stability=round(multi_seed_stability, 3),
            overall_risk=overall_risk,
            recommendations=recommendations,
        )
```

## 六、常见误区

### 误区一：测试集只用一次就够了

即使用了 purged CV，如果你反复在同一验证集上调参，最终还是会过拟合。正确做法是：验证集用于调参，测试集用于最终评估（只用一次），或者使用 nested cross-validation。

### 误区二：回测完美 = 策略有效

回测中可能存在隐性的前视偏差：归一化用了全量数据、特征工程用了未来信息、参数选择用了测试集。每一个环节都可能引入过拟合。

### 误区三：数据越多越不容易过拟合

金融数据的信噪比不会因为数据量增加而提高。10 年的日线数据和 1 年的数据相比，有效信息量的增加远没有样本量增加那么多，因为市场结构在不断变化。

### 误区四：简单模型不会过拟合

即使是线性模型，如果特征数量接近或超过样本量，也会严重过拟合。正则化不是可选的，而是必须的。

## 小结与练习

### 本课要点

1. 金融 ML 的过拟合比其他领域更严重，因为信噪比低、数据量小、存在多重检验
2. 时间序列交叉验证必须使用 purged 和 embargo，防止信息泄露
3. Deflated Sharpe Ratio 考虑了尝试次数，是评估策略真实有效性的关键指标
4. 稳定性选择比单次特征选择更稳健，应该成为特征工程的标准流程
5. 过拟合防范需要系统性框架，而不是单一技术

实现嵌套交叉验证：外层用于评估模型泛化能力，内层用于超参搜索。确保内层和外层都使用 purged 时间序列分割。

构建一个实时监控系统，跟踪策略在样本外的 Sharpe Ratio 衰减趋势。当衰减超过阈值时自动报警。

## 参考答案

### 练习一

**思路**：外层 CV 评估泛化能力，内层 CV 进行超参搜索。两层都使用 PurgedTimeSeriesSplit，确保没有信息泄露。

**答案**：

```python
def nested_cross_validation(
    model_class,
    param_grid: list,
    X: np.ndarray,
    y: np.ndarray,
    outer_splits: int = 5,
    inner_splits: int = 3,
    purge_gap: int = 5,
):
    """嵌套交叉验证"""
    outer_cv = PurgedTimeSeriesSplit(n_splits=outer_splits, purge_gap=purge_gap)
    inner_cv = PurgedTimeSeriesSplit(n_splits=inner_splits, purge_gap=purge_gap)
    results = []

    for fold, (train_idx, test_idx) in enumerate(outer_cv.split(X)):
        X_train, X_test = X[train_idx], X[test_idx]
        y_train, y_test = y[train_idx], y[test_idx]

        # 内层: 超参搜索
        best_score = float("inf")
        best_params = None

        for params in param_grid:
            inner_scores = []
            for inner_train_idx, inner_val_idx in inner_cv.split(X_train):
                X_inner_train = X_train[inner_train_idx]
                y_inner_train = y_train[inner_train_idx]
                X_inner_val = X_train[inner_val_idx]
                y_inner_val = y_train[inner_val_idx]

                from sklearn.base import clone
                model = clone(model_class)
                model.set_params(**params)
                model.fit(X_inner_train, y_inner_train)
                pred = model.predict(X_inner_val)
                rmse = np.sqrt(np.mean((y_inner_val - pred) ** 2))
                inner_scores.append(rmse)

            avg_score = np.mean(inner_scores)
            if avg_score < best_score:
                best_score = avg_score
                best_params = params

        # 用最优参数在全量训练集上训练，评估测试集
        from sklearn.base import clone
        final_model = clone(model_class)
        final_model.set_params(**best_params)
        final_model.fit(X_train, y_train)
        test_pred = final_model.predict(X_test)
        test_rmse = np.sqrt(np.mean((y_test - test_pred) ** 2))

        results.append({
            "fold": fold,
            "best_params": best_params,
            "inner_score": round(best_score, 4),
            "test_score": round(test_rmse, 4),
        })

    return results
```

**要点**：
- 外层和内层都使用 purged 分割，确保没有信息泄露
- 内层选择最优超参，外层评估泛化能力
- 计算成本是 O(outer × inner × n_params)，需要权衡

### 练习二

**思路**：维护滚动窗口的 Sharpe 计算，跟踪衰减趋势，当衰减超过阈值时触发报警。

**答案**：

```python
class SharpeDecayMonitor:
    """Sharpe Ratio 衰减监控"""

    def __init__(self, initial_sharpe: float, alert_threshold: float = 0.5):
        self.initial_sharpe = initial_sharpe
        self.alert_threshold = alert_threshold
        self.returns_history = []
        self.sharpe_history = []

    def update(self, daily_return: float):
        """更新每日收益"""
        self.returns_history.append(daily_return)

        # 计算滚动 Sharpe（最近 60 天）
        if len(self.returns_history) >= 60:
            recent = np.array(self.returns_history[-60:])
            rolling_sharpe = np.mean(recent) / (np.std(recent) + 1e-10) * np.sqrt(252)
            self.sharpe_history.append(rolling_sharpe)

            # 检查衰减
            decay_rate = (self.initial_sharpe - rolling_sharpe) / abs(self.initial_sharpe)
            if decay_rate > self.alert_threshold:
                return {
                    "alert": True,
                    "message": f"Sharpe 衰减 {decay_rate:.1%}，超过阈值 {self.alert_threshold:.1%}",
                    "current_sharpe": round(rolling_sharpe, 3),
                    "initial_sharpe": self.initial_sharpe,
                    "decay_rate": round(decay_rate, 3),
                }

        return {"alert": False}

    def get_report(self) -> dict:
        """获取监控报告"""
        if not self.sharpe_history:
            return {"status": "数据不足"}

        current = self.sharpe_history[-1]
        decay_rate = (self.initial_sharpe - current) / abs(self.initial_sharpe)

        return {
            "initial_sharpe": self.initial_sharpe,
            "current_sharpe": round(current, 3),
            "decay_rate": round(decay_rate, 3),
            "min_sharpe": round(min(self.sharpe_history), 3),
            "max_sharpe": round(max(self.sharpe_history), 3),
            "n_observations": len(self.returns_history),
        }
```

**要点**：
- 使用滚动窗口计算 Sharpe，而不是全局计算
- 衰减率 = (初始 Sharpe - 当前 Sharpe) / 初始 Sharpe
- 可以集成到策略监控系统中，实现实时报警
