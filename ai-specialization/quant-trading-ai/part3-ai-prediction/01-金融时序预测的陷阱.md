## 一、金融时序的非平稳性

### 1.1 什么是非平稳性

普通时序数据（如气温、心率）通常围绕一个稳定的均值波动，统计特性随时间变化缓慢。金融时序截然不同——它的统计特性（均值、方差、自相关结构）会随时间剧烈变化。

```
普通时序（气温）：
温度
  |    ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~
  |   ~                         ~
  |  ~                           ~
  | ~                             ~
  +---------------------------------> 时间
  均值相对稳定，方差变化小

金融时序（股价）：
价格
  |                              /
  |                         ____/
  |                    ____/
  |               ____/
  |          ____/
  |     ____/
  |____/
  +---------------------------------> 时间
  趋势在变，波动率在变，均值也在变
```

### 1.2 非平稳性带来的具体问题

**问题一：训练集和测试集分布不一致**

2020 年 3 月的市场波动率是 2019 年全年的 5 倍以上。如果用 2017-2019 年的数据训练，模型学到的波动模式在 2020 年完全失效。

**问题二：特征的统计意义随时间漂移**

一个在牛市中有效的动量因子，在熊市中可能变成反向指标。模型如果不能识别这种 regime change，就会在关键时刻做出错误决策。

**问题三：均值回归假设可能失效**

很多量化策略隐含着"价格会回归均值"的假设。但在结构性变化面前（如行业颠覆、政策转向），均值本身就在移动。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def demonstrate_nonstationarity():
    """演示金融时序的非平稳性"""
    np.random.seed(42)
    n_days = 1000

    # 生成非平稳序列：均值和方差都在变化
    regime_1 = np.random.normal(loc=0.001, scale=0.01, size=300)  # 低波动上涨
    regime_2 = np.random.normal(loc=-0.002, scale=0.03, size=400)  # 高波动下跌
    regime_3 = np.random.normal(loc=0.0015, scale=0.015, size=300)  # 中等波动上涨

    returns = np.concatenate([regime_1, regime_2, regime_3])
    prices = 100 * np.cumprod(1 + returns)

    # 计算滚动统计量
    df = pd.DataFrame({'price': prices, 'return': returns})
    df['rolling_mean'] = df['return'].rolling(60).mean()
    df['rolling_std'] = df['return'].rolling(60).std()

    fig, axes = plt.subplots(3, 1, figsize=(12, 10))

    axes[0].plot(prices)
    axes[0].set_title('股价序列（非平稳）')
    axes[0].axvline(x=300, color='r', linestyle='--', alpha=0.5)
    axes[0].axvline(x=700, color='r', linestyle='--', alpha=0.5)

    axes[1].plot(df['rolling_mean'])
    axes[1].set_title('60日滚动均值（均值在漂移）')
    axes[1].axhline(y=0, color='gray', linestyle='--')

    axes[2].plot(df['rolling_std'])
    axes[2].set_title('60日滚动波动率（方差在变化）')

    plt.tight_layout()
    plt.savefig('nonstationarity_demo.png', dpi=150)
    plt.show()

    # 统计检验
    from scipy import stats
    first_half = returns[:500]
    second_half = returns[500:]
    t_stat, p_value = stats.ttest_ind(first_half, second_half)
    print(f"前后半段均值差异检验: t={t_stat:.3f}, p={p_value:.4f}")
    print(f"前半段均值: {first_half.mean():.5f}, 后半段均值: {second_half.mean():.5f}")
    print(f"前半段标准差: {first_half.std():.5f}, 后半段标准差: {second_half.std():.5f}")

demonstrate_nonstationarity()
```

## 二、低信噪比：金融数据的本质困难

### 2.1 信噪比的定义

在信号处理中，信噪比（SNR）衡量有效信号相对于噪声的强度。金融数据的信噪比极低——日内收益率中，噪声占比通常超过 95%。

```
信号 vs 噪声（示意）：

日内收益率分解：
┌─────────────────────────────────────┐
│  真实信息（基本面变化、政策影响）      │  ~2-5%
├─────────────────────────────────────┤
│  市场微观结构噪声                      │  ~30%
│  （买卖价差、流动性冲击、订单流噪声）   │
├─────────────────────────────────────┤
│  情绪噪声                             │  ~40%
│  （恐慌、贪婪、跟风、谣言）            │
├─────────────────────────────────────┤
│  随机噪声                             │  ~25%
│  （无法解释的随机波动）                │
└─────────────────────────────────────┘
```

### 2.2 低信噪比对建模的影响

当信噪比极低时，模型很容易学到噪声而非信号。这会导致：

1. **训练集表现极好，测试集表现极差**——模型拟合了噪声
2. **模型对超参数极度敏感**——微小的参数变化导致完全不同的预测
3. **特征重要性不稳定**——每次训练选出的"重要特征"都不同

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import r2_score

def demonstrate_low_snr():
    """演示低信噪比如何导致过拟合"""
    np.random.seed(42)
    n_samples = 1000
    n_features = 50

    # 生成特征
    X = np.random.randn(n_samples, n_features)

    # 真实信号：只有前 3 个特征有预测能力
    true_signal = 0.02 * X[:, 0] + 0.015 * X[:, 1] - 0.01 * X[:, 2]

    # 噪声：强度是信号的 20 倍
    noise = np.random.normal(0, 0.3, n_samples)
    y = true_signal + noise

    # 计算真实信噪比
    snr = np.var(true_signal) / np.var(noise)
    print(f"信噪比: {snr:.4f}")
    print(f"信号标准差: {np.std(true_signal):.4f}")
    print(f"噪声标准差: {np.std(noise):.4f}")

    # 训练模型
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

    model = RandomForestRegressor(n_estimators=200, max_depth=10, random_state=42)
    model.fit(X_train, y_train)

    train_r2 = r2_score(y_train, model.predict(X_train))
    test_r2 = r2_score(y_test, model.predict(X_test))

    print(f"\n训练集 R²: {train_r2:.4f}")
    print(f"测试集 R²: {test_r2:.4f}")
    print(f"过拟合程度: {train_r2 - test_r2:.4f}")

    # 特征重要性分析
    importances = model.feature_importances_
    top_features = np.argsort(importances)[::-1][:10]
    print(f"\n模型认为最重要的 10 个特征: {top_features}")
    print(f"真实重要的特征: [0, 1, 2]")
    print(f"模型选对了: {len(set(top_features) & {0, 1, 2})} / 3")

demonstrate_low_snr()
```

## 三、前视偏差：最致命的陷阱

### 3.1 什么是前视偏差

前视偏差（look-ahead bias）是指在回测中使用了在实际交易时不可能获得的信息。这是量化回测中最常见、最致命的错误。

```
时间线示意：

真实场景（实盘）：
  T1          T2          T3          T4
  |           |           |           |
  数据可用    做决策      得到结果     数据可用
  ●───────────●───────────●───────────●
              ↑
              只能用 T1 及之前的数据

有前视偏差的回测：
  T1          T2          T3          T4
  |           |           |           |
  数据可用    做决策      得到结果     数据可用
  ●───────────●───────────●───────────●
              ↑
              错误地使用了 T2 或 T3 的数据
```

### 3.2 常见的前视偏差来源

**来源一：使用未来数据做特征**

```python
# ❌ 错误：用当天收盘价作为当天的特征
df['ma_5'] = df['close'].rolling(5).mean()  # 包含当天数据
df['signal'] = (df['close'] > df['ma_5']).astype(int)
# 决策时你还不知道今天的收盘价！

# ✅ 正确：用前一天的数据
df['ma_5'] = df['close'].shift(1).rolling(5).mean()
df['signal'] = (df['close'].shift(1) > df['ma_5']).astype(int)
```

**来源二：使用未来数据做标准化**

```python
# ❌ 错误：用整个数据集的均值和标准差做标准化
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)  # fit 用了未来数据

# ✅ 正确：只用训练集做 fit
scaler.fit(X_train)
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

**来源三：使用未来数据做特征选择**

```python
# ❌ 错误：用全部数据做特征选择
from sklearn.feature_selection import SelectKBest
selector = SelectKBest(k=10)
X_selected = selector.fit_transform(X, y)  # 用了测试集的 y

# ✅ 正确：在交叉验证循环内做特征选择
from sklearn.pipeline import Pipeline
pipe = Pipeline([
    ('selector', SelectKBest(k=10)),
    ('model', RandomForestRegressor())
])
# 在每个 fold 内，selector 只看到训练数据
```

### 3.3 完整的前视偏差演示

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import r2_score

def demonstrate_lookahead_bias():
    """演示前视偏差如何产生虚假的高收益"""
    np.random.seed(42)
    n_days = 500

    # 生成随机价格序列（真实信号为零）
    returns = np.random.normal(0, 0.02, n_days)
    prices = 100 * np.cumprod(1 + returns)
    dates = pd.date_range('2020-01-01', periods=n_days, freq='B')

    df = pd.DataFrame({
        'date': dates,
        'close': prices,
        'return': returns
    })

    # 构建特征
    for lag in [1, 2, 3, 5, 10]:
        df[f'return_lag_{lag}'] = df['return'].shift(lag)
        df[f'vol_lag_{lag}'] = df['return'].rolling(lag).std().shift(1)

    df = df.dropna()

    feature_cols = [c for c in df.columns if c not in ['date', 'close', 'return']]
    X = df[feature_cols].values
    y = df['return'].values

    # ---- 有前视偏差的回测（错误做法）----
    model_biased = RandomForestRegressor(n_estimators=100, random_state=42)
    model_biased.fit(X, y)  # 用了全部数据训练，包括未来
    predictions_biased = model_biased.predict(X)

    # 计算策略收益
    positions_biased = np.sign(predictions_biased)
    strategy_returns_biased = positions_biased * y
    cumulative_biased = np.cumprod(1 + strategy_returns_biased)

    # ---- 正确的回测（滚动窗口）----
    train_window = 200
    predictions_correct = np.zeros(len(y))

    for i in range(train_window, len(y)):
        X_train = X[i - train_window:i]
        y_train = y[i - train_window:i]

        model = RandomForestRegressor(n_estimators=50, random_state=42)
        model.fit(X_train, y_train)
        predictions_correct[i] = model.predict(X[i:i + 1])[0]

    positions_correct = np.sign(predictions_correct[train_window:])
    strategy_returns_correct = positions_correct * y[train_window:]
    cumulative_correct = np.cumprod(1 + strategy_returns_correct)

    # 买入持有基准
    cumulative_buyhold = np.cumprod(1 + y[train_window:])

    # 打印结果
    print("=" * 60)
    print("前视偏差演示结果")
    print("=" * 60)
    print(f"有前视偏差的回测:")
    print(f"  最终净值: {cumulative_biased[-1]:.3f}")
    print(f"  总收益率: {(cumulative_biased[-1] - 1) * 100:.1f}%")
    print(f"\n正确的滚动回测:")
    print(f"  最终净值: {cumulative_correct[-1]:.3f}")
    print(f"  总收益率: {(cumulative_correct[-1] - 1) * 100:.1f}%")
    print(f"\n买入持有基准:")
    print(f"  最终净值: {cumulative_buyhold[-1]:.3f}")
    print(f"  总收益率: {(cumulative_buyhold[-1] - 1) * 100:.1f}%")
    print(f"\n虚假超额收益: {(cumulative_biased[-1] - cumulative_correct[-1]) * 100:.1f}%")
    print("这些'收益'在实盘中完全无法复现！")

demonstrate_lookahead_bias()
```

## 四、正确的预测目标

### 4.1 为什么不要预测价格

预测绝对价格几乎没有意义，原因如下：

1. **价格是非平稳的**——模型需要外推到从未见过的价格区间
2. **价格变化的量级远小于价格本身**——模型会把精力花在拟合大趋势上
3. **收益率才是可比较的**——不同股票的价格不可比，但收益率可以

### 4.2 推荐的预测目标

```
预测目标选择指南：

┌─────────────────┬──────────────┬─────────────────────────────┐
│ 预测目标         │ 难度          │ 适用场景                     │
├─────────────────┼──────────────┼─────────────────────────────┤
│ 绝对价格         │ ★★★★★       │ 几乎不推荐                   │
│ 涨跌方向（分类）  │ ★★★☆☆       │ 信号生成、择时                │
│ 收益率（回归）    │ ★★★★☆       │ 需要精确的收益预测时           │
│ 收益率分位数      │ ★★★☆☆       │ 风险管理、期权定价             │
│ 波动率           │ ★★☆☆☆       │ 仓位管理、风险控制             │
│ 相对排名         │ ★★☆☆☆       │ 多因子选股                    │
└─────────────────┴──────────────┴─────────────────────────────┘
```

### 4.3 从预测到交易信号

```python
import numpy as np
import pandas as pd

def prediction_to_signal():
    """演示从预测目标到交易信号的完整流程"""
    np.random.seed(42)
    n_days = 252

    # 模拟真实收益率
    true_returns = np.random.normal(0.0003, 0.015, n_days)

    # 模型预测：有噪声的收益率预测
    predicted_returns = true_returns * 0.3 + np.random.normal(0, 0.012, n_days)

    # 方法 1：直接用预测值的符号做信号
    signal_direct = np.sign(predicted_returns)

    # 方法 2：设置阈值，只在高置信度时交易
    threshold = 0.005
    signal_threshold = np.where(predicted_returns > threshold, 1,
                       np.where(predicted_returns < -threshold, -1, 0))

    # 方法 3：用预测值的排名做信号（相对排名法）
    ranking_window = 20
    signal_ranking = np.zeros(n_days)
    for i in range(ranking_window, n_days):
        window_pred = predicted_returns[i - ranking_window:i + 1]
        rank = np.searchsorted(np.sort(window_pred), predicted_returns[i])
        percentile = rank / len(window_pred)
        if percentile > 0.7:
            signal_ranking[i] = 1
        elif percentile < 0.3:
            signal_ranking[i] = -1

    # 计算各策略的收益
    ret_direct = np.sum(signal_direct * true_returns)
    ret_threshold = np.sum(signal_threshold * true_returns)
    ret_ranking = np.sum(signal_ranking * true_returns)

    print("信号质量对比：")
    print(f"直接符号法: 交易 {np.sum(signal_direct != 0)} 天, 总收益 {ret_direct:.4f}")
    print(f"阈值过滤法: 交易 {np.sum(signal_threshold != 0)} 天, 总收益 {ret_threshold:.4f}")
    print(f"排名法:     交易 {np.sum(signal_ranking != 0)} 天, 总收益 {ret_ranking:.4f}")

    # 信息系数（IC）
    from scipy.stats import spearmanr
    ic, p_value = spearmanr(predicted_returns, true_returns)
    print(f"\n信息系数 (IC): {ic:.4f}, p-value: {p_value:.4f}")
    print(f"IC 绝对值 > 0.03 即有实用价值，> 0.05 算不错")

prediction_to_signal()
```

## 五、Backtest Overfitting

### 5.1 问题本质

当你尝试了足够多的策略参数、特征组合、模型架构，总能找到一个在历史数据上表现优异的策略。但这不意味着它在未来也能盈利——你只是在做数据挖掘（data snooping）。

```
多重检验问题：

尝试 100 个策略变体
┌─────────────────────────────────────────┐
│  ● ● ● ● ● ● ● ● ● ●  ← 大部分表现平庸  │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ★ ● ●  ← 1 个"显著"结果  │
│  ● ● ● ● ● ● ● ● ● ●    可能只是偶然     │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ● ● ●                   │
│  ● ● ● ● ● ● ● ● ● ●                   │
└─────────────────────────────────────────┘
在 5% 显著性水平下，100 次试验中预期有 5 个假阳性
```

### 5.2 Deflated Sharpe Ratio

```python
import numpy as np
from scipy import stats

def deflated_sharpe_ratio(observed_sr, n_trials, n_obs, skew=0, kurtosis=3):
    """
    计算 Deflated Sharpe Ratio（DSR）

    参数：
        observed_sr: 观察到的夏普比率
        n_trials: 尝试的策略数量
        n_obs: 样本数量
        skew: 收益率偏度
        kurtosis: 收益率峰度（正态分布为 3）
    """
    # 预期最大夏普比率（纯噪声下）
    e_max_sr = expected_max_sr(n_trials, n_obs, skew, kurtosis)

    # 计算 DSR
    # DSR = P(SR* < observed_sr)，其中 SR* 是纯噪声下的最大 SR
    sr_std = np.sqrt((1 + 0.5 * observed_sr**2 - skew * observed_sr
                      + (kurtosis - 3) / 4 * observed_sr**2) / (n_obs - 1))

    psr = stats.norm.cdf((observed_sr - e_max_sr) / sr_std)

    return psr

def expected_max_sr(n_trials, n_obs, skew=0, kurtosis=3):
    """计算 n_trials 次试验中预期的最大夏普比率"""
    euler_mascheroni = 0.5772156649
    e_max = (1 - euler_mascheroni) * stats.norm.ppf(1 - 1/n_trials) \
            + euler_mascheroni * stats.norm.ppf(1 - 1/(n_trials * np.e))
    return e_max

# 示例
print("Deflated Sharpe Ratio 分析")
print("=" * 50)

observed_sr = 1.5
n_obs = 252  # 一年日线数据

for n_trials in [1, 10, 50, 100, 500]:
```

## 六、正确的思路 vs 错误的思路

```
错误思路（直接预测价格）：

  历史价格 → LSTM → 预测明天价格 → 比较 → 交易信号
       ↑
    直接用价格做输入
    问题：非平稳、外推困难、前视偏差风险高


正确思路（预测相对关系/因子）：

  ┌─────────────────────────────────────────────────┐
  │  Step 1: 构造平稳特征                             │
  │    原始价格 → 收益率、波动率、动量、技术指标          │
  │                                                  │
  │  Step 2: 因子提取                                  │
  │    平稳特征 → ML 模型 → 因子得分                    │
  │                                                  │
  │  Step 3: 信号生成                                  │
  │    因子得分 → 阈值/排名 → 交易信号                  │
  │                                                  │
  │  Step 4: 严格回测                                  │
  │    滚动窗口 + purged CV + 样本外测试                │
  └─────────────────────────────────────────────────┘
```

```python
def correct_pipeline():
    """正确的量化预测 Pipeline 框架"""
    import numpy as np
    import pandas as pd

    # 1. 数据准备：收益率而非价格
    def prepare_features(price_series):
        df = pd.DataFrame({'price': price_series})
        df['return_1d'] = df['price'].pct_change()
        df['return_5d'] = df['price'].pct_change(5)
        df['volatility_20d'] = df['return_1d'].rolling(20).std()
        df['momentum_20d'] = df['price'] / df['price'].shift(20) - 1
        df['ma_ratio'] = df['price'] / df['price'].rolling(20).mean()
        return df.dropna()

    # 2. 严格的时间序列分割
    def time_series_split(df, n_splits=5):
        """不重叠的时间序列交叉验证"""
        fold_size = len(df) // (n_splits + 1)
        splits = []
        for i in range(n_splits):
            train_end = fold_size * (i + 2)
            test_start = train_end
            test_end = min(test_start + fold_size, len(df))
            splits.append((list(range(0, train_end)),
                          list(range(test_start, test_end))))
        return splits

    # 3. 样本外评估
    def evaluate_oos(predictions, actuals, positions):
        """样本外评估指标"""
        strategy_returns = positions * actuals
        total_return = np.prod(1 + strategy_returns) - 1
        sharpe = np.mean(strategy_returns) / np.std(strategy_returns) * np.sqrt(252)
        max_dd = np.min(np.minimum.accumulate(1 + strategy_returns) /
                       np.maximum.accumulate(1 + strategy_returns) - 1)
        ic = np.corrcoef(predictions, actuals)[0, 1]
        return {
            'total_return': total_return,
            'sharpe_ratio': sharpe,
            'max_drawdown': max_dd,
            'information_coefficient': ic
        }

    print("正确 Pipeline 框架已定义")
    print("关键原则：")
    print("1. 用收益率而非价格")
    print("2. 严格的时间序列分割")
    print("3. 样本外评估")
    print("4. 控制交易成本")

correct_pipeline()
```

## 七、常见误区

### 误区一：回测收益越高越好

**错误认知**：回测年化 100% 的策略一定比年化 20% 的好。

**正确理解**：极高的回测收益往往是过拟合的信号。稳健的年化 15-25% 策略，实盘可能远比回测 100% 的策略更可靠。

### 误区二：模型越复杂越好

**错误认知**：深度学习一定比线性模型好。

**正确理解**：在低信噪比的金融数据上，简单的线性模型配合好的特征工程，往往比复杂模型更稳健。复杂模型更容易过拟合噪声。

### 误区三：更多的特征 = 更好的模型

**错误认知**：把所有能想到的特征都喂给模型。

**正确理解**：每增加一个噪声特征，模型过拟合的风险就增加一分。特征选择比特征堆叠更重要。

### 误区四：历史会重复

**错误认知**：过去有效的策略未来也会有效。

**正确理解**：市场存在竞争效应——当一个策略被广泛使用时，它的超额收益就会消失。你需要理解策略赚的是什么钱，以及这种收益来源是否会持续。

---

## 小结

本课的核心要点：

1. **金融时序是非平稳的**——训练集和测试集的分布可能完全不同
2. **信噪比极低**——模型很容易学到噪声而非信号
3. **前视偏差是致命的**——一个微小的错误就能让回测结果完全失真
4. **不要预测价格**——选择收益率方向、因子排名等更合理的目标
5. **Backtest overfitting 是真实存在的**——用 Deflated Sharpe Ratio 修正
6. **简单模型 + 好特征 > 复杂模型 + 差特征**

### 练习二

**思路**：使用 Deflated Sharpe Ratio 公式，考虑多重检验修正。

**答案**：

```python
import numpy as np
from scipy import stats

def calculate_dsr():
    observed_sr = 2.0
    n_trials = 200
    n_obs = 504
    skew = -0.5
    kurtosis = 4

    # 计算预期最大夏普比率
    euler_mascheroni = 0.5772156649
    e_max_sr = (1 - euler_mascheroni) * stats.norm.ppf(1 - 1/n_trials) \
               + euler_mascheroni * stats.norm.ppf(1 - 1/(n_trials * np.e))

    # 计算 SR 的标准误
    sr_std = np.sqrt((1 + 0.5 * observed_sr**2 - skew * observed_sr
                      + (kurtosis - 3) / 4 * observed_sr**2) / (n_obs - 1))

    # 计算 DSR（概率）
    dsr = stats.norm.cdf((observed_sr - e_max_sr) / sr_std)

    print(f"观察到的夏普比率: {observed_sr}")
    print(f"尝试的策略数量: {n_trials}")
    print(f"预期最大 SR（纯噪声）: {e_max_sr:.3f}")
    print(f"SR 标准误: {sr_std:.4f}")
    print(f"Deflated Sharpe Ratio: {dsr:.4f}")
    print(f"解释：有 {dsr*100:.1f}% 的概率该策略是真实的")

    if dsr > 0.95:
        print("结论：策略可信度较高")
    elif dsr > 0.5:
        print("结论：需要更多数据验证")
    else:
        print("结论：策略很可能是过拟合的结果")

calculate_dsr()
```

**要点**：
- DSR 修正了多重检验带来的假阳性问题
- 偏度和峰度对 DSR 有显著影响（非正态分布需要更多样本）
- 即使 SR=2.0，在尝试 200 个策略后也可能不够显著
