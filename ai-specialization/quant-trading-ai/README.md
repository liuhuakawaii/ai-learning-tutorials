# 量化交易与金融 AI

> 从金融数据工程到 AI 预测模型，从策略回测到实盘交易——构建完整的量化交易系统。

## 这门课解决什么问题

量化交易不是"用 AI 预测涨跌"这么简单。一个能跑在实盘上的量化系统需要：

- **数据工程**：清洗、对齐、存储海量金融数据，缺失值和异常值处理直接决定策略质量
- **因子研究**：从几百个候选因子中筛选出真正有预测力的因子
- **策略开发**：不是拍脑袋想策略，而是基于统计规律和市场微观结构设计策略
- **回测系统**：避免过拟合、前视偏差、生存者偏差这些量化交易的"天坑"
- **风控系统**：仓位管理、止损、风险敞口控制，一次风控失败可能亏掉一年的利润
- **实盘执行**：滑点、延迟、手续费、冲击成本，回测赚钱实盘亏钱的原因就在这里

这门课不是教你"炒股秘籍"，而是教你构建一套工程化的量化交易系统。每一步都有严格的数学推导和工程实践，最终你能独立开发一个从数据采集到实盘执行的完整量化系统。

## 课程大纲

### Part 1：金融数据工程（6 课时）

> 量化交易的地基——数据质量直接决定策略上限

1. 量化交易工程全景——从数据到执行的完整链路与技术选型
2. 金融数据采集——Tushare / AKShare / Wind 的接口实战与数据质量控制
3. 数据清洗与对齐——缺失值、异常值、复权因子、停牌处理的工程实践
4. 时序数据存储——ClickHouse / TimescaleDB 的选型与优化
5. 因子数据管道——从原始行情到因子值的自动化计算流水线
6. **阶段实战：构建金融数据采集与清洗 Pipeline**

### Part 2：量化策略开发（8 课时）

> 从统计规律到可执行的交易策略

7. 因子投资基础——Alpha 因子的数学定义与经济直觉
8. 因子构建实战——动量、价值、质量、波动率因子的实现
9. 因子评估——IC/IR 分析、分层回测、因子衰减分析
10. 趋势跟踪策略——均线、通道突破、海龟交易法的工程实现
11. 均值回归策略——配对交易、统计套利的数学原理与实现
12. 事件驱动策略——财报、公告、新闻事件的量化反应
13. 多因子模型——因子加权、因子中性化、组合优化
14. **阶段实战：多因子选股策略**

### Part 3：AI 预测模型（8 课时）

> 用机器学习增强量化策略

15. 金融时序预测的陷阱——为什么直接预测价格几乎不可能
16. LightGBM / XGBoost 实战——特征工程与梯度提升在量化中的应用
17. LSTM / Transformer 时序模型——深度学习预测收益率分布
18. NLP 与金融——新闻情感分析、公告解读、社交媒体信号
19. 强化学习与交易——DQN / PPO 在仓位管理中的应用
20. 模型集成与 stacking——多模型融合的工程实践
21. 避免过拟合——交叉验证、时间序列分割、正则化策略
22. **阶段实战：AI 增强的多因子策略**

### Part 4：回测与风控（6 课时）

> 回测赚钱不算赚钱，风控才是生存的根本

23. 回测引擎设计——事件驱动 vs 向量化回测的选型与实现
24. 回测陷阱——前视偏差、生存者偏差、过拟合的检测与规避
25. 风险度量——VaR / CVaR / 最大回撤 / 夏普比率的计算与解读
26. 仓位管理——Kelly 公式、等权重、风险平价的工程实现
27. 止损策略——固定止损、跟踪止损、波动率止损的工程实践
28. **阶段实战：完整的回测与风控系统**

### Part 5：实盘交易（6 课时）

> 从回测到实盘的最后一公里

29. 实盘执行架构——信号生成 → 风控检查 → 订单执行 → 成交回报
30. 交易接口对接——CTP / 券商 API / 交易所接口的工程实践

## 学习建议

1. **数据质量是第一位的**。80% 的量化工作是数据清洗和特征工程
2. **不要相信回测结果**。回测必须严格避免前视偏差，否则就是自欺欺人
3. **风控比策略更重要**。一个普通策略 + 优秀风控 > 神奇策略 + 没有风控
4. **从小资金开始**。模拟盘验证后再用小资金实盘，逐步放大
5. **持续学习**。市场在变化，策略会衰减，量化交易是终身学习的过程
