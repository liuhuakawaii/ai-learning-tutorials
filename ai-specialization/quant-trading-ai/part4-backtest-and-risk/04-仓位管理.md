# 04 仓位管理：同样的策略，仓位不同，结果天差地别

> 你有一个年化 20% 的策略，全仓梭哈可能一年翻倍，也可能爆仓归零。仓位管理决定了你能在市场活多久。这一课我们学习如何科学地管理仓位。

完成本课后，你将能够：

## 场景引入

假设有两个交易员，他们使用完全相同的策略——一个简单的均线突破策略。唯一的区别是他们的仓位管理方式：

**交易员 A**：每次交易都全仓买入，不留现金。
**交易员 A**：每次交易只用 30% 的资金，其余保留现金。

他们同时在 2024 年 1 月开始交易。到 2024 年 12 月：

- 交易员 A：经历了两次 40% 的回撤，最终收益 -15%
- 交易员 B：最大回撤只有 12%，最终收益 +18%

同样的策略，为什么结果差这么多？

答案就是**仓位管理**。仓位管理不是简单的"买多少"的问题，它涉及到风险控制、资金利用效率、心理承受能力等多个维度。好的仓位管理可以让一个普通的策略变得优秀，差的仓位管理可以让一个优秀的策略爆仓。

## 核心概念

### 一、仓位管理的本质

```
仓位管理的核心问题：

  给定一个策略，每笔交易应该投入多少资金？

  太少 → 资金利用率低，收益被稀释
  太多 → 风险过高，一次大亏可能致命

  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │   收益                                               │
  │    ↑      *                                          │
  │    │    *   *                                        │
  │    │   *     *                                       │
  │    │  *       *                                      │
  │    │ *         *                                     │
  │    │*           *                                    │
  │    *              *                                  │
  │                      *                               │
  │                         *                            │
  │                            *                         │
  │                                                     │
  │    0%    20%    40%    60%    80%   100%            │
  │                   仓位比例                           │
  │                                                     │
  │    存在一个最优仓位，使得风险调整后的收益最大         │
  │                                                     │
  └─────────────────────────────────────────────────────┘
```

### 二、Kelly 公式

Kelly 公式是仓位管理的理论基础，它告诉你**在长期博弈中，如何最大化资金的几何增长率**。

```
Kelly 公式的推导（简化版）：

假设你有一个赌博机会：
  - 胜率 p，赢了获得 b 倍本金
  - 败率 q = 1-p，输了损失全部本金

每次下注比例 f，经过 n 次博弈后的资金：
  W(n) = W(0) × (1 + bf)^np × (1 - f)^nq

对 f 求导，令 dW/df = 0，得到最优仓位：
  f* = (bp - q) / b = p - q/b

这就是 Kelly 公式。

直觉理解：
  - 胜率越高，应该下注越多
  - 赔率越高，应该下注越多
  - 如果没有优势（bp < q），不应该下注

示例：
  胜率 p = 60%，赔率 b = 1（赢了翻倍，输了全亏）
  f* = 0.6 - 0.4/1 = 0.2 = 20%

  含义：每次应该用 20% 的资金下注
```

**Kelly 公式的局限**：

1. 假设你知道准确的胜率和赔率（实际上你不知道）
2. 假设每次博弈独立（实际上市场有相关性）
3. 全 Kelly 风险很高，实际中常用半 Kelly 或更保守的比例

### 三、等权重仓位管理

最简单的方法：每笔交易使用相同的资金比例。

```
等权重仓位管理：

总资金：100 万
持仓数量：5 只股票
每只股票：20 万（20%）

优点：
  - 简单易实现
  - 分散风险
  - 不需要估计预期收益或波动率

缺点：
  - 不考虑个股风险差异
  - 高风险股票和低风险股票分配相同资金
  - 可能导致风险集中
```

### 四、风险平价（Risk Parity）

风险平价的核心思想是：**让每个持仓对组合总风险的贡献相等**。

```
风险平价 vs 等权重：

假设两只股票：
  股票 A：波动率 10%
  股票 B：波动率 30%

等权重（50%/50%）：
  股票 A 的风险贡献：10% × 50% = 5%
  股票 B 的风险贡献：30% × 50% = 15%
  风险贡献比：1:3（不均衡）

风险平价：
  股票 A 的风险贡献 = 股票 B 的风险贡献
  → 股票 A 仓位：75%，股票 B 仓位：25%
  验证：10% × 75% = 7.5%，30% × 25% = 7.5% ✓

风险平价的直觉：低波动的资产多买，高波动的资产少买
```

### 五、波动率目标法

设定一个目标波动率，根据当前持仓的波动率动态调整仓位。

```
波动率目标法：

目标年化波动率：15%
当前持仓波动率：25%

仓位比例 = 目标波动率 / 当前波动率
         = 15% / 25% = 60%

含义：如果当前持仓波动率是 25%，
     要把组合波动率控制在 15%，
     需要把仓位降低到 60%。

动态调整：
  市场波动率低时 → 加仓（提高资金利用率）
  市场波动率高时 → 减仓（降低风险）
```

### 六、CPPI（Constant Proportion Portfolio Insurance）

CPPI 是一种保本策略，核心思想是：**随着资产价值的变化，动态调整风险资产和无风险资产的比例**。

```
CPPI 的工作原理：

设定：
  - 保本底线 F：你不想亏掉的钱（如 80 万）
  - 风险乘数 m：放大倍数（如 3）
  - 账户总值 V

风险资产配置 = m × (V - F)
无风险资产配置 = V - 风险资产配置

示例（m=3, F=80万）：

初始状态：V=100万
  风险资产 = 3 × (100-80) = 60万
  无风险资产 = 100-60 = 40万

上涨后：V=120万
  风险资产 = 3 × (120-80) = 120万
  无风险资产 = 120-120 = 0万
  （全部投入风险资产）

下跌后：V=90万
  风险资产 = 3 × (90-80) = 30万
  无风险资产 = 90-30 = 60万
  （减少风险敞口）

继续下跌：V=85万
  风险资产 = 3 × (85-80) = 15万
  无风险资产 = 85-15 = 70万
  （进一步减少风险敞口）

跌破底线：V=79万
  风险资产 = 3 × (79-80) = -3万 → 0万
  无风险资产 = 79万
  （全部转为无风险资产）
```

### 七、动态仓位调整

根据市场状态和策略信号强度动态调整仓位。

```
动态仓位调整的考虑因素：

1. 信号强度
   - 强信号 → 大仓位
   - 弱信号 → 小仓位

2. 市场状态
   - 牛市趋势 → 可以适当加仓
   - 熊市/震荡 → 减仓或观望

3. 波动率
   - 低波动 → 可以加仓
   - 高波动 → 减仓

4. 相关性
   - 持仓相关性高 → 减仓
   - 持仓相关性低 → 可以适当加仓

5. 账户状态
   - 连续盈利后 → 适当减仓（锁定利润）
   - 连续亏损后 → 大幅减仓（控制回撤）
```

## 代码实现

### 一、Kelly 公式实现

```python
import numpy as np
import pandas as pd
from typing import Dict, List

def kelly_criterion(win_rate: float, win_loss_ratio: float) -> float:
    """计算 Kelly 最优仓位

    Args:
        win_rate: 胜率（0-1）
        win_loss_ratio: 赔率（平均盈利 / 平均亏损）

    Returns:
        最优仓位比例（0-1）
    """
    # Kelly 公式：f* = p - q/b
    # 其中 p 是胜率，q=1-p 是败率，b 是赔率
    kelly = win_rate - (1 - win_rate) / win_loss_ratio

    # 限制在 [0, 1] 范围内
    return max(0, min(1, kelly))

def half_kelly(win_rate: float, win_loss_ratio: float) -> float:
    """半 Kelly 仓位（更保守）

    实际中常用半 Kelly，因为：
    1. 我们对胜率和赔率的估计有误差
    2. 全 Kelly 的波动太大
    3. 半 Kelly 的收益约为全 Kelly 的 75%，但风险降低一半
    """
    return kelly_criterion(win_rate, win_loss_ratio) / 2

def calculate_kelly_from_trades(trades: pd.DataFrame) -> Dict:
    """从历史交易记录计算 Kelly 仓位

    Args:
        trades: 包含 'profit' 列的交易记录

    Returns:
        Kelly 仓位信息
    """
    winning_trades = trades[trades['profit'] > 0]
    losing_trades = trades[trades['profit'] <= 0]

    if len(losing_trades) == 0:
        return {
            'win_rate': 1.0,
            'avg_win': winning_trades['profit'].mean(),
            'avg_loss': 0,
            'win_loss_ratio': float('inf'),
            'kelly': 1.0,
            'half_kelly': 0.5
        }

    win_rate = len(winning_trades) / len(trades)
    avg_win = winning_trades['profit'].mean()
    avg_loss = abs(losing_trades['profit'].mean())

    if avg_loss == 0:
        win_loss_ratio = float('inf')
    else:
        win_loss_ratio = avg_win / avg_loss

    kelly = kelly_criterion(win_rate, win_loss_ratio)
    half = half_kelly(win_rate, win_loss_ratio)

    return {
        'win_rate': win_rate,
        'avg_win': avg_win,
        'avg_loss': avg_loss,
        'win_loss_ratio': win_loss_ratio,
        'kelly': kelly,
        'half_kelly': half,
        'total_trades': len(trades),
        'winning_trades': len(winning_trades),
        'losing_trades': len(losing_trades)
    }
```

### 二、等权重与风险平价

```python
class EqualWeightAllocator:
    """等权重仓位管理"""

    def __init__(self, max_positions: int = 10):
        self.max_positions = max_positions

    def allocate(self, total_capital: float, n_positions: int) -> Dict[str, float]:
        """分配仓位

        Args:
            total_capital: 总资金
            n_positions: 持仓数量

        Returns:
            每个持仓的金额
        """
        n_positions = min(n_positions, self.max_positions)
        per_position = total_capital / n_positions

        return {f'stock_{i}': per_position for i in range(n_positions)}

class RiskParityAllocator:
    """风险平价仓位管理"""

    def __init__(self):
        pass

    def allocate(self, total_capital: float,
                 volatilities: Dict[str, float]) -> Dict[str, float]:
        """根据波动率分配仓位

        Args:
            total_capital: 总资金
            volatilities: 每个资产的年化波动率

        Returns:
            每个持仓的金额
        """
        # 计算波动率的倒数
        inv_vols = {k: 1.0 / v for k, v in volatilities.items()}

        # 归一化
        total_inv_vol = sum(inv_vols.values())
        weights = {k: v / total_inv_vol for k, v in inv_vols.items()}

        # 分配资金
        allocations = {k: total_capital * w for k, w in weights.items()}

        return allocations

    def allocate_with_correlation(self, total_capital: float,
                                   volatilities: Dict[str, float],
                                   correlation_matrix: np.ndarray) -> Dict[str, float]:
        """考虑相关性的风险平价分配

        Args:
            total_capital: 总资金
            volatilities: 每个资产的年化波动率
            correlation_matrix: 相关性矩阵

        Returns:
            每个持仓的金额
        """
        n = len(volatilities)
        vols = np.array(list(volatilities.values()))
        names = list(volatilities.keys())

        # 构建协方差矩阵
        # Cov(i,j) = ρ(i,j) × σ(i) × σ(j)
        cov_matrix = np.outer(vols, vols) * correlation_matrix

        # 风险平价优化：最小化 Σ(w_i × σ_i - w_j × σ_j)^2
        # 约束：Σw_i = 1, w_i >= 0

        from scipy.optimize import minimize

        def risk_budget_objective(weights):
            # 计算每个资产的风险贡献
            portfolio_vol = np.sqrt(weights @ cov_matrix @ weights)
            marginal_risk = cov_matrix @ weights
            risk_contrib = weights * marginal_risk / portfolio_vol

            # 目标：让所有资产的风险贡献相等
            target_risk = portfolio_vol / n
            return np.sum((risk_contrib - target_risk) ** 2)

        # 初始权重：等权重
        x0 = np.ones(n) / n

        # 约束：权重之和为 1
        constraints = {'type': 'eq', 'fun': lambda x: np.sum(x) - 1}

        # 边界：权重非负
        bounds = [(0.01, 1) for _ in range(n)]

        result = minimize(risk_budget_objective, x0,
                         method='SLSQP',
                         bounds=bounds,
                         constraints=constraints)

        weights = result.x
        allocations = {name: total_capital * w for name, w in zip(names, weights)}

        return allocations
```

### 三、波动率目标法

```python
class VolatilityTargetAllocator:
    """波动率目标仓位管理"""

    def __init__(self, target_volatility: float = 0.15,
                 lookback_window: int = 63,
                 max_leverage: float = 1.0,
                 min_leverage: float = 0.2):
        """
        Args:
            target_volatility: 目标年化波动率
            lookback_window: 计算波动率的回看窗口
            max_leverage: 最大杠杆（1.0 = 满仓）
            min_leverage: 最小杠杆（0.2 = 最低 20% 仓位）
        """
        self.target_volatility = target_volatility
        self.lookback_window = lookback_window
        self.max_leverage = max_leverage
        self.min_leverage = min_leverage

    def calculate_position_size(self, returns: pd.Series) -> float:
        """根据历史波动率计算仓位大小

        Args:
            returns: 历史收益率序列

        Returns:
            仓位比例（0.2 - 1.0）
        """
        if len(returns) < self.lookback_window:
            return self.min_leverage

        # 计算近期波动率
        recent_returns = returns[-self.lookback_window:]
        current_vol = recent_returns.std() * np.sqrt(252)

        if current_vol == 0:
            return self.max_leverage

        # 仓位 = 目标波动率 / 当前波动率
        position_size = self.target_volatility / current_vol

        # 限制范围
        position_size = max(self.min_leverage, min(self.max_leverage, position_size))

        return position_size

    def calculate_dynamic_positions(self, returns_df: pd.DataFrame) -> pd.DataFrame:
        """计算每个时间点的动态仓位

        Args:
            returns_df: 包含多个资产收益率的 DataFrame

        Returns:
            每个时间点每个资产的仓位比例
        """
        positions = pd.DataFrame(index=returns_df.index, columns=returns_df.columns)

        for col in returns_df.columns:
            for i in range(self.lookback_window, len(returns_df)):
                window_returns = returns_df[col].iloc[i-self.lookback_window:i]
                positions.iloc[i][col] = self.calculate_position_size(window_returns)

        return positions.astype(float)

if __name__ == "__main__":
    # 生成模拟数据
    np.random.seed(42)
    dates = pd.date_range('2024-01-01', periods=252, freq='B')

    low_vol_returns = np.random.normal(0.0005, 0.01, 126)  # 低波动期
```

### 四、CPPI 实现

```python
class CPPIAllocator:
    """CPPI（恒定比例投资组合保险）仓位管理"""

    def __init__(self, floor_percentage: float = 0.8,
                 multiplier: float = 3.0):
        """
        Args:
            floor_percentage: 保本底线占初始资金的比例
            multiplier: 风险乘数
        """
        self.floor_percentage = floor_percentage
        self.multiplier = multiplier

    def calculate_allocation(self, current_value: float,
                              initial_value: float) -> Dict[str, float]:
        """计算当前的资产配置

        Args:
            current_value: 当前账户总值
            initial_value: 初始资金

        Returns:
            风险资产和无风险资产的金额
        """
        # 计算保本底线
        floor = initial_value * self.floor_percentage

        # 计算缓冲（当前价值超过底线的部分）
        buffer = max(0, current_value - floor)

        # 风险资产配置 = 乘数 × 缓冲
        risk_allocation = self.multiplier * buffer

        # 限制不超过总资金
        risk_allocation = min(risk_allocation, current_value)

        # 无风险资产配置
        risk_free_allocation = current_value - risk_allocation

        return {
            'risk_asset': risk_allocation,
            'risk_free_asset': risk_free_allocation,
            'floor': floor,
            'buffer': buffer,
            'risk_pct': risk_allocation / current_value if current_value > 0 else 0
        }

    def backtest(self, asset_returns: pd.Series,
                  risk_free_rate: float = 0.02) -> pd.DataFrame:
        """回测 CPPI 策略

        Args:
            asset_returns: 风险资产的日收益率
            risk_free_rate: 年化无风险利率

        Returns:
            回测结果 DataFrame
        """
        daily_rf = (1 + risk_free_rate) ** (1/252) - 1
        initial_value = 1000000  # 初始资金 100 万

        results = []
        current_value = initial_value

        for date, asset_return in asset_returns.items():
            # 计算当前配置
            allocation = self.calculate_allocation(current_value, initial_value)

            # 计算收益
            risk_return = allocation['risk_asset'] * asset_return
            risk_free_return = allocation['risk_free_asset'] * daily_rf
            total_return = risk_return + risk_free_return

            current_value += total_return

            results.append({
                'date': date,
                'portfolio_value': current_value,
                'risk_asset_value': allocation['risk_asset'],
                'risk_free_asset_value': allocation['risk_free_asset'],
                'risk_pct': allocation['risk_pct'],
```

```python
class PositionManager:
    """综合仓位管理系统"""

    def __init__(self, total_capital: float,
                 max_positions: int = 10,
                 max_single_position: float = 0.2,
                 risk_per_trade: float = 0.02):
        """
        Args:
            total_capital: 总资金
            max_positions: 最大持仓数量
            max_single_position: 单只股票最大仓位
            risk_per_trade: 每笔交易的风险比例（如 2% 表示每笔交易最多亏 2%）
        """
        self.total_capital = total_capital
        self.max_positions = max_positions
        self.max_single_position = max_single_position
        self.risk_per_trade = risk_per_trade
        self.positions = {}  # symbol -> {'shares': 数量, 'cost': 成本, 'current_price': 当前价}

    def calculate_position_size(self, entry_price: float,
                                 stop_loss_price: float,
                                 volatility: float = None) -> Dict:
        """根据止损价计算仓位大小

        Args:
            entry_price: 入场价格
            stop_loss_price: 止损价格
            volatility: 年化波动率（可选）

        Returns:
            仓位信息
        """
        # 计算每股风险
        risk_per_share = abs(entry_price - stop_loss_price)

        if risk_per_share == 0:
            return {'shares': 0, 'amount': 0, 'risk': 0}

        # 计算可承受的总风险
        total_risk = self.total_capital * self.risk_per_trade

        # 计算仓位大小
        shares = int(total_risk / risk_per_share)

        # 考虑最大单只仓位限制
        max_amount = self.total_capital * self.max_single_position
        max_shares_by_amount = int(max_amount / entry_price)

        shares = min(shares, max_shares_by_amount)

        # A 股必须 100 股整数倍
        shares = (shares // 100) * 100

        amount = shares * entry_price

        # 如果有波动率信息，考虑波动率调整
        if volatility and volatility > 0:
            # 波动率越高，仓位越小
            vol_adjustment = min(1.0, 0.2 / volatility)
            shares = int(shares * vol_adjustment / 100) * 100
            amount = shares * entry_price

        return {
            'shares': shares,
            'amount': amount,
            'risk': shares * risk_per_share,
            'position_pct': amount / self.total_capital,
            'risk_pct': (shares * risk_per_share) / self.total_capital
        }

    def add_position(self, symbol: str, entry_price: float,
                      stop_loss_price: float) -> Dict:
        """添加新持仓"""
        if symbol in self.positions:
            return {'error': '已持有该股票'}

        if len(self.positions) >= self.max_positions:
            return {'error': '持仓数量已达上限'}

        # 计算仓位大小
        position_info = self.calculate_position_size(entry_price, stop_loss_price)

        if position_info['shares'] == 0:
            return {'error': '计算的仓位为 0'}

        if position_info['amount'] > self.get_available_capital():
            return {'error': '可用资金不足'}

        # 添加持仓
        self.positions[symbol] = {
            'shares': position_info['shares'],
            'entry_price': entry_price,
            'cost': position_info['amount'],
            'stop_loss': stop_loss_price,
            'current_price': entry_price
        }

        return {
            'success': True,
            'symbol': symbol,
            'shares': position_info['shares'],
            'amount': position_info['amount'],
            'stop_loss': stop_loss_price
        }

    def get_available_capital(self) -> float:
        """获取可用资金"""
        invested = sum(pos['cost'] for pos in self.positions.values())
        return self.total_capital - invested

    def update_price(self, symbol: str, current_price: float):
        """更新持仓价格"""
        if symbol in self.positions:
            self.positions[symbol]['current_price'] = current_price

    def get_portfolio_summary(self) -> Dict:
        """获取组合摘要"""
        total_invested = sum(pos['cost'] for pos in self.positions.values())
        total_market_value = sum(
            pos['shares'] * pos['current_price']
            for pos in self.positions.values()
        )

        total_pnl = total_market_value - total_invested
        total_pnl_pct = total_pnl / total_invested if total_invested > 0 else 0

        position_details = []
        for symbol, pos in self.positions.items():
            market_value = pos['shares'] * pos['current_price']
            pnl = market_value - pos['cost']
            pnl_pct = pnl / pos['cost'] if pos['cost'] > 0 else 0

            position_details.append({
                'symbol': symbol,
                'shares': pos['shares'],
                'cost': pos['cost'],
                'market_value': market_value,
                'pnl': pnl,
                'pnl_pct': pnl_pct,
                'position_pct': market_value / self.total_capital
            })

        return {
            'total_capital': self.total_capital,
            'total_invested': total_invested,
            'available_capital': self.get_available_capital(),
            'total_market_value': total_market_value,
            'total_pnl': total_pnl,
            'total_pnl_pct': total_pnl_pct,
            'position_count': len(self.positions),
            'positions': position_details
        }
```

## 常见误区

### 误区一：全仓梭哈

很多人看到"好机会"就全仓买入，甚至加杠杆。这种做法在牛市可能赚大钱，但一旦遇到黑天鹅，可能血本无归。

**正确做法**：永远留有余地。单只股票的仓位不要超过总资金的 20-30%。

### 误区二：不考虑相关性

买了 5 只股票，以为是分散投资，但这 5 只股票都是同一个行业的，涨跌高度相关。

**正确做法**：分散投资不仅是数量上的分散，更是相关性上的分散。

### 误区三：死守固定仓位

市场波动率从 10% 变成 30%，你还是保持同样的仓位。这相当于在高风险时期承担了过多的风险。

**正确做法**：根据市场状态动态调整仓位，波动率高时减仓，波动率低时加仓。

### 误区四：忽视止损和仓位的关系

止损设得很紧（比如 2%），但仓位很重（比如 50%）。结果一个小波动就被止损出局。

**正确做法**：止损和仓位应该配合使用。止损越紧，仓位应该越小；止损越宽，仓位可以适当大一些。

### 误区五：频繁调整仓位

每天都在调仓，结果交易成本吃掉了大部分收益。

**正确做法**：仓位调整应该有明确的规则和触发条件，避免过度交易。

## 小结与练习

### 小结

本课我们学习了以下仓位管理方法：

1. **Kelly 公式**：数学上最优的仓位比例，但实际中常用半 Kelly
2. **等权重**：简单但不考虑风险差异
3. **风险平价**：让每个持仓的风险贡献相等
4. **波动率目标**：根据波动率动态调整仓位
5. **CPPI**：保本策略，随着资产价值变化调整风险敞口
6. **综合系统**：结合止损、波动率、最大仓位等多因素

**核心原则**：
- 仓位管理的目标是最大化风险调整后的收益
- 没有放之四海而皆准的方法，需要根据策略特性选择
- 动态调整优于静态配置
- 仓位管理要和止损配合使用

### 练习一：Kelly 公式实践

**思路**：使用 Kelly 公式 f* = p - q/b 计算最优仓位。

**答案**：

```python
def kelly_exercise():
    """Kelly 公式练习"""

    # 给定参数
    win_rate = 0.55        # 胜率 55%
    avg_win = 0.03         # 平均盈利 3%
    avg_loss = 0.02        # 平均亏损 2%

    # 计算赔率
    win_loss_ratio = avg_win / avg_loss  # 赔率 = 3/2 = 1.5

    # Kelly 公式：f* = p - q/b
    kelly = win_rate - (1 - win_rate) / win_loss_ratio

    # 半 Kelly
    half_kelly = kelly / 2

    # 保守仓位（1/4 Kelly）
    quarter_kelly = kelly / 4

    print("=== Kelly 公式练习 ===\n")
    print(f"胜率: {win_rate:.0%}")
    print(f"平均盈利: {avg_win:.2%}")
    print(f"平均亏损: {avg_loss:.2%}")
    print(f"赔率: {win_loss_ratio:.2f}")
    print(f"\nKelly 最优仓位: {kelly:.2%}")
    print(f"半 Kelly 仓位: {half_kelly:.2%}")
    print(f"1/4 Kelly 仓位: {quarter_kelly:.2%}")

    # 解释
    print("\n=== 解释 ===")
    print(f"Kelly 公式: f* = p - q/b = {win_rate} - {1-win_rate}/{win_loss_ratio:.2f} = {kelly:.2%}")
    print(f"\n含义：每次交易应该投入总资金的 {kelly:.1%}")
    print(f"半 Kelly（更保守）：投入 {half_kelly:.1%}")
    print(f"\n为什么用半 Kelly？")
    print("1. 我们对胜率和赔率的估计有误差")
    print("2. 全 Kelly 的波动太大，可能造成心理压力")
    print("3. 半 Kelly 的收益约为全 Kelly 的 75%，但风险降低一半")

    return {
        'kelly': kelly,
        'half_kelly': half_kelly,
        'quarter_kelly': quarter_kelly
    }
```

**要点**：
- Kelly 公式给出的是理论最优，实际中常用半 Kelly 或更保守
- 胜率和赔率的估计误差会严重影响 Kelly 的效果
- 保守的投资者应该用 1/4 Kelly 或更低

### 练习二：实现风险平价

**思路**：计算波动率的倒数，然后归一化得到权重。

**答案**：

```python
def risk_parity_exercise():
    """风险平价练习"""

    # 给定波动率
    volatilities = {
        '债券ETF': 0.05,   # 5%
        '股票ETF': 0.20,   # 20%
        '商品ETF': 0.25    # 25%
    }

    # 计算波动率的倒数
    inv_vols = {k: 1.0 / v for k, v in volatilities.items()}

    # 归一化得到权重
    total_inv_vol = sum(inv_vols.values())
    weights = {k: v / total_inv_vol for k, v in inv_vols.items()}

    print("=== 风险平价练习 ===\n")
    print("各资产波动率:")
    for name, vol in volatilities.items():
        print(f"  {name}: {vol:.0%}")

    print("\n波动率倒数:")
    for name, inv_vol in inv_vols.items():
        print(f"  {name}: {inv_vol:.2f}")

    print("\n风险平价配置比例:")
    for name, weight in weights.items():
        print(f"  {name}: {weight:.2%}")

    # 验证风险贡献
    print("\n验证风险贡献（应该相等）:")
    risk_contributions = {}
    for name in volatilities:
        # 风险贡献 ≈ 权重 × 波动率
        risk_contributions[name] = weights[name] * volatilities[name]

    for name, contrib in risk_contributions.items():
        print(f"  {name}: {contrib:.4f}")

    # 如果投入 100 万
    total_capital = 1000000
    print(f"\n如果投入 {total_capital:,.0f} 元:")
    for name, weight in weights.items():
        print(f"  {name}: {total_capital * weight:,.0f} 元")

    return weights

if __name__ == "__main__":
    weights = risk_parity_exercise()
```

**要点**：
- 风险平价的核心是让每个资产的风险贡献相等
- 低波动资产配置更多，高波动资产配置更少
- 这种方法在资产相关性较低时效果最好

### 练习三：设计仓位管理系统

**思路**：综合考虑止损、波动率、最大仓位、相关性等因素。

**答案**：

```python
import numpy as np
from typing import Dict, List

class ComprehensivePositionManager:
    """综合仓位管理系统"""

    def __init__(self, total_capital: float,
                 max_risk_per_trade: float = 0.02,
                 max_position_pct: float = 0.20,
                 max_total_exposure: float = 0.80,
                 max_positions: int = 10):
        """
        Args:
            total_capital: 总资金
            max_risk_per_trade: 单笔交易最大风险比例
            max_position_pct: 单只股票最大仓位比例
            max_total_exposure: 最大总仓位比例
            max_positions: 最大持仓数量
        """
        self.total_capital = total_capital
        self.max_risk_per_trade = max_risk_per_trade
        self.max_position_pct = max_position_pct
        self.max_total_exposure = max_total_exposure
        self.max_positions = max_positions

    def calculate_position_size(self, entry_price: float,
                                 stop_loss_price: float,
                                 volatility: float,
                                 correlation_with_portfolio: float = 0.5) -> Dict:
        """计算综合考虑各因素的仓位大小

        Args:
            entry_price: 入场价格
            stop_loss_price: 止损价格
            volatility: 年化波动率
            correlation_with_portfolio: 与现有组合的相关性

        Returns:
            仓位信息
        """
        # 1. 基于止损的仓位
        risk_per_share = abs(entry_price - stop_loss_price)
        if risk_per_share == 0:
            return {'shares': 0, 'reason': '止损距离为 0'}

        max_risk_amount = self.total_capital * self.max_risk_per_trade
        shares_by_risk = int(max_risk_amount / risk_per_share)

        # 2. 基于最大仓位的限制
        max_amount = self.total_capital * self.max_position_pct
        shares_by_max = int(max_amount / entry_price)

        # 3. 基于波动率的调整
        # 波动率越高，仓位越小
        target_vol = 0.15  # 目标波动率
        vol_adjustment = min(1.0, target_vol / volatility) if volatility > 0 else 1.0
        shares_by_vol = int(shares_by_risk * vol_adjustment)

        # 4. 基于相关性的调整
        # 与现有组合相关性越高，仓位越小
        correlation_adjustment = 1.0 - (correlation_with_portfolio * 0.5)
        shares_by_corr = int(shares_by_vol * correlation_adjustment)

        # 取最小值
        shares = min(shares_by_risk, shares_by_max, shares_by_vol, shares_by_corr)

        # A 股必须 100 股整数倍
        shares = (shares // 100) * 100

        amount = shares * entry_price

        return {
            'shares': shares,
            'amount': amount,
            'amount_pct': amount / self.total_capital,
            'risk_amount': shares * risk_per_share,
            'risk_pct': (shares * risk_per_share) / self.total_capital,
            'adjustments': {
                'by_risk': shares_by_risk,
                'by_max': shares_by_max,
                'by_volatility': shares_by_vol,
                'by_correlation': shares_by_corr,
                'vol_adjustment': vol_adjustment,
                'correlation_adjustment': correlation_adjustment
            }
        }

    def suggest_position(self, entry_price: float,
                          stop_loss_price: float,
                          volatility: float,
                          current_positions: List[Dict] = None) -> Dict:
        """建议仓位大小

        Args:
            entry_price: 入场价格
            stop_loss_price: 止损价格
            volatility: 年化波动率
            current_positions: 当前持仓列表

        Returns:
            建议的仓位信息
        """
        # 计算与现有组合的相关性（简化处理）
        if current_positions:
            avg_correlation = 0.5  # 假设平均相关性
        else:
            avg_correlation = 0.0

        # 计算仓位
        position = self.calculate_position_size(
            entry_price, stop_loss_price, volatility, avg_correlation
        )

        # 检查总仓位限制
        if current_positions:
            current_exposure = sum(p.get('amount', 0) for p in current_positions)
            remaining_exposure = self.total_capital * self.max_total_exposure - current_exposure

            if position['amount'] > remaining_exposure:
                position['shares'] = int(remaining_exposure / entry_price / 100) * 100
                position['amount'] = position['shares'] * entry_price
                position['limited_by'] = 'total_exposure'

        # 检查持仓数量限制
        if current_positions and len(current_positions) >= self.max_positions:
            position['shares'] = 0
            position['amount'] = 0
            position['limited_by'] = 'max_positions'

        return position

    # 场景 1：低波动股票
    print("场景 1：低波动蓝筹股")
    pos1 = manager.suggest_position(

    current_positions = [

    print("4. 基于相关性：与现有组合相关性高时减仓")
    print("5. 取以上各限制的最小值")
```
