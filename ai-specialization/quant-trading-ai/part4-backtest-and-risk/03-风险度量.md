# 03 风险度量：只看收益率不看风险，迟早要出事

> 年化 30% 的策略一定比年化 15% 的好吗？不一定。如果前者的最大回撤是 60%，而后者只有 15%，你选哪个？这一课我们学习如何用量化指标来衡量和管理风险。

## 学习目标

完成本课后，你将能够：
- 理解并计算 VaR、CVaR、最大回撤等核心风险指标
- 掌握夏普比率、Sortino 比率、Calmar 比率的区别和适用场景
- 学会组合使用多个风险指标来全面评估策略
- 构建一个完整的风险度量框架

## 场景引入

2022 年，某量化基金的宣传材料上写着："过去三年年化收益 45%，远超市场平均水平。"很多投资者被这个数字吸引，纷纷买入。

然后 2023 年，该基金亏损了 38%。

为什么？因为宣传材料上没有告诉你的是：这个策略在 2020 年 3 月曾经单月亏损 25%，在 2021 年 9 月也回撤了 18%。它的高收益是用高风险换来的——而且是那种在极端情况下会爆仓的风险。

**收益率只是故事的一半，风险才是另一半。** 不理解风险的投资者，就像不看路况只看速度表的司机——迟早要出事。

今天我们要学习的就是如何量化风险。不是那种"感觉风险挺大的"主观判断，而是用数学指标来精确度量：这个策略到底有多危险？

## 核心概念

### 一、为什么需要风险度量？

```
两个策略的收益对比：

策略 A：年化 30%，最大回撤 60%
策略 B：年化 15%，最大回撤 15%

净值曲线（简化示意）：

策略 A：
  100 → 130 → 170 → 220 → 88 → 120 → 160 → 210
         ↑ 涨得快              ↑ 跌得惨

策略 B：
  100 → 110 → 115 → 125 → 112 → 118 → 128 → 140
         ↑ 涨得慢         ↑ 回撤小

如果你在最高点投入 100 万：
策略 A：220 万 → 88 万（亏了 132 万，需要涨 150% 才能回本）
策略 B：125 万 → 112 万（亏了 13 万，涨 12% 就回本了）

结论：高收益不等于好策略，风险调整后的收益才有意义
```

### 二、波动率（Volatility）

波动率是最基础的风险指标，衡量收益的离散程度。

```
波动率的直觉理解：

低波动率：                    高波动率：
  收益                         收益
   ↑    *                      ↑        *
   │   * *                     │  *       *
   │  *   *                    │    *       *
   │ *     *                   │      *   *
   │*       *                  │ *       *
   └──────────→ 时间           └──────────→ 时间
   收益变化平稳                 收益变化剧烈

年化波动率 = 日收益率标准差 × √252
```

**波动率的局限**：波动率把上行波动和下行波动同等对待。对于投资者来说，上涨的波动是"好事"，只有下跌的波动才是真正的风险。

### 三、VaR（Value at Risk）

VaR 回答的问题是：**在正常市场条件下，给定置信水平，我的最大损失是多少？**

```
VaR 的直觉理解：

收益率分布：
  频率
    ↑
    │      ████████
    │    ████████████
    │   ██████████████
    │  ████████████████
    │ ██████████████████
    │████████████████████
    └──────────────────────→ 收益率
    -10%  -5%   0%   5%  10%
         ↑
         │
         VaR(95%) = -5%
         含义：95% 的概率，单日损失不超过 5%

计算方法：
1. 历史模拟法：用历史收益率的分位数
2. 参数法：假设正态分布，用均值和标准差计算
3. 蒙特卡洛法：模拟大量可能的收益路径
```

**VaR 的局限**：VaR 只告诉你"正常情况"下的最大损失，但不告诉你"极端情况"下会亏多少。这就是为什么我们需要 CVaR。

### 四、CVaR（Conditional Value at Risk）

CVaR 回答的问题是：**如果损失超过了 VaR，平均会亏多少？** 也叫 Expected Shortfall（ES）。

```
CVaR 的直觉理解：

收益率分布：
  频率
    ↑
    │      ████████
    │    ████████████
    │   ██████████████
    │  ████████████████
    │ ██████████████████
    │████████████████████
    └──────────────────────→ 收益率
    -10%  -5%   0%   5%  10%
    ↑─────↑
    │     │
    │     VaR(95%) = -5%
    │
    CVaR(95%) = -7.5%
    含义：如果损失超过 VaR（5% 的极端情况），
         平均损失是 7.5%

CVaR ≥ VaR（总是成立）
CVaR 比 VaR 更保守，更能反映尾部风险
```

### 五、最大回撤（Maximum Drawdown）

最大回撤衡量的是：**从最高点到最低点，最大的跌幅是多少？**

```
最大回撤的计算：

净值曲线：
  1.5 │          *
      │        *   *
  1.3 │      *       *
      │    *           *
  1.1 │  *               *  *
      │*                     * *
  0.9 │                        *
      └──────────────────────────→ 时间
        ↑                ↑
        最高点           最低点
        1.5              0.9

最大回撤 = (1.5 - 0.9) / 1.5 = 40%
含义：从最高点到最低点，资产缩水了 40%

最大回撤的修复时间也很重要：
如果回撤后很快修复，说明策略恢复能力强
如果回撤后长期无法修复，说明策略可能有问题
```

### 六、风险调整收益指标

单纯看收益率没有意义，需要结合风险来看。以下是三个常用的风险调整收益指标：

**夏普比率（Sharpe Ratio）**：

```
夏普比率 = (策略收益率 - 无风险利率) / 策略波动率

直觉理解：
  - 夏普比率衡量的是每承担一单位风险，能获得多少超额收益
  - 夏普比率 = 1：每承担 1% 的风险，获得 1% 的超额收益（不错）
  - 夏普比率 = 2：每承担 1% 的风险，获得 2% 的超额收益（很好）
  - 夏普比率 < 0：还不如买国债

局限：
  - 把上行波动和下行波动同等对待
  - 假设收益服从正态分布
```

**Sortino 比率**：

```
Sortino 比率 = (策略收益率 - 无风险利率) / 下行波动率

下行波动率 = 只计算负收益的标准差

与夏普比率的区别：
  - 夏普比率：惩罚所有波动（包括上涨）
  - Sortino 比率：只惩罚下行波动

适用场景：
  - 策略收益分布不对称时（如期权策略）
  - 你更关心亏损而不是波动
```

**Calmar 比率**：

```
Calmar 比率 = 年化收益率 / 最大回撤

直觉理解：
  - 衡量每承担 1% 的最大回撤，能获得多少年化收益
  - Calmar = 1：承担 10% 的最大回撤，获得 10% 的年化收益
  - Calmar = 3：承担 10% 的最大回撤，获得 30% 的年化收益（很好）

适用场景：
  - 你更关心极端回撤而不是日常波动
  - 适合评估绝对收益策略
```

## 代码实现

### 一、基础风险指标计算

```python
import numpy as np
import pandas as pd
from scipy import stats
from typing import Dict, Optional

class RiskMetrics:
    """风险度量计算框架"""

    def __init__(self, returns: pd.Series, risk_free_rate: float = 0.02):
        """
        Args:
            returns: 日收益率序列
            risk_free_rate: 年化无风险利率
        """
        self.returns = returns.dropna()
        self.risk_free_rate = risk_free_rate
        self.daily_rf = (1 + risk_free_rate) ** (1/252) - 1

    def volatility(self, annualize: bool = True) -> float:
        """计算波动率"""
        vol = self.returns.std()
        if annualize:
            vol = vol * np.sqrt(252)
        return vol

    def downside_volatility(self, target_return: float = 0, annualize: bool = True) -> float:
        """计算下行波动率"""
        downside_returns = self.returns[self.returns < target_return]
        if len(downside_returns) == 0:
            return 0.0
        downside_vol = downside_returns.std()
        if annualize:
            downside_vol = downside_vol * np.sqrt(252)
        return downside_vol

    def var(self, confidence_level: float = 0.95, method: str = 'historical') -> float:
        """计算 VaR

        Args:
            confidence_level: 置信水平（如 0.95 表示 95%）
            method: 计算方法
                - 'historical': 历史模拟法
                - 'parametric': 参数法（假设正态分布）
                - 'cornish_fisher': Cornish-Fisher 展开（考虑偏度和峰度）
        """
        if method == 'historical':
            # 历史模拟法：直接用分位数
            return np.percentile(self.returns, (1 - confidence_level) * 100)

        elif method == 'parametric':
            # 参数法：假设正态分布
            z_score = stats.norm.ppf(1 - confidence_level)
            return self.returns.mean() + z_score * self.returns.std()

        elif method == 'cornish_fisher':
            # Cornish-Fisher 展开：考虑偏度和峰度
            z = stats.norm.ppf(1 - confidence_level)
            s = stats.skew(self.returns)
            k = stats.kurtosis(self.returns)

            # Cornish-Fisher 调整
            z_cf = z + (z**2 - 1) * s / 6 + (z**3 - 3*z) * k / 24 - (2*z**3 - 5*z) * s**2 / 36

            return self.returns.mean() + z_cf * self.returns.std()

        else:
            raise ValueError(f"不支持的方法: {method}")

    def cvar(self, confidence_level: float = 0.95, method: str = 'historical') -> float:
        """计算 CVaR（条件风险价值）

        CVaR = 超过 VaR 的损失的平均值
        """
        var_value = self.var(confidence_level, method)

        # 超过 VaR 的损失
        beyond_var = self.returns[self.returns <= var_value]

        if len(beyond_var) == 0:
            return var_value

        return beyond_var.mean()

    def max_drawdown(self) -> Dict:
        """计算最大回撤及其相关信息"""
        # 计算累积收益
        cumulative = (1 + self.returns).cumprod()

        # 计算滚动最高点
        rolling_max = cumulative.cummax()

        # 计算回撤
        drawdown = (cumulative - rolling_max) / rolling_max

        # 最大回撤
        max_dd = drawdown.min()
        max_dd_end = drawdown.idxmin()

        # 找到最大回撤的起始点
        max_dd_start = cumulative[:max_dd_end].idxmax()

        # 计算回撤持续时间
        if max_dd_end > max_dd_start:
            dd_duration = (max_dd_end - max_dd_start).days
        else:
            dd_duration = 0

        # 计算修复时间（如果已修复）
        recovery_mask = cumulative[max_dd_end:] >= rolling_max[max_dd_end]
        if recovery_mask.any():
            recovery_date = recovery_mask.idxmax()
            recovery_duration = (recovery_date - max_dd_end).days
        else:
            recovery_date = None
            recovery_duration = None

        return {
            'max_drawdown': max_dd,
            'max_dd_start': max_dd_start,
            'max_dd_end': max_dd_end,
            'dd_duration_days': dd_duration,
            'recovery_date': recovery_date,
            'recovery_duration_days': recovery_duration,
            'is_recovered': recovery_date is not None
        }

    def sharpe_ratio(self) -> float:
        """计算夏普比率"""
        excess_returns = self.returns - self.daily_rf
        if excess_returns.std() == 0:
            return 0.0
        return excess_returns.mean() / excess_returns.std() * np.sqrt(252)

    def sortino_ratio(self, target_return: float = 0) -> float:
        """计算 Sortino 比率"""
        excess_returns = self.returns - self.daily_rf
        downside_vol = self.downside_volatility(target_return, annualize=True)

        if downside_vol == 0:
            return 0.0

        annual_excess_return = excess_returns.mean() * 252
        return annual_excess_return / downside_vol

    def calmar_ratio(self) -> float:
        """计算 Calmar 比率"""
        max_dd = self.max_drawdown()['max_drawdown']
        if max_dd == 0:
            return 0.0

        annual_return = self.returns.mean() * 252
        return annual_return / abs(max_dd)

    def tail_ratio(self) -> float:
        """尾部比率：右尾分位数 / 左尾分位数

        > 1 表示右尾更厚（上涨潜力大于下跌风险）
        < 1 表示左尾更厚（下跌风险大于上涨潜力）
        """
        right_tail = np.percentile(self.returns, 95)
        left_tail = np.percentile(self.returns, 5)

        if left_tail == 0:
            return float('inf')

        return abs(right_tail / left_tail)

    def skewness(self) -> float:
        """计算偏度"""
        return stats.skew(self.returns)

    def kurtosis(self) -> float:
        """计算峰度"""
        return stats.kurtosis(self.returns)

    def get_full_report(self) -> Dict:
        """生成完整的风险报告"""
        dd_info = self.max_drawdown()

        return {
            # 收益指标
            'total_return': (1 + self.returns).prod() - 1,
            'annual_return': self.returns.mean() * 252,
            'annual_volatility': self.volatility(),

            # 风险指标
            'var_95_historical': self.var(0.95, 'historical'),
            'var_95_parametric': self.var(0.95, 'parametric'),
            'cvar_95': self.cvar(0.95),
            'max_drawdown': dd_info['max_drawdown'],
            'max_dd_duration_days': dd_info['dd_duration_days'],
            'recovery_duration_days': dd_info['recovery_duration_days'],

            # 风险调整收益
            'sharpe_ratio': self.sharpe_ratio(),
            'sortino_ratio': self.sortino_ratio(),
            'calmar_ratio': self.calmar_ratio(),

            # 分布特征
            'skewness': self.skewness(),
            'kurtosis': self.kurtosis(),
            'tail_ratio': self.tail_ratio(),
        }
```

### 二、滚动风险指标

```python
class RollingRiskMetrics:
    """滚动风险指标计算"""

    def __init__(self, returns: pd.Series, window: int = 63):
        """
        Args:
            returns: 日收益率序列
            window: 滚动窗口大小（天数），默认 63 天（约一个季度）
        """
        self.returns = returns
        self.window = window

    def rolling_volatility(self) -> pd.Series:
        """滚动波动率"""
        return self.returns.rolling(window=self.window).std() * np.sqrt(252)

    def rolling_sharpe(self, risk_free_rate: float = 0.02) -> pd.Series:
        """滚动夏普比率"""
        daily_rf = (1 + risk_free_rate) ** (1/252) - 1
        excess_returns = self.returns - daily_rf

        rolling_mean = excess_returns.rolling(window=self.window).mean()
        rolling_std = excess_returns.rolling(window=self.window).std()

        return (rolling_mean / rolling_std) * np.sqrt(252)

    def rolling_max_drawdown(self) -> pd.Series:
        """滚动最大回撤"""
        def max_dd_in_window(window_returns):
            cumulative = (1 + window_returns).cumprod()
            rolling_max = cumulative.cummax()
            drawdown = (cumulative - rolling_max) / rolling_max
            return drawdown.min()

        return self.returns.rolling(window=self.window).apply(max_dd_in_window, raw=True)

    def rolling_var(self, confidence_level: float = 0.95) -> pd.Series:
        """滚动 VaR"""
        def var_in_window(window_returns):
            return np.percentile(window_returns, (1 - confidence_level) * 100)

        return self.returns.rolling(window=self.window).apply(var_in_window, raw=True)

    def get_all_rolling_metrics(self, risk_free_rate: float = 0.02) -> pd.DataFrame:
        """获取所有滚动指标"""
        return pd.DataFrame({
            'rolling_volatility': self.rolling_volatility(),
            'rolling_sharpe': self.rolling_sharpe(risk_free_rate),
            'rolling_max_drawdown': self.rolling_max_drawdown(),
            'rolling_var_95': self.rolling_var(0.95)
        })
```

### 三、多策略风险对比

```python
class RiskComparison:
    """多策略风险对比分析"""

    def __init__(self, strategies: Dict[str, pd.Series], risk_free_rate: float = 0.02):
        """
        Args:
            strategies: 策略名称 -> 收益率序列 的字典
        """
        self.strategies = strategies
        self.risk_free_rate = risk_free_rate

    def comparison_table(self) -> pd.DataFrame:
        """生成策略对比表"""
        results = []

        for name, returns in self.strategies.items():
            metrics = RiskMetrics(returns, self.risk_free_rate)
            report = metrics.get_full_report()
            report['strategy'] = name
            results.append(report)

        df = pd.DataFrame(results)
        df.set_index('strategy', inplace=True)

        # 格式化显示
        format_dict = {
            'total_return': '{:.2%}',
            'annual_return': '{:.2%}',
            'annual_volatility': '{:.2%}',
            'var_95_historical': '{:.2%}',
            'cvar_95': '{:.2%}',
            'max_drawdown': '{:.2%}',
            'sharpe_ratio': '{:.2f}',
            'sortino_ratio': '{:.2f}',
            'calmar_ratio': '{:.2f}',
            'skewness': '{:.3f}',
            'kurtosis': '{:.3f}',
            'tail_ratio': '{:.2f}',
        }

        return df, format_dict

    def rank_strategies(self, metric: str = 'sharpe_ratio',
                        ascending: bool = False) -> pd.DataFrame:
        """按指定指标排名策略"""
        df, _ = self.comparison_table()
        return df.sort_values(metric, ascending=ascending)

    def risk_return_scatter_data(self) -> pd.DataFrame:
        """获取风险-收益散点图数据"""
        data = []
        for name, returns in self.strategies.items():
            metrics = RiskMetrics(returns, self.risk_free_rate)
            data.append({
                'strategy': name,
                'risk': metrics.volatility(),
                'return': metrics.returns.mean() * 252,
                'sharpe': metrics.sharpe_ratio()
            })
        return pd.DataFrame(data)
```

```python
def generate_sample_returns(n_days: int = 252, strategy_type: str = 'normal',
                             seed: int = 42) -> pd.Series:
    """生成不同类型的策略收益用于演示"""
    np.random.seed(seed)
    dates = pd.date_range('2024-01-01', periods=n_days, freq='B')

    if strategy_type == 'normal':
        # 正常策略
        returns = np.random.normal(0.0005, 0.015, n_days)

    elif strategy_type == 'high_volatility':
        # 高波动策略
        returns = np.random.normal(0.0008, 0.03, n_days)

    elif strategy_type == 'fat_tail':
        # 厚尾分布（偶尔大跌）
        returns = np.random.normal(0.0005, 0.012, n_days)
        # 添加一些极端事件
        extreme_indices = np.random.choice(n_days, 10, replace=False)
        returns[extreme_indices] = np.random.normal(-0.05, 0.02, 10)

    elif strategy_type == 'negative_skew':
        # 负偏态（下跌时跌得更多）
        returns = np.random.normal(0.0003, 0.015, n_days)
        # 让下跌幅度更大
        returns[returns < 0] *= 1.5

    else:
        returns = np.random.normal(0.0005, 0.015, n_days)

    return pd.Series(returns, index=dates)

if __name__ == "__main__":
    # 生成不同类型的策略收益
    strategies = {

        '厚尾型': generate_sample_returns(strategy_type='fat_tail', seed=42),

    print(df.to_string())

    # 排名
    print("\n" + "=" * 80)

    ranked = comparator.rank_strategies('sharpe_ratio')

    report = risk_calc.get_full_report()

    for key, value in report.items():
        if isinstance(value, float):
            if abs(value) < 1:
                print(f"{key}: {value:.4f}")
            else:
                print(f"{key}: {value:.2f}")
        else:
            print(f"{key}: {value}")

    # 最大回撤详情
    dd_info = risk_calc.max_drawdown()
    print("\n最大回撤详情:")
    print(f"  回撤幅度: {dd_info['max_drawdown']:.2%}")
    print(f"  开始时间: {dd_info['max_dd_start']}")
    print(f"  结束时间: {dd_info['max_dd_end']}")
    print(f"  持续天数: {dd_info['dd_duration_days']}")
    print(f"  是否修复: {'是' if dd_info['is_recovered'] else '否'}")
```

## 常见误区

### 误区一：只看收益率

很多人在比较策略时只看收益率，完全忽略风险。这就像评价一个学生只看最高分，不看平均分和标准差。

**正确做法**：始终使用风险调整收益指标（夏普比率、Sortino 比率等）来评估策略。

### 误区二：假设正态分布

金融市场的收益率通常不是正态分布的，而是有"肥尾"（极端事件更频繁）和"偏态"（上涨和下跌不对称）。

**正确做法**：同时使用参数法和历史模拟法计算 VaR/CVaR，关注偏度和峰度指标。

### 误区三：忽略回撤的持续时间

只关注最大回撤的幅度，忽略回撤持续的时间。一个持续 1 年的 30% 回撤和一个持续 1 个月的 30% 回撤，对投资者的心理影响完全不同。

**正确做法**：同时关注回撤幅度、持续时间和修复时间。

### 误区四：过度依赖单一指标

只看夏普比率，或者只看最大回撤。每个指标都有其局限性，需要综合使用。

**正确做法**：构建包含多个指标的风险报告，从不同角度评估风险。

### 误区五：历史风险等于未来风险

过去一年的波动率是 15%，不代表未来一年也是 15%。市场状态会变化，风险也会变化。

**正确做法**：使用滚动指标来监控风险的变化，设置风险预警阈值。

## 小结与练习

### 小结

本课我们学习了以下风险度量指标：

**基础风险指标**：
- **波动率**：衡量收益的离散程度
- **VaR**：正常情况下的最大损失
- **CVaR**：极端情况下的平均损失
- **最大回撤**：从最高点到最低点的跌幅

**风险调整收益指标**：
- **夏普比率**：每单位波动率的超额收益
- **Sortino 比率**：每单位下行波动率的超额收益
- **Calmar 比率**：每单位最大回撤的年化收益

**使用建议**：
1. 不要只看收益率，要看风险调整后的收益
2. 综合使用多个指标，不要过度依赖单一指标
3. 关注指标的动态变化，不要只看静态数值
4. 理解每个指标的局限性

def rolling_risk_analysis(returns: pd.Series, window: int = 63):
    """滚动风险分析"""

    rolling_calc = RollingRiskMetrics(returns, window)
    rolling_df = rolling_calc.get_all_rolling_metrics()

    print("=== 滚动风险分析 ===\n")

    # 1. 波动率分析
    print("【波动率分析】")

    print(f"  平均波动率: {vol.mean():.2%}")
    print(f"  最高波动率: {vol.max():.2%} ({vol.idxmax()})")
    print(f"  最低波动率: {vol.min():.2%} ({vol.idxmin()})")

    # 检测波动率聚集
    high_vol_periods = vol[vol > vol.mean() + vol.std()]
    if len(high_vol_periods) > 0:
        print(f"\n  高波动时期（>{vol.mean() + vol.std():.2%}）:")
        for date, value in high_vol_periods.head(5).items():
            print(f"    {date.strftime('%Y-%m-%d')}: {value:.2%}")

    # 2. 夏普比率分析
    print("\n【夏普比率分析】")
    sharpe = rolling_df['rolling_sharpe'].dropna()
    print(f"  平均夏普比率: {sharpe.mean():.2f}")
    print(f"  最高夏普比率: {sharpe.max():.2f} ({sharpe.idxmax()})")
    print(f"  最低夏普比率: {sharpe.min():.2f} ({sharpe.idxmin()})")

    # 检测夏普恶化的时期
    low_sharpe_periods = sharpe[sharpe < 0]
    if len(low_sharpe_periods) > 0:
        print(f"\n  负夏普时期（共 {len(low_sharpe_periods)} 天）:")
        print(f"    最早出现: {low_sharpe_periods.index[0].strftime('%Y-%m-%d')}")
        print(f"    最晚出现: {low_sharpe_periods.index[-1].strftime('%Y-%m-%d')}")

    # 3. 最大回撤分析
    print("\n【最大回撤分析】")
    max_dd = rolling_df['rolling_max_drawdown'].dropna()
    print(f"  平均最大回撤: {max_dd.mean():.2%}")
    print(f"  最大回撤: {max_dd.min():.2%} ({max_dd.idxmin()})")

    # 4. 风险预警
    print("\n【风险预警】")
    warnings = []

    # 波动率预警
    if vol.iloc[-1] > vol.mean() + 2 * vol.std():
        warnings.append(f"波动率异常高: {vol.iloc[-1]:.2%}")

    if max_dd.iloc[-1] < -0.2:
        warnings.append(f"回撤异常大: {max_dd.iloc[-1]:.2%}")

    if warnings:
        for w in warnings:
            print(f"  ⚠ {w}")
    else:
        print("  ✓ 当前无风险预警")

    return rolling_df

### 练习三：风险预警系统

**思路**：设置多个预警指标和阈值，当指标超过阈值时触发预警。

**答案**：

```python
class RiskAlertSystem:
    """风险预警系统"""

    def __init__(self, returns: pd.Series, window: int = 63):
        self.returns = returns
        self.window = window
        self.rolling_calc = RollingRiskMetrics(returns, window)

        # 默认预警阈值
        self.thresholds = {
            'volatility_high': 0.25,        # 波动率超过 25%
            'volatility_percentile': 0.95,   # 波动率超过历史 95 分位
            'sharpe_low': -0.5,              # 夏普比率低于 -0.5
            'drawdown_warning': -0.15,       # 回撤超过 15%
            'drawdown_critical': -0.25,      # 回撤超过 25%
            'var_95_high': -0.03,            # VaR 超过 3%
        }

    def check_alerts(self) -> list:
        """检查所有预警条件"""
        alerts = []
        rolling_df = self.rolling_calc.get_all_rolling_metrics()

        # 1. 波动率预警
        vol = rolling_df['rolling_volatility'].dropna()
        current_vol = vol.iloc[-1]

        if current_vol > self.thresholds['volatility_high']:
            alerts.append({
                'level': 'HIGH',
                'type': '波动率',
                'message': f'当前波动率 {current_vol:.2%} 超过阈值 {self.thresholds["volatility_high"]:.2%}',
                'value': current_vol,
                'threshold': self.thresholds['volatility_high']
            })

        vol_percentile = (vol < current_vol).mean()
        if vol_percentile > self.thresholds['volatility_percentile']:
            alerts.append({
                'level': 'MEDIUM',
                'type': '波动率',
                'message': f'当前波动率处于历史 {vol_percentile:.1%} 分位',
                'value': current_vol,
                'threshold': None
            })

        # 2. 夏普比率预警
        sharpe = rolling_df['rolling_sharpe'].dropna()
        current_sharpe = sharpe.iloc[-1]

        if current_sharpe < self.thresholds['sharpe_low']:
            alerts.append({
                'level': 'HIGH',
                'type': '夏普比率',
                'message': f'当前夏普比率 {current_sharpe:.2f} 低于阈值 {self.thresholds["sharpe_low"]}',
                'value': current_sharpe,
                'threshold': self.thresholds['sharpe_low']
            })

        # 3. 回撤预警
        # 计算当前回撤
        cumulative = (1 + self.returns).cumprod()
        rolling_max = cumulative.cummax()
        current_drawdown = (cumulative.iloc[-1] - rolling_max.iloc[-1]) / rolling_max.iloc[-1]

        if current_drawdown < self.thresholds['drawdown_critical']:
            alerts.append({
                'level': 'CRITICAL',
                'type': '回撤',
                'message': f'当前回撤 {current_drawdown:.2%} 超过危急阈值 {self.thresholds["drawdown_critical"]:.2%}',
                'value': current_drawdown,
                'threshold': self.thresholds['drawdown_critical']
            })
        elif current_drawdown < self.thresholds['drawdown_warning']:
            alerts.append({
                'level': 'HIGH',
                'type': '回撤',
                'message': f'当前回撤 {current_drawdown:.2%} 超过预警阈值 {self.thresholds["drawdown_warning"]:.2%}',
                'value': current_drawdown,
                'threshold': self.thresholds['drawdown_warning']
            })

        # 4. VaR 预警
        risk_calc = RiskMetrics(self.returns)
        current_var = risk_calc.var(0.95)

        if current_var < self.thresholds['var_95_high']:
            alerts.append({
                'level': 'MEDIUM',
                'type': 'VaR',
                'message': f'当前 VaR(95%) {current_var:.2%} 超过阈值 {self.thresholds["var_95_high"]:.2%}',
                'value': current_var,
                'threshold': self.thresholds['var_95_high']
            })

        return alerts

    def print_alerts(self):
        """打印预警信息"""
        alerts = self.check_alerts()

        if not alerts:
            print("✓ 当前无风险预警")
            return

        print(f"⚠ 发现 {len(alerts)} 个风险预警:\n")

        level_order = {'CRITICAL': 0, 'HIGH': 1, 'MEDIUM': 2, 'LOW': 3}
        alerts.sort(key=lambda x: level_order.get(x['level'], 99))

        for alert in alerts:
            level_icon = {
                'CRITICAL': '🔴',
                'HIGH': '🟠',
                'MEDIUM': '🟡',
                'LOW': '🟢'
            }.get(alert['level'], '⚪')

            print(f"{level_icon} [{alert['level']}] {alert['type']}")
            print(f"   {alert['message']}")
            if alert['threshold'] is not None:
                print(f"   阈值: {alert['threshold']:.2%}")
            print()

    def get_risk_status(self) -> Dict:
        """获取风险状态摘要"""
        alerts = self.check_alerts()

        if not alerts:
            return {'status': '正常', 'alert_count': 0, 'max_level': None}

        max_level = min(alerts, key=lambda x: {'CRITICAL': 0, 'HIGH': 1, 'MEDIUM': 2, 'LOW': 3}[x['level']])

        return {
            'status': '预警' if alerts else '正常',
            'alert_count': len(alerts),
            'max_level': max_level['level'],
            'alerts': alerts
        }

# 使用示例
if __name__ == "__main__":
    # 创建带问题的收益序列
    np.random.seed(42)
    dates = pd.date_range('2024-01-01', periods=252, freq='B')

    # 模拟一个有问题的策略：后期波动增大，出现大幅回撤
    normal_returns = np.random.normal(0.001, 0.01, 200)
    problem_returns = np.random.normal(-0.002, 0.04, 52)
    all_returns = np.concatenate([normal_returns, problem_returns])

    returns = pd.Series(all_returns, index=dates)

    # 运行风险预警系统
    alert_system = RiskAlertSystem(returns)
    alert_system.print_alerts()

    status = alert_system.get_risk_status()

    print(f"预警数量: {status['alert_count']}")
    if status['max_level']:
        print(f"最高级别: {status['max_level']}")
```

**要点**：
- 预警系统应该有多个级别（CRITICAL、HIGH、MEDIUM、LOW）
- 阈值应该根据策略特性和风险偏好调整
- 预警应该及时、明确、可操作
