# 回测引擎设计

> 一个回测引擎的好坏，决定了你能否信任策略的历史表现。设计不当的引擎会给你虚假的信心，实盘时才发现一切只是幻觉。

---

## 场景引入

你花了一个月研究出一个动量策略，用 Python 写了个简单的回测脚本：遍历每根 K 线，计算信号，记录交易，最后算收益。回测结果很漂亮——年化 28%，最大回撤 12%。

但你把策略接入实盘后，发现执行延迟导致信号和实际成交价差了 0.3%，手续费比你预估的高了一倍，而且你的脚本根本不支持同时管理多只股票的仓位。三个月后，账户亏损 8%。

问题不在策略，而在回测引擎。一个粗糙的回测脚本和一个工程化的回测引擎之间，差距是巨大的。本课将带你理解回测引擎的核心设计决策，并从零实现一个事件驱动回测框架。

---

## 学习目标

完成本课学习后，你将能够：

1. 理解事件驱动回测与向量化回测的区别与适用场景
2. 掌握回测引擎的核心组件：数据模块、信号模块、执行模块、组合模块
3. 实现一个支持多标的、多策略的事件驱动回测框架
4. 理解回测中的时间管理与数据流

## 核心概念

### 一、两种回测范式

回测引擎有两种主流架构：**向量化回测**和**事件驱动回测**。

```
向量化回测（Vectorized Backtest）：

  数据矩阵          信号矩阵          收益矩阵
  ┌──────────┐      ┌──────────┐      ┌──────────┐
  │ P1 P2 P3 │  →   │ S1 S2 S3 │  →   │ R1 R2 R3 │
  │ P1 P2 P3 │      │ S1 S2 S3 │      │ R1 R2 R3 │
  │ P1 P2 P3 │      │ S1 S2 S3 │      │ R1 R2 R3 │
  └──────────┘      └──────────┘      └──────────┘
  全部数据一次性加载    一次性计算所有信号    一次性计算收益

  优点：速度快（NumPy 向量化）、代码简洁
  缺点：难以处理复杂执行逻辑、容易引入前视偏差
```

```
事件驱动回测（Event-Driven Backtest）：

  时间线 ──────────────────────────────────────►

  T1: 收到数据 → 生成信号 → 风控检查 → 下单 → 记录
  T2: 收到数据 → 生成信号 → 风控检查 → 下单 → 记录
  T3: 收到数据 → 收到成交回报 → 更新持仓 → 记录
  ...

  每个时间步独立处理，模拟真实交易流程
  优点：逻辑严谨、接近实盘、易于扩展
  缺点：速度慢、代码复杂
```

```
两种范式的选型决策：

  ┌─────────────────────────────────────────────────┐
  │           你的策略需要什么？                       │
  └──────────────────────┬──────────────────────────┘
                         │
           ┌─────────────┴─────────────┐
           │                           │
     简单信号 + 大规模扫描        复杂执行 + 多标的管理
     （因子研究、IC 测试）        （多策略、风控、滑点模型）
           │                           │
           ▼                           ▼
      向量化回测                   事件驱动回测
     （VectorBT）                （自研 / Backtrader）
```

### 二、事件驱动回测的核心组件

一个工程化的事件驱动回测引擎由五个核心模块组成：

```
事件驱动回测引擎架构：

  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
  │  数据模块    │    │  信号模块    │    │  风控模块    │
  │  (DataFeed) │ →  │ (Strategy)  │ →  │ (RiskMgr)   │
  └─────────────┘    └─────────────┘    └──────┬──────┘
                                               │
                                               ▼
  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
  │  组合模块    │ ←  │  执行模块    │ ←  │  订单模块    │
  │ (Portfolio) │    │ (Executor)  │    │ (OrderMgr)  │
  └─────────────┘    └─────────────┘    └─────────────┘

  数据流：DataFeed → Strategy → RiskMgr → OrderMgr → Executor → Portfolio
  每个模块通过事件（Event）进行通信
```

各模块的职责：

```
模块          输入                    输出                    职责
──────────────────────────────────────────────────────────────────────
DataFeed      原始行情数据            Bar/Quote 事件          数据标准化、时间对齐
Strategy      Bar 事件               Signal 事件             信号计算、交易决策
RiskMgr       Signal 事件            Order 事件              仓位检查、风险限制
OrderMgr      Order 事件             执行请求                订单拆分、类型转换
Executor      执行请求                Fill 事件               模拟成交、滑点模型
Portfolio     Fill 事件               组合状态更新             持仓管理、P&L 计算
```

### 三、回测中的时间管理

时间管理是回测引擎中最容易出错的部分。核心原则是：**在时间 T，只能使用 T 及之前的数据**。

```
时间对齐问题示意：

  股票 A 的 K 线：  9:30  9:31  9:32  9:33  9:34
  股票 B 的 K 线：  9:30  9:31        9:33  9:34
                           ↑
                        B 在 9:32 缺失数据

  错误做法：在 9:32 用 A 的数据做决策，忽略了 B 缺失
  正确做法：在 9:32 只用两只股票截至 9:31 的最新数据

  这就是为什么需要"数据对齐"机制
```

### 四、Backtrader 架构分析

Backtrader 是 Python 生态中最成熟的开源回测框架之一。理解它的设计思想对自研引擎很有帮助：

```
Backtrader 的核心类层次：

  Cerebro（大脑）
    ├── DataFeed（数据源）
    │     ├── CSVData
    │     ├── PandasData
    │     └── ...
    ├── Strategy（策略）
    │     ├── next()        # 每根 K 线调用
    │     ├── notify_order() # 订单状态通知
    │     └── notify_trade() # 成交通知
    ├── Broker（经纪人）
    │     ├── cash          # 可用资金
    │     ├── position      # 持仓
    │     └── submit()      # 提交订单
    ├── Analyzer（分析器）
    │     ├── SharpeRatio
    │     ├── DrawDown
    │     └── Returns
    └── Observer（观察者）
          ├── BrokerObserver
          └── TradeObserver
```

## 代码示例：从零实现事件驱动回测引擎

以下代码实现一个简化但完整的事件驱动回测引擎，支持多标的、多策略、基本风控。

```python
"""
事件驱动回测引擎
支持多标的、多策略、止损止盈、手续费计算
"""

import numpy as np
import pandas as pd
from dataclasses import dataclass, field
from enum import Enum
from typing import Dict, List, Optional, Callable
from collections import defaultdict


# ========== 1. 基础数据结构 ==========

class EventType(Enum):
    BAR = "bar"           # K 线数据
    SIGNAL = "signal"     # 交易信号
    ORDER = "order"       # 订单
    FILL = "fill"         # 成交


class OrderSide(Enum):
    BUY = "buy"
    SELL = "sell"


class OrderType(Enum):
    MARKET = "market"     # 市价单
    LIMIT = "limit"       # 限价单


@dataclass
class Bar:
    """K 线数据"""
    symbol: str
    timestamp: pd.Timestamp
    open: float
    high: float
    low: float
    close: float
    volume: float


@dataclass
class Signal:
    """交易信号"""
    symbol: str
    timestamp: pd.Timestamp
    direction: int        # 1=买入, -1=卖出, 0=无信号
    strength: float = 1.0 # 信号强度 (0~1)
    reason: str = ""


@dataclass
class Order:
    """订单"""
    symbol: str
    timestamp: pd.Timestamp
    side: OrderSide
    quantity: int
    order_type: OrderType = OrderType.MARKET
    limit_price: Optional[float] = None
    stop_loss: Optional[float] = None
    take_profit: Optional[float] = None
    order_id: str = ""


@dataclass
class Fill:
    """成交回报"""
    symbol: str
    timestamp: pd.Timestamp
    side: OrderSide
    quantity: int
    price: float
    commission: float
    slippage: float
    order_id: str = ""


@dataclass
class Position:
    """持仓"""
    symbol: str
    quantity: int = 0
    avg_price: float = 0.0
    unrealized_pnl: float = 0.0
    realized_pnl: float = 0.0


# ========== 2. 数据模块 ==========

class DataFeed:
    """数据源：将 DataFrame 转换为 Bar 事件流"""

    def __init__(self, data_dict: Dict[str, pd.DataFrame]):
        """
        参数:
            data_dict: {symbol: DataFrame}，DataFrame 必须包含
                       open, high, low, close, volume 列，index 为 DatetimeIndex
        """
        self.data_dict = data_dict
        self.symbols = list(data_dict.keys())
        self._merged = self._merge_data()
        self._current_idx = 0

    def _merge_data(self) -> pd.DataFrame:
        """合并多标的数据，按时间排序"""
        all_bars = []
        for symbol, df in self.data_dict.items():
            for ts, row in df.iterrows():
                all_bars.append(Bar(
                    symbol=symbol,
                    timestamp=ts,
                    open=row['open'],
                    high=row['high'],
                    low=row['low'],
                    close=row['close'],
                    volume=row['volume']
                ))
        all_bars.sort(key=lambda x: (x.timestamp, x.symbol))
        return all_bars

    def __iter__(self):
        return self

    def __next__(self) -> Bar:
        if self._current_idx >= len(self._merged):
            raise StopIteration
        bar = self._merged[self._current_idx]
        self._current_idx += 1
        return bar

    def __len__(self):
        return len(self._merged)


# ========== 3. 策略基类 ==========

class Strategy:
    """策略基类：所有策略继承此类"""

    def __init__(self):
        self.engine = None  # 回测引擎引用

    def on_init(self):
        """初始化时调用"""
        pass

    def on_bar(self, bar: Bar):
        """每根 K 线调用"""
        pass

    def on_fill(self, fill: Fill):
        """成交通知"""
        pass

    def get_historical(self, symbol: str, n: int) -> pd.DataFrame:
        """获取历史数据"""
        if self.engine is None:
            return pd.DataFrame()
        return self.engine.get_history(symbol, n)

    def submit_signal(self, signal: Signal):
        """提交交易信号"""
        if self.engine:
            self.engine.process_signal(signal)


# ========== 4. 组合管理模块 ==========

class Portfolio:
    """组合管理：持仓、资金、P&L"""

    def __init__(self, initial_capital: float):
        self.initial_capital = initial_capital
        self.cash = initial_capital
        self.positions: Dict[str, Position] = {}
        self.fills: List[Fill] = []
        self.equity_curve: List[dict] = []

    def on_fill(self, fill: Fill):
        """处理成交回报"""
        self.fills.append(fill)
        pos = self.positions.setdefault(fill.symbol, Position(symbol=fill.symbol))

        if fill.side == OrderSide.BUY:
            # 买入：更新均价，扣减资金
            total_cost = pos.avg_price * pos.quantity + fill.price * fill.quantity
            pos.quantity += fill.quantity
            pos.avg_price = total_cost / pos.quantity if pos.quantity > 0 else 0
            self.cash -= fill.price * fill.quantity + fill.commission
        else:
            # 卖出：计算已实现盈亏
            pnl = (fill.price - pos.avg_price) * fill.quantity
            pos.realized_pnl += pnl
            pos.quantity -= fill.quantity
            self.cash += fill.price * fill.quantity - fill.commission

        # 记录权益曲线
        total_equity = self.cash + sum(
            p.quantity * p.avg_price for p in self.positions.values() if p.quantity > 0
        )
        self.equity_curve.append({
            'timestamp': fill.timestamp,
            'equity': total_equity,
            'cash': self.cash
        })

    def update_unrealized(self, prices: Dict[str, float]):
        """更新未实现盈亏"""
        for symbol, pos in self.positions.items():
            if symbol in prices and pos.quantity > 0:
                pos.unrealized_pnl = (prices[symbol] - pos.avg_price) * pos.quantity

    def get_total_equity(self, prices: Dict[str, float]) -> float:
        """计算总权益"""
        self.update_unrealized(prices)
        positions_value = sum(
            p.quantity * prices.get(p.symbol, p.avg_price)
            for p in self.positions.values() if p.quantity > 0
        )
        return self.cash + positions_value


# ========== 5. 执行模块 ==========

class Executor:
    """执行模块：模拟成交，计算滑点和手续费"""

    def __init__(self, commission_rate: float = 0.0003, slippage_rate: float = 0.001):
        self.commission_rate = commission_rate  # 手续费率
        self.slippage_rate = slippage_rate       # 滑点率
        self.latest_prices: Dict[str, float] = {}

    def update_price(self, bar: Bar):
        """更新最新价格"""
        self.latest_prices[bar.symbol] = bar.close

    def execute(self, order: Order) -> Optional[Fill]:
        """执行订单，返回成交回报"""
        if order.symbol not in self.latest_prices:
            return None

        base_price = self.latest_prices[order.symbol]

        # 计算滑点
        if order.side == OrderSide.BUY:
            exec_price = base_price * (1 + self.slippage_rate)
        else:
            exec_price = base_price * (1 - self.slippage_rate)

        # 计算手续费（A 股：佣金 + 印花税卖出时收）
        trade_value = exec_price * order.quantity
        commission = trade_value * self.commission_rate
        if order.side == OrderSide.SELL:
            commission += trade_value * 0.001  # 印花税 0.1%

        return Fill(
            symbol=order.symbol,
            timestamp=order.timestamp,
            side=order.side,
            quantity=order.quantity,
            price=exec_price,
            commission=commission,
            slippage=abs(exec_price - base_price),
            order_id=order.order_id
        )


# ========== 6. 回测引擎 ==========

class BacktestEngine:
    """事件驱动回测引擎"""

    def __init__(self, initial_capital: float = 1_000_000,
                 commission_rate: float = 0.0003,
                 slippage_rate: float = 0.001):
        self.portfolio = Portfolio(initial_capital)
        self.executor = Executor(commission_rate, slippage_rate)
        self.strategies: List[Strategy] = []
        self.data_feeds: Dict[str, pd.DataFrame] = {}
        self.price_history: Dict[str, List[float]] = defaultdict(list)
        self._order_counter = 0

    def add_strategy(self, strategy: Strategy):
        """添加策略"""
        strategy.engine = self
        self.strategies.append(strategy)

    def get_history(self, symbol: str, n: int) -> pd.DataFrame:
        """获取最近 n 根 K 线"""
        history = self.price_history.get(symbol, [])
        if len(history) < n:
            return pd.DataFrame()
        return pd.DataFrame({'close': history[-n:]})

    def process_signal(self, signal: Signal):
        """处理交易信号 → 转为订单 → 执行"""
        if signal.direction == 0:
            return

        current_price = self.executor.latest_prices.get(signal.symbol)
        if current_price is None:
            return

        # 计算可买数量（A 股 100 股整数倍）
        if signal.direction > 0:
            max_shares = int(self.portfolio.cash * 0.95 / current_price / 100) * 100
            quantity = max(int(max_shares * signal.strength / 100) * 100, 0)
            side = OrderSide.BUY
        else:
            pos = self.portfolio.positions.get(signal.symbol)
            quantity = pos.quantity if pos else 0
            side = OrderSide.SELL

        if quantity <= 0:
            return

        self._order_counter += 1
        order = Order(
            symbol=signal.symbol,
            timestamp=signal.timestamp,
            side=side,
            quantity=quantity,
            order_id=f"ORD_{self._order_counter:06d}"
        )

        fill = self.executor.execute(order)
        if fill:
            self.portfolio.on_fill(fill)
            for strategy in self.strategies:
                strategy.on_fill(fill)

    def run(self, data_dict: Dict[str, pd.DataFrame]) -> pd.DataFrame:
        """运行回测"""
        self.data_feeds = data_dict
        feed = DataFeed(data_dict)

        # 初始化策略
        for strategy in self.strategies:
            strategy.on_init()

        # 遍历每根 K 线
        for bar in feed:
            # 更新价格
            self.executor.update_price(bar)
            self.price_history[bar.symbol].append(bar.close)

            # 通知策略
            for strategy in self.strategies:
                strategy.on_bar(bar)

        # 生成回测报告
        return self._generate_report()

    def _generate_report(self) -> pd.DataFrame:
        """生成回测报告"""
        if not self.portfolio.equity_curve:
            return pd.DataFrame()

        equity_df = pd.DataFrame(self.portfolio.equity_curve)
        equity_df['return'] = equity_df['equity'].pct_change()

        total_return = equity_df['equity'].iloc[-1] / self.portfolio.initial_capital - 1
        n_days = len(equity_df)
        annual_return = (1 + total_return) ** (252 / max(n_days, 1)) - 1
        sharpe = (equity_df['return'].mean() / equity_df['return'].std() * np.sqrt(252)
                  if equity_df['return'].std() > 0 else 0)
        max_dd = self._calc_max_drawdown(equity_df['equity'].values)
        total_commission = sum(f.commission for f in self.portfolio.fills)

        print("=" * 60)
        print("回测报告")
        print("=" * 60)
        print(f"初始资金:     {self.portfolio.initial_capital:>15,.2f}")
        print(f"最终权益:     {equity_df['equity'].iloc[-1]:>15,.2f}")
        print(f"总收益率:     {total_return:>14.2%}")
        print(f"年化收益率:   {annual_return:>14.2%}")
        print(f"夏普比率:     {sharpe:>15.3f}")
        print(f"最大回撤:     {max_dd:>14.2%}")
        print(f"总手续费:     {total_commission:>15,.2f}")
        print(f"交易次数:     {len(self.portfolio.fills):>15d}")
        print("=" * 60)

        return equity_df

    @staticmethod
    def _calc_max_drawdown(equity: np.ndarray) -> float:
        """计算最大回撤"""
        peak = np.maximum.accumulate(equity)
        drawdown = (equity - peak) / peak
        return float(np.min(drawdown))


# ========== 7. 策略示例：双均线策略 ==========

class DualMovingAverageStrategy(Strategy):
    """双均线交叉策略"""

    def __init__(self, symbol: str, fast_period: int = 5, slow_period: int = 20):
        super().__init__()
        self.symbol = symbol
        self.fast_period = fast_period
        self.slow_period = slow_period
        self.position_held = False

    def on_bar(self, bar: Bar):
        if bar.symbol != self.symbol:
            return

        history = self.get_historical(self.symbol, self.slow_period + 1)
        if len(history) < self.slow_period + 1:
            return

        fast_ma = history['close'].iloc[-self.fast_period:].mean()
        slow_ma = history['close'].iloc[-self.slow_period:].mean()
        prev_fast = history['close'].iloc[-self.fast_period - 1:-1].mean()
        prev_slow = history['close'].iloc[-self.slow_period - 1:-1].mean()

        # 金叉买入
        if fast_ma > slow_ma and prev_fast <= prev_slow and not self.position_held:
            self.submit_signal(Signal(
                symbol=self.symbol,
                timestamp=bar.timestamp,
                direction=1,
                reason="金叉买入"
            ))
            self.position_held = True

        # 死叉卖出
        elif fast_ma < slow_ma and prev_fast >= prev_slow and self.position_held:
            self.submit_signal(Signal(
                symbol=self.symbol,
                timestamp=bar.timestamp,
                direction=-1,
                reason="死叉卖出"
            ))
            self.position_held = False


# ========== 8. 运行回测 ==========

def run_demo():
    """运行回测演示"""
    np.random.seed(42)

    # 生成模拟行情数据
    def generate_ohlcv(n_days: int, trend: float = 0.0003) -> pd.DataFrame:
        returns = np.random.normal(trend, 0.02, n_days)
        close = 100 * np.cumprod(1 + returns)
        high = close * (1 + np.abs(np.random.normal(0, 0.005, n_days)))
        low = close * (1 - np.abs(np.random.normal(0, 0.005, n_days)))
        open_price = close * (1 + np.random.normal(0, 0.003, n_days))
        volume = np.random.randint(1_000_000, 10_000_000, n_days).astype(float)
        dates = pd.date_range('2022-01-01', periods=n_days, freq='B')
        return pd.DataFrame({
            'open': open_price, 'high': high, 'low': low,
            'close': close, 'volume': volume
        }, index=dates)

    data = {
        'SH.600000': generate_ohlcv(500, 0.0004),
        'SH.600036': generate_ohlcv(500, 0.0002),
    }

    # 创建引擎并运行
    engine = BacktestEngine(initial_capital=1_000_000, commission_rate=0.0003, slippage_rate=0.001)
    engine.add_strategy(DualMovingAverageStrategy('SH.600000', fast_period=5, slow_period=20))
    engine.add_strategy(DualMovingAverageStrategy('SH.600036', fast_period=10, slow_period=30))

    equity_df = engine.run(data)

    # 输出权益曲线统计
    if not equity_df.empty:
        print(f"\n权益曲线数据点: {len(equity_df)}")
        print(f"最终现金: {engine.portfolio.cash:,.2f}")
        for symbol, pos in engine.portfolio.positions.items():
            print(f"  {symbol}: 持仓 {pos.quantity} 股, 已实现盈亏 {pos.realized_pnl:,.2f}")

    return engine, equity_df

engine, equity = run_demo()
```

## 常见误区

### 误区一：回测引擎只是"遍历 K 线算收益"

很多初学者认为回测就是 `for bar in data: if signal: record_profit()`。这种写法忽略了订单管理、资金约束、多标的同步等关键问题。当策略变复杂时（多标的、止损止盈、加减仓），代码会变得无法维护。

### 误区二：用收盘价成交

回测中假设"信号触发时以收盘价成交"在实盘中无法实现。信号通常在收盘前几秒才触发，但你不可能以收盘价买入。正确做法是用下一根 K 线的开盘价成交，或者加入滑点模型。

### 误区三：忽略手续费和滑点

A 股的交易成本包括：佣金（约万三）、印花税（卖出千一）、过户费（沪市十万分之一）。加上滑点，一次完整买卖的成本约 0.3%-0.5%。对于高频策略，成本可能占总收益的 30% 以上。

### 误区四：向量化回测可以替代事件驱动回测

向量化回测适合因子研究和大规模策略筛选（速度快），但不适合需要精确模拟执行的场景。正确的做法是：**先用向量化回测快速筛选，再用事件驱动回测严格验证**。

## 小结与练习

### 小结

1. 向量化回测适合快速筛选，事件驱动回测适合严格验证，两者互补而非替代
2. 事件驱动引擎由数据模块、信号模块、风控模块、执行模块、组合模块五个核心组件构成
3. 时间管理是回测引擎的核心——必须确保每个决策只使用当时可用的信息
4. 手续费和滑点必须在回测中完整模拟，否则回测结果不可信
5. 用下一根 K 线开盘价成交比用收盘价成交更接近实盘

## 参考答案

### 练习一

**思路**：在 `execute` 方法中，判断订单类型。对于限价单，比较当前价格与限价。

**答案**：

```python
def execute(self, order: Order, current_bar: Optional[Bar] = None) -> Optional[Fill]:
    if order.symbol not in self.latest_prices:
        return None

    base_price = self.latest_prices[order.symbol]

    if order.order_type == OrderType.LIMIT:
        # 限价单：买入时价格必须 <= 限价，卖出时价格必须 >= 限价
        if order.side == OrderSide.BUY and base_price > order.limit_price:
            return None  # 未触及限价
        if order.side == OrderSide.SELL and base_price < order.limit_price:
            return None
        exec_price = order.limit_price  # 以限价成交
    else:
        # 市价单：加滑点
        if order.side == OrderSide.BUY:
            exec_price = base_price * (1 + self.slippage_rate)
        else:
            exec_price = base_price * (1 - self.slippage_rate)

    trade_value = exec_price * order.quantity
    commission = trade_value * self.commission_rate
    if order.side == OrderSide.SELL:
        commission += trade_value * 0.001

    return Fill(
        symbol=order.symbol,
        timestamp=order.timestamp,
        side=order.side,
        quantity=order.quantity,
        price=exec_price,
        commission=commission,
        slippage=abs(exec_price - base_price),
        order_id=order.order_id
    )
```

**要点**：
- 限价单不需要滑点模型，因为价格已经由交易者指定
- 实盘中限价单可能部分成交，这里做了简化处理

### 练习二

**思路**：用分段函数计算佣金，并设置最低佣金。

**答案**：

```python
def _calc_commission(self, trade_value: float, side: OrderSide) -> float:
    """阶梯式佣金计算"""
    if trade_value < 50_000:
        rate = 0.0003      # 万三
    elif trade_value < 500_000:
        rate = 0.00025     # 万二点五
    else:
        rate = 0.0002      # 万二

    commission = max(trade_value * rate, 5.0)  # 最低 5 元

    if side == OrderSide.SELL:
        commission += trade_value * 0.001  # 印花税

    return commission
```

**要点**：
- 最低佣金 5 元是券商的实际规定，小额交易的相对成本会更高
- 这也解释了为什么量化策略倾向于减少交易频率——每次交易都有固定成本
