# 05 止损策略：不止损一夜回到解放前，频繁止损也会被割韭菜

> 止损是交易的"安全气囊"。但气囊弹出时机不对，本身也会造成伤害。如何设置止损，是量化交易中最需要"手感"的环节。

---

## 场景引入

2015 年 6 月，A 股从 5178 点暴跌。一个持有创业板股票的交易者，如果在下跌 5% 时止损，损失 5%。如果坚持不止损，到最低点时亏损超过 70%——需要涨 230% 才能回本。

但反过来，2019 年的一个震荡市中，另一个交易者用 3% 的固定止损，一个月内被止损 12 次，每次亏损 3% 加两次交易成本。累计亏损超过 40%，而那只股票最终涨了 30%。

**止损太宽，可能致命。止损太紧，可能被千刀万剐。** 这节课我们系统学习止损策略的设计与优化。

## 核心概念

### 一、止损的本质

止损的核心作用是**限制单次交易的最大亏损**。但止损同时也在做一件事：**截断盈利的可能性**。

```
止损的两面性：

  设止损                              不设止损
  ┌──────────────────┐                ┌──────────────────┐
  │ ✓ 限制单次亏损    │                │ ✗ 单次可能巨亏    │
  │ ✓ 保护总资金      │                │ ✓ 不会误伤盈利    │
  │ ✗ 可能频繁触发    │                │ ✗ 一次黑天鹅归零  │
  │ ✗ 增加交易成本    │                │                  │
  └──────────────────┘                └──────────────────┘

  关键：止损不是"要不要设"的问题，而是"怎么设"的问题
```

```
五种止损策略触发条件示意：

  时间轴 ──────────────────────────────────────────────►

  价格走势：
       B
      ╱╲        D
     ╱  ╲      ╱╲      F
    ╱    ╲    ╱  ╲    ╱
   ╱      ╲  ╱    ╲  ╱

  ├──────────┼──────┼────────────────────────────────┤
  │ 固定止损  │  C   │ 价格跌破 入场价 × (1-固定比例)  │
  │ 跟踪止损  │  E   │ 价格从最高点回落 固定比例       │

  └──────────┴──────┴────────────────────────────────┘
```

### 三、固定止损

固定止损是最简单的方法——当价格跌破买入价的固定百分比时卖出。

```
固定止损示意：

  价格
   │
   │    买入
   │     ●───╮
   │         │    盈利
   │         │   ╱
   │         │  ╱
   │         │ ╱
   │         ╰●─── 止损线（买入价 × 0.95）
   │          ↑
   │        触发止损
   └────────────────────→ 时间

  止损比例 vs 交易频率：
  ┌─────────────┬──────────────┬────────────────┐
  │  止损比例     │ 触发频率      │ 影响            │
  ├─────────────┼──────────────┼────────────────┤
  │  2%          │ 很高         │ 频繁止损，成本高  │
  │  5%          │ 适中         │ 平衡止损与持仓   │
  │  10%         │ 较低         │ 单次亏损较大     │
  │  20%         │ 很低         │ 几乎等于不止损   │
  └─────────────┴──────────────┴────────────────┘
```

### 四、跟踪止损（Trailing Stop）

跟踪止损的止损线随着价格上涨而上移，但不会随价格下跌而下移。它锁定了部分利润。

```
跟踪止损示意：

  价格
   │                    B
   │                   ╱╲
   │                  ╱  ╲    D
   │                 ╱    ╲  ╱
   │          A     ╱      ╲╱
   │         ╱╲   ╱         ↑
   │        ╱  ╲ ╱       触发止损
   │       ╱    C         
   │      ╱     ↑         
   │     ╱    止损线上移到C
   │    ╱               
   └────────────────────────→ 时间

  跟踪止损的优势：
  1. 上涨时锁定利润（止损线跟随上移）
  2. 下跌时限制亏损（止损线不下降）
  3. 自动适应趋势——趋势越强，锁定的利润越多
```

### 五、波动率止损（ATR 止损）

波动率止损根据市场波动率动态调整止损距离。用 ATR（Average True Range）作为波动率的度量。

```
ATR 止损原理：

  ATR = 平均真实波幅 = mean(TR₁, TR₂, ..., TRₙ)
  TR = max(High-Low, |High-PrevClose|, |Low-PrevClose|)

  止损距离 = ATR × 倍数（通常 2-3 倍）

  波动率高时 → ATR 大 → 止损距离宽 → 避免被正常波动止损
  波动率低时 → ATR 小 → 止损距离窄 → 快速止盈止损

  ┌─────────────────────────────────────────────────┐
  │  价格        止损线                               │
  │   │    ──────                                    │
  │   │   ╱      ╲                                   │
  │   │  ╱        ╲──────                            │
  │   │ ╱                ╲                           │
  │   │╱                  ╲──────                    │
  │   └────────────────────────────→ 时间            │
  │                                                  │
  │   ATR 止损线 = 当前价格 - N × ATR                 │
  │   ATR 增大时，止损线下降更快                       │
  │   ATR 减小时，止损线更接近价格                     │
  └─────────────────────────────────────────────────┘
```

### 六、时间止损

时间止损不看价格，看时间。如果持仓超过一定时间仍未盈利，就平仓离场。

```
时间止损示意：

  场景 1：持仓后价格快速上涨
  价格   ╱‾‾‾‾‾
        ╱
  入场 ●──────→ 3天内盈利，不触发时间止损
  ──────────────→ 时间
       │← 3天 →│

  场景 2：持仓后价格横盘
  价格   ──────────────
  入场 ●──────────────→ 10天仍无盈利，触发时间止损
  ──────────────────────→ 时间
       │←──── 10天 ────→│

  适用场景：
  - 趋势策略：趋势启动后应快速盈利，横盘说明判断错误
  - 事件驱动策略：事件影响有时间窗口，超时说明市场已消化
  - 资金效率：释放被"冻住"的资金投入更好的机会
```

### 七、信号止损

信号止损基于策略信号的反转来平仓。不看绝对价格，看策略逻辑是否仍然成立。

```
信号止损示意：

  均线策略示例：

  价格 │      快线
  　   │     ╱╲    快线
  　   │    ╱  ╲  ╱╲
  　   │   ╱    ╲╱  ╲
  　   │  ╱      慢线  ╲
  　   │ ╱              ╲
  　   └────────────────────→ 时间
  　        ↑    ↑
  　       买入  死叉→信号止损

  信号止损 vs 价格止损：
  ┌────────────┬────────────────────┬────────────────────┐
  │  对比维度   │  价格止损           │  信号止损           │
  ├────────────┼────────────────────┼────────────────────┤
  │  触发条件   │  价格跌破阈值       │  策略信号反转       │
  │  灵敏度     │  固定，不适应市场   │  随策略逻辑变化     │
  │  适用场景   │  所有策略           │  趋势/动量策略      │
  │  优点       │  简单明确           │  与策略逻辑一致     │
  │  缺点       │  可能与策略冲突     │  依赖策略质量       │
  └────────────┴────────────────────┴────────────────────┘
```

### 八、止损对策略表现的影响

止损不仅仅是"少亏"，它会系统性地改变策略的收益分布。

```
止损对策略指标的影响机制：

  无止损时的收益分布：
  频率
   │  ██
   │  ████
   │  ██████
   │  ████████
   │  ██████████
   │  ████████████      ██  ← 少数大亏损拉低整体表现
   │  ██████████████  ████
   └────────────────────────→ 收益
     -30%  -10%  0%  +10%  +30%

  有止损时的收益分布：
  频率
   │    ██
   │    ████
   │    ██████
   │    ████████
   │  ██████████
   │  ████████████
   │  ██████████████████  ← 大亏损被截断
   └────────────────────────→ 收益
     -5%  -10%  0%  +10%  +30%

  影响总结：
  ┌──────────────┬──────────────┬──────────────┐
  │  指标         │  无止损       │  有止损       │
  ├──────────────┼──────────────┼──────────────┤
  │  总收益       │  可能很高     │  通常略低     │
  │  胜率         │  较高         │  降低         │
  │  盈亏比       │  差（大亏损） │  改善         │
  │  最大回撤     │  可能巨大     │  显著减小     │
  │  夏普比率     │  较低         │  通常更高     │
  └──────────────┴──────────────┴──────────────┘
```

### 九、止损参数优化的陷阱

止损参数不能在回测中"选最优"——这会导致过拟合。

```
止损参数优化的正确思路：

  ❌ 错误：测试 2%、3%、4%、...、20%，选回测收益最高的
  → 这是数据挖掘，选出的参数在实盘中大概率失效

  ✅ 正确：
  1. 根据策略特征选择合理范围
     - 趋势策略：宽止损（1.5-3 倍 ATR）
     - 均值回归策略：窄止损（0.5-1.5 倍 ATR）

  2. 根据持仓周期选择
     - 日内交易：1-2 倍 ATR
     - 波段交易：2-3 倍 ATR
     - 中长线：3-5 倍 ATR

  3. 基于历史波动率动态计算
     - 止损距离 = f(ATR, 历史波动率分位数)
     - 高波动率时期自动放宽止损
     - 低波动率时期自动收紧止损

  4. 在合理范围内，选择稳健的参数
     - 参数微调后表现稳定的区间
     - 不同市场环境下都可接受的参数
```

### 十、动态止损策略

动态止损综合多种信号，根据市场状态自动切换止损方式。

```
动态止损决策树：

  当前持仓中
     │
     ├── 持仓时间 > 阈值 且 未盈利？
     │      └── 是 → 时间止损
     │
     ├── 策略信号反转？
     │      └── 是 → 信号止损
     │
     ├── 价格跌破 ATR 止损线？
     │      └── 是 → ATR 止损
     │
     ├── 价格从最高点回落超过阈值？
     │      └── 是 → 跟踪止损
     │
     └── 以上均未触发 → 继续持仓

  优先级：信号止损 > 时间止损 > ATR止损 > 跟踪止损
  原因：信号止损与策略逻辑最一致，优先级最高
```

### 一、ATR 计算与止损基类

```python
"""
止损策略实现
包含固定止损、跟踪止损、ATR 止损、时间止损、信号止损、动态止损
"""

import numpy as np
import pandas as pd
from typing import Optional


def calculate_atr(high: pd.Series, low: pd.Series, close: pd.Series,
                  period: int = 14) -> pd.Series:
    """计算 ATR（平均真实波幅）"""
    prev_close = close.shift(1)
    tr = pd.concat([
        high - low,
        (high - prev_close).abs(),
        (low - prev_close).abs()
    ], axis=1).max(axis=1)
    atr = tr.rolling(period).mean()
    return atr


class StopLossStrategy:
    """止损策略基类"""

    def __init__(self):
        self.entry_price: Optional[float] = None
        self.stop_price: Optional[float] = None

    def on_entry(self, price: float):
        """入场时调用"""
        self.entry_price = price
        self._update_stop(price)

    def on_bar(self, price: float) -> bool:
        """每根 K 线调用，返回是否触发止损"""
        if self.entry_price is None:
            return False
        self._update_stop(price)
        return price <= self.stop_price

    def _update_stop(self, price: float):
        """更新止损价（子类实现）"""
        pass

    def reset(self):
        """重置"""
        self.entry_price = None
        self.stop_price = None
```

### 二、五种止损策略实现

```python
class FixedStopLoss(StopLossStrategy):
    """固定百分比止损"""

    def __init__(self, stop_pct: float = 0.05):
        super().__init__()
        self.stop_pct = stop_pct

    def _update_stop(self, price: float):
        if self.entry_price is not None:
            self.stop_price = self.entry_price * (1 - self.stop_pct)


class TrailingStopLoss(StopLossStrategy):
    """跟踪止损：止损线只升不降"""

    def __init__(self, trail_pct: float = 0.05):
        super().__init__()
        self.trail_pct = trail_pct
        self.highest_price: Optional[float] = None

    def on_entry(self, price: float):
        super().on_entry(price)
        self.highest_price = price

    def _update_stop(self, price: float):
        if price > (self.highest_price or 0):
            self.highest_price = price
            self.stop_price = self.highest_price * (1 - self.trail_pct)

    def reset(self):
        super().reset()
        self.highest_price = None


class ATRStopLoss(StopLossStrategy):
    """ATR 波动率止损：根据市场波动率动态调整止损距离"""

    def __init__(self, atr_multiple: float = 2.0):
        super().__init__()
        self.atr_multiple = atr_multiple
        self.current_atr: Optional[float] = None

    def set_atr(self, atr_value: float):
        self.current_atr = atr_value

    def on_entry(self, price: float):
        super().on_entry(price)
        if self.current_atr is not None:
            self.stop_price = price - self.atr_multiple * self.current_atr

    def _update_stop(self, price: float):
        pass  # ATR 止损只在入场时设定


class TimeStopLoss(StopLossStrategy):
    """时间止损：持仓超过 N 根 K 线仍未盈利则平仓"""

    def __init__(self, max_holding_bars: int = 10):
        super().__init__()
        self.max_holding_bars = max_holding_bars
        self.bars_held: int = 0

    def on_entry(self, price: float):
        super().on_entry(price)
        self.bars_held = 0

    def on_bar(self, price: float) -> bool:
        if self.entry_price is None:
            return False
        self.bars_held += 1
        # 超过最大持仓时间且未盈利
        if self.bars_held >= self.max_holding_bars and price <= self.entry_price:
            return True
        return False

    def reset(self):
        super().reset()
        self.bars_held = 0


class SignalStopLoss(StopLossStrategy):
    """信号止损：基于策略信号反转平仓"""

    def __init__(self, fast_period: int = 10, slow_period: int = 30):
        super().__init__()
        self.fast_period = fast_period
        self.slow_period = slow_period
        self.price_history: list = []

    def on_entry(self, price: float):
        super().on_entry(price)

    def on_bar(self, price: float, signal_long: bool = True) -> bool:
        """检查信号是否反转

        Args:
            price: 当前价格
            signal_long: 当前策略是否仍看多
        """
        if self.entry_price is None:
            return False
        # 信号反转 = 策略不再看多
        return not signal_long

    def reset(self):
        super().reset()
        self.price_history = []
```

### 三、复合止损与动态止损

```python
class CompositeStopLoss(StopLossStrategy):
    """复合止损：任一条件触发即止损"""

    def __init__(self, strategies: list):
        super().__init__()
        self.strategies = strategies

    def on_entry(self, price: float):
        super().on_entry(price)
        for s in self.strategies:
            s.on_entry(price)

    def on_bar(self, price: float, **kwargs) -> bool:
        if self.entry_price is None:
            return False
        for s in self.strategies:
            if isinstance(s, SignalStopLoss):
                if s.on_bar(price, kwargs.get('signal_long', True)):
                    return True
            elif isinstance(s, TimeStopLoss):
                if s.on_bar(price):
                    return True
            else:
                if s.on_bar(price):
                    return True
        return False

    def reset(self):
        super().reset()
        for s in self.strategies:
            s.reset()


class DynamicStopLoss(StopLossStrategy):
    """动态止损：根据市场状态自动选择止损方式"""

    def __init__(self, atr_multiple: float = 2.0, trail_pct: float = 0.08,
                 max_holding_bars: int = 15, atr_period: int = 14):
        super().__init__()
        self.atr_multiple = atr_multiple
        self.trail_pct = trail_pct
        self.max_holding_bars = max_holding_bars
        self.current_atr: Optional[float] = None
        self.highest_price: Optional[float] = None
        self.bars_held: int = 0
        self.stop_reason: str = ""

    def set_atr(self, atr_value: float):
        self.current_atr = atr_value

    def on_entry(self, price: float):
        super().on_entry(price)
        self.highest_price = price
        self.bars_held = 0
        self.stop_reason = ""
        if self.current_atr is not None:
            self.stop_price = price - self.atr_multiple * self.current_atr

    def on_bar(self, price: float, signal_long: bool = True) -> bool:
        if self.entry_price is None:
            return False

        self.bars_held += 1

        # 优先级 1：信号止损
        if not signal_long:
            self.stop_reason = "信号反转"
            return True

        # 优先级 2：时间止损
        if self.bars_held >= self.max_holding_bars and price <= self.entry_price:
            self.stop_reason = "时间止损"
            return True

        # 优先级 3：跟踪止损（更新最高价）
        if price > (self.highest_price or 0):
            self.highest_price = price
            trailing_stop = self.highest_price * (1 - self.trail_pct)
            # 跟踪止损线不能低于 ATR 止损线
            if self.stop_price is None or trailing_stop > self.stop_price:
                self.stop_price = trailing_stop

        # 检查是否触发止损
        if self.stop_price is not None and price <= self.stop_price:
            self.stop_reason = "ATR/跟踪止损"
            return True

        return False

    def reset(self):
        super().reset()
        self.highest_price = None
        self.bars_held = 0
        self.current_atr = None
        self.stop_reason = ""
```

### 四、回测对比所有止损策略

```python
def backtest_stop_loss_methods():
    """回测比较不同止损方法"""
    np.random.seed(42)

    # 生成模拟行情
    n_days = 500
```

### 五、基于历史波动率的止损参数选择

```python
def select_stop_params_by_volatility(prices: pd.Series,
                                      lookback: int = 60) -> dict:
    """基于历史波动率选择止损参数

    核心思想：波动率高时放宽止损，波动率低时收紧止损
    """
    returns = prices.pct_change().dropna()

    # 计算历史波动率分位数
    rolling_vol = returns.rolling(lookback).std() * np.sqrt(252)
    current_vol = rolling_vol.iloc[-1]
    vol_percentile = (rolling_vol < current_vol).mean()

    # 根据波动率分位数选择参数
    if vol_percentile > 0.8:
        # 高波动环境：宽止损
        stop_pct = 0.10
        atr_mult = 3.0
        trail_pct = 0.10
        env_label = "高波动"
    elif vol_percentile > 0.5:
        # 中等波动
        stop_pct = 0.07
        atr_mult = 2.5
        trail_pct = 0.08
        env_label = "中等波动"
    else:
        # 低波动环境：窄止损
        stop_pct = 0.05
        atr_mult = 2.0
        trail_pct = 0.05
        env_label = "低波动"

    return {
        '环境': env_label,
        '当前波动率': current_vol,
        '波动率分位': vol_percentile,
        '固定止损': stop_pct,
        'ATR倍数': atr_mult,
        '跟踪止损': trail_pct,
    }
```

## 常见误区

### 误区一：止损设得太紧

止损设得太紧（如 2%），会被正常的市场波动频繁触发。每次止损都意味着一次亏损 + 两次交易成本。结果是"千刀万剐"——小亏损累积成大亏损。

**正确做法**：止损距离应大于市场正常波动幅度。用 ATR 作为参考，通常 2-3 倍 ATR 是合理起点。

### 误区二：止损设得太宽

止损设得太宽（如 20%），等于没有止损。单次亏损 20% 意味着需要涨 25% 才能回本。止损的意义在于控制单次亏损在可接受范围内。

**正确做法**：单次止损亏损不应超过总资金的 2-3%。

### 误区三：止损后立即反手

止损触发后立即反手做多/做空，是情绪化交易的表现。正确做法是止损后观望，等待新的入场信号。

### 误区四：所有策略用同一种止损

趋势策略适合宽止损（让利润奔跑），均值回归策略适合窄止损（快速截断亏损）。止损必须与策略逻辑匹配。

### 误区五：忽略止损对交易频率的影响

设置止损后，策略的交易频率可能显著增加（止损触发后重新入场）。高频交易意味着更高的交易成本，这部分成本必须计入回测。

## 小结与练习

### 小结

1. 五种止损方法各有适用场景：固定止损简单、跟踪止损锁定利润、ATR 止损适应波动率、时间止损提升资金效率、信号止损与策略逻辑一致
2. 止损通常降低胜率但改善盈亏比和最大回撤
3. 动态止损综合多种条件，是最接近实战的止损方式
4. 止损参数不能在回测中选最优——应该根据策略特征和持仓周期选择合理范围
5. 基于历史波动率动态调整止损参数，比固定参数更稳健

> **风险提示**：本课内容仅供教学，不构成投资建议。止损不能保证避免亏损，极端行情下可能出现跳空止损。

### 练习一

**思路**：组合 ATR 止损和时间止损，任一触发即执行。

**答案**：

```python
class ATRTimeCompositeStop(StopLossStrategy):
    """复合止损：ATR + 时间"""

    def __init__(self, atr_multiple: float = 2.0, max_bars: int = 15):
        super().__init__()
        self.atr_multiple = atr_multiple
        self.max_bars = max_bars
        self.current_atr: float = 0
        self.bars_held: int = 0

    def set_atr(self, atr_value: float):
        self.current_atr = atr_value

    def on_entry(self, price: float):
        self.entry_price = price
        self.bars_held = 0
        if self.current_atr > 0:
            self.stop_price = price - self.atr_multiple * self.current_atr

    def on_bar(self, price: float) -> bool:
        if self.entry_price is None:
            return False
        self.bars_held += 1

        # 条件 1：ATR 止损
        atr_triggered = (self.stop_price is not None and price <= self.stop_price)

        # 条件 2：时间止损（超过最大持仓时间且未盈利）
        time_triggered = (self.bars_held >= self.max_bars and price <= self.entry_price)

        return atr_triggered or time_triggered

    def reset(self):
        super().reset()
        self.bars_held = 0

# 测试
```

**要点**：
- ATR 止损捕获大幅下跌，时间止损捕获横盘消耗
- 两者互补：ATR 管"跌多少"，时间管"等多久"

```python
def stop_loss_sensitivity_analysis():
    """止损参数敏感性分析"""
    np.random.seed(42)
    n_days = 500
    dates = pd.date_range('2023-01-01', periods=n_days, freq='B')
    returns = np.random.normal(0.0003, 0.02, n_days)
    close = pd.Series(100 * np.cumprod(1 + returns), index=dates)
    high = close * (1 + np.abs(np.random.normal(0, 0.005, n_days)))
    low = close * (1 - np.abs(np.random.normal(0, 0.005, n_days)))
    atr = calculate_atr(high, low, close)

    ma_20 = close.rolling(20).mean()
    ma_60 = close.rolling(60).mean()
    signal = (ma_20 > ma_60).shift(1).fillna(0)

    atr_multiples = np.arange(1.0, 4.5, 0.5)

    print("ATR 倍数敏感性分析:")
    print(f"{'ATR倍数':>8} {'总收益':>10} {'夏普':>8} {'最大回撤':>10} {'胜率':>8}")
    print("-" * 50)

    for mult in atr_multiples:
        cash = 1_000_000
        shares = 0
        in_pos = False
        equity = []
        trades = []

        for i in range(60, n_days):
            p = close.iloc[i]
            if not in_pos and signal.iloc[i] == 1:
                shares = int(cash * 0.95 / p / 100) * 100
                if shares > 0:
                    cash -= shares * p
                    in_pos = True
                    entry = p
                    stop = ATRStopLoss(atr_multiple=mult)
                    if not np.isnan(atr.iloc[i]):
                        stop.set_atr(atr.iloc[i])
                    stop.on_entry(p)
            elif in_pos:
                stop_hit = stop.on_bar(p)
                exit_sig = ma_20.iloc[i] < ma_60.iloc[i]
                if stop_hit or exit_sig:
                    cash += shares * p
                    trades.append((p - entry) / entry)
                    shares = 0
                    in_pos = False
            equity.append(cash + shares * p)

        eq = pd.Series(equity, index=dates[60:])
        ret = eq.iloc[-1] / 1_000_000 - 1
        daily_ret = eq.pct_change().dropna()
        sr = daily_ret.mean() / daily_ret.std() * np.sqrt(252) if daily_ret.std() > 0 else 0
        dd = ((eq - eq.cummax()) / eq.cummax()).min()
        wr = sum(1 for t in trades if t > 0) / len(trades) if trades else 0

        print(f"{mult:>8.1f} {ret:>10.2%} {sr:>8.3f} {dd:>10.2%} {wr:>8.1%}")

    print("\n观察：参数在 2.0-3.0 之间通常表现较稳定（稳健区间）")

stop_loss_sensitivity_analysis()
```

**要点**：
- 如果参数从 2.0 变到 2.5 收益变化剧烈，说明策略对参数敏感（过拟合风险）
- 稳健区间：参数微调后表现变化平缓的区域
- 优先选择稳健区间的中值，而非收益最高的点
