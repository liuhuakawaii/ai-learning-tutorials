# 回测陷阱

> 回测年化 200%，实盘亏光——这不是段子，是量化交易最常见的事故。问题几乎总是出在回测陷阱上。

---

## 场景引入

小王用 Python 写了一个均线突破策略的回测，结果非常好：年化 45%，夏普 2.8，最大回撤 15%。他兴奋地把代码发到量化社区，一位前辈只看了 10 分钟就指出了三个致命问题：

1. 用当天收盘价生成信号，但假设以当天收盘价成交（前视偏差）
2. 用全 A 股数据回测，但没有剔除已退市的股票（生存者偏差）
3. 尝试了 30 组参数，选了最好的那组报告（过拟合）

这三个问题中任何一个，都足以让回测结果完全不可信。本课将系统讲解回测中最常见的陷阱，以及工程化的规避方法。

## 核心概念

### 一、前视偏差的七种来源

前视偏差（Look-Ahead Bias）是回测中最致命的错误。它指的是在回测中使用了在实际交易时不可能获得的信息。

```
前视偏差的七种来源：

  ┌─────────────────────────────────────────────────────────────┐
  │  1. 信号时间错位                                             │
  │     用 T 日数据生成信号，以 T 日价格成交                       │
  │     正确：用 T-1 日数据生成信号，以 T+1 开盘价成交             │
  ├─────────────────────────────────────────────────────────────┤
  │  2. 数据标准化泄露                                           │
  │     用全部数据（含未来）做 StandardScaler.fit                  │
  │     正确：只用训练集 fit，transform 测试集                     │
  ├─────────────────────────────────────────────────────────────┤
  │  3. 特征选择泄露                                             │
  │     用全部数据做特征选择，再交叉验证                            │
  │     正确：在每个 CV fold 内部做特征选择                        │
  ├─────────────────────────────────────────────────────────────┤
  │  4. 使用未来发布的信息                                        │
  │     用当天的财报数据做决策（实际要收盘后才发布）                 │
  │     正确：财报数据延后 1 天使用                                │
  ├─────────────────────────────────────────────────────────────┤
  │  5. 复权因子使用不当                                          │
  │     用当天的复权因子计算历史价格                               │
  │     正确：用当时的复权因子，或统一用前复权                      │
  ├─────────────────────────────────────────────────────────────┤
  │  6. 指数成分股泄露                                           │
  │     用今天的沪深 300 成分股回测历史                            │
  │     正确：用当时的成分股（需要历史成分股数据）                  │
  ├─────────────────────────────────────────────────────────────┤
  │  7. 参数优化泄露                                             │
  │     在全部数据上优化参数，再在同一样本上报告结果                 │
  │     正确：训练集优化参数，测试集验证                           │
  └─────────────────────────────────────────────────────────────┘
```

### 二、生存者偏差

生存者偏差（Survivorship Bias）是指回测只包含当前存在的股票，忽略了已退市、被合并、被摘牌的股票。

```
生存者偏差的影响：

  回测用的数据集：
  ┌──────────────────────────────────────┐
  │  2020 年上市的 4000 只股票             │
  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
  │  │ 好公司│ │ 好公司│ │ 好公司│ │ 好公司│   │
  │  └─────┘ └─────┘ └─────┘ └─────┘   │
  │  （已经活到 2025 年的股票）             │
  └──────────────────────────────────────┘

  实际 2020 年的数据应该包含：
  ┌──────────────────────────────────────┐
  │  2020 年上市的 4500 只股票             │
  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐   │
  │  │ 好公司│ │ 好公司│ │ 好公司│ │ 好公司│   │
  │  └─────┘ └─────┘ └─────┘ └─────┘   │
  │  ┌─────┐ ┌─────┐ ┌─────┐            │
  │  │ 退市 │ │ 退市 │ │ 退市 │            │
  │  └─────┘ └─────┘ └─────┘            │
  │  （包括已退市的 500 只股票）            │
  └──────────────────────────────────────┘

  影响：好公司被保留，差公司被遗漏 → 回测收益偏高
  量化影响：年化收益可能虚高 2-5 个百分点
```

### 三、过拟合与多重检验

当你尝试了足够多的策略变体，总能找到一个在历史上表现优异的。但这不代表它未来有效。

```
过拟合的检测流程：

  ┌──────────────────────────────────────┐
  │  Step 1: 数据分割                      │
  │  ┌────────────┬──────────┬──────────┐ │
  │  │ 训练集      │ 验证集    │ 测试集   │ │
  │  │ 2015-2019  │ 2020-2021│ 2022-2024│ │
  │  └────────────┴──────────┴──────────┘ │
  │  训练集优化参数，验证集选择模型，       │
  │  测试集只用一次                        │
  ├──────────────────────────────────────┤
  │  Step 2: Walk-Forward Analysis        │
  │  ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐     │
  │  │T1│T2│T3│T4│T5│T6│T7│T8│T9│T10│    │
  │  └──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘     │
  │  滚动窗口：训练 → 验证 → 训练 → 验证   │
  │  每个窗口都做样本外测试                │
  ├──────────────────────────────────────┤
  │  Step 3: Deflated Sharpe Ratio        │
  │  考虑尝试了多少个策略变体，             │
  │  对夏普比率做多重检验修正               │
  └──────────────────────────────────────┘
```

### 一、前视偏差检测器

```python
"""
前视偏差检测工具
检查回测代码中常见的前视偏差模式
"""

import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import accuracy_score


def demonstrate_signal_timing_bias():
    """演示信号时间错位导致的前视偏差"""
    np.random.seed(42)
    n_days = 500

    # 生成随机价格
    returns = np.random.normal(0, 0.02, n_days)
    close = 100 * np.cumprod(1 + returns)
    dates = pd.date_range('2022-01-01', periods=n_days, freq='B')
    df = pd.DataFrame({'close': close, 'return': returns}, index=dates)

    # 计算技术指标
    df['ma_20'] = df['close'].rolling(20).mean()
    df['ma_60'] = df['close'].rolling(60).mean()
    df = df.dropna()

    # ---- 错误做法：用当天数据生成信号，当天成交 ----
    df['signal_wrong'] = (df['ma_20'] > df['ma_60']).astype(int)
    df['strategy_return_wrong'] = df['signal_wrong'] * df['return']

    # ---- 正确做法：用前一天数据生成信号，当天成交 ----
    df['signal_correct'] = (df['ma_20'].shift(1) > df['ma_60'].shift(1)).astype(int)
    df['strategy_return_correct'] = df['signal_correct'] * df['return']

    cum_wrong = (1 + df['strategy_return_wrong']).cumprod()
    cum_correct = (1 + df['strategy_return_correct']).cumprod()
    cum_buyhold = (1 + df['return']).cumprod()

    print("=" * 60)
    print("信号时间错位偏差演示")
    print("=" * 60)
    print(f"有偏差回测总收益:     {(cum_wrong.iloc[-1] - 1):>10.2%}")
    print(f"正确回测总收益:       {(cum_correct.iloc[-1] - 1):>10.2%}")
    print(f"买入持有总收益:       {(cum_buyhold.iloc[-1] - 1):>10.2%}")
    print(f"虚假超额收益:         {(cum_wrong.iloc[-1] - cum_correct.iloc[-1]):>10.2%}")
    print("\n结论：信号时间错位会制造虚假的超额收益")


def demonstrate_scaling_bias():
    """演示数据标准化导致的前视偏差"""
    np.random.seed(42)
    n_samples = 1000
    n_features = 20

    X = np.random.randn(n_samples, n_features)
    y = (X[:, 0] * 0.1 + X[:, 1] * 0.05 + np.random.normal(0, 1, n_samples) > 0).astype(int)

    split_idx = 700
    X_train, X_test = X[:split_idx], X[split_idx:]
    y_train, y_test = y[:split_idx], y[split_idx:]

    # ---- 错误做法：用全部数据 fit ----
    scaler_wrong = StandardScaler()
    X_scaled_wrong = scaler_wrong.fit_transform(X)  # 用了未来数据
    X_train_w = X_scaled_wrong[:split_idx]
    X_test_w = X_scaled_wrong[split_idx:]

    model_w = RandomForestClassifier(n_estimators=100, random_state=42)
    model_w.fit(X_train_w, y_train)
    acc_wrong = accuracy_score(y_test, model_w.predict(X_test_w))

    # ---- 正确做法：只用训练集 fit ----
    scaler_correct = StandardScaler()
    X_train_c = scaler_correct.fit_transform(X_train)
    X_test_c = scaler_correct.transform(X_test)

    model_c = RandomForestClassifier(n_estimators=100, random_state=42)
    model_c.fit(X_train_c, y_train)
    acc_correct = accuracy_score(y_test, model_c.predict(X_test_c))

    print("\n" + "=" * 60)
    print("数据标准化偏差演示")
    print("=" * 60)
    print(f"有偏差准确率:   {acc_wrong:.4f}")
    print(f"正确准确率:     {acc_correct:.4f}")
    print(f"差异:           {acc_wrong - acc_correct:.4f}")
    print("结论：标准化偏差的影响取决于数据分布差异")


def demonstrate_survivorship_bias():
    """演示生存者偏差的影响"""
    np.random.seed(42)
    n_stocks = 200
    n_days = 500

    # 生成所有股票的收益（包括"退市"的）
    all_returns = np.random.normal(0.0002, 0.025, (n_days, n_stocks))

    # 模拟 20% 的股票"退市"（表现差的更容易退市）
    cumulative = np.cumprod(1 + all_returns, axis=0)
    final_values = cumulative[-1, :]
    survival_threshold = np.percentile(final_values, 20)
    survived = final_values > survival_threshold

    # 有生存者偏差的回测（只用存活股票）
    returns_with_bias = all_returns[:, survived]
    portfolio_with_bias = returns_with_bias.mean(axis=1)

    # 无生存者偏差的回测（用全部股票）
    portfolio_without_bias = all_returns.mean(axis=1)

    cum_with = np.cumprod(1 + portfolio_with_bias)
    cum_without = np.cumprod(1 + portfolio_without_bias)

    print("\n" + "=" * 60)
    print("生存者偏差演示")
    print("=" * 60)
    print(f"有偏差回测年化收益:   {(cum_with[-1]**(252/n_days) - 1):.2%}")
    print(f"无偏差回测年化收益:   {(cum_without[-1]**(252/n_days) - 1):.2%}")
    print(f"存活股票比例:         {survived.mean():.1%}")
    print(f"虚假年化超额:         {((cum_with[-1]**(252/n_days)) - (cum_without[-1]**(252/n_days))):.2%}")
    print("结论：生存者偏差使回测收益偏高 2-5 个百分点")


# 运行演示
demonstrate_signal_timing_bias()
demonstrate_scaling_bias()
demonstrate_survivorship_bias()
```

### 二、Walk-Forward Analysis

```python
"""
Walk-Forward Analysis
滚动窗口回测，避免过拟合
"""

import numpy as np
import pandas as pd
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import accuracy_score, classification_report


def walk_forward_analysis():
    """Walk-Forward Analysis 实现"""
    np.random.seed(42)

    # 生成模拟数据（带时变特征）
    n_days = 1000
    dates = pd.date_range('2020-01-01', periods=n_days, freq='B')

    # 特征：5 个技术指标
    features = np.random.randn(n_days, 5)

    # 标签：与特征有微弱关系（模拟真实情况）
    regime = np.sin(np.arange(n_days) / 100)  # 市场状态切换
    label_prob = 0.5 + 0.1 * (features[:, 0] * 0.3 + features[:, 1] * 0.2 + regime * 0.1)
    label_prob = np.clip(label_prob, 0, 1)
    labels = (np.random.random(n_days) < label_prob).astype(int)

    df = pd.DataFrame(features, columns=[f'f{i}' for i in range(5)], index=dates)
    df['label'] = labels

    # Walk-Forward 配置
    train_window = 300  # 训练窗口
    test_window = 60    # 测试窗口
    step_size = 60      # 滚动步长

    results = []
    feature_importances = []

    start = train_window
    while start + test_window <= n_days:
        # 训练集
        train_data = df.iloc[start - train_window:start]
        X_train = train_data.drop('label', axis=1)
        y_train = train_data['label']

        # 测试集
        test_data = df.iloc[start:start + test_window]
        X_test = test_data.drop('label', axis=1)
        y_test = test_data['label']

        # 训练模型
        model = GradientBoostingClassifier(
            n_estimators=50, max_depth=3, random_state=42
        )
        model.fit(X_train, y_train)

        # 样本外预测
        predictions = model.predict(X_test)
        acc = accuracy_score(y_test, predictions)

        results.append({
            'train_start': dates[start - train_window],
            'train_end': dates[start - 1],
            'test_start': dates[start],
            'test_end': dates[min(start + test_window - 1, n_days - 1)],
            'accuracy': acc,
            'n_train': len(X_train),
            'n_test': len(X_test)
        })

        feature_importances.append(model.feature_importances_)
        start += step_size

    results_df = pd.DataFrame(results)
    importances_df = pd.DataFrame(
        feature_importances,
        columns=[f'f{i}' for i in range(5)]
    )

    print("=" * 60)
    print("Walk-Forward Analysis 结果")
    print("=" * 60)
    print(f"\n滚动窗口数: {len(results_df)}")
    print(f"平均样本外准确率: {results_df['accuracy'].mean():.4f}")
    print(f"准确率标准差: {results_df['accuracy'].std():.4f}")
    print(f"最低准确率: {results_df['accuracy'].min():.4f}")
    print(f"最高准确率: {results_df['accuracy'].max():.4f}")

    print("\n各窗口准确率:")
    for _, row in results_df.iterrows():
        status = "PASS" if row['accuracy'] > 0.52 else "FAIL"
        print(f"  {row['test_start'].strftime('%Y-%m')} ~ {row['test_end'].strftime('%Y-%m')}: "
              f"{row['accuracy']:.4f} [{status}]")

    print("\n特征重要性稳定性（标准差）:")
    for col in importances_df.columns:
        print(f"  {col}: {importances_df[col].mean():.4f} ± {importances_df[col].std():.4f}")

    # 过拟合检测
    consistent_windows = (results_df['accuracy'] > 0.52).mean()
    print(f"\n过拟合检测:")
    print(f"  准确率 > 52% 的窗口比例: {consistent_windows:.1%}")
    if consistent_windows > 0.7:
        print("  结论：策略在大部分时间段有效，可信度较高")
    elif consistent_windows > 0.5:
        print("  结论：策略有效性不稳定，需要进一步研究")
    else:
        print("  结论：策略很可能是过拟合的")

    return results_df

wfa_results = walk_forward_analysis()
```

## 常见误区

### 误区一：只报告最好的参数组合

你尝试了 50 组均线参数，选了夏普比率最高的那组来报告。这本质上是 p-hacking。正确做法是报告所有参数的分布，或者用 Walk-Forward Analysis 验证。

### 误区二：用全 A 股回测却不提生存者偏差

很多免费数据源（如 AKShare 的股票列表）只包含当前上市的股票。用这种数据回测历史，相当于提前知道了哪些公司会活下来。

### 误区三：认为"回测越长越好"

超长回测（如 20 年）可能跨越了多个市场机制变化（如 2015 年涨跌停规则改变、注册制改革）。不同时期的数据可能不具可比性。

### 误区四：忽略数据窥探效应

每次你看一眼测试集的结果，就在无形中做了数据窥探。即使你没有修改代码，你的大脑也在根据测试集的结果做决策。测试集应该只用一次。

## 小结与练习

### 小结

1. 前视偏差有七种常见来源，信号时间错位和数据标准化泄露是最常见的两种
2. 生存者偏差使回测收益偏高 2-5 个百分点，必须使用包含退市股票的数据
3. Walk-Forward Analysis 是检测过拟合的金标准——滚动窗口训练+样本外验证
4. 回测结果必须通过自检清单才有可信度

### 练习二

**思路**：用 Walk-Forward Analysis 框架对均线策略做滚动回测。

**答案**：

```python
import numpy as np
import pandas as pd

def wfa_ma_strategy():
    """Walk-Forward Analysis 对均线策略"""
    np.random.seed(42)
    n_days = 1000
    returns = np.random.normal(0.0002, 0.02, n_days)
    close = 100 * np.cumprod(1 + returns)
    dates = pd.date_range('2020-01-01', periods=n_days, freq='B')
    df = pd.DataFrame({'close': close, 'return': returns}, index=dates)

    # 在训练集上选择最优均线参数
    train_window = 300
    test_window = 60
    param_candidates = [5, 10, 20, 30, 50]

    results = []
    start = train_window

    while start + test_window <= n_days:
        train_data = df.iloc[start - train_window:start]

        # 在训练集上测试各参数
        best_sharpe = -999
        best_param = param_candidates[0]

        for fast in param_candidates:
            for slow in param_candidates:
                if fast >= slow:
                    continue
                signal = (train_data['close'].rolling(fast).mean() >
                         train_data['close'].rolling(slow).mean()).shift(1).astype(int)
                ret = signal * train_data['return']
                sharpe = ret.mean() / ret.std() * np.sqrt(252) if ret.std() > 0 else 0
                if sharpe > best_sharpe:
                    best_sharpe = sharpe
                    best_param = (fast, slow)

        # 在测试集上用最优参数
        test_data = df.iloc[start:start + test_window]
        combined = df.iloc[start - best_param[1]:start + test_window]

        fast_ma = combined['close'].rolling(best_param[0]).mean()
        slow_ma = combined['close'].rolling(best_param[1]).mean()
        signal = (fast_ma > slow_ma).shift(1).astype(int)

        test_signal = signal.iloc[-test_window:]
        test_return = test_signal * test_data['return']

        test_sharpe = test_return.mean() / test_return.std() * np.sqrt(252) if test_return.std() > 0 else 0
        test_total = (1 + test_return).prod() - 1

        results.append({
            'test_start': dates[start],
            'best_params': best_param,
            'train_sharpe': best_sharpe,
            'test_sharpe': test_sharpe,
            'test_return': test_total
        })
        start += test_window

    results_df = pd.DataFrame(results)

    print("=" * 60)
    print("均线策略 Walk-Forward Analysis")
    print("=" * 60)
    for _, row in results_df.iterrows():
        print(f"  {row['test_start'].strftime('%Y-%m')}: "
              f"参数{row['best_params']} "
              f"训练SR={row['train_sharpe']:.2f} "
              f"测试SR={row['test_sharpe']:.2f} "
              f"测试收益={row['test_return']:.2%}")

    print(f"\n平均样本外夏普: {results_df['test_sharpe'].mean():.3f}")
    print(f"样本外正收益窗口: {(results_df['test_return'] > 0).mean():.1%}")

wfa_ma_strategy()
```

**要点**：
- 每个窗口独立选择最优参数，模拟真实的策略迭代过程
- 如果训练集表现好但测试集表现差，说明策略过拟合
