# 策略迭代

> 策略上线后表现越来越差，不是因为市场变了，而是因为你没有一套系统化的方法来检测衰减、验证改进、安全部署。

---

## 场景引入

你的双均线策略上线三个月了。第一个月赚了 5%，第二个月赚了 2%，第三个月亏了 3%。你开始怀疑：是市场环境变了？还是策略本身失效了？

你决定调整参数，把短期均线从 5 日改成 3 日。在历史数据上回测，新参数的夏普比率从 1.2 提升到了 1.8。你高兴地上线了新参数，结果接下来一周又亏了 2%。

问题出在哪里？你在历史数据上优化参数，但你没有验证新参数在**当前市场环境**下是否依然有效。你也没有安全地切换策略——直接全量替换，新策略不行了又全量回滚，来回折腾。

这就是策略迭代要解决的问题：如何科学地检测衰减、验证改进、安全部署。

---

## 核心概念

### 一、策略衰减检测

策略衰减是量化交易的常态。市场在变，参与者在变，策略的边际收益必然递减。关键不是阻止衰减，而是**及时发现衰减**。

```
策略衰减的三种模式：

  收益
   ↑
   │  ╭──────╮
   │ ╱        ╲          阶梯式衰减
   │╱          ╲─────────  （市场结构突变）
   └──────────────────→ 时间

   │  ╭─────────────
   │ ╱                 渐进式衰减
   │╱                  （参与者增多，alpha 被稀释）
   └──────────────────→

   │  ╭──╮  ╭──╮
   │ ╱    ╲╱    ╲       周期性波动
   │╱                  （策略有适用/不适用的市场环境）
   └──────────────────→
```

核心检测指标：

| 指标 | 计算方式 | 衰减信号 |
|------|---------|---------|
| 滚动夏普比率 | 60 日滚动窗口的夏普 | 连续下降超过 30% |
| IC 衰减 | 信号与收益的相关系数 | IC < 0.02 持续 5 天 |
| 最大回撤 | 峰值到谷值的最大跌幅 | 超过历史 95 分位 |
| 胜率变化 | 滚动窗口的盈利交易占比 | 下降超过 10 个百分点 |
| 盈亏比变化 | 平均盈利 / 平均亏损 | 下降超过 20% |

### 二、A/B 测试框架

```
策略 A/B 测试架构：

  ┌──────────────────────────────────────────────────────┐
  │                    资金分配器                          │
  │  ┌────────────┐              ┌────────────┐          │
  │  │  策略 A     │              │  策略 B     │          │
  │  │  （旧参数）  │              │  （新参数）  │          │
  │  │  70% 资金   │              │  30% 资金   │          │
  │  └─────┬──────┘              └─────┬──────┘          │
  │        │                           │                 │
  │        ▼                           ▼                 │
  │  ┌──────────┐              ┌──────────┐              │
  │  │ 执行引擎A │              │ 执行引擎B │              │
  │  └─────┬────┘              └─────┬────┘              │
  │        │                           │                 │
  │        └───────────┬───────────────┘                 │
  │                    ▼                                  │
  │            ┌──────────────┐                          │
  │            │  绩效对比器   │                          │
  │            │  统计显著性   │                          │
  │            └──────┬───────┘                          │
  │                   ▼                                   │
  │            ┌──────────────┐                          │
  │            │  决策引擎     │                          │
  │            │  切换/保留/回滚│                          │
  │            └──────────────┘                          │
  └──────────────────────────────────────────────────────┘

  决策规则：
  - 运行至少 20 个交易日
  - 新策略夏普 > 旧策略夏普 + 0.3（统计显著）
  - 新策略最大回撤 < 旧策略最大回撤
  - 满足以上条件 → 逐步提高新策略资金比例
```

```
参数优化方法对比：

  ┌─────────────┬──────────────────┬──────────────────┐
  │  方法        │  优点             │  缺点             │
  ├─────────────┼──────────────────┼──────────────────┤
  │  网格搜索    │  简单、可并行      │  维度灾难、慢      │

  └─────────────┴──────────────────┴──────────────────┘

  推荐：参数维度 ≤ 3 用网格搜索，> 3 用贝叶斯优化
  关键：必须用 walk-forward 验证，不能用全样本回测
```

### 一、策略衰减检测系统

```python
"""
策略衰减检测系统

依赖：pip install numpy pandas
"""

import numpy as np
import pandas as pd
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import Dict, List, Optional, Tuple
from enum import Enum


class DecaySignal(Enum):
    NONE = "none"
    SHARPE_DECAY = "sharpe_decay"
    IC_DECAY = "ic_decay"
    DRAWDOWN_EXCEED = "drawdown_exceed"
    WINRATE_DECLINE = "winrate_decline"
    PNL_RATIO_DECLINE = "pnl_ratio_decline"


@dataclass
class DecayAlert:
    signal: DecaySignal
    severity: str  # "warning" or "critical"
    message: str
    current_value: float
    threshold: float
    timestamp: datetime = field(default_factory=datetime.now)


class StrategyDecayDetector:
    """策略衰减检测器"""

    def __init__(
        self,
        sharpe_window: int = 60,
        sharpe_decline_pct: float = 0.3,
        ic_window: int = 20,
        ic_threshold: float = 0.02,
        ic_persistent_days: int = 5,
        drawdown_quantile: float = 0.95,
        winrate_window: int = 30,
        winrate_decline: float = 0.10,
        pnl_ratio_window: int = 30,
        pnl_ratio_decline: float = 0.20,
    ):
        self.sharpe_window = sharpe_window
        self.sharpe_decline_pct = sharpe_decline_pct
        self.ic_window = ic_window
        self.ic_threshold = ic_threshold
        self.ic_persistent_days = ic_persistent_days
        self.drawdown_quantile = drawdown_quantile
        self.winrate_window = winrate_window
        self.winrate_decline = winrate_decline
        self.pnl_ratio_window = pnl_ratio_window
        self.pnl_ratio_decline = pnl_ratio_decline

        self.returns_history: List[float] = []
        self.ic_history: List[float] = []
        self.trade_results: List[float] = []
        self.sharpe_history: List[float] = []
        self.alerts: List[DecayAlert] = []

    def add_return(self, ret: float):
        """添加每日收益"""
        self.returns_history.append(ret)
        self._check_sharpe_decay()
        self._check_drawdown()

    def add_ic(self, ic: float):
        """添加每日 IC 值"""
        self.ic_history.append(ic)
        self._check_ic_decay()

    def add_trade_result(self, pnl: float):
        """添加每笔交易结果"""
        self.trade_results.append(pnl)
        self._check_winrate_decline()
        self._check_pnl_ratio_decline()

    def _check_sharpe_decay(self):
        if len(self.returns_history) < self.sharpe_window * 2:
            return

        returns = np.array(self.returns_history)
        current_sharpe = self._calc_sharpe(returns[-self.sharpe_window:])
        historical_sharpe = self._calc_sharpe(returns[:-self.sharpe_window])

        self.sharpe_history.append(current_sharpe)

        if historical_sharpe > 0:
            decline = (historical_sharpe - current_sharpe) / historical_sharpe
            if decline > self.sharpe_decline_pct:
                self.alerts.append(DecayAlert(
                    signal=DecaySignal.SHARPE_DECAY,
                    severity="warning" if decline < 0.5 else "critical",
                    message=f"滚动夏普从 {historical_sharpe:.2f} 下降到 {current_sharpe:.2f}",
                    current_value=current_sharpe,
                    threshold=historical_sharpe * (1 - self.sharpe_decline_pct),
                ))

    def _check_ic_decay(self):
        if len(self.ic_history) < self.ic_persistent_days:
            return

        recent_ic = self.ic_history[-self.ic_persistent_days:]
        if all(ic < self.ic_threshold for ic in recent_ic):
            self.alerts.append(DecayAlert(
                signal=DecaySignal.IC_DECAY,
                severity="critical",
                message=f"IC 连续 {self.ic_persistent_days} 天低于 {self.ic_threshold}",
                current_value=np.mean(recent_ic),
                threshold=self.ic_threshold,
            ))

    def _check_drawdown(self):
        if len(self.returns_history) < 60:
            return

        equity = np.cumprod(1 + np.array(self.returns_history))
        running_max = np.maximum.accumulate(equity)
        drawdowns = (equity - running_max) / running_max

        current_dd = drawdowns[-1]
        historical_dd = drawdowns[:-1]
        threshold = np.percentile(np.abs(historical_dd), self.drawdown_quantile * 100)

        if abs(current_dd) > threshold:
            self.alerts.append(DecayAlert(
                signal=DecaySignal.DRAWDOWN_EXCEED,
                severity="critical",
                message=f"当前回撤 {current_dd:.2%} 超过历史 {self.drawdown_quantile:.0%} 分位",
                current_value=abs(current_dd),
                threshold=threshold,
            ))

    def _check_winrate_decline(self):
        if len(self.trade_results) < self.winrate_window * 2:
            return

        trades = np.array(self.trade_results)
        current_wr = np.mean(trades[-self.winrate_window:] > 0)
        historical_wr = np.mean(trades[:-self.winrate_window] > 0)

        if historical_wr - current_wr > self.winrate_decline:
            self.alerts.append(DecayAlert(
                signal=DecaySignal.WINRATE_DECLINE,
                severity="warning",
                message=f"胜率从 {historical_wr:.1%} 下降到 {current_wr:.1%}",
                current_value=current_wr,
                threshold=historical_wr - self.winrate_decline,
            ))

    def _check_pnl_ratio_decline(self):
        if len(self.trade_results) < self.pnl_ratio_window * 2:
            return

        trades = np.array(self.trade_results)
        recent = trades[-self.pnl_ratio_window:]
        historical = trades[:-self.pnl_ratio_window]

        recent_wins = recent[recent > 0]
        recent_losses = recent[recent < 0]
        hist_wins = historical[historical > 0]
        hist_losses = historical[historical < 0]

        if len(recent_wins) == 0 or len(recent_losses) == 0:
            return
        if len(hist_wins) == 0 or len(hist_losses) == 0:
            return

        current_ratio = np.mean(recent_wins) / abs(np.mean(recent_losses))
        hist_ratio = np.mean(hist_wins) / abs(np.mean(hist_losses))

        if hist_ratio > 0:
            decline = (hist_ratio - current_ratio) / hist_ratio
            if decline > self.pnl_ratio_decline:
                self.alerts.append(DecayAlert(
                    signal=DecaySignal.PNL_RATIO_DECLINE,
                    severity="warning",
                    message=f"盈亏比从 {hist_ratio:.2f} 下降到 {current_ratio:.2f}",
                    current_value=current_ratio,
                    threshold=hist_ratio * (1 - self.pnl_ratio_decline),
                ))

    def _calc_sharpe(self, returns: np.ndarray, risk_free: float = 0.0) -> float:
        if len(returns) < 2:
            return 0.0
        excess = returns - risk_free / 252
        if np.std(excess) == 0:
            return 0.0
        return np.mean(excess) / np.std(excess) * np.sqrt(252)

    def get_report(self) -> dict:
        """生成衰减检测报告"""
        return {
            "total_returns": len(self.returns_history),
            "total_trades": len(self.trade_results),
            "current_sharpe": self.sharpe_history[-1] if self.sharpe_history else None,
            "recent_ic": self.ic_history[-1] if self.ic_history else None,
            "active_alerts": len([a for a in self.alerts if a.severity == "critical"]),
            "warning_alerts": len([a for a in self.alerts if a.severity == "warning"]),
            "alerts": [
                {
                    "signal": a.signal.value,
                    "severity": a.severity,
                    "message": a.message,
                    "timestamp": a.timestamp.isoformat(),
                }
                for a in self.alerts[-10:]
            ],
        }

    def get_收益归因(self, returns: pd.Series,
                     factors: pd.DataFrame) -> Dict[str, float]:
        """收益归因分析（简化版 Barra 归因）"""
        from numpy.linalg import lstsq

        X = factors.values
        y = returns.values
        X_with_const = np.column_stack([np.ones(len(X)), X])
        coeffs, _, _, _ = lstsq(X_with_const, y, rcond=None)

        attribution = {"alpha": coeffs[0]}
        for i, col in enumerate(factors.columns):
            attribution[col] = coeffs[i + 1]
        return attribution
```

### 二、A/B 测试框架

```python
"""
策略 A/B 测试框架

支持并行运行新旧策略、统计显著性检验、自动决策
"""

import numpy as np
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import Callable, Dict, List, Optional
from enum import Enum
import json
from pathlib import Path


class ABTestDecision(Enum):
    CONTINUE = "continue"
    PROMOTE_NEW = "promote_new"
    KEEP_OLD = "keep_old"
    ROLLBACK = "rollback"


@dataclass
class StrategyPerformance:
    """策略绩效记录"""
    strategy_name: str
    daily_returns: List[float] = field(default_factory=list)
    trade_count: int = 0
    win_count: int = 0
    total_pnl: float = 0.0
    max_drawdown: float = 0.0
    start_time: datetime = field(default_factory=datetime.now)

    @property
    def sharpe(self) -> float:
        if len(self.daily_returns) < 2:
            return 0.0
        returns = np.array(self.daily_returns)
        if np.std(returns) == 0:
            return 0.0
        return np.mean(returns) / np.std(returns) * np.sqrt(252)

    @property
    def win_rate(self) -> float:
        if self.trade_count == 0:
            return 0.0
        return self.win_count / self.trade_count

    @property
    def avg_pnl_per_trade(self) -> float:
        if self.trade_count == 0:
            return 0.0
        return self.total_pnl / self.trade_count

    def to_dict(self) -> dict:
        return {
            "strategy_name": self.strategy_name,
            "sharpe": round(self.sharpe, 4),
            "win_rate": round(self.win_rate, 4),
            "trade_count": self.trade_count,
            "total_pnl": round(self.total_pnl, 2),
            "max_drawdown": round(self.max_drawdown, 4),
            "avg_pnl_per_trade": round(self.avg_pnl_per_trade, 2),
            "days_running": (datetime.now() - self.start_time).days,
        }


@dataclass
class ABTestConfig:
    """A/B 测试配置"""
    test_name: str
    old_strategy_name: str
    new_strategy_name: str
    old_weight: float = 0.7
    new_weight: float = 0.3
    min_trading_days: int = 20
    min_trades_per_strategy: int = 50
    sharpe_improvement_threshold: float = 0.3
    max_drawdown_tolerance: float = 0.05
    significance_level: float = 0.05


class ABTestManager:
    """A/B 测试管理器"""

    def __init__(self, config: ABTestConfig):
        self.config = config
        self.old_perf = StrategyPerformance(strategy_name=config.old_strategy_name)
        self.new_perf = StrategyPerformance(strategy_name=config.new_strategy_name)
        self.decisions: List[dict] = []
        self._running = False

    def record_daily_return(self, strategy: str, ret: float):
        """记录每日收益"""
        if strategy == self.config.old_strategy_name:
            self.old_perf.daily_returns.append(ret)
        elif strategy == self.config.new_strategy_name:
            self.new_perf.daily_returns.append(ret)

    def record_trade(self, strategy: str, pnl: float):
        """记录交易结果"""
        perf = (self.old_perf if strategy == self.config.old_strategy_name
                else self.new_perf)
        perf.trade_count += 1
        perf.total_pnl += pnl
        if pnl > 0:
            perf.win_count += 1

    def evaluate(self) -> ABTestDecision:
        """评估当前状态，做出决策"""
        old = self.old_perf
        new = self.new_perf
        cfg = self.config

        days = (datetime.now() - old.start_time).days
        if days < cfg.min_trading_days:
            return ABTestDecision.CONTINUE
        if old.trade_count < cfg.min_trades_per_strategy:
            return ABTestDecision.CONTINUE
        if new.trade_count < cfg.min_trades_per_strategy:
            return ABTestDecision.CONTINUE

        sharpe_improved = new.sharpe - old.sharpe
        t_stat, p_value = self._welch_t_test(
            old.daily_returns, new.daily_returns
        )

        decision_record = {
            "timestamp": datetime.now().isoformat(),
            "old_sharpe": round(old.sharpe, 4),
            "new_sharpe": round(new.sharpe, 4),
            "sharpe_diff": round(sharpe_improved, 4),
            "p_value": round(p_value, 4),
            "old_drawdown": round(old.max_drawdown, 4),
            "new_drawdown": round(new.max_drawdown, 4),
        }

        if sharpe_improved > cfg.sharpe_improvement_threshold:
            if p_value < cfg.significance_level:
                if abs(new.max_drawdown) < cfg.max_drawdown_tolerance:
                    decision_record["decision"] = "promote_new"
                    self.decisions.append(decision_record)
                    return ABTestDecision.PROMOTE_NEW

        if sharpe_improved < -cfg.sharpe_improvement_threshold:
            if p_value < cfg.significance_level:
                decision_record["decision"] = "keep_old"
                self.decisions.append(decision_record)
                return ABTestDecision.KEEP_OLD

        if abs(new.max_drawdown) > cfg.max_drawdown_tolerance * 2:
            decision_record["decision"] = "rollback"
            self.decisions.append(decision_record)
            return ABTestDecision.ROLLBACK

        decision_record["decision"] = "continue"
        self.decisions.append(decision_record)
        return ABTestDecision.CONTINUE

    def _welch_t_test(self, old: list, new: list) -> tuple:
        """Welch's t 检验"""
        old_arr = np.array(old)
        new_arr = np.array(new)
        n1, n2 = len(old_arr), len(new_arr)
        m1, m2 = np.mean(old_arr), np.mean(new_arr)
        v1, v2 = np.var(old_arr, ddof=1), np.var(new_arr, ddof=1)

        se = np.sqrt(v1 / n1 + v2 / n2)
        if se == 0:
            return 0.0, 1.0

        t_stat = (m2 - m1) / se

        num = (v1 / n1 + v2 / n2) ** 2
        den = (v1 / n1) ** 2 / (n1 - 1) + (v2 / n2) ** 2 / (n2 - 1)
        df = num / den if den > 0 else 1

        from scipy import stats
        p_value = 2 * (1 - stats.t.cdf(abs(t_stat), df=df))
        return t_stat, p_value

    def get_report(self) -> dict:
        """生成测试报告"""
        return {
            "test_name": self.config.test_name,
            "old_strategy": self.old_perf.to_dict(),
            "new_strategy": self.new_perf.to_dict(),
            "decisions": self.decisions[-5:],
            "current_decision": self.evaluate().value,
        }

    def save_report(self, path: str = "./ab_test_reports"):
        """保存测试报告"""
        report_dir = Path(path)
        report_dir.mkdir(parents=True, exist_ok=True)
        filename = f"{self.config.test_name}_{datetime.now():%Y%m%d}.json"
        with open(report_dir / filename, "w", encoding="utf-8") as f:
            json.dump(self.get_report(), f, ensure_ascii=False, indent=2)
```

```python
"""
参数优化工具

支持网格搜索和贝叶斯优化
"""

import numpy as np
from itertools import product
from dataclasses import dataclass
from typing import Callable, Dict, List, Tuple, Optional
import json
from pathlib import Path


@dataclass
class ParamRange:
    """参数范围定义"""
    name: str
    min_val: float
    max_val: float
    step: float = 1.0
    param_type: str = "float"  # "float" or "int"


class GridSearchOptimizer:
    """网格搜索优化器"""

    def __init__(
        self,
        objective_fn: Callable[[dict], float],
        param_ranges: List[ParamRange],
        higher_is_better: bool = True,
    ):
        self.objective_fn = objective_fn
        self.param_ranges = param_ranges
        self.higher_is_better = higher_is_better
        self.results: List[dict] = []

    def optimize(self, verbose: bool = True) -> dict:
        """执行网格搜索"""
        grids = {}
        for pr in self.param_ranges:
            if pr.param_type == "int":
                grids[pr.name] = list(
                    range(int(pr.min_val), int(pr.max_val) + 1, int(pr.step))
                )
            else:
                grids[pr.name] = list(np.arange(pr.min_val, pr.max_val, pr.step))

        param_combinations = [
            dict(zip(grids.keys(), values))
            for values in product(*grids.values())
        ]

        best_score = float("-inf") if self.higher_is_better else float("inf")
        best_params = None

        for i, params in enumerate(param_combinations):
            try:
                score = self.objective_fn(params)
            except Exception as e:
                score = float("-inf") if self.higher_is_better else float("inf")

            self.results.append({"params": params, "score": score})

            if self.higher_is_better and score > best_score:
                best_score = score
                best_params = params
            elif not self.higher_is_better and score < best_score:
                best_score = score
                best_params = params

            if verbose and (i + 1) % 100 == 0:
                print(f"进度: {i + 1}/{len(param_combinations)}, 当前最优: {best_score:.4f}")

        return {"best_params": best_params, "best_score": best_score}


class BayesianOptimizer:
    """贝叶斯优化器（简化实现，使用高斯过程）"""

    def __init__(
        self,
        objective_fn: Callable[[dict], float],
        param_ranges: List[ParamRange],
        n_initial: int = 10,
        n_iterations: int = 50,
        higher_is_better: bool = True,
    ):
        self.objective_fn = objective_fn
        self.param_ranges = param_ranges
        self.n_initial = n_initial
        self.n_iterations = n_iterations
        self.higher_is_better = higher_is_better
        self.observed_params: List[np.ndarray] = []
        self.observed_scores: List[float] = []

    def optimize(self, verbose: bool = True) -> dict:
        """执行贝叶斯优化"""
        dim = len(self.param_ranges)
        bounds = np.array([
            [pr.min_val, pr.max_val] for pr in self.param_ranges
        ])

        for i in range(self.n_initial):
            params_vec = np.random.uniform(
                bounds[:, 0], bounds[:, 1]
            )
            score = self._evaluate(params_vec)
            if verbose and (i + 1) % 5 == 0:
                print(f"初始采样: {i + 1}/{self.n_initial}")

        for i in range(self.n_iterations):
            next_params = self._suggest_next(bounds)
            score = self._evaluate(next_params)

            if verbose and (i + 1) % 10 == 0:
                best = max(self.observed_scores) if self.higher_is_better \
                    else min(self.observed_scores)
                print(f"迭代: {i + 1}/{self.n_iterations}, 最优: {best:.4f}")

        best_idx = (
            np.argmax(self.observed_scores) if self.higher_is_better
            else np.argmin(self.observed_scores)
        )
        best_vec = self.observed_params[best_idx]
        best_params = {
            pr.name: (int(best_vec[j]) if pr.param_type == "int"
                      else round(best_vec[j], 4))
            for j, pr in enumerate(self.param_ranges)
        }

        return {
            "best_params": best_params,
            "best_score": self.observed_scores[best_idx],
            "total_evaluations": len(self.observed_scores),
        }

    def _evaluate(self, params_vec: np.ndarray) -> float:
        params_dict = {
            pr.name: (int(params_vec[i]) if pr.param_type == "int"
                      else float(params_vec[i]))
            for i, pr in enumerate(self.param_ranges)
        }
        try:
            score = self.objective_fn(params_dict)
        except Exception:
            score = float("-inf") if self.higher_is_better else float("inf")

        self.observed_params.append(params_vec.copy())
        self.observed_scores.append(score)
        return score

    def _suggest_next(self, bounds: np.ndarray) -> np.ndarray:
        """使用 UCB (Upper Confidence Bound) 采集函数"""
        if len(self.observed_params) < 2:
            return np.random.uniform(bounds[:, 0], bounds[:, 1])

        X = np.array(self.observed_params)
        y = np.array(self.observed_scores)

        best_x = X[np.argmax(y)] if self.higher_is_better else X[np.argmin(y)]

        exploration = np.random.uniform(
            bounds[:, 0], bounds[:, 1]
        )
        kappa = 2.0
        candidate = best_x + kappa * (exploration - best_x) * \
            np.random.uniform(0.1, 1.0, size=bounds.shape[0])
        candidate = np.clip(candidate, bounds[:, 0], bounds[:, 1])
        return candidate
```

### 四、灰度发布与回滚

```python
"""
策略灰度发布与回滚系统
"""

import json
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from pathlib import Path
from typing import Callable, Dict, List, Optional


class DeploymentStage(Enum):
    SHADOW = "shadow"         # 影子模式：只记录信号，不实际交易
    CANARY = "canary"         # 金丝雀：5% 资金
    GRAY_20 = "gray_20"       # 灰度 20%
    GRAY_50 = "gray_50"       # 灰度 50%
    FULL = "full"             # 全量部署


@dataclass
class StrategyVersion:
    """策略版本"""
    version: str
    params: dict
    created_at: datetime = field(default_factory=datetime.now)
    description: str = ""
    backtest_report: Optional[dict] = None


@dataclass
class DeploymentRecord:
    """部署记录"""
    version: str
    stage: DeploymentStage
    deployed_at: datetime = field(default_factory=datetime.now)
    rolled_back: bool = False
    rollback_reason: str = ""
    performance: dict = field(default_factory=dict)


class GrayReleaseManager:
    """灰度发布管理器"""

    STAGE_WEIGHTS = {
        DeploymentStage.SHADOW: 0.0,
        DeploymentStage.CANARY: 0.05,
        DeploymentStage.GRAY_20: 0.20,
        DeploymentStage.GRAY_50: 0.50,
        DeploymentStage.FULL: 1.0,
    }

    def __init__(self, versions_dir: str = "./strategy_versions"):
        self.versions: Dict[str, StrategyVersion] = {}
        self.deployments: List[DeploymentRecord] = []
        self.current_stage = DeploymentStage.SHADOW
        self.active_version: Optional[str] = None
        self.versions_dir = Path(versions_dir)
        self.versions_dir.mkdir(parents=True, exist_ok=True)

    def register_version(self, version: StrategyVersion):
        """注册新策略版本"""
        self.versions[version.version] = version
        self._save_version(version)

    def deploy(self, version: str, stage: DeploymentStage):
        """部署策略到指定阶段"""
        if version not in self.versions:
            raise ValueError(f"版本 {version} 未注册")

        self.active_version = version
        self.current_stage = stage
        record = DeploymentRecord(version=version, stage=stage)
        self.deployments.append(record)

    def rollback(self, reason: str):
        """回滚到上一个稳定版本"""
        if not self.deployments:
            return

        current = self.deployments[-1]
        current.rolled_back = True
        current.rollback_reason = reason

        stable_deployments = [
            d for d in self.deployments
            if not d.rolled_back and d.stage in (
                DeploymentStage.GRAY_50, DeploymentStage.FULL
            )
        ]
        if stable_deployments:
            prev = stable_deployments[-1]
            self.active_version = prev.version
            self.current_stage = prev.stage
        else:
            self.active_version = None
            self.current_stage = DeploymentStage.SHADOW

    def promote(self):
        """提升到下一阶段"""
        stages = list(DeploymentStage)
        current_idx = stages.index(self.current_stage)
        if current_idx < len(stages) - 1:
            next_stage = stages[current_idx + 1]
            self.deploy(self.active_version, next_stage)

    def get_new_strategy_weight(self) -> float:
        """获取新策略的资金权重"""
        return self.STAGE_WEIGHTS.get(self.current_stage, 0.0)

    def _save_version(self, version: StrategyVersion):
        filepath = self.versions_dir / f"{version.version}.json"
        data = {
            "version": version.version,
            "params": version.params,
            "created_at": version.created_at.isoformat(),
            "description": version.description,
            "backtest_report": version.backtest_report,
        }
        with open(filepath, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    def get_status(self) -> dict:
        return {
            "active_version": self.active_version,
            "current_stage": self.current_stage.value,
            "new_weight": self.get_new_strategy_weight(),
            "total_deployments": len(self.deployments),
            "rollback_count": sum(1 for d in self.deployments if d.rolled_back),
        }
```

```python
"""
实盘数据回流系统

将实盘交易数据回流到策略研发流程，形成闭环
"""

import json
from dataclasses import dataclass, field
from datetime import datetime
from pathlib import Path
from typing import Dict, List, Optional
import csv


@dataclass
class LiveTradeRecord:
    """实盘交易记录"""
    trade_id: str
    strategy_name: str
    version: str
    symbol: str
    side: str  # "buy" or "sell"
    signal_time: datetime
    execute_time: datetime
    signal_price: float
    execute_price: float
    quantity: int
    slippage_bps: float
    commission: float
    realized_pnl: float
    market_regime: str = ""  # "trending", "ranging", "volatile"


@dataclass
class StrategyPerformanceSummary:
    """策略绩效汇总"""
    strategy_name: str
    version: str
    period_start: datetime
    period_end: datetime
    total_trades: int
    win_trades: int
    total_pnl: float
    max_drawdown: float
    sharpe_ratio: float
    avg_slippage_bps: float
    market_regimes: Dict[str, int] = field(default_factory=dict)


class LiveFeedbackLoop:
    """实盘数据回流闭环"""

    def __init__(self, data_dir: str = "./live_feedback"):
        self.data_dir = Path(data_dir)
        self.data_dir.mkdir(parents=True, exist_ok=True)
        self.trades: List[LiveTradeRecord] = []

    def record_trade(self, trade: LiveTradeRecord):
        """记录实盘交易"""
        self.trades.append(trade)
        self._append_to_csv(trade)

    def generate_performance_summary(
        self, strategy_name: str, version: str,
        start: datetime, end: datetime,
    ) -> StrategyPerformanceSummary:
        """生成绩效汇总"""
        filtered = [
            t for t in self.trades
            if t.strategy_name == strategy_name
            and t.version == version
            and start <= t.execute_time <= end
        ]

        if not filtered:
            return StrategyPerformanceSummary(
                strategy_name=strategy_name,
                version=version,
                period_start=start,
                period_end=end,
                total_trades=0, win_trades=0,
                total_pnl=0, max_drawdown=0,
                sharpe_ratio=0, avg_slippage_bps=0,
            )

        pnls = [t.realized_pnl for t in filtered]
        slippages = [t.slippage_bps for t in filtered]
        daily_pnl = {}
        for t in filtered:
            day = t.execute_time.date()
            daily_pnl[day] = daily_pnl.get(day, 0) + t.realized_pnl

        daily_returns = list(daily_pnl.values())
        sharpe = 0.0
        if len(daily_returns) > 1:
            import numpy as np
            arr = np.array(daily_returns)
            if np.std(arr) > 0:
                sharpe = np.mean(arr) / np.std(arr) * 252 ** 0.5

        equity = []
        cum = 0
        for p in daily_returns:
            cum += p
            equity.append(cum)
        max_dd = 0
        peak = 0
        for e in equity:
            peak = max(peak, e)
            max_dd = min(max_dd, e - peak)

        regime_counts = {}
        for t in filtered:
            regime_counts[t.market_regime] = regime_counts.get(t.market_regime, 0) + 1

        return StrategyPerformanceSummary(
            strategy_name=strategy_name,
            version=version,
            period_start=start,
            period_end=end,
            total_trades=len(filtered),
            win_trades=sum(1 for p in pnls if p > 0),
            total_pnl=sum(pnls),
            max_drawdown=max_dd,
            sharpe_ratio=sharpe,
            avg_slippage_bps=sum(slippages) / len(slippages),
            market_regimes=regime_counts,
        )

    def _append_to_csv(self, trade: LiveTradeRecord):
        csv_file = self.data_dir / "trades.csv"
        file_exists = csv_file.exists()
        with open(csv_file, "a", newline="", encoding="utf-8") as f:
            writer = csv.writer(f)
            if not file_exists:
                writer.writerow([
                    "trade_id", "strategy", "version", "symbol", "side",
                    "signal_time", "execute_time", "signal_price",
                    "execute_price", "quantity", "slippage_bps",
                    "commission", "pnl", "market_regime",
                ])
            writer.writerow([
                trade.trade_id, trade.strategy_name, trade.version,
                trade.symbol, trade.side,
                trade.signal_time.isoformat(), trade.execute_time.isoformat(),
                trade.signal_price, trade.execute_price, trade.quantity,
                trade.slippage_bps, trade.commission,
                trade.realized_pnl, trade.market_regime,
            ])

    def export_for_backtest(self, strategy_name: str,
                            output_path: str = None) -> str:
        """导出实盘数据用于回测验证"""
        filtered = [t for t in self.trades if t.strategy_name == strategy_name]
        output_path = output_path or str(
            self.data_dir / f"{strategy_name}_live_data.json"
        )
        data = [
            {
                "symbol": t.symbol,
                "side": t.side,
                "signal_time": t.signal_time.isoformat(),
                "execute_time": t.execute_time.isoformat(),
                "signal_price": t.signal_price,
                "execute_price": t.execute_price,
                "quantity": t.quantity,
                "pnl": t.realized_pnl,
            }
            for t in filtered
        ]
        with open(output_path, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return output_path
```

## 常见误区

### 误区一：用全样本回测验证新参数

在全部历史数据上回测优化参数，然后直接上线——这是**过拟合的典型做法**。正确的方法是用 walk-forward 验证：在最近 N 个月的数据上训练，在之后 1 个月的数据上测试，滚动前进。

### 误区二：直接全量切换策略

新参数在回测上表现好就全量替换——如果新参数在当前市场环境下不适应，你会承受全部损失。正确的做法是灰度发布：先用 5% 资金试运行，确认有效后再逐步提高比例。

### 误区三：只看收益不看归因

策略赚钱了就高兴，亏钱了就焦虑——但你不知道钱是怎么赚的、怎么亏的。收益归因能告诉你：你的 alpha 有多少来自市场 beta、多少来自行业暴露、多少来自真正的选股能力。

### 误区四：忽略策略衰减的滞后性

当你发现策略衰减时，衰减可能已经发生了很久。滚动夏普、IC 等指标需要用短窗口（20-60 天）高频检测，而不是等月底看月度报告。

## 小结

本课的核心要点：

1. **衰减检测**：滚动夏普、IC 衰减、胜率变化，多维度监控策略健康度
2. **A/B 测试**：并行运行新旧策略，用统计检验决定是否切换
3. **参数优化**：网格搜索适合低维，贝叶斯优化适合高维，必须 walk-forward 验证
4. **灰度发布**：shadow → canary → 20% → 50% → full，逐步放量
5. **数据回流**：实盘数据回流到研发流程，形成策略迭代闭环

> **风险提示**：策略迭代本身也有风险。过于频繁地调整参数会导致"数据窥探"（data snooping），反而降低策略的泛化能力。建议每次调整只改变一个变量，观察至少 20 个交易日再做下一步决策。

```python
import numpy as np

# 前 30 天
sharpe_before = 0.001 / 0.02 * np.sqrt(252)  # ≈ 0.79

# 后 30 天
sharpe_after = 0.0002 / 0.025 * np.sqrt(252)  # ≈ 0.13

# 衰减幅度
decline = (sharpe_before - sharpe_after) / sharpe_before  # ≈ 84%

# 判断：decline > 30% 阈值，存在明显衰减
print(f"夏普从 {sharpe_before:.2f} 下降到 {sharpe_after:.2f}，衰减 {decline:.1%}")
```

**要点**：
- 年化夏普 = 日均收益 / 日标准差 × √252
- 84% 的衰减幅度远超 30% 阈值，应触发 CRITICAL 级别告警
- 需要进一步分析衰减原因：市场环境变化？策略逻辑失效？交易成本上升？
