# 实盘执行架构

> 从回测到实盘，差的不是代码，而是一整套工程架构。信号生成只是冰山一角，水面下是风控、执行、监控的复杂系统。

---

## 场景引入

你终于把策略从回测搬到了实盘。第一天运行正常，赚了 0.3%。第二天，网络断了 5 分钟，你的程序没有自动重连，错过了一个重要的交易信号。第三天，策略同时下了 20 个订单，但你的资金只够执行 15 个，程序不知道优先执行哪个。第四天，交易所临时停牌了一只你重仓的股票，你的程序没有处理这个异常。

这些问题都不是策略问题，而是工程问题。实盘执行架构的核心是：**让系统在各种异常情况下都能正确运行**。

完成本课学习后，你将能够：

## 核心概念

### 一、实盘执行的完整链路

```
实盘执行链路：

  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ 策略引擎  │ →  │ 风控系统  │ →  │ 订单管理  │ →  │ 执行引擎  │
  │ 生成信号  │    │ 检查限制  │    │ 拆单/排队 │    │ 发送到   │
  │          │    │          │    │          │    │ 交易所   │
  └──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                        │
                                                        ▼
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ 策略更新  │ ←  │ 风险监控  │ ←  │ 组合更新  │ ←  │ 成交回报  │
  │ 调整信号  │    │ 实时风控  │    │ 更新持仓  │    │ 交易所   │
  │          │    │          │    │ 更新资金  │    │ 回报     │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘

  关键要求：
  1. 低延迟：信号到下单 < 100ms
  2. 高可靠：网络断开自动重连
  3. 幂等性：同一信号不会重复下单
  4. 可审计：每笔订单可追溯
```

### 二、订单管理系统（OMS）

OMS 是执行系统的核心，负责订单的生命周期管理。

```
订单状态机：

  Created → Submitted → PartiallyFilled → Filled
                ↓              ↓
           Rejected       Cancelled

  状态说明：
  Created         策略生成信号，OMS 创建订单
  Submitted       订单已发送到交易所
  PartiallyFilled 部分成交（大单可能分多次成交）
  Filled          完全成交
  Rejected        被交易所拒绝（资金不足、停牌等）
  Cancelled       被撤销（超时未成交、策略取消）
```

### 三、执行算法

大额订单不能一次性发送到市场，否则会造成严重的市场冲击。执行算法的目标是在给定时间内以最优方式完成交易。

```
常见执行算法：

  ┌─────────────┬──────────────────────────────────────────┐
  │  算法         │  原理                                    │
  ├─────────────┼──────────────────────────────────────────┤
  │  TWAP        │  时间加权平均：将订单均匀分配到时间段      │
  │              │  例：1000 股，分 10 分钟，每分钟 100 股    │
  ├─────────────┼──────────────────────────────────────────┤
  │  VWAP        │  成交量加权平均：按历史成交量分布分配       │
  │              │  开盘和尾盘成交量大，分配更多订单           │
  ├─────────────┼──────────────────────────────────────────┤
  │  ICEBERG     │  冰山单：只显示小部分订单，隐藏大部分       │
  │              │  避免市场知道你要买/卖大量                  │
  ├─────────────┼──────────────────────────────────────────┤
  │  IS          │  Implementation Shortfall：               │
  │              │  最小化执行价与决策价的差异                 │
  │              │  在速度和冲击之间找最优平衡                 │
  └─────────────┴──────────────────────────────────────────┘
```

### 四、故障处理

实盘系统必须能处理各种故障：

```
故障类型              处理方式
────────────────────────────────────────────────────
网络断开              自动重连 + 断线期间缓存订单
交易所拒绝            记录原因 + 通知策略 + 人工介入
行情延迟              超时检测 + 使用最新可用行情
程序崩溃              持久化状态 + 重启后恢复持仓
部分成交              跟踪已成交量 + 超时后撤销剩余
资金不足              风控预检查 + 拒绝超额订单
```

"""
实盘执行框架
实现订单管理、执行算法、故障处理
"""

import time
import uuid
import threading
from enum import Enum
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Callable
from collections import defaultdict
from datetime import datetime, timedelta
import numpy as np
import pandas as pd


# ========== 1. 订单定义 ==========

class OrderStatus(Enum):
    CREATED = "created"
    SUBMITTED = "submitted"
    PARTIALLY_FILLED = "partially_filled"
    FILLED = "filled"
    REJECTED = "rejected"
    CANCELLED = "cancelled"


class OrderSide(Enum):
    BUY = "buy"
    SELL = "sell"


@dataclass
class Order:
    order_id: str
    symbol: str
    side: OrderSide
    quantity: int
    price: float = 0.0
    status: OrderStatus = OrderStatus.CREATED
    filled_quantity: int = 0
    filled_price: float = 0.0
    created_at: datetime = field(default_factory=datetime.now)
    updated_at: datetime = field(default_factory=datetime.now)
    reject_reason: str = ""
    commission: float = 0.0


# ========== 2. 订单管理系统 ==========

class OrderManager:
    """订单管理系统"""

    def __init__(self):
        self.orders: Dict[str, Order] = {}
        self.order_history: List[Order] = []
        self._lock = threading.Lock()

    def create_order(self, symbol: str, side: OrderSide,
                     quantity: int, price: float = 0.0) -> Order:
        """创建订单"""
        with self._lock:
            order_id = f"ORD_{uuid.uuid4().hex[:8].upper()}"
            order = Order(
                order_id=order_id,
                symbol=symbol,
                side=side,
                quantity=quantity,
                price=price,
            )
            self.orders[order_id] = order
            return order

    def update_status(self, order_id: str, status: OrderStatus,
                      filled_qty: int = 0, filled_price: float = 0.0,
                      reject_reason: str = ""):
        """更新订单状态"""
        with self._lock:
            order = self.orders.get(order_id)
            if not order:
                return

            order.status = status
            order.updated_at = datetime.now()

            if filled_qty > 0:
                total_cost = (order.filled_price * order.filled_quantity +
                             filled_price * filled_qty)
                order.filled_quantity += filled_qty
                order.filled_price = total_cost / order.filled_quantity

            if status == OrderStatus.FILLED:
                order.filled_quantity = order.quantity
                self.order_history.append(order)
            elif status == OrderStatus.REJECTED:
                order.reject_reason = reject_reason
                self.order_history.append(order)
            elif status == OrderStatus.CANCELLED:
                self.order_history.append(order)

    def get_pending_orders(self) -> List[Order]:
        """获取未完成订单"""
        return [o for o in self.orders.values()
                if o.status in (OrderStatus.CREATED, OrderStatus.SUBMITTED, OrderStatus.PARTIALLY_FILLED)]

    def cancel_order(self, order_id: str):
        """撤销订单"""
        self.update_status(order_id, OrderStatus.CANCELLED)


# ========== 3. 风控预检查 ==========

class PreTradeRiskCheck:
    """交易前风控检查"""

    def __init__(self, config: dict):
        self.max_order_value = config.get('max_order_value', 500_000)
        self.max_position_pct = config.get('max_position_pct', 0.20)
        self.max_daily_trades = config.get('max_daily_trades', 100)
        self.daily_trade_count = 0

    def check(self, order: Order, portfolio_value: float,
              current_positions: Dict[str, int],
              current_prices: Dict[str, float]) -> Tuple[bool, str]:
        """检查订单是否通过风控"""
        # 单笔金额限制
        order_value = order.quantity * order.price
        if order_value > self.max_order_value:
            return False, f"单笔金额 {order_value:,.0f} 超过限制 {self.max_order_value:,.0f}"

        # 持仓比例限制
        if order.side == OrderSide.BUY:
            current_pos_value = current_positions.get(order.symbol, 0) * current_prices.get(order.symbol, 0)
            new_pos_value = current_pos_value + order_value
            if new_pos_value / portfolio_value > self.max_position_pct:
                return False, f"持仓比例将超过 {self.max_position_pct:.0%}"

        # 日内交易次数限制
        if self.daily_trade_count >= self.max_daily_trades:
            return False, f"日内交易次数已达上限 {self.max_daily_trades}"

        # 资金充足性检查
        if order.side == OrderSide.BUY:
            # 简化：假设现金 = 组合价值的一定比例
            pass

        self.daily_trade_count += 1
        return True, "PASS"

    def reset_daily(self):
        """每日重置"""
        self.daily_trade_count = 0


# ========== 4. 执行引擎 ==========

class ExecutionEngine:
    """执行引擎"""

    def __init__(self, commission_rate: float = 0.0003):
        self.commission_rate = commission_rate

    def execute_market_order(self, order: Order, current_price: float) -> Order:
        """执行市价单"""
        # 模拟滑点
        if order.side == OrderSide.BUY:
            exec_price = current_price * 1.001  # 0.1% 滑点
        else:
            exec_price = current_price * 0.999

        # 计算手续费
        trade_value = exec_price * order.quantity
        commission = max(trade_value * self.commission_rate, 5.0)
        if order.side == OrderSide.SELL:
            commission += trade_value * 0.001  # 印花税

        order.commission = commission
        return exec_price, order.quantity


class TWAPExecutor:
    """TWAP 执行算法"""

    def __init__(self, duration_minutes: int = 10, n_slices: int = 10):
        self.duration = duration_minutes
        self.n_slices = n_slices

    def split_order(self, order: Order) -> List[Order]:
        """将大单拆分为多个小单"""
        slice_qty = order.quantity // self.n_slices
        remainder = order.quantity % self.n_slices

        slices = []
        for i in range(self.n_slices):
            qty = slice_qty + (1 if i < remainder else 0)
            if qty > 0:
                slice_order = Order(
                    order_id=f"{order.order_id}_TWAP_{i:03d}",
                    symbol=order.symbol,
                    side=order.side,
                    quantity=qty,
                    price=order.price,
                )
                slices.append(slice_order)

        return slices


# ========== 5. 组合管理 ==========

class PortfolioManager:
    """组合管理"""

    def __init__(self, initial_capital: float):
        self.cash = initial_capital
        self.initial_capital = initial_capital
        self.positions: Dict[str, int] = defaultdict(int)
        self.avg_prices: Dict[str, float] = {}
        self.trade_log: List[dict] = []

    def on_fill(self, symbol: str, side: OrderSide, quantity: int,
                price: float, commission: float):
        """处理成交回报"""
        if side == OrderSide.BUY:
            # 更新持仓均价
            if symbol in self.positions and self.positions[symbol] > 0:
                total_cost = self.avg_prices[symbol] * self.positions[symbol] + price * quantity
                self.positions[symbol] += quantity
                self.avg_prices[symbol] = total_cost / self.positions[symbol]
            else:
                self.positions[symbol] = quantity
                self.avg_prices[symbol] = price
            self.cash -= price * quantity + commission
        else:
            pnl = (price - self.avg_prices.get(symbol, price)) * quantity
            self.positions[symbol] -= quantity
            self.cash += price * quantity - commission
            self.trade_log.append({
                'symbol': symbol, 'side': side.value,
                'quantity': quantity, 'price': price,
                'pnl': pnl, 'commission': commission,
                'timestamp': datetime.now()
            })

    def get_total_value(self, prices: Dict[str, float]) -> float:
        """计算组合总价值"""
        positions_value = sum(
            self.positions[s] * prices.get(s, 0)
            for s in self.positions if self.positions[s] > 0
        )
        return self.cash + positions_value

    def get_position_report(self) -> pd.DataFrame:
        """持仓报告"""
        rows = []
        for symbol, qty in self.positions.items():
            if qty > 0:
                rows.append({
                    'symbol': symbol,
                    'quantity': qty,
                    'avg_price': self.avg_prices.get(symbol, 0),
                })
        return pd.DataFrame(rows) if rows else pd.DataFrame()


# ========== 6. 完整执行系统 ==========

class LiveTradingSystem:
    """实盘执行系统"""

    def __init__(self, config: dict):
        self.order_mgr = OrderManager()
        self.risk_check = PreTradeRiskCheck(config)
        self.executor = ExecutionEngine(config.get('commission', 0.0003))
        self.portfolio = PortfolioManager(config['initial_capital'])
        self.twap = TWAPExecutor()
        self.current_prices: Dict[str, float] = {}

    def on_signal(self, symbol: str, side: OrderSide, quantity: int, price: float):
        """处理交易信号"""
        # 1. 创建订单
        order = self.order_mgr.create_order(symbol, side, quantity, price)

        # 2. 风控检查
        passed, reason = self.risk_check.check(
            order, self.portfolio.get_total_value(self.current_prices),
            dict(self.portfolio.positions), self.current_prices
        )
        if not passed:
            self.order_mgr.update_status(order.order_id, OrderStatus.REJECTED, reject_reason=reason)
            print(f"  订单被拒绝: {reason}")
            return

        # 3. 提交执行
        self.order_mgr.update_status(order.order_id, OrderStatus.SUBMITTED)
        exec_price, exec_qty = self.executor.execute_market_order(order, self.current_prices.get(symbol, price))

        # 4. 更新组合
        self.portfolio.on_fill(symbol, side, exec_qty, exec_price, order.commission)
        self.order_mgr.update_status(order.order_id, OrderStatus.FILLED, exec_qty, exec_price)

        print(f"  成交: {side.value} {symbol} {exec_qty}股 @ {exec_price:.2f} "
              f"手续费: {order.commission:.2f}")

    def update_prices(self, prices: Dict[str, float]):
        """更新行情"""
        self.current_prices.update(prices)

    def get_report(self) -> dict:
        """获取系统状态报告"""
        return {
            'cash': self.portfolio.cash,
            'total_value': self.portfolio.get_total_value(self.current_prices),
            'positions': self.portfolio.get_position_report(),
            'pending_orders': len(self.order_mgr.get_pending_orders()),
            'completed_orders': len(self.order_mgr.order_history),
            'rejected_orders': sum(1 for o in self.order_mgr.order_history
                                  if o.status == OrderStatus.REJECTED),
        }

## 常见误区

### 误区一：把回测代码直接用于实盘

回测代码是"历史重放"，实盘代码是"事件驱动"。回测中数据是完整的，实盘中数据可能是乱序的、延迟的、缺失的。两者的代码架构完全不同。

### 误区二：不做风控预检查

"先下单再检查"是危险的。应该在下单前就检查资金、持仓、交易次数等限制。预检查是风控的第一道防线。

### 误区三：忽略订单状态管理

很多初学者下了单就不管了。实际中订单可能被拒绝、部分成交、超时撤销。必须跟踪每个订单的完整生命周期。

## 小结与练习

### 小结

1. 实盘执行链路：信号 → 风控 → 订单 → 执行 → 回报，每个环节都可能出错
2. OMS 是执行系统的核心，必须跟踪订单的完整生命周期
3. 大额订单需要执行算法（TWAP/VWAP）来降低市场冲击
4. 故障处理是实盘系统的生命线——网络断开、交易所拒绝、程序崩溃都必须有预案

### 练习一

**思路**：根据历史成交量的时间分布，将订单按比例分配到各时段。

**答案**：

```python
class VWAPExecutor:
    """VWAP 执行算法"""

    def __init__(self, volume_profile: List[float]):
        """
        volume_profile: 各时段的历史成交量占比
        例如：[0.15, 0.10, 0.08, 0.07, 0.08, 0.07, 0.05, 0.06, 0.08, 0.10, 0.08, 0.08]
        表示 12 个时段各自的成交量占比
        """
        self.volume_profile = np.array(volume_profile)
        self.volume_profile /= self.volume_profile.sum()  # 归一化

    def split_order(self, order: Order) -> List[Order]:
        """按成交量分布拆分订单"""
        n_slices = len(self.volume_profile)
        quantities = np.round(order.quantity * self.volume_profile).astype(int)

        # 调整使总数等于原始数量
        diff = order.quantity - quantities.sum()
        if diff != 0:
            max_idx = np.argmax(quantities)
            quantities[max_idx] += diff

        slices = []
        for i, qty in enumerate(quantities):
            if qty > 0:
                slices.append(Order(
                    order_id=f"{order.order_id}_VWAP_{i:03d}",
                    symbol=order.symbol,
                    side=order.side,
                    quantity=int(qty),
                    price=order.price,
                ))
        return slices

# 示例
volume_profile = [0.15, 0.12, 0.08, 0.07, 0.08, 0.07, 0.06, 0.07, 0.08, 0.10, 0.06, 0.06]
vwap = VWAPExecutor(volume_profile)
order = Order(order_id="TEST", symbol="SH.600000", side=OrderSide.BUY, quantity=10000)
slices = vwap.split_order(order)
for s in slices:
    print(f"  {s.order_id}: {s.quantity} 股")
```

**要点**：
- VWAP 在成交量大的时段分配更多订单，减少市场冲击
- 实际中成交量分布是实时更新的，这里用的是历史平均分布

### 练习二

**思路**：在订单创建时记录时间，定期检查超时订单。

**答案**：

```python
class OrderManagerWithTimeout(OrderManager):
    """带超时撤销的订单管理"""

    def __init__(self, timeout_seconds: int = 30):
        super().__init__()
        self.timeout = timeout_seconds

    def check_timeout_orders(self):
        """检查并撤销超时订单"""
        now = datetime.now()
        for order in list(self.orders.values()):
            if order.status in (OrderStatus.SUBMITTED, OrderStatus.PARTIALLY_FILLED):
                elapsed = (now - order.updated_at).total_seconds()
                if elapsed > self.timeout:
                    print(f"  订单 {order.order_id} 超时 ({elapsed:.0f}s)，撤销")
                    self.cancel_order(order.order_id)

order = om.create_order("SH.600000", OrderSide.BUY, 100, 10.5)
om.update_status(order.order_id, OrderStatus.SUBMITTED)

import time
time.sleep(6)
om.check_timeout_orders()
print(f"订单状态: {om.orders[order.order_id].status}")
```

**要点**：
- 超时撤销防止订单在不利价格成交
- 实际中还需要处理部分成交的超时情况
