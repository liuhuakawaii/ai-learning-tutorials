# 滑点与冲击成本

> 回测赚钱实盘亏钱，80% 的原因在这里。滑点和冲击成本是吞噬策略收益的隐形杀手。

---

## 场景引入

你的均线策略在回测中年化收益 25%。实盘运行三个月后，实际收益只有 12%。你检查了代码，没有前视偏差，没有生存者偏差，手续费也正确计算了。那差的 13% 去哪了？

答案是：**滑点和冲击成本**。你的回测假设以收盘价成交，但实盘中你用的是市价单。买入时成交价比你看到的价格高了 0.2%，卖出时又低了 0.2%。一来一回 0.4%，如果一年交易 30 次，就是 12%。

## 核心概念

### 一、滑点的三种来源

```
滑点分解：

  ┌─────────────────────────────────────────────────────────┐
  │  1. 价格滑点（Price Slippage）                           │
  │     你看到的价格 vs 实际成交价格的差异                     │
  │     原因：报价在你下单的瞬间已经变化                       │
  │     量级：0.01% - 0.1%（流动性好的股票）                  │
  │           0.1% - 0.5%（流动性差的股票）                   │
  ├─────────────────────────────────────────────────────────┤
  │  2. 时间滑点（Timing Slippage）                          │
  │     从信号生成到订单到达交易所的时间差                      │
  │     原因：网络延迟、程序处理时间、券商系统延迟              │
  │     量级：10ms - 500ms，对应价格变化 0.01% - 0.3%        │
  ├─────────────────────────────────────────────────────────┤
  │  3. 流动性滑点（Liquidity Slippage）                     │
  │     大额订单消耗订单簿深度，导致成交均价偏离                │
  │     原因：订单量超过最优价位的挂单量                       │
  │     量级：取决于订单大小和市场深度                         │
  └─────────────────────────────────────────────────────────┘
```

### 二、订单簿与市场冲击

```
订单簿示意：

  卖方（Ask）                    买方（Bid）
  价格    数量                    价格    数量
  ─────────────                  ─────────────
  10.05   5000 股                10.03   8000 股
  10.06   3000 股                10.02   6000 股
  10.07   8000 股                10.01   4000 股
  10.08  10000 股                10.00  12000 股
  10.09  15000 股                 9.99  20000 股

  最优买价: 10.03    最优卖价: 10.05
  买卖价差: 0.02 (Spread)

  如果你要买入 8000 股：
  - 5000 股以 10.05 成交（最优卖价）
  - 3000 股以 10.06 成交（第二档卖价）
  - 平均成交价: (5000×10.05 + 3000×10.06) / 8000 = 10.05375
  - 冲击成本: (10.05375 - 10.05) / 10.05 = 0.037%

  如果你要买入 25000 股：
  - 需要消耗更多档位，平均成交价更高
  - 冲击成本可能达到 0.1% - 0.5%
```

### 三、冲击成本模型

```
常见的冲击成本估算模型：

  1. 线性模型：
     Impact = a × (OrderSize / ADV)
     其中 ADV = 日均成交量

  2. 平方根模型（最常用）：
     Impact = σ × k × √(OrderSize / ADV)
     其中 σ = 波动率，k = 校准系数（通常 0.5-1.0）

  3. Kyle's Lambda：
     Impact = λ × OrderSize
     λ = 信息不对称系数

  实证研究显示，平方根模型最接近真实情况：
  - 订单量为 ADV 的 1% 时，冲击约 5-10 bps
  - 订单量为 ADV 的 10% 时，冲击约 15-30 bps
  - 订单量为 ADV 的 50% 时，冲击约 40-80 bps
```

### 四、滑点对策略的影响

```
滑点对不同类型策略的影响：

  策略类型          年均交易次数    每次滑点    年化滑点成本
  ─────────────────────────────────────────────────────
  低频价值投资       10-20 次      0.2%       0.02-0.04%
  中频多因子         50-100 次     0.2%       0.10-0.20%
  高频动量           500+ 次       0.1%       0.50%+
  日内交易           2000+ 次      0.05%      1.00%+

  结论：
  - 高频策略对滑点极度敏感，0.01% 的差异就能决定盈亏
  - 低频策略对滑点相对不敏感，但仍需正确建模
  - 回测中必须包含滑点模型，否则结果不可信
```

## 代码示例

```python
"""
滑点与冲击成本模型
实现多种滑点估算方法和冲击成本计算
"""

import numpy as np
import pandas as pd
from scipy import stats


# ========== 1. 基础滑点模型 ==========

class SlippageModel:
    """滑点模型"""

    @staticmethod
    def fixed_rate(price: float, side: str, rate: float = 0.001) -> float:
        """固定比例滑点"""
        if side == 'buy':
            return price * (1 + rate)
        else:
            return price * (1 - rate)

    @staticmethod
    def spread_based(price: float, side: str, spread: float = 0.02) -> float:
        """基于买卖价差的滑点"""
        half_spread = spread / 2
        if side == 'buy':
            return price + half_spread
        else:
            return price - half_spread

    @staticmethod
    def volatility_based(price: float, side: str, volatility: float,
                         n_sigma: float = 0.5) -> float:
        """基于波动率的滑点"""
        slippage = price * volatility * n_sigma
        if side == 'buy':
            return price + slippage
        else:
            return price - slippage


# ========== 2. 市场冲击模型 ==========

class MarketImpactModel:
    """市场冲击成本模型"""

    @staticmethod
    def square_root_model(order_size: float, adv: float,
                          volatility: float, k: float = 0.5) -> float:
        """
        平方根冲击模型
        Impact = σ × k × √(OrderSize / ADV)

        参数:
            order_size: 订单金额
            adv: 日均成交金额
            volatility: 日波动率
            k: 校准系数
        """
        if adv <= 0:
            return 0
        participation = order_size / adv
        impact = volatility * k * np.sqrt(participation)
        return impact

    @staticmethod
    def linear_model(order_size: float, adv: float, a: float = 0.1) -> float:
        """
        线性冲击模型
        Impact = a × (OrderSize / ADV)
        """
        if adv <= 0:
            return 0
        return a * (order_size / adv)

    @staticmethod
    def kyle_lambda(order_size: float, lambda_coeff: float = 0.0001) -> float:
        """
        Kyle's Lambda 模型
        Impact = λ × OrderSize
        """
        return lambda_coeff * order_size


# ========== 3. 订单簿模拟 ==========

class OrderBookSimulator:
    """订单簿模拟器"""

    def __init__(self, mid_price: float = 10.0, n_levels: int = 10):
        self.mid_price = mid_price
        self.n_levels = n_levels
        self._generate_book()

    def _generate_book(self):
        """生成模拟订单簿"""
        spread = self.mid_price * 0.002  # 0.2% 价差

        # 卖方
        self.ask_prices = [self.mid_price + spread/2 + i * 0.01 for i in range(self.n_levels)]
        self.ask_volumes = [int(np.random.exponential(5000)) + 1000 for _ in range(self.n_levels)]

        # 买方
        self.bid_prices = [self.mid_price - spread/2 - i * 0.01 for i in range(self.n_levels)]
        self.bid_volumes = [int(np.random.exponential(5000)) + 1000 for _ in range(self.n_levels)]

    def simulate_market_buy(self, quantity: int) -> dict:
        """模拟市价买入"""
        remaining = quantity
        total_cost = 0
        fills = []

        for i in range(self.n_levels):
            if remaining <= 0:
                break
            fill_qty = min(remaining, self.ask_volumes[i])
            total_cost += fill_qty * self.ask_prices[i]
            fills.append({'price': self.ask_prices[i], 'quantity': fill_qty})
            remaining -= fill_qty

        if remaining > 0:
            return {'status': 'insufficient_liquidity', 'unfilled': remaining}

        avg_price = total_cost / quantity
        impact = (avg_price - self.ask_prices[0]) / self.ask_prices[0]

        return {
            'status': 'filled',
            'avg_price': avg_price,
            'total_cost': total_cost,
            'impact': impact,
            'fills': fills,
            'levels_consumed': len(fills)
        }

    def simulate_market_sell(self, quantity: int) -> dict:
        """模拟市价卖出"""
        remaining = quantity
        total_proceeds = 0
        fills = []

        for i in range(self.n_levels):
            if remaining <= 0:
                break
            fill_qty = min(remaining, self.bid_volumes[i])
            total_proceeds += fill_qty * self.bid_prices[i]
            fills.append({'price': self.bid_prices[i], 'quantity': fill_qty})
            remaining -= fill_qty

        if remaining > 0:
            return {'status': 'insufficient_liquidity', 'unfilled': remaining}

        avg_price = total_proceeds / quantity
        impact = (self.bid_prices[0] - avg_price) / self.bid_prices[0]

        return {
            'status': 'filled',
            'avg_price': avg_price,
            'total_proceeds': total_proceeds,
            'impact': impact,
            'fills': fills,
            'levels_consumed': len(fills)
        }


# ========== 4. 滑点对策略影响分析 ==========

def analyze_slippage_impact():
    """分析滑点对策略收益的影响"""
    np.random.seed(42)

    # 模拟策略参数
    n_trades_per_year = [10, 50, 100, 500, 1000, 3000]
    slippage_rates = [0.0005, 0.001, 0.002, 0.005]

    print("=" * 70)
    print("滑点对策略年化收益的影响（假设策略原始年化 20%）")
    print("=" * 70)

    base_return = 0.20

    print(f"\n{'交易次数/年':<12}", end="")
    for sr in slippage_rates:
        print(f"  滑点{sr:.1%}  ", end="")
    print("\n" + "-" * 60)

    for n_trades in n_trades_per_year:
        print(f"{n_trades:<12}", end="")
        for sr in slippage_rates:
            # 每次买卖算两次滑点（买+卖）
            annual_slippage = n_trades * 2 * sr
            net_return = base_return - annual_slippage
            print(f"  {net_return:>8.2%}  ", end="")
        print()

    # 冲击成本分析
    print(f"\n{'=' * 70}")
    print("冲击成本分析（平方根模型）")
    print(f"{'=' * 70}")

    adv = 50_000_000  # 日均成交金额 5000 万
    volatility = 0.02  # 日波动率 2%

    order_sizes = [100_000, 500_000, 1_000_000, 5_000_000, 10_000_000]

    print(f"\n日均成交金额: {adv/1e6:.0f}M")
    print(f"日波动率: {volatility:.1%}")
    print(f"\n{'订单金额':<12} {'参与率':>8} {'冲击成本':>10} {'年化影响(50次)':>15}")
    print("-" * 50)

    for size in order_sizes:
        participation = size / adv
        impact = MarketImpactModel.square_root_model(size, adv, volatility, k=0.5)
        annual_impact = impact * 2 * 50  # 50 次完整交易
        print(f"{size/1e6:.1f}M{'':<8} {participation:>8.2%} {impact:>10.4%} {annual_impact:>15.2%}")

    return


# ========== 5. 执行质量分析 ==========

def execution_quality_analysis():
    """执行质量分析"""
    np.random.seed(42)

    # 模拟不同执行方式的效果
    n_orders = 100
    prices = 100 + np.cumsum(np.random.normal(0, 0.5, n_orders))

    results = {'市价单': [], '限价单': [], 'TWAP': []}

    for i in range(n_orders):
        base_price = prices[i]

        # 市价单：立即成交，但有滑点
        slip = np.random.normal(0, 0.1)
        results['市价单'].append(base_price + slip)

        # 限价单：以指定价格成交，但有未成交风险
        if np.random.random() > 0.1:  # 90% 成交率
            results['限价单'].append(base_price - 0.05)
        # 未成交的不算

        # TWAP：分 5 笔成交，均价更接近 VWAP
        twap_prices = base_price + np.random.normal(0, 0.05, 5)
        results['TWAP'].append(twap_prices.mean())

    print(f"\n{'=' * 70}")
    print("执行质量对比")
    print(f"{'=' * 70}")

    for method, exec_prices in results.items():
        if not exec_prices:
            continue
        avg_slippage = np.mean([abs(p - prices[i]) for i, p in enumerate(exec_prices[:len(prices)])])
        std_slippage = np.std([abs(p - prices[i]) for i, p in enumerate(exec_prices[:len(prices)])])

        print(f"\n  {method}:")
        print(f"    平均滑点: {avg_slippage:.4f}")
        print(f"    滑点标准差: {std_slippage:.4f}")
        print(f"    成交率: {len(exec_prices)/n_orders:.1%}")


# 运行分析
analyze_slippage_impact()
execution_quality_analysis()

# 订单簿模拟
print(f"\n{'=' * 70}")
print("订单簿模拟")
print(f"{'=' * 70}")

book = OrderBookSimulator(mid_price=10.0)

# 不同规模的买入订单
for qty in [1000, 5000, 10000, 25000]:
    result = book.simulate_market_buy(qty)
    if result['status'] == 'filled':
        print(f"\n  买入 {qty} 股:")
        print(f"    平均成交价: {result['avg_price']:.4f}")
        print(f"    冲击成本: {result['impact']:.4%}")
        print(f"    消耗档位: {result['levels_consumed']}")
    else:
        print(f"\n  买入 {qty} 股: 流动性不足，未成交 {result['unfilled']} 股")
```

## 常见误区

### 误区一：回测中不计入滑点

很多回测脚本忽略了滑点。对于中低频策略，滑点可能占总收益的 10-30%。不计入滑点的回测结果是虚假的。

### 误区二：用固定滑点率

不同市场环境、不同股票、不同时段的滑点差异很大。流动性差的小盘股滑点可能是大盘股的 5-10 倍。应该根据股票的流动性特征动态调整滑点假设。

### 误区三：忽略冲击成本

当你的策略管理的资金规模增大时，冲击成本会显著增加。一个在 100 万资金下有效的策略，在 1 亿资金下可能因为冲击成本而失效。

### 误区四：认为限价单没有滑点

限价单虽然没有价格滑点，但有"机会成本"——如果价格没有触及限价，你就错过了交易机会。这个机会成本可能比滑点更大。

## 小结与练习

### 小结

1. 滑点由价格滑点、时间滑点、流动性滑点三部分组成
2. 平方根冲击模型是最常用的冲击成本估算方法
3. 高频策略对滑点极度敏感，低频策略相对不敏感但仍需建模
4. 执行算法（TWAP/VWAP）可以降低大额订单的冲击成本

## 参考答案

### 练习一

**思路**：用成交量和价差的组合来估算滑点率。

**答案**：

```python
def dynamic_slippage(price: float, side: str, volume: float,
                     avg_volume: float, spread: float) -> float:
    """
    动态滑点模型
    流动性差（成交量低、价差大）时滑点更大
    """
    # 基础滑点 = 半个价差
    base_slippage = spread / 2

    # 流动性调整：成交量越低，滑点越大
    volume_ratio = avg_volume / max(volume, 1)
    liquidity_factor = np.sqrt(volume_ratio)

    total_slippage = base_slippage * liquidity_factor

    if side == 'buy':
        return price * (1 + total_slippage)
    else:
        return price * (1 - total_slippage)

# 测试
print("动态滑点模型:")
for vol, sp in [(1e6, 0.01), (5e6, 0.02), (50e6, 0.01), (100e6, 0.005)]:
    slip = dynamic_slippage(10.0, 'buy', vol, 50e6, sp)
    print(f"  成交量{vol/1e6:.0f}M, 价差{sp:.3f}: 成交价{slip:.4f}, 滑点{(slip/10-1):.4%}")
```

**要点**：
- 流动性差的股票需要更宽的滑点假设
- 盘中不同时间段的流动性也不同（开盘和收盘流动性最好）

### 练习二

**思路**：模拟不同市场环境下 TWAP 和市价单的执行效果。

**答案**：

```python
def compare_execution_methods():
    """比较 TWAP 和市价单执行效果"""
    np.random.seed(42)
    n_simulations = 1000

    results = {'一次性市价单': [], 'TWAP(5笔)': [], 'TWAP(10笔)': []}

    for _ in range(n_simulations):
        # 模拟 5 分钟内的价格路径
        base_price = 10.0
        n_minutes = 5
        prices = base_price + np.cumsum(np.random.normal(0, 0.005, n_minutes))

        # 一次性市价单：在第 0 分钟执行，有较大冲击
        impact_1 = np.random.normal(0.002, 0.001)
        exec_1 = prices[0] * (1 + impact_1)
        results['一次性市价单'].append(exec_1 - base_price)

        # TWAP 5 笔：每分钟 1 笔
        twap_5 = np.mean(prices[:5] + np.random.normal(0.001, 0.0005, 5))
        results['TWAP(5笔)'].append(twap_5 - base_price)

        # TWAP 10 笔：每 30 秒 1 笔（简化为插值）
        twap_prices = np.interp(np.linspace(0, 4, 10), range(5), prices)
        twap_10 = np.mean(twap_prices + np.random.normal(0.0005, 0.0003, 10))
        results['TWAP(10笔)'].append(twap_10 - base_price)

    print("执行方法对比（偏差 = 执行价 - 决策价）:")
    print(f"{'方法':<15} {'平均偏差':>10} {'偏差标准差':>10} {'95%分位':>10}")
    print("-" * 50)
    for method, deviations in results.items():
        devs = np.array(deviations)
        print(f"{method:<15} {np.mean(devs):>10.4f} {np.std(devs):>10.4f} "
              f"{np.percentile(np.abs(devs), 95):>10.4f}")

compare_execution_methods()
```

**要点**：
- TWAP 降低了执行的不确定性（标准差更小）
- 分笔数越多，执行效果越稳定
- 但 TWAP 需要更长的执行时间，期间价格可能发生不利变化
