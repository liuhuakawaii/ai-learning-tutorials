# 实盘监控系统

> 策略跑起来了，但出了问题不知道——直到你打开账户发现已经亏了 20%。

---

## 场景引入

凌晨三点，你的量化策略在服务器上安静地运行着。你睡得很香。

早上起来打开账户，发现策略在凌晨 1:23 因为交易所 API 返回了一个意外的错误码，持仓状态和实际不一致，随后策略基于错误的持仓信号连续下了 15 笔反向订单。你不仅亏了昨晚的利润，还倒贴了 8% 的本金。

你回头看代码，发现错误处理逻辑确实有，但日志被淹没在几千行 INFO 级别的输出里。告警？没有。监控仪表盘？没有。你甚至不知道策略是什么时候开始出问题的。

这就是为什么需要监控系统——它不是锦上添花，而是实盘交易的生命线。

---

## 学习目标

完成本课学习后，你将能够：

4. 实现结构化日志系统与审计追踪
5. 用 WebSocket 实现实时状态推送

## 核心概念

### 一、监控指标体系

量化交易系统的监控不是随便加几个日志就行的。你需要一套分层的指标体系，每一层回答不同层面的问题：

```
监控指标五层体系：

  ┌─────────────────────────────────────────────────────────┐
  │  L5 - 策略层：信号质量                                    │
  │  ├── 信号产生频率                                        │
  │  ├── 信号与实际执行的偏差                                  │
  │  ├── 策略夏普比率（滚动）                                  │
  │  └── 策略衰减指标（IC 衰减、收益归因）                      │
  ├─────────────────────────────────────────────────────────┤
  │  L4 - 账户层：资金安全                                    │
  │  ├── 账户净值                                            │
  │  ├── 可用资金                                            │
  │  ├── 持仓集中度                                          │
  │  ├── 最大回撤                                            │
  │  └── 日度 / 周度盈亏                                      │
  ├─────────────────────────────────────────────────────────┤
  │  L3 - 业务层：交易执行                                    │
  │  ├── 持仓盈亏（实时 PnL）                                 │
  │  ├── 订单成交率                                          │
  │  ├── 滑点统计                                            │
  │  └── 风控触发次数                                        │
  ├─────────────────────────────────────────────────────────┤
  │  L2 - 服务层：交易系统                                    │
  │  ├── API 连接状态                                        │
  │  ├── 订单处理延迟                                        │
  │  ├── 事件队列深度                                        │
  │  └── 错误率 / 重试次数                                    │
  ├─────────────────────────────────────────────────────────┤
  │  L1 - 系统层：基础设施                                    │
  │  ├── CPU / 内存 / 磁盘使用率                              │
  │  ├── 网络延迟 / 丢包率                                    │
  │  └── 进程存活状态                                        │
  └─────────────────────────────────────────────────────────┘
```

| 指标类别 | 指标名 | 采集频率 | 告警阈值示例 | 严重程度 |
|---------|--------|---------|-------------|---------|
| 系统 | CPU 使用率 | 10s | > 80% | WARNING |
| 系统 | 内存使用率 | 10s | > 85% | WARNING |
| 服务 | API 延迟 | 每次请求 | > 500ms | WARNING |
| 服务 | 连接状态 | 5s | 断开 | CRITICAL |
| 业务 | 策略 PnL | 1s | 日亏损 > 2% | CRITICAL |
| 业务 | 订单失败率 | 1min | > 10% | WARNING |
| 账户 | 账户净值 | 1min | 回撤 > 5% | CRITICAL |
| 策略 | 夏普比率 | 1h | < 0.5 | WARNING |
| 策略 | IC 衰减 | 1d | 连续 5 天下降 | WARNING |

### 二、Prometheus + Grafana 技术栈

```
监控系统架构：

  ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ 交易系统  │ ──→ │Exporter  │ ──→ │Prometheus│ ──→ │ Grafana  │
  │ 产生指标  │     │暴露指标   │     │拉取存储   │     │ 可视化   │
  └──────────┘     └──────────┘     └─────┬────┘     └──────────┘
                                          │
                                          ▼
                                    ┌──────────┐
                                    │Alertmgr  │
                                    │告警路由   │ ──→ 邮件/微信/短信
                                    │去重/静默  │
                                    └──────────┘

  数据流：交易系统 → Prometheus Client → HTTP /metrics → Prometheus Server
  可视化：Prometheus → Grafana Dashboard
  告警：Prometheus → Alertmanager → 通知渠道
```

### 三、告警规则设计

告警系统最怕两个极端：要么什么都不报（出了问题不知道），要么什么都报（告警疲劳，真正的问题被淹没）。

```
告警分级设计：

  ┌─────────┬────────────────────┬──────────────┬────────────┐
  │  级别    │  触发条件           │  响应要求      │  通知方式   │
  ├─────────┼────────────────────┼──────────────┼────────────┤
  │  INFO   │  策略开仓/平仓      │  仅记录        │  日志       │
  │  WARNING│  指标接近阈值        │  1小时内处理   │  钉钉/微信  │
  │  ERROR  │  指标超过阈值        │  立即处理      │  短信+电话  │
  │  CRITI  │  资金安全受威胁      │  立即人工介入  │  电话+短信  │
  └─────────┴────────────────────┴──────────────┴────────────┘

  关键原则：
  1. 每个告警必须有明确的处理动作
  2. 同类告警 5 分钟内只发一次（去重）
  3. 非交易时间可降低告警灵敏度
  4. 告警必须有恢复通知
```

### 四、结构化日志与审计追踪

```
日志分类：

  ┌─────────────┬───────────────────────────────────────────┐
  │  日志类型    │  内容                                      │
  ├─────────────┼───────────────────────────────────────────┤
  │  系统日志    │  启动/停止/异常/重连                        │
  │  交易日志    │  下单/成交/撤单/资金变动                     │
  │  策略日志    │  信号生成/参数调整/策略切换                   │
  │  风控日志    │  风控检查/触发/拦截                          │
  │  审计日志    │  操作记录/配置变更/权限变更                   │
  └─────────────┴───────────────────────────────────────────┘

  每条日志必须包含：
  - timestamp（毫秒精度）
  - level（DEBUG/INFO/WARNING/ERROR/CRITICAL）
  - module（来源模块）
  - trade_id（关联交易的唯一标识）
  - message（结构化内容）
```

### 一、指标采集器

```python
"""
量化交易系统 Prometheus Exporter

依赖安装：
pip install prometheus-client psutil

启动方式：
python metrics_exporter.py
默认在 9091 端口暴露 /metrics 端点
"""

import time
import threading
import logging
from dataclasses import dataclass, field
from typing import Dict, Optional
from prometheus_client import (
    start_http_server, Gauge, Counter, Histogram, Summary, Info
)
import psutil

logger = logging.getLogger("MetricsExporter")


# ========== 指标定义 ==========

# 系统层
system_cpu_percent = Gauge("quant_cpu_percent", "CPU usage percentage")
system_memory_percent = Gauge("quant_memory_percent", "Memory usage percentage")
system_disk_percent = Gauge("quant_disk_percent", "Disk usage percentage")

# 服务层
api_latency = Histogram(
    "quant_api_latency_seconds",
    "API call latency",
    buckets=[0.01, 0.05, 0.1, 0.2, 0.5, 1.0, 2.0, 5.0]
)
api_errors_total = Counter(
    "quant_api_errors_total", "Total API errors", ["error_type"]
)
api_connection_status = Gauge(
    "quant_api_connected", "API connection status (1=connected)"
)
order_queue_depth = Gauge(
    "quant_order_queue_depth", "Pending orders in queue"
)

# 业务层
portfolio_pnl = Gauge(
    "quant_portfolio_pnl", "Realized PnL", ["strategy"]
)
position_value = Gauge(
    "quant_position_value", "Current position value", ["symbol"]
)
orders_total = Counter(
    "quant_orders_total", "Total orders", ["side", "status"]
)
slippage_bps = Histogram(
    "quant_slippage_bps",
    "Order slippage in basis points",
    buckets=[0, 1, 2, 5, 10, 20, 50, 100]
)

# 账户层
account_equity = Gauge("quant_account_equity", "Account equity")
account_available = Gauge("quant_account_available", "Available cash")
account_drawdown = Gauge(
    "quant_account_drawdown_percent", "Current drawdown percentage"
)

# 策略层
strategy_sharpe = Gauge(
    "quant_strategy_sharpe_rolling", "Rolling Sharpe ratio", ["strategy"]
)
signal_count = Counter(
    "quant_signals_total", "Total signals generated", ["strategy", "direction"]
)

# 系统信息
system_info = Info("quant_system", "Trading system info")


@dataclass
class MetricsCollector:
    """指标采集器，负责从交易系统收集数据并更新 Prometheus 指标"""

    strategies: Dict[str, object] = field(default_factory=dict)
    _running: bool = False
    _thread: Optional[threading.Thread] = None

    def register_strategy(self, name: str, strategy):
        """注册策略实例，用于采集策略层指标"""
        self.strategies[name] = strategy
        logger.info(f"注册策略指标源: {name}")

    def start(self, port: int = 9091, interval: float = 5.0):
        """启动 HTTP 服务和采集线程"""
        start_http_server(port)
        logger.info(f"Prometheus Exporter 启动在 :{port}/metrics")

        system_info.info({
            "version": "1.0.0",
            "start_time": str(int(time.time())),
        })

        self._running = True
        self._thread = threading.Thread(
            target=self._collect_loop, args=(interval,), daemon=True
        )
        self._thread.start()

    def stop(self):
        self._running = False

    def _collect_loop(self, interval: float):
        while self._running:
            try:
                self._collect_system()
                self._collect_strategies()
            except Exception as e:
                logger.error(f"指标采集异常: {e}")
            time.sleep(interval)

    def _collect_system(self):
        system_cpu_percent.set(psutil.cpu_percent())
        system_memory_percent.set(psutil.virtual_memory().percent)
        system_disk_percent.set(psutil.disk_usage("/").percent)

    def _collect_strategies(self):
        for name, strategy in self.strategies.items():
            if hasattr(strategy, "get_pnl"):
                portfolio_pnl.labels(strategy=name).set(strategy.get_pnl())
            if hasattr(strategy, "get_sharpe"):
                strategy_sharpe.labels(strategy=name).set(strategy.get_sharpe())

    def record_order(self, side: str, status: str):
        """记录订单事件"""
        orders_total.labels(side=side, status=status).inc()

    def record_signal(self, strategy: str, direction: str):
        """记录信号事件"""
        signal_count.labels(strategy=strategy, direction=direction).inc()

    def record_api_call(self, latency: float, error: Optional[str] = None):
        """记录 API 调用"""
        api_latency.observe(latency)
        if error:
            api_errors_total.labels(error_type=error).inc()

    def record_slippage(self, bps: float):
        """记录滑点"""
        slippage_bps.observe(bps)

    def update_account(self, equity: float, available: float, drawdown: float):
        """更新账户指标"""
        account_equity.set(equity)
        account_available.set(available)
        account_drawdown.set(drawdown)
```

### 二、告警管理器

```python
"""
告警管理系统

支持多级告警、去重、静默、多渠道通知
"""

import time
import json
import threading
import urllib.request
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from enum import Enum
from typing import Callable, Dict, List, Optional
from collections import defaultdict


class AlertLevel(Enum):
    INFO = "info"
    WARNING = "warning"
    ERROR = "error"
    CRITICAL = "critical"


@dataclass
class Alert:
    alert_id: str
    level: AlertLevel
    category: str
    message: str
    timestamp: datetime = field(default_factory=datetime.now)
    metadata: dict = field(default_factory=dict)
    resolved: bool = False


@dataclass
class AlertRule:
    rule_id: str
    name: str
    level: AlertLevel
    category: str
    condition: Callable[[], bool]
    message_template: str
    cooldown_seconds: int = 300
    _last_fired: float = 0


class AlertManager:
    """告警管理器"""

    def __init__(self):
        self.rules: Dict[str, AlertRule] = {}
        self.handlers: Dict[AlertLevel, List[Callable]] = defaultdict(list)
        self.active_alerts: Dict[str, Alert] = {}
        self.alert_history: List[Alert] = []
        self._lock = threading.Lock()
        self._running = False
        self._check_thread: Optional[threading.Thread] = None

    def register_rule(self, rule: AlertRule):
        self.rules[rule.rule_id] = rule

    def register_handler(self, level: AlertLevel, handler: Callable):
        self.handlers[level].append(handler)

    def start(self, check_interval: float = 10.0):
        self._running = True
        self._check_thread = threading.Thread(
            target=self._check_loop, args=(check_interval,), daemon=True
        )
        self._check_thread.start()

    def stop(self):
        self._running = False

    def fire_alert(self, alert: Alert):
        with self._lock:
            self.active_alerts[alert.alert_id] = alert
            self.alert_history.append(alert)

        for handler in self.handlers.get(alert.level, []):
            try:
                handler(alert)
            except Exception as e:
                print(f"告警通知失败: {e}")

    def resolve_alert(self, alert_id: str):
        with self._lock:
            if alert_id in self.active_alerts:
                self.active_alerts[alert_id].resolved = True
                del self.active_alerts[alert_id]

    def _check_loop(self, interval: float):
        while self._running:
            now = time.time()
            for rule in self.rules.values():
                if now - rule._last_fired < rule.cooldown_seconds:
                    continue
                try:
                    if rule.condition():
                        alert = Alert(
                            alert_id=f"{rule.rule_id}_{int(now)}",
                            level=rule.level,
                            category=rule.category,
                            message=rule.message_template,
                        )
                        self.fire_alert(alert)
                        rule._last_fired = now
                except Exception as e:
                    print(f"规则检查异常 [{rule.rule_id}]: {e}")
            time.sleep(interval)


class WeChatNotifier:
    """企业微信机器人通知"""

    def __init__(self, webhook_url: str):
        self.webhook_url = webhook_url

    def send(self, alert: Alert):
        level_emoji = {
            AlertLevel.INFO: "ℹ️",
            AlertLevel.WARNING: "⚠️",
            AlertLevel.ERROR: "🔴",
            AlertLevel.CRITICAL: "🚨",
        }
        content = (
            f"{level_emoji.get(alert.level, '')} "
            f"**{alert.level.value.upper()}**\n"
            f"分类: {alert.category}\n"
            f"信息: {alert.message}\n"
            f"时间: {alert.timestamp.strftime('%Y-%m-%d %H:%M:%S')}"
        )
        payload = json.dumps({
            "msgtype": "markdown",
            "markdown": {"content": content}
        }).encode("utf-8")

        req = urllib.request.Request(
            self.webhook_url,
            data=payload,
            headers={"Content-Type": "application/json"},
        )
        try:
            urllib.request.urlopen(req, timeout=5)
        except Exception as e:
            print(f"企业微信通知失败: {e}")


class EmailNotifier:
    """邮件通知"""

    def __init__(self, smtp_host: str, smtp_port: int,
                 username: str, password: str, recipients: List[str]):
        self.smtp_host = smtp_host
        self.smtp_port = smtp_port
        self.username = username
        self.password = password
        self.recipients = recipients

    def send(self, alert: Alert):
        import smtplib
        from email.mime.text import MIMEText

        body = (
            f"告警级别: {alert.level.value}\n"
            f"告警分类: {alert.category}\n"
            f"告警信息: {alert.message}\n"
            f"触发时间: {alert.timestamp}\n"
        )
        msg = MIMEText(body)
        msg["Subject"] = f"[量化告警] {alert.level.value.upper()}: {alert.category}"
        msg["From"] = self.username
        msg["To"] = ", ".join(self.recipients)

        try:
            with smtplib.SMTP(self.smtp_host, self.smtp_port) as server:
                server.starttls()
                server.login(self.username, self.password)
                server.send_message(msg)
        except Exception as e:
            print(f"邮件通知失败: {e}")
```

### 三、结构化日志系统

```python
"""
结构化日志系统

支持 JSON 格式输出、按日期轮转、审计追踪
"""

import json
import logging
import logging.handlers
from datetime import datetime
from pathlib import Path
from typing import Optional


class JsonFormatter(logging.Formatter):
    """JSON 格式化器"""

    def format(self, record: logging.LogRecord) -> str:
        log_entry = {
            "timestamp": datetime.fromtimestamp(record.created).isoformat(),
            "level": record.levelname,
            "module": record.module,
            "function": record.funcName,
            "line": record.lineno,
            "message": record.getMessage(),
        }
        if hasattr(record, "trade_id"):
            log_entry["trade_id"] = record.trade_id
        if hasattr(record, "extra_data"):
            log_entry["data"] = record.extra_data
        if record.exc_info:
            log_entry["exception"] = self.formatException(record.exc_info)
        return json.dumps(log_entry, ensure_ascii=False)


class TradingLogger:
    """交易系统专用日志器"""

    def __init__(self, log_dir: str = "./logs"):
        self.log_dir = Path(log_dir)
        self.log_dir.mkdir(parents=True, exist_ok=True)

        self._loggers = {}
        for category in ["system", "trade", "strategy", "risk", "audit"]:
            logger = logging.getLogger(f"quant.{category}")
            logger.setLevel(logging.DEBUG)

            file_handler = logging.handlers.TimedRotatingFileHandler(
                self.log_dir / f"{category}.log",
                when="midnight",
                backupCount=90,
                encoding="utf-8",
            )
            file_handler.setFormatter(JsonFormatter())
            logger.addHandler(file_handler)

            self._loggers[category] = logger

    def _log(self, category: str, level: int, message: str,
             trade_id: Optional[str] = None, **extra):
        logger = self._loggers.get(category)
        if not logger:
            return
        record = logger.makeRecord(
            logger.name, level, "(trading)", 0, message, (), None
        )
        if trade_id:
            record.trade_id = trade_id
        if extra:
            record.extra_data = extra
        logger.handle(record)

    def system(self, level: str, message: str, **kw):
        level_map = {
            "debug": logging.DEBUG, "info": logging.INFO,
            "warning": logging.WARNING, "error": logging.ERROR,
            "critical": logging.CRITICAL,
        }
        self._log("system", level_map.get(level, logging.INFO), message, **kw)

    def trade(self, message: str, trade_id: str = None, **kw):
        self._log("trade", logging.INFO, message, trade_id=trade_id, **kw)

    def strategy(self, message: str, **kw):
        self._log("strategy", logging.INFO, message, **kw)

    def risk(self, message: str, level: str = "warning", **kw):
        level_val = getattr(logging, level.upper(), logging.WARNING)
        self._log("risk", level_val, message, **kw)

    def audit(self, message: str, **kw):
        self._log("audit", logging.INFO, message, **kw)

    def query_trades(self, date: str) -> list:
        """查询指定日期的交易日志"""
        log_file = self.log_dir / f"trade.log"
        results = []
        if not log_file.exists():
            return results
        with open(log_file, "r", encoding="utf-8") as f:
            for line in f:
                try:
                    entry = json.loads(line)
                    if entry.get("timestamp", "").startswith(date):
                        results.append(entry)
                except json.JSONDecodeError:
                    continue
        return results
```

### 五、WebSocket 实时推送

```python
"""
WebSocket 实时状态推送

将交易系统的实时状态推送到前端 Dashboard
依赖：pip install websockets
"""

import asyncio
import json
import time
from dataclasses import dataclass, field
from datetime import datetime
from typing import Dict, Set
from enum import Enum


try:
    import websockets
    HAS_WEBSOCKETS = True
except ImportError:
    HAS_WEBSOCKETS = False
    print("websockets 未安装，WebSocket 功能不可用")


class MessageType(Enum):
    PNL_UPDATE = "pnl_update"
    ORDER_EVENT = "order_event"
    POSITION_UPDATE = "position_update"
    ALERT = "alert"
    SYSTEM_STATUS = "system_status"


@dataclass
class RealtimePusher:
    """WebSocket 实时推送服务"""

    host: str = "localhost"
    port: int = 8765
    _clients: Set = field(default_factory=set)
    _running: bool = False

    async def _handler(self, websocket, path):
        self._clients.add(websocket)
        try:
            async for message in websocket:
                pass
        finally:
            self._clients.discard(websocket)

    async def _broadcast(self, message: dict):
        if not self._clients:
            return
        payload = json.dumps(message, ensure_ascii=False, default=str)
        dead = set()
        for client in self._clients:
            try:
                await client.send(payload)
            except Exception:
                dead.add(client)
        self._clients -= dead

    def push(self, msg_type: MessageType, data: dict):
        """同步接口：推送消息到所有客户端"""
        message = {
            "type": msg_type.value,
            "timestamp": datetime.now().isoformat(),
            "data": data,
        }
        loop = asyncio.get_event_loop()
        if loop.is_running():
            asyncio.ensure_future(self._broadcast(message))
        else:
            loop.run_until_complete(self._broadcast(message))

    async def start_server(self):
        if not HAS_WEBSOCKETS:
            print("WebSocket 服务未启动：缺少 websockets 库")
            return
        self._running = True
        server = await websockets.serve(self._handler, self.host, self.port)
        print(f"WebSocket 服务启动: ws://{self.host}:{self.port}")
        await server.wait_closed()

    def start(self):
        """在新线程中启动 WebSocket 服务"""
        import threading
        thread = threading.Thread(
            target=lambda: asyncio.run(self.start_server()), daemon=True
        )
        thread.start()
```

## 常见误区

### 误区一：只监控系统层指标

很多团队只关注 CPU、内存等系统指标，忽略了业务层指标。系统正常不代表策略正常——你的程序可能 100% CPU 空闲，但策略已经亏了 10%。

### 误区二：告警阈值设置过严

把日亏损告警设为 0.1%，结果每天市场正常波动都会触发几十次告警。三天后你就开始忽略告警了，真正出问题时反而没注意到。阈值应该基于历史波动率设置，通常设为 2-3 倍标准差。

### 误区三：日志不做结构化

用 `print(f"买入了 {symbol}")` 这种方式记录日志，出了问题根本无法搜索和关联。结构化日志（JSON 格式）加上统一的 trade_id，才能在海量日志中快速定位问题链路。

### 误区四：监控和交易耦合

监控系统的异常不应该影响交易系统。指标采集、告警通知都应该在独立线程/进程中进行，使用 try-except 隔离，确保监控挂了交易还能跑。

## 小结

本课的核心要点：

1. **五层指标体系**：从系统层到策略层，层层递进，不遗漏关键指标
2. **Prometheus + Grafana**：云原生监控的事实标准，配置灵活、生态丰富
3. **告警分级**：WARNING → ERROR → CRITICAL，配合去重和静默机制
4. **结构化日志**：JSON 格式 + trade_id 关联，支持审计追踪
5. **WebSocket 推送**：实时状态展示，提升运维效率

> **风险提示**：监控系统本身也需要监控。Prometheus 挂了、Grafana 告警规则配错了、通知渠道失效——这些都可能导致"监控盲区"。建议为关键监控组件设置独立的存活检测。

### 练习二

**思路**：基于 JSONL 文件实现高效查询，避免加载整个文件。

**答案**：

```python
import json
from datetime import datetime
from pathlib import Path
from typing import List, Optional


class LogQuery:
    """日志查询工具"""

    def __init__(self, log_dir: str = "./logs"):
        self.log_dir = Path(log_dir)

    def query(
        self,
        category: str,
        start_time: Optional[datetime] = None,
        end_time: Optional[datetime] = None,
        level: Optional[str] = None,
        trade_id: Optional[str] = None,
        limit: int = 100,
    ) -> List[dict]:
        log_file = self.log_dir / f"{category}.log"
        if not log_file.exists():
            return []

        results = []
        with open(log_file, "r", encoding="utf-8") as f:
            for line in f:
                try:
                    entry = json.loads(line)
                except json.JSONDecodeError:
                    continue

                ts = datetime.fromisoformat(entry["timestamp"])
                if start_time and ts < start_time:
                    continue
                if end_time and ts > end_time:
                    continue
                if level and entry.get("level") != level.upper():
                    continue
                if trade_id and entry.get("trade_id") != trade_id:
                    continue

                results.append(entry)
                if len(results) >= limit:
                    break

        return results

    def trace_trade(self, trade_id: str) -> List[dict]:
        """追踪某笔交易的完整生命周期"""
        all_logs = []
        for category in ["trade", "risk", "system"]:
            all_logs.extend(self.query(category, trade_id=trade_id))
        all_logs.sort(key=lambda x: x["timestamp"])
        return all_logs
```

**要点**：
- `trace_trade` 方法可以跨模块追踪同一笔交易的完整链路
- `limit` 参数防止查询返回过多数据
- JSONL 格式支持流式读取，不需要加载整个文件到内存
