# 交易接口对接

> 策略再好，如果不能正确下单，一切都是空谈。交易接口是量化交易的最后一公里。

---

## 场景引入

你用 Python 写好了策略，回测结果很满意，现在想接入实盘。第一个问题就是：怎么让 Python 程序下单？

答案是交易接口（API）。不同的市场有不同的接口：A 股用券商 API 或 CTP，美股用 Interactive Brokers 或 Alpaca，加密货币用交易所 REST/WebSocket API。每种接口的协议、数据格式、延迟特性都不同。

本课将讲解交易接口的核心概念，并用 A 股场景演示接口对接的工程实践。

---

## 学习目标

完成本课学习后，你将能够：

1. 理解交易接口的类型：REST API、WebSocket、FIX 协议
2. 掌握 A 股场景下的主要接口方案（券商 API、CTP、模拟盘）
3. 实现一个统一的交易接口抽象层
4. 理解接口对接中的常见问题与解决方案

## 核心概念

### 一、交易接口类型

```
交易接口类型对比：

  ┌─────────────┬────────────────┬────────────────┬────────────────┐
  │  类型         │ REST API       │ WebSocket      │ FIX 协议       │
  ├─────────────┼────────────────┼────────────────┼────────────────┤
  │  通信方式     │ 请求-响应      │ 全双工推送      │ 全双工推送      │
  │  延迟         │ 100-500ms      │ 10-50ms        │ 1-10ms         │
  │  适用场景     │ 低频交易       │ 实时行情+交易   │ 高频交易       │
  │  复杂度       │ 低             │ 中             │ 高             │
  │  典型用户     │ 个人量化       │ 专业量化       │ 机构量化       │
  └─────────────┴────────────────┴────────────────┴────────────────┘
```

### 二、A 股交易接口方案

```
A 股量化交易接口方案：

  ┌──────────────────────────────────────────────────────────┐
  │  方案 1：券商 API（恒生/讯投/同花顺）                       │
  │  - 通过券商提供的 SDK 下单                                 │
  │  - 需要开通程序化交易权限                                   │
  │  - 延迟：50-200ms                                         │
  │  - 适合：中低频策略                                        │
  ├──────────────────────────────────────────────────────────┤
  │  方案 2：CTP 接口                                          │
  │  - 期货市场的标准接口，也有股票 CTP                         │
  │  - C++ 接口，Python 通过 ctpbee/vnpy 封装                  │
  │  - 延迟：1-10ms                                           │
  │  - 适合：期货/期权高频策略                                  │
  ├──────────────────────────────────────────────────────────┤
  │  方案 3：模拟盘接口                                        │
  │  - 实盘前的验证环节                                        │
  │  - 同花顺模拟炒股 / 腾讯模拟盘                              │
  │  - 不需要真实资金                                          │
  │  - 适合：策略验证、教学                                     │
  ├──────────────────────────────────────────────────────────┤
  │  方案 4：第三方交易框架                                     │
  │  - vnpy / backtrader-live / zipline-live                  │
  │  - 封装了多种接口，统一 API                                 │
  │  - 适合：快速接入、多接口统一                               │
  └──────────────────────────────────────────────────────────┘
```

### 三、统一接口抽象

无论底层用什么接口，上层策略代码应该使用统一的 API。这就是"适配器模式"。

```
统一接口架构：

  ┌─────────────────────────────────────────────────────┐
  │                    策略层                            │
  │  strategy.buy('SH.600000', 100, price=10.5)         │
  └──────────────────────┬──────────────────────────────┘
                         │
                         ▼
  ┌─────────────────────────────────────────────────────┐
  │                  统一交易接口                         │
  │  class TradingInterface:                            │
  │      def buy()                                      │
  │      def sell()                                     │
  │      def cancel()                                   │
  │      def get_position()                             │
  │      def get_balance()                              │
  └────────┬────────────┬────────────┬─────────────────┘
           │            │            │
           ▼            ▼            ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 券商API   │  │ CTP接口   │  │ 模拟盘    │
  │ Adapter  │  │ Adapter  │  │ Adapter  │
  └──────────┘  └──────────┘  └──────────┘
```

## 代码示例

```python
"""
统一交易接口实现
支持券商 API、模拟盘两种后端
"""

import time
import uuid
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Dict, List, Optional, Callable
import numpy as np
import pandas as pd


# ========== 1. 统一数据结构 ==========

class OrderSide(Enum):
    BUY = "buy"
    SELL = "sell"


class OrderType(Enum):
    MARKET = "market"
    LIMIT = "limit"


@dataclass
class TradeOrder:
    order_id: str
    symbol: str
    side: OrderSide
    quantity: int
    order_type: OrderType = OrderType.MARKET
    limit_price: float = 0.0
    status: str = "created"
    filled_qty: int = 0
    filled_price: float = 0.0
    commission: float = 0.0
    created_at: datetime = field(default_factory=datetime.now)


@dataclass
class Position:
    symbol: str
    quantity: int
    avg_price: float
    market_value: float = 0.0
    unrealized_pnl: float = 0.0


@dataclass
class Account:
    cash: float
    total_value: float
    positions: List[Position]
    available: float = 0.0


# ========== 2. 抽象接口 ==========

class TradingBackend(ABC):
    """交易后端抽象基类"""

    @abstractmethod
    def connect(self) -> bool:
        """连接到交易服务器"""
        pass

    @abstractmethod
    def disconnect(self):
        """断开连接"""
        pass

    @abstractmethod
    def submit_order(self, order: TradeOrder) -> TradeOrder:
        """提交订单"""
        pass

    @abstractmethod
    def cancel_order(self, order_id: str) -> bool:
        """撤销订单"""
        pass

    @abstractmethod
    def get_account(self) -> Account:
        """获取账户信息"""
        pass

    @abstractmethod
    def get_positions(self) -> List[Position]:
        """获取持仓"""
        pass

    @abstractmethod
    def get_order_status(self, order_id: str) -> TradeOrder:
        """查询订单状态"""
        pass


# ========== 3. 模拟盘后端 ==========

class SimulatedBackend(TradingBackend):
    """模拟交易后端"""

    def __init__(self, initial_capital: float = 1_000_000,
                 commission_rate: float = 0.0003,
                 slippage_rate: float = 0.001):
        self.initial_capital = initial_capital
        self.cash = initial_capital
        self.commission_rate = commission_rate
        self.slippage_rate = slippage_rate
        self.positions: Dict[str, Position] = {}
        self.orders: Dict[str, TradeOrder] = {}
        self.prices: Dict[str, float] = {}
        self.connected = False
        self._order_history: List[TradeOrder] = []

    def connect(self) -> bool:
        self.connected = True
        print("[模拟盘] 已连接")
        return True

    def disconnect(self):
        self.connected = False
        print("[模拟盘] 已断开")

    def update_prices(self, prices: Dict[str, float]):
        """更新行情（模拟盘需要外部提供行情）"""
        self.prices.update(prices)
        # 更新持仓市值
        for symbol, pos in self.positions.items():
            if symbol in self.prices:
                pos.market_value = pos.quantity * self.prices[symbol]
                pos.unrealized_pnl = (self.prices[symbol] - pos.avg_price) * pos.quantity

    def submit_order(self, order: TradeOrder) -> TradeOrder:
        if not self.connected:
            order.status = "rejected"
            return order

        price = self.prices.get(order.symbol, order.limit_price)
        if price <= 0:
            order.status = "rejected"
            return order

        # 滑点
        if order.side == OrderSide.BUY:
            exec_price = price * (1 + self.slippage_rate)
        else:
            exec_price = price * (1 - self.slippage_rate)

        # 检查资金/持仓
        if order.side == OrderSide.BUY:
            cost = exec_price * order.quantity
            commission = max(cost * self.commission_rate, 5.0)
            if cost + commission > self.cash:
                order.status = "rejected"
                return order
            # 扣减资金
            self.cash -= cost + commission
            # 更新持仓
            pos = self.positions.get(order.symbol)
            if pos and pos.quantity > 0:
                total = pos.avg_price * pos.quantity + exec_price * order.quantity
                pos.quantity += order.quantity
                pos.avg_price = total / pos.quantity
            else:
                self.positions[order.symbol] = Position(
                    symbol=order.symbol,
                    quantity=order.quantity,
                    avg_price=exec_price,
                    market_value=exec_price * order.quantity
                )
        else:
            pos = self.positions.get(order.symbol)
            if not pos or pos.quantity < order.quantity:
                order.status = "rejected"
                return order
            # 卖出
            proceeds = exec_price * order.quantity
            commission = max(proceeds * self.commission_rate, 5.0) + proceeds * 0.001
            self.cash += proceeds - commission
            pos.quantity -= order.quantity
            if pos.quantity == 0:
                del self.positions[order.symbol]

        order.status = "filled"
        order.filled_qty = order.quantity
        order.filled_price = exec_price
        order.commission = commission if 'commission' in dir() else 0
        self.orders[order.order_id] = order
        self._order_history.append(order)

        return order

    def cancel_order(self, order_id: str) -> bool:
        if order_id in self.orders:
            self.orders[order_id].status = "cancelled"
            return True
        return False

    def get_account(self) -> Account:
        total = self.cash + sum(p.market_value for p in self.positions.values())
        return Account(
            cash=self.cash,
            total_value=total,
            positions=list(self.positions.values()),
            available=self.cash
        )

    def get_positions(self) -> List[Position]:
        return [p for p in self.positions.values() if p.quantity > 0]

    def get_order_status(self, order_id: str) -> TradeOrder:
        return self.orders.get(order_id)


# ========== 4. 统一交易接口 ==========

class TradingInterface:
    """统一交易接口"""

    def __init__(self, backend: TradingBackend):
        self.backend = backend
        self._signal_log: List[dict] = []

    def connect(self) -> bool:
        return self.backend.connect()

    def disconnect(self):
        self.backend.disconnect()

    def buy(self, symbol: str, quantity: int, price: float = 0,
            order_type: OrderType = OrderType.MARKET) -> TradeOrder:
        """买入"""
        order = TradeOrder(
            order_id=f"ORD_{uuid.uuid4().hex[:8].upper()}",
            symbol=symbol,
            side=OrderSide.BUY,
            quantity=quantity,
            order_type=order_type,
            limit_price=price,
        )
        result = self.backend.submit_order(order)
        self._signal_log.append({
            'action': 'buy', 'symbol': symbol,
            'quantity': quantity, 'price': price,
            'status': result.status, 'timestamp': datetime.now()
        })
        return result

    def sell(self, symbol: str, quantity: int, price: float = 0,
             order_type: OrderType = OrderType.MARKET) -> TradeOrder:
        """卖出"""
        order = TradeOrder(
            order_id=f"ORD_{uuid.uuid4().hex[:8].upper()}",
            symbol=symbol,
            side=OrderSide.SELL,
            quantity=quantity,
            order_type=order_type,
            limit_price=price,
        )
        result = self.backend.submit_order(order)
        self._signal_log.append({
            'action': 'sell', 'symbol': symbol,
            'quantity': quantity, 'price': price,
            'status': result.status, 'timestamp': datetime.now()
        })
        return result

    def get_account(self) -> Account:
        return self.backend.get_account()

    def get_positions(self) -> List[Position]:
        return self.backend.get_positions()

    def get_signal_log(self) -> pd.DataFrame:
        return pd.DataFrame(self._signal_log)


# ========== 5. 运行演示 ==========

def run_trading_demo():
    """演示交易接口使用"""
    print("=" * 60)
    print("交易接口对接演示")
    print("=" * 60)

    # 创建模拟盘后端
    backend = SimulatedBackend(initial_capital=1_000_000)
    trading = TradingInterface(backend)

    # 连接
    trading.connect()

    # 更新行情
    backend.update_prices({
        'SH.600000': 10.50,
        'SH.600036': 35.80,
        'SZ.000001': 12.30,
    })

    # 下单
    print("\n--- 交易操作 ---")
    result = trading.buy('SH.600000', 1000, price=10.50)
    print(f"买入 SH.600000: {result.status}, 成交价: {result.filled_price:.2f}")

    result = trading.buy('SH.600036', 500, price=35.80)
    print(f"买入 SH.600036: {result.status}, 成交价: {result.filled_price:.2f}")

    result = trading.sell('SH.600000', 500, price=10.60)
    print(f"卖出 SH.600000: {result.status}, 成交价: {result.filled_price:.2f}")

    # 查看账户
    account = trading.get_account()
    print(f"\n--- 账户状态 ---")
    print(f"现金: {account.cash:,.2f}")
    print(f"总价值: {account.total_value:,.2f}")

    # 查看持仓
    positions = trading.get_positions()
    print(f"\n--- 持仓 ---")
    for pos in positions:
        print(f"  {pos.symbol}: {pos.quantity}股, 均价{pos.avg_price:.2f}, "
              f"市值{pos.market_value:,.2f}")

    # 交易日志
    log = trading.get_signal_log()
    print(f"\n--- 交易日志 ---")
    print(log.to_string(index=False))

    trading.disconnect()
    return trading

trading = run_trading_demo()
```

## 常见误区

### 误区一：不做接口测试就上实盘

接口对接中充满了坑：时区问题、数据格式差异、订单状态同步延迟。必须在模拟盘上充分测试后再接入实盘。

### 误区二：忽略接口的限流

大部分交易 API 有调用频率限制（如每秒 10 次）。如果策略频繁查询订单状态，可能触发限流导致下单失败。

### 误区三：不做断线重连

网络不稳定是常态。必须实现自动重连机制，并在重连后同步订单和持仓状态。

## 小结与练习

### 小结

1. 交易接口类型包括 REST API、WebSocket、FIX 协议，延迟从高到低
2. A 股场景下，券商 API 适合中低频策略，CTP 适合高频策略
3. 统一接口抽象（适配器模式）让策略代码与具体接口解耦
4. 模拟盘是实盘前的必经环节，必须在模拟盘上验证接口逻辑

> **风险提示**：本课内容仅供教学，不构成投资建议。实盘交易存在亏损风险，请务必在模拟盘验证后再用小资金实盘。

## 参考答案

### 练习一

**思路**：在 submit_order 中判断订单类型和价格关系。

**答案**：

```python
def submit_limit_order(self, order: TradeOrder) -> TradeOrder:
    """限价单处理"""
    price = self.prices.get(order.symbol, 0)
    if price <= 0:
        order.status = "pending"
        return order

    if order.side == OrderSide.BUY:
        if price <= order.limit_price:
            exec_price = order.limit_price
            # 执行买入逻辑...
            order.status = "filled"
            order.filled_price = exec_price
        else:
            order.status = "pending"
    else:
        if price >= order.limit_price:
            exec_price = order.limit_price
            # 执行卖出逻辑...
            order.status = "filled"
            order.filled_price = exec_price
        else:
            order.status = "pending"

    return order
```

**要点**：
- 限价单不一定立即成交，需要持续监控价格
- 实盘中限价单会在交易所排队等待成交

### 练习二

**思路**：用重试逻辑包装 connect 方法。

**答案**：

```python
class TradingInterfaceWithReconnect(TradingInterface):
    """带断线重连的交易接口"""

    def __init__(self, backend: TradingBackend, max_retries: int = 10, retry_interval: int = 5):
        super().__init__(backend)
        self.max_retries = max_retries
        self.retry_interval = retry_interval
        self.is_connected = False

    def connect_with_retry(self) -> bool:
        """带重试的连接"""
        for attempt in range(1, self.max_retries + 1):
            try:
                result = self.backend.connect()
                if result:
                    self.is_connected = True
                    print(f"连接成功（第 {attempt} 次尝试）")
                    return True
            except Exception as e:
                print(f"连接失败（第 {attempt} 次）: {e}")

            if attempt < self.max_retries:
                print(f"等待 {self.retry_interval} 秒后重试...")
                time.sleep(self.retry_interval)

        print(f"连接失败，已重试 {self.max_retries} 次")
        return False

    def check_and_reconnect(self):
        """检查连接状态，断开则重连"""
        if not self.is_connected:
            print("连接已断开，尝试重连...")
            self.connect_with_retry()
```

**要点**：
- 重连后需要同步持仓和订单状态
- 实际中还需要实现心跳检测来判断连接是否断开
