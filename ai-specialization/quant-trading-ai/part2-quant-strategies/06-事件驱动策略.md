# 事件驱动策略

> 财报发布后股价大幅波动，能否系统性捕捉？理解事件驱动的量化方法。

## 场景引入

2024 年 1 月，某科技公司发布财报，营收超预期 20%，股价当天跳涨 15%。但有趣的是，接下来的一周股价又涨了 8%。这不是偶然——学术研究发现，**财报发布后的价格调整是渐进的，通常持续 1-3 个月**。这个现象被称为"盈余公告后漂移"（Post-Earnings Announcement Drift, PEAD）。

事件驱动策略的核心思想是：**市场对新信息的反应不是瞬间完成的，而是有一个渐进的过程**。这个过程创造了系统性的交易机会。

常见的事件类型包括：
- **财报发布**：PEAD 策略
- **分红/回购**：股利事件策略
- **分析师评级变动**：分析师推荐策略
- **并购重组**：并购套利策略
- **指数成分调整**：指数再平衡策略

本课将重点讲解财报事件和分红事件的量化策略实现。

5. 评估事件驱动策略的风险和局限性

## 核心概念

### 一、事件窗口分析

事件窗口分析是事件驱动策略的基础框架。它通过定义"事件窗口"和"估计窗口"，计算事件发生前后的异常收益。

```
事件窗口分析的时间轴：

  估计窗口          事件窗口         后事件窗口
  [-250, -30]      [-5, +20]       [+21, +60]
       │               │                │
       ▼               ▼                ▼
  ┌─────────┐    ┌───────────┐    ┌───────────┐
  │ 用于估计 │    │ 事件发生  │    │ 观察后续  │
  │ 正常收益 │    │ 前后的    │    │ 价格行为  │
  │ 模型参数 │    │ 异常收益  │    │           │
  └─────────┘    └───────────┘    └───────────┘

异常收益 (AR) = 实际收益 - 期望收益
累积异常收益 (CAR) = 事件窗口内 AR 的累加
```

```python
"""
事件窗口分析框架
"""

import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)


def generate_event_data(n_stocks=100, n_days=300, event_day=200):
    """
    生成模拟事件数据

    参数：
        n_stocks: 股票数量
        n_days: 总天数
        event_day: 事件发生日

    返回：
        returns: 收益率 DataFrame
        market_return: 市场收益率
        event_dates: 每只股票的事件日期
        event_returns: 事件日的异常收益（模拟）
    """
    dates = pd.date_range('2023-01-01', periods=n_days, freq='B')
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    # 市场收益
    market_return = pd.Series(np.random.normal(0.0003, 0.01, n_days), index=dates)

    # 个股收益（带 beta）
    betas = np.random.uniform(0.5, 1.5, n_stocks)
    returns = pd.DataFrame(index=dates, columns=stock_ids, dtype=float)

    for i, stock in enumerate(stock_ids):
        alpha = np.random.normal(0, 0.001)
        epsilon = np.random.normal(0, 0.015, n_days)
        returns[stock] = alpha + betas[i] * market_return + epsilon

    # 事件日异常收益
    event_returns = np.random.normal(0.03, 0.05, n_stocks)  # 平均 3% 正向异常收益
    event_dates = {}

    for i, stock in enumerate(stock_ids):
        event_date = dates[event_day + np.random.randint(-10, 10)]
        event_dates[stock] = event_date
        # 事件日及之后几天有异常收益
        event_idx = dates.get_loc(event_date)
        for d in range(3):  # 异常收益持续 3 天
            if event_idx + d < n_days:
                returns.iloc[event_idx + d][stock] += event_returns[i] / 3

    return returns, market_return, event_dates, event_returns


def calculate_abnormal_returns(returns, market_return, event_date, stock,
                                estimation_window=(-250, -30),
                                event_window=(-5, 20)):
    """
    计算异常收益

    步骤：
    1. 在估计窗口内，用市场模型估计 alpha 和 beta
    2. 用估计的 alpha 和 beta 计算事件窗口内的期望收益
    3. 异常收益 = 实际收益 - 期望收益

    参数：
        returns: 收益率 DataFrame
        market_return: 市场收益率 Series
        event_date: 事件日期
        stock: 股票代码
        estimation_window: 估计窗口（相对于事件日）
        event_window: 事件窗口（相对于事件日）

    返回：
        ar: 异常收益 Series
        car: 累积异常收益 Series
    """
    dates = returns.index
    event_idx = dates.get_loc(event_date)

    # 估计窗口
    est_start = max(0, event_idx + estimation_window[0])
    est_end = event_idx + estimation_window[1]

    est_returns = returns[stock].iloc[est_start:est_end]
    est_market = market_return.iloc[est_start:est_end]

    # 市场模型回归：R_i = alpha + beta * R_m
    valid = ~(est_returns.isna() | est_market.isna())
    X = np.column_stack([np.ones(valid.sum()), est_market[valid].values])
    y = est_returns[valid].values
    betas, _, _, _ = np.linalg.lstsq(X, y, rcond=None)
    alpha_est, beta_est = betas

    # 事件窗口
    evt_start = max(0, event_idx + event_window[0])
    evt_end = min(len(dates), event_idx + event_window[1] + 1)

    evt_returns = returns[stock].iloc[evt_start:evt_end]
    evt_market = market_return.iloc[evt_start:evt_end]

    # 期望收益
    expected_returns = alpha_est + beta_est * evt_market

    # 异常收益
    ar = evt_returns - expected_returns

    # 累积异常收益
    car = ar.cumsum()

    # 相对于事件日的天数
    relative_days = range(event_window[0], event_window[0] + len(ar))
    ar.index = relative_days
    car.index = relative_days

    return ar, car


def event_study(returns, market_return, event_dates, stocks,
                estimation_window=(-250, -30), event_window=(-5, 20)):
    """
    事件研究：对所有股票计算异常收益并汇总

    参数：
        returns: 收益率 DataFrame
        market_return: 市场收益率 Series
        event_dates: 事件日期字典
        stocks: 股票列表
        estimation_window: 估计窗口
        event_window: 事件窗口

    返回：
        car_df: 所有股票的 CAR DataFrame
        car_mean: 平均 CAR
        car_t_stat: CAR 的 t 统计量
    """
    car_dict = {}

    for stock in stocks:
        if stock not in event_dates:
            continue
        event_date = event_dates[stock]
        try:
            ar, car = calculate_abnormal_returns(
                returns, market_return, event_date, stock,
                estimation_window, event_window
            )
            car_dict[stock] = car
        except Exception:
            continue

    car_df = pd.DataFrame(car_dict)
    car_mean = car_df.mean(axis=1)

    # t 检验：CAR 是否显著不为 0
    car_final = car_df.iloc[-1]  # 事件窗口最后一天的 CAR
    t_stat, p_value = stats.ttest_1samp(car_final.dropna(), 0)

    return car_df, car_mean, t_stat, p_value


# ========== 运行事件研究 ==========

print("=" * 60)
print("事件窗口分析")
print("=" * 60)

returns, market_return, event_dates, true_event_returns = generate_event_data()
stocks = list(event_dates.keys())

car_df, car_mean, t_stat, p_value = event_study(
    returns, market_return, event_dates, stocks
)

print(f"\n事件研究结果:")
print(f"  样本股票数: {len(car_df.columns)}")
print(f"  事件窗口: [-5, +20]")
print(f"  累积异常收益 (CAR[-5,+20]):")
print(f"    均值: {car_mean.iloc[-1]:.4%}")
print(f"    t 统计量: {t_stat:.4f}")
print(f"    p 值: {p_value:.4f}")
print(f"    显著性: {'是' if p_value < 0.05 else '否'} (5% 水平)")

# 显示 CAR 时间路径
print(f"\nCAR 时间路径:")
print(f"{'相对天数':<10} {'平均CAR':>12} {'显著性':>10}")
print("-" * 35)
for day in [-5, -3, -1, 0, 1, 3, 5, 10, 15, 20]:
    if day in car_mean.index:
        car_val = car_mean[day]
        # 用单样本 t 检验检验当天 CAR
        day_car = car_df.loc[day].dropna()
        t, p = stats.ttest_1samp(day_car, 0)
        sig = '***' if p < 0.01 else '**' if p < 0.05 else '*' if p < 0.1 else ''
        print(f"  {day:>3}        {car_val:>12.4%}    {sig}")

# ASCII CAR 图
print(f"\nCAR 可视化:")
max_abs = max(abs(car_mean.min()), abs(car_mean.max()))
for day in car_mean.index:
    car_val = car_mean[day]
    bar_len = int(car_val / max_abs * 30)
    bar = '█' * abs(bar_len)
    sign = '+' if car_val >= 0 else '-'
    if day % 5 == 0 or day == 0:
        print(f"  {day:>3}: {sign}{bar} {car_val:.4%}")
```

### 二、PEAD 策略（盈余公告后漂移）

PEAD 是最经典的事件驱动策略。当公司发布超预期的财报时，股价会在之后的 1-3 个月内继续向预期方向调整。

```
PEAD 的经济逻辑：

  财报发布 → 投资者逐步消化信息 → 价格渐进调整
  
  为什么不是瞬间调整？
  1. 信息不对称：机构投资者比散户更早理解财报含义
  2. 注意力有限：很多投资者不会立即阅读财报
  3. 交易限制：某些投资者不能立即交易（如基金调仓限制）
  4. 锚定效应：投资者对旧信息有锚定，对新信息反应不足

  SUE（Standardized Unexpected Earnings）= (实际EPS - 预期EPS) / 标准差
  
  SUE > 2  → 大幅超预期 → 正向漂移
  SUE < -2 → 大幅低于预期 → 负向漂移
```

```python
"""
PEAD 策略实现
"""

import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)


def generate_earnings_data(n_stocks=200, n_events=4):
    """
    生成模拟财报数据

    每只股票有 n_events 次财报发布
    """
    dates = pd.date_range('2022-01-01', periods=500, freq='B')
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    # 市场收益
    market_return = pd.Series(np.random.normal(0.0003, 0.01, 500), index=dates)

    # 个股收益
    returns = pd.DataFrame(index=dates, columns=stock_ids, dtype=float)
    betas = np.random.uniform(0.5, 1.5, n_stocks)

    for i, stock in enumerate(stock_ids):
        epsilon = np.random.normal(0, 0.015, 500)
        returns[stock] = betas[i] * market_return + epsilon

    # 财报事件
    earnings_events = []
    for i, stock in enumerate(stock_ids):
        for e in range(n_events):
            event_day = 60 + e * 100 + np.random.randint(-5, 5)
            if event_day >= 500:
                continue

            # SUE（标准化意外盈余）
            sue = np.random.normal(0, 1.5)

            # 事件日异常收益（与 SUE 正相关）
            event_abnormal = sue * 0.015 + np.random.normal(0, 0.02)

            # PEAD：事件后漂移（SUE 越高，漂移越大）
            drift_days = 20
            daily_drift = sue * 0.002 / drift_days  # 20 天漂移

            # 加入收益
            for d in range(drift_days):
                if event_day + d < 500:
                    returns.iloc[event_day + d][stock] += daily_drift
            returns.iloc[event_day][stock] += event_abnormal

            earnings_events.append({
                'stock': stock,
                'event_date': dates[event_day],
                'sue': sue,
                'event_return': event_abnormal
            })

    earnings_df = pd.DataFrame(earnings_events)
    return returns, market_return, earnings_df


def pead_strategy(returns, market_return, earnings_df,
                  sue_threshold=1.5, holding_days=20):
    """
    PEAD 策略

    规则：
    1. 财报发布后，筛选 SUE > threshold 的股票
    2. 买入超预期股票，持有 holding_days 天
    3. 做空低于预期股票（可选）

    参数：
        returns: 收益率 DataFrame
        market_return: 市场收益率 Series
        earnings_df: 财报事件 DataFrame
        sue_threshold: SUE 阈值
        holding_days: 持有天数

    返回：
        portfolio: 组合净值
        trades: 交易记录
    """
    dates = returns.index
    capital = 100000
    portfolio_values = []
    trades = []
    holdings = {}  # {stock: (entry_date, entry_price, shares)}

    for t in range(len(dates)):
        current_date = dates[t]

        # 检查是否有新的财报事件
        today_events = earnings_df[earnings_df['event_date'] == current_date]
        for _, event in today_events.iterrows():
            stock = event['stock']
            sue = event['sue']

            if sue > sue_threshold and stock not in holdings:
                # 买入超预期股票
                price = (1 + returns[stock]).cumprod().iloc[t] * 100  # 模拟价格
                shares = int(capital * 0.05 / price)  # 每只股票用 5% 资金
                if shares > 0:
                    holdings[stock] = {
                        'entry_date': current_date,
                        'entry_idx': t,
                        'shares': shares,
                        'entry_price': price
                    }
                    trades.append({
                        'date': current_date,
                        'stock': stock,
                        'action': '买入',
                        'sue': sue,
                        'price': price
                    })

        # 检查持仓是否到期
        expired = []
        for stock, info in holdings.items():
            if t - info['entry_idx'] >= holding_days:
                price = (1 + returns[stock]).cumprod().iloc[t] * 100
                pnl = (price - info['entry_price']) * info['shares']
                capital += pnl
                trades.append({
                    'date': current_date,
                    'stock': stock,
                    'action': '卖出',
                    'pnl': pnl,
                    'price': price
                })
                expired.append(stock)

        for stock in expired:
            del holdings[stock]

        # 计算组合价值
        holding_value = 0
        for stock, info in holdings.items():
            price = (1 + returns[stock]).cumprod().iloc[t] * 100
            holding_value += price * info['shares']

        portfolio_values.append(capital + holding_value)

    portfolio = pd.Series(portfolio_values, index=dates)
    trades_df = pd.DataFrame(trades)

    return portfolio, trades_df


# ========== 运行 PEAD 策略 ==========

print("=" * 60)
print("PEAD 策略回测")
print("=" * 60)

returns, market_return, earnings_df = generate_earnings_data()

print(f"\n财报数据统计:")
print(f"  股票数量: {earnings_df['stock'].nunique()}")
print(f"  财报事件数: {len(earnings_df)}")
print(f"  SUE 均值: {earnings_df['sue'].mean():.4f}")
print(f"  SUE 标准差: {earnings_df['sue'].std():.4f}")

# 运行策略
portfolio, trades = pead_strategy(returns, market_return, earnings_df,
                                   sue_threshold=1.5, holding_days=20)

total_return = portfolio.iloc[-1] / 100000 - 1
n_years = len(returns) / 252
annual_return = (1 + total_return) ** (1 / n_years) - 1
daily_returns = portfolio.pct_change().dropna()
annual_vol = daily_returns.std() * np.sqrt(252)
sharpe = annual_return / annual_vol if annual_vol > 0 else 0
max_dd = (portfolio / portfolio.expanding().max() - 1).min()

print(f"\n策略统计:")
print(f"  总收益: {total_return:.2%}")
print(f"  年化收益: {annual_return:.2%}")
print(f"  年化波动率: {annual_vol:.2%}")
print(f"  夏普比率: {sharpe:.2f}")
print(f"  最大回撤: {max_dd:.2%}")

# 交易统计
buy_trades = trades[trades['action'] == '买入']
sell_trades = trades[trades['action'] == '卖出']

print(f"\n交易统计:")
print(f"  买入次数: {len(buy_trades)}")
print(f"  卖出次数: {len(sell_trades)}")

if len(sell_trades) > 0 and 'pnl' in sell_trades.columns:
    wins = (sell_trades['pnl'] > 0).sum()
    win_rate = wins / len(sell_trades)
    avg_pnl = sell_trades['pnl'].mean()
    print(f"  胜率: {win_rate:.2%}")
    print(f"  平均盈亏: {avg_pnl:.2f}")

# SUE 分层分析
print(f"\nSUE 分层分析:")
sue_groups = pd.cut(earnings_df['sue'], bins=[-np.inf, -2, -1, 0, 1, 2, np.inf],
                     labels=['<-2', '-2~-1', '-1~0', '0~1', '1~2', '>2'])
sue_analysis = earnings_df.groupby(sue_groups, observed=True)['event_return'].agg(['mean', 'count'])
sue_analysis.columns = ['平均事件收益', '事件数量']
print(sue_analysis.round(4))
```

### 三、分红事件策略

分红（股利）事件也包含信息含量。高分红通常意味着公司现金流充裕、管理层对未来有信心。

```python
"""
分红事件驱动策略
"""

import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)


def generate_dividend_data(n_stocks=100, n_days=500):
    """生成模拟分红事件数据"""
    dates = pd.date_range('2022-01-01', periods=n_days, freq='B')
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    # 市场收益
    market_return = pd.Series(np.random.normal(0.0003, 0.01, n_days), index=dates)

    # 个股收益
    returns = pd.DataFrame(index=dates, columns=stock_ids, dtype=float)
    betas = np.random.uniform(0.5, 1.5, n_stocks)

    for i, stock in enumerate(stock_ids):
        epsilon = np.random.normal(0, 0.015, n_days)
        returns[stock] = betas[i] * market_return + epsilon

    # 分红事件
    dividend_events = []
    for i, stock in enumerate(stock_ids):
        # 每只股票每年分红 1-2 次
        for quarter in [0, 2]:  # 第 1 季度和第 3 季度
            event_day = 60 + quarter * 120 + np.random.randint(-10, 10)
            if event_day >= n_days:
                continue

            # 股息率（模拟：大部分 1-5%，少数特别高）
            div_yield = np.random.beta(2, 10) * 0.08
            if np.random.random() < 0.1:  # 10% 的公司高分红
                div_yield = np.random.uniform(0.05, 0.10)

            # 分红公告日异常收益（高分红有正向异常收益）
            event_abnormal = div_yield * 2 + np.random.normal(0, 0.01)

            # 除息日（通常在公告后 1 个月）
            ex_div_day = event_day + 20
            if ex_div_day < n_days:
                # 除息日价格下跌（约等于分红金额）
                returns.iloc[ex_div_day][stock] -= div_yield

            # 公告日异常收益
            returns.iloc[event_day][stock] += event_abnormal

            dividend_events.append({
                'stock': stock,
                'event_date': dates[event_day],
                'ex_div_date': dates[min(ex_div_day, n_days-1)],
                'div_yield': div_yield,
                'event_return': event_abnormal
            })

    dividend_df = pd.DataFrame(dividend_events)
    return returns, market_return, dividend_df


def dividend_strategy(returns, market_return, dividend_df,
                      div_yield_threshold=0.03, holding_days=30):
    """
    分红事件策略

    规则：
    1. 分红公告后，筛选股息率 > threshold 的股票
    2. 买入高分红股票，持有到除息日后卖出
    3. 赚取分红公告的正向异常收益

    参数：
        returns: 收益率 DataFrame
        market_return: 市场收益率 Series
        dividend_df: 分红事件 DataFrame
        div_yield_threshold: 股息率阈值
        holding_days: 持有天数

    返回：
        portfolio: 组合净值
        trades: 交易记录
    """
    dates = returns.index
    capital = 100000
    portfolio_values = []
    trades = []
    holdings = {}

    for t in range(len(dates)):
        current_date = dates[t]

        # 检查新的分红公告
        today_events = dividend_df[dividend_df['event_date'] == current_date]
        for _, event in today_events.iterrows():
            stock = event['stock']
            div_yield = event['div_yield']

            if div_yield > div_yield_threshold and stock not in holdings:
                price = (1 + returns[stock]).cumprod().iloc[t] * 100
                shares = int(capital * 0.05 / price)
                if shares > 0:
                    holdings[stock] = {
                        'entry_date': current_date,
                        'entry_idx': t,
                        'shares': shares,
                        'entry_price': price
                    }
                    trades.append({
                        'date': current_date,
                        'stock': stock,
                        'action': '买入',
                        'div_yield': div_yield,
                        'price': price
                    })

        # 检查持仓到期
        expired = []
        for stock, info in holdings.items():
            if t - info['entry_idx'] >= holding_days:
                price = (1 + returns[stock]).cumprod().iloc[t] * 100
                pnl = (price - info['entry_price']) * info['shares']
                capital += pnl
                trades.append({
                    'date': current_date,
                    'stock': stock,
                    'action': '卖出',
                    'pnl': pnl,
                    'price': price
                })
                expired.append(stock)

        for stock in expired:
            del holdings[stock]

        # 计算组合价值
        holding_value = 0
        for stock, info in holdings.items():
            price = (1 + returns[stock]).cumprod().iloc[t] * 100
            holding_value += price * info['shares']

        portfolio_values.append(capital + holding_value)

    portfolio = pd.Series(portfolio_values, index=dates)
    trades_df = pd.DataFrame(trades)

    return portfolio, trades_df


# ========== 运行分红事件策略 ==========

print("=" * 60)
print("分红事件驱动策略回测")
print("=" * 60)

returns, market_return, dividend_df = generate_dividend_data()
```

### 四、事件驱动策略的风险管理

```python
"""
事件驱动策略的风险管理
"""

import numpy as np
import pandas as pd

print("=" * 60)
print("事件驱动策略的风险管理")
print("=" * 60)

print("""
事件驱动策略的主要风险：

1. 事件预测风险
   - 无法预知事件何时发生
   - 财报发布时间可以预期，但突发新闻无法预测
   - 应对：只交易可预期的事件

2. 事件后反转风险
   - 不是所有事件都有漂移，有些事件后价格会反转
   - 超预期太多反而可能下跌（"买预期卖事实"）
   - 应对：设置止损，分散持仓

3. 流动性风险
   - 事件发生后，市场流动性可能突然枯竭
   - 大额交易可能产生严重冲击成本
   - 应对：限制单只股票的持仓比例

4. 数据偏差风险
   - 财报数据可能存在修正（事后修正预期值）
   - 使用修正后的数据会高估策略表现
   - 应对：使用事件发生时的实际预期值

5. 事件聚集风险
   - 财报季（每年 1 月、4 月、7 月、10 月）事件密集
   - 可能导致过度集中持仓
   - 应对：限制同时持有的事件股票数量

风险管理框架：
""")

# 风险管理示例代码
class EventRiskManager:
    """事件驱动策略风险管理器"""

    def __init__(self, max_position_pct=0.05, max_total_exposure=0.5,
                 stop_loss_pct=0.08, max_concurrent_events=10):
        self.max_position_pct = max_position_pct  # 单只股票最大仓位
        self.max_total_exposure = max_total_exposure  # 最大总暴露
        self.stop_loss_pct = stop_loss_pct  # 止损线
        self.max_concurrent_events = max_concurrent_events  # 最大同时事件数

    def check_position_limit(self, capital, price, shares):
        """检查单只股票仓位是否超限"""
        position_value = price * shares
        position_pct = position_value / capital
        return position_pct <= self.max_position_pct

    def check_total_exposure(self, capital, holdings):
        """检查总暴露是否超限"""
        total_value = sum(info['shares'] * info.get('current_price', info['entry_price'])
                         for info in holdings.values())
        return total_value / capital <= self.max_total_exposure

    def check_stop_loss(self, entry_price, current_price):
        """检查是否触发止损"""
        pnl_pct = (current_price - entry_price) / entry_price
        return pnl_pct <= -self.stop_loss_pct

    def check_concurrent_limit(self, holdings):
        """检查同时事件数是否超限"""
        return len(holdings) < self.max_concurrent_events


# 演示风险管理
risk_mgr = EventRiskManager()
capital = 1000000

print(f"风险管理参数:")
print(f"  单只股票最大仓位: {risk_mgr.max_position_pct:.0%}")
print(f"  最大总暴露: {risk_mgr.max_total_exposure:.0%}")
print(f"  止损线: {risk_mgr.stop_loss_pct:.0%}")
print(f"  最大同时事件数: {risk_mgr.max_concurrent_events}")

# 模拟检查
holdings = {f'STOCK_{i:03d}': {'entry_price': 100, 'shares': 500} for i in range(8)}
print(f"\n当前持仓数: {len(holdings)}")
print(f"同时事件限制检查: {'通过' if risk_mgr.check_concurrent_limit(holdings) else '超限'}")

# 新事件检查
new_stock_price = 50
new_shares = 1200
position_check = risk_mgr.check_position_limit(capital, new_stock_price, new_shares)
print(f"\n新事件仓位检查:")
print(f"  股票价格: {new_stock_price}")
print(f"  买入股数: {new_shares}")
print(f"  仓位占比: {new_stock_price * new_shares / capital:.2%}")
print(f"  检查结果: {'通过' if position_check else '超限'}")

# 止损检查
entry_price = 100
current_price = 91
stop_check = risk_mgr.check_stop_loss(entry_price, current_price)
print(f"\n止损检查:")
print(f"  入场价: {entry_price}")
print(f"  当前价: {current_price}")
print(f"  亏损: {(current_price - entry_price) / entry_price:.2%}")
print(f"  止损触发: {'是' if stop_check else '否'}")

print(f"\n{'=' * 60}")
print("风险提示")
print(f"{'=' * 60}")
print("""
事件驱动策略的风险管理要点：
1. 严格控制单只股票仓位（不超过 5%）
2. 限制同时持有的事件股票数量
3. 设置止损线（8-10%）
4. 避免在事件密集期过度集中持仓
```

## 常见误区

### 误区一：用修正后的预期值回测

很多数据库会事后修正分析师预期值。如果你用修正后的预期值来定义"超预期"，你的回测结果会严重高估。一定要用事件发生时的实际预期值。

### 误区二：忽略事件聚集效应

财报季（1 月、4 月、7 月、10 月）会有大量事件同时发生。如果你不控制同时持仓数量，你的组合会高度集中，风险很大。

### 误区三：把事件收益当作策略收益

事件日的异常收益看起来很诱人，但实际策略收益要考虑：
- 你能否提前知道哪些股票会有事件？
- 事件发生时你能否及时交易？
- 交易成本是多少？

### 误区 四：忽略信息泄露

有些事件信息在正式公告前就已经泄露（比如并购重组）。如果你的策略假设在公告日才交易，你会错过前期的异常收益，甚至可能在信息已经反映在价格中时才入场。

## 小结与练习

### 小结

1. 事件窗口分析是事件驱动策略的基础框架，通过估计窗口和事件窗口分离异常收益
2. PEAD 策略利用财报发布后的价格漂移，SUE 越高的股票漂移越大
3. 分红事件策略利用高分红公告的正向异常收益
4. 事件驱动策略需要严格的风险管理：仓位控制、止损、事件聚集管理
5. 数据质量（使用实际预期值而非修正值）对策略表现至关重要

```python
import numpy as np
```

```python
    max_dd = (portfolio / portfolio.expanding().max() - 1).min()

    results.append({
        'holding_days': holding_days,
        'total_return': total_ret,
        'annual_return': annual_ret,
```

- 通常 20-40 天是 PEAD 策略的最优持有期

### 练习三

**思路**：将两个策略的信号组合，分散化持仓。

**答案**：

```python
import numpy as np
import pandas as pd

np.random.seed(42)

# PEAD 策略
returns_earnings, market_return_earnings, earnings_df = generate_earnings_data()
pead_portfolio, _ = pead_strategy(returns_earnings, market_return_earnings, earnings_df)

# 分红策略
returns_div, market_return_div, dividend_df = generate_dividend_data()
div_portfolio, _ = dividend_strategy(returns_div, market_return_div, dividend_df)

# 等权组合
combined_returns = pd.DataFrame({
    'PEAD': pead_portfolio.pct_change(),
    '分红': div_portfolio.pct_change()
}).dropna()

combined_portfolio = (1 + combined_returns.mean(axis=1)).cumprod() * 100000

# 比较
for name, port in [('PEAD', pead_portfolio), ('分红', div_portfolio), ('组合', combined_portfolio)]:
    total_ret = port.iloc[-1] / 100000 - 1
    n_years = len(port) / 252
    annual_ret = (1 + total_ret) ** (1 / n_years) - 1
    daily_ret = port.pct_change().dropna()
    annual_vol = daily_ret.std() * np.sqrt(252)
    sharpe = annual_ret / annual_vol if annual_vol > 0 else 0
    max_dd = (port / port.expanding().max() - 1).min()

    print(f"\n{name} 策略:")
    print(f"  年化收益: {annual_ret:.2%}")
    print(f"  年化波动率: {annual_vol:.2%}")
    print(f"  夏普比率: {sharpe:.2f}")
    print(f"  最大回撤: {max_dd:.2%}")

print(f"\n组合策略的优势:")
print("1. 分散了单一事件类型的风险")
print("2. PEAD 和分红事件的时间分布不同，降低了聚集风险")
print("3. 组合后的夏普比率通常高于单一策略")
```

**要点**：
- 不同事件类型的策略组合可以降低风险
- 组合的关键是事件之间的时间分散性
- 等权组合是最简单的方法，更高级的方法可以用风险平价
