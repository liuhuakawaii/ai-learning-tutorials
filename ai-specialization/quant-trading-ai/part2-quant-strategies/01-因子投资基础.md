# 因子投资基础

> 为什么有些股票长期跑赢市场？理解因子投资的经济直觉与数学框架。

## 场景引入

假设你在 2010 年初有 100 万块钱，面临一个选择：买入沪深 300 指数基金，还是挑选一组"便宜的好公司"长期持有。如果你选了后者，到 2025 年底大概率跑赢指数 3-5 个百分点的年化收益。

这不是运气，而是因为"便宜的好公司"背后隐藏着一个系统性的收益来源——**价值因子**和**质量因子**。几十年的学术研究和实践表明，股票收益可以用少数几个"因子"来解释。理解因子，就是理解股票收益的底层密码。

因子投资的核心假设是：**市场并非完全有效，某些特征（因子）能持续预测股票的超额收益**。这些超额收益可能来自风险补偿，也可能来自投资者的行为偏差，但无论来源如何，它们在几十年的样本中反复出现。

## 核心概念

### 一、什么是因子？

在量化投资中，"因子"是一个能解释或预测股票收益的变量。它的定义非常宽泛：

- **宏观因子**：GDP 增速、通胀率、利率变化
- **基本面因子**：市盈率、市净率、ROE、营收增速
- **技术因子**：动量、换手率、波动率
- **另类因子**：分析师预期、新闻情绪、供应链数据

一个因子要成为"投资因子"，需要满足两个条件：

1. **横截面上有区分度**：不同股票在该因子上的取值有足够差异
2. **对未来收益有预测力**：因子值高的股票和低的股票，未来收益有显著差异

```
因子的本质：将股票收益分解为可解释部分 + 不可解释部分

股票收益 = β₁ × 因子₁ + β₂ × 因子₂ + ... + βₙ × 因子ₙ + α（残差）

其中：
  β = 因子暴露（该股票对因子的敏感度）
  α = 超额收益（因子无法解释的部分，即"真·Alpha"）
```

### 二、因子模型的数学框架

#### 2.1 截面回归（Cross-Sectional Regression）

截面回归是最直观的因子建模方式。在每一个时间截面上，用股票的因子暴露来解释其当期收益：

```
对每个交易日 t：
  Rᵢₜ = αₜ + β₁ₜ × F₁ᵢₜ + β₂ₜ × F₂ᵢₜ + ... + εᵢₜ

其中：
  Rᵢₜ = 股票 i 在时间 t 的收益率
  Fⱼᵢₜ = 股票 i 在因子 j 上的暴露值
  αₜ = 截距（当日所有股票的平均超额收益）
  εᵢₜ = 残差（个股特异性收益）
```

截面回归的含义：**在同一时间点上，比较不同股票的因子暴露与收益的关系**。

例如，今天有 3000 只股票，我们用市净率（PB）去解释它们今天的收益差异。如果低 PB 的股票平均收益更高，说明 PB 因子有负向预测力。

#### 2.2 时序回归（Time-Series Regression）

时序回归反过来，在每只股票的时间序列上，用因子收益来解释个股收益：

```
对每只股票 i：
  Rᵢₜ - Rfₜ = αᵢ + β₁ᵢ × (Rmₜ - Rfₜ) + β₂ᵢ × SMBₜ + β₃ᵢ × HMLₜ + εᵢₜ

其中：
  Rᵢₜ = 股票 i 在时间 t 的收益率
  Rfₜ = 无风险利率
  Rmₜ - Rfₜ = 市场超额收益
  SMBₜ = 规模因子收益（小盘 - 大盘）
  HMLₜ = 价值因子收益（高账面市值比 - 低账面市值比）
  αᵢ = 个股的超额收益（Jensen's Alpha）
```

时序回归的含义：**用一只股票过去的历史数据，估计它对各因子的敏感度**。

```
截面回归 vs 时序回归的区别：

截面回归：
  时间点 → 固定
  样本  → 所有股票
  问题  → "今天，哪些因子解释了股票间的收益差异？"

时序回归：
  股票  → 固定
  样本  → 多个时间点
  问题  → "过去一年，这只股票对市场因子的敏感度是多少？"
```

两种方法在数学上是等价的（在一定条件下），但计算效率和适用场景不同。实践中，截面回归更适合因子研究，时序回归更适合风险归因。

### 三、Fama-French 因子模型

#### 3.1 三因子模型（1993）

Eugene Fama 和 Kenneth French 在 1993 年提出了划时代的三因子模型：

```
Rᵢₜ - Rfₜ = αᵢ + βᵢₘ × (Rmₜ - Rfₜ) + βᵢₛ × SMBₜ + βᵢₕ × HMLₜ + εᵢₜ

三个因子：
  1. 市场因子 (MKT)：Rm - Rf，承担市场风险的补偿
  2. 规模因子 (SMB)：Small Minus Big，小盘股相对大盘股的超额收益
  3. 价值因子 (HML)：High Minus Low，高账面市值比（价值股）相对成长股的超额收益
```

三因子模型的经济直觉：

- **市场因子**：你承担了股市整体下跌的风险，所以获得风险溢价
- **规模因子**：小公司流动性差、信息不透明、破产风险高，投资者要求更高回报
- **价值因子**：便宜的公司往往是"落难"的公司，基本面有隐忧，投资者需要补偿

#### 3.2 五因子模型（2015）

Fama-French 在 2015 年将模型扩展为五因子：

```
Rᵢₜ - Rfₜ = αᵢ + βᵢₘ × MKTₜ + βᵢₛ × SMBₜ + βᵢₕ × HMLₜ
            + βᵢᵣ × RMWₜ + βᵢ𝒸 × CMAₜ + εᵢₜ

新增两个因子：
  4. 盈利因子 (RMW)：Robust Minus Weak，高盈利公司相对低盈利公司的超额收益
  5. 投资因子 (CMA)：Conservative Minus Aggressive，保守投资公司相对激进投资公司的超额收益
```

新增因子的经济直觉：

- **盈利因子**：高盈利的公司基本面更稳健，市场定价偏低，长期有超额收益
- **投资因子**：保守投资（低资产增速）的公司更注重股东回报，激进扩张的公司往往过度投资

```
五因子模型的因子关系图：

                    ┌─────────────┐
                    │  市场因子    │
                    │  (MKT)      │
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
    ┌──────┴──────┐ ┌──────┴──────┐ ┌──────┴──────┐
    │  规模因子    │ │  价值因子    │ │  盈利因子    │
    │  (SMB)      │ │  (HML)      │ │  (RMW)      │
    └─────────────┘ └─────────────┘ └──────┬──────┘
                                           │
                                    ┌──────┴──────┐
                                    │  投资因子    │
                                    │  (CMA)      │
                                    └─────────────┘

因子之间存在相关性，但各自捕获不同的收益来源
```

### 四、因子收益的来源：风险补偿 vs 行为偏差

因子的超额收益从哪来？这是学术界争论了几十年的问题。两种主流解释：

**风险补偿理论（Fama-French 观点）**

因子收益是对承担额外风险的补偿。价值股之所以有超额收益，是因为它们在经济衰退时损失更大。投资者是理性的，因子溢价是"公平"的风险价格。

**行为偏差理论（Shiller、Lakonishok 观点）**

投资者系统性地犯错：过度追捧热门股票（成长股），过度抛弃冷门股票（价值股）。因子收益来自于市场纠偏的过程。

```
两种理论的对比：

                    风险补偿                行为偏差
─────────────────────────────────────────────────────
因子溢价来源      承担风险的补偿          市场定价错误
是否会消失        不会（风险永远存在）     可能（投资者学习）
适用条件          市场基本有效            市场存在系统性偏差
投资策略          长期持有，承受波动      逆向投资，利用错误定价
代表人物          Fama, French           Shiller, Lakonishok

实际中，两种力量同时存在，因子溢价是两者的混合
```

对投资者的启示：**无论哪种理论正确，只要因子溢价持续存在，因子投资就有价值**。但你需要理解每种因子的驱动力，才能判断它是否会在未来消失。

### 五、因子 vs 技术指标

很多初学者会混淆"因子"和"技术指标"。两者有本质区别：

```
因子 vs 技术指标：

因子：
  - 有经济学解释（为什么这个特征能预测收益）
  - 在多个市场、多个时间段上经过验证
  - 通常基于截面排序（今天所有股票按 PB 排序）
  - 持有期长（月度/季度调仓）
  - 目标：捕获系统性超额收益

技术指标：
  - 基于价格/量的统计规律（不一定有经济学解释）
  - 通常在单个标的上使用
  - 通常基于时序信号（均线金叉、死叉）
  - 持有期短（日度/周度）
  - 目标：捕获择时信号

注意：动量既是因子，也是技术指标。
  - 作为因子：截面上，过去 12 个月涨得多的股票，未来 1 个月继续涨
  - 作为技术指标：时序上，价格突破 20 日均线时买入
  区别在于使用方式和经济解释
```

### 六、因子投资的历史演进

```
因子投资发展时间线：

1960s  CAPM 模型（Sharpe, Lintner）
       只有一个因子：市场因子
       股票收益 = β × 市场收益

1970s  Ross 提出 APT（套利定价理论）
       理论上可以有多个因子，但没说具体是哪些

1993   Fama-French 三因子模型
       市场 + 规模 + 价值，三个因子解释了大部分收益差异
       从此"因子动物园"开始扩张

2000s  Carhart 四因子模型
       加入动量因子（MOM）
       因子研究进入"批量发现"时代

2015   Fama-French 五因子模型
       加入盈利（RMW）和投资（CMA）
       试图解释价值因子为何失效

2018   Hou, Xue, Zhang 发表 q-factor 模型
       投资 + 盈利 + 规模 + 市场，四因子
       对 Fama-French 提出挑战

2020s  机器学习因子挖掘
       用深度学习自动发现非线性因子
       "因子动物园"已有 400+ 个因子
       学界开始反思：多少因子是真实的？
```

## 代码示例：截面回归计算个股 Alpha

以下代码演示如何用截面回归方法计算个股的 Alpha。我们模拟一组股票数据，然后用 Fama-French 因子进行截面回归。

```python
"""
截面回归计算个股 Alpha
模拟 100 只股票在 60 个月内的收益数据，
用 Fama-French 三因子进行截面回归，估计每月的 Alpha。
"""

import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)

# ========== 1. 模拟数据 ==========

n_stocks = 100
n_months = 60

# 生成因子收益序列（模拟 Fama-French 三因子）
market_premium = np.random.normal(0.008, 0.04, n_months)  # 月均 0.8%
smb_premium = np.random.normal(0.003, 0.03, n_months)     # 月均 0.3%
hml_premium = np.random.normal(0.004, 0.03, n_months)     # 月均 0.4%

# 生成个股的因子暴露（beta）
stock_market_beta = np.random.uniform(0.6, 1.5, n_stocks)
stock_smb_beta = np.random.uniform(-0.5, 1.5, n_stocks)  # 正=小盘，负=大盘
stock_hml_beta = np.random.uniform(-0.3, 1.2, n_stocks)  # 正=价值，负=成长

# 真实的个股 Alpha（我们设定部分股票有正 Alpha）
true_alpha = np.random.normal(0.001, 0.005, n_stocks)  # 月均 0.1%
true_alpha[:20] += 0.003  # 前 20 只股票有额外正 Alpha

# 生成个股收益矩阵
stock_returns = np.zeros((n_months, n_stocks))
for t in range(n_months):
    for i in range(n_stocks):
        stock_returns[t, i] = (
            true_alpha[i]
            + stock_market_beta[i] * market_premium[t]
            + stock_smb_beta[i] * smb_premium[t]
            + stock_hml_beta[i] * hml_premium[t]
            + np.random.normal(0, 0.03)  # 个股特异性波动
        )

# 构造 DataFrame
dates = pd.date_range('2020-01-01', periods=n_months, freq='ME')
stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]
returns_df = pd.DataFrame(stock_returns, index=dates, columns=stock_ids)

# 因子收益 DataFrame
factor_df = pd.DataFrame({
    'MKT': market_premium,
    'SMB': smb_premium,
    'HML': hml_premium
}, index=dates)

print("=" * 60)
print("截面回归计算个股 Alpha")
print("=" * 60)
print(f"\n股票数量: {n_stocks}")
print(f"时间跨度: {n_months} 个月")
print(f"因子数量: 3 (MKT, SMB, HML)")

# ========== 2. 截面回归 ==========

def cross_sectional_regression(stock_ret, factor_ret):
    """
    对每个时间截面做 OLS 回归
    R_i = alpha + beta_1 * F1 + beta_2 * F2 + beta_3 * F3 + epsilon

    参数:
        stock_ret: 每只股票的当期收益 (n_stocks,)
        factor_ret: 当期因子收益 (n_factors,)

    返回:
        alpha: 截距（当日平均超额收益）
        betas: 因子系数
        residuals: 残差（个股特异性收益）
    """
    n = len(stock_ret)
    X = np.column_stack([np.ones(n), factor_ret])  # 加截距项
    betas, residuals, rank, sv = np.linalg.lstsq(X, stock_ret, rcond=None)
    fitted = X @ betas
    resid = stock_ret - fitted
    return betas[0], betas[1:], resid


# 对每个月做截面回归
alphas = []
factor_betas_over_time = []
residual_returns = np.zeros_like(stock_returns)

for t in range(n_months):
    ret_t = stock_returns[t, :]
    factor_t = np.column_stack([
        market_premium[t] * np.ones(n_stocks),
        smb_premium[t] * np.ones(n_stocks),
        hml_premium[t] * np.ones(n_stocks)
    ])

    # 这里直接用三列因子暴露做回归
    # 实际上截面回归中，每只股票有自己的因子暴露值
    factor_exposure = np.column_stack([
        stock_market_beta,
        stock_smb_beta,
        stock_hml_beta
    ])

    alpha_t, betas_t, resid_t = cross_sectional_regression(ret_t, factor_exposure)
    alphas.append(alpha_t)
    factor_betas_over_time.append(betas_t)
    residual_returns[t, :] = resid_t

alphas = np.array(alphas)

# ========== 3. 估计个股 Alpha ==========

# 方法：用残差收益的时序均值作为个股 Alpha 估计
estimated_alpha = np.mean(residual_returns, axis=0)

print("\n" + "=" * 60)
print("个股 Alpha 估计结果（前 10 只股票）")
print("=" * 60)
print(f"{'股票ID':<12} {'真实Alpha':>12} {'估计Alpha':>12} {'误差':>12}")
print("-" * 60)

for i in range(10):
    error = estimated_alpha[i] - true_alpha[i]
    print(f"{'STOCK_' + f'{i:03d}':<12} {true_alpha[i]:>12.4%} {estimated_alpha[i]:>12.4%} {error:>12.4%}")

# ========== 4. 评估估计质量 ==========

# 计算估计 Alpha 与真实 Alpha 的相关系数
correlation = np.corrcoef(true_alpha, estimated_alpha)[0, 1]
rmse = np.sqrt(np.mean((estimated_alpha - true_alpha) ** 2))

print("\n" + "=" * 60)
print("估计质量评估")
print("=" * 60)
print(f"相关系数: {correlation:.4f}")
print(f"RMSE: {rmse:.4%}")

# ========== 5. 统计检验：哪些股票有显著 Alpha ==========

print("\n" + "=" * 60)
print("统计检验：显著 Alpha 的股票")
print("=" * 60)

significant_stocks = []
for i in range(n_stocks):
    t_stat, p_value = stats.ttest_1samp(residual_returns[:, i], 0)
    if p_value < 0.05:
        significant_stocks.append({
            'stock': stock_ids[i],
            'alpha': estimated_alpha[i],
            't_stat': t_stat,
            'p_value': p_value,
            'true_alpha': true_alpha[i]
        })

significant_df = pd.DataFrame(significant_stocks)
if len(significant_df) > 0:
    significant_df = significant_df.sort_values('alpha', ascending=False)
    print(f"\n在 5% 显著性水平下，{len(significant_df)} 只股票有显著 Alpha")
    print(f"\n{'股票ID':<12} {'估计Alpha':>12} {'t统计量':>10} {'p值':>10} {'真实Alpha':>12}")
    print("-" * 60)
    for _, row in significant_df.head(10).iterrows():
        print(f"{row['stock']:<12} {row['alpha']:>12.4%} {row['t_stat']:>10.2f} {row['p_value']:>10.4f} {row['true_alpha']:>12.4%}")
else:
    print("没有股票通过显著性检验")

# ========== 6. 因子收益的时序统计 ==========

print("\n" + "=" * 60)
print("因子收益时序统计")
print("=" * 60)
print(f"\n{'因子':<8} {'月均收益':>12} {'年化收益':>12} {'月波动率':>12} {'年化波动率':>12}")
print("-" * 60)

for col in factor_df.columns:
    monthly_mean = factor_df[col].mean()
    annual_return = monthly_mean * 12
    monthly_std = factor_df[col].std()
    annual_std = monthly_std * np.sqrt(12)
    print(f"{col:<8} {monthly_mean:>12.4%} {annual_return:>12.4%} {monthly_std:>12.4%} {annual_std:>12.4%}")

print("\n" + "=" * 60)
print("风险提示")
print("=" * 60)
print("""
本示例使用模拟数据，仅用于演示截面回归方法。
实际因子投资中：
1. 因子溢价可能在样本外消失（数据挖掘风险）
2. 交易成本会侵蚀因子收益
3. 因子拥挤可能导致溢价下降
4. 因子暴露需要动态调整
5. 以上内容仅供学习，不构成投资建议
""")
```

## 常见误区

### 误区一：因子就是"万能公式"

很多初学者认为找到一个因子就能稳定赚钱。实际上，单因子策略的年化超额收益通常只有 2-5%，而且会经历漫长的回撤期。因子投资是"大概率正确"的游戏，不是"每把都赢"。

### 误区二：把历史回测的因子收益当作未来收益

"过去 20 年价值因子年化超额 5%"不意味着未来也会如此。2018-2020 年价值因子经历了严重回撤，很多价值基金倒闭。因子溢价是时变的，甚至可能反转。

### 误区三：因子越多越好

研究者已经发现了 400+ 个因子（"因子动物园"），但其中大部分是数据挖掘的产物。真正被经济学理论支撑、在多个市场和时间段验证的因子不超过 10 个。盲目堆叠因子会导致过拟合。

### 误区 四：忽略因子之间的相关性

价值因子和质量因子高度正相关，动量因子和价值因子高度负相关。如果直接等权组合这些因子，实际暴露可能集中在少数风格上。

### 误区五：把截面回归和时序回归混为一谈

截面回归回答的是"今天，哪些特征解释了股票间的收益差异"，时序回归回答的是"过去一年，这只股票对市场有多敏感"。两者虽然在数学上有联系，但应用场景完全不同。

## 小结与练习

### 小结

1. 因子是能预测股票收益的系统性变量，需要在截面上有区分度且对未来收益有预测力
2. 截面回归在同一时间点比较不同股票的因子暴露与收益关系，时序回归用历史数据估计个股对因子的敏感度
3. Fama-French 三因子模型（市场、规模、价值）是因子投资的基础框架，五因子模型增加了盈利和投资因子
4. 因子溢价的来源可能是风险补偿，也可能是行为偏差，实际中两种力量同时存在
5. 因子投资需要长期视角，单因子策略的超额收益有限且会经历回撤

## 参考答案

### 练习一

**思路**：生成一个与动量方向相反的反转因子，加入截面回归。反转因子的经济逻辑是：过去一个月涨得多的股票，下个月倾向于回调。

**答案**：

```python
import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)

# 复用原代码的基础数据
n_stocks = 100
n_months = 60

# 生成反转因子暴露（与动量方向相反）
stock_rev_beta = np.random.uniform(-0.5, 1.0, n_stocks)

# 生成反转因子收益（通常为正，因为反转效应存在）
rev_premium = np.random.normal(0.002, 0.025, n_months)

# 重新生成个股收益，加入反转因子
market_premium = np.random.normal(0.008, 0.04, n_months)
smb_premium = np.random.normal(0.003, 0.03, n_months)
hml_premium = np.random.normal(0.004, 0.03, n_months)
stock_market_beta = np.random.uniform(0.6, 1.5, n_stocks)
stock_smb_beta = np.random.uniform(-0.5, 1.5, n_stocks)
stock_hml_beta = np.random.uniform(-0.3, 1.2, n_stocks)
true_alpha = np.random.normal(0.001, 0.005, n_stocks)
true_alpha[:20] += 0.003

stock_returns_4f = np.zeros((n_months, n_stocks))
for t in range(n_months):
    for i in range(n_stocks):
        stock_returns_4f[t, i] = (
            true_alpha[i]
            + stock_market_beta[i] * market_premium[t]
            + stock_smb_beta[i] * smb_premium[t]
            + stock_hml_beta[i] * hml_premium[t]
            + stock_rev_beta[i] * rev_premium[t]
            + np.random.normal(0, 0.03)
        )

# 4 因子截面回归
residual_returns_4f = np.zeros_like(stock_returns_4f)
for t in range(n_months):
    factor_exposure_4f = np.column_stack([
        stock_market_beta, stock_smb_beta, stock_hml_beta, stock_rev_beta
    ])
    X = np.column_stack([np.ones(n_stocks), factor_exposure_4f])
    betas, _, _, _ = np.linalg.lstsq(X, stock_returns_4f[t, :], rcond=None)
    residual_returns_4f[t, :] = stock_returns_4f[t, :] - X @ betas

# 比较 Alpha 估计质量
estimated_alpha_4f = np.mean(residual_returns_4f, axis=0)
corr_3f = np.corrcoef(true_alpha, np.mean(stock_returns_4f - np.column_stack([
    stock_market_beta * market_premium[t] for t in range(n_months)
]).T, axis=0))[0, 1]
corr_4f = np.corrcoef(true_alpha, estimated_alpha_4f)[0, 1]
rmse_3f = np.sqrt(np.mean((np.mean(stock_returns_4f, axis=0) - true_alpha) ** 2))
rmse_4f = np.sqrt(np.mean((estimated_alpha_4f - true_alpha) ** 2))

print(f"3 因子模型 - 相关系数: {corr_3f:.4f}, RMSE: {rmse_3f:.4%}")
print(f"4 因子模型 - 相关系数: {corr_4f:.4f}, RMSE: {rmse_4f:.4%}")
print("加入反转因子后，Alpha 估计的 RMSE 应该降低，因为更多收益被因子解释")
```

**要点**：
- 加入与真实数据生成过程一致的因子，能提高 Alpha 估计的准确性
- 但如果因子之间高度相关，改善幅度有限
- 这也说明了为什么多因子模型优于单因子模型

### 练习二

**思路**：时序回归对每只股票分别做回归，用过去 60 个月的数据估计 Alpha 和 Beta。

**答案**：

```python
import numpy as np
import pandas as pd
from scipy import stats

np.random.seed(42)

n_stocks = 100
n_months = 60

market_premium = np.random.normal(0.008, 0.04, n_months)
smb_premium = np.random.normal(0.003, 0.03, n_months)
hml_premium = np.random.normal(0.004, 0.03, n_months)
stock_market_beta = np.random.uniform(0.6, 1.5, n_stocks)
stock_smb_beta = np.random.uniform(-0.5, 1.5, n_stocks)
stock_hml_beta = np.random.uniform(-0.3, 1.2, n_stocks)
true_alpha = np.random.normal(0.001, 0.005, n_stocks)

stock_returns = np.zeros((n_months, n_stocks))
for t in range(n_months):
    for i in range(n_stocks):
        stock_returns[t, i] = (
            true_alpha[i]
            + stock_market_beta[i] * market_premium[t]
            + stock_smb_beta[i] * smb_premium[t]
            + stock_hml_beta[i] * hml_premium[t]
            + np.random.normal(0, 0.03)
        )

# 时序回归：对每只股票做 OLS
factor_matrix = np.column_stack([market_premium, smb_premium, hml_premium])
ts_alphas = np.zeros(n_stocks)
ts_betas = np.zeros((n_stocks, 3))

for i in range(n_stocks):
    y = stock_returns[:, i]
    X = np.column_stack([np.ones(n_months), factor_matrix])
    betas, _, _, _ = np.linalg.lstsq(X, y, rcond=None)
    ts_alphas[i] = betas[0]
    ts_betas[i, :] = betas[1:]

# 比与时序回归的 Alpha 估计
print("时序回归 Alpha 估计（前 5 只股票）:")
print(f"{'股票':<10} {'真实Alpha':>12} {'时序估计':>12}")
for i in range(5):
    print(f"{'STOCK_' + f'{i:03d}':<10} {true_alpha[i]:>12.4%} {ts_alphas[i]:>12.4%}")

corr_ts = np.corrcoef(true_alpha, ts_alphas)[0, 1]
print(f"\n时序回归 Alpha 相关系数: {corr_ts:.4f}")

# 时序回归 vs 截面回归
print("\n两种方法比较:")
print("时序回归：对每只股票单独回归，使用同一组因子收益")
print("截面回归：对每个时间点回归，使用不同的因子暴露")
print("在本例中，两种方法给出相似的 Alpha 估计")
```

**要点**：
- 时序回归对每只股票单独估计，使用的时间序列更长，估计更稳定
- 截面回归对每个时间点估计，能捕捉因子暴露的时变特征
- 实际中两种方法结合使用效果更好

### 练习三

**思路**：计算因子收益之间的相关系数，并用经济逻辑解释。

**答案**：

```python
import numpy as np
import pandas as pd

np.random.seed(42)
n_months = 60

# 生成模拟因子收益（加入负相关性使 SMB 和 HML 负相关）
noise_smb = np.random.normal(0, 0.02, n_months)
noise_hml = np.random.normal(0, 0.02, n_months)

mkt = np.random.normal(0.008, 0.04, n_months)
# SMB 和 HML 加入负相关：当小盘涨时，价值股往往跌（成长风格占优时）
smb = np.random.normal(0.003, 0.03, n_months)
hml = smb * (-0.3) + noise_hml  # 使 SMB 和 HML 负相关

factor_df = pd.DataFrame({'MKT': mkt, 'SMB': smb, 'HML': hml})
corr_matrix = factor_df.corr()

print("因子相关系数矩阵:")
print(corr_matrix.round(4))

print("\n经济解释:")
print("1. SMB 与 HML 通常负相关，因为：")
print("   - 小盘股往往是成长型公司，价值股往往是大公司")
print("   - 市场偏好成长风格时，小盘涨、价值跌")
print("   - 市场偏好价值风格时，大盘涨、小盘跌")
print("2. MKT 与 SMB/HML 的相关性较弱，因为：")
print("   - 市场因子捕获整体市场方向")
print("   - 规模和价值因子是相对收益（多空组合）")
print("3. 因子相关性对组合构建很重要：")
print("   - 负相关的因子组合可以降低整体波动")
print("   - 这是多因子策略的核心优势之一")
```

**要点**：
- SMB 和 HML 的负相关源于经济结构：小盘股通常是成长型，价值股通常是大公司
- 因子相关性会随市场环境变化，牛市和熊市中相关性可能不同
- 构建多因子组合时，需要考虑因子间的相关性以实现真正的分散化
