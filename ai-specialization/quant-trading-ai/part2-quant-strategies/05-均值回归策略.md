# 均值回归策略

## 场景引入

上一节课我们学习了趋势跟踪——"追涨杀跌"的系统化方法。但市场并非总是有趋势。在大量的震荡行情中，趋势策略会反复止损，资金曲线持续回撤。

有没有一种策略，专门在震荡市中赚钱？

这就是**均值回归**（Mean Reversion）。其核心假设是：**价格偏离均值后，会倾向于回归均值**。想象一根橡皮筋连接着价格和均值——拉得越远，回弹的力量越大。

均值回归策略的经典应用是**配对交易**（Pairs Trading）：找到两只高度相关的股票，当它们的价差异常扩大时，做多被低估的、做空被高估的，等待价差回归。

本节课将从均值回归的数学基础（Ornstein-Uhlenbeck 过程）出发，逐步实现协整检验、配对交易、布林带策略，并讨论完整的风险管理方案。

> **风险提示**：本课程仅用于量化交易技术教学，不构成任何投资建议。配对交易涉及做空操作，在 A 股中做空机制有限（融券成本高、券源不足），实际应用需充分考虑可执行性。历史回测表现不代表未来收益。

## 学习目标

完成本课学习后，你将能够：

1. 理解均值回归的数学基础（OU 过程）
2. 使用协整检验找到可配对的股票

5. 设计配对交易的风险管理方案

## 一、均值回归的数学基础

### 1.1 Ornstein-Uhlenbeck 过程

```
OU 过程描述均值回归的动态:

  dX_t = θ(μ - X_t)dt + σdW_t

  其中:
    X_t : 价差（或对数价格差）在时刻 t 的值
    μ   : 长期均值（回归目标）
    θ   : 回归速度（越大回归越快）
    σ   : 波动率
    W_t : 布朗运动

  直觉理解:
    - 当 X_t > μ 时，(μ - X_t) < 0，dX_t 倾向为负 → 价格被拉回
    - 当 X_t < μ 时，(μ - X_t) > 0，dX_t 倾向为正 → 价格被拉回
    - θ 越大，拉回的力量越强
```

### 1.2 半衰期估计

```python
# math/ou_process.py
"""
Ornstein-Uhlenbeck 过程分析
"""
import numpy as np
import pandas as pd
from scipy.optimize import minimize


def estimate_ou_params(spread: pd.Series) -> dict:
    """
    估计 OU 过程的参数

    使用离散化近似:
        X_{t+1} - X_t = θ(μ - X_t) * Δt + σ * ε

    可以转换为线性回归:
        ΔX_t = a + b * X_t + ε

    其中:
        a = θ * μ * Δt
        b = -θ * Δt
        半衰期 = -ln(2) / b

    参数:
        spread: 价差时间序列

    返回:
        OU 参数字典
    """
    spread = spread.dropna()
    if len(spread) < 30:
        return {"error": "数据不足"}

    # 构造回归数据
    x = spread.iloc[:-1].values          # X_t
    dx = np.diff(spread.values)          # ΔX_t = X_{t+1} - X_t

    # 线性回归: ΔX = a + b*X
    from numpy.linalg import lstsq
    X_reg = np.column_stack([np.ones(len(x)), x])
    coeffs, _, _, _ = lstsq(X_reg, dx, rcond=None)
    a, b = coeffs

    # 提取 OU 参数
    if b >= 0:
        return {
            "theta": None,
            "mu": None,
            "sigma": None,
            "half_life": None,
            "is_mean_reverting": False,
            "warning": "b >= 0，序列不具有均值回归特性",
        }

    dt = 1  # 日频数据
    theta = -b / dt
    mu = -a / b
    residuals = dx - (a + b * x)
    sigma = residuals.std() * np.sqrt(250)  # 年化

    half_life = np.log(2) / theta

    return {
        "theta": round(theta, 4),
        "mu": round(mu, 4),
        "sigma": round(sigma, 4),
        "half_life": round(half_life, 1),
        "is_mean_reverting": True,
        "speed": "快" if half_life < 10 else ("中" if half_life < 30 else "慢"),
    }


def calc_zscore(spread: pd.Series, window: int = 20) -> pd.Series:
    """
    计算价差的 Z-Score

    Z-Score = (当前值 - 滚动均值) / 滚动标准差

    Z-Score 的含义:
        |Z| > 2  : 价差偏离较大，有回归机会
        |Z| > 2.5: 价差偏离很大，强信号
        |Z| > 3  : 价差偏离极大，罕见信号
    """
    rolling_mean = spread.rolling(window=window).mean()
    rolling_std = spread.rolling(window=window).std()

    zscore = (spread - rolling_mean) / rolling_std.replace(0, np.nan)

    return zscore
```

### 1.3 OU 过程模拟验证

```python
def simulate_ou_process(
    theta: float = 0.1,
    mu: float = 0.0,
    sigma: float = 1.0,
    x0: float = 2.0,
    n_steps: int = 500,
    dt: float = 1/250,
) -> pd.Series:
    """
    模拟 OU 过程

    用于验证均值回归特性
    """
    np.random.seed(42)
    x = np.zeros(n_steps)
    x[0] = x0

    for t in range(1, n_steps):
        dx = theta * (mu - x[t-1]) * dt + sigma * np.sqrt(dt) * np.random.randn()
        x[t] = x[t-1] + dx

    return pd.Series(x, name="OU_Simulated")
```

## 二、协整检验

### 2.1 为什么需要协整

```
相关性 vs 协整:

  股票A 和 股票B 可能高度相关（同涨同跌），但不一定协整

  相关性: 衡量两个变量同时变动的程度
         ┌─────┐
    A:   │↗ ↗ ↗│   A和B同涨同跌
    B:   │↗ ↗ ↗│   相关性高
         └─────┘

  协整: 衡量两个变量的差是否稳定
         ┌─────┐
    A-B: │─ ─ ─│   差值在均值附近震荡
         └─────┘   协整成立 → 可以做配对交易

         ┌─────┐
    A-B: │↗↗↗↗↗│   差值持续发散
         └─────┘   协整不成立 → 不适合配对
```

### 2.2 Engle-Granger 两步法

```python
# math/cointegration.py
"""
协整检验
"""
import pandas as pd
import numpy as np
from typing import Optional


def engle_granger_test(
    y: pd.Series,
    x: pd.Series,
    significance: float = 0.05,
) -> dict:
    """
    Engle-Granger 两步法协整检验

    步骤:
        1. 对 y 和 x 做 OLS 回归，得到残差（价差）
        2. 对残差做 ADF 单位根检验
        3. 如果残差是平稳的（无单位根），则 y 和 x 协整

    参数:
        y           : 因变量（股票A的价格）
        x           : 自变量（股票B的价格）
        significance: 显著性水平

    返回:
        协整检验结果
    """
    from statsmodels.tsa.stattools import adfuller

    # 对齐数据
    common = y.index.intersection(x.index)
    y = y.loc[common].dropna()
    x = x.loc[common].dropna()
    common = y.index.intersection(x.index)
    y, x = y.loc[common], x.loc[common]

    if len(common) < 50:
        return {"error": "数据不足（至少需要50个观测值）", "is_cointegrated": False}

    # Step 1: OLS 回归
    from numpy.linalg import lstsq
    X = np.column_stack([np.ones(len(x)), x.values])
    coeffs, _, _, _ = lstsq(X, y.values, rcond=None)
    alpha, beta = coeffs

    # 残差 = 价差
    residuals = y.values - (alpha + beta * x.values)
    spread = pd.Series(residuals, index=common)

    # Step 2: ADF 检验
    adf_result = adfuller(residuals, maxlag=20, autolag="AIC")
    adf_stat = adf_result[0]
    p_value = adf_result[1]
    critical_values = adf_result[4]

    is_cointegrated = p_value < significance

    return {
        "is_cointegrated": is_cointegrated,
        "adf_statistic": round(adf_stat, 4),
        "p_value": round(p_value, 4),
        "critical_values": {k: round(v, 4) for k, v in critical_values.items()},
        "alpha": round(alpha, 4),
        "beta": round(beta, 4),
        "spread": spread,
        "spread_mean": round(spread.mean(), 4),
        "spread_std": round(spread.std(), 4),
    }


def find_cointegrated_pairs(
    prices: pd.DataFrame,
    significance: float = 0.05,
    min_corr: float = 0.7,
) -> list:
    """
    从股票池中找到协整配对

    流程:
        1. 先用相关系数初筛（过滤掉相关性低的配对）
        2. 对初筛通过的配对做协整检验
        3. 返回所有通过协整检验的配对

    参数:
        prices     : 价格数据，columns 为股票代码
        significance: 协整检验显著性水平
        min_corr   : 相关系数初筛阈值
    """
    symbols = prices.columns.tolist()
    n = len(symbols)
    pairs = []

    # 相关系数矩阵
    corr_matrix = prices.pct_change().corr()

    print(f"股票池: {n} 只股票, 共 {n*(n-1)//2} 个配对")
    print(f"相关系数筛选阈值: {min_corr}")

    tested = 0
    for i in range(n):
        for j in range(i + 1, n):
            sym_a, sym_b = symbols[i], symbols[j]

            # 初筛: 相关系数
            corr = corr_matrix.loc[sym_a, sym_b]
            if abs(corr) < min_corr:
                continue

            # 协整检验
            result = engle_granger_test(prices[sym_a], prices[sym_b], significance)
            tested += 1

            if result.get("is_cointegrated"):
                pairs.append({
                    "stock_a": sym_a,
                    "stock_b": sym_b,
                    "correlation": round(corr, 4),
                    "adf_pvalue": result["p_value"],
                    "beta": result["beta"],
                    "half_life": None,  # 后续计算
                    "spread_mean": result["spread_mean"],
                    "spread_std": result["spread_std"],
                })

    print(f"通过相关系数筛选: 对 {tested} 个配对做协整检验")
    print(f"找到协整配对: {len(pairs)} 个")

    # 按 p 值排序
    pairs = sorted(pairs, key=lambda p: p["adf_pvalue"])

    return pairs
```

## 三、配对交易策略

### 3.1 交易逻辑

```
配对交易信号生成:

  价差 Z-Score
   +3 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 开空价差（做空A，做多B）
       │
   +2 ─┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 开仓阈值
       │    ╲
       │     ╲
    0 ─┤──────╲───────────────────── 均值
       │       ╱
       │      ╱
   -2 ─┤ ─ ─╱─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 开仓阈值
       │
   -3 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 开多价差（做多A，做空B）

  开仓: |Z| > 2
  平仓: Z 回归到 0 附近（|Z| < 0.5）
  止损: |Z| > 3（价差继续发散）
```

### 3.2 完整实现

```python
# strategies/pairs_trading.py
"""
配对交易策略
"""
import pandas as pd
import numpy as np
from dataclasses import dataclass


@dataclass
class PairsConfig:
    """配对交易配置"""
    entry_z: float = 2.0          # 开仓 Z-Score 阈值
    exit_z: float = 0.5           # 平仓 Z-Score 阈值
    stop_z: float = 3.5           # 止损 Z-Score 阈值
    z_window: int = 20            # Z-Score 计算窗口
    ou_window: int = 60           # OU 参数估计窗口
    position_value: float = 100000  # 每对交易的名义价值
    cost_rate: float = 0.002      # 双边交易成本


class PairsTrader:
    """
    配对交易策略引擎

    管理一对股票的完整交易生命周期:
    价差计算 → Z-Score → 信号生成 → 仓位管理 → 收益计算
    """

    def __init__(
        self,
        price_a: pd.Series,
        price_b: pd.Series,
        beta: float = None,
        config: PairsConfig = None,
    ):
        """
        参数:
            price_a: 股票A的价格序列
            price_b: 股票B的价格序列
            beta   : 对冲比率（A/B的价格系数），None则自动估计
            config : 策略配置
        """
        self.config = config or PairsConfig()

        # 对齐数据
        common = price_a.index.intersection(price_b.index)
        self.price_a = price_a.loc[common]
        self.price_b = price_b.loc[common]

        # 估计或使用给定的对冲比率
        if beta is None:
            self.beta = self._estimate_beta()
        else:
            self.beta = beta

        # 计算价差
        self.spread = self.price_a - self.beta * self.price_b

        # 计算 Z-Score
        self.zscore = calc_zscore(self.spread, window=self.config.z_window)

    def _estimate_beta(self) -> float:
        """
        估计对冲比率 beta

        使用 OLS 回归: price_A = alpha + beta * price_B
        """
        from numpy.linalg import lstsq

        X = np.column_stack([np.ones(len(self.price_b)), self.price_b.values])
        coeffs, _, _, _ = lstsq(X, self.price_a.values, rcond=None)
        return coeffs[1]

    def generate_signals(self) -> pd.DataFrame:
        """
        生成交易信号

        信号规则:
            开空价差(Z > entry_z): 做空A + 做多B
            开多价差(Z < -entry_z): 做多A + 做空B
            平仓(|Z| < exit_z): 平掉所有仓位
            止损(|Z| > stop_z): 强制平仓
        """
        result = pd.DataFrame({
            "price_a": self.price_a,
            "price_b": self.price_b,
            "spread": self.spread,
            "zscore": self.zscore,
        })

        result["signal"] = 0
        position = 0  # 0=空仓, 1=多价差, -1=空价差

        for i in range(len(result)):
            z = result["zscore"].iloc[i]

            if pd.isna(z):
                result.iloc[i, result.columns.get_loc("signal")] = 0
                continue

            if position == 0:
                # 空仓状态: 检查开仓信号
                if z > self.config.entry_z:
                    position = -1  # 空价差
                    result.iloc[i, result.columns.get_loc("signal")] = -1
                elif z < -self.config.entry_z:
                    position = 1   # 多价差
                    result.iloc[i, result.columns.get_loc("signal")] = 1

            elif position == 1:
                # 多价差状态: 检查平仓或止损
                if abs(z) < self.config.exit_z:
                    position = 0
                    result.iloc[i, result.columns.get_loc("signal")] = -2  # 平仓
                elif z > self.config.stop_z:
                    position = 0
                    result.iloc[i, result.columns.get_loc("signal")] = -3  # 止损

            elif position == -1:
                # 空价差状态: 检查平仓或止损
                if abs(z) < self.config.exit_z:
                    position = 0
                    result.iloc[i, result.columns.get_loc("signal")] = 2   # 平仓
                elif z < -self.config.stop_z:
                    position = 0
                    result.iloc[i, result.columns.get_loc("signal")] = 3   # 止损

            result.iloc[i, result.columns.get_loc("position")] = position

        return result

    def backtest(self) -> pd.DataFrame:
        """
        执行配对交易回测

        计算策略收益（含交易成本）
        """
        signals = self.generate_signals()

        # 计算价差收益
        spread_return = self.spread.pct_change()

        # 策略收益 = 仓位 * 价差收益
        signals["strategy_return"] = signals["position"].shift(1) * spread_return

        # 交易成本
        signals["trade"] = signals["position"].diff().abs()
        signals["cost"] = signals["trade"] * self.config.cost_rate
        signals["strategy_return"] -= signals["cost"]

        # 累计收益
        signals["cum_strategy"] = (1 + signals["strategy_return"]).cumprod()

        return signals
```

## 四、布林带均值回归策略

### 4.1 策略逻辑

```
布林带策略:

  上轨 (MA + 2σ)  ──────╲         ╱──────
                         ╲       ╱
  中轨 (MA)      ────────╲─────╱───────── 均值回归目标
                           ╲ ╱
  下轨 (MA - 2σ)  ─────────╳─────────────

  触及上轨 → 超买 → 做空（预期回归中轨）
  触及下轨 → 超卖 → 做多（预期回归中轨）
```

### 4.2 完整实现

```python
# strategies/bollinger_reversion.py
"""
布林带均值回归策略
"""
import pandas as pd
import numpy as np


def bollinger_reversion_strategy(
    df: pd.DataFrame,
    window: int = 20,
    num_std: float = 2.0,
    cost_rate: float = 0.001,
) -> pd.DataFrame:
    """
    布林带均值回归策略

    信号规则:
        - 价格触及上轨 (MA + n*σ): 做空
        - 价格触及下轨 (MA - n*σ): 做多
        - 价格回归中轨 (MA): 平仓

    参数:
        df       : OHLCV 数据
        window   : 布林带窗口
        num_std  : 标准差倍数
        cost_rate: 交易成本
    """
    result = df.copy()

    # 计算布林带
    result["bb_mid"] = result["close"].rolling(window=window).mean()
    result["bb_std"] = result["close"].rolling(window=window).std()
    result["bb_upper"] = result["bb_mid"] + num_std * result["bb_std"]
    result["bb_lower"] = result["bb_mid"] - num_std * result["bb_std"]

    # %B 指标: 价格在布林带中的相对位置
    result["pct_b"] = (result["close"] - result["bb_lower"]) / \
                      (result["bb_upper"] - result["bb_lower"])

    # 生成信号
    result["signal"] = 0
    position = 0  # 0=空仓, 1=多头, -1=空头

    for i in range(len(result)):
        pct_b = result["pct_b"].iloc[i]

        if pd.isna(pct_b):
            result.iloc[i, result.columns.get_loc("signal")] = 0
            continue

        if position == 0:
            if pct_b <= 0:          # 触及下轨
                position = 1
                result.iloc[i, result.columns.get_loc("signal")] = 1
            elif pct_b >= 1:        # 触及上轨
                position = -1
                result.iloc[i, result.columns.get_loc("signal")] = -1

        elif position == 1:
            if pct_b >= 0.5:        # 回归中轨
                position = 0
                result.iloc[i, result.columns.get_loc("signal")] = 2   # 平多

        elif position == -1:
            if pct_b <= 0.5:        # 回归中轨
                position = 0
                result.iloc[i, result.columns.get_loc("signal")] = -2  # 平空

        result.iloc[i, result.columns.get_loc("position")] = position

    # 计算收益
    result["daily_return"] = result["close"].pct_change()
    result["strategy_return"] = result["position"].shift(1) * result["daily_return"]
    result["trade"] = result["position"].diff().abs()
    result["cost"] = result["trade"] * cost_rate
    result["strategy_return"] -= result["cost"]

    result["cum_strategy"] = (1 + result["strategy_return"]).cumprod()
    result["cum_benchmark"] = (1 + result["daily_return"]).cumprod()

    return result
```

## 五、风险管理

### 5.1 配对交易的风险维度

```
配对交易风险矩阵:

  ┌──────────────────┬──────────────────────────────────┐
  │  风险类型         │  应对方案                         │
  ├──────────────────┼──────────────────────────────────┤
  │  价差发散风险      │  止损线(Z>3.5)强制平仓            │
  │  (协整关系破裂)    │  定期重新检验协整性               │
  ├──────────────────┼──────────────────────────────────┤
  │  流动性风险        │  选择日均成交额>5000万的股票       │
  │  (无法平仓)       │  避免小盘股和停牌频繁的股票        │
  ├──────────────────┼──────────────────────────────────┤
  │  融券风险          │  A股做空需要融券，成本高且券源有限  │
  │  (做空成本)       │  实际中可能只能做多强势股          │
  ├──────────────────┼──────────────────────────────────┤
  │  单边持仓风险      │  控制单对名义价值占总资金比例       │
  │  (Beta不对冲)     │  多对分散化                       │
```

```python
"""
配对交易风险管理
"""
import pandas as pd
import numpy as np


class PairsRiskManager:
    """
    配对交易风险管理器

    管理内容:
    1. 价差发散止损
    2. 持仓时间限制
    3. 最大亏损限制
    4. 协整关系监控
    """

        self,

        self,
        zscore: float,
        holding_days: int,
        unrealized_pnl: float,
        spread: pd.Series,
    ) -> dict:
        """
        检查是否触发止损/平仓条件

        返回:
            should_stop: 是否应该平仓
            reason     : 平仓原因
        """
        reasons = []

        # 1. Z-Score 止损
        if abs(zscore) > self.z_stop:
            reasons.append(f"Z-Score止损: |{zscore:.2f}| > {self.z_stop}")

        # 2. 持仓时间限制
        if holding_days > self.max_holding_days:
            reasons.append(f"持仓超时: {holding_days}天 > {self.max_holding_days}天")

        # 3. 最大亏损限制
        if unrealized_pnl < -self.max_loss_pct:
            reasons.append(f"最大亏损: {unrealized_pnl:.2%} < -{self.max_loss_pct:.2%}")

        # 4. 协整关系检验
        if len(spread) >= self.coint_check_window:
            recent_spread = spread.tail(self.coint_check_window)
            from math.cointegration import engle_granger_test
            # 注意: 这里简化处理，实际应该用两只股票的价格重新检验

        should_stop = len(reasons) > 0

        return {
            "should_stop": should_stop,
            "reasons": reasons,
            "zscore": zscore,
            "holding_days": holding_days,
            "unrealized_pnl": unrealized_pnl,
        }

    def calc_optimal_position_size(
        self,
        account_value: float,
        spread_vol: float,
        max_risk_pct: float = 0.02,
    ) -> float:
        """
        计算最优仓位大小

        基于价差波动率和风险预算

        公式:
            position_value = account * max_risk% / (spread_vol * z_stop)
        """
        if spread_vol <= 0:
            return 0

        risk_per_pair = account_value * max_risk_pct
        position_value = risk_per_pair / (spread_vol * self.z_stop)

        return round(position_value, 2)
```

### 5.3 协整关系监控

```python
def monitor_cointegration(
    price_a: pd.Series,
    price_b: pd.Series,
    window: int = 60,
    check_interval: int = 20,
) -> pd.DataFrame:
    """
    滚动监控协整关系的稳定性

    定期重新检验协整性，如果协整关系破裂，发出警告

    参数:
        price_a, price_b: 价格序列
        window          : 检验窗口
        check_interval  : 检验间隔（天）
    """
    from math.cointegration import engle_granger_test

    results = []
    dates = price_a.index.tolist()

    for i in range(window, len(dates), check_interval):
        start = i - window
        end = i

        pa = price_a.iloc[start:end]
        pb = price_b.iloc[start:end]

        test = engle_granger_test(pa, pb)

        results.append({
            "date": dates[i],
            "is_cointegrated": test.get("is_cointegrated", False),
            "p_value": test.get("p_value", np.nan),
            "beta": test.get("beta", np.nan),
        })

    df = pd.DataFrame(results).set_index("date")

    # 统计协整关系的稳定性
    stable_pct = df["is_cointegrated"].mean()
    print(f"协整关系稳定性: {stable_pct:.2%} 的检验窗口通过协整检验")

    if stable_pct < 0.5:
        print("警告: 协整关系不稳定，建议更换配对")

    return df
```

```python
def evaluate_pairs_feasibility(
    pair: dict,
    stock_a_info: dict,
    stock_b_info: dict,
) -> dict:
    """
    评估配对交易在 A 股的可行性

    A 股做空的限制:
    1. 融券: 需要开通融资融券账户，券源有限
    2. 融券利率: 年化 8-10%，显著侵蚀收益
    3. 转融通: 门槛高，普通投资者无法参与
    """
    issues = []

    # 检查融券资格
    if not stock_a_info.get("margin_available"):
        issues.append(f"股票A ({pair['stock_a']}) 不在融券标的池中")
    if not stock_b_info.get("margin_available"):
        issues.append(f"股票B ({pair['stock_b']}) 不在融券标的池中")

    # 检查流动性
    if stock_a_info.get("avg_daily_amount", 0) < 50_000_000:
        issues.append(f"股票A 日均成交额不足5000万")
    if stock_b_info.get("avg_daily_amount", 0) < 50_000_000:
        issues.append(f"股票B 日均成交额不足5000万")

    # 检查ST/退市风险
    if stock_a_info.get("is_st") or stock_b_info.get("is_st"):
        issues.append("包含ST股，风险较高")

    # 估算融券成本
    borrow_cost_annual = 0.08  # 年化8%
    half_life = pair.get("half_life", 20)
    borrow_cost_per_trade = borrow_cost_annual * half_life / 250

    # 判断可行性
    feasible = len(issues) == 0
    expected_profit = pair.get("spread_std", 0) * 2 / pair.get("beta", 1)
    net_profit = expected_profit - borrow_cost_per_trade * 2  # 双边融券成本

    return {
        "feasible": feasible,
        "issues": issues,
        "expected_profit_per_trade": round(expected_profit, 4),
        "borrow_cost_per_trade": round(borrow_cost_per_trade, 4),
        "net_profit_per_trade": round(net_profit, 4),
        "recommendation": "可执行" if net_profit > 0.005 else "收益不足以覆盖成本",
    }
```

```python
# system/pairs_system.py
"""
配对交易完整系统
整合筛选、交易、风控
"""
import pandas as pd
import numpy as np


class PairsSystem:
    """
    配对交易系统

    完整流程:
        1. 股票池筛选
        2. 协整配对发现
        3. OU 参数估计
        4. 信号生成与交易
        5. 风险管理
        6. 绩效评估
    """

    def __init__(self, prices: pd.DataFrame, config: dict = None):
        self.prices = prices
        self.config = config or {}
        self.pairs = []
        self.results = {}

    def run(self):
        """执行完整流程"""
        print("=" * 50)
        print("配对交易系统启动")
        print("=" * 50)

        # Step 1: 发现配对
        print("\n[Step 1] 协整配对发现")
        from math.cointegration import find_cointegrated_pairs
        self.pairs = find_cointegrated_pairs(
            self.prices,
            significance=self.config.get("significance", 0.05),
            min_corr=self.config.get("min_corr", 0.7),
        )

        if not self.pairs:
            print("未找到协整配对，流程终止")
            return

        # Step 2: 对每个配对做回测
        print(f"\n[Step 2] 回测 {len(self.pairs)} 个配对")
        pair_results = []

        for pair_info in self.pairs:

            )

            bt_result = trader.backtest()

            from metrics.performance import calc_performance_metrics
            metrics = calc_performance_metrics(
                bt_result["strategy_return"].dropna()

            metrics["pair"] = f"{sym_a}/{sym_b}"

        # Step 3: 汇总

        return self.results
```

## 常见误区

### 误区一：把相关性当协整性

两只银行股高度相关（同涨同跌），但它们的价差可能持续发散而不是均值回归。相关性是"同方向动"，协整性是"差值稳定"。必须用 ADF 检验验证协整性，不能只看相关系数。

### 误区二：忽略协整关系的时变性

2020 年协整的配对，2023 年可能不再协整。行业格局变化、公司基本面分化都会导致协整关系破裂。必须定期重新检验（如每季度），并在配对交易系统中集成协整监控。

### 误区三：止损设得太宽

"价差总会回归的"——不一定。如果止损设在 Z=5，可能等来的是本金亏损 30%。配对交易的止损应该比趋势策略更严格，因为均值回归策略的核心假设是"价差会回来"，一旦假设被打破，必须果断退出。

### 误区四：忽略 A 股做空成本

在回测中假设可以自由做空，但 A 股融券年化成本 8-10%，很多股票根本没有券源。如果配对交易的年化超额收益只有 10%，融券成本就吃掉了大部分。在 A 股做配对交易，ETF 配对比个股配对更现实。

### 误区五：配对数量过多

找到 50 个协整配对很"令人兴奋"，但每个配对都需要独立管理，而且配对之间可能存在相关性（如都涉及银行股）。建议同时管理的配对不超过 5-10 对，且确保行业分散。

## 小结与练习

### 本课要点

- **均值回归**的核心假设是价格偏离均值后会回归，用 OU 过程数学建模
- **协整检验**是配对交易的基础，Engle-Granger 两步法是最常用的方法
- **Z-Score** 是配对交易的核心信号，开仓/平仓/止损都基于 Z-Score 的阈值
- **布林带策略**是单品种均值回归的经典方法，利用超买超卖信号
- **A 股做空限制**是配对交易的最大障碍，ETF 配对是更现实的替代方案
- **协整关系会变化**，必须定期重新检验，不能一劳永逸

### 练习一：OU 参数估计

**思路**：用线性回归估计 OU 过程的参数，判断序列是否具有均值回归特性。

**答案**：
```python
import numpy as np
import pandas as pd

# 模拟一个均值回归序列
np.random.seed(42)
n = 500
theta_true = 0.1
mu_true = 0.0
sigma_true = 0.5

x = np.zeros(n)
x[0] = 2.0
for t in range(1, n):
    x[t] = x[t-1] + theta_true * (mu_true - x[t-1]) + sigma_true * np.random.randn()

spread = pd.Series(x)

# 估计参数
dx = np.diff(x)
X = x[:-1]

from numpy.linalg import lstsq
X_reg = np.column_stack([np.ones(len(X)), X])
coeffs, _, _, _ = lstsq(X_reg, dx, rcond=None)
a, b = coeffs

theta_est = -b
mu_est = -a / b
half_life = np.log(2) / theta_est

print(f"真实 theta: {theta_true}")
print(f"估计 theta: {theta_est:.4f}")
print(f"真实 mu: {mu_true}")
print(f"估计 mu: {mu_est:.4f}")
print(f"半衰期: {half_life:.1f} 天")
```

**要点**：
- 估计值应接近真实值，误差来自随机噪声
- 如果 b > 0，说明序列不具有均值回归特性（可能是趋势序列）
- 半衰期是关键参数，决定了交易的持仓时间和调仓频率

```python
import pandas as pd
import akshare as ak
from statsmodels.tsa.stattools import adfuller

# 获取两只银行股数据
symbols = ["601398", "601939"]  # 工商银行、建设银行
prices = pd.DataFrame()

for sym in symbols:
    df = ak.stock_zh_a_hist(symbol=sym, period="daily",
                            start_date="20220101", adjust="hfq")
    df["date"] = pd.to_datetime(df["日期"])
    df = df.set_index("date")
    prices[sym] = df["close"]

# Step 1: OLS 回归
from numpy.linalg import lstsq
y = prices["601398"].values
x = prices["601939"].values
X = np.column_stack([np.ones(len(x)), x])
coeffs, _, _, _ = lstsq(X, y, rcond=None)
alpha, beta = coeffs

# 残差（价差）
spread = y - (alpha + beta * x)

# Step 2: ADF 检验
result = adfuller(spread)
print(f"ADF统计量: {result[0]:.4f}")
print(f"p值: {result[1]:.4f}")
print(f"是否协整(p<0.05): {result[1] < 0.05}")
print(f"Beta (对冲比率): {beta:.4f}")
```

**要点**：
- 同行业股票更容易协整（如两只银行股）
- p 值越小，协整关系越强
- Beta 是对冲比率，决定了两只股票的持仓比例

### 练习三：布林带策略

**思路**：实现布林带均值回归策略，在触及上轨时做空、触及下轨时做多。

**答案**：
```python
import pandas as pd
import numpy as np

# 生成模拟数据（均值回归型）
np.random.seed(42)
n = 500
price = 100 + np.cumsum(np.random.randn(n) * 0.5)
# 加入均值回归特性
for i in range(1, n):
    price[i] += (100 - price[i-1]) * 0.02

df = pd.DataFrame({"close": price}, index=pd.date_range("2023-01-01", periods=n))

# 布林带
window = 20
df["ma"] = df["close"].rolling(window).mean()
df["std"] = df["close"].rolling(window).std()
df["upper"] = df["ma"] + 2 * df["std"]
df["lower"] = df["ma"] - 2 * df["std"]

# 信号
df["position"] = 0
df.loc[df["close"] < df["lower"], "position"] = 1    # 超卖做多
df.loc[df["close"] > df["upper"], "position"] = -1   # 超买做空

# 持仓持续到回归中轨
for i in range(1, len(df)):
    if df["position"].iloc[i] == 0:
        prev_pos = df["position"].iloc[i-1]
        if prev_pos == 1 and df["close"].iloc[i] < df["ma"].iloc[i]:
            df.iloc[i, df.columns.get_loc("position")] = 1
        elif prev_pos == -1 and df["close"].iloc[i] > df["ma"].iloc[i]:
            df.iloc[i, df.columns.get_loc("position")] = -1

# 计算收益
df["ret"] = df["close"].pct_change()
df["strat_ret"] = df["position"].shift(1) * df["ret"]
cum = (1 + df["strat_ret"].dropna()).cumprod()

print(f"总收益: {cum.iloc[-1] - 1:.2%}")
print(f"年化收益: {(cum.iloc[-1] ** (250/len(df)) - 1):.2%}")
```

**要点**：
- 布林带策略在震荡市中表现好，在趋势市中可能反复止损
- 可以结合 RSI 或成交量指标过滤假信号
- 参数 window 和 num_std 需要根据标的的波动特性调整
