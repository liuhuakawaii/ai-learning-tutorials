# 趋势跟踪策略

## 场景引入

"趋势是你的朋友"（Trend is your friend）——这句话在交易界流传了几十年。趋势跟踪（Trend Following）是最古老、最经典的量化策略之一，其核心思想朴素到一句话就能说清：**价格上涨时买入，价格下跌时卖出**。

但朴素的思想不代表简单。在真实的 A 股市场中，你需要回答大量工程问题：

- 用什么指标定义"趋势"？均线、通道、还是动量？
- 信号出现后以什么价格执行？收盘价、次日开盘价、还是 VWAP？
- 仓位怎么管理？全仓进出还是金字塔加仓？
- 止损怎么设？固定百分比、ATR 倍数、还是移动止损？
- A 股的 T+1 制度和涨跌停制度对趋势策略有什么影响？

本节课将从最基础的双均线交叉出发，逐步实现唐奇安通道、海龟交易法则，最终构建一套完整的趋势跟踪系统。每个策略都提供完整的 Python 实现和性能评估。

> **风险提示**：本课程仅用于量化交易技术教学，不构成任何投资建议。趋势跟踪策略在震荡市中会产生大量假信号和亏损，历史回测表现不代表未来收益。实际交易存在滑点、流动性等风险。

## 一、趋势跟踪的理论基础

### 1.1 为什么趋势会存在

趋势跟踪之所以有效，背后有行为金融学的解释：

```
趋势形成的心理机制:

  信息扩散 → 初始反应不足 → 逐步反应 → 过度反应 → 反转
  ──────────────────────────────────────────────────────
  │ 少数人    │  趋势形成    │  趋势加速  │  趋势结束  │

  1. 信息不是同时到达所有投资者的
  2. 人类对新信息存在"锚定效应"，反应不足
  3. 当趋势形成后，"羊群效应"推动趋势加速
  4. 最终过度反应导致泡沫或崩盘
```

### 1.2 趋势跟踪策略分类

```
趋势跟踪策略
├── 均线类
│   ├── 双均线交叉（Golden/Death Cross）
│   ├── 三均线系统
│   └── MACD
│
├── 通道类
│   ├── 唐奇安通道（Donchian Channel）
│   ├── 布林带（Bollinger Bands）
│   └── Keltner Channel
│
├── 系统化交易
│   ├── 海龟交易法则（Turtle Trading）
│   ├── 趋势强度系统（ADX）
│   └── 动量轮动
│
└── 复合型
    ├── 多时间框架确认
    └── 趋势 + 动量 + 波动率
```

```python
趋势策略数据准备

import pandas as pd
import numpy as np


def load_stock_data(
    symbol: str,
    start_date: str = "20200101",

        start_date=start_date,

        adjust="hfq",  # 后复权
    )

    df = df.rename(columns={
        "日期": "date",
        "开盘": "open",
        "最高": "high",
        "最低": "low",
        "收盘": "close",
        "成交量": "volume",
    })

    df["date"] = pd.to_datetime(df["date"])
    df = df.set_index("date")
    df = df[["open", "high", "low", "close", "volume"]].astype(float)

    return df


def calc_technical_indicators(df: pd.DataFrame) -> pd.DataFrame:
    """
    计算常用技术指标
    """
    df = df.copy()

    # 均线
    for window in [5, 10, 20, 60, 120, 250]:
        df[f"ma_{window}"] = df["close"].rolling(window=window).mean()

    # ATR（平均真实波幅）
    df["tr"] = np.maximum(
        df["high"] - df["low"],
        np.maximum(
            abs(df["high"] - df["close"].shift(1)),
            abs(df["low"] - df["close"].shift(1)),
        ),
    )
    df["atr_20"] = df["tr"].rolling(window=20).mean()

    # 唐奇安通道
    for window in [20, 55]:
        df[f"dc_upper_{window}"] = df["high"].rolling(window=window).max()
        df[f"dc_lower_{window}"] = df["low"].rolling(window=window).min()

    return df
```

## 三、双均线交叉策略

### 3.1 策略逻辑

```
双均线交叉信号:

  短期均线 (如 MA5)  ───────────
                               ╲    金叉 → 买入信号
                                ╲
  长期均线 (如 MA20) ─────────────────────────
                                           ╱
                                          ╱   死叉 → 卖出信号
                                ───────────

  金叉: 短期均线从下方穿越长期均线
  死叉: 短期均线从上方穿越长期均线
```

### 3.2 完整实现

```python
# strategies/dual_ma.py
"""
双均线交叉策略
"""
import pandas as pd
import numpy as np


def dual_ma_strategy(
    df: pd.DataFrame,
    short_window: int = 5,
    long_window: int = 20,
    cost_rate: float = 0.001,
) -> pd.DataFrame:
    """
    双均线交叉策略

    信号规则:
        - 金叉（短期均线上穿长期均线）: 买入，仓位=1
        - 死叉（短期均线下穿长期均线）: 卖出，仓位=0

    参数:
        df          : OHLCV 数据
        short_window: 短期均线窗口
        long_window : 长期均线窗口
        cost_rate   : 单边交易成本（佣金+印花税+滑点）

    返回:
        包含信号、仓位、收益的 DataFrame
    """
    result = df.copy()

    # 计算均线
    result["ma_short"] = result["close"].rolling(window=short_window).mean()
    result["ma_long"] = result["close"].rolling(window=long_window).mean()

    # 生成信号
    result["signal"] = 0

    # 金叉: 短均线从下穿上
    golden_cross = (
        (result["ma_short"] > result["ma_long"]) &
        (result["ma_short"].shift(1) <= result["ma_long"].shift(1))
    )
    # 死叉: 短均线从上穿下
    death_cross = (
        (result["ma_short"] < result["ma_long"]) &
        (result["ma_short"].shift(1) >= result["ma_long"].shift(1))
    )

    result.loc[golden_cross, "signal"] = 1
    result.loc[death_cross, "signal"] = -1

    # 生成仓位（信号持续到下一个反向信号）
    result["position"] = 0
    current_pos = 0

    for i in range(len(result)):
        if result["signal"].iloc[i] == 1:
            current_pos = 1
        elif result["signal"].iloc[i] == -1:
            current_pos = 0
        result.iloc[i, result.columns.get_loc("position")] = current_pos

    # 计算收益
    result["daily_return"] = result["close"].pct_change()
    result["strategy_return"] = result["position"].shift(1) * result["daily_return"]

    # 扣除交易成本
    result["trade"] = result["position"].diff().abs()
    result["cost"] = result["trade"] * cost_rate
    result["strategy_return"] = result["strategy_return"] - result["cost"]

    # 累计收益
    result["cum_strategy"] = (1 + result["strategy_return"]).cumprod()
    result["cum_benchmark"] = (1 + result["daily_return"]).cumprod()

    return result
```

### 3.3 性能指标计算

```python
# metrics/performance.py
"""
策略性能指标
"""
import pandas as pd
import numpy as np


def calc_performance_metrics(
    strategy_returns: pd.Series,
    benchmark_returns: pd.Series = None,
    risk_free_rate: float = 0.03,
) -> dict:
    """
    计算策略的核心性能指标

    指标:
        年化收益率、年化波动率、夏普比率、最大回撤、
        胜率、盈亏比、交易次数
    """
    ret = strategy_returns.dropna()

    # 年化收益
    total_return = (1 + ret).prod() - 1
    n_years = len(ret) / 250
    ann_return = (1 + total_return) ** (1 / n_years) - 1 if n_years > 0 else 0

    # 年化波动
    ann_vol = ret.std() * np.sqrt(250)

    # 夏普比率
    sharpe = (ann_return - risk_free_rate) / ann_vol if ann_vol > 0 else 0

    # 最大回撤
    cum = (1 + ret).cumprod()
    peak = cum.cummax()
    drawdown = (cum - peak) / peak
    max_drawdown = drawdown.min()

    # 最大回撤持续时间
    dd_start = None
    dd_end = None
    max_dd_duration = 0
    current_dd_start = None

    for i, dd in enumerate(drawdown):
        if dd < 0 and current_dd_start is None:
            current_dd_start = i
        elif dd == 0 and current_dd_start is not None:
            duration = i - current_dd_start
            if duration > max_dd_duration:
                max_dd_duration = duration
            current_dd_start = None

    # Calmar 比率（年化收益 / 最大回撤）
    calmar = abs(ann_return / max_drawdown) if max_drawdown != 0 else 0

    # 胜率（日级别）
    win_rate = (ret > 0).mean()

    # 盈亏比
    avg_win = ret[ret > 0].mean() if (ret > 0).any() else 0
    avg_loss = abs(ret[ret < 0].mean()) if (ret < 0).any() else 1
    profit_loss_ratio = avg_win / avg_loss if avg_loss > 0 else float("inf")

    # Sortino 比率（用下行波动率）
    downside_ret = ret[ret < 0]
    downside_vol = downside_ret.std() * np.sqrt(250) if len(downside_ret) > 0 else 0
    sortino = (ann_return - risk_free_rate) / downside_vol if downside_vol > 0 else 0

    metrics = {
        "总收益": f"{total_return:.2%}",
        "年化收益": f"{ann_return:.2%}",
        "年化波动": f"{ann_vol:.2%}",
        "夏普比率": round(sharpe, 2),
        "Sortino比率": round(sortino, 2),
        "Calmar比率": round(calmar, 2),
        "最大回撤": f"{max_drawdown:.2%}",
        "最大回撤持续(天)": max_dd_duration,
        "胜率(日)": f"{win_rate:.2%}",
        "盈亏比": round(profit_loss_ratio, 2),
        "交易天数": len(ret),
    }

    # 如果有基准，计算超额收益
    if benchmark_returns is not None:
        bench = benchmark_returns.reindex(ret.index).fillna(0)
        excess = ret - bench
        ann_excess = excess.mean() * 250
        tracking_error = excess.std() * np.sqrt(250)
        info_ratio = ann_excess / tracking_error if tracking_error > 0 else 0

        metrics["超额年化收益"] = f"{ann_excess:.2%}"
        metrics["信息比率"] = round(info_ratio, 2)

    return metrics


def print_metrics(metrics: dict, title: str = "策略性能"):
    """格式化输出性能指标"""
    print(f"\n{'=' * 40}")
    print(f"  {title}")
    print(f"{'=' * 40}")
    for key, value in metrics.items():
        print(f"  {key:<20} {value}")
    print(f"{'=' * 40}\n")
```

## 四、唐奇安通道策略

### 4.1 策略逻辑

```
唐奇安通道突破:

  上轨 (N日最高价)  ──────╲         ╱──────
                           ╲       ╱
  中间                   ╲     ╱  突破上轨 → 买入
                             ╳
  下轨 (N日最低价)  ──────────────╱         ╲────
                                      跌破下轨 → 卖出

  经典参数: 上轨=20日最高, 下轨=10日最低
```

### 4.2 完整实现

```python
# strategies/donchian.py
"""
唐奇安通道突破策略
"""
import pandas as pd
import numpy as np


def donchian_strategy(
    df: pd.DataFrame,
    entry_window: int = 20,
    exit_window: int = 10,
    cost_rate: float = 0.001,
) -> pd.DataFrame:
    """
    唐奇安通道突破策略

    信号规则:
        - 价格突破 N 日最高价: 买入
        - 价格跌破 M 日最低价: 卖出

    入场和出场使用不同窗口:
    - 入场窗口较长（如20日），捕捉大趋势
    - 出场窗口较短（如10日），快速止损

    参数:
        df          : OHLCV 数据
        entry_window: 入场通道窗口
        exit_window : 出场通道窗口
        cost_rate   : 交易成本
    """
    result = df.copy()

    # 计算通道
    result["upper"] = result["high"].rolling(window=entry_window).max().shift(1)
    result["lower"] = result["low"].rolling(window=exit_window).min().shift(1)

    # 生成信号
    result["signal"] = 0
    result.loc[result["close"] > result["upper"], "signal"] = 1    # 突破上轨买入
    result.loc[result["close"] < result["lower"], "signal"] = -1   # 跌破下轨卖出

    # 仓位管理
    result["position"] = 0
    current_pos = 0

    for i in range(len(result)):
        sig = result["signal"].iloc[i]
        if sig == 1:
            current_pos = 1
        elif sig == -1:
            current_pos = 0
        result.iloc[i, result.columns.get_loc("position")] = current_pos

    # 计算收益
    result["daily_return"] = result["close"].pct_change()
    result["strategy_return"] = result["position"].shift(1) * result["daily_return"]
    result["trade"] = result["position"].diff().abs()
    result["cost"] = result["trade"] * cost_rate
    result["strategy_return"] -= result["cost"]

    result["cum_strategy"] = (1 + result["strategy_return"]).cumprod()
    result["cum_benchmark"] = (1 + result["daily_return"]).cumprod()

    return result
```

## 五、海龟交易法则

### 5.1 策略逻辑

海龟交易法则是 1983 年由 Richard Dennis 和 William Eckhardt 进行的著名交易实验中使用的完整交易系统。它是趋势跟踪策略的"教科书"级别实现。

```
海龟交易法则核心组件:

┌─────────────────────────────────────────────────┐
│              海龟交易系统                         │
├─────────────────────────────────────────────────┤
│                                                  │
│  1. 入场信号: 唐奇安通道突破                       │
│     - 系统1: 20日突破（短期）                      │
│     - 系统2: 55日突破（长期）                      │
│                                                  │
│  2. 仓位管理: 基于ATR的头寸规模                    │
│     - 1个Unit = 账户的1% / ATR                    │
│     - 每次加仓1个Unit，最多加仓4次                 │
│     - Unit之间间隔 0.5*ATR                        │
│                                                  │
│  3. 止损: 2*ATR                                   │
│     - 从入场价/加仓价计算                         │
│     - 所有Unit统一止损价                          │
│                                                  │
│  4. 出场: 10日/20日反向突破                        │
│     - 系统1: 10日反向突破出场                      │
│     - 系统2: 20日反向突破出场                      │
│                                                  │
└─────────────────────────────────────────────────┘
```

### 5.2 ATR 仓位计算

```python
# strategies/turtle.py
"""
海龟交易法则
"""
import pandas as pd
import numpy as np
from dataclasses import dataclass, field


@dataclass
class TurtleConfig:
    """海龟交易配置"""
    entry_window: int = 20        # 入场突破窗口
    exit_window: int = 10         # 出场突破窗口
    atr_window: int = 20          # ATR 计算窗口
    risk_per_trade: float = 0.01  # 每笔交易风险（账户的1%）
    max_units: int = 4            # 最大加仓次数
    unit_gap_atr: float = 0.5     # 加仓间隔（ATR倍数）
    stop_loss_atr: float = 2.0    # 止损距离（ATR倍数）
    cost_rate: float = 0.001      # 交易成本


def calc_atr(df: pd.DataFrame, window: int = 20) -> pd.Series:
    """
    计算 ATR（Average True Range）

    ATR 衡量市场波动程度，是海龟系统仓位管理的基础
    """
    tr = np.maximum(
        df["high"] - df["low"],
        np.maximum(
            abs(df["high"] - df["close"].shift(1)),
            abs(df["low"] - df["close"].shift(1)),
        ),
    )
    atr = tr.rolling(window=window).mean()
    return atr


def calc_position_size(
    account_value: float,
    atr: float,
    config: TurtleConfig,
) -> int:
    """
    计算海龟系统的头寸规模（Unit Size）

    公式:
        Dollar Volatility = N * Contract_Size
        Unit = Account * Risk% / Dollar Volatility

    简化版本（股票）:
        Unit = Account * 1% / ATR

    这意味着: 如果ATR较大（波动大），仓位较小；ATR较小（波动小），仓位较大
    目的是让每个交易单位承担相同的风险金额
    """
    if atr <= 0:
        return 0

    dollar_risk = account_value * config.risk_per_trade
    unit_size = int(dollar_risk / atr)

    # 确保至少100股（A股最小交易单位）
    unit_size = max(100, (unit_size // 100) * 100)

    return unit_size


@dataclass
class TurtlePosition:
    """海龟仓位状态"""
    units: int = 0                # 当前持有Unit数
    entry_prices: list = field(default_factory=list)  # 各Unit的入场价
    stop_price: float = 0.0       # 止损价
    last_add_price: float = 0.0   # 最近一次加仓价

    @property
    def avg_price(self) -> float:
        if not self.entry_prices:
            return 0
        return np.mean(self.entry_prices)

    @property
    def is_open(self) -> bool:
        return self.units > 0


def turtle_strategy(
    df: pd.DataFrame,
    initial_capital: float = 1_000_000,
    config: TurtleConfig = None,
) -> pd.DataFrame:
    """
    海龟交易法则完整实现

    参数:
        df             : OHLCV 数据
        initial_capital: 初始资金
        config         : 策略配置
    """
    if config is None:
        config = TurtleConfig()

    result = df.copy()

    # 计算指标
    result["atr"] = calc_atr(result, config.atr_window)
    result["entry_upper"] = result["high"].rolling(window=config.entry_window).max().shift(1)
    result["entry_lower"] = result["low"].rolling(window=config.entry_window).min().shift(1)
    result["exit_lower"] = result["low"].rolling(window=config.exit_window).min().shift(1)

    # 初始化
    capital = initial_capital
    position = TurtlePosition()
    records = []

    for i in range(len(result)):
        row = result.iloc[i]
        date = result.index[i]
        close = row["close"]
        atr = row["atr"]

        if pd.isna(atr) or atr <= 0:
            records.append({
                "date": date,
                "capital": capital,
                "position_units": 0,
                "signal": "无",
            })
            continue

        signal = "无"

        # === 入场/加仓逻辑 ===
        if not position.is_open:
            # 无持仓时，突破20日最高价买入
            if close > row["entry_upper"]:
                unit_size = calc_position_size(capital, atr, config)
                position.units = 1
                position.entry_prices = [close]
                position.last_add_price = close
                position.stop_price = close - config.stop_loss_atr * atr
                signal = "入场买入"
        else:
            # 已持仓时，检查是否可以加仓
            if position.units < config.max_units:
                add_price = position.last_add_price + config.unit_gap_atr * atr
                if close >= add_price:
                    unit_size = calc_position_size(capital, atr, config)
                    position.units += 1
                    position.entry_prices.append(close)
                    position.last_add_price = close
                    # 止损价跟随上移
                    position.stop_price = close - config.stop_loss_atr * atr
                    signal = f"加仓({position.units}Unit)"

        # === 止损逻辑 ===
        if position.is_open and close <= position.stop_price:
            # 止损出场
            pnl = (close - position.avg_price) / position.avg_price
            capital *= (1 + pnl)
            signal = f"止损出场(pnl={pnl:.2%})"
            position = TurtlePosition()

        # === 通道出场逻辑 ===
        elif position.is_open and close < row["exit_lower"]:
            pnl = (close - position.avg_price) / position.avg_price
            capital *= (1 + pnl)
            signal = f"通道出场(pnl={pnl:.2%})"
            position = TurtlePosition()

        records.append({
            "date": date,
            "capital": capital,
            "position_units": position.units,
            "avg_price": position.avg_price,
            "stop_price": position.stop_price,
            "signal": signal,
        })

    result_record = pd.DataFrame(records).set_index("date")
    result = result.join(result_record)

    # 计算收益率
    result["strategy_return"] = result["capital"].pct_change()
    result["daily_return"] = result["close"].pct_change()
    result["cum_strategy"] = result["capital"] / initial_capital
    result["cum_benchmark"] = (1 + result["daily_return"]).cumprod()

    return result
```

## 六、A 股特殊约束处理

### 6.1 T+1 制度

```python
def apply_t1_constraint(signals: pd.Series) -> pd.Series:
    """
    A股T+1制度处理

    问题: A股当日买入的股票当日不能卖出
    影响: 如果今天发出买入信号并执行，即使明天立刻发出卖出信号也无法执行

    方案: 卖出信号延迟一天执行
    """
    adjusted = signals.copy()

    for i in range(1, len(adjusted)):
        # 如果今天要卖出，但昨天刚买入（即今天是买入后的第一天）
        if adjusted.iloc[i] == -1 and adjusted.iloc[i - 1] == 1:
            # 延迟到明天执行卖出
            adjusted.iloc[i] = 0
            if i + 1 < len(adjusted):
                adjusted.iloc[i + 1] = -1

    return adjusted


def apply_price_limit_filter(
    signals: pd.DataFrame,
    prices: pd.DataFrame,
) -> pd.DataFrame:
    """
    涨跌停过滤

    问题: 涨停无法买入，跌停无法卖出
    方案: 过滤掉不可执行的信号
    """
    filtered = signals.copy()

    # 涨停判断（涨幅>=9.8%考虑精度容差）
    limit_up = prices["close"].pct_change() >= 0.098
    limit_down = prices["close"].pct_change() <= -0.098

    # 涨停时的买入信号无法执行
    filtered.loc[limit_up & (signals == 1)] = 0
    # 跌停时的卖出信号无法执行
    filtered.loc[limit_down & (signals == -1)] = 0

    return filtered
```

### 6.2 综合回测框架

```python
# backtest/engine.py
"""
回测引擎
"""
import pandas as pd
import numpy as np


class BacktestEngine:
    """
    简化版回测引擎

    支持:
    - T+1 约束
    - 涨跌停过滤
    - 交易成本
    - 滑点模拟
    """

    def __init__(
        self,
        initial_capital: float = 1_000_000,
        cost_rate: float = 0.0015,   # 佣金+印花税
        slippage: float = 0.001,     # 滑点
    ):
        self.initial_capital = initial_capital
        self.cost_rate = cost_rate
        self.slippage = slippage

    def run(
        self,
        prices: pd.DataFrame,
        signals: pd.Series,
    ) -> dict:
        """
        执行回测

        参数:
            prices  : OHLCV 数据
            signals : 交易信号 (1=买入, -1=卖出, 0=持有)
        """
        # 应用约束
        signals = apply_t1_constraint(signals)
        signals = apply_price_limit_filter(signals, prices)

        # 初始化
        capital = self.initial_capital
        shares = 0
        position = 0  # 0=空仓, 1=持仓

        records = []

        for i in range(len(prices)):
            date = prices.index[i]
            close = prices["close"].iloc[i]
            signal = signals.iloc[i]

            trade_price = close * (1 + self.slippage * signal)  # 滑点

            # 执行交易
            if signal == 1 and position == 0:
                # 买入
                cost = capital * self.cost_rate
                shares = int((capital - cost) / trade_price / 100) * 100
                capital = capital - shares * trade_price - cost
                position = 1

            elif signal == -1 and position == 1:
                # 卖出
                revenue = shares * trade_price
                cost = revenue * self.cost_rate
                capital = capital + revenue - cost
                shares = 0
                position = 0

            # 记录
            total_value = capital + shares * close
            records.append({
                "date": date,
                "capital": capital,
                "shares": shares,
                "total_value": total_value,
                "position": position,
            })

        result = pd.DataFrame(records).set_index("date")
        result["daily_return"] = result["total_value"].pct_change()
        result["cum_return"] = result["total_value"] / self.initial_capital

        return result
```

## 七、参数敏感性分析

```python
def parameter_sensitivity(
    df: pd.DataFrame,
    strategy_func,
    param_name: str,
    param_values: list,
) -> pd.DataFrame:
    """
    参数敏感性分析

    检验策略对参数的敏感程度
    好的策略应该在一定参数范围内都有效，而不是只在某个特定参数下有效
    """
    from metrics.performance import calc_performance_metrics

    results = []

    for value in param_values:
        params = {param_name: value}
        strategy_result = strategy_func(df, **params)

        metrics = calc_performance_metrics(
            strategy_result["strategy_return"].dropna(),
            strategy_result["daily_return"].dropna(),
        )

        metrics[param_name] = value
        results.append(metrics)

    return pd.DataFrame(results)


def monte_carlo_permutation_test(
    returns: pd.Series,
    n_simulations: int = 1000,
) -> dict:
    """
    蒙特卡洛排列检验

    将收益率序列随机打乱，重新计算策略指标，
    检验原始策略的表现是否显著优于随机策略
    """
    from metrics.performance import calc_performance_metrics

    original_metrics = calc_performance_metrics(returns)
    original_sharpe = original_metrics["夏普比率"]

    simulated_sharpes = []
    for _ in range(n_simulations):
        shuffled = returns.sample(frac=1).reset_index(drop=True)
        shuffled.index = returns.index
        m = calc_performance_metrics(shuffled)
        simulated_sharpes.append(m["夏普比率"])

    p_value = (np.array(simulated_sharpes) >= original_sharpe).mean()

    return {
        "原始夏普": original_sharpe,
        "模拟夏普均值": np.mean(simulated_sharpes),
        "p值": p_value,
        "是否显著(p<0.05)": p_value < 0.05,
    }
```

## 常见误区

### 误区一：趋势策略在所有市场都有效

趋势跟踪在**趋势明显的市场**表现好（如 2020-2021 年的结构性牛市），在**震荡市**中会反复止损，产生持续亏损。A 股的震荡市比例较高，这是趋势策略在 A 股面临的主要挑战。

### 误区二：只看收益不看回撤

一个策略年化收益 30%，但最大回撤 50%，你能在回撤中坚持执行吗？现实中很多投资者在回撤 20% 时就会放弃策略。夏普比率和 Calmar 比率比绝对收益更重要。

### 误区三：忽略交易成本和滑点

趋势策略的交易频率相对较高，如果每次交易成本 0.3%（佣金+印花税+滑点），月度换仓 2 次，年化交易成本就有 7.2%。这对策略收益的侵蚀是巨大的。

### 误区四：过度优化参数

"我的双均线策略在 MA(7, 23) 时回测收益最高"——这大概率是过拟合。参数敏感性分析的目的就是检查策略在不同参数下是否都有效。如果只在某个特定参数下有效，这个策略很可能是数据挖掘的产物。

### 误区五：用收盘价模拟实际交易

回测中用收盘价交易是不现实的——收盘价是收盘后才知道的。更合理的做法是用次日开盘价或 VWAP 执行。如果策略依赖日内突破信号，应该用分钟级数据。

## 小结与练习

### 本课要点

- **双均线交叉**是最基础的趋势策略，适合入门理解，但信号滞后
- **唐奇安通道**用高低点突破作为信号，比均线更直接地捕捉价格新高/新低
- **海龟交易法则**是一个完整的交易系统，包含入场、仓位管理、止损、出场四大模块
- **ATR 仓位管理**让每个交易单位承担相同风险金额，是系统化交易的核心
- **A 股约束**（T+1、涨跌停）必须在回测中考虑，否则结果会高估
- **参数敏感性**分析是区分"真正有效"和"过拟合"的关键

### 练习二：海龟仓位计算

**答案**：
```python
import numpy as np

def turtle_position_sizing(account_value, atr, risk_pct=0.01, min_lot=100):
    """
    海龟仓位计算

    参数:
        account_value: 账户总值
        atr          : 当前ATR
        risk_pct     : 每笔交易风险比例（默认1%）
        min_lot      : 最小交易单位（A股100股）
    """
    if atr <= 0:
        return 0

    dollar_risk = account_value * risk_pct
    unit_shares = dollar_risk / atr

    # 向下取整到最小交易单位
    unit_shares = int(unit_shares / min_lot) * min_lot
    unit_shares = max(min_lot, unit_shares)

    return unit_shares

# 示例
account = 1_000_000
atr = 15.5  # 假设ATR为15.5元

unit = turtle_position_sizing(account, atr)
risk_per_unit = unit * atr
risk_pct = risk_per_unit / account

print(f"账户价值: {account:,.0f}")
print(f"ATR: {atr}")
print(f"Unit大小: {unit} 股")
print(f"每Unit风险金额: {risk_per_unit:,.0f}")
print(f"每Unit风险比例: {risk_pct:.2%}")
```

**要点**：
- ATR 越大，Unit 越小——波动大时减少仓位，保持风险金额恒定
- 1% 的风险意味着连续 10 次止损才会亏损约 10%
- A 股有 100 股的最小交易单位限制，需要向下取整

### 练习三：趋势策略的 A 股适配

**思路**：在标准策略基础上增加 T+1 和涨跌停的处理。

**答案**：
```python
def adapt_for_a_share(signals, daily_pct_change):
    """
    A股适配处理

    参数:
        signals        : 原始交易信号
        daily_pct_change: 日涨跌幅
    """
    adjusted = signals.copy()

    # 1. 涨跌停过滤
    limit_up = daily_pct_change >= 0.098
    limit_down = daily_pct_change <= -0.098

    # 涨停不买入
    adjusted[limit_up & (adjusted == 1)] = 0
    # 跌停不卖出
    adjusted[limit_down & (adjusted == -1)] = 0

    # 2. T+1约束: 买入当天不能卖出
    for i in range(1, len(adjusted)):
        if adjusted.iloc[i] == -1 and adjusted.iloc[i-1] == 1:
            adjusted.iloc[i] = 0  # 取消今天的卖出

    # 3. 统计被过滤的信号
    filtered_count = (signals != adjusted).sum()
    print(f"原始信号数: {(signals != 0).sum()}")
    print(f"被过滤信号: {filtered_count}")
    print(f"有效信号数: {(adjusted != 0).sum()}")

    return adjusted
```

**要点**：
- T+1 的影响：信号延迟一天执行会略微降低收益，但更贴近实际
- 涨跌停的影响：在涨停板较多的市场环境下，可能错过大量买入机会
- 建议在回测中统计"被过滤信号"的比例，评估约束的影响程度
