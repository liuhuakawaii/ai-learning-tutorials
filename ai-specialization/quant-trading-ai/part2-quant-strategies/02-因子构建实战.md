# 因子构建实战

## 场景引入

上一章我们学习了因子投资的理论基础——知道了什么是因子、为什么因子能获取超额收益、以及 A 股市场常见的因子类型。但从理论到实践之间，横亘着一条巨大的鸿沟：**如何把一个抽象的因子概念，变成一行行可运行的代码？**

比如"动量因子"，教科书上写的是"过去 12 个月涨幅最大的股票未来表现更好"。但实操中你会遇到大量细节问题：

- 12 个月是用 250 个交易日还是 252 个？月初还是月末对齐？
- 最近 1 个月要不要跳过？（A 股短期反转效应很强）
- 行业之间天然有动量差异，怎么消除行业影响？
- 涨停板买不进去的股票怎么处理？

本节课将带你从零构建四类核心因子——**动量、价值、质量、波动率**，每个因子都给出完整的 Python 实现，并针对 A 股的特殊性做专门处理。

> **风险提示**：本课程仅用于量化投资技术教学，不构成任何投资建议。因子投资存在模型风险、数据偏差等多重风险，历史回测表现不代表未来收益。

### 1.2 因子标准化工具函数

在构建任何因子之前，先实现标准化工具函数：

```python
# factor_utils.py
"""
因子构建的通用工具函数
"""
import pandas as pd
import numpy as np


def winsorize_mad(series: pd.Series, n_mad: float = 5.0) -> pd.Series:
    """
    MAD（Median Absolute Deviation）去极值

    相比传统的 3σ 去极值，MAD 对极端值更鲁棒：
    - 3σ 用 mean 和 std，容易被极端值本身影响
    - MAD 用 median 和 MAD，不受极端值干扰

    公式:
        MAD = median(|Xi - median(X)|)
        上界 = median + n_mad * 1.4826 * MAD
        下界 = median - n_mad * 1.4826 * MAD
    """
    median = series.median()
    mad = (series - median).abs().median()
    mad_e = 1.4826 * mad  # 转换为与标准差等价的尺度

    upper = median + n_mad * mad_e
    lower = median - n_mad * mad_e

    return series.clip(lower=lower, upper=upper)


def standardize_zscore(series: pd.Series) -> pd.Series:
    """
    Z-Score 标准化

    将因子值转化为均值为 0、标准差为 1 的分布
    """
    mean = series.mean()
    std = series.std()
    if std == 0 or np.isnan(std):
        return series * 0
    return (series - mean) / std


def process_factor(factor_series: pd.Series) -> pd.Series:
    """
    因子标准化流水线：去极值 -> 缺失值填充 -> Z-Score
    """
    result = winsorize_mad(factor_series)
    result = result.fillna(result.median())
    result = standardize_zscore(result)
    return result


def rank_normalize(series: pd.Series) -> pd.Series:
    """
    排名标准化：将因子值转换为 [0, 1] 区间的排名百分位

    适用于需要消除因子分布非线性影响的场景
    """
    return series.rank(pct=True)
```

## 二、动量因子

### 2.1 动量效应的经济学逻辑

动量效应是最经典的市场异象之一：**过去涨得好的股票，未来继续涨得好**。这与有效市场假说矛盾——如果市场是有效的，过去的价格信息不应该能预测未来。

在 A 股中，动量效应有一些特殊表现：
- **长期动量有效**：12 个月的动量信号通常正向
- **短期反转明显**：最近 1 个月涨幅大的股票，下个月反而倾向于回调（涨跌停制度加剧了这一点）
- **行业动量显著**：行业轮动是 A 股的重要特征

### 2.2 经典动量因子（12M-1M）

```python
# factors/momentum.py
"""
动量因子构建
"""
import pandas as pd
import numpy as np
from typing import Optional


def calc_price_momentum(
    prices: pd.DataFrame,
    lookback: int = 250,
    skip: int = 20,
) -> pd.DataFrame:
    """
    经典价格动量因子（12M-1M Momentum）

    定义:
        momentum = close[t-skip] / close[t-lookback] - 1

    即过去 12 个月（lookback=250）的涨幅，但跳过最近 1 个月（skip=20）

    为什么要跳过最近1个月？
    - A股存在显著的短期反转效应
    - 跳过最近1个月可以过滤掉反转噪音，提升动量信号质量
    - 这也是学术文献中的标准做法（Jegadeesh & Titman, 1993）

    参数:
        prices  : DataFrame，index为日期，columns为股票代码，values为收盘价
        lookback: 回看窗口（交易日数）
        skip    : 跳过最近的交易日数

    返回:
        动量因子 DataFrame（同 prices 结构）
    """
    if prices.empty:
        return pd.DataFrame()

    # 确保按日期排序
    prices = prices.sort_index()

    # close[t-skip]: 跳过最近skip天的价格
    price_skip = prices.shift(skip)

    # close[t-lookback]: 回看起点的价格
    price_lookback = prices.shift(lookback)

    # 动量 = 区间涨幅
    momentum = price_skip / price_lookback - 1

    # 处理除零和异常值
    momentum = momentum.replace([np.inf, -np.inf], np.nan)

    return momentum


def calc_industry_relative_momentum(
    momentum: pd.DataFrame,
    industry_map: pd.Series,
) -> pd.DataFrame:
    """
    行业相对动量因子

    消除行业间动量差异，只保留个股在行业内的相对动量排名

    为什么要做行业相对化？
    - 某些行业天然有更高的动量（如牛市中的券商）
    - 不做行业中性化，动量策略会集中在少数热门行业
    - 行业相对动量可以更好地捕捉个股层面的动量效应

    参数:
        momentum    : 原始动量因子
        industry_map: Series，index为股票代码，values为行业代码

    返回:
        行业相对动量因子
    """
    result = momentum.copy()

    for date in momentum.index:
        daily = momentum.loc[date].dropna()
        if daily.empty:
            continue

        # 按行业分组，组内排名标准化
        daily_df = daily.to_frame("momentum")
        daily_df["industry"] = daily_df.index.map(industry_map)
        daily_df = daily_df.dropna(subset=["industry"])

        # 行业内排名百分位
        daily_df["rank_in_industry"] = daily_df.groupby("industry")["momentum"].rank(pct=True)

        result.loc[date, daily_df.index] = daily_df["rank_in_industry"]

    return result


def calc_momentum_composite(
    prices: pd.DataFrame,
    windows: list[int] = None,
    weights: list[float] = None,
) -> pd.DataFrame:
    """
    多窗口复合动量

    单一窗口的动量因子容易受到特定时间段的影响，
    多窗口复合可以提高信号的稳定性

    参数:
        prices : 价格数据
        windows: 多个回看窗口（默认 [20, 60, 120, 250]）
        weights: 各窗口权重（默认等权）
    """
    if windows is None:
        windows = [20, 60, 120, 250]
    if weights is None:
        weights = [1.0 / len(windows)] * len(windows)

    factors = []
    for window in windows:
        # 每个窗口都跳过最近5天
        mom = calc_price_momentum(prices, lookback=window, skip=5)
        # 排名标准化后加权
        mom_rank = mom.rank(axis=1, pct=True)
        factors.append(mom_rank * weights[0])  # 使用指定权重

    # 合成
    composite = sum(f for f, w in zip(factors, weights))

    return composite
```

### 2.3 行业动量因子

```python
def calc_sector_momentum(
    prices: pd.DataFrame,
    industry_map: pd.Series,
    lookback: int = 60,
) -> pd.DataFrame:
    """
    行业动量因子

    计算每个行业的整体动量，然后映射回个股
    适用于行业轮动策略
    """
    # 构建行业等权指数
    industry_prices = pd.DataFrame()
    for industry in industry_map.unique():
        stocks = industry_map[industry_map == industry].index
        valid_stocks = [s for s in stocks if s in prices.columns]
        if valid_stocks:
            industry_prices[industry] = prices[valid_stocks].mean(axis=1)

    # 计算行业动量
    industry_momentum = industry_prices / industry_prices.shift(lookback) - 1

    # 映射回个股
    stock_momentum = pd.DataFrame(index=prices.index, columns=prices.columns)
    for date in industry_momentum.index:
        for stock in prices.columns:
            ind = industry_map.get(stock)
            if ind in industry_momentum.columns:
                stock_momentum.loc[date, stock] = industry_momentum.loc[date, ind]

    return stock_momentum.astype(float)
```

## 三、价值因子

### 3.1 价值因子的经济学逻辑

价值因子基于一个朴素的投资理念：**买便宜的股票**。便宜不是指股价低，而是相对于公司的基本面（盈利、净资产等）而言，市场价格偏低。

格雷厄姆和多德在《证券分析》中最早系统阐述了这一思想。后续学术研究将其量化为各种估值指标。

在 A 股中，价值因子的表现有周期性：在大盘风格占优时表现好，在成长风格占优时可能持续跑输。

### 3.2 EP 因子（Earnings-to-Price）

```python
# factors/value.py
"""
价值因子构建
"""
import pandas as pd
import numpy as np


def calc_ep_factor(
    net_profit: pd.Series,
    market_cap: pd.Series,
) -> pd.Series:
    """
    EP 因子（盈利收益率 = 净利润 / 总市值）

    EP 是 PE 的倒数，逻辑上更自然：
    - PE 越高，EP 越低，股票越"贵"
    - EP 越高，股票相对越"便宜"

    为什么用 EP 而不是 PE？
    - EP 的分布更接近正态分布（PE 是偏态的）
    - EP 可以直接处理亏损股（EP为负），而 PE 在亏损时无意义
    - 因子标准化对正态分布的数据更有效

    参数:
        net_profit: 净利润（TTM）
        market_cap: 总市值

    返回:
        EP 因子 Series
    """
    # 避免除零
    ep = net_profit / market_cap.replace(0, np.nan)
    ep.name = "ep"
    return ep


def calc_bp_factor(
    book_value: pd.Series,
    market_cap: pd.Series,
) -> pd.Series:
    """
    BP 因子（账面市值比 = 净资产 / 总市值）

    BP 是 PB 的倒数，衡量的是每花 1 元钱能买到多少净资产
    """
    bp = book_value / market_cap.replace(0, np.nan)
    bp.name = "bp"
    return bp


def calc_sp_factor(
    revenue: pd.Series,
    market_cap: pd.Series,
) -> pd.Series:
    """
    SP 因子（营收市值比 = 营业收入 / 总市值）

    SP 是 PS 的倒数，适用于高利润波动的行业（如周期股）
    因为收入比利润更稳定
    """
    sp = revenue / market_cap.replace(0, np.nan)
    sp.name = "sp"
    return sp


def calc_composite_value(
    ep: pd.Series,
    bp: pd.Series,
    sp: pd.Series,
    weights: dict = None,
) -> pd.Series:
    """
    复合价值因子

    单一估值指标容易受会计政策、行业特征影响，
    多指标合成可以提高价值因子的稳定性

    参数:
        ep      : EP 因子
        bp      : BP 因子
        sp      : SP 因子
        weights : 各因子权重（默认等权）
    """
    if weights is None:
        weights = {"ep": 1/3, "bp": 1/3, "sp": 1/3}

    # 先对每个因子做排名标准化
    ep_rank = ep.rank(pct=True)
    bp_rank = bp.rank(pct=True)
    sp_rank = sp.rank(pct=True)

    # 加权合成
    composite = (
        ep_rank * weights.get("ep", 0) +
        bp_rank * weights.get("bp", 0) +
        sp_rank * weights.get("sp", 0)
    )
    composite.name = "composite_value"

    return composite
```

### 3.3 A 股价值因子的注意事项

```python
def filter_for_value_factor(
    df: pd.DataFrame,
    min_listing_days: int = 250,
) -> pd.DataFrame:
    """
    价值因子的样本过滤

    A 股特殊处理:
        1. 排除上市不足1年的股票（财务数据不稳定）
        2. 排除净资产为负的股票（BP 无意义）
        3. 排除金融行业（特殊的资本结构）
        4. 排除ST股（异常估值）
    """
    # 排除上市不足1年
    if "listing_date" in df.columns:
        from datetime import datetime, timedelta
        cutoff = datetime.now() - timedelta(days=min_listing_days)
        df = df[df["listing_date"] < cutoff]

    # 排除净资产为负
    if "book_value" in df.columns:
        df = df[df["book_value"] > 0]

    # 排除金融行业（银行、券商、保险）
    financial_industries = ["银行", "非银金融", "保险"]
    if "industry" in df.columns:
        df = ~df["industry"].isin(financial_industries)

    # 排除ST股
    if "is_st" in df.columns:
        df = df[~df["is_st"]]

    return df
```

## 四、质量因子

### 4.1 质量因子的经济学逻辑

质量因子的核心观点是：**高质量的公司长期表现更好**。这个逻辑很直觉——盈利能力强、财务健康、经营稳定的公司，理应获得更高的市场定价。

但市场并不完美定价"质量"，原因包括：
- 短期资金追逐高增长，忽视盈利质量
- 分析师覆盖不足的中小盘股，质量信息未被充分反映
- 散户主导的 A 股市场，质量定价效率更低

### 4.2 ROE 因子

```python
# factors/quality.py
"""
质量因子构建
"""
import pandas as pd
import numpy as np


def calc_roe_factor(
    net_profit_ttm: pd.Series,
    equity: pd.Series,
) -> pd.Series:
    """
    ROE 因子（净资产收益率 = 净利润TTM / 净资产）

    ROE 是衡量公司盈利能力最核心的指标
    巴菲特长期强调高 ROE 是选股的关键标准

    使用 TTM（滚动12个月）净利润而非单季度:
    - 平滑季节性波动
    - 更能反映持续盈利能力

    参数:
        net_profit_ttm : TTM净利润
        equity         : 净资产（股东权益）
    """
    roe = net_profit_ttm / equity.replace(0, np.nan)
    roe.name = "roe"
    return roe


def calc_gross_margin_factor(
    gross_profit: pd.Series,
    revenue: pd.Series,
) -> pd.Series:
    """
    毛利率因子（毛利润 / 营业收入）

    高毛利率通常意味着:
    - 产品有定价权（品牌溢价或技术壁垒）
    - 成本控制能力强
    - 竞争格局有利

    注意: 不同行业毛利率天然不同（白酒 vs 超市），
    因此使用时必须做行业中性化
    """
    margin = gross_profit / revenue.replace(0, np.nan)
    margin.name = "gross_margin"
    return margin


def calc_earnings_stability(
    quarterly_profit: pd.DataFrame,
    n_quarters: int = 8,
) -> pd.Series:
    """
    盈利稳定性因子

    用过去 N 个季度的净利润变异系数（CV）来衡量盈利稳定性
    CV 越低，盈利越稳定

    参数:
        quarterly_profit: DataFrame，每列为一只股票，每行为一个季度的净利润
        n_quarters      : 回看的季度数

    返回:
        稳定性因子（值越大越稳定，即取 -CV）
    """
    recent = quarterly_profit.tail(n_quarters)
    mean = recent.mean()
    std = recent.std()

    # 变异系数 CV = std / mean
    cv = std / mean.abs().replace(0, np.nan)

    # 取负号，因为 CV 越低越好，而因子值越大越好
    stability = -cv
    stability.name = "earnings_stability"

    return stability


def calc_quality_composite(
    roe: pd.Series,
    gross_margin: pd.Series,
    stability: pd.Series,
    industry: pd.Series,
    weights: dict = None,
) -> pd.Series:
    """
    复合质量因子

    将 ROE、毛利率、盈利稳定性三个维度合成

    关键步骤: 行业中性化
    - ROE 需要行业对比（高 ROE 在不同行业含义不同）
    - 毛利率必须行业对比（行业间差异巨大）
    - 稳定性也需要行业对比（周期行业天然不稳定）
    """
    if weights is None:
        weights = {"roe": 0.4, "margin": 0.3, "stability": 0.3}

    df = pd.DataFrame({
        "roe": roe,
        "gross_margin": gross_margin,
        "stability": stability,
        "industry": industry,
    })

    # 行业中性化：行业内排名标准化
    for col in ["roe", "gross_margin", "stability"]:
        df[f"{col}_rank"] = df.groupby("industry")[col].rank(pct=True)

    # 加权合成
    composite = (
        df["roe_rank"] * weights["roe"] +
        df["gross_margin_rank"] * weights["margin"] +
        df["stability_rank"] * weights["stability"]
    )
    composite.name = "quality_composite"

    return composite
```

### 4.3 应计利润因子（Accruals）

```python
def calc_accruals_factor(
    net_profit: pd.Series,
    operating_cashflow: pd.Series,
    total_assets: pd.Series,
) -> pd.Series:
    """
    应计利润因子

    应计利润 = (净利润 - 经营现金流) / 总资产

    逻辑:
    - 应计利润高的公司，盈利质量可能较低（靠会计手段增厚利润）
    - 应计利润低的公司，盈利更多来自实实在在的现金流
    - Sloan (1996) 首次发现应计利润异象

    在 A 股中:
    - 应计利润因子长期有效
    - 尤其在中小盘股中效果更明显
    """
    accruals = (net_profit - operating_cashflow) / total_assets.replace(0, np.nan)

    # 因子方向：应计利润越低越好，取负号
    factor = -accruals
    factor.name = "low_accruals"

    return factor
```

## 五、波动率因子

### 5.1 低波动异象

传统金融理论认为高风险（高波动）对应高收益，但实证研究发现了一个反直觉的现象：**低波动的股票长期收益反而更高**。这被称为"低波动异象"（Low Volatility Anomaly）。

原因可能包括：
- 彩票偏好：散户偏好高波动的"彩票型"股票，推高其价格、降低未来收益
- 基准约束：机构投资者为了不偏离基准太多，倾向于持有高 beta 股票
- 杠杆约束：无法加杠杆的投资者只能通过买高波动股来提高收益

### 5.2 已实现波动率

```python
# factors/volatility.py
"""
波动率因子构建
"""
import pandas as pd
import numpy as np


def calc_realized_volatility(
    returns: pd.DataFrame,
    window: int = 60,
) -> pd.DataFrame:
    """
    已实现波动率因子

    计算过去 N 天日收益率的标准差

    参数:
        returns: DataFrame，日收益率，index为日期，columns为股票代码
        window : 回看窗口（默认60个交易日，约3个月）

    返回:
        波动率因子（值越小代表波动越低，越"好"）
    """
    # 已实现波动率 = 日收益率标准差 * sqrt(250) 年化
    vol = returns.rolling(window=window, min_periods=int(window * 0.8)).std() * np.sqrt(250)

    # 取负号：低波动因子，波动越低因子值越大
    factor = -vol
    factor.columns = [f"neg_vol_{window}d" for _ in factor.columns]

    return factor


def calc_idiosyncratic_volatility(
    returns: pd.DataFrame,
    market_return: pd.Series,
    window: int = 60,
) -> pd.DataFrame:
    """
    特质波动率因子（Idiosyncratic Volatility）

    特质波动率 = 个股收益率对市场收益率回归后的残差标准差

    逻辑:
    - 已实现波动率包含了系统性风险（市场波动）
    - 特质波动率只衡量个股特有的风险
    - 特质波动率更能反映个股的"彩票属性"

    参数:
        returns      : 个股日收益率
        market_return: 市场日收益率（如沪深300）
        window       : 回归窗口
    """
    import statsmodels.api as sm

    result = pd.DataFrame(index=returns.index, columns=returns.columns, dtype=float)

    for end_idx in range(window, len(returns)):
        start_idx = end_idx - window
        window_returns = returns.iloc[start_idx:end_idx]
        window_market = market_return.iloc[start_idx:end_idx]

        for stock in returns.columns:
            stock_returns = window_returns[stock].dropna()
            aligned_market = window_market.reindex(stock_returns.index).dropna()
            common_idx = stock_returns.index.intersection(aligned_market.index)

            if len(common_idx) < window * 0.5:
                continue

            y = stock_returns.loc[common_idx].values
            X = sm.add_constant(aligned_market.loc[common_idx].values)

            try:
                model = sm.OLS(y, X).fit()
                residual_std = model.resid.std()
                result.iloc[end_idx][stock] = residual_std
            except Exception:
                continue

    # 取负号
    return -result.astype(float)


def calc_downside_volatility(
    returns: pd.DataFrame,
    window: int = 60,
    threshold: float = 0.0,
) -> pd.DataFrame:
    """
    下行波动率因子

    只计算低于阈值（默认0，即亏损日）的收益率的波动

    逻辑:
    - 同样的波动率，如果主要来自下跌，风险更大
    - 下行波动率更能反映投资者真正关心的"损失风险"
    - Sortino Ratio 就是用下行波动率替代总波动率

    参数:
        returns  : 日收益率
        window   : 回看窗口
        threshold: 收益率阈值（低于此值的收益率才计入）
    """
    # 只取低于阈值的收益率
    downside = returns.copy()
    downside[downside > threshold] = np.nan

    # 计算下行波动率
    down_vol = downside.rolling(window=window, min_periods=int(window * 0.5)).std() * np.sqrt(250)

    # 取负号
    factor = -down_vol

    return factor


def calc_volatility_composite(
    realized_vol: pd.Series,
    idio_vol: pd.Series,
    downside_vol: pd.Series,
    weights: dict = None,
) -> pd.Series:
    """
    复合波动率因子

    将已实现波动率、特质波动率、下行波动率三个维度合成
    """
    if weights is None:
        weights = {"realized": 0.4, "idio": 0.3, "downside": 0.3}

    # 排名标准化
    r1 = realized_vol.rank(pct=True)
    r2 = idio_vol.rank(pct=True)
    r3 = downside_vol.rank(pct=True)

    composite = (
        r1 * weights["realized"] +
        r2 * weights["idio"] +
        r3 * weights["downside"]
    )
    composite.name = "low_volatility"

    return composite
```

## 六、因子中性化

### 6.1 为什么要中性化

因子中性化是因子构建中至关重要的一步。如果不做中性化，你的"动量因子"可能本质上是"行业因子"，你的"价值因子"可能本质上是"小市值因子"。

```
未中性化的因子构成:

    原始因子 = 目标因子暴露 + 行业偏差 + 市值偏差 + 噪声
                ─────────────   ────────   ────────
                  想要的部分     不想要的     不想要的
```

### 6.2 回归法中性化

```python
# factors/neutralize.py
"""
因子中性化处理
"""
import pandas as pd
import numpy as np


def neutralize_by_regression(
    factor: pd.Series,
    industry: pd.Series,
    market_cap: pd.Series,
) -> pd.Series:
    """
    回归法因子中性化

    步骤:
        1. 将因子对行业哑变量和对数市值做回归
        2. 取残差作为中性化后的因子

    回归方程:
        factor_i = Σ(βk * Industry_k) + γ * log(market_cap) + ε_i

    残差 ε_i 就是剥离了行业和市值影响后的纯因子暴露

    参数:
        factor    : 原始因子值
        industry  : 行业分类代码
        market_cap: 总市值
    """
    import statsmodels.api as sm

    df = pd.DataFrame({
        "factor": factor,
        "industry": industry,
        "log_cap": np.log(market_cap.replace(0, np.nan)),
    }).dropna()

    if len(df) < 10:
        return factor * np.nan

    # 构建行业哑变量
    industry_dummies = pd.get_dummies(df["industry"], prefix="ind", drop_first=True)

    # 构建自变量矩阵
    X = pd.concat([industry_dummies, df[["log_cap"]]], axis=1)
    X = sm.add_constant(X)
    y = df["factor"]

    try:
        model = sm.OLS(y, X).fit()
        residuals = model.resids

        # 映射回原始索引
        result = factor.copy()
        result.loc[residuals.index] = residuals
        return result
    except Exception:
        return factor * np.nan


def neutralize_by_rank(
    factor: pd.Series,
    industry: pd.Series,
    market_cap: pd.Series,
    n_cap_groups: int = 5,
) -> pd.Series:
    """
    分组排名法中性化（简化版，不依赖回归）

    步骤:
        1. 按市值分为 N 组
        2. 在每个市值组内按行业分组
        3. 行业-市值组内做排名标准化

    优点: 不需要 statsmodels，更鲁棒
    缺点: 精度不如回归法
    """
    df = pd.DataFrame({
        "factor": factor,
        "industry": industry,
        "market_cap": market_cap,
    }).dropna()

    # 市值分组
    df["cap_group"] = pd.qcut(df["market_cap"], n_cap_groups, labels=False, duplicates="drop")

    # 行业-市值组内排名
    df["rank"] = df.groupby(["industry", "cap_group"])["factor"].rank(pct=True)

    result = factor.copy()
    result.loc[df.index] = df["rank"]
    return result
```

### 6.3 因子标准化完整流程

```python
def full_factor_processing(
    raw_factor: pd.Series,
    industry: pd.Series,
    market_cap: pd.Series,
) -> pd.Series:
    """
    因子标准化完整流程

    1. MAD 去极值
    2. Z-Score 标准化
    3. 行业市值中性化
    4. 再次 Z-Score 标准化
    """
    from factor_utils import winsorize_mad, standardize_zscore

    # Step 1: 去极值
    factor = winsorize_mad(raw_factor)

    # Step 2: Z-Score
    factor = standardize_zscore(factor)

    # Step 3: 中性化
    factor = neutralize_by_regression(factor, industry, market_cap)

    # Step 4: 再次标准化（中性化后分布可能偏移）
    factor = standardize_zscore(factor)

    return factor
```

## 七、A 股因子构建的特殊处理

### 7.1 涨跌停处理

```python
def handle_price_limits(
    factor: pd.DataFrame,
    price_data: pd.DataFrame,
) -> pd.DataFrame:
    """
    涨跌停处理

    问题: 涨停/跌停的股票无法交易，因子信号无法执行
    方案: 将涨跌停股票的因子值设为 NaN，避免产生不可执行的信号
    """
    # 判断涨停（涨幅 >= 9.8%，考虑精度容差）
    limit_up = price_data["pct_change"] >= 9.8
    limit_down = price_data["pct_change"] <= -9.8

    # 涨停时无法买入，跌停时无法卖出
    # 对于多头因子，排除涨停股；对于空头因子，排除跌停股
    factor = factor.copy()
    factor[limit_up] = np.nan
    factor[limit_down] = np.nan

    return factor
```

### 7.2 停牌处理

```python
def handle_suspension(
    factor: pd.DataFrame,
    volume: pd.DataFrame,
    min_trade_days: int = 5,
) -> pd.DataFrame:
    """
    停牌处理

    问题: 停牌股票的因子值可能是过时的数据
    方案: 过去 N 天无交易的股票，因子值设为 NaN
    """
    # 成交量为 0 视为停牌
    is_traded = volume > 0
    recent_traded = is_traded.rolling(window=min_trade_days).sum()

    factor = factor.copy()
    factor[recent_traded < 1] = np.nan  # 最近N天都没有交易

    return factor
```

## 常见误区

### 误区一：因子不做中性化就直接使用

最常见的错误是构建了动量因子后直接用于选股，结果发现"动量因子"本质上只是在赌行业轮动。中性化不是可选步骤，而是因子构建的必要流程。

### 误区二：用单一指标代表一个维度

只用 ROE 代表"质量"是不够的。ROE 可能被高杠杆推高，也可能因为小基数效应而虚高。至少需要 2-3 个互补指标来综合衡量一个维度。

### 误区三：忽略因子方向一致性

EP（高好）、波动率（低好）、应计利润（低好）——不同因子的"好"方向不同。如果不统一方向，合成时会相互抵消。建议统一处理为"因子值越大越好"。

### 误区四：财务数据直接使用单季度

A 股财务数据存在明显的季节性（Q4 集中确认收入/费用），直接用单季度数据会引入噪声。应使用 TTM（滚动 4 个季度）或同比数据。

### 误区五：回看窗口选择随意

动量因子回看 12 个月还是 6 个月？波动率窗口用 60 天还是 120 天？这些参数不应该随意选择，而应该：
- 参考学术文献的常用设定
- 在多个参数下测试因子稳定性
- 避免过度拟合特定参数

## 小结与练习

### 本课要点

- **动量因子**：经典 12M-1M 动量，跳过最近 1 个月以避免短期反转，可叠加行业相对化
- **价值因子**：EP、BP、SP 三个维度，EP 是 PE 的倒数，更适合做因子分析
- **质量因子**：ROE、毛利率、盈利稳定性，必须做行业中性化
- **波动率因子**：低波动异象是 A 股最稳定的因子之一，特质波动率比已实现波动率更有信息量
- **因子中性化**：剥离行业和市值影响，确保因子捕获的是目标维度的信息
- **A 股特殊性**：涨跌停、停牌、季节性财务数据都需要专门处理

## 参考答案

### 练习一：动量因子

**思路**：使用前复权的日收盘价数据，按公式计算 12 个月涨幅跳过最近 1 个月。关键在于数据对齐和缺失值处理。

**答案**：
```python
import akshare as ak
import pandas as pd

# 获取沪深300成分股的历史数据（示例用几只股票）
symbols = ["600519", "000858", "601318"]
prices = pd.DataFrame()

for sym in symbols:
    df = ak.stock_zh_a_hist(symbol=sym, period="daily",
                            start_date="20230101", adjust="hfq")
    df["date"] = pd.to_datetime(df["日期"])
    df = df.set_index("date")
    prices[sym] = df["收盘"]

# 计算 12M-1M 动量
lookback = 250
skip = 20
price_start = prices.shift(lookback)   # 12个月前
price_end = prices.shift(skip)         # 1个月前（跳过最近1个月）
momentum = price_end / price_start - 1

print(momentum.tail())
```

**要点**：
- 必须使用复权价格，否则分红除权会导致动量计算错误
- `shift(250)` 对应约 12 个月，`shift(20)` 对应约 1 个月
- 检查因子值是否在合理范围内（一般 -1 到 3 之间）

### 练习二：价值因子

**思路**：从 AKShare 获取财务数据和市值数据，分别计算 EP 和 BP，然后合成。

**答案**：
```python
import akshare as ak
import pandas as pd

# 获取财务数据
financial = ak.stock_financial_analysis_indicator(symbol="600519")

# 获取市值数据
quote = ak.stock_zh_a_spot_em()
quote = quote[quote["代码"] == "600519"]

# 计算 EP（示例简化处理）
net_profit = financial.iloc[0]["净利润(万元)"] * 10000  # 转为元
market_cap = quote.iloc[0]["总市值"]

ep = net_profit / market_cap
print(f"EP = {ep:.4f}")
print(f"PE = {1/ep:.2f}")
```

**要点**：
- 财务数据必须使用 TTM 口径
- 金融行业的估值指标需要单独处理
- EP 为负（亏损股）时，需要保留负值而不是设为 NaN

### 练习三：因子中性化

**思路**：用回归法将因子对行业哑变量和对数市值做回归，取残差。

**答案**：
```python
import numpy as np
import statsmodels.api as sm
import pandas as pd

# 假设已有因子值、行业、市值数据
np.random.seed(42)
n = 500
factor = pd.Series(np.random.randn(n))
industry = pd.Series(np.random.choice(["银行", "医药", "科技", "消费"], n))
market_cap = pd.Series(np.random.lognormal(23, 1, n))

# 构建行业哑变量
dummies = pd.get_dummies(industry, drop_first=True)
X = pd.concat([dummies, np.log(market_cap).rename("log_cap")], axis=1)
X = sm.add_constant(X)

# 回归取残差
model = sm.OLS(factor, X).fit()
neutralized = model.resid

print(f"原始因子标准差: {factor.std():.4f}")
print(f"中性化后标准差: {neutralized.std():.4f}")
print(f"行业和市值的解释力 R²: {model.rsquared:.4f}")
```

**要点**：
- R² 越高，说明原始因子被行业/市值解释的部分越多，中性化越有必要
- 中性化后因子的分布应更接近标准正态
- 如果中性化后因子 IC 显著下降，说明原始因子的选股能力主要来自行业/市值暴露
