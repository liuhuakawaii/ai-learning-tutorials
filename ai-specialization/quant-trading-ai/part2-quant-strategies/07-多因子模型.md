# 多因子模型

> 单因子不够用，如何组合多个因子构建更稳健的选股模型？

## 场景引入

前面几课我们分别学习了动量、价值、质量、波动率等因子，每个因子都有一定的预测力。但单因子策略面临两个核心问题：

1. **因子失效风险**：任何单一因子都会经历回撤期。价值因子在 2018-2020 年大幅回撤，动量因子在市场反转时频繁亏损。
2. **风格集中风险**：只用价值因子选股，你可能买到一堆银行股和地产股，行业暴露严重。

解决方案是**多因子模型**：将多个因子组合起来，利用因子之间的低相关性实现分散化，提高策略的稳健性。

多因子模型的核心挑战是：
- **因子加权**：如何决定每个因子的权重？
- **因子中性化**：如何消除因子中的行业和市值偏差？
- **组合优化**：如何在最大化因子暴露的同时控制风险？

本课将系统讲解多因子模型的构建方法。

## 学习目标

完成本课学习后，你将能够：

1. 理解多因子模型的核心思想和数学框架
2. 掌握等权、IC 加权、最优化三种因子加权方法
3. 实现因子中性化处理
4. 理解 Barra 风险模型的基本框架
5. 用组合优化构建多因子选股组合

## 核心概念

### 一、多因子模型的数学框架

```
多因子模型的基本形式：

  Rᵢ = αᵢ + Σⱼ βᵢⱼ × Fⱼ + εᵢ

  其中：
    Rᵢ = 股票 i 的收益
    αᵢ = 股票 i 的 Alpha（因子无法解释的部分）
    βᵢⱼ = 股票 i 对因子 j 的暴露（因子载荷）
    Fⱼ = 因子 j 的收益
    εᵢ = 残差（特异性风险）

  目标：找到高 Alpha 的股票，同时控制因子暴露

因子加权的核心问题：
  如何估计每个因子的权重 wⱼ，使得综合得分
  Score_i = Σⱼ wⱼ × z(Factor_j_i)
  能最大化预测力？
```

### 二、因子加权方法

```python
"""
因子加权方法
包含：等权、IC 加权、IC_IR 加权
"""

import numpy as np
import pandas as pd

np.random.seed(42)


def generate_factor_data(n_stocks=300, n_periods=60, n_factors=5):
    """
    生成多因子数据

    返回：
        factors: 因子值字典 {因子名: DataFrame}
        future_returns: 未来收益 DataFrame
    """
    dates = pd.date_range('2020-01-01', periods=n_periods, freq='ME')
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    factor_names = ['动量', '价值', '质量', '低波动', '流动性']
    factors = {}

    for name in factor_names:
        factors[name] = pd.DataFrame(
            np.random.randn(n_periods, n_stocks),
            index=dates,
            columns=stock_ids
        )

    # 未来收益（不同因子有不同预测力）
    signal_strengths = {'动量': 0.04, '价值': 0.03, '质量': 0.035, '低波动': 0.025, '流动性': 0.02}
    future_returns = pd.DataFrame(
        np.random.randn(n_periods, n_stocks) * 0.08,
        index=dates,
        columns=stock_ids
    )
    for name, strength in signal_strengths.items():
        for t in range(n_periods):
            future_returns.iloc[t] += factors[name].iloc[t] * strength

    return factors, future_returns


def calculate_factor_ic(factors, future_returns):
    """
    计算每个因子的 IC 时间序列

    返回：
        ic_dict: {因子名: IC Series}
    """
    ic_dict = {}

    for name, factor_df in factors.items():
        ic_list = []
        for t in range(len(factor_df)):
            f = factor_df.iloc[t].dropna()
            r = future_returns.iloc[t].dropna()
            common = f.index.intersection(r.index)
            if len(common) >= 30:
                ic_list.append(f[common].corr(r[common], method='spearman'))
            else:
                ic_list.append(np.nan)
        ic_dict[name] = pd.Series(ic_list, index=factor_df.index)

    return ic_dict


def equal_weight_factors(factors, z_score=True):
    """
    等权加权

    最简单的方法：将所有因子标准化后等权平均。

    优点：简单、不需要估计参数、不会过拟合
    缺点：没有考虑因子预测力的差异

    参数：
        factors: 因子值字典
        z_score: 是否标准化

    返回：
        composite_score: 综合得分 DataFrame
    """
    n_periods = len(list(factors.values())[0])
    n_stocks = len(list(factors.values())[0].columns)

    composite = pd.DataFrame(0, index=list(factors.values())[0].index,
                             columns=list(factors.values())[0].columns, dtype=float)

    for name, factor_df in factors.items():
        if z_score:
            # 截面标准化
            for t in range(n_periods):
                row = factor_df.iloc[t]
                composite.iloc[t] += (row - row.mean()) / row.std()
        else:
            composite += factor_df

    composite /= len(factors)
    return composite


def ic_weighted_factors(factors, future_returns, lookback=12):
    """
    IC 加权

    用每个因子的历史 IC 作为权重。
    IC 高的因子权重更大。

    优点：考虑了因子预测力的差异
    缺点：IC 估计有噪声，可能导致权重不稳定

    参数：
        factors: 因子值字典
        future_returns: 未来收益 DataFrame
        lookback: IC 计算的回看窗口

    返回：
        composite_score: 综合得分 DataFrame
        weights_over_time: 权重时间序列
    """
    ic_dict = calculate_factor_ic(factors, future_returns)

    n_periods = len(list(factors.values())[0])
    composite = pd.DataFrame(0, index=list(factors.values())[0].index,
                             columns=list(factors.values())[0].columns, dtype=float)
    weights_over_time = []

    for t in range(lookback, n_periods):
        # 计算每个因子过去 lookback 期的平均 IC
        weights = {}
        for name in factors.keys():
            ic_window = ic_dict[name].iloc[t-lookback:t].dropna()
            weights[name] = ic_window.mean()

        # 归一化权重（只使用权重为正的因子）
        total = sum(max(0, w) for w in weights.values())
        if total > 0:
            weights = {name: max(0, w) / total for name, w in weights.items()}
        else:
            weights = {name: 1 / len(factors) for name in factors.keys()}

        weights_over_time.append({'date': list(factors.values())[0].index[t], **weights})

        # 计算综合得分
        for name, factor_df in factors.items():
            row = factor_df.iloc[t]
            z_row = (row - row.mean()) / row.std()
            composite.iloc[t] += weights[name] * z_row

    weights_df = pd.DataFrame(weights_over_time).set_index('date')
    return composite, weights_df


# ========== 运行因子加权 ==========

print("=" * 60)
print("因子加权方法比较")
print("=" * 60)

# 计算各因子 IC
ic_dict = calculate_factor_ic(factors, future_returns)

print(f"\n各因子 IC 统计:")
print(f"{'因子':<10} {'IC均值':>10} {'IC标准差':>10} {'IC_IR':>10}")
print("-" * 45)
for name, ic_series in ic_dict.items():
    ic_clean = ic_series.dropna()
    print(f"{name:<10} {ic_clean.mean():>10.4f} {ic_clean.std():>10.4f} "
          f"{ic_clean.mean() / ic_clean.std():>10.4f}")

# 等权组合
equal_weight = equal_weight_factors(factors)

# IC 加权组合
ic_weight, weights_df = ic_weighted_factors(factors, future_returns, lookback=12)

print(f"\nIC 加权权重（最近 12 期平均）:")
latest_weights = weights_df.iloc[-12:].mean()
for name, weight in latest_weights.items():
    print(f"  {name}: {weight:.4f}")

# 比较两种方法的 IC
equal_ic_list = []
ic_weight_ic_list = []

for t in range(12, len(future_returns)):
    eq_score = equal_weight.iloc[t].dropna()
    ic_score = ic_weight.iloc[t].dropna()
    ret = future_returns.iloc[t].dropna()

    common_eq = eq_score.index.intersection(ret.index)
    common_ic = ic_score.index.intersection(ret.index)

    if len(common_eq) >= 30:
        equal_ic_list.append(eq_score[common_eq].corr(ret[common_eq], method='spearman'))
    if len(common_ic) >= 30:
        ic_weight_ic_list.append(ic_score[common_ic].corr(ret[common_ic], method='spearman'))

equal_ic = pd.Series(equal_ic_list)
ic_weight_ic = pd.Series(ic_weight_ic_list)

print(f"\n综合因子 IC 比较:")
print(f"{'方法':<15} {'IC均值':>10} {'IC_IR':>10}")
print("-" * 38)
print(f"{'等权':<15} {equal_ic.mean():>10.4f} {equal_ic.mean() / equal_ic.std():>10.4f}")
print(f"{'IC加权':<15} {ic_weight_ic.mean():>10.4f} {ic_weight_ic.mean() / ic_weight_ic.std():>10.4f}")
```

### 三、因子中性化

因子中性化是消除因子中的行业和市值偏差，使因子只反映个股特征。

```
因子中性化的目的：

  未中性化的 BP 因子：
    - 银行股 BP 高（因为银行估值普遍低）
    - 科技股 BP 低（因为科技股估值普遍高）
    - 因此 BP 因子会自动超配银行、低配科技
    - 这不是"价值效应"，而是"行业效应"

  中性化后的 BP 因子：
    - 在每个行业内，比较股票的相对 BP
    - 消除了行业偏差，只反映个股的"便宜程度"
    - 同时消除了市值偏差（大公司和小公司的 BP 不可直接比较）
```

```python
"""
因子中性化
"""

import numpy as np
import pandas as pd

np.random.seed(42)


def generate_factor_with_industry(n_stocks=300):
    """生成带行业分类的因子数据"""
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    # 行业分类（5 个行业）
    industries = np.random.choice(['金融', '科技', '消费', '医药', '制造'], n_stocks)
    industry_series = pd.Series(industries, index=stock_ids, name='Industry')

    # 市值（对数正态分布）
    market_cap = np.random.lognormal(4.5, 1.2, n_stocks)
    cap_series = pd.Series(market_cap, index=stock_ids, name='MarketCap')

    # BP 因子（行业有系统性差异：金融高，科技低）
    bp = np.random.normal(0.5, 0.2, n_stocks)
    # 行业偏差
    industry_bias = {'金融': 0.3, '科技': -0.3, '消费': 0.0, '医药': -0.1, '制造': 0.1}
    for i, ind in enumerate(industries):
        bp[i] += industry_bias[ind]
    bp = np.clip(bp, 0.1, 2.0)
    bp_series = pd.Series(bp, index=stock_ids, name='BP')

    return bp_series, industry_series, cap_series


def neutralize_factor(factor_series, industry_series, market_cap_series):
    """
    因子中性化（行业 + 市值）

    方法：OLS 回归取残差
    factor = α + β₁ × ln(market_cap) + Σ γⱼ × Industry_j + ε

    参数：
        factor_series: 因子值 Series
        industry_series: 行业分类 Series
        market_cap_series: 市值 Series

    返回：
        neutralized: 中性化后的因子值 Series
    """
    # 构造回归矩阵
    ln_cap = np.log(market_cap_series + 1)
    industry_dummies = pd.get_dummies(industry_series, prefix='ind', dtype=float)

    X = pd.concat([ln_cap.rename('ln_cap'), industry_dummies], axis=1)
    X = X.fillna(0)
    y = factor_series.values

    # OLS 回归
    X_mat = np.column_stack([np.ones(len(X)), X.values])
    valid = ~(np.isnan(y) | np.any(np.isnan(X_mat), axis=1))

    if valid.sum() < X_mat.shape[1] + 1:
        return factor_series * np.nan

    betas, _, _, _ = np.linalg.lstsq(X_mat[valid], y[valid], rcond=None)
    fitted = X_mat @ betas
    residual = y - fitted

    return pd.Series(residual, index=factor_series.index)


def analyze_neutralization_effect(factor_raw, factor_neutral, industry_series):
    """分析中性化的效果"""
    print(f"\n中性化前后对比:")

    # 行业均值
    print(f"\n  行业均值（中性化前）:")
    for ind in industry_series.unique():
        mask = industry_series == ind
        print(f"    {ind}: {factor_raw[mask].mean():.4f}")

    print(f"\n  行业均值（中性化后）:")
    for ind in industry_series.unique():
        mask = industry_series == ind
        print(f"    {ind}: {factor_neutral[mask].mean():.4f}")

    # 标准差变化
    print(f"\n  因子标准差:")
    print(f"    中性化前: {factor_raw.std():.4f}")
    print(f"    中性化后: {factor_neutral.std():.4f}")


# ========== 运行因子中性化 ==========

print("=" * 60)
print("因子中性化")
print("=" * 60)

bp_raw, industry_series, cap_series = generate_factor_with_industry()
bp_neutral = neutralize_factor(bp_raw, industry_series, cap_series)

analyze_neutralization_effect(bp_raw, bp_neutral, industry_series)

# 验证：中性化后与市值的相关性
print(f"\n与 ln(市值) 的相关系数:")
print(f"  中性化前: {bp_raw.corr(np.log(cap_series)):.4f}")
print(f"  中性化后: {bp_neutral.corr(np.log(cap_series)):.4f}")
```

### 四、Barra 风险模型

Barra 风险模型是机构投资者最广泛使用的多因子风险模型。它将股票收益分解为因子收益和特异性收益，并估计因子的协方差矩阵。

```
Barra 风险模型的基本框架：

  收益分解：
    Rᵢ = Σⱼ βᵢⱼ × Fⱼ + εᵢ

  风险分解：
    总风险² = 因子风险² + 特异性风险²

    因子风险 = β × Σ × βᵀ
    特异性风险 = diag(Δ)

  其中：
    β = 因子暴露矩阵 (n_stocks × n_factors)
    Σ = 因子协方差矩阵 (n_factors × n_factors)
    Δ = 特异性方差向量 (n_stocks × 1)

Barra 的因子体系（CNE6 为例）：
  - 国家因子（市场）
  - 行业因子（30+ 个行业）
  - 风格因子（规模、价值、动量、波动率、流动性等）
```

```python
"""
Barra 风险模型简化实现
"""

import numpy as np
import pandas as pd

np.random.seed(42)


def estimate_factor_covariance(factor_returns, window=60):
    """
    估计因子协方差矩阵

    参数：
        factor_returns: 因子收益 DataFrame (n_periods × n_factors)
        window: 估计窗口

    返回：
        factor_cov: 因子协方差矩阵
    """
    # 使用指数加权移动平均（EWMA），对近期数据赋予更高权重
    factor_cov = factor_returns.ewm(span=window).cov()
    latest_cov = factor_cov.iloc[-len(factor_returns.columns):]

    return latest_cov


def estimate_specific_risk(residual_returns, window=60):
    """
    估计特异性风险

    参数：
        residual_returns: 残差收益 DataFrame (n_periods × n_stocks)
        window: 估计窗口

    返回：
        specific_var: 特异性方差向量
    """
    specific_var = residual_returns.rolling(window=window).var().iloc[-1]
    return specific_var


def barra_risk_decomposition(portfolio_weights, factor_exposure, factor_cov, specific_var):
    """
    Barra 风险分解

    参数：
        portfolio_weights: 组合权重向量 (n_stocks,)
        factor_exposure: 因子暴露矩阵 (n_stocks × n_factors)
        factor_cov: 因子协方差矩阵 (n_factors × n_factors)
        specific_var: 特异性方差向量 (n_stocks,)

    返回：
        risk_decomposition: 风险分解结果
    """
    w = portfolio_weights
    B = factor_exposure.values
    Sigma = factor_cov.values
    Delta = np.diag(specific_var.values)

    # 因子风险
    factor_risk = w @ B @ Sigma @ B.T @ w

    # 特异性风险
    specific_risk = w @ Delta @ w

    # 总风险
    total_risk = factor_risk + specific_risk

    # 各因子的风险贡献
    factor_contributions = {}
    for j in range(B.shape[1]):
        factor_name = factor_exposure.columns[j]
        # 因子 j 的风险贡献 = w × βⱼ × σⱼ² × βⱼᵀ × w
        bj = B[:, j]
        factor_contributions[factor_name] = (w * bj) @ Sigma[j, :] @ (w * bj).T

    return {
        'total_risk': total_risk,
        'factor_risk': factor_risk,
        'specific_risk': specific_risk,
        'factor_risk_pct': factor_risk / total_risk if total_risk > 0 else 0,
        'specific_risk_pct': specific_risk / total_risk if total_risk > 0 else 0,
        'factor_contributions': factor_contributions
    }


# ========== 运行 Barra 风险模型 ==========

print("Barra 风险模型")
print("=" * 60)
```

### 五、组合优化

组合优化是多因子模型的最后一步：在最大化因子暴露的同时，控制风险和交易成本。

```
组合优化的基本问题：

  目标：最大化 Alpha（综合因子得分）
  约束：
    1. 权重之和 = 1（全仓投资）
    2. 单只股票权重 ≤ 5%（分散化）
    3. 行业偏离 ≤ 5%（行业中性）
    4. 因子暴露 ≤ 0.5（控制风格偏差）
    5. 换手率 ≤ 30%（控制交易成本）

  数学形式：
    max  w' × α - λ × w' × Σ × w
    s.t. Σwᵢ = 1, 0 ≤ wᵢ ≤ 0.05, ...

    其中：
      w = 权重向量
      α = Alpha 向量（综合因子得分）
      Σ = 协方差矩阵
      λ = 风险厌恶系数
```

```python
"""
组合优化
"""

import numpy as np
import pandas as pd
from scipy.optimize import minimize

np.random.seed(42)


def generate_optimization_data(n_stocks=100):
    """生成组合优化所需的数据"""
    stock_ids = [f'STOCK_{i:03d}' for i in range(n_stocks)]

    # Alpha 信号（综合因子得分）
    alpha = pd.Series(np.random.randn(n_stocks) * 0.01, index=stock_ids)

    # 行业分类
    industries = np.random.choice(['金融', '科技', '消费', '医药', '制造'], n_stocks)
    industry_series = pd.Series(industries, index=stock_ids)

    # 协方差矩阵（简化：用随机正定矩阵）
    A = np.random.randn(n_stocks, n_stocks) * 0.01
    cov_matrix = A @ A.T + np.eye(n_stocks) * 0.001

    return alpha, industry_series, cov_matrix, stock_ids


def portfolio_optimization(alpha, cov_matrix, risk_aversion=1.0,
                           max_weight=0.05, industry_series=None,
                           max_industry_dev=0.05):
    """
    组合优化

    目标：max α'w - λ × w'Σw
    约束：
      - Σwᵢ = 1
      - 0 ≤ wᵢ ≤ max_weight
      - 行业偏离约束（可选）

    参数：
        alpha: Alpha 向量
        cov_matrix: 协方差矩阵
        risk_aversion: 风险厌恶系数
        max_weight: 单只股票最大权重
        industry_series: 行业分类（可选）
        max_industry_dev: 行业最大偏离

    返回：
        optimal_weights: 最优权重
    """
    n = len(alpha)

    # 目标函数：最大化 Alpha - 风险
    def objective(w):
        alpha_return = w @ alpha.values
        risk = w @ cov_matrix @ w
        return -(alpha_return - risk_aversion * risk)

    # 约束
    constraints = [
        {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},  # 权重和为 1
    ]

    # 行业约束
    if industry_series is not None:
        industries = industry_series.unique()
        for ind in industries:
            ind_mask = (industry_series == ind).values
            ind_weight = ind_mask.sum() / n  # 基准行业权重
            constraints.append({
                'type': 'ineq',
                'fun': lambda w, mask=ind_mask, base=ind_weight: max_industry_dev - abs(w[mask].sum() - base)
            })

    # 边界
    bounds = [(0, max_weight)] * n

    # 初始权重
    w0 = np.ones(n) / n

    # 优化
    result = minimize(objective, w0, method='SLSQP', bounds=bounds, constraints=constraints)

    if result.success:
        optimal_weights = pd.Series(result.x, index=alpha.index)
        return optimal_weights
    else:
        print(f"优化失败: {result.message}")
        return pd.Series(w0, index=alpha.index)


def analyze_portfolio(weights, alpha, cov_matrix, industry_series):
    """分析优化后的组合"""
    # 组合 Alpha
    portfolio_alpha = weights @ alpha.values

    # 组合风险
    portfolio_risk = np.sqrt(weights @ cov_matrix @ weights.values * 12)

    # 信息比率
    ir = portfolio_alpha / portfolio_risk if portfolio_risk > 0 else 0

    # 持仓集中度
    n_held = (weights > 0.001).sum()
    top_10_weight = weights.nlargest(10).sum()

    # 行业分布
    industry_weights = {}
    for ind in industry_series.unique():
        mask = industry_series == ind
        industry_weights[ind] = weights[mask].sum()

    return {
        'alpha': portfolio_alpha,
        'risk': portfolio_risk,
        'ir': ir,
        'n_held': n_held,
        'top_10_weight': top_10_weight,
        'industry_weights': industry_weights
    }


# ========== 运行组合优化 ==========
```

## 常见误区

### 误区一：因子越多越好

堆叠过多因子会导致：
- 因子之间的相关性使分散效果大打折扣
- 过多参数增加过拟合风险
- 计算和维护成本急剧上升

建议使用 5-8 个经济逻辑清晰、相关性低的因子。

### 误区二：忽略因子相关性

价值因子和质量因子高度正相关，动量因子和价值因子高度负相关。如果不考虑相关性，你的"多因子"组合实际上可能只暴露在少数几个风格上。

### 误区三：过度优化

组合优化的目标函数中有太多约束和参数，容易导致过度拟合。建议：
- 使用简单的优化框架
- 对优化结果做样本外检验
- 保持一定的换手率约束

### 误区 四：忽略特异性风险

很多初学者只关注因子风险，忽略了特异性风险。对于集中持仓的组合，特异性风险可能占总风险的 50% 以上。

## 小结与练习

### 小结

1. 多因子模型通过组合多个因子实现分散化，提高策略稳健性
2. 因子加权方法包括等权、IC 加权和最优化，各有优劣
3. 因子中性化消除行业和市值偏差，使因子只反映个股特征
4. Barra 风险模型将组合风险分解为因子风险和特异性风险
5. 组合优化在最大化 Alpha 的同时控制风险和交易成本

### 练习一

**思路**：遍历不同的回看窗口，比较 IC 加权的 IC_IR。

**答案**：

```python
import numpy as np
import pandas as pd

np.random.seed(42)
factors, future_returns = generate_factor_data()

print("IC 加权回看窗口分析:")
print(f"{'窗口':<8} {'IC均值':>10} {'IC_IR':>10}")
print("-" * 30)

for lookback in [6, 12, 24]:
    _, weights_df = ic_weighted_factors(factors, future_returns, lookback=lookback)

    # 计算综合因子 IC
    ic_list = []
    for t in range(lookback, len(future_returns)):
        # 重新计算综合得分
        composite = pd.Series(0, index=future_returns.columns, dtype=float)
        for name, factor_df in factors.items():
            row = factor_df.iloc[t]
            z_row = (row - row.mean()) / row.std()
            w = weights_df.iloc[t-lookback][name] if t-lookback < len(weights_df) else 0.2
            composite += w * z_row

        ret = future_returns.iloc[t].dropna()
        common = composite.index.intersection(ret.index)
        if len(common) >= 30:
            ic_list.append(composite[common].corr(ret[common], method='spearman'))

    ic_series = pd.Series(ic_list)
    print(f"{lookback:<8} {ic_series.mean():>10.4f} {ic_series.mean() / ic_series.std():>10.4f}")
```

**要点**：
- 窗口太短（6 期）：IC 估计噪声大，权重不稳定
- 窗口太长（24 期）：IC 变化被平滑，反应迟钝
- 12 期通常是较好的平衡点

### 练习三

**思路**：用 Gram-Schmidt 正交化消除因子之间的相关性。

**答案**：

```python
import numpy as np
import pandas as pd

np.random.seed(42)

# 生成相关因子
n_stocks = 200
factor1 = np.random.randn(n_stocks)
factor2 = factor1 * 0.5 + np.random.randn(n_stocks) * 0.5  # 与 factor1 相关
factor3 = factor1 * 0.3 + factor2 * 0.3 + np.random.randn(n_stocks) * 0.4

factors_raw = pd.DataFrame({
    'F1': factor1,
    'F2': factor2,
    'F3': factor3
})

print("正交化前相关系数矩阵:")
print(factors_raw.corr().round(3))

def gram_schmidt(factors_df):
    """Gram-Schmidt 正交化"""
    orthogonal = factors_df.copy()
    for i in range(1, len(factors_df.columns)):
        for j in range(i):
            # 投影
            projection = np.dot(orthogonal.iloc[:, i], orthogonal.iloc[:, j]) / \
                         np.dot(orthogonal.iloc[:, j], orthogonal.iloc[:, j])
            orthogonal.iloc[:, i] -= projection * orthogonal.iloc[:, j]
    return orthogonal

factors_orth = gram_schmidt(factors_raw)

print(f"\n正交化后相关系数矩阵:")
print(factors_orth.corr().round(3))

print(f"\n正交化前后因子方差:")
print(f"{'因子':<8} {'正交化前':>12} {'正交化后':>12}")
for col in factors_raw.columns:
    print(f"{col:<8} {factors_raw[col].var():>12.4f} {factors_orth[col].var():>12.4f}")
```

**要点**：
- 正交化消除了因子之间的相关性
- 但正交化会改变因子的经济含义
- 实际中更常用的方法是：在组合优化中加入因子暴露约束
