# 03 数据清洗与对齐

## 场景引入

你兴冲冲地把上节课采集到的数据喂进策略回测引擎，结果发现：

- 某只股票在 2023 年 7 月 15 日的收盘价是 25.30 元，但 7 月 16 日突然变成了 15.80 元——这不是暴跌，是除权除息
- 回测显示你的策略在 2022 年收益率高达 80%，但实盘跑了一年只赚了 5%——因为你只回测了现在还在上市的股票，退市的那些亏损股被"选择性遗忘"了
- 你的多因子模型需要同时使用日线、周线和月线数据，但三种频率的数据无法直接对齐
- 某只股票在周三突然"消失"了——原来是停牌，但你的策略不知道，直接用了上周的数据

数据清洗是量化交易中最不起眼但最关键的工作。**一个未经清洗的数据集，比一个没有策略的交易系统更危险**——因为它会让你对错误的结果产生信心。

本节课将系统讲解 A 股数据清洗的核心问题和解决方案，带你构建一个完整的数据清洗管道。

> **风险提示**：数据清洗的质量直接影响回测结果的可靠性。不充分的清洗可能导致回测虚高，造成实盘亏损。请务必在实盘前对数据管道进行充分验证。

## 一、缺失数据处理

### 1.1 金融数据中的缺失模式

```
缺失数据的四种模式：

  1. 完全随机缺失（MCAR）
     示例：数据源偶发故障导致某天数据丢失
     特点：缺失与任何变量无关
     处理：删除或简单填充

  2. 随机缺失（MAR）
     示例：小盘股更可能出现数据缺失（关注度低）
     特点：缺失与其他可观测变量相关
     处理：基于相关变量的条件填充

  3. 非随机缺失（MNAR）
     示例：停牌期间没有行情数据
     特点：缺失与缺失值本身相关
     处理：标记为特殊状态，不参与计算

  4. 结构性缺失
     示例：新股上市前没有数据
     特点：缺失是已知的、可预期的
     处理：直接排除或标记
```

### 1.2 A 股特有的缺失场景

```python
"""
A 股数据缺失场景识别与处理
"""

import pandas as pd
import numpy as np
from typing import Optional
import logging

logger = logging.getLogger(__name__)


def identify_missing_patterns(df: pd.DataFrame) -> dict:
    """
    识别数据中的缺失模式
    返回各类缺失的数量和占比
    """
    patterns = {}

    # 1. 停牌导致的缺失（成交量为 0 或 NaN）
    if "volume" in df.columns:
        suspended = (df["volume"].fillna(0) == 0)
        patterns["停牌"] = {
            "count": suspended.sum(),
            "pct": f"{suspended.mean() * 100:.2f}%",
        }

    # 2. 涨跌停导致的缺失（无法成交）
    if "pct_change" in df.columns:
        limit_up = df["pct_change"] >= 9.8
        limit_down = df["pct_change"] <= -9.8
        patterns["涨停"] = {
            "count": limit_up.sum(),
            "pct": f"{limit_up.mean() * 100:.2f}%",
        }
        patterns["跌停"] = {
            "count": limit_down.sum(),
            "pct": f"{limit_down.mean() * 100:.2f}%",
        }

    # 3. 数据源缺失（原始 NaN）
    price_cols = ["open", "high", "low", "close"]
    for col in price_cols:
        if col in df.columns:
            missing = df[col].isna()
            if missing.sum() > 0:
                patterns[f"{col}_缺失"] = {
                    "count": missing.sum(),
                    "pct": f"{missing.mean() * 100:.2f}%",
                }

    return patterns


def handle_suspended_days(df: pd.DataFrame) -> pd.DataFrame:
    """
    处理停牌日数据
    策略：保留停牌标记，将停牌日的价格设为前一个交易日的收盘价
    注意：停牌日不应参与信号计算
    """
    df = df.copy()

    # 标记停牌日
    df["is_suspended"] = (df["volume"].fillna(0) == 0)

    # 停牌日价格用前值填充（仅用于展示，不用于信号计算）
    price_cols = ["open", "high", "low", "close"]
    for col in price_cols:
        if col in df.columns:
            # 只填充停牌日的缺失
            mask = df["is_suspended"] & df[col].isna()
            df.loc[mask, col] = df[col].ffill()

    # 停牌日成交量设为 0
    if "volume" in df.columns:
        df.loc[df["is_suspended"], "volume"] = 0

    logger.info(f"停牌日处理: {df['is_suspended'].sum()} 天")
    return df


def fill_missing_prices(
    df: pd.DataFrame,
    method: str = "ffill",
    max_gap: int = 5
) -> pd.DataFrame:
    """
    填充缺失价格数据

    Args:
        df: 包含价格数据的 DataFrame
        method: 填充方法 - "ffill"(前值), "linear"(线性), "none"(不填充)
        max_gap: 最大连续填充天数，超过则保留 NaN
    """
    df = df.copy()
    price_cols = ["open", "high", "low", "close"]

    if method == "none":
        return df

    for col in price_cols:
        if col not in df.columns:
            continue

        if method == "ffill":
            # 前值填充，但限制连续填充天数
            filled = df[col].ffill(limit=max_gap)
            df[col] = filled
        elif method == "linear":
            # 线性插值
            df[col] = df[col].interpolate(
                method="linear", limit=max_gap
            )

    return df
```

## 二、复权处理

### 2.1 什么是复权

复权是 A 股数据处理中最容易混淆的概念之一。当上市公司发生分红、送股、配股等行为时，股价会出现断崖式跳变。复权的目的是**消除这些跳变，使历史价格具有可比性**。

```
除权除息示例：

  股票 A 在 2024-06-15 每 10 股派 5 元（即每股派 0.5 元）

  除权前：收盘价 20.00 元
  除权后：收盘价 19.50 元（20.00 - 0.50）

  如果不做复权处理，价格图上会出现 -2.5% 的"假跌"

  价格
   │
 20├────●
   │     ╲  ← 看起来像是暴跌
19.5├      ●────●────●
   │
   └───────────────────── 时间
        除权日

  前复权后（以最新价为基准向前调整）：
   │
   │  ●────●
   │        ╲
   │         ●────●────●  ← 价格连续
   └───────────────────── 时间
```

### 2.2 前复权 vs 后复权

```
前复权（Forward Adjustment）：
  基准：最新价格不变
  方向：向前（向过去）调整历史价格
  公式：调整价 = 原始价 × (最新复权因子 / 当日复权因子)
  用途：看盘软件常用，方便与当前价格比较

后复权（Backward Adjustment）：
  基准：上市首日价格不变
  方向：向后（向未来）调整未来价格
  公式：调整价 = 原始价 × (当日复权因子 / 首日复权因子)
  用途：计算长期收益率更准确
```

### 2.3 复权计算实现

```python
class AdjustmentProcessor:
    """
    复权处理器
    支持前复权、后复权和不复权三种模式
    """
    def __init__(self):
        self.adj_records: list[dict] = []

    def load_adjustment_factors(
        self, df: pd.DataFrame
    ) -> pd.DataFrame:
        """
        从原始数据中计算复权因子
        复权因子 = 累计的 (1 + 送股比例 + 配股比例) × (1 - 派息/股价)
        """
        # 简化版本：从价格跳变推算复权因子
        # 实际项目中应从交易所或数据源获取准确的复权因子
        df = df.copy()

        # 计算日收益率
        df["raw_return"] = df["close"].pct_change()

        # 标记可能的除权日（收益率异常大的日期）
        # A 股涨跌停一般 ±10%，超过 15% 可能是除权
        df["potential_ex_right"] = df["raw_return"].abs() > 0.15

        return df

    def apply_forward_adjustment(
        self,
        df: pd.DataFrame,
        adj_factor_col: str = "adj_factor"
    ) -> pd.DataFrame:
        """
        前复权：以最新价格为基准，向前调整历史价格

        前复权价格 = 原始价格 × (当日复权因子 / 最新复权因子)
        """
        if adj_factor_col not in df.columns:
            # 如果没有复权因子列，假设不需要复权
            logger.warning("未找到复权因子列，返回原始数据")
            return df

        df = df.copy()
        latest_factor = df[adj_factor_col].iloc[-1]

        price_cols = ["open", "high", "low", "close"]
        for col in price_cols:
            if col in df.columns:
                df[f"{col}_raw"] = df[col]  # 保留原始价格
                df[col] = df[col] * df[adj_factor_col] / latest_factor

        logger.info("前复权处理完成")
        return df

    def apply_backward_adjustment(
        self,
        df: pd.DataFrame,
        adj_factor_col: str = "adj_factor"
    ) -> pd.DataFrame:
        """
        后复权：以上市首日价格为基准，向后调整价格

        后复权价格 = 原始价格 × (当日复权因子 / 首日复权因子)
        """
        if adj_factor_col not in df.columns:
            logger.warning("未找到复权因子列，返回原始数据")
            return df

        df = df.copy()
        first_factor = df[adj_factor_col].iloc[0]

        price_cols = ["open", "high", "low", "close"]
        for col in price_cols:
            if col in df.columns:
                df[f"{col}_raw"] = df[col]
                df[col] = df[col] * df[adj_factor_col] / first_factor

        logger.info("后复权处理完成")
        return df


def compute_adjustment_factor_from_actions(
    actions: pd.DataFrame,
) -> pd.DataFrame:
    """
    从公司行为数据计算复权因子

    Args:
        actions: 包含除权除息信息的 DataFrame
                columns: [date, bonus_shares, new_shares, cash_dividend, price]

    Returns:
        包含日期和复权因子的 DataFrame
    """
    # 复权因子计算公式：
    # 复权因子 = (1 + 送股比例 + 配股比例) × (1 - 每股派息 / 除权参考价)
    # 累计复权因子 = 各次复权因子的连乘

    factors = []
    cumulative_factor = 1.0

    for _, row in actions.iterrows():
        bonus = row.get("bonus_shares", 0)    # 每股送股数
        new = row.get("new_shares", 0)        # 每股配股数
        cash = row.get("cash_dividend", 0)    # 每股派息
        price = row.get("price", 0)           # 除权参考价

        if price > 0:
            factor = (1 + bonus + new) * (1 - cash / price)
        else:
            factor = 1.0

        cumulative_factor *= factor
        factors.append({
            "date": row["date"],
            "factor": factor,
            "cumulative_factor": cumulative_factor,
        })

    return pd.DataFrame(factors)
```

## 三、异常值检测与处理

### 3.1 异常值的来源

```
金融数据异常值来源：

  数据质量问题
    ├── 数据源错误（传输错误、格式错误）
    ├── 精度问题（小数点错位）
    └── 重复记录

  市场真实事件
    ├── 极端行情（2015 年股灾、2020 年疫情）
    ├── 个股事件（财务造假、重大事故）
    └── 交易制度变化（涨跌停调整）

  数据处理引入
    ├── 复权计算错误
    ├── 日期对齐错误
    └── 频率转换错误
```

### 3.2 异常值检测方法

```python
class OutlierDetector:
    """
    异常值检测器
    支持多种检测方法，可根据数据特征选择合适的方法
    """
    def __init__(self):
        self.outlier_mask: Optional[pd.Series] = None

    def detect_zscore(
        self,
        series: pd.Series,
        threshold: float = 3.0,
        window: int = 60
    ) -> pd.Series:
        """
        Z-score 异常检测
        使用滚动窗口计算 Z-score，适应非平稳的金融时间序列

        Args:
            series: 输入序列
            threshold: Z-score 阈值（默认 3.0）
            window: 滚动窗口大小

        Returns:
            布尔序列，True 表示异常值
        """
        rolling_mean = series.rolling(window=window, center=False).mean()
        rolling_std = series.rolling(window=window, center=False).std()

        zscore = (series - rolling_mean) / rolling_std
        outliers = zscore.abs() > threshold

        logger.info(
            f"Z-score 检测 (阈值={threshold}, 窗口={window}): "
            f"发现 {outliers.sum()} 个异常值"
        )
        return outliers

    def detect_iqr(
        self,
        series: pd.Series,
        multiplier: float = 1.5,
        window: int = 60
    ) -> pd.Series:
        """
        IQR（四分位距）异常检测
        对非正态分布数据更鲁棒

        Args:
            series: 输入序列
            multiplier: IQR 倍数（默认 1.5）
            window: 滚动窗口大小

        Returns:
            布尔序列，True 表示异常值
        """
        rolling_q1 = series.rolling(window=window).quantile(0.25)
        rolling_q3 = series.rolling(window=window).quantile(0.75)
        iqr = rolling_q3 - rolling_q1

        lower_bound = rolling_q1 - multiplier * iqr
        upper_bound = rolling_q3 + multiplier * iqr

        outliers = (series < lower_bound) | (series > upper_bound)

        logger.info(
            f"IQR 检测 (倍数={multiplier}, 窗口={window}): "
            f"发现 {outliers.sum()} 个异常值"
        )
        return outliers

    def detect_mad(
        self,
        series: pd.Series,
        threshold: float = 3.5,
        window: int = 60
    ) -> pd.Series:
        """
        MAD（中位数绝对偏差）异常检测
        比 Z-score 对极端值更鲁棒

        Args:
            series: 输入序列
            threshold: MAD 阈值（默认 3.5）
            window: 滚动窗口大小

        Returns:
            布尔序列，True 表示异常值
        """
        rolling_median = series.rolling(window=window).median()
        # MAD = median(|Xi - median(X)|)
        mad = (series - rolling_median).abs().rolling(window=window).median()
        # 修正的 Z-score
        modified_zscore = 0.6745 * (series - rolling_median) / mad
        outliers = modified_zscore.abs() > threshold

        logger.info(
            f"MAD 检测 (阈值={threshold}, 窗口={window}): "
            f"发现 {outliers.sum()} 个异常值"
        )
        return outliers


class OutlierHandler:
    """
    异常值处理器
    根据业务场景选择合适的处理策略
    """
    @staticmethod
    def winsorize(
        series: pd.Series,
        lower_pct: float = 0.01,
        upper_pct: float = 0.99
    ) -> pd.Series:
        """
        Winsorize（缩尾处理）：
        将极端值压缩到指定百分位数的范围内
        保留数据点的存在，但限制其极端程度

        Args:
            series: 输入序列
            lower_pct: 下百分位数（默认 1%）
            upper_pct: 上百分位数（默认 99%）
        """
        lower = series.quantile(lower_pct)
        upper = series.quantile(upper_pct)
        return series.clip(lower=lower, upper=upper)

    @staticmethod
    def rolling_winsorize(
        series: pd.Series,
        window: int = 252,
        lower_pct: float = 0.01,
        upper_pct: float = 0.99
    ) -> pd.Series:
        """
        滚动 Winsorize：使用滚动窗口计算百分位数
        适应数据分布随时间变化的情况
        """
        lower = series.rolling(window=window).quantile(lower_pct)
        upper = series.rolling(window=window).quantile(upper_pct)
        return series.clip(lower=lower, upper=upper)

    @staticmethod
    def replace_with_nan(
        series: pd.Series,
        outlier_mask: pd.Series
    ) -> pd.Series:
        """将异常值替换为 NaN（后续可用插值填充）"""
        result = series.copy()
        result[outlier_mask] = np.nan
        return result

    @staticmethod
    def replace_with_median(
        series: pd.Series,
        outlier_mask: pd.Series,
        window: int = 20
    ) -> pd.Series:
        """将异常值替换为滚动中位数"""
        result = series.copy()
        rolling_median = series.rolling(window=window, center=False).median()
        result[outlier_mask] = rolling_median[outlier_mask]
        return result


def process_returns_outliers(
    df: pd.DataFrame,
    return_col: str = "pct_change",
    method: str = "winsorize"
) -> pd.DataFrame:
    """
    处理收益率数据中的异常值

    Args:
        df: 包含收益率数据的 DataFrame
        return_col: 收益率列名
        method: 处理方法 - "winsorize", "zscore", "none"
    """
    df = df.copy()
    detector = OutlierDetector()
    handler = OutlierHandler()

    if method == "none":
        return df

    # 检测异常值
    if method == "zscore":
        outliers = detector.detect_zscore(
            df[return_col], threshold=4.0, window=60
        )
        df[return_col] = handler.replace_with_median(
            df[return_col], outliers
        )
    elif method == "winsorize":
        df[return_col] = handler.rolling_winsorize(
            df[return_col], window=252
        )

    return df
```

## 四、多频率数据对齐

### 4.1 频率对齐问题

```
多频率数据对齐的挑战：

  日线数据：  2024-01-02  2024-01-03  2024-01-04  ...
  周线数据：  2024-01-05                    2024-01-12  ...
  月线数据：  2024-01-31                                      2024-02-29  ...

  问题：如何让日线策略同时参考周线和月线信号？

  错误做法：直接用日期 merge（会产生大量 NaN 或前向填充偏差）
  正确做法：使用"as-of"对齐，确保不使用未来数据
```

### 4.2 频率转换与对齐实现

```python
class FrequencyAligner:
    """
    多频率数据对齐器
    处理不同频率数据的时间对齐问题
    """
    def __init__(self, trading_calendar: Optional[pd.DatetimeIndex] = None):
        self.trading_calendar = trading_calendar

    def resample_to_weekly(
        self, df: pd.DataFrame, date_col: str = "date"
    ) -> pd.DataFrame:
        """
        将日线数据转换为周线数据
        规则：周线 OHLCV = 该周最后一个交易日的值（不是整周的聚合）
        注意：不能用 open/high/low 的聚合，因为会引入未来数据
        """
        df = df.copy()
        df[date_col] = pd.to_datetime(df[date_col])
        df = df.set_index(date_col)

        weekly = df.resample("W-FRI").last()  # 以周五为周结束日
        weekly = weekly.dropna(subset=["close"])

        # 重置索引，将周五日期改为该周最后一个实际交易日
        weekly = weekly.reset_index()
        return weekly

    def resample_to_monthly(
        self, df: pd.DataFrame, date_col: str = "date"
    ) -> pd.DataFrame:
        """将日线数据转换为月线数据"""
        df = df.copy()
        df[date_col] = pd.to_datetime(df[date_col])
        df = df.set_index(date_col)

        monthly = df.resample("ME").last()
        monthly = monthly.dropna(subset=["close"])
        monthly = monthly.reset_index()
        return monthly

    def align_multi_frequency(
        self,
        daily_df: pd.DataFrame,
        weekly_df: pd.DataFrame,
        monthly_df: pd.DataFrame,
        date_col: str = "date"
    ) -> pd.DataFrame:
        """
        将周线和月线数据对齐到日线时间轴
        使用"as-of"合并，确保不使用未来数据

        关键原则：t 日只能使用 t 日及之前的数据
        """
        daily = daily_df.copy()
        daily[date_col] = pd.to_datetime(daily[date_col])

        weekly = weekly_df.copy()
        weekly[date_col] = pd.to_datetime(weekly[date_col])
        weekly = weekly.rename(columns={
            col: f"weekly_{col}" for col in weekly.columns if col != date_col
        })

        monthly = monthly_df.copy()
        monthly[date_col] = pd.to_datetime(monthly[date_col])
        monthly = monthly.rename(columns={
            col: f"monthly_{col}" for col in monthly.columns if col != date_col
        })

        # 使用 merge_asof 进行"as-of"合并
        # direction="backward" 确保只使用当前日期或之前的数据
        result = pd.merge_asof(
            daily.sort_values(date_col),
            weekly.sort_values(date_col),
            on=date_col,
            direction="backward",  # 关键：向后匹配，不使用未来数据
        )

        result = pd.merge_asof(
            result.sort_values(date_col),
            monthly.sort_values(date_col),
            on=date_col,
            direction="backward",
        )

        return result
```

## 五、A 股交易日历

### 5.1 交易日历的重要性

```
交易日历问题：

  A 股交易日 ≠ 工作日
    - 周末不开盘
    - 法定节假日不开盘（春节、国庆等）
    - 补班日不开盘（即使那天是工作日）
    - 特殊休市日（如 2020 年疫情延迟开市）

  影响：
    1. 数据对齐时需要排除非交易日
    2. 计算收益率时不能用自然日间隔
    3. 回测框架需要知道哪些天可以交易
```

### 5.2 交易日历实现

```python
class TradingCalendar:
    """
    A 股交易日历
    管理交易日、非交易日和特殊交易日
    """
    def __init__(self):
        self.holidays: set[str] = set()
        self._load_holidays()

    def _load_holidays(self):
        """加载 A 股节假日（实际项目中应从数据源获取）"""
        # 2024 年 A 股法定节假日（简化示例）
        holidays_2024 = [
            # 元旦
            "2024-01-01",
            # 春节
            "2024-02-09", "2024-02-10", "2024-02-11",
            "2024-02-12", "2024-02-13", "2024-02-14",
            "2024-02-15", "2024-02-16", "2024-02-17",
            # 清明节
            "2024-04-04", "2024-04-05", "2024-04-06",
            # 劳动节
            "2024-05-01", "2024-05-02", "2024-05-03",
            "2024-05-04", "2024-05-05",
            # 端午节
            "2024-06-08", "2024-06-09", "2024-06-10",
            # 中秋节
            "2024-09-15", "2024-09-16", "2024-09-17",
            # 国庆节
            "2024-10-01", "2024-10-02", "2024-10-03",
            "2024-10-04", "2024-10-05", "2024-10-06",
            "2024-10-07",
        ]
        self.holidays = set(holidays_2024)

    def is_trading_day(self, date: str) -> bool:
        """判断是否为交易日"""
        dt = pd.Timestamp(date)
        # 周末不是交易日
        if dt.weekday() >= 5:
            return False
        # 法定节假日不是交易日
        if date in self.holidays:
            return False
        return True

    def get_trading_days(
        self, start_date: str, end_date: str
    ) -> pd.DatetimeIndex:
        """获取指定日期范围内的所有交易日"""
        all_dates = pd.bdate_range(start=start_date, end=end_date)
        trading_days = [
            d for d in all_dates
            if self.is_trading_day(d.strftime("%Y-%m-%d"))
        ]
        return pd.DatetimeIndex(trading_days)

    def align_to_trading_days(
        self, df: pd.DataFrame, date_col: str = "date"
    ) -> pd.DataFrame:
        """
        将数据对齐到交易日历
        - 移除非交易日的数据行
        - 确保交易日连续
        """
        df = df.copy()
        df[date_col] = pd.to_datetime(df[date_col])

        # 生成完整的交易日序列
        start = df[date_col].min()
        end = df[date_col].max()
        all_trading_days = self.get_trading_days(
            start.strftime("%Y-%m-%d"),
            end.strftime("%Y-%m-%d"),
        )

        # 合并，缺失的交易日会变成 NaN
        full_df = pd.DataFrame({date_col: all_trading_days})
        aligned = pd.merge(full_df, df, on=date_col, how="left")

        logger.info(
            f"交易日对齐: 原始 {len(df)} 行, "
            f"对齐后 {len(aligned)} 行, "
            f"新增 {len(aligned) - len(df)} 个缺失交易日"
        )
        return aligned
```

## 六、幸存者偏差

### 6.1 什么是幸存者偏差

```
幸存者偏差（Survivorship Bias）：

  回测时使用的股票池 = 当前还在上市的股票
  但实际上，在回测期间有很多股票退市了

  示例：
  2015 年有 2800 只 A 股
  2025 年有 5300 只 A 股（新增 2500 只，退市 0 只？）

  问题：
  如果你在 2015 年回测 2025 年的股票池，
  你会漏掉那些在 2015-2025 之间退市的股票（通常是表现最差的）

  结果：
  回测收益率虚高，因为"坏学生"被自动排除了
```

### 6.2 幸存者偏差修正

```python
class SurvivorshipBiasCorrector:
    """
    幸存者偏差修正器
    处理回测中的幸存者偏差问题
    """
    def __init__(self):
        self.delisted_stocks: dict[str, str] = {}  # {symbol: delist_date}

    def load_delisted_stocks(self, delisted_df: pd.DataFrame):
        """
        加载退市股票列表

        Args:
            delisted_df: 包含退市信息的 DataFrame
                        columns: [symbol, name, delist_date, reason]
        """
        for _, row in delisted_df.iterrows():
            self.delisted_stocks[row["symbol"]] = row["delist_date"]
        logger.info(f"加载 {len(self.delisted_stocks)} 只退市股票")

    def get_valid_universe(
        self,
        date: str,
        all_symbols: list[str]
    ) -> list[str]:
        """
        获取指定日期的有效股票池
        排除在该日期之前已退市的股票

        Args:
            date: 查询日期
            all_symbols: 所有股票代码

        Returns:
            该日期有效的股票列表
        """
        valid = []
        for symbol in all_symbols:
            if symbol in self.delisted_stocks:
                delist_date = self.delisted_stocks[symbol]
                if date >= delist_date:
                    continue  # 已退市，排除
            valid.append(symbol)
        return valid

    def filter_data_by_universe(
        self,
        data_dict: dict[str, pd.DataFrame],
        date_col: str = "date"
    ) -> dict[str, pd.DataFrame]:
        """
        过滤数据，只保留每个日期有效的股票数据
        """
        filtered = {}
        for symbol, df in data_dict.items():
            if symbol in self.delisted_stocks:
                delist_date = self.delisted_stocks[symbol]
                # 只保留退市日期之前的数据
                df_filtered = df[
                    pd.to_datetime(df[date_col]) < delist_date
                ]
                if len(df_filtered) > 0:
                    filtered[symbol] = df_filtered
            else:
                filtered[symbol] = df

        logger.info(
            f"幸存者偏差修正: "
            f"原始 {len(data_dict)} 只, 修正后 {len(filtered)} 只"
        )
        return filtered
```

### 7.2 管道实现

```python
class DataCleaningPipeline:
    """
    数据清洗管道
    将所有清洗步骤串联为一个完整的流水线
    """
    def __init__(self, config: Optional[dict] = None):
        self.config = config or self._default_config()
        self.calendar = TradingCalendar()
        self.detector = OutlierDetector()
        self.handler = OutlierHandler()
        self.adjuster = AdjustmentProcessor()
        self.quality_checker = DataQualityChecker()
        self.cleaning_log: list[dict] = []

    def _default_config(self) -> dict:
        return {
            "adjustment_type": "forward",      # forward / backward / none
            "outlier_method": "winsorize",      # winsorize / zscore / iqr / none
            "fill_method": "ffill",             # ffill / linear / none
            "max_fill_gap": 5,                  # 最大连续填充天数
            "align_to_calendar": True,          # 是否对齐交易日历
            "quality_check": True,              # 是否执行质量检查
        }

    def _log_step(self, step: str, details: str):
        """记录清洗步骤"""
        self.cleaning_log.append({
            "step": step,
            "details": details,
            "timestamp": pd.Timestamp.now(),
        })

    def clean_single_stock(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        清洗单只股票的数据

        Args:
            df: 原始数据 DataFrame

        Returns:
            清洗后的 DataFrame
        """
        symbol = df["symbol"].iloc[0] if "symbol" in df.columns else "unknown"
        original_len = len(df)

        # 步骤 1：格式标准化
        df = self._standardize_format(df)
        self._log_step("格式标准化", f"{symbol}: {len(df)} 行")

        # 步骤 2：停牌处理
        df = handle_suspended_days(df)
        suspended_count = df["is_suspended"].sum()
        self._log_step("停牌处理", f"{symbol}: {suspended_count} 天停牌")

        # 步骤 3：复权处理
        if self.config["adjustment_type"] != "none":
            df = self._apply_adjustment(df)
            self._log_step("复权处理", f"{symbol}: {self.config['adjustment_type']}")

        # 步骤 4：异常值处理
        if self.config["outlier_method"] != "none":
            df = self._process_outliers(df)
            self._log_step("异常值处理", f"{symbol}: {self.config['outlier_method']}")

        # 步骤 5：缺失值填充
        if self.config["fill_method"] != "none":
            df = fill_missing_prices(
                df,
                method=self.config["fill_method"],
                max_gap=self.config["max_fill_gap"],
            )
            self._log_step("缺失值填充", f"{symbol}: {self.config['fill_method']}")

        # 步骤 6：交易日历对齐
        if self.config["align_to_calendar"]:
            df = self.calendar.align_to_trading_days(df)
            self._log_step("日历对齐", f"{symbol}: {len(df)} 行")

        # 步骤 7：质量验证
        if self.config["quality_check"]:
            result = self.quality_checker.run_all_checks(df)
            self._log_step("质量验证", f"{symbol}: {result['pass_rate']} 通过")

        logger.info(
            f"{symbol} 清洗完成: {original_len} → {len(df)} 行"
        )
        return df

    def _standardize_format(self, df: pd.DataFrame) -> pd.DataFrame:
        """标准化数据格式"""
        df = df.copy()

        # 确保日期列为 datetime 类型
        if "date" in df.columns:
            df["date"] = pd.to_datetime(df["date"])

        # 确保价格列为浮点类型
        price_cols = ["open", "high", "low", "close"]
        for col in price_cols:
            if col in df.columns:
                df[col] = pd.to_numeric(df[col], errors="coerce")

        # 确保成交量为整数
        if "volume" in df.columns:
            df["volume"] = pd.to_numeric(df["volume"], errors="coerce")

        # 按日期排序
        df = df.sort_values("date").reset_index(drop=True)

        # 去重
        if "date" in df.columns:
            df = df.drop_duplicates(subset=["date"], keep="last")

        return df

    def _apply_adjustment(self, df: pd.DataFrame) -> pd.DataFrame:
        """应用复权处理"""
        if self.config["adjustment_type"] == "forward":
            return self.adjuster.apply_forward_adjustment(df)
        elif self.config["adjustment_type"] == "backward":
            return self.adjuster.apply_backward_adjustment(df)
        return df

    def _process_outliers(self, df: pd.DataFrame) -> pd.DataFrame:
        """处理异常值"""
        if "pct_change" in df.columns:
            df = process_returns_outliers(
                df,
                return_col="pct_change",
                method=self.config["outlier_method"],
            )
        return df

    def clean_batch(
        self,
        data_dict: dict[str, pd.DataFrame]
    ) -> dict[str, pd.DataFrame]:
        """
        批量清洗多只股票的数据

        Args:
            data_dict: {symbol: DataFrame} 字典

        Returns:
            清洗后的 {symbol: DataFrame} 字典
        """
        cleaned = {}
        total = len(data_dict)

        for i, (symbol, df) in enumerate(data_dict.items(), 1):
            try:
                cleaned[symbol] = self.clean_single_stock(df)
            except Exception as e:
                logger.error(f"清洗 {symbol} 失败: {e}")
                continue

            if i % 100 == 0:
                logger.info(f"清洗进度: {i}/{total}")

        logger.info(f"批量清洗完成: {len(cleaned)}/{total}")
        return cleaned

    def get_cleaning_report(self) -> pd.DataFrame:
        """生成清洗报告"""
        return pd.DataFrame(self.cleaning_log)
```

## 八、常见误区

### 误区一："直接用 AKShare 返回的数据"

AKShare 返回的数据通常是不复权或前复权的，直接用于回测可能导致：
- 除权日出现虚假的价格跳变
- 均线等技术指标失真
- 回测结果不可靠

**正确做法**：明确复权方式，并在数据清洗管道中统一处理。

### 误区二："前复权和后复权效果一样"

两者适用场景不同：
- **前复权**：适合看盘和短期交易，方便与当前价格比较
- **后复权**：适合计算长期收益率，因为保持了收益率的正确性

**建议**：回测用后复权，信号计算用前复权。

### 误区三："异常值应该全部删除"

删除异常值会损失信息。正确的做法是：
- **数据错误**：用合理值替换（如中位数、前值）
- **真实极端行情**：保留但标记（如 2015 年股灾）
- **模型输入**：用 Winsorize 压缩极端值

### 误区四："幸存者偏差不重要"

研究表明，幸存者偏差可以使回测年化收益率虚高 1-3 个百分点。在 A 股市场，虽然退市股票不多，但它们往往是表现最差的——忽略它们会严重高估策略表现。

## 小结与练习

### 小结

本课系统讲解了数据清洗的核心问题：

- 缺失数据有四种模式，需要不同的处理策略
- 前复权和后复权有不同适用场景，回测应使用后复权
- 异常值处理应区分数据错误和真实极端行情
- 多频率数据应使用 merge_asof 避免未来数据泄露
- 幸存者偏差会使回测收益率虚高，必须修正

```python
# 生成含异常值的测试数据
np.random.seed(42)
data = pd.Series(np.random.normal(0, 1, 1000))
data[100] = 10.0   # 极端正异常
data[500] = -8.0   # 极端负异常
data[800] = 5.0    # 中等异常

detector = OutlierDetector()

zscore_outliers = detector.detect_zscore(data, threshold=3.0)
iqr_outliers = detector.detect_iqr(data, multiplier=1.5)
mad_outliers = detector.detect_mad(data, threshold=3.5)

print(f"Z-score 检测: {zscore_outliers.sum()} 个异常值")
print(f"IQR 检测: {iqr_outliers.sum()} 个异常值")
print(f"MAD 检测: {mad_outliers.sum()} 个异常值")

# 对比
print(f"\n三种方法都标记的: {(zscore_outliers & iqr_outliers & mad_outliers).sum()}")
print(f"仅 Z-score 标记: {(zscore_outliers & ~iqr_outliers & ~mad_outliers).sum()}")
print(f"仅 IQR 标记: {(~zscore_outliers & iqr_outliers & ~mad_outliers).sum()}")
```

**要点**：
- Z-score 假设正态分布，对极端值敏感
- IQR 对非正态分布更鲁棒
- MAD 比 Z-score 对极端值更鲁棒
- 实际应用中建议多种方法交叉验证

```python
def compute_derived_features(self, df: pd.DataFrame) -> pd.DataFrame:
    """计算衍生特征（技术指标）"""
    df = df.copy()

    # 移动平均线
    df["ma5"] = df["close"].rolling(window=5).mean()
    df["ma10"] = df["close"].rolling(window=10).mean()
    df["ma20"] = df["close"].rolling(window=20).mean()
    df["ma60"] = df["close"].rolling(window=60).mean()

    # RSI (14)
    delta = df["close"].diff()
    gain = delta.where(delta > 0, 0).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
    rs = gain / loss
    df["rsi_14"] = 100 - (100 / (1 + rs))

    # 布林带 (20, 2)
    df["boll_mid"] = df["close"].rolling(window=20).mean()
    boll_std = df["close"].rolling(window=20).std()
    df["boll_upper"] = df["boll_mid"] + 2 * boll_std
    df["boll_lower"] = df["boll_mid"] - 2 * boll_std

    # 波动率 (20 日)
    if "pct_change" in df.columns:
        df["volatility_20"] = (
            df["pct_change"].rolling(window=20).std() * np.sqrt(252)
        )

    # 成交量均线
    df["vol_ma5"] = df["volume"].rolling(window=5).mean()
    df["vol_ma20"] = df["volume"].rolling(window=20).mean()

    return df
```
