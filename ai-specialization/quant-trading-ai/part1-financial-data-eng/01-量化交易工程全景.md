## 一、量化交易不是赌博

### 1.1 赌博 vs 量化交易的本质区别

```
赌博模型：
  期望收益 = Σ(概率 × 收益) - 抽水
  核心特征：负期望值，长期必输

量化交易模型：
  期望收益 = Alpha × 置信度 - 交易成本 - 滑点
  核心特征：正期望值（目标），但不确定
```

赌博和量化交易的根本区别不在于"有没有用电脑"，而在于**期望值的来源**：

| 维度 | 赌博 | 量化交易 |
|------|------|----------|
| 期望值 | 负（庄家抽水） | 正（Alpha 信号） |
| 决策依据 | 运气 / 直觉 | 数据 + 模型 |
| 风险管理 | 无或简单止损 | 系统化风控体系 |
| 可重复性 | 单次博弈 | 大数定律下的统计套利 |
| 退出条件 | 输光或赢够 | 策略失效 / 市场结构变化 |

### 1.2 一个关键认知：Alpha 是有限的

Alpha（超额收益）是量化交易的核心概念。它不是凭空产生的，而是来源于：

- **信息优势**：比别人更快、更准确地获取和处理信息
- **分析优势**：从同样的数据中提取别人看不到的信号
- **执行优势**：以更低的成本完成交易
- **速度优势**：在别人反应之前完成交易

```
Alpha 衰减示意：

  Alpha
  强度
   │
   │  ★ 策略刚发布
   │   ╲
   │    ╲  其他人发现并模仿
   │     ╲
   │      ╲______  Alpha 趋近于零
   │              ╲___________
   └──────────────────────────── 时间
```

这意味着量化交易是一场**持续的军备竞赛**，不是"写完策略就躺赚"。

## 二、信号链：量化交易的骨架

### 2.1 完整信号链

量化交易系统的核心是一条**信号链（Signal Chain）**，数据从一端流入，订单从另一端流出：

```
┌─────────────────────────────────────────────────────────────────┐
│                       量化交易信号链                              │
│                                                                 │
│  ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐        │
│  │ 数据 │──▶│ Alpha│──▶│ 组合 │──▶│ 执行 │──▶│ 风控 │        │
│  │ 采集 │   │ 生成 │   │ 优化 │   │ 引擎 │   │ 系统 │        │
│  └──────┘   └──────┘   └──────┘   └──────┘   └──────┘        │
│     │           │           │           │           │          │
│     ▼           ▼           ▼           ▼           ▼          │
│  行情数据    因子信号    权重分配    订单拆分    风险限额        │
│  财务数据    机器学习    风险预算    滑点控制    异常检测        │
│  另类数据    统计模型    交易成本    市场冲击    合规检查        │
│  宏观数据    NLP 情绪    再平衡      智能路由    回撤控制        │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 五大模块详解

**模块一：数据采集（Data Ingestion）**

这是整个系统的地基。数据质量直接决定策略上限——垃圾进，垃圾出（Garbage In, Garbage Out）。

```
数据源层级：

  第一层：交易所原始数据（Level 1/2/3 行情）
    │
    ▼
  第二层：清洗后的标准化数据（OHLCV、财务报表）
    │
    ▼
  第三层：加工后的衍生数据（技术指标、因子值）
    │
    ▼
  第四层：另类数据（舆情、卫星图、供应链）
```

**模块二：Alpha 生成（Signal Generation）**

Alpha 信号是"买什么、卖什么"的决策依据。常见的 Alpha 来源：

```python
# Alpha 信号的典型分类
alpha_sources = {
    "基本面因子": ["市盈率", "市净率", "ROE", "营收增速"],
    "技术面因子": ["动量", "波动率", "成交量变化", "均线偏离"],
    "另类因子":   ["新闻情绪", "分析师预期修正", "资金流向"],
    "高频因子":   ["订单簿不平衡", "成交速率", "价格冲击"],
}
```

**模块三：组合优化（Portfolio Optimization）**

拿到一堆 Alpha 信号后，需要决定每只股票买多少。这不是简单地"信号最强的买最多"，而是一个受约束的优化问题：

```
目标函数：
  max  Σ(w_i × alpha_i) - λ × ΣΣ(w_i × w_j × Σ_ij) - TC(w, w_prev)

约束条件：
  Σw_i = 1                  （满仓约束）
  0 ≤ w_i ≤ 0.05            （单票上限 5%）
  |w_i - w_prev_i| ≤ 0.02   （换手率约束）
  Σ(w_i × beta_i) ≤ 0.8     （市场风险敞口）
```

**模块四：执行引擎（Execution Engine）**

好的执行算法可以节省 10-30 个基点的成本。常见的执行策略：

| 算法 | 适用场景 | 核心思想 |
|------|----------|----------|
| TWAP | 流动性好的股票 | 按时间均匀下单 |
| VWAP | 中等 urgency | 跟踪成交量分布下单 |
| IS (Implementation Shortfall) | 高 urgency | 最小化执行价与决策价的偏差 |
| POV | 被动执行 | 按市场成交量的比例下单 |

**模块五：风控系统（Risk Management）**

风控是量化交易的"安全气囊"，必须在策略失效前介入：

```
风控层级：

  第一层：单笔订单风控
    - 价格偏离检查（与最新价比较）
    - 数量上限检查
    - 重复下单检查

  第二层：日内组合风控
    - 当日亏损限额（如 -2% 强平）
    - 持仓集中度检查
    - 行业 / 风格敞口检查

  第三层：策略级风控
    - 最大回撤阈值（如 -15% 停止策略）
    - Alpha 信号衰减检测
    - 波动率 regime 检测
```

## 五、第一个量化策略：双均线交叉

理论讲再多，不如写一个能跑的策略。我们用最经典的**双均线交叉策略**来演示完整的信号链。

### 5.1 策略逻辑

```
双均线交叉策略：

  短期均线（如 5 日）上穿长期均线（如 20 日）→ 买入信号
  短期均线下穿长期均线 → 卖出信号

  价格
   │          ╱╲    ★ 买入点（金叉）
   │    ╱╲  ╱  ╲  ╱
   │   ╱  ╲╱    ╲╱     ★ 卖出点（死叉）
   │  ╱
   │ ╱
   └──────────────────── 时间
      5MA ──  20MA ──
```

### 5.2 完整代码实现

```python
"""
双均线交叉策略 - 量化交易入门示例
本示例展示完整的信号链：数据获取 → 信号生成 → 回测评估
"""

import pandas as pd
import numpy as np
from datetime import datetime, timedelta
from dataclasses import dataclass, field
from typing import Optional
import warnings
warnings.filterwarnings("ignore")


@dataclass
class TradeRecord:
    """交易记录数据结构"""
    date: datetime
    symbol: str
    direction: str       # "BUY" or "SELL"
    price: float
    quantity: int
    commission: float = 0.0
    slippage: float = 0.0


@dataclass
class StrategyConfig:
    """策略配置参数"""
    short_window: int = 5       # 短期均线周期
    long_window: int = 20       # 长期均线周期
    initial_capital: float = 100_000.0  # 初始资金
    commission_rate: float = 0.001      # 手续费率 0.1%
    slippage_rate: float = 0.001        # 滑点率 0.1%
    position_size: float = 0.95         # 仓位比例（留 5% 现金缓冲）


def generate_mock_data(
    symbol: str = "000001.SZ",
    start_date: str = "2023-01-01",
    end_date: str = "2024-12-31",
    seed: int = 42
) -> pd.DataFrame:
    """生成模拟股票数据（实际项目中应从数据源获取）"""
    np.random.seed(seed)
    dates = pd.bdate_range(start=start_date, end=end_date)
    n = len(dates)

    # 用几何布朗运动模拟价格
    dt = 1 / 252
    mu = 0.08          # 年化收益率 8%
    sigma = 0.25       # 年化波动率 25%
    initial_price = 10.0

    returns = np.random.normal(mu * dt, sigma * np.sqrt(dt), n)
    prices = initial_price * np.exp(np.cumsum(returns))

    # 生成 OHLCV
    highs = prices * (1 + np.abs(np.random.normal(0, 0.01, n)))
    lows = prices * (1 - np.abs(np.random.normal(0, 0.01, n)))
    opens = prices * (1 + np.random.normal(0, 0.005, n))
    volumes = np.random.randint(1_000_000, 50_000_000, n)

    df = pd.DataFrame({
        "date": dates[:n],
        "symbol": symbol,
        "open": opens,
        "high": highs,
        "low": lows,
        "close": prices,
        "volume": volumes,
    })
    df.set_index("date", inplace=True)
    return df


def compute_signals(df: pd.DataFrame, config: StrategyConfig) -> pd.DataFrame:
    """计算交易信号"""
    df = df.copy()
    df["ma_short"] = df["close"].rolling(window=config.short_window).mean()
    df["ma_long"] = df["close"].rolling(window=config.long_window).mean()

    # 信号：短期均线在长期均线上方为 1，否则为 0
    df["signal"] = 0
    df.loc[df["ma_short"] > df["ma_long"], "signal"] = 1

    # 生成交易动作：信号变化时触发
    df["position_change"] = df["signal"].diff()
    # position_change = 1 → 买入，-1 → 卖出
    return df


def run_backtest(
    df: pd.DataFrame,
    config: StrategyConfig
) -> tuple[pd.DataFrame, list[TradeRecord]]:
    """执行回测"""
    capital = config.initial_capital
    position = 0
    trades: list[TradeRecord] = []

    portfolio_values = []
    shares_list = []

    for i, (date, row) in enumerate(df.iterrows()):
        price = row["close"]
        change = row["position_change"]

        if change == 1 and position == 0:
            # 买入信号
            buy_price = price * (1 + config.slippage_rate)
            max_shares = int(
                (capital * config.position_size) / buy_price / 100
            ) * 100  # A 股按手（100 股）取整
            if max_shares > 0:
                cost = max_shares * buy_price
                commission = cost * config.commission_rate
                capital -= (cost + commission)
                position = max_shares
                trades.append(TradeRecord(
                    date=date, symbol=row["symbol"],
                    direction="BUY", price=buy_price,
                    quantity=max_shares, commission=commission,
                    slippage=max_shares * price * config.slippage_rate
                ))

        elif change == -1 and position > 0:
            # 卖出信号
            sell_price = price * (1 - config.slippage_rate)
            revenue = position * sell_price
            commission = revenue * config.commission_rate
            capital += (revenue - commission)
            trades.append(TradeRecord(
                date=date, symbol=row["symbol"],
                direction="SELL", price=sell_price,
                quantity=position, commission=commission,
                slippage=position * price * config.slippage_rate
            ))
            position = 0

        portfolio_value = capital + position * price
        portfolio_values.append(portfolio_value)
        shares_list.append(position)

    df["portfolio_value"] = portfolio_values
    df["shares_held"] = shares_list
    return df, trades


def compute_metrics(
    df: pd.DataFrame,
    trades: list[TradeRecord],
    config: StrategyConfig
) -> dict:
    """计算策略评估指标"""
    returns = df["portfolio_value"].pct_change().dropna()
    total_return = (
        df["portfolio_value"].iloc[-1] / config.initial_capital - 1
    )
    n_years = len(returns) / 252
    annual_return = (1 + total_return) ** (1 / n_years) - 1

    annual_vol = returns.std() * np.sqrt(252)
    sharpe_ratio = annual_return / annual_vol if annual_vol > 0 else 0

    # 最大回撤
    peak = df["portfolio_value"].expanding().max()
    drawdown = (df["portfolio_value"] - peak) / peak
    max_drawdown = drawdown.min()

    # 交易统计
    total_commission = sum(t.commission for t in trades)
    total_slippage = sum(t.slippage for t in trades)
    n_trades = len(trades)

    # 胜率
    buy_trades = [t for t in trades if t.direction == "BUY"]
    sell_trades = [t for t in trades if t.direction == "SELL"]
    wins = 0
    for buy, sell in zip(buy_trades, sell_trades):
        if sell.price > buy.price:
            wins += 1
    win_rate = wins / len(sell_trades) if sell_trades else 0

    return {
        "总收益率": f"{total_return:.2%}",
        "年化收益率": f"{annual_return:.2%}",
        "年化波动率": f"{annual_vol:.2%}",
        "夏普比率": f"{sharpe_ratio:.2f}",
        "最大回撤": f"{max_drawdown:.2%}",
        "交易次数": n_trades,
        "胜率": f"{win_rate:.2%}",
        "总手续费": f"{total_commission:.2f}",
        "总滑点成本": f"{total_slippage:.2f}",
    }


def main():
    """主函数：运行完整的信号链"""
    print("=" * 60)
    print("  双均线交叉策略回测")
    print("=" * 60)

    # 第一步：配置参数
    config = StrategyConfig(
        short_window=5,
        long_window=20,
        initial_capital=100_000.0,
    )
    print(f"\n策略参数：短均线={config.short_window}, "
          f"长均线={config.long_window}")

    # 第二步：获取数据
    print("\n[1/4] 获取数据...")
    df = generate_mock_data()
    print(f"  数据范围：{df.index[0].date()} ~ {df.index[-1].date()}")
    print(f"  数据条数：{len(df)}")

    # 第三步：计算信号
    print("\n[2/4] 计算交易信号...")
    df = compute_signals(df, config)
    buy_signals = (df["position_change"] == 1).sum()
    sell_signals = (df["position_change"] == -1).sum()
    print(f"  买入信号：{buy_signals} 次")
    print(f"  卖出信号：{sell_signals} 次")

    # 第四步：执行回测
    print("\n[3/4] 执行回测...")
    df, trades = run_backtest(df, config)

    # 第五步：评估结果
    print("\n[4/4] 计算评估指标...")
    metrics = compute_metrics(df, trades, config)
    print("\n" + "-" * 40)
    print("  回测结果")
    print("-" * 40)
    for key, value in metrics.items():
        print(f"  {key:　<8}: {value}")
    print("-" * 40)

    # 打印最近 5 笔交易
    print("\n最近 5 笔交易：")
    for t in trades[-5:]:
        print(f"  {t.date.date()} {t.direction:4} "
              f"{t.symbol} @ {t.price:.2f} x {t.quantity}")

    print("\n> 风险提示：本回测使用模拟数据，不代表真实交易表现。")
    print("> 实盘交易需考虑流动性、涨跌停、停牌等因素。")


if __name__ == "__main__":
    main()
```

### 5.3 代码要点解析

这段代码虽然简单，但展示了量化系统的几个核心工程模式：

1. **数据类建模**：用 `@dataclass` 定义交易记录和策略配置，比字典更安全
2. **信号与执行分离**：`compute_signals()` 只算信号，`run_backtest()` 负责执行，职责清晰
3. **成本模拟**：包含手续费和滑点，这在真实回测中至关重要
4. **A 股规则**：按 100 股整手取整，这是 A 股的基本交易规则

## 六、常见误区

### 误区一："量化交易 = 写个策略自动赚钱"

量化交易是一个**系统工程**，策略只是其中一环。一个能稳定盈利的量化系统，80% 的工作量在数据、基础设施和风控上。

### 误区二："回测赚钱，实盘就赚钱"

回测中存在大量陷阱：
- **未来函数（Look-ahead Bias）**：使用了未来才知道的数据
- **幸存者偏差（Survivorship Bias）**：只回测了现在还在上市的股票
- **过拟合（Overfitting）**：参数过度拟合历史数据
- **交易成本低估**：没有考虑滑点、冲击成本、涨跌停

### 误区三："越复杂的模型越好"

在量化领域，简单且鲁棒的策略往往比复杂模型更可靠。一个 3 参数的策略如果在 10 年数据上稳定盈利，通常比一个 100 参数的深度学习模型更值得信任。

### 误区四："有了好策略就能赚钱"

策略只是起点。执行质量、风控纪律、技术稳定性、资金管理，每一项都可能导致"好策略亏钱"。

## 七、工程建议

1. **从单体架构开始**：不要一开始就设计微服务，先把信号链跑通
2. **数据先行**：在写任何策略之前，先确保数据管道可靠
3. **回测框架标准化**：不要为每个策略写一套回测代码，抽象出通用框架
4. **日志和监控**：量化系统最怕"黑箱运行"，每一步都要有日志
5. **渐进式上线**：模拟盘 → 小资金实盘 → 逐步加仓

### 练习三

**思路**：在 `run_backtest()` 的循环中加入持仓盈亏检查。

**答案**：

```python
def run_backtest_with_stoploss(
    df: pd.DataFrame,
    config: StrategyConfig,
    stop_loss_pct: float = 0.05
) -> tuple[pd.DataFrame, list[TradeRecord]]:
    capital = config.initial_capital
    position = 0
    entry_price = 0.0
    trades: list[TradeRecord] = []
    portfolio_values = []
    shares_list = []

    for i, (date, row) in enumerate(df.iterrows()):
        price = row["close"]
        change = row["position_change"]

        # 止损检查：持仓亏损超过阈值时强制卖出
        if position > 0:
            unrealized_pnl = (price - entry_price) / entry_price
            if unrealized_pnl < -stop_loss_pct:
                sell_price = price * (1 - config.slippage_rate)
                revenue = position * sell_price
                commission = revenue * config.commission_rate
                capital += (revenue - commission)
                trades.append(TradeRecord(
                    date=date, symbol=row["symbol"],
                    direction="SELL", price=sell_price,
                    quantity=position, commission=commission,
                    slippage=position * price * config.slippage_rate
                ))
                position = 0
                portfolio_values.append(capital)
                shares_list.append(0)
                continue

        if change == 1 and position == 0:
            buy_price = price * (1 + config.slippage_rate)
            max_shares = int(
                (capital * config.position_size) / buy_price / 100
            ) * 100
            if max_shares > 0:
                cost = max_shares * buy_price
                commission = cost * config.commission_rate
                capital -= (cost + commission)
                position = max_shares
                entry_price = buy_price
                trades.append(TradeRecord(
                    date=date, symbol=row["symbol"],
                    direction="BUY", price=buy_price,
                    quantity=max_shares, commission=commission,
                    slippage=max_shares * price * config.slippage_rate
                ))

        elif change == -1 and position > 0:
            sell_price = price * (1 - config.slippage_rate)
            revenue = position * sell_price
            commission = revenue * config.commission_rate
            capital += (revenue - commission)
            trades.append(TradeRecord(
                date=date, symbol=row["symbol"],
                direction="SELL", price=sell_price,
                quantity=position, commission=commission,
                slippage=position * price * config.slippage_rate
            ))
            position = 0

        portfolio_value = capital + position * price
        portfolio_values.append(portfolio_value)
        shares_list.append(position)

    df["portfolio_value"] = portfolio_values
    df["shares_held"] = shares_list
    return df, trades
```

**要点**：
- 止损检查应在信号检查之前执行
- 止损后需要记录 `entry_price` 重置
- 止损可以显著降低最大回撤，但也会增加交易次数
