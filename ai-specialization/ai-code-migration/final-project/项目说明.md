# 毕业项目：遗留系统迁移工具链

## 项目概述

构建一套完整的遗留系统迁移工具，包含代码分析器、迁移规划器、自动转换器、测试生成器和进度看板，支持从 jQuery/Express/Vue2 等老技术栈迁移到 React/Vue3/Node.js 等现代技术栈。

## 核心功能

### 1. 代码分析器
- AST 解析：提取函数、类、模块的结构信息
- 依赖图谱：可视化模块间的依赖关系
- 调用链路：从入口函数到数据库操作的完整路径
- AI 代码摘要：LLM 批量生成代码的功能描述
- 复杂度评估：圈复杂度、代码行数、技术债评分

### 2. 迁移规划器
- AI 分析迁移难度：基于代码复杂度和依赖关系
- 自动生成迁移计划：推荐迁移顺序和分组
- 工作量估算：基于历史数据的工时预测
- 风险评估：识别高风险模块

### 3. 自动转换器
- AST 级转换：jQuery → React、CommonJS → ESM
- LLM 辅助翻译：复杂逻辑的语义级转换
- 批量重构：变量重命名、函数拆分、模块重组
- 转换结果对比：原文 vs 转换后，并排展示

### 4. 测试生成器
- 自动生成等价性测试
- 转换前后的输出对比
- 边界条件覆盖
- 集成测试脚手架

### 5. 进度看板
- 迁移进度：已转换 / 待转换 / 需人工处理
- 质量指标：测试覆盖率、通过率
- 风险预警：高复杂度、高依赖的模块
- 变更审计：每次转换的详细日志
