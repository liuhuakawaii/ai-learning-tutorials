# 第六课：阶段实战 —— 遗留代码智能分析工具

## 场景引入

前五课我们分别学习了 AST 基础、依赖分析、代码模式识别、调用链路分析、AI 代码理解。现在，是时候把这些知识整合成一个**完整的实战工具**了。

想象这个场景：你是一个技术负责人，团队要将一个老旧的 Node.js 电商系统迁移到新架构。你需要回答：模块怎么依赖？核心业务流程是什么？哪些是 Dead Code？哪些业务规则需要保留？迁移风险在哪？

手动回答需要两周。用我们即将构建的工具 `legacy-insight`，只需要几分钟。

## 核心概念

### 一、工具架构

```
┌─────────────────────────────────────────────┐
│              CLI 层 (cli.ts)                  │
│        命令行入口、参数解析、输出格式化          │
└───────────────────┬─────────────────────────┘
                    │
┌───────────────────┴─────────────────────────┐
│            编排层 (pipeline.ts)               │
│      协调各分析器执行顺序、结果聚合             │
└───────────────────┬─────────────────────────┘
                    │
┌───────────────────┴─────────────────────────┐
│           分析层 (analyzers/)                 │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
│ │AST解析  │ │依赖分析 │ │调用链路 │ │AI分析  │ │
│ └────────┘ └────────┘ └────────┘ └────────┘ │
└───────────────────┬─────────────────────────┘
                    │
┌───────────────────┴─────────────────────────┐
│            基础层 (core/)                     │
│       文件扫描、AST 工具、LLM 客户端           │
└─────────────────────────────────────────────┘
```

### 二、数据流

```
源码目录 → [文件扫描] → FileInfo[]
         → [AST 解析] → FileAstInfo[]
         → [依赖分析] → DependencyGraph
         → [调用链路] → CallGraph
         → [AI 分析] → AiFileAnalysis[]
         → [报告生成] → Markdown/JSON
```

AI 分析放最后——先用确定性方法获取结构信息，再用 AI 做语义理解，减少调用次数并为 AI 提供更多上下文。

```typescript
// src/core/scanner.ts
import { glob } from "glob";
import { statSync } from "fs";
import { extname } from "path";

export interface FileInfo {
  path: string;
  relativePath: string;
  extension: string;
  size: number;
  language: "javascript" | "typescript" | "python" | "unknown";
}

const LANG_MAP: Record<string, FileInfo["language"]> = {
  ".js": "javascript", ".jsx": "javascript", ".ts": "typescript", ".tsx": "typescript", ".py": "python",
};

export async function scanProject(projectPath: string): Promise<FileInfo[]> {
  const files = await glob("**/*.{ts,tsx,js,jsx,py}", {
    cwd: projectPath,
    ignore: ["**/node_modules/**", "**/dist/**", "**/.git/**", "**/__pycache__/**", "**/*.test.*"],
    nodir: true,
  });
  return files.map((file) => ({
    path: `${projectPath}/${file}`,
    relativePath: file,
    extension: extname(file),
    size: statSync(`${projectPath}/${file}`).size,
    language: LANG_MAP[extname(file)] ?? "unknown",
  })).sort((a, b) => a.relativePath.localeCompare(b.relativePath));
}
```

### 二、AST 解析器

```typescript
// src/core/parser.ts
import * as babelParser from "@babel/parser";
import * as babelTraverse from "@babel/traverse";
import * as t from "@babel/types";
import { readFileSync } from "fs";
import { FileInfo } from "./scanner";

export interface FunctionInfo { name: string; filePath: string; startLine: number; endLine: number; params: string[]; isAsync: boolean; bodyPreview: string; }
export interface ImportInfo { source: string; specifiers: string[]; filePath: string; }
export interface FileAstInfo { filePath: string; functions: FunctionInfo[]; imports: ImportInfo[]; exports: string[]; }

export function parseFile(file: FileInfo): FileAstInfo | null {
  try {
    const code = readFileSync(file.path, "utf-8");
    const ast = babelParser.parse(code, {
      sourceType: "unambiguous",
      plugins: ["jsx", file.language === "typescript" ? "typescript" : null, "decorators-legacy", "classProperties", "optionalChaining"].filter(Boolean) as any[],
    });
    const functions: FunctionInfo[] = [];
    const imports: ImportInfo[] = [];
    const exports: string[] = [];

    babelTraverse.default(ast, {
      FunctionDeclaration(path) {
        if (path.node.id) {
          functions.push({
            name: path.node.id.name, filePath: file.path,
            startLine: path.node.loc?.start.line ?? 0, endLine: path.node.loc?.end.line ?? 0,
            params: path.node.params.map((p) => t.isIdentifier(p) ? p.name : "_"),
            isAsync: path.node.async,
            bodyPreview: code.slice(path.node.body.start ?? 0, Math.min((path.node.body.start ?? 0) + 200, path.node.body.end ?? 0)),
          });
        }
      },
      ArrowFunctionExpression(path) {
        const parent = path.parent;
        if (t.isVariableDeclarator(parent) && t.isIdentifier(parent.id)) {
          functions.push({
            name: parent.id.name, filePath: file.path,
            startLine: path.node.loc?.start.line ?? 0, endLine: path.node.loc?.end.line ?? 0,
            params: path.node.params.map((p) => t.isIdentifier(p) ? p.name : "_"),
            isAsync: path.node.async, bodyPreview: "",
          });
        }
      },
      ImportDeclaration(path) {
        imports.push({
          source: path.node.source.value,
          specifiers: path.node.specifiers.map((s) => t.isImportDefaultSpecifier(s) ? s.local.name : t.isImportSpecifier(s) ? (t.isIdentifier(s.imported) ? s.imported.name : s.imported.value) : "_"),
          filePath: file.path,
        });
      },
      ExportNamedDeclaration(path) {
        if (path.node.declaration && t.isFunctionDeclaration(path.node.declaration) && path.node.declaration.id) exports.push(path.node.declaration.id.name);
      },
    });
    return { filePath: file.path, functions, imports, exports };
  } catch { return null; }
}
```

### 三、依赖分析器

```typescript
// src/analyzers/dependency.ts
import { FileAstInfo } from "../core/parser";
import { FileInfo } from "../core/scanner";
import { resolve, dirname, join } from "path";

export interface DependencyNode { filePath: string; imports: string[]; importedBy: string[]; externalDeps: string[]; }
export interface DependencyGraph { nodes: Map<string, DependencyNode>; circularDependencies: string[][]; externalDependencies: Set<string>; }

export function buildDependencyGraph(files: FileInfo[], astInfos: Map<string, FileAstInfo>): DependencyGraph {
  const graph: DependencyGraph = { nodes: new Map(), circularDependencies: [], externalDependencies: new Set() };
  const pathIndex = new Map<string, string>();
  for (const f of files) {
    pathIndex.set(f.relativePath, f.path);
    pathIndex.set(f.relativePath.replace(/\.(ts|tsx|js|jsx)$/, ""), f.path);
  }
  for (const f of files) graph.nodes.set(f.path, { filePath: f.path, imports: [], importedBy: [], externalDeps: [] });

  for (const [filePath, astInfo] of astInfos) {
    const node = graph.nodes.get(filePath)!;
    for (const imp of astInfo.imports) {
      if (imp.source.startsWith(".")) {
        const resolved = resolve(dirname(filePath), imp.source);
        const target = pathIndex.get(resolved) ?? pathIndex.get(resolved + ".ts") ?? pathIndex.get(join(resolved, "index.ts"));
        if (target) { node.imports.push(target); graph.nodes.get(target)?.importedBy.push(filePath); }
      } else {
        const pkg = imp.source.startsWith("@") ? imp.source.split("/").slice(0, 2).join("/") : imp.source.split("/")[0];
        node.externalDeps.push(pkg); graph.externalDependencies.add(pkg);
      }
    }
  }
  graph.circularDependencies = detectCycles(graph);
  return graph;
}

function detectCycles(graph: DependencyGraph): string[][] {
  const cycles: string[][] = [];
  const visited = new Set<string>();
  const inStack = new Set<string>();
  function dfs(node: string, path: string[]) {
    if (inStack.has(node)) { const s = path.indexOf(node); if (s >= 0) cycles.push(path.slice(s).concat(node)); return; }
    if (visited.has(node)) return;
    visited.add(node); inStack.add(node); path.push(node);
    for (const dep of graph.nodes.get(node)?.imports ?? []) dfs(dep, [...path]);
    inStack.delete(node);
  }
  for (const node of graph.nodes.keys()) dfs(node, []);
  return cycles;
}

export function formatDependencyReport(graph: DependencyGraph): string {
  const lines = ["## 依赖分析\n", `- **外部依赖**: ${graph.externalDependencies.size} 个`, `- **循环依赖**: ${graph.circularDependencies.length} 组\n`];
  if (graph.circularDependencies.length > 0) {
    lines.push("### ⚠️ 循环依赖\n");
    for (const cycle of graph.circularDependencies) lines.push(`- ${cycle.map((f) => `\`${f.split("/").pop()}\``).join(" → ")}`);
  }
  return lines.join("\n");
}
```

### 四、调用链路与 AI 分析器

```typescript
// src/analyzers/call-graph.ts
import { FileAstInfo } from "../core/parser";

export interface CallNode { id: string; name: string; filePath: string; line: number; callsTo: string[]; calledBy: string[]; sideEffects: string[]; }
export interface CallGraphData { nodes: Map<string, CallNode>; entryPoints: string[]; deadCode: string[]; }

const SIDE_EFFECT_RE: Record<string, RegExp> = {
  database: /\.(query|execute|insert|update|delete|find|save)\s*\(/,
  filesystem: /\.(readFile|writeFile|readFileSync|writeFileSync)\s*\(/,
  network: /(fetch|axios|http)\s*[.(]/,
  messaging: /\.(emit|publish|send)\s*\(/,
};

export function buildCallGraph(astInfos: Map<string, FileAstInfo>): CallGraphData {
  const graph: CallGraphData = { nodes: new Map(), entryPoints: [], deadCode: [] };
  for (const [fp, info] of astInfos) {
    for (const func of info.functions) {
      const id = `${fp}:${func.name}`;
      const effects = Object.entries(SIDE_EFFECT_RE).filter(([, re]) => re.test(func.bodyPreview)).map(([c]) => c);
      graph.nodes.set(id, { id, name: func.name, filePath: fp, line: func.startLine, callsTo: [], calledBy: [], sideEffects: effects });
    }
  }
  for (const [fp, info] of astInfos) {
    for (const func of info.functions) {
      const callerId = `${fp}:${func.name}`;
      const re = /(\w+)\s*\(/g;
      let m;
      while ((m = re.exec(func.bodyPreview))) {
        if (["if","else","for","while","return","new","typeof"].includes(m[1])) continue;
        const calleeId = `${fp}:${m[1]}`;
        if (graph.nodes.has(calleeId)) {
          graph.nodes.get(callerId)!.callsTo.push(calleeId);
          graph.nodes.get(calleeId)!.calledBy.push(callerId);
        }
      }
    }
  }
  for (const [id, node] of graph.nodes) {
    if (["main","handler","controller","route","app","run","init"].some((p) => node.name.includes(p)) || node.calledBy.length === 0) graph.entryPoints.push(id);
  }
  const reachable = new Set<string>();
  const queue = [...graph.entryPoints];
  while (queue.length) { const c = queue.shift()!; if (reachable.has(c)) continue; reachable.add(c); graph.nodes.get(c)?.callsTo.forEach((t) => { if (!reachable.has(t)) queue.push(t); }); }
  graph.deadCode = [...graph.nodes.keys()].filter((k) => !reachable.has(k));
  return graph;
}

export function formatCallGraphReport(graph: CallGraphData): string {
  const lines = ["## 调用链路分析\n", `- **函数总数**: ${graph.nodes.size}`, `- **入口点**: ${graph.entryPoints.length} 个`, `- **不可达代码**: ${graph.deadCode.length} 个\n`];
  if (graph.deadCode.length > 0) {
    lines.push("### 不可达代码候选\n");
    for (const id of graph.deadCode.slice(0, 10)) { const n = graph.nodes.get(id)!; lines.push(`- \`${n.name}\` (${n.filePath.split("/").pop()}:${n.line})`); }
  }
  return lines.join("\n");
}
```

```typescript
// src/analyzers/ai-analyzer.ts
import OpenAI from "openai";
import { FileAstInfo } from "../core/parser";
import { readFileSync } from "fs";

export interface AiFileAnalysis { filePath: string; summary: string; purpose: string; businessRules: string[]; complexity: "low"|"medium"|"high"; migrationPriority: "high"|"medium"|"low"; migrationNotes: string; }

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export async function analyzeFileWithAi(filePath: string, astInfo: FileAstInfo): Promise<AiFileAnalysis> {
  const code = readFileSync(filePath, "utf-8");
  const funcList = astInfo.functions.map((f) => `- ${f.name}(行${f.startLine}): ${f.isAsync ? "async" : "sync"}, 参数[${f.params.join(", ")}]`).join("\n");

  const response = await openai.chat.completions.create({
    model: "gpt-4o-mini", temperature: 0.1, response_format: { type: "json_object" },
    messages: [
      { role: "system", content: "你是遗留系统代码分析专家。请用中文输出 JSON。" },
      { role: "user", content: `分析文件 ${filePath}\n函数:\n${funcList || "(无)"}\n\n代码:\n\`\`\`\n${code.slice(0, 6000)}\n\`\`\`\n\n输出: {"summary":"","purpose":"","businessRules":[],"complexity":"low/medium/high","migrationPriority":"high/medium/low","migrationNotes":""}` },
    ],
  });
  return { filePath, ...JSON.parse(response.choices[0].message.content ?? "{}") };
}

export async function generateSystemSummary(analyses: AiFileAnalysis[]): Promise<string> {
  const summaries = analyses.map((a) => `- ${a.filePath.split("/").pop()}: ${a.summary} [${a.migrationPriority}]`).join("\n");
  const allRules = [...new Set(analyses.flatMap((a) => a.businessRules))];
  const resp = await openai.chat.completions.create({
    model: "gpt-4o", temperature: 0.1,
    messages: [
      { role: "system", content: "系统架构分析专家，用中文。" },
      { role: "user", content: `文件摘要:\n${summaries}\n\n业务规则:\n${allRules.map((r) => `- ${r}`).join("\n")}\n\n回答：1.核心业务 2.架构模式 3.迁移路径 4.风险点` },
    ],
  });
  return resp.choices[0].message.content ?? "";
}
```

### 五、分析流水线与 CLI

```typescript
// src/pipeline.ts
import { scanProject } from "./core/scanner";
import { parseFile, FileAstInfo } from "./core/parser";
import { buildDependencyGraph, formatDependencyReport } from "./analyzers/dependency";
import { buildCallGraph, formatCallGraphReport } from "./analyzers/call-graph";
import { analyzeFileWithAi, generateSystemSummary, AiFileAnalysis } from "./analyzers/ai-analyzer";

export async function runPipeline(projectPath: string, enableAi: boolean, aiLimit: number) {
  console.log("\n📁 扫描文件...");
  const files = await scanProject(projectPath);
  const byLang: Record<string, number> = {};
  for (const f of files) byLang[f.language] = (byLang[f.language] ?? 0) + 1;
  console.log(`  ${files.length} 个源文件`);

  console.log("\n🔧 解析 AST...");
  const astInfos = new Map<string, FileAstInfo>();
  let ok = 0, fail = 0;
  for (const file of files) { const info = parseFile(file); if (info) { astInfos.set(file.path, info); ok++; } else fail++; }
  console.log(`  成功 ${ok}, 失败 ${fail}`);

  console.log("\n🔗 依赖分析...");
  const depGraph = buildDependencyGraph(files, astInfos);
  console.log(`  外部依赖 ${depGraph.externalDependencies.size}, 循环 ${depGraph.circularDependencies.length}`);

  console.log("\n📞 调用链路...");
  const callGraph = buildCallGraph(astInfos);
  console.log(`  函数 ${callGraph.nodes.size}, 不可达 ${callGraph.deadCode.length}`);

  let aiAnalyses: AiFileAnalysis[] = [];
  let systemSummary = "";
  if (enableAi) {
    console.log("\n🤖 AI 分析...");
    const toAnalyze = files.slice(0, aiLimit);
    for (let i = 0; i < toAnalyze.length; i += 3) {
      const batch = toAnalyze.slice(i, i + 3);
      const results = await Promise.all(batch.map(async (f) => {
        const ast = astInfos.get(f.path);
        if (!ast) return null;
        try { return await analyzeFileWithAi(f.path, ast); } catch { return null; }
      }));
      aiAnalyses.push(...results.filter(Boolean) as AiFileAnalysis[]);
      console.log(`  ${Math.min(i + 3, toAnalyze.length)} / ${toAnalyze.length}`);
    }
    if (aiAnalyses.length > 0) systemSummary = await generateSystemSummary(aiAnalyses);
  }

  const report = generateReport(projectPath, files.length, depGraph, callGraph, aiAnalyses, systemSummary);
  return { scanResult: { totalFiles: files.length, byLanguage: byLang }, depGraph, callGraph, aiAnalyses, systemSummary, report };
}

function generateReport(projectPath: string, fileCount: number, depGraph: any, callGraph: any, aiAnalyses: AiFileAnalysis[], systemSummary: string): string {
  const s = ["# 遗留代码智能分析报告\n", `> \`${projectPath}\` | ${new Date().toISOString()}\n---\n`];
  s.push("## 项目概览\n| 指标 | 数值 |\n|------|------|");
  s.push(`| 源文件 | ${fileCount} |`, `| 函数 | ${callGraph.nodes.size} |`, `| 外部依赖 | ${depGraph.externalDependencies.size} |`);
  s.push(`| 循环依赖 | ${depGraph.circularDependencies.length} |`, `| 不可达代码 | ${callGraph.deadCode.length} |\n`);
  s.push(formatDependencyReport(depGraph), "\n---\n", formatCallGraphReport(callGraph));

  if (aiAnalyses.length > 0) {
    s.push("\n---\n## AI 语义分析\n");
    const pOrder: Record<string, number> = { high: 0, medium: 1, low: 2 };
    for (const a of [...aiAnalyses].sort((a, b) => (pOrder[a.migrationPriority] ?? 2) - (pOrder[b.migrationPriority] ?? 2))) {
      s.push(`### ${a.filePath.split("/").pop()}\n**功能**: ${a.summary}\n**目的**: ${a.purpose}\n`);
      if (a.businessRules.length) { s.push("**业务规则**:"); a.businessRules.forEach((r) => s.push(`- ${r}`)); }
      s.push(`**优先级**: ${a.migrationPriority} | **复杂度**: ${a.complexity}\n**建议**: ${a.migrationNotes}\n`);
    }
  }
  if (systemSummary) s.push("\n---\n## 系统级分析\n", systemSummary);
  s.push("\n---\n## 迁移建议\n1. 先迁移叶子模块\n2. 再迁移工具函数\n3. 然后业务逻辑层\n4. 最后路由控制器\n5. 清理 Dead Code");
  return s.join("\n");
}
```

## 常见误区

### 误区一：试图一次性分析所有文件

10 万行项目上千文件，全做 AST 和 AI 分析成本很高。**正确做法**：提供 `--ai-limit` 控制范围，先快速扫描再按需深入。

### 误区二：忽略解析失败的文件

真实项目总有语法错误或未知编码的文件。**正确做法**：跳过失败文件，在报告中单独列出。

### 误区三：把 AI 分析当确定性结果

LLM 输出有随机性。**正确做法**：报告中标注"仅供参考，请人工校验"。

### 误区四：不做增量分析

每次改一个文件就重新分析整个项目不可接受。**正确做法**：缓存已分析结果，只重新分析修改过的文件。

### 误区五：输出格式单一

只输出 Markdown，但用户可能想用脚本处理。**正确做法**：同时输出 JSON 格式，便于程序化处理。

## 小结与练习

### 小结

1. `legacy-insight` 整合了前五课全部知识：AST 解析、依赖分析、调用链路、AI 理解

3. **流水线设计**让分析有序进行
4. AI 放最后——先确定性方法，再 AI 语义理解
5. 需处理边界情况：解析失败、大文件、API 限流

### 练习一

**思路**：Python 脚本读取源文件，用 `ast` 模块解析，输出 JSON。Node.js 通过 `execFileSync` 调用。

**答案**：

```python
# scripts/parse_python.py
import ast, json, sys

def parse_file(filepath):
    with open(filepath, "r", encoding="utf-8") as f: source = f.read()
    tree = ast.parse(source, filename=filepath)
    functions, imports, classes = [], [], []
    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            functions.append({"name": node.name, "startLine": node.lineno, "endLine": node.end_lineno or node.lineno, "params": [a.arg for a in node.args.args], "isAsync": isinstance(node, ast.AsyncFunctionDef)})
        elif isinstance(node, ast.Import):
            for alias in node.names: imports.append({"source": alias.name, "specifiers": [alias.asname or alias.name]})
        elif isinstance(node, ast.ImportFrom):
            imports.append({"source": node.module or "", "specifiers": [a.name for a in node.names]})
        elif isinstance(node, ast.ClassDef):
            classes.append({"name": node.name, "methods": [n.name for n in node.body if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef))]})
    return {"filePath": filepath, "functions": functions, "imports": imports, "exports": [], "classes": classes}

if __name__ == "__main__": print(json.dumps(parse_file(sys.argv[1]), ensure_ascii=False))
```

TypeScript 侧：`execFileSync("python3", ["scripts/parse_python.py", filePath])` 获取 JSON 结果。
