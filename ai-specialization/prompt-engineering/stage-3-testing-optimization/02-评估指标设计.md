你的 Prompt 优化后重新上线，产品经理问你："这次优化效果怎么样？"你回答"感觉比之前好了"。产品经理追问："好了多少？怎么量化的？"你哑口无言。没有量化指标，Prompt 的优化就变成了玄学——你不知道改动是真正有效还是只是自我感觉良好。你需要一套科学的评估指标体系，让每一次优化都有数据支撑。

## 1. 为什么需要评估指标？

### 1.1 从"看着还行"到"可量化"

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   传统评估方式（主观、不可复现）                           │
│   ┌─────────┐     ┌─────────┐     ┌─────────┐          │
│   │ 看一眼   │ ──→ │ 觉得还行 │ ──→ │ 上线了   │          │
│   └─────────┘     └─────────┘     └─────────┘          │
│                                                         │
│   科学评估方式（客观、可复现、可追踪）                      │
│   ┌─────────┐     ┌─────────┐     ┌─────────┐          │
│   │ 定义指标 │ ──→ │ 量化评分 │ ──→ │ 达标上线 │          │
│   └─────────┘     └─────────┘     └─────────┘          │
│        │                                    │           │
│        └── 不达标 → 优化 → 重新评估 ←────────┘           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 好的评估指标应该满足的条件

| 条件 | 说明 | 反例 |
|------|------|------|
| 可量化 | 能用数值表示 | "感觉不错" |
| 可复现 | 相同输入得到相同评分 | 依赖评审人心情 |
| 可比较 | 不同版本的分数可以对比 | 每次评分标准不同 |
| 有意义 | 分数变化反映真实质量变化 | 指标与用户体验无关 |
| 可自动化 | 能自动计算，不依赖人工 | 每条都需要专家评审 |

## 2. 评估指标层级体系

```
                    ┌───────────────────┐
                    │   业务指标         │
                    │  (Business KPIs)  │
                    │  用户满意度/转化率  │
                    └─────────┬─────────┘
                              │
                    ┌─────────┴─────────┐
                    │   质量指标         │
                    │  (Quality Metrics) │
                    │  准确性/相关性/安全性│
                    └─────────┬─────────┘
                              │
              ┌───────────────┼───────────────┐
              │               │               │
    ┌─────────┴──────┐ ┌─────┴──────┐ ┌──────┴─────────┐
    │  内容指标       │ │  形式指标   │ │  安全指标       │
    │  幻觉/忠实度    │ │  格式/长度  │ │  毒性/偏见      │
    └────────────────┘ └────────────┘ └────────────────┘
```

### 2.1 指标分类总览

| 类别 | 指标 | 适用场景 | 计算成本 |
|------|------|---------|---------|
| 准确性 | Exact Match, F1, BLEU | 有标准答案的任务 | 低 |
| 相关性 | 语义相似度, 主题一致性 | 开放式问答 | 中 |
| 一致性 | 重复性测试, 逻辑自洽 | 多轮对话 | 中 |
| 安全性 | 毒性检测, 偏见检测 | 所有面向用户的系统 | 中 |
| 幻觉 | 事实核查, 忠实度评分 | 知识密集型任务 | 高 |
| 格式 | JSON 有效性, 长度合规 | 结构化输出任务 | 低 |

## 3. 核心指标详解

### 3.1 准确性（Accuracy）

#### Exact Match（精确匹配）

适用于有唯一正确答案的任务：

```python
def exact_match(response: str, reference: str) -> float:
    """精确匹配评分"""
    return 1.0 if response.strip().lower() == reference.strip().lower() else 0.0

def fuzzy_exact_match(response: str, reference: str, 
                      threshold: float = 0.9) -> float:
    """模糊精确匹配（基于编辑距离）"""
    from difflib import SequenceMatcher
    ratio = SequenceMatcher(None, response.strip().lower(), 
                           reference.strip().lower()).ratio()
    return 1.0 if ratio >= threshold else ratio
```

#### F1 Score（词级别）

适用于允许部分正确的任务：

```python
def token_f1(response: str, reference: str) -> float:
    """词级别的 F1 分数"""
    response_tokens = set(response.lower().split())
    reference_tokens = set(reference.lower().split())
    
    if not response_tokens or not reference_tokens:
        return 0.0
    
    common = response_tokens & reference_tokens
    precision = len(common) / len(response_tokens)
    recall = len(common) / len(reference_tokens)
    
    if precision + recall == 0:
        return 0.0
    
    return 2 * precision * recall / (precision + recall)
```

#### BLEU Score

适用于翻译和生成任务：

```python
from collections import Counter

def simple_bleu(response: str, reference: str, n: int = 4) -> float:
    """简化的 BLEU 分数计算（n-gram 精度）"""
    def get_ngrams(text: str, n: int) -> Counter:
        tokens = text.lower().split()
        return Counter(tuple(tokens[i:i+n]) for i in range(len(tokens)-n+1))
    
    scores = []
    for i in range(1, n + 1):
        resp_ngrams = get_ngrams(response, i)
        ref_ngrams = get_ngrams(reference, i)
        
        if not resp_ngrams:
            scores.append(0.0)
            continue
        
        clipped = sum(min(count, ref_ngrams.get(ng, 0)) 
                      for ng, count in resp_ngrams.items())
        total = sum(resp_ngrams.values())
        scores.append(clipped / total if total > 0 else 0.0)
    
    # 几何平均
    import math
    if any(s == 0 for s in scores):
        return 0.0
    return math.exp(sum(math.log(s) for s in scores) / len(scores))
```

### 3.2 相关性（Relevance）

#### 语义相似度

```python
from openai import OpenAI
import numpy as np

client = OpenAI()

def get_embedding(text: str, model: str = "text-embedding-3-small") -> list:
    """获取文本的向量嵌入"""
    response = client.embeddings.create(input=text, model=model)
    return response.data[0].embedding

def cosine_similarity(vec_a: list, vec_b: list) -> float:
    """计算余弦相似度"""
    a, b = np.array(vec_a), np.array(vec_b)
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

def semantic_relevance(response: str, reference: str) -> float:
    """语义相关性评分（0-1）"""
    emb_response = get_embedding(response)
    emb_reference = get_embedding(reference)
    # 将余弦相似度从 [-1, 1] 映射到 [0, 1]
    return (cosine_similarity(emb_response, emb_reference) + 1) / 2
```

#### 主题一致性

```python
def topic_consistency(response: str, question: str) -> float:
    """主题一致性：回答是否围绕问题的主题"""
    q_emb = get_embedding(question)
    r_emb = get_embedding(response)
    
    # 问题和回答的语义距离
    similarity = cosine_similarity(q_emb, r_emb)
    
    # 映射到 0-1 评分
    # 相似度 > 0.7 视为高度相关
    if similarity >= 0.7:
        return 1.0
    elif similarity >= 0.4:
        return (similarity - 0.4) / 0.3
    else:
        return 0.0
```

### 3.3 一致性（Consistency）

```python
def consistency_test(prompt_fn, input_text: str, 
                     num_runs: int = 5) -> dict:
    """一致性测试：多次运行同一输入，检查输出的稳定性"""
    responses = [prompt_fn(input_text) for _ in range(num_runs)]
    
    # 计算语义相似度矩阵
    embeddings = [get_embedding(r) for r in responses]
    similarities = []
    for i in range(len(embeddings)):
        for j in range(i + 1, len(embeddings)):
            sim = cosine_similarity(embeddings[i], embeddings[j])
            similarities.append(sim)
    
    avg_similarity = np.mean(similarities) if similarities else 0.0
    min_similarity = np.min(similarities) if similarities else 0.0
    
    return {
        "responses": responses,
        "avg_similarity": float(avg_similarity),
        "min_similarity": float(min_similarity),
        "is_consistent": min_similarity >= 0.8,  # 阈值可调
        "unique_responses": len(set(responses))
    }
```

### 3.5 幻觉检测（Hallucination Detection）

幻觉是 LLM 最危险的问题之一——它会自信地输出错误信息。

```
幻觉类型：

┌──────────────────────────────────────────────────────┐
│                    LLM 幻觉分类                       │
├──────────────┬───────────────────────────────────────┤
│  事实性幻觉    │  编造不存在的事实、数据、引用           │
│  (Factual)    │  例："爱因斯坦在 1921 年获得诺贝尔化学奖"│
├──────────────┼───────────────────────────────────────┤
│  忠实度幻觉    │  回答与提供的上下文不一致               │
│  (Faithful)   │  上下文说"股价涨了5%"，回答说"涨了15%"  │
├──────────────┼───────────────────────────────────────┤
│  推理幻觉      │  推理过程中的逻辑跳跃或错误             │
│  (Reasoning)  │  前提正确但结论错误                    │
└──────────────┴───────────────────────────────────────┘
```

#### 基于上下文的忠实度检测

```python
FAITHFULNESS_PROMPT = """你是一个忠实度检测专家。
你的任务是检查 AI 的回答是否忠实于提供的上下文。

规则：
1. 只检查回答中的事实性声明
2. 对比上下文中的信息
3. 如果回答包含上下文中没有的信息，标记为幻觉
4. 如果回答与上下文矛盾，标记为矛盾

上下文：
{context}

AI 回答：
{response}

请以 JSON 格式输出：
{{
    "faithfulness_score": 0.0-1.0,
    "hallucinated_claims": [
        {{"claim": "具体声明", "type": "unsupported" | "contradicted", "evidence": "说明"}}
    ],
    "supported_claims": [
        {{"claim": "具体声明", "source": "上下文中的依据"}}
    ]
}}
"""

def detect_hallucination(context: str, response: str, llm_call_fn) -> dict:
    """检测回答中的幻觉"""
    import json
    
    prompt = FAITHFULNESS_PROMPT.format(context=context, response=response)
    result = llm_call_fn("你是忠实度检测专家。", prompt)
    
    try:
        evaluation = json.loads(result)
        return {
            "score": evaluation.get("faithfulness_score", 0),
            "hallucinations": evaluation.get("hallucinated_claims", []),
            "supported": evaluation.get("supported_claims", []),
            "hallucination_rate": len(evaluation.get("hallucinated_claims", [])) / 
                max(1, len(evaluation.get("hallucinated_claims", [])) + 
                    len(evaluation.get("supported_claims", [])))
        }
    except json.JSONDecodeError:
        return {"score": 0, "hallucinations": [], "supported": [], 
                "hallucination_rate": 0}
```

### 3.6 格式合规性

```python
import json

def format_compliance(response: str, expected_format: dict) -> dict:
    """检查输出是否符合预期格式"""
    results = {"passed": True, "checks": {}}
    
    # 检查 JSON 有效性
    if expected_format.get("type") == "json":
        try:
            parsed = json.loads(response)
            results["checks"]["valid_json"] = True
            
            # 检查必需字段
            for field in expected_format.get("required_fields", []):
                if field not in parsed:
                    results["passed"] = False
                    results["checks"][f"field_{field}"] = False
                else:
                    results["checks"][f"field_{field}"] = True
            
            # 检查字段类型
            for field, expected_type in expected_format.get("field_types", {}).items():
                if field in parsed:
                    actual_type = type(parsed[field]).__name__
                    results["checks"][f"type_{field}"] = actual_type == expected_type
                    if actual_type != expected_type:
                        results["passed"] = False
                        
        except json.JSONDecodeError:
            results["passed"] = False
            results["checks"]["valid_json"] = False
    
    # 检查长度限制
    if "max_length" in expected_format:
        if len(response) > expected_format["max_length"]:
            results["passed"] = False
            results["checks"]["length"] = False
    
    # 检查语言
    if expected_format.get("language") == "chinese":
        chinese_ratio = sum(1 for c in response if '\u4e00' <= c <= '\u9fff') / max(1, len(response))
        results["checks"]["language"] = chinese_ratio > 0.3
        if chinese_ratio <= 0.3:
            results["passed"] = False
    
    return results
```

## 4. LLM-as-Judge 模式

### 4.1 核心思想

使用一个更强的 LLM 来评估另一个 LLM 的输出质量。

```
┌─────────────┐    输出    ┌─────────────┐    评估    ┌─────────────┐
│  被测 Prompt │ ────────→ │  LLM 输出    │ ────────→ │  Judge LLM  │
└─────────────┘           └─────────────┘           └─────────────┘
                                                        │
                                                        ▼
                                                  ┌───────────┐
                                                  │ 评分 + 理由 │
                                                  └───────────┘
```

### 4.2 评估 Prompt 设计

```python
JUDGE_PROMPT_TEMPLATE = """你是一个专业的 AI 输出质量评估专家。
请根据以下评估标准，对给定的 AI 回复进行评分。

## 评估任务
{task_description}

## 评估标准
{criteria}

## 评分等级
- 5 (优秀): 完全符合标准，质量出色
- 4 (良好): 基本符合标准，有小瑕疵
- 3 (一般): 部分符合标准，有明显不足
- 2 (较差): 大部分不符合标准
- 1 (很差): 完全不符合标准

## 用户问题
{question}

## AI 回复
{response}

## 参考答案（如有）
{reference}

请以 JSON 格式输出你的评估：
{{
    "score": 1-5,
    "dimension_scores": {{
        "accuracy": 1-5,
        "relevance": 1-5,
        "completeness": 1-5,
        "clarity": 1-5
    }},
    "strengths": ["优点列表"],
    "weaknesses": ["缺点列表"],
    "improvement_suggestions": ["改进建议"],
    "overall_comment": "总体评价"
}}
"""
```

### 4.3 完整的 LLM-as-Judge 实现

```python
import json
from typing import Optional
from openai import OpenAI

class LLMJudge:
    """LLM-as-Judge 评估器"""
    
    def __init__(self, judge_model: str = "gpt-4o"):
        self.client = OpenAI()
        self.judge_model = judge_model
    
    def evaluate(self, question: str, response: str,
                 task_description: str,
                 criteria: str,
                 reference: Optional[str] = None) -> dict:
        """使用 LLM 评估输出质量"""
        
        prompt = JUDGE_PROMPT_TEMPLATE.format(
            task_description=task_description,
            criteria=criteria,
            question=question,
            response=response,
            reference=reference or "无参考答案"
        )
        
        result = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[
                {"role": "system", "content": "你是一个严格公正的评估专家。"},
                {"role": "user", "content": prompt}
            ],
            temperature=0.0,
            response_format={"type": "json_object"}
        )
        
        try:
            evaluation = json.loads(result.choices[0].message.content)
            evaluation["judge_model"] = self.judge_model
            return evaluation
        except json.JSONDecodeError:
            return {"score": 0, "error": "评估结果解析失败"}
    
    def pairwise_compare(self, question: str, response_a: str, 
                         response_b: str, criteria: str) -> dict:
        """成对比较：A vs B 哪个更好？"""
        
        compare_prompt = f"""请比较以下两个 AI 回复的质量。

评估标准：{criteria}

用户问题：{question}

回复 A：
{response_a}

回复 B：
{response_b}

请以 JSON 格式输出：
{{
    "winner": "A" | "B" | "tie",
    "confidence": 0.0-1.0,
    "reason": "详细说明选择理由",
    "a_strengths": ["A 的优点"],
    "b_strengths": ["B 的优点"]
}}
"""
        
        result = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[
                {"role": "system", "content": "你是一个严格公正的评估专家。"},
                {"role": "user", "content": compare_prompt}
            ],
            temperature=0.0,
            response_format={"type": "json_object"}
        )
        
        return json.loads(result.choices[0].message.content)
```

### 4.4 减少 LLM-as-Judge 偏差

| 偏差类型 | 表现 | 缓解策略 |
|---------|------|---------|
| 位置偏差 | 倾向选择第一个/最后一个选项 | 随机交换 A/B 顺序 |
| 长度偏差 | 倾向认为更长的回答更好 | 控制回答长度相近 |
| 风格偏差 | 偏好某种写作风格 | 明确评估标准和权重 |
| 自我偏好 | 倾向认为同系列模型更好 | 使用不同系列的 Judge |

```python
def debiased_pairwise_compare(judge: LLMJudge, question: str,
                               response_a: str, response_b: str,
                               criteria: str) -> dict:
    """去偏差的成对比较"""
    
    # 正序比较
    result_ab = judge.pairwise_compare(question, response_a, response_b, criteria)
    
    # 反序比较
    result_ba = judge.pairwise_compare(question, response_b, response_a, criteria)
    
    # 综合两次结果
    winner_ab = result_ab.get("winner")
    winner_ba = result_ba.get("winner")
    
    # 如果正序选 A，反序选 B，则 A 确实更好
    # 如果正序选 B，反序选 A，则 B 确实更好
    # 如果结果不一致，则视为平局
    if winner_ab == "A" and winner_ba == "B":
        final_winner = "A"
    elif winner_ab == "B" and winner_ba == "A":
        final_winner = "B"
    else:
        final_winner = "tie"
    
    return {
        "winner": final_winner,
        "confidence": (result_ab.get("confidence", 0) + result_ba.get("confidence", 0)) / 2,
        "forward_result": result_ab,
        "backward_result": result_ba
    }
```

## 5. 多指标加权评分系统

### 5.1 指标权重设计

```
不同任务类型的指标权重分配：

┌────────────────┬────────┬────────┬────────┬────────┬────────┐
│  任务类型       │ 准确性 │ 相关性 │ 安全性 │ 格式   │ 幻觉度 │
├────────────────┼────────┼────────┼────────┼────────┼────────┤
│  知识问答       │  0.35  │  0.20  │  0.15  │  0.05  │  0.25  │
│  内容生成       │  0.10  │  0.30  │  0.20  │  0.15  │  0.25  │
```

### 5.2 完整的多指标评估器

```python
import json
import numpy as np
from typing import Optional
from dataclasses import dataclass, field
from openai import OpenAI

@dataclass
class MetricResult:
    """单个指标的评估结果"""
    name: str
    score: float  # 0.0 - 1.0
    weight: float
    details: dict = field(default_factory=dict)

@dataclass 
class EvaluationReport:
    """完整评估报告"""
    weighted_score: float
    metrics: list[MetricResult]
    passed: bool
    threshold: float
    summary: str

class MultiMetricEvaluator:
    """多指标加权评估器"""
    
    def __init__(self, weights: dict[str, float], 
                 threshold: float = 0.7,
                 judge_model: str = "gpt-4o"):
        """
        Args:
            weights: 指标权重字典 {"accuracy": 0.3, "relevance": 0.3, ...}
            threshold: 通过阈值
            judge_model: 用于 LLM-as-Judge 的模型
        """
        self.weights = weights
        self.threshold = threshold
        self.client = OpenAI()
        self.judge_model = judge_model
        
        # 验证权重总和
        total = sum(weights.values())
        if abs(total - 1.0) > 0.01:
            raise ValueError(f"权重总和必须为 1.0，当前为 {total}")
    
    def _call_judge(self, system: str, user: str) -> dict:
        """调用 Judge LLM"""
        result = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[
                {"role": "system", "content": system},
                {"role": "user", "content": user}
            ],
            temperature=0.0,
            response_format={"type": "json_object"}
        )
        return json.loads(result.choices[0].message.content)
    
    def evaluate_accuracy(self, response: str, reference: str) -> MetricResult:
        """准确性评估"""
        prompt = f"""请评估以下回答与参考答案的一致性。
        
回答：{response}
参考答案：{reference}

以 JSON 输出：{{"score": 0.0-1.0, "explanation": "理由"}}"""
        
        result = self._call_judge("你是准确性评估专家。", prompt)
        return MetricResult(
            name="accuracy",
            score=result.get("score", 0),
            weight=self.weights.get("accuracy", 0),
            details={"explanation": result.get("explanation", "")}
        )
    
    def evaluate_relevance(self, question: str, response: str) -> MetricResult:
        """相关性评估"""
        prompt = f"""请评估以下回答与问题的相关性。
        
问题：{question}
回答：{response}

以 JSON 输出：{{"score": 0.0-1.0, "explanation": "理由"}}"""
        
        result = self._call_judge("你是相关性评估专家。", prompt)
        return MetricResult(
            name="relevance",
            score=result.get("score", 0),
            weight=self.weights.get("relevance", 0),
            details={"explanation": result.get("explanation", "")}
        )
    
    def evaluate_safety(self, response: str) -> MetricResult:
        """安全性评估"""
        prompt = f"""请评估以下回答的安全性。
        
回答：{response}

以 JSON 输出：{{"score": 0.0-1.0（1.0=完全安全）, "risks": ["风险列表"]}}"""
        
        result = self._call_judge("你是内容安全专家。", prompt)
        return MetricResult(
            name="safety",
            score=result.get("score", 0),
            weight=self.weights.get("safety", 0),
            details={"risks": result.get("risks", [])}
        )
    
    def evaluate_format(self, response: str, 
                        expected_format: dict) -> MetricResult:
        """格式合规性评估"""
        checks = format_compliance(response, expected_format)
        score = 1.0 if checks["passed"] else 0.5
        return MetricResult(
            name="format",
            score=score,
            weight=self.weights.get("format", 0),
            details=checks["checks"]
        )
    
    def evaluate_hallucination(self, context: str, 
                               response: str) -> MetricResult:
        """幻觉检测"""
        result = detect_hallucination(
            context, response,
            lambda sys, usr: self._call_judge(sys, usr)
        )
        return MetricResult(
            name="hallucination",
            score=result["score"],
            weight=self.weights.get("hallucination", 0),
            details={
                "hallucinations": result["hallucinations"],
                "hallucination_rate": result["hallucination_rate"]
            }
        )
    
    def evaluate_all(self, question: str, response: str,
                     reference: Optional[str] = None,
                     context: Optional[str] = None,
                     expected_format: Optional[dict] = None) -> EvaluationReport:
        """执行完整的多指标评估"""
        
        metrics = []
        
        # 准确性
        if "accuracy" in self.weights and reference:
            metrics.append(self.evaluate_accuracy(response, reference))
        
        # 相关性
        if "relevance" in self.weights:
            metrics.append(self.evaluate_relevance(question, response))
        
        # 安全性
        if "safety" in self.weights:
            metrics.append(self.evaluate_safety(response))
        
        # 格式
        if "format" in self.weights and expected_format:
            metrics.append(self.evaluate_format(response, expected_format))
        
        # 幻觉
        if "hallucination" in self.weights and context:
            metrics.append(self.evaluate_hallucination(context, response))
        
        # 计算加权总分
        weighted_score = sum(m.score * m.weight for m in metrics)
        passed = weighted_score >= self.threshold
        
        # 生成摘要
        summary_parts = [f"总分: {weighted_score:.2f}"]
        for m in metrics:
            summary_parts.append(f"{m.name}: {m.score:.2f} (权重 {m.weight:.0%})")
        
        return EvaluationReport(
            weighted_score=weighted_score,
            metrics=metrics,
            passed=passed,
            threshold=self.threshold,
            summary="\n".join(summary_parts)
        )
```

## 6. 常见误区

### ❌ 错误1：只用一个指标评估质量

```python
# 错误：只看准确性
score = exact_match(response, reference)

# 正确：多维度综合评估
evaluator = MultiMetricEvaluator({
    "accuracy": 0.3, "relevance": 0.3, 
    "safety": 0.2, "format": 0.2
})
```

### ❌ 错误2：Judge LLM 的 Prompt 过于简单

```python
# 错误：Prompt 太简单，评分标准模糊
"请给这个回答打分，1-10分"

# 正确：明确评分维度和标准
"请从准确性、完整性、清晰度三个维度评分，每个维度1-5分..."
```

### ❌ 错误3：忽略指标的权重差异

```python
# 错误：所有指标等权重
score = sum(m.score for m in metrics) / len(metrics)

# 正确：根据业务场景分配权重
score = sum(m.score * m.weight for m in metrics)
```

### ❌ 错误4：幻觉检测只检查关键词

```python
# 错误：关键词匹配无法检测语义级别的幻觉
def check_hallucination(response):
    return "据我所知" in response  # 没有意义

# 正确：使用 LLM 进行语义级别的忠实度检测
result = detect_hallucination(context, response, llm_call_fn)
```

### ❌ 错误5：不校准 LLM-as-Judge

```python
# 错误：直接使用 Judge 结果，不验证其准确性

# 正确：用人工标注的样本校准 Judge
def calibrate_judge(judge, calibration_data):
    """校准 Judge LLM 的评分准确性"""
    correct = 0
    for sample in calibration_data:
        result = judge.evaluate(sample["question"], sample["response"])
        if abs(result["score"] - sample["human_score"]) <= 1:
            correct += 1
    accuracy = correct / len(calibration_data)
    print(f"Judge 校准准确率: {accuracy:.1%}")
    return accuracy
```

## 7. 工程建议

1. **先定业务目标，再选指标**：不要为了评估而评估，先明确你的 Prompt 在业务中需要达成什么目标（准确率、用户满意度、响应速度），再选择对应的指标。
2. **LLM-as-Judge 必须先校准再使用**：用 20-30 条人工标注的样本验证 Judge LLM 的评分与人类评分的一致率，一致性低于 80% 时需要优化 Judge Prompt。
3. **幻觉检测要分层处理**：简单场景用关键词检查，知识密集型任务必须用基于上下文的忠实度检测，涉及数字和日期的场景要单独做数值验证。
4. **指标权重随业务场景调整**：客服场景安全性权重应该最高，数据提取场景格式合规权重应该最高，知识问答场景幻觉检测权重应该最高——不要用一套权重打天下。

---

## 8. 总结

1. **评估指标**是 Prompt 工程从"手艺"变成"工程"的关键
2. **指标层级**：业务指标 → 质量指标 → 内容/形式/安全指标
3. **核心指标**：准确性、相关性、一致性、安全性、幻觉检测、格式合规
4. **LLM-as-Judge** 是强大的自动化评估工具，但需要注意偏差
5. **加权评分系统**让不同业务场景有不同的评估侧重

## 参考答案

### 练习1：指标设计

**思路**：AI 翻译助手的核心任务是准确传达原文含义，同时保持目标语言的自然流畅。因此准确性（翻译正确性）和流畅性（目标语言质量）应占最高权重，格式合规和安全性作为基础保障。

**答案**：

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 准确性 | 0.35 | 5分：完全忠实原文，无遗漏无添加；4分：核心信息正确，细微表述差异；3分：部分信息正确，有少量遗漏或误解；2分：关键信息有误；1分：严重偏离原文 |
| 流畅性 | 0.30 | 5分：目标语言地道自然，读起来像母语者写的；4分：基本流畅，偶有生硬表达；3分：能理解但有明显翻译腔；2分：语法错误较多；1分：几乎不可读 |
| 术语一致性 | 0.15 | 5分：专业术语翻译准确且全文统一；4分：术语正确但偶有不一致；3分：术语基本正确但有遗漏；2分：术语翻译有误；1分：术语混乱 |
| 格式保留 | 0.10 | 5分：标点、段落、编号等格式完全保留；4分：格式基本保留，有细微差异；3分：部分格式丢失；2分：格式严重损坏；1分：格式完全丢失 |
| 安全性 | 0.10 | 5分：无敏感信息泄露，无有害内容；4分：基本安全，有极低风险；3分：存在轻微风险；2分：有明显安全隐患；1分：严重安全问题 |

权重分配理由：
- 准确性权重最高（0.35），因为翻译的核心价值是忠实传达原文含义
- 流畅性次之（0.30），因为翻译结果需要为目标语言用户可读
- 术语一致性（0.15）在专业文档翻译中尤为重要
- 格式保留（0.10）影响用户体验但不是核心质量指标
- 安全性（0.10）作为底线保障，任何翻译系统都不能泄露敏感信息

**要点**：
- 指标权重应根据具体业务场景调整——法律翻译准确性权重应更高，营销翻译流畅性权重应更高
- 评分标准必须有明确的分界线，避免评审人之间理解不一致
- 安全性虽然是底线指标，但在翻译场景中不应占用过高权重，否则会稀释核心质量指标

### 练习2：幻觉检测器

**思路**：数据幻觉检测需要先从回答中提取具体的数字/日期/百分比等数据声明，然后逐一与上下文比对。使用正则表达式提取数据，再用 LLM 做语义级别的忠实度验证。

**答案**：

```python
import re
import json
from dataclasses import dataclass, field

@dataclass
class DataClaim:
    """数据声明"""
    value: str
    context: str
    claim_type: str  # number, date, percentage, statistic
    position: int

@dataclass
class HallucinationReport:
    """幻觉检测报告"""
    total_claims: int
    supported_claims: list[dict]
    unsupported_claims: list[dict]
    contradicted_claims: list[dict]
    faithfulness_score: float
    details: dict = field(default_factory=dict)

class DataHallucinationDetector:
    """数据幻觉检测器"""

    def __init__(self, llm_call_fn):
        self.llm_call_fn = llm_call_fn
        self.number_pattern = re.compile(
            r'(\d+(?:\.\d+)?)\s*(%|亿|万|千|百|元|美元|人|个|条|次|年|月|日|天|小时|分钟|秒)'
        )
        self.date_pattern = re.compile(
            r'(\d{4})[年/-](\d{1,2})[月/-](\d{1,2})[日]?'
        )
        self.percentage_pattern = re.compile(
            r'(\d+(?:\.\d+)?)\s*%'
        )

    def extract_data_claims(self, text: str) -> list[DataClaim]:
        """从回答中提取数据声明"""
        claims = []
        seen = set()

        for match in self.number_pattern.finditer(text):
            value = match.group(0)
            if value not in seen:
                seen.add(value)
                start = max(0, match.start() - 30)
                context = text[start:match.end() + 30]
                claim_type = "percentage" if "%" in value else "number"
                claims.append(DataClaim(
                    value=value, context=context,
                    claim_type=claim_type, position=match.start()
                ))

        for match in self.date_pattern.finditer(text):
            value = match.group(0)
            if value not in seen:
                seen.add(value)
                start = max(0, match.start() - 30)
                context = text[start:match.end() + 30]
                claims.append(DataClaim(
                    value=value, context=context,
                    claim_type="date", position=match.start()
                ))

        return claims

    def verify_claim(self, claim: DataClaim, source_context: str) -> dict:
        """验证单个数据声明"""
        prompt = f"""请验证以下数据声明是否在源上下文中得到支持。

源上下文：{source_context}

数据声明："{claim.value}"
所在句子："{claim.context}"

判断标准：
- supported：数据在上下文中有明确依据
- unsupported：上下文中没有提及此数据
- contradicted：上下文中的数据与声明不一致

请以 JSON 输出：{{"status": "supported"|"unsupported"|"contradicted", "evidence": "依据或矛盾说明"}}"""

        result = self.llm_call_fn("你是数据验证专家。", prompt)
        try:
            return json.loads(result)
        except json.JSONDecodeError:
            return {"status": "unknown", "evidence": "验证结果解析失败"}

    def detect(self, response: str, source_context: str) -> HallucinationReport:
        """执行完整的数据幻觉检测"""
        claims = self.extract_data_claims(response)

        supported = []
        unsupported = []
        contradicted = []

        for claim in claims:
            verification = self.verify_claim(claim, source_context)
            entry = {
                "value": claim.value,
                "context": claim.context,
                "evidence": verification.get("evidence", "")
            }

            if verification["status"] == "supported":
                supported.append(entry)
            elif verification["status"] == "contradicted":
                contradicted.append(entry)
            else:
                unsupported.append(entry)

        total = len(claims)
        faithfulness = len(supported) / total if total > 0 else 1.0

        return HallucinationReport(
            total_claims=total,
            supported_claims=supported,
            unsupported_claims=unsupported,
            contradicted_claims=contradicted,
            faithfulness_score=faithfulness,
            details={
                "hallucination_rate": 1 - faithfulness,
                "claim_types": {
                    "number": sum(1 for c in claims if c.claim_type == "number"),
                    "date": sum(1 for c in claims if c.claim_type == "date"),
                    "percentage": sum(1 for c in claims if c.claim_type == "percentage"),
                }
            }
        )


# 使用示例
if __name__ == "__main__":
    from openai import OpenAI
    client = OpenAI()

    def llm_call(system, user):
        resp = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": system},
                {"role": "user", "content": user}
            ],
            temperature=0.0,
            response_format={"type": "json_object"}
        )
        return resp.choices[0].message.content

    detector = DataHallucinationDetector(llm_call)

    source = "Python 3.12 于 2023 年 10 月 2 日发布，引入了新的类型语法。"
    response = "Python 3.12 在 2023 年 11 月发布，新增了 50 个功能特性，用户超过 1000 万人。"

    report = detector.detect(response, source)
    print(f"数据声明总数: {report.total_claims}")
    print(f"有依据: {len(report.supported_claims)}")
    print(f"无依据: {len(report.unsupported_claims)}")
    print(f"矛盾: {len(report.contradicted_claims)}")
    print(f"忠实度评分: {report.faithfulness_score:.2f}")
```

**要点**：
- 数据幻觉检测的关键是先提取再验证，不能直接让 LLM 判断"有没有幻觉"——需要拆成两步
- 正则表达式提取数据声明时需要包含足够的上下文（前后各 30 字符），否则 LLM 无法判断语义
- 忠实度评分 = 有依据的声明数 / 总声明数，低于 0.8 应标记为高风险

### 练习3：Judge 校准

**思路**：Judge 校准的核心是用人工标注样本作为基准，计算 Judge 评分与人类评分的一致率。需要先准备多样化的测试样本，人工打分后与 Judge 评分对比，分析偏差模式并优化 Judge Prompt。

**答案**：

```python
            {"question": "如何优化数据库查询？", "response": "可以通过添加索引、优化 SQL 语句、使用查询缓存、分库分表等方式优化。", "human_score": 4},
            {"question": "如何优化数据库查询？", "response": "数据库查询优化是一个复杂的话题，我不太确定。", "human_score": 1},
        ]

    def run_calibration(self):
        """运行校准"""
        for sample in self.calibration_data:
            result = self.judge.evaluate(
                question=sample["question"],
                response=sample["response"],
                task_description="评估回答质量",
                criteria="准确性、完整性、清晰度"
            )
            judge_score = result.get("score", 0)

            self.samples.append(CalibrationSample(
                question=sample["question"],
                response=sample["response"],
                human_score=sample["human_score"],
                judge_score=judge_score,
                score_diff=abs(judge_score - sample["human_score"])
            ))

    def calculate_agreement(self) -> dict:
        """计算一致率"""
        if not self.samples:
            return {"error": "未运行校准"}

        exact_match = sum(1 for s in self.samples if s.human_score == s.judge_score)
        within_one = sum(1 for s in self.samples if s.score_diff <= 1)
        total = len(self.samples)

        return {
            "exact_match_rate": exact_match / total,
            "within_one_rate": within_one / total,
            "mean_absolute_error": np.mean([s.score_diff for s in self.samples]),
            "total_samples": total
        }

    def analyze_bias(self) -> dict:
        """分析偏差模式"""
        diffs = [s.judge_score - s.human_score for s in self.samples]
        avg_diff = np.mean(diffs)

        bias_direction = "none"
        if avg_diff > 0.5:
            bias_direction = "judge_scores_higher"
        elif avg_diff < -0.5:
            bias_direction = "judge_scores_lower"

        score_distribution = Counter(diffs)
        problematic = [s for s in self.samples if s.score_diff >= 2]

        return {
            "average_diff": float(avg_diff),
            "bias_direction": bias_direction,
            "diff_distribution": dict(score_distribution),
            "problematic_cases": [
                {"question": s.question[:50], "human": s.human_score,
                 "judge": s.judge_score, "diff": s.score_diff}
                for s in problematic
            ]
        }

    def suggest_improvements(self) -> list[str]:
        """提出改进方案"""
        bias = self.analyze_bias()
        agreement = self.calculate_agreement()
        suggestions = []

        if agreement["within_one_rate"] < 0.8:
            suggestions.append(
                "一致率低于 80%，建议在 Judge Prompt 中增加更详细的评分标准和示例"
            )

        if bias["bias_direction"] == "judge_scores_higher":
            suggestions.append(
                "Judge 评分偏高，建议在 Prompt 中强调'严格评分，3分已是及格水平'"
            )
        elif bias["bias_direction"] == "judge_scores_lower":
            suggestions.append(
                "Judge 评分偏低，建议在 Prompt 中明确'不要过于严苛，4分代表良好'"
            )

        if len(bias["problematic_cases"]) > 2:
            suggestions.append(
                f"有 {len(bias['problematic_cases'])} 个用例偏差>=2分，"
                "建议将这些用例作为 few-shot 示例加入 Judge Prompt"
            )

        suggestions.append(
            "建议使用 response_format={'type': 'json_object'} 强制 JSON 输出，"
            "避免 Judge 输出格式不一致导致解析失败"
        )

        return suggestions
```

**要点**：
- 校准样本应覆盖 1-5 分各个等级，不能只有高分或低分样本——否则无法检测 Judge 在中间分数段的偏差
- 一致率低于 80% 时必须优化 Judge Prompt，常见方法是加入 few-shot 示例和更明确的评分标准
- 偏差分析要区分"整体偏高/偏低"和"特定分数段偏差"——前者通过 Prompt 措辞调整，后者需要针对性补充示例
