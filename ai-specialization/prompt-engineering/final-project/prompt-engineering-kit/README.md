# Prompt Engineering Toolkit

一个完整的 Prompt Engineering 工具包，整合模板管理、测试评估、优化分析和生产监控。

## 快速开始

```bash
pip install -r requirements.txt
python scripts/check.py
```

## 模块说明

- **template_engine** — Prompt 模板解析、渲染与变量管理
- **testing** — 测试用例运行、自动评分与报告生成
- **optimizer** — Prompt 质量分析与优化建议
- **monitor** — 运行追踪、告警与监控仪表盘
