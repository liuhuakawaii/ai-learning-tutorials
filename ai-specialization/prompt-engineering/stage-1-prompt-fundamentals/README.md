# Stage 1：Prompt 基础 — 写出能用的提示词

> 掌握 Prompt 的基本构成要素，理解 LLM 的工作方式，学会写出清晰、有效的基础提示词。

## 学习目标

完成本阶段后，你将能够：

- 理解 LLM 如何处理 Token 和生成文本
- 写出包含角色、任务、格式、约束四要素的完整 Prompt
- 使用系统提示词控制模型的行为和风格
- 设计清晰的输入输出格式，减少歧义
- 识别和调试常见的 Prompt 问题
