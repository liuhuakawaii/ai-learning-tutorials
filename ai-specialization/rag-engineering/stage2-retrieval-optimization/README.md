## 关键概念速查

| 概念 | 一句话解释 |
|------|-----------|
| BM25 | 经典关键词检索算法，基于词频和逆文档频率 |
| 向量检索 | 将文本编码为稠密向量，通过余弦相似度匹配 |
| RRF | Reciprocal Rank Fusion，多路检索结果的排名融合算法 |
| Cross-Encoder | 将 query 和 document 拼接后联合编码，精度高但慢 |
| Bi-Encoder | query 和 document 分别编码，速度快但精度略低 |
| HyDE | 先让 LLM 生成假设性回答，再用回答做检索 |
| Multi-Query | 将用户问题改写为多个变体，分别检索后合并 |
| NDCG | 归一化折损累积增益，考虑排序位置的评估指标 |
