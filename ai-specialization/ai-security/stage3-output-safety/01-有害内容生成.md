# 01 - 有害内容生成

> 从一次内容安全事件出发，理解有害内容的风险分类与防御策略

## 一次事故的复盘

某社交平台的 AI 客服在回答退货问题时，被诱导输出了暴力威胁回复。截图在社交媒体传播，股价当日下跌 3%。事后复盘：系统只做了关键词黑名单过滤，攻击者用 Unicode 变体字符替换字母就绕过了检测。

## 有害内容的四个维度

**违法违规**：暴恐、毒品赌博、色情——法律红线，零容忍。

**伦理道德**：歧视偏见、仇恨言论、自残内容——不一定违法，但会造成社会危害。

**虚假信息**：编造新闻、错误医疗建议、阴谋论——LLM 幻觉让这类风险特别突出。

**侵权内容**：版权侵犯、隐私泄露、肖像侵权。

## 检测方法一：规则引擎

```python
import re
from typing import List, Tuple
from enum import Enum

class ContentRisk(Enum):
    SAFE = 0; LOW = 1; MEDIUM = 2; HIGH = 3; CRITICAL = 4

class RuleBasedFilter:
    def __init__(self):
        self.keywords = {
            "violence": ["杀人", "炸弹", "枪支", "爆炸"],
            "hate_speech": ["种族歧视", "性别歧视"],
            "illegal": ["毒品", "赌博", "诈骗"],
            "self_harm": ["自杀", "自残"],
        }
        self.patterns = [
            (r"(?:如何|怎么).*(?:制作|制造).*(?:炸弹|武器|毒品)", "illegal", ContentRisk.CRITICAL),
            (r"(?:我想|我要).*(?:自杀|自残)", "self_harm", ContentRisk.HIGH),
        ]

    def check(self, text: str) -> Tuple[ContentRisk, List[dict]]:
        findings = []
        max_risk = ContentRisk.SAFE
        for cat, kws in self.keywords.items():
            for kw in kws:
                if kw in text:
                    findings.append({"category": cat, "keyword": kw})
                    max_risk = max(max_risk, ContentRisk.MEDIUM, key=lambda x: x.value)
        for pattern, cat, risk in self.patterns:
            if re.search(pattern, text, re.I):
                findings.append({"category": cat, "pattern": pattern})
                max_risk = max(max_risk, risk, key=lambda x: x.value)
        return max_risk, findings

    def normalize_unicode(self, text: str) -> str:
        import unicodedata
        text = unicodedata.normalize("NFKC", text)
        return re.sub(r'[\u200b\u200c\u200d\ufeff]', '', text)
```

规则引擎的弱点：同义词替换、隐喻表达、多语言混合都能绕过。

## 检测方法二：语义分类器

```python
class SemanticClassifier:
    """基于预训练模型的内容分类（实际项目中加载真实模型）"""

    def classify(self, text: str) -> dict:
        # 实际: from transformers import pipeline
        # classifier = pipeline("text-classification", model="unitary/toxic-bert")
        toxic_indicators = ["暴力", "色情", "歧视", "自杀", "毒品"]
        score = sum(1 for kw in toxic_indicators if kw in text) / len(toxic_indicators)
        return {"is_toxic": score > 0.3, "score": score}
```

## 审核 Pipeline：三层决策

```python
from dataclasses import dataclass
from datetime import datetime

@dataclass
class ReviewResult:
    action: str       # allow | reject | flag
    risk_level: str
    categories: List[str]
    reason: str
    filtered_content: str

class ContentModerationPipeline:
    def __init__(self):
        self.rule_filter = RuleBasedFilter()
        self.semantic = SemanticClassifier()
        self.review_queue: List[dict] = []
        self.stats = {"total": 0, "allowed": 0, "rejected": 0, "flagged": 0}

    def review(self, content: str) -> ReviewResult:
        self.stats["total"] += 1

        # 第一层：规则引擎
        rule_risk, rule_findings = self.rule_filter.check(content)
        # Unicode 归一化后再检测
        normalized = self.rule_filter.normalize_unicode(content)
        if normalized != content:
            norm_risk, norm_findings = self.rule_filter.check(normalized)
            if norm_risk.value > rule_risk.value:
                rule_risk, rule_findings = norm_risk, norm_findings

        if rule_risk.value >= ContentRisk.HIGH.value:
            self.stats["rejected"] += 1
            return ReviewResult("reject", rule_risk.name,
                [f["category"] for f in rule_findings], "规则引擎拦截", "内容违规")

        # 第二层：语义分类
        sem = self.semantic.classify(content)
        if sem["is_toxic"] and sem["score"] > 0.7:
            self.stats["rejected"] += 1
            return ReviewResult("reject", "HIGH", [], "语义分类器拦截", "内容有害")

        # 第三层：中等风险进人工队列
        if rule_risk.value >= ContentRisk.MEDIUM.value or sem["is_toxic"]:
            self.stats["flagged"] += 1
            self.review_queue.append({"content": content, "risk": rule_risk.name,
                                       "time": datetime.now().isoformat()})
            return ReviewResult("flag", rule_risk.name,
                [f["category"] for f in rule_findings], "需人工审核", content)

        self.stats["allowed"] += 1
        return ReviewResult("allow", "SAFE", [], "通过", content)


# 测试
pipeline = ContentModerationPipeline()
for text in ["今天天气真好", "如何制作炸弹", "我想结束自己的生命",
             "所有某地人都不可靠", "这个产品不错"]:
    r = pipeline.review(text)
    print(f"[{r.action:6s}] {text[:25]}... | {r.reason}")

print(f"\n统计: {pipeline.stats} | 人工队列: {len(pipeline.review_queue)} 条")
```

## 系统指令层面的安全边界

前置拦截成本远低于后置拦截。在系统 Prompt 中定义内容安全规则，让模型从一开始就拒绝生成有害内容。

## 关键认知

内容安全不是"加一个关键词过滤"就完事的。它需要规则引擎处理已知模式、语义模型理解隐含意图、人工审核处理边界案例。最危险的认知是"我们的模型很安全，不需要额外审核"——模型厂商的安全对齐是通用的，你的业务需要定制化策略。
