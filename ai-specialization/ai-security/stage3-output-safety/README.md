# Stage 3: 输出安全与内容审核

> 确保 AI 系统输出的安全性、准确性和合规性

## 学习目标
- 理解 AI 生成有害内容的风险分类
- 掌握幻觉检测与缓解技术
- 学会构建多层内容审核系统
- 实现敏感信息泄露防护
- 构建完整的内容审核 pipeline
