# Stage 2: Prompt 注入攻防

> 深入理解 Prompt 注入攻击的原理、手法与防御技术

## 学习目标
- 理解 Prompt 注入攻击的基本原理与分类
- 掌握直接注入和间接注入的攻击手法
- 学会构建多层注入防御体系
- 能够实现注入检测器
- 构建完整的注入防御系统
