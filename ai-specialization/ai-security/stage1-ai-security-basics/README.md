# Stage 1: AI 安全基础

> 建立 AI 安全的全局认知，了解威胁全景、行业标准和合规要求

## 学习目标
- 理解 AI 系统面临的安全威胁全景
- 掌握 OWASP Top 10 for LLM 的核心风险
- 学会进行 AI 系统攻击面分析
- 了解安全开发生命周期在 AI 项目中的应用
- 熟悉国内外 AI 合规法规要求
- 能够输出完整的安全评估报告
