## 课程大纲

### Stage 1: AI 安全基础 (6 lessons)
建立 AI 安全的全局认知，了解威胁全景、行业标准和合规要求。

| # | 课程 | 核心内容 |
|---|------|----------|
| 01 | AI安全威胁全景 | AI 系统面临的各类安全威胁分类与案例 |
| 02 | OWASP Top10 for LLM | OWASP LLM 应用十大安全风险详解 |
| 03 | 攻击面分析 | 识别 AI 系统的攻击面与威胁建模 |
| 04 | 安全开发生命周期 | Security by Design 在 AI 项目中的实践 |
| 05 | 合规与法规 | GDPR、AI Act、中国 AI 法规等合规要求 |
| 06 | 阶段实战 | 输出完整的 AI 系统安全评估报告 |

### Stage 2: Prompt 注入攻防 (6 lessons)
深入理解 Prompt 注入攻击的原理与防御技术。

| # | 课程 | 核心内容 |
|---|------|----------|
| 01 | Prompt注入原理 | 注入攻击的基本原理与分类体系 |
| 02 | 直接注入攻击 | 用户直接输入恶意 prompt 的攻击手法 |
| 03 | 间接注入攻击 | 通过外部数据源注入的高级攻击手法 |
| 04 | 注入防御策略 | 多层防御架构与最佳实践 |
| 05 | 输入过滤与检测 | 构建注入检测器的技术方案 |
| 06 | 阶段实战 | 构建完整的注入防御系统 |

### Stage 3: 输出安全与内容审核 (6 lessons)
确保 AI 系统输出的安全性和可靠性。

| # | 课程 | 核心内容 |
|---|------|----------|
| 01 | 有害内容生成 | AI 生成有害内容的风险与分类 |
| 02 | 幻觉与虚假信息 | AI 幻觉的成因、检测与缓解 |
| 03 | 内容审核系统 | 构建多层内容审核 pipeline |
| 04 | 输出过滤策略 | 输出过滤的技术方案与策略 |
| 05 | 敏感信息泄露防护 | 防止模型泄露训练数据和敏感信息 |
| 06 | 阶段实战 | 构建完整的内容审核 pipeline |

### Stage 4: 对抗攻击与模型安全 (6 lessons)
理解针对 AI 模型本身的攻击技术与防御方法。

| # | 课程 | 核心内容 |
|---|------|----------|
| 01 | 越狱攻击 | Jailbreak 技术分类与案例分析 |
| 02 | 对抗样本 | 对抗样本的生成与检测技术 |
| 03 | 数据投毒 | 训练数据投毒攻击与防御 |
| 04 | 模型窃取与逆向 | 模型知识产权保护技术 |
| 05 | 红队测试方法论 | AI 系统红队测试的系统方法 |
| 06 | 阶段实战 | 完整的红队测试演练 |

### Stage 5: AI 安全工程实践 (6 lessons)
将安全实践落地到工程体系中。

| # | 课程 | 核心内容 |
|---|------|----------|
| 01 | 安全架构设计 | AI 系统安全架构模式与设计原则 |
| 02 | 权限与访问控制 | AI 系统的细粒度权限控制 |
| 03 | 审计日志与监控 | 安全审计与实时监控体系 |
| 04 | 事件响应流程 | AI 安全事件的响应与处置 |
| 05 | AI安全工具链 | 安全工具选型与集成 |
| 06 | 阶段实战 | 构建完整的安全 AI 系统 |

## 学习建议

1. **按顺序学习**：Stage 1-4 有递进关系，建议按顺序完成
2. **动手实践**：每课的代码示例都要亲自运行
3. **完成练习**：每课末尾的 3 道练习题是巩固知识的关键
4. **阶段实战**：每个 Stage 的实战项目务必独立完成
5. **最终项目**：完成所有 Stage 后，做 Final Project 综合应用

## 预计学习时间

- 每课：2-3 小时
- 每阶段实战：4-6 小时
- 最终项目：8-12 小时
- **总计：约 100-120 小时**
