# WebGPU 粒子物理引擎 — 课程毕业项目

## 项目目标

构建一个基于 WebGPU 的百万级粒子物理引擎，支持粒子间碰撞检测、力场系统、GPU 计算着色器驱动的物理模拟。项目覆盖 WebGPU 创意编程课程中的核心知识：Compute Shader、Storage Buffer、GPU 并行计算、渲染管线、WGSL 着色器语言等。

## 技术栈

- **GPU API**：WebGPU
- **着色器语言**：WGSL
- **前端框架**：React + TypeScript 或 Vanilla TypeScript
- **数学库**：gl-matrix 或自定义矩阵/向量工具
- **构建**：Vite
- **测试**：Vitest

## 核心功能

### 模块一：GPU 粒子系统

- 基于 Compute Shader 的粒子更新（位置、速度、加速度）
- 使用 Storage Buffer 存储粒子数据（至少支持 100 万粒子）
- 双缓冲策略：读取上一帧状态，写入当前帧状态
- 粒子数据结构：位置(vec3)、速度(vec3)、颜色(vec4)、生命值(f32)、质量(f32)
- 粒子初始化：支持随机分布、球形分布、网格分布

### 模块二：力场系统

- 重力场（可调方向和强度）
- 点引力/斥力（鼠标点击产生）
- 风力场（方向和湍流）
- 涡旋力场
- 自定义力场（通过 WGSL 函数定义）
- 多个力场可叠加

### 模块三：碰撞检测

- 粒子与边界盒子的碰撞（反弹/吸收/穿过）
- 粒子间碰撞（基于空间哈希或均匀网格的 Broad Phase）
- 碰撞响应：弹性碰撞、非弹性碰撞
- 碰撞参数可调：弹性系数、摩擦力

### 模块四：渲染管线

- Instanced Rendering 或 Point Cloud 渲染
- 粒子大小随距离/速度变化
- 粒子颜色随生命值/速度渐变
- 支持 Billboard 粒子（始终面向摄像机）
- 混合模式：加法混合（发光效果）

### 模块五：交互与控制

- 参数面板：粒子数量、力场强度、碰撞系数、重力方向
- 鼠标交互：拖拽产生力场、点击发射粒子流
- 预设场景：
  - 烟花（爆炸 + 重力 + 衰减）
  - 流体模拟（SPH 简化版）
  - 星系模拟（引力 + 轨道）
  - 雨滴效果（重力 + 碰撞反弹）
- FPS 与粒子统计显示

## 验收标准

- [ ] 能在支持 WebGPU 的浏览器中运行，至少渲染 100 万粒子
- [ ] Compute Shader 驱动粒子物理更新，CPU 不参与逐粒子计算
- [ ] 至少实现重力、点引力、风力三种力场
- [ ] 粒子与边界盒子碰撞正常工作
- [ ] 粒子颜色随生命值或速度有渐变效果
- [ ] 鼠标交互能产生力场或发射粒子
- [ ] 至少有 2 个预设场景可切换
- [ ] 帧率监控显示，在 100 万粒子下保持 30fps 以上（中端 GPU）
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
