利用 GPU 并行计算能力实现程序化生成、生命游戏、群体行为和布料模拟，在浏览器中构建复杂的实时模拟系统。

## 验收标准

- 能在 GPU 上实现噪声/分形/WFC 的并行生成
- 能实现 Game of Life 及其变体的 GPU 计算
- 能用 Boids 算法实现大规模群体行为模拟
- 能用弹簧-质点系统实现布料或软体模拟
- 完成实时群体模拟可视化，支持万级以上个体
