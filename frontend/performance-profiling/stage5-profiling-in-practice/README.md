# 第五阶段：实战分析

## 阶段目标

综合运用 Performance、Memory、Network、Lighthouse 等工具，针对 React 应用、长列表、动画、移动端等场景进行系统性性能优化。

## 课时列表

1. [React 性能分析——React DevTools Profiler、渲染次数、不必要的重渲染](21-react-performance.md)
2. [长列表性能——虚拟滚动（react-window）、Intersection Observer、分页加载](22-long-list-performance.md)
3. [动画性能——GPU 加速、will-change、合成层、层爆炸](23-animation-performance.md)
4. [移动端性能——低端设备、弱网、电池优化、触控延迟](24-mobile-performance.md)
5. [阶段实战：为一个真实项目完成完整的性能优化](25-stage5-practice-full-optimization.md)

## 验收标准

- 能用 React DevTools Profiler 识别不必要的重渲染并优化
- 能用虚拟滚动解决长列表的渲染性能问题
- 能理解 GPU 加速、will-change 和合成层的工作原理
- 能为一个真实项目输出完整的性能优化报告
