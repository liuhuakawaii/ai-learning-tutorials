# VR 交互设计

## 场景引入

你拿到 VR 头显，打开一个应用，伸手去抓桌上的杯子——手穿过了杯子。按下扳机键，杯子飞了出去。挥动手柄，屏幕上的拳头纹丝不动。

这不是硬件问题，而是交互设计的问题。VR 交互的核心挑战是：**让用户忘记自己戴着头显、拿着手柄**。本课将带你构建一套完整的 VR 交互系统。

## 学习目标

- 理解 VR 控制器的数据模型和映射策略
- 实现基于手柄按钮的标准交互（抓取、指向）
- 构建手势识别系统，支持捏合、张开、指向等自然手势
- 设计触觉反馈模式，增强交互的真实感

### 按钮映射策略

不同 VR 平台的按钮布局不同，需要建立统一的抽象层：

```typescript
type VRAction = 'grab' | 'point' | 'menu' | 'confirm' | 'cancel' | 'teleport'

interface ButtonMapping {
  action: VRAction
  buttonIndex: number
  eventType: 'press' | 'release' | 'touch' | 'untouch'
  handedness: 'left' | 'right' | 'both'
}

const DEFAULT_MAPPING: ButtonMapping[] = [
  { action: 'grab',     buttonIndex: 1, eventType: 'press',   handedness: 'both' },
  { action: 'point',    buttonIndex: 0, eventType: 'touch',   handedness: 'both' },
  { action: 'menu',     buttonIndex: 3, eventType: 'press',   handedness: 'left' },
  { action: 'confirm',  buttonIndex: 0, eventType: 'press',   handedness: 'right' },
  { action: 'teleport', buttonIndex: 0, eventType: 'release', handedness: 'left' },
```

### 输入管理器

```typescript
class VRInputManager {
  private actions = new Map<VRAction, Set<() => void>>()
  private mapping: ButtonMapping[]
  private previousState: boolean[][] = []

  constructor(mapping: ButtonMapping[] = DEFAULT_MAPPING) {
    this.mapping = mapping
  }

  on(action: VRAction, callback: () => void): () => void {
    if (!this.actions.has(action)) this.actions.set(action, new Set())
    this.actions.get(action)!.add(callback)
    return () => this.actions.get(action)?.delete(callback)
  }

  update(session: XRSession) {
    const sources = session.inputSources
    for (let i = 0; i < sources.length; i++) {
      const source = sources[i]
      if (!source.gamepad) continue

      const buttons = source.gamepad.buttons
      if (!this.previousState[i]) this.previousState[i] = buttons.map(() => false)

      for (const m of this.mapping) {
        if (m.handedness !== 'both' && m.handedness !== source.handedness) continue
        const button = buttons[m.buttonIndex]
        if (!button) continue

        const isActive = m.eventType === 'press' || m.eventType === 'release'
          ? button.pressed : button.touched
        const wasActive = this.previousState[i][m.buttonIndex]

        let triggered = false
        if (m.eventType === 'press' || m.eventType === 'touch') {
          triggered = isActive && !wasActive
        } else {
          triggered = !isActive && wasActive
        }

        if (triggered) this.actions.get(m.action)?.forEach(cb => cb())
        this.previousState[i][m.buttonIndex] = isActive
      }
    }
  }
}
```

## 手势识别

手势识别的关键是定义清晰的状态机：

```typescript
type GestureType = 'open_hand' | 'fist' | 'pinch' | 'point' | 'thumbs_up'

interface FingerState {
  isExtended: boolean
  curlAmount: number  // 0 = 伸展, 1 = 弯曲
}

interface HandState {
  fingers: FingerState[]
  pinchDistance: number
  palmDirection: THREE.Vector3
}

class GestureRecognizer {
  private currentGesture: GestureType | null = null
  private callbacks = new Map<GestureType, Set<(confidence: number) => void>>()

  recognize(hand: HandState): GestureType | null {
    const { fingers, pinchDistance } = hand

    if (pinchDistance < 0.03 && fingers[2].isExtended && fingers[3].isExtended) {
      return this.emit('pinch', 1 - pinchDistance / 0.03)
    }
    if (fingers.every(f => f.curlAmount > 0.7)) {
      return this.emit('fist', Math.min(...fingers.map(f => f.curlAmount)))
    }
    if (fingers.every(f => f.isExtended)) {
      return this.emit('open_hand', 1)
    }
    if (fingers[1].isExtended && !fingers[2].isExtended && !fingers[3].isExtended) {
      return this.emit('point', 1)
    }
    if (fingers[0].isExtended && !fingers[1].isExtended && !fingers[2].isExtended) {
      return this.emit('thumbs_up', 1)
    }
    return null
  }

  private emit(gesture: GestureType, confidence: number): GestureType {
    if (this.currentGesture !== gesture) {
      this.currentGesture = gesture
      this.callbacks.get(gesture)?.forEach(cb => cb(confidence))
    }
    return gesture
  }

  on(gesture: GestureType, callback: (confidence: number) => void): () => void {
    if (!this.callbacks.has(gesture)) this.callbacks.set(gesture, new Set())
    this.callbacks.get(gesture)!.add(callback)
    return () => this.callbacks.get(gesture)?.delete(callback)
  }
}
```

## 抓取交互实现

```typescript
class GrabInteraction {
  private grabbedObject: THREE.Object3D | null = null
  private grabOffset = new THREE.Vector3()
  private grabbableObjects: THREE.Object3D[] = []

  constructor(
    private controller: THREE.XRGripSpace,
    private inputManager: VRInputManager
  ) {
    this.inputManager.on('grab', () => this.tryGrab())
  }

  registerGrabbable(object: THREE.Object3D) {
    this.grabbableObjects.push(object)
    object.userData.isGrabbable = true
  }

  private tryGrab() {
    if (this.grabbedObject) return
    const controllerPos = new THREE.Vector3()
    this.controller.getWorldPosition(controllerPos)

    let closest: THREE.Object3D | null = null
    let closestDist = 0.15

    for (const obj of this.grabbableObjects) {
      const objPos = new THREE.Vector3()
      obj.getWorldPosition(objPos)
      const dist = controllerPos.distanceTo(objPos)
      if (dist < closestDist) {
        closest = obj
        closestDist = dist
      }
    }

    if (closest) {
      this.grabbedObject = closest
      this.grabOffset.copy(controllerPos).sub(
        new THREE.Vector3().setFromMatrixPosition(closest.matrixWorld)
      )
    }
  }

  release() {
    this.grabbedObject = null
  }

  update() {
    if (!this.grabbedObject) return
    const pos = new THREE.Vector3()
    const quat = new THREE.Quaternion()
    this.controller.getWorldPosition(pos)
    this.controller.getWorldQuaternion(quat)
    this.grabbedObject.position.copy(pos).sub(this.grabOffset)
    this.grabbedObject.quaternion.copy(quat)
  }
}
```

## 常见误区

### 误区一：把手柄按钮直接映射到 2D 操作

VR 手柄不是游戏手柄。直接照搬 2D 按钮映射会让用户感到不自然。

### 误区二：手势识别追求 100% 准确率

手势识别存在固有模糊性。正确做法是用状态机 + 置信度阈值 + 时间窗口平滑结果。

### 误区三：忽略触觉反馈

没有触觉反馈的抓取交互会让用户感觉手穿过了物体，严重破坏沉浸感。

### 误区四：所有交互都用手势

手势追踪的精度和延迟不如手柄。高频交互（射击、移动）应使用手柄按钮。

## 工程建议

1. **交互优先级**：物理交互 > 手势 > 手柄按钮 > 眼动
2. **反馈完整性**：每个交互都必须有视觉、听觉、触觉三种反馈
3. **容错设计**：VR 中手会抖动，拾取判定要加缓冲区
4. **平台适配**：Quest、Pico、Vive 的手柄布局不同，务必通过抽象层隔离
5. **可发现性**：第一次进入 VR 时，用高亮 + 动画引导用户发现可交互物体

## 小结

VR 交互设计的核心是"让用户忘记自己在用设备"。本课介绍了三个关键层次：

- **控制器映射**：统一的输入抽象层，隔离不同平台差异
- **手势识别**：基于手指状态的有限状态机
- **触觉反馈**：预定义振动模式库，为每种交互提供物理反馈

## 参考答案

### 练习一

**思路**：用物理抛物线公式 `position + velocity * t + 0.5 * gravity * t²` 采样轨迹点，相邻点之间用 Raycaster 检测碰撞。

```typescript
class ParabolicPointer {
  private line: THREE.Line
  private hitMarker: THREE.Mesh
  private raycaster = new THREE.Raycaster()

  constructor(private controller: THREE.XRGripSpace, scene: THREE.Scene) {
    this.line = new THREE.Line(
      new THREE.BufferGeometry(),
      new THREE.LineBasicMaterial({ color: 0x00ff88 })
    )
    scene.add(this.line)

    this.hitMarker = new THREE.Mesh(
      new THREE.SphereGeometry(0.02),
      new THREE.MeshBasicMaterial({ color: 0xff8800 })
    )
    this.hitMarker.visible = false
    scene.add(this.hitMarker)
  }

  update(interactables: THREE.Object3D[]): THREE.Object3D | null {
    const origin = new THREE.Vector3()
    const direction = new THREE.Vector3()
    this.controller.getWorldPosition(origin)
    this.controller.getWorldDirection(direction)

    const velocity = direction.multiplyScalar(5)
    const gravity = new THREE.Vector3(0, -9.8, 0)
    const points: THREE.Vector3[] = []
    let hitObject: THREE.Object3D | null = null

    for (let i = 0; i <= 30; i++) {
      const t = i * 0.1
      const point = origin.clone()
        .add(velocity.clone().multiplyScalar(t))
        .add(gravity.clone().multiplyScalar(0.5 * t * t))
      points.push(point)

      if (i > 0 && !hitObject) {
        this.raycaster.set(points[i - 1], point.clone().sub(points[i - 1]).normalize())
        this.raycaster.far = points[i - 1].distanceTo(point)
        const hits = this.raycaster.intersectObjects(interactables, true)
        if (hits.length > 0) {
          hitObject = hits[0].object
          this.hitMarker.position.copy(hits[0].point)
          this.hitMarker.visible = true
        }
      }
    }

    this.line.geometry.setFromPoints(points)
    return hitObject
  }
}
```

**要点**：抛物线用物理公式采样比贝塞尔曲线更真实；碰撞检测在相邻采样点之间用 Raycaster。

### 练习二

**思路**：根据物理交互的真实感设计不同模式。杯子轻柔短促，键盘极短脉冲，碰撞强烈瞬时，弓箭渐增。

```typescript
const CUSTOM_HAPTICS = {
  pickUpCup:   { intensity: 0.3, duration: 40 },  // 轻柔接触玻璃

```

**要点**：短 duration + 低 intensity 适合高频交互；高 intensity + 长 duration 适合冲击类交互。
