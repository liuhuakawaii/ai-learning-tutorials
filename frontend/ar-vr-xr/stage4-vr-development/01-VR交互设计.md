# VR 交互设计：让用户忘记手柄的存在

## 当前项目状态

你已经能在 VR 中渲染场景、追踪头部。但用户伸手去抓虚拟杯子——手穿过了杯子。按下扳机键——杯子飞了出去。这不是硬件问题，是交互设计的问题。

VR 交互的核心挑战：**让用户觉得虚拟物体是"真的"**。本课构建一套完整的 VR 交互系统：抓取、指向、手势、触觉反馈。

## 射线交互（指向远处物体）

射线交互用于操作远处的物体——指向、点击、拖拽：

```typescript
class RayInteraction {
  private raycaster = new THREE.Raycaster()
  private rayLine: THREE.Line
  private hoveredObject: THREE.Object3D | null = null

  constructor(private scene: THREE.Scene) {
    // 可视化射线
    const geometry = new THREE.BufferGeometry().setFromPoints([
      new THREE.Vector3(0, 0, 0),
      new THREE.Vector3(0, 0, -5)
    ])
    this.rayLine = new THREE.Line(geometry,
      new THREE.LineBasicMaterial({ color: 0x00ff88 }))
    this.rayLine.visible = false
    scene.add(this.rayLine)
  }

  update(controller: THREE.XRGripSpace, objects: THREE.Object3D[]) {
    // 从控制器位置沿前方发射射线
    const matrix = controller.matrixWorld
    const origin = new THREE.Vector3().setFromMatrixPosition(matrix)
    const direction = new THREE.Vector3(0, 0, -1).applyMatrix4(
      new THREE.Matrix4().extractRotation(matrix)
    )

    this.raycaster.set(origin, direction)
    const hits = this.raycaster.intersectObjects(objects, true)

    // 更新射线长度
    const end = hits.length > 0
      ? hits[0].point
      : origin.clone().add(direction.multiplyScalar(5))

    this.rayLine.geometry.setFromPoints([origin, end])
    this.rayLine.visible = true

    // 高亮悬停物体
    if (this.hoveredObject !== hits[0]?.object) {
      if (this.hoveredObject) this.onHoverEnd(this.hoveredObject)
      this.hoveredObject = hits[0]?.object ?? null
      if (this.hoveredObject) this.onHoverStart(this.hoveredObject)
    }

    return hits[0] ?? null
  }

  private onHoverStart(obj: THREE.Object3D) {
    obj.userData._originalEmissive = obj.userData._emissive?.clone()
  }

  private onHoverEnd(obj: THREE.Object3D) {
    // 恢复原始状态
  }
}
```

## 抓取交互（近距离物体）

抓取需要物理反馈感——物体要"跟手"：

```typescript
class GrabInteraction {
  private grabbedObject: THREE.Object3D | null = null
  private grabOffset = new THREE.Vector3()

  tryGrab(controller: THREE.XRGripSpace, object: THREE.Object3D) {
    this.grabbedObject = object
    // 记录物体相对于控制器的偏移
    this.grabOffset.copy(object.position)
      .sub(new THREE.Vector3().setFromMatrixPosition(controller.matrixWorld))

    // 暂停物理模拟
    if (object.userData.rigidbody) {
      object.userData.rigidbody.disable()
    }
  }

  update(controller: THREE.XRGripSpace) {
    if (!this.grabbedObject) return

    const controllerPos = new THREE.Vector3()
      .setFromMatrixPosition(controller.matrixWorld)
    this.grabbedObject.position.copy(controllerPos).add(this.grabOffset)

    // 同步旋转
    const controllerQuat = new THREE.Quaternion()
      .setFromRotationMatrix(controller.matrixWorld)
    this.grabbedObject.quaternion.copy(controllerQuat)
  }

  release(controller: THREE.XRGripSpace) {
    if (!this.grabbedObject) return

    // 释放时继承控制器速度（扔出去）
    if (this.grabbedObject.userData.rigidbody) {
      const velocity = this.getControllerVelocity(controller)
      this.grabbedObject.userData.rigidbody.setVelocity(velocity)
      this.grabbedObject.userData.rigidbody.enable()
    }

    this.grabbedObject = null
  }
}
```

## 手势识别

手部追踪数据通过 `XRHand` 获取，包含 26 个关节的位置：

```typescript
interface XRHand extends Map<XRHandJoint, XRJointSpace> {}

type XRHandJoint =
  | 'wrist'
  | 'thumb-metacarpal' | 'thumb-phalanx-proximal' | 'thumb-phalanx-distal' | 'thumb-tip'
  | 'index-finger-metacarpal' | 'index-finger-phalanx-proximal'
  | 'index-finger-phalanx-intermediate' | 'index-finger-phalanx-distal' | 'index-finger-tip'
  // ... 其他手指

function isPinching(hand: XRHand): boolean {
  const thumbTip = hand.get('thumb-tip')
  const indexTip = hand.get('index-finger-tip')
  if (!thumbTip || !indexTip) return false

  // 计算拇指尖和食指尖的距离
  const distance = thumbTip.position.distanceTo(indexTip.position)
  return distance < 0.02 // 2cm 以内视为捏合
}

function isOpenHand(hand: XRHand): boolean {
  // 检查所有手指是否伸展
  const wrist = hand.get('wrist')
  const tips = ['thumb-tip', 'index-finger-tip', 'middle-finger-tip',
                'ring-finger-tip', 'pinky-finger-tip']

  for (const tip of tips) {
    const joint = hand.get(tip as XRHandJoint)
    if (!joint || !wrist) return false
    // 简化：检查指尖是否远离手腕
    if (joint.position.distanceTo(wrist.position) < 0.1) return false
  }
  return true
}
```

## 触觉反馈

触觉反馈让交互有"手感"：

```typescript
function hapticPulse(
  inputSource: XRInputSource,
  intensity: number = 0.5,
  duration: number = 50
) {
  // intensity: 0-1, duration: 毫秒
  inputSource.gamepad?.hapticActuators?.[0]?.pulse(intensity, duration)
}

// 使用场景
class VRButton {
  onPress() {
    hapticPulse(this.inputSource, 0.3, 30) // 轻触反馈
  }

  onGrab() {
    hapticPulse(this.inputSource, 0.7, 100) // 抓取反馈
  }

  onRelease() {
    hapticPulse(this.inputSource, 0.2, 20) // 释放反馈
  }
}
```

## 你可能踩的坑

**坑一：控制器模型不匹配**

不同设备的控制器形状完全不同。不要假设按钮位置，用 `inputSource.profiles` 检查设备类型再加载对应模型。

**坑二：手势识别误触发**

捏合距离阈值太松会导致误触发。建议加入防抖：连续 3 帧检测到捏合才触发。

**坑三：抓取后物体抖动**

物体跟手时如果直接设置位置，会和物理引擎冲突。需要在抓取期间禁用物理模拟，释放时重新启用。
