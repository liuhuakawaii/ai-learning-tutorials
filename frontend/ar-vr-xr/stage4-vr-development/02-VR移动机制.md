# VR 移动机制

## 场景引入

你在 VR 游戏中按下摇杆，角色开始向前移动——然后你立刻感到一阵恶心。这不是你的问题，而是移动机制设计的问题。VR 晕动症的根本原因是：**眼睛看到运动，但内耳感受不到加速度**。

本课将教你实现三种主流 VR 移动机制，并深入理解如何通过工程手段预防晕动症。

## 学习目标

- 实现瞬移（Teleportation）移动机制
- 实现平滑移动（Smooth Locomotion）并添加舒适度缓解措施
- 理解 VR 晕动症的生理机制和工程对策
- 构建统一的移动管理器，支持多种移动方式切换

## 瞬移（Teleportation）

瞬移是最舒适的 VR 移动方式。核心流程：指向目标 → 显示弧线 → 松手后瞬间移动。

```typescript
class TeleportMovement {
  private arcLine: THREE.Line
  private targetMarker: THREE.Mesh
  private isValidTarget = false
  private targetPosition = new THREE.Vector3()

  constructor(
    private xrManager: THREE.WebXRManager,
    private cameraRig: THREE.Group,
    private scene: THREE.Scene,
    private groundLayers: THREE.Object3D[] = []
  ) {
    this.arcLine = new THREE.Line(
      new THREE.BufferGeometry(),
      new THREE.LineBasicMaterial({ color: 0x00ff88, transparent: true, opacity: 0.6 })
    )
    scene.add(this.arcLine)

    this.targetMarker = new THREE.Mesh(
      new THREE.RingGeometry(0.15, 0.2, 32),
      new THREE.MeshBasicMaterial({ color: 0x00ff88, side: THREE.DoubleSide, transparent: true, opacity: 0.8 })
    )
    this.targetMarker.rotation.x = -Math.PI / 2
    this.targetMarker.visible = false
    scene.add(this.targetMarker)
  }

  updateArc(controller: THREE.Group) {
    const origin = new THREE.Vector3()
    const direction = new THREE.Vector3()
    controller.getWorldPosition(origin)
    controller.getWorldDirection(direction)

    const velocity = direction.multiplyScalar(8)
    const gravity = new THREE.Vector3(0, -12, 0)
    const points: THREE.Vector3[] = []
    this.isValidTarget = false
    let prevPoint = origin.clone()

    for (let i = 1; i <= 40; i++) {
      const t = i * 0.05
      const point = origin.clone()
        .add(velocity.clone().multiplyScalar(t))
        .add(gravity.clone().multiplyScalar(0.5 * t * t))
      points.push(point)

      const raycaster = new THREE.Raycaster(prevPoint, point.clone().sub(prevPoint).normalize())
      raycaster.far = prevPoint.distanceTo(point)
      const hits = raycaster.intersectObjects(this.groundLayers, true)

      if (hits.length > 0) {
        this.targetPosition.copy(hits[0].point)
        this.isValidTarget = true
        points[points.length - 1] = hits[0].point
        break
      }
      prevPoint = point.clone()
    }

    this.arcLine.geometry.setFromPoints(points)
    this.arcLine.visible = true
    this.targetMarker.position.copy(this.targetPosition)
    this.targetMarker.visible = this.isValidTarget
    this.targetMarker.material.color.setHex(this.isValidTarget ? 0x00ff88 : 0xff4444)
  }

  executeTeleport() {
    if (!this.isValidTarget) return
    const xrCamera = this.xrManager.getCamera()
    const cameraWorldPos = new THREE.Vector3()
    xrCamera.getWorldPosition(cameraWorldPos)
    const offset = cameraWorldPos.clone().sub(this.cameraRig.position)
    offset.y = 0
    this.cameraRig.position.copy(this.targetPosition).sub(offset)
    this.hideArc()
  }

  hideArc() {
    this.arcLine.visible = false
    this.targetMarker.visible = false
  }
}
```

### 淡入淡出过渡

瞬间跳转会让部分用户感到不适。添加淡入淡出过渡能显著提升舒适度：

```typescript
class TeleportTransition {
  private fadeQuad: THREE.Mesh
  private isTransitioning = false

  constructor(private scene: THREE.Scene) {
    const mat = new THREE.ShaderMaterial({
      uniforms: { uOpacity: { value: 0 } },
      vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = vec4(position.xy, 0.999, 1.0); }`,
      fragmentShader: `uniform float uOpacity; void main() { gl_FragColor = vec4(0,0,0, uOpacity); }`,
      transparent: true, depthTest: false, depthWrite: false
    })
    this.fadeQuad = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), mat)
    this.fadeQuad.renderOrder = 9999
  }

  async execute(teleportFn: () => void): Promise<void> {
    if (this.isTransitioning) return
    this.isTransitioning = true
    this.fadeQuad.visible = true
    this.scene.add(this.fadeQuad)

    await this.animateOpacity(0, 1, 150)
    teleportFn()
    await new Promise(r => setTimeout(r, 100))
    await this.animateOpacity(1, 0, 200)

    this.fadeQuad.visible = false
    this.scene.remove(this.fadeQuad)
    this.isTransitioning = false
  }

  private animateOpacity(from: number, to: number, duration: number): Promise<void> {
    return new Promise(resolve => {
      const start = performance.now()
      const mat = this.fadeQuad.material as THREE.ShaderMaterial
      const tick = () => {
        const t = Math.min((performance.now() - start) / duration, 1)
        mat.uniforms.uOpacity.value = from + (to - from) * t
        t < 1 ? requestAnimationFrame(tick) : resolve()
      }
      tick()
    })
  }
}
```

## 平滑移动（Smooth Locomotion）

```typescript
class SmoothLocomotion {
  private vignette: ComfortVignette

  constructor(private cameraRig: THREE.Group, private xrCamera: THREE.Camera, scene: THREE.Scene) {
    this.vignette = new ComfortVignette(scene)
  }

  update(inputX: number, inputY: number, speed: number, dt: number, enableVignette: boolean) {
    const headDir = new THREE.Vector3()
    this.xrCamera.getWorldDirection(headDir)
    headDir.y = 0; headDir.normalize()

    const headRight = new THREE.Vector3().crossVectors(headDir, new THREE.Vector3(0, 1, 0)).normalize()
    const moveDir = new THREE.Vector3()
      .addScaledVector(headRight, inputX)
      .addScaledVector(headDir, -inputY).normalize()

    const velocity = moveDir.multiplyScalar(speed * dt)
    this.cameraRig.position.lerp(this.cameraRig.position.clone().add(velocity), 0.15)

    if (enableVignette) this.vignette.setIntensity(velocity.length() / speed)
  }
}
```

### 舒适度视野收缩（Comfort Vignette）

移动时缩小视野范围，减少周边视觉的运动信息：

```typescript
class ComfortVignette {
  private overlay: THREE.Mesh
  private currentIntensity = 0

  constructor(scene: THREE.Scene) {
    const mat = new THREE.ShaderMaterial({
      uniforms: { uIntensity: { value: 0 } },
      vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = vec4(position.xy, 0.998, 1.0); }`,
      fragmentShader: `
        uniform float uIntensity; varying vec2 vUv;
        void main() {
          float dist = length(vUv - 0.5) * 2.0;
          float mask = smoothstep(0.3, 0.3 + uIntensity * 0.5, dist);
          gl_FragColor = vec4(0, 0, 0, mask * uIntensity * 0.85);
        }
      `,
      transparent: true, depthTest: false, depthWrite: false, side: THREE.DoubleSide
    })
    this.overlay = new THREE.Mesh(new THREE.RingGeometry(0.5, 2.0, 64), mat)
    this.overlay.renderOrder = 9998
    this.overlay.visible = false
    scene.add(this.overlay)
  }

  setIntensity(target: number) {
    this.currentIntensity += (target - this.currentIntensity) * 0.1
    this.overlay.visible = this.currentIntensity > 0.01
    if (this.overlay.visible) {
      (this.overlay.material as THREE.ShaderMaterial).uniforms.uIntensity.value = this.currentIntensity
    }
  }
}
```

## 离散转向

连续旋转容易导致眩晕，离散转向（每次转固定角度）更舒适：

```typescript
class SnapTurn {
  private canSnap = true

  constructor(private cameraRig: THREE.Group, private angle: number = 30) {}

  update(inputX: number) {
    if (Math.abs(inputX) > 0.7 && this.canSnap) {
      const radians = (this.angle * Math.PI / 180) * (inputX > 0 ? 1 : -1)
      const quat = new THREE.Quaternion().setFromAxisAngle(new THREE.Vector3(0, 1, 0), radians)
      this.cameraRig.quaternion.premultiply(quat)
      this.canSnap = false
    }
    if (Math.abs(inputX) < 0.3) this.canSnap = true
  }
}
```

## 晕动症工程对策

| 对策 | 说明 |
|------|------|
| 稳定参考框架 | 在视野中保留固定参考物（如虚拟鼻子），帮助大脑锚定空间 |
| 周边视觉抑制 | 移动时收缩视野，减少周边视觉的运动刺激 |
| 离散转向 | 每次转向固定角度（30-45度），避免连续旋转 |
| 帧率稳定 | 保持 90 FPS 稳定，帧率波动比低帧率更容易导致晕动症 |
| 不劫持相机 | 永远不要未经用户同意移动相机 |

## 统一移动管理器

```typescript
type MovementMode = 'teleport' | 'smooth' | 'none'

class MovementSystem {
  private mode: MovementMode = 'teleport'
  private teleport: TeleportMovement
  private smooth: SmoothLocomotion
  private snapTurn: SnapTurn
  private transition: TeleportTransition
  private settings = { vignette: true, speed: 3, snapTurn: true, snapAngle: 30 }

  constructor(xrManager: THREE.WebXRManager, cameraRig: THREE.Group, scene: THREE.Scene) {
    this.teleport = new TeleportMovement(xrManager, cameraRig, scene)
    this.smooth = new SmoothLocomotion(cameraRig, xrManager.getCamera(), scene)
    this.snapTurn = new SnapTurn(cameraRig, this.settings.snapAngle)
    this.transition = new TeleportTransition(scene)
  }

  setMode(mode: MovementMode) { this.mode = mode }

  update(leftInput: GamepadState, rightInput: GamepadState, dt: number) {
    if (this.mode === 'teleport' && leftInput.triggerReleased) {
      this.transition.execute(() => this.teleport.executeTeleport())
    } else if (this.mode === 'smooth') {
      this.smooth.update(leftInput.stickX, leftInput.stickY, this.settings.speed, dt, this.settings.vignette)
    }
    if (this.settings.snapTurn) this.snapTurn.update(rightInput.stickX)
  }
}

interface GamepadState { stickX: number; stickY: number; triggerHeld: boolean; triggerReleased: boolean }
```

## 常见误区

1. **只提供平滑移动**：大量用户只能接受瞬移，应同时支持两种模式
2. **瞬移不需要过渡**：淡入淡出能显著降低空间迷失感
3. **忽视帧率稳定性**：帧率波动比持续低帧率更容易引发晕动症
4. **移动速度越快越好**：VR 移动速度应比传统游戏慢 30-50%

## 工程建议

1. **用户偏好优先**：提供移动方式切换和舒适度设置面板
2. **新手引导**：第一次进入 VR 用最保守设置（瞬移 + 离散转向 + 视野收缩）
3. **物理一致性**：移动时避免相机穿过墙壁
4. **帧率预算**：移动系统的 CPU 开销必须严格控制

## 小结

VR 移动机制是舒适度与自由度之间的平衡。本课介绍了：

- **瞬移**：抛物线指向 + 淡入淡出过渡
- **平滑移动**：摇杆控制 + 视野收缩缓解
- **晕动症对策**：稳定参考、周边抑制、离散转向、帧率稳定

核心原则：**VR 移动的第一目标是舒适，第二目标才是自由**。

## 参考答案

### 练习一

**思路**：命中地面后计算与当前地面的高度差，用颜色提示高度变化，超阈值时禁止瞬移。

```typescript
class HeightAwareTeleport extends TeleportMovement {
  private maxHeightDiff = 2.0

  updateArc(controller: THREE.Group) {
    super.updateArc(controller)
    if (!this.isValidTarget) return
    const heightDiff = this.targetPosition.y - (controller.parent?.position.y ?? 0)
    if (Math.abs(heightDiff) > this.maxHeightDiff) {
      this.isValidTarget = false
      this.targetMarker.material.color.setHex(0xff0000)
    }
  }
}
```

**要点**：高度差阈值应可配置；超阈值时禁止瞬移而非仅显示警告。

### 练习二

**思路**：用 World-Space Canvas 面板实现，固定在用户前方 1.5 米处，通过 Raycaster 交互。设置需持久化到 localStorage。

```typescript
class ComfortSettingsPanel {
  private panel: THREE.Mesh
  private canvas: HTMLCanvasElement

  constructor(scene: THREE.Scene) {
    this.canvas = document.createElement('canvas')
    this.canvas.width = 512; this.canvas.height = 384
    const texture = new THREE.CanvasTexture(this.canvas)
    this.panel = new THREE.Mesh(
      new THREE.PlaneGeometry(0.6, 0.45),
      new THREE.MeshBasicMaterial({ map: texture, transparent: true })
    )
    scene.add(this.panel)
  }

  showInFrontOf(camera: THREE.Camera) {
    const forward = new THREE.Vector3(0, 0, -1.5).applyQuaternion(camera.quaternion)
    this.panel.position.copy(camera.position).add(forward)
    this.panel.lookAt(camera.position)
  }
}
```

**要点**：面板始终面向用户；设置需持久化到 localStorage。
