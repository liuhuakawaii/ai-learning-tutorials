# 阶段实战：VR 协作空间——多人在同一个虚拟房间

## 当前项目状态

你已经掌握了 VR 交互、移动机制、UI 系统和性能优化。现在要构建的是一个多人 VR 协作空间：团队成员戴上头显进入同一个虚拟房间，在白板上画图、在桌面上放 3D 模型、用语音讨论。

这不是 demo——它要能真正用起来。

## 技术栈

```
渲染层：Three.js + WebXR
网络层：WebSocket（信令）+ WebRTC（音频）
同步层：CRDT（无冲突复制数据类型）
服务端：Node.js + ws
```

## 信令与 WebRTC

多人音频需要 WebRTC，但 WebRTC 需要信令服务器来交换 SDP 和 ICE 候选：

```typescript
class SignalingClient {
  private ws: WebSocket
  private peerConnections = new Map<string, RTCPeerConnection>()

  constructor(url: string) {
    this.ws = new WebSocket(url)
    this.ws.onmessage = (e) => this.handleMessage(JSON.parse(e.data))
  }

  async joinRoom(roomId: string, userName: string) {
    this.ws.send(JSON.stringify({
      type: 'join', roomId, userName
    }))
  }

  private async handleMessage(msg: any) {
    switch (msg.type) {
      case 'peer-joined':
        await this.createPeerConnection(msg.peerId)
        break
      case 'offer':
        await this.handleOffer(msg.peerId, msg.sdp)
        break
      case 'answer':
        await this.handleAnswer(msg.peerId, msg.sdp)
        break
      case 'ice-candidate':
        await this.handleIceCandidate(msg.peerId, msg.candidate)
        break
    }
  }

  private async createPeerConnection(peerId: string) {
    const pc = new RTCPeerConnection({
      iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
    })

    // 添加本地音频流
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true })
    stream.getTracks().forEach(track => pc.addTrack(track, stream))

    pc.onicecandidate = (e) => {
      if (e.candidate) {
        this.ws.send(JSON.stringify({
          type: 'ice-candidate',
          peerId,
          candidate: e.candidate
        }))
      }
    }

    this.peerConnections.set(peerId, pc)
    return pc
  }
}
```

## 远程参与者渲染

每个远程参与者用一个简单的虚拟形象表示：

```typescript
class RemoteParticipant {
  private headGroup: THREE.Group
  private leftHand: THREE.Mesh
  private rightHand: THREE.Mesh
  private nameLabel: THREE.Sprite

  constructor(scene: THREE.Scene, name: string) {
    // 头部用球体
    this.headGroup = new THREE.Group()
    const head = new THREE.Mesh(
      new THREE.SphereGeometry(0.12, 16, 16),
      new THREE.MeshStandardMaterial({ color: 0x4a90d9 })
    )
    this.headGroup.add(head)

    // 名字标签
    this.nameLabel = this.createNameLabel(name)
    this.nameLabel.position.y = 0.2
    this.headGroup.add(this.nameLabel)

    // 手部用小球
    this.leftHand = new THREE.Mesh(
      new THREE.SphereGeometry(0.04, 8, 8),
      new THREE.MeshStandardMaterial({ color: 0x2ecc71 })
    )
    this.rightHand = this.leftHand.clone()
    scene.add(this.headGroup, this.leftHand, this.rightHand)
  }

  update(participant: Participant) {
    this.headGroup.position.set(...participant.headPose.position)
    this.headGroup.quaternion.set(...participant.headPose.quaternion)
    this.leftHand.position.set(...participant.leftHand.position)
    this.rightHand.position.set(...participant.rightHand.position)
  }
}
```

## 白板同步

白板用 CRDT 实现无冲突同步——每个人都可以同时画，不会互相覆盖：

```typescript
class WhiteboardCRDT {
  private strokes: Map<string, Stroke> = new Map()

  addStroke(stroke: Stroke) {
    this.strokes.set(stroke.id, stroke)
    this.broadcast({ type: 'stroke-add', stroke })
  }

  removeStroke(id: string) {
    this.strokes.delete(id)
    this.broadcast({ type: 'stroke-remove', id })
  }

  // 接收远程操作
  applyRemoteOperation(op: any) {
    switch (op.type) {
      case 'stroke-add':
        this.strokes.set(op.stroke.id, op.stroke)
        this.renderStroke(op.stroke)
        break
      case 'stroke-remove':
        this.strokes.delete(op.id)
        this.eraseStroke(op.id)
        break
    }
  }

  // 用时间戳解决冲突：后写入的胜
  merge(remoteStrokes: Stroke[]) {
    for (const remote of remoteStrokes) {
      const local = this.strokes.get(remote.id)
      if (!local || remote.timestamp > local.timestamp) {
        this.strokes.set(remote.id, remote)
      }
    }
  }
}
```

## 你可能踩的坑

**坑一：WebRTC 连接失败**

NAT 穿透是 WebRTC 最常见的问题。只用 STUN 服务器可能不够，需要 TURN 服务器做中继。

**坑二：状态同步延迟**

网络延迟会导致远程参与者的位置"跳变"。用插值平滑：保留前几帧的位置，在渲染时做线性插值。

**坑三：白板笔画太多导致卡顿**

每帧都在画新的笔画，三角形数量会快速增长。定期合并旧笔画为纹理贴图，减少几何体数量。

```typescript
class SpatialAudio {
  private audioContext: AudioContext
  private panners = new Map<string, PannerNode>()

  constructor() {
    this.audioContext = new AudioContext()
  }

  addParticipant(id: string, stream: MediaStream) {
    const source = this.audioContext.createMediaStreamSource(stream)
    const panner = this.audioContext.createPanner()
    panner.panningModel = 'HRTF'
    panner.distanceModel = 'inverse'
    panner.refDistance = 1
    panner.maxDistance = 10

    source.connect(panner)
    panner.connect(this.audioContext.destination)
    this.panners.set(id, panner)
  }

  updatePosition(id: string, x: number, y: number, z: number) {
    const panner = this.panners.get(id)
    if (panner) {
      panner.positionX.setValueAtTime(x, this.audioContext.currentTime)
      panner.positionY.setValueAtTime(y, this.audioContext.currentTime)
      panner.positionZ.setValueAtTime(z, this.audioContext.currentTime)
    }
  }
}
```

// 资产面板中的模型拖拽
class AssetPanel {
  private models = ['chair.glb', 'table.glb', 'monitor.glb']

  createPanel(scene: THREE.Scene) {
    // 在用户面前 1.5 米处创建一个浮动面板
    const panel = new THREE.Group()
    this.models.forEach((model, i) => {
      const thumbnail = this.createThumbnail(model)
      thumbnail.position.set(i * 0.3 - 0.3, 0, 0)
      panel.add(thumbnail)
    })
    panel.position.set(0, 1.2, -1.5)
    scene.add(panel)
    return panel
  }

  async onDrop(modelName: string, position: THREE.Vector3) {
    const model = await loadModel(`/models/${modelName}`)
    model.position.copy(position)
    scene.add(model)
    // 同步到其他参与者
    broadcast({ type: 'model-placed', model: modelName, position })
  }
}
