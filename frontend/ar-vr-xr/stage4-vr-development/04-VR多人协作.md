# VR 多人协作

## 场景引入

你和三个同事戴上 VR 头显，进入同一个虚拟会议室。你指向白板说"这里需要改"——但他们看到你指向了不同的位置。你画了一条线，三秒后别人才看到。转头说话，声音从四面八方传来。

这是 VR 多人协作的三大核心挑战：**空间同步、状态一致性和空间语音**。本课将带你构建一个支持多人实时协作的 VR 系统。

## 学习目标

- 设计 VR 多人协作的网络架构
- 实现控制器姿态和物体状态的实时同步
- 构建虚拟形象（Avatar）系统
- 实现基于空间位置的 3D 语音

### 实时同步核心

```typescript
class VRNetworkManager {
  private ws: WebSocket | null = null
  private peers = new Map<string, PeerState>()
  private localState: LocalState
  private updateRate = 30
  private lastSendTime = 0

  constructor(private serverUrl: string) {
    this.localState = {
      headPose: { position: [0,0,0], rotation: [0,0,0,1] },
      leftHand: { position: [0,0,0], rotation: [0,0,0,1] },
      rightHand: { position: [0,0,0], rotation: [0,0,0,1] }
    }
  }

  async connect(roomId: string, userName: string): Promise<void> {
    return new Promise((resolve, reject) => {
      this.ws = new WebSocket(`${this.serverUrl}/room/${roomId}`)
      this.ws.onopen = () => {
        this.ws!.send(JSON.stringify({ type: 'join', userName, timestamp: Date.now() }))
        resolve()
      }
      this.ws.onmessage = (event) => this.handleMessage(JSON.parse(event.data))
      this.ws.onerror = reject
    })
  }

  private handleMessage(message: any) {
    switch (message.type) {
      case 'peer_update':
        this.peers.set(message.peerId, {
          ...this.peers.get(message.peerId)!,
          headPose: message.headPose, leftHand: message.leftHand, rightHand: message.rightHand,
          lastUpdate: Date.now()
        })
        break
      case 'peer_join':
        this.peers.set(message.peerId, {
          userName: message.userName,
          headPose: { position: [0,0,0], rotation: [0,0,0,1] },
          leftHand: { position: [0,0,0], rotation: [0,0,0,1] },
          rightHand: { position: [0,0,0], rotation: [0,0,0,1] },
          lastUpdate: Date.now()
        })
        break
      case 'peer_leave': this.peers.delete(message.peerId); break
    }
  }

  update(dt: number) {
    this.lastSendTime += dt
    if (this.lastSendTime < 1 / this.updateRate) return
    this.lastSendTime = 0
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify({ type: 'peer_update', ...this.localState, timestamp: Date.now() }))
    }
  }

  setLocalPose(head: Pose, leftHand: Pose, rightHand: Pose) {
    this.localState = { headPose: head, leftHand, rightHand }
  }

  getPeers() { return this.peers }
}

interface Pose { position: [number,number,number]; rotation: [number,number,number,number] }
interface PeerState { userName: string; headPose: Pose; leftHand: Pose; rightHand: Pose; lastUpdate: number }
```

### 状态插值

网络数据包到达频率低于渲染帧率，需要插值平滑运动：

```typescript
class PoseInterpolator {
  private buffer: { pose: Pose; timestamp: number }[] = []

  addSample(pose: Pose, timestamp: number) {
    this.buffer.push({ pose, timestamp })
    if (this.buffer.length > 3) this.buffer.shift()
  }

  interpolate(renderTime: number): Pose | null {
    if (this.buffer.length < 2) return this.buffer[this.buffer.length - 1]?.pose ?? null
    let before = this.buffer[0], after = this.buffer[1]
    for (let i = 1; i < this.buffer.length; i++) {
      if (this.buffer[i].timestamp >= renderTime) { before = this.buffer[i - 1]; after = this.buffer[i]; break }
    }
    const t = after.timestamp === before.timestamp ? 0
      : Math.max(0, Math.min(1, (renderTime - before.timestamp) / (after.timestamp - before.timestamp)))
    return {
      position: before.pose.position.map((v, i) => v + (after.pose.position[i] - v) * t) as [number,number,number],
      rotation: slerp(before.pose.rotation, after.pose.rotation, t)
    }
  }
}

function slerp(a: [number,number,number,number], b: [number,number,number,number], t: number): [number,number,number,number] {
  let dot = a[0]*b[0] + a[1]*b[1] + a[2]*b[2] + a[3]*b[3]
  const bAdj = dot < 0 ? [-b[0],-b[1],-b[2],-b[3]] as typeof b : b
  dot = Math.abs(dot)
  if (dot > 0.9995) {
    const r = a.map((v, i) => v + (bAdj[i] - v) * t) as typeof a
    const len = Math.sqrt(r.reduce((s, v) => s + v*v, 0))
    return r.map(v => v / len) as typeof a
  }
  const theta = Math.acos(dot), sinT = Math.sin(theta)
  const wa = Math.sin((1 - t) * theta) / sinT, wb = Math.sin(t * theta) / sinT
  return [wa*a[0]+wb*bAdj[0], wa*a[1]+wb*bAdj[1], wa*a[2]+wb*bAdj[2], wa*a[3]+wb*bAdj[3]]
}
```

```typescript
    this.interpolators.leftHand.addSample(left, timestamp)
    this.interpolators.rightHand.addSample(right, timestamp)
  }

  render(renderTime: number) {
    const hp = this.interpolators.head.interpolate(renderTime)
    if (hp) { this.head.position.fromArray(hp.position); this.head.quaternion.fromArray(hp.rotation) }
    const lp = this.interpolators.leftHand.interpolate(renderTime)
    if (lp) { this.leftHand.position.fromArray(lp.position); this.leftHand.quaternion.fromArray(lp.rotation) }
    const rp = this.interpolators.rightHand.interpolate(renderTime)
    if (rp) { this.rightHand.position.fromArray(rp.position); this.rightHand.quaternion.fromArray(rp.rotation) }
  }

  getGroup() { return this.group }
  dispose() { this.group.traverse(c => { if (c instanceof THREE.Mesh) { c.geometry.dispose(); (c.material as any).dispose() } }) }
}
```

## 空间语音

```typescript
class SpatialVoiceChat {
  private audioCtx: AudioContext
  private peerNodes = new Map<string, { source: MediaStreamAudioSourceNode; panner: PannerNode }>()

  constructor() { this.audioCtx = new AudioContext() }

  async startMicrophone() {
    await navigator.mediaDevices.getUserMedia({
      audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true, sampleRate: 48000 }
    })
  }

  addPeerAudio(peerId: string, stream: MediaStream) {
    const source = this.audioCtx.createMediaStreamSource(stream)
    const panner = this.audioCtx.createPanner()
    panner.panningModel = 'HRTF'; panner.distanceModel = 'inverse'
    panner.refDistance = 1; panner.maxDistance = 50; panner.rolloffFactor = 2
    source.connect(panner); panner.connect(this.audioCtx.destination)
    this.peerNodes.set(peerId, { source, panner })
  }

  updatePeerPosition(peerId: string, position: [number,number,number]) {
    const nodes = this.peerNodes.get(peerId)
    if (!nodes) return
    const now = this.audioCtx.currentTime
    nodes.panner.positionX.setTargetAtTime(position[0], now, 0.05)
    nodes.panner.positionY.setTargetAtTime(position[1], now, 0.05)
    nodes.panner.positionZ.setTargetAtTime(position[2], now, 0.05)
  }

  updateListener(pos: [number,number,number], forward: [number,number,number], up: [number,number,number]) {
    const l = this.audioCtx.listener; const now = this.audioCtx.currentTime
    l.positionX?.setTargetAtTime(pos[0], now, 0.05)
    l.positionY?.setTargetAtTime(pos[1], now, 0.05)
    l.positionZ?.setTargetAtTime(pos[2], now, 0.05)
    l.forwardX?.setTargetAtTime(forward[0], now, 0.05)
    l.forwardY?.setTargetAtTime(forward[1], now, 0.05)
    l.forwardZ?.setTargetAtTime(forward[2], now, 0.05)
  }

  removePeerAudio(peerId: string) {
    const nodes = this.peerNodes.get(peerId)
    if (nodes) { nodes.source.disconnect(); nodes.panner.disconnect(); this.peerNodes.delete(peerId) }
  }
}
```

## 常见误区

1. **发送每帧数据**：网络更新 30 FPS 就够了，每帧都发浪费带宽
2. **直接设置网络数据到物体**：必须用插值缓冲区平滑运动
3. **忽视 WebRTC**：语音必须走 WebRTC P2P 通道，WebSocket 只用于信令
4. **同步所有物体**：只有被交互过的物体才需要同步

## 工程建议

1. **带宽预算**：每用户上行控制在 50-100 KB/s
2. **延迟容忍**：VR 协作延迟阈值 100ms
3. **WebRTC 优先**：音频视频走 WebRTC，控制消息走 WebSocket
4. **状态快照**：新用户加入时发送完整房间状态

## 小结

VR 多人协作需要解决三个核心问题：

- **网络同步**：WebSocket + 节流 + 插值
- **虚拟形象**：头部和手部姿态映射到 3D 模型
- **空间语音**：Web Audio API 的 HRTF 模型实现 3D 音频

核心原则：**在有限带宽下，用最少的数据传递最重要的信息**。

### 练习一

**思路**：服务器作为权威仲裁者。当前所有者超时后可被抢占。

```typescript
class OwnershipManager {
  private ownership = new Map<string, { ownerId: string; timestamp: number }>()
  private timeout = 5000

  async requestOwnership(objectId: string, peerId: string): Promise<boolean> {
    const current = this.ownership.get(objectId)
    if (!current || current.ownerId === peerId || Date.now() - current.timestamp > this.timeout) {
      this.ownership.set(objectId, { ownerId: peerId, timestamp: Date.now() })
      return true
    }
    return false
  }

  releaseOwnership(objectId: string, peerId: string) {
    const current = this.ownership.get(objectId)
    if (current?.ownerId === peerId) this.ownership.delete(objectId)
  }

  getOwner(objectId: string): string | null { return this.ownership.get(objectId)?.ownerId ?? null }
}
```

### 练习二

**思路**：手势是离散状态，用 bit 编码比浮点数更高效。

```typescript
const GESTURE_CODES = { open_hand: 0, fist: 1, pinch: 2, point: 3, thumbs_up: 4 }

class GestureSync {
  encode(left: GestureType, right: GestureType): number {
    return ((GESTURE_CODES[left] ?? 0) << 4) | (GESTURE_CODES[right] ?? 0)
  }

  decode(encoded: number): { left: GestureType; right: GestureType } {
    const map = Object.entries(GESTURE_CODES)
    const left = map.find(([_, c]) => c === ((encoded >> 4) & 0x0F))?.[0] as GestureType ?? 'open_hand'
    const right = map.find(([_, c]) => c === (encoded & 0x0F))?.[0] as GestureType ?? 'open_hand'
    return { left, right }
  }
}
```
