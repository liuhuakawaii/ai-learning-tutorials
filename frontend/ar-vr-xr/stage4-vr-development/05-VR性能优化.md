# VR 性能优化

## 场景引入

你刚完成了一个精美的 VR 场景，桌面测试一切流畅。戴上头显——画面卡顿、延迟明显。打开性能面板，GPU 占用 98%，帧率从 90 掉到了 45。

VR 的性能要求比传统 3D 苛刻得多：**双眼渲染（2 倍 draw call）、90 FPS 硬性要求、延迟必须低于 20ms**。本课将教你掌握 VR 专属的性能优化技术。

## 学习目标

- 理解 VR 渲染管线的性能瓶颈
- 实现注视点渲染（Foveated Rendering）
- 设计 VR 专属的 LOD 策略
- 掌握遮挡剔除（Occlusion Culling）
- 构建性能监控和自动降级系统

## VR 渲染管线分析

| 挑战 | 开销 | 解决方案 |
|------|------|----------|
| 双眼渲染 | 2x draw calls | Multi-view rendering, Instanced Stereo |
| 高分辨率 | 4x 像素着色 vs 1080p | Foveated Rendering, 动态分辨率 |
| 高帧率 | 每帧预算仅 11ms（90FPS） | 异步时间扭曲（ATW） |
| 低延迟 | 不能使用多帧延迟策略 | 前向渲染，减少后处理 |

```typescript
function calculateVRFrameBudget(targetFPS = 90) {
  const frame = 1000 / targetFPS
  return {
    cpu: { sceneGraph: frame*0.1, physics: frame*0.1, animation: frame*0.05, submit: frame*0.15 },
    gpu: { vertex: frame*0.2, fragment: frame*0.25, postProcess: frame*0.1 }
  }
}
```

## 注视点渲染（Foveated Rendering）

人眼只有中央凹区域（约 2° 视角）能看清细节。注视点渲染降低周边区域的渲染分辨率：

```typescript
class FixedFoveatedRenderer {
  private centerRT: THREE.WebGLRenderTarget
  private peripheryRT: THREE.WebGLRenderTarget

  constructor(private renderer: THREE.WebGLRenderer, width: number, height: number) {
    this.centerRT = new THREE.WebGLRenderTarget(width * 0.5, height * 0.5, {
      minFilter: THREE.LinearFilter, magFilter: THREE.LinearFilter
    })
    this.peripheryRT = new THREE.WebGLRenderTarget(width * 0.25, height * 0.25, {
      minFilter: THREE.LinearFilter, magFilter: THREE.LinearFilter
    })
  }

  render(scene: THREE.Scene, camera: THREE.Camera) {
    this.renderer.setRenderTarget(this.centerRT)
    this.renderer.render(scene, camera)
    this.renderer.setRenderTarget(this.peripheryRT)
    this.renderer.render(scene, camera)
    this.renderer.setRenderTarget(null)
  }
}
```

### 自动调节注视点等级

```typescript
class FoveationController {
  private level = 0
  constructor(private gl: WebGLRenderingContext) {}

  setLevel(level: 0 | 1 | 2 | 3) {
    this.level = level
    const ext = this.gl.getExtension('META_fixed_foveated_rendering')
    if (ext) ext.fixedFoveatedRendering.level = level
  }

  autoAdjust(gpuTimeMs: number, targetMs: number) {
    const ratio = gpuTimeMs / targetMs
    if (ratio > 1.2 && this.level < 3) this.setLevel(Math.min(3, this.level + 1) as any)
    else if (ratio < 0.8 && this.level > 0) this.setLevel(Math.max(0, this.level - 1) as any)
  }
}
```

## LOD 策略

VR 中的 LOD 特殊之处：物体在视野边缘时即使距离近也可降低细节，在视野中心时即使距离远也要保持细节：

```typescript
class VRLodSystem {
  private groups = new Map<string, { object: THREE.Object3D; levels: LodLevel[]; current: number }>()
  private headPos = new THREE.Vector3()
  private headDir = new THREE.Vector3()

  updateHead(pos: THREE.Vector3, dir: THREE.Vector3) { this.headPos.copy(pos); this.headDir.copy(dir) }

  register(id: string, object: THREE.Object3D, levels: LodLevel[]) {
    this.groups.set(id, { object, levels: levels.sort((a, b) => a.distance - b.distance), current: 0 })
  }

  update() {
    this.groups.forEach((group) => {
      const objPos = new THREE.Vector3()
      group.object.getWorldPosition(objPos)
      const distance = this.headPos.distanceTo(objPos)
      const toObj = objPos.clone().sub(this.headPos).normalize()
      const angle = toObj.angleTo(this.headDir)
      const adjustedDist = distance * (1 + angle * 2)

      let newLevel = 0
      for (let i = group.levels.length - 1; i >= 0; i--) {
        if (adjustedDist > group.levels[i].distance) { newLevel = i; break }
      }
      if (newLevel !== group.current) {
        group.levels.forEach((lod, i) => { if (lod.mesh) lod.mesh.visible = i === newLevel })
        group.current = newLevel
      }
    })
  }
}

interface LodLevel { distance: number; mesh: THREE.Object3D | null; triangleCount: number }
```

## 遮挡剔除（Occlusion Culling）

跳过被其他物体完全遮挡的对象的渲染，在室内场景中效果显著：

```typescript
class OcclusionCuller {
  private queryPool: WebGLQuery[] = []
  private visibleSet = new Set<string>()

  constructor(private gl: WebGL2RenderingContext) {
    for (let i = 0; i < 64; i++) this.queryPool.push(gl.createQuery()!)
  }

  frustumCull(objects: THREE.Object3D[], camera: THREE.Camera): THREE.Object3D[] {
    const frustum = new THREE.Frustum()
    const matrix = new THREE.Matrix4().multiplyMatrices(camera.projectionMatrix, camera.matrixWorldInverse)
    frustum.setFromProjectionMatrix(matrix)
    return objects.filter(obj => {
      if (!obj.geometry?.boundingSphere) return true
      const sphere = obj.geometry.boundingSphere.clone().applyMatrix4(obj.matrixWorld)
      return frustum.intersectsSphere(sphere)
    })
  }

  isVisible(id: string): boolean { return this.visibleSet.has(id) }
}
```

## 动态分辨率

帧率下降时自动降低渲染分辨率：

```typescript
class DynamicResolution {
  private currentScale = 1.0
  private history: number[] = []

  constructor(private targetFPS = 90, private minScale = 0.5, private maxScale = 1.0) {}

  recordFrameTime(ms: number) {
    this.history.push(ms)
    if (this.history.length > 30) this.history.shift()
  }

  update(): number {
    if (this.history.length < 10) return this.currentScale
    const avg = this.history.reduce((a, b) => a + b, 0) / this.history.length
    const target = 1000 / this.targetFPS
    if (avg > target * 1.1) this.currentScale = Math.max(this.minScale, this.currentScale - 0.02)
    else if (avg < target * 0.9) this.currentScale = Math.min(this.maxScale, this.currentScale + 0.01)
    return this.currentScale
  }

  apply(renderer: THREE.WebGLRenderer, baseW: number, baseH: number) {
    renderer.setSize(Math.round(baseW * this.currentScale), Math.round(baseH * this.currentScale), false)
  }
}
```

## 性能监控

```typescript
class VRPerformanceMonitor {
  private metrics = { fps: 0, frameTime: 0, drawCalls: 0, triangles: 0 }
  private buffer: number[] = []
  private lastTime = performance.now()

  update(renderer: THREE.WebGLRenderer) {
    const now = performance.now()
    const frameTime = now - this.lastTime; this.lastTime = now
    this.buffer.push(frameTime)
    if (this.buffer.length > 60) this.buffer.shift()
    this.metrics.fps = 1000 / (this.buffer.reduce((a, b) => a + b, 0) / this.buffer.length)
    this.metrics.frameTime = frameTime
    this.metrics.drawCalls = renderer.info.render.calls
    this.metrics.triangles = renderer.info.render.triangles
  }

  getMetrics() { return { ...this.metrics } }
}
```

## 常见误区

1. **只优化 GPU**：瓶颈可能在 CPU（draw call 过多），先用工具定位
2. **过度使用 LOD**：频繁切换会导致"弹跳"现象，在 VR 中更明显
3. **忽视纹理内存**：Quest 2 约 5GB GPU 内存，使用纹理压缩（ASTC/ETC2）
4. **用桌面标准衡量 VR**：60 FPS 在桌面流畅，在 VR 中会导致不适

## 工程建议

1. **性能预算先行**：项目初期设定三角形数、draw call、纹理内存上限
2. **Profile 优先**：用 Chrome DevTools / Oculus Performance Tool 定位瓶颈
3. **渐进式降级**：纹理 → 阴影 → 几何体 → 分辨率
4. **烘焙优先**：静态光照用 Lightmap，避免实时计算
5. **合批渲染**：相同材质合并 draw call，重复物体用 Instancing

## 小结

VR 性能优化的核心是**在 11ms/帧的预算内提供可接受的视觉质量**。本课介绍了四个关键技术：

- **注视点渲染**：降低周边区域的渲染分辨率
- **LOD**：根据距离和视角偏移动态调整模型精度
- **遮挡剔除**：跳过不可见物体的渲染
- **动态分辨率**：帧率压力下自动调整分辨率

记住：**VR 性能不是优化出来的，而是设计出来的**。

## 参考答案

### 练习一

**思路**：使用 `EXT_disjoint_timer_query_webgl2` 扩展，GPU 时间查询是异步的，需要多帧缓冲。

```typescript
class GPUTimer {
  private ext: any
  private pending: { query: WebGLQuery; callback: (ms: number) => void }[] = []
  private history: number[] = []

  constructor(private gl: WebGL2RenderingContext) {
    this.ext = gl.getExtension('EXT_disjoint_timer_query_webgl2')
  }

  begin() {
    if (!this.ext) return
    const query = this.gl.createQuery()!
    this.gl.beginQuery(this.ext.TIME_ELAPSED_EXT, query)
    this.pending.push({ query, callback: (ns) => {
      this.history.push(ns / 1_000_000)
      if (this.history.length > 60) this.history.shift()
    }})
  }

  end() { if (this.ext) this.gl.endQuery(this.ext.TIME_ELAPSED_EXT) }

  resolve() {
    if (!this.ext) return
    const disjoint = this.gl.getParameter(this.ext.GPU_DISJOINT_EXT)
    this.pending = this.pending.filter(p => {
      const available = this.gl.getQueryParameter(p.query, this.gl.QUERY_RESULT_AVAILABLE)
      if (available && !disjoint) {
        p.callback(this.gl.getQueryParameter(p.query, this.gl.QUERY_RESULT) as number)
        this.gl.deleteQuery(p.query); return false
      }
      return !available
    })
  }

  getAverage(): number {
    return this.history.length ? this.history.reduce((a, b) => a + b, 0) / this.history.length : 0
  }
}
```

### 练习二

**思路**：状态机管理降级等级，每级降级后冷却 2 秒再评估。

```typescript
class AutoDegradation {
  private tier = 0; private cooldown = 0; private fpsBuffer: number[] = []
  private tiers = [
    { name: 'Full Quality', apply: () => {} },
    { name: 'No Shadows', apply: (r: THREE.WebGLRenderer) => { r.shadowMap.enabled = false } },
    { name: 'Reduced Resolution', apply: (r: THREE.WebGLRenderer) => {
      r.setSize(r.domElement.width * 0.75, r.domElement.height * 0.75, false)
    }}
  ]

  constructor(private targetFPS = 90) {}

  recordFPS(fps: number) { this.fpsBuffer.push(fps); if (this.fpsBuffer.length > 60) this.fpsBuffer.shift() }

  update(dt: number, renderer: THREE.WebGLRenderer) {
    this.cooldown -= dt * 1000
    if (this.cooldown > 0 || this.fpsBuffer.length < 30) return
    const avg = this.fpsBuffer.reduce((a, b) => a + b, 0) / this.fpsBuffer.length
    if (avg < this.targetFPS * 0.9 && this.tier < this.tiers.length - 1) {
      this.tier++; this.tiers[this.tier].apply(renderer); this.cooldown = 2000; this.fpsBuffer = []
    } else if (avg > this.targetFPS * 1.1 && this.tier > 0) {
      this.tier--; this.cooldown = 2000; this.fpsBuffer = []
    }
  }
}
```
