# 阶段实战：第一个 3D 场景——从"能跑"到"能用"

## 当前项目状态

前 5 课建立了 3D 数学、坐标系、光照模型和开发环境。现在要做的不是"画一个立方体"，而是构建一个**工程化的 3D 场景骨架**——它要能作为后续所有 XR 项目的起点。

问题在于：Three.js 官方示例都是单文件 demo，放到真实项目里根本没法维护。你需要的是一个模块化的场景架构。

## 第一步：场景管理器

场景管理器是应用核心，负责初始化渲染器、管理渲染循环、协调子系统。关键设计决策：用回调列表而不是继承，让各子系统独立注册更新逻辑。

```typescript
import * as THREE from 'three'

class SceneManager {
  readonly renderer: THREE.WebGLRenderer
  readonly scene: THREE.Scene
  readonly camera: THREE.PerspectiveCamera
  private clock = new THREE.Clock()
  private updateCallbacks: ((dt: number) => void)[] = []

  constructor(container: HTMLElement) {
    this.renderer = new THREE.WebGLRenderer({ antialias: true })
    this.renderer.setSize(container.clientWidth, container.clientHeight)
    this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
    this.renderer.shadowMap.enabled = true
    this.renderer.shadowMap.type = THREE.PCFSoftShadowMap
    this.renderer.outputColorSpace = THREE.SRGBColorSpace
    this.renderer.toneMapping = THREE.ACESFilmicToneMapping
    container.appendChild(this.renderer.domElement)

    this.scene = new THREE.Scene()
    this.scene.background = new THREE.Color(0x87ceeb)

    this.camera = new THREE.PerspectiveCamera(
      60, container.clientWidth / container.clientHeight, 0.1, 100
    )

    window.addEventListener('resize', () => {
      this.camera.aspect = container.clientWidth / container.clientHeight
      this.camera.updateProjectionMatrix()
      this.renderer.setSize(container.clientWidth, container.clientHeight)
    })
  }

  onUpdate(callback: (dt: number) => void) {
    this.updateCallbacks.push(callback)
  }

  start() {
    this.renderer.setAnimationLoop(() => {
      const dt = this.clock.getDelta()
      for (const cb of this.updateCallbacks) cb(dt)
      this.renderer.render(this.scene, this.camera)
    })
  }
}
```

为什么用 `setAnimationLoop` 而不是 `requestAnimationFrame`？因为 WebXR 的帧循环需要和 XRSession 的 `requestAnimationFrame` 同步，`setAnimationLoop` 在 XR 模式下会自动切换。

## 第二步：轨道相机

用户需要拖拽旋转视角、滚轮缩放。核心是球坐标系管理相机位置：

```typescript
class OrbitCamera {
  private spherical = new THREE.Spherical(5, Math.PI / 3, 0)
  private target = new THREE.Vector3(0, 1, 0)
  private dragging = false
  private lastMouse = { x: 0, y: 0 }

  constructor(private camera: THREE.PerspectiveCamera, el: HTMLElement) {
    this.update()
    el.addEventListener('mousedown', (e) => {
      this.dragging = true
      this.lastMouse = { x: e.clientX, y: e.clientY }
    })
    el.addEventListener('mousemove', (e) => {
      if (!this.dragging) return
      this.spherical.theta -= (e.clientX - this.lastMouse.x) * 0.005
      this.spherical.phi = Math.max(0.1, Math.min(Math.PI - 0.1,
        this.spherical.phi - (e.clientY - this.lastMouse.y) * 0.005))
      this.lastMouse = { x: e.clientX, y: e.clientY }
      this.update()
    })
    el.addEventListener('mouseup', () => this.dragging = false)
    el.addEventListener('wheel', (e) => {
      this.spherical.radius = Math.max(1, Math.min(20,
        this.spherical.radius + e.deltaY * 0.01))
      this.update()
    })
  }

  private update() {
    const pos = new THREE.Vector3().setFromSpherical(this.spherical)
    this.camera.position.copy(this.target).add(pos)
    this.camera.lookAt(this.target)
  }
}
```

`phi` 限制在 `0.1 ~ π-0.1` 是为了防止相机翻转到地面以下——这在 XR 项目中会导致眩晕。

## 第三层：光照系统

三层光照：环境光（基础照明）+ 方向光（模拟太阳，产生阴影）+ 半球光（天空反射）。XR 中没有阴影的物体会"飘"在空中，破坏沉浸感。

```typescript
function setupLighting(scene: THREE.Scene) {
  scene.add(new THREE.AmbientLight(0x404040, 0.5))

  const sun = new THREE.DirectionalLight(0xffffff, 1.2)
  sun.position.set(10, 15, 10)
  sun.castShadow = true
  sun.shadow.mapSize.set(2048, 2048)
  const d = 15
  sun.shadow.camera.left = -d
  sun.shadow.camera.right = d
  sun.shadow.camera.top = d
  sun.shadow.camera.bottom = -d
  sun.shadow.bias = -0.001
  scene.add(sun)

  scene.add(new THREE.HemisphereLight(0x87ceeb, 0x362e1a, 0.4))
  return sun
}
```

阴影贴图分辨率 2048×2048 是性能和质量的平衡点。XR 中每帧都要渲染两次（左右眼），阴影计算成本翻倍，不能设太高。

## 第四步：射线交互

鼠标点击和悬停反馈通过射线检测实现。关键设计：InputManager 只负责检测命中，交互响应由物体自己处理。

```typescript
interface Interactable {
  mesh: THREE.Object3D
  onSelect?(): void
  onHover?(hovering: boolean): void
}

class InputManager {
  private raycaster = new THREE.Raycaster()
  private mouse = new THREE.Vector2()
  private items: Interactable[] = []
  private hovered: Interactable | null = null

  constructor(private renderer: THREE.WebGLRenderer,
              private camera: THREE.PerspectiveCamera) {
    const el = renderer.domElement
    el.addEventListener('click', () => {
      this.updateMouse(event as MouseEvent)
      this.hitTest()?.onSelect?.()
    })
    el.addEventListener('mousemove', (e) => {
      this.updateMouse(e)
      const hit = this.hitTest()
      if (this.hovered && this.hovered !== hit) {
        this.hovered.onHover?.(false)
        el.style.cursor = 'default'
      }
      if (hit && hit !== this.hovered) {
        hit.onHover?.(true)
        el.style.cursor = 'pointer'
      }
      this.hovered = hit
    })
  }

  register(item: Interactable) { this.items.push(item) }

  private updateMouse(e: MouseEvent) {
    const r = this.renderer.domElement.getBoundingClientRect()
    this.mouse.x = ((e.clientX - r.left) / r.width) * 2 - 1
    this.mouse.y = -((e.clientY - r.top) / r.height) * 2 + 1
  }

  private hitTest(): Interactable | null {
    this.raycaster.setFromCamera(this.mouse, this.camera)
    const hits = this.raycaster.intersectObjects(
      this.items.map(i => i.mesh), true
    )
    if (!hits.length) return null
    return this.items.find(i =>
      i.mesh === hits[0].object || i.mesh.children.includes(hits[0].object)
    ) ?? null
  }
}
```

## 你可能踩的坑

**坑一：所有代码写在一个文件里**

3D 应用复杂度增长快。SceneManager、OrbitCamera、InputManager 从一开始就要分开，后面加 XR 支持时不用重构。

**坑二：Three.js 默认配置就够用**

`SRGBColorSpace` + `ACESFilmicToneMapping` 画质提升明显，不开启的话颜色会偏灰。这两个配置在 XR 中尤其重要——头显的屏幕色域和普通显示器不同。

**坑三：不监控 draw call**

`renderer.info.render.calls` 和 `renderer.info.render.triangles` 从开发初期就要看。XR 要求 90fps，一个 draw call 超标就能让帧率崩掉。

## 练习

### 练习一：呼吸动画

在 `engine.onUpdate` 中为立方体添加 Y 轴呼吸动画：周期 2 秒，幅度 5%，各立方体相位错开。完成后用性能监控面板确认帧率没有下降。

### 练习二：添加一个可拖拽的物体

创建一个新的 3D 物体（球体或圆柱体），实现鼠标拖拽移动。提示：在 mousedown 时记录选中物体，mousemove 时用射线与地面平面求交更新位置，mouseup 时释放。

## 参考答案

### 练习一

```typescript
let time = 0
engine.onUpdate((dt) => {
  time += dt
  engine.scene.children.forEach((child, i) => {
    if (child instanceof THREE.Mesh && child.geometry.type === 'BoxGeometry') {
      const phase = time * Math.PI + i * 0.5
      child.scale.y = 1 + Math.sin(phase) * 0.05
    }
  })
})
```

幅度 0.05 足够明显但不夸张。相位用 `i * 0.5` 让各立方体节奏不同步，视觉更自然。

### 练习二

```typescript
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(0.3, 32, 32),
  new THREE.MeshStandardMaterial({ color: 0xff6b6b })
)
sphere.position.set(0, 0.3, 1)
sphere.castShadow = true
engine.scene.add(sphere)

let dragging = false
const plane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0)
const intersectPoint = new THREE.Vector3()

engine.renderer.domElement.addEventListener('mousemove', (e) => {
  if (!dragging) return
  const raycaster = new THREE.Raycaster()
  const rect = engine.renderer.domElement.getBoundingClientRect()
  const mouse = new THREE.Vector2(
    ((e.clientX - rect.left) / rect.width) * 2 - 1,
    -((e.clientY - rect.top) / rect.height) * 2 + 1
  )
  raycaster.setFromCamera(mouse, engine.camera)
  if (raycaster.ray.intersectPlane(plane, intersectPoint)) {
    sphere.position.x = intersectPoint.x
    sphere.position.z = intersectPoint.z
  }
})

input.register({
  mesh: sphere,
  onSelect() { dragging = !dragging }
})
```
