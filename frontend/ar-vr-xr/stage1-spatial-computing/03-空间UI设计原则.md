# 03 - 空间 UI 设计原则

## 场景引入

你把一个传统网页表单"放进" VR 空间里，用户盯着悬浮的输入框，用手柄激光指针点击虚拟键盘。10 分钟后用户摘下头显说："太累了。"

问题不在于代码，而在于**你用了 2D 设计思维做 3D 产品**。空间 UI 不是把 2D 界面搬到 3D 空间，而是一种完全不同的交互范式。

## 学习目标

- 理解 3D 交互与 2D 交互的本质区别
- 掌握空间 UI 的布局、尺度和深度设计原则
- 了解手势交互的设计规范
- 掌握避免用户疲劳和眩晕的舒适度设计

## 3D 交互 vs 2D 交互

2D 交互的输入是**二维点**（鼠标位置），空间交互的输入是**三维射线**（手的指向、视线方向）。这导致交互检测方式完全不同。

```typescript
import * as THREE from 'three'

// 2D 交互：点在矩形内
function isPointInRect(point: { x: number; y: number }, rect: DOMRect): boolean {
  return point.x >= rect.left && point.x <= rect.right &&
         point.y >= rect.top && point.y <= rect.bottom
}

// 3D 交互：射线与物体相交
function checkInteraction(
  origin: THREE.Vector3,
  direction: THREE.Vector3,
  targets: THREE.Object3D[]
): THREE.Intersection | null {
  const raycaster = new THREE.Raycaster()
  raycaster.set(origin, direction.normalize())
  const hits = raycaster.intersectObjects(targets, true)
  return hits.length > 0 ? hits[0] : null
}
```

| 维度 | 2D 交互 | 3D 空间交互 |
|------|---------|------------|
| 输入 | 2D 点 | 3D 射线 |
| 选择精度 | 像素级 | 射线指向（有误差） |
| 反馈 | 鼠标悬停 | 视线高亮、手势确认 |
| 疲劳度 | 低（手臂有支撑） | 高（手臂悬空） |

## 空间布局原则

### 原则一：舒适视区优先

人眼的舒适视区是一个约 60° 锥形区域（中心视线左右各 30°，上下各 15°）。重要内容必须放在这个区域内。

```typescript
function isInComfortZone(
  headPosition: THREE.Vector3,
  headForward: THREE.Vector3,
  targetPosition: THREE.Vector3,
  hLimit: number = 30,
  vLimit: number = 15
): boolean {
  const dir = targetPosition.clone().sub(headPosition).normalize()
  const hAngle = Math.acos(
    new THREE.Vector2(dir.x, dir.z).normalize()
      .dot(new THREE.Vector2(headForward.x, headForward.z).normalize())
  ) * (180 / Math.PI)
  const vAngle = Math.asin(dir.y) * (180 / Math.PI)
  return hAngle <= hLimit && Math.abs(vAngle) <= vLimit
}
```

### 原则二：深度层次分明

UI 元素需要在不同深度层上组织，避免层次混乱。

```typescript
const DEPTH_LAYERS = {
  INTERACTIVE: 0.5,   // 0.5 米：按钮、滑块
  INFORMATION: 1.5,   // 1.5 米：面板、卡片
  ENVIRONMENT: 5.0,   // 5 米以上：背景、装饰
} as const

function createUIPanel(
  width: number,
  height: number,
  layer: keyof typeof DEPTH_LAYERS
): THREE.Mesh {
  const geometry = new THREE.PlaneGeometry(width, height)
  const material = new THREE.MeshStandardMaterial({
    color: 0xffffff,
    transparent: true,
    opacity: 0.9,
    side: THREE.DoubleSide
  })
  const panel = new THREE.Mesh(geometry, material)
  panel.position.z = -DEPTH_LAYERS[layer]
  return panel
}
```

### 原则三：避免信息过载

3D 空间比 2D 屏幕大得多，但用户注意力有限。同一视野内活跃的交互元素不超过 5-7 个，超出部分用分组或空间分页管理。

## 手势交互设计

XR 中的基础手势：捏合（Pinch）、抓握（Grab）、戳点（Poke）、指向（Point）。

```typescript
interface HandData {
  joints: Map<string, THREE.Vector3>
  confidence: number
}

function detectPinch(hand: HandData): boolean {
  const thumb = hand.joints.get('thumb-tip')
  const index = hand.joints.get('index-tip')
  if (!thumb || !index) return false
  return thumb.distanceTo(index) < 0.02 // 2cm 以内
}
```

手势设计原则：

1. **大手势优先于小手势**：手部追踪精度 ±5mm，触发区域应比阈值大 2-3 倍
2. **明确的开始和结束**：手势需要"按下"和"释放"语义
3. **视觉反馈必须即时**：没有反馈的手势让用户不确定系统是否收到操作

```typescript
class GestureStateMachine {
  private state: 'idle' | 'triggered' | 'active' = 'idle'

  update(detected: boolean, onActivate: () => void, onRelease: () => void): void {
    switch (this.state) {
      case 'idle':
        if (detected) { this.state = 'triggered'; onActivate() }
        break
      case 'triggered':
        this.state = 'active' // 等一帧确认，避免抖动
        break
      case 'active':
        if (!detected) { this.state = 'idle'; onRelease() }
        break
    }
  }
}
```

## 舒适度设计

### 避免眩晕

XR 眩晕的主要原因是**视觉与前庭系统不一致**。触发因素：

1. **头部追踪延迟** > 20ms → 立即眩晕
2. **强制移动**：用户没动但视角被平移 → 眩晕
3. **帧率不稳定** → 轻度不适累积

传送移动是避免眩晕的标准方案：

```typescript
async function teleport(
  userRig: THREE.Group,
  target: THREE.Vector3,
  fadeOverlay: THREE.Mesh
): Promise<void> {
  const mat = fadeOverlay.material as THREE.MeshBasicMaterial

  // 淡出
  await animateOpacity(mat, 0, 1, 150)
  // 移动（保持头部高度）
  userRig.position.set(target.x, userRig.position.y, target.z)
  // 淡入
  await animateOpacity(mat, 1, 0, 150)
}

function animateOpacity(mat: THREE.MeshBasicMaterial, from: number, to: number, ms: number): Promise<void> {
  return new Promise(resolve => {
    const t0 = performance.now()
    const tick = () => {
      const p = Math.min((performance.now() - t0) / ms, 1)
      mat.opacity = from + (to - from) * p
      p < 1 ? requestAnimationFrame(tick) : resolve()
    }
    tick()
  })
}
```

### 避免疲劳

手臂悬空超过 30 秒就会疲劳。UI 应在手臂自然伸展范围内（约 60cm），并略低于视线高度以减少颈部疲劳。

```typescript
function isInArmReach(shoulder: THREE.Vector3, target: THREE.Vector3): boolean {
  return shoulder.distanceTo(target) <= 0.6
}
```

## 空间 UI 组件

### 面板

空间面板需要始终面向用户（Billboard 模式）：


### 按钮

3D 按钮需要明确的"可交互"视觉提示和按压反馈：

```typescript
function createSpatialButton(): THREE.Group {
  const group = new THREE.Group()
  const base = new THREE.Mesh(
    new THREE.BoxGeometry(0.15, 0.06, 0.02),
    new THREE.MeshStandardMaterial({ color: 0x4a90d9, roughness: 0.2 })
  )
  group.add(base)

  group.userData.onPress = () => {
    base.position.z = -0.005
    base.material.color.setHex(0x3a7bc8)
  }
  group.userData.onRelease = () => {
    base.position.z = 0
    base.material.color.setHex(0x4a90d9)
  }
  return group
}
```

## 常见误区

1. **"把 2D 界面直接放进 3D 空间"** —— 3D 空间需要考虑深度、视角、手臂可达性，设计思路完全不同
2. **"手势越多越好"** —— 手势越多误触发越高，大多数应用只需 2-3 种基础手势
3. **"3D 空间可以放更多内容"** —— 用户注意力和舒适视区有限，过多内容导致认知过载

## 工程建议

1. 从 2D 原型开始，画出舒适视区和深度层次，再进入 3D 实现
2. 用真实尺度设计，1 米在 VR 中就是 1 米，不要用像素思维
3. 每种手势都必须有视觉反馈，哪怕是简单的高亮变化
4. 至少支持传送和平滑移动两种方式，让用户选择
5. 真机测试舒适度，模拟器无法评估眩晕感

## 小结

- **交互范式**：从 2D 点到 3D 射线，空间交互需要全新设计思维
- **布局原则**：舒适视区（60° 锥形）、深度层次、信息密度控制
- **手势设计**：大手势优先、明确的开始/结束、视觉反馈
- **舒适度**：避免眩晕（传送移动）、避免疲劳（手臂可达性）

## 参考答案

### 练习一

**思路**：计算面板相对于头部的水平偏角和垂直偏角，判断是否在 ±30° / ±15° 范围内。

**答案**：
```typescript
import * as THREE from 'three'

const head = new THREE.Vector3(0, 1.6, 0)
const forward = new THREE.Vector3(0, 0, -1)
const panel = new THREE.Vector3(1.5, 1.6, -2)

const dir = panel.clone().sub(head) // (1.5, 0, -2)

// 水平偏角
const hDir = new THREE.Vector2(dir.x, dir.z)
const fDir = new THREE.Vector2(forward.x, forward.z)
const hAngle = hDir.angleTo(fDir) * (180 / Math.PI) // ≈ 36.9°

// 垂直偏角
const vAngle = Math.atan2(dir.y, Math.sqrt(dir.x ** 2 + dir.z ** 2)) * (180 / Math.PI) // 0°

const inComfort = hAngle <= 30 && Math.abs(vAngle) <= 15
console.log(`水平: ${hAngle.toFixed(1)}°, 垂直: ${vAngle.toFixed(1)}°, 舒适区内: ${inComfort}`)
// 水平 36.9° > 30°，不在舒适视区内
```

**要点**：
- 水平偏角超过 30° 时用户需要转头，长期使用会疲劳
- 解决方案：将面板移到 `(1.0, 1.6, -2)` 或更近位置
- 实际应用中 UI 应跟随头部运动，而不是固定在世界空间

### 练习二

**思路**：射线检测地面交点 → 淡出 → 移动 → 淡入。

**答案**：
```typescript
import * as THREE from 'three'

class TeleportSystem {
  private raycaster = new THREE.Raycaster()
  private ground: THREE.Mesh
  private fadeMat: THREE.MeshBasicMaterial

  constructor(scene: THREE.Scene, private rig: THREE.Group) {
    this.ground = new THREE.Mesh(
      new THREE.PlaneGeometry(50, 50),
      new THREE.MeshStandardMaterial({ color: 0x808080 })
    )
    this.ground.rotation.x = -Math.PI / 2
    scene.add(this.ground)

    const fade = new THREE.Mesh(
      new THREE.PlaneGeometry(2, 2),
      new THREE.MeshBasicMaterial({ color: 0, transparent: true, opacity: 0, depthTest: false })
    )
    fade.position.z = -0.5
    fade.renderOrder = 999
    this.fadeMat = fade.material
    rig.add(fade)
  }

  findTarget(camera: THREE.Camera): THREE.Vector3 | null {
    this.raycaster.setFromCamera(new THREE.Vector2(0, 0), camera)
    const hits = this.raycaster.intersectObject(this.ground)
    return hits.length > 0 ? hits[0].point : null
  }

  async teleport(target: THREE.Vector3): Promise<void> {
    await this.fade(0, 1, 150)
    this.rig.position.set(target.x, this.rig.position.y, target.z)
    await this.fade(1, 0, 150)
  }

  private fade(from: number, to: number, ms: number): Promise<void> {
    return new Promise(r => {
      const t0 = performance.now()
      const tick = () => {
        const p = Math.min((performance.now() - t0) / ms, 1)
        this.fadeMat.opacity = from + (to - from) * p
        p < 1 ? requestAnimationFrame(tick) : r()
      }
      tick()
    })
  }
}
```

**要点**：
- 淡入淡出是关键，瞬间移动会产生眩晕
- 保持用户高度不变，只改变 XZ 位置
- 实际项目中还需检测目标位置是否有障碍物

**常见错误写法**：直接 `userRig.position.copy(target)` 不做淡入淡出。视觉突变会让大脑无法处理空间跳转，产生不适。
