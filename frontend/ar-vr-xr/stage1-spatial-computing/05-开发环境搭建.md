# 05 - 开发环境搭建

## 场景引入

你决定用 WebXR + Three.js 开发第一个 XR 应用。`npm install three`，写了简单场景，点击"进入 VR"——什么都没发生。浏览器没有检测到 VR 设备，控制台报错 `navigator.xr is undefined`。

问题不在于代码，而是 WebXR 对运行环境有严格要求：HTTPS、浏览器支持、设备连接。本课帮你系统搭建 XR 开发环境。

## 学习目标

- 了解主流 XR 开发工具链（Unity、Unreal、WebXR）
- 搭建 WebXR + Three.js 开发环境
- 配置本地 HTTPS 开发服务器
- 掌握 XR 设备的调试方法

## XR 开发工具链对比

### Unity + XR Interaction Toolkit

优势：可视化编辑器、XR Interaction Toolkit 标准组件、一键发布多平台、Asset Store 资源丰富。
劣势：C# 学习曲线（对前端团队）、编译迭代慢、包体大。
适用：高质量游戏、复杂交互应用、需要原生性能的场景。

### Unreal Engine + OpenXR

优势：最强渲染能力（Nanite、Lumen）、蓝图系统降低门槛。
劣势：C++ 门槛高、编辑器资源消耗大、XR 生态不如 Unity。
适用：高画质 VR 体验、建筑可视化。

### WebXR + Three.js / Babylon.js

优势：TypeScript 零学习成本、热重载即时生效、天然跨平台、部署简单。
劣势：性能上限低于原生、WebXR API 较底层、部分设备功能缺失。
适用：展示型应用、协作工具、原型验证、前端团队入门。

## WebXR + Three.js 环境搭建

### 创建项目

```bash
# 前置：Node.js 18+
npm create vite@latest my-xr-app -- --template vanilla-ts
cd my-xr-app
npm install three
npm install -D @types/three @vitejs/plugin-basic-ssl
```

### 配置 HTTPS

WebXR 要求安全上下文（HTTPS 或 localhost）。手机/头显通过局域网访问必须配置 HTTPS。

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import basicSsl from '@vitejs/plugin-basic-ssl'

export default defineConfig({
  plugins: [basicSsl()],
  server: {
    host: '0.0.0.0', // 允许局域网访问
    port: 3000
  }
})
```

### 基础 WebXR 项目

```typescript
// src/main.ts
import * as THREE from 'three'
import { VRButton } from 'three/addons/webxr/VRButton.js'

const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(window.innerWidth, window.innerHeight)
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
renderer.xr.enabled = true
document.body.appendChild(renderer.domElement)
document.body.appendChild(VRButton.createButton(renderer))

const scene = new THREE.Scene()
scene.background = new THREE.Color(0x505050)

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000)

// 地面
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(20, 20),
  new THREE.MeshStandardMaterial({ color: 0x808080 })
)
ground.rotation.x = -Math.PI / 2
scene.add(ground)

// 测试立方体
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(0.5, 0.5, 0.5),
  new THREE.MeshStandardMaterial({ color: 0x00ff00 })
)
cube.position.set(0, 1, -1.5)
scene.add(cube)

// 光照
scene.add(new THREE.AmbientLight(0x404040))
const dirLight = new THREE.DirectionalLight(0xffffff, 1)
dirLight.position.set(5, 10, 5)
scene.add(dirLight)

// 渲染循环
renderer.setAnimationLoop(() => {
  renderer.render(scene, camera)
})

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(window.innerWidth, window.innerHeight)
})
```

## WebXR 模拟器

没有 XR 设备也能开发调试。推荐 **WebXR API Emulator** 浏览器扩展。

1. Chrome/Edge 扩展商店搜索 "WebXR API Emulator"
2. 安装后开发者工具中出现 "WebXR" 标签
3. 可模拟头显位置、手柄输入

```typescript
// 检测是否在模拟器中
function isSimulator(): boolean {
  return !navigator.xr?.isSessionSupported('immersive-vr')
}

if (isSimulator()) {
  console.log('⚠️ WebXR 模拟器环境，部分功能可能行为不同')
}
```

WebXR 远程日志：

```typescript
class RemoteLogger {
  private ws: WebSocket | null = null

  connect(url: string) {
    this.ws = new WebSocket(url)
    this.ws.onopen = () => console.log('远程日志已连接')
  }

  log(message: string, data?: unknown) {
    console.log(message, data)
    this.ws?.send(JSON.stringify({ timestamp: Date.now(), message, data }))
  }
}

const logger = new RemoteLogger()
logger.connect('ws://localhost:8080/logs')
```

## 常见误区

1. **"没有头显就不能开发 XR"** —— WebXR 模拟器可模拟大部分功能，用模拟器开发 + 真机最终测试效率最高
2. **"本地 HTTP 就够了"** —— WebXR 要求安全上下文，非 localhost 必须 HTTPS
3. **"Unity 和 WebXR 只能选一个"** —— 可以结合：Unity 做核心体验，WebXR 做原型和跨平台分发

## 工程建议

1. 前端团队从 WebXR 开始，学习成本最低、迭代最快
2. 配置好 HTTPS 开发服务器，这是 WebXR 硬性要求
3. 安装 WebXR 模拟器，没有设备也能开发 80% 功能
4. 用 `renderer.info` 监控性能，从第一行代码就关注
5. 建立真机测试流程，每周至少在真实设备上测试一次

## 小结

- **工具链选择**：Unity（主流原生）、Unreal（高画质）、WebXR（前端友好）
- **WebXR 环境**：Vite + Three.js + HTTPS + WebXR 模拟器
- **Unity 环境**：Unity LTS + XR Plugin Management + OpenXR
- **调试方法**：ADB 命令、远程日志、WebXR 模拟器

### 练习二

**答案**：
```typescript
// 立方体始终在用户前方（跟随视线）
renderer.setAnimationLoop(() => {
  const dir = new THREE.Vector3(0, 0, -2).applyQuaternion(camera.quaternion)
  cube.position.copy(camera.position).add(dir)
  cube.lookAt(camera.position)
  renderer.render(scene, camera)
})
```

**要点**：WebXR API Emulator 在开发者工具中提供 3D 场景可拖动模拟头显，输入与真实设备一致。真机测试时注意模拟器没有位置追踪精度限制。

**常见错误写法**：在非 HTTPS 环境下运行。WebXR API 在非安全上下文中不可用，`navigator.xr` 为 `undefined`。
