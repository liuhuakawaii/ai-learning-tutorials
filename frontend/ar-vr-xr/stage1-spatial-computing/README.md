# Stage 1：空间计算基础

## 阶段概述

本阶段是 AR/VR/XR 开发的入门基础，共 6 课时。我们从空间计算的行业全景出发，复习必要的 3D 数学知识，建立空间 UI 设计思维，理解 XR 应用的性能硬约束，搭建开发环境，最终完成第一个可运行的 3D 场景。

这个阶段不急于进入某个平台 SDK，而是先建立**通用基础**——无论你后续选择 Unity、Unreal 还是 WebXR，这些知识都是共通的。

## 学习目标

完成本阶段后，你将能够：

1. **区分 AR/VR/MR/XR 的技术边界**，了解主流设备生态和市场格局
2. **运用 3D 数学基础**——坐标系、变换矩阵、四元数——进行空间计算
3. **理解空间 UI 设计原则**，包括手势交互、舒适度设计和空间布局
4. **掌握 XR 性能约束**——帧率、延迟、渲染预算——并知道如何衡量
5. **搭建 XR 开发环境**，选择适合项目的工具链
6. **用 Three.js 构建第一个 3D 场景**，包含相机、光照和基础物体
