# 跨平台开发

## 场景引入

你的空间应用在 Meta Quest 上运行完美——手势交互流畅、渲染帧率稳定、空间锚点精准。产品经理说："下周要上 Apple Vision Pro。" 你打开项目，发现手部追踪 API 完全不同、渲染管线需要适配、空间锚点格式不兼容。

这就是空间计算跨平台开发的核心痛点：**每个平台的交互范式、渲染能力、空间 API 都不同**。直接移植代码几乎不可行，必须在架构层面做好抽象。

本课将讲解如何用 Unity 构建跨平台空间应用，以及 WebXR 作为"最大公约数"的兼容性方案。

## 学习目标

1. 理解空间计算跨平台开发的核心挑战
2. 掌握 Unity XR Interaction Toolkit 的平台抽象机制
3. 学会使用 WebXR 实现浏览器端的空间应用
4. 理解不同平台的性能差异与适配策略
5. 能够设计一个支持多平台的空间应用架构

## 一、跨平台挑战分析

### 1.1 平台差异矩阵

| 维度 | Meta Quest | Apple Vision Pro | HoloLens 2 | WebXR |
|------|-----------|-----------------|------------|-------|
| 交互方式 | 手柄 + 手势 | 纯手势 + 眼动 | 手势 + 语音 | 手柄 + 手势 |
| 渲染管线 | URP | Metal | URP | WebGL 2.0 |
| 空间锚点 | Spatial Anchor | World Anchor | Spatial Anchor | Anchor API |
| 最大面数 | ~500K | ~1M | ~300K | ~200K |
| 帧率要求 | 72/90/120 fps | 90 fps | 60 fps | 60+ fps |
| 空间感知 | Passthrough + Mesh | Scene Understanding | Spatial Mapping | Hit Test |

### 1.2 架构分层策略

```
┌──────────────────────────────────────┐
│  应用层：业务逻辑、UI、场景管理        │  ← 平台无关
├──────────────────────────────────────┤
│  交互层：输入抽象、手势映射、UI 交互    │  ← 平台适配
├──────────────────────────────────────┤
│  渲染层：材质适配、LOD 策略、后处理     │  ← 平台适配
├──────────────────────────────────────┤
│  平台层：XR SDK、空间 API、传感器      │  ← 平台特定
└──────────────────────────────────────┘
```

核心原则：**应用层平台无关，平台层通过接口隔离**。

## 二、Unity 跨平台架构

### 2.1 输入抽象层

使用接口隔离不同平台的输入实现：

```csharp
public interface ISpatialInput
{
    // 手部追踪
    bool TryGetHandPose(HandType hand, out Pose pose);
    bool IsPinching(HandType hand);
    bool IsGrabbing(HandType hand);

    // 眼动追踪（可选）
    bool TryGetGazePose(out Pose gazePose);

    // 控制器（可选）
    bool TryGetControllerPose(HandType hand, out Pose pose);

}
```

### 2.2 平台输入实现

**Meta Quest 实现**：

```csharp
using UnityEngine.XR.Hands;
using UnityEngine.XR.Interaction.Toolkit;

public class QuestSpatialInput : ISpatialInput
{
    private XRHandSubsystem handSubsystem;

    public QuestSpatialInput()
    {
        var subsystems = new List<XRHandSubsystem>();
        SubsystemManager.GetSubsystems(subsystems);
        handSubsystem = subsystems.FirstOrDefault();
    }

    public bool TryGetHandPose(HandType hand, out Pose pose)
    {
        if (handSubsystem == null)
        {
            pose = Pose.identity;
            return false;
        }

        var xrHand = hand == HandType.Left
            ? handSubsystem.leftHand
            : handSubsystem.rightHand;

        if (xrHand.GetJoint(XRHandJointID.IndexTip).TryGetPose(out pose))
        {
            return true;
        }
        pose = Pose.identity;
        return false;
    }

    public bool IsPinching(HandType hand)
    {
        var xrHand = hand == HandType.Left
            ? handSubsystem.leftHand
            : handSubsystem.rightHand;

        if (xrHand.GetJoint(XRHandJointID.ThumbTip).TryGetPose(out var thumb) &&
            xrHand.GetJoint(XRHandJointID.IndexTip).TryGetPose(out var index))
        {
            return Vector3.Distance(thumb.position, index.position) < 0.02f;
        }
        return false;
    }

    public bool IsGrabbing(HandType hand)
    {
        // 握拳检测：所有指尖到掌心的距离小于阈值
        var xrHand = hand == HandType.Left
            ? handSubsystem.leftHand
            : handSubsystem.rightHand;

        if (!xrHand.GetJoint(XRHandJointID.Palm).TryGetPose(out var palm))
            return false;

        float avgDistance = 0;
        int count = 0;
        foreach (var finger in new[] {
            XRHandJointID.IndexTip,
            XRHandJointID.MiddleTip,
            XRHandJointID.RingTip,
            XRHandJointID.LittleTip
        })
        {
            if (xrHand.GetJoint(finger).TryGetPose(out var tip))
            {
                avgDistance += Vector3.Distance(palm.position, tip.position);
                count++;
            }
        }
        return count > 0 && (avgDistance / count) < 0.05f;
    }

    public bool TryGetGazePose(out Pose gazePose)
    {
        gazePose = Pose.identity;
        return false; // Quest 不支持原生眼动
    }

    public bool TryGetControllerPose(HandType hand, out Pose pose)
    {
        var device = hand == HandType.Left
            ? InputDevices.GetDeviceAtXRNode(XRNode.LeftHand)
            : InputDevices.GetDeviceAtXRNode(XRNode.RightHand);

        if (device.TryGetFeatureValue(CommonUsages.devicePosition, out var pos) &&
            device.TryGetFeatureValue(CommonUsages.deviceRotation, out var rot))
        {
            pose = new Pose(pos, rot);
            return true;
        }
        pose = Pose.identity;
        return false;
    }

    public float GetTriggerValue(HandType hand)
    {
        var device = hand == HandType.Left
            ? InputDevices.GetDeviceAtXRNode(XRNode.LeftHand)
            : InputDevices.GetDeviceAtXRNode(XRNode.RightHand);

        device.TryGetFeatureValue(CommonUsages.trigger, out float value);
        return value;
    }
}
```

```csharp
public class VisionProSpatialInput : ISpatialInput
{
    public bool TryGetHandPose(HandType hand, out Pose pose)
    {
        // Vision Pro 使用 ARKit Hand Tracking
        // 通过 Unity PolySpatial 包访问
        #if UNITY_VISIONOS
        var provider = hand == HandType.Left
            ? HandTracking.leftHand
            : HandTracking.rightHand;

        if (provider.isTracked)
        {
            pose = new Pose(provider.indexTip.position, provider.indexTip.rotation);
            return true;
        }
        #endif
        pose = Pose.identity;
        return false;
    }

    public bool IsPinching(HandType hand)
    {
        #if UNITY_VISIONOS
        var provider = hand == HandType.Left
            ? HandTracking.leftHand
            : HandTracking.rightHand;
        return provider.pinch > 0.7f;
        #endif
        return false;
    }

    public bool TryGetGazePose(out Pose gazePose)
    {
        #if UNITY_VISIONOS
        if (EyeTracking.isTracking)
        {
            gazePose = new Pose(EyeTracking.fixationPoint, EyeTracking.lookRotation);
            return true;
        }
        #endif
        gazePose = Pose.identity;
        return false;
    }

    // Vision Pro 不支持控制器
    public bool IsGrabbing(HandType hand) => IsPinching(hand);
    public bool TryGetControllerPose(HandType hand, out Pose pose)
    { pose = Pose.identity; return false; }
    public float GetTriggerValue(HandType hand) => IsPinching(hand) ? 1f : 0f;
}
```

## 三、渲染适配

### 3.1 自适应 LOD 策略

```csharp
public class AdaptiveLODManager : MonoBehaviour
{
    [System.Serializable]
    public class LODProfile
    {
        public string platformName;
        public int maxTriangles;
        public int maxDrawCalls;
        public float targetFrameRate;
        public ShadowQuality shadowQuality;
    }

    [SerializeField] private List<LODProfile> profiles;

    private LODProfile currentProfile;

    void Start()
    {
        currentProfile = GetProfileForPlatform();
        ApplyProfile(currentProfile);
    }

    private LODProfile GetProfileForPlatform()
    {
        #if UNITY_ANDROID
        return profiles.Find(p => p.platformName == "Quest");
        #elif UNITY_VISIONOS
        return profiles.Find(p => p.platformName == "VisionPro");
        #elif UNITY_WEBGL
        return profiles.Find(p => p.platformName == "WebXR");
        #else
        return profiles.Find(p => p.platformName == "Default");
        #endif
    }

    private void ApplyProfile(LODProfile profile)
    {
        QualitySettings.shadowCascades = profile.shadowQuality == ShadowQuality.All ? 4 : 0;
        QualitySettings.shadows = profile.shadowQuality;

        // 动态调整 LOD 切换距离
        var lodGroups = FindObjectsOfType<LODGroup>();
        foreach (var lodGroup in lodGroups)
        {
            float scaleFactor = (float)profile.maxTriangles / 500000f;
            var lods = lodGroup.GetLODs();
            for (int i = 0; i < lods.Length; i++)
            {
                lods[i].screenRelativeTransitionHeight *= scaleFactor;
            }
            lodGroup.SetLODs(lods);
        }
    }
}
```

## 四、WebXR 兼容性方案

### 4.1 WebXR 基础架构

WebXR 是浏览器端的空间计算标准，优势是零安装、跨设备，但功能受限。

```javascript
// WebXR 会话管理
class WebXRSessionManager {
  constructor() {
    this.session = null;
    this.xrRefSpace = null;
  }

  async init() {
    if (!navigator.xr) {
      throw new Error('WebXR 不可用');
    }

    // 检查支持的特性
    const isARSupported = await navigator.xr.isSessionSupported('immersive-ar');
    const isVRSupported = await navigator.xr.isSessionSupported('immersive-vr');

    return { isARSupported, isVRSupported };
  }

  async startSession(mode = 'immersive-ar', features = []) {
    const requiredFeatures = ['local-floor'];
    const optionalFeatures = ['hand-tracking', 'hit-test', 'anchors', ...features];

    this.session = await navigator.xr.requestSession(mode, {
      requiredFeatures,
      optionalFeatures
    });

    this.xrRefSpace = await this.session.requestReferenceSpace('local-floor');

    return this.session;
  }

  onFrame(callback) {
    if (!this.session) return;

    const onFrame = (time, frame) => {
      this.session.requestAnimationFrame(onFrame);
      callback(time, frame);
    };
    this.session.requestAnimationFrame(onFrame);
  }
}
```

### 4.2 WebXR 手势识别

```javascript
class WebXRHandTracker {
  constructor(session) {
    this.session = session;
    this.handData = { left: null, right: null };
  }

  update(frame, refSpace) {
    for (const inputSource of this.session.inputSources) {
      if (inputSource.hand) {
        const hand = inputSource.handedness; // 'left' or 'right'
        const joints = {};

        for (const [jointName, jointSpace] of inputSource.hand.entries()) {
          const pose = frame.getJointPose(jointSpace, refSpace);
          if (pose) {
            joints[jointName] = {
              position: [pose.transform.position.x,
                         pose.transform.position.y,
                         pose.transform.position.z],
              orientation: [pose.transform.orientation.x,
                            pose.transform.orientation.y,
                            pose.transform.orientation.z,
                            pose.transform.orientation.w],
              radius: pose.radius
            };
          }
        }

        this.handData[hand] = joints;
      }
    }

    return this.handData;
  }

  detectPinch(hand) {
    const data = this.handData[hand];
    if (!data || !data['thumb-tip'] || !data['index-finger-tip']) return false;

    const thumb = data['thumb-tip'].position;
    const index = data['index-finger-tip'].position;
    const distance = Math.sqrt(
      (thumb[0] - index[0]) ** 2 +
      (thumb[1] - index[1]) ** 2 +
      (thumb[2] - index[2]) ** 2
    );

    return distance < 0.02; // 2cm 阈值
  }
}
```

### 4.3 WebXR 空间锚点

```javascript
class WebXRAnchorManager {
  constructor(session) {
    this.session = session;
    this.anchors = new Map();
  }

  async createAnchor(transform, frame) {
    if (!this.session.requestAnchor) {
      console.warn('当前设备不支持空间锚点');
      return null;
    }

    const anchor = await this.session.requestAnchor(transform, frame);
    const id = crypto.randomUUID();
    this.anchors.set(id, anchor);
    return id;
  }

  getAnchorPose(id, frame, refSpace) {
    const anchor = this.anchors.get(id);
    if (!anchor) return null;

    const pose = frame.getAnchorPose(anchor, refSpace);
    if (!pose) return null;

    return {
      position: pose.transform.position,
      orientation: pose.transform.orientation
    };
  }
}
```

## 常见误区

1. **"一份代码到处运行"**：空间计算不存在真正的 write once run anywhere，不同平台的交互差异需要针对性适配
2. **"WebXR 可以替代原生应用"**：WebXR 功能受限（无空间映射、性能较低），适合作为入口和演示，不适合复杂应用
3. **"Quest 和 HoloLens 代码通用"**：VR（封闭世界）和 AR（开放世界）的交互设计完全不同，代码复用率通常低于 50%
4. **"先做 PC VR 再移植到移动端"**：PC VR 的渲染负载远高于移动 VR，移植时几乎要重做渲染管线
5. **"平台适配是后期工作"**：平台适配必须在架构设计阶段考虑，后期插入适配层的代价极高

## 工程建议

1. **从最低规格平台开始开发**：先适配 WebXR 或 Quest，再向上扩展到 Vision Pro
2. **使用条件编译隔离平台代码**：`#if UNITY_ANDROID` 等宏隔离平台特定实现
3. **建立平台能力矩阵**：每个功能标注支持的平台，运行时动态降级
4. **自动化多平台构建**：使用 Unity Cloud Build 或 CI/CD 流水线，每次提交自动构建所有平台
5. **真实设备测试**：模拟器无法还原手部追踪、空间感知的真实行为

## 小结

本课讲解了空间计算跨平台开发的核心方法论：通过输入抽象层隔离平台差异、自适应 LOD 策略应对性能差异、WebXR 作为浏览器端的兼容性方案、平台能力检测实现运行时降级。

关键要点回顾：
- 四层架构：应用层→交互层→渲染层→平台层，通过接口隔离平台差异
- ISpatialInput 接口统一手柄、手势、眼动等不同输入方式
- WebXR 提供零安装的空间计算入口，但功能和性能受限
- 从最低规格平台开始开发，逐级适配高规格平台

## 参考答案

### 练习一

**思路**：Magic Leap 2 使用 OpenXR 标准，但有自定义扩展

**答案**：
```csharp
using UnityEngine;
using UnityEngine.XR;
using UnityEngine.XR.OpenXR;
using MagicLeap.OpenXR.Features;

public class MagicLeapSpatialInput : ISpatialInput
{
    private MagicLeapHandTracking handTracking;
    private InputDevice leftController;
    private InputDevice rightController;

    public MagicLeapSpatialInput()
    {
        // 获取 Magic Leap 手部追踪特性
        handTracking = OpenXRSettings.Instance.GetFeature<MagicLeapHandTracking>();

        // 获取控制器设备
        var devices = new List<InputDevice>();
        InputDevices.GetDevicesAtXRNode(XRNode.LeftHand, devices);
        leftController = devices.FirstOrDefault();
        InputDevices.GetDevicesAtXRNode(XRNode.RightHand, devices);
        rightController = devices.FirstOrDefault();
    }

    public bool TryGetHandPose(HandType hand, out Pose pose)
    {
        if (handTracking == null || !handTracking.enabled)
        {
            pose = Pose.identity;
            return false;
        }

        // Magic Leap 的手部追踪数据结构
        var handData = hand == HandType.Left
            ? handTracking.LeftHand
            : handTracking.RightHand;

        if (handData.IsConfident)
        {
            // 使用食指尖作为参考点
            var indexTip = handData.Joints[HandJoint.IndexTip];
            pose = new Pose(indexTip.Position, indexTip.Rotation);
            return true;
        }

        pose = Pose.identity;
        return false;
    }

    public bool IsPinching(HandType hand)
    {
        var handData = hand == HandType.Left
            ? handTracking.LeftHand
            : handTracking.RightHand;

        if (!handData.IsConfident) return false;

        var thumbTip = handData.Joints[HandJoint.ThumbTip];
        var indexTip = handData.Joints[HandJoint.IndexTip];
        return Vector3.Distance(thumbTip.Position, indexTip.Position) < 0.015f;
    }

    public bool IsGrabbing(HandType hand)
    {
        var handData = hand == HandType.Left
            ? handTracking.LeftHand
            : handTracking.RightHand;

        if (!handData.IsConfident) return false;

        // Magic Leap 提供手势状态 API
        return handData.Gesture == HandGesture.Fist;
    }

    public bool TryGetGazePose(out Pose gazePose)
    {
        // Magic Leap 2 支持眼动追踪
        var gazeDevice = InputDevices.GetDeviceAtXRNode(XRNode.CenterEye);
        if (gazeDevice.TryGetFeatureValue(CommonUsages.devicePosition, out var pos) &&
            gazeDevice.TryGetFeatureValue(CommonUsages.deviceRotation, out var rot))
        {
            gazePose = new Pose(pos, rot);
            return true;
        }
        gazePose = Pose.identity;
        return false;
    }

    public bool TryGetControllerPose(HandType hand, out Pose pose)
    {
        var device = hand == HandType.Left ? leftController : rightController;
        if (device.isValid &&
            device.TryGetFeatureValue(CommonUsages.devicePosition, out var pos) &&
            device.TryGetFeatureValue(CommonUsages.deviceRotation, out var rot))
        {
            pose = new Pose(pos, rot);
            return true;
        }
        pose = Pose.identity;
        return false;
    }

    public float GetTriggerValue(HandType hand)
    {
        var device = hand == HandType.Left ? leftController : rightController;
        if (device.isValid &&
            device.TryGetFeatureValue(CommonUsages.trigger, out float value))
        {
            return value;
        }
        return 0f;
    }
}
```

**要点**：
- Magic Leap 2 同时支持手部追踪和控制器，需要处理两者切换
- 手势置信度（IsConfident）是 ML2 特有的，低置信度时应降级到控制器
- 眼动追踪在 ML2 上是企业版特性

**答案**：

```javascript
class FeatureDegradationManager {
  constructor() {
    this.capabilities = null;
    this.activeInputMode = null;
  }

  async detectAndAdapt(session) {
    this.capabilities = await this.detectCapabilities(session);

    // 输入降级链：手部追踪 → 控制器 → 触摸屏
    if (this.capabilities.handTracking) {
      this.activeInputMode = 'hand-tracking';
      this.handTracker = new WebXRHandTracker(session);
    } else if (this.capabilities.controllers) {
      this.activeInputMode = 'controller';
      this.controllerInput = new WebXRControllerInput(session);
    } else {
      this.activeInputMode = 'touch';
      this.touchInput = new TouchFallbackInput();
    }

    // 空间能力降级：锚点 → 平面检测 → 固定位置
    if (this.capabilities.anchors) {
      this.spatialMode = 'anchors';
      this.anchorManager = new WebXRAnchorManager(session);
    } else if (this.capabilities.hitTest) {
      this.spatialMode = 'hit-test';
      this.hitTestManager = new WebXRHitTestManager(session);
    } else {
      this.spatialMode = 'fixed';
      this.fixedPlacement = new FixedPlacementManager();
    }
  }

  async detectCapabilities(session) {
    const caps = {
      handTracking: false,
      controllers: false,
      anchors: false,
      hitTest: false
    };

    // 手部追踪检测
    try {
      const handTestSession = await navigator.xr.requestSession('immersive-ar', {
        requiredFeatures: ['local-floor'],
        optionalFeatures: ['hand-tracking']
      });
      caps.handTracking = handTestSession.enabledFeatures?.includes('hand-tracking') ?? false;
      await handTestSession.end();
    } catch {
      caps.handTracking = false;
    }

    // 控制器检测（几乎所有 XR 设备都支持）
    caps.controllers = session.inputSources.some(s => s.targetRayMode === 'tracked-pointer');

    // 锚点检测
    caps.anchors = session.enabledFeatures?.includes('anchors') ?? false;

    // 命中检测
    caps.hitTest = session.enabledFeatures?.includes('hit-test') ?? false;

    return caps;
  }

  // 使用降级方案放置虚拟物体
  async placeObject(position, rotation) {
    switch (this.spatialMode) {
      case 'anchors':
        return await this.anchorManager.createAnchor({ position, rotation });
      case 'hit-test':
        return await this.hitTestManager.placeOnSurface(position);
      case 'fixed':
        return this.fixedPlacement.place(position, rotation);
    }
  }
}
```

**要点**：
- 降级策略应该是自动的，不需要用户干预
- 每个降级级别都要提供合理的用户体验
- 在 UI 中告知用户当前使用的功能级别

### 练习三

**思路**：将场景内容分为"核心"和"增强"两层

**答案**：

| 内容类别 | Quest（500K） | Vision Pro（1M） | 策略 |
|---------|-------------|-----------------|------|
| 核心交互对象 | 100K 三角形 | 100K 三角形 | 共享同一套模型 |
| 环境背景 | 50K（简模） | 200K（精模） | 平台特定版本 |
| UI 元素 | 30K | 30K | 共享 |
| 特效粒子 | 20K | 100K | 平台特定配置 |
| 阴影 | 关闭 | 开启（100K 额外开销） | 平台特定 |
| 后处理 | 无 | Bloom + 色差 | 平台特定 |
| 预留缓冲 | 300K | 470K | 用于动态内容 |

实现方案：
```csharp
public class ContentBudgetAllocator : MonoBehaviour
{
    [SerializeField] private int questBudget = 500000;
    [SerializeField] private int visionProBudget = 1000000;

    public void AllocateBudget(PlatformCapabilities caps)
    {
        int budget = caps.maxTextureSize > 2048 ? visionProBudget : questBudget;
        int used = 0;

        // 核心对象：优先级最高，保证质量
        used += AllocateForCategory("core-objects", budget * 0.2f);

        // 环境：根据剩余预算动态调整
        int environmentBudget = (int)(budget * 0.15f);
        if (used + environmentBudget > budget * 0.8f)
            environmentBudget = (int)(budget * 0.1f);
        used += AllocateForCategory("environment", environmentBudget);

        // UI：固定预算
        used += AllocateForCategory("ui", 30000);

        // 剩余预算给特效和缓冲
        int remaining = budget - used;
        AllocateForCategory("effects", remaining / 2);
        AllocateForCategory("dynamic-buffer", remaining / 2);
    }

    private int AllocateForCategory(string category, float budget)
    {
        // 根据预算设置该类别的 LOD 级别
        var objects = GetObjectsByCategory(category);
        int triangleCount = 0;

        foreach (var obj in objects)
        {
            var lodGroup = obj.GetComponent<LODGroup>();
            if (lodGroup != null)
            {
                // 选择满足预算的 LOD 级别
                int lodLevel = SelectLODLevel(lodGroup, budget / objects.Count);
                lodGroup.ForceLOD(lodLevel);
                triangleCount += GetTriangleCountAtLOD(lodGroup, lodLevel);
            }
        }

        return triangleCount;
    }
}
```

**要点**：
- 核心交互对象的模型质量不能妥协，是用户体验的底线
- 环境和特效是主要的调节旋钮
- 预留 20-30% 缓冲用于动态生成的内容（如用户创建的标注）
