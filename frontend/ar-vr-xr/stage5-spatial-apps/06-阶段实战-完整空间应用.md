## 架构设计

```
┌─────────────────────────────────────┐
```

核心设计决策：共享层包含场景图、网络同步、资产管线。AR 和 VR 模式只是"不同的视图"，数据完全共用。

```typescript
class SpatialWorkstation {
  private mode: 'flat' | 'ar' | 'vr' = 'flat'
  private sceneGraph: SceneGraph
  private networkSync: NetworkSync
  private assetPipeline: AssetPipeline

  constructor(canvas: HTMLCanvasElement) {
    this.sceneGraph = new SceneGraph()
    this.networkSync = new NetworkSync()
    this.assetPipeline = new AssetPipeline()
  }

  async switchMode(mode: 'ar' | 'vr') {
    if (mode === 'ar') {
      await this.enterAR()
    } else {
      await this.enterVR()
    }
    this.mode = mode
  }

  private async enterAR() {
    const session = await navigator.xr.requestSession('immersive-ar', {
      requiredFeatures: ['hit-test', 'local-floor'],
      optionalFeatures: ['anchors', 'plane-detection']
    })
    // AR 模式：摄像头背景 + 虚拟内容叠加
    renderer.xr.setSession(session)
    this.sceneGraph.setRenderMode('ar')
  }

  private async enterVR() {
    const session = await navigator.xr.requestSession('immersive-vr', {
      requiredFeatures: ['local-floor', 'bounded-floor'],
      optionalFeatures: ['hand-tracking']
    })
    // VR 模式：完全虚拟环境
    renderer.xr.setSession(session)
    this.sceneGraph.setRenderMode('vr')
  }
}
```

## 场景图管理

场景图是应用的核心数据结构——所有虚拟内容都从这里读取：

```typescript
class SceneGraph {
  private nodes: Map<string, SceneNode> = new Map()
  private root: THREE.Group

  constructor() {
    this.root = new THREE.Group()
    scene.add(this.root)
  }

  addNode(node: SceneNode) {
    this.nodes.set(node.id, node)
    this.root.add(node.object)
    this.networkSync.broadcast({ type: 'node-add', node: node.serialize() })
  }

  removeNode(id: string) {
    const node = this.nodes.get(id)
    if (node) {
      this.root.remove(node.object)
      this.nodes.delete(id)
      this.networkSync.broadcast({ type: 'node-remove', id })
    }
  }

  // AR 模式下只显示标记为 "ar" 的节点
  // VR 模式下显示所有节点
  setRenderMode(mode: 'ar' | 'vr') {
    for (const node of this.nodes.values()) {
      node.object.visible = mode === 'vr' || node.visibleInAR
    }
  }
}
```

## 内容管线

3D 资产从加载到渲染的完整流程：

```typescript
class AssetPipeline {
  private loader = new GLTFLoader()
  private cache = new Map<string, THREE.Group>()

  async load(url: string): Promise<THREE.Group> {
    if (this.cache.has(url)) return this.cache.get(url)!.clone()

    const gltf = await this.loader.loadAsync(url)
    const model = gltf.scene

    // 优化：合并几何体、压缩纹理
    this.optimizeModel(model)

    this.cache.set(url, model)
    return model.clone()
  }

  private optimizeModel(model: THREE.Group) {
    model.traverse((child) => {
      if (child instanceof THREE.Mesh) {
        // 启用实例化渲染
        child.frustumCulled = true
        // 压缩纹理
        if (child.material.map) {
          child.material.map.generateMipmaps = true
        }
      }
    })
  }
}
```

## 多人同步

场景图的变更需要同步到所有参与者：

```typescript
class NetworkSync {
  private ws: WebSocket
  private pendingOps: any[] = []

  constructor() {
    this.ws = new WebSocket('wss://your-server.com/room')
    this.ws.onmessage = (e) => this.applyRemote(JSON.parse(e.data))
  }

  broadcast(op: any) {
    this.pendingOps.push(op)
    // 批量发送，减少网络请求
    if (this.pendingOps.length >= 10 || Date.now() - this.lastFlush > 100) {
      this.flush()
    }
  }

  private flush() {
    if (this.pendingOps.length === 0) return
    this.ws.send(JSON.stringify(this.pendingOps))
    this.pendingOps = []
  }

  private applyRemote(ops: any[]) {
    for (const op of ops) {
      switch (op.type) {
        case 'node-add':
          sceneGraph.addNode(SceneNode.deserialize(op.node))
          break
        case 'node-remove':
          sceneGraph.removeNode(op.id)
          break
        case 'node-transform':
          sceneGraph.updateTransform(op.id, op.position, op.rotation)
          break
      }
    }
  }
}
```

## 你可能踩的坑

**坑一：AR/VR 切换时场景重置**

切换模式时 XRSession 会重建，场景图需要重新挂载。确保场景图的根节点不依赖任何 XRSession 生命周期。

**坑二：多人操作同一物体冲突**

两个人同时拖拽同一个物体会互相覆盖。用"操作锁"机制：第一个操作的人获得锁，其他人只能观察。

**坑三：3D 资产格式不统一**

不同来源的模型可能用不同的坐标系、单位、材质系统。在 AssetPipeline 中做统一处理。

```typescript
class SceneSerializer {
  serialize(sceneGraph: SceneGraph): string {
    const nodes = []
    for (const [id, node] of sceneGraph.nodes) {
      nodes.push({
        id,
        type: node.type,
        position: node.object.position.toArray(),
        rotation: node.object.rotation.toArray(),
        scale: node.object.scale.toArray(),
        assetUrl: node.assetUrl
      })
    }
    return JSON.stringify({ version: '1.0', nodes }, null, 2)
  }

  async deserialize(json: string, sceneGraph: SceneGraph, assets: AssetPipeline) {
    const data = JSON.parse(json)
    for (const nodeData of data.nodes) {
      const model = await assets.load(nodeData.assetUrl)
      model.position.fromArray(nodeData.position)
      model.rotation.fromArray(nodeData.rotation)
      model.scale.fromArray(nodeData.scale)
      sceneGraph.addNode(new SceneNode(nodeData.id, model, nodeData.assetUrl))
    }
  }
}
```

```typescript
class UndoRedoManager {
  private undoStack: Operation[] = []
  private redoStack: Operation[] = []

  execute(op: Operation) {
    op.execute()
    this.undoStack.push(op)
    this.redoStack = [] // 新操作清空重做栈
  }

  undo() {
    const op = this.undoStack.pop()
    if (op) {
      op.undo()
      this.redoStack.push(op)
    }
  }

  redo() {
    const op = this.redoStack.pop()
    if (op) {
      op.execute()
      this.undoStack.push(op)
    }
  }
}
```
