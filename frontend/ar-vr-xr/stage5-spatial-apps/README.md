# Stage 5：空间应用

## 阶段概述

本阶段是 AR/VR/XR 学习路径的终章，聚焦空间计算时代的完整应用开发与商业化落地。从场景理解与 AI 融合、数字孪生、商业模式设计、跨平台适配、发布分发到最终的综合实战项目，帮助你把前四个阶段的技术积累转化为可交付、可运营的空间应用产品。

## 学习目标

完成本阶段后，你将能够：

1. 利用空间计算 API 与 AI 模型实现场景语义理解和物体识别
2. 构建数字孪生系统，实现物理世界与虚拟世界的实时同步
3. 理解空间计算领域的商业模式与变现路径
4. 使用 Unity 和 WebXR 实现跨平台空间应用开发
5. 掌握主流 XR 应用平台的发布与分发流程
6. 独立完成一个完整的空间应用项目，从架构设计到上线运营

## 前置要求

- 完成 Stage 1~4 的学习内容
- 熟悉 Unity 开发环境与 C# 编程
- 了解基本的 Web 前端开发（HTML/CSS/JavaScript）
- 对产品设计与商业化有基本认知

## 学习建议

1. **循序渐进**：按照 01→06 的顺序学习，每课之间有递进关系
2. **动手实践**：每课的练习题务必完成，尤其是代码示例需要亲自运行
3. **项目驱动**：06 综合实战课是对前 5 课的综合应用，建议提前构思自己的项目方向
4. **关注商业化**：03 商业模式课不只是"讲道理"，需要结合实际市场数据进行分析
