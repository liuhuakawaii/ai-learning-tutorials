# 空间计算与 AI：让设备看懂真实世界

## 当前项目状态

你的 XR 应用已经能追踪图像、手势、位置。但设备对真实世界的理解仍然很浅——它知道"这里有一个平面"，但不知道"这是一张桌子，上面有一个杯子"。

AI 可以补上这一层语义理解。本课从三个维度讲解：场景语义分割、物体识别、空间锚点的 AI 增强。

## 空间感知的三层架构

```
语义层：物体是什么？功能是什么？   ← AI 语义理解
几何层：物体在哪里？形状如何？     ← SLAM / 深度估计
传感层：摄像头、IMU、LiDAR 数据   ← 原始传感器
```

传感层采集原始数据，几何层构建空间地图，语义层赋予地图"意义"。

## 场景语义分割

语义分割对图像中的每个像素分配类别标签（地面、墙壁、家具等）。在 XR 中用于：

- 识别可放置虚拟物体的平面类型（地面 vs 桌面）
- 遮挡处理（虚拟物体应被真实物体遮挡）
- 环境自适应（根据场景类型调整虚拟内容风格）

```typescript
// 使用 TensorFlow.js 在浏览器中运行语义分割
import * as tf from '@tensorflow/tfjs'
import '@tensorflow-models/deeplab'

async function segmentScene(imageData: ImageData) {
  const model = await deeplab.load({
    base: 'pascal',  // 20 个类别
    quantizationBytes: 2
  })

  const { legend, segmentationMap } = await model.segment(imageData)

  // legend: { 'chair': [r,g,b], 'floor': [r,g,b], ... }
  // segmentationMap: 每个像素的类别 ID

  return { legend, segmentationMap }
}
```

## 物体检测

物体检测告诉你"画面中有哪些物体，分别在哪里"：

```typescript
// 使用 COCO-SSD 模型检测常见物体
import * as cocoSsd from '@tensorflow-models/coco-ssd'

class ObjectDetector {
  private model: cocoSsd.ObjectDetection | null = null

  async init() {
    this.model = await cocoSsd.load({ base: 'lite_mobilenet_v2' })
  }

  async detect(videoFrame: HTMLVideoElement): Promise<cocoSsd.DetectedObject[]> {
    if (!this.model) return []
    return this.model.detect(videoFrame)
  }
}

// 在 XR 帧循环中使用
function onXRFrame(time: DOMHighResTimeStamp, frame: XRFrame) {
  const results = detector.detect(videoFrame)

  for (const obj of results) {
    // obj.class: 'cup', 'chair', 'person', ...
    // obj.bbox: [x, y, width, height]
    // obj.score: 0.0 - 1.0

    if (obj.score > 0.7) {
      attachLabel(obj.class, obj.bbox)
    }
  }
}
```

## 空间锚点的 AI 增强

传统空间锚点依赖几何特征。AI 增强方案可以：

1. **语义锚点**：锚定到"桌子上的杯子"而不是"坐标 (1.2, 0.8, -0.5)"
2. **重定位**：应用重启后，用物体识别重新找到锚点位置

```typescript
class SemanticAnchor {
  private objectSignature: string // 物体的视觉特征描述
  private lastKnownPose: XRPose

  constructor(objectClass: string, pose: XRPose, descriptor: Float32Array) {
    this.objectSignature = `${objectClass}_${descriptor.toString().slice(0, 100)}`
    this.lastKnownPose = pose
  }

  // 尝试通过物体识别重新定位
  async relocate(detections: DetectedObject[]): Promise<XRPose | null> {
    for (const det of detections) {
      if (this.matchesSignature(det)) {
        return this.estimatePoseFromDetection(det)
      }
    }
    return null
  }
}
```

## 你可能踩的坑

**坑一：模型推理太慢**

TensorFlow.js 的大模型在手机上可能每秒只能跑 1-2 帧。用小模型（`lite_mobilenet_v2`），或只在需要时触发检测（不是每帧都跑）。

**坑二：语义分割精度不够**

边缘像素容易分类错误。在 XR 中，分割错误会导致虚拟物体"穿透"真实物体。可以结合深度信息做后处理。

**坑三：模型体积太大**

COCO-SSD lite 约 5MB，DeepLab 约 2MB。首次加载会慢，需要做加载进度提示和缓存。

```typescript
class ObjectLabeler {
  private labels: Map<string, THREE.Sprite> = new Map()

  update(detections: cocoSsd.DetectedObject[], camera: THREE.Camera) {
    for (const det of detections) {
      let label = this.labels.get(det.class)
      if (!label) {
        label = this.createLabel(det.class)
        this.labels.set(det.class, label)
      }

      // 将 2D 检测框映射到 3D 空间
      const center = {
        x: (det.bbox[0] + det.bbox[2] / 2) / window.innerWidth * 2 - 1,
        y: -(det.bbox[1] + det.bbox[3] / 2) / window.innerHeight * 2 + 1
      }

      // 用射线检测获取深度
      const raycaster = new THREE.Raycaster()
      raycaster.setFromCamera(new THREE.Vector2(center.x, center.y), camera)
      const hits = raycaster.intersectObjects(scene.children)
      if (hits.length > 0) {
        label.position.copy(hits[0].point).add(new THREE.Vector3(0, 0.1, 0))
      }

      label.visible = det.score > 0.6
    }
  }
}
```

```typescript
async function smartPlace(
```
