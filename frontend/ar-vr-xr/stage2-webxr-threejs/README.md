# 阶段二：WebXR + Three.js 开发

## 阶段概述

本阶段是 AR/VR/XR 课程的核心技术阶段，聚焦 WebXR Device API 与 Three.js 的深度集成。你将从零掌握 WebXR 的会话管理、参考空间、帧循环等底层机制，并分别深入 AR 和 VR 两种会话类型的完整开发流程。

完成本阶段后，你将具备独立开发浏览器端 AR/VR 应用的能力，能够处理命中检测、平面识别、控制器输入、空间音频等核心功能。

## 前置要求

- 完成阶段一（空间计算基础），理解坐标系、变换矩阵、四元数
- 熟悉 TypeScript 基础语法
- 了解 Three.js 基本用法（场景、相机、渲染器、几何体、材质）
- 有基本的 Web 开发经验

## 学习目标

1. **理解 WebXR 架构**：掌握 XRSession 生命周期、参考空间类型、帧循环机制
2. **掌握 AR 开发**：实现命中检测放置、平面识别、锚点持久化
3. **掌握 VR 开发**：处理控制器输入、实现传送与抓取交互
4. **熟练 Three.js 集成**：使用 Three.js XR 模式进行渲染，管理 XR 控制器模型
5. **实现空间音频**：基于 HRTF 的 3D 音频定位与空间化
6. **完成实战项目**：独立构建 AR 产品展示应用

## 技术栈

| 技术 | 用途 | 版本要求 |
|------|------|----------|
| WebXR Device API | AR/VR 会话管理 | 浏览器原生支持 |
| Three.js | 3D 渲染引擎 | r150+ |
| TypeScript | 类型安全开发 | 5.0+ |
| Web Audio API | 空间音频 | 浏览器原生支持 |

## 开发环境

- Chrome 79+（Android）或 Chrome 109+（桌面）
- 支持 WebXR 的设备（Android 手机、Meta Quest、HoloLens 等）
- 本地 HTTPS 开发服务器（WebXR 要求安全上下文）
