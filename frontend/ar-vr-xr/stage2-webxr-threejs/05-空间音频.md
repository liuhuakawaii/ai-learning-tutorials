# 空间音频

## 场景引入

在一个 VR 博物馆中，你看到远处有一台电视机正在播放新闻。走近时，声音越来越清晰；走到电视机背后，声音从身后传来；走到另一个房间，声音变得模糊。这就是空间音频的效果——声音不再是平面的左右声道，而是存在于三维空间中的实体。

空间音频是提升沉浸感的关键因素之一。没有空间音频，虚拟世界是「沉默的画」；有了空间音频，虚拟世界变成了「可以聆听的空间」。本课将介绍如何使用 Web Audio API 实现 3D 空间音频。

## 学习目标

- 理解空间音频的基本原理
- 掌握 Web Audio API 的 AudioContext 和节点图
- 使用 PannerNode 实现 3D 音频定位
- 理解 HRTF 与空间音频的关系
- 将空间音频集成到 Three.js XR 应用中

## 空间音频基础

### 什么是空间音频

传统立体声只区分左右声道。空间音频模拟了真实世界中声音的传播方式：

- **距离衰减**：远处的声音比近处的安静
- **方向定位**：声音从特定方向传来
- **遮挡效应**：墙壁等障碍物会阻隔声音
- **多普勒效应**：移动声源的音调会变化

### Web Audio API 节点图

Web Audio API 基于节点图（Node Graph）架构。音频数据在节点之间流动，每个节点对音频做特定处理：

```
音频源 (AudioBufferSourceNode)
    │
    ↓
空间定位 (PannerNode)
    │
    ↓
音量控制 (GainNode)
    │
    ↓
监听器 (AudioListener)
    │
    ↓
音频输出 (扬声器/耳机)
```

## AudioContext

`AudioContext` 是 Web Audio API 的核心对象，管理所有音频节点和音频处理。

```typescript
class SpatialAudioManager {
  private context: AudioContext;
  private listener: AudioListener;

  constructor() {
    // 创建音频上下文
    this.context = new AudioContext();

    // 获取监听器（代表听众的位置和朝向）
    this.listener = this.context.listener;
  }

  // 用户交互后才能启动 AudioContext（浏览器策略）
  async resume(): Promise<void> {
    if (this.context.state === 'suspended') {
      await this.context.resume();
    }
  }

  // 创建音频缓冲区
  async loadAudio(url: string): Promise<AudioBuffer> {
    const response = await fetch(url);
    const arrayBuffer = await response.arrayBuffer();
    return await this.context.decodeAudioData(arrayBuffer);
  }

  dispose(): void {
    this.context.close();
  }
}
```

## AudioListener

`AudioListener` 代表听众（通常是用户的头部位置）。它定义了「收听者在哪里」和「朝向哪个方向」。

### 设置监听器位置

```typescript
// 直接设置监听器位置
function setListenerPosition(listener: AudioListener, x: number, y: number, z: number): void {
  // 旧版 API（positionX/Y/Z 属性）
  if (listener.positionX) {
    listener.positionX.value = x;
    listener.positionY.value = y;
    listener.positionZ.value = z;
  } else {
    // 新版 API（setPosition 方法）
    listener.setPosition(x, y, z);
  }
}

// 设置监听器朝向
function setListenerOrientation(
  listener: AudioListener,
  forwardX: number, forwardY: number, forwardZ: number,
  upX: number, upY: number, upZ: number
): void {
  // 旧版 API
  if (listener.forwardX) {
    listener.forwardX.value = forwardX;
    listener.forwardY.value = forwardY;
    listener.forwardZ.value = forwardZ;
    listener.upX.value = upX;
    listener.upY.value = upY;
    listener.upZ.value = upZ;
  } else {
    // 新版 API
    listener.setOrientation(forwardX, forwardY, forwardZ, upX, upY, upZ);
  }
}
```

### 与 XR 设备同步监听器

在 XR 应用中，监听器应该跟随用户（相机）的位置：

```typescript
function syncListenerToCamera(listener: AudioListener, camera: THREE.Camera): void {
  const position = new THREE.Vector3();
  const forward = new THREE.Vector3();
  const up = new THREE.Vector3();

  camera.getWorldPosition(position);
  camera.getWorldDirection(forward);
  up.copy(camera.up);

  listener.setPosition(position.x, position.y, position.z);
  listener.setOrientation(forward.x, forward.y, forward.z, up.x, up.y, up.z);
}
```

## PannerNode

`PannerNode` 是空间音频的核心节点。它控制声音在三维空间中的位置、方向和衰减。

### 创建 PannerNode

```typescript
function createPanner(context: AudioContext): PannerNode {
  const panner = context.createPanner();

  // 空间化算法
  panner.panningModel = 'HRTF';  // 高精度头相关传输函数

  // 距离衰减模型
  panner.distanceModel = 'inverse';  // 反比衰减（最接近真实）

  // 参考距离（开始衰减的距离）
  panner.refDistance = 1;  // 1 米

  // 最大距离（超过此距离不再衰减）
  panner.maxDistance = 100;  // 100 米

  // 衰减因子（衰减速度）
  panner.rolloffFactor = 1;

  // 锥形参数（方向性声源）
  panner.coneInnerAngle = 360;  // 内锥角度（无方向性）
  panner.coneOuterAngle = 360;  // 外锥角度
  panner.coneOuterGain = 0;     // 外锥增益

  return panner;
}
```

### PannerNode 参数详解

```
距离衰减模型：
┌──────────────────────────────────────────────────┐
│ 增益                                              │
│ 1.0 ┤■■■■                                          │
│     │    ■■■                                       │
│ 0.5 ┤       ■■■                                    │
│     │          ■■■■                                │
│ 0.0 ┤────────────────── 距离 →                    │
│     0    refD   maxD                               │
└──────────────────────────────────────────────────┘

distanceModel:
  - 'linear': 线性衰减（简单，不真实）
  - 'inverse': 反比衰减（最接近真实物理）
  - 'exponential': 指数衰减（衰减更快）
```

### 设置声源位置

```typescript
  }
}
```

## HRTF

HRTF（Head-Related Transfer Function，头相关传输函数）是空间音频的关键技术。

### 什么是 HRTF

人耳能够判断声音方向，是因为声音到达两只耳朵的时间和强度不同，而且声音经过头部、耳廓的反射和衍射后会发生频率变化。HRTF 就是对这些物理效应的数学建模。

```
声源 → 头部反射 → 左耳（时间差 + 强度差 + 频率变化）
                 → 右耳（时间差 + 强度差 + 频率变化）

HRTF = 从声源位置到耳道的完整传输函数
```

### 在 Web Audio API 中使用 HRTF

```typescript
// 设置 panningModel 为 'HRTF'
const panner = context.createPanner();
panner.panningModel = 'HRTF';

// 对比 'equalpower'（简单左右平衡算法）
const simplePanner = context.createPanner();
simplePanner.panningModel = 'equalpower';
```

`HRTF` 模式比 `equalpower` 更精确，但计算开销更大。对于少量声源（< 20 个），HRTF 是更好的选择。

### HRTF 的局限性

- HRTF 是基于平均头部尺寸的通用模型，不同人的 HRTF 不同
- 佩戴耳机时效果最好，扬声器环境下效果会打折扣
- 前后定位比上下定位更难区分

## 完整的空间音频系统

将以上概念整合为一个完整的空间音频系统：

```typescript
class SpatialAudioSystem {
  private context: AudioContext;
  private listener: AudioListener;
  private sources: Map<string, { source: AudioBufferSourceNode; panner: PannerNode; gain: GainNode }> = new Map();

  constructor() {
    this.context = new AudioContext();
    this.listener = this.context.listener;
  }

  async resume(): Promise<void> {
    if (this.context.state === 'suspended') {
      await this.context.resume();
    }
  }

  // 加载并创建空间音频源
  async createSpatialSource(
    id: string,
    audioUrl: string,
    position: { x: number; y: number; z: number },
    options: {
      loop?: boolean;
      refDistance?: number;
      maxDistance?: number;
      volume?: number;
    } = {}
  ): Promise<void> {
    // 加载音频
    const response = await fetch(audioUrl);
    const arrayBuffer = await response.arrayBuffer();
    const audioBuffer = await this.context.decodeAudioData(arrayBuffer);

    // 创建音频源
    const source = this.context.createBufferSource();
    source.buffer = audioBuffer;
    source.loop = options.loop ?? false;

    // 创建 PannerNode
    const panner = this.context.createPanner();
    panner.panningModel = 'HRTF';
    panner.distanceModel = 'inverse';
    panner.refDistance = options.refDistance ?? 1;
    panner.maxDistance = options.maxDistance ?? 100;
    panner.rolloffFactor = 1;
    panner.setPosition(position.x, position.y, position.z);

    // 创建音量控制
    const gain = this.context.createGain();
    gain.gain.value = options.volume ?? 1;

    // 连接节点图
    source.connect(panner);
    panner.connect(gain);
    gain.connect(this.context.destination);

    // 开始播放
    source.start();

    this.sources.set(id, { source, panner, gain });
  }

  // 更新声源位置
  updateSourcePosition(id: string, x: number, y: number, z: number): void {
    const entry = this.sources.get(id);
    if (!entry) return;
    entry.panner.setPosition(x, y, z);
  }

  // 更新监听器位置（跟随相机）
  updateListener(camera: THREE.Camera): void {
    const position = new THREE.Vector3();
    const forward = new THREE.Vector3();
    const up = new THREE.Vector3();

    camera.getWorldPosition(position);
    camera.getWorldDirection(forward);
    up.copy(camera.up);

    this.listener.setPosition(position.x, position.y, position.z);
    this.listener.setOrientation(
      forward.x, forward.y, forward.z,
      up.x, up.y, up.z
    );
  }

  // 调整音量
  setVolume(id: string, volume: number): void {
    const entry = this.sources.get(id);
    if (!entry) return;
    entry.gain.gain.value = Math.max(0, Math.min(1, volume));
  }

  // 停止并移除音频源
  removeSource(id: string): void {
    const entry = this.sources.get(id);
    if (!entry) return;
    entry.source.stop();
    entry.source.disconnect();
    entry.panner.disconnect();
    entry.gain.disconnect();
    this.sources.delete(id);
  }

  // 清理所有资源
  dispose(): void {
    this.sources.forEach((_, id) => this.removeSource(id));
    this.context.close();
  }
}
```

## Three.js 中的空间音频

Three.js 内置了对 Web Audio API 空间音频的支持，通过 `PositionalAudio` 类简化了集成。

### 使用 Three.js PositionalAudio

```typescript
import * as THREE from 'three';

class ThreeSpatialAudio {
  private listener: THREE.AudioListener;
  private audioLoader: THREE.AudioLoader;

  constructor(camera: THREE.Camera) {
    this.listener = new THREE.AudioListener();
    camera.add(this.listener);  // 监听器跟随相机
    this.audioLoader = new THREE.AudioLoader();
  }

  // 创建位置音频源
  createPositionalAudio(
    object: THREE.Object3D,
    audioUrl: string,
    options: {
      refDistance?: number;
      maxDistance?: number;
      loop?: boolean;
      volume?: number;
    } = {}
  ): void {
    const sound = new THREE.PositionalAudio(this.listener);

    this.audioLoader.load(audioUrl, (buffer) => {
      sound.setBuffer(buffer);
      sound.setRefDistance(options.refDistance ?? 1);
      sound.setMaxDistance(options.maxDistance ?? 100);
      sound.setRolloffFactor(1);
      sound.setDistanceModel('inverse');
      sound.setLoop(options.loop ?? false);
      sound.setVolume(options.volume ?? 1);
      sound.play();
    });

    object.add(sound);
  }
}
```

### PositionalAudio 的优势

使用 Three.js 的 `PositionalAudio` 而不是直接操作 Web Audio API 的原因：

1. **自动位置同步**：`PositionalAudio` 自动使用所属 Object3D 的世界坐标更新 PannerNode 位置
2. **自动朝向同步**：声源朝向自动跟随 Object3D 的旋转
3. **资源管理**：Three.js 统一管理音频资源的加载和释放
4. **API 简洁**：相比直接操作 Web Audio API 节点图，代码量大幅减少

### 在 XR 中使用 PositionalAudio

```typescript
function setupXRSceneWithAudio(scene: THREE.Scene, camera: THREE.Camera): void {
  // 添加监听器到相机
  const listener = new THREE.AudioListener();
  camera.add(listener);

  // 创建一个「电视机」物体
  const tvGeometry = new THREE.BoxGeometry(0.8, 0.5, 0.05);
  const tvMaterial = new THREE.MeshStandardMaterial({ color: 0x222222 });
  const tv = new THREE.Mesh(tvGeometry, tvMaterial);
  tv.position.set(0, 1.2, -3);
  scene.add(tv);

  // 给电视机添加声音
  const tvSound = new THREE.PositionalAudio(listener);
  const audioLoader = new THREE.AudioLoader();

  audioLoader.load('sounds/news-broadcast.mp3', (buffer) => {
    tvSound.setBuffer(buffer);
    tvSound.setRefDistance(0.5);
    tvSound.setLoop(true);
    tvSound.play();
  });

  tv.add(tvSound);  // 声音跟随电视机位置

  // 在渲染循环中更新监听器
  // Three.js PositionalAudio 会自动处理声源位置
  // 但监听器位置需要在 XR 模式下手动同步
  renderer.setAnimationLoop((timestamp, frame) => {
    // Three.js 会自动更新 PositionalAudio 的位置
    renderer.render(scene, camera);
  });
}
```

## 音频资源管理

空间音频涉及大量音频资源，正确的资源管理至关重要。

### 音频缓冲区共享

```typescript
class AudioBufferCache {
  private cache: Map<string, AudioBuffer> = new Map();
  private loader: THREE.AudioLoader;

  constructor() {
    this.loader = new THREE.AudioLoader();
  }

  async load(url: string): Promise<AudioBuffer> {
    if (this.cache.has(url)) {
      return this.cache.get(url)!;
    }

    return new Promise((resolve, reject) => {
      this.loader.load(
        url,
        (buffer) => {
          this.cache.set(url, buffer);
          resolve(buffer);
        },
        undefined,
        reject
      );
    });
  }

  dispose(): void {
    this.cache.clear();
  }
}
```

### 音频实例池

对于频繁播放的短音效（如脚步声、碰撞声），使用实例池避免频繁创建和销毁节点：

```typescript
class AudioPool {
  private pool: THREE.PositionalAudio[] = [];
  private listener: THREE.AudioListener;
  private buffer: AudioBuffer | null = null;
  private poolSize: number;

  constructor(listener: THREE.AudioListener, poolSize: number = 5) {
    this.listener = listener;
    this.poolSize = poolSize;
  }

  setBuffer(buffer: AudioBuffer): void {
    this.buffer = buffer;
    // 预创建音频实例
    for (let i = 0; i < this.poolSize; i++) {
      const audio = new THREE.PositionalAudio(this.listener);
      audio.setBuffer(buffer);
      this.pool.push(audio);
    }
  }

  play(position: THREE.Vector3, volume: number = 1): void {
    if (!this.buffer) return;

    // 找到一个空闲的实例
    const available = this.pool.find(a => !a.isPlaying);
    if (!available) return;  // 所有实例都在播放

    // 设置位置和音量
    available.position.copy(position);
    available.setVolume(volume);
    available.play();
  }
}
```

## 常见误区

### 误区一：忘记 resume AudioContext

浏览器要求 AudioContext 必须在用户交互后才能启动。如果在页面加载时就创建并播放音频，会静默失败。

```typescript
// 错误：页面加载时直接播放
const context = new AudioContext();
source.start();  // 可能静默失败

// 正确：在用户交互后启动
button.addEventListener('click', async () => {
  await context.resume();
  source.start();
});
```

### 误区二：PannerNode 位置不更新

声源位置设置一次后不再更新，导致物体移动时声音位置不跟随。对于移动的声源，必须每帧更新 PannerNode 位置。

### 误区三：同时播放过多 HRTF 音源

HRTF 计算开销较大。同时使用 20+ 个 HRTF 音源可能导致性能问题。对于远处的或不重要的音源，可以降级为 `equalpower` 模式。

### 误区四：忽略音频资源的内存占用

未压缩的音频文件（WAV）可能非常大。应该使用压缩格式（MP3、OGG）并控制同时加载的音频数量。

## 工程建议

1. **音频格式选择**：优先使用 OGG（浏览器兼容性好），备选 MP3。避免使用 WAV
2. **音频预加载**：在进入 XR 会话前预加载关键音频资源
3. **HRTF 选择性使用**：对重要音源使用 HRTF，对次要音源使用 equalpower
4. **音量分级**：根据距离和重要性动态调整音量，远处的不重要音源可以静音
5. **AudioContext 生命周期**：在 XR 会话结束时暂停 AudioContext，而不是关闭它

## 小结

本课介绍了空间音频的核心概念和实现方式：

- **AudioContext**：Web Audio API 的核心，管理音频节点和处理流程
- **AudioListener**：代表听众位置，应与相机同步
- **PannerNode**：控制声源在三维空间中的位置、方向和衰减
- **HRTF**：高精度的空间化算法，提供真实的方向定位感
- **Three.js PositionalAudio**：Three.js 对空间音频的封装，自动同步物体位置

空间音频虽然不是视觉效果，但对沉浸感的提升是巨大的。一个好的空间音频系统能让用户仅凭听觉就能判断虚拟物体的位置和距离。

## 参考答案

### 练习一

**思路**：每个乐器是一个独立的音频源，经过各自的 PannerNode 和 GainNode，最后汇聚到主音量控制器。

**答案**：
```
小提琴 (AudioBufferSource)
  → PannerNode (HRTF, position: -2, 1, -3)
  → GainNode (volume: 0.8)
  → MasterGain (volume: 1.0)
  → AudioContext.destination

钢琴 (AudioBufferSource)
  → PannerNode (HRTF, position: 0, 0.5, -2)
  → GainNode (volume: 1.0)
  → MasterGain
  → AudioContext.destination

长笛 (AudioBufferSource)
  → PannerNode (HRTF, position: 2, 1.5, -4)
  → GainNode (volume: 0.6)
  → MasterGain
  → AudioContext.destination
```

**要点**：
- 每个乐器有独立的 PannerNode 控制空间位置
- 每个乐器有独立的 GainNode 控制相对音量
- 所有音频汇聚到 MasterGain 统一控制总音量
- 使用 HRTF 实现精确的方向定位

### 练习二

**思路**：应用距离衰减公式计算增益值。

**答案**：
`inverse` 模型（默认）：
- 增益 = refDistance / (refDistance + rolloffFactor * (distance - refDistance))
- 1 米处：1 / (1 + 1 * (1-1)) = 1.0
- 5 米处：1 / (1 + 1 * (5-1)) = 0.2
- 10 米处：1 / (1 + 1 * (10-1)) = 0.1

`exponential` 模型（rolloffFactor=2）：
- 增益 = (distance / refDistance) ^ (-rolloffFactor)
- 1 米处：(1/1) ^ (-2) = 1.0
- 5 米处：(5/1) ^ (-2) = 0.04
- 10 米处：(10/1) ^ (-2) = 0.01

**要点**：
- `inverse` 衰减更平缓，适合大多数场景
- `exponential` 衰减更快，远处声音迅速变小
- 实际应用中，`inverse` 模型最接近真实物理

### 练习三

**思路**：在渲染循环中更新声源位置，并根据角色移动速度控制播放状态。

**答案**：
```typescript
class FollowingSound {
  private sound: THREE.PositionalAudio;
  private target: THREE.Object3D;
  private isMoving = false;

  constructor(listener: THREE.AudioListener, target: THREE.Object3D, buffer: AudioBuffer) {
    this.target = target;
    this.sound = new THREE.PositionalAudio(listener);
    this.sound.setBuffer(buffer);
    this.sound.setLoop(true);
    this.sound.setRefDistance(1);
    target.add(this.sound);
  }

  update(): void {
    const velocity = this.target.userData.velocity;
    const moving = velocity && velocity.length() > 0.01;

    if (moving && !this.isMoving) {
      this.sound.play();
      this.isMoving = true;
    } else if (!moving && this.isMoving) {
      this.sound.pause();
      this.isMoving = false;
    }
  }
}
```

**要点**：
- 声音作为 target 的子对象，自动跟随位置
- 使用 `pause()` 而不是 `stop()`，保持播放进度
- 速度阈值避免静止时的微小抖动触发播放
