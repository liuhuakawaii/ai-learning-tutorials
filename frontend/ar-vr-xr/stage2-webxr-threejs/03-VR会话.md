# VR 会话：控制器、传送与抓取

## 场景引入

上一课我们学习了 AR 会话的核心能力。现在切换到 VR 场景：用户戴着头显，手持两个控制器，站在一个完全虚拟的世界中。他需要在虚拟房间里走动、拿起桌上的物体、按下按钮。

VR 开发的核心挑战与 AR 不同——AR 关注的是虚拟与现实的融合，VR 关注的是沉浸式交互。本课将解决三个核心问题：如何读取控制器输入、如何实现传送移动、如何实现物体抓取。

## 学习目标

- 理解 VR 控制器的输入模型
- 掌握 XRInputSource 和 XRInputSourceArray 的使用
- 实现基于射线的传送（Teleportation）
- 实现物体抓取与释放
- 了解手部追踪的基础概念

## VR 控制器输入模型

### XRInputSource

每个 VR 控制器在 WebXR 中表现为一个 `XRInputSource`。它包含控制器的类型、目标射线（ray）、握持姿态（grip）等信息。

```typescript
// XRInputSource 关键属性
interface XRInputSource {
  // 控制器类型：'tracked-pointer'（手柄）或 'hand'（手部追踪）
  targetRayMode: 'gaze' | 'tracked-pointer' | 'screen';

  // 目标射线的空间（用于射线投射交互）
  targetRaySpace: XRSpace;

  // 握持空间（控制器的物理位置，用于渲染控制器模型）
  gripSpace?: XRSpace;

  // 手部数据（如果是手部追踪模式）
  hand?: XRHand;

  // 按钮和轴的当前状态
  // 通过 XRFrame.getGamepad() 获取
  gamepad?: Gamepad;

  // 主手标识：'left' 或 'right'
  handedness: XRHandedness;
}
```

### 读取输入源

输入源通过 `XRSession.inputSources` 获取，并通过事件监听变化：

```typescript
class VRInputManager {
  private leftController: XRInputSource | null = null;
  private rightController: XRInputSource | null = null;
  private session: XRSession;

  constructor(session: XRSession) {
    this.session = session;

    // 初始扫描已有控制器
    for (const source of session.inputSources) {
      this.onInputSourceAdded(source);
    }

    // 监听控制器连接/断开
    session.addEventListener('inputsourceschange', (event: XRInputSourcesChangeEvent) => {
      event.added.forEach((source) => this.onInputSourceAdded(source));
      event.removed.forEach((source) => this.onInputSourceRemoved(source));
    });
  }

  private onInputSourceAdded(source: XRInputSource): void {
    if (source.handedness === 'left') {
      this.leftController = source;
    } else if (source.handedness === 'right') {
      this.rightController = source;
    }
  }

  private onInputSourceRemoved(source: XRInputSource): void {
    if (source.handedness === 'left') {
      this.leftController = null;
    } else if (source.handedness === 'right') {
      this.rightController = null;
    }
  }
}
```

### 读取按钮和摇杆

控制器的按钮和摇杆状态通过 `Gamepad` API 获取：

```typescript
function readControllerInput(frame: XRFrame, source: XRInputSource): void {
  const gamepad = source.gamepad;
  if (!gamepad) return;

  // 按钮映射（标准 VR 控制器布局）
  // buttons[0]: 扳机键（Trigger）
  // buttons[1]: 握持键（Grip）
  // buttons[2]: A/X 按钮
  // buttons[3]: B/Y 按钮
  // buttons[4]: 菜单按钮

  const trigger = gamepad.buttons[0];
  const grip = gamepad.buttons[1];

  // 按钮状态
  if (trigger.pressed) {
    console.log('扳机键按下');
  }

  // 按钮值（0-1 的模拟值，用于渐进式输入）
  const triggerValue = trigger.value;  // 0 到 1
  console.log(`扳机键力度: ${triggerValue.toFixed(2)}`);

  // 摇杆轴
  // axes[0]: 左右（-1 到 1）
  // axes[1]: 前后（-1 到 1）
  const thumbstickX = gamepad.axes[0];
  const thumbstickY = gamepad.axes[1];
  console.log(`摇杆: (${thumbstickX.toFixed(2)}, ${thumbstickY.toFixed(2)})`);

```

### 获取控制器姿态

在每帧中获取控制器的位置和朝向：

```typescript
function getControllerPose(
  frame: XRFrame,
  source: XRInputSource,
  referenceSpace: XRReferenceSpace
): { gripPose: XRPose | null; rayPose: XRPose | null } {
  // 握持姿态（控制器的物理位置，用于渲染控制器模型）
  const gripPose = source.gripSpace
    ? frame.getPose(source.gripSpace, referenceSpace)
    : null;

  // 射线姿态（用于射线投射交互）
  const rayPose = frame.getPose(source.targetRaySpace, referenceSpace);

  return { gripPose, rayPose };
}
```

## 传送（Teleportation）

传送是 VR 中最常见的移动方式。它避免了传统移动带来的晕动症，同时让用户能够在大于物理空间的虚拟环境中自由移动。

### 设计思路

传送的交互流程：

1. 用户按住摇杆或扳机，进入传送模式
2. 从控制器发射一条抛物线或直线
3. 抛物线与地面的交点显示一个传送指示器
4. 用户松开按钮，瞬间移动到指示器位置

### 射线传送实现

```typescript
class Teleportation {
  private isAiming = false;
  private teleportTarget: THREE.Vector3 | null = null;
  private raycaster = new THREE.Raycaster();
  private groundPlane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0);  // Y=0 地面

  // 传送指示器
  private reticle: THREE.Mesh;

  startAiming(): void {
    this.isAiming = true;
    this.reticle.visible = true;
  }

  stopAiming(cameraRig: THREE.Group): void {
    if (this.isAiming && this.teleportTarget) {
      // 执行传送：移动相机根节点
      cameraRig.position.copy(this.teleportTarget);
    }
    this.isAiming = false;
    this.reticle.visible = false;
    this.teleportTarget = null;
  }

  updateAim(controllerRay: THREE.Ray, groundMeshes: THREE.Mesh[]): void {
    if (!this.isAiming) return;

    // 尝试与自定义地面网格求交
    const intersects = this.raycaster.intersectObjects(groundMeshes);

    if (intersects.length > 0) {
      this.teleportTarget = intersects[0].point;
      this.reticle.position.copy(this.teleportTarget);
      this.reticle.visible = true;
    } else {
      // 回退到平面求交
      const target = new THREE.Vector3();
      this.raycaster.ray = controllerRay;
      if (this.raycaster.ray.intersectPlane(this.groundPlane, target)) {
        this.teleportTarget = target;
        this.reticle.position.copy(this.teleportTarget);
        this.reticle.visible = true;
      } else {
        this.teleportTarget = null;
        this.reticle.visible = false;
      }
    }
  }
}
```

### 抛物线传送

抛物线传送比直线传送更自然，用户可以「抛出」一条弧线来指定落点：

```typescript
function calculateParabolicPath(
  origin: THREE.Vector3,
  direction: THREE.Vector3,
  gravity: number = 9.8,
  segments: number = 30,
  timeStep: number = 0.1
): THREE.Vector3[] {
  const points: THREE.Vector3[] = [];
  const velocity = direction.clone().multiplyScalar(5);  // 初始速度

  for (let i = 0; i <= segments; i++) {
    const t = i * timeStep;
    const point = new THREE.Vector3(
      origin.x + velocity.x * t,
      origin.y + velocity.y * t - 0.5 * gravity * t * t,
      origin.z + velocity.z * t
    );

    // 如果点低于地面，停止
    if (point.y < 0) {
      // 计算与地面的精确交点
      const tGround = (velocity.y + Math.sqrt(velocity.y * velocity.y + 2 * gravity * origin.y)) / gravity;
      point.set(
        origin.x + velocity.x * tGround,
        0,
        origin.z + velocity.z * tGround
      );
      points.push(point);
      break;
    }

    points.push(point);
  }

  return points;
}
```

## 抓取（Grabbing）

抓取是 VR 中与物体交互的核心方式。用户用手「抓住」物体，可以移动、旋转、甚至丢弃。

### 抓取交互状态机

抓取交互可以建模为一个简单状态机：

```
空闲 (Idle)
  ↓ [手接近物体 + 按下握持键]
抓取中 (Grabbing)
  ↓ [物体跟随手移动]
  ↓ [松开握持键]
释放 (Release)
  ↓ [物体根据手的速度飞出]
空闲 (Idle)
```

### 实现抓取系统

```typescript
class GrabSystem {
  private grabbedObject: THREE.Object3D | null = null;
  private grabOffset = new THREE.Vector3();
  private previousPosition = new THREE.Vector3();
  private velocity = new THREE.Vector3();

  // 尝试抓取：如果控制器附近的物体可被抓取，则抓住它
  tryGrab(controllerPosition: THREE.Vector3, candidates: THREE.Object3D[]): boolean {
    const grabRadius = 0.1;  // 10cm 抓取范围

    // 找到最近的可抓取物体
    let closest: THREE.Object3D | null = null;
    let closestDistance = Infinity;

    for (const candidate of candidates) {
      if (!candidate.userData.grabbable) continue;

      const distance = controllerPosition.distanceTo(candidate.position);
      if (distance < grabRadius && distance < closestDistance) {
        closest = candidate;
        closestDistance = distance;
      }
    }

    if (!closest) return false;

    // 计算抓取偏移量（手与物体中心的相对位置）
    this.grabOffset.copy(closest.position).sub(controllerPosition);
    this.grabbedObject = closest;
    this.previousPosition.copy(controllerPosition);

    // 标记物体为「已抓取」状态
    closest.userData.isGrabbed = true;

    return true;
  }

  // 更新抓取物体的位置
  update(controllerPosition: THREE.Vector3, controllerRotation: THREE.Quaternion): void {
    if (!this.grabbedObject) return;

    // 计算速度（用于释放时的投掷）
    this.velocity.copy(controllerPosition).sub(this.previousPosition);
    this.previousPosition.copy(controllerPosition);

    // 更新物体位置：手的位置 + 抓取偏移
    this.grabbedObject.position.copy(controllerPosition).add(this.grabOffset);
    this.grabbedObject.quaternion.copy(controllerRotation);
  }

  // 释放物体
  release(): THREE.Object3D | null {
    if (!this.grabbedObject) return null;

    const released = this.grabbedObject;
    released.userData.isGrabbed = false;

    // 应用投掷速度
    if (released.userData.physics) {
      released.userData.velocity = this.velocity.clone().multiplyScalar(10);
    }

    this.grabbedObject = null;
    return released;
  }

  get isGrabbing(): boolean {
    return this.grabbedObject !== null;
  }
}
```

### 抓取与物理的结合

释放物体时，通常需要给物体一个基于手部运动的速度：

```typescript
// 在帧循环中追踪手部速度
private handPositions: THREE.Vector3[] = [];
private readonly VELOCITY_SAMPLES = 5;

private trackVelocity(position: THREE.Vector3): THREE.Vector3 {
  this.handPositions.push(position.clone());

  if (this.handPositions.length > this.VELOCITY_SAMPLES) {
    this.handPositions.shift();
  }

  if (this.handPositions.length < 2) {
    return new THREE.Vector3();
  }

  // 计算最近几帧的平均速度
  const velocity = new THREE.Vector3();
  for (let i = 1; i < this.handPositions.length; i++) {
    const delta = this.handPositions[i].clone().sub(this.handPositions[i - 1]);
    velocity.add(delta);
  }
  velocity.divideScalar(this.handPositions.length - 1);

  return velocity;
}
```

## 手部追踪（Hand Tracking）

手部追踪是 VR 控制器的替代方案，让用户直接用双手与虚拟世界交互。

### XRHand 数据结构

```typescript
function processHandTracking(frame: XRFrame, source: XRInputSource, referenceSpace: XRReferenceSpace): void {
  if (!source.hand) return;  // 不是手部追踪输入源

  const hand: XRHand = source.hand;

  // 手部追踪提供 25 个关节

    'thumb-metacarpal', 'thumb-phalanx-proximal', 'thumb-phalanx-distal', 'thumb-tip',

    if (pose) {
```

### 捏合手势检测

捏合（Pinch）是手部追踪中最常用的手势：

```typescript
function detectPinch(hand: XRHand, frame: XRFrame, referenceSpace: XRReferenceSpace): boolean {
  const thumbTip = hand.get('thumb-tip');
  const indexTip = hand.get('index-finger-tip');

  if (!thumbTip || !indexTip) return false;

  const thumbPose = frame.getJointPose(thumbTip, referenceSpace);
  const indexPose = frame.getJointPose(indexTip, referenceSpace);

  if (!thumbPose || !indexPose) return false;

  const thumbPos = new THREE.Vector3(
    thumbPose.transform.position.x,
    thumbPose.transform.position.y,
    thumbPose.transform.position.z
  );
  const indexPos = new THREE.Vector3(
    indexPose.transform.position.x,
    indexPose.transform.position.y,
    indexPose.transform.position.z
  );

  const distance = thumbPos.distanceTo(indexPos);
  return distance < 0.02;  // 2cm 以内视为捏合
}
```

## 完整的 VR 交互控制器

将以上概念整合为一个完整的 VR 控制器系统：

```typescript
class VRInteractionController {
  private teleportation = new Teleportation();
  private grabSystem = new GrabSystem();
  private session: XRSession;
  private referenceSpace: XRReferenceSpace;

  constructor(session: XRSession, referenceSpace: XRReferenceSpace) {
    this.session = session;
    this.referenceSpace = referenceSpace;
  }

  update(frame: XRFrame, cameraRig: THREE.Group, grabbables: THREE.Object3D[]): void {
    for (const source of this.session.inputSources) {
      if (!source.gamepad) continue;

      const gripPose = source.gripSpace
        ? frame.getPose(source.gripSpace, this.referenceSpace)
        : null;
      const rayPose = frame.getPose(source.targetRaySpace, this.referenceSpace);

      if (!gripPose && !rayPose) continue;

      const gripPos = gripPose
        ? new THREE.Vector3(gripPose.transform.position.x, gripPose.transform.position.y, gripPose.transform.position.z)
        : null;
      const rayDir = rayPose
        ? new THREE.Vector3(0, 0, -1).applyQuaternion(
            new THREE.Quaternion(rayPose.transform.orientation.x, rayPose.transform.orientation.y, rayPose.transform.orientation.z, rayPose.transform.orientation.w)
          )
        : null;

      const trigger = source.gamepad.buttons[0];
      const grip = source.gamepad.buttons[1];
      const thumbstick = { x: source.gamepad.axes[0], y: source.gamepad.axes[1] };

      // 右手：传送（摇杆前推触发）
      if (source.handedness === 'right' && gripPos && rayDir) {
        if (thumbstick.y < -0.5) {
          this.teleportation.startAiming();
          const ray = new THREE.Ray(gripPos, rayDir);
          this.teleportation.updateAim(ray, []);
        } else if (this.teleportation.isAiming) {
          this.teleportation.stopAiming(cameraRig);
        }
      }

      // 左手：抓取（握持键触发）
      if (source.handedness === 'left' && gripPos) {
        if (grip.pressed && !this.grabSystem.isGrabbing) {
          this.grabSystem.tryGrab(gripPos, grabbables);
        } else if (grip.pressed && this.grabSystem.isGrabbing) {
          const rot = gripPose
            ? new THREE.Quaternion(gripPose.transform.orientation.x, gripPose.transform.orientation.y, gripPose.transform.orientation.z, gripPose.transform.orientation.w)
            : new THREE.Quaternion();
          this.grabSystem.update(gripPos, rot);
        } else if (!grip.pressed && this.grabSystem.isGrabbing) {
          this.grabSystem.release();
        }
      }
    }
  }
}
```

## 常见误区

### 误区一：直接使用原始输入数据

控制器的原始输入数据可能有噪声。按钮应该做防抖处理，摇杆应该设置死区（deadzone），避免轻微漂移导致误操作。

```typescript
// 摇杆死区处理
function applyDeadzone(value: number, deadzone: number = 0.15): number {
  if (Math.abs(value) < deadzone) return 0;
  // 重新映射到 0-1 范围
  return (value - Math.sign(value) * deadzone) / (1 - deadzone);
}
```

### 误区二：传送时忽略用户身高

传送到新位置时，需要考虑用户的物理身高。如果直接设置相机位置到地面，用户会「陷入」地面。

### 误区三：抓取物体后不处理碰撞

抓取物体移动时，物体可能穿过其他物体或墙壁。简单的做法是抓取时禁用物体的碰撞检测，释放时重新启用。

### 误区四：假设所有 VR 控制器布局相同

不同品牌的手柄按键布局不同。应该使用 `XRInputSource.profiles` 来识别设备类型，而不是硬编码按键映射。

## 工程建议

1. **输入抽象层**：建立统一的输入抽象层，将不同控制器的按键映射到统一的语义操作
2. **传送指示器**：使用明显的视觉和音效反馈，让用户清楚知道传送目标
3. **抓取反馈**：抓取和释放物体时提供触觉反馈（`Gamepad.hapticActuators`）
4. **手部追踪降级**：当控制器不可用时，提供手部追踪作为替代交互方式
5. **晕动症预防**：避免突然的视角移动，传送时使用淡入淡出过渡

## 小结

本课介绍了 VR 交互的三个核心机制：

- **控制器输入**：通过 `XRInputSource` 和 `Gamepad` API 读取按钮、摇杆和姿态数据
- **传送**：通过射线与地面求交确定目标位置，瞬间移动相机根节点
- **抓取**：通过距离检测找到可交互物体，跟踪控制器姿态实现物体移动

这三种机制构成了 VR 应用的基础交互模式。下一课将介绍如何使用 Three.js 简化这些 XR 功能的实现。

## 参考答案

### 练习一

**思路**：使用映射表将物理按键映射到语义操作，支持运行时修改。

**答案**：
```typescript
type Action = 'select' | 'grab' | 'teleport' | 'turn';

interface InputBinding {
  hand: 'left' | 'right';
  input: 'trigger' | 'grip' | 'thumbstick' | 'button-a' | 'button-b';
  event: 'press' | 'release' | 'axis';
  axisThreshold?: number;
}

class InputMapping {
  private bindings: Map<Action, InputBinding> = new Map([
    ['select', { hand: 'right', input: 'trigger', event: 'press' }],
    ['grab', { hand: 'left', input: 'grip', event: 'press' }],
    ['teleport', { hand: 'right', input: 'thumbstick', event: 'axis', axisThreshold: -0.5 }],
    ['turn', { hand: 'left', input: 'thumbstick', event: 'axis', axisThreshold: 0.5 }],
  ]);

  remap(action: Action, binding: InputBinding): void {
    this.bindings.set(action, binding);
  }

  checkAction(action: Action, source: XRInputSource, gamepad: Gamepad): boolean {
    const binding = this.bindings.get(action);
    if (!binding) return false;
    if (source.handedness !== binding.hand) return false;

    // 检查对应输入...
    return true;
  }
}
```

**要点**：
- 映射表实现了解耦，操作与具体按键分离
- 支持运行时重映射，便于适配不同控制器
- 可以扩展为从配置文件加载映射

### 练习二

**思路**：传送前检查目标位置是否在可行走区域内。

**答案**：
```typescript
class TeleportValidator {
  private bounds: THREE.Box3;

  constructor(bounds: THREE.Box3) {
    this.bounds = bounds;
  }

  validate(target: THREE.Vector3, obstacles: THREE.Mesh[]): boolean {
    // 检查是否在边界内
    if (!this.bounds.containsPoint(target)) {
      return false;
    }

    // 检查是否与障碍物重叠
    const testSphere = new THREE.Sphere(target, 0.3);  // 人体半径 30cm
    for (const obstacle of obstacles) {
      if (!obstacle.userData.walkable) {
        const obstacleBox = new THREE.Box3().setFromObject(obstacle);
        if (testSphere.intersectsBox(obstacleBox)) {
          return false;
        }
      }
    }

    return true;
  }
}
```

**要点**：
- 边界检测防止传送出游戏区域
- 碰撞检测防止传送进物体内部
- 使用球体近似人体体积，简化碰撞计算

### 练习三

**思路**：追踪两只手的距离变化，将距离比映射到物体缩放。

**答案**：
```typescript
class TwoHandScale {
  private initialDistance = 0;
  private initialScale = new THREE.Vector3();
  private target: THREE.Object3D | null = null;

  start(leftPos: THREE.Vector3, rightPos: THREE.Vector3, target: THREE.Object3D): void {
    this.target = target;
    this.initialDistance = leftPos.distanceTo(rightPos);
    this.initialScale.copy(target.scale);
  }

  update(leftPos: THREE.Vector3, rightPos: THREE.Vector3): void {
    if (!this.target) return;

    const currentDistance = leftPos.distanceTo(rightPos);
    const scaleFactor = currentDistance / this.initialDistance;

    this.target.scale.copy(this.initialScale).multiplyScalar(scaleFactor);

    // 限制缩放范围
    this.target.scale.clampScalar(0.1, 10);
  }

  end(): void {
    this.target = null;
  }
}
```

**要点**：
- 记录初始距离和初始缩放，计算相对变化
- 使用比例缩放而非绝对缩放，保持各轴比例一致
- 限制缩放范围防止物体过大或过小
