# 图像追踪与识别

## 场景引入

你去博物馆参观，打开手机 App 对准一幅画作，屏幕上立刻浮现出这幅画的创作背景、画家生平和高清细节放大。这就是图像追踪 AR 的典型应用——设备识别出你对准的图像，然后将虚拟内容精确叠加在图像上方。

图像追踪是 AR 开发中最基础也最成熟的追踪技术。它不需要 GPS、不需要深度传感器，只需要一个摄像头和一组预设的参考图像。

## 学习目标

- 理解图像追踪的核心原理（特征点提取与匹配）
- 使用 AR.js 实现基于标记的图像追踪
- 使用 WebXR Image Tracking API 实现无标记图像追踪
- 掌握追踪质量优化的关键技巧

## 核心概念

### 图像追踪的工作原理

图像追踪的核心流程分为三步：

1. **特征提取**：算法从参考图像中提取关键特征点（角点、边缘等），生成特征描述符
2. **特征匹配**：每一帧相机画面都经过同样的特征提取，然后与参考图像的特征描述符进行匹配
3. **姿态估计**：根据匹配到的特征点，计算相机相对于图像的 3D 位置和旋转

特征描述符通常是 128 维或 256 维的向量，即使图像旋转、缩放、部分遮挡，特征向量仍然能够正确匹配。

### 影响追踪质量的因素

- **图像复杂度**：特征点越多的图像越容易追踪。纯色、对称、重复纹理的图像追踪效果差
- **环境光照**：过暗或过曝都会导致特征提取失败
- **相机角度**：极端倾斜角度下匹配精度下降
- **运动模糊**：快速移动相机导致画面模糊，特征提取失败


## WebXR Image Tracking API

现代浏览器通过 WebXR Device API 原生支持图像追踪：

```javascript
async function startImageTracking() {
  const referenceImages = [
    { src: '/markers/poster.jpg', widthInMeters: 0.3 },
    { src: '/markers/bottle-label.jpg', widthInMeters: 0.08 }
  ];

  const session = await navigator.xr.requestSession('immersive-ar', {
    requiredFeatures: ['image-tracking'],
    trackedImages: referenceImages,
    optionalFeatures: ['dom-overlay'],
    domOverlay: { root: document.getElementById('overlay') }
  });

  const gl = document.createElement('canvas').getContext('webgl2', {
    xrCompatible: true
  });
  await session.updateRenderState({
    baseLayer: new XRWebGLLayer(session, gl)
  });

  const referenceSpace = await session.requestReferenceSpace('local');

  function onXRFrame(time, frame) {
    const results = frame.getImageTrackingResults();
    for (const result of results) {
      const pose = frame.getPose(result.imageSpace, referenceSpace);
      if (result.trackingState === 'tracked') {
        updateARContent(result.index, pose.transform.matrix);
      }
    }
    session.requestAnimationFrame(onXRFrame);
  }

  session.requestAnimationFrame(onXRFrame);
}
```

### 追踪状态管理

```javascript
class ImageTrackingManager {
  constructor() {
    this.trackedImages = new Map();
    this.callbacks = { onFound: [], onLost: [], onUpdate: [] };
  }

  on(event, callback) {
    if (this.callbacks[event]) this.callbacks[event].push(callback);
  }

  processResults(frame, referenceSpace) {
    const results = frame.getImageTrackingResults();
    for (const result of results) {
      const index = result.index;
      const pose = frame.getPose(result.imageSpace, referenceSpace);
      const wasTracked = this.trackedImages.get(index);
      const isTracked = result.trackingState === 'tracked';

      if (!wasTracked && isTracked) {
        this.trackedImages.set(index, 'tracked');
        this.emit('onFound', { index, pose });
      } else if (wasTracked && !isTracked) {
        this.trackedImages.set(index, 'lost');
        this.emit('onLost', { index });
      } else if (isTracked) {
        this.emit('onUpdate', { index, pose });
      }
    }
  }

  emit(event, data) {
    this.callbacks[event].forEach(cb => cb(data));
  }
}
```

## 项目实践：AR 产品展示

构建一个 AR 产品展示页面，用户扫描产品包装盒后显示 3D 模型和信息面板：

```javascript
import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

class ProductShowcaseAR {
  constructor(canvas) {
    this.scene = new THREE.Scene();
    this.camera = new THREE.PerspectiveCamera();
    this.renderer = new THREE.WebGLRenderer({ canvas, alpha: true });
    this.loader = new GLTFLoader();
    this.productModel = null;
  }

  async init() {
    const session = await navigator.xr.requestSession('immersive-ar', {
      requiredFeatures: ['image-tracking'],
      trackedImages: [{ src: '/markers/product-box.jpg', widthInMeters: 0.2 }]
    });

    this.renderer.xr.enabled = true;
    await this.renderer.xr.setSession(session);

    this.productModel = await this.loadModel('/models/product.glb');
    this.productModel.visible = false;
    this.scene.add(this.productModel);

    this.addLighting();
    this.renderer.setAnimationLoop(this.render.bind(this));
  }

  async loadModel(url) {
    return new Promise((resolve, reject) => {
      this.loader.load(url, (gltf) => {
        const model = gltf.scene;
        model.scale.set(0.1, 0.1, 0.1);
        resolve(model);
      }, null, reject);
    });
  }

  addLighting() {
    this.scene.add(new THREE.AmbientLight(0xffffff, 0.6));
    const dir = new THREE.DirectionalLight(0xffffff, 0.8);
    dir.position.set(1, 2, 1);
    this.scene.add(dir);
  }

  render(time, frame) {
    if (frame) {
      const results = frame.getImageTrackingResults();
      for (const result of results) {
        if (result.trackingState === 'tracked') {
          const pose = frame.getPose(result.imageSpace,
            this.renderer.xr.getReferenceSpace());
          this.productModel.visible = true;
          this.productModel.position.setFromMatrixPosition(
            new THREE.Matrix4().fromArray(pose.transform.matrix)
          );
        }
      }
    }
    this.renderer.render(this.scene, this.camera);
  }
}
```

## 常见误区

### 1. 以为任何图像都能追踪

纯色、低对比度、对称重复纹理的图像无法提取足够特征点。好的追踪图像应有丰富纹理、高对比度和不对称结构。

### 2. 忽视参考图像的物理尺寸

`widthInMeters` 决定了虚拟内容与现实图像的尺寸比例。设置错误会导致 3D 模型过大或过小，必须精确测量实际图像的物理宽度。

### 3. 追踪丢失后不做降级处理

追踪丢失后应短暂保持虚拟内容的位置（利用最后已知的姿态），渐隐消失，而不是突然消失。

## 工程建议

1. **图像预处理**：上线前用特征点检测工具预检图像质量，低于 100 个特征点的图像应替换
2. **多图限制**：同时追踪多张图像时，建议限制在 5 张以内以控制性能开销
3. **尺寸标注**：在管理后台维护每张图像的精确物理尺寸
4. **降级策略**：追踪丢失超过 2 秒时，显示提示文字引导用户重新对准
5. **内存管理**：参考图像会在内存中保留特征数据，不再使用时及时释放

## 小结

图像追踪是 AR 技术中最成熟的追踪方式，理解它的原理（特征提取 → 匹配 → 姿态估计）是学习更高级追踪技术的基础。在实际项目中，关键是选择合适的参考图像、精确设置物理尺寸、实现优雅的降级策略。

## 参考答案

### 练习一

**思路**：通过 Sobel 算子计算图像的边缘密度来评估特征丰富度。梯度幅度大的像素越多，说明边缘和特征越丰富。

**答案**：

```javascript
function assessImageQuality(imageElement) {
  const canvas = document.createElement('canvas');
  const ctx = canvas.getContext('2d');
  canvas.width = 200;
  canvas.height = Math.round((imageElement.height / imageElement.width) * 200);
  ctx.drawImage(imageElement, 0, 0, canvas.width, canvas.height);

  const imageData = ctx.getImageData(0, 0, canvas.width, canvas.height);
  const gray = new Uint8Array(canvas.width * canvas.height);
  for (let i = 0; i < gray.length; i++) {
    const d = imageData.data;
    gray[i] = Math.round(0.299 * d[i*4] + 0.587 * d[i*4+1] + 0.114 * d[i*4+2]);
  }

  let edgeCount = 0;
  const w = canvas.width, h = canvas.height;
  for (let y = 1; y < h - 1; y++) {
    for (let x = 1; x < w - 1; x++) {
      const idx = y * w + x;
      const gx = -gray[idx-w-1] + gray[idx-w+1] - 2*gray[idx-1] + 2*gray[idx+1]
                 - gray[idx+w-1] + gray[idx+w+1];
      const gy = -gray[idx-w-1] - 2*gray[idx-w] - gray[idx-w+1]
                 + gray[idx+w-1] + 2*gray[idx+w] + gray[idx+w+1];
      if (Math.sqrt(gx*gx + gy*gy) > 30) edgeCount++;
    }
  }

  return Math.min(100, Math.round(edgeCount / ((w-2) * (h-2)) * 300));
}
```

**要点**：缩小到 200px 宽度加速计算；标准 luminance 公式灰度化；Sobel 算子计算梯度后取幅值；边缘占比乘以 300 是经验值。

### 练习二

**思路**：维护每张图像的三态（lost → tracked → fading），追踪丢失时启动 500ms 渐隐动画。

**答案**：

```javascript
class MultiImageTracker {
  constructor() {
    this.trackers = new Map();
  }

  register(index, sceneObject) {
    this.trackers.set(index, {
      object: sceneObject, state: 'lost', fadeStart: null
    });
    sceneObject.visible = false;
  }

  processFrame(frame) {
    const refSpace = frame.session.requestReferenceSpace('local');
    const results = frame.getImageTrackingResults();

    for (const result of results) {
      const tracker = this.trackers.get(result.index);
      if (!tracker) continue;

      if (result.trackingState === 'tracked') {
        const pose = frame.getPose(result.imageSpace, refSpace);
        tracker.state = 'tracked';
        tracker.fadeStart = null;
        tracker.object.visible = true;
        tracker.object.position.setFromMatrixPosition(
          new THREE.Matrix4().fromArray(pose.transform.matrix)
        );
      } else if (tracker.state === 'tracked') {
        tracker.state = 'fading';
        tracker.fadeStart = performance.now();
      }
    }

    const now = performance.now();
    for (const [, tracker] of this.trackers) {
      if (tracker.state === 'fading' && tracker.fadeStart) {
        const progress = Math.min((now - tracker.fadeStart) / 500, 1);
        tracker.object.traverse(c => {
          if (c.material) { c.material.transparent = true; c.material.opacity = 1 - progress; }
        });
        if (progress >= 1) { tracker.state = 'lost'; tracker.object.visible = false; }
      }
    }
  }
}
```

**要点**：三态管理确保状态转换清晰；`performance.now()` 驱动渐隐动画；遍历模型所有子节点设置透明度。
