# 图像追踪：让 AR 识别真实世界的图片

## 当前项目状态

你已经能让虚拟物体出现在真实环境中。但用户要手动放置物体——他们想要的是：手机对准一张海报，虚拟内容自动浮现在海报上方。

图像追踪是 AR 中最成熟的追踪技术。不需要 GPS、不需要深度传感器，只需要摄像头和一组预设的参考图像。

## 工作原理

```
1. 特征提取：从参考图像中提取关键特征点（角点、边缘）
2. 特征匹配：每帧相机画面提取特征后与参考图像匹配
3. 姿态估计：根据匹配点计算相机相对于图像的 3D 位置和旋转
```

特征描述符是 128 维或 256 维的向量，即使图像旋转、缩放、部分遮挡，也能正确匹配。

## 影响追踪质量的因素

```
图像复杂度   → 纯色/对称/重复纹理追踪效果差
环境光照     → 过暗或过曝都会导致特征提取失败
相机角度     → 极端倾斜角度下匹配精度下降
运动模糊     → 快速移动相机导致特征提取失败
```

选择参考图像时，优先用特征点多的图片（杂志封面、电影海报），避免纯色、对称、重复图案。

## WebXR Image Tracking API

Chrome 81+ 支持的原生图像追踪 API：

```typescript
async function startImageTracking(session: XRSession) {
  // 准备参考图像
  const imageBitmap = await createImageBitmap(
    await (await fetch('/images/poster.jpg')).blob()
  )

  const tracker = await session.trackedImages?.add(imageBitmap, {
    widthInMeters: 0.3 // 图片在真实世界中的宽度
  })

  return tracker
}
```

在帧循环中获取追踪结果：

```typescript
function onXRFrame(time: DOMHighResTimeStamp, frame: XRFrame) {
  const results = frame.getImageTrackingResults()

  for (const result of results) {
    const pose = frame.getPose(result.imageSpace, refSpace)
    if (!pose) continue

    const state = result.trackingState // 'tracked' | 'emulated'

    if (state === 'tracked') {
      // 图像被检测到，更新虚拟内容位置
      posterOverlay.visible = true
      posterOverlay.position.set(
        pose.transform.position.x,
        pose.transform.position.y,
        pose.transform.position.z
      )
      posterOverlay.quaternion.set(
        pose.transform.orientation.x,
        pose.transform.orientation.y,
        pose.transform.orientation.z,
        pose.transform.orientation.w
      )
    } else {
      // 追踪丢失（图像被遮挡或离开视野）
      // 保持最后已知位置，或渐隐
      posterOverlay.visible = false
    }
  }

  session.requestAnimationFrame(onXRFrame)
}
```

## AR.js 方案（兼容性更好）

AR.js 基于 ARToolKit，支持更多浏览器，适合需要兼容旧设备的场景：

```html
<script src="https://aframe.io/releases/1.4.0/aframe.min.js"></script>
<script src="https://raw.githack.com/AR-js-org/AR.js/master/aframe/build/aframe-ar.js"></script>

<a-scene arjs="sourceType: webcam; debugUIEnabled: false;">
  <a-marker preset="hiro">
    <a-box position="0 0.5 0" color="red" scale="0.5 0.5 0.5"></a-box>
  </a-marker>
  <a-entity camera></a-entity>

```

AR.js 用预设的 marker 图案（如 Hiro marker），不需要自己制作参考图像。但精度和灵活性不如 WebXR Image Tracking。

## 多图像追踪

同时追踪多张图片，每张对应不同的虚拟内容：

```typescript
async function setupMultiImageTracking(session: XRSession) {
  const images = [
    { src: '/images/poster.jpg', width: 0.3, content: 'video' },
    { src: '/images/menu.jpg', width: 0.2, content: '3d-model' },
    { src: '/images/logo.jpg', width: 0.15, content: 'animation' }
  ]

  for (const img of images) {
    const bitmap = await createImageBitmap(await (await fetch(img.src)).blob())
    await session.trackedImages?.add(bitmap, { widthInMeters: img.width })
  }
}
```

## 追踪质量优化

**1. 图像预处理**

在上传参考图像前，确保它有足够的对比度和特征点：

```typescript
function analyzeImageQuality(imageData: ImageData): {
  score: number, recommendation: string
} {
  // 简化的质量评估：检查对比度和边缘密度
  let edgeCount = 0
  for (let i = 0; i < imageData.data.length; i += 4) {
    const r = imageData.data[i], g = imageData.data[i+1], b = imageData.data[i+2]
    const brightness = (r + g + b) / 3
    if (brightness < 50 || brightness > 200) edgeCount++
  }

  const edgeRatio = edgeCount / (imageData.width * imageData.height)
  return {
    score: edgeRatio,
    recommendation: edgeRatio > 0.3 ? '适合追踪' : '特征点不足，建议换图'
  }
}
```

**2. 环境自适应**

根据光照条件调整追踪参数：

```typescript
function adaptToLighting(frame: XRFrame) {
  const lightEstimate = frame.getLightEstimate?.()
  if (lightEstimate) {
    const intensity = lightEstimate.primaryLightIntensity
    if (intensity.x < 0.3) {
      showHint('环境太暗，追踪可能不稳定')
    }
  }
}
```

## 你可能踩的坑

**坑一：参考图像分辨率太高**

太大的图像会增加特征提取时间，导致追踪延迟。建议参考图像宽度 500-1000 像素。

**坑二：不做追踪丢失处理**

追踪丢失是常态——用户转头、遮挡图像、光线变化都会导致。必须有降级方案：保持最后位置、显示提示、或切换到其他追踪方式。

**坑三：忘记设置图像真实尺寸**

`widthInMeters` 如果不设或设错，虚拟物体的大小会和真实世界不匹配。

### 练习二

```typescript
function analyzeReferenceImage(canvas: HTMLCanvasElement): {
  score: number
  features: string[]
  suggestions: string[]
} {
  const ctx = canvas.getContext('2d')!
  const data = ctx.getImageData(0, 0, canvas.width, canvas.height)
  const features: string[] = []
  const suggestions: string[] = []

  // 检查对比度
  let min = 255, max = 0
  for (let i = 0; i < data.data.length; i += 4) {
    const gray = (data.data[i] + data.data[i+1] + data.data[i+2]) / 3
    min = Math.min(min, gray)
    max = Math.max(max, gray)
  }
  const contrast = max - min
  if (contrast > 128) features.push('对比度良好')
  else suggestions.push('增加图像对比度')

  // 检查对称性（简化）
  const score = Math.min(100, contrast / 1.28)
  return { score, features, suggestions }
}
```
