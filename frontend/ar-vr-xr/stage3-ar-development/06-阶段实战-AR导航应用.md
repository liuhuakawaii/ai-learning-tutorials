# 阶段实战：AR 导航——多源定位融合

## 当前项目状态

前五课分别学了图像追踪、面部追踪、物体追踪、GPS AR 和 LiDAR。真实项目不会只用一种技术——你需要把它们融合起来。本课构建一个 AR 导航应用：室外用 GPS，室内切换到视觉定位，到达目标时用图像标记精确对齐。

## 多源定位的核心问题

每个定位源都有精度和延迟的权衡：

```
定位源         精度      延迟      适用场景
GPS            5-10m     1s        室外
IMU            累积漂移   实时      短距离运动
视觉里程计      1-3m      100ms     室内
图像标记        <0.5m     50ms      精确到达
LiDAR          <0.1m     实时      环境扫描
```

单一源都不够用。GPS 精度太差，IMU 会漂移，视觉定位在空旷环境失效。解决方案是**加权融合**。

## 定位融合管理器

```typescript
interface PositionSource {
  name: string
  position: { lat: number; lng: number; alt: number }
  accuracy: number
  lastUpdate: number
  weight: number
}

class PositionFusionManager {
  private sources = new Map<string, PositionSource>()

  register(name: string, weight: number) {
    this.sources.set(name, {
      name, weight, accuracy: Infinity,
      position: { lat: 0, lng: 0, alt: 0 },
      lastUpdate: 0
    })
  }

  update(name: string, position: PositionSource['position'], accuracy: number) {
    const source = this.sources.get(name)
    if (!source) return
    source.position = position
    source.accuracy = accuracy
    source.lastUpdate = performance.now()
  }

  getFusedPosition(): { lat: number; lng: number; alt: number } | null {
    const now = performance.now()
    let totalWeight = 0
    let lat = 0, lng = 0, alt = 0

    for (const source of this.sources.values()) {
      // 忽略过期数据（超过 5 秒）
      if (now - source.lastUpdate > 5000) continue

      // 权重 = 基础权重 × 精度倒数 × 时间衰减
      const age = (now - source.lastUpdate) / 1000
      const timeDecay = Math.exp(-age * 0.5)
      const w = source.weight * (1 / source.accuracy) * timeDecay

      lat += source.position.lat * w
      lng += source.position.lng * w
      alt += source.position.alt * w
      totalWeight += w
    }

    if (totalWeight === 0) return null
    return { lat: lat / totalWeight, lng: lng / totalWeight, alt: alt / totalWeight }
  }
}
```

## 路径渲染

导航路径用 Three.js 的 `Line` 渲染，颜色表示方向：

```typescript
class NavigationPath {
  private pathLine: THREE.Line
  private arrowMarkers: THREE.Mesh[] = []

  constructor(private scene: THREE.Scene) {
    const material = new THREE.LineBasicMaterial({
      color: 0x00ff88, linewidth: 2
    })
    const geometry = new THREE.BufferGeometry()
    this.pathLine = new THREE.Line(geometry, material)
    scene.add(this.pathLine)
  }

  updatePath(points: THREE.Vector3[]) {
    this.pathLine.geometry.setFromPoints(points)
    this.updateArrows(points)
  }

  private updateArrows(points: THREE.Vector3[]) {
    // 清除旧箭头
    this.arrowMarkers.forEach(m => this.scene.remove(m))
    this.arrowMarkers = []

    // 每隔 5 米放一个方向箭头
    for (let i = 0; i < points.length - 1; i += 5) {
      const arrow = this.createArrow()
      arrow.position.copy(points[i])
      arrow.lookAt(points[Math.min(i + 1, points.length - 1)])
      this.scene.add(arrow)
      this.arrowMarkers.push(arrow)
    }
  }

  private createArrow(): THREE.Mesh {
    const geometry = new THREE.ConeGeometry(0.2, 0.5, 8)
    const material = new THREE.MeshStandardMaterial({ color: 0x00ff88 })
    const cone = new THREE.Mesh(geometry, material)
    cone.rotation.x = Math.PI / 2
    return cone
  }
}
```

## 你可能踩的坑

**坑一：GPS 首次定位太慢**

GPS 冷启动可能需要 30 秒。在 GPS 信号获取前，用 IMU + 视觉里程计提供临时定位，并在 UI 上显示"正在搜索信号"。

**坑二：坐标系不统一**

GPS 用经纬度，3D 渲染用 XYZ。需要一个统一的坐标系转换层。建议用起始点作为原点，经纬度转换为相对米数。

**坑三：路径点太少导致导航箭头跳动**

路径插值很重要。原始 GPS 路径点可能间隔 10 米以上，直接渲染箭头会很卡顿。用 CatmullRom 曲线平滑路径。
