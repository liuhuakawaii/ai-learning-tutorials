# 阶段三：AR 开发

## 阶段概述

本阶段聚焦增强现实（Augmented Reality）的核心开发技术。从图像追踪、面部追踪到物体识别，从 GPS 地理定位 AR 到 LiDAR 环境扫描，逐步掌握 AR 应用的关键能力。最终通过一个完整的 AR 导航应用，将本阶段所有知识融会贯通。

## 学习目标

完成本阶段后，你将能够：

- 使用 WebXR 和 AR.js 实现图像追踪与识别
- 利用面部追踪技术实现虚拟试妆、表情捕捉等应用
- 实现 3D 物体识别与虚拟模型对齐
- 基于 GPS 定义地理围栏，构建位置感知 AR 体验
- 使用 LiDAR 传感器进行环境扫描与三维网格重建
- 独立完成一个完整的 AR 导航应用

## 前置要求

- 完成阶段一（3D 数学与渲染基础）和阶段二（WebXR 基础）
- 熟悉 Three.js 基本用法
- 了解 WebGL 渲染管线
- 有基本的移动端调试经验

## 学习建议

1. **循序渐进**：课程按追踪精度从粗到细排列，GPS → 图像 → 面部 → 物体 → LiDAR，建议按顺序学习
2. **真机调试**：AR 功能高度依赖设备传感器，务必使用真机测试，模拟器无法替代
3. **关注光照**：AR 追踪效果受环境光照影响很大，调试时注意不同光照条件下的表现
4. **性能优先**：移动端 GPU 算力有限，始终关注帧率，避免在每一帧中执行昂贵的计算

## 阶段项目

本阶段的最终实战项目是 **AR 导航应用**，要求：

- 支持 GPS 粗定位 + 视觉精定位的双层定位方案
- 在相机画面上叠加 3D 箭头导航
- 实时显示距离和预计到达时间
- 支持离线地图数据缓存
- 帧率稳定在 30fps 以上
