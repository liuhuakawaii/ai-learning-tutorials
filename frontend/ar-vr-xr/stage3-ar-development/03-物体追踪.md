# 物体追踪与模型对齐

## 场景引入

工程师戴上 AR 眼镜看向一台发动机，屏幕上立刻在各个零部件上方浮现出名称和运行参数。用手机扫描一个玩具盒，屏幕上跳出这个玩具的 3D 模型。这就是物体追踪 AR——设备识别出你对准的 3D 物体，将虚拟内容精确对齐到物体表面。

## 学习目标

- 理解 3D 物体识别与图像追踪的本质区别
- 掌握点云匹配和 3D 特征描述的核心概念
- 使用多标记融合方案实现物体追踪
- 了解物体追踪的精度限制和优化策略

## 核心概念

### 物体追踪 vs 图像追踪

| 维度 | 图像追踪 | 物体追踪 |
|------|----------|----------|
| 目标 | 平面图像 | 3D 物体 |
| 特征 | 2D 角点、纹理 | 3D 点云、表面特征 |
| 姿态自由度 | 3 平移 + 2 旋转 | 3 平移 + 3 旋转 |
| 典型应用 | 书籍、海报 | 工业设备、玩具 |

### 3D 物体识别流程

```
离线阶段：3D 扫描 → 点云生成 → 3D 特征提取 → 构建特征数据库
在线阶段：相机帧 → 2D 特征提取 → 与数据库匹配 → 6DoF 姿态估计
```

离线阶段从多角度拍摄物体，生成完整 3D 特征数据库。在线阶段实时匹配特征并估计 6DoF 姿态。

## 多标记融合方案

WebXR 原生不支持通用 3D 物体追踪。实用方案是在物体表面粘贴多个图像标记：

```javascript
class MultiMarkerObjectTracker {
  constructor() {
    this.markers = new Map();
    this.objectPose = null;
  }

  registerMarker(index, offsetTransform) {
    this.markers.set(index, { offset: offsetTransform, lastPose: null });
  }

  updateFromImageTracking(results, frame, referenceSpace) {
    const visiblePoses = [];
    for (const result of results) {
      if (result.trackingState !== 'tracked') continue;
      const marker = this.markers.get(result.index);
      if (!marker) continue;

      const pose = frame.getPose(result.imageSpace, referenceSpace);
      const markerMatrix = new THREE.Matrix4().fromArray(pose.transform.matrix);
      const offsetMatrix = new THREE.Matrix4().fromArray(marker.offset);
      visiblePoses.push(markerMatrix.multiply(offsetMatrix));
    }

    if (visiblePoses.length > 0) {
      this.objectPose = this.averagePoses(visiblePoses);
    }
  }

  averagePoses(poses) {
    const avgPos = new THREE.Vector3();
    const avgQuat = new THREE.Quaternion();
    for (const pose of poses) {
      avgPos.add(new THREE.Vector3().setFromMatrixPosition(pose));
      avgQuat.slerp(new THREE.Quaternion().setFromRotationMatrix(pose), 1 / poses.length);
    }
    avgPos.divideScalar(poses.length);
    const result = new THREE.Matrix4();
    result.compose(avgPos, avgQuat, new THREE.Vector3(1, 1, 1));
    return result;
  }
}
```

### 基于 3D 扫描的物体识别

对于高级场景，可以使用第三方 SDK 或自建 3D 特征数据库：

```javascript
class ObjectRecognitionService {
  constructor(apiEndpoint) { this.apiEndpoint = apiEndpoint; }

  async scanObject(imageData, cameraIntrinsics) {
    const res = await fetch(`${this.apiEndpoint}/recognize`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ image: imageData, intrinsics: cameraIntrinsics })
    });
    const result = await res.json();
    if (result.matched) {
      return {
        objectId: result.objectId,
        pose: new THREE.Matrix4().fromArray(result.pose),
        confidence: result.confidence
      };
    }
    return null;
  }
}
```

## 模型对齐与 ICP 算法

ICP（Iterative Closest Point）用于微调初始姿态估计：

```javascript
class ICPAligner {
  constructor(maxIter = 20, threshold = 0.001) {
    this.maxIter = maxIter;
    this.threshold = threshold;
  }

  align(sourcePoints, targetPoints, initialTransform) {
    let transform = initialTransform.clone();
    let prevError = Infinity;

    for (let iter = 0; iter < this.maxIter; iter++) {
      const transformed = sourcePoints.map(p =>
        new THREE.Vector3(p.x, p.y, p.z).applyMatrix4(transform)
      );

      const matches = transformed.map(sp => {
        let minDist = Infinity, nearest = null;
        for (const tp of targetPoints) {
          const dist = sp.distanceTo(tp);
          if (dist < minDist) { minDist = dist; nearest = tp; }
        }
        return { source: sp, target: nearest, distance: minDist };
      });

      const error = matches.reduce((s, m) => s + m.distance, 0) / matches.length;
      if (Math.abs(prevError - error) < this.threshold) break;
      prevError = error;

      const srcCenter = new THREE.Vector3();
      const tgtCenter = new THREE.Vector3();
      matches.forEach(m => { srcCenter.add(m.source); tgtCenter.add(m.target); });
      srcCenter.divideScalar(matches.length);
      tgtCenter.divideScalar(matches.length);

      const delta = new THREE.Matrix4();
      delta.makeTranslation(
        tgtCenter.x - srcCenter.x, tgtCenter.y - srcCenter.y, tgtCenter.z - srcCenter.z
      );
      transform = delta.multiply(transform);
    }
    return transform;
  }
}
```

## 项目实践：工业设备 AR 标注

```javascript
class IndustrialARAnnotation {
  constructor() {
    this.annotations = [];
    this.objectTracker = new MultiMarkerObjectTracker();
  }

  registerEquipment(equipmentId, markers, annotationPoints) {
    markers.forEach(m => this.objectTracker.registerMarker(m.index, m.offset));
    annotationPoints.forEach(p => {
      this.annotations.push({
        equipmentId,
        localPosition: new THREE.Vector3(p.x, p.y, p.z),
        label: p.label,
        status: p.initialStatus || 'normal',
        sprite: null
      });
    });
  }

  createLabelSprite(text, status) {
    const canvas = document.createElement('canvas');
    canvas.width = 256; canvas.height = 64;
    const ctx = canvas.getContext('2d');
    const colors = { normal: '#4caf50', warning: '#ff9800', error: '#f44336' };
    ctx.fillStyle = colors[status] || colors.normal;
    ctx.roundRect(0, 0, 256, 64, 8); ctx.fill();
    ctx.fillStyle = '#fff'; ctx.font = '20px sans-serif';
    ctx.textAlign = 'center'; ctx.fillText(text, 128, 40);
    const texture = new THREE.CanvasTexture(canvas);
    return new THREE.Sprite(new THREE.SpriteMaterial({ map: texture, transparent: true }));
  }

  update(scene) {
    if (!this.objectTracker.objectPose) return;
    this.annotations.forEach(a => {
      if (!a.sprite) { a.sprite = this.createLabelSprite(a.label, a.status); scene.add(a.sprite); }
      a.sprite.position.copy(a.localPosition.clone().applyMatrix4(this.objectTracker.objectPose));
    });
  }
}
```

## 常见误区

### 1. 以为物体追踪可以识别任意物体

当前物体追踪需要预先扫描和注册物体。无监督的通用物体识别仍在研究阶段，不能用于生产环境。

### 2. 忽视光照变化的影响

物体表面的光照变化会显著影响特征提取。需要在多种光照条件下验证追踪稳定性。

### 3. 对齐精度不够就直接渲染

应设置置信度阈值，低于阈值时使用上一帧的平滑姿态，避免虚拟内容抖动。

## 工程建议

1. **多标记策略**：大型设备在不同面粘贴多个标记，提高识别成功率
2. **姿态平滑**：使用卡尔曼滤波器或指数移动平均平滑姿态输出
3. **LOD 策略**：远处物体使用低精度标注，近处使用高精度细节
4. **离线缓存**：将 3D 特征数据库缓存到本地，避免重复加载
5. **功耗管理**：物体追踪计算量大，非连续追踪时降低处理频率

## 小结

物体追踪让 AR 从"平面增强"走向"空间理解"，为工业维护、零售体验等场景打开新的可能。当前浏览器环境下的物体追踪仍需要多标记融合或第三方 SDK 的支持。

## 参考答案

### 练习一

**思路**：使用 DeviceOrientationEvent 获取设备朝向，将 360° 分为 8 个 45° 扇区，记录覆盖情况。

**答案**：

```javascript
class ObjectScanner {
  constructor() {
    this.sectors = 8;
    this.captured = new Set();
    this.heading = undefined;
  }

  async init() {
    if (typeof DeviceOrientationEvent.requestPermission === 'function') {
      const perm = await DeviceOrientationEvent.requestPermission();
      if (perm !== 'granted') return;
    }
    window.addEventListener('deviceorientation', e => { this.heading = e.alpha; });
  }

  getCurrentSector() {
    if (this.heading === undefined) return -1;
    return Math.floor(this.heading / 45) % this.sectors;
  }

  async capturePhoto(videoElement) {
    const sector = this.getCurrentSector();
    if (sector < 0) return { success: false, message: '无法获取设备朝向' };
    if (this.captured.has(sector)) return { success: false, message: '该角度已拍摄' };

    const canvas = document.createElement('canvas');
    canvas.width = videoElement.videoWidth;
    canvas.height = videoElement.videoHeight;
    canvas.getContext('2d').drawImage(videoElement, 0, 0);
    const blob = await new Promise(r => canvas.toBlob(r, 'image/jpeg', 0.8));
    this.captured.add(sector);

    const remaining = [];
    for (let i = 0; i < this.sectors; i++) {
      if (!this.captured.has(i)) remaining.push(i * 45);
    }
    return { success: true, sector, coverage: this.captured.size / this.sectors, remaining };
  }

  isComplete() { return this.captured.size >= this.sectors; }
}
```

**要点**：8 个扇区确保全方位覆盖；DeviceOrientationEvent 需要用户授权；防止重复拍摄。

### 练习二

**思路**：使用 Raycaster 检测点击在 3D 模型表面的位置，Canvas 动态生成标注精灵图。

**答案**：

```javascript
class ARAnnotationEditor {
  constructor(scene, camera, renderer) {
    this.scene = scene; this.camera = camera; this.renderer = renderer;
    this.raycaster = new THREE.Raycaster();
    this.mouse = new THREE.Vector2();
    this.annotations = [];
    this.targetMesh = null;
    this.selected = null;
    this.isDragging = false;
  }

  setTarget(mesh) { this.targetMesh = mesh; }

  onPointerDown(event) {
    const rect = this.renderer.domElement.getBoundingClientRect();
    this.mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
    this.mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
    this.raycaster.setFromCamera(this.mouse, this.camera);

    const intersects = this.raycaster.intersectObject(this.targetMesh, true);
    if (intersects.length > 0) {
      const existing = this.annotations.find(a =>
        a.sprite.position.distanceTo(intersects[0].point) < 0.05
      );
      if (existing) { this.selected = existing; this.isDragging = true; }
      else this.addAnnotation(intersects[0].point.clone());
    }
  }

  onPointerMove(event) {
    if (!this.isDragging || !this.selected) return;
    const rect = this.renderer.domElement.getBoundingClientRect();
    this.mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
    this.mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
    this.raycaster.setFromCamera(this.mouse, this.camera);
    const hits = this.raycaster.intersectObject(this.targetMesh, true);
    if (hits.length > 0) {
      this.selected.sprite.position.copy(hits[0].point);
      this.selected.surfacePoint = hits[0].point.clone();
    }
  }

  onPointerUp() { this.isDragging = false; this.selected = null; }

  addAnnotation(position) {
    const canvas = document.createElement('canvas');
    canvas.width = 128; canvas.height = 64;
    const ctx = canvas.getContext('2d');
    ctx.fillStyle = 'rgba(33, 150, 243, 0.9)';
    ctx.roundRect(0, 0, 128, 64, 6); ctx.fill();
    ctx.fillStyle = '#fff'; ctx.font = '16px sans-serif';
    ctx.textAlign = 'center'; ctx.fillText('点击编辑', 64, 40);

    const sprite = new THREE.Sprite(
      new THREE.SpriteMaterial({ map: new THREE.CanvasTexture(canvas), transparent: true })
    );
    sprite.scale.set(0.15, 0.075, 1);
    sprite.position.copy(position);
    this.scene.add(sprite);
    const annotation = { id: Date.now(), sprite, surfacePoint: position.clone(), label: '未命名' };
    this.annotations.push(annotation);
    return annotation;
  }

  exportAnnotations() {
    return this.annotations.map(a => ({
      id: a.id, label: a.label,
      position: { x: a.surfacePoint.x, y: a.surfacePoint.y, z: a.surfacePoint.z }
    }));
  }
}
```

**要点**：Raycaster 将 2D 坐标转换为 3D 射线；接近现有标注时进入拖拽模式；Canvas 动态生成纹理支持运行时修改。
