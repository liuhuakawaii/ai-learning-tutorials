# 面部追踪与虚拟试妆

## 场景引入

打开某短视频 App，选择一个"猫耳朵"特效，你的脸上立刻出现了可爱的猫耳朵和胡须——转头、低头，装饰物都稳稳地跟着你的脸移动。再打开某美妆品牌的小程序，对准自己的脸，不同色号的口红实时渲染在嘴唇上。

这些应用的核心技术就是面部追踪。它需要实时检测面部位置、提取面部关键点、构建面部 3D 网格，然后将虚拟内容精确对齐到面部特征上。

## 学习目标

- 理解面部检测与面部关键点追踪的工作原理
- 使用 MediaPipe Face Mesh 获取 468 个面部关键点
- 实现面部网格渲染与虚拟贴图
- 构建一个完整的 AR 虚拟试妆应用

## 核心概念

### 面部检测与关键点追踪

面部追踪分为两个阶段：

1. **面部检测**：在画面中找到人脸的位置。现代方法使用深度学习（如 BlazeFace 模型）
2. **关键点定位**：在检测到的人脸区域内定位 468 个 3D 关键点（眼睑、嘴唇、鼻翼、眉毛等）

每个关键点都有 x、y、z 三个坐标，其中 z 表示深度信息。468 个关键点通过预定义的三角剖分（约 900 个三角形）组成完整的面部网格。

### MediaPipe Face Mesh

MediaPipe 是 Google 开源的多媒体处理框架，Face Mesh 的处理流程：

```
相机帧 → 人脸检测（BlazeFace）→ 关键点定位（468 点）→ 三角网格化 → 输出
```

启用 `refineLandmarks` 后可额外追踪虹膜，总计 478 个关键点。

## MediaPipe Face Mesh 集成

```javascript
import { FaceMesh } from '@mediapipe/face_mesh';
import { Camera } from '@mediapipe/camera_utils';

class FaceTracker {
  constructor(videoElement) {
    this.video = videoElement;
    this.faceMesh = new FaceMesh({
      locateFile: (file) => `https://cdn.jsdelivr.net/npm/@mediapipe/face_mesh/${file}`
    });
    this.faceMesh.setOptions({
      maxNumFaces: 1,
      refineLandmarks: true,
      minDetectionConfidence: 0.5,
      minTrackingConfidence: 0.5
    });
    this.faceMesh.onResults(this.onResults.bind(this));
    this.landmarks = null;
    this.callbacks = [];
  }

  async start() {
    const camera = new Camera(this.video, {
      onFrame: async () => { await this.faceMesh.send({ image: this.video }); },
      width: 640, height: 480, facingMode: 'user'
    });
    await camera.start();
  }

  onResults(results) {
    if (results.multiFaceLandmarks?.length > 0) {
      this.landmarks = results.multiFaceLandmarks[0];
      this.callbacks.forEach(cb => cb(this.landmarks));
    }
  }

  onUpdate(callback) { this.callbacks.push(callback); }

  getLipOuterIndices() {
    return [61, 146, 91, 181, 84, 17, 314, 405, 321, 375, 291, 409, 270, 269, 267, 0, 37, 39, 40, 185];
  }
}
```

## 虚拟试妆实现

### 嘴唇着色

```javascript
class LipstickRenderer {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.color = '#ff0040';
    this.opacity = 0.7;
  }

  render(landmarks) {
    if (!landmarks) return;
    const lipOuter = [61, 146, 91, 181, 84, 17, 314, 405, 321, 375, 291, 409, 270, 269, 267, 0, 37, 39, 40, 185];
    const lipInner = [78, 191, 80, 81, 82, 13, 312, 311, 310, 415, 308, 324, 318, 402, 317, 14, 87, 178, 88, 95];

    this.ctx.save();
    this.ctx.globalAlpha = this.opacity;
    this.ctx.fillStyle = this.color;

    // 绘制外唇轮廓
    this.ctx.beginPath();
    this.drawSmoothPath(lipOuter.map(i => ({
      x: landmarks[i].x * this.canvas.width,
      y: landmarks[i].y * this.canvas.height
    })));
    this.ctx.fill();

    // 擦除内唇区域（避免覆盖牙齿）
    this.ctx.globalCompositeOperation = 'destination-out';
    this.ctx.beginPath();
    this.drawSmoothPath(lipInner.map(i => ({
      x: landmarks[i].x * this.canvas.width,
      y: landmarks[i].y * this.canvas.height
    })));
    this.ctx.fill();
    this.ctx.restore();
  }

  drawSmoothPath(points) {
    if (points.length < 3) return;
    this.ctx.moveTo(points[0].x, points[0].y);
    for (let i = 1; i < points.length - 1; i++) {
      const xc = (points[i].x + points[i+1].x) / 2;
      const yc = (points[i].y + points[i+1].y) / 2;
      this.ctx.quadraticCurveTo(points[i].x, points[i].y, xc, yc);
    }
    this.ctx.closePath();
  }

  setColor(hex) { this.color = hex; }
  setOpacity(value) { this.opacity = Math.max(0, Math.min(1, value)); }
}
```

### 3D 面部遮罩渲染

```javascript
import * as THREE from 'three';

class FaceMask3D {
  constructor(renderer) {
    this.scene = new THREE.Scene();
    this.camera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0.1, 10);
    this.camera.position.z = 5;
    this.renderer = renderer;
    this.maskMesh = null;
  }

  buildMesh(landmarks, triangles) {
    const geometry = new THREE.BufferGeometry();
    const positions = new Float32Array(landmarks.length * 3);
    const uvs = new Float32Array(landmarks.length * 2);

    for (let i = 0; i < landmarks.length; i++) {
      positions[i*3] = landmarks[i].x * 2 - 1;
      positions[i*3+1] = -(landmarks[i].y * 2 - 1);
      positions[i*3+2] = landmarks[i].z;
      uvs[i*2] = landmarks[i].x;
      uvs[i*2+1] = 1 - landmarks[i].y;
    }

    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    geometry.setAttribute('uv', new THREE.BufferAttribute(uvs, 2));
    geometry.setIndex(triangles);
    geometry.computeVertexNormals();

    const material = new THREE.MeshBasicMaterial({
      transparent: true, side: THREE.DoubleSide, depthWrite: false
    });
    this.maskMesh = new THREE.Mesh(geometry, material);
    this.scene.add(this.maskMesh);
  }

  updatePositions(landmarks) {
    if (!this.maskMesh) return;
    const pos = this.maskMesh.geometry.attributes.position.array;
    for (let i = 0; i < landmarks.length; i++) {
      pos[i*3] = landmarks[i].x * 2 - 1;
      pos[i*3+1] = -(landmarks[i].y * 2 - 1);
      pos[i*3+2] = landmarks[i].z;
    }
    this.maskMesh.geometry.attributes.position.needsUpdate = true;
  }

  render() { this.renderer.render(this.scene, this.camera); }
}
```

## 常见误区

### 1. 前置摄像头不需要镜像处理

前置摄像头输出的是镜像画面。直接在上面绘制 AR 内容会导致左右颠倒，需要对视频元素设置 `transform: scaleX(-1)` 或在 Canvas 绘制时做镜像翻转。

### 2. 面部关键点可以直接用于 3D 渲染

MediaPipe 的坐标系（x 向右 0-1，y 向下 0-1）与 Three.js 的 NDC 坐标系不同，需要做坐标转换。

### 3. 忽略帧率对追踪稳定性的影响

面部追踪在 30fps 以下会出现明显抖动。帧率不足时应降低输入分辨率，而不是勉强运行。

## 工程建议

1. **分辨率选择**：面部追踪不需要高分辨率，480p 足够，高分辨率只浪费算力
2. **关键点平滑**：相邻帧的关键点变化很小，用线性插值平滑两帧之间的跳变
3. **性能监控**：实时显示追踪帧率，低于 24fps 时自动降低处理精度
4. **多角度测试**：在侧脸、低头、抬头等极端角度下测试追踪稳定性
5. **肤色适配**：虚拟试妆颜色在不同肤色上效果不同，提供预览和自适应调整

## 小结

MediaPipe Face Mesh 提供了 468 个精确的面部关键点，使虚拟试妆、表情特效等应用成为可能。关键在于理解面部网格结构、正确处理坐标转换、优化渲染性能。

## 参考答案

### 练习一

**思路**：EAR 通过垂直距离与水平距离的比值计算。选取上下眼睑和左右眼角关键点，正常睁眼 EAR 约 0.3，闭眼约 0.05。

**答案**：

```javascript
class BlinkDetector {
  constructor() {
    this.LEFT_TOP = 159; this.LEFT_BOTTOM = 145;
    this.LEFT_LEFT = 33; this.LEFT_RIGHT = 133;
    this.RIGHT_TOP = 386; this.RIGHT_BOTTOM = 374;
    this.RIGHT_LEFT = 362; this.RIGHT_RIGHT = 263;
    this.threshold = 0.18;
    this.isBlinking = false;
    this.blinkCount = 0;
    this.callbacks = [];
  }

  onBlink(callback) { this.callbacks.push(callback); }

  calcEAR(lm, top, bottom, left, right) {
    const vert = Math.sqrt((lm[top].x-lm[bottom].x)**2 + (lm[top].y-lm[bottom].y)**2);
    const horiz = Math.sqrt((lm[left].x-lm[right].x)**2 + (lm[left].y-lm[right].y)**2);
    return vert / horiz;
  }

  process(landmarks) {
    const left = this.calcEAR(landmarks, this.LEFT_TOP, this.LEFT_BOTTOM, this.LEFT_LEFT, this.LEFT_RIGHT);
    const right = this.calcEAR(landmarks, this.RIGHT_TOP, this.RIGHT_BOTTOM, this.RIGHT_LEFT, this.RIGHT_RIGHT);
    const ear = (left + right) / 2;

    if (ear < this.threshold && !this.isBlinking) {
      this.isBlinking = true;
    } else if (ear >= this.threshold && this.isBlinking) {
      this.isBlinking = false;
      this.blinkCount++;
      this.callbacks.forEach(cb => cb(this.blinkCount));
    }
    return { ear, isBlinking: this.isBlinking, count: this.blinkCount };
  }
}
```

**要点**：EAR 是经典指标，不依赖时间序列模型；阈值 0.18 是经验值；状态机确保一次眨眼只触发一次回调。

### 练习二

**思路**：每种特效对应一组关键点索引，根据关键点计算特效的位置、旋转和缩放，使用 Canvas 2D 精灵图渲染。

**答案**：

```javascript
class FaceEffectSystem {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.currentEffect = null;
    this.configs = {
      catEars: { left: 234, right: 454, offsetY: -0.08, scale: 1.8, asset: '/assets/cat-ears.png' },
      sunglasses: { left: 33, right: 263, offsetY: 0.02, scale: 2.2, asset: '/assets/sunglasses.png' },
      mask: { left: 61, right: 291, offsetY: 0.04, scale: 1.6, asset: '/assets/mask.png' }
    };
    this.assets = {};
  }

  async loadAssets() {
    for (const [name, cfg] of Object.entries(this.configs)) {
      const img = new Image();
      img.src = cfg.asset;
      await new Promise(r => img.onload = r);
      this.assets[name] = img;
    }
  }

  setEffect(name) { this.currentEffect = name; }

  render(landmarks) {
    if (!this.currentEffect || !landmarks) return;
    const cfg = this.configs[this.currentEffect];
    const img = this.assets[this.currentEffect];
    if (!cfg || !img) return;

    const left = landmarks[cfg.left];
    const right = landmarks[cfg.right];
    const cx = ((left.x + right.x) / 2) * this.canvas.width;
    const cy = ((left.y + right.y) / 2) * this.canvas.height + cfg.offsetY * this.canvas.height;
    const faceW = Math.sqrt(((right.x-left.x)*this.canvas.width)**2 + ((right.y-left.y)*this.canvas.height)**2);
    const angle = Math.atan2((right.y-left.y)*this.canvas.height, (right.x-left.x)*this.canvas.width);
    const w = faceW * cfg.scale;
    const h = w * (img.height / img.width);

    this.ctx.save();
    this.ctx.translate(cx, cy);
    this.ctx.rotate(angle);
    this.ctx.drawImage(img, -w/2, -h/2, w, h);
    this.ctx.restore();
  }
}
```

**要点**：位置基于关键点几何关系计算；旋转角度跟随头部倾斜；缩放基于面部宽度；`offsetY` 微调每种特效的垂直位置。
