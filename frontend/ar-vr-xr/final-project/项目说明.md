# 毕业项目：空间计算展示平台

## 项目概述

本项目是一个基于 WebXR + Three.js 的空间计算展示平台，综合运用 AR/VR/XR 开发的全部技能，实现一个可在 AR 和 VR 模式下运行的交互式 3D 应用。

## 项目目标

构建一个完整的空间计算应用，具备以下能力：

1. **AR 模式** — 在真实环境中放置 3D 物体，支持平面检测、命中测试、锚点固定
2. **VR 模式** — 进入沉浸式 VR 环境，支持控制器交互、传送、物体抓取
3. **空间音频** — 3D 音频系统，物体发声时有方向感和距离感
4. **多人协作** — 基于 WebSocket 的实时同步，支持多人同时在同一空间交互
5. **AI 集成** — 场景理解与物体识别，根据环境自动放置内容
6. **跨平台** — 支持桌面浏览器、移动浏览器、VR 头显、AR 眼镜

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 3D 渲染 | Three.js r160+ | 场景管理、材质、光照 |
| XR 接口 | WebXR Device API | AR/VR 会话管理 |
| 类型安全 | TypeScript 5.x | 全项目类型化 |
| 构建工具 | Vite | 开发服务器、打包 |
| 网络同步 | WebSocket (ws) | 多人实时同步 |
| 空间音频 | Web Audio API | 3D 音频渲染 |
| 样式 | Tailwind CSS | UI 覆盖层样式 |

## 开发里程碑

### 里程碑 1：基础 XR 体验（对应 Stage 1-2）

- 搭建 Three.js 项目框架
- 实现 WebXR 会话管理（AR + VR）
- 在 AR 中放置基础几何体
- 在 VR 中实现基础控制器交互

### 里程碑 2：AR 功能完善（对应 Stage 3）

- 平面检测与命中测试
- 图像追踪（识别海报增强 3D 内容）
- 锚点系统（物体固定在真实位置）
- LiDAR 环境网格（如设备支持）

### 里程碑 3：VR 功能完善（对应 Stage 4）

- 传送系统
- 物体抓取与操作
- 空间音频
- 世界空间 UI 面板

### 里程碑 4：多人与 AI（对应 Stage 5）

- WebSocket 实时同步
- 虚拟形象系统
- AI 场景理解
- 完整跨平台支持
