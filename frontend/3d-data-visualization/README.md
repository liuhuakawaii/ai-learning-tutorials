# 3D 数据可视化

> 平面图表不够用时——地理数据、网络拓扑、时间序列需要 3D 可视化。

## 适合谁

- 想构建数据大屏、地理可视化、网络拓扑图等 3D 数据展示
- 会用 ECharts/D3 做 2D 图表，但需要 3D 场景
- 想用 Three.js/Deck.gl/Cesium 做大规模数据渲染

## 学完能做什么

- 用 Three.js 构建 3D 柱状图、散点图、力导向图
- 用 Deck.gl 渲染百万级点数据
- 用 Cesium.js 构建 3D 地球可视化
- 实现实时数据流的 3D 可视化
- 构建一个完整的 3D 数据大屏

## 学习路线

### 第一阶段：Three.js 数据可视化基础

1. 3D 柱状图——从数据到几何体的映射
2. 3D 散点图——点云渲染、颜色映射、交互选择
3. 3D 力导向图——网络拓扑的力布局算法
4. 数据映射——颜色/大小/位置的数据编码
5. 阶段实战：构建一个 3D 数据探索器

### 第二阶段：地理可视化

6. 3D 地球——Cesium.js 基础、图层系统
7. 地理数据渲染——GeoJSON、热力图、流线图
8. 飞线动画——城市间连线、弧线动画
9. 地形与建筑——3D 地形、建筑物拉伸、BIM 数据
10. 阶段实战：构建一个 3D 地球数据大屏

### 第三阶段：网络与拓扑

11. 网络拓扑图——节点-边布局、自动布局算法
12. 力导向图进阶——Fruchterman-Reingold、社区检测可视化
13. 树形结构——组织架构图、文件系统树、决策树
14. 知识图谱——实体关系、语义网络、SPARQL 可视化
15. 阶段实战：构建一个网络拓扑可视化工具

### 第四阶段：时间序列与实时数据

16. 3D 时间序列——时间轴、滑动窗口、数据滚动
17. 实时数据流——WebSocket 数据接入、增量更新
18. 数据动画——过渡动画、数据增长、趋势变化
19. 异常检测可视化——离群值高亮、阈值标记
20. 阶段实战：构建一个实时数据监控 3D 大屏

### 第五阶段：大规模数据渲染

21. Deck.gl 基础——大规模点/线/面数据渲染
22. GPU 加速——WebGL/Instanced Rendering、WebGPU Compute
23. 数据聚合——六边形聚合、聚类可视化、LOD
24. 交互与筛选——刷选、过滤、钻取、联动
25. 阶段实战：构建一个百万级数据的 3D 可视化系统
