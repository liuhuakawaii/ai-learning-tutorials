# 毕业项目：3D 数据大屏

## 项目概述

构建一个 3D 数据可视化大屏，支持地理数据、网络拓扑、时序数据的三维展示。目标是在浏览器中实现一个可交互、视觉冲击力强的数据分析看板。

## 技术栈

- **3D 渲染**：Three.js
- **图表**：ECharts（2D 辅助图表）
- **框架**：Vue 3 + TypeScript 或 React + TypeScript
- **构建**：Vite
- **数据**：静态 JSON / WebSocket 实时推送
- **着色器**：GLSL（自定义特效）

## 核心功能

### 1. 3D 地球可视化

- 球体贴图 + 国家边界线
- 数据点映射：将城市/站点数据投射到球面
- 飞线动画：城市间的连线（弧线 + 流光效果）
- 热力层：区域数据热度着色
- 缩放/旋转/点击交互
- 国家/区域信息浮窗

### 2. 3D 网络拓扑图

- 节点 + 边的 3D 布局（力导向布局或手动布局）
- 节点大小映射：度数/流量/权重
- 边粗细映射：带宽/延迟
- 动态数据：节点闪烁、数据流动画
- 聚焦模式：选中节点高亮相邻子图
- 支持至少 200 个节点流畅渲染

### 3. 3D 时序数据

- 3D 柱状图：X 轴时间，Y 轴指标，Z 轴分组
- 曲面图：双变量时序数据的 3D 曲面
- 粒子流：时间轴驱动的粒子运动轨迹
- 时间轴控件：拖拽、播放、倍速

### 4. 数据大屏布局

- 响应式大屏（适配 1920x1080 及以上）
- 面板系统：可拖拽排列的图表面板
- 主题切换：深色科技风 / 浅色商务风
- 自动刷新：WebSocket 推送或定时轮询

### 5. 交互系统

- 射线拾取（Raycasting）：点击 3D 元素查看详情
- 相机动画：平滑过渡到预设视角
- 筛选器：时间范围、区域、指标类型
- 数据钻取：从概览到明细

### 6. 自定义着色器特效

- 扫描线效果（科技感扫描波）
- 脉冲扩散效果（数据点高亮）
- 流光飞线（连线上的光点运动）
- 粒子系统（背景装饰）

## 验收标准

```bash
cd frontend/3d-data-visualization/final-project
node scripts/check.cjs
```

验证项：

- [ ] 3D 地球可旋转、缩放，飞线动画正常
- [ ] 网络拓扑图支持 200+ 节点流畅渲染（>30 FPS）
- [ ] 时序数据有时间轴控件，支持播放/拖拽
- [ ] 大屏布局响应式，深色主题视觉完整
- [ ] 至少 2 个自定义着色器效果正常运行
- [ ] 射线拾取可点击元素并显示详情
- [ ] 数据筛选和钻取功能可用
