# 第一阶段：Three.js 数据可视化基础

从 2D 图表进入 3D 可视化——用 Three.js 实现 3D 柱状图、散点图和力导向图，掌握数据到几何体的映射和交互选择。

## 验收标准

- 能用 Three.js 构建 3D 柱状图，正确映射数据到高度和颜色
- 能实现 3D 散点图，支持颜色映射和鼠标交互选择
- 能实现 3D 力导向布局算法
- 理解数据编码（颜色/大小/位置）的设计原则
- 完成 3D 数据探索器，支持旋转、缩放和数据筛选
