# 第二阶段：地理可视化

用 Cesium.js 构建 3D 地球可视化——渲染 GeoJSON 数据、飞线动画、地形建筑，实现一个数据大屏风格的地球仪表盘。

## 验收标准

- 能用 Cesium.js 加载和渲染 3D 地球
- 能在地球上渲染 GeoJSON 数据、热力图和流线图
- 能实现城市间的飞线弧线动画
- 能渲染 3D 地形和建筑物拉伸效果
- 完成 3D 地球数据大屏，支持多图层叠加和交互
