# 第三阶段：网络与拓扑

构建复杂网络的 3D 可视化——从基本的节点-边图到力导向图进阶、树形结构和知识图谱，实现一个网络拓扑可视化工具。

## 验收标准

- 能实现节点-边布局和自动布局算法
- 能用 Fruchterman-Reingold 算法实现力导向图
- 能渲染树形结构（组织架构、文件系统）
- 能可视化知识图谱的实体关系
- 完成网络拓扑可视化工具，支持布局切换和节点交互
