# 第四阶段：风格化渲染

探索非真实感渲染（NPR）技术，实现卡通渲染、像素艺术、故障艺术和生成艺术风格，构建一个可切换多种风格的渲染引擎。

## 验收标准

- 能实现卡通渲染的描边、色阶和高光效果
- 能用 Shader 实现像素化和抖动效果
- 能实现故障艺术（Glitch）和 CRT 扫描线效果
- 理解参数化设计在生成艺术中的应用
- 完成风格化渲染引擎，支持多种风格切换
