## 验收标准

- 能构建支持实时预览和热重载的 Shader 编辑器
- 能将 Shadertoy 作品移植到 Three.js 或 WebGPU 环境
- 能实现鼠标/触摸/音频等多种输入驱动 Shader 效果
- 能用时间轴和关键帧控制 Shader 动画
- 完成在线 Shader 创作工具，可编辑、预览和分享作品
