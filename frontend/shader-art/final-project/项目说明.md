# 在线 Shader 创作工具 — 课程毕业项目

## 项目目标

构建一个在线 Shader 编辑器，支持实时编写和预览 GLSL 着色器，提供参数调节面板，支持导出为图片或视频。项目覆盖 Shader 艺术课程中的核心知识：GLSL 语法、SDF 建模、噪声函数、光照模型、后处理效果等。

## 技术栈

- **渲染**：WebGL 2.0（通过 raw GL context 或 Three.js）
- **编辑器**：CodeMirror 6 或 Monaco Editor（GLSL 语法高亮）
- **前端框架**：React + TypeScript 或 Vue 3 + TypeScript
- **UI**：Tailwind CSS + 自定义面板
- **构建**：Vite
- **测试**：Vitest

## 核心功能

### 模块一：Shader 编辑器

- 代码编辑器，支持 GLSL 语法高亮和错误提示
- 实时预览：代码修改后立即编译并渲染
- 编译错误定位：点击错误跳转到对应行
- 支持 vertex shader 和 fragment shader 分开编辑
- 内置 uniform 变量：`u_time`、`u_resolution`、`u_mouse`

### 模块二：参数调节面板

- 支持在 Shader 中声明 uniform 参数，自动在面板中生成控件
- 参数类型：float（滑块）、vec2/vec3/vec4（颜色选择器或多滑块）、int（下拉选择）
- 参数可设置范围、步长、默认值
- 参数变化实时更新渲染结果
- 支持参数预设（保存/加载参数组合）

### 模块三：内置 Shader 库

- 至少 8 个预置 Shader 效果：
  - 基础 SDF（圆、矩形、交并差）
  - 分形（Mandelbrot、Julia 集）
  - 噪声纹理（Perlin、Simplex、Voronoi）
  - 光照模型（Phong、Blinn-Phong、PBR 简化版）
  - 后处理效果（模糊、边缘检测、像素化）
- 预置 Shader 可作为模板修改

### 模块四：导出功能

- 导出当前帧为 PNG 图片
- 录制一段动画导出为 WebM/MP4（可设置时长和帧率）
- 导出 Shader 代码为 `.glsl` 文件
- 分享功能：生成包含 Shader 代码的 URL（base64 编码）

### 模块五：交互控制

- 鼠标位置传递给 Shader（`u_mouse`）
- 键盘快捷键：运行/暂停时间、重置、全屏预览
- 支持纹理输入：上传图片作为 `sampler2D` uniform
- 多 Pass 渲染支持（反馈循环）

## 验收标准

- [ ] 编辑器支持 GLSL 语法高亮，修改代码后实时更新渲染
- [ ] 编译错误能在编辑器中标注位置和错误信息
- [ ] 至少支持 float、vec3、int 三种 uniform 参数类型的面板控件
- [ ] 内置至少 8 个不同类型的 Shader 效果
- [ ] 能导出当前帧为 PNG 图片
- [ ] 能录制一段动画并导出为视频
- [ ] 鼠标位置能传递给 Shader 使用
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
