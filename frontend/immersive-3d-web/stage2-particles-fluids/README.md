# 第二阶段：粒子与流体

## 阶段目标

掌握 GPU 粒子系统（Transform Feedback）和 WebGPU 流体模拟，能实现 100 万粒子实时渲染和粒子交互效果。

- 能实现鼠标跟随、力场等粒子交互效果
- 能实现粒子聚合/扩散到模型的过渡动画
