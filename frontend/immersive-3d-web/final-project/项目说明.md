# 沉浸式 3D 品牌官网 — 课程毕业项目

## 项目目标

构建一个沉浸式 3D 品牌官网，通过滚动叙事驱动场景切换，结合粒子效果、后处理管线、音画同步等技术，实现具有视觉冲击力的 Web 体验。项目覆盖沉浸式 3D Web 课程中的核心知识：ScrollTrigger 驱动动画、后处理管线、粒子系统、性能优化、移动端适配等。

## 技术栈

- **3D 引擎**：Three.js（r160+）
- **动画驱动**：GSAP + ScrollTrigger
- **后处理**：@react-three/postprocessing 或 Three.js EffectComposer
- **粒子系统**：@react-three/drei Points 或自定义 BufferGeometry
- **前端框架**：React + TypeScript + Next.js（SSR 首屏）
- **样式**：Tailwind CSS
- **构建**：Vite 或 Next.js

## 核心功能

### 模块一：滚动叙事场景

- 至少 4 个场景章节，由滚动位置驱动切换
- 场景过渡动画：摄像机飞行、物体变形、材质渐变
- 每个场景有独立的 3D 内容和文案
- 滚动进度指示器

### 模块二：粒子效果系统

- 粒子背景：根据场景切换改变形态（散落→聚合→流线→爆炸）
- 粒子与用户交互：鼠标移动产生扰动效果
- 粒子着色器：自定义 vertex/fragment shader 控制颜色和大小
- 性能保障：使用 InstancedMesh 或 BufferGeometry + Points

### 模块三：后处理管线

- Bloom（辉光）效果
- 景深（Depth of Field）
- 色调映射（Tone Mapping）
- 色差（Chromatic Aberration）
- 根据滚动位置动态调整后处理参数

### 模块四：音画同步（可选）

- 背景音乐播放
- 音频可视化：根据音频频谱驱动粒子或几何体变形
- 音量与场景关联

### 模块五：性能与适加

- 加载进度条与骨架屏
- 模型懒加载：按场景分块加载
- 移动端适配：降低粒子数量、简化后处理
- 帧率监控与动态降级
- SSR 首屏：HTML 内容先于 3D 加载完成

## 验收标准

- [ ] 页面滚动时至少有 4 个不同场景依次展示
- [ ] 场景过渡有平滑的摄像机或物体动画
- [ ] 粒子效果在不同场景间有形态变化
- [ ] 后处理效果（Bloom、景深等）正常工作
- [ ] 加载时有进度提示，不会白屏
- [ ] 移动端（宽度 < 768px）能正常展示（可降低效果）
- [ ] 首屏加载时间 < 5 秒（3G 网络模拟）
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
