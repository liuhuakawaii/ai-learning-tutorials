# 第一阶段：滚动驱动的 3D 叙事

## 阶段目标

掌握 GSAP ScrollTrigger 与 Three.js 联动的滚动驱动 3D 叙事技术，能构建 Apple 风格的产品滚动展示页。

## 课时列表

1. [Scroll-Driven Animation——GSAP ScrollTrigger + Three.js 联动原理](01-scroll-trigger-basics.md)
2. [相机动画——沿路径飞行、焦点切换、平滑过渡](02-camera-animation.md)
3. [模型变形——Morph Targets、顶点动画、过渡效果](03-morph-targets.md)
4. [光影变化——随滚动改变光照、环境、色调](04-lighting-changes.md)
5. [阶段实战：构建 Apple 风格产品滚动展示页](05-apple-style-product-page.md)

## 验收标准

- 能用 GSAP ScrollTrigger 驱动 Three.js 场景的滚动动画
- 能实现相机沿路径飞行并平滑切换焦点
- 能用 Morph Targets 实现模型的变形和过渡效果
- 能随滚动进度动态改变光照、环境和色调
