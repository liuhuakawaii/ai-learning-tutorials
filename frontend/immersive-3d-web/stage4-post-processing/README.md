# 第四阶段：后处理与视觉特效

## 阶段目标

掌握后处理链设计（Bloom/Glitch/景深/运动模糊）和风格化渲染技术，能将 3D 场景与 HTML/CSS 混合排版。

## 验收标准

- 能搭建包含 Bloom/Glitch/Chromatic Aberration 的后处理链
- 能实现景深和运动模糊的电影镜头效果
- 能实现卡通渲染、像素化或故障艺术等风格化渲染
- 能将 3D 场景与 HTML/CSS 混合排版构建完整页面
