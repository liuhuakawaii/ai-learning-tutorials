# 第三阶段：光线与材质

## 阶段目标

掌握实时光线追踪、PBR 物理材质、程序化纹理和环境光照技术，能构建实时产品配置器。

## 课时列表

1. [实时光线追踪——WebGPU Ray Tracing、降噪、混合渲染](11-ray-tracing.md)
2. [物理材质——PBR 深度、各向异性、次表面散射](12-physical-materials.md)
3. [程序化纹理——噪声/分形生成材质（大理石/木纹/地形）](13-procedural-textures.md)
4. [环境光——IBL、反射探针、动态天空](14-environment-lighting.md)
5. [阶段实战：构建实时产品配置器](15-product-configurator.md)

## 验收标准

- 能用 WebGPU Ray Tracing 实现实时光线追踪并理解降噪和混合渲染
- 能设计 PBR 材质（各向异性、次表面散射等高级属性）
- 能用噪声/分形算法生成程序化纹理（大理石、木纹、地形）
- 能用 IBL 和反射探针实现真实的环境光照效果
