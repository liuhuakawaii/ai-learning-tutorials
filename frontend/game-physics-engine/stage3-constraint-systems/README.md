# 第三阶段：约束系统

实现物体间的约束关系——距离约束、弹簧系统、铰链约束和约束求解器，让物理引擎能模拟绳索、链条和关节。

## 验收标准

- 能实现距离约束并用迭代法求解
- 能用胡克定律和阻尼实现弹簧系统
- 能实现铰链约束和角度限制
- 理解 Sequential Impulse 约束求解方法
- 完成绳索和链条模拟，约束稳定不抖动
