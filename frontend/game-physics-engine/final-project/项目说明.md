# 毕业项目：2D 物理引擎

## 项目概述

从零构建一个完整的 2D 物理引擎，支持刚体动力学、碰撞检测与响应、约束系统，并提供可视化调试界面。最终通过一个物理演示场景展示引擎能力。

## 技术栈

- **语言**：TypeScript
- **渲染**：Canvas 2D（调试可视化）
- **构建**：Vite
- **测试**：Vitest（物理计算的单元测试）
- **数学库**：自实现向量/矩阵运算（不使用第三方物理库）

## 核心功能

### 1. 向量数学库

- Vec2：加、减、标量乘、点积、叉积、归一化、长度
- Mat2x2：旋转矩阵、转置
- 浮点数容差比较（epsilon）

### 2. 刚体系统

- 质量、速度、加速度、力累加器
- 积分器：半隐式欧拉（Symplectic Euler）
- 线性阻尼
- 角速度、扭矩、角度积分
- 力的施加方式：持续力、脉冲（Impulse）

### 3. 碰撞检测

- 形状支持：圆形、AABB、凸多边形
- 分离轴定理（SAT）用于凸多边形
- 圆形 vs 圆形：距离检测
- 圆形 vs 多边形：最近点投影
- 碰撞信息：法线、穿透深度、接触点

### 4. 碰撞响应

- 基于冲量的响应（Impulse-based）
- 恢复系数（弹性碰撞）
- 库仑摩擦模型（静态摩擦 + 动态摩擦）
- 位置修正：Baumgarte 稳定化或位置投影

### 5. 约束系统

- 距离约束（Distance Constraint）：两点保持固定距离
- 弹簧约束（Spring）：弹性连接
- 铰链约束（Revolute Joint）：共享旋转点
- 约束求解：Sequential Impulse 迭代

### 6. 宽阶段（Broad Phase）

- 空间哈希（Spatial Hash）或均匀网格
- AABB 预筛选
- 碰撞对去重

### 7. 世界管理

- 物理世界：管理所有刚体和约束
- 时间步：固定时间步 + 累积器模式
- 休眠系统：静止物体进入休眠以节省计算

### 8. 可视化调试

- 形状轮廓渲染（区分静态/动态）
- 速度向量可视化
- 碰撞法线和接触点绘制
- AABB 包围盒显示
- 帧率和物理步数显示
- 暂停/单步/慢动作控制

### 9. 演示场景

- 堆叠场景：多个物体堆叠测试稳定性
- 链条/绳摆：约束系统展示
- 弹射场景：碰撞 + 摩擦展示
- 多米诺骨牌：连锁碰撞
- 用户可拖拽物体并抛掷

## 验收标准

```bash
cd frontend/game-physics-engine/final-project
node scripts/check.cjs
```

验证项：

- [ ] 向量数学库功能完整，通过单元测试
- [ ] 刚体动力学模拟稳定（堆叠不穿透）
- [ ] 圆形和凸多边形碰撞检测正确
- [ ] 碰撞响应有弹性 + 摩擦效果
- [ ] 约束系统（距离/弹簧/铰链）至少实现 2 种
- [ ] 宽阶段优化有效（>100 物体不卡顿）
- [ ] 可视化调试面板功能完整
- [ ] 至少 3 个演示场景可运行
