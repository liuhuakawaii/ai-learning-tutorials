# 第一阶段：碰撞检测

从最基础的碰撞检测开始——AABB、圆形碰撞、SAT 和 GJK 算法，理解不同形状间的碰撞判定原理，用弹球模拟验证所学。

## 验收标准

- 能实现 AABB 和圆形碰撞检测，理解包围盒的作用
- 能用 SAT 算法检测凸多边形间的碰撞
- 能用 GJK 算法检测任意凸形状的碰撞并用 EPA 求穿透深度
- 能实现基本的碰撞响应（反弹、分离）
- 完成弹球模拟，多个物体间碰撞检测正确且实时运行
