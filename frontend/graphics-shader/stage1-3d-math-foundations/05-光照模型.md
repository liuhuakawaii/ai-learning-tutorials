# 第五课：光照模型

## 场景引入

想象你在暗室中打开一盏台灯。桌面被照亮的部分清晰可见，灯光直射的区域特别明亮，桌面的光滑部分甚至反射出灯泡的轮廓。这种日常现象背后隐藏着三个核心光学机制：环境光让整个房间不完全黑暗，漫反射让桌面呈现出材质颜色，镜面反射则产生了高光。理解这三个机制，是让 3D 场景看起来"真实"的第一步。

## 学习目标

1. 理解环境光、漫反射、镜面反射三种光照成分的物理含义
2. 掌握 Lambert 漫反射模型的推导与计算公式
3. 掌握 Phong 和 Blinn-Phong 镜面反射模型的区别与适用场景
4. 能够用 GLSL 实现完整的 Blinn-Phong 光照 shader
5. 理解法向量、光照方向、观察方向在光照计算中的几何关系

## 一、光照的基本组成

在实时渲染中，一个表面最终的颜色通常由三种光照成分叠加而成：

```
最终颜色 = 环境光(Ambient) + 漫反射(Diffuse) + 镜面反射(Specular)
```

- **环境光**：模拟间接光照，即使没有光源直射，物体也不会完全黑暗
- **漫反射**：光线照射到粗糙表面后向各个方向均匀散射，是物体呈现颜色的主要原因
- **镜面反射**：光线照射到光滑表面后沿特定方向反射，产生高光

这三者并非严格的物理模拟，而是对真实光照的简化近似。在后续的 PBR（基于物理的渲染）课程中，我们会用更精确的模型替代它们，但 Blinn-Phong 至今仍是理解光照的良好起点。

## 二、法向量与光照方向

在讨论光照公式之前，我们需要明确几个关键向量的含义：

```
                  N (法向量，垂直于表面指向外侧)
                  ^
                  |
                  |
       L          |          V
    (光源方向)      |       (观察方向)
         \        |        /
          \       |       /
           \      |      /
            \     |     /
             \    |    /
              \   |   /
               \  |  /
                \ | /
                 \|/
                  *  --------> H (半程向量 = normalize(L + V))
               (表面上的点)
```

- **N** (Normal)：表面法向量，垂直于表面指向外侧
- **L** (Light)：从表面点指向光源的方向向量
- **V** (View)：从表面点指向摄像机的方向向量
- **H** (Half)：L 和 V 的半程向量，`H = normalize(L + V)`

这些向量都应该是**单位向量**（长度为 1），这样点积运算才能直接得到余弦值。

## 三、环境光 (Ambient)

环境光是最简单的光照成分，它模拟来自四面八方的间接光照：

```
I_ambient = k_a * I_light
```

其中 `k_a` 是材质的环境光反射系数（通常是一个 RGB 颜色），`I_light` 是环境光强度。

在 GLSL 中通常用一个简单的乘法表示：

```glsl
// 环境光：材质颜色乘以一个较小的环境光系数
vec3 ambient = 0.15 * u_materialColor;
```

环境光没有方向性，不依赖法向量，计算开销极低。但它也有明显的缺点——物体之间的遮挡关系完全被忽略，导致画面缺乏深度感。这就是为什么我们还需要漫反射和镜面反射。

## 四、漫反射 (Lambert)

漫反射遵循 Lambert 余弦定律：表面接收到的光强与光线入射角的余弦值成正比。

### 公式

```
I_diffuse = k_d * I_light * max(0, N · L)
```

### 物理直觉

- 当光线垂直照射表面时（N · L = 1），表面接收的光最多
- 当光线平行于表面时（N · L = 0），表面接收不到光
- 当光线从背面照射时（N · L < 0），用 `max(0, ...)` 截断到 0

### GLSL 实现

```glsl
// Lambert 漫反射
float NdotL = max(dot(normal, lightDir), 0.0);
vec3 diffuse = u_materialColor * u_lightColor * u_lightIntensity * NdotL;
```

漫反射只依赖法向量和光源方向，与观察者位置无关。这意味着无论你从哪个角度看一个漫反射表面，它的亮度都是一样的——这与我们在日常生活中看到的哑光材质（如木头、纸张）的行为一致。

## 五、镜面反射 (Phong)

Phong 镜面反射模型假设光滑表面会将光线沿反射方向集中反射：

### 公式

```
R = reflect(-L, N)  // 反射向量
I_specular = k_s * I_light * max(0, R · V)^shininess
```

`shininess`（光泽度）控制高光的大小和锐利程度：

- 光泽度越高（如 128），高光越小越锐利——如抛光金属
- 光泽度越低（如 8），高光越大越柔和——如塑料

### GLSL 实现

```glsl
// Phong 镜面反射
vec3 reflectDir = reflect(-lightDir, normal);
float RdotV = max(dot(reflectDir, viewDir), 0.0);
vec3 specular = u_lightColor * u_lightIntensity * pow(RdotV, u_shininess);
```

## 六、Blinn-Phong 模型

Blinn-Phong 是 Phong 模型的改进版本，用半程向量 H 替代了反射向量 R：

### 公式

```
H = normalize(L + V)
I_specular = k_s * I_light * max(0, N · H)^shininess
```

### 为什么 Blinn-Phong 更好？

1. **计算更高效**：当光源和摄像机都在无穷远时，H 是常量，不需要每帧重新计算
2. **边缘更自然**：Phong 模型在掠射角度时高光可能突然截断，Blinn-Phong 则平滑过渡
3. **与硬件更契合**：OpenGL 固定管线曾默认使用 Blinn-Phong

### 完整的 Blinn-Phong 光照公式

```
I = k_a * I_ambient
  + k_d * I_light * max(0, N·L)
  + k_s * I_light * max(0, N·H)^shininess
```

## 七、GLSL 完整实现

下面是一个完整的 Blinn-Phong 光照 shader，支持点光源和材质属性。

### 顶点着色器

```glsl
#version 300 es
precision highp float;

// 顶点属性
in vec3 a_position;
in vec3 a_normal;

// 变换矩阵
uniform mat4 u_modelMatrix;
uniform mat4 u_viewMatrix;
uniform mat4 u_projectionMatrix;
uniform mat3 u_normalMatrix;

// 传递给片元着色器
out vec3 v_worldPos;
out vec3 v_normal;

void main() {
    // 将顶点位置变换到世界空间
    vec4 worldPos = u_modelMatrix * vec4(a_position, 1.0);
    v_worldPos = worldPos.xyz;

    // 法向量变换到世界空间并归一化
    // 注意：必须使用 normalMatrix 而非 modelMatrix
    v_normal = normalize(u_normalMatrix * a_normal);

    // 最终裁剪空间位置
    gl_Position = u_projectionMatrix * u_viewMatrix * worldPos;
}
```

### 片元着色器

```glsl
#version 300 es
precision highp float;

// 从顶点着色器接收（经过插值）
in vec3 v_worldPos;
in vec3 v_normal;

// 光源参数
uniform vec3 u_lightPos;
uniform vec3 u_lightColor;
uniform float u_lightIntensity;

// 材质参数
uniform vec3 u_materialColor;
uniform float u_shininess;

// 相机位置
uniform vec3 u_cameraPos;

// 输出颜色
out vec4 fragColor;

void main() {
    // 重新归一化插值后的法向量（重要！）
    vec3 N = normalize(v_normal);
    vec3 L = normalize(u_lightPos - v_worldPos);
    vec3 V = normalize(u_cameraPos - v_worldPos);
    vec3 H = normalize(L + V);

    // 环境光
    vec3 ambient = 0.15 * u_materialColor;

    // 漫反射 (Lambert)
    float NdotL = max(dot(N, L), 0.0);
    vec3 diffuse = u_materialColor * u_lightColor * u_lightIntensity * NdotL;

    // 镜面反射 (Blinn-Phong)
    float NdotH = max(dot(N, H), 0.0);
    vec3 specular = u_lightColor * u_lightIntensity * pow(NdotH, u_shininess);

    // 叠加三种光照成分
    vec3 finalColor = ambient + diffuse + specular;
    fragColor = vec4(finalColor, 1.0);
}
```

## 八、TypeScript 光源与材质类

在应用层，我们需要管理光源和材质的参数，并将它们传递给 shader：

```typescript
/** 点光源 */
class PointLight {
    position: Float32Array;
    color: Float32Array;
    intensity: number;

    constructor(
        position: [number, number, number],
        color: [number, number, number] = [1, 1, 1],
        intensity: number = 1.0
    ) {
        this.position = new Float32Array(position);
        this.color = new Float32Array(color);
        this.intensity = intensity;
    }

    /** 设置 shader 中的光源 uniform */
    setUniforms(gl: WebGL2RenderingContext, program: WebGLProgram): void {
        gl.useProgram(program);
        gl.uniform3fv(gl.getUniformLocation(program, 'u_lightPos'), this.position);
        gl.uniform3fv(gl.getUniformLocation(program, 'u_lightColor'), this.color);
        gl.uniform1f(gl.getUniformLocation(program, 'u_lightIntensity'), this.intensity);
    }
}

/** 材质 */
class Material {
    color: Float32Array;
    shininess: number;

    constructor(
        color: [number, number, number],
        shininess: number = 32.0
    ) {
        this.color = new Float32Array(color);
        this.shininess = shininess;
    }

    /** 设置 shader 中的材质 uniform */
    setUniforms(gl: WebGL2RenderingContext, program: WebGLProgram): void {
        gl.useProgram(program);
        gl.uniform3fv(gl.getUniformLocation(program, 'u_materialColor'), this.color);
        gl.uniform1f(gl.getUniformLocation(program, 'u_shininess'), this.shininess);
    }
}
```

## 常见误区

**1. 忘记归一化法向量**

经过矩阵变换后的法向量可能不再是单位向量。如果法向量长度不为 1，点积运算的结果就不是真正的余弦值，会导致光照计算错误。在顶点着色器中，变换后务必调用 `normalize()`。

**2. 混淆光源方向和光线入射方向**

`lightDir = lightPos - fragPos` 得到的是从表面指向光源的方向，这是正确的 L 向量。但有些资料使用从光源指向表面的方向（入射方向），此时需要取反。在使用 `reflect()` 函数时尤其要注意：GLSL 的 `reflect` 期望入射方向。

**3. 在片元着色器中不重新归一化法向量**

从顶点着色器传递到片元着色器的法向量经过光栅化插值后长度会改变。如果不重新归一化，光照会出现明暗不均的伪影。

**4. 法向量矩阵使用 modelMatrix 而非 normalMatrix**

法向量的变换矩阵应该是 `transpose(inverse(modelMatrix))`，而不是 modelMatrix 本身。当模型存在非均匀缩放时，直接用 modelMatrix 变换法向量会导致方向错误。

## 工程建议

**1. 使用 Uniform Buffer Object 管理多个光源**

当场景中有多个光源时，将光源参数放入 UBO 可以减少 uniform 设置的调用次数，提升渲染性能。

**2. 光照计算的位置选择**

在顶点着色器中计算光照（Gouraud 着色）性能更好但精度低；在片元着色器中计算（Phong 着色）质量更高。移动端低端设备可以考虑 Gouraud，桌面端优先使用片元着色器。

**3. 注意光源衰减**

真实世界中光强随距离衰减。常用公式：`attenuation = 1.0 / (1.0 + k_linear * d + k_quadratic * d²)`。不加衰减的点光源会导致无论多远亮度都一样，不符合物理直觉。

**4. 为后续 PBR 留下扩展空间**

Blinn-Phong 虽然经典，但现代引擎普遍使用 PBR。在设计材质系统时，建议预留金属度（metallic）、粗糙度（roughness）等参数接口，便于后续升级。

## 小结

本课从物理直觉出发，讲解了光照模型的三个核心成分：环境光、漫反射和镜面反射。我们推导了 Lambert 漫反射公式和 Blinn-Phong 镜面反射公式，并用 GLSL 实现了完整的光照 shader。理解这些基础概念后，你就能让 3D 物体呈现出真实的明暗变化，而不是扁平的纯色。

## 参考答案

### 练习一

**思路**：用 uniform 数组存储 4 个光源的位置、颜色、强度，在片元着色器中循环累加每个光源的贡献。

**答案**：

```glsl
// 片元着色器中定义光源数量
#define MAX_LIGHTS 4

uniform vec3 u_lightPos[MAX_LIGHTS];
uniform vec3 u_lightColor[MAX_LIGHTS];
uniform float u_lightIntensity[MAX_LIGHTS];
uniform int u_lightCount;

void main() {
    vec3 N = normalize(v_normal);
    vec3 V = normalize(u_cameraPos - v_worldPos);
    vec3 result = 0.15 * u_materialColor; // 环境光只计算一次

    for (int i = 0; i < MAX_LIGHTS; i++) {
        if (i >= u_lightCount) break;
        vec3 L = normalize(u_lightPos[i] - v_worldPos);
        vec3 H = normalize(L + V);
        float NdotL = max(dot(N, L), 0.0);
        float NdotH = max(dot(N, H), 0.0);
        result += u_materialColor * u_lightColor[i] * u_lightIntensity[i] * NdotL;
        result += u_lightColor[i] * u_lightIntensity[i] * pow(NdotH, u_shininess);
    }
    fragColor = vec4(result, 1.0);
}
```

**要点**：
- 环境光只累加一次，不是每个光源都加
- 循环中用 `u_lightCount` 控制实际生效的光源数

### 练习二

**思路**：将 `NdotL` 和 `NdotH` 的计算移到顶点着色器，将结果作为 varying 传给片元着色器。

**答案**：

```glsl
// 顶点着色器
out vec3 v_lightColor;

void main() {
    vec3 worldPos = (u_modelMatrix * vec4(a_position, 1.0)).xyz;
    vec3 N = normalize(u_normalMatrix * a_normal);
    vec3 L = normalize(u_lightPos - worldPos);
    vec3 V = normalize(u_cameraPos - worldPos);
    vec3 H = normalize(L + V);

    vec3 ambient = 0.15 * u_materialColor;
    vec3 diffuse = u_materialColor * u_lightColor * max(dot(N, L), 0.0);
    vec3 specular = u_lightColor * pow(max(dot(N, H), 0.0), u_shininess);

    v_lightColor = ambient + diffuse + specular;
    gl_Position = u_projectionMatrix * u_viewMatrix * vec4(worldPos, 1.0);
}

// 片元着色器
in vec3 v_lightColor;
out vec4 fragColor;
void main() {
    fragColor = vec4(v_lightColor, 1.0);
}
```

**要点**：
- 低多边形上 Gouraud 着色会出现明显的亮度跳变
- 高多边形模型上两者差异不大

### 练习三

**思路**：在片元着色器中计算光源到表面点的距离，用衰减公式除以光强。

**答案**：

```glsl
void main() {
    vec3 N = normalize(v_normal);
    vec3 L = u_lightPos - v_worldPos;
    float distance = length(L);
    L = normalize(L);

    // 衰减公式
    float attenuation = 1.0 / (1.0 + 0.09 * distance + 0.032 * distance * distance);

    vec3 V = normalize(u_cameraPos - v_worldPos);
    vec3 H = normalize(L + V);

    vec3 ambient = 0.15 * u_materialColor;
    vec3 diffuse = u_materialColor * u_lightColor * u_lightIntensity * max(dot(N, L), 0.0) * attenuation;
    vec3 specular = u_lightColor * u_lightIntensity * pow(max(dot(N, H), 0.0), u_shininess) * attenuation;

    fragColor = vec4(ambient + diffuse + specular, 1.0);
}
```

**要点**：
- `linear` 系数控制中距离衰减速度，`quadratic` 控制远距离衰减速度
- 环境光通常不参与衰减，否则远处物体可能全黑
