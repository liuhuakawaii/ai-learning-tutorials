# 第4课：四元数与插值

## 场景引入

你在做一个 3D 相机动画：相机从位置 A 平滑旋转到位置 B。用欧拉角插值？当旋转经过某些角度时，相机会突然剧烈抖动甚至翻转——这就是**万向节锁（Gimbal Lock）**。用旋转矩阵插值？两个矩阵之间的线性插值会破坏正交性，导致物体扭曲变形。四元数（Quaternion）是解决这两个问题的数学工具，它是 3D 引擎中旋转表示的事实标准。

## 学习目标

1. 理解欧拉角的万向节锁问题及其成因
2. 掌握四元数的数学定义和几何含义
3. 掌握四元数的基本运算（乘法、共轭、归一化）
4. 实现 SLERP 插值并理解其优势
5. 能在实际项目中正确选择旋转表示方法

## 一、欧拉角与万向节锁

### 欧拉角

欧拉角用三个角度描述旋转：Pitch（俯仰）、Yaw（偏航）、Roll（翻滚）。

```
         Pitch (绕 X 轴)
            ↗
           /
  Yaw ← ──●── → Roll
  (绕 Y)  |   (绕 Z)
           ↓
```

### 万向节锁问题

当 Pitch 接近 ±90° 时，Yaw 和 Roll 的旋转轴重合，失去一个自由度：

```
  正常情况（3个自由度）：
  X 轴: ────→
  Y 轴: ────→  三个轴互相独立
  Z 轴: ────→

  万向节锁（Pitch = 90°）：
  X 轴: ────→
  Y 轴: ↘     Y 和 Z 轴重合！
  Z 轴: ↗     只剩 2 个自由度
```

```typescript
// 万向节锁演示
// 绕 X 轴旋转 90° 后，绕 Y 轴旋转和绕 Z 轴旋转效果相同
const euler1 = { x: 90, y: 45, z: 0 };   // Pitch=90, Yaw=45
const euler2 = { x: 90, y: 0, z: 45 };   // Pitch=90, Roll=45
// 这两个旋转的结果完全相同！丢失了一个自由度
```

万向节锁导致的问题：插值动画在经过 ±90° 时会出现不自然的运动。

## 二、四元数的数学定义

四元数是复数的扩展，由一个实部和三个虚部组成：

```
  q = w + xi + yj + zk

  其中 i² = j² = k² = ijk = -1
```

用向量形式表示：

```
  q = (w, x, y, z) = (w, v)

  w 是标量部分（scalar）
  v = (x, y, z) 是向量部分（vector）
```

### 单位四元数与旋转

**单位四元数**（模为 1 的四元数）可以表示旋转：

```
  |q| = √(w² + x² + y² + z²) = 1
```

用轴-角（axis-angle）表示构造四元数：

```
  绕单位轴 n 旋转角度 θ：

  q = (cos(θ/2), sin(θ/2) × nx, sin(θ/2) × ny, sin(θ/2) × nz)
```

注意：角度是**一半**，这是四元数的几何特性——四元数空间中的 360° 对应实际空间的 720°。

### 几何直觉

```
  四元数可以看作 4D 超球面上的点：

  w² + x² + y² + z² = 1

  对于 3D 空间中的每一个旋转，四元数空间中有两个点对应
  （q 和 -q 表示同一个旋转）
```

## 三、四元数基本运算

### 四元数乘法

两个四元数相乘表示旋转的组合（先 q1 旋转，再 q2 旋转）：

```
  q2 × q1 = (
    w2*w1 - x2*x1 - y2*y1 - z2*z1,
    w2*x1 + x2*w1 + y2*z1 - z2*y1,
    w2*y1 - x2*z1 + y2*w1 + z2*x1,
    w2*z1 + x2*y1 - y2*x1 + z2*w1
  )
```

注意：四元数乘法**不满足交换律**。

### 共轭

四元数的共轭将向量部分取反：

```
  q* = (w, -x, -y, -z)
```

### 逆

对于单位四元数，逆等于共轭：

```
  q⁻¹ = q* / |q|²

  当 |q| = 1 时：q⁻¹ = q*
```

### 用四元数旋转向量

```
  v' = q × (0, vx, vy, vz) × q⁻¹

  实际计算中用优化公式（避免完整的四元数乘法）。
```

## 四、SLERP 插值

### 为什么线性插值不行

旋转矩阵的线性插值会破坏正交性：

```
  线性插值：M(t) = (1-t) × M1 + t × M2

  问题：结果矩阵不再是正交矩阵 → 物体会扭曲变形
```

四元数的线性插值（LERP）也有问题：插值路径不是最短弧，速度不均匀。

### SLERP 公式

球面线性插值（Spherical Linear Interpolation）在四元数球面上沿大圆弧插值：

```
  SLERP(q1, q2, t) = q1 × sin((1-t)θ) / sin(θ) + q2 × sin(tθ) / sin(θ)

  其中 θ = arccos(q1 · q2)，t ∈ [0, 1]
```

```
  SLERP 的几何意义：

  4D 超球面上，从 q1 到 q2 沿大圆弧匀速运动。

        q2
       /
      / ← 匀速弧线
     /
    q1

  对比 LERP（直线）：
    q2
   /
  q1 ← 穿过球内部，速度不均匀
```

### 两个四元数的点积

```
  q1 · q2 = w1*w2 + x1*x2 + y1*y2 + z1*z2
```

当点积为负数时，取 q2 的相反四元数（-q2），确保走最短弧。

## 五、欧拉角 vs 四元数 vs 旋转矩阵

```
  ┌─────────────┬────────────┬──────────┬───────────┬────────────┐
  │    特性      │   欧拉角    │  四元数   │  旋转矩阵  │  轴-角     │
  ├─────────────┼────────────┼──────────┼───────────┼────────────┤
  │  存储空间    │  3 个数    │  4 个数   │  9 个数   │  4 个数    │
  │  万向节锁    │  有        │  无      │  无       │  无        │
  │  插值        │  不自然    │  优秀    │  差       │  困难      │
  │  组合旋转    │  困难      │  简单乘法 │  简单乘法  │  困难      │
  │  直观性      │  高        │  低      │  低       │  中        │
  │  变换向量    │  需转矩阵  │  直接用   │  直接用   │  需转矩阵  │
  └─────────────┴────────────┴──────────┴───────────┴────────────┘
```

**实际使用建议：**

- 用户输入（UI 编辑器）→ 欧拉角（直观）
- 运行时存储和插值 → 四元数（无万向节锁，SLERP 自然）
- GPU 变换 → 旋转矩阵（GPU 不支持四元数，需要在 shader 中转为矩阵）

## 六、TypeScript Quaternion 实现

```typescript
class Quaternion {
  constructor(
    public x: number = 0,
    public y: number = 0,
    public z: number = 0,
    public w: number = 1  // 默认为单位四元数（无旋转）
  ) {}

  // 从轴-角构造（轴必须是单位向量，角度为弧度）
  static fromAxisAngle(
    ax: number, ay: number, az: number,
    rad: number
  ): Quaternion {
    const half = rad / 2;
    const s = Math.sin(half);
    return new Quaternion(ax * s, ay * s, az * s, Math.cos(half));
  }

  // 从欧拉角构造（弧度，顺序：XYZ）
  static fromEuler(
    xRad: number, yRad: number, zRad: number
  ): Quaternion {
    const cx = Math.cos(xRad / 2), sx = Math.sin(xRad / 2);
    const cy = Math.cos(yRad / 2), sy = Math.sin(yRad / 2);
    const cz = Math.cos(zRad / 2), sz = Math.sin(zRad / 2);

    return new Quaternion(
      sx * cy * cz - cx * sy * sz,
      cx * sy * cz + sx * cy * sz,
      cx * cy * sz - sx * sy * cz,
      cx * cy * cz + sx * sy * sz
    );
  }

  // 模的平方
  lengthSq(): number {
    return this.x*this.x + this.y*this.y + this.z*this.z + this.w*this.w;
  }

  // 模
  length(): number {
    return Math.sqrt(this.lengthSq());
  }

  // 归一化
  normalize(): Quaternion {
    const len = this.length();
    if (len < 1e-10) return new Quaternion();
    const inv = 1 / len;
    return new Quaternion(
      this.x * inv, this.y * inv,
      this.z * inv, this.w * inv
    );
  }

  // 共轭
  conjugate(): Quaternion {
    return new Quaternion(-this.x, -this.y, -this.z, this.w);
  }

  // 逆（单位四元数的逆 = 共轭）
  inverse(): Quaternion {
    const lenSq = this.lengthSq();
    if (lenSq < 1e-10) return new Quaternion();
    const inv = 1 / lenSq;
    return new Quaternion(
      -this.x * inv, -this.y * inv,
      -this.z * inv, this.w * inv
    );
  }

  // 四元数乘法 this = this × q
  multiply(q: Quaternion): Quaternion {
    const ax = this.x, ay = this.y, az = this.z, aw = this.w;
    const bx = q.x, by = q.y, bz = q.z, bw = q.w;
    return new Quaternion(
      aw * bx + ax * bw + ay * bz - az * by,
      aw * by - ax * bz + ay * bw + az * bx,
      aw * bz + ax * by - ay * bx + az * bw,
      aw * bw - ax * bx - ay * by - az * bz
    );
  }

  // 点积
  dot(q: Quaternion): number {
    return this.x*q.x + this.y*q.y + this.z*q.z + this.w*q.w;
  }

  // 旋转向量
  rotateVector(vx: number, vy: number, vz: number): [number, number, number] {
    // v' = q × (0,v) × q*
    const qx = this.x, qy = this.y, qz = this.z, qw = this.w;
    // 优化公式（展开完整四元数乘法）
    const tx = 2 * (qy * vz - qz * vy);
    const ty = 2 * (qz * vx - qx * vz);
    const tz = 2 * (qx * vy - qy * vx);
    return [
      vx + qw * tx + (qy * tz - qz * ty),
      vy + qw * ty + (qz * tx - qx * tz),
      vz + qw * tz + (qx * ty - qy * tx),
    ];
  }

  // 转换为 4×4 旋转矩阵（列主序）
  toMat4(): Float32Array {
    const x = this.x, y = this.y, z = this.z, w = this.w;
    const x2 = x + x, y2 = y + y, z2 = z + z;
    const xx = x * x2, xy = x * y2, xz = x * z2;
    const yy = y * y2, yz = y * z2, zz = z * z2;
    const wx = w * x2, wy = w * y2, wz = w * z2;

    const out = new Float32Array(16);
    out[0]  = 1 - (yy + zz); out[1]  = xy + wz;       out[2]  = xz - wy;       out[3]  = 0;
    out[4]  = xy - wz;       out[5]  = 1 - (xx + zz); out[6]  = yz + wx;       out[7]  = 0;
    out[8]  = xz + wy;       out[9]  = yz - wx;       out[10] = 1 - (xx + yy); out[11] = 0;
    out[12] = 0;             out[13] = 0;             out[14] = 0;             out[15] = 1;
    return out;
  }

  toString(): string {
    return `Quat(${this.x.toFixed(4)}, ${this.y.toFixed(4)}, ${this.z.toFixed(4)}, ${this.w.toFixed(4)})`;
  }
}
```

## 七、SLERP 实现

```typescript
function slerp(
  q1: Quaternion, q2: Quaternion, t: number
): Quaternion {
  let dot = q1.dot(q2);

  // 如果点积为负，取反 q2，确保走最短弧
  let x2 = q2.x, y2 = q2.y, z2 = q2.z, w2 = q2.w;
  if (dot < 0) {
    x2 = -x2; y2 = -y2; z2 = -z2; w2 = -w2;
    dot = -dot;
  }

  // 如果四元数非常接近，用线性插值避免除以零
  if (dot > 0.9995) {
    const result = new Quaternion(
      q1.x + t * (x2 - q1.x),
      q1.y + t * (y2 - q1.y),
      q1.z + t * (z2 - q1.z),
      q1.w + t * (w2 - q1.w)
    );
    return result.normalize();
  }

  // SLERP 公式
  const theta = Math.acos(dot);
  const sinTheta = Math.sin(theta);
  const a = Math.sin((1 - t) * theta) / sinTheta;
  const b = Math.sin(t * theta) / sinTheta;

  return new Quaternion(
    a * q1.x + b * x2,
    a * q1.y + b * y2,
    a * q1.z + b * z2,
    a * q1.w + b * w2
  );
}
```

### 使用示例

```typescript
// 场景：相机从一个朝向平滑旋转到另一个朝向

// 起始旋转：面向 -Z 方向
const start = Quaternion.fromEuler(0, 0, 0);

// 目标旋转：面向 -X 方向（绕 Y 轴旋转 90°）
const end = Quaternion.fromAxisAngle(0, 1, 0, Math.PI / 2);

// 插值动画（假设 60 帧）
for (let frame = 0; frame <= 60; frame++) {
  const t = frame / 60;
  const current = slerp(start, end, t);

  // 转换为旋转矩阵用于渲染
  const rotMatrix = current.toMat4();

  // 或者直接用四元数旋转向量
  const [fx, fy, fz] = current.rotateVector(0, 0, -1);
  console.log(`帧 ${frame}: 前方向 = (${fx.toFixed(3)}, ${fy.toFixed(3)}, ${fz.toFixed(3)})`);
}

// 组合旋转：先绕 X 轴 30°，再绕 Y 轴 45°
const q1 = Quaternion.fromAxisAngle(1, 0, 0, Math.PI / 6);
const q2 = Quaternion.fromAxisAngle(0, 1, 0, Math.PI / 4);
const combined = q2.multiply(q1); // 注意顺序：先 q1 再 q2
console.log(`组合旋转: ${combined}`);
```

## 常见误区

### 1. 混淆乘法顺序

四元数乘法不满足交换律。`q2 × q1` 表示先 q1 旋转再 q2 旋转（与矩阵乘法一样，从右往左应用）。顺序搞反会导致完全不同的旋转结果。

### 2. 忘记归一化

浮点运算的累积误差会导致四元数逐渐偏离单位长度。在频繁乘法或插值后，必须重新归一化。非单位四元数不能正确表示旋转，会导致物体变形。

### 3. SLERP 前不检查点积符号

如果 `q1 · q2 < 0`，直接 SLERP 会走最长弧（绕远路）。必须先检查点积，如果为负就取反其中一个四元数，确保走最短弧。

### 4. 用欧拉角做插值

欧拉角插值在万向节锁附近会产生不自然的运动，而且三个分量独立插值无法保证旋转路径是最优的。动画系统中应该始终使用四元数 SLERP。

## 工程建议

### 1. 存储用四元数，UI 用欧拉角

运行时旋转数据用四元数存储和计算。用户界面（编辑器、调试面板）显示和输入时转为欧拉角，因为欧拉角对人类更直观。

### 2. 对极小角度用 LERP 优化

当两个四元数非常接近（dot > 0.9995）时，SLERP 和 LERP 几乎没有区别，但 LERP 计算更快。在实现中加入这个阈值判断可以提升性能。

### 3. 注意四元数的双覆盖性

`q` 和 `-q` 表示同一个旋转。在做 SLERP 时，如果两个四元数的点积为负，取反其中一个以走最短弧。这个特性也意味着不能简单地用 `==` 判断两个旋转是否相同。

### 4. 动画关键帧使用四元数

骨骼动画的关键帧旋转应该用四元数存储。运行时对相邻关键帧做 SLERP 插值，然后转换为矩阵传递给 GPU。这是所有主流 3D 引擎的做法。

## 小结

四元数是 3D 旋转的最佳表示：没有万向节锁，SLERP 插值自然平滑，组合旋转只需乘法。四元数 `q = (w, x, y, z)` 可以看作 4D 超球面上的点，单位四元数表示旋转。实际工程中，用四元数做计算，用欧拉角做显示，用矩阵做 GPU 变换——三者各司其职。

## 参考答案

### 练习 1

**思路**：Squad（Spherical and Quadrangle）插值是 SLERP 的扩展，用于多个四元数之间的平滑过渡。它类似于贝塞尔曲线：用四个控制点定义一段曲线，参数 t 在中间两个控制点之间插值，两端控制点影响切线方向。Squad 本质上是两次 SLERP 的组合。

**答案**：

```typescript
// 辅助函数：计算辅助四元数（用于 Squad 的切线控制）
function squadIntermediate(
  qPrev: Quaternion, qCurr: Quaternion, qNext: Quaternion
): Quaternion {
  const qCurrInv = qCurr.conjugate();
  const log1 = quaternionLog(qCurrInv.multiply(qPrev));
  const log2 = quaternionLog(qCurrInv.multiply(qNext));
  // 辅助四元数 = qCurr × exp(-1/4 × (log1 + log2))
  const sum = new Quaternion(
    (log1.x + log2.x) * -0.25,
    (log1.y + log2.y) * -0.25,
    (log1.z + log2.z) * -0.25,
    (log1.w + log2.w) * -0.25
  );
  return qCurr.multiply(quaternionExp(sum));
}

// 四元数对数（假设单位四元数）
function quaternionLog(q: Quaternion): Quaternion {
  const len = Math.sqrt(q.x*q.x + q.y*q.y + q.z*q.z);
  if (len < 1e-10) return new Quaternion(0, 0, 0, 0);
  const halfAngle = Math.atan2(len, q.w);
  const scale = halfAngle / len;
  return new Quaternion(q.x * scale, q.y * scale, q.z * scale, 0);
}

// 四元数指数
function quaternionExp(q: Quaternion): Quaternion {
  const len = Math.sqrt(q.x*q.x + q.y*q.y + q.z*q.z);
  if (len < 1e-10) return new Quaternion(0, 0, 0, 1);
  const s = Math.sin(len) / len;
  return new Quaternion(q.x*s, q.y*s, q.z*s, Math.cos(len)).normalize();
}

// Squad 插值主函数
function squad(
  q0: Quaternion, q1: Quaternion, q2: Quaternion, q3: Quaternion,
  t: number
): Quaternion {
  // 计算两个辅助四元数
  const a = squadIntermediate(q0, q1, q2);
  const b = squadIntermediate(q1, q2, q3);

  // 两次 SLERP：外层在 q1 和 q2 之间，内层在辅助四元数之间
  const s1 = slerp(q1, q2, t);
  const s2 = slerp(a, b, t);
  return slerp(s1, s2, 2 * t * (1 - t)).normalize();
}

// 测试：四个关键帧旋转
const q0 = Quaternion.fromAxisAngle(0, 1, 0, 0);
const q1 = Quaternion.fromAxisAngle(0, 1, 0, Math.PI / 3);
const q2 = Quaternion.fromAxisAngle(0, 1, 0, Math.PI * 2 / 3);
const q3 = Quaternion.fromAxisAngle(0, 1, 0, Math.PI);

for (let i = 0; i <= 10; i++) {
  const t = i / 10;
  const result = squad(q0, q1, q2, q3, t);
  const [fx, fy, fz] = result.rotateVector(0, 0, -1);
  console.log(`t=${t.toFixed(1)}: 前方向 = (${fx.toFixed(3)}, ${fy.toFixed(3)}, ${fz.toFixed(3)})`);
}
```

**要点**：
- Squad 需要四个控制四元数，插值发生在中间两个之间，两端影响曲线形状
- 当只有两个四元数时，Squad 退化为 SLERP
- 实际引擎中，Squad 用于骨骼动画的多关键帧平滑插值，比逐段 SLERP 更平滑

### 练习 2

**思路**：四元数转欧拉角需要从旋转矩阵的元素中提取角度。关键是处理万向节锁的奇异情况——当 pitch 接近 ±90° 时，yaw 和 roll 的旋转轴重合，需要将其中一个设为 0。

**答案**：

```typescript
// 在 Quaternion 类中添加
toEuler(): { x: number; y: number; z: number } {
  const { x, y, z, w } = this;
  const sinr_cosp = 2 * (w * x + y * z);
  const cosr_cosp = 1 - 2 * (x * x + y * y);
  const roll = Math.atan2(sinr_cosp, cosr_cosp);

  const sinp = 2 * (w * y - z * x);
  let pitch: number;
  if (Math.abs(sinp) >= 1) {
    // 万向节锁：pitch 接近 ±90°
    pitch = Math.sign(sinp) * Math.PI / 2;
  } else {
    pitch = Math.asin(sinp);
  }

  const siny_cosp = 2 * (w * z + x * y);
  const cosy_cosp = 1 - 2 * (y * y + z * z);
  const yaw = Math.atan2(siny_cosp, cosy_cosp);

  return { x: roll, y: yaw, z: pitch };
}

// 测试：fromEuler → toEuler 往返一致性
function testRoundTrip(rx: number, ry: number, rz: number) {
  const q = Quaternion.fromEuler(rx, ry, rz);
  const euler = q.toEuler();
  const diff = Math.abs(euler.x - rx) + Math.abs(euler.y - ry) + Math.abs(euler.z - rz);
  console.log(
    `输入: (${(rx*180/Math.PI).toFixed(1)}°, ${(ry*180/Math.PI).toFixed(1)}°, ${(rz*180/Math.PI).toFixed(1)}°) ` +
    `→ 输出: (${(euler.x*180/Math.PI).toFixed(1)}°, ${(euler.y*180/Math.PI).toFixed(1)}°, ${(euler.z*180/Math.PI).toFixed(1)}°) ` +
    `误差: ${diff.toFixed(6)}`
  );
}

testRoundTrip(0.5, 0.3, 0.1);           // 正常情况
testRoundTrip(0, Math.PI / 2, 0);       // 万向节锁边界
testRoundTrip(Math.PI / 4, 0, Math.PI / 6); // 另一个正常情况
```

**要点**：
- `Math.abs(sinp) >= 1` 是万向节锁的检测条件，此时将 yaw 设为 0（或 roll 设为 0）
- 往返转换在非奇异区域应保持一致，奇异区域会丢失一个自由度
- 欧拉角的旋转顺序（XYZ、ZYX 等）必须与 fromEuler 的顺序一致

### 练习 3

**思路**：分别用欧拉角线性插值和四元数 SLERP 让物体从 (0,0,-1) 旋转到 (0,-1,0)，经过 pitch=90° 的万向节锁区域。对比两者在该区域的行为差异。

**答案**：

```typescript
// 起始：面向 -Z
// 目标：面向 -Y（绕 X 轴旋转 90°）
const startEuler = { x: 0, y: 0, z: 0 };
const endEuler = { x: Math.PI / 2, y: 0, z: 0 };

const startQuat = Quaternion.fromEuler(0, 0, 0);
const endQuat = Quaternion.fromEuler(Math.PI / 2, 0, 0);

console.log('=== 欧拉角插值（经过万向节锁）===');
for (let i = 0; i <= 20; i++) {
  const t = i / 20;
  // 欧拉角直接线性插值
  const ex = startEuler.x + (endEuler.x - startEuler.x) * t;
  const ey = startEuler.y + (endEuler.y - startEuler.y) * t;
  const ez = startEuler.z + (endEuler.z - startEuler.z) * t;
  const q = Quaternion.fromEuler(ex, ey, ez);
  const [fx, fy, fz] = q.rotateVector(0, 0, -1);
  console.log(`t=${t.toFixed(2)}: 前方向 = (${fx.toFixed(4)}, ${fy.toFixed(4)}, ${fz.toFixed(4)})`);
}

console.log('=== 四元数 SLERP（平滑过渡）===');
for (let i = 0; i <= 20; i++) {
  const t = i / 20;
  const q = slerp(startQuat, endQuat, t);
  const [fx, fy, fz] = q.rotateVector(0, 0, -1);
  console.log(`t=${t.toFixed(2)}: 前方向 = (${fx.toFixed(4)}, ${fy.toFixed(4)}, ${fz.toFixed(4)})`);
}
```

**预期结论**：
- **欧拉角插值**：当 pitch 接近 90° 时，前方向向量可能出现抖动或短暂的异常偏转。三个分量独立插值无法保证旋转路径是最优弧线
- **四元数 SLERP**：前方向向量沿大圆弧匀速平滑过渡，从 (0,0,-1) 到 (0,-1,0) 走的是最短路径，没有任何抖动
- **根本原因**：欧拉角的三个旋转轴在 pitch=90° 时发生退化（Y 和 Z 轴重合），而四元数在 4D 球面上不存在这种退化
