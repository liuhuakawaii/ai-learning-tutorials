# 第3课：投影与相机

## 场景引入

你用手机拍了一张建筑的照片。近处的门看起来很大，远处的窗户看起来很小——这就是**透视效果**。而在建筑蓝图上，所有尺寸都按相同比例绘制，不管远近大小都一样——这就是**正交投影**。在 3D 图形中，相机决定了"从哪里看"，投影决定了"怎么看"。理解这两个概念，你才能正确地把 3D 世界渲染到 2D 屏幕上。

## 学习目标

1. 理解正交投影和透视投影的区别及适用场景
2. 掌握 View 矩阵（lookAt）的构造原理
3. 掌握透视投影矩阵和正交投影矩阵的构造方法
4. 理解 NDC（归一化设备坐标）和视锥体的概念
5. 能够用 TypeScript 实现完整的相机和投影矩阵

## 一、坐标变换管线

3D 顶点从模型空间到屏幕像素，经历以下变换：

```
  模型空间    世界空间    相机空间    裁剪空间    NDC空间     屏幕空间
  ┌─────┐   ┌─────┐   ┌─────┐   ┌─────┐   ┌─────┐   ┌─────┐
  │局部坐标│──→│世界坐标│──→│观察坐标│──→│裁剪坐标│──→│NDC坐标│──→│像素坐标│
  └─────┘   └─────┘   └─────┘   └─────┘   └─────┘   └─────┘
          Model        View     Projection    透视除法    Viewport
          Matrix      Matrix      Matrix      (÷w)      Mapping
```

- **Model 矩阵**：模型空间 → 世界空间（上一课学过）
- **View 矩阵**：世界空间 → 相机空间（本课重点）
- **Projection 矩阵**：相机空间 → 裁剪空间（本课重点）
- **透视除法**：裁剪空间 → NDC（硬件自动完成）
- **Viewport 映射**：NDC → 屏幕像素（WebGPU 配置）

## 二、View 矩阵（lookAt）

### 相机三要素

一个相机由三个要素定义：

```
  eye    — 相机位置（眼睛在哪）
  center — 观察目标（在看什么）
  up     — 上方向（头顶朝哪）
```

```
        up
        ↑
        |
        |  center
        |  /
        | / 视线方向
        |/
        eye ────→ right
       /
      ↙
    forward = normalize(center - eye)
```

### lookAt 矩阵构造

View 矩阵将世界坐标变换到以相机为原点的坐标系。构造过程：

```
  1. forward = normalize(center - eye)     // 视线方向
  2. right   = normalize(forward × up)     // 右方向
  3. camUp   = right × forward             // 相机的上方向

  View 矩阵 = 旋转部分 × 平移部分

  ┌ rx    ry    rz    -eye·right  ┐
  │ ux    uy    uz    -eye·camUp  │
  │ -fx   -fy   -fz   eye·forward│
  └ 0     0     0     1          ┘
```

注意 forward 取负号，因为在相机空间中，观察方向是 -Z 轴（右手坐标系）。

## 三、正交投影

正交投影没有近大远小的效果，物体不管远近都保持同样大小。常用于 2D 游戏、CAD、UI 渲染。

### 正交投影的视体

正交投影的视体是一个长方体（box），由六个面定义：

```
        top
        ┌────────────────┐
        │                │
  left  │    near plane   │  right
        │                │
        └────────────────┘
        bottom

  侧面视图：
        ┌──────────┐ ← top
        │          │
  near ─┤          ├─ far
        │          │
        └──────────┘ ← bottom
```

### 正交投影矩阵

```
  ┌ 2/(r-l)    0       0     -(r+l)/(r-l) ┐
  │   0     2/(t-b)    0     -(t+b)/(t-b) │
  │   0        0    -1/(f-n)  -f/(f-n)    │
  └   0        0       0          1        ┘
```

其中 l, r, b, t, n, f 分别是 left, right, bottom, top, near, far。

简化版（对称视体，l=-r, b=-t）：

```
  ┌ 1/r    0      0        0     ┐
  │  0    1/t     0        0     │
  │  0     0   -1/(f-n)  -f/(f-n)│
  └  0     0      0        1     ┘
```

## 四、透视投影

透视投影模拟人眼，近大远小。几乎所有 3D 游戏和应用都使用透视投影。

### 透视投影的视锥体（Frustum）

透视投影的视体是一个截头锥体（frustum）：

```
  俯视图：
           near plane
            ┌────┐
           /│    │\
          / │    │ \
         /  │    │  \
        /   │    │   \
       /    │    │    \
      ──────┘    └──────
             far plane

  侧视图：
              top
             /
            / ← 视野角度 (FOV)
   eye ────/
            \
             \
              bottom
```

### 透视投影矩阵

给定视野角度 `fov`、宽高比 `aspect`、近平面 `near`、远平面 `far`：

```
  f = 1 / tan(fov/2)

  ┌ f/aspect  0    0              0             ┐
  │    0      f    0              0             │
  │    0      0    far/(near-far)  near*far/(near-far) │
  └    0      0    -1             0             ┘
```

透视矩阵的关键效果：**将 z 值映射到 w 分量**。经过透视除法（x/w, y/w, z/w）后，远处的物体 z 趋近于 1，近处趋近于 -1，同时 x, y 也会因除以 w 而产生近大远小的效果。

## 五、NDC 坐标与透视除法

经过投影矩阵变换后，得到裁剪坐标 `(x, y, z, w)`。GPU 自动进行透视除法：

```
  NDC = (x/w, y/w, z/w)
```

WebGPU 的 NDC 范围：

```
  x: [-1, 1]  ← 左到右
  y: [-1, 1]  ← 下到上（注意：Y 轴向上）
  z: [0, 1]   ← 近到远（WebGPU 特有，OpenGL 是 [-1, 1]）
```

```
  NDC 空间 (WebGPU)：

       y
       ↑
       │  ┌─────────┐ (1,1,1)
       │ /        /│
       │/        / │
  ─────/────────/  │──→ x
      │        │  /
      │        │ /
      └────────┘/
    (-1,-1,0)  z
```

超出 NDC 范围的片段会被裁剪（clipping），这就是为什么物体在视野外不会被渲染。

## 六、TypeScript 实现

```typescript
class Mat4 {
  elements: Float32Array;

  constructor() {
    this.elements = new Float32Array(16);
    this.identity();
  }

  identity(): Mat4 {
    const e = this.elements;
    e.fill(0);
    e[0] = e[5] = e[10] = e[15] = 1;
    return this;
  }

  multiply(m: Mat4): Mat4 {
    const a = this.elements;
    const b = m.elements;
    const out = new Float32Array(16);
    for (let col = 0; col < 4; col++) {
      for (let row = 0; row < 4; row++) {
        out[col * 4 + row] =
          a[row]      * b[col * 4]     +
          a[4 + row]  * b[col * 4 + 1] +
          a[8 + row]  * b[col * 4 + 2] +
          a[12 + row] * b[col * 4 + 3];
      }
    }
    this.elements = out;
    return this;
  }

  // LookAt 矩阵
  static lookAt(
    eyeX: number, eyeY: number, eyeZ: number,
    centerX: number, centerY: number, centerZ: number,
    upX: number, upY: number, upZ: number
  ): Mat4 {
    // 计算 forward, right, up 三个轴
    let fx = centerX - eyeX;
    let fy = centerY - eyeY;
    let fz = centerZ - eyeZ;
    let len = Math.sqrt(fx * fx + fy * fy + fz * fz);
    fx /= len; fy /= len; fz /= len;

    // right = forward × up
    let rx = fy * upZ - fz * upY;
    let ry = fz * upX - fx * upZ;
    let rz = fx * upY - fy * upX;
    len = Math.sqrt(rx * rx + ry * ry + rz * rz);
    rx /= len; ry /= len; rz /= len;

    // camUp = right × forward
    const ux = ry * fz - rz * fy;
    const uy = rz * fx - rx * fz;
    const uz = rx * fy - ry * fx;

    const m = new Mat4();
    const e = m.elements;
    // 旋转部分（列主序）
    e[0] = rx;  e[1] = ux;  e[2] = -fx;  e[3] = 0;
    e[4] = ry;  e[5] = uy;  e[6] = -fy;  e[7] = 0;
    e[8] = rz;  e[9] = uz;  e[10] = -fz; e[11] = 0;
    // 平移部分
    e[12] = -(rx * eyeX + ry * eyeY + rz * eyeZ);
    e[13] = -(ux * eyeX + uy * eyeY + uz * eyeZ);
    e[14] = -(-fx * eyeX + -fy * eyeY + -fz * eyeZ);
    e[15] = 1;
    return m;
  }

  // 透视投影矩阵
  static perspective(
    fovY: number,    // 垂直视野角度（弧度）
    aspect: number,  // 宽高比
    near: number,    // 近平面距离
    far: number      // 远平面距离
  ): Mat4 {
    const f = 1 / Math.tan(fovY / 2);
    const rangeInv = 1 / (near - far);

    const m = new Mat4();
    const e = m.elements;
    e.fill(0);
    e[0] = f / aspect;
    e[5] = f;
    e[10] = far * rangeInv;
    e[11] = -1;
    e[14] = near * far * rangeInv;
    return m;
  }

  // 正交投影矩阵
  static orthographic(
    left: number, right: number,
    bottom: number, top: number,
    near: number, far: number
  ): Mat4 {
    const m = new Mat4();
    const e = m.elements;
    e.fill(0);
    e[0]  = 2 / (right - left);
    e[5]  = 2 / (top - bottom);
    e[10] = -1 / (far - near);       // WebGPU: z 映射到 [0,1]
    e[12] = -(right + left) / (right - left);
    e[13] = -(top + bottom) / (top - bottom);
    e[14] = -near / (far - near);
    e[15] = 1;
    return m;
  }

  toString(): string {
    const e = this.elements;
    return [
      `[${e[0].toFixed(3)} ${e[4].toFixed(3)} ${e[8].toFixed(3)} ${e[12].toFixed(3)}]`,
      `[${e[1].toFixed(3)} ${e[5].toFixed(3)} ${e[9].toFixed(3)} ${e[13].toFixed(3)}]`,
      `[${e[2].toFixed(3)} ${e[6].toFixed(3)} ${e[10].toFixed(3)} ${e[14].toFixed(3)}]`,
      `[${e[3].toFixed(3)} ${e[7].toFixed(3)} ${e[11].toFixed(3)} ${e[15].toFixed(3)}]`,
    ].join('\n');
  }
}
```

### 使用示例

```typescript
// 创建 View 矩阵：相机在 (0, 5, 10)，看向原点
const view = Mat4.lookAt(
  0, 5, 10,     // eye
  0, 0, 0,      // center
  0, 1, 0       // up
);

// 创建透视投影：60° 视野，16:9 宽高比
const projection = Mat4.perspective(
  60 * Math.PI / 180,  // fov
  16 / 9,              // aspect
  0.1,                 // near
  100                  // far
);

// MVP 矩阵 = Projection × View × Model
const model = new Mat4(); // 单位矩阵（物体在原点）
const mvp = new Mat4()
  .multiply(projection)
  .multiply(view)
  .multiply(model);

// 变换顶点到裁剪空间
const [cx, cy, cz, cw] = mvp.transformPoint(1, 0, 0);
// 透视除法得到 NDC
const ndcX = cx / cw;
const ndcY = cy / cw;
const ndcZ = cz / cw;
console.log(`NDC: (${ndcX.toFixed(3)}, ${ndcY.toFixed(3)}, ${ndcZ.toFixed(3)})`);
```

## 七、视锥体裁剪

视锥体由六个平面定义，只有在这个范围内的物体才会被渲染：

```
  视锥体六个平面：
  ┌─────────────┐
  │   Near (近)  │  最重要的裁剪面
  │   Far  (远)  │
  │   Left (左)  │
  │   Right(右)  │
  │   Top  (上)  │
  │   Bottom(下) │
  └─────────────┘
```

WebGPU 中，裁剪在裁剪空间自动进行：当 `|x| > w` 或 `|y| > w` 或 `z < 0` 或 `z > w` 时，顶点在视锥体外。这就是为什么裁剪坐标叫"clip coordinates"。

## 常见误区

### 1. near 值设得太小

near 值过小（如 0.0001）会导致深度缓冲精度严重下降，出现 z-fighting（深度冲突）。建议 near 不要小于 0.1，far 不要过大。对于大多数场景，near=0.1, far=1000 是合理的选择。

### 2. 忘记 WebGPU 的 z 范围是 [0,1]

OpenGL 的 NDC z 范围是 [-1, 1]，而 WebGPU 是 [0, 1]。直接把 OpenGL 的投影矩阵用在 WebGPU 中会导致深度映射错误。两者的投影矩阵公式略有不同。

### 3. 混淆 fov 的单位

投影矩阵需要弧度，但很多设计工具用角度。忘记转换 `(角度 * Math.PI / 180)` 会导致投影完全错误。建议封装一个接受角度的版本，在内部转换。

### 4. lookAt 的 up 向量和 forward 平行

当 eye 和 center 的连线与 up 向量平行时（比如从正上方往下看），叉积结果为零向量，View 矩阵会退化。需要特殊处理这种情况，比如切换 up 向量为 `(0, 0, 1)`。

## 工程建议

### 1. 缓存 VP 矩阵

View 矩阵只在相机移动时改变，Projection 矩阵只在窗口大小或 FOV 改变时改变。如果两者都没变，直接复用上一帧的 VP 矩阵，避免每帧重复计算。

### 2. 根据场景选择投影方式

3D 场景用透视投影，2D UI 用正交投影。很多引擎会在一帧中切换多次投影矩阵：3D 场景用透视，UI 叠加层用正交。在 WebGPU 中通过不同的 render pass 或 pipeline 来切换。

### 3. 合理设置远平面

远平面不是越远越好。far 值过大会浪费深度精度。如果你的场景最大可见距离是 500 米，就不要把 far 设为 10000。可以先用一个较大的值开发，后期根据实际场景调优。

### 4. 使用无限远透视矩阵

对于户外大场景，可以使用"无限远透视矩阵"（infinite far plane），让 far 趋近无穷大。这消除了远平面裁剪，同时将所有深度精度集中在近处，适合需要大量深度范围的场景。

## 小结

本课讲了 3D 渲染管线中的关键变换：View 矩阵（lookAt）将世界坐标变换到相机空间，投影矩阵（透视/正交）将相机空间变换到裁剪空间。透视投影产生近大远小的效果，正交投影保持物体大小不变。NDC 坐标是透视除法后的标准化坐标，WebGPU 中 x, y ∈ [-1,1]，z ∈ [0,1]。合理设置 near/far 和 fov 是保证渲染质量的关键。

## 参考答案

### 练习 1

**思路**：轨道相机用球坐标系描述位置——距离、水平角、垂直角唯一确定空间中的一点。将球坐标转为笛卡尔坐标后，加上目标点偏移就是相机位置，再用 lookAt 构造 View 矩阵。

**答案**：

```typescript
class OrbitCamera {
  constructor(
    public center: [number, number, number] = [0, 0, 0],
    public distance: number = 10,
    public theta: number = 0,      // 水平角度（弧度）
    public phi: number = Math.PI / 4  // 垂直角度（弧度，0=正上方，π=正下方）
  ) {}

  getEye(): [number, number, number] {
    // 球坐标转笛卡尔坐标
    const x = this.center[0] + this.distance * Math.sin(this.phi) * Math.sin(this.theta);
    const y = this.center[1] + this.distance * Math.cos(this.phi);
    const z = this.center[2] + this.distance * Math.sin(this.phi) * Math.cos(this.theta);
    return [x, y, z];
  }

  getViewMatrix(): Mat4 {
    const eye = this.getEye();
    return Mat4.lookAt(
      eye[0], eye[1], eye[2],
      this.center[0], this.center[1], this.center[2],
      0, 1, 0
    );
  }
}

// 测试：相机绕原点旋转
const camera = new OrbitCamera([0, 0, 0], 10, 0, Math.PI / 3);
const eye = camera.getEye();
console.log(`相机位置: (${eye[0].toFixed(2)}, ${eye[1].toFixed(2)}, ${eye[2].toFixed(2)})`);
// theta=0, phi=π/3: x=0, y=5, z=8.66

// 水平旋转 90°
camera.theta = Math.PI / 2;
const eye2 = camera.getEye();
console.log(`旋转后: (${eye2[0].toFixed(2)}, ${eye2[1].toFixed(2)}, ${eye2[2].toFixed(2)})`);
// x=8.66, y=5, z=0
```

**要点**：
- phi 的范围应限制在 (0, π) 之间，不能等于 0 或 π（否则 up 向量与 forward 平行）
- 实际项目中通常会限制 phi 的范围，比如 (0.01, π - 0.01)，避免万向节锁
- theta 可以任意旋转，phi 限制了相机不能翻转到地面以下

### 练习 2

**思路**：拾取射线的核心是将屏幕坐标反向投影到世界空间。先将像素坐标转为 NDC，再用 VP 矩阵的逆矩阵将 NDC 分别变换到近平面和远平面上的两个点，两点连线就是射线。

**答案**：

```typescript
interface Ray {
  origin: [number, number, number];
  direction: [number, number, number];
}

function screenToRay(
  mx: number, my: number,
  screenWidth: number, screenHeight: number,
  viewMatrix: Mat4,
  projMatrix: Mat4
): Ray {
  // 1. 屏幕坐标 → NDC（x,y ∈ [-1,1]，WebGPU z ∈ [0,1]）
  const ndcX = (mx / screenWidth) * 2 - 1;
  const ndcY = 1 - (my / screenHeight) * 2; // Y 轴翻转（屏幕 Y 向下，NDC Y 向上）

  // 2. 计算 VP 矩阵的逆
  const vp = new Mat4().multiply(projMatrix).multiply(viewMatrix);
  const vpInv = vp.inverse();

  // 3. 近平面上的点（NDC z = 0）
  const [nx, ny, nz, nw] = [
    vpInv.elements[0]*ndcX + vpInv.elements[4]*ndcY + vpInv.elements[12],
    vpInv.elements[1]*ndcX + vpInv.elements[5]*ndcY + vpInv.elements[13],
    vpInv.elements[2]*ndcX + vpInv.elements[6]*ndcY + vpInv.elements[14],
    vpInv.elements[3]*ndcX + vpInv.elements[7]*ndcY + vpInv.elements[15],
  ];
  const nearPoint: [number, number, number] = [nx/nw, ny/nw, nz/nw];

  // 4. 远平面上的点（NDC z = 1）
  const [fx, fy, fz, fw] = [
    vpInv.elements[0]*ndcX + vpInv.elements[4]*ndcY + vpInv.elements[8] + vpInv.elements[12],
    vpInv.elements[1]*ndcX + vpInv.elements[5]*ndcY + vpInv.elements[9] + vpInv.elements[13],
    vpInv.elements[2]*ndcX + vpInv.elements[6]*ndcY + vpInv.elements[10] + vpInv.elements[14],
    vpInv.elements[3]*ndcX + vpInv.elements[7]*ndcY + vpInv.elements[11] + vpInv.elements[15],
  ];
  const farPoint: [number, number, number] = [fx/fw, fy/fw, fz/fw];

  // 5. 构造射线
  const dx = farPoint[0] - nearPoint[0];
  const dy = farPoint[1] - nearPoint[1];
  const dz = farPoint[2] - nearPoint[2];
  const len = Math.sqrt(dx*dx + dy*dy + dz*dz);

  return {
    origin: nearPoint,
    direction: [dx/len, dy/len, dz/len]
  };
}

// 测试
const view = Mat4.lookAt(0, 5, 10, 0, 0, 0, 0, 1, 0);
const proj = Mat4.perspective(60 * Math.PI / 180, 16/9, 0.1, 100);
const ray = screenToRay(400, 300, 800, 600, view, proj);
console.log(`射线起点: (${ray.origin[0].toFixed(3)}, ${ray.origin[1].toFixed(3)}, ${ray.origin[2].toFixed(3)})`);
console.log(`射线方向: (${ray.direction[0].toFixed(3)}, ${ray.direction[1].toFixed(3)}, ${ray.direction[2].toFixed(3)})`);
// 方向应该大致指向 (0,0,0) - (0,5,10) 的方向，即向下前方
```

**要点**：
- 屏幕 Y 轴和 NDC Y 轴方向相反，需要翻转
- WebGPU 的 NDC z 范围是 [0,1]，近平面对应 z=0，远平面对应 z=1
- 拾取射线是碰撞检测、物体选择等交互功能的基础

### 练习 3

**思路**：用同一组顶点分别通过透视投影和正交投影变换到 NDC 空间，对比结果。透视投影的关键特征是 w 分量与 z 相关，导致透视除法后 x、y 会被距离影响。

**答案**：

```typescript
// 同一组顶点
const vertices: [number, number, number][] = [
  [1, 0, -2],   // 近处
  [1, 0, -10],  // 远处
  [1, 0, -50],  // 更远处
];

const view = Mat4.lookAt(0, 0, 0, 0, 0, -1, 0, 1, 0);
const perspProj = Mat4.perspective(60 * Math.PI / 180, 16/9, 0.1, 100);
const orthoProj = Mat4.orthographic(-10, 10, -10, 10, 0.1, 100);

const vpPersp = new Mat4().multiply(perspProj).multiply(view);
const vpOrtho = new Mat4().multiply(orthoProj).multiply(view);

console.log('=== 透视投影 NDC ===');
for (const [x, y, z] of vertices) {
  const [cx, cy, cz, cw] = [
    vpPersp.elements[0]*x + vpPersp.elements[8]*z + vpPersp.elements[12],
    vpPersp.elements[1]*x + vpPersp.elements[9]*z + vpPersp.elements[13],
    vpPersp.elements[2]*x + vpPersp.elements[10]*z + vpPersp.elements[14],
    vpPersp.elements[3]*x + vpPersp.elements[11]*z + vpPersp.elements[15],
  ];
  console.log(`(${x}, ${y}, ${z}) → NDC: (${(cx/cw).toFixed(4)}, ${(cy/cw).toFixed(4)}, ${(cz/cw).toFixed(4)})`);
}

console.log('=== 正交投影 NDC ===');
for (const [x, y, z] of vertices) {
  const [cx, cy, cz, cw] = [
    vpOrtho.elements[0]*x + vpOrtho.elements[8]*z + vpOrtho.elements[12],
    vpOrtho.elements[1]*x + vpOrtho.elements[9]*z + vpOrtho.elements[13],
    vpOrtho.elements[2]*x + vpOrtho.elements[10]*z + vpOrtho.elements[14],
    vpOrtho.elements[3]*x + vpOrtho.elements[11]*z + vpOrtho.elements[15],
  ];
  console.log(`(${x}, ${y}, ${z}) → NDC: (${(cx/cw).toFixed(4)}, ${(cy/cw).toFixed(4)}, ${(cz/cw).toFixed(4)})`);
}
```

**预期结论**：
- **透视投影**：同样 x=1 的三个点，NDC x 值随距离增大而减小（近大远小）。近处物体的 NDC x 可能是 0.8，远处可能只有 0.05
- **正交投影**：同样 x=1 的三个点，NDC x 值完全相同（不受距离影响）。无论远近，大小保持不变
- **深度值**：两种投影都将 z 映射到 [0,1]，但映射曲线不同——透视投影在近处分配更多精度（非线性），正交投影是线性映射
