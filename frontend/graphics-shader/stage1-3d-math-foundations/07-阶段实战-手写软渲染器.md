# 第七课：阶段实战 — 手写软渲染器

## 场景引入

在前面的课程中，我们学习了向量、矩阵、光照模型和颜色空间。现在是时候把所有知识整合到一起了。本课我们将不依赖 WebGL，仅用 Canvas 2D 的像素操作能力，从零实现一个完整的 3D 软渲染器。这个项目将帮助你彻底理解 GPU 渲染管线的每一步——因为你自己就是 GPU。

## 学习目标

1. 理解完整的顶点变换流水线（模型 → 世界 → 观察 → 投影 → 屏幕）
2. 掌握三角形光栅化算法（重心坐标法）
3. 实现深度缓冲（Z-buffer）解决遮挡问题
4. 使用重心坐标插值实现逐像素着色
5. 整合 Blinn-Phong 光照模型，渲染出有明暗变化的 3D 物体

## 一、渲染流水线概述

```
顶点数据
    │
    ▼
┌─────────────────┐
│  顶点变换       │  模型空间 → 世界空间 → 观察空间 → 裁剪空间
└────────┬────────┘
         ▼
┌─────────────────┐
│  透视除法       │  裁剪空间 → NDC（归一化设备坐标）
└────────┬────────┘
         ▼
┌─────────────────┐
│  视口变换       │  NDC → 屏幕坐标
└────────┬────────┘
         ▼
┌─────────────────┐
│  三角形光栅化   │  确定哪些像素被三角形覆盖
└────────┬────────┘
         ▼
┌─────────────────┐
│  逐像素着色     │  插值属性，计算光照，输出颜色
└────────┬────────┘
         ▼
    帧缓冲（屏幕）
```

## 二、数学工具函数

```typescript
type Vec3 = [number, number, number];
type Vec4 = [number, number, number, number];
type Mat4 = Float32Array; // 4x4 列主序

function vec3Sub(a: Vec3, b: Vec3): Vec3 { return [a[0]-b[0], a[1]-b[1], a[2]-b[2]]; }
function vec3Dot(a: Vec3, b: Vec3): number { return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]; }
function vec3Cross(a: Vec3, b: Vec3): Vec3 {
    return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]];
}
function vec3Normalize(v: Vec3): Vec3 {
    const len = Math.sqrt(v[0]**2 + v[1]**2 + v[2]**2);
    return len > 0 ? [v[0]/len, v[1]/len, v[2]/len] : [0,0,0];
}

function mat4Identity(): Mat4 {
    const m = new Float32Array(16); m[0]=m[5]=m[10]=m[15]=1; return m;
}
function mat4Multiply(a: Mat4, b: Mat4): Mat4 {
    const out = new Float32Array(16);
    for (let c = 0; c < 4; c++) for (let r = 0; r < 4; r++)
        out[c*4+r] = a[r]*b[c*4] + a[4+r]*b[c*4+1] + a[8+r]*b[c*4+2] + a[12+r]*b[c*4+3];
    return out;
}
function mat4MulVec4(m: Mat4, v: Vec4): Vec4 {
    return [
        m[0]*v[0]+m[4]*v[1]+m[8]*v[2]+m[12]*v[3],
        m[1]*v[0]+m[5]*v[1]+m[9]*v[2]+m[13]*v[3],
        m[2]*v[0]+m[6]*v[1]+m[10]*v[2]+m[14]*v[3],
        m[3]*v[0]+m[7]*v[1]+m[11]*v[2]+m[15]*v[3],
    ];
}
function mat4Perspective(fovY: number, aspect: number, near: number, far: number): Mat4 {
    const f = 1/Math.tan(fovY/2), nf = 1/(near-far);
    const m = new Float32Array(16);
    m[0]=f/aspect; m[5]=f; m[10]=(far+near)*nf; m[11]=-1; m[14]=2*far*near*nf;
    return m;
}
function mat4LookAt(eye: Vec3, target: Vec3, up: Vec3): Mat4 {
    const z = vec3Normalize(vec3Sub(eye, target));
    const x = vec3Normalize(vec3Cross(up, z));
    const y = vec3Cross(z, x);
    const m = new Float32Array(16);
    m[0]=x[0]; m[4]=x[1]; m[8]=x[2];  m[12]=-vec3Dot(x,eye);
    m[1]=y[0]; m[5]=y[1]; m[9]=y[2];  m[13]=-vec3Dot(y,eye);
    m[2]=z[0]; m[6]=z[1]; m[10]=z[2]; m[14]=-vec3Dot(z,eye);
    m[3]=0; m[7]=0; m[11]=0; m[15]=1;
    return m;
}
```

## 三、三角形光栅化（重心坐标法）

光栅化是将三角形转换为像素的过程。对三角形包围盒内的每个像素，计算重心坐标判断是否在内部：

```
       v0
       /\
      /  \      P = α·v0 + β·v1 + γ·v2
     / P  \     α + β + γ = 1
    / ·    \    P 在内部 ⟺ α≥0, β≥0, γ≥0
   /________\
  v1        v2
```

```typescript
interface Vertex { position: Vec3; normal: Vec3; color: Vec3; }

function boundingBox(v0: Vec3, v1: Vec3, v2: Vec3, w: number, h: number) {
    return {
        minX: Math.max(0, Math.floor(Math.min(v0[0], v1[0], v2[0]))),
        maxX: Math.min(w-1, Math.ceil(Math.max(v0[0], v1[0], v2[0]))),
        minY: Math.max(0, Math.floor(Math.min(v0[1], v1[1], v2[1]))),
        maxY: Math.min(h-1, Math.ceil(Math.max(v0[1], v1[1], v2[1]))),
    };
}

function barycentric(v0: Vec3, v1: Vec3, v2: Vec3, px: number, py: number): [number,number,number]|null {
    const ab = [v1[0]-v0[0], v1[1]-v0[1]];
    const ac = [v2[0]-v0[0], v2[1]-v0[1]];
    const ap = [px-v0[0], py-v0[1]];
    const denom = ab[0]*ac[1] - ab[1]*ac[0];
    if (Math.abs(denom) < 1e-10) return null;
    const beta = (ap[0]*ac[1] - ap[1]*ac[0]) / denom;
    const gamma = (ab[0]*ap[1] - ab[1]*ap[0]) / denom;
    const alpha = 1 - beta - gamma;
    if (alpha < 0 || beta < 0 || gamma < 0) return null;
    return [alpha, beta, gamma];
}
```

## 四、深度缓冲 (Z-buffer)

每个像素存储一个深度值，新像素只有在更近时才覆盖旧像素：

```typescript
class FrameBuffer {
    colorBuffer: Uint8ClampedArray;
    depthBuffer: Float32Array;
    constructor(public width: number, public height: number) {
        this.colorBuffer = new Uint8ClampedArray(width * height * 4);
        this.depthBuffer = new Float32Array(width * height);
    }
    clear(r: number, g: number, b: number): void {
        for (let i = 0; i < this.width * this.height; i++) {
            this.colorBuffer[i*4]=r; this.colorBuffer[i*4+1]=g;
            this.colorBuffer[i*4+2]=b; this.colorBuffer[i*4+3]=255;
            this.depthBuffer[i] = Infinity;
        }
    }
    setPixel(x: number, y: number, z: number, r: number, g: number, b: number): boolean {
        const idx = y * this.width + x;
        if (z >= this.depthBuffer[idx]) return false;
        this.depthBuffer[idx] = z;
        const ci = idx * 4;
        this.colorBuffer[ci] = Math.min(255, Math.max(0, Math.round(r*255)));
        this.colorBuffer[ci+1] = Math.min(255, Math.max(0, Math.round(g*255)));
        this.colorBuffer[ci+2] = Math.min(255, Math.max(0, Math.round(b*255)));
        this.colorBuffer[ci+3] = 255;
        return true;
    }
}
```

## 五、完整软渲染器

```typescript
class SoftwareRenderer {
    canvas: HTMLCanvasElement;
    ctx: CanvasRenderingContext2D;
    frameBuffer: FrameBuffer;
    mvpMatrix: Mat4 = mat4Identity();
    modelMatrix: Mat4 = mat4Identity();
    cameraPos: Vec3 = [0, 0, 5];
    lightPos: Vec3 = [5, 5, 5];

    constructor(canvas: HTMLCanvasElement) {
        this.canvas = canvas;
        this.ctx = canvas.getContext('2d')!;
        this.frameBuffer = new FrameBuffer(canvas.width, canvas.height);
    }

    setCamera(eye: Vec3, target: Vec3, fovY: number, near: number, far: number): void {
        this.cameraPos = eye;
        const view = mat4LookAt(eye, target, [0,1,0]);
        const proj = mat4Perspective(fovY, this.canvas.width/this.canvas.height, near, far);
        this.mvpMatrix = mat4Multiply(proj, view);
    }

    /** 顶点变换：模型空间 → 屏幕空间 */
    transformVertex(v: Vertex) {
        const worldPos4 = mat4MulVec4(this.modelMatrix, [...v.position, 1]);
        const clipPos = mat4MulVec4(this.mvpMatrix, [...v.position, 1]);
        const w = clipPos[3];
        const screenX = (clipPos[0]/w * 0.5 + 0.5) * this.canvas.width;
        const screenY = (1 - (clipPos[1]/w * 0.5 + 0.5)) * this.canvas.height;
        const screenZ = clipPos[2]/w * 0.5 + 0.5;
        const normal4 = mat4MulVec4(this.modelMatrix, [...v.normal, 0]);
        return {
            screenPos: [screenX, screenY, screenZ] as Vec3,
            worldPos: [worldPos4[0], worldPos4[1], worldPos4[2]] as Vec3,
            worldNormal: vec3Normalize([normal4[0], normal4[1], normal4[2]]),
            w,
        };
    }

    /** 绘制三角形（光栅化 + Blinn-Phong 着色） */
    drawTriangle(v0: Vertex, v1: Vertex, v2: Vertex): void {
        const t0 = this.transformVertex(v0);
        const t1 = this.transformVertex(v1);
        const t2 = this.transformVertex(v2);
        const bb = boundingBox(t0.screenPos, t1.screenPos, t2.screenPos,
            this.canvas.width, this.canvas.height);

        for (let y = bb.minY; y <= bb.maxY; y++) {
            for (let x = bb.minX; x <= bb.maxX; x++) {
                const bc = barycentric(t0.screenPos, t1.screenPos, t2.screenPos, x, y);
                if (!bc) continue;
                const [alpha, beta, gamma] = bc;

                // 透视校正插值
                const invW = alpha/t0.w + beta/t1.w + gamma/t2.w;
                const wa = (alpha/t0.w)/invW, wb = (beta/t1.w)/invW, wc = (gamma/t2.w)/invW;

                // 插值深度、世界坐标、法向量
                const z = wa*t0.screenPos[2] + wb*t1.screenPos[2] + wc*t2.screenPos[2];
                const worldPos: Vec3 = [
                    wa*t0.worldPos[0]+wb*t1.worldPos[0]+wc*t2.worldPos[0],
                    wa*t0.worldPos[1]+wb*t1.worldPos[1]+wc*t2.worldPos[1],
                    wa*t0.worldPos[2]+wb*t1.worldPos[2]+wc*t2.worldPos[2],
                ];
                const N = vec3Normalize([
                    wa*t0.worldNormal[0]+wb*t1.worldNormal[0]+wc*t2.worldNormal[0],
                    wa*t0.worldNormal[1]+wb*t1.worldNormal[1]+wc*t2.worldNormal[1],
                    wa*t0.worldNormal[2]+wb*t1.worldNormal[2]+wc*t2.worldNormal[2],
                ]);

                // Blinn-Phong 光照
                const L = vec3Normalize(vec3Sub(this.lightPos, worldPos));
                const V = vec3Normalize(vec3Sub(this.cameraPos, worldPos));
                const H = vec3Normalize([L[0]+V[0], L[1]+V[1], L[2]+V[2]]);
                const diffuse = Math.max(0, vec3Dot(N, L));
                const specular = Math.pow(Math.max(0, vec3Dot(N, H)), 32);

                // 插值顶点颜色并叠加光照
                const base: Vec3 = [
                    wa*v0.color[0]+wb*v1.color[0]+wc*v2.color[0],
                    wa*v0.color[1]+wb*v1.color[1]+wc*v2.color[1],
                    wa*v0.color[2]+wb*v1.color[2]+wc*v2.color[2],
                ];
                this.frameBuffer.setPixel(x, y, z,
                    base[0]*(0.15+diffuse*0.8)+specular*0.5,
                    base[1]*(0.15+diffuse*0.8)+specular*0.5,
                    base[2]*(0.15+diffuse*0.8)+specular*0.5);
            }
        }
    }

    flush(): void {
        this.ctx.putImageData(
            new ImageData(this.frameBuffer.colorBuffer, this.canvas.width, this.canvas.height), 0, 0);
    }

    render(mesh: { vertices: Vertex[]; indices: number[] }): void {
        this.frameBuffer.clear(20, 20, 30);
        for (let i = 0; i < mesh.indices.length; i += 3) {
            this.drawTriangle(
                mesh.vertices[mesh.indices[i]],
                mesh.vertices[mesh.indices[i+1]],
                mesh.vertices[mesh.indices[i+2]]);
        }
        this.flush();
    }
}
```

## 常见误区

**1. 忘记透视校正插值**

在透视投影下，直接对属性做线性插值会导致纹理扭曲。正确做法是先对 `1/w` 做线性插值，再用插值后的权重对属性插值。代码中的 `wa`、`wb`、`wc` 就是透视校正后的重心坐标。

**2. 深度值范围混淆**

NDC 空间的 z 值范围是 `[-1, 1]`，映射到屏幕空间后应归一化到 `[0, 1]` 用于深度比较。范围搞反会导致近处物体被远处物体遮挡。

**3. 法向量未归一化**

插值法向量后结果可能不再是单位向量。必须在逐像素光照计算前重新归一化，否则光照会出现明暗不均。

**4. 包围盒未裁剪到屏幕范围**

三角形部分超出屏幕时，包围盒 min/max 可能为负数或超过画布尺寸，导致数组越界。务必用 `Math.max(0, ...)` 和 `Math.min(width-1, ...)` 裁剪。

## 工程建议

**1. 先实现再优化**：先用最简单的方式跑通流程，再考虑并行化、SIMD、减少内存分配等优化。

**2. 对比硬件渲染结果**：将软渲染器输出与 WebGL 结果对比，验证变换矩阵、光照计算、深度测试是否正确。

**3. 逐步增加功能**：建议按以下顺序迭代：线框渲染 → 纯色实体 → 深度缓冲 → Blinn-Phong 光照 → 纹理映射。

**4. 理解性能瓶颈**：软渲染器的瓶颈在于逐像素循环。对比 GPU 的并行架构，你会更深刻地理解为什么硬件加速是必要的。

### 练习二

**思路**：用经度 theta 和纬度 phi 遍历球面，生成顶点和三角形索引。

**答案**：

```typescript
function createSphere(segments: number, rings: number): { vertices: Vertex[]; indices: number[] } {
    const vertices: Vertex[] = [], indices: number[] = [];
    for (let ring = 0; ring <= rings; ring++) {
        const phi = (ring / rings) * Math.PI;
        for (let seg = 0; seg <= segments; seg++) {
            const theta = (seg / segments) * 2 * Math.PI;
            const x = Math.sin(phi)*Math.cos(theta), y = Math.cos(phi), z = Math.sin(phi)*Math.sin(theta);
            vertices.push({ position: [x,y,z], normal: [x,y,z], color: [(x+1)*0.5,(y+1)*0.5,(z+1)*0.5] });
        }
    }
    for (let ring = 0; ring < rings; ring++) {
        for (let seg = 0; seg < segments; seg++) {
            const curr = ring*(segments+1)+seg, next = curr+segments+1;
            indices.push(curr, next, curr+1, curr+1, next, next+1);
        }
    }
    return { vertices, indices };
}
```

**要点**：球体顶点的法向量就是归一化后的位置向量。颜色可以用法向量映射为 RGB。

### 练习三

**思路**：计算三角形在屏幕空间的有向面积（叉积），为负则跳过。

**答案**：

```typescript
// 在 drawTriangle 开头添加
const e1 = [t1.screenPos[0]-t0.screenPos[0], t1.screenPos[1]-t0.screenPos[1]];
const e2 = [t2.screenPos[0]-t0.screenPos[0], t2.screenPos[1]-t0.screenPos[1]];
if (e1[0]*e2[1] - e1[1]*e2[0] <= 0) return; // 背面剔除
```

**要点**：正面通常定义为逆时针（CCW），背面为顺时针（CW）。开启背面剔除后性能几乎翻倍。
