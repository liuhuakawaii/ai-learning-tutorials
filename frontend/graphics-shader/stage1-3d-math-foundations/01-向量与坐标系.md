# 向量与坐标系：3D 图形的数学基石

## 现象

你在开发一个 3D 游戏，需要判断子弹是否击中敌人。子弹有飞行方向，敌人有位置——你需要计算两者之间的角度关系。这个问题的本质就是**向量的点积**。

向量是 3D 图形的基石。掌握它，后面的矩阵、光照、Shader 都有了基础。

## 向量 vs 点

```
点：表示位置    → (3, 4, 0) 表示空间中的一个位置
向量：表示方向和距离 → (3, 4, 0) 表示"向右 3、向上 4"

点 - 点 = 向量
点 + 向量 = 点
点 + 点 = 无意义
```

## 基本运算

```typescript
class Vec3 {
  constructor(public x = 0, public y = 0, public z = 0) {}

  add(v: Vec3): Vec3 { return new Vec3(this.x+v.x, this.y+v.y, this.z+v.z) }
  sub(v: Vec3): Vec3 { return new Vec3(this.x-v.x, this.y-v.y, this.z-v.z) }
  scale(s: number): Vec3 { return new Vec3(this.x*s, this.y*s, this.z*s) }
  length(): number { return Math.sqrt(this.x**2 + this.y**2 + this.z**2) }
  lengthSq(): number { return this.x**2 + this.y**2 + this.z**2 }

  normalize(): Vec3 {
    const len = this.length()
    return len > 0 ? this.scale(1/len) : new Vec3()
  }

  // 点积：计算夹角
  dot(v: Vec3): number { return this.x*v.x + this.y*v.y + this.z*v.z }

  // 叉积：计算法线
  cross(v: Vec3): Vec3 {
    return new Vec3(
      this.y*v.z - this.z*v.y,
      this.z*v.x - this.x*v.z,
      this.x*v.y - this.y*v.x
    )
  }

  // 两个向量的夹角
  angleTo(v: Vec3): number {
    const cos = this.dot(v) / (this.length() * v.length())
    return Math.acos(Math.max(-1, Math.min(1, cos)))
  }

  // 线性插值
  lerp(v: Vec3, t: number): Vec3 {
    return new Vec3(
      this.x + (v.x - this.x) * t,
      this.y + (v.y - this.y) * t,
      this.z + (v.z - this.z) * t
    )
  }

  // 反射
  reflect(normal: Vec3): Vec3 {
    return this.sub(normal.scale(2 * this.dot(normal)))
  }
}
```

## 点积的几何含义

```
a · b = |a| × |b| × cos(θ)

当 a、b 都是单位向量时：
  a · b = cos(θ)

  a · b > 0 → 锐角（方向大致相同）
  a · b = 0 → 直角（正交）
  a · b < 0 → 钝角（方向大致相反）
```

应用：判断敌人是否在视野内

```typescript
const forward = new Vec3(0, 0, -1)
const toEnemy = enemyPos.sub(myPos).normalize()
const halfFov = 30 * Math.PI / 180

const inView = forward.dot(toEnemy) > Math.cos(halfFov)
```

## 叉积的几何含义

```
a × b = 垂直于 a 和 b 所在平面的向量
|a × b| = |a| × |b| × sin(θ) = 平行四边形面积
方向由右手定则决定
```

应用：计算三角形法线

```typescript
const edge1 = p1.sub(p0)
const edge2 = p2.sub(p0)
const normal = edge1.cross(edge2).normalize()
```

## 左手 vs 右手坐标系

```
右手坐标系（WebGPU/OpenGL）    左手坐标系（DirectX）
  y ↑                            y ↑
    |                              |
    +----→ x                       +----→ x
   /                              \
  ↙                                ↘
 z（朝外）                        z（朝内）
```

WebGPU 使用右手坐标系：x 向右，y 向上，z 向屏幕外。

## 你可能踩的坑

**坑一：忘记归一化就做点积判断**

`a.dot(b)` 只有在两个都是单位向量时才等于 `cos(θ)`。

**坑二：叉积顺序搞反**

`a × b` 和 `b × a` 方向相反。法线方向取决于三角形顶点的绕序。

**坑三：用 `==` 判断向量相等**

浮点数精度问题。用 `distanceTo` 或分量差值判断。

### 练习二

```typescript
function pointInTriangle(A: Vec3, B: Vec3, C: Vec3, P: Vec3): boolean {
  const cross1 = (B.x-A.x)*(P.y-A.y) - (B.y-A.y)*(P.x-A.x)
  const cross2 = (C.x-B.x)*(P.y-B.y) - (C.y-B.y)*(P.x-B.x)
  const cross3 = (A.x-C.x)*(P.y-C.y) - (A.y-C.y)*(P.x-C.x)

  const hasPos = cross1 > 0 || cross2 > 0 || cross3 > 0
  const hasNeg = cross1 < 0 || cross2 < 0 || cross3 < 0
  return !(hasPos && hasNeg)
}
```

### 练习三

```typescript
function signedAngle(a: Vec3, b: Vec3): { angle: number; direction: string } {
  const dot = a.dot(b)
  const cross = a.cross(b)
  const angle = Math.atan2(cross.z, dot)
  return {
    angle: Math.abs(angle) * 180 / Math.PI,
    direction: angle >= 0 ? 'left' : 'right'
  }
}
```
