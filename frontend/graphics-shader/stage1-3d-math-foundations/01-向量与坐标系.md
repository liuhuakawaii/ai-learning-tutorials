# 第1课：向量与坐标系

## 场景引入

你在开发一个 3D 游戏，需要判断子弹是否击中敌人。子弹有飞行方向，敌人有位置，你需要计算两者之间的角度关系——如果角度太偏，子弹就打不中。这个问题的本质就是**向量的点积**。再比如，你需要让角色沿着地面斜坡滑动而不是穿透地面，这就需要用到**向量的投影和叉积**来计算法线方向。向量是 3D 图形的基石，掌握它是进入图形编程的第一步。

## 学习目标

1. 理解向量的几何意义和基本运算（加减、缩放、归一化）
2. 掌握点积的计算方法和几何含义（夹角、投影）
3. 掌握叉积的计算方法和几何含义（法线、面积、方向判定）
4. 理解左手坐标系与右手坐标系的区别及 OpenGL/WebGPU 的坐标系选择
5. 能够用 TypeScript 实现一个完整的 Vec3 类

## 一、向量的几何意义

向量（Vector）是既有大小又有方向的量。在 3D 空间中，一个向量可以用三个分量表示：

```
v = (x, y, z)
```

向量和点的区别：**点表示位置，向量表示方向和距离**。同一个坐标 `(3, 4, 0)` 作为点表示空间中的一个位置，作为向量表示"向右 3、向上 4"的方向和距离。

```
        y
        ↑
        |   · P(3,4)
        |  /
        | /  ← 向量 v = (3, 4, 0)
        |/
        +--------→ x
       /
      ↙
     z
```

## 二、向量的基本运算

### 向量加法

两个向量相加，对应分量相加，几何上就是"把两个箭头首尾相连"：

```
      b
     ↗
    /
   +-------→ a+b
   |
   ↓
   a

  a + b = (ax+bx, ay+by, az+bz)
```

### 向量减法

向量减法得到的是从 b 指向 a 的向量：

```
  b --------→ a
  ↑           |
  |   a - b   |
  +-----------+

  a - b = (ax-bx, ay-by, az-bz)
```

在游戏开发中，`目标位置 - 当前位置 = 方向向量`，这是最常见的用法。

### 标量乘法

向量乘以标量，方向不变（负数则反向），长度缩放：

```
  v      2v           -v
  →      →→           ←
```

### 向量长度

```
|v| = √(x² + y² + z²)
```

### 归一化（Normalization）

将向量缩放到长度为 1（单位向量），保留方向不变：

```
v̂ = v / |v|
```

归一化在图形编程中极其重要——法线、光照方向、视线方向几乎都要求是单位向量。

## 三、点积（Dot Product）

### 代数定义

```
a · b = ax*bx + ay*by + az*bz
```

### 几何定义

```
a · b = |a| * |b| * cos(θ)
```

其中 θ 是两个向量的夹角。

### 几何含义

点积的核心用途：**计算两个向量的夹角**。

```
        ↗ b
       / θ
      /
     → a

  cos(θ) = (a · b) / (|a| * |b|)

  当 a、b 都是单位向量时：
  cos(θ) = a · b
```

点积的符号告诉你两个向量的关系：

```
  a · b > 0  →  锐角（方向大致相同）
  a · b = 0  →  直角（正交）
  a · b < 0  →  钝角（方向大致相反）
```

### 投影

点积还表示**一个向量在另一个向量方向上的投影长度**：

```
          b
         ↗
        /
  -----+--------
       |← proj →|
  
  proj = |a| * cos(θ) = (a · b) / |b|
```

## 四、叉积（Cross Product）

### 代数定义

```
a × b = (
  ay*bz - az*by,
  az*bx - ax*bz,
  ax*by - ay*bx
)
```

### 几何含义

叉积的结果是一个**垂直于 a 和 b 所在平面的向量**，其长度等于 a 和 b 张成的平行四边形面积：

```
  |a × b| = |a| * |b| * sin(θ)
```

### 右手定则

叉积的方向由**右手定则**决定：

```
  右手四指从 a 弯向 b，拇指指向就是 a × b 的方向。

       a × b
        ↑  ↗ b
        | /
        |/
        +----→ a

  注意：a × b ≠ b × a
  a × b = -(b × a)
```

### 应用：计算三角形法线

```typescript
// 三角形三个顶点 p0, p1, p2
// 法线 = (p1-p0) × (p2-p0)
const edge1 = p1.sub(p0);
const edge2 = p2.sub(p0);
const normal = edge1.cross(edge2).normalize();
```

## 五、左手坐标系与右手坐标系

```
  右手坐标系 (OpenGL/WebGPU)    左手坐标系 (DirectX)
  
       y                           y
       ↑                           ↑
       |                           |
       |                           |
       +----→ x                    +----→ x
      /                           /
     ↙                           ↘
    z                             z
  (朝向屏幕外)                  (朝向屏幕内)
```

区分方法：用右手/左手，四指从 x 轴弯向 y 轴，拇指指向就是 z 轴方向。

**WebGPU 使用右手坐标系**，x 向右，y 向上，z 向屏幕外（朝向观察者）。

## 六、TypeScript Vec3 实现

```typescript
class Vec3 {
  constructor(
    public x: number = 0,
    public y: number = 0,
    public z: number = 0
  ) {}

  // 向量加法
  add(v: Vec3): Vec3 {
    return new Vec3(this.x + v.x, this.y + v.y, this.z + v.z);
  }

  // 向量减法
  sub(v: Vec3): Vec3 {
    return new Vec3(this.x - v.x, this.y - v.y, this.z - v.z);
  }

  // 标量乘法
  scale(s: number): Vec3 {
    return new Vec3(this.x * s, this.y * s, this.z * s);
  }

  // 向量长度
  length(): number {
    return Math.sqrt(this.x * this.x + this.y * this.y + this.z * this.z);
  }

  // 向量长度的平方（避免开方，用于比较距离）
  lengthSq(): number {
    return this.x * this.x + this.y * this.y + this.z * this.z;
  }

  // 归一化
  normalize(): Vec3 {
    const len = this.length();
    if (len < 1e-10) return new Vec3(0, 0, 0);
    return this.scale(1 / len);
  }

  // 点积
  dot(v: Vec3): number {
    return this.x * v.x + this.y * v.y + this.z * v.z;
  }

  // 叉积
  cross(v: Vec3): Vec3 {
    return new Vec3(
      this.y * v.z - this.z * v.y,
      this.z * v.x - this.x * v.z,
      this.x * v.y - this.y * v.x
    );
  }

  // 计算两个向量的夹角（弧度）
  angleTo(v: Vec3): number {
    const cosTheta = this.dot(v) / (this.length() * v.length());
    // clamp 防止浮点误差导致 NaN
    return Math.acos(Math.max(-1, Math.min(1, cosTheta)));
  }

  // 计算到另一个点的距离
  distanceTo(v: Vec3): number {
    return this.sub(v).length();
  }

  // 取反
  negate(): Vec3 {
    return new Vec3(-this.x, -this.y, -this.z);
  }

  // 线性插值
  lerp(v: Vec3, t: number): Vec3 {
    return new Vec3(
      this.x + (v.x - this.x) * t,
      this.y + (v.y - this.y) * t,
      this.z + (v.z - this.z) * t
    );
  }

  toString(): string {
    return `Vec3(${this.x.toFixed(3)}, ${this.y.toFixed(3)}, ${this.z.toFixed(3)})`;
  }
}
```

### 使用示例

```typescript
// 计算两个方向的夹角
const forward = new Vec3(0, 0, -1);
const toTarget = new Vec3(1, 0, -1).normalize();
const angle = forward.angleTo(toTarget);
console.log(`夹角: ${(angle * 180 / Math.PI).toFixed(1)}°`); // 45°

// 判断敌人是否在视野内（视野角度 60°）
const halfFov = 30 * Math.PI / 180;
const dot = forward.dot(toTarget);
const inView = dot > Math.cos(halfFov); // true

// 计算三角形法线
const p0 = new Vec3(0, 0, 0);
const p1 = new Vec3(1, 0, 0);
const p2 = new Vec3(0, 1, 0);
const normal = p1.sub(p0).cross(p2.sub(p0)).normalize();
console.log(`法线: ${normal}`); // Vec3(0.000, 0.000, 1.000)

// 反射向量（光线反弹）
const incident = new Vec3(1, -1, 0).normalize();
const n = new Vec3(0, 1, 0);
const reflected = incident.sub(n.scale(2 * incident.dot(n)));
console.log(`反射: ${reflected.normalize()}`);
```

## 常见误区

### 1. 混淆点和向量

点表示位置，向量表示方向。`点 - 点 = 向量`，`点 + 向量 = 点`，`点 + 点` 没有几何意义。在代码中可以用同一个类，但概念上要分清。

### 2. 忘记归一化就做点积判断

点积的几何含义 `a·b = |a||b|cos(θ)` 只有在两个向量都是单位向量时，`a·b` 才直接等于 `cos(θ)`。如果忘记归一化，点积结果会被长度影响，导致角度判断错误。

### 3. 混淆叉积的顺序

`a × b` 和 `b × a` 方向相反。在计算法线时，三角形顶点的绕序（winding order）决定了法线朝内还是朝外。WebGPU 默认逆时针为正面（front face）。

### 4. 用 `==` 判断向量相等

浮点数精度问题导致 `==` 判断几乎不可靠。应该用距离或分量差值判断：

```typescript
function vec3Equal(a: Vec3, b: Vec3, epsilon = 1e-6): boolean {
  return Math.abs(a.x - b.x) < epsilon &&
         Math.abs(a.y - b.y) < epsilon &&
         Math.abs(a.z - b.z) < epsilon;
}
```

## 工程建议

### 1. 优先使用 lengthSq() 做距离比较

比较两个点的距离时，不需要开方。`a.lengthSq() < b.lengthSq()` 比 `a.length() < b.length()` 快，因为省去了 `sqrt` 运算。

### 2. 归一化前检查零向量

零向量的长度为 0，归一化会产生除以零的 NaN。实现 normalize() 时一定要加长度检查，返回零向量或抛出明确错误。

### 3. 注意坐标系一致性

整个项目必须统一使用同一种坐标系。混用左手和右手坐标系会导致叉积方向错误、旋转方向反转等难以调试的问题。WebGPU 和 OpenGL 都是右手坐标系。

### 4. 缓存归一化结果

如果一个向量在多处使用且不会改变，提前归一化并缓存结果，避免每帧重复计算。比如角色的朝向向量，可以在改变时归一化一次，而不是每次使用时都调用 normalize()。

## 小结

本课建立了 3D 数学的基础：向量是描述方向和位置的核心工具，点积用于计算夹角和投影，叉积用于计算法线和判断方向。左手/右手坐标系的选择影响叉积方向，WebGPU 使用右手坐标系。Vec3 类是后续所有 3D 数学运算的基石。

## 参考答案

### 练习 1

**思路**：反射公式 `R = I - 2 * (I·N) * N` 的几何含义是：将入射向量沿法线方向"翻折"。点积 `I·N` 得到入射向量在法线方向上的投影长度，乘以 2 再乘以法线就是需要减去的分量。

**答案**：

```typescript
class Vec3 {
  // ... 已有方法 ...

  reflect(normal: Vec3): Vec3 {
    const dot2 = 2 * this.dot(normal);
    return new Vec3(
      this.x - dot2 * normal.x,
      this.y - dot2 * normal.y,
      this.z - dot2 * normal.z
    );
  }
}

// 测试
const incident = new Vec3(1, -1, 0).normalize();
const n = new Vec3(0, 1, 0);
const reflected = incident.reflect(n);
console.log(`入射: ${incident}`);   // Vec3(0.707, -0.707, 0.000)
console.log(`反射: ${reflected}`);  // Vec3(0.707, 0.707, 0.000)
// 验证：反射向量与法线的夹角应该等于入射向量与法线的夹角
console.log(`入射角: ${(incident.angleTo(n) * 180 / Math.PI).toFixed(1)}°`); // 45°
console.log(`反射角: ${(reflected.angleTo(n) * 180 / Math.PI).toFixed(1)}°`); // 45°
```

**要点**：
- 反射向量的长度与入射向量相同，只是方向改变
- 法线必须是单位向量，否则公式不成立
- 光照计算中反射向量用于镜面反射（specular），物理模拟中用于碰撞反弹

### 练习 2

**思路**：利用叉积判断点在三角形每条边的哪一侧。对于三角形 ABC，如果点 P 在内部，则从每条边的起点到终点再到 P 的转向应该一致（都是顺时针或都是逆时针）。叉积的 z 分量符号表示转向方向。

**答案**：

```typescript
function pointInTriangle(
  A: Vec3, B: Vec3, C: Vec3, P: Vec3
): boolean {
  // 计算三条边的叉积（只需要 z 分量）
  const cross1 = (B.x - A.x) * (P.y - A.y) - (B.y - A.y) * (P.x - A.x);
  const cross2 = (C.x - B.x) * (P.y - B.y) - (C.y - B.y) * (P.x - B.x);
  const cross3 = (A.x - C.x) * (P.y - C.y) - (A.y - C.y) * (P.x - C.x);

  // 三个叉积同号（都正或都负）则点在内部
  const hasPos = cross1 > 0 || cross2 > 0 || cross3 > 0;
  const hasNeg = cross1 < 0 || cross2 < 0 || cross3 < 0;
  return !(hasPos && hasNeg);
}

// 测试
const A = new Vec3(0, 0, 0);
const B = new Vec3(4, 0, 0);
const C = new Vec3(2, 4, 0);

console.log(pointInTriangle(A, B, C, new Vec3(2, 1, 0)));  // true（内部）
console.log(pointInTriangle(A, B, C, new Vec3(0, 3, 0)));  // false（外部）
console.log(pointInTriangle(A, B, C, new Vec3(2, 0, 0)));  // true（边上）
```

**要点**：
- 这是 2D 三角形测试，忽略了 z 分量。3D 三角形需要先将点投影到三角形所在平面
- 此方法是光栅化的核心算法——GPU 判断像素是否在三角形内用的就是类似逻辑
- 叉积为 0 表示点在边上，可根据需求决定算内部还是外部

### 练习 3

**思路**：用 `atan2(cross_z, dot)` 可以得到带符号的夹角（-π 到 π），比单独用 `acos` 更优，因为它天然包含了方向信息，且不存在 `acos` 在接近 0° 或 180° 时的精度问题。

**答案**：

```typescript
function signedAngle(a: Vec3, b: Vec3): { angle: number; direction: 'left' | 'right' } {
  const dot = a.dot(b);
  const cross = a.cross(b);
  // atan2 返回 -π 到 π 的带符号角度
  const angle = Math.atan2(cross.z, dot);

  return {
    angle: Math.abs(angle) * 180 / Math.PI,
    direction: angle >= 0 ? 'left' : 'right'
  };
}

// 测试
const forward = new Vec3(0, 0, -1);

const left45 = new Vec3(-1, 0, -1).normalize();
const result1 = signedAngle(forward, left45);
console.log(`角度: ${result1.angle.toFixed(1)}°, 方向: ${result1.direction}`);
// 角度: 45.0°, 方向: left

const right90 = new Vec3(1, 0, 0);
const result2 = signedAngle(forward, right90);
console.log(`角度: ${result2.angle.toFixed(1)}°, 方向: ${result2.direction}`);
// 角度: 90.0°, 方向: right

const backward = new Vec3(0, 0, 1);
const result3 = signedAngle(forward, backward);
console.log(`角度: ${result3.angle.toFixed(1)}°, 方向: ${result3.direction}`);
// 角度: 180.0°, 方向: left（叉积为零时 atan2 返回 0，归为 left）
```

**要点**：
- `atan2(cross_z, dot)` 比 `acos(dot)` 更鲁棒，因为不需要 clamp，且天然带符号
- 叉积 z 分量为正表示 b 在 a 的左侧（右手坐标系，逆时针方向）
- 当两向量平行时叉积为零向量，方向判断退化，需要特殊处理
