# Stage 1：3D 数学基础

3D 图形编程的底层是数学。本阶段从向量、矩阵、四元数到投影变换，系统性地建立你对 3D 空间的数学直觉。理解这些概念不是为了做题，而是为了在写 Shader 和调试渲染问题时，能准确判断"为什么画面不对"。

## 课时列表

| 序号 | 文件 | 主题 |
|------|------|------|
| 01 | 向量与坐标系.md | 向量运算、坐标系手性、点积叉积的几何意义 |
| 02 | 矩阵运算与变换.md | 平移/旋转/缩放矩阵、矩阵乘法顺序、组合变换 |
| 03 | 四元数与旋转.md | 欧拉角的万向节锁、四元数原理、Three.js 中的旋转 API |
| 04 | 投影与视图变换.md | 正交投影 vs 透视投影、LookAt 矩阵、MVP 流程 |
| 05 | 插值与曲线.md | 线性插值、贝塞尔曲线、Catmull-Rom、动画曲线设计 |
| 06 | 碰撞检测数学.md | AABB/球体/OBB 碰撞、射线检测、Three.js Raycaster |
| 07 | 数学在图形学中的综合应用.md | 法线变换、切线空间、TBN 矩阵，为 Stage 3 的 Shader 打基础 |

## 学习目标

- 掌握向量的点积、叉积及其在光照、投影中的应用
- 理解矩阵变换的组合顺序（先缩放→再旋转→最后平移）
- 理解四元数解决万向节锁的原理，能在 Three.js 中正确使用旋转
- 能手动推导 MVP（Model-View-Projection）变换流程
- 了解贝塞尔曲线与插值在动画中的应用
- 能实现基本的射线检测与碰撞判断

## 阶段交付物

- **数学可视化 Demo**：用 Three.js 绘制向量、矩阵变换的交互式可视化（可拖拽观察变换效果）
- **坐标系变换工具函数**：实现一套可在项目中复用的矩阵/四元数工具函数（TypeScript）
- **验证通过**：运行 `npm run check` 通过 Stage 1 的数学基础验证
