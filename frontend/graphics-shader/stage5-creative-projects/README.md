# Stage 5：创意项目实战

综合运用前四个阶段的知识，进入创意编码的世界。本阶段没有固定答案——每个项目都是开放式的，重点是培养"用代码表达视觉想法"的能力。你将产出可展示的创意 3D 作品，作为个人作品集的重要组成。

## 课时列表

| 序号 | 文件 | 主题 |
|------|------|------|
| 01 | 创意编码方法论与工具链.md | 创意编码的思维方式、工具链搭建、作品展示平台 |
| 02 | 交互式粒子艺术.md | 鼠标/触摸交互驱动的粒子系统，音频响应式视觉 |
| 03 | Generative Art：程序化生成艺术.md | L-System、元胞自动机、基于规则的视觉生成 |
| 04 | 沉浸式 3D 场景.md | 多材质/多光照/后处理组合的完整沉浸式场景 |
| 05 | 音乐可视化.md | Web Audio API + Three.js，音频频谱驱动 3D 视觉 |
| 06 | Shadertoy 风格 Shader 创作.md | 单文件 Shader 艺术、从零构建复杂视觉效果 |
| 07 | 数据驱动的 3D 可视化.md | 地理数据、关系图、时序数据的 3D 可视化方案 |
| 08 | AR/VR 创意原型.md | WebXR 基础、AR 场景搭建、VR 交互原型 |

## 学习目标

- 建立创意编码的思维方式：从想法→草图→代码→迭代的完整流程
- 能用粒子系统和交互事件实现视觉艺术作品
- 掌握程序化生成艺术的核心算法（L-System、元胞自动机等）
- 能构建包含完整材质、光照、后处理的沉浸式 3D 场景
- 实现音频驱动的 3D 可视化
- 能在 Shadertoy 风格下用纯 Shader 创作视觉艺术
- 了解 WebXR 的基本概念，能搭建简单的 AR/VR 原型

## 阶段交付物

- **创意作品集**：至少 3 个可交互的创意 3D 作品（粒子艺术、生成艺术、音乐可视化任选）
- **毕业项目**：一个完整的、可公开展示的 3D 创意应用，包含交互、动画和视觉特效
- **作品展示页**：基于 React Three Fiber 的个人作品展示页面
- **验证通过**：运行 `npm run check` 通过最终项目验证
