## 场景引入

传统 3D 资产制作流程漫长：建模师花数天雕刻网格，美术师手绘纹理贴图，技术美术反复调试 Shader 参数。如今 AI 正在重塑这条流水线——Stable Diffusion 能在秒级生成高质量纹理，NeRF 可以从几张照片重建完整 3D 场景，大语言模型甚至能直接编写 GLSL 代码。本课将探讨 AI 与 3D 图形的交叉领域，学习如何将 AI 生成的资产融入 Three.js 工作流。

### 生成无缝纹理

AI 生成的图片通常不是无缝的，需要后处理：

```typescript
function makeSeamlessTexture(imageData: ImageData): ImageData {
  const { width, height, data } = imageData
  const output = new Uint8ClampedArray(data.length)
  const blendZone = width / 4

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const idx = (y * width + x) * 4

      // 水平混合：左右边缘互相渗透
      let alphaX = 1.0
      if (x < blendZone) alphaX = x / blendZone
      if (x > width - blendZone) alphaX = (width - x) / blendZone

      // 垂直混合
      let alphaY = 1.0
      if (y < blendZone) alphaY = y / blendZone
      if (y > height - blendZone) alphaY = (height - y) / blendZone

      // 从偏移位置采样（半宽/半高偏移）
      const ox = (x + width / 2) % width
      const oy = (y + height / 2) % height
      const idxO = (oy * width + ox) * 4

      const alpha = Math.min(alphaX, alphaY)
      output[idx] = data[idx] * alpha + data[idxO] * (1 - alpha)
      output[idx + 1] = data[idx + 1] * alpha + data[idxO + 1] * (1 - alpha)
      output[idx + 2] = data[idx + 2] * alpha + data[idxO + 2] * (1 - alpha)
      output[idx + 3] = 255
    }
  }
  return new ImageData(output, width, height)
}
```

## NeRF 与 3D Gaussian Splatting

### NeRF 基本概念

```
NeRF (Neural Radiance Fields) 原理：

输入: 多视角照片 + 相机位姿
      │
      ▼
神经网络 F(x,y,z,θ,φ) → (r,g,b,σ)
      │                    │      │
      │                   颜色   密度
      │
      ▼
体渲染方程 → 合成新视角图像

关键特点:
  - 隐式表示（没有显式网格）
  - 连续场（任意分辨率采样）
  - 训练慢，推理也慢
```

### 3D Gaussian Splatting 基本概念

```
3DGS 与传统网格对比：

传统网格:               3D Gaussian Splatting:
  顶点 + 面              高斯椭球集合
  ┌───┐                  ●  ●
  │   │  三角面片         ● ● ●   每个椭球:
  └───┘                   ●  ●    - 位置 (x,y,z)
                          ● ●    - 协方差 (形状)
  光栅化渲染              ●  ●    - 颜色 (SH)
                          - 透明度 (α)
                         高斯溅射渲染

优势: 训练快（分钟级），实时渲染（100+fps）
劣势: 存储大，编辑困难
```

### AI 生成代码的验证流程

```typescript
class ShaderValidator {
  static validate(source: string, gl: WebGL2RenderingContext): {
    valid: boolean
    errors: string[]
  } {
    const errors: string[] = []

    // 检查语法
    if (!source.includes('void main()')) {
      errors.push('缺少 main 函数')
    }

    // 检查精度声明
    if (!source.includes('precision') && !source.includes('#version 300 es')) {
      errors.push('缺少精度声明')
    }

    // 编译测试
    const shader = gl.createShader(gl.FRAGMENT_SHADER)!
    gl.shaderSource(shader, source)
    gl.compileShader(shader)

    if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
      const log = gl.getShaderInfoLog(shader) || ''
      errors.push(`编译错误: ${log}`)
    }
    gl.deleteShader(shader)

    return { valid: errors.length === 0, errors }
  }
}
```

### AI 生成模型的后处理

AI 生成的网格通常有噪声面和非流形几何，需要后处理：

```typescript
import * as THREE from 'three'
import { SimplifyModifier } from 'three/addons/modifiers/SimplifyModifier.js'

function postProcessAIMesh(geometry: THREE.BufferGeometry): THREE.BufferGeometry {
  // 1. 移除退化三角形
  const index = geometry.getIndex()
  if (index) {
    const indices = index.array as Uint16Array
    const valid: number[] = []
    for (let i = 0; i < indices.length; i += 3) {
      const a = indices[i], b = indices[i + 1], c = indices[i + 2]
      if (a !== b && b !== c && a !== c) {
        valid.push(a, b, c)
      }
    }
    geometry.setIndex(valid)
  }

  // 2. 重新计算法线
  geometry.computeVertexNormals()

  // 3. 简化（如果面数过多）
  const faceCount = geometry.index
    ? geometry.index.count / 3
    : geometry.attributes.position.count / 3

  if (faceCount > 50000) {
    const modifier = new SimplifyModifier()
    const targetFaces = Math.floor(faceCount * 0.3)
    geometry = modifier.modify(geometry, targetFaces)
  }

  return geometry
}
```

## 程序化 + AI 混合工作流

```
混合工作流：

程序化生成              AI 生成                 融合
┌─────────┐          ┌─────────┐          ┌─────────┐
│基础几何体│          │纹理贴图 │          │最终资产 │
│UV 展开  │──────+──▶│法线贴图 │──────▶  │完整渲染 │
│LOD 层级 │          │环境光照 │          │         │
└─────────┘          └─────────┘          └─────────┘
     │                     │
     │  确定性、可参数化    │  高质量、多样化
     │  快速迭代            │  需要人工审核
```

```typescript
class HybridAssetPipeline {
  // 程序化生成基础网格
  generateBaseGeometry(params: {
    type: 'box' | 'sphere' | 'cylinder'
    segments: number
    deformNoise: number
  }): THREE.BufferGeometry {
    let geo: THREE.BufferGeometry
    switch (params.type) {
      case 'box': geo = new THREE.BoxGeometry(1, 1, 1, params.segments); break
      case 'sphere': geo = new THREE.SphereGeometry(1, params.segments, params.segments); break
      case 'cylinder': geo = new THREE.CylinderGeometry(0.5, 0.5, 1, params.segments); break
    }

    if (params.deformNoise > 0) {
      this.applyNoiseDeformation(geo, params.deformNoise)
    }
    geo.computeVertexNormals()
    return geo
  }

  private applyNoiseDeformation(geo: THREE.BufferGeometry, amount: number) {
    const pos = geo.attributes.position
    for (let i = 0; i < pos.count; i++) {
      const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i)
      const noise = (Math.sin(x * 3) * Math.cos(y * 3) * Math.sin(z * 3)) * amount
      pos.setXYZ(i, x + noise * 0.1, y + noise * 0.1, z + noise * 0.1)
    }
  }

  // 加载 AI 生成的纹理
  async loadAITexture(prompt: string): Promise<THREE.Texture> {
    const response = await fetch('/api/generate-texture', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ prompt, size: 1024 }),
    })
    const blob = await response.blob()
    const url = URL.createObjectURL(blob)
    return new THREE.TextureLoader().loadAsync(url)
  }

  // 组合程序化几何 + AI 纹理
  async createAsset(params: {
    geometry: { type: string; segments: number; deform: number }
    texturePrompt: string
  }): Promise<THREE.Mesh> {
    const geometry = this.generateBaseGeometry({
      type: params.geometry.type as any,
      segments: params.geometry.segments,
      deformNoise: params.geometry.deform,
    })

    const [diffuseMap, normalMap] = await Promise.all([
      this.loadAITexture(params.texturePrompt),
      this.loadAITexture(params.texturePrompt + ', normal map, blue-purple tones'),
    ])

    const material = new THREE.MeshStandardMaterial({
      map: diffuseMap,
      normalMap: normalMap,
      roughness: 0.5,
      metalness: 0.2,
    })

    return new THREE.Mesh(geometry, material)
  }
}
```

## Three.js 中加载 AI 生成资产

```typescript
class AIAssetLoader {
  private gltfLoader = new GLTFLoader()
  private textureLoader = new THREE.TextureLoader()
  private cache = new Map<string, THREE.Object3D>()

  async loadGLB(url: string): Promise<THREE.Group> {
    if (this.cache.has(url)) {
      return this.cache.get(url)!.clone() as THREE.Group
    }
    const gltf = await this.gltfLoader.loadAsync(url)
    const model = gltf.scene

    model.traverse(child => {
      if (child instanceof THREE.Mesh) {
        child.castShadow = true
        child.receiveShadow = true
      }
    })

    this.cache.set(url, model.clone())
    return model
  }

  async loadTexture(url: string, options?: {
    seamless?: boolean
    normalStrength?: number
  }): Promise<THREE.Texture> {
    const texture = await this.textureLoader.loadAsync(url)
    texture.wrapS = texture.wrapT = THREE.RepeatWrapping

    if (options?.seamless) {
      texture.repeat.set(2, 2)
    }
    return texture
  }
}

## 常见误区

1. **盲目信任 AI 生成的 Shader 代码**：LLM 生成的 GLSL 代码可能包含语法正确但语义错误的数学表达式，或者使用了不兼容当前 WebGL 版本的特性。必须经过编译验证和视觉检查。

2. **忽略 AI 纹理的 UV 适配问题**：AI 生成的纹理是平面图片，直接应用到 3D 模型上会因 UV 展开方式不同而产生拉伸。应该先用目标模型的 UV 布局作为 ControlNet 的引导图。

3. **将 NeRF/3DGS 当作通用建模工具**：这些技术擅长重建真实场景，但不擅长生成虚构内容，且输出的表示形式（隐式场/点云）与传统网格管线不兼容，后处理成本高。

4. **过度依赖 AI 生成而忽略艺术指导**：AI 生成的内容缺乏一致性和叙事性。应该将 AI 作为加速工具，而非替代美术总监的角色——最终的视觉决策权应留在人类手中。

## 工程建议

1. **建立 AI 资产的版本管理**：AI 生成的资产具有随机性，同一 Prompt 每次输出不同。应记录 Prompt、种子、模型版本等元数据，确保可复现。

2. **实现纹理生成的异步队列**：批量生成 AI 纹理时，用队列管理请求，避免 API 限流；同时用占位纹理（纯色或低分辨率）先渲染场景，AI 纹理生成完毕后热替换。

3. **为 AI 生成内容添加水印**：在开发流程中，为 AI 生成的纹理添加隐形水印或元数据标记，便于后续的版权追溯和资产管理。

4. **混合精度策略**：AI 生成的高分辨率纹理（2K/4K）在移动端会爆内存，应生成多个分辨率版本，根据设备能力动态加载。

## 小结

本课探讨了 AI 与 3D 图形的交叉领域。Stable Diffusion 可以快速生成纹理贴图，但需要后处理实现无缝拼接；NeRF 和 3DGS 能从照片重建 3D 场景，但在 Web 端的实时渲染仍有挑战；LLM 可以辅助编写 Shader 代码，但必须经过严格验证。最实用的模式是程序化 + AI 混合工作流：用程序化方法控制结构和参数，用 AI 生成高多样性的视觉细节。

    method: 'POST',
    headers: { 'Content-Type': 'application/json' },

  const texture = new THREE.Texture(img)
  texture.wrapS = THREE.RepeatWrapping
  texture.wrapT = THREE.RepeatWrapping

### 练习二

**思路**：文本描述到 Shader 代码的管线是一个"生成→验证→反馈"的闭环。LLM 根据用户描述生成 fragment shader 源码，ShaderValidator 通过创建 WebGL 上下文尝试编译，失败时将 GL 错误信息拼入 Prompt 反馈给 LLM 重新生成，最多重试 N 次。

**答案**：

```typescript
import * as THREE from 'three'

interface LLMResponse {
  choices: Array<{ message: { content: string } }>
}

function extractGLSL(text: string): string | null {
  const match = text.match(/```glsl\s*([\s\S]*?)```/) || text.match(/```(?:c|cpp)?\s*([\s\S]*?)```/)
  return match ? match[1].trim() : null
}

function validateShader(source: string, type: 'vertex' | 'fragment'): { valid: boolean; error: string } {
  const canvas = document.createElement('canvas')
  const gl = canvas.getContext('webgl2') || canvas.getContext('webgl')
  if (!gl) return { valid: false, error: '无法创建 WebGL 上下文' }

  const shader = gl.createShader(type === 'vertex' ? gl.VERTEX_SHADER : gl.FRAGMENT_SHADER)!
  gl.shaderSource(shader, source)
  gl.compileShader(shader)

  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const error = gl.getShaderInfoLog(shader) || '未知错误'
    gl.deleteShader(shader)
    return { valid: false, error }
  }
  gl.deleteShader(shader)
  return { valid: true, error: '' }
}

async function callLLM(messages: Array<{ role: string; content: string }>, apiKey: string): Promise<string> {
  const response = await fetch('https://api.openai.com/v1/chat/completions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${apiKey}` },
    body: JSON.stringify({
      model: 'gpt-4o',
      messages,
      temperature: 0.3
    })
  })
  const data: LLMResponse = await response.json()
  return data.choices[0].message.content
}

async function generateShader(userDescription: string, apiKey: string, maxRetries = 3): Promise<string> {
  const systemPrompt = `你是一个 GLSL Shader 专家。用户会描述一个视觉效果，你需要生成完整的 fragment shader 代码。
要求：
1. 只输出 fragment shader，不要 vertex shader
2. 使用 WebGL 1 兼容语法（precision mediump float）
3. 必须声明 uniform 变量：uniform float u_time; uniform vec2 u_resolution; uniform vec2 u_mouse;
4. 输出用 \`\`\`glsl 代码块包裹
5. 最终颜色赋值给 gl_FragColor`

  const messages: Array<{ role: string; content: string }> = [
    { role: 'system', content: systemPrompt },
    { role: 'user', content: userDescription }
  ]

  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    const llmOutput = await callLLM(messages, apiKey)
    const shaderCode = extractGLSL(llmOutput)

    if (!shaderCode) {
      messages.push({ role: 'assistant', content: llmOutput })
      messages.push({ role: 'user', content: '你没有输出有效的 GLSL 代码块。请重新生成，使用 ```glsl 包裹。' })
      continue
    }

    const validation = validateShader(shaderCode, 'fragment')
    if (validation.valid) {
      console.log(`第 ${attempt + 1} 次尝试成功`)
      return shaderCode
    }

    console.warn(`第 ${attempt + 1} 次编译失败: ${validation.error}`)
    messages.push({ role: 'assistant', content: llmOutput })
    messages.push({ role: 'user', content: `Shader 编译失败，错误信息：\n${validation.error}\n请修复这些错误并重新生成完整的 fragment shader。` })
  }

  throw new Error(`经过 ${maxRetries + 1} 次尝试仍无法生成有效 Shader`)
}

async function generateTextureFromAPI(prompt: string, apiBase: string): Promise<THREE.Texture> {

  return tex
}

function createFallbackTexture(color: number): THREE.Texture {

  return new THREE.CanvasTexture(canvas)
}

### 练习四

**思路**：3D Gaussian Splatting（3DGS）是一种新兴的场景表示方法，用数万个高斯椭球体代替传统三角网格。加载 3DGS 模型需要解析 .ply 文件中的高斯参数（位置、协方差、颜色、不透明度），然后用自定义 Shader 渲染。对比传统网格需要在相同场景下测量帧率和内存占用。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const gsVertexShader = `
attribute vec3 a_position;
attribute vec4 a_rotation;
attribute vec3 a_scale;
attribute vec4 a_color;

uniform mat4 u_viewMatrix;
uniform mat4 u_projectionMatrix;

varying vec4 v_color;
varying vec2 v_uv;

mat3 quatToMat3(vec4 q) {
  float x = q.x, y = q.y, z = q.z, w = q.w;
  return mat3(
    1.0 - 2.0*(y*y + z*z), 2.0*(x*y - w*z), 2.0*(x*z + w*y),
    2.0*(x*y + w*z), 1.0 - 2.0*(x*x + z*z), 2.0*(y*z - w*x),
    2.0*(x*z - w*y), 2.0*(y*z + w*x), 1.0 - 2.0*(x*x + y*y)
  );
}

void main() {
  mat3 rot = quatToMat3(a_rotation);
  mat3 S = mat3(a_scale.x, 0.0, 0.0, 0.0, a_scale.y, 0.0, 0.0, 0.0, a_scale.z);
  mat3 M = rot * S;

  vec4 viewPos = u_viewMatrix * vec4(a_position, 1.0);
  vec3 quadPos = M * vec3(0.0, 0.0, 0.0);

  vec4 projPos = u_projectionMatrix * viewPos;
  gl_Position = projPos;
  gl_PointSize = max(2.0, 300.0 / projPos.w);

  float SH_C0 = 0.28209479177387814;
  v_color = vec4(0.5 + SH_C0 * a_color.rgb, a_color.a);
}
`

const gsFragmentShader = `
varying vec4 v_color;
void main() {
  vec2 d = gl_PointCoord - 0.5;
  float r2 = dot(d, d);
  if (r2 > 0.25) discard;
  float alpha = v_color.a * exp(-4.0 * r2);
  gl_FragColor = vec4(v_color.rgb, alpha);
}
`

interface GaussianData {
  count: number
  positions: Float32Array
  rotations: Float32Array
  scales: Float32Array
  colors: Float32Array
}

function parsePlyBuffer(buffer: ArrayBuffer): GaussianData {
  const text = new TextDecoder().decode(buffer)
  const headerEnd = text.indexOf('end_header\n') + 'end_header\n'.length
  const header = text.substring(0, headerEnd)
  const countMatch = header.match(/element vertex (\d+)/)
  const count = countMatch ? parseInt(countMatch[1]) : 0

  const positions = new Float32Array(count * 3)
  const rotations = new Float32Array(count * 4)
  const scales = new Float32Array(count * 3)
  const colors = new Float32Array(count * 4)

  const lines = text.substring(headerEnd).trim().split('\n')
  for (let i = 0; i < Math.min(count, lines.length); i++) {
    const vals = lines[i].split(' ').map(Number)
    positions[i * 3] = vals[0]; positions[i * 3 + 1] = vals[1]; positions[i * 3 + 2] = vals[2]
    rotations[i * 4] = vals[6]; rotations[i * 4 + 1] = vals[7]
    rotations[i * 4 + 2] = vals[8]; rotations[i * 4 + 3] = vals[9]
    scales[i * 3] = Math.exp(vals[10]); scales[i * 3 + 1] = Math.exp(vals[11]); scales[i * 3 + 2] = Math.exp(vals[12])
    colors[i * 4] = vals[3] / 255; colors[i * 4 + 1] = vals[4] / 255
    colors[i * 4 + 2] = vals[5] / 255; colors[i * 4 + 3] = 1.0
  }

  return { count, positions, rotations, scales, colors }
}

async function loadGaussianSplat(plyUrl: string, scene: THREE.Scene): Promise<THREE.Points> {
  const response = await fetch(plyUrl)
  const buffer = await response.arrayBuffer()
  const data = parsePlyBuffer(buffer)

  const geo = new THREE.BufferGeometry()
  geo.setAttribute('a_position', new THREE.BufferAttribute(data.positions, 3))
  geo.setAttribute('a_rotation', new THREE.BufferAttribute(data.rotations, 4))
  geo.setAttribute('a_scale', new THREE.BufferAttribute(data.scales, 3))
  geo.setAttribute('a_color', new THREE.BufferAttribute(data.colors, 4))

  const mat = new THREE.ShaderMaterial({
    vertexShader: gsVertexShader, fragmentShader: gsFragmentShader,
    transparent: true, depthWrite: false, blending: THREE.NormalBlending
  })

  const points = new THREE.Points(geo, mat)
  scene.add(points)
  return points
}
