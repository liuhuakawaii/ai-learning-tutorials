# 3D 应用架构

## 场景引入

当你的 Three.js 项目从一个演示 Demo 演变为包含数百个对象、多种交互、复杂状态管理的真实应用时，面条式的代码会让维护变成噩梦——修改一个功能会意外破坏另一个，添加新特性需要在几十个文件中寻找耦合点。本课将学习如何用 ECS（Entity-Component-System）模式、资源管理器、场景图、事件系统等架构模式构建可扩展、可维护的 3D 应用。

## 学习目标

1. 理解 ECS（Entity-Component-System）模式并实现一个简易 ECS
2. 设计资源管理器（加载、缓存、释放）
3. 掌握场景图（Scene Graph）的组织与遍历
4. 实现解耦的事件系统
5. 学习 3D 应用的状态管理策略
6. 掌握 Three.js 应用架构的最佳实践

## ECS 模式：Entity-Component-System

### 核心概念

```
传统 OOP 方式（继承链深、耦合重）：

GameObject
  ├── Character
  │     ├── Player
  │     │     └── MagicPlayer
  │     └── Enemy
  └── Item
        ├── Weapon
        └── Potion

ECS 方式（组合优于继承）：

Entity: 只是一个 ID

Component: 纯数据
  Position { x, y, z }
  Velocity { x, y, z }
  Health { current, max }
  Renderable { mesh }
  Collider { shape, size }
  PlayerControlled { }

System: 纯逻辑
  MovementSystem      → 处理 Position + Velocity
  RenderSystem        → 处理 Position + Renderable
  CollisionSystem     → 处理 Position + Collider
  HealthSystem        → 处理 Health
  InputSystem         → 处理 PlayerControlled + Velocity
```

### 简易 ECS 实现

```typescript
// Entity: 就是一个数字 ID
type Entity = number

// Component: 纯数据接口
interface Position { x: number; y: number; z: number }
interface Velocity { x: number; y: number; z: number }
interface Renderable { mesh: THREE.Mesh }
interface Health { current: number; max: number }
interface PlayerControlled { speed: number }

// Component 存储：Map<Entity, Component>
class ComponentStore<T> {
  private store = new Map<Entity, T>()

  add(entity: Entity, component: T): void {
    this.store.set(entity, component)
  }

  get(entity: Entity): T | undefined {
    return this.store.get(entity)
  }

  has(entity: Entity): boolean {
    return this.store.has(entity)
  }

  remove(entity: Entity): void {
    this.store.delete(entity)
  }

  entities(): Entity[] {
    return [...this.store.keys()]
  }
}

// World: 管理所有实体和组件
class World {
  private nextEntityId = 0
  private components = new Map<string, ComponentStore<any>>()
  private systems: System[] = []

  createEntity(): Entity {
    return this.nextEntityId++
  }

  registerComponent<T>(name: string): ComponentStore<T> {
    const store = new ComponentStore<T>()
    this.components.set(name, store)
    return store
  }

  getStore<T>(name: string): ComponentStore<T> {
    return this.components.get(name) as ComponentStore<T>
  }

  addSystem(system: System): void {
    this.systems.push(system)
  }

  update(dt: number): void {
    for (const system of this.systems) {
      system.update(this, dt)
    }
  }
}

// System: 处理特定组件组合的逻辑
interface System {
  update(world: World, dt: number): void
}

// 示例系统实现
class MovementSystem implements System {
  update(world: World, dt: number): void {
    const positions = world.getStore<Position>('position')
    const velocities = world.getStore<Velocity>('velocity')

    for (const entity of velocities.entities()) {
      const pos = positions.get(entity)
      const vel = velocities.get(entity)
      if (!pos || !vel) continue

      pos.x += vel.x * dt
      pos.y += vel.y * dt
      pos.z += vel.z * dt
    }
  }
}

class RenderSystem implements System {
  update(world: World, dt: number): void {
    const positions = world.getStore<Position>('position')
    const renderables = world.getStore<Renderable>('renderable')

    for (const entity of renderables.entities()) {
      const pos = positions.get(entity)
      const render = renderables.get(entity)
      if (!pos || !render) continue

      render.mesh.position.set(pos.x, pos.y, pos.z)
    }
  }
}
```

### 使用 ECS 构建场景

```typescript
function createGameScene(scene: THREE.Scene): World {
  const world = new World()

  // 注册组件
  const positions = world.registerComponent<Position>('position')
  const velocities = world.registerComponent<Velocity>('velocity')
  const renderables = world.registerComponent<Renderable>('renderable')
  const health = world.registerComponent<Health>('health')
  const playerCtrl = world.registerComponent<PlayerControlled>('playerControl')

  // 注册系统
  world.addSystem(new MovementSystem())
  world.addSystem(new RenderSystem())
  world.addSystem(new CollisionSystem())

  // 创建玩家实体
  const player = world.createEntity()
  positions.add(player, { x: 0, y: 1, z: 0 })
  velocities.add(player, { x: 0, y: 0, z: 0 })
  const playerMesh = new THREE.Mesh(
    new THREE.CapsuleGeometry(0.3, 1, 8, 16),
    new THREE.MeshStandardMaterial({ color: 0x00aaff })
  )
  scene.add(playerMesh)
  renderables.add(player, { mesh: playerMesh })
  health.add(player, { current: 100, max: 100 })
  playerCtrl.add(player, { speed: 5 })

  // 创建敌人实体
  for (let i = 0; i < 10; i++) {
    const enemy = world.createEntity()
    positions.add(enemy, {
      x: (Math.random() - 0.5) * 20,
      y: 1,
      z: (Math.random() - 0.5) * 20,
    })
    velocities.add(enemy, { x: 0, y: 0, z: 0 })
    const enemyMesh = new THREE.Mesh(
      new THREE.CapsuleGeometry(0.3, 1, 8, 16),
      new THREE.MeshStandardMaterial({ color: 0xff4444 })
    )
    scene.add(enemyMesh)
    renderables.add(enemy, { mesh: enemyMesh })
    health.add(enemy, { current: 50, max: 50 })
  }

  return world
}
```

## 资源管理器

### 设计目标

```
资源管理器职责：

加载层              缓存层              释放层
┌─────────┐       ┌─────────┐       ┌─────────┐
│ 加载队列  │       │ 引用计数  │       │ LRU 淘汰 │
│ 进度追踪  │──────▶│ 按 URL   │──────▶│ 延迟释放 │
│ 错误重试  │       │ 去重     │       │ 显式清理 │
└─────────┘       └─────────┘       └─────────┘
```

```typescript
interface Resource {
  data: any
  refCount: number
  lastUsed: number
  size: number
}

class ResourceManager {
  private cache = new Map<string, Resource>()
  private loaders = new Map<string, (url: string) => Promise<any>>()
  private loadingPromises = new Map<string, Promise<any>>()
  private totalMemory = 0
  private memoryBudget: number

  constructor(memoryBudgetMB: number = 512) {
    this.memoryBudget = memoryBudgetMB * 1024 * 1024
    this.registerDefaults()
  }

  private registerDefaults(): void {
    this.registerLoader('texture', async (url: string) => {
      return new THREE.TextureLoader().loadAsync(url)
    })
    this.registerLoader('gltf', async (url: string) => {
      const loader = new GLTFLoader()
      return loader.loadAsync(url)
    })
    this.registerLoader('audio', async (url: string) => {
      return new AudioContext().decodeAudioData(
        await (await fetch(url)).arrayBuffer()
      )
    })
  }

  registerLoader(type: string, loader: (url: string) => Promise<any>): void {
    this.loaders.set(type, loader)
  }

  async load<T>(type: string, url: string): Promise<T> {
    const key = `${type}:${url}`

    // 命中缓存
    const cached = this.cache.get(key)
    if (cached) {
      cached.refCount++
      cached.lastUsed = Date.now()
      return cached.data as T
    }

    // 正在加载中（去重）
    if (this.loadingPromises.has(key)) {
      return this.loadingPromises.get(key) as Promise<T>
    }

    // 发起加载
    const loader = this.loaders.get(type)
    if (!loader) throw new Error(`Unknown resource type: ${type}`)

    const promise = loader(url).then(data => {
      this.cache.set(key, {
        data,
        refCount: 1,
        lastUsed: Date.now(),
        size: this.estimateSize(data),
      })
      this.totalMemory += this.estimateSize(data)
      this.loadingPromises.delete(key)
      return data as T
    })

    this.loadingPromises.set(key, promise)
    return promise
  }

  release(type: string, url: string): void {
    const key = `${type}:${url}`
    const resource = this.cache.get(key)
    if (!resource) return

    resource.refCount--
    if (resource.refCount <= 0) {
      this.disposeResource(resource)
      this.cache.delete(key)
      this.totalMemory -= resource.size
    }
  }

  private disposeResource(resource: Resource): void {
    const data = resource.data
    if (data instanceof THREE.Texture) data.dispose()
    else if (data instanceof THREE.BufferGeometry) data.dispose()
    else if (data instanceof THREE.Material) data.dispose()
    else if (data.scene) {
      data.scene.traverse((child: any) => {
        if (child.geometry) child.geometry.dispose()
        if (child.material) {
          (Array.isArray(child.material) ? child.material : [child.material])
            .forEach((m: THREE.Material) => m.dispose())
        }
      })
    }
  }

  private estimateSize(data: any): number {
    if (data instanceof THREE.Texture) {
      const img = data.image
      return (img?.width || 512) * (img?.height || 512) * 4
    }
    if (data instanceof THREE.BufferGeometry) {
      let size = 0
      for (const name of Object.keys(data.attributes)) {
        const attr = data.attributes[name] as THREE.BufferAttribute
        size += attr.array.byteLength
      }
      return size
    }
    return 0
  }
}
```

```typescript
class SceneGraphManager {
  private scene: THREE.Scene
  private nodes = new Map<string, THREE.Object3D>()
  private groups = new Map<string, THREE.Group>()

  constructor(scene: THREE.Scene) {
    this.scene = scene
    this.createDefaultGroups()
  }

  private createDefaultGroups(): void {
    const groups = ['environment', 'entities', 'ui', 'effects']
    groups.forEach(name => {
      const group = new THREE.Group()
      group.name = name
      this.scene.add(group)
      this.groups.set(name, group)
    })
  }

  addNode(name: string, object: THREE.Object3D, parent?: string): void {
    const parentNode = parent
      ? this.groups.get(parent) || this.nodes.get(parent) || this.scene
      : this.scene
    parentNode.add(object)
    this.nodes.set(name, object)
  }

  getNode(name: string): THREE.Object3D | undefined {
    return this.nodes.get(name)
  }

  removeNode(name: string): void {
    const node = this.nodes.get(name)
    if (node) {
      node.parent?.remove(node)
      this.nodes.delete(name)
    }
  }

  traverse(callback: (node: THREE.Object3D, depth: number) => void): void {
    const visit = (node: THREE.Object3D, depth: number) => {
      callback(node, depth)
      node.children.forEach(child => visit(child, depth + 1))
    }
    this.scene.children.forEach(child => visit(child, 0))
  }
}
```

## 事件系统

```typescript
type EventHandler = (...args: any[]) => void

class EventEmitter {
  private listeners = new Map<string, Set<EventHandler>>()

  on(event: string, handler: EventHandler): () => void {
    if (!this.listeners.has(event)) {
      this.listeners.set(event, new Set())
    }
    this.listeners.get(event)!.add(handler)
    return () => this.off(event, handler)
  }

  off(event: string, handler: EventHandler): void {
    this.listeners.get(event)?.delete(handler)
  }

  emit(event: string, ...args: any[]): void {
    this.listeners.get(event)?.forEach(handler => handler(...args))
  }

  once(event: string, handler: EventHandler): void {
    const wrapper = (...args: any[]) => {
      handler(...args)
      this.off(event, wrapper)
    }
    this.on(event, wrapper)
  }
}

// 3D 应用事件总线
class AppEventBus extends EventEmitter {
  // 类型安全的事件定义
  static readonly EVENTS = {
    ENTITY_SELECTED: 'entity:selected',
    ENTITY_DESTROYED: 'entity:destroyed',
    SCENE_LOADED: 'scene:loaded',
    CAMERA_CHANGED: 'camera:changed',
    RESIZE: 'app:resize',
    QUALITY_CHANGED: 'quality:changed',
  } as const
}

// 使用示例
const events = new AppEventBus()

events.on(AppEventBus.EVENTS.ENTITY_SELECTED, (entity: Entity) => {
  highlightEntity(entity)
  showInspector(entity)
})

events.on(AppEventBus.EVENTS.RESIZE, (width: number, height: number) => {
  camera.aspect = width / height
  camera.updateProjectionMatrix()
  renderer.setSize(width, height)
})
```

## 状态管理

```typescript
// 3D 应用全局状态
interface AppState {
  camera: {
    position: THREE.Vector3
    target: THREE.Vector3
    fov: number
  }
  scene: {
    entities: Map<Entity, ComponentSnapshot>
    selectedEntity: Entity | null
  }
  rendering: {
    quality: 'low' | 'medium' | 'high'
    shadowsEnabled: boolean
    postProcessing: boolean
  }
  ui: {
    showInspector: boolean
    showPerformance: boolean
  }
}

class StateManager {
  private state: AppState
  private subscribers = new Set<(state: AppState) => void>()

  constructor(initialState: AppState) {
    this.state = structuredClone(initialState) as any
  }

  get(): AppState {
    return this.state
  }

  update(partial: Partial<AppState>): void {
    Object.assign(this.state, partial)
    this.subscribers.forEach(fn => fn(this.state))
  }

  subscribe(fn: (state: AppState) => void): () => void {
    this.subscribers.add(fn)
    return () => this.subscribers.delete(fn)
  }
}
```

## 可扩展架构设计

### 应用生命周期

```
应用启动流程：

init()            load()           start()          loop()
  │                 │                │                │
  ├─ 创建 Renderer  ├─ 加载资源      ├─ 注册事件       ├─ input.update()
  ├─ 创建 Scene     ├─ 解析数据      ├─ 启动系统       ├─ world.update()
  ├─ 创建 Camera    ├─ 构建场景      ├─ 开始渲染       ├─ render()
  └─ 创建 World     └─ 预热 GPU      └─ 播放音乐       └─ requestAnimationFrame
```

```typescript
class Application {
  readonly renderer: THREE.WebGLRenderer
  readonly scene: THREE.Scene
  readonly camera: THREE.PerspectiveCamera
  readonly world: World
  readonly resources: ResourceManager
  readonly events: AppEventBus
  readonly state: StateManager
  private clock = new THREE.Clock()
  private isRunning = false

  constructor(container: HTMLElement) {
    this.renderer = new THREE.WebGLRenderer({ antialias: true })
    this.scene = new THREE.Scene()
    this.camera = new THREE.PerspectiveCamera(60, 1, 0.1, 1000)
    this.world = new World()
    this.resources = new ResourceManager(512)
    this.events = new AppEventBus()
    this.state = new StateManager(this.defaultState())

    container.appendChild(this.renderer.domElement)
    this.setupResize()
  }

  private defaultState(): AppState {
    return {
      camera: { position: new THREE.Vector3(0, 5, 10), target: new THREE.Vector3(), fov: 60 },
      scene: { entities: new Map(), selectedEntity: null },
      rendering: { quality: 'high', shadowsEnabled: true, postProcessing: true },
      ui: { showInspector: false, showPerformance: false },
    }
  }

  private setupResize(): void {
    const ro = new ResizeObserver(entries => {
      const { width, height } = entries[0].contentRect
      this.camera.aspect = width / height
      this.camera.updateProjectionMatrix()
      this.renderer.setSize(width, height)
      this.events.emit(AppEventBus.EVENTS.RESIZE, width, height)
    })
    ro.observe(this.renderer.domElement.parentElement!)
  }

  start(): void {
    this.isRunning = true
    this.clock.start()
    this.animate()
  }

  stop(): void {
    this.isRunning = false
  }

  private animate = (): void => {
    if (!this.isRunning) return
    requestAnimationFrame(this.animate)
    const dt = this.clock.getDelta()
    this.world.update(dt)
    this.renderer.render(this.scene, this.camera)
  }

  dispose(): void {
    this.stop()
    this.resources.disposeScene(this.scene)
    this.renderer.dispose()
  }
}
```

## 常见误区

1. **在 System 中直接操作 Three.js 对象**：System 应该只修改组件数据，由专门的 RenderSystem 将组件数据同步到 Three.js 对象。这样可以在不渲染的场景下（如服务端）复用 System 逻辑。

2. **过度使用全局事件总线**：事件系统方便解耦，但滥用会导致数据流难以追踪（"谁在监听这个事件？""这个事件什么时候触发？"）。对于有明确调用关系的模块，直接方法调用更清晰。

3. **资源加载没有错误处理和重试**：网络请求随时可能失败，资源加载器必须有超时、重试和降级策略。一个纹理加载失败不应该导致整个应用崩溃。

4. **将所有状态放在一个大对象中**：全局状态应该按职责拆分——渲染状态（质量、后处理）、场景状态（实体、选中对象）、UI 状态（面板开关），各模块只订阅自己关心的部分。

## 工程建议

1. **从 ECS 的轻量版开始**：完整的 ECS 框架对中小项目是过度设计。可以从"组件存储 + 系统列表"的轻量版开始，项目复杂度增长时再逐步引入查询优化、序列化、序列化等功能。

2. **资源清单（Asset Manifest）先行**：在应用启动前定义好所有需要加载的资源清单，支持分阶段加载——先加载必要资源启动场景，再后台加载次要资源。

3. **用 TypeScript 的类型系统约束组件**：利用 TypeScript 的接口和泛型，确保 System 只能访问它声明依赖的组件，编译期捕获拼写错误和类型不匹配。

4. **分离更新逻辑和渲染逻辑**：游戏/模拟的更新频率可以与渲染频率不同——物理可以 30Hz 更新，渲染 60fps，UI 事件驱动。用固定时间步长的 `update(dt)` 和可变的 `render(alpha)` 分离。

## 小结

本课学习了 3D 应用的架构设计模式。ECS 模式通过"组合优于继承"的理念，将数据（Component）和逻辑（System）彻底分离，使系统可独立测试和复用。资源管理器解决了加载、缓存、释放的全生命周期管理。场景图提供了层级化的空间组织。事件系统实现了模块间的松耦合通信。这些模式组合在一起，可以支撑从小型交互 Demo 到大型 3D 应用的可扩展架构。

## 参考答案

### 练习一

**思路**：ECS 框架的核心是三个概念：Entity（只是一个 ID）、Component（纯数据对象，按类型存储在 Map 中）、System（处理逻辑，查询拥有特定组件组合的实体并执行更新）。实现时用 `World` 类统一管理实体的创建/销毁和组件的注册/查询。

**答案**：

```typescript
type Entity = number

interface ComponentClass<T = any> {
  new (...args: any[]): T
  name: string
}

class World {
  private nextEntityId = 0
  private entities = new Set<Entity>()
  private components = new Map<string, Map<Entity, any>>()
  private systems: System[] = []

  createEntity(): Entity {
    const id = this.nextEntityId++
    this.entities.add(id)
    return id
  }

  destroyEntity(entity: Entity): void {
    this.entities.delete(entity)
    this.components.forEach(store => store.delete(entity))
  }

  addComponent<T>(entity: Entity, component: T): void {
    const name = component!.constructor.name
    if (!this.components.has(name)) {
      this.components.set(name, new Map())
    }
    this.components.get(name)!.set(entity, component)
  }

  getComponent<T>(entity: Entity, ComponentClass: ComponentClass<T>): T | undefined {
    return this.components.get(ComponentClass.name)?.get(entity)
  }

  removeComponent(entity: Entity, ComponentClass: ComponentClass): void {
    this.components.get(ComponentClass.name)?.delete(entity)
  }

  query(...ComponentClasses: ComponentClass[]): Entity[] {
    const names = ComponentClasses.map(c => c.name)
    return [...this.entities].filter(entity =>
      names.every(name => this.components.get(name)?.has(entity))
    )
  }

  addSystem(system: System): void {
    system.world = this
    this.systems.push(system)
  }

  update(dt: number): void {
    this.systems.forEach(system => system.update(dt))
  }
}

abstract class System {
  world!: World
  abstract update(dt: number): void
}

class Position { constructor(public x = 0, public y = 0, public z = 0) {} }
class Velocity { constructor(public vx = 0, public vy = 0, public vz = 0) {} }
class Lifetime { constructor(public remaining: number, public max: number) {} }
class RenderData { constructor(public mesh: THREE.Mesh | null = null) {} }

class MovementSystem extends System {
  update(dt: number): void {
    const entities = this.world.query(Position, Velocity)
    for (const entity of entities) {
      const pos = this.world.getComponent(entity, Position)!
      const vel = this.world.getComponent(entity, Velocity)!
      pos.x += vel.vx * dt
      pos.y += vel.vy * dt
      pos.z += vel.vz * dt
      vel.vy -= 9.8 * dt
    }
  }
}

class LifetimeSystem extends System {
  update(dt: number): void {
    const entities = this.world.query(Lifetime)
    for (const entity of entities) {
      const life = this.world.getComponent(entity, Lifetime)!
      life.remaining -= dt
      if (life.remaining <= 0) {
        const render = this.world.getComponent(entity, RenderData)
        if (render?.mesh) {
          render.mesh.parent?.remove(render.mesh)
          render.mesh.geometry.dispose()
        }
        this.world.destroyEntity(entity)
      }
    }
  }
}

class RenderSystem extends System {
  constructor(private scene: THREE.Scene) { super() }

  update(_dt: number): void {
    const entities = this.world.query(Position, RenderData)
    for (const entity of entities) {
      const pos = this.world.getComponent(entity, Position)!
      const render = this.world.getComponent(entity, RenderData)!
      if (render.mesh) {
        render.mesh.position.set(pos.x, pos.y, pos.z)
      }
    }
  }
}
```

### 练习二

**思路**：资源管理器需要处理三种资源（纹理、模型、音频）的加载、缓存和释放。引用计数追踪每个资源被多少实体使用，归零时标记为可释放。LRU 淘汰在内存超限时找出最久未使用的资源并释放。

**答案**：

```typescript
import * as THREE from 'three'

interface ResourceEntry {
  type: 'texture' | 'model' | 'audio'
  data: any
  refCount: number
  lastUsed: number
  size: number
}

class ResourceManager {
  private cache = new Map<string, ResourceEntry>()
  private memoryBudget: number
  private currentMemory = 0

  constructor(memoryBudgetMB: number = 256) {
    this.memoryBudget = memoryBudgetMB * 1024 * 1024
  }

  async loadTexture(url: string): Promise<THREE.Texture> {
    const cached = this.cache.get(url)
    if (cached) {
      cached.refCount++
      cached.lastUsed = Date.now()
      return cached.data as THREE.Texture
    }

    const loader = new THREE.TextureLoader()
    return new Promise((resolve, reject) => {
      loader.load(url, (texture) => {
        const size = this.estimateTextureSize(texture)
        this.currentMemory += size
        this.cache.set(url, {
          type: 'texture', data: texture, refCount: 1, lastUsed: Date.now(), size
        })
        this.evictIfNeeded()
        resolve(texture)
      }, undefined, reject)
    })
  }

  async loadModel(url: string): Promise<THREE.Group> {
    const cached = this.cache.get(url)
    if (cached) {
      cached.refCount++
      cached.lastUsed = Date.now()
      return cached.data as THREE.Group
    }

    const { GLTFLoader } = await import('three/addons/loaders/GLTFLoader.js')
    const loader = new GLTFLoader()
    return new Promise((resolve, reject) => {
      loader.load(url, (gltf) => {
        const size = this.estimateModelSize(gltf.scene)
        this.currentMemory += size
        this.cache.set(url, {
          type: 'model', data: gltf.scene, refCount: 1, lastUsed: Date.now(), size
        })
        this.evictIfNeeded()
        resolve(gltf.scene)
      }, undefined, reject)
    })
  }

  async loadAudio(url: string): Promise<AudioBuffer> {
    const cached = this.cache.get(url)
    if (cached) {
      cached.refCount++
      cached.lastUsed = Date.now()
      return cached.data as AudioBuffer
    }

    const ctx = new AudioContext()
    const response = await fetch(url)
    const buffer = await response.arrayBuffer()
    const audioBuffer = await ctx.decodeAudioData(buffer)
    const size = audioBuffer.length * audioBuffer.numberOfChannels * 4
    this.currentMemory += size
    this.cache.set(url, {
      type: 'audio', data: audioBuffer, refCount: 1, lastUsed: Date.now(), size
    })
    ctx.close()
    this.evictIfNeeded()
    return audioBuffer
  }

  addRef(url: string): void {
    const entry = this.cache.get(url)
    if (entry) entry.refCount++
  }

  release(url: string): void {
    const entry = this.cache.get(url)
    if (!entry) return
    entry.refCount--
    if (entry.refCount <= 0) {
      this.destroyResource(url, entry)
    }
  }

  private destroyResource(url: string, entry: ResourceEntry): void {
    if (entry.type === 'texture') {
      (entry.data as THREE.Texture).dispose()
    } else if (entry.type === 'model') {
      (entry.data as THREE.Group).traverse(child => {
        if ((child as THREE.Mesh).isMesh) {
          const mesh = child as THREE.Mesh
          mesh.geometry.dispose()
          if (Array.isArray(mesh.material)) {
            mesh.material.forEach(m => m.dispose())
          } else {
            mesh.material.dispose()
          }
        }
      })
    }
    this.currentMemory -= entry.size
    this.cache.delete(url)
  }

  private evictIfNeeded(): void {
    while (this.currentMemory > this.memoryBudget && this.cache.size > 0) {
      let oldest: [string, ResourceEntry] | null = null
      this.cache.forEach((entry, url) => {
        if (entry.refCount <= 0 && (!oldest || entry.lastUsed < oldest[1].lastUsed)) {
          oldest = [url, entry]
        }
      })
      if (oldest) {
        this.destroyResource(oldest[0], oldest[1])
      } else {
        break
      }
    }
  }

  private estimateTextureSize(texture: THREE.Texture): number {
    const img = texture.image as HTMLImageElement | HTMLCanvasElement
    if (!img) return 0
    const w = (img as HTMLImageElement).width || 256
    const h = (img as HTMLImageElement).height || 256
    return w * h * 4
  }

  private estimateModelSize(group: THREE.Group): number {
    let size = 0
    group.traverse(child => {
      if ((child as THREE.Mesh).isMesh) {
        const geo = (child as THREE.Mesh).geometry
        geo.attributes && Object.values(geo.attributes).forEach(attr => {
          size += (attr as THREE.BufferAttribute).array.byteLength
        })
      }
    })
    return size
  }

  getStats() {
    return {
      entries: this.cache.size,
      currentMB: Math.round(this.currentMemory / 1024 / 1024),
      budgetMB: Math.round(this.memoryBudget / 1024 / 1024)
    }
  }
}
```

**要点**：
- 引用计数确保正在使用的资源不会被误释放，`addRef` 和 `release` 必须成对调用
- LRU 淘汰只释放 `refCount === 0` 的资源，没有空闲资源时即使超限也不会强制释放
- `estimateTextureSize` 用 `width * height * 4`（RGBA）估算，实际 GPU 纹理可能因 mipmap 额外增加 ~33%
- Model 的大小估算遍历所有 Geometry 的 BufferAttribute，这比遍历 Mesh 数量更准确

```typescript
type EventHandler = (...args: any[]) => void

class EventBus {
  private handlers = new Map<string, Set<EventHandler>>()

  on(event: string, handler: EventHandler): () => void {
    if (!this.handlers.has(event)) this.handlers.set(event, new Set())
    this.handlers.get(event)!.add(handler)
    return () => this.handlers.get(event)?.delete(handler)
  }

  emit(event: string, ...args: any[]): void {
    this.handlers.get(event)?.forEach(handler => handler(...args))
  }
}

class HealthSystem {
  constructor(private world: World) {
    world.events.on('damage', (entity: Entity, amount: number) => {
      const health = world.getComponent(entity, Health)
      if (!health) return
      health.current = Math.max(0, health.current - amount)
      if (health.current <= 0) {
        world.events.emit('death', entity)
      }
    })

class SkillSystem {
  private cooldowns = new Map<string, number>()

  constructor(private world: World, private player: Entity) {
    world.events.on('skill', (skillName: string) => {
      const now = performance.now()
      const lastUsed = this.cooldowns.get(skillName) || 0
      const cooldowns: Record<string, number> = { fireball: 1000, lightning: 2000, heal: 3000 }
      if (now - lastUsed < (cooldowns[skillName] || 1000)) return
      this.cooldowns.set(skillName, now)

      const playerPos = world.getComponent(this.player, Transform)!
      const ranges: Record<string, number> = { fireball: 5, lightning: 8, heal: 3 }
      const damages: Record<string, number> = { fireball: 30, lightning: 50, heal: -20 }
      const range = ranges[skillName] || 5
      const damage = damages[skillName] || 20

      const targets = world.query(Health, Transform).filter(e => {
        if (e === this.player && skillName !== 'heal') return false
        const t = world.getComponent(e, Transform)!
        const dx = t.x - playerPos.x, dz = t.z - playerPos.z
        return Math.sqrt(dx * dx + dz * dz) <= range
      })

      targets.forEach(target => {
        world.events.emit('damage', target, damage)
        world.events.emit('skill-effect', skillName, world.getComponent(target, Transform)!)
      })
    })
  }
}

class VFXSystem {
  private scene: THREE.Scene
  private effects: Array<{ mesh: THREE.Object3D; startTime: number }> = []

  constructor(private world: World, scene: THREE.Scene) {
    this.scene = scene
    world.events.on('death', (entity: Entity) => {
      const transform = world.getComponent(entity, Transform)
      if (transform) this.spawnDeathEffect(transform)
      world.destroyEntity(entity)
    })
    world.events.on('skill-effect', (skill: string, transform: Transform) => {
      this.spawnSkillEffect(skill, transform)
    })
  }

  private spawnDeathEffect(pos: Transform) {
    const geo = new THREE.SphereGeometry(0.5, 16, 16)
    const mat = new THREE.MeshBasicMaterial({ color: 0xff4444, transparent: true, opacity: 0.8 })
    const mesh = new THREE.Mesh(geo, mat)
    mesh.position.set(pos.x, pos.y, pos.z)
    this.scene.add(mesh)
    this.effects.push({ mesh, startTime: performance.now() })
  }

  private spawnSkillEffect(skill: string, pos: Transform) {
    const colors: Record<string, number> = { fireball: 0xff6600, lightning: 0x44aaff, heal: 0x44ff44 }
    const geo = new THREE.SphereGeometry(0.3, 8, 8)
    const mat = new THREE.MeshBasicMaterial({ color: colors[skill] || 0xffffff, transparent: true, opacity: 0.6 })
    const mesh = new THREE.Mesh(geo, mat)
    mesh.position.set(pos.x, pos.y + 0.5, pos.z)
    this.scene.add(mesh)
    this.effects.push({ mesh, startTime: performance.now() })
  }

  update() {
    const now = performance.now()
    for (let i = this.effects.length - 1; i >= 0; i--) {
      const age = (now - this.effects[i].startTime) / 1000
      if (age > 1) {
        this.scene.remove(this.effects[i].mesh)
        this.effects.splice(i, 1)
      } else {
        this.effects[i].mesh.scale.setScalar(1 + age * 2)
        const mat = (this.effects[i].mesh as THREE.Mesh).material as THREE.MeshBasicMaterial
        mat.opacity = 0.8 * (1 - age)
      }
    }
  }
}
```

```typescript
class StateManager {
  private state = new Map<string, any>()
  private listeners = new Map<string, Set<(value: any) => void>>()

  get<T>(key: string): T | undefined { return this.state.get(key) }

  set<T>(key: string, value: T): void {
    this.state.set(key, value)
    this.listeners.get(key)?.forEach(fn => fn(value))
  }

  onChange(key: string, fn: (value: any) => void): () => void {
    if (!this.listeners.has(key)) this.listeners.set(key, new Set())
    this.listeners.get(key)!.add(fn)
    return () => this.listeners.get(key)?.delete(fn)
  }
}

class ResourceManager {
  private cache = new Map<string, { data: any; refCount: number }>()

    return new Promise((resolve, reject) => {
      this.loader.load(url, tex => {
        this.cache.set(url, { data: tex, refCount: 1 })

    const entry = this.cache.get(url)
    if (!entry) return
    entry.refCount--
    if (entry.refCount <= 0) {
      entry.data.dispose?.()
      this.cache.delete(url)
    }
  }

  }
  query(...CCs: (new (...a: any[]) => any)[]): Entity[] {
    const names = CCs.map(c => c.name)
    return [...this.entities].filter(e => names.every(n => this.components.get(n)?.has(e)))
  }
  addSystem(s: ECSSystem): void { s.world = this; this.systems.push(s) }
  update(dt: number): void { this.systems.forEach(s => s.update(dt)) }
}

abstract class ECSSystem { world!: ECSWorld; abstract update(dt: number): void }

class Position { constructor(public x = 0, public y = 0, public z = 0) {} }
class Rotation { constructor(public x = 0, public y = 0, public z = 0) {} }
class MeshRef { constructor(public mesh: THREE.Mesh) {} }
class BobAnimation { constructor(public baseY: number, public amplitude: number, public speed: number) {} }

class TransformSyncSystem extends ECSSystem {
  update(_dt: number): void {
    for (const e of this.world.query(Position, MeshRef)) {
      const pos = this.world.getComponent(e, Position)!
      const ref = this.world.getComponent(e, MeshRef)!
      ref.mesh.position.set(pos.x, pos.y, pos.z)
    }
    for (const e of this.world.query(Rotation, MeshRef)) {
      const rot = this.world.getComponent(e, Rotation)!
      const ref = this.world.getComponent(e, MeshRef)!
      ref.mesh.rotation.set(rot.x, rot.y, rot.z)
    }
  }
}

class BobSystem extends ECSSystem {
  update(dt: number): void {
    for (const e of this.world.query(Position, BobAnimation)) {
      const pos = this.world.getComponent(e, Position)!
      const bob = this.world.getComponent(e, BobAnimation)!
      pos.y = bob.baseY + Math.sin(performance.now() * 0.001 * bob.speed) * bob.amplitude
    }
  }
}

class SpinSystem extends ECSSystem {
  update(dt: number): void {
    for (const e of this.world.query(Rotation)) {
      const rot = this.world.getComponent(e, Rotation)!
      rot.y += dt
    }
  }
}

async function refactoredApp() {
  const state = new StateManager()
  const resources = new ResourceManager()
  const world = new ECSWorld()
  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100)
  camera.position.set(0, 3, 8)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  document.body.appendChild(renderer.domElement)

  scene.add(new THREE.AmbientLight(0xffffff, 0.5))
  scene.add(new THREE.DirectionalLight(0xffffff, 0.8))

  state.set('score', 0)
  state.set('health', 100)
  state.onChange('health', (h: number) => console.log(`Health changed: ${h}`))

  world.addSystem(new TransformSyncSystem())
  world.addSystem(new BobSystem())
  world.addSystem(new SpinSystem())

  const woodTex = await resources.loadTexture('/textures/wood.jpg')
  const stoneTex = await resources.loadTexture('/textures/stone.jpg')

  const box = world.createEntity()
  const boxMesh = new THREE.Mesh(
    new THREE.BoxGeometry(1, 1, 1),
    new THREE.MeshStandardMaterial({ map: woodTex })
  )
  scene.add(boxMesh)
  world.addComponent(box, new Position(0, 0.5, -2))
  world.addComponent(box, new Rotation(0, 0, 0))
  world.addComponent(box, new MeshRef(boxMesh))

  const sphere = world.createEntity()
  const sphereMesh = new THREE.Mesh(
    new THREE.SphereGeometry(0.5, 32, 32),
    new THREE.MeshStandardMaterial({ map: stoneTex })
  )
  scene.add(sphereMesh)
  world.addComponent(sphere, new Position(2, 0.5, 0))
  world.addComponent(sphere, new BobAnimation(0.5, 0.3, 2))
  world.addComponent(sphere, new MeshRef(sphereMesh))

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  const clock = new THREE.Clock()
  function animate() {
    requestAnimationFrame(animate)
    const dt = Math.min(clock.getDelta(), 0.05)
    world.update(dt)
    renderer.render(scene, camera)
  }
  animate()
}
```

**要点**：
- 重构前后最大的变化：散落的 `let score = 0` → 集中的 `state.set('score', 0)`，状态变更可追踪
- 资源加载从 `new TextureLoader().load()` → `resources.loadTexture()`，自动缓存 + 引用计数
- 位置/旋转从 `mesh.position.set()` → ECS Component，修改数据自动同步到渲染
- 新增功能（如 Bob 动画）只需添加新 Component + 新 System，不修改现有代码
