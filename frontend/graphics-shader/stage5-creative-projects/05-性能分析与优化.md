# 性能分析与优化

## 场景引入

你的 3D 应用在开发机上跑得流畅，一上手机就卡成幻灯片——这种经历每个 WebGL 开发者都遇到过。性能优化不是凭感觉猜，而是基于数据做决策。本课将系统学习 GPU 性能分析工具的使用、Draw Call 合批策略、Overdraw 检测、LOD 系统、纹理压缩技术，以及移动端的专项优化方法，让你的 3D 应用在任何设备上都能流畅运行。

## 学习目标

1. 掌握 Spector.js 和 WebGPU Inspector 等 GPU Profiler 工具
2. 理解 Draw Call 的开销本质和合批（Instancing / Batching）策略
3. 学会检测和减少 Overdraw
4. 实现 LOD（Level of Detail）策略
5. 掌握纹理压缩格式（ASTC / ETC2 / BC）的选择与使用
6. 理解 WebGL 的内存管理机制
7. 掌握移动端专项优化技巧

```typescript
import { Spector } from 'spectorjs'

class PerformanceProfiler {
  private spector: Spector
  private fpsHistory: number[] = []
  private frameTimeSamples: number[] = []

  constructor() {
    this.spector = new Spector()
    this.spector.displayUI()
  }

  captureFrame(): void {
    this.spector.captureCanvas(document.querySelector('canvas')!)
  }

  // 内置 FPS 监控
  startFPSMonitor(): void {
    let lastTime = performance.now()
    let frames = 0

    const update = () => {
      frames++
      const now = performance.now()
      if (now - lastTime >= 1000) {
        const fps = Math.round(frames * 1000 / (now - lastTime))
        this.fpsHistory.push(fps)
        if (this.fpsHistory.length > 60) this.fpsHistory.shift()
        console.log(`FPS: ${fps} | Avg: ${this.averageFPS.toFixed(1)}`)
        frames = 0
        lastTime = now
      }
      requestAnimationFrame(update)
    }
    requestAnimationFrame(update)
  }

  get averageFPS(): number {
    return this.fpsHistory.reduce((a, b) => a + b, 0) / this.fpsHistory.length
  }

  get p99FrameTime(): number {
    const sorted = [...this.frameTimeSamples].sort((a, b) => b - a)
    return sorted[Math.floor(sorted.length * 0.01)] || 0
  }
}
```

## Draw Call 分析与合批

### Draw Call 的开销本质

```
Draw Call 开销分解：

CPU 端                     GPU 端
┌──────────────┐          ┌──────────────┐
│ 设置渲染状态  │          │ 执行顶点着色  │
│ 绑定 Shader  │          │ 光栅化       │
│ 绑定纹理     │  ──────▶ │ 执行片元着色  │
│ 绑定 VBO     │  提交     │ 写入帧缓冲   │
│ 发送 Uniform │          │              │
│ drawArrays() │          │              │
└──────────────┘          └──────────────┘
  ~0.1-1ms/次               与三角形数成正比

问题: 每次 Draw Call 的 CPU 开销是固定的
      1000 个小物体 = 1000 次状态切换 + 提交
      → CPU 成为瓶颈（GPU 在等 CPU）
```

### Instancing 合批

```typescript
// 方案一：InstancedMesh（Three.js 内置）
function createInstancedObjects(
  geometry: THREE.BufferGeometry,
  material: THREE.Material,
  positions: THREE.Vector3[],
  rotations: number[]
): THREE.InstancedMesh {
  const count = positions.length
  const mesh = new THREE.InstancedMesh(geometry, material, count)
  const matrix = new THREE.Matrix4()
  const quaternion = new THREE.Quaternion()

  for (let i = 0; i < count; i++) {
    quaternion.setFromAxisAngle(new THREE.Vector3(0, 1, 0), rotations[i])
    matrix.compose(positions[i], quaternion, new THREE.Vector3(1, 1, 1))
    mesh.setMatrixAt(i, matrix)
  }

  mesh.instanceMatrix.needsUpdate = true
  return mesh
}
```

### 手动 Batching（合并几何体）

```typescript
// 方案二：静态合批（适合不移动的物体）
class StaticBatcher {
  static mergeMeshes(meshes: THREE.Mesh[]): THREE.Mesh {
    const geometries: THREE.BufferGeometry[] = []

    meshes.forEach(mesh => {
      const geo = mesh.geometry.clone()
      geo.applyMatrix4(mesh.matrixWorld)
      geometries.push(geo)
    })

    const merged = BufferGeometryUtils.mergeGeometries(geometries)
    const material = (meshes[0].material as THREE.Material).clone()
    return new THREE.Mesh(merged, material)
  }
}

// 使用 BufferGeometryUtils
import { mergeGeometries } from 'three/addons/utils/BufferGeometryUtils.js'

function batchStaticObjects(objects: THREE.Mesh[]): THREE.Mesh {
  const geos = objects.map(obj => {
    const g = obj.geometry.clone()
    g.applyMatrix4(obj.matrixWorld)
    return g
  })
  const merged = mergeGeometries(geos, false)!
  return new THREE.Mesh(merged, objects[0].material as THREE.Material)
}
```

### 合批策略对比

```
策略           适用场景          限制             Draw Call 减少
─────────────────────────────────────────────────────────────
Instancing    大量相同几何体     同一材质          N → 1
Static Batch  静态不动物体      合并后不可单独操作  N → 1
Dynamic Batch 少量三角形的小物体 每帧重新合并有开销  N → ~1
Texture Atlas 不同纹理的物体    需要 UV 重映射     减少纹理切换
```

## Overdraw 检测

### 什么是 Overdraw

```
Overdraw 示意：

理想情况（1x overdraw）：      严重 Overdraw：
  ┌─────────┐                   ┌─────────┐
  │ AAAAA   │                   │ AAAAA   │
  │ AAAAA   │                   │ AABBA   │ ← B 在 A 上面
  │  BBBBB  │                   │ AABBA   │   A 被画了两次
  │  BBBBB  │                   │ BBBBB   │
  └─────────┘                   └─────────┘
  每个像素写入 1 次              部分像素写入 2+ 次

Overdraw 度量：
  实际片元着色次数 / 屏幕像素数
  理想值: 1.0
  可接受: < 2.0
  危险: > 3.0
```

```typescript
class OverdrawDetector {
  private scene: THREE.Scene
  private overdrawMaterial: THREE.ShaderMaterial
  private originalMaterials: Map<THREE.Object3D, THREE.Material | THREE.Material[]> = new Map()

  constructor(scene: THREE.Scene) {
    this.scene = scene
    this.overdrawMaterial = new THREE.ShaderMaterial({
      vertexShader: `void main() { gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
      fragmentShader: `void main() { gl_FragColor = vec4(0.1, 0.1, 0.1, 0.2); }`,
      transparent: true,
      blending: THREE.AdditiveBlending,
      depthWrite: false,
    })
  }

  enable(): void {
    this.scene.traverse(child => {
      if (child instanceof THREE.Mesh) {
        this.originalMaterials.set(child, child.material)
        child.material = this.overdrawMaterial
      }
    })
  }

  disable(): void {
    this.originalMaterials.forEach((material, child) => {
      if (child instanceof THREE.Mesh) {
        child.material = material
      }
    })
  }
}
```

## LOD 策略

### Three.js LOD 系统

```typescript
class LODManager {
  private lod: THREE.LOD

  constructor() {
    this.lod = new THREE.LOD()
  }

  addLevel(
    geometry: THREE.BufferGeometry,
    material: THREE.Material,
    distance: number,
    detail: number
  ): void {
    // detail 参数用于降低顶点数
    const mesh = new THREE.Mesh(geometry, material)
    this.lod.addLevel(mesh, distance)
  }

  // 自动生成多级 LOD
  static autoLOD(highDetailGeo: THREE.BufferGeometry): THREE.BufferGeometry[] {
    const levels: THREE.BufferGeometry[] = [highDetailGeo]
    const simplifier = new SimplifyModifier()

    const ratios = [0.5, 0.25, 0.1]
    ratios.forEach(ratio => {
      const targetFaces = Math.floor(
        (highDetailGeo.index?.count || highDetailGeo.attributes.position.count) / 3 * ratio
      )
      const simplified = simplifier.modify(highDetailGeo.clone(), targetFaces)
      levels.push(simplified)
    })

    return levels
  }
}
```

### 屏幕空间 LOD

```typescript
// 根据物体在屏幕上的投影大小选择 LOD
class ScreenSpaceLOD {
  static getLODLevel(
    object: THREE.Object3D,
    camera: THREE.PerspectiveCamera,
    screenWidth: number
  ): number {
    const distance = camera.position.distanceTo(object.position)
    const fov = camera.fov * Math.PI / 180
    const objectSize = 1 // 假设物体半径为 1

    // 物体在屏幕上的近似像素大小
    const screenSize = (objectSize / (distance * Math.tan(fov / 2))) * screenWidth

    if (screenSize > 200) return 0  // 高精度
    if (screenSize > 50) return 1   // 中精度
    if (screenSize > 10) return 2   // 低精度
    return -1                        // 不渲染
  }
}
```

```typescript
function getOptimalTextureSize(
  targetSize: number,
  device: { maxTextureSize: number; isMobile: boolean }
): number {
  const maxSize = device.isMobile
    ? Math.min(device.maxTextureSize, 2048)
    : device.maxTextureSize

  // 确保是 2 的幂次
  let size = 1
  while (size * 2 <= targetSize && size * 2 <= maxSize) {
    size *= 2
  }
  return size
}
```

```typescript
class MemoryManager {
  private allocatedTextures = new Map<string, { texture: THREE.Texture; lastUsed: number }>()

  // 检查 GPU 内存使用
  getGPUMemoryUsage(gl: WebGL2RenderingContext): {
    used: number
    total: number
  } {
    const ext = gl.getExtension('WEBGL_debug_renderer_info')
    // 无法直接获取，只能估算
    return { used: 0, total: 0 }
  }

  // 安全释放纹理
  disposeTexture(texture: THREE.Texture): void {
    texture.dispose()
    if (texture.image instanceof HTMLImageElement) {
      texture.image.src = ''
    }
  }

  // 场景资源清理
  disposeScene(scene: THREE.Scene): void {
    scene.traverse(object => {
      if (object instanceof THREE.Mesh) {
        object.geometry.dispose()
        const materials = Array.isArray(object.material)
          ? object.material
          : [object.material]
        materials.forEach(m => {
          Object.keys(m).forEach(key => {
            const value = (m as any)[key]
            if (value instanceof THREE.Texture) {
              value.dispose()
            }
          })
          m.dispose()
        })
      }
    })
  }

  // LRU 纹理缓存
  private maxTextures = 50
  addTexture(key: string, texture: THREE.Texture): void {
    if (this.allocatedTextures.size >= this.maxTextures) {
      const oldest = [...this.allocatedTextures.entries()]
        .sort((a, b) => a[1].lastUsed - b[1].lastUsed)[0]
      this.disposeTexture(oldest[1].texture)
      this.allocatedTextures.delete(oldest[0])
    }
    this.allocatedTextures.set(key, { texture, lastUsed: Date.now() })
  }
}
```

## 移动端优化

### 移动端专项检查清单

```
移动端 WebGL 优化清单：

分辨率
  ├─ 使用 renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
  ├─ 考虑渲染到低分辨率 FBO 再上采样
  └─ 避免 4K 分辨率纹理

着色器
  ├─ 使用 mediump 精度（highp 在部分设备很慢）
  ├─ 避免分支（if/else）在片元着色器中
  ├─ 减少纹理采样次数
  └─ 避免 discard（破坏 Early-Z）

几何体
  ├─ 移动端三角形上限: ~100K
  ├─ 使用索引绘制
  └─ 顶点属性越少越好

纹理
  ├─ 使用压缩纹理（ASTC/ETC2）
  ├─ Mipmap 必须开启
  └─ 纹理尺寸不超过 2048x2048
```

```typescript
class MobileOptimizer {
  static detectCapabilities(gl: WebGL2RenderingContext): {
    maxTextureSize: number
    maxVertexUniforms: number
    maxFragmentUniforms: number
    isMobileGPU: boolean
    renderer: string
  } {
    const debugExt = gl.getExtension('WEBGL_debug_renderer_info')
    const renderer = debugExt
      ? gl.getParameter(debugExt.UNMASKED_RENDERER_WEBGL)
      : 'unknown'

    return {
      maxTextureSize: gl.getParameter(gl.MAX_TEXTURE_SIZE),
      maxVertexUniforms: gl.getParameter(gl.MAX_VERTEX_UNIFORM_VECTORS),
      maxFragmentUniforms: gl.getParameter(gl.MAX_FRAGMENT_UNIFORM_VECTORS),
      isMobileGPU: /mali|adreno|powervr|apple gpu/i.test(renderer),
      renderer,
    }
  }

  static optimizeForMobile(
    renderer: THREE.WebGLRenderer,
    scene: THREE.Scene
  ): void {
    const caps = this.detectCapabilities(renderer.getContext())

    if (caps.isMobileGPU) {
      // 降低渲染分辨率
      renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.5))

      // 简化材质
      scene.traverse(child => {
        if (child instanceof THREE.Mesh) {
          if (child.material instanceof THREE.MeshStandardMaterial) {
            child.material.roughness = 1 // 避免环境贴图计算
            child.material.metalness = 0
          }
        }
      })

      // 关闭抗锯齿
      // （需要在创建 renderer 时设置）
    }
  }
}
```

## 常见误区

1. **只看 FPS 不看帧时间**：FPS 是非线性的——从 60fps 降到 30fps 是 16.7ms 的差距，从 30fps 降到 20fps 也是 16.7ms，但感知完全不同。应该用毫秒为单位衡量帧时间，更直观地判断性能预算。

2. **过度合批导致材质浪费**：将所有物体合为一个大 Draw Call，如果部分物体需要不同的材质效果（如高光 vs 哑光），反而会因为需要切换材质状态而失去合批收益。应该按材质分组合批。

3. **忽略纹理上传的卡顿**：`gl.texImage2D` 是同步阻塞操作，大纹理上传会导致帧率骤降。应该用 `requestVideoFrameCallback` 或分帧上传，或者使用 Compressed Texture 直接加载 GPU 可用格式。

4. **盲目降低多边形数量**：现代 GPU 的顶点处理能力远超片元处理能力。瓶颈通常在片元着色器（纹理采样、光照计算），减少多边形对性能改善有限，反而增加了 LOD 切换的视觉跳变。

## 工程建议

1. **建立性能预算**：为每个系统分配固定的帧时间预算——渲染 5ms、物理 1ms、AI 1ms、UI 1ms，总计不超过目标帧时间的 80%，留 20% 应对突发。

2. **用 Chrome DevTools Performance 面板定位 CPU 瓶颈**：Spector.js 看 GPU 调用，Performance 面板看 CPU 耗时。很多"渲染慢"的问题其实是 JavaScript 逻辑（场景遍历、矩阵更新）占用了过多 CPU 时间。

3. **实现自适应画质**：检测帧率持续低于目标值时，自动降低渲染分辨率、关闭后处理效果、切换到低精度 LOD，保证流畅度优先。

4. **自动化性能测试**：在 CI 中用 Puppeteer 打开 3D 场景，录制 10 秒的帧率数据，设置回归阈值（如平均 FPS 不能低于 55），防止性能退化。

## 小结

本课系统学习了 3D 应用性能分析与优化的完整工具链。Spector.js 帮助我们看清每一帧的 GPU 调用，Instancing 和 Batching 将成百上千的 Draw Call 压缩为个位数，Overdraw 检测揭示像素的重复绘制，LOD 系统根据距离动态调整几何精度，纹理压缩大幅降低显存占用和带宽。移动端优化需要更严格的预算——更低的分辨率、更简单的材质、更少的三角形。性能优化的核心原则：先测量，再优化，有预算，有监控。

```typescript
  btnIndividual.onclick = createIndividualMeshes
  document.body.appendChild(btnIndividual)

  btnInstanced.textContent = 'Instancing 模式'
  btnInstanced.style.cssText = 'position:fixed;top:120px;left:10px;padding:8px 16px;z-index:10;'
  btnInstanced.onclick = createInstancedMeshes
  document.body.appendChild(btnInstanced)

  createIndividualMeshes()

  let frameCount = 0
  let lastTime = performance.now()
  let fps = 0

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  function animate() {
    requestAnimationFrame(animate)
    frameCount++
    const now = performance.now()
    if (now - lastTime >= 1000) {
      fps = frameCount
      frameCount = 0
      lastTime = now
    }

    const drawCalls = renderer.info.render.calls
    infoEl.innerHTML = `
      模式: ${mode === 'individual' ? '独立 Mesh' : 'Instancing'}<br>
      Draw Call: ${drawCalls}<br>
      FPS: ${fps}<br>
      三角形: ${renderer.info.render.triangles.toLocaleString()}
    `

    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}
```

### 练习二

**思路**：LOD 系统根据物体到相机的距离自动切换几何精度。Three.js 内置了 `THREE.LOD` 对象，可以添加多个级别的 Mesh 并设置距离阈值。用 lil-gui 显示当前活跃的 LOD 级别和三角形数量。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

function createLODDemo() {
  const scene = new THREE.Scene()
  scene.background = new THREE.Color(0x1a1a2e)
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000)
  camera.position.set(0, 5, 20)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true
  controls.minDistance = 2
  controls.maxDistance = 100

  scene.add(new THREE.AmbientLight(0xffffff, 0.5))
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.8)
  dirLight.position.set(5, 10, 5)
  scene.add(dirLight)

  const lod = new THREE.LOD()
  const mat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7, roughness: 0.4, metalness: 0.2 })

  const levels = [
    { segments: 100, distance: 0 },
    { segments: 50, distance: 15 },
    { segments: 20, distance: 30 },
    { segments: 10, distance: 50 },
    { segments: 4, distance: 80 }
  ]

  levels.forEach(level => {
    const geo = new THREE.SphereGeometry(2, level.segments, level.segments)
    const mesh = new THREE.Mesh(geo, mat.clone())
    lod.addLevel(mesh, level.distance)
  })

  scene.add(lod)

  const guiState = {
    currentLOD: 'Level 0 (100段)',
    triangles: 0,
    distance: 0
  }

  const gui = new GUI({ title: 'LOD 状态' })
  gui.add(guiState, 'currentLOD').name('当前级别').disable()
  gui.add(guiState, 'triangles').name('三角形数').disable()
  gui.add(guiState, 'distance').name('相机距离').disable()

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  function animate() {
    requestAnimationFrame(animate)
    controls.update()
    lod.update(camera)

    const dist = camera.position.distanceTo(lod.position)
    const currentLevel = lod.getCurrentLevel()
    const activeMesh = lod.levels[currentLevel]?.object as THREE.Mesh

    guiState.currentLOD = `Level ${currentLevel} (${levels[currentLevel].segments}段)`
    guiState.triangles = activeMesh ? activeMesh.geometry.index!.count / 3 : 0
    guiState.distance = Math.round(dist * 10) / 10

    renderer.render(scene, camera)
  }
  animate()
}
```

**要点**：
- `THREE.LOD` 内部根据相机距离自动切换可见级别，只需调用 `lod.update(camera)`
- 距离阈值应根据物体大小和场景规模调整，大场景需要更远的切换距离
- `getCurrentLevel()` 返回当前活跃的 LOD 级别索引，可用于 UI 展示

### 练习三

**思路**：Overdraw 可视化的核心是将所有物体的材质替换为半透明叠加材质（`blending: AdditiveBlending`），每经过一个物体颜色叠加一次。Overdraw 严重的区域会变得非常亮。通过调整物体排序（`renderOrder`）或开启背面剔除来减少 overdraw。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

function createOverdrawVisualizer() {
  const scene = new THREE.Scene()
  scene.background = new THREE.Color(0x000000)
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100)
  camera.position.set(0, 5, 12)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true

  scene.add(new THREE.AmbientLight(0xffffff, 0.3))

  const normalMaterials: Map<THREE.Mesh, THREE.Material> = new Map()
  const meshes: THREE.Mesh[] = []

  const overdrawMat = new THREE.MeshBasicMaterial({
    color: 0x00ff00,
    transparent: true,
    opacity: 0.15,
    blending: THREE.AdditiveBlending,
    depthWrite: false,
    side: THREE.DoubleSide
  })

  const geometries = [
    new THREE.SphereGeometry(1, 32, 32),
    new THREE.BoxGeometry(1.5, 1.5, 1.5),
    new THREE.TorusGeometry(0.8, 0.3, 16, 32),
    new THREE.ConeGeometry(0.8, 1.5, 32),
    new THREE.TorusKnotGeometry(0.6, 0.2, 64, 16)
  ]

  for (let i = 0; i < 30; i++) {
    const geo = geometries[i % geometries.length]
    const mat = new THREE.MeshStandardMaterial({
      color: new THREE.Color().setHSL(Math.random(), 0.7, 0.5),
      roughness: 0.5, side: THREE.DoubleSide
    })
    const mesh = new THREE.Mesh(geo, mat)
    mesh.position.set(
      (Math.random() - 0.5) * 15,
      Math.random() * 5,
      (Math.random() - 0.5) * 15
    )
    mesh.rotation.set(Math.random() * Math.PI, Math.random() * Math.PI, 0)
    normalMaterials.set(mesh, mat)
    meshes.push(mesh)
    scene.add(mesh)
  }

  let overdrawMode = false

  const toggleBtn = document.createElement('button')
  toggleBtn.textContent = '切换 Overdraw 可视化'
  toggleBtn.style.cssText = 'position:fixed;top:10px;left:10px;padding:8px 16px;z-index:10;'
  document.body.appendChild(toggleBtn)

  const infoEl = document.createElement('div')
  infoEl.style.cssText = 'position:fixed;top:50px;left:10px;color:#fff;font-size:13px;z-index:10;'
  document.body.appendChild(infoEl)

  const optimizeBtn = document.createElement('button')
  optimizeBtn.textContent = '应用优化（排序 + 剔除）'
  optimizeBtn.style.cssText = 'position:fixed;top:90px;left:10px;padding:8px 16px;z-index:10;'
  document.body.appendChild(optimizeBtn)

  toggleBtn.onclick = () => {
    overdrawMode = !overdrawMode
    meshes.forEach(mesh => {
      if (overdrawMode) {
        mesh.material = overdrawMat
      } else {
        mesh.material = normalMaterials.get(mesh)!
      }
    })
    infoEl.textContent = overdrawMode ? 'Overdraw 可视化：绿色越亮 = 重绘次数越多' : '正常渲染模式'
  }

  optimizeBtn.onclick = () => {
    meshes.forEach((mesh, i) => {
      mesh.renderOrder = i

    if (overdrawMode) {

      toggleBtn.click()

  }

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)

  }
```

**要点**：
- AdditiveBlending + 低 opacity 是 Overdraw 可视化的标准方法，叠加越多次颜色越亮
- `renderOrder` 控制渲染顺序，从前到后渲染可以利用 Early-Z 剔除减少片元着色
- `DoubleSide` 渲染正反两面，改为 `FrontSide` 可以直接减半 overdraw
- Overdraw 可视化是定性工具（看哪里重），不是定量工具（不能精确知道重了几遍）

### 练习四

**思路**：移动端优化是一个渐进过程——先建立基准帧率，然后依次应用优化策略并记录每步的帧率变化。关键策略：Instancing 合批、降低 pixelRatio、简化材质（Standard → Basic/Lambert）、减少阴影、降低分辨率。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import GUI from 'lil-gui'

function createMobileOptimizationDemo() {
  const scene = new THREE.Scene()
  scene.background = new THREE.Color(0x1a1a2e)
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 200)
  camera.position.set(0, 15, 30)

  const renderer = new THREE.WebGLRenderer({ antialias: false, powerPreference: 'high-performance' })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(1)
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true
  controls.autoRotate = true
  controls.autoRotateSpeed = 1

  scene.add(new THREE.AmbientLight(0xffffff, 0.6))
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.8)
  dirLight.position.set(5, 10, 5)
  scene.add(dirLight)

  const OBJECT_COUNT = 500
  const geometries = [
    new THREE.BoxGeometry(0.5, 0.5, 0.5),
    new THREE.SphereGeometry(0.3, 16, 16),
    new THREE.ConeGeometry(0.3, 0.6, 16)
  ]

  interface OptimizationState {
    useInstancing: boolean
    pixelRatio: number
    materialType: 'standard' | 'lambert' | 'basic'
    resolutionScale: number
    useShadows: boolean
  }

  const state: OptimizationState = {
    useInstancing: false,
    pixelRatio: 1,
    materialType: 'standard',
    resolutionScale: 1,
    useShadows: false
  }

  let individualMeshes: THREE.Mesh[] = []
  let instancedMeshes: THREE.InstancedMesh[] = []
  const objectData: Array<{ pos: THREE.Vector3; geoIdx: number; color: number }> = []

  for (let i = 0; i < OBJECT_COUNT; i++) {
    objectData.push({
      pos: new THREE.Vector3(
        (Math.random() - 0.5) * 40,
        Math.random() * 5,
        (Math.random() - 0.5) * 40
      ),
      geoIdx: i % 3,
      color: new THREE.Color().setHSL(Math.random(), 0.7, 0.5).getHex()
    })
  }

  function createMaterial(): THREE.Material {
    switch (state.materialType) {
      case 'standard':
        return new THREE.MeshStandardMaterial({ roughness: 0.5, metalness: 0.2 })
      case 'lambert':
        return new THREE.MeshLambertMaterial()
      case 'basic':
        return new THREE.MeshBasicMaterial()
    }
  }

  function rebuildScene() {
    individualMeshes.forEach(m => { scene.remove(m); m.geometry.dispose(); (m.material as THREE.Material).dispose() })
    instancedMeshes.forEach(m => { scene.remove(m); m.dispose() })
    individualMeshes = []
    instancedMeshes = []

    if (state.useInstancing) {
      for (let g = 0; g < geometries.length; g++) {
        const items = objectData.filter(d => d.geoIdx === g)
        if (items.length === 0) continue
        const mat = createMaterial()
        const instMesh = new THREE.InstancedMesh(geometries[g], mat, items.length)
        const dummy = new THREE.Object3D()
        items.forEach((item, i) => {
          dummy.position.copy(item.pos)
          dummy.updateMatrix()
          instMesh.setMatrixAt(i, dummy.matrix)
          instMesh.setColorAt(i, new THREE.Color(item.color))
        })
        instMesh.instanceMatrix.needsUpdate = true
        if (instMesh.instanceColor) instMesh.instanceColor.needsUpdate = true
        scene.add(instMesh)
        instancedMeshes.push(instMesh)
      }
    } else {
      objectData.forEach(item => {
        const mat = createMaterial() as THREE.MeshStandardMaterial
        if ('color' in mat) mat.color.setHex(item.color)
        const mesh = new THREE.Mesh(geometries[item.geoIdx], mat)
        mesh.position.copy(item.pos)
        scene.add(mesh)
        individualMeshes.push(mesh)
      })
    }
  }

  rebuildScene()

  const infoEl = document.createElement('div')
  infoEl.style.cssText = 'position:fixed;top:10px;left:10px;color:#fff;font-size:13px;z-index:10;background:rgba(0,0,0,0.7);padding:10px;border-radius:6px;white-space:pre;'
  document.body.appendChild(infoEl)

  const gui = new GUI({ title: '优化控制' })
  gui.add(state, 'useInstancing').name('Instancing').onChange(() => rebuildScene())
  gui.add(state, 'pixelRatio', [1, 1.5, 2]).name('Pixel Ratio').onChange((v: number) => {
    renderer.setPixelRatio(v)
    renderer.setSize(window.innerWidth, window.innerHeight)
  })
  gui.add(state, 'materialType', ['standard', 'lambert', 'basic']).name('材质类型').onChange(() => rebuildScene())
  gui.add(state, 'resolutionScale', 0.25, 1, 0.25).name('分辨率比例').onChange((v: number) => {
    renderer.setSize(window.innerWidth * v, window.innerHeight * v)
    renderer.domElement.style.width = '100%'
    renderer.domElement.style.height = '100%'
  })

  let frameCount = 0
  let lastTime = performance.now()
  let fps = 0
  const fpsHistory: number[] = []

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth * state.resolutionScale, window.innerHeight * state.resolutionScale)
    renderer.domElement.style.width = '100%'
    renderer.domElement.style.height = '100%'
  })

  function animate() {
    requestAnimationFrame(animate)
    frameCount++
    const now = performance.now()
    if (now - lastTime >= 1000) {
      fps = frameCount
      frameCount = 0
      lastTime = now
      fpsHistory.push(fps)
      if (fpsHistory.length > 10) fpsHistory.shift()
    }

    const avgFps = fpsHistory.length > 0
      ? Math.round(fpsHistory.reduce((a, b) => a + b) / fpsHistory.length)
      : 0

    infoEl.textContent = [
      `FPS: ${fps} (均值: ${avgFps})`,
      `Draw Call: ${renderer.info.render.calls}`,
      `三角形: ${renderer.info.render.triangles.toLocaleString()}`,
      `模式: ${state.useInstancing ? 'Instancing' : '独立Mesh'}`,
      `材质: ${state.materialType}`,
      `DPR: ${state.pixelRatio}`,
      `分辨率: ${Math.round(state.resolutionScale * 100)}%`
    ].join('\n')

    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}

createMobileOptimizationDemo()
```

**要点**：
- 移动端优化的核心原则是"先测量，再优化"，每步只改一个变量并记录帧率
- Instancing 是收益最大的优化（Draw Call 从 500 降到 3），应优先应用
- 材质从 Standard → Lambert → Basic 逐级简化，Standard 有 PBR 计算开销，Basic 只有颜色
- 分辨率降低（如 0.75x）对帧率提升显著，因为片元着色器的执行量与像素数成正比
