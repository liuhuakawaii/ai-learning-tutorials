# 数据可视化 3D：用 Three.js 让数据"活"起来

## 现象

你有一份城市人口数据，用 ECharts 画了一个柱状图——能看，但不震撼。如果把这些柱子放到 3D 城市地图上，每个建筑的高度代表人口密度，颜色代表收入水平——数据就有了空间感。

3D 数据可视化的核心：把数据维度映射到视觉维度。

## 视觉编码映射

```
数据维度    →    视觉维度
数值大小    →    高度 / 大小
类别        →    颜色
时间        →    位置 / 动画
关系        →    连线 / 距离
密度        →    透明度 / 粒子密度
```

## 3D 柱状图

```typescript
import * as THREE from 'three'

function createBarChart3D(data: { x: number; z: number; value: number; category: string }[]) {
  const group = new THREE.Group()

  const colorMap = {
    'A': 0x4a90d9,
    'B': 0xe74c3c,
    'C': 0x2ecc71
  }

  for (const item of data) {
    const height = item.value * 0.1
    const geometry = new THREE.BoxGeometry(0.8, height, 0.8)
    const material = new THREE.MeshStandardMaterial({
      color: colorMap[item.category] || 0xffffff,
      roughness: 0.3
    })

    const bar = new THREE.Mesh(geometry, material)
    bar.position.set(item.x, height / 2, item.z)
    bar.castShadow = true

    // 存储数据引用
    bar.userData = { ...item }

    group.add(bar)
  }

  return group
}
```

## 3D 散点图

```typescript
function createScatterPlot3D(data: { x: number; y: number; z: number; size: number; color: number }[]) {
  const geometry = new THREE.BufferGeometry()
  const positions = new Float32Array(data.length * 3)
  const colors = new Float32Array(data.length * 3)
  const sizes = new Float32Array(data.length)

  for (let i = 0; i < data.length; i++) {
    positions[i * 3] = data[i].x
    positions[i * 3 + 1] = data[i].y
    positions[i * 3 + 2] = data[i].z

    const color = new THREE.Color(data[i].color)
    colors[i * 3] = color.r
    colors[i * 3 + 1] = color.g
    colors[i * 3 + 2] = color.b

    sizes[i] = data[i].size
  }

  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
  geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3))
  geometry.setAttribute('size', new THREE.BufferAttribute(sizes, 1))

  const material = new THREE.ShaderMaterial({
    uniforms: {},
    vertexShader: `
      attribute float size;
      attribute vec3 color;
      varying vec3 v_color;
      void main() {
        v_color = color;
        vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
        gl_Position = projectionMatrix * mvPosition;
        gl_PointSize = size * (200.0 / -mvPosition.z);
      }
    `,
    fragmentShader: `
      varying vec3 v_color;
      void main() {
        float dist = length(gl_PointCoord - vec2(0.5));
        if (dist > 0.5) discard;
        gl_FragColor = vec4(v_color, 1.0);
      }
    `,
    vertexColors: true
  })

  return new THREE.Points(geometry, material)
}
```

## 交互：数据标注

```typescript
function createDataLabel(text: string, position: THREE.Vector3): THREE.Sprite {
  const canvas = document.createElement('canvas')
  canvas.width = 256; canvas.height = 64
  const ctx = canvas.getContext('2d')!
  ctx.fillStyle = 'rgba(0,0,0,0.7)'
  ctx.roundRect(0, 0, 256, 64, 8)
  ctx.fill()
  ctx.fillStyle = 'white'
  ctx.font = '24px system-ui'
  ctx.fillText(text, 16, 40)

  const texture = new THREE.CanvasTexture(canvas)
  const material = new THREE.SpriteMaterial({ map: texture })
  const sprite = new THREE.Sprite(material)
  sprite.position.copy(position)
  sprite.scale.set(2, 0.5, 1)

  return sprite
}
```

## 你可能踩的坑

**坑一：数据量太大导致卡顿**

几千个柱子或几万个散点就可能卡。用 InstancedMesh 或 GPU 粒子。

**坑二：3D 图表不直观**

3D 图表看起来酷，但读取精确数值比 2D 困难。提供 tooltip 和辅助线。

**坑三：相机角度影响数据判读**

某些角度会遮挡数据。提供预设视角按钮。

```typescript
function createHeatmap3D(data: number[][], cellSize: number) {
  const group = new THREE.Group()
  const maxVal = Math.max(...data.flat())

  for (let x = 0; x < data.length; x++) {
    for (let z = 0; z < data[x].length; z++) {
      const value = data[x][z] / maxVal
      const height = value * 5
      const color = new THREE.Color().setHSL((1 - value) * 0.7, 1, 0.5)

      const geometry = new THREE.BoxGeometry(cellSize, height, cellSize)
      const material = new THREE.MeshStandardMaterial({ color, roughness: 0.5 })
      const cell = new THREE.Mesh(geometry, material)
      cell.position.set(x * cellSize, height / 2, z * cellSize)
      group.add(cell)
    }
  }

  return group
}
```

```typescript
import gsap from 'gsap'

function animateBarHeight(bar: THREE.Mesh, newHeight: number) {
  gsap.to(bar.scale, { y: newHeight / bar.geometry.parameters.height, duration: 0.5 })
  gsap.to(bar.position, { y: newHeight / 2, duration: 0.5 })
}
```
