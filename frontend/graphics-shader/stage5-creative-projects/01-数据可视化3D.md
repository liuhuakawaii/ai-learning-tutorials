# 数据可视化 3D

## 场景引入

传统的 2D 图表在展示复杂数据关系时力不从心——当你需要同时展示地理位置、时间维度和数值大小时，二维平面很快变得拥挤不堪。Three.js 结合 WebGL 能让我们将百万级数据点渲染为交互式 3D 场景：柱状图在三维空间中排列、散点图悬浮于虚拟坐标系、地球仪上热力图随数据实时变化。本课将带你从零构建一套完整的 3D 数据可视化系统。

## 学习目标

1. 掌握 Three.js 中 3D 柱状图、散点图、折线图的实现方法
2. 理解地理数据可视化（Globe / Mapbox）的核心原理
3. 学会使用 InstancedMesh 渲染大规模数据点
4. 实现数据驱动的颜色映射（Color Mapping）
5. 掌握 D3.js 与 Three.js 的集成方案

## 3D 柱状图基础

3D 柱状图的核心思路是：每个数据点对应一个拉伸的 BoxGeometry，高度映射数值，颜色映射分类或区间。

```
数据集 → 归一化 → 几何体生成 → 材质着色 → 场景组装
  │         │          │            │           │
  │      [0,1]    BoxGeometry   ColorRamp    Scene
  │         ↑          ↑            ↑
  │     min/max     width/depth   gradient
  └── raw values
```

```typescript
import * as THREE from 'three'

interface DataPoint {
  label: string
  value: number
  category: string
}

function createBarChart(data: DataPoint[]): THREE.Group {
  const group = new THREE.Group()
  const maxVal = Math.max(...data.map(d => d.value))
  const barWidth = 0.8
  const gap = 0.2
  const colorMap = new THREE.Color()

  data.forEach((point, i) => {
    const normalizedHeight = point.value / maxVal
    const height = normalizedHeight * 10
    const geometry = new THREE.BoxGeometry(barWidth, height, barWidth)
    geometry.translate(0, height / 2, 0)

    const hue = (i / data.length) * 0.7
    colorMap.setHSL(hue, 0.8, 0.5)
    const material = new THREE.MeshStandardMaterial({ color: colorMap.clone() })

    const mesh = new THREE.Mesh(geometry, material)
    mesh.position.x = i * (barWidth + gap)
    mesh.userData = { label: point.label, value: point.value }
    group.add(mesh)
  })

  group.position.x = -(data.length * (barWidth + gap)) / 2
  return group
}
```

每个柱体的 `userData` 存储原始数据，方便后续射线拾取（Raycasting）实现交互。

## 散点图与折线图

散点图用 `BufferGeometry` 批量管理点位，比逐个创建 Mesh 高效得多：

```typescript
function createScatterPlot(points: [number, number, number][]): THREE.Points {
  const positions = new Float32Array(points.length * 3)
  const colors = new Float32Array(points.length * 3)

  points.forEach(([x, y, z], i) => {
    positions[i * 3] = x
    positions[i * 3 + 1] = y
    positions[i * 3 + 2] = z

    const t = y / 100
    const color = new THREE.Color().setHSL(0.6 - t * 0.6, 0.9, 0.5)
    colors[i * 3] = color.r
    colors[i * 3 + 1] = color.g
    colors[i * 3 + 2] = color.b
  })

  const geometry = new THREE.BufferGeometry()
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
  geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3))

  const material = new THREE.PointsMaterial({
    size: 0.15,
    vertexColors: true,
    transparent: true,
    opacity: 0.8,
  })

  return new THREE.Points(geometry, material)
}
```

function createLineChart(data: [number, number][]): THREE.Line {
  const curve = new THREE.CatmullRomCurve3(
    data.map(([x, y]) => new THREE.Vector3(x, y, 0))
  )

## 地理数据可视化

### Globe 实现

地球可视化的核心是将经纬度转换为球面坐标：

```
经纬度 → 弧度 → 球面坐标 (x, y, z)

lat/lon (度) → lat/lon (弧度) →
  x = R * cos(lat) * cos(lon)
  y = R * sin(lat)
  z = R * cos(lat) * sin(lon)
```

```typescript
function latLonToVector3(lat: number, lon: number, radius: number): THREE.Vector3 {
  const phi = (90 - lat) * (Math.PI / 180)
  const theta = (lon + 180) * (Math.PI / 180)
  return new THREE.Vector3(
    -(radius * Math.sin(phi) * Math.cos(theta)),
    radius * Math.cos(phi),
    radius * Math.sin(phi) * Math.sin(theta)
  )
}

function plotDataOnGlobe(
  data: Array<{ lat: number; lon: number; value: number }>,
  radius: number
): THREE.Group {
  const group = new THREE.Group()
  data.forEach(d => {
    const pos = latLonToVector3(d.lat, d.lon, radius)
    const color = new THREE.Color().setHSL(0.6 - d.value * 0.6, 0.9, 0.5)
    const barHeight = d.value * 2
    const barGeo = new THREE.CylinderGeometry(0.02, 0.02, barHeight, 8)
    barGeo.translate(0, barHeight / 2, 0)
    const bar = new THREE.Mesh(barGeo, new THREE.MeshBasicMaterial({ color }))
    bar.position.copy(pos)
    bar.lookAt(new THREE.Vector3(0, 0, 0))
    bar.rotateX(Math.PI / 2)
    group.add(bar)
  })
  return group
}
```

## InstancedMesh 大数据量渲染

当数据点超过 10 万个时，逐个 Mesh 的方式会因 Draw Call 过多而崩溃。InstancedMesh 将同一几何体的多个实例合并为一次绘制调用：

```
传统方式: 100,000 Mesh = 100,000 Draw Calls  →  卡死
InstancedMesh: 100,000 实例 = 1 Draw Call   →  流畅
```

```typescript
function createInstancedScatter(
  data: Float32Array,
  count: number
): THREE.InstancedMesh {
  const geometry = new THREE.SphereGeometry(0.05, 8, 8)
  const material = new THREE.MeshStandardMaterial()
  const mesh = new THREE.InstancedMesh(geometry, material, count)

  const dummy = new THREE.Object3D()
  const color = new THREE.Color()
  const maxVal = 100

  for (let i = 0; i < count; i++) {
    const x = data[i * 3]
    const y = data[i * 3 + 1]
    const z = data[i * 3 + 2]

    dummy.position.set(x, y, z)
    dummy.updateMatrix()
    mesh.setMatrixAt(i, dummy.matrix)

    const t = y / maxVal
    color.setHSL(0.6 - t * 0.6, 0.8, 0.5)
    mesh.setColorAt(i, color)
  }

  mesh.instanceMatrix.needsUpdate = true
  if (mesh.instanceColor) mesh.instanceColor.needsUpdate = true
  return mesh
}
```

## 数据驱动的颜色映射

颜色映射是数据可视化的灵魂。常用策略：

```
Sequential:  深 → 浅（单色渐变，适合连续数据）
Diverging:   冷色 → 中性 → 暖色（适合有中心点的数据）
Categorical: 离散色板（适合分类数据）

RGB 色带示意:
  低值 ████████████████████████████ 高值
  #0000ff ────────────────── #ff0000
  (蓝)      (青→绿→黄)        (红)
```

```typescript
function valueToColor(value: number, min: number, max: number): THREE.Color {
  const t = (value - min) / (max - min)
  const color = new THREE.Color()
  color.setHSL(0.66 * (1 - t), 0.9, 0.5)
  return color
}

function createLegend(
  min: number,
  max: number,
  steps: number = 10
): HTMLCanvasElement {

  canvas.width = 256
  canvas.height = 20
  const ctx = canvas.getContext('2d')!
  for (let i = 0; i < steps; i++) {

    ctx.fillRect((i / steps) * 256, 0, 256 / steps + 1, 20)
  }

}
```

## 交互式数据探索

通过 Raycasting 实现鼠标悬停和点击交互：

```typescript
class DataExplorer {
  private raycaster = new THREE.Raycaster()
  private mouse = new THREE.Vector2()
  private tooltip: HTMLDivElement
  private camera: THREE.Camera
  private targets: THREE.Object3D[]

  constructor(camera: THREE.Camera, targets: THREE.Object3D[]) {
    this.camera = camera
    this.targets = targets
    this.tooltip = document.createElement('div')
    Object.assign(this.tooltip.style, {
      position: 'absolute',
      padding: '8px 12px',
      background: 'rgba(0,0,0,0.8)',
      color: '#fff',
      borderRadius: '4px',
      fontSize: '13px',
      pointerEvents: 'none',
      display: 'none',
    })
    document.body.appendChild(this.tooltip)
  }

  onMouseMove(event: MouseEvent) {
    this.mouse.x = (event.clientX / window.innerWidth) * 2 - 1
    this.mouse.y = -(event.clientY / window.innerHeight) * 2 + 1
    this.raycaster.setFromCamera(this.mouse, this.camera)
    const intersects = this.raycaster.intersectObjects(this.targets)

    if (intersects.length > 0) {
      const obj = intersects[0].object
      const { label, value } = obj.userData
      this.tooltip.style.display = 'block'
      this.tooltip.style.left = event.clientX + 10 + 'px'
      this.tooltip.style.top = event.clientY + 10 + 'px'
      this.tooltip.textContent = `${label}: ${value}`
    } else {
      this.tooltip.style.display = 'none'
    }
  }
}
```

## D3.js + Three.js 集成

D3 擅长数据处理和比例尺计算，Three.js 擅长 3D 渲染。最佳实践是用 D3 做数据转换，用 Three.js 做渲染：

```typescript
import * as d3 from 'd3'

interface RawData {
  country: string
  gdp: number
  population: number
  continent: string
}

function processDataWithD3(data: RawData[]) {
  const xScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.population)!])
    .range([-5, 5])

  const yScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.gdp)!])
    .range([0, 10])

  const colorScale = d3.scaleOrdinal(d3.schemeCategory10)
    .domain([...new Set(data.map(d => d.continent))])

  return data.map(d => ({
    position: new THREE.Vector3(xScale(d.population), yScale(d.gdp), 0),
    color: new THREE.Color(colorScale(d.continent)),
    label: d.country,
    value: d.gdp,
  }))
}
```

## 常见误区

1. **逐个创建 Mesh 而非使用 InstancedMesh**：数据量超过 1000 个对象时，InstancedMesh 能将 Draw Call 从上千次压缩到个位数，性能差距可达百倍。

2. **在每一帧都执行 Raycasting**：射线检测是 O(n) 操作，数据量大时应先用空间分区（如 Octree）缩小检测范围，或者只在鼠标移动时才触发。

3. **忽略颜色映射的感知均匀性**：RGB 线性插值在视觉上并不均匀，人眼对绿色更敏感。应使用 HSL 或专用色彩空间（如 Lab）进行插值，或直接使用 d3-scale-chromatic 提供的感知均匀色带。

4. **数据更新时销毁并重建整个场景**：应该只更新 BufferAttribute 中变化的部分，设置 `needsUpdate = true` 即可，避免频繁的内存分配和 GC。

## 工程建议

1. **数据预处理在 Worker 中完成**：大规模数据的归一化、聚合、过滤等计算放到 Web Worker 中，避免阻塞主线程的渲染循环。

2. **使用 Float32Array 统一管理顶点数据**：避免使用 JavaScript 对象数组传递坐标，Float32Array 的内存布局与 GPU 直接兼容，上传效率最高。

3. **实现渐进式渲染**：百万级数据不要一次性全部添加到场景，先渲染低精度的聚合视图，用户缩放时再按需加载细节层级。

4. **导出 Canvas 为图片**：`renderer.domElement.toDataURL()` 可以让用户导出当前视图为 PNG，这在数据报告场景中非常实用。

## 小结

本课学习了 3D 数据可视化的完整技术栈：从基础的柱状图、散点图、折线图，到地理数据的 Globe 可视化，再到大规模数据的 InstancedMesh 渲染优化。关键在于理解数据到视觉属性的映射关系——数值映射高度/大小，分类映射颜色，地理位置映射球面坐标。D3.js 负责数据转换，Three.js 负责 3D 渲染，两者配合是目前最成熟的方案。

### 练习一

**思路**：3D 柱状图需要三个核心交互——悬停显示数值（Raycaster 检测 + CSS Tooltip）、点击高亮（切换材质 emissive 属性）、拖拽旋转（OrbitControls）。关键是将数据绑定到 Mesh 的 userData 上，Raycaster 命中时从中读取原始数据。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

interface DataItem {
  label: string
  value: number
  category: string
}

const categoryColors: Record<string, string> = {
  A: '#4fc3f7', B: '#81c784', C: '#ffb74d', D: '#e57373'
}

function createBarChart(data: DataItem[]) {
  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000)
  camera.position.set(12, 10, 12)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true

  const maxVal = Math.max(...data.map(d => d.value))
  const bars: THREE.Mesh[] = []
  const cols = Math.ceil(Math.sqrt(data.length))

  data.forEach((item, i) => {
    const normalizedHeight = (item.value / maxVal) * 5
    const geo = new THREE.BoxGeometry(0.8, normalizedHeight, 0.8)
    const mat = new THREE.MeshStandardMaterial({
      color: categoryColors[item.category] || '#ffffff'
    })
    const bar = new THREE.Mesh(geo, mat)
    bar.position.set(
      (i % cols) * 1.2 - (cols * 1.2) / 2,
      normalizedHeight / 2,
      Math.floor(i / cols) * 1.2 - (cols * 1.2) / 2
    )
    bar.userData = { label: item.label, value: item.value, originalEmissive: new THREE.Color(0x000000) }
    scene.add(bar)
    bars.push(bar)
  })

  const ambientLight = new THREE.AmbientLight(0xffffff, 0.6)
  scene.add(ambientLight)
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.8)
  dirLight.position.set(5, 10, 5)
  scene.add(dirLight)

  const raycaster = new THREE.Raycaster()
  const mouse = new THREE.Vector2()
  let selectedBar: THREE.Mesh | null = null
  let hoveredBar: THREE.Mesh | null = null

  const tooltip = document.createElement('div')
  tooltip.style.cssText = 'position:fixed;padding:6px 12px;background:rgba(0,0,0,0.8);color:#fff;border-radius:4px;font-size:13px;pointer-events:none;display:none;z-index:10;'
  document.body.appendChild(tooltip)

  renderer.domElement.addEventListener('mousemove', (e) => {
    mouse.x = (e.clientX / window.innerWidth) * 2 - 1
    mouse.y = -(e.clientY / window.innerHeight) * 2 + 1
    raycaster.setFromCamera(mouse, camera)
    const hits = raycaster.intersectObjects(bars)

    if (hoveredBar && hoveredBar !== selectedBar) {
      ;(hoveredBar.material as THREE.MeshStandardMaterial).emissive.set(0x000000)
    }
    hoveredBar = null

    if (hits.length > 0) {
      const bar = hits[0].object as THREE.Mesh
      hoveredBar = bar
      if (bar !== selectedBar) {
        ;(bar.material as THREE.MeshStandardMaterial).emissive.set(0x333333)
      }
      tooltip.style.display = 'block'
      tooltip.style.left = e.clientX + 10 + 'px'
      tooltip.style.top = e.clientY - 30 + 'px'
      tooltip.textContent = `${bar.userData.label}: ${bar.userData.value}`
    } else {
      tooltip.style.display = 'none'
    }
  })

  renderer.domElement.addEventListener('click', () => {
    if (selectedBar) {
      ;(selectedBar.material as THREE.MeshStandardMaterial).emissive.set(0x000000)
    }
    if (hoveredBar) {
      selectedBar = hoveredBar
      ;(selectedBar.material as THREE.MeshStandardMaterial).emissive.set(0x666600)
    } else {
      selectedBar = null
    }
  })

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  function animate() {
    requestAnimationFrame(animate)
    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}

const sampleData: DataItem[] = Array.from({ length: 16 }, (_, i) => ({
  label: `Item-${i}`,
  value: Math.random() * 100,
  category: ['A', 'B', 'C', 'D'][i % 4]
}))
createBarChart(sampleData)
```

**要点**：
- Raycaster 需要在每一帧根据鼠标位置更新，不能只在 click 事件中调用
- 通过 `userData` 将业务数据绑定到 Three.js 对象上，命中时直接读取
- OrbitControls 的 `enableDamping` 让旋转有惯性，体验更自然
- Tooltip 用 CSS 定位而非 3D 文本，渲染成本低且清晰度高

### 练习二

**思路**：地球仪的核心是球体 + 经纬度到 3D 坐标的转换。每个国家的 GDP 数据映射为柱体高度，洲映射颜色。柱体从球面沿法线方向（即球心到该点的方向）向外延伸。自动旋转通过在 animate 循环中递增 `rotation.y` 实现。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

interface CountryData {
  name: string
  lat: number
  lon: number
  gdp: number
  continent: string
}

const continentColors: Record<string, string> = {
  Asia: '#ff7043', Europe: '#42a5f5', Africa: '#66bb6a',
  'North America': '#ab47bc', 'South America': '#ffa726', Oceania: '#26c6da'
}

function latLonToVector3(lat: number, lon: number, radius: number): THREE.Vector3 {
  const phi = (90 - lat) * (Math.PI / 180)
  const theta = (lon + 180) * (Math.PI / 180)
  return new THREE.Vector3(
    -radius * Math.sin(phi) * Math.cos(theta),
    radius * Math.cos(phi),
    radius * Math.sin(phi) * Math.sin(theta)
  )
}

function createGlobe(data: CountryData[]) {
  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000)
  camera.position.set(0, 0, 4)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true
  controls.autoRotate = true
  controls.autoRotateSpeed = 0.5

  const globeGroup = new THREE.Group()
  scene.add(globeGroup)

  const earthGeo = new THREE.SphereGeometry(1, 64, 64)
  const earthMat = new THREE.MeshStandardMaterial({
    color: 0x1a237e, roughness: 0.8, metalness: 0.1
  })
  globeGroup.add(new THREE.Mesh(earthGeo, earthMat))

  const maxGdp = Math.max(...data.map(d => d.gdp))
  data.forEach(country => {
    const surfacePos = latLonToVector3(country.lat, country.lon, 1)
    const barHeight = (country.gdp / maxGdp) * 0.5
    const barGeo = new THREE.CylinderGeometry(0.01, 0.01, barHeight, 8)
    const barMat = new THREE.MeshStandardMaterial({
      color: continentColors[country.continent] || '#ffffff'
    })
    const bar = new THREE.Mesh(barGeo, barMat)

    bar.position.copy(surfacePos.clone().multiplyScalar(1 + barHeight / 2))
    bar.lookAt(new THREE.Vector3(0, 0, 0))
    bar.rotateX(Math.PI / 2)
    bar.userData = { name: country.name, gdp: country.gdp }
    globeGroup.add(bar)
  })

  scene.add(new THREE.AmbientLight(0xffffff, 0.5))
  const sunLight = new THREE.DirectionalLight(0xffffff, 1)
  sunLight.position.set(5, 3, 5)
  scene.add(sunLight)

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  function animate() {
    requestAnimationFrame(animate)
    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}

const sampleData: CountryData[] = [
  { name: 'China', lat: 35, lon: 105, gdp: 17.7, continent: 'Asia' },
  { name: 'USA', lat: 38, lon: -97, gdp: 25.5, continent: 'North America' },
  { name: 'Germany', lat: 51, lon: 10, gdp: 4.2, continent: 'Europe' },
  { name: 'Brazil', lat: -14, lon: -51, gdp: 1.9, continent: 'South America' },
  { name: 'Nigeria', lat: 10, lon: 8, gdp: 0.47, continent: 'Africa' },
  { name: 'Australia', lat: -25, lon: 133, gdp: 1.7, continent: 'Oceania' },
]
createGlobe(sampleData)
```

**要点**：
- `latLonToVector3` 是地理可视化的核心函数，将经纬度转为球面 3D 坐标
- 柱体方向需通过 `lookAt(球心)` + `rotateX(PI/2)` 使其沿球面法线向外延伸
- 将地球和所有柱体放入 `Group`，整体旋转时不会影响各自的相对位置
- `autoRotate` 配合 `enableDamping` 产生缓慢自转效果，用户拖拽后会继续自转

### 练习三

**思路**：10 万个点必须用 InstancedMesh 渲染，否则 Draw Call 会直接卡死。LOD 的核心思想是根据相机距离动态调整每个实例的缩放——远处的点更大以保持可见性，近处的点更小以避免遮挡。搜索/过滤通过修改实例矩阵（将不需要的点缩放为 0）实现。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

const COUNT = 100000

function createScatterPlot() {
  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000)
  camera.position.set(0, 0, 50)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true

  const positions: Float32Array = new Float32Array(COUNT * 3)
  const colors: Float32Array = new Float32Array(COUNT * 3)
  const categories: number[] = []
  const colorPalette = [
    new THREE.Color('#4fc3f7'), new THREE.Color('#81c784'),
    new THREE.Color('#ffb74d'), new THREE.Color('#e57373'),
    new THREE.Color('#ce93d8')
  ]

  for (let i = 0; i < COUNT; i++) {
    positions[i * 3] = (Math.random() - 0.5) * 80
    positions[i * 3 + 1] = (Math.random() - 0.5) * 80
    positions[i * 3 + 2] = (Math.random() - 0.5) * 80
    const cat = Math.floor(Math.random() * 5)
    categories.push(cat)
    colors[i * 3] = colorPalette[cat].r
    colors[i * 3 + 1] = colorPalette[cat].g
    colors[i * 3 + 2] = colorPalette[cat].b
  }

  const geo = new THREE.SphereGeometry(0.1, 8, 8)
  const mat = new THREE.MeshStandardMaterial()
  const instancedMesh = new THREE.InstancedMesh(geo, mat, COUNT)
  instancedMesh.instanceColor = new THREE.InstancedBufferAttribute(colors, 3)

  const dummy = new THREE.Object3D()
  const visibleFlags = new Uint8Array(COUNT).fill(1)
  const baseScale = 1

  function updateInstances() {
    const camPos = camera.position
    for (let i = 0; i < COUNT; i++) {
      if (visibleFlags[i] === 0) {
        dummy.position.set(positions[i * 3], positions[i * 3 + 1], positions[i * 3 + 2])
        dummy.scale.set(0, 0, 0)
      } else {
        const dx = positions[i * 3] - camPos.x
        const dy = positions[i * 3 + 1] - camPos.y
        const dz = positions[i * 3 + 2] - camPos.z
        const dist = Math.sqrt(dx * dx + dy * dy + dz * dz)
        const lodScale = THREE.MathUtils.clamp(dist / 20, 0.3, 3) * baseScale
        dummy.position.set(positions[i * 3], positions[i * 3 + 1], positions[i * 3 + 2])
        dummy.scale.setScalar(lodScale)
      }
      dummy.updateMatrix()
      instancedMesh.setMatrixAt(i, dummy.matrix)
    }
    instancedMesh.instanceMatrix.needsUpdate = true
  }

  scene.add(instancedMesh)
  scene.add(new THREE.AmbientLight(0xffffff, 0.6))
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.8)
  dirLight.position.set(10, 10, 10)
  scene.add(dirLight)

  const searchInput = document.createElement('input')
  searchInput.placeholder = '输入类别编号 (0-4) 过滤...'
  searchInput.style.cssText = 'position:fixed;top:10px;left:10px;padding:8px;font-size:14px;z-index:10;'
  document.body.appendChild(searchInput)

  searchInput.addEventListener('input', () => {
    const query = searchInput.value.trim()
    for (let i = 0; i < COUNT; i++) {
      visibleFlags[i] = query === '' || categories[i].toString() === query ? 1 : 0
    }
    updateInstances()
  })

  window.addEventListener('resize', () => {
    camera.aspect = window.innerWidth / window.innerHeight
    camera.updateProjectionMatrix()
    renderer.setSize(window.innerWidth, window.innerHeight)
  })

  updateInstances()
  function animate() {
    requestAnimationFrame(animate)
    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}

createScatterPlot()
```

**要点**：
- InstancedMesh 是渲染大量相同几何体的唯一可行方案，10 万个点只有 1 个 Draw Call
- LOD 通过距离计算动态缩放实例，远处点更大保证可见性
- "隐藏"实例的方法是将其 scale 设为 0，而不是从 InstancedMesh 中移除（后者会重建缓冲区）
- `instanceMatrix.needsUpdate` 必须设为 true 才能将 CPU 端的矩阵变化上传到 GPU

### 练习四

**思路**：D3 的 `d3-force-3d` 模块支持三维力导向布局。核心是创建 ForceSimulation，添加 charge（排斥力）、link（连接弹簧力）、center（居中力），在 Three.js 的 animate 循环中 tick simulation 并更新节点位置。节点大小映射度数（连接数），颜色映射社区 ID。

**答案**：

```typescript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

interface GraphNode {
  id: number
  community: number
  degree: number
  x?: number; y?: number; z?: number
  vx?: number; vy?: number; vz?: number
  fx?: number; fy?: number; fz?: number
}

interface GraphLink {
  source: number
  target: number
}

function createForceGraph(nodes: GraphNode[], links: GraphLink[]) {
  const scene = new THREE.Scene()
  const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000)
  camera.position.set(0, 0, 80)

  const renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setSize(window.innerWidth, window.innerHeight)
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  document.body.appendChild(renderer.domElement)

  const controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true

  const communityColors = [
    0x4fc3f7, 0x81c784, 0xffb74d, 0xe57373, 0xce93d8, 0x26c6da, 0xffee58
  ]

  const nodeMeshes: THREE.Mesh[] = []
  const maxDegree = Math.max(...nodes.map(n => n.degree))

  nodes.forEach(node => {
    const size = 0.3 + (node.degree / maxDegree) * 1.5
    const geo = new THREE.SphereGeometry(size, 16, 16)
    const mat = new THREE.MeshStandardMaterial({
      color: communityColors[node.community % communityColors.length]
    })
    const mesh = new THREE.Mesh(geo, mat)
    mesh.userData = { id: node.id, degree: node.degree }
    scene.add(mesh)
    nodeMeshes.push(mesh)
  })

  const linePositions = new Float32Array(links.length * 6)
  const lineGeo = new THREE.BufferGeometry()
  lineGeo.setAttribute('position', new THREE.BufferAttribute(linePositions, 3))
  const lineMat = new THREE.LineBasicMaterial({ color: 0x444466, transparent: true, opacity: 0.4 })
  const lines = new THREE.LineSegments(lineGeo, lineMat)
  scene.add(lines)

  scene.add(new THREE.AmbientLight(0xffffff, 0.6))
  const dirLight = new THREE.DirectionalLight(0xffffff, 0.8)
  dirLight.position.set(10, 10, 10)
  scene.add(dirLight)

  // 简化版力导向模拟（实际项目中用 d3-force-3d）
  function simulateStep(alpha: number) {
    const repulsion = 500
    const attraction = 0.01
    const centerForce = 0.01

    for (let i = 0; i < nodes.length; i++) {
      if (!nodes[i].vx) { nodes[i].vx = 0; nodes[i].vy = 0; nodes[i].vz = 0 }
      if (!nodes[i].x) { nodes[i].x = (Math.random() - 0.5) * 40; nodes[i].y = (Math.random() - 0.5) * 40; nodes[i].z = (Math.random() - 0.5) * 40 }

      for (let j = i + 1; j < nodes.length; j++) {
        if (!nodes[j].x) { nodes[j].x = (Math.random() - 0.5) * 40; nodes[j].y = (Math.random() - 0.5) * 40; nodes[j].z = (Math.random() - 0.5) * 40 }
        let dx = nodes[i].x! - nodes[j].x!
        let dy = nodes[i].y! - nodes[j].y!
        let dz = nodes[i].z! - nodes[j].z!
        let dist = Math.sqrt(dx * dx + dy * dy + dz * dz) || 0.1
        let force = repulsion / (dist * dist)
        const fx = (dx / dist) * force * alpha
        const fy = (dy / dist) * force * alpha
        const fz = (dz / dist) * force * alpha
        nodes[i].vx! += fx; nodes[i].vy! += fy; nodes[i].vz! += fz
        nodes[j].vx! -= fx; nodes[j].vy! -= fy; nodes[j].vz! -= fz
      }

      nodes[i].vx! -= nodes[i].x! * centerForce * alpha
      nodes[i].vy! -= nodes[i].y! * centerForce * alpha
      nodes[i].vz! -= nodes[i].z! * centerForce * alpha
    }

    links.forEach(link => {
      const s = nodes[link.source], t = nodes[link.target]
      const dx = t.x! - s.x!, dy = t.y! - s.y!, dz = t.z! - s.z!
      const dist = Math.sqrt(dx * dx + dy * dy + dz * dz) || 0.1
      const force = (dist - 5) * attraction * alpha
      const fx = (dx / dist) * force, fy = (dy / dist) * force, fz = (dz / dist) * force
      s.vx! += fx; s.vy! += fy; s.vz! += fz
      t.vx! -= fx; t.vy! -= fy; t.vz! -= fz
    })

    nodes.forEach((node, i) => {
      node.vx! *= 0.9; node.vy! *= 0.9; node.vz! *= 0.9
      node.x! += node.vx!; node.y! += node.vy!; node.z! += node.vz!
      nodeMeshes[i].position.set(node.x!, node.y!, node.z!)
    })
  }

  let alpha = 1
  function animate() {
    requestAnimationFrame(animate)
    if (alpha > 0.001) {
      simulateStep(alpha)
      alpha *= 0.995

      let idx = 0
      links.forEach(link => {
        const s = nodes[link.source], t = nodes[link.target]
        linePositions[idx++] = s.x!; linePositions[idx++] = s.y!; linePositions[idx++] = s.z!
        linePositions[idx++] = t.x!; linePositions[idx++] = t.y!; linePositions[idx++] = t.z!
      })
      lineGeo.attributes.position.needsUpdate = true
    }
    controls.update()
    renderer.render(scene, camera)
  }
  animate()
}

// 生成示例图数据
const nodeCount = 60
const graphNodes: GraphNode[] = Array.from({ length: nodeCount }, (_, i) => ({
  id: i, community: i % 5, degree: 0
}))
const graphLinks: GraphLink[] = []
for (let i = 0; i < nodeCount; i++) {
  const linkCount = 1 + Math.floor(Math.random() * 4)
  for (let j = 0; j < linkCount; j++) {
    const target = Math.floor(Math.random() * nodeCount)
    if (target !== i) {
      graphLinks.push({ source: i, target })
      graphNodes[i].degree++
      graphNodes[target].degree++
    }
  }
}
createForceGraph(graphNodes, graphLinks)
```

**要点**：
- 实际项目中应使用 `d3-force-3d` 库而非手写力模拟，这里为演示原理做了简化
- 力导向布局需要多帧迭代才能收敛，用 `alpha` 值衰减控制冷却过程
- 边的几何体用 `LineSegments` + 预分配 Float32Array，每帧更新 position 属性即可
- 节点大小必须在创建时确定（因为 SphereGeometry 的半径在构造时固定），不能后续动态缩放几何体，如需动态大小应使用 InstancedMesh
