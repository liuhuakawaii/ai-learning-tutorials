# 第6课：相机控制与交互

## 场景引入

你打开一个 3D 产品展示页面，鼠标拖拽可以旋转视角，滚轮可以缩放，点击零件会弹出信息卡片。这种"用鼠标和 3D 世界交互"的体验，是 3D Web 应用区别于视频和图片的核心价值。Three.js 提供了 OrbitControls（轨道相机控制）、Raycaster（射线检测）和 DragControls（拖拽控制）等工具，让你不用从零实现复杂的数学计算。本课把这些交互能力串联起来，构建一个可交互的 3D 场景。

## 学习目标

1. 掌握 OrbitControls 的配置与常见参数调整
2. 理解 Raycaster 射线检测的原理与实现
3. 学会用鼠标点击选中 3D 物体并做出响应
4. 掌握 DragControls 实现物体拖拽
5. 了解触摸事件支持和自定义相机控制的思路

## 一、OrbitControls 轨道控制

OrbitControls 是最常用的相机控制器，让相机围绕目标点旋转：

```typescript
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";

const controls = new OrbitControls(camera, renderer.domElement);

// 基础配置
controls.target.set(0, 0, 0);     // 相机围绕旋转的目标点
controls.enableDamping = true;      // 开启惯性阻尼（松手后继续滑动）
controls.dampingFactor = 0.05;      // 阻尼系数，越小惯性越大

// 旋转配置
controls.enableRotate = true;       // 允许旋转
controls.rotateSpeed = 0.8;         // 旋转速度
controls.minPolarAngle = 0;         // 最小极角（从顶部往下看的最小角度）
controls.maxPolarAngle = Math.PI;   // 最大极角（默认可以转到背面）

// 缩放配置
controls.enableZoom = true;         // 允许缩放
controls.zoomSpeed = 1.0;           // 缩放速度
controls.minDistance = 1;            // 最近距离
controls.maxDistance = 50;           // 最远距离

// 平移配置
controls.enablePan = true;          // 允许平移
controls.panSpeed = 0.5;            // 平移速度
controls.screenSpacePanning = true; // 在屏幕平面平移（而非世界平面）

// 限制垂直旋转范围（防止翻转到地下）
controls.minPolarAngle = 0.1;
controls.maxPolarAngle = Math.PI / 2 - 0.1;

// 渲染循环中必须调用
function animate(): void {
    requestAnimationFrame(animate);
    controls.update(); // 开启 damping 时必须每帧调用
    renderer.render(scene, camera);
}
animate();
```

```
  OrbitControls 操作方式：

  鼠标左键拖拽 → 旋转视角（围绕目标点）
  鼠标右键拖拽 → 平移视角（移动目标点）
  鼠标滚轮    → 缩放（改变相机到目标点的距离）
  触摸单指拖拽 → 旋转
  触摸双指捏合 → 缩放
  触摸双指拖拽 → 平移
```

## 二、Raycaster 射线检测

Raycaster 从相机位置向鼠标位置发射一条射线，检测它与哪些物体相交：

```
  相机位置
      │
      │  ← 射线方向（从相机穿过鼠标位置）
      │
      ▼
  ┌───●───┐   ← 鼠标在屏幕上的位置
  │  物体  │
  └───────┘
      │
      ▼
  交点信息：位置、法线、距离、被击中的对象
```

```typescript
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

function onMouseClick(event: MouseEvent): void {
    // 将鼠标位置归一化到 -1 ~ +1 范围
    const rect = renderer.domElement.getBoundingClientRect();
    mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
    mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;

    // 更新射线
    raycaster.setFromCamera(mouse, camera);

    // 检测与哪些物体相交
    const intersects = raycaster.intersectObjects(scene.children, true);
    // 第二个参数 true = 递归检测子对象

    if (intersects.length > 0) {
        const hit = intersects[0]; // 最近的交点
        console.log("击中物体:", hit.object.name);
        console.log("击中位置:", hit.point);
        console.log("击中法线:", hit.face?.normal);
        console.log("距离:", hit.distance);
    }
}

renderer.domElement.addEventListener("click", onMouseClick);
```

## 三、物体选中与高亮

点击选中物体后，通常需要视觉反馈。核心模式是：取消上次高亮 → 射线检测 → 高亮新物体：

```typescript
let selectedObject: THREE.Object3D | null = null;

function onSelect(event: MouseEvent): void {
    // ... 坐标归一化和射线检测（同上） ...

    // 取消之前的高亮
    if (selectedObject) {
        ((selectedObject as THREE.Mesh).material as THREE.MeshStandardMaterial)
            .emissive.set(0x000000);
        selectedObject = null;
    }

    if (intersects.length > 0) {
        const hit = intersects[0].object;
        if (hit.userData.interactive) {
            selectedObject = hit;
            // 高亮效果：设置自发光
            ((hit as THREE.Mesh).material as THREE.MeshStandardMaterial)
                .emissive.set(0x333333);
            // 显示信息面板
            showInfoPanel(hit.userData);
        }
    }
}
```

`userData.interactive` 是自定义标记，用来区分可交互物体和地面、辅助线等非交互对象。

## 四、完整的交互场景代码

在之前课程的场景基础上，叠加 OrbitControls 和 Raycaster 的核心代码：

```typescript
import * as THREE from "three";
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";

// 假设 scene、camera、renderer 已按前几课的方式创建
// 此处只展示交互相关的核心代码

// 相机控制
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.dampingFactor = 0.05;
controls.minDistance = 2;
controls.maxDistance = 20;
controls.maxPolarAngle = Math.PI / 2 - 0.05;

// 创建可交互物体并标记
const interactiveObjects: THREE.Mesh[] = [];
const geometries = [
    new THREE.BoxGeometry(0.8, 0.8, 0.8),
    new THREE.SphereGeometry(0.5, 32, 32),
    new THREE.CylinderGeometry(0.4, 0.4, 1, 32),
    new THREE.TorusGeometry(0.4, 0.15, 16, 32),
];
const colors = [0x4fc3f7, 0xff7043, 0x66bb6a, 0xab47bc];

geometries.forEach((geo, i) => {
    const mesh = new THREE.Mesh(geo, new THREE.MeshStandardMaterial({
        color: colors[i], roughness: 0.3, metalness: 0.5,
    }));
    mesh.position.set(i * 2.5 - 3.75, 0.5, 0);
    mesh.castShadow = true;
    mesh.userData.interactive = true;
    mesh.userData.name = ["立方体", "球体", "圆柱体", "圆环体"][i];
    scene.add(mesh);
    interactiveObjects.push(mesh);
});

// 射线检测 + 选中高亮
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
let selectedObject: THREE.Object3D | null = null;

renderer.domElement.addEventListener("click", (event: MouseEvent) => {
    const rect = renderer.domElement.getBoundingClientRect();
    mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
    mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
    raycaster.setFromCamera(mouse, camera);
    const intersects = raycaster.intersectObjects(interactiveObjects);

    if (selectedObject) {
        ((selectedObject as THREE.Mesh).material as THREE.MeshStandardMaterial)
            .emissive.set(0x000000);
        selectedObject = null;
    }
    if (intersects.length > 0) {
        selectedObject = intersects[0].object;
        ((selectedObject as THREE.Mesh).material as THREE.MeshStandardMaterial)
            .emissive.set(0x333333);
        console.log(`选中: ${selectedObject.userData.name}`);
    }
});

// 鼠标悬停手型
renderer.domElement.addEventListener("mousemove", (event: MouseEvent) => {
    const rect = renderer.domElement.getBoundingClientRect();
    mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
    mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
    raycaster.setFromCamera(mouse, camera);
    const hits = raycaster.intersectObjects(interactiveObjects);
    renderer.domElement.style.cursor = hits.length > 0 ? "pointer" : "default";
});

// 渲染循环中必须调用 controls.update()
const clock = new THREE.Clock();
function animate(): void {
    requestAnimationFrame(animate);
    controls.update();
    const delta = clock.getDelta();
    interactiveObjects.forEach((obj, i) => { obj.rotation.y += delta * (0.3 + i * 0.1); });
    renderer.render(scene, camera);
}
animate();
```

## 五、DragControls 拖拽控制

`DragControls` 让用户直接拖拽物体在场景中移动：

```typescript
import { DragControls } from "three/examples/jsm/controls/DragControls.js";

const dragControls = new DragControls(
    interactiveObjects,  // 可拖拽物体数组
    camera,
    renderer.domElement
);

// 拖拽开始时禁用 OrbitControls（避免冲突）
dragControls.addEventListener("dragstart", (event) => {
    controls.enabled = false; // 禁用相机控制
    const mat = (event.object as THREE.Mesh).material as THREE.MeshStandardMaterial;
    mat.emissive.set(0x222222);
});

// 拖拽过程中
dragControls.addEventListener("drag", (event) => {
    // 限制物体在地面上（Y 轴固定）
    event.object.position.y = 0.5;
});

// 拖拽结束时重新启用 OrbitControls
dragControls.addEventListener("dragend", (event) => {
    controls.enabled = true;
    const mat = (event.object as THREE.Mesh).material as THREE.MeshStandardMaterial;
    mat.emissive.set(0x000000);
});
```

**关键点**：拖拽时必须禁用 OrbitControls，否则两者会同时响应鼠标事件，导致画面抖动或物体乱飞。

## 六、触摸与指针事件统一

Three.js 的 OrbitControls 和 DragControls 原生支持触摸事件。推荐用 Pointer Events API 统一处理鼠标和触摸：

```typescript
// Pointer Events 同时覆盖鼠标和触摸，无需分别监听
renderer.domElement.addEventListener("pointerdown", onPointerDown);
renderer.domElement.addEventListener("pointermove", onPointerMove);
renderer.domElement.addEventListener("pointerup", onPointerUp);

// 射线检测的坐标提取（兼容触摸）
function getPointerPosition(event: PointerEvent): THREE.Vector2 {
    const rect = renderer.domElement.getBoundingClientRect();
    return new THREE.Vector2(
        ((event.clientX - rect.left) / rect.width) * 2 - 1,
        -((event.clientY - rect.top) / rect.height) * 2 + 1
    );
}
```

移动端需要在 canvas 上设置 `touch-action: none` CSS 属性，阻止浏览器默认的双指缩放页面行为。

## 七、自定义相机控制思路

当 OrbitControls 无法满足需求时（如第一人称视角、跟随相机），需要手动实现。核心思路是监听键盘 WASD 控制移动方向，监听鼠标移动控制视角旋转，用 `PointerLock API` 捕获鼠标：

```typescript
// 第一人称相机的关键逻辑
// 1. 点击 canvas 后调用 canvas.requestPointerLock() 捕获鼠标
// 2. mousemove 事件中用 movementX/Y 更新 yaw（水平角）和 pitch（垂直角）
// 3. 键盘 WASD 根据 yaw 计算前进/后退/左右方向向量
// 4. 每帧将 yaw/pitch 应用到 camera.rotation（顺序 YXZ）
// 5. pitch 限制在 ±89° 防止翻转

// 跟随相机的关键逻辑
// 1. 维护一个偏移量（offset）相对于目标物体
// 2. 每帧把相机位置设为 target.position + offset
// 3. 调用 camera.lookAt(target.position)
// 4. 用 lerp 平滑插值避免相机抖动
```

## 常见误区

**1. OrbitControls 和 DragControls 同时响应鼠标事件**
拖拽物体时必须在 `dragstart` 事件中禁用 `controls.enabled = false`，在 `dragend` 中重新启用。否则相机会跟着物体一起动。

**2. 射线检测忘记更新相机矩阵**
如果在 `camera.updateProjectionMatrix()` 之前进行射线检测，结果可能不准确。确保在 resize 事件中更新相机矩阵。

**3. `intersectObjects` 的 recursive 参数**
`intersectObjects(objects, false)` 只检测传入数组中的直接对象。如果物体在 Group 内部，需要传 `true` 递归检测子对象，否则点不中。

**4. 拖拽时物体穿透地面**
DragControls 默认在世界坐标系中拖拽。如果需要限制物体在地面上移动，必须在 `drag` 事件中手动固定 Y 坐标。

## 工程建议

**1. 对大量物体使用空间优化**
当场景有上千个可交互物体时，逐个射线检测太慢。使用 `THREE.BVH`（包围体层级）或 octree 空间索引加速查找。

**2. 区分"选中"和"拖拽"逻辑**
鼠标按下时记录位置，如果移动距离超过阈值则判定为拖拽，否则判定为点击。避免轻微手抖触发误点击。

**3. 移动端适配用 `touch-action: none`**
在 canvas 上设置 `touch-action: none` CSS 属性，阻止浏览器默认的双指缩放页面行为。结合上一节的 Pointer Events API，可同时覆盖桌面和移动端。

## 小结

本课构建了完整的 3D 交互能力：OrbitControls 提供直觉化的相机操控（旋转、缩放、平移），Raycaster 实现从 2D 屏幕坐标到 3D 世界的射线检测，DragControls 让物体可被鼠标拖拽移动。我们还讨论了触摸事件适配和自定义第一人称相机控制。这些能力组合在一起，就能构建出如 3D 产品配置器、建筑漫游、数据可视化等交互式 3D Web 应用。

## 参考答案

### 练习一

**思路**：记录 OrbitControls 的初始相机位置和目标点，点击按钮时用 `lerp` 在渲染循环中平滑插值到初始状态，实现带缓动的视角重置。

**答案**：

```typescript
import * as THREE from "three";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(3, 3, 5);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;
controls.target.set(0, 0, 0);

// 记录初始状态
const initialPosition = camera.position.clone();
const initialTarget = controls.target.clone();

// 场景物体
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7 });
const box = new THREE.Mesh(boxGeo, boxMat);
scene.add(box);

const sphereGeo = new THREE.SphereGeometry(0.5, 32, 32);
const sphereMat = new THREE.MeshStandardMaterial({ color: 0xff7043 });
const sphere = new THREE.Mesh(sphereGeo, sphereMat);
sphere.position.set(2, 0, 0);
scene.add(sphere);

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 5, 5);
scene.add(dirLight);

scene.add(new THREE.GridHelper(10, 10, 0x444466, 0x333355));

// 重置按钮
const btn = document.createElement("button");
btn.textContent = "重置视角";
btn.style.position = "fixed";
btn.style.bottom = "20px";
btn.style.left = "50%";
btn.style.transform = "translateX(-50%)";
btn.style.padding = "8px 20px";
btn.style.cursor = "pointer";
document.body.appendChild(btn);

let isResetting = false;
const lerpSpeed = 0.05;

btn.addEventListener("click", () => {
    isResetting = true;
});

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();

    // 平滑重置相机
    if (isResetting) {
        camera.position.lerp(initialPosition, lerpSpeed);
        controls.target.lerp(initialTarget, lerpSpeed);

        // 判断是否接近目标位置
        if (camera.position.distanceTo(initialPosition) < 0.01) {
            camera.position.copy(initialPosition);
            controls.target.copy(initialTarget);
            isResetting = false;
        }
    }

    box.rotation.y += delta * 0.5;
    sphere.rotation.y += delta * 0.3;

    controls.update();
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `Vector3.lerp(target, alpha)` 每帧插值，`alpha` 越小动画越平滑但越慢
- 重置时必须同时插值 `camera.position` 和 `controls.target`，否则相机会看向错误的方向
- 用距离阈值 `0.01` 判断动画结束，避免无限趋近导致的浮点精度问题
- 重置期间应禁用 OrbitControls 的用户输入，防止冲突（这里简化处理）

### 练习二

**思路**：用 Raycaster 检测点击的物体，将物体信息（名称、位置、材质颜色）写入一个 HTML 面板。点击空白处（未命中任何物体）时关闭面板。

**答案**：

```typescript
import * as THREE from "three";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(4, 3, 6);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;

// 场景物体（设置 name 便于识别）
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7 });
const box = new THREE.Mesh(boxGeo, boxMat);
box.name = "蓝色立方体";
box.position.set(-2, 0, 0);
scene.add(box);

const sphereGeo = new THREE.SphereGeometry(0.6, 32, 32);
const sphereMat = new THREE.MeshStandardMaterial({ color: 0xff7043 });
const sphere = new THREE.Mesh(sphereGeo, sphereMat);
sphere.name = "橙色球体";
scene.add(sphere);

const torusGeo = new THREE.TorusGeometry(0.5, 0.2, 16, 32);
const torusMat = new THREE.MeshStandardMaterial({ color: 0x66bb6a });
const torus = new THREE.Mesh(torusGeo, torusMat);
torus.name = "绿色圆环";
torus.position.set(2, 0, 0);
scene.add(torus);

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 5, 5);
scene.add(dirLight);

// 信息面板
const panel = document.createElement("div");
panel.style.position = "fixed";
panel.style.top = "20px";
panel.style.right = "20px";
panel.style.width = "250px";
panel.style.padding = "16px";
panel.style.background = "rgba(0,0,0,0.8)";
panel.style.color = "#fff";
panel.style.borderRadius = "8px";
panel.style.fontFamily = "monospace";
panel.style.fontSize = "14px";
panel.style.display = "none";
panel.style.zIndex = "100";
document.body.appendChild(panel);

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

function showObjectInfo(object: THREE.Object3D): void {
    const mesh = object as THREE.Mesh;
    const mat = mesh.material as THREE.MeshStandardMaterial;
    const pos = mesh.position;

    panel.innerHTML = `
        <h3 style="margin:0 0 10px 0;">${mesh.name || "未命名物体"}</h3>
        <p><strong>位置:</strong> (${pos.x.toFixed(1)}, ${pos.y.toFixed(1)}, ${pos.z.toFixed(1)})</p>
        <p><strong>材质类型:</strong> ${mat.type}</p>
        <p><strong>颜色:</strong> <span style="color:#${mat.color.getHexString()}">#${mat.color.getHexString()}</span></p>
        <p><strong>金属度:</strong> ${mat.metalness}</p>
        <p><strong>粗糙度:</strong> ${mat.roughness}</p>
    `;
    panel.style.display = "block";
}

canvas.addEventListener("click", (event: MouseEvent) => {
    pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
    pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;

    raycaster.setFromCamera(pointer, camera);
    const intersects = raycaster.intersectObjects(scene.children, false);

    // 过滤掉非 Mesh 对象（如灯光、Helper）
    const meshHit = intersects.find((hit) => (hit.object as THREE.Mesh).isMesh);

    if (meshHit) {
        showObjectInfo(meshHit.object);
    } else {
        panel.style.display = "none"; // 点击空白处关闭
    }
});

function animate(): void {
    requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `raycaster.intersectObjects` 的第二个参数 `false` 表示不递归检测子物体（这里场景结构简单）
- 面板的显隐通过 `display` 属性控制，点击空白处（无命中）时隐藏
- `pointer` 坐标必须归一化到 `-1 ~ 1`，且 Y 轴取反
- 实际项目中建议用 React/Vue 管理面板状态，这里用原生 DOM 简化演示

### 练习三

**思路**：在第一人称控制的移动逻辑中，每帧预测相机的下一个位置，用 Raycaster 检测前方是否有物体。如果距离小于阈值则阻止前进，实现简单的碰撞阻挡。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x222233);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 1.6, 5);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

// 场景障碍物
const wallGeo = new THREE.BoxGeometry(4, 3, 0.5);
const wallMat = new THREE.MeshStandardMaterial({ color: 0x888899 });
const wall = new THREE.Mesh(wallGeo, wallMat);
wall.position.set(0, 1.5, -2);
wall.name = "墙壁";
scene.add(wall);

const boxGeo = new THREE.BoxGeometry(1.5, 1.5, 1.5);
const boxMat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7 });
const box = new THREE.Mesh(boxGeo, boxMat);
box.position.set(3, 0.75, 1);
box.name = "箱子";
scene.add(box);

const groundGeo = new THREE.PlaneGeometry(20, 20);
const groundMat = new THREE.MeshStandardMaterial({ color: 0x444455 });
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
scene.add(ground);

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 10, 5);
scene.add(dirLight);

// 第一人称控制
const keys: Record<string, boolean> = {};
const moveSpeed = 3;
const collisionDistance = 0.5; // 碰撞检测距离

window.addEventListener("keydown", (e) => { keys[e.code] = true; });
window.addEventListener("keyup", (e) => { keys[e.code] = false; });

// 鼠标控制视角
canvas.requestPointerLock();
canvas.addEventListener("mousemove", (e) => {
    if (document.pointerLockElement === canvas) {
        camera.rotation.y -= e.movementX * 0.002;
        camera.rotation.x -= e.movementY * 0.002;
        camera.rotation.x = Math.max(-Math.PI / 2, Math.min(Math.PI / 2, camera.rotation.x));
    }
});

const direction = new THREE.Vector3();
const raycaster = new THREE.Raycaster();
const collisionObjects = [wall, box]; // 需要检测碰撞的物体

function canMove(dir: THREE.Vector3): boolean {
    raycaster.set(camera.position, dir.normalize());
    raycaster.far = collisionDistance;
    const hits = raycaster.intersectObjects(collisionObjects);
    return hits.length === 0; // 没有命中才能移动
}

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();

    direction.set(0, 0, 0);

    if (keys["KeyW"]) direction.z -= 1;
    if (keys["KeyS"]) direction.z += 1;
    if (keys["KeyA"]) direction.x -= 1;
    if (keys["KeyD"]) direction.x += 1;

    if (direction.length() > 0) {
        direction.normalize().applyQuaternion(camera.quaternion);
        direction.y = 0; // 保持水平移动
        direction.normalize();

        // 碰撞检测：只有无障碍时才移动
        if (canMove(direction)) {
            camera.position.addScaledVector(direction, moveSpeed * delta);
        }
    }

    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `raycaster.set(origin, direction)` 从相机位置沿移动方向发射射线
- `raycaster.far = collisionDistance` 限制检测距离，太远则无法紧贴墙壁，太近则可能穿透
- `applyQuaternion(camera.quaternion)` 将移动方向从局部坐标转为世界坐标，确保 WASD 相对于相机朝向
- 这是最简单的碰撞方案，生产环境建议用物理引擎（如 Rapier）或 BVH 空间索引
