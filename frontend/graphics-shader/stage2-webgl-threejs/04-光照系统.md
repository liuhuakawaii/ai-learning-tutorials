# 第4课：光照系统

## 场景引入

同一个白色的球体，在阳光下是明亮的，在烛光下是温暖的，在霓虹灯下是彩色的。光照决定了场景的氛围和物体的立体感。没有光照，所有物体都是一片平坦的色块。Three.js 提供了多种光源类型和阴影系统，让你能模拟从晴天正午到昏暗酒吧的各种光照环境。本课系统学习 Three.js 的光照体系。

## 学习目标

1. 掌握四种基础光源的特性、参数和适用场景
2. 理解光照强度、颜色和距离衰减的计算方式
3. 学会配置 ShadowMap 实时阴影系统
4. 能够使用光源助手（Helper）调试场景光照
5. 理解环境贴图作为间接光照的原理与用法

## 一、四种基础光源

```
  AmbientLight          DirectionalLight       PointLight           SpotLight
  (环境光)              (平行光)               (点光源)             (聚光灯)

  ┌──────────┐          ☀ →→→→               ●                     ◇
  │ ↗↗↗↗↗↗↗↗│          →→→→→→→              ↑↓←→                 ╲│╱
  │ ↗↗↗↗↗↗↗↗│          →→→→→→→              全方向               锥形
  │ ↗↗↗↗↗↗↗↗│          →→→→→→→              发散                  光束
  └──────────┘          方向一致               有衰减                有衰减
  无方向，均匀照亮       无衰减                距离越远越暗          有锥角和边缘
```

```typescript
import * as THREE from "three";

// 环境光：均匀照亮所有物体，无方向、无阴影
const ambientLight = new THREE.AmbientLight(0xffffff, 0.3);

// 平行光：模拟太阳光，所有光线方向平行，无衰减
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 10, 5);

// 点光源：从一个点向所有方向发光，有距离衰减
const pointLight = new THREE.PointLight(0xff9900, 2.0, 20, 2);
// 参数：颜色, 强度, 最大距离, 衰减指数

// 聚光灯：锥形光束，有方向、有锥角、有衰减
const spotLight = new THREE.SpotLight(0x00aaff, 3.0, 30, Math.PI / 6, 0.3, 2);
// 参数：颜色, 强度, 最大距离, 锥角, 边缘柔化, 衰减指数
```

## 二、光照衰减

真实世界中光的强度随距离减弱。Three.js 的 `PointLight` 和 `SpotLight` 使用物理正确的衰减公式：

```
  光照强度
    │
  1 ┤●
    │ ╲
    │  ╲
    │   ╲
    │    ╲
    │     ╲─────────
  0 ┤─────────────────── 距离
    0    distance

  衰减公式：intensity / (distance ^ decay)
  decay=2 时为物理正确的平方反比衰减
```

```typescript
// 物理正确衰减设置
renderer.useLegacyLights = false; // Three.js r155+ 默认行为

// 点光源：白色灯泡，照亮半径 10 米
const bulb = new THREE.PointLight(0xffffff, 50, 10, 2);
// intensity=50 是物理单位（lumens），不是 0~1 的归一化值
```

注意：当 `useLegacyLights = false`（新版本默认），光照强度使用物理单位。旧版本中强度范围是 0~1，新版本中点光源的强度通常在 10~100 量级。

## 三、阴影系统

阴影让物体有空间关系的真实感。Three.js 使用 ShadowMap 技术：

```typescript
// 第一步：渲染器开启阴影
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // 柔和阴影边缘

// 第二步：光源开启阴影投射
dirLight.castShadow = true;
dirLight.shadow.mapSize.width = 2048;  // 阴影贴图分辨率
dirLight.shadow.mapSize.height = 2048;
dirLight.shadow.camera.near = 0.5;
dirLight.shadow.camera.far = 50;
dirLight.shadow.camera.left = -10;
dirLight.shadow.camera.right = 10;
dirLight.shadow.camera.top = 10;
dirLight.shadow.camera.bottom = -10;
dirLight.shadow.bias = -0.0001; // 修正阴影瑕疵（shadow acne）

// 第三步：物体投射和接收阴影
cube.castShadow = true;    // 物体会投射阴影
plane.receiveShadow = true; // 物体会接收阴影
```

```
  阴影渲染原理（ShadowMap）：

  光源位置
      ╲
       ╲  第一步：从光源视角渲染深度图
        ╲
    ┌────╲────────┐
    │     ╲       │  ← ShadowMap：记录每个像素到光源的距离
    │   物体      │
    │     ╲       │
    └──────╲──────┘
            ╲
             ╲  第二步：从相机视角渲染，对比深度
              ╲
         ┌─────╲─────┐
         │      ╲    │  ← 如果片元到光源的距离 > ShadowMap 记录的距离
         │    阴影区  │     说明被其他物体遮挡 → 该片元在阴影中
         └───────────┘
```

## 四、光源助手

调试光照时，Helper 能可视化光源的位置和范围：

```typescript
// 平行光助手：显示光源位置和照射方向
const dirHelper = new THREE.DirectionalLightHelper(dirLight, 1);
// 参数：光源, 辅助线长度
scene.add(dirHelper);

// 点光源助手：显示光源位置和照射范围
const pointHelper = new THREE.PointLightHelper(pointLight, 0.5);
scene.add(pointHelper);

// 聚光灯助手：显示锥形范围
const spotHelper = new THREE.SpotLightHelper(spotLight);
scene.add(spotHelper);

// 平行光阴影相机助手：显示阴影投射范围
const shadowHelper = new THREE.CameraHelper(dirLight.shadow.camera);
scene.add(shadowHelper);
```

阴影相机助手特别有用——它显示的框就是阴影渲染的范围。如果物体阴影被截断，说明阴影相机的 `left/right/top/bottom` 设置不够大。

## 五、完整代码：多光源阴影场景

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(60, 16 / 9, 0.1, 100);
camera.position.set(6, 4, 8);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(1280, 720);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;

// 地面
const groundGeo = new THREE.PlaneGeometry(20, 20);
const groundMat = new THREE.MeshStandardMaterial({
    color: 0x333344,
    roughness: 0.8,
    metalness: 0.2,
});
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);

// 立方体
const cubeGeo = new THREE.BoxGeometry(1, 1, 1);
const cubeMat = new THREE.MeshStandardMaterial({
    color: 0x4fc3f7,
    roughness: 0.3,
    metalness: 0.5,
});
const cube = new THREE.Mesh(cubeGeo, cubeMat);
cube.position.set(-1.5, 0.5, 0);
cube.castShadow = true;
scene.add(cube);

// 球体
const sphereGeo = new THREE.SphereGeometry(0.6, 32, 32);
const sphereMat = new THREE.MeshStandardMaterial({
    color: 0xff7043,
    roughness: 0.2,
    metalness: 0.7,
});
const sphere = new THREE.Mesh(sphereGeo, sphereMat);
sphere.position.set(1.5, 0.6, 0);
sphere.castShadow = true;
scene.add(sphere);

// 环境光 — 给暗部提供基础亮度
const ambient = new THREE.AmbientLight(0x404060, 0.5);
scene.add(ambient);

// 平行光 — 主光源，模拟太阳
const sun = new THREE.DirectionalLight(0xffeedd, 2.0);
sun.position.set(5, 8, 3);
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);
sun.shadow.camera.near = 0.5;
sun.shadow.camera.far = 30;
sun.shadow.camera.left = -8;
sun.shadow.camera.right = 8;
sun.shadow.camera.top = 8;
sun.shadow.camera.bottom = -8;
sun.shadow.bias = -0.0001;
scene.add(sun);

// 点光源 — 暖色补光
const warmBulb = new THREE.PointLight(0xff9944, 15, 10, 2);
warmBulb.position.set(-3, 3, 2);
warmBulb.castShadow = true;
scene.add(warmBulb);

// 聚光灯 — 蓝色重点光
const blueSpot = new THREE.SpotLight(0x4488ff, 30, 15, Math.PI / 5, 0.3, 2);
blueSpot.position.set(3, 5, -2);
blueSpot.target.position.set(0, 0, 0);
blueSpot.castShadow = true;
scene.add(blueSpot);
scene.add(blueSpot.target);

// 光源助手（调试用）
scene.add(new THREE.DirectionalLightHelper(sun, 1));
scene.add(new THREE.PointLightHelper(warmBulb, 0.3));

// 渲染循环
const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const t = clock.getElapsedTime();

    cube.rotation.y = t * 0.5;
    cube.rotation.x = t * 0.3;
    sphere.position.y = 0.6 + Math.sin(t * 2) * 0.3;

    // 点光源缓慢移动
    warmBulb.position.x = Math.sin(t * 0.5) * 3;
    warmBulb.position.z = Math.cos(t * 0.5) * 3;

    renderer.render(scene, camera);
}

animate();
```

## 六、环境贴图作为光照

环境贴图不仅用于反射，还能作为间接光照来源（Image-Based Lighting, IBL）：

```typescript
import { RGBELoader } from "three/examples/jsm/loaders/RGBELoader.js";

const rgbeLoader = new RGBELoader();
rgbeLoader.load("/hdr/venice_sunset.hdr", (texture) => {
    texture.mapping = THREE.EquirectangularReflectionMapping;

    // 设置为场景环境 → 所有 PBR 材质自动使用它计算间接光照
    scene.environment = texture;

    // 设置为背景
    scene.background = texture;
    scene.backgroundBlurriness = 0.3; // 背景模糊程度
});
```

设置 `scene.environment` 后，即使没有添加任何光源，PBR 材质也会被环境贴图照亮。这是因为 PBR 着色器会用环境贴图的各个方向颜色来近似计算漫反射和镜面反射的间接光照。

## 常见误区

**1. 只用环境光不用方向光**
环境光是均匀的，不会在物体表面产生明暗对比。只有环境光的场景看起来像阴天——没有立体感。正确做法是环境光打底 + 方向光/点光源提供主要照明。

**2. ShadowMap 分辨率设得太高或太低**
太低（如 512）阴影有明显锯齿；太高（如 4096）浪费显存。一般场景 1024~2048 是平衡点。如果只需要粗糙阴影，512 也够用。

**3. 忘记设置 `castShadow` 和 `receiveShadow`**
`renderer.shadowMap.enabled = true` 只是开启了渲染器的阴影功能，每个物体还需要单独设置 `castShadow`（投射）和 `receiveShadow`（接收），否则不会产生阴影。

**4. shadow.bias 设置不当导致条纹瑕疵**
`bias` 太大会导致阴影与物体分离（悬浮阴影），太小会出现 `shadow acne`（条纹状自阴影）。通常从 `-0.0001` 开始微调。

## 工程建议

**1. 用最少的阴影光源**
阴影计算昂贵。场景中只让主光源（太阳或主灯）投射阴影，辅助光源用 `castShadow = false`。一个阴影光源通常足够提供空间感。

**2. 限制阴影范围**
平行光的 `shadow.camera` 范围应该刚好覆盖可见场景，不要设得太大。范围越大，阴影贴图的有效分辨率越低，阴影越粗糙。

**3. 移动端使用 `THREE.BasicShadowMap`**
`PCFSoftShadowMap` 的柔和阴影在移动端性能开销较大。如果性能紧张，用 `BasicShadowMap` 配合较低分辨率，或直接关闭阴影。

**4. 用 `scene.environment` 统一管理间接光照**
不要给每个材质单独设置 `envMap`。设置 `scene.environment` 后，场景中所有 PBR 材质自动使用，代码更简洁，也更容易切换环境。

## 小结

本课学习了 Three.js 的光照系统：AmbientLight 提供均匀底光，DirectionalLight 模拟太阳，PointLight 模拟灯泡，SpotLight 模拟聚光灯。阴影通过 ShadowMap 技术实现，需要渲染器、光源和物体三方面配合开启。环境贴图作为 IBL 光源能让 PBR 材质在没有直接光源时也呈现真实的间接光照效果。合理搭配这些光源类型，就能为场景营造出各种真实的光照氛围。

## 参考答案

### 练习一

**思路**：用滑块控件（HTML range input）控制方向光的 Y 位置和旋转角度，模拟太阳从地平线升起再落下的过程。根据角度插值光源颜色（日出橙色→正午白色→日落橙色），并同步调整环境光强度。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x87ceeb);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(5, 3, 8);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

// 地面
const groundGeo = new THREE.PlaneGeometry(20, 20);
const groundMat = new THREE.MeshStandardMaterial({ color: 0x228b22 });
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);

// 立方体
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0xffffff });
const box = new THREE.Mesh(boxGeo, boxMat);
box.position.y = 0.5;
box.castShadow = true;
scene.add(box);

// 环境光（随时间变化强度）
const ambientLight = new THREE.AmbientLight(0xffffff, 0.3);
scene.add(ambientLight);

// 方向光
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.castShadow = true;
dirLight.shadow.mapSize.set(1024, 1024);
dirLight.shadow.camera.left = -10;
dirLight.shadow.camera.right = 10;
dirLight.shadow.camera.top = 10;
dirLight.shadow.camera.bottom = -10;
scene.add(dirLight);

// 滑块控件
const slider = document.createElement("input");
slider.type = "range";
slider.min = "0";
slider.max = "100";
slider.value = "50";
slider.style.position = "fixed";
slider.style.bottom = "20px";
slider.style.left = "50%";
slider.style.transform = "translateX(-50%)";
slider.style.width = "60%";
document.body.appendChild(slider);

// 根据滑块值更新光照
function updateSunlight(progress: number): void {
    // progress: 0=日出, 50=正午, 100=日落
    const angle = (progress / 100) * Math.PI; // 0 到 π
    const radius = 10;

    dirLight.position.set(
        Math.cos(angle) * radius,
        Math.sin(angle) * radius,
        3
    );

    // 颜色插值：日出/日落橙色 → 正午白色
    const sunColor = new THREE.Color();
    if (progress < 25 || progress > 75) {
        // 日出/日落：橙红色
        sunColor.setRGB(1.0, 0.5, 0.2);
        ambientLight.intensity = 0.15;
        scene.background = new THREE.Color(0xff8c42);
    } else if (progress < 40 || progress > 60) {
        // 过渡：暖白色
        sunColor.setRGB(1.0, 0.85, 0.7);
        ambientLight.intensity = 0.25;
        scene.background = new THREE.Color(0xadd8e6);
    } else {
        // 正午：白色
        sunColor.setRGB(1.0, 1.0, 0.95);
        ambientLight.intensity = 0.4;
        scene.background = new THREE.Color(0x87ceeb);
    }

    dirLight.color = sunColor;
}

slider.addEventListener("input", () => {
    updateSunlight(Number(slider.value));
});

updateSunlight(50);

function animate(): void {
    requestAnimationFrame(animate);
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- 方向光的位置决定光线方向（从位置指向目标点），`Math.sin/cos` 模拟太阳弧线轨迹
- 日出/日落时光源角度低，颜色偏暖（橙红），环境光要减弱；正午时光源在头顶，颜色偏白
- `scene.background` 也可以随时间变化，增强天空氛围感
- 阴影的 `shadow.camera` 范围要覆盖场景，否则阴影会被裁切

### 练习二

**思路**：创建一个点光源和一个球体，通过 GUI 控件切换 `decay` 值（0、1、2）。`decay=0` 时亮度不随距离衰减，`decay=1` 时线性衰减，`decay=2` 时遵循物理规律的平方反比衰减。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 0, 8);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

// 地面参考
const groundGeo = new THREE.PlaneGeometry(20, 20);
const groundMat = new THREE.MeshStandardMaterial({ color: 0x333344 });
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
ground.position.y = -2;
scene.add(ground);

// 球体阵列，距离点光源不同距离
for (let i = 0; i < 5; i++) {
    const sphereGeo = new THREE.SphereGeometry(0.3, 32, 32);
    const sphereMat = new THREE.MeshStandardMaterial({ color: 0xffffff });
    const sphere = new THREE.Mesh(sphereGeo, sphereMat);
    sphere.position.set(i * 2 - 4, 0, 0); // -4, -2, 0, 2, 4
    scene.add(sphere);
}

// 点光源
const pointLight = new THREE.PointLight(0xffaa00, 10, 50, 2);
pointLight.position.set(0, 2, 0);
scene.add(pointLight);

// 光源可视化
const lightHelper = new THREE.PointLightHelper(pointLight, 0.2);
scene.add(lightHelper);

// 控件面板
const panel = document.createElement("div");
panel.style.position = "fixed";
panel.style.bottom = "20px";
panel.style.left = "50%";
panel.style.transform = "translateX(-50%)";
panel.style.display = "flex";
panel.style.gap = "10px";
document.body.appendChild(panel);

[0, 1, 2].forEach((decayValue) => {
    const btn = document.createElement("button");
    btn.textContent = `decay = ${decayValue}`;
    btn.style.padding = "8px 16px";
    btn.style.cursor = "pointer";
    btn.addEventListener("click", () => {
        pointLight.decay = decayValue;
        console.log(`decay=${decayValue}: 亮度随距离衰减方式改变`);
    });
    panel.appendChild(btn);
});

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const elapsed = clock.getElapsedTime();

    // 光源上下浮动，方便观察不同距离的亮度变化
    pointLight.position.y = 2 + Math.sin(elapsed) * 1.5;

    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `decay=0`：亮度不衰减，所有球体亮度相同（非物理，但可用于特殊效果）
- `decay=1`：线性衰减，远距离物体仍有明显亮度
- `decay=2`：平方反比衰减，符合真实光照物理规律，远处物体明显变暗
- `PointLight` 的 `intensity` 参数配合 `decay` 使用，`decay=2` 时需要更大的 `intensity` 值

### 练习三

**思路**：创建聚光灯并配置 `shadow.camera` 的 `fov`（光锥角度）、`near`/`far`（阴影范围）。用 `SpotLightHelper` 可视化光锥方向，用 `CameraHelper` 可视化阴影相机的视锥体，两者配合调试。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(5, 5, 8);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

// 地面
const groundGeo = new THREE.PlaneGeometry(20, 20);
const groundMat = new THREE.MeshStandardMaterial({ color: 0x444455 });
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;
scene.add(ground);

// 被照射的物体
const boxGeo = new THREE.BoxGeometry(1, 2, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7 });
const box = new THREE.Mesh(boxGeo, boxMat);
box.position.set(0, 1, 0);
box.castShadow = true;
box.receiveShadow = true;
scene.add(box);

const sphereGeo = new THREE.SphereGeometry(0.5, 32, 32);
const sphereMat = new THREE.MeshStandardMaterial({ color: 0xff7043 });
const sphere = new THREE.Mesh(sphereGeo, sphereMat);
sphere.position.set(2, 0.5, 1);
sphere.castShadow = true;
scene.add(sphere);

// 聚光灯
const spotLight = new THREE.SpotLight(0xffffff, 50);
spotLight.position.set(3, 6, 3);
spotLight.angle = Math.PI / 6;           // 光锥角度（弧度）
spotLight.penumbra = 0.3;                // 边缘柔和度
spotLight.decay = 2;                     // 物理衰减
spotLight.distance = 20;                 // 最远照射距离

// 阴影配置
spotLight.castShadow = true;
spotLight.shadow.mapSize.set(1024, 1024);
spotLight.shadow.camera.near = 1;        // 阴影相机近裁面
spotLight.shadow.camera.far = 20;        // 阴影相机远裁面
spotLight.shadow.camera.fov = 30;        // 阴影相机视锥角度（应与 spotLight.angle 匹配）
spotLight.shadow.bias = -0.001;          // 阴影偏移，减少伪影

scene.add(spotLight);

// 目标点（聚光灯照射方向）
spotLight.target.position.set(0, 0, 0);
scene.add(spotLight.target);

// Helper 可视化
const spotHelper = new THREE.SpotLightHelper(spotLight);
scene.add(spotHelper);

const shadowCamHelper = new THREE.CameraHelper(spotLight.shadow.camera);
scene.add(shadowCamHelper);

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const elapsed = clock.getElapsedTime();

    // 让聚光灯缓慢移动
    spotLight.position.x = 3 + Math.sin(elapsed * 0.5) * 2;
    spotLight.position.z = 3 + Math.cos(elapsed * 0.5) * 2;

    // 更新 Helper
    spotHelper.update();
    shadowCamHelper.update();

    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `SpotLightHelper` 显示光锥的范围和方向（黄色线框），帮助确认照射区域
- `CameraHelper` 显示阴影相机的视锥体（白色线框），确保阴影不被裁切
- `shadow.camera.fov` 应与 `spotLight.angle` 保持一致，否则阴影范围和光照范围不匹配
- `shadow.bias` 用于修正阴影伪影（shadow acne），值太大会导致阴影偏移，太小会出现条纹
