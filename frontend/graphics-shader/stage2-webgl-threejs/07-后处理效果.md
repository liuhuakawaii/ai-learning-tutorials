# 第七课：后处理效果

## 场景引入

你是否注意到，很多游戏画面看起来比普通 3D 场景更加"电影化"——物体边缘有柔和的辉光，暗角处有自然的渐变，整体色调统一而富有氛围感。这些效果并不是在主渲染阶段完成的，而是通过**后处理（Post-Processing）**技术，在渲染结果的基础上再做一次或多次图像处理。就像摄影师在 RAW 文件上应用滤镜一样，后处理是 3D 渲染管线的最后一道"调味"工序。

## 学习目标

1. 理解后处理的基本原理和渲染管线中的位置
2. 掌握 Three.js EffectComposer 的使用流程
3. 学会使用内置 Pass（RenderPass、ShaderPass）构建后处理链
4. 实现 Bloom（辉光）和 SSAO（环境光遮蔽）效果
5. 能够编写自定义后处理 Shader

## 一、后处理的基本原理

后处理的核心思想是：先将场景渲染到一张离屏纹理（Framebuffer），然后对这张纹理进行图像处理，最终将处理结果显示到屏幕上。

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌──────────┐
│  场景渲染    │────▶│  Pass 1     │────▶│  Pass 2     │────▶│  屏幕输出 │
│  (RenderPass)│     │  (Bloom)    │     │  (Vignette) │     │          │
└─────────────┘     └─────────────┘     └─────────────┘     └──────────┘
     FBO A               FBO B               FBO C              默认帧缓冲
```

每个 Pass 接收上一步的输出纹理作为输入，执行特定的图像处理，再输出到下一个 FBO。这就是**链式调用（Ping-Pong）**的原理。

## 二、EffectComposer 使用流程

EffectComposer 是 Three.js 中管理后处理链的核心类。

```typescript
import {
  EffectComposer,
  RenderPass,
  ShaderPass,
  UnrealBloomPass,
  SSAOPass,
  OutputPass,
} from 'three/addons/postprocessing'
import * as THREE from 'three'

// 初始化渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(window.innerWidth, window.innerHeight)
renderer.toneMapping = THREE.ACESFilmicToneMapping
renderer.toneMappingExposure = 1.0
document.body.appendChild(renderer.domElement)

// 创建 EffectComposer
const composer = new EffectComposer(renderer)

// 创建场景和相机
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  100
)

// 添加基础渲染 Pass（必须第一个）
const renderPass = new RenderPass(scene, camera)
composer.addPass(renderPass)

// 添加 Bloom 效果
const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight),
  1.5,  // 强度
  0.4,  // 半径
  0.85  // 阈值
)
composer.addPass(bloomPass)

// 添加输出 Pass（必须最后一个，负责色彩空间转换）
const outputPass = new OutputPass()
composer.addPass(outputPass)

// 渲染循环中使用 composer.render() 替代 renderer.render()
function animate() {
  requestAnimationFrame(animate)
  composer.render()
}
animate()
```

**关键点：** RenderPass 必须是链中的第一个，OutputPass 必须是最后一个。

## 三、Bloom（辉光）效果实现

Bloom 效果模拟的是高亮度区域的光线溢出，让亮的地方"发光"。

```
原始渲染 ──▶ 提取亮部 ──▶ 高斯模糊 ──▶ 与原图叠加 ──▶ Bloom 结果
              (阈值滤波)    (多 Pass)    (加法混合)
```

```typescript
import { EffectComposer, RenderPass, UnrealBloomPass, OutputPass } from 'three/addons/postprocessing'

// 创建一个发光物体
const emissiveGeometry = new THREE.SphereGeometry(1, 64, 64)
const emissiveMaterial = new THREE.MeshStandardMaterial({
  color: 0x00ff88,
  emissive: 0x00ff88,
  emissiveIntensity: 2.0,
})
const sphere = new THREE.Mesh(emissiveGeometry, emissiveMaterial)
scene.add(sphere)

// Bloom 参数调整
const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight),
  1.5,   // strength: Bloom 强度
  0.4,   // radius: Bloom 半径（越大扩散越广）
  0.85   // threshold: 亮度阈值（低于此值不产生 Bloom）
)
composer.addPass(bloomPass)
composer.addPass(new OutputPass())
```

通过调整 `emissiveIntensity` 和 Bloom 的 `threshold`，可以精确控制哪些区域产生辉光。

## 四、SSAO（环境光遮蔽）

SSAO（Screen Space Ambient Occlusion）模拟的是物体缝隙和角落处因光线被遮挡而变暗的效果，增加场景的真实感。

```typescript
import { EffectComposer, RenderPass, SSAOPass, OutputPass } from 'three/addons/postprocessing'

// SSAO 需要法线纹理
const normalRenderTarget = new THREE.WebGLRenderTarget(
  window.innerWidth,
  window.innerHeight,
  {
    type: THREE.HalfFloatType,
  }
)

const ssaoPass = new SSAOPass(
  scene,
  camera,
  window.innerWidth,
  window.innerHeight
)
ssaoPass.kernelRadius = 16    // 采样半径
ssaoPass.minDistance = 0.005  // 最小距离（避免自遮挡）
ssaoPass.maxDistance = 0.1    // 最大距离（超过此距离不计算遮蔽）

composer.addPass(renderPass)
composer.addPass(ssaoPass)
composer.addPass(new OutputPass())
```

SSAO 计算开销较大，需要在效果质量和性能之间做权衡。

## 五、自定义后处理 Shader

当内置 Pass 无法满足需求时，可以用 ShaderPass 编写自定义后处理效果。

### 暗角（Vignette）效果

```glsl
// 暗角效果 Fragment Shader
uniform sampler2D tDiffuse;    // 输入纹理（上一个 Pass 的输出）
uniform float uIntensity;      // 暗角强度
uniform float uSmoothness;     // 边缘过渡平滑度
varying vec2 vUv;

void main() {
  // 采样原始颜色
  vec4 color = texture2D(tDiffuse, vUv);

  // 计算当前像素到画面中心的距离
  vec2 center = vUv - 0.5;
  float dist = length(center);

  // 使用 smoothstep 创建平滑的暗角遮罩
  float vignette = smoothstep(0.8, 0.8 * uSmoothness, dist * (uIntensity + uIntensity));

  // 将暗角应用到颜色上
  color.rgb *= vignette;

  gl_FragColor = color;
}
```

### 在 TypeScript 中使用自定义 Shader

```typescript
import { ShaderPass } from 'three/addons/postprocessing'

const vignetteShader = {
  uniforms: {
    tDiffuse: { value: null },
    uIntensity: { value: 1.0 },
    uSmoothness: { value: 0.5 },
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform float uIntensity;
    uniform float uSmoothness;
    varying vec2 vUv;

    void main() {
      vec4 color = texture2D(tDiffuse, vUv);
      vec2 center = vUv - 0.5;
      float dist = length(center);
      float vignette = smoothstep(0.8, 0.8 * uSmoothness, dist * (uIntensity + uIntensity));
      color.rgb *= vignette;
      gl_FragColor = color;
    }
  `,
}

const vignettePass = new ShaderPass(vignetteShader)
composer.addPass(vignettePass)
```

## 六、完整的后处理管线示例

```typescript
import {
  EffectComposer,
  RenderPass,
  UnrealBloomPass,
  ShaderPass,
  OutputPass,
} from 'three/addons/postprocessing'

function setupPostProcessing(
  renderer: THREE.WebGLRenderer,
  scene: THREE.Scene,
  camera: THREE.Camera
): EffectComposer {
  const composer = new EffectComposer(renderer)

  // 第一步：基础渲染
  composer.addPass(new RenderPass(scene, camera))

  // 第二步：Bloom 辉光
  const bloom = new UnrealBloomPass(
    new THREE.Vector2(window.innerWidth, window.innerHeight),
    0.8, 0.3, 0.9
  )
  composer.addPass(bloom)

  // 第三步：自定义暗角
  const vignette = new ShaderPass(vignetteShader)
  composer.addPass(vignette)

  // 第四步：输出
  composer.addPass(new OutputPass())

  return composer
}

// 响应窗口大小变化
window.addEventListener('resize', () => {
  const w = window.innerWidth
  const h = window.innerHeight
  renderer.setSize(w, h)
  composer.setSize(w, h)
  camera.aspect = w / h
  camera.updateProjectionMatrix()
})
```

## 常见误区

### 1. 把所有效果都堆上去

后处理每个 Pass 都有性能开销。Bloom + SSAO + 色调映射 + 暗角全开，低端设备可能直接掉到 30fps 以下。应该根据产品定位选择必要的效果，并提供画质选项。

### 2. 忘记添加 OutputPass

OutputPass 负责最终的色彩空间转换（linear → sRGB）。如果不添加它，画面会显得过亮或颜色不正确。

### 3. Bloom 阈值设置不当

如果阈值太低，整个场景都会发光；如果太高，只有最亮的像素才有效果。通常阈值设在 0.8-0.95 之间，配合 emissive 材质使用。

### 4. 后处理与抗锯齿冲突

MSAA（多重采样抗锯齿）在后处理场景中表现不佳。使用 FXAA Pass 替代，或者在 Renderer 中开启 `antialias: true` 并使用 EffectComposer 的内置采样。

## 工程建议

1. **按需启用后处理效果：** 提供画质等级选项，让低端设备能关闭昂贵的效果如 SSAO
2. **使用 RenderTarget 的精度：** 对于需要高精度的效果（如 Bloom），使用 `HalfFloatType` 的 RenderTarget 避免色彩精度丢失
3. **监控 Draw Call：** 每个后处理 Pass 都会增加 Draw Call，使用 `renderer.info` 监控总绘制次数
4. **Pass 顺序很重要：** Bloom 应在色调映射之前，暗角应在所有色彩处理之后

## 小结

后处理是提升 3D 场景视觉品质的关键技术。通过 EffectComposer 管理多个 Pass，我们可以像搭积木一样组合各种图像效果。Three.js 提供了丰富的内置 Pass，同时支持自定义 Shader 实现独特的视觉风格。

### 练习二

**思路**：用 `ShaderPass` 编写自定义灰度 Shader。在片元着色器中采样原始颜色，用亮度公式（加权 RGB）转为灰度值，输出到屏幕。

**答案**：

```typescript
import * as THREE from "three";
import { EffectComposer, RenderPass, ShaderPass, OutputPass } from "three/addons/postprocessing";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x222233);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 2, 5);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: false });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

// 彩色场景物体
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0xff4444 });
const box = new THREE.Mesh(boxGeo, boxMat);
box.position.set(-1.5, 0, 0);
scene.add(box);

const sphereGeo = new THREE.SphereGeometry(0.6, 32, 32);
const sphereMat = new THREE.MeshStandardMaterial({ color: 0x44ff44 });
const sphere = new THREE.Mesh(sphereGeo, sphereMat);
scene.add(sphere);

const torusGeo = new THREE.TorusGeometry(0.5, 0.2, 16, 32);
const torusMat = new THREE.MeshStandardMaterial({ color: 0x4444ff });
const torus = new THREE.Mesh(torusGeo, torusMat);
torus.position.set(1.5, 0, 0);
scene.add(torus);

scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(3, 5, 3);
scene.add(dirLight);

// 自定义灰度 Shader
const GrayscaleShader = {
    uniforms: {
        tDiffuse: { value: null },
        uIntensity: { value: 1.0 }, // 1.0=完全灰度, 0.0=原始彩色
    },
    vertexShader: `
        varying vec2 vUv;
        void main() {
            vUv = uv;
            gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
        }
    `,
    fragmentShader: `
        uniform sampler2D tDiffuse;
        uniform float uIntensity;
        varying vec2 vUv;

        void main() {
            vec4 color = texture2D(tDiffuse, vUv);

            // ITU-R BT.709 亮度公式（人眼对绿色最敏感）
            float gray = dot(color.rgb, vec3(0.2126, 0.7152, 0.0722));

            // 在灰度和原始颜色之间插值
            color.rgb = mix(color.rgb, vec3(gray), uIntensity);

            gl_FragColor = color;
        }
    `,
};

// 后处理管线
const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

const grayscalePass = new ShaderPass(GrayscaleShader);
composer.addPass(grayscalePass);
composer.addPass(new OutputPass());

// 切换按钮
const btn = document.createElement("button");
btn.textContent = "切换灰度/彩色";
btn.style.position = "fixed";
btn.style.bottom = "20px";
btn.style.left = "50%";
btn.style.transform = "translateX(-50%)";
btn.style.padding = "8px 20px";
btn.style.cursor = "pointer";
document.body.appendChild(btn);

let isGrayscale = true;
btn.addEventListener("click", () => {
    isGrayscale = !isGrayscale;
    grayscalePass.uniforms.uIntensity.value = isGrayscale ? 1.0 : 0.0;
});

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();
    box.rotation.y += delta * 0.5;
    sphere.rotation.y += delta * 0.3;
    torus.rotation.x += delta * 0.4;
    composer.render();
}

animate();
```

**要点**：
- 自定义 Shader 需要 `vertexShader` 和 `fragmentShader`，以及 `uniforms` 声明
- `tDiffuse` 是上一个 Pass 的输出纹理，后处理 Shader 必须声明它
- 亮度公式 `dot(rgb, vec3(0.2126, 0.7152, 0.0722))` 是 ITU-R BT.709 标准，比简单平均更符合人眼感知
- `mix(a, b, t)` 在原始颜色和灰度之间插值，`t=1` 完全灰度，`t=0` 完全彩色

```typescript
let frameCount = 0;
let fps = 0;
let renderTime = 0;

function animate(): void {
    requestAnimationFrame(animate);

    const frameStart = performance.now();

    composer.render();

    const frameEnd = performance.now();
    renderTime = frameEnd - frameStart;

    // 每秒更新一次 FPS
    frameCount++;
    if (frameEnd - lastTime >= 1000) {
        fps = frameCount;
        frameCount = 0;
        lastTime = frameEnd;
    }

    // 更新面板
    const passCount = composer.passes.length;
    const drawCalls = renderer.info.render.calls;
    const triangles = renderer.info.render.triangles;

    perfPanel.innerHTML = `
        <div>FPS: ${fps}</div>
        <div>渲染耗时: ${renderTime.toFixed(2)} ms</div>
        <div>Pass 数量: ${passCount}</div>
        <div>Draw Call: ${drawCalls}</div>
        <div>三角形: ${triangles}</div>
    `;
}

animate();
```

**要点**：
- `composer.passes.length` 获取后处理管线中的 Pass 数量
- `renderer.info.render.calls` 和 `.triangles` 提供 Draw Call 和三角形计数
- `performance.now()` 的精度比 `Date.now()` 高，适合测量毫秒级渲染耗时
- FPS 用每秒帧数统计比逐帧计算更稳定，避免单帧抖动导致数值跳动
