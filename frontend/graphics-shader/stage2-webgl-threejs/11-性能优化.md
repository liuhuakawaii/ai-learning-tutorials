# 第十一课：性能优化

## 场景引入

你开发了一个 3D 产品展示页面，本地测试流畅无比，但上线后用户反馈"页面卡成 PPT"。检查发现，页面有 2000 颗树、100 个建筑模型，每帧的 Draw Call 超过 500 次，GPU 忙得喘不过气。3D 应用的性能优化，核心在于**减少 GPU 工作量**：减少 Draw Call、减少面数、减少纹理内存。这一课我们系统地学习这些优化手段。

## 学习目标

1. 掌握 InstancedMesh 实例化渲染，大幅减少 Draw Call
2. 理解 LOD（Level of Detail）的原理和使用
3. 学会视锥体剔除和遮挡剔除
4. 了解纹理压缩技术
5. 掌握 R3F 中的 React 性能优化技巧

## 一、理解 Draw Call

每次 CPU 告诉 GPU"画这个东西"，就是一次 Draw Call。每个不同材质的 mesh 都是一次独立的 Draw Call。

```
场景：100 个相同形状的树
─────────────────────────────────────────────────
未优化：100 个 mesh = 100 次 Draw Call
         CPU ──▶ [Draw 1] [Draw 2] ... [Draw 100] ──▶ GPU

实例化：1 个 InstancedMesh = 1 次 Draw Call
         CPU ──▶ [Draw 1 (100 instances)] ──▶ GPU
```

Draw Call 的瓶颈在 CPU 端。每次 Draw Call 都有状态切换开销（绑定 shader、设置 uniform、绑定纹理），减少 Draw Call 是 3D 性能优化的第一优先级。

## 二、InstancedMesh 实例化渲染

InstancedMesh 允许在一次 Draw Call 中渲染大量相同几何体和材质的物体，仅位置、旋转、颜色不同。

```typescript
import * as THREE from 'three'

// 创建 InstancedMesh
const count = 5000  // 实例数量
const geometry = new THREE.SphereGeometry(0.5, 16, 16)
const material = new THREE.MeshStandardMaterial({ color: 0x4488ff })
const instancedMesh = new THREE.InstancedMesh(geometry, material, count)

// 设置每个实例的变换矩阵
const dummy = new THREE.Object3D()
const color = new THREE.Color()

for (let i = 0; i < count; i++) {
  // 随机位置
  dummy.position.set(
    (Math.random() - 0.5) * 50,
    (Math.random() - 0.5) * 50,
    (Math.random() - 0.5) * 50
  )

  // 随机缩放
  const scale = 0.3 + Math.random() * 0.7
  dummy.scale.set(scale, scale, scale)

  // 更新变换矩阵
  dummy.updateMatrix()
  instancedMesh.setMatrixAt(i, dummy.matrix)

  // 随机颜色（可选）
  color.setHSL(Math.random(), 0.7, 0.6)
  instancedMesh.setColorAt(i, color)
}

// 标记矩阵需要更新
instancedMesh.instanceMatrix.needsUpdate = true
if (instancedMesh.instanceColor) {
  instancedMesh.instanceColor.needsUpdate = true
}

scene.add(instancedMesh)
```

### R3F 中的 InstancedMesh

```tsx
import { useRef, useMemo } from 'react'
import { useFrame } from '@react-three/fiber'
import * as THREE from 'three'

function InstancedSpheres({ count = 1000 }) {
  const meshRef = useRef<THREE.InstancedMesh>(null!)

  const { positions, dummy } = useMemo(() => {
    const positions = Array.from({ length: count }, () => ({
      x: (Math.random() - 0.5) * 40,
      y: (Math.random() - 0.5) * 40,
      z: (Math.random() - 0.5) * 40,
      speed: 0.5 + Math.random() * 2,
    }))
    return { positions, dummy: new THREE.Object3D() }
  }, [count])

  useFrame((state) => {
    const t = state.clock.elapsedTime
    for (let i = 0; i < count; i++) {
      const { x, y, z, speed } = positions[i]
      dummy.position.set(
        x + Math.sin(t * speed) * 0.5,
        y + Math.cos(t * speed * 0.8) * 0.5,
        z
      )
      dummy.updateMatrix()
      meshRef.current.setMatrixAt(i, dummy.matrix)
    }
    meshRef.current.instanceMatrix.needsUpdate = true
  })

  return (
    <instancedMesh ref={meshRef} args={[undefined, undefined, count]}>
      <sphereGeometry args={[0.2, 16, 16]} />
      <meshStandardMaterial color="hotpink" />
    </instancedMesh>
  )
}
```

注意：R3F 中使用 `<instancedMesh>` 标签，`args` 的第三个参数是实例数量。

## 三、LOD（Level of Detail）

LOD 根据物体与相机的距离，自动切换不同精度的模型。远处的物体用低面数模型，近处用高面数模型。

```
相机                       远处 LOD 0 (500 面)    中等 LOD 1 (2000 面)    近处 LOD 2 (10000 面)
 │                              ┌───┐                 ┌─────┐                 ┌───────┐
 │                              │   │                 │     │                 │       │
 │     ◀── 50m ──▶             └───┘                 │     │                 │       │
 │     ◀── 20m ──▶                                   └─────┘                 │       │
 │     ◀── 5m ──▶                                                            └───────┘
```

### Three.js 中的 LOD

```typescript
import * as THREE from 'three'

const lod = new THREE.LOD()

// 高精度模型（近距离）
const highDetail = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 64),
  new THREE.MeshStandardMaterial({ color: 'red' })
)
lod.addLevel(highDetail, 0)    // 0m 开始使用

// 中精度模型
const midDetail = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),
  new THREE.MeshStandardMaterial({ color: 'red' })
)
lod.addLevel(midDetail, 20)    // 20m 开始使用

// 低精度模型（远距离）
const lowDetail = new THREE.Mesh(
  new THREE.SphereGeometry(1, 8, 8),
  new THREE.MeshStandardMaterial({ color: 'red' })
)
lod.addLevel(lowDetail, 50)    // 50m 开始使用

scene.add(lod)
```

### R3F 中的 LOD

```tsx

  </mesh>
  <mesh>
    <sphereGeometry args={[1, 8, 8]} />
    <meshStandardMaterial color="red" />
  </mesh>
</LOD>
```

## 四、视锥体剔除（Frustum Culling）

Three.js 默认开启视锥体剔除：不在相机视野内的物体不会被渲染。这是最基础也最有效的优化。

```
           相机视锥体
          /─────────\
         /   可见区域  \
        /    ✓  ✓  ✓    \
       /  ✓         ✓    \
      /───────────────────\
                  ✗  ✗     ← 视锥体外的物体不渲染
```

```typescript
// Three.js 默认自动执行视锥体剔除
// 但可以手动控制单个物体是否参与剔除
mesh.frustumCulled = true   // 默认值，参与剔除
mesh.frustumCulled = false  // 禁用剔除（始终渲染）

// 对于粒子系统或始终在视野内的物体，可以禁用剔除减少 CPU 计算
```

## 五、遮挡剔除（Occlusion Culling）

遮挡剔除判断物体是否被其他物体完全遮挡，被遮挡的物体不渲染。Three.js 本身不内置此功能，但可以用 `OcclusionQuery` 手动实现。

```
         相机
          │
          ▼
    ┌───────────┐
    │  墙壁 A    │  ← 渲染（可见）
    │  (不透明)   │
    └───────────┘
    ┌───────────┐
    │  物体 B    │  ← 不渲染（被 A 完全遮挡）
    └───────────┘
```

对于简单场景，遮挡剔除的开销可能大于收益。它更适合室内场景或有大量遮挡物的环境。

## 六、Draw Call 合并策略

### 几何体合并

```typescript
import { BufferGeometryUtils } from 'three/addons/utils/BufferGeometryUtils'

// 将多个几何体合并为一个
const geometries = meshes.map((mesh) => mesh.geometry.clone())

// 应用各自的变换矩阵
meshes.forEach((mesh, i) => {
  geometries[i].applyMatrix4(mesh.matrixWorld)
})

// 合并
const mergedGeometry = BufferGeometryUtils.mergeGeometries(geometries)
const mergedMesh = new THREE.Mesh(mergedGeometry, sharedMaterial)
scene.add(mergedMesh)
```

合并后只有一个 mesh，一次 Draw Call。代价是失去了对单个物体的独立控制。

### 材质图集（Texture Atlas）

将多个小纹理合并到一张大纹理上，让不同物体共享同一材质。

```
┌─────────────────────────────────┐
│  纹理图集 (2048x2048)            │
│  ┌──────┐  ┌──────┐            │
│  │ 木头  │  │ 石头  │            │
│  │ UV区  │  │ UV区  │            │
│  └──────┘  └──────┘            │
│  ┌──────┐  ┌──────┐            │
│  │ 草地  │  │ 金属  │            │
│  │ UV区  │  │ UV区  │            │
│  └──────┘  └──────┘            │
└─────────────────────────────────┘
```

## 七、纹理压缩

未压缩的纹理会占用大量 GPU 显存。使用压缩纹理格式可以显著减少内存占用和加载时间。

```typescript
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader'
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js'

const ktx2Loader = new KTX2Loader()
  .setTranscoderPath('/basis/')  // Basis Universal 转码器路径
  .detectSupport(renderer)

ktx2Loader.load('/textures/diffuse.ktx2', (texture) => {
  material.map = texture
  material.needsUpdate = true
})
```

```
格式              压缩率      适用场景
─────────────────────────────────────────────
PNG               无压缩      UI、需要透明通道
JPG               有损        照片类纹理
Basis/KTX2        6-8 倍      通用（推荐）
DDS (DXT/BC)      4 倍        桌面端
ASTC              4-6 倍      移动端（高质量）
```

## 常见误区

### 1. 过早优化

不要在项目初期就花大量时间做 LOD、合并几何体。先用最简单的方式实现功能，用性能监控工具找到真正的瓶颈，再针对性优化。

### 2. 忽略 JavaScript 端的性能

GPU 不是唯一的瓶颈。如果 JavaScript 端每帧都在做大量计算（比如遍历 1000 个物体更新位置），CPU 也会成为瓶颈。用 `requestAnimationFrame` 的 `delta` 和 Chrome Performance 面板定位问题。

### 3. 盲目降低面数

减少面数确实能提升顶点着色器性能，但现代 GPU 的瓶颈通常在片元着色器（像素填充率）和 Draw Call 数量上。减少 50% 的面数可能只带来 5% 的帧率提升。

### 4. 忘记 dispose 资源

Three.js 的 geometry、material、texture 不会自动垃圾回收。切换场景时如果不手动 dispose，GPU 显存会持续增长直到崩溃。

## 工程建议

1. **优先减少 Draw Call：** 使用 InstancedMesh、合并几何体、共享材质，效果最显著
2. **合理使用 LOD：** 对于大量重复物体（树木、建筑）效果明显，对于少量物体不必使用
3. **纹理压缩必做：** KTX2 + Basis Universal 是目前最通用的方案，压缩率 6-8 倍
4. **用 R3F 的 Perf 组件：** `@react-three/perf` 提供实时的 GPU/CPU/内存监控面板

## 小结

3D 性能优化的核心是减少 GPU 工作量：减少 Draw Call（InstancedMesh、几何体合并）、减少渲染面数（LOD、视锥体剔除）、减少显存占用（纹理压缩、资源 dispose）。R3F 中还需要注意 React 层面的优化，避免不必要的组件重渲染。

## 参考答案

### 练习一

**思路**：用 `THREE.InstancedMesh` 将 5000 个球体合并为 1 个 Draw Call。通过 `setMatrixAt` 为每个实例设置独立的变换矩阵（位置、旋转、缩放），用 `setColorAt` 设置独立颜色。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 200);
camera.position.set(0, 30, 50);
camera.lookAt(0, 0, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(20, 30, 20);
scene.add(dirLight);

const INSTANCE_COUNT = 5000;
const SPREAD_RANGE = 40;

// InstancedMesh：一个几何体 + 一个材质 = 1 个 Draw Call
const geometry = new THREE.SphereGeometry(0.3, 16, 16);
const material = new THREE.MeshStandardMaterial({ roughness: 0.5, metalness: 0.3 });
const instancedMesh = new THREE.InstancedMesh(geometry, material, INSTANCE_COUNT);

const matrix = new THREE.Matrix4();
const color = new THREE.Color();
const position = new THREE.Vector3();
const quaternion = new THREE.Quaternion();
const scale = new THREE.Vector3(1, 1, 1);

for (let i = 0; i < INSTANCE_COUNT; i++) {
    // 随机位置
    position.set(
        (Math.random() - 0.5) * SPREAD_RANGE,
        (Math.random() - 0.5) * SPREAD_RANGE,
        (Math.random() - 0.5) * SPREAD_RANGE
    );

    // 构建变换矩阵
    matrix.compose(position, quaternion, scale);
    instancedMesh.setMatrixAt(i, matrix);

    // 随机颜色
    color.setHSL(Math.random(), 0.7, 0.6);
    instancedMesh.setColorAt(i, color);
}

instancedMesh.instanceMatrix.needsUpdate = true;
instancedMesh.instanceColor!.needsUpdate = true;

scene.add(instancedMesh);

// 打印 Draw Call 数量
console.log("InstancedMesh Draw Call 数量:", renderer.info.render.calls); // 应该是 1

// 对比：如果用普通 Mesh，需要 5000 个 Draw Call
// for (let i = 0; i < 5000; i++) {
//     const mesh = new THREE.Mesh(geometry, material);
//     mesh.position.random().multiplyScalar(40).subScalar(20);
//     scene.add(mesh);
// }
// console.log("普通 Mesh Draw Call 数量:", renderer.info.render.calls); // 5000+

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    instancedMesh.rotation.y += clock.getDelta() * 0.05;
    renderer.render(scene, camera);
    // 渲染后再查看 Draw Call
    // console.log("每帧 Draw Call:", renderer.info.render.calls);
}

animate();
```

**要点**：
- `InstancedMesh` 将同一几何体的多个实例合并为 1 个 Draw Call，是大量重复物体的性能最优解
- `setMatrixAt` 的矩阵包含位置、旋转、缩放信息，用 `Matrix4.compose()` 从分量构建
- `setColorAt` 让每个实例有独立颜色，不需要额外的材质
- `instanceMatrix.needsUpdate = true` 必须设置，否则修改不会生效
- 5000 个普通 Mesh = 5000 Draw Call，InstancedMesh = 1 Draw Call，性能差距巨大

### 练习二

**思路**：Three.js 的 `LOD`（Level of Detail）对象根据物体到相机的距离自动切换不同精度的模型。创建 3 个不同面数的球体，用 `addLevel` 添加到 LOD 并设置切换距离。

**答案**：

```typescript
import * as THREE from "three";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111122);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 500);
camera.position.set(0, 5, 15);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(10, 10, 10);
scene.add(dirLight);

const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;

// 创建 LOD 对象
const lod = new THREE.LOD();

// 高精度版本（近距离）：64x64 分段
const highGeo = new THREE.SphereGeometry(2, 64, 64);
const highMat = new THREE.MeshStandardMaterial({ color: 0x4fc3f7, wireframe: false });
const highMesh = new THREE.Mesh(highGeo, highMat);
lod.addLevel(highMesh, 0); // 距离 0~20 时显示

// 中精度版本（中距离）：16x16 分段
const midGeo = new THREE.SphereGeometry(2, 16, 16);
const midMat = new THREE.MeshStandardMaterial({ color: 0x66bb6a, wireframe: false });
const midMesh = new THREE.Mesh(midGeo, midMat);
lod.addLevel(midMesh, 20); // 距离 20~50 时显示

// 低精度版本（远距离）：8x8 分段
const lowGeo = new THREE.SphereGeometry(2, 8, 8);
const lowMat = new THREE.MeshStandardMaterial({ color: 0xff7043, wireframe: false });
const lowMesh = new THREE.Mesh(lowGeo, lowMat);
lod.addLevel(lowMesh, 50); // 距离 50+ 时显示

scene.add(lod);

// 添加距离标注
const infoDiv = document.createElement("div");
infoDiv.style.position = "fixed";
infoDiv.style.top = "10px";
infoDiv.style.left = "10px";
infoDiv.style.padding = "10px";
infoDiv.style.background = "rgba(0,0,0,0.8)";
infoDiv.style.color = "#fff";
infoDiv.style.fontFamily = "monospace";
infoDiv.style.fontSize = "13px";
infoDiv.style.borderRadius = "6px";
document.body.appendChild(infoDiv);

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    controls.update();

    const distance = camera.position.distanceTo(lod.position);
    const level = lod.getCurrentLevel(); // 当前显示的 LOD 级别
    const levelNames = ["高精度 (64x64)", "中精度 (16x16)", "低精度 (8x8)"];
    const levelColors = ["#4fc3f7", "#66bb6a", "#ff7043"];

    infoDiv.innerHTML = `
        <div>距离: ${distance.toFixed(1)}</div>
        <div>当前级别: <span style="color:${levelColors[level]}">${levelNames[level]}</span></div>
        <div>面数: ${[highGeo, midGeo, lowGeo][level].index!.count / 3}</div>
    `;

    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `lod.addLevel(mesh, distance)` 的 `distance` 是从此距离开始显示该级别
- LOD 自动根据相机到物体中心的距离选择合适的级别，无需手动判断
- 高精度版本距离阈值为 0（最近时显示），低精度版本距离阈值最大（最远时显示）
- 三个精度级别共用同一个 LOD 对象，Three.js 自动管理切换

### 练习三

**思路**：用 `React.memo` 包裹子组件，只有当 props 变化时才重渲染。配合 `useCallback` 稳定事件处理函数引用，确保未被交互的组件不会因为父组件重渲染而跟着重渲染。

**答案**：

```tsx
import { useState, useCallback, memo } from "react";
import { Canvas, useFrame } from "@react-three/fiber";
import * as THREE from "three";

interface ItemProps {
    id: number;
    position: [number, number, number];
    isSelected: boolean;
    onSelect: (id: number) => void;
}

// 用 memo 包裹：只有 props 变化时才重渲染
const CubeItem = memo(function CubeItem({ id, position, isSelected, onSelect }: ItemProps) {
    const meshRef = useRef<THREE.Mesh>(null!);

    useFrame((_, delta) => {
        if (meshRef.current) {
            meshRef.current.rotation.y += delta * 0.3;
        }
    });

    // 打印渲染次数（开发时验证 memo 效果）
    console.log(`CubeItem ${id} rendered`);

    return (
        <mesh
            ref={meshRef}
            position={position}
            onClick={(e) => {
                e.stopPropagation();
                onSelect(id);
            }}
        >
            <boxGeometry args={[0.5, 0.5, 0.5]} />
            <meshStandardMaterial
                color={isSelected ? "#ff4444" : "#4fc3f7"}
                emissive={isSelected ? "#ff4444" : "#000000"}
                emissiveIntensity={isSelected ? 0.3 : 0}
            />
        </mesh>
    );
});

// 生成 100 个物体的位置
const ITEMS = Array.from({ length: 100 }, (_, i) => ({
    id: i,
    position: [
        (Math.floor(i / 10) - 5) * 1.2,
        0,
        ((i % 10) - 5) * 1.2,
    ] as [number, number, number],
}));

function Scene() {
    const [selectedId, setSelectedId] = useState<number | null>(null);

    // 用 useCallback 稳定函数引用，避免每次渲染创建新函数
    const handleSelect = useCallback((id: number) => {
        setSelectedId((prev) => (prev === id ? null : id));
    }, []);

    return (
        <>
            {ITEMS.map((item) => (
                <CubeItem
                    key={item.id}
                    id={item.id}
                    position={item.position}
                    isSelected={selectedId === item.id}
                    onSelect={handleSelect}
                />
            ))}
        </>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [0, 10, 15], fov: 60 }}>
            <ambientLight intensity={0.4} />
            <directionalLight position={[10, 10, 10]} intensity={1.0} />
            <Scene />
        </Canvas>
    );
}
```

**要点**：
- `React.memo` 对比 props 的浅比较，只有 `id`、`position`、`isSelected`、`onSelect` 中任一变化时组件才重渲染
- `useCallback` 的依赖数组为 `[]`，确保 `handleSelect` 引用永远不变，否则 memo 会失效
- 点击某个物体时，只有它的 `isSelected` 从 `false` 变为 `true`，其他 99 个组件的 props 不变，不会重渲染
- `position` 数组在 `ITEMS` 中预先创建，引用稳定，不会每帧生成新数组
