# 第十课：物理引擎集成

## 场景引入

你在游戏中见过这样的场景：箱子从高处掉落，碰到地面后弹起再落下；两个球碰撞后各自改变方向；一条绳子挂住物体自然下垂。这些逼真的物理行为不是逐帧手写位置计算出来的，而是由**物理引擎**在后台模拟刚体运动、碰撞检测和约束求解。在 R3F 生态中，`@react-three/rapier` 提供了开箱即用的物理模拟能力。

## 学习目标

1. 理解物理引擎的核心概念：刚体、碰撞体、约束
2. 掌握 @react-three/rapier 的基本使用
3. 学会处理碰撞检测事件
4. 理解物理材质参数（摩擦力、弹性）
5. 了解 cannon-es 作为替代方案

## 一、物理引擎核心概念

### 刚体（Rigid Body）

刚体是不会变形的物体，物理引擎只模拟它的平移和旋转运动。

```
类型            说明                    示例
──────────────────────────────────────────────────
Dynamic         受力和碰撞影响          掉落的箱子、球
Kinematic       可以移动但不受力影响    电梯、移动平台
Fixed           完全不动                地面、墙壁
```

### 碰撞体（Collider）

碰撞体是刚体的几何形状，用于碰撞检测。它独立于渲染用的 mesh，可以更简单（用低精度形状提高性能）。

```
渲染网格（高精度）         碰撞体（低精度）
    ┌─────┐                  ┌─────┐
   /│    /│                 /│    /│
  / │   / │      ──▶       / │   / │
 ┌─────┐  │               ┌─────┐  │
 │  │  │  │               │  │  │  │
 │ /   │ /                │ /   │ /
 │/    │/                 │/    │/
 └─────┘                  └─────┘
  10000 三角面              12 三角面（Box Collider）
```

### 约束（Constraint）

约束限制刚体之间的相对运动，比如铰链（门）、滑轨（抽屉）、弹簧（悬挂）。

### 基本物理场景

```tsx
import { Canvas } from '@react-three/fiber'
import {
  Physics,
  RigidBody,
  CuboidCollider,
  BallCollider,
  MeshCollider,
} from '@react-three/rapier'
import { OrbitControls, Grid } from '@react-three/drei'

function FallingBox() {
  return (
    <RigidBody position={[0, 5, 0]}>
      <mesh castShadow>
        <boxGeometry args={[1, 1, 1]} />
        <meshStandardMaterial color="hotpink" />
      </mesh>
    </RigidBody>
  )
}

function FallingSphere() {
  return (
    <RigidBody position={[1, 8, 0]} colliders="ball">
      <mesh castShadow>
        <sphereGeometry args={[0.5, 32, 32]} />
        <meshStandardMaterial color="orange" />
      </mesh>
    </RigidBody>
  )
}

function Ground() {
  return (
    <RigidBody type="fixed">
      <mesh rotation={[-Math.PI / 2, 0, 0]} receiveShadow>
        <planeGeometry args={[20, 20]} />
        <meshStandardMaterial color="#cccccc" />
      </mesh>
    </RigidBody>
  )
}

export default function App() {
  return (
    <Canvas camera={{ position: [5, 5, 10] }} shadows>
      <ambientLight intensity={0.5} />
      <directionalLight position={[5, 10, 5]} castShadow />

      <Physics gravity={[0, -9.81, 0]} debug>
        <FallingBox />
        <FallingSphere />
        <Ground />
      </Physics>

      <OrbitControls />
    </Canvas>
  )
}
```

`Physics` 组件是物理世界的容器，所有需要物理行为的物体必须放在它内部。`gravity` 设置重力加速度，`debug` 模式会显示碰撞体线框。

## 三、RigidBody 属性详解

```tsx
<RigidBody
  // 刚体类型
  type="dynamic"          // dynamic | kinematic | fixed

  // 初始位置和旋转
  position={[0, 5, 0]}
  rotation={[0, 0, 0]}

  // 物理属性
  mass={1}                // 质量（千克）
  linearDamping={0}       // 线性阻尼（速度衰减）
  angularDamping={0.5}    // 角速度阻尼

  // 碰撞体
  colliders="cuboid"      // 自动创建碰撞体：cuboid | ball | hull | trimesh
  // 或使用自定义碰撞体子组件
>
  <mesh>
    <boxGeometry />
    <meshStandardMaterial />
  </mesh>
</RigidBody>
```

`colliders` 属性控制自动生成的碰撞体形状。`"cuboid"` 是包围盒，`"ball"` 是球体包围，`"hull"` 是凸包，`"trimesh"` 是精确网格（性能差，仅用于静态物体）。

## 四、碰撞检测事件

```tsx
import { RigidBody, RapierRigidBody } from '@react-three/rapier'
import { useRef } from 'react'

function InteractiveBox() {
  const rigidRef = useRef<RapierRigidBody>(null)

  return (
    <RigidBody
      ref={rigidRef}
      position={[0, 3, 0]}
      // 碰撞开始
      onCollisionEnter={({ manifold, target, other }) => {
        console.log('碰撞开始！')
        console.log('碰撞点数:', manifold.solverContacts)
        console.log('当前对象:', target.rigidBodyObject?.name)
      }}
      // 碰撞结束
      onCollisionExit={({ target, other }) => {
        console.log('碰撞结束')
      }}
      // 传感器模式（触发器，不产生物理响应）
      // sensor
      // onIntersectionEnter={() => console.log('进入触发区域')}
      // onIntersectionExit={() => console.log('离开触发区域')}
    >
      <mesh castShadow>
        <boxGeometry args={[1, 1, 1]} />
        <meshStandardMaterial color="yellow" />
      </mesh>
    </RigidBody>
  )
}
```

碰撞事件在检测到接触时触发，适合用于播放音效、计分、触发动画等逻辑。

## 五、物理材质

物理材质控制物体表面的摩擦力和弹性。

```tsx
import { RigidBody } from '@react-three/rapier'

// 方式一：通过 Physics 全局设置
<Physics
  gravity={[0, -9.81, 0]}
  defaultRestitution={0.5}    // 默认弹性
  defaultFriction={0.5}       // 默认摩擦力
>
  {/* ... */}
</Physics>

// 方式二：通过 RigidBody 局部设置
<RigidBody
  position={[0, 5, 0]}
  friction={0.1}              // 低摩擦（光滑表面）
  restitution={0.8}           // 高弹性（弹力球）
>
  <mesh>
    <sphereGeometry args={[0.5, 32, 32]} />
    <meshStandardMaterial color="lime" />
  </mesh>
</RigidBody>
```

```
参数             范围        说明
──────────────────────────────────────────────
friction        0 ~ 1       0 = 无摩擦（冰面），1 = 高摩擦（橡胶）
restitution     0 ~ 1       0 = 完全不弹，1 = 完全弹性碰撞
```

## 六、堆叠示例：多个物体的物理模拟

```tsx
import { Canvas, useFrame } from '@react-three/fiber'
import { Physics, RigidBody } from '@react-three/rapier'
import { useRef, useState } from 'react'

function BoxStack() {
  const rows = 5
  const boxes = []

  for (let row = 0; row < rows; row++) {
    const count = rows - row
    for (let i = 0; i < count; i++) {
      const x = (i - (count - 1) / 2) * 1.1
      const y = row * 1.1 + 0.5
      boxes.push(
        <RigidBody
          key={`${row}-${i}`}
          position={[x, y, 0]}
          friction={0.7}
          restitution={0.1}
        >
          <mesh castShadow>
            <boxGeometry args={[1, 1, 1]} />
            <meshStandardMaterial
              color={`hsl(${row * 40 + i * 20}, 70%, 60%)`}
            />
          </mesh>
        </RigidBody>
      )
    }
  }

  return <>{boxes}</>
}

function ShootingBall() {
  const ref = useRef<any>(null)
  const [resetKey, setResetKey] = useState(0)

  useFrame(({ pointer }) => {
    // 跟随鼠标位置
    if (ref.current) {
      ref.current.setTranslation({
        x: pointer.x * 5,
        y: 2,
        z: 0,
      })
    }
  })

  const handleClick = () => {
    if (ref.current) {
      ref.current.setLinvel({ x: 0, y: 0, z: -20 }, true)
    }
  }

  return (
    <RigidBody ref={ref} colliders="ball" type="kinematicPosition">
      <mesh onClick={handleClick}>
        <sphereGeometry args={[0.4, 32, 32]} />
        <meshStandardMaterial color="red" />
      </mesh>
    </RigidBody>
  )
}

export default function App() {
  return (
    <Canvas camera={{ position: [0, 5, 15], fov: 50 }} shadows>
      <ambientLight intensity={0.5} />
      <directionalLight position={[5, 10, 5]} castShadow />

      <Physics gravity={[0, -9.81, 0]}>
        {/* 地面 */}
        <RigidBody type="fixed">
          <mesh rotation={[-Math.PI / 2, 0, 0]} receiveShadow>
            <planeGeometry args={[30, 30]} />
            <meshStandardMaterial color="#ddd" />
          </mesh>
        </RigidBody>

        <BoxStack />
        <ShootingBall />
      </Physics>
    </Canvas>
  )
}
```

## 七、cannon-es 替代方案

`use-cannon` 是基于 cannon-es 的 R3F 物理库，API 风格略有不同。

```tsx
import { Physics, useSphere, useBox, usePlane } from '@react-three/cannon'

function CannonBall() {
  const [ref] = useSphere(() => ({
    mass: 1,
    position: [0, 5, 0],
    args: [0.5],
  }))

  return (
    <mesh ref={ref}>
      <sphereGeometry args={[0.5, 32, 32]} />
      <meshStandardMaterial color="orange" />
    </mesh>
  )
}

function CannonGround() {
  const [ref] = usePlane(() => ({
    rotation: [-Math.PI / 2, 0, 0],
    type: 'Static',
  }))

  return (
    <mesh ref={ref} receiveShadow>
      <planeGeometry args={[20, 20]} />
      <meshStandardMaterial color="#ccc" />
    </mesh>
  )
}
```

cannon-es 使用 hook 返回 ref 的模式，而 rapier 使用声明式组件模式。rapier 的性能通常更好，是目前 R3F 生态的推荐选择。

## 常见误区

### 1. 给渲染网格使用 trimesh 碰撞体

trimesh 碰撞体精度高但性能极差，且对动态物体不稳定。动态物体应使用 cuboid、ball 或 hull 等简化碰撞体。

### 2. 忘记设置地面为 fixed 类型

默认 RigidBody 类型是 dynamic，地面如果也是 dynamic，会因为重力掉下去。地面必须设置为 `type="fixed"`。

### 3. 物理参数与视觉参数混淆

物体的大小由碰撞体决定，不是由 mesh 决定。如果碰撞体和 mesh 大小不一致，物体会"穿模"或浮在空中。

### 4. 每帧直接修改位置

物理引擎需要通过力和冲量来驱动物体。直接 `setTranslation` 会绕过物理计算，导致碰撞检测异常。仅在必要时使用 kinematic 类型并直接控制。

## 工程建议

1. **碰撞体尽量简化：** 用 cuboid 和 ball 替代精确网格，性能提升显著
2. **使用 debug 模式开发：** Physics 的 debug 属性可以可视化碰撞体，方便调试
3. **合理设置阻尼：** linearDamping 和 angularDamping 可以防止物体无限滚动，让模拟更可控
4. **物理和渲染分离：** 碰撞体用简单形状，渲染用复杂模型，两者独立管理

## 小结

物理引擎让 3D 场景从静态展示变为动态模拟。@react-three/rapier 以声明式的方式将物理模拟集成到 R3F 中，RigidBody + Collider 的组合覆盖了大部分物理场景需求。碰撞检测事件让你能响应物理交互，实现丰富的用户反馈。

## 参考答案

### 练习一

**思路**：用 `@react-three/rapier` 的 `Physics` 和 `RigidBody` 创建物理世界。5 个球设置不同的初始 Y 坐标（高度），地面用 `type="fixed"` 固定。Rapier 会自动模拟重力、碰撞和弹跳。

**答案**：

```tsx
import { Canvas } from "@react-three/fiber";
import { Physics, RigidBody } from "@react-three/rapier";
import { OrbitControls } from "@react-three/drei";

function FallingBall({ position, color }: { position: [number, number, number]; color: string }) {
    return (
        <RigidBody position={position} colliders="ball" restitution={0.7}>
            <mesh castShadow>
                <sphereGeometry args={[0.4, 32, 32]} />
                <meshStandardMaterial color={color} />
            </mesh>
        </RigidBody>
    );
}

function Ground() {
    return (
        <RigidBody type="fixed" colliders="cuboid">
            <mesh receiveShadow rotation={[-Math.PI / 2, 0, 0]}>
                <planeGeometry args={[20, 20]} />
                <meshStandardMaterial color="#444455" />
            </mesh>
        </RigidBody>
    );
}

// 围栏防止球滚出视野
function Wall({ position, rotation }: { position: [number, number, number]; rotation: [number, number, number] }) {
    return (
        <RigidBody type="fixed" colliders="cuboid" position={position} rotation={rotation}>
            <mesh>
                <boxGeometry args={[20, 2, 0.2]} />
                <meshStandardMaterial color="#333344" transparent opacity={0.3} />
            </mesh>
        </RigidBody>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [8, 8, 12], fov: 50 }} shadows>
            <ambientLight intensity={0.4} />
            <directionalLight position={[5, 10, 5]} intensity={1.0} castShadow />

            <Physics gravity={[0, -9.81, 0]} debug>
                {/* 5 个球从不同高度掉落 */}
                <FallingBall position={[-2, 8, 0]} color="#ff4444" />
                <FallingBall position={[-1, 6, 0.5]} color="#44ff44" />
                <FallingBall position={[0, 10, -0.5]} color="#4444ff" />
                <FallingBall position={[1, 5, 0.3]} color="#ffff44" />
                <FallingBall position={[2, 7, -0.3]} color="#ff44ff" />

                <Ground />
                <Wall position={[0, 1, 5]} rotation={[0, 0, 0]} />
                <Wall position={[0, 1, -5]} rotation={[0, 0, 0]} />
                <Wall position={[5, 1, 0]} rotation={[0, Math.PI / 2, 0]} />
                <Wall position={[-5, 1, 0]} rotation={[0, Math.PI / 2, 0]} />
            </Physics>

            <OrbitControls />
        </Canvas>
    );
}
```

**要点**：
- `restitution`（弹性系数）控制弹跳高度，0=不弹，1=完全弹性碰撞
- `type="fixed"` 让地面不受重力和碰撞影响，固定不动
- `gravity={[0, -9.81, 0]}` 模拟真实重力加速度（米/秒²）
- `debug` 模式显示碰撞体线框，开发阶段建议开启，生产环境关闭

### 练习二

**思路**：弹珠台需要：斜坡（倾斜的固定刚体）、挡板（可旋转的运动学刚体）、弹射器（点击后对弹珠施加力）。用 `type="kinematic"` 控制挡板旋转，用 `RigidBody.applyImpulse()` 实现弹射。

**答案**：

```tsx
import { useRef, useCallback } from "react";
import { Canvas, useFrame } from "@react-three/fiber";
import { Physics, RigidBody, RapierRigidBody } from "@react-three/rapier";
import { OrbitControls } from "@react-three/drei";
import * as THREE from "three";

function Ramp() {
    return (
        <RigidBody type="fixed" colliders="cuboid" position={[0, 3, -3]} rotation={[0.4, 0, 0]}>
            <mesh>
                <boxGeometry args={[3, 0.2, 6]} />
                <meshStandardMaterial color="#555566" />
            </mesh>
        </RigidBody>
    );
}

function Flipper({ position, side }: { position: [number, number, number]; side: "left" | "right" }) {
    const ref = useRef<RapierRigidBody>(null!);
    const active = useRef(false);

    useFrame(() => {
        if (!ref.current) return;
        const targetAngle = active.current ? (side === "left" ? 0.5 : -0.5) : 0;
        const current = ref.current.rotation();
        const currentEuler = new THREE.Euler().setFromQuaternion(
            new THREE.Quaternion(current.x, current.y, current.z, current.w)
        );
        const newAngle = THREE.MathUtils.lerp(currentEuler.z, targetAngle, 0.2);
        ref.current.setNextKinematicRotation(
            new THREE.Quaternion().setFromEuler(new THREE.Euler(0, 0, newAngle))
        );
    });

    return (
        <RigidBody
            ref={ref}
            type="kinematic"
            position={position}
            colliders="cuboid"
            onPointerDown={() => { active.current = true; }}
            onPointerUp={() => { active.current = false; }}
        >
            <mesh>
                <boxGeometry args={[1.5, 0.15, 0.3]} />
                <meshStandardMaterial color="#ff8800" />
            </mesh>
        </RigidBody>
    );
}

function Marble({ onLaunch }: { onLaunch: (ref: RapierRigidBody) => void }) {
    const ref = useRef<RapierRigidBody>(null!);

    const handleLaunch = useCallback(() => {
        if (ref.current) {
            ref.current.setTranslation({ x: 0, y: 1, z: 4 }, true);
            ref.current.setLinvel({ x: 0, y: 0, z: 0 }, true);
            // 向前上方弹射
            setTimeout(() => {
                ref.current.applyImpulse({ x: 0, y: 8, z: -15 }, true);
            }, 50);
        }
    }, []);

    return (
        <>
            <RigidBody ref={ref} colliders="ball" position={[0, 1, 4]} restitution={0.5}>
                <mesh castShadow>
                    <sphereGeometry args={[0.25, 32, 32]} />
                    <meshStandardMaterial color="#ff4444" metalness={0.8} roughness={0.2} />
                </mesh>
            </RigidBody>
            <LaunchButton onClick={handleLaunch} />
        </>
    );
}

function LaunchButton({ onClick }: { onClick: () => void }) {
    return (
        <mesh position={[0, 0.5, 5]} onClick={onClick}>
            <boxGeometry args={[1.5, 0.5, 0.5]} />
            <meshStandardMaterial color="#44ff44" />
        </mesh>
    );
}

function Walls() {
    return (
        <>
            <RigidBody type="fixed" colliders="cuboid" position={[0, 1, 0]}>
                <mesh>
                    <boxGeometry args={[0.15, 2, 10]} />
                    <meshStandardMaterial color="#333344" transparent opacity={0.5} />
                </mesh>
            </RigidBody>
            <RigidBody type="fixed" colliders="cuboid" position={[-2, 1, 0]}>
                <mesh>
                    <boxGeometry args={[0.15, 2, 10]} />
                    <meshStandardMaterial color="#333344" transparent opacity={0.5} />
                </mesh>
            </RigidBody>
            <RigidBody type="fixed" colliders="cuboid" position={[2, 1, 0]}>
                <mesh>
                    <boxGeometry args={[0.15, 2, 10]} />
                    <meshStandardMaterial color="#333344" transparent opacity={0.5} />
                </mesh>
            </RigidBody>
        </>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [0, 8, 10], fov: 50 }} shadows>
            <ambientLight intensity={0.4} />
            <directionalLight position={[5, 10, 5]} intensity={1.0} castShadow />

            <Physics gravity={[0, -9.81, 0]}>
                <Ramp />
                <Flipper position={[-1, 0.5, 2]} side="left" />
                <Flipper position={[1, 0.5, 2]} side="right" />
                <Marble onLaunch={() => {}} />
                <Walls />

                {/* 地面 */}
                <RigidBody type="fixed" colliders="cuboid">
                    <mesh receiveShadow rotation={[-Math.PI / 2, 0, 0]}>
                        <planeGeometry args={[10, 10]} />
                        <meshStandardMaterial color="#222233" />
                    </mesh>
                </RigidBody>
            </Physics>

            <OrbitControls />
        </Canvas>
    );
}
```

**要点**：
- `type="kinematic"` 的刚体不受物理力影响，但可以碰撞其他物体，适合做挡板、平台等可控物体
- `applyImpulse` 施加瞬时冲量，适合弹射器效果；`applyForce` 施加持续力，适合推力
- `setNextKinematicRotation` 在 `useFrame` 中每帧更新运动学物体的旋转
- `restitution` 让弹珠碰到墙壁和挡板时弹跳

### 练习三

**思路**：给物体添加 `onCollisionEnter` 事件，检测碰撞对象是否为地面。碰撞时通过 `useState` 或 `useRef` 更新颜色状态。

**答案**：

```tsx
import { useRef, useState } from "react";
import { Canvas } from "@react-three/fiber";
import { Physics, RigidBody, RapierRigidBody } from "@react-three/rapier";
import { OrbitControls } from "@react-three/drei";

function ColorChangeBall() {
    const ref = useRef<RapierRigidBody>(null!);
    const [color, setColor] = useState("#4fc3f7");
    const [hasHitGround, setHasHitGround] = useState(false);

    return (
        <RigidBody
            ref={ref}
            position={[0, 5, 0]}
            colliders="ball"
            restitution={0.6}
            onCollisionEnter={({ other }) => {
                // 检查碰撞对象是否是地面（通过 rigidBodyObject 的 name 判断）
                const otherObj = other.rigidBodyObject;
                if (otherObj?.name === "ground" && !hasHitGround) {
                    setHasHitGround(true);
                    setColor("#ff4444");
                    console.log("球碰到了地面！颜色变为红色");
                }
            }}
        >
            <mesh castShadow>
                <sphereGeometry args={[0.5, 32, 32]} />
                <meshStandardMaterial color={color} />
            </mesh>
        </RigidBody>
    );
}

function Ground() {
    return (
        <RigidBody type="fixed" colliders="cuboid" name="ground">
            <mesh receiveShadow rotation={[-Math.PI / 2, 0, 0]}>
                <planeGeometry args={[20, 20]} />
                <meshStandardMaterial color="#444455" />
            </mesh>
        </RigidBody>
    );
}

function MultiBallScene() {
    const balls = [
        { id: 1, pos: [-2, 6, 0] as [number, number, number], color: "#4fc3f7" },
        { id: 2, pos: [0, 8, 0.5] as [number, number, number], color: "#66bb6a" },
        { id: 3, pos: [2, 4, -0.5] as [number, number, number], color: "#ff7043" },
    ];

    return (
        <>
            {balls.map((ball) => (
                <BallWithColorChange key={ball.id} position={ball.pos} initialColor={ball.color} />
            ))}
        </>
    );
}

function BallWithColorChange({ position, initialColor }: { position: [number, number, number]; initialColor: string }) {
    const [color, setColor] = useState(initialColor);
    const hitRef = useRef(false);

    return (
        <RigidBody
            position={position}
            colliders="ball"
            restitution={0.6}
            onCollisionEnter={({ other }) => {
                if (other.rigidBodyObject?.name === "ground" && !hitRef.current) {
                    hitRef.current = true;
                    setColor("#ff4444");
                }
            }}
        >
            <mesh castShadow>
                <sphereGeometry args={[0.4, 32, 32]} />
                <meshStandardMaterial color={color} />
            </mesh>
        </RigidBody>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [5, 5, 10], fov: 50 }} shadows>
            <ambientLight intensity={0.4} />
            <directionalLight position={[5, 10, 5]} intensity={1.0} castShadow />

            <Physics gravity={[0, -9.81, 0]}>
                <MultiBallScene />
                <Ground />
            </Physics>

            <OrbitControls />
        </Canvas>
    );
}
```

**要点**：
- `onCollisionEnter` 的 `other` 参数包含碰撞对方的信息，`other.rigidBodyObject` 是对应的 DOM 对象
- 用 `name` 属性标识刚体，比通过位置判断更可靠
- `hitRef` 防止碰撞事件重复触发（物理引擎每帧都可能检测到接触）
- 碰撞事件适合做视觉反馈（变色、粒子效果）和游戏逻辑（计分、触发）
