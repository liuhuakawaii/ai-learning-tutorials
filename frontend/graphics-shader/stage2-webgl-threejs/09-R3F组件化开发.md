# 第九课：R3F 组件化开发

## 场景引入

上一课你学会了 R3F 的基本用法，但一个真实项目不可能把所有代码都写在一个文件里。想象你要做一个 3D 电商展示页面：有产品模型、灯光系统、交互控件、信息标注……每个模块都需要独立开发和测试。R3F 的组件化模式，配合 Drei 辅助库和状态管理方案，能让你像搭乐高一样构建复杂的 3D 应用。

## 学习目标

1. 掌握自定义 3D 组件的封装模式
2. 学会使用 Drei 库中的常用辅助组件
3. 理解 R3F 中的状态管理方案（Zustand）
4. 实现 3D 物体的事件交互
5. 掌握 Suspense 异步加载模式

## 一、自定义 3D 组件封装

好的 3D 组件应该像 React UI 组件一样：有清晰的 props 接口，内部逻辑自包含。

```tsx
import { useRef } from 'react'
import { useFrame } from '@react-three/fiber'
import type { Mesh } from 'three'

interface RotatingCubeProps {
  position?: [number, number, number]
  color?: string
  speed?: number
  size?: number
}

export function RotatingCube({
  position = [0, 0, 0],
  color = 'hotpink',
  speed = 1,
  size = 1,
}: RotatingCubeProps) {
  const meshRef = useRef<Mesh>(null!)

  useFrame((_, delta) => {
    meshRef.current.rotation.x += delta * speed
    meshRef.current.rotation.y += delta * speed * 0.7
  })

  return (
    <mesh ref={meshRef} position={position} castShadow>
      <boxGeometry args={[size, size, size]} />
      <meshStandardMaterial color={color} />
    </mesh>
  )
}
```

使用时就像普通 React 组件：

```tsx
<RotatingCube position={[-2, 1, 0]} color="orange" speed={0.5} />
<RotatingCube position={[2, 1, 0]} color="cyan" speed={1.2} size={0.8} />
```

## 二、Drei 辅助库

`@react-three/drei` 是 R3F 的官方辅助库，提供了大量高频使用的组件。

### OrbitControls 轨道控制器

```tsx
import { OrbitControls } from '@react-three/drei'

<Canvas>
  <OrbitControls
    makeDefault              // 成为默认控制器
    enableDamping            // 启用阻尼（惯性）
    dampingFactor={0.05}
    minDistance={2}           // 最近距离
    maxDistance={20}          // 最远距离
    maxPolarAngle={Math.PI / 2}  // 限制垂直旋转（不翻转到地面以下）
  />
</Canvas>
```

### Environment 环境光照

```tsx
import { Environment } from '@react-three/drei'

// 可选预设：sunset, dawn, night, warehouse, forest, apartment, studio, city
```

Environment 提供基于图像的光照（IBL），一个组件就能让场景的反射和光照效果提升数个档次。

## 三、useFrame 动画进阶

### 跟随鼠标移动

```tsx
import { useRef } from 'react'
import { useFrame, useThree } from '@react-three/fiber'
import * as THREE from 'three'

function FollowMouse() {
  const meshRef = useRef<THREE.Mesh>(null!)
  const { pointer } = useThree()

  useFrame(() => {
    // lerp 平滑插值，让运动更自然
    meshRef.current.position.x = THREE.MathUtils.lerp(
      meshRef.current.position.x, pointer.x * 3, 0.05
    )
    meshRef.current.position.z = THREE.MathUtils.lerp(
      meshRef.current.position.z, pointer.y * 3, 0.05
    )
  })

  return (
    <mesh ref={meshRef}>
      <sphereGeometry args={[0.5, 32, 32]} />
      <meshStandardMaterial color="coral" />
    </mesh>
  )
}
```

## 四、状态管理：Zustand + R3F

Zustand 是 R3F 生态中最流行的状态管理库，轻量且原生支持 React。

```tsx
import { create } from 'zustand'

interface SceneStore {
  selectedObject: string | null
  isAnimating: boolean
  colorScheme: 'light' | 'dark'
  selectObject: (id: string | null) => void
  toggleAnimation: () => void
  setColorScheme: (scheme: 'light' | 'dark') => void
}

const useSceneStore = create<SceneStore>((set) => ({
  selectedObject: null,
  isAnimating: true,
  colorScheme: 'light',
  selectObject: (id) => set({ selectedObject: id }),
  toggleAnimation: () => set((state) => ({ isAnimating: !state.isAnimating })),
  setColorScheme: (scheme) => set({ colorScheme: scheme }),
}))
```

### 在 3D 组件中使用状态

```tsx
import { useSceneStore } from './store'

function InteractiveBox({ id }: { id: string }) {
  const selected = useSceneStore((s) => s.selectedObject === id)
  const selectObject = useSceneStore((s) => s.selectObject)

  return (
    <mesh onClick={() => selectObject(id)}>
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial
        color={selected ? 'gold' : 'gray'}
        emissive={selected ? 'gold' : 'black'}
        emissiveIntensity={selected ? 0.3 : 0}
      />
    </mesh>
  )
}
```

### UI 控制面板联动

```tsx
function ControlPanel() {
  const isAnimating = useSceneStore((s) => s.isAnimating)
  const toggleAnimation = useSceneStore((s) => s.toggleAnimation)
  const selected = useSceneStore((s) => s.selectedObject)

  return (
    <div className="control-panel">
      <button onClick={toggleAnimation}>
        {isAnimating ? '暂停动画' : '恢复动画'}
      </button>
      {selected && <p>选中对象：{selected}</p>}
    </div>
  )
}
```

Zustand 的优势在于：3D 组件和 HTML 组件共享同一个 store，状态双向同步。

## 五、事件处理

R3F 的事件系统基于 raycaster，支持大部分 DOM 事件。

```tsx
function EventDemo() {
  const [hovered, setHovered] = useState(false)

  return (
    <mesh
      // 鼠标事件
      onClick={(e) => {
        e.stopPropagation()  // 阻止事件冒泡
        console.log('点击坐标:', e.point)
      }}
      onPointerOver={(e) => {
        e.stopPropagation()
        setHovered(true)
        document.body.style.cursor = 'pointer'
      }}
      onPointerOut={() => {
        setHovered(false)
        document.body.style.cursor = 'default'
      }}
      // 拖拽事件
      onPointerDown={(e) => e.stopPropagation()}
      onPointerUp={(e) => e.stopPropagation()}
    >
      <boxGeometry />
      <meshStandardMaterial color={hovered ? 'hotpink' : 'orange'} />
    </mesh>
  )
}
```

事件对象包含 `point`（世界坐标交点）、`object`（被点击的 Three.js 对象）、`uv`（纹理坐标）等信息。

## 六、Suspense 异步加载

R3F 原生支持 React Suspense，用于处理模型加载、纹理加载等异步操作。

```tsx
import { Suspense } from 'react'
import { useGLTF, useTexture, Html } from '@react-three/drei'

function Model({ url }: { url: string }) {
  const { scene } = useGLTF(url)
  return <primitive object={scene.clone()} />
}

function LoadingFallback() {
  return (
    <Html center>
      <div style={{ color: 'white', fontSize: '16px' }}>加载中...</div>
    </Html>
  )
}

export default function App() {
  return (
    <Canvas>
      <Suspense fallback={<LoadingFallback />}>
        <Model url="/models/product.glb" />
      </Suspense>
    </Canvas>
  )
}
```

`useGLTF` 和 `useTexture` 都是基于 Suspense 的 hook，加载完成前会抛出 Promise，由最近的 Suspense boundary 捕获。

## 七、完整的组件化应用示例

```tsx
import { Canvas } from '@react-three/fiber'
import { OrbitControls, Environment, ContactShadows } from '@react-three/drei'
import { Suspense } from 'react'

// 灯光组件
function Lighting() {
  return (
    <>
      <ambientLight intensity={0.3} />
      <directionalLight
        position={[5, 8, 5]}
        castShadow
        shadow-mapSize={[1024, 1024]}
      />
      <pointLight position={[-3, 3, -3]} color="blue" intensity={0.5} />
    </>
  )
}

// 地面组件
function Ground() {
  return (
    <ContactShadows
      position={[0, -0.01, 0]}
      opacity={0.4}
      scale={20}
      blur={2}
      far={10}
    />
  )
}

// 产品展示组件
function ProductShowcase() {
  return (
    <group position={[0, 0.5, 0]}>
      <RotatingCube color="#4488ff" speed={0.3} />
    </group>
  )
}

export default function App() {
  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <Canvas camera={{ position: [4, 3, 5] }} shadows>
        <Suspense fallback={null}>
          <Lighting />
          <Environment preset="studio" />
          <ProductShowcase />
          <Ground />
          <OrbitControls makeDefault />
        </Suspense>
      </Canvas>
    </div>
  )
}
```

## 常见误区

### 1. 在 3D 组件中直接操作 DOM

R3F 的组件虽然用 JSX 写，但它们运行在 Three.js 渲染器中，不能直接使用 `document.querySelector`。如果需要操作 DOM，应该在 Canvas 外层的 React 组件中处理。

### 2. 把所有状态都放进 Zustand

不是所有状态都需要全局管理。物体的局部动画状态（如旋转角度）用 `useRef` 就够了，只有需要跨组件共享的状态才放 store。

### 3. 滥用 primitive 组件

`<primitive object={...}>` 是用来直接插入 Three.js 对象的逃生口。对于可以用 JSX 声明的几何体和材质，优先用 JSX 写法，性能更好且支持 React 的 diff 机制。

### 4. 忽略组件卸载时的清理

3D 组件卸载时，R3F 会自动 dispose geometry 和 material，但事件监听器、定时器、外部资源引用需要手动清理。

## 工程建议

1. **组件拆分原则：** 一个视觉上独立的 3D 对象就是一个组件，就像 UI 中一个按钮是一个组件
2. **Drei 优先：** 遇到常见的 3D 需求（控制器、文字、环境光、阴影），先查 Drei 是否已有封装
3. **用 React DevTools 调试：** R3F 的组件树可以在 React DevTools 中查看，属性变化一目了然
4. **Suspense 分层：** 将加载慢的资源（大模型）和加载快的资源（几何体）放在不同的 Suspense boundary 中

## 小结

R3F 的组件化开发模式让 3D 应用的架构和传统 React 应用趋于一致。Drei 提供了开箱即用的辅助组件，Zustand 实现了 3D 和 UI 的状态同步，Suspense 处理了异步加载。掌握这套组合，就能高效地构建复杂的交互式 3D 应用。

## 参考答案

### 练习一

**思路**：封装一个 `AnimatedSphere` 组件，接收 `radius`、`color`、`bounceHeight` 等 props。用 `useFrame` 在每帧中通过 `Math.sin` 计算 Y 轴位置，实现弹跳效果。

**答案**：

```tsx
import { useRef } from "react";
import { useFrame } from "@react-three/fiber";
import * as THREE from "three";

interface AnimatedSphereProps {
    radius?: number;
    color?: string;
    bounceHeight?: number;
    bounceSpeed?: number;
    position?: [number, number, number];
}

function AnimatedSphere({
    radius = 0.5,
    color = "#4fc3f7",
    bounceHeight = 1.5,
    bounceSpeed = 2,
    position = [0, 0, 0],
}: AnimatedSphereProps) {
    const meshRef = useRef<THREE.Mesh>(null!);
    const baseY = position[1] + radius; // 地面以上的基础高度

    useFrame((state) => {
        const elapsed = state.clock.getElapsedTime();
        // sin 函数产生周期性弹跳，取绝对值确保不穿地
        const offset = Math.abs(Math.sin(elapsed * bounceSpeed)) * bounceHeight;
        meshRef.current.position.y = baseY + offset;

        // 落地时轻微压扁，弹起时拉伸
        const squash = 1 - Math.abs(Math.sin(elapsed * bounceSpeed)) * 0.15;
        const stretch = 1 + Math.abs(Math.sin(elapsed * bounceSpeed)) * 0.1;
        meshRef.current.scale.set(stretch, squash, stretch);
    });

    return (
        <mesh ref={meshRef} position={position}>
            <sphereGeometry args={[radius, 32, 32]} />
            <meshStandardMaterial color={color} />
        </mesh>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [0, 3, 8], fov: 60 }}>
            <ambientLight intensity={0.4} />
            <directionalLight position={[5, 5, 5]} intensity={1.0} />

            {/* 地面 */}
            <mesh rotation={[-Math.PI / 2, 0, 0]} position={[0, 0, 0]}>
                <planeGeometry args={[10, 10]} />
                <meshStandardMaterial color="#333344" />
            </mesh>

            {/* 不同参数的弹跳球 */}
            <AnimatedSphere position={[-3, 0, 0]} color="#ff7043" bounceHeight={2} bounceSpeed={1.5} />
            <AnimatedSphere position={[0, 0, 0]} color="#4fc3f7" bounceHeight={1.5} bounceSpeed={2} />
            <AnimatedSphere position={[3, 0, 0]} color="#66bb6a" bounceHeight={1} bounceSpeed={3} radius={0.7} />
        </Canvas>
    );
}
```

**要点**：
- `Math.abs(Math.sin(...))` 确保弹跳值始终非负，球不会穿入地面
- 缩放变形（squash/stretch）让弹跳更有物理感：落地压扁，弹起拉伸
- Props 提供默认值，使用时可以只传需要覆盖的参数
- `baseY = position[1] + radius` 确保球的底部在地面上，而非球心在地面上

### 练习二

**思路**：用 Zustand 创建 store 管理选中状态，3D 物体组件的 `onClick` 事件更新选中对象，HTML 面板组件订阅 store 显示选中物体的信息。

**答案**：

```tsx
import { create } from "zustand";
import { Canvas } from "@react-three/fiber";

// 类型定义
interface SceneObject {
    id: string;
    name: string;
    color: string;
    position: [number, number, number];
}

interface SceneStore {
    selectedId: string | null;
    selectObject: (id: string | null) => void;
}

const useSceneStore = create<SceneStore>((set) => ({
    selectedId: null,
    selectObject: (id) => set({ selectedId: id }),
}));

// 场景物体数据
const objects: SceneObject[] = [
    { id: "sphere-1", name: "蓝色球体", color: "#4fc3f7", position: [-3, 0, 0] },
    { id: "box-1", name: "橙色立方体", color: "#ff7043", position: [0, 0, 0] },
    { id: "torus-1", name: "绿色圆环", color: "#66bb6a", position: [3, 0, 0] },
];

function SelectableObject({ id, name, color, position }: SceneObject) {
    const selectedId = useSceneStore((s) => s.selectedId);
    const selectObject = useSceneStore((s) => s.selectObject);
    const isSelected = selectedId === id;

    return (
        <mesh
            position={position}
            onClick={(e) => {
                e.stopPropagation();
                selectObject(isSelected ? null : id); // 再次点击取消选中
            }}
        >
            <sphereGeometry args={[0.8, 32, 32]} />
            <meshStandardMaterial
                color={isSelected ? "#ffffff" : color}
                emissive={isSelected ? color : "#000000"}
                emissiveIntensity={isSelected ? 0.5 : 0}
            />
        </mesh>
    );
}

function InfoPanel() {
    const selectedId = useSceneStore((s) => s.selectedId);
    const selectedObj = objects.find((o) => o.id === selectedId);

    return (
        <div style={{
            position: "fixed",
            top: 20,
            right: 20,
            width: 220,
            padding: 16,
            background: "rgba(0,0,0,0.85)",
            color: "#fff",
            borderRadius: 8,
            fontFamily: "monospace",
            fontSize: 14,
        }}>
            {selectedObj ? (
                <>
                    <h3 style={{ margin: "0 0 12px" }}>{selectedObj.name}</h3>
                    <p>ID: {selectedObj.id}</p>
                    <p>
                        颜色:{" "}
                        <span style={{ color: selectedObj.color }}>{selectedObj.color}</span>
                    </p>
                    <p>位置: ({selectedObj.position.join(", ")})</p>
                    <button
                        onClick={() => useSceneStore.getState().selectObject(null)}
                        style={{ marginTop: 8, padding: "4px 12px", cursor: "pointer" }}
                    >
                        取消选中
                    </button>
                </>
            ) : (
                <p style={{ color: "#888" }}>点击物体查看详情</p>
            )}
        </div>
    );
}

export default function App() {
    return (
        <>
            <Canvas camera={{ position: [0, 2, 8], fov: 60 }}>
                <ambientLight intensity={0.4} />
                <directionalLight position={[5, 5, 5]} intensity={1.0} />

                {objects.map((obj) => (
                    <SelectableObject key={obj.id} {...obj} />
                ))}
            </Canvas>
            <InfoPanel />
        </>
    );
}
```

**要点**：
- Zustand 的 selector 模式（`useSceneStore((s) => s.selectedId)`）确保只有相关状态变化时组件才重渲染
- `e.stopPropagation()` 防止点击事件冒泡到 Canvas 的空白区域
- `InfoPanel` 是普通 React 组件，放在 `Canvas` 外部，不需要 R3F 上下文
- 再次点击同一物体取消选中，提供更自然的交互体验

### 练习三

**思路**：用 Drei 的 `Text` 组件在 3D 场景中显示文字，将 `billboard` 属性设为 `true`（或包裹在 `<Billboard>` 组件中），让文字始终面向相机。

**答案**：

```tsx
import { Canvas } from "@react-three/fiber";
import { Text, Billboard, OrbitControls } from "@react-three/drei";

function FloatingLabel({ text, position }: { text: string; position: [number, number, number] }) {
    return (
        <Billboard position={position} follow={true} lockX={false} lockY={false} lockZ={false}>
            <Text
                fontSize={0.4}
                color="white"
                anchorX="center"
                anchorY="middle"
                outlineWidth={0.02}
                outlineColor="#000000"
            >
                {text}
            </Text>
        </Billboard>
    );
}

function LabeledObject({
    position,
    label,
    color,
}: {
    position: [number, number, number];
    label: string;
    color: string;
}) {
    return (
        <group position={position}>
            <mesh>
                <sphereGeometry args={[0.5, 32, 32]} />
                <meshStandardMaterial color={color} />
            </mesh>
            {/* 标签悬浮在物体上方 */}
            <FloatingLabel text={label} position={[0, 1, 0]} />
        </group>
    );
}

export default function App() {
    return (
        <Canvas camera={{ position: [0, 2, 8], fov: 60 }}>
            <ambientLight intensity={0.4} />
            <directionalLight position={[5, 5, 5]} intensity={1.0} />

            <LabeledObject position={[-3, 0, 0]} label="球体 A" color="#4fc3f7" />
            <LabeledObject position={[0, 0, 0]} label="球体 B" color="#ff7043" />
            <LabeledObject position={[3, 0, 0]} label="球体 C" color="#66bb6a" />

            {/* 浮动标题 */}
            <Billboard position={[0, 3.5, 0]}>
                <Text
                    fontSize={0.6}
                    color="#ffea00"
                    anchorX="center"
                    anchorY="middle"
                    font="/fonts/Inter-Bold.woff"
                >
                    Drei Billboard Demo
                </Text>
            </Billboard>

            <OrbitControls />
        </Canvas>
    );
}
```

**要点**：
- `<Billboard>` 组件让子物体始终面向相机，`follow={true}` 跟随相机旋转
- `<Text>` 是 Drei 对 Three.js `TextGeometry` 的封装，支持自动换行和 SDF 渲染
- `outlineWidth` 和 `outlineColor` 给文字添加描边，确保在各种背景下都可读
- 将标签放在 `group` 内并设置相对偏移，让标签跟随物体移动但保持固定间距
