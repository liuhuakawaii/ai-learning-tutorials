# 第5课：模型加载与动画

## 场景引入

前面几课我们用代码创建几何体——立方体、球体、平面。但真实项目的 3D 模型通常由美术人员在 Blender、Maya 或 3ds Max 中制作，导出为标准格式后由程序员加载到网页中。一辆汽车、一个角色、一栋建筑，不可能用 `BoxGeometry` 拼出来。本课学习如何加载 glTF 模型并播放其中的动画，这是 3D Web 应用最核心的能力之一。

## 学习目标

1. 了解 glTF/GLB 格式的特点和适用场景
2. 掌握 GLTFLoader 加载模型的完整流程
3. 理解骨骼动画（SkinnedMesh/Skeleton）的工作原理
4. 学会使用 AnimationMixer 控制模型动画的播放、暂停和混合
5. 能够用 KeyframeTrack 创建自定义关键帧动画

## 一、glTF 格式介绍

glTF（GL Transmission Format）是 3D 行业的"JPEG"，由 Khronos Group 制定，被所有主流引擎和工具支持：

```
  glTF 文件结构：

  .gltf（JSON）          .glb（二进制打包）
  ├── 场景描述            ├── JSON 部分
  ├── 节点层级            ├── 二进制数据（顶点、索引）
  ├── 网格数据引用         └── 纹理（可嵌入）
  ├── 材质定义
  ├── 动画数据
  └── 引用外部文件
      ├── .bin（二进制顶点/索引数据）
      └── .png/.jpg（纹理）

  推荐使用 .glb：单文件，加载简单，体积更小
```

glTF 的设计目标是"运行时直接加载"，不需要复杂的解析过程。它对 PBR 材质的支持非常好，Three.js 的 `MeshStandardMaterial` 属性几乎与 glTF 的材质模型一一对应。

## 二、GLTFLoader 加载模型

```typescript
import * as THREE from "three";
import { GLTFLoader } from "three/examples/jsm/loaders/GLTFLoader.js";
import { DRACOLoader } from "three/examples/jsm/loaders/DRACOLoader.js";

// Draco 压缩加载器（可选，模型如果用了 Draco 压缩就需要）
const dracoLoader = new DRACOLoader();
dracoLoader.setDecoderPath("/draco/"); // Draco 解码器路径

const loader = new GLTFLoader();
loader.setDRACOLoader(dracoLoader);

// 加载模型
loader.load(
    "/models/robot.glb",
    (gltf) => {
        const model = gltf.scene;

        // 遍历模型，开启阴影
        model.traverse((child) => {
            if ((child as THREE.Mesh).isMesh) {
                child.castShadow = true;
                child.receiveShadow = true;
                // 优化：如果模型很大，可以开启视锥剔除
                child.frustumCulled = true;
            }
        });

        // 调整模型大小和位置
        const box = new THREE.Box3().setFromObject(model);
        const size = box.getSize(new THREE.Vector3());
        const center = box.getCenter(new THREE.Vector3());

        // 归一化到合适大小
        const maxDim = Math.max(size.x, size.y, size.z);
        const scale = 2 / maxDim;
        model.scale.setScalar(scale);

        // 居中
        model.position.sub(center.multiplyScalar(scale));

        scene.add(model);
    },
    (progress) => {
        // 加载进度
        const percent = (progress.loaded / progress.total) * 100;
        console.log(`加载进度: ${percent.toFixed(1)}%`);
    },
    (error) => {
        console.error("模型加载失败:", error);
    }
);
```

## 三、骨骼动画

角色动画使用骨骼系统：一组层级化的骨头（Bones）驱动网格顶点变形。

```
  骨骼层级结构：

  根骨骼 (Hips)
       │
   ┌───┼───────┐
   │   │       │
 Spine  L.Leg  R.Leg
   │   │       │
 Chest L.Foot  R.Foot
   │
 ┌─┼──┐
 │ │  │
L.Arm Neck R.Arm
 │     │     │
L.Hand Head R.Hand

每个骨骼是一个 Transform（位置/旋转/缩放）
顶点通过 "蒙皮权重" 绑定到多个骨骼
动画改变骨骼的旋转 → 顶点跟着变形 → 角色动起来
```

```typescript
// glTF 加载后的动画数据
loader.load("/models/character.glb", (gltf) => {
    const model = gltf.scene;
    scene.add(model);

    // gltf.animations 是 AnimationClip 数组
    console.log("可用动画:", gltf.animations.map(c => c.name));
    // 例如: ["idle", "walk", "run", "jump"]

    // 检查是否有骨骼网格
    model.traverse((child) => {
        if ((child as THREE.SkinnedMesh).isSkinnedMesh) {
            const skinnedMesh = child as THREE.SkinnedMesh;
            console.log("骨骼数量:", skinnedMesh.skeleton.bones.length);
            console.log("蒙皮权重:", skinnedMesh.geometry.attributes.skinWeight);
        }
    });
});
```

## 四、AnimationMixer 动画控制

`AnimationMixer` 是 Three.js 的动画播放引擎：

```typescript
let mixer: THREE.AnimationMixer;
const actions: Record<string, THREE.AnimationAction> = {};
let currentAction: THREE.AnimationAction;

loader.load("/models/character.glb", (gltf) => {
    const model = gltf.scene;
    scene.add(model);

    // 创建动画混合器
    mixer = new THREE.AnimationMixer(model);

    // 把所有 AnimationClip 转为 AnimationAction
    gltf.animations.forEach((clip) => {
        const action = mixer.clipAction(clip);
        actions[clip.name] = action;
    });

    // 播放第一个动画
    currentAction = actions["idle"];
    currentAction.play();
});

// 切换动画（带交叉淡入淡出）
function switchAnimation(name: string, duration = 0.3): void {
    const nextAction = actions[name];
    if (!nextAction || currentAction === nextAction) return;

    nextAction.reset();
    nextAction.play();
    currentAction.crossFadeTo(nextAction, duration, true);
    currentAction = nextAction;
}

// 渲染循环中更新动画
const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();

    // 必须每帧更新混合器
    if (mixer) mixer.update(delta);

    renderer.render(scene, camera);
}

animate();
```

## 五、AnimationAction 详解

`AnimationAction` 控制单个动画的行为：

```typescript
const walkAction = actions["walk"];

// 播放控制
walkAction.play();      // 开始播放
walkAction.stop();      // 停止
walkAction.paused = true; // 暂停

// 时间控制
walkAction.time = 0;           // 跳到指定时间
walkAction.timeScale = 1.5;    // 播放速度（1=正常，2=两倍速）
walkAction.timeScale = -1;     // 倒放

// 循环模式
walkAction.setLoop(THREE.LoopRepeat, Infinity); // 无限循环
walkAction.setLoop(THREE.LoopOnce, 1);          // 播放一次后停在最后一帧
walkAction.clampWhenFinished = true;             // LoopOnce 时生效

// 权重（用于动画混合）
walkAction.weight = 0.5; // 0=无影响，1=完全生效
```

```
  动画交叉淡入淡出 (crossFade)：

  idle 权重:   1 ─────╲
                        ╲
                         ╲
                          ╲───── 0
  walk 权重:   0 ─────────╱
                        ╱
                       ╱
                      ╱─────── 1

              ├── duration ──┤
              旧动画淡出       新动画淡入
```

## 六、关键帧动画

如果没有外部模型的动画数据，可以用 `KeyframeTrack` 代码创建动画：

```typescript
// 创建一个位移动画
const times = [0, 1, 2, 3]; // 关键帧时间点（秒）
const values = [
    0, 0, 0,   // t=0: 原点
    2, 0, 0,   // t=1: 向右移动
    2, 2, 0,   // t=2: 向上移动
    0, 0, 0,   // t=3: 回到原点
];

const positionTrack = new THREE.VectorKeyframeTrack(
    ".position",  // 属性路径
    times,
    values,
    THREE.InterpolateSmooth // 平滑插值
);

// 创建旋转动画
const rotTimes = [0, 2, 4];
const rotValues = [
    0, 0, 0, 1,         // t=0: 无旋转（四元数）
    0, Math.sin(Math.PI / 4), 0, Math.cos(Math.PI / 4), // t=2: 旋转 90°
    0, 0, 0, 1,         // t=4: 转回来
];

const rotationTrack = new THREE.QuaternionKeyframeTrack(
    ".quaternion",
    rotTimes,
    rotValues
);

// 把多个 Track 组合成一个 Clip
const clip = new THREE.AnimationClip("orbit", 4, [positionTrack, rotationTrack]);

// 使用
const mixer = new THREE.AnimationMixer(mesh);
const action = mixer.clipAction(clip);
action.setLoop(THREE.LoopRepeat, Infinity);
action.play();
```

## 七、模型优化建议

加载到网页的模型需要优化，否则加载慢、渲染卡。三个核心方向：

- **几何体压缩**：使用 Draco 压缩（通常减少 80%+ 体积），建模工具导出时勾选或用 `gltf-pipeline` 处理
- **纹理压缩**：使用 KTX2Loader 加载 Basis Universal 压缩纹理，GPU 可直接解压，大幅减少显存和带宽
- **实例化渲染**：大量相同模型使用 `THREE.InstancedMesh`，一次 draw call 绘制所有实例

## 常见误区

**1. 加载模型后不调整大小和位置**
glTF 模型的尺寸由建模软件决定，可能极大或极小。加载后应该用 `Box3.setFromObject()` 计算包围盒，归一化到场景合适的大小。

**2. 忘记在渲染循环中调用 `mixer.update(delta)`**
动画混合器需要每帧更新。如果不调用 `update`，动画不会动。如果传入的 `delta` 不是基于真实时间差，动画速度会不正常。

**3. 加载大模型不显示进度**
`GLTFLoader.load` 的第二个参数是进度回调。对于大模型（>5MB），应该显示加载进度条，否则用户会以为页面卡死了。

**4. 遍历模型时没有检查类型**
`model.traverse` 回调中的 child 可能是 Group、Bone、Mesh 等多种类型。用 `(child as THREE.Mesh).isMesh` 检查后再操作，避免对非 Mesh 对象调用 `castShadow` 等属性。

## 工程建议

**1. 优先使用 glb 格式**
glb 是 glTF 的二进制打包版本，单文件，体积更小，加载更简单。除非需要编辑 JSON 结构，否则始终用 glb。

**2. 对静态模型预烘焙动画到顶点**
如果模型的动画不需要运行时控制（如风吹树叶），可以在建模工具中烘焙为顶点动画纹理（MAT），比骨骼动画更高效。

**3. 用 `dispose()` 释放不再使用的模型资源**
切换场景时，旧模型的几何体、材质、纹理都需要释放：
```typescript
model.traverse((child) => {
    if ((child as THREE.Mesh).isMesh) {
        child.geometry.dispose();
        (child.material as THREE.Material).dispose();
    }
});
```

**4. 使用 LoadingManager 统一管理多个资源加载**
当场景需要加载模型、纹理、环境贴图等多种资源时，用 `THREE.LoadingManager` 统一管理进度和完成事件。

## 小结

本课学习了 3D Web 应用的核心流程：加载外部模型并播放动画。glTF/GLB 是当前最通用的 3D 交换格式，Three.js 的 GLTFLoader 能直接加载它。骨骼动画通过 AnimationMixer 控制，支持播放、暂停、速度调节和交叉淡入淡出。KeyframeTrack 则让你用代码创建自定义动画。掌握这些能力后，你就能把美术制作的资产变成网页上的交互式 3D 体验。

### 练习一

**思路**：用 GLTFLoader 加载模型后，遍历 `gltf.animations` 获取所有动画名称，为每个动画创建按钮。点击按钮时用 `crossFadeTo` 平滑切换动画。

**答案**：

```typescript
import * as THREE from "three";
import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x222233);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 2, 5);
camera.lookAt(0, 1, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 5, 5);
scene.add(dirLight);

let mixer: THREE.AnimationMixer;
const actions: Record<string, THREE.AnimationAction> = {};
let currentAction: THREE.AnimationAction;

const loader = new GLTFLoader();
loader.load("/models/character.glb", (gltf) => {
    const model = gltf.scene;
    scene.add(model);

    mixer = new THREE.AnimationMixer(model);

    // 列出所有可用动画
    const animNames = gltf.animations.map((clip) => clip.name);
    console.log("可用动画:", animNames);

    // 为每个动画创建 Action
    gltf.animations.forEach((clip) => {
        actions[clip.name] = mixer.clipAction(clip);
    });

    // 播放第一个动画
    if (animNames.length > 0) {
        currentAction = actions[animNames[0]];
        currentAction.play();
    }

    // 创建 UI 按钮
    const panel = document.createElement("div");
    panel.style.position = "fixed";
    panel.style.bottom = "20px";
    panel.style.left = "50%";
    panel.style.transform = "translateX(-50%)";
    panel.style.display = "flex";
    panel.style.gap = "8px";
    document.body.appendChild(panel);

    animNames.forEach((name) => {
        const btn = document.createElement("button");
        btn.textContent = name;
        btn.style.padding = "6px 14px";
        btn.style.cursor = "pointer";
        btn.addEventListener("click", () => {
            const next = actions[name];
            if (!next || currentAction === next) return;
            next.reset();
            next.play();
            currentAction.crossFadeTo(next, 0.3, true);
            currentAction = next;
        });
        panel.appendChild(btn);
    });
});

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    const delta = clock.getDelta();
    if (mixer) mixer.update(delta);
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `gltf.animations` 是 `AnimationClip[]`，每个 clip 的 `.name` 就是动画名称
- `crossFadeTo` 的第三个参数 `true` 表示在切换时保持权重过渡（warp），实现平滑混合
- `next.reset()` 重置动画到起始状态，避免从上次停止的位置继续
- 每帧必须调用 `mixer.update(delta)`，否则动画不会播放

### 练习二

**思路**：用 `KeyframeTrack` 创建位置和缩放的关键帧动画。位置轨迹模拟下落和弹起（Y 轴在高处→地面→高处循环），缩放轨迹在触地瞬间压缩（Y 轴变扁），再恢复。

**答案**：

```typescript
import * as THREE from "three";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x222233);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 2, 5);
camera.lookAt(0, 1, 0);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

scene.add(new THREE.AmbientLight(0xffffff, 0.4));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(3, 5, 3);
scene.add(dirLight);

// 地面参考
const groundGeo = new THREE.PlaneGeometry(10, 10);
const groundMat = new THREE.MeshStandardMaterial({ color: 0x444455 });
const ground = new THREE.Mesh(groundGeo, groundMat);
ground.rotation.x = -Math.PI / 2;
scene.add(ground);

// 弹跳立方体
const boxGeo = new THREE.BoxGeometry(1, 1, 1);
const boxMat = new THREE.MeshStandardMaterial({ color: 0xff7043 });
const box = new THREE.Mesh(boxGeo, boxMat);
scene.add(box);

// 位置关键帧：高处→地面→高处（模拟弹跳）
const positionTrack = new THREE.VectorKeyframeTrack(
    ".position",
    [0, 0.4, 0.5, 0.9, 1.0],   // 时间点
    [
        0, 4, 0,    // t=0: 高处
        0, 0.5, 0,  // t=0.4: 即将触地
        0, 0.5, 0,  // t=0.5: 触地瞬间（压缩时位置不变）
        0, 3, 0,    // t=0.9: 弹起
        0, 4, 0,    // t=1.0: 回到高处
    ]
);

// 缩放关键帧：触地时压缩，弹起时恢复
const scaleTrack = new THREE.VectorKeyframeTrack(
    ".scale",
    [0, 0.38, 0.5, 0.62, 1.0],
    [
        1, 1, 1,      // t=0: 正常
        1, 1, 1,      // t=0.38: 即将触地，正常
        1.3, 0.5, 1.3, // t=0.5: 触地压缩（X/Z 撑开，Y 压扁）
        0.9, 1.1, 0.9, // t=0.62: 弹起回弹
        1, 1, 1,       // t=1.0: 恢复正常
    ]
);

// 创建动画片段
const clip = new THREE.AnimationClip("Bounce", 1.0, [positionTrack, scaleTrack]);

const mixer = new THREE.AnimationMixer(box);
const action = mixer.clipAction(clip);
action.setLoop(THREE.LoopRepeat); // 循环播放
action.play();

const clock = new THREE.Clock();

function animate(): void {
    requestAnimationFrame(animate);
    mixer.update(clock.getDelta());
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `VectorKeyframeTrack` 的时间数组必须单调递增，值数组每 3 个为一组（x, y, z）
- 触地时的压缩用缩放实现：Y 轴压扁（0.5），X/Z 撑开（1.3），保持体积大致不变
- `THREE.LoopRepeat` 让动画循环播放，`THREE.LoopOnce` 则只播放一次
- 关键帧之间 Three.js 自动插值（默认线性），可以用 `InterpolateSmooth` 实现缓动效果

### 练习三

**思路**：加载模型后用 `Box3.setFromObject()` 计算包围盒，根据包围盒的对角线长度和相机 FOV 计算合适的相机距离，让模型完整显示在画面中央。

**答案**：

```typescript
import * as THREE from "three";
import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x222233);

const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);

const canvas = document.getElementById("canvas") as HTMLCanvasElement;
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.0);
dirLight.position.set(5, 5, 5);
scene.add(dirLight);

// 地面网格
const gridHelper = new THREE.GridHelper(10, 10, 0x444466, 0x333355);
scene.add(gridHelper);

const controls = new OrbitControls(camera, canvas);
controls.enableDamping = true;

const loader = new GLTFLoader();

function fitCameraToModel(model: THREE.Object3D): void {
    const box = new THREE.Box3().setFromObject(model);
    const center = box.getCenter(new THREE.Vector3());
    const size = box.getSize(new THREE.Vector3());

    // 计算包围球半径
    const maxDim = Math.max(size.x, size.y, size.z);
    const fov = camera.fov * (Math.PI / 180);
    let cameraZ = maxDim / (2 * Math.tan(fov / 2));

    // 留一些余量
    cameraZ *= 1.5;

    // 相机定位到包围盒中心正前方
    camera.position.set(center.x, center.y, center.z + cameraZ);
    camera.near = cameraZ / 100;
    camera.far = cameraZ * 100;
    camera.updateProjectionMatrix();

    // OrbitControls 的目标设为包围盒中心
    controls.target.copy(center);
    controls.update();

    console.log("模型尺寸:", size);
    console.log("包围盒中心:", center);
    console.log("相机距离:", cameraZ);
}

loader.load(
    "/models/character.glb",
    (gltf) => {
        const model = gltf.scene;
        scene.add(model);
        fitCameraToModel(model);
    },
    (progress) => {
        const percent = (progress.loaded / progress.total) * 100;
        console.log(`加载进度: ${percent.toFixed(1)}%`);
    },
    (error) => {
        console.error("模型加载失败:", error);
    }
);

function animate(): void {
    requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);
}

animate();
```

**要点**：
- `Box3.setFromObject()` 递归计算所有子物体的包围盒，返回模型的整体 AABB
- 相机距离公式：`maxDim / (2 * tan(fov/2))`，确保模型完全在视锥体内
- `near/far` 要根据相机距离调整，太大会导致 Z-fighting，太小会裁切模型
- `controls.target` 设为包围盒中心，这样 OrbitControls 的旋转围绕模型中心而非原点
