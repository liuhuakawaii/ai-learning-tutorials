# 粒子系统：用 GPU 渲染十万个粒子

## 现象

你要做一个火焰效果。用 Mesh 逐个创建粒子，1000 个就卡了。但 Shadertoy 上有人渲染十万个粒子还很流畅——因为他们用了 GPU 粒子。

## CPU 粒子 vs GPU 粒子

```
CPU 粒子：
  每帧更新每个粒子的位置（JS 循环）
  每个粒子一个 Mesh（draw call 爆炸）
  上限：几千个

GPU 粒子：
  粒子状态存在 GPU 缓冲区中
  用 Vertex Shader 更新位置
  用 Instanced Rendering 批量绘制
  上限：几十万个
```

## Three.js GPU 粒子

```typescript
import * as THREE from 'three'

class GPUParticleSystem {
  private geometry: THREE.BufferGeometry
  private material: THREE.ShaderMaterial
  private mesh: THREE.Points
  private count: number

  constructor(count: number) {
    this.count = count

    // 粒子属性
    const positions = new Float32Array(count * 3)
    const velocities = new Float32Array(count * 3)
    const lifetimes = new Float32Array(count)
    const sizes = new Float32Array(count)

    for (let i = 0; i < count; i++) {
      this.resetParticle(i, positions, velocities, lifetimes, sizes)
    }

    this.geometry = new THREE.BufferGeometry()
    this.geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
    this.geometry.setAttribute('a_velocity', new THREE.BufferAttribute(velocities, 3))
    this.geometry.setAttribute('a_lifetime', new THREE.BufferAttribute(lifetimes, 1))
    this.geometry.setAttribute('a_size', new THREE.BufferAttribute(sizes, 1))

    this.material = new THREE.ShaderMaterial({
      uniforms: {
        u_time: { value: 0 },
        u_delta: { value: 0 },
        u_gravity: { value: new THREE.Vector3(0, -9.8, 0) }
      },
      vertexShader: `
        attribute vec3 a_velocity;
        attribute float a_lifetime;
        attribute float a_size;
        uniform float u_time;
        uniform float u_delta;
        uniform vec3 u_gravity;
        varying float v_alpha;

        void main() {
          // 用时间计算粒子生命周期
          float age = mod(u_time, a_lifetime);
          v_alpha = 1.0 - age / a_lifetime;

          // 物理模拟
          vec3 pos = position + a_velocity * age + 0.5 * u_gravity * age * age;

          vec4 mvPosition = modelViewMatrix * vec4(pos, 1.0);
          gl_Position = projectionMatrix * mvPosition;
          gl_PointSize = a_size * (300.0 / -mvPosition.z);
        }
      `,
      fragmentShader: `
        varying float v_alpha;
        void main() {
          // 圆形粒子
          float dist = length(gl_PointCoord - vec2(0.5));
          if (dist > 0.5) discard;

          float alpha = v_alpha * (1.0 - dist * 2.0);
          gl_FragColor = vec4(1.0, 0.6, 0.2, alpha);
        }
      `,
      transparent: true,
      depthWrite: false,
      blending: THREE.AdditiveBlending
    })

    this.mesh = new THREE.Points(this.geometry, this.material)
  }

  private resetParticle(i: number, positions: Float32Array, velocities: Float32Array,
                         lifetimes: Float32Array, sizes: Float32Array) {
    const i3 = i * 3
    positions[i3] = (Math.random() - 0.5) * 0.5
    positions[i3+1] = 0
    positions[i3+2] = (Math.random() - 0.5) * 0.5

    velocities[i3] = (Math.random() - 0.5) * 2
    velocities[i3+1] = 2 + Math.random() * 3
    velocities[i3+2] = (Math.random() - 0.5) * 2

    lifetimes[i] = 1 + Math.random() * 2
    sizes[i] = 5 + Math.random() * 10
  }

  update(delta: number) {
    this.material.uniforms.u_time.value += delta
    this.material.uniforms.u_delta.value = delta
  }

  getObject() { return this.mesh }
}

// 使用
const particles = new GPUParticleSystem(50000)
scene.add(particles.getObject())

function animate() {
  const delta = clock.getDelta()
  particles.update(delta)
  renderer.render(scene, camera)
  requestAnimationFrame(animate)
}
```

## 你可能踩的坑

**坑一：粒子太多导致带宽瓶颈**

每帧传输大量粒子数据到 GPU 会成为瓶颈。用 Transform Feedback 在 GPU 端更新粒子。

**坑二：透明度排序**

透明粒子需要从后往前渲染。粒子系统通常用 `depthWrite: false` + `AdditiveBlending` 绕过排序问题。

**坑三：粒子生命周期管理**

用 `mod(u_time, a_lifetime)` 让粒子循环。但需要注意时间精度问题。
