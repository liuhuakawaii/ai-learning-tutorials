# 粒子系统

## 场景引入

火焰的飞溅、烟雾的飘散、雨滴的下落、魔法特效的光芒——这些视觉效果的共同点是什么？它们都由大量微小粒子组成，每个粒子遵循简单物理规则，但汇聚在一起却呈现出令人信服的动态视觉。粒子系统是实时渲染中最常用的特效技术之一，从游戏到可视化应用无处不在。本节将从最基础的 Points 渲染开始，逐步深入到 GPU 粒子系统，最终实现一个能处理 10 万粒子的高性能方案。

## 学习目标

- 理解 Points 材质与 Billboard 的渲染原理
- 掌握 InstancedMesh 实现粒子系统的方法
- 学会 GPU 粒子（Transform Feedback / Compute Shader）的实现思路
- 理解粒子发射器的生命周期管理
- 能够实现力场影响下的粒子运动
- 掌握 10 万级粒子的性能优化策略

## 1. Points 材质基础

最简单的粒子渲染方式是使用 `gl.POINTS` 图元。每个点在顶点着色器中可以设置 `gl_PointSize` 来控制大小。

```glsl
// 粒子顶点着色器
attribute vec3 aPosition;
attribute float aSize;
attribute float aLife;       // 生命周期 0~1

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uTime;

varying float vLife;

void main() {
    vLife = aLife;
    vec4 viewPos = uView * vec4(aPosition, 1.0);
    gl_Position = uProjection * viewPos;

    // 粒子越大越远越小（透视衰减）
    gl_PointSize = aSize * (300.0 / -viewPos.z);
}
```

```glsl
// 粒子片段着色器
precision mediump float;
varying float vLife;
uniform sampler2D uParticleTexture;

void main() {
    // 使用点精灵坐标采样圆形纹理
    vec2 uv = gl_PointCoord;
    vec4 texColor = texture2D(uParticleTexture, uv);

    // 根据生命周期淡出
    float alpha = smoothstep(0.0, 0.2, vLife) * smoothstep(1.0, 0.8, vLife);
    gl_FragColor = vec4(texColor.rgb, texColor.a * alpha);
}
```

Points 渲染的优点是简单高效，但有明显限制：

```
Points 渲染的限制：

+-------------------+-------------------+-------------------+
|    问题           |    原因           |    后果           |
+-------------------+-------------------+-------------------+
| 最大尺寸限制      | gl_PointSize 上限  | 粒子不能太大      |
| 不能旋转          | 点精灵无朝向      | 形状固定          |
| 透视变形          | 屏幕空间方形      | 边缘锯齿明显      |
| 深度排序困难      | 无面片信息        | 透明混合错误      |
+-------------------+-------------------+-------------------+
```

## 2. Billboard 原理

Billboard（广告牌）是一个始终面向相机的四边形。相比 Points，它提供了更多控制自由度。

```
Billboard 面向相机原理：

        相机位置
           *
          /|
         / |
        /  |  视线方向
       /   |
      /    v
     +-----+-----+
     |  Billboard  |  <-- 始终垂直于视线
     +-----+-----+
           |
           * 粒子位置

构建 Billboard 的三个向量：
  right = normalize(cross(cameraUp, viewDir))
  up    = cross(viewDir, right)
  四个顶点 = center ± right * halfWidth ± up * halfHeight
```

```typescript
// Three.js 中手动构建 Billboard 四边形
import * as THREE from 'three';

function createBillboardGeometry(
  positions: Float32Array,
  sizes: Float32Array
): THREE.BufferGeometry {
  const count = positions.length / 3;
  const vertices = new Float32Array(count * 4 * 3); // 每个粒子 4 个顶点
  const uvs = new Float32Array(count * 4 * 2);
  const indices = new Uint32Array(count * 6);        // 每个粒子 2 个三角形

  for (let i = 0; i < count; i++) {
    const px = positions[i * 3];
    const py = positions[i * 3 + 1];
    const pz = positions[i * 3 + 2];
    const s = sizes[i];
    const vi = i * 4;

    // 四个角点（局部空间，着色器中转 Billboard）
    vertices[vi * 3]     = px; vertices[vi * 3 + 1] = py; vertices[vi * 3 + 2] = pz;
    vertices[(vi+1) * 3] = px; vertices[(vi+1) * 3 + 1] = py; vertices[(vi+1) * 3 + 2] = pz;
    vertices[(vi+2) * 3] = px; vertices[(vi+2) * 3 + 1] = py; vertices[(vi+2) * 3 + 2] = pz;
    vertices[(vi+3) * 3] = px; vertices[(vi+3) * 3 + 1] = py; vertices[(vi+3) * 3 + 2] = pz;

    // UV 坐标
    uvs[vi * 2] = 0; uvs[vi * 2 + 1] = 0;
    uvs[(vi+1) * 2] = 1; uvs[(vi+1) * 2 + 1] = 0;
    uvs[(vi+2) * 2] = 1; uvs[(vi+2) * 2 + 1] = 1;
    uvs[(vi+3) * 2] = 0; uvs[(vi+3) * 2 + 1] = 1;

    // 两个三角形
    const ii = i * 6;
    indices[ii] = vi; indices[ii+1] = vi+1; indices[ii+2] = vi+2;
    indices[ii+3] = vi; indices[ii+4] = vi+2; indices[ii+5] = vi+3;
  }

  const geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(vertices, 3));
  geo.setAttribute('uv', new THREE.BufferAttribute(uvs, 2));
  geo.setIndex(new THREE.BufferAttribute(indices, 1));
  return geo;
}
```

Billboard 顶点着色器核心：

```glsl
// Billboard 顶点着色器
attribute vec3 aCenter;      // 粒子中心位置
attribute vec2 aCorner;      // 角点偏移 (-1,-1) (1,-1) (1,1) (-1,1)
attribute float aSize;
attribute float aLife;

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uScale;

varying vec2 vUV;
varying float vLife;

void main() {
    vLife = aLife;
    vUV = aCorner * 0.5 + 0.5;

    // 从 View 矩阵提取相机的 right 和 up 向量
    vec3 right = vec3(uView[0][0], uView[1][0], uView[2][0]);
    vec3 up    = vec3(uView[0][1], uView[1][1], uView[2][1]);

    float size = aSize * uScale;
    vec3 worldPos = aCenter
        + right * aCorner.x * size
        + up    * aCorner.y * size;

    gl_Position = uProjection * uView * vec4(worldPos, 1.0);
}
```

## 3. InstancedMesh 粒子

使用 InstancedMesh 可以大幅减少 Draw Call，每个粒子作为一个实例。

```typescript
import * as THREE from 'three';

const PARTICLE_COUNT = 50000;

// 共享几何体（一个四边形）
const quadGeo = new THREE.PlaneGeometry(1, 1);

// 实例属性
const instancePositions = new Float32Array(PARTICLE_COUNT * 3);
const instanceSizes = new Float32Array(PARTICLE_COUNT);
const instanceLives = new Float32Array(PARTICLE_COUNT);

// 初始化粒子
for (let i = 0; i < PARTICLE_COUNT; i++) {
  instancePositions[i * 3] = (Math.random() - 0.5) * 20;
  instancePositions[i * 3 + 1] = Math.random() * 10;
  instancePositions[i * 3 + 2] = (Math.random() - 0.5) * 20;
  instanceSizes[i] = 0.1 + Math.random() * 0.3;
  instanceLives[i] = Math.random();
}

const geometry = quadGeo.clone();
geometry.setAttribute('aInstancePosition',
  new THREE.InstancedBufferAttribute(instancePositions, 3));
geometry.setAttribute('aInstanceSize',
  new THREE.InstancedBufferAttribute(instanceSizes, 1));
geometry.setAttribute('aInstanceLife',
  new THREE.InstancedBufferAttribute(instanceLives, 1));

const material = new THREE.ShaderMaterial({
  vertexShader: billboardVertShader,
  fragmentShader: particleFragShader,
  uniforms: {
    uTime: { value: 0 },
    uParticleTexture: { value: particleTexture },
  },
  transparent: true,
  depthWrite: false,
  blending: THREE.AdditiveBlending,
});

const instancedMesh = new THREE.InstancedMesh(geometry, material, PARTICLE_COUNT);
scene.add(instancedMesh);
```

InstancedMesh 顶点着色器：

```glsl
// InstancedMesh Billboard 着色器
attribute vec3 aInstancePosition;
attribute float aInstanceSize;
attribute float aInstanceLife;

varying vec2 vUV;
varying float vLife;

void main() {
    vLife = aInstanceLife;
    vUV = uv;  // PlaneGeometry 自带 UV

    vec3 right = vec3(viewMatrix[0][0], viewMatrix[1][0], viewMatrix[2][0]);
    vec3 up    = vec3(viewMatrix[0][1], viewMatrix[1][1], viewMatrix[2][1]);

    vec3 worldPos = aInstancePosition
        + right * position.x * aInstanceSize
        + up    * position.y * aInstanceSize;

    gl_Position = projectionMatrix * viewMatrix * vec4(worldPos, 1.0);
}
```

## 4. GPU 粒子（Transform Feedback）

当粒子数量达到 10 万级别，CPU 更新成为瓶颈。GPU 粒子利用 Transform Feedback 在 GPU 上完成位置/速度更新。

```
GPU 粒子流水线：

  ┌─────────────────────────────────────────────────────┐
  │                    GPU                              │
  │                                                     │
  │  ┌──────────┐    Transform     ┌──────────┐        │
  │  │ 上一帧   │    Feedback      │ 新位置   │        │
  │  │ 位置/速度 │ ──────────────> │ 位置/速度 │        │
  │  └──────────┘                  └──────────┘        │
  │       │                             │              │
  │       │         渲染 Pass           │              │
  │       └─────────────────────────────┘              │
  │                     │                              │
  │                     v                              │
  │              屏幕输出粒子                            │
  └─────────────────────────────────────────────────────┘

  关键：数据始终在 GPU 上，无需回传 CPU
```

```typescript
// WebGL2 Transform Feedback 粒子设置
const gl = renderer.getContext() as WebGL2RenderingContext;

// 创建 Transform Feedback
const tf = gl.createTransformFeedback();
gl.bindTransformFeedback(gl.TRANSFORM_FEEDBACK, tf);

// 双缓冲：A 写入，B 读出，下一帧交换
const bufferA = gl.createBuffer();
const bufferB = gl.createBuffer();

gl.bindBuffer(gl.ARRAY_BUFFER, bufferA);
gl.bufferData(gl.ARRAY_BUFFER, initialData, gl.DYNAMIC_COPY);

gl.bindBuffer(gl.ARRAY_BUFFER, bufferB);
gl.bufferData(gl.ARRAY_BUFFER, initialData, gl.DYNAMIC_COPY);

// 绑定 Transform Feedback Buffer
gl.bindTransformFeedback(gl.TRANSFORM_FEEDBACK, tf);
gl.bindBufferBase(gl.TRANSFORM_FEEDBACK_BUFFER, 0, bufferB);

// 开始 Transform Feedback
gl.beginTransformFeedback(gl.POINTS);
gl.drawArrays(gl.POINTS, 0, PARTICLE_COUNT);
gl.endTransformFeedback();

// 交换缓冲
[bufferA, bufferB] = [bufferB, bufferA];
```

GPU 更新粒子的着色器：

```glsl
// Transform Feedback 更新着色器
#version 300 es
precision highp float;

in vec3 aPosition;
in vec3 aVelocity;
in float aLife;
in float aSize;

uniform float uDeltaTime;
uniform float uTime;
uniform vec3 uGravity;
uniform float uLifeDecay;

out vec3 vPosition;
out vec3 vVelocity;
out float vLife;
out float vSize;

// 哈希随机函数
float hash(float n) { return fract(sin(n) * 43758.5453); }

void main() {
    vec3 pos = aPosition;
    vec3 vel = aVelocity;
    float life = aLife - uLifeDecay * uDeltaTime;

    // 生命耗尽，重置粒子
    if (life <= 0.0) {
        float seed = float(gl_VertexID) + uTime;
        pos = vec3(
            (hash(seed) - 0.5) * 10.0,
            hash(seed + 1.0) * 5.0,
            (hash(seed + 2.0) - 0.5) * 10.0
        );
        vel = vec3(
            (hash(seed + 3.0) - 0.5) * 2.0,
            hash(seed + 4.0) * 5.0 + 2.0,
            (hash(seed + 5.0) - 0.5) * 2.0
        );
        life = 1.0;
    }

    // 物理更新
    vel += uGravity * uDeltaTime;
    pos += vel * uDeltaTime;

    // 地面碰撞
    if (pos.y < 0.0) {
        pos.y = 0.0;
        vel.y *= -0.3; // 反弹衰减
        vel.xz *= 0.8; // 摩擦
    }

    vPosition = pos;
    vVelocity = vel;
    vLife = life;
    vSize = aSize;
}
```

## 5. 粒子发射器

粒子发射器控制粒子的初始属性：位置、速度、生命周期、大小等。

```
常见发射器形状：

  点发射器          球形发射器        圆锥发射器
      *              ****              *
     /|\            * ** *           / | \
    / | \          *  **  \         /  |  \
   /  |  \        *  ** *          /   |   \
  发射方向         球面均匀          锥体内随机

  盒形发射器        圆环发射器
  +-------+          ***
  | * * * |        *     *
  | * * * |       *       *
  | * * * |        *     *
  +-------+          ***
```

```typescript
interface ParticleEmitter {
  position: THREE.Vector3;
  emitRate: number;          // 每秒发射数量
  lifeRange: [number, number];
  sizeRange: [number, number];
  speedRange: [number, number];
  direction: THREE.Vector3;  // 发射方向
  spread: number;            // 扩散角度（弧度）
}

function emitParticle(
  emitter: ParticleEmitter,
  rng: () => number
): { pos: THREE.Vector3; vel: THREE.Vector3; life: number; size: number } {
  // 随机生命周期和大小
  const life = emitter.lifeRange[0] +
    rng() * (emitter.lifeRange[1] - emitter.lifeRange[0]);
  const size = emitter.sizeRange[0] +
    rng() * (emitter.sizeRange[1] - emitter.sizeRange[0]);

  // 在扩散锥体内随机方向
  const theta = rng() * Math.PI * 2;
  const phi = rng() * emitter.spread;
  const dir = new THREE.Vector3(
    Math.sin(phi) * Math.cos(theta),
    Math.cos(phi),
    Math.sin(phi) * Math.sin(theta)
  );
  // 将方向旋转到发射器朝向
  dir.applyQuaternion(
    new THREE.Quaternion().setFromUnitVectors(
      new THREE.Vector3(0, 1, 0), emitter.direction
    )
  );

  const speed = emitter.speedRange[0] +
    rng() * (emitter.speedRange[1] - emitter.speedRange[0]);

  return {
    pos: emitter.position.clone(),
    vel: dir.multiplyScalar(speed),
    life,
    size,
  };
}
```

## 6. 粒子力场

力场可以改变粒子运动轨迹，实现风、漩涡、引力等效果。

```glsl
// GPU 粒子力场计算（在更新着色器中）
uniform float uWindStrength;
uniform vec3 uWindDirection;
uniform float uTurbulence;

// 漩涡力场
vec3 vortexForce(vec3 pos, vec3 center, float strength, vec3 axis) {
    vec3 toCenter = center - pos;
    float dist = length(toCenter);
    if (dist < 0.01) return vec3(0.0);

    vec3 tangent = normalize(cross(axis, toCenter));
    return tangent * strength / (dist * dist);
}

// Perlin 噪声风力
vec3 windForce(vec3 pos, float time) {
    float noiseX = snoise(pos * 0.1 + time * 0.3);
    float noiseY = snoise(pos * 0.1 + time * 0.3 + 100.0);
    float noiseZ = snoise(pos * 0.1 + time * 0.3 + 200.0);
    return uWindDirection * uWindStrength + vec3(noiseX, noiseY, noiseZ) * uTurbulence;
}

// 在 main() 中累加力
void main() {
    vec3 force = uGravity;
    force += windForce(aPosition, uTime);
    force += vortexForce(aPosition, vec3(0, 5, 0), 2.0, vec3(0, 1, 0));

    vec3 vel = aVelocity + force * uDeltaTime;
    vec3 pos = aPosition + vel * uDeltaTime;

    // ... 输出
}
```

## 7. 10 万粒子性能优化

```
性能优化策略对比：

  策略                  Draw Call   CPU 开销   GPU 开销   适用场景
  ──────────────────────────────────────────────────────────────
  Points                1           低         低         简单效果
  InstancedMesh         1           低         中         中等规模
  Transform Feedback    1~2         极低       高         大规模 GPU 粒子
  Compute Shader        1           极低       高         WebGL2/WebGPU
```

关键优化点：

```typescript
// 1. 粒子池化 - 避免 GC
class ParticlePool {
  private pool: Float32Array;
  private aliveCount: number = 0;

  constructor(maxCount: number) {
    // 位置(3) + 速度(3) + 生命(1) + 大小(1) = 8 floats/粒子
    this.pool = new Float32Array(maxCount * 8);
  }

  // 顺序排列活跃粒子，尾部是死亡粒子
  swap(index: number): void {
    this.aliveCount--;
    const lastAlive = this.aliveCount;
    const stride = 8;
    // 将最后一个活跃粒子移到当前位置
    for (let i = 0; i < stride; i++) {
      this.pool[index * stride + i] = this.pool[lastAlive * stride + i];
    }
  }
}

// 2. 视锥剔除
function isParticleVisible(pos: THREE.Vector3, camera: THREE.Camera): boolean {
  const frustum = new THREE.Frustum();
  frustum.setFromProjectionMatrix(
    new THREE.Matrix4().multiplyMatrices(
      camera.projectionMatrix, camera.matrixWorldInverse
    )
  );
  return frustum.containsPoint(pos);
}

// 3. LOD：远处粒子降低数量和大小
function getParticleLOD(distance: number): { count: number; sizeScale: number } {
  if (distance < 20) return { count: 1.0, sizeScale: 1.0 };
  if (distance < 50) return { count: 0.5, sizeScale: 0.8 };
  return { count: 0.2, sizeScale: 0.6 };
}

// 4. 使用 Uint16 索引减少带宽
// 5. 纹理图集减少材质切换
// 6. 混合模式排序：不透明粒子先渲染，透明粒子后渲染
```

## 常见误区

1. **过度依赖 CPU 更新**：粒子数量超过 1 万时，CPU 每帧遍历更新位置/速度会成为瓶颈。应该使用 Transform Feedback 或 Compute Shader 将物理计算搬到 GPU 上，CPU 只负责发射和参数传递。

2. **忽略深度排序**：透明粒子如果不排序，会出现"后面的粒子遮挡前面"的视觉错误。要么使用加法混合（Additive Blending）绕过排序，要么对粒子按距离排序后再渲染。

3. **每个粒子一个 Draw Call**：新手常为每个粒子创建独立 Mesh，导致成千上万的 Draw Call。应该使用 InstancedMesh 或将所有粒子合并到一个 BufferGeometry 中。

4. **不考虑内存碎片**：频繁创建和销毁粒子对象会导致 GC 压力。应该使用对象池（Particle Pool），预分配固定大小的数组，复用已死亡粒子的内存。

---

## 工程建议

1. **选择合适的粒子方案**：1000 粒子以内用 Points 或 InstancedMesh 即可；1 万粒子考虑 InstancedMesh + GPU 更新；10 万以上必须用 Transform Feedback。不要过度设计。

2. **纹理图集优化**：将多种粒子纹理（烟、火、火花、光晕）合到一张图集中，通过 UV 偏移选择不同纹理，避免材质切换。

3. **混合模式策略**：发光粒子用 Additive Blending，烟雾粒子用 Alpha Blending。不同混合模式的粒子应分批渲染，先渲染不透明物体，再渲染 Alpha Test，最后渲染透明粒子。

4. **监控 GPU 时间**：使用 `renderer.info` 或 WebGL 扩展 `EXT_disjoint_timer_query` 监控粒子渲染的 GPU 耗时，确保在目标帧率预算内（通常粒子系统不应超过 2ms）。

## 小结

本节从最简单的 Points 渲染开始，逐步介绍了 Billboard、InstancedMesh、GPU 粒子三种递进方案。粒子系统的核心是：用最少的 Draw Call 渲染最多的粒子，同时保持物理模拟的流畅性。力场、发射器形状、生命周期管理是丰富粒子效果的关键。在实际项目中，应根据粒子数量和平台性能选择合适的方案。

## 参考答案

### 练习一

**思路**：使用 Points 材质渲染雨滴，每个粒子从随机高度下落，到达地面（y=0）后重置到上方。在顶点着色器中控制 `gl_PointSize` 模拟透视衰减，片段着色器中拉伸 UV 使点精灵呈水滴形状。

**答案**：

```glsl
// 顶点着色器
attribute vec3 aPosition;
attribute float aLife;
attribute float aSpeed;

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uTime;
uniform float uRainLength;

varying float vLife;
varying float vSpeed;

void main() {
    vLife = aLife;
    vSpeed = aSpeed;

    // 位置更新：y 方向下落
    vec3 pos = aPosition;
    pos.y -= mod(uTime * aSpeed, 20.0);

    // 如果落到地面以下，重置到上方
    if (pos.y < 0.0) {
        pos.y += 20.0;
    }

    vec4 viewPos = uView * vec4(pos, 1.0);
    gl_Position = uProjection * viewPos;

    // 透视衰减 + 拉长效果
    gl_PointSize = max(2.0, 8.0 * (100.0 / -viewPos.z));
}
```

```glsl
// 片段着色器
precision mediump float;
varying float vLife;
varying float vSpeed;

void main() {
    vec2 uv = gl_PointCoord;

    // 拉伸 UV 使雨滴呈椭圆形（模拟运动模糊）
    uv.y = (uv.y - 0.5) * 4.0 + 0.5;

    // 超出范围的像素丢弃
    if (uv.y < 0.0 || uv.y > 1.0) discard;

    // 雨滴渐变：顶部透明，底部不透明
    float alpha = smoothstep(0.0, 0.3, uv.y) * smoothstep(1.0, 0.7, uv.y);
    vec3 color = vec3(0.7, 0.8, 1.0); // 浅蓝色雨滴

    gl_FragColor = vec4(color, alpha * 0.6);
}
```


### 练习二

**思路**：将练习一的 Points 方案改为 InstancedMesh 方案。每个实例是一个面片（PlaneGeometry），通过 instance attribute 传递位置和生命周期。在顶点着色器中构建 Billboard 矩阵，使面片始终面向相机。

**答案**：

```typescript
// Three.js InstancedMesh 雨滴实现
import * as THREE from 'three';

const rainCount = 3000;
const geometry = new THREE.PlaneGeometry(0.05, 0.3); // 细长雨滴形状

const material = new THREE.ShaderMaterial({
    uniforms: {
        uTime: { value: 0 },
        uRainTexture: { value: rainTexture },
    },
    vertexShader: `
        attribute vec3 instanceOffset;
        attribute float instanceSpeed;
        attribute float instanceLife;

        uniform float uTime;

        varying vec2 vUV;
        varying float vAlpha;

        void main() {
            vUV = uv;

            // 计算当前位置
            vec3 pos = instanceOffset;
            pos.y -= mod(uTime * instanceSpeed, 20.0);
            if (pos.y < 0.0) pos.y += 20.0;

            // Billboard：提取相机的右方向和上方向
            vec3 camRight = vec3(viewMatrix[0][0], viewMatrix[1][0], viewMatrix[2][0]);
            vec3 camUp    = vec3(viewMatrix[0][1], viewMatrix[1][1], viewMatrix[2][1]);

            // 将面片顶点变换到世界空间（Billboard）
            vec3 worldPos = pos + camRight * position.x + camUp * position.y;

            gl_Position = projectionMatrix * viewMatrix * vec4(worldPos, 1.0);

            // 基于生命周期的透明度
            float life = mod(instanceLife + uTime * 0.1, 1.0);
            vAlpha = smoothstep(0.0, 0.1, life) * smoothstep(1.0, 0.8, life);
        }
    `,
    fragmentShader: `
        uniform sampler2D uRainTexture;
        varying vec2 vUV;
        varying float vAlpha;

        void main() {
            vec4 texColor = texture2D(uRainTexture, vUV);
            gl_FragColor = vec4(texColor.rgb, texColor.a * vAlpha * 0.7);
        }
    `,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending,
});

const mesh = new THREE.InstancedMesh(geometry, material, rainCount);

// 设置 instance attributes
const offsets = new Float32Array(rainCount * 3);
const speeds = new Float32Array(rainCount);
const lifes = new Float32Array(rainCount);

for (let i = 0; i < rainCount; i++) {
    offsets[i * 3] = (Math.random() - 0.5) * 40;
    offsets[i * 3 + 1] = 0;
    offsets[i * 3 + 2] = (Math.random() - 0.5) * 40;
    speeds[i] = 5.0 + Math.random() * 8.0;
    lifes[i] = Math.random();
}

geometry.setAttribute('instanceOffset', new THREE.InstancedBufferAttribute(offsets, 3));
geometry.setAttribute('instanceSpeed', new THREE.InstancedBufferAttribute(speeds, 1));
geometry.setAttribute('instanceLife', new THREE.InstancedBufferAttribute(lifes, 1));
```

**要点**：
- Billboard 矩阵从 `viewMatrix` 中提取相机的右方向和上方向向量
- InstancedMesh 方案的优势是可以使用任意几何形状和纹理，不受 `gl_PointSize` 限制
- Instance attribute 使用 `InstancedBufferAttribute` 传递，每个实例一份数据

### 练习三

**思路**：火焰粒子需要 Additive Blending 叠加发光效果，颜色从黄（出生）渐变到红（消亡），最终变为透明。粒子受向上的热力和轻微的随机扰动影响，模拟火焰的飘动。

**答案**：

```glsl
// 火焰顶点着色器
attribute vec3 aPosition;
attribute vec3 aVelocity;
attribute float aLife;
attribute float aSize;

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uTime;

varying float vLife;
varying vec2 vUV;

void main() {
    vLife = aLife;

    // 粒子位置：向上飘动 + 轻微横向摆动
    vec3 pos = aPosition;
    float age = mod(uTime * 0.5 + aLife, 1.0);
    pos += aVelocity * age;
    pos.x += sin(uTime * 3.0 + aLife * 6.28) * 0.1 * age;

    vec4 viewPos = uView * vec4(pos, 1.0);
    gl_Position = uProjection * viewPos;

    // 粒子随生命周期缩小
    float size = aSize * (1.0 - age * 0.5);
    gl_PointSize = size * (200.0 / -viewPos.z);

    vLife = 1.0 - age; // 1=刚出生, 0=消亡
}
```

```glsl
void main() {
    vec2 uv = gl_PointCoord;
    float dist = length(uv - 0.5) * 2.0;

    // 圆形粒子，边缘渐变
    float circle = 1.0 - smoothstep(0.0, 1.0, dist);

    vec3 yellow = vec3(1.0, 0.9, 0.2);
    vec3 orange = vec3(1.0, 0.5, 0.0);
    vec3 red    = vec3(0.8, 0.1, 0.0);
    vec3 dark   = vec3(0.3, 0.0, 0.0);

    vec3 color;
    if (vLife > 0.7) {
        color = mix(orange, yellow, (vLife - 0.7) / 0.3);
    } else if (vLife > 0.3) {
        color = mix(red, orange, (vLife - 0.3) / 0.4);
    } else {
        color = mix(dark, red, vLife / 0.3);
    }

    // 透明度：出生时淡入，消亡时淡出
    float alpha = smoothstep(0.0, 0.1, vLife) * smoothstep(0.0, 0.5, vLife);

    gl_FragColor = vec4(color * circle, alpha * circle);
}
```

### 练习四

**思路**：Transform Feedback 允许 GPU 在顶点着色器阶段输出数据到 Buffer Object，实现无需 CPU 介入的粒子更新。创建两个 Buffer 交替使用（Ping-Pong），一个读取当前状态，另一个写入下一帧状态。漩涡力场通过旋转向量实现。

**答案**：

```glsl
// Transform Feedback 更新着色器
#version 300 es
precision highp float;

in vec3 aPosition;
in vec3 aVelocity;
in float aLife;

uniform float uDeltaTime;
uniform float uTime;
uniform vec3 uVortexCenter;    // 漩涡中心
uniform float uVortexStrength; // 漩涡强度

out vec3 vPosition;
out vec3 vVelocity;
out float vLife;

// 旋转向量（绕 Y 轴）
vec3 rotateY(vec3 v, float angle) {
    float c = cos(angle);
    float s = sin(angle);
    return vec3(v.x * c + v.z * s, v.y, -v.x * s + v.z * c);
}

void main() {
    vec3 pos = aPosition;
    vec3 vel = aVelocity;
    float life = aLife;

    // 更新生命周期
    life -= uDeltaTime * 0.2;

    // 如果粒子死亡，重置到发射位置
    if (life <= 0.0) {
        // 随机重置（使用位置作为伪随机种子）
        float seed = fract(sin(dot(pos.xy, vec2(12.9898, 78.233))) * 43758.5453);
        pos = vec3(
            (seed - 0.5) * 2.0,
            0.0,
            (fract(seed * 7.13) - 0.5) * 2.0
        );
        vel = vec3(
            (fract(seed * 3.17) - 0.5) * 0.5,
            2.0 + fract(seed * 5.31) * 3.0,
            (fract(seed * 11.93) - 0.5) * 0.5
        );
        life = 1.0;
    }

    // 漩涡力场：计算到中心的方向，施加切线力
    vec3 toCenter = uVortexCenter - pos;
    float dist = length(toCenter.xz);
    vec3 tangent = normalize(vec3(-toCenter.z, 0.0, toCenter.x));

    // 力场强度随距离衰减
    float force = uVortexStrength / (1.0 + dist * dist);
    vel += tangent * force * uDeltaTime;

    // 重力
    vel.y -= 0.5 * uDeltaTime;

    // 阻尼
    vel *= 0.99;

    // 位置更新
    pos += vel * uDeltaTime;

    vPosition = pos;
    vVelocity = vel;
    vLife = life;
}
```

```typescript
// Transform Feedback 设置
const particleCount = 100000;

// 创建两个 Buffer（Ping-Pong）
const buffers: THREE.BufferAttribute[] = [
    new THREE.BufferAttribute(new Float32Array(particleCount * 7), 7), // pos(3)+vel(3)+life(1)
    new THREE.BufferAttribute(new Float32Array(particleCount * 7), 7),
];

// 初始化粒子数据
for (let i = 0; i < particleCount; i++) {
    const offset = i * 7;
    buffers[0].array[offset]     = (Math.random() - 0.5) * 4; // x
    buffers[0].array[offset + 1] = Math.random() * 5;          // y
    buffers[0].array[offset + 2] = (Math.random() - 0.5) * 4; // z
    buffers[0].array[offset + 3] = (Math.random() - 0.5) * 0.5; // vx
    buffers[0].array[offset + 4] = 2.0 + Math.random() * 3.0;   // vy
    buffers[0].array[offset + 5] = (Math.random() - 0.5) * 0.5; // vz
    buffers[0].array[offset + 6] = Math.random();                // life
}

// 使用 THREE.BufferGeometry 创建 Transform Feedback
const gl = renderer.getContext();
const tf = gl.createTransformFeedback();

// 每帧交替读写 Buffer
let readBuffer = 0;
function update() {
    gl.bindTransformFeedback(gl.TRANSFORM_FEEDBACK, tf);
    gl.bindBufferBase(gl.TRANSFORM_FEEDBACK_BUFFER, 0, buffers[1 - readBuffer].buffer);

    gl.beginTransformFeedback(gl.POINTS);
    // 绘制使用 buffers[readBuffer] 作为输入
    gl.drawArrays(gl.POINTS, 0, particleCount);
    gl.endTransformFeedback();

    gl.bindTransformFeedback(gl.TRANSFORM_FEEDBACK, null);
    readBuffer = 1 - readBuffer; // 交换
}
```

**要点**：
- Transform Feedback 是 WebGL 2.0 特性（GLSL 300 es），需要 `#version 300 es` 声明
- Ping-Pong 双缓冲避免读写同一 Buffer 造成数据竞争
- 漩涡力场通过计算切线方向的力实现，力的大小随距离平方衰减

### 练习五

**思路**：根据粒子到相机的距离，在顶点着色器中计算 LOD 等级。近距离粒子保持完整密度和大小，远距离粒子降低密度（部分粒子不渲染）并增大单个粒子尺寸以补偿视觉效果。

**答案**：

```glsl
// LOD 粒子顶点着色器
attribute vec3 aPosition;
attribute float aSize;
attribute float aLife;
attribute float aSeed; // 用于 LOD 密度裁剪的随机种子

uniform mat4 uProjection;
uniform mat4 uView;
uniform vec3 uCameraPos;
uniform float uLodNear;   // LOD 近距离阈值，如 10
uniform float uLodFar;    // LOD 远距离阈值，如 50

varying float vLife;
varying float vAlpha;

void main() {
    float dist = length(aPosition - uCameraPos);

    // LOD 等级计算：0=最近，1=中距离，2=远距离
    float lod = smoothstep(uLodNear, uLodFar, dist);

    // 远距离粒子随机丢弃（降低密度）
    // aSeed 是 0~1 的随机值，当 LOD 越高时丢弃阈值越严格
    float discardThreshold = lod * 0.7; // 最远丢弃 70% 的粒子
    if (aSeed < discardThreshold) {
        // 将顶点移到不可见位置
        gl_Position = vec4(0.0, 0.0, -10000.0, 1.0);
        gl_PointSize = 0.0;
        vLife = 0.0;
        vAlpha = 0.0;
        return;
    }

    vLife = aLife;

    vec4 viewPos = uView * vec4(aPosition, 1.0);
    gl_Position = uProjection * viewPos;

    // LOD 影响粒子大小：远处粒子更大以补偿密度降低
    float sizeMultiplier = mix(1.0, 2.5, lod);
    gl_PointSize = aSize * sizeMultiplier * (300.0 / -viewPos.z);

    // 远距离粒子略微提高透明度，避免过于突兀
    vAlpha = mix(1.0, 0.6, lod);
}
```

```typescript
// TypeScript LOD 粒子系统管理
class LODParticleSystem {
    private lodNear: number;
    private lodFar: number;

    constructor(options: { lodNear?: number; lodFar?: number } = {}) {
        this.lodNear = options.lodNear ?? 10;
        this.lodFar = options.lodFar ?? 50;
    }

    createLODAttribute(count: number): Float32Array {
        const seeds = new Float32Array(count);
        for (let i = 0; i < count; i++) {
            seeds[i] = Math.random();
        }
        return seeds;
    }

    updateUniforms(camera: THREE.Camera, material: THREE.ShaderMaterial): void {
        material.uniforms.uLodNear.value = this.lodNear;
        material.uniforms.uLodFar.value = this.lodFar;
        material.uniforms.uCameraPos.value.copy(camera.position);
    }
}
```

**要点**：
- LOD 密度裁剪使用 `discard` 或将顶点移到不可见位置实现，避免分支开销
- 远距离粒子增大尺寸补偿密度降低，保持视觉上的"粒子云"效果
- LOD 阈值应根据场景规模和粒子密度动态调整，避免远处明显"跳变"
