# 卡通渲染

## 场景引入

《原神》《塞尔达传说：旷野之息》《女神异闻录5》——这些游戏都有着独特的卡通风格画面。它们不是简单的"低画质"，而是精心设计的非写实渲染（NPR）技术。卡通渲染的核心是将连续的光照变化量化为离散的色阶，同时用描边强化轮廓，让画面看起来像手绘动画。本节将从最基础的 Cel Shading 开始，逐步深入到描边、色阶控制、风格化高光等技术。

## 学习目标

- 掌握 Cel Shading（色阶量化）的实现原理
- 学会两种描边技术：法线外扩和屏幕空间边缘检测
- 理解 Ramp 贴图的色阶控制方法
- 掌握风格化高光和头发高光模型
- 能够实现完整的 NPR 卡通渲染管线

## 1. Cel Shading（色阶量化）

Cel Shading 的核心是将连续的光照值量化为离散的几个等级。

```
色阶量化示意：

  光照值
  1.0 ┤ ████████████████████  亮面
      │ ████████████████████
  0.5 ┤───────────────────────── 阈值
      │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  暗面
  0.0 ┤ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
      └────────────────────────
      0         角度          180

  连续渐变 (Phong)     2级色阶       3级色阶
  ┌──────────┐      ┌──────────┐   ┌──────────┐
  │ ░░░▒▒▒███│      │ ▓▓▓██████│   │ ░░░▒▒▒███│
  │ ░░░▒▒▒███│  ──> │ ▓▓▓██████│   │ ░░░▒▒▒███│
  │ ░░░▒▒▒███│      │ ▓▓▓██████│   │ ░░░▒▒▒███│
  └──────────┘      └──────────┘   └──────────┘
```

```glsl
// 基础 Cel Shading 片段着色器
uniform vec3 uBaseColor;
uniform vec3 uShadowColor;
uniform float uShadowThreshold;  // 0.5
uniform int uShadowLevels;       // 色阶数量 2~4

varying vec3 vNormal;
varying vec3 vLightDir;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 lightDir = normalize(vLightDir);

    // Lambert 漫反射
    float NdotL = dot(normal, lightDir);

    // 色阶量化
    float shadow;
    if (uShadowLevels == 2) {
        shadow = step(uShadowThreshold, NdotL);
    } else {
        // 多级量化
        shadow = floor(NdotL * float(uShadowLevels)) / float(uShadowLevels);
        shadow = max(shadow, 0.0);
    }

    // 颜色混合
    vec3 color = mix(uShadowColor, uBaseColor, shadow);

    gl_FragColor = vec4(color, 1.0);
}
```

更精确的色阶量化（使用 smoothstep 避免锯齿）：

```glsl
// 带过渡带的色阶量化
float smoothShadow(float NdotL, float threshold, float smoothWidth) {
    // 在阈值处有微小过渡，避免硬边锯齿
    return smoothstep(threshold - smoothWidth, threshold + smoothWidth, NdotL);
}

// 3 级色阶
float threeLevelShadow(float NdotL) {
    float level1 = smoothstep(0.3, 0.35, NdotL);
    float level2 = smoothstep(0.6, 0.65, NdotL);
    return (level1 + level2) * 0.5;
}
```

## 2. 描边技术

### 2.1 法线外扩描边

在顶点着色器中沿法线方向外扩顶点，渲染背面形成描边。

```
法线外扩描边原理：

  正面（正常渲染）    背面（法线外扩）    合成效果
     ╱╲                 ╱╲              ╱╲
    ╱  ╲               ╱  ╲            ╱║╲
   ╱    ╲             ╱    ╲          ║╱  ╲║
  ╱──────╲           ╱══════╲        ║╱────╲║
                                      描边

  步骤：
  1. 第一个 Pass：正常渲染正面
  2. 第二个 Pass：翻转面剔除，渲染背面
  3. 背面顶点沿法线外扩 outlineWidth
  4. 背面使用纯色（通常黑色）
```

```glsl
// 描边顶点着色器（法线外扩）
attribute vec3 aPosition;
attribute vec3 aNormal;

uniform mat4 uModelViewMatrix;
uniform mat4 uProjectionMatrix;
uniform float uOutlineWidth;   // 描边宽度 0.01~0.05
uniform float uOutlineZOffset; // 深度偏移避免 Z-fighting

varying vec3 vColor;

void main() {
    // 在视空间中外扩法线
    vec3 viewNormal = normalize(mat3(uModelViewMatrix) * aNormal);
    vec3 viewPos = (uModelViewMatrix * vec4(aPosition, 1.0)).xyz;

    // 沿法线方向外扩
    viewPos += viewNormal * uOutlineWidth;

    // 深度偏移（将描边稍微推远，避免 Z-fighting）
    viewPos.z += uOutlineZOffset;

    gl_Position = uProjectionMatrix * vec4(viewPos, 1.0);
}
```

```typescript
// Three.js 描边实现
class OutlineRenderer {
  private outlineMaterial: THREE.ShaderMaterial;

  constructor() {
    this.outlineMaterial = new THREE.ShaderMaterial({
      uniforms: {
        uOutlineWidth: { value: 0.03 },
        uOutlineColor: { value: new THREE.Color(0x000000) },
        uOutlineZOffset: { value: 0.001 },
      },
      vertexShader: outlineVertShader,
      fragmentShader: `
        uniform vec3 uOutlineColor;
        void main() {
          gl_FragColor = vec4(uOutlineColor, 1.0);
        }
      `,
      side: THREE.BackSide, // 只渲染背面
    });
  }

  renderOutline(renderer: THREE.WebGLRenderer, mesh: THREE.Mesh): void {
    // 保存原始材质
    const originalMaterial = mesh.material;

    // 切换为描边材质
    mesh.material = this.outlineMaterial;
    renderer.render(mesh, camera); // 需要单独渲染到模板缓冲

    // 恢复原始材质
    mesh.material = originalMaterial;
  }
}
```

### 2.2 屏幕空间边缘检测

```glsl
// Sobel 边缘检测片段着色器
uniform sampler2D uSceneTexture;
uniform sampler2D uDepthTexture;
uniform sampler2D uNormalTexture;
uniform vec2 uTexelSize;
uniform float uDepthThreshold;
uniform float uNormalThreshold;

varying vec2 vUV;

float depthEdge(vec2 uv) {
    // 采样周围 8 个像素的深度
    float d = texture2D(uDepthTexture, uv).r;
    float dN = texture2D(uDepthTexture, uv + vec2(0, uTexelSize.y)).r;
    float dS = texture2D(uDepthTexture, uv - vec2(0, uTexelSize.y)).r;
    float dE = texture2D(uDepthTexture, uv + vec2(uTexelSize.x, 0)).r;
    float dW = texture2D(uDepthTexture, uv - vec2(uTexelSize.x, 0)).r;

    // Sobel 算子
    float gx = dE - dW;
    float gy = dN - dS;
    return sqrt(gx * gx + gy * gy);
}

float normalEdge(vec2 uv) {
    vec3 n = texture2D(uNormalTexture, uv).rgb;
    vec3 nN = texture2D(uNormalTexture, uv + vec2(0, uTexelSize.y)).rgb;
    vec3 nS = texture2D(uNormalTexture, uv - vec2(0, uTexelSize.y)).rgb;
    vec3 nE = texture2D(uNormalTexture, uv + vec2(uTexelSize.x, 0)).rgb;
    vec3 nW = texture2D(uNormalTexture, uv - vec2(uTexelSize.x, 0)).rgb;

    vec3 gx = nE - nW;
    vec3 gy = nN - nS;
    return sqrt(dot(gx, gx) + dot(gy, gy));
}

void main() {
    vec3 scene = texture2D(uSceneTexture, vUV).rgb;

    float dEdge = depthEdge(vUV);
    float nEdge = normalEdge(vUV);

    float edge = step(uDepthThreshold, dEdge) + step(uNormalThreshold, nEdge);
    edge = clamp(edge, 0.0, 1.0);

    vec3 color = mix(scene, vec3(0.0), edge);
    gl_FragColor = vec4(color, 1.0);
}
```

## 3. Ramp 贴图（色阶控制）

Ramp 贴图是一种预计算的色阶查找表，通过 NdotL 值采样得到最终颜色。

```
Ramp 贴图原理：

  NdotL 值    采样 Ramp 贴图          输出颜色
  0.0 ───────> ██ (最左侧)    ───>   深阴影色
  0.3 ───────> ▓▓              ───>   浅阴影色
  0.5 ───────> ░░ (阈值)       ───>   过渡色
  0.7 ───────> ▒▒              ───>   亮面色
  1.0 ───────> ██ (最右侧)    ───>   高光色

  Ramp 贴图示例（256x1 纹理）：
  ┌─────────────────────────────────────────┐
  │ 深蓝 │ 浅蓝 │ 过渡 │ 浅黄 │ 亮黄 │ 白 │
  └─────────────────────────────────────────┘
```

```glsl
// Ramp 贴图着色器
uniform sampler2D uRampTexture;  // 256x1 或 512x1
uniform vec3 uBaseColor;
uniform float uRampOffset;  // 偏移调整

varying vec3 vNormal;
varying vec3 vLightDir;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 lightDir = normalize(vLightDir);

    float NdotL = dot(normal, lightDir) * 0.5 + 0.5; // 映射到 0~1
    NdotL = clamp(NdotL + uRampOffset, 0.0, 1.0);

    // 采样 Ramp 贴图
    vec3 rampColor = texture2D(uRampTexture, vec2(NdotL, 0.5)).rgb;

    vec3 color = uBaseColor * rampColor;
    gl_FragColor = vec4(color, 1.0);
}
```

## 4. 风格化高光

卡通渲染中的高光通常是硬边的圆形或条状光斑。

```glsl
// 卡通高光
uniform float uSpecularThreshold;  // 高光阈值
uniform float uSpecularSmooth;     // 过渡宽度
uniform vec3 uSpecularColor;
uniform float uSpecularSize;

// Blinn-Phong 卡通高光
float celSpecular(vec3 normal, vec3 viewDir, vec3 lightDir, float shininess) {
    vec3 halfDir = normalize(viewDir + lightDir);
    float NdotH = max(dot(normal, halfDir), 0.0);
    float spec = pow(NdotH, shininess);
    return smoothstep(uSpecularThreshold - uSpecularSmooth,
                      uSpecularThreshold + uSpecularSmooth, spec);
}

// 条状高光（用于头发）
float hairSpecular(vec3 normal, vec3 viewDir, vec3 lightDir,
                   vec3 hairDir, float exponent) {
    // Kajiya-Kay 模型
    float TdotL = dot(hairDir, lightDir);
    float TdotV = dot(hairDir, viewDir);
    float sinTL = sqrt(1.0 - TdotL * TdotL);
    float sinTV = sqrt(1.0 - TdotV * TdotV);

    float spec = pow(max(TdotL * TdotV + sinTL * sinTV, 0.0), exponent);
    return smoothstep(uSpecularThreshold, uSpecularThreshold + 0.05, spec);
}
```

## 5. 头发高光模型

头发渲染需要特殊的各向异性高光模型。

```
头发高光模型（Kajiya-Kay）：

  头发方向 T
  ──────────────────────>
        ╲  光线 L
         ╲
          ╲ θ
  ─────────*────────────── 头发
          ╱
         ╱ 反射
        ╱

  高光 = pow(cos(θ), exponent)
  其中 θ 是反射方向与视线方向的夹角

  双高光条带：
  ┌──────────────────┐
  │    ████ 主高光    │  <- R 通道，较窄较亮
  │  ▓▓▓▓▓▓ 副高光   │  <- G 通道，较宽较暗
  │                  │
  └──────────────────┘
```

```glsl
// 头发渲染着色器
uniform vec3 uHairColor;
uniform vec3 uHighlightColor1;  // 主高光颜色
uniform vec3 uHighlightColor2;  // 副高光颜色
uniform float uHighlightExponent1;
uniform float uHighlightExponent2;
uniform float uHighlightOffset; // 副高光偏移

varying vec3 vTangent;
varying vec3 vNormal;
varying vec3 vLightDir;
varying vec3 vViewDir;

void main() {
    vec3 T = normalize(vTangent);
    vec3 N = normalize(vNormal);
    vec3 L = normalize(vLightDir);
    vec3 V = normalize(vViewDir);

    // 漫反射（卡通化）
    float NdotL = dot(N, L) * 0.5 + 0.5;
    float shadow = smoothstep(0.4, 0.45, NdotL);

    // 主高光（较窄）
    float TdotL = dot(T, L);
    float TdotV = dot(T, V);
    float sinTL = sqrt(max(0.0, 1.0 - TdotL * TdotL));
    float sinTV = sqrt(max(0.0, 1.0 - TdotV * TdotV));
    float spec1 = pow(max(TdotL * TdotV + sinTL * sinTV, 0.0),
                      uHighlightExponent1);

    // 副高光（较宽，有偏移）
    float spec2 = pow(max(TdotL * TdotV + sinTL * sinTV + uHighlightOffset, 0.0),
                      uHighlightExponent2);

    // 合成
    vec3 baseColor = uHairColor * (0.5 + 0.5 * shadow);
    vec3 color = baseColor;
    color += uHighlightColor1 * smoothstep(0.5, 0.6, spec1);
    color += uHighlightColor2 * smoothstep(0.3, 0.4, spec2) * 0.5;

    gl_FragColor = vec4(color, 1.0);
}
```

## 常见误区

1. **色阶阈值太硬**：直接使用 `step()` 函数会导致色阶边界出现明显锯齿。应该使用 `smoothstep()` 添加一个很窄的过渡带（0.01~0.05），在保持硬边风格的同时消除锯齿。

2. **描边宽度不随距离变化**：法线外扩描边如果使用固定宽度，远处物体会有很粗的描边，近处物体描边太细。应该根据顶点到相机的距离动态调整描边宽度。

3. **忽略法线平滑**：硬边模型的法线在边缘处不连续，会导致描边出现断裂。应该使用平滑法线组（Smooth Normals）作为描边的法线源，或者在着色器中对法线进行平滑处理。

4. **所有物体使用同一套 NPR 参数**：不同材质（皮肤、头发、衣服、金属）应该使用不同的 Ramp 贴图和色阶参数。应该通过材质属性传递 NPR 参数，而不是全局统一。

---

## 工程建议

1. **Ramp 贴图设计**：使用 256x1 的横向渐变纹理作为 Ramp 贴图。设计时先确定色阶数量（通常 2~3 级），再在阈值处留出 2~4 像素的过渡带。

2. **描边分层**：角色和重要物体使用法线外扩描边（质量高），场景物体使用屏幕空间描边（性能好）。不同物体可以有不同的描边颜色和宽度。

3. **多 Pass 渲染优化**：描边 Pass 可以和主渲染 Pass 合并（使用双面渲染 + 模板测试），减少 Draw Call。对于大量物体，考虑使用 Instance Rendering。

4. **风格一致性**：整个场景应保持统一的 NPR 风格参数（色阶数量、描边宽度、过渡带宽度）。可以通过全局 Uniform 或 Post Processing Volume 统一控制。

## 参考答案

### 练习一

**思路**：Cel Shading 的核心是将连续的 NdotL 值量化为离散色阶。2 级色阶使用 `step` 函数二值化，3 级色阶使用 `floor` 函数三值化。为了在阈值处避免锯齿，加入微小的 `smoothstep` 过渡带。

**答案**：

```glsl
// Cel Shading 片段着色器（支持 2/3 级切换）
precision mediump float;

uniform vec3 uBaseColor;
uniform vec3 uShadowColor;
uniform vec3 uShadowColor2;     // 第三级阴影颜色
uniform float uThreshold1;      // 第一级阈值，如 0.5
uniform float uThreshold2;      // 第二级阈值，如 0.2
uniform int uShadowLevels;      // 2 或 3
uniform float uSmoothWidth;     // 过渡带宽度，如 0.02

varying vec3 vNormal;
varying vec3 vLightDir;

float quantize(float value, float threshold, float smoothWidth) {
    return smoothstep(threshold - smoothWidth, threshold + smoothWidth, value);
}

void main() {
    vec3 normal = normalize(vNormal);
    vec3 lightDir = normalize(vLightDir);
    float NdotL = dot(normal, lightDir);

    vec3 color;
    if (uShadowLevels == 2) {
        // 2 级色阶：亮面 / 暗面
        float shadow = quantize(NdotL, uThreshold1, uSmoothWidth);
        color = mix(uShadowColor, uBaseColor, shadow);
    } else {
        // 3 级色阶：亮面 / 中间面 / 暗面
        if (NdotL > uThreshold1) {
            color = uBaseColor;
        } else if (NdotL > uThreshold2) {
            float t = quantize(NdotL, uThreshold2, uSmoothWidth);
            color = mix(uShadowColor2, uShadowColor, t);
        } else {
            color = uShadowColor2;
        }
    }

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- 过渡带 `smoothWidth` 极小（0.01~0.03），只用于消除锯齿，不影响整体色阶感
- 多级色阶的颜色应有明度差异且可带色相偏移（如暗面偏冷色），增加画面层次感
- 色阶数量不宜超过 4 级，否则趋近于连续渐变，失去卡通风格

### 练习二

**思路**：法线外扩描边在第二个 Pass 中实现：将顶点沿法线方向外扩一定距离，然后渲染背面（`Cull Front`），形成描边轮廓。描边宽度和颜色通过 Uniform 控制。

**答案**：

```glsl
// 描边顶点着色器
attribute vec3 aPosition;
attribute vec3 aNormal;

uniform mat4 uModelViewMatrix;
uniform mat4 uProjectionMatrix;
uniform float uOutlineWidth;    // 描边宽度，如 0.03
uniform vec3 uOutlineColor;     // 描边颜色

varying vec3 vColor;

void main() {
    // 沿法线方向外扩顶点
    vec3 pos = aPosition + aNormal * uOutlineWidth;

    gl_Position = uProjectionMatrix * uModelViewMatrix * vec4(pos, 1.0);
    vColor = uOutlineColor;
}
```

```typescript
    render(renderer: THREE.WebGLRenderer, scene: THREE.Scene, camera: THREE.Camera, meshes: THREE.Mesh[]): void {
        // 切换到描边材质
        const originalMaterials = new Map<THREE.Mesh, THREE.Material>();
        for (const mesh of meshes) {
            originalMaterials.set(mesh, mesh.material as THREE.Material);
            mesh.material = this.outlineMaterial;
        }

        renderer.render(scene, camera);

        // 恢复原始材质
        for (const [mesh, material] of originalMaterials) {
            mesh.material = material;
        }
    }
}
```

**要点**：
- 法线外扩描边只渲染背面（`BackSide`），正面的法线外扩部分被正面面片遮挡
- 描边宽度应在屏幕空间保持一致，需要根据顶点深度调整外扩距离
- 尖锐边缘处法线不连续会导致描边断裂，可通过平滑法线或使用沿法线方向的偏移缓解

### 练习三

**思路**：Ramp 贴图是一张 1D 纹理，水平方向表示光照强度（0~1），垂直方向存储对应的颜色。用 NdotL 值作为 UV 的 U 坐标采样 Ramp 贴图，实现灵活的色阶和色调控制。

**答案**：

```glsl
// Ramp 贴图着色器
precision mediump float;

uniform sampler2D uRampTex;     // Ramp 贴图（1D 梯度纹理）
uniform sampler2D uDiffuseTex;  // 漫反射贴图
uniform vec3 uLightDir;

varying vec3 vNormal;
varying vec2 vUV;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 lightDir = normalize(uLightDir);
    float NdotL = dot(normal, lightDir);

    // 使用 NdotL 采样 Ramp 贴图
    // 将 [-1, 1] 映射到 [0, 1]
    float rampUV = NdotL * 0.5 + 0.5;
    vec3 rampColor = texture2D(uRampTex, vec2(rampUV, 0.5)).rgb;

    // 叠加漫反射贴图
    vec3 diffuse = texture2D(uDiffuseTex, vUV).rgb;
    vec3 finalColor = diffuse * rampColor;

    gl_FragColor = vec4(finalColor, 1.0);
}
```

```typescript
// 创建 3 级色阶 Ramp 贴图
function createRampTexture(): THREE.DataTexture {
    const width = 256;
    const data = new Uint8Array(width * 4);

    for (let i = 0; i < width; i++) {
        const t = i / width;
        let r: number, g: number, b: number;

        if (t > 0.6) {
            // 亮面：暖白色
            r = 255; g = 240; b = 220;
        } else if (t > 0.3) {
            // 中间面：柔和色
            r = 180; g = 160; b = 140;
        } else {
            // 暗面：冷暗色
            r = 80; g = 70; b = 100;
        }

        data[i * 4] = r;
        data[i * 4 + 1] = g;
        data[i * 4 + 2] = b;
        data[i * 4 + 3] = 255;
    }

    const texture = new THREE.DataTexture(data, width, 1, THREE.RGBAFormat);
    texture.minFilter = THREE.NearestFilter;
    texture.magFilter = THREE.NearestFilter;
    texture.needsUpdate = true;
    return texture;
}
```

**要点**：
- Ramp 贴图的过滤模式应设为 `NearestFilter` 以保持硬边色阶，或 `LinearFilter` 用于柔和过渡
- 色阶之间的过渡带可以通过在 Ramp 贴图中绘制平滑梯度来精确控制
- 暗面使用冷色（偏蓝/紫）而非纯黑，可以让画面更有艺术感

### 练习四

**思路**：Kajiya-Kay 模型将头发表面建模为各向异性高光。使用切线方向（沿发丝方向）与光照/视线方向的关系计算高光，分为主高光（锐利）和副高光（柔和偏移）。

**答案**：

```glsl
// Kajiya-Kay 头发渲染片段着色器
precision mediump float;

uniform vec3 uBaseColor;
uniform vec3 uHighlightColor1;   // 主高光颜色
uniform vec3 uHighlightColor2;   // 副高光颜色
uniform float uSpecularPower1;   // 主高光锐度
uniform float uSpecularPower2;   // 副高光锐度
uniform float uHighlightOffset2; // 副高光偏移
uniform vec3 uLightDir;
uniform vec3 uViewDir;

varying vec3 vTangent;
varying vec3 vNormal;
varying vec2 vUV;

void main() {
    vec3 T = normalize(vTangent);
    vec3 N = normalize(vNormal);
    vec3 L = normalize(uLightDir);
    vec3 V = normalize(uViewDir);

    // 漫反射：Kajiya-Kay 使用 sin 而非 dot
    float TdotL = dot(T, L);
    float sinTL = sqrt(1.0 - TdotL * TdotL);
    float diffuse = sinTL;

    // 主高光
    vec3 H = normalize(L + V);
    float TdotH = dot(T, H);
    float sinTH = sqrt(1.0 - TdotH * TdotH);
    float spec1 = pow(max(1.0 - sinTH, 0.0), uSpecularPower1);

    // 副高光：沿法线方向偏移切线
    vec3 T2 = normalize(T + N * uHighlightOffset2);
    float T2dotH = dot(T2, H);
    float sinT2H = sqrt(1.0 - T2dotH * T2dotH);
    float spec2 = pow(max(1.0 - sinT2H, 0.0), uSpecularPower2);

    // 最终颜色
    vec3 color = uBaseColor * diffuse * 0.6
               + uHighlightColor1 * spec1
               + uHighlightColor2 * spec2 * 0.5;

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- Kajiya-Kay 的核心：用 `sin(T, L)` 代替 `dot(N, L)` 计算漫反射，用 `sin(T, H)` 计算高光
- 副高光通过偏移切线方向（`T + N * offset`）产生，模拟头发的双层反射
- 头发切线需要在建模软件中预计算，或在着色器中从法线和 UV 梯度推导

### 练习五

**思路**：完整的 NPR 管线包含多个 Pass：1) Cel Shading 主渲染；2) 描边 Pass；3) 可选的后处理 Pass（如 Bloom 用于风格化高光）。Ramp 贴图集成到主渲染 Pass 中，风格化高光替换标准 Blinn-Phong 高光。

**答案**：

```typescript
// NPR 渲染管线管理器
class NPRPipeline {
    private outlineMaterial: THREE.ShaderMaterial;
    private mainMaterial: THREE.ShaderMaterial;
    private renderTarget: THREE.WebGLRenderTarget;

    constructor() {
        // 主渲染材质：Cel Shading + Ramp + 风格化高光
        this.mainMaterial = new THREE.ShaderMaterial({
            uniforms: {
                uRampTex: { value: null },
                uDiffuseTex: { value: null },
                uLightDir: { value: new THREE.Vector3(1, 1, 1).normalize() },
                uSpecularSize: { value: 0.2 },     // 高光大小
                uSpecularSoftness: { value: 0.1 },  // 高光柔和度
                uSpecularColor: { value: new THREE.Color(1, 1, 1) },
            },
            vertexShader: nprVertexShader,
            fragmentShader: `
                precision mediump float;
                uniform sampler2D uRampTex;
                uniform sampler2D uDiffuseTex;
                uniform vec3 uLightDir;
                uniform float uSpecularSize;
                uniform float uSpecularSoftness;
                uniform vec3 uSpecularColor;

                varying vec3 vNormal;
                varying vec3 vViewDir;
                varying vec2 vUV;

                void main() {
                    vec3 N = normalize(vNormal);
                    vec3 L = normalize(uLightDir);
                    vec3 V = normalize(vViewDir);
                    vec3 H = normalize(L + V);

                    // Ramp 贴图着色
                    float NdotL = dot(N, L);
                    float rampU = NdotL * 0.5 + 0.5;
                    vec3 rampColor = texture2D(uRampTex, vec2(rampU, 0.5)).rgb;
                    vec3 diffuse = texture2D(uDiffuseTex, vUV).rgb * rampColor;

                    // 风格化高光：硬边圆形高光
                    float NdotH = max(dot(N, H), 0.0);
                    float spec = smoothstep(1.0 - uSpecularSize - uSpecularSoftness,
                                           1.0 - uSpecularSize, NdotH);

                    vec3 finalColor = diffuse + uSpecularColor * spec;
                    gl_FragColor = vec4(finalColor, 1.0);
                }
            `,
        });
    }

    render(renderer: THREE.WebGLRenderer, scene: THREE.Scene, camera: THREE.Camera): void {
        // Pass 1: 主渲染（Cel Shading + Ramp + 高光）
        renderer.render(scene, camera);

}
```

- NPR 管线的 Pass 顺序：主渲染 → 描边 → 后处理（可选 Bloom）
- 风格化高光使用 `smoothstep` 创建硬边效果，与写实渲染的 Blinn-Phong 渐变高光不同
- 全局参数（色阶数、描边宽度、高光大小）应通过全局 Uniform 统一管理，保持风格一致性
