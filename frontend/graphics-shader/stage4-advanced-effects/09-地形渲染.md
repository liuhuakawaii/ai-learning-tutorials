# 地形渲染

## 场景引入

从《上古卷轴》的广袤大陆到《塞尔达传说：旷野之息》的海拉鲁平原，地形是开放世界游戏的骨架。一个高质量的地形系统需要处理海量几何数据、多层次纹理混合、动态 LOD 切换等复杂问题。本节将从高度图生成开始，逐步讲解 LOD 策略、纹理混合、草地渲染等核心技术，最终构建一个完整的地形渲染系统。

## 学习目标

- 掌握高度图生成方法（噪声叠加）
- 理解 LOD 策略（MipMap / GeoMipMap / Chunk-based）
- 学会基于高度和坡度的纹理混合
- 掌握地形 Splatting 技术
- 理解草地渲染（Instanced Billboard）
- 了解地形物理碰撞的实现

## 1. 高度图生成

高度图是一张灰度纹理，每个像素的亮度代表该点的地形高度。

```
高度图示意：

  灰度值   高度
  ██ 255   最高（山峰）
  ▓▓ 191   较高（山脊）
  ▒▒ 127   中等（丘陵）
  ░░ 63    较低（平原）
  ·· 0     最低（谷底）

  ┌────────────────────────────────────┐
  │      ██                            │
  │     ████                           │
  │    ██████  ▓▓                      │
  │   ████████▓▓▓▓                     │
  │  ░░░░▒▒▒▒▒▒▓▓▓▓                   │
  │ ░░░░░░▒▒▒▒▒▒▒▒▓▓                  │
  │····░░░░░░░░▒▒▒▒▒▒                  │
  │········░░░░░░░░░░                  │
  └────────────────────────────────────┘
```

### 噪声叠加（分形噪声）

```glsl
// Perlin 噪声函数
float perlinNoise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    vec2 u = f * f * (3.0 - 2.0 * f);

    float a = hash(i);
    float b = hash(i + vec2(1.0, 0.0));
    float c = hash(i + vec2(0.0, 1.0));
    float d = hash(i + vec2(1.0, 1.0));

    return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

// 分形叠加（FBM - Fractal Brownian Motion）
float fbm(vec2 p, int octaves) {
    float value = 0.0;
    float amplitude = 0.5;
    float frequency = 1.0;

    for (int i = 0; i < octaves; i++) {
        value += amplitude * perlinNoise(p * frequency);
        amplitude *= 0.5;   // 振幅衰减
        frequency *= 2.0;   // 频率倍增
    }

    return value;
}

// 不同叠加层级的效果：
// 1 octave:  基本地形起伏
// 2 octaves: 加入中等细节
// 4 octaves: 加入小丘和山谷
// 8 octaves: 加入岩石和裂缝
```

```typescript
// CPU 端高度图生成
class HeightMapGenerator {
  private width: number;
  private height: number;
  private data: Float32Array;

  constructor(width: number, height: number) {
    this.width = width;
    this.height = height;
    this.data = new Float32Array(width * height);
  }

  generate(options: {
    scale: number;
    octaves: number;
    persistence: number;
    lacunarity: number;
    seed: number;
  }): Float32Array {
    const { scale, octaves, persistence, lacunarity, seed } = options;
    const noise = new SimplexNoise(seed);

    for (let y = 0; y < this.height; y++) {
      for (let x = 0; x < this.width; x++) {
        let amplitude = 1.0;
        let frequency = 1.0;
        let value = 0.0;

        for (let o = 0; o < octaves; o++) {
          const nx = x / this.width * scale * frequency;
          const ny = y / this.height * scale * frequency;
          value += noise.noise2D(nx, ny) * amplitude;
          amplitude *= persistence;
          frequency *= lacunarity;
        }

        // 归一化到 0~1
        this.data[y * this.width + x] = (value + 1) * 0.5;
      }
    }

    return this.data;
  }

  getHeight(x: number, y: number): number {
    const ix = Math.floor(x) % this.width;
    const iy = Math.floor(y) % this.height;
    return this.data[iy * this.width + ix];
  }

  // 双线性插值获取精确高度
  getHeightInterpolated(x: number, y: number): number {
    const ix = Math.floor(x);
    const iy = Math.floor(y);
    const fx = x - ix;
    const fy = y - iy;

    const h00 = this.getHeight(ix, iy);
    const h10 = this.getHeight(ix + 1, iy);
    const h01 = this.getHeight(ix, iy + 1);
    const h11 = this.getHeight(ix + 1, iy + 1);

    const h0 = h00 * (1 - fx) + h10 * fx;
    const h1 = h01 * (1 - fx) + h11 * fx;
    return h0 * (1 - fy) + h1 * fy;
  }
}
```

## 2. LOD 策略

地形 LOD（Level of Detail）根据距离动态调整网格精度。

```
LOD 策略对比：

  MipMap LOD              GeoMipMap LOD           Chunk-based LOD
  ┌──────────────────┐   ┌──────────────────┐    ┌──────────────────┐
  │ ████████████████ │   │ ████  ██████████ │    │ ████████ ████████│
  │ ████████████████ │   │ ████  ██████████ │    │ ████████ ████████│
  │ ▓▓▓▓▓▓▓▓████████ │   │ ▓▓▓▓  ▓▓▓▓██████ │    │ ▓▓▓▓    ▓▓▓▓████│
  │ ▓▓▓▓▓▓▓▓████████ │   │ ▓▓▓▓  ▓▓▓▓██████ │    │ ▓▓▓▓    ▓▓▓▓████│
  │ ░░░░░░░░▓▓▓▓▓▓▓▓ │   │ ░░░░  ░░░░▓▓▓▓▓▓ │    │ ░░      ░░  ▓▓▓▓│
  └──────────────────┘   └──────────────────┘    └──────────────────┘
  整张图统一精度          分块独立精度              独立 Chunk 精度
```

```typescript
// GeoMipMap 地形 LOD 系统
class GeoMipMapTerrain {
  private chunks: TerrainChunk[][] = [];
  private chunkSize: number;
  private lodLevels: number;

  constructor(heightMap: HeightMapGenerator, chunkSize: number = 64) {
    this.chunkSize = chunkSize;
    this.lodLevels = 4;

    const chunksX = Math.ceil(heightMap.width / chunkSize);
    const chunksY = Math.ceil(heightMap.height / chunkSize);

    for (let cy = 0; cy < chunksY; cy++) {
      this.chunks[cy] = [];
      for (let cx = 0; cx < chunksX; cx++) {
        this.chunks[cy][cx] = new TerrainChunk(
          heightMap, cx * chunkSize, cy * chunkSize, chunkSize
        );
      }
    }
  }

  updateLOD(cameraPosition: THREE.Vector3): void {
    for (const row of this.chunks) {
      for (const chunk of row) {
        const distance = chunk.getCenter().distanceTo(cameraPosition);
        chunk.setLOD(this.calculateLOD(distance));
      }
    }
  }

  private calculateLOD(distance: number): number {
    if (distance < 50) return 0;   // 最高精度
    if (distance < 150) return 1;
    if (distance < 300) return 2;
    return 3;                       // 最低精度
  }
}

class TerrainChunk {
  private meshes: THREE.Mesh[] = []; // 每个 LOD 级别的 Mesh
  private currentLOD: number = 0;

  constructor(
    heightMap: HeightMapGenerator,
    offsetX: number,
    offsetY: number,
    size: number
  ) {
    // 为每个 LOD 级别生成不同精度的网格
    for (let lod = 0; lod < 4; lod++) {
      const resolution = size >> lod; // LOD 0: 64, LOD 1: 32, LOD 2: 16
      const geometry = this.generateChunkGeometry(
        heightMap, offsetX, offsetY, size, resolution
      );
      this.meshes[lod] = new THREE.Mesh(geometry, terrainMaterial);
    }
  }

  private generateChunkGeometry(
    heightMap: HeightMapGenerator,
    offsetX: number,
    offsetY: number,
    size: number,
    resolution: number
  ): THREE.BufferGeometry {
    const vertices: number[] = [];
    const indices: number[] = [];
    const uvs: number[] = [];

    const step = size / resolution;

    for (let y = 0; y <= resolution; y++) {
      for (let x = 0; x <= resolution; x++) {
        const worldX = offsetX + x * step;
        const worldY = offsetY + y * step;
        const height = heightMap.getHeightInterpolated(worldX, worldY);

        vertices.push(worldX, height * 100, worldY);
        uvs.push(x / resolution, y / resolution);

        if (x < resolution && y < resolution) {
          const i = y * (resolution + 1) + x;
          indices.push(i, i + 1, i + resolution + 1);
          indices.push(i + 1, i + resolution + 2, i + resolution + 1);
        }
      }
    }

    const geometry = new THREE.BufferGeometry();
    geometry.setAttribute('position', new THREE.Float32BufferAttribute(vertices, 3));
    geometry.setAttribute('uv', new THREE.Float32BufferAttribute(uvs, 2));
    geometry.setIndex(indices);
    geometry.computeVertexNormals();
    return geometry;
  }

  setLOD(level: number): void {
    if (level !== this.currentLOD) {
      this.meshes[this.currentLOD].visible = false;
      this.meshes[level].visible = true;
      this.currentLOD = level;
    }
  }
}
```

## 3. 纹理混合

地形纹理根据高度和坡度自动混合。

```
高度-坡度纹理映射：

  高度
  ↑  ████ 雪地
  │  ████
  │  ▓▓▓▓ 岩石
  │  ▓▓▓▓
  │  ▒▒▒▒ 草地
  │  ▒▒▒▒
  │  ░░░░ 泥土/沙地
  └──────────────> 坡度
     平缓  陡峭

  陡峭处 → 岩石纹理（无论高度）
  平缓高处 → 雪地
  平缓中处 → 草地
  平缓低处 → 泥土/沙地
```

```glsl
// 地形纹理混合片段着色器
uniform sampler2D uGrassTexture;
uniform sampler2D uRockTexture;
uniform sampler2D uSnowTexture;
uniform sampler2D uDirtTexture;
uniform sampler2D uSandTexture;

uniform float uGrassHeight;
uniform float uRockHeight;
uniform float uSnowHeight;
uniform float uSlopeThreshold;

varying vec3 vWorldPos;
varying vec3 vNormal;
varying vec2 vUV;

// 三平面投影（避免拉伸）
vec3 triplanarMapping(sampler2D tex, vec3 worldPos, vec3 normal, float scale) {
    vec3 blend = abs(normal);
    blend = pow(blend, vec3(4.0));
    blend /= dot(blend, vec3(1.0));

    vec3 xProj = texture2D(tex, worldPos.yz * scale).rgb;
    vec3 yProj = texture2D(tex, worldPos.xz * scale).rgb;
    vec3 zProj = texture2D(tex, worldPos.xy * scale).rgb;

    return xProj * blend.x + yProj * blend.y + zProj * blend.z;
}

void main() {
    float height = vWorldPos.y;
    vec3 normal = normalize(vNormal);

    // 坡度计算（法线 y 分量越小越陡峭）
    float slope = 1.0 - normal.y;

    // 基础纹理采样（使用三平面投影避免 UV 拉伸）
    float texScale = 0.05;
    vec3 grass = triplanarMapping(uGrassTexture, vWorldPos, normal, texScale);
    vec3 rock = triplanarMapping(uRockTexture, vWorldPos, normal, texScale * 2.0);
    vec3 snow = triplanarMapping(uSnowTexture, vWorldPos, normal, texScale);
    vec3 dirt = triplanarMapping(uDirtTexture, vWorldPos, normal, texScale);
    vec3 sand = triplanarMapping(uSandTexture, vWorldPos, normal, texScale);

    // 基于高度的混合权重
    float grassWeight = smoothstep(uGrassHeight - 5.0, uGrassHeight + 5.0, height);
    float rockWeight = smoothstep(uRockHeight - 5.0, uRockHeight + 5.0, height);
    float snowWeight = smoothstep(uSnowHeight - 5.0, uSnowHeight + 5.0, height);

    // 基于坡度的混合
    float slopeRock = smoothstep(uSlopeThreshold - 0.1, uSlopeThreshold + 0.1, slope);

    // 混合逻辑：坡度优先
    vec3 color = dirt;  // 基础色
    color = mix(color, grass, grassWeight * (1.0 - slopeRock));
    color = mix(color, rock, max(rockWeight, slopeRock));
    color = mix(color, snow, snowWeight * (1.0 - slopeRock));

    gl_FragColor = vec4(color, 1.0);
}
```

## 4. 地形 Splatting

Splatting 使用 Alpha 贴图（Splat Map）控制多种纹理的混合区域。

```
Splat Map 原理：

  Splat Map（RGBA 通道）：
  R 通道 → 草地      G 通道 → 岩石
  ┌──────────┐      ┌──────────┐
  │ ████████ │      │          │
  │ ████████ │      │  ████████│
  │          │      │ ████████ │
  └──────────┘      └──────────┘

  B 通道 → 泥土      A 通道 → 雪地
  ┌──────────┐      ┌──────────┐
  │          │      │          │
  │  ████████│      │      ████│
  │ ████████ │      │     ████ │
  └──────────┘      └──────────┘

  最终颜色 = grass * R + rock * G + dirt * B + snow * A
  其中 R + G + B + A = 1（归一化）
```

```glsl
// Splatting 着色器
uniform sampler2D uSplatMap;
uniform sampler2D uTexture0; // 草地
uniform sampler2D uTexture1; // 岩石
uniform sampler2D uTexture2; // 泥土
uniform sampler2D uTexture3; // 雪地
uniform float uTextureScale;

varying vec2 vUV;

void main() {
    // 采样 Splat Map
    vec4 splat = texture2D(uSplatMap, vUV);

    // 归一化权重（确保总和为 1）
    float totalWeight = splat.r + splat.g + splat.b + splat.a;
    splat /= totalWeight;

    // 采样各层纹理（使用不同缩放避免重复感）
    vec2 scaledUV = vUV * uTextureScale;
    vec3 tex0 = texture2D(uTexture0, scaledUV).rgb;
    vec3 tex1 = texture2D(uTexture1, scaledUV * 0.7).rgb;
    vec3 tex2 = texture2D(uTexture2, scaledUV * 1.3).rgb;
    vec3 tex3 = texture2D(uTexture3, scaledUV * 0.9).rgb;

    // 混合
    vec3 color = tex0 * splat.r
               + tex1 * splat.g
               + tex2 * splat.b
               + tex3 * splat.a;

    gl_FragColor = vec4(color, 1.0);
}
```

## 5. 草地渲染（Instanced Billboard）

使用实例化渲染大量草地。

```
草地渲染策略：

  Instanced Billboard          Geometry Shader 草叶
  ┌──────────────────┐        ┌──────────────────┐
  │  │  │  │  │  │   │        │ ╱╲ ╱╲ ╱╲ ╱╲ ╱╲  │
  │  │  │  │  │  │   │        │╱  ╲╱  ╲╱  ╲╱  ╲ │
  │  │  │  │  │  │   │        │    │    │    │    │
  └──────────────────┘        └──────────────────┘
  简单，性能好                 复杂，效果好
  适合远距离                   适合近距离
```

```glsl
// 草地实例化顶点着色器
attribute vec3 aInstancePosition;
attribute float aInstanceRotation;
attribute float aInstanceScale;

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uTime;
uniform float uWindStrength;

varying vec2 vUV;
varying float vHeight;

void main() {
    vUV = uv;
    vHeight = position.y; // 草叶高度

    // 风力动画
    float wind = sin(uTime * 2.0 + aInstancePosition.x * 0.5 + aInstancePosition.z * 0.3);
    wind *= uWindStrength * vHeight; // 草叶越高受风影响越大

    // 旋转矩阵
    float c = cos(aInstanceRotation);
    float s = sin(aInstanceRotation);
    mat2 rot = mat2(c, -s, s, c);

    // 缩放
    vec3 pos = position * aInstanceScale;
    pos.xz = rot * pos.xz;

    // 风力偏移（只影响顶部）
    pos.x += wind * smoothstep(0.3, 1.0, vHeight);

    // 世界位置
    pos += aInstancePosition;

    gl_Position = uProjection * uView * vec4(pos, 1.0);
}
```

```typescript
// 草地实例化管理
class GrassRenderer {
  private instancedMesh: THREE.InstancedMesh;
  private instanceCount: number;

  constructor(terrain: GeoMipMapTerrain, density: number = 10) {
    // 草叶几何体
    const grassGeometry = new THREE.PlaneGeometry(0.3, 1.0, 1, 4);
    grassGeometry.translate(0, 0.5, 0); // 底部对齐原点

    // 计算实例数量
    const terrainSize = terrain.getSize();
    this.instanceCount = terrainSize * terrainSize * density;

    // 实例属性
    const positions = new Float32Array(this.instanceCount * 3);
    const rotations = new Float32Array(this.instanceCount);
    const scales = new Float32Array(this.instanceCount);

    let idx = 0;
    for (let i = 0; i < this.instanceCount; i++) {
      const x = Math.random() * terrainSize;
      const z = Math.random() * terrainSize;
      const y = terrain.getHeight(x, z);

      // 只在草地高度范围内生成
      if (y > 20 && y < 80 && terrain.getSlope(x, z) < 0.3) {
        positions[idx * 3] = x;
        positions[idx * 3 + 1] = y;
        positions[idx * 3 + 2] = z;
        rotations[idx] = Math.random() * Math.PI * 2;
        scales[idx] = 0.8 + Math.random() * 0.4;
        idx++;
      }
    }

    this.instanceCount = idx; // 实际有效实例数

    grassGeometry.setAttribute('aInstancePosition',
      new THREE.InstancedBufferAttribute(positions.slice(0, idx * 3), 3));
    grassGeometry.setAttribute('aInstanceRotation',
      new THREE.InstancedBufferAttribute(rotations.slice(0, idx), 1));
    grassGeometry.setAttribute('aInstanceScale',
      new THREE.InstancedBufferAttribute(scales.slice(0, idx), 1));

    this.instancedMesh = new THREE.InstancedMesh(
      grassGeometry, grassMaterial, this.instanceCount
    );
  }

  update(time: number, windStrength: number): void {
    (this.instancedMesh.material as THREE.ShaderMaterial)
      .uniforms.uTime.value = time;
    (this.instancedMesh.material as THREE.ShaderMaterial)
      .uniforms.uWindStrength.value = windStrength;
  }
}
```

## 6. 地形物理碰撞

```typescript
// 地形碰撞检测
class TerrainCollision {
  private heightMap: HeightMapGenerator;

  constructor(heightMap: HeightMapGenerator) {
    this.heightMap = heightMap;
  }

  // 获取指定位置的地形高度
  getHeightAt(worldX: number, worldZ: number): number {
    return this.heightMap.getHeightInterpolated(worldX, worldZ) * 100;
  }

  // 获取地形法线（用于坡度判断和物体放置）
  getNormalAt(worldX: number, worldZ: number): THREE.Vector3 {
    const delta = 1.0;
    const hL = this.getHeightAt(worldX - delta, worldZ);
    const hR = this.getHeightAt(worldX + delta, worldZ);
    const hD = this.getHeightAt(worldX, worldZ - delta);
    const hU = this.getHeightAt(worldX, worldZ + delta);

    const normal = new THREE.Vector3(
      hL - hR,
      2.0 * delta,
      hD - hU
    );
    return normal.normalize();
  }

  // 获取坡度（0=平坦, 1=垂直）
  getSlopeAt(worldX: number, worldZ: number): number {
    const normal = this.getNormalAt(worldX, worldZ);
    return 1.0 - normal.y;
  }

  // 角色与地形碰撞响应
  resolveCollision(
    position: THREE.Vector3,
    radius: number
  ): { position: THREE.Vector3; onGround: boolean; slope: number } {
    const terrainHeight = this.getHeightAt(position.x, position.z);
    const normal = this.getNormalAt(position.x, position.z);
    const slope = 1.0 - normal.y;

    const onGround = position.y - radius <= terrainHeight;

    if (onGround) {
      position.y = terrainHeight + radius;
    }

    return { position, onGround, slope };
  }
}
```

## 常见误区

1. **纹理拉伸**：在陡峭坡面上使用标准 UV 映射会导致纹理严重拉伸。应该使用三平面投影（Triplanar Mapping）或根据坡度切换纹理投影方式。

2. **LOD 切换跳变**：不同 LOD 级别之间的网格精度差异会导致明显的"跳变"。应该使用 Morphing（形态过渡）在 LOD 边界处平滑过渡。

3. **草地渲染不考虑遮挡**：大量草地实例会严重影响性能。应该使用视锥剔除、距离剔除和遮挡剔除，只渲染相机可见范围内的草地。

4. **高度图分辨率不足**：低分辨率高度图会导致地形出现明显的"阶梯"感。应该使用多层噪声叠加或高分辨率高度图，并在着色器中做法线插值。

---

## 工程建议

1. **Chunk 大小选择**：64x64 或 128x128 是地形 Chunk 的常用大小。太小会导致 Draw Call 过多，太大会导致 LOD 切换不灵活。

2. **纹理图集优化**：将所有地形纹理打包到一张纹理图集中，通过 UV 偏移选择不同纹理，减少材质切换。

3. **草地距离分级**：近处使用几何草叶（效果好），中距离使用 Billboard 草地（性能好），远处不渲染草地（使用纹理模拟）。

4. **物理碰撞简化**：地形物理碰撞不需要使用渲染用的高精度网格，可以使用 1/4 精度的高度图进行碰撞检测。

## 小结

### 练习一

**思路**：使用多层 Perlin 噪声叠加生成高度图。不同频率（octave）和振幅的噪声叠加可以产生从大尺度地形轮廓到小尺度细节的丰富地貌。使用 FBM（Fractal Brownian Motion）方法简化多层叠加。

**答案**：

```typescript
// Perlin 噪声高度图生成
class PerlinNoise {
    private permutation: number[];

    constructor(seed: number = 0) {
        // 初始化排列表
        this.permutation = [];
        for (let i = 0; i < 256; i++) this.permutation[i] = i;
        // Fisher-Yates 洗牌
        for (let i = 255; i > 0; i--) {
            const j = Math.floor(this.seededRandom(seed + i) * (i + 1));
            [this.permutation[i], this.permutation[j]] = [this.permutation[j], this.permutation[i]];
        }
        // 扩展到 512 避免溢出
        for (let i = 0; i < 256; i++) this.permutation[256 + i] = this.permutation[i];
    }

    private seededRandom(seed: number): number {
        const x = Math.sin(seed * 127.1) * 43758.5453;
        return x - Math.floor(x);
    }

    private fade(t: number): number {
        return t * t * t * (t * (t * 6 - 15) + 10);
    }

    private lerp(a: number, b: number, t: number): number {
        return a + t * (b - a);
    }

    private grad(hash: number, x: number, y: number): number {
        const h = hash & 3;
        const u = h < 2 ? x : y;
        const v = h < 2 ? y : x;
        return ((h & 1) === 0 ? u : -u) + ((h & 2) === 0 ? v : -v);
    }

    noise2D(x: number, y: number): number {
        const X = Math.floor(x) & 255;
        const Y = Math.floor(y) & 255;
        const xf = x - Math.floor(x);
        const yf = y - Math.floor(y);
        const u = this.fade(xf);
        const v = this.fade(yf);

        const p = this.permutation;
        const aa = p[p[X] + Y];
        const ab = p[p[X] + Y + 1];
        const ba = p[p[X + 1] + Y];
        const bb = p[p[X + 1] + Y + 1];

        return this.lerp(
            this.lerp(this.grad(aa, xf, yf), this.grad(ba, xf - 1, yf), u),
            this.lerp(this.grad(ab, xf, yf - 1), this.grad(bb, xf - 1, yf - 1), u),
            v
        );
    }
}

// FBM（分形布朗运动）生成高度图
function generateHeightMap(width: number, height: number): Float32Array {
    const noise = new PerlinNoise(42);
    const heightMap = new Float32Array(width * height);

    const octaves = 6;        // 噪声层数
    const persistence = 0.5;  // 振幅衰减
    const lacunarity = 2.0;   // 频率增长
    const baseScale = 0.005;  // 基础频率

    for (let y = 0; y < height; y++) {
        for (let x = 0; x < width; x++) {
            let amplitude = 1.0;
            let frequency = baseScale;
            let total = 0.0;
            let maxAmplitude = 0.0;

            for (let o = 0; o < octaves; o++) {
                total += noise.noise2D(x * frequency, y * frequency) * amplitude;
                maxAmplitude += amplitude;
                amplitude *= persistence;
                frequency *= lacunarity;
            }

            // 归一化到 [0, 1]
            heightMap[y * width + x] = (total / maxAmplitude + 1.0) * 0.5;
        }
    }

    return heightMap;
}
```

**要点**：
- FBM 通过叠加不同频率和振幅的噪声，产生从大山脉到小石块的多尺度细节
- `persistence` 控制细节丰富度（越大细节越多），`lacunarity` 控制频率增长速度
- 可以添加 domain warping（对输入坐标进行噪声偏移）产生更自然的扭曲地形

### 练习二

**思路**：GeoMipMap 将地形分成固定大小的块（Chunk），每个块根据与相机的距离选择不同精度的网格。远处的块使用更少的三角形，近处的块使用完整精度。关键挑战是块之间的裂缝处理。

**答案**：

```typescript
// GeoMipMap 地形 LOD 系统
class GeoMipMapTerrain {
    private chunks: TerrainChunk[][];
    private chunkSize: number;
    private lodLevels: number;

    constructor(heightMap: Float32Array, size: number, chunkSize: number = 16) {
        this.chunkSize = chunkSize;
        this.lodLevels = 4;
        this.chunks = [];

        const chunkCount = size / chunkSize;
        for (let cy = 0; cy < chunkCount; cy++) {
            this.chunks[cy] = [];
            for (let cx = 0; cx < chunkCount; cx++) {
                this.chunks[cy][cx] = new TerrainChunk(
                    heightMap, size, cx * chunkSize, cy * chunkSize, chunkSize
                );
            }
        }
    }

    updateLOD(cameraPos: THREE.Vector3): void {
        for (const row of this.chunks) {
            for (const chunk of row) {
                const dist = chunk.getDistanceTo(cameraPos);
                // 根据距离选择 LOD 级别
                if (dist < 20) {
                    chunk.setLOD(0); // 最高精度
                } else if (dist < 50) {
                    chunk.setLOD(1);
                } else if (dist < 100) {
                    chunk.setLOD(2);
                } else {
                    chunk.setLOD(3); // 最低精度
                }
            }
        }

        // 处理相邻块之间的 LOD 差异（裂缝修复）
        for (const row of this.chunks) {
            for (const chunk of row) {
                chunk.fixSeams(this.getNeighbors(chunk));
            }
        }
    }
}

class TerrainChunk {
    private meshes: THREE.Mesh[]; // 每个 LOD 级别一个 mesh
    private currentLOD: number;
    private worldX: number;
    private worldZ: number;

    constructor(
        heightMap: Float32Array, mapSize: number,
        startX: number, startZ: number, chunkSize: number
    ) {
        this.meshes = [];
        this.currentLOD = 0;
        this.worldX = startX;
        this.worldZ = startZ;

        // 生成 4 个 LOD 级别的 mesh
        for (let lod = 0; lod < 4; lod++) {
            const step = Math.pow(2, lod); // LOD 0: 每格1点, LOD 1: 每格2点...
            const mesh = this.generateLODMesh(heightMap, mapSize, startX, startZ, chunkSize, step);
            this.meshes.push(mesh);
        }
    }

    private generateLODMesh(
        heightMap: Float32Array, mapSize: number,
        startX: number, startZ: number, chunkSize: number, step: number
    ): THREE.Mesh {
        const resolution = chunkSize / step;
        const vertices: number[] = [];
        const indices: number[] = [];

        // 生成顶点
        for (let z = 0; z <= resolution; z++) {
            for (let x = 0; x <= resolution; x++) {
                const mapX = startX + x * step;
                const mapZ = startZ + z * step;
                const height = heightMap[mapZ * mapSize + mapX];

                vertices.push(mapX, height * 50, mapZ); // 50 = 高度缩放

                const i = z * (resolution + 1) + x;

                indices.push(i + 1, i + resolution + 1, i + resolution + 2);
```

### 练习三

**思路**：地形纹理混合基于高度和坡度两个因子：低处草地、高处岩石、最高处雪地；陡坡强制使用岩石纹理。使用 Splatting 技术将多张纹理按权重混合。

**答案**：

```glsl
// 地形纹理混合片段着色器
precision highp float;

uniform sampler2D uGrassTex;
uniform sampler2D uRockTex;
uniform sampler2D uSnowTex;
uniform sampler2D uHeightMap;

uniform float uGrassHeight;    // 草地最高高度，如 0.3
uniform float uRockHeight;     // 岩石开始高度，如 0.6
uniform float uSnowHeight;     // 雪地开始高度，如 0.85
uniform float uSlopeThreshold; // 坡度阈值，如 0.6

varying vec2 vUV;
varying vec3 vWorldPos;
varying vec3 vNormal;

void main() {
    float height = vWorldPos.y / 50.0; // 归一化高度
    vec3 normal = normalize(vNormal);

    // 坡度：法线与上方向的夹角
    float slope = 1.0 - normal.y; // 0=平坦, 1=垂直

    // 纹理坐标（世界空间投影，避免拉伸）
    vec2 texUV = vWorldPos.xz * 0.1;

    // 采样三张纹理
    vec3 grass = texture2D(uGrassTex, texUV * 2.0).rgb;
    vec3 rock = texture2D(uRockTex, texUV * 1.5).rgb;
    vec3 snow = texture2D(uSnowTex, texUV * 3.0).rgb;

    // 基于高度的权重
    float grassWeight = 1.0 - smoothstep(uGrassHeight - 0.05, uGrassHeight + 0.05, height);
    float rockWeight = smoothstep(uRockHeight - 0.1, uRockHeight + 0.1, height)
                     - smoothstep(uSnowHeight - 0.05, uSnowHeight + 0.05, height);
    float snowWeight = smoothstep(uSnowHeight - 0.05, uSnowHeight + 0.05, height);

    // 坡度修正：陡坡强制使用岩石
    float slopeFactor = smoothstep(uSlopeThreshold - 0.1, uSlopeThreshold + 0.1, slope);
    grassWeight *= (1.0 - slopeFactor);
    snowWeight *= (1.0 - slopeFactor);
    rockWeight = max(rockWeight, slopeFactor);

    // 归一化权重
    float totalWeight = grassWeight + rockWeight + snowWeight;
    grassWeight /= totalWeight;
    rockWeight /= totalWeight;
    snowWeight /= totalWeight;

    // 混合纹理
    vec3 color = grass * grassWeight + rock * rockWeight + snow * snowWeight;

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- 坡度通过法线的 Y 分量计算：`slope = 1 - N.y`，平坦地面 N.y ≈ 1
- 纹理使用世界空间 UV 投影（`vWorldPos.xz`），避免 UV 接缝和拉伸
- 权重归一化确保混合后的颜色亮度一致

### 练习四

**思路**：使用 InstancedMesh 渲染大量草叶 Billboard。每个实例是一个面片，通过 instance attribute 传递位置和随机参数。在顶点着色器中构建 Billboard 矩阵，并添加基于正弦函数的风力摆动动画。

**答案**：

```glsl
// 草地顶点着色器
precision highp float;

attribute vec3 aPosition;      // 面片顶点
attribute vec2 aUV;
attribute vec3 instancePos;    // 实例位置
attribute float instanceRotY;  // 随机旋转
attribute float instanceScale; // 随机缩放
attribute float instancePhase; // 风力动画相位

uniform mat4 uProjection;
uniform mat4 uView;
uniform float uTime;
uniform vec3 uWindDir;         // 风向
uniform float uWindStrength;   // 风力强度

varying vec2 vUV;
varying float vHeight; // 草叶高度（用于根部固定）

void main() {
    vUV = aUV;

    // 草叶高度因子（0=根部，1=顶部）
    float heightFactor = aUV.y;
    vHeight = heightFactor;

    // 绕 Y 轴随机旋转
    float cosR = cos(instanceRotY);
    float sinR = sin(instanceRotY);
    vec3 pos = aPosition;
    pos.xz = mat2(cosR, -sinR, sinR, cosR) * pos.xz;

    // 风力摆动（顶部摆动幅度大，根部不动）
    float windEffect = heightFactor * heightFactor; // 非线性：顶部更敏感
    float wind = sin(uTime * 2.0 + instancePhase + instancePos.x * 0.5) * uWindStrength;
    float wind2 = sin(uTime * 1.3 + instancePhase * 1.7 + instancePos.z * 0.3) * uWindStrength * 0.5;
    pos.x += (uWindDir.x * wind + wind2 * 0.3) * windEffect;
    pos.z += (uWindDir.z * wind + wind2 * 0.3) * windEffect;

    // 随机缩放
    pos *= instanceScale;

    // 世界空间位置
    vec3 worldPos = pos + instancePos;

    gl_Position = uProjection * uView * vec4(worldPos, 1.0);
}
```

```typescript
// 草地实例数据生成
function generateGrassInstances(
    heightMap: Float32Array, mapSize: number,
    count: number
): { positions: Float32Array, rotations: Float32Array, scales: Float32Array, phases: Float32Array } {
    const positions = new Float32Array(count * 3);
    const rotations = new Float32Array(count);
    const scales = new Float32Array(count);
    const phases = new Float32Array(count);

    for (let i = 0; i < count; i++) {
        // 随机位置（在地形范围内）
        const x = Math.random() * mapSize;
        const z = Math.random() * mapSize;
        const mapX = Math.floor(x);
        const mapZ = Math.floor(z);
        const height = heightMap[mapZ * mapSize + mapX] * 50; // 高度缩放

        // 只在低处（草地）生成
        if (height > 30) continue;

        positions[i * 3] = x;
        positions[i * 3 + 1] = height;
        positions[i * 3 + 2] = z;
        rotations[i] = Math.random() * Math.PI * 2;
        scales[i] = 0.8 + Math.random() * 0.4;
        phases[i] = Math.random() * Math.PI * 2;
    }

    return { positions, rotations, scales, phases };
}
```

**要点**：
- 风力摆动使用 `heightFactor²` 使顶部更敏感，根部几乎不动
- 多个不同频率和相位的正弦函数叠加产生自然的摆动效果
- 草叶密度可以通过调整实例数量和分布范围控制

### 练习五

**思路**：地形碰撞检测使用高度图查询：给定 XZ 坐标，从高度图中读取对应的高度值，与角色的 Y 坐标比较判断是否碰撞。坡度通过计算高度图梯度得到，用于调整角色移动速度。

**答案**：

```typescript
// 地形碰撞检测系统
class TerrainCollider {
    private heightMap: Float32Array;
    private mapSize: number;
    private heightScale: number;

    constructor(heightMap: Float32Array, mapSize: number, heightScale: number = 50) {
        this.heightMap = heightMap;
        this.mapSize = mapSize;
        this.heightScale = heightScale;
    }

    // 获取指定 XZ 坐标的地形高度（双线性插值）
    getHeight(worldX: number, worldZ: number): number {
        // 边界检查
        worldX = Math.max(0, Math.min(this.mapSize - 1, worldX));
        worldZ = Math.max(0, Math.min(this.mapSize - 1, worldZ));

        // 整数和小数部分
        const x0 = Math.floor(worldX);
        const z0 = Math.floor(worldZ);
        const x1 = Math.min(x0 + 1, this.mapSize - 1);
        const z1 = Math.min(z0 + 1, this.mapSize - 1);
        const fx = worldX - x0;
        const fz = worldZ - z0;

        // 双线性插值
        const h00 = this.heightMap[z0 * this.mapSize + x0];
        const h10 = this.heightMap[z0 * this.mapSize + x1];
        const h01 = this.heightMap[z1 * this.mapSize + x0];
        const h11 = this.heightMap[z1 * this.mapSize + x1];

        const h0 = h00 + (h10 - h00) * fx;
        const h1 = h01 + (h11 - h01) * fx;
        const height = h0 + (h1 - h0) * fz;

        return height * this.heightScale;
    }

    // 获取地形法线（通过高度梯度计算）
    getNormal(worldX: number, worldZ: number): THREE.Vector3 {
        const eps = 0.5;
        const hL = this.getHeight(worldX - eps, worldZ);
        const hR = this.getHeight(worldX + eps, worldZ);
        const hD = this.getHeight(worldX, worldZ - eps);
        const hU = this.getHeight(worldX, worldZ + eps);

        // 梯度 → 法线
        const normal = new THREE.Vector3(
            (hL - hR) / (2 * eps),
            1.0,
            (hD - hU) / (2 * eps)
        ).normalize();

        return normal;
    }

    // 获取坡度（0=平坦, 1=垂直）
    getSlope(worldX: number, worldZ: number): number {
        const normal = this.getNormal(worldX, worldZ);
        return 1.0 - normal.y;
    }

    // 碰撞响应：将角色吸附到地形表面
    resolveCollision(
        position: THREE.Vector3,
        velocity: THREE.Vector3
    ): { position: THREE.Vector3; onGround: boolean; slope: number } {
        const terrainHeight = this.getHeight(position.x, position.z);
        const slope = this.getSlope(position.x, position.z);

        const onGround = position.y <= terrainHeight + 0.1;

        if (onGround) {
            position.y = terrainHeight;

            // 坡度影响速度
            if (slope > 0.3) {
                // 陡坡减速
                const speedFactor = 1.0 - (slope - 0.3) * 2.0;
                velocity.multiplyScalar(Math.max(0.1, speedFactor));

                // 下坡加速，上坡减速
                const normal = this.getNormal(position.x, position.z);
                const downhillDir = new THREE.Vector3(normal.x, 0, normal.z).normalize();
                const moveDir = velocity.clone().normalize();
                const alignment = downhillDir.dot(moveDir);

                if (alignment > 0) {
                    // 下坡：加速
                    velocity.multiplyScalar(1.0 + alignment * 0.5);
                } else {
                    // 上坡：减速
                    velocity.multiplyScalar(1.0 + alignment * 0.3);
                }
            }

            // 极陡坡无法攀爬
            if (slope > 0.7) {
                velocity.set(0, velocity.y, 0);
            }
        }

        return { position, onGround, slope };
    }
}
```

**要点**：
- 双线性插值避免高度图离散采样导致的台阶感
- 坡度通过高度梯度计算：`slope = 1 - N.y`，其中 N 是地形法线
- 碰撞响应应考虑坡度对速度的影响：下坡加速、上坡减速、极陡坡无法攀爬
