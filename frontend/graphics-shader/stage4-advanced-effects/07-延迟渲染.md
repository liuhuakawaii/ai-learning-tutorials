# 延迟渲染

## 场景引入

当场景中有 100 个动态灯光时，前向渲染需要对每个物体执行 100 次光照计算，性能急剧下降。延迟渲染（Deferred Rendering）通过将几何信息和光照计算分离，使得光照成本仅与像素数量和灯光数量相关，而与场景复杂度无关。这种架构在《战地》系列、《毁灭战士》等大型游戏中被广泛使用。本节将从原理对比开始，深入讲解延迟渲染的完整实现。

## 学习目标

- 理解前向渲染与延迟渲染的架构差异
- 掌握 G-Buffer 的布局设计
- 学会 Deferred Lighting Pass 的实现
- 理解 Light Volumes 的优化方法
- 了解透明物体在延迟渲染中的处理
- 掌握 Tiled Deferred 的进阶方案

## 1. 前向 vs 延迟渲染对比

```
前向渲染 (Forward Rendering)：

  对每个物体：
    ┌──────────┐     ┌──────────┐     ┌──────────┐
    │ 物体1    │ ──> │ 顶点着色 │ ──> │ 光照计算 │ ──> 帧缓冲
    └──────────┘     └──────────┘     └──────────┘
    ┌──────────┐     ┌──────────┐     ┌──────────┐
    │ 物体2    │ ──> │ 顶点着色 │ ──> │ 光照计算 │ ──> 帧缓冲
    └──────────┘     └──────────┘     └──────────┘
    ...每个物体 × N 个光源

  复杂度：O(物体数 × 光源数)


延迟渲染 (Deferred Rendering)：

  Pass 1: Geometry Pass（写入 G-Buffer）
    ┌──────────┐     ┌──────────┐
    │ 物体1    │ ──> │ G-Buffer │
    └──────────┘     └──────────┘
    ┌──────────┐     ┌──────────┐
    │ 物体2    │ ──> │ G-Buffer │
    └──────────┘     └──────────┘

  Pass 2: Lighting Pass（逐像素光照）
    ┌──────────┐     ┌──────────┐     ┌──────────┐
    │ G-Buffer │ ──> │ 光源1    │ ──> │ 光源2... │ ──> 帧缓冲
    └──────────┘     └──────────┘     └──────────┘

  复杂度：O(物体数) + O(像素数 × 光源数)
```

```
对比表格：

  特性              前向渲染          延迟渲染
  ────────────────────────────────────────────────────
  多光源性能        差（线性增长）    好（独立计算）
  带宽消耗          低               高（G-Buffer 读写）
  透明物体          支持             需要特殊处理
  MSAA 支持        原生支持         需要额外处理
  内存占用          低               高（多个 RT）
  实现复杂度        简单             中等
  适用场景          光源少、透明多    光源多、不透明为主
```

## 2. G-Buffer 布局

G-Buffer（Geometry Buffer）存储每个像素的几何和材质信息。

```
典型 G-Buffer 布局（RGBA16F 格式）：

  RT0: Position (世界坐标)
  ┌──────┬──────┬──────┬──────┐
  │  R   │  G   │  B   │  A   │
  │ Pos.x│ Pos.y│ Pos.z│ -    │
  └──────┴──────┴──────┴──────┘

  RT1: Normal (世界空间法线)
  ┌──────┬──────┬──────┬──────┐
  │  R   │  G   │  B   │  A   │
  │ N.x  │ N.y  │ N.z  │ -    │
  └──────┴──────┴──────┴──────┘

  RT2: Albedo + AO
  ┌──────┬──────┬──────┬──────┐
  │  R   │  G   │  B   │  A   │
  │ Al.r │ Al.g │ Al.b │ AO   │
  └──────┴──────┴──────┴──────┘

  RT3: Metallic-Roughness + Emissive
  ┌──────┬──────┬──────┬──────┐
  │  R   │  G   │  B   │  A   │
  │Metal │Rough │Em.r  │Em.g  │
  └──────┴──────┴──────┴──────┘

  优化：将 Position 从深度重建，节省一个 RT
```

```glsl
// G-Buffer 写入（Geometry Pass 片段着色器）
#extension GL_EXT_draw_buffers : require

uniform vec3 uAlbedo;
uniform float uMetallic;
uniform float uRoughness;
uniform float uAO;
uniform vec3 uEmissive;

varying vec3 vWorldPos;
varying vec3 vNormal;
varying vec2 vUV;

void main() {
    // RT0: 世界坐标
    gl_FragData[0] = vec4(vWorldPos, 1.0);

    // RT1: 世界空间法线
    gl_FragData[1] = vec4(normalize(vNormal), 1.0);

    // RT2: Albedo + AO
    vec3 albedo = texture2D(uAlbedoMap, vUV).rgb * uAlbedo;
    gl_FragData[2] = vec4(albedo, uAO);

    // RT3: Metallic-Roughness + Emissive
    gl_FragData[3] = vec4(uMetallic, uRoughness, uEmissive.r, uEmissive.g);
}
```

## 3. Deferred Lighting Pass

在 Lighting Pass 中，读取 G-Buffer 信息，对每个光源计算光照。

```glsl
// Deferred Lighting 片段着色器
uniform sampler2D uPositionMap;
uniform sampler2D uNormalMap;
uniform sampler2D uAlbedoAOMap;
uniform sampler2D uMetalRoughEmissiveMap;

// 当前光源属性
uniform vec3 uLightPos;
uniform vec3 uLightColor;
uniform float uLightRadius;
uniform float uLightIntensity;
uniform vec3 uCameraPos;

varying vec2 vUV;

const float PI = 3.14159265359;

// PBR 函数（复用 PBR 课程中的实现）
float distributionGGX(vec3 N, vec3 H, float roughness);
float geometrySmith(vec3 N, vec3 V, vec3 L, float roughness);
vec3 fresnelSchlick(float cosTheta, vec3 F0);

void main() {
    // 从 G-Buffer 读取数据
    vec3 worldPos = texture2D(uPositionMap, vUV).rgb;
    vec3 normal = normalize(texture2D(uNormalMap, vUV).rgb);
    vec4 albedoAO = texture2D(uAlbedoAOMap, vUV);
    vec4 metalRoughEmissive = texture2D(uMetalRoughEmissiveMap, vUV);

    vec3 albedo = albedoAO.rgb;
    float ao = albedoAO.a;
    float metallic = metalRoughEmissive.r;
    float roughness = metalRoughEmissive.g;
    vec3 emissive = vec3(metalRoughEmissive.b, metalRoughEmissive.a, 0.0);

    // 如果该像素没有几何信息（天空），跳过
    if (length(normal) < 0.1) {
        gl_FragColor = vec4(0.0);
        return;
    }

    // 光照计算
    vec3 V = normalize(uCameraPos - worldPos);
    vec3 L = normalize(uLightPos - worldPos);
    vec3 H = normalize(V + L);

    float distance = length(uLightPos - worldPos);
    float attenuation = clamp(1.0 - pow(distance / uLightRadius, 4.0), 0.0, 1.0);
    attenuation = attenuation * attenuation / (distance * distance + 1.0);
    vec3 radiance = uLightColor * uLightIntensity * attenuation;

    // PBR 光照
    vec3 F0 = mix(vec3(0.04), albedo, metallic);
    float D = distributionGGX(normal, H, roughness);
    float G = geometrySmith(normal, V, L, roughness);
    vec3 F = fresnelSchlick(max(dot(H, V), 0.0), F0);

    vec3 kS = F;
    vec3 kD = (vec3(1.0) - kS) * (1.0 - metallic);

    float NdotL = max(dot(normal, L), 0.0);
    vec3 numerator = D * G * F;
    float denominator = 4.0 * max(dot(normal, V), 0.0) * NdotL + 0.001;
    vec3 specular = numerator / denominator;

    vec3 Lo = (kD * albedo / PI + specular) * radiance * NdotL;

    gl_FragColor = vec4(Lo + emissive, 1.0);
}
```

## 4. Light Volumes

Light Volumes 将光照计算限制在光源影响范围内，避免对全屏像素计算每个光源。

```
Light Volumes 原理：

  全屏光照（无优化）          Light Volumes
  ┌──────────────────┐      ┌──────────────────┐
  │ ● ● ● ● ● ● ● ● │      │     ·  ·  ·      │
  │ ● ● ● ● ● ● ● ● │      │   · ████████ ·    │
  │ ● ● ● ● ● ● ● ● │      │  · ████●█████ ·   │
  │ ● ● ● ● ● ● ● ● │      │   · ████████ ·    │
  │ ● ● ● ● ● ● ● ● │      │     ·  ·  ·      │
  └──────────────────┘      └──────────────────┘
  每个像素计算所有光源        只在光源体积内计算
  ● = 计算光照               ● = 光源位置
                              █ = 光照影响范围
```

```typescript
// Light Volume 渲染
class LightVolumeRenderer {
  private sphereGeometry: THREE.SphereGeometry;
  private coneGeometry: THREE.ConeGeometry;

  constructor() {
    this.sphereGeometry = new THREE.SphereGeometry(1, 16, 16);
    this.coneGeometry = new THREE.ConeGeometry(1, 1, 16);
  }

  renderPointLight(
    renderer: THREE.WebGLRenderer,
    light: PointLight,
    camera: THREE.Camera,
    gBufferTextures: GBufferTextures
  ): void {
    // 渲染一个球体，代表点光源的影响范围
    const material = new THREE.ShaderMaterial({
      uniforms: {
        uLightPos: { value: light.position },
        uLightColor: { value: light.color },
        uLightRadius: { value: light.radius },
        uLightIntensity: { value: light.intensity },
        uPositionMap: { value: gBufferTextures.position },
        uNormalMap: { value: gBufferTextures.normal },
        uAlbedoAOMap: { value: gBufferTextures.albedoAO },
        uMetalRoughMap: { value: gBufferTextures.metalRough },
        uCameraPos: { value: camera.position },
      },
      vertexShader: lightVolumeVertShader,
      fragmentShader: deferredLightingFragShader,
      // 关键设置
      side: THREE.BackSide,  // 渲染球体背面
      depthWrite: false,
      depthTest: false,
    });

    const mesh = new THREE.Mesh(this.sphereGeometry, material);
    mesh.scale.setScalar(light.radius);
    mesh.position.copy(light.position);
    renderer.render(mesh, camera);
  }
}
```

## 5. 透明物体处理

延迟渲染无法直接处理透明物体，因为透明物体需要混合而非覆盖。

```
透明物体处理方案：

  方案 1: 前向渲染混合
  ┌──────────────┐
  │ 延迟渲染 Pass │ ──> 不透明物体
  ├──────────────┤
  │ 前向渲染 Pass │ ──> 透明物体（混合到帧缓冲）
  └──────────────┘

  方案 2: 深度剥离（Depth Peeling）
  ┌──────────────┐
  │ Pass 0       │ ──> 最近层
  ├──────────────┤
  │ Pass 1       │ ──> 第二层（剥离最近层）
  ├──────────────┤
  │ Pass 2       │ ──> 第三层
  └──────────────┘
  从后往前混合

  方案 3: OIT（Order-Independent Transparency）
  使用 Per-Pixel Linked List 或 Moment-Based OIT
```

```typescript
// 混合渲染管线
class HybridRenderer {
  private deferredRenderer: DeferredRenderer;
  private forwardRenderer: ForwardRenderer;

  render(scene: THREE.Scene, camera: THREE.Camera): void {
    // 1. 分离不透明和透明物体
    const opaqueObjects: THREE.Object3D[] = [];
    const transparentObjects: THREE.Object3D[] = [];

    scene.traverse((obj) => {
      if (obj instanceof THREE.Mesh) {
        if ((obj.material as THREE.Material).transparent) {
          transparentObjects.push(obj);
        } else {
          opaqueObjects.push(obj);
        }
      }
    });

    // 2. 延迟渲染不透明物体
    this.deferredRenderer.render(opaqueObjects, camera);

    // 3. 前向渲染透明物体（叠加到延迟渲染结果上）
    this.forwardRenderer.render(transparentObjects, camera);
  }
}
```

## 6. Tiled Deferred

Tiled Deferred 将屏幕分成小块（Tile），每个 Tile 只计算影响该区域的光源。

```
Tiled Deferred 原理：

  屏幕分割（16x16 像素/Tile）：

  ┌───┬───┬───┬───┬───┬───┐
  │   │   │   │   │   │   │
  ├───┼───┼───┼───┼───┼───┤
  │   │ ● │ ● │   │   │   │  ● = 光源
  ├───┼───┼───┼───┼───┼───┤
  │   │ ● │   │ ○ │   │   │  ○ = 另一个光源
  ├───┼───┼───┼───┼───┼───┤
  │   │   │ ○ │ ○ │   │   │
  ├───┼───┼───┼───┼───┼───┤

  每个 Tile 的光源列表：
  Tile(1,1): [光源A]
  Tile(1,2): [光源A, 光源B]
  Tile(2,2): [光源B]
  Tile(3,2): [光源B]
```

```glsl
// Tiled Deferred - Compute Shader（WebGL2 使用纹理模拟）
// 步骤 1: 为每个 Tile 计算受影响的光源列表
// 使用共享内存存储 Tile 的光源列表

#define TILE_SIZE 16
#define MAX_LIGHTS_PER_TILE 64

shared uint tileLightCount;
shared uint tileLightIndices[MAX_LIGHTS_PER_TILE];

layout(local_size_x = TILE_SIZE, local_size_y = TILE_SIZE) in;
void main() {
    ivec2 tileCoord = ivec2(gl_WorkGroupID.xy);
    ivec2 pixelCoord = ivec2(gl_GlobalInvocationID.xy);

    if (gl_LocalInvocationIndex == 0u) {
        tileLightCount = 0u;
    }
    barrier();

    // 计算 Tile 的深度范围
    float minDepth = 1.0;
    float maxDepth = 0.0;
    // ... 读取 Tile 内所有像素深度，计算 min/max

    // 每个线程检查一个光源是否与 Tile 相交
    for (uint i = gl_LocalInvocationIndex; i < uLightCount; i += TILE_SIZE * TILE_SIZE) {
        vec3 lightPos = uLightPositions[i].xyz;
        float lightRadius = uLightPositions[i].w;

        // 光源与 Tile 的视锥体相交测试
        if (lightIntersectsTile(lightPos, lightRadius, tileCoord, minDepth, maxDepth)) {
            uint idx = atomicAdd(tileLightCount, 1u);
            if (idx < MAX_LIGHTS_PER_TILE) {
                tileLightIndices[idx] = i;
            }
        }
    }
    barrier();

    // 步骤 2: 使用 Tile 的光源列表计算光照
    vec2 uv = vec2(pixelCoord) / vec2(uResolution);
    vec3 worldPos = texture(uPositionMap, uv).rgb;
    vec3 normal = texture(uNormalMap, uv).rgb;
    // ... 其他 G-Buffer 数据

    vec3 Lo = vec3(0.0);
    for (uint i = 0u; i < tileLightCount; i++) {
        uint lightIdx = tileLightIndices[i];
        Lo += computeLight(lightIdx, worldPos, normal, ...);
    }

    imageStore(uOutput, pixelCoord, vec4(Lo, 1.0));
}
```

## 常见误区

1. **G-Buffer 格式浪费带宽**：使用 RGBA32F 存储所有 G-Buffer 会导致带宽消耗巨大。实际上 Position 可以从深度重建，Normal 可以用 Octahedron 编码压缩到 RG16F，Albedo 用 RGBA8 即可。

2. **Light Volume 渲染顺序错误**：Light Volume 应该使用加法混合（Additive Blending）叠加光照结果，如果使用默认的覆盖混合会丢失之前的光照计算。

3. **忽略 G-Buffer 的内存对齐**：GPU 对纹理采样有对齐要求，G-Buffer 的格式和通道分配应该考虑硬件对齐，避免浪费带宽。

4. **所有光源都用 Light Volume**：极远的环境光或全屏光源不需要 Light Volume，应该作为全屏 Pass 处理。只有局部光源（点光源、聚光灯）才使用 Light Volume。

---

## 工程建议

1. **G-Buffer 格式优化**：Position 从深度重建（节省 1 个 RT），Normal 使用球面坐标或 Octahedron 编码（压缩到 RG8），Metallic-Roughness 合并到一张纹理。

2. **带宽优化**：使用 `EXT_color_buffer_half_float` 扩展，G-Buffer 使用 RGBA16F 格式。移动端考虑使用 RGBA8 + 深度重建方案。

3. **混合渲染管线设计**：不透明物体走延迟渲染，透明物体走前向渲染。使用模板标记哪些像素需要前向渲染处理，避免全屏前向 Pass。

4. **性能监控**：监控 G-Buffer 的带宽消耗、Light Volume 的 Overdraw、每个 Tile 的光源数量。这些指标是延迟渲染优化的关键。

## 参考答案

### 练习一

**思路**：延迟渲染分为两个阶段：G-Buffer Pass（几何阶段）将场景的法线、深度、材质等信息写入多张纹理，Deferred Lighting Pass（光照阶段）读取 G-Buffer 信息计算光照。两个阶段解耦，使得光照计算与场景几何复杂度无关。

**答案**：

```typescript
// 基础延迟渲染管线
class DeferredRenderer {
    private gBuffer: THREE.WebGLRenderTarget;
    private lightPassMaterial: THREE.ShaderMaterial;

    constructor(width: number, height: number) {
        // G-Buffer：4 个 RenderTarget
        this.gBuffer = new THREE.WebGLRenderTarget(width, height, {
            count: 4,
            formats: [THREE.RGBAFormat, THREE.RGBAFormat, THREE.RGBAFormat, THREE.RGBAFormat],
            types: [THREE.UnsignedByteType, THREE.HalfFloatType, THREE.UnsignedByteType, THREE.UnsignedByteType],
        });

        // Deferred Lighting 材质
        this.lightPassMaterial = new THREE.ShaderMaterial({
            uniforms: {
                uAlbedoTex: { value: this.gBuffer.textures[0] },
                uNormalTex: { value: this.gBuffer.textures[1] },
                uDepthTex: { value: this.gBuffer.textures[2] },
                uMaterialTex: { value: this.gBuffer.textures[3] },
                uLightPositions: { value: [] },
                uLightColors: { value: [] },
                uCameraPos: { value: new THREE.Vector3() },
            },
            vertexShader: fullscreenVertexShader,
            fragmentShader: deferredLightingFragmentShader,
        });
    }
}
```

```glsl
// G-Buffer 写入片段着色器（几何阶段）
#extension GL_EXT_draw_buffers : require
precision highp float;

uniform vec3 uAlbedo;
uniform float uMetallic;
uniform float uRoughness;

varying vec3 vNormal;
varying vec3 vWorldPos;
varying vec2 vUV;

void main() {
    // RT0: Albedo (RGB) + AO (A)
    gl_FragData[0] = vec4(uAlbedo, 1.0);

    // RT1: World Normal (RGB) - 从 [-1,1] 映射到 [0,1]
    vec3 N = normalize(vNormal);
    gl_FragData[1] = vec4(N * 0.5 + 0.5, 1.0);

    // RT2: Depth (R) - 线性深度
    gl_FragData[2] = vec4(gl_FragCoord.z, 0.0, 0.0, 1.0);

    // RT3: Metallic (R) + Roughness (G)
    gl_FragData[3] = vec4(uMetallic, uRoughness, 0.0, 1.0);
}
```

```glsl
// Deferred Lighting 片段着色器（光照阶段）
precision highp float;

uniform sampler2D uAlbedoTex;
uniform sampler2D uNormalTex;
uniform sampler2D uDepthTex;
uniform sampler2D uMaterialTex;
uniform vec3 uLightPositions[16];
uniform vec3 uLightColors[16];
uniform int uLightCount;
uniform vec3 uCameraPos;
uniform mat4 uInvViewProj;

varying vec2 vUV;

void main() {
    // 读取 G-Buffer
    vec3 albedo = texture2D(uAlbedoTex, vUV).rgb;
    vec3 normal = texture2D(uNormalTex, vUV).rgb * 2.0 - 1.0;
    float depth = texture2D(uDepthTex, vUV).r;
    vec4 material = texture2D(uMaterialTex, vUV);
    float metallic = material.r;
    float roughness = material.g;

    // 重建世界坐标
    vec4 clipPos = vec4(vUV * 2.0 - 1.0, depth * 2.0 - 1.0, 1.0);
    vec4 worldPos = uInvViewProj * clipPos;
    vec3 fragPos = worldPos.xyz / worldPos.w;

    // PBR 光照计算（简化版）
    vec3 V = normalize(uCameraPos - fragPos);
    vec3 F0 = mix(vec3(0.04), albedo, metallic);
    vec3 Lo = vec3(0.0);

    for (int i = 0; i < 16; i++) {
        if (i >= uLightCount) break;

        vec3 L = normalize(uLightPositions[i] - fragPos);
        vec3 H = normalize(V + L);
        float dist = length(uLightPositions[i] - fragPos);
        vec3 radiance = uLightColors[i] / (dist * dist);

        float NdotL = max(dot(normal, L), 0.0);
        vec3 F = fresnelSchlick(max(dot(H, V), 0.0), F0);
        vec3 kD = (vec3(1.0) - F) * (1.0 - metallic);

        Lo += (kD * albedo / 3.14159 + F * 0.25) * radiance * NdotL;
    }

    vec3 ambient = vec3(0.03) * albedo;
    vec3 color = ambient + Lo;

    color = color / (color + vec3(1.0));
    color = pow(color, vec3(1.0 / 2.2));
    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- G-Buffer 使用 MRT（Multiple Render Targets）一次写入多张纹理
- 光照 Pass 是全屏四边形，逐像素读取 G-Buffer 并计算光照
- 延迟渲染的光源数量不影响几何复杂度，但光照计算量随光源数线性增长

### 练习二

**思路**：使用 4 个 RenderTarget 的 G-Buffer 布局，避免存储世界坐标（可以从深度重建）。RT0 存储 Albedo，RT1 存储法线，RT2 存储深度，RT3 存储材质参数。通过逆投影矩阵从深度重建世界坐标。

**答案**：

```glsl
// 4 RT G-Buffer 布局
// RT0: RGBA8  - Albedo(RGB) + AO(A)
// RT1: RGBA16F - World Normal(RGB) + Unused(A)
// RT2: D24S8  - Depth(24bit) + Stencil(8bit)
// RT3: RGBA8  - Metallic(R) + Roughness(G) + Emissive(B) + Unused(A)

// G-Buffer 写入
void main() {
    gl_FragData[0] = vec4(albedo, ao);
    gl_FragData[1] = vec4(normalize(vNormal) * 0.5 + 0.5, 1.0);
    // 深度由硬件自动写入，无需手动输出
    gl_FragData[2] = vec4(metallic, roughness, emissive, 1.0);
}
```

```glsl
// 从深度重建世界坐标

    vec4 worldPos = invViewProj * clipPos;
```

**要点**：
- 深度重建避免存储 worldPos（3 个 float），节省 G-Buffer 带宽
- 使用 `D24S8` 格式可以同时获得深度和模板缓冲，模板可用于标记透明物体

### 练习三

**思路**：Light Volume 将每个点光源渲染为一个球体几何体。球体的大小由光源的影响半径决定。在片段着色器中读取 G-Buffer 并计算该光源的贡献。只渲染相机在球体内部的面片（`BackFace` 剔除），避免重复计算。

**答案**：

```typescript
// Light Volume 渲染器
class LightVolumeRenderer {
    private sphereGeometry: THREE.SphereGeometry;
    private lightMaterial: THREE.ShaderMaterial;

    constructor() {
        this.sphereGeometry = new THREE.SphereGeometry(1, 16, 16);
        this.lightMaterial = new THREE.ShaderMaterial({
            uniforms: {
                uAlbedoTex: { value: null },
                uNormalTex: { value: null },
                uDepthTex: { value: null },
                uMaterialTex: { value: null },
                uLightPos: { value: new THREE.Vector3() },
                uLightColor: { value: new THREE.Color() },
                uLightRadius: { value: 10 },
                uCameraPos: { value: new THREE.Vector3() },
                uInvViewProj: { value: new THREE.Matrix4() },
            },
            vertexShader: lightVolumeVertexShader,
            fragmentShader: lightVolumeFragmentShader,
            side: THREE.BackSide, // 关键：只渲染背面
            depthWrite: false,
            depthTest: false,
            blending: THREE.AdditiveBlending,
        });
    }

    renderLight(renderer: THREE.WebGLRenderer, light: PointLight, camera: THREE.Camera): void {
        // 设置光源参数
        this.lightMaterial.uniforms.uLightPos.value.copy(light.position);
        this.lightMaterial.uniforms.uLightColor.value.copy(light.color);
        this.lightMaterial.uniforms.uLightRadius.value = light.radius;

        // 创建光源球体 mesh 并渲染
        const mesh = new THREE.Mesh(this.sphereGeometry, this.lightMaterial);
        mesh.position.copy(light.position);
        mesh.scale.setScalar(light.radius);

        renderer.render(mesh, camera);
    }

    renderAllLights(renderer: THREE.WebGLRenderer, lights: PointLight[], camera: THREE.Camera): void {
        for (const light of lights) {
            this.renderLight(renderer, light, camera);
        }
    }
```

```glsl
// Light Volume 片段着色器
precision highp float;

uniform sampler2D uAlbedoTex;
uniform sampler2D uNormalTex;
uniform sampler2D uDepthTex;
uniform sampler2D uMaterialTex;
uniform vec3 uLightPos;
uniform vec3 uLightColor;
uniform float uLightRadius;
uniform vec3 uCameraPos;
uniform mat4 uInvViewProj;

varying vec2 vUV;

void main() {
    // 读取 G-Buffer
    vec3 albedo = texture2D(uAlbedoTex, vUV).rgb;
    vec3 normal = texture2D(uNormalTex, vUV).rgb * 2.0 - 1.0;
    float depth = texture2D(uDepthTex, vUV).r;

    if (depth >= 1.0) discard; // 跳过天空

    // 重建世界坐标
    vec3 worldPos = reconstructWorldPos(vUV, depth, uInvViewProj);

    // 光照计算
    vec3 L = uLightPos - worldPos;
    float dist = length(L);
    L = normalize(L);

    // 距离衰减（物理反平方 + 平滑截断）
    float attenuation = 1.0 / (dist * dist + 1.0);
    float radiusFade = 1.0 - smoothstep(uLightRadius * 0.8, uLightRadius, dist);
    attenuation *= radiusFade;

    // PBR 光照（简化）
    vec3 V = normalize(uCameraPos - worldPos);
    vec3 H = normalize(V + L);
    float NdotL = max(dot(normal, L), 0.0);

    vec3 radiance = uLightColor * attenuation;
    vec3 color = albedo * radiance * NdotL;

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- Light Volume 使用 `BackSide` 渲染，当相机在球体内部时可以看到正面
- 距离衰减使用平滑截断（`smoothstep`），避免光源影响区域的硬边
- Additive Blending 累加多个光源的贡献，渲染顺序不影响结果

### 练习四

**思路**：延迟渲染不支持透明物体（因为 G-Buffer 只存储最近表面的信息）。解决方案：不透明物体走延迟渲染，透明物体走前向渲染。使用模板标记哪些像素需要前向处理。

**答案**：

```typescript
// 混合渲染管线
class HybridRenderer {
    private deferredRenderer: DeferredRenderer;
    private forwardRenderer: THREE.WebGLRenderer;

    render(
        renderer: THREE.WebGLRenderer,
        scene: THREE.Scene,
        camera: THREE.Camera,
        opaqueMeshes: THREE.Mesh[],
        transparentMeshes: THREE.Mesh[]
    ): void {
        // Pass 1: G-Buffer（仅不透明物体）
        renderer.setRenderTarget(this.deferredRenderer.gBuffer);
        renderer.clear();

        // 使用模板标记不透明像素
        renderer.state.buffers.stencil.setTest(true);
        renderer.state.buffers.stencil.setOp(
            THREE.ReplaceStencilOp,
            THREE.ReplaceStencilOp,
            THREE.ReplaceStencilOp
        );
        renderer.state.buffers.stencil.setFunc(THREE.AlwaysStencilFunc, 1, 0xff);

        for (const mesh of opaqueMeshes) {
            renderer.render(mesh, camera);
        }

        // Pass 2: Deferred Lighting（读取 G-Buffer）
        renderer.setRenderTarget(null);
        renderer.state.buffers.stencil.setFunc(THREE.EqualStencilFunc, 1, 0xff);
        this.deferredRenderer.renderLighting(renderer, camera);

        // Pass 3: 前向渲染透明物体
        renderer.state.buffers.stencil.setTest(false);
        renderer.sortObjects = true; // 透明物体需要按深度排序

        for (const mesh of transparentMeshes) {
            renderer.render(mesh, camera);
        }
    }
}
```

**要点**：
- 透明物体必须在延迟渲染之后渲染，否则会被 G-Buffer 覆盖
- 透明物体需要按深度从远到近排序（`sortObjects = true`）
- 模板测试可以避免对已渲染的不透明像素重复计算

### 练习五

**思路**：Tiled Deferred 将屏幕分成 16x16 的 Tile，每个 Tile 计算影响该区域的光源列表。使用 Compute Shader 或前缀和算法分配光源到 Tile，然后在光照阶段只遍历该 Tile 的有效光源，大幅减少光照计算量。

**答案**：

```glsl
// Tiled Deferred - 光源分配（Compute Shader 概念）
// 实际实现通常在 WebGL 2.0 Compute 或通过多 Pass 实现

// Tile 大小
const TILE_SIZE = 16;

struct TileLightList {
    int count;
    int lightIndices[64]; // 每个 Tile 最多 64 个光源
};

// Tile 屏幕分割逻辑（TypeScript 概念实现）
class TiledDeferred {
    private tileCountX: number;
    private tileCountY: number;
    private tileLightLists: Uint32Array;

    constructor(screenWidth: number, screenHeight: number) {
        this.tileCountX = Math.ceil(screenWidth / TILE_SIZE);
        this.tileCountY = Math.ceil(screenHeight / TILE_SIZE);
        this.tileLightLists = new Uint32Array(
            this.tileCountX * this.tileCountY * (1 + 64) // count + indices
        );
    }

    assignLights(
        lights: PointLight[],
        camera: THREE.Camera,
        invViewProj: THREE.Matrix4
    ): void {
        // 为每个 Tile 计算视锥体
        for (let ty = 0; ty < this.tileCountY; ty++) {
            for (let tx = 0; tx < this.tileCountX; tx++) {
                const tileIndex = ty * this.tileCountX + tx;
                const offset = tileIndex * (1 + 64);

                // Tile 在屏幕空间的边界
                const minX = tx * TILE_SIZE;
                const minY = ty * TILE_SIZE;
                const maxX = minX + TILE_SIZE;
                const maxY = minY + TILE_SIZE;

                // 将 Tile 边界变换到世界空间（近/远平面）
                const tileFrustum = this.computeTileFrustum(
                    minX, minY, maxX, maxY, invViewProj
                );

                // 测试每个光源是否与 Tile 视锥体相交
                let count = 0;
                for (let i = 0; i < lights.length && count < 64; i++) {
                    if (this.lightIntersectsTile(lights[i], tileFrustum)) {
                        this.tileLightLists[offset + 1 + count] = i;
                        count++;
                    }
                }
                this.tileLightLists[offset] = count;
            }
        }
    }

    private computeTileFrustum(
        minX: number, minY: number,
        maxX: number, maxY: number,
        invViewProj: THREE.Matrix4
    ): THREE.Frustum {
        // 将 Tile 的四个角点反投影到世界空间
        // 构建 Tile 的视锥体（6 个平面）
        // ... 省略具体实现
        return new THREE.Frustum();
    }

    private lightIntersectsTile(light: PointLight, frustum: THREE.Frustum): boolean {
        // 光源球体与 Tile 视锥体相交测试
        return frustum.intersectsSphere(
            new THREE.Sphere(light.position, light.radius)
        );
    }
}
```

```glsl
// Tiled Deferred 光照着色器（使用 Tile 光源列表）
uniform sampler2D uTileLightData; // 存储 Tile 光源列表的纹理
uniform int uTileCountX;

void main() {
    // 计算当前像素所属的 Tile
    ivec2 tileCoord = ivec2(gl_FragCoord.xy) / TILE_SIZE;
    int tileIndex = tileCoord.y * uTileCountX + tileCoord.x;

    // 读取该 Tile 的光源数量
    int lightCount = int(texelFetch(uTileLightData, ivec2(0, tileIndex), 0).r);

    // 只遍历该 Tile 的有效光源
    vec3 Lo = vec3(0.0);
    for (int i = 0; i < 64; i++) {
        if (i >= lightCount) break;

        int lightIndex = int(texelFetch(uTileLightData, ivec2(i + 1, tileIndex), 0).r);
        // 使用 lightIndex 计算光照 ...
        Lo += calculateLight(lightIndex, worldPos, normal, albedo);
    }
}
```

**要点**：
- Tiled Deferred 将光源分配从 O(pixels × lights) 降低到 O(pixels × lights_per_tile)
- Tile 视锥体由屏幕空间边界 + 深度范围定义，需要反投影到世界空间
- 光源数量上限（64/Tile）需要根据场景复杂度调整，溢出时可降级为全局遍历
