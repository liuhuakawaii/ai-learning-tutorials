# Stage 4：高级特效

掌握了 Shader 基础后，本阶段进入 3D 图形的进阶领域：后处理管线、粒子系统、PBR 物理渲染、程序化纹理、屏幕空间效果等。这些技术是高品质 3D 应用和游戏引擎的核心，也是创意编码的利器。

## 学习目标

- 掌握后处理管线的搭建方法，能实现 Bloom、色调映射等常见效果
- 理解 GPU 粒子系统的工作原理，能实现大规模粒子效果
- 掌握 Ray Marching 基础，能实现体积光和雾效
- 理解 PBR 渲染的物理基础，能配置和自定义 PBR 材质
- 能用分形和噪声算法生成程序化纹理
- 了解 SSAO/SSR 等屏幕空间效果的实现原理
- 初步掌握 Compute Shader 的使用场景和编写方法

## 阶段交付物

- **后处理效果库**：至少 3 个可组合的后处理效果（Bloom、色调映射、自定义滤镜）
- **GPU 粒子演示**：一个包含 10 万+ 粒子的高性能粒子系统
- **PBR 材质展示**：展示不同金属度/粗糙度/环境贴图组合的 PBR 材质球场景
- **验证通过**：运行 `npm run check` 通过 Stage 4 的高级特效验证
