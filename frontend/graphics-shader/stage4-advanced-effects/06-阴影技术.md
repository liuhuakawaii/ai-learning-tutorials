# 阴影技术

## 场景引入

没有阴影的 3D 场景看起来总是"飘"在空中——物体与地面的关系不明确，空间深度感缺失。阴影是连接物体与环境的视觉纽带，是营造真实感的最关键元素之一。从最基础的 Shadow Map 到级联阴影（CSM），阴影技术经历了数十年的发展。本节将系统讲解各种阴影技术的原理、问题和优化方法。

## 学习目标

- 掌握 Shadow Map 的基本原理（深度 Pass）
- 理解 Shadow Acne 和 Peter Panning 的成因与解决方案
- 学会 PCF 软阴影的实现
- 掌握 CSM（级联阴影映射）的架构
- 理解 VSM（Variance Shadow Map）的数学原理
- 掌握阴影系统的性能优化策略

## 1. Shadow Map 原理

Shadow Map 是最广泛使用的实时阴影技术，核心思想是从光源视角渲染深度图，然后在主渲染 Pass 中比较。

```
Shadow Map 原理：

  光源视角渲染              主渲染时比较
  ┌──────────────┐         ┌──────────────┐
  │   ░░░████    │         │              │
  │  ░░░██████   │         │  遮挡物       │
  │ ░░░░███████  │         │  ████████    │
  │░░░░░████████ │         │ ████████     │
  │ ░░░░███████  │         │              │
  │  ░░░██████   │         │  地面         │
  │   ░░░████    │         │ ──────────   │
  └──────────────┘         └──────────────┘
  深度图：░=近  █=远        片段深度 > Shadow Map → 阴影中

  判断逻辑：
  if (fragmentDepth > shadowMapDepth + bias) {
      // 在阴影中
  } else {
      // 被照亮
  }
```

```glsl
// Shadow Map 生成（光源视角的深度 Pass）
// 顶点着色器
uniform mat4 uLightViewMatrix;
uniform mat4 uLightProjectionMatrix;

varying vec4 vLightSpacePos;

void main() {
    vLightSpacePos = uLightProjectionMatrix * uLightViewMatrix * vec4(position, 1.0);
    gl_Position = vLightSpacePos;
}

// 片段着色器（只写深度）
void main() {
    gl_FragColor = vec4(gl_FragCoord.z, 0.0, 0.0, 1.0);
}
```

```glsl
// 主渲染 Pass 中采样 Shadow Map
uniform sampler2D uShadowMap;
uniform mat4 uLightSpaceMatrix;
uniform float uShadowBias;

varying vec3 vWorldPos;
varying vec3 vNormal;
varying vec3 vLightDir;

float shadowCalculation(vec3 worldPos, vec3 normal, vec3 lightDir) {
    // 变换到光源空间
    vec4 lightSpacePos = uLightSpaceMatrix * vec4(worldPos, 1.0);
    vec3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
    projCoords = projCoords * 0.5 + 0.5; // 映射到 0~1

    // 采样 Shadow Map
    float closestDepth = texture2D(uShadowMap, projCoords.xy).r;
    float currentDepth = projCoords.z;

    // 动态 Bias（根据法线与光线夹角调整）
    float bias = max(uShadowBias * (1.0 - dot(normal, lightDir)), uShadowBias * 0.1);

    // 阴影判断
    float shadow = currentDepth - bias > closestDepth ? 1.0 : 0.0;

    // 超出 Shadow Map 范围的区域不产生阴影
    if (projCoords.x < 0.0 || projCoords.x > 1.0 ||
        projCoords.y < 0.0 || projCoords.y > 1.0 ||
        projCoords.z > 1.0) {
        shadow = 0.0;
    }

    return shadow;
}
```

## 2. Shadow Acne 与 Peter Panning

```
Shadow Acne（阴影痤疮）：

  表面上出现条纹状伪影
  ┌──────────────────────┐
  │ ▓░▓░▓░▓░▓░▓░▓░▓░▓░▓ │  ← 明暗交替条纹
  │ ░▓░▓░▓░▓░▓░▓░▓░▓░▓░ │
  └──────────────────────┘

  原因：Shadow Map 精度有限，表面片段深度 ≈ Shadow Map 深度
        浮点精度误差导致交替判定为"在阴影中"和"被照亮"

  解决：添加 Bias（偏移量）
  shadow = currentDepth - bias > closestDepth ? 1.0 : 0.0


  Peter Panning（彼得·潘效应）：

  物体与阴影分离，阴影"飘"在空中
        ████████
        ████████  物体
         ↓
  ────────────────────── 地面
      ░░░░░░░░  阴影（偏移过大）
         ↑
       分离！

  原因：Bias 设置过大

  解决方案对比：
  ┌──────────────────┬──────────┬──────────┐
  │ 方案             │ 优点     │ 缺点     │
  ├──────────────────┼──────────┼──────────┤
  │ 固定 Bias        │ 简单     │ 不自适应 │
  │ 法线 Bias        │ 自适应   │ 计算开销 │
  │ Second Pass Bias │ 精确     │ 额外 Pass│
  │ 深度偏移         │ 简单     │ 可能漏光 │
  └──────────────────┴──────────┴──────────┘
```

```glsl
// 改进的 Bias 计算
float computeShadowBias(vec3 normal, vec3 lightDir, float baseBias) {
    // 基于法线与光线夹角的动态 Bias
    float cosTheta = dot(normal, lightDir);
    float bias = baseBias * tan(acos(cosTheta));
    bias = clamp(bias, 0.0, baseBias * 5.0);
    return bias;
}

// Slope-Scale Depth Bias（斜率缩放深度偏移）
float slopeScaleBias(vec3 normal, vec3 lightDir) {
    float slope = 1.0 - dot(normal, lightDir);
    return mix(0.001, 0.01, slope);
}
```

## 3. PCF 软阴影

PCF（Percentage Closer Filtering）通过在阴影边界多次采样并平均，产生柔和的阴影边缘。

```
PCF 采样模式：

  3x3 PCF                5x5 PCF              Poisson Disk
  ┌───┬───┬───┐          ┌─┬─┬─┬─┬─┐              ·
  │ · │ · │ · │          │·│·│·│·│·│           ·     ·
  ├───┼───┼───┤          ├─┼─┼─┼─┼─┤            ·   ·
  │ · │ · │ · │          │·│·│·│·│·│           ·  ·  ·
  ├───┼───┼───┤          ├─┼─┼─┼─┼─┤            ·   ·
  │ · │ · │ · │          │·│·│·│·│·│           ·     ·
  └───┴───┴───┘          └─┼─┼─┼─┼─┘              ·

  性能：9 次采样           25 次采样           16~32 次采样
```

```glsl
// PCF 软阴影实现
float shadowPCF(sampler2D shadowMap, vec3 projCoords, float bias) {
    float shadow = 0.0;
    vec2 texelSize = 1.0 / textureSize(shadowMap, 0);

    // 3x3 PCF
    for (int x = -1; x <= 1; x++) {
        for (int y = -1; y <= 1; y++) {
            vec2 offset = vec2(x, y) * texelSize;
            float closestDepth = texture2D(shadowMap, projCoords.xy + offset).r;
            shadow += projCoords.z - bias > closestDepth ? 1.0 : 0.0;
        }
    }

    return shadow / 9.0;
}

// Poisson Disk PCF（更自然的软阴影）
const vec2 poissonDisk[16] = vec2[](
    vec2(-0.94201624, -0.39906216),
    vec2(0.94558609, -0.76890725),
    vec2(-0.09418410, -0.92938870),
    vec2(0.34495938, 0.29387760),
    vec2(-0.91588581, 0.45771432),
    vec2(-0.81544232, -0.87912464),
    vec2(-0.38277543, 0.27676845),
    vec2(0.97484398, 0.75648379),
    vec2(0.44323325, -0.97511554),
    vec2(0.53742981, -0.47373420),
    vec2(-0.26496911, -0.41893023),
    vec2(0.79197514, 0.19090188),
    vec2(-0.24188840, 0.99706507),
    vec2(-0.81409955, 0.91437590),
    vec2(0.19984126, 0.78641367),
    vec2(0.14383161, -0.14100790)
);

float shadowPoisson(sampler2D shadowMap, vec3 projCoords, float bias) {
    float shadow = 0.0;
    float currentDepth = projCoords.z;
    vec2 texelSize = 1.0 / textureSize(shadowMap, 0);

    for (int i = 0; i < 16; i++) {
        float closestDepth = texture2D(shadowMap,
            projCoords.xy + poissonDisk[i] * texelSize * 2.0).r;
        shadow += currentDepth - bias > closestDepth ? 1.0 : 0.0;
    }

    return shadow / 16.0;
}
```

## 4. CSM（级联阴影映射）

CSM 将视锥体分成多个层级，每个层级使用独立的 Shadow Map，近处高精度、远处低精度。

```
CSM 原理：

  近        中        远
  ┌───┐    ┌───┐    ┌───┐
  │///│    │///│    │   │
  │///│    │///│    │   │  Shadow Map 分辨率
  │///│    │///│    │   │  近: 2048x2048
  └───┘    └───┘    └───┘  中: 1024x1024
  │ Cascade 0 │ C1  │ C2 │  远: 512x512
  │  0~20m    │20~80│80+ │

  视锥体分割：
  相机 *──────────────────────────────────>
       ├──────────┤
       │ Cascade 0│  高分辨率 Shadow Map
       ├──────────────┤
       │   Cascade 1  │  中分辨率 Shadow Map
       ├────────────────────────┤
       │      Cascade 2         │  低分辨率 Shadow Map
```

```typescript
  splits: number[];       // 分割距离 [20, 80, 300]
  resolutions: number[];  // 每级分辨率 [2048, 1024, 512]
}

class CascadedShadowMap {
  private cascades: Array<{
    camera: THREE.OrthographicCamera;
    renderTarget: THREE.WebGLRenderTarget;
    splitNear: number;
    splitFar: number;
  }>;

  constructor(config: CascadeConfig) {
    this.cascades = config.splits.map((far, i) => {
      const near = i === 0 ? 0.1 : config.splits[i - 1];
      const res = config.resolutions[i];

      return {
        camera: new THREE.OrthographicCamera(-50, 50, 50, -50, 0.1, 500),
        renderTarget: new THREE.WebGLRenderTarget(res, res, {
          format: THREE.DepthFormat,
          type: THREE.FloatType,
        }),
        splitNear: near,
        splitFar: far,
      };
    });
  }

  update(mainCamera: THREE.Camera, lightDirection: THREE.Vector3): void {
    for (const cascade of this.cascades) {
      // 计算当前级联的视锥体
      const frustum = this.computeFrustum(mainCamera, cascade.splitNear, cascade.splitFar);

      // 计算包围球
      const center = frustum.center;
      const radius = frustum.radius;

      // 正交投影相机覆盖包围球
      cascade.camera.position.copy(center).add(
        lightDirection.clone().multiplyScalar(radius)
      );
      cascade.camera.lookAt(center);
      cascade.camera.left = -radius;
      cascade.camera.right = radius;
      cascade.camera.top = radius;
      cascade.camera.bottom = -radius;
      cascade.camera.near = 0.1;
      cascade.camera.far = radius * 2;
      cascade.camera.updateProjectionMatrix();
    }
  }

  private computeFrustum(camera: THREE.Camera, near: number, far: number) {
    // 计算视锥体 8 个角点
    // ... 省略详细计算
    return { center: new THREE.Vector3(), radius: 50 };
  }

  selectCascade(depth: number): number {
    for (let i = 0; i < this.cascades.length; i++) {
```

## 5. VSM（Variance Shadow Map）

VSM 使用统计方法替代深度比较，天然支持硬件过滤实现软阴影。

```
VSM 原理：

  传统 Shadow Map          VSM
  存储：单深度值            存储：深度 和 深度²
  比较：step 函数           比较：切比雪夫不等式

  切比雪夫不等式：
  P(x ≥ t) ≤ σ² / (σ² + (t - μ)²)

  其中：
  μ = 平均深度（Shadow Map 第一通道）
  σ² = 方差（E[x²] - E[x]²）
  t = 当前片段深度

  优势：可以使用 Mipmap 和各向异性过滤
       一次采样即可获得柔和阴影
```

```glsl
// VSM 阴影计算
float chebyshevUpperBound(float depth, vec2 moments) {
    // moments.x = 平均深度 μ
    // moments.y = 深度平方的平均 E[x²]

    // 不在阴影中
    if (depth <= moments.x) return 1.0;

    // 计算方差
    float variance = moments.y - moments.x * moments.x;
    variance = max(variance, 0.00002); // 避免除零

    // 切比雪夫不等式
    float d = depth - moments.x;
    float pMax = variance / (variance + d * d);

    // 减轻 Light Bleeding
    pMax = smoothstep(0.2, 1.0, pMax);

    return pMax;
}

// VSM 生成 Pass（写入深度和深度²）
// 片段着色器
varying float vDepth;

void main() {
    float depth = vDepth;
    float depthSquared = depth * depth;

    // 两个通道分别存储
    gl_FragColor = vec4(depth, depthSquared, 0.0, 1.0);
}

// VSM 采样
float shadowVSM(sampler2D shadowMap, vec3 projCoords) {
    vec2 moments = texture2D(shadowMap, projCoords.xy).rg;
    return chebyshevUpperBound(projCoords.z, moments);
}
```

## 6. 阴影优化

```
阴影优化策略：

  ┌────────────────┬──────────────────────────────────────────┐
  │ 策略           │ 说明                                     │
  ├────────────────┼──────────────────────────────────────────┤
  │ 视锥剔除       │ 只渲染在光源视锥内的物体                 │
  │ 分辨率自适应   │ 近处高分辨率，远处低分辨率               │
  │ 纹理压缩       │ 使用 ETC2/BC 压缩 Shadow Map             │
  │ 级联混合       │ CSM 边界处平滑过渡避免明显接缝           │
  │ 深度预 Pass    │ 先渲染深度再渲染颜色，减少 Overdraw      │
  │ Shadow Cache   │ 静态物体的 Shadow Map 缓存不每帧重渲染   │
  │ 软阴影降级     │ 远处物体使用更少的 PCF 采样              │
  └────────────────┴──────────────────────────────────────────┘
```

```typescript
// 阴影优化管理器
class ShadowOptimizer {
  // 动态分辨率调整
  adjustShadowResolution(
    cascadeIndex: number,
    gpuTime: number,
    targetMs: number
  ): number {
    const baseRes = [2048, 1024, 512];
    const scale = gpuTime > targetMs ? 0.5 : 1.0;
    return Math.floor(baseRes[cascadeIndex] * scale);
  }

  // 静态物体缓存
  private staticShadowCache: Map<string, THREE.WebGLRenderTarget> = new Map();

  cacheStaticShadow(
    key: string,
    renderer: THREE.WebGLRenderer,
    scene: THREE.Scene,
    camera: THREE.Camera
  ): void {
    if (this.staticShadowCache.has(key)) return;

    const rt = new THREE.WebGLRenderTarget(1024, 1024);
    renderer.setRenderTarget(rt);
    renderer.render(scene, camera);
    renderer.setRenderTarget(null);

    this.staticShadowCache.set(key, rt);
  }

  // PCF 采样数自适应
  getPCFSamples(distance: number): number {
    if (distance < 20) return 16;
    if (distance < 50) return 9;
    return 4;
  }
}
```

## 常见误区

1. **Bias 设置不考虑场景尺度**：Bias 值与 Shadow Map 的分辨率和场景尺度相关。一个在小场景中合适的 Bias 值，在大场景中可能完全无效。应该根据场景包围盒和 Shadow Map 分辨率动态计算 Bias。

2. **PCF 采样范围固定**：固定大小的 PCF 采样在近距离看起来太硬，远距离看起来太软。应该根据片段到相机的距离调整 PCF 采样半径。

3. **CSM 级联边界硬切**：不同级联之间如果不做混合，会在边界处出现明显的阴影质量变化。应该在过渡区域同时采样两个级联并线性插值。

4. **VSM 的 Light Bleeding**：VSM 在深度差异较大时会出现"漏光"现象（亮区域被错误地标记为阴影中）。可以通过调整 `smoothstep` 的阈值缓解，但无法完全消除。

---

## 工程建议

1. **Shadow Map 分辨率选择**：角色渲染通常使用 2048x2048，场景使用 1024x1024。移动端可以降到 1024x1024 和 512x512。分辨率过高会导致内存占用过大，过低会出现明显锯齿。

2. **多光源阴影管理**：场景中有多个光源时，应该只为主光源生成高质量阴影，次级光源使用简化的阴影方案（如低分辨率 Shadow Map 或烘焙阴影）。

3. **阴影距离裁剪**：超出一定距离的物体不参与阴影计算。通常将阴影距离设为相机远裁剪面的 50%~70%，避免为极远处物体浪费 Shadow Map 空间。

4. **实时调试工具**：实现阴影调试可视化（显示级联分布、Shadow Map 深度、Bias 效果），在开发阶段快速定位问题。

### 练习一

**思路**：Shadow Map 的核心是两趟渲染：第一趟从光源视角渲染场景深度到 Shadow Map，第二趟在正常渲染时将片段变换到光源空间，比较片段深度与 Shadow Map 中存储的深度，判断是否在阴影中。

```glsl
// 顶点着色器
attribute vec3 aPosition;
uniform mat4 uLightViewProj;

void main() {
    gl_Position = uLightViewProj * vec4(aPosition, 1.0);
}
```

```glsl
// 片段着色器（深度 Pass）

void main() {
    // 输出线性深度
    gl_FragColor = vec4(gl_FragCoord.z, 0.0, 0.0, 1.0);
```

```glsl
// 阴影判断片段着色器（主渲染 Pass）
precision highp float;

uniform sampler2D uShadowMap;
uniform mat4 uLightViewProj;
uniform float uShadowBias;

varying vec3 vWorldPos;
varying vec3 vNormal;
varying vec3 vLightDir;

void main() {
    vec3 N = normalize(vNormal);
    vec3 L = normalize(vLightDir);

    // 将世界坐标变换到光源裁剪空间
    vec4 lightClipPos = uLightViewProj * vec4(vWorldPos, 1.0);

    // 透视除法，变换到 NDC [-1,1]，再映射到 [0,1]
    vec3 lightNDC = lightClipPos.xyz / lightClipPos.w;
    vec3 shadowUV = lightNDC * 0.5 + 0.5;

    // 采样 Shadow Map
    float shadowDepth = texture2D(uShadowMap, shadowUV.xy).r;
    float currentDepth = shadowUV.z;

    // 深度比较（带 Bias）
    float shadow = currentDepth - uShadowBias > shadowDepth ? 0.3 : 1.0;

    // Lambert 漫反射
    float NdotL = max(dot(N, L), 0.0);
    vec3 color = vec3(1.0, 0.3, 0.3) * NdotL * shadow;

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- Shadow Map 分辨率直接影响阴影质量，通常使用 1024x1024 或 2048x2048
- 阴影 Bias 必须存在，否则会出现 Shadow Acne（阴影条纹）
- 边界检查：UV 超出 [0,1] 范围的片段应视为不在阴影中

### 练习二

**思路**：PCF（Percentage-Closer Filtering）通过对 Shadow Map 进行多次采样并取平均值，实现软阴影效果。3x3 采样核在当前像素周围 9 个点采样深度，每次比较结果取平均，阴影边缘产生渐变。

**答案**：

```glsl
// PCF 软阴影片段着色器
precision highp float;

uniform sampler2D uShadowMap;
uniform vec2 uShadowMapSize;  // Shadow Map 分辨率

// 3x3 PCF 采样
float PCFShadow(vec3 shadowUV, float bias) {
    float shadow = 0.0;
    vec2 texelSize = 1.0 / uShadowMapSize;

    // 3x3 采样核
    for (int x = -1; x <= 1; x++) {
        for (int y = -1; y <= 1; y++) {
            vec2 offset = vec2(float(x), float(y)) * texelSize;
            float shadowDepth = texture2D(uShadowMap, shadowUV.xy + offset).r;
            float currentDepth = shadowUV.z;

            // 比较并累加
            shadow += currentDepth - bias > shadowDepth ? 0.0 : 1.0;
        }
    }

    // 取平均值（9 个采样点）
    shadow /= 9.0;

    return shadow;
}

void main() {
    // ... 变换到光源空间 ...
    vec3 shadowUV = lightClipPos.xyz / lightClipPos.w * 0.5 + 0.5;

    float shadow = PCFShadow(shadowUV, 0.005);

    vec3 color = ambient + diffuse * shadow;
    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- 采样核越大阴影越柔和，但性能开销线性增长（3x3=9次采样，5x5=25次）
- 使用 Poisson Disk 分布可以用更少采样点获得更均匀的软阴影效果
- PCF 的软阴影宽度固定，不会随物体距离变化（这是 PCSS 解决的问题）

### 练习三

**思路**：Shadow Acne 的根本原因是 Shadow Map 的离散采样精度不足。基于法线方向的动态 Bias 根据表面法线与光线方向的夹角调整 Bias 值：夹角越大（斜面），Bias 越大，因为斜面在 Shadow Map 中的深度变化更大。

**答案**：

```glsl
// 动态 Bias 片段着色器
precision highp float;

uniform sampler2D uShadowMap;
uniform float uBaseBias;       // 基础 Bias，如 0.001
uniform float uMaxBias;        // 最大 Bias，如 0.01
uniform vec3 uLightDir;

varying vec3 vWorldPos;
varying vec3 vNormal;

float calculateDynamicBias(vec3 normal, vec3 lightDir) {
    // 法线与光线方向的夹角
    float NdotL = max(dot(normal, lightDir), 0.0);

    // 夹角越大（斜面），Bias 越大
    // tan(acos(NdotL)) = sqrt(1 - NdotL²) / NdotL
    float cosTheta = NdotL;
    float tanTheta = sqrt(1.0 - cosTheta * cosTheta) / max(cosTheta, 0.001);

    // 动态 Bias = baseBias + 基于斜率的额外 Bias
    float bias = uBaseBias + tanTheta * uBaseBias * 2.0;
    bias = clamp(bias, uBaseBias, uMaxBias);

    return bias;
}

float shadowWithDynamicBias(vec3 shadowUV, vec3 normal, vec3 lightDir) {
    float bias = calculateDynamicBias(normal, lightDir);

    // 边界检查
    if (shadowUV.x < 0.0 || shadowUV.x > 1.0 ||
        shadowUV.y < 0.0 || shadowUV.y > 1.0 ||
        shadowUV.z > 1.0) {
        return 1.0;
    }

    float shadowDepth = texture2D(uShadowMap, shadowUV.xy).r;
    float currentDepth = shadowUV.z;

    return currentDepth - bias > shadowDepth ? 0.3 : 1.0;
}
```

**要点**：
- 固定 Bias 在斜面上不够用，在平面上又过大（导致 Peter Panning）
- 动态 Bias 基于 `tan(theta)` 计算斜面的深度梯度，自动调整 Bias 大小
- Bias 过大会导致阴影与物体分离（Peter Panning），过小会出现 Shadow Acne

### 练习四

**思路**：CSM（Cascaded Shadow Maps）将视锥体沿深度方向分为多个级联，每个级联使用独立的 Shadow Map。近处级联分辨率高（阴影质量好），远处级联分辨率低（覆盖范围大）。两级 CSM 将视锥体分为近/远两部分。

**答案**：

```typescript
// 两级 CSM 系统
class CascadedShadowMap {
    private nearShadowMap: THREE.WebGLRenderTarget;
    private farShadowMap: THREE.WebGLRenderTarget;
    private nearCamera: THREE.OrthographicCamera;
    private farCamera: THREE.OrthographicCamera;

    constructor(resolution: number = 2048) {
        this.nearShadowMap = new THREE.WebGLRenderTarget(resolution, resolution);
        this.farShadowMap = new THREE.WebGLRenderTarget(resolution / 2, resolution / 2);
        this.nearCamera = new THREE.OrthographicCamera();
        this.farCamera = new THREE.OrthographicCamera();
    }

    update(mainCamera: THREE.PerspectiveCamera, lightDirection: THREE.Vector3): void {
        const fov = mainCamera.fov * Math.PI / 180;
        const aspect = mainCamera.aspect;
        const near = mainCamera.near;
        const far = mainCamera.far;

        // 级联分割点
        const splitNear = near;
        const splitMid = near + (far - near) * 0.15;  // 近级联：前 15%
        const splitFar = far;

        // 计算每个级联的视锥体
        this.updateCascadeCamera(this.nearCamera, mainCamera, lightDirection, splitNear, splitMid, fov, aspect);
        this.updateCascadeCamera(this.farCamera, mainCamera, lightDirection, splitMid, splitFar, fov, aspect);
    }

    private updateCascadeCamera(
        cascadeCamera: THREE.OrthographicCamera,
        mainCamera: THREE.PerspectiveCamera,
        lightDir: THREE.Vector3,
        near: number, far: number,
        fov: number, aspect: number
    ): void {
        // 计算级联视锥体的 8 个角点
        const halfHeightNear = Math.tan(fov / 2) * near;
        const halfWidthNear = halfHeightNear * aspect;
        const halfHeightFar = Math.tan(fov / 2) * far;
        const halfWidthFar = halfHeightFar * aspect;

        const cameraPos = mainCamera.position;
        const cameraDir = new THREE.Vector3(0, 0, -1).applyQuaternion(mainCamera.quaternion);
        const cameraRight = new THREE.Vector3(1, 0, 0).applyQuaternion(mainCamera.quaternion);
        const cameraUp = new THREE.Vector3(0, 1, 0).applyQuaternion(mainCamera.quaternion);

        const nearCenter = cameraPos.clone().add(cameraDir.clone().multiplyScalar(near));
        const farCenter = cameraPos.clone().add(cameraDir.clone().multiplyScalar(far));

        const corners = [
            nearCenter.clone().add(cameraRight.clone().multiplyScalar(-halfWidthNear)).add(cameraUp.clone().multiplyScalar(-halfHeightNear)),
            nearCenter.clone().add(cameraRight.clone().multiplyScalar(halfWidthNear)).add(cameraUp.clone().multiplyScalar(-halfHeightNear)),
            nearCenter.clone().add(cameraRight.clone().multiplyScalar(halfWidthNear)).add(cameraUp.clone().multiplyScalar(halfHeightNear)),
            nearCenter.clone().add(cameraRight.clone().multiplyScalar(-halfWidthNear)).add(cameraUp.clone().multiplyScalar(halfHeightNear)),
            farCenter.clone().add(cameraRight.clone().multiplyScalar(-halfWidthFar)).add(cameraUp.clone().multiplyScalar(-halfHeightFar)),
            farCenter.clone().add(cameraRight.clone().multiplyScalar(halfWidthFar)).add(cameraUp.clone().multiplyScalar(-halfHeightFar)),
            farCenter.clone().add(cameraRight.clone().multiplyScalar(halfWidthFar)).add(cameraUp.clone().multiplyScalar(halfHeightFar)),
            farCenter.clone().add(cameraRight.clone().multiplyScalar(-halfWidthFar)).add(cameraUp.clone().multiplyScalar(halfHeightFar)),
        ];

        // 计算包围盒并设置正交相机
        const center = new THREE.Vector3();
        corners.forEach(c => center.add(c));
        center.divideScalar(8);

        cascadeCamera.position.copy(center).add(lightDir.clone().multiplyScalar(50));
        cascadeCamera.lookAt(center);
        cascadeCamera.updateProjectionMatrix();
    }
}
```

```glsl
// CSM 级联选择片段着色器
uniform sampler2D uShadowMapNear;
uniform sampler2D uShadowMapFar;
uniform mat4 uLightViewProjNear;
uniform mat4 uLightViewProjFar;
uniform float uSplitMid; // 级联分割点的线性深度

float getCSMShadow(vec3 worldPos, float linearDepth) {
    if (linearDepth < uSplitMid) {
        // 近级联
        vec4 lightPos = uLightViewProjNear * vec4(worldPos, 1.0);
        vec3 uv = lightPos.xyz / lightPos.w * 0.5 + 0.5;
        return PCFShadow(uShadowMapNear, uv, 0.002);
    } else {
        // 远级联
        vec4 lightPos = uLightViewProjFar * vec4(worldPos, 1.0);
        vec3 uv = lightPos.xyz / lightPos.w * 0.5 + 0.5;
        return PCFShadow(uShadowMapFar, uv, 0.005);
    }
}
```

**要点**：
- 级联分割点通常按指数分布（而非线性），近处分配更多深度范围
- 级联之间的过渡区域应平滑混合，避免可见的接缝线
- 每个级联的正交相机应紧密包围视锥体切片，最大化利用 Shadow Map 分辨率

### 练习五

**思路**：PCF 和 VSM 是两种不同的软阴影实现方式。PCF 通过多次采样取平均，VSM 通过存储深度的均值和方差，用概率论计算遮挡概率。对比两者在质量、性能、内存和实现复杂度上的差异。

**答案**：

```glsl
// VSM 方差阴影片段着色器
precision highp float;

uniform sampler2D uVSMTexture; // 存储 depth 和 depth²

float vsmShadow(vec3 shadowUV) {
    vec2 moments = texture2D(uVSMTexture, shadowUV.xy).rg;
    float depth = shadowUV.z;

    // Chebyshev 不等式
    float p = step(depth, moments.x); // 当前深度 <= 平均深度时为 1
    float variance = max(moments.y - moments.x * moments.x, 0.00002);

    float d = depth - moments.x;
    float pMax = variance / (variance + d * d);

    // 锐化
    pMax = smoothstep(0.2, 1.0, pMax);

    return max(p, pMax);
}
```

**PCF vs VSM 对比分析：**

```
+────────────────────+────────────────────+────────────────────+
|       特性         |        PCF         |        VSM         |
+────────────────────+────────────────────+────────────────────+
| 采样次数           | 9~25 次（3x3/5x5）| 1 次（双通道）     |
| GPU 开销           | 高（多次纹理采样）| 低（单次采样）     |
| 阴影质量           | 硬边 + 有限软边   | 自然软边           |
| 光渗（Light Bleed）| 无                 | 有（深场景明显）   |
| 内存               | 单通道深度         | 双通道（depth+depth²）|
| 可模糊性           | 不支持             | 支持高斯模糊       |
| 多光源扩展         | 每光源需独立 Map   | 每光源需独立 Map   |
| 实现复杂度         | 简单               | 中等               |
+────────────────────+────────────────────+────────────────────+
```

**分析：**
- PCF 的优势：实现简单，无光渗问题，适合需要精确阴影边界的场景
- PCF 的劣势：多次采样性能开销大，软阴影宽度固定
- VSM 的优势：单次采样性能好，支持模糊产生自然软边，适合大面积软阴影
- VSM 的劣势：光渗问题（深度差异大时亮区被错误遮挡），需要额外内存存储方差
- 实际选择：精确阴影用 PCF，大面积软阴影用 VSM，移动端考虑 EVSM（指数方差阴影）

**要点**：
- VSM 的核心是 Chebyshev 不等式：给定均值和方差，计算当前值大于某阈值的概率上界
- 光渗问题可以通过 EVSM（Exponential VSM）或 MSM（Moment Shadow Maps）缓解
- PCF 可以结合 PCSS（Percentage-Closer Soft Shadows）实现自适应阴影半径
