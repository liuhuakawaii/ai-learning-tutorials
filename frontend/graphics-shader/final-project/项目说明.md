# Shader 特效展示站 — 课程毕业项目

## 项目目标

构建一个 Shader 特效展示网站，包含至少 5 个不同类型的 Shader 效果，每个效果有独立的交互控制面板。项目覆盖图形学 Shader 课程中的核心知识：坐标变换、SDF、噪声、光照、后处理、Ray Marching 等。

## 技术栈

- **渲染**：WebGL 2.0 或 WebGPU
- **着色器语言**：GLSL 或 WGSL
- **前端框架**：React + TypeScript 或 Vue 3 + TypeScript
- **UI**：Tailwind CSS + 自定义控件
- **路由**：React Router 或 Vue Router
- **构建**：Vite
- **测试**：Vitest

## 核心功能

### 必选 Shader 效果（至少实现 5 个）

#### 效果一：2D SDF 场景

- 使用 SDF 绘制多个几何体（圆、矩形、三角形）
- 支持布尔运算（并集、交集、差集）
- 平滑混合（smooth union）
- 交互：鼠标控制某个物体的位置

#### 效果二：3D Ray Marching

- 使用 Ray Marching 渲染一个 3D 场景
- 至少包含 3 种 SDF 基元（球、盒子、圆环）
- 支持软阴影和环境光遮蔽
- 交互：鼠标控制摄像机旋转

#### 效果三：分形艺术

- Mandelbrot 或 Julia 集
- 支持缩放和平移探索
- 自定义颜色映射（色带）
- 交互：鼠标控制 Julia 集参数或 Mandelbrot 缩放

#### 效果四：Perlin 噪声纹理

- 实现 2D/3D Perlin 或 Simplex 噪声
- 支持 FBM（分形布朗运动）叠加
- 应用：云彩、大理石、地形高度图
- 交互：参数控制噪声频率、振幅、层数

#### 效果五：光照与材质

- Blinn-Phong 光照模型
- 多光源支持（点光源、方向光）
- 材质参数：漫反射、高光、粗糙度
- 交互：拖拽调整光源位置

#### 可选扩展效果（加分项）

- 水面折射/反射
- 粒子系统（GPU 驱动）
- 体积渲染（体积光、雾）
- 卡通着色（Cel Shading）
- 后处理链（Bloom、模糊、色彩校正）

### 展示站功能

- 首页：所有特效的缩略图网格
- 特效详情页：全屏 Shader 预览 + 参数面板
- 代码查看：点击可查看当前 Shader 的 GLSL/WGSL 源码
- 响应式布局，支持移动端

## 验收标准

- [ ] 至少有 5 个不同的 Shader 效果正常渲染
- [ ] 每个效果有独立的参数控制面板，参数变化实时生效
- [ ] Ray Marching 效果有软阴影和 AO
- [ ] 分形效果支持缩放探索
- [ ] 噪声效果支持 FBM 参数调节
- [ ] 首页能展示所有特效的缩略图
- [ ] 点击特效可进入详情页全屏预览
- [ ] 支持查看 Shader 源码
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
