# 顶点着色器深入

## 场景引入

上一课学习了 GLSL 基础语法，现在进入顶点着色器的世界。顶点着色器是渲染管线的第一个可编程阶段，它的核心任务是将模型的顶点从局部坐标系变换到屏幕坐标系。但这个看似简单的任务包含大量工程细节：变换矩阵的构造顺序、法线的正确变换方式、实例化渲染的实现、以及如何用顶点动画取代 CPU 端的骨骼计算。理解这些细节，是实现高效渲染的基础。

## 学习目标

1. 深入理解 MVP 变换矩阵的构造与应用
2. 掌握法线变换的数学原理（逆转置矩阵）
3. 实现实例化渲染与顶点动画
4. 理解逐顶点光照的计算方法与局限性

## 一、MVP 变换矩阵详解

### 1.1 变换流程

顶点从模型空间到屏幕空间的完整变换链：

```
局部坐标    模型矩阵     世界坐标    观察矩阵     相机坐标    投影矩阵     裁剪坐标    透视除法     NDC坐标
(Model)  ─────────→  (World)  ─────────→  (View)  ─────────→  (Clip)  ─────────→  (NDC)
  (x,y,z)            M_model              M_view              M_proj              (x/w, y/w, z/w)

NDC坐标     视口变换      屏幕坐标
(NDC)   ─────────→  (Screen)
(-1~1)              (像素)
```

### 1.2 MVP 矩阵构造

```glsl
// 顶点着色器
uniform mat4 uModelMatrix;      // 模型矩阵：局部 → 世界
uniform mat4 uViewMatrix;       // 观察矩阵：世界 → 相机
uniform mat4 uProjectionMatrix; // 投影矩阵：相机 → 裁剪

attribute vec3 aPosition;       // 顶点位置（局部坐标）
attribute vec3 aNormal;         // 顶点法线（局部坐标）

varying vec3 vWorldPos;         // 传递给片元着色器的世界坐标
varying vec3 vWorldNormal;      // 传递给片元着色器的世界法线

void main() {
    // 计算世界坐标
    vec4 worldPos = uModelMatrix * vec4(aPosition, 1.0);
    vWorldPos = worldPos.xyz;

    // 计算世界法线（使用逆转置矩阵）
    vWorldNormal = normalize(
        mat3(uModelMatrix) * aNormal  // 简化版：仅当模型矩阵无非均匀缩放时正确
    );

    // MVP 变换
    gl_Position = uProjectionMatrix * uViewMatrix * worldPos;
}
```

### 1.3 投影矩阵的两种类型

**透视投影**（近大远小）：

```typescript
// Three.js 中的透视投影矩阵构造
const projectionMatrix = new THREE.Matrix4();
projectionMatrix.makePerspective(
    -aspect * near * Math.tan(fov / 2),  // left
     aspect * near * Math.tan(fov / 2),  // right
     near * Math.tan(fov / 2),           // top
    -near * Math.tan(fov / 2),           // bottom
     near,                                // near
     far                                  // far
);
```

```
透视投影的视锥体：

        ┌─────────────────┐ far
       ╱                   ╲
      ╱                     ╲
     ╱                       ╲
    ╱                         ╲
   ╱            ◉ 相机          ╲
  ╱                               ╲
 └─────────────────────────────────┘ near
           ↑ 视角 (fov)
```

**正交投影**（无透视效果，用于 2D/UI）：

```typescript
const orthoMatrix = new THREE.Matrix4();
orthoMatrix.makeOrthographic(
    -width / 2,  width / 2,   // left, right
     height / 2, -height / 2, // top, bottom
     near, far
);
```

## 二、法线变换

### 2.1 为什么不能直接用模型矩阵变换法线？

当模型矩阵包含**非均匀缩放**时，直接用模型矩阵变换法线会导致法线方向错误：

```
非均匀缩放导致法线错误：

原始状态（均匀缩放）          非均匀缩放后（错误）
    ↑ 法线                      ↑ 法线（应倾斜）
    │                          ╱
    │                         ╱
┌───┴───┐                 ┌──╱─────┐
│       │                 │╱       │
│       │                 │        │
└───────┘                 └────────┘
    ↓ 法线                      ↓ 法线（应倾斜）

正确做法：使用逆转置矩阵变换法线
```

### 2.2 逆转置矩阵的计算

```glsl
// 正确的法线变换
uniform mat4 uModelMatrix;
uniform mat4 uNormalMatrix;  // = transpose(inverse(modelMatrix))，CPU 端预计算

void main() {
    vec3 worldNormal = normalize(uNormalMatrix.xyz * aNormal);

    // 或者在 Shader 中计算（不推荐，inverse 很昂贵）
    mat3 normalMat = transpose(inverse(mat3(uModelMatrix)));
    vec3 worldNormal = normalize(normalMat * aNormal);
}
```

**CPU 端预计算**（推荐）：

```typescript
// Three.js 中自动计算
const normalMatrix = new THREE.Matrix3();
normalMatrix.getNormalMatrix(modelMatrix);

// 手动计算
function computeNormalMatrix(modelMatrix: THREE.Matrix4): THREE.Matrix3 {
    const inv = new THREE.Matrix4().copy(modelMatrix).invert();
    const normalMat = new THREE.Matrix3().getNormalMatrix(modelMatrix);
    return normalMat;
}
```

## 三、实例化渲染

### 3.1 问题场景

渲染 10000 个相同的草叶模型，逐个调用 `drawArrays` 会产生 10000 次 Draw Call，CPU 开销巨大。实例化渲染允许一次 Draw Call 绘制所有实例。

### 3.2 使用 gl_InstanceID

```glsl
// 顶点着色器
attribute vec3 aPosition;
attribute vec3 aNormal;

// 实例化属性（每个实例独有的数据）
attribute vec3 aInstanceOffset;   // 每个实例的位置偏移
attribute float aInstanceScale;   // 每个实例的缩放
attribute float aInstanceRotation; // 每个实例的旋转角度

uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;

varying vec3 vNormal;
varying vec3 vWorldPos;

mat3 rotateY(float angle) {
    float s = sin(angle);
    float c = cos(angle);
    return mat3(
        c, 0.0, s,
        0.0, 1.0, 0.0,
       -s, 0.0, c
    );
}

void main() {
    // 应用实例变换
    mat3 rotation = rotateY(aInstanceRotation);
    vec3 localPos = rotation * aPosition * aInstanceScale + aInstanceOffset;

    vNormal = rotation * aNormal;
    vWorldPos = localPos;

    gl_Position = uProjectionMatrix * uViewMatrix * vec4(localPos, 1.0);
}
```

**TypeScript 端设置**：

```typescript
// Three.js 实例化渲染设置
const geometry = new THREE.InstancedBufferGeometry();
geometry.copy(baseGeometry);

// 实例化属性
const offsets = new Float32Array(instanceCount * 3);
const scales = new Float32Array(instanceCount);
const rotations = new Float32Array(instanceCount);

for (let i = 0; i < instanceCount; i++) {
    offsets[i * 3] = Math.random() * 100 - 50;
    offsets[i * 3 + 1] = 0;
    offsets[i * 3 + 2] = Math.random() * 100 - 50;
    scales[i] = 0.5 + Math.random() * 1.5;
    rotations[i] = Math.random() * Math.PI * 2;
}

geometry.setAttribute('aInstanceOffset',
    new THREE.InstancedBufferAttribute(offsets, 3));
geometry.setAttribute('aInstanceScale',
    new THREE.InstancedBufferAttribute(scales, 1));
geometry.setAttribute('aInstanceRotation',
    new THREE.InstancedBufferAttribute(rotations, 1));

const mesh = new THREE.Mesh(geometry, material);
mesh.instanceCount = instanceCount;
```

### 3.3 gl_InstanceID 内建变量

```glsl
// 使用 gl_InstanceID 计算实例属性（无需额外 Buffer）
void main() {
    float id = float(gl_InstanceID);
    float row = floor(id / 100.0);
    float col = mod(id, 100.0);

    vec3 offset = vec3(
        (col - 50.0) * 2.0,
        0.0,
        (row - 50.0) * 2.0
    );

    vec3 localPos = aPosition + offset;
    gl_Position = uProjectionMatrix * uViewMatrix * vec4(localPos, 1.0);
}
```

## 四、顶点动画

### 4.1 波浪效果

将动画计算从 CPU 移到 GPU，大幅减少数据传输：

```glsl
uniform float uTime;
uniform float uWaveHeight;
uniform float uWaveFrequency;
uniform float uWaveSpeed;

void main() {
    vec3 pos = aPosition;

    // 多层波浪叠加
    float wave1 = sin(pos.x * uWaveFrequency + uTime * uWaveSpeed) * uWaveHeight;
    float wave2 = sin(pos.z * uWaveFrequency * 0.7 + uTime * uWaveSpeed * 1.3) * uWaveHeight * 0.5;
    float wave3 = sin((pos.x + pos.z) * uWaveFrequency * 0.5 + uTime * uWaveSpeed * 0.8) * uWaveHeight * 0.3;

    pos.y += wave1 + wave2 + wave3;

    // 法线需要重新计算（使用偏导数）
    float dx = cos(pos.x * uWaveFrequency + uTime * uWaveSpeed) * uWaveHeight * uWaveFrequency;
    float dz = cos(pos.z * uWaveFrequency * 0.7 + uTime * uWaveSpeed * 1.3) * uWaveHeight * 0.5 * uWaveFrequency * 0.7;
    vec3 normal = normalize(vec3(-dx, 1.0, -dz));

    vNormal = normal;
    vWorldPos = pos;
    gl_Position = uProjectionMatrix * uViewMatrix * vec4(pos, 1.0);
}
```

### 4.2 草地摆动动画

```glsl
uniform float uTime;
uniform float uWindStrength;
uniform vec2 uWindDirection;

void main() {
    vec3 pos = aPosition;

    // 使用顶点高度控制摆动幅度（底部不动，顶部摆动最大）
    float heightFactor = smoothstep(0.0, 1.0, pos.y);

    // 风向摆动
    float windPhase = dot(pos.xz, uWindDirection) * 0.5 + uTime * 2.0;
    float windOffset = sin(windPhase) * uWindStrength * heightFactor;

    // 加入高频扰动，模拟阵风
    float gust = sin(uTime * 5.0 + pos.x * 10.0) * 0.3 * heightFactor;

    pos.x += windOffset + gust;
    pos.z += windOffset * 0.5;

    gl_Position = uProjectionMatrix * uViewMatrix * vec4(pos, 1.0);
}
```

## 五、逐顶点光照

### 5.1 Lambert 光照模型

```glsl
uniform vec3 uLightDir;      // 光源方向（世界空间，指向光源）
uniform vec3 uLightColor;    // 光源颜色
uniform vec3 uAmbientColor;  // 环境光颜色

varying vec3 vColor;         // 传递给片元着色器的颜色

void main() {
    vec3 worldNormal = normalize(mat3(uModelMatrix) * aNormal);
    vec3 lightDir = normalize(uLightDir);

    // Lambert 漫反射
    float NdotL = max(dot(worldNormal, lightDir), 0.0);

    // 最终颜色 = 环境光 + 漫反射
    vec3 color = uAmbientColor + uLightColor * NdotL;

    vColor = color;
    gl_Position = uProjectionMatrix * uViewMatrix * uModelMatrix * vec4(aPosition, 1.0);
}
```

### 5.2 逐顶点 vs 逐片元光照

```
逐顶点光照：                        逐片元光照：
在顶点着色器中计算颜色               在片元着色器中计算颜色
通过 varying 插值传递给片元           每个像素独立计算

优点：计算量小（顶点数 << 像素数）     优点：精度高，效果好
缺点：高光等细节丢失                   缺点：计算量大

     逐顶点（Gouraud 着色）              逐片元（Phong 着色）
    ┌─────────────────┐              ┌─────────────────┐
    │  ●───────●      │              │  ●───────●      │
    │  │       │      │              │  │ * * * │      │
    │  │  颜色  │      │              │  │* 高光 *│      │
    │  │  插值  │      │              │  │ * * * │      │
    │  ●───────●      │              │  ●───────●      │
    └─────────────────┘              └─────────────────┘
    高光可能完全丢失                    高光清晰锐利
```

## 常见误区

1. **法线变换错误**：在有非均匀缩放的模型上直接用 `mat3(modelMatrix) * normal` 会导致法线方向错误。必须使用逆转置矩阵。

2. **gl_Position 必须赋值**：顶点着色器的核心职责是计算 `gl_Position`。忘记赋值会导致渲染结果未定义。

3. **w 分量的重要性**：`gl_Position = vec4(pos, 1.0);` 中的 `1.0` 很关键。设为 `0.0` 会将顶点视为方向向量，导致透视投影失效。

4. **varying 变量的插值**：顶点着色器输出的 varying 变量会在光栅化阶段自动插值。不要在顶点着色器中做逐像素的计算，那是片元着色器的工作。

---

## 工程建议

1. **预计算变换矩阵**：逆转置矩阵、MVP 矩阵等应在 CPU 端预计算，通过 Uniform 传入 Shader。避免在 Shader 中做 `inverse` 运算。

2. **实例化渲染优先**：渲染大量相同物体时，始终使用实例化渲染。Three.js 中使用 `InstancedMesh`，原生 WebGL 使用 `drawArraysInstanced`。

3. **顶点动画的法线问题**：使用顶点动画时，法线必须随顶点位移同步更新。可以通过解析求导（如波浪的偏导数）或有限差分法近似计算。

4. **减少 varying 数量**：每个 varying 变量都会占用插值器资源。只传递片元着色器真正需要的数据，能合并的就合并。

## 参考答案

### 练习一

**思路**：水面 Shader 的核心是多层正弦波叠加（FBM 思想），每层用不同频率和振幅模拟不同尺度的波浪。变形后法线的计算是关键——不能直接用原始法线，需要对叠加后的高度场求偏导数来得到正确的法线方向。

**答案**：
```glsl
// 水面 - 顶点着色器
precision mediump float;

uniform mat4 uModelMatrix;
uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;
uniform float uTime;

attribute vec3 aPosition;

varying vec3 vWorldPos;
varying vec3 vNormal;

// 单层波浪的偏导数，返回 (高度, dH/dx, dH/dz)
vec3 waveLayer(vec2 pos, float frequency, float amplitude, float speed, vec2 direction) {
    float phase = dot(normalize(direction), pos) * frequency + uTime * speed;
    return vec3(
        sin(phase) * amplitude,                          // 高度
        cos(phase) * normalize(direction).x * frequency * amplitude,  // dH/dx
        cos(phase) * normalize(direction).y * frequency * amplitude   // dH/dz
    );
}

void main() {
    vec3 pos = aPosition;

    // 三层波浪叠加
    vec3 w1 = waveLayer(pos.xz, 2.0, 0.15, 1.0, vec2(1.0, 0.0));
    vec3 w2 = waveLayer(pos.xz, 4.0, 0.08, 1.5, vec2(0.7, 0.7));
    vec3 w3 = waveLayer(pos.xz, 8.0, 0.03, 2.5, vec2(-0.3, 1.0));

    float totalHeight = w1.x + w2.x + w3.x;
    pos.y += totalHeight;

    // 从偏导数计算变形后的法线
    float dhdx = w1.y + w2.y + w3.y;
    float dhdz = w1.z + w2.z + w3.z;
    vec3 normal = normalize(vec3(-dhdx, 1.0, -dhdz));

    vec4 worldPos = uModelMatrix * vec4(pos, 1.0);
    vWorldPos = worldPos.xyz;
    vNormal = normalize(mat3(uModelMatrix) * normal);

    gl_Position = uProjectionMatrix * uViewMatrix * worldPos;
}
```

```glsl
// 水面 - 片元着色器
precision mediump float;

uniform vec3 uCameraPos;
uniform vec3 uLightDir;
uniform vec3 uWaterColor;

varying vec3 vWorldPos;
varying vec3 vNormal;

void main() {
    vec3 normal = normalize(vNormal);
    vec3 viewDir = normalize(uCameraPos - vWorldPos);
    vec3 lightDir = normalize(uLightDir);

    // Phong 光照
    float diffuse = max(dot(normal, lightDir), 0.0);
    vec3 reflectDir = reflect(-lightDir, normal);
    float specular = pow(max(dot(viewDir, reflectDir), 0.0), 64.0);

    // Fresnel
    float fresnel = pow(1.0 - max(dot(normal, viewDir), 0.0), 3.0);

    vec3 color = uWaterColor * (0.3 + diffuse * 0.5);
    color += vec3(1.0) * specular * 0.8;
    color += vec3(0.5, 0.7, 1.0) * fresnel * 0.3;

    gl_FragColor = vec4(color, 0.85);
}
```

**要点**：
- 多层波浪叠加时，每层的 `direction` 应不同，否则波浪方向一致会显得不自然
- 法线通过偏导数 `(-dH/dx, 1.0, -dH/dz)` 计算，这是梯度法线的标准公式
- 频率越高、振幅越小的波浪代表细节涟漪，低频高振幅代表大浪

### 练习二

**思路**：实例化渲染的核心是用一次 `drawArraysInstanced` 调用绘制所有实例，每个实例的变换矩阵通过 `gl_InstanceID` 从实例属性数组中获取。关键是在每个实例的 Attribute 中存储位置、旋转和缩放数据。

**答案**：
```typescript
// TypeScript / Three.js 实例化渲染实现
import * as THREE from 'three';

const instanceCount = 10000;

// 创建 InstancedMesh
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x4488ff });
const mesh = new THREE.InstancedMesh(geometry, material, instanceCount);

const dummy = new THREE.Object3D();
const positions: number[] = [];
const rotations: number[] = [];
const scales: number[] = [];

// 初始化每个实例的属性
for (let i = 0; i < instanceCount; i++) {
    positions.push(
        (Math.random() - 0.5) * 100,
        (Math.random() - 0.5) * 100,
        (Math.random() - 0.5) * 100
    );
    rotations.push(Math.random() * Math.PI * 2);
    scales.push(0.5 + Math.random() * 1.5);
}

// 每帧更新实例矩阵
function updateInstances(time: number) {
    for (let i = 0; i < instanceCount; i++) {
        dummy.position.set(positions[i * 3], positions[i * 3 + 1], positions[i * 3 + 2]);
        dummy.rotation.set(
            rotations[i] + time * 0.5,
            rotations[i] * 1.3 + time * 0.3,
            0
        );
        const s = scales[i];
        dummy.scale.set(s, s, s);
        dummy.updateMatrix();
        mesh.setMatrixAt(i, dummy.matrix);
    }
    mesh.instanceMatrix.needsUpdate = true;
}

// 原生 WebGL2 版本的核心代码（概念）
// 1. 创建实例属性 VBO（位置、旋转、缩放）
// 2. 使用 gl.vertexAttribDivisor(location, 1) 让每个实例读取一次
// 3. 调用 gl.drawArraysInstanced(gl.TRIANGLES, 0, vertexCount, instanceCount)
```

**要点**：
- `InstancedMesh` 内部使用 `drawArraysInstanced`，一次调用绘制所有实例
- `gl_InstanceID` 是内建变量，片元/顶点着色器可用它区分不同实例
- 性能差异：10000 个独立 draw call vs 1 个 instanced draw call，帧率可能从 5fps 提升到 60fps
- `instanceMatrix.needsUpdate = true` 每帧都要设置，否则不会上传新数据

### 练习三

**思路**：骨骼动画的核心是：CPU 端计算每根骨骼的变换矩阵（全局变换 = 父骨骼变换 × 本地变换），然后通过 Uniform 数组传入顶点着色器。顶点着色器根据骨骼索引和权重对顶点进行蒙皮计算（线性混合蒙皮 LBS）。

**答案**：
```glsl
// 骨骼动画 - 顶点着色器
precision mediump float;

const int MAX_BONES = 64;

uniform mat4 uModelMatrix;
uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;
uniform mat4 uBones[MAX_BONES];  // 骨骼变换矩阵数组

attribute vec3 aPosition;
attribute vec3 aNormal;
attribute vec4 aBoneIndices;    // 影响该顶点的 4 根骨骼索引
attribute vec4 aBoneWeights;    // 对应的权重

varying vec3 vWorldNormal;
varying vec3 vWorldPos;

void main() {
    // 线性混合蒙皮（LBS）
    mat4 boneMatrix =
        uBones[int(aBoneIndices.x)] * aBoneWeights.x +
        uBones[int(aBoneIndices.y)] * aBoneWeights.y +
        uBones[int(aBoneIndices.z)] * aBoneWeights.z +
        uBones[int(aBoneIndices.w)] * aBoneWeights.w;

    // 用骨骼矩阵变换顶点
    vec4 skinnedPos = boneMatrix * vec4(aPosition, 1.0);
    vec3 skinnedNormal = normalize(mat3(boneMatrix) * aNormal);

    vec4 worldPos = uModelMatrix * skinnedPos;
    vWorldPos = worldPos.xyz;
    vWorldNormal = normalize(mat3(uModelMatrix) * skinnedNormal);

    gl_Position = uProjectionMatrix * uViewMatrix * worldPos;
}
```

```typescript
// CPU 端骨骼矩阵计算（伪代码）
function computeBoneMatrices(skeleton: Skeleton, pose: Pose): Float32Array[] {
    const boneMatrices: THREE.Matrix4[] = [];

    for (let i = 0; i < skeleton.bones.length; i++) {
        const bone = skeleton.bones[i];
        const localMatrix = pose.localMatrices[i];

        // 全局变换 = 父骨骼的全局变换 × 本地变换
        if (bone.parentIndex >= 0) {
            boneMatrices[i] = boneMatrices[bone.parentIndex].clone().multiply(localMatrix);
        } else {
            boneMatrices[i] = localMatrix.clone();
        }

        // 最终矩阵 = 全局变换 × 逆绑定矩阵
        boneMatrices[i].multiply(bone.inverseBindMatrix);
    }

    return boneMatrices.map(m => m.elements);
}
```

**要点**：
- 通常每个顶点最多受 4 根骨骼影响（`aBoneWeights` 的 4 个分量之和应为 1.0）
- `uBones[i]` 传入的是 `全局变换 × 逆绑定矩阵`，不是单纯的骨骼变换
- 骨骼数量受 Uniform 数组大小限制，一般不超过 64-128 根
- LBS 在关节处会有"糖纸"扭曲问题，更高级的方案是 DQS（对偶四元数蒙皮）

### 练习四

**思路**：透视投影和正交投影的核心区别是投影矩阵的构造方式。透视投影使远处物体看起来更小（近大远小），正交投影保持物体大小不变。通过 Uniform 控制投影矩阵切换即可。

**答案**：
```typescript
// Three.js 中的投影切换
import * as THREE from 'three';

const camera = new THREE.PerspectiveCamera(50, aspect, 0.1, 1000);
const orthoCamera = new THREE.OrthographicCamera(
    -10 * aspect, 10 * aspect,  // left, right
    10, -10,                     // top, bottom
    0.1, 1000                    // near, far
);

// 统一放在同一位置
let usePerspective = true;

function toggleProjection() {
    usePerspective = !usePerspective;
    const activeCamera = usePerspective ? camera : orthoCamera;
    renderer.render(scene, activeCamera);
}

// 监听键盘事件
window.addEventListener('keydown', (e) => {
    if (e.key === 'p') toggleProjection();
});
```

```glsl
// Shader 端无需修改——投影矩阵通过 uProjectionMatrix 传入
// 透视投影矩阵中 w 分量不为 1，导致透视除法后产生近大远小效果
// 正交投影矩阵中 w 分量保持为 1，透视除法不改变坐标比例
```

**要点**：
- 透视投影的关键是 `gl_Position.w = -z`（相机空间），透视除法 `x/w, y/w` 使远处物体变小
- 正交投影保持 `w = 1`，所以除法后坐标不变
- 观察差异：透视投影下平行线会汇聚于灭点，正交投影下平行线永远平行
- 3D 游戏几乎都用透视投影，正交投影用于 2D 游戏、UI、工程制图
