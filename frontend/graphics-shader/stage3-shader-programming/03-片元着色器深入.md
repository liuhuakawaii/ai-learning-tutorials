# 片元着色器深入

## 场景引入

顶点着色器负责"把顶点放在正确的位置"，而片元着色器负责"决定每个像素最终是什么颜色"。这是渲染管线中计算量最大、也是最能体现视觉效果的阶段。纹理采样、多纹理混合、透明度处理、深度写入——这些操作都发生在片元着色器中。掌握片元着色器的各种技巧，是实现高质量渲染效果的关键。

## 学习目标

1. 掌握 2D 和立方体纹理采样的完整用法
2. 实现多纹理混合与自定义混合模式
3. 理解 Alpha 测试、深度写入与模板测试的配合
4. 能够编写高质量的片元着色器代码

## 一、纹理采样

### 1.1 2D 纹理采样

纹理采样是将图片映射到模型表面的核心操作：

```glsl
uniform sampler2D uDiffuseMap;    // 漫反射贴图
uniform sampler2D uNormalMap;     // 法线贴图
uniform sampler2D uSpecularMap;   // 高光贴图

varying vec2 vUv;                 // 纹理坐标（由顶点着色器插值传入）

void main() {
    // 基础采样
    vec4 diffuseColor = texture2D(uDiffuseMap, vUv);

    // 法线贴图采样（将 [0,1] 范围映射到 [-1,1]）
    vec3 normal = texture2D(uNormalMap, vUv).rgb * 2.0 - 1.0;

    // 高光贴图采样
    float specular = texture2D(uSpecularMap, vUv).r;

    gl_FragColor = diffuseColor;
}
```

### 1.2 纹理采样的数学原理

```
纹理坐标 (UV) 与纹理像素 (texel) 的关系：

纹理坐标系 (0,0) → (1,1)
┌────────────────────┐
│ ┌──┬──┬──┬──┐      │
│ │  │  │  │  │      │  纹理尺寸：4x4
│ ├──┼──┼──┼──┤      │
│ │  │  │  │  │      │  采样点 (0.375, 0.375)
│ ├──┼──┼──┼──┤      │  → 映射到 texel (1.5, 1.5)
│ │  │  │● │  │      │  → 双线性插值周围 4 个 texel
│ ├──┼──┼──┼──┤      │
│ │  │  │  │  │      │
│ └──┴──┴──┴──┘      │
└────────────────────┘

双线性插值：
┌──────┬──────┐
│  A   │  B   │
│  ●───┼───●  │  采样点 P 落在四个 texel 中间
├──────┼──────┤  最终颜色 = lerp(lerp(A,B,t.x), lerp(C,D,t.x), t.y)
│  C   │  D   │
│  ●───┼───●  │
└──────┴──────┘
```

### 1.3 立方体纹理采样

立方体纹理用于环境映射、反射和天空盒：

```glsl
uniform samplerCube uEnvMap;      // 环境贴图
uniform samplerCube uCubeMap;     // 天空盒

varying vec3 vWorldNormal;        // 世界空间法线
varying vec3 vWorldPos;           // 世界空间位置
varying vec3 vViewDir;            // 视线方向

void main() {
    // 反射方向采样（用于金属材质）
    vec3 reflectDir = reflect(-vViewDir, vWorldNormal);
    vec3 envColor = textureCube(uEnvMap, reflectDir).rgb;

    // 天空盒采样（直接使用视线方向）
    vec3 skyColor = textureCube(uCubeMap, vViewDir).rgb;

    // 折射效果
    float eta = 1.0 / 1.5;  // 空气到玻璃
    vec3 refractDir = refract(-vViewDir, vWorldNormal, eta);
    vec3 refractColor = textureCube(uEnvMap, refractDir).rgb;

    // Fresnel 混合反射和折射
    float fresnel = pow(1.0 - max(dot(vWorldNormal, vViewDir), 0.0), 3.0);
    vec3 finalColor = mix(refractColor, envColor, fresnel);

    gl_FragColor = vec4(finalColor, 1.0);
}
```

## 二、多纹理混合

### 2.1 基础混合方式

```glsl
uniform sampler2D uTextureA;
uniform sampler2D uTextureB;
uniform sampler2D uMaskTexture;
uniform float uMixFactor;

varying vec2 vUv;

void main() {
    vec4 colorA = texture2D(uTextureA, vUv);
    vec4 colorB = texture2D(uTextureB, vUv);

    // 方式 1：固定比例混合
    vec4 blended = mix(colorA, colorB, uMixFactor);

    // 方式 2：使用遮罩纹理混合
    float mask = texture2D(uMaskTexture, vUv).r;
    vec4 masked = mix(colorA, colorB, mask);

    // 方式 3：叠加模式（Photoshop 的 Overlay）
    vec4 overlay = colorA;
    overlay.r = colorA.r < 0.5
        ? 2.0 * colorA.r * colorB.r
        : 1.0 - 2.0 * (1.0 - colorA.r) * (1.0 - colorB.r);
    overlay.g = colorA.g < 0.5
        ? 2.0 * colorA.g * colorB.g
        : 1.0 - 2.0 * (1.0 - colorA.g) * (1.0 - colorB.g);
    overlay.b = colorA.b < 0.5
        ? 2.0 * colorA.b * colorB.b
        : 1.0 - 2.0 * (1.0 - colorA.b) * (1.0 - colorB.b);

    gl_FragColor = overlay;
}
```

### 2.2 常用混合模式实现

```glsl
// 正片叠底（Multiply）
vec4 multiply(vec4 a, vec4 b) {
    return a * b;
}

// 滤色（Screen）
vec4 screen(vec4 a, vec4 b) {
    return 1.0 - (1.0 - a) * (1.0 - b);
}

// 叠加（Overlay）
vec4 overlay(vec4 a, vec4 b) {
    vec4 result;
    result.r = a.r < 0.5 ? 2.0 * a.r * b.r : 1.0 - 2.0 * (1.0 - a.r) * (1.0 - b.r);
    result.g = a.g < 0.5 ? 2.0 * a.g * b.g : 1.0 - 2.0 * (1.0 - a.g) * (1.0 - b.g);
    result.b = a.b < 0.5 ? 2.0 * a.b * b.b : 1.0 - 2.0 * (1.0 - a.b) * (1.0 - b.b);
    result.a = a.a;
    return result;
}

// 柔光（Soft Light）
vec4 softLight(vec4 a, vec4 b) {
    return (1.0 - 2.0 * b) * a * a + 2.0 * b * a;
}
```

### 2.3 纹理图集（Texture Atlas）

使用一张大图包含多个小图，减少纹理切换次数：

```glsl
uniform sampler2D uAtlas;     // 图集纹理
uniform vec4 uAtlasRegion;    // 图集区域 (x, y, width, height)

varying vec2 vUv;

void main() {
    // 将 UV 映射到图集中的指定区域
    vec2 atlasUV = uAtlasRegion.xy + vUv * uAtlasRegion.zw;
    vec4 color = texture2D(uAtlas, atlasUV);
    gl_FragColor = color;
}
```

## 三、Alpha 测试与 discard

### 3.1 Alpha 测试

```glsl
uniform sampler2D uTexture;
uniform float uAlphaThreshold;

varying vec2 vUv;

void main() {
    vec4 color = texture2D(uTexture, vUv);

    // Alpha 测试：低于阈值的像素直接丢弃
    if (color.a < uAlphaThreshold) {
        discard;  // 丢弃此片元，不写入颜色缓冲和深度缓冲
    }

    gl_FragColor = color;
}
```

**discard 的影响**：

```
discard 执行后：
┌─────────────────────────────────┐
│  颜色缓冲    ✗ 不写入           │
│  深度缓冲    ✗ 不写入           │
│  模板缓冲    ✗ 不写入           │
│  后续管线    ✗ 终止             │
└─────────────────────────────────┘

注意：discard 会破坏 Early-Z 优化，因为 GPU 无法提前判断
哪些像素会被丢弃。在移动端应尽量避免使用。
```

### 3.2 Alpha 混合 vs Alpha 测试

```glsl
// Alpha 混合（推荐）：需要正确设置混合模式
// 在 JavaScript 端设置：
// gl.enable(gl.BLEND);
// gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);

// 片元着色器
void main() {
    vec4 color = texture2D(uTexture, vUv);
    gl_FragColor = color;  // alpha 通道用于混合
}

// Alpha 测试（用于植被、铁丝网等硬边缘透明）：
void main() {
    vec4 color = texture2D(uTexture, vUv);
    if (color.a < 0.5) discard;
    gl_FragColor = vec4(color.rgb, 1.0);  // 输出不透明
}
```

## 四、gl_FragDepth

### 4.1 自定义深度值

```glsl
// 默认情况下，GPU 自动使用插值后的 gl_FragCoord.z 作为深度值
// 有时需要手动写入自定义深度值

void main() {
    // 方式 1：直接赋值（覆盖自动值）
    gl_FragDepth = 0.5;  // 所有片元写入相同的深度值

    // 方式 2：基于距离计算
    float dist = length(vWorldPos - uCameraPos);
    gl_FragDepth = dist / uFarPlane;  // 线性化深度

    // 方式 3：使用 gl_FragCoord.z（等价于默认行为）
    gl_FragDepth = gl_FragCoord.z;
}
```

### 4.2 深度预计算优化

```glsl
// 在顶点着色器中预计算深度
varying float vDepth;

void main() {
    vec4 clipPos = uProjectionMatrix * uViewMatrix * uModelMatrix * vec4(aPosition, 1.0);
    vDepth = clipPos.z / clipPos.w;  // NDC 深度
    gl_Position = clipPos;
}

// 片元着色器中使用
void main() {
    gl_FragDepth = vDepth;  // 使用插值后的深度
}
```

模板测试在片元着色器执行前进行，用于实现遮罩、描边等效果：

```glsl
// 模板测试配置（JavaScript 端）
// gl.enable(gl.STENCIL_TEST);
```

### 5.2 描边效果实现

```glsl
// 描边 Shader
uniform float uOutlineWidth;
uniform vec3 uOutlineColor;
uniform sampler2D uDepthTexture;

varying vec2 vUv;

void main() {
    vec2 texelSize = 1.0 / vec2(textureSize(uDepthTexture, 0));

    // 采样周围像素的深度值
    float depth = texture2D(uDepthTexture, vUv).r;
    float depthN = texture2D(uDepthTexture, vUv + vec2(0.0, texelSize.y)).r;
    float depthS = texture2D(uDepthTexture, vUv - vec2(0.0, texelSize.y)).r;
    float depthE = texture2D(uDepthTexture, vUv + vec2(texelSize.x, 0.0)).r;
    float depthW = texture2D(uDepthTexture, vUv - vec2(texelSize.x, 0.0)).r;

    // Sobel 边缘检测
    float edgeX = depthE - depthW;
    float edgeY = depthN - depthS;
    float edge = sqrt(edgeX * edgeX + edgeY * edgeY);

    // 超过阈值则显示描边颜色
    if (edge > uOutlineWidth) {
        gl_FragColor = vec4(uOutlineColor, 1.0);
    } else {
        gl_FragColor = texture2D(uDiffuseMap, vUv);
    }
}
```

## 六、完整示例：多纹理材质

```glsl
// 完整的 PBR 材质片元着色器
precision mediump float;

uniform sampler2D uAlbedoMap;       // 漫反射贴图
uniform sampler2D uNormalMap;       // 法线贴图
uniform sampler2D uMetallicRoughnessMap; // 金属度/粗糙度贴图
uniform sampler2D uAOMap;           // 环境光遮蔽贴图
uniform sampler2D uEmissiveMap;     // 自发光贴图

uniform vec3 uLightDir;
uniform vec3 uLightColor;
uniform vec3 uCameraPos;

varying vec2 vUv;
varying vec3 vWorldPos;
varying vec3 vWorldNormal;
varying vec3 vWorldTangent;
varying vec3 vWorldBitangent;

vec3 calculateNormal() {
    vec3 normal = texture2D(uNormalMap, vUv).rgb * 2.0 - 1.0;
    mat3 TBN = mat3(
        normalize(vWorldTangent),
        normalize(vWorldBitangent),
        normalize(vWorldNormal)
    );
    return normalize(TBN * normal);
}

void main() {
    // 采样所有纹理
    vec4 albedo = texture2D(uAlbedoMap, vUv);
    vec3 normal = calculateNormal();
    vec2 metallicRoughness = texture2D(uMetallicRoughnessMap, vUv).rg;
    float ao = texture2D(uAOMap, vUv).r;
    vec3 emissive = texture2D(uEmissiveMap, vUv).rgb;

    float metallic = metallicRoughness.r;
    float roughness = metallicRoughness.g;

    // 简化的光照计算
    vec3 lightDir = normalize(uLightDir);
    vec3 viewDir = normalize(uCameraPos - vWorldPos);
    vec3 halfDir = normalize(lightDir + viewDir);

    float NdotL = max(dot(normal, lightDir), 0.0);
    float NdotH = max(dot(normal, halfDir), 0.0);

    // 漫反射
    vec3 diffuse = albedo.rgb * uLightColor * NdotL;

    // 高光反射
    float spec = pow(NdotH, (1.0 - roughness) * 128.0);
    vec3 specular = mix(vec3(0.04), albedo.rgb, metallic) * uLightColor * spec;

    // 最终颜色
    vec3 finalColor = (diffuse + specular) * ao + emissive;

    // Gamma 校正
    finalColor = pow(finalColor, vec3(1.0 / 2.2));

    gl_FragColor = vec4(finalColor, albedo.a);
}
```

## 常见误区

1. **纹理坐标原点位置**：WebGL 的纹理坐标原点在左下角，而图片通常以左上角为原点。加载图片后可能需要翻转 Y 轴。

2. **discard 破坏 Early-Z**：使用 `discard` 会禁用 GPU 的 Early-Z 优化，导致深度测试无法提前跳过被遮挡的片元。在移动端应尽量用 Alpha 混合替代。

3. **gl_FragDepth 的性能影响**：手动写入 `gl_FragDepth` 会禁用 GPU 的深度优化（如 Hi-Z、Reverse-Z）。除非必要，不要手动写入。

4. **纹理采样的边界处理**：UV 坐标超出 [0,1] 范围时的行为由纹理的 wrap mode 决定。默认是 `clamp-to-edge`，重复纹理需要设置为 `repeat`。

---

## 工程建议

1. **纹理加载顺序**：先加载不透明的基础纹理，再叠加透明的细节纹理。这样可以利用 Early-Z 跳过被遮挡的像素。

2. **减少纹理采样次数**：合并纹理通道（如将金属度、粗糙度、AO 打包到一张纹理的 RGB 通道）可以减少纹理采样次数和带宽占用。

3. **Alpha 测试的替代方案**：对于植被等需要硬边缘透明的场景，可以使用 Alpha to Coverage（MSAA 环境下）替代 `discard`，既保持边缘锐利又不破坏 Early-Z。

4. **深度值的线性化**：透视投影下的深度值是非线性的（近处精度高，远处精度低）。如果需要线性深度（如用于雾效），需要手动线性化：`float linearDepth = (2.0 * near * far) / (far + near - z * (far - near))`。

## 参考答案

### 练习一

**思路**：立方体贴图反射的核心是用视线方向和法线计算反射方向，然后用反射方向采样环境贴图。Fresnel 系数控制反射和漫反射的混合比例——掠射角度越大，反射越强。这是 PBR 材质中金属反射的基本实现。

**答案**：
```glsl
// 反射效果 - 顶点着色器
uniform mat4 uModelMatrix;
uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;

attribute vec3 aPosition;
attribute vec3 aNormal;

varying vec3 vWorldPos;
varying vec3 vWorldNormal;

void main() {
    vec4 worldPos = uModelMatrix * vec4(aPosition, 1.0);
    vWorldPos = worldPos.xyz;
    vWorldNormal = normalize(mat3(uModelMatrix) * aNormal);
    gl_Position = uProjectionMatrix * uViewMatrix * worldPos;
}
```

```glsl
// 反射效果 - 片元着色器
precision mediump float;

uniform samplerCube uEnvMap;
uniform vec3 uCameraPos;
uniform vec3 uDiffuseColor;
uniform float uReflectivity;  // 基础反射率

varying vec3 vWorldPos;
varying vec3 vWorldNormal;

void main() {
    vec3 normal = normalize(vWorldNormal);
    vec3 viewDir = normalize(uCameraPos - vWorldPos);

    // 计算反射方向
    vec3 reflectDir = reflect(-viewDir, normal);
    vec3 envColor = textureCube(uEnvMap, reflectDir).rgb;

    // Fresnel（Schlick 近似）
    float cosTheta = max(dot(normal, viewDir), 0.0);
    float fresnel = uReflectivity + (1.0 - uReflectivity) * pow(1.0 - cosTheta, 5.0);

    // 混合漫反射和反射
    vec3 finalColor = mix(uDiffuseColor, envColor, fresnel);

    gl_FragColor = vec4(finalColor, 1.0);
}
```

**要点**：
- `reflect(-viewDir, normal)` 中的负号是因为 `reflect` 函数期望入射方向指向表面
- Schlick 近似 `R0 + (1-R0) * (1-cosθ)^5` 是实时渲染中最常用的 Fresnel 公式
- `uReflectivity` 通常用 `0.04`（非金属）或 `0.5-1.0`（金属）

### 练习二

**思路**：地形混合的关键是根据高度和坡度为每种纹理分配权重。高度决定垂直分布（低处草地、中间岩石、高处雪地），坡度决定水平分布（缓坡用草地/泥土、陡坡用岩石）。用 `smoothstep` 实现平滑过渡。

**答案**：
```glsl
// 地形混合 - 片元着色器
precision mediump float;

uniform sampler2D uGrassTex;
uniform sampler2D uRockTex;
uniform sampler2D uSnowTex;
uniform sampler2D uDirtTex;
uniform float uHeightScale;   // 高度缩放系数
uniform float uGrassHeight;   // 草地上限
uniform float uRockHeight;    // 岩石上限
uniform float uSnowHeight;    // 雪地起始高度

varying vec2 vUv;
varying vec3 vWorldPos;
varying vec3 vWorldNormal;

void main() {
    vec3 normal = normalize(vWorldNormal);
    float height = vWorldPos.y * uHeightScale;

    // 计算坡度（法线与上方向的夹角余弦）
    float slope = 1.0 - normal.y;  // 0 = 平坦，1 = 垂直

    // 各纹理权重
    float grassWeight = smoothstep(uGrassHeight - 2.0, uGrassHeight, height) * (1.0 - smoothstep(uGrassHeight, uGrassHeight + 2.0, height));
    float rockWeight = smoothstep(uRockHeight - 3.0, uRockHeight, height);
    float snowWeight = smoothstep(uSnowHeight, uSnowHeight + 3.0, height);
    float dirtWeight = 1.0 - grassWeight - rockWeight - snowWeight;

    // 坡度影响：陡坡用岩石替代草地
    float slopeFactor = smoothstep(0.4, 0.7, slope);
    grassWeight *= (1.0 - slopeFactor);
    rockWeight += slopeFactor * (grassWeight + dirtWeight);

    // 采样纹理
    vec3 grass = texture2D(uGrassTex, vUv * 8.0).rgb;
    vec3 rock  = texture2D(uRockTex, vUv * 4.0).rgb;
    vec3 snow  = texture2D(uSnowTex, vUv * 6.0).rgb;
    vec3 dirt  = texture2D(uDirtTex, vUv * 8.0).rgb;

    // 归一化权重
    float total = grassWeight + rockWeight + snowWeight + dirtWeight;
    vec3 color = (grass * grassWeight + rock * rockWeight + snow * snowWeight + dirt * dirtWeight) / total;

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- `normal.y` 接近 1 表示地面平坦，接近 0 表示陡峭
- UV 乘以不同的缩放系数（`* 8.0`）使不同纹理有不同重复频率，增加自然感
- `smoothstep` 的两个阈值参数控制过渡带宽度，值越大过渡越平滑

### 练习三

**思路**：阴影映射分两个 Pass：第一个 Pass 从光源视角渲染深度图，第二个 Pass 将片元变换到光源空间，比较其深度与深度图中的值。如果片元深度大于深度图值，说明被遮挡（在阴影中）。

**答案**：
```glsl
// Pass 1：从光源视角渲染深度（顶点着色器）
uniform mat4 uLightMVP;

attribute vec3 aPosition;

varying float vDepth;

void main() {
    vec4 pos = uLightMVP * vec4(aPosition, 1.0);
    vDepth = pos.z / pos.w;  // 归一化深度
    gl_Position = pos;
}
```

```glsl
// Pass 1：深度输出（片元着色器）
precision mediump float;

varying float vDepth;

void main() {
    // 将深度编码到 RGBA 4 个通道（提高精度）
    float depth = vDepth;
    gl_FragColor = vec4(
        fract(depth * 255.0),
        fract(depth * 255.0 * 255.0),
        fract(depth * 255.0 * 255.0 * 255.0),
        1.0
    );
}
```

```glsl
// Pass 2：阴影判断（片元着色器）
precision mediump float;

uniform sampler2D uShadowMap;
uniform mat4 uLightMVP;
uniform vec3 uLightDir;
uniform vec3 uDiffuseColor;

varying vec3 vWorldPos;
varying vec3 vWorldNormal;

float unpackDepth(vec4 rgba) {
    return dot(rgba.rgb, vec3(1.0, 1.0/255.0, 1.0/65025.0));
}

void main() {
    vec3 normal = normalize(vWorldNormal);
    vec3 lightDir = normalize(uLightDir);

    // 将片元变换到光源裁剪空间
    vec4 lightSpacePos = uLightMVP * vec4(vWorldPos, 1.0);
    vec3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
    projCoords = projCoords * 0.5 + 0.5;  // 映射到 [0,1]

    // 从深度图采样并比较
    float shadowMapDepth = unpackDepth(texture2D(uShadowMap, projCoords.xy));
    float currentDepth = projCoords.z;

    // 阴影偏移防止自阴影
    float bias = max(0.005 * (1.0 - dot(normal, lightDir)), 0.001);
    float shadow = currentDepth - bias > shadowMapDepth ? 0.3 : 1.0;

    // 光照计算
    float diffuse = max(dot(normal, lightDir), 0.0);
    vec3 color = uDiffuseColor * (0.2 + diffuse * shadow);

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- bias 用于防止自阴影（shadow acne），值根据表面朝向动态调整
- 深度编码到 RGB 通道可以提高精度（WebGL 默认纹理精度不足）
- PCF（Percentage-Closer Filtering）可以通过多次采样实现柔和阴影边缘

### 练习四

**思路**：模板测试实现透视镜需要两个 Pass：第一个 Pass 在圆形区域写入模板值，第二个 Pass 只在模板值匹配的区域渲染不同材质。利用模板缓冲区分"镜内"和"镜外"。

**答案**：
```typescript
// TypeScript 端设置（Three.js）
const stencilRef = 1;

// Pass 1：写入模板（圆形遮罩）
const maskMaterial = new THREE.ShaderMaterial({
    colorWrite: false,      // 不写颜色
    depthWrite: false,      // 不写深度
    stencilWrite: true,
    stencilRef: stencilRef,
    stencilFunc: THREE.AlwaysStencilFunc,
    stencilZPass: THREE.ReplaceStencilOp,
});

// Pass 2：镜内材质（只在模板值为 1 的区域渲染）
const innerMaterial = new THREE.ShaderMaterial({
    stencilWrite: true,
    stencilRef: stencilRef,
    stencilFunc: THREE.EqualStencilFunc,
});

// Pass 3：镜外材质（只在模板值不为 1 的区域渲染）
const outerMaterial = new THREE.ShaderMaterial({
    stencilWrite: true,
    stencilRef: stencilRef,
    stencilFunc: THREE.NotEqualStencilFunc,
});
```

```glsl
// 圆形遮罩 - 顶点着色器（Pass 1）
uniform mat4 uMVP;
attribute vec3 aPosition;

void main() {
    gl_Position = uMVP * vec4(aPosition, 1.0);
}
```

```glsl
// 圆形遮罩 - 片元着色器（Pass 1）
precision mediump float;

void main() {
    // 不输出颜色，只写入模板值
    gl_FragColor = vec4(0.0);
}
```

**要点**：
- 模板测试在片元着色器执行之前进行，所以 Pass 1 不需要片元着色器计算
- `AlwaysStencilFunc` + `ReplaceStencilOp` 确保圆形区域写入指定的模板值
- 三次绘制：写模板 → 渲染镜内 → 渲染镜外，每次使用不同的模板比较函数
