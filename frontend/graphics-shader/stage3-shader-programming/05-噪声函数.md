# 噪声函数

## 场景引入

自然界中几乎找不到完全规则的几何形状——云朵的边缘、山脉的起伏、大理石的纹理，都带有一种"有序的随机"。这种视觉效果无法用简单的数学函数（正弦、余弦）模拟，需要引入噪声函数。噪声是 Shader 编程中最强大的工具之一，它能生成程序化的纹理、地形、火焰、云层等自然效果，而无需任何图片资源。理解噪声的原理和实现，是从"能写 Shader"到"能写好 Shader"的关键跨越。

## 学习目标

1. 理解伪随机数生成的原理（hash/fract）
2. 掌握 Value Noise 和 Perlin Noise 的实现
3. 理解 FBM（分形布朗运动）的叠加原理
4. 学会将噪声应用于纹理、地形、云等实际场景

## 一、伪随机数生成

### 1.1 为什么 GPU 需要伪随机？

GPU 没有真正的随机数生成器（没有时钟、没有用户输入），所有"随机"都必须是确定性的——相同的输入总是产生相同的输出。

```glsl
// 经典的伪随机函数：fract(sin(...))
float random(vec2 st) {
    return fract(sin(dot(st.xy, vec2(12.9898, 78.233))) * 43758.5453);
}

// 使用示例
void main() {
    vec2 uv = vUv;
    float r = random(uv);  // 每个像素一个"随机"值
    gl_FragColor = vec4(vec3(r), 1.0);
}
```

**原理图解**：

```
伪随机数生成链：

输入 (x,y)
    │
    ▼
dot((x,y), (12.9898, 78.233))  →  标量值
    │
    ▼
sin(标量)                       →  [-1, 1] 的震荡
    │
    ▼
× 43758.5453                    →  放大，制造高频震荡
    │
    ▼
fract(...)                      →  取小数部分，得到 [0, 1]
```

### 1.2 更好的 Hash 函数

`fract(sin(...))` 在某些 GPU 上精度不足，会产生明显的条纹。以下是更健壮的版本：

```glsl
// 基于 fract 的 2D hash
vec2 hash2(vec2 p) {
    p = vec2(dot(p, vec2(127.1, 311.7)),
             dot(p, vec2(269.5, 183.3)));
    return -1.0 + 2.0 * fract(sin(p) * 43758.5453123);
}

// 基于整数运算的 hash（更稳定）
uint hash(uint x) {
    x ^= x >> 16u;
    x *= 0x45d9f3bu;
    x ^= x >> 16u;
    x *= 0x45d9f3bu;
    x ^= x >> 16u;
    return x;
}

// 浮点版本
float hashFloat(vec2 p) {
    return fract(sin(dot(p, vec2(12.9898, 78.233))) * 43758.5453);
}
```

## 二、Value Noise

### 2.1 原理

Value Noise 是最简单的噪声类型：在整数格点上生成随机值，格点之间使用插值平滑过渡。

```
Value Noise 原理：

1. 在整数格点上生成随机值
   0.8     0.2
    ●───────●
    │       │
    │  插值  │
    │  区域  │
    │       │
    ●───────●
   0.3     0.9

2. 使用 smoothstep 插值
   P(x,y) = mix(
       mix(0.8, 0.2, smooth_x),   // 上边插值
       mix(0.3, 0.9, smooth_x),   // 下边插值
       smooth_y                     // 垂直插值
   )
```

### 2.2 实现

```glsl
// 2D Value Noise
float valueNoise(vec2 p) {
    vec2 i = floor(p);  // 整数部分（格点坐标）
    vec2 f = fract(p);  // 小数部分（格点内的位置）

    // 四个角的随机值
    float a = random(i);                    // 左下
    float b = random(i + vec2(1.0, 0.0));   // 右下
    float c = random(i + vec2(0.0, 1.0));   // 左上
    float d = random(i + vec2(1.0, 1.0));   // 右上

    // Hermite 插值（比线性插值更平滑）
    vec2 u = f * f * (3.0 - 2.0 * f);  // smoothstep 公式

    // 双线性插值
    return mix(
        mix(a, b, u.x),
        mix(c, d, u.x),
        u.y
    );
}

void main() {
    vec2 uv = vUv * 8.0;  // 控制噪声频率
    float n = valueNoise(uv);
    gl_FragColor = vec4(vec3(n), 1.0);
}
```

**视觉特征**：

```
Value Noise 的特征：
┌─────────────────────────────┐
│  ●  ●  ●  ●  ●  ●  ●  ●   │  格点处值随机
│  ╲ ╱  ╲ ╱  ╲ ╱  ╲ ╱  ╲ ╱  │  过渡平滑
│   ●    ●    ●    ●    ●    │  但有明显的"块状"感
│  ╱ ╲  ╱ ╲  ╱ ╲  ╱ ╲  ╱ ╲  │  因为插值只在格点间进行
│  ●  ●  ●  ●  ●  ●  ●  ●   │
└─────────────────────────────┘

优点：计算简单
缺点：有明显的方向性伪影（轴对齐的块状）
```

## 三、Perlin Noise

### 3.1 原理

Perlin Noise 由 Ken Perlin 在 1983 年发明，解决了 Value Noise 的方向性问题。核心思想：不在格点上存储随机值，而是存储随机**梯度向量**，通过距离与梯度的点积来计算噪声值。

```
Perlin Noise 原理：

1. 每个格点存储一个随机梯度向量
   →  ↗      ←
    ●─────────●
    │         │
    │  P 点的  │
    │  噪声值  │
    │         │
    ●─────────●
   ↓  ↘      ↑

2. 对于点 P，计算：
   noise(P) = dot(梯度[P的格点], P - 格点位置)

3. 四个角的噪声值加权平均
```

### 3.2 实现

```glsl
// 2D Perlin Noise
vec2 grad(vec2 p) {
    // 伪随机梯度向量
    p = vec2(dot(p, vec2(127.1, 311.7)),
             dot(p, vec2(269.5, 183.3)));
    return -1.0 + 2.0 * fract(sin(p) * 43758.5453123);
}

float perlinNoise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);

    // 四个角到点 P 的距离向量
    vec2 d00 = f - vec2(0.0, 0.0);
    vec2 d10 = f - vec2(1.0, 0.0);
    vec2 d01 = f - vec2(0.0, 1.0);
    vec2 d11 = f - vec2(1.0, 1.0);

    // 四个角的梯度与距离的点积
    float n00 = dot(grad(i + vec2(0, 0)), d00);
    float n10 = dot(grad(i + vec2(1, 0)), d10);
    float n01 = dot(grad(i + vec2(0, 1)), d01);
    float n11 = dot(grad(i + vec2(1, 1)), d11);

    // Hermite 插值
    vec2 u = f * f * (3.0 - 2.0 * f);

    return mix(
        mix(n00, n10, u.x),
        mix(n01, n11, u.x),
        u.y
    ) * 0.5 + 0.5;  // 映射到 [0, 1]
}

void main() {
    vec2 uv = vUv * 4.0;
    float n = perlinNoise(uv);
    gl_FragColor = vec4(vec3(n), 1.0);
}
```

```
Value Noise:                    Perlin Noise:
┌──────────────────┐           ┌──────────────────┐
│ ████████░░░░░░░░ │           │ ░░▒▒▒▒▓▓████▒▒░░ │
│ ████████░░░░░░░░ │           │ ░▒▒▓▓████▓▓▒▒░░░ │
│ ████████░░░░░░░░ │           │ ▒▒▓▓████████▓▓▒▒ │
│ ░░░░████████░░░░ │           │ ▒▓████████▓▓▒▒░░ │
│ ░░░░████████░░░░ │           │ ░▒▒▓▓████▒▒░░░░░ │
└──────────────────┘           └──────────────────┘
  有明显的轴对齐块状               各向同性，更自然
```

## 四、FBM（分形布朗运动）

### 4.1 叠加原理

单层噪声看起来太"圆润"，缺乏细节。FBM 通过叠加多层不同频率和振幅的噪声来增加细节：

```
FBM 叠加原理：

第 1 层（低频，高振幅）    第 2 层（中频，中振幅）    第 3 层（高频，低振幅）
    ╭──╮                      ╭╮ ╭╮                    ╭╮╭╮╭╮╭╮
   ╭╯  ╰╮                   ╭╯╰╮╯╰╮                 ╭╯╰╯╰╯╰╯╰╮
  ╭╯    ╰╮                ╭╯   ╰╯  ╰╮              ╭╯         ╰╮
──╯      ╰──           ──╯          ╰──         ──╯            ╰──

  +           +              =               最终结果
                                    ╭─╮ ╭╮ ╭╮╭╮
                                   ╭╯ ╰╮╯╰╮╯╰╯╰╮
                                  ╭╯   ╰╯  ╰╯   ╰╮
                               ──╯                ╰──

公式：noise = Σ (amplitude * noise(frequency * p))
      amplitude *= persistence (通常 0.5)
      frequency *= lacunarity  (通常 2.0)
```

### 4.2 实现

```glsl
// FBM 函数
float fbm(vec2 p, int octaves) {
    float value = 0.0;
    float amplitude = 0.5;
    float frequency = 1.0;

    for (int i = 0; i < octaves; i++) {
        value += amplitude * perlinNoise(p * frequency);
        frequency *= 2.0;   // lacunarity
        amplitude *= 0.5;   // persistence
    }

    return value;
}

// 使用示例
void main() {
    vec2 uv = vUv * 4.0;
    float n = fbm(uv, 6);  // 6 层叠加
    gl_FragColor = vec4(vec3(n), 1.0);
}
```

### 4.3 FBM 参数控制

```glsl
// 可调参数的 FBM
float fbmCustom(vec2 p, int octaves, float lacunarity, float persistence) {
    float value = 0.0;
    float amplitude = 1.0;
    float frequency = 1.0;
    float maxValue = 0.0;  // 用于归一化

    for (int i = 0; i < octaves; i++) {
        value += amplitude * perlinNoise(p * frequency);
        maxValue += amplitude;
        frequency *= lacunarity;
        amplitude *= persistence;
    }

    return value / maxValue;  // 归一化到 [0, 1]
}
```

**参数效果对比**：

```
lacunarity = 2.0, persistence = 0.5  →  经典分形，细节均匀
lacunarity = 3.0, persistence = 0.5  →  高频更多，细节更密集
lacunarity = 2.0, persistence = 0.7  →  振幅衰减慢，粗糙感更强
lacunarity = 2.0, persistence = 0.3  →  振幅衰减快，更平滑
```

## 五、噪声的实际应用

### 5.1 云朵效果

```glsl
uniform float uTime;

float cloudNoise(vec2 p) {
    // 基础 FBM
    float n = fbm(p + uTime * 0.1, 6);

    // 添加扭曲
    vec2 q = vec2(
        fbm(p + vec2(0.0, 0.0), 4),
        fbm(p + vec2(5.2, 1.3), 4)
    );

    vec2 r = vec2(
        fbm(p + 4.0 * q + vec2(1.7, 9.2) + uTime * 0.15, 4),
        fbm(p + 4.0 * q + vec2(8.3, 2.8) + uTime * 0.126, 4)
    );

    return fbm(p + 4.0 * r, 6);
}

void main() {
    vec2 uv = vUv * 3.0;
    float cloud = cloudNoise(uv);
    cloud = smoothstep(0.3, 0.7, cloud);  // 增加对比度

    vec3 skyColor = vec3(0.4, 0.6, 0.9);
    vec3 cloudColor = vec3(1.0);
    vec3 color = mix(skyColor, cloudColor, cloud);

    gl_FragColor = vec4(color, 1.0);
}
```

### 5.2 地形生成

```glsl
float terrainHeight(vec2 p) {
    // 多层噪声叠加，模拟不同尺度的地形特征
    float height = 0.0;

    // 大尺度：山脉轮廓
    height += fbm(p * 0.5, 4) * 100.0;

    // 中尺度：丘陵
    height += fbm(p * 2.0, 4) * 20.0;

    // 小尺度：地表细节
    height += fbm(p * 8.0, 3) * 5.0;

    return height;
}

void main() {
    vec2 worldPos = vUv * 100.0;
    float h = terrainHeight(worldPos);

    // 基于高度着色
    vec3 color;
    if (h < 10.0) {
        color = vec3(0.2, 0.5, 0.8);  // 水
    } else if (h < 30.0) {
        color = vec3(0.2, 0.7, 0.3);  // 草地
    } else if (h < 60.0) {
        color = vec3(0.5, 0.4, 0.3);  // 岩石
    } else {
        color = vec3(0.9, 0.9, 0.95); // 雪
    }

    gl_FragColor = vec4(color, 1.0);
}
```

### 5.3 木纹纹理

```glsl
float woodPattern(vec2 p) {
    // 基础噪声扭曲
    vec2 q = p + vec2(
        fbm(p * 2.0, 3) * 0.5,
        fbm(p * 2.0 + vec2(5.2, 1.3), 3) * 0.5
    );

    // 环形纹理（模拟木纹）
    float ring = length(q) * 10.0;
    ring += fbm(q * 4.0, 3) * 2.0;  // 噪声扭曲环形

    return fract(ring);
}

void main() {
    vec2 uv = vUv * 2.0;
    float wood = woodPattern(uv);

    vec3 lightWood = vec3(0.8, 0.6, 0.4);
    vec3 darkWood = vec3(0.4, 0.2, 0.1);
    vec3 color = mix(darkWood, lightWood, wood);

    gl_FragColor = vec4(color, 1.0);
}
```

### 5.4 火焰效果

```glsl
uniform float uTime;

float fireNoise(vec2 p) {
    // 时间驱动的向上滚动
    p.y -= uTime * 2.0;

    // 多层 FBM
    float n = fbm(p * 4.0, 5);

    // 添加向上拉伸
    n *= smoothstep(0.0, 0.5, p.y);

    return n;
}

void main() {
    vec2 uv = vUv;

    // 火焰形状（底部宽，顶部窄）
    float shape = 1.0 - uv.y;
    shape *= smoothstep(0.0, 0.3, uv.y);  // 底部平滑
    shape *= smoothstep(1.0, 0.5, uv.y);  // 顶部收窄

    // 噪声扭曲
    float fire = fireNoise(uv);
    fire *= shape;

    // 颜色映射
    vec3 color;
    if (fire > 0.7) {
        color = vec3(1.0, 0.9, 0.5);  // 亮黄色
    } else if (fire > 0.4) {
        color = vec3(1.0, 0.4, 0.1);  // 橙色
    } else if (fire > 0.2) {
        color = vec3(0.8, 0.1, 0.0);  // 红色
    } else {
        color = vec3(0.0);             // 透明
    }

    gl_FragColor = vec4(color, fire);
}
```

## 常见误区

1. **`fract(sin(...))` 的精度问题**：在某些 GPU（尤其是移动端）上，`sin` 函数的精度不足，会导致明显的条纹。重要场景应使用基于整数运算的 hash 函数。

2. **噪声频率过高导致走样**：当噪声频率超过像素密度时，会出现摩尔纹。应使用 `fwidth()` 控制噪声频率，或在高频处使用预过滤的噪声纹理。

3. **FBM 层数过多的性能问题**：每增加一层 FBM，计算量翻倍。移动端通常 4-6 层即可，桌面端可以 8-10 层。

4. **噪声值范围误解**：不同噪声函数的输出范围不同。Perlin Noise 原始范围是 [-1, 1]，Value Noise 是 [0, 1]。使用前要确认并归一化。

---

## 工程建议

1. **噪声纹理预计算**：对于不需要动态变化的噪声，可以在 CPU 端或加载时预计算为纹理，通过采样获取。这比在 Shader 中实时计算快得多。

2. **使用 `fwidth()` 控制细节**：在不同距离使用不同频率的噪声，避免远处走样：`float lod = log2(fwidth(uv.x));`

3. **缓存噪声结果**：如果同一像素需要多次使用同一噪声值，先计算并存储到变量中，避免重复计算。

4. **选择合适的噪声类型**：Value Noise 适合柔和的效果（云、雾），Perlin Noise 适合自然纹理（地形、木纹），Simplex Noise 在高频时性能更好。

## 参考答案

### 练习一

**思路**：Simplex Noise 与 Perlin Noise 的核心区别在于网格结构——Simplex 使用单纯形网格（三角形），Perlin 使用正方形网格。Simplex 在高维空间性能更好（2D 中梯度数量从 4 个减少到 3 个），且没有明显的轴对齐伪影。实现时需要理解 skew/unskew 变换。

**答案**：
```glsl
// Simplex Noise 实现
precision mediump float;

// 2D 简单形噪声的 skew 常数
const float F2 = 0.3660254;  // 0.5 * (sqrt(3.0) - 1.0)
const float G2 = 0.2113249;  // (3.0 - sqrt(3.0)) / 6.0

vec3 mod289(vec3 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; }
vec2 mod289(vec2 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; }
vec3 permute(vec3 x) { return mod289(((x * 34.0) + 1.0) * x); }

// 梯度函数
vec4 taylorInvSqrt(vec4 r) { return 1.79284291400159 - 0.85373472095314 * r; }

float snoise(vec2 v) {
    // Skew 坐标到简单形网格
    vec2 i = floor(v + (v.x + v.y) * F2);
    vec2 x0 = v - i + (i.x + i.y) * G2;

    // 确定在哪个三角形中
    vec2 i1 = (x0.x > x0.y) ? vec2(1.0, 0.0) : vec2(0.0, 1.0);

    // 三个顶点的坐标
    vec2 x1 = x0 - i1 + G2;
    vec2 x2 = x0 - 1.0 + 2.0 * G2;

    // 排列梯度
    i = mod289(i);
    vec3 p = permute(permute(i.y + vec3(0.0, i1.y, 1.0))
                             + i.x + vec3(0.0, i1.x, 1.0));

    // 计算贡献
    vec3 m = max(0.5 - vec3(dot(x0, x0), dot(x1, x1), dot(x2, x2)), 0.0);
    m = m * m;
    m = m * m;

    // 梯度
    vec3 x = 2.0 * fract(p * C.zzz) - 1.0;  // C = vec3(1.0/289.0, 1.0/...) 等
    vec3 h = abs(x) - 0.5;
    vec3 ox = floor(x + 0.5);
    vec3 a0 = x - ox;
    m *= taylorInvSqrt(vec4(a0 * a0 + h * h, 0.0)).xyz;

    // 求和
    vec3 g;
    g.x = dot(a0, x0);
    g.y = dot(vec2(a0.x, h.x), x1);  // 注意这里用了 swizzle
    g.z = dot(a0.yz, x2);
    return 130.0 * dot(m, g);
}

// 对比测试
void main() {
    vec2 uv = gl_FragCoord.xy / uResolution * 4.0;

    float simplexVal = snoise(uv) * 0.5 + 0.5;
    float perlinVal = cnoise(uv) * 0.5 + 0.5;  // 使用课程中的 Perlin Noise

    // 左半屏显示 Simplex，右半屏显示 Perlin
    vec2 screenUv = gl_FragCoord.xy / uResolution;
    float val = screenUv.x < 0.5 ? simplexVal : perlinVal;
    gl_FragColor = vec4(vec3(val), 1.0);
}
```

**要点**：
- Simplex Noise 的梯度数量为 N+1（2D 中 3 个），Perlin 为 2^N（4 个），计算量更小
- Simplex 没有轴对齐伪影，在高频采样时视觉质量更好
- `F2` 和 `G2` 常数将正方形网格变换为等边三角形网格
- 性能对比：Simplex 在高维（4D+）时优势明显，2D 时两者差异不大

### 练习二

**思路**：大理石纹理的核心是用 FBM 生成扰动值，然后将其作为正弦函数的输入来模拟石头内部的纹路走向。通过颜色映射（深色到浅色的渐变）实现不同深浅的纹路效果。

**答案**：
```glsl
// 程序化大理石纹理
precision mediump float;

uniform float uTime;
uniform vec2 uResolution;

// 基础 hash 和噪声
float hash(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    f = f * f * (3.0 - 2.0 * f);  // smoothstep

    float a = hash(i);
    float b = hash(i + vec2(1.0, 0.0));
    float c = hash(i + vec2(0.0, 1.0));
    float d = hash(i + vec2(1.0, 1.0));

    return mix(mix(a, b, f.x), mix(c, d, f.x), f.y);
}

// FBM
float fbm(vec2 p, int octaves) {
    float value = 0.0;
    float amplitude = 0.5;
    float frequency = 1.0;
    for (int i = 0; i < 6; i++) {
        if (i >= octaves) break;
        value += amplitude * noise(p * frequency);
        frequency *= 2.0;
        amplitude *= 0.5;
    }
    return value;
}

void main() {
    vec2 uv = gl_FragCoord.xy / uResolution;

    // 用 FBM 生成扰动
    float distortion = fbm(uv * 3.0, 6);

    // 用正弦函数模拟大理石纹路
    float vein = sin(uv.x * 20.0 + distortion * 10.0) * 0.5 + 0.5;
    vein = pow(vein, 0.5);  // 增加对比度

    // 颜色映射：深灰 → 白色渐变
    vec3 darkVein = vec3(0.15, 0.1, 0.08);   // 深色纹路
    vec3 lightBase = vec3(0.95, 0.93, 0.90); // 浅色基底
    vec3 midTone = vec3(0.6, 0.55, 0.5);     // 中间色

    vec3 color = mix(darkVein, midTone, vein);
    color = mix(color, lightBase, smoothstep(0.3, 0.7, vein));

    // 添加一些细微的噪声纹理
    float detail = noise(uv * 50.0) * 0.05;
    color += vec3(detail);

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- `sin(x + distortion)` 中的 `distortion` 使直线纹路弯曲，模拟天然石头纹理
- `pow(vein, 0.5)` 使纹路更集中（亮部更亮），增加对比度
- 多层颜色映射（`darkVein → midTone → lightBase`）比简单双色更自然

### 练习三

**思路**：水面效果的核心是用噪声扰动法线，模拟波浪对光线的散射。Fresnel 效果控制反射和折射的比例——正对水面时看到水下（折射），掠射角度看到反射。关键是用 FBM 驱动法线贴图的 UV 偏移。

**答案**：
```glsl
// 噪声水面 - 顶点着色器
uniform mat4 uModelMatrix;
uniform mat4 uViewMatrix;
uniform mat4 uProjectionMatrix;

attribute vec3 aPosition;

varying vec3 vWorldPos;
varying vec2 vUv;

void main() {
    vec4 worldPos = uModelMatrix * vec4(aPosition, 1.0);
    vWorldPos = worldPos.xyz;
    vUv = aPosition.xz * 0.5 + 0.5;  // 世界 XZ 平面作为 UV
    gl_Position = uProjectionMatrix * uViewMatrix * worldPos;
}
```

```glsl
// 噪声水面 - 片元着色器
precision mediump float;

uniform float uTime;
uniform vec3 uCameraPos;
uniform samplerCube uEnvMap;
uniform vec3 uWaterShallow;  // 浅水颜色
uniform vec3 uWaterDeep;     // 深水颜色

varying vec3 vWorldPos;
varying vec2 vUv;

// 噪声函数（简化版）
float noise(vec2 p) { /* ... 同前 ... */ }
float fbm(vec2 p) {
    float v = 0.0, a = 0.5;
    for (int i = 0; i < 5; i++) {
        v += a * noise(p); p *= 2.0; a *= 0.5;
    }
    return v;
}

void main() {
    vec2 uv = vUv;

    // 用噪声扰动 UV（模拟波浪）
    float t = uTime * 0.3;
    vec2 distortedUv = uv + vec2(
        fbm(uv * 4.0 + vec2(t, 0.0)),
        fbm(uv * 4.0 + vec2(0.0, t))
    ) * 0.1;

    // 从扰动后的噪声计算法线
    float eps = 0.01;
    float h0 = fbm(distortedUv * 8.0);
    float hx = fbm((distortedUv + vec2(eps, 0.0)) * 8.0);
    float hz = fbm((distortedUv + vec2(0.0, eps)) * 8.0);
    vec3 normal = normalize(vec3(h0 - hx, eps, h0 - hz));

    // 视线方向和 Fresnel
    vec3 viewDir = normalize(uCameraPos - vWorldPos);
    float cosTheta = max(dot(normal, viewDir), 0.0);
    float fresnel = pow(1.0 - cosTheta, 3.0);

    // 反射和折射
    vec3 reflectDir = reflect(-viewDir, normal);
    vec3 reflectColor = textureCube(uEnvMap, reflectDir).rgb;

    // 水底颜色（深度衰减）
    vec3 waterColor = mix(uWaterShallow, uWaterDeep, 0.6);

    // 最终颜色
    vec3 color = mix(waterColor, reflectColor, fresnel);

    // 高光
    vec3 lightDir = normalize(vec3(1.0, 1.0, 0.5));
    float specular = pow(max(dot(reflect(-lightDir, normal), viewDir), 0.0), 128.0);
    color += vec3(1.0) * specular * 0.5;

    gl_FragColor = vec4(color, 0.9);
}
```

**要点**：
- 用 FBM 驱动 UV 偏移（而非直接驱动颜色），产生自然的波浪扭曲效果
- 有限差分法计算法线：`normal = (h-center, eps, h-center)`，eps 越小法线越精细
- Fresnel 和立方体贴图反射的组合是水面渲染的标准方案
- 时间参数 `uTime * 0.3` 控制波浪移动速度，值越小越平静

### 练习四

**思路**：星空背景的核心是用多层噪声生成不同大小的星星，每层代表不同尺度的星群。闪烁动画通过 `sin(uTime + random)` 使每颗星星以不同频率和相位闪烁。关键是用 `step` 将连续噪声变成离散的亮点。

**答案**：
```glsl
// 程序化星空背景
precision mediump float;

uniform float uTime;
uniform vec2 uResolution;

float hash(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    f = f * f * (3.0 - 2.0 * f);
    return mix(
        mix(hash(i), hash(i + vec2(1, 0)), f.x),
        mix(hash(i + vec2(0, 1)), hash(i + vec2(1, 1)), f.x),
        f.y
    );
}

// 单层星星
float starLayer(vec2 uv, float size, float brightness) {
    vec2 grid = floor(uv);
    vec2 f = fract(uv) - 0.5;

    // 每个格子中随机位置的星星
    vec2 starPos = vec2(hash(grid) - 0.5, hash(grid + 100.0) - 0.5) * 0.8;
    float dist = length(f - starPos);

    // 闪烁：每颗星星有独立的随机相位
    float twinkle = sin(uTime * (2.0 + hash(grid + 200.0) * 3.0)
                        + hash(grid + 300.0) * 6.28) * 0.3 + 0.7;

    // 星星的形状（高斯衰减）
    float star = smoothstep(size, size * 0.2, dist) * brightness * twinkle;

    return star;
}

void main() {
    vec2 uv = (gl_FragCoord.xy - 0.5 * uResolution) / uResolution.y;

    // 深空背景
    vec3 color = vec3(0.02, 0.02, 0.05);

    // 多层星星（从小到大）
    color += vec3(0.8, 0.85, 1.0) * starLayer(uv * 80.0, 0.03, 0.5);   // 小星星（密集）
    color += vec3(1.0, 0.95, 0.8) * starLayer(uv * 40.0, 0.05, 0.8);   // 中星星
    color += vec3(1.0, 0.9, 0.7) * starLayer(uv * 20.0, 0.08, 1.0);    // 大星星（稀疏）

    // 星云（用 FBM 生成）
    float nebula = noise(uv * 3.0 + uTime * 0.01);
    nebula = pow(nebula, 3.0) * 0.3;
    color += vec3(0.2, 0.1, 0.3) * nebula;

    // 偶尔的亮星（特别大的亮度）
    float brightStar = starLayer(uv * 15.0, 0.12, 1.5);
    color += vec3(1.0, 0.98, 0.95) * brightStar * step(0.95, hash(floor(uv * 15.0)));

    gl_FragColor = vec4(color, 1.0);
}
```

**要点**：
- 每层使用不同的 UV 缩放（`* 80.0`、`* 40.0`、`* 20.0`）控制星星密度
- 闪烁公式 `sin(time * freq + phase)` 中，`freq` 和 `phase` 都用 hash 随机化
- `smoothstep(size, size * 0.2, dist)` 控制星星的大小和柔化程度
- 星云效果叠加在星星下方，增加画面层次感
