# 毕业项目：程序化世界生成器

## 项目概述

构建一个可探索的程序化生成世界，包含地形、生物群落、植被、建筑和天气系统。玩家可以在无限扩展的世界中自由移动探索，体验每次生成都不同的地貌。

## 技术栈

- **渲染**：Three.js 或 WebGL 2
- **框架**：TypeScript
- **构建**：Vite
- **噪声**：Simplex Noise / Perlin Noise（自实现或 snoise 库）
- **UI**：HTML + CSS（HUD 信息面板）

## 核心功能

### 1. 地形生成

- 多层噪声叠加：大陆架 → 山脉 → 丘陵 → 细节
- 高度图 → 网格转换（Chunk 机制）
- Chunk 大小可配（如 64x64），支持至少 5x5 Chunk 可视化
- LOD（Level of Detail）：远处 Chunk 降低精度
- 地形着色：高度分层着色（海洋 → 沙滩 → 草地 → 岩石 → 雪）

### 2. 生物群落系统

- 温度 + 湿度双轴映射 → 生物群落类型
- 生物群落：海洋、沙漠、草原、森林、针叶林、苔原、热带雨林
- 每个群落有专属配色、植被密度、地形特征
- 群落边界自然过渡（不是硬切）

### 3. 植被系统

- 程序化树木：L-System 或参数化树干 + 树冠
- 草地：Instanced Mesh + 风吹摆动着色器
- 植被密度由生物群落 + 坡度 + 海拔决定
- 岩石、花丛等装饰物随机分布

### 4. 水体系统

- 海洋：平面 + 波浪着色器 + 反射
- 河流：沿地形低洼路径生成
- 湖泊：封闭低洼区域积水
- 水面透明度随深度变化

### 5. 建筑/结构生成

- 村庄：在平坦区域放置房屋
- 房屋：程序化生成（矩形主体 + 屋顶 + 门窗）
- 道路：连接村庄的路径（A* 沿地形寻路）
- 遗迹/地标：特殊兴趣点随机放置

### 6. 天气与时间系统

- 日夜循环：太阳位置变化 + 光照变化
- 天空盒：渐变 + 星空 + 月亮
- 雾效：距离雾 + 高度雾
- 天气状态：晴天、阴天、雨天（粒子效果）

### 7. 无限加载

- 视距 Chunk 管理：只加载玩家周围的 Chunk
- 异步生成：新 Chunk 在后台线程生成（Web Worker）
- Chunk 回收：远离玩家的 Chunk 释放资源
- 种子控制：相同种子生成相同世界

### 8. 玩家控制

- 第一人称或俯视角相机
- WASD 移动 + 鼠标视角控制
- 小地图：显示周围地形缩略图
- 坐标显示 + 生物群落名称

## 验收标准

```bash
cd frontend/procedural-world-generation/final-project
node scripts/check.cjs
```

验证项：

- [ ] 地形生成：多层噪声产生自然地貌
- [ ] 生物群落：至少 5 种群落，边界自然过渡
- [ ] 植被：树木和草地在合适区域生成
- [ ] 水体：海洋/河流可见，有波浪效果
- [ ] 建筑：至少村庄和道路系统
- [ ] 无限加载：移动时新 Chunk 自动加载，FPS > 30
- [ ] 种子控制：相同种子生成相同世界
- [ ] 日夜循环和天气效果可见
