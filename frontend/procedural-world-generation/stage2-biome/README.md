# 第二阶段：生物群落

在地形基础上添加生命——基于温度和湿度生成不同生物群落，放置植被、生成水体、添加天气效果，构建一个多生态的世界。

## 验收标准

- 能根据温度和湿度映射不同 Biome（森林、沙漠、雪地等）
- 能基于气候数据程序化放置植被
- 能生成河流、湖泊等水体
- 能实现云、雾、雨、雪等天气视觉效果
- 完成多生物群落世界，不同区域有明显的生态差异
