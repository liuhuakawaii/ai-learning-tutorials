# 程序化世界生成

> 用代码生成一个可探索的世界——地形、生物群落、洞穴、植被、城市。

## 适合谁

- 想理解 Minecraft/No Man's Sky 的世界是怎么用代码生成的
- 想构建自己的程序化生成游戏或交互式体验
- 对噪声算法、分形、细胞自动机在游戏中的应用感兴趣

## 学完能做什么

- 用噪声算法生成地形（高度图、侵蚀模拟）
- 生成不同的生物群落（森林、沙漠、雪地）
- 用细胞自动机生成洞穴系统
- 实现无限世界的 Chunk 加载与卸载
- 构建一个可探索的程序化 3D 世界

## 学习路线

### 第一阶段：地形生成

1. 噪声基础——Perlin/Simplex/Worley 噪声的工程实现
2. 高度图生成——多层噪声叠加、Domain Warping
3. 地形特征——山峰、山谷、平原、海岸线的生成
4. 侵蚀模拟——热力侵蚀、水力侵蚀的简化实现
5. 阶段实战：生成一个有山有水的地形并渲染

### 第二阶段：生物群落

6. 温度与湿度——气候模型、Biome 映射
7. 植被分布——基于气候的植被生成、树木放置
8. 水体生成——河流、湖泊、海洋的程序化生成
9. 天气系统——云、雾、雨、雪的视觉效果
10. 阶段实战：生成一个有多生物群落的世界

### 第三阶段：结构生成

11. 洞穴系统——Cellular Automata、3D 洞穴网络
12. 废墟与建筑——程序化建筑生成、损坏效果
13. 道路网络——路径生成、A* 路径规划
14. NPC 与生物——程序化行为、生态系统模拟
15. 阶段实战：在世界中生成洞穴和建筑

### 第四阶段：无限世界

16. Chunk 系统——分块加载/卸载、LOD 管理
17. 种子系统——确定性生成、种子分享
18. 异步生成——Worker 线程、生成队列、平滑过渡
19. 世界种子编辑——参数化控制、预览系统
20. 阶段实战：实现一个无限可探索的世界

### 第五阶段：渲染与交互

21. 体素渲染——Marching Cubes、Greedy Meshing
22. 地形渲染——多层纹理、法线贴图、视差映射
23. 植被渲染——Billboard、实例化、风吹动画
24. 玩家交互——移动、碰撞、挖掘、建造
25. 阶段实战：构建一个完整的程序化世界探索体验
