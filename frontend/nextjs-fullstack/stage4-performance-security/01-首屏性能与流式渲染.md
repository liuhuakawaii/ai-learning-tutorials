# 首屏性能与流式渲染

## 问题

用户打开页面，浏览器要等服务端渲染完所有内容才能开始显示。如果某个组件的数据查询很慢（比如 2 秒），整个页面都要等 2 秒。

## 流式渲染的解决方案

Next.js 支持流式渲染：先把已经准备好的部分发给浏览器，慢的部分准备好了再补上。

```tsx
import { Suspense } from 'react'

export default function DashboardPage() {
  return (
    <div>
      <h1>Dashboard</h1>
      {/* 这部分立即渲染 */}
      <QuickStats />

      {/* 这部分等数据准备好后再渲染 */}
      <Suspense fallback={<ChartSkeleton />}>
        <SlowChart />
      </Suspense>

      <Suspense fallback={<ActivitySkeleton />}>
        <RecentActivity />
      </Suspense>
    </div>
  )
}
```

浏览器收到的 HTML 是分块的：先显示标题和快速统计，图表和活动列表的位置显示骨架屏，数据准备好后再替换。

## loading.tsx

Next.js 的 `loading.tsx` 是 Suspense 的语法糖：

```tsx
// app/(admin)/dashboard/loading.tsx
export default function DashboardLoading() {
  return (
    <div className="space-y-6 animate-pulse">
      <div className="h-8 w-48 bg-gray-200 rounded"></div>
      <div className="grid grid-cols-4 gap-4">
        {[1,2,3,4].map(i => <div key={i} className="h-24 bg-gray-200 rounded"></div>)}
      </div>
    </div>
  )
}
```

## Server Components 的数据获取

Server Components 可以直接 `await`，Next.js 会自动并行化没有依赖关系的请求：

```tsx
export default async function Dashboard() {
  // 这两个请求并行执行
  const [stats, activities] = await Promise.all([
    getStats(),        // 200ms
    getActivities(),   // 300ms
  ])
  // 总耗时约 300ms，不是 500ms
}
```

## 部分预渲染（PPR）

Next.js 15 支持 PPR：页面的静态部分在构建时生成，动态部分在请求时流式渲染。

```tsx
export default async function ProductPage({ params }) {
  const product = await getProduct(params.id) // 静态部分

  return (
    <div>
      <h1>{product.name}</h1>
      <p>{product.description}</p>

      {/* 动态部分：价格可能变化 */}
      <Suspense fallback={<PriceSkeleton />}>
        <DynamicPrice productId={params.id} />
      </Suspense>
    </div>
  )
}
```

## 图片优化

```tsx
import Image from 'next/image'

<Image
  src="/hero.jpg"
  alt="Hero"
  width={1200}
  height={600}
  priority              // 首屏图片，预加载
  placeholder="blur"    // 加载时显示模糊占位
  blurDataURL={blurHash}
/>

// 远程图片需要配置域名
// next.config.js
module.exports = {
  images: {
    remotePatterns: [{ hostname: 'cdn.example.com' }],
  },
}
```

`next/image` 自动处理：响应式尺寸、WebP/AVIF 转换、懒加载、占位符。

## 字体优化

```tsx
import { Inter } from 'next/font/google'

const inter = Inter({ subsets: ['latin'] })

export default function RootLayout({ children }) {
  return (
    <html lang="zh" className={inter.className}>
      <body>{children}</body>
    </html>
  )
}
```

`next/font` 在构建时下载字体并自托管，消除 CLS（布局偏移）。

## 脚本优化

```tsx
import Script from 'next/script'

// 第三方脚本加载策略
<Script src="https://analytics.example.com/script.js" strategy="lazyOnload" />
<Script src="https://chat.example.com/widget.js" strategy="afterInteractive" />
<Script src="/critical.js" strategy="beforeInteractive" />
```

| strategy | 时机 | 适用场景 |
|----------|------|----------|
| `beforeInteractive` | 页面可交互前 | 关键脚本 |
| `afterInteractive` | 页面可交互后 | 分析、聊天 |
| `lazyOnload` | 空闲时 | 非关键脚本 |

### 练习三

```bash
npx lighthouse http://localhost:3000 --output html --output-path ./report.html
```

常见问题和修复：
- FCP 慢 → 检查是否阻塞渲染的脚本太多
- LCP 慢 → 给首屏大图加 `priority`
- CLS 高 → 给图片和字体设置明确尺寸
