# 第二课：搜索、筛选、排序、分页

## 场景引入

你的项目管理工具有了几十个项目，用户开始抱怨"找不到我上周创建的那个项目"。你发现项目列表只有简单的分页，没有搜索、没有筛选、没有排序。用户要翻好几页才能找到目标项目，体验极差。你决定加上这些功能，但很快遇到了新问题：搜索词在页面刷新后丢失了、筛选条件无法通过链接分享给同事、搜索和分页的组合逻辑搞混了。你需要一套基于 URL 参数的状态管理方案，让搜索、筛选、排序、分页的状态都能持久化、可分享、可回退。

## 学习目标

完成本课学习后，你将能够：

1. 实现服务端搜索功能
2. 使用 URL 参数管理筛选状态
3. 实现排序功能
4. 实现分页组件
5. 组合搜索、筛选、排序和分页

## 一、URL 参数管理

### 1.1 为什么用 URL 参数

```
✅ 使用 URL 参数：
  - 用户可以分享搜索结果链接
  - 浏览器前进/后退可用
  - 刷新页面状态保持
  - SEO 友好

❌ 使用 state：
  - 刷新页面状态丢失
  - 无法分享链接
  - 浏览器前进/后退失效
```

## 二、搜索功能

### 2.1 搜索表单

```tsx
// components/SearchBar.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'
import { useState } from 'react'

export function SearchBar({ placeholder }: { placeholder?: string }) {
  const router = useRouter()
  const searchParams = useSearchParams()
  const [query, setQuery] = useState(searchParams.get('q') || '')

  function handleSearch(e: React.FormEvent) {
    e.preventDefault()
    const params = new URLSearchParams(searchParams.toString())

    if (query) {
      params.set('q', query)
    } else {
      params.delete('q')
    }

    params.delete('page') // 搜索时重置页码
    router.push(`?${params.toString()}`)
  }

  return (
    <form onSubmit={handleSearch} className="flex gap-2">
      <input
        type="text"
        value={query}
        onChange={e => setQuery(e.target.value)}
        placeholder={placeholder || '搜索...'}
        className="flex-1 px-4 py-2 border rounded"
      />
      <button
        type="submit"
        className="px-4 py-2 bg-blue-500 text-white rounded"
      >
        搜索
      </button>
    </form>
  )
}
```

```tsx
      <ul>

          <li key={project.id}>{project.name}</li>
        ))}

  )
}
```

## 三、筛选功能

### 3.1 筛选组件

```tsx
// components/FilterBar.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'

interface FilterOption {
  label: string
  value: string
}

interface FilterBarProps {
  filters: {
    name: string
    label: string
    options: FilterOption[]
  }[]
}

export function FilterBar({ filters }: FilterBarProps) {
  const router = useRouter()
  const searchParams = useSearchParams()

  function handleChange(name: string, value: string) {
    const params = new URLSearchParams(searchParams.toString())

    if (value) {
      params.set(name, value)
    } else {
      params.delete(name)
    }

    params.delete('page')
    router.push(`?${params.toString()}`)
  }

  return (
    <div className="flex gap-4 flex-wrap">
      {filters.map(filter => (
        <select
          key={filter.name}
          value={searchParams.get(filter.name) || ''}
          onChange={e => handleChange(filter.name, e.target.value)}
          className="px-3 py-2 border rounded"
        >
          <option value="">{filter.label}</option>
          {filter.options.map(option => (
            <option key={option.value} value={option.value}>
              {option.label}
            </option>
          ))}
        </select>
      ))}
    </div>
  )
}
```

```tsx
interface SortOption {
  label: string
  value: string
}

export function SortSelect({ options }: { options: SortOption[] }) {
  const router = useRouter()
  const searchParams = useSearchParams()

    >

  )
}
```

## 五、分页功能

### 5.1 分页组件

```tsx
// components/Pagination.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'

interface PaginationProps {
  totalPages: number
  currentPage: number
}

export function Pagination({ totalPages, currentPage }: PaginationProps) {
  const router = useRouter()
  const searchParams = useSearchParams()

  function goToPage(page: number) {
    const params = new URLSearchParams(searchParams.toString())
    params.set('page', String(page))
    router.push(`?${params.toString()}`)
  }

  if (totalPages <= 1) return null

  return (
    <div className="flex justify-center gap-2 mt-6">
      <button
        onClick={() => goToPage(currentPage - 1)}
        disabled={currentPage <= 1}
        className="px-3 py-1 border rounded disabled:opacity-50"
      >
        上一页
      </button>

      {Array.from({ length: totalPages }, (_, i) => i + 1)
        .filter(page => {
          // 显示当前页附近的页码
          return Math.abs(page - currentPage) <= 2 || page === 1 || page === totalPages
        })
        .map((page, index, array) => {
          // 添加省略号
          const showEllipsis = index > 0 && page - array[index - 1] > 1

          return (
            <span key={page}>
              {showEllipsis && <span className="px-2">...</span>}
              <button
                onClick={() => goToPage(page)}
                className={`px-3 py-1 border rounded ${
                  page === currentPage ? 'bg-blue-500 text-white' : ''
                }`}
              >
                {page}
              </button>
            </span>
          )
        })}

      <button
        onClick={() => goToPage(currentPage + 1)}
        disabled={currentPage >= totalPages}
        className="px-3 py-1 border rounded disabled:opacity-50"
      >
        下一页
      </button>
    </div>
  )
}
```

```tsx
// app/projects/page.tsx
import { prisma } from '@/lib/prisma'
import { SearchBar } from '@/components/SearchBar'
import { FilterBar } from '@/components/FilterBar'
import { SortSelect } from '@/components/SortSelect'
import { Pagination } from '@/components/Pagination'
import { EmptyState } from '@/components/EmptyState'

export default async function ProjectsPage({
  searchParams
}: {
  searchParams: Promise<{
    q?: string
    status?: string
    sort?: string
    page?: string
  }>
}) {
  const { q, status, sort, page: pageStr } = await searchParams
  const page = Math.max(1, parseInt(pageStr || '1'))
  const pageSize = 10

  // 构建查询条件
  const where = {
    AND: [
      q ? {
        OR: [
          { name: { contains: q, mode: 'insensitive' as const } },
          { description: { contains: q, mode: 'insensitive' as const } },
        ]
      } : {},
      status ? { status } : {},
    ]
  }

  // 构建排序
  const orderBy = (() => {
    switch (sort) {
      case 'name': return { name: 'asc' as const }

      default: return { createdAt: 'desc' as const }
    }
  })()

  // 查询数据
  const [projects, totalCount] = await Promise.all([
    prisma.project.findMany({
      where,
      orderBy,
      skip: (page - 1) * pageSize,
      take: pageSize,
    }),
    prisma.project.count({ where }),
  ])

  const totalPages = Math.ceil(totalCount / pageSize)

  return (
    <div>
      <h2 className="text-2xl font-bold mb-6">项目列表</h2>

      {/* 工具栏 */}
      <div className="flex flex-wrap gap-4 mb-6">
        <div className="flex-1 min-w-[200px]">
          <SearchBar placeholder="搜索项目..." />
        </div>
        <FilterBar
          filters={[
            {
              name: 'status',
              label: '状态',

                { label: '进行中', value: 'active' },

            { label: '最新创建', value: 'newest' },

          ]}
        />
      </div>

      {/* 结果统计 */}
      <p className="text-sm text-gray-500 mb-4">
        共 {totalCount} 个项目

        <EmptyState
          icon="📁"
          title="没有找到项目"

              <h3 className="font-medium">{project.name}</h3>
              <p className="text-gray-500 text-sm">{project.description}</p>
            </div>
          ))}
        </div>
      )}

      {/* 分页 */}
      <Pagination totalPages={totalPages} currentPage={page} />
    </div>
  )
```

## 参考答案

### 练习一：实现项目搜索

**思路**：搜索功能的核心是 URL 参数驱动——搜索词存在 URL 的 `q` 参数中，服务端从 `searchParams` 读取并构建 Prisma 查询条件。搜索时必须重置页码，否则用户在第 5 页搜索可能看到空结果。

**答案**：

```tsx
// components/ProjectSearchBar.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'
import { useState, useTransition } from 'react'

export function ProjectSearchBar() {
  const router = useRouter()
  const searchParams = useSearchParams()
  const [query, setQuery] = useState(searchParams.get('q') || '')
  const [isPending, startTransition] = useTransition()

  function handleSearch(e: React.FormEvent) {
    e.preventDefault()
    const trimmed = query.trim()

    startTransition(() => {
      const params = new URLSearchParams(searchParams.toString())
      if (trimmed) {
        params.set('q', trimmed)
      } else {
        params.delete('q')
      }
      params.delete('page')
      router.push(`/projects?${params.toString()}`)
    })
  }

  function handleClear() {
    setQuery('')
    startTransition(() => {
      const params = new URLSearchParams(searchParams.toString())
      params.delete('q')
      params.delete('page')
      router.push(`/projects?${params.toString()}`)
    })
  }

  return (
    <form onSubmit={handleSearch} className="flex gap-2">
      <div className="relative flex-1">
        <input
          type="text"
          value={query}
          onChange={e => setQuery(e.target.value)}
          placeholder="搜索项目名称或描述..."
          className="w-full px-4 py-2 pr-8 border rounded"
        />
        {query && (
          <button
            type="button"
            onClick={handleClear}
            className="absolute right-2 top-1/2 -translate-y-1/2 text-gray-400 hover:text-gray-600"
          >
            ✕
          </button>
        )}
      </div>
      <button
        type="submit"
        disabled={isPending}
        className="px-4 py-2 bg-blue-500 text-white rounded disabled:opacity-50"
      >
        {isPending ? '搜索中...' : '搜索'}
      </button>
    </form>
  )
}
```

**要点**：
- 用 `useTransition` 包裹路由更新，避免输入框在搜索过程中卡顿
- 清除按钮（✕）让用户可以快速重置搜索，体验更好
- 服务端用三元表达式构建 `where`：有搜索词时用 `OR` 模糊匹配，没有时传空对象查全部
- 搜索结果数量提示帮助用户了解搜索效果

### 练习二：实现多条件筛选

**思路**：多条件筛选的关键是把所有筛选参数统一存在 URL 中，用 `AND` 组合多个 Prisma 条件。每个筛选条件的变更都独立更新对应的 URL 参数，并重置页码。日期范围筛选需要两个参数（`from` 和 `to`），用 `z.coerce` 做类型转换。

**答案**：

```tsx
// app/projects/page.tsx（筛选条件构建部分）
import { prisma } from '@/lib/prisma'
import { getSession } from '@/lib/session'

export default async function ProjectsPage({
  searchParams
}: {
  searchParams: Promise<{
    q?: string
    status?: string
    creator?: string
    from?: string
    to?: string
    page?: string
  }>
}) {
  const { q, status, creator, from, to, page: pageStr } = await searchParams
  const session = await getSession()
  const page = Math.max(1, parseInt(pageStr || '1'))
  const pageSize = 10

  const conditions: any[] = []

  if (q?.trim()) {
    conditions.push({
      OR: [
        { name: { contains: q.trim(), mode: 'insensitive' } },
        { description: { contains: q.trim(), mode: 'insensitive' } },
      ]
    })
  }

  if (status) {
    conditions.push({ status })
  }

  if (creator === 'me' && session?.userId) {
    conditions.push({ creatorId: session.userId })
  } else if (creator === 'others' && session?.userId) {
    conditions.push({ creatorId: { not: session.userId } })
  }

  if (from || to) {
    const dateCondition: any = {}
    if (from) dateCondition.gte = new Date(from)
    if (to) dateCondition.lte = new Date(to + 'T23:59:59.999Z')
    conditions.push({ createdAt: dateCondition })
  }

  const where = conditions.length > 0 ? { AND: conditions } : {}

  const [projects, totalCount] = await Promise.all([
    prisma.project.findMany({
      where,
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * pageSize,
      take: pageSize,
    }),
    prisma.project.count({ where }),
  ])

  const totalPages = Math.ceil(totalCount / pageSize)

  return (
    <div>
      <h2 className="text-2xl font-bold mb-6">项目列表</h2>
      <ProjectFilterBar />
      <p className="text-sm text-gray-500 mt-4 mb-4">共 {totalCount} 个项目</p>
      <ul className="space-y-3">
        {projects.map(project => (
          <li key={project.id} className="p-4 bg-white border rounded">
            <h3 className="font-medium">{project.name}</h3>
          </li>
        ))}
      </ul>
      <Pagination totalPages={totalPages} currentPage={page} />
    </div>
  )
}
```

**要点**：
- 用数组 `conditions` 动态构建 Prisma `where` 条件，只在有值时才添加对应条件
- 日期范围的 `to` 参数要补 `T23:59:59.999Z`，否则只匹配当天 0 点
- "清除筛选"按钮只在有筛选条件时显示，一次性清空所有筛选参数
- 每个筛选条件变更都独立更新对应参数，保留其他参数不变

### 练习三：实现分页

**思路**：分页组件需要处理三个核心问题：页码计算（当前页、总页数）、边界禁用（第一页禁用"上一页"、最后一页禁用"下一页"）、页码省略（总页数多时只显示当前页附近的页码）。URL 参数驱动确保分页状态可分享。

**答案**：

```tsx
// components/Pagination.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'

interface PaginationProps {
  totalPages: number
  currentPage: number
  siblingCount?: number
}

export function Pagination({ totalPages, currentPage, siblingCount = 2 }: PaginationProps) {
  const router = useRouter()
  const searchParams = useSearchParams()

  if (totalPages <= 1) return null

  function goToPage(page: number) {
    const params = new URLSearchParams(searchParams.toString())
    params.set('page', String(page))
    router.push(`?${params.toString()}`)
  }

  function getPageNumbers(): (number | 'ellipsis')[] {
    const pages: (number | 'ellipsis')[] = []
    const leftSibling = Math.max(currentPage - siblingCount, 1)
    const rightSibling = Math.min(currentPage + siblingCount, totalPages)

    if (leftSibling > 1) {
      pages.push(1)
      if (leftSibling > 2) {
        pages.push('ellipsis')
      }
    }

    for (let i = leftSibling; i <= rightSibling; i++) {
      pages.push(i)
    }

    if (rightSibling < totalPages) {
      if (rightSibling < totalPages - 1) {
        pages.push('ellipsis')
      }
      pages.push(totalPages)
    }

    return pages
  }

  const pages = getPageNumbers()

  return (
    <nav className="flex justify-center items-center gap-1 mt-8" aria-label="分页导航">
      <button
        onClick={() => goToPage(currentPage - 1)}
        disabled={currentPage <= 1}
        className="px-3 py-2 text-sm border rounded hover:bg-gray-50 disabled:opacity-50 disabled:cursor-not-allowed"
        aria-label="上一页"
      >
        ← 上一页
      </button>

      {pages.map((page, index) =>
        page === 'ellipsis' ? (
          <span key={`ellipsis-${index}`} className="px-2 py-2 text-gray-400">
            ...
          </span>
        ) : (
          <button
            key={page}
            onClick={() => goToPage(page)}
            className={`px-3 py-2 text-sm border rounded min-w-[36px] ${
              page === currentPage
                ? 'bg-blue-500 text-white border-blue-500'
                : 'hover:bg-gray-50'
            }`}
            aria-label={`第 ${page} 页`}
            aria-current={page === currentPage ? 'page' : undefined}
          >
            {page}
          </button>
        )
      )}

      <button
        onClick={() => goToPage(currentPage + 1)}
        disabled={currentPage >= totalPages}
        className="px-3 py-2 text-sm border rounded hover:bg-gray-50 disabled:opacity-50 disabled:cursor-not-allowed"
        aria-label="下一页"
      >
        下一页 →
      </button>

      <span className="ml-4 text-sm text-gray-500">
        第 {currentPage} / {totalPages} 页
      </span>
    </nav>
  )
}
```

## 常见误区

1. **"用 useState 管理搜索状态就行"**：`useState` 在页面刷新后会丢失，无法通过 URL 分享搜索结果，浏览器前进/后退也不能恢复状态。应该用 URL searchParams 管理所有筛选状态。
2. **"搜索时不需要重置页码"**：用户在第 5 页搜索新关键词，如果不重置页码，可能看到空结果（新搜索只有 2 页）。搜索时必须把 `page` 重置为 1。
3. **"Prisma 的 contains 就够搜索了"**：`contains` 做的是子串匹配，不支持分词、权重排序等高级搜索。对于简单场景够用，复杂场景需要引入全文搜索引擎（如 PostgreSQL 的 `tsvector` 或 Meilisearch）。
4. **"分页用 skip/offset 性能没问题"**：`skip(10000)` 数据库仍然要扫描前 10000 条记录。大数据量场景应该用 cursor-based 分页（`cursor` + `take`）。

## 工程建议

1. **用 `URLSearchParams` 统一管理所有筛选参数**：搜索词（`q`）、筛选条件（`status`）、排序（`sort`）、页码（`page`）都存在 URL 中，组件通过 `useSearchParams` 读取。
2. **服务端查询要同时返回数据和总数**：用 `Promise.all([findMany, count])` 并行获取列表数据和总数，总数用于计算总页数。
3. **筛选条件变更时重置页码**：搜索、筛选、排序任何一个变化，都应该把 `page` 重置为 1，避免用户看到空结果或越界页码。
4. **分页组件要处理好边界情况**：第一页时禁用"上一页"按钮，最后一页时禁用"下一页"按钮，总页数为 1 时隐藏分页组件。
