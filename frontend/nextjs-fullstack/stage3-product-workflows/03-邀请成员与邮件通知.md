# 第三课：邀请成员与邮件通知

## 场景引入

你的团队协作工具支持手动添加成员（管理员输入邮箱），但用户反馈"我邀请了同事，他却不知道怎么加入"。你需要一套完整的邀请流程：管理员输入邮箱 → 系统生成唯一邀请链接 → 发送邀请邮件 → 被邀请人点击链接 → 登录或注册 → 自动加入团队。这个流程涉及 token 生成、过期管理、状态流转、邮件发送、邮箱匹配验证等多个环节，任何一个环节出错都会导致邀请失败。

## 学习目标

完成本课学习后，你将能够：

1. 实现邀请链接系统
2. 处理邀请的接受和拒绝
3. 理解邮件发送的基本原理
4. 实现邮件通知功能
5. 处理邀请的过期和重复

## 一、邀请系统设计

### 1.1 邀请流程

```
1. 管理员输入被邀请人邮箱
2. 系统生成邀请链接
3. 发送邀请邮件
4. 被邀请人点击链接
5. 被邀请人登录/注册
6. 自动加入团队
```

### 1.2 数据模型

```prisma
model Invitation {
  id        String   @id @default(cuid())
  email     String
  token     String   @unique
  role      Role     @default(MEMBER)
  status    InvitationStatus @default(PENDING)
  expiresAt DateTime
  createdAt DateTime @default(now())

  team     Team   @relation(fields: [teamId], references: [id], onDelete: Cascade)
  teamId   String
  inviter  User   @relation(fields: [inviterId], references: [id])
  inviterId String

  @@unique([email, teamId])
}

enum InvitationStatus {
  PENDING
  ACCEPTED
  EXPIRED
  REVOKED
}
```

## 二、创建邀请

### 2.1 生成邀请链接

```tsx
// lib/invitation.ts
import crypto from 'crypto'
import { prisma } from './prisma'

export async function createInvitation({
  email,
  teamId,
  inviterId,
  role = 'MEMBER',
}: {
  email: string
  teamId: string
  inviterId: string
  role?: 'ADMIN' | 'MEMBER'
}) {
  // 检查是否已有待处理的邀请
  const existing = await prisma.invitation.findFirst({
    where: {
      email,
      teamId,
      status: 'PENDING',
    }
  })

  if (existing) {
    // 如果未过期，返回现有邀请
    if (existing.expiresAt > new Date()) {
      return { invitation: existing, isNew: false }
    }
    // 如果已过期，更新状态
    await prisma.invitation.update({
      where: { id: existing.id },
      data: { status: 'EXPIRED' }
    })
  }

  // 生成唯一 token
  const token = crypto.randomBytes(32).toString('hex')

  // 设置过期时间（7 天）
  const expiresAt = new Date()
  expiresAt.setDate(expiresAt.getDate() + 7)

  const invitation = await prisma.invitation.create({
    data: {
      email,
      token,
      role,
      expiresAt,
      teamId,
      inviterId,
    }
  })

  return { invitation, isNew: true }
}
```

### 2.2 Server Action

```tsx
// app/teams/[teamId]/actions.ts
'use server'

import { z } from 'zod'
import { revalidatePath } from 'next/cache'
import { prisma } from '@/lib/prisma'
import { requireTeamRole } from '@/lib/permissions'
import { createInvitation } from '@/lib/invitation'
import { sendInvitationEmail } from '@/lib/email'

const InviteSchema = z.object({
  email: z.string().email('邮箱格式不正确'),
  role: z.enum(['ADMIN', 'MEMBER']).default('MEMBER'),
})

export async function inviteMember(teamId: string, prevState: any, formData: FormData) {
  const { userId } = await requireTeamRole(teamId, 'ADMIN')

  const validated = InviteSchema.safeParse({
    email: formData.get('email'),
    role: formData.get('role'),
  })

  if (!validated.success) {
    return { errors: validated.error.flatten().fieldErrors }
  }

  const { email, role } = validated.data

  // 检查用户是否已是成员
  const existingUser = await prisma.user.findUnique({
    where: { email }
  })

  if (existingUser) {
    const isMember = await prisma.membership.findUnique({
      where: {
        userId_teamId: { userId: existingUser.id, teamId }
      }
    })

    if (isMember) {
      return { error: '该用户已是团队成员' }
    }
  }

  // 创建邀请
  const { invitation, isNew } = await createInvitation({
    email,
    teamId,
    inviterId: userId,
    role,
  })

  // 获取团队信息
  const team = await prisma.team.findUnique({
    where: { id: teamId }
  })

  // 发送邀请邮件
  const inviteUrl = `${process.env.NEXT_PUBLIC_URL}/invitations/${invitation.token}`

  await sendInvitationEmail({
    to: email,
    teamName: team!.name,
    inviteUrl,
    expiresInDays: 7,
  })

  revalidatePath(`/teams/${teamId}/members`)

  return {
    success: true,
    message: isNew ? '邀请已发送' : '邀请已重新发送'
  }
}
```

```tsx
    )

  return (

      <div className="max-w-md w-full p-8 bg-white rounded-lg shadow">
        <h1 className="text-2xl font-bold mb-4">团队邀请</h1>
```

### 3.2 接受邀请的 Action

```tsx
// app/invitations/[token]/actions.ts
'use server'

import { prisma } from '@/lib/prisma'
import { getCurrentUser } from '@/lib/auth'
import { revalidatePath } from 'next/cache'
import { redirect } from 'next/navigation'

export async function acceptInvitation(token: string) {
  const user = await getCurrentUser()

  if (!user) {
    redirect(`/login?redirect=/invitations/${token}`)
  }

  const invitation = await prisma.invitation.findUnique({
    where: { token }
  })

  if (!invitation) {
    return { error: '邀请不存在' }
  }

  if (invitation.status !== 'PENDING') {
    return { error: '邀请已处理' }
  }

  if (invitation.expiresAt < new Date()) {
    return { error: '邀请已过期' }
  }

  if (invitation.email !== user.email) {
    return { error: '邮箱不匹配' }
  }

  // 检查是否已是成员
  const existingMember = await prisma.membership.findUnique({
    where: {
      userId_teamId: {
        userId: user.id,
        teamId: invitation.teamId
      }
    }
  })

  if (existingMember) {
    // 更新邀请状态
    await prisma.invitation.update({
      where: { id: invitation.id },
      data: { status: 'ACCEPTED' }
    })
    return { success: true, message: '你已是团队成员' }
  }

  // 添加成员并更新邀请状态
  await prisma.$transaction([
    prisma.membership.create({
      data: {
        userId: user.id,
        teamId: invitation.teamId,
        role: invitation.role,
      }
    }),
    prisma.invitation.update({
      where: { id: invitation.id },
      data: { status: 'ACCEPTED' }
    })
  ])

  revalidatePath(`/teams/${invitation.teamId}`)
  redirect(`/teams/${invitation.teamId}`)
}
```

## 参考答案

### 练习一：实现邀请流程

**思路**：邀请流程的核心是 token 生成 → 邀请页面展示 → 验证并接受。token 必须用 `crypto.randomBytes` 生成不可预测的随机字符串，邀请页面要依次检查 token 有效性、过期状态、登录状态、邮箱匹配，全部通过后才允许接受。

**答案**：

```tsx
// lib/invitation.ts
import crypto from 'crypto'
import { prisma } from './prisma'

export async function createInvitation({
  email,
  teamId,
  inviterId,
  role = 'MEMBER',
}: {
  email: string
  teamId: string
  inviterId: string
  role?: 'ADMIN' | 'MEMBER'
}) {
  const existing = await prisma.invitation.findFirst({
    where: { email, teamId, status: 'PENDING' },
  })

  if (existing) {
    if (existing.expiresAt > new Date()) {
      return { invitation: existing, isNew: false }
    }
    await prisma.invitation.update({
      where: { id: existing.id },
      data: { status: 'EXPIRED' },
    })
  }

  const token = crypto.randomBytes(32).toString('hex')
  const expiresAt = new Date()
  expiresAt.setDate(expiresAt.getDate() + 7)

  const invitation = await prisma.invitation.create({
    data: { email, token, role, expiresAt, teamId, inviterId },
  })

  return { invitation, isNew: true }
}
```

**要点**：
- `crypto.randomBytes(32).toString('hex')` 生成 64 字符的随机 token，不可预测
- 邀请页面依次检查：token 存在 → 未过期 → 状态为 PENDING → 已登录 → 邮箱匹配，每一步都有明确的错误提示
- 未登录用户跳转到登录页并携带 `redirect` 参数，登录后自动回到邀请页面
- 已有待处理邀请时返回现有邀请而非重复创建，避免数据库冗余

### 练习二：处理邀请状态

**思路**：邀请有四种状态（PENDING → ACCEPTED / EXPIRED / REVOKED），需要处理每种状态的转换逻辑。撤销邀请是管理员操作，过期是自动检测，重复邀请通过 `@@unique([email, teamId])` 约束和查询现有记录来处理。

```tsx
function InvitationItem({
  invitation,
  teamId,
  canManage,
}: {
  invitation: Invitation
  teamId: string
  canManage: boolean
}) {
  const [isPending, startTransition] = useTransition()
  const isExpiring = invitation.expiresAt.getTime() - Date.now() < 2 * 24 * 60 * 60 * 1000

  function handleRevoke() {
    if (!confirm(`确定要撤销对 ${invitation.email} 的邀请吗？`)) return

    startTransition(async () => {
      await revokeInvitation(teamId, invitation.id)
    })
  }

    startTransition(async () => {
      await resendInvitation(teamId, invitation.id)
    })
  }

  return (
    <li className="flex justify-between items-center p-3 bg-gray-50 rounded">
      <div>
        <span className="font-medium">{invitation.email}</span>
        <span className="text-xs text-gray-500 ml-2 px-2 py-0.5 bg-gray-200 rounded">
          {invitation.role}
        </span>
        {isExpiring && (
          <span className="text-xs text-orange-500 ml-2">即将过期</span>
        )}
      </div>

      {canManage && (
        <div className="flex gap-2">
          <button
            onClick={handleResend}
            disabled={isPending}
            className="text-sm text-blue-500 hover:text-blue-700 disabled:opacity-50"

            className="text-sm text-red-500 hover:text-red-700 disabled:opacity-50"

            撤销
          </button>
        </div>
      )}
    </li>
  )
}
```

```tsx
'use server'

import { prisma } from '@/lib/prisma'
import { requireTeamRole } from '@/lib/permissions'
import { revalidatePath } from 'next/cache'

export async function revokeInvitation(teamId: string, invitationId: string) {
  await requireTeamRole(teamId, 'ADMIN')

  const invitation = await prisma.invitation.findUnique({
    where: { id: invitationId },
  })

  if (!invitation || invitation.teamId !== teamId) {
    return { error: '邀请不存在' }
  }

  if (invitation.status !== 'PENDING') {
    return { error: '该邀请已处理' }
  }

  await prisma.invitation.update({
    where: { id: invitationId },
    data: { status: 'REVOKED' },
  })

  revalidatePath(`/teams/${teamId}/members`)
  return { success: true }
}

export async function resendInvitation(teamId: string, invitationId: string) {
  await requireTeamRole(teamId, 'ADMIN')

  const invitation = await prisma.invitation.findUnique({
    where: { id: invitationId },
  })

  if (!invitation || invitation.teamId !== teamId) {
    return { error: '邀请不存在' }
  }

  if (invitation.status !== 'PENDING') {
    return { error: '该邀请已处理' }
  }

  const newExpiresAt = new Date()
  newExpiresAt.setDate(newExpiresAt.getDate() + 7)

  await prisma.invitation.update({
    where: { id: invitationId },
    data: { expiresAt: newExpiresAt },
  })

  const team = await prisma.team.findUnique({ where: { id: teamId } })
  const inviteUrl = `${process.env.NEXT_PUBLIC_URL}/invitations/${invitation.token}`

  await sendInvitationEmail({
    to: invitation.email,
    teamName: team!.name,
    inviteUrl,
    expiresInDays: 7,
  })

  revalidatePath(`/teams/${teamId}/members`)
  return { success: true, message: '邀请已重新发送' }
}
```

```tsx
// app/teams/[teamId]/invite/actions.ts（邮件发送集成）
'use server'

import { revalidatePath } from 'next/cache'
import { prisma } from '@/lib/prisma'
import { requireTeamRole } from '@/lib/permissions'
import { createInvitation } from '@/lib/invitation'
import { sendInvitationEmail } from '@/lib/email'

export async function inviteMember(teamId: string, prevState: any, formData: FormData) {
  const { userId } = await requireTeamRole(teamId, 'ADMIN')

  const email = formData.get('email') as string
  const role = (formData.get('role') as string) || 'MEMBER'

  if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    return { errors: { email: ['邮箱格式不正确'] } }
  }

  const existingUser = await prisma.user.findUnique({ where: { email } })
  if (existingUser) {
    const isMember = await prisma.membership.findUnique({
      where: { userId_teamId: { userId: existingUser.id, teamId } },
    })
    if (isMember) {
      return { error: '该用户已是团队成员' }
    }
  }

  const { invitation, isNew } = await createInvitation({
    email,
    teamId,
    inviterId: userId,
    role: role as 'ADMIN' | 'MEMBER',
  })

  const [team, inviter] = await Promise.all([
    prisma.team.findUnique({ where: { id: teamId }, select: { name: true } }),
    prisma.user.findUnique({ where: { id: userId }, select: { name: true } }),
  ])

  const inviteUrl = `${process.env.NEXT_PUBLIC_URL}/invitations/${invitation.token}`

  sendInvitationEmail({
    to: email,
    teamName: team!.name,
    inviteUrl,
    inviterName: inviter!.name || '团队管理员',
    expiresInDays: 7,
  }).catch(err => console.error('邀请邮件发送失败:', err))

  revalidatePath(`/teams/${teamId}/members`)

  return {
    success: true,
    message: isNew ? '邀请已发送' : '邀请已重新发送',
  }
}
```

**要点**：
- 邮件发送用 `.catch()` 异步处理，不阻塞 Server Action 的返回，用户立即看到"邀请已发送"
- HTML 邮件用内联样式（`style` 属性），因为大多数邮件客户端不支持 `<style>` 标签
- 邮件中包含纯文本链接 fallback，某些邮件客户端可能不渲染按钮
- `sendInvitationAcceptedEmail` 在接受邀请成功后通知邀请人，提升协作体验

## 常见误区

1. **"邀请 token 用用户 ID 就行"**：用户 ID 是可预测的，攻击者可以伪造邀请链接。必须用 `crypto.randomBytes(32).toString('hex')` 生成不可预测的随机 token。
2. **"邀请链接永不过期"**：没有过期时间的邀请链接是安全隐患——如果被邀请人的邮箱被盗，攻击者可以用旧的邀请链接加入团队。邀请链接应该设置 7 天过期。
3. **"被邀请人点击链接就直接加入"**：必须验证当前登录用户的邮箱是否和邀请的邮箱匹配。否则攻击者可以拦截邀请链接，用自己的账号加入别人的团队。
4. **"邮件发送失败就不用管了"**：邮件可能因为各种原因发送失败（SMTP 超时、收件方服务器拒绝）。应该有重试机制或至少记录失败日志，让用户知道邀请是否发送成功。

## 工程建议

1. **用 `@@unique([email, teamId])` 防止重复邀请**：同一个邮箱对同一个团队只能有一个待处理的邀请。如果已有待处理邀请，返回现有邀请而不是创建新的。
2. **用事务保证邀请接受的原子性**：创建 Membership 和更新 Invitation 状态应该在同一个 `prisma.$transaction` 中执行，避免一个成功一个失败导致数据不一致。
3. **邀请链接要保存 redirect 参数**：未登录用户点击邀请链接时，跳转到登录页并带上 `?redirect=/invitations/token`，登录成功后自动回到邀请页面。
4. **邮件发送用队列异步处理**：不要在 Server Action 中同步发送邮件，用 Resend 或 Nodemailer 的异步方式，避免邮件发送阻塞用户的操作响应。
