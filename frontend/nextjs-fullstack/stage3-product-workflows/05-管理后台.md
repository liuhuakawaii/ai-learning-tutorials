# 第五课：管理后台

## 场景引入

你的 SaaS 产品有了几百个注册用户和几十个团队，运营团队开始问你：能不能看到最近 7 天注册了多少新用户？能不能封禁一个发送垃圾内容的用户？能不能调整某个团队的套餐？这些操作在用户端的 Dashboard 里是做不了的，你需要一个独立的管理后台——只有管理员能访问，可以查看系统全局数据、管理用户和团队、修改系统配置。管理后台的权限模型和用户端完全不同，你需要区分普通管理员和超级管理员，并且记录所有管理操作以备审计。

## 学习目标

完成本课学习后，你将能够：

1. 设计管理后台的权限模型
2. 实现用户管理功能
3. 实现数据统计和图表
4. 实现系统配置管理
5. 处理管理操作的安全性

```tsx
// lib/admin.ts
import { getCurrentUser } from './auth'
import { redirect } from 'next/navigation'

export async function requireAdmin() {
  const user = await getCurrentUser()

  if (!user || (user.role !== 'ADMIN' && user.role !== 'SUPER_ADMIN')) {
    redirect('/dashboard')
  }

  return user
}

export async function requireSuperAdmin() {
  const user = await getCurrentUser()

  if (!user || user.role !== 'SUPER_ADMIN') {
    redirect('/dashboard')
  }

  return user
}

export function isAdmin(user: { role: string }) {
  return user.role === 'ADMIN' || user.role === 'SUPER_ADMIN'
}

export function isSuperAdmin(user: { role: string }) {
  return user.role === 'SUPER_ADMIN'
}
```

### 4.1 用户列表

```tsx
// app/admin/users/page.tsx
import { prisma } from '@/lib/prisma'
import { SearchBar } from '@/components/SearchBar'
import { Pagination } from '@/components/Pagination'
import { UserActions } from './UserActions'

export default async function UsersPage({
  searchParams
}: {
  searchParams: Promise<{ q?: string; page?: string }>
}) {
  const { q, page: pageStr } = await searchParams
  const page = Math.max(1, parseInt(pageStr || '1'))
  const pageSize = 20

  const where = q ? {
    OR: [
      { name: { contains: q, mode: 'insensitive' as const } },
      { email: { contains: q, mode: 'insensitive' as const } },
    ]
  } : {}

  const [users, total] = await Promise.all([
    prisma.user.findMany({
      where,
      select: {
        id: true,
        name: true,
        email: true,
        role: true,
        createdAt: true,
        _count: {
          select: {
            memberships: true,
            ownedTeams: true,
          }
        }
      },
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * pageSize,
      take: pageSize,
    }),
    prisma.user.count({ where }),
  ])

  const totalPages = Math.ceil(total / pageSize)

  return (
    <div>
      <h2 className="text-2xl font-bold mb-6">用户管理</h2>

      <div className="mb-6">
        <SearchBar placeholder="搜索用户..." />
      </div>

      <div className="bg-white rounded-lg border overflow-hidden">
        <table className="w-full">
          <thead className="bg-gray-50">
            <tr>
              <th className="text-left p-4">用户</th>
              <th className="text-left p-4">角色</th>
              <th className="text-left p-4">团队/项目</th>
              <th className="text-left p-4">注册时间</th>
              <th className="text-right p-4">操作</th>
            </tr>
          </thead>
          <tbody>
            {users.map(user => (
              <tr key={user.id} className="border-t">
                <td className="p-4">
                  <div>
                    <p className="font-medium">{user.name || '未设置'}</p>
                    <p className="text-sm text-gray-500">{user.email}</p>
                  </div>
                </td>
                <td className="p-4">
                  <span className={`px-2 py-1 rounded text-sm ${
                    user.role === 'SUPER_ADMIN' ? 'bg-red-100 text-red-800' :
                    user.role === 'ADMIN' ? 'bg-blue-100 text-blue-800' :
                    'bg-gray-100 text-gray-800'
                  }`}>
                    {user.role}

                <td className="p-4 text-sm text-gray-500">
                  {new Date(user.createdAt).toLocaleDateString('zh-CN')}
                </td>
                <td className="p-4 text-right">
                  <UserActions userId={user.id} currentRole={user.role} />
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>

      <Pagination totalPages={totalPages} currentPage={page} />
    </div>
  )
```

### 4.2 用户操作

```tsx
// app/admin/users/UserActions.tsx
'use client'

import { useState } from 'react'
import { updateUserRole, banUser } from './actions'

export function UserActions({
  userId,
  currentRole
}: {
  userId: string
  currentRole: string
}) {
  const [loading, setLoading] = useState(false)

  async function handleRoleChange(role: string) {
    setLoading(true)
    await updateUserRole(userId, role)
    setLoading(false)
  }

  async function handleBan() {
    if (!confirm('确定要封禁此用户吗？')) return
    setLoading(true)
    await banUser(userId)
    setLoading(false)
  }

  return (
    <div className="flex gap-2 justify-end">
      <select
        value={currentRole}
        onChange={e => handleRoleChange(e.target.value)}
        disabled={loading}
        className="px-2 py-1 border rounded text-sm"
      >
        <option value="USER">用户</option>
        <option value="ADMIN">管理员</option>
        <option value="SUPER_ADMIN">超级管理员</option>
      </select>
      <button
        onClick={handleBan}
        disabled={loading}
        className="px-3 py-1 text-sm text-red-600 border border-red-300 rounded hover:bg-red-50"
      >
        封禁
      </button>
    </div>
  )
}
```

### 4.3 管理操作

```tsx
// app/admin/users/actions.ts
'use server'

import { requireSuperAdmin } from '@/lib/admin'
import { prisma } from '@/lib/prisma'
import { revalidatePath } from 'next/cache'

export async function updateUserRole(userId: string, role: string) {
  await requireSuperAdmin()

  await prisma.user.update({
    where: { id: userId },
    data: { role: role as any }
  })

  revalidatePath('/admin/users')
}

export async function banUser(userId: string) {
  await requireSuperAdmin()

  // 不能封禁自己
  const currentUser = await requireSuperAdmin()
  if (currentUser.id === userId) {
    throw new Error('不能封禁自己')
  }

  // 删除用户的所有 session
  // 更新用户状态
  await prisma.user.update({
    where: { id: userId },
    data: { banned: true, bannedAt: new Date() }
  })

  revalidatePath('/admin/users')
}
```

```typescript
'use server'

import { requireSuperAdmin } from '@/lib/admin'
import { prisma } from '@/lib/prisma'
import { revalidatePath } from 'next/cache'

export async function updateUserRole(userId: string, role: string) {
  await requireSuperAdmin()

  await prisma.user.update({
    where: { id: userId },
    data: { role: role as any },
  })

  revalidatePath('/admin/users')
}

export async function banUser(userId: string) {
  const admin = await requireSuperAdmin()
  if (admin.id === userId) {
    throw new Error('不能封禁自己')
  }

  await prisma.user.update({
    where: { id: userId },
    data: { banned: true, bannedAt: new Date() },
  })

  revalidatePath('/admin/users')
}

export async function unbanUser(userId: string) {
  await requireSuperAdmin()

  await prisma.user.update({
    where: { id: userId },
    data: { banned: false, bannedAt: null },
  })

  revalidatePath('/admin/users')
}
```

```typescript
// lib/audit.ts
import { prisma } from './prisma'

export async function logAdminAction({
  adminId,
  action,
  targetId,
  details,
}: {
  adminId: string
  action: string
  targetId?: string
  details?: Record<string, any>
}) {
  await prisma.adminLog.create({
    data: {
      adminId,
      action,
      targetId,
      details: details ? JSON.stringify(details) : null,
    },
  })
}

export async function getAdminLogs({
  action,
  page = 1,
  pageSize = 50,
}: {
  action?: string
  page?: number
  pageSize?: number
}) {
  const where = action ? { action } : {}

  const [logs, total] = await Promise.all([
    prisma.adminLog.findMany({
      where,
      include: {
        admin: { select: { id: true, name: true, email: true } },
      },
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * pageSize,
      take: pageSize,
    }),
    prisma.adminLog.count({ where }),
  ])

  return {
    logs,
    total,
    page,
    pageSize,
    totalPages: Math.ceil(total / pageSize),
  }
}
```

## 常见误区

1. **"管理后台和用户端共用一套权限"**：管理后台需要独立的权限模型（ADMIN、SUPER_ADMIN），和团队内的角色（OWNER、ADMIN、MEMBER）是完全不同的维度。一个用户可能是某个团队的 OWNER，但不是系统管理员。
2. **"管理员可以做任何事所以不需要检查"**：即使是超级管理员，某些操作也需要限制——比如不能封禁自己、不能删除自己的账号、不能降低自己的权限。
3. **"管理操作不需要记录日志"**：管理员修改用户角色、封禁账号、修改系统设置等操作必须记录审计日志。如果管理员误操作，需要有迹可循。
4. **"管理后台不需要搜索和分页"**：用户管理页面可能有几千条记录，没有搜索和分页的页面完全不可用。管理后台的列表页面必须支持搜索、筛选和分页。

## 工程建议

1. **管理后台用独立的路由组和 layout**：`app/admin/layout.tsx` 包含管理后台的侧边栏和权限检查，和用户端的 `(dashboard)` 路由组完全隔离。
2. **用 `requireSuperAdmin()` 保护敏感操作**：修改用户角色、封禁账号、修改系统设置等操作必须在 Server Action 中调用 `requireSuperAdmin()` 检查权限。
3. **管理操作要记录审计日志**：每次角色变更、用户封禁、系统设置修改都要写入 `AdminLog` 表，包含操作者 ID、操作类型、目标 ID 和操作详情。
4. **系统设置用 key-value 模型存储**：`SystemSetting` 表用 `key: string` + `value: string` 的结构，灵活存储各种配置项，不需要每次加配置都改 schema。
