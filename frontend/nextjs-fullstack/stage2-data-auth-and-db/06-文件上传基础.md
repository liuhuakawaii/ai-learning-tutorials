# 第六课：文件上传基础

## 场景引入

你的团队协作工具需要支持用户上传头像和项目附件。你用 `<input type="file">` 做了一个简单的上传表单，提交后发现几个问题：用户上传了一个 50MB 的视频文件导致服务器内存爆满；有人上传了 `.exe` 可执行文件存在安全隐患；上传完成后页面没有任何预览，用户不确定是否上传成功。更深层的问题是，文件保存在服务器的本地磁盘上，下次部署时容器重建，所有上传的文件都消失了。你需要一套完整的文件上传方案：验证、存储、预览、持久化。

## 学习目标

完成本课学习后，你将能够：

1. 理解文件上传的基本原理
2. 在 Next.js 中处理文件上传
3. 实现图片上传和预览
4. 了解对象存储的概念
5. 实现文件大小和类型验证

## 三、保存到本地文件系统

### 3.1 创建上传目录

```bash
mkdir -p public/uploads
```

### 3.2 保存文件

```tsx
'use server'

import { writeFile, mkdir } from 'fs/promises'
import { join } from 'path'

export async function uploadFile(formData: FormData) {
  const file = formData.get('file') as File

  if (!file || file.size === 0) {
    return { error: '请选择文件' }
  }

  // 生成唯一文件名
  const ext = file.name.split('.').pop()
  const fileName = `${Date.now()}-${Math.random().toString(36).slice(2)}.${ext}`

  // 确保目录存在
  const uploadDir = join(process.cwd(), 'public', 'uploads')
  await mkdir(uploadDir, { recursive: true })

  // 保存文件
  const filePath = join(uploadDir, fileName)
  const bytes = await file.arrayBuffer()
  await writeFile(filePath, Buffer.from(bytes))

  // 返回可访问的 URL
  const url = `/uploads/${fileName}`

  return { success: true, url }
}
```

## 四、图片上传与预览

### 4.1 客户端预览

```tsx
// components/ImageUpload.tsx
'use client'

import { useState, useRef } from 'react'

interface ImageUploadProps {
  onUpload: (formData: FormData) => Promise<{ url?: string; error?: string }>
  currentImage?: string
}

export function ImageUpload({ onUpload, currentImage }: ImageUploadProps) {
  const [preview, setPreview] = useState<string | null>(currentImage || null)
  const [uploading, setUploading] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const inputRef = useRef<HTMLInputElement>(null)

  function handleFileChange(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0]
    if (!file) return

    // 客户端验证
    if (file.size > 5 * 1024 * 1024) {
      setError('文件大小不能超过 5MB')
      return
    }

    if (!file.type.startsWith('image/')) {
      setError('只能上传图片')
      return
    }

    setError(null)

    // 创建预览
    const reader = new FileReader()
    reader.onloadend = () => {
      setPreview(reader.result as string)
    }
    reader.readAsDataURL(file)
  }

  async function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault()
    setUploading(true)
    setError(null)

    const formData = new FormData(e.currentTarget)
    const result = await onUpload(formData)

    if (result.error) {
      setError(result.error)
    }

    setUploading(false)
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <div
        className="border-2 border-dashed rounded-lg p-8 text-center cursor-pointer hover:border-blue-500"
        onClick={() => inputRef.current?.click()}
      >
        {preview ? (
          <img
            src={preview}
            alt="预览"
            className="max-w-full max-h-48 mx-auto"
          />
        ) : (
          <div className="text-gray-500">
            <p>点击选择图片</p>
            <p className="text-sm">支持 JPG、PNG、GIF，最大 5MB</p>
          </div>
        )}
      </div>

      <input
        ref={inputRef}
        type="file"
        name="file"
        accept="image/*"
        onChange={handleFileChange}
        className="hidden"
      />

      {error && (
        <p className="text-red-500 text-sm">{error}</p>
      )}

      <button
        type="submit"
        disabled={uploading || !preview}
        className="px-4 py-2 bg-blue-500 text-white rounded disabled:opacity-50"
      >
        {uploading ? '上传中...' : '上传'}
      </button>
    </form>
  )
}
```

## 五、对象存储简介

### 5.1 为什么需要对象存储

```
本地文件系统的问题：

❌ 不适合生产环境
  - 服务器重启后文件可能丢失
  - 多服务器部署时文件不同步

❌ 不适合大文件
  - 占用服务器磁盘空间
  - 没有 CDN 加速

✅ 对象存储的优势
  - 持久化存储
  - CDN 加速
  - 按使用量付费
  - 高可用性
```

### 5.2 常见对象存储服务

```
服务              特点
─────────────────────────────────────
AWS S3           最成熟，功能最全
Cloudflare R2    无出口费用
阿里云 OSS       国内访问快
腾讯云 COS       国内访问快
MinIO            自托管，兼容 S3
```

### 5.3 S3 兼容 API

大多数对象存储都兼容 S3 API：

```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

```tsx
// lib/s3.ts
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3'
import { getSignedUrl } from '@aws-sdk/s3-request-presigner'

const s3Client = new S3Client({
  region: 'auto',
  endpoint: process.env.S3_ENDPOINT,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY!,
    secretAccessKey: process.env.S3_SECRET_KEY!,
  },
})

export async function uploadToS3(
  file: Buffer,
  fileName: string,
  contentType: string
): Promise<string> {
  const key = `uploads/${Date.now()}-${fileName}`

  await s3Client.send(new PutObjectCommand({
    Bucket: process.env.S3_BUCKET,
    Key: key,
    Body: file,
    ContentType: contentType,
  }))

  return `${process.env.S3_PUBLIC_URL}/${key}`
}
```

## 六、头像上传完整示例

### 6.1 Server Action

```tsx
// app/profile/actions.ts
'use server'

import { writeFile, mkdir } from 'fs/promises'
import { join } from 'path'
import { prisma } from '@/lib/prisma'
import { getSession } from '@/lib/session'
import { revalidatePath } from 'next/cache'

const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']
const MAX_SIZE = 2 * 1024 * 1024 // 2MB

export async function uploadAvatar(formData: FormData) {
  const session = await getSession()
  if (!session.userId) {
    return { error: '未登录' }
  }

  const file = formData.get('avatar') as File

  if (!file || file.size === 0) {
    return { error: '请选择文件' }
  }

  if (!ALLOWED_TYPES.includes(file.type)) {
    return { error: '只支持 JPG、PNG、GIF、WebP 格式' }
  }

  if (file.size > MAX_SIZE) {
    return { error: '文件大小不能超过 2MB' }
  }

  // 生成唯一文件名
  const ext = file.name.split('.').pop()
  const fileName = `avatar-${session.userId}-${Date.now()}.${ext}`

  // 保存文件
  const uploadDir = join(process.cwd(), 'public', 'avatars')
  await mkdir(uploadDir, { recursive: true })

  const filePath = join(uploadDir, fileName)
  const bytes = await file.arrayBuffer()
  await writeFile(filePath, Buffer.from(bytes))

  // 更新用户头像
  const avatarUrl = `/avatars/${fileName}`
  await prisma.user.update({
    where: { id: session.userId },
    data: { avatar: avatarUrl },
  })

  revalidatePath('/profile')
  return { success: true, url: avatarUrl }
}
```

## 七、多文件上传

### 7.1 处理多个文件

```tsx
'use server'

export async function uploadMultiple(formData: FormData) {
  const files = formData.getAll('files') as File[]

  if (files.length === 0) {
    return { error: '请选择文件' }
  }

  if (files.length > 10) {
    return { error: '最多上传 10 个文件' }
  }

  const uploadedUrls: string[] = []

  for (const file of files) {
    if (file.size === 0) continue

    const ext = file.name.split('.').pop()
    const fileName = `${Date.now()}-${Math.random().toString(36).slice(2)}.${ext}`

    const uploadDir = join(process.cwd(), 'public', 'uploads')
    await mkdir(uploadDir, { recursive: true })

    const filePath = join(uploadDir, fileName)
    const bytes = await file.arrayBuffer()
    await writeFile(filePath, Buffer.from(bytes))

    uploadedUrls.push(`/uploads/${fileName}`)
  }

  return { success: true, urls: uploadedUrls }
}
```

## 参考答案

### 练习一：实现基础文件上传

**思路**：基础文件上传的核心流程是：前端表单提交 FormData → 服务端获取 File 对象 → 验证类型和大小 → 生成唯一文件名 → 保存到本地文件系统 → 返回可访问的 URL。关键是在服务端做完整的验证，不能只依赖前端的 `accept` 属性。

**答案**：

```tsx
// app/upload/actions.ts
'use server'

import { writeFile, mkdir } from 'fs/promises'
import { join } from 'path'
import { z } from 'zod'

const UploadSchema = z.object({
  file: z.custom<File>()
    .refine(file => file instanceof File && file.size > 0, '请选择文件')
    .refine(file => file.size <= 10 * 1024 * 1024, '文件大小不能超过 10MB')
    .refine(
      file => [
        'image/jpeg', 'image/png', 'image/gif', 'image/webp',
        'application/pdf',
        'application/msword',
        'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
      ].includes(file.type),
      '不支持的文件类型'
    ),
})

export async function uploadFile(formData: FormData) {
  const validated = UploadSchema.safeParse({
    file: formData.get('file'),
  })

  if (!validated.success) {
    return { errors: validated.error.flatten().fieldErrors }
  }

  const file = validated.data.file
  const ext = file.name.split('.').pop()
  const fileName = `${Date.now()}-${Math.random().toString(36).slice(2)}.${ext}`

  const uploadDir = join(process.cwd(), 'public', 'uploads')
  await mkdir(uploadDir, { recursive: true })

  const filePath = join(uploadDir, fileName)
  const bytes = await file.arrayBuffer()
  await writeFile(filePath, Buffer.from(bytes))

  return { success: true, url: `/uploads/${fileName}`, fileName: file.name }
}
```


**要点**：
- `z.custom<File>()` 配合 `.refine()` 可以在 Zod Schema 中定义完整的文件验证规则
- 唯一文件名用 `Date.now()` + 随机字符串，避免两个用户同时上传同名文件导致覆盖
- `await mkdir(uploadDir, { recursive: true })` 确保上传目录存在，不存在则自动创建
- 服务端验证是必须的，前端的 `accept` 属性可以被绕过

### 练习二：实现图片上传与预览

**思路**：图片预览在客户端用 `FileReader.readAsDataURL()` 生成 base64 URL 实现，不需要等上传完成。核心是把文件选择、预览、上传三个状态管理好：选择文件时立即预览，点击上传时才真正发请求，上传完成后用服务端返回的 URL 替换预览。

**答案**：

```tsx
// components/ImageUpload.tsx
'use client'

import { useState, useRef } from 'react'

interface ImageUploadProps {
  onUpload: (formData: FormData) => Promise<{ url?: string; error?: string }>
  currentImage?: string
  maxSizeMB?: number
}

export function ImageUpload({ onUpload, currentImage, maxSizeMB = 5 }: ImageUploadProps) {
  const [preview, setPreview] = useState<string | null>(currentImage || null)
  const [uploading, setUploading] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const [progress, setProgress] = useState(0)
  const inputRef = useRef<HTMLInputElement>(null)

  function handleFileChange(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0]
    if (!file) return

    if (file.size > maxSizeMB * 1024 * 1024) {
      setError(`文件大小不能超过 ${maxSizeMB}MB`)
      return
    }

    if (!file.type.startsWith('image/')) {
      setError('只能上传图片文件')
      return
    }

    setError(null)

    const reader = new FileReader()
    reader.onloadend = () => {
      setPreview(reader.result as string)
    }
    reader.readAsDataURL(file)
  }

  async function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault()
    const file = inputRef.current?.files?.[0]
    if (!file) {
      setError('请先选择图片')
      return
    }

    setUploading(true)
    setError(null)
    setProgress(0)

    const progressInterval = setInterval(() => {
      setProgress(prev => Math.min(prev + 10, 90))
    }, 200)

    const formData = new FormData()
    formData.append('file', file)
    const result = await onUpload(formData)

    clearInterval(progressInterval)
    setProgress(100)

    if (result.error) {
      setError(result.error)
      setProgress(0)
    } else if (result.url) {
      setPreview(result.url)
    }

    setUploading(false)
  }

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <div
        className="border-2 border-dashed rounded-lg p-8 text-center cursor-pointer hover:border-blue-500 transition-colors"
        onClick={() => inputRef.current?.click()}
      >
        {preview ? (
          <img
            src={preview}
            alt="预览"
            className="max-w-full max-h-48 mx-auto rounded"
          />
        ) : (
          <div className="text-gray-500">
            <p className="text-lg mb-1">点击选择图片</p>
            <p className="text-sm">支持 JPG、PNG、GIF、WebP，最大 {maxSizeMB}MB</p>
          </div>
        )}
      </div>

      <input
        ref={inputRef}
        type="file"
        name="file"
        accept="image/jpeg,image/png,image/gif,image/webp"
        onChange={handleFileChange}
        className="hidden"
      />

      {error && <p className="text-red-500 text-sm">{error}</p>}

      {uploading && (
        <div className="w-full bg-gray-200 rounded-full h-2">
          <div
            className="bg-blue-500 h-2 rounded-full transition-all"
            style={{ width: `${progress}%` }}
          />
        </div>
      )}

      <button
        type="submit"
        disabled={uploading || !preview}
        className="w-full px-4 py-2 bg-blue-500 text-white rounded disabled:opacity-50"
      >
        {uploading ? `上传中 ${progress}%` : '上传图片'}
      </button>
    </form>
  )
}
```

**要点**：
- `FileReader.readAsDataURL()` 在客户端生成预览，不需要等服务端响应
- 用 `setInterval` 模拟上传进度，提升用户体验（真实进度需要 XMLHttpRequest 的 `upload.onprogress`）
- 点击预览区域触发隐藏的 `input` 点击，比原生文件选择按钮更好看
- 上传完成后用服务端返回的 URL 替换 base64 预览，避免 base64 字符串占用过多内存

### 练习三：实现头像上传功能

**思路**：头像上传需要和用户系统联动：上传文件 → 验证 → 保存 → 更新数据库中的 avatar 字段 → 刷新页面展示新头像。关键点是生成带用户 ID 的文件名（避免冲突）、限制头像文件大小（通常 2MB 足够）、以及在导航栏等位置展示头像。

**答案**：

```tsx
// app/profile/actions.ts
'use server'

import { writeFile, mkdir, unlink } from 'fs/promises'
import { join } from 'path'
import { prisma } from '@/lib/prisma'
import { getSession } from '@/lib/session'
import { revalidatePath } from 'next/cache'

const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/gif', 'image/webp']
const MAX_SIZE = 2 * 1024 * 1024

export async function uploadAvatar(formData: FormData) {
  const session = await getSession()
  if (!session?.userId) {
    return { error: '未登录' }
  }

  const file = formData.get('avatar') as File

  if (!file || file.size === 0) {
    return { error: '请选择文件' }
  }

  if (!ALLOWED_TYPES.includes(file.type)) {
    return { error: '只支持 JPG、PNG、GIF、WebP 格式' }
  }

  if (file.size > MAX_SIZE) {
    return { error: '文件大小不能超过 2MB' }
  }

  const ext = file.name.split('.').pop()
  const fileName = `avatar-${session.userId}-${Date.now()}.${ext}`

  const uploadDir = join(process.cwd(), 'public', 'avatars')
  await mkdir(uploadDir, { recursive: true })

  const filePath = join(uploadDir, fileName)
  const bytes = await file.arrayBuffer()
  await writeFile(filePath, Buffer.from(bytes))

  const avatarUrl = `/avatars/${fileName}`

  const currentUser = await prisma.user.findUnique({
    where: { id: session.userId },
    select: { avatar: true },
  })

  await prisma.user.update({
    where: { id: session.userId },
    data: { avatar: avatarUrl },
  })

  if (currentUser?.avatar && currentUser.avatar.startsWith('/avatars/')) {
    const oldPath = join(process.cwd(), 'public', currentUser.avatar)
    try {
      await unlink(oldPath)
    } catch {
      // 旧文件不存在时忽略
    }
  }

  revalidatePath('/profile')
  revalidatePath('/dashboard')
  return { success: true, url: avatarUrl }
}
```

```tsx
// components/AvatarUpload.tsx
'use client'

import { useState, useRef } from 'react'
import { uploadAvatar } from '@/app/profile/actions'

export function AvatarUpload({ currentAvatar }: { currentAvatar?: string }) {
  const [preview, setPreview] = useState<string | null>(currentAvatar || null)
  const [uploading, setUploading] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const inputRef = useRef<HTMLInputElement>(null)

  function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0]
    if (!file) return

    if (file.size > 2 * 1024 * 1024) {
      setError('文件大小不能超过 2MB')
      return
    }
    if (!file.type.startsWith('image/')) {
      setError('只能上传图片')
      return
    }

    setError(null)
    const reader = new FileReader()
    reader.onloadend = () => setPreview(reader.result as string)
    reader.readAsDataURL(file)
  }

  async function handleUpload() {
    const file = inputRef.current?.files?.[0]
    if (!file) return

    setUploading(true)
    setError(null)

    const formData = new FormData()
    formData.append('avatar', file)

    const result = await uploadAvatar(formData)

    if (result.error) {
      setError(result.error)
    }

    setUploading(false)
  }

  return (
    <div className="flex items-center gap-6">
      <div
        className="w-24 h-24 rounded-full bg-gray-200 overflow-hidden cursor-pointer border-2 border-gray-300 hover:border-blue-500 transition-colors"
        onClick={() => inputRef.current?.click()}
      >
        {preview ? (
          <img src={preview} alt="头像" className="w-full h-full object-cover" />
        ) : (
          <div className="w-full h-full flex items-center justify-center text-gray-400 text-sm">
            选择头像
          </div>
        )}
      </div>

      <div className="space-y-2">
        <input
          ref={inputRef}
          type="file"
          accept="image/jpeg,image/png,image/gif,image/webp"
          onChange={handleChange}
          className="hidden"
        />
        <button
          onClick={() => inputRef.current?.click()}
          className="block px-4 py-2 text-sm border rounded hover:bg-gray-50"
        >
          选择图片
        </button>
        <button
          onClick={handleUpload}
          disabled={uploading || !inputRef.current?.files?.[0]}
          className="block px-4 py-2 text-sm bg-blue-500 text-white rounded disabled:opacity-50"
        >
          {uploading ? '上传中...' : '上传头像'}
        </button>
        {error && <p className="text-red-500 text-sm">{error}</p>}
        <p className="text-xs text-gray-500">支持 JPG、PNG、GIF、WebP，最大 2MB</p>
      </div>
    </div>
  )
}
```

## 常见误区

1. **"只在前端验证文件类型就够了"**：用户可以修改文件扩展名绕过前端的 `accept` 属性。服务端必须检查 `file.type`（MIME 类型），不能只看文件名后缀。
2. **"用原始文件名保存就行"**：两个用户都上传 `avatar.jpg` 会互相覆盖。必须生成唯一文件名（如 `avatar-${userId}-${Date.now()}.jpg`），避免文件名冲突。
3. **"本地文件系统可以用于生产环境"**：本地存储在服务器重启、容器重建时会丢失文件，多服务器部署时文件不同步。生产环境必须用对象存储（S3、R2、OSS）。
4. **"文件大小限制只在后端做"**：后端确实需要验证，但如果不在前端做限制，大文件会完整上传到服务器后才被拒绝，浪费带宽和时间。前端用 `file.size` 即时检查。

## 工程建议

1. **用 Zod 验证文件对象**：`z.custom<File>().refine(file => file.size > 0).refine(file => file.size <= 5 * 1024 * 1024)` 可以在一个 Schema 中定义所有文件验证规则。
2. **客户端用 `FileReader` 实现即时预览**：`FileReader.readAsDataURL()` 可以在文件上传前就生成预览 URL，让用户确认选择是否正确。
3. **用预签名 URL 让客户端直传对象存储**：不要让文件经过你的服务器中转。生成一个预签名 URL，让浏览器直接上传到 S3/R2，减轻服务器压力。
4. **多文件上传要逐个验证和记录**：用 `formData.getAll('files')` 获取所有文件后，逐个验证类型和大小，逐个生成唯一文件名，逐个上传。不要把所有文件拼成一个大 buffer。
