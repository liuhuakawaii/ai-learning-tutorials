# 第一阶段：App Router 基础

## 阶段目标

理解 Next.js App Router 的核心模型：路由、布局、Server Components、Client Components、数据获取、缓存和表单动作。

## 课时安排

1. Next.js 与 React SPA 的差异
2. app 目录、layout、page、template
3. Server Components 与 Client Components
4. 数据获取、缓存和 revalidate
5. Server Actions 与表单提交
6. loading、error、not-found 状态
7. 阶段实战：内容管理面板

## 阶段项目

做一个内容管理面板，支持文章列表、详情、创建、编辑和删除，数据可以先用内存或本地 JSON 模拟。

## 验收标准

- 页面结构符合 App Router 约定
- 清楚区分服务端组件和客户端组件
- 表单有 loading、error、success 状态
- 路由层级清晰
