> 从"写页面"到"造零件"，建立设计系统思维

- 理解设计系统的核心概念和价值

## 学习建议

1. **理解设计系统**：不要只关注组件实现，理解设计系统的整体架构
2. **动手实践**：每节课的示例代码都要亲手跑一遍
3. **参考优秀案例**：学习 Ant Design、Material UI 等优秀组件库的设计
4. **关注可访问性**：不要忽视无障碍访问的重要性

## 常见问题

### Q: 设计系统和 UI Kit 有什么区别？

A: UI Kit 是组件的集合，设计系统是包含 Token、组件、模式、文档的完整体系。设计系统提供了一致的设计语言和开发规范。

### Q: 为什么需要 Design Token？

A: Design Token 是设计系统的基础，它将设计决策（颜色、字体、间距等）抽象为可复用的变量，确保设计一致性。

### Q: 如何选择 CSS-in-JS 方案？

A: 根据项目需求选择。styled-components 适合 React 项目，Emotion 性能好，CSS Modules 兼容性好。
