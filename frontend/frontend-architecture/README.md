# 前端基建与架构工程

> 系统掌握中大型项目所需的工程化能力和架构设计思维

## 课程定位

这门课不是工具使用教程，而是帮助你建立**"能设计、能落地、能演进"的基建能力**。

学完这门课，你将能够：
- 设计和搭建 Monorepo 项目架构
- 从零构建企业级组件库和设计系统
- 深度定制构建工具链（Vite/Webpack）
- 建立代码规范和质量门禁体系
- 设计和实现前端监控系统
- 进行系统性的性能优化
- 设计微前端等复杂架构方案
- 开发企业级脚手架和工具链
- 搭建 CI/CD 自动化流水线
- 处理前端安全与合规问题

## 目标受众

- 有 1-3 年经验的前端开发者
- 能独立完成业务开发，但对项目工程化感到迷茫
- 想参与或主导组件库、脚手架、监控体系等基建工作
- 准备晋升高级/资深前端，需要补齐架构视野

## 前置要求

- 熟悉 HTML/CSS/JavaScript 基础
- 了解 React 或 Vue 框架基本使用
- 有 npm/pnpm 包管理经验
- 了解基本的 Git 操作

## 不覆盖什么

- 不从零讲 HTML/CSS/JavaScript 基础
- 不讲具体 UI 框架 API（React/Vue 基础）
- 不讲后端架构（有专门的系统设计课程）
- 不讲 3D/图形学/音视频等垂直领域

## 学习路线

```
stage1 工程化基础与 Monorepo
    ↓
stage2 组件库与设计系统
    ↓
stage3 构建工具链深度
    ↓
stage4 代码质量与规范体系
    ↓
stage5 前端监控与可观测性
    ↓
stage6 性能工程与优化
    ↓
stage7 架构模式与演进
    ↓
stage8 脚手架与工具链
    ↓
stage9 CI/CD 与发布体系
    ↓
stage10 安全与合规
    ↓
```

**建议学习顺序**：stage1 → stage2 → stage3 → stage4 → stage5 → stage6 → stage7 → stage8 → stage9 → stage10 → final-project

前 4 个阶段是基础，建议按顺序学习。stage5-stage10 可以根据实际需求调整顺序，但建议先完成前 4 个阶段。

## 阶段概览

### stage1：工程化基础与 Monorepo（10 课时）

从真实项目痛点出发，理解为什么需要工程化，掌握 Monorepo 架构设计。

**核心能力**：多包管理、依赖治理、版本发布

### stage2：组件库与设计系统（10 课时）

从 Design Token 到组件实现，建立设计系统思维。

**核心能力**：设计系统、组件架构、主题系统、无障碍访问

### stage3：构建工具链深度（10 课时）

深入 Vite/Webpack 原理，掌握构建优化和插件开发。

**核心能力**：构建优化、插件开发、代码分割、资源优化

### stage4：代码质量与规范体系（8 课时）

从"靠自觉"到"靠工程"，建立代码质量门禁。

**核心能力**：ESLint、Prettier、TypeScript 严格模式、代码审查

### stage5：前端监控与可观测性（10 课时）

建立全链路可观测性，从线上黑盒到全透明。

**核心能力**：错误监控、性能采集、用户行为追踪、告警系统

### stage6：性能工程与优化（10 课时）

系统性性能优化方法论，从测量到优化到验证。

**核心能力**：网络优化、渲染优化、代码分割、SSR/SSG

### stage7：架构模式与演进（10 课时）

掌握微前端、状态管理、国际化等复杂架构设计。

**核心能力**：微前端、状态管理、数据缓存、架构演进

### stage8：脚手架与工具链（8 课时）

开发企业级脚手架，提升团队开发效率。

**核心能力**：CLI 开发、模板引擎、代码生成、插件机制

### stage9：CI/CD 与发布体系（8 课时）

搭建自动化流水线，实现持续集成和持续部署。

**核心能力**：GitHub Actions、构建流水线、部署策略、灰度发布

### stage10：安全与合规（6 课时）

前端安全防御和数据合规，建立安全内建思维。

**核心能力**：XSS/CSRF 防御、CSP、依赖安全、数据隐私

## 毕业项目

### 企业级前端基建平台（3 周）

搭建一个可直接用于团队的前端基建平台，包含：

1. **Monorepo 项目模板** —— 包含应用和组件库
2. **企业级脚手架** —— 一键创建项目、生成代码
3. **组件库基础** —— 包含 5-10 个基础组件
4. **构建配置** —— Vite/Webpack 预设
5. **代码规范** —— ESLint/Prettier/Stylelint 配置包
6. **监控 SDK** —— 错误捕获与性能采集
7. **CI/CD 配置** —— GitHub Actions 工作流

### 验收方式

```bash
cd frontend/frontend-architecture/final-project

# 验证项目结构
pnpm check

# 验证构建产物
pnpm build

# 验证测试覆盖
pnpm test

# 启动演示项目
pnpm dev
```

## 课程特点

- **实战驱动**：每个阶段都有配套练习和阶段项目
- **讲清原理**：不只讲"怎么用"，更讲"为什么这样设计"
- **真实场景**：所有案例都来自真实项目痛点
- **可验证**：毕业项目提供完整的验收脚本
- **渐进式**：从基础到高级，逐步建立完整能力

## 常见问题

### Q: 这门课适合新手吗？

A: 不适合。这门课面向有 1-3 年经验的前端开发者。如果你刚入行，建议先学习基础课程。

### Q: 需要会 React 还是 Vue？

A: 课程示例主要使用 React，但架构思想是通用的。会 React 或 Vue 其中一个即可。

### Q: 学完能达到什么水平？

A: 能够独立设计和搭建中大型项目的前端基础设施，具备高级/资深前端工程师的架构视野。

### Q: 课程有配套代码吗？

A: 是的。每个阶段都有配套代码示例，毕业项目提供完整的可运行项目。
