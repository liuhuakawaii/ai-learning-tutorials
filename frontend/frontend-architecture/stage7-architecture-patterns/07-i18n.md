# 07. 国际化架构设计 —— i18n 方案选型、动态语言包加载、RTL 支持、日期/货币格式化

> 国际化不是"把中文换成英文"——它是让应用适应不同语言、文化和地区习惯的系统工程

## 本课目标

- 理解国际化（i18n）的完整范围：不只是翻译文本
- 掌握 i18next 和 vue-i18n 的核心用法和架构
- 设计动态语言包加载策略
- 实现 RTL（从右到左）布局支持
- 处理日期、货币、数字的本地化格式化

## 国际化不只是翻译

很多团队对国际化的理解停留在"把中文字符串换成英文"。但真正的国际化要处理的问题远不止这些：

```
国际化需要处理的问题：

1. 文本翻译
   - 静态文本（UI 标签、按钮、提示）
   - 动态文本（错误消息、通知内容）
   - 复数形式（1 item vs 2 items vs 0 items）
   - 性别相关（He/She/They）

2. 布局方向
   - LTR（从左到右）：中文、英文、法语
   - RTL（从右到左）：阿拉伯语、希伯来语、波斯语
   - 布局需要镜像：导航栏、侧边栏、表单对齐

3. 日期和时间
   - 格式：2024-01-15 vs 01/15/2024 vs 15.01.2024
   - 星期：Monday vs Lundi vs Montag
   - 时区：UTC vs 本地时区

4. 数字和货币
   - 千分位：1,234.56 vs 1.234,56
   - 货币符号：$100 vs 100€ vs ¥100
   - 货币位置：$100 vs 100$

5. 排序
   - 拼音排序 vs 笔画排序 vs Unicode 排序
   - 不同语言的排序规则不同

6. 图片和颜色
   - 某些颜色在不同文化中有不同含义
   - 图片中的文字需要本地化
   - 手势图标的方向（← vs →）
```

## i18next 架构

i18next 是 JavaScript 生态中最成熟的国际化框架。

### 基础配置

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';
import Backend from 'i18next-http-backend';

i18n
  // 语言检测：自动检测用户语言
  .use(LanguageDetector)
  // 后端加载：按需加载语言包
  .use(Backend)
  // React 集成
  .use(initReactI18next)
  .init({
    // 回退语言
    fallbackLng: 'en',
    // 支持的语言
    supportedLngs: ['en', 'zh-CN', 'ja', 'ar'],
    // 命名空间（按功能模块分割语言包）
    ns: ['common', 'auth', 'dashboard'],
    defaultNS: 'common',
    // 后端配置
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json',
    },
    // 插值配置
    interpolation: {
      escapeValue: false, // React 已经处理了 XSS
    },
    // 检测配置
    detection: {
      order: ['querystring', 'cookie', 'localStorage', 'navigator'],
      caches: ['cookie'],
    },
  });
```

## 动态语言包加载

大型应用的语言包可能很大，不适合一次性加载所有语言。

### 按命名空间分割

```typescript
// 语言包文件结构
// locales/
//   en/
//     common.json      (10KB) - 基础 UI 文本
//     auth.json        (5KB)  - 登录/注册相关
//     dashboard.json   (15KB) - 仪表盘相关
//     settings.json    (8KB)  - 设置页面相关
//   zh-CN/
//     common.json
//     auth.json
//     dashboard.json
//     settings.json

// 使用 Suspense 加载语言包
import { Suspense } from 'react';
import { useTranslation } from 'react-i18next';

function Dashboard() {
  const { t, i18n } = useTranslation('dashboard');

  // 首次进入仪表盘页面时，才加载 dashboard 语言包
  useEffect(() => {
    i18n.loadNamespaces('dashboard');
  }, [i18n]);

  return (
    <div>
      <h1>{t('title')}</h1>
      <p>{t('welcome', { name: user.name })}</p>
    </div>
  );
}

// 在路由切换时预加载对应的语言包
function RouteWithI18n({ namespace, children }) {
  const { i18n } = useTranslation();

  useEffect(() => {
    i18n.loadNamespaces(namespace);
  }, [namespace, i18n]);

  return <Suspense fallback={<Loading />}>{children}</Suspense>;
}
```

### 语言包缓存

```typescript
// 使用 Service Worker 缓存语言包
// 或者使用 localStorage 缓存
import i18n from 'i18next';

// 缓存已加载的语言包
const cache = new Map();

i18n.on('loaded', (loaded) => {
  Object.entries(loaded).forEach(([lng, namespaces]) => {
    Object.entries(namespaces).forEach(([ns, resources]) => {
      const key = `${lng}:${ns}`;
      cache.set(key, resources);
      try {
        localStorage.setItem(`i18n:${key}`, JSON.stringify(resources));
      } catch (e) {
        // localStorage 满了，清除旧的缓存
        clearOldI18nCache();
      }
    });
  });
});

// 从缓存中恢复
function restoreCache() {
  for (let i = 0; i < localStorage.length; i++) {
    const key = localStorage.key(i);
    if (key?.startsWith('i18n:')) {
      const [lng, ns] = key.replace('i18n:', '').split(':');
      const resources = JSON.parse(localStorage.getItem(key)!);
      i18n.addResourceBundle(lng, ns, resources);
    }
  }
}
```

## RTL 支持

RTL（Right-to-Left）语言需要整个布局镜像。

### CSS 方案

```css
/* 使用 CSS 逻辑属性 */
/* 不要用 left/right，用 start/end */
.container {
  margin-inline-start: 16px;  /* LTR: margin-left, RTL: margin-right */
  padding-inline-end: 16px;   /* LTR: padding-right, RTL: padding-left */
  text-align: start;           /* LTR: left, RTL: right */
  border-inline-start: 1px solid; /* LTR: border-left, RTL: border-right */
}

/* 使用 CSS 变量控制方向 */
[dir="ltr"] {
  --direction: 1;
  --start: left;
  --end: right;
}

[dir="rtl"] {
  --direction: -1;
  --start: right;
  --end: left;
}

/* 使用逻辑属性的现代写法 */
.sidebar {
  float: inline-start;
  clear: inline-end;
}
```

### 切换方向

```typescript
import { useTranslation } from 'react-i18next';

function useDirection() {
  const { i18n } = useTranslation();

  useEffect(() => {
    const dir = i18n.dir(); // 'ltr' 或 'rtl'
    document.documentElement.dir = dir;
    document.documentElement.lang = i18n.language;
  }, [i18n.language]);

  return i18n.dir();
}

// RTL 语言列表
const RTL_LANGUAGES = ['ar', 'he', 'fa', 'ur'];

function isRTL(language: string): boolean {
  return RTL_LANGUAGES.some((lng) => language.startsWith(lng));
}
```

### 图片和图标的 RTL 处理

```css
/* 某些图标需要在 RTL 模式下镜像 */
[dir="rtl"] .icon-arrow {
  transform: scaleX(-1);
}

/* 但某些图标不应该镜像（如播放按钮） */
[dir="rtl"] .icon-play {
  transform: none; /* 保持原样 */
}

/* 使用 CSS 逻辑属性处理背景图片位置 */
.logo {
  background-position: center start;
}
```

## 日期、货币、数字格式化

### 使用 Intl API

```typescript
// 日期格式化
const dateFormatter = new Intl.DateTimeFormat('zh-CN', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
  weekday: 'long',
});

dateFormatter.format(new Date('2024-01-15'));
// "2024年1月15日 星期一"

// 英文
new Intl.DateTimeFormat('en-US', {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
}).format(new Date('2024-01-15'));
// "January 15, 2024"

// 数字格式化
const numberFormatter = new Intl.NumberFormat('zh-CN');
numberFormatter.format(1234567.89);
// "1,234,567.89"

// 德语
new Intl.NumberFormat('de-DE').format(1234567.89);
// "1.234.567,89"

// 货币格式化
const currencyFormatter = new Intl.NumberFormat('zh-CN', {
  style: 'currency',
  currency: 'CNY',
});
currencyFormatter.format(1234.56);
// "¥1,234.56"

// 美元
new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
}).format(1234.56);
// "$1,234.56"
```

### 封装工具函数

```typescript
import i18n from 'i18next';

// 日期格式化
export function formatDate(date: Date | string, options?: Intl.DateTimeFormatOptions): string {
  const d = typeof date === 'string' ? new Date(date) : date;
  return new Intl.DateTimeFormat(i18n.language, {
    year: 'numeric',
    month: 'short',
    day: 'numeric',
    ...options,
  }).format(d);
}

// 相对时间
export function formatRelativeTime(date: Date | string): string {
  const d = typeof date === 'string' ? new Date(date) : date;
  const now = new Date();
  const diff = now.getTime() - d.getTime();

  const rtf = new Intl.RelativeTimeFormat(i18n.language, { numeric: 'auto' });

  if (diff < 60000) return rtf.format(-Math.floor(diff / 1000), 'second');
  if (diff < 3600000) return rtf.format(-Math.floor(diff / 60000), 'minute');
  if (diff < 86400000) return rtf.format(-Math.floor(diff / 3600000), 'hour');
  return rtf.format(-Math.floor(diff / 86400000), 'day');
}

// 货币格式化
export function formatCurrency(amount: number, currency = 'CNY'): string {
  return new Intl.NumberFormat(i18n.language, {
    style: 'currency',
    currency,
  }).format(amount);
}

// 使用
formatDate('2024-01-15'); // "2024年1月15日" 或 "Jan 15, 2024"
formatRelativeTime('2024-01-15T10:00:00'); // "3天前" 或 "3 days ago"
formatCurrency(1234.56); // "¥1,234.56" 或 "$1,234.56"
```

## 参考答案

### 练习一

```
1. 语言包组织结构：
   locales/
     en/
       common.json       - 通用 UI 文本
       product.json      - 商品相关
       cart.json         - 购物车相关
       checkout.json     - 结算相关
       order.json        - 订单相关
     zh-CN/
       (同上)
     ar/
       (同上)

2. 动态加载策略：
   - common.json 随主包加载（首屏需要）
   - 其他命名空间按路由加载
   - 预加载：用户进入首页时预加载 product.json
   - 缓存：localStorage 缓存已加载的语言包

3. RTL 支持：
   - 使用 CSS 逻辑属性（margin-inline-start 等）
   - 切换语言时设置 document.documentElement.dir
   - 图标镜像：箭头类图标 scaleX(-1)
   - 布局测试：开发时用阿拉伯语测试布局

4. 货币和日期：
   - 使用 Intl.NumberFormat 和 Intl.DateTimeFormat
   - 语言切换时自动更新格式
   - 货币：中文用 CNY，英文用 USD，阿拉伯语用 SAR
```
