# 毕业项目：企业级前端基建平台

## 项目概述

搭建一个完整的前端基建平台，包含 Monorepo 项目模板、企业级脚手架、组件库、构建配置、代码规范、监控 SDK 和 CI/CD 配置。目标是建立一个可直接用于团队的前端基础设施。

## 技术栈

- **包管理**：pnpm workspace
- **构建工具**：Vite
- **组件库**：React + TypeScript
- **代码规范**：ESLint + Prettier + Stylelint
- **监控**：自研 SDK
- **CI/CD**：GitHub Actions

## 核心功能

### 1. Monorepo 项目模板

- 支持多应用和多包结构
- 共享依赖和配置
- 增量构建和测试
- 统一的版本管理

### 2. 企业级脚手架

- `create` 命令：创建新项目
- `generate` 命令：生成组件、页面、Hook
- `add` 命令：添加插件
- `preset` 命令：管理预设

### 3. 组件库基础

- Button 按钮
- Input 输入框
- Modal 弹窗
- Toast 消息提示
- Tabs 标签页
- Table 表格
- Form 表单
- Select 选择器

### 4. 构建配置

- Vite 预设
- Webpack 预设
- 环境变量管理
- 代理配置

### 5. 代码规范

- ESLint 配置
- Prettier 配置
- Stylelint 配置
- Commitlint 配置

### 6. 监控 SDK

- 错误监控
- 性能采集
- 用户行为追踪
- 上报接口

### 7. CI/CD 配置

- 代码质量检查
- 自动化测试
- 多环境部署
- 灰度发布

│   ├── cli/                    # 脚手架工具
│   ├── config/                 # 配置包
│   │   ├── eslint/             # ESLint 配置

## 验收标准

```bash
cd frontend/frontend-architecture/final-project
node scripts/check.cjs
```

验证项：

- [ ] Monorepo 结构正确，可以正常构建
- [ ] 脚手架可以正常创建项目和生成代码
- [ ] 组件库包含所有要求的组件
- [ ] 构建配置支持多环境
- [ ] 代码规范配置完整
- [ ] 监控 SDK 可以正常工作
- [ ] CI/CD 流水线正常运行
- [ ] 有完整的文档
