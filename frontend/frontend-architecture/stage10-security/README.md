# stage10：安全与合规

> 安全不是"加上去的功能"，而是"内建到开发流程中的思维方式"

## 学习目标

完成本阶段后，你将能够：
- 理解前端安全的核心威胁和防御策略
- 掌握 XSS、CSRF、点击劫持等常见攻击的防御方法
- 学会配置 CSP（内容安全策略）和 SRI（子资源完整性）
- 了解依赖安全扫描和供应链攻击防御
- 掌握数据隐私合规（GDPR、CCPA）的前端实现
- 建立安全内建的开发流程

- 了解 HTTP 协议基础

## 学习建议

1. **从攻击者视角思考**：理解攻击原理才能有效防御
2. **实践优先**：每个安全概念都要动手实践
3. **不要过度防御**：安全措施要平衡安全性和用户体验
4. **持续关注**：安全威胁不断演变，需要持续学习
5. **团队协作**：安全是团队责任，不是一个人的事

## 常见问题

### Q: 前端安全真的那么重要吗？

A: 是的。前端是用户直接接触的界面，也是攻击者最容易接触的地方。XSS、CSRF、点击劫持等攻击都直接威胁用户数据和系统安全。

### Q: 安全措施会影响用户体验吗？

A: 部分安全措施可能会影响用户体验（如 CSP 可能限制某些功能），但大多数安全措施对用户透明。关键是找到安全性和用户体验的平衡点。

### Q: 如何快速提升项目安全性？

A: 从最简单、收益最高的措施开始：
1. 升级有漏洞的依赖
2. 添加基本的 HTTP 安全头
3. 对用户输入进行验证和编码
4. 使用 HTTPS

### Q: 安全审计需要多长时间？

A: 取决于项目规模和复杂度。小型项目可能需要 1-2 天，大型项目可能需要 1-2 周。建议定期进行安全审计，而不是等到出了问题才做。
