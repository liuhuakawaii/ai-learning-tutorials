# 应用图标与启动屏

## 场景引入

应用功能开发完成，但模拟器上仍然是 Expo 默认的灰色图标，启动屏一片空白。图标和启动屏是用户对应用的第一印象——粗糙的图标让人怀疑专业性，加载缓慢的启动屏会在前 3 秒赶走用户。本节课将完成图标设计、启动屏配置、品牌资源管理和暗色模式支持。

## 学习目标

1. 理解 iOS 和 Android 对应用图标的尺寸和格式要求
2. 使用 `expo-splash-screen` 配置启动屏并实现动画效果
3. 建立品牌资源管理规范，支持多分辨率和暗色模式

## 应用图标设计规范

### iOS 图标尺寸

| 用途 | 尺寸（px） | 说明 |
|------|-----------|------|
| App Store | 1024×1024 | 必须提供，不含透明通道 |
| iPhone @2x | 120×120 | 主屏幕图标 |
| iPhone @3x | 180×180 | 主屏幕图标 |
| iPad @2x | 167×167 | iPad Pro |
| 通知 @2x/@3x | 48/72 | 通知中心 |
| 设置 @2x/@3x | 58/87 | 系统设置 |

### Android 自适应图标

Android 使用前景层 + 背景层组成，常见密度：mdpi(48)、hdpi(72)、xhdpi(96)、xxhdpi(144)、xxxhdpi(192)。

### app.json 配置

```typescript
{
  "expo": {
    "icon": "./assets/icon.png",
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#1a1a2e",
        "monochromeImage": "./assets/monochrome-icon.png"
      }
    },
    "ios": { "icon": "./assets/icon.png" }
  }
}
```

设计原则：保持简洁（小尺寸可辨认）、安全区域（核心内容在中心 80%）、不含透明通道（iOS 审核拒绝）。

### 控制隐藏时机

```typescript
// App.tsx
import { useCallback, useEffect, useState } from 'react';
import { View } from 'react-native';
import * as SplashScreen from 'expo-splash-screen';
import { useFonts } from 'expo-font';

SplashScreen.preventAutoHideAsync();

export default function App() {
  const [fontsLoaded] = useFonts({
    'Inter-Regular': require('./assets/fonts/Inter-Regular.ttf'),
  });
  const [appReady, setAppReady] = useState(false);

  useEffect(() => {
    async function prepare() {
      try {
        await loadInitialData();
      } catch (e) {
        console.warn('资源预加载失败:', e);
      } finally {
        setAppReady(true);
      }
    }
    prepare();
  }, []);

  const onLayout = useCallback(async () => {
    if (fontsLoaded && appReady) {
      await SplashScreen.hideAsync();
    }
  }, [fontsLoaded, appReady]);

  if (!fontsLoaded || !appReady) return null;
  return <View style={{ flex: 1 }} onLayout={onLayout}>...</View>;
}

async function loadInitialData(): Promise<void> {
  await new Promise(resolve => setTimeout(resolve, 500));
}
```

### 启动屏动画效果

```typescript
// components/AnimatedSplash.tsx
import { useEffect, useRef } from 'react';
import { Animated, Dimensions, StyleSheet } from 'react-native';
import * as SplashScreen from 'expo-splash-screen';

const { width } = Dimensions.get('window');

export function AnimatedSplash({ onComplete }: { onComplete: () => void }) {
  const scale = useRef(new Animated.Value(0.5)).current;
  const opacity = useRef(new Animated.Value(0)).current;
  const containerOpacity = useRef(new Animated.Value(1)).current;

  useEffect(() => {
    Animated.parallel([
      Animated.spring(scale, { toValue: 1, friction: 6, tension: 40, useNativeDriver: true }),
      Animated.timing(opacity, { toValue: 1, duration: 600, useNativeDriver: true }),
    ]).start(() => {
      setTimeout(() => {
        Animated.timing(containerOpacity, {
          toValue: 0, duration: 400, useNativeDriver: true,
        }).start(async () => {
          await SplashScreen.hideAsync();
          onComplete();
        });
      }, 800);
    });
  }, []);

  return (
    <Animated.View style={[styles.container, { opacity: containerOpacity }]}>
      <Animated.Image
        source={require('../assets/brand/logo.png')}
        style={[styles.logo, { opacity, transform: [{ scale }] }]}
        resizeMode="contain"
      />
    </Animated.View>
  );
}

const styles = StyleSheet.create({
  container: {
    ...StyleSheet.absoluteFillObject,
    backgroundColor: '#1a1a2e',
    justifyContent: 'center',
    alignItems: 'center',
    zIndex: 999,
  },
  logo: { width: width * 0.4, height: width * 0.4 },
});
```

### 使用 Sharp 批量生成图标

```typescript
// scripts/generate-icons.ts
import sharp from 'sharp';
import path from 'path';
import fs from 'fs';

const SOURCE = path.resolve(__dirname, '../assets/brand/icon-1024.png');
const OUT = path.resolve(__dirname, '../assets/generated');

const specs = [
  { dir: 'ios', name: 'icon-120', size: 120 },
  { dir: 'ios', name: 'icon-180', size: 180 },
  { dir: 'ios', name: 'icon-167', size: 167 },
  { dir: 'android/mipmap-mdpi', name: 'ic_launcher', size: 48 },
  { dir: 'android/mipmap-hdpi', name: 'ic_launcher', size: 72 },
  { dir: 'android/mipmap-xhdpi', name: 'ic_launcher', size: 96 },
  { dir: 'android/mipmap-xxhdpi', name: 'ic_launcher', size: 144 },
  { dir: 'android/mipmap-xxxhdpi', name: 'ic_launcher', size: 192 },
];

async function main() {
  for (const { dir, name, size } of specs) {
    const outDir = path.join(OUT, dir);
    fs.mkdirSync(outDir, { recursive: true });
    await sharp(SOURCE)
      .resize(size, size, { fit: 'contain', background: '#1a1a2e' })
      .png()
      .toFile(path.join(outDir, `${name}.png`));
    console.log(`✓ ${dir}/${name}.png (${size}×${size})`);
  }
}

main().catch(console.error);
```

```typescript
import { useColorScheme } from 'react-native';

const ICONS = {
  light: require('../assets/brand/icon-1024.png'),

```

Android 13+ 支持单色图标主题，在 `adaptiveIcon` 中配置 `monochromeImage` 即可让图标跟随系统主题色变化。

## 常见误区

1. **使用小尺寸图片放大作为图标**：源文件必须 1024×1024，放大低分辨率图片会模糊
2. **启动屏 resizeMode 选错**：`cover` 裁切图片，`contain` 留白，需根据设计选择
3. **不等待资源加载就隐藏启动屏**：导致启动屏消失后出现白屏闪烁
4. **忽略 Android 自适应图标**：不配置前景层和背景层，部分设备图标显示异常
5. **图标包含透明通道**：iOS App Store 审核会拒绝透明图标

## 工程建议

1. **图标源文件使用矢量工具设计**：Figma 或 Sketch 设计，导出 1024×1024 PNG
2. **启动屏图片控制在 500KB 以内**：避免影响安装包大小
3. **启动屏背景色与应用主题一致**：避免隐藏时出现颜色跳变
4. **CI 集成图标生成脚本**：确保各平台图标同步更新
5. **定期检查 App Store 图标规范变更**

## 参考答案

### 练习一

**思路**：使用 `expo-splash-screen` 阻止自动隐藏，在 `App.tsx` 中等待资源加载完成后再调用 `hideAsync`。

```typescript
// App.tsx
import * as SplashScreen from 'expo-splash-screen';
import { useFonts } from 'expo-font';
import { useCallback, useEffect, useState } from 'react';
import { View } from 'react-native';

SplashScreen.preventAutoHideAsync();

export default function App() {
  const [fontsLoaded] = useFonts({ 'Inter': require('./assets/fonts/Inter.ttf') });
  const [dataReady, setDataReady] = useState(false);

  useEffect(() => {
    loadInitialData().finally(() => setDataReady(true));
  }, []);

  const onLayout = useCallback(async () => {
    if (fontsLoaded && dataReady) await SplashScreen.hideAsync();
  }, [fontsLoaded, dataReady]);

  if (!fontsLoaded || !dataReady) return null;
  return <View style={{ flex: 1 }} onLayout={onLayout}>...</View>;
}
```

**要点**：`preventAutoHideAsync` 在模块顶层调用；两个条件都满足后才隐藏。

### 练习二

**思路**：使用 `sharp` 对源图片缩放，遍历所有规格批量生成。

```typescript
import sharp from 'sharp';
import path from 'path';
import fs from 'fs';

const SOURCE = path.resolve(__dirname, '../assets/brand/icon-1024.png');
const OUT = path.resolve(__dirname, '../assets/generated');

const specs = [
  { dir: 'ios', name: 'icon-120', size: 120 },
  { dir: 'ios', name: 'icon-180', size: 180 },
  { dir: 'android/mipmap-xxhdpi', name: 'ic_launcher', size: 144 },
  { dir: 'android/mipmap-xxxhdpi', name: 'ic_launcher', size: 192 },
];

async function main() {
  for (const { dir, name, size } of specs) {
    const outDir = path.join(OUT, dir);
    fs.mkdirSync(outDir, { recursive: true });
    await sharp(SOURCE).resize(size, size, { fit: 'contain', background: '#1a1a2e' })
      .png().toFile(path.join(outDir, `${name}.png`));
    console.log(`✓ ${dir}/${name}.png`);
  }
}
main().catch(console.error);
```

**要点**：`sharp` 的 `resize` 支持 `fit` 模式；Android 按密度目录组织。
