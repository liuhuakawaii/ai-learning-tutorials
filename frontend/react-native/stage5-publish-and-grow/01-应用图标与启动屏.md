# 应用图标与启动屏

## 启动屏

用户点击 App 图标到看到第一个页面之间显示的画面。好的启动屏让应用感觉"秒开"。

### Expo 启动屏配置

```json
// app.json
{
  "expo": {
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#ffffff"
    }
  }
}
```

`resizeMode` 选项：
- `contain`：保持比例，完整显示
- `cover`：保持比例，填满屏幕（可能裁剪）
- `native`：原始尺寸

### 自定义启动屏

如果需要更复杂的启动屏（动画、渐变），用 `expo-splash-screen` 控制：

```typescript
import * as SplashScreen from 'expo-splash-screen'

SplashScreen.preventAutoHideAsync() // 阻止自动隐藏

export default function App() {
  const [ready, setReady] = useState(false)

  useEffect(() => {
    async function prepare() {
      await loadFonts()
      await loadInitialData()
      setReady(true)
      await SplashScreen.hideAsync() // 准备好后隐藏
    }
    prepare()
  }, [])

  if (!ready) return null
  return <MainApp />
}
```

## 应用图标

App 图标是用户在桌面上看到的第一印象。

### 尺寸要求

| 平台 | 尺寸 | 格式 |
|------|------|------|
| iOS | 1024×1024 | PNG（无透明） |
| Android | 512×512 | PNG（自适应图标有前景/背景） |

### Expo 图标配置

```json
// app.json
{
  "expo": {
    "icon": "./assets/icon.png",
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#ffffff"
      }
    }
  }
}
```

Android 自适应图标：前景图（Logo）+ 背景色。系统会自动裁剪成圆形、圆角矩形等形状。

### 设计原则

1. **简洁**：小尺寸下也能辨认
2. **高对比度**：在各种背景下都清晰
3. **无文字或极少文字**：文字在小图标上不可读
4. **品牌一致**：颜色和风格与品牌统一

### 练习三

```typescript
import * as SplashScreen from 'expo-splash-screen'
import Animated, { FadeIn } from 'react-native-reanimated'

SplashScreen.preventAutoHideAsync()

export default function App() {
  const [ready, setReady] = useState(false)

  useEffect(() => {
    loadData().then(() => {
      setReady(true)
      SplashScreen.hideAsync()
    })
  }, [])

  if (!ready) return null
  return <Animated.View entering={FadeIn.duration(500)}><MainApp /></Animated.View>
}
```
