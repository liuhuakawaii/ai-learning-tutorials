# 性能优化

## 场景引入

应用功能完善但用户反馈「打开太慢」「列表卡顿」「手机发烫」。性能直接影响留存——启动超过 3 秒，流失率增加 50%。React Native 性能瓶颈集中在：启动时间、内存管理、帧率、包体积。本节课从这四个维度系统讲解优化策略，介绍 Hermes 引擎和性能监测工具。

## 学习目标

1. 优化启动时间，实现预加载和懒加载
2. 管理内存，优化图片缓存和大列表渲染
3. 避免 JS 线程阻塞，保持 60fps
4. 使用 Tree Shaking 和 Code Splitting 减小包体积
5. 配置 Hermes 引擎

## 启动时间优化

### 预加载策略

```typescript
// services/Preloader.ts
import { Image } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

export class Preloader {
  private static ready = false;

  static async preloadEssentials(): Promise<void> {
    await Promise.allSettled([
      this.preloadImages(),
      this.preloadCache(),
    ]);
    this.ready = true;
  }

  private static async preloadImages(): Promise<void> {
    const images = [
      require('../assets/brand/logo.png'),
      require('../assets/home/banner.png'),
    ];
    await Promise.all(
      images.map((src) => Image.prefetch(Image.resolveAssetSource(src).uri))
    );
  }

  private static async preloadCache(): Promise<void> {
    await AsyncStorage.multiGet(['@user/profile', '@settings/app']);
  }

  static isReady(): boolean { return this.ready; }
}
```

```typescript
// App.tsx
import { Preloader } from './services/Preloader';

export default function App() {
  const [ready, setReady] = useState(false);

  useEffect(() => {
    Preloader.preloadEssentials().finally(() => setReady(true));
  }, []);

  if (!ready) return <SplashScreen />;
  return <RootNavigator />;
}
```

## 内存管理

### 图片优化

```typescript
// components/OptimizedImage.tsx
import { Image, ImageStyle, StyleProp } from 'react-native';
import FastImage from 'react-native-fast-image';

interface Props {
  source: { uri: string } | number;
  width?: number; height?: number;
  style?: StyleProp<ImageStyle>;
  useFastImage?: boolean;
}

export function OptimizedImage({ source, width, height, style, useFastImage = false }: Props) {
  const imageStyle = [width ? { width } : {}, height ? { height } : {}, style];

  if (useFastImage && typeof source === 'object' && 'uri' in source) {
    return <FastImage source={{ uri: source.uri, priority: FastImage.priority.normal }} style={imageStyle} />;
  }
  return <Image source={source} style={imageStyle} resizeMethod="resize" />;
}
```

### 大列表优化

```typescript
// components/OptimizedList.tsx
import { useCallback, useMemo } from 'react';
import { FlatList, FlatListProps } from 'react-native';

interface Props<T> extends Omit<FlatListProps<T>, 'renderItem'> {
  data: T[];
  renderItem: (item: T, index: number) => React.ReactElement;
  estimatedItemHeight?: number;
}

export function OptimizedList<T extends { id: string }>({
  data, renderItem, estimatedItemHeight = 80, ...props
}: Props<T>) {
  const keyExtractor = useCallback((item: T) => item.id, []);

  const getItemLayout = useCallback(
    (_: any, index: number) => ({
      length: estimatedItemHeight,
      offset: estimatedItemHeight * index,
      index,
    }),
    [estimatedItemHeight]
  );

  const handleRenderItem = useCallback(
    ({ item, index }: { item: T; index: number }) => renderItem(item, index),
    [renderItem]
  );

  return (
    <FlatList
      data={data}
      renderItem={handleRenderItem}
      keyExtractor={keyExtractor}
      getItemLayout={getItemLayout}
      removeClippedSubviews={true}
      maxToRenderPerBatch={10}
      windowSize={5}
      initialNumToRender={10}
      updateCellsBatchingPeriod={50}
      {...props}
    />
  );
}
```

### 动画性能

```typescript
// 使用 Reanimated 在 UI 线程执行动画
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

export function SmoothCard({ children }: { children: React.ReactNode }) {
  const scale = useSharedValue(1);
  const animatedStyle = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }] }));

  return (
    <Animated.View style={animatedStyle}
      onTouchStart={() => { scale.value = withSpring(0.95, { damping: 15 }); }}
      onTouchEnd={() => { scale.value = withSpring(1, { damping: 15 }); }}>
      {children}
    </Animated.View>
  );
}
```

## Hermes 引擎

Hermes 是 Meta 为 React Native 开发的 JS 引擎，专为移动端优化。

```jsonc
// app.json
{ "expo": { "jsEngine": "hermes" } }
```

| 指标 | Hermes | JSC |
|------|--------|-----|
| 启动时间 | ~350ms | ~650ms |
| 内存占用 | ~45MB | ~65MB |

核心优势：预编译字节码（启动时无需解析）、减少内存占用、更快启动。

## 性能监测工具

```typescript
// services/PerformanceTracker.ts
export class PerformanceTracker {
  private static marks = new Map<string, number>();

  static mark(name: string): void {
    this.marks.set(name, performance.now());
  }

  static async measureAsync<T>(name: string, fn: () => Promise<T>): Promise<T> {
    const start = performance.now();
    try { return await fn(); }
    finally { console.log(`[Perf] ${name}: ${(performance.now() - start).toFixed(1)}ms`); }
  }
}
```

## 常见误区

1. **过度使用 `useMemo` / `useCallback`**：轻量计算不值得缓存，缓存本身有开销
2. **忽略 `key` 稳定性**：使用 index 作为 key 导致不必要的重渲染
3. **在 render 中创建新对象**：每次新引用触发子组件重渲染
4. **FlatList 不设置 `getItemLayout`**：影响滚动性能
5. **图片不压缩**：原始大图消耗大量内存
6. **忽略 Hermes**：不启用则浪费启动性能

## 工程建议

1. **先测量再优化**：用性能工具找真正的瓶颈
2. **首屏优先**：只加载首屏必要的资源和代码
3. **图片使用 WebP 格式**：比 PNG 小 30%
4. **列表用 `getItemLayout`**：固定高度必须设置
5. **动画用 Reanimated**：移至 UI 线程
6. **CI 中检查 Bundle 体积**：防止膨胀

## 小结

从启动时间、内存、帧率、包体积四个维度讲解了优化。核心：预加载首屏资源、懒加载非首屏模块、FlatList 优化大列表、耗时操作移出 JS 线程、启用 Hermes。记住「先测量再优化」。

### 练习二

```typescript
export function OptimizedList<T extends { id: string }>({ data, renderItem, estimatedItemHeight = 80 }: any) {
  const keyExtractor = useCallback((item: T) => item.id, []);
  const getItemLayout = useCallback(
    (_: any, i: number) => ({ length: estimatedItemHeight, offset: estimatedItemHeight * i, index: i }),
    [estimatedItemHeight]
  );
  return (
    <FlatList
      data={data} renderItem={({ item, index }) => renderItem(item, index)}

```

**要点**：`getItemLayout` 跳过布局计算；`removeClippedSubviews` 减少内存；回调用 `useCallback` 稳定引用。
