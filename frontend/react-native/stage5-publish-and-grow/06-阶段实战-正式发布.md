# 阶段实战：正式发布

## 项目目标

把 AI 助手 App 从"开发环境能跑"变成"用户能下载"。覆盖构建、发布、OTA 更新、崩溃监控、性能优化。

## 发布前 Checklist

### 一、应用信息

- [ ] App 名称已确定
- [ ] Bundle Identifier / Package Name 已确定
- [ ] 版本号已设置（`app.json` 的 `version`）
- [ ] 应用图标已配置（1024×1024）
- [ ] 启动屏已配置
- [ ] 应用描述和截图已准备

### 二、功能验证

- [ ] 所有核心功能正常
- [ ] 错误状态有友好提示
- [ ] 网络异常有处理
- [ ] 低端设备测试通过
- [ ] iOS 和 Android 都测试过

### 三、性能

- [ ] 启动时间 < 2 秒
- [ ] 列表滚动流畅（60fps）
- [ ] 内存占用合理（< 200MB）
- [ ] 无内存泄漏

### 四、安全

- [ ] API Key 不在代码中硬编码
- [ ] 敏感数据加密存储
- [ ] 网络请求使用 HTTPS

## EAS Build

Expo 的云端构建服务：

```bash
# 安装 EAS CLI
npm install -g eas-cli

# 登录
eas login

# 配置构建
eas build:configure

# 构建 iOS
eas build --platform ios

# 构建 Android
eas build --platform android

# 同时构建
eas build --platform all
```

`eas.json` 配置：

```json
{
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "preview": {
      "distribution": "internal"
    },
    "production": {}
  }
}
```

## App Store 发布

### iOS

1. 在 Apple Developer 注册开发者账号
2. 在 App Store Connect 创建应用
3. 用 EAS Build 构建 `.ipa`
4. 用 `eas submit` 上传到 App Store Connect
5. 填写应用信息、截图、描述
6. 提交审核

```bash
eas submit --platform ios
```

### Android

1. 在 Google Play Console 创建应用
2. 用 EAS Build 构建 `.aab`
3. 上传到 Google Play Console
4. 填写应用信息
5. 提交审核

```bash
eas submit --platform android
```

## OTA 热更新

不需要重新发版，直接推送代码更新：

```bash
# 发布 OTA 更新
eas update --branch production --message "修复 bug"
```

```typescript
// app/_layout.tsx
import * as Updates from 'expo-updates'

export default function RootLayout() {
  useEffect(() => {
    async function checkUpdate() {
      const update = await Updates.checkForUpdateAsync()
      if (update.isAvailable) {
        await Updates.fetchUpdateAsync()
        await Updates.reloadAsync() // 立即应用更新
      }
    }
    checkUpdate()
  }, [])
}
```

OTA 更新的限制：只能更新 JS 代码和资源，不能更新原生代码。

## 性能优化

### 启动优化

```typescript
// 延迟加载非关键模块
const HeavyComponent = lazy(() => import('./HeavyComponent'))
```

### 列表优化

```tsx
<FlatList
  data={items}
  renderItem={renderItem}
  getItemLayout={(data, index) => ({ length: 80, offset: 80 * index, index })}
  maxToRenderPerBatch={10}
  windowSize={5}
  removeClippedSubviews
/>
```

### 图片优化

```tsx
<Image source={{ uri: url }} style={{ width, height }} resizeMode="cover" />
```

使用适当尺寸的图片，不要加载 4000×3000 的图片显示在 100×100 的区域。
