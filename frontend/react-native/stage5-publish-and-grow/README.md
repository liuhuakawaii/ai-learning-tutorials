# Stage 5：发布与增长

> 从开发完成到正式上架——图标、启动屏、审核、热更新、监控、性能优化。

## 学习目标

完成本阶段后，你将能够：

1. 设计符合规范的应用图标与启动屏
2. 完成 iOS/Android 应用商店提交
3. 配置 OTA 热更新
4. 集成崩溃监控与性能追踪
5. 优化应用启动时间和运行性能
6. 完成应用的正式发布流程

## 课时列表

| # | 课时 | 核心内容 |
|---|------|----------|
| 01 | 应用图标与启动屏 | 品牌资源、多分辨率适配 |
| 02 | App Store 发布 | iOS/Android 审核、ASO 优化 |
| 03 | OTA 热更新 | EAS Update、版本管理 |
| 04 | 崩溃监控 | Sentry 集成、崩溃分析 |
| 05 | 性能优化 | 启动时间、内存、帧率优化 |
| 06 | 阶段实战：正式发布 | 完成发布流程 |

## 阶段项目

正式发布——完成图标设计、商店提交、热更新配置、监控告警、性能优化的完整流程。
