# 生物识别

## 场景引入

你在做一个金融 App，用户每次打开都要输入密码，体验很差。产品经理要求加入 Face ID 和指纹解锁——但实际开发中你会遇到：设备不支持生物识别怎么办？Face ID 被拒绝后是否降级到密码？SecureStore 存的密钥在生物识别通过后才能解密，流程怎么设计？这节课我们把生物识别从调用到架构设计完整走一遍。

## 学习目标

- 使用 expo-local-authentication 实现 Face ID 和指纹认证
- 设计生物识别与密码回退的降级策略
- 使用 expo-secure-store 安全存储敏感数据
- 理解生物识别的局限性和安全边界
- 将生物识别应用到支付确认和应用锁场景

## 一、expo-local-authentication

### 1.1 安装配置

```bash
npx expo install expo-local-authentication
```

```json
// app.json
{ "expo": { "plugins": [["expo-local-authentication", { "faceIDPermission": "用于快速解锁和确认支付" }]] } }
```

iOS 需在 Info.plist 添加 `NSFaceIDUsageDescription`。

### 1.2 检查设备能力

```typescript
import * as LocalAuthentication from 'expo-local-authentication'

async function checkBiometricCapability() {
  const hasHardware = await LocalAuthentication.hasHardwareAsync()
  const supportedTypes = await LocalAuthentication.supportedAuthenticationTypesAsync()
  const isEnrolled = await LocalAuthentication.isEnrolledAsync()

  return {
    isAvailable: hasHardware && isEnrolled,
    hasHardware,
    supportedTypes,
    isEnrolled,
    typeName: getBiometricType(supportedTypes),
  }
}

function getBiometricType(types: LocalAuthentication.AuthenticationType[]): string {
  if (types.includes(LocalAuthentication.AuthenticationType.FACIAL_RECOGNITION)) return 'Face ID'
  if (types.includes(LocalAuthentication.AuthenticationType.FINGERPRINT)) return '指纹'
  if (types.includes(LocalAuthentication.AuthenticationType.IRIS)) return '虹膜'
  return '生物识别'
}
```

### 1.3 发起认证

```typescript
async function authenticate(prompt: string) {
  const capability = await checkBiometricCapability()
  if (!capability.isAvailable) {
    return { success: false, error: capability.hasHardware ? '未设置生物识别' : '设备不支持' }
  }

  const result = await LocalAuthentication.authenticateAsync({
    prompt, cancelLabel: '取消', disableDeviceFallback: false,
  })

  if (result.success) return { success: true }

  const errorMap: Record<string, string> = {
    user_cancel: '用户取消', user_fallback: '用户选择密码',
    lockout: '多次失败已锁定', not_enrolled: '未设置生物识别',
  }
  return { success: false, error: errorMap[result.error ?? ''] ?? '认证失败' }
}
```

## 二、降级策略设计

```
初始状态 → 检查能力 → 生物识别可用？→ 是 → 生物识别认证 → 成功 → 已认证
                ↓ 否                         ↓ 失败
            密码认证 ←─────────────────── 用户选择密码
                ↓ 失败
            认证失败
```

```typescript
async function authenticateWithFallback(config: {
  maxRetries?: number; allowPassword?: boolean; prompt?: string
} = {}) {
  const { maxRetries = 3, allowPassword = true, prompt = '请验证身份' } = config

  const capability = await checkBiometricCapability()
  if (!capability.isAvailable) {
    return allowPassword
      ? { status: await authenticateWithPassword(), method: 'password' as const }
      : { status: 'failed', method: 'biometric' as const }
  }

  for (let i = 0; i < maxRetries; i++) {
    const result = await LocalAuthentication.authenticateAsync({
      prompt: i > 0 ? `${prompt}（第 ${i + 1} 次）` : prompt,
      disableDeviceFallback: !allowPassword,
    })

    if (result.success) return { status: 'authenticated', method: 'biometric' as const }

    if (['user_fallback', 'lockout'].includes(result.error ?? '') && allowPassword) {
      return { status: await authenticateWithPassword(), method: 'password' as const }
    }
  }
  return { status: 'failed', method: 'biometric' as const }
}

async function authenticateWithPassword(): Promise<string> {
  // 实际实现中弹出密码输入 Modal
  return 'authenticated'
}
```

## 三、安全存储 SecureStore

```bash
npx expo install expo-secure-store
```

```typescript
import * as SecureStore from 'expo-secure-store'

// 基本操作
async function saveSecure(key: string, value: string) {
  await SecureStore.setItemAsync(key, value, {
    keychainAccessible: SecureStore.WHEN_UNLOCKED_THIS_DEVICE_ONLY,
  })
}

async function getSecure(key: string) {
  return SecureStore.getItemAsync(key)
}
```

| 访问选项 | 说明 | 安全性 |
|---------|------|-------|
| `WHEN_UNLOCKED` | 设备解锁时可访问 | 中 |
| `WHEN_UNLOCKED_THIS_DEVICE_ONLY` | 仅本设备解锁时 | 高 |
| `AFTER_FIRST_UNLOCK` | 首次解锁后一直可访问 | 低 |

## 四、应用锁实现

```typescript
import { useState, useEffect, useCallback } from 'react'
import { AppState } from 'react-native'

const LOCK_TIMEOUT = 60 * 1000

export function useAppLock() {
  const [isLocked, setIsLocked] = useState(false)
  const [enabled, setEnabled] = useState(false)

  useEffect(() => {
    SecureStore.getItemAsync('app_lock_enabled').then(v => setEnabled(v === 'true'))
  }, [])

  useEffect(() => {
    if (!enabled) return
    const sub = AppState.addEventListener('change', async (state) => {
      if (state === 'background') {
        await SecureStore.setItemAsync('last_active', Date.now().toString())
      } else if (state === 'active') {
        const last = await SecureStore.getItemAsync('last_active')
        if (last && Date.now() - parseInt(last) > LOCK_TIMEOUT) setIsLocked(true)
      }
    })
    return () => sub.remove()
  }, [enabled])

  const unlock = useCallback(async () => {
    const result = await authenticate('解锁应用')
    if (result.success) { setIsLocked(false); return true }
    return false
  }, [])

  return { isLocked, enabled, unlock, toggle: async (v: boolean) => {
    await SecureStore.setItemAsync('app_lock_enabled', v.toString())
    setEnabled(v)
    if (v) setIsLocked(true)
  }}
}
```

## 五、支付确认场景

```typescript
async function confirmPayment(payment: { amount: number; recipient: string }) {
  const userConfirmed = await new Promise<boolean>(resolve => {
    Alert.alert('确认支付', `向 ${payment.recipient} 支付 ¥${payment.amount.toFixed(2)}`, [
      { text: '取消', style: 'cancel', onPress: () => resolve(false) },
      { text: '确认支付', onPress: () => resolve(true) },
    ])
  })

  if (!userConfirmed) return false

  const { typeName } = await checkBiometricCapability()
  const authResult = await authenticate(`使用${typeName}确认支付`)
  return authResult.success
}
```

## 六、平台差异

| 特性 | iOS | Android |
|------|-----|---------|
| 生物识别 | Face ID / Touch ID | 指纹 / 面部 / 虹膜 |
| 密码回退 | 系统密码 | 设备密码/PIN/图案 |
| 安全存储 | Keychain | Android Keystore |
| 面部安全 | 高（结构光） | 参差不齐（2D/3D） |

---

## 常见误区

1. **把生物识别当作唯一认证手段**：它是设备级认证，服务端仍需验证 Token。
2. **SecureStore 存大量数据**：设计用于 < 2KB 的密钥和 Token，大量数据用加密 SQLite。
3. **不处理不可用情况**：部分设备不支持、用户未设置、硬件损坏，必须有密码回退。
4. **后台调用认证**：`authenticateAsync` 必须在前台调用，后台会直接失败。

---

## 工程建议

1. **认证结果缓存 5 分钟**，期间操作不重复弹窗，切后台后重新认证。
2. **SecureStore key 加应用前缀**，如 `com.myapp.auth_token`，避免冲突。
3. **lockout 时引导用户去系统设置解锁**，而非只显示"失败"。
4. **支付场景用 `requireConfirmation: true`**，Android 需额外点击确认。

---

## 小结

- expo-local-authentication 封装了 Face ID 和指纹认证，使用前必须检查设备能力
- 降级策略是核心：设备不支持→密码，用户取消→密码，锁定→密码
- expo-secure-store 提供 Keychain/Keystore 级安全存储，适合 Token 和密钥
- 生物识别是设备级认证，保护本地凭证，不能替代服务端认证

## 参考答案

### 练习一

**思路**：检查设备能力，开启时验证一次，关闭时走密码流程。

**答案**：

```typescript
import { useState, useEffect } from 'react'
import { View, Text, Switch, Alert } from 'react-native'
import * as SecureStore from 'expo-secure-store'
import * as LocalAuthentication from 'expo-local-authentication'

export function BiometricSettings() {
  const [enabled, setEnabled] = useState(false)
  const [capability, setCapability] = useState({ available: false, typeName: '生物识别' })

  useEffect(() => {
    (async () => {
      const hasHardware = await LocalAuthentication.hasHardwareAsync()
      const isEnrolled = await LocalAuthentication.isEnrolledAsync()
      const types = await LocalAuthentication.supportedAuthenticationTypesAsync()
      const typeName = types.includes(LocalAuthentication.AuthenticationType.FACIAL_RECOGNITION) ? 'Face ID'
        : types.includes(LocalAuthentication.AuthenticationType.FINGERPRINT) ? '指纹' : '生物识别'
      setCapability({ available: hasHardware && isEnrolled, typeName })
      setEnabled((await SecureStore.getItemAsync('biometric_enabled')) === 'true')
    })()
  }, [])

  const handleToggle = async (value: boolean) => {
    if (value) {
      const result = await LocalAuthentication.authenticateAsync({ prompt: `验证${capability.typeName}以开启` })
      if (!result.success) return
      await SecureStore.setItemAsync('biometric_enabled', 'true')
      setEnabled(true)
    } else {
      Alert.alert('确认关闭', '关闭后将使用密码解锁', [
        { text: '取消', style: 'cancel' },
        { text: '确认', style: 'destructive', onPress: async () => {
          await SecureStore.setItemAsync('biometric_enabled', 'false')
          setEnabled(false)
        }},
      ])
    }
  }

  if (!capability.available) return <Text style={{ padding: 20, color: '#999' }}>设备未设置{capability.typeName}</Text>

  return (
    <View style={{ flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 16, backgroundColor: '#fff', borderRadius: 12 }}>
      <View>
        <Text style={{ fontSize: 16, fontWeight: '600' }}>{capability.typeName}解锁</Text>
        <Text style={{ fontSize: 13, color: '#666' }}>使用{capability.typeName}快速解锁</Text>
      </View>
      <Switch value={enabled} onValueChange={handleToggle} />
    </View>
  )
}
```

### 练习二

**思路**：SecureStore 存储笔记 JSON，每次读写都经过生物识别验证。初始状态显示"点击查看笔记"按钮，点击后触发认证，通过后加载内容。保存时再次认证。

**答案要点**：
- `authUser()` 先检查硬件和注册状态，不支持则跳过认证直接返回 true
- 笔记 key 用 `note_${noteId}` 前缀，避免与其他 SecureStore 数据冲突
- `WHEN_UNLOCKED_THIS_DEVICE_ONLY` 确保数据不被备份到其他设备
- 初始状态用 `loaded` 标志控制，未认证时不渲染任何敏感内容
- 大量笔记应改用加密的 SQLite 数据库，SecureStore 适合 < 2KB 的小数据
