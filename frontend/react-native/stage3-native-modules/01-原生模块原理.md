# 原生模块原理

## 为什么需要原生模块

React Native 的核心能力来自 JavaScript，但有些功能 JavaScript 做不到：

- 访问硬件（摄像头、蓝牙、NFC、GPS）
- 调用系统 API（生物识别、推送通知、文件系统）
- 高性能计算（图像处理、音视频编解码）
- 后台任务（后台定位、后台下载）

这些需要调用平台原生 API（iOS 的 Swift/ObjC，Android 的 Kotlin/Java）。

## 三种方式获取原生能力

### 1. Expo SDK 模块

最简单。Expo 封装了常用原生功能：

```bash
npx expo install expo-camera expo-location expo-notifications
```

```typescript
import { Camera } from 'expo-camera'
import * as Location from 'expo-location'

const { status } = await Camera.requestCameraPermissionsAsync()
const location = await Location.getCurrentPositionAsync()
```

### 2. Expo Dev Client

当 Expo SDK 没有你需要的功能，但社区有原生模块时：

```bash
npx expo install expo-dev-client
npx expo prebuild
```

这会生成 `ios/` 和 `android/` 目录，可以添加任何原生依赖。

### 3. Bare React Native

完全脱离 Expo，手动管理原生代码。适用于深度定制场景。

## Expo 模块的工作原理

```
JavaScript 层
  ↓ 调用
Expo Module API
  ↓ 桥接
原生层 (Swift/Kotlin)
  ↓ 调用
系统 API (iOS/Android)
```

Expo SDK 52+ 使用 Expo Modules API，比旧的 Turbo Modules 更简洁：

```swift
// iOS 原生模块示例
import ExpoModulesCore

public class MyModule: Module {
  public func definition() -> ModuleDefinition {
    Name("MyModule")

    Function("getDeviceName") { () -> String in
      return UIDevice.current.name
    }
  }
}
```

```typescript
// JavaScript 调用
import MyModule from './MyModule'
const name = MyModule.getDeviceName()
```

## 权限处理

原生功能通常需要用户授权：

```typescript
import { Camera } from 'expo-camera'

// 请求权限
const { status } = await Camera.requestCameraPermissionsAsync()

if (status !== 'granted') {
  Alert.alert('需要权限', '请在设置中允许访问摄像头')
  return
}

// 使用功能
<Camera style={{ flex: 1 }} />
```

权限状态：
- `granted`：已授权
- `denied`：已拒绝（可以再次请求）
- `never_ask_again`：永久拒绝（只能去设置里手动开启）

## 跨平台差异

同一个功能在 iOS 和 Android 上可能有不同行为：

```typescript
import { Platform } from 'react-native'

if (Platform.OS === 'ios') {
  // iOS 特有逻辑
} else {
  // Android 特有逻辑
}
```

常见差异：
- 推送通知的权限模型不同
- 文件路径格式不同
- 后台任务的限制不同
- 某些 API 只在一个平台可用

## 练习

### 练习一：权限封装

封装一个 `usePermission` Hook，统一处理权限请求、拒绝、永久拒绝三种状态。

### 练习二：跨平台适配

用 `Platform.select` 为 iOS 和 Android 设置不同的样式。

### 练习三：设备信息

用 `expo-device` 获取设备信息（型号、系统版本、是否模拟器），展示在页面上。

## 参考答案

### 练习一

```typescript
function usePermission(requestFn: () => Promise<{ status: string }>) {
  const [status, setStatus] = useState('undetermined')

  const request = async () => {
    const result = await requestFn()
    setStatus(result.status)
    return result.status
  }

  return { status, request, isGranted: status === 'granted' }
}

// 使用
const cameraPermission = usePermission(Camera.requestCameraPermissionsAsync)
```

### 练习二

```typescript
import { Platform } from 'react-native'

const styles = StyleSheet.create({
  container: {
    ...Platform.select({
      ios: { shadowColor: '#000', shadowOffset: { width: 0, height: 2 }, shadowOpacity: 0.1 },
      android: { elevation: 4 },
    }),
  },
})
```

### 练习三

```typescript
import * as Device from 'expo-device'

export default function DeviceInfo() {
  return (
    <View>
      <Text>型号: {Device.modelName}</Text>
      <Text>系统: {Device.osName} {Device.osVersion}</Text>
      <Text>模拟器: {Device.isDevice ? '否' : '是'}</Text>
    </View>
  )
}
```
