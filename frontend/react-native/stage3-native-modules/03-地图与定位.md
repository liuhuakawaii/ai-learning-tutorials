# 地图与定位

## 场景引入

你在做一个外卖配送 App，骑手需要实时定位、地图上显示商家和用户位置、计算最优配送路线。核心挑战：GPS 定位有误差（室内可达 50 米）、地图渲染大量 Marker 会卡顿、后台定位消耗电量、不同设备定位精度差异巨大。这节课从定位原理到地图实战，把 LBS 能力打通。

## 学习目标

- 使用 expo-location 获取 GPS 定位并理解精度等级
- 集成 react-native-maps 显示地图和自定义标注
- 实现地理围栏检测和区域进出通知
- 处理定位权限和精度策略
- 了解路线规划 API 的接入方式

### 1.2 获取当前位置

```typescript
import * as Location from 'expo-location'

async function getCurrentPosition() {
  const { status } = await Location.requestForegroundPermissionsAsync()
  if (status !== 'granted') return null

  const location = await Location.getCurrentPositionAsync({
    accuracy: Location.Accuracy.Balanced,
  })

  return {
    latitude: location.coords.latitude,
    longitude: location.coords.longitude,
    accuracy: location.coords.accuracy,
    timestamp: location.timestamp,
  }
}
```

### 1.3 精度等级选择

| 精度等级 | 误差 | 电量 | 适用场景 |
|---------|------|------|---------|
| `Lowest` | 3000m | 极低 | 城市级推荐 |
| `Low` | 1000m | 低 | 天气推送 |
| `Balanced` | 100m | 中 | 大部分场景 |
| `High` | 10m | 高 | 导航配送 |
| `BestForNavigation` | 3m | 极高 | 精确导航 |

## 三、地理围栏

```typescript
function calculateDistance(lat1: number, lon1: number, lat2: number, lon2: number): number {
  const R = 6371000
  const dLat = (lat2 - lat1) * Math.PI / 180
  const dLon = (lon2 - lon1) * Math.PI / 180
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) * Math.sin(dLon / 2) ** 2
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a))
}

function useGeofenceMonitoring(regions: GeofenceRegion[]) {
  const insideRegions = useRef<Set<string>>(new Set())

  useEffect(() => {
    let sub: Location.LocationSubscription
    const start = async () => {
      sub = await Location.watchPositionAsync(
        { accuracy: Location.Accuracy.High, distanceInterval: 10 },
        (location) => {
          const { latitude, longitude } = location.coords
          regions.forEach(region => {
            const dist = calculateDistance(latitude, longitude, region.latitude, region.longitude)
            const isInside = dist <= region.radius
            const wasInside = insideRegions.current.has(region.id)
            if (isInside && !wasInside) {
              insideRegions.current.add(region.id)
              console.log(`进入区域: ${region.id}`)
            } else if (!isInside && wasInside) {
              insideRegions.current.delete(region.id)
              console.log(`离开区域: ${region.id}`)
            }
          })
        }
      )
    }
    start()
    return () => sub?.remove()
  }, [regions])
}
```

## 四、路线规划

```typescript
async function getRoute(
  origin: { latitude: number; longitude: number },
  destination: { latitude: number; longitude: number },
  apiKey: string
) {
  const url = `https://maps.googleapis.com/maps/api/directions/json?origin=${origin.latitude},${origin.longitude}&destination=${destination.latitude},${destination.longitude}&mode=walking&key=${apiKey}`

  const response = await fetch(url)
  const data = await response.json()
  if (data.status !== 'OK' || !data.routes.length) return null

  const leg = data.routes[0].legs[0]
  return {
    distance: leg.distance.value,
    duration: leg.duration.value,
    polyline: data.routes[0].overview_polyline.points,
  }
}

// 解码 Polyline 并显示在地图上
import { Polyline } from 'react-native-maps'

function decodePolyline(encoded: string) {
  const points: { latitude: number; longitude: number }[] = []
  let index = 0, lat = 0, lng = 0
  while (index < encoded.length) {
    let shift = 0, result = 0, byte: number
    do { byte = encoded.charCodeAt(index++) - 63; result |= (byte & 0x1f) << shift; shift += 5 } while (byte >= 0x20)
    lat += (result & 1) ? ~(result >> 1) : (result >> 1)
    shift = 0; result = 0
    do { byte = encoded.charCodeAt(index++) - 63; result |= (byte & 0x1f) << shift; shift += 5 } while (byte >= 0x20)
    lng += (result & 1) ? ~(result >> 1) : (result >> 1)
    points.push({ latitude: lat / 1e5, longitude: lng / 1e5 })
  }
  return points
}
```

TaskManager.defineTask(BG_TASK, ({ data, error }) => {

async function startBackgroundLocation() {
  const { status } = await Location.requestBackgroundPermissionsAsync()

    accuracy: Location.Accuracy.Balanced,

## 常见误区

1. **一上来就用最高精度**：`BestForNavigation` 快速消耗电量，大部分场景用 `Balanced` 足够。
2. **不处理定位失败**：室内、隧道 GPS 信号弱，必须处理超时和低精度。
3. **地图 Marker 不加限制**：数百个 Marker 会卡顿，使用聚类算法合并。
4. **后台定位不做电量优化**：设置合理的 `distanceInterval` 和 `deferredUpdatesInterval`。

---

## 工程建议

1. **定位精度按业务动态调整**：搜索用 Balanced，导航切换 BestForNavigation，退出恢复。
2. **路线规划结果缓存 5 分钟**，减少 API 调用。
3. **后台定位必须配置前台服务**，否则 Android 会杀掉任务。
4. **测试时用模拟 GPS 轨迹**，验证围栏和路线偏差。

---

## 小结

- expo-location 提供完整定位能力，精度等级应根据场景选择
- react-native-maps 支持自定义 Marker，大量标注需聚类优化
- 地理围栏用 `watchPositionAsync` 实时监听比定时轮询更高效
- 路线规划需调用第三方 API，结果解码为 Polyline 显示在地图上

## 参考答案

### 练习一

**思路**：Haversine 公式计算距离，排序后渲染列表和 Marker。

**答案**：

```typescript
import { useState, useEffect } from 'react'
import { View, Text, FlatList } from 'react-native'
import MapView, { Marker } from 'react-native-maps'
import * as Location from 'expo-location'

interface Shop { id: string; name: string; latitude: number; longitude: number }

function haversine(lat1: number, lon1: number, lat2: number, lon2: number): number {
  const R = 6371000, dLat = (lat2 - lat1) * Math.PI / 180, dLon = (lon2 - lon1) * Math.PI / 180
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) * Math.sin(dLon / 2) ** 2
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a))
}

export function NearbyShops({ shops }: { shops: Shop[] }) {
  const [location, setLocation] = useState<Location.LocationObject | null>(null)
  const [sorted, setSorted] = useState<(Shop & { distance: number })[]>([])

  useEffect(() => {
    (async () => {
      const { status } = await Location.requestForegroundPermissionsAsync()
      if (status !== 'granted') return
      const loc = await Location.getCurrentPositionAsync()
      setLocation(loc)
      setSorted(shops
        .map(s => ({ ...s, distance: haversine(loc.coords.latitude, loc.coords.longitude, s.latitude, s.longitude) }))
        .sort((a, b) => a.distance - b.distance)
      )
    })()
  }, [shops])

  if (!location) return <Text>获取位置中...</Text>
  return (
    <View style={{ flex: 1 }}>
      <MapView style={{ flex: 1 }} initialRegion={{ ...location.coords, latitudeDelta: 0.02, longitudeDelta: 0.02 }} showsUserLocation>
        {sorted.map(s => (
          <Marker key={s.id} coordinate={{ latitude: s.latitude, longitude: s.longitude }}
            pinColor={s.distance < 1000 ? '#34C759' : '#8E8E93'} title={s.name}
            description={s.distance < 1000 ? `${Math.round(s.distance)}m` : `${(s.distance / 1000).toFixed(1)}km`} />
        ))}
      </MapView>
      <FlatList data={sorted} style={{ maxHeight: 200 }} keyExtractor={i => i.id}
        renderItem={({ item }) => (
          <View style={{ flexDirection: 'row', padding: 12, borderBottomWidth: 0.5, borderBottomColor: '#eee' }}>
            <Text style={{ flex: 1 }}>{item.name}</Text>
            <Text style={{ color: '#007AFF' }}>{item.distance < 1000 ? `${Math.round(item.distance)}m` : `${(item.distance / 1000).toFixed(1)}km`}</Text>
          </View>
        )}
      />
    </View>
  )
}
```

### 练习二

**思路**：用 `Circle` 组件绘制围栏区域，`watchPositionAsync` 持续监听位置，`distanceInterval: 5` 每移动 5 米触发检测。围栏内部填充绿色半透明，外部填充红色。底部状态栏动态切换颜色和文字。

**答案要点**：
- 围栏中心 `FENCE = { latitude: 39.9042, longitude: 116.4074, radius: 200 }`
- `Circle` 的 `fillColor` 和 `strokeColor` 根据 `inside` 状态动态切换
- 状态栏用 `backgroundColor: inside ? '#34C759' : '#FF3B30'` 提供即时视觉反馈
- 实际签到还需校验时间（工作时间段）和防作弊（模拟定位检测）
