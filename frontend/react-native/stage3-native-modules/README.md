# Stage 3：原生模块

> 穿透 JavaScript 层，调用设备原生能力——摄像头、地图、蓝牙、生物识别。

## 学习目标

完成本阶段后，你将能够：

1. 理解 React Native 原生模块架构演进
2. 使用 expo-camera 拍照录像
3. 集成地图与 GPS 定位
4. 实现蓝牙通信
5. 集成 Face ID / 指纹认证
6. 完成一个带地图和生物识别的签到 App

## 课时列表

| # | 课时 | 核心内容 |
|---|------|----------|
| 01 | 原生模块原理 | Bridge/JSI/Turbo Modules |
| 02 | Camera 与图片 | expo-camera、图片选择、裁剪 |
| 03 | 地图与定位 | react-native-maps、GPS 定位 |
| 04 | 蓝牙与 NFC | 低功耗蓝牙通信 |
| 05 | 生物识别 | Face ID/指纹认证 |
| 06 | 阶段实战：签到 App | 带地图和生物识别的签到 App |

## 阶段项目

签到 App——支持地图定位签到、生物识别验证、签到记录存储。
