# 手势与动画

## 场景引入

用户在任务列表中向左滑动卡片露出"删除"按钮，下拉刷新有弹性回弹，任务完成时打勾有缩放动画——这些交互细节决定 App 是否"好用"。React Native 没有 CSS 动画，需要用 `react-native-gesture-handler` 处理手势，`react-native-reanimated` 处理动画。

## 学习目标

- 掌握 RNGH 基础手势（点击、长按、拖拽、滑动）
- 理解 Reanimated 3 核心工作流
- 实现页面过渡动画和列表动画
- 实现手势驱动动画

## React Native Gesture Handler 基础

```bash
npx expo install react-native-gesture-handler react-native-reanimated
```

**点击手势：**

```tsx
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

function TapExample() {
  const scale = useSharedValue(1);
  const tap = Gesture.Tap()
    .onBegin(() => { scale.value = withSpring(0.9); })
    .onFinalize(() => { scale.value = withSpring(1); });
  const style = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }] }));

  return (
    <GestureDetector gesture={tap}>
      <Animated.View style={[styles.card, style]}><Text>点击我</Text></Animated.View>
    </GestureDetector>
  );
}
```

**拖拽手势：**

```tsx
function DragExample() {
  const translateX = useSharedValue(0);
  const translateY = useSharedValue(0);
  const context = useSharedValue({ x: 0, y: 0 });

  const drag = Gesture.Pan()
    .onStart(() => { context.value = { x: translateX.value, y: translateY.value }; })
    .onUpdate((e) => {
      translateX.value = context.value.x + e.translationX;
      translateY.value = context.value.y + e.translationY;
    })
    .onEnd(() => {
      translateX.value = withSpring(0);
      translateY.value = withSpring(0);
    });

  const style = useAnimatedStyle(() => ({
    transform: [{ translateX: translateX.value }, { translateY: translateY.value }],
  }));

  return (
    <GestureDetector gesture={drag}>
      <Animated.View style={[styles.box, style]} />
    </GestureDetector>
  );
}
```

**滑动删除手势：**

```tsx
function SwipeToDelete({ onDelete }: { onDelete: () => void }) {
  const translateX = useSharedValue(0);
  const itemHeight = useSharedValue(70);
  const opacity = useSharedValue(1);

  const swipe = Gesture.Pan()
    .activeOffsetX([-20, 20])
    .onUpdate((e) => { if (e.translationX < 0) translateX.value = e.translationX; })
    .onEnd((e) => {
      if (e.translationX < -120) {
        translateX.value = withSpring(-400);
        itemHeight.value = withSpring(0);
        opacity.value = withSpring(0, {}, () => { 'worklet'; runOnJS(onDelete)(); });
      } else {
        translateX.value = withSpring(0);
      }
    });

  const style = useAnimatedStyle(() => ({
    transform: [{ translateX: translateX.value }],
    height: itemHeight.value,
    opacity: opacity.value,
  }));

  return (
    <GestureDetector gesture={swipe}>
      <Animated.View style={[styles.item, style]}>
        <Text>向左滑动删除</Text>
      </Animated.View>
    </GestureDetector>
  );
}
```

## Reanimated 3 核心工作流

Reanimated 在 UI 线程执行动画，不阻塞 JS 线程。

**useSharedValue**：JS 和 UI 线程共享的可变值。

```tsx
const offset = useSharedValue(0);
offset.value = 100; // 直接赋值
```

**useAnimatedStyle**：根据 SharedValue 动态生成样式。

```tsx
const style = useAnimatedStyle(() => ({
  transform: [{ translateX: offset.value }],
  opacity: interpolate(offset.value, [0, 100], [1, 0]),
}));
```

**动画函数：**

```tsx
// 弹簧动画（最常用）
offset.value = withSpring(100, { damping: 10, stiffness: 100 });

// 时间动画
offset.value = withTiming(100, { duration: 300, easing: Easing.bezier(0.25, 0.1, 0.25, 1) });

// 延迟、序列、循环
offset.value = withDelay(200, withSpring(100));
offset.value = withSequence(withTiming(50, { duration: 150 }), withTiming(0, { duration: 150 }));
offset.value = withRepeat(withTiming(1, { duration: 500 }), -1, true);
```

## 页面过渡动画

```tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack screenOptions={{ animation: 'slide_from_right', animationDuration: 300 }}>
      <Stack.Screen name="(tabs)" />
      <Stack.Screen name="task/[id]" options={{ animation: 'fade', animationDuration: 200 }} />
    </Stack>
  );
}
```

内置动画：`default`、`fade`、`flip`、`simple_push`、`slide_from_bottom`、`slide_from_left`、`slide_from_right`。

## 列表动画

```tsx
import Animated, { FadeInDown } from 'react-native-reanimated';

function AnimatedTaskList({ tasks }: { tasks: Task[] }) {
  return (
    <FlatList
      data={tasks}
      keyExtractor={(item) => item.id}
      renderItem={({ item, index }) => (
        <Animated.View entering={FadeInDown.delay(index * 80).duration(300)}>
          <TaskCard task={item} />
        </Animated.View>
      )}
    />
  );
}
```

内置入场动画：`FadeIn`、`FadeInDown`、`SlideInDown`、`ZoomIn`、`BounceIn` 等。

## 手势驱动动画

拖拽排序示例：

```tsx
function DraggableItem({ children, onDragEnd }: { children: React.ReactNode; onDragEnd: (y: number) => void }) {
  const translateY = useSharedValue(0);
  const context = useSharedValue(0);

  const pan = Gesture.Pan()
    .onStart(() => { context.value = translateY.value; })
    .onUpdate((e) => { translateY.value = context.value + e.translationY; })
    .onEnd((e) => {
      translateY.value = withSpring(0);
      runOnJS(onDragEnd)(e.translationY);
    });

  const style = useAnimatedStyle(() => ({ transform: [{ translateY: translateY.value }] }));

  return (
    <GestureDetector gesture={pan}>
      <Animated.View style={style}>{children}</Animated.View>
    </GestureDetector>
  );
}
```

`runOnJS` 用于从 UI 线程调用 JS 线程函数。

## 常见误区

1. **在 worklet 中直接 setState**：需要用 `runOnJS` 桥接
2. **混用 Animated 和 Reanimated**：两套 API 不兼容
3. **忽略手势冲突**：父子组件都有手势时需 `Gesture.Simultaneous()` 或 `Gesture.Exclusive()`
4. **大位移用 withSpring**：弹簧动画会震荡很久，应配合 clamp 限制范围
5. **不处理动画清理**：组件卸载时动画未停止导致内存泄漏

## 工程建议

1. 优先用 Reanimated 而非 Animated API，性能更好
2. 用 `Gesture.Exclusive` 处理手势优先级
3. 列表动画用 `entering`/`exiting` 属性，比手动管理简洁
4. 测试手势用真机，模拟器不够准确
5. 动画参数用 `{ mass, damping, stiffness }` 精调不同场景的手感

## 小结

`react-native-gesture-handler` 提供高性能手势识别，`react-native-reanimated` 提供流畅动画引擎。核心模式：`useSharedValue` 创建共享值，`Gesture` 定义手势，`useAnimatedStyle` 映射样式。

## 参考答案

### 练习一

**思路**：用 `Gesture.Pan` 检测水平滑动，限制范围，`withSpring` 回弹。

**答案**：

```tsx
function SwipeableCard({ children }: { children: React.ReactNode }) {
  const translateX = useSharedValue(0);
  const pan = Gesture.Pan()
    .activeOffsetX([-15, 15])
    .onUpdate((e) => { translateX.value = Math.max(-80, Math.min(80, e.translationX)); })
    .onEnd(() => { translateX.value = withSpring(0, { damping: 15, stiffness: 200 }); });

  const cardStyle = useAnimatedStyle(() => ({ transform: [{ translateX: translateX.value }] }));

  return (
    <View style={{ position: 'relative', marginVertical: 4 }}>
      <View style={{ position: 'absolute', left: 0, top: 0, bottom: 0, width: 80, backgroundColor: '#34C759', borderRadius: 8, justifyContent: 'center', alignItems: 'center' }}>
        <Text style={{ color: '#fff' }}>完成</Text>
      </View>
      <View style={{ position: 'absolute', right: 0, top: 0, bottom: 0, width: 80, backgroundColor: '#FF9500', borderRadius: 8, justifyContent: 'center', alignItems: 'center' }}>
        <Text style={{ color: '#fff' }}>收藏</Text>
      </View>
      <GestureDetector gesture={pan}>
        <Animated.View style={[{ backgroundColor: '#fff', padding: 16, borderRadius: 8, zIndex: 1 }, cardStyle]}>
          {children}
        </Animated.View>
      </GestureDetector>
    </View>
  );
}
```

**要点**：`activeOffsetX` 防止与垂直滚动冲突，背景色层用绝对定位放在卡片下方。

### 练习二

**思路**：`FlatList` 的 `renderItem` 用 `FadeInDown` + `delay` 控制入场时间差。

**答案**：

```tsx
import Animated, { FadeInDown } from 'react-native-reanimated';

function AnimatedTaskList({ tasks }: { tasks: { id: string; title: string }[] }) {
  return (
    <FlatList
      data={tasks}
      keyExtractor={(item) => item.id}
      renderItem={({ item, index }) => (
        <Animated.View entering={FadeInDown.delay(index * 100).duration(300).springify()} style={{ padding: 16, marginBottom: 8, backgroundColor: '#fff', borderRadius: 8 }}>
          <Text>{item.title}</Text>
        </Animated.View>
      )}
    />
  );
}
```

**要点**：`delay(index * 100)` 控制间隔，`.springify()` 让动画以弹簧方式收尾。
