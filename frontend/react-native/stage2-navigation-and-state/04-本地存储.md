# 本地存储

## 场景引入

用户创建了 10 个任务，关闭 App 再打开，任务全没了。我们需要把数据持久化到设备上。React Native 生态有多种存储方案：AsyncStorage（简单键值对）、MMKV（高性能键值对）、SQLite（关系型数据库）。选哪个取决于数据量和查询需求。

## 学习目标

- 掌握 AsyncStorage 的使用与局限
- 了解 MMKV 的高性能优势
- 使用 expo-sqlite 实现关系型数据存储
- 理解存储选型取舍与数据迁移策略

## AsyncStorage 基础

```bash
npx expo install @react-native-async-storage/async-storage
```

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage';

// 基础操作
await AsyncStorage.setItem('username', '张三');
const username = await AsyncStorage.getItem('username');
await AsyncStorage.removeItem('username');

// 对象必须序列化
await AsyncStorage.setItem('user', JSON.stringify({ name: '张三', age: 28 }));
const user = JSON.parse(await AsyncStorage.getItem('user') || '{}');

// 批量操作
await AsyncStorage.multiSet([['key1', 'value1'], ['key2', 'value2']]);
const values = await AsyncStorage.multiGet(['key1', 'key2']);
```

类型安全封装：

```tsx
class TypedStorage {
  static async set<T>(key: string, value: T): Promise<void> {
    await AsyncStorage.setItem(key, JSON.stringify(value));
  }
  static async get<T>(key: string): Promise<T | null> {
    const raw = await AsyncStorage.getItem(key);
    return raw ? JSON.parse(raw) : null;
  }
}
```

**局限**：全异步 API、无过期机制、全局命名空间、大数据量性能差、不支持加密。

## MMKV 高性能存储

```bash
npx expo install react-native-mmkv
```

```tsx
import { MMKV } from 'react-native-mmkv';

const storage = new MMKV({ id: 'app-storage', encryptionKey: 'my-key' });

// 同步 API
storage.set('username', '张三');
const username = storage.getString('username');
storage.set('isFirstLaunch', false);
const isFirst = storage.getBoolean('isFirstLaunch');
storage.delete('username');
```

类型安全封装：

```tsx
import { MMKV } from 'react-native-mmkv';
const mmkv = new MMKV({ id: 'app-storage' });

interface StorageSchema {
  tasks: Task[];
  settings: UserSettings;
  lastSyncTime: number;
}

export const storage = {
  get<K extends keyof StorageSchema>(key: K): StorageSchema[K] | undefined {
    const raw = mmkv.getString(key);
    return raw ? JSON.parse(raw) : undefined;
  },
  set<K extends keyof StorageSchema>(key: K, value: StorageSchema[K]): void {
    mmkv.set(key, JSON.stringify(value));
  },
  remove<K extends keyof StorageSchema>(key: K): void {
    mmkv.delete(key);
  },
};

// 完全类型安全
storage.set('tasks', [{ id: '1', title: '买菜' }]);
const tasks = storage.get('tasks'); // Task[] | undefined
```

**MMKV vs AsyncStorage：**

| 特性 | AsyncStorage | MMKV |
|------|-------------|------|
| 速度 | 慢（异步） | 快 30 倍（同步） |
| API | 全异步 | 同步 |
| 加密 | 不支持 | 原生支持 |
| 适用 | 简单配置 | 高频读写、敏感数据 |

## SQLite 关系型数据库

数据量大、需要复杂查询时用 SQLite。

```bash
npx expo install expo-sqlite
```

```tsx
import * as SQLite from 'expo-sqlite';

const db = SQLite.openDatabaseSync('tasks.db');

db.execSync(`
  CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    description TEXT,
    priority TEXT DEFAULT 'medium',
    status TEXT DEFAULT 'pending',
    due_date TEXT,
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
  );
`);
```

封装任务数据库：

```tsx
interface Task {
  id: number;
  title: string;
  description: string | null;
  priority: 'low' | 'medium' | 'high';
  status: 'pending' | 'done';
  due_date: string | null;
  created_at: string;
}

class TaskDatabase {
  private db: SQLite.SQLiteDatabase;

  constructor() {
    this.db = SQLite.openDatabaseSync('tasks.db');
    this.init();
  }

  private init() {
    this.db.execSync(`
      CREATE TABLE IF NOT EXISTS tasks (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL, description TEXT,
        priority TEXT DEFAULT 'medium', status TEXT DEFAULT 'pending',
        due_date TEXT, created_at TEXT DEFAULT (datetime('now')),
        updated_at TEXT DEFAULT (datetime('now'))
      );
    `);
  }

  getAll(status?: string): Task[] {
    if (status) return this.db.getAllSync('SELECT * FROM tasks WHERE status = ? ORDER BY created_at DESC', [status]);
    return this.db.getAllSync('SELECT * FROM tasks ORDER BY created_at DESC');
  }

  getById(id: number): Task | null {
    return this.db.getFirstSync('SELECT * FROM tasks WHERE id = ?', [id]);
  }

  create(data: { title: string; description?: string; priority?: string; due_date?: string }): number {
    const result = this.db.runSync(
      'INSERT INTO tasks (title, description, priority, due_date) VALUES (?, ?, ?, ?)',
      [data.title, data.description || null, data.priority || 'medium', data.due_date || null]
    );
    return result.lastInsertRowId;
  }

  update(id: number, data: Partial<Task>): void {
    const fields: string[] = [];
    const values: (string | number | null)[] = [];
    for (const [key, val] of Object.entries(data)) {
      if (key !== 'id') { fields.push(`${key} = ?`); values.push(val as string); }
    }
    fields.push("updated_at = datetime('now')");
    values.push(id);
    this.db.runSync(`UPDATE tasks SET ${fields.join(', ')} WHERE id = ?`, values);
  }

  delete(id: number): void {
    this.db.runSync('DELETE FROM tasks WHERE id = ?', [id]);
  }

  getStats(): { total: number; pending: number; done: number } {
    return this.db.getFirstSync(`
      SELECT COUNT(*) as total,
        SUM(CASE WHEN status='pending' THEN 1 ELSE 0 END) as pending,
        SUM(CASE WHEN status='done' THEN 1 ELSE 0 END) as done
      FROM tasks
    `)!;
  }
}

export const taskDB = new TaskDatabase();
```

Hook 封装：

```tsx
function useTasks(status?: string) {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [loading, setLoading] = useState(true);
  const refresh = useCallback(() => {
    setLoading(true);
    try { setTasks(taskDB.getAll(status)); } finally { setLoading(false); }
  }, [status]);
  useEffect(() => { refresh(); }, [refresh]);
  return { tasks, loading, refresh };
}
```

## 存储选型对比

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 用户偏好设置 | MMKV | 同步读取、简单键值对 |
| 登录 Token | MMKV + 加密 | 需要加密、高频读取 |
| 任务列表 | SQLite | 需要查询、排序、过滤 |
| 缓存数据 | AsyncStorage | 低频、不重要 |

## 数据迁移策略

```tsx
class TaskDatabase {
  private db: SQLite.SQLiteDatabase;
  private readonly CURRENT_VERSION = 2;

  private migrate() {
    const version = this.getDBVersion();
    if (version < 1) {
      this.db.execSync(`CREATE TABLE IF NOT EXISTS tasks (id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT NOT NULL, status TEXT DEFAULT 'pending', created_at TEXT DEFAULT (datetime('now')));`);
    }
    if (version < 2) {
      this.db.execSync(`ALTER TABLE tasks ADD COLUMN description TEXT;`);
      this.db.execSync(`ALTER TABLE tasks ADD COLUMN priority TEXT DEFAULT 'medium';`);
      this.db.execSync(`ALTER TABLE tasks ADD COLUMN due_date TEXT;`);
    }
    this.setDBVersion(this.CURRENT_VERSION);
  }

  private getDBVersion(): number {
    this.db.execSync(`CREATE TABLE IF NOT EXISTS db_meta (key TEXT PRIMARY KEY, value TEXT);`);
    const row = this.db.getFirstSync<{ value: string }>("SELECT value FROM db_meta WHERE key='version'");
    return row ? parseInt(row.value, 10) : 0;
  }

  private setDBVersion(v: number) {
    this.db.runSync("INSERT OR REPLACE INTO db_meta (key, value) VALUES ('version', ?)", [v.toString()]);
  }
}
```

迁移原则：幂等执行、新增字段有默认值、生产前验证。

## 常见误区

1. **AsyncStorage 当数据库用**：几百条数据全量读取，性能灾难
2. **MMKV 存大量数据**：适合少量高频，大量用 SQLite
3. **SQLite 不用事务**：批量插入逐条执行比事务慢 100 倍
4. **不做数据迁移**：版本更新后结构变化导致崩溃
5. **敏感数据明文存储**：Token、密码必须加密

## 工程建议

1. MMKV 做键值存储，SQLite 做数据库，两者互补
2. SQLite 查询用参数化（`?`），不拼接 SQL
3. 数据库初始化放 App 启动时
4. 大批量操作用 `withTransactionSync` 保证原子性
5. 测试时用独立数据库文件

## 小结

AsyncStorage 适合简单场景，MMKV 提供高性能键值存储，SQLite 提供完整关系型能力。选型依据：数据量、查询复杂度、读写频率。

## 参考答案

### 练习一

**思路**：MMKV 存储 + 类型接口封装。

**答案**：

```tsx
import { MMKV } from 'react-native-mmkv';

interface Settings { theme: 'light' | 'dark'; language: 'zh' | 'en'; notificationsEnabled: boolean; }
const mmkv = new MMKV({ id: 'settings' });
const DEFAULTS: Settings = { theme: 'light', language: 'zh', notificationsEnabled: true };

export const settingsStorage = {
  get(): Settings {
    const raw = mmkv.getString('settings');
    if (!raw) return DEFAULTS;
    try { return { ...DEFAULTS, ...JSON.parse(raw) }; } catch { return DEFAULTS; }
  },
  set(partial: Partial<Settings>): void {
    mmkv.set('settings', JSON.stringify({ ...this.get(), ...partial }));
  },
  reset(): void { mmkv.delete('settings'); },
};

settingsStorage.set({ theme: 'dark' });
const { theme } = settingsStorage.get();
```

**要点**：提供默认值防 `undefined`，`set` 用部分更新，`get` 加 try-catch。

### 练习二

**思路**：`LIKE` 模糊搜索 + `trim()` 去空格。

**答案**：

```tsx
class TaskDatabase {
  search(keyword: string): Task[] {
    const pattern = `%${keyword.trim()}%`;
    return this.db.getAllSync(
      'SELECT * FROM tasks WHERE title LIKE ? OR description LIKE ? ORDER BY created_at DESC',
      [pattern, pattern]
    );
  }
}

function useTaskSearch() {
  const [keyword, setKeyword] = useState('');
  const [results, setResults] = useState<Task[]>([]);
  const search = (text: string) => {
    setKeyword(text);
    setResults(text.trim() ? taskDB.search(text) : []);
  };
  return { keyword, results, search };
}
```

**要点**：空关键词时清空结果，`LIKE` 用 `%keyword%` 匹配包含关键词的记录。
