# 推送通知

## 场景引入

用户设定了任务截止日期，到了当天手机弹出通知："任务《提交周报》将在 2 小时后到期"。点击通知，App 直接打开任务详情页。推送通知涉及平台差异（iOS APNs / Android FCM）、权限管理、后台处理。Expo 通过 `expo-notifications` 封装了大部分复杂性。

## 学习目标

- 掌握 Expo Notifications 本地通知
- 理解远程推送 FCM/APNs 配置
- 实现通知权限请求与响应处理
- 处理后台通知和通知分组

## 本地通知

```bash
npx expo install expo-notifications expo-device
```

配置前台通知行为：

```tsx
import * as Notifications from 'expo-notifications';

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: true,
    shouldSetBadge: true,
  }),
});
```

请求权限：

```tsx
import * as Device from 'expo-device';
import { Platform } from 'react-native';
import Constants from 'expo-constants';

async function registerForPushNotifications(): Promise<string | undefined> {
  if (!Device.isDevice) { alert('模拟器不支持推送'); return; }

  const { status: existing } = await Notifications.getPermissionsAsync();
  let finalStatus = existing;
  if (existing !== 'granted') {
    const { status } = await Notifications.requestPermissionsAsync();
    finalStatus = status;
  }
  if (finalStatus !== 'granted') { alert('请在设置中开启通知权限'); return; }

  if (Platform.OS === 'android') {
    await Notifications.setNotificationChannelAsync('default', {
      name: '默认通知',
      importance: Notifications.AndroidImportance.HIGH,
      vibrationPattern: [0, 250, 250, 250],
    });
  }

  const token = await Notifications.getExpoPushTokenAsync({
    projectId: Constants.expoConfig?.extra?.eas?.projectId,
  });
  return token.data;
}
```

发送本地通知：

```tsx
async function sendLocalNotification(title: string, body: string) {
  await Notifications.scheduleNotificationAsync({
    content: { title, body, sound: 'default', data: { taskId: '42' } },
    trigger: null, // 立即发送
  });
}
```

定时通知：

```tsx
async function scheduleTaskReminder(taskId: string, taskTitle: string, dueDate: Date) {
  const reminderTime = new Date(dueDate.getTime() - 2 * 60 * 60 * 1000);
  if (reminderTime <= new Date()) return null;

  const notificationId = await Notifications.scheduleNotificationAsync({
    content: {
      title: '任务提醒',
      body: `《${taskTitle}》将在 2 小时后到期`,
      sound: 'default',
      data: { taskId, type: 'reminder' },
    },
    trigger: { type: Notifications.SchedulableTriggerInputTypes.DATE, date: reminderTime },
  });

  return notificationId;
}

// 取消通知
await Notifications.cancelScheduledNotificationAsync(notificationId);
await Notifications.cancelAllScheduledNotificationsAsync();
```

## 远程推送

流程：设备获取 Token → 发送到服务器 → 服务器调用 Expo Push API → Expo 转发到 APNs/FCM。

服务器端发送（Node.js）：

```typescript
import fetch from 'node-fetch';

async function sendPushNotification(expoPushToken: string, title: string, body: string, data?: Record<string, unknown>) {
  const response = await fetch('https://exp.host/--/api/v2/push/send', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ to: expoPushToken, sound: 'default', title, body, data, channelId: 'default' }),
  });
  return response.json();
}

// 批量发送
async function sendBatch(tokens: string[], title: string, body: string) {
  const messages = tokens.map((to) => ({ to, sound: 'default', title, body }));
  return fetch('https://exp.host/--/api/v2/push/send', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(messages),
  }).then((r) => r.json());
}
```

自建服务器配置（app.json）：

```json
{
  "expo": {
    "plugins": [["expo-notifications", {
      "icon": "./assets/notification-icon.png",
      "color": "#007AFF"
    }]]
  }
}
```

## 通知响应处理

```tsx
import { useEffect } from 'react';
import * as Notifications from 'expo-notifications';
import { router } from 'expo-router';

function useNotificationResponse() {
  useEffect(() => {
    // 热启动：App 在后台时点击通知
    const sub = Notifications.addNotificationResponseReceivedListener((response) => {
      const { taskId } = response.notification.request.content.data;
      if (taskId) router.push({ pathname: '/task/[id]', params: { id: String(taskId) } });
    });

    // 冷启动：App 从关闭状态被通知打开
    Notifications.getLastNotificationResponseAsync().then((response) => {
      if (response) {
        const { taskId } = response.notification.request.content.data;
        if (taskId) setTimeout(() => router.push({ pathname: '/task/[id]', params: { id: String(taskId) } }), 500);
      }
    });

    return () => sub.remove();
  }, []);
}
```

前台通知监听：

```tsx
useEffect(() => {
  const received = Notifications.addNotificationReceivedListener((n) => {
    console.log('前台收到:', n.request.content);
  });
  const response = Notifications.addNotificationResponseReceivedListener((r) => {
    console.log('用户点击:', r.actionIdentifier);
  });
  return () => { received.remove(); response.remove(); };
}, []);
```

## 后台通知

```tsx
import * as BackgroundFetch from 'expo-background-fetch';
import * as TaskManager from 'expo-task-manager';

const BG_TASK = 'BACKGROUND_NOTIFICATION_TASK';

TaskManager.defineTask(BG_TASK, async ({ data, error }) => {
  if (error) return;
  const notification = data as Notifications.Notification;
  const { taskId } = notification.request.content.data;
  console.log('后台处理:', taskId);
});

Notifications.registerTaskAsync(BG_TASK);
```

> 后台任务有时间限制（iOS 约 30 秒），不能执行长时间操作。

## 通知分组

```tsx
async function sendGroupedNotification(taskTitle: string, group = 'tasks') {
  await Notifications.scheduleNotificationAsync({
    content: {
      title: '任务更新',
      body: `《${taskTitle}》状态已变更`,
      ...(Platform.OS === 'android' && { groupId: group, tag: group }),
    },
    trigger: null,
  });
}

// Android 分组摘要
async function sendGroupSummary(group: string, count: number) {
  if (Platform.OS !== 'android') return;
  await Notifications.scheduleNotificationAsync({
    content: {
      title: '任务管理',
      body: `你有 ${count} 条任务更新`,
      groupId: group,
      tag: `${group}_summary`,
    },
    trigger: null,
  });
}
```

Badge 管理：

```tsx
await Notifications.setBadgeCountAsync(count);
await Notifications.setBadgeCountAsync(0); // 清除
```

## 常见误区

1. **模拟器测试推送**：必须用真机
2. **忽略 Android Channel**：8.0+ 必须创建 Notification Channel
3. **Token 不更新**：可能变化，需定期重新获取
4. **不处理权限拒绝**：引导用户去系统设置
5. **前台通知不显示**：需通过 `setNotificationHandler` 配置

## 工程建议

1. 本地通知用于定时提醒，远程推送用于服务器消息
2. Push Token 存到服务器，每次启动检查变化
3. 用 `data` 字段传业务数据，不要放 `body`
4. Android 和 iOS 分别测试通知样式
5. 用 Expo 推送工具测试：`npx expo push:android --message "测试"`

## 小结

Expo Notifications 统一了 iOS/Android 通知 API。核心流程：请求权限 → 获取 Token → 发送通知 → 处理响应。本地通知用于定时提醒，远程推送用于服务器消息。

## 参考答案

### 练习一

**思路**：`scheduleNotificationAsync` 安排定时通知，计算截止前 30 分钟。

**答案**：

```tsx
import * as Notifications from 'expo-notifications';

async function scheduleTaskDueReminder(taskId: string, taskTitle: string, dueDate: Date): Promise<string | null> {
  const reminderTime = new Date(dueDate.getTime() - 30 * 60 * 1000);
  if (reminderTime <= new Date()) return null;

  const notificationId = await Notifications.scheduleNotificationAsync({
    content: {
      title: '任务即将到期',
      body: `《${taskTitle}》将在 30 分钟后到期`,
      sound: 'default',
      data: { taskId, type: 'due_reminder' },
    },
    trigger: { type: Notifications.SchedulableTriggerInputTypes.DATE, date: reminderTime },
  });

  return notificationId;
}

// 使用
const notifId = await scheduleTaskDueReminder('42', '提交周报', new Date('2025-01-15T17:00:00'));
if (notifId) taskDB.update(42, { reminder_id: notifId });

// 取消
if (notifId) await Notifications.cancelScheduledNotificationAsync(notifId);
```

**要点**：检查是否已过期，保存 `notificationId` 以便取消。

### 练习二

**思路**：`addNotificationResponseReceivedListener` 监听点击，`getLastNotificationResponseAsync` 处理冷启动。

**答案**：

```tsx
function useNotificationNavigation() {
  useEffect(() => {
    const sub = Notifications.addNotificationResponseReceivedListener((response) => {
      const { taskId } = response.notification.request.content.data;
      if (taskId) router.push({ pathname: '/task/[id]', params: { id: String(taskId) } });
    });

    Notifications.getLastNotificationResponseAsync().then((response) => {
      if (response) {
        const { taskId } = response.notification.request.content.data;
        if (taskId) setTimeout(() => router.push({ pathname: '/task/[id]', params: { id: String(taskId) } }), 1000);
      }
    });

    return () => sub.remove();
  }, []);
}
```

**要点**：冷启动需延迟跳转等待导航初始化，`taskId` 必须转字符串。
