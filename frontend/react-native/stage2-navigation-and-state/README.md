# Stage 2：导航与状态

> 深入移动端导航模式、手势动画、表单交互、本地存储与推送通知。

## 学习目标

完成本阶段后，你将能够：

1. 配置嵌套导航与 Deep Link
2. 使用 Reanimated 实现流畅手势动画
3. 处理移动端表单与键盘交互
4. 选择合适的本地存储方案
5. 集成推送通知系统
6. 完成一个带推送的任务管理 App

## 课时列表

| # | 课时 | 核心内容 |
|---|------|----------|
| 01 | 深度导航配置 | 嵌套导航、动态路由、Deep Link |
| 02 | 手势与动画 | React Native Reanimated、手势处理 |
| 03 | 表单与输入 | 键盘管理、表单验证、日期选择 |
| 04 | 本地存储 | AsyncStorage/MMKV/SQLite |
| 05 | 推送通知 | Expo Notifications、FCM 集成 |
| 06 | 阶段实战：任务管理 App | 带推送的任务管理 App |

## 阶段项目

任务管理 App——支持任务 CRUD、分组筛选排序、本地推送提醒、手势交互。
