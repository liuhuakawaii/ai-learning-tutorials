# 表单与输入

## 场景引入

用户创建新任务：输入标题、填写描述、选择截止日期、设置优先级。移动端表单的核心挑战：键盘弹起遮挡内容，日期选择用原生底部弹出组件，提交前要验证所有字段。

## 学习目标

- 掌握 TextInput 属性与样式定制
- 理解键盘管理策略
- 集成 react-hook-form + Zod 表单验证
- 使用 DateTimePicker 和底部弹出表单

## TextInput 基础

```tsx
import { TextInput, View, Text, StyleSheet, useState } from 'react-native';

function TaskTitleInput() {
  const [title, setTitle] = useState('');
  return (
    <View style={styles.field}>
      <Text style={styles.label}>任务标题</Text>
      <TextInput
        style={styles.input}
        value={title}
        onChangeText={setTitle}
        placeholder="输入任务标题"
        placeholderTextColor="#C7C7CC"
        maxLength={100}
        returnKeyType="next"
        autoCapitalize="sentences"
      />
      <Text style={styles.charCount}>{title.length}/100</Text>
    </View>
  );
}
```

常用属性：`keyboardType`（键盘类型）、`secureTextEntry`（密码）、`multiline`（多行）、`returnKeyType`（回车键文字）、`autoComplete`（自动填充）。

## 键盘管理

`KeyboardAvoidingView` 解决键盘遮挡问题：

```tsx
import { KeyboardAvoidingView, Platform, ScrollView } from 'react-native';

function TaskForm() {
  return (
    <KeyboardAvoidingView
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
      style={{ flex: 1 }}
      keyboardVerticalOffset={88}
    >
      <ScrollView
        contentContainerStyle={{ padding: 16 }}
        keyboardShouldPersistTaps="handled"
      >
        <TextInput style={styles.input} placeholder="任务标题" />
        <TextInput style={[styles.input, { height: 100, textAlignVertical: 'top' }]} placeholder="任务描述" multiline />
      </ScrollView>
    </KeyboardAvoidingView>
  );
}
```

关键参数：iOS 用 `padding`，Android 用 `height`，`keyboardVerticalOffset` 补偿导航栏高度。

## react-hook-form 集成

```bash
npx expo install react-hook-form @hookform/resolvers zod
```

Zod schema 定义验证规则：

```tsx
import { z } from 'zod';

const taskSchema = z.object({
  title: z.string().min(1, '标题不能为空').max(100, '标题最多 100 字'),
  description: z.string().max(500, '描述最多 500 字').optional(),
  priority: z.enum(['low', 'medium', 'high']),
  dueDate: z.date().optional(),
});

type TaskFormData = z.infer<typeof taskSchema>;
```

集成表单：

```tsx
import { useForm, Controller } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

function CreateTaskForm() {
  const { control, handleSubmit, formState: { errors, isSubmitting } } = useForm<TaskFormData>({
    resolver: zodResolver(taskSchema),
    defaultValues: { title: '', description: '', priority: 'medium' },
  });

  const onSubmit = (data: TaskFormData) => Alert.alert('创建成功', JSON.stringify(data));

  return (
    <View style={{ padding: 16 }}>
      <Controller
        control={control}
        name="title"
        render={({ field: { onChange, onBlur, value } }) => (
          <View style={styles.field}>
            <Text style={styles.label}>任务标题 *</Text>
            <TextInput
              style={[styles.input, errors.title && { borderColor: '#FF3B30' }]}
              value={value}
              onChangeText={onChange}
              onBlur={onBlur}
              placeholder="输入任务标题"
            />
            {errors.title && <Text style={styles.error}>{errors.title.message}</Text>}
          </View>
        )}
      />

      <Controller
        control={control}
        name="priority"
        render={({ field: { onChange, value } }) => (
          <View style={styles.field}>
            <Text style={styles.label}>优先级</Text>
            <View style={{ flexDirection: 'row', gap: 8 }}>
              {(['low', 'medium', 'high'] as const).map((p) => (
                <TouchableOpacity
                  key={p}
                  style={[styles.chip, value === p && styles.chipActive]}
                  onPress={() => onChange(p)}
                >
                  <Text style={[styles.chipText, value === p && { color: '#fff' }]}>
                    {p === 'low' ? '低' : p === 'medium' ? '中' : '高'}
                  </Text>
                </TouchableOpacity>
              ))}
            </View>
          </View>
        )}
      />

      <TouchableOpacity style={styles.button} onPress={handleSubmit(onSubmit)}>
        <Text style={{ color: '#fff', fontSize: 16, fontWeight: '600' }}>
          {isSubmitting ? '创建中...' : '创建任务'}
        </Text>
      </TouchableOpacity>
    </View>
  );
}
```

## 表单验证策略

```tsx
const { control, handleSubmit, formState: { errors } } = useForm<TaskFormData>({
  resolver: zodResolver(taskSchema),
  mode: 'onBlur',           // 失焦时验证（推荐）
  reValidateMode: 'onChange', // 出错后输入时实时验证
});
```

`mode` 选项：`onSubmit`（默认）、`onBlur`（推荐）、`onChange`（频繁重渲染）、`onTouched`、`all`。

## DateTimePicker

```bash
npx expo install @react-native-community/datetimepicker
```

```tsx
import DateTimePicker, { DateTimePickerEvent } from '@react-native-community/datetimepicker';
import { Platform, TouchableOpacity } from 'react-native';

function DateField({ value, onChange }: { value: Date | undefined; onChange: (d: Date) => void }) {
  const [show, setShow] = useState(false);

  const handleChange = (_: DateTimePickerEvent, date?: Date) => {
    setShow(Platform.OS === 'ios');
    if (date) onChange(date);
  };

  return (
    <View>
      <TouchableOpacity style={styles.dateBtn} onPress={() => setShow(true)}>
        <Text>{value ? value.toLocaleDateString('zh-CN') : '选择截止日期'}</Text>
      </TouchableOpacity>
      {show && (
        <DateTimePicker
          value={value || new Date()}
          mode="date"
          display={Platform.OS === 'ios' ? 'spinner' : 'default'}
          minimumDate={new Date()}
          onChange={handleChange}
        />
      )}
    </View>
  );
}
```

```tsx
import BottomSheet, { BottomSheetScrollView } from '@gorhom/bottom-sheet';
import { useRef } from 'react';

function CreateTaskSheet({ visible, onClose }: { visible: boolean; onClose: () => void }) {
  const ref = useRef<BottomSheet>(null);
  if (!visible) return null;

  return (
    <BottomSheet
      ref={ref}
      index={0}
      snapPoints={['50%', '90%']}
      onChange={(i) => { if (i === -1) onClose(); }}
      enablePanDownToClose
    >
      <BottomSheetScrollView contentContainerStyle={{ padding: 16 }}>
        <Text style={{ fontSize: 18, fontWeight: '700', marginBottom: 16 }}>新建任务</Text>
        <TextInput style={styles.input} placeholder="任务标题" />
        <TouchableOpacity style={styles.button}>
          <Text style={{ color: '#fff' }}>创建</Text>
        </TouchableOpacity>
      </BottomSheetScrollView>
    </BottomSheet>
  );
}
```

> `@gorhom/bottom-sheet` 要求 `GestureHandlerRootView` 包裹在 App 根部。

## 常见误区

1. **不做键盘管理**：输入框被键盘遮挡
2. **用受控组件管理所有状态**：每个字符触发重渲染，表单大了会卡
3. **验证时机选 `onChange`**：用户没输完就报错
4. **DateTimePicker 不处理平台差异**：iOS 和 Android 行为不同
5. **底部弹出表单不用 `enablePanDownToClose`**：违背移动端交互习惯

## 工程建议

1. 表单验证用 Zod schema，前后端可共享
2. `KeyboardAvoidingView` iOS 用 `padding`，Android 用 `height`
3. 输入框用 `selectionColor` 和 `cursorColor` 定制光标颜色
4. 日期选择器 iOS 用 `display="spinner"`，Android 用默认对话框
5. 表单提交按钮加 `disabled` 状态防止重复提交

## 小结

移动端表单核心是键盘管理、验证时机和平台差异。`react-hook-form` + Zod 是最佳组合，`KeyboardAvoidingView` 解决键盘遮挡，`DateTimePicker` 提供原生日期选择。

## 参考答案

### 练习一

**思路**：Zod schema 用 `refine` 做跨字段验证。

**答案**：

```tsx
const registerSchema = z.object({
  email: z.string().min(1, '邮箱不能为空').email('邮箱格式不正确'),
  password: z.string().min(8, '密码至少 8 位'),
  confirmPassword: z.string().min(1, '请确认密码'),
}).refine((d) => d.password === d.confirmPassword, {
  message: '两次密码不一致',
  path: ['confirmPassword'],
});

function RegisterForm() {
  const { control, handleSubmit, formState: { errors } } = useForm<z.infer<typeof registerSchema>>({
    resolver: zodResolver(registerSchema),
    mode: 'onBlur',
    reValidateMode: 'onChange',
  });

  const onSubmit = (data: z.infer<typeof registerSchema>) => console.log('注册:', data.email);

  return (
    <View style={{ padding: 16 }}>
      <Controller
        control={control}
        name="email"
        render={({ field: { onChange, onBlur, value } }) => (
          <View style={{ marginBottom: 16 }}>
            <Text style={{ marginBottom: 6, fontWeight: '600' }}>邮箱</Text>
            <TextInput style={styles.input} value={value} onChangeText={onChange} onBlur={onBlur} keyboardType="email-address" autoCapitalize="none" />
            {errors.email && <Text style={styles.error}>{errors.email.message}</Text>}
          </View>
        )}
      />
      <Controller
        control={control}
        name="password"
        render={({ field: { onChange, onBlur, value } }) => (
          <View style={{ marginBottom: 16 }}>
            <Text style={{ marginBottom: 6, fontWeight: '600' }}>密码</Text>
            <TextInput style={styles.input} value={value} onChangeText={onChange} onBlur={onBlur} secureTextEntry />
            {errors.password && <Text style={styles.error}>{errors.password.message}</Text>}
          </View>
        )}
      />
      <Controller
        control={control}
        name="confirmPassword"
        render={({ field: { onChange, onBlur, value } }) => (
          <View style={{ marginBottom: 16 }}>
            <Text style={{ marginBottom: 6, fontWeight: '600' }}>确认密码</Text>
            <TextInput style={styles.input} value={value} onChangeText={onChange} onBlur={onBlur} secureTextEntry />
            {errors.confirmPassword && <Text style={styles.error}>{errors.confirmPassword.message}</Text>}
          </View>
        )}
      />
      <TouchableOpacity style={styles.button} onPress={handleSubmit(onSubmit)}>
        <Text style={{ color: '#fff', fontWeight: '600' }}>注册</Text>
      </TouchableOpacity>
    </View>
  );
}
```

**要点**：`z.refine` 的 `path` 指定错误显示在哪个字段。

### 练习二

**思路**：两个 DateTimePicker，结束日期的 `minimumDate` 绑定开始日期。

**答案**：

```tsx
function DateRangePicker() {
  const [start, setStart] = useState(new Date());
  const [end, setEnd] = useState(new Date());
  const [showStart, setShowStart] = useState(false);
  const [showEnd, setShowEnd] = useState(false);

  return (
    <View style={{ padding: 16 }}>
      <View style={{ flexDirection: 'row', justifyContent: 'space-between', marginBottom: 16 }}>
        <Text style={{ fontWeight: '600' }}>开始日期</Text>
        <TouchableOpacity onPress={() => setShowStart(true)}>
          <Text>{start.toLocaleDateString('zh-CN')}</Text>
        </TouchableOpacity>
      </View>
      <View style={{ flexDirection: 'row', justifyContent: 'space-between', marginBottom: 16 }}>
        <Text style={{ fontWeight: '600' }}>结束日期</Text>
        <TouchableOpacity onPress={() => setShowEnd(true)}>
          <Text>{end.toLocaleDateString('zh-CN')}</Text>
        </TouchableOpacity>
      </View>
      {showStart && (
        <DateTimePicker
          value={start}
          mode="date"
          display={Platform.OS === 'ios' ? 'spinner' : 'default'}
          onChange={(_, d) => { setShowStart(Platform.OS === 'ios'); if (d) { setStart(d); if (d > end) setEnd(d); } }}
        />
      )}
      {showEnd && (
        <DateTimePicker
          value={end}
          mode="date"
          display={Platform.OS === 'ios' ? 'spinner' : 'default'}
          minimumDate={start}
          onChange={(_, d) => { setShowEnd(Platform.OS === 'ios'); if (d) setEnd(d); }}
        />
      )}
    </View>
  );
}
```

**要点**：`minimumDate={start}` 确保结束不早于开始，修改开始时自动修正结束。
