# 深度导航配置

## 场景引入

用户点击"任务详情"要进入新页面，点击底部 Tab 要切换模块，收到推送通知要直接跳转到对应页面——这些都需要导航系统。Expo 推荐 `expo-router`，基于文件系统路由，用写 Next.js 的方式写 React Native 导航。

## 学习目标

- 掌握嵌套导航结构（Stack 内嵌 Tab）
- 理解动态路由参数传递与获取
- 实现路由守卫与 Deep Link
- 了解导航状态持久化与屏幕生命周期

## 嵌套导航：Stack 内嵌 Tab

`expo-router` 用目录结构定义路由：

```
app/
├── _layout.tsx          # 根布局（Stack）
├── (tabs)/              # Tab 组
│   ├── _layout.tsx      # Tab 布局
│   ├── index.tsx        # 首页
│   ├── tasks.tsx        # 任务
│   └── settings.tsx     # 设置
├── task/
│   └── [id].tsx         # 任务详情
└── login.tsx            # 登录页
```

根布局 `app/_layout.tsx`：

```tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack screenOptions={{ headerShown: false }}>
      <Stack.Screen name="(tabs)" />
      <Stack.Screen
        name="task/[id]"
        options={{ presentation: 'modal', headerShown: true, title: '任务详情' }}
      />
      <Stack.Screen name="login" options={{ presentation: 'fullScreenModal' }} />
    </Stack>
  );
}
```

Tab 布局 `app/(tabs)/_layout.tsx`：

```tsx
import { Tabs } from 'expo-router';
import { Ionicons } from '@expo/vector-icons';

export default function TabLayout() {
  return (
    <Tabs screenOptions={{ tabBarActiveTintColor: '#007AFF' }}>
      <Tabs.Screen
        name="index"
        options={{
          title: '首页',
          tabBarIcon: ({ color, size }) => <Ionicons name="home-outline" size={size} color={color} />,
        }}
      />
      <Tabs.Screen
        name="tasks"
        options={{
          title: '任务',
          tabBarIcon: ({ color, size }) => <Ionicons name="checkbox-outline" size={size} color={color} />,
        }}
      />
      <Tabs.Screen
        name="settings"
        options={{
          title: '设置',
          tabBarIcon: ({ color, size }) => <Ionicons name="settings-outline" size={size} color={color} />,
        }}
      />
    </Tabs>
  );
}
```

## 动态路由与参数传递

`[param]` 语法定义动态路由。`app/task/[id].tsx` 匹配 `/task/123`。

```tsx
import { Link, router } from 'expo-router';

// Link 组件传递
<Link href={{ pathname: '/task/[id]', params: { id: '42' } }}>查看任务</Link>

// 命令式导航
router.push({ pathname: '/task/[id]', params: { id: '42', source: 'list' } });
```

接收参数：

```tsx
import { useLocalSearchParams } from 'expo-router';

export default function TaskDetail() {
  const { id, source } = useLocalSearchParams<{ id: string; source?: string }>();
  return (
    <View style={{ padding: 16 }}>
      <Text>任务 ID：{id}</Text>
    </View>
  );
}
```

## 路由守卫：登录态拦截

在 Layout 层判断登录状态：

```tsx
import { useEffect } from 'react';
import { router, Stack, Redirect } from 'expo-router';
import { useAuth } from '../hooks/useAuth';

export default function RootLayout() {
  const { isAuthenticated, isLoading } = useAuth();

  useEffect(() => {
    if (!isLoading && !isAuthenticated) router.replace('/login');
  }, [isAuthenticated, isLoading]);

  if (isLoading) return null;

  return (
    <Stack>
      <Stack.Screen name="(tabs)" />
      <Stack.Screen name="task/[id]" />
      <Stack.Screen name="login" />
    </Stack>
  );
}

// 更优雅的封装
function ProtectedLayout({ children }: { children: React.ReactNode }) {
  const { isAuthenticated } = useAuth();
  if (!isAuthenticated) return <Redirect href="/login" />;
  return <>{children}</>;
}
```

## Deep Link 配置

`app.json` 配置 URL Scheme：

```json
{
  "expo": {
    "scheme": "mytaskapp",
    "android": {
      "intentFilters": [{
        "action": "VIEW",
        "autoVerify": true,
        "data": [{ "scheme": "https", "host": "mytaskapp.com", "pathPrefix": "/task" }],
        "category": ["BROWSABLE", "DEFAULT"]
      }]
    }
  }
}
```

处理 Deep Link 事件：

```tsx
import { useEffect } from 'react';
import * as Linking from 'expo-linking';
import { router } from 'expo-router';

function useDeepLinkHandler() {
  useEffect(() => {
    const subscription = Linking.addEventListener('url', ({ url }) => {
      const { path } = Linking.parse(url);
      if (path?.startsWith('task/')) {
        const id = path.split('/')[1];
        router.push({ pathname: '/task/[id]', params: { id } });
      }
    });

    Linking.getInitialURL().then((url) => {
      if (url) {
        const { path } = Linking.parse(url);
        if (path?.startsWith('task/')) {
          router.push({ pathname: '/task/[id]', params: { id: path.split('/')[1] } });
        }
      }
    });

    return () => subscription.remove();
  }, []);
}
```

## 导航状态持久化

```tsx
import { useNavigationContainerRef } from 'expo-router';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { useEffect } from 'react';

const NAV_KEY = 'NAVIGATION_STATE';

export default function RootLayout() {
  const navRef = useNavigationContainerRef();

  useEffect(() => {
    AsyncStorage.getItem(NAV_KEY).then((state) => {
      if (state) navRef.resetRoot(JSON.parse(state));
    });
    const unsubscribe = navRef.addListener('state', () => {
      AsyncStorage.setItem(NAV_KEY, JSON.stringify(navRef.getRootState()));
    });
    return unsubscribe;
  }, [navRef]);

  return <Stack><Stack.Screen name="(tabs)" /></Stack>;
}
```

> 建议加版本号校验，避免路由结构变更后恢复旧状态导致崩溃。

## 屏幕生命周期

```tsx
import { useFocusEffect, useNavigation } from 'expo-router';
import { useCallback } from 'react';

export default function TaskList() {
  const navigation = useNavigation();

  useFocusEffect(
    useCallback(() => {
      console.log('获得焦点，刷新数据');
      refreshTasks();
      return () => console.log('失去焦点');
    }, [])
  );

  useEffect(() => {
    const unsubscribe = navigation.addListener('beforeRemove', (e) => {
      if (!hasUnsavedChanges) return;
      e.preventDefault();
      Alert.alert('确认离开？', '你有未保存的更改', [
        { text: '取消', style: 'cancel' },
        { text: '离开', onPress: () => navigation.dispatch(e.data.action) },
      ]);
    });
    return unsubscribe;
  }, [navigation, hasUnsavedChanges]);

  return <View>{/* ... */}</View>;
}
```

## 常见误区

1. **把所有页面都放 Stack 里**：Tab 页面应放 `(tabs)` 分组
2. **过度使用 `navigation.reset`**：只在登出等场景使用
3. **忽略 Android 返回按钮**：`expo-router` 默认处理，自定义拦截需 `beforeRemove`
4. **Deep Link 参数不校验**：外部参数不可信，必须做类型检查
5. **Layout 中重路由死循环**：`useEffect` 依赖项设置不当会反复触发

## 工程建议

1. 用文件系统组织路由，利用 TypeScript 类型推导
2. Deep Link 测试用 `npx uri-scheme open mytaskapp://task/42 --ios`
3. 导航状态持久化要加版本号
4. 生产环境用 `expo-linking` 而非 `Linking` 原生模块
5. Tab 图标用 `@expo/vector-icons`，内置多种图标库

## 小结

`expo-router` 用文件系统路由降低配置成本。核心要点：目录结构表达导航层级，`[param]` 处理动态路由，Layout 做全局守卫，`useFocusEffect` 处理屏幕焦点事件。
