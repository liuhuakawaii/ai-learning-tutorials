# 深度导航配置

## 导航不只是页面跳转

React Native 的导航比 Web 复杂得多。Web 上跳转就是改 URL，浏览器处理历史记录。移动端需要考虑：

- Tab 切换时保持页面状态
- 返回手势（iOS 从左边缘右滑）
- 深层链接（从通知跳转到特定页面）
- 模态框 vs 推送页面的动画差异
- 嵌套导航（Tab 里有 Stack，Stack 里有 Tab）

## Expo Router 基础

Expo Router 基于文件系统，文件名即路由：

```
app/
├── _layout.tsx          # 根布局
├── (tabs)/
│   ├── _layout.tsx      # Tab 布局
│   ├── index.tsx        # / (Tab 1)
│   └── explore.tsx      # /explore (Tab 2)
├── article/[id].tsx     # /article/123
└── modal.tsx            # /modal (模态框)
```

## Stack 导航

页面推入/弹出，有前进后退的层次感：

```tsx
// app/_layout.tsx
import { Stack } from 'expo-router'

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      <Stack.Screen name="article/[id]" options={{ title: '详情' }} />
      <Stack.Screen name="modal" options={{ presentation: 'modal' }} />
    </Stack>
  )
}
```

`presentation: 'modal'` 让页面从底部滑入，而不是从右侧推入。

## Tab 导航

底部标签栏，切换时保持各 Tab 的页面状态：

```tsx
// app/(tabs)/_layout.tsx
import { Tabs } from 'expo-router'
import { Ionicons } from '@expo/vector-icons'

export default function TabLayout() {
  return (
    <Tabs screenOptions={{ tabBarActiveTintColor: '#3b82f6' }}>
      <Tabs.Screen name="index" options={{
        title: '首页',
        tabBarIcon: ({ color, size }) => <Ionicons name="home-outline" size={size} color={color} />,
      }} />
      <Tabs.Screen name="profile" options={{
        title: '我的',
        tabBarIcon: ({ color, size }) => <Ionicons name="person-outline" size={size} color={color} />,
      }} />
    </Tabs>
  )
}
```

## 编程式导航

```tsx
import { useRouter } from 'expo-router'

export default function MyComponent() {
  const router = useRouter()

  return (
    <View>
      <Button title="详情" onPress={() => router.push(`/article/${id}`)} />
      <Button title="返回" onPress={() => router.back()} />
      <Button title="替换" onPress={() => router.replace('/home')} />
      <Button title="模态" onPress={() => router.push('/modal')} />
    </View>
  )
}
```

`push` 推入新页面，`replace` 替换当前页面（没有返回动画），`back` 返回上一页。

## 深层链接

配置 `app.json` 的 `scheme`，让外部链接直接跳转到应用内页面：

```json
{
  "expo": {
    "scheme": "myapp"
  }
}
```

之后 `myapp://article/123` 会打开文章详情页。

## 导航守卫

Expo Router 没有内置的路由守卫。用 `useEffect` + `redirect` 实现：

```tsx
import { useRouter, useSegments } from 'expo-router'
import { useAuth } from '@/hooks/useAuth'

export function AuthGate({ children }) {
  const router = useRouter()
  const segments = useSegments()
  const { user } = useAuth()

  useEffect(() => {
    const inAuthGroup = segments[0] === '(auth)'
    if (!user && !inAuthGroup) {
      router.replace('/login')
    } else if (user && inAuthGroup) {
      router.replace('/')
    }
  }, [user, segments])

  return children
}
```
