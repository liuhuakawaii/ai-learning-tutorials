# Stage 1：Expo 基础

> 从零搭建 React Native 开发环境，掌握核心组件、导航、状态管理和网络请求。

## 学习目标

完成本阶段后，你将能够：

1. 使用 Expo CLI 创建和运行 React Native 项目
2. 使用核心组件构建移动端 UI
3. 实现多页面导航
4. 管理应用状态和网络请求
5. 独立完成一个新闻阅读 App

## 课时列表

| # | 课时 | 核心内容 |
|---|------|----------|
| 01 | Expo 环境搭建 | Expo CLI、模拟器、真机调试 |
| 02 | 核心组件与样式 | View/Text/Image/ScrollView、Flexbox 布局 |
| 03 | 导航系统 | Expo Router、Stack/Tab/Drawer 导航 |
| 04 | 状态管理 | Zustand/React Query 在移动端的使用 |
| 05 | 网络请求 | fetch/axios、离线缓存、错误处理 |
| 06 | 阶段实战：新闻阅读 App | 构建完整新闻阅读 App |

## 阶段项目

新闻阅读 App——支持新闻列表浏览、文章详情、收藏、搜索功能。
