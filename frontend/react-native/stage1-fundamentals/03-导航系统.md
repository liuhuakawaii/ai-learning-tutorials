# 导航系统

## 场景引入

App 有多个页面：首页、详情、个人中心。用户需要跳转、返回、底部标签切换。Web 由浏览器 URL 处理，React Native 需要导航库。Expo Router 基于 React Navigation，用文件系统路由降低配置成本。

## 学习目标

- 理解 Expo Router 文件系统路由
- 实现 Stack/Tab/Drawer 导航
- 掌握参数传递与路由守卫

---

## 一、Expo Router 基础

`app/` 目录下每个文件自动成为路由：

```
app/
├── _layout.tsx          # 根布局
├── index.tsx            # 首页（/）
├── (tabs)/
│   ├── _layout.tsx      # Tab 布局
│   ├── index.tsx        # Tab 首页
│   └── explore.tsx      # 探索页
└── article/[id].tsx     # 动态路由
```

安装：`npx create-expo-app@latest my-app --template tabs`，配置 `app.json` 添加 `"scheme": "myapp"` 和 `"plugins": ["expo-router"]`。

### 跳转与返回

```typescript
// app/index.tsx
import { View, Text, TouchableOpacity, FlatList, StyleSheet } from 'react-native';
import { useRouter } from 'expo-router';

const ITEMS = [{ id: '1', title: '新闻一' }, { id: '2', title: '新闻二' }, { id: '3', title: '新闻三' }];

export default function HomeScreen() {
  const router = useRouter();

  return (
    <FlatList data={ITEMS} keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <TouchableOpacity style={styles.card} onPress={() => router.push({
          pathname: '/detail', params: { id: item.id, title: item.title },
        })}>
          <Text style={styles.title}>{item.title}</Text>
          <Text style={styles.meta}>点击查看详情 →</Text>
        </TouchableOpacity>
      )} />
  );
}

const styles = StyleSheet.create({
  card: { backgroundColor: '#fff', padding: 16, marginHorizontal: 16, marginVertical: 6, borderRadius: 12, elevation: 2 },
  title: { fontSize: 17, fontWeight: '600' },
  meta: { fontSize: 13, color: '#007AFF', marginTop: 8 },
});
```

```typescript
// app/detail.tsx
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';
import { useLocalSearchParams, useRouter, Stack } from 'expo-router';

export default function DetailScreen() {
  const { id, title } = useLocalSearchParams<{ id: string; title: string }>();
  const router = useRouter();

  return (
    <View style={styles.container}>
      <Stack.Screen options={{ title: title ?? '详情' }} />
      <Text style={styles.title}>{title}</Text>
      <Text style={styles.content}>新闻 {id} 的详细内容...</Text>
      <TouchableOpacity style={styles.btn} onPress={() => router.back()}>
        <Text style={styles.btnText}>返回</Text>
      </TouchableOpacity>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16, gap: 16 },
  title: { fontSize: 22, fontWeight: '700' },
  content: { fontSize: 15, color: '#444', lineHeight: 22 },
  btn: { backgroundColor: '#007AFF', padding: 14, borderRadius: 10, alignItems: 'center' },
  btnText: { color: '#fff', fontSize: 16, fontWeight: '600' },
});
```

**导航方法**：`router.push`（压入）、`router.replace`（替换，无法返回）、`router.back`（返回）、`router.canGoBack()`（检查能否返回）。

## 六、路由守卫

```typescript
// app/_layout.tsx
import { useEffect } from 'react';
import { Stack, useRouter, useSegments } from 'expo-router';
import { useAuthStore } from '@/stores/auth';

export default function RootLayout() {
  const router = useRouter();
  const segments = useSegments();
  const { isAuthenticated } = useAuthStore();

  useEffect(() => {
    const inAuthGroup = segments[0] === '(auth)';
    if (!isAuthenticated && !inAuthGroup) router.replace('/(auth)/login');
    else if (isAuthenticated && inAuthGroup) router.replace('/(tabs)');
  }, [isAuthenticated, segments]);

  return (
    <Stack screenOptions={{ headerShown: false }}>
      <Stack.Screen name="(tabs)" />
      <Stack.Screen name="(auth)" options={{ presentation: 'modal' }} />
    </Stack>
  );
}
```

```typescript
// stores/auth.ts
import { create } from 'zustand';
import AsyncStorage from '@react-native-async-storage/async-storage';

interface User { id: string; name: string; }
interface AuthState { user: User | null; isAuthenticated: boolean; login: (u: User) => Promise<void>; logout: () => Promise<void>; }

export const useAuthStore = create<AuthState>((set) => ({
  user: null, isAuthenticated: false,
  login: async (user) => { await AsyncStorage.setItem('user', JSON.stringify(user)); set({ user, isAuthenticated: true }); },
  logout: async () => { await AsyncStorage.removeItem('user'); set({ user: null, isAuthenticated: false }); },
}));
```

```typescript
// app/(auth)/login.tsx
import { View, Text, TextInput, TouchableOpacity, StyleSheet } from 'react-native';
import { useState } from 'react';
import { useAuthStore } from '@/stores/auth';

export default function LoginScreen() {

        <Text style={styles.btnText}>登录</Text>

  );
}
```

## 常见误区

1. **Tab 内直接 push**：在根 Stack 层跳转，应嵌套子 Stack
2. **路由守卫闪烁**：加 loading 状态避免短暂看到首页
3. **参数类型混淆**：始终是字符串，数字需转换
4. **useEffect 中直接导航**：可能在渲染完成前执行
5. **Drawer/Tab 嵌套顺序错**：通常 Drawer 在外，Tab 在内

---

## 工程建议

1. **目录分组**：`(group)` 不影响 URL，用于逻辑分组
2. **类型安全**：`useLocalSearchParams<T>` 泛型
3. **深度链接**：配置 scheme 支持外部跳转
4. **返回按钮自定义**：headerLeft 覆盖默认行为

---

## 小结

- Expo Router 文件即路由，文件名即路径
- Stack 用于页面跳转，Tab 用于模块切换
- `useRouter` 提供 push/replace/back，`useLocalSearchParams` 接收参数
- 路由守卫监听 useSegments + 认证状态实现拦截
