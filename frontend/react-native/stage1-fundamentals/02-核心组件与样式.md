# 核心组件与样式

## 场景引入

Web 开发中你用 `div`、`span`、`img`，React Native 里这些标签不存在。它提供跨平台原生组件，布局基于 Flexbox（默认方向是列），样式是 JS 对象而非 CSS。这节课掌握核心组件和样式系统。

## 学习目标

- 掌握 View、Text、Image 等核心组件
- 理解 StyleSheet 与 Flexbox 布局
- 使用 useWindowDimensions 实现响应式设计
- 使用 Platform.select 处理平台差异
- 实现暗色模式适配

---

## 一、核心组件

### 1.1 View — 容器

相当于 Web 的 `div`，默认不支持点击，需要交互请用 `TouchableOpacity`。

```typescript
import { View, Text, StyleSheet } from 'react-native';

export default function ViewExample() {
  return (
    <View style={styles.container}>
      <View style={styles.card}>
        <Text style={styles.title}>订单详情</Text>
        <View style={styles.divider} />
        <Text style={styles.content}>商品: React Native 实战教程</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5', padding: 16 },
  card: { backgroundColor: '#fff', borderRadius: 12, padding: 20, elevation: 3 },
  title: { fontSize: 18, fontWeight: '600' },
  divider: { height: 1, backgroundColor: '#e0e0e0', marginVertical: 12 },
  content: { fontSize: 15, color: '#666', marginTop: 8 },
});
```

### 1.2 Text — 文本

支持嵌套，子 Text 继承父 Text 样式。文本必须放在 Text 中，不能直接写在 View 里。

```typescript
import { Text, StyleSheet } from 'react-native';

export default function TextExample() {
  return (
    <Text style={styles.paragraph}>
      普通文本，<Text style={styles.bold}>粗体</Text>，
      <Text style={styles.link} onPress={() => console.log('点击')}>可点击链接</Text>。
    </Text>
  );
}

const styles = StyleSheet.create({
  paragraph: { fontSize: 16, lineHeight: 24, color: '#333' },
  bold: { fontWeight: '700' },
  link: { color: '#007AFF', textDecorationLine: 'underline' },
});
```

### 1.3 Image — 图片

网络图片必须指定宽高，本地图片用 `require`。`resizeMode`：`cover`（等比填满可能裁剪）、`contain`（等比完整显示）、`stretch`（拉伸）。

```typescript
import { View, Image, StyleSheet } from 'react-native';

export default function ImageExample() {
  return (
    <View style={styles.row}>
      <Image source={{ uri: 'https://picsum.photos/200/200' }} style={styles.img} resizeMode="cover" />
      <Image source={require('@/assets/images/local.png')} style={styles.img} resizeMode="contain" />
    </View>
  );
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', gap: 16, padding: 16 },
  img: { width: 120, height: 120, borderRadius: 12 },
});
```

### 1.4 ScrollView 与 FlatList

```typescript
import { View, Text, ScrollView, FlatList, StyleSheet } from 'react-native';

// ScrollView: 少量内容，一次性渲染全部子元素
function ScrollExample() {
  return (
    <ScrollView>
      {Array.from({ length: 20 }, (_, i) => (
        <View key={i} style={styles.item}><Text>第 {i + 1} 项</Text></View>
      ))}
    </ScrollView>
  );
}

// FlatList: 大量数据，虚拟化按需渲染
function FlatListExample() {
  const data = Array.from({ length: 1000 }, (_, i) => ({ id: String(i), title: `新闻 ${i + 1}` }));
  return (
    <FlatList
      data={data} keyExtractor={(item) => item.id}
      renderItem={({ item }) => <View style={styles.item}><Text>{item.title}</Text></View>}
      ItemSeparatorComponent={() => <View style={styles.sep} />}
      ListEmptyComponent={<Text style={styles.empty}>暂无数据</Text>}
      onEndReached={() => console.log('加载更多')} onEndReachedThreshold={0.3}
    />
  );
}

const styles = StyleSheet.create({
  item: { padding: 16, backgroundColor: '#fff' },
  sep: { height: 1, backgroundColor: '#f0f0f0' },
  empty: { textAlign: 'center', marginTop: 40, color: '#999' },
});
```

**选型**：少于 50 项 → ScrollView；大量数据/无限滚动 → FlatList；分组 → SectionList。

## 二、StyleSheet 与 Flexbox

### 2.1 StyleSheet 优势

`StyleSheet.create` 在启动时一次性创建样式对象，避免内联样式每次渲染都创建新对象。

### 2.2 Flexbox 布局

与 Web 两个关键差异：默认 `flexDirection` 是 `column`，默认 `flex` 值为 `0`。

```typescript
import { View, StyleSheet } from 'react-native';

export default function FlexExample() {
  return (
    <View style={styles.screen}>
      <View style={styles.row}>
        <View style={[styles.box, { backgroundColor: '#FF6B6B' }]} />
        <View style={[styles.box, { backgroundColor: '#4ECDC4' }]} />
        <View style={[styles.box, { backgroundColor: '#45B7D1' }]} />
      </View>
      <View style={styles.center}>
        <View style={[styles.box, { backgroundColor: '#DDA0DD' }]} />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, padding: 16, gap: 16 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', gap: 12 },
  center: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  box: { width: 80, height: 80, borderRadius: 8 },
});
```

## 三、响应式设计

```typescript
import { useWindowDimensions, View, Text, FlatList, StyleSheet } from 'react-native';

export default function AdaptiveGrid() {
  const { width } = useWindowDimensions();
  const numColumns = width > 768 ? 3 : width > 480 ? 2 : 1;
  const data = Array.from({ length: 6 }, (_, i) => ({ id: String(i), title: `卡片 ${i + 1}` }));

  return (
    <FlatList
      data={data} numColumns={numColumns} key={numColumns}
      contentContainerStyle={{ padding: 16, gap: 8 }}
      columnWrapperStyle={numColumns > 1 ? { gap: 8 } : undefined}
      renderItem={({ item }) => (
        <View style={[styles.card, { flex: 1 / numColumns }]}>
          <Text>{item.title}</Text>
        </View>
      )}
      keyExtractor={(item) => item.id}
    />
  );
}

const styles = StyleSheet.create({
  card: { aspectRatio: 1, backgroundColor: '#E8F4FD', borderRadius: 8, justifyContent: 'center', alignItems: 'center', marginBottom: 8 },
});
```

**推荐**：始终用 `useWindowDimensions`（Hook，旋转时自动更新），不要用 `Dimensions.get`（静态值）。

## 四、平台差异

```typescript
import { Platform, StyleSheet, View, Text } from 'react-native';

export default function PlatformExample() {
  return (
    <View style={styles.card}>
      <Text>当前平台: {Platform.OS}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    padding: 16, backgroundColor: '#fff', borderRadius: 8,
    ...Platform.select({
      ios: { shadowColor: '#000', shadowOffset: { width: 0, height: 2 }, shadowOpacity: 0.15, shadowRadius: 6 },
      android: { elevation: 4 },
    }),
  },
});
```

平台特定文件：`Header.ios.tsx` 和 `Header.android.tsx`，Metro 自动按平台选择。

## 五、暗色模式

```typescript
import { useColorScheme, View, Text, StyleSheet } from 'react-native';

const themes = {
  light: { bg: '#FFF', surface: '#F5F5F5', text: '#1A1A1A', primary: '#007AFF' },
  dark: { bg: '#1A1A1A', surface: '#2C2C2C', text: '#FFF', primary: '#0A84FF' },
};

export default function DarkModeExample() {
  const scheme = useColorScheme();
  const c = themes[scheme ?? 'light'];

  return (
    <View style={[styles.container, { backgroundColor: c.bg }]}>
      <View style={[styles.card, { backgroundColor: c.surface }]}>
        <Text style={[styles.title, { color: c.text }]}>暗色模式示例</Text>
        <Text style={{ color: c.text }}>当前: {scheme === 'dark' ? '深色' : '浅色'}</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16 },
  card: { padding: 20, borderRadius: 12, gap: 8 },
  title: { fontSize: 20, fontWeight: '700' },
});
```

## 常见误区

1. **View 中直接写文本**：必须用 Text 包裹
2. **网络图片不指定尺寸**：不会显示
3. **大量数据用 ScrollView**：应该用 FlatList
4. **Flexbox 默认方向搞错**：是 column 不是 row
5. **用 Dimensions.get 做响应式**：应该用 useWindowDimensions
6. **样式用字符串**：`fontSize: "16px"` 错误，是无单位数字

---

## 工程建议

1. **设计令牌**：颜色、间距、字号抽成常量
2. **主题系统**：useColorScheme + 颜色常量实现切换
3. **优先 FlatList**：未来扩展不需重构
4. **样式分层**：基础 StyleSheet，动态用数组合并 `style={[base, dynamic]}`
5. **测试横屏**：useWindowDimensions 需验证旋转布局

---

## 小结

- View/Text/Image 是基础构建块，Text 不能省略
- ScrollView 适合少量内容，FlatList 适合大量数据
- Flexbox 默认 column 方向，flex 默认 0
- useWindowDimensions 是响应式首选
- Platform.select 处理 iOS/Android 差异
- useColorScheme 适配暗色模式

### 练习二

```typescript
import { FlatList, View, Text, useWindowDimensions, StyleSheet } from 'react-native';

export default function ResponsiveGrid() {
  const { width } = useWindowDimensions();
  const numColumns = width > 768 ? 3 : width > 480 ? 4 : 2;
  const gap = 8;
  const itemW = (width - 32 - gap * (numColumns - 1)) / numColumns;
  const data = Array.from({ length: 20 }, (_, i) => ({ id: String(i), title: `项目 ${i + 1}` }));

  return (
    <FlatList data={data} numColumns={numColumns} key={numColumns}
      contentContainerStyle={{ padding: 16 }} columnWrapperStyle={{ gap }}
      ItemSeparatorComponent={() => <View style={{ height: gap }} />}
      renderItem={({ item }) => (
        <View style={[styles.item, { width: itemW, height: itemW }]}><Text>{item.title}</Text></View>
      )}
      keyExtractor={(item) => item.id} />
  );
}

const styles = StyleSheet.create({
  item: { borderRadius: 8, justifyContent: 'center', alignItems: 'center', backgroundColor: '#E8F4FD' },
});
```

`key={numColumns}` 强制列数变化时重新渲染。

### 练习三

```typescript
import { View, Text, useColorScheme, StyleSheet } from 'react-native';

const themes = {
  light: { bg: '#F2F2F7', surface: '#FFF', text: '#000', secondary: '#8E8E93', sep: '#C6C6C8' },
  dark: { bg: '#000', surface: '#1C1C1E', text: '#FFF', secondary: '#8E8E93', sep: '#38383A' },
};

export default function SettingsScreen() {
  const c = themes[useColorScheme() ?? 'light'];
  const items = [{ title: '通知设置', sub: '管理推送通知' }, { title: '隐私设置', sub: '数据与权限管理' }];

  return (
    <View style={[styles.container, { backgroundColor: c.bg }]}>
      <Text style={[styles.header, { color: c.text }]}>设置</Text>
      <View style={[styles.group, { backgroundColor: c.surface }]}>
        {items.map((item, i) => (
          <View key={i} style={[styles.row, i < items.length - 1 && { borderBottomWidth: StyleSheet.hairlineWidth, borderBottomColor: c.sep }]}>
            <View>
              <Text style={{ color: c.text, fontSize: 16, fontWeight: '500' }}>{item.title}</Text>
              <Text style={{ color: c.secondary, fontSize: 13, marginTop: 2 }}>{item.sub}</Text>
            </View>
            <Text style={{ color: c.secondary, fontSize: 24 }}>›</Text>
          </View>
        ))}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16 },
  header: { fontSize: 32, fontWeight: '700', marginBottom: 24 },
  group: { borderRadius: 12, overflow: 'hidden' },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 16 },
});
```

`StyleSheet.hairlineWidth` 适配 Retina 屏分隔线。
