# 语音交互

## 场景引入

外卖骑手双手都在扶车把，想给客户发一条"已经到了楼下"的消息，却发现打字不方便。如果 App 支持语音输入，骑手只需按住按钮说一句话，就能自动转成文字并发送。

语音交互在驾驶、做饭、运动等双手被占用的场景中是唯一高效的交互方式。本节课从 TTS（文字转语音）和 STT（语音转文字）两个方向，带你构建完整的语音交互链路。

## 学习目标

- 掌握 expo-speech 实现语音合成（TTS）
- 掌握 react-native-voice 实现语音识别（STT）
- 学会设计完整的语音交互流程
- 了解多语言支持和语音唤醒词的实现方案

## 语音合成（TTS）：expo-speech

```typescript
// src/services/TTSService.ts
import * as Speech from 'expo-speech';

export class TTSService {
  private isSpeaking = false;

  async speak(text: string, options?: Speech.SpeechOptions): Promise<void> {
    if (this.isSpeaking) await this.stop();
    this.isSpeaking = true;

    await Speech.speak(text, {
      language: 'zh-CN',
      pitch: 1.0,
      rate: 1.0,
      onDone: () => { this.isSpeaking = false; },
      onStopped: () => { this.isSpeaking = false; },
      onError: () => { this.isSpeaking = false; },
      ...options,
    });
  }

  async stop(): Promise<void> {
    if (this.isSpeaking) {
      await Speech.stop();
      this.isSpeaking = false;
    }
  }

  async getAvailableVoices(): Promise<Speech.Voice[]> {
    return Speech.getAvailableVoicesAsync();
  }
}
```

### 语音队列管理

```typescript
// src/services/SpeechQueue.ts
import * as Speech from 'expo-speech';

interface QueueItem {
  text: string;
  options?: Speech.SpeechOptions;
  priority: 'high' | 'normal';
}

export class SpeechQueue {
  private queue: QueueItem[] = [];
  private processing = false;

  enqueue(text: string, priority: 'high' | 'normal' = 'normal'): void {
    if (priority === 'high') {
      Speech.stop();
      this.queue.unshift({ text, priority });
    } else {
      this.queue.push({ text, priority });
    }
    this.processNext();
  }

  private async processNext(): Promise<void> {
    if (this.processing || this.queue.length === 0) return;
    this.processing = true;
    const item = this.queue.shift()!;

    await Speech.speak(item.text, {
      language: 'zh-CN',
      rate: 1.0,
      onDone: () => { this.processing = false; this.processNext(); },
      onStopped: () => { this.processing = false; },
      onError: () => { this.processing = false; this.processNext(); },
      ...item.options,
    });
  }

  clear(): void {
    this.queue = [];
    Speech.stop();
    this.processing = false;
  }
}
```

## 语音识别（STT）：react-native-voice

```typescript
// src/services/STTService.ts
import Voice, { SpeechResultsEvent, SpeechErrorEvent } from '@react-native-voice/voice';

export class STTService {
  private isListening = false;
  private onResultCallback: ((text: string) => void) | null = null;

  constructor() {
    Voice.onSpeechResults = (event: SpeechResultsEvent) => {
      if (event.value?.length) this.onResultCallback?.(event.value[0]);
    };
    Voice.onSpeechError = () => { this.isListening = false; };
    Voice.onSpeechEnd = () => { this.isListening = false; };
  }

  async startListening(language: string, onResult: (text: string) => void): Promise<void> {
    if (this.isListening) await this.stopListening();
    this.onResultCallback = onResult;
    try {
      await Voice.start(language);
      this.isListening = true;
    } catch (error) {
      throw new Error(`启动语音识别失败: ${error}`);
    }
  }

  async stopListening(): Promise<void> {
    if (this.isListening) {
      await Voice.stop();
      this.isListening = false;
    }
  }

  destroy(): void { Voice.destroy(); }
}
```

## 按住说话组件

```typescript
// src/components/PushToTalkButton.tsx
import React, { useState, useCallback, useRef } from 'react';
import { Pressable, Text, StyleSheet, Animated } from 'react-native';
import { STTService } from '../services/STTService';

interface Props {
  onTranscript: (text: string) => void;
  language?: string;
}

export function PushToTalkButton({ onTranscript, language = 'zh-CN' }: Props) {
  const [isRecording, setIsRecording] = useState(false);
  const scaleAnim = useRef(new Animated.Value(1)).current;
  const sttRef = useRef(new STTService()).current;

  const handlePressIn = useCallback(async () => {
    setIsRecording(true);
    Animated.spring(scaleAnim, { toValue: 1.3, useNativeDriver: true }).start();
    await sttRef.startListening(language, (text) => {
      onTranscript(text);
      setIsRecording(false);
      Animated.spring(scaleAnim, { toValue: 1, useNativeDriver: true }).start();
    });
  }, [language, onTranscript]);

  const handlePressOut = useCallback(async () => {
    await sttRef.stopListening();
    setIsRecording(false);
    Animated.spring(scaleAnim, { toValue: 1, useNativeDriver: true }).start();
  }, []);

  return (
    <Pressable onPressIn={handlePressIn} onPressOut={handlePressOut}>
      <Animated.View style={[styles.button, { transform: [{ scale: scaleAnim }] }]}>
        <Text style={styles.text}>{isRecording ? '松开结束' : '按住说话'}</Text>
      </Animated.View>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: { width: 80, height: 80, borderRadius: 40, backgroundColor: '#007AFF', justifyContent: 'center', alignItems: 'center' },
  text: { color: '#fff', fontSize: 14, fontWeight: '600' },
});
```

## 语音对话流程

```typescript
// src/services/VoiceChatService.ts
import { STTService } from './STTService';
import { TTSService } from './TTSService';

type VoiceChatState = 'idle' | 'listening' | 'processing' | 'speaking';

export class VoiceChatService {
  private stt: STTService;
  private tts: TTSService;
  private state: VoiceChatState = 'idle';
  private onStateChange: ((state: VoiceChatState) => void) | null = null;

  constructor() {
    this.stt = new STTService();
    this.tts = new TTSService();
  }

  setStateChangeListener(listener: (state: VoiceChatState) => void): void {
    this.onStateChange = listener;
  }

  private setState(newState: VoiceChatState): void {
    this.state = newState;
    this.onStateChange?.(newState);
  }

  async startVoiceChat(processMessage: (text: string) => Promise<string>): Promise<void> {
    this.setState('listening');
    await this.stt.startListening('zh-CN', async (userText) => {
      this.setState('processing');
      try {
        const aiResponse = await processMessage(userText);
        this.setState('speaking');
        await this.tts.speak(aiResponse);
      } catch {
        await this.tts.speak('抱歉，处理出错了');
      }
      this.setState('idle');
    });
  }

  async stop(): Promise<void> {
    await this.stt.stopListening();
    await this.tts.stop();
    this.setState('idle');
  }
}
```

```typescript
// src/config/languages.ts
export interface LanguageConfig {
  code: string;
  name: string;
  ttsLanguage: string;
  sttLanguage: string;
}

export const supportedLanguages: LanguageConfig[] = [
  { code: 'zh', name: '中文', ttsLanguage: 'zh-CN', sttLanguage: 'zh-CN' },
  { code: 'en', name: 'English', ttsLanguage: 'en-US', sttLanguage: 'en-US' },
  { code: 'ja', name: '日本語', ttsLanguage: 'ja-JP', sttLanguage: 'ja-JP' },
];

// src/hooks/useLanguage.ts
import { useState, useCallback } from 'react';
import { supportedLanguages, LanguageConfig } from '../config/languages';

export function useLanguage(defaultCode: string = 'zh') {
  const [current, setCurrent] = useState<LanguageConfig>(
    supportedLanguages.find(l => l.code === defaultCode) || supportedLanguages[0]
  );

  const switchLanguage = useCallback((code: string) => {
    const lang = supportedLanguages.find(l => l.code === code);
    if (lang) setCurrent(lang);
  }, []);

  return { current, switchLanguage, supported: supportedLanguages };
}
```

## 常见误区

1. **不做静音检测就持续录音**：持续录音会快速消耗电量，必须实现 VAD（Voice Activity Detection），在检测到静音时自动停止。
2. **TTS 语言参数不匹配**：中文文本用英文引擎朗读会乱码，必须确保语言参数与文本一致。
3. **忽略权限请求时机**：麦克风权限应该在用户首次使用语音功能时请求，并解释用途。
4. **将 STT 结果直接作为最终结果**：语音识别有错误率，关键操作需要用户确认后再执行。
5. **不做网络状态检测**：云端 STT 依赖网络，离线时应有明确提示。

## 工程建议

- **录音格式**：16kHz 采样率、16bit PCM，这是大多数 STT 引擎的最佳输入格式
- **分段发送**：长语音按句号或停顿分段，减少等待时间
- **电量优化**：唤醒词用专用低功耗模型，不用完整 STT 引擎做唤醒
- **用户体验**：录音时显示波形动画，识别中显示中间结果
- **无障碍**：语音交互不是无障碍的替代品，需同时支持屏幕阅读器

## 小结

移动端语音交互由 TTS（expo-speech）、STT（react-native-voice）和对话管理三部分组成。工程上重点关注：权限管理、静音检测、多语言切换和电量优化。

## 参考答案

### 练习一

**思路**：按住说话 + STT 识别 + 可编辑 TextInput + 保存到列表。核心是 `Pressable` 的 `onPressIn/onPressOut` 触发 STT，识别结果写入 draft state，用户修正后保存。

**要点**：识别结果可编辑后保存（OCR/STT 都不可能 100% 准确）；录音动画反馈让用户知道 App 在"听"。

### 练习二

**思路**：用正则匹配实现命令解析，`register` 方法支持扩展。核心代码：`const match = input.trim().match(cmd.pattern)` 提取参数，`cmd.action(match.slice(1))` 执行。

**要点**：正则覆盖中文指令，注意 `，` 和 `,` 兼容；未匹配时给出反馈而非静默失败。
