# Stage 4：AI 移动端集成

> 将 AI 能力带入移动端——语音交互、图像识别、实时对话、离线推理。

## 学习目标

完成本阶段后，你将能够：

1. 在移动端部署和运行 AI 模型
2. 实现语音识别与合成
3. 集成 OCR 与条码扫描
4. 构建流式 AI 对话界面
5. 实现离线 AI 推理能力
6. 完成一个完整的 AI 助手 App

## 课时列表

| # | 课时 | 核心内容 |
|---|------|----------|
| 01 | 移动端 AI 推理 | on-device 模型、Core ML/NNAPI |
| 02 | 语音交互 | 语音识别、TTS、实时语音 |
| 03 | 图像识别 | 拍照识别、OCR、条码扫描 |
| 04 | 实时 AI 对话 | 流式响应、WebSocket、上下文管理 |
| 05 | 离线 AI 能力 | 本地模型部署、离线推理 |
| 06 | 阶段实战：AI 助手 App | 构建完整 AI 移动助手 |

## 阶段项目

AI 助手 App——支持文字/语音/图片多模态输入、流式对话、离线降级。
