# 离线 AI 能力

## 场景引入

用户在地铁里想用 AI 助手翻译一段英文，但信号极差，请求 30 秒没有响应，最终收到"网络连接失败"。

纯云端 AI 的致命弱点——完全依赖网络。地铁、电梯、山区、飞机模式都是无信号场景。如果 App 能在离线状态下提供基本 AI 能力，用户体验会好得多。本节课探讨如何在设备端部署 AI 模型，实现离线推理。

## 学习目标

- 理解本地模型部署的策略与约束
- 掌握量化模型（GGML）的基本概念
- 学会实现 on-device RAG
- 掌握模型热更新和离线/在线切换策略

## 部署方案对比

| 方案 | 模型大小 | 推理速度 | 质量 | 适用场景 |
|------|----------|----------|------|----------|
| TFLite 小模型 | 10-50MB | 极快 | 低 | 分类、关键词检测 |
| 量化 LLM (2B) | 1-2GB | 较慢 | 中 | 简单问答、摘要 |
| 量化 LLM (7B) | 4-6GB | 慢 | 较高 | 复杂对话、翻译 |
| 云端 API | 无 | 依赖网络 | 最高 | 所有场景（在线时） |

移动端实际可行：量化后的小参数量 LLM（1B-3B），配合 RAG 增强特定领域知识。

## 模型选择

```typescript
// src/services/ModelSelector.ts
interface DeviceProfile { ramGB: number; storageGB: number; }
interface ModelOption { name: string; sizeMB: number; minRamGB: number; quality: string; tasks: string[]; }

const models: ModelOption[] = [
  { name: 'qwen2-0.5b-q4', sizeMB: 400, minRamGB: 2, quality: 'low', tasks: ['qa', 'summary'] },
  { name: 'qwen2-1.5b-q4', sizeMB: 900, minRamGB: 3, quality: 'medium', tasks: ['qa', 'summary', 'translate'] },
  { name: 'qwen2-3b-q4', sizeMB: 1800, minRamGB: 4, quality: 'high', tasks: ['qa', 'summary', 'translate', 'creative'] },
];

export class ModelSelector {
  selectBest(device: DeviceProfile, task: string): ModelOption | null {
    return models
      .filter(m => m.minRamGB <= device.ramGB && m.sizeMB / 1024 < device.storageGB * 0.1)
      .filter(m => m.tasks.includes(task))
      .sort((a, b) => ({ low: 0, medium: 1, high: 2 }[b.quality]! - { low: 0, medium: 1, high: 2 }[a.quality]!))[0] ?? null;
  }
}
```

## 量化模型

量化将权重从 FP32/FP16 压缩到 INT4，移动端推荐 GGML Q4_K_M 格式：

| 量化位数 | 大小倍数 | 质量保留 | 说明 |
|----------|----------|----------|------|
| FP16 | 0.5x | 99%+ | 现代 GPU 原生支持 |
| INT8 | 0.25x | 97-99% | 质量损失极小 |
| INT4 | 0.125x | 90-95% | 移动端主流选择 |

## 模型下载与管理

```typescript
// src/services/ModelManager.ts
import * as FileSystem from 'expo-file-system';

export class ModelManager {
  private modelDir = `${FileSystem.documentDirectory}models/`;

  async ensureDir(): Promise<void> {
    const info = await FileSystem.getInfoAsync(this.modelDir);
    if (!info.exists) await FileSystem.makeDirectoryAsync(this.modelDir, { intermediates: true });
  }

  async downloadModel(url: string, name: string, onProgress: (pct: number) => void): Promise<string> {
    await this.ensureDir();
    const path = `${this.modelDir}${name}`;
    const existing = await FileSystem.getInfoAsync(path);
    if (existing.exists) { onProgress(100); return path; }

    const download = FileSystem.createDownloadResumable(url, path, {}, (p) => {
      onProgress(Math.round(p.totalBytesWritten / p.totalBytesExpectedToWrite * 100));
    });
    const result = await download.downloadAsync();
    if (!result) throw new Error('下载失败');
    return result.uri;
  }

  async listModels(): Promise<Array<{ name: string; sizeMB: number }>> {
    await this.ensureDir();
    const files = await FileSystem.readDirectoryAsync(this.modelDir);
    const result = [];
    for (const f of files) {
      if (!f.endsWith('.gguf')) continue;
      const info = await FileSystem.getInfoAsync(`${this.modelDir}${f}`);
      result.push({ name: f, sizeMB: Math.round((info.size ?? 0) / 1024 / 1024) });
    }
    return result;
  }

  async deleteModel(name: string): Promise<void> {
    const path = `${this.modelDir}${name}`;
    if ((await FileSystem.getInfoAsync(path)).exists) await FileSystem.deleteAsync(path);
  }
}
```

## On-Device RAG

```typescript
// src/services/LocalRAG.ts
interface Chunk { id: string; content: string; embedding: number[]; metadata: Record<string, string>; }
interface SearchResult { chunk: Chunk; score: number; }

export class LocalRAG {
  private chunks: Chunk[] = [];
  private dim = 384;

  private embed(text: string): number[] {
    const words = text.toLowerCase().split(/\s+/);
    const vec = new Array(this.dim).fill(0);
    for (const w of words) {
      let h = 0; for (let i = 0; i < w.length; i++) h = ((h << 5) - h + w.charCodeAt(i)) | 0;
      vec[Math.abs(h) % this.dim] += 1 / words.length;
    }
    const norm = Math.sqrt(vec.reduce((s, v) => s + v * v, 0));
    return norm > 0 ? vec.map(v => v / norm) : vec;
  }

  addDocument(content: string, metadata: Record<string, string> = {}): void {
    const sentences = content.split(/[。！？\n]+/).filter(s => s.trim().length > 10);
    for (let i = 0; i < sentences.length; i++) {
      const c = sentences[i].trim();
      this.chunks.push({ id: `c_${Date.now()}_${i}`, content: c, embedding: this.embed(c), metadata });
    }
  }

  search(query: string, topK = 3): SearchResult[] {
    const qe = this.embed(query);
    return this.chunks
      .map(c => ({ chunk: c, score: qe.reduce((s, v, i) => s + v * c.embedding[i], 0) }))
      .sort((a, b) => b.score - a.score)
      .slice(0, topK)
      .filter(r => r.score > 0.1);
  }

  buildRAGPrompt(query: string): string {
    const results = this.search(query);
    if (!results.length) return query;
    const ctx = results.map(r => `- ${r.chunk.content}`).join('\n');
    return `根据以下资料回答。如果没有相关信息，请说明不确定。\n\n资料：\n${ctx}\n\n问题：${query}`;
  }

  getChunkCount(): number { return this.chunks.length; }
}
```

## 离线/在线切换

```typescript
// src/services/HybridAIService.ts
import NetInfo from '@react-native-community/netinfo';
import { AIClient, ChatMessage } from './AIClient';
import { LocalRAG } from './LocalRAG';

type Mode = 'online' | 'offline' | 'auto';

export class HybridAIService {
  private client: AIClient | null = null;
  private rag = new LocalRAG();
  private mode: Mode;
  private isOnline = true;

  constructor(mode: Mode = 'auto') {
    this.mode = mode;
    NetInfo.addEventListener(s => { this.isOnline = s.isConnected ?? false; });
  }

  setClient(c: AIClient): void { this.client = c; }
  getRAG(): LocalRAG { return this.rag; }

  async chat(messages: ChatMessage[]): Promise<string> {
    if (this.shouldUseOnline() && this.client) {
      try {
        const res = await this.client.chat({ model: 'gpt-4o-mini', messages });
        return res.content;
      } catch { return this.offlineChat(messages); }
    }
    return this.offlineChat(messages);
  }

  private shouldUseOnline(): boolean {
    if (this.mode === 'online') return true;
    if (this.mode === 'offline') return false;
    return this.isOnline;
  }

  private offlineChat(messages: ChatMessage[]): string {
    const last = [...messages].reverse().find(m => m.role === 'user');
    if (!last) return '离线模式下无法处理，请连接网络后重试。';
    const results = this.rag.search(last.content, 3);
    if (!results.length) return '（离线模式）本地知识库中未找到相关信息。';
    return `（离线模式）根据本地知识库：\n\n${results.map(r => r.chunk.content).join('\n\n')}`;
  }

  getMode(): 'online' | 'offline' { return this.shouldUseOnline() ? 'online' : 'offline'; }
}
```

## 模型热更新

```typescript
// src/services/ModelUpdateService.ts
import { ModelManager } from './ModelManager';

interface Manifest {
  version: string;
  models: Array<{ name: string; url: string; sizeMB: number }>;
}

export class ModelUpdateService {
  private manager = new ModelManager();
  private manifestUrl: string;
  private currentVersion = '';

  constructor(manifestUrl: string) { this.manifestUrl = manifestUrl; }

  async checkUpdates(): Promise<Manifest | null> {
    try {
      const res = await fetch(this.manifestUrl);
      const manifest: Manifest = await res.json();
      return manifest.version !== this.currentVersion ? manifest : null;
    } catch { return null; }
  }

  async autoUpdate(): Promise<void> {
    const manifest = await this.checkUpdates();
    if (!manifest) return;
    for (const m of manifest.models) {
      console.log(`下载模型: ${m.name}...`);
      await this.manager.downloadModel(m.url, m.name, (p) => console.log(`${p}%`));
    }
    this.currentVersion = manifest.version;
  }
}
```

## 常见误区

1. **高估设备端模型能力**：3B 量化模型远不如 GPT-4o，定位是"能用"而非"好用"。
2. **不做设备性能检测**：2GB RAM 跑 3B 模型会 OOM 崩溃，必须根据设备选模型。
3. **忽略下载体验**：1-2GB 模型需要进度提示、断点续传和 WiFi 检测。
4. **离线 RAG 用全文搜索**：关键词匹配无法处理语义相似性，"没电"和"电池耗尽"应匹配。
5. **不清理旧模型**：更新后旧文件不删除，存储空间持续增长。

## 工程建议

- **模型分级**：准备小/中/大三个模型，根据设备自动选择
- **下载策略**：仅 WiFi 下自动下载，移动数据需用户确认
- **缓存策略**：离线推理结果缓存，相同问题不重复推理
- **降级体验**：离线模式明确标注，管理用户预期
- **存储管理**：提供模型管理界面，让用户手动删除不需要的模型
- **电量感知**：电量 < 20% 时建议切换到在线模式

## 小结

离线 AI 通过量化 LLM（GGML INT4）+ LocalRAG 在设备端提供基本 AI 服务。HybridAIService 实现在线/离线智能切换，ModelManager 管理模型生命周期。核心是：选对模型 → 本地推理 → 智能切换。

## 参考答案

### 练习一

**思路**：通过 react-native-device-info 获取设备信息，匹配最佳模型。

```typescript
import DeviceInfo from 'react-native-device-info';

interface Capability {
  totalRamGB: number;
  freeStorageGB: number;
  isLowEnd: boolean;
  recommendedModel: string | null;
  features: string[];
}

export class DeviceAdapter {
  async analyze(): Promise<Capability> {
    const ram = await DeviceInfo.getTotalMemory();
    const storage = await DeviceInfo.getFreeDiskStorage();
    const ramGB = ram / (1024 ** 3);
    const storageGB = storage / (1024 ** 3);
    const isLowEnd = ramGB < 3;

    let model: string | null = null;
    const features: string[] = [];

    if (ramGB >= 6 && storageGB > 5) {
      model = 'qwen2-3b-q4'; features.push('offline-chat', 'offline-translate', 'rag');
    } else if (ramGB >= 4 && storageGB > 3) {
      model = 'qwen2-1.5b-q4'; features.push('offline-chat', 'rag');
    } else if (ramGB >= 2 && storageGB > 1) {
      model = 'qwen2-0.5b-q4'; features.push('offline-summary');
    }

    return { totalRamGB: ramGB, freeStorageGB: storageGB, isLowEnd, recommendedModel: model, features };
  }
}
```

**要点**：RAM 决定模型大小，存储决定能下载几个；低端机强制走在线模式。

### 练习二

**思路**：预加载中英对照短语到 LocalRAG，检索语义最接近的翻译。

```typescript
import { LocalRAG } from '../services/LocalRAG';

const phrases = [
  { zh: '你好', en: 'Hello' }, { zh: '谢谢', en: 'Thank you' },
  { zh: '多少钱', en: 'How much?' }, { zh: '洗手间在哪', en: 'Where is the restroom?' },
  { zh: '我需要帮助', en: 'I need help' }, { zh: '请叫出租车', en: 'Please call a taxi' },
];

export class OfflineTranslator {
  private rag = new LocalRAG();

  constructor() {
    for (const p of phrases) this.rag.addDocument(`${p.zh} → ${p.en}`, { zh: p.zh, en: p.en });
  }

  translate(input: string): { text: string; confidence: number } | null {
    const results = this.rag.search(input, 1);
    if (!results.length || results[0].score < 0.2) return null;
    return { text: results[0].chunk.metadata.en ?? '', confidence: results[0].score };
  }

  addPhrase(zh: string, en: string): void {
    this.rag.addDocument(`${zh} → ${en}`, { zh, en });
  }
}
```

**要点**：置信度低于阈值返回 null，提示用户该短语不在离线库中；支持自定义添加。
