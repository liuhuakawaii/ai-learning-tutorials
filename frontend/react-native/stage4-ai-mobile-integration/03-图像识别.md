# 图像识别

## 场景引入

你在参加行业展会，收到一沓名片。传统做法是手动输入联系人信息，费时费力。如果 App 能拍照自动识别名片上的姓名、电话、邮箱并存入通讯录，效率能提升 10 倍。

图像识别在移动端的应用远不止名片扫描：商品识别、文档 OCR、条码扫描等场景都依赖将视觉信息转化为结构化数据。本节课从拍照到识别的完整链路出发，带你实现多个实际场景。

## 学习目标

- 掌握 React Native 中拍照与图片选择的完整流程
- 学会使用 react-native-mlkit-ocr 实现文字识别
- 掌握 expo-camera 实现条码和二维码扫描
- 能够实现名片识别和商品识别等实际场景

## 拍照与图片选择

```typescript
// src/services/ImageService.ts
import * as ImagePicker from 'expo-image-picker';
import { manipulateAsync, SaveFormat } from 'expo-image-manipulator';

export class ImageService {
  async takePhoto(): Promise<string | null> {
    const permission = await ImagePicker.requestCameraPermissionsAsync();
    if (!permission.granted) throw new Error('需要相机权限');
    const result = await ImagePicker.launchCameraAsync({ quality: 0.8, allowsEditing: true });
    if (result.canceled) return null;
    return result.assets[0].uri;
  }

  async pickFromGallery(): Promise<string | null> {
    const permission = await ImagePicker.requestMediaLibraryPermissionsAsync();
    if (!permission.granted) throw new Error('需要相册权限');
    const result = await ImagePicker.launchImageLibraryAsync({ quality: 0.8 });
    if (result.canceled) return null;
    return result.assets[0].uri;
  }

  async preprocessForOCR(imageUri: string): Promise<string> {
    const processed = await manipulateAsync(imageUri, [{ resize: { width: 1200 } }], { compress: 0.8, format: SaveFormat.JPEG });
    return processed.uri;
  }
}
```

## OCR 文字识别

```typescript
// src/services/OCRService.ts
import MlkitOcr from 'react-native-mlkit-ocr';

export interface TextBlock {
  text: string;
  confidence: number;
  boundingBox: { left: number; top: number; right: number; bottom: number };
}

export class OCRService {
  async recognizeText(imageUri: string): Promise<TextBlock[]> {
    const result = await MlkitOcr.detectFromUri(imageUri);
    return result.map(block => ({
      text: block.text,
      confidence: block.confidence ?? 0.9,
      boundingBox: block.boundingBox,
    }));
  }

  mergeSameLineBlocks(blocks: TextBlock[], lineThreshold = 20): string[] {
    const sorted = [...blocks].sort((a, b) => {
      const diff = a.boundingBox.top - b.boundingBox.top;
      return Math.abs(diff) > lineThreshold ? diff : a.boundingBox.left - b.boundingBox.left;
    });
    const lines: string[][] = [[]];
    let currentTop = sorted[0]?.boundingBox.top ?? 0;

    for (const block of sorted) {
      if (Math.abs(block.boundingBox.top - currentTop) > lineThreshold) {
        lines.push([]);
        currentTop = block.boundingBox.top;
      }
      lines[lines.length - 1].push(block.text);
    }
    return lines.map(l => l.join(' '));
  }
}
```

## 名片识别场景

```typescript
// src/services/BusinessCardService.ts
import { OCRService } from './OCRService';

interface ContactInfo {
  name: string; phone: string; email: string;
  company: string; title: string; rawText: string[];
}

export class BusinessCardService {
  private ocr = new OCRService();

  async recognizeCard(imageUri: string): Promise<ContactInfo> {
    const blocks = await this.ocr.recognizeText(imageUri);
    const lines = this.ocr.mergeSameLineBlocks(blocks);
    return {
      name: this.extractByLength(lines),
      phone: this.extractByPattern(lines, /(\+?[\d\s\-()]{7,15})/),
      email: this.extractByPattern(lines, /[\w.+-]+@[\w-]+\.[\w.]+/),
      company: this.extractByKeywords(lines, ['公司', '集团', '有限', 'Inc', 'Corp']),
      title: this.extractByKeywords(lines, ['经理', '总监', '工程师', 'CEO', 'CTO']),
      rawText: lines,
    };
  }

  private extractByPattern(lines: string[], regex: RegExp): string {
    for (const line of lines) { const m = line.match(regex); if (m) return m[0]; }
    return '';
  }

  private extractByKeywords(lines: string[], keywords: string[]): string {
    for (const line of lines) { if (keywords.some(kw => line.includes(kw))) return line.trim(); }
    return lines[0] || '';
  }

  private extractByLength(lines: string[]): string {
    for (const line of lines) {
      const c = line.trim();
      if (c.length >= 2 && c.length <= 10 && !/[\d@.]/.test(c)) return c;
    }
    return lines[0] || '';
  }
}
```

## 条码与二维码扫描

```typescript
// src/screens/BarcodeScannerScreen.tsx
import React, { useState } from 'react';
import { View, Text, StyleSheet, Alert } from 'react-native';
import { CameraView, useCameraPermissions } from 'expo-camera';

export function BarcodeScannerScreen() {
  const [permission] = useCameraPermissions();
  const [scanned, setScanned] = useState(false);
  const [barcode, setBarcode] = useState<string | null>(null);

  if (!permission?.granted) {
    return <View style={styles.center}><Text>需要相机权限来扫描条码</Text></View>;
  }

  const handleScanned = async ({ data, type }: { data: string; type: string }) => {
    if (scanned) return;
    setScanned(true);
    setBarcode(data);
    try {
      const res = await fetch(`https://api.example.com/product/${data}`);
      if (res.ok) { const info = await res.json(); Alert.alert(info.name, info.price); }
    } catch { Alert.alert('条码', data); }
  };

  return (
    <View style={styles.container}>
      <CameraView
        style={styles.camera}
        onBarcodeScanned={scanned ? undefined : handleScanned}
        barcodeScannerSettings={{ barcodeTypes: ['ean13', 'ean8', 'qr', 'code128'] }}
      >
        <View style={styles.overlay}><View style={styles.scanArea} /></View>
      </CameraView>
      {barcode && (
        <View style={styles.result}>
          <Text style={styles.barcodeText}>条码: {barcode}</Text>
          <Text onPress={() => { setScanned(false); setBarcode(null); }} style={styles.link}>重新扫描</Text>
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 }, camera: { flex: 1 },
  overlay: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  scanArea: { width: 250, height: 250, borderWidth: 2, borderColor: '#00ff00', borderRadius: 8 },
  center: { flex: 1, justifyContent: 'center', alignItems: 'center' },

  barcodeText: { fontSize: 16, fontWeight: '600' }, link: { color: '#007AFF', marginTop: 12, textAlign: 'center' },
});
```

## 商品识别

```typescript
// src/services/ProductRecognitionService.ts
import { OCRService } from './OCRService';

interface ProductInfo { name: string; brand: string; category: string; }

export class ProductRecognitionService {
  private ocr = new OCRService();
  private knownBrands = ['华为', '小米', '苹果', '三星', 'OPPO', 'vivo', 'Nike', 'Adidas'];

  async recognizeProduct(imageUri: string): Promise<ProductInfo> {
    const blocks = await this.ocr.recognizeText(imageUri);
    const lines = this.ocr.mergeSameLineBlocks(blocks);
    const brand = this.findBrand(lines);
    return {
      brand,
      name: brand ? `${brand} ${lines.find(l => /\b[A-Z]\d+/.test(l)) || ''}`.trim() : lines[0] || '未知',
      category: this.guessCategory(lines),
    };
  }

  private findBrand(lines: string[]): string {
    for (const line of lines) {
      for (const brand of this.knownBrands) { if (line.includes(brand)) return brand; }
    }
    return '';
  }

  private guessCategory(lines: string[]): string {
    const text = lines.join(' ');
    if (/手机|Phone|平板|Pad/.test(text)) return '电子产品';
    if (/鞋|Shirt|衣/.test(text)) return '服饰';
    return '其他';
  }
}
```

## 常见误区

1. **不做图片预处理直接识别**：原始图片（4000×3000）直接传给 OCR 会很慢且浪费内存，应先缩放到宽度 1000-1500px。
2. **忽略 OCR 置信度过滤**：低置信度结果通常是噪声，应设置阈值（如 0.6）过滤。
3. **将所有文字块当作独立行**：OCR 返回的文字块可能按词或段落分割，需根据空间位置合并同行。
4. **条码扫描不做去重**：摄像头持续扫描会产生大量重复结果，首次识别后应暂停。
5. **在 JS 线程处理图像**：图像处理应在原生层或 GPU 上执行。

## 工程建议

- **权限处理**：相机权限在使用前请求，被拒绝后引导用户到设置页
- **图片压缩**：上传前压缩到 1MB 以内
- **OCR 预处理**：灰度化 + 二值化可显著提升文档 OCR 准确率
- **识别结果缓存**：相同图片的识别结果应缓存，避免重复调用
- **离线优先**：OCR 和条码扫描可纯离线工作

## 小结

图像识别核心链路：拍照/选图 → 预处理 → OCR/分类 → 结构化解析。react-native-mlkit-ocr 提供 OCR，expo-camera 的条码扫描覆盖零售场景。工程上重点：图片预处理、置信度过滤、离线能力。

## 参考答案

### 练习一

**思路**：三步流程——拍照 → OCR 识别 → 可编辑结果。所有字段用 TextInput 展示，用户修正后保存。核心是 `BusinessCardService.recognizeCard()` 返回结构化 ContactInfo，每个字段可单独编辑。

**要点**：识别过程显示 loading；所有字段可编辑（OCR 准确率不可能 100%）；提供拍照和相册两种入口。

### 练习二

**思路**：连续扫描 + 去重 + 计数。核心逻辑：`setItems(prev => existing ? prev.map(i => i.barcode === data ? { ...i, count: i.count + 1 } : i) : [...prev, { barcode: data, count: 1 }])`。用 800ms 暂停窗口防重复触发。

**要点**：暂停窗口防同一帧重复触发；重复条码只增计数不添新行；导出为后续对接库存系统预留接口。
