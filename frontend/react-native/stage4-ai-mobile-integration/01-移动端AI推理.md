# 移动端 AI 推理

## AI 在移动端的三种模式

### 1. 云端 API

最简单——把数据发到服务器，服务器用大模型处理，返回结果。

```typescript
const response = await fetch('https://api.openai.com/v1/chat/completions', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: '你好' }],
  }),
})
```

优点：能力最强。缺点：需要网络、有延迟、有成本。

### 2. 设备端推理

模型直接在手机上运行，不需要网络。

```typescript
// 使用 expo-modules-core 加载 TFLite 模型
import { loadTensorflowModel } from 'react-native-fast-tflite'

const model = await loadTensorflowModel(require('./model.tflite'))
const output = await model.run([inputTensor])
```

优点：离线可用、无延迟、无成本。缺点：模型小、能力有限。

### 3. 混合模式

简单任务在设备端处理（文本分类、关键词提取），复杂任务调云端（长文本生成、代码分析）。

## 设备端推理框架

| 框架 | 平台 | 模型格式 | 特点 |
|------|------|---------|------|
| Core ML | iOS | .mlmodel | Apple 原生，性能最好 |
| TensorFlow Lite | 跨平台 | .tflite | 社区大，模型多 |
| ONNX Runtime | 跨平台 | .onnx | 微软出品，兼容性好 |
| MediaPipe | 跨平台 | .tflite | Google 出品，预训练模型丰富 |

## 端侧 AI 应用场景

- **图像分类**：识别物体、场景
- **文本分类**：情感分析、垃圾过滤
- **语音识别**：离线语音转文字
- **OCR**：文字识别
- **姿态检测**：人体关键点

这些任务的模型小（几 MB），推理快（毫秒级），适合端侧。

## 实时 AI 对话

```typescript
import { useState } from 'react'

export function ChatScreen() {
  const [messages, setMessages] = useState([])
  const [input, setInput] = useState('')
  const [loading, setLoading] = useState(false)

  async function send() {
    if (!input.trim() || loading) return
    const userMsg = { role: 'user', content: input }
    setMessages(prev => [...prev, userMsg])
    setInput('')
    setLoading(true)

    const response = await fetch('/api/chat', {
      method: 'POST',
      body: JSON.stringify({ messages: [...messages, userMsg] }),
    })
    const data = await response.json()
    setMessages(prev => [...prev, { role: 'assistant', content: data.reply }])
    setLoading(false)
  }

  return (
    <View style={{ flex: 1 }}>
      <FlatList data={messages} renderItem={({ item }) => <MessageBubble message={item} />} />
      <View style={{ flexDirection: 'row' }}>
        <TextInput value={input} onChangeText={setInput} placeholder="输入消息..." />
        <Button title="发送" onPress={send} disabled={loading} />
      </View>
    </View>
  )
}
```
