# 实时 AI 对话

## 场景引入

用户在 AI 助手 App 里输入"帮我写一封请假邮件"，点击发送后等了 15 秒，屏幕空白一片。用户失去耐心，杀掉了 App。

问题不是 AI 响应慢——大模型生成几百字确实需要时间——而是缺少流式体验。如果文字像打字机一样逐字出现，体感等待时间会缩短 5-10 倍。本节课带你实现完整的实时 AI 对话系统。

## 学习目标

- 掌握 OpenAI API 在 React Native 中的集成方式
- 学会实现 SSE 流式响应，打造打字机效果
- 掌握对话上下文窗口管理策略
- 学会对话历史持久化和 token 用量控制

## OpenAI API 客户端

```typescript
// src/services/AIClient.ts
export interface ChatMessage {
  role: 'system' | 'user' | 'assistant';
  content: string;
}

export interface ChatCompletionRequest {
  model: string;
  messages: ChatMessage[];
  stream?: boolean;
  temperature?: number;
  max_tokens?: number;
}

export class AIClient {
  private apiKey: string;
  private baseUrl: string;

  constructor(apiKey: string, baseUrl = 'https://api.openai.com/v1/chat/completions') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
  }

  async chat(request: ChatCompletionRequest): Promise<{ content: string; usage: { prompt: number; completion: number } }> {
    const response = await fetch(this.baseUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${this.apiKey}` },
      body: JSON.stringify({ ...request, stream: false }),
    });
    if (!response.ok) throw new Error(`API 请求失败: ${response.status}`);
    const data = await response.json();
    return {
      content: data.choices[0].message.content,
      usage: { prompt: data.usage.prompt_tokens, completion: data.usage.completion_tokens },
    };
  }
}
```

## 流式响应（SSE）

```typescript
// src/services/StreamingAIClient.ts
import { ChatMessage, ChatCompletionRequest } from './AIClient';

export interface StreamCallbacks {
  onToken: (token: string) => void;
  onComplete: (fullText: string, usage?: { prompt: number; completion: number }) => void;
  onError: (error: Error) => void;
}

export class StreamingAIClient {
  private apiKey: string;
  private baseUrl: string;
  private abortController: AbortController | null = null;

  constructor(apiKey: string, baseUrl = 'https://api.openai.com/v1/chat/completions') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
  }

  async streamChat(request: Omit<ChatCompletionRequest, 'stream'>, callbacks: StreamCallbacks): Promise<void> {
    this.abortController = new AbortController();
    let fullText = '';

    try {
      const response = await fetch(this.baseUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${this.apiKey}` },
        body: JSON.stringify({ ...request, stream: true }),
        signal: this.abortController.signal,
      });
      if (!response.ok) throw new Error(`API 请求失败: ${response.status}`);

      const reader = response.body?.getReader();
      if (!reader) throw new Error('无法获取响应流');

      const decoder = new TextDecoder();
      let buffer = '';

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() ?? '';

        for (const line of lines) {
          const trimmed = line.trim();
          if (!trimmed || trimmed === 'data: [DONE]' || !trimmed.startsWith('data: ')) continue;
          try {
            const json = JSON.parse(trimmed.slice(6));
            const delta = json.choices?.[0]?.delta?.content;
            if (delta) { fullText += delta; callbacks.onToken(delta); }
            if (json.choices?.[0]?.finish_reason === 'stop') {
              callbacks.onComplete(fullText, {
                prompt: json.usage?.prompt_tokens ?? 0,
                completion: json.usage?.completion_tokens ?? 0,
              });
            }
          } catch { /* 跳过解析失败的行 */ }
        }
      }
    } catch (error: any) {
      if (error.name === 'AbortError') callbacks.onComplete(fullText);
      else callbacks.onError(error);
    }
  }

  abort(): void { this.abortController?.abort(); }
}
```

## 流式对话 Hook

```typescript
// src/hooks/useStreamingChat.ts
import { useState, useRef, useCallback } from 'react';
import { StreamingAIClient } from '../services/StreamingAIClient';
import { ChatMessage } from '../services/AIClient';

interface Options {
  apiKey: string;
  model?: string;
  systemPrompt?: string;
  temperature?: number;
}

export function useStreamingChat(options: Options) {
  const { apiKey, model = 'gpt-4o-mini', systemPrompt = '你是一个有用的 AI 助手。', temperature = 0.7 } = options;
  const [messages, setMessages] = useState<ChatMessage[]>([{ role: 'system', content: systemPrompt }]);
  const [isStreaming, setIsStreaming] = useState(false);
  const [currentText, setCurrentText] = useState('');
  const [tokenUsage, setTokenUsage] = useState({ prompt: 0, completion: 0, total: 0 });
  const clientRef = useRef(new StreamingAIClient(apiKey));

  const sendMessage = useCallback(async (content: string) => {
    const userMsg: ChatMessage = { role: 'user', content };
    const updated = [...messages, userMsg];
    setMessages(updated);
    setIsStreaming(true);
    setCurrentText('');

    await clientRef.current.streamChat(
      { model, messages: updated, temperature },
      {
        onToken: (token) => setCurrentText(prev => prev + token),
        onComplete: (fullText, usage) => {
          setMessages([...updated, { role: 'assistant', content: fullText }]);
          setCurrentText('');
          setIsStreaming(false);
          if (usage) setTokenUsage(prev => ({
            prompt: prev.prompt + usage.prompt,
            completion: prev.completion + usage.completion,
            total: prev.total + usage.prompt + usage.completion,
          }));
        },
        onError: () => { setIsStreaming(false); setCurrentText(''); },
      }
    );
  }, [messages, model, temperature]);

  const stop = useCallback(() => clientRef.current.abort(), []);
  const clear = useCallback(() => {
    setMessages([{ role: 'system', content: systemPrompt }]);
    setTokenUsage({ prompt: 0, completion: 0, total: 0 });
  }, [systemPrompt]);

  return { messages, isStreaming, currentText, sendMessage, stop, clear, tokenUsage };
}
```

## 上下文窗口管理

```typescript
// src/services/ContextManager.ts
import { ChatMessage } from './AIClient';

export class ContextManager {
  private maxTokens: number;
  private summary = '';

  constructor(maxTokens = 4096) { this.maxTokens = maxTokens; }

  estimateTokens(text: string): number {
    const zh = (text.match(/[\u4e00-\u9fff]/g) || []).length;
    return Math.ceil(zh / 1.5 + (text.length - zh) / 4);
  }

  trimMessages(messages: ChatMessage[]): ChatMessage[] {
    const system = messages.filter(m => m.role === 'system');
    const chat = messages.filter(m => m.role !== 'system');
    const budget = this.maxTokens - 1024;
    let used = system.reduce((s, m) => s + this.estimateTokens(m.content), 0);
    const trimmed: ChatMessage[] = [];

    for (let i = chat.length - 1; i >= 0; i--) {
      const cost = this.estimateTokens(chat[i].content);
      if (used + cost > budget) break;
      trimmed.unshift(chat[i]);
      used += cost;
    }

    if (trimmed.length < chat.length && this.summary) {
      return [...system, { role: 'system', content: `之前的对话摘要：${this.summary}` }, ...trimmed];
    }
    return [...system, ...trimmed];
  }

  async generateSummary(messages: ChatMessage[]): Promise<string> {
    const text = messages.filter(m => m.role !== 'system').map(m => `${m.role}: ${m.content}`).join('\n');
    this.summary = text.slice(0, 500) + '...';
    return this.summary;
  }
}
```

## 对话历史持久化

```typescript
// src/services/ChatStorage.ts
import AsyncStorage from '@react-native-async-storage/async-storage';
import { ChatMessage } from './AIClient';

export interface Conversation {
  id: string; title: string; messages: ChatMessage[]; createdAt: number; updatedAt: number;
}

const KEY = 'conversations';

export class ChatStorage {
  async save(conv: Conversation): Promise<void> {
    const all = await this.getAll();
    const idx = all.findIndex(c => c.id === conv.id);
    if (idx >= 0) all[idx] = { ...conv, updatedAt: Date.now() };
    else all.push({ ...conv, createdAt: Date.now(), updatedAt: Date.now() });
    await AsyncStorage.setItem(KEY, JSON.stringify(all));
  }

  async getAll(): Promise<Conversation[]> {
    const data = await AsyncStorage.getItem(KEY);
    return data ? JSON.parse(data) : [];
  }

  async get(id: string): Promise<Conversation | null> {
    return (await this.getAll()).find(c => c.id === id) ?? null;
  }

  async delete(id: string): Promise<void> {
    await AsyncStorage.setItem(KEY, JSON.stringify((await this.getAll()).filter(c => c.id !== id)));
  }
}
```

## Token 用量控制

```typescript
// src/services/TokenBudget.ts
export class TokenBudget {
  private dailyLimit: number;
  private dailyUsed = 0;
  private dayStart: number;

  constructor(dailyLimit = 100000) {
    this.dailyLimit = dailyLimit;
    const d = new Date(); d.setHours(0, 0, 0, 0);
    this.dayStart = d.getTime();
  }

  private checkReset(): void {
    const d = new Date(); d.setHours(0, 0, 0, 0);
    if (d.getTime() > this.dayStart) { this.dailyUsed = 0; this.dayStart = d.getTime(); }
  }

  canSend(estimated: number): { ok: boolean; reason?: string } {
    this.checkReset();
    if (this.dailyUsed + estimated > this.dailyLimit)
      return { ok: false, reason: `已达每日上限 (${this.dailyUsed}/${this.dailyLimit})` };
    return { ok: true };
  }

  record(prompt: number, completion: number): void { this.dailyUsed += prompt + completion; }

  getUsage(): { used: number; limit: number; pct: number } {
    this.checkReset();
    return { used: this.dailyUsed, limit: this.dailyLimit, pct: Math.round(this.dailyUsed / this.dailyLimit * 100) };
  }
}
```

## 常见误区

1. **不做请求取消**：用户快速连续发送时，旧的流式请求应取消，否则多个响应会交替输出。用 AbortController 管理。
2. **无限累积上下文**：所有历史消息都发给 API 会导致 token 爆炸。必须实现上下文裁剪。
3. **流式 token 直接拼 state**：用 `setState(prev => prev + token)` 闭包可能丢字符。应用 ref 存完整文本。
4. **不处理网络中断**：移动端网络不稳定，流式请求随时可能中断，需要优雅降级。
5. **对话历史只存内存**：App 被杀后对话就丢了，必须持久化。

## 工程建议

- **API Key 安全**：绝对不要在客户端硬编码，通过后端代理转发
- **流式超时**：设置 60-120 秒超时
- **重试策略**：网络错误时指数退避（1s → 2s → 4s），最多 3 次
- **成本控制**：实现每日 token 上限，接近阈值时提醒
- **消息压缩**：长对话做上下文压缩，只保留最近 N 轮 + 摘要

## 小结

实时 AI 对话系统三层架构：传输层（SSE 流式响应）、体验层（打字机 + Markdown 渲染）、管理层（上下文裁剪 + token 控制 + 持久化）。StreamingAIClient 负责流式通信，ContextManager 管理上下文，ChatStorage 处理持久化。

## 参考答案

### 练习一

**思路**：中断后将已接收内容作为 assistant 前缀注入上下文，附带"请继续"的 user 消息，重新发起请求让模型续写。用指数退避（1s → 2s → 4s）控制重试频率。核心：`{ role: 'assistant', content: received }` + `{ role: 'user', content: '请继续' }`。

**要点**：指数退避避免频繁重试；续写是新请求有新计费；用 `AbortController` 管理取消。

### 练习二

**思路**：ChatStorage 管理多对话，左侧 FlatList 列表 + 右侧 StreamingMarkdown。搜索在本地 `filter(c => c.title.includes(query))` 过滤。新建对话调用 `clear()` 重置状态，切换对话调用 `storage.get(id)` 加载消息。

**要点**：搜索同时匹配标题和内容；长按删除防误操作；空状态有友好提示。
