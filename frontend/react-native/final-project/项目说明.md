# 毕业项目：AI 智能助手 App

> 整合五阶段所学，构建一个具备 AI 能力的可发布移动应用。

## 项目概述

本项目是 React Native 移动端开发课程的毕业项目。学员需要基于前五个阶段的实战成果，整合为一个完整的 **AI 智能助手 App**，并完成发布上架。

## 功能要求

### 核心模块

| 模块 | 来源阶段 | 功能 |
|------|----------|------|
| 新闻聚合 | Stage 1 | 新闻列表、详情阅读、收藏、搜索 |
| 任务管理 | Stage 2 | 任务 CRUD、分组筛选、推送提醒、手势交互 |
| 地图签到 | Stage 3 | GPS 签到、生物识别验证、签到记录 |
| AI 对话 | Stage 4 | 多模态输入、流式对话、离线降级 |
| 应用发布 | Stage 5 | 图标启动屏、商店提交、热更新、监控 |

### 技术要求

- 使用 Expo SDK 52+ 与 Expo Router v4
- 使用 TypeScript 全量类型
- 状态管理：Zustand + React Query
- 本地存储：MMKV + SQLite
- AI 集成：OpenAI API + on-device 模型
- 发布：EAS Build + EAS Update
- 监控：Sentry

## 验证要求

毕业项目需通过以下验证：

1. **代码质量**：TypeScript 类型检查通过，无 `any` 类型滥用
2. **功能完整性**：5 个核心模块均可用
3. **AI 能力**：流式对话可用，离线降级正常
4. **性能指标**：启动时间 < 2s，列表滚动 60fps
5. **发布就绪**：可通过 EAS Build 构建
