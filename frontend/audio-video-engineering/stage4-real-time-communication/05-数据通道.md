# 数据通道

## 场景引入

视频会议不只是音视频。你需要聊天功能让参与者发文字消息，需要文件分享让团队传文档，需要实时同步光标位置让协作更高效。

WebRTC 提供了 DataChannel，专门用于在浏览器之间传输任意数据。它和音视频流共享同一个连接，但走的是独立的 SCTP 通道——可靠或不可靠、有序或无序，完全由你控制。

这节课我们学习 DataChannel 的使用，实现文件传输和实时消息功能。

## 学习目标

1. 掌握 RTCDataChannel 的创建和配置
2. 理解可靠性参数：ordered、maxRetransmits、maxPacketLifeTime
3. 实现大文件分块传输
4. 实现实时聊天消息
5. 了解 SCTP 协议的特性

## RTCDataChannel 基础

### 创建方式

DataChannel 的创建有两种方式，取决于谁先发起：

```javascript
// 方式一：主动创建方
const pc = new RTCPeerConnection(config);
const channel = pc.createDataChannel('chat', {
  ordered: true,
  // 可靠模式（默认）
});

channel.onopen = () => {
  console.log('数据通道已打开');
  channel.send('Hello from A!');
};

channel.onmessage = (event) => {
  console.log('收到消息:', event.data);
};

channel.onclose = () => {
  console.log('数据通道已关闭');
};

// 方式二：被动接收方
pc.ondatachannel = (event) => {
  const channel = event.channel;
  console.log('收到数据通道:', channel.label);

  channel.onopen = () => {
    console.log('通道就绪');
  };

  channel.onmessage = (event) => {
    console.log('收到消息:', event.data);
  };
};
```

### 可靠性配置

DataChannel 的可靠性通过创建时的参数控制：

```javascript
// 完全可靠、有序（默认，类似 TCP）
const reliableOrdered = pc.createDataChannel('reliable', {
  ordered: true
});

// 可靠但无序（重传但不排序）
const reliableUnordered = pc.createDataChannel('reliable-unordered', {
  ordered: false,
  maxRetransmits: 3  // 最多重传 3 次
});

// 不可靠（适合实时数据，丢了就丢了）
const unreliable = pc.createDataChannel('unreliable', {
  ordered: false,
  maxPacketLifeTime: 200  // 200ms 后不再重传
});

// 不可靠、有序（适合实时状态同步）
const unreliableOrdered = pc.createDataChannel('unreliable-ordered', {
  ordered: true,
  maxPacketLifeTime: 200
});
```

可靠性选择指南：

```
┌─────────────────────┬─────────┬─────────┬──────────────────┐
│ 场景                 │ ordered │ 重传    │ 配置              │
├─────────────────────┼─────────┼─────────┼──────────────────┤
│ 聊天消息             │ ✓       │ ✓       │ ordered: true    │
│ 文件传输             │ ✓       │ ✓       │ ordered: true    │
│ 游戏状态同步         │ ✗       │ ✗       │ maxPacketLifeTime│
│ 光标位置             │ ✗       │ ✗       │ maxPacketLifeTime│
│ 信令消息             │ ✓       │ ✓       │ ordered: true    │
└─────────────────────┴─────────┴─────────┴──────────────────┘
```

## 文件传输

### 核心挑战

DataChannel 的消息大小有限制（通常 256KB 左右），大文件必须分块传输。同时需要处理进度跟踪、断点续传、接收端重组等问题。

### 发送端实现

```javascript
class FileSender {
  constructor(channel) {
    this.channel = channel;
    this.chunkSize = 16384; // 16KB 分块
  }

  async sendFile(file) {
    const metadata = {
      type: 'file-meta',
      name: file.name,
      size: file.size,
      mimeType: file.type,
      totalChunks: Math.ceil(file.size / this.chunkSize)
    };

    // 发送文件元数据
    this.channel.send(JSON.stringify(metadata));

    // 分块读取并发送
    const reader = file.stream().getReader();
    let chunkIndex = 0;
    let sentBytes = 0;

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      // 等待缓冲区清空（背压控制）
      if (this.channel.bufferedAmount > 65536) {
        await this.waitForBuffer();
      }

      this.channel.send(value);
      sentBytes += value.byteLength;
      chunkIndex++;

      // 报告进度
      this.onProgress?.({
        sent: sentBytes,
        total: file.size,
        percent: Math.round((sentBytes / file.size) * 100)
      });
    }

    // 发送完成标记
    this.channel.send(JSON.stringify({ type: 'file-end', name: file.name }));
  }

  waitForBuffer() {
    return new Promise(resolve => {
      const check = () => {
        if (this.channel.bufferedAmount <= 32768) {
          resolve();
        } else {
          setTimeout(check, 50);
        }
      };
      check();
    });
  }
}
```

### 接收端实现

```javascript
class FileReceiver {
  constructor() {
    this.receiving = null;
    this.chunks = [];
    this.receivedBytes = 0;
  }

  handleMessage(data) {
    // 文本消息：可能是元数据或结束标记
    if (typeof data === 'string') {
      const message = JSON.parse(data);

      if (message.type === 'file-meta') {
        this.receiving = {
          name: message.name,
          size: message.size,
          mimeType: message.mimeType,
          totalChunks: message.totalChunks
        };
        this.chunks = [];
        this.receivedBytes = 0;
        return;
      }

      if (message.type === 'file-end') {
        this.assembleFile();
        return;
      }
    }

    // 二进制数据：文件块
    if (data instanceof ArrayBuffer) {
      this.chunks.push(data);
      this.receivedBytes += data.byteLength;

      this.onProgress?.({
        received: this.receivedBytes,
        total: this.receiving.size,
        percent: Math.round((this.receivedBytes / this.receiving.size) * 100)
      });
    }
  }

  assembleFile() {
    const blob = new Blob(this.chunks, { type: this.receiving.mimeType });
    const url = URL.createObjectURL(blob);

    // 触发下载
    const a = document.createElement('a');
    a.href = url;
    a.download = this.receiving.name;
    a.click();

    // 清理
    setTimeout(() => URL.revokeObjectURL(url), 60000);
    this.chunks = [];
    this.receiving = null;

    this.onComplete?.({ name: this.receiving?.name, size: this.receivedBytes });
  }
}
```

### 完整的文件传输类

```javascript
class FileTransfer {
  constructor(channel) {
    this.channel = channel;
    this.sender = new FileSender(channel);
    this.receiver = new FileReceiver();

    channel.onmessage = (event) => {
      this.receiver.handleMessage(event.data);
    };

    this.sender.onProgress = (progress) => {
      this.onSendProgress?.(progress);
    };

    this.receiver.onProgress = (progress) => {
      this.onReceiveProgress?.(progress);
    };

    this.receiver.onComplete = (info) => {
      this.onFileReceived?.(info);
    };
  }

  async send(file) {
    return this.sender.sendFile(file);
  }
}

// 使用
const channel = pc.createDataChannel('file-transfer', { ordered: true });
const transfer = new FileTransfer(channel);

transfer.onSendProgress = (p) => {
  console.log(`发送进度: ${p.percent}%`);
};

transfer.onReceiveProgress = (p) => {
  console.log(`接收进度: ${p.percent}%`);
};

transfer.onFileReceived = (info) => {
  console.log('文件接收完成:', info.name);
};

// 发送文件
const fileInput = document.getElementById('fileInput');
fileInput.addEventListener('change', async (e) => {
  const file = e.target.files[0];
  await transfer.send(file);
});
```

## 实时聊天消息

### 消息协议设计

```javascript
// 消息类型定义
const MessageTypes = {
  TEXT: 'text',
  SYSTEM: 'system',
  TYPING: 'typing',
  CURSOR: 'cursor',
  REACTION: 'reaction'
};

class ChatChannel {
  constructor(channel) {
    this.channel = channel;
    this.messageHandlers = new Map();
    this.messageHistory = [];

    channel.onmessage = (event) => {
      const message = JSON.parse(event.data);
      this.handleMessage(message);
    };
  }

  sendText(text, senderInfo) {
    const message = {
      type: MessageTypes.TEXT,
      id: this.generateId(),
      text,
      sender: senderInfo,
      timestamp: Date.now()
    };

    this.channel.send(JSON.stringify(message));
    this.addToHistory(message);
    return message;
  }

  sendTyping(isTyping, senderInfo) {
    this.channel.send(JSON.stringify({
      type: MessageTypes.TYPING,
      sender: senderInfo,
      isTyping
    }));
  }

  sendReaction(emoji, messageId, senderInfo) {
    this.channel.send(JSON.stringify({
      type: MessageTypes.REACTION,
      emoji,
      messageId,
      sender: senderInfo
    }));
  }

  sendSystem(text) {
    this.channel.send(JSON.stringify({
      type: MessageTypes.SYSTEM,
      text,
      timestamp: Date.now()
    }));
  }

  handleMessage(message) {
    switch (message.type) {
      case MessageTypes.TEXT:
        this.addToHistory(message);
        this.emit('message', message);
        break;
      case MessageTypes.TYPING:
        this.emit('typing', message);
        break;
      case MessageTypes.REACTION:
        this.emit('reaction', message);
        break;
      case MessageTypes.SYSTEM:
        this.emit('system', message);
        break;
    }
  }

  addToHistory(message) {
    this.messageHistory.push(message);
    if (this.messageHistory.length > 500) {
      this.messageHistory.shift();
    }
  }

  generateId() {
    return Date.now().toString(36) + Math.random().toString(36).substr(2);
  }

  on(event, handler) {
    if (!this.messageHandlers.has(event)) {
      this.messageHandlers.set(event, []);
    }
    this.messageHandlers.get(event).push(handler);
  }

  emit(event, data) {
    const handlers = this.messageHandlers.get(event) || [];
    handlers.forEach(h => h(data));
  }
}
```

### 实时光标同步

协作场景中，同步用户光标位置很常见：

```javascript
class CursorSync {
  constructor(channel, container) {
    this.channel = channel;
    this.container = container;
    this.cursors = new Map(); // userId -> cursorElement
    this.throttleTimer = null;

    channel.onmessage = (event) => {
      const data = JSON.parse(event.data);
      if (data.type === 'cursor') {
        this.updateCursor(data);
      }
    };
  }

  // 发送自己的光标位置（节流）
  sendPosition(x, y, userId, color) {
    if (this.throttleTimer) return;

    this.throttleTimer = setTimeout(() => {
      this.throttleTimer = null;
    }, 50); // 每 50ms 最多发送一次

    this.channel.send(JSON.stringify({
      type: 'cursor',
      userId,
      x,
      y,
      color
    }));
  }

  updateCursor(data) {
    let cursor = this.cursors.get(data.userId);

    if (!cursor) {
      cursor = document.createElement('div');
      cursor.className = 'remote-cursor';
      cursor.innerHTML = `
        <svg width="16" height="16" viewBox="0 0 16 16">
          <path d="M0 0L16 12L8 12L12 16L8 16L4 12L0 12Z"
                fill="${data.color}" stroke="white" stroke-width="1"/>
        </svg>
        <span class="cursor-label">${data.userId}</span>
      `;
      cursor.style.position = 'absolute';
      cursor.style.pointerEvents = 'none';
      this.container.appendChild(cursor);
      this.cursors.set(data.userId, cursor);
    }

    cursor.style.left = data.x + 'px';
    cursor.style.top = data.y + 'px';
    cursor.style.display = 'block';

    // 超过 3 秒没更新则隐藏
    clearTimeout(cursor.hideTimer);
    cursor.hideTimer = setTimeout(() => {
      cursor.style.display = 'none';
    }, 3000);
  }

  removeCursor(userId) {
    const cursor = this.cursors.get(userId);
    if (cursor) {
      cursor.remove();
      this.cursors.delete(userId);
    }
  }
}
```

## SCTP 协议

DataChannel 底层使用 SCTP（Stream Control Transmission Protocol）协议，运行在 DTLS 之上。

### SCTP 的特性

```
SCTP vs TCP vs UDP:
┌──────────────────┬───────┬───────┬───────┐
│ 特性              │ TCP   │ UDP   │ SCTP  │
├──────────────────┼───────┼───────┼───────┤
│ 可靠性            │ ✓     │ ✗     │ 可选  │
│ 有序性            │ ✓     │ ✗     │ 可选  │
│ 多流              │ ✗     │ ✗     │ ✓     │
│ 消息边界          │ ✗     │ ✓     │ ✓     │
│ 多宿主            │ ✗     │ ✗     │ ✓     │
└──────────────────┴───────┴───────┴───────┘
```

SCTP 的关键优势：
- **多流（Multi-streaming）**：一个 SCTP 连接可以包含多个独立的流，流之间互不阻塞
- **消息边界**：保留消息边界，不需要像 TCP 那样处理粘包
- **可选可靠性**：可以配置每个流的重传策略

### DataChannel 与 SCTP 流的映射

```javascript
// 创建多个 DataChannel，每个对应一个 SCTP 流
const chatChannel = pc.createDataChannel('chat', {
  ordered: true,
  negotiated: true,
  id: 0  // 显式指定 SCTP 流 ID
});

const fileChannel = pc.createDataChannel('file', {
  ordered: true,
  negotiated: true,
  id: 1
});

const cursorChannel = pc.createDataChannel('cursor', {
  ordered: false,
  maxPacketLifeTime: 100,
  negotiated: true,
  id: 2
});

// 三个通道互不阻塞
// 文件传输不会影响光标同步的实时性
```

`negotiated: true` 表示双方都预先创建了这个通道，不需要通过 offer/answer 协商。

## 多 DataChannel 管理

```javascript
class DataChannelManager {
  constructor(pc) {
    this.pc = pc;
    this.channels = new Map();
  }

  createChannel(name, options = {}) {
    const channel = this.pc.createDataChannel(name, options);

    const wrapper = {
      channel,
      name,
      ready: false,
      messageQueue: [],
      handlers: new Map()
    };

    channel.onopen = () => {
      wrapper.ready = true;
      // 发送队列中的消息
      while (wrapper.messageQueue.length > 0) {
        const msg = wrapper.messageQueue.shift();
        channel.send(msg);
      }
    };

    channel.onmessage = (event) => {
      const handlers = wrapper.handlers.get('message') || [];
      handlers.forEach(h => h(event.data));
    };

    channel.onclose = () => {
      wrapper.ready = false;
    };

    channel.onerror = (error) => {
      const handlers = wrapper.handlers.get('error') || [];
      handlers.forEach(h => h(error));
    };

    this.channels.set(name, wrapper);
    return wrapper;
  }

  send(channelName, data) {
    const wrapper = this.channels.get(channelName);
    if (!wrapper) throw new Error(`通道 ${channelName} 不存在`);

    if (wrapper.ready) {
      wrapper.channel.send(data);
    } else {
      wrapper.messageQueue.push(data);
    }
  }

  on(channelName, event, handler) {
    const wrapper = this.channels.get(channelName);
    if (!wrapper) throw new Error(`通道 ${channelName} 不存在`);

    if (!wrapper.handlers.has(event)) {
      wrapper.handlers.set(event, []);
    }
    wrapper.handlers.get(event).push(handler);
  }

  close(channelName) {
    const wrapper = this.channels.get(channelName);
    if (wrapper) {
      wrapper.channel.close();
      this.channels.delete(channelName);
    }
  }

  closeAll() {
    for (const [name, wrapper] of this.channels) {
      wrapper.channel.close();
    }
    this.channels.clear();
  }

  getStats() {
    const stats = {};
    for (const [name, wrapper] of this.channels) {
      stats[name] = {
        ready: wrapper.ready,
        bufferedAmount: wrapper.channel.bufferedAmount,
        bufferedAmountLowThreshold: wrapper.channel.bufferedAmountLowThreshold
      };
    }
    return stats;
  }
}
```

## 常见误区

### 误区一：DataChannel 有消息大小限制

DataChannel 确实有单条消息大小限制（通常 256KB），但这是可以通过分块传输解决的。实际上，SCTP 协议支持最大 65535 字节的分片，DataChannel 会自动处理分片重组。开发者需要关心的是：大消息会占用缓冲区，需要做背压控制。

### 误区二：DataChannel 和 WebSocket 差不多

虽然 API 相似，但 DataChannel 有本质区别：
- DataChannel 是点对点的，不经过服务器
- DataChannel 支持二进制传输，WebSocket 默认文本
- DataChannel 可以配置可靠性，WebSocket 只有可靠模式
- DataChannel 和音视频共享连接，不需要额外建立连接

### 误区三：ordered: false 就是 UDP

`ordered: false` 只是不保证顺序，但仍然可能是可靠的（取决于 maxRetransmits 配置）。要实现真正的不可靠传输，必须设置 `maxPacketLifeTime` 或 `maxRetransmits`。

### 误区四：DataChannel 不需要关心流量控制

SCTP 有内置的流控机制，但在应用层你仍然需要做背压控制。检查 `channel.bufferedAmount`，当缓冲区过大时暂停发送：

```javascript
function sendWithBackpressure(channel, data) {
  if (channel.bufferedAmount > 65536) {
    return new Promise(resolve => {
      channel.onbufferedamountlow = () => {
        channel.send(data);
        resolve();
      };
      channel.bufferedAmountLowThreshold = 32768;
    });
  }
  channel.send(data);
  return Promise.resolve();
}
```

## 工程建议

1. **文件传输使用 binary 模式**。ArrayBuffer 比 base64 编码的字符串高效得多，减少约 33% 的数据量。

2. **不同类型的数据用不同的 DataChannel**。聊天消息、文件传输、光标同步分别创建通道，避免大文件传输阻塞实时消息。

3. **实现背压控制**。发送端监控 `bufferedAmount`，接收端控制处理速度。特别是文件传输场景，要避免发送过快导致内存溢出。

4. **DataChannel 和 WebSocket 互补**。DataChannel 用于浏览器之间的直接通信（文件、实时状态），WebSocket 用于浏览器和服务器之间的通信（信令、持久化存储）。

5. **处理通道断开**。DataChannel 会跟随 PeerConnection 的生命周期，连接断开时通道也会关闭。需要实现重连逻辑：

```javascript
pc.onconnectionstatechange = () => {
  if (pc.connectionState === 'disconnected') {
    // 通道可能需要重建
    setupDataChannels(pc);
  }
};
```

## 小结

DataChannel 是 WebRTC 的第三根支柱（音频、视频、数据），它提供了浏览器之间的任意数据传输能力。

核心要点：
- **可靠性可配置**：ordered/unordered、可靠/不可由，按场景选择
- **文件传输**：分块发送、背压控制、进度跟踪
- **多通道隔离**：不同类型的数据用不同通道，互不阻塞
- **SCTP 协议**：多流、消息边界、可选可靠性

DataChannel 让 WebRTC 从"视频通话工具"升级为"实时协作平台"。

## 参考答案

### 练习一

**思路**：文件拖拽用 DragEvent API，传输用分块 + 背压控制，进度通过已发送字节数计算。中断处理需要记录已发送的块数，支持从断点继续。

**答案**：

```javascript
class FileTransferApp {
  constructor(channel) {
    this.channel = channel;
    this.chunkSize = 16384;
    this.receiving = null;
    this.chunks = [];
    this.receivedBytes = 0;

    this.channel.onmessage = (event) => {
      this.handleMessage(event.data);
    };
  }

  // 设置拖拽区域
  setupDropZone(element) {
    element.addEventListener('dragover', (e) => {
      e.preventDefault();
      e.stopPropagation();
      element.classList.add('drag-over');
    });

    element.addEventListener('dragleave', (e) => {
      e.preventDefault();
      element.classList.remove('drag-over');
    });

    element.addEventListener('drop', (e) => {
      e.preventDefault();
      e.stopPropagation();
      element.classList.remove('drag-over');

      const files = e.dataTransfer.files;
      if (files.length > 0) {
        this.sendFile(files[0]);
      }
    });
  }

  async sendFile(file) {
    const metadata = {
      type: 'file-meta',
      name: file.name,
      size: file.size,
      mimeType: file.type || 'application/octet-stream'
    };

    this.channel.send(JSON.stringify(metadata));

    let offset = 0;
    const totalSize = file.size;

    while (offset < totalSize) {
      // 背压控制
      while (this.channel.bufferedAmount > 65536) {
        await new Promise(r => setTimeout(r, 50));
      }

      const chunk = file.slice(offset, offset + this.chunkSize);
      const buffer = await chunk.arrayBuffer();
      this.channel.send(buffer);

      offset += buffer.byteLength;

      this.onProgress?.({
        direction: 'send',
        sent: offset,
        total: totalSize,
        percent: Math.round((offset / totalSize) * 100)
      });
    }

    this.channel.send(JSON.stringify({
      type: 'file-end',
      name: file.name,
      checksum: await this.calculateChecksum(file)
    }));
  }

  handleMessage(data) {
    if (typeof data === 'string') {
      const msg = JSON.parse(data);

      if (msg.type === 'file-meta') {
        this.receiving = msg;
        this.chunks = [];
        this.receivedBytes = 0;
        this.onReceiveStart?.(msg);
        return;
      }

      if (msg.type === 'file-end') {
        this.assembleFile(msg);
        return;
      }
    }

    if (data instanceof ArrayBuffer && this.receiving) {
      this.chunks.push(data);
      this.receivedBytes += data.byteLength;

      this.onProgress?.({
        direction: 'receive',
        received: this.receivedBytes,
        total: this.receiving.size,
        percent: Math.round((this.receivedBytes / this.receiving.size) * 100)
      });
    }
  }

  assembleFile(endMsg) {
    const blob = new Blob(this.chunks, { type: this.receiving.mimeType });

    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = this.receiving.name;
    document.body.appendChild(a);
    a.click();
    document.body.removeChild(a);
    setTimeout(() => URL.revokeObjectURL(url), 60000);

    this.onComplete?.({
      name: this.receiving.name,
      size: this.receivedBytes,
      blob
    });

    this.chunks = [];
    this.receiving = null;
    this.receivedBytes = 0;
  }

  async calculateChecksum(file) {
    const buffer = await file.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
    return Array.from(new Uint8Array(hashBuffer))
      .map(b => b.toString(16).padStart(2, '0'))
      .join('');
  }
}

// 使用
const channel = pc.createDataChannel('file-transfer', { ordered: true });
const transfer = new FileTransferApp(channel);

transfer.setupDropZone(document.getElementById('dropZone'));

transfer.onProgress = (p) => {
  const bar = document.getElementById('progressBar');
  bar.style.width = p.percent + '%';
  bar.textContent = p.percent + '%';
};

transfer.onComplete = (info) => {
  console.log('文件接收完成:', info.name, info.size, 'bytes');
};
```

**要点**：
- `file.slice()` 可以分块读取文件，不需要一次加载到内存
- 背压控制防止缓冲区溢出
- SHA-256 校验和可以验证文件完整性

### 练习二

**思路**：创建专用的聊天 DataChannel，设计消息协议区分不同类型。输入状态用节流发送，避免频繁触发。

**答案**：

```javascript
class ChatApp {
  constructor(channel, currentUserId) {
    this.channel = channel;
    this.userId = currentUserId;
    this.messages = [];
    this.typingUsers = new Map();
    this.handlers = new Map();

    this.channel.onmessage = (event) => {
      this.handleMessage(JSON.parse(event.data));
    };
  }

  sendMessage(text) {
    if (!text.trim()) return;

    const message = {
      type: 'chat',
      id: this.generateId(),
      userId: this.userId,
      text: text.trim(),
      timestamp: Date.now()
    };

    this.channel.send(JSON.stringify(message));
    this.messages.push(message);
    this.emit('newMessage', message);
    this.stopTyping();
  }

  sendTyping() {
    if (this._typingTimer) return;

    this.channel.send(JSON.stringify({
      type: 'typing',
      userId: this.userId,
      isTyping: true
    }));

    this._typingTimer = setTimeout(() => {
      this._typingTimer = null;
    }, 2000);

    // 自动停止输入状态
    clearTimeout(this._stopTypingTimer);
    this._stopTypingTimer = setTimeout(() => {
      this.stopTyping();
    }, 3000);
  }

  stopTyping() {
    clearTimeout(this._typingTimer);
    this._typingTimer = null;
    clearTimeout(this._stopTypingTimer);

    this.channel.send(JSON.stringify({
      type: 'typing',
      userId: this.userId,
      isTyping: false
    }));
  }

  sendSystemMessage(text) {
    const message = {
      type: 'system',
      text,
      timestamp: Date.now()
    };
    this.channel.send(JSON.stringify(message));
    this.messages.push(message);
    this.emit('newMessage', message);
  }

  handleMessage(msg) {
    switch (msg.type) {
      case 'chat':
        this.messages.push(msg);
        this.emit('newMessage', msg);
        break;

      case 'typing':
        if (msg.isTyping) {
          this.typingUsers.set(msg.userId, Date.now());
        } else {
          this.typingUsers.delete(msg.userId);
        }
        this.emit('typingUpdate', this.getTypingText());
        break;

      case 'system':
        this.messages.push(msg);
        this.emit('newMessage', msg);
        break;
    }
  }

  getTypingText() {
    const users = Array.from(this.typingUsers.keys());
    if (users.length === 0) return '';
    if (users.length === 1) return `${users[0]} 正在输入...`;
    return `${users.join('、')} 正在输入...`;
  }

  getHistory(limit = 50) {
    return this.messages.slice(-limit);
  }

  generateId() {
    return Date.now().toString(36) + Math.random().toString(36).substr(2, 6);
  }

  on(event, handler) {
    if (!this.handlers.has(event)) {
      this.handlers.set(event, []);
    }
    this.handlers.get(event).push(handler);
  }

  emit(event, data) {
    const handlers = this.handlers.get(event) || [];
    handlers.forEach(h => h(data));
  }
}

// 使用
const chatChannel = pc.createDataChannel('chat', { ordered: true });
const chat = new ChatApp(chatChannel, 'user-123');

```

**要点**：
- 输入状态需要节流，避免每个按键都发送消息
- 自动停止输入状态，防止用户停止输入后状态卡住
- 消息历史存储在内存中，大型应用应持久化到服务器
