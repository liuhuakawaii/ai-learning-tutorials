# Stage 4：实时通信

> 6 课时 | WebRTC 与会议系统

## 阶段概述

本阶段深入 WebRTC 技术栈，从信令协商到点对点通信，再到多方会议架构，学习实时音视频处理与数据通道，最终构建一个视频会议系统。

## 学习目标

- 理解 WebRTC 信令、ICE、STUN/TURN 机制
- 掌握点对点视频通话与屏幕共享
- 了解 SFU/MCU 多方会议架构
- 学会实时音视频处理（AI 降噪、虚拟背景）
- 掌握 DataChannel 数据传输
