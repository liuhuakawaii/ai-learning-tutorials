# 实时音视频处理

## 场景引入

视频通话已经不是新鲜事了。现在的用户期望更多：虚拟背景让自己在杂乱的房间里也能体面出镜，AI 降噪让键盘声和狗叫声不再打扰会议，美颜功能让人在镜头前更自信。

这些功能的共同特点是：**在音视频数据离开浏览器之前，对其进行实时处理**。这节课我们学习如何在 WebRTC 的媒体管道中插入自定义处理逻辑，实现降噪、虚拟背景和美颜。

## 学习目标

1. 掌握 MediaStreamTrack 的操作：克隆、替换、约束修改
2. 理解 Insertable Streams（编码变换）的原理和用法
3. 使用 Web Audio API + WASM 实现 AI 降噪
4. 使用 Canvas 实现虚拟背景
5. 实现基础的美颜处理

## MediaStreamTrack 操作

### 轨道的基本操作

MediaStreamTrack 是 WebRTC 中媒体流的基本单元。每个 Track 代表一路音频或视频。

```javascript
// 获取轨道
const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
const videoTrack = stream.getVideoTracks()[0];
const audioTrack = stream.getAudioTracks()[0];

// 克隆轨道（共享底层源）
const clonedTrack = videoTrack.clone();

// 暂停/恢复（通过 enabled 属性）
videoTrack.enabled = false; // 暂停
videoTrack.enabled = true;  // 恢复

// 获取约束
console.log(videoTrack.getConstraints());
console.log(videoTrack.getSettings());  // 实际生效的参数

// 动态修改约束
await videoTrack.applyConstraints({
  width: { ideal: 640 },
  height: { ideal: 480 },
  frameRate: { ideal: 15 }
});

// 停止轨道（释放摄像头/麦克风）
videoTrack.stop();
```

### 轨道替换

轨道替换是实现特效的核心机制：处理后的轨道替换原始轨道。

```javascript
// 在 PeerConnection 中替换轨道
const sender = pc.getSenders().find(s => s.track?.kind === 'video');
await sender.replaceTrack(processedVideoTrack);

// 替换不需要重新协商 SDP
// 远程端会自动接收新的轨道数据
```

## Insertable Streams：编码变换

Insertable Streams（也叫 Encoded Transform）允许你在编码之后、发送之前访问和修改媒体帧。这对于加密、水印、自定义编码非常有用。

### 使用方式

```javascript
// 获取编码后的流
const sender = pc.getSenders().find(s => s.track?.kind === 'video');
const encodedStream = sender.createEncodedStreams();

const readable = encodedStream.readable;   // 编码后的数据
const writable = encodedStream.writable;   // 处理后写回

// 创建变换管道
const transformStream = new TransformStream({
  transform(encodedFrame, controller) {
    // encodedFrame 是编码后的视频帧
    // 可以修改帧数据、添加元数据等
    controller.enqueue(encodedFrame);
  }
});

readable.pipeThrough(transformStream).pipeTo(writable);
```

### 接收端解码变换

```javascript
const receiver = pc.getReceivers().find(r => r.track.kind === 'video');
const encodedStream = receiver.createEncodedStreams();

const transformStream = new TransformStream({
  transform(encodedFrame, controller) {
    // 接收端可以读取发送端添加的元数据
    controller.enqueue(encodedFrame);
  }
});

encodedStream.readable
  .pipeThrough(transformStream)
  .pipeTo(encodedStream.writable);
```

### 帧级操作示例：添加时间戳水印

```javascript
const sender = pc.getSenders().find(s => s.track?.kind === 'video');
const { readable, writable } = sender.createEncodedStreams();

const transform = new TransformStream({
  transform(frame, controller) {
    // 在帧的 metadata 中添加时间戳
    const metadata = frame.getMetadata();
    metadata.customTimestamp = Date.now();
    frame.metadata = metadata;
    controller.enqueue(frame);
  }
});

readable.pipeThrough(transform).pipeTo(writable);
```

## AI 降噪：Web Audio + RNNoise

### Web Audio API 基础

Web Audio API 提供了强大的音频处理能力：

```javascript
// 创建音频上下文
const audioContext = new AudioContext({ sampleRate: 48000 });

// 从麦克风获取音频源
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const source = audioContext.createMediaStreamSource(stream);

// 创建处理器节点
const gainNode = audioContext.createGain();
gainNode.gain.value = 1.5; // 增加音量

// 连接音频图
source.connect(gainNode);
gainNode.connect(audioContext.destination);
```

### 使用 AudioWorklet 实现降噪

AudioWorklet 是在独立线程中运行的音频处理器，不会阻塞主线程：

```javascript
// noise-suppressor-processor.js（Worklet 文件）
class NoiseSuppressorProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this.isReady = false;
    this.wasmInstance = null;
    this.inputBuffer = new Float32Array(480);  // 10ms @ 48kHz
    this.outputBuffer = new Float32Array(480);
    this.port.onmessage = (event) => {
      if (event.data.type === 'wasm-module') {
        this.initWasm(event.data.module);
      }
    };
  }

  async initWasm(wasmBytes) {
    const module = await WebAssembly.instantiate(wasmBytes, {
      env: {
        memory: new WebAssembly.Memory({ initial: 256 }),
        rnnoise_process: () => {}
      }
    });
    this.wasmInstance = module.instance.exports;
    this.isReady = true;
  }

  process(inputs, outputs, parameters) {
    const input = inputs[0];
    const output = outputs[0];

    if (!input || !input[0] || !this.isReady) {
      return true;
    }

    const inputChannel = input[0];
    const outputChannel = output[0];

    // 将音频数据拷贝到 WASM 内存
    const wasmInput = new Float32Array(
      this.wasmInstance.memory.buffer,
      this.wasmInstance.get_input_ptr(),
      480
    );
    wasmInput.set(inputChannel.subarray(0, 480));

    // 调用降噪处理
    this.wasmInstance.process_frame(480);

    // 读取处理后的数据
    const wasmOutput = new Float32Array(
      this.wasmInstance.memory.buffer,
      this.wasmInstance.get_output_ptr(),
      480
    );
    outputChannel.set(wasmOutput);

    return true;
  }
}

registerProcessor('noise-suppressor', NoiseSuppressorProcessor);
```

主文件中加载 Worklet：

```javascript
async function setupNoiseSuppression(audioTrack) {
  const audioContext = new AudioContext({ sampleRate: 48000 });

  // 注册 Worklet
  await audioContext.audioWorklet.addModule('noise-suppressor-processor.js');

  // 创建处理节点
  const workletNode = new AudioWorkletNode(audioContext, 'noise-suppressor');

  // 加载 WASM 模块并发送给 Worklet
  const wasmResponse = await fetch('rnnoise.wasm');
  const wasmBytes = await wasmResponse.arrayBuffer();
  workletNode.port.postMessage({
    type: 'wasm-module',
    module: wasmBytes
  });

  // 创建音频图
  const source = audioContext.createMediaStreamSource(
    new MediaStream([audioTrack])
  );
  const destination = audioContext.createMediaStreamDestination();

  source.connect(workletNode);
  workletNode.connect(destination);

  // 返回处理后的音频轨道
  return destination.stream.getAudioTracks()[0];
}

// 使用：替换 PeerConnection 中的音频轨道
async function enableNoiseSuppression(pc) {
  const audioSender = pc.getSenders().find(s => s.track?.kind === 'audio');
  const originalTrack = audioSender.track;
  const processedTrack = await setupNoiseSuppression(originalTrack);
  await audioSender.replaceTrack(processedTrack);
}
```

## 虚拟背景：Canvas 分割

### 原理

虚拟背景的核心是**人像分割**：将画面中的人物和背景分离，然后替换背景。

```
原始帧 → 人像分割模型 → 前景 mask → 合成（前景 + 新背景）→ 输出
```

### 使用 BodyPix 实现

```javascript
import * as bodyPix from '@tensorflow-models/body-pix';

class VirtualBackground {
  constructor() {
    this.net = null;
    this.canvas = document.createElement('canvas');
    this.ctx = this.canvas.getContext('2d');
    this.backgroundImage = null;
    this.isRunning = false;
  }

  async init() {
    // 加载分割模型
    this.net = await bodyPix.load({
      architecture: 'MobileNetV1',
      outputStride: 16,
      multiplier: 0.75,
      quantBytes: 2
    });
  }

  async setBackground(imageUrl) {
    const img = new Image();
    img.crossOrigin = 'anonymous';
    await new Promise((resolve, reject) => {
      img.onload = resolve;
      img.onerror = reject;
      img.src = imageUrl;
    });
    this.backgroundImage = img;
  }

  async processFrame(videoElement) {
    // 获取人像分割结果
    const segmentation = await this.net.segmentPerson(videoElement, {
      flipHorizontal: false,
      internalResolution: 'medium',
      segmentationThreshold: 0.7
    });

    const { width, height } = videoElement;
    this.canvas.width = width;
    this.canvas.height = height;

    // 方式一：模糊背景
    this.drawBlurredBackground(videoElement, segmentation, width, height);

    // 方式二：替换为图片背景
    // this.drawImageBackground(videoElement, segmentation, width, height);

    return this.canvas;
  }

  drawBlurredBackground(videoElement, segmentation, width, height) {
    // 绘制模糊的背景
    this.ctx.filter = 'blur(10px)';
    this.ctx.drawImage(videoElement, 0, 0, width, height);
    this.ctx.filter = 'none';

    // 获取背景像素
    const backgroundPixels = this.ctx.getImageData(0, 0, width, height);

    // 绘制清晰的前景
    this.ctx.drawImage(videoElement, 0, 0, width, height);
    const foregroundPixels = this.ctx.getImageData(0, 0, width, height);

    // 用 mask 合成：背景用模糊的，前景用清晰的
    const mask = segmentation.data;
    for (let i = 0; i < mask.length; i++) {
      const pixelIndex = i * 4;
      if (mask[i] === 0) {
        // 背景像素：使用模糊版本
        foregroundPixels.data[pixelIndex] = backgroundPixels.data[pixelIndex];
        foregroundPixels.data[pixelIndex + 1] = backgroundPixels.data[pixelIndex + 1];
        foregroundPixels.data[pixelIndex + 2] = backgroundPixels.data[pixelIndex + 2];
      }
    }

    this.ctx.putImageData(foregroundPixels, 0, 0);
  }

  drawImageBackground(videoElement, segmentation, width, height) {
    // 绘制背景图片
    this.ctx.drawImage(this.backgroundImage, 0, 0, width, height);

    // 获取背景像素
    const bgPixels = this.ctx.getImageData(0, 0, width, height);

    // 绘制前景
    this.ctx.drawImage(videoElement, 0, 0, width, height);
    const fgPixels = this.ctx.getImageData(0, 0, width, height);

    // 合成
    const mask = segmentation.data;
    for (let i = 0; i < mask.length; i++) {
      if (mask[i] === 0) {
        const idx = i * 4;
        fgPixels.data[idx] = bgPixels.data[idx];
        fgPixels.data[idx + 1] = bgPixels.data[idx + 1];
        fgPixels.data[idx + 2] = bgPixels.data[idx + 2];
      }
    }

    this.ctx.putImageData(fgPixels, 0, 0);
  }

  getProcessedStream(videoTrack) {
    const video = document.createElement('video');
    video.srcObject = new MediaStream([videoTrack]);
    video.play();

    this.canvas.width = videoTrack.getSettings().width || 640;
    this.canvas.height = videoTrack.getSettings().height || 480;

    this.isRunning = true;

    const renderLoop = async () => {
      if (!this.isRunning) return;
      await this.processFrame(video);
      requestAnimationFrame(renderLoop);
    };
    renderLoop();

    return this.canvas.captureStream(30).getVideoTracks()[0];
  }

  stop() {
    this.isRunning = false;
  }
}
```

## 美颜处理

### Canvas 美颜

```javascript
class BeautyFilter {
  constructor() {
    this.canvas = document.createElement('canvas');
    this.ctx = this.canvas.getContext('2d');
    this.settings = {
      smoothness: 0.3,    // 磨皮强度 0-1
      brightness: 0.1,    // 亮度调整 0-1
      contrast: 0.05      // 对比度调整 0-1
    };
  }

  processFrame(videoElement) {
    const { width, height } = videoElement;
    this.canvas.width = width;
    this.canvas.height = height;

    // 绘制原始帧
    this.ctx.drawImage(videoElement, 0, 0, width, height);

    // 获取像素数据
    const imageData = this.ctx.getImageData(0, 0, width, height);
    const data = imageData.data;

    // 磨皮：简单的高斯模糊混合
    if (this.settings.smoothness > 0) {
      this.applySmoothing(data, width, height, this.settings.smoothness);
    }

    // 亮度和对比度调整
    this.adjustBrightnessContrast(
      data,
      this.settings.brightness,
      this.settings.contrast
    );

    this.ctx.putImageData(imageData, 0, 0);
    return this.canvas;
  }

  applySmoothing(data, width, height, strength) {
    const radius = Math.floor(strength * 5);
    const tempData = new Uint8ClampedArray(data);

    for (let y = radius; y < height - radius; y++) {
      for (let x = radius; x < width - radius; x++) {
        let r = 0, g = 0, b = 0, count = 0;

        for (let dy = -radius; dy <= radius; dy++) {
          for (let dx = -radius; dx <= radius; dx++) {
            const idx = ((y + dy) * width + (x + dx)) * 4;
            r += tempData[idx];
            g += tempData[idx + 1];
            b += tempData[idx + 2];
            count++;
          }
        }

        const idx = (y * width + x) * 4;
        const blend = strength;
        data[idx] = data[idx] * (1 - blend) + (r / count) * blend;
        data[idx + 1] = data[idx + 1] * (1 - blend) + (g / count) * blend;
        data[idx + 2] = data[idx + 2] * (1 - blend) + (b / count) * blend;
      }
    }
  }

  adjustBrightnessContrast(data, brightness, contrast) {
    const factor = (259 * (contrast * 255 + 255)) / (255 * (259 - contrast * 255));

    for (let i = 0; i < data.length; i += 4) {
      // 亮度
      data[i] += brightness * 255;
      data[i + 1] += brightness * 255;
      data[i + 2] += brightness * 255;

      // 对比度
      data[i] = factor * (data[i] - 128) + 128;
      data[i + 1] = factor * (data[i + 1] - 128) + 128;
      data[i + 2] = factor * (data[i + 2] - 128) + 128;
    }
  }

  getProcessedStream(videoTrack) {
    const video = document.createElement('video');
    video.srcObject = new MediaStream([videoTrack]);
    video.play();

    const settings = videoTrack.getSettings();
    this.canvas.width = settings.width || 640;
    this.canvas.height = settings.height || 480;

    const renderLoop = () => {
      this.processFrame(video);
      requestAnimationFrame(renderLoop);
    };
    renderLoop();

    return this.canvas.captureStream(30).getVideoTracks()[0];
  }
}
```

```javascript
class OptimizedProcessor {
  constructor(processWidth = 320, processHeight = 240) {
    this.processWidth = processWidth;
    this.processHeight = processHeight;
    this.outputCanvas = document.createElement('canvas');
    this.processCanvas = document.createElement('canvas');
    this.processCanvas.width = processWidth;
    this.processCanvas.height = processHeight;

  process(videoElement, outputWidth, outputHeight) {

    const outputCtx = this.outputCanvas.getContext('2d');

    // 在小尺寸上处理

    // 这里执行耗时的像素处理

    );

    this.outputCanvas.width = outputWidth;
    this.outputCanvas.height = outputHeight;
```

### 使用 WebGL 加速

```javascript
class WebGLProcessor {
  constructor() {
    this.canvas = document.createElement('canvas');
    this.gl = this.canvas.getContext('webgl2');
    this.initShaders();
  }

  initShaders() {
    const vertexShaderSource = `
      attribute vec2 a_position;
      attribute vec2 a_texCoord;
      varying vec2 v_texCoord;
      void main() {
        gl_Position = vec4(a_position, 0.0, 1.0);
        v_texCoord = a_texCoord;
      }
    `;

    const fragmentShaderSource = `
      precision mediump float;
      varying vec2 v_texCoord;
      uniform sampler2D u_image;
      uniform float u_brightness;
      uniform float u_smoothness;

      void main() {
        vec4 color = texture2D(u_image, v_texCoord);

        // 亮度调整
        color.rgb += u_brightness;

        // 简单柔化（采样周围像素）
        if (u_smoothness > 0.0) {
          vec2 texelSize = vec2(1.0) / vec2(textureSize(u_image, 0));
          vec4 sum = vec4(0.0);
          for (float x = -1.0; x <= 1.0; x += 1.0) {
            for (float y = -1.0; y <= 1.0; y += 1.0) {
              sum += texture2D(u_image, v_texCoord + vec2(x, y) * texelSize);
            }
          }
          vec4 blurred = sum / 9.0;
          color = mix(color, blurred, u_smoothness);
        }

        gl_FragColor = color;
      }
    `;

    this.program = this.createProgram(vertexShaderSource, fragmentShaderSource);
  }

  createProgram(vertexSrc, fragmentSrc) {
    const gl = this.gl;
    const vs = gl.createShader(gl.VERTEX_SHADER);
    gl.shaderSource(vs, vertexSrc);
    gl.compileShader(vs);

    const fs = gl.createShader(gl.FRAGMENT_SHADER);
    gl.shaderSource(fs, fragmentSrc);
    gl.compileShader(fs);

    const program = gl.createProgram();
    gl.attachShader(program, vs);
    gl.attachShader(program, fs);
    gl.linkProgram(program);

    return program;
  }

  process(videoElement, settings) {
    const gl = this.gl;
    const { width, height } = videoElement;

    this.canvas.width = width;
    this.canvas.height = height;
    gl.viewport(0, 0, width, height);

    gl.useProgram(this.program);

    // 上传视频帧为纹理
    const texture = gl.createTexture();
    gl.bindTexture(gl.TEXTURE_2D, texture);
    gl.texImage2D(
      gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA,
      gl.UNSIGNED_BYTE, videoElement
    );

    // 设置参数
    gl.uniform1f(
      gl.getUniformLocation(this.program, 'u_brightness'),
      settings.brightness || 0
    );
    gl.uniform1f(
      gl.getUniformLocation(this.program, 'u_smoothness'),
      settings.smoothness || 0
    );

    // 绘制
    gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);

    return this.canvas;
  }
}
```

## 常见误区

### 误区一：ML 处理会带来很大延迟

确实有延迟，但可以通过优化控制在可接受范围内：
- 降低处理分辨率（320x240 而非 1280x720）
- 使用 WebGL/WebGPU 加速
- 降低处理帧率（15fps 处理，30fps 输出）
- 使用 WASM 而非纯 JS

实际测试中，BodyPix 在中端手机上处理 320x240 的分割约需 20-30ms，完全能满足 15fps 的实时性。

### 误区二：Canvas 处理会阻塞主线章

是的，Canvas 2D 的像素操作在主线程执行。解决方案：
- 使用 OffscreenCanvas + Worker
- 使用 WebGL 处理
- 降低处理频率

### 误区三：replaceTrack 会导致画面卡顿

不会。replaceTrack 是原子操作，切换瞬间完成。但处理管线初始化时可能有短暂延迟，建议在切换前先预热处理管线。

## 工程建议

1. **处理分辨率和输出分辨率分离**。在低分辨率（如 320x240）上做 ML 分割，然后将 mask 放大到原始分辨率进行合成。这样既保证了处理速度，又不损失输出质量。

2. **提供降级方案**。不是所有设备都支持 ML 处理。根据设备性能自动降级：

```javascript
async function detectProcessingCapability() {
  const start = performance.now();
  const canvas = document.createElement('canvas');
  canvas.width = 320;
  canvas.height = 240;
  const ctx = canvas.getContext('2d');
  const imageData = ctx.createImageData(320, 240);

  // 模拟像素处理
  for (let i = 0; i < imageData.data.length; i += 4) {
    imageData.data[i] = 128;
  }
  ctx.putImageData(imageData, 0, 0);

  const elapsed = performance.now() - start;
  return {
    canProcess: elapsed < 16,
    pixelTime: elapsed,
    recommendedQuality: elapsed < 8 ? 'high' : elapsed < 16 ? 'medium' : 'low'
  };
}
```

3. **Web Audio 的音频处理要和视频处理分开**。音频处理用 AudioWorklet（独立线程），视频处理用 Canvas/WebGL（主线程或 Worker）。不要在同一个处理循环中混合处理。

4. **资源释放要及时**。ML 模型、Canvas、AudioContext 都占用大量内存。不用时要释放：

```javascript
function cleanup() {
  model?.dispose();
  audioContext?.close();
  canvas = null;
}
```

## 小结

实时音视频处理的核心机制：

- **轨道替换**：`replaceTrack` 是特效管线的入口，处理后的轨道替换原始轨道
- **Insertable Streams**：编码后的帧级操作，适合加密、水印等场景
- **音频处理**：Web Audio API + AudioWorklet，适合降噪、回声消除
- **视频处理**：Canvas 像素操作或 WebGL，适合虚拟背景、美颜

性能是实时处理的核心挑战。降低处理分辨率、使用硬件加速、合理的帧率控制是三大优化方向。

### 练习一

**思路**：使用 AudioWorklet 在独立线程中处理音频。核心是实现一个简单的噪声门限——频域中低于阈值的频率分量置零。

**答案**：

Worklet 处理器文件 `noise-gate-processor.js`：

```javascript
class NoiseGateProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this.threshold = 0.02;
    this.enabled = true;
    this.port.onmessage = (event) => {
      if (event.data.type === 'setThreshold') {
        this.threshold = event.data.value;
      } else if (event.data.type === 'setEnabled') {
        this.enabled = event.data.value;
      }
    };
  }

  process(inputs, outputs) {
    const input = inputs[0];
    const output = outputs[0];

    if (!input || !input[0]) return true;

    for (let channel = 0; channel < input.length; channel++) {
      const inputData = input[channel];
      const outputData = output[channel];

      if (!this.enabled) {
        outputData.set(inputData);
        continue;
      }

      for (let i = 0; i < inputData.length; i++) {
        const sample = inputData[i];
        if (Math.abs(sample) < this.threshold) {
          outputData[i] = 0;
        } else {
          outputData[i] = sample;
        }
      }
    }

    return true;
  }
}

registerProcessor('noise-gate', NoiseGateProcessor);
```

主文件：

```javascript
class NoiseSuppression {
  constructor() {
    this.audioContext = null;
    this.workletNode = null;
    this.source = null;
    this.destination = null;
    this.isEnabled = true;
  }

  async init(audioTrack) {
    this.audioContext = new AudioContext({ sampleRate: 48000 });
    await this.audioContext.audioWorklet.addModule('noise-gate-processor.js');

    this.workletNode = new AudioWorkletNode(this.audioContext, 'noise-gate');

    this.source = this.audioContext.createMediaStreamSource(
      new MediaStream([audioTrack])
    );
    this.destination = this.audioContext.createMediaStreamDestination();

    this.source.connect(this.workletNode);
    this.workletNode.connect(this.destination);

    // 监控处理延迟
    this.startLatencyMonitor();
  }

  getProcessedTrack() {
    return this.destination.stream.getAudioTracks()[0];
  }

  setThreshold(value) {
    this.workletNode.port.postMessage({
      type: 'setThreshold',
      value: Math.max(0, Math.min(1, value))
    });
  }

  toggle() {
    this.isEnabled = !this.isEnabled;
    this.workletNode.port.postMessage({
      type: 'setEnabled',
      value: this.isEnabled
    });
    return this.isEnabled;
  }

  startLatencyMonitor() {
    // 使用 AudioWorklet 的 currentTime 监控延迟
    let lastTime = this.audioContext.currentTime;
    setInterval(() => {
      const currentTime = this.audioContext.currentTime;
      const elapsed = currentTime - lastTime;
      lastTime = currentTime;
      // 简单的延迟估算
      console.log('音频处理延迟:', (elapsed * 1000).toFixed(2), 'ms');
    }, 1000);
  }

  destroy() {
    this.source?.disconnect();
    this.workletNode?.disconnect();
    this.audioContext?.close();
  }
}

// 使用
async function enableNoiseSuppression(pc) {
  const audioSender = pc.getSenders().find(s => s.track?.kind === 'audio');
  const originalTrack = audioSender.track;

  const ns = new NoiseSuppression();
  await ns.init(originalTrack);

  const processedTrack = ns.getProcessedTrack();
  await audioSender.replaceTrack(processedTrack);

  return ns;
}
```

**要点**：
- AudioWorklet 运行在独立线程，不阻塞主线程
- 噪声门限是最简单的降噪方案，生产环境建议用 RNNoise
- 处理延迟监控对调试很重要

### 练习二

**思路**：使用 BodyPix 进行人像分割，然后在 Canvas 上合成前景和背景。支持图片背景和模糊背景两种模式。

**答案**：

```javascript
class VirtualBackgroundProcessor {
  constructor() {
    this.net = null;
    this.canvas = document.createElement('canvas');
    this.ctx = this.canvas.getContext('2d', { willReadFrequently: true });
    this.bgCanvas = document.createElement('canvas');
    this.bgCtx = this.bgCanvas.getContext('2d');
    this.mode = 'blur'; // 'blur' | 'image' | 'none'
    this.bgImage = null;
    this.isRunning = false;
    this.lastMask = null;
  }

  async init() {
    const bodyPix = await import(
      'https://cdn.jsdelivr.net/npm/@tensorflow-models/body-pix'
    );
    this.net = await bodyPix.load({
      architecture: 'MobileNetV1',
      outputStride: 16,
      multiplier: 0.75,
      quantBytes: 2
    });
  }

  async loadImage(url) {
    return new Promise((resolve, reject) => {
      const img = new Image();
      img.crossOrigin = 'anonymous';
      img.onload = () => {
        this.bgImage = img;
        resolve();
      };
      img.onerror = reject;
      img.src = url;
    });
  }

  setMode(mode) {
    this.mode = mode;
  }

  async processFrame(video) {
    if (!this.net || !video.videoWidth) return;

    const width = video.videoWidth;
    const height = video.videoHeight;

    if (this.canvas.width !== width) {
      this.canvas.width = width;
      this.canvas.height = height;
      this.bgCanvas.width = width;
      this.bgCanvas.height = height;
    }

    // 获取分割结果
    const segmentation = await this.net.segmentPerson(video, {
      flipHorizontal: false,
      internalResolution: 'medium',
      segmentationThreshold: 0.7
    });

    this.lastMask = segmentation.data;

    // 绘制前景
    this.ctx.drawImage(video, 0, 0, width, height);
    const fgData = this.ctx.getImageData(0, 0, width, height);

    if (this.mode === 'blur') {
      // 模糊背景
      this.ctx.filter = 'blur(12px)';
      this.ctx.drawImage(video, 0, 0, width, height);
      this.ctx.filter = 'none';
      const bgData = this.ctx.getImageData(0, 0, width, height);

      for (let i = 0; i < this.lastMask.length; i++) {
        if (this.lastMask[i] === 0) {
          const idx = i * 4;
          fgData.data[idx] = bgData.data[idx];
          fgData.data[idx + 1] = bgData.data[idx + 1];
          fgData.data[idx + 2] = bgData.data[idx + 2];
        }
      }
    } else if (this.mode === 'image' && this.bgImage) {
      // 图片背景
      this.bgCtx.drawImage(this.bgImage, 0, 0, width, height);
      const bgData = this.bgCtx.getImageData(0, 0, width, height);

      for (let i = 0; i < this.lastMask.length; i++) {
        if (this.lastMask[i] === 0) {
          const idx = i * 4;
          fgData.data[idx] = bgData.data[idx];
          fgData.data[idx + 1] = bgData.data[idx + 1];
          fgData.data[idx + 2] = bgData.data[idx + 2];
        }
      }
    }

    this.ctx.putImageData(fgData, 0, 0);
  }

  getProcessedStream(videoTrack) {
    const video = document.createElement('video');
    video.srcObject = new MediaStream([videoTrack]);
    video.muted = true;
    video.play();

    const settings = videoTrack.getSettings();
    this.canvas.width = settings.width || 640;
    this.canvas.height = settings.height || 480;

    this.isRunning = true;

    const loop = async () => {
      if (!this.isRunning) return;
      await this.processFrame(video);
      requestAnimationFrame(loop);
    };
    loop();

    return this.canvas.captureStream(30).getVideoTracks()[0];
  }

  stop() {
    this.isRunning = false;
    this.net?.dispose();
  }
}

// 使用
const vb = new VirtualBackgroundProcessor();
await vb.init();
await vb.loadImage('https://example.com/office-bg.jpg');
vb.setMode('image');

const processedTrack = vb.getProcessedStream(originalVideoTrack);
const sender = pc.getSenders().find(s => s.track?.kind === 'video');
await sender.replaceTrack(processedTrack);
```

**要点**：
- 使用 `willReadFrequently` 选项优化频繁的像素读取
- 分割模型的 `internalResolution` 影响精度和速度
- mask 可以做边缘平滑处理，避免锯齿
