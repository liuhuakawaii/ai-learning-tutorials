# Stage 3：流媒体技术

> 6 课时 | 流媒体与直播

## 阶段概述

本阶段讲解 HLS/DASH 自适应流媒体协议，开发自定义播放器，了解 CDN 与 P2P 分发，掌握直播推流与低延迟技术，最终搭建一个完整直播平台。

## 学习目标

- 理解 HLS/DASH 自适应码率原理
- 掌握自定义视频播放器开发
- 了解视频 CDN 与 P2P 分发架构
- 学会 RTMP/SRT 推流与转码
- 掌握 WebRTC、LL-HLS 等低延迟方案
