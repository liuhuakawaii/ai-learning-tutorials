# 第二课：视频播放器开发

## 场景引入

你在 B 站看视频，按下空格暂停，按 `F` 键全屏，按 `→` 快进 5 秒，拖动进度条时显示缩略图预览。这些交互看起来简单，但背后是对 HTML5 Video API 的深度理解和大量边界情况的处理。

浏览器原生的 `<video controls>` 提供了基本的播放控件，但样式不可定制，交互行为在不同浏览器中不一致，功能也有限（没有画质切换、弹幕、倍速播放等）。所有主流视频平台——YouTube、B 站、Netflix——都选择自研播放器 UI。

本课将从 HTML5 Video 的事件模型开始，逐步构建一个功能完整的自定义播放器。

## 学习目标

完成本课学习后，你将能够：

1. 理解 HTML5 Video 的状态机和事件触发顺序
2. 实现自定义播放控件（播放/暂停、进度条、音量、全屏）
3. 处理键盘快捷键和画中画功能
4. 理解 MSE（Media Source Extensions）的基本工作原理
5. 正确处理播放器的各种异常状态

## HTML5 Video 基础

### Video 元素的核心属性

```javascript
const video = document.createElement('video');
video.src = 'video.mp4';

// 时间相关
video.currentTime;     // 当前播放位置（秒）
video.duration;        // 视频总时长（秒）
video.playbackRate;    // 播放速率（0.5, 1, 1.5, 2）
video.paused;          // 是否暂停
video.ended;           // 是否播放结束

// 缓冲相关
video.buffered;        // TimeRanges 对象，已缓冲的时间范围
video.readyState;      // 就绪状态（0-4）
video.networkState;    // 网络状态（0-3）

// 音量
video.volume;          // 音量（0.0 - 1.0）
video.muted;           // 是否静音

// 尺寸
video.videoWidth;      // 视频原始宽度
video.videoHeight;     // 视频原始高度
```

### readyState 详解

`readyState` 决定了播放器能做什么：

| 值 | 常量 | 含义 | 可执行操作 |
|----|------|------|-----------|
| 0 | HAVE_NOTHING | 没有数据 | 不能播放 |
| 1 | HAVE_METADATA | 有元数据 | 知道时长和尺寸 |
| 2 | HAVE_CURRENT_DATA | 当前帧可用 | 可以显示一帧 |
| 3 | HAVE_FUTURE_DATA | 未来几帧可用 | 可以短暂播放 |
| 4 | HAVE_ENOUGH_DATA | 数据充足 | 可以流畅播放 |

### 事件触发顺序

这是播放器开发中最容易踩坑的地方。不同浏览器的事件顺序存在差异，但一般遵循以下模式：

```
loadstart → loadedmetadata → loadeddata → canplay → canplaythrough
                         ↓
                    play → playing（首次播放）
                         ↓
                  timeupdate（持续触发，约 4次/秒）
                         ↓
                   pause / ended
```

加载失败时：

```
loadstart → error → abort（用户中断）/ stalled（下载停滞）
```

```javascript
// 监听完整生命周期
const events = [
  'loadstart', 'progress', 'suspend', 'abort', 'error',
  'emptied', 'stalled', 'loadedmetadata', 'loadeddata',
  'canplay', 'canplaythrough', 'playing', 'waiting',
  'seeking', 'seeked', 'ended', 'durationchange',
  'timeupdate', 'play', 'pause', 'ratechange', 'resize', 'volumechange'
];

events.forEach(event => {
  video.addEventListener(event, () => {
    console.log(`[Video Event] ${event} | readyState=${video.readyState}`);
  });
});
```

### 进度条实现

进度条需要处理三种交互：显示当前进度、点击跳转、拖拽跳转。

```javascript
const progressContainer = document.getElementById('progressContainer');
const progressPlayed = document.getElementById('progressPlayed');
const progressBuffered = document.getElementById('progressBuffered');
const progressHandle = document.getElementById('progressHandle');
const timeDisplay = document.getElementById('timeDisplay');

function formatTime(seconds) {
  const mins = Math.floor(seconds / 60);
  const secs = Math.floor(seconds % 60);
  return `${mins}:${secs.toString().padStart(2, '0')}`;
}

// 更新播放进度
video.addEventListener('timeupdate', () => {
  if (!video.duration) return;

  const percent = (video.currentTime / video.duration) * 100;
  progressPlayed.style.width = `${percent}%`;
  progressHandle.style.left = `${percent}%`;
  timeDisplay.textContent = `${formatTime(video.currentTime)} / ${formatTime(video.duration)}`;
});

// 更新缓冲进度
video.addEventListener('progress', () => {
  if (!video.duration || video.buffered.length === 0) return;

  // 取最后一个缓冲区的结束位置
  const bufferedEnd = video.buffered.end(video.buffered.length - 1);
  const percent = (bufferedEnd / video.duration) * 100;
  progressBuffered.style.width = `${percent}%`;
});

// 点击进度条跳转
progressContainer.addEventListener('click', (e) => {
  if (!video.duration) return;

  const rect = progressContainer.getBoundingClientRect();
  const percent = (e.clientX - rect.left) / rect.width;
  video.currentTime = percent * video.duration;
});

// 拖拽进度条
let isDragging = false;

progressContainer.addEventListener('mousedown', (e) => {
  isDragging = true;
  seekToPosition(e);
});

document.addEventListener('mousemove', (e) => {
  if (!isDragging) return;
  seekToPosition(e);
});

document.addEventListener('mouseup', () => {
  isDragging = false;
});

function seekToPosition(e) {
  const rect = progressContainer.getBoundingClientRect();
  let percent = (e.clientX - rect.left) / rect.width;
  percent = Math.max(0, Math.min(1, percent));

  progressPlayed.style.width = `${percent * 100}%`;
  progressHandle.style.left = `${percent * 100}%`;

  if (video.duration) {
    video.currentTime = percent * video.duration;
  }
}
```

## 快捷键

键盘快捷键是专业播放器的标配：

```javascript
document.addEventListener('keydown', (e) => {
  // 如果焦点在输入框中，不处理快捷键
  if (e.target.tagName === 'INPUT' || e.target.tagName === 'TEXTAREA') return;

  switch (e.key) {
    case ' ':
    case 'k':
      e.preventDefault();
      togglePlay();
      break;
    case 'ArrowLeft':
      e.preventDefault();
      video.currentTime = Math.max(0, video.currentTime - 5);
      break;
    case 'ArrowRight':
      e.preventDefault();
      video.currentTime = Math.min(video.duration, video.currentTime + 5);
      break;
    case 'ArrowUp':
      e.preventDefault();
      video.volume = Math.min(1, video.volume + 0.1);
      break;
    case 'ArrowDown':
      e.preventDefault();
      video.volume = Math.max(0, video.volume - 0.1);
      break;
    case 'f':
      e.preventDefault();
      if (document.fullscreenElement) {
        document.exitFullscreen();
      } else {
        player.requestFullscreen();
      }
      break;
    case 'm':
      e.preventDefault();
      video.muted = !video.muted;
      break;
    case 'j':
      e.preventDefault();
      video.currentTime = Math.max(0, video.currentTime - 10);
      break;
    case 'l':
      e.preventDefault();
      video.currentTime = Math.min(video.duration, video.currentTime + 10);
      break;
    case '0':
    case '1':
    case '2':
    case '3':
    case '4':
    case '5':
    case '6':
    case '7':
    case '8':
    case '9':
      e.preventDefault();
      video.currentTime = (parseInt(e.key) / 10) * video.duration;
      break;
  }
});
```

## MSE 与 SourceBuffer

### MSE 工作原理

MSE（Media Source Extensions）允许 JavaScript 直接向 `<video>` 元素喂数据，而不需要通过 `src` 属性加载完整文件。这是 hls.js、dash.js 等播放库的基础。

```
传统方式：
  video.src = 'video.mp4'  → 浏览器自己下载和解码

MSE 方式：
  MediaSource → SourceBuffer → video 元素
       ↑
  JS 手动 fetch 分片数据并 append 到 SourceBuffer
```

### MSE 基本用法

```javascript
const mediaSource = new MediaSource();
video.src = URL.createObjectURL(mediaSource);

mediaSource.addEventListener('sourceopen', () => {
  // 创建 SourceBuffer，指定编解码类型
  const sourceBuffer = mediaSource.addSourceBuffer(
    'video/mp4; codecs="avc1.42E01E, mp4a.40.2"'
  );

  // 加载初始化段（包含 moov box）
  fetch('init.mp4')
    .then(response => response.arrayBuffer())
    .then(initData => {
      sourceBuffer.addEventListener('updateend', () => {
        // 初始化段添加完成后，加载第一个媒体段
        loadSegment(0);
      }, { once: true });
      sourceBuffer.appendBuffer(initData);
    });
});

async function loadSegment(index) {
  const response = await fetch(`segment_${index}.m4s`);
  const data = await response.arrayBuffer();

  const sourceBuffer = mediaSource.sourceBuffers[0];

  if (sourceBuffer.updating) {
    // SourceBuffer 正在更新，等待完成
    sourceBuffer.addEventListener('updateend', () => {
      sourceBuffer.appendBuffer(data);
    }, { once: true });
  } else {
    sourceBuffer.appendBuffer(data);
  }
}
```

### 管理缓冲区

SourceBuffer 的缓冲区需要定期清理，否则内存会持续增长：

```javascript
function cleanBuffer(sourceBuffer, keepBehind) {
  if (sourceBuffer.updating || sourceBuffer.buffered.length === 0) return;

  const currentTime = video.currentTime;
  const buffered = sourceBuffer.buffered;

  for (let i = 0; i < buffered.length; i++) {
    const start = buffered.start(i);
    const end = buffered.end(i);

    // 清理播放位置之前的数据，保留最近 keepBehind 秒
    if (end < currentTime - keepBehind) {
      sourceBuffer.remove(start, end);
      break;
    }
  }
}

// 每 30 秒清理一次缓冲区
setInterval(() => {
  const sourceBuffer = mediaSource.sourceBuffers[0];
  cleanBuffer(sourceBuffer, 30);
}, 30000);
```

## 常见误区

### 误区一：事件触发顺序在所有浏览器中一致

不同浏览器对 Video 事件的触发顺序有细微差异。例如，某些浏览器在 `loadeddata` 之前触发 `canplay`，某些则相反。不要依赖特定顺序，应该根据 `readyState` 判断当前状态。

### 误区二：`timeupdate` 事件精确到每帧

`timeupdate` 事件的触发频率由浏览器决定，通常是每秒 4 次（每 250ms），不同浏览器可能不同。不要用它来做精确的帧级同步。

### 误区三：`video.duration` 总是立即可用

对于渐进式下载的视频，`duration` 在 `loadedmetadata` 事件后才可用。对于 MSE 流，`duration` 可能在 `MediaSource.endOfStream()` 之前为 `Infinity`。

### 误区四：`video.play()` 总是成功的

现代浏览器限制自动播放，`play()` 返回 Promise，可能被拒绝。必须处理 `catch` 分支，通常需要用户交互后才能播放。

## 工程建议

1. **始终监听 `waiting` 和 `canplay` 事件**：在 `waiting` 时显示 loading 指示器，在 `canplay` 时隐藏
2. **使用 `requestAnimationFrame` 更新 UI**：比 `timeupdate` 更流畅，适合进度条动画
3. **防抖 `seeking` 操作**：拖动进度条时不要每次都 seek，使用防抖减少跳转次数
4. **处理 `stalled` 事件**：网络卡顿时给用户反馈，而不是静默等待
5. **使用 `playsinline` 属性**：在移动端防止视频自动全屏
6. **清理 MSE 资源**：页面卸载时调用 `mediaSource.endOfStream()` 释放资源

### 练习二

**思路**：创建 `SegmentLoader` 类管理分片加载，维护加载队列，根据播放位置决定何时加载下一个分片。

**答案**：

```javascript
class MSESegmentLoader {
  constructor(video, initUrl, segmentUrls) {
    this.video = video;
    this.initUrl = initUrl;
    this.segmentUrls = segmentUrls;
    this.currentIndex = 0;
    this.mediaSource = null;
    this.sourceBuffer = null;
    this.pendingBuffers = [];
    this.isAppending = false;

    this._init();
  }

  _init() {
    this.mediaSource = new MediaSource();
    this.video.src = URL.createObjectURL(this.mediaSource);

    this.mediaSource.addEventListener('sourceopen', () => {
      this._loadInitSegment();
    });
  }

  async _loadInitSegment() {
    const response = await fetch(this.initUrl);
    const data = await response.arrayBuffer();

    this.sourceBuffer = this.mediaSource.addSourceBuffer(
      'video/mp4; codecs="avc1.42E01E, mp4a.40.2"'
    );

    this.sourceBuffer.addEventListener('updateend', () => {
      this.isAppending = false;
      this._processQueue();
      this.video.play().catch(() => {});
    });

    this._appendBuffer(data);

    // 开始监控播放位置
    this._startMonitoring();
  }

  _appendBuffer(data) {
    if (this.sourceBuffer.updating) {
      this.pendingBuffers.push(data);
    } else {
      this.isAppending = true;
      this.sourceBuffer.appendBuffer(data);
    }
  }

  _processQueue() {
    if (this.pendingBuffers.length > 0 && !this.sourceBuffer.updating) {
      const next = this.pendingBuffers.shift();
      this.isAppending = true;
      this.sourceBuffer.appendBuffer(next);
    }
  }

  async _loadSegment(index) {
    if (index >= this.segmentUrls.length) {
      this.mediaSource.endOfStream();
      return;
    }

    const response = await fetch(this.segmentUrls[index]);
    const data = await response.arrayBuffer();
    this._appendBuffer(data);
    this.currentIndex = index + 1;
  }

  _startMonitoring() {
    const checkInterval = setInterval(() => {
      if (this.video.ended) {
        clearInterval(checkInterval);
        return;
      }

      // 计算缓冲区尾部
      let bufferEnd = 0;
      const buffered = this.video.buffered;
      for (let i = 0; i < buffered.length; i++) {
        if (buffered.end(i) > bufferEnd) {
          bufferEnd = buffered.end(i);
        }
      }

      // 缓冲区不足 5 秒时加载下一个分片
      const bufferAhead = bufferEnd - this.video.currentTime;
      if (bufferAhead < 5 && this.currentIndex < this.segmentUrls.length) {
        this._loadSegment(this.currentIndex);
      }
    }, 1000);
  }
}

// 使用
const loader = new MSESegmentLoader(
  document.getElementById('video'),
  'init.mp4',
  ['seg_0.m4s', 'seg_1.m4s', 'seg_2.m4s', 'seg_3.m4s', 'seg_4.m4s']
);
```

**要点**：
- `pendingBuffers` 队列处理 SourceBuffer 正在更新时的追加请求
- 缓冲区水位监控确保在缓冲区不足时提前加载，避免播放卡顿
- 所有分片加载完毕后调用 `endOfStream()` 通知 MediaSource

**思路**：使用 CSS 变量定义颜色方案，通过 JavaScript 切换 `data-theme` 属性。

**答案**：


```javascript
const themeBtn = document.getElementById('themeBtn');
const player = document.getElementById('player');

themeBtn.addEventListener('click', () => {
  const current = player.getAttribute('data-theme');
  const next = current === 'light' ? 'dark' : 'light';
  player.setAttribute('data-theme', next);
  themeBtn.textContent = next === 'light' ? '🌙' : '☀️';
  localStorage.setItem('player-theme', next);
});

// 恢复保存的主题
const savedTheme = localStorage.getItem('player-theme') || 'dark';
player.setAttribute('data-theme', savedTheme);
themeBtn.textContent = savedTheme === 'light' ? '🌙' : '☀️';
```

**要点**：
- CSS 变量使主题切换只需改变一个属性，所有相关颜色自动更新
- 使用 `localStorage` 保存用户偏好，下次打开时恢复
- 默认深色主题，符合视频播放器的常见设计
