# 第五课：字幕与水印

## 场景引入

你在一个视频平台上看到的每一条字幕、每一个角落里的台标，背后都涉及字幕渲染和水印技术。字幕让观众理解不同语言的内容，水印保护创作者的版权。

在浏览器端实现字幕和水印，需要解决几个核心问题：如何解析字幕文件的时间轴、如何在视频上精确渲染文字、如何实现动态水印、以及如何将字幕烧录到视频中。

## 学习目标

1. 掌握 SRT 字幕格式的解析和渲染
2. 了解 ASS/SSA 格式的高级样式能力
3. 理解 WebVTT 的浏览器原生支持机制
4. 学会实现 Canvas 动态水印
5. 掌握使用 FFmpeg.wasm 烧录字幕到视频的方法

## SRT 格式

SRT（SubRip Text）是最简单的字幕格式，几乎所有的字幕工具都支持。其结构由序号、时间轴和字幕文本组成。

### SRT 文件结构

```
1
00:00:01,000 --> 00:00:04,000
这是第一行字幕

2
00:00:05,500 --> 00:00:08,200
这是第二行字幕
可以有多行

3
00:00:10,000 --> 00:00:13,000
第三行字幕
```

### SRT 解析器

```javascript
function parseSRT(srtContent) {
  const blocks = srtContent.trim().split(/\n\s*\n/);
  const subtitles = [];

  for (const block of blocks) {
    const lines = block.trim().split('\n');
    if (lines.length < 3) continue;

    const index = parseInt(lines[0], 10);
    const timeMatch = lines[1].match(
      /(\d{2}):(\d{2}):(\d{2}),(\d{3})\s*-->\s*(\d{2}):(\d{2}):(\d{2}),(\d{3})/
    );

    if (!timeMatch) continue;

    const startTime = parseTime(timeMatch[1], timeMatch[2], timeMatch[3], timeMatch[4]);
    const endTime = parseTime(timeMatch[5], timeMatch[6], timeMatch[7], timeMatch[8]);
    const text = lines.slice(2).join('\n');

    subtitles.push({ index, startTime, endTime, text });
  }

  return subtitles;
}

function parseTime(hours, minutes, seconds, milliseconds) {
  return (
    parseInt(hours) * 3600 +
    parseInt(minutes) * 60 +
    parseInt(seconds) +
    parseInt(milliseconds) / 1000
  );
}
```

### SRT 时间轴查找

```javascript
function getSubtitleAtTime(subtitles, currentTime) {
  return subtitles.find(
    sub => currentTime >= sub.startTime && currentTime <= sub.endTime
  ) || null;
}

function getSubtitlesInRange(subtitles, startTime, endTime) {
  return subtitles.filter(
    sub => sub.endTime > startTime && sub.startTime < endTime
  );
}
```

## ASS/SSA 格式

ASS（Advanced SubStation Alpha）是功能更强大的字幕格式，支持丰富的样式定义：字体、颜色、位置、旋转、动画等。

### ASS 文件结构

```ini
[Script Info]
Title: Example
ScriptType: v4.00+
PlayResX: 1920
PlayResY: 1080

[V4+ Styles]
Format: Name,Fontname,Fontsize,PrimaryColour,SecondaryColour,OutlineColour,Bold,Italic,Underline,StrikeOut,ScaleX,ScaleY,Spacing,Angle,BorderStyle,Outline,Shadow,Alignment,MarginL,MarginR,MarginV,Encoding
Style: Default,Microsoft YaHei,48,&H00FFFFFF,&H000000FF,&H00000000,0,0,0,0,100,100,0,0,1,2,1,2,10,10,30,1
Style: Title,Arial,72,&H0000FFFF,&H000000FF,&H00000000,-1,0,0,0,100,100,0,0,1,3,2,8,10,10,30,1

[Events]
Format: Layer,Start,End,Style,Name,MarginL,MarginR,MarginV,Effect,Text
Dialogue: 0,0:00:01.00,0:00:04.00,Default,,0,0,0,,这是默认样式的字幕
Dialogue: 0,0:00:05.00,0:00:08.00,Title,,0,0,0,,{\pos(960,100)}这是居中标题
Dialogue: 0,0:00:10.00,0:00:13.00,Default,,0,0,0,,{\fad(500,500)}这是淡入淡出字幕
```

### ASS 解析器

```javascript
function parseASS(assContent) {
  const lines = assContent.split('\n');
  const styles = {};
  const events = [];
  let currentSection = '';

  for (const line of lines) {
    const trimmed = line.trim();

    if (trimmed.startsWith('[')) {
      currentSection = trimmed;
      continue;
    }

    if (currentSection === '[V4+ Styles]' && trimmed.startsWith('Style:')) {
      const parts = trimmed.replace('Style:', '').split(',');
      styles[parts[0]] = {
        fontName: parts[1],
        fontSize: parseInt(parts[2]),
        primaryColor: parts[3],
        bold: parts[7] === '-1',
        alignment: parseInt(parts[18]),
      };
    }

    if (currentSection === '[Events]' && trimmed.startsWith('Dialogue:')) {
      const content = trimmed.replace('Dialogue: ', '');
      const commaIndex = content.indexOf(',');
      const parts = [
        content.substring(0, commaIndex),
        ...content.substring(commaIndex + 1).split(',').slice(0, 8),
        content.substring(commaIndex + 1).split(',').slice(9).join(',')
      ];

      events.push({
        layer: parseInt(parts[0]),
        startTime: parseASSTime(parts[1]),
        endTime: parseASSTime(parts[2]),
        style: parts[3],
        text: parts[8],
        overrides: parseOverrides(parts[8]),
      });
    }
  }

  return { styles, events };
}

function parseASSTime(timeStr) {
  const match = timeStr.match(/(\d+):(\d{2}):(\d{2})\.(\d{2})/);
  if (!match) return 0;
  return (
    parseInt(match[1]) * 3600 +
    parseInt(match[2]) * 60 +
    parseInt(match[3]) +
    parseInt(match[4]) / 100
  );
}

function parseOverrides(text) {
  const overrideMatch = text.match(/\{([^}]+)\}/);
  if (!overrideMatch) return {};

  const overrides = {};
  const tagStr = overrideMatch[1];

  // 位置标签 \pos(x,y)
  const posMatch = tagStr.match(/\\pos\((\d+),(\d+)\)/);
  if (posMatch) {
    overrides.position = { x: parseInt(posMatch[1]), y: parseInt(posMatch[2]) };
  }

  // 淡入淡出 \fad(in,out)
  const fadMatch = tagStr.match(/\\fad\((\d+),(\d+)\)/);
  if (fadMatch) {
    overrides.fade = {
      in: parseInt(fadMatch[1]),
      out: parseInt(fadMatch[2]),
    };
  }

  return overrides;
}
```

## WebVTT：浏览器原生支持

WebVTT（Web Video Text Tracks）是 HTML5 标准的字幕格式，浏览器原生支持，通过 `<track>` 元素加载。

### WebVTT 文件格式

```vtt
WEBVTT

00:00:01.000 --> 00:00:04.000
这是第一行字幕

00:00:05.500 --> 00:00:08.200 position:10% line:80%
这是带有位置信息的字幕

00:00:10.000 --> 00:00:13.000 align:start size:50%
这是左对齐的字幕
```

### HTML5 Track 元素

```html
<video id="video" controls>
  <source src="video.mp4" type="video/mp4">
  <track src="subtitles.vtt" kind="subtitles" srclang="zh" label="中文" default>
  <track src="subtitles-en.vtt" kind="subtitles" srclang="en" label="English">
</video>
```

## 动态水印

水印用于标识视频来源或版权信息。动态水印在画面上移动，更难被裁剪去除。

### Canvas 文字水印

```javascript
class DynamicWatermark {
  constructor(canvas, videoElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.video = videoElement;
    this.config = {
      text: '© 2024 Example',
      fontSize: 24,
      fontColor: 'rgba(255, 255, 255, 0.5)',
      speed: 50, // 像素/秒
      angle: 30, // 运动角度（度）
    };
    this.position = { x: 0, y: 0 };
    this.startTime = 0;
    this.animFrameId = null;
  }

  start() {
    this.startTime = performance.now();
    this.position = { x: 0, y: 0 };
    this.renderLoop();
  }

  stop() {
    if (this.animFrameId) {
      cancelAnimationFrame(this.animFrameId);
      this.animFrameId = null;
    }
  }

  renderLoop() {
    const now = performance.now();
    const elapsed = (now - this.startTime) / 1000;

    // 更新水印位置
    const radians = (this.config.angle * Math.PI) / 180;
    this.position.x = (this.config.speed * elapsed * Math.cos(radians)) % this.canvas.width;
    this.position.y = (this.config.speed * elapsed * Math.sin(radians)) % this.canvas.height;

    // 渲染
    this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    this.ctx.drawImage(this.video, 0, 0, this.canvas.width, this.canvas.height);
    this.drawWatermark();

    this.animFrameId = requestAnimationFrame(() => this.renderLoop());
  }

  drawWatermark() {
    const ctx = this.ctx;
    ctx.save();

    ctx.font = `${this.config.fontSize}px Arial`;
    ctx.fillStyle = this.config.fontColor;
    ctx.textAlign = 'left';
    ctx.textBaseline = 'top';

    // 平铺水印
    const textWidth = ctx.measureText(this.config.text).width;
    const spacing = 200;

    for (let y = this.position.y - spacing; y < this.canvas.height + spacing; y += spacing) {
      for (let x = this.position.x - spacing; x < this.canvas.width + spacing; x += spacing) {
        ctx.fillText(this.config.text, x, y);
      }
    }

    ctx.restore();
  }
}
```

### 图片水印

```javascript
class ImageWatermark {
  constructor(canvas, videoElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.video = videoElement;
    this.image = null;
    this.config = {
      position: 'bottom-right', // 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right'
      margin: 20,
      opacity: 0.6,
      scale: 0.1, // 相对于视频宽度的比例
    };
  }

  async loadImage(src) {
    return new Promise((resolve) => {
      this.image = new Image();
      this.image.onload = () => resolve();
      this.image.src = src;
    });
  }

  render() {
    const ctx = this.ctx;
    ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    ctx.drawImage(this.video, 0, 0, this.canvas.width, this.canvas.height);

    if (!this.image) return;

    const watermarkWidth = this.canvas.width * this.config.scale;
    const watermarkHeight = (this.image.height / this.image.width) * watermarkWidth;

    let x, y;
    switch (this.config.position) {
      case 'top-left':
        x = this.config.margin;
        y = this.config.margin;
        break;
      case 'top-right':
        x = this.canvas.width - watermarkWidth - this.config.margin;
        y = this.config.margin;
        break;
      case 'bottom-left':
        x = this.config.margin;
        y = this.canvas.height - watermarkHeight - this.config.margin;
        break;
      case 'bottom-right':
      default:
        x = this.canvas.width - watermarkWidth - this.config.margin;
        y = this.canvas.height - watermarkHeight - this.config.margin;
    }

    ctx.save();
    ctx.globalAlpha = this.config.opacity;
    ctx.drawImage(this.image, x, y, watermarkWidth, watermarkHeight);
    ctx.restore();
  }
}
```

## 烧录字幕

烧录字幕是指将字幕直接嵌入到视频画面中，成为视频的一部分。这样做的好处是不需要播放器支持字幕格式，缺点是字幕无法关闭。

### 使用 FFmpeg.wasm 烧录 SRT

```javascript
async function burnSubtitles(videoFile, srtContent) {
  const ffmpeg = new FFmpeg();

  const baseURL = 'https://unpkg.com/@ffmpeg/core@0.12.6/dist/umd';
  await ffmpeg.load({
    coreURL: await toBlobURL(`${baseURL}/ffmpeg-core.js`, 'text/javascript'),
    wasmURL: await toBlobURL(`${baseURL}/ffmpeg-core.wasm`, 'application/wasm'),
  });

  // 写入视频和字幕文件
  await ffmpeg.writeFile('input.mp4', await fetchFile(videoFile));
  await ffmpeg.writeFile('subtitles.srt', new TextEncoder().encode(srtContent));

  // 烧录字幕
  await ffmpeg.exec([
    '-i', 'input.mp4',
    '-vf', "subtitles=subtitles.srt:force_style='FontSize=24,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2'",
    '-c:a', 'copy',
    'output.mp4'
  ]);

  const data = await ffmpeg.readFile('output.mp4');
  return new Blob([data.buffer], { type: 'video/mp4' });
}
```

## 常见误区

### 误区一：字幕编码不重要

字幕文件的编码格式会导致乱码。SRT 文件常见的编码有 UTF-8、GBK、GB2312。如果解析时使用错误的编码，中文会变成乱码。

```javascript
async function readSRTWithEncoding(file, encoding = 'utf-8') {
  const buffer = await file.arrayBuffer();
  const decoder = new TextDecoder(encoding);
  return decoder.decode(buffer);
}

// 检测编码（简化版）
function detectEncoding(buffer) {
  const bytes = new Uint8Array(buffer);
  // UTF-8 BOM
  if (bytes[0] === 0xEF && bytes[1] === 0xBB && bytes[2] === 0xBF) {
    return 'utf-8';
  }
  // 简单的 GBK 检测：检查是否有连续的高字节
  let highByteCount = 0;
  for (let i = 0; i < Math.min(1000, bytes.length); i++) {
    if (bytes[i] > 0x7F) highByteCount++;
  }
  return highByteCount > 10 ? 'gbk' : 'utf-8';
}
```

### 误区二：WebVTT 和 SRT 可以互换

虽然 WebVTT 和 SRT 格式相似，但它们有本质区别：
- WebVTT 以 `WEBVTT` 头部开始
- WebVTT 的时间分隔符是 `.`，SRT 是 `,`
- WebVTT 支持位置、对齐等样式属性

### 误区三：水印可以完全防盗

任何可见水印都可以被裁剪、模糊或 AI 去除。水印的作用是提高盗版成本，而非完全防止。对于高价值内容，建议使用不可见的数字水印技术。

---

## 工程建议

1. **播放用 WebVTT，编辑用 SRT**：WebVTT 浏览器原生支持，SRT 格式简单易编辑
2. **字幕编码统一为 UTF-8**：上传时检测编码并转换为 UTF-8，避免乱码问题
3. **水印使用半透明**：避免遮挡视频内容，opacity 建议 0.3-0.5
4. **动态水印平铺**：平铺式水印更难被去除，但要注意不要过于影响观看体验
5. **烧录字幕前预览**：让用户在烧录前确认字幕样式和位置，避免浪费处理时间

## 小结

本课讲解了字幕和水印的核心技术：

- SRT 是最简单的字幕格式，易于解析和编辑
- ASS/SSA 支持丰富的样式和动画，适合专业字幕制作

- FFmpeg.wasm 可以将字幕烧录到视频中，支持 SRT 和 ASS 格式

## 参考答案

### 练习一

**思路**：按空行分割 SRT 文件为多个块，每个块解析序号、时间轴和文本。提供 `getCueAtTime` 方法用于实时查找。

**答案**：

```javascript
class SRTParser {
  constructor() {
    this.subtitles = [];
  }

  parse(content) {
    // 统一换行符
    const normalized = content.replace(/\r\n/g, '\n').replace(/\r/g, '\n');
    const blocks = normalized.split(/\n\n+/);
    this.subtitles = [];

    for (const block of blocks) {
      const lines = block.trim().split('\n');
      if (lines.length < 3) continue;

      const index = parseInt(lines[0], 10);
      if (isNaN(index)) continue;

      const timeMatch = lines[1].match(
        /(\d{2}):(\d{2}):(\d{2})[,.](\d{3})\s*-->\s*(\d{2}):(\d{2}):(\d{2})[,.](\d{3})/
      );
      if (!timeMatch) continue;

      const startTime = this.parseTime(timeMatch[1], timeMatch[2], timeMatch[3], timeMatch[4]);
      const endTime = this.parseTime(timeMatch[5], timeMatch[6], timeMatch[7], timeMatch[8]);
      const text = lines.slice(2).join('\n');

      this.subtitles.push({ index, startTime, endTime, text });
    }

    return this.subtitles;
  }

  parseTime(h, m, s, ms) {
    return parseInt(h) * 3600 + parseInt(m) * 60 + parseInt(s) + parseInt(ms) / 1000;
  }

  getCueAtTime(time) {
    return this.subtitles.find(
      sub => time >= sub.startTime && time <= sub.endTime
    ) || null;
  }

  getCuesInRange(start, end) {
    return this.subtitles.filter(
      sub => sub.endTime > start && sub.startTime < end
    );
  }

  static async fromFile(file, encoding = 'utf-8') {
    const parser = new SRTParser();
    const buffer = await file.arrayBuffer();
    const decoder = new TextDecoder(encoding);
    const content = decoder.decode(buffer);
    parser.parse(content);
    return parser;
  }
}

// 使用示例
const parser = await SRTParser.fromFile(srtFile, 'utf-8');
const video = document.getElementById('video');

video.addEventListener('timeupdate', () => {
  const cue = parser.getCueAtTime(video.currentTime);
  if (cue) {
    subtitleDisplay.textContent = cue.text;
    subtitleDisplay.style.display = 'block';
  } else {
    subtitleDisplay.style.display = 'none';
  }
});
```

**要点**：
- 使用 `\n\n+` 分割块，兼容不同数量的空行
- 时间格式同时支持逗号和句点作为毫秒分隔符
- `getCueAtTime` 使用 `find` 查找当前时间的字幕

```javascript
    ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    ctx.drawImage(this.video, 0, 0, this.canvas.width, this.canvas.height);

    for (const wm of this.watermarks) {
      if (wm.type === 'text') {
        this.renderTextWatermark(ctx, wm, elapsed);
      } else if (wm.type === 'image') {
        this.renderImageWatermark(ctx, wm);
      }
    }

    this.animFrameId = requestAnimationFrame(() => this.renderLoop());
  }

  renderTextWatermark(ctx, wm, elapsed) {
    ctx.save();
    ctx.font = `${wm.fontSize}px ${wm.fontFamily}`;
    ctx.fillStyle = wm.color;

    const radians = (wm.angle * Math.PI) / 180;
    wm.offsetX = (wm.speed * elapsed * Math.cos(radians)) % wm.spacing;
    wm.offsetY = (wm.speed * elapsed * Math.sin(radians)) % wm.spacing;

    for (let y = wm.offsetY - wm.spacing; y < this.canvas.height + wm.spacing; y += wm.spacing) {
      for (let x = wm.offsetX - wm.spacing; x < this.canvas.width + wm.spacing; x += wm.spacing) {
        ctx.fillText(wm.text, x, y);
      }
    }

    ctx.restore();
  }

  renderImageWatermark(ctx, wm) {
    if (!wm.image.complete) return;

    let x, y;
    switch (wm.position) {
      case 'top-left':
        x = wm.margin; y = wm.margin; break;
      case 'top-right':
        x = this.canvas.width - wm.width - wm.margin; y = wm.margin; break;
      case 'bottom-left':
        x = wm.margin; y = this.canvas.height - wm.height - wm.margin; break;
      default:
        x = this.canvas.width - wm.width - wm.margin;
        y = this.canvas.height - wm.height - wm.margin;
    }

    ctx.save();
    ctx.globalAlpha = wm.opacity;
    ctx.drawImage(wm.image, x, y, wm.width, wm.height);
    ctx.restore();
  }
}

// 使用示例
const wm = new WatermarkSystem(canvas, video);
wm.addTextWatermark('© 2024 MyChannel', {
  fontSize: 24,
  color: 'rgba(255,255,255,0.3)',
  speed: 40,
  angle: 30,
  spacing: 350,
});
wm.addImageWatermark('/logo.png', {
  position: 'bottom-right',
  width: 120,
  height: 60,
  opacity: 0.5,
});
wm.start();
```

**要点**：
- 文字水印通过三角函数计算位移，实现对角线移动效果
- 使用取模运算 `%` 让水印循环移动
- 图片水印支持四个角落定位
- `ctx.save()` 和 `ctx.restore()` 隔离每个水印的绘制状态
