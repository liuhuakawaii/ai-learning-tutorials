# Stage 2：视频处理

> 6 课时 | 编解码与编辑

## 阶段概述

本阶段深入视频编解码原理，学习 FFmpeg WASM 浏览器端视频处理，掌握视频滤镜、合成、字幕技术，最终完成一个在线视频编辑器。

## 学习目标

- 理解 H.264/H.265/VP9/AV1 编码原理
- 掌握 FFmpeg WASM 进行浏览器端视频处理
- 学会用 WebGL 着色器实现视频滤镜
- 掌握视频合成、字幕、水印技术
- 构建完整的在线视频编辑器
