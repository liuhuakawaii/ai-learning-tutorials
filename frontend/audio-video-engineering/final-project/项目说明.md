# 毕业项目：在线视频平台

## 项目概述

构建一个完整的在线视频平台，涵盖视频上传、转码、存储、分发、播放、互动的全链路。本项目综合运用课程所学的音视频工程技术，模拟真实生产环境的视频平台架构。

## 技术栈

- **前端**：React/Next.js + TypeScript
- **后端**：Node.js + Express
- **流媒体**：HLS 自适应码率
- **转码**：FFmpeg
- **存储**：本地文件系统（可扩展至 S3）
- **WebRTC**：实时通信模块

## 功能模块

### 模块一：视频上传与管理
- 分片上传，支持断点续传
- 视频元数据管理（标题、描述、标签）
- 上传进度展示

### 模块二：视频转码
- FFmpeg 多码率转码
- HLS 分片生成
- 缩略图提取

### 模块三：视频播放
- 自定义播放器，支持 HLS 自适应码率
- 播放控制（播放/暂停、进度、音量、全屏）
- 画质切换

### 模块四：实时通信
- WebRTC 点对点视频通话
- 屏幕共享
- 实时聊天

### 模块五：质量与安全
- 码率自适应优化
- 基本的访问控制
- 播放数据统计

## 开发步骤

### Phase 1：基础搭建
1. 初始化项目结构
2. 搭建 Express 服务器
3. 创建基础前端页面
4. 实现文件上传 API

### Phase 2：视频处理
5. 集成 FFmpeg 转码
6. 生成 HLS 分片
7. 实现视频列表和管理

### Phase 3：播放器
8. 开发自定义播放器
9. 集成 HLS.js 自适应播放
10. 添加播放控制 UI

### Phase 4：实时通信
11. 搭建 WebSocket 信令服务器
12. 实现 WebRTC 视频通话
13. 添加屏幕共享

### Phase 5：优化与完善
14. 添加错误处理和日志
15. 性能优化
16. 编写验证脚本

## 验证标准

运行 `node scripts/check.cjs` 验证以下内容：

- [ ] 项目结构完整
- [ ] 服务器可启动
- [ ] 上传 API 正常工作
- [ ] HLS 转码生成正确的分片文件
- [ ] 播放器可加载 HLS 流
- [ ] WebRTC 信令连接正常
- [ ] 前端页面可访问
