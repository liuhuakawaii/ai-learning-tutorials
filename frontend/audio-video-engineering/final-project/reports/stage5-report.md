## 核心知识点回顾

### 质量优化
- 每内容自适应编码比固定编码阶梯更高效
- VMAF 是 Netflix 使用的客观质量指标
- 画质增强可以在不增加码率的情况下提升观感

### 性能与功耗
- WebCodecs 提供底层编解码控制
- 硬件加速显著降低 CPU 消耗和功耗
- 移动端需要特别关注功耗和发热

### 版权保护
- DRM（Widevine/FairPlay/PlayReady）是行业标准
- EME API 是浏览器端 DRM 的接口
- 数字水印用于追踪泄露来源
