## 核心知识点回顾

### HLS 与 DASH
- HLS 使用 M3U8 + TS 分片，Apple 生态标准
- DASH 使用 MPD + ISO BMFF，更通用
- 自适应码率根据网络状况切换质量层级

### 播放器开发
- HTML5 Video 事件模型复杂，需注意状态机
- 自定义 UI 需要处理各种边界情况
- MSE 允许手动控制分片加载

### 直播推流
- RTMP 是最成熟的推流协议
- SRT 提供更低延迟和更好的抗丢包能力
- 关键帧间隔直接影响 HLS 分片精度
