## 核心知识点回顾

### 编解码与容器
- 编解码（Codec）是压缩/解压缩算法
- 容器格式（MP4/WebM）是包装编解码后数据的壳
- 同一个容器可以装不同编解码的数据

### Web Audio API
- AudioContext 是音频处理的核心环境
- 节点图架构：Source → Processing → Destination
- AudioWorklet 是生产环境推荐的自定义处理方案

### MediaRecorder
- 基于 MediaStream 进行录制
- 支持录音和录屏
- 必须检查 isTypeSupported 确保编码器可用
