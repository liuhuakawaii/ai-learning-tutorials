# 阶段实战：在线录音机——排查麦克风无声问题

## 现象

你按照 MDN 文档写了录音代码，在 Chrome 上测试正常，在 Safari 上却完全没有声音。控制台没有报错，MediaRecorder 状态显示 "recording"，但 `ondataavailable` 产生的 Blob 大小为 0。

这种问题在音视频开发中极其常见——同一个 API 在不同浏览器上的行为差异。

## 排查过程

### 第一步：确认问题范围

```javascript
// 测试 1：getUserMedia 能拿到流吗？
const stream = await navigator.mediaDevices.getUserMedia({ audio: true })
console.log('Audio tracks:', stream.getAudioTracks().length)
console.log('Track settings:', stream.getAudioTracks()[0].getSettings())

// 测试 2：MediaRecorder 支持什么格式？
const types = [
  'audio/webm;codecs=opus',
  'audio/webm;codecs=vorbis',
  'audio/mp4;codecs=mp4a',
  'audio/ogg;codecs=opus',
  'audio/wav'
]
types.forEach(t => console.log(t, MediaRecorder.isTypeSupported(t)))
```

在 Safari 上跑测试 2，发现 `audio/webm` 全部不支持——Safari 只支持 `audio/mp4`。

### 第二步：确认 MediaRecorder 创建成功

```javascript
// 不指定 mimeType，让浏览器自动选择
const mimeType = types.find(t => MediaRecorder.isTypeSupported(t))
console.log('Using mimeType:', mimeType) // Safari: audio/mp4;codecs=mp4a

const recorder = new MediaRecorder(stream, { mimeType })
console.log('Recorder state:', recorder.state) // 应该是 "inactive"
```

### 第三步：检查 AudioContext 与 MediaStream 的关系

Safari 上 AudioContext 和 MediaStream 的协作有已知问题：

```javascript
// Safari 需要在用户交互事件中创建 AudioContext
document.addEventListener('click', async () => {
  const audioCtx = new AudioContext()
  if (audioCtx.state === 'suspended') {
    await audioCtx.resume() // Safari 必须显式 resume
  }
  // 然后再开始录音
})
```

### 第四步：定位根因

问题出在 Safari 的 MediaRecorder 实现上：如果 MediaStream 没有活跃的音频轨道，MediaRecorder 会静默失败。

```javascript
// 检查轨道状态
stream.getAudioTracks().forEach(track => {
  console.log('Track enabled:', track.enabled)
  console.log('Track muted:', track.muted)
  console.log('Track readyState:', track.readyState) // 'live' 或 'ended'
})

// Safari 上 track.muted 可能是 true
// 解决方案：监听 track 的 unmute 事件
stream.getAudioTracks()[0].addEventListener('unmute', () => {
  console.log('Track unmuted, safe to record')
})
```

## 完整的跨浏览器录音机

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>跨浏览器录音机</title>
  <style>
    body { font-family: system-ui; max-width: 500px; margin: 40px auto; }
    .status { padding: 12px; background: #f5f5f5; border-radius: 8px; margin: 12px 0; }
    .error { background: #fee; color: #c00; }
    canvas { width: 100%; height: 100px; background: #111; border-radius: 4px; }
    button { padding: 10px 24px; font-size: 16px; cursor: pointer; margin: 4px; }
    .recording { background: #e74c3c; color: white; }
    audio { width: 100%; margin: 12px 0; }
  </style>
</head>
<body>
  <h2>在线录音机</h2>
  <canvas id="visualizer"></canvas>
  <div class="status" id="status">就绪</div>
  <div>
    <button id="recordBtn">开始录音</button>
    <button id="stopBtn" disabled>停止</button>
  </div>
  <div id="recordings"></div>

  <script>
    const statusEl = document.getElementById('status')
    const recordBtn = document.getElementById('recordBtn')
    const stopBtn = document.getElementById('stopBtn')
    const canvas = document.getElementById('visualizer')
    const ctx = canvas.getContext('2d')

    let mediaRecorder = null
    let audioContext = null
    let analyser = null
    let stream = null
    let chunks = []

    function getSupportedType() {
      const candidates = [
        'audio/webm;codecs=opus',
        'audio/mp4;codecs=mp4a',
        'audio/webm;codecs=vorbis',
        'audio/ogg;codecs=opus',
        'audio/wav'
      ]
      return candidates.find(t => MediaRecorder.isTypeSupported(t))
    }

    function setStatus(msg, isError = false) {
      statusEl.textContent = msg
      statusEl.className = 'status' + (isError ? ' error' : '')
    }

    function drawVisualization() {
      if (!analyser) return
      requestAnimationFrame(drawVisualization)

      const data = new Uint8Array(analyser.frequencyBinCount)
      analyser.getByteTimeDomainData(data)

      canvas.width = canvas.parentElement.clientWidth
      ctx.fillStyle = '#111'
      ctx.fillRect(0, 0, canvas.width, canvas.height)

      ctx.strokeStyle = mediaRecorder?.state === 'recording' ? '#e74c3c' : '#555'
      ctx.lineWidth = 2
      ctx.beginPath()

      const sliceWidth = canvas.width / data.length
      let x = 0
      for (let i = 0; i < data.length; i++) {
        const y = (data[i] / 128.0) * canvas.height / 2
        i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y)
        x += sliceWidth
      }
      ctx.stroke()
    }

    recordBtn.addEventListener('click', async () => {
      try {
        stream = await navigator.mediaDevices.getUserMedia({
          audio: { noiseSuppression: true, echoCancellation: true }
        })

        // 检查轨道状态
        const track = stream.getAudioTracks()[0]
        console.log('Track state:', track.readyState, 'muted:', track.muted)

        // AudioContext（Safari 需要交互事件中创建）
        audioContext = new AudioContext()
        if (audioContext.state === 'suspended') await audioContext.resume()

        analyser = audioContext.createAnalyser()
        analyser.fftSize = 2048
        const source = audioContext.createMediaStreamSource(stream)
        source.connect(analyser)

        const mimeType = getSupportedType()
        if (!mimeType) {
          setStatus('浏览器不支持任何录音格式', true)
          return
        }

        mediaRecorder = new MediaRecorder(stream, { mimeType })
        chunks = []

        mediaRecorder.ondataavailable = (e) => {
          if (e.data.size > 0) chunks.push(e.data)
        }

        mediaRecorder.onstop = () => {
          const blob = new Blob(chunks, { type: mimeType })
          addRecording(blob, mimeType)
          cleanup()
        }

        mediaRecorder.onerror = (e) => {
          setStatus(`录制错误: ${e.error.message}`, true)
          cleanup()
        }

        mediaRecorder.start(100)
        recordBtn.disabled = true
        stopBtn.disabled = false
        setStatus(`录音中 (${mimeType})`)
        drawVisualization()

      } catch (err) {
        handleMicError(err)
      }
    })

    stopBtn.addEventListener('click', () => {
      if (mediaRecorder?.state === 'recording') {
        mediaRecorder.stop()
      }
      recordBtn.disabled = false
      stopBtn.disabled = true
      setStatus('录音完成')
    })

    function cleanup() {
      stream?.getTracks().forEach(t => t.stop())
      audioContext?.close()
      stream = null
      audioContext = null
      analyser = null
    }

    function handleMicError(err) {
      const messages = {
        NotAllowedError: '麦克风权限被拒绝',
        NotFoundError: '未找到麦克风设备',
        NotReadableError: '麦克风被其他应用占用'
      }
      setStatus(messages[err.name] || `录音失败: ${err.message}`, true)
    }

    function addRecording(blob, mimeType) {
      const url = URL.createObjectURL(blob)
      const ext = mimeType.includes('mp4') ? '.m4a' : '.webm'
      const div = document.createElement('div')
      div.innerHTML = `
        <audio controls src="${url}"></audio>
        <a href="${url}" download="recording${ext}">下载 (${(blob.size/1024).toFixed(1)} KB)</a>
      `
      document.getElementById('recordings').appendChild(div)
    }
  </script>
</body>
</html>
```

## 你可能踩的坑

**坑一：AudioContext 不关闭导致资源泄漏**

每个 AudioContext 占用系统音频资源。录音结束后必须 `close()`。

**坑二：Blob URL 未释放**

每次创建 `URL.createObjectURL` 都占用内存。页面卸载时需要 `revokeObjectURL`。

**坑三：MediaRecorder 停止后轨道仍活跃**

`MediaRecorder.stop()` 不会停止 MediaStream 的轨道，麦克风指示灯仍然亮着。必须手动 `stream.getTracks().forEach(t => t.stop())`。

## 练习

### 练习一：录音降噪

在录音机中添加高通滤波器（截止频率 100Hz），去除低频噪音。要求滤波器只影响可视化和录制的音频，不影响原始 stream。

### 练习二：录音计时器

添加录音时长显示，格式 `MM:SS.ms`。达到最大时长（默认 60 分钟）自动停止，剩余 10 秒时计时器变红闪烁。

### 练习一

```javascript
// source → highpass → lowpass → analyser
const highpass = audioContext.createBiquadFilter()
highpass.type = 'highpass'
highpass.frequency.setValueAtTime(100, audioContext.currentTime)

const lowpass = audioContext.createBiquadFilter()
lowpass.type = 'lowpass'
lowpass.frequency.setValueAtTime(8000, audioContext.currentTime)

source.connect(highpass)
highpass.connect(lowpass)
lowpass.connect(analyser)

// 录制用经过滤波的流
const destination = audioContext.createMediaStreamDestination()
lowpass.connect(destination)
const filteredStream = destination.stream
mediaRecorder = new MediaRecorder(filteredStream, { mimeType })
```

```javascript
let startTime = 0
let timerInterval = null

function startTimer(maxMinutes = 60) {
  startTime = Date.now()
  const maxDuration = maxMinutes * 60 * 1000
  const warningAt = maxDuration - 10000

  timerInterval = setInterval(() => {
    const elapsed = Date.now() - startTime
    timerEl.textContent = formatTime(elapsed)

    if (elapsed >= warningAt) {
      timerEl.style.color = '#e74c3c'
      timerEl.style.opacity = Math.sin(Date.now() / 100) > 0 ? '1' : '0.3'
    }
    if (elapsed >= maxDuration) {
      stopBtn.click()
      clearInterval(timerInterval)
    }
  }, 50)
}
```
