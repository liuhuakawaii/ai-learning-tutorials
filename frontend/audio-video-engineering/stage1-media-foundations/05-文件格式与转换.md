# 第五课：文件格式与转换

## 场景引入

用户在你的在线录音应用中录了一段音频，录制格式是 WebM（因为浏览器默认使用 WebM）。但用户想把文件发给朋友的 iPhone 播放，而 iOS 对 WebM 的支持有限。用户问："能不能帮我转成 MP3？"

在服务端做格式转换需要部署 FFmpeg、处理文件上传下载、消耗服务器资源。但现代浏览器已经具备了一定的本地格式处理能力——通过 `Blob`、`File` API 和 `FFmpeg.wasm`，我们可以在浏览器中完成轻量级的格式转换。

本课将学习常见的音视频格式、浏览器支持检测、以及基于 WebAssembly 的本地格式转换。

## 学习目标

完成本课学习后，你将能够：

1. 说出常见音视频格式的特点和适用场景
2. 使用 `canPlayType` 和 `isTypeSupported` 检测浏览器支持
3. 理解 FFmpeg.wasm 的基本使用方法
4. 使用 Blob 和 File API 创建、下载、上传文件
5. 根据场景选择合适的格式方案

## 常见格式

### 视频格式

| 格式 | 容器 | 视频编码 | 音频编码 | 浏览器支持 | 特点 |
|------|------|----------|----------|------------|------|
| MP4 | MPEG-4 | H.264 | AAC | 全平台 | 兼容性最好 |
| WebM | Matroska | VP8/VP9/AV1 | Vorbis/Opus | Chrome/Firefox | 开源免费 |
| MOV | QuickTime | H.264/H.265 | AAC | Safari | Apple 生态 |

### 音频格式

| 格式 | 编码 | 浏览器支持 | 特点 | 典型用途 |
|------|------|------------|------|----------|
| MP3 | MPEG-1 Layer 3 | 全平台 | 通用性最强 | 音乐分发 |
| AAC | AAC-LC | 全平台 | 同码率优于 MP3 | 流媒体 |
| WAV | PCM | 全平台 | 无压缩，文件大 | 专业音频 |
| Opus | Opus | Chrome/Firefox | 低延迟，高压缩 | 实时通信 |
| FLAC | FLAC | Chrome/Firefox | 无损压缩 | 音乐存档 |
| OGG | Vorbis/Opus | Chrome/Firefox | 开源 | 替代 MP3 |

## 浏览器支持检测

### canPlayType

`HTMLMediaElement.canPlayType()` 返回三个值：`"probably"`（很可能支持）、`"maybe"`（可能支持）、`""`（不支持）。

```javascript
const video = document.createElement('video');
const audio = document.createElement('audio');

// 视频格式检测
function checkVideoSupport() {
  const formats = [
    { label: 'MP4 + H.264', type: 'video/mp4; codecs="avc1.42E01E, mp4a.40.2"' },
    { label: 'MP4 + H.265', type: 'video/mp4; codecs="hev1.1.6.L93.B0"' },
    { label: 'WebM + VP8', type: 'video/webm; codecs="vp8, vorbis"' },
    { label: 'WebM + VP9', type: 'video/webm; codecs="vp9, opus"' },
    { label: 'WebM + AV1', type: 'video/webm; codecs="av01.0.08M.08, opus"' },
  ];

  formats.forEach(f => {
    const support = video.canPlayType(f.type);
    console.log(`${f.label}: ${support || '不支持'}`);
  });
}

// 音频格式检测
function checkAudioSupport() {
  const formats = [
    { label: 'MP3', type: 'audio/mpeg' },
    { label: 'AAC', type: 'audio/mp4; codecs="mp4a.40.2"' },
    { label: 'Opus', type: 'audio/ogg; codecs="opus"' },
    { label: 'FLAC', type: 'audio/flac' },
    { label: 'WAV', type: 'audio/wav' },
  ];

  formats.forEach(f => {
    const support = audio.canPlayType(f.type);
    console.log(`${f.label}: ${support || '不支持'}`);
  });
}
```

### MediaRecorder.isTypeSupported

用于检测 MediaRecorder 支持的编码格式：

```javascript
function getRecorderSupport() {
  const types = [
    'video/webm;codecs=vp8,opus',
    'video/webm;codecs=vp9,opus',
    'video/webm;codecs=vp8',
    'video/webm;codecs=vp9',
    'video/mp4;codecs=avc1',
    'audio/webm;codecs=opus',
    'audio/webm;codecs=vorbis',
    'audio/mp4;codecs=mp4a',
    'audio/ogg;codecs=opus',
    'audio/wav',
  ];

  const supported = types.filter(t => MediaRecorder.isTypeSupported(t));
  const unsupported = types.filter(t => !MediaRecorder.isTypeSupported(t));

  return { supported, unsupported };
}
```

```javascript
      'video/mp4': '.mp4',
```

## FFmpeg.wasm 初探

### 什么是 FFmpeg.wasm

FFmpeg.wasm 是 FFmpeg 的 WebAssembly 版本，可以在浏览器中运行 FFmpeg 的完整功能，包括格式转换、音视频处理等。

### 加载与基本使用

```javascript
// 通过 CDN 加载 FFmpeg.wasm
async function loadFFmpeg() {
  // 动态加载脚本
  const script = document.createElement('script');
  script.src = 'https://unpkg.com/@ffmpeg/ffmpeg@0.12.7/dist/umd/ffmpeg.js';
  document.head.appendChild(script);

  await new Promise((resolve) => { script.onload = resolve; });

  const { FFmpeg } = FFmpegWASM;
  const ffmpeg = new FFmpeg();

  // 加载 FFmpeg 核心（约 30MB，需要耐心等待）
  await ffmpeg.load({
    coreURL: 'https://unpkg.com/@ffmpeg/core@0.12.4/dist/umd/ffmpeg-core.js',
    wasmURL: 'https://unpkg.com/@ffmpeg/core@0.12.4/dist/umd/ffmpeg-core.wasm',
  });

  return ffmpeg;
}
```

### 浏览器中的格式转换示例

```javascript
// WebM 转 WAV（纯前端）
async function convertWebmToWav(webmBlob) {
  const ffmpeg = await loadFFmpeg();

  // 将 Blob 写入 FFmpeg 虚拟文件系统
  const inputData = new Uint8Array(await webmBlob.arrayBuffer());
  await ffmpeg.writeFile('input.webm', inputData);

  // 执行转换命令
  await ffmpeg.exec(['-i', 'input.webm', 'output.wav']);

  // 读取输出文件
  const outputData = await ffmpeg.readFile('output.wav');
  const wavBlob = new Blob([outputData.buffer], { type: 'audio/wav' });

  // 清理虚拟文件系统
  await ffmpeg.deleteFile('input.webm');
  await ffmpeg.deleteFile('output.wav');

  return wavBlob;
}

// 使用示例
async function downloadAsWav(webmBlob) {
  const wavBlob = await convertWebmToWav(webmBlob);
  const url = URL.createObjectURL(wavBlob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'recording.wav';
  a.click();
  URL.revokeObjectURL(url);
}
```

### 监听转换进度

```javascript
async function convertWithProgress(inputBlob, onProgress) {
  const ffmpeg = await loadFFmpeg();

  ffmpeg.on('progress', ({ progress, time }) => {
    // progress: 0-1 的浮点数
    // time: 已处理的时间（微秒）
    onProgress(Math.round(progress * 100));
  });

  ffmpeg.on('log', ({ message }) => {
    console.log('[FFmpeg]', message);
  });

  const inputData = new Uint8Array(await inputBlob.arrayBuffer());
  await ffmpeg.writeFile('input.webm', inputData);

  await ffmpeg.exec([
    '-i', 'input.webm',
    '-ar', '44100',    // 采样率
    '-ac', '2',        // 声道数
    '-b:a', '192k',    // 码率
    'output.mp3'
  ]);

  const outputData = await ffmpeg.readFile('output.mp3');
  return new Blob([outputData.buffer], { type: 'audio/mpeg' });
}

// 使用
convertWithProgress(webmBlob, (percent) => {
  console.log(`转换进度: ${percent}%`);
}).then(mp3Blob => {
  console.log('转换完成');
});
```

### 下载文件

```javascript
function downloadBlob(blob, filename) {
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);

  setTimeout(() => URL.revokeObjectURL(url), 1000);
```

### Blob URL 管理

```javascript
class BlobURLManager {
  constructor() {
    this.urls = new Set();
  }

  create(blob) {
    const url = URL.createObjectURL(blob);
    this.urls.add(url);
    return url;
  }

  revoke(url) {
    URL.revokeObjectURL(url);
    this.urls.delete(url);
  }

  revokeAll() {
    this.urls.forEach(url => URL.revokeObjectURL(url));
    this.urls.clear();
  }
}

// 使用示例
const manager = new BlobURLManager();
const url = manager.create(audioBlob);

// 组件卸载时清理
window.addEventListener('beforeunload', () => manager.revokeAll());
```

## 常见误区

### 误区一：浏览器支持播放就能录制

`canPlayType` 检测的是播放能力，不等于 MediaRecorder 的录制能力。例如，Safari 可以播放 MP4 + H.264，但不一定支持用 MediaRecorder 录制为该格式。

### 误区二：FFmpeg.wasm 可以轻松完成所有转换

FFmpeg.wasm 需要下载约 30MB 的核心文件，首次加载较慢。而且浏览器环境下的性能远不如原生 FFmpeg，大型文件的转换可能需要较长时间。它适合轻量级转换，不适合大批量处理。

### 误区三：WAV 文件比 MP3 音质好

WAV 是无压缩格式，MP3 是有损压缩。WAV 的"好"在于它保留了所有原始数据，但如果原始录音质量就一般，WAV 不会比 MP3 带来更好的听感。选择格式应考虑使用场景，而非盲目追求无损。

### 误区四：文件扩展名决定了文件格式

文件扩展名只是提示，真正决定格式的是文件的二进制签名（magic number）和内部结构。一个 `.mp3` 文件可能是 WebM 数据改了扩展名。服务端应该根据文件内容而非扩展名来判断格式。

```html
        const format = formatSelect.value;
        const inputName = 'input' + getExtension(inputFile.name);
        const outputName = `output.${format}`;

        const inputData = new Uint8Array(await inputFile.arrayBuffer());
        await ffmpeg.writeFile(inputName, inputData);

        progressText.textContent = '转换中...';

        const args = ['-i', inputName];
        if (format === 'mp3') args.push('-b:a', '192k');
        if (format === 'ogg') args.push('-c:a', 'libvorbis', '-b:a', '192k');
        args.push(outputName);

        await ffmpeg.exec(args);

        const outputData = await ffmpeg.readFile(outputName);
        const mimeTypes = { mp3: 'audio/mpeg', wav: 'audio/wav', ogg: 'audio/ogg' };
        const blob = new Blob([outputData.buffer], { type: mimeTypes[format] });

        const url = URL.createObjectURL(blob);
        downloadLink.href = url;
        downloadLink.download = inputFile.name.replace(/\.[^.]+$/, `.${format}`);
        downloadLink.style.display = 'inline';
        downloadLink.textContent = `下载 ${format.toUpperCase()} 文件`;

        progressText.textContent = '转换完成！';

        await ffmpeg.deleteFile(inputName);
        await ffmpeg.deleteFile(outputName);
      } catch (err) {
        progressText.textContent = `错误: ${err.message}`;
      } finally {
        convertBtn.disabled = false;
      }
    });

    function getExtension(filename) {
      const dot = filename.lastIndexOf('.');
      return dot >= 0 ? filename.substring(dot) : '.bin';
    }
  </script>
</body>
</html>
```

**要点**：
- FFmpeg.wasm 首次加载约 30MB，需要良好的加载提示
- 转换完成后要清理虚拟文件系统中的临时文件
- 使用 ES module 方式导入 FFmpeg.wasm 更简洁
