# Stage 1：媒体基础

> 6 课时 | 音视频入门

## 阶段概述

本阶段从音视频基础概念出发，逐步讲解 Web Audio API、Canvas 视频帧操作、MediaRecorder 录制、文件格式转换，最终完成一个在线录音机项目。

## 学习目标

- 理解音视频编解码、容器格式、采样率等核心概念
- 掌握 Web Audio API 的节点图架构
- 学会用 Canvas 操作视频帧
- 掌握 MediaRecorder 录音录屏
- 了解常见音视频格式及浏览器端转换方案
