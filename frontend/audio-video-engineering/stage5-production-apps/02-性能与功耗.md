# 第二课：性能与功耗

## 场景引入

一个用户在手机浏览器上观看在线视频，30 分钟后发现手机发热严重，电量从 80% 降到了 45%。他关掉了视频页面，打开另一个使用原生播放器的 App 观看同样内容，同样 30 分钟只消耗了 8% 的电量。

差距在哪里？浏览器中的视频播放使用的是软解码（CPU 解码），而原生 App 使用的是硬解码（GPU 解码）。CPU 解码一个 1080p 视频每秒需要处理数百万次运算，功耗可达 2-3W；而 GPU 有专用的视频解码电路，同样任务的功耗仅为 0.3-0.5W。

在生产级应用中，性能和功耗优化不是可选项——它直接决定用户体验和设备续航。本课将深入讲解硬件加速、WebCodecs、内存管理等核心优化技术。

## 学习目标

完成本课学习后，你将能够：

1. 理解硬件加速解码的原理，正确使用 VideoDecoder/VideoEncoder API
2. 掌握 WebCodecs API 的帧级控制能力
3. 实施功耗优化策略（分辨率缩放、帧率降级）
4. 管理视频处理中的内存，避免 GC 压力
5. 使用 Web Workers 将解码和处理任务移出主线程

## 硬件加速

### GPU 解码原理

现代设备的 GPU 都有专用的视频解码模块（如 NVIDIA 的 NVDEC、Intel 的 Quick Sync、Apple 的 VideoToolbox）。这些模块是固定功能电路，只能执行特定的解码操作，但效率极高：

```javascript
// 检查硬件解码支持
async function checkHardwareDecodeSupport() {
  const configs = [
    { codec: 'avc1.42E01E', hardware: 'GPU' },        // H.264 Baseline
    { codec: 'hev1.1.6.L93.B0', hardware: 'GPU' },    // H.265 Main
    { codec: 'vp09.00.10.08', hardware: 'GPU' },       // VP9 Profile 0
    { codec: 'av01.0.08M.08', hardware: 'GPU' },       // AV1 Main
  ];

  const results = [];

  for (const config of configs) {
    try {
      const support = await VideoDecoder.isConfigSupported({
        codec: config.codec,
        hardwareAcceleration: 'prefer-hardware',
      });
      results.push({
        codec: config.codec,
        supported: support.supported,
        hardwareAccelerated: support.config?.hardwareAcceleration === 'prefer-hardware'
      });
    } catch (e) {
      results.push({
        codec: config.codec,
        supported: false,
        error: e.message
      });
    }
  }

  return results;
}
```

### VideoDecoder API

WebCodecs 的 VideoDecoder 提供了底层视频解码能力，可以逐帧控制解码过程：

```javascript
// 使用 VideoDecoder 解码视频
class HardwareDecoder {
  constructor(onFrame) {
    this.onFrame = onFrame;
    this.decoder = null;
    this.frameCount = 0;
  }

  async initialize(config) {
    this.decoder = new VideoDecoder({
      output: (frame) => this.handleFrame(frame),
      error: (e) => console.error('解码错误:', e)
    });

    await this.decoder.configure({
      codec: config.codec || 'avc1.42E01E',
      codedWidth: config.width || 1920,
      codedHeight: config.height || 1080,
      hardwareAcceleration: 'prefer-hardware',
      // 优化解码延迟
      optimizeForLatency: true
    });

    console.log('解码器初始化完成');
  }

  handleFrame(frame) {
    this.frameCount++;
    // 将解码后的帧传递给回调
    this.onFrame(frame);
    // 使用完毕后释放帧资源
    frame.close();
  }

  // 解码一个 EncodedVideoChunk
  decodeChunk(chunk) {
    if (this.decoder.state !== 'configured') {
      throw new Error('解码器未配置');
    }
    this.decoder.decode(chunk);
  }

  async flush() {
    if (this.decoder.state === 'configured') {
      await this.decoder.flush();
    }
  }

  destroy() {
    if (this.decoder && this.decoder.state !== 'closed') {
      this.decoder.close();
    }
  }
}
```

## WebCodecs API

### 帧级控制

WebCodecs 最大的优势是提供帧级别的精确控制，适合需要逐帧处理的场景：

```javascript
// 从视频文件提取关键帧
async function extractKeyframes(videoFile) {
  const response = await fetch(URL.createObjectURL(videoFile));
  const buffer = await response.arrayBuffer();

  // 使用 MP4 解复用器解析视频流
  const demuxer = new MP4Demuxer(buffer);
  const videoTrack = demuxer.getVideoTrack();

  const decoder = new VideoDecoder({
    output: (frame) => {
      // 将帧绘制到 Canvas
      const canvas = document.createElement('canvas');
      canvas.width = frame.displayWidth;
      canvas.height = frame.displayHeight;
      const ctx = canvas.getContext('2d');
      ctx.drawImage(frame, 0, 0);
      frame.close();

      // 保存为图片
      const link = document.createElement('a');
      link.download = `keyframe_${Date.now()}.png`;
      link.href = canvas.toDataURL('image/png');
      link.click();
    },
    error: console.error
  });

  await decoder.configure({
    codec: videoTrack.codec,
    codedWidth: videoTrack.width,
    codedHeight: videoTrack.height
  });

  // 只解码关键帧
  for (const sample of videoTrack.samples) {
    if (sample.isSync) {
      const chunk = new EncodedVideoChunk({
        type: 'key',
        timestamp: sample.timestamp,
        data: sample.data
      });
      decoder.decode(chunk);
    }
  }

  await decoder.flush();
  decoder.close();
}
```

### Canvas 帧处理

将解码帧与 Canvas 结合实现实时滤镜：

```javascript
// 实时视频滤镜处理
class VideoFilterProcessor {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d', { willReadFrequently: true });
    this.filters = [];
  }

  addFilter(filterFn) {
    this.filters.push(filterFn);
  }

  // 处理单帧
  processFrame(videoFrame) {
    // 将 VideoFrame 绘制到 Canvas
    this.ctx.drawImage(videoFrame, 0, 0, this.canvas.width, this.canvas.height);

    // 依次应用滤镜
    let imageData = this.ctx.getImageData(0, 0, this.canvas.width, this.canvas.height);

    for (const filter of this.filters) {
      imageData = filter(imageData);
    }

    this.ctx.putImageData(imageData, 0, 0);
    videoFrame.close();
  }
}

// 灰度滤镜
function grayscaleFilter(imageData) {
  const data = imageData.data;
  for (let i = 0; i < data.length; i += 4) {
    const gray = data[i] * 0.299 + data[i + 1] * 0.587 + data[i + 2] * 0.114;
    data[i] = data[i + 1] = data[i + 2] = gray;
  }
  return imageData;
}

// 对比度增强
function contrastFilter(imageData, factor = 1.5) {
  const data = imageData.data;
  const intercept = 128 * (1 - factor);
  for (let i = 0; i < data.length; i += 4) {
    for (let c = 0; c < 3; c++) {
      data[i + c] = Math.max(0, Math.min(255, data[i + c] * factor + intercept));
    }
  }
  return imageData;
}
```

## 功耗优化

### 分辨率自适应

根据设备能力和电量状态动态调整渲染分辨率：

```javascript
// 基于设备状态的分辨率自适应
class PowerAwareRenderer {
  constructor(videoElement) {
    this.video = videoElement;
    this.targetResolution = { width: 1920, height: 1080 };
    this.batteryLevel = 1.0;
    this.isCharging = false;

    this.initBatteryMonitoring();
  }

  async initBatteryMonitoring() {
    if ('getBattery' in navigator) {
      const battery = await navigator.getBattery();

      const updateBattery = () => {
        this.batteryLevel = battery.level;
        this.isCharging = battery.charging;
        this.adjustResolution();
      };

      battery.addEventListener('levelchange', updateBattery);
      battery.addEventListener('chargingchange', updateBattery);
      updateBattery();
    }
  }

  adjustResolution() {
    if (this.isCharging) {
      // 充电时使用最高分辨率
      this.targetResolution = { width: 1920, height: 1080 };
    } else if (this.batteryLevel < 0.2) {
      // 电量低于 20% 降低到 480p
      this.targetResolution = { width: 854, height: 480 };
    } else if (this.batteryLevel < 0.5) {
      // 电量低于 50% 降低到 720p
      this.targetResolution = { width: 1280, height: 720 };
    } else {
      this.targetResolution = { width: 1920, height: 1080 };
    }

    console.log(`电量: ${(this.batteryLevel * 100).toFixed(0)}%, ` +
      `目标分辨率: ${this.targetResolution.width}x${this.targetResolution.height}`);
  }
}
```

### 帧率降级

降低帧率可以显著减少解码和渲染的功耗：

```javascript
// 智能帧率控制
class FrameRateController {
  constructor(videoElement) {
    this.video = videoElement;
    this.targetFps = 30;
    this.isVisible = true;
    this.userActive = true;
    this.inactivityTimer = null;

    this.setupVisibilityDetection();
    this.setupActivityDetection();
  }

  setupVisibilityDetection() {
    document.addEventListener('visibilitychange', () => {
      this.isVisible = !document.hidden;
      this.updateFrameRate();
    });
  }

  setupActivityDetection() {
    const resetTimer = () => {
      this.userActive = true;
      clearTimeout(this.inactivityTimer);
      this.inactivityTimer = setTimeout(() => {
        this.userActive = false;
        this.updateFrameRate();
      }, 30000); // 30 秒无操作
      this.updateFrameRate();
    };

    ['mousemove', 'keydown', 'touchstart'].forEach(event => {
      document.addEventListener(event, resetTimer, { passive: true });
    });
  }

  updateFrameRate() {
    if (!this.isVisible) {
      // 页面不可见时暂停播放
      this.video.pause();
      this.targetFps = 0;
    } else if (!this.userActive) {
      // 用户不活跃时降低帧率
      this.targetFps = 15;
    } else {
      this.targetFps = 30;
    }

    // 如果使用 MediaStream，可以调整轨道帧率
    if (this.video.srcObject) {
      const tracks = this.video.srcObject.getVideoTracks();
      tracks.forEach(track => {
        const capabilities = track.getCapabilities();
        if (capabilities.frameRate) {
          track.applyConstraints({
            frameRate: { max: this.targetFps }
          });
        }
      });
    }
  }
}
```

## 内存管理

### 视频缓冲池

频繁创建和销毁 VideoFrame 会造成内存碎片和 GC 压力。使用对象池可以复用帧缓冲：

```javascript
// VideoFrame 对象池
class VideoFramePool {
  constructor(maxSize = 30) {
    this.pool = [];
    this.maxSize = maxSize;
    this.activeCount = 0;
  }

  // 获取一个帧缓冲
  acquire(width, height) {
    this.activeCount++;

    // 尝试从池中复用
    const existing = this.pool.find(f =>
      f.codedWidth === width && f.codedHeight === height
    );

    if (existing) {
      this.pool.splice(this.pool.indexOf(existing), 1);
      return existing;
    }

    // 池中没有合适的，创建新的
    return new VideoFrame(new Uint8Array(width * height * 4), {
      format: 'RGBA',
      codedWidth: width,
      codedHeight: height,
      timestamp: 0
    });
  }

  // 归还帧缓冲
  release(frame) {
    this.activeCount--;

    if (this.pool.length < this.maxSize) {
      this.pool.push(frame);
    } else {
      // 池已满，直接销毁
      frame.close();
    }
  }

  // 清空池
  clear() {
    this.pool.forEach(f => f.close());
    this.pool = [];
  }

  getStats() {
    return {
      poolSize: this.pool.length,
      activeCount: this.activeCount,
      maxSize: this.maxSize
    };
  }
}
```

```javascript
// 监控视频处理的内存使用
class MemoryMonitor {
  constructor() {
    this.samples = [];
    this.interval = null;
  }

  start(intervalMs = 1000) {
    this.interval = setInterval(() => {
      const sample = this.collectSample();
      this.samples.push(sample);

      // 保留最近 60 个采样
      if (this.samples.length > 60) {
        this.samples.shift();
      }

      // 检测内存压力
      if (sample.usedJSHeapSize > sample.jsHeapSizeLimit * 0.8) {
        console.warn('内存使用率超过 80%，建议释放缓冲区');
        this.onMemoryPressure();
      }
    }, intervalMs);
  }

  collectSample() {
    const memory = performance.memory || {};
    return {
      timestamp: Date.now(),
      usedJSHeapSize: memory.usedJSHeapSize || 0,
      totalJSHeapSize: memory.totalJSHeapSize || 0,
      jsHeapSizeLimit: memory.jsHeapSizeLimit || 0
    };
  }

  onMemoryPressure() {
    // 触发内存压力回调，由使用者决定释放哪些资源
    if (this.onPressure) this.onPressure();
  }

  stop() {
    clearInterval(this.interval);
  }

  getReport() {
    if (this.samples.length === 0) return null;

    const heapSizes = this.samples.map(s => s.usedJSHeapSize);
    return {
      min: Math.min(...heapSizes),
      max: Math.max(...heapSizes),
      avg: heapSizes.reduce((a, b) => a + b, 0) / heapSizes.length,
      current: heapSizes[heapSizes.length - 1]
    };
  }
}
```

## Web Workers

### 解码 Worker

将视频解码移入 Web Worker，避免阻塞主线程：

```javascript
// worker.js - 解码 Worker
self.onmessage = async (e) => {
  const { type, data } = e.data;

  switch (type) {
    case 'init':
      await initDecoder(data.config);
      break;
    case 'decode':
      decodeChunk(data.chunk);
      break;
    case 'flush':
      await decoder.flush();
      break;
  }
};

let decoder = null;

async function initDecoder(config) {
  decoder = new VideoDecoder({
    output: (frame) => {
      // 将解码后的帧数据发送回主线程
      const buffer = new ArrayBuffer(frame.allocationSize());
      frame.copyTo(buffer);

      self.postMessage({
        type: 'frame',
        data: {
          buffer,
          timestamp: frame.timestamp,
          duration: frame.duration,
          displayWidth: frame.displayWidth,
          displayHeight: frame.displayHeight,
          format: frame.format
        }
      }, [buffer]); // Transferable，零拷贝

      frame.close();
    },
    error: (error) => {
      self.postMessage({ type: 'error', data: { message: error.message } });
    }
  });

  await decoder.configure(config);
  self.postMessage({ type: 'ready' });
}

function decodeChunk(chunkData) {
  const chunk = new EncodedVideoChunk({
    type: chunkData.type,
    timestamp: chunkData.timestamp,
    data: chunkData.data
  });
  decoder.decode(chunk);
}
```

```javascript
// main.js - 主线程
class WorkerDecoder {
  constructor() {
    this.worker = new Worker('worker.js');
    this.frameCallback = null;

    this.worker.onmessage = (e) => {
      const { type, data } = e.data;

      if (type === 'frame' && this.frameCallback) {
        // 从 Transferable 恢复 VideoFrame
        const frame = new VideoFrame(data.buffer, {
          timestamp: data.timestamp,
          duration: data.duration,
          displayWidth: data.displayWidth,
          displayHeight: data.displayHeight,
          format: data.format
        });
        this.frameCallback(frame);
      }
    };
  }

  async initialize(config) {
    return new Promise((resolve) => {
      this.worker.onmessage = (e) => {
        if (e.data.type === 'ready') resolve();
      };
      this.worker.postMessage({ type: 'init', data: { config } });
    });
  }

  decode(chunk) {
    const chunkData = {
      type: chunk.type,
      timestamp: chunk.timestamp,
      data: chunk.data.buffer.slice(0)
    };
    this.worker.postMessage({ type: 'decode', data: { chunk: chunkData } });
  }

  onFrame(callback) {
    this.frameCallback = callback;
  }

  destroy() {
    this.worker.terminate();
  }
}
```

### 帧处理 Worker

将 CPU 密集的帧处理（滤镜、分析）也移入 Worker：

```javascript
// frame-processor-worker.js
self.onmessage = (e) => {
  const { imageData, filters } = e.data;

  let result = new Uint8ClampedArray(imageData.buffer);

  for (const filter of filters) {
    result = applyFilter(result, filter);
  }

  // 发回处理后的数据
  self.postMessage({
    buffer: result.buffer,
    width: imageData.width,
    height: imageData.height
  }, [result.buffer]);
};

function applyFilter(data, filter) {
  const output = new Uint8ClampedArray(data.length);

  switch (filter.type) {
    case 'brightness':
      for (let i = 0; i < data.length; i += 4) {
        output[i] = Math.min(255, data[i] + filter.value);
        output[i + 1] = Math.min(255, data[i + 1] + filter.value);
        output[i + 2] = Math.min(255, data[i + 2] + filter.value);
        output[i + 3] = data[i + 3];
      }
      break;

    case 'invert':
      for (let i = 0; i < data.length; i += 4) {
        output[i] = 255 - data[i];
        output[i + 1] = 255 - data[i + 1];
        output[i + 2] = 255 - data[i + 2];
        output[i + 3] = data[i + 3];
      }
      break;
  }

  return output;
}
```

## 常见误区

### 误区一：软解码可以作为万能回退方案

软解码虽然兼容性好，但对高分辨率视频（4K、8K）的性能和功耗表现极差。在移动设备上，软解码 4K 视频可能导致帧率不足、设备过热。生产环境中应该优先使用硬解码，只在硬解码不可用时降级到软解码，并同时降低分辨率。

### 误区二：Web Workers 能解决所有性能问题

Web Workers 适合 CPU 密集型计算，但视频解码涉及 GPU 资源和大块内存的频繁拷贝。将解码移入 Worker 可以避免阻塞主线程，但内存拷贝的开销可能抵消部分收益。对于轻量级处理，直接在主线程使用 requestAnimationFrame 可能更高效。

### 误区三：帧率越低越省电

帧率降低确实减少了解码和渲染的工作量，但屏幕刷新率是固定的（通常 60Hz）。在低帧率下，GPU 仍然需要以屏幕刷新率绘制相同的帧，省电效果有限。真正的省电需要结合降低分辨率和使用硬件解码。

### 误区四：内存监控不需要考虑

JavaScript 的垃圾回收机制在处理大块视频缓冲时可能产生显著的停顿（GC Pause）。一个 1080p 的 RGBA 帧约 8MB，频繁创建和销毁会导致 GC 频繁触发。使用对象池和 Transferable Objects 可以有效减少 GC 压力。

```javascript
// 完整的硬件能力检测
async function detectHardwareCapabilities() {
  const capabilities = {
    webcodecs: typeof VideoDecoder !== 'undefined',
    hardwareDecode: false,
    supportedCodecs: [],
    maxResolution: null,
    batteryApi: 'getBattery' in navigator
  };

  if (!capabilities.webcodecs) {
    console.warn('WebCodecs 不支持，将使用传统 video 元素');
    return capabilities;
  }

  // 检测各编码的硬件解码支持
  const codecs = [
    { name: 'H.264', codec: 'avc1.42E01E' },
    { name: 'H.265', codec: 'hev1.1.6.L93.B0' },
    { name: 'VP9', codec: 'vp09.00.10.08' },
    { name: 'AV1', codec: 'av01.0.08M.08' },
  ];

  for (const { name, codec } of codecs) {
    try {
      const result = await VideoDecoder.isConfigSupported({
        codec,
        hardwareAcceleration: 'prefer-hardware'
      });

      if (result.supported) {
        capabilities.supportedCodecs.push({
          name,
          codec,
          hardwareAccelerated:
            result.config?.hardwareAcceleration === 'prefer-hardware'
        });

        if (result.config?.hardwareAcceleration === 'prefer-hardware') {
          capabilities.hardwareDecode = true;
        }
      }
    } catch (e) {
      // 该编码不支持
    }
  }

  return capabilities;
}
```

```javascript
    strategy.targetResolution = '480p';
    strategy.targetFps = 24;
  } else if (networkInfo.effectiveType === '2g') {
    strategy.targetResolution = '360p';
    strategy.targetFps = 15;
  }

  return strategy;
}
```

## 小结

本课深入讲解了音视频性能与功耗优化的核心技术：

- **硬件加速**：利用 GPU 的专用解码电路，大幅降低 CPU 占用和功耗
- **WebCodecs API**：提供帧级控制能力，适合实时处理和自定义播放器
- **功耗优化**：根据设备电量和使用状态动态调整分辨率和帧率
- **内存管理**：使用对象池和 Transferable Objects 减少 GC 压力
- **Web Workers**：将解码和处理任务移出主线程，保持 UI 响应

性能优化的核心原则是**按需分配资源**——在满足用户体验的前提下，尽可能降低功耗和内存占用。

### 练习一

**思路**：使用 VideoDecoder API 配置解码器，通过解复用器提取视频样本，逐帧解码后绘制到 Canvas。

**答案**：

```javascript
class WebCodecsPlayer {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.decoder = null;
    this.isHardwareAccelerated = false;
  }

  async initialize(codec, width, height) {
    // 优先尝试硬解码
    let config = {
      codec,
      codedWidth: width,
      codedHeight: height,
      hardwareAcceleration: 'prefer-hardware'
    };

    let support = await VideoDecoder.isConfigSupported(config);

    if (support.supported) {
      this.isHardwareAccelerated = true;
      console.log('使用硬件加速解码');
    } else {
      // 回退到软解码
      config.hardwareAcceleration = 'no-preference';
      support = await VideoDecoder.isConfigSupported(config);

      if (!support.supported) {
        throw new Error(`不支持的编码: ${codec}`);
      }
      console.log('使用软件解码');
    }

    this.decoder = new VideoDecoder({
      output: (frame) => this.renderFrame(frame),
      error: (e) => console.error('解码错误:', e)
    });

    await this.decoder.configure(config);
  }

  renderFrame(frame) {
    this.canvas.width = frame.displayWidth;
    this.canvas.height = frame.displayHeight;
    this.ctx.drawImage(frame, 0, 0);
    frame.close();
  }

  async decodeFile(file) {
    const buffer = await file.arrayBuffer();
    // 简化：假设已知编码格式，实际需要解复用器
    const chunk = new EncodedVideoChunk({
      type: 'key',
      timestamp: 0,
      data: new Uint8Array(buffer)
    });
    this.decoder.decode(chunk);
    await this.decoder.flush();
  }

  destroy() {
    if (this.decoder && this.decoder.state !== 'closed') {
      this.decoder.close();
    }
  }
}
```

**要点**：
- 通过 `isConfigSupported` 逐级检测硬解码和软解码支持
- `VideoFrame` 使用后必须调用 `close()` 释放资源
- 实际应用中需要使用 MP4 解复用器提取编码数据

```html
  <script>
    const fpsHistory = [];
    const MAX_HISTORY = 50;
    let frameCount = 0;
    let lastTime = performance.now();

    function updateMonitor() {
      const now = performance.now();
      const elapsed = now - lastTime;

      // 计算 FPS
      const fps = Math.round((frameCount / elapsed) * 1000);
      frameCount = 0;
      lastTime = now;
      fpsHistory.push(fps);
      if (fpsHistory.length > MAX_HISTORY) fpsHistory.shift();

      document.getElementById('fps').textContent = `${fps} fps`;

      // 内存监控
      if (performance.memory) {
        const used = (performance.memory.usedJSHeapSize / 1024 / 1024).toFixed(1);
        const limit = (performance.memory.jsHeapSizeLimit / 1024 / 1024).toFixed(0);
        const el = document.getElementById('memory');
        el.textContent = `${used} / ${limit} MB`;
        el.className = performance.memory.usedJSHeapSize / performance.memory.jsHeapSizeLimit > 0.8
          ? 'value warning' : 'value';
      }

      // 绘制帧率图表
      drawChart();
    }

    function drawChart() {
      const canvas = document.getElementById('chart');
      const ctx = canvas.getContext('2d');
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      ctx.strokeStyle = '#0f0';
      ctx.lineWidth = 1;
      ctx.beginPath();

      for (let i = 0; i < fpsHistory.length; i++) {
        const x = (i / MAX_HISTORY) * canvas.width;
        const y = canvas.height - (fpsHistory[i] / 60) * canvas.height;
        if (i === 0) ctx.moveTo(x, y);
        else ctx.lineTo(x, y);
      }
      ctx.stroke();
    }

    // 电量监控
    if (navigator.getBattery) {
      navigator.getBattery().then(battery => {
        const update = () => {
          const level = (battery.level * 100).toFixed(0);
          const charging = battery.charging ? ' 充电中' : '';
          document.getElementById('battery').textContent = `${level}%${charging}`;
        };
        battery.addEventListener('levelchange', update);
        battery.addEventListener('chargingchange', update);
        update();
      });
    }

    setInterval(updateMonitor, 1000);
  </script>
</body>
</html>
```

**要点**：
- `performance.memory` 仅 Chrome 支持，需要特性检测
- 帧率计算使用采样窗口（1 秒），避免瞬时波动
- 电量监控使用 Battery API，需注意浏览器兼容性
