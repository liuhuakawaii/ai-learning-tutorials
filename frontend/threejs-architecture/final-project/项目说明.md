# 3D 编辑器 — 课程毕业项目

## 项目目标

构建一个简化版 3D 场景编辑器，支持场景图管理、物体选择、变换操作（移动/旋转/缩放）、撤销重做、场景序列化与加载。项目覆盖 Three.js 架构课程中的核心知识：场景图、变换层级、Raycasting、几何/材质管理、序列化策略等。

## 技术栈

- **渲染引擎**：Three.js（r160+）
- **前端框架**：React + TypeScript 或 Vue 3 + TypeScript
- **状态管理**：Zustand 或 Pinia
- **UI 组件**：Leva（参数面板）或自定义控制面板
- **构建工具**：Vite
- **测试**：Vitest

## 核心功能

### 模块一：场景图管理

- 场景树面板：展示所有物体的父子层级关系
- 支持添加/删除节点
- 支持拖拽调整父子关系（reparent）
- 场景树与 3D 视口双向同步选择

### 模块二：物体创建与管理

- 内置几何体库：立方体、球体、圆柱、平面、圆环、自定义
- 材质系统：MeshStandardMaterial 参数调节（颜色、金属度、粗糙度、贴图）
- 支持导入 glTF/OBJ 模型
- 物体列表面板，支持重命名、隐藏/显示、锁定

### 模块三：选择与变换

- Raycasting 鼠标拾取：点击选中物体
- 选中物体高亮（轮廓线或包围盒）
- TransformControls 集成：移动（W）、旋转（E）、缩放（R）切换
- 变换空间切换：世界坐标 / 局部坐标
- 数值输入：精确设置位置、旋转、缩放值

### 模块四：撤销与重做

- Command 模式实现撤销/重做栈
- 支持的操作：添加物体、删除物体、变换、修改材质、调整层级
- 快捷键：Ctrl+Z 撤销、Ctrl+Shift+Z 重做
- 撤销栈深度限制与内存管理

### 模块五：场景序列化

- 场景导出为 JSON（包含所有物体、材质、层级、变换信息）
- JSON 导入恢复场景
- 支持导出为 glTF 格式
- 自动保存到 localStorage（防丢失）

### 模块六：视口与相机

- 多视口：透视视图 + 正交三视图（可选）
- 轨道控制器：旋转/缩放/平移
- 网格地面与坐标轴指示器
- 响应式布局，支持视口大小变化

## 验收标准

- [ ] 场景树面板能正确展示物体层级，支持添加/删除/拖拽
- [ ] 点击 3D 视口中的物体会选中并高亮
- [ ] TransformControls 可以移动、旋转、缩放物体
- [ ] Ctrl+Z 能撤销上一步操作，Ctrl+Shift+Z 能重做
- [ ] 场景能导出为 JSON 并重新加载恢复
- [ ] 至少支持 3 种内置几何体的创建
- [ ] 材质参数可以在面板中实时调节
- [ ] 所有核心模块有单元测试
- [ ] 项目可通过 `node scripts/check.js` 验证结构完整性
