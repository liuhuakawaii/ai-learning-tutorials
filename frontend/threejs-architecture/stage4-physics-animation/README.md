# 第四阶段：物理与动画

## 阶段目标

掌握物理引擎集成、骨骼动画系统、粒子系统和物理模拟，能构建带物理碰撞和动画的交互场景。

## 课时列表

1. [物理引擎集成——Cannon.js/Ammo.js/Rapier 对比、与 Three.js 同步](16-physics-integration.md)
2. [骨骼动画——Skeleton/SkinnedMesh、动画混合、状态机](17-skeletal-animation.md)
3. [粒子系统——GPU 粒子、Transform Feedback、Billboard](18-particle-system.md)
4. [物理模拟——布料/流体/软体的简化实现](19-physics-simulation.md)
5. [阶段实战：构建带物理和动画的交互场景](20-physics-animation-scene.md)

## 验收标准

- 能集成物理引擎（Cannon.js/Rapier）实现碰撞检测和物理模拟
- 能用 Skeleton/SkinnedMesh 实现骨骼动画和动画混合
- 能用 GPU 粒子系统渲染大量粒子并实现 Billboard 效果
- 能实现布料或流体的简化物理模拟
