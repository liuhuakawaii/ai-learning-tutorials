# 阶段实战：扩展商业化方案——从免费到可持续

## 当前项目状态

你的 AI 阅读助手已经有几千用户。服务器成本在涨，但扩展是免费的。需要设计一个可持续的商业模式。

## 商业模式选择

```
模式            优点                    缺点
免费+广告       简单，用户门槛低        收入不稳定，用户体验差
一次性付费      收入可预期              用户增长慢
订阅制          持续收入，可预测        需要持续提供新价值
Freemium        用户基数大，转化率可观  免费/付费功能划分需要技巧
```

对于 AI 阅读助手，推荐 **Freemium**：免费用户每天 5 次摘要，付费用户无限次。

## 实现方案

```javascript
// background.js
class UsageTracker {
  async getUsage() {
    const { usage = { count: 0, date: '' } } = await chrome.storage.local.get('usage')
    const today = new Date().toISOString().slice(0, 10)

    if (usage.date !== today) {
      usage.count = 0
      usage.date = today
    }

    return usage
  }

  async canUse(isPremium) {
    if (isPremium) return true
    const usage = await this.getUsage()
    return usage.count < 5 // 免费用户每天 5 次
  }

  async increment() {
    const usage = await this.getUsage()
    usage.count++
    await chrome.storage.local.set({ usage })
  }
}
```

async function checkSubscription() {
  const { subscriptionId } = await chrome.storage.sync.get('subscriptionId')
  if (!subscriptionId) return { isPremium: false }

  const response = await fetch(`https://your-api.com/subscription/${subscriptionId}`)
  const data = await response.json()
  return { isPremium: data.active, expiresAt: data.expiresAt }
}

async function trackEvent(eventName, data) {
  const { analyticsEnabled } = await chrome.storage.sync.get('analyticsEnabled')
  if (!analyticsEnabled) return

  await fetch('https://your-analytics.com/event', {
    method: 'POST',
    body: JSON.stringify({
      event: eventName,
      data,
      timestamp: Date.now(),
      extensionVersion: chrome.runtime.getManifest().version
    })
  })
}

## 你可能踩的坑

**坑一：免费功能太多**

用户没有理由付费。免费版要有价值但有限制。

**坑二：付费功能太少**

用户觉得不值。付费版要有明显的价值提升。

**坑三：不处理订阅过期**

订阅到期后要优雅降级到免费版，而不是直接报错。
