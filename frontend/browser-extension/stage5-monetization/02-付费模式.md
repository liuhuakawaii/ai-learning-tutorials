# 付费模式

## 场景引入

你开发了一个功能强大的扩展，投入了大量时间和精力。如何让它产生收入？是让用户一次性购买，还是按月订阅？是完全免费靠广告，还是提供免费版和付费版？

付费模式的选择直接影响用户体验、收入稳定性和产品发展。本课将讲解浏览器扩展的主流付费模式，帮助你做出合理的选择。

## 学习目标

- 了解浏览器扩展的主流付费模式
- 掌握订阅制和一次性购买的实现方式
- 理解 Freemium 模式的策略设计
- 学会集成支付系统

## 付费模式对比

| 模式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 一次性购买 | 收入即时、用户理解简单 | 收入不稳定、难以持续 | 功能固定的工具 |
| 订阅制 | 收入稳定、可持续发展 | 用户抵触、流失率高 | 持续更新的服务 |
| Freemium | 用户获取容易 | 免费用户转化率低 | 大众市场产品 |
| 广告 | 用户无需付费 | 体验差、收入低 | 流量大的工具 |
| 捐赠 | 无商业压力 | 收入极不稳定 | 开源/个人项目 |

## 一次性购买

### 使用 Chrome 应用商店内置支付

Chrome Web Store 提供内置的付费功能：

```javascript
// 检查用户是否已购买
async function checkPurchase() {
  return new Promise((resolve) => {
    google.payments.inapp.getPurchases({
      parameters: { env: 'prod' },
      success: (response) => {
        const activeItems = response.response.details;
        resolve(activeItems.length > 0);
      },
      failure: () => {
        resolve(false);
      }
    });
  });
}

// 发起购买
function initiatePurchase() {
  google.payments.inapp.buy({
    parameters: { env: 'prod' },
    sku: 'premium_version',
    success: () => {
      enablePremiumFeatures();
    },
    failure: (error) => {
      console.error('购买失败:', error);
    }
  });
}
```

## 订阅制

### 订阅管理

```javascript
// services/subscription.js
class SubscriptionManager {
  constructor() {
    this.storageKey = 'subscription';
  }

  async getStatus() {
    const { [this.storageKey]: sub } = await chrome.storage.local.get(this.storageKey);
    return sub || { plan: 'free', expiresAt: null };
  }

  async isActive() {
    const sub = await this.getStatus();
    if (sub.plan === 'free') return false;
    if (!sub.expiresAt) return false;
    return new Date(sub.expiresAt) > new Date();
  }

  async activate(plan, duration) {
    const expiresAt = new Date();
    expiresAt.setMonth(expiresAt.getMonth() + duration);

    await chrome.storage.local.set({
      [this.storageKey]: {
        plan,
        activatedAt: new Date().toISOString(),
        expiresAt: expiresAt.toISOString()
      }
    });
  }

  async checkExpiry() {
    const sub = await this.getStatus();
    if (sub.plan !== 'free' && new Date(sub.expiresAt) <= new Date()) {
      await this.downgrade();
      return true;
    }
    return false;
  }

  async downgrade() {
    await chrome.storage.local.set({
      [this.storageKey]: { plan: 'free', expiresAt: null }
    });
  }
}

const subscription = new SubscriptionManager();

// 定期检查订阅状态
chrome.alarms.create('checkSubscription', { periodInMinutes: 60 });

chrome.alarms.onAlarm.addListener(async (alarm) => {
  if (alarm.name === 'checkSubscription') {
    const expired = await subscription.checkExpiry();
    if (expired) {
      chrome.notifications.create({
        type: 'basic',
        iconUrl: 'icons/icon128.png',
        title: '订阅已到期',
        message: '您的高级订阅已到期，请续费以继续使用高级功能。'
      });
    }
  }
});
```

### 功能分级

```javascript
// utils/feature-gate.js
class FeatureGate {
  constructor() {
    this.features = {
      free: ['basic_summary', 'basic_translation', 'save_note'],
      pro: ['ai_summary', 'ai_translation', 'export', 'cloud_sync'],
      premium: ['unlimited_ai', 'priority_support', 'custom_models']
    };
  }

  async canUse(feature) {
    const sub = await subscription.getStatus();

    if (this.features.free.includes(feature)) return true;
    if (this.features.pro.includes(feature)) {
      return sub.plan === 'pro' || sub.plan === 'premium';
    }
    if (this.features.premium.includes(feature)) {
      return sub.plan === 'premium';
    }

    return false;
  }

  async requireFeature(feature) {
    if (!(await this.canUse(feature))) {
      this.showUpgradePrompt(feature);
      return false;
    }
    return true;
  }

  showUpgradePrompt(feature) {
    const messages = {
      ai_summary: 'AI 摘要功能需要 Pro 订阅',
      ai_translation: 'AI 翻译功能需要 Pro 订阅',
      export: '导出功能需要 Pro 订阅'
    };

    chrome.notifications.create({
      type: 'basic',
      iconUrl: 'icons/icon128.png',
      title: '升级到 Pro',
      message: messages[feature] || '此功能需要高级订阅',
      buttons: [{ title: '查看详情' }]
    });
  }
}
```

## Freemium 模式

### 免费版策略

```javascript
// 限制免费版的使用次数
class UsageTracker {
  constructor() {
    this.limits = {
      free: { daily: 10, monthly: 100 },
      pro: { daily: Infinity, monthly: Infinity }
    };
  }

  async getUsage() {
    const { usage = { daily: 0, monthly: 0, lastReset: null } } =
      await chrome.storage.local.get('usage');

    const now = new Date();
    const lastReset = usage.lastReset ? new Date(usage.lastReset) : null;

    // 每日重置
    if (!lastReset || lastReset.getDate() !== now.getDate()) {
      usage.daily = 0;
    }

    // 每月重置
    if (!lastReset || lastReset.getMonth() !== now.getMonth()) {
      usage.monthly = 0;
    }

    usage.lastReset = now.toISOString();
    await chrome.storage.local.set({ usage });

    return usage;
  }

  async canUse(feature) {
    const sub = await subscription.getStatus();
    const limit = this.limits[sub.plan];
    const usage = await this.getUsage();

    if (usage.daily >= limit.daily) {
      return { allowed: false, reason: 'daily_limit' };
    }
    if (usage.monthly >= limit.monthly) {
      return { allowed: false, reason: 'monthly_limit' };
    }

    return { allowed: true };
  }

  async incrementUsage() {
    const usage = await this.getUsage();
    usage.daily += 1;
    usage.monthly += 1;
    await chrome.storage.local.set({ usage });
  }
}
```

## 收入分析

### 关键指标

```javascript
// 计算关键业务指标
function calculateMetrics(users, revenue) {
  return {
    // 月活跃用户
    mau: users.filter(u => u.lastActive > Date.now() - 30 * 24 * 60 * 60 * 1000).length,

    // 付费转化率
    conversionRate: (users.filter(u => u.plan !== 'free').length / users.length * 100).toFixed(2) + '%',

    // 月度经常性收入
    mrr: revenue.filter(r => r.type === 'subscription')
      .reduce((sum, r) => sum + r.amount, 0),

    // 用户生命周期价值
    ltv: (revenue.reduce((sum, r) => sum + r.amount, 0) / users.length).toFixed(2),

    // 流失率
    churnRate: (users.filter(u => u.churned).length / users.length * 100).toFixed(2) + '%'
  };
}
```

## 常见误区

### 误区一：过早收费

用户还没有体验到价值就要求付费，会导致大量流失。让用户先体验核心功能。

### 误区二：免费版太好

如果免费版已经满足大部分用户需求，付费转化率会很低。需要在免费版和付费版之间找到平衡。

### 误区三：价格不透明

隐藏价格或收费不明确会导致用户不信任。在描述中明确说明付费模式。

### 误区四：忽视用户价值

价格应该基于用户获得的价值，而非开发成本。一个能节省用户时间的工具可以定更高的价格。

## 工程建议

1. **价值先行**：让用户先体验到价值，再考虑收费
2. **价格分层**：提供不同价位的选择，满足不同用户需求
3. **透明定价**：在商店描述中明确说明价格和功能差异
4. **持续更新**：付费用户期望持续获得新功能和改进
5. **用户反馈**：根据用户反馈调整定价策略

## 小结

浏览器扩展的付费模式有多种选择，关键是找到适合你产品和用户的方式。一次性购买适合功能固定的工具，订阅制适合持续更新的服务，Freemium 适合大众市场产品。

```javascript
class SubscriptionService {
  async createSubscription(planId, paymentMethod) {
    const response = await fetch('https://api.example.com/subscriptions', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ planId, paymentMethod })
    });

    const subscription = await response.json();

    await chrome.storage.local.set({
      subscription: {
        id: subscription.id,
        plan: planId,
        status: 'active',
        currentPeriodEnd: subscription.currentPeriodEnd
      }
    });

    return subscription;
  }

  async cancelSubscription() {
    const { subscription } = await chrome.storage.local.get('subscription');

    await fetch(`https://api.example.com/subscriptions/${subscription.id}/cancel`, {
      method: 'POST'
    });

    subscription.status = 'canceled';
    await chrome.storage.local.set({ subscription });
  }

  async checkAndUpdateStatus() {
    const { subscription } = await chrome.storage.local.get('subscription');
    if (!subscription || subscription.status !== 'active') return;

    if (new Date(subscription.currentPeriodEnd) < new Date()) {
      subscription.status = 'expired';
      await chrome.storage.local.set({ subscription });

      chrome.notifications.create({
        type: 'basic',
        iconUrl: 'icons/icon128.png',
        title: '订阅已到期',
        message: '请续费以继续使用高级功能'
      });
    }
  }
}
```

### 练习三

**答案**：

```javascript
class ConversionFunnel {
  constructor() {
    this.events = [];
  }

  async track(event, data = {}) {
    this.events.push({
      event,
      data,
      timestamp: Date.now()
    });

    await chrome.storage.local.set({ conversionEvents: this.events });
  }

  async getFunnel() {
    const { conversionEvents = [] } = await chrome.storage.local.get('conversionEvents');

    return {
      installs: conversionEvents.filter(e => e.event === 'install').length,
      firstUse: conversionEvents.filter(e => e.event === 'first_use').length,
      featureDiscovery: conversionEvents.filter(e => e.event === 'feature_discovery').length,
      upgradePromptShown: conversionEvents.filter(e => e.event === 'upgrade_prompt_shown').length,
      upgradeClicked: conversionEvents.filter(e => e.event === 'upgrade_clicked').length,
      purchased: conversionEvents.filter(e => e.event === 'purchased').length
    };
  }

  async getConversionRates() {
    const funnel = await this.getFunnel();

    return {
      installToUse: (funnel.firstUse / funnel.installs * 100).toFixed(2) + '%',
      useToDiscovery: (funnel.featureDiscovery / funnel.firstUse * 100).toFixed(2) + '%',
      promptToClick: (funnel.upgradeClicked / funnel.upgradePromptShown * 100).toFixed(2) + '%',
      clickToPurchase: (funnel.purchased / funnel.upgradeClicked * 100).toFixed(2) + '%'
    };
  }
}
```
