# 数据分析

## 场景引入

"你无法改善你无法衡量的东西。"数据分析是扩展运营的基础。通过追踪用户行为、分析留存率、优化转化漏斗，你可以做出数据驱动的决策，持续改进产品。

但浏览器扩展的数据分析有其特殊性：你没有服务器端的访问日志，用户行为数据需要在客户端收集，还要考虑用户隐私。

本课将讲解如何在扩展中建立数据分析体系。

## 学习目标

- 设计扩展的数据分析架构
- 追踪关键用户行为指标
- 分析用户留存和转化
- 在数据收集和用户隐私之间取得平衡

## 分析架构

### 数据收集层

```javascript
// services/analytics.js
class AnalyticsService {
  constructor() {
    this.queue = [];
    this.flushInterval = 30000;
    this.maxQueueSize = 50;

    this.startFlushTimer();
  }

  track(event, properties = {}) {
    const entry = {
      event,
      properties: {
        ...properties,
        extensionVersion: chrome.runtime.getManifest().version,
        timestamp: Date.now()
      }
    };

    this.queue.push(entry);

    if (this.queue.length >= this.maxQueueSize) {
      this.flush();
    }
  }

  startFlushTimer() {
    setInterval(() => this.flush(), this.flushInterval);
  }

  async flush() {
    if (this.queue.length === 0) return;

    const events = [...this.queue];
    this.queue = [];

    try {
      await fetch('https://api.example.com/analytics', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ events })
      });
    } catch {
      this.queue.push(...events);
    }
  }

  // 本地存储分析数据
  async trackLocal(event, data = {}) {
    const { analytics = [] } = await chrome.storage.local.get('analytics');

    analytics.push({
      event,
      data,
      timestamp: Date.now()
    });

    // 只保留最近 1000 条
    if (analytics.length > 1000) {
      analytics.splice(0, analytics.length - 1000);
    }

    await chrome.storage.local.set({ analytics });
  }
}

const analytics = new AnalyticsService();
```

## 关键指标

### 用户行为指标

```javascript
class MetricsCalculator {
  constructor() {
    this.storageKey = 'metrics';
  }

  async calculate() {
    const { analytics = [] } = await chrome.storage.local.get('analytics');

    return {
      // 日活跃用户
      dau: this.calculateDAU(analytics),
      // 周活跃用户
      wau: this.calculateWAU(analytics),
      // 月活跃用户
      mau: this.calculateMAU(analytics),
      // 功能使用频率
      featureUsage: this.calculateFeatureUsage(analytics),
      // 平均会话时长
      avgSessionDuration: this.calculateAvgSessionDuration(analytics),
      // 错误率
      errorRate: this.calculateErrorRate(analytics)
    };
  }

  calculateDAU(events) {
    const today = new Date();
    today.setHours(0, 0, 0, 0);

    const todayEvents = events.filter(e =>
      new Date(e.timestamp) >= today
    );

    return new Set(todayEvents.map(e => e.userId)).size;
  }

  calculateFeatureUsage(events) {
    const featureEvents = events.filter(e => e.event === 'feature_used');
    const usage = {};

    featureEvents.forEach(e => {
      const feature = e.data?.feature;
      if (feature) {
        usage[feature] = (usage[feature] || 0) + 1;
      }
    });

    return usage;
  }

  calculateErrorRate(events) {
    const total = events.length;
    const errors = events.filter(e => e.event === 'error').length;
    return total > 0 ? (errors / total * 100).toFixed(2) + '%' : '0%';
  }
}
```

### 留存分析

```javascript
class RetentionAnalyzer {
  async analyze() {
    const { analytics = [] } = await chrome.storage.local.get('analytics');

    const cohorts = this.buildCohorts(analytics);
    const retention = this.calculateRetention(cohorts);

    return retention;
  }

  buildCohorts(events) {
    const cohorts = {};

    events.forEach(event => {
      const date = new Date(event.timestamp);
      const cohortKey = `${date.getFullYear()}-${date.getMonth() + 1}`;

      if (!cohorts[cohortKey]) {
        cohorts[cohortKey] = new Set();
      }
      cohorts[cohortKey].add(event.userId);
    });

    return cohorts;
  }

  calculateRetention(cohorts) {
    const cohortKeys = Object.keys(cohorts).sort();
    const retention = {};

    for (let i = 0; i < cohortKeys.length; i++) {
      const cohort = cohortKeys[i];
      const cohortSize = cohorts[cohort].size;

      retention[cohort] = {
        size: cohortSize,
        retention: {}
      };

      for (let j = i; j < cohortKeys.length; j++) {
        const month = j - i;
        const activeInMonth = this.getActiveUsersInMonth(
          cohorts[cohort],
          cohortKeys[j]
        );

        retention[cohort].retention[month] = {
          active: activeInMonth,
          rate: (activeInMonth / cohortSize * 100).toFixed(2) + '%'
        };
      }
    }

    return retention;
  }

  getActiveUsersInMonth(cohortUsers, monthKey) {
    // 简化实现
    return Math.floor(cohortUsers.size * Math.random());
  }
}
```

### 转化漏斗

```javascript
class FunnelAnalyzer {
  async analyze() {
    const { analytics = [] } = await chrome.storage.local.get('analytics');

    const funnel = {
      install: this.countEvent(analytics, 'extension_installed'),
      firstUse: this.countEvent(analytics, 'first_use'),
      featureDiscovery: this.countEvent(analytics, 'feature_discovered'),
      upgradePrompt: this.countEvent(analytics, 'upgrade_prompt_shown'),
      upgradeClick: this.countEvent(analytics, 'upgrade_clicked'),
      purchase: this.countEvent(analytics, 'purchase_completed')
    };

    return {
      steps: funnel,
      conversionRates: {
        installToUse: this.rate(funnel.firstUse, funnel.install),
        useToDiscovery: this.rate(funnel.featureDiscovery, funnel.firstUse),
        promptToClick: this.rate(funnel.upgradeClick, funnel.upgradePrompt),
        clickToPurchase: this.rate(funnel.purchase, funnel.upgradeClick)
      }
    };
  }

  countEvent(events, eventName) {
    return events.filter(e => e.event === eventName).length;
  }

  rate(numerator, denominator) {
    if (denominator === 0) return '0%';
    return (numerator / denominator * 100).toFixed(2) + '%';
  }
}
```

```javascript
// popup/dashboard.js
class AnalyticsDashboard {
  constructor() {
    this.metrics = new MetricsCalculator();
    this.retention = new RetentionAnalyzer();
    this.funnel = new FunnelAnalyzer();
  }

  async render() {
    const [metrics, retention, funnel] = await Promise.all([
      this.metrics.calculate(),
      this.retention.analyze(),
      this.funnel.analyze()
    ]);

    const container = document.getElementById('dashboard');
    container.innerHTML = `
      <div class="metrics-grid">
        <div class="metric-card">
          <h3>日活跃用户</h3>
          <div class="value">${metrics.dau}</div>
        </div>
        <div class="metric-card">
          <h3>周活跃用户</h3>
          <div class="value">${metrics.wau}</div>
        </div>
        <div class="metric-card">
          <h3>月活跃用户</h3>
          <div class="value">${metrics.mau}</div>
        </div>
        <div class="metric-card">
          <h3>错误率</h3>
          <div class="value">${metrics.errorRate}</div>
        </div>
      </div>

      <div class="section">
        <h2>功能使用频率</h2>
        ${this.renderFeatureChart(metrics.featureUsage)}
      </div>

      <div class="section">
        <h2>转化漏斗</h2>
        ${this.renderFunnel(funnel)}
      </div>
    `;
  }

  renderFeatureChart(usage) {
    const entries = Object.entries(usage).sort((a, b) => b[1] - a[1]);
    const max = entries[0]?.[1] || 1;

    return entries.map(([feature, count]) => `
      <div class="bar-row">
        <span class="label">${feature}</span>
        <div class="bar" style="width: ${(count / max * 100)}%"></div>
        <span class="value">${count}</span>
      </div>
    `).join('');
  }

  renderFunnel(funnel) {
    const steps = Object.entries(funnel.steps);
    const max = steps[0]?.[1] || 1;

    return `
      <div class="funnel">
        ${steps.map(([step, count]) => `
          <div class="funnel-step">
            <div class="funnel-bar" style="width: ${(count / max * 100)}%"></div>
            <span class="funnel-label">${step}: ${count}</span>
            <span class="funnel-rate">${funnel.conversionRates[this.getRateKey(step)] || ''}</span>
          </div>
        `).join('')}
      </div>
    `;
  }

  getRateKey(step) {
    const mapping = {
      install: 'installToUse',
      firstUse: 'useToDiscovery',
      featureDiscovery: 'promptToClick',
      upgradePrompt: 'clickToPurchase'
    };
    return mapping[step];
  }
}
```

### 匿名化

```javascript
class PrivacyPreservingAnalytics {
  constructor() {
    this.userId = this.getOrCreateAnonymousId();
  }

  getOrCreateAnonymousId() {
    let { anonymousId } = await chrome.storage.local.get('anonymousId');
    if (!anonymousId) {
      anonymousId = crypto.randomUUID();
      chrome.storage.local.set({ anonymousId });
    }
    return anonymousId;
  }

  track(event, data = {}) {
    // 只发送匿名 ID，不发送可识别信息
    analytics.track(event, {
      ...data,
      userId: this.userId
    });
  }
}
```

### 用户控制

```javascript
// 允许用户选择退出数据收集
async function getAnalyticsConsent() {
  const { analyticsConsent } = await chrome.storage.local.get('analyticsConsent');

  if (analyticsConsent === undefined) {
    // 首次使用，请求同意
    return await requestConsent();
  }

  return analyticsConsent;
}

async function requestConsent() {
  return new Promise((resolve) => {
    const dialog = document.createElement('div');
    dialog.className = 'consent-dialog';
    dialog.innerHTML = `
      <p>帮助我们改进产品？我们会匿名收集使用数据。</p>
      <button id="consent-yes">同意</button>
      <button id="consent-no">拒绝</button>
    `;

    document.body.appendChild(dialog);

    document.getElementById('consent-yes').addEventListener('click', () => {
      chrome.storage.local.set({ analyticsConsent: true });
      dialog.remove();
      resolve(true);
    });

    document.getElementById('consent-no').addEventListener('click', () => {
      chrome.storage.local.set({ analyticsConsent: false });
      dialog.remove();
      resolve(false);
    });
  });
}
```

## 常见误区

### 误区一：收集所有数据

收集过多数据不仅浪费存储，还可能侵犯用户隐私。只收集真正需要的数据。

### 误区二：不尊重用户选择

如果用户选择退出数据收集，必须尊重他们的选择。

### 误区三：只看数据不看用户

数据能告诉你"是什么"，但不能告诉你"为什么"。结合用户反馈理解数据。

### 误区四：指标虚荣

下载量高不代表产品好。关注真正有价值的指标（留存率、活跃度）。

## 工程建议

1. **数据最小化**：只收集必要的数据
2. **用户控制**：允许用户选择退出数据收集
3. **本地优先**：能本地计算的指标不要发送到服务器
4. **隐私保护**：匿名化用户数据
5. **行动导向**：收集数据是为了做出更好的决策

## 小结

数据分析是扩展运营的基础。通过追踪用户行为、分析留存和转化，可以做出数据驱动的决策。同时必须尊重用户隐私，只收集必要的数据。

### 练习二

**答案**：

```javascript
async function calculateRetention() {
  const { events = [] } = await chrome.storage.local.get('events');

  const installs = events.filter(e => e.event === 'installed');
  const retention = {};

  for (const install of installs) {
    const installDate = new Date(install.timestamp);
    const userId = install.data?.userId;

    const day1 = new Date(installDate);
    day1.setDate(day1.getDate() + 1);
    const day7 = new Date(installDate);
    day7.setDate(day7.getDate() + 7);
    const day30 = new Date(installDate);
    day30.setDate(day30.getDate() + 30);

    const userEvents = events.filter(e => e.data?.userId === userId);

    retention[userId] = {
      day1: userEvents.some(e => new Date(e.timestamp) >= day1),
      day7: userEvents.some(e => new Date(e.timestamp) >= day7),
      day30: userEvents.some(e => new Date(e.timestamp) >= day30)
    };
  }

  const users = Object.values(retention);
  return {
    day1: (users.filter(u => u.day1).length / users.length * 100).toFixed(2) + '%',
    day7: (users.filter(u => u.day7).length / users.length * 100).toFixed(2) + '%',
    day30: (users.filter(u => u.day30).length / users.length * 100).toFixed(2) + '%'
  };
}
```
