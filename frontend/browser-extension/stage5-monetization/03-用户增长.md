# 用户增长

## 场景引入

"酒香也怕巷子深"。即使你开发了一个优秀的扩展，如果没有有效的推广策略，用户量可能一直上不去。

浏览器扩展的增长有其独特性：它依赖 Chrome 应用商店的搜索、口碑传播和内容营销。与移动应用不同，扩展没有"应用商店推荐"这样的流量入口（虽然有，但很少）。你需要更聪明的策略来获取用户。

本课将讲解扩展的用户增长策略，包括口碑传播、内容营销、SEO 和社区运营。

## 学习目标

- 掌握扩展的口碑传播策略
- 学会通过内容营销获取用户
- 了解扩展 SEO 的特殊技巧
- 理解社区运营的价值

## 口碑传播

口碑是扩展最有效的增长方式。一个用户推荐给朋友，比任何广告都有效。

### 创造"值得分享"的体验

```javascript
// 在用户完成重要操作后展示分享提示
async function showSharePrompt(context) {
  const { sharePromptShown } = await chrome.storage.local.get('sharePromptShown');
  if (sharePromptShown) return;

  if (context === 'summary_generated' || context === 'article_saved') {
    const notification = document.createElement('div');
    notification.className = 'share-prompt';
    notification.innerHTML = `
      <p>觉得好用？推荐给朋友吧！</p>
      <button id="share-btn">分享</button>
      <button id="dismiss-btn">稍后</button>
    `;

    document.body.appendChild(notification);

    document.getElementById('share-btn').addEventListener('click', () => {
      const shareUrl = 'https://chrome.google.com/webstore/detail/YOUR_EXTENSION_ID';
      navigator.clipboard.writeText(shareUrl);
      alert('链接已复制！');
      chrome.storage.local.set({ sharePromptShown: true });
    });
  }
}
```

### 推荐奖励

```javascript
// 推荐系统
class ReferralSystem {
  constructor() {
    this.storageKey = 'referral';
  }

  async generateReferralLink() {
    const { userId } = await this.getUserId();
    return `https://chrome.google.com/webstore/detail/YOUR_EXTENSION_ID?ref=${userId}`;
  }

  async trackReferral(referrerId) {
    const { referrals = {} } = await chrome.storage.local.get('referral');

    if (!referrals[referrerId]) {
      referrals[referrerId] = { count: 0, rewards: 0 };
    }

    referrals[referrerId].count += 1;

    // 每推荐 5 人获得奖励
    if (referrals[referrerId].count % 5 === 0) {
      referrals[referrerId].rewards += 1;
      await this.grantReward(referrerId);
    }

    await chrome.storage.local.set({ referral: referrals });
  }

  async grantReward(userId) {
    // 给推荐人添加 Pro 天数
    const { subscription } = await chrome.storage.local.get('subscription');
    const expiresAt = new Date(subscription.expiresAt || Date.now());
    expiresAt.setDate(expiresAt.getDate() + 7);

    subscription.expiresAt = expiresAt.toISOString();
    await chrome.storage.local.set({ subscription });

    chrome.notifications.create({
      type: 'basic',
      iconUrl: 'icons/icon128.png',
      title: '推荐奖励',
      message: '恭喜！您获得了 7 天 Pro 订阅奖励！'
    });
  }
}
```

```javascript
// 收集用户反馈
class FeedbackCollector {
  constructor() {
    this.storageKey = 'feedback';
  }

  async submit(feedback) {
    const { feedbacks = [] } = await chrome.storage.local.get(this.storageKey);

    feedbacks.push({
      ...feedback,
      timestamp: Date.now(),
      version: chrome.runtime.getManifest().version
    });

    await chrome.storage.local.set({ feedback: feedbacks });

    // 发送到服务器
    await fetch('https://api.example.com/feedback', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(feedback)
    });
  }

  async promptForFeedback() {
    const { lastFeedbackPrompt, usageCount = 0 } =
      await chrome.storage.local.get(['lastFeedbackPrompt', 'usageCount']);

    if (usageCount > 10 && (!lastFeedbackPrompt || Date.now() - lastFeedbackPrompt > 30 * 24 * 60 * 60 * 1000)) {
      this.showFeedbackPrompt();
      await chrome.storage.local.set({ lastFeedbackPrompt: Date.now() });
    }
  }

  showFeedbackPrompt() {
    chrome.notifications.create('feedback', {
      type: 'basic',
      iconUrl: 'icons/icon128.png',
      title: '您的反馈很重要',
      message: '花 1 分钟告诉我们您的使用体验，帮助我们做得更好！',
      buttons: [{ title: '去反馈' }]
    });
  }
}
```

### 数据驱动增长

```javascript
// 追踪增长指标
class GrowthTracker {
  async track(event, data = {}) {
    const { growthEvents = [] } = await chrome.storage.local.get('growthEvents');

    growthEvents.push({
      event,
      data,
      timestamp: Date.now()
    });

    await chrome.storage.local.set({ growthEvents });
  }

  async getMetrics() {
    const { growthEvents = [] } = await chrome.storage.local.get('growthEvents');

    const now = Date.now();
    const day = 24 * 60 * 60 * 1000;

    return {
      daily: growthEvents.filter(e => now - e.timestamp < day).length,
      weekly: growthEvents.filter(e => now - e.timestamp < 7 * day).length,
      monthly: growthEvents.filter(e => now - e.timestamp < 30 * day).length
    };
  }
}
```

## 常见误区

### 误区一：只关注新用户

留存老用户比获取新用户成本低得多。确保扩展持续提供价值。

### 误区二：过度营销

过于频繁的推广会惹恼用户。找到合适的频率和方式。

### 误区三：忽视产品本身

再好的营销也留不住用户，如果产品本身不好。产品是增长的基础。

### 误区四：不追踪数据

没有数据就没有方向。追踪关键指标，用数据驱动决策。

## 工程建议

1. **口碑优先**：创造值得分享的体验，让用户主动推荐
2. **内容为王**：持续输出有价值的内容，建立专业形象
3. **SEO 基础**：优化商店描述和关键词，提高搜索排名
4. **社区建设**：建立用户社区，收集反馈，培养忠诚用户
5. **数据驱动**：追踪增长指标，用数据指导决策

## 小结

用户增长是一个系统工程，涉及口碑传播、内容营销、SEO 优化和社区运营等多个方面。核心是创造真正有价值的产品，让用户愿意推荐给他人。

### 练习三

**答案**：

```javascript
class Analytics {
  constructor() {
    this.events = [];
  }

  track(event, properties = {}) {
    this.events.push({
      event,
      properties,
      timestamp: Date.now()
    });

    // 批量发送
    if (this.events.length >= 10) {
      this.flush();
    }
  }

  async flush() {
    const events = [...this.events];
    this.events = [];

    try {
      await fetch('https://api.example.com/analytics', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ events })
      });
    } catch {
      // 发送失败，放回队列
      this.events.push(...events);
    }
  }
}

const analytics = new Analytics();

// 使用
analytics.track('extension_installed');
analytics.track('feature_used', { feature: 'summary' });
analytics.track('upgrade_clicked');
```
