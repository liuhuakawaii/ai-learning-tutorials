# 阶段实战：网页高亮标注工具

## 场景引入

前面五课学习了扩展的基础架构：Content Script 操作 DOM、Background Service Worker 事件驱动、Popup UI 展示、三方消息通信。现在是时候把这些知识综合起来，构建一个真实有用的工具了。

我们要构建一个"网页高亮标注工具"：用户在任何网页上选中文本，可以高亮并添加笔记。所有标注数据持久化存储，下次访问同一页面时自动恢复高亮。

这个项目虽然不复杂，但完整覆盖了扩展开发的核心流程。

## 学习目标

- 综合运用 Content Script、Background、Popup 三方架构
- 实现文本选中、高亮、标注的完整交互流程
- 使用 chrome.storage 持久化标注数据
- 处理页面刷新后的高亮恢复
- 掌握扩展项目的完整开发流程

## 功能规划

```
网页高亮标注工具
├── 选中文本后弹出操作菜单（高亮颜色选择）
├── 高亮文本并添加笔记
├── 侧边栏展示当前页面所有标注
├── 点击标注跳转到对应位置
├── 标注数据持久化，刷新页面后恢复

```

## 第二步：高亮功能核心

```javascript
// content/highlighter.js
class TextHighlighter {
  constructor() {
    this.highlightClass = 'ext-highlight-annotated';
    this.dataAttribute = 'data-annotation-id';
  }

  highlightRange(range, color, annotationId) {
    const span = document.createElement('span');
    span.className = this.highlightClass;
    span.setAttribute(this.dataAttribute, annotationId);
    span.style.backgroundColor = color;
    span.style.cursor = 'pointer';

    try {
      range.surroundContents(span);
    } catch (error) {
      this.highlightComplexRange(range, color, annotationId);
    }
  }

  highlightComplexRange(range, color, annotationId) {
    const fragment = range.extractContents();
    const wrapper = document.createElement('span');
    wrapper.className = this.highlightClass;
    wrapper.setAttribute(this.dataAttribute, annotationId);
    wrapper.style.backgroundColor = color;
    wrapper.appendChild(fragment);
    range.insertNode(wrapper);
  }

  removeHighlight(annotationId) {
    const highlights = document.querySelectorAll(
      `[${this.dataAttribute}="${annotationId}"]`
    );
    highlights.forEach(el => {
      const parent = el.parentNode;
      while (el.firstChild) {
        parent.insertBefore(el.firstChild, el);
      }
      parent.removeChild(el);
      parent.normalize();
    });
  }

  getSelectedRange() {
    const selection = window.getSelection();
    if (selection.rangeCount === 0 || selection.isCollapsed) return null;
    return selection.getRangeAt(0);
  }

  getSelectedText() {
    const selection = window.getSelection();
    return selection.toString().trim();
  }

  getXPathForRange(range) {
    const container = range.startContainer;
    const xpath = this.getXPath(container.nodeType === Node.TEXT_NODE
      ? container.parentNode
      : container
    );
    const textContent = container.textContent;
    const startOffset = range.startOffset;

    return {
      xpath,
      startOffset,
      textSnippet: textContent.substring(
        Math.max(0, startOffset - 20),
        startOffset + range.toString().length + 20
      )
    };
  }

  getXPath(element) {
    if (element === document.body) return '/html/body';
    const index = this.getElementIndex(element);
    return `${this.getXPath(element.parentNode)}/${element.tagName.toLowerCase()}[${index}]`;
  }

  getElementIndex(element) {
    let index = 1;
    let sibling = element.previousSibling;
    while (sibling) {
      if (sibling.nodeType === Node.ELEMENT_NODE &&
          sibling.tagName === element.tagName) {
        index++;
      }
      sibling = sibling.previousSibling;
    }
    return index;
  }

  restoreHighlight(annotation) {
    try {
      const element = this.getElementByXPath(annotation.xpath);
      if (!element) return false;

      const textNode = this.findTextNode(element, annotation.textSnippet, annotation.startOffset);
      if (!textNode) return false;

      const range = document.createRange();
      const offset = textNode.textContent.indexOf(annotation.selectedText);
      if (offset === -1) return false;

      range.setStart(textNode, offset);
      range.setEnd(textNode, offset + annotation.selectedText.length);
      this.highlightRange(range, annotation.color, annotation.id);
      return true;
    } catch {
      return false;
    }
  }

  getElementByXPath(xpath) {
    const result = document.evaluate(
      xpath, document, null,
      XPathResult.FIRST_ORDERED_NODE_TYPE, null
    );
    return result.singleNodeValue;
  }

  findTextNode(element, snippet, offset) {
    const walker = document.createTreeWalker(
      element,
      NodeFilter.SHOW_TEXT,
      null,
      false
    );

    while (walker.nextNode()) {
      const node = walker.currentNode;
      if (node.textContent.includes(snippet.substring(20, snippet.length - 20))) {
        return node;
      }
    }
    return null;
  }
}

window.__highlighter = new TextHighlighter();
```

`TextHighlighter` 类负责：
- 将选中的文本范围包裹在高亮 `<span>` 中
- 记录高亮位置的 XPath 和偏移量，用于刷新后恢复
- 处理跨元素的复杂选区

class SelectionMenu {
  constructor(onAction) {
    this.onAction = onAction;
    this.menu = null;
    this.colors = ['#ffeb3b', '#4caf50', '#2196f3', '#ff9800', '#e91e63'];
    this.create();
  }

  create() {
    this.menu = document.createElement('div');
    this.menu.className = 'ext-selection-menu';
    this.menu.style.display = 'none';

    const colorPicker = document.createElement('div');
    colorPicker.className = 'ext-color-picker';

    this.colors.forEach(color => {
      const btn = document.createElement('button');
      btn.className = 'ext-color-btn';
      btn.style.backgroundColor = color;
      btn.dataset.color = color;
      btn.addEventListener('click', (e) => {
        e.stopPropagation();
        this.onAction('highlight', { color });
        this.hide();
      });
      colorPicker.appendChild(btn);
    });

    const noteBtn = document.createElement('button');
    noteBtn.className = 'ext-action-btn';
    noteBtn.textContent = '📝 添加笔记';
    noteBtn.addEventListener('click', (e) => {
      e.stopPropagation();
      this.onAction('note', {});
      this.hide();
    });

    this.menu.appendChild(colorPicker);
    this.menu.appendChild(noteBtn);
    document.body.appendChild(this.menu);
  }

  show(x, y) {
    this.menu.style.left = `${x}px`;
    this.menu.style.top = `${y - 60}px`;
    this.menu.style.display = 'flex';
  }

  hide() {
    this.menu.style.display = 'none';
  }

  isVisible() {
    return this.menu.style.display !== 'none';
  }
}

// content/sidebar.js
class AnnotationSidebar {
  constructor(highlighter) {
    this.highlighter = highlighter;
    this.sidebar = null;
    this.isOpen = false;
    this.create();
  }

  create() {
    const container = document.createElement('div');
    container.id = 'ext-annotation-sidebar';
    container.className = 'ext-sidebar';
    container.innerHTML = `
      <div class="ext-sidebar-header">
        <h3>我的标注</h3>
        <button class="ext-sidebar-close">✕</button>
      </div>
      <div class="ext-sidebar-content">
        <div class="ext-annotation-list"></div>
        <div class="ext-empty-state">选中文本即可添加标注</div>
      </div>
    `;

    container.querySelector('.ext-sidebar-close').addEventListener('click', () => {
      this.close();
    });

    document.body.appendChild(container);
    this.sidebar = container;
  }

  open() {
    this.sidebar.classList.add('open');
    this.isOpen = true;
  }

  close() {
    this.sidebar.classList.remove('open');
    this.isOpen = false;
  }

  toggle() {
    if (this.isOpen) this.close();
    else this.open();
  }

  renderAnnotations(annotations) {
    const list = this.sidebar.querySelector('.ext-annotation-list');
    const empty = this.sidebar.querySelector('.ext-empty-state');

    if (annotations.length === 0) {
      list.innerHTML = '';
      empty.style.display = 'block';
      return;
    }

    empty.style.display = 'none';
    list.innerHTML = annotations.map(ann => `
      <div class="ext-annotation-item" data-id="${ann.id}">
        <div class="ext-ann-color" style="background: ${ann.color}"></div>
        <div class="ext-ann-content">
          <p class="ext-ann-text">"${ann.selectedText.substring(0, 100)}${ann.selectedText.length > 100 ? '...' : ''}"</p>
          ${ann.note ? `<p class="ext-ann-note">${ann.note}</p>` : ''}
          <span class="ext-ann-time">${new Date(ann.createdAt).toLocaleString()}</span>
        </div>
        <button class="ext-ann-delete" data-id="${ann.id}">🗑</button>
      </div>
    `).join('');

    list.querySelectorAll('.ext-annotation-item').forEach(item => {
      item.addEventListener('click', () => {
        const id = item.dataset.id;
        const el = document.querySelector(`[data-annotation-id="${id}"]`);
        if (el) {
          el.scrollIntoView({ behavior: 'smooth', block: 'center' });
          el.style.outline = '2px solid #1a73e8';
          setTimeout(() => el.style.outline = '', 2000);
        }
      });
    });

    list.querySelectorAll('.ext-ann-delete').forEach(btn => {
      btn.addEventListener('click', (e) => {
        e.stopPropagation();
        const id = btn.dataset.id;
        this.highlighter.removeHighlight(id);
        this.onDelete(id);
      });
    });
  }

  onDelete = () => {};
}

## 第五步：主控制器

```javascript
// content/content.js
(async function main() {
  const highlighter = window.__highlighter;

  const currentUrl = window.location.href;
  const storageKey = `annotations_${currentUrl}`;

  let annotations = await loadAnnotations();

  restoreHighlights();

  const menu = new SelectionMenu(handleMenuAction);
  const sidebar = new AnnotationSidebar(highlighter);
  sidebar.onDelete = async (id) => {
    annotations = annotations.filter(a => a.id !== id);
    await saveAnnotations();
    sidebar.renderAnnotations(annotations);
  };
  sidebar.renderAnnotations(annotations);

  document.addEventListener('mouseup', handleMouseUp);
  document.addEventListener('mousedown', handleMouseDown);

  function handleMouseUp(event) {
    if (event.target.closest('.ext-selection-menu') ||
        event.target.closest('.ext-annotation-sidebar')) {
      return;
    }

    const selectedText = highlighter.getSelectedText();
    if (selectedText.length > 0) {
      const range = highlighter.getSelectedRange();
      const rect = range.getBoundingClientRect();
      menu.show(
        rect.left + rect.width / 2 - 75,
        rect.top + window.scrollY
      );
    }
  }

  function handleMouseDown(event) {
    if (!event.target.closest('.ext-selection-menu') &&
        !event.target.closest('.ext-annotation-sidebar')) {
      menu.hide();
    }
  }

  function handleMenuAction(action, data) {
    const range = highlighter.getSelectedRange();
    const selectedText = highlighter.getSelectedText();
    if (!range || !selectedText) return;

    const annotation = {
      id: `ann_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`,
      selectedText,
      color: data.color || '#ffeb3b',
      note: '',
      url: currentUrl,
      ...highlighter.getXPathForRange(range),
      createdAt: new Date().toISOString()
    };

    if (action === 'note') {
      const note = prompt('请输入笔记:');
      if (!note) return;
      annotation.note = note;
    }

    highlighter.highlightRange(range, annotation.color, annotation.id);
    annotations.push(annotation);
    saveAnnotations();
    sidebar.renderAnnotations(annotations);

    window.getSelection().removeAllRanges();
  }

  async function loadAnnotations() {
    const result = await chrome.storage.local.get(storageKey);
    return result[storageKey] || [];
  }

  async function saveAnnotations() {
    await chrome.storage.local.set({ [storageKey]: annotations });
  }

  function restoreHighlights() {
    annotations.forEach(ann => {
      highlighter.restoreHighlight(ann);
    });
  }
})();
```

// popup/popup.js
document.addEventListener('DOMContentLoaded', async () => {
  const data = await chrome.storage.local.get(null);
  const allAnnotations = [];

  for (const [key, value] of Object.entries(data)) {
    if (key.startsWith('annotations_') && Array.isArray(value)) {
      allAnnotations.push(...value);
    }

    .sort((a, b) => new Date(b.createdAt) - new Date(a.createdAt))

## 工程建议

1. **XPath 恢复策略的局限**：XPath 定位依赖页面结构不变。如果页面结构变化（如 SPA 路由切换），标注可能无法恢复。更健壮的方案可以结合文本指纹匹配。
2. **大量标注的性能**：如果一个页面有数百个高亮，恢复时会有性能问题。考虑分批恢复或使用 `requestIdleCallback`。
3. **Shadow DOM 中的文本**：当前实现无法高亮 Shadow DOM 内部的文本。如果目标网站大量使用 Shadow DOM，需要递归处理。
4. **数据导出**：考虑添加 JSON 导出功能，让用户备份自己的标注数据。

## 常见误区

### 误区一：range.surroundContents 可以处理所有选区

当选区跨越多个 DOM 节点时，`surroundContents` 会抛出异常。需要使用 `extractContents` + 手动插入的方式处理复杂选区。

### 误区二：用 innerHTML 存储高亮位置

不要试图用 innerHTML 中的位置来记录高亮，因为其他高亮的插入会改变 HTML 结构，导致位置偏移。XPath + 文本偏移是更可靠的定位方式。

### 误区三：忽略页面卸载时的清理

注入的 DOM 元素和事件监听器在页面刷新时会自动清理。但如果使用了 MutationObserver，需要确保在页面卸载时断开观察。

### 练习一

**思路**：在 popup 或 sidebar 中添加导出按钮，遍历标注数据生成 Markdown。

**答案**：

```javascript
function exportToMarkdown(annotations) {
  const grouped = {};
  annotations.forEach(ann => {
    if (!grouped[ann.url]) grouped[ann.url] = [];
    grouped[ann.url].push(ann);
  });

  let md = '# 我的网页标注\n\n';
  md += `导出时间: ${new Date().toLocaleString()}\n\n`;

  for (const [url, anns] of Object.entries(grouped)) {
    md += `## ${new URL(url).hostname}\n`;
    md += `> ${url}\n\n`;

    anns.forEach(ann => {
      md += `- <mark style="background:${ann.color}">${ann.selectedText}</mark>\n`;
      if (ann.note) md += `  - 笔记: ${ann.note}\n`;
    });

    md += '\n';
  }

  const blob = new Blob([md], { type: 'text/markdown' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `annotations-${new Date().toISOString().slice(0, 10)}.md`;
  a.click();
  URL.revokeObjectURL(url);
}
```
