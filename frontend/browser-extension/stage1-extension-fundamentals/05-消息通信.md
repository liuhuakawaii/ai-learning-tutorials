# 消息通信

## 场景引入

扩展的三个核心组件——Popup、Content Script、Background——运行在完全隔离的 JavaScript 上下文中。它们不能直接调用对方的函数，不能访问对方的变量。但扩展的功能往往需要这三个组件协同工作：

- Popup 需要从 Content Script 获取页面数据
- Content Script 需要调用 Background 的 Chrome API
- Background 需要通知所有 Content Script 执行某个操作

消息传递（Message Passing）是连接这三个组件的唯一桥梁。掌握它的各种模式和陷阱，是开发复杂扩展的基础。

## 学习目标

- 掌握一次性消息（sendMessage）的使用方式
- 理解长连接端口（connect）的使用场景
- 实现三方组件的协调通信
- 处理消息传递中的常见错误

## 一次性消息

最简单的通信方式：发送一条消息，等待一个响应。

### Popup → Content Script

```javascript
// popup.js - 发送消息给 content script
async function getPageTitle(tabId) {
  try {
    const response = await chrome.tabs.sendMessage(tabId, {
      type: 'GET_PAGE_TITLE'
    });
    return response.title;
  } catch (error) {
    console.error('无法获取页面标题:', error);
    return null;
  }
}

// 使用
const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
const title = await getPageTitle(tab.id);
```

```javascript
// content.js - 监听并响应消息
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'GET_PAGE_TITLE') {
    sendResponse({ title: document.title });
  }
  return false;
});
```

### Content Script → Background

```javascript
// content.js - 请求 background 执行操作
async function saveData(data) {
  const response = await chrome.runtime.sendMessage({
    type: 'SAVE_DATA',
    payload: data
  });

  if (response.success) {
    console.log('数据已保存');
  } else {
    console.error('保存失败:', response.error);
  }
}
```

```javascript
// background.js - 处理来自 content script 的请求
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'SAVE_DATA') {
    chrome.storage.local.set({ data: message.payload })
      .then(() => sendResponse({ success: true }))
      .catch(error => sendResponse({ success: false, error: error.message }));
    return true;
  }
});
```

### Background → Content Script

```javascript
// background.js - 向指定标签页发送消息
async function notifyContentScript(tabId, data) {
  try {
    const response = await chrome.tabs.sendMessage(tabId, {
      type: 'UPDATE_DISPLAY',
      payload: data
    });
    console.log('Content script 响应:', response);
  } catch (error) {
    console.error('发送失败，content script 可能未注入:', error);
  }
}
```

```javascript
// content.js - 监听来自 background 的消息
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'UPDATE_DISPLAY') {
    updatePageDisplay(message.payload);
    sendResponse({ received: true });
  }
  return false;
});
```

## 长连接端口

一次性消息适合简单的请求-响应模式。当需要持续通信时（如实时数据流、双向对话），使用长连接端口。

### Popup ↔ Background

```javascript
// popup.js - 建立长连接
const port = chrome.runtime.connect({ name: 'popup' });

port.onMessage.addListener((message) => {
  switch (message.type) {
    case 'PROGRESS':
      updateProgressBar(message.progress);
      break;
    case 'COMPLETE':
      showCompletion(message.result);
      break;
    case 'ERROR':
      showError(message.error);
      break;
  }
});

port.onDisconnect.addListener(() => {
  console.log('与 background 的连接断开');
});

// 发送消息
port.postMessage({ type: 'START_TASK', taskId: 'sync' });

// Popup 关闭时自动断开连接
```

```javascript
// background.js - 监听长连接
chrome.runtime.onConnect.addListener((port) => {
  if (port.name === 'popup') {
    port.onMessage.addListener(async (message) => {
      if (message.type === 'START_TASK') {
        await handleLongTask(port);
      }
    });

    port.onDisconnect.addListener(() => {
      console.log('Popup 已断开');
    });
  }
});

async function handleLongTask(port) {
  const steps = 10;
  for (let i = 0; i < steps; i++) {
    await processStep(i);
    try {
      port.postMessage({
        type: 'PROGRESS',
        progress: Math.round(((i + 1) / steps) * 100)
      });
    } catch {
      break;
    }
  }
  port.postMessage({ type: 'COMPLETE', result: '任务完成' });
}
```

### 向所有 Content Script 广播

```javascript
// background.js - 广播消息给所有标签页
async function broadcastToAllTabs(message) {
  const tabs = await chrome.tabs.query({});
  const results = [];

  for (const tab of tabs) {
    try {
      const response = await chrome.tabs.sendMessage(tab.id, message);
      results.push({ tabId: tab.id, response });
    } catch {
      // 该标签页没有注入 content script
    }
  }

  return results;
}

// 使用
await broadcastToAllTabs({
  type: 'REFRESH',
  reason: 'settings_changed'
});
```

## 消息格式设计

定义清晰的消息格式可以避免混乱：

```javascript
// message-types.js - 消息类型常量
const MessageType = {
  // Popup → Content
  GET_PAGE_INFO: 'GET_PAGE_INFO',
  HIGHLIGHT_TEXT: 'HIGHLIGHT_TEXT',
  INJECT_UI: 'INJECT_UI',

  // Content → Background
  SAVE_ANNOTATION: 'SAVE_ANNOTATION',
  LOG_EVENT: 'LOG_EVENT',

  // Background → Content
  REFRESH_DISPLAY: 'REFRESH_DISPLAY',
  APPLY_SETTINGS: 'APPLY_SETTINGS',

  // Background → Popup
  TASK_PROGRESS: 'TASK_PROGRESS',
  TASK_COMPLETE: 'TASK_COMPLETE'
};
```

```javascript
// 统一的消息封装
function createMessage(type, payload = {}, meta = {}) {
  return {
    type,
    payload,
    meta: {
      timestamp: Date.now(),
      source: chrome.runtime.id,
      ...meta
    }
  };
}

// 使用
const message = createMessage(MessageType.SAVE_ANNOTATION, {
  text: '选中的文本',

  color: '#ffeb3b'
});
```

## 错误处理

消息传递中的错误很常见，必须妥善处理。

### Content Script 未注入

```javascript
// 安全地发送消息给 content script
async function safeSendMessage(tabId, message) {
  try {
    return await chrome.tabs.sendMessage(tabId, message);
  } catch (error) {
    if (error.message.includes('Receiving end does not exist')) {
      // Content script 未注入，尝试注入后重试
      await chrome.scripting.executeScript({
        target: { tabId },
        files: ['content.js']
      });
      return await chrome.tabs.sendMessage(tabId, message);
    }
    throw error;
  }
}
```

### Service Worker 已终止

```javascript
// content.js - 确保 Service Worker 已启动
async function ensureBackgroundReady() {
  try {
    await chrome.runtime.sendMessage({ type: 'PING' });
  } catch {
    // Service Worker 可能需要时间启动
    await new Promise(resolve => setTimeout(resolve, 100));
  }
}

// 发送消息前先确保连接就绪
await ensureBackgroundReady();
const response = await chrome.runtime.sendMessage({ type: 'GET_DATA' });
```

### 超时处理

```javascript
function sendMessageWithTimeout(message, timeout = 5000) {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => {
      reject(new Error('消息发送超时'));
    }, timeout);

    chrome.runtime.sendMessage(message, (response) => {
      clearTimeout(timer);
      if (chrome.runtime.lastError) {
        reject(new Error(chrome.runtime.lastError.message));
      } else {
        resolve(response);
      }
    });
  });
}
```

### 异步响应的注意事项

`sendResponse` 只能在事件处理器同步调用，或者在 `return true` 后异步调用一次：

```javascript
// ❌ 错误：忘记 return true
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  fetchData().then(data => {
    sendResponse(data); // 可能已经失效
  });
  // 没有 return true，sendResponse 会在函数返回后失效
});

// ❌ 错误：多次调用 sendResponse
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  sendResponse('第一次');
  setTimeout(() => {
    sendResponse('第二次'); // 错误：只能调用一次
  }, 1000);
  return true;
});

// ✅ 正确
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  fetchData().then(data => {
    sendResponse(data);
  }).catch(error => {
    sendResponse({ error: error.message });
  });
  return true;
});
```

## 三方通信实战

一个完整的三方通信场景：用户在 Popup 中点击"提取页面数据"，Popup 请求 Content Script 提取数据，Content Script 将数据发给 Background 保存，Background 保存完成后通知 Popup 更新 UI。

```
Popup                    Content Script              Background
  │                          │                          │
  │──GET_PAGE_DATA──────────>│                          │
  │                          │──SAVE_TO_STORAGE────────>│
  │                          │                          │──保存数据
  │                          │<──SAVE_RESULT────────────│
  │<──PAGE_DATA_RESULT──────│                          │
  │                          │                          │
  │──REFRESH_DISPLAY────────>│                          │
```

```javascript
// popup.js
document.getElementById('extract').addEventListener('click', async () => {
  const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });

  try {
    const pageData = await chrome.tabs.sendMessage(tab.id, {
      type: 'EXTRACT_PAGE_DATA'
    });

    document.getElementById('result').textContent =
      JSON.stringify(pageData, null, 2);
  } catch (error) {
    document.getElementById('error').textContent = error.message;
  }
});
```

```javascript
// content.js
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'EXTRACT_PAGE_DATA') {
    const data = {
      title: document.title,
      url: window.location.href,
      text: document.body.innerText.substring(0, 5000),
      links: [...document.querySelectorAll('a[href]')].slice(0, 50).map(a => ({
        text: a.textContent.trim(),
        href: a.href
      }))
    };

    chrome.runtime.sendMessage({
      type: 'SAVE_EXTRACTED_DATA',
      payload: data
    });

    sendResponse(data);
  }
  return false;
});
```

```javascript
// background.js
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'SAVE_EXTRACTED_DATA') {
    saveExtractedData(message.payload);
  }
  return false;
});

async function saveExtractedData(data) {
  const { extractedData = [] } = await chrome.storage.local.get('extractedData');
  extractedData.push({
    ...data,
    extractedAt: new Date().toISOString()
  });
  await chrome.storage.local.set({
    extractedData: extractedData.slice(-100)
  });
}
```

## 常见误区

### 误区一：sendMessage 返回 Promise

`chrome.tabs.sendMessage` 和 `chrome.runtime.sendMessage` 的回调形式是基于回调的，不是原生 Promise。虽然最新版本的 Chrome 已经支持 Promise 化的 API，但为了兼容性，最好用 `await` 或手动封装。

```javascript
// 推荐写法（Chrome 99+）
const response = await chrome.runtime.sendMessage(message);

// 兼容写法
function sendMessage(message) {
  return new Promise((resolve, reject) => {
    chrome.runtime.sendMessage(message, (response) => {
      if (chrome.runtime.lastError) {
        reject(chrome.runtime.lastError);
      } else {
        resolve(response);
      }
    });
  });
}
```

### 误区二：在 content script 中向所有标签页广播

Content script 只能通过 `chrome.runtime.sendMessage` 向 background 发送消息，不能直接访问其他标签页。向所有标签页广播需要 background 中转。

### 误区三：消息处理器中的异步操作没有 return true

如果消息处理器需要异步返回结果，必须 `return true` 告诉 Chrome "我会稍后调用 sendResponse"。否则 sendResponse 会在事件处理器返回后立即失效。

### 误区四：假设消息一定能到达

消息可能因为多种原因失败：content script 未注入、Service Worker 已终止、标签页已关闭等。所有消息发送都应该有错误处理。

## 工程建议

1. **定义消息类型常量**：用常量定义消息类型，避免字符串拼写错误
2. **统一消息格式**：所有消息使用 `{ type, payload }` 格式，便于调试
3. **错误处理全覆盖**：每个 `sendMessage` 都要有 try-catch
4. **合理选择通信方式**：简单请求-响应用 `sendMessage`，持续通信用 `connect`
5. **避免消息风暴**：不要在短时间内发送大量消息，会阻塞主线程

## 小结

消息传递是扩展组件之间通信的唯一方式。一次性消息（`sendMessage`）适合请求-响应模式，长连接端口（`connect`）适合持续通信场景。理解消息的流向、错误处理和异步响应机制，是构建复杂扩展的基础。

### 练习二

**思路**：background 维护端口列表，收到消息后转发给所有已连接的 content script。

**答案**：

```javascript
// background.js
const contentPorts = new Map();

chrome.runtime.onConnect.addListener((port) => {
  if (port.name === 'broadcast') {
    const tabId = port.sender.tab?.id;
    if (tabId) {
      contentPorts.set(tabId, port);
      port.onDisconnect.addListener(() => {
        contentPorts.delete(tabId);
      });
    }

    port.onMessage.addListener((message) => {
      if (message.type === 'BROADCAST') {
        for (const [id, p] of contentPorts) {
          if (id !== tabId) {
            try {
              p.postMessage({
                type: 'BROADCAST_RECEIVED',
                payload: message.payload,
                fromTab: tabId
              });
            } catch {
              contentPorts.delete(id);
            }
          }
        }
      }
    });
  }
});
```

### 练习三

**思路**：维护一个消息队列，在 Service Worker 可用时依次发送。

**答案**：

```javascript
// content.js
class MessageQueue {
  constructor() {
    this.queue = [];
    this.processing = false;
  }

  async send(message) {
    return new Promise((resolve, reject) => {
      this.queue.push({ message, resolve, reject });
      this.processQueue();
    });
  }

  async processQueue() {
    if (this.processing || this.queue.length === 0) return;
    this.processing = true;

    while (this.queue.length > 0) {
      const { message, resolve, reject } = this.queue[0];
      try {
        const response = await this.trySend(message);
        resolve(response);
        this.queue.shift();
      } catch (error) {
        if (error.message.includes('Receiving end does not exist')) {
          await new Promise(r => setTimeout(r, 200));
        } else {
          reject(error);
          this.queue.shift();
        }
      }
    }

    this.processing = false;
  }

  trySend(message) {
    return new Promise((resolve, reject) => {
      chrome.runtime.sendMessage(message, (response) => {
        if (chrome.runtime.lastError) {
          reject(new Error(chrome.runtime.lastError.message));
        } else {
          resolve(response);
        }
      });
    });
  }
}

const messageQueue = new MessageQueue();

// 使用
const result = await messageQueue.send({ type: 'GET_DATA' });
```
