# 阶段一：扩展基础

> 理解浏览器扩展的核心架构，掌握 Manifest V3 规范，完成第一个可运行的扩展项目。

## 学习目标

- 理解浏览器扩展的架构模型与运行机制
- 掌握 Manifest V3 的配置规范
- 熟练使用 Content Script 操作网页 DOM
- 理解 Background Service Worker 的事件驱动模型
- 实现 popup / content script / background 三方通信
- 独立完成一个网页高亮标注工具

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 浏览器扩展是什么 | 扩展架构、Manifest V3、权限模型 |
| 02 | 第一个扩展 | popup、content script、background service worker |
| 03 | Content Script | DOM 操作、注入策略、隔离世界 |
| 04 | Background Service Worker | 事件驱动、生命周期、存储 |
| 05 | 消息通信 | popup/content/background 三方通信 |
| 06 | 阶段实战 | 网页高亮标注工具 |

## 学完本阶段你能做到

独立开发一个具备 popup 界面、Content Script 注入、Background 事件处理和三方通信的完整扩展。
