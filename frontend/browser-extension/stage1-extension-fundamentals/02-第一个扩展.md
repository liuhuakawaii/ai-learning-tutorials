# 第一个扩展

## 场景引入

理解了扩展的架构模型后，是时候动手写一个真正的扩展了。本课将从零开始创建一个完整的扩展，包含 popup 界面、content script 和 background service worker，让你亲身体验这三个核心组件如何协同工作。

我们要构建的是一个"页面信息查看器"：点击扩展图标弹出面板，显示当前页面的标题、链接数量和图片数量。功能虽然简单，但涵盖了扩展开发的核心流程。

## 学习目标

- 从零搭建一个完整的浏览器扩展项目
- 实现 popup 界面的 HTML/CSS/JS
- 编写 Content Script 提取页面信息
- 使用 Background Service Worker 协调数据
- 掌握扩展的加载与调试流程

## 第一步：manifest.json

```json
{
  "manifest_version": 3,
  "name": "页面信息查看器",
  "version": "1.0.0",
  "description": "查看当前页面的基本信息",
  "permissions": ["activeTab"],
  "action": {
    "default_popup": "popup/popup.html",
    "default_icon": {
      "16": "icons/icon16.png",
      "48": "icons/icon48.png",
      "128": "icons/icon128.png"
    }
  },
  "background": {
    "service_worker": "background.js"
  },
  "content_scripts": [
    {
      "matches": ["<all_urls>"],
      "js": ["content/content.js"]
    }
  ]
}
```

这个配置做了三件事：
- 声明一个 popup 面板
- 注册一个 background service worker
- 在所有网页上注入 content script

## 第二步：Content Script

Content Script 是注入到网页中的脚本，它能直接操作页面 DOM。我们用它来提取页面信息：

```javascript
// content/content.js

function getPageInfo() {
  const title = document.title;
  const url = window.location.href;
  const links = document.querySelectorAll('a[href]');
  const images = document.querySelectorAll('img');

  const externalLinks = [];
  const internalLinks = [];

  links.forEach(link => {
    const href = link.href;
    if (href.startsWith(window.location.origin)) {
      internalLinks.push(href);
    } else if (href.startsWith('http')) {
      externalLinks.push(href);
    }
  });

  return {
    title,
    url,
    totalLinks: links.length,
    internalLinks: internalLinks.length,
    externalLinks: externalLinks.length,
    images: images.length,
    brokenImages: [...images].filter(img => !img.complete || img.naturalWidth === 0).length,
    timestamp: new Date().toISOString()
  };
}

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'GET_PAGE_INFO') {
    const info = getPageInfo();
    sendResponse(info);
  }
  return true;
});
```

关键点：
- `chrome.runtime.onMessage` 监听来自 popup 或 background 的消息
- `sendResponse` 回传数据给消息发送方
- `return true` 表示异步响应（虽然这里是同步的，但养成好习惯）

```javascript
// popup/popup.js
document.addEventListener('DOMContentLoaded', async () => {
  const loading = document.getElementById('loading');
  const content = document.getElementById('content');

  try {
    const [tab] = await chrome.tabs.query({
      active: true,
      currentWindow: true
    });

    const response = await chrome.tabs.sendMessage(tab.id, {
      type: 'GET_PAGE_INFO'
    });

    if (response) {
      document.getElementById('title').textContent = response.title || '-';
      document.getElementById('totalLinks').textContent = response.totalLinks;
      document.getElementById('internalLinks').textContent = response.internalLinks;
      document.getElementById('externalLinks').textContent = response.externalLinks;
      document.getElementById('images').textContent = response.images;
      document.getElementById('brokenImages').textContent = response.brokenImages;

      loading.classList.add('hidden');
      content.classList.remove('hidden');
    }
  } catch (error) {
    loading.textContent = '无法获取页面信息，请刷新页面后重试';
    console.error('获取页面信息失败:', error);
  }
});
```

popup.js 的核心流程：
1. 通过 `chrome.tabs.query` 获取当前活跃标签页
2. 通过 `chrome.tabs.sendMessage` 向 content script 发送消息
3. 接收响应并更新 UI

## 第四步：Background Service Worker

background.js 作为扩展的"大脑"，负责监听浏览器事件：

```javascript
// background.js

chrome.runtime.onInstalled.addListener(() => {
  console.log('页面信息查看器已安装');
});

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'LOG_VISIT') {
    console.log(`用户访问了: ${message.url}`);
  }
  return false;
});
```

当前这个简单例子中，background 主要用于扩展生命周期管理。在后续课程中，它会承担更多职责。

## 加载与调试

### Chrome 加载扩展

1. 打开 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择项目文件夹

### 调试 Popup

- 右键扩展图标 → "审查弹出内容" → 打开 DevTools
- 或在 `chrome://extensions/` 页面点击"检查视图"

### 调试 Content Script

- 在目标网页上按 F12 打开 DevTools
- Console 面板顶部的下拉菜单选择扩展的上下文
- 或在 Sources 面板的 "Content scripts" 分组中找到注入的脚本

### 调试 Background

- 在 `chrome://extensions/` 页面点击"检查视图"（Service Worker）
- 注意 Service Worker 可能已被终止，需要触发事件才会重新启动

### 热重载技巧

开发时每次修改代码都需要在 `chrome://extensions/` 页面点击刷新按钮。可以安装 "Extensions Reloader" 扩展，或者使用 WXT/Plasmo 等框架提供的热重载功能。

## 常见误区

### 误区一：Popup 中可以直接访问网页 DOM

Popup 运行在独立的上下文中，无法直接访问任何网页的 DOM。必须通过消息传递与 Content Script 通信。

```javascript
// 错误：在 popup 中直接操作网页 DOM
document.querySelector('h1').textContent; // 这是 popup 自己的 DOM

// 正确：通过消息获取网页信息
const response = await chrome.tabs.sendMessage(tab.id, { type: 'GET_DATA' });
```

### 误区二：Content Script 可以使用网页的全局变量

Content Script 运行在隔离世界中，网页的 `window` 对象上的自定义属性对 Content Script 不可见。

```javascript
// 网页中定义了 window.myApp = { ... }
// Content Script 中访问：
console.log(window.myApp); // undefined
console.log(window.location.href); // 这个可以，因为是浏览器标准 API
```

### 误区三：忘记处理消息响应

`sendMessage` 是异步操作，必须用 `await` 或 `.then()` 处理。如果 content script 没有监听消息，`sendMessage` 会抛出错误。

```javascript
// 必须用 try-catch 包裹
try {
  const response = await chrome.tabs.sendMessage(tab.id, { type: 'PING' });
} catch (error) {
  // Content script 可能未注入（如在 chrome:// 页面上）
  console.log('无法连接到 content script');
}
```

### 误区四：在 Popup 中执行耗时操作

Popup 在关闭时会销毁所有正在执行的脚本。如果需要执行耗时操作，应该交给 Background Service Worker。

## 工程建议

1. **文件按类型分目录**：popup/、content/、background/、icons/ 分开管理
2. **图标准备齐全**：16px（扩展管理页面）、48px（扩展管理页面列表）、128px（安装确认和 Chrome 应用商店）
3. **Popup 宽度适配**：Chrome 限制 popup 最大宽度为 800px，高度为 600px
4. **错误处理要完善**：在 `chrome://` 页面和 Chrome 应用商店等特殊页面上，content script 无法注入
5. **console.log 位置**：popup 的日志在 popup DevTools 中，background 的日志在 Service Worker DevTools 中

## 小结

本课从零搭建了一个完整的浏览器扩展，包含三个核心组件：

- **Content Script**：注入到网页中，负责提取页面信息
- **Popup**：点击图标弹出的 UI 面板，展示信息
- **Background Service Worker**：监听生命周期事件

这三个组件通过消息传递机制协同工作，构成了扩展开发的基础模式。接下来的课程将深入每个组件的高级用法。

## 参考答案

### 练习一

**思路**：在 content script 的 `getPageInfo` 函数中增加新的数据提取逻辑。

**答案**：

```javascript
function getPageInfo() {
  const title = document.title;
  const url = window.location.href;
  const links = document.querySelectorAll('a[href]');
  const images = document.querySelectorAll('img');
  const stylesheets = document.querySelectorAll('link[rel="stylesheet"], style');

  const bodyText = document.body.innerText || '';
  const loadTime = performance.timing
    ? performance.timing.loadEventEnd - performance.timing.navigationStart
    : null;

  return {
    title,
    url,
    totalLinks: links.length,
    images: images.length,
    loadTime,
    stylesheetCount: stylesheets.length,
    charCount: bodyText.length,
    timestamp: new Date().toISOString()
  };
}
```

**要点**：
- `performance.timing` 返回的是毫秒值，需要做差值计算
- `document.body.innerText` 获取纯文本，自动过滤 HTML 标签
- `link[rel="stylesheet"]` 选择外部样式表，`style` 选择内联样式

### 练习二

**思路**：在 popup.js 中捕获错误，根据错误类型显示不同提示。

**答案**：

```javascript
document.addEventListener('DOMContentLoaded', async () => {
  const loading = document.getElementById('loading');

  try {
    const [tab] = await chrome.tabs.query({
      active: true,
      currentWindow: true
    });

    if (!tab.url || tab.url.startsWith('chrome://') || tab.url.startsWith('chrome-extension://')) {
      loading.textContent = '当前页面不支持此扩展';
      loading.style.color = '#e74c3c';
      return;
    }

    const response = await chrome.tabs.sendMessage(tab.id, {
      type: 'GET_PAGE_INFO'
    });

    if (response) {
      // 更新 UI ...
      document.getElementById('loading').classList.add('hidden');
      document.getElementById('content').classList.remove('hidden');
    }
  } catch (error) {
    loading.textContent = '无法连接到页面，请刷新后重试';
    loading.style.color = '#e74c3c';
  }
});
```

**要点**：
- `chrome://` 和 `chrome-extension://` 页面不支持注入脚本
- 检查 `tab.url` 是否存在（某些情况下可能为 undefined）
- 错误信息要对用户友好，不要显示技术细节

### 练习三

**思路**：在 content script 提取信息后，通过 background 将数据存入 storage。

**答案**：

```javascript
// popup.js 中增加存储逻辑
async function saveToHistory(pageInfo) {
  const { history = [] } = await chrome.storage.local.get('history');

  const newEntry = {
    title: pageInfo.title,
    url: pageInfo.url,
    timestamp: pageInfo.timestamp
  };

  const filtered = history.filter(item => item.url !== newEntry.url);
  filtered.unshift(newEntry);

  await chrome.storage.local.set({
    history: filtered.slice(0, 5)
  });
}

async function displayHistory() {
  const { history = [] } = await chrome.storage.local.get('history');
  const historyList = document.getElementById('history');

  if (history.length === 0) {
    historyList.innerHTML = '<p class="empty">暂无历史记录</p>';
    return;
  }

  historyList.innerHTML = history.map(item =>
    `<div class="history-item">
      <span class="history-title">${item.title}</span>
      <span class="history-url">${item.url}</span>
    </div>`
  ).join('');
}
```

**要点**：
- 使用 `chrome.storage.local.get/set` 进行数据持久化
- 先过滤重复 URL，再添加新记录，保持最近 5 条
- 历史列表要在 popup 打开时立即加载
