# AI 摘要扩展

## 场景引入

"这篇文章太长了，能不能帮我总结一下？"——这是 AI 浏览器扩展最常见的需求。用户在浏览长文时，一键生成摘要，快速了解核心内容。

本课将讲解如何集成 LLM API、实现流式输出、处理长文本分块，构建一个实用的 AI 摘要扩展。

## 学习目标

- 掌握在扩展中集成 LLM API 的方式
- 实现流式输出（Streaming）的 UI 展示
- 学会处理长文本的分块策略
- 构建完整的 AI 摘要工作流

## LLM API 集成

### API 调用封装

```javascript
// services/llm.js
class LLMService {
  constructor(apiKey, baseUrl = 'https://api.openai.com/v1') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
  }

  async summarize(text, options = {}) {
    const {
      maxLength = 200,
      language = 'zh-CN',
      style = 'concise'  // 'concise' | 'detailed' | 'bullet'
    } = options;

    const prompt = this.buildPrompt(text, maxLength, language, style);

    const response = await fetch(`${this.baseUrl}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`
      },
      body: JSON.stringify({
        model: options.model || 'gpt-4o-mini',
        messages: [
          { role: 'system', content: '你是一个专业的文本摘要助手。' },
          { role: 'user', content: prompt }
        ],
        max_tokens: maxLength * 2,
        temperature: 0.3
      })
    });

    if (!response.ok) {
      throw new Error(`API 调用失败: ${response.status}`);
    }

    const data = await response.json();
    return data.choices[0].message.content;
  }

  buildPrompt(text, maxLength, language, style) {
    const styleInstructions = {
      concise: `用简洁的语言总结以下内容，控制在 ${maxLength} 字以内。`,
      detailed: `详细总结以下内容，保留关键信息和数据，控制在 ${maxLength * 2} 字以内。`,
      bullet: `用要点列表的形式总结以下内容，每个要点一句话，最多 10 个要点。`
    };

    return `${styleInstructions[style]}

请用 ${language} 回答。

原文：
${text}`;
  }
}
```

### 流式输出

流式输出让用户可以实时看到 AI 生成的内容，体验更好。

```javascript
// services/llm-stream.js
class LLMStreamService {
  constructor(apiKey, baseUrl = 'https://api.openai.com/v1') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
  }

  async *streamSummarize(text, options = {}) {
    const prompt = this.buildPrompt(text, options);

    const response = await fetch(`${this.baseUrl}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`
      },
      body: JSON.stringify({
        model: options.model || 'gpt-4o-mini',
        messages: [
          { role: 'system', content: '你是一个专业的文本摘要助手。' },
          { role: 'user', content: prompt }
        ],
        max_tokens: 1000,
        temperature: 0.3,
        stream: true
      })
    });

    if (!response.ok) {
      throw new Error(`API 调用失败: ${response.status}`);
    }

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop();

      for (const line of lines) {
        if (line.startsWith('data: ')) {
          const data = line.slice(6).trim();
          if (data === '[DONE]') return;

          try {
            const parsed = JSON.parse(data);
            const content = parsed.choices[0]?.delta?.content;
            if (content) {
              yield content;
            }
          } catch {}
        }
      }
    }
  }

  buildPrompt(text, options) {
    const style = options.style || 'concise';
    const language = options.language || 'zh-CN';

    return `请用 ${language} 总结以下内容，风格：${style}

${text}`;
  }
}
```

// content.js
class AISummarizer {
  constructor() {
    this.llmService = null;
    this.setupMessageListener();
  }

  setupMessageListener() {
    chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
      if (message.type === 'SUMMARIZE_PAGE') {
        this.handleSummarize(message.options).then(sendResponse);
        return true;
      }
      if (message.type === 'EXTRACT_AND_SUMMARIZE') {
        this.handleExtractAndSummarize(message.options).then(sendResponse);
        return true;
      }
    });
  }

  async handleSummarize(options) {
    try {
      const article = this.extractArticle();
      if (!article) {
        return { error: '无法提取页面内容' };
      }

      const summary = await this.callBackground({
        type: 'LLM_SUMMARIZE',
        text: article.textContent,
        options
      });

      return { summary, title: article.title };
    } catch (error) {
      return { error: error.message };
    }
  }

  async handleExtractAndSummarize(options) {
    try {
      const article = this.extractArticle();
      if (!article) {
        return { error: '无法提取页面内容' };
      }

      const port = chrome.runtime.connect({ name: 'summarize-stream' });
      let fullText = '';

      port.onMessage.addListener((message) => {
        if (message.type === 'STREAM_CHUNK') {
          fullText += message.chunk;
          this.showStreamingSummary(fullText);
        }
        if (message.type === 'STREAM_END') {
          this.finalizeSummary(fullText);
          port.disconnect();
        }
        if (message.type === 'STREAM_ERROR') {
          this.showError(message.error);
          port.disconnect();
        }

        type: 'START_SUMMARIZE',

## Background 处理流式请求

```javascript
// background.js
chrome.runtime.onConnect.addListener((port) => {
  if (port.name === 'summarize-stream') {
    port.onMessage.addListener(async (message) => {
      if (message.type === 'START_SUMMARIZE') {
        await handleStreamSummarize(port, message.text, message.options);
      }
    });
  }
});

async function handleStreamSummarize(port, text, options) {
  const { apiKey, baseUrl } = await chrome.storage.local.get(['apiKey', 'baseUrl']);

  if (!apiKey) {
    port.postMessage({ type: 'STREAM_ERROR', error: '请先配置 API Key' });
    return;
  }

  const chunks = splitTextIntoChunks(text, 3000);

  try {
    for (const chunk of chunks) {
      const response = await fetch(`${baseUrl || 'https://api.openai.com/v1'}/chat/completions`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${apiKey}`
        },
        body: JSON.stringify({
          model: options.model || 'gpt-4o-mini',
          messages: [
            {
              role: 'system',
              content: '你是一个专业的文本摘要助手。请用简洁的语言总结内容。'
            },
            {
              role: 'user',
              content: `请总结以下内容：\n\n${chunk}`
            }
          ],
          max_tokens: 500,
          temperature: 0.3,
          stream: true
        })
      });

      if (!response.ok) {
        throw new Error(`API 错误: ${response.status}`);
      }

      const reader = response.body.getReader();
      const decoder = new TextDecoder();
      let buffer = '';

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop();

        for (const line of lines) {
          if (line.startsWith('data: ')) {
            const data = line.slice(6).trim();
            if (data === '[DONE]') break;

            try {
              const parsed = JSON.parse(data);
              const content = parsed.choices[0]?.delta?.content;
              if (content) {
                port.postMessage({ type: 'STREAM_CHUNK', chunk: content });
              }
            } catch {}
          }
        }
      }
    }

    port.postMessage({ type: 'STREAM_END' });
  } catch (error) {
    port.postMessage({ type: 'STREAM_ERROR', error: error.message });
  }
}

function splitTextIntoChunks(text, maxChunkSize) {
  const sentences = text.match(/[^。！？.!?]+[。！？.!?]+/g) || [text];
  const chunks = [];
  let currentChunk = '';

  for (const sentence of sentences) {
    if (currentChunk.length + sentence.length > maxChunkSize) {
      if (currentChunk) chunks.push(currentChunk);
      currentChunk = sentence;
    } else {
      currentChunk += sentence;
    }
  }

  if (currentChunk) chunks.push(currentChunk);
  return chunks;
}
```

## 常见误区

### 误区一：在 Content Script 中直接调用 API

Content Script 可以发送网络请求，但 API Key 不应该存储在 Content Script 中。应该通过 Background Service Worker 中转，更安全。

### 误区二：一次性发送所有文本

LLM 有 token 限制（如 4096、8192、128k）。超长文本需要分块处理，然后合并摘要。

### 误区三：忽略 API 错误处理

API 调用可能因为网络问题、配额限制、内容过滤等原因失败。必须有完善的错误处理和用户提示。

### 误区四：流式输出不需要缓冲

SSE（Server-Sent Events）的数据可能被拆分成多个 chunk，需要缓冲处理以避免 JSON 解析错误。

## 工程建议

1. **API Key 安全**：存储在 chrome.storage 中，不要硬编码或暴露给 Content Script
2. **流式输出**：优先使用流式 API，用户体验明显更好
3. **文本分块**：根据模型 token 限制合理分块，避免信息丢失
4. **摘要缓存**：同一页面的摘要结果应该缓存，避免重复调用
5. **模型选择**：摘要任务不需要最强的模型，gpt-4o-mini 就够用

## 小结

AI 摘要扩展的核心是 LLM API 集成和流式输出。通过 Content Script 提取页面内容，Background Service Worker 调用 API 并处理流式响应，实时更新 UI 展示摘要结果。

async function saveSummary(url, title, summary, style) {
  const { summaryHistory = [] } = await chrome.storage.local.get('summaryHistory');

  summaryHistory.unshift({
    id: `summary_${Date.now()}`,
    url,
    title,
    summary,
    style,
    createdAt: new Date().toISOString(),
    favorite: false
  });

  await chrome.storage.local.set({
    summaryHistory: summaryHistory.slice(0, 200)
  });
}

async function searchSummaries(query) {
  const { summaryHistory = [] } = await chrome.storage.local.get('summaryHistory');
  const lowerQuery = query.toLowerCase();

  return summaryHistory.filter(item =>
    item.title.toLowerCase().includes(lowerQuery) ||
    item.summary.toLowerCase().includes(lowerQuery)
  );
}

async function exportSummaries(format = 'markdown') {
  const { summaryHistory = [] } = await chrome.storage.local.get('summaryHistory');

  if (format === 'markdown') {
    let md = '# 摘要历史\n\n';
    summaryHistory.forEach(item => {
      md += `## ${item.title}\n`;
      md += `> ${item.url}\n\n`;
      md += `${item.summary}\n\n`;
      md += `---\n\n`;
    });

    const blob = new Blob([md], { type: 'text/markdown' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = `summaries-${new Date().toISOString().slice(0, 10)}.md`;
    a.click();
  }
}
