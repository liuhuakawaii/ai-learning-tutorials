# 页面内容提取

## 场景引入

AI 浏览器扩展的第一步，是从网页中提取高质量的文本内容。无论是摘要、翻译还是智能搜索，都需要先获取干净、结构化的页面文本。

但网页内容提取远比想象中复杂：页面上有导航栏、侧边栏、广告、评论区等大量"噪音"内容；动态加载的单页应用（SPA）内容在页面加载后才出现；不同网站的 DOM 结构千差万别。如何从这些复杂页面中提取出"正文"？

本课将讲解 DOM 解析策略、Readability 算法和文本清洗技术。

## 学习目标

- 掌握从网页中提取结构化内容的方法
- 理解 Readability 算法的核心思想
- 学会清洗和格式化提取的文本
- 处理动态内容和复杂页面结构

## 基础提取方法

### 获取页面全文

// content.js - 最简单的提取
function getSimpleText() {
  return document.body.innerText;
}

// 去除多余空白
function getCleanText() {
  const text = document.body.innerText;
  return text
    .replace(/\s+/g, ' ')
    .replace(/\n\s*\n/g, '\n\n')

### 提取结构化内容

```javascript
function extractStructuredContent() {
  const content = {
    title: document.title,
    meta: extractMeta(),
    headings: extractHeadings(),
    paragraphs: extractParagraphs(),
    links: extractLinks(),
    images: extractImages()
  };
  return content;
}

function extractMeta() {
  const meta = {};
  document.querySelectorAll('meta').forEach(el => {
    const name = el.getAttribute('name') || el.getAttribute('property');
    const content = el.getAttribute('content');
    if (name && content) {
      meta[name] = content;
    }
  });
  return {
    description: meta['description'] || meta['og:description'] || '',
    author: meta['author'] || '',
    keywords: meta['keywords'] || '',
    publishDate: meta['article:published_time'] || meta['date'] || ''
  };
}

function extractHeadings() {
  return [...document.querySelectorAll('h1, h2, h3, h4, h5, h6')].map(h => ({
    level: parseInt(h.tagName[1]),
    text: h.textContent.trim()
  }));
}

function extractParagraphs() {
  return [...document.querySelectorAll('article p, main p, .content p, .post p')]
    .map(p => p.textContent.trim())
    .filter(text => text.length > 20);
}

function extractLinks() {
  return [...document.querySelectorAll('a[href]')].map(a => ({
    text: a.textContent.trim(),
    href: a.href
  })).filter(link => link.text.length > 0);
}

function extractImages() {
  return [...document.querySelectorAll('article img, main img, .content img')]
    .map(img => ({
      src: img.src,
      alt: img.alt || '',
      width: img.naturalWidth,
      height: img.naturalHeight
    }))
    .filter(img => img.width > 100 && img.height > 100);
}
```

## Readability 算法

Mozilla 的 Readability.js 是最成熟的网页正文提取算法，Firefox 的"阅读模式"就使用了它。

### 核心思想

Readability 算法的核心是**评分系统**：

1. **预处理**：移除 script、style、nav、footer 等非内容元素
2. **候选提取**：找出所有可能包含正文的容器元素（div、article、section 等）
3. **评分**：对每个候选元素打分，考虑因素包括：
   - 文本长度（越长越可能是正文）
   - 段落密度（p 标签占比）
   - 逗号密度（自然语言特征）
   - 正面特征词（article、content、post 等 class/id）
   - 负面特征词（comment、sidebar、ad、footer 等）
4. **选择**：得分最高的元素作为正文容器
5. **清理**：移除容器内的广告、相关文章等噪音内容

### 使用 Readability.js

```javascript
// 安装：npm install @mozilla/readability

// content.js
import Readability from '@mozilla/readability';

function extractArticle() {
  const documentClone = document.cloneNode(true);
  const reader = new Readability(documentClone);
  const article = reader.parse();

  if (!article) return null;

  return {
    title: article.title,
    content: article.content,       // HTML 格式的正文
    textContent: article.textContent, // 纯文本格式的正文
    length: article.length,
    excerpt: article.excerpt,
    byline: article.byline,         // 作者
    siteName: article.siteName,     // 网站名称
    publishedTime: article.publishedTime
  };
}
```

## 文本清洗

提取的原始文本通常需要进一步清洗才能用于 AI 处理。

```javascript
class TextCleaner {
  constructor(options = {}) {
    this.maxLength = options.maxLength || 10000;
    this.removeUrls = options.removeUrls ?? true;
    this.removeEmails = options.removeEmails ?? true;
    this.normalizeWhitespace = options.normalizeWhitespace ?? true;
  }

  clean(text) {
    let cleaned = text;

    // 移除 URL
    if (this.removeUrls) {
      cleaned = cleaned.replace(/https?:\/\/[^\s]+/g, '');
    }

    // 移除邮箱
    if (this.removeEmails) {
      cleaned = cleaned.replace(/[\w.-]+@[\w.-]+\.\w+/g, '');
    }

    // 移除连续的特殊字符
    cleaned = cleaned.replace(/[=\-_*#]{3,}/g, '\n');

    // 移除多余空白
    if (this.normalizeWhitespace) {
      cleaned = cleaned
        .replace(/[ \t]+/g, ' ')
        .replace(/\n{3,}/g, '\n\n')
        .replace(/^\s+|\s+$/gm, '');
    }

    // 截断
    if (cleaned.length > this.maxLength) {
      cleaned = this.truncateAtSentence(cleaned, this.maxLength);
    }

    return cleaned.trim();
  }

  truncateAtSentence(text, maxLength) {
    if (text.length <= maxLength) return text;

    const truncated = text.substring(0, maxLength);
    const lastPeriod = truncated.lastIndexOf('。');
    const lastQuestion = truncated.lastIndexOf('？');
    const lastExcl = truncated.lastIndexOf('！');
    const cutPoint = Math.max(lastPeriod, lastQuestion, lastExcl);

    return cutPoint > maxLength * 0.8
      ? truncated.substring(0, cutPoint + 1)
      : truncated + '...';
  }
}
```

## HTML 转 Markdown

将提取的 HTML 转换为 Markdown 格式，更适合 AI 处理。

```javascript
function htmlToMarkdown(html) {
  const parser = new DOMParser();
  const doc = parser.parseFromString(html, 'text/html');

  function convertNode(node) {
    if (node.nodeType === Node.TEXT_NODE) {
      return node.textContent;
    }

    if (node.nodeType !== Node.ELEMENT_NODE) return '';

    const tag = node.tagName.toLowerCase();
    const children = [...node.childNodes].map(convertNode).join('');

    switch (tag) {
      case 'h1': return `\n# ${children.trim()}\n\n`;
      case 'h2': return `\n## ${children.trim()}\n\n`;
      case 'h3': return `\n### ${children.trim()}\n\n`;
      case 'h4': return `\n#### ${children.trim()}\n\n`;
      case 'p': return `\n${children.trim()}\n\n`;
      case 'strong':
      case 'b': return `**${children.trim()}**`;
      case 'em':
      case 'i': return `*${children.trim()}*`;
      case 'a': return `[${children.trim()}](${node.href || ''})`;
      case 'img': return `![${node.alt || ''}](${node.src || ''})`;
      case 'ul': return `\n${children}\n`;
      case 'ol': return `\n${children}\n`;
      case 'li': return `- ${children.trim()}\n`;
      case 'blockquote': return `\n> ${children.trim()}\n\n`;
      case 'code': return `\`${children.trim()}\``;
      case 'pre': return `\n\`\`\`\n${children.trim()}\n\`\`\`\n\n`;
      case 'br': return '\n';
      case 'hr': return '\n---\n\n';
      default: return children;
    }
  }

  return convertNode(doc.body)
    .replace(/\n{3,}/g, '\n\n')
    .trim();
}
```

## 处理动态内容

现代网站大量使用 JavaScript 动态渲染内容，需要等待内容加载完成。

```javascript
async function waitForContent(selector, timeout = 5000) {
  return new Promise((resolve, reject) => {
    const element = document.querySelector(selector);
    if (element && element.textContent.trim().length > 0) {
      resolve(element);
      return;
    }

    const timer = setTimeout(() => {
      observer.disconnect();
      resolve(document.querySelector(selector));
    }, timeout);

    const observer = new MutationObserver(() => {
      const el = document.querySelector(selector);
      if (el && el.textContent.trim().length > 0) {
        observer.disconnect();
        clearTimeout(timer);
        resolve(el);
      }
    });

    observer.observe(document.body, {
      childList: true,
      subtree: true,
      characterData: true
    });
  });
}

// 等待 SPA 内容加载
async function extractSPAContent() {
  const selectors = ['article', 'main', '.content', '.post', '#content'];

  for (const selector of selectors) {
    const element = await waitForContent(selector, 3000);
    if (element) {
      return {
        html: element.innerHTML,
        text: element.innerText,
        selector
      };
    }
  }

  return {
    html: document.body.innerHTML,
    text: document.body.innerText,
    selector: 'body'
  };
}
```

function extractMetadata() {
  const getMetaContent = (name) => {

  };
}

## JSON-LD 结构化数据

很多网站使用 JSON-LD 格式嵌入结构化数据：

```javascript
function extractJsonLD() {
  const scripts = document.querySelectorAll('script[type="application/ld+json"]');
  const data = [];

  scripts.forEach(script => {
    try {
      const parsed = JSON.parse(script.textContent);
      data.push(parsed);
    } catch {}
  });

  return data;
}

// 提取文章信息
function extractFromJsonLD() {
  const jsonLD = extractJsonLD();
  const article = jsonLD.find(item =>
    item['@type'] === 'Article' ||
    item['@type'] === 'NewsArticle' ||
    item['@type'] === 'BlogPosting'
  );

  if (!article) return null;

  return {
    title: article.headline,
    author: article.author?.name,
    publishDate: article.datePublished,
    modifiedDate: article.dateModified,
    description: article.description,
    image: article.image?.url || article.image,
    publisher: article.publisher?.name
  };
}
```

## 常见误区

### 误区一：document.body.innerText 就够了

`innerText` 包含了页面上所有可见文本，包括导航、侧边栏、广告等噪音。直接使用会导致 AI 处理时浪费 token 且质量差。

### 误区二：Readability 在所有网站上都有效

Readability 对文章类页面效果很好，但对电商页面、社交媒体、论坛等非文章类页面效果较差。需要根据页面类型选择不同的提取策略。

### 误区三：忽略 Shadow DOM 和 iframe

现代网站大量使用 Shadow DOM 和 iframe，标准的 DOM 查询无法穿透这些边界。需要递归处理。

### 误区四：不处理页面编码

某些页面使用非 UTF-8 编码，提取的文本可能出现乱码。`document.characterSet` 可以获取页面编码。

## 工程建议

1. **多策略提取**：先尝试 Readability，失败后回退到启发式提取
2. **文本清洗**：去除 URL、邮箱、多余空白等噪音，提高 AI 处理质量
3. **长度控制**：根据 AI 模型的 token 限制截断文本，在合适的位置断句
4. **缓存结果**：页面内容不会频繁变化，提取结果应该缓存
5. **错误处理**：某些页面可能无法提取任何有意义的内容，要优雅处理

## 小结

页面内容提取是 AI 浏览器扩展的基础能力。Readability 算法是最成熟的正文提取方案，但需要配合文本清洗、动态内容处理和元数据提取，才能获得高质量的输入数据。

function detectPageType() {
  const url = window.location.href;
  const hostname = window.location.hostname;

```javascript
function extractImageDescriptions() {
  const images = document.querySelectorAll('img');
  const descriptions = [];

  images.forEach(img => {
    const desc = {
      src: img.src,
      alt: img.alt || '',
      context: ''
    };

    const figcaption = img.closest('figure')?.querySelector('figcaption');
    if (figcaption) {
      desc.context = figcaption.textContent.trim();
    }

    const parent = img.parentElement;
    if (parent) {
      const sibling = parent.querySelector('p, .caption, .description');
      if (sibling) {
        desc.context = desc.context || sibling.textContent.trim().substring(0, 200);
      }
    }

    if (img.alt || desc.context) {
      descriptions.push(desc);
    }
  });

  return descriptions;
}
```
