# 页面内容提取：如何从任意网页中"读懂"内容

## 当前项目状态

你要做一个 AI 阅读助手扩展：用户在任何网页上点击"总结"按钮，扩展自动提取页面内容，发送给 LLM 生成摘要。第一个问题是：如何从千差万别的网页中提取出干净的正文内容？

## 提取策略

不同网站的 DOM 结构完全不同。你需要多种策略组合：

```
1. <article> / <main> 标签（HTML5 语义化标签）
2. Readability 算法（Mozilla 的阅读模式算法）
3. 自定义选择器（针对特定网站）
4. 正文密度启发式（文本最密集的区域）
```

## Readability 算法

Mozilla 的 Readability.js 是最成熟的方案：

```javascript
import { Readability } from '@mozilla/readability'

function extractContent() {
  const documentClone = document.cloneNode(true)
  const reader = new Readability(documentClone)
  const article = reader.parse()

  if (article) {
    return {
      title: article.title,
      content: article.textContent,
      html: article.content,
      excerpt: article.excerpt,
      author: article.byline
    }
  }
  return null
}
```

## 简化实现

不想引入库的话，用启发式方法：

```javascript
function extractMainContent() {
  // 策略 1：语义化标签
  const article = document.querySelector('article, main, [role="main"]')
  if (article) return article.innerText

  // 策略 2：文本密度最高的 div
  const candidates = document.querySelectorAll('div, section')
  let best = null
  let bestScore = 0

  for (const el of candidates) {
    const text = el.innerText.trim()
    const links = el.querySelectorAll('a')
    const linkText = Array.from(links).reduce((sum, a) => sum + a.textContent.length, 0)
    const textDensity = (text.length - linkText) / text.length

    if (text.length > 200 && textDensity > bestScore) {
      bestScore = textDensity
      best = el
    }
  }

  return best?.innerText || document.body.innerText
}
```

## 清洗 HTML

提取的 HTML 可能包含不需要的元素：

```javascript
function cleanHTML(html) {
  const doc = new DOMParser().parseFromString(html, 'text/html')

  // 移除脚本、样式、广告
  const removeSelectors = [
    'script', 'style', 'iframe', 'noscript',
    '.ad', '.advertisement', '.social-share',
    'nav', 'footer', 'header'
  ]

  removeSelectors.forEach(selector => {
    doc.querySelectorAll(selector).forEach(el => el.remove())
  })

  // 移除空元素
  doc.querySelectorAll('*').forEach(el => {
    if (el.textContent.trim() === '' && el.tagName !== 'BR' && el.tagName !== 'IMG') {
      el.remove()
    }
  })

  return doc.body.innerHTML
}
```

## 针对特定网站的优化

```javascript
const SITE_SELECTORS = {
  'github.com': {
    content: '.markdown-body',
    title: '.js-issue-title'
  },
  'medium.com': {
    content: 'article',
    title: 'h1'
  },
  'stackoverflow.com': {
    content: '.js-post-body',
    title: '.question-hyperlink'
  }
}

function extractForSite() {
  const hostname = window.location.hostname.replace('www.', '')
  const selectors = SITE_SELECTORS[hostname]

  if (selectors) {
    const content = document.querySelector(selectors.content)
    const title = document.querySelector(selectors.title)
    return {
      title: title?.textContent || document.title,
      content: content?.innerText || ''
    }
  }

  return extractMainContent()
}
```

## 你可能踩的坑

**坑一：Content Script 的 DOM 是实时的**

如果页面正在动态加载（SPA），提取时内容可能不完整。等 `document.readyState === 'complete'` 再提取。

**坑二：iframe 中的内容**

Content Script 默认只注入主页面。iframe 中的内容需要单独处理。

**坑三：Shadow DOM**

现代网站越来越多使用 Shadow DOM。标准 DOM 查询无法穿透 Shadow 边界。

```javascript
function detectPageType() {
  const url = window.location.href
  if (url.includes('/article/') || url.includes('/post/') || url.includes('/blog/'))
    return 'article'
  if (url.includes('/product/') || url.includes('/item/'))
    return 'product'
  if (url.includes('/question/') || url.includes('/thread/'))
    return 'forum'
  if (document.querySelector('video'))
    return 'video'

  // 启发式判断
  const article = document.querySelector('article')
  if (article && article.innerText.length > 500) return 'article'

  return 'unknown'
}
```

```javascript
function scoreExtraction(text) {
  let score = 0
  if (text.length > 200) score += 20
  if (text.length > 1000) score += 20
  const paragraphs = text.split(/\n\s*\n/).length
  if (paragraphs > 3) score += 20
  const linkDensity = (text.match(/https?:\/\//g) || []).length / text.length
  if (linkDensity < 0.01) score += 20
  if (!text.includes('cookie') && !text.includes('subscribe')) score += 20
  return score
}
```
