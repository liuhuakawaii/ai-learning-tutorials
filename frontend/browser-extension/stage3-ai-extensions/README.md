# 阶段三：AI 浏览器扩展

> 将 AI 能力集成到浏览器扩展中，实现页面内容提取、智能摘要、翻译、写作助手等 AI 驱动功能。

## 学习目标

- 从网页中高效提取和清洗结构化内容
- 集成 LLM API 实现流式输出的 AI 摘要
- 构建划词翻译和全页翻译功能
- 开发写作助手（内容生成、语法检查、改写）
- 实现基于语义的智能搜索
- 独立完成一个 AI 阅读助手扩展

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 页面内容提取 | DOM 解析、Readability、文本清洗 |
| 02 | AI 摘要扩展 | LLM API 集成、流式显示 |
| 03 | 翻译扩展 | 划词翻译、全页翻译 |
| 04 | 写作助手 | 内容生成、语法检查、改写 |
| 05 | 智能搜索 | 语义搜索、知识图谱 |
| 06 | 阶段实战 | AI 阅读助手 |

## 学完本阶段你能做到

构建具备 AI 能力的浏览器扩展，实现内容提取、摘要、翻译、写作辅助等智能功能。
