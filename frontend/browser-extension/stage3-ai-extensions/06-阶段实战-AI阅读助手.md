# 阶段实战：AI 阅读助手——从页面提取到 LLM 摘要

## 当前项目状态

前五课学了内容提取、LLM API 集成、翻译、写作助手和语义搜索。本课把它们整合成一个完整的 AI 阅读助手扩展：用户在任何网页上点击"总结"，扩展提取内容、调用 LLM、在侧边栏展示摘要和关键点。

## 功能规划

```
AI 阅读助手
├── 一键总结：提取页面内容 → LLM 生成摘要
├── 关键点提取：提取 3-5 个核心观点
├── 翻译：整页翻译或选中翻译
├── 问答：针对页面内容提问
├── 历史记录：保存阅读历史和摘要
└── 侧边栏：展示所有 AI 功能的输出
```

## 内容提取

```javascript
// content.js
class ContentExtractor {
  extract() {
    // 优先用语义化标签
    const article = document.querySelector('article, main, [role="main"]')
    if (article && article.innerText.length > 300) {
      return this.clean(article.innerText)
    }

    // 回退到正文密度启发式
    return this.clean(this.extractByDensity())
  }

  extractByDensity() {
    const candidates = document.querySelectorAll('div, section')
    let best = null, bestScore = 0

    for (const el of candidates) {
      const text = el.innerText.trim()
      if (text.length < 200) continue
      const links = el.querySelectorAll('a')
      const linkText = Array.from(links).reduce((s, a) => s + a.textContent.length, 0)
      const density = (text.length - linkText) / text.length
      if (density > bestScore) { bestScore = density; best = el }
    }
    return best?.innerText || document.body.innerText
  }

  clean(text) {
    return text
      .replace(/\s+/g, ' ')
      .replace(/\n{3,}/g, '\n\n')
      .trim()
      .substring(0, 8000) // LLM 上下文限制
  }
}
```

## LLM 集成

```javascript
// background.js
class LLMService {
  constructor(apiKey) {
    this.apiKey = apiKey
    this.baseURL = 'https://api.openai.com/v1'
  }

  async summarize(content) {
    const response = await fetch(`${this.baseURL}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`
      },
      body: JSON.stringify({
        model: 'gpt-4o-mini',
        messages: [
          {
            role: 'system',
            content: '你是一个阅读助手。请用中文总结以下内容，提取3-5个关键点。输出格式：\n## 摘要\n...\n## 关键点\n1. ...\n2. ...'
          },
          { role: 'user', content }
        ],
        max_tokens: 1000,
        stream: true
      })
    })

    return this.handleStream(response)
  }

  async *handleStream(response) {
    const reader = response.body.getReader()
    const decoder = new TextDecoder()

    while (true) {
      const { done, value } = await reader.read()
      if (done) break

      const chunk = decoder.decode(value)
      const lines = chunk.split('\n').filter(l => l.startsWith('data: '))

      for (const line of lines) {
        const data = line.slice(6)
        if (data === '[DONE]') return

        try {
          const json = JSON.parse(data)
          const content = json.choices[0]?.delta?.content
          if (content) yield content
        } catch {}
      }
    }
  }

  async ask(content, question) {
    const response = await fetch(`${this.baseURL}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`
      },
      body: JSON.stringify({
        model: 'gpt-4o-mini',
        messages: [
          {
            role: 'system',
            content: `基于以下文章回答问题。如果文章中没有相关信息，请说明。\n\n文章内容：\n${content}`
          },
          { role: 'user', content: question }
        ],
        max_tokens: 500
      })
    })

    const data = await response.json()
    return data.choices[0].message.content
  }
}
```

## 侧边栏 UI

```javascript
// sidepanel.js
class SidebarUI {
  constructor() {
    this.resultEl = document.getElementById('result')
    this.inputEl = document.getElementById('question-input')
  }

  showLoading() {
    this.resultEl.innerHTML = '<div class="loading">正在分析...</div>'
  }

  async streamSummary(stream) {
    this.resultEl.innerHTML = ''
    let fullText = ''

    for await (const chunk of stream) {
      fullText += chunk
      this.resultEl.innerHTML = this.renderMarkdown(fullText)
      this.resultEl.scrollTop = this.resultEl.scrollHeight
    }

    return fullText
  }

  showAnswer(answer) {
    const div = document.createElement('div')
    div.className = 'answer'
    div.innerHTML = `<h4>回答</h4><p>${answer}</p>`
    this.resultEl.appendChild(div)
  }

  renderMarkdown(text) {
    return text
      .replace(/## (.+)/g, '<h3>$1</h3>')
      .replace(/\d+\. (.+)/g, '<li>$1</li>')
      .replace(/\n/g, '<br>')
  }
}
```

## 完整工作流

```javascript
// background.js
chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  if (msg.type === 'SUMMARIZE') {
    handleSummarize(msg.content, sender.tab.id)
  }
  if (msg.type === 'ASK') {
    handleAsk(msg.content, msg.question, sender.tab.id)
  }
  return true
})

async function handleSummarize(content, tabId) {
  const apiKey = await getApiKey()
  if (!apiKey) {
    chrome.tabs.sendMessage(tabId, { type: 'ERROR', message: '请先配置 API Key' })
    return
  }

  const llm = new LLMService(apiKey)
  const stream = await llm.summarize(content)

  chrome.tabs.sendMessage(tabId, { type: 'STREAM_START' })
  for await (const chunk of stream) {
    chrome.tabs.sendMessage(tabId, { type: 'STREAM_CHUNK', chunk })
  }
  chrome.tabs.sendMessage(tabId, { type: 'STREAM_END' })
}
```

## 你可能踩的坑

**坑一：内容太长超出上下文限制**

网页内容可能有几万字。需要截断到 LLM 的上下文窗口内（通常 8000-16000 字符）。

**坑二：API Key 安全**

不要在 Content Script 中存储 API Key。只在 Background Service Worker 中使用，用 chrome.storage.session 存储。

**坑三：流式输出中断**

用户切换标签页或关闭侧边栏时，流式输出需要正确中断和清理。

### 练习二

```javascript
async function saveToHistory(url, title, summary) {
  const { history = [] } = await chrome.storage.local.get('history')
  history.unshift({
    url, title, summary,
    readAt: new Date().toISOString()
  })
  // 保留最近 100 条
  await chrome.storage.local.set({ history: history.slice(0, 100) })
}

async function renderHistory() {
  const { history = [] } = await chrome.storage.local.get('history')
  return history.map(item => `
    <div class="history-item">
      <a href="${item.url}" target="_blank">${item.title}</a>
      <p>${item.summary.substring(0, 100)}...</p>
      <span>${new Date(item.readAt).toLocaleDateString()}</span>
    </div>
  `).join('')
}
```
