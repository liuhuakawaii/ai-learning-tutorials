# 毕业项目：AI 阅读助手扩展

## 项目概述

本项目是浏览器扩展开发课程的毕业项目。你需要综合运用全部 5 个阶段所学的知识，独立完成一个功能完整的 AI 阅读助手浏览器扩展。

## 项目目标

构建一个跨浏览器（Chrome/Firefox/Edge）的 AI 阅读助手扩展，具备以下核心能力：

1. **页面内容提取**：使用 Readability 算法提取网页正文
2. **AI 摘要**：集成 LLM API 生成文章摘要
3. **划词翻译**：选中文本即时翻译
4. **阅读笔记**：记录和管理阅读笔记
5. **阅读模式**：干净的阅读视图
6. **数据持久化**：阅读历史、笔记、设置的持久化存储

## 功能需求

### 核心功能（必须完成）

| 功能 | 描述 | 对应阶段 |
|------|------|----------|
| 页面内容提取 | 使用 Readability 提取正文 | 阶段 3 |
| AI 摘要 | 一键生成文章摘要（简洁/详细/要点） | 阶段 3 |
| 划词翻译 | 选中文本弹出翻译结果 | 阶段 3 |
| 阅读笔记 | 添加、查看、删除笔记 | 阶段 1 |
| 阅读模式 | 干净的阅读视图 | 阶段 4 |
| Popup 面板 | 扩展主界面 | 阶段 1 |
| 消息通信 | popup/content/background 三方通信 | 阶段 1 |
| 数据存储 | chrome.storage 持久化 | 阶段 2 |

### 扩展功能（加分项）

| 功能 | 描述 | 对应阶段 |
|------|------|----------|
| Side Panel | 侧边栏展示阅读内容 | 阶段 2 |
| 右键菜单 | 右键翻译/摘要/保存 | 阶段 2 |
| 阅读统计 | 阅读时间、文章数统计 | 阶段 5 |
| 语义搜索 | 搜索已读文章 | 阶段 3 |
| 多浏览器兼容 | Chrome/Firefox/Edge | 阶段 4 |
| 自动化测试 | Puppeteer E2E 测试 | 阶段 4 |

## 技术要求

### 技术栈

- **语言**：JavaScript 或 TypeScript
- **规范**：Manifest V3
- **框架**：可选 WXT / Plasmo，或纯原生
- **AI API**：OpenAI / Claude / 其他 LLM API

## 验证要求

完成项目后，运行验证脚本确保项目结构和功能完整：

```bash
node scripts/check.cjs
```

验证脚本会检查：
- 必需文件是否存在
- manifest.json 配置是否正确
- 关键功能模块是否实现

## 学习建议

1. **先完成核心功能**：确保核心功能稳定后再添加扩展功能
2. **分阶段开发**：按照 5 个阶段的顺序逐步实现
3. **多测试**：在不同浏览器和不同网站上测试
4. **参考课程内容**：每个功能的实现方式在对应课程中有详细讲解
