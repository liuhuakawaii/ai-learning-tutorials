# 标签页管理

## 场景引入

浏览器的核心交互单位是标签页。用户可能同时打开几十个标签页，在不同的页面之间切换。扩展经常需要知道用户当前在看什么页面、打开新标签页、获取其他标签页的信息、甚至批量操作多个标签页。

`chrome.tabs` API 提供了完整的标签页管理能力。配合 `chrome.windows` API，你可以构建标签页管理器、会话保存器、批量操作工具等实用扩展。

## 学习目标

- 掌握 chrome.tabs 的核心 API
- 学会查询和操作标签页
- 理解标签页事件监听
- 实现标签页分组和管理功能

## 查询标签页

```javascript
// 获取当前活跃标签页
const [activeTab] = await chrome.tabs.query({
  active: true,
  currentWindow: true
});
console.log('当前标签页:', activeTab.url, activeTab.title);

// 获取所有标签页
const allTabs = await chrome.tabs.query({});
console.log('所有标签页数量:', allTabs.length);

// 按条件查询
const githubTabs = await chrome.tabs.query({
  url: '*://github.com/*'
});
console.log('GitHub 标签页:', githubTabs.length);

// 获取当前窗口的所有标签页
const currentWindowTabs = await chrome.tabs.query({
  currentWindow: true
});
```

## 操作标签页

### 创建标签页

```javascript
// 创建新标签页
const tab = await chrome.tabs.create({
  url: 'https://example.com'
});

// 在指定位置创建
const tab2 = await chrome.tabs.create({
  url: 'https://example.com',
  index: 0,        // 放在最前面
  active: true,    // 切换到新标签页
  pinned: false
});

// 创建但不切换
const backgroundTab = await chrome.tabs.create({
  url: 'https://example.com',
  active: false
});
```

### 更新标签页

```javascript
// 更新 URL
await chrome.tabs.update(tabId, {
  url: 'https://new-url.com'
});

// 切换到该标签页
await chrome.tabs.update(tabId, {
  active: true
});

// 固定/取消固定
await chrome.tabs.update(tabId, {
  pinned: true
});

// 静音
await chrome.tabs.update(tabId, {
  muted: true
});
```

### 关闭标签页

```javascript
// 关闭单个标签页
await chrome.tabs.remove(tabId);

// 关闭多个标签页
await chrome.tabs.remove([tabId1, tabId2, tabId3]);
```

### 移动标签页

```javascript
// 移动到窗口最前面
await chrome.tabs.move(tabId, { index: 0 });

// 移动到另一个窗口
await chrome.tabs.move(tabId, {
  windowId: targetWindowId,
  index: 0
});
```

## 执行脚本

在标签页中执行脚本是扩展最常见的操作之一：

```javascript
// 注入脚本文件
const results = await chrome.scripting.executeScript({
  target: { tabId },
  files: ['content.js']
});

// 注入函数
const results = await chrome.scripting.executeScript({
  target: { tabId },
  func: (selector) => {
    return document.querySelector(selector)?.textContent;
  },
  args: ['h1']
});

// 获取执行结果
console.log('脚本返回值:', results[0].result);

// 注入到多个标签页
const allTabs = await chrome.tabs.query({ url: '*://example.com/*' });
for (const tab of allTabs) {
  await chrome.scripting.executeScript({
    target: { tabId: tab.id },
    files: ['content.js']
  });
}
```

chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => {
  // changeInfo 包含变化的属性
  if (changeInfo.status === 'loading') {

## 实战：标签页管理器

```javascript
// background.js
class TabManager {
  constructor() {
    this.setupListeners();
  }

  setupListeners() {
    chrome.tabs.onCreated.addListener(tab => this.onTabCreated(tab));
    chrome.tabs.onRemoved.addListener(id => this.onTabRemoved(id));
    chrome.tabs.onUpdated.addListener((id, info, tab) => this.onTabUpdated(id, info, tab));
    chrome.tabs.onActivated.addListener(info => this.onTabActivated(info));
  }

  onTabCreated(tab) {
    console.log('新标签页:', tab.url || '空白页');
  }

  onTabRemoved(tabId) {
    console.log('标签页关闭:', tabId);
  }

  onTabUpdated(tabId, changeInfo, tab) {
    if (changeInfo.status === 'complete') {
      this.updateBadge();
    }
  }

  onTabActivated(activeInfo) {
    console.log('活跃标签页:', activeInfo.tabId);
  }

  async updateBadge() {
    const tabs = await chrome.tabs.query({});
    chrome.action.setBadgeText({ text: String(tabs.length) });
    chrome.action.setBadgeBackgroundColor({ color: '#1a73e8' });
  }

  async getTabGroups() {
    const tabs = await chrome.tabs.query({ currentWindow: true });
    const domains = {};

    tabs.forEach(tab => {
      if (!tab.url) return;
      try {
        const domain = new URL(tab.url).hostname;
        if (!domains[domain]) domains[domain] = [];
        domains[domain].push(tab);
      } catch {}
    });

    return domains;
  }

  async closeDuplicates() {
    const tabs = await chrome.tabs.query({});
    const seen = new Set();
    const duplicates = [];

    tabs.forEach(tab => {
      if (tab.url && seen.has(tab.url)) {
        duplicates.push(tab.id);
      } else {
        seen.add(tab.url);
      }
    });

    if (duplicates.length > 0) {
      await chrome.tabs.remove(duplicates);
    }

    return duplicates.length;
  }

  async suspendInactive() {
    const tabs = await chrome.tabs.query({
      active: false,
      currentWindow: true
    });

    for (const tab of tabs) {
      if (tab.url && !tab.url.startsWith('chrome://')) {
        await chrome.tabs.discard(tab.id);
      }
    }
  }
}

const tabManager = new TabManager();
```

## 常见误区

### 误区一：所有标签页都有 URL

某些标签页（如新标签页、chrome:// 页面）的 `url` 属性可能为空或受限。访问这些 URL 需要特殊权限。

### 误区二：tabs.query 返回所有标签页

默认情况下 `tabs.query({})` 只返回扩展有权限访问的标签页。要获取所有标签页，需要 `"tabs"` 权限。

### 误区三：onUpdated 会为每个变化触发一次

`onUpdated` 可能对同一个标签页触发多次（loading → complete），需要根据 `changeInfo` 判断具体变化。

### 误区四：chrome.tabs.discard 会关闭标签页

`chrome.tabs.discard` 会释放标签页的内存，但保留标签页。刷新后内容会重新加载。

## 工程建议

1. **谨慎使用 tabs 权限**：`activeTab` 通常足够，`tabs` 权限会暴露所有标签页的 URL
2. **批量操作注意性能**：大量标签页操作时使用 `Promise.all` 或分批处理
3. **处理特殊页面**：`chrome://`、`chrome-extension://` 等页面无法注入脚本
4. **标签页 ID 有效期**：标签页关闭后 ID 失效，不要长期持有
5. **事件去重**：`onUpdated` 可能多次触发，使用 debounce 或状态检查避免重复处理

## 小结

`chrome.tabs` 和 `chrome.windows` API 提供了完整的浏览器标签页管理能力。掌握查询、操作、事件监听和分组管理，可以构建标签页管理器、会话恢复器等实用工具。

### 练习二

**答案**：

```javascript
// background.js
async function findDuplicates() {
  const tabs = await chrome.tabs.query({});
  const urlMap = new Map();
  const duplicates = [];

  tabs.forEach(tab => {
    if (!tab.url || tab.url.startsWith('chrome://')) return;

    if (urlMap.has(tab.url)) {
      duplicates.push(tab);
    } else {
      urlMap.set(tab.url, tab);
    }
  });

  return duplicates;
}

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'FIND_DUPLICATES') {
    findDuplicates().then(duplicates => {
      sendResponse({
        count: duplicates.length,
        tabs: duplicates.map(t => ({ id: t.id, title: t.title, url: t.url }))
      });
    });
    return true;
  }

  if (message.type === 'CLOSE_DUPLICATES') {
    findDuplicates().then(async duplicates => {
      await chrome.tabs.remove(duplicates.map(t => t.id));
      sendResponse({ closed: duplicates.length });
    });
    return true;
  }
});
```

### 练习三

**答案**：

```javascript
// background.js
async function saveSnapshot(name) {
  const tabs = await chrome.tabs.query({ currentWindow: true });
  const snapshot = {
    name: name || `快照 ${new Date().toLocaleString()}`,
    createdAt: new Date().toISOString(),
    tabs: tabs.map(t => ({
      url: t.url,
      title: t.title,
      pinned: t.pinned,
      index: t.index
    }))
  };

  const { snapshots = [] } = await chrome.storage.local.get('snapshots');
  snapshots.push(snapshot);
  await chrome.storage.local.set({ snapshots });

  return snapshot;
}

async function restoreSnapshot(snapshotIndex) {
  const { snapshots = [] } = await chrome.storage.local.get('snapshots');
  const snapshot = snapshots[snapshotIndex];
  if (!snapshot) return;

  for (const tab of snapshot.tabs) {
    await chrome.tabs.create({
      url: tab.url,
      pinned: tab.pinned,
      active: false
    });
  }
}

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'SAVE_SNAPSHOT') {
    saveSnapshot(message.name).then(sendResponse);
    return true;
  }
  if (message.type === 'RESTORE_SNAPSHOT') {
    restoreSnapshot(message.index).then(() => sendResponse({ success: true }));
    return true;
  }
  if (message.type === 'GET_SNAPSHOTS') {
    chrome.storage.local.get('snapshots').then(sendResponse);
    return true;
  }
});
```
