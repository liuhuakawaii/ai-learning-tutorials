# 右键菜单与通知

## 场景引入

右键菜单（Context Menu）是浏览器中最自然的交互方式之一。用户选中一段文字，右键点击，看到"翻译选中文本"、"搜索选中内容"等选项——这些功能都来自浏览器扩展。

系统通知（Notification）则是在浏览器后台向用户推送信息的方式。当监控的价格变化、定时任务完成、或需要用户注意时，一条通知可以及时触达用户。

本课将系统讲解这两个 API 的使用方式和最佳实践。

## 学习目标

- 掌握 chrome.contextMenus 的创建和管理
- 理解不同上下文类型的右键菜单
- 学会使用 chrome.notifications 推送系统通知
- 实现菜单和通知的联动功能

## 右键菜单

### 基础创建

```javascript
// background.js - 在 onInstalled 中创建菜单
chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({
    id: 'search-selection',
    title: '搜索 "%s"',
    contexts: ['selection']
  });
});
```

`contexts` 决定菜单在什么情况下显示：

| 值 | 显示时机 |
|-----|---------|
| `selection` | 选中文本时 |
| `link` | 右键点击链接时 |
| `image` | 右键点击图片时 |
| `page` | 右键点击页面空白处时 |
| `editable` | 右键点击输入框时 |
| `video` / `audio` | 右键点击媒体元素时 |
| `frame` | 右键点击 iframe 时 |
| `all` | 所有情况 |

### 处理点击事件

```javascript
chrome.contextMenus.onClicked.addListener(async (info, tab) => {
  switch (info.menuItemId) {
    case 'search-selection':
      const query = info.selectionText;
      await chrome.tabs.create({
        url: `https://www.google.com/search?q=${encodeURIComponent(query)}`
      });
      break;

    case 'translate':
      await translateText(info.selectionText, tab.id);
      break;

    case 'save-link':
      await saveLink({
        url: info.linkUrl,
        text: info.linkText
      });
      break;

    case 'save-image':
      await saveImage(info.srcUrl);
      break;
  }
});

async function translateText(text, tabId) {
  const translated = await callTranslationAPI(text);
  chrome.tabs.sendMessage(tabId, {
    type: 'SHOW_TRANSLATION',
    original: text,
    translated
  });
}
```

### 动态更新菜单

```javascript
async function updateMenuState() {
  const { enabled } = await chrome.storage.local.get('enabled');

  chrome.contextMenus.update('my-tools', {
    title: enabled ? '我的工具 ✓' : '我的工具'
  });
}

chrome.storage.onChanged.addListener((changes) => {
  if (changes.enabled) {
    updateMenuState();
  }
});
```

### 删除菜单

```javascript
// 删除单个菜单

// 删除所有菜单
chrome.contextMenus.removeAll();
```

## 系统通知

### 基础通知

```javascript
chrome.notifications.create({
  type: 'basic',
  iconUrl: 'icons/icon128.png',
  title: '任务完成',
  message: '所有页面已处理完毕',

});
```

### 通知类型

```javascript
// 基础通知
chrome.notifications.create('basic-notification', {

// 列表通知
chrome.notifications.create('list-notification', {
  type: 'list',

  items: [
    { title: '消息 1', message: '来自用户 A' },
    { title: '消息 2', message: '来自用户 B' },
    { title: '消息 3', message: '来自用户 C' }
  ]
});

// 进度通知
chrome.notifications.create('progress-notification', {
  type: 'progress',
  iconUrl: 'icons/icon128.png',
  title: '下载中',
  message: '正在处理...',
  progress: 0
});

// 更新进度
chrome.notifications.update('progress-notification', {
  progress: 50,
  message: '处理中 50%...'
});
```

### 处理通知事件

```javascript
// 点击通知
chrome.notifications.onClicked.addListener((notificationId) => {
  switch (notificationId) {
    case 'task-complete':
      chrome.tabs.create({ url: 'result.html' });
      break;
  }
  chrome.notifications.clear(notificationId);
});

// 点击通知按钮
chrome.notifications.onButtonClicked.addListener((notificationId, buttonIndex) => {
  if (notificationId === 'new-message') {
    if (buttonIndex === 0) {
      // "查看详情"
      chrome.tabs.create({ url: 'messages.html' });
    } else {
      // "忽略"
      chrome.notifications.clear(notificationId);
    }
  }
});

// 通知关闭
chrome.notifications.onClosed.addListener((notificationId, byUser) => {
  console.log(`通知 ${notificationId} 关闭，用户操作: ${byUser}`);
});
```

## 菜单与通知联动

一个完整的场景：用户右键选中文本，选择"翻译"，翻译完成后推送通知。

```javascript
// background.js
chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({
    id: 'translate-selection',
    title: '翻译 "%s"',
    contexts: ['selection']
  });
});

chrome.contextMenus.onClicked.addListener(async (info, tab) => {
  if (info.menuItemId === 'translate-selection') {
    const text = info.selectionText;

    chrome.notifications.create('translating', {
      type: 'progress',
      iconUrl: 'icons/icon128.png',
      title: '翻译中',
      message: `正在翻译: ${text.substring(0, 30)}...`,
      progress: 0
    });

    try {
      const result = await translateText(text);

      chrome.notifications.create('translation-done', {
        type: 'basic',
        iconUrl: 'icons/icon128.png',
        title: '翻译完成',
        message: result.translatedText.substring(0, 100),
        buttons: [{ title: '复制结果' }],
        requireInteraction: true
      });

      chrome.notifications.clear('translating');

      await chrome.storage.local.set({
        lastTranslation: {
          original: text,
          translated: result.translatedText,
          timestamp: Date.now()
        }
      });
    } catch (error) {
      chrome.notifications.create('translation-error', {
        type: 'basic',
        iconUrl: 'icons/icon128.png',
        title: '翻译失败',
        message: error.message
      });
      chrome.notifications.clear('translating');
    }
  }
});

async function translateText(text) {
  const response = await fetch('https://api.example.com/translate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text, target: 'zh-CN' })
  });
  return response.json();
}
```

## 常见误区

### 误区一：右键菜单可以在 content script 中创建

`chrome.contextMenus` 只能在 background service worker 中使用。Content script 无法创建菜单。

### 误区二：通知需要 activeTab 权限

`chrome.notifications` 需要 `"notifications"` 权限，不是 `activeTab`。它与标签页无关。

### 误区三：菜单项创建后不能修改

可以通过 `chrome.contextMenus.update()` 修改菜单的 title、checked 等属性。但不能修改 `parentId` 和 `contexts`。

### 误区四：通知创建后会一直显示

通知默认会自动消失。设置 `requireInteraction: true` 可以保持显示，但用户仍然可以手动关闭。

## 工程建议

1. **菜单 ID 语义化**：使用有意义的 ID，便于事件处理和调试
2. **合理使用 contexts**：不要在所有上下文中都显示菜单，会干扰用户
3. **通知频率控制**：不要频繁发送通知，会让用户关闭通知权限
4. **通知内容简洁**：标题和消息要简短明了，详细内容通过按钮跳转
5. **清理旧菜单**：扩展更新时清理不再需要的菜单项

## 小结

右键菜单和系统通知是扩展与用户交互的重要方式。菜单提供了上下文感知的操作入口，通知提供了后台事件的触达能力。合理使用这两个 API 可以显著提升扩展的用户体验。

### 练习二

**答案**：

```javascript
// background.js
class NotificationManager {
  constructor() {
    this.queue = [];
    this.isShowing = false;
    this.maxVisible = 3;
  }

  async show(options) {
    const { notificationPrefs = { enabled: true } } =
      await chrome.storage.local.get('notificationPrefs');

    if (!notificationPrefs.enabled) return;

    if (this.isShowing) {
      this.queue.push(options);
      return;
    }

    this.isShowing = true;
    const id = `notif_${Date.now()}`;

    await chrome.notifications.create(id, {
      type: 'basic',
      iconUrl: 'icons/icon128.png',
      ...options
    });

    await this.saveToHistory(id, options);

    setTimeout(() => {
      this.isShowing = false;
      this.processQueue();
    }, 1000);
  }

  processQueue() {
    if (this.queue.length > 0) {
      const next = this.queue.shift();
      this.show(next);
    }
  }

  async saveToHistory(id, options) {
    const { notifHistory = [] } = await chrome.storage.local.get('notifHistory');
    notifHistory.unshift({
      id,
      title: options.title,
      message: options.message,
      timestamp: Date.now()
    });
    await chrome.storage.local.set({
      notifHistory: notifHistory.slice(0, 100)
    });
  }
}

const notifManager = new NotificationManager();
```

### 练习三

**答案**：

```javascript
// background.js
chrome.runtime.onInstalled.addListener(() => {
  chrome.alarms.create('check-reminders', { periodInMinutes: 0.5 });
});

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'SET_REMINDER') {
    setReminder(message.delayMinutes, message.text).then(sendResponse);
    return true;
  }
  if (message.type === 'GET_REMINDERS') {
    chrome.storage.local.get('reminders').then(sendResponse);
    return true;
  }
});

async function setReminder(delayMinutes, text) {
  const { reminders = [] } = await chrome.storage.local.get('reminders');
  const reminder = {
    id: `reminder_${Date.now()}`,
    text,
    triggerAt: Date.now() + delayMinutes * 60 * 1000,
    createdAt: Date.now()
  };

  reminders.push(reminder);
  await chrome.storage.local.set({ reminders });
  return { success: true, reminder };
}

chrome.alarms.onAlarm.addListener(async (alarm) => {
  if (alarm.name !== 'check-reminders') return;

  const { reminders = [] } = await chrome.storage.local.get('reminders');
  const now = Date.now();
  const due = reminders.filter(r => r.triggerAt <= now);

  for (const reminder of due) {
    chrome.notifications.create(reminder.id, {
      type: 'basic',
      iconUrl: 'icons/icon128.png',
      title: '提醒',
      message: reminder.text,
      requireInteraction: true
    });
  }

  const remaining = reminders.filter(r => r.triggerAt > now);
  await chrome.storage.local.set({ reminders: remaining });
});
```
