# 阶段二：高级 API

> 深入 Chrome Extensions 高级 API，掌握存储、网络拦截、标签页管理等核心能力，构建功能丰富的扩展。

## 学习目标

- 熟练使用 chrome.storage 三种存储模式
- 掌握 declarativeNetRequest 网络拦截与修改
- 管理标签页与窗口的完整生命周期
- 实现右键菜单与系统通知
- 构建侧边栏面板与 DevTools 扩展
- 独立完成一个 API 聚合面板扩展

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 存储 API | chrome.storage.local/sync/session |
| 02 | 网络拦截 | declarativeNetRequest、webRequest |
| 03 | 标签页管理 | chrome.tabs、窗口管理 |
| 04 | 右键菜单与通知 | contextMenus、notifications |
| 05 | 侧边栏与 DevTools | sidePanel、devtools panel |
| 06 | 阶段实战 | API 聚合面板 |

## 学完本阶段你能做到

利用 Chrome 高级 API 构建功能丰富的扩展，具备网络拦截、标签页管理、通知推送等能力。
