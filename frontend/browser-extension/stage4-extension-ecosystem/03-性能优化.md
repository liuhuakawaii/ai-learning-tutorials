# 性能优化

## 场景引入

用户安装了 20 个扩展，浏览器变得越来越慢。每个扩展都在后台运行脚本、监听事件、占用内存。Chrome 的任务管理器显示某些扩展占用了数百 MB 内存。

性能是扩展被卸载的第三大原因（仅次于功能不足和 bugs）。一个高效的扩展应该：内存占用小、CPU 使用低、启动速度快、不影响网页加载。

本课将讲解扩展性能优化的核心策略。

## 学习目标

- 掌握内存管理和泄漏预防
- 学会优化 Service Worker 的启动和运行
- 了解 Content Script 的性能优化
- 掌握懒加载和按需注入策略

## Service Worker 优化

### 快速启动

Service Worker 的启动时间直接影响用户体验：

```javascript
// ❌ 启动时执行大量同步操作
chrome.runtime.onInstalled.addListener(() => {
  // 同步操作阻塞启动
  const data = processLargeDataset();
  initializeDatabase(data);
  setupAllListeners();
});

// ✅ 延迟初始化
chrome.runtime.onInstalled.addListener(async () => {
  // 只执行必要的初始化
  await chrome.storage.local.set({ initialized: true });

  // 其他初始化延迟执行
  chrome.alarms.create('lazyInit', { delayInMinutes: 0.1 });
});

chrome.alarms.onAlarm.addListener((alarm) => {
  if (alarm.name === 'lazyInit') {
    initializeHeavyFeatures();
  }
});
```

### 减少 Service Worker 存活时间

```javascript
// ❌ 使用 setInterval 保持 Service Worker 活跃
setInterval(() => {
  performTask();
}, 60000);

// ✅ 使用 chrome.alarms
chrome.alarms.create('periodicTask', { periodInMinutes: 1 });

chrome.alarms.onAlarm.addListener((alarm) => {
  if (alarm.name === 'periodicTask') {
    performTask();
  }
});
```

### 避免不必要的事件监听

```javascript
// ❌ 监听所有标签页事件
chrome.tabs.onUpdated.addListener((tabId, changeInfo, tab) => {
  // 处理逻辑...
});

// ✅ 只在需要时监听
function setupTabListener() {
  chrome.tabs.onUpdated.addListener(handleTabUpdate);
}

function removeTabListener() {
  chrome.tabs.onUpdated.removeListener(handleTabUpdate);
}
```

```javascript
  "matches": ["<all_urls>"],
  "js": ["heavy-content.js"]

  });

```

### 懒加载功能模块

```javascript
// content.js
class ContentScriptLoader {
  constructor() {
    this.modules = new Map();
    this.setupMessageListener();
  }

  setupMessageListener() {
    chrome.runtime.onMessage.addListener(async (message, sender, sendResponse) => {
      if (message.type === 'LOAD_MODULE') {
        const module = await this.loadModule(message.module);
        const result = await module.execute(message.payload);
        sendResponse(result);
      }
      return true;
    });
  }

  async loadModule(name) {
    if (this.modules.has(name)) {
      return this.modules.get(name);
    }

    const module = await import(chrome.runtime.getURL(`modules/${name}.js`));
    this.modules.set(name, module);
    return module;
  }
}
```

### 减少 DOM 查询

```javascript
// ❌ 频繁查询 DOM
function processData() {
  const items = document.querySelectorAll('.item');
  items.forEach(item => {
    const value = item.querySelector('.value').textContent;
    // 处理...
  });

// ✅ 缓存查询结果
class DOMCache {
  constructor() {
    this.cache = new Map();
    this.observer = new MutationObserver(() => this.invalidate());
    this.observer.observe(document.body, { childList: true, subtree: true });
  }

  query(selector) {
    if (!this.cache.has(selector)) {
      this.cache.set(selector, document.querySelectorAll(selector));
    }
    return this.cache.get(selector);
  }

  invalidate() {
    this.cache.clear();
  }
}
```

## 内存管理

### 避免内存泄漏

```javascript
// ❌ 未清理的事件监听器
function setupListeners() {
  window.addEventListener('scroll', handleScroll);
  window.addEventListener('resize', handleResize);
  // 没有清理逻辑
}

// ✅ 可清理的事件监听器
class EventManager {
  constructor() {
    this.listeners = [];
  }

  add(element, event, handler) {
    element.addEventListener(event, handler);
    this.listeners.push({ element, event, handler });
  }

  removeAll() {
    this.listeners.forEach(({ element, event, handler }) => {
      element.removeEventListener(event, handler);
    });
    this.listeners = [];
  }
}
```

### 限制缓存大小

```javascript
class LRUCache {
  constructor(maxSize = 100) {
    this.maxSize = maxSize;
    this.cache = new Map();
  }

  get(key) {
    if (!this.cache.has(key)) return null;

    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value);
    return value;
  }

  set(key, value) {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    }

    this.cache.set(key, value);

    if (this.cache.size > this.maxSize) {
      const firstKey = this.cache.keys().next().value;
      this.cache.delete(firstKey);
    }
  }
}
```

### 使用 WeakMap 和 WeakRef

```javascript
// ❌ Map 导致内存泄漏
const elementData = new Map();

function processElement(element) {
  elementData.set(element, { processed: true });
  // 即使 element 被移除，Map 中的引用仍然存在
}

// ✅ WeakMap 自动释放
const elementData = new WeakMap();

function processElement(element) {
  elementData.set(element, { processed: true });
  // element 被移除后，WeakMap 中的条目自动释放
}
```

## 存储优化

### 批量操作

```javascript
// ❌ 逐条写入
for (const item of items) {
  await chrome.storage.local.set({ [item.id]: item });
}

// ✅ 批量写入
const batch = {};
items.forEach(item => { batch[item.id] = item; });
await chrome.storage.local.set(batch);
```

### 压缩存储数据

```javascript
async function setCompressed(key, data) {
  const json = JSON.stringify(data);
  const compressed = await compressString(json);
  await chrome.storage.local.set({ [key]: compressed });
}

async function getCompressed(key) {
  const { [key]: compressed } = await chrome.storage.local.get(key);
  if (!compressed) return null;
  const json = await decompressString(compressed);
  return JSON.parse(json);
}

async function compressString(str) {
  const stream = new Blob([str]).stream();
  const compressedStream = stream.pipeThrough(new CompressionStream('gzip'));
  const chunks = [];
  for await (const chunk of compressedStream) {
    chunks.push(chunk);
  }
  const blob = new Blob(chunks);
  return blob.text();
}
```

## 网络请求优化

### 请求去重

```javascript
class RequestDeduplicator {
  constructor() {
    this.pending = new Map();
  }

  async fetch(url, options) {
    const key = `${url}:${JSON.stringify(options)}`;

    if (this.pending.has(key)) {
      return this.pending.get(key);
    }

    const promise = fetch(url, options).finally(() => {
      this.pending.delete(key);
    });

    this.pending.set(key, promise);
    return promise;
  }
}
```

### 响应缓存

```javascript
class ResponseCache {
  constructor(ttl = 5 * 60 * 1000) {
    this.cache = new Map();
    this.ttl = ttl;
  }

  async fetch(url) {
    const cached = this.cache.get(url);
    if (cached && Date.now() - cached.timestamp < this.ttl) {
      return cached.data;
    }

    const response = await fetch(url);
    const data = await response.json();

    this.cache.set(url, { data, timestamp: Date.now() });
    return data;
  }
}
```

## 性能监控

```javascript
class PerformanceMonitor {
  constructor() {
    this.metrics = {};
  }

  start(label) {
    this.metrics[label] = { start: performance.now() };
  }

  end(label) {
    if (!this.metrics[label]) return;

    this.metrics[label].duration = performance.now() - this.metrics[label].start;
    console.log(`${label}: ${this.metrics[label].duration.toFixed(2)}ms`);
  }

  getMetrics() {
    return { ...this.metrics };
  }
}

// 使用

perf.end('contentExtraction');
```

## 常见误区

### 误区一：扩展小就不需要优化

即使扩展代码量小，如果注入到所有页面或频繁执行，也会影响性能。

### 误区二：Service Worker 不需要清理

Service Worker 虽然会被终止，但在运行期间的内存泄漏仍会影响浏览器性能。

### 误区三：缓存越多越好

无限制的缓存会导致内存溢出。必须设置缓存上限和过期策略。

### 误区四：忽略启动时间

Service Worker 的冷启动时间可能有几百毫秒。在启动时执行大量操作会让用户感觉扩展"卡"。

## 工程建议

1. **按需注入**：不要在所有页面注入 Content Script
2. **延迟初始化**：启动时只执行必要操作，其他功能懒加载
3. **限制缓存**：设置缓存上限，使用 LRU 策略
4. **批量操作**：存储和 DOM 操作尽量批量执行
5. **性能监控**：在开发阶段监控关键路径的性能

## 小结

性能优化的核心是：减少资源占用、延迟初始化、按需加载、合理缓存。通过这些策略，可以构建高效、不影响用户体验的扩展。

### 练习三

**答案**：

```javascript
class TTLCache {
  constructor(maxSize = 100, ttl = 5 * 60 * 1000) {
    this.maxSize = maxSize;
    this.ttl = ttl;
    this.cache = new Map();
  }

  get(key) {
    const entry = this.cache.get(key);
    if (!entry) return null;

    if (Date.now() - entry.timestamp > this.ttl) {
      this.cache.delete(key);
      return null;
    }

    this.cache.delete(key);
    this.cache.set(key, entry);
    return entry.value;
  }

  set(key, value) {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    }

    this.cache.set(key, {
      value,
      timestamp: Date.now()
    });

    if (this.cache.size > this.maxSize) {
      const firstKey = this.cache.keys().next().value;
      this.cache.delete(firstKey);
    }
  }

  clear() {
    this.cache.clear();
  }

  size() {
    return this.cache.size;
  }
}
```
