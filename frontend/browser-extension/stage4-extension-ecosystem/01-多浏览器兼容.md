# 多浏览器兼容：同一个扩展，Chrome 和 Firefox 都能跑

## 当前项目状态

你的扩展在 Chrome 上运行良好。现在要支持 Firefox、Edge、Safari。问题是：不同浏览器的 API 有差异，manifest 字段有差异，甚至打包格式都不同。

## API 差异

```
Chrome          Firefox         Edge            Safari
chrome.*        browser.*       chrome.*        chrome.*
Promise API     Promise API     Promise API     回调 API（部分）
```

Firefox 用 `browser.*` 命名空间，但 Chrome 的 `chrome.*` 在 Firefox 中也有兼容层（通过 `webextension-polyfill`）。

```javascript
// 使用 webextension-polyfill 统一 API
import browser from 'webextension-polyfill'

// 统一使用 browser.* 命名空间
await browser.storage.local.set({ key: 'value' })
const tabs = await browser.tabs.query({ active: true })
browser.runtime.onMessage.addListener((msg) => { ... })
```

## Manifest 差异

```json
// Chrome Manifest V3
{
  "manifest_version": 3,
  "background": {
    "service_worker": "background.js"
  },
  "permissions": ["storage", "activeTab"],
  "host_permissions": ["<all_urls>"]
}

// Firefox Manifest V3（略有不同）
{
  "manifest_version": 3,
  "background": {
    "scripts": ["background.js"]  // Firefox 用 scripts 而非 service_worker
  },
  "permissions": ["storage", "activeTab"],
  "host_permissions": ["<all_urls>"],
  "browser_specific_settings": {
    "gecko": {
      "id": "my-extension@example.com",
      "strict_min_version": "109.0"
    }
  }
}
```

## 条件编译

用构建工具为不同浏览器生成不同的 manifest：

```javascript
// build.js
const baseManifest = {
  manifest_version: 3,
  name: 'My Extension',
  version: '1.0.0',
  permissions: ['storage', 'activeTab'],
  content_scripts: [{
    matches: ['<all_urls>'],
    js: ['content.js']
  }]
}

function buildForBrowser(browser) {
  const manifest = { ...baseManifest }

  if (browser === 'firefox') {
    manifest.background = { scripts: ['background.js'] }
    manifest.browser_specific_settings = {
      gecko: { id: 'my-extension@example.com' }
    }
  } else {
    manifest.background = { service_worker: 'background.js' }
  }

  return manifest
}
```

## 跨浏览器测试

```javascript
// 检测当前浏览器
function getBrowser() {
  if (typeof chrome !== 'undefined' && chrome.runtime) {
    if (navigator.userAgent.includes('Firefox')) return 'firefox'
    if (navigator.userAgent.includes('Edg')) return 'edge'
    return 'chrome'
  }
  return 'unknown'
}

// 根据浏览器使用不同 API
async function setBadge(text) {
  const browser = getBrowser()
  if (browser === 'firefox') {
    browser.action.setBadgeText({ text })
  } else {
    chrome.action.setBadgeText({ text })
  }
}
```

## Safari 扩展

Safari 扩展和 Chrome/Firefox 差异最大：
- 需要 Xcode 项目
- 打包为 macOS App 或 iOS App
- API 命名空间是 `safari.extension`
- 支持的 API 子集较小

```javascript
// Safari 适配
if (typeof safari !== 'undefined') {
  // Safari 特有逻辑
  safari.extension.settings.addEventListener('change', (e) => {
    // Safari 的设置 API
  })
}
```

```

    │
    ├─→ Chrome 构建 → manifest v3 + service_worker
    ├─→ Firefox 构建 → manifest v3 + scripts + gecko settings
    ├─→ Edge 构建 → 同 Chrome
    └─→ Safari 构建 → Xcode 项目 + Safari Web Extension
```


## 你可能踩的坑

**坑一：Firefox 的 Promise 行为不同**

Firefox 的 `browser.*` 返回标准 Promise，Chrome 的 `chrome.*` 在某些 API 上仍用回调。用 polyfill 统一。

**坑二：Safari 的权限模型不同**

Safari 不支持 `activeTab`，需要明确声明 `host_permissions`。

**坑三：不同浏览器的 CSP 不同**

Chrome Manifest V3 的 CSP 更严格。不要用 `eval` 或内联脚本。

### 练习二

```javascript
async function compatibilityCheck() {
  const results = {}
  const apis = [
    'chrome.storage',
    'chrome.tabs',
    'chrome.runtime',
    'chrome.sidePanel',
    'chrome.action',
    'chrome.contextMenus'
  ]

  for (const api of apis) {
    const parts = api.split('.')
    let obj = globalThis
    for (const part of parts) obj = obj?.[part]
    results[api] = typeof obj !== 'undefined'
  }

  return results
}
```
