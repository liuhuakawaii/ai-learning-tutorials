# 阶段实战：跨浏览器扩展——一套代码多端运行

## 当前项目状态

前五课学了多浏览器兼容、安全模型、性能优化、自动化测试和扩展框架。本课把 AI 阅读助手扩展改造为支持 Chrome、Firefox、Edge 三端。

## 共享代码

```typescript
// src/shared/utils.ts
import browser from 'webextension-polyfill'

export async function getStorage(key: string) {
  const result = await browser.storage.local.get(key)
  return result[key]
}

export async function setStorage(key: string, value: any) {
  await browser.storage.local.set({ [key]: value })
}

export function onMessage(callback: (msg: any) => Promise<any>) {
  browser.runtime.onMessage.addListener((msg, sender) => {
    return callback(msg)
  })
}

export async function sendMessage(msg: any) {
  return browser.runtime.sendMessage(msg)
}
```

## 条件构建

```typescript
// build.ts
import fs from 'fs'

const target = process.env.BROWSER || 'chrome'

const baseManifest = JSON.parse(fs.readFileSync('src/shared/manifest.base.json', 'utf-8'))

const overrides = {
  chrome: {
    background: { service_worker: 'background.js' }
  },
  firefox: {
    background: { scripts: ['background.js'] },
    browser_specific_settings: {
      gecko: { id: 'ai-reader@example.com' }
    }
  },
  edge: {
    background: { service_worker: 'background.js' }
  }
}

const manifest = { ...baseManifest, ...overrides[target] }
fs.writeFileSync(`dist/${target}/manifest.json`, JSON.stringify(manifest, null, 2))
```

## 浏览器特有逻辑

```typescript
// src/shared/background.ts
import browser from 'webextension-polyfill'

// 统一的 API 调用
async function getCurrentTab() {
  const [tab] = await browser.tabs.query({ active: true, currentWindow: true })
  return tab
}

// Firefox 特有：侧边栏 API
if (typeof browser.sidebarAction !== 'undefined') {
  browser.sidebarAction.setPanel({ panel: 'sidepanel.html' })
}

// Chrome 特有：Side Panel API
if (typeof chrome !== 'undefined' && chrome.sidePanel) {
  chrome.sidePanel.setOptions({ path: 'sidepanel.html' })
}
```

## 你可能踩的坑

**坑一：polyfill 增加包体积**

webextension-polyfill 约 15KB。如果你只支持 Chrome，不需要 polyfill。

**坑二：Firefox 的 background scripts 行为不同**

Firefox 的 background scripts 是持久的（不休眠），Chrome 的 Service Worker 会休眠。不要依赖全局变量。

**坑三：测试环境差异**

Puppeteer 只支持 Chrome。Firefox 测试需要用 web-ext run 或 Playwright。

```yaml
# .github/workflows/build.yml
name: Build Extensions
on: push
jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        browser: [chrome, firefox, edge]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm install
      - run: npm run build:${{ matrix.browser }}
      - uses: actions/upload-artifact@v4
        with:
          name: ${{ matrix.browser }}
          path: dist/${{ matrix.browser }}/
```

### 练习二

```typescript
class FeatureDetector {
  static hasSidePanel(): boolean {
    return typeof chrome !== 'undefined' && !!chrome.sidePanel
  }

  static hasSidebarAction(): boolean {
    return typeof browser !== 'undefined' && !!browser.sidebarAction
  }

  static hasOffscreen(): boolean {
    return typeof chrome !== 'undefined' && !!chrome.offscreen
  }

  static getSidebarAPI(): 'sidePanel' | 'sidebarAction' | null {
    if (this.hasSidePanel()) return 'sidePanel'
    if (this.hasSidebarAction()) return 'sidebarAction'
    return null
  }
}
```
