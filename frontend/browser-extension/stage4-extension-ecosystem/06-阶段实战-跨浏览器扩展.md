# 阶段实战：跨浏览器扩展

## 场景引入

阶段四学习了多浏览器兼容、安全、性能优化、自动化测试和扩展框架。现在将这些知识综合起来，使用 WXT 框架构建一个生产级的跨浏览器扩展。

我们要构建的是一个"网页阅读模式"扩展：一键将杂乱的网页转换为干净的阅读视图，支持字体调整、主题切换、阅读进度保存。这个项目需要在 Chrome、Firefox 和 Edge 上都能正常运行。

## 学习目标

- 使用 WXT 框架构建跨浏览器扩展
- 实现阅读模式的完整功能
- 处理三端兼容性问题
- 编写自动化测试
- 优化性能和安全

## Background

```typescript
// entrypoints/background.ts
export default defineBackground(() => {
  chrome.runtime.onInstalled.addListener(async () => {
    await chrome.storage.sync.set({
      settings: {
        fontSize: 18,
        fontFamily: 'system-ui',
        theme: 'light',
        lineHeight: 1.8,
        maxWidth: 720
      }
    });
  });

  chrome.commands?.onCommand?.addListener(async (command) => {
    if (command === 'toggle-reading-mode') {
      const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
      if (tab.id) {
        chrome.tabs.sendMessage(tab.id, { type: 'TOGGLE_READING_MODE' });
      }
    }
  });

  chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
    if (message.type === 'GET_SETTINGS') {
      chrome.storage.sync.get('settings').then(sendResponse);
      return true;
    }

    if (message.type === 'SAVE_PROGRESS') {
      saveReadingProgress(message.data).then(sendResponse);
      return true;
    }
  });
});

async function saveReadingProgress(data: { url: string; progress: number }) {
  const { readingProgress = {} } = await chrome.storage.local.get('readingProgress');
  readingProgress[data.url] = {
    progress: data.progress,
    timestamp: Date.now()
  };
  await chrome.storage.local.set({ readingProgress });
  return { success: true };
}
```

## Content Script

```typescript
// entrypoints/content.ts
import { Readability } from '@mozilla/readability';
import { ReaderView } from '../components/ReaderView';
import { ThemeManager } from '../components/ThemeManager';

export default defineContentScript({
  matches: ['<all_urls>'],
  main() {
    let readerView: ReaderView | null = null;
    let isActive = false;

    chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
      if (message.type === 'TOGGLE_READING_MODE') {
        if (isActive) {
          deactivate();
        } else {
          activate();
        }
        sendResponse({ active: isActive });
      }
      return false;
    });

    async function activate() {
      try {
        const article = extractArticle();
        if (!article) {
          showNotification('无法提取文章内容');
          return;
        }

        const { settings } = await chrome.runtime.sendMessage({
          type: 'GET_SETTINGS'
        });

        readerView = new ReaderView(article, settings);
        readerView.render();
        isActive = true;

        restoreProgress();
      } catch (error) {
        console.error('激活阅读模式失败:', error);
      }
    }

    function deactivate() {
      if (readerView) {
        saveCurrentProgress();
        readerView.remove();
        readerView = null;
        isActive = false;
      }
    }

    function extractArticle() {
      try {
        const doc = document.cloneNode(true) as Document;
        const reader = new Readability(doc);
        return reader.parse();
      } catch {
        return fallbackExtract();
      }
    }

    function fallbackExtract() {
      const title = document.title;
      const content = document.body.innerText;
      return {
        title,
        content,
        textContent: content,
        length: content.length
      };
    }

    async function restoreProgress() {
      const { readingProgress = {} } = await chrome.storage.local.get('readingProgress');
      const progress = readingProgress[window.location.href];
      if (progress) {
        window.scrollTo(0, progress.progress * document.body.scrollHeight);
      }
    }

    function saveCurrentProgress() {
      const progress = window.scrollY / document.body.scrollHeight;
      chrome.runtime.sendMessage({
        type: 'SAVE_PROGRESS',
        data: {
          url: window.location.href,
          progress
        }
      });
    }
  }
});
```

## ReaderView 组件

```typescript
// components/ReaderView.ts
export class ReaderView {
  private container: HTMLDivElement | null = null;
  private article: any;
  private settings: any;

  constructor(article: any, settings: any) {
    this.article = article;
    this.settings = settings;
  }

  render() {
    this.container = document.createElement('div');
    this.container.id = 'reading-mode-container';

    const shadow = this.container.attachShadow({ mode: 'closed' });

    shadow.innerHTML = `
      <style>
        :host {
          all: initial;
        }
        .reader-overlay {
          position: fixed;
          top: 0;
          left: 0;
          right: 0;
          bottom: 0;
          background: var(--bg-color, #fff);
          z-index: 2147483647;
          overflow-y: auto;
          font-family: var(--font-family, system-ui);
        }
        .reader-content {
          max-width: var(--max-width, 720px);
          margin: 0 auto;
          padding: 40px 20px;
          font-size: var(--font-size, 18px);
          line-height: var(--line-height, 1.8);
          color: var(--text-color, #333);
        }
        .reader-title {
          font-size: 2em;
          font-weight: 700;
          margin-bottom: 16px;
        }
        .reader-meta {
          color: #666;
          font-size: 0.9em;
          margin-bottom: 32px;
        }
        .reader-body {
          line-height: var(--line-height, 1.8);
        }
        .reader-body img {
          max-width: 100%;
          height: auto;
          border-radius: 8px;
          margin: 16px 0;
        }
        .toolbar {
          position: fixed;
          top: 20px;
          right: 20px;
          display: flex;
          gap: 8px;
          z-index: 1;
        }
        .toolbar button {
          padding: 8px 12px;
          border: none;
          border-radius: 8px;
          background: rgba(0,0,0,0.1);
          cursor: pointer;
          font-size: 14px;
        }
        .theme-light {
          --bg-color: #fff;
          --text-color: #333;
        }
        .theme-dark {
          --bg-color: #1a1a1a;
          --text-color: #e0e0e0;
        }
        .theme-sepia {
          --bg-color: #f4ecd8;
          --text-color: #5b4636;
        }
      </style>
      <div class="reader-overlay theme-${this.settings.theme}">
        <div class="toolbar">
          <button id="font-decrease">A-</button>
          <button id="font-increase">A+</button>
          <button id="theme-toggle">主题</button>
          <button id="close-reader">关闭</button>
        </div>
        <div class="reader-content">
          <h1 class="reader-title">${this.article.title}</h1>
          <div class="reader-meta">
            ${this.article.byline ? `<span>${this.article.byline}</span> · ` : ''}
            <span>约 ${this.estimateReadingTime()} 分钟阅读</span>
          </div>
          <div class="reader-body">
            ${this.article.content || this.article.textContent}
          </div>
        </div>
      </div>
    `;

    document.body.appendChild(this.container);
    this.setupToolbar(shadow);
  }

  estimateReadingTime(): number {
    const wordsPerMinute = 300;
    const words = (this.article.textContent || '').length / 2;
    return Math.ceil(words / wordsPerMinute);
  }

  setupToolbar(shadow: ShadowRoot) {
    const themes = ['light', 'dark', 'sepia'];
    let currentTheme = themes.indexOf(this.settings.theme);

    shadow.getElementById('font-decrease')?.addEventListener('click', () => {
      this.settings.fontSize = Math.max(14, this.settings.fontSize - 2);
      this.updateStyles(shadow);
    });

    shadow.getElementById('font-increase')?.addEventListener('click', () => {
      this.settings.fontSize = Math.min(28, this.settings.fontSize + 2);
      this.updateStyles(shadow);
    });

    shadow.getElementById('theme-toggle')?.addEventListener('click', () => {
      currentTheme = (currentTheme + 1) % themes.length;
      const overlay = shadow.querySelector('.reader-overlay') as HTMLElement;
      overlay.className = `reader-overlay theme-${themes[currentTheme]}`;
    });

    shadow.getElementById('close-reader')?.addEventListener('click', () => {
      this.remove();
    });
  }

  updateStyles(shadow: ShadowRoot) {
    const content = shadow.querySelector('.reader-content') as HTMLElement;
    if (content) {
      content.style.fontSize = `${this.settings.fontSize}px`;
    }
  }

  remove() {
    if (this.container) {
      this.container.remove();
      this.container = null;
    }
  }
}
```

```typescript
// utils/browser-compat.ts
export function getBrowser(): 'chrome' | 'firefox' | 'edge' {
  if (typeof browser !== 'undefined' && browser.runtime?.getBrowserInfo) {
    return 'firefox';
  }
  if (navigator.userAgent.includes('Edg/')) {
    return 'edge';
  }
  return 'chrome';
}

export function supportsSidePanel(): boolean {
  return getBrowser() === 'chrome' || getBrowser() === 'edge';
}

export function getApi() {
  return typeof browser !== 'undefined' ? browser : chrome;
}
```

## 工程建议

1. **WXT 框架**：使用 WXT 简化构建流程和多浏览器适配
2. **Readability.js**：使用成熟的正文提取算法
3. **Shadow DOM**：使用 Shadow DOM 隔离阅读模式的样式
4. **设置同步**：使用 chrome.storage.sync 跨设备同步设置
5. **测试覆盖**：编写 E2E 测试确保三端兼容

## 常见误区

### 误区一：直接修改原页面 DOM

阅读模式应该创建独立的容器，覆盖在原页面上，而不是修改原页面 DOM。这样退出阅读模式时可以完全恢复。

### 误区二：不处理动态内容

某些网站的内容是动态加载的，Readability 可能无法提取。需要实现降级方案。

### 误区三：忽略滚动位置

阅读模式应该恢复用户的滚动位置，提供连续的阅读体验。

```typescript
const fonts = [
  { name: '系统默认', value: 'system-ui' },
  { name: '宋体', value: 'SimSun, serif' },
  { name: '微软雅黑', value: 'Microsoft YaHei, sans-serif' },

  { name: 'Georgia', value: 'Georgia, serif' },
  { name: 'Merriweather', value: 'Merriweather, serif' }
];

function createFontSelector(currentFont: string): HTMLSelectElement {
  const select = document.createElement('select');
  fonts.forEach(font => {
    const option = document.createElement('option');
    option.value = font.value;
    option.textContent = font.name;
    option.selected = font.value === currentFont;
    select.appendChild(option);
  });

  select.addEventListener('change', async () => {
    const { settings } = await chrome.storage.sync.get('settings');
    settings.fontFamily = select.value;
    await chrome.storage.sync.set({ settings });
  });

  return select;
}
```

```typescript
async function updateReadingStats(article: any) {
  const { readingStats = {
    articlesRead: 0,
    totalWords: 0,
    totalMinutes: 0
  } } = await chrome.storage.local.get('readingStats');

  readingStats.articlesRead += 1;
  readingStats.totalWords += article.textContent.length;
  readingStats.totalMinutes += Math.ceil(article.textContent.length / 600);

  await chrome.storage.local.set({ readingStats });
}
```

```typescript
async function exportToMarkdown(article: any) {
  const md = `# ${article.title}\n\n${article.textContent}`;

  const blob = new Blob([md], { type: 'text/markdown' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = `${article.title.substring(0, 50)}.md`;
  a.click();
  URL.revokeObjectURL(url);
}
```
