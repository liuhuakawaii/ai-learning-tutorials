# 扩展安全

## 场景引入

浏览器扩展拥有比普通网页更高的权限——它可以访问你的浏览数据、修改网页内容、拦截网络请求。一个恶意扩展可以窃取你的密码、注入广告、追踪你的所有上网行为。

Chrome 应用商店的安全审核越来越严格，很多扩展因为安全问题被下架。理解扩展的安全模型并实施最佳实践，不仅保护用户，也确保你的扩展能通过审核。

## 学习目标

- 理解扩展的安全模型和攻击面
- 掌握内容安全策略（CSP）的配置
- 学会实施权限最小化原则
- 了解常见的安全漏洞和防御方式

## 内容安全策略（CSP）

CSP 是扩展安全的第一道防线，限制扩展可以加载和执行的资源。

### Manifest V3 的 CSP

Manifest V3 的 CSP 是固定的，不能自定义：

```
script-src 'self';
object-src 'self';
```

这意味着：
- 只能执行打包在扩展内的脚本
- 不能使用 `eval()` 或 `new Function()`
- 不能加载远程脚本

### 常见 CSP 错误

```javascript
// ❌ 不允许：eval
eval('console.log("hello")');

// ❌ 不允许：内联脚本
// <script>console.log('inline')</script>

// ❌ 不允许：远程脚本
const script = document.createElement('script');
script.src = 'https://cdn.example.com/lib.js';
document.head.appendChild(script);

// ✅ 允许：打包在扩展内的脚本
const script = document.createElement('script');
script.src = chrome.runtime.getURL('lib.js');
document.head.appendChild(script);
```

### Content Script 的 CSP

Content Script 运行在网页的上下文中，但有自己的 CSP：

```javascript
// Content Script 可以使用 eval（但不推荐）
// Content Script 不能修改网页的 CSP

// 如果网页的 CSP 阻止了某些操作，Content Script 也受影响
// 例如：网页禁止内联脚本时，Content Script 注入的内联脚本也会被阻止
```

## 权限最小化

### 申请最小权限

```json
{
  "manifest_version": 3,

  // ❌ 过度申请
  "permissions": [
    "tabs",
    "storage",
    "cookies",
    "history",
    "downloads",
    "bookmarks",
    "notifications",
    "webRequest",
    "<all_urls>"
  ],

  // ✅ 最小权限
  "permissions": [
    "activeTab",
    "storage"
  ]
}
```

### 使用 activeTab

`activeTab` 只在用户主动交互时授予临时权限，是最安全的选择：

```javascript
// 用户点击扩展图标后才能执行
chrome.action.onClicked.addListener(async (tab) => {
  await chrome.scripting.executeScript({
    target: { tabId: tab.id },
    files: ['content.js']
  });
});
```

### 可选权限

运行时请求权限，让用户明确授权：

```javascript
async function requestDownloadPermission() {
  const granted = await chrome.permissions.request({
    permissions: ['downloads']
  });

  if (!granted) {
    showPermissionDeniedMessage();
    return false;
  }

  return true;
}
```

## 输入验证

### 验证消息内容

```javascript
// background.js
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  // ❌ 不验证：直接使用消息内容
  // eval(message.code);

  // ✅ 验证：检查消息格式和内容
  if (!message || typeof message.type !== 'string') {
    return;
  }

  const allowedTypes = ['EXTRACT', 'TRANSLATE', 'SAVE'];
  if (!allowedTypes.includes(message.type)) {
    return;
  }

  // 验证数据
  if (message.type === 'SAVE') {
    if (!message.data || typeof message.data.text !== 'string') {
      return;
    }
    if (message.data.text.length > 10000) {
      return;
    }
  }

  // 处理消息...
});
```

### 验证 URL

```javascript
function isValidUrl(url) {
  try {
    const parsed = new URL(url);
    return ['http:', 'https:'].includes(parsed.protocol);
  } catch {
    return false;
  }
}

// 在使用 URL 前验证
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'REDIRECT') {
    if (!isValidUrl(message.url)) {
      sendResponse({ error: 'Invalid URL' });
      return;
    }
    chrome.tabs.update(sender.tab.id, { url: message.url });
  }
});
```

### 防止 XSS

```javascript
// ❌ 不安全：直接插入 HTML
element.innerHTML = userProvidedText;

// ✅ 安全：使用 textContent
element.textContent = userProvidedText;

// ✅ 安全：如果必须使用 HTML，进行转义
function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

element.innerHTML = escapeHtml(userProvidedText);
```

## 存储安全

### 不存储敏感信息

```javascript
// ❌ 不要存储明文密码
await chrome.storage.local.set({
  password: 'user123'
});

// ✅ 使用 OAuth 或 token
await chrome.storage.local.set({
  authToken: 'encrypted_token_here'
});
```

### 加密敏感数据

```javascript
async function encryptData(data, key) {
  const encoder = new TextEncoder();
  const dataBuffer = encoder.encode(JSON.stringify(data));

  const cryptoKey = await crypto.subtle.importKey(
    'raw',
    encoder.encode(key),
    { name: 'AES-GCM' },
    false,
    ['encrypt']
  );

  const iv = crypto.getRandomValues(new Uint8Array(12));
  const encrypted = await crypto.subtle.encrypt(
    { name: 'AES-GCM', iv },
    cryptoKey,
    dataBuffer
  );

  return {
    iv: Array.from(iv),
    data: Array.from(new Uint8Array(encrypted))
  };
}
```

## Content Script 安全

### 隔离 DOM 操作

```javascript
// ✅ 使用 Shadow DOM 隔离 UI
function createIsolatedUI() {
  const container = document.createElement('div');
  const shadow = container.attachShadow({ mode: 'closed' });

  shadow.innerHTML = `
    <style>/* 样式不会被网页影响 */</style>
    <div class="my-ui">...</div>
  `;

  document.body.appendChild(container);
}
```

### 验证 DOM 来源

```javascript
// ❌ 不安全：信任网页的 DOM 内容
const price = document.querySelector('.price').textContent;
sendToBackground({ price: parseFloat(price) });

// ✅ 安全：验证数据格式
const priceEl = document.querySelector('.price');
if (priceEl) {
  const priceText = priceEl.textContent.trim();
  const price = parseFloat(priceText);
  if (!isNaN(price) && price >= 0 && price < 1000000) {
    sendToBackground({ price });
  }
}
```

## 网络请求安全

### 验证 API 响应

```javascript
async function fetchFromAPI(url) {
  const response = await fetch(url);

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }

  const contentType = response.headers.get('content-type');
  if (!contentType || !contentType.includes('application/json')) {
    throw new Error('Invalid content type');
  }

  const data = await response.json();

  // 验证数据结构
  if (typeof data !== 'object' || data === null) {
    throw new Error('Invalid response format');
  }

  return data;
}
```

### 防止 SSRF

```javascript
// ❌ 不安全：直接使用用户提供的 URL
fetch(userProvidedUrl);

// ✅ 安全：验证 URL 域名
function isAllowedDomain(url) {
  const allowedDomains = ['api.example.com', 'cdn.example.com'];
  try {
    const parsed = new URL(url);
    return allowedDomains.includes(parsed.hostname);
  } catch {
    return false;
  }
}

if (isAllowedDomain(userProvidedUrl)) {
  fetch(userProvidedUrl);
}
```

### 检查依赖安全


### 最小化依赖

```json
{
  "dependencies": {
    "webextension-polyfill": "^0.10.0"
  }
}
```

每个依赖都是潜在的攻击面。只引入真正需要的依赖。

## 常见安全漏洞

### 1. 过度权限

申请了不需要的权限，增加了攻击面。

### 2. eval 使用

使用 `eval()` 或 `new Function()` 执行动态代码，可能导致代码注入。

### 3. 不验证消息

不验证来自 Content Script 或 Popup 的消息，可能导致恶意操作。

### 4. 明文存储密钥

将 API Key 或密码明文存储在扩展中。

### 5. 不安全的 DOM 操作

直接使用 `innerHTML` 插入未验证的内容，导致 XSS。

## 工程建议

1. **权限最小化**：只申请真正需要的权限，优先使用 `activeTab`
2. **输入验证**：验证所有外部输入（消息、URL、DOM 内容）
3. **CSP 合规**：不使用 eval，不加载远程脚本
4. **敏感数据加密**：不要明文存储密钥和密码
5. **依赖审计**：定期检查依赖的安全漏洞
6. **Shadow DOM 隔离**：使用 Shadow DOM 隔离扩展的 UI

## 小结

扩展安全是一个系统性工程，涉及 CSP 配置、权限管理、输入验证、数据存储和代码审计等多个层面。遵循最小权限原则和防御性编程实践，可以构建安全可靠的扩展。

### 练习二

**答案**：

```javascript
class MessageValidator {
  static schemas = {
    SAVE_NOTE: {
      required: ['text', 'url'],
      types: { text: 'string', url: 'string' },
      limits: { text: 10000, url: 2000 }
    },
    TRANSLATE: {
      required: ['text', 'targetLang'],
      types: { text: 'string', targetLang: 'string' },
      limits: { text: 5000 }
    }
  };

  static validate(message) {
    if (!message || typeof message !== 'object') {
      return { valid: false, error: 'Invalid message format' };
    }

    const schema = this.schemas[message.type];
    if (!schema) {
      return { valid: false, error: `Unknown message type: ${message.type}` };
    }

    for (const field of schema.required) {
      if (!(field in message)) {
        return { valid: false, error: `Missing required field: ${field}` };
      }
    }

    for (const [field, type] of Object.entries(schema.types)) {
      if (field in message && typeof message[field] !== type) {
        return { valid: false, error: `Invalid type for ${field}` };
      }
    }

    for (const [field, limit] of Object.entries(schema.limits)) {
      if (field in message && message[field].length > limit) {
        return { valid: false, error: `${field} exceeds limit of ${limit}` };
      }
    }

    return { valid: true };
  }
}

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  const validation = MessageValidator.validate(message);
  if (!validation.valid) {
    sendResponse({ error: validation.error });
    return;
  }
  // 处理消息...
});
```

### 练习三

**答案**：

```javascript
class SecureStorage {
  constructor() {
    this.keyName = 'encryption_key';
  }

  async init() {
    const { [this.keyName]: existingKey } = await chrome.storage.local.get(this.keyName);
    if (!existingKey) {
      const key = await crypto.subtle.generateKey(
        { name: 'AES-GCM', length: 256 },
        true,
        ['encrypt', 'decrypt']
      );
      const exported = await crypto.subtle.exportKey('jwk', key);
      await chrome.storage.local.set({ [this.keyName]: exported });
    }
  }

  async getKey() {
    const { [this.keyName]: jwk } = await chrome.storage.local.get(this.keyName);
    return crypto.subtle.importKey(
      'jwk',
      jwk,
      { name: 'AES-GCM' },
      false,
      ['encrypt', 'decrypt']
    );
  }

  async encrypt(data) {
    const key = await this.getKey();
    const iv = crypto.getRandomValues(new Uint8Array(12));
    const encoded = new TextEncoder().encode(JSON.stringify(data));

    const encrypted = await crypto.subtle.encrypt(
      { name: 'AES-GCM', iv },
      key,
      encoded
    );

    return {
      iv: Array.from(iv),
      data: Array.from(new Uint8Array(encrypted))
    };
  }

  async decrypt(encrypted) {
    const key = await this.getKey();
    const iv = new Uint8Array(encrypted.iv);
    const data = new Uint8Array(encrypted.data);

    const decrypted = await crypto.subtle.decrypt(
      { name: 'AES-GCM', iv },
      key,
      data
    );

    return JSON.parse(new TextDecoder().decode(decrypted));
  }

  async setSecure(key, value) {
    const encrypted = await this.encrypt(value);
    await chrome.storage.local.set({ [`secure_${key}`]: encrypted });
  }

  async getSecure(key) {
    const { [`secure_${key}`]: encrypted } = await chrome.storage.local.get(`secure_${key}`);
    if (!encrypted) return null;
    return this.decrypt(encrypted);
  }
}
```
