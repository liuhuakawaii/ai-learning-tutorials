# 阶段四：扩展生态

> 掌握跨浏览器兼容、安全模型、性能优化、自动化测试和主流扩展框架，构建生产级扩展。

## 学习目标

- 适配 Chrome / Firefox / Edge 三端差异
- 理解扩展安全模型并实施最佳安全实践
- 优化扩展内存、CPU 和加载性能
- 使用 Puppeteer 构建 E2E 测试套件
- 掌握 WXT / Plasmo / CRXJS 等主流框架
- 独立完成一个跨浏览器兼容的扩展

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 多浏览器兼容 | Chrome/Firefox/Edge 适配 |
| 02 | 扩展安全 | CSP、权限最小化、代码审计 |
| 03 | 性能优化 | 内存管理、懒加载、Worker 优化 |
| 04 | 自动化测试 | Puppeteer 测试、E2E 测试 |
| 05 | 扩展框架 | WXT/Plasmo/CRXJS |
| 06 | 阶段实战 | 跨浏览器扩展 |

## 学完本阶段你能做到

构建生产级扩展，具备跨浏览器兼容、安全防护、性能优化和自动化测试能力。
