## 验收标准

- 能用 Voronoi 图和 Delaunay 三角剖分生成艺术图案
- 能用 Perlin 噪声流场驱动粒子轨迹生成流场动画
- 能将图像转化为 Voronoi 像素或马赛克效果
- 能将音频频谱数据输入驱动生成图案
- 完成流场动画作品，粒子轨迹形成有机视觉效果
