# 毕业项目：生成艺术系列

## 项目概述

创作一个包含至少 5 种算法的生成艺术系列作品，每件作品可独立运行并导出 SVG/PNG。通过数学规则、随机性和参数控制，探索算法美学的边界。

## 技术栈

- **语言**：TypeScript
- **渲染**：Canvas 2D / SVG / WebGL（按需选择）
- **框架**：Vite（开发服务器 + 构建）
- **导出**：canvas-to-blob（PNG）、SVG 序列化（SVG）
- **UI**：dat.gui 或 lil-gui（参数调节面板）

## 核心功能

### 1. 算法作品集（至少 5 件）

每件作品需要满足：

- 独立的算法实现，不是简单调参变体
- 可交互的参数面板（至少 3 个可调参数）
- 支持随机种子控制（可复现同一构图）
- 导出 SVG 和 PNG 格式

推荐算法方向（至少选 5 个，鼓励自选）：

| 算法 | 核心思想 | 典型效果 |
|------|---------|---------|
| Perlin 圏声场 | 连续随机场 + 粒子追踪 | 流体线条、云雾纹理 |
| L-System | 递归字符串替换 + 龟绘图 | 分形树、科赫雪花 |
| Voronoi 图 | 距离场划分 | 马赛克、细胞纹理 |
| 反应扩散 | Gray-Scott 模型 | 斑点、迷宫纹理 |
| 粒子系统 | 力场 + 生命周期 | 烟花、星云、群体行为 |
| 遗传算法艺术 | 进化 + 适应度函数 | 图像逼近、风格演化 |
| 波函数坍缩 | 约束传播 + 熵最小化 | 程序化瓦片地图 |
| Agent-Based | 简单规则 + 涌现 | 城市生长、交通流 |
| 分形递归 | 自相似 + 缩放 | Mandelbrot、Julia 集 |
| 网格变形 | 弹簧质点 + 扰动 | 织物、液态金属 |

### 2. 展示画廊

- 网格布局展示所有作品缩略图
- 点击进入单件作品的全屏模式
- 每件作品附带算法简介和参数说明

### 3. 导出系统

- PNG 导出：支持自定义分辨率（1x / 2x / 4x）
- SVG 导出：矢量格式，适合打印
- 批量导出：一次导出所有作品

### 4. 参数动画录制

- 关键帧录制：设置参数在不同时间点的值
- 自动插值生成过渡动画
- 导出为 GIF 或 WebM

## 验收标准

```bash
cd frontend/generative-art-algorithms/final-project
node scripts/check.cjs
```

验证项：

- [ ] 包含至少 5 件独立算法作品
- [ ] 每件作品有可交互的参数面板
- [ ] 每件作品支持随机种子控制
- [ ] 支持 SVG 和 PNG 导出
- [ ] 画廊页面可浏览所有作品
- [ ] 代码结构清晰，算法与展示分离
- [ ] 作品视觉效果有辨识度，不是简单的几何拼贴
