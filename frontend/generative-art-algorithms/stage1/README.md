# 第一阶段：基础

建立生成艺术的数学直觉——掌握随机与噪声、颜色理论、形状生成和网格系统，用代码生成第一幅抽象画。

## 课时列表

| 课时 | 标题 |
|------|------|
| 01 | [随机与噪声——伪随机、Perlin/Simplex 噪声、噪声场](01-random-and-noise.md) |
| 02 | [颜色理论——调色板生成、色彩和谐、渐变算法](02-color-theory.md) |
| 03 | [形状生成——随机游走、Lissajous 曲线、参数方程](03-shape-generation.md) |
| 04 | [网格系统——六边形网格、三角网格、Voronoi 图](04-grid-systems.md) |
| 05 | [阶段实战：用噪声和网格生成一幅抽象画](05-abstract-painting.md) |

## 验收标准

- 能用 Perlin/Simplex 噪声生成自然纹理和噪声场
- 能用算法生成和谐的调色板并应用渐变
- 能用随机游走、参数方程生成有机形状
- 能实现六边形网格和 Voronoi 图的基础生成
- 完成一幅用噪声和网格生成的抽象画作品
