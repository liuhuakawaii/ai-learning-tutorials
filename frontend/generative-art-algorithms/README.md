# 生成艺术算法

> 每课实现一个算法，产出一个视觉作品。

## 适合谁

- 想用代码创造视觉艺术，但不知道有哪些经典算法
- 看到 generative art 觉得很酷，想系统学习
- 想建立"算法→视觉"的直觉

## 学完能做什么

- 用代码实现 Voronoi、Reaction-Diffusion、L-System、WFC 等经典生成算法
- 理解噪声、分形、细胞自动机的数学直觉
- 将生成算法应用于艺术创作、游戏开发、设计系统
- 构建参数化的生成艺术作品，可导出 SVG/图片/动画

## 学习路线

### 第一阶段：基础

1. 随机与噪声——伪随机、Perlin/Simplex 噪声、噪声场
2. 颜色理论——调色板生成、色彩和谐、渐变算法
3. 形状生成——随机游走、Lissajous 曲线、参数方程
4. 网格系统——六边形网格、三角网格、Voronoi 图
5. 阶段实战：用噪声和网格生成一幅抽象画

### 第二阶段：模式

6. 分形——Mandelbrot、Julia、Sierpinski、分形树
7. 细胞自动机——Conway's Game of Life、Langton's Ant、Rule 30
8. Reaction-Diffusion——Gray-Scott 模型、Turing 模式
9. L-System——植物生长模拟、递归图形
10. 阶段实战：生成一组分形和植物图案

### 第三阶段：系统

11. 遗传算法——进化艺术、适应度函数设计
12. 粒子系统——力场、吸引/排斥、粒子生命
13. 群体行为——Boids 算法、涌现模式
14. Wave Function Collapse——从规则生成地图/图案
15. 阶段实战：用遗传算法进化出一组艺术图案

### 第四阶段：进阶

16. Voronoi 艺术——Voronoi 图的视觉化、Delaunay 三角剖分
17. 流场可视化——Perlin 噪声流场、粒子轨迹
18. 图像像素化——Voronoi 像素、马赛克、抖动
19. 音频可视化——频谱驱动的生成图案
20. 阶段实战：生成一个流场动画作品

### 第五阶段：创作

21. 参数化设计——种子控制、参数空间探索
22. 动画与过渡——噪声动画、形态变换、生长动画
23. 交互式生成——鼠标/触摸输入驱动生成
24. 导出与发布——SVG/PNG/WebGL 输出、NFT 元数据
25. 阶段实战：创作一个完整的生成艺术系列
