# 毕业项目：WASM 多媒体处理平台

## 项目概述

构建一个基于 WebAssembly 的多媒体处理平台，支持图像处理、音视频转码、文件压缩等高性能计算任务。前端界面使用 Vue3 / React，核心计算逻辑使用 Rust 编译为 Wasm 模块，通过 Web Worker 实现多线程并行处理，利用 SIMD 指令集加速计算密集型操作。

平台需要在浏览器中完成所有计算，不依赖后端服务，体现 WebAssembly "前端即高性能" 的核心价值。

## 项目目标

1. **综合运用**：整合 5 个阶段所学的 Wasm 技术栈
2. **工程完整**：具备完整的构建、测试、部署流程
3. **性能可测**：每个核心功能都有 JS vs Wasm 的性能对比数据
4. **生产可用**：错误处理、边界情况、用户体验达到生产标准

## 功能需求

### 核心功能

| 功能模块 | 说明 | 涉及技术 |
|----------|------|----------|
| 图像处理 | 灰度化、模糊、锐化、边缘检测、格式转换 | Rust + wasm-bindgen、Canvas API |
| 音频处理 | 波形可视化、格式转码、音量调节、裁剪 | Rust + Web Audio API、SharedArrayBuffer |
| 文件压缩 | ZIP/GZIP 压缩与解压 | Rust 移植 miniz_oxide |
| 批量处理 | 多文件并行处理、任务队列 | Web Worker 线程池、Atomics |
| 性能面板 | 实时显示处理速度、内存占用、线程状态 | Performance API、Chrome DevTools |

### 扩展功能（加分项）

- 视频帧提取与滤镜处理（WebCodecs API）
- WebGPU 加速的图像处理
- WASI 文件系统集成
- 组件模型（Component Model）模块化

## 技术栈

| 层次 | 技术选型 |
|------|----------|
| 前端框架 | Vue3 + TypeScript + Vite（或 React，二选一） |
| Wasm 主语言 | Rust + wasm-bindgen + wasm-pack |
| Wasm 辅助 | AssemblyScript（用于对比模块或扩展功能） |
| 多线程 | Web Worker + SharedArrayBuffer + Atomics |
| 性能加速 | SIMD intrinsics（Rust std::arch） |
| 构建工具 | Vite + wasm-pack-plugin / vite-plugin-wasm |
| 测试 | Vitest（前端）+ wasm-pack test（Wasm 模块） |
| CI/CD | GitHub Actions（构建 + 测试 + 部署） |

## 验证方式

在项目根目录运行验证脚本：

```bash
node scripts/check.cjs
```

脚本会检查：
- 必要的文件和目录结构是否存在
- Rust Cargo.toml 配置是否正确
- 前端代码是否包含 Wasm 集成的关键模式
- Worker 相关代码是否正确实现
- 测试文件是否齐全
