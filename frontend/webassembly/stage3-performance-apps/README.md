# Stage 3: 性能应用

## 阶段概述

本阶段聚焦 WebAssembly 在高性能场景下的实际应用。从 SIMD 指令集加速、多线程并行计算，到音视频实时处理、物理引擎模拟和浏览器端密码学计算，每节课都围绕一个真实的性能密集型场景展开，让你掌握 WASM 在生产环境中的核心应用模式。

## 前置要求

- 完成 Stage 1（WASM 基础）和 Stage 2（Rust + WASM）
- 熟悉 Rust 基本语法和 wasm-bindgen 用法
- 了解浏览器渲染管线和基本并发概念

## 课程列表

| 序号 | 课程 | 主题 | 核心技能 |
|------|------|------|----------|
| 01 | SIMD 指令 | 向量化计算加速 | v128 类型、i32x4/f32x4 操作、性能对比 |
| 02 | 多线程 WASM | 并行计算架构 | SharedArrayBuffer、Atomics、线程池 |
| 03 | 音视频处理 | 多媒体数据处理 | Web Audio API、视频帧提取、实时滤镜 |
| 04 | 物理引擎 | 游戏物理模拟 | Rapier.js、碰撞检测、物理步进 |
| 05 | 密码学计算 | 浏览器端加密 | SHA-256、RSA/ECDSA、零知识证明基础 |
| 06 | 阶段实战 | 实时音视频滤镜 | 完整滤镜管道、SIMD 优化、移动端适配 |

## 学习目标

完成本阶段后，你将能够：

1. **使用 SIMD 指令**对 WASM 代码进行向量化加速，理解 128 位向量操作的原理和适用场景
2. **实现多线程 WASM 应用**，掌握 SharedArrayBuffer 和 Atomics 的线程同步机制
3. **构建音视频处理管道**，用 WASM 实现实时图像和音频滤镜
4. **集成物理引擎**，理解刚体模拟、碰撞检测和物理步进的核心算法
5. **实现浏览器端密码学计算**，了解 WASM 在大数运算和加密算法中的性能优势
6. **完成一个完整的实时音视频滤镜应用**，综合运用 SIMD、多线程和 Canvas 渲染技术

## 阶段项目

本阶段的实战项目是**实时音视频滤镜应用**（第 06 课），它综合运用了前 5 课的知识：

- 使用摄像头捕获视频流（getUserMedia）
- WASM 实现多种滤镜（灰度、模糊、边缘检测）
- SIMD 优化关键计算路径
- Canvas 实时渲染处理后的帧
- 性能监控与移动端适配

## 环境准备

```bash
# 确保 Rust 工具链已安装
rustup target add wasm32-unknown-unknown

# 安装 wasm-pack
cargo install wasm-pack

# 安装 Node.js 依赖（用于开发服务器）
npm install -g http-server

# 验证浏览器 SIMD 支持
# Chrome 91+ / Firefox 89+ / Safari 16.4+
```

## 学习建议

1. **按顺序学习**：每课的知识点会逐步递进，第 06 课的实战综合了前面所有内容
2. **动手实践**：每课都有练习题，务必完成代码编写
3. **关注性能**：本阶段的核心是性能，建议用浏览器 DevTools 的 Performance 面板对比优化前后的差异
4. **注意浏览器兼容性**：SIMD 和多线程特性需要较新版本的浏览器，开发前请确认支持情况
