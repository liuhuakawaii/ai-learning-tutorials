# 04 - 物理引擎：游戏物理模拟

## 场景引入

假设你正在开发一个 2D 游戏，里面有弹跳的球、碰撞的方块和绳索连接的物体。你需要让这些物体遵循物理定律运动——重力、碰撞反弹、摩擦力。

在 JavaScript 中实现物理模拟不仅代码复杂，而且性能难以满足大量物体的需求。WebAssembly 可以将物理计算密集的部分移到原生性能的代码中，让浏览器中的游戏物理效果媲美原生应用。

本课将讲解物理引擎的核心概念，并演示如何用 Rust 实现简单的 2D 物理系统，以及如何集成成熟的物理引擎库 Rapier.js。

## 学习目标

- 理解物理引擎的核心组件：刚体、碰撞检测、约束
- 掌握 AABB 和圆形碰撞检测算法

## 物理引擎基础

### 核心概念

物理引擎模拟现实世界的物理行为，主要包含三个核心组件：

**刚体（Rigid Body）**：不会变形的物体，具有位置、速度、旋转、质量等属性。

```
刚体属性：
├── 位置（position）：物体在空间中的坐标
├── 速度（velocity）：物体的运动速度和方向
├── 加速度（acceleration）：力作用下的速度变化率
├── 旋转（rotation）：物体的朝向角度
├── 角速度（angular_velocity）：旋转的速度
├── 质量（mass）：物体的惯性大小
└── 类型（body_type）：
    ├── Dynamic：受力和碰撞影响（如球）
    ├── Kinematic：不受力影响，但可以碰撞（如移动平台）
    └── Static：完全不动（如地面）
```

**碰撞检测（Collision Detection）**：判断两个物体是否接触，并计算碰撞响应。

**约束（Constraint）**：限制物体运动的条件，如铰链、弹簧、绳索。

### 物理步进

物理引擎以固定的时间步长（通常 1/60 秒）更新模拟状态：

```
每一帧的处理流程：
1. 应用力（重力、用户施加的力）
2. 积分（更新速度和位置）
3. 碰撞检测
4. 碰撞响应
5. 约束求解
```

## 碰撞检测算法

### AABB（轴对齐包围盒）

AABB 是最简单的碰撞检测算法，用一个与坐标轴对齐的矩形包围物体：

```rust
// src/collision.rs
use wasm_bindgen::prelude::*;

/// AABB 碰撞检测
#[wasm_bindgen]
pub struct AABB {
    pub x: f32,      // 左上角 x
    pub y: f32,      // 左上角 y
    pub width: f32,
    pub height: f32,
}

#[wasm_bindgen]
impl AABB {
    #[wasm_bindgen(constructor)]
    pub fn new(x: f32, y: f32, width: f32, height: f32) -> AABB {
        AABB { x, y, width, height }
    }

    /// 检测两个 AABB 是否重叠
    pub fn intersects(&self, other: &AABB) -> bool {
        self.x < other.x + other.width
            && self.x + self.width > other.x
            && self.y < other.y + other.height
            && self.y + self.height > other.y
    }

    /// 计算重叠区域（用于碰撞响应）
    pub fn overlap(&self, other: &AABB) -> Option<OverlapResult> {
        let overlap_x = (self.x + self.width).min(other.x + other.width)
                       - self.x.max(other.x);
        let overlap_y = (self.y + self.height).min(other.y + other.height)
                       - self.y.max(other.y);

        if overlap_x > 0.0 && overlap_y > 0.0 {
            // 选择最小穿透轴
            if overlap_x < overlap_y {
                let normal_x = if self.x + self.width / 2.0 < other.x + other.width / 2.0 {
                    -1.0
                } else {
                    1.0
                };
                Some(OverlapResult {
                    normal_x,
                    normal_y: 0.0,
                    depth: overlap_x,
                })
            } else {
                let normal_y = if self.y + self.height / 2.0 < other.y + other.height / 2.0 {
                    -1.0
                } else {
                    1.0
                };
                Some(OverlapResult {
                    normal_x: 0.0,
                    normal_y,
                    depth: overlap_y,
                })
            }
        } else {
            None
        }
    }
}

/// 碰撞结果：法线方向和穿透深度
#[wasm_bindgen]
pub struct OverlapResult {
    pub normal_x: f32,
    pub normal_y: f32,
    pub depth: f32,
}
```

### 圆形碰撞检测

```rust
/// 圆形碰撞检测
#[wasm_bindgen]
pub struct Circle {
    pub x: f32,
    pub y: f32,
    pub radius: f32,
}

#[wasm_bindgen]
impl Circle {
    #[wasm_bindgen(constructor)]
    pub fn new(x: f32, y: f32, radius: f32) -> Circle {
        Circle { x, y, radius }
    }

    /// 检测两个圆是否重叠
    pub fn intersects(&self, other: &Circle) -> bool {
        let dx = self.x - other.x;
        let dy = self.y - other.y;
        let distance_sq = dx * dx + dy * dy;
        let radius_sum = self.radius + other.radius;
        distance_sq < radius_sum * radius_sum
    }

    /// 计算碰撞法线和穿透深度
    pub fn collision_info(&self, other: &Circle) -> Option<OverlapResult> {
        let dx = other.x - self.x;
        let dy = other.y - self.y;
        let distance_sq = dx * dx + dy * dy;
        let radius_sum = self.radius + other.radius;

        if distance_sq < radius_sum * radius_sum {
            let distance = distance_sq.sqrt();
            if distance < 0.0001 {
                // 两圆完全重叠，任意选择一个方向
                return Some(OverlapResult {
                    normal_x: 1.0,
                    normal_y: 0.0,
                    depth: radius_sum,
                });
            }

            let normal_x = dx / distance;
            let normal_y = dy / distance;
            let depth = radius_sum - distance;

            Some(OverlapResult {
                normal_x,
                normal_y,
                depth,
            })
        } else {
            None
        }
    }
}
```

## 简单 2D 物理系统

### 物理世界

```rust
// src/physics.rs
use wasm_bindgen::prelude::*;

/// 物理世界：管理所有刚体和碰撞
#[wasm_bindgen]
pub struct PhysicsWorld {
    // 每个刚体的位置、速度、加速度
    positions_x: Vec<f32>,
    positions_y: Vec<f32>,
    velocities_x: Vec<f32>,
    velocities_y: Vec<f32>,
    // 刚体属性
    radii: Vec<f32>,        // 用圆形表示
    masses: Vec<f32>,
    restitutions: Vec<f32>, // 弹性系数
    is_static: Vec<bool>,
    // 世界参数
    gravity_x: f32,
    gravity_y: f32,
    num_bodies: usize,
}

#[wasm_bindgen]
impl PhysicsWorld {
    #[wasm_bindgen(constructor)]
    pub fn new(gravity_x: f32, gravity_y: f32) -> PhysicsWorld {
        PhysicsWorld {
            positions_x: Vec::new(),
            positions_y: Vec::new(),
            velocities_x: Vec::new(),
            velocities_y: Vec::new(),
            radii: Vec::new(),
            masses: Vec::new(),
            restitutions: Vec::new(),
            is_static: Vec::new(),
            gravity_x,
            gravity_y,
            num_bodies: 0,
        }
    }

    /// 添加一个圆形刚体
    pub fn add_circle(
        &mut self,
        x: f32, y: f32,
        radius: f32,
        mass: f32,
        restitution: f32,
        static_body: bool
    ) -> usize {
        let id = self.num_bodies;
        self.positions_x.push(x);
        self.positions_y.push(y);
        self.velocities_x.push(0.0);
        self.velocities_y.push(0.0);
        self.radii.push(radius);
        self.masses.push(mass);
        self.restitutions.push(restitution);
        self.is_static.push(static_body);
        self.num_bodies += 1;
        id
    }

    /// 物理步进：更新一个时间步
    pub fn step(&mut self, dt: f32) {
        // 1. 应用重力和积分
        for i in 0..self.num_bodies {
            if self.is_static[i] {
                continue;
            }

            // 速度 += 加速度 * 时间
            self.velocities_x[i] += self.gravity_x * dt;
            self.velocities_y[i] += self.gravity_y * dt;

            // 位置 += 速度 * 时间
            self.positions_x[i] += self.velocities_x[i] * dt;
            self.positions_y[i] += self.velocities_y[i] * dt;
        }

        // 2. 碰撞检测和响应
        for i in 0..self.num_bodies {
            for j in (i + 1)..self.num_bodies {
                self.resolve_collision(i, j);
            }
        }
    }

    /// 处理两个刚体之间的碰撞
    fn resolve_collision(&mut self, i: usize, j: usize) {
        let dx = self.positions_x[j] - self.positions_x[i];
        let dy = self.positions_y[j] - self.positions_y[i];
        let distance_sq = dx * dx + dy * dy;
        let radius_sum = self.radii[i] + self.radii[j];

        if distance_sq >= radius_sum * radius_sum {
            return; // 没有碰撞
        }

        let distance = distance_sq.sqrt();
        if distance < 0.0001 {
            return;
        }

        // 碰撞法线
        let nx = dx / distance;
        let ny = dy / distance;

        // 穿透深度
        let depth = radius_sum - distance;

        // 分离物体（位置修正）
        let total_mass = if self.is_static[i] {
            self.masses[j]
        } else if self.is_static[j] {
            self.masses[i]
        } else {
            self.masses[i] + self.masses[j]
        };

        if !self.is_static[i] {
            let ratio = if self.is_static[j] {
                1.0
            } else {
                self.masses[j] / total_mass
            };
            self.positions_x[i] -= nx * depth * ratio;
            self.positions_y[i] -= ny * depth * ratio;
        }

        if !self.is_static[j] {
            let ratio = if self.is_static[i] {
                1.0
            } else {
                self.masses[i] / total_mass
            };
            self.positions_x[j] += nx * depth * ratio;
            self.positions_y[j] += ny * depth * ratio;
        }

        // 速度响应（弹性碰撞）
        let relative_vx = self.velocities_x[i] - self.velocities_x[j];
        let relative_vy = self.velocities_y[i] - self.velocities_y[j];
        let relative_velocity_normal = relative_vx * nx + relative_vy * ny;

        // 如果物体在分离，不需要响应
        if relative_velocity_normal > 0.0 {
            return;
        }

        let restitution = self.restitutions[i].min(self.restitutions[j]);
        let impulse = -(1.0 + restitution) * relative_velocity_normal;

        if !self.is_static[i] {
            let ratio = if self.is_static[j] {
                1.0 / self.masses[i]
            } else {
                1.0 / total_mass
            };
            self.velocities_x[i] += impulse * nx * self.masses[j] * ratio;
            self.velocities_y[i] += impulse * ny * self.masses[j] * ratio;
        }

        if !self.is_static[j] {
            let ratio = if self.is_static[i] {
                1.0 / self.masses[j]
            } else {
                1.0 / total_mass
            };
            self.velocities_x[j] -= impulse * nx * self.masses[i] * ratio;
            self.velocities_y[j] -= impulse * ny * self.masses[i] * ratio;
        }
    }

    // 获取器：供 JavaScript 渲染使用
    pub fn get_positions_x(&self) -> Vec<f32> { self.positions_x.clone() }
    pub fn get_positions_y(&self) -> Vec<f32> { self.positions_y.clone() }
    pub fn get_radii(&self) -> Vec<f32> { self.radii.clone() }
    pub fn get_num_bodies(&self) -> usize { self.num_bodies }

    /// 设置某个刚体的速度
    pub fn set_velocity(&mut self, id: usize, vx: f32, vy: f32) {
        if id < self.num_bodies {
            self.velocities_x[id] = vx;
            self.velocities_y[id] = vy;
        }
    }
}
```

## Rapier.js 集成

Rapier 是一个用 Rust 编写的高性能物理引擎，提供 WASM 版本可以直接在浏览器中使用。

### 安装

### 基本使用

```javascript
// rapier-demo.js
import RAPIER from '@dimforge/rapier2d-compat';

async function initPhysics() {
    // 初始化 Rapier（加载 WASM 模块）
    await RAPIER.init();

    // 创建物理世界
    const gravity = { x: 0.0, y: -9.81 };
    const world = new RAPIER.World(gravity);

    // 创建地面（静态刚体）
    const groundBody = world.createRigidBody(
        RAPIER.RigidBodyDesc.fixed()
            .setTranslation(0.0, -10.0)
    );
    const groundCollider = world.createCollider(
        RAPIER.ColliderDesc.cuboid(50.0, 0.5),
        groundBody
    );

    // 创建动态球体
    const ballBody = world.createRigidBody(
        RAPIER.RigidBodyDesc.dynamic()
            .setTranslation(0.0, 5.0)
    );
    const ballCollider = world.createCollider(
        RAPIER.ColliderDesc.ball(0.5),
        ballBody
    );

    // 游戏循环
    function gameLoop() {
        // 物理步进
        world.step();

        // 获取球体位置
        const pos = ballBody.translation();
        console.log(`球体位置: (${pos.x.toFixed(2)}, ${pos.y.toFixed(2)})`);

        // 渲染（这里只是示例，实际会更新 Canvas 或 WebGL）
        requestAnimationFrame(gameLoop);
    }

    gameLoop();
}

initPhysics();
```

```javascript
    function processEvents() {
        world.step(eventQueue);

        eventQueue.drainCollisionEvents((handle1, handle2, started) => {
```

## 物理步进与渲染循环集成

### 固定时间步长

```javascript
// game-loop.js
class GameLoop {
    constructor(physicsWorld, renderer) {
        this.world = physicsWorld;
        this.renderer = renderer;
        this.fixedDt = 1.0 / 60.0; // 物理固定步长
        this.accumulator = 0.0;
        this.lastTime = 0;
    }

    start() {
        this.lastTime = performance.now() / 1000.0;
        requestAnimationFrame((time) => this.update(time));
    }

    update(currentTime) {
        const now = currentTime / 1000.0;
        let frameTime = now - this.lastTime;
        this.lastTime = now;

        // 防止螺旋死亡（spiral of death）
        if (frameTime > 0.25) {
            frameTime = 0.25;
        }

        this.accumulator += frameTime;

        // 物理更新：固定时间步长
        while (this.accumulator >= this.fixedDt) {
            this.world.step(this.fixedDt);
            this.accumulator -= this.fixedDt;
        }

        // 插值因子：用于平滑渲染
        const alpha = this.accumulator / this.fixedDt;
        this.renderer.render(alpha);

        requestAnimationFrame((time) => this.update(time));
    }
}
```

### 位置插值

```javascript
// renderer.js
class PhysicsRenderer {
    constructor(canvas, physicsWorld) {
        this.canvas = canvas;
        this.ctx = canvas.getContext('2d');
        this.world = physicsWorld;
        // 存储上一帧的位置，用于插值
        this.prevPositions = [];
    }

    render(alpha) {
        this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);

        const positions = this.world.get_positions_x();
        const positionsY = this.world.get_positions_y();
        const radii = this.world.get_radii();

        for (let i = 0; i < this.world.get_num_bodies(); i++) {
            // 位置插值
            let renderX, renderY;
            if (this.prevPositions[i]) {
                renderX = this.prevPositions[i].x * (1 - alpha) + positions[i] * alpha;
                renderY = this.prevPositions[i].y * (1 - alpha) + positionsY[i] * alpha;
            } else {
                renderX = positions[i];
                renderY = positionsY[i];
            }

            // 坐标转换（物理坐标 → 屏幕坐标）
            const screenX = renderX * 50 + this.canvas.width / 2;
            const screenY = this.canvas.height / 2 - renderY * 50;
            const screenRadius = radii[i] * 50;

            // 绘制圆形
            this.ctx.beginPath();
            this.ctx.arc(screenX, screenY, screenRadius, 0, Math.PI * 2);
            this.ctx.fillStyle = '#4a90d9';
            this.ctx.fill();
            this.ctx.strokeStyle = '#2c5f8a';
            this.ctx.lineWidth = 2;
            this.ctx.stroke();
        }

        // 保存当前帧位置
        this.prevPositions = positions.map((x, i) => ({
            x, y: positionsY[i]
        }));
    }
}
```

## 常见误区

**1. 不固定时间步长**

如果物理步长随帧率变化，模拟结果会不稳定——帧率高时物体运动快，帧率低时运动慢。必须使用固定时间步长，并用插值平滑渲染。

**2. 忽略"螺旋死亡"**

当一帧的处理时间过长时，累积的物理步进会越来越多，导致下一帧更长，形成恶性循环。需要限制最大帧时间。

**3. 碰撞检测遗漏（隧穿效应）**

高速运动的物体可能在一帧内穿过薄物体。解决方案是使用连续碰撞检测（CCD）或限制物体最大速度。

**4. 过度精确的物理模拟**

游戏物理不需要完全符合真实物理定律。可以适当"作弊"——如增加弹性、减小摩擦——让游戏感觉更好。

## 工程建议

1. **使用成熟的物理引擎**：除非是学习目的，否则使用 Rapier 等成熟引擎，自己实现的物理引擎很难处理所有边界情况
2. **固定时间步长 + 插值**：物理用固定步长，渲染用插值，这是物理引擎集成的标准做法
3. **空间分区优化**：对于大量物体，使用四叉树或网格分区减少碰撞检测的对数
4. **分层碰撞**：用碰撞组（collision groups）让不同类型的物体只与特定物体碰撞
5. **性能监控**：物理步进通常是游戏循环中最耗时的部分，需要持续监控

## 小结

物理引擎是游戏和交互应用的核心组件：

- 刚体、碰撞检测和约束是物理引擎的三大核心
- AABB 和圆形碰撞是最基础的检测算法
- 物理步进需要固定时间步长，渲染需要位置插值
- Rapier.js 提供了成熟的 Rust 物理引擎的 WASM 版本
- 注意隧穿效应、螺旋死亡等常见问题

## 参考答案

### 练习一

**思路**：添加 4 个静态矩形（上下左右边界），在碰撞检测中处理圆-矩形碰撞。

```rust
use wasm_bindgen::prelude::*;

/// 边界墙
#[wasm_bindgen]
pub struct BoundaryWall {
    pub x: f32,
    pub y: f32,
    pub width: f32,
    pub height: f32,
}

#[wasm_bindgen]
impl BoundaryWall {
    #[wasm_bindgen(constructor)]
    pub fn new(x: f32, y: f32, width: f32, height: f32) -> BoundaryWall {
        BoundaryWall { x, y, width, height }
    }
}

/// 圆-矩形碰撞检测
pub fn circle_rect_collision(
    cx: f32, cy: f32, radius: f32,
    rx: f32, ry: f32, rw: f32, rh: f32
) -> Option<(f32, f32, f32)> {
    // 找到矩形上离圆心最近的点
    let closest_x = cx.max(rx).min(rx + rw);
    let closest_y = cy.max(ry).min(ry + rh);

    let dx = cx - closest_x;
    let dy = cy - closest_y;
    let dist_sq = dx * dx + dy * dy;

    if dist_sq < radius * radius {
        let dist = dist_sq.sqrt();
        if dist < 0.0001 {
            // 圆心在矩形内部
            return Some((0.0, 1.0, radius));
        }
        let nx = dx / dist;
        let ny = dy / dist;
        let depth = radius - dist;
        Some((nx, ny, depth))
    } else {
        None
    }
}

/// 在 PhysicsWorld 中添加边界检查
pub fn check_boundaries(
    pos_x: &mut f32, pos_y: &mut f32,
    vel_x: &mut f32, vel_y: &mut f32,
    radius: f32,
    min_x: f32, max_x: f32,
    min_y: f32, max_y: f32,
    restitution: f32
) {
    // 左边界
    if *pos_x - radius < min_x {
        *pos_x = min_x + radius;
        *vel_x = -*vel_x * restitution;
    }
    // 右边界
    if *pos_x + radius > max_x {
        *pos_x = max_x - radius;
        *vel_x = -*vel_x * restitution;
    }
    // 下边界
    if *pos_y - radius < min_y {
        *pos_y = min_y + radius;
        *vel_y = -*vel_y * restitution;
    }
    // 上边界
    if *pos_y + radius > max_y {
        *pos_y = max_y - radius;
        *vel_y = -*vel_y * restitution;
    }
}
```

**要点**：
- 圆-矩形碰撞的核心是找矩形上离圆心最近的点
- 边界碰撞需要修正位置，防止物体卡在墙里
- 弹性系数衰减可以用乘法实现

### 练习二

**思路**：在碰撞响应后，将弹性系数乘以衰减因子。

```rust
/// 在碰撞响应中添加弹性衰减
fn resolve_collision_with_decay(&mut self, i: usize, j: usize) {
    // ... 碰撞检测代码 ...

    // 计算弹性系数时应用衰减
    let decay_factor = 0.98;
    let base_restitution = self.restitutions[i].min(self.restitutions[j]);
    let effective_restitution = base_restitution * decay_factor;

    // 更新衰减后的弹性系数
    self.restitutions[i] *= decay_factor;
    self.restitutions[j] *= decay_factor;

    // 防止弹性系数降到 0
    if self.restitutions[i] < 0.01 {
        self.restitutions[i] = 0.01;
    }
    if self.restitutions[j] < 0.01 {
        self.restitutions[j] = 0.01;
    }

    // ... 使用 effective_restitution 计算冲量 ...
}
```

**要点**：
- 衰减因子 0.98 意味着每次碰撞损失 2% 的弹性
- 设置最小弹性系数防止物体完全停止弹跳
- 可以根据碰撞速度调整衰减——碰撞越猛烈，衰减越大

### 练习三

**思路**：用 Rapier.js 创建弹珠台场景：斜面用旋转的静态刚体，障碍物用小圆形静态刚体。

```javascript
import RAPIER from '@dimforge/rapier2d-compat';

async function createPinball() {
    await RAPIER.init();

    const gravity = { x: 0.0, y: -9.81 };
    const world = new RAPIER.World(gravity);

    // 底部边界
    const floor = world.createRigidBody(RAPIER.RigidBodyDesc.fixed());
    world.createCollider(
        RAPIER.ColliderDesc.cuboid(5.0, 0.2).setTranslation(0.0, -8.0),
        floor
    );

    // 左右边界
    const leftWall = world.createRigidBody(RAPIER.RigidBodyDesc.fixed());
    world.createCollider(
        RAPIER.ColliderDesc.cuboid(0.2, 8.0).setTranslation(-5.0, 0.0),
        leftWall
    );

    const rightWall = world.createRigidBody(RAPIER.RigidBodyDesc.fixed());
    world.createCollider(
        RAPIER.ColliderDesc.cuboid(0.2, 8.0).setTranslation(5.0, 0.0),
        rightWall
    );

    // 斜面（用旋转的静态刚体）
    const ramp = world.createRigidBody(
        RAPIER.RigidBodyDesc.fixed()
            .setTranslation(-2.0, 2.0)
            .setRotation(-0.3) // 约 17 度倾斜
    );
    world.createCollider(
        RAPIER.ColliderDesc.cuboid(3.0, 0.1),
        ramp
    );

    // 障碍物（圆形）
    const obstaclePositions = [
        { x: 0.0, y: 0.0 },
        { x: -1.5, y: -2.0 },
        { x: 1.5, y: -2.0 },
        { x: 0.0, y: -4.0 },
    ];

    for (const pos of obstaclePositions) {
        const obstacle = world.createRigidBody(
            RAPIER.RigidBodyDesc.fixed().setTranslation(pos.x, pos.y)
        );
        world.createCollider(
            RAPIER.ColliderDesc.ball(0.3),
            obstacle
        );
    }

    // 弹珠
    const marble = world.createRigidBody(
        RAPIER.RigidBodyDesc.dynamic()
            .setTranslation(0.0, 5.0)
            .setLinearDamping(0.1)
    );
    world.createCollider(
        RAPIER.ColliderDesc.ball(0.2)
            .setRestitution(0.7)
            .setDensity(1.0),
        marble
    );

    // 游戏循环
    function gameLoop() {
        world.step();

        const pos = marble.translation();
        // 更新渲染...

        requestAnimationFrame(gameLoop);
    }

    gameLoop();
}
```

**要点**：
- 弹珠台的关键是斜面和障碍物的布局
