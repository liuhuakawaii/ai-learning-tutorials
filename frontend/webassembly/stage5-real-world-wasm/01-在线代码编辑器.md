# 在线代码编辑器

## 用 WASM 做什么

在线代码编辑器需要两个 WASM 模块：

1. **语法高亮**：把源代码解析为 token 流，生成带样式的 HTML
2. **代码执行**：在沙箱中运行用户代码，捕获输出

语法高亮是 CPU 密集型——大文件（10000+ 行）需要逐字符解析。代码执行需要安全隔离——用户代码不能访问宿主环境。

## 技术栈

- Monaco Editor（编辑器组件）
- WASM 语法分析器（Rust 实现）
- WASM 沙箱执行器（WASI 或自定义沙箱）

## 语法高亮

用 Rust 实现一个简单的词法分析器：

```rust
// highlighter.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn highlight_js(source: &str) -> String {
    let mut html = String::new();
    let chars: Vec<char> = source.chars().collect();
    let mut i = 0;

    while i < chars.len() {
        // 关键字
        if is_keyword_start(chars, i) {
            let (token, end) = read_keyword(&chars, i);
            if is_keyword(&token) {
                html.push_str(&format!("<span class=\"kw\">{}</span>", token));
            } else if is_string_literal(&token) {
                html.push_str(&format!("<span class=\"str\">{}</span>", token));
            } else {
                html.push_str(&token);
            }
            i = end;
        }
        // 字符串
        else if chars[i] == '"' || chars[i] == '\'' || chars[i] == '`' {
            let (token, end) = read_string(&chars, i);
            html.push_str(&format!("<span class=\"str\">{}</span>", token));
            i = end;
        }
        // 注释
        else if chars[i] == '/' && i + 1 < chars.len() && chars[i+1] == '/' {
            let end = chars[i..].iter().position(|&c| c == '\n').unwrap_or(chars.len() - i);
            html.push_str(&format!("<span class=\"cmt\">{}</span>", &source[i..i+end]));
            i += end;
        }
        // 数字
        else if chars[i].is_ascii_digit() {
            let (token, end) = read_number(&chars, i);
            html.push_str(&format!("<span class=\"num\">{}</span>", token));
            i = end;
        }
        // 标识符
        else if chars[i].is_alphabetic() || chars[i] == '_' {
            let (token, end) = read_identifier(&chars, i);
            html.push_str(&token);
            i = end;
        }
        // 其他字符
        else {
            html.push_str(&chars[i].to_string());
            i += 1;
        }
    }

    html
}

fn is_keyword(s: &str) -> bool {
    matches!(s, "const" | "let" | "var" | "function" | "return" | "if" | "else" | "for" | "while" | "class" | "import" | "export" | "default" | "from" | "async" | "await" | "new" | "this" | "true" | "false" | "null" | "undefined")
}
```

## 编辑器集成

```typescript
import Editor from '@monaco-editor/react'

function CodeEditor() {
  const [code, setCode] = useState('')
  const [highlighted, setHighlighted] = useState('')

  useEffect(() => {
    // 用 WASM 高亮
    import('./pkg/highlighter.js').then(({ highlight_js }) => {
      setHighlighted(highlight_js(code))
    })
  }, [code])

  return (
    <div className="editor-container">
      <Editor
        language="javascript"
        value={code}
        onChange={setCode}
        theme="vs-dark"
        options={{ minimap: { enabled: false } }}
      />
      <div className="preview" dangerouslySetInnerHTML={{ __html: highlighted }} />
    </div>
  )
}
```

## 代码执行沙箱

```rust
// executor.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct Executor {
    output: Vec<String>,
}

#[wasm_bindgen]
impl Executor {
    #[wasm_bindgen(constructor)]
    pub fn new() -> Self { Self { output: Vec::new() } }

    pub fn execute(&mut self, code: &str) -> String {
        self.output.clear();

        // 简单的表达式求值
        // 生产环境应该用完整的 JS 解释器
        for line in code.lines() {
            let trimmed = line.trim();
            if trimmed.starts_with("console.log(") {
                let inner = &trimmed[12..trimmed.len()-1];
                self.output.push(format!("{}\n", inner));
            }
        }

        self.output.join("")
    }

    pub fn get_output(&self) -> String {
        self.output.join("")
    }
}
```
