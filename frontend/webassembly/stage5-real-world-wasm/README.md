# Stage 5: 真实项目

## 阶段概述

本阶段将前四个阶段积累的 WASM 知识应用到真实工程项目中。你将从零构建四个完整应用——在线代码编辑器、图像编辑器、数据可视化引擎和游戏引擎，每个项目都深度使用 WebAssembly 处理核心计算逻辑。最后通过性能优化实战和综合项目，掌握 WASM 工程化的完整链路。

## 学习目标

- 掌握 WASM 在大型前端项目中的架构设计模式
- 学会用 WASM 实现高性能编辑器、图形处理、数据可视化和游戏引擎
- 掌握 WASM 应用的性能分析与优化方法论
- 理解 WASM 模块与前端框架（Vue/React）的集成模式
- 具备独立设计和交付 WASM 驱动的生产级应用的能力

## 前置要求

- 完成 Stage 1-4 的学习
- 熟悉 Rust 语言基础和 wasm-bindgen 工具链
- 了解 Canvas 2D / WebGL 基本用法
- 熟悉 Vue3 或 React 框架
- 安装 Rust 工具链、wasm-pack、Node.js 18+

## 学习建议

1. 每个项目都建议先通读全文，理解架构设计后再动手编码
2. 代码示例是可运行的最小完整实现，务必亲手敲一遍
3. 每课末尾的练习是项目功能的扩展，完成它们能加深理解
4. 第 6 课的综合项目建议用 2-3 天完整做完，它是整个课程的毕业设计
