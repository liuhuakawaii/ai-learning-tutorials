# 03 - 数据可视化引擎

## 场景引入

你在做金融数据看板，需要渲染 10 万个实时数据点。JavaScript 排序 10 万条数据需要 120ms，Canvas 逐点绘制需要 200ms。两者加起来超过 300ms，拖动时间轴时明显掉帧。WASM 可以把排序压到 8ms，配合 WebGL 实例化渲染把绘制压到 5ms。

## 学习目标

- 掌握用 WASM 处理大规模数据集（排序、聚合、采样）
- 理解 WebGL 实例化渲染
- 学会实现视口裁剪和 LOD 策略
- 掌握内存池设计

## WASM 数据处理

```rust
// src/data_engine.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct DataEngine {
    x: Vec<f64>, y: Vec<f64>,    // SoA 布局，缓存友好
    timestamps: Vec<f64>,
    categories: Vec<u8>,
    len: usize,
}

#[wasm_bindgen]
impl DataEngine {
    #[wasm_bindgen(constructor)]
    pub fn new(capacity: usize) -> Self {
        DataEngine {
            x: vec![0.0; capacity], y: vec![0.0; capacity],
            timestamps: vec![0.0; capacity], categories: vec![0; capacity], len: 0,
        }
    }

    pub fn load_batch(&mut self, x: &[f64], y: &[f64], ts: &[f64], cat: &[u8]) {
        let count = x.len().min(self.x.len());
        self.x[..count].copy_from_slice(&x[..count]);
        self.y[..count].copy_from_slice(&y[..count]);
        self.timestamps[..count].copy_from_slice(&ts[..count]);
        self.categories[..count].copy_from_slice(&cat[..count]);
        self.len = count;
    }

    pub fn len(&self) -> usize { self.len }
    pub fn x_ptr(&self) -> *const f64 { self.x.as_ptr() }
    pub fn y_ptr(&self) -> *const f64 { self.y.as_ptr() }

    // 按 x 排序
    pub fn sort_by_x(&mut self) {
        let mut idx: Vec<usize> = (0..self.len).collect();
        idx.sort_unstable_by(|&a, &b| self.x[a].total_cmp(&self.x[b]));
        let (mut sx, mut sy, mut st, mut sc) = (vec![0.0; self.len], vec![0.0; self.len], vec![0.0; self.len], vec![0u8; self.len]);
        for (n, &o) in idx.iter().enumerate() {
            sx[n] = self.x[o]; sy[n] = self.y[o]; st[n] = self.timestamps[o]; sc[n] = self.categories[o];
        }
        self.x[..self.len].copy_from_slice(&sx);
        self.y[..self.len].copy_from_slice(&sy);
        self.timestamps[..self.len].copy_from_slice(&st);
        self.categories[..self.len].copy_from_slice(&sc);
    }

    // 按范围过滤（二分查找）
    pub fn filter_by_range(&self, x_min: f64, x_max: f64) -> Vec<u32> {
        let left = self.x[..self.len].partition_point(|&v| v < x_min);
        let right = self.x[..self.len].partition_point(|&v| v <= x_max);
        (left as u32..right as u32).collect()
    }

    // LTTB 降采样：保留数据形状特征
    pub fn aggregate_lttb(&self, target: usize) -> (Vec<f64>, Vec<f64>) {
        if self.len <= target || target < 3 { return (self.x[..self.len].to_vec(), self.y[..self.len].to_vec()); }
        let (mut rx, mut ry) = (vec![0.0f64; target], vec![0.0f64; target]);
        rx[0] = self.x[0]; ry[0] = self.y[0];
        rx[target-1] = self.x[self.len-1]; ry[target-1] = self.y[self.len-1];
        let bucket = (self.len - 2) as f64 / (target - 2) as f64;
        let mut a = 0usize;
        for i in 1..target-1 {
            let bs = ((i-1) as f64 * bucket) as usize + 1;
            let be = ((i as f64 * bucket) as usize + 1).min(self.len - 1);
            let ns = (i as f64 * bucket) as usize + 1;
            let ne = ((i+1) as f64 * bucket) as usize + 1;
            let (ax, ay) = self.bucket_avg(ns.min(self.len-1), ne.min(self.len-1));
            let (mut max_area, mut max_idx) = (-1.0f64, bs);
            for j in bs..=be {
                let area = ((self.x[a] - ax) * (self.y[j] - self.y[a]) - (self.x[a] - self.x[j]) * (ay - self.y[a])).abs();
                if area > max_area { max_area = area; max_idx = j; }
            }
            rx[i] = self.x[max_idx]; ry[i] = self.y[max_idx]; a = max_idx;
        }
        (rx, ry)
    }

    fn bucket_avg(&self, s: usize, e: usize) -> (f64, f64) {
        let n = (e - s + 1) as f64;
        (self.x[s..=e].iter().sum::<f64>() / n, self.y[s..=e].iter().sum::<f64>() / n)
    }
}
```

## 视口裁剪与空间索引

```rust
// src/culling.rs
use wasm_bindgen::prelude::*;
use std::collections::HashMap;

#[wasm_bindgen]
pub struct SpatialGrid {
    cell_size: f64,
    grid: HashMap<(i32, i32), Vec<u32>>,
}

#[wasm_bindgen]
impl SpatialGrid {
    #[wasm_bindgen(constructor)]
    pub fn new(cell_size: f64) -> Self { SpatialGrid { cell_size, grid: HashMap::new() } }

    pub fn build(&mut self, x: &[f64], y: &[f64]) {
        self.grid.clear();
        for i in 0..x.len() {
            let gx = (x[i] / self.cell_size).floor() as i32;
            let gy = (y[i] / self.cell_size).floor() as i32;
            self.grid.entry((gx, gy)).or_default().push(i as u32);
        }
    }

    pub fn query(&self, x_min: f64, x_max: f64, y_min: f64, y_max: f64) -> Vec<u32> {
        let (xs, xe) = ((x_min / self.cell_size).floor() as i32, (x_max / self.cell_size).floor() as i32);
        let (ys, ye) = ((y_min / self.cell_size).floor() as i32, (y_max / self.cell_size).floor() as i32);
        let mut result = Vec::new();
        for gx in xs..=xe { for gy in ys..=ye {
            if let Some(indices) = self.grid.get(&(gx, gy)) { result.extend(indices); }
        }}
        result
    }
}
```

## LOD 策略

```typescript
// src/lod-manager.ts
import { DataEngine } from '../pkg/data_engine';

interface LODLevel { zoom: number; count: number; x: Float64Array; y: Float64Array; }

export class LODManager {
  private levels: LODLevel[] = [];

  constructor(private engine: DataEngine) {}

  buildLevels() {
    const thresholds = [
      { zoom: 0.1, count: 1000 }, { zoom: 0.5, count: 5000 },
      { zoom: 1.0, count: 20000 }, { zoom: 5.0, count: this.engine.len() },
    ];
    for (const { zoom, count } of thresholds) {
      const [x, y] = this.engine.aggregate_lttb(Math.min(count, this.engine.len()));
      this.levels.push({ zoom, count, x: new Float64Array(x), y: new Float64Array(y) });
    }
  }

  getLevel(zoom: number): LODLevel {
    return this.levels.reduce((best, lv) => zoom >= lv.zoom ? lv : best, this.levels[0]);
  }
}
```

## 与 D3.js 协作

D3 负责比例尺和坐标轴，WASM 负责数据处理：

```typescript
import * as d3 from 'd3';
import { DataEngine } from '../pkg/data_engine';

export class D3WasmBridge {
  private xScale: d3.ScaleLinear<number, number>;
  private yScale: d3.ScaleLinear<number, number>;
  constructor(private engine: DataEngine, w: number, h: number) {
    this.xScale = d3.scaleLinear().range([0, w]);
    this.yScale = d3.scaleLinear().range([h, 0]);
  }
  updateDomain() {
    const x = new Float64Array(this.engine.data_buffer, this.engine.x_ptr(), this.engine.len());
    const y = new Float64Array(this.engine.data_buffer, this.engine.y_ptr(), this.engine.len());
    this.xScale.domain(d3.extent(x) as [number, number]);
    this.yScale.domain(d3.extent(y) as [number, number]);
  }
  toScreenCoords(): Float32Array {
    const len = this.engine.len();
    const x = new Float64Array(this.engine.data_buffer, this.engine.x_ptr(), len);
    const y = new Float64Array(this.engine.data_buffer, this.engine.y_ptr(), len);
    const coords = new Float32Array(len * 2);
    for (let i = 0; i < len; i++) { coords[i*2] = this.xScale(x[i]); coords[i*2+1] = this.yScale(y[i]); }
    return coords;
  }
}
```

## 内存池设计

```rust
// src/pool.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct MemoryPool {
    small: Vec<Vec<u8>>, medium: Vec<Vec<u8>>, large: Vec<Vec<u8>>,
    allocated: usize, peak: usize,
}

#[wasm_bindgen]
impl MemoryPool {
    #[wasm_bindgen(constructor)]
    pub fn new() -> Self { MemoryPool { small: vec![], medium: vec![], large: vec![], allocated: 0, peak: 0 } }

    pub fn acquire(&mut self, size: usize) -> Vec<u8> {
        let bucket = if size < 4096 { &mut self.small } else if size < 262144 { &mut self.medium } else { &mut self.large };
        let buf = bucket.pop().filter(|b| b.capacity() >= size).unwrap_or_else(|| Vec::with_capacity(size));
        self.allocated += size; if self.allocated > self.peak { self.peak = self.allocated; }
        buf
    }

    pub fn release(&mut self, mut buf: Vec<u8>, size: usize) {
        buf.clear();
        let bucket = if size < 4096 { &mut self.small } else if size < 262144 { &mut self.medium } else { &mut self.large };
        if bucket.len() < 16 { bucket.push(buf); }
        self.allocated = self.allocated.saturating_sub(size);
    }

    pub fn peak_bytes(&self) -> usize { self.peak }
}
```

## 常见误区

1. **用 JS 排序再传给 WebGL** — 数据处理应在 WASM 中完成，只把屏幕坐标传给 WebGL
2. **渲染所有 10 万个点** — 视口裁剪和 LOD 是必须的
3. **每次缩放重新聚合** — 应预计算多个 LOD 级别，缩放时只切换
4. **用 Vec<f64> 传坐标给 WebGL** — WebGL 需要 f32，应在 WASM 中转换

## 工程建议

1. **SoA 优于 AoS** — `x: [f64], y: [f64]` 比 `points: [(f64, f64)]` 缓存更友好
2. **LTTB 保留数据形状** — 比随机采样好得多
3. **网格哈希加速空间查询** — O(1) 查找比遍历快几个数量级
4. **分离数据处理和渲染** — WASM 处理数据，WebGL 渲染，D3 做比例尺

## 小结

WASM 做排序、聚合、采样和裁剪，WebGL 做实例化渲染，D3 做比例尺。内存池避免频繁分配，空间索引加速裁剪，LTTB 降采样保留数据形状。三者各司其职，实现 10 万数据点 60fps。

```rust
pub fn compute_boxplot(&self) -> (Vec<u8>, Vec<f64>, Vec<f64>, Vec<f64>, Vec<f64>, Vec<f64>) {
    let mut groups: std::collections::BTreeMap<u8, Vec<f64>> = std::collections::BTreeMap::new();
    for i in 0..self.len { groups.entry(self.categories[i]).or_default().push(self.y[i]); }
    let (mut cats, mut mins, mut q1s, mut meds, mut q3s, mut maxs) = (vec![], vec![], vec![], vec![], vec![], vec![]);
    for (cat, mut vals) in groups {
        vals.sort_by(|a, b| a.total_cmp(b));
        let n = vals.len();
        cats.push(cat); mins.push(vals[0]); maxs.push(vals[n-1]);
        q1s.push(percentile(&vals, 25.0)); meds.push(percentile(&vals, 50.0)); q3s.push(percentile(&vals, 75.0));
    }
    (cats, mins, q1s, meds, q3s, maxs)
}

fn percentile(sorted: &[f64], p: f64) -> f64 {
    let idx = p / 100.0 * (sorted.len() - 1) as f64;
    let (lo, hi) = (idx.floor() as usize, idx.ceil() as usize);
    if lo == hi { sorted[lo] } else { sorted[lo] * (1.0 - idx + lo as f64) + sorted[hi] * (idx - lo as f64) }
}
```

**要点**：BTreeMap 保证 category 有序。

```rust
pub fn build_line_vertices(x: &[f64], y: &[f64], w: f64, h: f64) -> Vec<f32> {
    let mut verts = Vec::with_capacity(x.len() * 2);
```

```rust
pub fn interpolate(from: &[f64], to: &[f64], t: f64) -> Vec<f64> {
    let t = t.clamp(0.0, 1.0);
    from.iter().zip(to.iter()).map(|(a, b)| a + (b - a) * t).collect()
```
