# 02 - 图像编辑器

## 场景引入

你在做一个在线图片编辑工具，用户调整亮度、对比度时，4000×3000 的图片（1200 万像素）在 JavaScript 中单个滤镜需要 300ms，叠加 3 个滤镜就是 900ms，拖动滑块时明显卡顿。WASM 能把单个滤镜压到 40ms 以内，多个滤镜可以用管道模式一次遍历完成。

## 学习目标

- 掌握 Canvas 渲染管线与 WASM 滤镜的集成架构
- 理解管道模式在图像处理中的应用
- 学会实现撤销/重做（命令模式）
- 掌握图层系统和混合模式

## 架构设计

```
UI 层 (Vue/React)  →  Canvas 渲染管线  →  WASM 核心  →  像素数据 (ArrayBuffer)
  工具栏/图层面板      图层合成→滤镜→输出    滤镜/直方图     ImageData/历史记录
```

关键决策：像素数据存储在 WASM 线性内存中，JavaScript 通过 TypedArray 视图访问，避免数据拷贝。

## WASM 滤镜管道

```rust
// src/filters.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct ImageBuffer { data: Vec<u8>, width: u32, height: u32 }

#[wasm_bindgen]
impl ImageBuffer {
    #[wasm_bindgen(constructor)]
    pub fn new(width: u32, height: u32) -> Self {
        ImageBuffer { data: vec![0; (width * height * 4) as usize], width, height }
    }
    pub fn load_from_rgba(&mut self, data: &[u8]) { self.data.copy_from_slice(data); }
    pub fn data_ptr(&self) -> *const u8 { self.data.as_ptr() }
    pub fn data_len(&self) -> usize { self.data.len() }

    // 管道模式：一次遍历应用所有滤镜
    pub fn apply_pipeline(&mut self, brightness: f32, contrast: f32, saturation: f32) {
        for pixel in self.data.chunks_exact_mut(4) {
            let (mut r, mut g, mut b) = (pixel[0] as f32, pixel[1] as f32, pixel[2] as f32);
            // 亮度
            r += brightness; g += brightness; b += brightness;
            // 对比度
            r = (r - 128.0) * contrast + 128.0;
            g = (g - 128.0) * contrast + 128.0;
            b = (b - 128.0) * contrast + 128.0;
            // 饱和度
            let gray = 0.2126 * r + 0.7152 * g + 0.0722 * b;
            r = gray + (r - gray) * saturation;
            g = gray + (g - gray) * saturation;
            b = gray + (b - gray) * saturation;

            pixel[0] = r.clamp(0.0, 255.0) as u8;
            pixel[1] = g.clamp(0.0, 255.0) as u8;
            pixel[2] = b.clamp(0.0, 255.0) as u8;
        }
    }
}
```

## 前端集成

```typescript
// src/editor-core.ts
import init, { ImageBuffer } from '../pkg/image_editor';

export class ImageEditor {
  private buffer!: ImageBuffer;
  private canvas: HTMLCanvasElement;
  private ctx: CanvasRenderingContext2D;

  constructor(canvas: HTMLCanvasElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d')!;
  }

  async init() { await init(); }

  loadImage(img: HTMLImageElement) {
    this.canvas.width = img.width;
    this.canvas.height = img.height;
    this.ctx.drawImage(img, 0, 0);
    const imageData = this.ctx.getImageData(0, 0, img.width, img.height);
    this.buffer = new ImageBuffer(img.width, img.height);
    this.buffer.load_from_rgba(imageData.data);
  }

  applyFilters(brightness: number, contrast: number, saturation: number) {
    this.buffer.apply_pipeline(brightness, contrast, saturation);
    const ptr = this.buffer.data_ptr();
    const len = this.buffer.data_len();
    const pixels = new Uint8Array(this.buffer.data_buffer, ptr, len);
    const imageData = new ImageData(new Uint8ClampedArray(pixels), this.canvas.width, this.canvas.height);
    this.ctx.putImageData(imageData, 0, 0);
  }
}
```

## 高斯模糊（分离式实现）

将二维卷积拆成两次一维卷积，复杂度从 O(r²) 降到 O(r)：

```rust
// src/blur.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn gaussian_blur(data: &mut [u8], width: u32, height: u32, radius: u32) {
    let radius = radius.min(50);
    let kernel = build_kernel(radius);
    let mut buffer = vec![0u8; data.len()];
    blur_pass(data, &mut buffer, width, height, &kernel, true);  // 水平
    blur_pass(&mut buffer, data, width, height, &kernel, false); // 垂直
}

fn build_kernel(radius: u32) -> Vec<f32> {
    let size = (radius * 2 + 1) as usize;
    let sigma = radius as f32 / 3.0;
    let mut kernel: Vec<f32> = (0..size).map(|i| {
        let x = i as f32 - radius as f32;
        (-x * x / (2.0 * sigma * sigma)).exp()
    }).collect();
    let sum: f32 = kernel.iter().sum();
    kernel.iter_mut().for_each(|v| *v /= sum);
    kernel
}

fn blur_pass(src: &[u8], dst: &mut [u8], w: u32, h: u32, kernel: &[f32], horizontal: bool) {
    let r = (kernel.len() / 2) as i32;
    for y in 0..h { for x in 0..w {
        let (mut rv, mut gv, mut bv) = (0.0f32, 0.0f32, 0.0f32);
        for k in -r..=r {
            let (nx, ny) = if horizontal { ((x as i32 + k).clamp(0, w as i32 - 1) as u32, y) }
                           else { (x, (y as i32 + k).clamp(0, h as i32 - 1) as u32) };
            let idx = ((ny * w + nx) * 4) as usize;
            let wt = kernel[(k + r) as usize];
            rv += src[idx] as f32 * wt; gv += src[idx+1] as f32 * wt; bv += src[idx+2] as f32 * wt;
        }
        let idx = ((y * w + x) * 4) as usize;
        dst[idx] = rv.round() as u8; dst[idx+1] = gv.round() as u8;
        dst[idx+2] = bv.round() as u8; dst[idx+3] = src[idx+3];
    }}
}
```

## 撤销/重做（命令模式）

```rust
// src/history.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct HistoryManager {
    undo_stack: Vec<Vec<u8>>,
    redo_stack: Vec<Vec<u8>>,
    max_history: usize,
}

#[wasm_bindgen]
impl HistoryManager {
    #[wasm_bindgen(constructor)]
    pub fn new(max_history: usize) -> Self {
        HistoryManager { undo_stack: Vec::new(), redo_stack: Vec::new(), max_history }
    }

    pub fn push(&mut self, data: &[u8]) {
        self.undo_stack.push(data.to_vec());
        self.redo_stack.clear();
        if self.undo_stack.len() > self.max_history { self.undo_stack.remove(0); }
    }

    pub fn undo(&mut self) -> bool {
        if let Some(snapshot) = self.undo_stack.pop() { self.redo_stack.push(snapshot); true } else { false }
    }

    pub fn redo(&mut self) -> bool {
        if let Some(snapshot) = self.redo_stack.pop() { self.undo_stack.push(snapshot); true } else { false }
    }

    pub fn current_data_ptr(&self) -> *const u8 {
        self.undo_stack.last().map(|s| s.as_ptr()).unwrap_or(std::ptr::null())
    }
    pub fn can_undo(&self) -> bool { !self.undo_stack.is_empty() }
    pub fn can_redo(&self) -> bool { !self.redo_stack.is_empty() }
}
```

## 图层系统与混合模式

```rust
// src/layers.rs
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
#[derive(Clone, Copy)]
pub enum BlendMode { Normal, Multiply, Screen, Overlay, Darken, Lighten }

#[wasm_bindgen]
pub struct LayerStack {
    layers: Vec<(Vec<u8>, f32, BlendMode, bool)>, // (data, opacity, mode, visible)
    width: u32, height: u32,
}

#[wasm_bindgen]
impl LayerStack {
    #[wasm_bindgen(constructor)]
    pub fn new(width: u32, height: u32) -> Self {
        LayerStack { layers: Vec::new(), width, height }
    }

    pub fn add_layer(&mut self) -> usize {
        self.layers.push((vec![0; (self.width * self.height * 4) as usize], 1.0, BlendMode::Normal, true));
        self.layers.len() - 1
    }

    pub fn set_opacity(&mut self, index: usize, opacity: f32) {
        if let Some(layer) = self.layers.get_mut(index) { layer.1 = opacity.clamp(0.0, 1.0); }
    }

    pub fn composite(&self, output: &mut [u8]) {
        output.fill(0);
        for (data, opacity, mode, visible) in &self.layers {
            if !visible { continue; }
            for (base, overlay) in output.chunks_exact_mut(4).zip(data.chunks_exact(4)) {
                let sa = overlay[3] as f32 / 255.0 * opacity;
                let (sr, sg, sb) = match mode {
                    BlendMode::Normal => (overlay[0] as f32, overlay[1] as f32, overlay[2] as f32),
                    BlendMode::Multiply => (base[0] as f32 * overlay[0] as f32 / 255.0, base[1] as f32 * overlay[1] as f32 / 255.0, base[2] as f32 * overlay[2] as f32 / 255.0),
                    BlendMode::Screen => (255.0 - (255.0 - base[0] as f32) * (255.0 - overlay[0] as f32) / 255.0, 255.0 - (255.0 - base[1] as f32) * (255.0 - overlay[1] as f32) / 255.0, 255.0 - (255.0 - base[2] as f32) * (255.0 - overlay[2] as f32) / 255.0),
                    _ => (overlay[0] as f32, overlay[1] as f32, overlay[2] as f32),
                };
                let da = base[3] as f32 / 255.0;
                let out_a = sa + da * (1.0 - sa);
                if out_a > 0.0 {
                    base[0] = ((sr * sa + base[0] as f32 * da * (1.0 - sa)) / out_a).clamp(0.0, 255.0) as u8;
                    base[1] = ((sg * sa + base[1] as f32 * da * (1.0 - sa)) / out_a).clamp(0.0, 255.0) as u8;
                    base[2] = ((sb * sa + base[2] as f32 * da * (1.0 - sa)) / out_a).clamp(0.0, 255.0) as u8;
                    base[3] = (out_a * 255.0).clamp(0.0, 255.0) as u8;
                }
            }
        }
    }
}
```

```rust
pub fn encode_png(data: &[u8], width: u32, height: u32) -> Vec<u8> {
```

## 常见误区

1. **每次滤镜都从 Canvas 读取再写回** — 应在 WASM 内存中维护像素数据，避免反复拷贝
2. **高斯模糊用二维卷积** — 分离式实现将 O(r²) 降到 O(r)
3. **撤销栈保存引用** — 必须深拷贝像素数据
4. **一次性处理超大图片** — 应分块处理，避免内存峰值过高

## 工程建议

1. **WASM 内存是 Single Source of Truth** — Canvas 只是显示层
2. **图层合成用增量更新** — 只重绘修改过的图层区域
3. **导出用流式编码** — 大图片分块编码
4. **Worker 线程处理** — 不阻塞 UI

## 小结

管道模式让多个滤镜一次遍历完成，命令模式让撤销/重做简洁，分块策略让大图处理可行。核心原则：像素数据住在 WASM 内存中，Canvas 只负责显示。

```rust
#[wasm_bindgen]
pub fn compute_histogram(data: &[u8]) -> Vec<u32> {
    let mut hist = vec![0u32; 768]; // R[256] + G[256] + B[256]
    for pixel in data.chunks_exact(4) {
        hist[pixel[0] as usize] += 1;
        hist[256 + pixel[1] as usize] += 1;
        hist[512 + pixel[2] as usize] += 1;
    }
    hist
}
```

**要点**：直方图是可向量化的操作，可用 SIMD 进一步加速。

### 练习二

```rust
#[wasm_bindgen]
pub fn crop_pixels(src: &[u8], src_w: u32, x: u32, y: u32, w: u32, h: u32) -> Vec<u8> {
    let mut dst = vec![0u8; (w * h * 4) as usize];
    for row in 0..h {
        let src_off = ((y + row) * src_w + x) as usize * 4;
        let dst_off = (row * w) as usize * 4;
        dst[dst_off..dst_off + w as usize * 4].copy_from_slice(&src[src_off..src_off + w as usize * 4]);
    }
    dst
}
```

**要点**：非破坏性裁剪保留原始数据，裁剪只是视图操作。

### 练习三

```rust
fn get_pixel_reflect(data: &[u8], w: i32, h: i32, x: i32, y: i32) -> [u8; 4] {
    let fx = if x < 0 { -x - 1 } else if x >= w { 2 * w - x - 1 } else { x };
    let fy = if y < 0 { -y - 1 } else if y >= h { 2 * h - y - 1 } else { y };
    let idx = ((fy * w + fx) * 4) as usize;
    [data[idx], data[idx+1], data[idx+2], data[idx+3]]
}
```

**要点**：镜像模式视觉最自然，不会产生边界伪影。
