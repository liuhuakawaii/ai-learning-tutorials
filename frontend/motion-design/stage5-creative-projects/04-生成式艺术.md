# 第四课：生成式艺术

## 场景引入

屏幕上出现一幅从未见过的画作——数百条交织的曲线遵循数学规则，整体效果像自然界的水流或风的轨迹。每次刷新页面画面都不一样，但风格始终统一。这就是生成式艺术：由算法创造的、不可重复的视觉作品。

核心不是"画什么"，而是"怎么画"——设计一套**规则和约束**，让算法在规则内自由创作。随机性创造不可预测的结果，噪声创造有结构的变化。

## 学习目标

1. 理解生成式艺术的基本概念：随机性、噪声、规则系统
2. 掌握 Perlin/Simplex 噪声的使用方法
3. 学会用 Canvas 2D 实现流动场效果
4. 了解分形的基本原理与实现
5. 掌握 GLSL 着色器基础，能编写简单的片段着色器
6. 理解粒子生命系统与涌现行为
7. 学会管理随机种子以实现作品的可复现性
8. 掌握生成式作品的导出方法（PNG/SVG/动画）

## 生成式艺术的设计哲学

生成式艺术的本质是**设计系统而非设计画面**。传统艺术中，创作者直接控制每一个笔触；生成式艺术中，创作者定义规则、约束和随机性来源，然后让系统在这些约束内自主演化。

### 三层设计模型

一套好的生成式系统通常包含三层：

1. **结构层（Structure）**：定义画布的基本组织方式——网格、极坐标、拓扑连接、空间分区。结构层决定了作品的"骨架"。
2. **变化层（Variation）**：在结构上叠加变化——噪声扰动、颜色映射、大小渐变。变化层让骨架长出"血肉"。
3. **随机层（Randomness）**：引入可控的不可预测性——粒子初始位置、分支角度偏移、颜色微调。随机层让每次生成都有独特性。

三层的权重决定了作品的风格：

```javascript
// 结构主导：网格、对称、几何感强
// 变化主导：有机、流动、自然感强
// 随机主导：混乱、实验性、不可控

// 典型的权重分配
const config = {
  structureWeight: 0.5,   // 结构占比
  variationWeight: 0.35,  // 变化占比
  randomnessWeight: 0.15  // 随机占比
};
```

### 约束即美学

好的生成式作品往往来自严格的约束。约束不是限制，而是创造风格的工具：

- **颜色约束**：只用 3-5 种颜色，比用全光谱更有辨识度
- **几何约束**：只用圆形、只用直线、只用 90 度角——限制越强，风格越鲜明
- **运动约束**：粒子只能沿特定方向移动、只能加速不能减速

```javascript
// 颜色约束示例：5色调色板
const palette = ["#264653", "#2a9d8f", "#e9c46a", "#f4a261", "#e76f51"];

// 在代码中只从调色板取色，不使用随机颜色
function getColor(noiseValue) {
  const index = Math.floor(((noiseValue + 1) / 2) * palette.length);
  return palette[Math.min(index, palette.length - 1)];
}
```

### 迭代与涌现

生成式艺术的创作过程是**迭代式**的：写代码 → 运行 → 观察 → 调整参数 → 再运行。很多优秀的作品来自"意外"——参数调错时出现的有趣图案。

涌现（Emergence）是指简单规则产生复杂行为。蚂蚁觅食、鸟群飞行、雪花结晶都是涌现现象。在代码中，几个简单规则就能产生令人惊讶的视觉效果：

```javascript
// 三条简单规则产生群聚行为
// 1. 靠近：向邻居的平均位置移动
// 2. 对齐：朝邻居的平均方向移动
// 3. 分离：远离过近的邻居
```

## 随机性 vs 噪声

纯随机数在每个点上完全独立，生成"噪点"而非"结构"。噪声函数在相邻点之间产生平滑过渡，创造有机的自然变化：

```javascript
import { createNoise2D } from "simplex-noise";
const noise2D = createNoise2D();

for (let x = 0; x < canvas.width; x++) {
  for (let y = 0; y < canvas.height; y++) {
    const scale = 0.01;
    const value = noise2D(x * scale, y * scale);
    const brightness = ((value + 1) / 2) * 255;
    ctx.fillStyle = `rgb(${brightness}, ${brightness}, ${brightness})`;
    ctx.fillRect(x, y, 1, 1);
  }
}
```

噪声的核心参数：

- **频率（Frequency）**：控制噪声的"缩放"。频率越高，细节越多，变化越密集。
- **振幅（Amplitude）**：控制噪声值的范围。振幅越大，变化越剧烈。
- **八度（Octaves）**：叠加多层不同频率的噪声，模拟自然界的层次感。

```javascript
// 多八度叠加（分形布朗运动，fBm）
function fbm(x, y, octaves = 4) {
  let value = 0;
  let amplitude = 1;
  let frequency = 1;
  let maxValue = 0;

  for (let i = 0; i < octaves; i++) {
    value += noise2D(x * frequency, y * frequency) * amplitude;
    maxValue += amplitude;
    amplitude *= 0.5;    // 振幅衰减：高频层影响越来越小
    frequency *= 2;      // 频率倍增：每层细节更密集
  }

  return value / maxValue; // 归一化到 [-1, 1]
}
```

## 种子管理与可复现性

生成式艺术的一个关键问题是：如何重现"偶然好看"的图案？答案是**固定随机种子**。

### 为什么需要种子

`Math.random()` 不接受种子参数，每次调用都是不可预测的。当你偶然发现一个漂亮的图案，想再次生成或微调时，没有种子就无法重现。

### seedrandom 库

```javascript
import seedrandom from "seedrandom";

// 创建可复现的随机数生成器
const rng = seedrandom("my-artwork-v1");

// 用 rng() 替代 Math.random()
const x = rng() * canvas.width;
const y = rng() * canvas.height;
const hue = rng() * 360;
```

### 种子与噪声的配合

Simplex 噪声本身是确定性的（相同输入产生相同输出），但粒子的初始位置、颜色选择等需要种子：

```javascript
import { createNoise2D } from "simplex-noise";
import seedrandom from "seedrandom";

// 噪声函数不需要种子（它是确定性的）
const noise2D = createNoise2D();

// 粒子系统用种子控制初始状态
function createParticles(count, seed) {
  const rng = seedrandom(seed);
  return Array.from({ length: count }, () => ({
    x: rng() * canvas.width,
    y: rng() * canvas.height,
    hue: rng() * 360,
    maxLife: 100 + rng() * 200
  }));
}

// 相同种子 always 产生相同结果
const particles1 = createParticles(500, "seed-a");
const particles2 = createParticles(500, "seed-a"); // 与 particles1 完全相同
```

将种子编码到 URL 中，方便分享和复现：


## 噪声动画

增加时间维度，创造流动效果：

```javascript
import { createNoise3D } from "simplex-noise";
const noise3D = createNoise3D();
let time = 0;

function drawNoiseAnimation() {
  requestAnimationFrame(drawNoiseAnimation);
  time += 0.01;
  const imageData = ctx.createImageData(canvas.width, canvas.height);
  const scale = 0.008;

  for (let x = 0; x < canvas.width; x++) {
    for (let y = 0; y < canvas.height; y++) {
      const value = noise3D(x * scale, y * scale, time);
      const brightness = ((value + 1) / 2) * 255;
      const idx = (y * canvas.width + x) * 4;
      imageData.data[idx] = brightness;
      imageData.data[idx + 1] = brightness * 0.7;
      imageData.data[idx + 2] = brightness * 0.4;
      imageData.data[idx + 3] = 255;
    }
  }
  ctx.putImageData(imageData, 0, 0);
}
```

注意：逐像素操作在大画布上很慢，实际项目应用 WebGL 着色器。

## 流动场（Flow Field）

生成式艺术最经典的技术——粒子沿噪声定义的方向移动：

```javascript
import { createNoise2D } from "simplex-noise";
const noise2D = createNoise2D();
let zOffset = 0;

class Particle {
  constructor() { this.reset(); }
  reset() {
    this.x = Math.random() * canvas.width;
    this.y = Math.random() * canvas.height;
    this.vx = 0; this.vy = 0;
    this.life = 0; this.maxLife = 100 + Math.random() * 200;
  }
  update() {
    const angle = noise2D(this.x * 0.005, this.y * 0.005 + zOffset) * Math.PI * 2;
    this.vx += Math.cos(angle) * 0.3;
    this.vy += Math.sin(angle) * 0.3;
    this.vx *= 0.95; this.vy *= 0.95;
    this.x += this.vx; this.y += this.vy;
    this.life++;
    if (this.life > this.maxLife || this.x < 0 || this.x > canvas.width ||
        this.y < 0 || this.y > canvas.height) this.reset();
  }
  draw() {
    const alpha = 1 - this.life / this.maxLife;
    ctx.fillStyle = `rgba(255, 255, 255, ${alpha * 0.3})`;
    ctx.fillRect(this.x, this.y, 1.5, 1.5);
  }
}

const particles = Array.from({ length: 500 }, () => new Particle());

function drawFlowField() {
  requestAnimationFrame(drawFlowField);
  ctx.fillStyle = "rgba(0, 0, 0, 0.03)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  zOffset += 0.003;
  particles.forEach(p => { p.update(); p.draw(); });
}
```

## 分形树

分形是自相似的几何结构——局部与整体形状相似：

```javascript
function drawTree(x, y, length, angle, depth) {
  if (depth === 0) return;
  const endX = x + Math.cos(angle) * length;
  const endY = y + Math.sin(angle) * length;
  const green = 80 + depth * 20;

  ctx.beginPath();
  ctx.moveTo(x, y);
  ctx.lineTo(endX, endY);
  ctx.strokeStyle = `rgb(60, ${green}, 40)`;
  ctx.lineWidth = depth * 1.5;
  ctx.lineCap = "round";
  ctx.stroke();

  const branchAngle = 0.4 + Math.random() * 0.3;
  const lengthRatio = 0.65 + Math.random() * 0.15;

  drawTree(endX, endY, length * lengthRatio, angle - branchAngle, depth - 1);
  drawTree(endX, endY, length * lengthRatio, angle + branchAngle, depth - 1);
}

drawTree(canvas.width / 2, canvas.height, 100, -Math.PI / 2, 10);
```

## 交互式生成艺术

让用户的鼠标移动影响噪声参数：

```javascript
let mouseX = 0.5, mouseY = 0.5;
canvas.addEventListener("mousemove", e => {
  mouseX = e.clientX / canvas.width;
  mouseY = e.clientY / canvas.height;
});

function drawInteractiveField() {
  requestAnimationFrame(drawInteractiveField);
  ctx.fillStyle = "rgba(0, 0, 0, 0.05)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  const scale = 0.01 + mouseX * 0.02;
  const speed = mouseY * 0.01;
  const time = performance.now() * speed;

  for (let i = 0; i < 30; i++) {
    const x = Math.random() * canvas.width;
    const y = Math.random() * canvas.height;
    const value = noise2D(x * scale + time, y * scale);
    const size = (value + 1) * 3;
    ctx.beginPath();
    ctx.arc(x, y, size, 0, Math.PI * 2);
    ctx.fillStyle = `hsla(${(value + 1) * 120}, 80%, 60%, 0.6)`;
    ctx.fill();
  }
}
```

## 粒子生命与涌现系统

涌现（Emergence）是生成式艺术中最迷人的现象：简单规则产生复杂行为。粒子生命系统是研究涌现的经典模型——每个粒子只遵循几条局部规则，但群体能形成有机的、不可预测的结构。

### 基本原理

粒子生命系统中，每种"颜色"的粒子对其他颜色的粒子有引力或斥力。力的大小随距离变化：

```javascript
// 粒子间力的规则矩阵
// rules[a][b] 表示颜色 a 的粒子对颜色 b 的粒子施加的力
// 正值 = 吸引，负值 = 排斥
const rules = {
  red:    { red: 0.1,  blue: -0.3, green: 0.5 },
  blue:   { red: 0.3,  blue: -0.1, green: -0.2 },
  green:  { red: -0.5, blue: 0.2,  green: 0.1 }
};
```

### 完整实现

```javascript
import seedrandom from "seedrandom";

const COLORS = ["#ff6b6b", "#4ecdc4", "#45b7d1", "#96ceb4", "#ffeaa7"];
const PARTICLE_COUNT = 800;
const FORCE_RADIUS = 80;
const FORCE_STRENGTH = 0.5;

const rng = seedrandom("particle-life-seed");

class LifeParticle {
  constructor(colorIndex) {
    this.x = rng() * canvas.width;
    this.y = rng() * canvas.height;
    this.vx = 0;
    this.vy = 0;
    this.colorIndex = colorIndex;
  }

  update(particles, rules) {
    let fx = 0, fy = 0;

    for (const other of particles) {
      if (other === this) continue;

      const dx = other.x - this.x;
      const dy = other.y - this.y;
      const dist = Math.sqrt(dx * dx + dy * dy);

      if (dist > FORCE_RADIUS || dist < 0.1) continue;

      const force = rules[this.colorIndex][other.colorIndex] * FORCE_STRENGTH;
      // 力随距离衰减：近处斥力（防止重叠），远处引力/斥力
      const normalizedDist = dist / FORCE_RADIUS;
      const magnitude = force * (1 - normalizedDist);

      fx += (dx / dist) * magnitude;
      fy += (dy / dist) * magnitude;
    }

    this.vx = (this.vx + fx) * 0.92; // 阻尼
    this.vy = (this.vy + fy) * 0.92;
    this.x += this.vx;
    this.y += this.vy;

    // 边界反弹
    if (this.x < 0) { this.x = 0; this.vx *= -0.5; }
    if (this.x > canvas.width) { this.x = canvas.width; this.vx *= -0.5; }
    if (this.y < 0) { this.y = 0; this.vy *= -0.5; }
    if (this.y > canvas.height) { this.y = canvas.height; this.vy *= -0.5; }
  }

  draw() {
    ctx.fillStyle = COLORS[this.colorIndex];
    ctx.beginPath();
    ctx.arc(this.x, this.y, 2, 0, Math.PI * 2);
    ctx.fill();
  }
}

// 初始化粒子：每种颜色均匀分布
const particles = [];
for (let c = 0; c < COLORS.length; c++) {
  for (let i = 0; i < PARTICLE_COUNT / COLORS.length; i++) {
    particles.push(new LifeParticle(c));
  }
}

// 随机生成规则（或手动调参）
function generateRules() {
  const rules = {};
  for (let i = 0; i < COLORS.length; i++) {
    rules[i] = {};
    for (let j = 0; j < COLORS.length; j++) {
      rules[i][j] = (rng() - 0.5) * 2; // [-1, 1] 范围的随机力
    }
  }
  return rules;
}

const rules = generateRules();

function animate() {
  requestAnimationFrame(animate);
  ctx.fillStyle = "rgba(0, 0, 0, 0.1)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  particles.forEach(p => {
    p.update(particles, rules);
    p.draw();
  });
}

animate();
```

### 调参技巧

粒子生命系统的视觉效果高度依赖规则矩阵。几个经验：

- **对角线为负**（同类相斥）防止粒子聚成一团
- **对角线为正**（同类相聚）形成集群
- **不同颜色间力的符号交替**产生追逐和捕食行为
- **力的半径不宜太大**，否则所有粒子挤在一起

## Shader 基础：GLSL 入门

Canvas 2D 逐像素操作在大画布上极慢——1920x1080 有 207 万像素，每帧计算噪声根本不现实。WebGL 着色器天然并行，GPU 的数千个核心同时处理每个像素。

### GLSL 是什么

GLSL（OpenGL Shading Language）是运行在 GPU 上的程序。两种着色器：

- **顶点着色器（Vertex Shader）**：处理每个顶点的位置
- **片段着色器（Fragment Shader）**：处理每个像素的颜色

生成式艺术主要用片段着色器——每个像素独立计算颜色。

### 最小可运行示例

```html
<canvas id="glCanvas" width="800" height="600"></canvas>
<script>
const canvas = document.getElementById("glCanvas");
const gl = canvas.getContext("webgl");

// 顶点着色器：画一个全屏矩形
const vertexShaderSource = `
  attribute vec2 a_position;
  void main() {
    gl_Position = vec4(a_position, 0.0, 1.0);
  }
`;

// 片段着色器：每个像素根据坐标计算颜色
const fragmentShaderSource = `
  precision mediump float;
  uniform vec2 u_resolution;
  uniform float u_time;

  void main() {
    vec2 uv = gl_FragCoord.xy / u_resolution;
    // 简单的颜色渐变
    float r = sin(uv.x * 3.14 + u_time) * 0.5 + 0.5;
    float g = sin(uv.y * 3.14 + u_time * 0.7) * 0.5 + 0.5;
    float b = sin((uv.x + uv.y) * 3.14 + u_time * 1.3) * 0.5 + 0.5;
    gl_FragColor = vec4(r, g, b, 1.0);
  }
`;

// 编译着色器
function createShader(gl, type, source) {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    console.error(gl.getShaderInfoLog(shader));
    gl.deleteShader(shader);
    return null;
  }
  return shader;
}

// 创建程序
const vertexShader = createShader(gl, gl.VERTEX_SHADER, vertexShaderSource);
const fragmentShader = createShader(gl, gl.FRAGMENT_SHADER, fragmentShaderSource);
const program = gl.createProgram();
gl.attachShader(program, vertexShader);
gl.attachShader(program, fragmentShader);
gl.linkProgram(program);
gl.useProgram(program);

// 创建全屏矩形
const positions = new Float32Array([-1,-1, 1,-1, -1,1, 1,1]);
const buffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
gl.bufferData(gl.ARRAY_BUFFER, positions, gl.STATIC_DRAW);

const posLoc = gl.getAttribLocation(program, "a_position");
gl.enableVertexAttribArray(posLoc);
gl.vertexAttribPointer(posLoc, 2, gl.FLOAT, false, 0, 0);

// 传递 uniform
const resLoc = gl.getUniformLocation(program, "u_resolution");
const timeLoc = gl.getUniformLocation(program, "u_time");

function render(time) {
  requestAnimationFrame(render);
  gl.uniform2f(resLoc, canvas.width, canvas.height);
  gl.uniform1f(timeLoc, time * 0.001);
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
}

requestAnimationFrame(render);
</script>
```

### GLSL 噪声

GLSL 没有内置噪声函数，需要自己实现。经典方法是用哈希函数：

```glsl
// 简单的 2D 噪声（value noise）
float hash(vec2 p) {
  return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  // 四个角的哈希值，双线性插值
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  vec2 u = f * f * (3.0 - 2.0 * f); // smoothstep
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

// 分形叠加
float fbm(vec2 p) {
  float value = 0.0;
  float amplitude = 0.5;
  for (int i = 0; i < 6; i++) {
    value += amplitude * noise(p);
    p *= 2.0;
    amplitude *= 0.5;
  }
  return value;
}
```

### Shader 中的流动场

```glsl
precision mediump float;
uniform vec2 u_resolution;
uniform float u_time;

// [hash 和 noise 函数省略，同上]

void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;

  // 用噪声定义角度
  float angle = noise(uv * 5.0 + u_time * 0.2) * 6.28;
  vec2 dir = vec2(cos(angle), sin(angle));

  // 叠加多层噪声创造流动感
  float n = fbm(uv * 3.0 + dir * 0.5 + u_time * 0.1);

  // 用噪声值映射颜色
  vec3 color = mix(
    vec3(0.05, 0.05, 0.15),  // 深蓝
    vec3(0.9, 0.6, 0.3),     // 暖橙
    n
  );

  gl_FragColor = vec4(color, 1.0);
}
```

## Worley 噪声（细胞噪声）

Perlin/Simplex 噪声产生云雾般的平滑变化，Worley 噪声产生细胞、石头、蜂巢般的纹理。原理是计算每个像素到最近"特征点"的距离：

```javascript
import seedrandom from "seedrandom";

function createWorleyNoise(width, height, cellSize, seed) {
  const rng = seedrandom(seed);
  const cols = Math.ceil(width / cellSize);
  const rows = Math.ceil(height / cellSize);

  // 在每个网格单元中随机放置一个特征点
  const points = [];
  for (let cy = 0; cy < rows; cy++) {
    for (let cx = 0; cx < cols; cx++) {
      points.push({
        x: cx * cellSize + rng() * cellSize,
        y: cy * cellSize + rng() * cellSize
      });
    }
  }

  const imageData = ctx.createImageData(width, height);

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      // 查找最近的特征点
      let minDist = Infinity;
      let secondDist = Infinity;

      // 只需检查当前格子及周围 8 个格子
      const cx = Math.floor(x / cellSize);
      const cy = Math.floor(y / cellSize);

      for (let dy = -1; dy <= 1; dy++) {
        for (let dx = -1; dx <= 1; dx++) {
          const nx = cx + dx;
          const ny = cy + dy;
          if (nx < 0 || nx >= cols || ny < 0 || ny >= rows) continue;

          const idx = ny * cols + nx;
          const px = points[idx].x;
          const py = points[idx].y;
          const dist = Math.sqrt((x - px) ** 2 + (y - py) ** 2);

          if (dist < minDist) {
            secondDist = minDist;
            minDist = dist;
          } else if (dist < secondDist) {
            secondDist = dist;
          }
        }
      }

      // F1：到最近点的距离（细胞纹理）
      // F2 - F1：到第二近点减最近点的距离（边缘纹理）
      const value = (secondDist - minDist) / cellSize;
      const brightness = Math.floor(value * 255);

      const idx = (y * width + x) * 4;
      imageData.data[idx] = brightness;
      imageData.data[idx + 1] = brightness;
      imageData.data[idx + 2] = brightness;
      imageData.data[idx + 3] = 255;
    }
  }

  return imageData;
}

// 使用
const worleyImage = createWorleyNoise(400, 400, 40, "worley-seed-1");
ctx.putImageData(worleyImage, 0, 0);
```

Worley 噪声的应用场景：

- **石头/岩石纹理**：F1 距离产生自然的细胞裂纹
- **蜂巢/龟裂**：F2-F1 产生清晰的边缘
- **生物细胞**：调整 cellSize 控制细胞大小

## 常见误区

**误区一：把"随机"当"好看"。** 纯随机是混乱的。美感来自**规则与随机的平衡**——规则提供结构，随机提供变化。

**误区二：忽略种子（Seed）。** 想重现"偶然好看"的图案，必须固定随机种子。没有种子，调参过程变成"不断刷新碰运气"。

**误区三：性能问题被忽略。** 1920x1080 画布有 207 万像素，逐像素计算噪声不可行。应用 WebGL 着色器，或缩小画布后缩放显示。

**误区四：分形递归过深。** 递归 15 层意味着 32768 条线段，可能超过一帧预算。限制深度在 10-12 层，或用迭代替代递归。

**误区五：颜色随机而非设计。** 随机 HSL 颜色产生刺眼的彩虹效果。好的生成式作品有精心设计的调色板——用 `hsluv` 或 `chroma.js` 创建和谐的色彩方案。

**误区六：噪声频率选择不当。** 频率太低（0.001）产生几乎不变的大色块；频率太高（0.5）产生密集噪点。0.005-0.02 是大多数场景的合理起点。

**误区七：不清理画布导致残影。** 用 `clearRect` 而非 `fillRect` 叠加半透明黑色，会产生意外的渐隐效果。如果不需要渐隐，每帧应 `clearRect` 后重绘。

**误区八：过度使用 `Math.random()`。** `Math.random()` 不可控——无法固定种子、无法重现、无法序列化状态。所有需要可复现的随机都应使用 `seedrandom` 或类似库。

## 工程建议

1. **用 WebGL 着色器处理逐像素操作。** 片段着色器天然并行，比 Canvas 2D 快 100 倍以上。
2. **固定随机种子用于可复现性。** 用 `seedrandom` 库替代 `Math.random()`，将种子编码到 URL 中。
3. **控制粒子数量上限。** 维护粒子池，超过阈值停止创建。1000 个粒子在大多数浏览器中流畅，超过 5000 需要 WebGL。
4. **使用离屏 Canvas 做静态层。** 不变的背景绘制到离屏 Canvas，每帧只更新动态部分。
5. **提供"导出"功能。** 导出为高分辨率 PNG 或 SVG，用 `captureStream` 录制动画。
6. **调色板预先定义。** 用 Coolors.co 或 Adobe Color 生成调色板，在代码中硬编码 5-8 种颜色。
7. **噪声频率从低到高调试。** 从 0.005 开始，逐步增加直到找到"有结构但有细节"的平衡点。
8. **用 requestAnimationFrame 控制帧率。** 不要用 `setInterval`。如果渲染耗时超过 16ms，考虑降低画布分辨率或跳帧。

## 小结

生成式艺术的核心是**设计规则而非设计画面**。噪声函数提供有结构的随机性，流动场让粒子形成有机轨迹，分形通过递归创造自相似结构。Canvas 2D 适合快速原型，WebGL 着色器适合高性能渲染。交互性让用户成为"共同创作者"。种子管理让你能重现每一次"偶然"。

### 练习一

**思路**：用 3D 噪声生成动画纹理。多八度叠加通过不同缩放级别多次采样并加权求和。

**答案**：
```javascript
import { createNoise3D } from "simplex-noise";
const noise3D = createNoise3D();
let time = 0, scale = 0.01;

// 监听滑块输入，动态调整缩放级别
document.querySelector("#scale-slider").addEventListener("input", e => {
  scale = parseFloat(e.target.value);
});

// 分形噪声：多八度叠加
// octaves: 叠加层数，越多细节越丰富但计算量越大
// persistence: 振幅衰减率，通常 0.5
// lacunarity: 频率倍增率，通常 2.0
function fractalNoise(x, y, t, octaves = 4) {
  let value = 0, amplitude = 1, frequency = 1, maxValue = 0;
  for (let i = 0; i < octaves; i++) {
    value += noise3D(x * frequency * scale, y * frequency * scale, t) * amplitude;
    maxValue += amplitude;
    amplitude *= 0.5;
    frequency *= 2;
  }
  return value / maxValue; // 归一化到 [-1, 1]
}

function draw() {
  requestAnimationFrame(draw);
  time += 0.005;
  const imageData = ctx.createImageData(canvas.width, canvas.height);
  for (let x = 0; x < canvas.width; x++) {
    for (let y = 0; y < canvas.height; y++) {
      const v = ((fractalNoise(x, y, time) + 1) / 2) * 255;
      const idx = (y * canvas.width + x) * 4;
      imageData.data[idx] = imageData.data[idx + 1] = imageData.data[idx + 2] = v;
      imageData.data[idx + 3] = 255;
    }
  }
  ctx.putImageData(imageData, 0, 0);
}

draw();
```

**要点**：`amplitude *= 0.5` 和 `frequency *= 2` 是最常用的衰减参数。低频八度提供大结构，高频八度添加细节。缩放滑块让用户体验频率对纹理的影响。

### 练习二

**思路**：噪声定义流动方向，极低透明度黑色矩形覆盖实现渐隐轨迹。记录上一帧位置绘制连续线段。

**答案**：
```javascript
import { createNoise3D } from "simplex-noise";
const noise3D = createNoise3D();
let timeOffset = 0;
const noiseScale = 0.005;

class FlowParticle {
  constructor() { this.reset(); }
  reset() {
    this.x = Math.random() * canvas.width;
    this.y = Math.random() * canvas.height;
    this.vx = 0;
    this.vy = 0;
    this.life = 0;
    this.maxLife = 150 + Math.random() * 250;
    this.prevX = this.x;
    this.prevY = this.y;
  }
  update() {
    this.prevX = this.x;
    this.prevY = this.y;
    // 噪声定义流动方向，乘以 2PI 映射到完整角度
    const angle = noise3D(this.x * noiseScale, this.y * noiseScale, timeOffset) * Math.PI * 2;
    // 施加力并添加阻尼
    this.vx += Math.cos(angle) * 0.3;
    this.vy += Math.sin(angle) * 0.3;
    this.vx *= 0.95;
    this.vy *= 0.95;
    this.x += this.vx;
    this.y += this.vy;
    this.life++;
    // 生命结束或出界时重置
    if (this.life > this.maxLife || this.x < -10 || this.x > canvas.width + 10 ||
        this.y < -10 || this.y > canvas.height + 10) this.reset();
  }
  draw() {
    // alpha 随生命衰减，产生渐隐效果
    const alpha = 1 - this.life / this.maxLife;
    ctx.strokeStyle = `rgba(200, 220, 255, ${alpha * 0.4})`;
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(this.prevX, this.prevY);
    ctx.lineTo(this.x, this.y);
    ctx.stroke();
  }
}

const particles = Array.from({ length: 300 }, () => new FlowParticle());

function animate() {
  requestAnimationFrame(animate);
  // 极低透明度黑色覆盖：每帧淡出 4% 的旧轨迹
  ctx.fillStyle = "rgba(0, 0, 0, 0.04)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  timeOffset += 0.002; // 噪声场缓慢变化
  particles.forEach(p => { p.update(); p.draw(); });
}

animate();
```

**要点**：记录 `prevX/prevY` 让轨迹是连续线段；alpha 值控制渐隐速度；`timeOffset` 增量要小，否则噪声场变化太快导致粒子轨迹断裂。

### 练习三

**思路**：鼠标位置映射到分形参数，每次移动清空画布重绘。添加微小随机偏移让树更自然。

```javascript
  if (depth === 0 || length < 2) return;
  const endX = x + Math.cos(angle) * length;
  const endY = y + Math.sin(angle) * length;
  // t 从 0（树干）到 1（树叶），用于颜色渐变

  ctx.beginPath();
  ctx.moveTo(x, y);
  ctx.lineTo(endX, endY);
  // 颜色从深棕绿渐变到浅绿
  ctx.strokeStyle = `rgb(${40 + t * 160}, ${120 + t * 100}, ${30 + t * 50})`;
  ctx.lineWidth = depth * 1.2;
  ctx.lineCap = "round";
  ctx.stroke();

  // jitter 添加微小随机偏移，让树不那么机械
  const jitter = (Math.random() - 0.5) * 0.2;
  drawBranch(endX, endY, length * lengthRatio, angle - branchAngle + jitter, depth - 1, maxDepth);
  drawBranch(endX, endY, length * lengthRatio, angle + branchAngle + jitter, depth - 1, maxDepth);
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  drawBranch(canvas.width / 2, canvas.height * 0.85, 100, -Math.PI / 2, 10, 10);
}

draw();
```

**要点**：`jitter` 添加微小随机偏移让树更自然；颜色从深绿渐变到浅绿；`length < 2` 作为递归终止条件防止无限递归。

### 练习四

**思路**：Worley 噪声的核心是计算每个像素到最近特征点的距离。用网格优化：每个特征点只在自己的格子内，只需检查周围 8 个格子。F2-F1 模式产生更清晰的边缘。

**答案**：
```javascript
import seedrandom from "seedrandom";

let cellSize = 40;
let mode = "f1"; // "f1" 或 "f2-f1"
const seed = "worley-exercise";

// 监听模式切换
document.querySelector("#mode-select").addEventListener("change", e => {
  mode = e.target.value;
  render();
});

// 监听 cellSize 滑块
document.querySelector("#cell-slider").addEventListener("input", e => {
  cellSize = parseInt(e.target.value);
  render();
});

function render() {
  const rng = seedrandom(seed);
  const width = canvas.width;
  const height = canvas.height;
  const cols = Math.ceil(width / cellSize);
  const rows = Math.ceil(height / cellSize);

  // 在每个格子中随机放置一个特征点
  const points = [];
  for (let cy = 0; cy < rows; cy++) {
    for (let cx = 0; cx < cols; cx++) {
      points.push({
        x: cx * cellSize + rng() * cellSize,
        y: cy * cellSize + rng() * cellSize
      });
    }
  }

  const imageData = ctx.createImageData(width, height);

  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      let minDist = Infinity;
      let secondDist = Infinity;

      const cx = Math.floor(x / cellSize);
      const cy = Math.floor(y / cellSize);

      // 检查当前格子及周围 8 个格子
      for (let dy = -1; dy <= 1; dy++) {
        for (let dx = -1; dx <= 1; dx++) {
          const nx = cx + dx;
          const ny = cy + dy;
          if (nx < 0 || nx >= cols || ny < 0 || ny >= rows) continue;

          const idx = ny * cols + nx;
          const px = points[idx].x;
          const py = points[idx].y;
          const dist = Math.sqrt((x - px) ** 2 + (y - py) ** 2);

          if (dist < minDist) {
            secondDist = minDist;
            minDist = dist;
          } else if (dist < secondDist) {
            secondDist = dist;
          }
        }
      }

      let value;
      if (mode === "f1") {
        value = minDist / cellSize; // 归一化
      } else {
        value = (secondDist - minDist) / cellSize;
      }

      const brightness = Math.floor(Math.min(value, 1) * 255);
      const idx = (y * width + x) * 4;
      imageData.data[idx] = brightness;
      imageData.data[idx + 1] = brightness;
      imageData.data[idx + 2] = brightness;
      imageData.data[idx + 3] = 255;
    }
  }

  ctx.putImageData(imageData, 0, 0);
}

render();

// 导出功能
document.querySelector("#export-btn").addEventListener("click", () => {
  const link = document.createElement("a");
  link.download = `worley-${mode}-${cellSize}.png`;
  link.href = canvas.toDataURL("image/png");
  link.click();
});
```

**要点**：网格优化将时间复杂度从 O(n²) 降到 O(n)；F1 模式产生平滑的细胞纹理，F2-F1 产生清晰的细胞边界；固定种子保证可复现。

着色器代码（GLSL）：
```glsl
precision mediump float;
uniform vec2 u_resolution;
uniform vec2 u_mouse;
uniform float u_time;

// 哈希函数：伪随机数生成
float hash(vec2 p) {
  return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

// Value Noise：基于哈希的 2D 噪声
float noise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

// 分形布朗运动：多层噪声叠加
float fbm(vec2 p, int octaves) {
  float value = 0.0;
  float amplitude = 0.5;
  float frequency = 1.0;
  for (int i = 0; i < 8; i++) {
    if (i >= octaves) break;
    value += amplitude * noise(p * frequency);
    frequency *= 2.0;
    amplitude *= 0.5;
  }
  return value;
}

void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;

  // 鼠标 X 控制噪声频率（1.0 - 8.0）
  float freq = 1.0 + u_mouse.x * 7.0;

  // 鼠标 Y 控制颜色混合比例
  float colorMix = u_mouse.y;

  // 时间驱动的缓慢流动
  vec2 p = uv * freq + vec2(u_time * 0.05, u_time * 0.03);

  // 6 层 fBm
  float n = fbm(p, 6);

  // 三种颜色的混合
  vec3 colorA = vec3(0.1, 0.05, 0.2);   // 深紫
  vec3 colorB = vec3(0.9, 0.3, 0.1);    // 暖橙
  vec3 colorC = vec3(0.1, 0.8, 0.7);    // 青绿

  // 根据噪声值和鼠标 Y 混合颜色
  vec3 color;
  if (n < colorMix) {
    color = mix(colorA, colorB, n / colorMix);
  } else {
    color = mix(colorB, colorC, (n - colorMix) / (1.0 - colorMix));
  }

  gl_FragColor = vec4(color, 1.0);
}
```

```javascript
export function createShaderArt(canvasId) {
  const canvas = document.getElementById(canvasId);
  const gl = canvas.getContext("webgl");

  const vertexSource = `
    attribute vec2 a_position;
    void main() {
      gl_Position = vec4(a_position, 0.0, 1.0);
    }
  `;

  // 片段着色器源码（同上，此处省略重复）
  const fragmentSource = document.getElementById("frag-shader").textContent;

  function compileShader(type, source) {
    const shader = gl.createShader(type);
    gl.shaderSource(shader, source);
    gl.compileShader(shader);
    if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
      console.error(gl.getShaderInfoLog(shader));
      return null;
    }
    return shader;
  }

  const vs = compileShader(gl.VERTEX_SHADER, vertexSource);
  const fs = compileShader(gl.FRAGMENT_SHADER, fragmentSource);
  const program = gl.createProgram();
  gl.attachShader(program, vs);
  gl.attachShader(program, fs);
  gl.linkProgram(program);
  gl.useProgram(program);

  // 全屏矩形
  const buf = gl.createBuffer();
  gl.bindBuffer(gl.ARRAY_BUFFER, buf);
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1,-1,1,-1,-1,1,1,1]), gl.STATIC_DRAW);
  const pos = gl.getAttribLocation(program, "a_position");
  gl.enableVertexAttribArray(pos);
  gl.vertexAttribPointer(pos, 2, gl.FLOAT, false, 0, 0);

  const uRes = gl.getUniformLocation(program, "u_resolution");
  const uMouse = gl.getUniformLocation(program, "u_mouse");
  const uTime = gl.getUniformLocation(program, "u_time");

  let mouseX = 0.5, mouseY = 0.5;

  function render(time) {
    requestAnimationFrame(render);
    gl.uniform2f(uRes, canvas.width, canvas.height);
    gl.uniform2f(uMouse, mouseX, mouseY);
    gl.uniform1f(uTime, time * 0.001);
    gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
  }

  requestAnimationFrame(render);

  return {
    setMouse(x, y) {
      mouseX = x;
      mouseY = y;
    }
  };
}
```

**要点**：GLSL 中 `if` 分支在 GPU 上效率低，可以用 `smoothstep` 替代硬切换；`u_mouse` 归一化到 [0,1] 方便着色器使用；fBm 的 octaves 数量直接影响性能，6-8 层是合理上限。
