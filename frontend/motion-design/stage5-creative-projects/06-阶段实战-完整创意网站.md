## Hero 区域：Three.js 粒子场

背景用 Three.js 创建一个缓慢旋转的粒子场，营造科技感：

```javascript
import * as THREE from 'three'

const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000)
camera.position.z = 30

const renderer = new THREE.WebGLRenderer({ canvas: document.getElementById('three-canvas'), alpha: true })
renderer.setSize(window.innerWidth, window.innerHeight)
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))

// 粒子
const count = 2000
const positions = new Float32Array(count * 3)
for (let i = 0; i < count * 3; i++) {
  positions[i] = (Math.random() - 0.5) * 100
}
const geo = new THREE.BufferGeometry()
geo.setAttribute('position', new THREE.BufferAttribute(positions, 3))
const mat = new THREE.PointsMaterial({ color: 0x3b82f6, size: 0.15, transparent: true, opacity: 0.6 })
const points = new THREE.Points(geo, mat)
scene.add(points)

// 鼠标交互
let mouseX = 0, mouseY = 0
document.addEventListener('mousemove', e => {
  mouseX = (e.clientX / window.innerWidth - 0.5) * 2
  mouseY = (e.clientY / window.innerHeight - 0.5) * 2
})

function animate() {
  requestAnimationFrame(animate)
  points.rotation.y += 0.001
  points.rotation.x += 0.0005
  camera.position.x += (mouseX * 3 - camera.position.x) * 0.05
  camera.position.y += (-mouseY * 3 - camera.position.y) * 0.05
  camera.lookAt(scene.position)
  renderer.render(scene, camera)
}
animate()
```

## 文字拆分动画

标题文字逐字符入场：

```javascript
function splitText(el) {
  const text = el.textContent
  el.innerHTML = ''
  text.split('').forEach(char => {
    const span = document.createElement('span')
    span.textContent = char === ' ' ? '\u00A0' : char
    span.style.display = 'inline-block'
    el.appendChild(span)
  })
  return el.querySelectorAll('span')
}

const chars = splitText(document.querySelector('.split-text'))
gsap.from(chars, {
  y: 80, opacity: 0, rotationX: -90,
  duration: 0.8, stagger: 0.03,
  ease: 'back.out(1.7)',
})
```

## 页面过渡

页面内锚点跳转用平滑滚动 + GSAP：

```javascript
document.querySelectorAll('a[href^="#"]').forEach(link => {
  link.addEventListener('click', e => {
    e.preventDefault()
    const target = document.querySelector(link.getAttribute('href'))
    gsap.to(window, { scrollTo: target, duration: 1, ease: 'power2.inOut' })
  })
})
```

## 性能优化

```javascript
// 1. 减少动画时暂停 Three.js
document.addEventListener('visibilitychange', () => {
  if (document.hidden) cancelAnimationFrame(animationId)
  else animationId = requestAnimationFrame(animate)
})

// 2. 按需渲染
ScrollTrigger.addEventListener('refresh', () => renderer.render(scene, camera))

// 3. 像素比限制
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
```

## 无障碍

```javascript
if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
  gsap.globalTimeline.timeScale(20)
  // Three.js 背景仍然渲染，但不旋转
  points.rotation.y = 0
}
```

### 练习三

1. 打开 Chrome DevTools → Performance
2. 点击 Record，从页面顶部滚动到底部
3. 查看帧率图表，找到掉帧区域
4. 常见原因：
   - 同时动画过多元素（减少或分批）
   - 触发 Layout 的属性（改用 transform/opacity）
   - Three.js 渲染过重（减少粒子数量、按需渲染）
5. 优化后重新录制验证
