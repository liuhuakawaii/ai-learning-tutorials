## 项目架构设计

### 为什么需要架构设计？

很多创意网站的原型阶段很炫酷，但一旦要加功能、改交互、适配设备，代码就变成一团乱麻。根本原因是：**没有在一开始就定义清楚模块边界和通信方式。**

架构设计的核心目标：

1. **关注点分离** —— 每个展区只关心自己的动画逻辑，不关心其他展区在做什么
2. **统一通信协议** —— 模块之间通过事件总线通信，不直接引用彼此的 DOM 或状态
3. **生命周期管理** —— 每个模块有明确的 init/destroy 周期，进入视口时启动，离开时销毁
4. **性能分级策略** —— 根据设备能力动态调整效果复杂度

## 事件总线

事件总线是整个架构的神经中枢。它解决的核心问题是：**模块 A 需要响应模块 B 的状态变化，但 A 不应该直接依赖 B。**

```javascript
// utils/event-bus.js
class EventBus {
  constructor() {
    this.listeners = new Map();
  }

  on(event, callback) {
    if (!this.listeners.has(event)) {
      this.listeners.set(event, new Set());
    }
    this.listeners.get(event).add(callback);
    // 返回取消订阅函数，模块销毁时调用
    return () => this.listeners.get(event).delete(callback);
  }

  emit(event, data) {
    const cbs = this.listeners.get(event);
    if (cbs) cbs.forEach(cb => cb(data));
  }

  // 一次性监听，用于等待某个事件后执行一次
  once(event, callback) {
    const unsubscribe = this.on(event, (data) => {
      unsubscribe();
      callback(data);
    });
    return unsubscribe;
  }
}

export const bus = new EventBus();
```

### 事件设计

事件命名采用 `模块:动作` 的格式，保持一致性：

| 事件名 | 触发时机 | 数据 |
|--------|---------|------|
| `loader:complete` | 加载动画结束 | 无 |
| `scroll:progress` | 滚动进度变化 | `{ progress: 0-1, direction: 'up'|'down' }` |
| `section:enter` | 展区进入视口 | `{ id: string, index: number }` |
| `section:leave` | 展区离开视口 | `{ id: string }` |
| `audio:energy` | 音频能量变化 | `{ bass: 0-1, mid: 0-1, treble: 0-1 }` |
| `performance:degrade` | 性能降级 | `"severe" \| "moderate"` |
| `theme:change` | 主题切换 | `"light" \| "dark"` |
| `form:validation` | 表单验证结果 | `{ field: string, valid: boolean, message: string }` |

## 加载动画

加载动画不只是视觉装饰，它的工程价值在于：**在用户看到页面之前，预加载所有关键资源（字体、音频、大图），避免后续动画出现卡顿或闪烁。**

```javascript
// loader.js
import { gsap } from "gsap";
import { bus } from "./utils/event-bus.js";

export function initLoader() {
  const loader = document.querySelector("#loader");
  const progress = loader.querySelector(".loader-progress");
  const counter = loader.querySelector(".loader-counter");

  // 需要预加载的资源列表
  const resourcesToPreload = [
    { type: "font", family: "Space Grotesk" },
    { type: "font", family: "Inter" },
    { type: "audio", src: "assets/audio/ambient.mp3" },
    { type: "image", src: "assets/images/og-image.jpg" },
  ];

  let loaded = 0;
  const total = resourcesToPreload.length;

  // 模拟资源加载进度
  // 实际项目中应使用真实的资源预加载逻辑
  const interval = setInterval(() => {
    loaded = Math.min(100, loaded + Math.random() * 15);
    const progressValue = loaded / 100;

    // 更新进度条和计数器
    gsap.to(progress, { scaleX: progressValue, duration: 0.3, ease: "power1.out" });
    counter.textContent = `${Math.round(loaded)}%`;

    if (loaded >= 100) {
      clearInterval(interval);
      // 加载完成后，先停顿一下再隐藏，给用户"完成感"
      gsap.to(loader, {
        opacity: 0,
        duration: 0.8,
        delay: 0.5,
        ease: "power2.inOut",
        onComplete: () => {
          loader.style.display = "none";
          // 通知所有模块：加载完成，可以开始动画
          bus.emit("loader:complete");
        },
      });
    }
  }, 200);
}
```

## Hero 区域——数据叙事开场

Hero 区域是用户看到的第一个画面，它需要同时完成两件事：**建立视觉基调**和**传递核心信息**。

```javascript
// sections/hero.js
import { gsap } from "gsap";
import { bus } from "../utils/event-bus.js";

export function initHero() {
  const canvas = document.querySelector("#hero-canvas");
  const ctx = canvas.getContext("2d");

  // 响应式画布尺寸
  function resizeCanvas() {
    canvas.width = window.innerWidth;
    canvas.height = window.innerHeight;
  }
  resizeCanvas();
  window.addEventListener("resize", resizeCanvas);

  // 粒子系统
  const particles = Array.from({ length: 80 }, () => ({
    x: Math.random() * canvas.width,
    y: Math.random() * canvas.height,
    vx: (Math.random() - 0.5) * 0.5,
    vy: (Math.random() - 0.5) * 0.5,
    radius: Math.random() * 2 + 1,
    opacity: Math.random() * 0.5 + 0.2,
  }));

  let animationId;

  function animate() {
    animationId = requestAnimationFrame(animate);
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    particles.forEach(p => {
      p.x += p.vx;
      p.y += p.vy;

      // 边界反弹
      if (p.x < 0 || p.x > canvas.width) p.vx *= -1;
      if (p.y < 0 || p.y > canvas.height) p.vy *= -1;

      ctx.beginPath();
      ctx.arc(p.x, p.y, p.radius, 0, Math.PI * 2);
      ctx.fillStyle = `rgba(255, 255, 255, ${p.opacity})`;
      ctx.fill();
    });
  }

  // 等待加载完成后启动粒子动画和数字滚动
  bus.on("loader:complete", () => {
    animate();

    // 数字滚动动画：从 0 滚动到 2847
    const counter = { value: 0 };
    gsap.to(counter, {
      value: 2847,
      duration: 2.5,
      ease: "power2.out",
      onUpdate: () => {
        document.querySelector("#hero-number").textContent =
          Math.round(counter.value).toLocaleString();
      },
    });
  });

  // 返回销毁函数，用于性能降级时停止动画
  return () => {
    cancelAnimationFrame(animationId);
  };
}
```

## 生成式艺术展区

生成式艺术展区展示两件作品：流动场和粒子宇宙。关键设计决策是：**用 IntersectionObserver 控制每件作品的启停，只有进入视口的作品才运行动画。**

```javascript
// sections/gallery.js
import { createNoise2D } from "simplex-noise";
import { bus } from "../utils/event-bus.js";

const noise2D = createNoise2D();

export function initGallery() {
  const container = document.querySelector("#gallery");
  const artworks = [
    { id: "flow-field", title: "流动场 #47", draw: drawFlowField },
    { id: "particle-universe", title: "粒子宇宙", draw: drawParticleUniverse },
  ];

  const cleanupFns = [];

  artworks.forEach(art => {
    // 创建作品容器
    const wrapper = document.createElement("div");
    wrapper.className = "artwork";
    wrapper.innerHTML = `
      <canvas id="canvas-${art.id}" width="600" height="400"></canvas>
      <h3>${art.title}</h3>
      <p class="artwork-desc">生成式艺术 · 实时渲染</p>
    `;
    container.appendChild(wrapper);

    const canvas = wrapper.querySelector("canvas");
    const ctx = canvas.getContext("2d");
    let animId = null;

    // 用 IntersectionObserver 控制启停
    const observer = new IntersectionObserver(entries => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          animId = art.draw(canvas, ctx);
        } else if (animId) {
          cancelAnimationFrame(animId);
          animId = null;
        }
      });
    }, { threshold: 0.3 });

    observer.observe(canvas);

    cleanupFns.push(() => {
      observer.disconnect();
      if (animId) cancelAnimationFrame(animId);
    });
  });

  // 监听性能降级事件
  bus.on("performance:degrade", level => {
    if (level === "severe") {
      cleanupFns.forEach(fn => fn());
      container.innerHTML = "<p class='degrade-notice'>效果已因性能降级而关闭</p>";
    }
  });
}

function drawFlowField(canvas, ctx) {
  const particles = Array.from({ length: 200 }, () => ({
    x: Math.random() * canvas.width,
    y: Math.random() * canvas.height,
    vx: 0,
    vy: 0,
  }));

  function animate() {
    const animId = requestAnimationFrame(animate);

    // 用半透明黑色覆盖，产生拖尾效果
    ctx.fillStyle = "rgba(0, 0, 0, 0.05)";
    ctx.fillRect(0, 0, canvas.width, canvas.height);

    const time = performance.now() * 0.0005;

    particles.forEach(p => {
      // 用 simplex noise 计算流动方向
      const angle = noise2D(p.x * 0.005, p.y * 0.005 + time) * Math.PI * 2;
      p.vx += Math.cos(angle) * 0.2;
      p.vy += Math.sin(angle) * 0.2;

      // 阻尼衰减，防止速度失控
      p.vx *= 0.95;
      p.vy *= 0.95;

      p.x += p.vx;
      p.y += p.vy;

      // 边界环绕
      if (p.x < 0) p.x = canvas.width;
      if (p.x > canvas.width) p.x = 0;
      if (p.y < 0) p.y = canvas.height;
      if (p.y > canvas.height) p.y = 0;

      ctx.fillStyle = "rgba(180, 200, 255, 0.5)";
      ctx.fillRect(p.x, p.y, 1.5, 1.5);
    });

    return animId;
  }

  return animate();
}

function drawParticleUniverse(canvas, ctx) {
  const particles = Array.from({ length: 300 }, () => {
    const angle = Math.random() * Math.PI * 2;
    const radius = Math.random() * Math.min(canvas.width, canvas.height) * 0.4;
    return {
      angle,
      radius,
      speed: 0.001 + Math.random() * 0.003,
      size: Math.random() * 2 + 0.5,
      hue: Math.random() * 60 + 200, // 蓝紫色系
    };
  });

  function animate() {
    const animId = requestAnimationFrame(animate);

    ctx.fillStyle = "rgba(0, 0, 0, 0.08)";
    ctx.fillRect(0, 0, canvas.width, canvas.height);

    const cx = canvas.width / 2;
    const cy = canvas.height / 2;

    particles.forEach(p => {
      p.angle += p.speed;
      const x = cx + Math.cos(p.angle) * p.radius;
      const y = cy + Math.sin(p.angle) * p.radius;

      ctx.beginPath();
      ctx.arc(x, y, p.size, 0, Math.PI * 2);
      ctx.fillStyle = `hsla(${p.hue}, 80%, 60%, 0.7)`;
      ctx.fill();
    });

    return animId;
  }

  return animate();
}
```

## 音频互动区

音频互动区是整个体验的"高潮"——用户主动触发，页面根据音频能量实时变化。

```javascript
// sections/audio-room.js
import { bus } from "../utils/event-bus.js";

export function initAudioRoom() {
  const btn = document.querySelector("#audio-play-btn");
  const visualizer = document.querySelector("#audio-canvas");
  const ctx = visualizer.getContext("2d");
  let audioCtx, analyser, isPlaying = false;

  btn.addEventListener("click", async () => {
    // 延迟创建 AudioContext，避免浏览器自动播放策略拦截
    if (!audioCtx) {
      audioCtx = new AudioContext();
      analyser = audioCtx.createAnalyser();
      analyser.fftSize = 256;

      const audio = document.querySelector("#ambient-audio");
      const source = audioCtx.createMediaElementSource(audio);
      source.connect(analyser);
      analyser.connect(audioCtx.destination);
    }

    const audio = document.querySelector("#ambient-audio");

    if (isPlaying) {
      audio.pause();
      btn.textContent = "播放";
    } else {
      await audioCtx.resume();
      audio.play();
      btn.textContent = "暂停";
      drawAudio();
    }
    isPlaying = !isPlaying;
  });

  function drawAudio() {
    if (!isPlaying) return;
    requestAnimationFrame(drawAudio);

    const data = new Uint8Array(analyser.frequencyBinCount);
    analyser.getByteFrequencyData(data);

    // 计算不同频段的能量，广播给其他模块
    const binCount = data.length;
    const bass = Array.from(data.slice(0, Math.floor(binCount * 0.1)))
      .reduce((a, b) => a + b, 0) / (Math.floor(binCount * 0.1) * 255);
    const mid = Array.from(data.slice(Math.floor(binCount * 0.1), Math.floor(binCount * 0.5)))
      .reduce((a, b) => a + b, 0) / (Math.floor(binCount * 0.4) * 255);
    const treble = Array.from(data.slice(Math.floor(binCount * 0.5)))
      .reduce((a, b) => a + b, 0) / (Math.floor(binCount * 0.5) * 255);

    bus.emit("audio:energy", { bass, mid, treble });

    // 绘制圆形频谱
    ctx.fillStyle = "rgba(0, 0, 0, 0.2)";
    ctx.fillRect(0, 0, visualizer.width, visualizer.height);

    const cx = visualizer.width / 2;
    const cy = visualizer.height / 2;

    for (let i = 0; i < data.length; i++) {
      const angle = (i / data.length) * Math.PI * 2;
      const len = (data[i] / 255) * 80;

      ctx.beginPath();
      ctx.moveTo(
        cx + Math.cos(angle) * 60,
        cy + Math.sin(angle) * 60
      );
      ctx.lineTo(
        cx + Math.cos(angle) * (60 + len),
        cy + Math.sin(angle) * (60 + len)
      );
      // 根据频率位置设置颜色
      ctx.strokeStyle = `hsl(${(i / data.length) * 360}, 85%, 60%)`;
      ctx.lineWidth = 2;
      ctx.stroke();
    }
  }
}
```

## 滚动叙事编排

滚动叙事是创意网站的核心交互模式。它不只是"滚动触发动画"，而是要像电影导演一样**编排节奏**——哪里快、哪里慢、哪里停顿、哪里爆发。

### 为什么要单独做滚动编排？

很多开发者把 ScrollTrigger 逻辑分散在各个模块里，结果是：展区 A 的动画和展区 B 的动画互相冲突，滚动到某个位置时两个动画同时触发，体验很混乱。

解决方案是：**用一个集中的滚动编排器管理所有展区的进出时序。**

```javascript
// scroll-choreographer.js
import { gsap } from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import { bus } from "./utils/event-bus.js";

gsap.registerPlugin(ScrollTrigger);

export function initScrollChoreography() {
  const sections = document.querySelectorAll(".section");
  let lastDirection = "down";

  // 监听全局滚动方向
  ScrollTrigger.create({
    trigger: document.body,
    start: "top top",
    end: "bottom bottom",
    onUpdate: (self) => {
      const direction = self.direction === 1 ? "down" : "up";
      if (direction !== lastDirection) {
        lastDirection = direction;
      }
      bus.emit("scroll:progress", {
        progress: self.progress,
        direction,
      });
    },
  });

  // 为每个展区创建进入/离开触发器
  sections.forEach((section, index) => {
    const sectionId = section.id;

    ScrollTrigger.create({
      trigger: section,
      start: "top 80%",    // 展区顶部进入视口 80% 位置时触发
      end: "bottom 20%",   // 展区底部离开视口 20% 位置时触发
      onEnter: () => {
        bus.emit("section:enter", { id: sectionId, index });
        // 展区进入时的通用动画：淡入 + 上移
        gsap.fromTo(section, { opacity: 0, y: 50 }, {
          opacity: 1, y: 0, duration: 0.8, ease: "power2.out",
        });
      },
      onLeave: () => {
        bus.emit("section:leave", { id: sectionId });
      },
      onEnterBack: () => {
        bus.emit("section:enter", { id: sectionId, index });
      },
      onLeaveBack: () => {
        bus.emit("section:leave", { id: sectionId });
      },
    });

    // 展区内的视差效果
    const parallaxBg = section.querySelector(".parallax-bg");
    if (parallaxBg) {
      gsap.to(parallaxBg, {
        y: -100,
        ease: "none",
        scrollTrigger: {
          trigger: section,
          start: "top bottom",
          end: "bottom top",
          scrub: true,
        },
      });
    }
  });

  // 展区间过渡：呼吸空间
  // 在展区之间创建空白间隔，滚动时有"留白"感
  sections.forEach((section, i) => {
    if (i < sections.length - 1) {
      const spacer = document.createElement("div");
      spacer.className = "section-spacer";
      spacer.style.height = "30vh";
      section.after(spacer);
    }
  });
}
```

### 叙事节奏设计原则

1. **序曲（Hero）** —— 缓慢展开，数字滚动 + 粒子渐入，节奏舒缓
2. **发展（Gallery）** —— 每件作品独立触发，滚动速度决定动画速度
3. **高潮（Audio Room）** —— 用户主动触发，音频驱动视觉爆发
4. **尾声（Contact/Footer）** —— 回归平静，表单交互简洁明了

关键技巧：**展区之间的"留白"不是浪费空间，而是让用户的注意力有喘息的机会。** 没有留白的创意网站就像没有休止符的音乐——听起来很累。

## 响应式设计

```javascript
  return { dpr, width: canvas.clientWidth * dpr, height: canvas.clientHeight * dpr };
}
```

## 性能监控与降级

性能监控不是"发现问题后关掉所有效果"，而是**分级降级**——先关最耗能的效果，保留核心体验。

```javascript
// utils/performance.js
import { bus } from "./event-bus.js";

export function initPerformanceMonitor() {
  let frames = 0;
  let last = performance.now();
  const fpsHistory = [];

  function check() {
    requestAnimationFrame(check);
    frames++;

    const now = performance.now();
    if (now - last >= 1000) {
      const fps = (frames / (now - last)) * 1000;
      fpsHistory.push(fps);

      // 保留最近 5 秒的 FPS 数据
      if (fpsHistory.length > 5) fpsHistory.shift();

      const avgFps = fpsHistory.reduce((a, b) => a + b) / fpsHistory.length;

      // 分级降级策略
      if (avgFps < 20) {
        bus.emit("performance:degrade", "severe");    // 严重：关闭所有粒子效果
      } else if (avgFps < 40) {
        bus.emit("performance:degrade", "moderate");   // 中等：减少粒子数量
      }

      frames = 0;
      last = now;
    }
  }

  check();
}

// 全局降级响应
bus.on("performance:degrade", level => {
  if (level === "severe") {
    // 关闭所有粒子画布
    document.querySelectorAll(".particle-canvas").forEach(c => {
      c.style.display = "none";
    });
    // 显示降级提示
    const notice = document.createElement("div");
    notice.className = "perf-notice";
    notice.textContent = "已为您的设备优化显示效果";
    document.body.appendChild(notice);
    gsap.fromTo(notice, { opacity: 0, y: 20 }, { opacity: 1, y: 0, duration: 0.5 });
  }
});
```

## 常见误区

**误区一：过度设计加载动画。** 加载动画超过 3 秒会让用户流失。创意网站的加载动画应该是"快速且有品质感"，而不是"漫长且华丽"。如果资源加载真的需要很久，应该用真实的进度条而不是假动画。

**误区二：所有效果同时启动。** 很多初学者会在页面加载完成后同时启动所有展区的动画，结果浏览器直接卡死。正确做法是用 IntersectionObserver 控制——只有当前视口内的动画才运行。

**误区三：忽视叙事节奏。** 展区之间需要"留白"和呼吸空间。如果用户滚动时每个展区都在抢注意力，体验会很累。好的创意网站像好的电影——有快有慢，有高潮有低谷。

**误区四：硬编码所有参数。** 动画速度、颜色、粒子数应该统一管理在设计系统中，而不是散布在各个模块里。这样改一个参数就能全局生效，也方便做响应式适配。

**误区五：不测试真实设备。** 开发机（通常是高配 MacBook）流畅不代表用户设备流畅。一定要在中低端手机上测试。建议用 Chrome DevTools 的 CPU 节流模拟低端设备。

**误区六：忽视无障碍。** `prefers-reduced-motion` 媒体查询不是可选的，而是必须支持的。有些用户对动画敏感（前庭功能障碍），强制播放动画会造成身体不适。同时要确保所有交互元素可通过键盘访问。

**误区七：Canvas 不提供替代内容。** Canvas 元素对屏幕阅读器是不透明的。关键信息不应该只存在于 Canvas 中，应该同时提供 DOM 层的文本替代。给 canvas 元素添加 `role="img"` 和 `aria-label`。

**误区八：音频自动播放。** 浏览器严格限制自动播放音频。不要尝试在页面加载时自动播放——这会被浏览器拦截，还可能导致用户立刻关闭页面。音频必须由用户主动触发（点击按钮）。

## 工程建议

1. **模块化架构。** 每个展区独立模块，事件总线通信。不要让模块之间直接引用彼此的 DOM 或状态。

2. **统一管理动画时间线。** 用 ScrollTrigger 管理触发时机，用集中的滚动编排器协调各展区的进出时序，避免动画冲突。

3. **预加载关键资源。** 音频、字体、大图在加载阶段预加载，避免后续动画出现闪烁或卡顿。

4. **分级降级。** 低端设备先减少粒子数量，再关闭粒子效果，最后用静态图片替代。降级是"少一些效果"而非"完全没效果"。

5. **无障碍支持。** `prefers-reduced-motion` 禁用非必要动画，关键交互元素支持键盘操作，Canvas 提供 aria-label。

6. **性能预算。** 在项目开始时就设定性能目标：首屏加载 < 3 秒，滚动 FPS > 50，内存 < 200MB。用 Lighthouse 和 Web Vitals 持续监控。

7. **代码分割。** 每个展区模块独立打包，用动态 `import()` 按需加载。用户不需要在首屏就加载音频可视化的代码。

8. **版本化资源。** 静态资源（JS/CSS/图片）使用内容哈希命名，确保 CDN 缓存能正确更新。

## 小结

创意网站不是技术堆砌，而是**叙事载体**。架构上用事件总线解耦；性能上用 IntersectionObserver 控制启停；体验上用加载动画做序曲、滚动驱动做叙事、音频互动做高潮。技术服务于内容，内容服务于体验。

记住三个核心原则：
1. **先设计系统，再写效果** —— 统一的颜色、间距、时间管理让一切看起来是一个整体
2. **先跑通再优化** —— 先让所有模块能跑，再做性能降级和响应式适配
3. **先测低端再炫技** —— 在中低端设备上跑得动，才是真的跑得动

```javascript
// utils/event-bus.js
class EventBus {
  constructor() { this.listeners = new Map(); }
  on(event, callback) {
    if (!this.listeners.has(event)) this.listeners.set(event, new Set());
    this.listeners.get(event).add(callback);
    return () => this.listeners.get(event).delete(callback);
  }
  emit(event, data) {
    const cbs = this.listeners.get(event);
    if (cbs) cbs.forEach(cb => cb(data));
  }
}
export const bus = new EventBus();
```

```javascript
      history.push(fps);
      if (history.length > 5) history.shift();

      const avg = history.reduce((a, b) => a + b) / history.length;

      if (avg < 30) bus.emit("perf:degrade", "severe");
      else if (avg < 45) bus.emit("perf:degrade", "moderate");

      frames = 0;
      last = now;
    }
  }

  check();
}

// 无障碍：prefers-reduced-motion
if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
  document.body.classList.add("reduced-motion");
}
```

**思路**：表单验证用实时监听 `input` 事件，验证状态用 CSS class 管理，动画用 GSAP 实现。

```javascript
// sections/contact.js
import { gsap } from "gsap";
import { bus } from "../utils/event-bus.js";

export function initContactForm() {
  const form = document.querySelector("#contact-form");
  if (!form) return;

  const fields = {
    name: {
      input: form.querySelector("#field-name"),
      error: form.querySelector("#error-name"),
      validate: (value) => value.trim().length > 0 ? null : "请输入姓名",
    },
    email: {
      input: form.querySelector("#field-email"),
      error: form.querySelector("#error-email"),
      validate: (value) => {
        if (!value.trim()) return "请输入邮箱";
        const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
        return emailRegex.test(value) ? null : "邮箱格式不正确";
      },
    },
    message: {
      input: form.querySelector("#field-message"),
      error: form.querySelector("#error-message"),
      validate: (value) => {
        if (!value.trim()) return "请输入留言";
        return value.trim().length >= 10 ? null : "留言不少于 10 个字";
      },
    },
  };

  const submitBtn = form.querySelector("#submit-btn");
  const validationState = { name: false, email: false, message: false };

  // 为每个字段绑定实时验证
  Object.entries(fields).forEach(([key, field]) => {
    field.input.addEventListener("input", () => {
      const error = field.validate(field.input.value);

      if (error) {
        validationState[key] = false;
        showError(field, error);
      } else {
        validationState[key] = true;
        showSuccess(field);
      }

      updateSubmitButton();
    });
  });

  function showError(field, message) {
    field.error.textContent = message;
    field.error.classList.add("visible");
    field.input.classList.remove("valid");
    field.input.classList.add("invalid");

    // 抖动动画
    gsap.fromTo(field.input,
      { x: -8 },
      { x: 0, duration: 0.4, ease: "elastic.out(1, 0.3)" }
    );

    bus.emit("form:validation", {
      field: field.input.name,
      valid: false,
      message,
    });
  }

  function showSuccess(field) {
    field.error.textContent = "";
    field.error.classList.remove("visible");
    field.input.classList.remove("invalid");
    field.input.classList.add("valid");

    // 打勾动画
    const checkmark = field.input.parentElement.querySelector(".checkmark");
    if (checkmark) {
      gsap.fromTo(checkmark,
        { scale: 0, opacity: 0 },
        { scale: 1, opacity: 1, duration: 0.3, ease: "back.out(1.7)" }
      );
    }

    bus.emit("form:validation", {
      field: field.input.name,
      valid: true,
      message: null,
    });
  }

  function updateSubmitButton() {
    const allValid = Object.values(validationState).every(Boolean);
    submitBtn.disabled = !allValid;
    submitBtn.classList.toggle("enabled", allValid);
  }

  // 表单提交
  form.addEventListener("submit", (e) => {
    e.preventDefault();

    if (!Object.values(validationState).every(Boolean)) return;

    // 提交成功动画
    gsap.to(form, {
      opacity: 0,
      y: -20,
      duration: 0.4,
      onComplete: () => {
        const success = document.createElement("div");
        success.className = "submit-success";
        success.innerHTML = `
          <svg class="success-icon" viewBox="0 0 52 52">
            <circle cx="26" cy="26" r="25" fill="none" stroke="currentColor" stroke-width="2"/>
            <path d="M14 27l7 7 16-16" fill="none" stroke="currentColor" stroke-width="3"/>
          </svg>
          <p>感谢您的留言！</p>
        `;
        form.parentElement.appendChild(success);

        gsap.fromTo(success,
          { opacity: 0, scale: 0.8 },
          { opacity: 1, scale: 1, duration: 0.6, ease: "back.out(1.7)" }
        );

        // 对勾动画
        const path = success.querySelector("path");
        const pathLength = path.getTotalLength();
        gsap.fromTo(path,
          { strokeDasharray: pathLength, strokeDashoffset: pathLength },
          { strokeDashoffset: 0, duration: 0.8, delay: 0.3, ease: "power2.out" }
        );
      },
    });
  });
}
```

### 练习五

**思路**：主题切换通过改变 CSS 变量实现，所有颜色自动跟随变化。切换动画用 CSS transition 而非 GSAP，因为 CSS transition 对颜色变化的性能更好。

**答案**：
```javascript
// theme.js
import { bus } from "./utils/event-bus.js";

const THEMES = {
  dark: {
    "--color-bg-primary": "#0a0a0f",
    "--color-bg-secondary": "#12121a",
    "--color-text-primary": "#e8e8f0",
    "--color-text-secondary": "#8888a0",
    "--color-accent": "#4F46E5",
    "--color-accent-glow": "rgba(79, 70, 229, 0.3)",
  },
  light: {
    "--color-bg-primary": "#f8f8fc",
    "--color-bg-secondary": "#ffffff",
    "--color-text-primary": "#1a1a2e",
    "--color-text-secondary": "#6b6b80",
    "--color-accent": "#5B4FE9",
    "--color-accent-glow": "rgba(91, 79, 233, 0.2)",
  },
};

export function initTheme() {
  const toggleBtn = document.querySelector("#theme-toggle");

  // 从 localStorage 读取上次的主题偏好
  const savedTheme = localStorage.getItem("preferred-theme") || "dark";
  applyTheme(savedTheme);

  toggleBtn.addEventListener("click", () => {
    const current = document.documentElement.getAttribute("data-theme") || "dark";
    const next = current === "dark" ? "light" : "dark";
    applyTheme(next);
    localStorage.setItem("preferred-theme", next);
    bus.emit("theme:change", next);
  });
}

function applyTheme(themeName) {
  const theme = THEMES[themeName];
  if (!theme) return;

  // 先添加过渡 class，确保切换有动画
  document.documentElement.classList.add("theme-transitioning");

  // 批量更新 CSS 变量
  Object.entries(theme).forEach(([prop, value]) => {
    document.documentElement.style.setProperty(prop, value);
  });

  document.documentElement.setAttribute("data-theme", themeName);

  // 更新切换按钮图标
  const toggleBtn = document.querySelector("#theme-toggle");
  if (toggleBtn) {
    toggleBtn.textContent = themeName === "dark" ? "☀️" : "🌙";
    toggleBtn.setAttribute("aria-label",
      themeName === "dark" ? "切换到浅色模式" : "切换到深色模式"
    );
  }
}
```
