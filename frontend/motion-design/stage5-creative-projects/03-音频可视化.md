# 第三课：音频可视化

## 场景引入

你按下播放键，屏幕上的几何图形随音乐脉动——低音鼓点让圆形膨胀，高频旋律让粒子飞舞，节拍切换时颜色变换。这不是预设动画，而是音频数据**实时驱动**的视觉效果。

音频可视化的本质是"听觉→视觉"的转译。Web Audio API 提供精确分析能力，提取频率、音量、节拍信息，映射到视觉元素的大小、位置、颜色上。

## 学习目标

1. 理解 Web Audio API 的架构与核心概念
2. 掌握 AnalyserNode、BiquadFilterNode、AudioWorklet 的使用方法
3. 学会用 Canvas 2D 实现频谱柱状图、波形图、圆形频谱
4. 掌握节拍检测算法的实现原理
5. 了解用 WebGL 和 Three.js 实现高性能音频可视化
6. 学会接入麦克风输入并实现实时音频效果链

## Web Audio API 架构

Web Audio API 基于**音频图**（Audio Graph）模型，由多个节点（Node）通过连线（connect）组成处理管线。每个节点负责一种音频处理任务：解码、分析、滤波、增益、输出等。

```
音频源（MediaElement / MediaStream / Oscillator）
    ↓
处理节点（BiquadFilter / GainNode / DelayNode）
    ↓
分析节点（AnalyserNode）
    ↓
输出（audioDestination / MediaRecorder）
```

核心初始化代码：

```javascript
// 创建音频上下文——所有音频节点的容器
const audioContext = new AudioContext();

// 创建分析器节点，用于提取频率和时域数据
const analyser = audioContext.createAnalyser();
analyser.fftSize = 2048;                    // FFT 窗口大小，必须是 2 的幂
analyser.smoothingTimeConstant = 0.85;      // 帧间平滑系数，0=无平滑，1=完全平滑
analyser.minDecibels = -90;                  // 频率数据的最小分贝值
analyser.maxDecibels = -10;                  // 频率数据的最大分贝值

// frequencyBinCount = fftSize / 2，代表可用的频率 bin 数量
const bufferLength = analyser.frequencyBinCount;
const frequencyData = new Uint8Array(bufferLength);   // 频域数据（0-255）
const timeDomainData = new Uint8Array(bufferLength);  // 时域数据（0-255，128 为静音）
```

### BiquadFilterNode：频率滤波

`BiquadFilterNode` 是一个二阶 IIR 滤波器，可用于提取特定频段或消除噪音。常见的滤波类型包括：

| type | 用途 | 典型场景 |
|------|------|----------|
| `lowpass` | 低通滤波，只保留低频 | 提取贝斯节奏 |
| `highpass` | 高通滤波，只保留高频 | 提取人声齿音 |
| `bandpass` | 带通滤波，只保留特定频段 | 分离中频乐器 |
| `notch` | 带阻滤波，消除特定频段 | 消除电源嗡嗡声（50/60Hz） |
| `peaking` | 峰化均衡器 | 增强或衰减某频段 |

```javascript
// 创建一个低通滤波器，只保留 200Hz 以下的低频
const lowpass = audioContext.createBiquadFilter();
lowpass.type = "lowpass";
lowpass.frequency.value = 200;    // 截止频率
lowpass.Q.value = 1.0;            // 品质因数，越大共振越强

// 创建一个带通滤波器，提取 1000Hz-4000Hz 的人声频段
const bandpass = audioContext.createBiquadFilter();
bandpass.type = "bandpass";
bandpass.frequency.value = 2500;  // 中心频率
bandpass.Q.value = 0.5;           // Q 值越小，通带越宽

// 在音频图中插入滤波器
source.connect(lowpass);
lowpass.connect(bandpass);
bandpass.connect(analyser);
analyser.connect(audioContext.destination);
```

滤波器的 `frequency` 和 `Q` 参数可以用 `AudioParam` 进行动态调制，实现扫频（Wah）等效果：

```javascript
// 用低频振荡器（LFO）调制滤波器频率，产生自动哇音效果
const lfo = audioContext.createOscillator();
const lfoGain = audioContext.createGain();
lfo.frequency.value = 2;          // LFO 频率 2Hz
lfoGain.gain.value = 1000;        // 调制幅度
lfo.connect(lfoGain);
lfoGain.connect(lowpass.frequency);
lfo.start();
```

### AudioWorklet：自定义音频处理

`AudioWorklet` 允许你在独立的音频渲染线程中运行自定义 JavaScript 代码，延迟极低（通常 2-5ms）。它是 `ScriptProcessorNode`（已废弃）的替代方案。

**AudioWorklet 的核心概念：**

- **AudioWorkletProcessor**：运行在音频渲染线程中的处理器类
- **AudioWorkletNode**：在主线程中创建的节点，与处理器通信
- **MessagePort**：主线程与音频线程之间的通信通道

第一步，编写处理器文件 `beat-processor.js`：

```javascript
// beat-processor.js —— 运行在音频渲染线程中
class BeatDetectorProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this.energyHistory = new Float32Array(43);  // 存储约 1 秒的能量历史
    this.historyIndex = 0;
    this.threshold = 1.3;                        // 阈值倍数
    this.lastBeatTime = 0;
  }

  process(inputs, outputs, parameters) {
    const input = inputs[0];
    if (!input || !input[0]) return true;

    const channel = input[0];
    let energy = 0;
    for (let i = 0; i < channel.length; i++) {
      energy += channel[i] * channel[i];
    }
    energy /= channel.length;

    // 计算历史平均能量
    let avgEnergy = 0;
    for (let i = 0; i < this.energyHistory.length; i++) {
      avgEnergy += this.energyHistory[i];
    }
    avgEnergy /= this.energyHistory.length;

    // 当前能量超过历史均值的 threshold 倍时，判定为节拍
    if (energy > avgEnergy * this.threshold && energy > 0.01) {
      const now = currentTime;
      if (now - this.lastBeatTime > 0.15) {  // 最短间隔 150ms，防止重复触发
        this.lastBeatTime = now;
        this.port.postMessage({ type: "beat", energy, time: now });
      }
    }

    this.energyHistory[this.historyIndex % this.energyHistory.length] = energy;
    this.historyIndex++;

    return true;  // 保持处理器活跃
  }
}

registerProcessor("beat-detector", BeatDetectorProcessor);
```

第二步，在主线程中注册并使用：

```javascript
// 主线程代码
await audioContext.audioWorklet.addModule("beat-processor.js");

const beatNode = new AudioWorkletNode(audioContext, "beat-detector");
beatNode.port.onmessage = (event) => {
  if (event.data.type === "beat") {
    console.log("节拍检测！", event.data.energy);
    triggerBeatVisual();  // 触发视觉节拍反应
  }
};

// 连接到音频图
source.connect(beatNode);
beatNode.connect(analyser);
analyser.connect(audioContext.destination);
```

`AudioWorklet` 的 `process` 函数每秒被调用约 3000 次（取决于采样率和缓冲区大小），因此内部代码必须极度高效——避免对象分配、避免 DOM 操作、避免复杂计算。

## 麦克风输入

通过 `getUserMedia` 获取麦克风音频流，实现实时音频可视化：

```javascript
async function startMicrophoneVisualization() {
  // 请求麦克风权限
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: {
      echoCancellation: false,    // 关闭回声消除，保留原始音频
      noiseSuppression: false,    // 关闭降噪，保留完整频率信息
      autoGainControl: false      // 关闭自动增益，保留原始动态范围
    }
  });

  // 从麦克风流创建音频源
  const micSource = audioContext.createMediaStreamSource(stream);

  // 注意：麦克风源不要连接到 destination，否则会啸叫！
  micSource.connect(analyser);
  // 不要写 analyser.connect(audioContext.destination)

  drawFrequencyBars();  // 开始可视化渲染
}

// 停止麦克风
function stopMicrophone(stream) {
  stream.getTracks().forEach(track => track.stop());
}
```

**麦克风输入的注意事项：**

1. 必须在 HTTPS 环境下才能使用 `getUserMedia`（localhost 除外）
2. 不要把麦克风源连接到 `audioContext.destination`，否则会产生刺耳的反馈啸叫
3. 关闭 `echoCancellation`、`noiseSuppression`、`autoGainControl` 可以获得更原始的音频数据，但会增加环境噪音
4. 用户拒绝麦克风权限时需要优雅降级，提供提示信息

## 波形/示波器可视化

波形图显示音频信号随时间变化的振幅，是示波器的经典视觉表现。与频谱图不同，波形图使用时域数据（`getByteTimeDomainData`），每个采样点代表某一时刻的信号振幅。

```javascript
    const v = timeDomainData[i] / 128.0;

    if (i === 0) {
      ctx.moveTo(x, y);

      ctx.lineTo(x, y);

  ctx.lineTo(canvas.width, canvas.height / 2);

  ctx.strokeStyle = "rgba(0, 255, 136, 0.15)";
  ctx.lineWidth = 1;
  ctx.beginPath();
  ctx.moveTo(0, canvas.height / 2);
  ctx.lineTo(canvas.width, canvas.height / 2);
  ctx.stroke();
```

```javascript
const canvas = document.querySelector("#visualizer");
const ctx = canvas.getContext("2d");

function drawFrequencyBars() {

  const barWidth = canvas.width / bufferLength * 2.5;

  const usableLength = Math.floor(bufferLength * 0.6);

    ctx.fillStyle = `hsl(${hue}, 80%, ${40 + (frequencyData[i] / 255) * 30}%)`;
    ctx.fillRect(x, canvas.height - barHeight, barWidth - 1, barHeight);
    x += barWidth;
  }
```

## 节拍检测算法

节拍检测是音频可视化中最实用的算法之一。核心思想是：当当前帧的能量显著高于历史平均能量时，判定为节拍。以下是两种实现方式。

### 基于能量阈值的节拍检测

```javascript
class EnergyBeatDetector {
  constructor(historySize = 43, threshold = 1.4) {
    this.historySize = historySize;       // 历史窗口大小，43 帧约 1 秒
    this.threshold = threshold;           // 阈值倍数
    this.energyHistory = [];
    this.lastBeatTime = 0;
    this.minInterval = 150;               // 最短节拍间隔（ms）
    this.onBeat = null;                   // 节拍回调函数
  }

  // 计算某一频段的平均能量
  computeBandEnergy(data, startBin, endBin) {
    let sum = 0;
    for (let i = startBin; i < endBin; i++) {
      sum += data[i] * data[i];
    }
    return sum / (endBin - startBin);
  }

  update(frequencyData) {
    // 只关注低频段（鼓点、贝斯通常在 60-250Hz）
    // 假设采样率 44100Hz，fftSize 2048，每个 bin 约 21.5Hz
    // 60Hz ≈ bin 3，250Hz ≈ bin 12
    const energy = this.computeBandEnergy(frequencyData, 3, 12);

    // 计算历史平均能量
    let avgEnergy = 0;
    for (let i = 0; i < this.energyHistory.length; i++) {
      avgEnergy += this.energyHistory[i];
    }
    avgEnergy /= this.energyHistory.length || 1;

    // 计算历史能量方差（用于动态调整阈值）
    let variance = 0;
    for (let i = 0; i < this.energyHistory.length; i++) {
      const diff = this.energyHistory[i] - avgEnergy;
      variance += diff * diff;
    }
    variance /= this.energyHistory.length || 1;

    // 动态阈值：方差大时（音乐变化剧烈）提高阈值，减少误触发
    const dynamicThreshold = this.threshold + Math.sqrt(variance) * 0.001;

    const now = performance.now();
    if (energy > avgEnergy * dynamicThreshold && now - this.lastBeatTime > this.minInterval) {
      this.lastBeatTime = now;
      if (this.onBeat) this.onBeat(energy);
    }

    // 更新历史记录（环形缓冲区）
    this.energyHistory.push(energy);
    if (this.energyHistory.length > this.historySize) {
      this.energyHistory.shift();
    }
  }
}

// 使用示例
const beatDetector = new EnergyBeatDetector(43, 1.4);
beatDetector.onBeat = (energy) => {
  // 节拍触发时的视觉反应
  document.body.style.transform = "scale(1.02)";
  setTimeout(() => document.body.style.transform = "scale(1)", 100);
};

function animationLoop() {
  requestAnimationFrame(animationLoop);
  analyser.getByteFrequencyData(frequencyData);
  beatDetector.update(frequencyData);
  drawFrequencyBars();
}
animationLoop();
```

### 基于频谱通量的节拍检测

频谱通量（Spectral Flux）方法比较相邻帧的频谱差异，突变处即为节拍：

```javascript
class SpectralFluxBeatDetector {
  constructor(threshold = 0.5) {
    this.threshold = threshold;
    this.previousSpectrum = null;
    this.fluxHistory = [];
    this.historySize = 30;
    this.lastBeatTime = 0;
    this.onBeat = null;
  }

  update(frequencyData) {
    const spectrum = new Float32Array(frequencyData.length);
    for (let i = 0; i < frequencyData.length; i++) {
      spectrum[i] = frequencyData[i] / 255;
    }

    if (!this.previousSpectrum) {
      this.previousSpectrum = spectrum;
      return;
    }

    // 计算频谱通量：当前帧与上一帧的正向差异之和
    let flux = 0;
    for (let i = 0; i < spectrum.length; i++) {
      const diff = spectrum[i] - this.previousSpectrum[i];
      if (diff > 0) flux += diff;  // 只取正向变化（能量增加）
    }

    this.fluxHistory.push(flux);
    if (this.fluxHistory.length > this.historySize) {
      this.fluxHistory.shift();
    }

    // 计算局部平均通量
    let avgFlux = 0;
    for (let i = 0; i < this.fluxHistory.length; i++) {
      avgFlux += this.fluxHistory[i];
    }
    avgFlux /= this.fluxHistory.length;

    const now = performance.now();
    if (flux > avgFlux + this.threshold && now - this.lastBeatTime > 150) {
      this.lastBeatTime = now;
      if (this.onBeat) this.onBeat(flux);
    }

    this.previousSpectrum = spectrum;
  }
}
```

## GSAP + 音频数据联动

将音频数据映射到 GSAP 控制的 DOM 元素：

```javascript
import { gsap } from "gsap";

const elements = document.querySelectorAll(".reactive-element");

function updateElements() {
  requestAnimationFrame(updateElements);
  analyser.getByteFrequencyData(frequencyData);

  // 将频率数据分为低、中、高三个频段
  const bass = average(frequencyData.slice(0, 10));    // 低频：鼓点、贝斯
  const mid = average(frequencyData.slice(10, 100));    // 中频：人声、吉他
  const high = average(frequencyData.slice(100, 200));  // 高频：镲片、泛音

  // 低频驱动缩放——鼓点时元素膨胀
  gsap.to(elements[0], { scale: 1 + (bass / 255) * 0.8, duration: 0.1, ease: "none" });
  // 中频驱动旋转——旋律变化时元素转动
  gsap.to(elements[1], { rotation: (mid / 255) * 360, duration: 0.1, ease: "none" });
  // 高频驱动颜色——高频丰富时颜色变化
  gsap.to(elements[2], { backgroundColor: `hsl(${(high / 255) * 120}, 80%, 50%)`, duration: 0.15 });
}

function average(arr) { return arr.reduce((a, b) => a + b, 0) / arr.length; }
updateElements();
```

```javascript
    float dist = length(gl_PointCoord - vec2(0.5));
    if (dist > 0.5) discard;
    // 边缘渐隐，产生柔和的粒子效果
    gl_FragColor = vec4(v_color, 1.0 - smoothstep(0.3, 0.5, dist));
  }
`;

function renderParticles() {
  requestAnimationFrame(renderParticles);
  analyser.getByteFrequencyData(frequencyData);
  const positions = new Float32Array(particleCount * 2);
  const sizes = new Float32Array(particleCount);

  for (let i = 0; i < particleCount; i++) {
    // 将粒子均匀映射到频率数据
    const energy = frequencyData[Math.floor((i / particleCount) * 128)] / 255;
    const angle = (i / particleCount) * Math.PI * 2;
    // 粒子半径随能量变化
    positions[i * 2] = Math.cos(angle) * (0.3 + energy * 0.5);
    positions[i * 2 + 1] = Math.sin(angle) * (0.3 + energy * 0.5);
    sizes[i] = 2 + energy * 8;
  }

  gl.bindBuffer(gl.ARRAY_BUFFER, positionBuffer);
  gl.bufferData(gl.ARRAY_BUFFER, positions, gl.DYNAMIC_DRAW);
  gl.bindBuffer(gl.ARRAY_BUFFER, sizeBuffer);
  gl.bufferData(gl.ARRAY_BUFFER, sizes, gl.DYNAMIC_DRAW);
  gl.drawArrays(gl.POINTS, 0, particleCount);
}
```

## 音频分析性能优化

音频可视化是 CPU 密集型任务，优化不当会导致掉帧和延迟。以下是关键优化策略：

### 1. 降低分析频率

每帧都调用 `getByteFrequencyData` 会占用 CPU 时间。对于不那么敏感的可视化，可以隔帧采集：

```javascript
let frameCount = 0;
function render() {
  requestAnimationFrame(render);
  frameCount++;
  // 每 2 帧采集一次音频数据，减少 CPU 开销
  if (frameCount % 2 === 0) {
    analyser.getByteFrequencyData(frequencyData);
  }
  draw();  // 始终渲染，保证视觉流畅
}
```

### 2. 减少频率 bin 数量

不需要使用所有频率 bin。将 `fftSize` 从 2048 降到 512，频率 bin 从 1024 降到 256，分析精度降低但计算量大幅减少：

```javascript
// 对于只需要低频响应的可视化
analyser.fftSize = 512;  // 而非 2048
```

### 3. 使用 OffscreenCanvas

将渲染逻辑移到 Worker 线程，避免阻塞主线程：

```javascript
// 主线程
const canvas = document.querySelector("#vis");
const offscreen = canvas.transferControlToOffscreen();
const worker = new Worker("render-worker.js");
worker.postMessage({ canvas: offscreen, type: "init" }, [offscreen]);

// 每帧发送频率数据到 Worker
function sendAudioData() {
  requestAnimationFrame(sendAudioData);
  analyser.getByteFrequencyData(frequencyData);
  worker.postMessage({ type: "audioData", data: frequencyData.slice() });
}
sendAudioData();
```

### 4. 避免内存分配

在动画循环中避免创建新数组或对象，复用预分配的缓冲区：

```javascript
// 不好：每帧创建新数组
function bad() {
  const data = new Uint8Array(bufferLength);  // 每帧都分配内存
  analyser.getByteFrequencyData(data);
}

// 好：复用预分配数组
const data = new Uint8Array(bufferLength);     // 只分配一次
function good() {
  analyser.getByteFrequencyData(data);         // 复用已有数组
}
```

## 常见误区

**误区一：直接用原始频率数据。** `getByteFrequencyData` 逐帧波动很大，直接映射到视觉元素会产生抖动。应添加平滑处理，例如指数移动平均：

```javascript
// 平滑后的数据
const smoothedData = new Float32Array(bufferLength);
function smoothData(raw, smoothed, factor) {
  for (let i = 0; i < raw.length; i++) {
    smoothed[i] = smoothed[i] * factor + (raw[i] / 255) * (1 - factor);
  }
}
smoothData(frequencyData, smoothedData, 0.7);
```

**误区二：每帧都请求新数据。** `getByteFrequencyData` 不是免费操作，它涉及内部缓冲区拷贝。可以隔帧获取，或者将分析和渲染拆到不同循环中。

**误区三：忘记处理 AudioContext 暂停。** 标签页不可见时 `AudioContext` 会被暂停，需监听 `visibilitychange` 事件恢复：

```javascript
document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
    audioContext.suspend();
  } else {
    audioContext.resume();
  }
});
```

**误区四：过度使用高分辨率分析。** `fftSize` 设为 8192 不会让可视化更好看，反而增加计算量和延迟。2048 已足够大多数场景。

**误区五：麦克风源连接到 destination。** 这会立刻产生反馈啸叫。麦克风源只连接到分析节点，不连接到输出。

**误区六：忽略 AudioContext 的生命周期。** 每个页面只应创建一个 `AudioContext`，不要每次播放都新建。浏览器对 `AudioContext` 实例数有上限（通常 6 个），超出后会报错。

**误区七：在 AudioWorklet 中做重计算。** `AudioWorklet` 的 `process` 函数运行在实时音频线程中，执行时间不能超过缓冲区时长（约 2.9ms@128samples/44.1kHz）。复杂计算应通过 `MessagePort` 发送到主线程处理。

**误区八：不做移动端降级。** 移动设备的 CPU 和 GPU 资源有限，大量粒子或高频率分析会导致严重卡顿。应检测设备能力，动态降低粒子数量和分析精度：

```javascript
const isMobile = /Mobi|Android/i.test(navigator.userAgent);
const particleCount = isMobile ? 500 : 5000;
analyser.fftSize = isMobile ? 512 : 2048;
```

## 工程建议

1. **分离音频分析和渲染逻辑。** 两个独立循环，分析可以 30fps，渲染保持 60fps，各自用 `requestAnimationFrame` 或 `setInterval` 驱动。

2. **用 `requestAnimationFrame` 驱动渲染。** 不要用 `setInterval`，RAF 会自动在标签页不可见时暂停，节省电量。

3. **限制分析频率范围。** 只渲染前 128-256 个频率 bin 通常够用。人耳对低频更敏感，低频段的 bin 更值得精细展示。

4. **提供音量控制。** 可视化灵敏度应独立于音量。用 `GainNode` 控制音量，用单独的参数控制可视化幅度。

5. **移动端降级。** 移动设备用更简单的 Canvas 2D 渲染，减少粒子数量，降低 `fftSize`。

6. **预分配所有缓冲区。** 在动画循环外创建所有 `TypedArray`、Canvas、ImageData 等对象，循环内只做数据更新和绘制。

7. **使用 `willReadFrequently` 优化 Canvas 2D。** 如果频繁调用 `getImageData`，创建上下文时传入 `{ willReadFrequently: true }` 提示浏览器优化：

```javascript
const ctx = canvas.getContext("2d", { willReadFrequently: true });
```

8. **提供静音可视化模式。** 用户可能想看可视化但不听声音。提供一个开关，将 `analyser` 断开与 `destination` 的连接，但仍保持与源的连接以继续分析。

## 小结

音频可视化是 Web Audio API 与 Canvas/WebGL 的结合。`AnalyserNode` 提供频率和时域数据，可映射到任何视觉属性。Canvas 2D 适合简单柱状图和波形图，WebGL 适合大量粒子的高性能渲染。GSAP 作为"胶水层"将音频数据平滑映射到 DOM 元素。节拍检测让视觉效果与音乐节奏同步，`AudioWorklet` 提供低延迟的自定义音频处理能力。

### 练习二

**思路**：将频率数据映射到 360 度圆周，三角函数计算线条起点终点。

**答案**：
```javascript
function drawCircular() {
  requestAnimationFrame(drawCircular);
  analyser.getByteFrequencyData(data);
  ctx.fillStyle = "rgba(0, 0, 0, 0.15)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  const cx = canvas.width / 2, cy = canvas.height / 2, baseR = 60;
  for (let i = 0; i < 128; i++) {
    const angle = (i / 128) * Math.PI * 2 - Math.PI / 2;
    const energy = data[i] / 255;
    const x1 = cx + Math.cos(angle) * baseR;
    const y1 = cy + Math.sin(angle) * baseR;
    const x2 = cx + Math.cos(angle) * (baseR + energy * 100);
    const y2 = cy + Math.sin(angle) * (baseR + energy * 100);
    ctx.beginPath();
    ctx.moveTo(x1, y1);
    ctx.lineTo(x2, y2);
    ctx.strokeStyle = `hsl(${(i / 128) * 360}, 90%, ${50 + energy * 20}%)`;
    ctx.lineWidth = 2.5;
    ctx.stroke();
  }
}
```

**要点**：`- Math.PI / 2` 让起始角度从正上方开始；亮度随能量增加让高能量频段更醒目。

### 练习三

**思路**：将频率分成 5 个频段，计算平均能量映射到元素动画属性。

**答案**：
```javascript
import { gsap } from "gsap";

const circles = document.querySelectorAll(".circle");
const bands = [[0, 10], [10, 30], [30, 60], [60, 100], [100, 160]];

function avg(arr, s, e) {
  const sl = arr.slice(s, e);
  return sl.reduce((a, b) => a + b, 0) / sl.length;
}

function animate() {
  requestAnimationFrame(animate);
  analyser.getByteFrequencyData(data);
  bands.forEach(([s, e], i) => {
    const energy = avg(data, s, e) / 255;
    if (i < 2) gsap.to(circles[i], { scale: 1 + energy * (0.6 - i * 0.2), duration: 0.1 });
    else if (i < 4) gsap.to(circles[i], { rotation: energy * (180 + i * 90), duration: 0.15 });
    else gsap.to(circles[i], { backgroundColor: `hsl(${energy * 120}, 80%, 50%)`, duration: 0.2 });
  });
}
```

**要点**：频段划分参考音乐频率分布——低频能量高但范围窄，高频能量低但信息丰富。

### 练习四

**思路**：用 Three.js 创建 16×16 的 BoxGeometry 网格，每帧从频率数据中采样更新每个柱体的高度和颜色。相机用 `OrbitControls` 做自动旋转。

**答案**：
```javascript
import * as THREE from "three";
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(12, 10, 12);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const controls = new OrbitControls(camera, renderer.domElement);
controls.autoRotate = true;
controls.autoRotateSpeed = 1.5;

// 光照
const ambientLight = new THREE.AmbientLight(0x404040);
scene.add(ambientLight);
const pointLight = new THREE.PointLight(0xffffff, 1, 50);
pointLight.position.set(5, 15, 5);
scene.add(pointLight);

// 创建 16x16 柱体网格
const gridSize = 16;
const spacing = 0.6;
const boxes = [];
const boxGeometry = new THREE.BoxGeometry(0.4, 1, 0.4);

for (let row = 0; row < gridSize; row++) {
  for (let col = 0; col < gridSize; col++) {
    const material = new THREE.MeshPhongMaterial({ color: 0x0088ff });
    const mesh = new THREE.Mesh(boxGeometry, material);
    mesh.position.set(
      (row - gridSize / 2) * spacing,
      0.5,
      (col - gridSize / 2) * spacing
    );
    scene.add(mesh);
    boxes.push(mesh);
  }
}

// 音频设置
const audioCtx = new AudioContext();
const analyser = audioCtx.createAnalyser();
analyser.fftSize = 512;
const data = new Uint8Array(analyser.frequencyBinCount);

// 加载音频并连接
const audio = document.querySelector("audio");
const source = audioCtx.createMediaElementSource(audio);
source.connect(analyser);
analyser.connect(audioCtx.destination);

// 节拍检测
const beatDetector = new EnergyBeatDetector(43, 1.4);
let beatScale = 1;

beatDetector.onBeat = () => {
  beatScale = 1.15;  // 节拍时放大
};

function animate() {
  requestAnimationFrame(animate);
  analyser.getByteFrequencyData(data);
  beatDetector.update(data);

  // 节拍缩放衰减
  beatScale += (1 - beatScale) * 0.1;

  for (let i = 0; i < boxes.length; i++) {
    // 将网格位置映射到频率数据
    const row = Math.floor(i / gridSize);
    const col = i % gridSize;
    const freqIndex = Math.floor(((row + col) / (gridSize * 2)) * 128);
    const energy = data[freqIndex] / 255;

    // 更新柱体高度
    const targetScale = 0.1 + energy * 4;
    boxes[i].scale.y += (targetScale - boxes[i].scale.y) * 0.15;
    boxes[i].scale.y *= beatScale;

    // 更新颜色
    const hue = (energy * 0.6 + row / gridSize * 0.4) * 360;
    boxes[i].material.color.setHSL(hue / 360, 0.9, 0.3 + energy * 0.4);
  }

  controls.update();
  renderer.render(scene, camera);
}

animate();
```

**要点**：用 `scale.y` 控制柱体高度比改变 geometry 更高效；颜色用 HSL 映射保持视觉和谐；节拍缩放用衰减动画而非瞬间变化，更自然。

```javascript
  for (let i = 0; i < 128; i++) {
    const h = (freqData[i] / 255) * specCanvas.height;
    specCtx.fillStyle = `hsl(${(i / 128) * 270}, 85%, 55%)`;
    specCtx.fillRect(sx, specCanvas.height - h, barW - 1, h);
    sx += barW;
  }
}
```

**要点**：dB 到线性增益的转换公式 `Math.pow(10, db / 20)` 是音频工程的基础知识；旁通模式让用户直观对比处理前后差异；麦克风源不连接到 destination 防止啸叫。
