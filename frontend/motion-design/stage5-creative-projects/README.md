# Stage 5：创意项目

> 综合运用所有技术，完成从创意到落地的完整动效项目。

## 本阶段目标

- 掌握数据驱动的叙事动画
- 实现页面级过渡动画
- 用 Web Audio API 做音频可视化
- 理解生成式艺术的基本方法
- 掌握动画性能优化的系统策略

## 课时列表

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 数据叙事动画 | 数据驱动的故事讲述 |
| 02 | 页面过渡动画 | Barba.js、路由过渡 |
| 03 | 音频可视化 | Web Audio + Canvas/WebGL |
| 04 | 生成式艺术 | 算法艺术、噪声、分形 |
| 05 | 性能优化 | 动画性能、GPU 加速、降级策略 |
| 06 | 阶段实战 | 综合创意网站 |

## 学完本阶段你能

- 用动画讲述数据故事，让图表"活"起来
- 实现丝滑的页面过渡效果
- 把音频变成可视化艺术
- 在性能约束下做出最有创意的动效
