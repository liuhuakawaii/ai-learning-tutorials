# 数据叙事动画

## 数据 + 动画 = 故事

纯数字很难打动人。"用户增长 125%"不如"一个数字从 0 滚动到 125%，配合折线从左到右绘制，每个里程碑弹出标注"有冲击力。

数据叙事动画的核心原则：**动画引导注意力，数据提供内容，节奏制造情绪**。

## 数字滚动

最基础的数据动画。从 0 滚动到目标值：

```javascript
function countUp(el, target, duration = 1500) {
  const start = performance.now()
  function tick(now) {
    const p = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - p, 3)  // easeOutCubic
    el.textContent = Math.round(target * eased).toLocaleString()
    if (p < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
```

格式化版本（千分位、前缀后缀）：

```javascript
function countUpFormatted(el, target, { prefix = '', suffix = '', duration = 1500, decimals = 0 } = {}) {
  const start = performance.now()
  function tick(now) {
    const p = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - p, 3)
    const val = (target * eased).toFixed(decimals).replace(/\B(?=(\d{3})+(?!\d))/g, ',')
    el.textContent = prefix + val + suffix
    if (p < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
```

## 数据驱动的图表入场

用 D3 的 enter/update/exit 模式，配合动画：

```javascript
function drawBarChart(container, data) {
  const svg = d3.select(container).append('svg').attr('width', 500).attr('height', 300)
  const x = d3.scaleBand().domain(data.map(d => d.label)).range([0, 480]).padding(0.3)
  const y = d3.scaleLinear().domain([0, d3.max(data, d => d.value)]).range([280, 0])

  svg.selectAll('rect').data(data).enter()
    .append('rect')
    .attr('x', d => x(d.label))
    .attr('width', x.bandwidth())
    .attr('y', 280).attr('height', 0)
    .attr('fill', '#3b82f6').attr('rx', 4)
    .transition().duration(800)
    .delay((d, i) => i * 120)
    .ease(d3.easeCubicOut)
    .attr('y', d => y(d.value))
    .attr('height', d => 280 - y(d.value))
}
```

关键：柱子从底部"生长"出来，错落延迟制造节奏感。

## 时间线编排

用 GSAP Timeline 把多个数据动画编排成一个故事：

```javascript
const tl = gsap.timeline({ defaults: { ease: 'power2.out' } })

tl
  // 第一幕：标题入场
  .from('.section-title', { y: 40, opacity: 0, duration: 0.6 })
  // 第二幕：数字滚动
  .add(() => {
    document.querySelectorAll('.counter').forEach(el => {
      countUp(el, parseInt(el.dataset.target))
    })
  }, '-=0.2')
  // 第三幕：图表入场
  .from('.chart-container', { y: 60, opacity: 0, duration: 0.8 }, '+=0.5')
  .add(() => drawBarChart('#chart', chartData), '-=0.4')
  // 第四幕：结论
  .from('.conclusion', { y: 30, opacity: 0, duration: 0.5 }, '+=0.3')
```

## 滚动驱动叙事

用 ScrollTrigger 控制故事节奏——用户滚动到某个位置才播放下一段：

```javascript
gsap.registerPlugin(ScrollTrigger)

// 每个章节独立触发
document.querySelectorAll('.story-section').forEach(section => {
  const tl = gsap.timeline({
    scrollTrigger: {
      trigger: section,
      start: 'top 70%',
      toggleActions: 'play none none none',
    }
  })

  tl.from(section.querySelector('h2'), { y: 30, opacity: 0, duration: 0.5 })
    .from(section.querySelector('.chart'), { y: 40, opacity: 0, duration: 0.6 }, '-=0.2')
    .from(section.querySelector('.insight'), { y: 20, opacity: 0, duration: 0.4 }, '-=0.1')
})
```

## 饼图生长动画

用 `attrTween` 让每段弧从起角"生长"到终止角：

```javascript
const pie = d3.pie().value(d => d.value).sort(null)
const arc = d3.arc().innerRadius(60).outerRadius(100)

svg.selectAll('path').data(pie(data)).enter()
  .append('path')
  .attr('fill', (d, i) => colors[i])
  .transition().duration(600).delay((d, i) => i * 200)
  .attrTween('d', function(d) {
    const interp = d3.interpolate({ startAngle: d.startAngle, endAngle: d.startAngle }, d)
    return t => arc(interp(t))
  })
```

## 折线逐步绘制

`stroke-dashoffset` 从全长到 0：

```javascript
const path = svg.append('path').datum(data)
  .attr('fill', 'none').attr('stroke', '#3b82f6')
  .attr('stroke-width', 2.5).attr('d', line)

const len = path.node().getTotalLength()
path.attr('stroke-dasharray', len).attr('stroke-dashoffset', len)
  .transition().duration(2000).ease(d3.easeCubicInOut)
  .attr('stroke-dashoffset', 0)
```

## 设计原则

1. **动画服务于数据**：不要为了炫酷加动画。每个动画都应该帮助用户理解数据
2. **时长控制**：数据入场不超过 2 秒，悬停反馈不超过 200ms
3. **交错制造节奏**：列表项错落出现，但总时长不要超过 3 秒
4. **减少动画降级**：`prefers-reduced-motion` 用户应该直接看到最终状态
5. **大数据量做采样**：几千个数据点不要逐个动画

## 练习

### 练习一：数据故事页

设计一个"2024 年度报告"页面：标题入场 → 4 个关键指标数字滚动 → 柱状图入场 → 饼图生长 → 折线逐步绘制 → 总结文字淡入。所有动画由滚动触发。

### 练习二：实时数据面板

模拟实时数据：每 3 秒随机更新图表数据，柱状图用 D3 transition 平滑过渡到新高度，数字从当前值滚动到新值。

### 练习三：对比动画

左右两组数据对比，左侧数据增长时柱子向上生长（绿色），右侧数据下降时柱子缩短（红色）。用 D3 的 enter/update 处理数据变化。
