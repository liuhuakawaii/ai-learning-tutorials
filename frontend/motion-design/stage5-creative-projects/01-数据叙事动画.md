# 第一课：数据叙事动画

## 场景引入

你打开一个年度报告页面，随着滚动，柱状图缓缓生长、数字跳动上升、地图热点逐个亮起——整个过程像在讲述一个故事。数据叙事动画的核心：用动画引导注意力，让数据自己"开口说话"。

传统数据可视化关注准确性，而数据叙事在此基础上增加了**时间维度**和**情感维度**。柱状图快速弹出传达"增长冲击力"，缓慢淡入则传达"稳健积累"。动画节奏本身就是叙事。

## 学习目标

1. 理解数据叙事动画的设计原则与叙事结构
2. 掌握用 GSAP + D3.js 实现数据驱动的动画序列
3. 学会将滚动交互与数据展示节奏结合
4. 能够独立完成一个完整的数据叙事页面

## 数据叙事的基本结构

```
开场（Hook）→ 展开（Development）→ 高潮（Climax）
```

- **开场**：用大数字或冲击性画面抓住注意力
- **展开**：逐步展示数据维度，每组数据配合独立动画
- **高潮**：揭示关键洞察或总结性数据

## 动画节奏如何引导注意力

数据叙事动画的本质是**用时间轴控制观众的注意力流**。人类视觉系统对运动高度敏感，动画节奏直接决定了观众"先看什么、后看什么、看多久"。

### 注意力引导的三个机制

**机制一：入场顺序决定阅读顺序。** 当多个数据元素同时存在时，先出现的元素会率先捕获注意力。柱状图中从左到右依次生长，观众自然按时间线阅读；如果从中间向两侧展开，则暗示"以某个节点为中心的对比"。

**机制二：速度变化传递情绪。** 缓动曲线不仅影响观感，还传递数据含义：
- `power2.out`（先快后慢）：适合展示"增长到达目标"，传达确定感
- `power2.in`（先慢后快）：适合展示"加速突破"，传达紧迫感
- `elastic.out`：适合强调"超出预期"的惊喜感
- `linear`：适合展示"匀速稳定"的趋势

**机制三：停顿制造焦点。** 在动画序列中插入短暂停顿（0.3-0.5 秒），让观众有时间消化上一组数据，再进入下一组。这比连续不断的数据流更有效。

```javascript
const tl = gsap.timeline();

// 第一组数据：快速入场，建立节奏
tl.to(".section-a .bar", {
  scaleY: 1, transformOrigin: "bottom",
  duration: 0.5, stagger: 0.1, ease: "power2.out",
});

// 停顿 0.6 秒，让观众消化
tl.to({}, { duration: 0.6 });

// 第二组数据：稍慢入场，暗示数据更复杂
tl.to(".section-b .bar", {
  scaleY: 1, transformOrigin: "bottom",
  duration: 0.8, stagger: 0.15, ease: "power2.out",
});
```

### 节奏模式

实际项目中常用的三种节奏模式：

| 模式 | 动画特征 | 适用场景 |
|------|---------|---------|
| 递进式 | 元素依次出现，间隔均匀 | 时间线数据、排行榜 |
| 对比式 | 两组数据同时动画，形成对比 | 同比/环比、A/B 测试 |
| 聚焦式 | 所有元素同时出现，随后高亮关键值 | 总览仪表盘、KPI 看板 |

## 数字滚动动画

最基础的数据叙事元素——让数字从 0 动态增长到目标值：

```javascript
import { gsap } from "gsap";

function animateCounter(element, targetValue, duration = 2) {
  const counter = { value: 0 };
  gsap.to(counter, {
    value: targetValue,
    duration,
    ease: "power2.out",
    onUpdate: () => {
      if (targetValue >= 10000) {
        element.textContent = (counter.value / 10000).toFixed(1) + "万";
      } else {
        element.textContent = Math.round(counter.value).toLocaleString();
      }
    },
  });
}

animateCounter(document.querySelector("#revenue"), 128500, 2.5);
```

`power2.out` 缓动让数字前期快速增长、后期减速，模拟"逐渐看清全貌"的心理感受。

## D3.js 数据绑定 + GSAP 动画

D3.js 负责数据绑定和 DOM 生成，GSAP 负责动画控制。两者的分工原则是：**D3 管数据到 DOM 的映射，GSAP 管 DOM 到视觉的过渡**。

```javascript
import * as d3 from "d3";
import { gsap } from "gsap";

const data = [
  { month: "1月", revenue: 4200 }, { month: "2月", revenue: 3800 },
  { month: "3月", revenue: 5100 }, { month: "4月", revenue: 6300 },
  { month: "5月", revenue: 7200 }, { month: "6月", revenue: 8900 },
];

const svg = d3.select("#chart").append("svg").attr("width", 600).attr("height", 300);
const xScale = d3.scaleBand().domain(data.map(d => d.month)).range([0, 600]).padding(0.3);
const yScale = d3.scaleLinear().domain([0, 10000]).range([300, 0]);

const bars = svg.selectAll("rect").data(data).enter().append("rect")
  .attr("x", d => xScale(d.month))
  .attr("width", xScale.bandwidth())
  .attr("y", 300).attr("height", 0).attr("fill", "#4F46E5");

const tl = gsap.timeline({ paused: true });
bars.each(function (d, i) {
  tl.to(this, {
    y: yScale(d.revenue), height: 300 - yScale(d.revenue),
    duration: 0.6, ease: "back.out(1.2)",
  }, i * 0.15);
});
```

## 环形图动画

操作 SVG 的 `stroke-dasharray` 和 `stroke-dashoffset` 实现绘制动画：

```javascript
function animateDonut(segments, container) {
  const radius = 80, circumference = 2 * Math.PI * radius;
  let cumulativePercent = 0;

  segments.forEach((segment, index) => {
    const circle = document.createElementNS("http://www.w3.org/2000/svg", "circle");
    circle.setAttribute("cx", "100");
    circle.setAttribute("cy", "100");
    circle.setAttribute("r", String(radius));
    circle.setAttribute("fill", "none");
    circle.setAttribute("stroke", segment.color);
    circle.setAttribute("stroke-width", "30");
    circle.setAttribute("stroke-dasharray", `${circumference} ${circumference}`);
    circle.setAttribute("stroke-dashoffset", String(circumference));
    container.appendChild(circle);

    const segmentLength = (segment.percent / 100) * circumference;
    const offset = circumference - cumulativePercent * circumference / 100;

    gsap.to(circle, {
      strokeDashoffset: offset - segmentLength,
      duration: 1.2, ease: "power2.inOut", delay: index * 0.3,
    });
    cumulativePercent += segment.percent;
  });
}
```

## 折线图动画

折线图的动画核心是路径绘制（path drawing），利用 SVG 的 `stroke-dasharray` 和 `stroke-dashoffset` 让线条像被"画出来"一样：

```javascript
import * as d3 from "d3";
import { gsap } from "gsap";

function createAnimatedLineChart(data, container, { width = 600, height = 300, padding = 40 } = {}) {
  const svg = d3.select(container)
    .append("svg")
    .attr("width", width)
    .attr("height", height);

  const xScale = d3.scalePoint()
    .domain(data.map(d => d.label))
    .range([padding, width - padding]);

  const yScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.value) * 1.1])
    .range([height - padding, padding]);

  // 生成路径
  const line = d3.line()
    .x(d => xScale(d.label))
    .y(d => yScale(d.value))
    .curve(d3.curveMonotoneX);

  const path = svg.append("path")
    .datum(data)
    .attr("d", line)
    .attr("fill", "none")
    .attr("stroke", "#4F46E5")
    .attr("stroke-width", 3);

  // 路径绘制动画
  const pathLength = path.node().getTotalLength();
  path
    .attr("stroke-dasharray", pathLength)
    .attr("stroke-dashoffset", pathLength);

  gsap.to(path.node(), {
    strokeDashoffset: 0,
    duration: 2,
    ease: "power2.inOut",
  });

  // 数据点依次出现
  const dots = svg.selectAll(".dot")
    .data(data)
    .enter()
    .append("circle")
    .attr("class", "dot")
    .attr("cx", d => xScale(d.label))
    .attr("cy", d => yScale(d.value))
    .attr("r", 0)
    .attr("fill", "#4F46E5");

  gsap.to(dots.nodes(), {
    r: 5,
    duration: 0.3,
    stagger: 0.15,
    delay: 1.5,
    ease: "back.out(2)",
  });

  return { svg, xScale, yScale, path };
}
```

### 带 Tooltip 的交互式折线图

数据点悬浮显示具体数值，是数据可视化的常见需求：

```javascript
function addLineChartTooltip(svg, data, xScale, yScale) {
  const tooltip = d3.select("body")
    .append("div")
    .attr("class", "chart-tooltip")
    .style("position", "absolute")
    .style("visibility", "hidden")
    .style("background", "rgba(0,0,0,0.8)")
    .style("color", "#fff")
    .style("padding", "8px 12px")
    .style("border-radius", "4px")
    .style("font-size", "13px")
    .style("pointer-events", "none");

  const overlay = svg.append("rect")
    .attr("width", svg.attr("width"))
    .attr("height", svg.attr("height"))
    .attr("fill", "none")
    .style("pointer-events", "all");

  const hoverLine = svg.append("line")
    .attr("stroke", "#999")
    .attr("stroke-width", 1)
    .attr("stroke-dasharray", "4,4")
    .style("opacity", 0);

  const hoverDot = svg.append("circle")
    .attr("r", 6)
    .attr("fill", "#4F46E5")
    .attr("stroke", "#fff")
    .attr("stroke-width", 2)
    .style("opacity", 0);

  overlay.on("mousemove", function (event) {
    const [mx] = d3.pointer(event);
    const xValues = data.map(d => xScale(d.label));
    const closest = data.reduce((prev, curr, i) =>
      Math.abs(xValues[i] - mx) < Math.abs(xValues[prev] - mx) ? i : prev, 0);

    const d = data[closest];
    const cx = xScale(d.label);
    const cy = yScale(d.value);

    hoverLine
      .attr("x1", cx).attr("x2", cx)
      .attr("y1", yScale.range()[0]).attr("y2", cy)
      .style("opacity", 1);

    hoverDot
      .attr("cx", cx).attr("cy", cy)
      .style("opacity", 1);

    tooltip
      .style("visibility", "visible")
      .html(`${d.label}<br/>值: ${d.value.toLocaleString()}`)
      .style("left", `${event.pageX + 12}px`)
      .style("top", `${event.pageY - 28}px`);
  });

  overlay.on("mouseleave", function () {
    hoverLine.style("opacity", 0);
    hoverDot.style("opacity", 0);
    tooltip.style("visibility", "hidden");
  });
}
```

## 散点图动画

散点图适合展示两个变量之间的关系。动画可以从中心向外扩散，或按数据维度分批出现：

```javascript
import * as d3 from "d3";
import { gsap } from "gsap";

function createAnimatedScatter(data, container, { width = 600, height = 400, padding = 50 } = {}) {
  const svg = d3.select(container)
    .append("svg")
    .attr("width", width)
    .attr("height", height);

  const xScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.x) * 1.1])
    .range([padding, width - padding]);

  const yScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.y) * 1.1])
    .range([height - padding, padding]);

  const rScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.size)])
    .range([4, 20]);

  // 坐标轴
  svg.append("g")
    .attr("transform", `translate(0,${height - padding})`)
    .call(d3.axisBottom(xScale));

  svg.append("g")
    .attr("transform", `translate(${padding},0)`)
    .call(d3.axisLeft(yScale));

  // 散点初始状态：在图表中心，半径为 0
  const dots = svg.selectAll(".scatter-dot")
    .data(data)
    .enter()
    .append("circle")
    .attr("class", "scatter-dot")
    .attr("cx", (width - padding + padding) / 2)
    .attr("cy", (height - padding + padding) / 2)
    .attr("r", 0)
    .attr("fill", d => d.color || "#4F46E5")
    .attr("opacity", 0.7);

  // 动画：从中心扩散到真实位置
  const tl = gsap.timeline();

  tl.to(dots.nodes(), {
    cx: (i) => xScale(data[i].x),
    cy: (i) => yScale(data[i].y),
    r: (i) => rScale(data[i].size),
    duration: 1,
    stagger: { amount: 0.8, from: "center" },
    ease: "power2.out",
  });

  return { svg, xScale, yScale, dots };
}
```

## 地图与地理数据可视化动画

地图可视化是数据叙事中最具冲击力的形式之一。通过动画让地理位置数据逐步展开，可以有效传达区域分布和变化趋势。

### SVG 地图路径动画

使用 GeoJSON 数据配合 D3 的地图投影，实现省份/区域的逐步点亮效果：

```javascript
import * as d3 from "d3";
import { gsap } from "gsap";

async function createAnimatedMap(geoJsonUrl, dataMap, container) {
  const width = 800, height = 600;

  const svg = d3.select(container)
    .append("svg")
    .attr("width", width)
    .attr("height", height);

  const projection = d3.geoMercator()
    .center([104, 37])
    .scale(800)
    .translate([width / 2, height / 2]);

  const pathGenerator = d3.geoPath().projection(projection);

  const geoData = await d3.json(geoJsonUrl);

  // 绘制地图路径
  const paths = svg.selectAll("path")
    .data(geoData.features)
    .enter()
    .append("path")
    .attr("d", pathGenerator)
    .attr("fill", "#e5e7eb")
    .attr("stroke", "#fff")
    .attr("stroke-width", 1);

  // 按数据值排序，值小的先亮，值大的后亮——形成"热点扩散"效果
  const sortedFeatures = [...geoData.features].sort((a, b) => {
    const valA = dataMap[a.properties.name] || 0;
    const valB = dataMap[b.properties.name] || 0;
    return valA - valB;
  });

  // 根据数据值设置颜色比例尺
  const colorScale = d3.scaleSequential(d3.interpolateBlues)
    .domain([0, d3.max(Object.values(dataMap))]);

  // 逐个区域点亮
  sortedFeatures.forEach((feature, i) => {
    const regionName = feature.properties.name;
    const value = dataMap[regionName] || 0;

    gsap.to(`path[data-name="${regionName}"]`, {
      fill: colorScale(value),
      duration: 0.4,
      delay: i * 0.08,
      ease: "power1.inOut",
    });
  });

  // 给每个路径添加 data 属性用于选择
  paths.attr("data-name", d => d.properties.name);

  return { svg, paths, projection };
}
```

## 数据对比动画

对比两组数据（如同比、环比、A/B 测试结果）时，动画设计需要突出差异：

```javascript
function animateComparison(container, dataA, dataB, labels) {
  const width = 600, height = 300, barHeight = 30, gap = 10;

  const svg = d3.select(container)
    .append("svg")
    .attr("width", width)
    .attr("height", (barHeight + gap) * labels.length);

  const maxVal = Math.max(d3.max(dataA), d3.max(dataB));
  const xScale = d3.scaleLinear().domain([0, maxVal]).range([0, width / 2 - 60]);

  labels.forEach((label, i) => {
    const y = i * (barHeight + gap);

    // A 组（向左延伸）
    const barA = svg.append("rect")
      .attr("x", width / 2 - xScale(dataA[i]))
      .attr("y", y)
      .attr("width", 0)
      .attr("height", barHeight)
      .attr("fill", "#4F46E5")
      .attr("rx", 3);

    // B 组（向右延伸）
    const barB = svg.append("rect")
      .attr("x", width / 2)
      .attr("y", y)
      .attr("width", 0)
      .attr("height", barHeight)
      .attr("fill", "#F59E0B")
      .attr("rx", 3);

    // 标签
    svg.append("text")
      .attr("x", width / 2)
      .attr("y", y + barHeight / 2 + 4)
      .attr("text-anchor", "middle")
      .attr("font-size", "12px")
      .attr("fill", "#333")
      .text(label);

    // 动画：从中间向两侧展开
    gsap.to(barA.node(), {
      width: xScale(dataA[i]),
      duration: 0.8,
      delay: i * 0.12,
      ease: "power2.out",
    });

    gsap.to(barB.node(), {
      width: xScale(dataB[i]),
      duration: 0.8,
```

为数据图表添加语义化标注，让屏幕阅读器能理解数据内容：

```javascript
function addChartAccessibility(svgElement, data, chartTitle) {
  svgElement.setAttribute("role", "img");
```

```javascript
function addKeyboardNavigation(dots, data, tooltip) {
```

### Resize 监听与重绘

窗口大小变化时销毁旧图表并重建：

```javascript
function setupResponsiveChart(container, data) {
  let chart = null;

  function render() {
    if (chart) {
      chart.svg.remove();
      ScrollTrigger.getAll().forEach(st => {
        if (st.trigger === container) st.kill();
      });
    }
    chart = createResponsiveChart(container, data);
  }

    render();
  });
  resizeObserver.observe(container);

  return () => resizeObserver.disconnect();
}
```

## 常见误区

**误区一：动画过度导致数据失真。** 弹性缓动让柱子"超过"目标高度再回弹，观众会误判数据大小。数据动画应优先保证准确性。在柱状图和饼图中，避免使用 `elastic` 和 `bounce` 缓动。

**误区二：所有数据同时动画。** 20 根柱子一起生长，观众来不及阅读。正确做法是分组分步展示或使用交错动画（stagger）。一般建议交错间隔 0.08-0.15 秒。

**误区三：忽略移动端体验。** 复杂 SVG 动画在小屏幕上可能卡顿，必须有降级方案。移动端应减少同时动画的元素数量，缩短动画时长，禁用弹性缓动。

**误区四：数字滚动时没有格式化。** 数字从 0 滚动到 1283456，用户看到乱跳的数字。应该加千分位分隔符和"万""亿"单位。

**误区五：忽略坐标轴动画。** 只动画数据不动画坐标轴，导致坐标轴突然出现，破坏叙事流畅性。坐标轴应先于数据出现，或与数据同步淡入。

**误区六：颜色编码不一致。** 同一类别在不同图表中使用不同颜色，观众需要重新建立映射关系。应建立全局颜色变量，确保同一数据类别在所有图表中使用相同颜色。

**误区七：动画时长与数据重要性不匹配。** 关键数据和次要数据使用相同的动画时长。重要数据应使用更慢的动画（1-1.5 秒）来强调，次要数据用更快的动画（0.3-0.5 秒）快速带过。

**误区八：缺乏退出动画。** 数据更新时旧数据直接消失，新数据凭空出现。应使用淡出 + 淡入的过渡，让观众理解数据在"变化"而非"替换"。

## 工程建议

1. **动画时长与数据量匹配。** 5 个数据点用 2 秒，50 个数据点需要更长时间或分页。
2. **用 `will-change` 提示浏览器。** 对频繁动画的 SVG 元素添加 `will-change: transform`。
3. **提供"跳过动画"选项。** 重复访问用户或辅助技术用户应能跳过动画。
4. **数据格式化与动画分离。** 格式化逻辑应是独立工具函数。
5. **测试极端数据。** 数据值为 0 或极大值时动画是否正常。
6. **颜色方案考虑色盲用户。** 避免仅依赖红绿区分数据，使用色盲友好的调色板（如蓝橙对比），或配合纹理/形状区分。
7. **大数据集使用 Canvas 代替 SVG。** 当数据点超过 1000 个时，SVG DOM 操作会严重影响性能。应切换到 Canvas 渲染，GSAP 同样可以驱动 Canvas 对象的属性动画。
8. **动画完成后清理 ScrollTrigger。** 单页应用中路由切换时，旧页面的 ScrollTrigger 实例不会自动销毁，会导致内存泄漏和意外行为。在组件卸载时调用 `ScrollTrigger.getAll().forEach(st => st.kill())`。

## 小结

数据叙事动画的核心不是"让图表动起来"，而是**用动画节奏引导观众理解数据**。D3.js 负责数据绑定，GSAP 负责动画控制，ScrollTrigger 将叙事节奏与滚动同步。三者各司其职，实现既准确又动人的数据故事。

在实际项目中，还需要关注无障碍设计（减少动画偏好、ARIA 标注、键盘导航）和响应式适配（viewBox 缩放、ResizeObserver 重绘、移动端降级）。这些工程细节决定了数据叙事动画能否真正服务于所有用户。

### 练习一

**思路**：用 GSAP 驱动代理对象的 value 属性，在 onUpdate 回调中格式化并更新 DOM。

**答案**：
```javascript
import { gsap } from "gsap";

function createCounter(element, options = {}) {
  const { from = 0, to = 100, duration = 2, ease = "power2.out", onComplete = null } = options;
  const proxy = { value: from };

  function formatNumber(num) {
    const absNum = Math.abs(num);
    if (absNum >= 100000000) return (num / 100000000).toFixed(1) + "亿";
    if (absNum >= 10000) return (num / 10000).toFixed(1) + "万";
    return Math.round(num).toLocaleString("zh-CN");
  }

  return gsap.to(proxy, {
    value: to, duration, ease,
    onUpdate: () => { element.textContent = formatNumber(proxy.value); },
    onComplete: () => { element.textContent = formatNumber(to); onComplete?.(); },
  });
}
```

**要点**：格式化逻辑独立为 `formatNumber`；使用代理对象而非直接操作 DOM；提供 `onComplete` 回调。

### 练习四

**答案**：

```javascript
  .attr("opacity", 1);

  .x(d => xScale(d.label))
  .y(d => yScale(d.value))
  .curve(d3.curveMonotoneX);

const path = svg.append("path")

  .attr("fill", "none")

  path
    .attr("stroke-dasharray", pathLength)
    .attr("stroke-dashoffset", pathLength);

  gsap.to(path.node(), {
    strokeDashoffset: 0,
    duration: 2,

    r: 5,
    duration: 0.3,
    stagger: 0.2,
    delay: 1.8,
    ease: "back.out(2)",

}

  .attr("class", "line-tooltip")
  .style("position", "absolute")
  .style("visibility", "hidden")
  .style("background", "rgba(0,0,0,0.8)")
```
