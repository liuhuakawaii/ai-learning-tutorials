# 第四课：requestAnimationFrame 与时间管理

## 场景引入

当你需要用 JavaScript 实现逐帧控制的动画——物理模拟、粒子效果、Canvas 渲染或滚动联动动画时，`requestAnimationFrame`（rAF）是唯一正确的选择。它比 `setInterval` 更精准、更省电，是浏览器专门为动画设计的调度机制。

想象你在做一个跟随鼠标移动的光标拖尾效果。如果用 `setInterval`，你可能会遇到光标抖动、延迟、甚至在后台标签页疯狂消耗 CPU 的问题。而 rAF 天然解决了这些痛点——它告诉浏览器"在下一次重绘之前，请帮我执行这个回调"，从而把动画调度和浏览器渲染管线完美对齐。

## 学习目标

- 理解 rAF 的工作原理和回调时机
- 掌握基于时间的动画编程模式
- 学会管理多个 rAF 动画的启动与停止
- 理解 rAF 与浏览器渲染管线的关系
- 能够实现帧率监控、动画暂停/恢复等实用功能
- 了解 rAF 在不同场景下的最佳实践

## 一、为什么不用 setInterval

### 1.1 setInterval 的问题

```javascript
// 不推荐
let position = 0
setInterval(() => {
  position += 2
  box.style.transform = `translateX(${position}px)`
}, 16)
```

这段代码有三个严重问题：

**问题一：时间不精确。** `setInterval` 的间隔受主线程阻塞影响。如果主线程正在执行一个耗时 200ms 的任务，那这个回调就会被推迟。浏览器实际执行间隔可能远大于或远小于你设定的 16ms。

**问题二：与渲染不同步。** `setInterval` 的回调可能在两次渲染之间执行多次，导致多次修改 DOM 但只有最后一次被渲染出来，浪费 CPU 算力。更糟糕的是，回调也可能恰好在渲染之后执行，导致这次修改要等到下一帧才生效，凭空增加一帧延迟。

**问题三：后台不暂停。** 当用户切换到其他标签页时，`setInterval` 仍然在后台持续执行，白白消耗电池和 CPU 资源。对于移动端用户来说，这是一个严重的体验问题。

### 1.2 requestAnimationFrame 的优势

```javascript
// 推荐
function animate() {
  position += 2
  box.style.transform = `translateX(${position}px)`
  requestAnimationFrame(animate)
}
requestAnimationFrame(animate)
```

rAF 相比 `setInterval` 的核心优势：

| 特性 | setInterval | requestAnimationFrame |
|------|------------|----------------------|
| 同步刷新率 | 不同步 | 自动同步（通常 60fps） |
| 后台标签页 | 持续运行 | 自动暂停 |
| 回调时机 | 不确定 | 渲染前统一调度 |
| 多次调用 | 多个定时器竞争 | 同帧内批量回调 |
| 电池消耗 | 持续消耗 | 智能节能 |
| 返回值 | timer ID（数字） | rAF ID（数字） |

### 1.3 两者执行时机的直观对比

```
setInterval 的情况（不稳定）：
时间轴: |---16ms---|---16ms---|---16ms---|---16ms---|
回调:     cb  cb      cb         cb  cb  cb    cb
渲染:       |             |            |           |
         ↑ 回调和渲染完全脱节，有的帧执行多次，有的帧一次都没有

requestAnimationFrame 的情况（稳定）：
时间轴: |---16.67ms---|---16.67ms---|---16.67ms---|
回调:      cb            cb            cb
渲染:       |              |              |
         ↑ 每帧恰好执行一次，紧贴渲染时机
```

## 二、rAF 基础用法

### 2.1 基本模式与停止

```javascript
let animationId = null

function startAnimation() {
  function loop() {
    update()
    render()
    animationId = requestAnimationFrame(loop)
  }
  animationId = requestAnimationFrame(loop)
}

function stopAnimation() {
  cancelAnimationFrame(animationId)
  animationId = null
}
```

这个模式有三个关键点：

1. **递归调用**：`loop` 函数在每次执行时再次调用 `requestAnimationFrame(loop)`，形成持续的动画循环。
2. **保存 ID**：每次调用 rAF 都会返回一个唯一的 ID，用于后续取消。
3. **取消动画**：`cancelAnimationFrame(id)` 取消下一次回调。如果动画循环已经停止，调用 cancel 是无害的。

### 2.2 回调参数

```javascript
requestAnimationFrame((timestamp) => {
  // timestamp：自页面加载以来的毫秒数，精度为 5 微秒
  console.log(timestamp) // 例如 12345.6789
})
```

`timestamp` 是一个 `DOMHighResTimeStamp`，精度远高于 `Date.now()` 的毫秒级。这个时间戳在同一次回调中所有 rAF 回调共享相同的值，方便多个动画同步。

### 2.3 完整的 HTML 示例

```html
<!DOCTYPE html>
<html lang="zh">
<head>
<style>
  .box {
    width: 60px;
    height: 60px;
    background: #3498db;
    border-radius: 8px;
    position: absolute;
    top: 100px;
    left: 0;
  }
  .controls {
    position: fixed;
    top: 10px;
    left: 10px;
    z-index: 10;
  }
  button {
    padding: 8px 16px;
    margin-right: 8px;
    cursor: pointer;
  }
</style>

  <button id="startBtn">开始</button>
  <button id="stopBtn">停止</button>

```

## 三、基于时间的动画

### 3.1 帧率无关的动画

每帧固定移动 2px，在 30fps 设备上速度只有 60fps 的一半。正确做法是基于 **deltaTime**：

```javascript
let lastTime = 0
const speed = 200 // 每秒 200px
let position = 0

function animate(timestamp) {
  if (lastTime === 0) lastTime = timestamp
  const deltaTime = (timestamp - lastTime) / 1000 // 转换为秒
  lastTime = timestamp

  position += speed * deltaTime
  box.style.transform = `translateX(${position}px)`
  requestAnimationFrame(animate)
}
requestAnimationFrame(animate)
```

**为什么用 deltaTime？** 假设速度是 200px/s：

- 60fps 设备：每帧间隔 ~16.67ms，deltaTime ≈ 0.0167，每帧移动 3.33px
- 30fps 设备：每帧间隔 ~33.33ms，deltaTime ≈ 0.0333，每帧移动 6.67px

两种设备每秒都移动 200px，视觉速度一致。

### 3.2 deltaTime 的陷阱

标签页切换回来时 deltaTime 可能非常大，导致物体"传送"。限制最大值：

```javascript
const clampedDelta = Math.min(deltaTime, 0.1) // 最大 100ms
```

为什么要限制为 100ms？因为标签页切回时，两帧间隔可能是几秒甚至几分钟。如果不做限制，一个速度为 500px/s 的物体会瞬间跳出屏幕。100ms 意味着最大跳变 50px，用户几乎感知不到。

### 3.3 deltaTime 完整示例：多个物体独立运动

```html
<!DOCTYPE html>
<html lang="zh">
<head>
<style>
  body { margin: 0; overflow: hidden; background: #1a1a2e; }
  .particle {
    width: 20px;
    height: 20px;
    border-radius: 50%;
    position: absolute;
    top: 50%;
    left: 0;
  }
</style>
</head>
<body>
<script>
const colors = ['#e74c3c', '#3498db', '#2ecc71', '#f39c12', '#9b59b6']
const particles = colors.map((color, i) => {
  const el = document.createElement('div')
  el.className = 'particle'
  el.style.background = color
  el.style.top = `${100 + i * 80}px`
  document.body.appendChild(el)
  return { el, x: 0, speed: 80 + i * 60 }
})

let lastTime = 0

function animate(timestamp) {
  if (lastTime === 0) lastTime = timestamp
  const deltaTime = Math.min((timestamp - lastTime) / 1000, 0.1)
  lastTime = timestamp

  particles.forEach(p => {
    p.x += p.speed * deltaTime
    if (p.x > window.innerWidth) p.x = -20
    p.el.style.transform = `translateX(${p.x}px)`
  })

  requestAnimationFrame(animate)
}

requestAnimationFrame(animate)
</script>
</body>
</html>
```

每个粒子速度不同，但在任何帧率下它们的相对速度比例都保持不变。

## 四、动画循环封装

### 4.1 基础动画控制器

当页面中有多个动画时，为每个动画单独创建 rAF 循环是浪费的。更好的做法是用一个统一的循环管理所有动画：

```javascript
class AnimationController {
  constructor() {
    this.animations = new Map()
    this.isRunning = false
    this.lastTime = 0
  }

  add(id, updateFn) {
    this.animations.set(id, updateFn)
    if (!this.isRunning) this.start()
  }

  remove(id) {
    this.animations.delete(id)
    if (this.animations.size === 0) this.stop()
  }

  start() {
    this.isRunning = true
    this.lastTime = performance.now()
    this.loop(performance.now())
  }

  stop() {
    this.isRunning = false
    if (this.rafId) { cancelAnimationFrame(this.rafId); this.rafId = null }
  }

  loop = (timestamp) => {
    if (!this.isRunning) return
    const deltaTime = Math.min((timestamp - this.lastTime) / 1000, 0.1)
    this.lastTime = timestamp
    this.animations.forEach(fn => fn(deltaTime))
    this.rafId = requestAnimationFrame(this.loop)
  }
}

// 使用
const controller = new AnimationController()
controller.add('player', dt => { player.x += player.vx * dt })
controller.add('enemy', dt => { enemy.x += enemy.speed * dt })
```

**为什么用一个循环？** 多个 rAF 回调虽然浏览器会在同一帧内批量执行，但它们的 deltaTime 计算可能不一致（因为 performance.now() 的调用时机不同），导致动画同步出问题。统一循环确保所有动画共享同一个 deltaTime。

### 4.2 带暂停的动画循环

```javascript
class PausableAnimation {
  constructor(callback) {
    this.callback = callback
    this.rafId = null
    this.lastTime = 0
    this.paused = false
  }

  start() { this.lastTime = performance.now(); this.paused = false; this.tick(this.lastTime) }

  tick = (timestamp) => {
    if (this.paused) return
    const delta = Math.min((timestamp - this.lastTime) / 1000, 0.1)
    this.lastTime = timestamp
    this.callback(delta)
    this.rafId = requestAnimationFrame(this.tick)
  }

  pause() { this.paused = true; if (this.rafId) { cancelAnimationFrame(this.rafId); this.rafId = null } }
  resume() { if (this.paused) { this.paused = false; this.lastTime = performance.now(); this.tick(this.lastTime) } }
}
```

### 4.3 带完成回调的动画控制器

```javascript
class TimedAnimation {
  constructor(duration, onUpdate, onComplete) {
    this.duration = duration
    this.onUpdate = onUpdate
    this.onComplete = onComplete
    this.startTime = 0
    this.rafId = null
    this.running = false
  }

  start() {
    this.startTime = performance.now()
    this.running = true
    this.tick(this.startTime)
  }

  tick = (timestamp) => {
    if (!this.running) return
    const elapsed = timestamp - this.startTime
    const progress = Math.min(elapsed / this.duration, 1)

    this.onUpdate(progress)

    if (progress < 1) {
      this.rafId = requestAnimationFrame(this.tick)
    } else {
      this.running = false
      if (this.onComplete) this.onComplete()
    }
  }

  cancel() {
    this.running = false
    if (this.rafId) {
      cancelAnimationFrame(this.rafId)
      this.rafId = null
    }
  }
}

// 使用：2 秒内将元素从左移到右
const anim = new TimedAnimation(
  2000,
  (progress) => {
    box.style.transform = `translateX(${progress * 500}px)`
  },
  () => {
    console.log('动画完成')
  }
)
anim.start()
```

## 五、rAF 与渲染管线

```
浏览器一帧的完整流程：
┌─────────────────────────────────────────────────────┐
│  1. 输入事件处理（click、scroll、touch 等）           │
│  2. JavaScript 执行                                  │
│  3. requestAnimationFrame 回调 ← 在这里修改 DOM      │
│  4. Style 计算（解析 CSS，计算最终样式）               │
│  5. Layout（计算元素位置和大小）                       │
│  6. Paint（绘制像素到图层）                            │
│  7. Composite（合并图层，输出到屏幕）                  │
│  8. 屏幕显示                                         │
└─────────────────────────────────────────────────────┘
```

rAF 在渲染前执行，同一帧内的 DOM 修改会一起生效。这意味着如果你在 rAF 中修改了元素的位置和颜色，浏览器会一次性计算样式、布局和绘制，而不会触发两次重排。

### 5.1 rAF vs setTimeout(fn, 0)

```javascript
// 方式 A：用 setTimeout
setTimeout(() => {
  box.style.transform = 'translateX(100px)'
  // 可能已经错过了当前帧的渲染，要等下一帧
}, 0)

// 方式 B：用 rAF
requestAnimationFrame(() => {
  box.style.transform = 'translateX(100px)'
  // 保证在下一帧渲染前执行
})
```

`setTimeout(fn, 0)` 并不会立即执行——它会被放到宏任务队列末尾，可能在渲染之后才执行，导致修改要到再下一帧才可见。rAF 则保证在渲染前执行。

### 5.2 读写分离避免强制同步布局

```javascript
// 错误：在循环中交替读写布局属性
function bad() {
  requestAnimationFrame(() => {
    const height = box.offsetHeight  // 读 → 触发重排
    box.style.height = height + 10 + 'px'  // 写 → 标记脏
    const width = box.offsetWidth  // 读 → 强制重排！
    box.style.width = width + 10 + 'px'  // 写
  })
}

// 正确：先批量读，再批量写
function good() {
  requestAnimationFrame(() => {
    const height = box.offsetHeight  // 读
    const width = box.offsetWidth    // 读
    box.style.height = height + 10 + 'px'  // 写
    box.style.width = width + 10 + 'px'    // 写
  })
}
```

## 六、实用模式

### 6.1 FPS 监控器

```javascript
function createFPSMonitor() {
  const display = document.createElement('div')
  Object.assign(display.style, {
    position: 'fixed',
    top: '10px',
    right: '10px',
    background: 'rgba(0,0,0,0.8)',
    color: '#0f0',
    padding: '8px 12px',
    fontFamily: 'monospace',
    fontSize: '14px',
    borderRadius: '4px',
    zIndex: '9999',
    pointerEvents: 'none'
  })
  document.body.appendChild(display)

  const frameTimes = []
  let lastUpdate = 0

  function tick(timestamp) {
    frameTimes.push(timestamp)
    // 保留最近 1 秒的帧时间
    while (frameTimes.length > 0 && frameTimes[0] < timestamp - 1000) {
      frameTimes.shift()
    }
    // 每 500ms 更新一次显示
    if (timestamp - lastUpdate > 500) {
      const fps = frameTimes.length
      const color = fps >= 55 ? '#0f0' : fps >= 30 ? '#ff0' : '#f00'
      display.textContent = `FPS: ${fps}`
      display.style.color = color
      lastUpdate = timestamp
    }
    requestAnimationFrame(tick)
  }

  requestAnimationFrame(tick)
  return display
}
```

### 6.2 平滑滚动进度条

```javascript
function createScrollProgress() {
  const bar = document.createElement('div')
  Object.assign(bar.style, {
    position: 'fixed',
    top: '0',
    left: '0',
    height: '3px',
    background: 'linear-gradient(90deg, #3498db, #e74c3c)',
    zIndex: '9999',
    transition: 'none',
    pointerEvents: 'none'
  })
  document.body.appendChild(bar)

  let targetPercent = 0
  let currentPercent = 0

  window.addEventListener('scroll', () => {
    const scrollHeight = document.documentElement.scrollHeight - window.innerHeight
    targetPercent = scrollHeight > 0 ? (window.scrollY / scrollHeight) * 100 : 0
  })

  function animate() {
    currentPercent += (targetPercent - currentPercent) * 0.15
    bar.style.width = `${currentPercent}%`
    requestAnimationFrame(animate)
  }

  requestAnimationFrame(animate)
}
```

这个滚动进度条使用了"追赶"模式：每帧当前位置向目标位置靠近 15%，产生平滑的延迟跟随效果，比直接设置 `width` 要流畅得多。

### 6.3 鼠标跟随光标

```javascript
function createFollowerCursor() {
  const cursor = document.createElement('div')
  Object.assign(cursor.style, {
    width: '20px',
    height: '20px',
    borderRadius: '50%',
    background: 'rgba(52, 152, 219, 0.6)',
    position: 'fixed',

    zIndex: '9999',
    transition: 'none'
  })
  document.body.appendChild(cursor)

  let mouseX = 0, mouseY = 0
  let cursorX = 0, cursorY = 0

  document.addEventListener('mousemove', (e) => {
    mouseX = e.clientX
    mouseY = e.clientY
  })

  function animate() {
    cursorX += (mouseX - cursorX) * 0.12
    cursorY += (mouseY - cursorY) * 0.12
    cursor.style.transform = `translate(${cursorX - 10}px, ${cursorY - 10}px)`
    requestAnimationFrame(animate)
  }

  requestAnimationFrame(animate)
}
```

### 6.4 rAF 封装为 Promise

```javascript
function raf() {
  return new Promise(resolve => requestAnimationFrame(resolve))
}

// 使用：等待下一帧
async function fadeIn(element) {
  element.style.opacity = '0'
  element.style.display = 'block'

  await raf() // 等一帧让浏览器应用 opacity: 0
  element.style.transition = 'opacity 0.3s ease'
  element.style.opacity = '1'
}
```

## 常见误区

### 误区一：在 rAF 中执行昂贵计算

16.67ms 预算与渲染共享。如果你在 rAF 回调中执行了一个需要 50ms 的计算（比如大量 DOM 查询或复杂数据处理），就会导致掉帧。重计算应放到 Web Worker：

```javascript
// 错误：在 rAF 中做重计算
function animate() {
  const result = heavyComputation(data) // 阻塞主线程
  render(result)
  requestAnimationFrame(animate)
}

// 正确：用 Worker 处理重计算
const worker = new Worker('compute.js')
worker.postMessage(data)
worker.onmessage = (e) => {
  // 只在 rAF 中做渲染
  requestAnimationFrame(() => render(e.data))
}
```

### 误区二：忘记取消 rAF

组件卸载或动画结束时必须 `cancelAnimationFrame`，否则回调会持续执行，造成内存泄漏：

```javascript
// React 组件中的正确用法
useEffect(() => {
  let animId = null

  function animate() {
    update()
    animId = requestAnimationFrame(animate)
  }
  animId = requestAnimationFrame(animate)

  return () => {
    if (animId) cancelAnimationFrame(animId)
  }
}, [])
```

### 误区三：用 Date.now() 代替 timestamp

rAF 提供的 timestamp 精度更高（5 微秒 vs 1 毫秒），而且在同帧内所有回调共享相同的时间戳，保证动画同步。

```javascript
// 不推荐
let lastTime = Date.now()
function animate() {
  const now = Date.now()
  const dt = now - lastTime  // 精度只有 1ms
  lastTime = now
  // ...
}

// 推荐
let lastTime = 0
function animate(timestamp) {
  if (lastTime === 0) lastTime = timestamp
  const dt = timestamp - lastTime  // 精度 5μs
  lastTime = timestamp
  // ...
}
```

### 误区四：不限制 deltaTime

`Math.min(deltaTime, 0.1)` 防止挂起后恢复的跳变。这是最容易被忽略的细节——开发时可能不会发现问题（因为开发时很少切换标签页），但用户在实际使用中随时可能切走再切回来。

### 误区五：创建多个 rAF 循环

```javascript
// 不推荐：每个动画一个循环
function animatePlayer() {
  player.update()
  requestAnimationFrame(animatePlayer)
}
function animateEnemy() {
  enemy.update()
  requestAnimationFrame(animateEnemy)
}
requestAnimationFrame(animatePlayer)
requestAnimationFrame(animateEnemy)

// 推荐：统一循环
function animate() {
  player.update()
  enemy.update()
  requestAnimationFrame(animate)
}
requestAnimationFrame(animate)
```

## 工程建议

1. **所有 JS 动画都用 rAF**。`setInterval` 不适合做动画。
2. **基于时间计算位移**。`position += speed * deltaTime`，保证不同帧率下表现一致。
3. **限制 deltaTime 上限 100ms**。防止标签页切换后的跳变。
4. **一个 rAF 循环管理所有动画**。避免多个回调竞争和 deltaTime 不一致。
5. **组件生命周期中管理 rAF**。mount 启动，unmount 取消，防止内存泄漏。
6. **批量读布局属性，再批量写样式**。避免强制同步布局。
7. **开发阶段加入 FPS 监控**。及时发现性能瓶颈。
8. **用 `performance.now()` 获取高精度时间**，不要用 `Date.now()`。

## 小结

- rAF 是浏览器专为动画设计的调度 API，与刷新率同步，后台自动暂停
- 基于 deltaTime 的计算确保不同帧率下表现一致
- `Math.min(deltaTime, 0.1)` 防止标签页切换后的跳变
- 一个集中的 rAF 循环比多个分散的更高效，且保证 deltaTime 一致
- rAF 在渲染管线中处于 JS 执行和样式计算之间，是修改 DOM 的最佳时机
- 始终在组件卸载时取消 rAF，防止内存泄漏

### 练习一

**思路**：弹簧动画的核心是胡克定律 `F = -k * x`，其中 `x` 是当前位移。加上阻尼力 `F_d = -d * v` 让振荡逐渐衰减。每帧更新速度和位置，当速度和位移都足够小时停止动画。

```html
function springAnimation(element, targetX, targetY, options = {}) {
  const {
    stiffness = 0.08,
    damping = 0.85,
    threshold = 0.1
  } = options

  let x = 0, y = 0, vx = 0, vy = 0
  let lastTime = 0

  function animate(timestamp) {
    if (lastTime === 0) lastTime = timestamp
    const dt = Math.min((timestamp - lastTime) / 16.67, 3)
    lastTime = timestamp

    const ax = (targetX - x) * stiffness
    const ay = (targetY - y) * stiffness
    vx = (vx + ax) * damping
    vy = (vy + ay) * damping
    x += vx * dt
    y += vy * dt

    element.style.transform = `translate(${x}px, ${y}px)`

    const isSettled =
      Math.abs(vx) < threshold &&
      Math.abs(vy) < threshold &&
      Math.abs(targetX - x) < threshold &&
      Math.abs(targetY - y) < threshold

    if (!isSettled) {
      requestAnimationFrame(animate)
    } else {
      element.style.transform = `translate(${targetX}px, ${targetY}px)`
    }
  }

  requestAnimationFrame(animate)
}

const ball = document.getElementById('ball')
document.addEventListener('click', (e) => {
  springAnimation(ball, e.clientX - 25, e.clientY - 25, {
    stiffness: 0.06,
    damping: 0.88
  })
})
</script>
</body>
</html>
```

**要点**：
- `stiffness` 控制弹簧刚度，值越大回弹越快
- `damping` 控制阻尼，值越小振荡衰减越快（0.8-0.95 为合理范围）
- `dt` 使用 `/16.67` 归一化，使参数在不同帧率下表现一致
- 使用 `Math.min(dt, 3)` 防止 deltaTime 跳变

```html
function createFPSMonitor() {
  const panel = document.getElementById('fpsPanel')
  const fpsValue = panel.querySelector('.fps-value')
  const frameTime = panel.querySelector('.frame-time')
  const minMax = panel.querySelector('.min-max')

  const frameTimes = []
  let lastUpdate = 0
  let minFps = Infinity
  let maxFps = 0
  let visible = true

  panel.addEventListener('click', () => {
    visible = !visible
    panel.classList.toggle('hidden', !visible)
  })

  function tick(timestamp) {
    frameTimes.push(timestamp)

    // 移除超过 1 秒的记录
    while (frameTimes.length > 0 && frameTimes[0] < timestamp - 1000) {
      frameTimes.shift()
    }

    if (timestamp - lastUpdate > 500) {
      const fps = frameTimes.length
      const avgFrameTime = frameTimes.length > 1
        ? ((frameTimes[frameTimes.length - 1] - frameTimes[0]) / (frameTimes.length - 1)).toFixed(1)
        : '--'

      minFps = Math.min(minFps, fps)
      maxFps = Math.max(maxFps, fps)

      const color = fps >= 55 ? '#0f0' : fps >= 30 ? '#ff0' : '#f00'
      fpsValue.textContent = `FPS: ${fps}`
      fpsValue.style.color = color
      frameTime.textContent = `Frame: ${avgFrameTime}ms`
      minMax.textContent = `Min/Max: ${minFps}/${maxFps}`

      lastUpdate = timestamp
    }

    requestAnimationFrame(tick)
  }

  requestAnimationFrame(tick)
}
```

```html
class PausableTimer {
  constructor(totalSeconds, onUpdate, onComplete) {
    this.totalMs = totalSeconds * 1000
    this.elapsedMs = 0
    this.lastTime = 0
    this.rafId = null
    this.paused = true
    this.finished = false
    this.onUpdate = onUpdate
    this.onComplete = onComplete
  }

  start() {
    if (!this.paused || this.finished) return
    this.paused = false
    this.lastTime = performance.now()
    this.tick(this.lastTime)
  }

  tick = (timestamp) => {
    if (this.paused || this.finished) return
    this.elapsedMs += timestamp - this.lastTime
    this.lastTime = timestamp

    const remaining = Math.max(0, this.totalMs - this.elapsedMs)
    const progress = this.elapsedMs / this.totalMs
    this.onUpdate(remaining / 1000, progress)

    if (this.elapsedMs >= this.totalMs) {
      this.finished = true
      this.onUpdate(0, 1)
      if (this.onComplete) this.onComplete()
      return
    }

    this.rafId = requestAnimationFrame(this.tick)
  }

  pause() {
    this.paused = true
    if (this.rafId) {
      cancelAnimationFrame(this.rafId)
      this.rafId = null
    }
  }

  reset() {
    this.pause()
    this.elapsedMs = 0
    this.finished = false
    this.paused = true
    this.onUpdate(this.totalMs / 1000, 0)
  }
}
```

### 练习四

**思路**：在 Canvas 上绘制弹跳球，使用 rAF 驱动动画循环，deltaTime 保证帧率无关。每个球有独立的位置和速度，碰到边界时反转对应方向的速度分量。监听 `resize` 事件更新画布尺寸。

```html
class Ball {
  constructor(x, y, radius, color, speedX, speedY) {
    this.x = x
    this.y = y
    this.radius = radius
    this.color = color
    this.vx = speedX
    this.vy = speedY
  }

  update(dt) {
    this.x += this.vx * dt
    this.y += this.vy * dt

    if (this.x - this.radius < 0) {
      this.x = this.radius
      this.vx = Math.abs(this.vx)
    } else if (this.x + this.radius > canvas.width) {
      this.x = canvas.width - this.radius
      this.vx = -Math.abs(this.vx)
    }

    if (this.y - this.radius < 0) {
      this.y = this.radius
      this.vy = Math.abs(this.vy)
    } else if (this.y + this.radius > canvas.height) {
      this.y = canvas.height - this.radius
      this.vy = -Math.abs(this.vy)
    }
  }

  draw(ctx) {
    ctx.beginPath()
    ctx.arc(this.x, this.y, this.radius, 0, Math.PI * 2)
    ctx.fillStyle = this.color
    ctx.fill()
    ctx.closePath()
  }
}

}
```

- 使用 `Math.min(dt, 0.1)` 防止标签页切换后的跳变
