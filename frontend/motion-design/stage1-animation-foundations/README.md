# Stage 1：动画基础

> 从零理解 Web 动画的底层原理，掌握 CSS 动画和原生 API。

## 本阶段目标

- 理解帧动画、缓动函数、时间轴的核心概念
- 熟练使用 CSS Transition 和 CSS Animation
- 掌握 Web Animations API 和 requestAnimationFrame
- 能独立编写 10 个经典 CSS 动画效果

## 课时列表

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 动画原理 | 帧率、时间管理、缓动函数基础 |
| 02 | CSS Transition 与 Animation | 过渡、关键帧、性能考量 |
| 03 | Web Animations API | WAAPI、Animation 对象、控制 |
| 04 | 请求动画帧 | requestAnimationFrame、时间差计算 |
| 05 | 缓动函数深入 | 贝塞尔曲线、弹性、弹跳缓动 |
| 06 | 阶段实战 | 10 个经典 CSS 动画合集 |

## 学完本阶段你能

- 不再"凭感觉调参"，而是理解每一帧是怎么产生的
- 能用 CSS 写出流畅的过渡和关键帧动画
- 能用 JS 精确控制动画的播放、暂停、反转
- 为后续 GSAP 和 Three.js 学习打下坚实基础
