# 第五课：缓动函数深入——贝塞尔曲线、弹性与弹跳

## 场景引入

第一课中我们初步了解了缓动函数。但真实项目需求远不止于此：你需要一个"果冻般"的弹性效果，或者一个"落地后弹跳"的物理动画，又或者需要精确控制加速减速的曲线形状。本课深入贝塞尔曲线的数学原理，掌握自定义缓动函数的创建方法。

想象你正在做一个抽屉式导航菜单。如果用 `ease-in-out`，菜单滑出来的感觉是"机械的"——均匀加速再减速。但如果你用一个带轻微过冲的缓动，菜单会"弹出来"，给用户一种有机的、有生命力的感觉。缓动函数的选择，直接决定了动画的"气质"。

## 学习目标

- 理解三次贝塞尔曲线的数学原理和几何直觉
- 掌握 `cubic-bezier()` 参数含义和调节技巧
- 学会实现弹性（elastic）和弹跳（bounce）缓动函数
- 了解 `steps()` 缓动的应用场景
- 能够根据动画语义选择合适的缓动函数
- 掌握缓动函数的可视化调试方法

## 一、三次贝塞尔曲线

### 1.1 数学基础

`cubic-bezier(x1, y1, x2, y2)` 定义两个控制点 P1 和 P2：

```
P0 = (0, 0)   起点（动画开始：时间 0，进度 0）
P1 = (x1, y1) 控制点 1（控制起始段的曲率）
P2 = (x2, y2) 控制点 2（控制结束段的曲率）
P3 = (1, 1)   终点（动画结束：时间 1，进度 1）
```

曲线的参数方程：

```javascript
function cubicBezier(t, p1x, p1y, p2x, p2y) {
  const t2 = t * t, t3 = t2 * t
  const mt = 1 - t, mt2 = mt * mt, mt3 = mt2 * mt
  return {
    x: 3 * mt2 * t * p1x + 3 * mt * t2 * p2x + t3,
    y: 3 * mt2 * t * p1y + 3 * mt * t2 * p2y + t3
  }
}
```

**几何直觉**：想象一根绳子被两个磁铁拉扯。P1 在起点附近拉绳子，P2 在终点附近拉绳子。绳子的形状就是缓动曲线。如果 P1 的 y 值小于 0，绳子会被拉到"地下"（产生先倒退再前进的效果）；如果 P2 的 y 值大于 1，绳子会被拉到"天上"（产生过冲效果）。

### 1.2 参数含义

`x1, x2`：控制点 X 坐标，必须在 0-1 之间（控制时间轴）。
`y1, y2`：控制点 Y 坐标，可以超出 0-1（产生过冲效果）。

```css
/* 标准缓动的贝塞尔值 */
ease:        cubic-bezier(0.25, 0.1, 0.25, 1.0)   /* 默认缓动，略微加速再减速 */
ease-in:     cubic-bezier(0.42, 0, 1.0, 1.0)       /* 慢启动，匀速结束 */
ease-out:    cubic-bezier(0, 0, 0.58, 1.0)         /* 匀速启动，慢结束 */
ease-in-out: cubic-bezier(0.42, 0, 0.58, 1.0)     /* 慢启动，慢结束 */
```

**理解 x 和 y 的分工**：
- **x 值**（0-1）控制"时间"——曲线在水平方向的分布。x 越小，该段曲线在水平方向越"压缩"，意味着变化更快。
- **y 值**（可超出 0-1）控制"进度"——曲线在垂直方向的分布。y > 1 表示进度超过 100%（过冲），y < 0 表示进度为负（先倒退）。

### 1.3 自定义贝塞尔曲线

```css
/* 弹性过冲：先略微倒退，再超过目标，最后回来 */
.elastic { transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55); }

/* 快速启动，缓慢结束：像火箭发射 */
.snappy { transition-timing-function: cubic-bezier(0.19, 1, 0.22, 1); }

/* iOS 弹簧：苹果系统常用的缓动 */
.ios-spring { transition-timing-function: cubic-bezier(0.25, 0.46, 0.45, 0.94); }

/* 果冻效果：明显的过冲 */
.jelly { transition-timing-function: cubic-bezier(0.68, -0.6, 0.32, 1.6); }

/* 平滑停止：启动快，结束很平滑 */
.smooth-stop { transition-timing-function: cubic-bezier(0.22, 0.68, 0, 1.0); }
```

推荐使用 [cubic-bezier.com](https://cubic-bezier.com) 可视化调试——拖动控制点可以实时预览效果。

### 1.4 贝塞尔曲线的视觉分类

```
                y
                ↑
            1.5 |        ·P2 (过冲)
                |       /
            1.0 |-----/-------  ← 终点 P3
                |    /
            0.5 |   /
                |  /
            0.0 |--●-----------→ x
                0   0.5   1.0
                P0 (起点)

曲线超过 y=1 时，动画会"冲过头"再回来
曲线低于 y=0 时，动画会"先倒退"再前进
```

**常见的曲线形状与对应效果**：

| 曲线形状 | 贝塞尔值 | 效果描述 |
|---------|---------|---------|
| 直线 | linear (0,0,1,1) | 匀速，无加速减速 |
| 凸形 | ease-out (0,0,0.58,1) | 快启动，慢结束 |
| 凹形 | ease-in (0.42,0,1,1) | 慢启动，快结束 |
| S 形 | ease-in-out (0.42,0,0.58,1) | 慢-快-慢 |
| 过冲 | (0.34,1.56,0.64,1) | 超过目标再回来 |
| 倒退 | (0.68,-0.6,0.32,1) | 先退后进 |

## 二、弹性缓动（Elastic）

弹性动画模拟弹簧效果：物体到达目标后来回振荡，振幅逐渐减小。贝塞尔曲线无法精确表达多次振荡，需要手写。

### 2.1 弹性函数的数学原理

```javascript
function elasticOut(t) {
  const p = 0.3
  return Math.pow(2, -10 * t) * Math.sin((t - p / 4) * (2 * Math.PI) / p) + 1
}

function elasticIn(t) {
  const p = 0.3
  return -Math.pow(2, 10 * (t - 1)) * Math.sin((t - 1 - p / 4) * (2 * Math.PI) / p)
}
```

**分解这个公式**：
- `Math.pow(2, -10 * t)`：指数衰减，控制振幅逐渐减小。t=0 时衰减因子为 1，t=1 时衰减因子约为 0.001。
- `Math.sin(...)`：正弦波，控制来回振荡。周期由 `p` 决定。
- `+ 1`：将曲线整体上移，使终点值为 1。

**参数 p 的作用**：
- `p = 0.3`（默认）：约 3 次振荡
- `p = 0.4`：振荡更慢，约 2.5 次
- `p = 0.2`：振荡更快，约 5 次

### 2.2 用 WAAPI 将弹性函数转为关键帧

贝塞尔曲线无法表达多次振荡，但我们可以将弹性函数的输出采样为关键帧：

```javascript
function animateElastic(element, property, from, to) {
  const keyframes = []
  const steps = 60
  for (let i = 0; i <= steps; i++) {
    const t = i / steps
    const value = from + (to - from) * elasticOut(t)
    keyframes.push({ [property]: `${value}px`, offset: t })
  }
  return element.animate(keyframes, {
    duration: 1000,
    fill: 'forwards',
    easing: 'linear' // 已经在关键帧中编码了缓动
  })
}
```

**为什么用 `easing: 'linear'`？** 因为缓动已经在关键帧值中编码了。如果再加一个非 linear 的 easing，会导致缓动被"叠加"两次，效果不对。

### 2.3 弹性函数的可调参数版本

```javascript
function createElasticOut(amplitude = 1, period = 0.3) {
  return function(t) {
    if (t === 0 || t === 1) return t
    const s = period / (2 * Math.PI) * Math.asin(1 / amplitude)
    return amplitude * Math.pow(2, -10 * t) * Math.sin((t - s) * (2 * Math.PI) / period) + 1
  }
}

// 使用
const gentleElastic = createElasticOut(1, 0.5)   // 轻柔弹性
const strongElastic = createElasticOut(1.5, 0.3) // 强烈弹性
const subtleElastic = createElasticOut(0.5, 0.2) // 微妙弹性
```

## 三、弹跳缓动（Bounce）

弹跳模拟球落地效果：碰到"地面"后反弹，每次反弹高度递减。

### 3.1 弹跳函数的数学原理

```javascript
function bounceOut(t) {
  if (t < 1 / 2.75) return 7.5625 * t * t
  if (t < 2 / 2.75) { t -= 1.5 / 2.75; return 7.5625 * t * t + 0.75 }
  if (t < 2.5 / 2.75) { t -= 2.25 / 2.75; return 7.5625 * t * t + 0.9375 }
  t -= 2.625 / 2.75; return 7.5625 * t * t + 0.984375
}

function bounceIn(t) { return 1 - bounceOut(1 - t) }
```

**7.5625 是怎么来的？** 这个常数由物理约束推导：

弹跳比例 k = 1/2.75 ≈ 0.3636。每次弹跳的最高点在时间轴上的位置是 1/k, 2/k, 2.5/k, 2.625/k。抛物线方程 `y = a * t²` 在每个区间的起点 y=0，终点 y 对应弹跳高度。解方程得到 a = 7.5625。

**四段抛物线的含义**：
1. 第一段（t < 0.364）：球从高处落下，y 从 0 到 1
2. 第二段（t < 0.727）：第一次弹起，y 从 0.75 到 1
3. 第三段（t < 0.909）：第二次弹起，y 从 0.9375 到 1
4. 第四段（t < 1）：最后一次弹起，y 从 0.984375 到 1

### 3.2 弹跳函数的可调参数版本

```javascript
function createBounceOut(bounciness = 3) {
  function bounce(t, n) {
    if (t < 1 / n) return t * t * n * n
    if (t < 2 / n) { t -= 1.5 / n; return t * t * n * n + 0.75 }
    if (t < 2.5 / n) { t -= 2.25 / n; return t * t * n * n + 0.9375 }
    t -= 2.625 / n; return t * t * n * n + 0.984375
  }
  return function(t) { return bounce(t, bounciness) }
}

const gentleBounce = createBounceOut(4)   // 更平缓
const normalBounce = createBounceOut(2.75) // 标准
const sharpBounce = createBounceOut(2)     // 更剧烈
```

## 四、Steps 缓动

`steps()` 将动画分成离散步进，适合精灵图动画和打字机效果。

### 4.1 打字机效果

```css
.typewriter {
  overflow: hidden;
  border-right: 2px solid #333;
  white-space: nowrap;
  width: 0;
  animation: typing 2s steps(13) forwards, blink 0.7s step-end infinite;
}
@keyframes typing { to { width: 13ch; } }
@keyframes blink { 50% { border-color: transparent; } }
```

**steps(13) 的含义**：动画被分成 13 步完成。因为文字有 13 个字符，每步显示一个字符，模拟真实的打字效果。步数必须与字符数匹配，否则会跳过字符或停顿。

### 4.2 精灵图动画

```css
.sprite {
  width: 64px;
  height: 64px;
  background: url('sprite-sheet.png') 0 0;
  animation: spriteWalk 0.8s steps(8) infinite;
}
@keyframes spriteWalk {
  from { background-position: 0 0; }
  to { background-position: -512px 0; }
}
```

精灵图动画的核心思路：一张包含 8 帧的精灵图，宽度 512px（每帧 64px）。用 `steps(8)` 让背景位置每次跳 64px，而不是平滑移动，从而实现逐帧切换。

### 4.3 steps 的跳跃位置

`steps(count, position)` 的第二个参数控制跳跃时机：

| 值 | 含义 | 适用场景 |
|---|------|---------|
| `jump-start` | 起点跳跃，第一帧立即跳到新值 | 不常用 |
| `jump-end` | 终点跳跃（默认） | 精灵图、打字机 |
| `jump-both` | 两端都跳跃 | 需要更"急促"的效果 |
| `jump-none` | 两端都不跳跃 | 两端都需要停留 |

```css
/* 等价写法 */
.steps(4, jump-end)    /* 默认 */
.step-end              /* CSS 简写 */
.steps(4)              /* 省略第二个参数 */
```

## 五、缓动函数组合

### 5.1 CSS 自定义属性存储缓动

```css
:root {
  --ease-snappy: cubic-bezier(0.19, 1, 0.22, 1);
  --ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-smooth: cubic-bezier(0.4, 0, 0.2, 1);
  --ease-elastic: cubic-bezier(0.68, -0.6, 0.32, 1.6);
  --ease-ios: cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
.card { transition: transform 0.3s var(--ease-snappy); }
.modal { transition: opacity 0.3s var(--ease-smooth); }
```

将缓动函数提取为 CSS 自定义属性有两个好处：
1. **统一管理**：修改一处，全局生效
2. **语义化命名**：`var(--ease-snappy)` 比 `cubic-bezier(0.19, 1, 0.22, 1)` 更易读

### 5.2 场景选择指南

```javascript
const easings = {
  // 入场动画：元素进入画面，需要"弹出来"的感觉
  enter: 'cubic-bezier(0.34, 1.56, 0.64, 1)',

  // 出场动画：元素离开画面，需要"快速消失"
  exit: 'cubic-bezier(0.55, 0, 1, 0.45)',

  // 强调动画：吸引注意力，需要明显的过冲
  emphasis: 'cubic-bezier(0.68, -0.6, 0.32, 1.6)',

  // 平滑过渡：无过冲，适合连续变化
  smooth: 'cubic-bezier(0.4, 0, 0.2, 1)',

  // 弹性反馈：用户交互后的响应
  feedback: 'cubic-bezier(0.34, 1.56, 0.64, 1)',

  // 自然减速：模拟摩擦力
  decelerate: 'cubic-bezier(0, 0, 0.2, 1)'
}
```

## 常见误区

### 误区一：弹性动画用贝塞尔曲线模拟

贝塞尔曲线无法表达多次振荡。`cubic-bezier(0.34, 1.56, 0.64, 1)` 只能产生一次过冲，不是真正的弹性效果。如果需要多次振荡（像弹簧一样来回弹），必须手写缓动函数。

### 误区二：y 值超出范围没有意义

`cubic-bezier` 的 y 值可以 < 0 或 > 1，产生过冲效果，这是有意设计的。`y < 0` 让动画先倒退再前进，`y > 1` 让动画超过目标再回来。这是贝塞尔曲线最强大的特性之一。

### 误区三：所有场景都用弹性缓动

弹性动画适合强调性动画（如弹窗出现、按钮点击反馈），不适合表单校验、数据列表等持续性 UI。过度使用弹性动画会让界面感觉"幼稚"和不稳定。

### 误区四：忽略 prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

部分用户对动画敏感（前庭功能障碍），必须提供无动画降级。

### 误区五：缓动函数与动画时长不匹配

弹性缓动需要更长的时长才能看到完整效果。如果给一个 100ms 的弹性动画，用户根本看不到振荡。弹性动画建议 500ms 以上。

## 工程建议

1. **轻度过冲用贝塞尔 y 值**。`y1 = -0.5` 或 `y2 = 1.5` 比手写弹性函数更轻量。
2. **弹性动画控制振荡 2-3 次**。过多振荡让用户不耐烦。
3. **弹跳动画需要明确的"地面"参考面**。没有参照物的弹跳会让人困惑。
4. **配合 `prefers-reduced-motion` 提供无动画降级**。
5. **将常用缓动提取为 CSS 自定义属性**。方便统一管理和主题切换。
6. **使用可视化工具调试缓动**。cubic-bezier.com 是最好的在线工具。
7. **缓动选择要考虑动画语义**：入场用过冲，出场用加速，连续用平滑。
8. **测试不同设备上的表现**。低端设备可能无法流畅运行动画。

## 小结

- 三次贝塞尔曲线通过两个控制点定义缓动，y 值超出 0-1 产生过冲
- 弹性缓动用指数衰减的正弦波模拟弹簧，弹跳用分段抛物线模拟落地
- `steps()` 将动画分为离散步进，适合精灵图和打字机效果
- 缓动选择取决于动画语义：入场、出场、强调、连续
- 将缓动函数提取为 CSS 自定义属性，便于统一管理和语义化引用
- 始终考虑 `prefers-reduced-motion` 无障碍需求

```html
    ball.style.transform = `translateX(-50%)`

    // 阴影：球越高阴影越小
    const heightRatio = 1 - (currentY - startY) / (groundY - startY)
    const shadowScale = 0.5 + heightRatio * 0.5
    shadow.style.transform = `translateX(-50%) scaleX(${shadowScale})`
    shadow.style.opacity = 0.3 + heightRatio * 0.4

    if (progress < 1) {
      requestAnimationFrame(step)
    }
  }

  ball.style.top = `${startY}px`
  requestAnimationFrame(step)
})
</script>
</body>
</html>
```

**要点**：
- bounceOut 自然模拟了球落地弹跳的效果，不需要手写物理公式
- 阴影的 `scaleX` 和 `opacity` 随球的高度线性变化，增强立体感
- 球的高度越高，阴影越小越淡；球落地时阴影最大最深
