# 第六课：阶段实战 — 品牌官网动效系统

## 场景引入

你接到一个真实项目：为科技品牌设计官网动效。首页需要冲击力入场动画，产品展示需要滚动交互，关于我们需要时间线叙事，整个网站需要统一的动效语言。

这不是 demo，是生产环境项目。你需要考虑：动效与 React 集成、页面切换处理、移动端降级、60fps 流畅度。

为什么需要"动效系统"而不是"散落的动画代码"？因为：
- 散落的代码会导致不同区域的动画风格不一致（有的快有的慢，有的用 ease 这个有的用那个）
- 没有统一管理层，动画冲突和内存泄漏难以排查
- 移动端降级、减弱动效偏好等全局策略无法统一执行

## 学习目标

- 学会规划和设计网站动效体系
- 掌握多组件的 GSAP 动画架构
- 理解动效系统的工程化：复用、降级、性能
- 能独立实现一个完整的品牌官网动效方案

### 为什么需要独立的 motion 目录

将动效逻辑从组件中抽离有几个好处：
- 组件只关心"是什么"，动效层关心"怎么动"
- 动效逻辑可以跨组件复用（多个组件用同一个 useScrollReveal）
- 测试时可以单独 mock 动效层
- 未来替换动画库时只需改 motion 目录

## 三、插件注册与全局配置

```javascript
// motion/registerPlugins.ts
import { gsap } from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"
import { SplitText } from "gsap/SplitText"
import { TextPlugin } from "gsap/TextPlugin"
import { MotionPathPlugin } from "gsap/MotionPathPlugin"

export function registerGSAPPlugins() {
  gsap.registerPlugin(ScrollTrigger, SplitText, TextPlugin, MotionPathPlugin)
  gsap.defaults({ ease: "power3.out", duration: 0.6 })
  gsap.ticker.lagSmoothing(0)
}
```

`gsap.ticker.lagSmoothing(0)` 的作用：默认情况下 GSAP 会在浏览器标签页切换回来时"平滑"跳过丢失的帧，这可能导致动画卡顿。设置为 0 可以禁用这个行为，让动画立即恢复。

### 减弱动效偏好检测

```javascript
// motion/utils/prefersReducedMotion.ts
export function getReducedMotionPreference() {
  return window.matchMedia("(prefers-reduced-motion: reduce)").matches
}

export function withReducedMotionSupport(animationFn) {
  if (getReducedMotionPreference()) return gsap.timeline()
  return animationFn()
}
```

### 动效级别检测

根据设备能力分级配置动效参数：

```javascript
// motion/utils/motionLevel.ts
export type MotionLevel = "none" | "minimal" | "reduced" | "full"

export function getMotionLevel(): MotionLevel {
  if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
    return "none"
  }
  if (navigator.hardwareConcurrency && navigator.hardwareConcurrency <= 2) {
    return "minimal"
  }
  if (window.innerWidth < 768) {
    return "reduced"
  }
  return "full"
}

export const motionPresets: Record<MotionLevel, {
  stagger: number
  duration: number
  enableParticles: boolean
  enableParallax: boolean
}> = {
  none: { stagger: 0, duration: 0, enableParticles: false, enableParallax: false },
  minimal: { stagger: 0.05, duration: 0.4, enableParticles: false, enableParallax: false },
  reduced: { stagger: 0.03, duration: 0.5, enableParticles: false, enableParallax: true },
  full: { stagger: 0.02, duration: 0.8, enableParticles: true, enableParallax: true }
}
```

## 四、可复用的动画 Hooks

### useScrollReveal

```javascript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"

gsap.registerPlugin(ScrollTrigger)

export function useScrollReveal(options = {}) {
  const ref = useRef(null)
  const {
    y = 50, opacity = 0, duration = 0.8,
    stagger = 0.1, start = "top 75%", selector = ".reveal-item"
  } = options

  useGSAP(() => {
    gsap.from(selector, {
      y, opacity, duration, stagger,
      scrollTrigger: {
        trigger: ref.current, start,
        toggleActions: "play none none reverse"
      }
    })
  }, { scope: ref })

  return ref
}
```

### useTextReveal

```javascript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { SplitText } from "gsap/SplitText"

gsap.registerPlugin(SplitText)

export function useTextReveal(options = {}) {
  const ref = useRef(null)
  const {
    type = "chars", from = { y: 40, opacity: 0 },
    stagger = 0.03, duration = 0.8, ease = "back.out(1.7)"
  } = options

  useGSAP(() => {
    const split = new SplitText(ref.current, { type })
    const targets = type === "chars" ? split.chars
      : type === "words" ? split.words : split.lines

    gsap.from(targets, { ...from, stagger, duration, ease })
  }, { scope: ref })

  return ref
}
```

### useCountUp

```javascript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"

gsap.registerPlugin(ScrollTrigger)

export function useCountUp(target: number, format = "number") {
  const ref = useRef(null)

  const formatters: Record<string, (v: number) => string> = {
    number: (v) => Math.round(v).toLocaleString(),
    currency: (v) => "¥" + Math.round(v).toLocaleString(),
    percent: (v) => Math.round(v) + "%"
  }

  useGSAP(() => {
    const obj = { value: 0 }
    gsap.to(obj, {
      value: target,
      duration: 2,
      ease: "power1.out",
      scrollTrigger: {
        trigger: ref.current,
        start: "top 80%"
      },
      onUpdate: () => {
        if (ref.current) {
          ref.current.textContent = formatters[format](obj.value)
        }
      }
    })
  }, { scope: ref })

  return ref
}
```

## 五、Hero 区域 — 冲击力入场

Hero 是用户看到的第一个区域，入场动画决定了第一印象。设计原则：快速、有冲击力、不让人等待。

```javascript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { SplitText } from "gsap/SplitText"

gsap.registerPlugin(SplitText)

function Hero() {
  const heroRef = useRef(null)

  useGSAP(() => {
    const tl = gsap.timeline({ defaults: { ease: "power3.out" } })

    // 背景先入场，建立空间感
    tl.from(".hero-bg", { scale: 1.1, opacity: 0, duration: 1.5 })

    // 主标题逐字弹入
    const titleSplit = new SplitText(".hero-title", { type: "chars" })
    tl.from(titleSplit.chars, {
      y: 80, opacity: 0, rotationX: -60,
      stagger: { each: 0.03, from: "center" }, duration: 1
    }, "-=1")

    // 副标题逐行擦除
    const subSplit = new SplitText(".hero-subtitle", {
      type: "lines", linesClass: "subtitle-line"
    })
    gsap.set(".subtitle-line", { overflow: "hidden" })
    tl.from(subSplit.lines, { y: "100%", stagger: 0.1, duration: 0.7 }, "-=0.5")

    // CTA 弹入
    tl.from(".hero-cta", { scale: 0, ease: "back.out(1.7)", duration: 0.6 }, "-=0.3")
  }, { scope: heroRef })

  return (
    <section ref={heroRef} className="hero">
      <div className="hero-bg" />
      <h1 className="hero-title">重新定义数字体验</h1>
      <p className="hero-subtitle">用科技连接未来，用设计感动人心</p>
      <button className="hero-cta">开始探索</button>
    </section>
  )
}
```

### Hero 动画的时序设计

```
时间轴：
0.0s  背景开始缩放淡入（1.5s）
0.5s  标题开始逐字弹入（1s）
1.0s  副标题开始擦除（0.7s）
1.2s  CTA 弹入（0.6s）
1.8s  所有动画完成
```

总时长控制在 2 秒以内。用户注意力窗口很短，超过 2 秒的入场动画会被视为"卡顿"。

## 七、关于我们 — 时间线叙事

时间线叙事是"关于我们"页面的经典模式——用滚动驱动时间线，逐个展示里程碑：

```javascript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"

gsap.registerPlugin(ScrollTrigger)

function AboutTimeline() {
  const sectionRef = useRef(null)

  useGSAP(() => {
    const milestones = gsap.utils.toArray(".milestone")

    const tl = gsap.timeline({
      scrollTrigger: {
        trigger: sectionRef.current,
        start: "top top",
        end: `+=${milestones.length * 800}`,
        pin: true,
        scrub: 1,
        snap: {
          snapTo: 1 / (milestones.length - 1),
          duration: { min: 0.2, max: 0.5 }
        }
      }
    })

    milestones.forEach((milestone, i) => {
      const year = milestone.querySelector(".year")
      const content = milestone.querySelector(".content")

      if (i > 0) {
        tl.to(milestones[i - 1], { opacity: 0, y: -30, duration: 0.3 })

      tl.from(year, { x: -50, opacity: 0, duration: 0.5 })
        .from(content, { y: 30, opacity: 0, duration: 0.5 }, "<")
        .addLabel(`year-${i}`)
    })
  }, { scope: sectionRef })

  return (
    <section ref={sectionRef} className="about">
      <div className="timeline-container">
        <div className="timeline-line" />
        <div className="milestone">
          <span className="year">2018</span>
          <div className="content">
```

### snap 的作用

`snap` 让滚动在每个里程碑位置"吸附"，避免停在两个里程碑之间的尴尬位置：

```javascript
snap: {

  duration: { min: 0.2, max: 0.5 },    // 吸附动画时长

  ease: "power2.inOut"                  // 吸附缓动
```

## 九、性能优化与移动端降级

### 性能优化核心原则

```javascript
// 1. 只用 transform 和 opacity，避免触发重排
gsap.to(".box", { x: 100, opacity: 0.5 }) // ✅
gsap.to(".box", { width: 200, left: 100 }) // ❌

// 2. 大量元素用 batch 替代 stagger
ScrollTrigger.batch(".item", {
  onEnter: (els) => gsap.from(els, { y: 30, stagger: 0.02 })
})

// 3. 及时销毁 ScrollTrigger
useGSAP(() => {
  // useGSAP 会在组件卸载时自动清理
}, { scope: ref })

// 4. 避免在高频事件中触发动画
window.addEventListener("scroll", () => {
  // 不要在这里创建新动画
  // 用 ScrollTrigger 的回调代替
})
```

### 移动端降级策略

```javascript
function getMotionLevel() {
  if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) return "none"
  if (navigator.hardwareConcurrency <= 2) return "minimal"
  if (window.innerWidth < 768) return "reduced"
  return "full"
}

// 根据级别调整动画参数
function getAnimationConfig() {
  const level = getMotionLevel()
  const configs = {
    none: { stagger: 0, duration: 0, enableSplit: false },
    minimal: { stagger: 0.05, duration: 0.3, enableSplit: false },
    reduced: { stagger: 0.03, duration: 0.5, enableSplit: true },
    full: { stagger: 0.02, duration: 0.8, enableSplit: true }
  }
  return configs[level]
}
```

## 常见误区

1. **一开始就写代码**：先规划再实现，列出所有动效的位置和时序关系。没有规划的动效系统会变成"动效垃圾场"。

2. **每个组件独立管理动画**：应该有统一的动效管理层，避免冲突和重复。两个组件同时操作同一个元素会导致不可预测的行为。

3. **忽略减弱动效偏好**：`prefers-reduced-motion` 对有前庭功能障碍的用户是必需的。这不只是"nice to have"，是可访问性要求。

4. **不在真机上测试**：桌面端流畅的动画在低端手机上可能卡顿。Chrome DevTools 的 CPU 节流只能模拟，不能完全代表真机表现。

5. **ScrollTrigger 不刷新**：动态加载内容后，ScrollTrigger 的位置计算会过时。需要调用 `ScrollTrigger.refresh()`。

6. **Timeline 嵌套过深**：超过 3 层嵌套的 Timeline 难以维护和调试。建议拆分成多个独立的 Timeline。

7. **忘记处理页面离开**：用户快速滚动跳过某个区域时，`toggleActions: "play none none reverse"` 会正确处理进入和离开，但如果你用了 `once: true`，离开后再次进入不会重新播放。

## 工程建议

1. **建立动效设计系统**：统一时长、缓动、间距规范。建议维护一个 `motion-tokens` 配置文件。

2. **用配置驱动动画**：参数抽离到配置文件，方便设计师调整。设计师不需要看代码就能修改动效参数。

3. **分层加载动效**：首屏优先，非首屏延迟初始化。用 `IntersectionObserver` 延迟初始化不可见区域的动画。

4. **监控动画性能**：在开发环境中用 `gsap.ticker` 监控帧率：

```javascript
gsap.ticker.add(() => {
  const fps = gsap.ticker.deltaRatio()
  if (fps < 0.8) { // 低于约 48fps
    console.warn("Animation performance degraded:", fps)
  }
})
```

5. **为动效写文档**：记录每个区域的动效设计意图，方便团队成员理解和维护。

## 小结

一个专业的动效系统不是把 GSAP 代码散落在各组件里，而是有统一的架构：先规划再实现（配置中心）、复用动画逻辑（Hooks）、处理边界情况（减弱动效、移动端降级）、保证性能（只用 transform/opacity、批量处理、及时销毁）。

动效系统的核心价值：让动效成为产品的有机组成部分，而不是"锦上添花"的附加品。

### 练习一

**思路**：每个预设是函数，返回 GSAP 动画配置。用 `Partial` 类型让所有参数可选。

**答案**：

```typescript
import { gsap } from "gsap"

interface MotionPreset {
  from: gsap.TweenVars
  stagger?: number
  duration?: number
  ease?: string
}

type PresetOverrides = Partial<MotionPreset>

export const presets = {
  fadeIn(overrides: PresetOverrides = {}): MotionPreset {
    return { from: { opacity: 0 }, duration: 0.6, ease: "power2.out", ...overrides }
  },
  slideUp(overrides: PresetOverrides = {}): MotionPreset {
    return { from: { y: 50, opacity: 0 }, duration: 0.7, ease: "power3.out", ...overrides }
  },
  scaleIn(overrides: PresetOverrides = {}): MotionPreset {
    return { from: { scale: 0.8, opacity: 0 }, duration: 0.5, ease: "back.out(1.7)", ...overrides }
  },
  wipeReveal(overrides: PresetOverrides = {}): MotionPreset {
    return { from: { y: "100%", opacity: 0 }, duration: 0.8, ease: "power3.out", ...overrides }
  },
  staggerChildren(overrides: PresetOverrides = {}): MotionPreset {
    return { from: { y: 30, opacity: 0 }, stagger: 0.1, duration: 0.6, ease: "power2.out", ...overrides }
  }
}

// 使用示例
function applyPreset(selector: string, presetName: keyof typeof presets) {
  const config = presets[presetName]()
  gsap.from(selector, {
    ...config.from,
    stagger: config.stagger,
    duration: config.duration,
    ease: config.ease
  })
}
```

**要点**：
- `Partial<MotionPreset>` 让所有参数可选，用户只需传想覆盖的参数
- 展开运算符 `...overrides` 实现参数合并
- 每个预设函数既可独立使用，也可被 Hook 调用

### 练习二

**思路**：每区域独立 `useGSAP`，`useReducedMotion` 检测偏好，减弱时用 `gsap.set()` 设最终状态。

**答案**：

```typescript
import { useRef } from "react"
import { useGSAP } from "@gsap/react"
import gsap from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"
import { SplitText } from "gsap/SplitText"

gsap.registerPlugin(ScrollTrigger, SplitText)

function useReducedMotion() {
  return window.matchMedia("(prefers-reduced-motion: reduce)").matches
}

function Hero() {
  const ref = useRef(null)
  const reduced = useReducedMotion()

  useGSAP(() => {
    if (reduced) {
      gsap.set(".hero-title, .hero-subtitle, .hero-cta", { opacity: 1, y: 0 })
      return
    }
    const tl = gsap.timeline()
    const split = new SplitText(".hero-title", { type: "chars" })
    tl.from(split.chars, {
      y: 80, opacity: 0,
      stagger: { each: 0.03, from: "center" },
      duration: 1
    })
    .from(".hero-subtitle", { y: 30, opacity: 0, duration: 0.6 }, "-=0.5")
    .from(".hero-cta", { scale: 0, ease: "back.out(1.7)", duration: 0.5 }, "-=0.2")
  }, { scope: ref })

  return (
    <section ref={ref} className="hero">
      <h1 className="hero-title">重新定义数字体验</h1>
      <p className="hero-subtitle">用科技连接未来</p>
      <button className="hero-cta">开始探索</button>
    </section>
  )
}

function Features() {
  const ref = useRef(null)
  const reduced = useReducedMotion()

  useGSAP(() => {
    if (reduced) return

      y: 50, opacity: 0, stagger: 0.12,
      scrollTrigger: {
        trigger: ref.current,

  return (
    <section ref={ref} className="features">

    </section>

  const ref = useRef(null)
  const reduced = useReducedMotion()

  useGSAP(() => {
    if (reduced) return
    document.querySelectorAll(".stat-num").forEach(el => {
```

### 练习三

**思路**：用 ScrollTrigger 的 `onUpdate` 回调获取滚动进度，映射到 `scaleX`。颜色渐变用 CSS 变量或 `onUpdate` 中动态设置。

**答案**：

```javascript
import { gsap } from "gsap"
import { ScrollTrigger } from "gsap/ScrollTrigger"

gsap.registerPlugin(ScrollTrigger)

function createScrollProgress() {
  const prefersReducedMotion = window.matchMedia(
    "(prefers-reduced-motion: reduce)"
  ).matches

  // 创建进度条 DOM
  const bar = document.createElement("div")
  bar.className = "scroll-progress"
  document.body.prepend(bar)

  // CSS
  Object.assign(bar.style, {
    position: "fixed",
    top: 0,
    left: 0,
    width: "100%",
    height: "4px",
    transformOrigin: "left center",
    transform: "scaleX(0)",
    zIndex: 9999,
    background: "linear-gradient(90deg, #3b82f6, #8b5cf6)",
    willChange: "transform"
  })

  if (prefersReducedMotion) {
    // 减弱模式：直接绑定，无过渡
    ScrollTrigger.create({
      trigger: document.body,
      start: "top top",
      end: "bottom bottom",
      onUpdate: (self) => {
        bar.style.transform = `scaleX(${self.progress})`
      }
    })
  } else {
    // 正常模式：平滑跟随
    const progressObj = { value: 0 }

    ScrollTrigger.create({
      trigger: document.body,
      start: "top top",
      end: "bottom bottom",
      onUpdate: (self) => {
        gsap.to(progressObj, {
          value: self.progress,
          duration: 0.3,
          ease: "power2.out",
          onUpdate: () => {
            bar.style.transform = `scaleX(${progressObj.value})`
          }
        })
      }
    })
  }
}

createScrollProgress()
```

**要点**：
- `transform: scaleX()` 是合成属性，不会触发重排，性能最优
- `transformOrigin: "left center"` 让进度条从左向右增长
- 减弱动效偏好时跳过平滑过渡，直接设置最终值
- `willChange: "transform"` 提示浏览器优化

### 练习四

**思路**：创建全屏加载层，Timeline 编排 Logo 和加载指示器动画，页面 load 事件后播放退出动画。

**答案**：

```javascript
import { gsap } from "gsap"

function createLoadingAnimation() {
  // 创建加载层 DOM
  const loader = document.createElement("div")
  loader.className = "page-loader"
  loader.innerHTML = `
    <div class="loader-logo">NEXUS</div>
    <div class="loader-pulse"></div>
  `
  document.body.prepend(loader)

  // CSS
  const style = document.createElement("style")
  style.textContent = `
    .page-loader {
      position: fixed;
      inset: 0;
      z-index: 10000;
      display: flex;
      flex-direction: column;
      align-items: center;
      justify-content: center;
      background: #0f172a;
    }
    .loader-logo {
      font-size: 3rem;
      font-weight: 800;
      color: white;
      letter-spacing: 0.2em;
    }
    .loader-pulse {
      width: 40px;
      height: 4px;
      margin-top: 2rem;
      border-radius: 2px;
      background: #3b82f6;
    }
  `
  document.head.appendChild(style)

  // 入场动画
  const enterTl = gsap.timeline()
  enterTl
    .from(".loader-logo", {
      scale: 0.5,
      opacity: 0,
      duration: 0.6,
      ease: "back.out(1.7)"
    })
    .to(".loader-pulse", {
      scaleX: 2,
      opacity: 0.3,
      repeat: -1,
      yoyo: true,
      duration: 0.6,
      ease: "power2.inOut"
    }, "-=0.3")

  // 页面加载完成后退出
  function onLoaded() {
    // 停止脉冲动画
    gsap.killTweensOf(".loader-pulse")

    const exitTl = gsap.timeline({
      onComplete: () => loader.remove()
    })

    exitTl
      .to(".loader-logo", {
        y: -30,
        opacity: 0,
        duration: 0.4,
        ease: "power3.in"
      })
      .to(loader, {
        yPercent: -100,
        duration: 0.6,
        ease: "power3.inOut"
      }, "-=0.2")
  }

  if (document.readyState === "complete") {
    setTimeout(onLoaded, 800) // 至少显示 0.8 秒
  } else {
    window.addEventListener("load", () => setTimeout(onLoaded, 800))
  }
}

createLoadingAnimation()
```

**要点**：
- 入场和退出用两个独立 Timeline，避免时序混乱
- `onComplete: () => loader.remove()` 确保动画结束后移除 DOM
- `setTimeout(onLoaded, 800)` 保证加载画面至少显示 0.8 秒，避免闪烁
- 脉冲动画用 `repeat: -1` + `yoyo` 实现循环呼吸效果
