# 阶段实战：品牌官网动效

## 项目目标

用 GSAP + ScrollTrigger 为一个品牌着陆页添加完整的动效系统：导航入场、Hero 区域动画、功能卡片滚动揭示、数据指标数字滚动、视差背景、页面过渡。

这不是 demo，是可以直接用在生产项目里的动效方案。

## 技术栈

- GSAP 3（核心动画）
- ScrollTrigger（滚动驱动）
- 原生 HTML/CSS/JS

## 导航入场

页面加载后导航从上方滑入：

```javascript
gsap.from('.nav', {
  y: -80, opacity: 0, duration: 0.8, ease: 'power2.out',
})
```

## Hero 区域时间线

标题、副标题、按钮依次入场，用 Timeline 编排：

```javascript
const heroTL = gsap.timeline({ defaults: { ease: 'power2.out' } })

heroTL
  .from('.hero-title', { y: 60, opacity: 0, duration: 0.8 })
  .from('.hero-subtitle', { y: 40, opacity: 0, duration: 0.6 }, '-=0.3')
  .from('.cta-btn', { y: 30, opacity: 0, scale: 0.9, duration: 0.5 }, '-=0.2')
```

`'-=0.3'` 表示比正常时间点提前 0.3 秒开始，产生重叠效果。

## 功能卡片滚动揭示

每张卡片进入视口时从下方滑入：

```javascript
gsap.from('.feature-card', {
  scrollTrigger: {
    trigger: '.features',
    start: 'top 80%',
    toggleActions: 'play none none none',
  },
  y: 60, opacity: 0, duration: 0.6,
  stagger: 0.15, ease: 'power2.out',
})
```

`start: 'top 80%'` = 当 `.features` 顶部到达视口 80% 位置时触发。

## 数据指标数字滚动

```javascript
function animateCounters() {
  document.querySelectorAll('.stat-number').forEach(el => {
    const target = parseInt(el.dataset.target)
    gsap.to(el, {
      textContent: target,
      duration: 2,
      ease: 'power1.out',
      snap: { textContent: 1 },
      scrollTrigger: {
        trigger: el,
        start: 'top 85%',
        once: true,
      },
    })
  })
}
```

`snap: { textContent: 1 }` 让数字只取整数。

## 视差背景

背景图片滚动速度比内容慢：

```javascript
gsap.to('.parallax-bg', {
  yPercent: 30,
  ease: 'none',
  scrollTrigger: {
    trigger: '.parallax-section',
    start: 'top bottom',
    end: 'bottom top',
    scrub: true,
  },
})
```

`scrub: true` 让动画进度和滚动位置绑定。`yPercent: 30` 背景向下移动 30%。

## 进度条

页面滚动时顶部显示阅读进度：

```javascript
gsap.to('.progress-bar', {
  scaleX: 1, ease: 'none',
  scrollTrigger: {
    trigger: 'body',
    start: 'top top',
    end: 'bottom bottom',
    scrub: 0.3,
  },
})
```

```css
.progress-bar {

  background: #3b82f6;
  transform-origin: left;
  transform: scaleX(0);
  z-index: 100;
}
```

## 按钮悬停动画

```javascript
const btn = document.querySelector('.cta-btn')
btn.addEventListener('mouseenter', () => {
  gsap.to(btn, { scale: 1.05, duration: 0.2, ease: 'power2.out' })
})
btn.addEventListener('mouseleave', () => {
  gsap.to(btn, { scale: 1, duration: 0.3, ease: 'back.out(1.7)' })
})
```

## 无障碍

```javascript
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)')
if (prefersReducedMotion.matches) {
  gsap.globalTimeline.timeScale(20) // 加速到几乎瞬间完成
}
```

## 练习

### 练习一：完整着陆页

实现完整的品牌着陆页：导航 + Hero + 3 个功能卡片 + 3 个数据指标 + 视差区域 + 进度条。所有动画用 GSAP + ScrollTrigger。

### 练习二：滚动驱动时间线

用 `scrub` 实现一个"故事线"：5 个步骤水平排列，滚动时当前步骤高亮，其他步骤变暗。步骤之间有连接线逐步绘制。

### 练习三：页面过渡

点击导航链接时，当前页面淡出 + 向上滑出，新页面淡入 + 从下方滑入。用 GSAP timeline 编排。

## 参考答案

### 练习一

```javascript
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
gsap.registerPlugin(ScrollTrigger)

// 导航
gsap.from('.nav', { y: -80, opacity: 0, duration: 0.8, ease: 'power2.out' })

// Hero
const heroTL = gsap.timeline({ defaults: { ease: 'power2.out' } })
heroTL.from('.hero-title', { y: 60, opacity: 0, duration: 0.8 })
  .from('.hero-subtitle', { y: 40, opacity: 0, duration: 0.6 }, '-=0.3')
  .from('.cta-btn', { y: 30, opacity: 0, scale: 0.9, duration: 0.5 }, '-=0.2')

// 功能卡片
gsap.from('.feature-card', {
  scrollTrigger: { trigger: '.features', start: 'top 80%' },
  y: 60, opacity: 0, duration: 0.6, stagger: 0.15, ease: 'power2.out',
})

// 数字
document.querySelectorAll('.stat-number').forEach(el => {
  gsap.to(el, {
    textContent: parseInt(el.dataset.target), duration: 2, ease: 'power1.out',
    snap: { textContent: 1 },
    scrollTrigger: { trigger: el, start: 'top 85%', once: true },
  })
})

// 视差
gsap.to('.parallax-bg', {
  yPercent: 30, ease: 'none',
  scrollTrigger: { trigger: '.parallax-section', start: 'top bottom', end: 'bottom top', scrub: true },
})

// 进度条
gsap.to('.progress-bar', {
  scaleX: 1, ease: 'none',
  scrollTrigger: { trigger: 'body', start: 'top top', end: 'bottom bottom', scrub: 0.3 },
})
```
