# Stage 3：GSAP 大师课

> 掌握业界最流行的动画库 GSAP，实现专业级 Web 动效。

## 本阶段目标

- 深入理解 GSAP 核心 API 和 Timeline 系统
- 精通 ScrollTrigger 滚动触发动画
- 掌握 GSAP 在 React 中的正确用法
- 实现文字动画和路径动画

## 课时列表

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | GSAP 核心 API | gsap.to/from/fromTo、Timeline、Stagger |
| 02 | ScrollTrigger | 滚动触发、pinning、scrub |
| 03 | GSAP 与 React | useGSAP hook、清理、性能优化 |
| 04 | Text 动画 | SplitText、打字机、逐字动画 |
| 05 | MotionPath | 路径动画、曲线运动 |
| 06 | 阶段实战 | 完整品牌官网动效开发 |

## 学完本阶段你能

- 用 GSAP Timeline 编排复杂的多步动画
- 用 ScrollTrigger 实现滚动驱动的沉浸式体验
- 在 React 项目中正确使用 GSAP（避免内存泄漏）
- 实现专业级的文字动画和路径动画
