# 毕业项目：创意动效作品集网站

## 项目概述

构建一个完整的创意动效作品集网站，综合运用本课程所学的全部技术：CSS 动画、GSAP、Three.js、滚动驱动动画、页面过渡、音频可视化等。

## 项目目标

1. 展示至少 5 种不同类型的动效技术
2. 全站 60fps 流畅运行
3. 响应式设计，移动端适配
4. 性能降级策略（低端设备自动简化动效）

## 技术栈

- **构建工具**：Vite
- **框架**：React 18+ / Vue 3（任选）
- **动画库**：GSAP 3 + ScrollTrigger
- **3D**：Three.js（可选）
- **样式**：Tailwind CSS / CSS Modules
- **部署**：Vercel / Netlify

## 页面结构

### 1. 首页 Hero
- 品牌 Logo 动画（SVG path 动画 + 文字拆分）
- 粒子背景（Canvas / Three.js）
- 滚动引导动画

### 2. 作品展示区
- 网格布局 + 悬浮交互
- 点击展开详情（页面过渡动画）
- 图片懒加载 + 渐入动画

### 3. 关于页面
- 时间轴动画（ScrollTrigger 驱动）
- 技能雷达图（数据可视化动画）

### 4. 联系页
- 表单交互动效
- 音频可视化彩蛋（可选）

## 验收标准

运行 `node scripts/check.cjs` 验证以下项目：

### 基础检查（必须通过）
- [ ] 项目目录结构完整
- [ ] package.json 存在且包含必要依赖
- [ ] 所有页面文件存在
- [ ] 无 TypeScript 编译错误

### 动效检查（必须通过）
- [ ] 至少包含 5 种不同类型的动画
- [ ] GSAP Timeline 正确使用
- [ ] ScrollTrigger 配置合理
- [ ] 存在性能降级逻辑

### 质量检查
- [ ] 代码无 console.log 残留
- [ ] 图片资源经过优化
- [ ] 移动端响应式正常

## 提交要求

| 维度 | 权重 | 说明 |
