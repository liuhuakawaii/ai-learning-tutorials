# 物理动画：Cannon.js、Rapier 与刚体模拟

## 场景引入

上节课我们用关键帧和骨骼驱动动画，所有运动都是预设的。但现实中，物体的运动遵循物理规律——球会受重力下落，碰撞后会反弹，堆叠的箱子会倒塌。如果这些效果全靠手动 K 帧，工作量巨大且效果不真实。

物理引擎解决了这个问题：我们定义物体的质量、形状、材质属性，物理引擎负责计算每帧的位置和旋转。Three.js 负责渲染，物理引擎负责运动，两者通过同步 transform 数据协作。

## 学习目标

1. 理解物理引擎在 3D 动画中的角色和工作流程
2. 掌握 Cannon.js 的刚体创建、碰撞检测、约束系统
3. 了解 Rapier 的高性能特性和与 Cannon.js 的差异
4. 掌握物理引擎与 Three.js 的同步策略
5. 能够实现弹簧、铰链、车辆等复杂物理约束
6. 理解碰撞检测的两阶段流程及其对性能的影响

## 物理引擎工作流程

```
每帧循环：
  1. 物理引擎 step() 计算新的位置/旋转
  2. 将物理引擎的 transform 同步到 Three.js 物体
  3. Three.js 渲染
```

核心原则：物理引擎是唯一的运动真相来源，Three.js 只负责"画"。

## 碰撞检测：两阶段管线

物理引擎的碰撞检测分为两个阶段，理解它们对性能调优至关重要。

### Broadphase（粗筛阶段）

想象你在一间有 1000 个人的房间里，要找出谁在互相接触。逐一检查每两个人是否碰到了，需要检查 1000 × 999 / 2 = 499500 次，这太慢了。

Broadphase 的思路是：先用一个简单的包围盒（AABB）快速排除明显不可能碰撞的物体对。就像你站在房间的一角，只需要关注附近的人，不需要检查对面墙角的人。

常见的 Broadphase 算法：

| 算法 | 原理 | 适用场景 |
|------|------|---------|
| NaiveBroadphase | 暴力检查所有物体对 | < 50 个物体 |
| SAPBroadphase | 扫描排序法，沿三个轴排序 AABB | 中等规模，物体分布均匀 |
| GridBroadphase | 空间网格划分 | 大量物体且分布较均匀 |

**SAPBroadphase**（Sweep and Prune）的工作原理：把每个物体的 AABB 投影到 x、y、z 三条轴上，对投影区间排序，只有当两个物体在三条轴上的投影都重叠时，才进入下一阶段。排序可以用增量插入排序，因为每帧物体位置变化不大，排序近乎 O(n)。

```javascript
// Cannon.js 中切换 Broadphase
world.broadphase = new CANNON.SAPBroadphase(world)

// 设置 Broadphase 的世界边界（可选优化）
world.broadphase.aabbMin.set(-50, -50, -50)
world.broadphase.aabbMax.set(50, 50, 50)
```

### Narrowphase（精筛阶段）

Broadphase 筛出"可能碰撞"的物体对后，Narrowphase 做精确的几何相交测试。这一步会计算具体的碰撞点、碰撞法线、穿透深度，这些信息用于后续的碰撞响应（弹开、摩擦等）。

不同碰撞体形状的 Narrowphase 复杂度差异巨大：

```
球 vs 球：    距离比较，O(1)
球 vs 盒子：  最近点计算，O(1)
盒子 vs 盒子：SAT 算法，O(n) 其中 n 是面数
凸体 vs 凸体：GJK/EPA 算法，O(n+m)
Trimesh vs 任意：遍历三角面，O(n) 且 n 通常很大
```

这就是为什么黄金法则是"用最简单的碰撞体"——不仅 Broadphase 排除快，Narrowphase 计算也快。

## Cannon.js 基础

```javascript
import * as THREE from 'three'
import * as CANNON from 'cannon-es'

const world = new CANNON.World()
world.gravity.set(0, -9.82, 0)
world.broadphase = new CANNON.SAPBroadphase(world)
world.solver.iterations = 10
world.allowSleep = true

const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(45, innerWidth / innerHeight, 0.1, 100)
camera.position.set(0, 5, 10)
const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(innerWidth, innerHeight)
document.body.appendChild(renderer.domElement)

const groundBody = new CANNON.Body({ mass: 0, shape: new CANNON.Plane() })
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0)
world.addBody(groundBody)

const groundMesh = new THREE.Mesh(
  new THREE.PlaneGeometry(20, 20),
  new THREE.MeshStandardMaterial({ color: 0x808080 })
)
groundMesh.rotation.x = -Math.PI / 2; scene.add(groundMesh)

const sphereBody = new CANNON.Body({
  mass: 1, shape: new CANNON.Sphere(0.5), position: new CANNON.Vec3(0, 5, 0)
})
world.addBody(sphereBody)

const sphereMesh = new THREE.Mesh(
  new THREE.SphereGeometry(0.5, 32, 32),
  new THREE.MeshStandardMaterial({ color: 0xe74c3c })
)
scene.add(sphereMesh)

const clock = new THREE.Clock()
function animate() {
  requestAnimationFrame(animate)
  world.step(1 / 60, clock.getDelta(), 3)
  sphereMesh.position.copy(sphereBody.position)
  sphereMesh.quaternion.copy(sphereBody.quaternion)
  renderer.render(scene, camera)
}
animate()
```

## 碰撞体形状选择

| 形状 | 性能 | 适用场景 |
|------|------|---------|
| Sphere | 最快 | 球类、弹珠 |
| Box | 快 | 箱子、建筑 |
| Cylinder | 中等 | 罐子、柱子 |
| ConvexPolyhedron | 较慢 | 不规则凸物体 |
| Trimesh | 最慢 | 静态地形 |

**黄金法则**：用最简单的形状能解决问题就不用复杂的。球体碰撞检测比三角网格快 100 倍以上。

### Compound Shape（复合碰撞体）

当物体形状不规则但又不想用 Trimesh 时，可以用多个简单形状组合：

```javascript
const carBody = new CANNON.Body({ mass: 150 })
// 车身主体用盒子
carBody.addShape(
  new CANNON.Box(new CANNON.Vec3(1, 0.3, 2)),
  new CANNON.Vec3(0, 0.3, 0)
)
// 车顶用较小的盒子
carBody.addShape(
  new CANNON.Box(new CANNON.Vec3(0.8, 0.3, 1)),
  new CANNON.Vec3(0, 0.9, -0.2)
)
world.addBody(carBody)
```

Compound Shape 在 Narrowphase 中会依次检测每个子形状，比单个 ConvexPolyhedron 更高效。

## 材质与碰撞响应

```javascript
const groundMaterial = new CANNON.Material('ground')
const ballMaterial = new CANNON.Material('ball')

// 定义两种材质接触时的物理属性
const contactMaterial = new CANNON.ContactMaterial(groundMaterial, ballMaterial, {
  friction: 0.4,        // 摩擦系数：0 无摩擦，值越大越难滑动
  restitution: 0.6,     // 弹性系数：0 完全不弹，1 完全弹性碰撞
  contactEquationStiffness: 1e8,      // 接触方程刚度
  contactEquationRelaxation: 3        // 接触方程松弛度
})
world.addContactMaterial(contactMaterial)

// 给物体指定材质
const groundBody = new CANNON.Body({
  mass: 0,
  shape: new CANNON.Plane(),
  material: groundMaterial
})

const sphereBody = new CANNON.Body({
  mass: 1,
  shape: new CANNON.Sphere(0.5),
  material: ballMaterial
})
```

`restitution` 控制弹性系数：0 完全不弹，1 完全弹性碰撞。实际物理世界中几乎没有完美弹性碰撞，一般设置在 0.1~0.7 之间。篮球约 0.6，网球约 0.75，铅球约 0.1。

## 约束系统详解

约束（Constraint）限制两个刚体之间的相对运动。物理引擎通过约束求解器在每帧迭代中逐步修正违反约束的状态。

### 铰链约束（HingeConstraint）

铰链约束像门的合页，只允许绕一个轴旋转：

```javascript
// 创建门板
const doorBody = new CANNON.Body({
  mass: 5,
  shape: new CANNON.Box(new CANNON.Vec3(0.05, 1, 0.5)),
  position: new CANNON.Vec3(0, 1, 0)
})
world.addBody(doorBody)

// 门框（静态）
const frameBody = new CANNON.Body({ mass: 0, position: new CANNON.Vec3(-0.5, 1, 0) })
world.addBody(frameBody)

// 铰链约束：门的一侧边缘连接到门框
const hinge = new CANNON.HingeConstraint(doorBody, frameBody, {
  pivotA: new CANNON.Vec3(-0.5, 0, 0),  // 门体上的连接点（左侧边缘）
  pivotB: new CANNON.Vec3(0, 0, 0),      // 门框上的连接点
  axisA: new CANNON.Vec3(0, 1, 0),       // 旋转轴：垂直方向
  axisB: new CANNON.Vec3(0, 1, 0)
})
world.addConstraint(hinge)

// 可选：设置铰链的转动限制
hinge.setMotorSpeed(0)          // 无电机驱动
// hinge.enableMotor()           // 启用电机可自动关门
// hinge.setMotorSpeed(-1)       // 负速度 = 自动关闭
```

### 距离约束（DistanceConstraint）

保持两个物体之间的距离不变，像一根刚性杆：

```javascript
const bodyA = new CANNON.Body({ mass: 1, position: new CANNON.Vec3(0, 5, 0) })
const bodyB = new CANNON.Body({ mass: 1, position: new CANNON.Vec3(2, 5, 0) })
world.addBody(bodyA)
world.addBody(bodyB)

// 保持 2 米距离
const distConstraint = new CANNON.DistanceConstraint(bodyA, bodyB, 2)
world.addConstraint(distConstraint)
```

### 弹簧约束（Spring）

弹簧约束在两个物体之间施加弹性力，距离越远力越大。这在 Cannon.js 中通过 `Spring` 实现：

```javascript
const anchorBody = new CANNON.Body({ mass: 0, position: new CANNON.Vec3(0, 8, 0) })
const weightBody = new CANNON.Body({
  mass: 2,
  shape: new CANNON.Sphere(0.3),
  position: new CANNON.Vec3(0, 4, 0)
})
world.addBody(anchorBody)
world.addBody(weightBody)

const spring = new CANNON.Spring(anchorBody, weightBody, {
  restLength: 3,           // 自然长度
  stiffness: 50,           // 弹簧刚度（越大越硬）
  damping: 1,              // 阻尼（越大振荡衰减越快）
  localAnchorA: new CANNON.Vec3(0, 0, 0),  // 锚点在 bodyA 上的局部坐标
  localAnchorB: new CANNON.Vec3(0, 0, 0)   // 锚点在 bodyB 上的局部坐标
})

// Spring 不是约束，需要在每帧手动应用力
world.addEventListener('preStep', () => {
  spring.applyForce()
})
```

弹簧的视觉表现可以用一条动态更新的曲线：

```javascript
const springCurve = new THREE.CatmullRomCurve3([
  anchorBody.position.clone(),
  weightBody.position.clone()
])
const springLine = new THREE.Line(
  new THREE.BufferGeometry().setFromPoints(springCurve.getPoints(30)),
  new THREE.LineBasicMaterial({ color: 0x00ff00 })
)
scene.add(springLine)

// 每帧更新弹簧线段
function updateSpringVisual() {
  const points = [
    new THREE.Vector3().copy(anchorBody.position),
    new THREE.Vector3().copy(weightBody.position)
  ]
  springLine.geometry.setFromPoints(points)
}
```

### 锁定约束（LockConstraint）

完全锁定两个物体的相对位置和旋转，相当于把它们焊在一起：

```javascript
const boxA = new CANNON.Body({ mass: 1, shape: new CANNON.Box(new CANNON.Vec3(0.5, 0.5, 0.5)) })
const boxB = new CANNON.Body({ mass: 1, shape: new CANNON.Box(new CANNON.Vec3(0.5, 0.5, 0.5)), position: new CANNON.Vec3(1, 0, 0) })
world.addBody(boxA)
world.addBody(boxB)

// 锁定两个盒子的相对变换
const lockConstraint = new CANNON.LockConstraint(boxA, boxB)
world.addConstraint(lockConstraint)
```

LockConstraint 适合组装复杂物体——比如把多个简单形状锁定成一个机器人。

### 点对点约束（PointToPointConstraint）

允许两个物体绕连接点自由旋转，像一个球形关节：

```javascript
const ballBody = new CANNON.Body({ mass: 1, shape: new CANNON.Sphere(0.3) })
const ropeAnchor = new CANNON.Body({ mass: 0, position: new CANNON.Vec3(0, 8, 0) })
world.addBody(ballBody)
world.addBody(ropeAnchor)

const p2p = new CANNON.PointToPointConstraint(
  ballBody,
  new CANNON.Vec3(0, 0.3, 0),   // 球体上的连接点
  ropeAnchor,
  new CANNON.Vec3(0, 0, 0)       // 锚点上的连接点
)
world.addConstraint(p2p)
```

PointToPointConstraint 可以实现吊灯、秋千、吊桥等效果。

## 车辆物理

Cannon.js 内置了 `RaycastVehicle`，通过射线检测模拟车轮与地面的接触：

```javascript
const chassisBody = new CANNON.Body({
  mass: 150,
  shape: new CANNON.Box(new CANNON.Vec3(1, 0.3, 2)),
  position: new CANNON.Vec3(0, 2, 0)
})
world.addBody(chassisBody)

const vehicle = new CANNON.RaycastVehicle({
  chassisBody,
  indexRightAxis: 0,
  indexUpAxis: 1,
  indexForwardAxis: 2
})

// 车轮配置
const wheelOptions = {
  radius: 0.3,
  directionLocal: new CANNON.Vec3(0, -1, 0),
  suspensionStiffness: 30,
  suspensionRestLength: 0.3,
  frictionSlip: 1.4,
  dampingRelaxation: 2.3,
  dampingCompression: 4.4,
  maxSuspensionForce: 100000,
  rollInfluence: 0.01,
  axleLocal: new CANNON.Vec3(-1, 0, 0),
  chassisConnectionPointLocal: new CANNON.Vec3(0, 0, 0),
  maxSuspensionTravel: 0.3,
  customSlidingRotationalSpeed: -30,
  useCustomSlidingRotationalSpeed: true
}

// 四个车轮的位置
const wheelPositions = [
  new CANNON.Vec3(-0.8, -0.1, 1),    // 左前
  new CANNON.Vec3(0.8, -0.1, 1),     // 右前
  new CANNON.Vec3(-0.8, -0.1, -1),   // 左后
  new CANNON.Vec3(0.8, -0.1, -1)     // 右后
]

wheelPositions.forEach(pos => {
  wheelOptions.chassisConnectionPointLocal = pos
  vehicle.addWheel(wheelOptions)
})

vehicle.addToWorld(world)

// 为每个车轮创建物理轮体
const wheelBodies = vehicle.wheelInfos.map(wheel => {
  const body = new CANNON.Body({ mass: 0, type: CANNON.Body.KINEMATIC })
  const shape = new CANNON.Cylinder(wheel.radius, wheel.radius, 0.2, 20)
  body.addShape(shape, new CANNON.Vec3(), new CANNON.Quaternion().setFromEuler(0, 0, -Math.PI / 2))
  world.addBody(body)
  return body
})

// 键盘控制
const controls = { forward: false, backward: false, left: false, right: false }
document.addEventListener('keydown', e => {
  if (e.code === 'KeyW') controls.forward = true
  if (e.code === 'KeyS') controls.backward = true
  if (e.code === 'KeyA') controls.left = true
  if (e.code === 'KeyD') controls.right = true
})
document.addEventListener('keyup', e => {
  if (e.code === 'KeyW') controls.forward = false
  if (e.code === 'KeyS') controls.backward = false
  if (e.code === 'KeyA') controls.left = false
  if (e.code === 'KeyD') controls.right = false
})

// 每帧更新车辆
function updateVehicle() {
  const engineForce = 500
  const brakeForce = 50
  const steerAngle = 0.3

  // 后轮驱动
  if (controls.forward) {
    vehicle.applyEngineForce(engineForce, 2)
    vehicle.applyEngineForce(engineForce, 3)
  } else if (controls.backward) {
    vehicle.applyEngineForce(-engineForce * 0.5, 2)
    vehicle.applyEngineForce(-engineForce * 0.5, 3)
  } else {
    vehicle.applyEngineForce(0, 2)
    vehicle.applyEngineForce(0, 3)
  }

  // 前轮转向
  if (controls.left) {
    vehicle.setSteeringValue(steerAngle, 0)
    vehicle.setSteeringValue(steerAngle, 1)
  } else if (controls.right) {
    vehicle.setSteeringValue(-steerAngle, 0)
    vehicle.setSteeringValue(-steerAngle, 1)
  } else {
    vehicle.setSteeringValue(0, 0)
    vehicle.setSteeringValue(0, 1)
  }

  // 同步车轮 mesh
  for (let i = 0; i < vehicle.wheelInfos.length; i++) {
    vehicle.updateWheelTransform(i)
    const t = vehicle.wheelInfos[i].worldTransform
    wheelBodies[i].position.copy(t.position)
    wheelBodies[i].quaternion.copy(t.quaternion)
  }
}
```

## 布娃娃物理（Ragdoll）

布娃娃用多个刚体模拟人体各部位，通过约束连接，让角色在摔倒、受击时产生自然的物理反应：

```javascript
function createRagdoll(world, position) {
  const bodies = {}
  const constraints = []

  // 头部
  bodies.head = new CANNON.Body({
    mass: 4,
    shape: new CANNON.Sphere(0.15),
    position: new CANNON.Vec3(position.x, position.y + 1.6, position.z)
  })

  // 躯干
  bodies.torso = new CANNON.Body({
    mass: 15,
    shape: new CANNON.Cylinder(0.15, 0.15, 0.6, 8),
    position: new CANNON.Vec3(position.x, position.y + 1.1, position.z)
  })

  // 上臂
  bodies.upperArmL = new CANNON.Body({
    mass: 3,
    shape: new CANNON.Cylinder(0.06, 0.06, 0.3, 6),
    position: new CANNON.Vec3(position.x - 0.3, position.y + 1.2, position.z)
  })
  bodies.upperArmR = new CANNON.Body({
    mass: 3,
    shape: new CANNON.Cylinder(0.06, 0.06, 0.3, 6),
    position: new CANNON.Vec3(position.x + 0.3, position.y + 1.2, position.z)
  })

  // 前臂
  bodies.lowerArmL = new CANNON.Body({
    mass: 2,
    shape: new CANNON.Cylinder(0.05, 0.05, 0.3, 6),
    position: new CANNON.Vec3(position.x - 0.3, position.y + 0.85, position.z)
  })
  bodies.lowerArmR = new CANNON.Body({
    mass: 2,
    shape: new CANNON.Cylinder(0.05, 0.05, 0.3, 6),
    position: new CANNON.Vec3(position.x + 0.3, position.y + 0.85, position.z)
  })

  // 大腿
  bodies.upperLegL = new CANNON.Body({
    mass: 8,
    shape: new CANNON.Cylinder(0.08, 0.08, 0.4, 6),
    position: new CANNON.Vec3(position.x - 0.1, position.y + 0.5, position.z)
  })
  bodies.upperLegR = new CANNON.Body({
    mass: 8,
    shape: new CANNON.Cylinder(0.08, 0.08, 0.4, 6),
    position: new CANNON.Vec3(position.x + 0.1, position.y + 0.5, position.z)
  })

  // 小腿
  bodies.lowerLegL = new CANNON.Body({
    mass: 5,
    shape: new CANNON.Cylinder(0.06, 0.06, 0.4, 6),
    position: new CANNON.Vec3(position.x - 0.1, position.y + 0.1, position.z)
  })
  bodies.lowerLegR = new CANNON.Body({
    mass: 5,
    shape: new CANNON.Cylinder(0.06, 0.06, 0.4, 6),
    position: new CANNON.Vec3(position.x + 0.1, position.y + 0.1, position.z)
  })

  Object.values(bodies).forEach(b => {
    b.linearDamping = 0.2
    b.angularDamping = 0.5
    world.addBody(b)
  })

  // 连接约束：头 -> 躯干
  constraints.push(new CANNON.ConeTwistConstraint(bodies.head, bodies.torso, {
    pivotA: new CANNON.Vec3(0, -0.15, 0),
    pivotB: new CANNON.Vec3(0, 0.3, 0),
    axisA: new CANNON.Vec3(0, 1, 0),
    axisB: new CANNON.Vec3(0, 1, 0),
    angle: Math.PI / 6,    // 最大倾斜角度
    twistAngle: Math.PI / 8 // 最大扭转角度
  }))

  // 躯干 -> 上臂
  constraints.push(new CANNON.ConeTwistConstraint(bodies.torso, bodies.upperArmL, {
    pivotA: new CANNON.Vec3(-0.2, 0.25, 0),
    pivotB: new CANNON.Vec3(0, 0.15, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0),
    angle: Math.PI / 3
  }))

  constraints.push(new CANNON.ConeTwistConstraint(bodies.torso, bodies.upperArmR, {
    pivotA: new CANNON.Vec3(0.2, 0.25, 0),
    pivotB: new CANNON.Vec3(0, 0.15, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0),
    angle: Math.PI / 3
  }))

  // 上臂 -> 前臂
  constraints.push(new CANNON.HingeConstraint(bodies.upperArmL, bodies.lowerArmL, {
    pivotA: new CANNON.Vec3(0, -0.15, 0),
    pivotB: new CANNON.Vec3(0, 0.15, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0)
  }))

  constraints.push(new CANNON.HingeConstraint(bodies.upperArmR, bodies.lowerArmR, {
    pivotA: new CANNON.Vec3(0, -0.15, 0),
    pivotB: new CANNON.Vec3(0, 0.15, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0)
  }))

  // 躯干 -> 大腿
  constraints.push(new CANNON.ConeTwistConstraint(bodies.torso, bodies.upperLegL, {
    pivotA: new CANNON.Vec3(-0.1, -0.3, 0),
    pivotB: new CANNON.Vec3(0, 0.2, 0),
    axisA: new CANNON.Vec3(0, 1, 0),
    axisB: new CANNON.Vec3(0, 1, 0),
    angle: Math.PI / 4
  }))

  constraints.push(new CANNON.ConeTwistConstraint(bodies.torso, bodies.upperLegR, {
    pivotA: new CANNON.Vec3(0.1, -0.3, 0),
    pivotB: new CANNON.Vec3(0, 0.2, 0),
    axisA: new CANNON.Vec3(0, 1, 0),
    axisB: new CANNON.Vec3(0, 1, 0),
    angle: Math.PI / 4
  }))

  // 大腿 -> 小腿
  constraints.push(new CANNON.HingeConstraint(bodies.upperLegL, bodies.lowerLegL, {
    pivotA: new CANNON.Vec3(0, -0.2, 0),
    pivotB: new CANNON.Vec3(0, 0.2, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0)
  }))

  constraints.push(new CANNON.HingeConstraint(bodies.upperLegR, bodies.lowerLegR, {
    pivotA: new CANNON.Vec3(0, -0.2, 0),
    pivotB: new CANNON.Vec3(0, 0.2, 0),
    axisA: new CANNON.Vec3(1, 0, 0),
    axisB: new CANNON.Vec3(1, 0, 0)
  }))

  constraints.forEach(c => world.addConstraint(c))

  return { bodies, constraints }
}
```

### 基础同步：逐物体复制

### 批量同步：TypedArray 直写

当物体数量很多时，逐个 copy 的开销不可忽略。更高效的方式是直接写入 mesh 的 matrixWorld：

```javascript
function syncPhysicsBatch(physicsBodies, meshes) {
  for (let i = 0; i < physicsBodies.length; i++) {
    const body = physicsBodies[i]
    const mesh = meshes[i]
    mesh.position.copy(body.position)
    mesh.quaternion.copy(body.quaternion)
    mesh.updateMatrix()

```

### 插值同步：平滑渲染

物理步长（通常 1/60s）和渲染帧率不一定匹配。插值可以让渲染更平滑：

```javascript
class PhysicsInterpolator {
  constructor() {
    this.prevTransform = new Map()
    this.currTransform = new Map()
  }

  saveState(physicsMap) {
    for (const [mesh, body] of physicsMap) {
      const prev = this.currTransform.get(mesh)
      if (prev) this.prevTransform.set(mesh, { ...prev })
      this.currTransform.set(mesh, {
        position: body.position.clone(),
        quaternion: body.quaternion.clone()
      })
    }
  }

  apply(mesh, alpha) {
    const prev = this.prevTransform.get(mesh)
    const curr = this.currTransform.get(mesh)
    if (!prev || !curr) return

    mesh.position.lerpVectors(prev.position, curr.position, alpha)
    mesh.quaternion.slerpQuaternions(prev.quaternion, curr.quaternion, alpha)
  }
}
```

### 对象池管理

频繁创建和销毁刚体会产生内存碎片和 GC 压力。使用对象池：

```javascript
class PhysicsPool {
  constructor(world, maxCount) {
    this.world = world
    this.pool = []
    this.active = []

    for (let i = 0; i < maxCount; i++) {
      const body = new CANNON.Body({ mass: 1, shape: new CANNON.Sphere(0.3) })
      body.sleep()
      world.addBody(body)
      this.pool.push(body)
    }
  }

  spawn(position, velocity) {
    const body = this.pool.pop()
    if (!body) return null
    body.position.copy(position)
    body.velocity.copy(velocity)
    body.wakeUp()
    this.active.push(body)
    return body
  }

  recycle(body) {
    body.sleep()
    body.velocity.set(0, 0, 0)
    body.angularVelocity.set(0, 0, 0)
    const idx = this.active.indexOf(body)
    if (idx > -1) this.active.splice(idx, 1)
    this.pool.push(body)
  }

  recycleAll() {
    while (this.active.length > 0) {
      this.recycle(this.active[0])
    }
  }
}
```

### 帧率自适应步长

当渲染帧率下降时，物理模拟不应跳帧：

```javascript
const fixedTimeStep = 1 / 60
let accumulator = 0

function animate() {
  requestAnimationFrame(animate)
  const delta = clock.getDelta()

  accumulator += delta
  while (accumulator >= fixedTimeStep) {
    world.step(fixedTimeStep)
    accumulator -= fixedTimeStep
  }

  const alpha = accumulator / fixedTimeStep
  syncPhysicsWithInterpolation(physicsMap, alpha)
  renderer.render(scene, camera)
}
```

## 常见误区

1. **物理步长与渲染帧率耦合**：使用固定步长 `world.step(1/60)` 而非动态 delta。动态 delta 会导致模拟不稳定，尤其在帧率波动时物体可能穿透。

2. **大量刚体使用 NaiveBroadphase**：应切换为 `SAPBroadphase`，性能提升 5-10 倍。NaiveBroadphase 对 N 个物体做 O(N²) 检查，SAP 仅对重叠区间做检查。

3. **Trimesh 作为动态刚体**：Trimesh 只适用于静态物体。动态 Trimesh 的碰撞法线计算不可靠，会导致物体穿透或飞出。

4. **忘记设置 damping**：没有阻尼的物体会永远旋转和滑动。`linearDamping` 和 `angularDamping` 一般设在 0.1~0.5。

5. **同步时直接赋值而非 copy**：`mesh.position = body.position` 是引用而非复制，会导致 mesh 和物理 body 共享同一个向量，产生不可预测的行为。

6. **约束迭代次数不足**：复杂约束链（如布娃娃）需要更多 solver iterations。默认 10 次对简单场景够用，但布娃娃可能需要 20~30 次。

7. **物理世界没有边界检测**：物体飞出视野后继续消耗计算资源。应定期检查物体位置，超出边界时移除或回收。

8. **在碰撞回调中直接修改物理世界**：在 `collide` 事件中 `removeBody` 可能导致求解器状态不一致。应标记待删除物体，在下一帧开始前统一处理。

## 工程建议

1. **维护 physicsMap** 存储 Three.js mesh 与物理 body 的对应关系。用 `Map` 或 `WeakMap` 都可以，`WeakMap` 允许 mesh 被 GC 时自动清理。

2. **使用 sleeping 优化**：静止超过阈值的刚体自动休眠，跳过模拟计算。大量堆叠物体场景下效果显著，可节省 50%+ 的物理计算。

3. **碰撞分组使用 bit mask**：`collisionFilterGroup` 和 `collisionFilterMask` 控制哪些物体之间需要检测碰撞。UI 层的碰撞体和游戏物理层应该在不同组。

4. **移动端降低 solver iterations**：默认 10 次可降至 3-5 次，同时增大 damping 值补偿精度损失。

5. **调试时启用碰撞体可视化**：用线框 mesh 匹配碰撞体形状，帮助发现穿透、悬浮、尺寸不匹配等问题。Three.js 的 `BoxHelper` 和 `WireframeGeometry` 可以辅助。

6. **物理更新和渲染分离到不同调度**：物理用 `setInterval` 固定频率，渲染用 `requestAnimationFrame`。两者解耦后，即使渲染掉帧，物理模拟仍然稳定。

7. **使用 Web Worker 运行物理引擎**：Rapier 原生支持 WASM + Worker，物理计算完全不阻塞主线程渲染。这是实现复杂场景 60fps 的关键手段。

8. **对大量同类物体使用实例化渲染**：物理 body 独立，但 Three.js mesh 用 `InstancedMesh` 批量渲染，减少 draw call。每帧更新 `instanceMatrix`。

## 小结

物理动画的核心是将运动计算交给物理引擎，Three.js 只负责渲染。Cannon.js 适合简单场景和快速原型，Rapier 适合大量刚体的高性能需求。掌握刚体、碰撞体、约束三大概念，就能实现从简单坠落到复杂机械联动的物理动画效果。

碰撞检测的 Broadphase/Narrowphase 两阶段管线是性能调优的基础——选择合适的碰撞体形状和 Broadphase 算法，比任何微优化都有效。

```javascript
  setTimeout(() => { pyramidBodies.forEach((b, i) => { if (b.velocity.length() < 0.1) { world.removeBody(b); scene.remove(pyramidMeshes[i]) } }) }, 5000)
  dragStart = null
})
```

**要点**：
- 鼠标拖拽的 dx/dy 映射为球的发射方向和力度
- 箱子堆叠时每层间距加 0.01 避免初始穿透
- `setTimeout` 延迟移除时需要判断速度阈值，避免移除仍在运动的箱子
- 球的质量设为 2（比箱子重），撞击效果更明显

### 练习三

**思路**：用 Cannon.js 的 Spring 实现弹性力，`preStep` 事件中每帧应用弹簧力。鼠标交互用 `pointerdown`/`pointermove`/`pointerup` 实现拖拽释放。

**答案**：

```javascript
const anchorBody = new CANNON.Body({ mass: 0, position: new CANNON.Vec3(0, 8, 0) })
world.addBody(anchorBody)

const ballBody = new CANNON.Body({
  mass: 3,
  shape: new CANNON.Sphere(0.4),
  position: new CANNON.Vec3(0, 4, 0),
  linearDamping: 0.05
})
world.addBody(ballBody)

const spring = new CANNON.Spring(anchorBody, ballBody, {
  restLength: 3,
  stiffness: 80,
  damping: 2,
  localAnchorA: new CANNON.Vec3(0, 0, 0),
  localAnchorB: new CANNON.Vec3(0, 0, 0)
})

world.addEventListener('preStep', () => { spring.applyForce() })

// 锚点可视化
const anchorMesh = new THREE.Mesh(
  new THREE.SphereGeometry(0.15, 16, 16),
  new THREE.MeshStandardMaterial({ color: 0x333333 })
)
anchorMesh.position.copy(anchorBody.position)
scene.add(anchorMesh)

// 球体可视化
const ballMesh = new THREE.Mesh(
  new THREE.SphereGeometry(0.4, 32, 32),
  new THREE.MeshStandardMaterial({ color: 0x3498db })
)
scene.add(ballMesh)

// 弹簧线段可视化
const springMaterial = new THREE.LineBasicMaterial({ color: 0x00ff00, linewidth: 2 })
const springGeometry = new THREE.BufferGeometry()
const springLine = new THREE.Line(springGeometry, springMaterial)
scene.add(springLine)

// 鼠标拖拽交互
const raycaster = new THREE.Raycaster()
const mouse = new THREE.Vector2()
let isDragging = false
let dragPlane = new THREE.Plane(new THREE.Vector3(0, 0, 1), 0)

renderer.domElement.addEventListener('pointerdown', (e) => {
  mouse.x = (e.clientX / innerWidth) * 2 - 1
  mouse.y = -(e.clientY / innerHeight) * 2 + 1
  raycaster.setFromCamera(mouse, camera)
  const intersects = raycaster.intersectObject(ballMesh)
  if (intersects.length > 0) {
    isDragging = true
    ballBody.mass = 0
    ballBody.updateMassProperties()
    ballBody.velocity.set(0, 0, 0)
  }
})

renderer.domElement.addEventListener('pointermove', (e) => {
  if (!isDragging) return
  mouse.x = (e.clientX / innerWidth) * 2 - 1
  mouse.y = -(e.clientY / innerHeight) * 2 + 1
  raycaster.setFromCamera(mouse, camera)
  const intersection = new THREE.Vector3()
  raycaster.ray.intersectPlane(dragPlane, intersection)
  if (intersection) {
    ballBody.position.set(intersection.x, intersection.y, intersection.z)
  }
})

renderer.domElement.addEventListener('pointerup', () => {
  if (!isDragging) return
  isDragging = false
  ballBody.mass = 3
  ballBody.updateMassProperties()
})

// 渲染循环
function animate() {
  requestAnimationFrame(animate)
  world.step(1 / 60, clock.getDelta(), 3)

  ballMesh.position.copy(ballBody.position)
  ballMesh.quaternion.copy(ballBody.quaternion)

  // 更新弹簧线段
  const points = [
    new THREE.Vector3().copy(anchorBody.position),
    new THREE.Vector3().copy(ballBody.position)
  ]
  springGeometry.setFromPoints(points)

  renderer.render(scene, camera)
}
animate()
```

**要点**：
- Spring 必须在 `preStep` 中手动调用 `applyForce()`，它不是自动生效的约束
- 拖拽时将 mass 设为 0 使其变成静态，释放时恢复质量
- `updateMassProperties()` 在修改 mass 后必须调用，否则惯性张量不会更新
- damping 设为 2 让振荡在几秒内衰减，避免永远弹跳

### 练习四

**思路**：使用 `CANNON.RaycastVehicle` 创建车辆，键盘事件控制油门和转向，静态盒子搭建赛道。

**答案**：

```javascript
// 赛道
const trackPieces = [
  { size: [20, 0.1, 5], pos: [0, 0, 0] },
  { size: [5, 0.1, 5], pos: [10, 1, 0], rot: [0.2, 0, 0] },   // 上坡
  { size: [5, 0.1, 5], pos: [14, 2, 0] },
  { size: [5, 0.1, 5], pos: [14, 2, -5], rot: [0, 0, 0] },    // 弯道入口
  { size: [5, 0.1, 5], pos: [14, 2, -10] }
]

trackPieces.forEach(({ size, pos, rot }) => {
  const body = new CANNON.Body({
    mass: 0,
    shape: new CANNON.Box(new CANNON.Vec3(...size.map(s => s / 2))),
    position: new CANNON.Vec3(...pos)
  })
  if (rot) body.quaternion.setFromEuler(...rot)
  world.addBody(body)

  const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(...size),
    new THREE.MeshStandardMaterial({ color: 0x555555 })
  )
  mesh.position.set(...pos)
  if (rot) mesh.rotation.set(...rot)
  scene.add(mesh)
})

// 车辆
const chassisBody = new CANNON.Body({
  mass: 150,
  shape: new CANNON.Box(new CANNON.Vec3(1, 0.3, 2)),
  position: new CANNON.Vec3(0, 2, 0)
})
world.addBody(chassisBody)

const vehicle = new CANNON.RaycastVehicle({
  chassisBody,
  indexRightAxis: 0,
  indexUpAxis: 1,
  indexForwardAxis: 2
})

const wheelOptions = {
  radius: 0.3,
  directionLocal: new CANNON.Vec3(0, -1, 0),
  suspensionStiffness: 30,
  suspensionRestLength: 0.3,
  frictionSlip: 1.4,
  dampingRelaxation: 2.3,
  dampingCompression: 4.4,
  maxSuspensionForce: 100000,
  rollInfluence: 0.01,
  axleLocal: new CANNON.Vec3(-1, 0, 0),
  chassisConnectionPointLocal: new CANNON.Vec3(0, 0, 0),
  maxSuspensionTravel: 0.3
}

const wheelPositions = [
  new CANNON.Vec3(-0.8, -0.1, 1),
  new CANNON.Vec3(0.8, -0.1, 1),
  new CANNON.Vec3(-0.8, -0.1, -1),
  new CANNON.Vec3(0.8, -0.1, -1)
]

wheelPositions.forEach(pos => {
  wheelOptions.chassisConnectionPointLocal = pos
  vehicle.addWheel(wheelOptions)
})
vehicle.addToWorld(world)

// 速度仪表盘 UI
const speedDisplay = document.createElement('div')
speedDisplay.style.cssText = 'position:fixed;bottom:20px;right:20px;font-size:24px;color:white;font-family:monospace;background:rgba(0,0,0,0.7);padding:10px 20px;border-radius:8px'
document.body.appendChild(speedDisplay)

// 键盘控制
const keys = {}
document.addEventListener('keydown', e => keys[e.code] = true)
document.addEventListener('keyup', e => keys[e.code] = false)

// 车辆更新
function updateVehicle() {
  const engineForce = 800
  const brakeForce = 50
  const steerAngle = 0.3

  // 油门
  if (keys.KeyW) {
    vehicle.applyEngineForce(engineForce, 2)
    vehicle.applyEngineForce(engineForce, 3)
  } else if (keys.KeyS) {
    vehicle.applyEngineForce(-engineForce * 0.5, 2)
    vehicle.applyEngineForce(-engineForce * 0.5, 3)
  } else {
    vehicle.applyEngineForce(0, 2)
    vehicle.applyEngineForce(0, 3)
  }

  // 刹车（空格键）
  if (keys.Space) {
    for (let i = 0; i < 4; i++) vehicle.setBrake(brakeForce, i)
  } else {
    for (let i = 0; i < 4; i++) vehicle.setBrake(0, i)
  }

  // 转向
  if (keys.KeyA) {
    vehicle.setSteeringValue(steerAngle, 0)
    vehicle.setSteeringValue(steerAngle, 1)
  } else if (keys.KeyD) {
    vehicle.setSteeringValue(-steerAngle, 0)
    vehicle.setSteeringValue(-steerAngle, 1)
  } else {
    vehicle.setSteeringValue(0, 0)
    vehicle.setSteeringValue(0, 1)
  }

  // 速度仪表盘
  const speedKmh = Math.round(chassisBody.velocity.length() * 3.6)
  speedDisplay.textContent = `${speedKmh} km/h`

  // 碰撞减速：检测与其他物体的碰撞
  chassisBody.addEventListener('collide', () => {
    const currentSpeed = chassisBody.velocity.length()
    if (currentSpeed > 5) {
      chassisBody.velocity.scale(0.7, chassisBody.velocity)
    }
  })
}

// 跟随相机
function updateCamera() {
  const offset = new THREE.Vector3(0, 3, -6)
  offset.applyQuaternion(chassisBody.quaternion)
  const targetPos = new THREE.Vector3().copy(chassisBody.position).add(offset)
  camera.position.lerp(targetPos, 0.1)
  camera.lookAt(chassisBody.position.x, chassisBody.position.y + 1, chassisBody.position.z)
}

// 主循环
function animate() {
  requestAnimationFrame(animate)
  world.step(1 / 60, clock.getDelta(), 3)

  // 同步车身
  chassisMesh.position.copy(chassisBody.position)
  chassisMesh.quaternion.copy(chassisBody.quaternion)

  // 同步车轮
  for (let i = 0; i < vehicle.wheelInfos.length; i++) {
    vehicle.updateWheelTransform(i)
    const t = vehicle.wheelInfos[i].worldTransform
    wheelMeshes[i].position.copy(t.position)
    wheelMeshes[i].quaternion.copy(t.quaternion)
  }

  updateVehicle()
  updateCamera()
  renderer.render(scene, camera)
}
animate()
```

**要点**：
- `RaycastVehicle` 通过射线检测模拟车轮悬挂，不需要创建车轮碰撞体
- `updateWheelTransform(i)` 必须在每帧调用以更新车轮的世界变换
- 碰撞减速通过 `collide` 事件检测，用 `velocity.scale()` 瞬间减速
- 跟随相机使用 `lerp` 平滑插值，避免相机抖动
- 速度仪表盘直接从 `chassisBody.velocity.length()` 换算为 km/h
