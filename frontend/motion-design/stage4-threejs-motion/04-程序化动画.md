# 程序化动画：噪声驱动、L-system 与群集行为

## 场景引入

前几课的动画要么是预设关键帧，要么由物理引擎驱动。还有一类动画由算法"生长"出来：树的枝条按规则分叉、粒子群像鸟群一样飞翔、地形随噪声起伏。这类动画称为程序化动画（Procedural Animation），核心特征是：规则简单，结果复杂；每次运行都不同。

程序化动画在产品动效中应用广泛：首页有机背景动效、loading 动画中的粒子群集、数据可视化中的流场线条。掌握噪声、L-system、群集行为三种核心算法，就能覆盖 90% 的程序化动画需求。

1. 掌握 Perlin 噪声的原理与应用
2. 理解 Simplex 噪声与 Perlin 噪声的差异

4. 掌握 Boids 群集行为算法

6. 能在 Three.js 中实现噪声粒子场、程序化植物、群集动画

## Perlin 噪声

### 为什么需要噪声

随机数（`Math.random()`）产生的值彼此独立，相邻坐标没有关联。但自然界的现象——云、火焰、地形、水流——都是连续变化的。我们需要一种"连续的随机"：相邻点的值接近，远处的值不相关。

Perlin 噪声正是为此设计的梯度噪声，输出值在 [-1, 1] 之间连续平滑变化。

### 算法逐步拆解

Perlin 噪声的计算分为五步：

**第一步：确定网格单元**

输入坐标 `(x, y, z)` 会落在某个单位立方体内。通过 `Math.floor` 取整得到立方体的左下角坐标 `(X, Y, Z)`，同时保留小数部分 `(x, y, z)` 作为单元内的相对位置。

```javascript
const X = Math.floor(x) & 255  // 网格 x 坐标（0-255 循环）
const Y = Math.floor(y) & 255  // 网格 y 坐标
const Z = Math.floor(z) & 255  // 网格 z 坐标
x -= Math.floor(x)             // 单元内相对 x（0 到 1）
y -= Math.floor(y)             // 单元内相对 y
z -= Math.floor(z)             // 单元内相对 z
```

**第二步：计算淡入曲线（Fade Curve）**

直接线性插值会产生明显的网格感。Perlin 使用五次多项式 `6t⁵ - 15t⁴ + 10t³` 做平滑过渡，使导数在 0 和 1 处为零，消除视觉伪影。

```javascript
fade(t) {
  return t * t * t * (t * (t * 6 - 15) + 10)
  // 原始 Perlin 用的是 3t² - 2t³，改进版用五次多项式效果更好
}
```

**第三步：计算梯度向量**

每个网格顶点有一个伪随机的梯度方向。通过哈希置换表 `perm` 确定梯度方向，梯度与距离向量做点积，得到该顶点对当前点的贡献值。

```javascript
grad(hash, x, y, z) {
  const h = hash & 15           // 取哈希低 4 位，确定 16 种梯度方向
  const u = h < 8 ? x : y      // 前半用 x，后半用 y
  const v = h < 4 ? y : (h === 12 || h === 14 ? x : z)  // 确定第二个分量
  return ((h & 1) === 0 ? u : -u) + ((h & 2) === 0 ? v : -v)  // 根据低位决定正负
}
```

**第四步：插值混合**

对立方体 8 个顶点的贡献值，沿 x、y、z 三个方向依次做线性插值，得到最终噪声值。

```javascript
// 8 个顶点的贡献值通过三次 lerp 混合：
// 先沿 x 方向插值（4 对 → 4 个值）
// 再沿 y 方向插值（2 对 → 2 个值）
// 最后沿 z 方向插值（1 对 → 1 个值）
return lerp(
  lerp(lerp(grad(p[AA], x, y, z),     grad(p[BA], x-1, y, z), u),
       lerp(grad(p[AB], x, y-1, z),    grad(p[BB], x-1, y-1, z), u), v),
  lerp(lerp(grad(p[AA+1], x, y, z-1), grad(p[BA+1], x-1, y, z-1), u),
       lerp(grad(p[AB+1], x, y-1, z-1),grad(p[BB+1], x-1, y-1, z-1), u), v), w)
)
```

**第五步：哈希置换表**

置换表是 0-255 的随机排列，用于将任意坐标映射到伪随机梯度。双倍长度（512）避免取模运算。

```javascript
// 初始化：Fisher-Yates 洗牌
for (let i = 255; i > 0; i--) {
  const j = s % (i + 1)
  const tmp = p[i]; p[i] = p[j]; p[j] = tmp
}
// 扩展到 512 长度
for (let i = 0; i < 512; i++) this.perm[i] = p[i & 255]
```

### 完整实现

```javascript
class PerlinNoise {
  constructor(seed = 0) {
    this.perm = new Uint8Array(512)
    const p = new Uint8Array(256)
    for (let i = 0; i < 256; i++) p[i] = i
    let s = seed
    for (let i = 255; i > 0; i--) {
      s = (s * 16807) % 2147483647
      const j = s % (i + 1)
      const tmp = p[i]; p[i] = p[j]; p[j] = tmp
    }
    for (let i = 0; i < 512; i++) this.perm[i] = p[i & 255]
  }

  fade(t) { return t * t * t * (t * (t * 6 - 15) + 10) }
  lerp(a, b, t) { return a + t * (b - a) }

  grad(hash, x, y, z) {
    const h = hash & 15
    const u = h < 8 ? x : y
    const v = h < 4 ? y : (h === 12 || h === 14 ? x : z)
    return ((h & 1) === 0 ? u : -u) + ((h & 2) === 0 ? v : -v)
  }

  noise3D(x, y, z) {
    const X = Math.floor(x) & 255
    const Y = Math.floor(y) & 255
    const Z = Math.floor(z) & 255
    x -= Math.floor(x); y -= Math.floor(y); z -= Math.floor(z)
    const u = this.fade(x), v = this.fade(y), w = this.fade(z)
    const p = this.perm
    const A = p[X] + Y, AA = p[A] + Z, AB = p[A + 1] + Z
    const B = p[X + 1] + Y, BA = p[B] + Z, BB = p[B + 1] + Z
    return this.lerp(
      this.lerp(
        this.lerp(this.grad(p[AA], x, y, z), this.grad(p[BA], x - 1, y, z), u),
        this.lerp(this.grad(p[AB], x, y - 1, z), this.grad(p[BB], x - 1, y - 1, z), u), v),
      this.lerp(
        this.lerp(this.grad(p[AA + 1], x, y, z - 1), this.grad(p[BA + 1], x - 1, y, z - 1), u),
        this.lerp(this.grad(p[AB + 1], x, y - 1, z - 1), this.grad(p[BB + 1], x - 1, y - 1, z - 1), u), v), w)
  }

  noise2D(x, y) { return this.noise3D(x, y, 0) }
}
```

## Perlin 噪声 vs Simplex 噪声

### Perlin 噪声的局限

Perlin 噪声在高维空间存在两个问题：

1. **计算复杂度**：d 维空间需要计算 2ᵈ 个顶点（3D 需要 8 个），随维度指数增长
2. **方向偏差**：插值沿坐标轴对齐，产生可见的方向性伪影（"块状感"）

### Simplex 噪声的改进

2001 年 Ken Perlin 提出 Simplex 噪声，用单纯形（simplex）替代超立方体：

| 特性 | Perlin 噪声 | Simplex 噪声 |
|------|------------|-------------|
| 网格形状 | 超立方体 | 单纯形（三角形/四面体） |
| 3D 顶点数 | 8 | 4 |
| 方向偏差 | 有（坐标轴对齐） | 无（各向同性更均匀） |
| 复杂度 | O(2ᵈ) | O(d²) |
| 视觉质量 | 好 | 更好（无方向伪影） |

### Simplex 噪声算法要点

Simplex 噪声的核心变化：

1. **坐标变换**：将输入坐标从立方体网格变换到单纯形网格（skewing）
2. **单纯形选择**：确定输入点在哪个单纯形内
3. **距离计算**：使用衰减函数 `max(0, r² - d²)³` 替代点积

```javascript
// Simplex 噪声的坐标变换（2D 示例）
const F2 = 0.5 * (Math.sqrt(3) - 1)  // ≈ 0.366
const G2 = (3 - Math.sqrt(3)) / 6     // ≈ 0.211

// skew 变换：将正方形网格变为三角形网格
const s = (x + y) * F2
const i = Math.floor(x + s)
const j = Math.floor(y + s)

// unskew 变换：回到原始坐标
const t = (i + j) * G2
const x0 = x - (i - t)  // 相对于第一个顶点
const y0 = y - (j - t)
```

### 何时选择哪种

- **产品动效、粒子场**：两者差异不大，Perlin 实现简单
- **地形生成、需要高质量**：Simplex 方向偏差更小
- **2D 纹理生成**：Simplex 视觉效果明显更好
- **已有现成库**：直接用 `simplex-noise` npm 包，无需自己实现

## 噪声驱动的粒子场

用噪声控制粒子速度，形成有机的流场效果。

```javascript
const noise = new PerlinNoise(42)
const particleCount = 3000

// 初始化粒子位置：随机分布在 10x10x10 的空间内
const positions = new Float32Array(particleCount * 3)
for (let i = 0; i < particleCount; i++) {
  positions[i * 3]     = (Math.random() - 0.5) * 10
  positions[i * 3 + 1] = (Math.random() - 0.5) * 10
  positions[i * 3 + 2] = (Math.random() - 0.5) * 10
}

const geometry = new THREE.BufferGeometry()
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))

const material = new THREE.PointsMaterial({
  color: 0xffffff,
  size: 0.03,
  transparent: true,
  opacity: 0.6
})
scene.add(new THREE.Points(geometry, material))

let elapsed = 0

function updateNoiseField() {
  const pos = geometry.getAttribute('position')
  elapsed += 0.016

  for (let i = 0; i < particleCount; i++) {
    const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i)

    // 用噪声生成两个角度，控制粒子的运动方向
    // noise3D 的第三个参数随时间变化，产生动画效果
    const angle  = noise.noise3D(x * 0.3, y * 0.3, z * 0.3 + elapsed * 0.2) * Math.PI * 2
    const angle2 = noise.noise3D(x * 0.3 + 100, y * 0.3 + 100, z * 0.3 + elapsed * 0.2) * Math.PI

    // 将噪声角度转换为位移向量
    const dx = Math.cos(angle) * Math.sin(angle2) * 0.032
    const dy = Math.sin(angle) * 0.016
    const dz = Math.cos(angle) * Math.cos(angle2) * 0.0096

    pos.setXYZ(i, x + dx, y + dy, z + dz)

    // 边界回收：超出范围的粒子重置到随机位置
    if (Math.abs(pos.getX(i)) > 5 || Math.abs(pos.getY(i)) > 5 || Math.abs(pos.getZ(i)) > 5) {
      pos.setXYZ(i, (Math.random() - 0.5) * 2, (Math.random() - 0.5) * 2, (Math.random() - 0.5) * 2)
    }
  }
  pos.needsUpdate = true
}
```

## FBM（分形布朗运动）

单层噪声的细节有限。叠加多层不同频率和振幅的噪声，产生更丰富的细节——这就是 FBM（Fractal Brownian Motion）。

```javascript
function fbm(noise, x, y, z, octaves = 4, lacunarity = 2, gain = 0.5) {
  let value = 0, amplitude = 1, frequency = 1
  for (let i = 0; i < octaves; i++) {
    // 每一层（octave）频率翻倍、振幅减半
    // 第 1 层：大尺度起伏（山脉轮廓）
    // 第 2 层：中尺度细节（山脊纹理）
    // 第 3 层：小尺度噪点（岩石表面）
    // 第 4 层：微小噪点（表面粗糙感）
    value += amplitude * noise.noise3D(x * frequency, y * frequency, z * frequency)
    amplitude *= gain       // 振幅衰减（默认 0.5，每层减半）
    frequency *= lacunarity // 频率增长（默认 2.0，每层翻倍）
  }
  return value
}
```

**关键参数说明**：

- `octaves`（层数）：层数越多细节越丰富，但计算量线性增长。4-6 层通常足够
- `lacunarity`（间隙度）：频率倍增系数。大于 2 会产生更"碎"的细节
- `gain`（增益）：振幅衰减系数。越小越平滑，越大越粗糙

## L-system：程序化植物

L-system（Lindenmayer 系统）通过递归替换规则生成复杂的分形结构。1968 年由生物学家 Aristid Lindenmayer 提出，用于模拟植物生长。

### 基本文法规则

L-system 由三部分组成：

1. **初始符号**（Axiom）：起始字符串，如 `F`
2. **替换规则**（Rules）：每个符号的替换规则，如 `F → FF+[+F-F-F]-[-F+F+F]`
3. **迭代次数**：重复应用规则的次数

以生成一棵树为例：

```
初始：F
规则：F → FF+[+F-F-F]-[-F+F+F]

第 1 次迭代：FF+[+F-F-F]-[-F+F+F]
第 2 次迭代：（每个 F 再次展开，字符串指数增长）
第 3 次迭代：（继续展开）
```

符号含义：
- `F`：向前画线
- `+`：右转
- `-`：左转
- `[`：保存当前位置（入栈）
- `]`：恢复位置（出栈），产生分叉

### 完整实现

```javascript
function buildTree(scene) {
  // 第一步：递归生成 L-system 字符串
  let current = 'F'
  for (let i = 0; i < 3; i++) {
    let next = ''
    for (const c of current) {
      // 规则：F 展开为更复杂的分支结构
      next += c === 'F' ? 'FF+[+F-F-F]-[-F+F+F]' : c
    }
    current = next
  }

  // 第二步：解释字符串为线段集合
  const stack = []
  const positions = []  // 存储线段端点对
  let pos   = new THREE.Vector3(0, 0, 0)   // 当前位置
  let dir   = new THREE.Vector3(0, 1, 0)   // 当前朝向（向上）
  let right = new THREE.Vector3(1, 0, 0)   // 右向量（用于旋转）

  const branchLength = 0.3                  // 每段枝条长度
  const branchAngle  = 25 * Math.PI / 180   // 分叉角度（25 度）

  for (const char of current) {
    switch (char) {
      case 'F': {
        // 向前移动 branchLength 距离，记录线段
        const nextPos = pos.clone().add(dir.clone().multiplyScalar(branchLength))
        positions.push(pos.x, pos.y, pos.z, nextPos.x, nextPos.y, nextPos.z)
        pos = nextPos
        break
      }
      case '+':
        // 绕 right 轴正向旋转
        dir.applyAxisAngle(right, branchAngle)
        break
      case '-':
        // 绕 right 轴反向旋转
        dir.applyAxisAngle(right, -branchAngle)
        break
      case '[':
        // 保存当前状态到栈
        stack.push({ pos: pos.clone(), dir: dir.clone(), right: right.clone() })
        break
      case ']': {
        // 从栈恢复状态，添加随机旋转使树更自然
        const saved = stack.pop()
        pos   = saved.pos
        dir   = saved.dir
        right = saved.right
        // 出栈时绕主轴随机旋转，增加自然感
        right.applyAxisAngle(dir, Math.random() * 0.5)
        break
      }
    }
  }

  // 第三步：合并所有线段为单个 BufferGeometry
  const geo = new THREE.BufferGeometry()
  geo.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3))
  scene.add(new THREE.LineSegments(geo, new THREE.LineBasicMaterial({ color: 0x2ecc71 })))
}
```

## Boids 群集行为

Craig Reynolds 的 Boids 算法用三条规则模拟鸟群：**分离**（避免碰撞）、**对齐**（同方向飞行）、**聚合**（向中心靠拢）。这三条简单规则就能产生复杂的群体行为。

### 三条核心规则

1. **分离（Separation）**：与邻近个体保持最小距离，避免碰撞
2. **对齐（Alignment）**：与邻近个体的平均速度保持一致
3. **聚合（Cohesion）**：向邻近个体的中心移动

### Boid 类实现

```javascript
class Boid {
  constructor() {
    this.position = new THREE.Vector3(
      (Math.random() - 0.5) * 10,
      (Math.random() - 0.5) * 10,
      (Math.random() - 0.5) * 10
    )
    this.velocity = new THREE.Vector3(
      (Math.random() - 0.5) * 2,
      (Math.random() - 0.5) * 2,
      (Math.random() - 0.5) * 2
    )
    this.acceleration = new THREE.Vector3()
  }

  // 分离：远离过近的邻居
  separation(boids, radius = 1) {
    const steer = new THREE.Vector3()
    let count = 0
    for (const other of boids) {
      if (other === this) continue
      const dist = this.position.distanceTo(other.position)
      if (dist < radius && dist > 0) {
        // 方向：从邻居指向自己，权重与距离成反比
        steer.add(this.position.clone().sub(other.position).normalize().divideScalar(dist))
        count++
      }
    }
    if (count > 0) steer.divideScalar(count)
    return steer
  }

  // 对齐：匹配邻居的平均速度
  alignment(boids, radius = 2) {
    const avgVelocity = new THREE.Vector3()
    let count = 0
    for (const other of boids) {
      if (other === this) continue
      if (this.position.distanceTo(other.position) < radius) {
        avgVelocity.add(other.velocity)
        count++
      }
    }
    if (count > 0) {
      avgVelocity.divideScalar(count)                    // 平均速度
        .normalize()
        .multiplyScalar(this.velocity.length())           // 保持原速
      return avgVelocity.sub(this.velocity).clampLength(0, 0.1)  // 限制转向力
    }
    return new THREE.Vector3()
  }

  // 聚合：向邻居中心移动
  cohesion(boids, radius = 2) {
    const center = new THREE.Vector3()
    let count = 0
    for (const other of boids) {
      if (other === this) continue
      if (this.position.distanceTo(other.position) < radius) {
        center.add(other.position)
        count++
      }
    }
    if (count > 0) {
      center.divideScalar(count)  // 邻居中心
      return center.sub(this.position).normalize().multiplyScalar(0.05)
    }
    return new THREE.Vector3()
  }

  // 更新位置与速度
  update(dt, maxSpeed = 3, bounds = 8) {
    this.velocity.add(this.acceleration.multiplyScalar(dt))
    this.velocity.clampLength(0, maxSpeed)
    this.position.add(this.velocity.clone().multiplyScalar(dt))
    this.acceleration.set(0, 0, 0)

    // 边界反弹：到达边界时反转对应速度分量
    if (Math.abs(this.position.x) > bounds) this.velocity.x *= -1
    if (Math.abs(this.position.y) > bounds) this.velocity.y *= -1
    if (Math.abs(this.position.z) > bounds) this.velocity.z *= -1
  }
}
```

### Boids 渲染与动画循环

```javascript
// 使用 InstancedMesh 高效渲染大量 Boid
const coneGeo = new THREE.ConeGeometry(0.1, 0.3, 4)
coneGeo.rotateX(Math.PI / 2)  // 使锥体朝前（速度方向）
const boidMesh = new THREE.InstancedMesh(
  coneGeo,
  new THREE.MeshStandardMaterial({ color: 0xf39c12 }),
  100
)
scene.add(boidMesh)

const boids = Array.from({ length: 100 }, () => new Boid())
const dummy = new THREE.Object3D()
const up = new THREE.Vector3(0, 1, 0)

function animate() {
  requestAnimationFrame(animate)

  // 计算所有 Boid 的力
  for (const boid of boids) {
    boid.acceleration.set(0, 0, 0)

    // 施加三个群集力，权重分别为 1.5、1.0、1.0
    // 分离权重最高，优先避免碰撞
    boid.applyForce = (f) => boid.acceleration.add(f)
    boid.applyForce(boid.separation(boids).multiplyScalar(1.5))
    boid.applyForce(boid.alignment(boids))
    boid.applyForce(boid.cohesion(boids))

    boid.update(0.016)
  }

  // 更新 InstancedMesh 的变换矩阵
  for (let i = 0; i < 100; i++) {
    dummy.position.copy(boids[i].position)
    // 使锥体朝向速度方向
    dummy.quaternion.setFromUnitVectors(up, boids[i].velocity.clone().normalize())
    dummy.updateMatrix()
    boidMesh.setMatrixAt(i, dummy.matrix)
  }
  boidMesh.instanceMatrix.needsUpdate = true

  renderer.render(scene, camera)
}
animate()
```

## Voronoi 图案

Voronoi 图将空间按最近邻划分为多个区域，产生类似细胞、龟裂、蜂巢的自然图案。

### 基本原理

给定一组种子点，Voronoi 图将空间划分为若干区域，每个区域内的所有点到其种子点的距离小于到任何其他种子点的距离。区域边界形成独特的多边形网格。

### GPU 实现思路

在 Shader 中实现 Voronoi 效率最高。核心是将每个像素映射到网格单元，比较到相邻 9 个单元种子点的距离：

```glsl
// GLSL Voronoi 片段着色器
vec2 random2(vec2 p) {
  return fract(sin(vec2(dot(p, vec2(127.1, 311.7)), dot(p, vec2(269.5, 183.3)))) * 43758.5453);
}

void main() {
  vec2 st = gl_FragCoord.xy / u_resolution.xy;
  st.x *= u_resolution.x / u_resolution.y;
  st *= 8.0;  // 缩放控制网格密度

  vec2 i_st = floor(st);  // 整数部分：网格坐标
  vec2 f_st = fract(st);  // 小数部分：网格内位置

  float minDist = 10.0;   // 到最近种子的距离
  vec2 minPoint;           // 最近种子的坐标

  // 遍历 3x3 邻域，找到最近的种子点
  for (int y = -1; y <= 1; y++) {
    for (int x = -1; x <= 1; x++) {
      vec2 neighbor = vec2(float(x), float(y));
      vec2 point = random2(i_st + neighbor);  // 该单元的随机种子位置
      point = 0.5 + 0.5 * sin(u_time + 6.2831 * point);  // 动态移动
      float dist = length(neighbor + point - f_st);
      if (dist < minDist) {
        minDist = dist;
        minPoint = point;
      }
    }
  }

  // 用距离生成颜色
  gl_FragColor = vec4(vec3(minDist), 1.0);
}
```

### Voronoi 的应用场景

- **细胞纹理**：模拟生物细胞表面
- **破碎效果**：物体破碎的裂纹走向
- **地形特征**：模拟河流流域、领地划分
- **抽象背景**：动态 Voronoi 可作为产品首页的有机背景

## 反应扩散（Reaction-Diffusion）

反应扩散模型模拟两种化学物质在空间中的相互作用，产生类似斑马条纹、豹纹、珊瑚图案的自然纹理。

### Gray-Scott 模型

最常用的反应扩散模型是 Gray-Scott 模型，包含两种物质 U 和 V：

```
∂U/∂t = Du * ∇²U - U*V² + f*(1-U)
∂V/∂t = Dv * ∇²V + U*V² - (f+k)*V
```

其中：
- `Du, Dv`：扩散率（V 的扩散率通常比 U 小）
- `f`：补给率（U 的输入速率）
- `k`：去除率（V 的移除速率）
- `∇²`：拉普拉斯算子（相邻像素的差值）

### GPU 实现

反应扩散的计算量大，适合在 Shader 或 Compute Shader 中实现：

```javascript
// 通过 ping-pong 双缓冲实现迭代
const size = 512
const fboA = new THREE.WebGLRenderTarget(size, size, { type: THREE.FloatType })
const fboB = new THREE.WebGLRenderTarget(size, size, { type: THREE.FloatType })

const rdShader = new THREE.ShaderMaterial({
  uniforms: {
    u_feed:    { value: 0.055 },    // f 参数
    u_kill:    { value: 0.062 },    // k 参数
    u_diffuseA: { value: 1.0 },     // U 扩散率
    u_diffuseB: { value: 0.5 },     // V 扩散率
    u_resolution: { value: new THREE.Vector2(size, size) },
    u_texture: { value: null }
  },
  fragmentShader: `
    uniform sampler2D u_texture;
    uniform float u_feed, u_kill, u_diffuseA, u_diffuseB;
    uniform vec2 u_resolution;

    void main() {
      vec2 uv = gl_FragCoord.xy / u_resolution;
      vec2 step = 1.0 / u_resolution;

      // 拉普拉斯卷积核（9 点）
      vec2 center = texture2D(u_texture, uv).rg;
      vec2 laplacian = -center;
      laplacian += texture2D(u_texture, uv + vec2(step.x, 0.0)).rg * 0.2;
      laplacian += texture2D(u_texture, uv - vec2(step.x, 0.0)).rg * 0.2;
      laplacian += texture2D(u_texture, uv + vec2(0.0, step.y)).rg * 0.2;
      laplacian += texture2D(u_texture, uv - vec2(0.0, step.y)).rg * 0.2;
      laplacian += texture2D(u_texture, uv + step).rg * 0.05;
      laplacian += texture2D(u_texture, uv - step).rg * 0.05;
      laplacian += texture2D(u_texture, uv + vec2(step.x, -step.y)).rg * 0.05;
      laplacian += texture2D(u_texture, uv + vec2(-step.x, step.y)).rg * 0.05;

      float u = center.r, v = center.g;
      float reaction = u * v * v;
      float newU = u + (u_diffuseA * laplacian.r - reaction + u_feed * (1.0 - u));
      float newV = v + (u_diffuseB * laplacian.g + reaction - (u_feed + u_kill) * v);

      gl_FragColor = vec4(clamp(newU, 0.0, 1.0), clamp(newV, 0.0, 1.0), 0.0, 1.0);
    }
  `
})
```

### 参数与图案

不同的 `f` 和 `k` 参数组合产生截然不同的图案：

- `f=0.055, k=0.062`：斑点图案（类似豹纹）
- `f=0.037, k=0.06`：条纹图案（类似斑马纹）
- `f=0.025, k=0.06`：迷宫图案（类似指纹）
- `f=0.012, k=0.05`：珊瑚状分支

## 性能考量

程序化动画的计算量随粒子数量和算法复杂度快速增长，必须关注性能。

### 噪声计算优化

1. **预计算查找表**：将噪声值预计算到纹理中，Shader 采样比实时计算快 10 倍以上
2. **降低精度**：用 `noise2D` 替代 `noise3D`，减少一个维度的计算
3. **减少 octave 数量**：4 层 FBM 通常足够，6 层以上收益递减
4. **GPU 计算**：大量粒子的噪声计算移到 Compute Shader 或 Transform Feedback

### Boids 空间优化

暴力搜索邻居的复杂度是 O(n²)，100 个 Boid 可接受，1000 个就会卡顿。

```javascript
// 空间哈希：将空间划分为网格，只检查同一格和相邻格的 Boid
class SpatialHash {
  constructor(cellSize = 2) {
    this.cellSize = cellSize
    this.cells = new Map()
  }

  _key(x, y, z) {
    const cx = Math.floor(x / this.cellSize)
    const cy = Math.floor(y / this.cellSize)
    const cz = Math.floor(z / this.cellSize)
    return `${cx},${cy},${cz}`
  }

  insert(boid) {
    const key = this._key(boid.position.x, boid.position.y, boid.position.z)
    if (!this.cells.has(key)) this.cells.set(key, [])
    this.cells.get(key).push(boid)
  }

  query(position, radius) {
    const results = []
    const r = Math.ceil(radius / this.cellSize)
    const cx = Math.floor(position.x / this.cellSize)
    const cy = Math.floor(position.y / this.cellSize)
    const cz = Math.floor(position.z / this.cellSize)

    for (let dx = -r; dx <= r; dx++) {
      for (let dy = -r; dy <= r; dy++) {
        for (let dz = -r; dz <= r; dz++) {
          const key = `${cx+dx},${cy+dy},${cz+dz}`
          const cell = this.cells.get(key)
          if (cell) results.push(...cell)
        }
      }
    }
    return results
  }

  clear() { this.cells.clear() }
}
```

| 场景 | 优化方案 | 效果 |

| 大量相同形状的粒子 | `InstancedMesh` | 100 个物体 → 1 个 DrawCall |
| 线段集合（L-system） | 合并为单个 `BufferGeometry` | 减少 DrawCall |
| 纯 Shader 效果（Voronoi、反应扩散） | 单个全屏四边形 | 1 个 DrawCall |

## 常见误区

1. **噪声频率太高**：表现为锯齿状，频率应控制在 0.01-0.5 范围。频率 > 1 时噪声值变化过于剧烈，失去连续性
2. **噪声频率太低**：所有粒子运动方向几乎一致，看不出噪声效果。频率 < 0.01 时噪声在一个屏幕范围内几乎不变
3. **L-system 迭代次数太多**：字符串长度指数增长，7 次迭代可能产生数万个线段。建议 3-5 次，或用 LOD 根据距离动态调整
4. **Boids 不限制速度**：必须使用 `clampLength`，否则速度累积后 Boids 会飞出视野且无法回头
5. **群集行为权重不做调试**：三个力的相对权重决定了群集的"性格"。分离 > 对齐 → 松散游荡；对齐 > 聚合 → 紧密编队飞行
6. **噪声种子不固定**：每次刷新结果不同，不利于调试和复现。开发阶段用固定种子，上线后可切换为随机种子
7. **FBM 的 gain 参数过大**：gain > 0.7 时高频层的贡献过大，产生粗糙的噪点感。gain < 0.3 时高频层几乎不可见，浪费计算
8. **反应扩散不做边界处理**：边界条件（Neumann / Dirichlet）直接影响图案的边缘行为。常用做法是让边界物质浓度固定为初始值

## 工程建议

1. **使用 simplex-noise 库替代自实现**：社区库经过优化，API 更友好（`createNoise3D(seed)`），支持 2D/3D/4D
2. **噪声动画通过增加时间维度实现**：`noise3D(x, y, time)` 产生平滑动画，时间步长建议 0.01-0.05
3. **Boids 的邻居查找使用空间哈希**：将 O(n²) 降到 O(n)，1000 个 Boids 时性能提升 50 倍以上
4. **L-system 渲染使用 BufferGeometry 合并**：将所有线段合并为一个 DrawCall，避免数千个独立 Line 对象
5. **程序化动画需要可控的随机种子**：开发调试用固定种子，生产环境用 `Date.now()` 作为种子
6. **Voronoi 和反应扩散用 Shader 实现**：CPU 逐像素计算太慢，GPU 并行计算可以实时运行 512×512 的网格
7. **噪声参数用 GUI 面板实时调节**：使用 lil-gui 暴露频率、振幅、种子等参数，调试效率提升 10 倍
8. **大量粒子使用 Transform Feedback**：将粒子更新逻辑移入顶点着色器，避免 CPU-GPU 数据传输瓶颈

## 小结

程序化动画的核心思想是"用规则生成复杂"。噪声提供连续随机性，L-system 提供递归生长，Boids 提供涌现行为，Voronoi 提供空间划分，反应扩散提供有机纹理。五者可以组合：噪声驱动 Boids 的聚合目标、L-system 的生长方向受噪声影响、群集在噪声流场中运动、Voronoi 种子作为反应扩散的起点。

程序化动画的魅力在于：规则越简单，结果越意外。

### 练习三

**思路**：用 ShaderMaterial 实现 Voronoi，种子点用正弦函数做周期运动，边缘用 `smoothstep` 做发光。

**答案**：

```javascript
const voronoiMaterial = new THREE.ShaderMaterial({
  uniforms: {
    u_time: { value: 0 },
    u_resolution: { value: new THREE.Vector2(innerWidth, innerHeight) }
  },
  vertexShader: `
    varying vec2 v_uv;
    void main() {
      v_uv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform float u_time;
    uniform vec2 u_resolution;

    vec2 random2(vec2 p) {
      return fract(sin(vec2(
        dot(p, vec2(127.1, 311.7)),
        dot(p, vec2(269.5, 183.3))
      )) * 43758.5453);
    }

    void main() {
      vec2 st = gl_FragCoord.xy / u_resolution;
      st.x *= u_resolution.x / u_resolution.y;
      st *= 6.0;

      vec2 i_st = floor(st);
      vec2 f_st = fract(st);

      float minDist = 10.0;
      float secondDist = 10.0;

      for (int y = -1; y <= 1; y++) {
        for (int x = -1; x <= 1; x++) {
          vec2 neighbor = vec2(float(x), float(y));
          vec2 point = random2(i_st + neighbor);
          point = 0.5 + 0.5 * sin(u_time * 0.8 + 6.2831 * point);

          float dist = length(neighbor + point - f_st);
          if (dist < minDist) {
            secondDist = minDist;
            minDist = dist;
          } else if (dist < secondDist) {
            secondDist = dist;
          }
        }
      }

      // 边缘发光：secondDist - minDist 接近 0 时为边缘
      float edge = 1.0 - smoothstep(0.0, 0.06, secondDist - minDist);
      vec3 color = mix(vec3(0.05, 0.05, 0.15), vec3(0.4, 0.8, 1.0), edge);
      color += vec3(minDist * 0.3);

      gl_FragColor = vec4(color, 1.0);
    }
  `
})

bgPlane.frustumCulled = false
```

### 练习四

**思路**：用 ping-pong FBO 实现反应扩散迭代，lil-gui 暴露参数，鼠标交互添加种子点。

**答案**：

```javascript
import { GUI } from 'lil-gui'

const size = 512
const params = { feed: 0.055, kill: 0.062, reset: () => initTexture() }

// 创建两个 FBO 用于 ping-pong 迭代
const rtOptions = { type: THREE.FloatType, minFilter: THREE.NearestFilter, magFilter: THREE.NearestFilter }
let fboA = new THREE.WebGLRenderTarget(size, size, rtOptions)
let fboB = new THREE.WebGLRenderTarget(size, size, rtOptions)

// 初始化纹理：U=1, V=0，中心区域 V=1 作为种子
function initTexture() {
  const data = new Float32Array(size * size * 4)
  for (let i = 0; i < size * size; i++) {
    const x = i % size, y = Math.floor(i / size)
    data[i * 4]     = 1.0  // U
    data[i * 4 + 1] = 0.0  // V
    // 中心添加种子
    const dx = x - size / 2, dy = y - size / 2
    if (dx * dx + dy * dy < 100) data[i * 4 + 1] = 1.0
  }
  const tex = new THREE.DataTexture(data, size, size, THREE.RGBAFormat, THREE.FloatType)
  tex.needsUpdate = true
  return tex
}

const rdMaterial = new THREE.ShaderMaterial({
  uniforms: {
    u_texture: { value: initTexture() },
    u_feed: { value: params.feed },
    u_kill: { value: params.kill },
    u_resolution: { value: new THREE.Vector2(size, size) }
  },
  fragmentShader: `
    uniform sampler2D u_texture;
    uniform float u_feed, u_kill;
    uniform vec2 u_resolution;

    void main() {
      vec2 uv = gl_FragCoord.xy / u_resolution;
      vec2 step = 1.0 / u_resolution;
      vec2 c = texture2D(u_texture, uv).rg;

      vec2 lap = -c * 0.6;
      lap += texture2D(u_texture, uv + vec2(step.x, 0)).rg * 0.2;
      lap += texture2D(u_texture, uv - vec2(step.x, 0)).rg * 0.2;
      lap += texture2D(u_texture, uv + vec2(0, step.y)).rg * 0.2;
      lap += texture2D(u_texture, uv - vec2(0, step.y)).rg * 0.2;
      lap += texture2D(u_texture, uv + step).rg * 0.05;
      lap += texture2D(u_texture, uv - step).rg * 0.05;
      lap += texture2D(u_texture, uv + vec2(step.x, -step.y)).rg * 0.05;
      lap += texture2D(u_texture, uv + vec2(-step.x, step.y)).rg * 0.05;

      float reaction = c.r * c.g * c.g;
      float newU = c.r + (lap.r - reaction + u_feed * (1.0 - c.r));
      float newV = c.g + (lap.g + reaction - (u_feed + u_kill) * c.g);

      gl_FragColor = vec4(clamp(newU, 0.0, 1.0), clamp(newV, 0.0, 1.0), 0.0, 1.0);
    }
  `
})

// 用正交相机渲染 FBO
const orthoCam = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1)
const rdQuad = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), rdMaterial)

// 可视化材质
const displayMaterial = new THREE.ShaderMaterial({
  uniforms: { u_texture: { value: null } },
  fragmentShader: `
    uniform sampler2D u_texture;
    void main() {
      vec2 v = texture2D(u_texture, gl_FragCoord.xy / 512.0).rg;
      float c = 1.0 - v.g;
      gl_FragColor = vec4(vec3(c * 0.2, c * 0.5, c * 0.8), 1.0);
    }
  `
})

// GUI 面板
const gui = new GUI()
gui.add(params, 'feed', 0.01, 0.1).onChange(v => rdMaterial.uniforms.u_feed.value = v)
gui.add(params, 'kill', 0.04, 0.07).onChange(v => rdMaterial.uniforms.u_kill.value = v)
gui.add(params, 'reset')

// 鼠标点击添加种子
renderer.domElement.addEventListener('click', (e) => {
  const x = (e.clientX / innerWidth) * size
  const y = (1 - e.clientY / innerHeight) * size
  // 在鼠标位置附近添加 V 物质（需要写入 FBO 纹理）
})

function animate() {
  requestAnimationFrame(animate)
  // 每帧迭代 8 次加速收敛
  for (let i = 0; i < 8; i++) {
    rdMaterial.uniforms.u_texture.value = fboA.texture
    renderer.setRenderTarget(fboB)
    renderer.render(rdQuad, orthoCam)
    const temp = fboA; fboA = fboB; fboB = temp
  }
  renderer.setRenderTarget(null)
  displayMaterial.uniforms.u_texture.value = fboA.texture
  renderer.render(new THREE.Mesh(new THREE.PlaneGeometry(2, 2), displayMaterial), orthoCam)
}

```

**要点**：ping-pong 双缓冲实现迭代；每帧多次迭代加速收敛；`f` 和 `k` 的微小变化会产生截然不同的图案，是很好的数学可视化案例。
