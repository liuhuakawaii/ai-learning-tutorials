# 阶段实战：3D 产品展示动画

## 做什么

用 Three.js 构建一个交互式 3D 产品展示页面：产品模型加载、自动旋转、鼠标交互、材质切换、入场动画、信息标注。

这是一个完整的 3D 产品展示方案，可以直接用在电商或品牌官网。

## 场景搭建

```javascript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'

const scene = new THREE.Scene()
scene.background = new THREE.Color(0xf0f2f5)

const camera = new THREE.PerspectiveCamera(45, window.innerWidth / window.innerHeight, 0.1, 100)
camera.position.set(3, 2, 5)

const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true })
renderer.setSize(window.innerWidth, window.innerHeight)
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
renderer.shadowMap.enabled = true
renderer.toneMapping = THREE.ACESFilmicToneMapping
renderer.toneMappingExposure = 1.2
document.getElementById('canvas-container').appendChild(renderer.domElement)
```

`ACESFilmicToneMapping` 让光影更接近电影级效果。

## 光照系统

产品展示需要三点照明：

```javascript
// 主光：从右上方打过来
const keyLight = new THREE.DirectionalLight(0xffffff, 1.5)
keyLight.position.set(5, 5, 5)
keyLight.castShadow = true
scene.add(keyLight)

// 补光：从左侧补暗部
const fillLight = new THREE.DirectionalLight(0xffffff, 0.5)
fillLight.position.set(-3, 3, 3)
scene.add(fillLight)

// 背光：从后方勾勒轮廓
const rimLight = new THREE.DirectionalLight(0xffffff, 0.8)
rimLight.position.set(0, 3, -5)
scene.add(rimLight)

// 环境光：整体提亮
scene.add(new THREE.AmbientLight(0xffffff, 0.3))
```

## 模型加载

```javascript
const loader = new GLTFLoader()
let model, mixer

loader.load('/models/product.glb', (gltf) => {
  model = gltf.scene
  model.traverse(child => {
    if (child.isMesh) {
      child.castShadow = true
      child.receiveShadow = true
    }
  })
  scene.add(model)

  // 如果模型有内置动画
  if (gltf.animations.length) {
    mixer = new THREE.AnimationMixer(model)
    mixer.clipAction(gltf.animations[0]).play()
  }

  // 入场动画
  gsap.from(model.scale, { x: 0, y: 0, z: 0, duration: 1, ease: 'back.out(1.7)' })
  gsap.from(model.rotation, { y: Math.PI, duration: 1.2, ease: 'power2.out' })
})
```

## 轨道控制器

鼠标拖拽旋转、滚轮缩放：

```javascript
const controls = new OrbitControls(camera, renderer.domElement)
controls.enableDamping = true       // 阻尼：松手后惯性滑行
controls.dampingFactor = 0.05
controls.enablePan = false          // 禁止平移
controls.minDistance = 3            // 最小缩放距离
controls.maxDistance = 10           // 最大缩放距离
controls.maxPolarAngle = Math.PI / 2  // 不允许翻到底部
controls.autoRotate = true          // 自动旋转
controls.autoRotateSpeed = 1
```

鼠标交互时暂停自动旋转：

```javascript
renderer.domElement.addEventListener('pointerdown', () => controls.autoRotate = false)
renderer.domElement.addEventListener('pointerup', () => {
  setTimeout(() => controls.autoRotate = true, 3000)
})
```

## 材质切换

点击按钮切换产品颜色：

```javascript
const materials = {
  blue:   new THREE.MeshStandardMaterial({ color: 0x3b82f6, metalness: 0.3, roughness: 0.5 }),
  red:    new THREE.MeshStandardMaterial({ color: 0xef4444, metalness: 0.3, roughness: 0.5 }),
  gold:   new THREE.MeshStandardMaterial({ color: 0xf59e0b, metalness: 0.8, roughness: 0.2 }),
  black:  new THREE.MeshStandardMaterial({ color: 0x1e293b, metalness: 0.5, roughness: 0.3 }),
}

function switchMaterial(name) {
  const mat = materials[name]
  model.traverse(child => {
    if (child.isMesh && child.name === 'body') {
      gsap.to(child.material.color, {
        r: mat.color.r, g: mat.color.g, b: mat.color.b,
        duration: 0.5,
      })
      gsap.to(child.material, { metalness: mat.metalness, roughness: mat.roughness, duration: 0.5 })
    }
  })
}
```

## 信息标注

在 3D 空间中标注产品特点：

```javascript
const annotations = [
  { position: new THREE.Vector3(1.2, 1.5, 0), text: '铝合金外壳' },
  { position: new THREE.Vector3(-0.8, 0.5, 1), text: 'USB-C 接口' },
  { position: new THREE.Vector3(0, 2, -0.5), text: '4K 显示屏' },
]

function updateAnnotations() {
  annotations.forEach(ann => {
    const screenPos = ann.position.clone().project(camera)
    const x = (screenPos.x * 0.5 + 0.5) * window.innerWidth
    const y = (-screenPos.y * 0.5 + 0.5) * window.innerHeight
    const el = document.getElementById(ann.id)
    if (el) {
      el.style.transform = `translate(${x}px, ${y}px)`
      // 隐藏背面的标注
      const dir = ann.position.clone().sub(camera.position).normalize()
      const normal = new THREE.Vector3(0, 0, 1)
      el.style.display = dir.dot(normal) > 0 ? 'block' : 'none'
    }
  })
}
```

## 动画循环

```javascript
const clock = new THREE.Clock()

function animate() {
  requestAnimationFrame(animate)
  const delta = clock.getDelta()

  if (mixer) mixer.update(delta)
  controls.update()
  updateAnnotations()
  renderer.render(scene, camera)
}
animate()
```

## 响应式

```javascript
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(window.innerWidth, window.innerHeight)
})
```

## 性能优化

- 模型压缩：glTF 用 Draco 压缩，文件体积减小 80%
- 纹理压缩：用 KTX2 格式 + Basis 纹理压缩
- LOD：远处用低面数模型
- 按需渲染：没有交互时停止渲染循环

```javascript
// 按需渲染
controls.addEventListener('change', () => renderer.render(scene, camera))
```

canvas.addEventListener('mousemove', e => {
  if (!isDragging) return
  const delta = e.clientX - startX
  if (Math.abs(delta) > 10) {
    currentIndex = (currentIndex + (delta > 0 ? 1 : -1) + 36) % 36
    drawImage(images[currentIndex])
    startX = e.clientX
  }
})
canvas.addEventListener('mouseup', () => isDragging = false)
