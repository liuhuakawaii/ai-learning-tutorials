# 阶段实战：3D 产品展示动画

## 场景引入

前面五课我们分别学习了关键帧动画、物理引擎、流体模拟、程序化动画和 3D 交互。本课将这些技术整合到一个真实项目中：为一款智能手表构建 3D 产品展示页面。

这个页面需要实现：产品模型加载与自动旋转展示、点击部件切换视角并显示信息、表带拆解动画、背景粒子流场、触摸手势支持、性能适配。这是一个综合性项目，考验架构能力和工程判断力。

为什么选智能手表？因为它同时具备金属、玻璃、橡胶/皮革等多种材质，有旋转表冠等可交互部件，且产品尺寸适中——既不会像汽车那样模型面数过高导致加载慢，也不会像耳机那样几何细节过少导致展示效果平庸。它是学习 3D 产品展示的理想载体。

## 学习目标

1. 掌握 3D 产品展示页面的完整架构设计
2. 能将关键帧动画、物理引擎、粒子系统整合到同一场景
3. 理解多系统协作时的状态管理和事件通信
4. 掌握移动端性能降级策略
5. 理解相机动画系统与环境贴图对产品质感的影响
6. 掌握 glTF 模型加载优化的工程实践

### 架构设计思路

这个架构遵循**单一职责 + 注册制**原则：

- **SceneManager** 只负责渲染循环和系统调度，不关心具体业务逻辑
- **各系统**（动画、粒子、交互）独立实现，通过 `registerSystem()` 注册到 SceneManager
- **EventBus** 作为中间层，让交互系统点击部件时，动画系统和 UI 系统能响应，但彼此不知道对方的存在
- **ModelLoader** 封装所有加载逻辑，包括 Draco 解压、进度回调、LOD 选择

这种设计的好处是：当你需要替换粒子系统（比如从 Perlin 噪声换成 curl noise），只需要替换一个类，不影响其他任何代码。

## 场景初始化

```javascript
import * as THREE from 'three'
import { OrbitControls } from 'three/addons/controls/OrbitControls.js'

class SceneManager {
  constructor(container) {
    // 创建场景
    this.scene = new THREE.Scene()

    // 透视相机：40° FOV 适合产品展示（不会产生广角畸变）
    this.camera = new THREE.PerspectiveCamera(40, innerWidth / innerHeight, 0.1, 100)
    this.camera.position.set(3, 2, 4)

    // 渲染器配置：开启抗锯齿、透明背景、高性能模式
    this.renderer = new THREE.WebGLRenderer({
      antialias: true,
      alpha: true,
      powerPreference: 'high-performance'
    })
    this.renderer.setSize(innerWidth, innerHeight)
    // 像素比上限为 2，避免高 DPI 屏幕（如 3x）性能浪费
    this.renderer.setPixelRatio(Math.min(devicePixelRatio, 2))
    // ACES 色调映射让高光过渡更自然，适合金属材质
    this.renderer.toneMapping = THREE.ACESFilmicToneMapping
    this.renderer.toneMappingExposure = 1.2
    // 开启阴影
    this.renderer.shadowMap.enabled = true
    this.renderer.shadowMap.type = THREE.PCFSoftShadowMap
    container.appendChild(this.renderer.domElement)

    // 轨道控制器：允许旋转，禁止平移，限制距离范围
    this.controls = new OrbitControls(this.camera, this.renderer.domElement)
    this.controls.enableDamping = true
    this.controls.dampingFactor = 0.05
    this.controls.enablePan = false
    this.controls.minDistance = 2
    this.controls.maxDistance = 8
    // 限制垂直角度，避免翻转到模型底部
    this.controls.minPolarAngle = Math.PI * 0.2
    this.controls.maxPolarAngle = Math.PI * 0.8

    this.clock = new THREE.Clock()
    this.systems = []

    window.addEventListener('resize', () => {
      this.camera.aspect = innerWidth / innerHeight
      this.camera.updateProjectionMatrix()
      this.renderer.setSize(innerWidth, innerHeight)
    })
  }

  // 注册子系统，主循环中统一调用 update
  registerSystem(system) {
    this.systems.push(system)
  }

  // 主循环：更新控制器 → 更新所有子系统 → 渲染
  update() {
    const delta = this.clock.getDelta()
    this.controls.update()
    for (const s of this.systems) s.update(delta)
    this.renderer.render(this.scene, this.camera)
  }
}
```

## 光照配置

产品展示对光照要求高——需要展现材质的金属质感和表面细节。经典的三点光照方案（主光 + 补光 + 轮廓光）是产品摄影的标准配置：

```javascript
class Lighting {
  constructor(scene) {
    // 环境光：提供基础亮度，避免阴影区域全黑
    scene.add(new THREE.AmbientLight(0xffffff, 0.4))

    // 主光（Key Light）：从右上方照射，产生主要阴影
    const key = new THREE.DirectionalLight(0xffffff, 2)
    key.position.set(5, 5, 5)
    key.castShadow = true
    key.shadow.mapSize.set(1024, 1024)
    key.shadow.camera.near = 0.5
    key.shadow.camera.far = 20
    key.shadow.bias = -0.001
    scene.add(key)

    // 补光（Fill Light）：从左下方照射，减弱阴影对比度
    const fill = new THREE.DirectionalLight(0x8888ff, 0.5)
    fill.position.set(-3, 2, -3)
    scene.add(fill)

    // 轮廓光（Rim Light）：从后方照射，勾勒产品轮廓
    const rim = new THREE.DirectionalLight(0xffa500, 0.8)
    rim.position.set(0, 3, -5)
    scene.add(rim)
  }
}
```

为什么补光是淡蓝色？因为暖色主光 + 冷色补光会产生色温对比，让画面更有层次感。轮廓光用暖橙色则是为了让产品边缘产生"镀金"效果，提升高级感。

## 环境贴图与反射

金属和玻璃材质如果没有环境贴图（Environment Map），看起来会像塑料。环境贴图提供反射信息，是产品展示质感的关键：

```javascript
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js'

class EnvironmentMap {
  constructor(scene, renderer) {
    this.scene = scene
    this.renderer = renderer
  }

  // 加载 HDR 环境贴图
  async load(hdrUrl) {
    const pmremGenerator = new THREE.PMREMGenerator(this.renderer)
    pmremGenerator.compileEquirectangularShader()

    const texture = await new Promise((resolve, reject) => {
      new RGBELoader().load(hdrUrl, resolve, undefined, reject)
    })

    // 从 HDR 生成预过滤的环境贴图（支持不同粗糙度的反射）
    const envMap = pmremGenerator.fromEquirectangular(texture).texture
    texture.dispose()
    pmremGenerator.dispose()

    // 设置为场景默认环境，所有 PBR 材质自动使用
    this.scene.environment = envMap
    // 不设置 scene.background，保持透明背景（适合网页嵌入）
  }

  // 为模型的所有 Mesh 应用环境贴图强度
  applyToModel(model, intensity = 1.0) {
    model.traverse((child) => {
      if (!child.isMesh) return
      child.material.envMapIntensity = intensity
    })
  }
}
```

**关键点**：`scene.environment` 和 `scene.background` 是独立的。设置 `environment` 不会影响背景——它只影响 PBR 材质的反射。这让你可以同时拥有透明/自定义背景和真实的环境反射。

## 产品模型加载与部件识别

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'

class ProductModel {
  constructor(scene) {
    this.scene = scene
    this.model = null
    this.parts = new Map()    // 存储命名部件的引用
    this.mixers = []          // AnimationMixer 实例列表
  }

  async load(url) {
    // 使用 Promise 包装回调式 API
    const gltf = await new Promise((resolve, reject) => {
      new GLTFLoader().load(url, resolve, undefined, reject)
    })

    this.model = gltf.scene

    // 遍历模型，按名称识别部件并设置阴影
    this.model.traverse((child) => {
      if (!child.isMesh) return
      child.castShadow = true
      child.receiveShadow = true

      // 根据模型中的命名约定识别部件
      if (child.name.includes('strap')) {
        this.parts.set('strap', child)
        child.userData = { name: '表带', desc: '氟橡胶材质，耐汗耐腐蚀' }
      } else if (child.name.includes('dial')) {
        this.parts.set('dial', child)
        child.userData = { name: '表盘', desc: '1.9寸 AMOLED 屏幕，峰值亮度 2000nit' }
      } else if (child.name.includes('crown')) {
        this.parts.set('crown', child)
        child.userData = { name: '表冠', desc: '旋转表冠，支持滚动列表和缩放' }
      }
    })

    // 如果 glTF 文件包含动画剪辑，自动播放
    if (gltf.animations.length > 0) {
      const mixer = new THREE.AnimationMixer(this.model)
      gltf.animations.forEach((clip) => {
        const action = mixer.clipAction(clip)
        action.setLoop(THREE.LoopRepeat)
        action.play()
      })
      this.mixers.push(mixer)
    }

    this.scene.add(this.model)
  }

  update(delta) {
    for (const m of this.mixers) m.update(delta)
  }

  getPartByName(name) { return this.parts.get(name) }
  getAllParts() { return Array.from(this.parts.values()) }
}
```

## 相机动画系统

产品展示中，相机不应该只有手动旋转。点击部件时，相机需要自动飞到最佳观赏角度——这就是 CameraAnimator 的职责：

```javascript
class CameraAnimator {
  constructor(camera, controls) {
    this.camera = camera
    this.controls = controls
    this.isAnimating = false
    this.startPos = new THREE.Vector3()
    this.targetPos = new THREE.Vector3()
    this.startTarget = new THREE.Vector3()
    this.targetLookAt = new THREE.Vector3()
    this.progress = 0
    this.duration = 1.2
  }

  // 聚焦到某个世界坐标点，自动计算最佳相机位置
  focusOn(worldPosition, distance = 2.5) {
    if (this.isAnimating) return

    // 保存起始状态
    this.startPos.copy(this.camera.position)
    this.startTarget.copy(this.controls.target)

    // 目标位置：在物体前方偏上的位置
    this.targetPos.copy(worldPosition).add(new THREE.Vector3(distance * 0.6, distance * 0.4, distance * 0.8))
    this.targetLookAt.copy(worldPosition)

    this.progress = 0
    this.isAnimating = true
    // 禁用用户控制，避免动画期间冲突
    this.controls.enabled = false
  }

  // 恢复到初始视角
  resetToOverview() {
    this.focusOn(new THREE.Vector3(0, 0, 0), 5)
  }

  update(delta) {
    if (!this.isAnimating) return

    this.progress += delta / this.duration
    if (this.progress >= 1) {
      this.progress = 1
      this.isAnimating = false
      this.controls.enabled = true
    }

    // cubic easeInOut 让相机先加速再减速
    const t = this.progress < 0.5
      ? 4 * this.progress ** 3
      : 1 - Math.pow(-2 * this.progress + 2, 3) / 2

    // 插值相机位置和观察目标
    this.camera.position.lerpVectors(this.startPos, this.targetPos, t)
    this.controls.target.lerpVectors(this.startTarget, this.targetLookAt, t)
  }
}
```

**设计要点**：动画期间禁用 OrbitControls，动画结束后重新启用。否则用户的拖拽输入会和动画插值"打架"，导致相机抖动。

## 拆解动画系统

```javascript
class DisassemblyAnimation {
  constructor(product) {
    this.product = product
    this.isPlaying = false
    this.progress = 0
    this.duration = 1.5
    this.direction = 1       // 1 = 拆解，-1 = 组装
    this.positions = new Map() // 记录原始位置
  }

  play() {
    if (this.isPlaying) return
    // 首次播放时记录各部件原始位置
    for (const [name, part] of this.product.parts) {
      this.positions.set(name, part.position.clone())
    }
    this.isPlaying = true
    // 根据当前进度决定方向：未拆则拆，已拆则装
    this.direction = this.progress < 0.5 ? 1 : -1
  }

  update(delta) {
    if (!this.isPlaying) return

    // 更新进度（0 → 1 或 1 → 0）
    this.progress = Math.max(0, Math.min(1,
      this.progress + (delta / this.duration) * this.direction
    ))

    // cubic easeInOut 缓动
    const t = this.progress < 0.5
      ? 4 * this.progress ** 3
      : 1 - Math.pow(-2 * this.progress + 2, 3) / 2

    // 表带向上飘起，同时变透明
    const strap = this.product.getPartByName('strap')
    if (strap && this.positions.has('strap')) {
      strap.position.y = this.positions.get('strap').y + t * 1.5
      strap.material.transparent = true
      strap.material.opacity = 1 - t * 0.3
    }

    // 表冠向右侧滑出
    const crown = this.product.getPartByName('crown')
    if (crown && this.positions.has('crown')) {
      crown.position.x = this.positions.get('crown').x + t * 0.8
    }

    // 进度到达端点时停止
    if (this.progress >= 1 || this.progress <= 0) {
      this.isPlaying = false
    }
  }
}
```

## 背景粒子流场

```javascript
class ParticleField {
  constructor(scene, count = 1500) {
    this.count = count
    this.noise = new PerlinNoise(42) // Perlin 噪声生成器，种子 42
    this.elapsed = 0

    // 预分配顶点位置和颜色数组
    const positions = new Float32Array(count * 3)
    const colors = new Float32Array(count * 3)

    for (let i = 0; i < count; i++) {
      // 随机分布在 20×20×20 的空间内
      positions[i * 3]     = (Math.random() - 0.5) * 20
      positions[i * 3 + 1] = (Math.random() - 0.5) * 20
      positions[i * 3 + 2] = (Math.random() - 0.5) * 20
      // 蓝紫色系，营造科技感
      const c = new THREE.Color().setHSL(0.55 + Math.random() * 0.1, 0.8, 0.6)
      colors[i * 3]     = c.r
      colors[i * 3 + 1] = c.g
      colors[i * 3 + 2] = c.b
    }

    const geometry = new THREE.BufferGeometry()
    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
    geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3))

    this.points = new THREE.Points(geometry, new THREE.PointsMaterial({
      size: 0.04,
      vertexColors: true,
      transparent: true,
      opacity: 0.6,
      blending: THREE.AdditiveBlending, // 叠加混合，粒子重叠处更亮
      depthWrite: false                  // 关闭深度写入，避免透明排序问题
    }))

    scene.add(this.points)
  }

  update(delta) {
    this.elapsed += delta
    const pos = this.points.geometry.getAttribute('position')

    for (let i = 0; i < this.count; i++) {
      const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i)
      // 用 Perlin 噪声生成流动方向
      const angle = this.noise.noise3D(x * 0.1, y * 0.1, this.elapsed * 0.1) * Math.PI * 2

      // 沿噪声方向移动粒子
      pos.setXYZ(i,
        x + Math.cos(angle) * 0.3 * delta,
        y + Math.sin(angle * 0.7) * 0.15 * delta,
        z + Math.sin(angle) * 0.09 * delta
      )

      // 边界回收：超出 ±10 时反弹回来
      if (Math.abs(pos.getX(i)) > 10) pos.setX(i, -pos.getX(i) * 0.9)
      if (Math.abs(pos.getY(i)) > 10) pos.setY(i, -pos.getY(i) * 0.9)
      if (Math.abs(pos.getZ(i)) > 10) pos.setZ(i, -pos.getZ(i) * 0.9)
    }

    pos.needsUpdate = true // 通知 GPU 数据已更新
  }
}
```

## 交互管理器

```javascript
class InteractionManager {
  constructor(renderer, camera) {
    this.raycaster = new THREE.Raycaster()
    this.mouse = new THREE.Vector2()
    this.interactables = []
    this.hoveredObject = null
    this.selectedObject = null
    this.callbacks = { hover: [], select: [], deselect: [] }

    // 使用 pointer 事件同时支持鼠标和触屏
    renderer.domElement.addEventListener('pointermove', (e) => this.onPointerMove(e, camera))
    renderer.domElement.addEventListener('pointerdown', (e) => this.onPointerDown(e, camera))
  }

  // 将屏幕坐标转换为 NDC（-1 到 +1）
  updateMouse(e) {
    this.mouse.x = (e.clientX / innerWidth) * 2 - 1
    this.mouse.y = -(e.clientY / innerHeight) * 2 + 1
  }

  onPointerMove(e, camera) {
    this.updateMouse(e)
    this.raycaster.setFromCamera(this.mouse, camera)
    const hits = this.raycaster.intersectObjects(this.interactables, true)
    const newHovered = hits.length > 0 ? hits[0].object : null

    // 只在 hover 对象变化时触发事件，避免每帧重复触发
    if (newHovered !== this.hoveredObject) {
      if (this.hoveredObject) {
        this.emit('hover', { object: this.hoveredObject, state: 'leave' })
      }
      this.hoveredObject = newHovered
      if (this.hoveredObject) {
        this.emit('hover', { object: this.hoveredObject, state: 'enter' })
      }
    }
  }

  onPointerDown(e, camera) {
    this.updateMouse(e)
    this.raycaster.setFromCamera(this.mouse, camera)
    const hits = this.raycaster.intersectObjects(this.interactables, true)

    // 先取消之前选中的对象
    if (this.selectedObject) {
      this.emit('deselect', { object: this.selectedObject })
      this.selectedObject = null
    }

    // 如果点击到了新对象，触发 select 事件
    if (hits.length > 0) {
      this.selectedObject = hits[0].object
      this.emit('select', { object: this.selectedObject })
    }
  }

  register(object) { this.interactables.push(object) }
  on(event, cb) { if (this.callbacks[event]) this.callbacks[event].push(cb) }
  emit(event, data) { for (const cb of this.callbacks[event]) cb(data) }
}
```

## 模型加载优化

生产环境中，一个未经优化的 glTF 模型可能有几十 MB。以下是三种关键优化手段：

### Draco 压缩

Draco 是 Google 开发的网格压缩库，可以将 glTF 中的几何数据压缩 80%-95%：

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js'

class ModelLoader {
  constructor() {
    this.loader = new GLTFLoader()
    this.dracoLoader = new DRACOLoader()
    // 指向 Draco 解码器的 WASM 文件（通常放在 public 目录下）
    this.dracoLoader.setDecoderPath('/draco/')
    this.loader.setDRACOLoader(this.dracoLoader)
  }

  async load(url, onProgress) {
    return new Promise((resolve, reject) => {
      this.loader.load(url, resolve, onProgress, reject)
    })
  }

  dispose() {
    this.dracoLoader.dispose()
  }
}
```

使用 Draco 前需要用 gltf-pipeline 或 Blender 将模型预压缩：
```bash
# 使用 gltf-pipeline 压缩
npx gltf-pipeline -i model.glb -o model-draco.glb --draco.compressionLevel 7
```

### LOD（Level of Detail）

根据相机距离自动切换不同精度的模型，远处用低面数模型节省 GPU：

```javascript
import * as THREE from 'three'

class LODProductModel {
  constructor(scene) {
    this.lod = new THREE.LOD()
    scene.add(this.lod)
  }

  addLevel(model, distance) {
    this.lod.addLevel(model, distance)
  }

  // LOD 在渲染时自动根据相机距离选择层级
  // 无需手动 update——Three.js 渲染循环会处理
}
```

典型配置：近距离（< 3m）用原始高精度模型，中距离（3-6m）用 50% 面数版本，远距离（> 6m）用 20% 面数版本。

### 渐进式加载

先加载低精度占位模型，再异步替换为高精度版本，用户不会看到空白：

```javascript
class ProgressiveLoader {
  constructor(productModel, loader) {
    this.product = productModel
    this.loader = loader
  }

  async loadProgressive(lowUrl, highUrl) {
    // 第一步：快速加载低精度模型（通常只有几百 KB）
    const lowGltf = await this.loader.load(lowUrl)
    this.product.setModel(lowGltf.scene)

    // 第二步：后台加载高精度模型
    const highGltf = await this.loader.load(highUrl)
    // 替换模型，用户几乎无感知
    this.product.replaceModel(highGltf.scene)
  }
}
```

## 性能监控与降级

```javascript
class PerformanceMonitor {
  constructor() {
    this.fps = 60
    this.frames = 0
    this.lastTime = performance.now()
    this.level = 'high' // 'high' | 'medium' | 'low'
  }

  update() {
    this.frames++
    const now = performance.now()
    if (now - this.lastTime >= 1000) {
      this.fps = this.frames
      this.frames = 0
      this.lastTime = now
      // 根据帧率自动切换画质等级
      this.level = this.fps < 30 ? 'low' : this.fps < 50 ? 'medium' : 'high'
    }
  }

  // 不同等级返回不同的粒子数量
  getParticleCount() {
    return { high: 1500, medium: 800, low: 300 }[this.level]
  }

  // 不同等级返回不同的像素比
  getPixelRatio() {
    return {
      high: Math.min(devicePixelRatio, 2),
      medium: 1.5,
      low: 1
    }[this.level]
  }

  // 不同等级决定是否开启阴影
  shouldCastShadows() {
    return this.level !== 'low'
  }
}
```

## 常见误区

1. **所有系统共享同一个 clock delta**：物理引擎需要固定步长（如 1/60 秒），直接用 `clock.getDelta()` 的可变步长会导致物理模拟不稳定。应该用累加器模式：`accumulator += delta; while (accumulator >= fixedStep) { physics.update(fixedStep); accumulator -= fixedStep }`。

2. **粒子系统深度写入导致透明排序问题**：应设置 `depthWrite: false`，同时使用 `AdditiveBlending` 让重叠粒子自然融合。

3. **移动端不降级直接上线**：1500 粒子 + 物理引擎在中低端手机上会卡顿。必须有帧率检测和自动降级机制，或者在初始化时根据 `navigator.hardwareConcurrency` 预判设备能力。

4. **交互和 OrbitControls 冲突**：拖拽物体时必须禁用 OrbitControls，否则会同时旋转相机和拖拽物体。更稳妥的做法是用状态机管理：`idle → dragging_object → orbiting_camera`。

5. **忘记处理模型加载失败**：网络超时、文件损坏、WebGL 上下文丢失都可能发生。必须有 try/catch 和用户友好的错误提示，而不是让页面白屏。

6. **环境贴图分辨率过高**：4K HDR 环境贴图占用大量显存。产品展示用 1024×512 或 2048×1024 已经足够，PMREM 会自动生成各级 mipmap。

7. **每次 resize 都重新创建渲染器**：只需调用 `renderer.setSize()` 和 `camera.updateProjectionMatrix()` 即可。重建渲染器会导致 WebGL 上文丢失，所有 GPU 资源（纹理、Buffer）需要重新上传。

## 工程建议

1. **使用 EventBus 解耦系统间通信**：动画系统不直接引用交互系统。当用户点击部件时，交互系统发出 `part:select` 事件，动画系统和 UI 系统各自监听并响应。这样任意系统都可以独立替换或移除。

2. **懒加载 glTF 模型**：首屏只加载低精度模型（或占位几何体），用户交互后再加载高精度版本。配合 `Suspense`（React）或 `v-if`（Vue）可以实现无缝过渡。

3. **生产环境使用 Draco 压缩**：glTF 模型体积减少 80%。配合 gzip 传输，一个 20MB 的手表模型可以压缩到 2MB 以内。注意：Draco 解码在主线程会阻塞，大量模型应使用 Web Worker 版本的解码器。

4. **添加 loading 进度条**：使用 GLTFLoader 的 `onProgress` 回调。注意 `event.loaded / event.total` 只反映下载进度，不包括解析和上传 GPU 的时间。解析大模型可能额外花费 1-3 秒。

5. **使用 `renderer.info` 监控 GPU 状态**：`renderer.info.memory` 显示几何体和纹理数量，`renderer.info.render` 显示 draw call 数量。如果 draw call 持续增长，说明有资源泄漏。

6. **模型命名规范**：在 Blender/3ds Max 中就约定好部件命名（如 `watch_strap`、`watch_dial`），比在代码中用正则匹配可靠得多。命名规范是 3D 项目中最容易被忽视但影响最大的工程实践。

7. **使用 `renderer.compile()` 预编译着色器**：在模型加载完成后调用 `renderer.compile(scene, camera)`，可以避免首次渲染时的卡顿（着色器编译发生在第一次使用时）。这对产品展示尤为重要——用户旋转模型时不应当遇到突然掉帧。

## 小结

3D 产品展示页面是多种技术的综合应用。核心架构是：SceneManager 管理渲染循环，各系统通过注册机制统一 update，通过事件机制解耦通信。性能适配是关键——根据帧率动态调整粒子数量、像素比。

关键决策回顾：
- **FOV 40°** 而非默认 75°：产品展示需要"长焦压缩"效果，避免广角畸变
- **三点光照 + 环境贴图**：金属材质必须有环境反射，否则看起来像塑料
- **相机动画系统**：点击部件时自动聚焦，而不是只高亮——这能大幅提升用户体验
- **Draco 压缩 + LOD + 渐进加载**：三者组合可以把 20MB 的模型做到 2 秒内可见
- **帧率驱动降级**：不是"移动端关特效"的二元方案，而是根据实际帧率动态调整

**答案**：

```javascript
const strap = product.getPartByName('strap')
const presets = {
  metal: { color: new THREE.Color(0xc0c0c0), metalness: 0.9, roughness: 0.1 },
  rubber: { color: new THREE.Color(0x2c3e50), metalness: 0.0, roughness: 0.8 },
  leather: { color: new THREE.Color(0x8b4513), metalness: 0.1, roughness: 0.6 }
}
let currentTween = null

function switchMaterial(name, duration = 0.5) {
  const target = presets[name]
  if (!target) return
  if (currentTween) cancelAnimationFrame(currentTween)

  const mat = strap.material
  const startColor = mat.color.clone()
  const startMetalness = mat.metalness
  const startRoughness = mat.roughness
  const t0 = performance.now()

  function tween() {
    const elapsed = (performance.now() - t0) / 1000 / duration
    const t = Math.min(elapsed, 1)
    // easeInOutQuad
    const e = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2

    mat.color.lerpColors(startColor, target.color, e)
    mat.metalness = startMetalness + (target.metalness - startMetalness) * e
    mat.roughness = startRoughness + (target.roughness - startRoughness) * e

    if (t < 1) currentTween = requestAnimationFrame(tween)
  }
  tween()
}

document.getElementById('btn-sport').onclick = () => switchMaterial('rubber')
document.getElementById('btn-classic').onclick = () => switchMaterial('leather')
```

**要点**：lerpColors 实现颜色平滑过渡；metalness 和 roughness 同步插值避免材质突变。

### 练习二

**思路**：为每个部件定义起始位置和延迟时间，setTimeout 依次启动 tween 动画。

**答案**：

```javascript
const assembly = [
  { name: 'dial', from: new THREE.Vector3(0, 5, 0), delay: 0 },
  { name: 'strap', from: new THREE.Vector3(0, 0, 3), delay: 0.5 },
  { name: 'crown', from: new THREE.Vector3(3, 0, 0), delay: 1.1 }
]
const targets = new Map()

function initAssembly() {
  for (const cfg of assembly) {
    const part = product.getPartByName(cfg.name)
    if (!part) continue
    // 记录目标位置，将部件移到起始位置并隐藏
    targets.set(cfg.name, part.position.clone())
    part.position.copy(cfg.from)
    part.visible = false
  }
}

function playAssembly() {
  for (const cfg of assembly) {
    const part = product.getPartByName(cfg.name)
    if (!part) continue
    const target = targets.get(cfg.name)
    const startPos = cfg.from.clone()
    const duration = 0.8

    setTimeout(() => {
      part.visible = true
      const t0 = performance.now()

      function animate() {
        const t = Math.min((performance.now() - t0) / 1000 / duration, 1)
        // cubic easeOut：快速到达后减速
        part.position.lerpVectors(startPos, target, 1 - Math.pow(1 - t, 3))
        // 到达前 10% 进度内添加弹跳效果
        if (t >= 0.9) {
          part.position.y += Math.sin((t - 0.9) / 0.1 * Math.PI) * 0.05
        }
        if (t < 1) {
          requestAnimationFrame(animate)
        } else {
          part.position.copy(target)
        }
      }
      animate()
    }, cfg.delay * 1000)
  }
}

initAssembly()
setTimeout(playAssembly, 500)
```

**要点**：cubic easeOut 让部件快速到达后减速；到达前 10% 进度内添加 sin 弹跳效果。

### 练习三

**思路**：监听 touchmove 事件，计算两指连线角度差，映射为 Y 轴旋转量。松手后用惯性系数衰减。

**答案**：

```javascript
class TouchRotation {
  constructor(domElement, target) {
    this.target = target
    this.rotationY = 0
    this.angularVelocity = 0
    this.friction = 0.95       // 惯性衰减系数
    this.lastAngle = null
    this.isDragging = false

    domElement.addEventListener('touchstart', (e) => this.onTouchStart(e), { passive: false })
    domElement.addEventListener('touchmove', (e) => this.onTouchMove(e), { passive: false })
    domElement.addEventListener('touchend', () => this.onTouchEnd())
  }

  getAngle(touches) {
    const dx = touches[1].clientX - touches[0].clientX
    const dy = touches[1].clientY - touches[0].clientY
    return Math.atan2(dy, dx)
  }

  onTouchStart(e) {
    if (e.touches.length < 2) return
    e.preventDefault()
    this.isDragging = true
    this.lastAngle = this.getAngle(e.touches)
    this.angularVelocity = 0
  }

  onTouchMove(e) {
    if (!this.isDragging || e.touches.length < 2) return
    e.preventDefault()
    const angle = this.getAngle(e.touches)
    const delta = angle - this.lastAngle
    this.rotationY += delta
    this.angularVelocity = delta
    this.lastAngle = angle
  }

  onTouchEnd() {
    this.isDragging = false
    // 松手后保留最后的角速度，update 中做衰减
  }

  update(delta) {
    // 非拖拽时应用惯性
    if (!this.isDragging) {
      this.rotationY += this.angularVelocity
      this.angularVelocity *= this.friction
      if (Math.abs(this.angularVelocity) < 0.001) this.angularVelocity = 0
    }
    this.target.rotation.y = this.rotationY
  }
}
```

**要点**：`atan2` 计算手指连线角度；惯性用指数衰减（每帧乘以 friction），手感自然且实现简单。

### 练习四

**思路**：定义光照参数预设，使用 requestAnimationFrame 在 1 秒内线性插值过渡。

**答案**：

```javascript
  daylight: { color: new THREE.Color(0xffffff), intensity: 2, fillColor: new THREE.Color(0x8888ff), fillIntensity: 0.5 },
  warm:     { color: new THREE.Color(0xffaa44), intensity: 1.5, fillColor: new THREE.Color(0xff8833), fillIntensity: 0.4 },
  cool:     { color: new THREE.Color(0x6688ff), intensity: 1.8, fillColor: new THREE.Color(0x4466cc), fillIntensity: 0.6 }

function transitionLighting(keyLight, fillLight, presetName, duration = 1.0) {
  const target = lightPresets[presetName]
  if (!target) return

  // 记录起始状态
  const startKeyColor = keyLight.color.clone()
  const startKeyIntensity = keyLight.intensity
  const startFillColor = fillLight.color.clone()
  const startFillIntensity = fillLight.intensity
  const t0 = performance.now()

  function tween() {
    const t = Math.min((performance.now() - t0) / 1000 / duration, 1)
    // easeInOutCubic
    const e = t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2

    keyLight.color.lerpColors(startKeyColor, target.color, e)
    keyLight.intensity = startKeyIntensity + (target.intensity - startKeyIntensity) * e
    fillLight.color.lerpColors(startFillColor, target.fillColor, e)
    fillLight.intensity = startFillIntensity + (target.fillIntensity - startFillIntensity) * e

    if (t < 1) requestAnimationFrame(tween)
  }
  tween()
}

// 绑定按钮
document.getElementById('btn-daylight').onclick = () => transitionLighting(keyLight, fillLight, 'daylight')
document.getElementById('btn-warm').onclick = () => transitionLighting(keyLight, fillLight, 'warm')
document.getElementById('btn-cool').onclick = () => transitionLighting(keyLight, fillLight, 'cool')
```

**要点**：光照过渡必须同时插值颜色和强度，否则只变色不变亮度会不自然。使用 easeInOutCubic 让过渡开始和结束都很平滑，中间段有"呼吸感"。
