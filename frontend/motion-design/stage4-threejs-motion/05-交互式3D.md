# 交互式 3D：鼠标交互、手势与物理反馈

## 场景引入

静态的 3D 场景只是"好看"，用户能与之交互才是"好用"。产品 3D 展示页面的核心交互包括：鼠标拖拽旋转模型、点击部件高亮、悬停显示信息、触摸手势操作。这些交互不是简单的事件监听——需要理解射线检测（Raycasting）、坐标变换、触摸协议、以及如何将交互反馈与物理引擎结合产生"触感"。

本课从 Three.js 的 Raycaster 出发，逐步实现鼠标拾取、拖拽旋转、手势操作、物理反馈四层交互能力，并覆盖移动端手势、BVH 加速、触觉反馈和无障碍访问等工程话题。

## Raycaster：射线检测

### 原理

Raycaster 从相机位置发射一条射线，检测与场景中物体的交点。这是 3D 交互的基础。

核心数学：给定屏幕坐标 `(clientX, clientY)`，先归一化到 NDC（Normalized Device Coordinates）范围 `[-1, 1]`，再结合相机的投影矩阵逆变换，得到一条从相机出发、穿过屏幕上该点的射线。

```
屏幕像素 (clientX, clientY)
       ↓ 归一化
NDC (nx, ny) ∈ [-1, 1] × [-1, 1]
       ↓ 相机逆投影
世界空间射线 origin + t × direction
       ↓ 与物体求交
最近交点 → 命中的 Mesh
```

### 基本用法

```javascript
import * as THREE from 'three'

const raycaster = new THREE.Raycaster()
const mouse = new THREE.Vector2()

function getIntersects(event, objects, camera) {
  // 将像素坐标归一化到 [-1, 1]
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1

  // 从相机发射射线
  raycaster.setFromCamera(mouse, camera)

  // 检测交点，第二个参数 true 表示递归检测子对象
  return raycaster.intersectObjects(objects, true)
}
```

`intersectObjects` 的第二个参数 `true` 表示递归检测子对象，对 glTF 模型很重要——glTF 的网格通常挂在子节点上，不递归就检测不到。

### 射线参数说明

```javascript
// Raycaster 构造参数：(origin, direction, near, far)
const raycaster = new THREE.Raycaster(
  new THREE.Vector3(0, 0, 0),   // 射线起点
  new THREE.Vector3(0, 0, -1),  // 射线方向（需归一化）
  0.1,  // near：忽略比这个距离更近的交点
  100   // far：忽略比这个距离更远的交点
)
```

`near` 和 `far` 在交互场景中很有用——比如只允许用户拾取 10 米以内的物体，远处物体即使在射线上也忽略。

### 交点对象结构

`intersectObjects` 返回的每个交点对象包含丰富的信息：

```javascript
const intersects = raycaster.intersectObjects(objects, true)
if (intersects.length > 0) {
  const hit = intersects[0]
  hit.object    // 命中的 Mesh
  hit.point     // 世界坐标中的交点 (Vector3)
  hit.distance  // 射线起点到交点的距离
  hit.face      // 命中的三角面 { a, b, c, normal, materialIndex }
  hit.uv        // 交点在面片上的 UV 坐标
}
```

`uv` 坐标在贴图交互中很有用——比如用户点击 3D 模型的某个区域，可以用 UV 判断点击了贴图的哪个位置。

### 性能注意事项

Raycaster 的时间复杂度是 `O(n × m)`，其中 `n` 是待检测物体数量，`m` 是每个物体的三角面数量。100 个简单 BoxGeometry 没问题，但 10000 个高精度模型就必须优化。后续 BVH 章节会介绍加速方案。

## 鼠标拾取与高亮

```javascript
const meshes = []
for (let i = 0; i < 5; i++) {
  const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(0.8, 0.8, 0.8),
    new THREE.MeshStandardMaterial({ color: 0x3498db })
  )
  mesh.position.set((i - 2) * 1.5, 0, 0)
  scene.add(mesh)
  meshes.push(mesh)
}

let hoveredMesh = null

renderer.domElement.addEventListener('pointermove', (event) => {
  // 清除上一帧的高亮
  if (hoveredMesh) {
    hoveredMesh.material.emissive.setHex(0x000000)
    hoveredMesh = null
  }

  const intersects = getIntersects(event, meshes, camera)
  if (intersects.length > 0) {
    hoveredMesh = intersects[0].object
    hoveredMesh.material.emissive.setHex(0x333333)
    renderer.domElement.style.cursor = 'pointer'
  } else {
    renderer.domElement.style.cursor = 'default'
  }
})
```

高亮的本质是修改材质的 `emissive` 属性——它叠加在基础颜色上，不改变原始颜色，适合做临时视觉反馈。如果需要更强的高亮效果（如轮廓描边），可以使用 OutlinePass 后处理。

```javascript
let selectedMesh = null

renderer.domElement.addEventListener('pointerdown', (event) => {

    infoPanel.style.top = `${-(worldPos.y * 0.5 - 0.5) * innerHeight}px`

```

`position.clone().project(camera)` 将世界坐标转换为 NDC 坐标，再映射回像素位置。注意 `project` 返回的 `z` 值：如果 `z > 1`，说明物体在相机背后，不应显示浮层。

## 拖拽旋转（Trackball 风格）

```javascript
let isDragging = false
let previousMouse = { x: 0, y: 0 }
let targetRotation = { x: 0, y: 0 }
const targetMesh = meshes[0]

renderer.domElement.addEventListener('pointerdown', (e) => {
  if (getIntersects(e, [targetMesh], camera).length > 0) {
    isDragging = true
    previousMouse = { x: e.clientX, y: e.clientY }
  }
})

renderer.domElement.addEventListener('pointermove', (e) => {
  if (!isDragging) return
  // 累积旋转增量
  targetRotation.y += (e.clientX - previousMouse.x) * 0.01
  targetRotation.x += (e.clientY - previousMouse.y) * 0.01
  previousMouse = { x: e.clientX, y: e.clientY }
})

renderer.domElement.addEventListener('pointerup', () => {
  isDragging = false
})

function animate() {
  requestAnimationFrame(animate)
  // 插值平滑旋转
  targetMesh.rotation.x += (targetRotation.x - targetMesh.rotation.x) * 0.1
  targetMesh.rotation.y += (targetRotation.y - targetMesh.rotation.y) * 0.1
  renderer.render(scene, camera)
}
```

`0.01` 是灵敏度系数，`0.1` 是插值系数。灵敏度过高会导致旋转跳动，过低则反应迟钝。插值系数让旋转有"惯性"——松手后物体不会立刻停止，而是缓慢减速。

| 属性 | 作用 | 推荐值 |
|------|------|--------|
| enableDamping | 阻尼惯性 | true |
| dampingFactor | 阻尼强度 | 0.05–0.1 |
| minDistance | 最小缩放距离 | 根据场景 |

| target | 相机注视点 | 物体中心 |

### 自定义相机控制

当 OrbitControls 不能满足需求时（比如需要限制在某个平面内旋转，或需要特定的视角动画），可以自己实现相机控制：

```javascript
class CameraController {
  constructor(camera, domElement) {
    this.camera = camera
    this.domElement = domElement
    this.spherical = new THREE.Spherical(5, Math.PI / 3, 0)
    this.target = new THREE.Vector3()
    this.isDragging = false
    this.previousPointer = { x: 0, y: 0 }

    this.bindEvents()
  }

  bindEvents() {
    this.domElement.addEventListener('pointerdown', (e) => {
      this.isDragging = true
      this.previousPointer = { x: e.clientX, y: e.clientY }
    })

    this.domElement.addEventListener('pointermove', (e) => {
      if (!this.isDragging) return
      const dx = e.clientX - this.previousPointer.x
      const dy = e.clientY - this.previousPointer.y
      this.spherical.theta -= dx * 0.005
      this.spherical.phi = Math.max(0.1, Math.min(Math.PI / 2, this.spherical.phi - dy * 0.005))
      this.previousPointer = { x: e.clientX, y: e.clientY }
    })

    this.domElement.addEventListener('pointerup', () => {
      this.isDragging = false
    })

    this.domElement.addEventListener('wheel', (e) => {
      this.spherical.radius = Math.max(2, Math.min(15, this.spherical.radius + e.deltaY * 0.01))
    })
  }

  update() {
    const pos = new THREE.Vector3().setFromSpherical(this.spherical).add(this.target)
    this.camera.position.copy(pos)
    this.camera.lookAt(this.target)
  }
}
```

球坐标（Spherical）比直接操作欧拉角更直观：`radius` 控制距离，`phi` 控制仰角，`theta` 控制方位角。

## 触摸手势处理

```javascript
class TouchHandler {
  constructor(domElement) {
    this.touches = new Map()
    this.onRotate = null
    this.onPinch = null

    domElement.addEventListener('touchstart', (e) => {
      e.preventDefault()
      for (const t of e.changedTouches) {
        this.touches.set(t.identifier, { x: t.clientX, y: t.clientY })
      }
    }, { passive: false })

    domElement.addEventListener('touchmove', (e) => {
      e.preventDefault()
      const arr = Array.from(e.touches)

      // 单指旋转
      if (arr.length === 1) {
        const prev = this.touches.get(arr[0].identifier)
        if (prev && this.onRotate) {
          this.onRotate(arr[0].clientX - prev.x, arr[0].clientY - prev.y)
        }
        this.touches.set(arr[0].identifier, { x: arr[0].clientX, y: arr[0].clientY })
      }

      // 双指缩放
      if (arr.length === 2) {
        const [t1, t2] = arr
        const p1 = this.touches.get(t1.identifier)
        const p2 = this.touches.get(t2.identifier)
        if (p1 && p2 && this.onPinch) {
          const currentDist = Math.hypot(t1.clientX - t2.clientX, t1.clientY - t2.clientY)
          const prevDist = Math.hypot(p1.x - p2.x, p1.y - p2.y)
          this.onPinch(currentDist / prevDist)
        }
        this.touches.set(t1.identifier, { x: t1.clientX, y: t1.clientY })
        this.touches.set(t2.identifier, { x: t2.clientX, y: t2.clientY })
      }
    }, { passive: false })

    domElement.addEventListener('touchend', (e) => {
      for (const t of e.changedTouches) {
        this.touches.delete(t.identifier)
      }
    })
  }
}
```

## 自定义手势识别：滑动与长按

除了基本的旋转和缩放，实际产品中经常需要识别"滑动"和"长按"等自定义手势。

### 滑动手势（Swipe）

```javascript
class SwipeRecognizer {
  constructor(domElement, options = {}) {
    this.domElement = domElement
    this.threshold = options.threshold || 50   // 最小滑动距离（像素）
    this.timeout = options.timeout || 300       // 最大滑动时间（毫秒）
    this.startPos = null
    this.startTime = 0
    this.onSwipe = options.onSwipe || (() => {})

    domElement.addEventListener('touchstart', (e) => {
      const t = e.touches[0]
      this.startPos = { x: t.clientX, y: t.clientY }
      this.startTime = Date.now()
    }, { passive: true })

    domElement.addEventListener('touchend', (e) => {
      if (!this.startPos) return
      const t = e.changedTouches[0]
      const dx = t.clientX - this.startPos.x
      const dy = t.clientY - this.startPos.y
      const dist = Math.hypot(dx, dy)
      const elapsed = Date.now() - this.startTime

      if (dist >= this.threshold && elapsed <= this.timeout) {
        const direction = Math.abs(dx) > Math.abs(dy)
          ? (dx > 0 ? 'right' : 'left')
          : (dy > 0 ? 'down' : 'up')
        this.onSwipe({ direction, distance: dist, velocity: dist / elapsed })
      }
      this.startPos = null
    }, { passive: true })
  }
}

// 使用
const swiper = new SwipeRecognizer(renderer.domElement, {
  onSwipe: ({ direction, velocity }) => {
    if (direction === 'left') rotateToNextModel()
    if (direction === 'right') rotateToPrevModel()
  }
})
```

### 长按手势（Long Press）

```javascript
class LongPressRecognizer {
  constructor(domElement, options = {}) {
    this.delay = options.delay || 500           // 长按触发时间（毫秒）
    this.moveTolerance = options.tolerance || 10 // 允许的移动距离
    this.onLongPress = options.onLongPress || (() => {})
    this.timer = null
    this.startPos = null

    domElement.addEventListener('touchstart', (e) => {
      const t = e.touches[0]
      this.startPos = { x: t.clientX, y: t.clientY }
      this.timer = setTimeout(() => {
        this.onLongPress({ x: this.startPos.x, y: this.startPos.y })
        this.timer = null
      }, this.delay)
    }, { passive: true })

    domElement.addEventListener('touchmove', (e) => {
      if (!this.timer) return
      const t = e.touches[0]
      const dist = Math.hypot(t.clientX - this.startPos.x, t.clientY - this.startPos.y)
      if (dist > this.moveTolerance) {
        clearTimeout(this.timer)
        this.timer = null
      }
    }, { passive: true })

    domElement.addEventListener('touchend', () => {
      if (this.timer) { clearTimeout(this.timer); this.timer = null }
    }, { passive: true })
  }
}

// 使用：长按物体弹出详细信息
const longPresser = new LongPressRecognizer(renderer.domElement, {
  onLongPress: ({ x, y }) => {
    const hits = getIntersects({ clientX: x, clientY: y }, meshes, camera)
    if (hits.length > 0) {
      showDetailedInfo(hits[0].object, x, y)
    }
  }
})
```

长按识别的关键是 `moveTolerance`——用户手指在按下期间不可避免会有微小抖动，允许 10 像素的误差能避免误取消。同时 `touchend` 必须清理定时器，否则松手后仍会触发。

## 物理引擎拖拽交互

```javascript
import * as CANNON from 'cannon-es'

const world = new CANNON.World({ gravity: new CANNON.Vec3(0, -9.82, 0) })
const dragPlane = new THREE.Plane()
const intersection = new THREE.Vector3()
let dragState = null

renderer.domElement.addEventListener('pointerdown', (e) => {
  const intersects = getIntersects(e, physicsMeshes, camera)
  if (intersects.length === 0) return

  const hitMesh = intersects[0].object
  const hitBody = meshBodyMap.get(hitMesh)
  if (!hitBody) return

  // 拖拽时设为 KINEMATIC：不被重力影响，但参与碰撞
  hitBody.type = CANNON.Body.KINEMATIC
  hitBody.velocity.set(0, 0, 0)
  hitBody.angularVelocity.set(0, 0, 0)

  // 用相机方向构造拖拽平面
  dragPlane.setFromNormalAndCoplanarPoint(
    camera.getWorldDirection(new THREE.Vector3()).negate(),
    intersects[0].point
  )

  dragState = {
    mesh: hitMesh,
    body: hitBody,
    offset: hitMesh.position.clone().sub(intersects[0].point)
  }
})

renderer.domElement.addEventListener('pointermove', (e) => {
  if (!dragState) return
  mouse.x = (e.clientX / innerWidth) * 2 - 1
  mouse.y = -(e.clientY / innerHeight) * 2 + 1
  raycaster.setFromCamera(mouse, camera)

  if (raycaster.ray.intersectPlane(dragPlane, intersection)) {
    dragState.body.position.set(...intersection.add(dragState.offset).toArray())
  }
})

renderer.domElement.addEventListener('pointerup', () => {
  if (dragState) {
    // 释放后恢复 DYNAMIC，立即受重力影响
    dragState.body.type = CANNON.Body.DYNAMIC
    dragState = null
  }
})
```

## BVH 加速射线检测

当场景中有大量三角面时（如高精度 3D 扫描模型），默认的 Raycaster 逐面检测会非常慢。BVH（Bounding Volume Hierarchy，层次包围体）将三角面组织成树结构，射线先与大的包围盒做粗检测，再逐层缩小范围。

### 使用 three-mesh-bvh

```javascript
import { computeBoundsTree, disposeBoundsTree, acceleratedRaycast } from 'three-mesh-bvh'

// 扩展 BufferGeometry，使其支持 BVH
THREE.BufferGeometry.prototype.computeBoundsTree = computeBoundsTree
THREE.BufferGeometry.prototype.disposeBoundsTree = disposeBoundsTree
THREE.Mesh.prototype.raycast = acceleratedRaycast

// 构建 BVH（只需一次，耗时与面数成正比）
const geometry = new THREE.BoxGeometry(1, 1, 1, 100, 100, 100)
geometry.computeBoundsTree()

const mesh = new THREE.Mesh(geometry, new THREE.MeshStandardMaterial())
scene.add(mesh)
```

构建 BVH 后，`raycaster.intersectObjects` 会自动使用树结构加速，无需改变调用方式。性能提升取决于模型面数：

| 三角面数 | 默认 Raycaster | BVH 加速 | 提升倍数 |
|----------|---------------|----------|---------|
| 1,000 | ~0.5ms | ~0.1ms | 5× |
| 10,000 | ~5ms | ~0.2ms | 25× |
| 100,000 | ~50ms | ~0.5ms | 100× |
| 1,000,000 | ~500ms | ~1ms | 500× |

### 动态物体的 BVH

BVH 构建后是静态的——如果物体变形（如骨骼动画），需要每帧重建或使用 SAH（Surface Area Heuristic）优化：

```javascript
// 对于频繁变形的物体，使用更小的 BVH 粒度
geometry.computeBoundsTree({ strategy: 'CENTER', maxDepth: 20 })

// 或者只对静态环境用 BVH，动态物体用默认检测
const staticBVHMeshes = [ground, walls, furniture]
const dynamicMeshes = [character, weapon]

function getIntersectsOptimized(event, camera) {
  // 先用 BVH 检测静态物体
  const staticHits = getIntersects(event, staticBVHMeshes, camera)
  // 再检测动态物体
  const dynamicHits = getIntersects(event, dynamicMeshes, camera)
  // 合并并按距离排序
  return [...staticHits, ...dynamicHits].sort((a, b) => a.distance - b.distance)
}
```

## 弹性反馈动画

```javascript
class SpringFeedback {
  constructor(object, restPos, stiffness = 0.1, damping = 0.8) {
    this.object = object
    this.restPos = restPos.clone()
    this.stiffness = stiffness
    this.damping = damping
    this.velocity = new THREE.Vector3()
  }

  update() {
    // 弹簧力：F = -k * (x - x0)
    const displacement = this.object.position.clone().sub(this.restPos)
    this.velocity.add(displacement.multiplyScalar(-this.stiffness))
    this.velocity.multiplyScalar(this.damping)
    this.object.position.add(this.velocity)
  }
}
```

`stiffness` 控制弹性强度——值越大回弹越快；`damping` 控制阻尼——值越小衰减越慢、振荡越明显。典型组合：`stiffness=0.1, damping=0.8` 产生轻柔的弹性效果；`stiffness=0.3, damping=0.6` 产生更明显的弹跳。

## 触觉反馈（Haptic Feedback）

在移动设备上，视觉和听觉之外的第三种反馈通道是触觉——通过振动马达让用户"摸到"交互。

### Vibration API

```javascript
class HapticFeedback {
  static light() {
    // 轻触反馈：10ms
    if (navigator.vibrate) navigator.vibrate(10)
  }

  static medium() {
    // 中等反馈：20ms
    if (navigator.vibrate) navigator.vibrate(20)
  }

  static heavy() {
    // 重反馈：40ms
    if (navigator.vibrate) navigator.vibrate(40)
  }

  static pattern() {
    // 模式反馈：短-长-短
    if (navigator.vibrate) navigator.vibrate([10, 50, 30])
  }

  static success() {
```

### 触觉反馈的注意事项

1. **iOS Safari 不支持 `navigator.vibrate`**——需要用 Web Audio API 模拟，或使用 iOS 的 Core Haptics（仅限原生 App）
2. **不要滥用**——只有有意义的交互节点才给触觉反馈，频繁振动会让用户烦躁
3. **强度递进**——轻触 < 碰撞 < 选中 < 错误，形成一致的触觉语言
4. **与视觉同步**——振动必须和视觉反馈同时发生，延迟超过 50ms 用户会感觉"不对劲"

```javascript
class KeyboardInteraction {
  constructor(camera, controls, interactables) {
    this.camera = camera
    this.controls = controls
    this.interactables = interactables
    this.focusIndex = -1

    document.addEventListener('keydown', (e) => {
      switch (e.key) {
        case 'Tab':
          e.preventDefault()
          this.cycleFocus(e.shiftKey ? -1 : 1)
          break
        case 'Enter':
        case ' ':
          e.preventDefault()
          this.selectFocused()
          break
        case 'Escape':
          this.clearSelection()
          break
      }
    })
  }

  cycleFocus(direction) {
    // 清除当前高亮
    if (this.focusIndex >= 0) {
      this.interactables[this.focusIndex].material.emissive.setHex(0)
    }

    this.focusIndex += direction
    if (this.focusIndex >= this.interactables.length) this.focusIndex = 0
    if (this.focusIndex < 0) this.focusIndex = this.interactables.length - 1

    // 高亮并聚焦
    const focused = this.interactables[this.focusIndex]
    focused.material.emissive.setHex(0x333333)

    // 相机平滑看向聚焦物体
    this.controls.target.copy(focused.position)
    this.controls.update()

    // 更新 ARIA
    focused.element?.setAttribute('aria-selected', 'true')
  }

  selectFocused() {
    if (this.focusIndex >= 0) {
      selectObject(this.interactables[this.focusIndex])
    }
  }

  clearSelection() {
    if (this.focusIndex >= 0) {
      this.interactables[this.focusIndex].material.emissive.setHex(0)
      this.focusIndex = -1
    }
  }
}
```

## 常见误区

1. **Raycaster 不更新鼠标坐标**：每次检测时必须重新计算 `mouse.x` 和 `mouse.y`，不能复用上一次的值。射线方向完全依赖坐标，旧坐标意味着射线指向错误方向。

2. **intersectObjects 忘记递归**：glTF 模型的网格在子节点中，不传 `true` 就检测不到。如果发现模型"点不中"，先检查是否遗漏了递归参数。

3. **触摸事件不 preventDefault**：会导致页面滚动、缩放等默认行为干扰 3D 交互。但要注意 `passive` 选项——在 Chrome 中 `touchstart` 默认是 `passive: true`，必须显式传 `{ passive: false }` 才能在回调中调用 `preventDefault`。

4. **拖拽时物体穿透其他物体**：应设为 KINEMATIC 类型。DYNAMIC 类型在拖拽时会与重力和碰撞力"抢控制权"，导致物体抖动或穿透。

5. **悬停浮层不检查 z 值**：物体在相机后面时 `project()` 返回的 `z > 1`，需要检查 `screenPos.z < 1` 才显示浮层，否则会出现"背后的物体也有浮层"的诡异现象。

6. **Raycaster 的 near/far 设置不当**：`near` 太小可能导致相机内部的物体被拾取；`far` 太大会降低精度。应根据场景尺寸合理设置。

7. **触摸事件不清理 Map**：`touchend` 必须删除对应的触摸点，否则 Map 会无限增长。特别是多指操作时，遗漏清理会导致"幽灵触摸"。

8. **物理拖拽不归零速度**：切换到 KINEMATIC 前必须 `velocity.set(0, 0, 0)` 和 `angularVelocity.set(0, 0, 0)`，否则残留速度会在恢复 DYNAMIC 时瞬间爆发。

## 工程建议

1. **交互层与渲染层分离**：交互逻辑放在独立的 `InteractionManager` 中，不要和渲染循环混在一起。这样可以单独测试交互逻辑，也方便切换输入方式（鼠标/触摸/手柄）。

2. **移动端使用 passive: false 的 touch 事件**：确保 `preventDefault` 生效。但只在需要阻止默认行为的事件上使用——`touchstart` 如果只需要记录位置，可以用 `passive: true` 提升性能。

3. **大量可交互对象使用空间索引**：八叉树或 BVH 加速 Raycaster。如果场景有 100+ 个可交互对象，逐个检测会明显掉帧。BVH 适合高面数模型，八叉树适合多物体场景。

4. **拖拽时禁用 OrbitControls**：`controls.enabled = false`。否则拖拽物体会同时旋转相机，体验非常混乱。`pointerup` 时记得恢复。

5. **使用 debounce 处理 resize**：避免频繁触发。resize 会改变相机宽高比和渲染器尺寸，高频触发会导致性能抖动。

6. **统一使用 Pointer Events**：不要混用 `mousedown/touchstart` 和 `pointerdown`。Pointer Events 统一了鼠标、触摸和触控笔输入，自动处理 `pointerId`，代码更简洁也更不容易出 bug。

7. **交互状态用有限状态机管理**：当交互模式增多（悬停、选中、拖拽、长按）时，状态之间会有互斥关系。用状态机（如 `idle → hovering → selected → dragging`）避免状态混乱。

8. **为交互对象设置 userData**：在 Mesh 上挂载业务数据（名称、ID、类别），避免在交互回调中通过索引反查业务数据。`mesh.userData = { id: 'part-001', name: '引擎盖', category: 'body' }`。

## 小结

3D 交互系统的核心是 Raycaster——将 2D 屏幕坐标转换为 3D 射线。在此基础上实现拾取、高亮、拖拽、手势四层交互能力。物理引擎的加入让交互有"重量感"。触摸手势需要处理单指/双指的不同语义。BVH 加速让大规模模型的射线检测成为可能。移动端交互需要重新映射手势、优化触摸目标尺寸、适配性能。触觉反馈提供了视觉之外的第三维度。无障碍设计让 3D 体验对所有用户可用。交互层应与渲染层解耦。

### 练习二

**思路**：Cannon.js 创建物理世界，Raycaster + 拖拽平面实现鼠标控制。拖拽时 KINEMATIC，释放时 DYNAMIC。

**答案**：

```javascript

const groundBody = new CANNON.Body({ mass: 0, shape: new CANNON.Plane() })
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0)
world.addBody(groundBody)

const boxBodies = []
const boxMeshes = []
const boxSize = 0.6

for (let i = 0; i < 3; i++) {
  const body = new CANNON.Body({
    mass: 1,
    shape: new CANNON.Box(new CANNON.Vec3(0.3, 0.3, 0.3)),
    position: new CANNON.Vec3(0, boxSize * i + 0.3, 0)
  })
  world.addBody(body)
  boxBodies.push(body)

  const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(boxSize, boxSize, boxSize),
    new THREE.MeshStandardMaterial({
      color: new THREE.Color().setHSL(i / 3, 0.7, 0.5),
      transparent: true
    })
  )
  scene.add(mesh)
  boxMeshes.push(mesh)
}

const meshBodyMap = new Map()
boxMeshes.forEach((m, i) => meshBodyMap.set(m, boxBodies[i]))

let dragState = null
const dragPlane = new THREE.Plane(new THREE.Vector3(0, 1, 0), 0)

renderer.domElement.addEventListener('pointerdown', (e) => {
  const hits = getIntersects(e, boxMeshes, camera)
  if (hits.length === 0) return
  const body = meshBodyMap.get(hits[0].object)
  body.type = CANNON.Body.KINEMATIC
  body.velocity.set(0, 0, 0)
  body.angularVelocity.set(0, 0, 0)
  hits[0].object.material.opacity = 0.5
  dragState = { mesh: hits[0].object, body }
})

renderer.domElement.addEventListener('pointermove', (e) => {
  if (!dragState) return
  mouse.x = (e.clientX / innerWidth) * 2 - 1
  mouse.y = -(e.clientY / innerHeight) * 2 + 1
  raycaster.setFromCamera(mouse, camera)
  const pt = new THREE.Vector3()
  if (raycaster.ray.intersectPlane(dragPlane, pt)) {
    dragState.body.position.set(pt.x, 0.3, pt.z)
  }
})

renderer.domElement.addEventListener('pointerup', () => {
  if (!dragState) return
  dragState.body.type = CANNON.Body.DYNAMIC
  dragState.mesh.material.opacity = 1
  dragState = null
})
```

**要点**：KINEMATIC 类型让物体不被物理引擎计算运动但保持碰撞；释放后恢复 DYNAMIC 立即受重力。

### 练习三

**思路**：组合 SwipeRecognizer、TouchHandler 和 LongPressRecognizer 三个手势识别器。用 GSAP 或 Tween 做模型切换的平滑过渡动画。

**答案**：

```javascript
const productModels = [modelA, modelB, modelC]
let currentIndex = 0
const container = new THREE.Group()
scene.add(container)
container.add(productModels[0])

// 滑动切换
const swiper = new SwipeRecognizer(renderer.domElement, {
  onSwipe: ({ direction, velocity }) => {
    if (direction === 'left') switchModel(1)
    if (direction === 'right') switchModel(-1)
  }
})

function switchModel(direction) {
  HapticFeedback.light()
  const outgoing = productModels[currentIndex]
  currentIndex = (currentIndex + direction + productModels.length) % productModels.length
  const incoming = productModels[currentIndex]

  // 淡出旧模型
  gsap.to(outgoing.position, {
    x: -direction * 5,
    duration: 0.4,
    ease: 'power2.in',
    onComplete: () => container.remove(outgoing)
  })

  // 淡入新模型
  incoming.position.set(direction * 5, 0, 0)
  incoming.scale.setScalar(0.8)
  container.add(incoming)
  gsap.to(incoming.position, { x: 0, duration: 0.4, ease: 'power2.out' })
  gsap.to(incoming.scale, { x: 1, y: 1, z: 1, duration: 0.4, ease: 'back.out(1.7)' })

  announceToScreenReader(`当前产品：${incoming.userData.name}，第 ${currentIndex + 1} 个，共 ${productModels.length} 个`)
}

// 双指缩放
const touchHandler = new TouchHandler(renderer.domElement)
touchHandler.onPinch = (scale) => {
  const current = container.scale.x
  container.scale.setScalar(Math.max(0.5, Math.min(3, current * scale)))
}

// 长按显示详情
const longPresser = new LongPressRecognizer(renderer.domElement, {
  onLongPress: ({ x, y }) => {
    HapticFeedback.heavy()
    const model = productModels[currentIndex]
    showProductDetail(model.userData, x, y)
  }
})
```

**要点**：`switchModel` 同时处理进出动画，`direction` 参数决定进出方向相反；`currentIndex` 用取模实现循环切换；长按的 `moveTolerance` 防止滑动误触。

### 练习四

**思路**：加载高精度模型后，分别记录有无 BVH 时的射线检测耗时。用 `performance.now()` 测量单次检测时间。

**答案**：

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js'
import { computeBoundsTree, disposeBoundsTree, acceleratedRaycast } from 'three-mesh-bvh'

// 扩展 Three.js 原型
THREE.BufferGeometry.prototype.computeBoundsTree = computeBoundsTree
THREE.BufferGeometry.prototype.disposeBoundsTree = disposeBoundsTree
THREE.Mesh.prototype.raycast = acceleratedRaycast

const loader = new GLTFLoader()
let testMesh = null
let bvhEnabled = false

loader.load('high-poly-model.glb', (gltf) => {
  testMesh = gltf.scene.children[0]
  scene.add(testMesh)

  // 构建 BVH
  testMesh.geometry.computeBoundsTree()
  bvhEnabled = true
  runBenchmark()
})

function runBenchmark() {
  const iterations = 1000
  const tempRaycaster = new THREE.Raycaster()
  const directions = []

  // 预生成随机射线方向
  for (let i = 0; i < iterations; i++) {
    directions.push(new THREE.Vector3(
      Math.random() * 2 - 1,
      Math.random() * 2 - 1,
      Math.random() * 2 - 1
    ).normalize())
  }

  // 测试 BVH 模式
  const startBVH = performance.now()
  for (const dir of directions) {
    tempRaycaster.set(new THREE.Vector3(0, 5, 0), dir)
    tempRaycaster.intersectObject(testMesh, true)
  }
  const bvhTime = performance.now() - startBVH

  // 禁用 BVH 重新测试
  testMesh.geometry.disposeBoundsTree()
  const startDefault = performance.now()
  for (const dir of directions) {
    tempRaycaster.set(new THREE.Vector3(0, 5, 0), dir)
    tempRaycaster.intersectObject(testMesh, true)
  }
  const defaultTime = performance.now() - startDefault

  // 显示结果
  const panel = document.getElementById('benchmark-panel')
  panel.innerHTML = `
    <div>默认 Raycaster: ${defaultTime.toFixed(2)}ms (${iterations} 次)</div>
    <div>BVH 加速: ${bvhTime.toFixed(2)}ms (${iterations} 次)</div>
    <div>提升: ${(defaultTime / bvhTime).toFixed(1)}x</div>
  `

  // 恢复 BVH
  testMesh.geometry.computeBoundsTree()
}
```

**要点**：`disposeBoundsTree()` 移除 BVH 数据恢复默认检测；性能对比要控制变量（相同射线方向）；结果面板实时显示让用户直观感受差异。
