# Stage 4：Three.js 动画

> 进入 3D 动画世界，用 Three.js 实现物理模拟、流体效果和程序化动画。

## 本阶段目标

- 掌握 Three.js 动画系统（关键帧、骨骼、变形目标）
- 理解物理引擎的基本原理和集成方式
- 实现流体模拟和程序化动画
- 构建交互式 3D 场景

## 课时列表

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | Three.js 动画基础 | 关键帧动画、骨骼系统、变形目标 |
| 02 | 物理动画 | Cannon.js、Rapier、刚体模拟 |
| 03 | 流体模拟 | 粒子流体、SPH 方法 |
| 04 | 程序化动画 | 噪声驱动、L-system、群集行为 |
| 05 | 交互式 3D | 鼠标交互、手势、物理反馈 |
| 06 | 阶段实战 | 完整 3D 产品展示动画 |

## 学完本阶段你能

- 用 Three.js 创建和控制 3D 动画
- 集成物理引擎实现真实的碰撞和重力效果
- 用噪声和算法生成程序化动画
- 构建鼠标交互驱动的 3D 场景
