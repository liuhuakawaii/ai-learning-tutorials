# 01 - 3D 变换动画

## 场景引入

鼠标悬停卡片翻转露出背面信息、立方体在页面中央缓缓旋转、产品图片在三维空间中轮播——这些效果的底层都是 CSS 3D 变换。很多人觉得 3D 动画很难，但只要理解透视、坐标系和变换叠加这三个核心概念，CSS 的 3D 能力已经足够强大。

在真实项目中，3D 变换的应用场景非常广泛：
- **电商产品展示**：商品卡片翻转展示详情，360 度旋转查看产品
- **导航交互**：侧边菜单以 3D 方式展开，Tab 切换时内容翻转
- **数据可视化**：立体图表、环形数据展示
- **品牌页面**：Logo 旋转、品牌故事时间线的立体展示
- **游戏化界面**：卡牌游戏翻牌效果、骰子动画

本课从翻转卡片的真实场景出发，逐步构建立方体旋转效果，同时讲清楚每个属性背后的数学含义。

## 学习目标

- 理解 `perspective` 的工作原理和两种设置方式
- 掌握 `transform-style: preserve-3d` 与 `flat` 的区别
- 了解 `backface-visibility` 在翻转动画中的作用
- 理解 3D 坐标系和变换函数的数学含义
- 能独立实现翻转卡片、3D 立方体、3D 轮播等常见效果
- 掌握 3D 动画的性能优化和调试技巧

## 一、3D 坐标系基础

在学习 3D 变换之前，先理解 CSS 的三维坐标系：

```
        Y 轴（向下为正）
        ↑
        |
        |
        +------→ X 轴（向右为正）
       /
      /
     ↙
    Z 轴（向屏幕外为正）
```

- **X 轴**：水平方向，向右为正
- **Y 轴**：垂直方向，向下为正（注意和数学坐标系不同）
- **Z 轴**：垂直于屏幕方向，向屏幕外（靠近用户）为正

对应的旋转方向遵循**右手法则**：
- `rotateX(angle)`：绕 X 轴旋转，正值时顶部向屏幕内倾斜
- `rotateY(angle)`：绕 Y 轴旋转，正值时右侧向屏幕内旋转
- `rotateZ(angle)`：绕 Z 轴旋转，正值时顺时针旋转

理解这个坐标系是掌握所有 3D 变换的基础。

## 二、透视：让平面变立体

`perspective` 属性就是"摄像机到舞台的距离"，值越小透视越强烈，近大远小的效果越明显。

```css
/* 方式一：父元素设置，所有子元素共享透视点 */
.scene { perspective: 800px; }

/* 方式二：transform 中设置，每个元素独立透视 */
.card { transform: perspective(800px) rotateY(45deg); }
```

父元素设置时，所有子元素从同一个消失点透视；`transform: perspective()` 则是每个元素独立的透视空间。

### 透视值的直观感受

| 透视值 | 效果 | 适用场景 |
|--------|------|----------|
| 200-400px | 强烈透视，近大远小非常明显 | 夸张的视觉效果、游戏界面 |
| 600-1000px | 适中透视，自然立体感 | 卡片翻转、产品展示 |
| 1200-2000px | 微弱透视，接近正交投影 | 需要轻微立体感的 UI 元素 |

```html
<div class="perspective-demo">
  <div class="perspective-box" style="perspective: 200px;">200px</div>
  <div class="perspective-box" style="perspective: 600px;">600px</div>
  <div class="perspective-box" style="perspective: 1500px;">1500px</div>
</div>
```

```css
.perspective-demo {
  display: flex; gap: 40px; justify-content: center; padding: 60px;
}
.perspective-box {
  width: 120px; height: 120px;
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white; display: flex; align-items: center; justify-content: center;
  border-radius: 12px; font-size: 14px;
  transform: rotateY(45deg);
}
```

### perspective-origin：透视消失点

`perspective-origin` 控制消失点的位置，默认是元素中心 `50% 50%`。

```css
/* 消失点在左上角 */
.scene-top-left { perspective-origin: 0% 0%; }

/* 消失点在右侧 */
.scene-right { perspective-origin: 100% 50%; }

/* 消失点在底部 */
.scene-bottom { perspective-origin: 50% 100%; }
```

改变消失点会让同一个 3D 变换呈现完全不同的视觉效果，就像从不同角度观察物体。

## 三、翻转卡片实战

```html
<div class="scene">
  <div class="card">
    <div class="front">正面</div>
    <div class="back">背面</div>
  </div>
</div>
```

```css
.scene {
  width: 300px; height: 200px;
  perspective: 1000px;
}

.card {
  width: 100%; height: 100%;
  position: relative;
  transform-style: preserve-3d;   /* 保持 3D 空间 */
  transition: transform 0.6s ease;
}

.card:hover { transform: rotateY(180deg); }

.front, .back {
  position: absolute;
  width: 100%; height: 100%;
  backface-visibility: hidden;     /* 背对屏幕时不可见 */
}

.front {
  background: #3b82f6; color: white;
  display: flex; align-items: center; justify-content: center;
}

.back {
  background: #ef4444; color: white;
  transform: rotateY(180deg);      /* 初始就旋转 180 度 */
  display: flex; align-items: center; justify-content: center;
}
```

三个关键点：`transform-style: preserve-3d` 保持 3D 空间；`backface-visibility: hidden` 隐藏背面；背面元素初始旋转 180 度。

### 翻转卡片的变体：带阴影的立体翻转


## 四、transform-style 与 overflow 的冲突

`transform-style` 只有 `flat`（默认）和 `preserve-3d` 两个值。一个常见坑：父元素设置了 `overflow: hidden`，浏览器会强制把 `transform-style` 回退到 `flat`。

```css
/* 这样写会破坏 3D 效果 */
.broken-scene {
  overflow: hidden;
  transform-style: preserve-3d;  /* 无效 */
}
```

做 3D 效果时，确保祖先元素没有 `overflow: hidden`。

### 其他会破坏 preserve-3d 的属性

以下 CSS 属性也会强制浏览器将 `transform-style` 回退为 `flat`：

```css
/* 这些属性都会破坏 3D 空间 */
.breaks-3d-1 { opacity: 0.9; }          /* opacity 不为 1 时 */
.breaks-3d-2 { filter: blur(1px); }      /* 任何 filter 值 */
.breaks-3d-3 { clip-path: inset(0); }    /* clip-path 不为 none */
.breaks-3d-4 { mask: url(#mask); }       /* mask 不为 none */
.breaks-3d-5 { mix-blend-mode: multiply; } /* 混合模式 */
.breaks-3d-6 { isolation: isolate; }     /* isolation 属性 */
```

如果需要同时使用这些效果和 3D 变换，解决方案是将 3D 容器和效果容器分开：

```html
<!-- 正确做法：分离 3D 容器和效果容器 -->
<div class="effect-layer" style="opacity: 0.9;">
  <div class="scene" style="transform-style: preserve-3d;">
    <div class="cube">...</div>
  </div>
</div>
```

## 五、3D 立方体

用六个 `div` 拼成立方体，每个面通过 `translateZ` 推到对应位置。

```html
<div class="cube-scene">
  <div class="cube">
    <div class="face front">前</div>
    <div class="face back">后</div>
    <div class="face left">左</div>
    <div class="face right">右</div>
    <div class="face top">上</div>
    <div class="face bottom">下</div>
  </div>
</div>
```

```css
.cube-scene {
  width: 200px; height: 200px;
  perspective: 600px; margin: 100px auto;
}

.cube {
  width: 100%; height: 100%;
  position: relative;
  transform-style: preserve-3d;
  animation: rotateCube 8s infinite linear;
}

.face {
  position: absolute;
  width: 200px; height: 200px;
  display: flex; align-items: center; justify-content: center;
  font-size: 24px; color: white;
  border: 2px solid rgba(255, 255, 255, 0.3);
  opacity: 0.85;
}

.front  { background: #3b82f6; transform: translateZ(100px); }
.back   { background: #ef4444; transform: rotateY(180deg) translateZ(100px); }
.left   { background: #10b981; transform: rotateY(-90deg) translateZ(100px); }
.right  { background: #f59e0b; transform: rotateY(90deg) translateZ(100px); }
.top    { background: #8b5cf6; transform: rotateX(90deg) translateZ(100px); }
.bottom { background: #ec4899; transform: rotateX(-90deg) translateZ(100px); }

@keyframes rotateCube {
  from { transform: rotateX(0deg) rotateY(0deg); }
  to   { transform: rotateX(360deg) rotateY(360deg); }
}
```

`translateZ(100px)` 是立方体边长的一半。每个面先旋转到正确朝向，再沿法线方向推出。

### 立方体面的定位原理

立方体每个面的 transform 遵循相同规律：
1. 先旋转到正确的朝向（与目标面垂直）
2. 再沿 Z 轴推出边长一半的距离

```
前面：不需要旋转，直接 translateZ(100px)
后面：rotateY(180deg) 翻转，再 translateZ(100px)
左面：rotateY(-90deg) 左转，再 translateZ(100px)
右面：rotateY(90deg) 右转，再 translateZ(100px)
上面：rotateX(90deg) 上翻，再 translateZ(100px)
下面：rotateX(-90deg) 下翻，再 translateZ(100px)
```

```javascript
const cube = document.getElementById('cube')
let rotateX = -20, rotateY = 30
let isDragging = false
let startX, startY

cube.parentElement.addEventListener('mousedown', (e) => {
  isDragging = true
  startX = e.clientX
  startY = e.clientY
})

document.addEventListener('mousemove', (e) => {
  if (!isDragging) return
  const deltaX = e.clientX - startX
  const deltaY = e.clientY - startY
  rotateY += deltaX * 0.5
  rotateX -= deltaY * 0.5
  cube.style.transform = `rotateX(${rotateX}deg) rotateY(${rotateY}deg)`
  startX = e.clientX
  startY = e.clientY
})

document.addEventListener('mouseup', () => { isDragging = false })
```

## 六、变换叠加顺序

CSS `transform` 中多个函数从左往右依次应用：

```css
/* 先旋转再平移：沿旋转后的坐标轴平移 */
transform: rotateY(45deg) translateX(100px);

/* 先平移再旋转：沿原始坐标轴平移，然后旋转 */
transform: translateX(100px) rotateY(45deg);
```

结果完全不同。建议用"先定位，再旋转"的思路：先用 `translate` 放到正确位置，再用 `rotate` 调整朝向。

### 理解变换顺序的数学原理

CSS transform 的叠加方式是**矩阵乘法**，从右往左应用到坐标点上：

```
transform: A B C
实际执行顺序：先 C，再 B，最后 A
```

但对于写代码的人来说，从左往右读更直观——"先做 A，再做 B，最后做 C"。

```css
/* 示例：让元素绕一个不在中心的点旋转 */
/* 方法：先移到旋转中心，旋转，再移回来 */
transform: translateX(100px) rotate(45deg) translateX(-100px);
```

### 常见变换顺序的对比

```css
/* 效果 A：元素在原地旋转，然后向右移动 */
.box-a { transform: rotate(45deg) translateX(100px); }
/* 结果：元素向右上方移动（因为坐标轴已经旋转了） */

/* 效果 B：元素先向右移动，然后在新位置旋转 */
.box-b { transform: translateX(100px) rotate(45deg); }
/* 结果：元素向右移动，在原地旋转 */
```

## 七、3D 轮播效果

用 3D 变换实现环形轮播，这是产品展示页面的常见需求：


```css
  padding: 10px 24px;
  margin: 0 8px;
  background: #3b82f6; color: white;
  border: none; border-radius: 8px;
  cursor: pointer; font-size: 16px;
}
```

```javascript
const carousel = document.getElementById('carousel')
let currentIndex = 0
const totalItems = 6
const anglePerItem = 360 / totalItems

document.getElementById('prevBtn').addEventListener('click', () => {
  currentIndex = (currentIndex - 1 + totalItems) % totalItems
  carousel.style.transform = `rotateY(${currentIndex * anglePerItem}deg)`
})

document.getElementById('nextBtn').addEventListener('click', () => {
  currentIndex = (currentIndex + 1) % totalItems
  carousel.style.transform = `rotateY(-${currentIndex * anglePerItem}deg)`
})
```

### 轮播的数学原理

环形轮播的核心公式：

```
每个项的角度 = 360° / 项数
translateZ 的距离 = 项宽度 / (2 * tan(π / 项数))
```

例如 6 个项，每个宽 200px：
- 角度间隔：360° / 6 = 60°
- 推出距离：200 / (2 * tan(30°)) ≈ 173px（实际使用中可微调）

## 九、性能注意事项

3D 变换动画在性能上有天然优势——浏览器会把有 `transform` 动画的元素提升为合成层，在 GPU 上处理。但合成层也占用显存，页面上同时存在的合成层不宜超过几十个。

```css
/* 好：触发 GPU 加速 */
.card { transform: rotateY(180deg) scale(1.05); }

/* 差：触发重排和重绘 */
.card { width: 320px; height: 220px; }
```

### 合成层管理

浏览器自动创建合成层的条件：

```css
/* 以下情况会创建新的合成层 */
.will-animate { will-change: transform; }
.has-3d { transform: translateZ(0); }
.backface-hidden { backface-visibility: hidden; }
.animated { animation: move 1s; }  /* 3D transform 动画时 */
```

过多的合成层会消耗显存，导致页面卡顿。优化建议：

```css
/* 不要给每个元素都加 will-change */
/* 只在动画开始前添加，动画结束后移除 */
.animating { will-change: transform; }
.idle { will-change: auto; }
```

```javascript

  element.style.willChange = 'transform'
})

element.addEventListener('animationend', () => {
  element.style.willChange = 'auto'
})
```

### 性能对比

| 属性 | 触发 | 性能 |
|------|------|------|
| `transform` | 合成 | GPU 加速，高性能 |
| `opacity` | 合成 | GPU 加速，高性能 |
| `width/height` | 布局+绘制 | 触发重排，低性能 |
| `top/left` | 布局+绘制 | 触发重排，低性能 |
| `box-shadow` | 绘制 | 触发重绘，中等性能 |
| `filter` | 合成（部分） | 取决于滤镜类型 |

## 常见误区

1. **忘记设置 `transform-style: preserve-3d`**：没有这个属性，所有 3D 变换都会被压扁成 2D。
2. **在祖先元素上使用 `overflow: hidden`**：强制 `transform-style` 回退到 `flat`。
3. **混淆透视的两种写法**：`perspective` 属性是共享透视，`transform: perspective()` 是独立透视。
4. **变换顺序搞反**：`rotate` 和 `translate` 顺序不同，结果完全不同。
5. **忽略 `backface-visibility`**：翻转动画不设置此属性，背面内容会镜像显示。
6. **perspective 值设置不当**：太小导致变形严重，太大则看不出 3D 效果。
7. **忘记 SVG 元素的 transform-origin**：SVG 默认变换原点是画布左上角。

## 工程建议

1. 给 3D 场景容器统一设置 `perspective`，而不是在每个元素上写 `transform: perspective()`。
2. 立方体等复杂结构建议用 JavaScript 动态添加面和计算位置。
3. 移动端 `perspective` 值不宜太小（< 300px），透视变形太剧烈会让用户不适。
4. 调试时打开 Chrome DevTools 的 3D View 面板，直观查看合成层和元素位置。
5. 使用 `will-change: transform` 提示浏览器优化，但不要滥用。
6. 3D 动画优先使用 `transform` 属性，避免修改 `width`、`height`、`top`、`left` 等触发重排的属性。
7. 移动端注意触摸事件的处理，`touchstart` 和 `mousedown` 行为不同。

## 小结

本课学习了 CSS 3D 变换的核心机制：`perspective` 控制透视强度，`transform-style: preserve-3d` 开启 3D 空间，`backface-visibility` 控制背面可见性。通过翻转卡片、3D 立方体、3D 轮播三个实战案例，理解了变换叠加顺序和性能优化要点。掌握这些技术后，可以实现各种立体 UI 效果，提升用户体验。

**思路**：监听 `mousemove`，获取鼠标相对于卡片中心的偏移，映射到 -15 到 15 度的旋转角度。


```css

}

  width: 100%; height: 100%;
  background: linear-gradient(135deg, #667eea, #764ba2);
  border-radius: 12px; color: white; font-size: 18px;
  display: flex; align-items: center; justify-content: center;
  transition: transform 0.15s ease-out;
}
```

```javascript
const card = document.getElementById('tiltCard')
const content = card.querySelector('.content')

card.addEventListener('mousemove', (e) => {
  const rect = card.getBoundingClientRect()
  const rotateY = ((e.clientX - rect.left - rect.width/2) / (rect.width/2)) * 15
  const rotateX = -((e.clientY - rect.top - rect.height/2) / (rect.height/2)) * 15
  content.style.transform = `rotateX(${rotateX}deg) rotateY(${rotateY}deg)`
})

card.addEventListener('mouseleave', () => {
  content.style.transform = 'rotateX(0deg) rotateY(0deg)'
})
```

**要点**：鼠标 X 偏移对应 `rotateY`，Y 偏移对应 `rotateX`，方向相反才自然。
