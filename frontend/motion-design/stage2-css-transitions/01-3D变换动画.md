# 3D 变换动画

## 从翻转卡片开始

鼠标悬停卡片，正面翻转露出背面信息。这个效果在电商产品展示、个人简历、记忆翻牌游戏中随处可见。

先看最小实现：

```html
<div class="scene">
  <div class="card">
    <div class="front">正面</div>
    <div class="back">背面</div>
  </div>
</div>
```

```css
.scene { width: 300px; height: 200px; perspective: 800px; }
.card {
  width: 100%; height: 100%; position: relative;
  transform-style: preserve-3d;
  transition: transform 0.6s ease;
}
.card:hover { transform: rotateY(180deg); }
.front, .back {
  position: absolute; inset: 0;
  backface-visibility: hidden;
  display: flex; align-items: center; justify-content: center;
  border-radius: 12px; font-size: 20px; color: #fff;
}
.front { background: #3b82f6; }
.back { background: #ef4444; transform: rotateY(180deg); }
```

三个关键属性各管一件事：

| 属性 | 作用 | 缺了会怎样 |
|------|------|-----------|
| `perspective` | 定义景深，产生近大远小效果 | 没有立体感，只是 2D 缩放 |
| `transform-style: preserve-3d` | 子元素保持在 3D 空间 | 正反面被压扁到 2D |
| `backface-visibility: hidden` | 隐藏背面 | 翻转时正面镜像显示 |

背面元素要预设 `rotateY(180deg)`，否则翻转后它和正面朝向相同。

## CSS 3D 坐标系

```
Y 轴（向下为正）
↑
|
+------→ X 轴（向右为正）
/
↙
Z 轴（向屏幕外为正）
```

旋转方向遵循右手法则：
- `rotateX(angle)`：绕 X 轴，正值顶部向屏幕内倾
- `rotateY(angle)`：绕 Y 轴，正值右侧向屏幕内转
- `rotateZ(angle)`：绕 Z 轴，正值顺时针

## perspective 的两种写法

```css
/* 父元素设置：所有子元素共享透视点 */
.scene { perspective: 800px; }

/* transform 中设置：每个元素独立透视 */
.card { transform: perspective(800px) rotateY(45deg); }
```

透视值越小，近大远小越夸张：

| 值 | 效果 | 适用 |
|----|------|------|
| 200-400px | 强烈透视 | 游戏、夸张视觉 |
| 600-1000px | 自然立体 | 卡片、产品展示 |
| 1200-2000px | 微弱立体 | 轻微立体感的 UI |

## 会破坏 preserve-3d 的属性

一个常见坑——以下属性会让 `preserve-3d` 失效：

```css
/* 这些都会强制回退到 flat */
.breaks-3d { overflow: hidden; }          /* 最常见 */
.breaks-3d { opacity: 0.9; }              /* 不为 1 时 */
.breaks-3d { filter: blur(1px); }         /* 任何 filter */
.breaks-3d { clip-path: inset(0); }       /* clip-path */
```

解决方案：把 3D 容器和效果容器分开：

```html
<div style="opacity: 0.9;">        <!-- 效果层 -->
  <div style="transform-style: preserve-3d;">  <!-- 3D 层 -->
    <div class="cube">...</div>
  </div>
</div>
```

## 3D 立方体

六个面，每个面先旋转到正确朝向，再沿法线方向推出边长的一半：

```css
.cube-scene { width: 200px; height: 200px; perspective: 600px; margin: 80px auto; }
.cube {
  width: 100%; height: 100%; position: relative;
  transform-style: preserve-3d;
  animation: spin-cube 8s infinite linear;
}
.face {
  position: absolute; width: 200px; height: 200px;
  display: flex; align-items: center; justify-content: center;
  font-size: 24px; color: #fff; opacity: 0.85;
  border: 2px solid rgba(255,255,255,0.2);
}
.front  { background: #3b82f6; transform: translateZ(100px); }
.back   { background: #ef4444; transform: rotateY(180deg) translateZ(100px); }
.left   { background: #10b981; transform: rotateY(-90deg) translateZ(100px); }
.right  { background: #f59e0b; transform: rotateY(90deg) translateZ(100px); }
.top    { background: #8b5cf6; transform: rotateX(90deg) translateZ(100px); }
.bottom { background: #ec4899; transform: rotateX(-90deg) translateZ(100px); }
@keyframes spin-cube {
  from { transform: rotateX(0) rotateY(0); }
  to   { transform: rotateX(360deg) rotateY(360deg); }
}
```

规律：`translateZ(100px)` = 边长的一半。每个面先 `rotate` 到朝向，再 `translateZ` 推出。

## 变换顺序很重要

```css
/* 先旋转再平移：沿旋转后的坐标轴移动 */
transform: rotateY(45deg) translateX(100px);
/* 结果：元素向右前方移动 */

/* 先平移再旋转：沿原始坐标轴移动 */
transform: translateX(100px) rotateY(45deg);
/* 结果：元素向右移动，在新位置旋转 */
```

建议用"先定位，再旋转"的思路。

## 交互式立方体：鼠标拖拽

```javascript
const cube = document.getElementById('cube')
let rx = -20, ry = 30, dragging = false, sx, sy

cube.parentElement.addEventListener('mousedown', e => {
  dragging = true; sx = e.clientX; sy = e.clientY
})
document.addEventListener('mousemove', e => {
  if (!dragging) return
  ry += (e.clientX - sx) * 0.5
  rx -= (e.clientY - sy) * 0.5
  cube.style.transform = `rotateX(${rx}deg) rotateY(${ry}deg)`
  sx = e.clientX; sy = e.clientY
})
document.addEventListener('mouseup', () => dragging = false)
```

## 3D 环形轮播

N 个项均匀分布在一个圆上：

```css
.carousel-scene { width: 300px; height: 200px; perspective: 800px; margin: 60px auto; }
.carousel {
  width: 100%; height: 100%; position: relative;
  transform-style: preserve-3d;
  transition: transform 0.6s cubic-bezier(0.4, 0, 0.2, 1);
}
.carousel-item {
  position: absolute; width: 200px; height: 140px; left: 50px; top: 30px;
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: #fff; display: flex; align-items: center; justify-content: center;
  font-size: 18px; border-radius: 12px;
  transform: rotateY(calc(60deg * var(--i))) translateZ(250px);
}
```

```javascript
const total = 6, angle = 360 / total
let cur = 0
function go(dir) {
  cur = (cur + dir + total) % total
  carousel.style.transform = `rotateY(-${cur * angle}deg)`
}
```

核心公式：`translateZ = 宽度 / (2 × tan(π / N))`。6 个 200px 宽的项 → 约 173px。

## 性能与调试

3D 变换触发 GPU 合成层，性能天然好。但合成层也占显存，不要同时创建几十个。

```css
/* 动态管理 will-change */
.card:hover { will-change: transform; }  /* 动画前 */
.card       { will-change: auto; }       /* 空闲时 */
```

Chrome DevTools → More tools → 3D View 可以看到所有合成层的堆叠情况。

## 练习

### 练习一：鼠标跟随倾斜

在翻转卡片基础上，鼠标在卡片上移动时，根据鼠标位置微微倾斜（最多 ±15 度），移出后回正。

### 练习二：3D 骰子

六个面分别显示 1-6 个点，点击按钮骰子随机旋转并停在某个面。

### 练习三：3D 折叠面板

手风琴效果，每个面板像翻书一样绕 X 轴旋转展开/收起。

## 参考答案

### 练习一

```javascript
const card = document.querySelector('.card-content')
const scene = document.querySelector('.scene')
scene.addEventListener('mousemove', e => {
  const r = scene.getBoundingClientRect()
  const ry = ((e.clientX - r.left - r.width/2) / (r.width/2)) * 15
  const rx = -((e.clientY - r.top - r.height/2) / (r.height/2)) * 15
  card.style.transform = `rotateX(${rx}deg) rotateY(${ry}deg)`
})
scene.addEventListener('mouseleave', () => {
  card.style.transform = 'rotateX(0) rotateY(0)'
})
```

鼠标 X 偏移对应 `rotateY`，Y 偏移对应 `rotateX`，方向相反才自然。
