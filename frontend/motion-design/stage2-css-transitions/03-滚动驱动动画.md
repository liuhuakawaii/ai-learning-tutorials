# 03 - 滚动驱动动画

## 场景引入

打开 Apple 产品页面，向下滚动时图片淡入、文字滑入、产品旋转——这些动画和滚动行为绑定。滚到哪，动画就播到哪。过去实现这类效果需要监听 `scroll` 事件手动计算，代码繁琐且容易卡顿。现在 CSS 原生的 `scroll-timeline` 和 `IntersectionObserver` 让这件事变得简单高效。

在真实项目中，滚动驱动动画的应用场景非常丰富：
- **产品展示页**：滚动时产品图片旋转、特性卡片依次出现
- **品牌故事页**：时间线滚动展示、文字渐显、背景色渐变
- **数据仪表盘**：滚动触发图表动画、数据卡片错落出现
- **长文章/博客**：阅读进度指示、章节导航高亮
- **落地页**：Hero 区域视差效果、功能模块滚动淡入
- **电商页面**：商品列表无限滚动加载、滚动触发筛选动画

## 学习目标

- 掌握 `IntersectionObserver` 实现滚动触发动画
- 理解 CSS `scroll-timeline` 的工作原理
- 了解 `animation-range` 的精确控制
- 能实现滚动淡入、进度条、视差效果、动画序列等效果
- 掌握滚动动画的性能优化和调试技巧

## 一、IntersectionObserver：滚动触发

`IntersectionObserver` 检测元素是否进入视口，在浏览器空闲时间执行回调，不会造成主线程卡顿。

```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate-in')
      observer.unobserve(entry.target)  // 只触发一次
    }
  })
}, { threshold: 0.2 })

document.querySelectorAll('.fade-in').forEach(el => observer.observe(el))
```

```css
.fade-in {
  opacity: 0; transform: translateY(30px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.fade-in.animate-in {
  opacity: 1; transform: translateY(0);
}
```

### IntersectionObserver 配置选项

```javascript
const options = {
  // root: 观察的根元素，默认是视口
  root: null,  // null 表示视口
  
  // rootMargin: 根元素的外边距，类似 CSS margin
  rootMargin: '0px 0px -100px 0px',  // 底部提前 100px 触发
  
  // threshold: 触发回调的可见比例阈值
  threshold: [0, 0.25, 0.5, 0.75, 1]  // 多个阈值
}

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    // entry.isIntersecting: 是否可见
    // entry.intersectionRatio: 可见比例 (0-1)
    // entry.boundingClientRect: 元素边界
    // entry.rootBounds: 根元素边界
    
    console.log(`可见比例: ${entry.intersectionRatio}`)
    
    if (entry.isIntersecting) {
      entry.target.classList.add('animate-in')
    }
  })
}, options)
```

### threshold 的实际应用

不同 threshold 值适合不同场景：

| threshold | 含义 | 适用场景 |
|-----------|------|----------|
| 0 | 任意像素可见即触发 | 懒加载图片、触发简单动画 |
| 0.2 | 20% 可见时触发 | 一般的内容淡入动画 |
| 0.5 | 50% 可见时触发 | 需要元素明显出现后才触发 |
| 1 | 完全可见时触发 | 必须完全展示的内容 |
| [0, 0.5, 1] | 多阈值 | 根据可见比例做不同程度的动画 |

```javascript
// 根据可见比例做不同程度的动画
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    const ratio = entry.intersectionRatio
    entry.target.style.opacity = ratio
    entry.target.style.transform = `translateY(${(1 - ratio) * 50}px)`
  })
}, { threshold: Array.from({ length: 20 }, (_, i) => i / 19) })
```


### JavaScript 动态计算交错延迟

当元素数量不确定时，用 JavaScript 动态计算：

```javascript
function setupStagger(container, options = {}) {
  const items = container.querySelectorAll('.stagger-item')
  const { delay = 0.1, direction = 'forward' } = options

  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        items.forEach((item, index) => {
          const order = direction === 'forward' ? index : items.length - 1 - index
          item.style.transitionDelay = `${order * delay}s`
          item.classList.add('animate-in')
        })
        observer.unobserve(entry.target)
      }
    })
  }, { threshold: 0.2 })

  observer.observe(container)
}

document.querySelectorAll('.stagger-container').forEach(container => {
  setupStagger(container, { delay: 0.12, direction: 'forward' })
})
```

## 三、CSS scroll-timeline

`scroll-timeline` 把动画进度和滚动位置绑定：

```css
@keyframes fadeSlideIn {
  from { opacity: 0; transform: translateY(50px); }
  to   { opacity: 1; transform: translateY(0); }
}

.scroll-animated {
  animation: fadeSlideIn linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}
```

`animation-timeline: view()` 表示动画进度和元素在视口中的可见性绑定。

`animation-range` 关键字含义：
- `entry`：元素进入视口的过程
- `exit`：元素离开视口的过程
- `cover`：元素在视口中可见的整个过程
- `contain`：元素完全在视口内的过程

### animation-range 详解

```css
/* 元素进入视口时播放动画 */
.enter-animate {
  animation: fadeIn linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}

/* 元素在视口中可见的整个过程中播放 */
.cover-animate {
  animation: scaleUp linear both;
  animation-timeline: view();
  animation-range: cover 0% cover 100%;
}

/* 元素完全进入视口后开始播放 */
.contain-animate {
  animation: slideIn linear both;
  animation-timeline: view();
  animation-range: contain 0% contain 50%;
}

/* 组合使用：进入时淡入，离开时淡出 */
.enter-exit-animate {
  animation: fadeBoth linear both;
  animation-timeline: view();
  animation-range: entry 0% exit 100%;
}

@keyframes fadeBoth {
  0% { opacity: 0; transform: translateY(30px); }
  50% { opacity: 1; transform: translateY(0); }
  100% { opacity: 0; transform: translateY(-30px); }
}
```

### view() 的详细参数

```css
/* view(axis) - 指定滚动轴 */
.view-block {
  animation-timeline: view(block);  /* 垂直滚动（默认） */
}

.view-inline {
  animation-timeline: view(inline); /* 水平滚动 */
}

/* view(axis, inset) - 指定视口边缘偏移 */
.view-inset {
  animation-timeline: view(block auto);
  animation-range: entry 10% entry 90%;  /* 更平缓的动画 */
}
```

## 四、滚动进度条

用 `scroll-timeline` 实现页面顶部阅读进度条，只需三行 CSS：

```css
.progress-bar {
  position: fixed; top: 0; left: 0;
  height: 3px; background: #3b82f6;
  transform-origin: left;
  animation: growProgress linear both;
  animation-timeline: scroll(root);
}

@keyframes growProgress {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}
```

`scroll(root)` 监听根元素的滚动，进度条完全跟随页面滚动。

## 五、JavaScript 精细控制

需要更精细控制时，用 JS 计算元素可见比例：

```javascript
function createScrollProgress(element, callback) {
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        window.addEventListener('scroll', onScroll)
      } else {
        window.removeEventListener('scroll', onScroll)
      }
    })
  })

  function onScroll() {
    const rect = element.getBoundingClientRect()
    const progress = Math.max(0, Math.min(1,
      (window.innerHeight - rect.top) / (window.innerHeight + rect.height)
    ))
    callback(progress)
  }

  observer.observe(element)
}

// 使用：滚动时淡出并缩小
createScrollProgress(document.querySelector('.hero'), (progress) => {
  hero.style.opacity = 1 - progress * 0.5
  hero.style.transform = `scale(${1 - progress * 0.1})`
})
```

### 通用滚动进度计算函数

```javascript
function getScrollProgress(element) {
  const rect = element.getBoundingClientRect()
  const windowHeight = window.innerHeight
  
  // 元素顶部进入视口时 progress = 0
  // 元素底部离开视口时 progress = 1
  const progress = (windowHeight - rect.top) / (windowHeight + rect.height)
  return Math.max(0, Math.min(1, progress))
}

// 使用
window.addEventListener('scroll', () => {
  const elements = document.querySelectorAll('.scroll-track')
  elements.forEach(el => {
    const progress = getScrollProgress(el)
    // 根据进度设置各种样式
    el.style.opacity = progress
    el.style.transform = `translateY(${(1 - progress) * 60}px)`
  })
})
```

### requestAnimationFrame 节流

滚动事件触发频率很高，用 `requestAnimationFrame` 节流：

```javascript
let ticking = false

window.addEventListener('scroll', () => {
  if (!ticking) {
    requestAnimationFrame(() => {
      updateAnimations()
      ticking = false
    })
    ticking = true
  }
})

function updateAnimations() {
  const scrollY = window.scrollY
  // 更新所有滚动驱动的动画
  document.querySelectorAll('.parallax').forEach(el => {
    const speed = parseFloat(el.dataset.speed) || 0.5
    const offset = scrollY * speed
    el.style.transform = `translateY(${offset}px)`
  })
}
```

## 十、性能优化

### 避免直接监听 scroll 事件

```javascript
// ❌ 错误：直接监听 scroll
window.addEventListener('scroll', () => {
  // 每次滚动都执行，频率很高
  heavyCalculation()
})

// ✅ 正确：使用 IntersectionObserver
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate-in')
    }
  })
})

// ✅ 正确：使用 requestAnimationFrame 节流
let ticking = false
window.addEventListener('scroll', () => {
  if (!ticking) {
    requestAnimationFrame(() => {
      heavyCalculation()
      ticking = false
    })
    ticking = true
  }
})
```

### 减少重排

```css
/* ❌ 错误：修改触发重排的属性 */
.bad-animation {
  transition: top 0.3s, left 0.3s, width 0.3s;
}

/* ✅ 正确：使用 transform 和 opacity */
.good-animation {
  transition: transform 0.3s, opacity 0.3s;
  will-change: transform, opacity;
}
```

### 使用 will-change

```css
/* 在动画开始前添加 will-change */
.scroll-animate {
  will-change: transform, opacity;
}

/* 动画结束后移除（通过 JavaScript） */
.scroll-animate.animated {
  will-change: auto;
}
```

```javascript
// 动态管理 will-change
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.style.willChange = 'transform, opacity'
      entry.target.classList.add('animate-in')
      
      // 动画结束后移除 will-change
      entry.target.addEventListener('transitionend', () => {
        entry.target.style.willChange = 'auto'
      }, { once: true })
    }
  })
})
```

### 批量处理

```javascript
// ❌ 错误：每个元素一个 observer
document.querySelectorAll('.fade-in').forEach(el => {
  const observer = new IntersectionObserver(callback)
  observer.observe(el)
})

// ✅ 正确：一个 observer 观察所有元素
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate-in')
      observer.unobserve(entry.target)
    }
  })
}, { threshold: 0.2 })

document.querySelectorAll('.fade-in').forEach(el => observer.observe(el))
```

## 常见误区

1. **直接监听 scroll 事件做动画**：触发频率极高，会导致严重卡顿。用 `IntersectionObserver` 或 `requestAnimationFrame` 节流。
2. **忘记取消观察**：触发后不调用 `unobserve()`，每次进出视口都会重复触发动画。
3. **scroll-timeline 兼容性**：2023 年底才在主流浏览器支持，生产环境需检查兼容性。
4. **animation-range 方向搞反**：方向要和元素运动方向匹配，否则会反向播放。
5. **threshold 设置不当**：太小会导致动画过早触发，太大会导致动画过晚触发。
6. **忘记 rootMargin**：默认情况下元素需要进入视口才触发，可能需要调整触发时机。
7. **大量元素不做批量处理**：每个元素创建独立 observer 会浪费内存。

## 工程建议

1. 优先用 `IntersectionObserver` 实现"滚动触发动画"，兼容性好、性能优秀。
2. 纯展示性滚动联动（进度条、颜色渐变）用 `scroll-timeline`。
3. 需要精细控制的场景用 JS + `requestAnimationFrame` 节流。
4. 大量元素需要滚动触发时，用一个 observer 实例观察所有元素。
5. 移动端注意触摸滚动的性能，避免在滚动时执行复杂计算。
6. 使用 `will-change` 提示浏览器优化，但不要滥用。
7. 提供 `prefers-reduced-motion` 媒体查询支持，尊重用户的动画偏好。

## 小结

本课学习了滚动驱动动画的三种方案：`IntersectionObserver`（触发式）、CSS `scroll-timeline`（绑定式）、JavaScript（精细控制）。性能是核心挑战——避免直接监听 scroll 事件，善用浏览器原生 API。掌握了这些技术后，可以实现各种与滚动行为绑定的精美动画效果。

### 练习五

**思路**：用 `IntersectionObserver` 检测进入视口，用 JavaScript 实现数字递增动画。

```html
<div class="counter-section">
  <div class="counter" data-target="1000">0</div>
  <div class="counter" data-target="500">0</div>
  <div class="counter" data-target="99">0</div>
</div>
```

```css
.counter {
  font-size: 4rem;
  font-weight: bold;
  text-align: center;
  margin: 40px 0;
  color: #3b82f6;
}
```

```javascript
function animateCounter(element) {
  const target = parseInt(element.dataset.target)
  const duration = 2000
  const start = 0
  const startTime = performance.now()

  function update(currentTime) {
    const elapsed = currentTime - startTime
    const progress = Math.min(elapsed / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3)
    const current = Math.round(start + (target - start) * eased)
    element.textContent = current.toLocaleString()

    if (progress < 1) {
      requestAnimationFrame(update)
    }
  }

  requestAnimationFrame(update)
}

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      animateCounter(entry.target)
      observer.unobserve(entry.target)
    }
  })
}, { threshold: 0.5 })

document.querySelectorAll('.counter').forEach(el => observer.observe(el))
```

**要点**：使用 `requestAnimationFrame` 实现平滑的数字递增，`easing` 函数让动画更自然，`IntersectionObserver` 确保只在元素可见时触发。
