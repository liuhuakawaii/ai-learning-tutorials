# 05 - 粒子系统

## 场景引入

科技感网站背景中飘动的光点——成百上千个小圆点缓缓移动，鼠标靠近时被推开。这就是粒子系统。它是动效开发中最常见的"氛围层"，不承载信息，但能极大提升页面视觉品质。

想象夜空中的萤火虫：每只萤火虫有自己的飞行轨迹、亮度和寿命，它们独立运动又共同构成一幅画面。粒子系统的核心思想正是如此——用大量简单的个体，通过规则驱动，涌现出复杂的视觉效果。

本课从 Canvas 2D 粒子开始，讲解粒子系统核心概念（发射、更新、渲染循环），然后介绍 WebGL 粒子的性能优势，最后探讨真实项目中的工程实践。

## 学习目标

- 理解粒子系统的核心循环：发射 → 更新 → 渲染
- 掌握用 Canvas 2D 实现千级粒子动画
- 掌握鼠标交互、重力模拟等物理效果
- 了解 WebGL 粒子的性能优势和基本思路
- 能实现背景粒子场、鼠标交互粒子、文字粒子等效果
- 理解粒子系统的性能瓶颈和优化策略

## 一、粒子系统核心概念

### 1.1 三要素

每个粒子系统由三部分组成：

1. **粒子（Particle）**：最小单元，拥有位置、速度、生命周期、大小、颜色等属性
2. **发射器（Emitter）**：控制粒子的生成速率、初始位置、初始速度方向和范围
3. **更新循环（Update Loop）**：每帧更新所有粒子的状态，移除死亡粒子，生成新粒子

### 1.2 粒子类设计

```javascript
class Particle {
  constructor(x, y, options = {}) {
    this.x = x
    this.y = y
    this.vx = options.vx ?? (Math.random() - 0.5) * 2
    this.vy = options.vy ?? (Math.random() - 0.5) * 2
    this.life = options.life ?? 1.0
    this.decay = options.decay ?? (0.005 + Math.random() * 0.01)
    this.size = options.size ?? (2 + Math.random() * 3)
    this.color = options.color ?? '#3b82f6'
  }

  update() {
    this.x += this.vx
    this.y += this.vy
    this.life -= this.decay
  }

  isDead() {
    return this.life <= 0
  }
}
```

**设计要点：**

- **可选参数**：`options` 对象让粒子在创建时可以定制，发射器可以批量控制粒子属性。
- **生命衰减**：`life` 从 1.0 开始，每帧减去 `decay`，归零时粒子消亡。这种设计比基于时间的方案更简单，因为帧率变化时粒子的"存活帧数"是稳定的。
- **随机性**：`Math.random() - 0.5` 产生 -0.5 到 0.5 的随机值，乘以速度系数后让粒子向四面八方扩散。

### 1.3 生命周期直觉

把粒子想象成烟花：
- **诞生**：从一个点向四周发射
- **飞行**：受重力影响画出抛物线
- **消亡**：越来越小、越来越透明，最终消失

`life` 值可以直接用于透明度和大小的计算：`opacity = life`，`size = baseSize * life`，实现自然的消亡效果。

## 二、Canvas 2D 粒子场

### 2.1 基础粒子场

粒子在画布上随机漂移，边界反弹，相邻粒子间画连线产生"星座"效果。

```html
<!DOCTYPE html>
<html lang="zh">
<head>
<style>
  * { margin: 0; padding: 0; }
  body { overflow: hidden; background: #0f172a; }
  canvas { display: block; }
</style>
</head>
<body>
<canvas id="particleCanvas"></canvas>
<script>
const canvas = document.getElementById('particleCanvas')
const ctx = canvas.getContext('2d')

function resize() {
  canvas.width = window.innerWidth
  canvas.height = window.innerHeight
}
resize()
window.addEventListener('resize', resize)

const particles = Array.from({ length: 150 }, () => ({
  x: Math.random() * canvas.width,
  y: Math.random() * canvas.height,
  vx: (Math.random() - 0.5) * 0.8,
  vy: (Math.random() - 0.5) * 0.8,
  size: 1 + Math.random() * 2,
  opacity: 0.3 + Math.random() * 0.7
}))

function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  // 更新并绘制粒子（合并到一个路径）
  ctx.beginPath()
  particles.forEach(p => {
    p.x += p.vx
    p.y += p.vy
    if (p.x < 0 || p.x > canvas.width) p.vx *= -1
    if (p.y < 0 || p.y > canvas.height) p.vy *= -1
    ctx.moveTo(p.x + p.size, p.y)
    ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
  })
  ctx.fillStyle = 'rgba(59, 130, 246, 0.6)'
  ctx.fill()

  // 连线
  const maxDist = 120
  for (let i = 0; i < particles.length; i++) {
    for (let j = i + 1; j < particles.length; j++) {
      const dx = particles[i].x - particles[j].x
      const dy = particles[i].y - particles[j].y
      const dist = Math.sqrt(dx * dx + dy * dy)
      if (dist < maxDist) {
        ctx.beginPath()
        ctx.moveTo(particles[i].x, particles[i].y)
        ctx.lineTo(particles[j].x, particles[j].y)
        ctx.strokeStyle = `rgba(59, 130, 246, ${(1 - dist / maxDist) * 0.3})`
        ctx.lineWidth = 0.5
        ctx.stroke()
      }
    }
  }

  requestAnimationFrame(animate)
}
animate()
</script>
</body>
</html>
```

### 2.2 性能关键点

**绘制合并**：所有粒子合并到一个路径中只调用一次 `fill()`，这是 Canvas 2D 性能优化的关键。如果每个粒子单独 `fill()`，150 个粒子就是 150 次绘制调用。

```javascript
// 差：每个粒子一次 fill
particles.forEach(p => {
  ctx.beginPath()
  ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
  ctx.fillStyle = 'rgba(59, 130, 246, 0.6)'
  ctx.fill()
})

// 好：合并到一个路径，一次 fill
ctx.beginPath()
particles.forEach(p => {
  ctx.moveTo(p.x + p.size, p.y)
  ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
})
ctx.fillStyle = 'rgba(59, 130, 246, 0.6)'
ctx.fill()
```

**连线的性能问题**：连线检查是 O(n²) 的——150 个粒子需要检查 150×149/2 = 11,175 对。当粒子数量增加时，这个开销会急剧增长。

### 2.3 空间分区优化

用网格分区将连线检查从 O(n²) 降到接近 O(n)：

```javascript
class SpatialGrid {
  constructor(width, height, cellSize) {
    this.cellSize = cellSize
    this.cols = Math.ceil(width / cellSize)
    this.rows = Math.ceil(height / cellSize)
    this.cells = new Array(this.cols * this.rows).fill(null).map(() => [])
  }

  clear() {
    this.cells.forEach(cell => cell.length = 0)
  }

  insert(particle) {
    const col = Math.floor(particle.x / this.cellSize)
    const row = Math.floor(particle.y / this.cellSize)
    if (col >= 0 && col < this.cols && row >= 0 && row < this.rows) {
      this.cells[row * this.cols + col].push(particle)
    }
  }

  getNeighbors(particle, radius) {
    const neighbors = []
    const col = Math.floor(particle.x / this.cellSize)
    const row = Math.floor(particle.y / this.cellSize)
    const cellRadius = Math.ceil(radius / this.cellSize)

    for (let r = row - cellRadius; r <= row + cellRadius; r++) {
      for (let c = col - cellRadius; c <= col + cellRadius; c++) {
        if (r >= 0 && r < this.rows && c >= 0 && c < this.cols) {
          const cell = this.cells[r * this.cols + c]
          cell.forEach(p => {
            if (p !== particle) neighbors.push(p)
          })
        }
      }
    }
    return neighbors
  }
}

// 使用
const grid = new SpatialGrid(canvas.width, canvas.height, 150)

function animate() {
  grid.clear()
  particles.forEach(p => grid.insert(p))

  // 连线只检查邻居
  ctx.beginPath()
  particles.forEach(p => {
    const neighbors = grid.getNeighbors(p, 120)
    neighbors.forEach(n => {
      const dx = p.x - n.x
      const dy = p.y - n.y
      const dist = Math.sqrt(dx * dx + dy * dy)
      if (dist < 120) {
        ctx.moveTo(p.x, p.y)
        ctx.lineTo(n.x, n.y)
      }
    })
  })
  ctx.strokeStyle = 'rgba(59, 130, 246, 0.2)'
  ctx.lineWidth = 0.5
  ctx.stroke()

  requestAnimationFrame(animate)
}
```

## 三、鼠标交互

### 3.1 排斥力

让粒子对鼠标位置产生排斥反应，鼠标靠近时粒子被推开：

```javascript
const mouse = { x: -1000, y: -1000, radius: 100 }
canvas.addEventListener('mousemove', (e) => {
  mouse.x = e.clientX
  mouse.y = e.clientY
})
canvas.addEventListener('mouseleave', () => {
  mouse.x = -1000
  mouse.y = -1000
})

function applyMouseForce(p) {
  const dx = p.x - mouse.x
  const dy = p.y - mouse.y
  const dist = Math.sqrt(dx * dx + dy * dy)
  if (dist < mouse.radius && dist > 0) {
    const force = (mouse.radius - dist) / mouse.radius
    const angle = Math.atan2(dy, dx)
    p.x += Math.cos(angle) * force * 3
    p.y += Math.sin(angle) * force * 3
  }
}
```

**物理直觉**：排斥力和距离成反比——越近排斥越强。`force = (radius - dist) / radius` 在鼠标边缘（`dist ≈ radius`）时接近 0，在鼠标中心（`dist ≈ 0`）时接近 1。

### 3.2 吸引力

有时候我们需要粒子被鼠标吸引，比如制作"磁铁"效果：

```javascript
function applyMouseAttraction(p) {
  const dx = mouse.x - p.x
  const dy = mouse.y - p.y
  const dist = Math.sqrt(dx * dx + dy * dy)
  if (dist < mouse.radius && dist > 5) {
    const force = (mouse.radius - dist) / mouse.radius * 0.5
    p.vx += (dx / dist) * force
    p.vy += (dy / dist) * force
  }
}
```

### 3.3 弹簧回弹

粒子被推开后自动回到原位，适合文字粒子效果：

```javascript
function applySpringForce(p) {
  // 鼠标排斥
  const dx = p.x - mouse.x
  const dy = p.y - mouse.y
  const dist = Math.sqrt(dx * dx + dy * dy)
  if (dist < 60 && dist > 0) {
    const force = (60 - dist) / 60
    p.vx += (dx / dist) * force * 5
    p.vy += (dy / dist) * force * 5
  }

  // 弹簧回弹（指向原始位置的力）
  p.vx += (p.homeX - p.x) * 0.03
  p.vy += (p.homeY - p.y) * 0.03

  // 阻尼（让粒子最终停下来）
  p.vx *= 0.92
  p.vy *= 0.92

  p.x += p.vx
  p.y += p.vy
}
```

**弹簧模型的三个力**：
1. **排斥力**：鼠标靠近时推开粒子
2. **回弹力**：指向原始位置的弹簧力，`系数 0.03` 控制回弹速度
3. **阻尼力**：`× 0.92` 让速度逐渐衰减，防止无限振荡

## 四、粒子发射器

### 4.1 基础发射器

从特定位置持续发射粒子，适合鼠标轨迹、按钮点击特效：

```javascript
class Emitter {
  constructor(x, y, options = {}) {
    this.x = x
    this.y = y
    this.particles = []
    this.rate = options.rate ?? 3
    this.gravity = options.gravity ?? 0.05
    this.colors = options.colors ?? ['#fbbf24', '#f59e0b', '#ef4444']
  }

  emit() {
    for (let i = 0; i < this.rate; i++) {
      const angle = Math.random() * Math.PI * 2
      const speed = 1 + Math.random() * 3
      this.particles.push({
        x: this.x,
        y: this.y,
        vx: Math.cos(angle) * speed,
        vy: Math.sin(angle) * speed - 2,
        life: 1,
        decay: 0.015 + Math.random() * 0.02,
        size: 2 + Math.random() * 4,
        color: this.colors[Math.floor(Math.random() * this.colors.length)]
      })
    }
  }

  update(ctx) {
    this.emit()
    this.particles = this.particles.filter(p => {
      p.x += p.vx
      p.y += p.vy
      p.vy += this.gravity
      p.life -= p.decay
      if (p.life <= 0) return false

      ctx.beginPath()
      ctx.arc(p.x, p.y, p.size * p.life, 0, Math.PI * 2)
      ctx.fillStyle = p.color.replace(')', `, ${p.life})`).replace('rgb', 'rgba')
      ctx.globalAlpha = p.life
      ctx.fillStyle = p.color
      ctx.fill()
      return true
    })
    ctx.globalAlpha = 1
  }
}
```

`p.vy += 0.05` 模拟重力，`p.size * p.life` 让粒子消亡时逐渐变小。

### 4.2 烟花效果

点击产生烟花，粒子受重力影响画出抛物线：

```javascript
const canvas = document.getElementById('fireworks')
const ctx = canvas.getContext('2d')
canvas.width = window.innerWidth
canvas.height = window.innerHeight

const fireworks = []
const colors = ['#ef4444', '#f59e0b', '#10b981', '#3b82f6', '#8b5cf6', '#ec4899']

canvas.addEventListener('click', (e) => {
  const particleCount = 80
  for (let i = 0; i < particleCount; i++) {
    const angle = (Math.PI * 2 / particleCount) * i
    const speed = 2 + Math.random() * 4
    fireworks.push({
      x: e.clientX,
      y: e.clientY,
      vx: Math.cos(angle) * speed,
      vy: Math.sin(angle) * speed,
      life: 1,
      decay: 0.01 + Math.random() * 0.015,
      size: 1.5 + Math.random() * 2.5,
      color: colors[Math.floor(Math.random() * colors.length)]
    })
  }
})

function animate() {
  ctx.fillStyle = 'rgba(15, 23, 42, 0.15)'
  ctx.fillRect(0, 0, canvas.width, canvas.height)

  for (let i = fireworks.length - 1; i >= 0; i--) {
    const p = fireworks[i]
    p.x += p.vx
    p.y += p.vy
    p.vy += 0.08
    p.vx *= 0.99
    p.life -= p.decay

    if (p.life <= 0) {
      fireworks.splice(i, 1)
      continue
    }

    ctx.globalAlpha = p.life
    ctx.beginPath()
    ctx.arc(p.x, p.y, p.size * p.life, 0, Math.PI * 2)
    ctx.fillStyle = p.color
    ctx.fill()
  }

  ctx.globalAlpha = 1
  requestAnimationFrame(animate)
}
animate()
```

**关键细节**：
- `ctx.fillStyle = 'rgba(15, 23, 42, 0.15)'` 代替 `clearRect`，产生拖尾效果——每帧不完全清除，留下半透明的残影。
- `p.vx *= 0.99` 模拟空气阻力，让水平速度逐渐衰减。
- `p.vy += 0.08` 模拟重力，让粒子画出抛物线。
- 从后往前遍历（`for (let i = length - 1; i >= 0; i--)`），这样 `splice` 不会影响后续索引。

## 五、WebGL 粒子基础

### 5.1 为什么需要 WebGL

Canvas 2D 的性能瓶颈在于**逐粒子绘制**——每个粒子都需要 CPU 计算位置、调用绘图 API。当粒子数量超过几千个时，CPU 成为瓶颈。

WebGL 把计算转移到 GPU：
- **并行计算**：GPU 有数千个核心，可以同时处理所有粒子
- **批量渲染**：一次 `drawArrays` 调用绘制所有粒子
- **着色器计算**：粒子的位置更新可以在 GPU 上完成

### 5.2 Three.js 粒子

用 Three.js 实现 WebGL 粒子最简单：

```javascript
const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000)
camera.position.z = 50

const renderer = new THREE.WebGLRenderer({ canvas: document.getElementById('webgl-canvas') })
renderer.setSize(window.innerWidth, window.innerHeight)

const count = 10000
const geometry = new THREE.BufferGeometry()
const positions = new Float32Array(count * 3)
const colors = new Float32Array(count * 3)

for (let i = 0; i < count; i++) {
  positions[i * 3]     = (Math.random() - 0.5) * 100
  positions[i * 3 + 1] = (Math.random() - 0.5) * 100
  positions[i * 3 + 2] = (Math.random() - 0.5) * 100
  colors[i * 3]     = 0.23 + Math.random() * 0.3
  colors[i * 3 + 1] = 0.5 + Math.random() * 0.3
  colors[i * 3 + 2] = 0.96
}

geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3))
geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3))

const material = new THREE.PointsMaterial({
  size: 0.5,
  vertexColors: true,
  transparent: true,
  opacity: 0.8
})

const points = new THREE.Points(geometry, material)
scene.add(points)

function animate() {
  requestAnimationFrame(animate)
  points.rotation.y += 0.001
  points.rotation.x += 0.0005
  renderer.render(scene, camera)
}
animate()
```

### 5.3 纯 WebGL 着色器粒子

不依赖 Three.js，直接用 WebGL 实现粒子系统：

```javascript
const vsSource = `
  attribute vec2 a_position;
  attribute float a_size;
  attribute float a_life;
  varying float v_life;
  void main() {
    gl_Position = vec4(a_position, 0.0, 1.0);
    gl_PointSize = a_size * a_life;
    v_life = a_life;
  }
`

const fsSource = `
  precision mediump float;
  varying float v_life;
  void main() {
    float dist = length(gl_PointCoord - vec2(0.5));
    if (dist > 0.5) discard;
    gl_FragColor = vec4(0.23, 0.51, 0.96, v_life * 0.8);
  }
`
```

着色器在 GPU 上为每个粒子并行执行，`gl_PointSize` 控制点的大小，`v_life` 传递生命值用于透明度计算。

### 5.4 Canvas 2D vs WebGL 选择指南

| 粒子数量 | 推荐方案 | 原因 |
|----------|----------|------|
| < 200 | Canvas 2D | 简单够用，无需额外依赖 |
| 200 - 1000 | Canvas 2D + 优化 | 绘制合并 + 空间分区 |
| 1000 - 10000 | WebGL (Three.js) | GPU 批量渲染 |
| > 10000 | WebGL + GPGPU | 计算着色器更新粒子位置 |

## 六、性能优化

### 6.1 绘制合并

同色粒子合并到一个路径中，只调用一次 `fill()`。这是最基础也最重要的优化。

### 6.2 高分屏适配

```javascript
const dpr = window.devicePixelRatio || 1
canvas.width = canvas.clientWidth * dpr
canvas.height = canvas.clientHeight * dpr
ctx.scale(dpr, dpr)
```

不设置 `devicePixelRatio` 时，高分屏上粒子会模糊。设置后 Canvas 的物理像素和 CSS 像素匹配，显示清晰。

### 6.3 对象池

频繁创建和销毁粒子对象会产生 GC 压力。对象池预先分配固定数量的粒子对象，用"激活/未激活"状态代替创建/销毁：

```javascript
class ParticlePool {
  constructor(size) {
    this.pool = Array.from({ length: size }, () => ({
      active: false,
      x: 0, y: 0, vx: 0, vy: 0,
      life: 0, decay: 0, size: 0
    }))
  }

  spawn(x, y, options = {}) {
    const particle = this.pool.find(p => !p.active)
    if (!particle) return null
    particle.active = true
    particle.x = x
    particle.y = y
    particle.vx = options.vx ?? (Math.random() - 0.5) * 2
    particle.vy = options.vy ?? (Math.random() - 0.5) * 2
    particle.life = 1
    particle.decay = options.decay ?? 0.01
    particle.size = options.size ?? 3
    return particle
  }

  update(ctx) {
    ctx.beginPath()
    this.pool.forEach(p => {
      if (!p.active) return
      p.x += p.vx
      p.y += p.vy
      p.life -= p.decay
      if (p.life <= 0) { p.active = false; return }
      ctx.moveTo(p.x + p.size, p.y)
      ctx.arc(p.x, p.y, p.size * p.life, 0, Math.PI * 2)
    })
    ctx.fillStyle = 'rgba(59, 130, 246, 0.6)'
    ctx.fill()
  }
}
```

### 6.4 粒子数量建议

| 方案 | 建议上限 | 瓶颈 |
|------|----------|------|
| Canvas 2D（无连线） | 500 | 绘制调用 |
| Canvas 2D（有连线） | 200 | O(n²) 距离计算 |
| Canvas 2D + 空间分区 | 1000 | 内存和 GC |
| WebGL | 100,000+ | GPU 显存 |
| WebGL + GPGPU | 1,000,000+ | 计算着色器复杂度 |

## 七、真实项目场景

### 7.1 科技公司官网背景

最常见的应用：深色背景 + 低透明度蓝色粒子 + 连线，营造科技感。粒子数量 100-200，透明度 0.3-0.6，连线距离 100-150px。

### 7.2 加载动画

页面加载时显示粒子聚合效果：粒子从四面八方汇聚到中心，形成 Logo 或文字。加载完成后粒子散开。

### 7.3 按钮反馈

按钮点击时从点击位置发射粒子，增强交互反馈感。粒子数量 20-30，生命周期 0.5-1 秒，颜色和按钮主题色一致。

### 7.4 数据可视化点缀

图表中用粒子表示数据流动方向，比如资金流向、用户迁移路径等。

## 常见误区

1. **粒子数量不加控制**：没有上限的发射器会拖垮帧率。必须设置最大粒子数。
2. **每个粒子单独设置 fillStyle**：频繁切换 `fillStyle` 是 Canvas 2D 的性能杀手。同色粒子应该合并绘制。
3. **忘记清理死亡粒子**：数组会无限膨胀，内存泄漏。每帧都要过滤掉 `life <= 0` 的粒子。
4. **低端设备不做降级**：需要根据设备性能调整粒子数量，移动端减半。
5. **忽略 `devicePixelRatio`**：高分屏上粒子会模糊。
6. **连线检查不做优化**：200 个粒子的 O(n²) 检查是 19,900 次，每帧都做会卡。
7. **用 `clearRect` 代替半透明覆盖**：拖尾效果应该用 `fillRect` + 半透明背景色，而不是完全清除再重绘。

## 工程建议

1. 用 `requestAnimationFrame` 驱动渲染循环，保证和浏览器刷新率同步。
2. 用 `OffscreenCanvas`（Web Worker）把粒子计算移出主线程。
3. 高分屏上设置 `devicePixelRatio` 避免模糊。
4. 粒子系统是氛围层，不应抢走主要内容的注意力——保持低透明度和低饱和度。
5. 用对象池减少 GC 压力，特别是发射器场景。
6. 超过 1000 个粒子时考虑 WebGL 方案。
7. 页面不可见时暂停渲染：`document.addEventListener('visibilitychange', ...)`。
8. 移动端触摸事件用 `touchmove` 代替 `mousemove`，注意坐标转换。

## 小结

本课学习了粒子系统的核心架构、Canvas 2D 粒子场实现、鼠标交互原理、以及 WebGL 粒子的性能优势。从绘制合并到空间分区，从 Canvas 降级到 WebGL 升级，每个优化决策都需要根据粒子数量和设备性能来权衡。

粒子系统的精髓在于：用简单的规则驱动大量个体，涌现出复杂的视觉效果。掌握这个思想，你就能创造出无限多样的动态背景。

### 练习一

**思路**：所有星星用同一个 `fillStyle`，合并到一个路径。闪烁用 `opacity` 属性实现，每帧改变方向。

```javascript
const canvas = document.getElementById('starCanvas')
const ctx = canvas.getContext('2d')
canvas.width = window.innerWidth
canvas.height = window.innerHeight

const stars = Array.from({ length: 300 }, () => ({
  x: Math.random() * canvas.width,
  y: Math.random() * canvas.height,
  vx: (Math.random() - 0.5) * 0.3,
  vy: (Math.random() - 0.5) * 0.3,
  size: 0.5 + Math.random() * 1.5,
  opacity: 0.3 + Math.random() * 0.7,
  flickerSpeed: 0.005 + Math.random() * 0.01,
  flickerDir: 1
}))

function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  ctx.beginPath()
  stars.forEach(s => {
    s.x += s.vx
    s.y += s.vy
    s.opacity += s.flickerSpeed * s.flickerDir
    if (s.opacity >= 1) s.flickerDir = -1
    if (s.opacity <= 0.2) s.flickerDir = 1
    if (s.x < 0 || s.x > canvas.width) s.vx *= -1
    if (s.y < 0 || s.y > canvas.height) s.vy *= -1
    ctx.moveTo(s.x + s.size, s.y)
    ctx.arc(s.x, s.y, s.size, 0, Math.PI * 2)
  })
  ctx.fillStyle = 'rgba(255, 255, 255, 0.8)'
  ctx.fill()

  requestAnimationFrame(animate)
}
animate()
```

**要点**：
- 所有星星合并到一个路径，一次 `fill()` 调用。
- `flickerSpeed` 每个星星不同，产生错落的闪烁效果。
- `flickerDir` 在 1 和 -1 之间切换，控制透明度增减方向。

### 练习二

**思路**：全局粒子数组，点击时 push 50 个，半透明 fillRect 产生拖尾。

```javascript
const canvas = document.getElementById('fireworkCanvas')
const ctx = canvas.getContext('2d')
canvas.width = window.innerWidth
canvas.height = window.innerHeight

const particles = []
const colors = ['#ef4444', '#f59e0b', '#10b981', '#3b82f6', '#8b5cf6', '#ec4899']

canvas.addEventListener('click', (e) => {
  for (let i = 0; i < 50; i++) {
    const angle = Math.random() * Math.PI * 2
    const speed = 2 + Math.random() * 5
    particles.push({
      x: e.clientX,
      y: e.clientY,
      vx: Math.cos(angle) * speed,
      vy: Math.sin(angle) * speed,
      life: 1,
      decay: 0.01 + Math.random() * 0.02,
      size: 2 + Math.random() * 3,
      color: colors[Math.floor(Math.random() * colors.length)]
    })
  }
})

function animate() {
  ctx.fillStyle = 'rgba(15, 23, 42, 0.2)'
  ctx.fillRect(0, 0, canvas.width, canvas.height)

  for (let i = particles.length - 1; i >= 0; i--) {
    const p = particles[i]
    p.x += p.vx
    p.y += p.vy
    p.vy += 0.1
    p.vx *= 0.99
    p.life -= p.decay
    if (p.life <= 0) { particles.splice(i, 1); continue }
    ctx.globalAlpha = p.life
    ctx.beginPath()
    ctx.arc(p.x, p.y, p.size * p.life, 0, Math.PI * 2)
    ctx.fillStyle = p.color
    ctx.fill()
  }
  ctx.globalAlpha = 1
  requestAnimationFrame(animate)
}
animate()
```

**要点**：
- `fillStyle = 'rgba(15, 23, 42, 0.2)'` 每帧覆盖半透明背景，产生拖尾。
- `p.vy += 0.1` 重力加速度，`p.vx *= 0.99` 空气阻力。
- 从后往前遍历，`splice` 不影响后续索引。

### 练习三

**思路**：临时 Canvas 绘制文字，`getImageData` 获取像素，转换为粒子。弹簧力回弹。

```javascript
const canvas = document.getElementById('textCanvas')
const ctx = canvas.getContext('2d')
canvas.width = window.innerWidth
canvas.height = window.innerHeight

const mouse = { x: -1000, y: -1000 }
canvas.addEventListener('mousemove', e => { mouse.x = e.clientX; mouse.y = e.clientY })
canvas.addEventListener('mouseleave', () => { mouse.x = -1000; mouse.y = -1000 })

function getTextPixels(text) {
  const tmp = document.createElement('canvas')
  const tCtx = tmp.getContext('2d')
  tmp.width = canvas.width
  tmp.height = canvas.height
  tCtx.font = 'bold 80px sans-serif'
  tCtx.fillStyle = 'white'
  tCtx.textAlign = 'center'
  tCtx.textBaseline = 'middle'
  tCtx.fillText(text, canvas.width / 2, canvas.height / 2)

  const data = tCtx.getImageData(0, 0, tmp.width, tmp.height)
  const pixels = []
  for (let y = 0; y < tmp.height; y += 4) {
    for (let x = 0; x < tmp.width; x += 4) {
      if (data.data[(y * tmp.width + x) * 4 + 3] > 128) {
        pixels.push({ homeX: x, homeY: y })
      }
    }
  }
  return pixels
}

const particles = getTextPixels('HELLO').map(p => ({
  x: p.homeX, y: p.homeY,
  homeX: p.homeX, homeY: p.homeY,
  vx: 0, vy: 0, size: 1.5
}))

function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  ctx.beginPath()
  particles.forEach(p => {
    const dx = p.x - mouse.x
    const dy = p.y - mouse.y
    const dist = Math.sqrt(dx * dx + dy * dy)
    if (dist < 60 && dist > 0) {
      const force = (60 - dist) / 60
      p.vx += (dx / dist) * force * 5
      p.vy += (dy / dist) * force * 5
    }
    p.vx += (p.homeX - p.x) * 0.03
    p.vy += (p.homeY - p.y) * 0.03
    p.vx *= 0.92
    p.vy *= 0.92
    p.x += p.vx
    p.y += p.vy
    ctx.moveTo(p.x + p.size, p.y)
    ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
  })
  ctx.fillStyle = '#3b82f6'
  ctx.fill()

  requestAnimationFrame(animate)
}
animate()
```

**要点**：
- `getImageData` 获取文字像素，每隔 4 像素采样一个点（降低密度）。
- 弹簧力三要素：排斥力（鼠标靠近时推开）、回弹力（指向原位）、阻尼力（速度衰减）。
- `0.92` 的阻尼系数让粒子在 30-40 帧内回到原位。

### 练习五

**思路**：实现空间分区，对比优化前后的帧率。用 `performance.now()` 测量每帧耗时。

```javascript
class SpatialGrid {
  constructor(width, height, cellSize) {
    this.cellSize = cellSize
    this.cols = Math.ceil(width / cellSize)
    this.rows = Math.ceil(height / cellSize)
    this.cells = new Array(this.cols * this.rows).fill(null).map(() => [])
  }
  clear() { this.cells.forEach(c => c.length = 0) }
  insert(p) {
    const col = Math.floor(p.x / this.cellSize)
    const row = Math.floor(p.y / this.cellSize)
    if (col >= 0 && col < this.cols && row >= 0 && row < this.rows)
      this.cells[row * this.cols + col].push(p)
  }
  getNeighbors(p, radius) {
    const result = []
    const col = Math.floor(p.x / this.cellSize)
    const row = Math.floor(p.y / this.cellSize)
    const cr = Math.ceil(radius / this.cellSize)
    for (let r = row - cr; r <= row + cr; r++) {
      for (let c = col - cr; c <= col + cr; c++) {
        if (r >= 0 && r < this.rows && c >= 0 && c < this.cols)
          this.cells[r * this.cols + c].forEach(n => { if (n !== p) result.push(n) })
      }
    }
    return result
  }
}

const canvas = document.getElementById('gridCanvas')
const ctx = canvas.getContext('2d')
canvas.width = window.innerWidth
canvas.height = window.innerHeight

const particles = Array.from({ length: 200 }, () => ({
  x: Math.random() * canvas.width,
  y: Math.random() * canvas.height,
  vx: (Math.random() - 0.5) * 0.8,
  vy: (Math.random() - 0.5) * 0.8,
  size: 1 + Math.random() * 2
}))

const grid = new SpatialGrid(canvas.width, canvas.height, 150)
const maxDist = 120
let useGrid = true
let frameTime = 0

function drawConnections() {
  const start = performance.now()
  ctx.beginPath()

  if (useGrid) {
    grid.clear()
    particles.forEach(p => grid.insert(p))
    particles.forEach(p => {
      grid.getNeighbors(p, maxDist).forEach(n => {
        const dx = p.x - n.x, dy = p.y - n.y
        const dist = Math.sqrt(dx * dx + dy * dy)
        if (dist < maxDist) {
          ctx.moveTo(p.x, p.y)
          ctx.lineTo(n.x, n.y)
        }
      })
    })
  } else {
    for (let i = 0; i < particles.length; i++) {
      for (let j = i + 1; j < particles.length; j++) {
        const dx = particles[i].x - particles[j].x
        const dy = particles[i].y - particles[j].y
        const dist = Math.sqrt(dx * dx + dy * dy)
        if (dist < maxDist) {
          ctx.moveTo(particles[i].x, particles[i].y)
          ctx.lineTo(particles[j].x, particles[j].y)
        }
      }
    }
  }

  ctx.strokeStyle = 'rgba(59, 130, 246, 0.2)'
  ctx.lineWidth = 0.5
  ctx.stroke()
  frameTime = performance.now() - start
}

function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height)

  particles.forEach(p => {
    p.x += p.vx; p.y += p.vy
    if (p.x < 0 || p.x > canvas.width) p.vx *= -1
    if (p.y < 0 || p.y > canvas.height) p.vy *= -1
  })

  ctx.beginPath()
  particles.forEach(p => {
    ctx.moveTo(p.x + p.size, p.y)
    ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
  })
  ctx.fillStyle = 'rgba(59, 130, 246, 0.6)'
  ctx.fill()

  drawConnections()

  ctx.fillStyle = 'white'
  ctx.font = '14px monospace'
  ctx.fillText(`${useGrid ? '空间分区' : '暴力检查'}: ${frameTime.toFixed(2)}ms`, 10, 25)

  requestAnimationFrame(animate)
}
animate()

// 按空格键切换模式
document.addEventListener('keydown', e => {
  if (e.code === 'Space') useGrid = !useGrid
})
```

**要点**：
- 空间分区将连线检查从 O(n²) 降到接近 O(n)。
- 按空格键切换两种模式，对比底部显示的耗时。
- 200 个粒子时，暴力检查约 19,900 次，空间分区通常只需几百次。
