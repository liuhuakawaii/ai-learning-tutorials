# Stage 2：CSS 高级动效

> 突破 CSS 动画的平面限制，进入 3D、SVG、滚动驱动的高级领域。

## 本阶段目标

- 掌握 CSS 3D 变换和透视原理
- 理解 SVG 路径动画和 morphing 技术
- 实现滚动驱动动画和视差效果
- 用 Canvas 构建粒子系统

## 课时列表

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 3D 变换动画 | perspective、transform-style、背面可见性 |
| 02 | SVG 动画 | path 动画、stroke-dashoffset、形状变形 |
| 03 | 滚动驱动动画 | scroll-timeline、IntersectionObserver |
| 04 | 视差效果 | 多层视差、滚动联动 |
| 05 | 粒子系统 | Canvas 粒子、WebGL 粒子基础 |
| 06 | 阶段实战 | D3 + 动画的交互式数据可视化 |

## 学完本阶段你能

- 用 CSS 3D 实现翻转卡片、立方体等立体效果
- 用 SVG 路径动画实现 logo 描边、形状变形
- 实现高性能的滚动驱动动画
- 用 Canvas 构建千级粒子的实时动画
