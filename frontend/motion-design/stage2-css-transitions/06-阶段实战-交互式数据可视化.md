# 06 - 阶段实战：交互式数据可视化

## 场景引入

前五课学的 3D 变换、SVG 动画、滚动驱动、视差效果、粒子系统，每一项都是独立技术。真实项目中它们往往需要组合使用。本课用一个完整实战项目——交互式数据可视化仪表盘——把前面的技术串起来。

想象你接到一个需求：为一家互联网公司搭建数据仪表盘，需要展示用户增长、收入趋势、产品占比等数据。产品经理说："数字要动起来，图表要有入场动画，整体要有科技感。"这就是本课要解决的问题。

技术栈：原生 HTML/CSS/JS + D3.js（数据绑定和图表生成）+ 前面学到的动画技术。

## 一、D3.js 快速入门

### 1.1 核心思想

D3（Data-Driven Documents）的核心是**数据驱动 DOM**：把数据绑定到 DOM 元素，数据变化时自动更新。这和手动操作 DOM 的区别在于：

- **手动方式**：`for` 循环创建元素，数据变了要重新循环
- **D3 方式**：声明式绑定，D3 自动处理增删改

```html
<div id="chart"></div>
<script src="https://d3js.org/d3.v7.min.js"></script>
```

```javascript
const data = [85, 120, 90, 150, 200, 170]

const svg = d3.select('#chart')
  .append('svg')
  .attr('width', 400)
  .attr('height', 300)

svg.selectAll('rect')
  .data(data)
  .enter()
  .append('rect')
  .attr('x', (d, i) => i * 55 + 10)
  .attr('y', d => 300 - d)
  .attr('width', 40)
  .attr('height', d => d)
  .attr('fill', '#3b82f6')
```

`selectAll().data().enter().append()` 是 D3 经典模式：**选择 → 绑定 → 创建**。

### 1.2 数据绑定三模式

D3 的数据绑定有三个核心操作：

1. **enter（进入）**：数据比 DOM 元素多，需要创建新元素
2. **update（更新）**：数据和 DOM 元素一一对应，更新属性
3. **exit（退出）**：DOM 元素比数据多，需要删除多余元素

```javascript
const update = svg.selectAll('rect').data(data)

// 进入：创建新元素
update.enter()
  .append('rect')
  .attr('x', (d, i) => i * 55 + 10)
  .attr('width', 40)
  .attr('fill', '#3b82f6')
  .attr('y', 300)
  .attr('height', 0)
  .transition().duration(800)
  .attr('y', d => 300 - d)
  .attr('height', d => d)

// 更新：修改已有元素
update.transition().duration(800)
  .attr('y', d => 300 - d)
  .attr('height', d => d)

// 退出：删除多余元素
update.exit()
  .transition().duration(400)
  .attr('height', 0)
  .attr('y', 300)
  .remove()
```

## 二、比例尺和坐标轴

### 2.1 为什么需要比例尺

真实数据不是像素值。如果数据是 [85, 120, 90, 150, 200, 170]，你不能直接用 `200` 作为像素高度——可能是 `200px`，也可能是 `200万`。比例尺把数据值映射到屏幕范围。

### 2.2 比例尺类型

| 比例尺 | 用途 | 示例 |
|--------|------|------|
| `scaleLinear` | 连续数据 → 连续范围 | 温度 → 像素高度 |
| `scaleBand` | 分类数据 → 均匀分布 | 月份 → 柱子位置 |
| `scaleTime` | 时间数据 → 连续范围 | 日期 → X 轴位置 |
| `scaleOrdinal` | 分类数据 → 颜色 | 类别 → 颜色 |

### 2.3 完整坐标轴示例

```javascript
const dataset = [
  { month: '1月', value: 85 },
  { month: '2月', value: 120 },
  { month: '3月', value: 90 },
  { month: '4月', value: 150 },
  { month: '5月', value: 200 },
  { month: '6月', value: 170 }
]

const margin = { top: 20, right: 20, bottom: 40, left: 50 }
const width = 500 - margin.left - margin.right
const height = 300 - margin.top - margin.bottom

const x = d3.scaleBand()
  .domain(dataset.map(d => d.month))
  .range([0, width])
  .padding(0.3)

const y = d3.scaleLinear()
  .domain([0, d3.max(dataset, d => d.value)])
  .range([height, 0])

const svg = d3.select('#chart')
  .append('svg')
  .attr('width', width + margin.left + margin.right)
  .attr('height', height + margin.top + margin.bottom)
  .append('g')
  .attr('transform', `translate(${margin.left},${margin.top})`)

// X 轴
svg.append('g')
  .attr('transform', `translate(0,${height})`)
  .call(d3.axisBottom(x))
  .selectAll('text')
  .attr('fill', '#94a3b8')

// Y 轴
svg.append('g')
  .call(d3.axisLeft(y).ticks(5))
  .selectAll('text')
  .attr('fill', '#94a3b8')

// 网格线
svg.append('g')
  .attr('class', 'grid')
  .call(d3.axisLeft(y).ticks(5).tickSize(-width).tickFormat(''))
  .selectAll('line')
  .attr('stroke', '#1e293b')
  .attr('stroke-dasharray', '3,3')

svg.selectAll('.grid .domain').remove()
```

`scaleBand` 用于分类数据，自动计算每个柱子的位置和宽度。`scaleLinear` 用于连续数据，把数据值映射到像素高度。

### 3.3 完整的柱状图组件

把柱状图封装成可复用的组件：

```javascript
function createBarChart(container, data, options = {}) {
  const {
    width = 500, height = 300,
    margin = { top: 20, right: 20, bottom: 40, left: 50 },
    color = '#3b82f6', animationDuration = 800, staggerDelay = 100
  } = options

  const innerWidth = width - margin.left - margin.right
  const innerHeight = height - margin.top - margin.bottom

  const x = d3.scaleBand()
    .domain(data.map(d => d.label))
    .range([0, innerWidth])
    .padding(0.3)

  const y = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.value) * 1.1])
    .range([innerHeight, 0])

  const svg = d3.select(container)
    .append('svg')
    .attr('width', width)
    .attr('height', height)
    .append('g')
    .attr('transform', `translate(${margin.left},${margin.top})`)

  // X 轴
  svg.append('g')
    .attr('transform', `translate(0,${innerHeight})`)
    .call(d3.axisBottom(x))
    .attr('class', 'axis')

  // Y 轴
  svg.append('g')
    .call(d3.axisLeft(y).ticks(5))
    .attr('class', 'axis')

  // 柱子
  const bars = svg.selectAll('.bar')
    .data(data)
    .enter()
    .append('rect')
    .attr('class', 'bar')
    .attr('x', d => x(d.label))
    .attr('width', x.bandwidth())
    .attr('y', innerHeight)
    .attr('height', 0)
    .attr('fill', color)
    .attr('rx', 4)

  // 入场动画
  bars.transition()
    .duration(animationDuration)
    .delay((d, i) => i * staggerDelay)
    .ease(d3.easeCubicOut)
    .attr('y', d => y(d.value))
    .attr('height', d => innerHeight - y(d.value))

  // 更新方法
  return {
    update(newData) {
      const t = d3.transition().duration(animationDuration).ease(d3.easeCubicOut)
      y.domain([0, d3.max(newData, d => d.value) * 1.1])
      svg.select('.axis').transition(t).call(d3.axisLeft(y).ticks(5))
      svg.selectAll('.bar').data(newData, d => d.label)
        .transition(t)
        .attr('y', d => y(d.value))
        .attr('height', d => innerHeight - y(d.value))
    }
  }
}
```

## 四、环形图 + 描边动画

### 4.1 基础环形图

用 D3 生成环形图，配合 `attrTween` 实现弧线生长动画：

```javascript
const pieData = [
  { label: '产品A', value: 35 },
  { label: '产品B', value: 25 },
  { label: '产品C', value: 20 },
  { label: '产品D', value: 20 }
]

const pie = d3.pie().value(d => d.value).sort(null)
const arc = d3.arc().innerRadius(60).outerRadius(100)
const colors = ['#3b82f6', '#10b981', '#f59e0b', '#ef4444']

const pieSvg = d3.select('#donut')
  .append('svg').attr('width', 250).attr('height', 250)
  .append('g').attr('transform', 'translate(125,125)')

pieSvg.selectAll('path')
  .data(pie(pieData))
  .enter()
  .append('path')
  .attr('fill', (d, i) => colors[i])
  .attr('stroke', 'white').attr('stroke-width', 2)
  .style('opacity', 0)
  .transition().duration(600).delay((d, i) => i * 200)
  .style('opacity', 1)
  .attrTween('d', function(d) {
    const interpolate = d3.interpolate(
      { startAngle: d.startAngle, endAngle: d.startAngle }, d
    )
    return t => arc(interpolate(t))
  })
```

`attrTween` 对任意属性做插值，让每段弧从起角"生长"到终止角。

### 4.2 环形图交互

悬停时扇区向外突出，显示数值：

```javascript
const arcHover = d3.arc().innerRadius(60).outerRadius(110)

pieSvg.selectAll('path')
  .data(pie(pieData))
  .enter()
  .append('path')

  .attr('stroke', 'white')

  .on('mouseenter', function(event, d) {
    d3.select(this)
      .transition().duration(200)
      .attr('d', arcHover)

    const percent = ((d.endAngle - d.startAngle) / (Math.PI * 2) * 100).toFixed(1)
    d3.select('#tooltip')
      .style('display', 'block')
      .style('left', event.pageX + 10 + 'px')
      .style('top', event.pageY - 30 + 'px')
      .html(`${d.data.label}: ${d.data.value} (${percent}%)`)
  })
  .on('mouseleave', function() {
    d3.select(this)
      .transition().duration(200)
      .attr('d', arc)
    d3.select('#tooltip').style('display', 'none')
  })
```

### 5.2 数字滚动动画

数值从 0 滚动到目标值，配合缓动函数：

```javascript
function animateNumber(element, target, duration = 1500) {
  const startTime = performance.now()
  function update(currentTime) {
    const progress = Math.min((currentTime - startTime) / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3)  // easeOutCubic
    element.textContent = Math.round(target * eased).toLocaleString()
    if (progress < 1) requestAnimationFrame(update)
  }
  requestAnimationFrame(update)
}

document.querySelectorAll('.card-number').forEach(el => {
  animateNumber(el, parseInt(el.dataset.target))
})
```

### 5.3 带前缀/后缀的数字动画

实际项目中数字常常需要前缀（¥）或后缀（%）：

```javascript
function animateFormattedNumber(element, target, options = {}) {
  const {
    duration = 1500,
    prefix = '',
    suffix = '',
    decimals = 0,
    separator = ','
  } = options

  const startTime = performance.now()
  function update(currentTime) {
    const progress = Math.min((currentTime - startTime) / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3)
    const current = target * eased
    const formatted = current.toFixed(decimals)
      .replace(/\B(?=(\d{3})+(?!\d))/g, separator)
    element.textContent = prefix + formatted + suffix
    if (progress < 1) requestAnimationFrame(update)
  }
  requestAnimationFrame(update)
}

// 使用
animateFormattedNumber(document.getElementById('revenue'), 1258000, {
  prefix: '¥',
  suffix: '',
  decimals: 0
})

animateFormattedNumber(document.getElementById('growth'), 12.5, {
  prefix: '',
  suffix: '%',
  decimals: 1
})
```

## 七、折线图 + 描边动画

### 7.1 折线入场动画

折线从左到右逐步绘制，类似 SVG 描边效果：

```javascript
function createLineChart(container, data) {
  const margin = { top: 20, right: 20, bottom: 40, left: 50 }
  const width = 500 - margin.left - margin.right
  const height = 300 - margin.top - margin.bottom

  const x = d3.scaleLinear()
    .domain([0, data.length - 1])
    .range([0, width])

  const y = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.value) * 1.1])
    .range([height, 0])

  const svg = d3.select(container)
    .append('svg')
    .attr('width', width + margin.left + margin.right)
    .attr('height', height + margin.top + margin.bottom)
    .append('g')
    .attr('transform', `translate(${margin.left},${margin.top})`)

  // 坐标轴
  svg.append('g')
    .attr('transform', `translate(0,${height})`)
    .call(d3.axisBottom(x).ticks(data.length))

  svg.append('g')
    .call(d3.axisLeft(y).ticks(5))

  // 折线生成器
  const line = d3.line()
    .x((d, i) => x(i))
    .y(d => y(d.value))
    .curve(d3.curveMonotoneX)

  // 渐变区域
  const area = d3.area()
    .x((d, i) => x(i))
    .y0(height)
    .y1(d => y(d.value))
    .curve(d3.curveMonotoneX)

  // 绘制渐变
  const gradient = svg.append('defs')
    .append('linearGradient')
    .attr('id', 'area-gradient')
    .attr('x1', '0%').attr('y1', '0%')
    .attr('x2', '0%').attr('y2', '100%')

  gradient.append('stop').attr('offset', '0%').attr('stop-color', '#3b82f6').attr('stop-opacity', 0.3)
  gradient.append('stop').attr('offset', '100%').attr('stop-color', '#3b82f6').attr('stop-opacity', 0)

  svg.append('path')
    .datum(data)
    .attr('fill', 'url(#area-gradient)')
    .attr('d', area)

  // 折线描边动画
  const path = svg.append('path')
    .datum(data)
    .attr('fill', 'none')
    .attr('stroke', '#3b82f6')
    .attr('stroke-width', 2.5)
    .attr('d', line)

  const totalLength = path.node().getTotalLength()
  path
    .attr('stroke-dasharray', totalLength)
    .attr('stroke-dashoffset', totalLength)
    .transition().duration(2000).ease(d3.easeCubicInOut)
    .attr('stroke-dashoffset', 0)

  // 数据点在线到达时出现
  svg.selectAll('.dot')
    .data(data)
    .enter()
    .append('circle')
    .attr('cx', (d, i) => x(i))
    .attr('cy', d => y(d.value))
    .attr('r', 0)
    .attr('fill', '#3b82f6')
    .attr('stroke', 'white')
    .attr('stroke-width', 2)
    .transition().duration(400)
    .delay((d, i) => 2000 / data.length * i + 200)
```

**要点**：

## 八、背景粒子氛围

### 8.1 低透明度粒子层

用第五课的粒子技术添加低透明度背景粒子层。粒子数量 50 个，透明度 0.15——它是氛围层，不应抢走数据的注意力。

```javascript
function createAmbientParticles(canvas) {
  const ctx = canvas.getContext('2d')
  const dpr = window.devicePixelRatio || 1

  function resize() {
    canvas.width = canvas.clientWidth * dpr
    canvas.height = canvas.clientHeight * dpr
    ctx.scale(dpr, dpr)
  }
  resize()
  window.addEventListener('resize', resize)

  const particles = Array.from({ length: 50 }, () => ({
    x: Math.random() * canvas.clientWidth,
    y: Math.random() * canvas.clientHeight,
    vx: (Math.random() - 0.5) * 0.3,
    vy: (Math.random() - 0.5) * 0.3,
    size: 1 + Math.random() * 2,
    opacity: 0.05 + Math.random() * 0.15
  }))

  function animate() {
    ctx.clearRect(0, 0, canvas.clientWidth, canvas.clientHeight)
    ctx.beginPath()
    particles.forEach(p => {
      p.x += p.vx
      p.y += p.vy
      if (p.x < 0 || p.x > canvas.clientWidth) p.vx *= -1
      if (p.y < 0 || p.y > canvas.clientHeight) p.vy *= -1
      ctx.moveTo(p.x + p.size, p.y)
      ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2)
    })
    ctx.fillStyle = 'rgba(59, 130, 246, 0.15)'
    ctx.fill()
    requestAnimationFrame(animate)
  }
  animate()
}
```

### 8.2 粒子与页面可见性

页面不可见时暂停粒子渲染，节省性能：

```javascript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    cancelAnimationFrame(animationId)
  } else {
    animationId = requestAnimationFrame(animate)
  }
})
```

## 常见误区

1. **动画喧宾夺主**：数据可视化中，数据是主角，动画是辅助。入场动画不超过 2 秒，悬停反馈不超过 200ms。
2. **D3 和 CSS 动画冲突**：图表内部用 D3 transition，外部用 CSS。不要同时用两种方式动画同一个属性。
3. **大数据量不做优化**：几千个数据点逐个动画会卡顿，应做数据聚合或采样。
4. **数字格式不统一**：金额加千分位，百分比保留小数位，单位一致。
5. **忽略移动端触摸**：不能只依赖 hover，需要支持 touch 事件。
6. **图表不提供文字替代**：屏幕阅读器用户无法理解纯视觉图表。
7. **颜色仅靠色相区分**：色盲用户可能无法区分红绿色，应同时用形状或图案区分。

## 工程建议

1. D3 负责数据处理和图表生成，CSS/GSAP 负责动画——各司其职。
2. 图表入场动画的错落延迟不超过数据项数量 × 100ms。
3. 数字滚动动画时长控制在 1-2 秒。
4. 移动端图表要考虑触摸交互，不能只依赖 hover。
5. 用 `IntersectionObserver` 延迟渲染不可见的图表，减少首屏压力。
6. 粒子背景是氛围层，数量控制在 50 以内，透明度 0.1-0.2。
7. 为所有图表提供数据表格的替代方案，确保可访问性。
8. 数据更新时用 D3 的 enter/update/exit 模式，而不是清空重绘。

```javascript

    month,
    value: 50 + Math.round(Math.random() * 200)

function updateBarChart(newData) {
  y.domain([0, d3.max(newData, d => d.value) * 1.1])

  svg.selectAll('.bar')
    .data(newData, d => d.month)
    .transition()
    .duration(800)
    .ease(d3.easeCubicOut)
    .attr('y', d => y(d.value))
    .attr('height', d => height - y(d.value))

  svg.select('.y-axis')
    .transition()
    .duration(800)
    .call(d3.axisLeft(y).ticks(5))
}

function animateNumber(element, target, duration = 800) {
  const startTime = performance.now()
  const startValue = parseInt(element.textContent.replace(/,/g, '')) || 0
  function update(currentTime) {
    const progress = Math.min((currentTime - startTime) / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3)
    const current = startValue + (target - startValue) * eased
    element.textContent = Math.round(current).toLocaleString()
    if (progress < 1) requestAnimationFrame(update)
  }
  requestAnimationFrame(update)
}

document.getElementById('refreshBtn').addEventListener('click', () => {
  const newData = generateRandomData()
  updateBarChart(newData)
  document.querySelectorAll('.card-number').forEach(el => {
    const target = 10000 + Math.round(Math.random() * 5000)
    animateNumber(el, target, 800)
  })
})
```

**要点**：
- D3 用 key 函数 `d => d.month` 确保数据正确对应 DOM 元素。
- `animateNumber` 从当前值开始动画，而不是从 0 开始，避免刷新时数字跳变。
- `easeOutCubic` 缓动让数字先快后慢，视觉上更自然。

### 练习四

**思路**：使用 `attrTween` 实现扇区入场动画，悬停时用更大的 `outerRadius` 的 arc 突出扇区。

```javascript
const pieData = [
  { label: '产品A', value: 35 },
  { label: '产品B', value: 25 },
  { label: '产品C', value: 20 },
  { label: '产品D', value: 20 }
]

const pie = d3.pie().value(d => d.value).sort(null)
const arc = d3.arc().innerRadius(60).outerRadius(100)
const arcHover = d3.arc().innerRadius(60).outerRadius(115)
const colors = ['#3b82f6', '#10b981', '#f59e0b', '#ef4444']

const svg = d3.select('#donut')
  .append('svg').attr('width', 300).attr('height', 300)
  .append('g').attr('transform', 'translate(150,150)')

const paths = svg.selectAll('path')
  .data(pie(pieData))
  .enter()
  .append('path')
  .attr('fill', (d, i) => colors[i])
  .attr('stroke', 'white')
  .attr('stroke-width', 2)
  .style('cursor', 'pointer')

// 入场动画
paths.transition().duration(600).delay((d, i) => i * 200)
  .attrTween('d', function(d) {
    const interpolate = d3.interpolate(
      { startAngle: d.startAngle, endAngle: d.startAngle }, d
    )
    return t => arc(interpolate(t))
  })

// 悬停交互
paths
  .on('mouseenter', function(event, d) {
    d3.select(this)
      .transition().duration(200)
      .attr('d', arcHover)

    const percent = ((d.endAngle - d.startAngle) / (Math.PI * 2) * 100).toFixed(1)
    svg.append('text')
      .attr('class', 'hover-label')
      .attr('text-anchor', 'middle')
      .attr('fill', '#e2e8f0')
      .attr('font-size', '14px')
      .attr('font-weight', 'bold')
      .text(`${d.data.label}: ${d.data.value} (${percent}%)`)
      .style('opacity', 0)
      .transition().duration(200)
      .style('opacity', 1)
  })
  .on('mouseleave', function() {
    d3.select(this)
      .transition().duration(200)
      .attr('d', arc)
    svg.selectAll('.hover-label')
      .transition().duration(200)
      .style('opacity', 0)
      .remove()
  })

// 中心总数
const total = pieData.reduce((sum, d) => sum + d.value, 0)
svg.append('text')
  .attr('text-anchor', 'middle')
  .attr('dy', '0.35em')
  .attr('fill', '#e2e8f0')
  .attr('font-size', '24px')
  .attr('font-weight', 'bold')
  .text(total)
```

**要点**：
- `attrTween` 对 `d` 属性做插值，让每段弧从起角"生长"到终止角。
- 悬停时用 `arcHover`（更大的 `outerRadius`）让扇区突出。
- 中心显示总数，使用 `text-anchor: middle` 居中。

```javascript
// 数字动画
function animateNumber(el, target, duration = 1500) {
  const startTime = performance.now()
  function update(t) {
    const progress = Math.min((t - startTime) / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3)
    el.textContent = Math.round(target * eased).toLocaleString()
    if (progress < 1) requestAnimationFrame(update)
  }
  requestAnimationFrame(update)
}

// 卡片入场
const cardObserver = new IntersectionObserver(entries => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const card = entry.target
      const delay = parseInt(card.dataset.delay) || 0
      setTimeout(() => {
        card.classList.add('animate-in')
        const num = card.querySelector('.card-number')
        if (num) animateNumber(num, parseInt(num.dataset.target))
      }, delay)
      cardObserver.unobserve(card)
    }
  })
}, { threshold: 0.3 })

document.querySelectorAll('.data-card').forEach((card, i) => {
  card.dataset.delay = i * 150
  cardObserver.observe(card)
})

// 图表入场
const chartObserver = new IntersectionObserver(entries => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('chart-visible')
      chartObserver.unobserve(entry.target)
    }
  })
}, { threshold: 0.3 })

document.querySelectorAll('.chart-container').forEach(el => chartObserver.observe(el))

// 背景粒子
createAmbientParticles(document.getElementById('particleBg'))

// 刷新按钮
document.getElementById('refreshBtn').addEventListener('click', () => {
  document.querySelectorAll('.card-number').forEach(el => {
    animateNumber(el, 5000 + Math.round(Math.random() * 15000), 800)
  })
})
```

**要点**：
- 卡片和图表分别用不同的 `IntersectionObserver` 控制入场。
- 卡片有错落延迟（`i * 150ms`），视觉上更优雅。
- 粒子背景是氛围层，数量少、透明度低，不抢夺注意力。
- 响应式布局在移动端自动调整列数。
- `prefers-reduced-motion` 媒体查询尊重用户动画偏好。
