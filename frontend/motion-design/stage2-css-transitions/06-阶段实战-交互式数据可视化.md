# 阶段实战：交互式数据可视化仪表盘

## 做什么

把前五课的 3D 变换、SVG 动画、滚动驱动、视差、粒子技术组合到一个项目里：带动画的数据仪表盘。

需求：数字滚动、柱状图入场、环形图描边、折线图逐步绘制、背景粒子氛围。所有图表滚动到视口才渲染。

## D3.js 核心：数据驱动 DOM

```javascript
const data = [85, 120, 90, 150, 200, 170]

d3.select('#chart').append('svg').attr('width', 400).attr('height', 300)
  .selectAll('rect').data(data).enter().append('rect')
  .attr('x', (d, i) => i * 55 + 10)
  .attr('y', d => 300 - d)
  .attr('width', 40)
  .attr('height', d => d)
  .attr('fill', '#3b82f6')
```

`selectAll().data().enter().append()` —— 选择、绑定、创建。数据比 DOM 多就创建新元素，少就删除多余的。

## 比例尺

真实数据不是像素值。比例尺把数据映射到屏幕范围：

```javascript
const x = d3.scaleBand()
  .domain(dataset.map(d => d.month))
  .range([0, width])
  .padding(0.3)

const y = d3.scaleLinear()
  .domain([0, d3.max(dataset, d => d.value)])
  .range([height, 0])
```

`scaleBand` 用于分类数据，`scaleLinear` 用于连续数据。

## 带入场动画的柱状图

柱子从底部生长，错落出现：

```javascript
svg.selectAll('.bar').data(dataset).enter()
  .append('rect').attr('class', 'bar')
  .attr('x', d => x(d.month))
  .attr('width', x.bandwidth())
  .attr('y', height).attr('height', 0)
  .attr('fill', '#3b82f6').attr('rx', 4)
  .transition().duration(800)
  .delay((d, i) => i * 100)
  .ease(d3.easeCubicOut)
  .attr('y', d => y(d.value))
  .attr('height', d => height - y(d.value))
```

D3 的 `.transition()` 直接在数据绑定后加动画。`delay` 实现错落。

## 环形图 + 描边动画

`attrTween` 对弧线做插值，让每段弧从起角"生长"到终止角：

```javascript
const pie = d3.pie().value(d => d.value).sort(null)
const arc = d3.arc().innerRadius(60).outerRadius(100)

svg.selectAll('path').data(pie(pieData)).enter()
  .append('path')
  .attr('fill', (d, i) => colors[i])
  .attr('stroke', '#fff').attr('stroke-width', 2)
  .transition().duration(600).delay((d, i) => i * 200)
  .attrTween('d', function(d) {
    const interp = d3.interpolate(
      { startAngle: d.startAngle, endAngle: d.startAngle }, d
    )
    return t => arc(interp(t))
  })
```

悬停时扇区突出用更大的 `outerRadius`：

```javascript
const arcHover = d3.arc().innerRadius(60).outerRadius(115)
.on('mouseenter', function(e, d) {
  d3.select(this).transition().duration(200).attr('d', arcHover)
})
.on('mouseleave', function() {
  d3.select(this).transition().duration(200).attr('d', arc)
})
```

## 数字滚动动画

```javascript
function animateNumber(el, target, duration = 1500) {
  const start = performance.now()
  function tick(now) {
    const p = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - p, 3)  // easeOutCubic
    el.textContent = Math.round(target * eased).toLocaleString()
    if (p < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
```

带前缀后缀的版本：

```javascript
function animateFormatted(el, target, { prefix = '', suffix = '', duration = 1500 } = {}) {
  const start = performance.now()
  function tick(now) {
    const p = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - p, 3)
    el.textContent = prefix + Math.round(target * eased).toLocaleString() + suffix
    if (p < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
// animateFormatted(el, 1258000, { prefix: '¥' })
```

## 折线图描边动画

`stroke-dashoffset` 从全长到 0，实现从左到右绘制：

```javascript
const path = svg.append('path').datum(data)
  .attr('fill', 'none').attr('stroke', '#3b82f6')
  .attr('stroke-width', 2.5).attr('d', line)

const totalLength = path.node().getTotalLength()
path
  .attr('stroke-dasharray', totalLength)
  .attr('stroke-dashoffset', totalLength)
  .transition().duration(2000).ease(d3.easeCubicInOut)
  .attr('stroke-dashoffset', 0)

// 数据点在线到达时出现
svg.selectAll('.dot').data(data).enter()
  .append('circle')
  .attr('cx', (d, i) => x(i)).attr('cy', d => y(d.value))
  .attr('r', 0).attr('fill', '#3b82f6').attr('stroke', '#fff').attr('stroke-width', 2)
  .transition().duration(400)
  .delay((d, i) => 2000 / data.length * i + 200)
  .attr('r', 5)
```

## 滚动触发入场

```javascript
const observer = new IntersectionObserver(entries => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const el = entry.target
      const delay = parseInt(el.dataset.delay) || 0
      setTimeout(() => {
        el.classList.add('visible')
        const num = el.querySelector('.card-number')
        if (num) animateNumber(num, parseInt(num.dataset.target))
      }, delay)
      observer.unobserve(el)
    }
  })
}, { threshold: 0.3 })

document.querySelectorAll('.data-card').forEach((card, i) => {
  card.dataset.delay = i * 150
  observer.observe(card)
})
```

## 背景粒子氛围

50 个低透明度粒子——它是氛围层，不抢数据注意力：

```javascript
function createParticles(canvas) {
  const ctx = canvas.getContext('2d')
  function resize() { canvas.width = canvas.clientWidth; canvas.height = canvas.clientHeight }
  resize(); window.addEventListener('resize', resize)

  const particles = Array.from({ length: 50 }, () => ({
    x: Math.random() * canvas.clientWidth,
    y: Math.random() * canvas.clientHeight,
    vx: (Math.random() - 0.5) * 0.3,
    vy: (Math.random() - 0.5) * 0.3,
    size: 1 + Math.random() * 2,
  }))

  function draw() {
    ctx.clearRect(0, 0, canvas.width, canvas.height)
    ctx.fillStyle = 'rgba(59, 130, 246, 0.12)'
    particles.forEach(p => {
      p.x += p.vx; p.y += p.vy
      if (p.x < 0 || p.x > canvas.width) p.vx *= -1
      if (p.y < 0 || p.y > canvas.height) p.vy *= -1
      ctx.beginPath(); ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2); ctx.fill()
    })
    requestAnimationFrame(draw)
  }
  draw()
}
```

页面不可见时暂停：`document.addEventListener('visibilitychange', ...)`。

## 练习

### 练习一：完整仪表盘

4 张数据卡片（3D 翻转 + 数字滚动）+ 柱状图（入场 + 悬停）+ 环形图（描边 + 点击高亮）+ 折线图（描边 + 数据点）+ 背景粒子。响应式布局，IntersectionObserver 控制入场。

### 练习二：数据刷新

添加"刷新"按钮，点击后随机更新所有数据。图表用 D3 transition 平滑过渡，数字从当前值滚动到新值（不是从 0 开始）。

### 练习三：环形图交互

环形图悬停时扇区突出并显示百分比标签。点击扇区时高亮并显示详情面板。

关键点：

- `prefers-reduced-motion` 媒体查询尊重用户偏好

### 练习二

```javascript
function animateNumber(el, target, duration = 800) {
  const start = performance.now()
  const from = parseInt(el.textContent.replace(/,/g, '')) || 0
  function tick(now) {
    const p = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - p, 3)
    el.textContent = Math.round(from + (target - from) * eased).toLocaleString()
    if (p < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
```

从当前值开始，不是从 0，避免刷新时数字跳变。
