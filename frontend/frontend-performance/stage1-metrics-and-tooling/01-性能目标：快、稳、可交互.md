# 性能目标：快、稳、可交互——不是玄学，是指标

## 现象

团队刚完成电商改版，老板在旗舰手机上体验流畅，很满意。但运营数据：移动端转化率下降 15%，跳出率上升 20%。用低端安卓机测试：首屏 6 秒，点击"加入购物车"后将近 1 秒才有反应，广告位把商品列表挤来挤去。

用户不会告诉你页面慢，他们只会默默离开。

## 性能影响的是真金白银

```
Amazon：页面加载每慢 100ms，销售额下降 1%
Google：搜索结果每慢 500ms，流量下降 20%
BBC：页面每多 1 秒，流失 10% 用户
```

## 用户感知的三个维度

```
快（Speed）
  页面内容多快能展示出来？
  对应指标：LCP（Largest Contentful Paint）
  标准：≤ 2.5s 良好，2.5-4s 需改进，> 4s 差

稳（Stability）
  页面加载过程中内容会不会乱跳？
  对应指标：CLS（Cumulative Layout Shift）
  标准：≤ 0.1 良好，0.1-0.25 需改进，> 0.25 差

可交互（Interactivity）
  点击按钮后多久才有反应？
  对应指标：INP（Interaction to Next Paint）
  标准：≤ 200ms 良好，200-500ms 需改进，> 500ms 差
```

## LCP：最大内容绘制

LCP 是页面上最大的内容块出现的时间。通常是 Hero 图片、大标题或视频封面。

```
用户打开页面后的心理时间线：

  0ms        页面空白 ────────────────────── 用户：还在等...
  500ms      开始出现内容 ────────────────── 用户：好像在加载
  1000ms     主要内容出现 ────────────────── 用户：可以了
  2500ms     所有内容加载完成 ────────────── 用户：不错
  4000ms     还在转圈 ────────────────────── 用户：怎么这么慢？
  8000ms     还是空白 ────────────────────── 用户：算了不等了
```

## CLS：累积布局偏移

你正在看文章，准备点击一个链接。突然一个广告加载出来，整个页面往下移——你点到了广告而不是你想点的链接。

常见原因：
- 图片没有设置宽高
- 动态插入的内容（广告、Cookie 提示）
- Web 字体加载导致文字宽度变化
- JS 异步加载后渲染列表

## INP：交互到下次绘制

页面加载完成了，但用户点了按钮，过了半秒才反应——这就是交互延迟。

```
0 ~ 100ms    感觉是"即时"的
100 ~ 300ms  有延迟但可接受
300ms ~ 1s   明显感觉卡
> 1s         完全失去耐心
```

常见原因：
- 大量未优化的 JS 一次性执行
- 复杂的 DOM 操作
- 同步的布局计算
- 第三方脚本

## 正确的优化流程

```
❌ 错误：觉得页面慢 → 压缩图片
✅ 正确：
  1. 先用工具测量，拿到数据
  2. 找到最大的瓶颈
  3. 针对性优化
  4. 再次测量，对比效果
  5. 记录优化前后数据
```

口诀：**测量 → 定位 → 优化 → 验证 → 记录**

## Lighthouse 分数不是一切

```
Lighthouse Performance: 98 分
"我们的网站性能非常好！"

但是...
真实用户数据（CrUX）：
  LCP P75 = 4.5s   (Poor!)
  INP P75 = 380ms  (Needs Improvement!)

Lighthouse 是在你的笔记本上跑的
真实用户用的是千元机 + 3G 网络
```

Lighthouse 是 Lab 数据，真实用户数据才是 Field 数据。两者都需要关注，但最终以 Field 数据为准。

## 练习

### 练习一：跑一次 Lighthouse

打开任意网站，F12 → Lighthouse → Performance，记录 Performance 得分和三个 Core Web Vitals 指标。

### 练习二：感受布局抖动

找一个新闻网站，用手机打开，慢慢滚动，观察内容抖动。记录抖动次数和原因。

---

## 参考答案

### 练习一

以电商网站为例（实际结果因网站而异）：
```
Performance Score: 62
LCP: 3.8s (Needs Improvement) → 首屏 hero 图片
INP: 280ms (Needs Improvement) → 搜索框输入
CLS: 0.08 (Good) → 图片设置了尺寸
```

LCP 最差是因为首屏图片 800KB JPEG，没有 preload。

### 练习二

典型观察：3-5 次抖动。
- 头图加载后撑开空间 → img 没有 width/height
- 广告位加载 → 从顶部插入横幅
- 字体切换 → Web 字体加载后文字宽度变化
- 评论区加载 → JS 异步加载组件
