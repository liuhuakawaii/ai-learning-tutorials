# 阶段实战：性能监控面板——持续保障性能

## 现象

你的页面性能优化达标了，但怎么确保不会退化？需要一个持续监控系统。

## 监控架构

```
用户浏览器
  │
  ├─→ web-vitals 采集
  │
  ├─→ PerformanceObserver 监听长任务
  │
  └─→ sendBeacon 上报
       │
       ▼
监控服务器（/api/vitals）
  │
  ├─→ 存储到数据库
  │
  └─→ 告警（超过阈值时）
       │
       ▼
监控面板（Dashboard）
  ├─→ 实时指标
  ├─→ 趋势图表
  └─→ 告警历史
```

```javascript
// vitals.ts
import { onLCP, onINP, onCLS, onFCP, onTTFB } from 'web-vitals'

function sendMetric(metric) {
  const body = JSON.stringify({
    name: metric.name,
    value: metric.value,
    rating: metric.rating, // 'good' | 'needs-improvement' | 'poor'
    id: metric.id,
    page: window.location.pathname,
    device: navigator.userAgent,
    timestamp: Date.now()
  })

  navigator.sendBeacon('/api/vitals', body)
}

onLCP(sendMetric)
onINP(sendMetric)
onCLS(sendMetric)
```

```javascript
// monitor.js
class PerformanceMonitor {
  private metrics = new Map()
  private chart: Chart

  async init() {
    await this.loadData()
    this.renderCards()
    this.renderChart()
    this.startAutoRefresh()
  }

  async loadData() {
    const res = await fetch('/api/vitals?range=7d')
    const data = await res.json()

    for (const entry of data) {
      if (!this.metrics.has(entry.name)) {
        this.metrics.set(entry.name, [])
      }
      this.metrics.get(entry.name).push(entry)
    }
  }

  renderCards() {
    const container = document.getElementById('metrics')!
    const latest = this.getLatestMetrics()

    container.innerHTML = `
      <div class="metric-card ${this.getRating(latest.lcp, 2500, 4000)}">
        <div class="label">LCP</div>
        <div class="value">${(latest.lcp / 1000).toFixed(2)}s</div>
        <div class="p75">P75: ${(latest.lcpP75 / 1000).toFixed(2)}s</div>
      </div>
      <div class="metric-card ${this.getRating(latest.inp, 200, 500)}">
        <div class="label">INP</div>
        <div class="value">${latest.inp.toFixed(0)}ms</div>
        <div class="p75">P75: ${latest.inpP75.toFixed(0)}ms</div>
      </div>
      <div class="metric-card ${this.getRating(latest.cls, 0.1, 0.25)}">
        <div class="label">CLS</div>
        <div class="value">${latest.cls.toFixed(3)}</div>
        <div class="p75">P75: ${latest.clsP75.toFixed(3)}</div>
      </div>
    `
  }

  renderChart() {
    const ctx = document.getElementById('trend') as HTMLCanvasElement
    const lcpData = this.metrics.get('LCP') || []

    this.chart = new Chart(ctx, {
      type: 'line',
      data: {
        labels: lcpData.map(d => new Date(d.timestamp).toLocaleDateString()),
        datasets: [{
          label: 'LCP P75',
          data: lcpData.map(d => d.value),
          borderColor: '#4a90d9',
          fill: false
        }]
      },
      options: {
        scales: {
          y: {
            beginAtZero: true,
            title: { display: true, text: 'ms' }
          }
        }
      }
    })
  }

  getRating(value, good, poor) {
    if (value <= good) return 'good'
    if (value <= poor) return 'needs-improvement'
    return 'poor'
  }

  startAutoRefresh() {
    setInterval(() => this.loadData().then(() => this.renderCards()), 60000)
  }
}

new PerformanceMonitor().init()
```

## 告警机制

```javascript
// 服务端
function checkAlerts(metrics) {
  const alerts = []

  if (metrics.lcpP75 > 4000) {
    alerts.push({ type: 'critical', metric: 'LCP', value: metrics.lcpP75 })
  }
  if (metrics.inpP75 > 500) {
    alerts.push({ type: 'warning', metric: 'INP', value: metrics.inpP75 })
  }

  if (alerts.length > 0) {
    sendSlackNotification(alerts)
    sendEmailAlert(alerts)
  }
}
```

## 你可能踩的坑

**坑一：数据量太大**

每秒上报大量数据会压垮服务器。采样率 10-50% 足够。

**坑二：P75 计算不准确**

需要足够的样本量。至少 100 个数据点才能计算可靠的 P75。

**坑三：告警疲劳**

太多告警会导致开发者忽略。只在真正回归时告警。

## 练习

### 练习一：告警规则

实现一个告警规则引擎：支持配置不同指标的阈值、通知方式（邮件/Slack/钉钉）和通知频率。

### 练习二：A/B 性能对比

实现一个功能：对比两个版本的性能数据，自动检测是否有统计显著的回归。

### 练习一

```javascript
const alertRules = [
  { metric: 'LCP', threshold: 4000, level: 'critical', channel: 'slack' },
  { metric: 'INP', threshold: 500, level: 'warning', channel: 'email' },
  { metric: 'CLS', threshold: 0.25, level: 'warning', channel: 'slack' }
]

function evaluateAlerts(metrics) {
  const triggered = []
  for (const rule of alertRules) {
    const value = metrics[rule.metric.toLowerCase() + 'P75']
    if (value > rule.threshold) {
      triggered.push({ ...rule, value })
    }
  }
  return triggered
}
```

### 练习二

```javascript
function compareVersions(baseline, current) {
  const results = {}
  for (const metric of ['lcp', 'inp', 'cls']) {
    const baseP75 = percentile(baseline[metric], 75)
    const currP75 = percentile(current[metric], 75)
    const change = (currP75 - baseP75) / baseP75
    const significant = Math.abs(change) > 0.1 // 10% 阈值

    results[metric] = {
      baseline: baseP75,
      current: currP75,
      change: `${(change * 100).toFixed(1)}%`,
      significant,
      direction: change > 0 ? 'regression' : 'improvement'
    }
  }
  return results
}
```
