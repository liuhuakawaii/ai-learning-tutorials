# 阶段实战：首屏加载优化——把 LCP 从 4 秒降到 2 秒

## 现象

你的页面 LCP 4.2 秒。Lighthouse 报告指出三个问题：大图片未压缩、阻塞渲染的 JS、没有 preload。本课针对这些问题进行优化。

## 排查过程

### 第一步：定位 LCP 元素

```javascript
// 用 PerformanceObserver 获取 LCP
const observer = new PerformanceObserver((list) => {
  const entries = list.getEntries()
  const lastEntry = entries[entries.length - 1]
  console.log('LCP 元素:', lastEntry.element)
  console.log('LCP 时间:', lastEntry.startTime)
  console.log('LCP 类型:', lastEntry.entryType) // image / text
})
observer.observe({ type: 'largest-contentful-paint', buffered: true })
```

### 第二步：分析 LCP 资源

```
LCP 元素：<img class="hero" src="hero.png">
  大小：3.2MB（PNG 未压缩）
  加载时间：2.1 秒
  没有 preload
  没有 fetchpriority
```

### 第三步：优化

```html
<!-- 优化 1：图片格式转换和压缩 -->
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" width="1200" height="600"
       fetchpriority="high" alt="Hero">
</picture>

<!-- 优化 2：preload -->
<link rel="preload" href="/images/hero.avif" as="image" type="image/avif">

<!-- 优化 3：关键 CSS 内联 -->
<style>
  .hero { aspect-ratio: 2/1; background: #f0f0f0; }
</style>

<!-- 优化 4：非关键 JS defer -->
<script defer src="app.js"></script>
<script defer src="analytics.js"></script>
```

## 优化前后对比

```

资源变化：
```

## 关键优化技术

### 1. 图片优化

```javascript
// 响应式图片
<img
  srcset="hero-400.webp 400w, hero-800.webp 800w, hero-1200.webp 1200w"
  sizes="(max-width: 600px) 100vw, 50vw"
  src="hero-800.webp"
  width="1200" height="600"
  loading="eager"  // LCP 图片不要 lazy load
  fetchpriority="high"
>
```

### 2. 关键 CSS

```javascript
// 用 critters 提取关键 CSS
// vite.config.ts
import critters from 'critters'

export default {
  plugins: [
    critters({
      preload: 'swap',
      pruneSource: true
    })
  ]
}
```

### 3. 脚本优化

```html
<!-- 关键脚本：defer -->
<script defer src="app.js"></script>

<!-- 非关键脚本：延迟加载 -->
<script>
  // 等待空闲时加载 analytics
  if ('requestIdleCallback' in window) {
    requestIdleCallback(() => {
      const s = document.createElement('script')
      s.src = '/analytics.js'
      document.body.appendChild(s)
    })
  }
</script>
```

## 你可能踩的坑

**坑一：LCP 图片用了 lazy load**

LCP 图片必须尽快加载。`loading="lazy"` 会延迟 LCP。

**坑二：关键 CSS 提取不完整**

内联的 CSS 如果漏了首屏样式，会导致 FOUC。用工具自动提取。

**坑三：defer 脚本有依赖**

多个 defer 脚本按顺序执行，但如果它们有依赖关系，顺序可能不对。
