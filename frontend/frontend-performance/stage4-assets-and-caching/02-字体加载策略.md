# 第2课：字体加载策略

> **课程定位**：优化字体加载，避免 FOIT/FOUT 影响用户体验
> **前置知识**：了解 CSS @font-face 和字体格式
> **预计时长**：30 分钟

## 场景引入

设计师坚持使用一款品牌字体，文件大小 3MB，包含 2 万多个汉字。上线后用户反馈"打开页面好几秒都是白的"——这是典型的 FOIT（Flash of Invisible Text）问题。你尝试把 font-display 改成 swap，结果文字跳来跳去，CLS 直接飙到 0.4。更麻烦的是，用户用的是 4G 网络，字体下载完之前整个首屏都不可交互。如何在保证品牌字体的同时，让用户尽快看到内容？

2. 掌握 font-display 各值的行为
3. 学会预加载和子集化字体
4. 建立字体加载的最佳实践

## 二、font-display

```css
@font-face {
  font-family: 'MyFont';
  src: url('/fonts/myfont.woff2') format('woff2');
  font-display: auto; /* 默认值 */
}
```

```
┌──────────────┬──────────────────────────────────────────────┐
│ 值            │ 行为                                          │
├──────────────┼──────────────────────────────────────────────┤
│ auto         │ 浏览器决定（通常是 block 或 swap）             │
│ block        │ 短暂隐藏（3s），然后用后备字体                 │
│ swap         │ 立即用后备字体，Web 字体加载后替换             │
│ fallback     │ 短暂隐藏（100ms），然后用后备字体              │
│ optional     │ 只在加载够快时使用（100ms 内）                 │
└──────────────┴──────────────────────────────────────────────┘

推荐：
- 关键字体：swap（立即可用，加载后替换）
- 非关键字体：optional（不造成布局偏移）
- 品牌字体：fallback（平衡隐藏时间和替换机会）
```

## 三、字体预加载

### 3.1 link preload

```html
<!-- 提前加载关键字体 -->
<link rel="preload" href="/fonts/main.woff2" as="font"
      type="font/woff2" crossorigin>

<!-- 只预加载实际使用的字体文件 -->
<!-- 不要预加载所有字体变体 -->
```

## 四、字体子集化

### 4.1 什么是子集化

```
┌──────────────────────────────────────────────────────────────┐
│              字体子集化                                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  完整字体（如思源黑体）：                                     │
│  - 包含 20000+ 汉字 + 符号                                    │
│  - 文件大小：5-15 MB                                          │
│                                                              │
│  子集化后（只包含页面用到的字）：                              │
│  - 包含 100-500 个汉字                                        │
│  - 文件大小：20-100 KB                                        │
│                                                              │
│  对于英文：只加载需要的字重（400, 700）                       │
│  不要加载所有字重（100-900）                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 子集化工具

```bash
# glyphhanger（自动分析页面用到的字符）
npx glyphhanger --subset=*.woff2 --CSS --formats=woff2

# fonttools（Python 工具）
pyftsubset font.woff2 --text-file=used-chars.txt --output-file=subset.woff2

# subfont（自动化子集化）
npx subfont --root ./dist --in-place
```

### 4.3 unicode-range 按需加载

```css
/* 只在页面包含中文字符时加载中文字体 */
@font-face {
  font-family: 'MyFont';
  src: url('/fonts/myfont-latin.woff2') format('woff2');
  unicode-range: U+0000-00FF; /* 基本拉丁字符 */
  font-display: swap;
}

@font-face {
  font-family: 'MyFont';
  src: url('/fonts/myfont-chinese.woff2') format('woff2');
  unicode-range: U+4E00-9FFF; /* CJK 统一汉字 */
  font-display: swap;
}

/* 浏览器只下载页面实际用到的字符范围对应的字体文件 */
```

## 五、后备字体尺寸匹配

### 5.1 问题

```
┌──────────────────────────────────────────────────────────────┐
│              字体替换导致布局偏移                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  后备字体（Arial）和 Web 字体（CustomFont）尺寸不同：          │
│                                                              │
│  Arial:       "Hello World" ← 宽度 120px                     │
│  CustomFont:  "Hello World" ← 宽度 135px                     │
│                                                              │
│  字体切换时 → 文字宽度变化 → 布局偏移（CLS）                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 解决方案

```css
/* 用 size-adjust 匹配后备字体尺寸 */
@font-face {
  font-family: 'CustomFont-Fallback';
  src: local('Arial');
  size-adjust: 104%;          /* 整体缩放 */
  ascent-override: 90%;       /* 上升线 */
  descent-override: 22%;      /* 下降线 */
  line-gap-override: 0%;      /* 行间距 */
}

body {
  font-family: 'CustomFont', 'CustomFont-Fallback', sans-serif;
}
```

### 5.3 自动化工具

```bash
# fontaine（自动计算后备字体调整值）
npm install fontaine

// nuxt.config.ts
import { defineNuxtConfig } from 'nuxt/config'
import { FontaineTransform } from 'fontaine'

export default defineNuxtConfig({
  vite: {
    plugins: [
      FontaineTransform.vite({
        fallbacks: ['Arial'],
        resolvePath: (id) => new URL(id, import.meta.url),
      }),
    ],
  },
})
```

## 六、字体加载 API

```javascript
// 使用 Font Loading API 监控字体加载
document.fonts.ready.then(() => {
  console.log('所有字体加载完成');
});

// 监控单个字体
const font = new FontFace('MyFont', 'url(/fonts/myfont.woff2)');
font.load().then(() => {
  document.fonts.add(font);
  console.log('MyFont 加载完成');
});

// 检查字体是否已加载
if (document.fonts.check('16px MyFont')) {
  console.log('MyFont 已可用');
}
```

## 参考答案

### 练习一：font-display 对比

**思路**：使用同一个字体文件，分别设置 font-display: block、swap、optional，在慢速网络下观察加载行为。

**答案**：

```css
/* 测试 1: font-display: block */
@font-face {
  font-family: 'TestFont';
  src: url('/fonts/test.woff2') format('woff2');
  font-display: block;
}
/* 行为：字体加载完成前，文字完全不可见（FOIT）
   等待时间：约 3 秒（浏览器阻塞期）
   适合：品牌 Logo 字体，必须显示自定义字体 */

/* 测试 2: font-display: swap */
@font-face {
  font-family: 'TestFont';
  src: url('/fonts/test.woff2') format('woff2');
  font-display: swap;
}
/* 行为：立即显示后备字体，Web 字体加载完成后切换（FOUT）
   切换时可能有布局偏移
   适合：正文字体，优先保证文字可见 */

/* 测试 3: font-display: optional */
@font-face {
  font-family: 'TestFont';
  src: url('/fonts/test.woff2') format('woff2');
  font-display: optional;
}
/* 行为：100ms 内没加载完就放弃，使用后备字体
   没有 FOUT，但可能永远不显示 Web 字体
   适合：非关键正文字体，消除 CLS */
```

```markdown
慢速网络（Slow 3G）观察结果：

block: 文字不可见 3 秒 → 突然显示自定义字体
swap: 立即显示 Arial → 5 秒后切换为自定义字体（有跳动）
optional: 立即显示 Arial → 始终是 Arial（字体加载被放弃）

选择建议：
- 品牌字体（Logo）: block（必须显示）
- 正文字体: swap + size-adjust（优先可见性）
- 辅助字体: optional（消除 CLS）
```

**要点**：
- block 会导致 FOIT（文字不可见），影响用户体验
- swap 会导致 FOUT（字体切换），配合 size-adjust 可消除 CLS
- optional 在慢网络下可能永远不显示 Web 字体

### 练习二：字体子集化

**思路**：取一个包含中文的完整字体文件，用工具子集化，对比子集化前后的文件大小。

**答案**：

```bash
# 使用 glyphhanger 子集化
npm install -g glyphhanger

# 只保留页面上出现的字符
glyphhanger --subset=fonts/NotoSansSC-Regular.ttf \
  --whitelist="ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789你好世界测试中文" \
  --formats=woff2

# 或使用 fonttools（Python）
pip install fonttools brotli

# 生成子集
pyftsubset fonts/NotoSansSC-Regular.ttf \
  --text-file=characters.txt \
  --output-file=fonts/NotoSansSC-Subset.woff2 \
  --flavor=woff2
```

```markdown
子集化结果：

原始字体: NotoSansSC-Regular.ttf
- 完整文件: 8.5MB
- 包含字符: 60,000+ 个汉字

子集化后（200 个常用汉字）:
- 子集文件: 45KB (WOFF2)
- 包含字符: 200 个

体积减少: 99.5%

中文字体子集化策略：
1. 按页面内容动态生成子集（最精确）
2. 按常用字表生成通用子集（平衡）
3. 按 unicode-range 分组加载（最佳实践）
```

**要点**：
- 中文字体必须子集化，否则文件大小不可接受
- WOFF2 格式压缩率最好，应该优先使用
- unicode-range 可以让浏览器按需加载字符范围

### 练习三：后备字体匹配

**思路**：选择一个 Web 字体和它的后备字体，用 size-adjust 调整后备字体尺寸，验证字体切换时没有布局偏移。

**答案**：

```css
/* 定义后备字体（尺寸调整后） */
@font-face {
  font-family: 'CustomFont-Fallback';
  src: local('Arial');
  size-adjust: 104%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}

/* 定义 Web 字体 */
@font-face {
  font-family: 'CustomFont';
  src: url('/fonts/custom.woff2') format('woff2');
  font-display: swap;
}

/* 使用字体栈 */
body {
  font-family: 'CustomFont', 'CustomFont-Fallback', sans-serif;
}
```

```markdown
验证方法：

1. 正常加载页面：
   - 后备字体立即显示
   - Web 字体加载后切换
   - 观察切换时是否有文字跳动

2. 模拟 Web 字体加载失败：
   - DevTools → Network → 右键字体请求 → Block request URL
   - 刷新页面
   - 后备字体应该和 Web 字体尺寸接近，布局不变

3. 用 Performance 面板录制：
   - 查看 Experience 轨道是否有布局偏移标记
   - 修复前 CLS: 0.08（字体切换引起）
   - 修复后 CLS: 0.00

自动计算工具：
- fontaine (Nuxt/Vite 插件)
- 自动分析 Web 字体和后备字体的差异
- 生成 @font-face 的 size-adjust 等属性
```

**要点**：
- size-adjust 整体缩放后备字体，使其宽度接近 Web 字体
- ascent-override 和 descent-override 调整字体的垂直度量
- fontaine 工具可以自动计算这些值

## 常见误区

1. **font-display: optional 会让字体永远不显示**：optional 的行为是"如果 100ms 内没加载完就放弃"，在慢网络下确实可能永远用后备字体。但这对非品牌字体（如正文字体）其实是合理的——用户体验优先于字体美观。
2. **中文字体不做子集化直接上线**：一个完整的思源黑体 5-15MB，即使压缩后也有 1-2MB。用户可能只需要页面上出现的 200 个汉字，却被迫下载整个字体库。子集化后通常只有 20-100KB。
3. **preload 所有字体文件**：preload 只应用于首屏关键字体。preload 过多字体会抢带宽，反而拖慢其他关键资源的加载。通常首屏只需要 1-2 个字体文件。
4. **忽略后备字体尺寸匹配**：用 swap 后，后备字体和 Web 字体宽度不同会导致文字行数变化，引发布局偏移。应该用 `size-adjust` 等属性让后备字体尺寸接近 Web 字体。

## 工程建议

1. **用 fontaine 自动计算后备字体调整值**：fontaine 工具能自动分析 Web 字体和后备字体的尺寸差异，生成 @font-face 的 size-adjust、ascent-override 等属性，消除手动调试的麻烦。
2. **用 unicode-range 按需加载字符范围**：把中文字体按 unicode-range 拆分成拉丁、常用汉字、生僻字等多个子集，浏览器只下载页面实际用到的字符范围对应的文件。
3. **用 Font Loading API 监控字体加载**：通过 `document.fonts.ready` 和 `new FontFace()` 监控字体加载状态，结合 Performance 面板分析字体对 LCP 和 CLS 的影响。
4. **建立字体使用规范**：限制团队使用的字体数量（建议不超过 3 个文件）和字重（只加载 400、700），在 PR Review 中检查字体文件大小。

## 小结

1. **FOIT vs FOUT**：FOIT 不可见，FOUT 字体跳动
2. **font-display: swap**：推荐，立即用后备字体
3. **预加载关键字体**：`<link rel="preload">`
4. **子集化**：中文字体必须子集化，减少 90%+ 体积
5. **unicode-range**：按需加载字符范围
6. **size-adjust**：匹配后备字体尺寸，消除 CLS
