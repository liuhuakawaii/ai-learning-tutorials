# 阶段实战：资源体积减半——找出资源大户

## 现象

你的页面总资源 4.8MB，42 个请求。目标是减半到 2.4MB 以内。

## 排查过程

### 第一步：Network 面板分析

```
资源类型    大小      占比
JS         1.2MB     25%
图片       3.1MB     65%
CSS        180KB     4%
字体       200KB     4%
其他       120KB     2%
```

图片是最大的资源大户。

### 第二步：图片优化

```javascript
// 批量转 WebP
const images = ['hero.png', 'product1.jpg', 'product2.jpg', 'banner.png']
for (const img of images) {
  await sharp(img)
    .resize(1200, null, { fit: 'inside', withoutEnlargement: true })
    .webp({ quality: 80 })
    .toFile(img.replace(/\.\w+$/, '.webp'))
}

// 结果：3.1MB → 480KB（-85%）
```

### 第三步：JS 优化

```javascript
// 分析 bundle
// vite build --mode analyze
// 或用 rollup-plugin-visualizer

// 发现 moment.js 占 70KB，替换为 dayjs
import dayjs from 'dayjs' // 2KB

// 发现 lodash 全量引入，改为按需引入
import debounce from 'lodash/debounce' // 1KB

// 结果：1.2MB → 320KB（-73%）
```

### 第四步：CSS 优化

```javascript
// PurgeCSS 移除未使用的 CSS
import purgecss from '@fullhuman/postcss-purgecss'

// 结果：180KB → 45KB（-75%）
```

### 第五步：字体优化

```javascript
// 字体子集化
import { subsetSync } from '@aspect-build/aspect-fonttools'

// 只保留常用字符
subsetSync('font.woff2', 'subset.woff2', {
  text: '你好世界欢迎使用我们的产品'
})

// 结果：200KB → 20KB（-90%）
```

## 优化前后对比

```
资源类型    优化前      优化后      改善
JS         1.2MB       320KB       -73%
图片       3.1MB       480KB       -85%
CSS        180KB       45KB        -75%
字体       200KB       20KB        -90%
其他       120KB       80KB        -33%
─────────────────────────────────────
总计       4.8MB       945KB       -80%
```

## 关键技术

### 1. 代码分割

```typescript
// 路由级别的代码分割
const Dashboard = lazy(() => import('./pages/Dashboard'))
const Settings = lazy(() => import('./pages/Settings'))
```

### 2. Tree Shaking

```typescript
// 不好：引入整个库
import _ from 'lodash'
_.debounce(fn, 300)

// 好：只引入需要的函数
import debounce from 'lodash/debounce'
debounce(fn, 300)
```

### 3. HTTP 缓存

```
# 静态资源：长期缓存
Cache-Control: public, max-age=31536000, immutable

# HTML：不缓存
Cache-Control: no-cache

# API：短时间缓存
Cache-Control: public, max-age=60
```

## 你可能踩的坑

**坑一：图片压缩过度**

质量太低会影响用户体验。80% 质量通常是平衡点。

**坑二：Tree Shaking 失败**

CommonJS 模块不支持 Tree Shaking。确保使用 ES Module。

**坑三：字体子集化遗漏字符**

如果用户输入了子集中没有的字符，会显示为方块。

## 练习

### 练习一：Bundle 分析

用 rollup-plugin-visualizer 分析你的项目 bundle，找出最大的依赖。

### 练习二：资源预算

设置资源预算：JS < 300KB，图片 < 500KB，CSS < 50KB。在 CI 中检查是否超标。

## 参考答案

```javascript
// vite.config.ts
import { visualizer } from 'rollup-plugin-visualizer'

export default {
  plugins: [
    visualizer({
      open: true,
      filename: 'bundle-analysis.html'
    })
  ]
}
```

### 练习二

```javascript
// scripts/check-budget.js
const budgets = {
  js: 300 * 1024,
  css: 50 * 1024,
  images: 500 * 1024
}

function checkBudget(distDir) {
  const stats = analyzeDist(distDir)
  for (const [type, limit] of Object.entries(budgets)) {
    if (stats[type] > limit) {
      console.error(`❌ ${type}: ${formatKB(stats[type])} > ${formatKB(limit)}`)
      process.exit(1)
    }
  }
}
```
