# 第3课：代码分割

> **课程定位**：把大的 JS 包拆分成按需加载的小块，减少初始加载体积
> **前置知识**：了解 JavaScript 模块和打包工具
> **预计时长**：30 分钟

## 场景引入

你的 SPA 项目上线半年，功能越加越多：仪表盘、设置页、图表分析、PDF 导出、Excel 导出……打包后 `main.js` 已经膨胀到 800KB gzipped。用户反馈"打开首页要等 5 秒"，但其实首页只需要其中 50KB 的代码。更糟的是，用户打开首页后根本不会去设置页和分析页——那 700KB 白白下载了。你需要把大包拆成按需加载的小块，让用户只下载当前页面需要的代码。

## 二、路由级代码分割

### 2.1 React.lazy

```jsx
import { lazy, Suspense } from 'react';

// 路由级代码分割
const Dashboard = lazy(() => import('./pages/Dashboard'));
const Settings = lazy(() => import('./pages/Settings'));
const Analytics = lazy(() => import('./pages/Analytics'));

function App() {
  return (
    <Suspense fallback={<LoadingSpinner />}>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/dashboard" element={<Dashboard />} />
        <Route path="/settings" element={<Settings />} />
        <Route path="/analytics" element={<Analytics />} />
      </Routes>
    </Suspense>
  );
}
```

### 2.2 Next.js 自动分割

```
App Router 自动按路由分割：

app/
├── page.tsx           → 首页 chunk
├── dashboard/
│   └── page.tsx       → 仪表盘 chunk
├── settings/
│   └── page.tsx       → 设置 chunk
└── analytics/
    └── page.tsx       → 分析 chunk

每个页面自动成为独立的 chunk，无需手动配置
```

## 三、组件级代码分割

```jsx
import { lazy, Suspense } from 'react';

// 重量级组件按需加载
const HeavyChart = lazy(() => import('./HeavyChart'));
const RichTextEditor = lazy(() => import('./RichTextEditor'));
const PDFViewer = lazy(() => import('./PDFViewer'));

function Dashboard() {
  const [showChart, setShowChart] = useState(false);

  return (
    <div>
      <h1>Dashboard</h1>

      {/* 图表只在用户点击时加载 */}
      <button onClick={() => setShowChart(true)}>Show Chart</button>
      {showChart && (
        <Suspense fallback={<ChartSkeleton />}>
          <HeavyChart />
        </Suspense>
      )}
    </div>
  );
}
```

## 四、动态导入

### 4.1 基本动态导入

```javascript
// 条件加载
async function loadData(useV2) {
  if (useV2) {
    const { fetchV2 } = await import('./api-v2');
    return fetchV2();
  } else {
    const { fetchV1 } = await import('./api-v1');
    return fetchV1();
  }
}

// 按需加载工具库
async function exportToPDF(data) {
  const { jsPDF } = await import('jspdf');
  const doc = new jsPDF();
  // ...
  doc.save('export.pdf');
}
```

### 4.2 命名导出的动态导入

```javascript
// 导入单个导出
const { formatDate } = await import('./utils');

// 导入默认导出
const Chart = (await import('./Chart')).default;

// 导入多个
const { useState, useEffect } = await import('react');
```

## 五、预加载策略

### 5.1 鼠标悬停预加载

```jsx
function NavLink({ to, children }) {
  const handleMouseEnter = () => {
    // 鼠标悬停时预加载路由
    const route = routes[to];
    if (route?.component) {
      route.component.preload?.();
    }
  };

  return (
    <Link to={to} onMouseEnter={handleMouseEnter}>
      {children}
    </Link>
  );
}
```

### 5.2 可视区域预加载

```jsx
import { useEffect, useRef } from 'react';

function PreloadOnVisible({ children, load }) {
  const ref = useRef();

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          load(); // 组件进入可视区域时预加载
          observer.disconnect();
        }
      },
      { rootMargin: '200px' } // 提前 200px 开始加载
    );

    if (ref.current) observer.observe(ref.current);
    return () => observer.disconnect();
  }, [load]);

  return <div ref={ref}>{children}</div>;
}

// 使用
<PreloadOnVisible load={() => import('./HeavyChart')}>
  <ChartPlaceholder />
</PreloadOnVisible>
```

### 5.3 空闲时预加载

```javascript
// requestIdleCallback 预加载
function preloadWhenIdle(modulePath) {
  if ('requestIdleCallback' in window) {
    requestIdleCallback(() => {
      import(modulePath);
    });
  } else {
    setTimeout(() => import(modulePath), 1);
  }
}

// 应用启动后预加载可能需要的模块
preloadWhenIdle('./pages/Dashboard');
preloadWhenIdle('./components/HeavyChart');
```

## 七、优化打包体积的技巧

### 7.1 替换大型库

```
┌───────────────────────┬────────────────────┬─────────────────┐
│ 大型库                 │ 轻量替代            │ 体积减少         │
├───────────────────────┼────────────────────┼─────────────────┤
│ moment.js (300KB)     │ date-fns (5KB 按需) │ 98%             │
│ lodash (70KB)         │ lodash-es (按需)    │ 按需加载         │
│ axios (15KB)          │ fetch (0KB)         │ 100%            │
│ chart.js (200KB)      │ 按需导入            │ 60-80%          │
│ antd (500KB+)         │ 按需导入            │ 80%+            │
└───────────────────────┴────────────────────┴─────────────────┘
```

### 7.2 Tree Shaking

```javascript
// ❌ 导入整个库 → 无法 tree shake
import _ from 'lodash';
_.get(obj, 'a.b');

// ✅ 只导入需要的函数
import get from 'lodash-es/get';
get(obj, 'a.b');

// ✅ 或使用原生可选链
obj?.a?.b;
```

### 7.3 动态导入大型依赖

```javascript
// 只在需要时加载大型库
async function generateChart(data) {
  const { Chart } = await import('chart.js');
  // ...
}

async function exportPDF(data) {
  const { jsPDF } = await import('jspdf');
  // ...
}
```

## 参考答案

### 练习一：路由级分割

**思路**：创建一个多页面应用，用 React.lazy 实现路由级代码分割，用 Network 面板验证只加载当前路由的 JS。

**答案**：

```jsx
import { lazy, Suspense } from 'react';
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

// 路由级代码分割
const Home = lazy(() => import('./pages/Home'));
const Dashboard = lazy(() => import('./pages/Dashboard'));
const Settings = lazy(() => import('./pages/Settings'));

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/dashboard">Dashboard</Link>
        <Link to="/settings">Settings</Link>
      </nav>
      <Suspense fallback={<div>Loading...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/dashboard" element={<Dashboard />} />
          <Route path="/settings" element={<Settings />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}
```

```markdown
Network 面板验证：

初始加载（访问 /）：
- 只加载 Home.chunk.js (15KB)
- Dashboard.chunk.js 和 Settings.chunk.js 未加载

导航到 /dashboard：
- 加载 Dashboard.chunk.js (25KB)
- Home.chunk.js 已缓存

导航到 /settings：
- 加载 Settings.chunk.js (12KB)
- 其他 chunk 已缓存

对比不分割：
- 不分割: 1 个 bundle.js (120KB)
- 分割后: 首屏只加载 15KB + 公共依赖 30KB = 45KB
- 首屏体积减少 62%
```

**要点**：
- React.lazy + Suspense 是路由级代码分割的标准方案
- 每个路由一个 chunk，首屏只加载当前路由的代码
- Suspense 的 fallback 是必须的，否则加载时会白屏

### 练习二：组件级分割

**思路**：找到项目中最重的组件，用 lazy + Suspense 实现按需加载，添加鼠标悬停预加载。

**答案**：

```jsx
import { lazy, Suspense, useCallback } from 'react';

// 重量级组件：图表库
const HeavyChart = lazy(() => import('./components/HeavyChart'));

function Dashboard() {
  // 鼠标悬停时预加载
  const handleMouseEnter = useCallback(() => {
    import('./components/HeavyChart');
  }, []);

  return (
    <div>
      <h1>Dashboard</h1>
      <div onMouseEnter={handleMouseEnter}>
        <Suspense fallback={<ChartSkeleton />}>
          <HeavyChart data={chartData} />
        </Suspense>
      </div>
    </div>
  );
}

// 骨架屏
function ChartSkeleton() {
  return (
    <div style={{ height: 300, background: '#f0f0f0', borderRadius: 8 }}>
      <div style={{ padding: 16, color: '#999' }}>Loading chart...</div>
    </div>
  );
}
```

```markdown
优化效果：

优化前：
- 首屏加载: 320KB（包含 chart.js + 组件代码）
- 首屏 LCP: 3.5s

优化后：
- 首屏加载: 45KB（不含 chart.js）
- 首屏 LCP: 1.8s
- 用户 hover 到图表区域时: 预加载 chart.js
- 用户看到图表时: 已加载完成，无感知延迟

悬停预加载的效果：
- 不预加载: 点击后等待 800ms 加载图表
- 预加载: 点击后立即显示图表（已加载完成）
```

**要点**：
- 只有重量级组件（图表库、编辑器、PDF 查看器）才值得按需加载
- 鼠标悬停预加载可以让用户无感知延迟
- 必须配合 Suspense 和骨架屏使用

**思路**：用 bundle analyzer 分析项目打包体积，找到最大的 3 个依赖，尝试替换或按需导入。

**答案**：

分析结果：

Bundle 总大小: 520KB (gzipped)

最大的 3 个依赖：
1. moment.js + locales: 85KB (16%)

- bundle analyzer 的可视化报告中，色块越大说明体积越大
- moment.js 和 lodash 是最常见的"体积大户"
- 按需导入（tree shaking）和动态导入（lazy loading）是两大优化手段

## 常见误区

1. **把所有组件都用 lazy 包裹**：过度分割会导致大量小 chunk 请求，HTTP 请求本身有开销（TCP 连接、TLS 握手）。只有重量级组件（图表库、编辑器、PDF 查看器）才值得按需加载。
2. **动态导入后忘记处理加载状态**：`React.lazy` 必须配合 `<Suspense>` 使用，否则会抛出未捕获的 Promise 导致白屏。加载中和加载失败都需要有 UI 反馈。
3. **只做路由级分割，忽略共享依赖**：如果两个路由页面都依赖同一个大型库（如 chart.js），不做提取的话这个库会被打包两次。需要配置 splitChunks 提取公共依赖。
4. **以为 Tree Shaking 能解决所有体积问题**：Tree Shaking 只对 ES Module 有效。如果你用的是 CommonJS 的 lodash（`import _ from 'lodash'`），Tree Shaking 完全无效。必须用 `lodash-es` 或按函数导入。

## 工程建议

1. **用 bundle analyzer 定期审查打包体积**：每次大版本发布前运行 `rollup-plugin-visualizer` 或 `@next/bundle-analyzer`，找到体积异常增长的依赖，及时替换或按需导入。
2. **鼠标悬停预加载路由**：用户 hover 到导航链接时，用 `route.component.preload?.()` 预加载目标页面的 chunk，这样用户点击时页面已经加载好了，体感是"秒开"。
3. **用 size-limit 在 CI 中检查入口体积**：配置 `size-limit` 限制首屏 JS 体积（建议 ≤ 200KB gzipped），超标时 CI 失败，防止体积悄悄膨胀。
4. **优先替换大型依赖而非分割它们**：moment.js（300KB）换成 date-fns（按需 5KB），axios（15KB）换成原生 fetch（0KB）——替换比重塑分割更彻底。

## 小结

1. **代码分割**：把大包拆成按需加载的小块
2. **路由级分割**：每个路由一个 chunk，首屏只加载首页
3. **组件级分割**：重量级组件 lazy 加载
4. **预加载**：鼠标悬停、可视区域、空闲时
5. **体积优化**：替换大型库、Tree Shaking、动态导入
