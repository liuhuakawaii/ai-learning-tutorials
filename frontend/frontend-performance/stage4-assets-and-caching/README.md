# 第四阶段：资源、缓存与网络

## 阶段目标

优化图片、字体、脚本、缓存和第三方资源，降低传输体积和加载阻塞，并建立资源预算意识。

## 课时安排

1. 图片格式和响应式图片
2. 字体加载策略
3. 代码分割
4. HTTP 缓存和 CDN
5. API 缓存
6. 第三方脚本治理
7. 阶段实战：资源体积减半

## 阶段项目

继续使用 `performance-rescue-demo`。对比 `slow.html`、`work.html` 和 `optimized.html` 的资源组成，重点分析：

- 图片是否过大，是否需要响应式尺寸或更低质量
- 字体是否阻塞首屏，是否可以改用系统字体或 `font-display`
- 第三方脚本是否需要首屏同步执行
- 首屏资源是否超过预算
- 哪些资源应该缓存、延迟或按需加载

输出 `reports/stage4-assets-budget.md`。

## 验收标准

- 图片体积减少至少 50% 或给出无法减少的理由
- 初始 JS 阻塞显著下降
- 字体不阻塞主要内容
- 第三方脚本有加载策略
- 有明确资源预算和超标处理方式
