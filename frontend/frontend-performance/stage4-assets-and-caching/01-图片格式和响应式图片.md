# 图片格式和响应式图片：选错格式浪费 80% 带宽

## 现象

你的页面有 10 张产品图，每张 500KB JPEG，总共 5MB。用 WebP 压缩后每张 80KB，总共 800KB——带宽减少 84%。

## 图片格式对比

```
格式      透明    动画    压缩率    浏览器支持    适用场景
JPEG      ✗       ✗       中        全部          照片
PNG       ✓       ✗       低        全部          需要透明的照片
GIF       ✓       ✓       低        全部          简单动画
WebP      ✓       ✓       高        全部          通用
AVIF      ✓       ✓       极高      现代浏览器    高质量照片
SVG       ✓       ✓       N/A       全部          图标、插图
```

## WebP vs JPEG

```
同一张照片（1920×1080）：
  JPEG 80% 质量：245KB
  WebP 80% 质量：98KB（-60%）
  AVIF 80% 质量：62KB（-75%）
```

## 响应式图片

不同设备需要不同尺寸的图片：

```html
<!-- srcset：根据屏幕宽度选择图片 -->
<img
  srcset="photo-400.webp 400w, photo-800.webp 800w, photo-1200.webp 1200w"
  sizes="(max-width: 600px) 100vw, (max-width: 1200px) 50vw, 33vw"
  src="photo-800.webp"
  width="1200" height="800"
  loading="lazy"
  alt="Product photo"
>

<!-- picture：格式回退 -->
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" width="1200" height="800" alt="Photo">
</picture>
```

## 图片压缩

```javascript
// 用 Sharp 压缩图片
import sharp from 'sharp'

async function compressImage(inputPath, outputPath) {
  await sharp(inputPath)
    .resize(1200, 800, { fit: 'inside', withoutEnlargement: true })
    .webp({ quality: 80 })
    .toFile(outputPath)
}

// 批量压缩
async function compressAll(images) {
  for (const img of images) {
    await compressImage(img, img.replace(/\.\w+$/, '.webp'))
  }
}
```

## Lazy Loading

```html
<!-- 原生 lazy load -->
<img src="photo.webp" loading="lazy" width="400" height="300">

<!-- LCP 图片不要 lazy load -->
<img src="hero.webp" loading="eager" fetchpriority="high">
```

## 你可能踩的坑

**坑一：LCP 图片 lazy load**

LCP 图片必须尽快加载，不要 lazy load。

**坑二：没有 width/height**

图片加载前浏览器不知道尺寸，会导致 CLS。必须设置 width/height 或 aspect-ratio。

**坑三：AVIF 不支持回退**

旧浏览器不支持 AVIF。用 `<picture>` 提供 WebP 和 JPEG 回退。

## 参考答案

### 练习一

```javascript
import sharp from 'sharp'
import { readdir } from 'fs/promises'

async function buildResponsiveImages(dir) {
  const files = await readdir(dir)
  const images = files.filter(f => /\.(jpg|jpeg|png)$/i.test(f))

  for (const img of images) {
    for (const size of [400, 800, 1200]) {
      await sharp(`${dir}/${img}`)
        .resize(size, null, { fit: 'inside', withoutEnlargement: true })
        .webp({ quality: 80 })
        .toFile(`${dir}/${img.replace(/\.\w+$/, `-${size}.webp`)}`)
    }
  }
}
```

### 练习二

```css
/* 用 aspect-ratio 替代 width/height */
img {
  aspect-ratio: 16/9;
  width: 100%;
  height: auto;
  object-fit: cover;
}
```
