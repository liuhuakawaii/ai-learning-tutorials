# Market Insight Dashboard 项目说明

## 项目目标

构建一个端到端数据产品：从数据源进入系统，到清洗、入库、查询、可视化、定时更新和监控，形成完整闭环。

## 内置 demo

课程提供一个可运行最小闭环：

```text
data-product-course/final-project/market-insight-demo
```

运行：

```bash
cd data-product-course/final-project/market-insight-demo
npm run check
npm run etl
npm start
```

打开：

- http://localhost:4180/
- http://localhost:4180/api/summary
- http://localhost:4180/api/jobs
- http://localhost:4180/api/quality

这个 demo 用招聘岗位 CSV 演示 raw data、clean data、quality report、metrics、API 和 Dashboard。真实项目可以替换数据源和存储层，但交付物和验收标准保持一致。

## 推荐主题

任选一个：

- 招聘岗位与薪资趋势
- 商品价格监控
- 技术文章热度分析
- 城市天气与空气质量趋势
- 开源项目增长趋势

## 核心模块

1. 数据源
   - CSV 导入
   - 公开 API
   - 合规网页采集

2. ETL
   - 原始数据落库
   - 字段清洗
   - 去重
   - 批次号与日志

3. 数据仓库
   - raw tables
   - clean tables
   - metric tables
   - 索引与查询优化

4. API
   - 列表查询
   - 趋势查询
   - 排名查询
   - 详情查询
   - 导出接口

5. Dashboard
   - 指标总览
   - 趋势图
   - 排名榜
   - 筛选器
   - 明细表

6. 自动化
   - 定时任务
   - 手动刷新
   - 失败重试
   - 数据质量报告

## 阶段交付物

| 阶段 | 交付物 | 对应 demo |
|------|--------|-----------|
| 第一阶段 | 数据源调研、数据字典、采集边界 | `docs/data-source-research.md`、`docs/data-dictionary.md` |
| 第二阶段 | ETL 批次、清洗结果、异常数据和质量规则 | `scripts/run-etl.js`、`reports/stage2-etl-quality.md` |
| 第三阶段 | 查询、筛选、聚合和质量接口 | `server.js`、`reports/stage3-api-report.md` |
| 第四阶段 | Dashboard 信息架构、指标卡、明细表和状态设计 | `public/index.html`、`reports/stage4-dashboard-report.md` |
| 第五阶段 | 调度、增量、告警、部署和运营报告 | `reports/stage5-ops-report.md` |

## 验收标准

- 每次 ETL 都有批次号、开始时间、结束时间和状态
- 原始数据和清洗数据分开存储
- Dashboard 至少包含 4 种图表或数据视图
- API 支持分页、筛选、排序
- 任务失败时能看到错误原因并重新执行
- 至少有 5 条数据质量规则
- 内置 demo 的 `npm run check` 和 `npm run etl` 均通过
