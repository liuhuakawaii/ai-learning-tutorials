## 一、指标卡组件

### 1.1 指标卡设计

```tsx
interface MetricCardProps {
  title: string;
  value: string | number;
  change?: number;  // 变化百分比
  unit?: string;
  icon?: React.ReactNode;
}

function MetricCard({ title, value, change, unit, icon }: MetricCardProps) {
  const isPositive = change && change > 0;
  
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <div className="flex items-center justify-between">
        <span className="text-gray-500 text-sm">{title}</span>
        {icon}
      </div>
      <div className="mt-2">
        <span className="text-3xl font-bold">{value}</span>
        {unit && <span className="text-gray-500 ml-1">{unit}</span>}
      </div>
      {change !== undefined && (
        <div className={`mt-2 text-sm ${isPositive ? 'text-green-500' : 'text-red-500'}`}>
          {isPositive ? '↑' : '↓'} {Math.abs(change)}%
        </div>
      )}
    </div>
  );
}
```

## 二、趋势图

### 2.1 折线图

```tsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer } from 'recharts';

interface TrendChartProps {
  data: Array<{ date: string; value: number }>;
  title: string;
  xLabel?: string;
  yLabel?: string;
}

function TrendChart({ data, title, xLabel, yLabel }: TrendChartProps) {
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">{title}</h3>
      <ResponsiveContainer width="100%" height={300}>
        <LineChart data={data}>
          <CartesianGrid strokeDasharray="3 3" />
          <XAxis dataKey="date" label={xLabel} />
          <YAxis label={yLabel} />
          <Tooltip />
          <Line type="monotone" dataKey="value" stroke="#3b82f6" strokeWidth={2} />
        </LineChart>
      </ResponsiveContainer>
    </div>
  );
}
```

### 2.2 柱状图

```tsx
import { BarChart, Bar, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer } from 'recharts';

function BarChartComponent({ data, title }) {
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">{title}</h3>
      <ResponsiveContainer width="100%" height={300}>
        <BarChart data={data}>
          <CartesianGrid strokeDasharray="3 3" />
          <XAxis dataKey="name" />
          <YAxis />
          <Tooltip />
          <Bar dataKey="value" fill="#3b82f6" />
        </BarChart>
      </ResponsiveContainer>
    </div>
  );
}
```

## 常见误区

- **指标卡不区分主次**：所有指标卡用同样大小、同样颜色，用户无法快速识别哪个是核心指标。应该通过字号、颜色、位置来区分优先级。
- **变化百分比颜色不统一**：有的系统涨了用绿色、跌了用红色，有的反过来。上线前必须和业务方确认颜色语义，避免用户误解。
- **趋势图 X 轴标签过多**：30 天的数据全显示日期，标签挤成一团看不清。应该根据图表宽度动态调整标签密度，或者用缩略轴。
- **图表不处理空数据和异常值**：数据为空时显示空白、有极端值时折线图飞出可视区域，这些都是常见但容易忽略的问题。

---

## 工程建议

1. **指标卡组件支持 loading 和 error 状态**：不要只写正常状态的渲染逻辑，数据加载中和请求失败时也需要有对应的 UI 反馈。
2. **趋势图用 ResponsiveContainer 包裹**：让图表自适应父容器宽度，避免在不同屏幕尺寸下出现溢出或空白。
3. **大数据量趋势图开启采样**：当数据点超过 500 个时，考虑对数据做降采样或用后端聚合，避免前端渲染卡顿。
4. **图表颜色使用设计系统 Token**：不要硬编码 `#3b82f6`，而是引用 Tailwind 的 `text-blue-500` 或自定义的设计 Token，方便后续主题切换。

## 参考答案

### 练习一

**思路**：基于课程中的 MetricCard 组件，传入招聘数据即可。关键是要区分主次——平均薪资用更大字号和强调色，因为它是最核心的业务指标。

**答案**：

```tsx
import { MetricCard } from '@/components/MetricCard';

const metrics = [
  { title: '岗位总数', value: '12,345', change: 5.2, icon: <BriefcaseIcon /> },
  { title: '平均薪资', value: '27,500', unit: '元/月', change: 2.1, icon: <MoneyIcon /> },
  { title: '城市数量', value: '32', change: 3, icon: <CityIcon /> },
  { title: '今日新增', value: '156', change: -2.3, icon: <TrendIcon /> },
];

function DashboardOverview() {
  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
      {metrics.map((metric) => (
        <MetricCard
          key={metric.title}
          title={metric.title}
          value={metric.value}
          change={metric.change}
          unit={metric.unit}
          icon={metric.icon}
        />
      ))}
    </div>
  );
}
```

**要点**：
- change 为正数显示绿色上箭头，负数显示红色下箭头
- 平均薪资需要额外的 unit 属性显示"元/月"
- 响应式布局：移动端1列，平板2列，桌面4列

### 练习二

**思路**：使用 Recharts 的 LineChart 组件，X 轴显示日期、Y 轴显示岗位数量。关键处理：X 轴标签过多时用 interval 控制显示密度，Tooltip 显示具体数值。

**答案**：

```tsx
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer } from 'recharts';

const trendData = [
  { date: '06-01', count: 320 },
  { date: '06-02', count: 345 },
  { date: '06-03', count: 298 },
  { date: '06-04', count: 412 },
  { date: '06-05', count: 389 },
  // ... 更多日期数据
  { date: '06-30', count: 456 },
];

function JobTrendChart() {
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">近30天岗位数量趋势</h3>
      <ResponsiveContainer width="100%" height={300}>
        <LineChart data={trendData}>
          <CartesianGrid strokeDasharray="3 3" />
          <XAxis
            dataKey="date"
            interval={4}
            tick={{ fontSize: 12 }}
          />
          <YAxis />
          <Tooltip
            formatter={(value: number) => [`${value} 个`, '岗位数量']}
            labelFormatter={(label: string) => `日期：${label}`}
          />
          <Line
            type="monotone"
            dataKey="count"
            stroke="#3b82f6"
            strokeWidth={2}
            dot={{ r: 3 }}
            activeDot={{ r: 5 }}
          />
        </LineChart>
      </ResponsiveContainer>
    </div>
  );
}
```

**要点**：
- `interval={4}` 让 X 轴每隔 5 天显示一个标签，避免 30 个日期挤在一起
- `Tooltip` 的 `formatter` 让悬浮提示显示"XX 个"而不是裸数字
- `ResponsiveContainer` 确保图表自适应父容器宽度

### 练习三

**思路**：使用 Recharts 的 BarChart 组件展示 TOP10 城市。数据需要先按岗位数量降序排序取前 10。横向柱状图更适合展示城市名称较长的场景。

**答案**：

```tsx
import { BarChart, Bar, XAxis, YAxis, CartesianGrid, Tooltip, ResponsiveContainer, Cell } from 'recharts';

const cityData = [
  { city: '北京', count: 2345 },
  { city: '上海', count: 2100 },
  { city: '深圳', count: 1890 },
  { city: '杭州', count: 1560 },
  { city: '广州', count: 1420 },
  { city: '成都', count: 1280 },
  { city: '南京', count: 1100 },
  { city: '武汉', count: 980 },
  { city: '西安', count: 870 },
  { city: '苏州', count: 760 },
];

const COLORS = ['#3b82f6', '#2563eb', '#1d4ed8', '#60a5fa', '#93c5fd',
                '#3b82f6', '#2563eb', '#1d4ed8', '#60a5fa', '#93c5fd'];

function CityRankingChart() {
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">TOP10 城市岗位数量</h3>
      <ResponsiveContainer width="100%" height={400}>
        <BarChart data={cityData} layout="vertical" margin={{ left: 60 }}>
          <CartesianGrid strokeDasharray="3 3" />
          <XAxis type="number" />
          <YAxis type="category" dataKey="city" />
          <Tooltip formatter={(value: number) => [`${value} 个`, '岗位数量']} />
          <Bar dataKey="count" radius={[0, 4, 4, 0]}>
            {cityData.map((_, index) => (
              <Cell key={index} fill={COLORS[index]} />
            ))}
          </Bar>
        </BarChart>
      </ResponsiveContainer>
    </div>
  );
}
```

**要点**：
- 用 `layout="vertical"` 实现横向柱状图，城市名称在左侧更易读
- 每个柱子用不同深浅的蓝色区分排名
- `margin={{ left: 60 }}` 给城市名称留足空间
- 数据要预先按 count 降序排序
