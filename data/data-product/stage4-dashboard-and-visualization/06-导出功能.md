## 一、CSV 导出

```typescript
// 前端导出 CSV
function exportToCSV(data: any[], filename: string) {
  const headers = Object.keys(data[0]);
  const csv = [
    headers.join(','),
    ...data.map(row => headers.map(h => row[h]).join(','))
  ].join('\n');
  
  const blob = new Blob(['﻿' + csv], { type: 'text/csv;charset=utf-8;' });
  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = filename;
  link.click();
}
```

## 常见误区

- **CSV 导出不处理中文编码**：直接用 `text/csv` 生成 CSV，打开后中文变成乱码。需要加 BOM 头（`\uFEFF`）并指定 `charset=utf-8`，Excel 才能正确识别。
- **图片导出不考虑跨域问题**：用 html2canvas 截图时，图表如果引用了外部资源（CDN 图片、字体），会因为跨域限制导致截图失败或空白。
- **大数据量导出不做过滤**：一次性把几万行数据全导出来，浏览器直接卡死。应该在导出前应用当前的筛选条件，或者限制导出行数。
- **导出按钮不防重复点击**：用户点了导出没反应（其实在生成中），又点了一次，结果触发了两次导出。应该在导出过程中禁用按钮并显示进度。

---

## 工程建议

1. **CSV 导出始终加 BOM 头**：`new Blob(['\uFEFF' + csvContent], { type: 'text/csv;charset=utf-8;' })`，确保 Excel 打开中文不乱码。
2. **大文件导出用后端流式生成**：超过 1 万行的数据导出，应该由后端生成文件并返回下载链接，避免前端内存溢出。
3. **图片导出前检查跨域配置**：确保图表库的静态资源设置了正确的 CORS 头，或者把资源部署在同域下，避免 html2canvas 截图失败。
4. **导出功能要有权限控制**：不是所有用户都应该能导出数据，敏感数据的导出需要做权限校验，并记录导出日志用于审计。

## 参考答案

### 练习一

**思路**：CSV 导出的核心问题是中文编码。必须加 BOM 头（`\uFEFF`）让 Excel 正确识别 UTF-8 编码。同时要处理字段中包含逗号、换行符等特殊字符的情况，用双引号包裹这些字段。

**答案**：

```typescript
interface ExportColumn {
  key: string;
  title: string;
  formatter?: (value: any, row: Record<string, any>) => string;
}

function exportToCSV(
  data: Record<string, any>[],
  columns: ExportColumn[],
  filename: string
) {
  // 转义字段中的特殊字符
  const escapeField = (value: string): string => {
    if (value.includes(',') || value.includes('"') || value.includes('\n')) {
      return `"${value.replace(/"/g, '""')}"`;
    }
    return value;
  };

  // 生成表头
  const header = columns.map((col) => escapeField(col.title)).join(',');

  // 生成数据行
  const rows = data.map((row) =>
    columns
      .map((col) => {
        const raw = row[col.key];
        const formatted = col.formatter ? col.formatter(raw, row) : String(raw ?? '');
        return escapeField(formatted);
      })
      .join(',')
  );

  // 拼接 CSV 内容，加 BOM 头确保中文不乱码
  const csvContent = [header, ...rows].join('\n');
  const blob = new Blob(['\uFEFF' + csvContent], {
    type: 'text/csv;charset=utf-8;',
  });

  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = filename.endsWith('.csv') ? filename : `${filename}.csv`;
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
  URL.revokeObjectURL(link.href);
}

// 使用示例
const columns: ExportColumn[] = [
  { key: 'city', title: '城市' },
  { key: 'count', title: '岗位数量' },
  { key: 'salary', title: '平均薪资', formatter: (v) => `¥${v.toLocaleString()}` },
  { key: 'change', title: '环比变化', formatter: (v) => `${v > 0 ? '+' : ''}${v}%` },
];

const data = [
  { city: '北京', count: 2345, salary: 28000, change: 5.2 },
  { city: '上海', count: 2100, salary: 26500, change: 3.1 },
  { city: '深圳', count: 1890, salary: 25000, change: -1.5 },
];

exportToCSV(data, columns, '岗位数据导出.csv');
```

**要点**：
- BOM 头 `\uFEFF` 是解决 Excel 打开 CSV 中文乱码的关键
- 字段包含逗号、双引号、换行符时必须用双引号包裹，双引号要转义为两个双引号
- `formatter` 支持自定义格式化，薪资加人民币符号，变化加正负号
- `URL.revokeObjectURL` 释放内存，避免内存泄漏

### 练习二

**思路**：使用 html2canvas 将 DOM 元素转为 canvas，再导出为 PNG。关键处理：异步等待图表渲染完成、处理跨域资源、支持高分辨率导出。

**答案**：

```typescript
import html2canvas from 'html2canvas';

interface ExportImageOptions {
  filename?: string;
  scale?: number;         // 缩放比例，2 表示 2x 高清
  backgroundColor?: string;
  format?: 'png' | 'jpeg';
  quality?: number;       // JPEG 质量 0-1
}

async function exportChartToImage(
  elementId: string,
  options: ExportImageOptions = {}
) {
  const {
    filename = 'chart-export',
    scale = 2,
    backgroundColor = '#ffffff',
    format = 'png',
    quality = 0.95,
  } = options;

  const element = document.getElementById(elementId);
  if (!element) {
    throw new Error(`Element with id "${elementId}" not found`);
  }

  // 等待图表动画完成（ECharts/Recharts 渲染需要时间）
  await new Promise((resolve) => setTimeout(resolve, 500));

  const canvas = await html2canvas(element, {
    scale,
    backgroundColor,
    useCORS: true,           // 启用跨域资源加载
    allowTaint: false,       // 不允许污染 canvas
    logging: false,
    windowWidth: element.scrollWidth,
    windowHeight: element.scrollHeight,
  });

  const mimeType = format === 'png' ? 'image/png' : 'image/jpeg';
  const extension = format === 'png' ? '.png' : '.jpg';
  const dataUrl = canvas.toDataURL(mimeType, quality);

  const link = document.createElement('a');
  link.download = filename.endsWith(extension) ? filename : `${filename}${extension}`;
  link.href = dataUrl;
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
}

// 使用示例：导出单个图表
await exportChartToImage('trend-chart', {
  filename: '岗位趋势图',
  scale: 2,
  format: 'png',
});

// 使用示例：导出整个 Dashboard 截图
async function exportFullDashboard() {
  const dashboard = document.getElementById('dashboard-container');
  if (!dashboard) return;

  // 临时隐藏筛选器和操作按钮
  const hiddenElements = dashboard.querySelectorAll('[data-export-hide]');
  hiddenElements.forEach((el) => ((el as HTMLElement).style.display = 'none'));

  await exportChartToImage('dashboard-container', {
    filename: `Dashboard-${new Date().toISOString().slice(0, 10)}`,
    scale: 2,
  });

  // 恢复显示
  hiddenElements.forEach((el) => ((el as HTMLElement).style.display = ''));
}
```

**要点**：
- `scale: 2` 生成 2x 分辨率图片，在 Retina 屏幕上更清晰
- `useCORS: true` 让 html2canvas 尝试加载跨域资源，但需要服务器配置 CORS 头
- 导出前等待 500ms，确保图表动画和渲染已完成
- 导出整个 Dashboard 时，用 `data-export-hide` 标记不需要导出的元素（如筛选器、按钮），导出时临时隐藏
