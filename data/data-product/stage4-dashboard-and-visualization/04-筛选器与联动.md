## 常见误区

- **筛选器之间没有联动关系**：选了"北京市"之后，技能筛选器还显示全国的技能列表，用户选了一个不存在的组合，结果返回空数据。
- **每次筛选都触发全量请求**：改了一个筛选条件，所有图表都重新请求一遍 API，造成大量不必要的网络请求和页面闪烁。
- **筛选状态不持久化**：用户精心设置了一组筛选条件，切换页面后再回来，所有筛选都重置了，需要重新设置。
- **忽略防抖处理**：输入框筛选时每次按键都触发请求，造成大量无意义的 API 调用和页面抖动。

---

## 工程建议

1. **筛选器状态统一管理**：用 Context 或状态管理库维护筛选器状态，确保所有组件从同一个数据源读取筛选条件，避免状态不一致。
2. **关联筛选器要级联更新**：当父级筛选器（如城市）变化时，子级筛选器（如区域）应该自动清空或更新可选值，而不是保留无效选项。
3. **URL 参数同步筛选状态**：把筛选条件序列化到 URL query string 中，用户刷新页面或分享链接时能恢复筛选状态。
4. **文本输入筛选加 300ms 防抖**：搜索框输入时不要实时请求，等用户停止输入 300ms 后再触发请求，减少服务器压力。

## 参考答案

### 练习一

**思路**：用 React Context 统一管理筛选器状态，所有组件从同一个 Context 读取筛选条件。筛选器变化时，通过 Context 更新状态，所有订阅该 Context 的组件自动重新渲染并请求数据。

**答案**：

```tsx
import { createContext, useContext, useState, useCallback, useMemo } from 'react';

interface FilterState {
  city: string;
  skills: string[];
  salaryRange: [number, number];
  dateRange: [string, string];
}

interface FilterContextType {
  filters: FilterState;
  updateFilter: <K extends keyof FilterState>(key: K, value: FilterState[K]) => void;
  resetFilters: () => void;
}

const defaultFilters: FilterState = {
  city: '',
  skills: [],
  salaryRange: [0, 100000],
  dateRange: ['', ''],
};

const FilterContext = createContext<FilterContextType | null>(null);

function FilterProvider({ children }: { children: React.ReactNode }) {
  const [filters, setFilters] = useState<FilterState>(() => {
    const params = new URLSearchParams(window.location.search);
    return {
      city: params.get('city') || defaultFilters.city,
      skills: params.get('skills')?.split(',').filter(Boolean) || defaultFilters.skills,
      salaryRange: [
        Number(params.get('salaryMin')) || defaultFilters.salaryRange[0],
        Number(params.get('salaryMax')) || defaultFilters.salaryRange[1],
      ],
      dateRange: [
        params.get('startDate') || defaultFilters.dateRange[0],
        params.get('endDate') || defaultFilters.dateRange[1],
      ],
    };
  });

  const updateFilter = useCallback(<K extends keyof FilterState>(key: K, value: FilterState[K]) => {
    setFilters((prev) => {
      const next = { ...prev, [key]: value };
      // 同步到 URL
      const params = new URLSearchParams();
      if (next.city) params.set('city', next.city);
      if (next.skills.length) params.set('skills', next.skills.join(','));
      if (next.salaryRange[0] > 0) params.set('salaryMin', String(next.salaryRange[0]));
      if (next.salaryRange[1] < 100000) params.set('salaryMax', String(next.salaryRange[1]));
      if (next.dateRange[0]) params.set('startDate', next.dateRange[0]);
      if (next.dateRange[1]) params.set('endDate', next.dateRange[1]);
      window.history.replaceState(null, '', `?${params.toString()}`);
      return next;
    });
  }, []);

  const resetFilters = useCallback(() => {
    setFilters(defaultFilters);
    window.history.replaceState(null, '', window.location.pathname);
  }, []);

  const value = useMemo(() => ({ filters, updateFilter, resetFilters }), [filters, updateFilter, resetFilters]);

  return <FilterContext.Provider value={value}>{children}</FilterContext.Provider>;
}

function useFilters() {
  const context = useContext(FilterContext);
  if (!context) throw new Error('useFilters must be used within FilterProvider');
  return context;
}

// 使用示例：筛选器组件
function CityFilter() {
  const { filters, updateFilter } = useFilters();
  const cities = ['北京', '上海', '深圳', '杭州', '广州'];

  return (
    <select
      value={filters.city}
      onChange={(e) => updateFilter('city', e.target.value)}
      className="border rounded px-3 py-2"
    >
      <option value="">全部城市</option>
      {cities.map((city) => (
        <option key={city} value={city}>{city}</option>
      ))}
    </select>
  );
}

// 使用示例：图表组件消费筛选状态
function TrendChart() {
  const { filters } = useFilters();
  const { data, isLoading } = useQuery(['trend', filters], () =>
    fetchTrendData(filters)
  );

  if (isLoading) return <div>加载中...</div>;
  return <LineChart data={data} />;
}
```

**要点**：
- FilterProvider 初始化时从 URL 参数恢复筛选状态
- updateFilter 同时更新 state 和 URL，确保刷新不丢失
- useFilters hook 让任何子组件都能读写筛选状态
- React Query 的 queryKey 包含 filters，筛选变化自动重新请求

### 练习二

**思路**：从级联更新、防抖、缓存三个维度优化。城市变化时清空技能筛选器的无效选项，搜索框加防抖，相同筛选条件用缓存避免重复请求。

**答案**：

```tsx
import { useMemo, useRef, useEffect } from 'react';

// 优化1：级联筛选器
function SkillFilter() {
  const { filters, updateFilter } = useFilters();

  // 根据选中城市过滤可选技能
  const availableSkills = useMemo(() => {
    if (!filters.city) return allSkills;
    return allSkills.filter((skill) => skill.cities.includes(filters.city));
  }, [filters.city]);

  // 城市变化时，清空不在可选范围内的已选技能
  useEffect(() => {
    const validSkills = filters.skills.filter((s) => availableSkills.includes(s));
    if (validSkills.length !== filters.skills.length) {
      updateFilter('skills', validSkills);
    }
  }, [filters.city, availableSkills]);

  return (
    <select
      multiple
      value={filters.skills}
      onChange={(e) => {
        const selected = Array.from(e.target.selectedOptions, (o) => o.value);
        updateFilter('skills', selected);
      }}
      className="border rounded px-3 py-2"
    >
      {availableSkills.map((skill) => (
        <option key={skill.name} value={skill.name}>{skill.name}</option>
      ))}
    </select>
  );
}

// 优化2：搜索框防抖
function SearchInput() {
  const { updateFilter } = useFilters();
  const timerRef = useRef<NodeJS.Timeout>();

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    clearTimeout(timerRef.current);
    timerRef.current = setTimeout(() => {
      updateFilter('keyword', e.target.value);
    }, 300);
  };

  useEffect(() => {
    return () => clearTimeout(timerRef.current);
  }, []);

  return (
    <input
      type="text"
      placeholder="搜索岗位..."
      onChange={handleChange}
      className="border rounded px-3 py-2 w-64"
    />
  );
}

// 优化3：React Query 缓存
function useFilteredQuery<T>(key: string, fetcher: (filters: FilterState) => Promise<T>) {
  const { filters } = useFilters();
  return useQuery({
    queryKey: [key, filters],
    queryFn: () => fetcher(filters),
    staleTime: 30_000,
    placeholderData: (prev) => prev,
  });
}
```

**要点**：
- 级联更新：城市变化后自动过滤掉无效的技能选项，而不是保留让用户选到空结果
- 防抖 300ms：用户停止输入后才发请求，避免每次按键都请求
- `placeholderData` 让筛选切换时保留上一次数据，避免页面闪烁
- `staleTime: 30s` 让相同筛选条件在 30 秒内不重复请求
