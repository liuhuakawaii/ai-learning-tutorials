## 常见误区

- **一开始就追求完美**：花太多时间在细节上（动画、颜色微调），结果核心功能没做完。实战应该先把功能跑通，再逐步打磨。
- **组件之间耦合度太高**：指标卡组件直接调用了筛选器的状态，导致组件无法复用。应该通过 props 或 Context 解耦，让每个组件只关心自己的数据。
- **忽略移动端适配**：只在桌面端开发和测试，演示时用平板或手机打开，布局全乱了。实战项目必须考虑响应式。
- **不做数据 Mock**：完全依赖后端接口，后端还没开发完就卡住了。应该用 Mock 数据先把前端功能做完，后端接口 ready 后再对接。

---

## 工程建议

1. **先搭骨架再填内容**：先用静态数据把页面布局和组件结构搭起来，确认交互流程没问题后，再接入真实 API 和动态数据。
2. **组件开发顺序：从原子到页面**：先实现指标卡、图表等原子组件，再组装成容器，最后拼成页面。这样每个组件都可以独立测试和复用。
3. **用 Mock 数据并行开发**：前端用 MSW 或 JSON 文件模拟 API 响应，不等后端接口，前后端可以并行推进，最后联调对接。
4. **演示前做一次完整的端到端测试**：从打开页面、筛选数据、查看图表到导出报告，走一遍完整流程，确保演示时不会翻车。

## 参考答案

### 练习一

**思路**：数据分析看板的核心功能包括指标卡、趋势图、排名表、筛选器和数据导出。先搭建页面骨架，用 Mock 数据填充各组件，再通过 Context 实现筛选联动。

**答案**：

```tsx
import { createContext, useContext, useState, useMemo } from "react";

// 筛选上下文
interface FilterState {
  dateRange: [string, string];
  department: string;
  source: string;
}

const FilterContext = createContext<{
  filters: FilterState;
  setFilters: (f: Partial<FilterState>) => void;
}>({
  filters: { dateRange: ["2024-01-01", "2024-01-31"], department: "all", source: "all" },
  setFilters: () => {},
});

function useFilter() {
  return useContext(FilterContext);
}

// Mock 数据
const mockJobs = [
  { id: 1, title: "前端工程师", company: "A公司", salary: "20-30K", source: "boss", department: "技术", date: "2024-01-15" },
  { id: 2, title: "后端工程师", company: "B公司", salary: "25-35K", source: "lagou", department: "技术", date: "2024-01-16" },
  { id: 3, title: "产品经理", company: "C公司", salary: "18-25K", source: "zhilian", department: "产品", date: "2024-01-17" },
];

// 指标卡组件
function MetricCard({ title, value, trend }: { title: string; value: string | number; trend?: string }) {
  return (
    <div style={{ border: "1px solid #e5e7eb", borderRadius: 8, padding: 16, flex: 1 }}>
      <div style={{ fontSize: 14, color: "#6b7280" }}>{title}</div>
      <div style={{ fontSize: 28, fontWeight: 700, marginTop: 8 }}>{value}</div>
      {trend && <div style={{ fontSize: 12, color: "#10b981", marginTop: 4 }}>{trend}</div>}
    </div>
  );
}

// 排名表组件
function RankingTable({ data }: { data: typeof mockJobs }) {
  return (
    <table style={{ width: "100%", borderCollapse: "collapse" }}>
      <thead>
        <tr style={{ borderBottom: "2px solid #e5e7eb" }}>
          <th style={{ textAlign: "left", padding: 8 }}>排名</th>
          <th style={{ textAlign: "left", padding: 8 }}>职位</th>
          <th style={{ textAlign: "left", padding: 8 }}>公司</th>
          <th style={{ textAlign: "left", padding: 8 }}>薪资</th>
        </tr>
      </thead>
      <tbody>
        {data.map((job, index) => (
          <tr key={job.id} style={{ borderBottom: "1px solid #f3f4f6" }}>
            <td style={{ padding: 8 }}>{index + 1}</td>
            <td style={{ padding: 8 }}>{job.title}</td>
            <td style={{ padding: 8 }}>{job.company}</td>
            <td style={{ padding: 8 }}>{job.salary}</td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}

// 筛选器组件
function FilterBar() {
  const { filters, setFilters } = useFilter();
  return (
    <div style={{ display: "flex", gap: 12, marginBottom: 16 }}>
      <select value={filters.source} onChange={(e) => setFilters({ source: e.target.value })}>
        <option value="all">全部来源</option>
        <option value="boss">Boss直聘</option>
        <option value="lagou">拉勾</option>
        <option value="zhilian">智联招聘</option>
      </select>
      <select value={filters.department} onChange={(e) => setFilters({ department: e.target.value })}>
        <option value="all">全部部门</option>
        <option value="技术">技术</option>
        <option value="产品">产品</option>
      </select>
    </div>
  );
}

// 主看板
export default function Dashboard() {
  const [filters, setFiltersRaw] = useState<FilterState>({
    dateRange: ["2024-01-01", "2024-01-31"],
    department: "all",
    source: "all",
  });

  const setFilters = (partial: Partial<FilterState>) => setFiltersRaw((prev) => ({ ...prev, ...partial }));

  const filteredData = useMemo(() => {
    return mockJobs.filter((job) => {
      if (filters.source !== "all" && job.source !== filters.source) return false;
      if (filters.department !== "all" && job.department !== filters.department) return false;
      return true;
    });
  }, [filters]);

  return (
    <FilterContext.Provider value={{ filters, setFilters }}>
      <div style={{ padding: 24, maxWidth: 1200, margin: "0 auto" }}>
        <h1 style={{ fontSize: 24, fontWeight: 700, marginBottom: 24 }}>招聘数据分析看板</h1>
        <FilterBar />
        <div style={{ display: "flex", gap: 16, marginBottom: 24 }}>
          <MetricCard title="总职位数" value={filteredData.length} trend="+12%" />
          <MetricCard title="平均薪资" value="24.3K" trend="+5%" />
          <MetricCard title="数据来源" value="3个" />
        </div>
        <div style={{ border: "1px solid #e5e7eb", borderRadius: 8, padding: 16 }}>
          <h2 style={{ fontSize: 16, fontWeight: 600, marginBottom: 12 }}>职位排名</h2>
          <RankingTable data={filteredData} />
        </div>
      </div>
    </FilterContext.Provider>
  );
}
```

**要点**：
- 用 `createContext` + `useContext` 实现筛选器与各组件的解耦，组件通过 Context 获取筛选状态而非直接耦合
- `useMemo` 缓存筛选结果，避免每次渲染都重新计算
- 组件职责单一：MetricCard 只管指标展示，RankingTable 只管表格渲染，FilterBar 只管筛选交互

### 练习二

**思路**：用户体验优化包括加载状态、空数据提示、错误处理、响应式布局和导出反馈。在每个数据依赖点添加对应的状态处理，让看板在各种边界条件下都有合理的展示。

**答案**：

```tsx
import { useState, useEffect, useCallback } from "react";

// 加载骨架屏
function SkeletonCard() {
  return (
    <div style={{ border: "1px solid #e5e7eb", borderRadius: 8, padding: 16, flex: 1, background: "#f9fafb" }}>
      <div style={{ height: 14, width: 60, background: "#e5e7eb", borderRadius: 4, marginBottom: 12 }} />
      <div style={{ height: 28, width: 80, background: "#e5e7eb", borderRadius: 4 }} />
    </div>
  );
}

// 空状态组件
function EmptyState({ message }: { message: string }) {
  return (
    <div style={{ textAlign: "center", padding: 48, color: "#9ca3af" }}>
      <div style={{ fontSize: 40, marginBottom: 12 }}>📭</div>
      <div>{message}</div>
    </div>
  );
}

// 错误状态组件
function ErrorState({ message, onRetry }: { message: string; onRetry: () => void }) {
  return (
    <div style={{ textAlign: "center", padding: 48, color: "#ef4444" }}>
      <div style={{ fontSize: 40, marginBottom: 12 }}>⚠️</div>
      <div style={{ marginBottom: 12 }}>{message}</div>
      <button onClick={onRetry} style={{ padding: "8px 16px", cursor: "pointer" }}>重试</button>
    </div>
  );
}

// 导出按钮（带 loading 反馈）
function ExportButton({ data }: { data: unknown[] }) {
  const [exporting, setExporting] = useState(false);

  const handleExport = useCallback(async () => {
    setExporting(true);
    try {
      const csv = data.map((row) => Object.values(row).join(",")).join("\n");
      const blob = new Blob([csv], { type: "text/csv" });
      const url = URL.createObjectURL(blob);
      const a = document.createElement("a");
      a.href = url;
      a.download = "export.csv";
      a.click();
      URL.revokeObjectURL(url);
    } finally {
      setExporting(false);
    }
  }, [data]);

  return (
    <button onClick={handleExport} disabled={exporting || data.length === 0} style={{ padding: "8px 16px" }}>
      {exporting ? "导出中..." : "导出 CSV"}
    </button>
  );
}

// 带完整状态处理的看板
export default function EnhancedDashboard() {
  const [data, setData] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const fetchData = useCallback(async () => {
    setLoading(true);
    setError(null);
    try {
      const res = await fetch("/api/jobs");
      if (!res.ok) throw new Error(`请求失败: ${res.status}`);
      const json = await res.json();
      setData(json);
    } catch (e: any) {
      setError(e.message || "加载失败");
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => { fetchData(); }, [fetchData]);

  if (loading) {
    return (
      <div style={{ display: "flex", gap: 16, padding: 24 }}>
        <SkeletonCard /><SkeletonCard /><SkeletonCard />
      </div>
    );
  }

  if (error) return <ErrorState message={error} onRetry={fetchData} />;
  if (data.length === 0) return <EmptyState message="暂无数据，请调整筛选条件" />;

  return (
    <div style={{ padding: 24 }}>
      <div style={{ display: "flex", justifyContent: "space-between", marginBottom: 16 }}>
        <h1>招聘数据分析看板</h1>
        <ExportButton data={data} />
      </div>
      {/* 正常数据展示... */}
    </div>
  );
}
```

**要点**：
- 加载时用骨架屏（SkeletonCard）替代空白页面，给用户即时反馈
- 错误状态提供"重试"按钮，用户无需刷新页面即可恢复
- 导出按钮在执行期间显示"导出中..."并禁用，防止重复点击
- 空数据时给出明确提示，引导用户调整筛选条件
