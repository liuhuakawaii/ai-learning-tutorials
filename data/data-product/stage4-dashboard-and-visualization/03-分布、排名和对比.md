## 常见误区

- **饼图分类过多**：超过 5-6 个分类全用饼图展示，小扇区挤在一起根本看不清。应该把占比小的分类合并为"其他"，或者改用横向柱状图。
- **排名表不支持排序和高亮**：静态排名表用户只能看，不能按不同维度排序，也没有高亮上升/下降的排名变化，信息密度大打折扣。
- **对比图表时间维度不一致**：同比图用了自然月，环比图用了 30 天，用户对比时发现数据对不上，产生困惑。
- **分布图忽略长尾数据**：只展示 TOP10 而忽略长尾分布，用户无法了解"其他"类别到底有多少数据。

---

## 工程建议

1. **饼图超过 6 个分类时合并为"其他"**：保持饼图可读性，或者直接改用横向柱状图，柱状图对多分类的支持更好。
2. **排名表支持多维度排序**：实现点击表头排序的功能，并用箭头图标标识排序方向，让用户可以从不同角度分析排名。
3. **对比图表统一时间粒度**：同比和环比使用相同的时间粒度（天/周/月），避免用户因时间维度不一致产生困惑。
4. **分布图提供下钻能力**：点击饼图扇区或柱状图柱子时，支持下钻到具体明细，让用户可以从宏观分布看到微观数据。

## 参考答案

### 练习一

**思路**：分布用饼图展示城市岗位占比，排名用可排序表格展示 TOP10 城市，对比用分组柱状图展示同比数据。关键是处理好饼图分类过多和排名表交互。

**答案**：

```tsx
import { PieChart, Pie, Cell, Tooltip, ResponsiveContainer } from 'recharts';
import { useState } from 'react';

const cityDistribution = [
  { city: '北京', count: 2345 },
  { city: '上海', count: 2100 },
  { city: '深圳', count: 1890 },
  { city: '杭州', count: 1560 },
  { city: '广州', count: 1420 },
  { city: '其他', count: 3200 },
];

const COLORS = ['#3b82f6', '#2563eb', '#1d4ed8', '#60a5fa', '#93c5fd', '#dbeafe'];

function CityDistributionChart() {
  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">城市岗位分布</h3>
      <ResponsiveContainer width="100%" height={300}>
        <PieChart>
          <Pie
            data={cityDistribution}
            dataKey="count"
            nameKey="city"
            cx="50%"
            cy="50%"
            outerRadius={100}
            label={({ city, percent }) => `${city} ${(percent * 100).toFixed(1)}%`}
          >
            {cityDistribution.map((_, index) => (
              <Cell key={index} fill={COLORS[index]} />
            ))}
          </Pie>
          <Tooltip formatter={(value: number) => [`${value} 个`, '岗位数量']} />
        </PieChart>
      </ResponsiveContainer>
    </div>
  );
}

// 排名表：支持点击表头排序
type SortKey = 'city' | 'count' | 'change';
type SortDir = 'asc' | 'desc';

function RankingTable({ data }: { data: typeof cityDistribution & { change: number }[] }) {
  const [sortKey, setSortKey] = useState<SortKey>('count');
  const [sortDir, setSortDir] = useState<SortDir>('desc');

  const handleSort = (key: SortKey) => {
    if (sortKey === key) {
      setSortDir(sortDir === 'asc' ? 'desc' : 'asc');
    } else {
      setSortKey(key);
      setSortDir('desc');
    }
  };

  const sorted = [...data].sort((a, b) => {
    const mul = sortDir === 'asc' ? 1 : -1;
    return a[sortKey] > b[sortKey] ? mul : -mul;
  });

  return (
    <table className="w-full text-sm">
      <thead>
        <tr className="border-b">
          <th className="p-2 text-left cursor-pointer" onClick={() => handleSort('city')}>
            城市 {sortKey === 'city' && (sortDir === 'asc' ? '↑' : '↓')}
          </th>
          <th className="p-2 text-right cursor-pointer" onClick={() => handleSort('count')}>
            岗位数 {sortKey === 'count' && (sortDir === 'asc' ? '↑' : '↓')}
          </th>
          <th className="p-2 text-right cursor-pointer" onClick={() => handleSort('change')}>
            变化 {sortKey === 'change' && (sortDir === 'asc' ? '↑' : '↓')}
          </th>
        </tr>
      </thead>
      <tbody>
        {sorted.map((row, i) => (
          <tr key={row.city} className={i % 2 === 0 ? 'bg-gray-50' : ''}>
            <td className="p-2">{row.city}</td>
            <td className="p-2 text-right">{row.count}</td>
            <td className={`p-2 text-right ${row.change > 0 ? 'text-green-500' : 'text-red-500'}`}>
              {row.change > 0 ? '↑' : '↓'} {Math.abs(row.change)}%
            </td>
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

**要点**：
- 饼图超过 6 个分类时，把占比小的合并为"其他"
- 排名表支持点击表头排序，用箭头标识当前排序方向
- 变化列用绿色/红色高亮涨跌

### 练习二

**思路**：从可读性、交互性和一致性三个方面优化。饼图加上图例和点击下钻，排名表加上高亮和搜索，对比图统一时间粒度。

**答案**：

```tsx
// 优化1：饼图加图例 + 点击下钻
function OptimizedPieChart({ data, onSliceClick }) {
  const [activeIndex, setActiveIndex] = useState<number | null>(null);

  return (
    <div className="bg-white rounded-lg p-6 shadow-sm">
      <h3 className="text-lg font-semibold mb-4">城市岗位分布</h3>
      <ResponsiveContainer width="100%" height={300}>
        <PieChart>
          <Pie
            data={data}
            dataKey="count"
            nameKey="city"
            cx="50%"
            cy="50%"
            outerRadius={100}
            onMouseEnter={(_, index) => setActiveIndex(index)}
            onMouseLeave={() => setActiveIndex(null)}
            onClick={(entry) => onSliceClick?.(entry.city)}
            style={{ cursor: 'pointer' }}
          >
            {data.map((_, index) => (
              <Cell
                key={index}
                fill={COLORS[index]}
                opacity={activeIndex === null || activeIndex === index ? 1 : 0.6}
              />
            ))}
          </Pie>
          <Tooltip />
        </PieChart>
      </ResponsiveContainer>
      {/* 自定义图例 */}
      <div className="flex flex-wrap gap-3 mt-4 justify-center">
        {data.map((item, index) => (
          <div key={item.city} className="flex items-center gap-1 text-sm">
            <div className="w-3 h-3 rounded" style={{ backgroundColor: COLORS[index] }} />
            <span>{item.city}</span>
          </div>
        ))}
      </div>
    </div>
  );
}

// 优化2：对比图统一时间粒度
function ComparisonChart({ thisYear, lastYear }) {
  return (

      <h3 className="text-lg font-semibold mb-4">同比对比（按月）</h3>
      <ResponsiveContainer width="100%" height={300}>

```

**要点**：
- 鼠标悬浮时高亮当前扇区，其他扇区变淡，引导用户注意力
- 点击饼图扇区触发下钻，展示该城市的明细数据
- 同比和环比使用相同的时间粒度（月），避免数据对不上
- 图例用自定义组件而非 Recharts 默认图例，样式更灵活
