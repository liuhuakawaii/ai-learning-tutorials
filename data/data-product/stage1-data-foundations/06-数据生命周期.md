# 第6课：数据生命周期

> **课程定位**：理解数据从采集到展示的完整流转过程，建立分层存储的意识
> **前置知识**：第5课（数据字典设计）
> **预计时长**：40 分钟

---

## 场景引入

你的数据产品上线后，某天产品经理说"上周的平均薪资数据不对"。你去查聚合表，发现确实是错的，但不知道是原始数据有问题、清洗逻辑有 bug、还是聚合算法算错了。因为你只存了一张最终的聚合表，中间过程全部丢失。你不得不重新跑一遍整个流程，但原始数据也已经被覆盖了。这时候你才理解：分层存储不是"多此一举"，而是"留一条后路"。

---

## 学习目标

完成本课学习后，你将能够：

1. 描述数据从采集到展示的完整生命周期

3. 理解为什么需要分层存储
4. 设计一个数据流转方案
5. 处理数据生命周期中的常见问题

## 一、数据的四个阶段

### 1.1 生命周期概览

```
┌─────────────────────────────────────────────────────────────────┐
│                    数据生命周期                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐ │
│   │  原始数据 │ →  │  清洗数据 │ →  │  聚合数据 │ →  │  展示数据 │ │
│   │  (Raw)    │    │  (Clean) │    │(Metrics) │    │ (Display)│ │
│   └──────────┘    └──────────┘    └──────────┘    └──────────┘ │
│        │               │               │               │       │
│        ▼               ▼               ▼               ▼       │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │                      处理流程                            │  │
│   │  采集 → 清洗 → 转换 → 聚合 → 存储 → 查询 → 展示         │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 四个阶段详解

```
┌──────────────────────────────────────────────────────────────┐
│                    数据四阶段                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  阶段 1：原始数据（Raw）                                      │
│  ├── 来源：直接从数据源获取                                  │
│  ├── 特点：未处理、可能有脏数据                              │
│  ├── 存储：raw 表 / 原始文件                                 │
│  └── 用途：追溯来源、重新处理                                │
│                                                              │
│  阶段 2：清洗数据（Clean）                                    │
│  ├── 来源：原始数据经过清洗                                  │
│  ├── 特点：格式统一、无效数据已过滤                          │
│  ├── 存储：clean 表                                          │
│  └── 用途：数据分析、生成指标                                │
│                                                              │
│  阶段 3：聚合数据（Metrics）                                  │
│  ├── 来源：清洗数据经过聚合计算                              │
│  ├── 特点：按维度汇总、计算指标                              │
│  ├── 存储：metrics 表                                        │
│  └── 用途：趋势分析、对比分析                                │
│                                                              │
│  阶段 4：展示数据（Display）                                  │
│  ├── 来源：聚合数据或清洗数据                                │
│  ├── 特点：格式化、带单位、适合展示                          │
│  ├── 存储：API 响应 / 缓存                                   │
│  └── 用途：Dashboard、报表、导出                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.3 清洗代码示例

```python
import re
from decimal import Decimal

def clean_job_data(raw_data: dict) -> dict:
    """清洗招聘数据"""
    
    # 1. 去除空白
    title = raw_data.get("title", "").strip()
    company = raw_data.get("company", "").strip()
    city = raw_data.get("city", "").strip()
    
    # 2. 解析薪资
    salary_str = raw_data.get("salary", "")
    salary_min, salary_max = parse_salary(salary_str)
    
    # 3. 标准化经验要求
    experience = normalize_experience(raw_data.get("experience", ""))
    
    # 4. 标准化学历要求
    education = normalize_education(raw_data.get("education", ""))
    
    # 5. 构建清洗后的数据
    clean_data = {
        "job_id": raw_data.get("id"),
        "title": title,
        "company": company,
        "city": city,
        "district": raw_data.get("district", "").strip() or None,
        "salary_min": salary_min,
        "salary_max": salary_max,
        "salary_avg": (salary_min + salary_max) / 2 if salary_min and salary_max else None,
        "experience": experience,
        "education": education,
        "skills": raw_data.get("skills", "").strip() or None,
        "source": raw_data.get("source"),
        "source_url": raw_data.get("url"),
        "publish_date": parse_date(raw_data.get("publish_date")),
        "crawl_time": raw_data.get("crawl_time"),
        "batch_id": raw_data.get("batch_id"),
    }
    
    return clean_data

def parse_salary(salary_str: str) -> tuple:
    """解析薪资字符串"""
    # 示例：'20K-35K·14薪' → (20000, 35000)
    match = re.search(r'(\d+)[Kk]-(\d+)[Kk]', salary_str)
    if match:
        min_salary = int(match.group(1)) * 1000
        max_salary = int(match.group(2)) * 1000
        return min_salary, max_salary
    return None, None

def normalize_experience(exp: str) -> str:
    """标准化经验要求"""
    exp_map = {
        "应届": "不限",
        "1年以下": "1-3年",
        "1-3年": "1-3年",
        "3-5年": "3-5年",
        "5-10年": "5-10年",
        "10年以上": "10年以上",
    }
    return exp_map.get(exp, exp)
```

### 4.3 聚合代码示例

```python
import pandas as pd

def aggregate_city_daily(clean_data: pd.DataFrame, stat_date: str) -> pd.DataFrame:
    """按城市按天聚合"""
    
    # 筛选当天数据
    daily_data = clean_data[clean_data['crawl_time'].dt.date == stat_date]
    
    # 按城市聚合
    agg_result = daily_data.groupby('city').agg(
        job_count=('job_id', 'count'),
        avg_salary=('salary_avg', 'mean'),
        max_salary=('salary_max', 'max'),
        min_salary=('salary_min', 'min'),
    ).reset_index()
    
    # 添加日期
    agg_result['stat_date'] = stat_date
    
    return agg_result

def aggregate_skill_monthly(clean_data: pd.DataFrame, stat_month: str) -> pd.DataFrame:
    """按技能按月聚合"""
    
    # 筛选当月数据
    monthly_data = clean_data[
        clean_data['crawl_time'].dt.strftime('%Y-%m') == stat_month
    ]
    
    # 拆分技能字段
    skills_data = monthly_data.assign(
        skill=monthly_data['skills'].str.split(',')
    ).explode('skill')
    
    # 去除空白
    skills_data['skill'] = skills_data['skill'].str.strip()
    
    # 按技能聚合
    agg_result = skills_data.groupby('skill').agg(
        demand_count=('job_id', 'count'),
        avg_salary=('salary_avg', 'mean'),
    ).reset_index()
    
    # 添加月份
    agg_result['stat_month'] = stat_month
    
    return agg_result
```

## 七、分层存储的好处

### 7.1 为什么分层？

```
┌──────────────────────────────────────────────────────────────┐
│                    分层存储的好处                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 数据可追溯                                                │
│     └── 任何指标都可以追溯到原始数据                          │
│                                                              │
│  2. 逻辑可修改                                                │
│     └── 清洗逻辑变更后可重新处理                              │
│                                                              │
│  3. 查询性能优化                                              │
│     └── 聚合表预计算，查询更快                                │
│                                                              │
│  4. 职责分离                                                  │
│     └── 每层只做一件事，代码清晰                              │
│                                                              │
│  5. 故障隔离                                                  │
│     └── 某层出问题不影响其他层                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 7.2 分层对比

```
┌─────────────┬──────────────┬──────────────┬──────────────┐
│    层级     │   数据特点    │   存储位置    │   访问频率   │
├─────────────┼──────────────┼──────────────┼──────────────┤
│  Raw        │ 原始、未处理  │ raw 表       │ 低（追溯用） │
│  Clean      │ 清洗、标准化  │ clean 表     │ 中（分析用） │
│  Metrics    │ 聚合、计算    │ metrics 表   │ 高（展示用） │
│  Display    │ 格式化、展示  │ 缓存/API     │ 最高         │
└─────────────┴──────────────┴──────────────┴──────────────┘
```

## 常见误区

- **"原始数据没用，直接删"**：原始数据看起来又脏又乱，但它是最真实的数据快照。当清洗逻辑有 bug 需要重新处理时，如果没有原始数据，就只能重新采集——而历史数据可能已经拿不到了。
- **跳过清洗层直接聚合**：为了省事，直接从原始数据聚合出指标。结果原始数据里的脏数据（空值、异常值、重复值）全部混进指标里，导致指标不可信。
- **认为分层会让系统变复杂**：分层确实多了一些表和流程，但它让每一层的职责清晰、问题可定位。当数据出错时，你可以逐层排查，而不是在一个大杂烩里找 bug。
- **聚合指标和原始指标混用**：`avg_salary` 既用来做聚合计算，又直接返回给前端展示。一旦聚合逻辑变更，前端展示也会受影响。展示层应该有自己的格式化逻辑。

---

## 工程建议

- **每层数据都有明确的输入输出定义**：用文档记录每层的数据来源、处理逻辑、输出格式。新人看到文档就能理解数据是怎么流转的，不需要通读代码。
- **原始数据设置保留策略**：原始数据不需要永久保留（存储成本高），但也不能用完就删。建议保留 30-90 天，超过期限的数据可以归档到冷存储（如对象存储）。
- **每层数据独立建索引**：原始表按 `crawl_time` 和 `batch_id` 索引（追溯用）；清洗表按业务字段索引（查询用）；聚合表按维度组合索引（展示用）。不同层的查询模式不同，索引策略也应该不同。
- **数据流转过程要有日志和指标**：记录每层处理的数据量、耗时、成功/失败数。当某天指标突然异常时，你可以通过日志快速定位是哪层出的问题。

### 练习二

**思路**：逐一处理原始数据的每个字段——去空白、解析数值、计算派生值、标准化状态、格式化时间。

**答案**：

```python
from datetime import datetime
from decimal import Decimal

def clean_product_data(raw_data: dict) -> dict:
    """清洗商品数据"""

    # 1. 去除空白
    product_name = raw_data.get("product_name", "").strip()

    # 2. 解析价格为数值
    price_str = raw_data.get("price", "0")
    # 移除人民币符号和逗号，转为 Decimal
    current_price = Decimal(price_str.replace("￥", "").replace(",", "").strip())

    # 3. 解析折扣并计算折后价
    discount_str = raw_data.get("discount", "")
    if "折" in discount_str:
        # "8.5折" → 0.85
        discount_rate = Decimal(discount_str.replace("折", "")) / 10
    else:
        discount_rate = Decimal("1.0")

    discounted_price = (current_price * discount_rate).quantize(Decimal("0.01"))

    # 4. 标准化库存状态
    stock_str = raw_data.get("stock", "")
    stock_map = {
        "有货": "in_stock",
        "无货": "out_of_stock",
        "预售": "presale",
        "缺货": "out_of_stock",
    }
    stock_status = stock_map.get(stock_str, "unknown")

    # 5. 格式化时间
    update_time_str = raw_data.get("update_time", "")
    try:
        update_time = datetime.strptime(update_time_str, "%Y/%m/%d %H:%M:%S")
    except ValueError:
        update_time = datetime.now()

    return {
        "product_name": product_name,
        "current_price": current_price,
        "discount_rate": discount_rate,
        "discounted_price": discounted_price,
        "stock_status": stock_status,
        "update_time": update_time,
    }


# 测试
```

**要点**：
- 金额用 Decimal 而不是 float，避免浮点精度问题（0.1 + 0.2 ≠ 0.3）

### 练习三

**思路**：用 pandas 的 groupby 按城市聚合，计算统计指标。有货率需要先将状态转换为布尔值再求均值。

**答案**：

```python
import pandas as pd
from decimal import Decimal

def aggregate_by_city(clean_data: pd.DataFrame) -> pd.DataFrame:
    """按城市聚合商品指标"""

    # 确保数值类型正确
    clean_data["current_price"] = pd.to_numeric(clean_data["current_price"], errors="coerce")
    clean_data["in_stock"] = (clean_data["stock_status"] == "in_stock").astype(int)

    # 按城市聚合
    agg_result = clean_data.groupby("city").agg(
        product_count=("product_id", "count"),          # 商品数量
        avg_price=("current_price", "mean"),             # 平均价格
        max_price=("current_price", "max"),              # 最高价格
        min_price=("current_price", "min"),              # 最低价格
        in_stock_rate=("in_stock", "mean"),              # 有货率
    ).reset_index()

    # 有货率转为百分比
    agg_result["in_stock_rate"] = (agg_result["in_stock_rate"] * 100).round(2)

    # 数值格式化
    agg_result["avg_price"] = agg_result["avg_price"].round(2)
    agg_result["max_price"] = agg_result["max_price"].round(2)
    agg_result["min_price"] = agg_result["min_price"].round(2)

    return agg_result
```
