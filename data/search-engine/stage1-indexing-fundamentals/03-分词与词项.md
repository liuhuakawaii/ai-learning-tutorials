# 分词与词项处理

## 场景引入

上节课我们构建了倒排索引，但有个被忽略的前提：文本必须先被拆分成词项（terms），才能建立索引。对于英文来说按空格切分就行，但中文完全不同。

"南京市长江大桥" 应该切成 "南京市 / 长江大桥" 还是 "南京 / 市长 / 江大桥"？分词质量直接决定搜索引擎的召回率。如果用户搜索"苹果手机"，而分词器把"苹果手机"切成"苹果"和"手机"，那么只包含"苹果"（水果）的文档也会被召回。

### 分词失败的真实案例

分词问题不只是学术讨论，它在生产环境中会导致严重的搜索质量问题：

- **品牌名被切碎**："iPhone 15 Pro Max" 如果被切成 "iphone"、"15"、"pro"、"max"，搜索 "iPhone 15" 会召回所有包含 "15" 的文档（如 "15号线地铁"）。
- **新词识别失败**："ChatGPT"、"Sora"、"Kimi" 这类新词不在通用词典中，分词器可能切成无意义的片段。
- **中英文混排**："用Python写爬虫" 需要同时处理中文分词和英文 tokenization，简单的正则切分会丢失语义。
- **歧义消解**："下雨天留客天留我不留" 有至少 5 种断句方式，每种含义完全不同。

这些问题的核心在于：**分词是搜索引擎质量的第一道关卡**。分词错了，后续的索引、检索、排序都无法弥补。

## 中文分词算法

### 基于词典的分词：最大匹配算法

核心思想是：在词典中找到与当前文本匹配的最长词。

```python
def max_forward_match(text: str, dictionary: set[str], max_word_len: int = 5) -> list[str]:
    """正向最大匹配分词"""
    result = []
    i = 0
    while i < len(text):
        matched = False
        for length in range(min(max_word_len, len(text) - i), 0, -1):
            word = text[i:i + length]
            if word in dictionary:
                result.append(word)
                i += length
                matched = True
                break
        if not matched:
            result.append(text[i])
            i += 1
    return result


dictionary = {"南京", "南京市", "市长", "长江", "长江大桥", "大桥"}
print("正向最大匹配:", max_forward_match("南京市长江大桥", dictionary))
# ['南京市', '长江大桥'] ✓
```

正向最大匹配只从左往右看，容易在歧义处出错。反向最大匹配从右往左切分，两者结合可以处理更多情况。但最大匹配算法有明显局限：依赖人工维护的词典，无法识别新词（如"内卷"、"躺平"），没有考虑词频和上下文。

### 基于统计的分词

jieba 使用**基于前缀词典的最大概率切分 + HMM 新词发现**的组合策略：

```python
import jieba

text = "南京市长江大桥今天通车了"
print("精确模式:", list(jieba.cut(text)))
# ['南京市', '长江大桥', '今天', '通车', '了']

print("全模式:", list(jieba.cut(text, cut_all=True)))
# ['南京', '南京市', '京市', '市长', '长江', '长江大桥', '大桥', '今天', '通车', '了']

print("搜索引擎模式:", list(jieba.cut_for_search(text)))
# ['南京', '京市', '南京市', '长江', '大桥', '长江大桥', '今天', '通车', '了']
```

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| 精确模式 | 最大概率切分，结果最准确 | 文本分析、索引构建 |
| 全模式 | 找出所有可能的词，有冗余 | 关键词提取 |
| 搜索引擎模式 | 长词再切分，提高召回率 | 搜索引擎索引 |

### 基于深度学习的分词

传统分词依赖词典和统计规则，而深度学习分词（如 BERT 的 WordPiece、SentencePiece）通过子词（subword）切分来处理未登录词（OOV）。

核心思想是：将罕见词拆分为常见子词的组合。例如 "ChatGPT" 可能被拆分为 "Chat" + "G" + "PT"，这样即使词典中没有 "ChatGPT"，也能通过子词匹配召回相关文档。

```python
class SimpleBPE:
    """简化的 BPE（Byte Pair Encoding）分词演示"""

    def __init__(self, vocab_size: int = 100):
        self.vocab_size = vocab_size
        self.merges: list[tuple[str, str]] = []
        self.vocab: set[str] = set()

    def train(self, corpus: list[str]):
        """从语料中学习合并规则"""
        # 初始化：每个字符作为一个 token
        word_freq: dict[str, int] = {}
        for text in corpus:
            for word in text.split():
                chars = " ".join(list(word)) + " </w>"
                word_freq[chars] = word_freq.get(chars, 0) + 1

        self.vocab = set()
        for chars in word_freq:
            for c in chars.split():
                self.vocab.add(c)

        for _ in range(self.vocab_size - len(self.vocab)):
            pairs = self._get_pair_counts(word_freq)
            if not pairs:
                break
            best_pair = max(pairs, key=pairs.get)
            self.merges.append(best_pair)
            word_freq = self._merge_pair(best_pair, word_freq)
            self.vocab.add(best_pair[0] + best_pair[1])

    def tokenize(self, text: str) -> list[str]:
        """使用学到的规则分词"""
        tokens = list(text)
        for left, right in self.merges:
            i = 0
            while i < len(tokens) - 1:
                if tokens[i] == left and tokens[i + 1] == right:
                    tokens[i] = left + right
                    del tokens[i + 1]
                else:
                    i += 1
        return tokens

    def _get_pair_counts(self, word_freq: dict[str, int]) -> dict[tuple, int]:
        pairs: dict[tuple, int] = {}
        for chars, freq in word_freq.items():
            symbols = chars.split()
            for i in range(len(symbols) - 1):
                pair = (symbols[i], symbols[i + 1])
                pairs[pair] = pairs.get(pair, 0) + freq
        return pairs

    def _merge_pair(self, pair: tuple[str, str], word_freq: dict[str, int]) -> dict[str, int]:
        result = {}
        bigram = " ".join(pair)
        replacement = "".join(pair)
        for chars, freq in word_freq.items():
            new_chars = chars.replace(bigram, replacement)
            result[new_chars] = freq
        return result


# 使用示例
bpe = SimpleBPE(vocab_size=200)
bpe.train(["搜索引擎 搜索引擎 倒排索引 倒排索引 索引构建"])
print("分词结果:", bpe.tokenize("搜索引擎"))
```

**传统分词 vs 深度学习分词的选择**：
- 传统分词（jieba）：速度快、可解释、适合中文，是搜索引擎索引阶段的首选
- 深度学习分词（BPE/WordPiece）：能处理未登录词，适合语义检索（向量化），但速度较慢
- 生产实践中，索引阶段用传统分词保证速度，查询理解阶段可以结合深度学习分词做语义扩展

## 分词 Pipeline

完整流程：原始文本 → 分词 → 去停用词 → 词干提取 → 同义词扩展。

### 步骤一：分词

```python
import re


def tokenize(text: str, mode: str = "search") -> list[str]:
    """中英文混合分词"""
    try:
        import jieba
        tokens = jieba.cut_for_search(text) if mode == "search" else jieba.cut(text)
    except ImportError:
        tokens = re.findall(r"[\u4e00-\u9fff]+|[a-zA-Z0-9]+", text)

    result = []
    for token in tokens:
        token = token.strip().lower()
        if token and (re.match(r"[a-z0-9]+", token) or len(token) >= 1):
            result.append(token)
    return result
```

### 步骤二：停用词过滤

```python
STOPWORDS = {

    "会", "着", "没有", "好", "自己", "这", "他", "她", "它",
    "the", "a", "an", "is", "are", "was", "were",

def remove_stopwords(tokens: list[str], stopwords: set[str] = STOPWORDS) -> list[str]:
```

### 停用词的自动化选择

人工维护停用词表费时费力，而且不同领域需要不同的停用词。更科学的方法是通过 **IDF（逆文档频率）** 自动识别停用词：IDF 越低的词，在越多文档中出现，区分度越低，越可能是停用词。

```python
import math
from collections import Counter


class AutoStopwordDetector:
    """基于 IDF 的自动停用词检测"""

    def __init__(self, idf_threshold: float = 2.0):
        self.idf_threshold = idf_threshold  # 低于此阈值的词被视为停用词
        self.idf_cache: dict[str, float] = {}

    def build_idf(self, documents: list[list[str]]):
        """从文档集合中计算每个词的 IDF"""
        doc_count = len(documents)
        df: Counter = Counter()  # document frequency

        for doc_tokens in documents:
            unique_tokens = set(doc_tokens)
            for token in unique_tokens:
                df[token] += 1

        for term, freq in df.items():
            self.idf_cache[term] = math.log(doc_count / (1 + freq))

    def detect_stopwords(self, tokens: list[str]) -> tuple[list[str], list[str]]:
        """将词项分为内容词和停用词"""
        content_tokens = []
        stopwords = []
        for token in tokens:
            idf = self.idf_cache.get(token, 5.0)  # 未见过的词给高 IDF
            if idf < self.idf_threshold:
                stopwords.append(token)
            else:
                content_tokens.append(token)
        return content_tokens, stopwords

    def get_idf_report(self, top_n: int = 20) -> list[tuple[str, float]]:
        """查看 IDF 最低的词（停用词候选）"""
        sorted_terms = sorted(self.idf_cache.items(), key=lambda x: x[1])
        return sorted_terms[:top_n]


# 使用示例
documents = [
    ["python", "是", "最好", "的", "编程", "语言"],
    ["java", "是", "企业", "级", "的", "编程", "语言"],
    ["搜索引擎", "需要", "倒排索引", "和", "分词"],
    ["python", "适合", "开发", "搜索引擎", "原型"],
]

detector = AutoStopwordDetector(idf_threshold=1.5)
detector.build_idf(documents)

print("IDF 最低的词（停用词候选）:")
for term, idf in detector.get_idf_report(10):
    print(f"  {term}: IDF={idf:.2f}")
```

**要点**：
- IDF 阈值需要根据语料规模调整，通常在 1.5-3.0 之间
- 自动检测可以作为人工维护的辅助，不能完全替代。例如"的"的 IDF 极低，但有些领域中"的"可能有特殊含义

### 步骤三：词干提取（Stemming）

词干提取将词语的不同形态归并到同一词根，主要适用于英文：

```python
def simple_stem(word: str) -> str:
    if len(word) <= 3:
        return word
    for suffix in ["ing", "tion", "ness", "ment", "able", "ies", "ed", "ly", "er", "s"]:
        if word.endswith(suffix) and len(word) - len(suffix) >= 3:
            return word[:-len(suffix)]
    return word


for w in ["running", "searching", "searches", "engines"]:
    print(f"{w:12s} → {simple_stem(w)}")
```

中文一般不需要词干提取，因为中文没有词形变化。但有时需要做同义词归并。

### 步骤四：同义词扩展

```python
SYNONYM_MAP = {
    "电脑": ["计算机", "pc", "微机"],
    "手机": ["移动电话", "智能机", "mobile"],
    "ai": ["人工智能", "artificial intelligence"],
}


def expand_synonyms(tokens: list[str], synonym_map: dict = SYNONYM_MAP) -> list[str]:
    expanded = list(tokens)
    for token in tokens:
        for key, synonyms in synonym_map.items():
            if token == key or token in synonyms:
                for variant in {key} | set(synonyms):
                    if variant not in expanded:
                        expanded.append(variant)
    return expanded


print(expand_synonyms(["电脑", "维修"]))
# ['电脑', '维修', '计算机', 'pc', '微机']
```

### 拼写纠错

用户经常输入错别字："pytohn"（python）、"到排索引"（倒排索引）。搜索引擎需要自动纠正或提供建议。拼写纠错的核心是找到与错误输入"最相似"的正确词。

```python
class SimpleSpellCorrector:
    """基于编辑距离和拼音的拼写纠错"""

    def __init__(self, vocabulary: list[str]):
        self.vocabulary = vocabulary
        self.vocab_set = set(vocabulary)

    def correct(self, word: str, max_distance: int = 2) -> list[tuple[str, int]]:
        """返回编辑距离最小的候选词列表"""
        if word in self.vocab_set:
            return [(word, 0)]

        candidates = []
        for vocab_word in self.vocabulary:
            dist = self._edit_distance(word, vocab_word)
            if dist <= max_distance:
                candidates.append((vocab_word, dist))

        candidates.sort(key=lambda x: x[1])
        return candidates[:5]

    @staticmethod
    def _edit_distance(s1: str, s2: str) -> int:
        m, n = len(s1), len(s2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1):
            dp[i][0] = i
        for j in range(n + 1):
            dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                cost = 0 if s1[i-1] == s2[j-1] else 1
                dp[i][j] = min(dp[i-1][j] + 1, dp[i][j-1] + 1, dp[i-1][j-1] + cost)
        return dp[m][n]


class PinyinSpellCorrector:
    """基于拼音相似度的中文纠错"""

    # 简化的拼音映射（完整实现需要 pypinyin 库）
    PINYIN_MAP = {
        "到": "dao", "倒": "dao", "道": "dao",
        "排": "pai", "牌": "pai", "派": "pai",
        "索": "suo", "所": "suo", "锁": "suo",
        "引": "yin", "因": "yin", "音": "yin",
    }

    @classmethod
    def get_pinyin(cls, char: str) -> str:
        return cls.PINYIN_MAP.get(char, char)

    @classmethod
    def pinyin_similarity(cls, word1: str, word2: str) -> float:
        """计算两个词的拼音相似度"""
        if len(word1) != len(word2):
            return 0.0
        pinyin1 = [cls.get_pinyin(c) for c in word1]
        pinyin2 = [cls.get_pinyin(c) for c in word2]
        match = sum(1 for p1, p2 in zip(pinyin1, pinyin2) if p1 == p2)
        return match / len(word1) if word1 else 0.0


# 使用示例
corrector = SimpleSpellCorrector(["python", "java", "搜索引擎", "倒排索引", "分词"])
print("纠正 'pytohn':", corrector.correct("pytohn"))
# [('python', 2)]

print("拼音相似度:", PinyinSpellCorrector.pinyin_similarity("到排索引", "倒排索引"))
# 1.0（拼音完全相同，只是字形不同）
```

**拼写纠错的工程权衡**：
- 编辑距离适合英文拼写错误，对中文同音字效果差
- 拼音相似度适合中文同音字替换，但无法处理多字漏字
- 生产环境通常结合两种方法，再加上用户搜索日志的统计纠正（"搜 A 的人有 80% 其实想搜 B"）

## 完整 Pipeline

```python
class TextProcessor:
    def __init__(self, stopwords: set[str] = None, synonyms: dict = None):
        self.stopwords = stopwords or STOPWORDS
        self.synonyms = synonyms or SYNONYM_MAP

    def index_text(self, text: str) -> list[str]:
        """索引阶段：分词 + 去停用词"""
        tokens = tokenize(text)
        return remove_stopwords(tokens, self.stopwords)

    def query_text(self, text: str) -> list[str]:
        """查询阶段：分词 + 去停用词 + 同义词扩展"""
        tokens = tokenize(text)
        tokens = remove_stopwords(tokens, self.stopwords)
        return expand_synonyms(tokens, self.synonyms)


processor = TextProcessor()
print("索引词项:", processor.index_text("Python是一种通用编程语言"))
print("查询词项:", processor.query_text("Python AI应用"))
```

## 常见误区

1. **认为分词精度越高越好**：搜索引擎更看重召回率，宁可多切也不能漏。搜索引擎模式就是基于这个原则。
2. **索引时不做去停用词**：停用词的 Posting List 极长，占用大量存储但对检索无贡献。
3. **在索引阶段做同义词扩展**：会导致索引体积膨胀，应该在查询阶段扩展。
4. **忽略自定义词典**：通用分词器无法识别专业术语，必须维护领域词典。
5. **过度切分导致精度下降**：搜索引擎模式会把"长江大桥"切成"长江"+"大桥"+"长江大桥"。虽然提高了召回率，但搜索"长江"时会召回只提到"长江大桥"的文档，降低精确率。需要根据业务场景调整切分粒度。
6. **忽略中日韩统一表意文字**：中文（CJK）字符范围是 U+4E00-U+9FFF，但一些生僻字、扩展区字符（如 B 区 U+20000-U+2A6DF）不在这个范围内。分词器需要处理这些边界情况。
7. **混合语言处理不当**："我用 Python3.11 写了一个 AI 应用" 包含中文、英文、数字、版本号。简单的正则切分会把 "Python3.11" 切成 "Python" 和 "11"，丢失版本信息。需要设计专门的混合语言分词规则。

## 工程建议

1. **分词器要保持索引和查询一致**：索引时用什么分词器，查询时就必须用同样的。
2. **停用词表要根据业务调整**：通用停用词表可能不够，需要根据场景增减。
3. **定期更新词典**：语言在变化，新词不断出现，词典需要定期维护。
4. **对分词结果做质量监控**：定期抽样检查分词结果。
5. **用真实查询做分词 Benchmark**：不要只用学术数据集测试分词器。从线上搜索日志中抽样 1000 条查询，人工标注正确的分词结果，定期评估分词器的准确率和召回率。
6. **记录分词审计日志**：对每条查询记录分词结果，便于排查"为什么搜 X 没有召回 Y"的问题。这在搜索引擎的调试阶段尤其重要。
7. **处理特殊字符和 Emoji**：用户输入可能包含 Emoji（"推荐一部电影🎬"）、特殊符号（"C++"、".NET"）、全角半角混用。分词 Pipeline 需要在预处理阶段统一处理这些情况，否则会导致索引和查询不匹配。

### 练习一

**思路**：分别运行正向和反向最大匹配，用启发式规则选择较优结果。

```python
def bidirectional_match(text: str, dictionary: set[str], max_word_len: int = 5) -> list[str]:
    forward = max_forward_match(text, dictionary, max_word_len)
    backward = max_forward_match(text[::-1], dictionary, max_word_len)[::-1]  # 简化实现

    if len(forward) != len(backward):
        return forward if len(forward) < len(backward) else backward

    forward_single = sum(1 for w in forward if len(w) == 1)
    backward_single = sum(1 for w in backward if len(w) == 1)
    if forward_single != backward_single:
        return forward if forward_single < backward_single else backward

    return forward
```

**要点**：双向匹配是启发式方法，不能保证所有情况正确；更好的方案是基于统计模型（HMM、CRF）利用上下文消歧。

### 练习三

**思路**：构建 IDF 后，设置阈值过滤低区分度的词。

**答案**：

```python
import math
from collections import Counter


def build_idf(documents: list[list[str]]) -> dict[str, float]:
    doc_count = len(documents)
    df: Counter = Counter()
    for doc in documents:
        for token in set(doc):
            df[token] += 1
    return {term: math.log(doc_count / (1 + freq)) for term, freq in df.items()}


def auto_filter_stopwords(tokens: list[str], idf: dict[str, float], threshold: float = 2.0) -> tuple[list[str], list[str]]:
    content = []
    stopwords = []
    for token in tokens:
        idf_score = idf.get(token, 5.0)
        if idf_score < threshold:
            stopwords.append(token)
        else:
            content.append(token)
    return content, stopwords


# 测试
documents = [
    ["python", "是", "最好", "的", "编程", "语言"],
    ["java", "是", "企业", "级", "编程", "语言"],
    ["搜索引擎", "需要", "倒排索引"],
    ["python", "开发", "搜索引擎"],
]
idf = build_idf(documents)

text_tokens = ["python", "是", "最好", "的", "编程", "语言"]
content, stopwords = auto_filter_stopwords(text_tokens, idf, threshold=1.5)
print(f"内容词: {content}")
print(f"停用词: {stopwords}")
```

**要点**：
- IDF 阈值的选择影响过滤粒度：阈值越高，过滤越激进
- 建议先用 IDF 自动检测，再人工审核和调整

### 练习四

**思路**：将中文转为拼音，在搜索日志中查找拼音相同的历史查询。

**答案**：

```python
class PinyinCorrector:
    # 简化拼音映射
    CHAR_TO_PINYIN = {
        "到": "dao", "倒": "dao", "道": "dao",
        "排": "pai", "牌": "pai", "派": "pai",
        "索": "suo", "所": "suo", "锁": "suo",
        "引": "yin", "因": "yin", "音": "yin",
    }

    def __init__(self, search_log: dict[str, int]):
        """search_log: {query: search_count}"""
        self.search_log = search_log
        self.pinyin_index: dict[str, list[tuple[str, int]]] = {}
        self._build_index()

    def _build_index(self):
        for query, count in self.search_log.items():
            pinyin = self._to_pinyin(query)
            if pinyin not in self.pinyin_index:
                self.pinyin_index[pinyin] = []
            self.pinyin_index[pinyin].append((query, count))

    def _to_pinyin(self, text: str) -> str:
        return " ".join(self.CHAR_TO_PINYIN.get(c, c) for c in text)

    def suggest(self, query: str, top_k: int = 3) -> list[tuple[str, int]]:
        pinyin = self._to_pinyin(query)
        candidates = self.pinyin_index.get(pinyin, [])
        candidates.sort(key=lambda x: x[1], reverse=True)
        return [(q, c) for q, c in candidates if q != query][:top_k]


# 使用示例
log = {"倒排索引": 1000, "到排索引": 50, "搜索引擎": 2000, "搜引擎": 30}
corrector = PinyinCorrector(log)
print("建议:", corrector.suggest("到排索引"))
# [('倒排索引', 1000)]
```

**要点**：拼音纠错依赖搜索日志的统计，搜索频率越高的候选越可能是正确答案

### 练习五

**思路**：用正则表达式先提取特殊 token（编程语言名、版本号、特殊符号），再对剩余中文部分分词。

**答案**：

```python
import re


def mixed_tokenize(text: str) -> list[str]:
    """处理中英文混排的分词"""
    # 规则优先级：特殊token > 英文+数字 > 中文
    patterns = [
        r'[A-Z][a-z]*\+\+',           # C++
        r'\.[A-Z][a-zA-Z]+',          # .NET
        r'[A-Za-z_][A-Za-z0-9_.]*',   # Python3.11, ChatGPT
        r'[\u4e00-\u9fff]+',          # 中文
    ]
    combined = "|".join(patterns)
    tokens = re.findall(combined, text)

    result = []
    for token in tokens:
        if re.match(r'[\u4e00-\u9fff]+', token):
            # 中文部分用简单规则切分（实际应使用 jieba）
            result.extend(_simple_chinese_split(token))
        else:
            result.append(token)
    return result


def _simple_chinese_split(text: str) -> list[str]:
    """简单的中文切分（演示用）"""
    words = ["和", "的", "是", "在", "用", "写", "了"]
    result = []
    i = 0
    while i < len(text):
        matched = False
        for word in sorted(words, key=len, reverse=True):
            if text[i:i+len(word)] == word:
                result.append(word)
                i += len(word)
                matched = True
                break
        if not matched:
            result.append(text[i])
            i += 1
    return result


# 测试
print(mixed_tokenize("用Python3.11写爬虫"))
# ['用', 'Python3.11', '写', '爬虫']

print(mixed_tokenize("C++和Java的区别"))
# ['C++', '和', 'Java', '的', '区别']
```

**要点**：
- 正则的优先级很重要：特殊 token（C++、.NET）必须在通用英文规则之前匹配
- 生产环境中，中文部分应调用 jieba 而非简单切分
