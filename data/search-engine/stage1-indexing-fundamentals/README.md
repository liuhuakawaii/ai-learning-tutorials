# 阶段一：索引基础

> 理解搜索引擎的骨架——从爬虫到倒排索引，构建检索系统的第一块基石。

## 学习目标

- 理解搜索引擎的整体架构和数据流向
- 掌握倒排索引的原理、实现与压缩技术
- 学会中文分词、停用词过滤、词干提取
- 实现布尔检索模型，支持 AND/OR 查询
- 理解内存索引与磁盘索引的构建策略
- 完成一个可运行的倒排索引系统

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 搜索引擎架构 | 整体架构、爬虫→索引→检索→排序 pipeline |
| 02 | 倒排索引 | 倒排表、posting list、压缩编码 |
| 03 | 分词与词项 | 中文分词算法、停用词、词干提取 |
| 04 | 布尔检索 | 布尔模型、AND/OR 操作、跳表优化 |
| 05 | 索引构建 | 内存/磁盘索引、分布式索引策略 |
| 06 | 阶段实战 | 构建完整的倒排索引系统 |

## 阶段产出

完成本阶段后，你将拥有一个支持中文分词、布尔查询的倒排索引系统，能够对文档集合进行索引和检索。
