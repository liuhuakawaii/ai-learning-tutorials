# 搜索引擎工程

> 从零构建一个生产级搜索引擎，涵盖索引、检索、排序、分布式与真实场景。

## 课程定位

本课程面向有编程基础、希望深入理解搜索引擎内部原理并能独立构建搜索系统的开发者。30 课时，5 个阶段，从倒排索引到 Elasticsearch 集群，从 BM25 到语义检索，从电商搜索到 AI 增强搜索。

**前置要求：**
- 熟悉 Python 或 JavaScript/TypeScript
- 了解基本数据结构（哈希表、树、堆）
- 了解基本概率与线性代数概念

**学完本课程你能做到：**
- 从零实现一个完整的倒排索引和布尔检索系统
- 理解并实现 TF-IDF、BM25、向量空间、语言模型等检索模型
- 使用 Learning-to-Rank 构建排序系统
- 部署和优化 Elasticsearch 集群
- 针对电商、日志、AI 增强等场景设计搜索方案

## 技术栈

- **核心实现**：Python（索引、检索、排序）
- **分布式**：Elasticsearch 8.x
- **向量检索**：FAISS / Milvus
- **机器学习**：LightGBM（LTR）、Sentence-Transformers（语义检索）
- **前端演示**：Vue3 + FastAPI
- **日志场景**：ELK Stack（Elasticsearch + Logstash + Kibana）
