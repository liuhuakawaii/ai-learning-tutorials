# 阶段三：排序与学习

> 从规则到机器学习——让排序模型自动学习最优的相关性函数。

## 学习目标

- 理解搜索引擎排序的基本原理和手动调权方法
- 掌握 Learning-to-Rank 三种范式（pointwise/pairwise/listwise）
- 学会搜索特征工程：查询特征、文档特征、交互特征
- 理解点击模型和 CTR 预估
- 实现基于用户行为的个性化排序
- 构建一个完整的 LTR 排序系统

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 排序基础 | 相关性排序、手动调权规则 |
| 02 | Learning-to-Rank | pointwise/pairwise/listwise |
| 03 | 特征工程 | 查询特征、文档特征、交互特征 |
| 04 | 点击模型 | CTR 预估、位置偏差修正 |
| 05 | 个性化排序 | 用户画像、行为序列建模 |
| 06 | 阶段实战 | LTR 排序系统 |

## 阶段产出

完成本阶段后，你将拥有一个基于 LightGBM 的 Learning-to-Rank 排序系统，支持特征工程和模型训练。
