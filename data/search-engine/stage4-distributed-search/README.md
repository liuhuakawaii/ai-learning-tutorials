# 阶段四：分布式搜索

> 从单机到集群——用 Elasticsearch 构建生产级搜索服务。

## 学习目标

- 理解 Elasticsearch 的集群、分片、副本架构
- 掌握 Query-Then-Fetch 查询执行流程
- 学会索引策略：分词器配置、Mapping 设计
- 实现桶聚合、指标聚合、管道聚合
- 掌握缓存、路由、索引优化等性能调优手段
- 构建一个完整的 ES 搜索服务

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | Elasticsearch 架构 | 集群、分片、副本、节点角色 |
| 02 | 查询执行 | Query/Fetch、scatter/gather |
| 03 | 索引策略 | 分词器、Mapping、索引模板 |
| 04 | 聚合分析 | 桶聚合、指标聚合、管道聚合 |
| 05 | 性能优化 | 缓存、路由、索引优化 |
| 06 | 阶段实战 | ES 搜索服务 |

## 阶段产出

完成本阶段后，你将拥有一个基于 Elasticsearch 的生产级搜索服务，支持中文分词、聚合分析和性能优化。
