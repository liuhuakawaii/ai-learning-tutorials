# 阶段五：真实搜索场景

> 从理论到落地——在电商、日志、AI 增强等真实场景中构建搜索引擎。

## 学习目标

- 设计电商搜索的商品索引、筛选、排序和推荐方案
- 使用 ELK Stack 构建日志搜索和分析系统
- 实现 RAG + 搜索、LLM 重排等 AI 增强搜索
- 掌握 NDCG、MRR 等搜索质量评估指标
- 优化搜索体验：搜索建议、纠错、高亮
- 构建一个完整的搜索引擎项目

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 电商搜索 | 商品搜索、筛选、排序、推荐 |
| 02 | 日志搜索 | ELK Stack、日志分析 |
| 03 | AI 搜索增强 | RAG + 搜索、LLM 重排 |
| 04 | 搜索质量评估 | NDCG、MRR、人工评估 |
| 05 | 搜索体验优化 | 搜索建议、纠错、高亮 |
| 06 | 阶段实战 | 完整搜索引擎 |

## 阶段产出

完成本阶段后，你将拥有一个面向真实场景的搜索引擎，支持电商、日志、AI 增强等多种搜索模式。
