# 阶段二：检索模型

> 从"有没有"到"好不好"——让搜索引擎理解相关性，返回最匹配的结果。

## 学习目标

- 掌握 TF-IDF 和 BM25 的数学原理与实现
- 理解向量空间模型和余弦相似度
- 学会语言模型和查询似然方法
- 实现基于 Embedding 的语义检索
- 掌握混合检索的分数融合策略
- 构建一个多策略检索系统

## 课时安排

| 课时 | 标题 | 核心内容 |
|------|------|----------|
| 01 | TF-IDF 模型 | 词频、逆文档频率、BM25 公式 |
| 02 | 向量空间模型 | 余弦相似度、TF-IDF 向量化 |
| 03 | 语言模型 | 查询似然、Jelinek-Mercer 平滑 |
| 04 | 语义检索 | Embedding、向量数据库、双塔模型 |
| 05 | 混合检索 | BM25 + 向量、RRF 分数融合 |
| 06 | 阶段实战 | 多策略检索系统 |

## 阶段产出

完成本阶段后，你将拥有一个支持 BM25、向量语义、混合检索的多策略检索系统。
