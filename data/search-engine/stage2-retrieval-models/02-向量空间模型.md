# 向量空间模型（VSM）

## 场景引入

上一课我们用 BM25 解决了关键词匹配问题。但 BM25 有一个根本限制：它只能匹配**字面上相同**的词。用户搜索"手机"，无法匹配到包含"智能手机"的文档；搜索"如何减肥"，无法匹配到"瘦身方法"。

向量空间模型（Vector Space Model, VSM）提供了一种更灵活的思路：把每个文档和查询都表示为一个高维向量，然后通过向量之间的距离或相似度来衡量相关性。在这个空间里，语义相近的词会映射到相近的维度，从而实现超越字面匹配的检索。

## 学习目标

1. 理解文档和查询的向量表示方法
2. 掌握余弦相似度的几何直觉与计算
3. 学会用 TF-IDF 构建文档向量
4. 能用 Python + NumPy 实现完整的向量检索系统
5. 理解向量空间模型的优势与局限，为后续稠密向量检索打下基础

## 历史背景：从布尔模型到向量空间

在向量空间模型出现之前，信息检索主要使用**布尔模型**（Boolean Model）：用户用 AND、OR、NOT 组合关键词，系统返回精确匹配的结果。布尔模型的问题是：结果要么全有要么全无，没有"部分匹配"的概念，无法按相关性排序。

1968 年，Gerard Salton 在康奈尔大学 SMART 信息检索系统中首次提出了向量空间模型。SMART 系统的核心创新是：把文本当作数学对象来处理，用向量运算代替字符串匹配。这个思想深刻影响了此后五十年的信息检索研究，直到今天的 BERT 和 GPT 也在用向量表示文本——只不过维度从几万维降到了几百维。

## 文档的向量表示

向量空间模型的核心思想是：假设词汇表有 N 个词，每个文档可以表示为一个 N 维向量，每个维度对应一个词的权重。

最简单的表示是词袋模型（Bag of Words）：向量的每个维度是对应词的出现次数。

```
词汇表: [无线, 蓝牙, 耳机, 音质, 降噪]
文档: "蓝牙耳机降噪" → [0, 1, 1, 0, 1]
```

但词袋模型的问题和 TF-IDF 一样——所有词被同等对待。更好的方式是用 TF-IDF 值作为向量的每个维度：

```python
import numpy as np
from collections import Counter
import math

class Vectorizer:
    def __init__(self):
        self.vocab = {}
        self.idf = {}

    def fit(self, documents: list[list[str]]):
        word_set = set()
        for doc in documents:
            word_set.update(doc)
        self.vocab = {word: idx for idx, word in enumerate(sorted(word_set))}

        num_docs = len(documents)
        df = Counter()
        for doc in documents:
            for word in set(doc):
                df[word] += 1
        self.idf = {w: math.log((num_docs + 1) / (c + 1)) + 1 for w, c in df.items()}
        return self

    def transform(self, documents: list[list[str]]) -> np.ndarray:
        vecs = np.zeros((len(documents), len(self.vocab)))
        for i, doc in enumerate(documents):
            tf = Counter(doc)
            total = len(doc)
            for word, count in tf.items():
                if word in self.vocab:
                    tfidf = (count / total) * self.idf.get(word, 0)
                    vecs[i][self.vocab[word]] = tfidf
        return vecs

    def transform_query(self, query: list[str]) -> np.ndarray:
        vec = np.zeros(len(self.vocab))
        tf = Counter(query)
        total = len(query)
        for word, count in tf.items():
            if word in self.vocab:
                vec[self.vocab[word]] = (count / total) * self.idf.get(word, 0)
        return vec

corpus = [
    ["无线", "蓝牙", "耳机", "降噪", "蓝牙"],
    ["有线", "耳机", "音质", "清晰"],
    ["蓝牙", "音箱", "低音", "震撼"],
    ["降噪", "耳机", "佩戴", "舒适"],
    ["无线", "充电", "手机", "快充"],
]

vec = Vectorizer().fit(corpus)
doc_vectors = vec.transform(corpus)
print(f"文档向量维度: {doc_vectors.shape}")  # (5, 11)
print(f"词汇表: {vec.vocab}")
```

## 余弦相似度

两个向量的相似度怎么衡量？最常用的是**余弦相似度**（Cosine Similarity），它计算两个向量夹角的余弦值：

```
cosine_sim(A, B) = (A · B) / (||A|| × ||B||)
```

余弦相似度的取值范围是 [-1, 1]，在 TF-IDF 向量（非负）的场景下取值 [0, 1]：
- 值为 1：方向完全相同，语义一致
- 值为 0：正交，完全无关
- 值越接近 1，越相似

**为什么用余弦而不是欧氏距离？** 因为余弦相似度只关注**方向**，不受向量长度影响。一个长文档和一个短文档如果讨论同一主题，它们的 TF-IDF 向量方向相同，但长度不同。余弦相似度能正确识别它们的相关性，而欧氏距离会因为长度差异给出较低的相似度。

**几何直觉：** 想象二维平面上两个向量。如果它们指向同一方向（夹角 0°），余弦值为 1；如果垂直（夹角 90°），余弦值为 0。在高维空间中，这个直觉依然成立——余弦相似度衡量的是两个向量在"方向"上的一致性。

```python
def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    dot = np.dot(a, b)
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return dot / (norm_a * norm_b)

query_vec = vec.transform_query(["蓝牙", "耳机"])
for i in range(len(corpus)):
    sim = cosine_similarity(query_vec, doc_vectors[i])
    print(f"文档{i} vs 查询: 余弦相似度={sim:.4f}, 内容={''.join(corpus[i])}")
```

## 其他相似度度量

除了余弦相似度，向量空间模型中还有其他常用的相似度度量方式：

```python
def euclidean_similarity(a: np.ndarray, b: np.ndarray) -> float:
    """欧氏距离转换为相似度（距离越小越相似）"""
    dist = np.linalg.norm(a - b)
    return 1.0 / (1.0 + dist)

def dot_product_similarity(a: np.ndarray, b: np.ndarray) -> float:
    """点积相似度（向量已归一化时等价于余弦相似度）"""
    return float(np.dot(a, b))

def jaccard_similarity(set_a: set, set_b: set) -> float:
    """Jaccard 相似度（基于集合，忽略权重）"""
    intersection = len(set_a & set_b)
    union = len(set_a | set_b)
    return intersection / union if union > 0 else 0.0

# 对比三种相似度
query = vec.transform_query(["蓝牙", "耳机"])
for i in range(len(corpus)):
    cos_sim = cosine_similarity(query, doc_vectors[i])
    euc_sim = euclidean_similarity(query, doc_vectors[i])
    dot_sim = dot_product_similarity(query, doc_vectors[i])
    print(f"文档{i}: cosine={cos_sim:.4f}, euclidean={euc_sim:.4f}, dot={dot_sim:.4f}")
```

| 度量方式 | 取值范围 | 是否受向量长度影响 | 适用场景 |
|----------|----------|-------------------|----------|
| 余弦相似度 | [-1, 1] | 否 | TF-IDF 文本检索（首选） |
| 欧氏距离 | [0, +∞) | 是 | 稠密向量（Embedding） |
| 点积 | (-∞, +∞) | 是 | 已归一化的向量 |
| Jaccard | [0, 1] | 不适用 | 集合比较，忽略权重 |

## 完整的向量检索系统

将上面的组件组合起来，构建一个完整的向量检索系统：

```python
class VectorSearchEngine:
    def __init__(self):
        self.vectorizer = Vectorizer()
        self.doc_vectors = None
        self.raw_docs = []

    def index(self, documents: list[str]):
        self.raw_docs = documents
        tokenized = [list(doc) for doc in documents]
        self.vectorizer.fit(tokenized)
        self.doc_vectors = self.vectorizer.transform(tokenized)
        print(f"索引完成: {len(documents)} 个文档, {len(self.vectorizer.vocab)} 个词")

    def search(self, query: str, top_k: int = 5) -> list[tuple[str, float]]:
        query_tokens = list(query)
        query_vec = self.vectorizer.transform_query(query_tokens)
        scores = []
        for i in range(len(self.raw_docs)):
            sim = cosine_similarity(query_vec, self.doc_vectors[i])
            scores.append((self.raw_docs[i], sim))
        scores.sort(key=lambda x: -x[1])
        return scores[:top_k]

docs = [
    "无线蓝牙耳机降噪效果好",
    "有线耳机音质清晰自然",
    "蓝牙音箱低音震撼有力",
    "降噪耳机佩戴舒适轻便",
    "无线充电手机快充方便",
    "蓝牙耳机续航时间长",
]

engine = VectorSearchEngine()
engine.index(docs)

results = engine.search("蓝牙耳机")
for doc, score in results:
    print(f"[{score:.4f}] {doc}")
```

## 向量空间模型的局限

VSM 虽然比 BM25 灵活，但仍有明显局限：

1. **高维稀疏问题**：词汇表动辄几万到几十万维，每个文档向量绝大部分维度为零，存储和计算效率低。

2. **词袋假设的缺陷**：忽略了词序信息。"狗咬人"和"人咬狗"的向量表示完全相同。

3. **语义鸿沟**：虽然 TF-IDF 向量能部分捕捉词的重要性，但"手机"和"智能手机"的向量仍然正交——因为它们是不同的词。

4. **无法处理同义词和多义词**：同义词在不同维度上，无法关联；多义词在同一维度上，无法消歧。

这些局限推动了后续语义检索技术的发展（将在第 4 课讲解），但 VSM 作为基础范式，其核心思想——**将文本映射到向量空间，用向量运算代替字符串匹配**——贯穿了整个现代检索系统。

## 余弦相似度的高效计算

当文档数量很大时，逐一计算余弦相似度太慢。利用矩阵运算可以一次性计算查询与所有文档的相似度：

```python
def batch_cosine_similarity(query_vec: np.ndarray, doc_matrix: np.ndarray) -> np.ndarray:
    """一次性计算查询向量与所有文档向量的余弦相似度"""
    query_norm = np.linalg.norm(query_vec)
    if query_norm == 0:
        return np.zeros(doc_matrix.shape[0])
    doc_norms = np.linalg.norm(doc_matrix, axis=1)
    doc_norms[doc_norms == 0] = 1  # 避免除零
    similarities = doc_matrix.dot(query_vec) / (doc_norms * query_norm)
    return similarities

scores = batch_cosine_similarity(query_vec, doc_vectors)
top_indices = np.argsort(-scores)[:3]
for idx in top_indices:
    print(f"文档{idx}: 相似度={scores[idx]:.4f}")
```

向量化的矩阵乘法比逐行循环快 10~100 倍，在百万级文档上差距更明显。

**性能对比实验：**

```python
import time

def benchmark_batch_vs_loop(query_vec, doc_matrix, iterations=1000):
    """对比批量计算和逐行循环的性能差异"""
    start = time.time()
    for _ in range(iterations):
        _ = batch_cosine_similarity(query_vec, doc_matrix)
    batch_time = time.time() - start

    start = time.time()
    for _ in range(iterations):
        for i in range(doc_matrix.shape[0]):
            _ = cosine_similarity(query_vec, doc_matrix[i])
    loop_time = time.time() - start

    print(f"批量计算: {batch_time:.3f}s")
    print(f"逐行循环: {loop_time:.3f}s")
    print(f"加速比: {loop_time / batch_time:.1f}x")
```

## 稀疏矩阵优化

在实际应用中，TF-IDF 矩阵通常是高度稀疏的（95% 以上的元素为零）。使用稀疏矩阵可以大幅降低内存占用：

```python
from scipy.sparse import csr_matrix, lil_matrix

def build_sparse_tfidf(documents: list[list[str]], vectorizer: 'Vectorizer') -> csr_matrix:
    """构建稀疏 TF-IDF 矩阵"""
    n_docs = len(documents)
    n_features = len(vectorizer.vocab)
    lil = lil_matrix((n_docs, n_features))

    for i, doc in enumerate(documents):
        tf = Counter(doc)
        total = len(doc)
        for word, count in tf.items():
            if word in vectorizer.vocab:
                col_idx = vectorizer.vocab[word]
                tfidf_val = (count / total) * vectorizer.idf.get(word, 0)
                lil[i, col_idx] = tfidf_val

    return lil.tocsr()

sparse_docs = build_sparse_tfidf(corpus, vec)
print(f"稀疏矩阵形状: {sparse_docs.shape}")
print(f"非零元素: {sparse_docs.nnz}")
print(f"稀疏率: {1 - sparse_docs.nnz / (sparse_docs.shape[0] * sparse_docs.shape[1]):.2%}")

# 稀疏矩阵的余弦相似度计算
query_sparse = csr_matrix(query_vec.reshape(1, -1))
sparse_scores = sparse_docs.dot(query_sparse.T).toarray().flatten()
doc_norms = np.sqrt(sparse_docs.multiply(sparse_docs).sum(axis=1)).A1
query_norm = np.linalg.norm(query_vec)
sparse_cosine = sparse_scores / (doc_norms * query_norm)
print(f"稀疏计算结果与稠密一致: {np.allclose(scores, sparse_cosine, atol=1e-6)}")
```

## 常见误区

1. **混淆余弦相似度和欧氏距离**：余弦相似度衡量方向，欧氏距离衡量绝对距离。TF-IDF 向量推荐用余弦相似度。

2. **忘记归一化 TF**：不归一化会导致长文档向量长度偏大，虽然余弦相似度不受长度影响，但向量本身的质量会下降。

3. **认为向量检索必须用深度学习**：TF-IDF 向量 + 余弦相似度在很多场景下效果不错，且计算成本极低，不应跳过。

4. **忽略零向量问题**：如果查询词全不在词汇表中，查询向量为零向量，余弦相似度无意义。需要做防御性检查。

5. **把 VSM 和 Embedding 混为一谈**：VSM 是稀疏高维表示（几万维），Embedding 是稠密低维表示（几百维），两者有本质区别。

6. **忽略词汇表大小的影响**：词汇表越大，向量维度越高，计算和存储成本越高。实践中通常需要做特征选择（如只保留 Top-K 高频词或低 IDF 阈值过滤）。

7. **在小语料库上期望 VSM 优于 BM25**：小语料库中 TF-IDF 的 IDF 估计不准确，VSM 的优势无法体现。VSM 更适合大规模语料。

## 工程建议

1. **先用 VSM 做基线**：在任何检索项目中，先用 TF-IDF + 余弦相似度建立基线（baseline），再尝试更复杂的模型。

2. **用稀疏矩阵存储**：Scipy 的 `csr_matrix` 可以高效存储高维稀疏向量，内存占用大幅降低。

3. **预计算并归一化文档向量**：查询时只需计算一次查询向量的归一化，文档向量提前归一化存储。

4. **结合倒排索引做预过滤**：不必对所有文档计算向量相似度，先用倒排索引缩小候选集，再用向量相似度精排。

5. **维度选择**：如果词汇表过大（超过 10 万），可以只保留 TF-IDF 最高的 Top-K 词，降低维度。

6. **增量索引策略**：新文档加入时，词汇表可能扩展。需要设计增量更新机制：新词加入词汇表，已有文档的向量需要补零对齐。

7. **混合检索**：在实际系统中，VSM 常与 BM25 混合使用。BM25 擅长精确关键词匹配，VSM 擅长部分匹配。混合分数 = α × BM25 + (1-α) × VSM_Cosine，α 通过评估确定。

## 小结

- 向量空间模型将文档和查询表示为高维向量，用向量相似度衡量相关性。
- TF-IDF 向量是经典的文档表示方法，每个维度对应一个词的 TF-IDF 权重。
- 余弦相似度衡量向量方向的一致性，不受向量长度影响，是 VSM 的标准相似度度量。
- VSM 的局限在于高维稀疏和无法捕捉语义，这推动了后续稠密向量检索的发展。
- 在工程实践中，稀疏矩阵存储和批量向量计算是 VSM 性能优化的关键手段。

## 参考答案

### 练习一

**思路**：欧氏距离越小越相似，需要取倒数或负数来反转排序方向。归一化向量后，余弦相似度和欧氏距离有一一对应关系。

**答案**：
```python
class VectorSearchEngineV2(VectorSearchEngine):
    def search(self, query: str, top_k: int = 5, method: str = "cosine") -> list:
        query_tokens = list(query)
        query_vec = self.vectorizer.transform_query(query_tokens)
        scores = []
        for i in range(len(self.raw_docs)):
            if method == "cosine":
                sim = cosine_similarity(query_vec, self.doc_vectors[i])
            elif method == "euclidean":
                dist = np.linalg.norm(query_vec - self.doc_vectors[i])
                sim = 1 / (1 + dist)  # 转换为相似度
            scores.append((self.raw_docs[i], sim))
        scores.sort(key=lambda x: -x[1])
        return scores[:top_k]
```

**要点**：
- 欧氏距离通过 `1/(1+d)` 转换为 [0,1] 的相似度
- 在归一化后的向量上，`||a-b||² = 2(1 - cos_sim)`，两者等价
- 未归一化时，欧氏距离受向量长度影响，结果可能不同

### 练习二

**思路**：用 scipy.sparse.csr_matrix 存储，利用稀疏矩阵乘法计算相似度。

**答案**：
```python
from scipy.sparse import csr_matrix
import sys

def to_sparse(doc_vectors: np.ndarray) -> csr_matrix:
    return csr_matrix(doc_vectors)

sparse_vecs = to_sparse(doc_vectors)
dense_size = doc_vectors.nbytes
sparse_size = sparse_vecs.data.nbytes + sparse_vecs.indices.nbytes + sparse_vecs.indptr.nbytes
print(f"稠密矩阵: {dense_size / 1024:.1f} KB")
print(f"稀疏矩阵: {sparse_size / 1024:.1f} KB")
print(f"压缩比: {dense_size / sparse_size:.1f}x")

sparse_scores = sparse_vecs.dot(query_vec)
print(f"稀疏计算结果与稠密一致: {np.allclose(scores, sparse_scores)}")
```

**要点**：
- TF-IDF 矩阵通常 95% 以上元素为零，稀疏矩阵压缩比可达 10~50 倍
- csr_matrix 的 dot 方法自动利用稀疏性加速矩阵乘法
- 文档数量越大，稀疏存储的优势越明显

### 练习四

**思路**：三种裁剪策略从不同角度减少词汇表大小。策略 1 保留最具区分力的词；策略 2 移除"万能词"；策略 3 移除"罕见词"。

**答案**：
```python
class TrimmedVectorizer(Vectorizer):
    def fit_with_trimming(self, documents, strategy="top_k", top_k=1000,
                          max_doc_ratio=0.8, min_doc_count=2):
        self.fit(documents)
        n_docs = len(documents)
        df = Counter()
        for doc in documents:
            for word in set(doc):
                df[word] += 1

        if strategy == "top_k":
            word_tfidf_max = {}
            tf_results = compute_tf(documents)
            for tf in tf_results:
                for word, vals in tf.items():
                    score = vals["normalized"] * self.idf.get(word, 0)
                    word_tfidf_max[word] = max(word_tfidf_max.get(word, 0), score)
            kept = sorted(word_tfidf_max.items(), key=lambda x: -x[1])[:top_k]
            keep_set = {w for w, _ in kept}
        elif strategy == "max_df":
            keep_set = {w for w, c in df.items() if c / n_docs <= max_doc_ratio}
        elif strategy == "min_df":
            keep_set = {w for w, c in df.items() if c >= min_doc_count}
        else:
            keep_set = set(self.vocab.keys())

        old_size = len(self.vocab)
        self.vocab = {w: i for i, w in enumerate(sorted(keep_set))}
        self.idf = {w: v for w, v in self.idf.items() if w in keep_set}
        print(f"策略={strategy}: {old_size} -> {len(self.vocab)} 词")
        return self
```

### 练习五

**思路**：分别实现 BM25 和 VSM 检索，然后对分数做加权组合。关键在于两种分数的量纲不同，需要归一化后再组合。

**答案**：
```python
class HybridSearchEngine:
    def __init__(self, k1=1.5, b=0.75):
        self.bm25 = None
        self.vsm = VectorSearchEngine()
        self.raw_docs = []

    def index(self, documents: list[str]):
        self.raw_docs = documents
        tokenized = [list(doc) for doc in documents]
        self.bm25 = BM25(tokenized, k1=1.5, b=0.75)
        self.vsm.index(documents)

    def _normalize(self, scores: list[float]) -> list[float]:
        """Min-Max 归一化到 [0, 1]"""
        min_s, max_s = min(scores), max(scores)
        if max_s == min_s:
            return [0.5] * len(scores)
        return [(s - min_s) / (max_s - min_s) for s in scores]

    def search(self, query: str, alpha: float = 0.5, top_k: int = 5):
        query_tokens = list(query)
        n = len(self.raw_docs)

        bm25_scores = [self.bm25._score_doc(query_tokens, i) for i in range(n)]
        query_vec = self.vsm.vectorizer.transform_query(query_tokens)
        vsm_scores = [cosine_similarity(query_vec, self.vsm.doc_vectors[i]) for i in range(n)]

        bm25_norm = self._normalize(bm25_scores)
        vsm_norm = self._normalize(vsm_scores)

        hybrid = [alpha * bm25_norm[i] + (1 - alpha) * vsm_norm[i] for i in range(n)]
        ranked = sorted(range(n), key=lambda i: -hybrid[i])[:top_k]
        return [(self.raw_docs[i], round(hybrid[i], 4)) for i in ranked]
```

**要点**：
