# 毕业项目：搜索引擎工程

## 项目概述

构建一个完整的搜索引擎系统，涵盖从索引构建到搜索服务的全流程。项目分为 5 个阶段，每个阶段对应课程的一个阶段，最终形成一个支持中文分词、多策略检索、LTR 排序、分布式部署的生产级搜索引擎。

## 技术栈

- **核心语言**：Python 3.10+
- **搜索引擎**：Elasticsearch 8.x
- **向量检索**：FAISS
- **机器学习**：LightGBM、sentence-transformers
- **Web 框架**：FastAPI
- **前端**：Vue3（可选）

## 阶段任务

### 阶段一：索引基础（对应 Stage 1）

**目标**：实现倒排索引和分词系统

**任务清单**：
- [ ] 实现中文分词器（基于 jieba，支持自定义词典）
- [ ] 实现倒排索引（支持增删改查）
- [ ] 实现布尔检索（AND/OR/NOT）
- [ ] 实现索引持久化（JSON/二进制格式）
- [ ] 编写单元测试

**验收标准**：
- 分词器对中文文本的分词准确率 ≥ 90%
- 倒排索引支持 10 万级文档
- 布尔查询响应时间 < 100ms
- 所有单元测试通过

### 阶段二：检索模型（对应 Stage 2）

**目标**：实现多策略检索系统

**任务清单**：
- [ ] 实现 BM25 检索
- [ ] 实现向量语义检索（FAISS）
- [ ] 实现混合检索（BM25 + 向量 + RRF）
- [ ] 实现检索结果对比实验
- [ ] 编写评估脚本

**验收标准**：
- BM25 检索 NDCG@10 ≥ 0.4
- 向量检索 NDCG@10 ≥ 0.35
- 混合检索 NDCG@10 ≥ 0.45
- 检索响应时间 < 200ms

### 阶段三：排序与学习（对应 Stage 3）

**目标**：实现 Learning-to-Rank 排序系统

**任务清单**：
- [ ] 实现特征提取（查询特征、文档特征、交互特征）
- [ ] 实现 LambdaMART 排序模型
- [ ] 实现点击模型和位置偏差修正
- [ ] 实现个性化排序
- [ ] 编写模型训练和评估脚本

**验收标准**：
- LTR 模型 NDCG@10 ≥ 0.5
- 特征维度 ≥ 20
- 模型训练时间 < 10 分钟
- 排序响应时间 < 50ms

### 阶段四：分布式搜索（对应 Stage 4）

**目标**：部署 Elasticsearch 集群并实现搜索服务

**任务清单**：
- [ ] 部署 ES 集群（单节点或多节点）
- [ ] 设计索引 Mapping
- [ ] 实现中文分词配置（IK 分词器）
- [ ] 实现聚合分析
- [ ] 优化查询性能

**验收标准**：
- ES 集群健康状态为 green
- 索引 10 万级文档
- 搜索响应时间 < 100ms
- 聚合查询响应时间 < 500ms

### 阶段五：真实搜索场景（对应 Stage 5）

**目标**：构建完整的搜索引擎服务

**任务清单**：
- [ ] 实现 FastAPI 搜索服务
- [ ] 实现搜索建议和纠错
- [ ] 实现搜索高亮
- [ ] 实现 AI 增强搜索（RAG + LLM 重排）
- [ ] 实现搜索质量评估
- [ ] 编写完整的 API 文档

**验收标准**：
- 搜索服务支持 100 QPS
- 搜索建议响应时间 < 50ms
- AI 增强搜索准确率提升 ≥ 10%
- API 文档完整且可访问

## 环境配置

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动 Elasticsearch（需要本地安装或 Docker）
docker run -d --name es -p 9200:9200 -e "discovery.type=single-node" elasticsearch:8.11.0

# 启动搜索服务
python -m uvicorn api.main:app --reload --port 8000
```

## 评估方式

1. **代码质量**：通过验证脚本检查代码结构和功能完整性
2. **阶段报告**：每个阶段完成后填写对应的报告文件
3. **性能测试**：运行性能测试脚本，验证响应时间和吞吐量
4. **功能演示**：通过 API 调用演示搜索功能
