## 一、为什么需要审计日志

### 1.1 审计日志的作用

```
安全审计：
  → 追踪谁在什么时候做了什么
  → 发现异常操作
  → 事故调查和取证

合规要求：
  → 满足法规要求（如 GDPR）
  → 提供操作证明
  → 数据变更追踪

问题排查：
  → 定位问题原因
  → 回溯操作历史
  → 恢复误操作
```

### 1.2 生活类比

```
银行交易记录：
  时间        操作        金额      余额
  2024-01-15  工资入账    +5000     15000
  2024-01-16  转账        -2000     13000
  2024-01-17  消费        -500      12500

审计日志：
  时间        用户        操作        目标        详情
  2024-01-15  张三        创建项目    项目A       {name: "项目A"}
  2024-01-16  李四        删除成员    王五        {role: "MEMBER"}
```

## 二、数据模型

### 2.1 审计日志表

```prisma
model AuditLog {
  id        String   @id @default(cuid())
  action    String   // 操作类型
  resource  String   // 资源类型
  resourceId String? // 资源 ID
  details   Json?    // 操作详情
  ipAddress String?  // IP 地址
  userAgent String?  // 浏览器标识
  createdAt DateTime @default(now())

  // 操作者
  user   User   @relation(fields: [userId], references: [id])
  userId String

  // 所属团队（可选）
  team   Team?  @relation(fields: [teamId], references: [id])
  teamId String?

  @@index([userId])
  @@index([teamId])
  @@index([action])
  @@index([createdAt])
}
```

## 三、记录审计日志

### 3.1 核心记录函数

```tsx
// lib/audit.ts
import { prisma } from './prisma'
import { headers } from 'next/headers'

interface LogOptions {
  userId: string
  action: AuditAction
  resource: string
  resourceId?: string
  details?: Record<string, any>
  teamId?: string
}

export async function logAudit({
  userId,
  action,
  resource,
  resourceId,
  details,
  teamId,
}: LogOptions) {
  const headersList = await headers()

  await prisma.auditLog.create({
    data: {
      userId,
      action,
      resource,
      resourceId,
      details: details || undefined,
      teamId,
      ipAddress: headersList.get('x-forwarded-for') || headersList.get('x-real-ip'),
      userAgent: headersList.get('user-agent'),
    }
  })
}
```

## 四、审计日志查询

### 4.1 查询函数

```tsx
// lib/audit.ts
export async function getAuditLogs({
  teamId,
  userId,
  action,
  startDate,
  endDate,
  page = 1,
  pageSize = 50,
}: {
  teamId?: string
  userId?: string
  action?: string
  startDate?: Date
  endDate?: Date
  page?: number
  pageSize?: number
}) {
  const where = {
    AND: [
      teamId ? { teamId } : {},
      userId ? { userId } : {},
      action ? { action } : {},
      startDate || endDate ? {
        createdAt: {
          ...(startDate ? { gte: startDate } : {}),
          ...(endDate ? { lte: endDate } : {}),
        }
      } : {},
    ]
  }

  const [logs, total] = await Promise.all([
    prisma.auditLog.findMany({
      where,
      include: {
        user: {
          select: { id: true, name: true, email: true }
        }
      },
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * pageSize,
      take: pageSize,
    }),
    prisma.auditLog.count({ where }),
  ])

  return {
    logs,
    total,
    page,
    pageSize,
    totalPages: Math.ceil(total / pageSize),
  }
}
```

## 五、审计日志界面

### 5.1 团队审计日志页面

```tsx
// app/teams/[teamId]/settings/audit/page.tsx
import { getAuditLogs } from '@/lib/audit'
import { requireTeamRole } from '@/lib/permissions'
import { AuditLogList } from './AuditLogList'
import { AuditLogFilters } from './AuditLogFilters'

export default async function AuditPage({
  params,
  searchParams
}: {
  params: Promise<{ teamId: string }>
  searchParams: Promise<{ action?: string; page?: string }>
}) {
  const { teamId } = await params
  const { action, page: pageStr } = await searchParams

  await requireTeamRole(teamId, 'ADMIN')

  const page = Math.max(1, parseInt(pageStr || '1'))
  const { logs, totalPages } = await getAuditLogs({
    teamId,
    action,
    page,
  })

  return (
    <div>
      <h2 className="text-2xl font-bold mb-6">审计日志</h2>

      <AuditLogFilters teamId={teamId} />

      <AuditLogList logs={logs} totalPages={totalPages} currentPage={page} />
    </div>
  )
}
```

### 5.2 日志列表组件

// app/teams/[teamId]/settings/audit/AuditLogList.tsx
import { Pagination } from '@/components/Pagination'

const actionLabels: Record<string, string> = {

  MEMBER_INVITE: '邀请成员',

  details: any
  ipAddress: string | null
  createdAt: Date
  user: {
    id: string
    name: string | null
    email: string
  }

export function AuditLogList({
  logs,
  totalPages,
  currentPage

  logs: AuditLog[]
  totalPages: number

  return (

              <th className="text-left p-4">时间</th>

              <th className="text-left p-4">详情</th>

                    <pre className="whitespace-pre-wrap">
                      {JSON.stringify(log.details, null, 2)}

### 5.3 筛选组件

```tsx
// app/teams/[teamId]/settings/audit/AuditLogFilters.tsx
'use client'

import { useRouter, useSearchParams } from 'next/navigation'

export function AuditLogFilters({ teamId }: { teamId: string }) {
  const router = useRouter()
  const searchParams = useSearchParams()

  function handleFilterChange(key: string, value: string) {
    const params = new URLSearchParams(searchParams.toString())

    if (value) {
      params.set(key, value)
    } else {
      params.delete(key)
    }

    params.delete('page')
    router.push(`?${params.toString()}`)
  }

  return (
    <div className="flex gap-4 mb-6">
      <select
        value={searchParams.get('action') || ''}
        onChange={e => handleFilterChange('action', e.target.value)}
        className="px-3 py-2 border rounded"
      >
        <option value="">所有操作</option>
        <option value="TEAM_CREATE">创建团队</option>
        <option value="MEMBER_INVITE">邀请成员</option>
        <option value="MEMBER_REMOVE">移除成员</option>
        <option value="PROJECT_CREATE">创建项目</option>
        <option value="PROJECT_DELETE">删除项目</option>
      </select>
    </div>
  )
}

## 九、小结

```
本课核心要点：

1. 审计日志记录：谁、什么时候、做了什么、对谁
2. 操作类型要分类清晰
3. 记录 IP 地址和浏览器标识
4. 支持按时间、操作类型、用户筛选
5. 审计日志只能追加，不能修改或删除
