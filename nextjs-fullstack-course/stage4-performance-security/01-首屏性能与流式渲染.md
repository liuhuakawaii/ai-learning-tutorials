## 一、Core Web Vitals

### 1.1 三个核心指标

```
LCP（Largest Contentful Paint）最大内容绘制
  → 衡量加载性能
  → 目标：< 2.5 秒

FID（First Input Delay）首次输入延迟
  → 衡量交互性
  → 目标：< 100 毫秒

CLS（Cumulative Layout Shift）累积布局偏移
  → 衡量视觉稳定性
  → 目标：< 0.1
```

### 1.2 生活类比

```
LCP = 餐厅上菜速度
  点单后多久能看到主菜

FID = 服务员响应速度
  举手后多久服务员过来

CLS = 菜单会不会突然变化
  点菜时菜单会不会突然换位置
```

## 二、流式渲染

### 2.1 什么是流式渲染

```
传统渲染：
  服务器等待所有数据准备好
  → 生成完整 HTML
  → 一次性发送给浏览器
  → 用户等待时间长

流式渲染：
  服务器先发送页面框架
  → 数据准备好后逐块发送
  → 浏览器逐步显示内容
  → 用户更快看到内容
```

### 2.2 Next.js 中的流式渲染

```tsx
// app/dashboard/page.tsx
import { Suspense } from 'react'

// 慢组件
async function SlowStats() {
  const stats = await fetchStats() // 耗时 2 秒
  return <div>{/* 渲染统计 */}</div>
}

// 快组件
async function QuickHeader() {
  return <h1>Dashboard</h1>
}

export default function DashboardPage() {
  return (
    <div>
      <QuickHeader />
      <Suspense fallback={<StatsSkeleton />}>
        <SlowStats />
      </Suspense>
    </div>
  )
}
```

### 2.3 流式渲染的过程

```
时间线：

0ms    服务器开始渲染
       → 发送 <html><body><h1>Dashboard</h1>

100ms  → 发送 <div>骨架屏</div>

2000ms → 数据准备好
       → 发送真正的统计内容
       → 浏览器替换骨架屏
```

## 三、使用 Suspense

### 3.1 基础用法

```tsx
import { Suspense } from 'react'

export default function Page() {
  return (
    <div>
      <h1>页面标题</h1>

      <Suspense fallback={<div>加载中...</div>}>
        <AsyncComponent />
      </Suspense>
    </div>
  )
}

async function AsyncComponent() {
  const data = await fetchData()
  return <div>{data}</div>
}
```

### 3.2 多个 Suspense

```tsx
export default function DashboardPage() {
  return (
    <div className="grid grid-cols-2 gap-4">
      <Suspense fallback={<CardSkeleton />}>
        <StatsCard />
      </Suspense>

      <Suspense fallback={<CardSkeleton />}>
        <RecentActivity />
      </Suspense>

      <Suspense fallback={<TableSkeleton />}>
        <ProjectsTable />
      </Suspense>

      <Suspense fallback={<ListSkeleton />}>
        <TeamMembers />
      </Suspense>
    </div>
  )
}
```

### 3.3 loading.tsx 等价于 Suspense

```tsx
// app/dashboard/loading.tsx
export default function Loading() {
  return <div>加载中...</div>
}

// 等价于：
// app/dashboard/layout.tsx
export default function Layout({ children }) {
  return (
    <Suspense fallback={<Loading />}>
      {children}
    </Suspense>
  )
}
```

## 四、优化首屏

### 4.1 减少 JavaScript

```tsx
// ❌ 整个页面都是客户端组件
'use client'

export default function Page() {
  const [data, setData] = useState(null)

  useEffect(() => {
    fetch('/api/data').then(r => r.json()).then(setData)
  }, [])

  return <div>{/* ... */}</div>
}

// ✅ 服务端组件，零 JS
export default async function Page() {
  const data = await db.query('SELECT * FROM posts')
  return <div>{/* ... */}</div>
}
```

### 4.2 动态导入

```tsx
// 不需要首屏加载的组件
import dynamic from 'next/dynamic'

const HeavyChart = dynamic(() => import('./HeavyChart'), {
  loading: () => <ChartSkeleton />,
  ssr: false, // 不在服务端渲染
})

export default function Page() {
  return (
    <div>
      <h1>数据图表</h1>
      <HeavyChart />
    </div>
  )
}
```

### 4.3 避免客户端-服务端瀑布流

```tsx
// ❌ 瀑布流
export default function Page() {
  return (
    <Suspense fallback={<SkeletonA />}>
      <ComponentA />
    </Suspense>
  )
}

async function ComponentA() {
  const data = await fetchA()
  return (
    <Suspense fallback={<SkeletonB />}>
      <ComponentB parentId={data.id} />
    </Suspense>
  )
}

// ✅ 并行加载
export default function Page() {
  return (
    <>
      <Suspense fallback={<SkeletonA />}>
        <ComponentA />
      </Suspense>
      <Suspense fallback={<SkeletonB />}>
        <ComponentB />
      </Suspense>
    </>
  )
}
```

## 五、骨架屏最佳实践

### 5.1 匹配真实布局

```tsx
// ❌ 不好的骨架屏
function BadSkeleton() {
  return <div className="animate-pulse">加载中...</div>
}

// ✅ 好的骨架屏
function GoodSkeleton() {
  return (
    <div className="animate-pulse">
      {/* 模拟标题 */}
      <div className="h-8 bg-gray-200 rounded w-1/3 mb-4"></div>

      {/* 模拟卡片 */}
      <div className="grid grid-cols-3 gap-4 mb-6">
        {[1, 2, 3].map(i => (
          <div key={i} className="h-24 bg-gray-200 rounded"></div>
        ))}
      </div>

      {/* 模拟列表 */}
      <div className="space-y-3">
        {[1, 2, 3, 4].map(i => (
          <div key={i} className="h-12 bg-gray-200 rounded"></div>
        ))}
      </div>
    </div>
  )
}
```

### 5.2 使用真实颜色

```tsx
function Skeleton({ className }: { className?: string }) {
  return (
    <div
      className={`bg-gray-200 rounded animate-pulse ${className}`}
    />
  )
}
```
