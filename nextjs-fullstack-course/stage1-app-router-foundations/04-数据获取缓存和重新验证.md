## 一、Server Components 中的数据获取

### 1.1 直接 async/await

在 Server Component 中，你可以直接使用 async/await 获取数据：

```tsx
// app/posts/page.tsx
export default async function PostsPage() {
  // 直接在组件中获取数据
  const posts = await db.post.findMany({
    orderBy: { createdAt: 'desc' }
  })

  return (
    <ul>
      {posts.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```

### 1.2 使用 fetch

```tsx
export default async function WeatherPage() {
  const res = await fetch('https://api.weather.com/today')
  const data = await res.json()

  return <div>今天温度: {data.temperature}°C</div>
}
```

### 1.3 并行数据获取

```tsx
// ❌ 串行获取（慢）
export default async function DashboardPage() {
  const user = await getUser()      // 等待 100ms
  const posts = await getPosts()    // 等待 200ms
  const stats = await getStats()    // 等待 150ms
  // 总耗时: 450ms
}

// ✅ 并行获取（快）
export default async function DashboardPage() {
  const [user, posts, stats] = await Promise.all([
    getUser(),    // 同时开始
    getPosts(),   // 同时开始
    getStats()    // 同时开始
  ])
  // 总耗时: 200ms（取最长的那个）
}
```

### 1.4 请求去重

Next.js 会自动对相同请求进行去重：

```tsx
// 这两个组件都请求同一个 API
async function UserHeader() {
  const user = await fetch('/api/user')  // 请求 A
  return <h1>{user.name}</h1>
}

async function UserAvatar() {
  const user = await fetch('/api/user')  // 请求 A（不会重复请求）
  return <img src={user.avatar} />
}

export default function Page() {
  return (
    <div>
      <UserHeader />
      <UserAvatar />
    </div>
  )
}
```

## 二、缓存机制

### 2.1 两层缓存

```
请求流程：

浏览器请求 /dashboard
  ↓
Next.js 检查第一层缓存：数据缓存（Data Cache）
  ↓ 命中 → 直接返回缓存的数据
  ↓ 未命中
执行 Server Component
  ↓
组件内的 fetch 请求
  ↓
Next.js 检查第二层缓存：完整路由缓存（Full Route Cache）
  ↓ 命中 → 返回缓存的 HTML
  ↓ 未命中
执行数据获取 → 渲染 HTML → 缓存 → 返回
```

### 2.2 fetch 缓存策略

默认情况下，`fetch` 请求会被缓存：

```tsx
// 默认会被缓存（STATIC）
const res = await fetch('https://api.example.com/data')

// 明确不缓存（DYNAMIC）
const res = await fetch('https://api.example.com/data', {
  cache: 'no-store'
})

// 设置缓存过期时间
const res = await fetch('https://api.example.com/data', {
  next: { revalidate: 60 }  // 60 秒后可以重新验证
})
```

### 2.3 三种缓存策略

```
策略              行为                          使用场景
──────────────────────────────────────────────────────────
force-cache      始终使用缓存                   静态数据，几乎不变
(default)        构建时获取一次，之后用缓存
no-store         每次请求都重新获取             用户特定数据、实时数据
revalidate: N    缓存 N 秒，过期后重新验证      偶尔变化的数据
```

## 三、重新验证

### 3.1 基于时间的重新验证（Time-based）

```tsx
// 每 60 秒可以重新验证一次
export const revalidate = 60

export default async function NewsPage() {
  const news = await fetch('https://api.news.com/latest', {
    next: { revalidate: 60 }
  })

  return <NewsList items={news} />
}
```

流程：

```
0:00 用户访问 → 获取最新数据 → 缓存
0:30 用户访问 → 返回缓存
1:00 用户访问 → 返回缓存（但标记为 stale）
1:01 用户访问 → 后台重新获取数据 → 更新缓存 → 返回新数据
```

### 3.2 基于标签的重新验证（Tag-based）

用标签标记缓存，然后按标签清除：

```tsx
// 获取数据时标记标签
async function getPosts() {
  return fetch('https://api.example.com/posts', {
    next: { tags: ['posts'] }
  })
}

// 在 Server Action 中按标签清除缓存
'use server'

import { revalidateTag } from 'next/cache'

export async function createPost(data) {
  await db.post.create({ data })
  revalidateTag('posts')  // 清除所有标记为 'posts' 的缓存
}
```

### 3.3 基于路径的重新验证（Path-based）

```tsx
'use server'

import { revalidatePath } from 'next/cache'

export async function updatePost(id, data) {
  await db.post.update({ where: { id }, data })

  // 重新验证特定路径
  revalidatePath('/posts')
  revalidatePath(`/posts/${id}`)
}
```

### 3.4 revalidateTag vs revalidatePath

```
revalidateTag('posts')
  → 清除所有标记为 'posts' 的缓存
  → 不管这些数据在哪个页面被使用
  → 适合：数据被多个页面引用

revalidatePath('/dashboard')
  → 重新验证整个 /dashboard 路由
  → 影响该路径下的所有数据
  → 适合：页面数据来自多个来源
```

## 四、动态函数

### 4.1 使路由变为动态

使用以下函数会让整个路由变为动态（不缓存）：

```tsx
import { cookies, headers } from 'next/headers'

export default async function Page() {
  // 使用 cookies() 会让路由变为动态
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')

  // 使用 headers() 会让路由变为动态
  const headersList = await headers()
  const userAgent = headersList.get('user-agent')

  return <div>...</div>
}
```

```
静态路由 vs 动态路由：

静态路由：
  → 构建时生成 HTML
  → 所有用户看到相同内容
  → 可以部署到 CDN

动态路由：
  → 每次请求时生成 HTML
  → 不同用户可能看到不同内容
  → 需要服务器运行
```

### 4.2 搜索参数使路由动态

```tsx
// 只要使用了 searchParams，路由就变成动态
export default async function Page({
  searchParams
}: {
  searchParams: Promise<{ query?: string }>
}) {
  const { query } = await searchParams

  return <div>搜索: {query}</div>
}
```

## 五、实践示例

### 5.1 带缓存的文章列表

```tsx
// app/posts/page.tsx
export const revalidate = 60 // 60 秒重新验证

export default async function PostsPage() {
  const posts = await fetch('https://api.example.com/posts', {
    next: { tags: ['posts'] }
  }).then(r => r.json())

  return (
    <div>
      <h1>文章列表</h1>
      <ul>
        {posts.map(post => (
          <li key={post.id}>
            <a href={`/posts/${post.id}`}>{post.title}</a>
          </li>
        ))}
      </ul>
    </div>
  )
}
```

### 5.2 用户特定数据（不缓存）

```tsx
// app/dashboard/page.tsx
import { getUser } from '@/lib/auth'

export default async function DashboardPage() {
  // 用户数据不缓存
  const user = await getUser({ cache: 'no-store' })

  return (
    <div>
      <h1>欢迎回来，{user.name}</h1>
      <p>上次登录: {user.lastLogin}</p>
    </div>
  )
}
```

### 5.3 混合缓存策略

```tsx
// app/dashboard/page.tsx
import { getUser } from '@/lib/auth'

export default async function DashboardPage() {
  // 用户数据：不缓存
  const user = await getUser({ cache: 'no-store' })

  // 统计数据：每 5 分钟更新
  const stats = await fetch('https://api.example.com/stats', {
    next: { revalidate: 300 }
  }).then(r => r.json())

  // 配置数据：缓存
  const config = await fetch('https://api.example.com/config').then(r => r.json())

  return (
    <div>
      <h1>{user.name} 的工作台</h1>
      <Stats data={stats} />
      <Config data={config} />
    </div>
  )
}
```

## 六、常见陷阱

### 6.1 陷阱：在 Client Component 中直接查数据库

```tsx
// ❌ 错误：Client Component 不能访问数据库
'use client'

export default function UserList() {
  const users = await db.user.findMany()  // 报错！
  return <ul>...</ul>
}
```

```tsx
// ✅ 正确：在 Server Component 中获取数据，传给 Client Component
// app/page.tsx
import UserList from './UserList'

export default async function Page() {
  const users = await db.user.findMany()
  return <UserList users={users} />
}

// app/UserList.tsx
'use client'
export default function UserList({ users }) {
  return <ul>...</ul>
}
```

### 6.2 陷阱：请求瀑布流

```tsx
// ❌ 瀑布流：每个 await 都要等前一个完成
export default async function Page() {
  const user = await getUser()           // 等 100ms
  const team = await getTeam(user.teamId) // 等 200ms（依赖 user）
  const projects = await getProjects(team.id) // 等 150ms（依赖 team）
  // 总耗时: 450ms
}

// ✅ 并行获取无依赖的数据
export default async function Page() {
  const user = await getUser()  // 必须先获取

  // 这两个可以并行
  const [team, recentPosts] = await Promise.all([
    getTeam(user.teamId),
    getRecentPosts(user.id)
  ])

  return <div>...</div>
}
```

### 6.3 陷阱：忘记缓存导致重复请求

```tsx
// ❌ 每次渲染都请求（没有缓存）
export default async function Page() {
  const data = await fetch('https://api.example.com/data')
  // ...
}

// ✅ 使用缓存
export default async function Page() {
  const data = await fetch('https://api.example.com/data', {
    next: { revalidate: 60 }
  })
  // ...
}
```

### 练习 3：Server Action 重新验证

创建一个简单的文章创建功能，创建后自动刷新列表：

```tsx
// app/posts/page.tsx
import { createPost } from './actions'

export default async function PostsPage() {
  const posts = await db.post.findMany()

  return (
    <div>
      <h1>文章列表</h1>
      <form action={createPost}>
        <input name="title" placeholder="文章标题" required />
        <button type="submit">创建</button>
      </form>
      <ul>
        {posts.map(post => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  )
}

// app/posts/actions.ts
'use server'

import { revalidatePath } from 'next/cache'

export async function createPost(formData) {
  const title = formData.get('title')
  await db.post.create({ data: { title } })
  revalidatePath('/posts')
}
```

## 八、小结

```
本课核心要点：

1. Server Component 可以直接用 async/await 获取数据
2. fetch 默认会被缓存，可以用 cache: 'no-store' 或 revalidate 控制
3. revalidate 基于时间，revalidateTag 基于标签，revalidatePath 基于路径
4. cookies() 和 headers() 会让路由变为动态
5. 并行获取无依赖的数据可以提升性能
6. 数据获取要放在 Server Component 中，通过 props 传给 Client Component
```
