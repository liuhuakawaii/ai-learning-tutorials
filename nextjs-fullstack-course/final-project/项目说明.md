# Micro SaaS Starter 项目说明

## 项目目标

构建一个小型 SaaS 产品模板。它要包含真实产品必备的账号、团队、权限、数据、支付思路、管理后台和部署流程。

## 内置 scaffold

课程提供一个项目骨架：

```text
nextjs-fullstack-course/final-project/micro-saas-starter-scaffold
```

运行：

```bash
cd nextjs-fullstack-course/final-project/micro-saas-starter-scaffold
npm run check
```

它包含 App Router 路由结构、Prisma schema、权限矩阵、审计日志页面和阶段报告模板。后续课程会逐步把 scaffold 扩展为完整可运行应用。

## 产品主题

默认主题：AI 内容工具站。用户可以创建项目、上传资料、生成内容、查看历史记录，并根据套餐限制使用额度。

## 核心模块

1. 账号系统
   - 邮箱登录
   - Session 管理
   - 用户资料

2. 团队空间
   - 创建团队
   - 邀请成员
   - 角色权限

3. 项目与文档
   - 项目 CRUD
   - 文档上传
   - 搜索与筛选

4. AI 功能
   - 生成内容
   - 保存历史
   - 用量统计

5. 订阅与配额
   - 免费 / Pro / Team 套餐
   - 每月用量限制
   - 超额提示

6. 管理后台
   - 用户列表
   - 项目统计
   - 审计日志
   - 错误记录

## 验收标准

- 未登录用户不能访问 Dashboard
- 普通成员不能修改团队计费设置
- 表单提交有服务端校验
- 数据列表支持分页、搜索、筛选
- 至少 5 个关键页面通过移动端适配检查
- 生产环境能完成数据库迁移并正常启动
- 内置 scaffold 的 `npm run check` 通过

## 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Next.js App Router |
| 语言 | TypeScript |
| 样式 | TailwindCSS |
| 数据库 | PostgreSQL |
| ORM | Prisma |
| 认证 | iron-session |
| 表单 | React Hook Form + Zod |
| 部署 | Vercel / Docker |

## 扩展功能

完成基础功能后，可以继续添加：

1. **支付集成**：Stripe 支付流程
2. **AI 功能**：集成 OpenAI API
3. **实时通知**：WebSocket 推送
4. **数据导出**：CSV/Excel 导出
5. **API 文档**：自动生成 API 文档
6. **多语言**：i18n 国际化
7. **深色模式**：主题切换
8. **移动端**：响应式优化
