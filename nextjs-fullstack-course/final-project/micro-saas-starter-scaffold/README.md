# Micro SaaS Starter Scaffold

这是 Next.js 全栈课程的贯穿项目骨架。它不是完整安装版应用，而是用来统一课程中的页面结构、数据模型、权限边界和验收标准。

## 检查

```bash
npm run check
```

## 课程映射

- 第一阶段：实现 `app/(dashboard)/projects/page.tsx` 和表单状态。
- 第二阶段：根据 `prisma/schema.prisma` 实现用户、团队、成员和权限。
- 第三阶段：补搜索、筛选、邀请、套餐、审计日志。
- 第四阶段：按 `docs/security-review.md` 做性能、安全和无障碍审查。
- 第五阶段：补部署、迁移、种子数据和上线 checklist。
