## 概述

Stage 4 专注于将 RAG 系统从原型推向生产环境。你将学习性能优化、缓存策略、流式响应、安全防御、可观测性，以及完整的生产级部署实践。

完成本阶段后，你将具备部署和维护企业级 RAG 系统的全部核心能力。

## 前置要求

- 完成 Stage 1-3 的全部课程
- 熟悉 Python 异步编程 (asyncio)
- 了解 Docker 基础操作
- 具备基本的 Linux 命令行能力

## 技术栈

本阶段使用的核心技术：

- **Web 框架**: FastAPI + Uvicorn
- **缓存**: Redis
- **向量数据库**: ChromaDB / Pinecone
- **可观测性**: OpenTelemetry, LangSmith, Grafana
- **容器化**: Docker + Docker Compose
- **LLM**: OpenAI API (GPT-4)
- **异步**: asyncio, aiohttp

## 学习目标

完成 Stage 4 后，你将能够：

1. **性能优化** — 识别并消除 RAG 系统中的性能瓶颈
2. **缓存设计** — 实现多级缓存策略，显著降低延迟和成本
3. **流式响应** — 构建低延迟的流式 RAG 体验
4. **安全防御** — 防御 Prompt 注入等安全攻击
5. **可观测性** — 建立完整的监控、追踪和告警体系
6. **生产部署** — 将 RAG 系统部署到生产环境并持续运维

## 环境准备

```bash
# 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows

# 安装依赖
pip install fastapi uvicorn redis chromadb openai \
    opentelemetry-api opentelemetry-sdk \
    langsmith prometheus-client \
    docker docker-compose

# 启动 Redis (需要 Docker)
docker run -d --name redis -p 6379:6379 redis:7-alpine
```

## 评估标准

每个课程包含 3 个练习，完成标准：

- [ ] 01 性能优化：实现异步并行检索，延迟降低 50%+
- [ ] 02 缓存策略：实现语义缓存，缓存命中率 > 30%
- [ ] 03 流式 RAG：实现 SSE 流式端点，TTFT < 500ms
- [ ] 04 安全防御：通过所有注入攻击测试用例
- [ ] 05 可观测性：搭建完整的追踪和监控面板
- [ ] 06 阶战：成功部署并通过端到端测试
