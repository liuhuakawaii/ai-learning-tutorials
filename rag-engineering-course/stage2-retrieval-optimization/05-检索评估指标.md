## 1. 为什么需要评估指标？

没有评估，就没有优化方向。你改进了检索器，但怎么知道它变得更好了？

## 2. 核心评估指标详解

### 2.1 Recall@K（召回率）

**含义**: 在返回的 Top-K 结果中，覆盖了多少比例的相关文档？

```
                |Top-K ∩ 相关文档|
Recall@K = ─────────────────────
               |相关文档总数|

示例:
  相关文档 = {Doc1, Doc3, Doc5, Doc7}
  Top-5 结果 = [Doc1, Doc2, Doc3, Doc8, Doc9]
  命中 = {Doc1, Doc3} → 2 个
  Recall@5 = 2/4 = 0.50
```

### 2.2 Precision@K（精确率）

**含义**: 返回的 Top-K 结果中，有多少比例是相关的？

```
                |Top-K ∩ 相关文档|
Precision@K = ─────────────────────
                    K

示例:
  相关文档 = {Doc1, Doc3, Doc5}
  Top-5 结果 = [Doc1, Doc2, Doc3, Doc8, Doc9]
  命中 = {Doc1, Doc3} → 2 个
  Precision@5 = 2/5 = 0.40
```

### 2.3 MRR（Mean Reciprocal Rank）

**含义**: 第一个相关结果出现在第几位？越靠前越好。

```
              1
MRR = ─── × Σ  ─────────────
       |Q|   q∈Q  rank(q)

其中 rank(q) = 第一个相关结果在 Top-K 中的排名

示例:
  Query 1: 第一个相关结果排第 2 位 → 1/2 = 0.50
  Query 2: 第一个相关结果排第 1 位 → 1/1 = 1.00
  Query 3: 第一个相关结果排第 5 位 → 1/5 = 0.20
  MRR = (0.50 + 1.00 + 0.20) / 3 = 0.567
```

### 2.4 NDCG（Normalized Discounted Cumulative Gain）

**含义**: 考虑排序位置的增益——排在前面的相关文档贡献更大。

```
DCG@K = Σᵢ₌₁ᴷ  relᵢ / log₂(i + 1)

NDCG@K = DCG@K / IDCG@K

其中:
  relᵢ = 第 i 个位置的文档相关性分数（0 或 1，或多级 0-3）
  IDCG = 理想排序下的 DCG（所有相关文档排在最前面）

示例 (二元相关性):
  相关文档 = {Doc1, Doc3, Doc5}
  Top-5 结果 = [Doc1, Doc2, Doc3, Doc8, Doc5]
  相关性 =      [1,   0,   1,   0,   1  ]

  DCG@5 = 1/log₂(2) + 0/log₂(3) + 1/log₂(4) + 0/log₂(5) + 1/log₂(6)
        = 1.0 + 0 + 0.5 + 0 + 0.387 = 1.887

  IDCG@5 = 1/log₂(2) + 1/log₂(3) + 1/log₂(4) + 0 + 0
         = 1.0 + 0.631 + 0.5 = 2.131

  NDCG@5 = 1.887 / 2.131 = 0.885
```

## 3. 指标对比速查表

| 指标 | 衡量什么 | 值域 | 何时使用 | 局限 |
|------|---------|------|---------|------|
| **Recall@K** | 覆盖率 | [0, 1] | 关注"不漏掉"相关文档 | 不关心排序位置 |
| **Precision@K** | 准确度 | [0, 1] | 关注"返回的都是有用的" | 不关心排序位置 |
| **MRR** | 首个结果的位置 | [0, 1] | 关注"第一个答案多快出现" | 只看第一个相关结果 |
| **NDCG@K** | 排序质量 | [0, 1] | 关注"好的排在前面" | 需要多级相关性标注 |

**选择建议**:
- **客服/FAQ 场景**: 重点看 MRR（用户期望第一个结果就是答案）
- **研究/探索场景**: 重点看 Recall@K（不漏掉重要信息）
- **推荐/搜索场景**: 重点看 NDCG@K（好的排在前面）
- **通用评估**: 同时看 Recall@5 + MRR + NDCG@10

## 4. 从零实现评估指标

```python
"""
检索评估指标 - 从零实现
支持: Recall@K, Precision@K, MRR, NDCG@K
"""
import math
from typing import List, Set, Dict, Tuple
from dataclasses import dataclass


@dataclass
class EvalResult:
    """单个查询的评估结果"""
    query: str
    recall_at_k: float
    precision_at_k: float
    reciprocal_rank: float
    ndcg_at_k: float
    retrieved_ids: List[str]
    relevant_ids: Set[str]


def recall_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
    """
    Recall@K: Top-K 中覆盖了多少相关文档

    Args:
        retrieved: 检索结果 ID 列表（按排名排序）
        relevant: 相关文档 ID 集合
        k: 截断位置

    Returns:
        Recall@K 值
    """
    if not relevant:
        return 0.0
    retrieved_at_k = set(retrieved[:k])
    hits = len(retrieved_at_k & relevant)
    return hits / len(relevant)


def precision_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
    """
    Precision@K: Top-K 中有多少是相关的

    Args:
        retrieved: 检索结果 ID 列表
        relevant: 相关文档 ID 集合
        k: 截断位置

    Returns:
        Precision@K 值
    """
    if k == 0:
        return 0.0
    retrieved_at_k = retrieved[:k]
    hits = sum(1 for doc_id in retrieved_at_k if doc_id in relevant)
    return hits / k


def mean_reciprocal_rank(retrieved: List[str], relevant: Set[str], k: int = 10) -> float:
    """
    MRR: 第一个相关结果的倒数排名

    Args:
        retrieved: 检索结果 ID 列表
        relevant: 相关文档 ID 集合
        k: 检查的最大位置

    Returns:
        Reciprocal Rank 值（单个查询）
    """
    for i, doc_id in enumerate(retrieved[:k]):
        if doc_id in relevant:
            return 1.0 / (i + 1)
    return 0.0


def ndcg_at_k(retrieved: List[str], relevant: Set[str], k: int) -> float:
    """
    NDCG@K: 归一化折损累积增益

    Args:
        retrieved: 检索结果 ID 列表
        relevant: 相关文档 ID 集合（二元相关性）
        k: 截断位置

    Returns:
        NDCG@K 值
    """
    if not relevant:
        return 0.0

    # DCG: 实际排序的折损增益
    dcg = 0.0
    for i, doc_id in enumerate(retrieved[:k]):
        rel = 1.0 if doc_id in relevant else 0.0
        dcg += rel / math.log2(i + 2)  # i+2 因为 log₂(1) = 0

    # IDCG: 理想排序的折损增益
    ideal_rels = sorted(
        [1.0 if doc_id in relevant else 0.0 for doc_id in retrieved[:k]],
        reverse=True
    )
    # 补充缺失的相关文档
    num_relevant = min(len(relevant), k)
    while len(ideal_rels) < num_relevant:
        ideal_rels.append(1.0)
    ideal_rels = ideal_rels[:k]

    idcg = 0.0
    for i, rel in enumerate(ideal_rels):
        idcg += rel / math.log2(i + 2)

    return dcg / idcg if idcg > 0 else 0.0


def evaluate_query(
    query: str,
    retrieved: List[str],
    relevant: Set[str],
    k: int = 5
) -> EvalResult:
    """评估单个查询"""
    return EvalResult(
        query=query,
        recall_at_k=recall_at_k(retrieved, relevant, k),
        precision_at_k=precision_at_k(retrieved, relevant, k),
        reciprocal_rank=mean_reciprocal_rank(retrieved, relevant, k),
        ndcg_at_k=ndcg_at_k(retrieved, relevant, k),
        retrieved_ids=retrieved[:k],
        relevant_ids=relevant
    )


def evaluate_batch(
    results: List[EvalResult]
) -> Dict[str, float]:
    """汇总批量评估结果"""
    n = len(results)
    if n == 0:
        return {}

    return {
        "mean_recall": sum(r.recall_at_k for r in results) / n,
        "mean_precision": sum(r.precision_at_k for r in results) / n,
        "mrr": sum(r.reciprocal_rank for r in results) / n,
        "mean_ndcg": sum(r.ndcg_at_k for r in results) / n,
        "num_queries": n
    }


# ========== 使用示例 ==========
if __name__ == "__main__":
    # 模拟检索结果
    test_cases = [
        {
            "query": "iPhone 电池容量",
            "retrieved": ["doc1", "doc3", "doc5", "doc2", "doc8"],
            "relevant": {"doc1", "doc5", "doc7"}
        },
        {
            "query": "Python Web 框架对比",
            "retrieved": ["doc10", "doc11", "doc12", "doc13", "doc14"],
            "relevant": {"doc10", "doc12"}
        },
        {
            "query": "退款流程",
            "retrieved": ["doc20", "doc21", "doc22", "doc23", "doc24"],
            "relevant": {"doc22", "doc23"}
        },
    ]

    all_results = []
    for tc in test_cases:
        result = evaluate_query(
            tc["query"], tc["retrieved"], tc["relevant"], k=5
        )
        all_results.append(result)
        print(f"Query: {result.query}")
        print(f"  Recall@5:    {result.recall_at_k:.3f}")
        print(f"  Precision@5: {result.precision_at_k:.3f}")
        print(f"  MRR:         {result.reciprocal_rank:.3f}")
        print(f"  NDCG@5:      {result.ndcg_at_k:.3f}")
        print()

    # 汇总
    summary = evaluate_batch(all_results)
    print("=" * 50)
    print(f"批量评估汇总 ({summary['num_queries']} queries):")
    print(f"  Mean Recall@5:    {summary['mean_recall']:.3f}")
    print(f"  Mean Precision@5: {summary['mean_precision']:.3f}")
    print(f"  MRR:              {summary['mrr']:.3f}")
    print(f"  Mean NDCG@5:      {summary['mean_ndcg']:.3f}")
```

## 5. 构建评估数据集

评估数据集是所有指标计算的基础。没有高质量的 ground truth，指标毫无意义。

```python
"""
评估数据集构建工具
支持: 手动标注、LLM 辅助标注、数据集持久化
"""
import json
import os
from typing import List, Dict, Set, Optional
from dataclasses import dataclass, asdict, field
from datetime import datetime


@dataclass
class QueryAnnotation:
    """单条查询标注"""
    query: str
    relevant_doc_ids: List[str]  # 相关文档 ID 列表
    difficulty: str = "medium"   # easy / medium / hard
    category: str = "general"    # 查询类别
    notes: str = ""              # 标注备注
    created_at: str = field(default_factory=lambda: datetime.now().isoformat())


class EvalDatasetBuilder:
    """
    评估数据集构建器

    工作流:
    1. 添加文档库
    2. 添加查询 + 标注相关文档
    3. 保存/加载数据集
    4. 统计数据集质量
    """

    def __init__(self, dataset_name: str = "rag_eval"):
        self.dataset_name = dataset_name
        self.annotations: List[QueryAnnotation] = []
        self.doc_store: Dict[str, str] = {}  # doc_id -> content

    def add_documents(self, documents: List[Dict[str, str]]):
        """
        添加文档到文档库

        Args:
            documents: [{"id": "doc1", "content": "..."}, ...]
        """
        for doc in documents:
            self.doc_store[doc["id"]] = doc["content"]
        print(f"已添加 {len(documents)} 个文档，总计 {len(self.doc_store)} 个")

    def add_annotation(
        self,
        query: str,
        relevant_doc_ids: List[str],
        difficulty: str = "medium",
        category: str = "general",
        notes: str = ""
    ):
        """添加一条查询标注"""
        # 验证文档 ID 存在
        for doc_id in relevant_doc_ids:
            if doc_id not in self.doc_store:
                print(f"⚠️ 警告: 文档 ID '{doc_id}' 不在文档库中")

        annotation = QueryAnnotation(
            query=query,
            relevant_doc_ids=relevant_doc_ids,
            difficulty=difficulty,
            category=category,
            notes=notes
        )
        self.annotations.append(annotation)

    def save(self, filepath: str):
        """保存数据集到 JSON 文件"""
        dataset = {
            "name": self.dataset_name,
            "created_at": datetime.now().isoformat(),
            "num_documents": len(self.doc_store),
            "num_annotations": len(self.annotations),
            "documents": self.doc_store,
            "annotations": [asdict(a) for a in self.annotations]
        }

        os.makedirs(os.path.dirname(filepath) or ".", exist_ok=True)
        with open(filepath, "w", encoding="utf-8") as f:
            json.dump(dataset, f, ensure_ascii=False, indent=2)
        print(f"数据集已保存: {filepath}")
        print(f"  文档数: {len(self.doc_store)}")
        print(f"  标注数: {len(self.annotations)}")

    @classmethod
    def load(cls, filepath: str) -> "EvalDatasetBuilder":
        """从 JSON 文件加载数据集"""
        with open(filepath, "r", encoding="utf-8") as f:
            dataset = json.load(f)

        builder = cls(dataset_name=dataset["name"])
        builder.doc_store = dataset["documents"]

        for ann in dataset["annotations"]:
            builder.annotations.append(QueryAnnotation(**ann))

        print(f"数据集已加载: {filepath}")
        print(f"  文档数: {len(builder.doc_store)}")
        print(f"  标注数: {len(builder.annotations)}")
        return builder

    def stats(self) -> Dict:
        """统计数据集质量指标"""
        if not self.annotations:
            return {"num_annotations": 0}

        relevant_counts = [len(a.relevant_doc_ids) for a in self.annotations]
        difficulties = {}
        categories = {}
        for a in self.annotations:
            difficulties[a.difficulty] = difficulties.get(a.difficulty, 0) + 1
            categories[a.category] = categories.get(a.category, 0) + 1

        return {
            "num_documents": len(self.doc_store),
            "num_annotations": len(self.annotations),
            "avg_relevant_per_query": sum(relevant_counts) / len(relevant_counts),
            "min_relevant": min(relevant_counts),
            "max_relevant": max(relevant_counts),
            "difficulty_distribution": difficulties,
            "category_distribution": categories
        }


# ========== 使用示例 ==========
if __name__ == "__main__":
    builder = EvalDatasetBuilder("my_rag_eval")

    # 添加文档
    documents = [
        {"id": "doc1", "content": "iPhone 15 Pro Max 配备 4422mAh 电池，支持 27W 快充"},
        {"id": "doc2", "content": "智能手机电池技术发展趋势：固态电池将取代锂离子电池"},
        {"id": "doc3", "content": "iPhone 15 Pro Max 摄像头采用 4800 万像素主摄"},
        {"id": "doc4", "content": "手机续航优化指南：关闭后台应用可延长电池使用时间"},
        {"id": "doc5", "content": "Samsung Galaxy S24 Ultra 电池容量为 5000mAh"},
        {"id": "doc6", "content": "iPhone 15 保护壳推荐：Spigen、OtterBox 等品牌"},
        {"id": "doc7", "content": "Django 是 Python 最流行的 Web 框架，遵循 MVT 架构"},
        {"id": "doc8", "content": "FastAPI 是高性能 Web 框架，支持异步请求处理"},
        {"id": "doc9", "content": "Flask 是轻量级微框架，适合小型项目"},
        {"id": "doc10", "content": "Python Web 框架性能对比：FastAPI > Flask > Django"},
    ]
    builder.add_documents(documents)

    # 添加标注
    builder.add_annotation(
        query="iPhone 15 Pro Max 电池容量",
        relevant_doc_ids=["doc1"],
        difficulty="easy",
        category="product-spec"
    )
    builder.add_annotation(
        query="哪个手机电池最大",
        relevant_doc_ids=["doc1", "doc5"],
        difficulty="medium",
        category="comparison"
    )
    builder.add_annotation(
        query="Python Web 框架哪个性能最好",
        relevant_doc_ids=["doc8", "doc10"],
        difficulty="medium",
        category="tech-comparison"
    )
    builder.add_annotation(
        query="如何延长手机续航",
        relevant_doc_ids=["doc4"],
        difficulty="easy",
        category="how-to"
    )

    # 查看统计
    print("\n数据集统计:")
    stats = builder.stats()
    for k, v in stats.items():
        print(f"  {k}: {v}")

    # 保存
    builder.save("eval_dataset.json")
```

## 6. 批量评估运行器

```python
"""
批量检索评估运行器
支持: 多检索器对比、多指标同时计算、结果导出
"""
import json
import time
from typing import List, Dict, Callable, Set, Any
from dataclasses import dataclass, asdict, field


@dataclass
class ExperimentResult:
    """单个实验结果"""
    retriever_name: str
    k: int
    mean_recall: float
    mean_precision: float
    mrr: float
    mean_ndcg: float
    latency_ms: float
    num_queries: int
    per_query_results: List[Dict] = field(default_factory=list)


class BatchEvaluator:
    """
    批量检索评估器

    用法:
    1. 注册检索器（函数签名: query -> List[doc_id]）
    2. 加载评估数据集
    3. 运行评估
    4. 对比结果
    """

    def __init__(self):
        self.retrievers: Dict[str, Callable] = {}
        self.dataset: List[Dict] = []  # [{"query": ..., "relevant": set(...)}, ...]

    def register_retriever(self, name: str, retriever_fn: Callable):
        """
        注册检索器

        Args:
            name: 检索器名称
            retriever_fn: 检索函数，签名: (query: str) -> List[str]
                         返回文档 ID 列表（按排名排序）
        """
        self.retrievers[name] = retriever_fn
        print(f"已注册检索器: {name}")

    def load_dataset(self, annotations: List[Dict]):
        """
        加载评估数据集

        Args:
            annotations: [{"query": str, "relevant_doc_ids": [str, ...]}, ...]
        """
        self.dataset = []
        for ann in annotations:
            self.dataset.append({
                "query": ann["query"],
                "relevant": set(ann["relevant_doc_ids"]),
                "category": ann.get("category", "general"),
                "difficulty": ann.get("difficulty", "medium")
            })
        print(f"已加载 {len(self.dataset)} 条评估数据")

    def evaluate_single(
        self,
        retriever_name: str,
        retriever_fn: Callable,
        k: int = 5
    ) -> ExperimentResult:
        """评估单个检索器"""
        per_query = []
        total_latency = 0.0

        for item in self.dataset:
            start = time.time()
            retrieved = retriever_fn(item["query"])
            latency = (time.time() - start) * 1000
            total_latency += latency

            r_at_k = recall_at_k(retrieved, item["relevant"], k)
            p_at_k = precision_at_k(retrieved, item["relevant"], k)
            rr = mean_reciprocal_rank(retrieved, item["relevant"], k)
            ndcg = ndcg_at_k(retrieved, item["relevant"], k)

            per_query.append({
                "query": item["query"],
                "category": item["category"],
                "difficulty": item["difficulty"],
                "recall": r_at_k,
                "precision": p_at_k,
                "rr": rr,
                "ndcg": ndcg,
                "latency_ms": latency
            })

        n = len(self.dataset)
        return ExperimentResult(
            retriever_name=retriever_name,
            k=k,
            mean_recall=sum(r["recall"] for r in per_query) / n,
            mean_precision=sum(r["precision"] for r in per_query) / n,
            mrr=sum(r["rr"] for r in per_query) / n,
            mean_ndcg=sum(r["ndcg"] for r in per_query) / n,
            latency_ms=total_latency / n,
            num_queries=n,
            per_query_results=per_query
        )

    def run_all(self, k: int = 5) -> List[ExperimentResult]:
        """运行所有已注册检索器的评估"""
        results = []
        for name, fn in self.retrievers.items():
            print(f"\n评估检索器: {name} (k={k})")
            result = self.evaluate_single(name, fn, k)
            results.append(result)
            print(f"  Recall@{k}: {result.mean_recall:.3f}")
            print(f"  Precision@{k}: {result.mean_precision:.3f}")
            print(f"  MRR: {result.mrr:.3f}")
            print(f"  NDCG@{k}: {result.mean_ndcg:.3f}")
            print(f"  Avg Latency: {result.latency_ms:.1f}ms")
        return results

    @staticmethod
    def compare_results(results: List[ExperimentResult]) -> str:
        """生成对比表格"""
        header = f"{'Retriever':<20} {'Recall@K':<12} {'Precision@K':<14} {'MRR':<10} {'NDCG@K':<10} {'Latency':<10}"
        sep = "-" * len(header)
        lines = [sep, header, sep]

        for r in results:
            line = (
                f"{r.retriever_name:<20} "
                f"{r.mean_recall:<12.3f} "
                f"{r.mean_precision:<14.3f} "
                f"{r.mrr:<10.3f} "
                f"{r.mean_ndcg:<10.3f} "
                f"{r.latency_ms:<10.1f}ms"
            )
            lines.append(line)

        lines.append(sep)
        return "\n".join(lines)

    @staticmethod
    def export_results(results: List[ExperimentResult], filepath: str):
        """导出结果到 JSON"""
        data = {
            "experiments": [
                {
                    "retriever": r.retriever_name,

        }

            json.dump(data, f, ensure_ascii=False, indent=2)
        print(f"结果已导出: {filepath}")

import math

def recall_at_k(retrieved, relevant, k):
    if not relevant:
        return 0.0
    return len(set(retrieved[:k]) & relevant) / len(relevant)

def precision_at_k(retrieved, relevant, k):
    if k == 0:
        return 0.0
    return sum(1 for d in retrieved[:k] if d in relevant) / k

def mean_reciprocal_rank(retrieved, relevant, k=10):
    for i, d in enumerate(retrieved[:k]):
        if d in relevant:
            return 1.0 / (i + 1)
    return 0.0

def ndcg_at_k(retrieved, relevant, k):
    if not relevant:
        return 0.0
    dcg = sum(
        (1.0 if retrieved[i] in relevant else 0.0) / math.log2(i + 2)
        for i in range(min(k, len(retrieved)))
    )
    ideal_rels = sorted(
        [1.0 if retrieved[i] in relevant else 0.0 for i in range(min(k, len(retrieved)))],
        reverse=True
    )
    num_rel = min(len(relevant), k)
    while len(ideal_rels) < num_rel:
        ideal_rels.append(1.0)
    idcg = sum(r / math.log2(i + 2) for i, r in enumerate(ideal_rels[:k]))
    return dcg / idcg if idcg > 0 else 0.0
```

### 7.1 按维度细分分析

```python
"""
按维度细分评估结果，定位薄弱环节
"""
from typing import List, Dict
from collections import defaultdict


def analyze_by_dimension(
    per_query_results: List[Dict],
    dimension: str = "category"
) -> Dict[str, Dict[str, float]]:
    """
    按指定维度分组统计指标

    Args:
        per_query_results: 每个查询的评估结果
        dimension: 分组维度 (category / difficulty)

    Returns:
        {dimension_value: {metric: value}, ...}
    """
    groups = defaultdict(list)
    for r in per_query_results:
        key = r.get(dimension, "unknown")
        groups[key].append(r)

    analysis = {}
    for key, queries in groups.items():
        n = len(queries)
        analysis[key] = {
            "num_queries": n,
            "mean_recall": sum(q["recall"] for q in queries) / n,
            "mean_precision": sum(q["precision"] for q in queries) / n,
            "mrr": sum(q["rr"] for q in queries) / n,
            "mean_ndcg": sum(q["ndcg"] for q in queries) / n,
            "mean_latency_ms": sum(q["latency_ms"] for q in queries) / n
        }

    return analysis


def find_weak_queries(
    per_query_results: List[Dict],
    metric: str = "recall",
    threshold: float = 0.5
) -> List[Dict]:
    """找出表现差的查询"""
    return [r for r in per_query_results if r.get(metric, 0) < threshold]


# ========== 使用示例 ==========
if __name__ == "__main__":
    # 模拟评估结果
    per_query = [
        {"query": "iPhone 电池", "category": "product", "difficulty": "easy",
         "recall": 1.0, "precision": 0.6, "rr": 1.0, "ndcg": 0.95, "latency_ms": 50},
        {"query": "Python 框架", "category": "tech", "difficulty": "medium",
         "recall": 0.5, "precision": 0.4, "rr": 0.5, "ndcg": 0.45, "latency_ms": 80},
        {"query": "退款流程", "category": "policy", "difficulty": "easy",
         "recall": 1.0, "precision": 0.8, "rr": 1.0, "ndcg": 0.98, "latency_ms": 40},
        {"query": "API 认证", "category": "tech", "difficulty": "hard",
         "recall": 0.3, "precision": 0.2, "rr": 0.33, "ndcg": 0.28, "latency_ms": 120},
    ]

    # 按类别分析
    print("按类别分析:")
    by_cat = analyze_by_dimension(per_query, "category")
    for cat, metrics in by_cat.items():
        print(f"\n  [{cat}] ({metrics['num_queries']} queries)")
        print(f"    Recall: {metrics['mean_recall']:.3f}")
        print(f"    MRR:    {metrics['mrr']:.3f}")

    # 按难度分析
    print("\n按难度分析:")
    by_diff = analyze_by_dimension(per_query, "difficulty")
    for diff, metrics in by_diff.items():
        print(f"\n  [{diff}] ({metrics['num_queries']} queries)")
        print(f"    Recall: {metrics['mean_recall']:.3f}")

    # 找出弱查询
    print("\nRecall < 0.5 的查询:")
    weak = find_weak_queries(per_query, metric="recall", threshold=0.5)
    for q in weak:
        print(f"  - {q['query']} (recall={q['recall']:.2f}, category={q['category']})")
```

## 8. 常见错误与避坑指南

### ❌ 错误 1: Ground Truth 质量差

```python
# 错误: 随便标几个文档作为相关文档
relevant = {"doc1"}  # 只标了一个，漏标了 doc3, doc5

# 正确: 多人标注，交叉验证
# 使用 LLM 辅助标注 + 人工审核
relevant = {"doc1", "doc3", "doc5"}  # 经过验证的完整标注
```

### ❌ 错误 2: 只看平均值

```python
# 错误: 平均 Recall = 0.8，看起来不错
# 但实际: 80% 的查询 Recall = 1.0，20% 的查询 Recall = 0.0
# 那 20% 完全检索不到！

# 正确: 看分布，找弱查询
weak_queries = find_weak_queries(results, threshold=0.5)
print(f"有 {len(weak_queries)} 个查询表现很差")
```

### ❌ 错误 3: K 值选择不当

```python
# 错误: 用 Recall@100 评估，K 太大，指标没有区分度
recall_100 = recall_at_k(retrieved, relevant, k=100)  # 几乎总是 1.0

# 正确: K 应与实际使用场景一致
# 如果 LLM 只看 Top-5，就用 Recall@5
recall_5 = recall_at_k(retrieved, relevant, k=5)
```

### ❌ 错误 4: 评估数据集太小

```python
# 错误: 只有 5 个查询，结果随机性太大
dataset = annotations[:5]

# 正确: 至少 50+ 个查询，覆盖各类场景
# 理想: 100-500 个查询
dataset = annotations  # 完整数据集
```

### ❌ 错误 5: 忽略延迟指标

```python
# 错误: 只看效果指标，不看延迟

# 正确: 效果和延迟一起看
```
