## 1. 为什么需要多路召回？

在前三课中，我们分别学习了混合检索、重排序和查询改写。但生产环境中，仅靠"向量 + BM25"两路往往不够。不同类型的查询需要不同的匹配策略：

```
┌─────────────────────────────────────────────────────────────────┐
│                    多路召回架构全景                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  用户 Query: "2024年 Q3 的退款政策是什么？"                       │
│       │                                                         │
│       ├──────────────┬──────────────┬──────────────┐             │
│       ▼              ▼              ▼              ▼             │
│  ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐          │
│  │ 语义检索 │   │ 关键词   │   │ 元数据   │   │ 知识图谱 │          │
│  │         │   │ 检索     │   │ 过滤     │   │ 检索    │          │
│  │"退款流程 │   │ 匹配     │   │ year=   │   │ 实体    │          │
│  │ 相关文档"│   │"退款""Q3"│   │ 2024    │   │ 关系    │          │

│  └────┬────┘   └────┬────┘   └────┬────┘   └────┬────┘          │
│       │             │             │             │                │
│       └─────────────┼─────────────┼─────────────┘                │
│                     ▼                                            │
│            ┌─────────────────┐                                   │

│                     ▼                                            │
```

每路检索器有不同的"视角"：

| 检索路径 | 匹配维度 | 擅长 | 不擅长 |
|---------|---------|------|--------|
| 语义检索 | 向量相似度 | 同义词、自然语言问题 | 精确型号、日期 |
| 关键词检索 | 词频匹配 | 专有名词、精确术语 | 同义词、改述 |
| 元数据过滤 | 结构化属性 | 时间范围、类别筛选 | 语义理解 |
| 知识图谱 | 实体关系 | 多跳推理、关联查询 | 开放域问题 |

## 2. 元数据过滤 + 语义搜索

元数据过滤是最直接的精度提升手段——先用结构化条件缩小范围，再做语义匹配：

### 2.1 多字段检索器实现

```python
"""
多字段检索器：支持元数据过滤 + 语义搜索联合检索
"""
from langchain.schema import Document
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings
from typing import List, Dict, Optional, Any, Tuple
from dataclasses import dataclass, field


@dataclass
class RetrievalFilter:
    """检索过滤条件"""
    source: Optional[str] = None
    category: Optional[str] = None
    year: Optional[int] = None
    quarter: Optional[str] = None
    tags: Optional[List[str]] = None
    custom: Optional[Dict[str, Any]] = None

    def to_chroma_filter(self) -> Optional[Dict]:
        """转换为 Chroma 可用的过滤条件"""
        conditions = []

        if self.source:
            conditions.append({"source": self.source})
        if self.category:
            conditions.append({"category": self.category})
        if self.year:
            conditions.append({"year": self.year})
        if self.quarter:
            conditions.append({"quarter": self.quarter})
        if self.tags:
            conditions.append({"tags": {"$in": self.tags}})

        if self.custom:
            conditions.append(self.custom)

        if not conditions:
            return None
        if len(conditions) == 1:
            return conditions[0]
        return {"$and": conditions}


class MultiFieldRetriever:
    """
    多字段检索器

    支持:
    - 纯语义搜索
    - 元数据过滤 + 语义搜索
    - 渐进式放松过滤（严格 → 宽松 → 无过滤）
    """

    def __init__(self, documents: List[Document], embedding_model=None):
        self.embeddings = embedding_model or OpenAIEmbeddings()
        self.vectorstore = Chroma.from_documents(documents, self.embeddings)
        self.documents = documents

    def retrieve(
        self,
        query: str,
        filters: Optional[RetrievalFilter] = None,
        top_k: int = 5,
        fallback: bool = True
    ) -> List[Tuple[Document, float]]:
        """
        检索文档

        Args:
            query: 查询文本
            filters: 元数据过滤条件
            top_k: 返回数量
            fallback: 是否启用渐进式放松

        Returns:
            [(document, score), ...]
        """
        if filters is None:
            return self._search(query, None, top_k)

        # 尝试严格过滤
        chroma_filter = filters.to_chroma_filter()
        results = self._search(query, chroma_filter, top_k)

        # 回退策略：逐步放松过滤
        if fallback and len(results) < top_k:
            results = self._fallback_search(query, filters, top_k)

        return results

    def _search(
        self, query: str, filters: Optional[Dict], top_k: int
    ) -> List[Tuple[Document, float]]:
        """执行带过滤的向量搜索"""
        if filters:
            return self.vectorstore.similarity_search_with_score(
                query, k=top_k, filter=filters
            )
        return self.vectorstore.similarity_search_with_score(query, k=top_k)

    def _fallback_search(
        self, query: str, filters: RetrievalFilter, top_k: int
    ) -> List[Tuple[Document, float]]:
        """渐进式放松过滤"""
        # 第一步：保留核心过滤（source + category）
        relaxed = RetrievalFilter(
            source=filters.source,
            category=filters.category
        )
        chroma_filter = relaxed.to_chroma_filter()
        results = self._search(query, chroma_filter, top_k)

        if results:
            return results

        # 第二步：完全无过滤
        return self._search(query, None, top_k)

if __name__ == "__main__":
    documents = [
        Document(
            page_content="用户认证 API：支持 OAuth2.0 和 JWT，提供 /auth/login 和 /auth/refresh 接口",
            metadata={"source": "api-docs", "category": "auth", "year": 2024, "quarter": "Q3"}
        ),
        Document(

        ),
        Document(

            metadata={"source": "changelog", "category": "refund", "year": 2024, "quarter": "Q3"}
        ),
        Document(
            page_content="2023年退款政策：退款需 5-7 个工作日人工审核",
            metadata={"source": "policy", "category": "refund", "year": 2023, "quarter": "Q4"}
        ),
        Document(
```

## 3. Parent-Child 文档检索

**核心思想**: 用小块做精确检索，返回大块（父块）给 LLM 以获取完整上下文。

```
┌─────────────────────────────────────────────────────────────────┐
│                Parent-Child 检索策略                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  索引阶段:                                                       │
│  ┌─────────────────────────────────────────┐                    │
│  │            原始文档                      │                    │
│  │  ┌─────────────────────────────────┐    │                    │
│  │  │         Parent 块 (1000 字符)    │    │                    │
│  │  │                                 │    │                    │
│  │  │  ┌────────┐ ┌────────┐ ┌──────┐│    │                    │
│  │  │  │Child 1 │ │Child 2 │ │Child3││    │ ← 小块 (200 字符)  │
│  │  │  │200字符 │ │200字符 │ │200字 ││    │                    │
│  │  │  └────────┘ └────────┘ └──────┘│    │                    │
│  │  │                                 │    │                    │
│  │  └─────────────────────────────────┘    │                    │
│  └─────────────────────────────────────────┘                    │
│                                                                 │
│  检索阶段:                                                       │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐   │
│  │ Query    │───▶│ Child    │───▶│ 找到     │───▶│ 返回     │   │
│  │          │    │ 向量检索  │    │ Parent   │    │ Parent   │   │
│  └──────────┘    └──────────┘    └──────────┘    └──────────┘   │
│                                                                 │
│  为什么有效?                                                     │
│  · 小块 (Child): 精确匹配，减少噪音                              │
│  · 大块 (Parent): 完整上下文，LLM 回答更准确                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.1 Parent-Child 完整实现

```python
"""
Parent-Child 检索策略实现
小块精确检索 + 大块完整上下文
"""
from langchain.schema import Document
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings
from typing import List, Dict, Tuple
import uuid
import hashlib


class ParentChildRetriever:
    """
    Parent-Child 检索器

    核心流程:
    1. 将文档切分为 Parent 块（大块）
    2. 将每个 Parent 切分为 Child 块（小块）
    3. 用 Child 块构建向量索引
    4. 检索时：用 query 匹配 Child → 返回对应 Parent
    """

    def __init__(
        self,
        documents: List[Document],
        parent_chunk_size: int = 1000,
        parent_chunk_overlap: int = 100,
        child_chunk_size: int = 200,
        child_chunk_overlap: int = 50,
        embedding_model=None
    ):
        self.embeddings = embedding_model or OpenAIEmbeddings()

        # 分块器
        self.parent_splitter = RecursiveCharacterTextSplitter(
            chunk_size=parent_chunk_size,
            chunk_overlap=parent_chunk_overlap
        )
        self.child_splitter = RecursiveCharacterTextSplitter(
            chunk_size=child_chunk_size,
            chunk_overlap=child_chunk_overlap
        )

        # 存储
        self.parent_store: Dict[str, Document] = {}
        self.child_to_parent: Dict[str, str] = {}

        # 处理文档
        self._process_documents(documents)

    def _generate_id(self, content: str) -> str:
        """基于内容生成稳定的文档 ID"""
        return hashlib.md5(content.encode()).hexdigest()[:12]

    def _process_documents(self, documents: List[Document]):
        """将文档切分为 Parent 和 Child 块，构建索引"""
        all_children = []

        for doc in documents:
            # 切分 Parent 块
            parent_chunks = self.parent_splitter.split_documents([doc])

            for parent in parent_chunks:
                parent_id = self._generate_id(parent.page_content)
                parent.metadata["parent_id"] = parent_id
                parent.metadata["chunk_type"] = "parent"
                self.parent_store[parent_id] = parent

                # 将每个 Parent 切分为 Child 块
                child_chunks = self.child_splitter.split_documents([parent])

                for child in child_chunks:
                    child_id = self._generate_id(child.page_content)
                    child.metadata["child_id"] = child_id
                    child.metadata["parent_id"] = parent_id
                    child.metadata["chunk_type"] = "child"
                    self.child_to_parent[child_id] = parent_id
                    all_children.append(child)

        # 用 Child 块构建向量索引
        if all_children:
            self.child_vectorstore = Chroma.from_documents(
                all_children, self.embeddings
            )
        else:
            self.child_vectorstore = None

    def retrieve(
        self,
        query: str,
        top_k: int = 3,
        child_k: int = 10
    ) -> List[Tuple[Document, float]]:
        """
        Parent-Child 检索

        Args:
            query: 查询文本
            top_k: 返回的 Parent 块数量
            child_k: 检索的 Child 块数量（应大于 top_k）

        Returns:
            [(parent_document, best_child_score), ...]
        """
        if not self.child_vectorstore:
            return []

        # Step 1: 检索最相关的 Child 块
        child_results = self.child_vectorstore.similarity_search_with_score(
            query, k=child_k
        )

        # Step 2: 找到对应的 Parent 块，取最高分 Child 的分数
        parent_scores: Dict[str, float] = {}
        parent_child_count: Dict[str, int] = {}

        for child_doc, score in child_results:
            parent_id = child_doc.metadata.get("parent_id")
            if not parent_id:
                continue

            # 更新 Parent 的最佳分数（分数越低越相似）
            if parent_id not in parent_scores or score < parent_scores[parent_id]:
                parent_scores[parent_id] = score

            # 统计命中 Child 数量（用于排序参考）
            parent_child_count[parent_id] = parent_child_count.get(parent_id, 0) + 1

        # Step 3: 按分数排序，返回 Top-K Parent
        sorted_parents = sorted(parent_scores.items(), key=lambda x: x[1])

        results = []
        for parent_id, score in sorted_parents[:top_k]:
            parent_doc = self.parent_store.get(parent_id)
            if parent_doc:
                # 将命中子块数量附加到 metadata
                parent_doc.metadata["matched_children"] = parent_child_count.get(parent_id, 0)
                results.append((parent_doc, score))

        return results
```

## 4. 上下文压缩 (Contextual Compression)

检索到的文档块可能包含大量无关信息。上下文压缩只保留与查询相关的部分，减少 LLM 输入中的噪音：

```
┌─────────────────────────────────────────────────────────────────┐
│                  上下文压缩示意                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Query: "FastAPI 的性能如何"                                     │
│                                                                 │
│  原始检索结果:                                                   │
│  ┌─────────────────────────────────────────────┐                │
│  │ "FastAPI 是一个现代的、高性能的 Web 框架，    │                │
│  │  基于 Python 类型提示。它自动生成 API 文档，   │                │
│  │  支持异步请求处理，性能接近 Node.js 和 Go。    │                │
│  │  FastAPI 特别适合构建 RESTful API 和微服务。"  │                │
│  └─────────────────────────────────────────────┘                │
│                                                                 │
│  压缩后:                                                        │
│  ┌─────────────────────────────────────────────┐                │
│  │ "FastAPI 是高性能的 Web 框架，               │                │
│  │  支持异步请求处理，性能接近 Node.js 和 Go。"   │                │
│  └─────────────────────────────────────────────┘                │
│                                                                 │
│  效果: 去除了"类型提示""API 文档""微服务"等与性能无关的信息       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.1 上下文压缩实现

```python
"""
上下文压缩检索器
使用 LLM 对检索结果进行压缩，只保留与查询相关的部分
"""
from langchain_openai import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain.schema import Document
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings
from typing import List, Tuple
import re


class ContextualCompressor:
    """上下文压缩器——使用 LLM 提取与查询相关的片段"""

    def __init__(self, llm_model: str = "gpt-4o-mini"):
        self.llm = ChatOpenAI(model=llm_model, temperature=0)

        self.compress_prompt = ChatPromptTemplate.from_template("""
你是一个文档压缩专家。请根据查询，从文档中提取与查询最相关的部分。
规则:
1. 只保留直接回答查询或提供关键背景信息的内容
2. 保留原文，不要改写
3. 如果文档与查询完全无关，输出 "IRRELEVANT"

查询: {query}

原始文档:
{document}

请输出压缩后的文档内容:
""")

    def compress(self, query: str, documents: List[Document]) -> List[Document]:
        """
        压缩文档列表

        Args:
            query: 用户查询
            documents: 检索到的文档列表

        Returns:
            压缩后的文档列表（无关文档被移除）
        """
        compressed_docs = []
        chain = self.compress_prompt | self.llm

        for doc in documents:
            response = chain.invoke({
                "query": query,
                "document": doc.page_content
            })

            content = response.content.strip()

            # 跳过无关文档
            if content == "IRRELEVANT" or len(content) < 10:
                continue

            compressed_doc = Document(
                page_content=content,
                metadata={
                    **doc.metadata,
                    "compressed": True,
                    "original_length": len(doc.page_content),
                    "compressed_length": len(content)
                }
            )
            compressed_docs.append(compressed_doc)

        return compressed_docs


class CompressedRetriever:
    """带上下文压缩的检索器"""

    def __init__(
        self,
        documents: List[Document],
        embedding_model=None,
        llm_model: str = "gpt-4o-mini"
    ):
        self.embeddings = embedding_model or OpenAIEmbeddings()
        self.vectorstore = Chroma.from_documents(documents, self.embeddings)
        self.compressor = ContextualCompressor(llm_model)

    def retrieve(
        self,
        query: str,
        top_k: int = 5,
        compress: bool = True
    ) -> List[Document]:
        """
        检索并可选压缩

        Args:
            query: 查询文本
            top_k: 检索数量
            compress: 是否启用压缩

        Returns:
            检索结果
        """
        docs = self.vectorstore.similarity_search(query, k=top_k)

        if compress:
            docs = self.compressor.compress(query, docs)

        return docs

if __name__ == "__main__":
```

## 5. 完整多路召回管线

将以上所有策略整合为一个完整的检索管线：

```python
"""
完整多路召回管线
整合: 向量检索 + BM25 + 元数据过滤 + Parent-Child + 上下文压缩 + Reranker
"""
from langchain.schema import Document
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.vectorstores import Chroma
from langchain_community.retrievers import BM25Retriever
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from sentence_transformers import CrossEncoder
from typing import List, Dict, Optional, Tuple
from collections import defaultdict
import uuid
import hashlib
import time


class MultiPathRetriever:
    """
    多路召回检索器

    检索路径:
    1. 向量检索（语义匹配）
    2. BM25 检索（关键词匹配）
    3. Parent-Child 检索（精确匹配 + 完整上下文）
    4. 元数据过滤（结构化筛选）

    后处理:
    - RRF 融合
    - Reranker 精排
    - 上下文压缩（可选）
    """

    def __init__(
        self,
        documents: List[Document],
        reranker_model: str = "BAAI/bge-reranker-v2-m3",
        llm_model: str = "gpt-4o-mini",
        parent_chunk_size: int = 1000,
        child_chunk_size: int = 200
    ):
        self.embeddings = OpenAIEmbeddings()
        start = time.time()

        # ===== 路 1: 向量检索 =====
        self.vectorstore = Chroma.from_documents(documents, self.embeddings)

        # ===== 路 2: BM25 检索 =====
        self.bm25 = BM25Retriever.from_documents(documents)
        self.bm25.k = 10

        # ===== 路 3: Parent-Child =====
        self.parent_store: Dict[str, Document] = {}
        self._setup_parent_child(documents, parent_chunk_size, child_chunk_size)

        # ===== Reranker =====
        self.reranker = CrossEncoder(reranker_model, max_length=512)

        # ===== 上下文压缩器 =====
        self.llm = ChatOpenAI(model=llm_model, temperature=0)
        self.compress_prompt = ChatPromptTemplate.from_template(
            "从以下文档中提取与查询最相关的部分，保留原文:\n"
            "查询: {query}\n文档: {document}\n压缩后:"
        )

        elapsed = time.time() - start
        print(f"索引构建完成: {elapsed:.2f}s | 文档: {len(documents)}")

    def _setup_parent_child(self, documents, parent_size, child_size):
        """构建 Parent-Child 索引"""
        parent_splitter = RecursiveCharacterTextSplitter(
            chunk_size=parent_size, chunk_overlap=100
        )
        child_splitter = RecursiveCharacterTextSplitter(
            chunk_size=child_size, chunk_overlap=50
        )

        all_children = []
        for doc in documents:
            parents = parent_splitter.split_documents([doc])
            for parent in parents:
                pid = hashlib.md5(parent.page_content.encode()).hexdigest()[:12]
                parent.metadata["parent_id"] = pid
                self.parent_store[pid] = parent

                children = child_splitter.split_documents([parent])
                for child in children:
                    child.metadata["parent_id"] = pid
                    all_children.append(child)

        if all_children:
            self.pc_vectorstore = Chroma.from_documents(all_children, self.embeddings)
        else:
            self.pc_vectorstore = None

    def _rrf_fusion(
        self,
        results_list: List[List[Tuple[str, float, Document]]],
        k: int = 60
    ) -> List[Tuple[float, Document]]:
        """RRF 融合多路结果"""
        rrf_scores: Dict[str, float] = defaultdict(float)
        doc_map: Dict[str, Document] = {}

        for results in results_list:
            for rank, (doc_id, score, doc) in enumerate(results):
                rrf_scores[doc_id] += 1.0 / (k + rank + 1)
                doc_map[doc_id] = doc

        sorted_docs = sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
        return [(score, doc_map[doc_id]) for doc_id, score in sorted_docs]

    def _compress(self, query: str, doc: Document) -> Optional[Document]:
        """压缩单个文档"""
        chain = self.compress_prompt | self.llm
        response = chain.invoke({"query": query, "document": doc.page_content})
        content = response.content.strip()
        if len(content) < 10:
            return None
        return Document(
            page_content=content,
            metadata={**doc.metadata, "compressed": True}
        )

    def retrieve(
        self,
        query: str,
        top_k: int = 5,
        metadata_filter: Optional[Dict] = None,
        use_reranker: bool = True,
        use_compression: bool = False
    ) -> List[Dict]:
        """
        多路召回主流程

        Args:
            query: 查询文本
            top_k: 最终返回数量
            metadata_filter: 元数据过滤条件
            use_reranker: 是否使用 Reranker
            use_compression: 是否启用上下文压缩

        Returns:
            [{"content": str, "metadata": dict, "score": float, "path": str}, ...]
        """
        # 路 1: 向量检索
        vf = metadata_filter
        vector_docs = self.vectorstore.similarity_search_with_score(
            query, k=10, filter=vf
        )
        vector_results = [
            (doc.page_content[:50], score, doc) for doc, score in vector_docs
        ]

        # 路 2: BM25 检索
        bm25_docs = self.bm25.get_relevant_documents(query)
        bm25_results = [
            (doc.page_content[:50], 0.0, doc) for doc in bm25_docs
        ]

        # 路 3: Parent-Child 检索
        pc_results = []
        if self.pc_vectorstore:
            pc_docs = self.pc_vectorstore.similarity_search_with_score(query, k=10)
            seen = set()
            for doc, score in pc_docs:
                pid = doc.metadata.get("parent_id")
                if pid and pid not in seen:
                    seen.add(pid)
                    parent = self.parent_store.get(pid)
                    if parent:
                        pc_results.append((pid, score, parent))

        # RRF 融合
        fused = self._rrf_fusion([vector_results, bm25_results, pc_results])

        # Reranker 精排
        if use_reranker and fused:
            pairs = [(query, doc.page_content) for _, doc in fused]
            scores = self.reranker.predict(pairs)
            scored = list(zip(scores, [doc for _, doc in fused]))
            scored.sort(key=lambda x: x[0], reverse=True)
            fused = [(float(s), doc) for s, doc in scored]

        # 上下文压缩
        final = []
        for score, doc in fused[:top_k]:
            if use_compression:
                compressed = self._compress(query, doc)
                if compressed:
                    doc = compressed
            final.append({
                "content": doc.page_content,
                "metadata": doc.metadata,
                "score": score
            })

        return final
```

## 6. 单路 vs 多路召回对比

| 维度 | 单路召回 | 多路召回 |
|------|---------|---------|
| **召回率** | 中等 (60-70%) | 高 (80-90%) |
| **精确率** | 取决于单一检索器 | 通过融合与 Reranker 提升 |
| **延迟** | 低 (50-100ms) | 中 (100-300ms) |
| **上下文质量** | 原始块，可能含噪音 | 压缩后，更精准 |
| **复杂度** | 低 | 中高 |
| **维护成本** | 低 | 中（需维护多路索引） |
| **适用场景** | 简单问答、Demo、原型 | 生产环境、复杂业务 |

## 7. 常见错误与避坑指南

### ❌ 错误 1: 元数据过滤条件太严格

```python
# 错误: 四重过滤，可能返回 0 条结果
filters = {"source": "api-docs", "version": "v2", "module": "auth", "lang": "zh"}

# 正确: 设置回退机制
results = retriever.retrieve(query, filters=strict_filters)
if not results:
    results = retriever.retrieve(query, filters=relaxed_filters)
if not results:
    results = retriever.retrieve(query)  # 无过滤兜底
```

### ❌ 错误 2: Parent 块太大导致上下文浪费

```python
# 错误: Parent 块 5000 字符，大部分与查询无关
parent_chunk_size = 20000  # 浪费 token，增加成本

# 正确: 合理控制大小，或配合上下文压缩
parent_chunk_size = 1000  # 适中大小
```

### ❌ 错误 3: 多路文档 ID 不一致

```python
# 错误: 不同检索器使用不同的文档标识，无法正确融合
vectorstore 用 content hash
bm25 用列表 index
parent_child 用 uuid

# 正确: 统一 ID 体系
def get_doc_id(doc):
    return hashlib.md5(doc.page_content.encode()).hexdigest()[:12]
```

### ❌ 错误 4: child_k 设置太小

```python
# 错误: child_k = 3, top_k = 5，Parent 数量不够
results = retriever.retrieve(query, top_k=5, child_k=3)

# 正确: child_k 应远大于 top_k
results = retriever.retrieve(query, top_k=5, child_k=20)
```

### ❌ 错误 5: 上下文压缩不处理 IRRELEVANT

```python
# 错误: 压缩后直接使用，可能返回空或无关内容
compressed = compressor.compress(query, docs)

# 正确: 过滤掉无关文档
compressed = [d for d in compressed if len(d.page_content) > 10]
```
