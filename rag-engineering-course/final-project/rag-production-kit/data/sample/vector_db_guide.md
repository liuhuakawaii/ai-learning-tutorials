# 向量数据库选型指南

## 概述

向量数据库是 RAG 系统的核心组件之一，负责存储和检索高维向量。
选择合适的向量数据库对系统的性能和可扩展性至关重要。

## 主流向量数据库

### Milvus
- 开源，支持分布式部署
- 支持多种索引类型（HNSW、IVF 等）
- 适合大规模生产环境

### Qdrant
- Rust 实现，性能优异
- 支持丰富的过滤条件
- 提供云服务和自部署选项

### Weaviate
- GraphQL API
- 内置向量化模块
- 适合快速原型开发

### Pinecone
- 全托管服务
- 使用简单，无需运维
- 适合小规模应用

### ChromaDB
- 轻量级，适合开发测试
- Python 原生支持
- 嵌入式部署

## 选型建议

| 场景 | 推荐 | 原因 |
|------|------|------|
| 生产大规模 | Milvus | 分布式、高可用 |
| 高性能需求 | Qdrant | Rust 实现、低延迟 |
| 快速原型 | ChromaDB | 简单易用 |
| 全托管 | Pinecone | 无需运维 |
