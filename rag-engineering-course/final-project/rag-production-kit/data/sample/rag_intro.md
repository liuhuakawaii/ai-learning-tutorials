# RAG 技术简介

## 什么是 RAG?

RAG (Retrieval-Augmented Generation) 是一种结合信息检索和文本生成的 AI 技术范式。
它通过从外部知识库中检索相关文档，然后将这些文档作为上下文提供给大语言模型（LLM），
从而生成更准确、更有依据的回答。

## RAG 的核心流程

RAG 系统通常包含三个主要阶段：

1. **索引阶段 (Indexing)**：将文档解析、分块、向量化后存储到向量数据库
2. **检索阶段 (Retrieval)**：根据用户查询，从向量数据库中检索相关文档
3. **生成阶段 (Generation)**：将检索到的文档与用户查询一起输入 LLM 生成答案

## RAG 的优势

- **减少幻觉**：基于真实文档生成，减少 LLM 编造信息的概率
- **知识可更新**：只需更新知识库，无需重新训练模型
- **可追溯性**：可以追溯答案来源，提高可信度
- **成本效益**：相比微调大模型，RAG 的实施成本更低

## 常见应用场景

- 企业知识库问答
- 智能客服系统
- 技术文档助手
- 法律/医疗领域问答
