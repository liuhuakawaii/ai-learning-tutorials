## 阶段概述

Stage 5 是 RAG 工程课程的核心评估阶段。在前四个阶段中，你已经构建了一个完整的 RAG 系统，
现在需要回答一个关键问题：**你的 RAG 系统到底好不好？好在哪里？差在哪里？如何持续改进？**

本阶段将从四个维度系统化解决 RAG 评估问题：

```
                    ┌─────────────────────┐
                    │   RAG 评估体系       │
                    └──────────┬──────────┘
           ┌──────────────────┼──────────────────┐
           │                  │                  │
    ┌──────▼──────┐   ┌──────▼──────┐   ┌──────▼──────┐
    │  技术评估    │   │  人工评估    │   │  业务评估    │
    │  自动化指标  │   │  标注与审核  │   │  A/B 测试    │
    └──────┬──────┘   └──────┬──────┘   └──────┬──────┘
           │                  │                  │
           └──────────────────┼──────────────────┘
                      ┌──────▼──────┐
                      │  持续优化    │
                      │  闭环迭代    │
                      └─────────────┘
```

## 课程目录

| # | 课程名称 | 时长 | 核心内容 |
|---|---------|------|---------|
| 01 | [RAG 评估体系设计](./01-RAG评估体系设计.md) | 50 min | 端到端评估框架、组件级 vs 系统级指标、评估数据集构建 |
| 02 | [RAGAS 深度实战](./02-RAGAS深度实战.md) | 55 min | RAGAS 四大指标、批量评估、自定义指标、结果可视化 |
| 03 | [人工评估与标注](./03-人工评估与标注.md) | 45 min | 标注规范设计、标注工具开发、标注一致性、人机结合 |
| 04 | [A/B 测试与灰度发布](./04-A-B测试与灰度发布.md) | 50 min | A/B 测试设计、流量分配、统计显著性、灰度发布策略 |
| 05 | [持续优化闭环](./05-持续优化闭环.md) | 45 min | 数据飞轮、反馈收集、自动化重训练、知识库更新 |
| 06 | [阶段实战：RAG 评估 Pipeline](./06-阶段实战-RAG评估pipeline.md) | 90 min | 完整评估流水线实战项目 |

## 前置要求

- ✅ Stage 1-4 全部完成
- ✅ 拥有一个可运行的 RAG 系统（至少包含基础的检索+生成功能）
- ✅ 熟悉 Python 编程和基本的统计学概念

## 学习目标

完成 Stage 5 后，你将能够：

1. **设计评估体系** — 为 RAG 系统构建完整的评估框架，涵盖组件级和系统级指标
2. **使用 RAGAS** — 熟练运用 RAGAS 框架进行自动化评估，包括自定义指标
3. **组织人工评估** — 设计标注规范、开发标注工具、计算标注一致性
4. **实施 A/B 测试** — 设计实验、分配流量、计算统计显著性、执行灰度发布
5. **构建优化闭环** — 建立数据飞轮，实现从反馈到改进的自动化循环
6. **端到端实战** — 构建完整的 RAG 评估 Pipeline
