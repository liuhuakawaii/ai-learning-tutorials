# Stage 5：云原生生态

> 6 课时 | 探索 Kubernetes 之上的高级生态和前沿实践

## 阶段概述

前四个阶段你掌握了 K8s 的核心能力和运维实践。这个阶段向更广阔的云原生生态延伸：Serverless 让你不用管扩缩容、Service Mesh 让你精细控制微服务流量、GPU 调度让你在 K8s 上跑 AI 工作负载、多集群管理解决跨区域部署问题、成本优化帮你省下真金白银。

## 学习目标

完成本阶段后，你能够：

1. 使用 Knative 在 K8s 上运行 Serverless 工作负载
2. 理解 Service Mesh 的核心概念和 Istio 基本用法
3. 在 K8s 上调度 GPU 资源并部署 AI 模型服务
4. 管理多个 K8s 集群的部署和配置
5. 分析和优化 K8s 集群的资源成本
6. 搭建一个云原生 AI 推理平台

## 学习建议

- 本阶段内容偏进阶，建议先完成前四个阶段
- Serverless 和 Service Mesh 是选学内容，根据实际需求决定深入程度
- GPU 调度和 AI 工作负载是当前热门方向，值得重点投入
- 成本优化是企业级 K8s 运营的必备技能
