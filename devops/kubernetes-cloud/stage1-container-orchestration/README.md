# Stage 1：容器编排基础

> 6 课时 | 从 Docker 过渡到 Kubernetes 编排思维

## 阶段概述

你已经会用 Docker 构建和运行容器。但当应用从一个容器变成十几个容器——前端、后端、数据库、缓存、消息队列——手动管理变得不现实。这个阶段解决的核心问题是：**如何自动化管理大量容器？**

## 学习目标

完成本阶段后，你能够：

1. 理解容器编排的必要性和核心价值
2. 描述 Kubernetes 的整体架构和组件职责
3. 使用 kubectl 与集群进行日常交互
4. 深入理解 Pod 的生命周期和高级特性
5. 合理配置资源请求与限制
6. 在本地搭建完整的 K8s 集群用于开发和测试

## 学习建议

- 如果你只有 Docker 基础，第 1 课是必要的过渡
- 第 2-3 课是后续所有内容的基础，务必动手操作
- 第 4-5 课是区分"会用"和"用好"K8s 的关键
- 第 6 课的本地集群会在后续所有阶段中使用
