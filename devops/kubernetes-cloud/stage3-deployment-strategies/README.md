# Stage 3：部署策略

> 6 课时 | 从手动 kubectl 到自动化、零停机部署

## 阶段概述

Stage 2 你已经能把应用部署到 K8s 了。但"部署"这件事远不止 `kubectl apply`。生产环境需要零停机发布、需要快速回滚、需要多环境一致性。这个阶段解决的核心问题是：**如何安全、高效、可重复地将代码变更推送到生产环境？**

## 学习目标

完成本阶段后，你能够：

1. 使用 Helm 打包和管理 K8s 应用
2. 实现蓝绿部署实现零停机发布
3. 配置金丝雀发布进行渐进式流量切换
4. 使用 ArgoCD/Flux 建立 GitOps 工作流
5. 管理 Dev/Staging/Prod 多环境配置
6. 搭建端到端的 GitOps 流水线

## 学习建议

- Helm 是 K8s 生态的事实标准包管理器，第 1 课是后续课程的基础
- 蓝绿部署和金丝雀发布是生产环境必备技能，理解原理后重点看实现
- GitOps 是当前行业最佳实践，建议完整走一遍 ArgoCD 的流程
