# Stage 4：可观测性与运维

> 6 课时 | 让集群和应用的运行状态可见、可查、可预警

## 阶段概述

应用部署上线只是开始。真正考验运维能力的是：出了问题能不能快速发现？发现了能不能快速定位？定位了能不能快速修复？这个阶段围绕可观测性三大支柱——指标（Metrics）、日志（Logs）、追踪（Traces）展开，同时覆盖故障排查和安全加固。

## 学习目标

完成本阶段后，你能够：

1. 使用 Prometheus 采集和查询集群与应用指标
2. 使用 Grafana 设计监控 Dashboard
3. 搭建 EFK/Loki 日志收集和查询体系
4. 掌握 K8s 故障排查的系统方法
5. 实施 RBAC、NetworkPolicy 和 Pod Security 安全策略
6. 搭建完整的监控告警体系

## 学习建议

- Prometheus + Grafana 是 K8s 监控的黄金组合，第 1-2 课务必动手搭建
- 日志体系选择 Loki（轻量）或 EFK（功能全），根据团队规模决定
- 故障排查能力需要大量实践，建议故意制造故障再修复
- 安全加固不是可选项，第 5 课的内容应该在生产环境落地
