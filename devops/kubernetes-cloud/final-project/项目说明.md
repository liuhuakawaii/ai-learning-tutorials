# 毕业项目：云原生 AI 推理平台

## 项目目标

搭建一个完整的云原生 AI 推理平台，综合运用课程中学到的所有核心技能。平台需要支持多环境部署、自动化发布、完整的可观测性、安全加固，并能弹性处理 AI 推理请求。

## 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Vue3 + Nginx | 用户交互界面 |
| API 服务 | Python FastAPI | 业务逻辑和推理调度 |
| 模型服务 | vLLM / TGI | LLM 推理引擎 |
| 数据库 | PostgreSQL | 会话和用户数据 |
| 缓存 | Redis | 推理结果缓存 |
| 包管理 | Helm Chart | 应用打包和部署 |
| 部署 | ArgoCD + GitOps | 声明式自动化部署 |
| 监控 | Prometheus + Grafana | 指标采集和可视化 |
| 日志 | Loki + Promtail | 日志收集和查询 |
| 安全 | RBAC + NetworkPolicy | 访问控制和网络隔离 |

## 分阶段完成要求

### Stage 1 交付物

- [ ] 本地 K8s 集群可正常运行（Kind 或 Minikube）
- [ ] 集群包含至少 2 个 Worker Node
- [ ] kubectl 能正常连接和操作集群
- [ ] 提交 Stage 1 报告

### Stage 2 交付物

- [ ] API 服务 Deployment 部署成功，3 副本运行
- [ ] Service 能正常暴露 API 服务
- [ ] Ingress 配置完成，可通过域名访问
- [ ] ConfigMap 和 Secret 配置正确注入
- [ ] PostgreSQL 使用 StatefulSet 部署，数据持久化
- [ ] 提交 Stage 2 报告

### Stage 3 交付物

- [ ] Helm Chart 开发完成，支持 `helm install` 一键部署
- [ ] values.yaml 区分 staging 和 prod 配置
- [ ] 蓝绿部署方案设计和实现
- [ ] 金丝雀发布方案设计和实现
- [ ] ArgoCD 配置完成，Git push 触发自动部署
- [ ] 提交 Stage 3 报告

### Stage 4 交付物

- [ ] Prometheus 采集集群和应用指标
- [ ] Grafana Dashboard 展示关键指标
- [ ] Loki 日志收集正常工作
- [ ] 告警规则配置完成（CPU、内存、错误率）
- [ ] RBAC 和 NetworkPolicy 安全策略实施
- [ ] 提交 Stage 4 报告

### Stage 5 交付物

- [ ] 模型服务支持 GPU 调度（如有 GPU 资源）
- [ ] HPA 配置完成，支持自动扩缩容
- [ ] 资源成本分析报告
- [ ] 完整的平台端到端测试通过
- [ ] 提交 Stage 5 报告

## 验证方式

```bash
cd kubernetes-cloud-course/final-project
node scripts/check.cjs
```
