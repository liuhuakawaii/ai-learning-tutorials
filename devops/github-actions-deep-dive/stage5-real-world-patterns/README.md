# 第五阶段：实战模式

## 阶段目标

掌握 Monorepo CI、Docker 构建优化、部署模式和 CI 监控等实战模式，能为 Monorepo 项目设计完整的 CI/CD 方案。

## 课时列表

1. [Monorepo CI——路径过滤、增量构建、Turborepo 集成](21-monorepo-ci.md)
2. [Docker 构建优化——BuildKit、多平台构建、镜像推送](22-docker-build-optimization.md)
3. [部署模式——蓝绿部署、金丝雀发布、自动回滚](23-deployment-patterns.md)
4. [CI 监控——构建时长趋势、失败率、缓存命中率](24-ci-monitoring.md)
5. [阶段实战：为一个 Monorepo 项目设计完整的 CI/CD 方案](25-stage-project-monorepo-cicd.md)

## 验收标准

- 能为 Monorepo 配置路径过滤和增量构建
- 能用 BuildKit 优化 Docker 构建速度并实现多平台构建
- 能实现蓝绿部署或金丝雀发布并配置自动回滚
- 能搭建 CI 监控看板跟踪构建时长、失败率和缓存命中率
