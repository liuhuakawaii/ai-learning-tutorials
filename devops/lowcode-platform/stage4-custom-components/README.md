# 阶段四：自定义组件

> 6 课时 | 掌握低代码平台的组件开发体系

## 阶段目标

- 理解低代码组件的规范和生命周期
- 能开发自定义图表组件（ECharts/D3）
- 能集成代码编辑器、富文本等复杂编辑器组件
- 掌握地图、支付、IM 等第三方服务集成
- 理解组件市场的设计和版本管理
- 能构建完整的团队组件库

## 学习建议

1. 先理解低代码平台的组件规范，再动手开发
2. 图表组件是高频需求，建议重点掌握
3. 组件库实战建议基于 React 或 Vue 完成
