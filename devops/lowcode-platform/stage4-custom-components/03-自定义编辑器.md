# 自定义编辑器：代码编辑器、富文本与 Markdown

## 场景引入

低代码平台的典型场景是内容管理系统（CMS）。运营团队需要编辑文章（富文本）、开发者写 SQL 查询（代码编辑器）、技术团队写文档（Markdown）。如果平台只有通用文本输入框，体验会非常粗糙。

本节课讲解如何集成 Monaco Editor、富文本编辑器和 Markdown 编辑器，以及内容安全和文件嵌入等工程问题。

## 学习目标

- 掌握 Monaco Editor 在低代码组件中的集成与配置
- 理解富文本编辑器（TipTap）的架构和接入方式
- 能实现带实时预览的 Markdown 编辑器
- 了解内容安全（XSS 防护）和文件嵌入的工程实践

## Monaco Editor 集成

Monaco Editor 是 VS Code 的核心组件，支持语法高亮、智能补全、错误提示。常用于 SQL 编辑器、JSON 配置编辑器等场景。

```typescript
import React, { useEffect, useRef } from 'react';
import * as monaco from 'monaco-editor';

interface CodeEditorProps {
  language: string; value: string;
  onChange?: (value: string) => void;
  theme?: 'vs' | 'vs-dark' | 'hc-black';
  readOnly?: boolean; fontSize?: number;
}

const CodeEditor: React.FC<CodeEditorProps> = (rawProps) => {
  const props = { language: 'javascript', value: '', theme: 'vs', readOnly: false, fontSize: 14, ...rawProps };
  const containerRef = useRef<HTMLDivElement>(null);
  const editorRef = useRef<monaco.editor.IStandaloneCodeEditor | null>(null);
  const onChangeRef = useRef(props.onChange);
  onChangeRef.current = props.onChange;

  useEffect(() => {
    if (!containerRef.current) return;
    const editor = monaco.editor.create(containerRef.current, {
      value: props.value, language: props.language, theme: props.theme,
      readOnly: props.readOnly, fontSize: props.fontSize,
      automaticLayout: true, scrollBeyondLastLine: false, tabSize: 2,
    });
    editor.onDidChangeModelContent(() => onChangeRef.current?.(editor.getValue()));
    editorRef.current = editor;
    return () => editor.dispose();
  }, []);

  useEffect(() => {
    if (editorRef.current && editorRef.current.getValue() !== props.value) editorRef.current.setValue(props.value);
  }, [props.value]);

  return <div ref={containerRef} style={{ width: '100%', height: 300, border: '1px solid #d9d9d9' }} />;
};
```

### SQL 自动补全

```typescript
function registerSqlCompletion(tables: { name: string; columns: string[] }[]) {
  monaco.languages.registerCompletionItemProvider('sql', {
    provideCompletionItems: (model, position) => {
      const word = model.getWordUntilPosition(position);
      const range = { startLineNumber: position.lineNumber, endLineNumber: position.lineNumber, startColumn: word.startColumn, endColumn: word.endColumn };
      const suggestions: monaco.languages.CompletionItem[] = [];

      tables.forEach(table => {
        suggestions.push({ label: table.name, kind: monaco.languages.CompletionItemKind.Struct, insertText: table.name, range, detail: '表名' });
        table.columns.forEach(col => suggestions.push({ label: `${table.name}.${col}`, kind: monaco.languages.CompletionItemKind.Field, insertText: col, range, detail: `${table.name} 的字段` }));
      });

      ['SELECT','FROM','WHERE','JOIN','GROUP BY','ORDER BY','LIMIT'].forEach(kw =>
        suggestions.push({ label: kw, kind: monaco.languages.CompletionItemKind.Keyword, insertText: kw, range }));

      return { suggestions };
    },
  });
}
```

## 富文本编辑器（TipTap）

TipTap 基于 ProseMirror，提供声明式扩展系统，适合深度定制：

```typescript
import React from 'react';
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import Image from '@tiptap/extension-image';
import Link from '@tiptap/extension-link';

interface RichTextEditorProps {
  content: string;
  onChange?: (html: string) => void;
  maxLength?: number; allowImage?: boolean;
}

const RichTextEditor: React.FC<RichTextEditorProps> = (rawProps) => {
  const props = { content: '', maxLength: 50000, allowImage: true, ...rawProps };
  const extensions = [StarterKit, Link.configure({ openOnClick: false }), ...(props.allowImage ? [Image] : [])];

  const editor = useEditor({
    extensions, content: props.content,
    onUpdate: ({ editor }) => {
      const html = editor.getHTML();
      if (html.length <= props.maxLength) props.onChange?.(html);
    },
  });

  return (
    <div className="rich-text-editor">
      <div className="toolbar">
        <button onClick={() => editor?.chain().focus().toggleBold().run()} className={editor?.isActive('bold') ? 'active' : ''}>B</button>
        <button onClick={() => editor?.chain().focus().toggleItalic().run()} className={editor?.isActive('italic') ? 'active' : ''}>I</button>
        <button onClick={() => editor?.chain().focus().toggleHeading({ level: 2 }).run()}>H2</button>
        <button onClick={() => editor?.chain().focus().toggleBulletList().run()}>列表</button>
        <button onClick={() => { const url = prompt('请输入链接'); if (url) editor?.chain().focus().setLink({ href: url }).run(); }}>链接</button>
      </div>
      <EditorContent editor={editor} />
    </div>
  );
};
```

## Markdown 编辑器

左右分栏（左边编辑、右边实时预览）：

```typescript
import React, { useState, useMemo } from 'react';
import ReactMarkdown from 'react-markdown';
import remarkGfm from 'remark-gfm';
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter';

interface MarkdownEditorProps { value: string; onChange?: (value: string) => void; height?: number; }

const MarkdownEditor: React.FC<MarkdownEditorProps> = (rawProps) => {
  const props = { value: '', height: 500, ...rawProps };
  const [content, setContent] = useState(props.value);

  const renderers = useMemo(() => ({
    code({ inline, className, children, ...rest }: any) {
      const match = /language-(\w+)/.exec(className || '');
      return !inline && match
        ? <SyntaxHighlighter language={match[1]} PreTag="div" {...rest}>{String(children).replace(/\n$/, '')}</SyntaxHighlighter>
        : <code className={className} {...rest}>{children}</code>;
    },
  }), []);

  return (
    <div style={{ display: 'flex', height: props.height }}>
      <textarea value={content} onChange={e => { setContent(e.target.value); props.onChange?.(e.target.value); }}
        style={{ flex: 1, padding: 12, fontFamily: 'monospace', resize: 'none', borderRight: '1px solid #d9d9d9' }} />
      <div style={{ flex: 1, padding: 12, overflow: 'auto' }}>
        <ReactMarkdown remarkPlugins={[remarkGfm]} components={renderers}>{content}</ReactMarkdown>
      </div>
    </div>
  );
};
```

## 内容安全（XSS 防护）

富文本和 Markdown 输出是 HTML，必须过滤后才能渲染：

```typescript
import DOMPurify from 'dompurify';

function sanitizeContent(html: string): string {
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS: ['p','br','strong','em','u','s','h1','h2','h3','h4','ul','ol','li','a','img','table','thead','tbody','tr','th','td','blockquote','code','pre','hr'],
    ALLOWED_ATTR: ['href','src','alt','title','class','target','width','height'],
    ALLOW_DATA_ATTR: false,
  });
}

const SafeHtmlRenderer: React.FC<{ html: string }> = ({ html }) => {
  const safeHtml = useMemo(() => sanitizeContent(html), [html]);
  return <div dangerouslySetInnerHTML={{ __html: safeHtml }} />;
};
```

## 文件与图片嵌入

```typescript
async function uploadFile(file: File, uploadUrl: string): Promise<{ url: string; name: string }> {
  const formData = new FormData();
  formData.append('file', file);
  const res = await fetch(uploadUrl, { method: 'POST', body: formData });
  if (!res.ok) throw new Error('上传失败');
  return res.json();
}

function handleImageUpload(editor: any, uploadUrl: string) {
  const input = document.createElement('input');
  input.type = 'file'; input.accept = 'image/*';
  input.onchange = async () => {
    const file = input.files?.[0];
    if (!file) return;
    if (file.size > 5 * 1024 * 1024) { alert('图片不能超过 5MB'); return; }
    const result = await uploadFile(file, uploadUrl);
    editor.chain().focus().setImage({ src: result.url, alt: result.name }).run();
  };
  input.click();
}
```

## 常见误区

1. **富文本不做 XSS 过滤**：直接 dangerouslySetInnerHTML 渲染用户 HTML，必须经 DOMPurify 过滤。
2. **Monaco Editor 打包体积过大**：完整包约 5MB，应使用 webpack 插件按需加载语言支持。
3. **编辑器内容不做自动保存**：页面意外关闭会丢失内容，应用 localStorage 或防抖自动保存。

## 工程建议

1. **按场景选择编辑器**：纯文本/SQL 用 Monaco，文章用 TipTap，技术文档用 Markdown。
2. **onChange 做防抖处理**：富文本 onUpdate 每次按键触发，300ms 防抖减少不必要重渲染。
3. **提供 readOnly 模式**：平台预览模式需禁用编辑能力和工具栏。

## 小结

- Monaco Editor 适合代码编辑场景，核心是配置语言支持和自动补全。
- TipTap 是富文本编辑主流方案，扩展系统适合深度定制。
- Markdown 编辑器核心是左右分栏和实时预览。
- 所有 HTML 输出必须经 XSS 过滤（DOMPurify）后才能渲染。

## 参考答案

### 练习一

**思路**：createModel 指定 JSON 语言，marker 做错误标记，try/catch 校验 JSON 合法性。

**答案**：
```typescript
import React, { useEffect, useRef } from 'react';
import * as monaco from 'monaco-editor';

interface JsonEditorProps { value: string; onChange?: (validJson: string) => void; readOnly?: boolean; }

const JsonEditor: React.FC<JsonEditorProps> = (rawProps) => {
  const props = { value: '{}', readOnly: false, ...rawProps };
  const containerRef = useRef<HTMLDivElement>(null);
  const onChangeRef = useRef(props.onChange);
  onChangeRef.current = props.onChange;

  useEffect(() => {
    if (!containerRef.current) return;
    const model = monaco.editor.createModel(props.value, 'json');
    const editor = monaco.editor.create(containerRef.current, { model, readOnly: props.readOnly, automaticLayout: true, tabSize: 2 });

    editor.addCommand(monaco.KeyMod.Shift | monaco.KeyMod.Alt | monaco.KeyCode.KeyF, () => editor.getAction('editor.action.formatDocument')?.run());

    editor.onDidChangeModelContent(() => {
      const value = editor.getValue();
      try {
        JSON.parse(value);
        monaco.editor.setModelMarkers(model, 'owner', []);
        onChangeRef.current?.(value);
      } catch (e: any) {
        const match = e.message.match(/position (\d+)/);
        const pos = match ? model.getPositionAt(parseInt(match[1])) : { lineNumber: 1, column: 1 };
        monaco.editor.setModelMarkers(model, 'owner', [{ severity: monaco.MarkerSeverity.Error, message: e.message, startLineNumber: pos.lineNumber, startColumn: pos.column, endLineNumber: pos.lineNumber, endColumn: pos.column + 1 }]);
      }
    });

    return () => { model.dispose(); editor.dispose(); };
  }, []);

  return <div ref={containerRef} style={{ width: '100%', height: 300, border: '1px solid #d9d9d9' }} />;
};
```

**要点**：setModelMarkers 清空错误标记实现合法时无红色波浪线；onChangeRef 用 ref 存回调避免依赖问题。

### 练习二

**思路**：正则逐层过滤——先移除 script 标签，再移除 on* 属性，再过滤 javascript: 协议。

**答案**：
```typescript
function sanitizeContent(html: string): string {
  let result = html;
  result = result.replace(/<script\b[^<]*(?:(?!<\/script>)<[^<]*)*<\/script>/gi, '');
  result = result.replace(/<style\b[^<]*(?:(?!<\/style>)<[^<]*)*<\/style>/gi, '');
  result = result.replace(/\s+on\w+\s*=\s*["'][^"']*["']/gi, '');
  result = result.replace(/\s+on\w+\s*=\s*[^\s>]*/gi, '');
  result = result.replace(/href\s*=\s*["']javascript:[^"']*["']/gi, 'href="#"');
  result = result.replace(/src\s*=\s*["']javascript:[^"']*["']/gi, 'src=""');
  result = result.replace(/src\s*=\s*["']data:[^"']*["']/gi, 'src=""');
  return result;
}
```

**要点**：href 中 javascript: 是常见攻击向量必须单独处理；生产环境建议用 DOMPurify 库更安全。
