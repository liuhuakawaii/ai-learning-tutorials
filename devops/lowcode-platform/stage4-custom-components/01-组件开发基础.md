# 组件开发基础：规范、Props、事件与生命周期

## 场景引入

某企业低代码平台上线半年，内置的 30 多个基础组件已不够用——产品经理需要「进度条+标签+操作按钮」的复合组件，财务部门需要金额自动格式化的专用输入框。平台团队面临选择：不断往核心包塞新组件，还是开放组件开发能力让业务团队自己扩展？

后者需要一套完善的组件规范，让第三方组件能安全、稳定地运行在平台中。本节课将讲解低代码组件的开发规范、Props 定义、事件系统和生命周期钩子。

## 学习目标

- 理解低代码组件与传统前端组件的区别
- 掌握组件清单文件 manifest.json 的结构与字段定义
- 能设计类型安全的 Props 系统（类型、默认值、校验、联动）
- 理解组件事件模型和生命周期钩子的使用场景

## 低代码组件 vs 传统前端组件

传统组件通过代码调用、props 传值。低代码组件需同时服务两个受众：**平台运行时**（渲染执行）和**配置者**（设计器中拖拽配置）。因此除了 UI 逻辑，还需要**元数据描述**——告诉平台有哪些属性可配置、支持哪些事件、数据源怎么绑定。

```
传统组件：代码调用 → 渲染
低代码组件：manifest.json → 设计器配置面板 → 运行时渲染
```

## 组件清单 manifest.json

```json
{
  "name": "ProgressTag",
  "version": "1.0.0",
  "description": "带进度条和状态标签的复合展示组件",
  "category": "data-display",
  "component": "./ProgressTag.tsx",
  "props": {
    "percent": { "type": "number", "default": 0, "label": "进度百分比", "min": 0, "max": 100 },
    "status": { "type": "string", "default": "active", "options": ["active", "success", "exception", "normal"], "label": "状态类型" },
    "showLabel": { "type": "boolean", "default": true, "label": "是否显示标签" },
    "color": { "type": "color", "default": "#1890ff", "label": "进度条颜色" }
  },
  "events": ["onChange", "onRetry"],
  "slots": ["suffix"],
  "size": { "width": 300, "height": 60 }
}
```

| 字段 | 作用 | 必填 |
|------|------|------|
| name | 组件唯一标识，驼峰命名 | 是 |
| version | 语义化版本号 | 是 |
| component | 组件代码入口路径 | 是 |
| props | 属性定义，控制配置面板 | 是 |
| events | 可触发的事件列表 | 否 |

## Props 系统设计

### 类型定义与校验

```typescript
interface PropDefinition {
  type: 'string' | 'number' | 'boolean' | 'object' | 'array' | 'color' | 'date' | 'json' | 'select' | 'api';
  default?: unknown;
  required?: boolean;
  label: string;
  validator?: (value: unknown) => boolean | string;
}
```

### 带校验的组件实现

```typescript
import React from 'react';

interface ProgressTagProps {
  percent: number;
  status: 'active' | 'success' | 'exception' | 'normal';
  showLabel: boolean;
  color: string;
  onChange?: (value: number) => void;
}

const defaultProps: ProgressTagProps = {
  percent: 0, status: 'active', showLabel: true, color: '#1890ff',
};

const ProgressTag: React.FC<Partial<ProgressTagProps>> = (rawProps) => {
  const props = { ...defaultProps, ...rawProps };
  const safePercent = Math.max(0, Math.min(100, Number(props.percent) || 0));
  const statusColors = { active: props.color, success: '#52c41a', exception: '#ff4d4f', normal: '#d9d9d9' };

  return (
    <div className="progress-tag">
      <div className="progress-bar" style={{ width: `${safePercent}%`, backgroundColor: statusColors[props.status] }} />
      {props.showLabel && <span className="label">{safePercent}%</span>}
    </div>
  );
};
```

### Props 联动

manifest.json 中用表达式控制属性显隐：

```json
{
  "props": {
    "color": {
      "type": "color", "label": "自定义颜色",
      "visible": "{{ props.status === 'active' || props.status === 'normal' }}"
    }
  }
}
```

## 事件系统

事件支持两个方向：**组件→平台**（用户点击）、**平台→组件**（触发提交）。

```typescript
interface ComponentEvent {
  name: string;
  label: string;
  params?: { name: string; type: string; description: string }[];
}

const handleClick = () => {
  props.onClick?.({ timestamp: Date.now(), percent: safePercent });
};
```

事件配置面板让配置者将事件关联到平台动作（打开弹窗、刷新数据源、跳转页面）。

## 生命周期钩子

低代码组件生命周期比传统组件多一层——还需响应数据源变化和配置变更：

```typescript
import { useEffect, useRef } from 'react';

const DataChart: React.FC<DataChartProps> = (props) => {
  const chartRef = useRef<HTMLDivElement>(null);
  const instanceRef = useRef<echarts.ECharts | null>(null);

  // onMount
  useEffect(() => {
    if (chartRef.current) {
      instanceRef.current = echarts.init(chartRef.current);
      instanceRef.current.setOption(props.option);
    }
    return () => { instanceRef.current?.dispose(); }; // onUnmount
  }, []);

  // onDataChange
  useEffect(() => {
    instanceRef.current?.setOption({ series: [{ data: props.dataSource }] });
  }, [props.dataSource]);

  return <div ref={chartRef} style={{ width: '100%', height: 300 }} />;
};
```

## 组件沙箱与隔离

第三方组件用 iframe 沙箱隔离，限制全局对象访问：

```typescript
function createSandbox(componentCode: string): HTMLIFrameElement {
  const iframe = document.createElement('iframe');
  iframe.sandbox.add('allow-scripts');
  document.body.appendChild(iframe);
  const doc = iframe.contentDocument!;
  doc.open();
  doc.write(`<html><body><div id="root"></div>
    <script>['fetch','XMLHttpRequest','eval'].forEach(k => window[k] = undefined);</script>
    <script>${componentCode}</script></body></html>`);
  doc.close();
  return iframe;
}
```

## 组件注册与发现

```typescript
class ComponentRegistry {
  private components = new Map<string, ComponentMeta>();

  register(manifest: ComponentMeta) {
    if (this.components.has(manifest.name)) throw new Error(`组件 ${manifest.name} 已存在`);
    this.components.set(manifest.name, { ...manifest, registeredAt: Date.now() });
  }

  get(name: string) { return this.components.get(name); }

  listByCategory(category: string) {
    return Array.from(this.components.values()).filter(c => c.category === category);
  }

  search(keyword: string) {
    const lower = keyword.toLowerCase();
    return Array.from(this.components.values()).filter(c =>
      c.name.toLowerCase().includes(lower) || c.description?.toLowerCase().includes(lower));
  }
}
```

## 常见误区

1. **把低代码组件当普通 React 组件写**：忽略 manifest.json，导致组件无法在设计器中配置。
2. **Props 不做校验和降级**：配置者可能输入意外值，组件必须对所有输入做安全处理。
3. **生命周期中遗漏清理逻辑**：onUnmount 不销毁第三方实例导致内存泄漏。

## 工程建议

1. **先写 manifest.json 再写组件代码**：清单文件是组件的「契约」，先定义好接口再实现逻辑。
2. **为每个 Prop 提供合理的默认值**：配置者可能只修改部分属性，组件在默认值下应能正常渲染。
3. **组件粒度控制在单一职责**：复合需求通过平台容器组件组合实现，而非一个组件塞入过多功能。

## 小结

- 低代码组件比传统组件多了一层元数据描述（manifest.json），同时服务于设计器和运行时。
- Props 系统需要支持类型约束、默认值校验、动态选项和属性联动。
- 事件系统是组件与平台的通信桥梁，需要声明式定义和结构化参数。
- 生命周期钩子还需处理数据源变化和配置变更。
- 安全隔离（沙箱）是运行第三方组件的必要措施。

## 参考答案

### 练习一

**思路**：头像、名称、角色各设计可配置属性，角色用 select 限定选项，头像大小用 number 设边界。

**答案**：
```json
{
  "name": "UserBadge", "version": "1.0.0", "category": "data-display",
  "component": "./UserBadge.tsx",
  "props": {
    "avatarUrl": { "type": "string", "default": "", "label": "头像地址" },
    "userName": { "type": "string", "default": "未命名用户", "required": true, "label": "用户名称" },
    "role": { "type": "select", "default": "member", "options": ["admin","editor","member","guest"], "label": "用户角色" },
    "avatarSize": { "type": "number", "default": 40, "min": 24, "max": 120, "label": "头像尺寸" },
    "showRole": { "type": "boolean", "default": true, "label": "是否显示角色标签" },
    "tagColor": { "type": "color", "default": "#1890ff", "label": "角色标签颜色" }
  },
  "events": [{ "name": "onClick", "label": "点击用户", "params": [{ "name": "userName", "type": "string", "description": "被点击的用户名" }] }],
  "slots": ["extra"]
}
```

**要点**：role 用 select 限定枚举值；avatarSize 设 min/max 边界防极端值。

### 练习二

**思路**：用 useEffect 处理 onMount/onUnmount，对 avatarUrl 做空值降级，avatarSize 做边界保护。

**答案**：
```typescript
import React, { useEffect, useRef } from 'react';

interface UserBadgeProps {
  avatarUrl?: string; userName: string; role?: 'admin' | 'editor' | 'member' | 'guest';
  avatarSize?: number; showRole?: boolean; tagColor?: string;
  onClick?: (data: { userName: string }) => void;
}

const roleLabels: Record<string, string> = { admin: '管理员', editor: '编辑者', member: '成员', guest: '访客' };

const UserBadge: React.FC<UserBadgeProps> = (rawProps) => {
  const props = { avatarUrl: '', userName: '未命名用户', role: 'member' as const, avatarSize: 40, showRole: true, tagColor: '#1890ff', ...rawProps };
  const timerRef = useRef<ReturnType<typeof setInterval> | null>(null);

  useEffect(() => {
    console.log(`[UserBadge] 已挂载: ${props.userName}`);
    timerRef.current = setInterval(() => {}, 30000);
    return () => {
      if (timerRef.current) { clearInterval(timerRef.current); timerRef.current = null; }
      console.log(`[UserBadge] 已卸载: ${props.userName}`);
    };
  }, []);

  const safeSize = Math.max(24, Math.min(120, Number(props.avatarSize) || 40));
  const displayName = String(props.userName || '未命名用户').slice(0, 20);
  const src = props.avatarUrl || `https://ui-avatars.com/api/?name=${encodeURIComponent(displayName)}&size=${safeSize}`;

  return (
    <div className="user-badge" onClick={() => props.onClick?.({ userName: displayName })}>
      <img src={src} alt={displayName} width={safeSize} height={safeSize} style={{ borderRadius: '50%' }} />
      <span className="name">{displayName}</span>
      {props.showRole && <span className="role-tag" style={{ backgroundColor: props.tagColor }}>{roleLabels[props.role]}</span>}
    </div>
  );
};
```

**要点**：Math.max/min 边界保护防极端值；userName slice 截断防布局破坏；useEffect 返回清理函数。
