# 自定义图表组件：ECharts/D3 集成与数据绑定

## 场景引入

数据分析平台的运营看板是低代码平台最常用的场景之一。产品经理要求看板包含销售趋势折线图、区域分布饼图、关键指标雷达图，数据从后端 API 实时拉取，每 30 秒自动刷新。

传统开发需要前端逐一接入图表库、处理数据格式、编写轮询逻辑。而在低代码平台中，如果图表组件设计得当，配置者只需：拖入组件 → 选择图表类型 → 绑定数据源 → 设置刷新频率，全程无需写代码。

本节课将讲解如何集成 ECharts 和 D3.js，设计灵活的数据绑定协议，让图表组件既强大又易用。

## 学习目标

- 掌握 ECharts 在低代码组件中的集成方式
- 理解数据绑定协议（静态/API/实时）的设计
- 能实现图表配置面板与代码的映射
- 了解 D3.js 在自定义可视化中的应用

## ECharts 集成

ECharts 是国内低代码平台最常用的图表库。集成的核心挑战是将其 500+ 配置项映射到可视化配置面板。

### 基础图表组件

```typescript
import React, { useEffect, useRef, useCallback } from 'react';
import * as echarts from 'echarts';

interface ChartComponentProps {
  chartType: 'bar' | 'line' | 'pie' | 'scatter' | 'radar';
  data: Record<string, unknown>[];
  option?: echarts.EChartsOption;
  theme?: string;
  autoResize?: boolean;
  onDataPointClick?: (params: { name: string; value: unknown }) => void;
}

const ChartComponent: React.FC<ChartComponentProps> = ({ chartType, data, option, theme, autoResize = true, onDataPointClick }) => {
  const containerRef = useRef<HTMLDivElement>(null);
  const chartRef = useRef<echarts.ECharts | null>(null);

  useEffect(() => {
    if (!containerRef.current) return;
    chartRef.current = echarts.init(containerRef.current, theme);
    chartRef.current.on('click', (params: echarts.ECElementEvent) => {
      onDataPointClick?.({ name: String(params.name || ''), value: params.value });
    });
    return () => { chartRef.current?.dispose(); };
  }, [theme]);

  useEffect(() => {
    if (!chartRef.current) return;
    chartRef.current.setOption(option || buildOptionFromData(chartType, data), { notMerge: true });
  }, [chartType, data, option]);

  useEffect(() => {
    if (!autoResize || !chartRef.current) return;
    const obs = new ResizeObserver(() => chartRef.current?.resize());
    if (containerRef.current) obs.observe(containerRef.current);
    return () => obs.disconnect();
  }, [autoResize]);

  return <div ref={containerRef} style={{ width: '100%', height: '100%', minHeight: 200 }} />;
};
```

### 从数据自动构建配置

```typescript
function buildOptionFromData(chartType: string, data: Record<string, unknown>[]): echarts.EChartsOption {
  if (!data?.length) return { title: { text: '暂无数据', left: 'center', top: 'center' } };

  const keys = Object.keys(data[0]);
  const categories = data.map(item => String(item[keys[0]]));
  const values = data.map(item => Number(item[keys[1]]) || 0);

  switch (chartType) {
    case 'bar': case 'line':
      return { tooltip: { trigger: 'axis' }, xAxis: { type: 'category', data: categories }, yAxis: { type: 'value' }, series: [{ type: chartType, data: values }] };
    case 'pie':
      return { tooltip: { trigger: 'item' }, series: [{ type: 'pie', data: data.map(item => ({ name: String(item[keys[0]]), value: Number(item[keys[1]]) || 0 })) }] };
    case 'scatter':
      return { tooltip: { trigger: 'item' }, xAxis: { type: 'value' }, yAxis: { type: 'value' }, series: [{ type: 'scatter', data: data.map(item => [Number(item[keys[0]]), Number(item[keys[1]])]) }] };
    default: return {};
  }
}
```

## 数据绑定协议

```typescript
interface DataBinding {
  mode: 'static' | 'api' | 'realtime';
  staticData?: Record<string, unknown>[];
  apiConfig?: {
    url: string; method: 'GET' | 'POST';
    headers?: Record<string, string>; params?: Record<string, unknown>;
    dataPath: string;       // JSONPath 提取数据
    refreshInterval?: number; // 自动刷新间隔（秒）
  };
  realtimeConfig?: { url: string; topic: string };
}
```

### 数据源执行引擎

```typescript
class DataSourceEngine {
  private intervals = new Map<string, ReturnType<typeof setInterval>>();

  async resolve(binding: DataBinding): Promise<Record<string, unknown>[]> {
    switch (binding.mode) {
      case 'static': return binding.staticData || [];
      case 'api': return this.fetchFromApi(binding.apiConfig!);
      default: return [];
    }
  }

  startAutoRefresh(id: string, binding: DataBinding, callback: (data: Record<string, unknown>[]) => void) {
    if (binding.mode !== 'api' || !binding.apiConfig?.refreshInterval) return;
    this.stopAutoRefresh(id);
    const interval = setInterval(async () => {
      callback(await this.fetchFromApi(binding.apiConfig!));
    }, binding.apiConfig.refreshInterval * 1000);
    this.intervals.set(id, interval);
  }

  stopAutoRefresh(id: string) {
    const interval = this.intervals.get(id);
    if (interval) { clearInterval(interval); this.intervals.delete(id); }
  }

  private async fetchFromApi(config: NonNullable<DataBinding['apiConfig']>): Promise<Record<string, unknown>[]> {
    try {
      const response = await fetch(config.url, {
        method: config.method, headers: { 'Content-Type': 'application/json', ...config.headers },
        body: config.method === 'POST' ? JSON.stringify(config.params) : undefined,
      });
      const json = await response.json();
      return config.dataPath.split('.').reduce((acc: any, key) => acc?.[key], json) || [];
    } catch { return []; }
  }
}
```

## D3 自定义可视化

当 ECharts 内置类型无法满足需求时（力导向图、桑基图），用 D3.js 实现：

```typescript
import React, { useEffect, useRef } from 'react';
import * as d3 from 'd3';

interface ForceGraphProps {
  nodes: { id: string; group: number }[];
  links: { source: string; target: string; value: number }[];
  width?: number; height?: number;
  onNodeClick?: (nodeId: string) => void;
}

const ForceGraph: React.FC<ForceGraphProps> = ({ nodes, links, width = 600, height = 400, onNodeClick }) => {
  const svgRef = useRef<SVGSVGElement>(null);

  useEffect(() => {
    if (!svgRef.current || !nodes.length) return;
    const svg = d3.select(svgRef.current);
    svg.selectAll('*').remove();

    const simulation = d3.forceSimulation(nodes as d3.SimulationNodeDatum[])
      .force('link', d3.forceLink(links).id((d: any) => d.id).distance(80))
      .force('charge', d3.forceManyBody().strength(-200))
      .force('center', d3.forceCenter(width / 2, height / 2));

    svg.append('g').selectAll('line').data(links).join('line')
      .attr('stroke', '#999').attr('stroke-width', d => Math.sqrt(d.value));

    svg.append('g').selectAll('circle').data(nodes).join('circle')
      .attr('r', 8).attr('fill', d => d3.schemeCategory10[d.group % 10])
      .on('click', (_, d) => onNodeClick?.((d as any).id)).style('cursor', 'pointer');

    simulation.on('tick', () => {
      svg.selectAll('line').attr('x1', (d: any) => d.source.x).attr('y1', (d: any) => d.source.y)
        .attr('x2', (d: any) => d.target.x).attr('y2', (d: any) => d.target.y);
      svg.selectAll('circle').attr('cx', (d: any) => d.x).attr('cy', (d: any) => d.y);
    });

    return () => simulation.stop();
  }, [nodes, links, width, height]);

  return <svg ref={svgRef} width={width} height={height} />;
};
```

## 常见误区

1. **直接暴露 ECharts 全量配置项**：500+ 配置项会让面板极其复杂，应提炼高频项，高级配置走「自定义 JSON」入口。
2. **数据绑定不处理空值和格式错误**：后端 API 可能返回空或格式变化，组件必须安全转换，否则图表白屏。
3. **不做销毁清理**：ECharts 实例、D3 的 forceSimulation、ResizeObserver 都需在卸载时清理。

## 工程建议

1. **优先 ECharts 内置图表，D3 做兜底**：ECharts 覆盖 90% 常见场景，只有完全自定义可视化才引入 D3。
2. **数据源引擎支持缓存和重试**：API 可能因网络波动失败，加入重试（最多 3 次，指数退避）提升体验。
3. **图表配置支持导入导出**：让配置者能导出 JSON，方便在不同页面间复用。

## 小结

- ECharts 是低代码图表组件首选，核心工作是将配置项映射到可视化面板。
- 数据绑定协议支持静态、API、实时三种模式，API 模式需支持自动刷新。
- D3.js 适用于 ECharts 无法覆盖的自定义可视化场景。
- 响应式处理和实例清理是图表组件的两个关键工程点。

### 练习一

**思路**：echarts.init 初始化，useEffect 监听数据变化 setOption 更新，ResizeObserver 处理尺寸变化，卸载时 dispose。

**答案**：
```typescript
import React, { useEffect, useRef } from 'react';
import * as echarts from 'echarts';

interface BarChartProps {
  title?: string; xAxisName?: string; yAxisName?: string;
  colorScheme?: 'default' | 'blue' | 'warm';
  data: { category: string; value: number }[];
  onClick?: (params: { category: string; value: number }) => void;
}

const colorMap = { default: ['#5470c6','#91cc75','#fac858'], blue: ['#1890ff','#40a9ff','#69c0ff'], warm: ['#fa541c','#fa8c16','#faad14'] };

const BarChart: React.FC<BarChartProps> = (rawProps) => {
  const props = { title: '', xAxisName: '', yAxisName: '', colorScheme: 'default' as const, data: [], ...rawProps };
  const containerRef = useRef<HTMLDivElement>(null);
  const chartRef = useRef<echarts.ECharts | null>(null);

  useEffect(() => {
    if (!containerRef.current) return;
    chartRef.current = echarts.init(containerRef.current);
    chartRef.current.on('click', (p: echarts.ECElementEvent) => props.onClick?.({ category: String(p.name), value: Number(p.value) }));
    const obs = new ResizeObserver(() => chartRef.current?.resize());
    obs.observe(containerRef.current);
    return () => { chartRef.current?.dispose(); obs.disconnect(); };
  }, []);

  useEffect(() => {
    chartRef.current?.setOption({
      title: props.title ? { text: props.title, left: 'center' } : undefined,
      tooltip: { trigger: 'axis' }, color: colorMap[props.colorScheme],
      xAxis: { type: 'category', data: props.data.map(d => d.category), name: props.xAxisName },
      yAxis: { type: 'value', name: props.yAxisName },
      series: [{ type: 'bar', data: props.data.map(d => d.value) }],
    }, { notMerge: true });
  }, [props.data, props.title, props.xAxisName, props.yAxisName, props.colorScheme]);

  return <div ref={containerRef} style={{ width: '100%', height: 300 }} />;
};
```

**要点**：ResizeObserver 与图表实例同生命周期；onClick 提取 name/value 结构化传参。

### 练习二

**思路**：用类封装，apiConfig 的 dataPath 用点号路径提取嵌套数据，autoRefresh 用 setInterval 实现。

**答案**：
```typescript
interface StaticBinding { mode: 'static'; staticData: Record<string, unknown>[]; }
interface ApiBinding { mode: 'api'; apiConfig: { url: string; method: 'GET'|'POST'; headers?: Record<string,string>; params?: Record<string,unknown>; dataPath: string; refreshInterval?: number; }; }
type Binding = StaticBinding | ApiBinding;

class DataSourceEngine {
  private timers = new Map<string, ReturnType<typeof setInterval>>();

  async resolve(binding: Binding): Promise<Record<string, unknown>[]> {
    if (binding.mode === 'static') return binding.staticData;
    return this.fetchData(binding.apiConfig);
  }

  startAutoRefresh(id: string, binding: ApiBinding, cb: (d: Record<string,unknown>[]) => void) {
    this.stopRefresh(id);
    const ms = (binding.apiConfig.refreshInterval || 30) * 1000;
    const run = async () => cb(await this.fetchData(binding.apiConfig));
    run();
    this.timers.set(id, setInterval(run, ms));
  }

  stopRefresh(id: string) { const t = this.timers.get(id); if (t) { clearInterval(t); this.timers.delete(id); } }
  stopAll() { this.timers.forEach((_, id) => this.stopRefresh(id)); }

  private async fetchData(c: ApiBinding['apiConfig']): Promise<Record<string, unknown>[]> {
    try {
      const url = c.method === 'GET' && c.params ? `${c.url}?${new URLSearchParams(c.params as any)}` : c.url;
      const res = await fetch(url, { method: c.method, headers: { 'Content-Type': 'application/json', ...c.headers }, body: c.method === 'POST' ? JSON.stringify(c.params) : undefined });
      const json = await res.json();
      const result = c.dataPath.split('.').reduce((a: any, k) => a?.[k], json);
      return Array.isArray(result) ? result : [];
    } catch { return []; }
  }
}
```

**要点**：stopAll 确保页面切换时所有轮询被清理；fetchData 返回空数组而非抛异常。
