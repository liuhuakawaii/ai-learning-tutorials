# 第三方集成组件：地图、支付与 IM 集成

## 场景引入

某连锁餐饮企业用低代码平台搭建门店管理系统，需要三个关键功能：地图展示门店位置和路线规划、客户在线下单付款、客服与客户实时沟通。三者共同特点：都需对接第三方服务，涉及 API Key 管理、安全认证、异步回调等复杂工程问题。

本节课讲解如何在低代码平台中封装地图、支付、IM 组件，以及 OAuth 和 Webhook 的工程实践。

## 学习目标

- 掌握地图组件集成（AMap），包括标记、路线和地理围栏
- 理解支付组件的安全设计流程
- 能实现基于 WebSocket 的 IM 聊天组件
- 了解 OAuth 集成和 Webhook 接收器

## 地图组件集成

### AMap 基础集成

```typescript
import React, { useEffect, useRef } from 'react';

interface MapComponentProps {
  center: { lng: number; lat: number };
  zoom: number;
  markers?: { lng: number; lat: number; title: string; content?: string }[];
  route?: { start: { lng: number; lat: number }; end: { lng: number; lat: number } };
  geofence?: { center: { lng: number; lat: number }; radius: number };
  onMarkerClick?: (marker: { title: string; lng: number; lat: number }) => void;
}

const MapComponent: React.FC<MapComponentProps> = (rawProps) => {
  const props = { center: { lng: 116.397428, lat: 39.90923 }, zoom: 12, markers: [], ...rawProps };
  const containerRef = useRef<HTMLDivElement>(null);
  const mapRef = useRef<any>(null);

  useEffect(() => {
    if (!containerRef.current || !window.AMap) return;
    const map = new window.AMap.Map(containerRef.current, { center: [props.center.lng, props.center.lat], zoom: props.zoom });
    mapRef.current = map;

    props.markers?.forEach(m => {
      const marker = new window.AMap.Marker({ position: [m.lng, m.lat], title: m.title });
      if (m.content) {
        const infoWindow = new window.AMap.InfoWindow({ content: `<div style="padding:8px"><h4>${m.title}</h4><p>${m.content}</p></div>` });
        marker.on('click', () => { infoWindow.open(map, marker.getPosition()); props.onMarkerClick?.({ title: m.title, lng: m.lng, lat: m.lat }); });
      }
      map.add(marker);
    });

    if (props.route) {
      const driving = new window.AMap.Driving({ map });
      driving.search(new window.AMap.LngLat(props.route.start.lng, props.route.start.lat), new window.AMap.LngLat(props.route.end.lng, props.route.end.lat));
    }

    if (props.geofence) {
      map.add(new window.AMap.Circle({ center: [props.geofence.center.lng, props.geofence.center.lat], radius: props.geofence.radius, strokeColor: '#1890ff', fillColor: '#1890ff', fillOpacity: 0.1 }));
    }

    return () => map.destroy();
  }, []);

  return <div ref={containerRef} style={{ width: '100%', height: 400 }} />;
};
```

### 地理围栏检测

```typescript
function isPointInGeofence(point: { lng: number; lat: number }, fence: { center: { lng: number; lat: number }; radius: number }): boolean {
  const R = 6371000;
  const dLat = (fence.center.lat - point.lat) * Math.PI / 180;
  const dLng = (fence.center.lng - point.lng) * Math.PI / 180;
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(point.lat * Math.PI / 180) * Math.cos(fence.center.lat * Math.PI / 180) * Math.sin(dLng / 2) ** 2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a)) <= fence.radius;
}
```

## 支付组件集成

支付是最敏感的集成，低代码平台不应让配置者直接处理密钥，而是通过后端代理请求。

### Stripe 支付流程

```typescript
import React, { useState } from 'react';
import { loadStripe } from '@stripe/stripe-js';
import { Elements, CardElement, useStripe, useElements } from '@stripe/react-stripe-js';

interface PaymentProps {
  amount: number; currency: string; description: string; apiEndpoint: string;
  stripePublicKey: string;
  onSuccess?: (paymentId: string) => void; onError?: (error: string) => void;
}

const CheckoutForm: React.FC<Omit<PaymentProps, 'stripePublicKey'>> = ({ amount, currency, description, apiEndpoint, onSuccess, onError }) => {
  const stripe = useStripe();
  const elements = useElements();
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!stripe || !elements) return;
    setLoading(true);
    try {
      const res = await fetch(`${apiEndpoint}/create-payment-intent`, {
        method: 'POST', headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ amount: Math.round(amount * 100), currency, description }),
      });
      const { clientSecret } = await res.json();
      const { error, paymentIntent } = await stripe.confirmCardPayment(clientSecret, {
        payment_method: { card: elements.getElement(CardElement)! },
      });
      if (error) onError?.(error.message || '支付失败');
      else if (paymentIntent?.status === 'succeeded') onSuccess?.(paymentIntent.id);
    } catch (err: any) { onError?.(err.message); }
    finally { setLoading(false); }
  };

  return (
    <form onSubmit={handleSubmit} style={{ maxWidth: 400 }}>
      <div style={{ padding: 12, border: '1px solid #d9d9d9', borderRadius: 4, marginBottom: 16 }}>
        <CardElement options={{ style: { base: { fontSize: '16px' } } }} />
      </div>
      <button type="submit" disabled={!stripe || loading} style={{ width: '100%', padding: 12, background: '#1890ff', color: '#fff', border: 'none', borderRadius: 4 }}>
        {loading ? '处理中...' : `支付 ${currency.toUpperCase()} ${amount.toFixed(2)}`}
      </button>
    </form>
  );
};

const PaymentComponent: React.FC<PaymentProps> = (props) => (
  <Elements stripe={loadStripe(props.stripePublicKey)}>
    <CheckoutForm {...props} />
  </Elements>
);
```

## IM 聊天组件

```typescript
import React, { useEffect, useRef, useState, useCallback } from 'react';

interface Message { id: string; sender: string; content: string; timestamp: number; type: 'text' | 'image' | 'system'; }
interface ChatProps { wsUrl: string; room: string; currentUser: string; onMessage?: (msg: Message) => void; }

const ChatComponent: React.FC<ChatProps> = (rawProps) => {
  const props = { currentUser: '匿名用户', ...rawProps };
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState('');
  const [connected, setConnected] = useState(false);
  const wsRef = useRef<WebSocket | null>(null);
  const listRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const ws = new WebSocket(`${props.wsUrl}?room=${props.room}`);
    wsRef.current = ws;
    ws.onopen = () => setConnected(true);
    ws.onclose = () => setConnected(false);
    ws.onmessage = (e) => { try { const msg = JSON.parse(e.data); setMessages(p => [...p, msg]); props.onMessage?.(msg); } catch {} };
    return () => ws.close();
  }, [props.wsUrl, props.room]);

  useEffect(() => { if (listRef.current) listRef.current.scrollTop = listRef.current.scrollHeight; }, [messages]);

  const sendMessage = useCallback(() => {
    if (!input.trim() || !wsRef.current || wsRef.current.readyState !== WebSocket.OPEN) return;
    wsRef.current.send(JSON.stringify({ id: `${Date.now()}-${Math.random().toString(36).slice(2,8)}`, sender: props.currentUser, content: input.trim(), timestamp: Date.now(), type: 'text' }));
    setInput('');
  }, [input, props.currentUser]);

  return (
    <div style={{ display: 'flex', flexDirection: 'column', height: 400, border: '1px solid #d9d9d9', borderRadius: 8 }}>
      <div style={{ padding: '8px 12px', borderBottom: '1px solid #d9d9d9', display: 'flex', justifyContent: 'space-between' }}>
        <span>聊天室: {props.room}</span>
        <span style={{ color: connected ? '#52c41a' : '#ff4d4f' }}>{connected ? '已连接' : '未连接'}</span>
      </div>
      <div ref={listRef} style={{ flex: 1, overflow: 'auto', padding: 12 }}>
        {messages.map(msg => (
          <div key={msg.id} style={{ marginBottom: 8, textAlign: msg.sender === props.currentUser ? 'right' : 'left' }}>
            <div style={{ fontSize: 12, color: '#999' }}>{msg.sender}</div>
            <div style={{ display: 'inline-block', padding: '6px 12px', borderRadius: 8, background: msg.sender === props.currentUser ? '#1890ff' : '#f0f0f0', color: msg.sender === props.currentUser ? '#fff' : '#333' }}>{msg.content}</div>
          </div>
        ))}
      </div>
      <div style={{ display: 'flex', padding: 8, borderTop: '1px solid #d9d9d9' }}>
        <input value={input} onChange={e => setInput(e.target.value)} onKeyDown={e => e.key === 'Enter' && sendMessage()} style={{ flex: 1, padding: '8px 12px', border: '1px solid #d9d9d9', borderRadius: 4 }} placeholder="输入消息..." />
        <button onClick={sendMessage} style={{ marginLeft: 8, padding: '8px 16px' }} disabled={!connected}>发送</button>
      </div>
    </div>
  );
};
```

## Webhook 接收器

```typescript
import crypto from 'crypto';

function verifyWebhookSignature(payload: string, signature: string, secret: string): boolean {
  const expected = crypto.createHmac('sha256', secret).update(payload).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(`sha256=${expected}`));
}
```

## 常见误区

1. **API Key 暴露在前端**：地图 JS Key 可放前端（有域名白名单），但支付私钥必须在后端。
2. **WebSocket 不处理断线重连**：必须实现自动重连（指数退避），否则用户看到「已断开」无法恢复。
3. **Webhook 不验证签名**：任何人都可伪造请求，必须验证 HMAC 签名。

## 工程建议

1. **第三方 SDK 用动态加载**：地图 SDK 约 1MB，用 script 标签动态加载减少首屏体积。
2. **支付用沙箱模式开发**：Stripe test mode、支付宝沙箱环境，开发测试阶段必须使用。
3. **IM 消息做本地持久化**：WebSocket 只负责实时传输，历史消息通过 REST API 分页查询缓存到 IndexedDB。

## 小结

- 地图组件核心是 SDK 动态加载、标记/路线渲染和事件交互。
- 支付组件安全设计是重中之重：金额后端计算、密钥后端持有、结果异步确认。
- IM 组件基于 WebSocket，需处理断线重连和消息持久化。
- OAuth 和 Webhook 分别解决「平台调用第三方」和「第三方回调平台」。

## 参考答案

### 练习一

**思路**：Map 存储标记（key 为 ID），添加时去重，地理围栏用 Haversine 公式计算距离。

**答案**：
```typescript
interface Marker { id: string; lng: number; lat: number; title: string; data?: Record<string, unknown>; }
interface Geofence { id: string; center: { lng: number; lat: number }; radius: number; }

class MapMarkerManager {
  private markers = new Map<string, Marker>();

  add(marker: Marker): boolean { if (this.markers.has(marker.id)) return false; this.markers.set(marker.id, { ...marker }); return true; }
  remove(id: string): boolean { return this.markers.delete(id); }
  get(id: string) { return this.markers.get(id); }
  getAll(): Marker[] { return Array.from(this.markers.values()); }

  batchUpdatePosition(updates: { id: string; lng: number; lat: number }[]): number {
    let count = 0;
    for (const u of updates) { const m = this.markers.get(u.id); if (m) { m.lng = u.lng; m.lat = u.lat; count++; } }
    return count;
  }

  filterByGeofence(fence: Geofence): Marker[] {
    return this.getAll().filter(m => {
      const R = 6371000;
      const dLat = (fence.center.lat - m.lat) * Math.PI / 180;
      const dLng = (fence.center.lng - m.lng) * Math.PI / 180;
      const a = Math.sin(dLat/2)**2 + Math.cos(m.lat*Math.PI/180) * Math.cos(fence.center.lat*Math.PI/180) * Math.sin(dLng/2)**2;
      return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a)) <= fence.radius;
    });
  }
}
```

**要点**：Map 存储自动去重；batchUpdatePosition 返回成功数量；filterByGeofence 内联 Haversine 避免外部依赖。

### 练习二

**思路**：包装原生 WebSocket，onclose 触发重连，指数退避计算延迟，消息暂存队列重连后发送。

**答案**：
```typescript
class ReconnectableWebSocket {
  private ws: WebSocket | null = null;
  private queue: string[] = [];
  private attempts = 0;
  private shouldReconnect = true;
  private timer: ReturnType<typeof setTimeout> | null = null;
  onMessage?: (data: string) => void;
  onReconnect?: (attempt: number) => void;
  onOpen?: () => void;

  constructor(private url: string) { this.connect(); }

  private connect() {
    this.ws = new WebSocket(this.url);
    this.ws.onopen = () => { this.attempts = 0; this.onOpen?.(); this.flush(); };
    this.ws.onmessage = (e) => this.onMessage?.(e.data);
    this.ws.onclose = () => { if (this.shouldReconnect) this.scheduleReconnect(); };
    this.ws.onerror = () => this.ws?.close();
  }

  private scheduleReconnect() {
    const delay = Math.min(1000 * 2 ** this.attempts, 30000);
    this.attempts++;
    this.timer = setTimeout(() => { this.onReconnect?.(this.attempts); this.connect(); }, delay);
  }

  private flush() { while (this.queue.length && this.ws?.readyState === WebSocket.OPEN) this.ws.send(this.queue.shift()!); }

  send(data: string) { if (this.ws?.readyState === WebSocket.OPEN) this.ws.send(data); else this.queue.push(data); }

  close() { this.shouldReconnect = false; if (this.timer) clearTimeout(this.timer); this.ws?.close(); }
}
```

**要点**：指数退避 `1000 * 2^attempts` 上限 30 秒；flush 在 onopen 时调用确保断线消息重发；close 设 shouldReconnect=false 防手动关闭触发重连。
