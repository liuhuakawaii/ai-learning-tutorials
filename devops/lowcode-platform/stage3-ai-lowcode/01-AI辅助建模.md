# AI 辅助建模：自然语言生成数据模型

> 前置知识：数据模型设计基础（阶段一），API 设计基础

## 一个产品经理的困境

张伟是一家电商公司的产品经理，需要为售后管理系统设计数据模型。传统做法：写需求文档 → 交给架构师设计 ER 图 → 开发人员手动建表。通常需要 3-5 天。一旦需求理解有偏差，返工成本很高。

现在张伟打开低代码平台的 AI 建模助手，输入："我需要一个售后工单系统，客户提交工单，客服分配处理，支持多轮沟通记录，工单有优先级和状态流转。"

几秒钟后，AI 自动生成了完整的数据模型：字段类型、关联关系、枚举值都已推断完毕。

这就是 AI 辅助建模的核心价值：**将业务语言直接转化为技术实现。**

## 转换链路

```
用户输入（自然语言）
    ↓
Prompt 构造（系统指令 + 用户输入 + 上下文）
    ↓
LLM 推理（生成结构化 JSON）
    ↓
校验修正（字段类型检查、关联完整性）
    ↓
最终模型（可直接用于建表）
```

## Prompt 设计

让 LLM 生成数据模型的关键是 Prompt 的设计：

```typescript
function buildModelingPrompt(userInput: string): string {
  return `你是一个数据建模专家。用户会用自然语言描述业务需求，你需要生成数据模型的 JSON Schema。

规则：
1. 每个实体生成一个 JSON 对象，包含 name、fields 数组
2. 每个字段包含 name、type、required、label
3. type 可以是：string、number、boolean、date、text、select、relation
4. 如果是 select 类型，需要提供 options 数组
5. 如果是 relation 类型，需要提供 target 实体名
6. 根据业务语义推断字段是否 required
7. 用中文生成 label

用户需求：
${userInput}

请生成完整的数据模型 JSON。`;
}
```

## 校验与修正

LLM 生成的模型不一定完美。需要自动校验：

```typescript
interface ValidationResult {
  valid: boolean;
  errors: string[];
  warnings: string[];
}

function validateModel(entities: Entity[]): ValidationResult {
  const errors: string[] = [];
  const warnings: string[] = [];

  for (const entity of entities) {
    // 检查是否有主键
    if (!entity.fields.some(f => f.name === 'id')) {
      warnings.push(`${entity.name}: 没有显式定义 id 字段，系统将自动添加`);
    }

    // 检查 relation 目标是否存在
    for (const field of entity.fields) {
      if (field.type === 'relation') {
        if (!entities.some(e => e.name === field.target)) {
          errors.push(`${entity.name}.${field.name}: 关联目标 ${field.target} 不存在`);
        }
      }
    }

    // 检查是否有 created_at
    if (!entity.fields.some(f => f.name === 'created_at')) {
      warnings.push(`${entity.name}: 建议添加 created_at 字段`);
    }
  }

  return { valid: errors.length === 0, errors, warnings };
}
```

### 练习二

```typescript
function validateModel(entities: Entity[]): string[] {
  const errors: string[] = [];
  const entityNames = new Set(entities.map(e => e.name));

  for (const entity of entities) {
    for (const field of entity.fields) {
      if (field.type === 'relation' && !entityNames.has(field.target)) {
        errors.push(`${entity.name}.${field.name}: target "${field.target}" not found`);
      }
    }

    const hasCreatedAt = entity.fields.some(f => f.name === 'created_at');
    const hasUpdatedAt = entity.fields.some(f => f.name === 'updated_at');
    if (!hasCreatedAt) errors.push(`${entity.name}: missing created_at`);
    if (!hasUpdatedAt) errors.push(`${entity.name}: missing updated_at`);
  }

  return errors;
}
```
