## RAG 基础架构

RAG 先从知识库检索相关信息，再将结果作为上下文提供给 LLM 生成回答：

```
用户提问 → 向量化 → 相似度检索 → 构造 Prompt(问题+上下文) → LLM 生成回答(附引用)
```

核心数据结构：

```typescript
interface Document { id: string; title: string; content: string; metadata: { source: string; category: string; lastUpdated: string } }
interface DocumentChunk { id: string; documentId: string; content: string; embedding: number[]; metadata: { startIndex: number; endIndex: number } }
interface RetrievedChunk { chunk: DocumentChunk; score: number }
```

## 知识库构建

### 文档分块

分块太大会引入噪声，太小会丢失上下文：

```typescript
function chunkDocument(content: string, maxSize = 500, overlap = 50): string[] {
  const separators = ['\n\n', '\n', '。', '；', ' '];
  const chunks: string[] = [];

  function split(text: string, sepIdx: number): string[] {
    if (text.length <= maxSize) return [text];
    const sep = separators[sepIdx] || ' ';
    const parts = text.split(sep);
    let current = '';
    const result: string[] = [];
    for (const part of parts) {
      if ((current + sep + part).length > maxSize) {
        if (current) result.push(current.trim());
        current = part;
      } else {
        current = current ? current + sep + part : part;
      }
    }
    if (current.trim()) result.push(current.trim());
    return result;
  }

  let allChunks = split(content, 0);
  if (overlap > 0 && allChunks.length > 1) {
    allChunks = allChunks.map((c, i) => (i > 0 ? allChunks[i - 1].slice(-overlap) : '') + c);
  }
  return allChunks;
}
```

### 向量化与检索

```typescript
class KnowledgeBase {
  private chunks: DocumentChunk[] = [];

  async addDocument(doc: Document): Promise<void> {
    const textChunks = chunkDocument(doc.content);
    for (let i = 0; i < textChunks.length; i++) {
      const embedding = await this.getEmbedding(textChunks[i]);
      this.chunks.push({ id: `${doc.id}_${i}`, documentId: doc.id, content: textChunks[i], embedding, metadata: { startIndex: i * 500, endIndex: (i + 1) * 500 } });
    }
  }

  private async getEmbedding(text: string): Promise<number[]> {
    const res = await openai.embeddings.create({ model: 'text-embedding-3-small', input: text });
    return res.data[0].embedding;
  }

  async search(query: string, topK = 3): Promise<RetrievedChunk[]> {
    const queryEmb = await this.getEmbedding(query);
    return this.chunks
      .map(chunk => ({ chunk, score: this.cosineSimilarity(queryEmb, chunk.embedding) }))
      .sort((a, b) => b.score - a.score)
      .slice(0, topK);
  }

  private cosineSimilarity(a: number[], b: number[]): number {
    let dot = 0, na = 0, nb = 0;
    for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] * a[i]; nb += b[i] * b[i]; }
    return dot / (Math.sqrt(na) * Math.sqrt(nb));
  }
}
```

## RAG 问答实现

```typescript
const RAG_PROMPT = `基于参考资料回答问题。
参考资料：{{REFERENCES}}
规则：只基于资料回答，不足时说明"无法确定"，标注引用[来源:标题]，简洁中文。
问题：{{QUESTION}}`;

async function ragQuery(kb: KnowledgeBase, question: string): Promise<{ answer: string; sources: Array<{ title: string; score: number }>; confidence: number }> {
  const chunks = await kb.search(question, 3);
  const refs = chunks.map((r, i) => `[${i + 1}] ${r.chunk.content}（相关度:${r.score.toFixed(2)}）`).join('\n\n');
  const response = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [{ role: 'system', content: '你是产品客服，基于资料回答。' }, { role: 'user', content: RAG_PROMPT.replace('{{REFERENCES}}', refs).replace('{{QUESTION}}', question) }],
    temperature: 0.3
  });
  return {
    answer: response.choices[0].message.content,
    sources: chunks.map(r => ({ title: r.chunk.documentId, score: r.score })),
    confidence: chunks[0]?.score || 0
  };
}
```

## 对话状态管理

```typescript
interface Message { id: string; role: 'user' | 'assistant' | 'system'; content: string; timestamp: number; metadata?: { sources?: string[]; confidence?: number } }

class ConversationManager {
  private conversations = new Map<string, { messages: Message[]; context: Record<string, unknown> }>();

  getConversation(id: string) {
    if (!this.conversations.has(id)) this.conversations.set(id, { messages: [], context: {} });
    return this.conversations.get(id)!;
  }

  addMessage(convId: string, msg: Message) {
    const conv = this.getConversation(convId);
    conv.messages.push(msg);
    if (conv.messages.length > 50) {
      conv.messages = [...conv.messages.slice(0, 2), { id: 'summary', role: 'system', content: '[历史已省略]', timestamp: Date.now() }, ...conv.messages.slice(-10)];
    }
  }
}
```

## Function Calling 数据操作

ChatBot 不仅回答问题，还能执行数据操作：

```typescript
const FUNCTIONS = [
  { type: 'function', function: {
    name: 'query_orders', description: '查询用户订单',
    parameters: { type: 'object', properties: { userId: { type: 'string' }, status: { type: 'string', enum: ['pending','shipped','delivered','cancelled'] } }, required: ['userId'] }
  }},
  { type: 'function', function: {
    name: 'create_ticket', description: '创建客服工单',
    parameters: { type: 'object', properties: { title: { type: 'string' }, description: { type: 'string' }, priority: { type: 'string', enum: ['low','medium','high','urgent'] } }, required: ['title','description'] }
  }}
];

async function chatWithFunctions(messages: Message[], userMsg: string, userId: string): Promise<Message> {
  const apiMessages = messages.map(m => ({ role: m.role, content: m.content }));
  apiMessages.push({ role: 'user', content: userMsg });

  const response = await openai.chat.completions.create({ model: 'gpt-4o', messages: apiMessages, tools: FUNCTIONS, tool_choice: 'auto' });
  const assistant = response.choices[0].message;

  if (assistant.tool_calls) {
    const results = [];
    for (const call of assistant.tool_calls) {
      const args = JSON.parse(call.function.arguments);
      const result = await handleFunctionCall(call.function.name, args, userId);
      results.push({ tool_call_id: call.id, content: JSON.stringify(result) });
    }
    const final = await openai.chat.completions.create({
      model: 'gpt-4o', messages: [...apiMessages, assistant, ...results.map(r => ({ role: 'tool' as const, content: r.content, tool_call_id: r.tool_call_id }))]
    });
    return { id: `msg_${Date.now()}`, role: 'assistant', content: final.choices[0].message.content, timestamp: Date.now() };
  }
  return { id: `msg_${Date.now()}`, role: 'assistant', content: assistant.content, timestamp: Date.now() };
}
```

async function summarizeConversation(messages: Message[]): Promise<string> {
  const history = messages.map(m => `${m.role === 'user' ? '用户' : '助手'}：${m.content}`).join('\n');

## 常见误区

1. **分块大小随意**：太小（<100字）丢失上下文，太大（>1000字）引入噪声。技术文档 300-500 字，FAQ 整条为一块。
2. **不做检索质量评估**：低相关结果会让 LLM 基于错误信息回答，应设相似度阈值触发兜底。
3. **忽略对话上下文**："那第二种方案呢"需要理解上一轮内容，必须纳入完整对话历史。

## 工程建议

1. **分层知识库**：按主题分层（文档/FAQ/操作指南），先路由到相关层再精确检索。
2. **反馈闭环**：收集"有用/无用"反馈优化知识库，高频无用问答需人工审核。
3. **流式输出**：LLM 流式生成配合打字机动画，减少用户等待时间。

## 小结

- RAG 通过"检索+生成"解决 LLM 知识时效性和幻觉问题
- 知识库构建包括分块、向量化、索引，分块策略直接影响问答质量
- 对话 UI 需维护历史、上下文、消息管理，支持摘要压缩
- Function Calling 让 ChatBot 从"问答"升级为"操作"

## 参考答案

### 练习一

**思路**：先按标题拆分为 Section，超大 Section 在内部按段落二次拆分。

**答案**：
```typescript
function chunkMarkdownDocument(content: string, maxSize = 500): Array<{ title: string; content: string }> {
  const chunks: Array<{ title: string; content: string }> = [];
  const sections = content.split(/(?=^#{1,3}\s)/m).filter(s => s.trim());
  for (const section of sections) {
    const titleMatch = section.match(/^(#{1,3})\s+(.+)/);
    const title = titleMatch ? titleMatch[2].trim() : '无标题';
    if (section.length <= maxSize) {
      chunks.push({ title, content: section.trim() });
    } else {
      const paragraphs = section.split(/\n\n+/).filter(p => p.trim());
      let current = '', idx = 1;
      for (const p of paragraphs) {
        if ((current + '\n\n' + p).length > maxSize) {
          if (current) { chunks.push({ title: `${title} (${idx})`, content: current.trim() }); idx++; }
          current = p;
        } else { current = current ? current + '\n\n' + p : p; }
      }
      if (current.trim()) chunks.push({ title: idx > 1 ? `${title} (${idx})` : title, content: current.trim() });
    }
  }
  return chunks;
}
```

**要点**：正则 `(?=^#{1,3}\s)` 按标题拆分且不丢失标题，拆分后加序号定位来源。
