# 阶段实战：AI 驱动的智能客服系统

## 场景引入

经过前五节课，我们掌握了 AI 辅助建模、页面生成、数据处理、工作流、对话界面等能力。现在将这些能力整合，构建完整的 AI 驱动业务系统——智能客服系统。

系统覆盖客服全流程：AI 创建工单模型、AI 生成工单表单、智能路由分配、AI 辅助回复、知识库问答、数据看板分析。通过这个实战项目，理解 AI 能力如何与低代码平台深度集成。

## 学习目标

- 掌握 AI 能力在低代码平台中的端到端集成方法
- 学会将建模、页面、工作流、对话界面组合为完整业务系统
- 理解 AI 驱动系统的设计原则与架构决策
- 能够独立规划 AI + 低代码的业务方案

## 第三步：智能工单路由

基于 AI 分类和技能匹配的路由引擎：

```typescript
const ROUTING_PROMPT = `将工单分配给最合适的客服。
工单：标题{{title}}，描述{{description}}，分类{{category}}，优先级{{priority}}，情感{{sentiment}}
可用客服：{{AGENTS}}
规则：技能匹配、工单数不超限、满意度优先、紧急工单分配空闲客服、负面工单分配经验丰富客服。
输出：{ assignedAgentId, reason, suggestedCategory }`;

class IntelligentRouter {
  async routeTicket(ticket: CSTicket, agents: Agent[]): Promise<{ assignedAgentId: string | null; reason: string; suggestedCategory: string }> {
    const sentiment = await analyzeSentiment(ticket.description);
    const classification = await this.classifyTicket(ticket);
    const available = agents.filter(a => a.status !== 'offline' && a.currentTicketCount < a.maxConcurrentTickets);

    if (!available.length) return { assignedAgentId: null, reason: '无可用客服', suggestedCategory: classification.category };

    const agentList = available.map(a => `- ${a.id} ${a.name}：技能[${a.skills}]，当前${a.currentTicketCount}单，满意度${a.satisfactionScore}`).join('\n');
    const prompt = ROUTING_PROMPT
      .replace('{{title}}', ticket.title).replace('{{description}}', ticket.description)
      .replace('{{category}}', ticket.category).replace('{{priority}}', ticket.priority)
      .replace('{{sentiment}}', sentiment.sentiment).replace('{{AGENTS}}', agentList);

    const response = await openai.chat.completions.create({
      model: 'gpt-4o',
      messages: [{ role: 'system', content: '只输出 JSON。' }, { role: 'user', content: prompt }],
      temperature: 0.1, response_format: { type: 'json_object' }
    });
    const result = JSON.parse(response.choices[0].message.content);
    result.suggestedCategory = classification.category;
    return result;
  }

  private async classifyTicket(ticket: CSTicket): Promise<{ category: string; confidence: number }> {
    const response = await openai.chat.completions.create({
      model: 'gpt-4o',
      messages: [
        { role: 'system', content: '工单分类：technical/billing/account/feature/complaint。只输出 JSON。' },
        { role: 'user', content: `${ticket.title}\n${ticket.description}` }
      ],
      temperature: 0, response_format: { type: 'json_object' }
    });
    return JSON.parse(response.choices[0].message.content);
  }
}
```

const REPLY_PROMPT = `根据对话历史和知识库生成回复建议。
工单：{{title}}，分类{{category}}，情感{{sentiment}}
对话：{{HISTORY}}
知识库：{{KNOWLEDGE}}
生成3条建议：professional(正式)、concise(简洁)、caring(关怀)。负面情感先表达歉意。

async function generateReplySuggestions(ticket: CSTicket, messages: ConversationMessage[], knowledge: RetrievedChunk[]): Promise<{ suggestions: Array<{ style: string; content: string }> }> {
  const history = messages.slice(-10).map(m => `${m.senderType === 'customer' ? '客户' : '客服'}：${m.content}`).join('\n');
  const knowledgeText = knowledge.map(c => c.chunk.content).join('\n\n');
  const sentiment = await analyzeSentiment(messages.filter(m => m.senderType === 'customer').pop()?.content || '');

  let prompt = REPLY_PROMPT
    .replace('{{title}}', ticket.title).replace('{{category}}', ticket.category)
    .replace('{{sentiment}}', sentiment.sentiment).replace('{{HISTORY}}', history).replace('{{KNOWLEDGE}}', knowledgeText);

  const response = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [{ role: 'system', content: '只输出 JSON。' }, { role: 'user', content: prompt }],
    temperature: 0.5, response_format: { type: 'json_object' }
  });
  return JSON.parse(response.choices[0].message.content);
}

## 第五步：客户端 ChatBot

```typescript
class CustomerServiceBot {
  private kb: KnowledgeBase;
  async handleMessage(convId: string, msg: string): Promise<{ type: 'answer' | 'escalate' | 'fallback'; content: string; sources?: string[]; ticketId?: string }> {
    const rag = await ragQuery(this.kb, msg);
    if (rag.confidence >= 0.7) return { type: 'answer', content: rag.answer, sources: rag.sources.map(s => s.title) };

    const sentiment = await analyzeSentiment(msg);
    if (sentiment.urgency === 'high' || sentiment.sentiment === 'angry') {
      const ticket = await this.createTicket(convId, msg, sentiment);
      return { type: 'escalate', content: '已创建加急工单，客服会尽快联系您。', ticketId: ticket.id };
    }
    return { type: 'fallback', content: '这个问题我暂时无法回答，已转接人工客服。' };
  }
}
```

## 常见误区

1. **AI 能力过度集中**：将所有 AI 放在一个节点，单点故障影响全局。应分散到独立节点，各有降级策略。
2. **忽略冷启动**：知识库为空时 RAG 失效，上线初期应有兜底（转人工）并持续积累内容。
3. **不做效果度量**：不跟踪准确率和满意度无法优化，每个 AI 节点应埋点记录输入输出和人工修正。

## 工程建议

1. **渐进式上线**：先上线辅助功能（回复建议、知识库推荐），验证效果后再上自动功能（自动分类、自动回复）。
2. **人工审核通道**：AI 分类和回复建议初期有人工审核，随准确率提升逐步减少。
3. **成本控制**：高频场景（每条消息情感分析）考虑轻量模型或缓存策略。

## 小结

- 智能客服系统整合建模、页面、路由、回复、问答、看板六大 AI 能力
- 架构分界面、AI、业务、存储四层，各层松耦合独立演进
- 智能路由基于分类和技能匹配，结合情感分析差异化分配
- RAG 知识库承担 60%+ 常见问题，减少人工压力
- 渐进上线、人工审核、效果度量是生产环境三个关键保障

### 练习二

**思路**：维护文档版本表记录哈希值，更新时比较新旧哈希，只重新向量化变化片段。

**答案**：
```typescript
class IncrementalKB {
  private versions = new Map<string, { documentId: string; chunkId: string; contentHash: string }>();

  async incrementalUpdate(docId: string, newContent: string): Promise<{ added: number; updated: number; deleted: number }> {
    const newChunks = chunkDocument(newContent);
    let added = 0, updated = 0, deleted = 0;
    const newVersions: string[] = [];

    for (let i = 0; i < newChunks.length; i++) {
      const chunkId = `${docId}_${i}`;
      const hash = this.hash(newChunks[i]);
      newVersions.push(chunkId);
      const existing = this.versions.get(chunkId);
      if (!existing) { await this.addChunk(chunkId, docId, newChunks[i]); added++; }
      else if (existing.contentHash !== hash) { await this.updateChunk(chunkId, newChunks[i]); updated++; }
      this.versions.set(chunkId, { documentId: docId, chunkId, contentHash: hash });
    }

    for (const [id, v] of this.versions) {
      if (v.documentId === docId && !newVersions.includes(id)) { await this.deleteChunk(id); deleted++; }
    }
    return { added, updated, deleted };
  }

  private hash(content: string): string {
    let h = 0; for (let i = 0; i < content.length; i++) { h = ((h << 5) - h) + content.charCodeAt(i); h &= h; }
    return h.toString(36);
  }
}
```

**要点**：哈希比较避免不必要向量化，处理分块数量变化，更新应原子化避免不一致。
