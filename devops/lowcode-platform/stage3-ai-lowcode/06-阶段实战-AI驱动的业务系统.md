# 阶段实战：AI 驱动的智能客服系统

> 前置知识：AI 辅助建模、AI 生成页面、AI 数据处理、AI 工作流、AI 对话界面（第 1-5 课）

## 你要做什么

构建一个 AI 驱动的智能客服系统。覆盖客服全流程：AI 创建工单模型、AI 生成工单表单、智能路由分配、AI 辅助回复、知识库问答、数据看板分析。

这不是 demo——这是 AI 能力与低代码平台深度集成的完整方案。

## 系统架构

```
┌──────────────────────────────────────────┐
│  用户界面层                               │

```

## 第一步：AI 生成数据模型

用自然语言描述需求，让 AI 生成数据模型：

```
输入："智能客服系统，客户通过聊天窗口提交问题，
      系统自动识别意图并创建工单，客服可以人工回复，
      也可以用 AI 生成回复建议，支持知识库问答。"

AI 生成：
  - tickets（工单表）
  - conversations（对话记录表）
  - knowledge_articles（知识库文章表）
  - customer_profiles（客户画像表）
  - intent_labels（意图标签表）
```

校验并补充：添加 `ai_confidence` 字段记录 AI 识别意图的置信度，添加 `ai_suggested_reply` 字段存储 AI 生成的回复建议。

## 第四步：AI 辅助回复

当客服打开一个工单时，AI 自动生成回复建议：

```typescript
async function generateReplySuggestion(ticket: Ticket): Promise<string> {
  const context = {
    ticket_description: ticket.description,
    customer_history: await getCustomerHistory(ticket.customer_id),
    knowledge_results: await searchKnowledge(ticket.description),
    conversation_history: await getConversationHistory(ticket.id),
  };

  const prompt = `你是一个专业的客服代表。根据以下信息，生成一个专业的回复建议。

客户问题：${context.ticket_description}

相关知识库文章：
${context.knowledge_results.map(a => `- ${a.title}: ${a.summary}`).join('\n')}

历史对话：
${context.conversation_history.map(m => `${m.sender}: ${m.content}`).join('\n')}

请生成一个专业、友好、有帮助的回复。如果需要更多信息，请礼貌地询问。`;

  return await llm.generate(prompt);
}
```

## 第五步：知识库问答

客户在聊天窗口提问时，系统自动从知识库中搜索相关答案：

```typescript
async function searchKnowledge(query: string): Promise<Article[]> {
  // 语义搜索
  const embedding = await llm.embed(query);
  const results = await vectorDB.search({
    collection: 'knowledge_articles',
    vector: embedding,
    limit: 3,
    threshold: 0.7,
  });

  return results;
}
```

如果知识库有高置信度的答案，直接返回给客户。如果没有，创建工单转人工。

创建一个客服效率看板，展示：平均首次响应时间、平均解决时间、AI 辅助回复使用率、客户满意度。
