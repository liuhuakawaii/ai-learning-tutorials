# 阶段三：AI + 低代码

> 6 课时 | 将 AI 能力融入低代码平台，实现智能化开发

## 阶段目标

- 理解 AI 与低代码结合的核心价值
- 掌握自然语言生成数据模型和页面的技术
- 能实现 AI 驱动的数据处理和工作流
- 能在低代码平台中嵌入 ChatBot 和知识库
- 能设计和实现 AI 驱动的完整业务系统

## 学习建议

1. 需要对 OpenAI API 或类似 LLM API 有基本了解
2. 每节课都涉及 API 调用，提前准备好 API Key
3. 重点理解 Prompt Engineering 在低代码场景的应用
