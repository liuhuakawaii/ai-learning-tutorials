# 二次开发

## 场景引入

某低代码平台已经服务了上百家企业客户，但不同行业的需求差异很大：制造业需要对接 MES 系统的自定义组件，金融行业需要嵌入合规审批流程，教育机构需要接入第三方考试系统。如果每个定制需求都由平台团队开发，不仅响应慢，还会让核心代码越来越臃肿。

二次开发的目标是让平台具备可扩展性：通过插件机制让第三方开发者扩展平台能力，通过 Webhook 让外部系统响应平台事件，通过开放 API 让外部应用与平台集成。本课将讲解插件系统架构、Webhook 机制和 SDK 设计。

## 学习目标

- 理解插件架构设计模式（Hooks/Filters/Actions）
- 掌握插件生命周期管理（安装/激活/停用/卸载）
- 学会设计 Webhook 系统（事件订阅/重试机制/签名验证）
- 了解开放 API 的版本策略和 SDK 设计

## 插件架构设计

### 核心概念

插件系统的设计灵感来自 WordPress 的 Hooks 机制，核心思想是：平台在关键节点定义"钩子"（Hook），插件通过注册回调函数来扩展行为。

```typescript
// src/plugin/hooks.ts
type HookCallback = (...args: any[]) => any | Promise<any>;

export class HookManager {
  private hooks: Map<string, HookCallback[]> = new Map();

  // 注册钩子
  on(hookName: string, callback: HookCallback, priority: number = 10): void {
    if (!this.hooks.has(hookName)) {
      this.hooks.set(hookName, []);
    }
    this.hooks.get(hookName)!.push({ callback, priority } as any);
    // 按优先级排序
    this.hooks.get(hookName)!.sort((a: any, b: any) => a.priority - b.priority);
  }

  // 触发钩子（同步）
  emit(hookName: string, ...args: any[]): void {
    const callbacks = this.hooks.get(hookName) || [];
    for (const cb of callbacks) {
      (cb as any).callback(...args);
    }
  }

  // 触发钩子（异步，可等待结果）
  async emitAsync(hookName: string, ...args: any[]): Promise<any[]> {
    const callbacks = this.hooks.get(hookName) || [];
    const results = [];
    for (const cb of callbacks) {
      results.push(await (cb as any).callback(...args));
    }
    return results;
  }

  // 触发 Filter（可修改数据的钩子）
  async applyFilter<T>(hookName: string, value: T, ...args: any[]): Promise<T> {
    const callbacks = this.hooks.get(hookName) || [];
    let result = value;
    for (const cb of callbacks) {
      result = await (cb as any).callback(result, ...args);
    }
    return result;
  }
}

export const hooks = new HookManager();
```

### 插件生命周期管理

```typescript
// src/plugin/lifecycle.ts
import { pool } from '../db';
import { hooks } from './hooks';
import { PluginLoader } from './loader';

export interface PluginInfo {
  id: string;
  name: string;
  version: string;
  status: 'installed' | 'active' | 'inactive' | 'error';
  settings: Record<string, any>;
}

export class PluginManager {
  private loader: PluginLoader;

  constructor() {
    this.loader = new PluginLoader();
  }

  // 安装插件
  async install(tenantId: string, pluginPath: string): Promise<PluginInfo> {
    const manifest = await this.loader.loadManifest(pluginPath);

    // 检查权限声明
    this.validatePermissions(manifest.permissions);

    // 写入数据库
    const { rows } = await pool.query(
      `INSERT INTO plugins (tenant_id, name, version, status, manifest, installed_at)
       VALUES ($1, $2, $3, 'installed', $4, NOW())
       RETURNING *`,
      [tenantId, manifest.name, manifest.version, JSON.stringify(manifest)]
    );

    return rows[0];
  }

  // 激活插件
  async activate(tenantId: string, pluginId: string): Promise<void> {
    const { rows } = await pool.query(
      `SELECT * FROM plugins WHERE id = $1 AND tenant_id = $2`,
      [pluginId, tenantId]
    );

    if (rows.length === 0) throw new Error('插件不存在');

    const plugin = rows[0];
    const manifest = plugin.manifest;

    // 加载插件代码并注册钩子
    const pluginModule = await this.loader.loadPlugin(plugin.id);
    if (typeof pluginModule.activate === 'function') {
      await pluginModule.activate({ hooks, settings: plugin.settings });
    }

    // 注册声明式钩子
    for (const [hookName, handlerName] of Object.entries(manifest.hooks || {})) {
      hooks.on(hookName, pluginModule[handlerName as string]);
    }

    await pool.query(
      `UPDATE plugins SET status = 'active', activated_at = NOW() WHERE id = $1`,
      [pluginId]
    );
  }

  // 停用插件
  async deactivate(tenantId: string, pluginId: string): Promise<void> {
    const pluginModule = await this.loader.loadPlugin(pluginId);
    if (typeof pluginModule.deactivate === 'function') {
      await pluginModule.deactivate({ hooks });
    }

    await pool.query(
      `UPDATE plugins SET status = 'inactive' WHERE id = $1 AND tenant_id = $2`,
      [pluginId, tenantId]
    );
  }

  // 卸载插件
  async uninstall(tenantId: string, pluginId: string): Promise<void> {
    await this.deactivate(tenantId, pluginId);
    await pool.query(
      `DELETE FROM plugins WHERE id = $1 AND tenant_id = $2`,
      [pluginId, tenantId]
    );
  }

  private validatePermissions(permissions: string[]): void {
    const allowed = ['read:forms', 'write:forms', 'webhook:register', 'read:users'];
    for (const perm of permissions) {
      if (!allowed.includes(perm)) {
        throw new Error(`不允许的权限: ${perm}`);
      }
    }
  }
}
```

```typescript
// src/webhook/dispatcher.ts
import crypto from 'crypto';
import fetch from 'node-fetch';
import { pool } from '../db';

interface WebhookPayload {
  event: string;
  tenantId: string;
  timestamp: number;
  data: any;
}

export async function dispatchWebhook(
  tenantId: string,
  event: string,
  data: any
): Promise<void> {
  // 查找该租户订阅了此事件的所有 Webhook
  const { rows: subscriptions } = await pool.query(
    `SELECT * FROM webhook_subscriptions
     WHERE tenant_id = $1 AND event = $2 AND status = 'active'`,
    [tenantId, event]
  );

  const payload: WebhookPayload = {
    event,
    tenantId,
    timestamp: Date.now(),
    data,
  };

  for (const sub of subscriptions) {
    // 异步发送，不阻塞主流程
    deliverWebhook(sub, payload).catch(console.error);
  }
}

async function deliverWebhook(
  subscription: any,
  payload: WebhookPayload
): Promise<void> {
  const body = JSON.stringify(payload);
  const signature = crypto
    .createHmac('sha256', subscription.secret)
    .update(body)
    .digest('hex');

  const headers = {
    'Content-Type': 'application/json',
    'X-Webhook-Signature': `sha256=${signature}`,
    'X-Webhook-Event': payload.event,
    'X-Webhook-Delivery': crypto.randomUUID(),
  };

  try {
    const response = await fetch(subscription.url, {
      method: 'POST',
      headers,
      body,
      timeout: 10000,
    });

    await logDelivery(subscription.id, payload, response.status, null);
  } catch (err: any) {
    await logDelivery(subscription.id, payload, 0, err.message);
    // 加入重试队列
    await scheduleRetry(subscription.id, payload, 1);
  }
}
```

### 重试机制

```typescript
// src/webhook/retry.ts
import { redis } from '../redis';

const MAX_RETRIES = 5;
const RETRY_DELAYS = [60, 300, 900, 3600, 7200]; // 1分钟/5分钟/15分钟/1小时/2小时

export async function scheduleRetry(
  subscriptionId: string,
  payload: any,
  attempt: number
): Promise<void> {
  if (attempt > MAX_RETRIES) {
    await markFailed(subscriptionId);
    return;
  }

  const delay = RETRY_DELAYS[attempt - 1];
  const retryJob = JSON.stringify({
    subscriptionId,
    payload,
    attempt,
    scheduledAt: Date.now() + delay * 1000,
  });

  // 使用 Redis sorted set 实现延迟队列
  await redis.zadd('webhook:retries', Date.now() + delay * 1000, retryJob);
}

// 重试 Worker
export async function processRetries(): Promise<void> {
  const now = Date.now();
  const jobs = await redis.zrangebyscore('webhook:retries', 0, now, 'LIMIT', 0, 10);

  for (const jobStr of jobs) {
    const job = JSON.parse(jobStr);
    await redis.zrem('webhook:retries', jobStr);

    try {
      await redeliverWebhook(job.subscriptionId, job.payload);
      await logDelivery(job.subscriptionId, job.payload, 200, null);
    } catch (err: any) {
      await scheduleRetry(job.subscriptionId, job.payload, job.attempt + 1);
    }
  }
}
```

```typescript
// src/plugin/apiRegistry.ts
import { Router } from 'express';

interface CustomEndpoint {
  method: 'GET' | 'POST' | 'PUT' | 'DELETE';
  path: string;
  handler: (req: any, res: any) => void;
  pluginId: string;
}

export class ApiRegistry {
  private endpoints: CustomEndpoint[] = [];
  private router = Router();

  register(endpoint: CustomEndpoint): void {
    const fullPath = `/api/plugins/${endpoint.pluginId}${endpoint.path}`;
    this.router[endpoint.method.toLowerCase() as 'get'](
      fullPath,
      endpoint.handler
    );
    this.endpoints.push(endpoint);
  }

  getRouter(): Router {
    return this.router;
  }

  listEndpoints(pluginId?: string): CustomEndpoint[] {
    if (pluginId) {
      return this.endpoints.filter(e => e.pluginId === pluginId);
    }
    return this.endpoints;
  }
}

export const apiRegistry = new ApiRegistry();
```

```typescript
// sdk/src/client.ts
export class LowCodeClient {
  private baseUrl: string;
  private apiKey: string;

  constructor(options: { baseUrl: string; apiKey: string }) {
    this.baseUrl = options.baseUrl.replace(/\/$/, '');
```

## 常见误区

1. **插件权限不加限制**：允许插件访问所有 API 和数据，一旦插件有 Bug 或恶意行为，影响范围不可控。必须声明和校验权限
2. **Webhook 同步调用外部系统**：在主流程中同步调用 Webhook 目标 URL，外部系统超时会阻塞平台。必须异步发送，失败重试
3. **API 不做版本管理**：上线后直接修改接口行为，导致已有集成方代码崩溃。所有接口变更必须通过新版本发布

## 工程建议

1. **插件运行在沙箱中**：使用 VM2 或 Worker Threads 隔离插件执行环境，防止插件代码访问主机文件系统或执行危险操作
2. **Webhook 签名验证是必须的**：接收方必须验证签名以确保请求来自平台而非伪造。提供 SDK 封装签名验证逻辑
3. **SDK 优先于文档**：好的 SDK 可以大幅降低集成门槛。SDK 应覆盖认证、错误处理、重试等通用逻辑，让开发者专注于业务

## 小结

- 插件系统通过 Hooks/Filters/Actions 机制实现可扩展性，平台定义钩子点，插件注册回调
- 插件生命周期包括安装、激活、停用、卸载四个阶段，每个阶段有对应的资源分配和清理
- Webhook 系统需要支持事件订阅、签名验证、失败重试（指数退避）和投递日志
- API 版本策略通过 URL 路径区分版本，旧版本设置 Sunset 头提示迁移
- 开发者 SDK 封装认证和通用逻辑，降低第三方集成成本

### 练习一：实现 Hook 管理器

设计一个 HookManager 类，支持 on（注册钩子）、emit（同步触发）、applyFilter（链式过滤）三个方法。要求支持优先级排序，优先级数值越小越先执行。

编写一个 Webhook 接收端的签名验证函数。输入为请求体字符串、签名头和密钥，使用 HMAC-SHA256 验证签名是否合法。

## 参考答案

### 练习一

**思路**：使用 Map 存储钩子名到回调数组的映射，每个回调包含函数和优先级。注册时按优先级插入排序，触发时按顺序执行。

**答案**：
```typescript
interface HookEntry {
  callback: Function;
  priority: number;
}

export class HookManager {
  private hooks = new Map<string, HookEntry[]>();

  on(name: string, callback: Function, priority = 10): void {
    if (!this.hooks.has(name)) {
      this.hooks.set(name, []);
    }
    const entries = this.hooks.get(name)!;
    entries.push({ callback, priority });
    entries.sort((a, b) => a.priority - b.priority);
  }

  emit(name: string, ...args: any[]): void {
    for (const entry of this.hooks.get(name) || []) {
      entry.callback(...args);
    }
  }

  async applyFilter<T>(name: string, value: T, ...args: any[]): Promise<T> {
    let result = value;
    for (const entry of this.hooks.get(name) || []) {
      result = await entry.callback(result, ...args);
    }
    return result;
  }
}
```

**要点**：
- 优先级排序在注册时完成，触发时直接遍历，避免重复排序
- applyFilter 是链式的：前一个回调的返回值作为下一个的输入
- 优先级 10 作为默认值，特殊插件可用更低数值（如 1）抢先执行

### 练习二

**思路**：使用 Node.js crypto 模块计算 HMAC-SHA256 签名，与请求头中的签名对比。注意处理 `sha256=` 前缀和时序安全比较。

**答案**：
```typescript
import crypto from 'crypto';

export function verifyWebhookSignature(
  body: string,
  signatureHeader: string,
  secret: string
): boolean {
  // 提取签名值（格式：sha256=xxxx）
  const parts = signatureHeader.split('=');
  if (parts.length !== 2 || parts[0] !== 'sha256') {
    return false;
  }

  const receivedSignature = parts[1];

  // 计算期望的签名
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(body)
    .digest('hex');

  // 使用时序安全的比较函数，防止时序攻击
  return crypto.timingSafeEqual(
    Buffer.from(receivedSignature, 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );
}

// Express 中间件用法
app.post('/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-webhook-signature'] as string;
  const isValid = verifyWebhookSignature(
    req.body.toString(),
    signature,
    WEBHOOK_SECRET
  );

  if (!isValid) {
    res.status(401).json({ error: '签名验证失败' });
    return;
  }

  // 处理 Webhook 事件
  handleEvent(JSON.parse(req.body));
  res.status(200).json({ received: true });
});
```

**要点**：
- 必须使用 `crypto.timingSafeEqual` 而非 `===` 比较签名，防止时序攻击泄露签名信息
- Express 中需使用 `express.raw()` 获取原始请求体，`express.json()` 会改变格式导致签名不匹配
- 签名格式通常为 `sha256=<hex_digest>`，需先解析前缀再比较
