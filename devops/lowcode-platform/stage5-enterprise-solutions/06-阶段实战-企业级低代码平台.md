## 多租户数据隔离

```
方案一：共享数据库，行级隔离
  所有租户的数据在同一个数据库，用 tenant_id 字段区分。
  优点：成本低、运维简单
  缺点：隔离性最弱，一个租户的慢查询可能影响其他租户
  适合：租户数量多、数据量小

方案二：共享数据库，Schema 隔离
  每个租户一个 Schema，共享数据库实例。
  优点：隔离性较好，成本适中
  缺点：Schema 数量有上限
  适合：租户数量中等（100-1000）

方案三：独立数据库
  每个租户一个独立数据库实例。
  优点：隔离性最强
  缺点：成本最高，运维复杂
  适合：大客户、合规要求高
```

推荐：大多数场景用方案一（行级隔离）+ 方案二（大客户 Schema 隔离）的混合模式。

## 插件系统

```typescript
// 插件接口定义
interface Plugin {
  name: string;
  version: string;
  initialize(context: PluginContext): void;
  destroy(): void;
}

interface PluginContext {
  // 注册自定义组件
  registerComponent(component: ComponentDefinition): void;
  // 注册自定义工作流节点
  registerWorkflowNode(node: WorkflowNodeDefinition): void;
  // 注册 API 扩展
  registerApiRoute(route: ApiRouteDefinition): void;
  // 监听事件
  on(event: string, handler: Function): void;
  // 访问平台 API
  api: PlatformApi;
}

// 插件示例：自定义审批节点
export default {
  name: 'approval-plugin',
  version: '1.0.0',
  initialize(ctx) {
    ctx.registerWorkflowNode({
      type: 'approval',
      name: '审批节点',
      config: {
        approver: { type: 'user', required: true },
        timeout: { type: 'number', default: 48 },
      },
      execute: async (input, config) => {
        const approved = await waitForApproval(config.approver, config.timeout);
        return { approved, comment: approved ? '已批准' : '已拒绝' };
      },
    });
  },
  destroy() {},
};
```

## 性能优化

```
缓存策略：
  ├── 页面配置：Redis 缓存，发布时失效
  ├── 数据模型：Redis 缓存，变更时失效
  ├── 用户权限：本地缓存 + Redis，登录时刷新
  └── 静态资源：CDN + 浏览器缓存

数据库优化：
  ├── 读写分离：写主库，读从库
  ├── 索引优化：tenant_id + 常用查询字段组合索引
  ├── 查询优化：避免 N+1 查询，使用 DataLoader
  └── 连接池：合理配置连接池大小

前端优化：
  ├── 代码分割：按路由懒加载
  ├── 组件懒加载：低代码组件按需加载
  ├── 预渲染：首屏 SSR
  └── 资源压缩：Gzip + 图片压缩
```

### 练习三

```typescript
import express from 'express';
import crypto from 'crypto';

const app = express();
app.use(express.json());

app.post('/webhook/form-submitted', (req, res) => {
  const signature = req.headers['x-webhook-signature'];
  const expected = crypto
    .createHmac('sha256', process.env.WEBHOOK_SECRET)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (signature !== expected) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  const { form_name, data } = req.body;

  // 转发到企业微信机器人
  fetch(process.env.WECOM_WEBHOOK_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      msgtype: 'markdown',
      markdown: {
        content: `**新表单提交**\n> 表单：${form_name}\n> 提交者：${data.submitter}\n> 时间：${data.created_at}`,
      },
    }),
  });

  res.json({ success: true });
});
```
