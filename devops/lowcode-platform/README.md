# 低代码/无代码平台开发与应用

> 30 课时 | 5 个阶段 | 从零掌握低代码平台搭建与企业级落地

## 课程定位

本课程面向有前端基础的开发者，系统讲解低代码/无代码平台的原理、选型、搭建与企业级应用。不停留在"拖拖拽拽"的表面，而是深入数据模型设计、组件体系、AI 集成、私有化部署等工程实践，让你真正理解低代码平台的运作机制，并能独立搭建和定制企业级低代码平台。

## 前置要求

- HTML/CSS/JavaScript 基础
- 了解 REST API 概念
- 基本的数据库知识（SQL）
- Node.js v18+ 环境

## 学完你能做到

1. 理解低代码平台的架构原理和设计决策
2. 能根据业务需求选择合适的低代码平台
3. 掌握数据模型设计、表单引擎、工作流引擎等核心模块
4. 能集成 AI 能力到低代码平台中
5. 能开发自定义组件并建立团队组件库
6. 能完成企业级低代码平台的私有化部署和定制开发

## 毕业项目

搭建一个**企业级低代码应用平台**，包含数据建模、页面搭建、工作流引擎、AI 辅助、自定义组件、私有化部署的完整能力。详见 [项目说明](./final-project/项目说明.md)。
