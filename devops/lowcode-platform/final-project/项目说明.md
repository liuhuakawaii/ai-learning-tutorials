# 毕业项目：企业级低代码应用平台

## 项目概述

搭建一个具备数据建模、页面搭建、工作流引擎、AI 辅助、自定义组件、私有化部署能力的企业级低代码应用平台。

## 项目目标

通过本项目，综合运用 5 个阶段所学知识，从零搭建一个可实际使用的低代码平台，覆盖从数据建模到应用发布的完整链路。

## 功能要求

### 一、数据建模模块（对应阶段一）

1. **可视化数据模型设计器**
   - 支持拖拽创建实体（表）
   - 支持字段类型：文本、数字、日期、布尔、枚举、关联
   - 支持一对一、一对多、多对多关系定义
   - 自动生成数据库表结构和 REST API

2. **数据管理**
   - 数据导入（CSV/Excel）
   - 数据导出
   - 数据验证规则
   - 批量操作

### 二、页面搭建模块（对应阶段二）

1. **可视化页面设计器**
   - 拖拽式组件布局
   - 属性面板配置
   - 数据源绑定
   - 事件绑定

2. **核心页面类型**
   - Dashboard 看板（图表、指标卡、实时数据）
   - 列表页（搜索、筛选、分页、排序）
   - 表单页（联动、校验、文件上传）
   - 详情页（多 Tab、关联数据展示）

3. **工作流引擎**
   - 可视化流程设计器
   - 审批节点、条件分支、并行网关
   - 通知机制（邮件、站内信）
   - 流程监控与日志

### 三、AI 能力模块（对应阶段三）

1. **AI 辅助建模**
   - 自然语言描述 → 数据模型
   - 智能字段推荐
   - 关系推断

2. **AI 生成页面**
   - 需求描述 → 页面结构
   - 布局优化建议
   - 组件推荐

3. **AI 数据处理**
   - 自然语言查询 → SQL/API 调用
   - 智能数据清洗
   - 数据分析报告生成

4. **AI 对话界面**
   - 内嵌 ChatBot 组件
   - 知识库问答
   - 上下文感知对话

### 四、组件体系（对应阶段四）

1. **内置组件**
   - 基础组件：按钮、输入框、选择器、日期选择
   - 布局组件：栅格、卡片、分割线、标签页
   - 数据组件：表格、列表、树形、级联
   - 图表组件：折线图、柱状图、饼图、仪表盘

2. **自定义组件规范**
   - 组件 Props 定义
   - 事件系统
   - 生命周期钩子
   - 数据绑定协议

3. **组件市场**
   - 组件发布与版本管理
   - 团队组件库
   - 组件文档自动生成

### 五、企业级能力（对应阶段五）

1. **私有化部署**
   - Docker Compose 一键部署
   - Kubernetes Helm Chart
   - 环境变量配置
   - 域名与 HTTPS 配置

2. **安全体系**
   - JWT 认证
   - RBAC 权限模型
   - 数据行级权限
   - 操作审计日志
   - 数据加密存储

3. **多租户**
   - 租户管理后台
   - 数据隔离
   - 配额管理
   - 计费接口

## 技术栈

- **前端**：React 18 + TypeScript + Ant Design
- **后端**：Node.js + Express/Fastify + TypeScript
- **数据库**：PostgreSQL（主库）+ Redis（缓存）
- **AI 集成**：OpenAI API / 本地 LLM
- **部署**：Docker + Docker Compose
- **构建**：Vite + pnpm workspace

## 分阶段交付

### 阶段一交付：数据建模与 API 生成
- 可视化数据模型设计器
- 自动 REST API 生成
- 基础 CRUD 操作
- 验证脚本：`node scripts/check.cjs --stage 1`

### 阶段二交付：页面搭建与工作流
- 可视化页面设计器
- Dashboard、列表、表单页面
- 工作流引擎基础版
- 验证脚本：`node scripts/check.cjs --stage 2`

### 阶段三交付：AI 集成
- AI 辅助建模
- AI 生成页面
- AI 数据查询
- 验证脚本：`node scripts/check.cjs --stage 3`

### 阶段四交付：组件体系
- 自定义组件规范
- 组件市场基础版
- 示例组件库
- 验证脚本：`node scripts/check.cjs --stage 4`

### 阶段五交付：企业级部署
- Docker Compose 部署配置
- 安全与权限完善
- 多租户基础版
- 验证脚本：`node scripts/check.cjs --stage 5`

## 评分标准

| 维度 | 权重 | 说明 |
|------|------|------|
| 数据建模 | 20% | 模型设计合理性、API 自动生成质量 |
| 页面搭建 | 25% | 设计器易用性、页面类型覆盖度 |
| AI 集成 | 20% | AI 功能实用性、响应质量 |
| 组件体系 | 15% | 组件规范合理性、扩展性 |
| 企业级能力 | 20% | 部署方案、安全体系、多租户 |

## 运行方式

```bash
# 安装依赖
pnpm install

# 启动开发环境
pnpm dev

# 运行验证脚本
node scripts/check.cjs

# Docker 部署
cd docker && docker-compose up -d
```
