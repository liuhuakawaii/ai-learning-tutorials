# 表单设计：复杂表单、联动、校验与文件上传

## 场景引入

你正在为制造企业搭建供应商入驻申请系统。供应商需要填写包含公司信息、资质证照、银行账户的复杂表单。表单中有大量联动逻辑：选择不同企业类型后字段随之变化；上传营业执照后公司名称自动识别填充；银行账户实时校验格式；整个表单分成多个步骤逐步填写。

表单是企业应用中最复杂、最容易出问题的组件。低代码平台需要在可视化配置框架下支持复杂场景，而不是只能做简单单列表单。本节课深入讲解复杂表单布局、字段联动、校验规则和文件上传。

## 学习目标

- 掌握复杂表单的布局方案：分区、分 Tab、分步骤
- 理解字段联动的四种模式：显隐、启用禁用、值填充、选项联动
- 学会配置校验规则：必填、格式、范围、异步校验
- 掌握文件上传的完整配置：单文件、多文件、预览、进度

## 字段联动

### 显隐联动

根据字段值控制其他字段的显示与隐藏：

```typescript
const companyTypeLinkage = {
  type: 'visibility',
  trigger: 'companyType',
  condition: { operator: 'eq', value: 'individual' },
  targets: ['registeredCapital', 'legalPerson']
}
// 选择"个体工商户"时，注册资本和法人代表字段隐藏
```

### 值填充联动

字段变化时自动填充其他字段：

```typescript
const ocrLinkage = {
  type: 'value',
  trigger: 'businessLicense',
  targets: [
    { field: 'companyName', source: 'expression', expression: 'trigger.ocr.companyName' },
    { field: 'creditCode', source: 'expression', expression: 'trigger.ocr.creditCode' },
    { field: 'establishDate', source: 'expression', expression: 'trigger.ocr.establishDate' }
  ]
}
```

### 选项联动

父级选择框决定子级选项列表：

```typescript
const regionLinkage = {
  type: 'options',
  trigger: 'province',
  target: 'city',
  dataSource: { type: 'api', url: '/api/regions/cities', paramField: 'provinceCode' }
}
```

## 校验规则

### 基础校验

```typescript
const commonRules: Record<string, ValidationRule[]> = {
  creditCode: [
    { type: 'required', message: '请输入统一社会信用代码' },
    { type: 'pattern', pattern: '^[0-9A-HJ-NPQRTUWXY]{2}\\d{6}[0-9A-HJ-NPQRTUWXY]{10}$',

  bankAccount: [
    { type: 'required', message: '请输入银行账号' },

}
```

### 异步校验

调用后端接口验证（如检查名称是否重复）：

```typescript
const duplicateCheckConfig = {
  url: '/api/suppliers/check-name',
  method: 'GET',
  paramField: 'companyName',
  debounce: 500,
  successCondition: { field: 'data.exists', value: true, matchResult: 'invalid' },
  message: '该公司名称已存在，请检查是否重复提交'
}
```

## 常见误区

1. **校验时机不当**：用户输入时就触发校验，每输入一个字符就报错。应使用 onBlur 校验或设置 debounce
2. **联动死循环**：A 变化触发 B 更新，B 又触发 A 更新。配置时需检查循环依赖
3. **上传不校验前端**：完全依赖后端校验文件类型和大小，用户上传大文件后才收到错误。应在 beforeUpload 前端校验

## 工程建议

1. **分步表单每步独立校验**：不要在最后一步才校验所有步骤，每步切换时就校验当前步骤字段
2. **联动配置需要防抖**：值填充联动如果触发 API 请求，应设置 300-500ms debounce
3. **上传文件命名规范**：重命名为 `{业务类型}_{时间戳}_{随机数}.{扩展名}`，避免中文文件名问题

## 小结

- 复杂表单布局优先使用分区，信息量更大时使用分步骤引导填写
- 字段联动有显隐、启用禁用、值填充、选项联动四种模式，注意循环依赖
- 校验规则分层配置：前端基础校验（格式、范围）+ 后端异步校验（唯一性）
- 文件上传需要前端预校验，支持预览和进度显示，配置响应数据映射

## 参考答案

### 练习一

**思路**：分区布局分为"个人信息""教育经历""工作经历"。教育和工作用动态列表组件支持增删。身份证号异步校验唯一性。

**答案**：

```typescript
const onboardingForm = {
  sections: [
    {
      key: 'personal', title: '个人基本信息', columns: 3,
      fields: [
        { key: 'name', label: '姓名', type: 'input', required: true },
        { key: 'idCard', label: '身份证号', type: 'input', required: true, span: 2,
          rules: [
            { type: 'pattern', pattern: '^\\d{17}[\\dX]$', message: '请输入正确的18位身份证号' },
            { type: 'async', asyncValidator: { url: '/api/employees/check-idcard', debounce: 500,
              message: '该身份证号已存在' } }
          ] },
        { key: 'phone', label: '手机号', type: 'input', required: true },
        { key: 'department', label: '入职部门', type: 'select', required: true,
          dataSource: { type: 'api', url: '/api/departments' } }
      ]
    },
    {
      key: 'education', title: '教育经历', type: 'formList', addable: true, removable: true, minItems: 1,
      fields: [
        { key: 'school', label: '学校名称', type: 'input', required: true },
        { key: 'major', label: '专业', type: 'input', required: true },
        { key: 'degree', label: '学历', type: 'select',
          options: [{ label: '专科', value: 'college' }, { label: '本科', value: 'bachelor' },
            { label: '硕士', value: 'master' }] },
        { key: 'dateRange', label: '就读时间', type: 'dateRange', required: true }
      ]
    },
    {
      key: 'work', title: '工作经历', type: 'formList', addable: true, removable: true, minItems: 0,
      fields: [
        { key: 'company', label: '公司名称', type: 'input', required: true },
        { key: 'position', label: '职位', type: 'input', required: true },
        { key: 'dateRange', label: '任职时间', type: 'dateRange', required: true }
      ]
    }
  ],
  submit: { api: { url: '/api/employees', method: 'POST' }, successAction: { type: 'navigate', target: '/employees' } }
}
```

**要点**：
- 身份证号异步校验设置 500ms 防抖
- 教育经历最少 1 条，工作经历最少 0 条（应届生可能没有）
- FormList 组件支持动态增删，每条记录独立校验

### 练习二

**思路**：分步骤：第一步选类目，第二步填信息和属性，第三步上传图片，第四步设价格。类目选择后联动加载品牌和属性。

**答案**：

```typescript
const productForm = {
  type: 'steps',
  steps: [
    { key: 'category', title: '选择类目',
      fields: [{ key: 'category', label: '商品类目', type: 'cascader', required: true,
        dataSource: { type: 'api', url: '/api/categories/tree' } }] },
    { key: 'basic', title: '基本信息',
      fields: [
        { key: 'name', label: '商品名称', type: 'input', required: true, maxLength: 120 },
        { key: 'brand', label: '品牌', type: 'select', required: true,
          linkage: { trigger: 'category', source: { type: 'api', url: '/api/brands', paramField: 'categoryId' } } },
        { key: 'attributes', label: '商品属性', type: 'dynamicForm',
          linkage: { trigger: 'category', source: { type: 'api', url: '/api/attributes', paramField: 'categoryId' } } }
      ] },
    { key: 'media', title: '图片与详情',
      fields: [
        { key: 'mainImages', label: '商品主图', type: 'upload', required: true,
          uploadConfig: { type: 'multi', maxCount: 5, listType: 'picture-card', draggable: true } },
        { key: 'detail', label: '商品详情', type: 'richEditor', required: true }
      ] },
    { key: 'price', title: '价格库存',
      fields: [
        { key: 'price', label: '售价(元)', type: 'number', required: true, min: 0.01, precision: 2 },
        { key: 'memberPrice', label: '会员价(元)', type: 'number', precision: 2,
          linkage: { trigger: 'price', type: 'visibility', condition: { field: 'hasMemberLevel', value: true } } },
        { key: 'stock', label: '库存数量', type: 'number', required: true, min: 0 }
      ] }
  ]
}
```

**要点**：
- 类目使用 cascader 级联选择器，品牌和属性通过选项联动加载
- 主图支持拖拽排序（draggable: true），最多 5 张
- 会员价仅在店铺开启会员功能时显示（显隐联动）
