# 报表与导出：报表设计器、Excel/PDF 导出

## 场景引入

你是公司财务负责人，每月需要生成销售汇总表、应收账款明细、利润分析报告。这些报表需按固定格式排版，支持按部门和时间分组汇总，还要导出为 Excel 供同事二次分析，导出为 PDF 用于存档打印。过去这些工作由财务人员手动用 Excel 完成，每月耗费两三天。

报表是企业数据价值最终落地的载体。Dashboard 适合实时监控，报表更强调数据完整性和可存档性。本节课讲解报表设计器、数据聚合、Excel/PDF 导出和定时报表。

## 学习目标

- 掌握报表设计器的基本用法，包括数据源配置和字段拖拽
- 理解数据聚合的三种模式：分组、透视、交叉表
- 学会使用 xlsx 库实现 Excel 导出
- 了解定时报表的调度配置和打印友好布局

## Excel 导出

### 使用 xlsx 库

```typescript
import * as XLSX from 'xlsx'

function exportToExcel(data: any[], config: ExcelExportConfig) {
  const worksheetData = [
    config.columns.map(col => col.header),
    ...data.map(row => config.columns.map(col => row[col.key]))
  ]

  const worksheet = XLSX.utils.aoa_to_sheet(worksheetData)
  config.columns.forEach((_, i) => {
    worksheet['!cols'] = worksheet['!cols'] || []
    worksheet['!cols'][i] = { wch: config.columns[i].width || 15 }
  })

  const workbook = XLSX.utils.book_new()
  XLSX.utils.book_append_sheet(workbook, worksheet, config.sheetName)
  XLSX.writeFile(workbook, `${config.filename}.xlsx`)
}

const salesExcelConfig = {
  filename: '销售报表',
  sheetName: '销售数据',
  columns: [
    { key: 'region', header: '区域', width: 12 },
    { key: 'salesperson', header: '销售人员', width: 15 },
    { key: 'orderCount', header: '订单数', width: 10 },
    { key: 'amount', header: '销售金额', width: 15, format: '#,##0.00' }
  ]
}
```

### 多 Sheet 导出

```typescript
async function exportMultiSheet(config: MultiSheetExport) {
  const workbook = XLSX.utils.book_new()
  for (const sheet of config.sheets) {
    const res = await fetch(sheet.dataSource.url, { method: 'POST', body: JSON.stringify(sheet.dataSource.params) })
    const { data } = await res.json()
    const worksheet = XLSX.utils.json_to_sheet(data, { header: sheet.columns.map(c => c.key) })
    XLSX.utils.book_append_sheet(workbook, worksheet, sheet.name)
  }
  XLSX.writeFile(workbook, `${config.filename}.xlsx`)
}
```

## 常见误区

1. **导出大数据量不处理**：一次导出十万行导致浏览器内存溢出。超过 1 万行应使用后端流式导出
2. **报表格式硬编码**：格式写死在代码中，修改需重新发版。应将模板配置化存储在数据库中
3. **PDF 中文乱码**：生成 PDF 时未配置中文字体，中文显示为方块。需在配置中指定中文字体文件

## 工程建议

1. **大数据量导出走后端**：超过 1 万行由后端生成文件返回下载链接，前端轮询导出进度
2. **报表模板版本管理**：模板修改后保留历史版本，支持回滚
3. **Excel 导出保留公式**：有计算列时使用 Excel 公式而非静态值，方便用户修改数据后自动重算

## 小结

- 报表设计器采用"页头-数据区-页尾"三段式结构，支持表格、分组、透视三种模式
- 透视表通过行、列、值交叉组合生成多维度汇总表
- Excel 导出使用 xlsx 库，大数据量走后端流式导出
- 定时报表通过 cron 表达式调度，支持邮件和存储多渠道分发

## 参考答案

### 练习一

**思路**：透视表配置行 region 列 month 值 amount(sum)。导出时在 Excel 中插入小计行和合计行。

**答案**：

```typescript
import * as XLSX from 'xlsx'

async function exportPivotToExcel(pivotData: any[]) {
  const months = [...new Set(pivotData.map(d => d.month))].sort()
  const regions = [...new Set(pivotData.map(d => d.region))]

  const rows: any[][] = [['区域', ...months.map(m => `${m}月`), '合计']]
  for (const region of regions) {
    const row: any[] = [region]
    let total = 0
    for (const month of months) {
      const cell = pivotData.find(d => d.region === region && d.month === month)
      const value = cell ? cell.amount : 0
      row.push(value)
      total += value
    }
    row.push(total)
    rows.push(row)
  }

  const totalRow = ['合计']
  for (let i = 0; i < months.length; i++) {
    totalRow.push(rows.slice(1).reduce((sum, row) => sum + (row[i + 1] || 0), 0))
  }
  totalRow.push(rows.slice(1).reduce((sum, row) => sum + row[row.length - 1], 0))
  rows.push(totalRow)

  const ws = XLSX.utils.aoa_to_sheet(rows)
  const wb = XLSX.utils.book_new()
  XLSX.utils.book_append_sheet(wb, ws, '销售透视表')
  XLSX.writeFile(wb, '销售透视报表.xlsx')
}
```

**要点**：
- 透视数据先从 API 获取原始数据，再按行列维度聚合
- 小计行在每组末尾，合计行在最后，手动计算
- 金额列使用数字格式 `#,##0.00`

- 同时发送 PDF（存档）和 Excel（二次分析）
- 报表文件按年月归档存储
