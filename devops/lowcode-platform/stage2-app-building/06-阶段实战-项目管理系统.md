# 阶段实战：项目管理系统

> 前置知识：Dashboard、列表详情页、表单设计、报表、移动端适配（第 1-5 课）

## 你要做什么

用低代码平台搭建一个轻量级项目管理系统，替代 Jira。核心功能：任务看板、甘特图、团队管理、活动动态、冲刺规划。

两周内完成第一版。

## 领域模型

```typescript
interface Project {
  id: string;
  name: string;
  key: string;           // 如 "CRM"
  description: string;
  owner_id: string;
  status: 'active' | 'archived';
  created_at: Date;
}

interface Task {
  id: string;
  project_id: string;
  title: string;
  description: string;
  status: 'backlog' | 'todo' | 'in_progress' | 'review' | 'done';
  priority: 'critical' | 'high' | 'medium' | 'low';
  assignee_id: string;
  reporter_id: string;
  sprint_id: string;
  story_points: number;
  due_date: Date;
  tags: string[];
  created_at: Date;
  updated_at: Date;
}

interface Sprint {
  id: string;
  project_id: string;
  name: string;
  start_date: Date;
  end_date: Date;
  goal: string;
  status: 'planning' | 'active' | 'completed';
}

interface Activity {
  id: string;
  task_id: string;
  user_id: string;
  type: 'comment' | 'status_change' | 'assignment' | 'update';
  content: string;
  created_at: Date;
}
```

## 页面规划

```
项目管理系统页面：
├── 项目列表页（所有项目概览）
├── 项目详情页
│   ├── 看板视图（按状态分列的卡片墙）
│   ├── 列表视图（表格形式的任务列表）
│   ├── 甘特图视图（时间线展示）
│   └── 冲刺规划（Backlog + Sprint 分配）
├── 任务详情页
│   ├── 基本信息（标题、描述、状态、优先级）
│   ├── 活动动态（评论、变更记录）
│   └── 关联任务
├── 团队管理页（成员列表、工作量分配）
└── 报表页（燃尽图、速度图、任务分布）
```

## 看板视图

看板是项目管理系统最核心的视图。用拖拽方式改变任务状态：

```json
{
  "type": "kanban",
  "dataSource": {
    "type": "api",
    "endpoint": "/api/tasks",
    "params": { "project_id": "{{project.id}}" }
  },
  "groupBy": "status",
  "columns": [
    { "key": "backlog", "title": "Backlog", "color": "#d9d9d9" },
    { "key": "todo", "title": "To Do", "color": "#1890ff" },
    { "key": "in_progress", "title": "In Progress", "color": "#faad14" },
    { "key": "review", "title": "Review", "color": "#722ed1" },
    { "key": "done", "title": "Done", "color": "#52c41a" }
  ],
  "cardTemplate": {
    "title": "{{title}}",
    "subtitle": "{{assignee_id.name}}",
    "badges": [
      { "field": "priority", "color": "critical:red,high:orange,medium:blue,low:gray" },
      { "field": "story_points", "prefix": "SP:" }
    ]
  },
  "onDrop": {
    "action": "update",
    "field": "status",
    "value": "{{column.key}}"
  }
}
```

```json
  "dependencies": true

```

## 冲刺规划

```
左侧：Backlog（未分配到 Sprint 的任务）
右侧：当前 Sprint（已分配的任务）

操作：
- 从 Backlog 拖拽任务到 Sprint
- 在 Sprint 内调整优先级
- 从 Sprint 拖回 Backlog
- 显示 Sprint 容量（总 Story Points）
```

## 练习

### 练习一：添加时间追踪

为任务添加"已花费时间"和"预估时间"字段。在任务详情页显示时间追踪进度条。

### 练习二：添加通知

配置工作流：当任务被分配给某人时，发送通知。当任务状态变为"review"时，通知 reviewer。

### 练习三：速度图

创建一个速度图报表：展示每个 Sprint 完成的 Story Points 趋势。用于评估团队的交付能力。

## 参考答案

### 练习一

添加字段：

```json
{ "name": "estimated_hours", "type": "number", "label": "预估工时" },
{ "name": "spent_hours", "type": "number", "label": "已花费工时" }
```

时间追踪组件：

```json
{
  "type": "progress",
  "value": "{{task.spent_hours}}",
  "max": "{{task.estimated_hours}}",
  "format": "{{spent}}h / {{estimated}}h",
  "color": {
    "green": "< 80%",
    "yellow": "80-100%",
    "red": "> 100%"
  }
}
```
