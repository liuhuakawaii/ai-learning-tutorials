# 阶段二：应用搭建

> 6 课时 | 掌握低代码平台的核心应用搭建能力

## 阶段目标

- 能搭建数据驱动的 Dashboard 看板
- 掌握 CRUD 页面的快速开发模式
- 能设计复杂的表单交互和数据联动
- 掌握报表设计和数据导出
- 理解移动端适配策略
- 能独立搭建完整的项目管理系统

## 学习建议

1. 每节课都动手搭建实际页面，不要只看不练
2. Dashboard 和列表页是最高频的场景，务必熟练
3. 项目管理系统实战建议分模块逐步完成
