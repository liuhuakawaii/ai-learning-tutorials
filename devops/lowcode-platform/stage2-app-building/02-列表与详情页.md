# 列表与详情页：CRUD 页面、搜索筛选与分页排序

## 场景引入

你正在为公司搭建客户管理系统，第一个要做的页面就是客户列表。需要支持按名称搜索、按状态筛选、按创建时间排序，还要分页浏览上万条记录。点击某行跳转到客户详情页，查看基本信息、联系记录、订单历史。运营人员还需要批量导出和批量修改状态。

这个场景覆盖了企业应用中最常见的页面模式——列表与详情。订单列表、商品列表、用户列表、审批列表都离不开它。本节课系统讲解低代码平台中列表页和详情页的构建方法。

## 学习目标

- 掌握数据表格组件的配置方法，包括列定义、格式化和自定义渲染
- 理解搜索、筛选、排序的交互设计与配置方式
- 区分客户端分页和服务端分页的适用场景
- 学会详情页的 Tabs 布局和主从关系模式

### 筛选条件 URL 同步

筛选条件应同步到 URL，用户刷新页面或分享链接时能保留筛选状态：

```typescript
function syncFiltersToUrl(filters: Record<string, any>) {
  const params = new URLSearchParams()
  Object.entries(filters).forEach(([key, value]) => {
    if (value !== undefined && value !== '' && value !== null) params.set(key, String(value))
  })
  window.history.replaceState(null, '', `${window.location.pathname}?${params.toString()}`)
}
```

## 分页策略

```typescript
// 客户端分页：一次性加载全部数据，前端切页（< 500 条）
const clientPagination = { type: 'client', pageSize: 20, pageSizeOptions: [10, 20, 50] }

// 服务端分页：每次请求一页数据（> 500 条）
const serverPagination = {
  type: 'server', pageSize: 20, pageSizeOptions: [10, 20, 50, 100],
  api: { pageField: 'page', sizeField: 'pageSize', totalField: 'data.total', itemsField: 'data.items' }
}
```

分页参数需和筛选参数一起发送，切换筛选时应重置到第一页。

## 常见误区

1. **默认加载全量数据**：列表页默认不带筛选条件，首次加载就请求全量数据。应设置合理默认筛选（如"最近30天"）
2. **忽略空状态设计**：筛选无结果时只显示空白页面。应展示友好空状态提示，并提供"清除筛选"入口
3. **详情页信息平铺**：把所有字段堆在一个页面上。应使用 Tabs 或分组卡片按业务逻辑归类

## 工程建议

1. **筛选条件变化时重置页码**：用户切换筛选后，当前页码可能超出新结果总页数，应自动回到第一页
2. **表格列宽设置最小值**：避免列宽过窄导致内容截断，名称类字段应设置 minWidth 并允许 tooltip
3. **详情页数据懒加载**：Tabs 中的数据不要一次性全部请求，切换到某 Tab 时才加载对应数据

## 小结

- 数据表格列定义需要明确格式化方式，状态字段使用颜色标签提升可读性
- 搜索栏遵循"常用外露、高级收起"原则，筛选条件同步到 URL
- 数据量 < 500 条用客户端分页，> 500 条必须用服务端分页
- 详情页使用 Tabs 组织信息，Tab 内数据懒加载，主从模式减少页面跳转

### 练习一

**思路**：订单列表是典型服务端分页场景。搜索栏提供订单号精确搜索和状态下拉筛选，排序为创建时间和金额。批量发货需选中"待发货"状态订单。

- 分页 20 条/页，支持切换到 50、100

### 练习二

**思路**：顶部摘要 + Tabs 经典布局。各 Tab 独立加载，联系记录和订单用表格，备注用时间线。

**答案**：

```typescript
const customerDetailConfig = {
  header: {
    fields: [{ key: 'name', label: '客户名称', span: 'title' }, { key: 'level', format: 'status' },
      { key: 'phone', label: '联系电话' }, { key: 'email', label: '邮箱' }],

  tabs: [
    { key: 'info', label: '基本信息', component: 'Descriptions',
      dataSource: { type: 'api', url: '/api/customers/:id', loadOn: 'mount' } },
    { key: 'contacts', label: '联系记录', component: 'DataTable',
      dataSource: { type: 'api', url: '/api/customers/:id/contacts', loadOn: 'tab-active' },
      columns: [{ key: 'type', title: '联系方式' }, { key: 'content', title: '内容' },
        { key: 'contactAt', title: '时间', format: 'date' }] },
    { key: 'orders', label: '订单历史', component: 'DataTable',
      dataSource: { type: 'api', url: '/api/customers/:id/orders', loadOn: 'tab-active' },
      columns: [{ key: 'orderNo', title: '订单号' }, { key: 'status', format: 'status' },
        { key: 'amount', format: 'currency' }] },
    { key: 'notes', label: '跟进备注', component: 'Timeline',
```

**要点**：
- 基本信息 Tab 在页面加载时请求（loadOn: mount），其他 Tab 切换时加载
- 联系记录和订单用 DataTable 支持排序筛选，备注用 Timeline 更适合时间序列
- Header 操作按钮根据权限动态显示
