# 阶段实战：本地生产模拟环境

> 前置知识：Compose 全部课程（第 1-6 课）

## 你要搭什么

一个完整的本地开发环境，模拟生产架构：

```
浏览器请求 → Nginx 反向代理 → Next.js 前端 / Express API
                                    ↓
                              PostgreSQL + Redis
```

一条命令启动，新同事入职五分钟跑起来。这不是 demo——这是你在真实项目里会交给团队的东西。

## docker-compose.yml

```yaml
services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      frontend:
        condition: service_healthy
      api:
        condition: service_healthy
    restart: unless-stopped

  frontend:
    build:
      context: ./frontend
      target: development
    volumes:
      - ./frontend/src:/app/src
    environment:
      - NEXT_PUBLIC_API_URL=http://localhost/api
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000"]
      interval: 10s
      retries: 3

  api:
    build:
      context: ./api
      target: development
    volumes:
      - ./api/src:/app/src
    environment:
      DATABASE_URL: postgres://postgres:secret@db:5432/appdb
      REDIS_URL: redis://redis:6379
      NODE_ENV: development
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_started
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:4000/health"]
      interval: 10s
      retries: 3

  db:
    image: postgres:14-alpine
    environment:
      POSTGRES_DB: appdb
      POSTGRES_PASSWORD: secret
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./init-db:/docker-entrypoint-initdb.d:ro
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    volumes:
      - redis-data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      retries: 5

volumes:
  pgdata:
  redis-data:
```

## Nginx 配置

```nginx
# nginx/nginx.conf
upstream frontend {
    server frontend:3000;
}

upstream api {
    server api:4000;
}

server {
    listen 80;

    location /api/ {
        proxy_pass http://api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        proxy_pass http://frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 启动与验证

```bash
# 一条命令启动
docker compose up -d

# 查看所有容器状态
docker compose ps

# 访问前端
curl http://localhost

# 访问 API
curl http://localhost/api/health

# 查看日志
docker compose logs -f api

# 停止
docker compose down

# 停止并清除数据
docker compose down -v
```

## 可能遇到的问题

### 问题一：前端连不上 API

症状：前端页面报网络错误，但 API 单独能访问。

排查：检查 `NEXT_PUBLIC_API_URL`。浏览器发出的请求走的是 Nginx，不是容器内部网络。所以 API URL 必须是 `http://localhost/api`，不是 `http://api:4000`。

### 问题二：数据库初始化脚本没执行

症状：表不存在，但 PostgreSQL 容器正常运行。

排查：`/docker-entrypoint-initdb.d` 只在**首次创建数据卷**时执行。如果你之前 `docker compose up` 过一次，pgdata 卷里已经有数据了。解决方式：

```bash
docker compose down -v   # 删除数据卷
docker compose up -d     # 重新启动，触发初始化
```

### 问题三：热更新不生效

症状：修改了 src 下的代码，但容器里的应用没有变化。

排查：检查 `volumes` 配置是否正确挂载了 `./api/src:/app/src`。如果用的是 Windows，注意路径分隔符和文件系统大小写敏感问题。

## 练习

### 练习一：添加数据库管理工具

在 compose.yml 中添加 pgAdmin 服务（`dpage/pgadmin4` 镜像，端口 5050），配置它能连接到 db 服务。用浏览器访问 pgAdmin，验证能看到 appdb 的表。

### 练习二：添加 Redis 缓存

修改 API 的健康检查，让它同时检查 Redis 连接。在 API 中添加一个 `/cache-test` 接口：第一次请求返回当前时间并写入 Redis，后续请求返回缓存的时间（TTL 30 秒）。

### 练习三：模拟生产配置

创建 `compose.prod.yml`（不挂载 bind mount、不用 development target），用以下命令启动：

```bash
docker compose -f docker-compose.yml -f compose.prod.yml up -d
```

验证所有服务正常运行，没有热更新功能。

## 参考答案

### 练习一

```yaml
pgadmin:
  image: dpage/pgadmin4
  ports:
    - "5050:80"
  environment:
    PGADMIN_DEFAULT_EMAIL: admin@example.com
    PGADMIN_DEFAULT_PASSWORD: admin
  depends_on:
    db:
      condition: service_healthy
```

访问 `http://localhost:5050`，用 `admin@example.com / admin` 登录。添加 server 时，host 填 `db`，username 填 `postgres`，password 填 `secret`。

### 练习二

API 健康检查同时检查 Redis：

```typescript
healthRouter.get('/', async (req, res) => {
  try {
    await redis.ping();
    res.json({ status: 'ok', redis: 'connected', db: 'connected' });
  } catch (err) {
    res.status(503).json({ status: 'degraded', redis: 'disconnected' });
  }
});
```

缓存接口：

```typescript
app.get('/cache-test', async (req, res) => {
  const cached = await redis.get('cache-test');
  if (cached) {
    return res.json({ source: 'cache', time: cached });
  }
  const now = new Date().toISOString();
  await redis.set('cache-test', now, 'EX', 30);
  res.json({ source: 'fresh', time: now });
});
```
