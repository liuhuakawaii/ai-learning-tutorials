# 第一阶段：Docker 基础

## 阶段目标

理解镜像、容器、Dockerfile、构建上下文、网络、卷和多阶段构建，能独立容器化一个应用。

## 课时安排

1. 为什么需要容器
2. 镜像、容器、仓库（含镜像存储位置和生命周期）
3. Dockerfile 基础（含构建上下文和 .dockerignore）
4. 构建缓存与多阶段构建（含镜像体积优化）
5. 数据卷与网络（含开发热更新和容器间通信）
6. 安全基础（非 root 用户、密钥管理、漏洞扫描）
7. 阶段实战：容器化 Node API

## 阶段项目

为一个 Node API 写 Dockerfile，支持开发和生产两种运行方式。

## 验收标准

- 镜像能成功构建
- 容器启动后可访问健康检查
- 不把 node_modules 和密钥打进镜像
- 使用非 root 用户或说明安全边界
- 使用多阶段构建，镜像体积 < 200MB
