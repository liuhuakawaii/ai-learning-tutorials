# Production Launch Kit 项目说明

## 项目目标

构建一套可复用的全栈项目上线模板。它要能在本地用 Compose 跑起来，也能通过 CI/CD 部署到服务器。

## 内置 project kit

课程提供一个可检查模板：

```text
docker-cicd-course/final-project/production-launch-kit
```

运行：

```bash
cd docker-cicd-course/final-project/production-launch-kit
npm run check
npm start
```

API：

- http://localhost:4190/health
- http://localhost:4190/version

如果本机安装了 Docker，可以运行 `docker compose up --build` 做完整容器验证。

## 系统组成

```txt
web        Next.js 前端
api        Node.js 或 FastAPI 后端
postgres   主数据库
redis      缓存 / 队列
nginx      反向代理
actions    CI/CD workflow
scripts    deploy / backup / rollback
```

## 核心文件

- `Dockerfile.web`
- `Dockerfile.api`
- `docker-compose.yml`
- `docker-compose.prod.yml`
- `.github/workflows/ci.yml`
- `.github/workflows/deploy.yml`
- `scripts/deploy.sh`
- `scripts/backup-db.sh`
- `scripts/rollback.sh`
- `.env.example`

## 阶段交付物

| 阶段 | 交付物 | 对应 project kit |
|------|--------|------------------|
| 第一阶段 | Dockerfile、多阶段构建、构建上下文和安全边界 | `Dockerfile.api`、`.dockerignore`、`reports/stage1-container.md` |
| 第二阶段 | Compose services、volume、healthcheck 和启动顺序 | `docker-compose.yml`、`reports/stage2-compose.md` |
| 第三阶段 | CI workflow、构建步骤、镜像策略和 secrets 边界 | `.github/workflows/ci.yml`、`reports/stage3-ci.md` |
| 第四阶段 | 反向代理、HTTPS、迁移、备份和部署脚本 | `scripts/deploy.sh`、`scripts/backup-db.sh`、`reports/stage4-deploy.md` |
| 第五阶段 | 健康检查、资源限制、回滚、安全基线 | `docker-compose.prod.yml`、`scripts/rollback.sh`、`reports/stage5-reliability.md` |

## 验收标准

- `docker compose up` 能启动完整本地环境
- CI 能完成 lint、test、build
- 镜像使用多阶段构建
- 数据库数据通过 volume 持久化
- API 有 `/health` 健康检查
- 部署脚本可重复执行
- README 包含故障排查和回滚步骤
- 内置 project kit 的 `npm run check` 通过
