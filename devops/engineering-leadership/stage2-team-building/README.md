# 阶段 2：团队建设

> 6 课时 | 搭建一支能打硬仗的工程团队

## 本阶段目标

完成这个阶段后，你将能够：
- 设计高效的招聘流程，从 JD 到 Offer 全链路把控
- 建立团队文化：心理安全、价值观对齐、多样性包容
- 用 OKR 对齐目标，做绩效评估，处理低绩效成员
- 设计人才培养体系：导师制、轮岗、培训计划
- 应对团队从 5 人到 50 人的扩展挑战，设计组织架构
- 输出一份完整的团队建设方案

## 课时列表

| 课时 | 主题 | 核心能力 |
|------|------|----------|
| 01 | 招聘与面试 | JD 设计、面试流程、评估标准 |
| 02 | 团队文化 | 价值观、心理安全、多样性 |
| 03 | 绩效管理 | OKR、绩效评估、低绩效处理 |
| 04 | 人才培养 | 职业发展、导师制、培训体系 |
| 05 | 团队扩展 | 组织架构、管理层培养、规模化 |
| 06 | 阶段实战：团队建设方案 | 综合应用、方案设计、落地执行 |

## 学完本阶段的标志

- 你有一套标准的面试评估表和评分标准
- 你的团队能说出 3 条以上团队价值观
- 你完成过至少一次完整的绩效评估周期
- 你有一份针对当前团队的建设方案
