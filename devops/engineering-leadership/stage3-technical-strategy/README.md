# 阶段 3：技术战略

> 6 课时 | 用技术驱动业务，而不是被业务拖着走

## 本阶段目标

完成这个阶段后，你将能够：
- 制定技术愿景和技术路线图，与业务目标对齐
- 识别、量化、制定技术债务偿还策略
- 建立架构评审机制，用 ADR 和技术雷达治理架构
- 用结构化框架做技术选型，管理迁移风险
- 设计创新机制：20% 时间、黑客马拉松、POC 验证
- 输出一份完整的技术战略规划

## 课时列表

| 课时 | 主题 | 核心能力 |
|------|------|----------|
| 01 | 技术愿景 | 路线图、业务对齐、技术叙事 |
| 02 | 技术债务管理 | 识别、量化、偿还策略 |
| 03 | 架构治理 | 架构评审、ADR、技术雷达 |
| 04 | 技术选型 | 评估框架、风险分析、迁移策略 |
| 05 | 创新管理 | 20% 时间、黑客马拉松、POC |
| 06 | 阶段实战：技术战略规划 | 综合应用、战略制定、路线图 |

## 学完本阶段的标志

- 你有一份技术路线图，每条线都能对齐到业务目标
- 你能量化团队的技术债务（人天、风险等级）
- 你建立过架构评审流程并写过 ADR
- 你有一份正在执行的技术战略规划
