# 阶段 4：执行与交付

> 6 课时 | 把战略变成可交付的结果

## 本阶段目标

完成这个阶段后，你将能够：
- 选择并落地适合团队的敏捷实践（Scrum/Kanban）
- 用项目管理框架控制范围、时间、风险和干系人
- 设计发布管理流程：灰度发布、回滚、发布节奏
- 建立质量保障体系：代码审查、测试策略、SLA
- 高效进行跨团队协作：依赖管理、对齐、冲突解决
- 输出一份完整的大型项目交付方案

## 学完本阶段的标志

- 你的团队有稳定的迭代节奏和可预测的交付能力
- 你管理过至少一个涉及 3 个以上团队的项目
- 你的团队有明确的 SLA 和质量指标
- 你有一份完整的大型项目交付方案作为参考
