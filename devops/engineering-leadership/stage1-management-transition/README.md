# 阶段 1：管理转型

> 6 课时 | 从工程师到管理者的第一次蜕变

## 本阶段目标

完成这个阶段后，你将能够：
- 理解 IC 和 Manager 的本质区别，完成心态转变
- 通过一对一会议建立信任、发现问题、辅导成长
- 合理分配任务，在"放手"和"可控"之间找到平衡
- 用结构化框架做技术决策，写 ADR 记录决策过程
- 向上管理：与上级建立有效沟通，争取资源
- 制定并执行一份新经理 90 天上任计划

## 课时列表

| 课时 | 主题 | 核心能力 |
|------|------|----------|
| 01 | 从 IC 到 Manager | 角色认知、心态调整、时间管理 |
| 02 | 一对一会议 | 倾听、反馈、辅导、信任建立 |
| 03 | 任务分配 | 识人用人、委派、跟进机制 |
| 04 | 技术决策 | 决策框架、trade-off 分析、ADR |
| 05 | 向上管理 | 汇报技巧、资源争取、预期管理 |
| 06 | 阶段实战：新经理 90 天计划 | 综合应用、计划制定、执行落地 |

## 学完本阶段的标志

- 你能清晰说出"我这周在管理上花了多少时间，花在了哪里"
- 你和每个直接下属都建立了固定的 1:1 节奏
- 你写过至少一份 ADR（Architecture Decision Record）
- 你有一份正在执行的 90 天计划
