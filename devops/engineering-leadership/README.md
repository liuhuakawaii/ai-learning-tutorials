# 工程管理与技术领导力

> 30 课时 | 5 个阶段 | 面向从 IC 转型管理者或希望系统提升领导力的工程负责人

## 课程定位

这门课不是管理学理论的堆砌，而是一份**工程管理者的真实作战手册**。每一节课都从工程团队中反复出现的真实场景出发——怎么跟绩效不达标的下属谈、怎么在技术选型中做取舍、怎么向 CEO 要到更多人头——然后给出可以直接落地的方法和工具。

**适合谁：**
- 刚从高级工程师晋升 Tech Lead / Engineering Manager 的人
- 带 3-15 人团队、希望系统提升管理能力的一线经理
- 有技术背景、想理解工程团队运作逻辑的产品或业务负责人

**不适合：**
- 没有技术背景的纯管理者（本课程假设你理解软件工程的基本概念）
- 只想学框架 API 不关心团队协作的纯 IC

## 学习路线

```
阶段 1：管理转型（6 课时）
  └─ 从 IC 到 Manager 的角色转变、1:1、任务分配、向上管理

阶段 2：团队建设（6 课时）
  └─ 招聘、文化、绩效、人才培养、组织扩展

阶段 3：技术战略（6 课时）
  └─ 技术愿景、技术债务、架构治理、技术选型、创新管理

阶段 4：执行与交付（6 课时）
  └─ 敏捷实践、项目管理、发布管理、质量保障、跨团队协作

阶段 5：职业成长（6 课时）
  └─ 技术影响力、高管沟通、组织设计、工程文化、职业路径
```

## 学习建议

1. **按顺序学习**：每个阶段都建立在前一个阶段的基础上
2. **完成每课练习**：管理能力只能通过实践获得，练习是最低成本的实践
3. **找一个管理导师**：课程提供框架，但真实场景中的判断力需要经验积累
4. **写管理日志**：记录你每周的管理决策和反思，90 天后回看会有巨大收获
