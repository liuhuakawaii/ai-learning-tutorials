# 阶段1：单元测试

> 6 课时 | 建立测试思维，掌握 Vitest 实战

## 阶段目标

- 理解测试金字塔和 FIRST 原则
- 熟练使用 Vitest 编写单元测试
- 掌握异步代码的测试方法
- 实践 TDD 开发流程
- 能独立为工具函数库编写完整测试

## 课时列表

| 课时 | 标题 | 核心技能 |
|------|------|----------|
| 01 | 测试思维与原则 | 测试金字塔、FIRST 原则、AAA 模式 |
| 02 | Vitest 实战 | 配置、断言、describe/it/expect |
| 03 | Jest 对比与迁移 | Jest vs Vitest、迁移策略 |
| 04 | 异步测试 | Promise/async/callback 测试 |
| 05 | TDD 实践 | 测试驱动开发流程 |
| 06 | 阶段实战 | 为工具函数库写完整测试 |

## 学完本阶段你能做到

- 看到一个函数，能立即规划出需要测试的场景
- 用 Vitest 编写清晰、可维护的单元测试
- 用 TDD 方式开发新功能
