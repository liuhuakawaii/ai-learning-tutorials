# 阶段实战：质量度量看板

## 场景引入

前面五课我们分别学了覆盖率、变异测试、模糊测试和基准测试。每种工具都能生成报告，但散落在各处。团队需要一个统一的质量度量看板，一眼看到质量趋势。

## 学习目标

- 整合覆盖率、变异测试、基准测试三类数据
- 搭建静态看板展示质量趋势
- 集成到 CI 实现自动更新

## 数据收集

```typescript
// scripts/collect-metrics.ts
import { readFileSync, writeFileSync, existsSync, mkdirSync } from 'fs'
import { join } from 'path'

interface MetricsEntry {
  timestamp: string
  commit: string
  branch: string
  coverage: { statements: number; branches: number; functions: number; lines: number }
  mutationScore: number
  mutationDetails: { killed: number; survived: number; total: number }
  benchmarks: Record<string, { hz: number; mean: number; p99: number }>
}

function collectCoverage(): MetricsEntry['coverage'] {
  const path = join(process.cwd(), 'coverage', 'coverage-summary.json')
  if (!existsSync(path)) return { statements: 0, branches: 0, functions: 0, lines: 0 }
  const data = JSON.parse(readFileSync(path, 'utf-8'))
  return {
    statements: data.total.statements.pct,
    branches: data.total.branches.pct,
    functions: data.total.functions.pct,
    lines: data.total.lines.pct,
  }
}

function collectMutation() {
  const path = join(process.cwd(), 'reports', 'mutation.json')
  if (!existsSync(path)) return { killed: 0, survived: 0, total: 0, score: 0 }
  const data = JSON.parse(readFileSync(path, 'utf-8'))
  let killed = 0, survived = 0
  for (const file of Object.values(data.files) as any[]) {
    killed += file.killed; survived += file.survived
  }
  const total = killed + survived
  return { killed, survived, total, score: total > 0 ? Math.round((killed / total) * 100) : 0 }
}

function collectBenchmarks(): MetricsEntry['benchmarks'] {
  const path = join(process.cwd(), 'bench-results', 'results.json')
  if (!existsSync(path)) return {}
  const data = JSON.parse(readFileSync(path, 'utf-8'))
  const result: MetricsEntry['benchmarks'] = {}
  for (const suite of data.testResults || []) {
    for (const b of suite.benchmarkResults || []) {
      result[b.name] = { hz: Math.round(b.hz), mean: Number(b.mean.toFixed(6)), p99: Number(b.p99.toFixed(6)) }
    }
  }
  return result
}

function main() {
  const dir = join(process.cwd(), 'metrics')
  if (!existsSync(dir)) mkdirSync(dir, { recursive: true })
  const historyPath = join(dir, 'history.json')
  const history: MetricsEntry[] = existsSync(historyPath) ? JSON.parse(readFileSync(historyPath, 'utf-8')) : []

  const mutation = collectMutation()
  const entry: MetricsEntry = {
    timestamp: new Date().toISOString(),
    commit: process.env.GITHUB_SHA?.slice(0, 7) || 'local',
    branch: process.env.GITHUB_REF_NAME || 'local',
    coverage: collectCoverage(),
    mutationScore: mutation.score,
    mutationDetails: { killed: mutation.killed, survived: mutation.survived, total: mutation.total },
    benchmarks: collectBenchmarks(),
  }
  history.push(entry)
  writeFileSync(historyPath, JSON.stringify(history.slice(-90), null, 2))
  console.log(`📊 覆盖率: ${entry.coverage.statements}% | 变异: ${entry.mutationScore}% | 基准: ${Object.keys(entry.benchmarks).length} 项`)
}
main()
```

## 生成 HTML 看板

// scripts/generate-dashboard.ts
import { readFileSync, writeFileSync, existsSync, mkdirSync } from 'fs'
import { join } from 'path'

interface MetricsEntry {
  timestamp: string; commit: string; branch: string
  coverage: { statements: number; branches: number; functions: number; lines: number }
  mutationScore: number; mutationDetails: { killed: number; survived: number; total: number }
  benchmarks: Record<string, { hz: number; mean: number; p99: number }>

function main() {
  const p = join(process.cwd(), 'metrics', 'history.json')
  if (!existsSync(p)) { console.error('❌ 未找到 metrics/history.json'); process.exit(1) }
  const history: MetricsEntry[] = JSON.parse(readFileSync(p, 'utf-8'))
  const dir = join(process.cwd(), 'dashboard')
  if (!existsSync(dir)) mkdirSync(dir, { recursive: true })
  writeFileSync(join(dir, 'index.html'), generateHTML(history))
  console.log('✅ 看板已生成: dashboard/index.html')
}

## CI 集成

```yaml
# .github/workflows/quality.yml
name: Quality Dashboard
on:
  push: { branches: [main] }
  pull_request: { branches: [main] }

jobs:
  quality:
    runs-on: ubuntu-latest
    permissions: { contents: write, pages: write }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci

      - name: Run tests with coverage
        run: npx vitest run --coverage

      - name: Run mutation tests
        run: npx stryker run --incremental
        continue-on-error: true

      - name: Run benchmarks
        run: npx vitest bench --reporter=json --outputFile=./bench-results/results.json
        continue-on-error: true

      - name: Collect metrics
        run: npx tsx scripts/collect-metrics.ts

      - name: Generate dashboard
        run: npx tsx scripts/generate-dashboard.ts

      - name: Deploy to GitHub Pages
        if: github.ref == 'refs/heads/main'
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dashboard
```

## 常见误区

**误区一：看板就是质量保证**——看板是观测工具，数据下降时需要人分析原因。

**误区二：追求所有指标都绿色**——设置合理范围比追求完美更重要。

**误区三：只看最新数据**——趋势比绝对值更有意义。

## 工程建议

1. **数据只保留最近 90 条**：避免膨胀
2. **CI 中变异测试和基准测试允许失败**：用 `continue-on-error: true`
3. **PR 中展示度量变化**：比静态看板更直观
4. **定期 Review 看板**：每周花 5 分钟看趋势

## 小结

- 质量度量看板整合覆盖率、变异测试、基准测试三类数据
- 数据收集脚本读取各工具 JSON 输出，追加到历史记录
- HTML 看板用 Chart.js 展示趋势，GitHub Pages 自动部署
- 关注趋势而非绝对值

```typescript
function collectTestStats() {
  const path = join(process.cwd(), 'test-results.json')
  if (!existsSync(path)) return { total: 0, passed: 0, failed: 0 }
  const data = JSON.parse(readFileSync(path, 'utf-8'))
  const tests: Array<{ status: string }> = []
  function extract(suite: any) {
    for (const t of suite.tests || []) tests.push({ status: t.result?.status || 'unknown' })
    for (const c of suite.suites || []) extract(c)
  }
  for (const s of data.testResults || []) extract(s)
  return {
    total: tests.length,
    passed: tests.filter(t => t.status === 'passed').length,
    failed: tests.filter(t => t.status === 'failed').length,
  }
}
```
