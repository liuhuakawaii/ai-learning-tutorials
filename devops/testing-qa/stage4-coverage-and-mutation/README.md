# 阶段4：覆盖率与变异测试

> 6 课时 | 度量测试质量，发现盲区

## 阶段目标

- 理解代码覆盖率的含义和局限
- 掌握变异测试的原理和工具
- 实践模糊测试和属性测试
- 建立性能基准测试
- 搭建质量度量看板

## 课时列表

| 课时 | 标题 | 核心技能 |
|------|------|----------|
| 01 | 代码覆盖率 | 语句/分支/函数/行覆盖率 |
| 02 | 覆盖率陷阱 | 高覆盖率不等于高质量 |
| 03 | 变异测试 | Stryker 原理、变异算子 |
| 04 | 模糊测试 | 属性测试、随机输入测试 |
| 05 | 性能基准测试 | Vitest benchmark、回归检测 |
| 06 | 阶段实战 | 搭建质量度量系统 |

## 学完本阶段你能做到

- 用覆盖率报告指导测试补充
- 用变异测试发现测试盲区
- 建立性能回归检测机制
