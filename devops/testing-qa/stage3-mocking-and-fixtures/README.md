# 阶段3：Mock 与 Fixture

> 6 课时 | 隔离依赖，构建可控测试环境

## 阶段目标

- 理解 Mock 的原则和边界
- 掌握 MSW 网络 Mock
- 构建测试数据工厂
- 正确使用 Snapshot 测试
- 掌握时间/随机数的 Mock 技巧
- 搭建完整的测试基础设施
