# 测试与质量保障

> 30 课时 | 5 个阶段 | 从单元测试到完整 CI 测试体系

## 课程简介

本课程面向有前端基础、希望系统掌握测试与质量保障的开发者。课程从测试思维出发，覆盖单元测试、集成测试、E2E 测试、Mock 策略、覆盖率分析、变异测试、CI 测试流水线等核心主题，最终帮助你在真实项目中建立完整的质量保障体系。

## 学习路线

```
阶段1：单元测试（6课时）
  ↓ 掌握测试基础，建立测试习惯
阶段2：集成与E2E（6课时）
  ↓ 从组件到浏览器的全链路测试
阶段3：Mock与Fixture（6课时）
  ↓ 隔离依赖，构建可控测试环境
阶段4：覆盖率与变异测试（6课时）
  ↓ 度量测试质量，发现盲区
阶段5：CI测试策略（6课时）
  → 将测试融入工程化流程
```

## 学习建议

1. **动手优先**：每课的练习必须亲自完成，不要只看不做
2. **循序渐进**：按顺序学习，每个阶段的技能为下一阶段打基础
3. **项目驱动**：将学到的测试方法应用到自己的项目中
4. **代码先行**：所有示例代码都是完整可运行的，建议先跑通再理解

## 前置要求

- 熟悉 JavaScript/TypeScript
- 了解 Node.js 基础
- 有 React 基础（阶段2-3需要）
- 了解 Git 和命令行基础操作
