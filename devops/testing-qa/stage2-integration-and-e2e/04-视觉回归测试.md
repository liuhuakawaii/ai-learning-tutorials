# 视觉回归测试

## 场景引入

你改了按钮颜色，代码审查通过，E2E 测试绿了。上线后产品经理："导航栏 logo 怎么被挤到下一行了？" 你改的按钮样式导致容器宽度变化，间接影响了 logo 布局。

功能测试验证"能不能用"，视觉回归测试验证"看起来对不对"——通过截图对比，在像素级别发现意外 UI 变化。

## 学习目标

- 理解视觉回归测试的价值和原理
- 使用 Playwright 截图对比
- 掌握 Chromatic 和 Percy 集成
- 学会设置容差和处理动态内容

---

## 工作流程

1. **基线拍摄**：首次运行截图作为基准
2. **对比拍摄**：后续运行同一位置再截图
3. **像素差异计算**：逐像素对比生成差异图
4. **判定**：差异超阈值则失败，人工审查

能捕获：意外样式变更、布局错位、字体加载失败、响应式断点问题。

---

## 截图对比原理

```
差异值 = |R1-R2| + |G1-G2| + |B1-B2|
```

差异值超过阈值的像素被标记为"不同"。不同像素比例超过容差百分比则测试失败。工具会生成红色高亮的差异图（diff image）。

## Playwright 截图

```typescript
import { test, expect } from '@playwright/test'

test('首页视觉对比', async ({ page }) => {
  await page.goto('/')
  await expect(page).toHaveScreenshot('homepage.png')
})

test('导航栏截图', async ({ page }) => {
  await page.goto('/')
  const navbar = page.getByRole('navigation')
  await expect(navbar).toHaveScreenshot('navbar.png')
})
```

`toHaveScreenshot` 首次运行生成基线，后续自动对比。

### 截图配置

```typescript
// playwright.config.ts
export default defineConfig({
  expect: {
    toHaveScreenshot: {
      maxDiffPixelRatio: 0.01,
      threshold: 0.2,
      animations: 'disabled'
    }
  }
})
```

更新基线：`npx playwright test --update-screenshots`

## Chromatic 集成 Storybook

Chromatic 是 Storybook 官方视觉测试平台，专为组件级视觉回归设计。

```bash
npm install --save-dev chromatic
```

```json
{ "scripts": { "chromatic": "npx chromatic --project-token=<token>" } }
```

### Story 示例

```typescript
// src/components/Button.stories.tsx
import type { Meta, StoryObj } from '@storybook/react'
import { Button } from './Button'

const meta: Meta<typeof Button> = {
  title: 'Components/Button',
  component: Button
}
export default meta
type Story = StoryObj<typeof meta>

export const Primary: Story = { args: { children: '主要按钮', variant: 'primary' } }
export const Secondary: Story = { args: { children: '次要按钮', variant: 'secondary' } }
export const DangerSmall: Story = { args: { children: '删除', variant: 'danger', size: 'sm' } }
export const Loading: Story = { args: { children: '提交中...', loading: true } }
```

运行：`npx chromatic --project-token=<token> --ci`

Chromatic 在云端对比截图，团队在 Web 界面审查并批准/拒绝变更。

## Percy 集成

Percy 是 BrowserStack 旗下的通用视觉测试平台。

```bash
npm install --save-dev @percy/cli @percy/playwright
```

```typescript
// e2e/visual.spec.ts
import { test } from '@playwright/test'
import percySnapshot from '@percy/playwright'

test('首页快照', async ({ page }) => {
  await page.goto('/')
  await percySnapshot(page, 'Homepage')
})

test('响应式快照', async ({ page }) => {
  await page.goto('/')
  await page.setViewportSize({ width: 1280, height: 720 })
  await percySnapshot(page, 'Homepage - Desktop')

  await page.setViewportSize({ width: 375, height: 812 })
  await percySnapshot(page, 'Homepage - Mobile')
})
```

运行：`PERCY_TOKEN=<token> npx percy exec -- npx playwright test`

## 设置容差阈值

完全精确的像素对比不可行——字体渲染、抗锯齿、亚像素差异都会导致误报。

```typescript
// playwright 全局配置
expect: {
  toHaveScreenshot: {
    maxDiffPixels: 100,
    maxDiffPixelRatio: 0.01,
    threshold: 0.3
  }
}

// 单个断言覆盖
await expect(page).toHaveScreenshot('page.png', {
  maxDiffPixelRatio: 0.05,
  threshold: 0.5
})
```

Chromatic 容差：
```typescript
// Story 级别
export const Primary: Story = {
  parameters: { chromatic: { diffThreshold: 0.1 } }
}
```

## 处理动态内容

### 日期和时间

```typescript
test('固定日期截图', async ({ page }) => {
  await page.addInitScript(() => {
    const fixed = new Date('2025-01-15T10:00:00Z')
    Date.now = () => fixed.getTime()
    Date.prototype.getTime = () => fixed.getTime()
  })
  await page.goto('/dashboard')
  await expect(page).toHaveScreenshot('dashboard.png')
})
```

### 动画和过渡

```typescript
test('禁用动画截图', async ({ page }) => {
  await page.goto('/')
  await page.addStyleTag({
    content: `*, *::before, *::after {
      animation-duration: 0s !important;
      transition-duration: 0s !important;
    }`
  })
  await expect(page).toHaveScreenshot('no-animations.png')
})
```

### 隐藏动态元素

```typescript
await expect(page).toHaveScreenshot('dashboard.png', {
  mask: [
    page.getByTestId('current-time'),
    page.getByTestId('user-avatar')
  ]
})
```

被遮盖区域显示为纯色方块，不影响其他区域对比。

## 常见误区

1. **所有页面都做视觉测试**：维护基线成本高。优先关键页面和共享组件。
2. **基线不更新**：UI 变更是预期的但忘记更新基线，团队习惯性忽略失败。
3. **CI 中用开发构建**：source map、调试工具改变页面外观。用 production build。
4. **忽略跨平台差异**：macOS/Windows 字体渲染不同。CI 用固定 Docker 环境。
5. **不等待资源加载**：截图时图片字体未加载完成。用 `waitForLoadState('networkidle')`。

---

## 工程建议

- 视觉测试放独立 CI job，不影响功能测试速度
- 共享组件库做完整视觉测试，页面只覆盖关键路径
- 定期清理不需要的基线截图
- 视觉测试失败必须人工审查，不要自动合并

---

## 小结

- 视觉回归测试通过截图对比发现意外 UI 变化
- Playwright 内置 `toHaveScreenshot` 支持页面和元素级截图
- Chromatic 适合 Storybook 组件库，Percy 是通用平台
- 合理容差 + 处理动态内容是视觉测试关键

## 参考答案

### 练习一

```typescript
import { test, expect } from '@playwright/test'

test.describe('登录页视觉', () => {
  test('全页面截图', async ({ page }) => {
    await page.goto('/login')
    await page.waitForLoadState('networkidle')
    await expect(page).toHaveScreenshot('login-full.png', {
      fullPage: true, maxDiffPixelRatio: 0.01
    })
  })

  test('表单区域截图', async ({ page }) => {
    await page.goto('/login')
    await expect(page.getByRole('form')).toHaveScreenshot('login-form.png', {
      threshold: 0.2
    })
  })
})
```

### 练习二

```typescript
import { test, expect } from '@playwright/test'

test('含日期页面截图', async ({ page }) => {
  await page.addInitScript(() => {
    const fixed = new Date('2025-06-15T12:00:00Z')
    const Orig = Date
    class Mock extends Orig {
      constructor(...a: any[]) { a.length === 0 ? super(fixed.getTime()) : super(...a) }
    }
    ;(window as any).Date = Mock
  })
  await page.goto('/dashboard')
  await page.waitForLoadState('networkidle')
  await expect(page).toHaveScreenshot('dashboard.png', {
    mask: [page.getByTestId('current-time')],
    maxDiffPixelRatio: 0.02
  })
})
```
