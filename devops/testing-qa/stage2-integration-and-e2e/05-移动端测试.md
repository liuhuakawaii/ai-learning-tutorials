# 移动端测试

## 场景引入

你的 React Native 应用在模拟器上完美运行，用户反馈："安卓手机上偶尔崩溃，双指缩放没反应。" Jest 单元测试覆盖不到这些——没有真实触摸事件、手势系统和设备特性。

移动端测试的额外挑战：触摸交互、手势识别、屏幕适配、设备特性模拟。

## 学习目标

- 理解移动端测试与 Web 测试的差异
- 使用 React Native Testing Library 测试组件
- 使用 Detox 进行 E2E 测试
- 掌握手势交互和设备特性模拟

---

## 测试策略分层

| 层级 | 工具 | 覆盖范围 |
|------|------|---------|
| 单元测试 | Jest + RNTL | 组件逻辑、纯函数 |
| 集成测试 | RNTL | 组件交互、导航 |
| E2E 测试 | Detox | 完整用户流程 |

```typescript
// src/components/TodoItem.tsx
export function TodoItem({ title, completed, onToggle, onDelete }: {
  title: string; completed: boolean; onToggle: () => void; onDelete: () => void
}) {
  return (
    <View style={{ flexDirection: 'row', padding: 12, alignItems: 'center' }}>
      <TouchableOpacity testID="toggle-button" onPress={onToggle}>
        <Text>{completed ? '✅' : '⬜'}</Text>
      </TouchableOpacity>
      <Text style={{ flex: 1, fontSize: 16, textDecorationLine: completed ? 'line-through' : 'none' }}>{title}</Text>
      <TouchableOpacity testID="delete-button" onPress={onDelete}>
        <Text>删除</Text>
      </TouchableOpacity>
    </View>
  )
}

// __tests__/TodoItem.test.tsx
import { render, fireEvent, screen } from '@testing-library/react-native'

describe('TodoItem', () => {
  const props = { title: '学习 RN', completed: false, onToggle: jest.fn(), onDelete: jest.fn() }
  beforeEach(() => jest.clearAllMocks())

  it('显示标题', () => { render(<TodoItem {...props} />); expect(screen.getByText('学习 RN')).toBeTruthy() })
  it('未完成显示空方块', () => { render(<TodoItem {...props} />); expect(screen.getByText('⬜')).toBeTruthy() })
  it('已完成显示勾选', () => { render(<TodoItem {...props} completed />); expect(screen.getByText('✅')).toBeTruthy() })
  it('点击切换', () => { render(<TodoItem {...props} />); fireEvent.press(screen.getByTestId('toggle-button')); expect(props.onToggle).toHaveBeenCalled() })
  it('点击删除', () => { render(<TodoItem {...props} />); fireEvent.press(screen.getByTestId('delete-button')); expect(props.onDelete).toHaveBeenCalled() })
})
```

### 表单测试

```typescript
// src/components/AddTodo.tsx
export function AddTodo({ onAdd }: { onAdd: (title: string) => void }) {
  const [text, setText] = useState('')
  const handleSubmit = () => { if (text.trim()) { onAdd(text.trim()); setText('') } }
  return (
    <View style={{ flexDirection: 'row', padding: 16 }}>
      <TextInput testID="todo-input" placeholder="添加新任务" value={text} onChangeText={setText} />
      <Button title="添加" onPress={handleSubmit} />
    </View>
  )
}

// __tests__/AddTodo.test.tsx
describe('AddTodo', () => {
  it('输入后点击添加', () => {
    const onAdd = jest.fn(); render(<AddTodo onAdd={onAdd} />)
    fireEvent.changeText(screen.getByTestId('todo-input'), '买菜')
    fireEvent.press(screen.getByText('添加'))
    expect(onAdd).toHaveBeenCalledWith('买菜')
  })
  it('空文本不触发', () => {
    const onAdd = jest.fn(); render(<AddTodo onAdd={onAdd} />)
    fireEvent.press(screen.getByText('添加'))
    expect(onAdd).not.toHaveBeenCalled()
  })
})
```

```typescript
// e2e/todoFlow.test.ts
import { by, device, element, expect } from 'detox'

describe('Todo 应用', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }) })
  beforeEach(async () => { await device.reloadReactNative() })

  it('添加任务', async () => {
    await element(by.id('todo-input')).typeText('学习 Detox')
    await element(by.text('添加')).tap()
    await expect(element(by.text('学习 Detox'))).toBeVisible()
  })

  it('切换完成状态', async () => {
    await element(by.id('todo-input')).typeText('买菜')
    await element(by.text('添加')).tap()
    await element(by.id('toggle-button').withAncestor(by.text('买菜'))).tap()
    await expect(element(by.text('✅'))).toBeVisible()
  })

  it('删除任务', async () => {
    await element(by.id('todo-input')).typeText('待删除')
    await element(by.text('添加')).tap()
    await element(by.id('delete-button').withAncestor(by.text('待删除'))).tap()
    await expect(element(by.text('待删除'))).not.toBeVisible()
  })
})
```

## 常见误区

1. **过度依赖 testID**：优先 `getByText`、`getByRole`（RNTL 支持 accessibilityRole）。
2. **E2E 覆盖所有场景**：E2E 运行慢，核心路径用 E2E，边界用单元测试。
3. **不测深色模式**：移动端普遍支持，两种模式都需验证。
4. **忽略无障碍**：用 `getByRole` 和 `getByLabelText` 确保 VoiceOver/TalkBack 正确。
5. **只测 iOS**：两个平台 UI 差异大，CI 同时覆盖。

---

## 工程建议

- RNTL 用于日常快速反馈，Detox 用于 CI 关键流程
- Detox 需编译原生应用，CI 缓存 build 产物
- `--take-screenshots failing` 失败时自动截图
- 手势测试在真机和模拟器可能不同，CI 用模拟器保持一致
- 单元测试每次提交，E2E 测试每天一次

---

## 小结

- 移动端测试需处理触摸、手势和设备特性
- RNTL 遵循 Testing Library 哲学，测试用户可见行为
- Detox 在真实设备/模拟器上运行 E2E
- 设备特性（网络、GPS）需专门模拟策略

```typescript
function TaskList({ tasks, onTaskPress }: { tasks: { id: string; title: string }[]; onTaskPress: (id: string) => void }) {
  if (!tasks.length) return <View><Text>暂无任务</Text></View>
  return (
    <FlatList data={tasks} keyExtractor={i => i.id}
      renderItem={({ item }) => (
        <TouchableOpacity onPress={() => onTaskPress(item.id)}><Text>{item.title}</Text></TouchableOpacity>
      )} />
  )
}

describe('TaskList', () => {
  const tasks = [{ id: '1', title: '买菜' }, { id: '2', title: '写代码' }]
  it('显示列表', () => { render(<TaskList tasks={tasks} onTaskPress={jest.fn()} />); expect(screen.getByText('买菜')).toBeTruthy() })
  it('空列表', () => { render(<TaskList tasks={[]} onTaskPress={jest.fn()} />); expect(screen.getByText('暂无任务')).toBeTruthy() })
  it('点击回调', () => { const fn = jest.fn(); render(<TaskList tasks={tasks} onTaskPress={fn} />); fireEvent.press(screen.getByText('买菜')); expect(fn).toHaveBeenCalledWith('1') })
})
```
