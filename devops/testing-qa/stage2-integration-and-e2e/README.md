# 阶段2：集成与 E2E

> 6 课时 | 从组件到浏览器的全链路测试

## 阶段目标

- 掌握 API 集成测试的方法
- 熟练使用 Testing Library 测试 React 组件
- 用 Playwright 编写 E2E 测试
- 理解视觉回归测试和移动端测试
- 能为完整应用搭建 E2E 测试套件

## 课时列表

| 课时 | 标题 | 核心技能 |
|------|------|----------|
| 01 | API 集成测试 | Supertest、数据库测试、事务回滚 |
| 02 | React 组件测试 | Testing Library、用户交互测试 |
| 03 | Playwright 入门 | 浏览器自动化、页面对象模型 |
| 04 | 视觉回归测试 | 截图对比、Chromatic 集成 |
| 05 | 移动端测试 | React Native Testing Library、Detox |
| 06 | 阶段实战 | 为完整应用写 E2E 测试 |

## 学完本阶段你能做到

- 测试 API 接口的请求-响应-数据库全链路
- 以用户视角测试 React 组件
- 用 Playwright 模拟真实用户操作
