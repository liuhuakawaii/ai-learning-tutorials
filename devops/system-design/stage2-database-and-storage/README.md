# 阶段 2：数据库与存储

> 6 课时 | 根据业务特征选择合适的存储方案，掌握数据密集型系统的设计方法

## 阶段概述

没有万能的数据库，只有适合特定场景的存储方案。本阶段系统性地对比 SQL 与 NoSQL 数据库的适用场景，深入分库分表的策略与代价，讲解消息队列在异步架构中的核心作用，以及对象存储与 CDN 在海量数据场景下的应用。最后通过一个数据密集型系统实战项目，将存储选型能力落地。

这个阶段的核心目标是建立**存储选型的判断力**——面对一个具体的业务场景，你能说清楚为什么选 A 不选 B，以及选 A 的代价是什么。

## 学习目标

完成本阶段后，你将能够：

1. 根据数据特征（结构化/半结构化/非结构化）选择合适的数据库
2. 理解 MySQL 和 PostgreSQL 的核心差异，做出合理选型
3. 掌握 Redis、MongoDB、Cassandra 等 NoSQL 的适用场景
4. 设计分库分表方案，理解分片带来的复杂性和迁移策略
5. 使用消息队列解耦异步流程，保证消息可靠性
6. 设计对象存储与 CDN 方案，处理海量静态资源

## 前置要求

- 完成阶段 1 的学习，或具备等效的系统设计基础知识
- 了解 SQL 数据库的基本操作和索引原理
- 了解缓存和负载均衡的基本概念
