## 二、阶段概述

本阶段是整个课程的核心难点，聚焦于分布式系统的关键问题——一致性、可用性和容错性。通过学习分布式锁、分布式事务、消息队列和限流降级等核心技术，设计电商平台在分布式环境下的可靠运行方案。

**核心学习目标**：
- 理解 CAP 定理和 BASE 理论在实际系统中的应用
- 掌握分布式锁的多种实现方案及其适用场景
- 理解分布式事务的核心问题与解决方案（2PC / TCC / Saga / 本地消息表）
- 设计可靠的消息队列方案，处理消息丢失、重复和顺序问题
- 掌握限流、降级、熔断的核心原理与实现
