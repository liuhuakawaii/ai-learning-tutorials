# 系统设计与架构

> 30 课时 | 面向有后端基础的开发者，从设计思维到真实案例，系统掌握大规模系统设计能力

## 课程简介

本课程不是"背八股文"式的系统设计速成，而是一门围绕**真实工程问题**展开的系统设计实战课。每节课从一个具体的业务场景出发，拆解设计决策背后的权衡逻辑，让你真正理解"为什么这样设计"而非"答案是什么"。

课程覆盖从单体应用到分布式微服务架构的完整演进路径，包含 5 个递进阶段、30 个课时，最终通过 6 个真实系统案例和一个毕业项目，将所学知识融会贯通。

## 学习目标

完成本课程后，你将能够：

1. **需求分析与建模**：将模糊的业务需求转化为清晰的技术方案，完成 API 设计和数据建模
2. **存储选型决策**：根据业务特征选择合适的数据库和存储方案，理解分库分表的适用场景
3. **分布式系统设计**：掌握 CAP 理论、一致性模型、分布式事务等核心概念，设计高可用系统
4. **微服务架构实践**：理解服务拆分策略、通信模式、可观测性，构建完整的微服务系统
5. **真实案例分析**：具备分析和设计 Twitter 信息流、即时通讯、搜索引擎等真实系统的能力
6. **面试表达能力**：能够清晰地在白板上阐述设计思路，进行有深度的技术讨论

## 前置要求

- 熟悉至少一门后端语言（Java/Go/Python/Node.js）
- 了解基本的数据库操作（SQL、索引、事务）
- 有 RESTful API 开发经验
- 了解基本的网络协议（HTTP、TCP）
- 有 Linux 基本操作能力

## 毕业项目

### 项目：设计一个在线协作文档系统（类 Google Docs）

综合运用全课程所学，完成一个在线协作文档系统的设计方案，包含：

- **需求分析**：功能需求拆解、非功能需求量化、容量估算
- **系统架构**：整体架构图、核心组件设计、数据流向
- **详细设计**：数据模型、API 设计、实时协作算法（OT/CRDT）、版本控制
- **可靠性设计**：容灾方案、数据备份、故障恢复
- **扩展性设计**：分片策略、缓存方案、CDN 加速
- **可观测性**：监控指标、告警规则、链路追踪方案
- **成本估算**：资源需求、成本优化建议

毕业项目验证脚本位于 `final-project/scripts/` 目录。

## 课程约定

### 内容风格

- 每节课从**真实业务场景**出发，不以 API 清单或概念罗列驱动
- 代码示例完整可运行，使用业务语义命名（禁用 foo/bar/data）
- 涉及 tradeoff 必须讲清利弊和适用场景
- 禁止"显而易见""很简单"等跳步表达

### 文件规范

- 语言：中文
- 格式：Markdown，每课时独立文件，命名 `01-标题.md`
- 每个 stage 目录下有 `README.md` 作为阶段概述
- 每节课包含：场景引入、核心概念、代码示例、练习与答案解析

### 练习规范

每节课的练习必须包含参考答案，答案需包含：
- 解题思路（关键判断过程）
- 完整参考代码或详细文字解答
- 要点总结与常见错误分析
