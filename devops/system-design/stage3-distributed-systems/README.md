# 阶段 3：分布式系统

> 6 课时 | 掌握分布式系统的核心挑战与解决方案，设计高可用、高可靠的分布式架构

## 阶段概述

分布式系统的核心挑战是"在不可靠的组件上构建可靠的系统"。本阶段从 CAP 理论和一致性模型出发，逐步深入分布式事务、分布式锁、限流熔断、幂等设计等关键问题。每个话题都从"为什么需要"开始，到"有哪些方案"，再到"怎么选择"。最后通过一个分布式任务调度实战项目，将理论知识转化为工程实践。

这个阶段的核心目标是建立**分布式思维**——理解分布式环境下的各种"不可能"和"有代价"，学会在一致性、可用性和性能之间做出合理的权衡。

## 学习目标

完成本阶段后，你将能够：

1. 理解 CAP 定理的真正含义，区分强一致性和最终一致性的适用场景
2. 掌握 2PC/TCC/Saga 等分布式事务模式的原理和取舍
3. 设计分布式锁方案，理解不同实现的优缺点
4. 实现限流与熔断机制，保护系统在高负载下的稳定性
5. 设计幂等方案，确保分布式环境下请求的安全重试
6. 构建分布式任务调度系统，理解任务分配与容错机制

## 前置要求

- 完成阶段 1 和阶段 2 的学习，或具备等效知识
- 理解网络通信的基本概念（延迟、超时、丢包）
- 了解基本的并发编程概念（锁、线程安全）
