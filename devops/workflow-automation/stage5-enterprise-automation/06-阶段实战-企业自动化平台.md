# 阶段实战：企业自动化平台

## 目标

将 n8n 作为企业级自动化平台：工作流模板库、监控面板、权限体系、审计日志、高可用部署、运维文档。让非技术团队也能自助使用自动化。

## 平台架构

```
用户层：
├── 开发者（创建复杂工作流）
├── 运营（使用模板创建工作流）
└── 管理员（管理配置和权限）

平台层：
├── n8n 编辑器（工作流设计）
├── 模板库（预置工作流模板）
├── 监控面板（执行状态、性能指标）
└── 管理后台（用户、权限、配置）

基础设施层：
├── n8n 集群（Editor + Workers）
├── PostgreSQL（数据存储）
├── Redis（队列和缓存）
└── Nginx（负载均衡和 SSL）
```

## 工作流模板库

```
分类        模板                说明
──────────────────────────────────────────
通知        邮件通知、Slack      基础通知模板
数据        数据同步、报表生成    数据处理模板
客服        AI 客服、工单系统    客户服务模板
营销        邮件营销、社交媒体    营销自动化模板
运维        监控告警、备份清理    运维自动化模板
```

每个模板包含：工作流 JSON（可导入）、使用说明（README）、配置参数（变量说明）、依赖服务（需要的凭证）、示例数据（测试用）。

## 监控面板

关键指标：

```
指标          来源        展示
──────────────────────────────────
执行总数      n8n API     折线图
成功率        n8n API     仪表盘
平均执行时间  n8n API     折线图
队列长度      Redis       数字
Worker 状态   n8n API     状态列表
错误分布      n8n API     饼图
```

告警规则：

```
执行失败率 > 5%（最近 10 分钟）→ Slack
队列长度 > 100（持续 5 分钟）→ Slack + 邮件
Worker 离线（立即）→ 电话
```

## Docker Compose 生产配置

```yaml
version: '3.8'

services:
  n8n:
    image: n8nio/n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - EXECUTIONS_MODE=queue
      - QUEUE_BULL_REDIS_HOST=redis
      - DB_TYPE=postgresdb
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_DATABASE=n8n
      - N8N_ENCRYPTION_KEY=${ENCRYPTION_KEY}
    volumes:
      - n8n_data:/home/node/.n8n
    depends_on:
      - redis
      - postgres
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5678/healthz"]
      interval: 30s
      timeout: 10s
      retries: 3

  n8n-worker:
    image: n8nio/n8n
    command: worker
    restart: always
    environment:
      - EXECUTIONS_MODE=queue
      - QUEUE_BULL_REDIS_HOST=redis
      - DB_TYPE=postgresdb
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_DATABASE=n8n
    deploy:
      replicas: 3

  redis:
    image: redis:7-alpine
    restart: always
    volumes:
      - redis_data:/data

  postgres:
    image: postgres:15
    restart: always
    environment:
      - POSTGRES_DB=n8n
      - POSTGRES_USER=n8n
      - POSTGRES_PASSWORD=${DB_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data

  nginx:
    image: nginx:alpine
    restart: always
    ports:
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./certs:/etc/nginx/certs
    depends_on:
      - n8n

volumes:
  n8n_data:
  redis_data:
  postgres_data:
```

## 运维文档

### 日常巡检清单

```markdown
## 每日
- [ ] 检查 n8n 服务状态
- [ ] 检查 Worker 运行状态
- [ ] 检查队列长度
- [ ] 查看失败执行
- [ ] 检查磁盘空间

## 每周
- [ ] 审查审计日志
- [ ] 检查备份状态
- [ ] 性能指标分析
- [ ] 安全漏洞扫描
```

### 故障处理手册

```
故障              症状          处理步骤
──────────────────────────────────────────────
n8n 无法访问      502 错误      检查容器→检查日志→重启服务
执行排队          延迟增加      检查 Worker→检查 Redis→扩展 Worker
数据库连接失败    执行报错      检查 PostgreSQL→检查连接数→重启数据库
内存溢出          容器重启      检查工作流→优化内存→增加资源
```
