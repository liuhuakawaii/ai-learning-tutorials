# 阶段实战：全渠道营销自动化

## 场景

电商公司需要全渠道营销系统：从 Google Sheets 读取营销计划 → AI 生成内容 → 多平台发布（邮件、社交媒体、短信）→ 跟踪效果 → 更新 CRM。营销团队只需维护计划表。

## 系统架构

```
数据源：Google Sheets（营销计划）+ CRM（客户数据）

处理层：
├── 内容生成（AI）
├── 渠道分发（邮件/社交媒体/短信）
└── 效果跟踪（UTM/事件追踪）

输出层：
├── 邮件（SendGrid）
├── 社交媒体（Twitter API）
├── 短信（Twilio）
└── CRM（HubSpot）
```

## 营销计划管理

Google Sheets 结构：

```
campaign_id | campaign_name | target_audience | channels | schedule_time | content_brief | status
```

```
Schedule（每天检查）→ Google Sheets（读取今日计划）→ IF（有新计划？）→ 执行营销流程
```

```javascript
const plan = $input.first().json

const content = {

    image: plan.image_url
  },
  sms: {
    body: `【${plan.brand}】${plan.content_brief.substring(0, 50)}... 退订回T`
  }
}

return Object.entries(content).map(([channel, data]) => ({
  json: {
    campaign_id: plan.campaign_id,
    channel,
    ...data,
    utm_url: generateUtmUrl(plan.landing_url, channel, plan.campaign_id)
  }
}))
```

UTM 追踪链接：

```javascript
function generateUtmUrl(baseUrl, channel, campaignId) {
  const params = new URLSearchParams({
    utm_source: channel,
    utm_medium: 'automation',
    utm_campaign: campaignId
  })
  return `${baseUrl}?${params.toString()}`
}
```

## 渠道分发

### 邮件（SendGrid）

```json
{
  "method": "POST",
  "url": "https://api.sendgrid.com/v3/mail/send",
  "headers": {
    "Authorization": "Bearer {{ $credentials.sendgridApiKey }}",
    "Content-Type": "application/json"
  },
  "body": {
    "personalizations": [{ "to": [{ "email": "={{ $json.recipient }}" }], "subject": "={{ $json.subject }}" }],
    "from": { "email": "marketing@example.com" },
    "content": [{ "type": "text/html", "value": "={{ $json.html_body }}" }]
  }
}
```

## 效果跟踪

```javascript
const events = $input.all()
const stats = {
  campaign_id: events[0].json.campaign_id,
  total_sent: events.filter(e => e.json.event_type === 'sent').length,
  total_opened: events.filter(e => e.json.event_type === 'opened').length,
  total_clicked: events.filter(e => e.json.event_type === 'clicked').length,
  total_converted: events.filter(e => e.json.event_type === 'converted').length
}
stats.open_rate = stats.total_opened / stats.total_sent
stats.click_rate = stats.total_clicked / stats.total_opened
stats.conversion_rate = stats.total_converted / stats.total_clicked
return [{ json: stats }]
```

## 完整工作流

```
Schedule（每天 9:00）
    ↓
Google Sheets（读取今日计划）
    ↓
Loop（逐个活动）
    ↓
Code（生成多渠道内容）
    ↓
Loop（逐个渠道）
    ├─ Email → SendGrid
    ├─ Social → Twitter
    └─ SMS → Twilio
    ↓
数据库（记录发送事件）
    ↓
更新 Google Sheets 状态
```

效果收集流程：

```
Schedule（每天 18:00）→ 数据库（收集今日事件）→ Code（统计）→ Sheets（更新效果）
    ↓
IF（效果异常？）→ 是 → 告警通知
```
