## 一、系统架构

### 1.1 整体设计

```
数据源：
├── Google Sheets（营销计划）
├── CRM（客户数据）
└── Analytics（效果数据）

处理层：
├── 内容生成（AI）
├── 渠道分发（邮件/社交媒体/短信）
└── 效果跟踪（UTM/事件追踪）

输出层：
├── 邮件（SendGrid/SES）
├── 社交媒体（Twitter/Facebook）
├── 短信（Twilio）
└── CRM（HubSpot/Salesforce）
```

### 1.2 数据流

```
Google Sheets（营销计划）
    ↓
Loop（逐条执行）
    ↓
AI 生成内容（多版本）
    ↓
渠道分发
    ├─ 邮件 → SendGrid
    ├─ 社交媒体 → Twitter API
    └─ 短信 → Twilio
    ↓
UTM 追踪链接生成
    ↓
效果数据收集
    ↓
CRM 更新
```

## 三、内容生成

### 3.1 多渠道内容适配

```javascript
// Code 节点：为不同渠道生成内容
const plan = $input.first().json;

const content = {
  email: {
    subject: `${plan.campaign_name} - 限时优惠！`,
    body: generateEmailBody(plan),
    template: 'marketing'
  },
  social: {
    text: `${plan.content_brief} 🔥\n\n限时优惠，立即抢购！\n\n#促销 #优惠`,
    image: plan.image_url
  },
  sms: {
    body: `【${plan.brand}】${plan.content_brief.substring(0, 50)}... 退订回T`
  }
};

return Object.entries(content).map(([channel, data]) => ({
  json: {
    campaign_id: plan.campaign_id,
    channel,
    ...data,
    utm_url: generateUtmUrl(plan.landing_url, channel, plan.campaign_id)
  }
}));
```

### 3.2 UTM 追踪链接

```javascript
function generateUtmUrl(baseUrl, channel, campaignId) {
  const params = new URLSearchParams({
    utm_source: channel,
    utm_medium: 'automation',
    utm_campaign: campaignId
  });
  return `${baseUrl}?${params.toString()}`;
}
```

### 5.2 效果统计

```javascript
// Code 节点：计算营销效果
const events = $input.all();

const stats = {
  campaign_id: events[0].json.campaign_id,
  total_sent: events.filter(e => e.json.event_type === 'sent').length,
  total_opened: events.filter(e => e.json.event_type === 'opened').length,
  total_clicked: events.filter(e => e.json.event_type === 'clicked').length,
  total_converted: events.filter(e => e.json.event_type === 'converted').length
};

stats.open_rate = stats.total_opened / stats.total_sent;
stats.click_rate = stats.total_clicked / stats.total_opened;
stats.conversion_rate = stats.total_converted / stats.total_clicked;

return [{ json: stats }];
```

## 常见误区

### 误区一："所有渠道用同一份内容"

不同渠道有不同的格式和长度限制。邮件可以详细，社交媒体要简洁，短信要精炼。

### 误区二："发送了就结束了"

发送只是开始。需要跟踪打开、点击、转化等效果指标。

### 误区三："不需要用户同意"

营销消息需要用户明确同意（opt-in）。短信和邮件有严格的合规要求。

---

## 工程建议

1. **内容适配**：每个渠道的内容要根据平台特点调整。
2. **频率控制**：不要过度营销，避免用户反感。
3. **效果跟踪**：UTM 参数和事件追踪是必备的。
4. **合规要求**：遵守 GDPR、CAN-SPAM 等法规。
5. **A/B 测试**：测试不同内容和发送时间的效果。

## 小结

- 全渠道营销系统整合邮件、社交媒体和短信等多个渠道
- 内容生成需要适配不同渠道的格式要求
- UTM 参数和事件追踪实现效果监控
- CRM 更新实现营销-销售闭环
- 合规和频率控制是营销自动化的底线
