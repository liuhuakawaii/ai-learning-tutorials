```json
{

  "port": 5432,
  "database": "myapp",
  "user": "n8n_user",
  "password": "secure_password",
  "ssl": true

```

### 1.2 查询操作

```json
{
  "resource": "database",
  "operation": "executeQuery",
  "query": "SELECT * FROM orders WHERE status = $1 AND created_at > $2",
  "options": {
    "parameters": ["pending", "2024-01-01"]
  }
}
```

### 1.3 插入操作

```json
{
  "resource": "database",
  "operation": "insert",
  "table": "orders",
  "columns": "order_id, customer_id, amount, status",
  "values": "={{ $json.order_id }}, {{ $json.customer_id }}, {{ $json.amount }}, 'pending'"
}
```

### 1.4 批量插入

```javascript
// Code 节点：构建批量插入 SQL
const items = $input.all();

const values = items.map((item, i) => 
  `($${i*4+1}, $${i*4+2}, $${i*4+3}, $${i*4+4})`
).join(', ');

const params = items.flatMap(item => [
  item.json.order_id,
  item.json.customer_id,
  item.json.amount,
  'pending'
]);

const query = `INSERT INTO orders (order_id, customer_id, amount, status) 
VALUES ${values} 
ON CONFLICT (order_id) DO NOTHING`;

return [{ json: { query, params } }];
```

### 3.4 聚合查询

```json
{
  "resource": "document",
  "operation": "aggregate",
  "collection": "events",
  "query": [
    {
      "$match": {
        "event_type": "purchase",
        "timestamp": { "$gte": "={{ $now.minus({ days: 30 }).toISO() }}" }
      }
    },
    {
      "$group": {
        "_id": "$user_id",
        "total_spent": { "$sum": "$amount" },
        "order_count": { "$sum": 1 }
      }
    },
    {
      "$sort": { "total_spent": -1 }
    },
    {
      "$limit": 10
    }
  ]
}
```

## 四、跨数据库同步

### 4.1 PostgreSQL → MongoDB

```
PostgreSQL（读取订单）
    ↓
Code（转换格式）
    ↓
MongoDB（写入分析集合）
```

格式转换：

```javascript
const orders = $input.all();

return orders.map(order => ({
  json: {
    _id: order.json.order_id,
    customer: {
      id: order.json.customer_id,
      name: order.json.customer_name
    },
    items: order.json.items,
    total: order.json.amount,
    status: order.json.status,
    created_at: new Date(order.json.created_at),
    synced_at: new Date()
  }
}));
```

### 4.2 增量同步

```javascript
// 获取上次同步时间
const staticData = $getWorkflowStaticData('global');
const lastSync = staticData.last_sync || '2024-01-01';

// 查询新增数据
const query = `SELECT * FROM orders WHERE updated_at > $1`;
const params = [lastSync];

// 更新同步时间
staticData.last_sync = new Date().toISOString();

return [{ json: { query, params } }];
```

## 五、性能优化

### 5.1 查询优化

| 策略 | 说明 |
|------|------|
| 索引 | 为常用查询字段创建索引 |
| 分页 | 使用 LIMIT 和 OFFSET |
| 批量操作 | 合并多条 INSERT/UPDATE |
| 连接池 | 使用连接池减少连接开销 |

### 5.2 批量操作

```javascript
// 批量插入（每批 100 条）
const items = $input.all();
const batchSize = 100;
const batches = [];

for (let i = 0; i < items.length; i += batchSize) {
  batches.push(items.slice(i, i + batchSize));
}

return batches.map(batch => ({
  json: {
    values: batch.map(item => item.json),
    count: batch.length
  }
}));
```

### 5.3 错误处理

```javascript
try {
  const result = await db.query(query, params);
  return [{ json: { success: true, data: result } }];
} catch (error) {
  if (error.code === '23505') { // 唯一约束冲突
    return [{ json: { success: false, error: 'duplicate', message: error.message } }];
  }
  throw error; // 其他错误继续抛出
}
```

## 常见误区

### 误区一："SQL 注入不是问题"

n8n 的参数化查询可以防止 SQL 注入。不要用字符串拼接构建 SQL。

### 误区二："数据库连接不需要关闭"

n8n 会自动管理连接。但在 Code 节点中手动创建的连接需要关闭。

### 误区三："MongoDB 不需要索引"

MongoDB 同样需要索引优化查询性能。

---

## 工程建议

1. **使用参数化查询**：防止 SQL 注入。
2. **批量操作**：减少数据库往返次数。
3. **错误重试**：数据库操作可能因为连接问题失败。
4. **监控慢查询**：记录查询执行时间。
5. **读写分离**：查询操作用只读副本。

- n8n 内置了 PostgreSQL、MySQL 和 MongoDB 节点
- 支持 CRUD 操作、原生 SQL 查询和聚合查询
- 跨数据库同步需要数据格式转换
- 性能优化包括索引、批量操作和连接池
- 参数化查询防止 SQL 注入
