你的系统每天生成大量报表文件（PDF、CSV），需要存储到云存储中，并按日期归档。同时，用户上传的文件需要同步到备份存储。你需要用 n8n 实现文件的自动上传、下载、归档和清理。

## 一、AWS S3

### 1.1 配置凭证

```json
{
  "name": "AWS S3",
  "region": "ap-southeast-1",
  "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
  "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY"
}
```

### 1.2 上传文件

```json
{
  "resource": "bucket",
  "operation": "upload",
  "bucketName": "my-reports",
  "fileName": "reports/{{ $now.toFormat('yyyy/MM/dd') }}/report-{{ $json.id }}.pdf",
  "binaryPropertyName": "data",
  "options": {
    "contentType": "application/pdf",
    "ACL": "private"
  }
}
```

### 1.3 下载文件

```json
{
  "resource": "bucket",
  "operation": "download",
  "bucketName": "my-reports",
  "fileName": "={{ $json.file_path }}"
}
```

### 1.4 列出文件

```json
{
  "resource": "bucket",
  "operation": "list",
  "bucketName": "my-reports",
  "prefix": "reports/2024/03/",
  "options": {
    "maxKeys": 100
  }
}
```

### 1.5 生成预签名 URL

```json
{
  "resource": "bucket",
  "operation": "getSignedUrl",
  "bucketName": "my-reports",
  "fileName": "={{ $json.file_path }}",
  "options": {
    "expiresIn": 3600
  }
}
```

## 三、阿里云 OSS

### 3.1 配置

使用 HTTP Request 节点调用 OSS API：

```javascript
// Code 节点：生成 OSS 签名
const crypto = require('crypto');

const accessKeyId = 'your-access-key';
const accessKeySecret = 'your-secret';
const bucket = 'my-bucket';
const region = 'oss-cn-hangzhou';

const date = new Date().toUTCString();
const canonicalResource = `/${bucket}/${fileName}`;
const stringToSign = `PUT\n\napplication/octet-stream\n${date}\n${canonicalResource}`;

const signature = crypto
  .createHmac('sha1', accessKeySecret)
  .update(stringToSign)
  .digest('base64');

return [{
  json: {
    url: `https://${bucket}.${region}.aliyuncs.com/${fileName}`,
    authorization: `OSS ${accessKeyId}:${signature}`,
    date: date
  }
}];
```

### 3.2 上传文件

```json
{
  "method": "PUT",
  "url": "={{ $json.url }}",
  "headers": {
    "Authorization": "={{ $json.authorization }}",
    "Date": "={{ $json.date }}",
    "Content-Type": "application/octet-stream"
  },
  "body": "={{ $binary.data }}"
}
```

## 四、文件归档工作流

### 4.1 按日期归档

```
Schedule（每天凌晨）
    ↓
S3（列出昨日文件）
    ↓
Loop（逐个处理）
    ↓
S3（复制到归档目录）
    ↓
S3（删除原文件）
    ↓
Slack（发送归档报告）
```

### 4.2 归档策略

```javascript
// Code 节点：计算归档路径
const file = $input.first().json;
const date = DateTime.fromISO(file.lastModified);

const archivePath = `archive/${date.toFormat('yyyy/MM/dd')}/${file.name}`;

return [{
  json: {
    ...file,
    archive_path: archivePath,
    should_archive: date < $now.minus({ days: 30 })
  }
}];
```

### 4.3 清理过期文件

```javascript
// Code 节点：计算过期文件
const files = $input.all();
const retentionDays = 90;
const cutoff = $now.minus({ days: retentionDays });

const expired = files.filter(f => {
  const date = DateTime.fromISO(f.json.lastModified);
  return date < cutoff;
});

return expired.map(f => ({
  json: {
    file_path: f.json.Key,
    last_modified: f.json.lastModified,
    size: f.json.Size,
    action: 'delete'
  }
}));
```


## 常见误区

### 误区一："文件上传不需要检查大小"

大多数云存储有单文件大小限制（S3 5GB，OSS 5GB）。需要检查文件大小，大文件用分片上传。

### 误区二："预签名 URL 是永久的"

预签名 URL 有过期时间。过期后无法访问，需要重新生成。

### 误区三："Google Drive 不需要配额管理"

Google Drive API 有配额限制（每分钟 12,000 次请求）。批量操作要注意频率。

---

## 工程建议

1. **使用分片上传**：大文件（> 100MB）使用分片上传。
2. **设置生命周期**：配置自动清理过期文件。
3. **监控存储用量**：定期检查存储空间使用情况。
4. **备份策略**：重要文件至少存储在两个位置。
5. **权限控制**：文件访问权限要最小化。
