# 第四课：内容生成流水线

> **课程定位**：用 AI 批量生成内容，实现从创作到发布的自动化
> **前置知识**：了解 AI 节点和 Prompt 设计
> **预计时长**：35 分钟

---

## 场景引入

你的市场团队需要每周产出 20 篇社交媒体帖子、5 篇博客文章和 1 份新闻通讯。人工写耗时太长，直接用 AI 生成质量参差不齐。你需要一条内容生成流水线：AI 生成初稿 → 质量检查 → 人工审核 → 自动发布。

---

## 学习目标

完成本课学习后，你将能够：

1. 设计批量内容生成工作流
2. 实现 AI 生成内容的质量检查
3. 构建人工审核流程
4. 实现多平台自动发布

## 一、内容生成架构

### 1.1 流水线设计

```
输入：内容计划（主题、类型、平台）
    ↓
AI 生成初稿
    ↓
AI 质量检查
    ├─ 通过 → 人工审核
    └─ 不通过 → 重新生成（最多 3 次）
    ↓
人工审核
    ├─ 通过 → 格式化 → 发布
    └─ 驳回 → 修改 → 重新审核
    ↓
多平台发布
```

### 1.2 内容类型

| 类型 | 长度 | 风格 | 平台 |
|------|------|------|------|
| 社交媒体帖子 | < 280 字 | 轻松、吸引眼球 | Twitter/微博 |
| 博客文章 | 1000-3000 字 | 专业、深入 | 官网/Medium |
| 新闻通讯 | 500-1000 字 | 简洁、信息密集 | 邮件 |
| 产品描述 | 100-300 字 | 突出卖点 | 电商平台 |

## 二、AI 生成

### 2.1 生成 Prompt 模板

```javascript
const prompt = `你是一个专业的内容创作者。请根据以下要求生成内容：

主题：${topic}
类型：${content_type}
平台：${platform}
目标受众：${audience}
关键词：${keywords}
字数要求：${word_count}
风格：${tone}

要求：
1. 标题吸引眼球
2. 内容有深度和价值
3. 包含行动号召（CTA）
4. 自然融入关键词
5. 符合平台特点

请以 JSON 格式返回：
{
  "title": "标题",
  "content": "正文",
  "tags": ["标签1", "标签2"],
  "cta": "行动号召"
}`;
```

### 2.2 批量生成

```
Google Sheets（内容计划）
    ↓
Loop（逐条处理）
    ↓
Code（构建 Prompt）
    ↓
OpenAI（生成内容）
    ↓
Code（解析结果）
    ↓
Google Sheets（写回生成结果）
```

### 2.3 多变体生成

为同一主题生成多个版本：

```javascript
const variants = [];
for (let i = 0; i < 3; i++) {
  const response = await callOpenAI({
    prompt: originalPrompt,
    temperature: 0.7 + (i * 0.2), // 不同的创造性
  });
  variants.push(response);
}

return variants.map((v, i) => ({
  json: { variant: i + 1, content: v }
}));
```

## 三、质量检查

### 3.1 AI 质量评估

```javascript
const prompt = `评估以下内容的质量，返回 JSON 格式：

内容：
${content}

评估维度（1-10 分）：
1. 相关性：与主题的相关程度
2. 原创性：是否有独特见解
3. 可读性：是否易于理解
4. 吸引力：是否能吸引读者
5. 准确性：信息是否准确

返回格式：
{
  "scores": {
    "relevance": 8,
    "originality": 7,
    "readability": 9,
    "appeal": 8,
    "accuracy": 9
  },
  "overall": 8.2,
  "pass": true,
  "issues": ["问题1", "问题2"],
  "suggestions": ["建议1", "建议2"]
}`;
```

### 3.2 质量阈值

```javascript
const quality = $input.first().json;
const threshold = 7.0;

const pass = quality.overall >= threshold && 
             quality.scores.accuracy >= 8 &&
             quality.issues.length === 0;

return [{
  json: {
    ...quality,
    pass,
    action: pass ? 'approve' : 'regenerate'
  }
}];
```

### 3.3 重试机制

```
生成 → 质量检查
    ├─ 通过 → 继续
    └─ 不通过 → 重新生成（最多 3 次）
              ├─ 第 1 次：调整 Prompt
              ├─ 第 2 次：降低 temperature
              └─ 第 3 次：标记需要人工处理
```

## 四、人工审核

### 4.1 审核流程

```
生成内容写入 Google Sheets
    ↓
Slack 通知审核人
    ↓
审核人在 Sheets 中标记状态
    ↓
Schedule 轮询状态
    ├─ approved → 发布
    ├─ rejected → 通知作者修改
    └─ pending → 继续等待
```

### 4.2 审核表设计

| 列名 | 说明 |
|------|------|
| content_id | 内容 ID |
| title | 标题 |
| content | 正文 |
| status | pending/approved/rejected |
| reviewer | 审核人 |
| comments | 审核意见 |
| publish_time | 计划发布时间 |

## 五、多平台发布

### 5.1 平台适配

```javascript
// Code 节点：内容格式化
const content = $input.first().json;

const formatted = {
  twitter: content.content.substring(0, 270) + '... ' + content.cta,
  blog: {
    title: content.title,
    body: content.content,
    tags: content.tags
  },
  newsletter: {
    subject: content.title,
    html: markdownToHtml(content.content),
    preview: content.content.substring(0, 100)
  }
};

return [{ json: formatted }];
```

### 5.2 定时发布

```
Schedule（每小时检查）
    ↓
Google Sheets（查询待发布内容）
    ↓
IF（发布时间到了？）
    ├─ 是 → 发布到对应平台
    └─ 否 → 跳过
```

### 5.3 发布节点

| 平台 | 节点 | 操作 |
|------|------|------|
| Twitter | HTTP Request | POST /2/tweets |
| WordPress | HTTP Request | POST /wp-json/wp/v2/posts |
| 邮件 | Send Email | SMTP 发送 |
| Slack | Slack | chat.postMessage |

## 常见误区

### 误区一："AI 生成的内容不需要审核"

AI 可能产生不准确、不恰当或有版权风险的内容。人工审核是必要的质量保障。

### 误区二："一次生成就够了"

高质量内容通常需要多次迭代。重试机制和人工修改流程是必要的。

### 误区三："所有平台用同一份内容"

不同平台有不同的格式和风格要求。需要适配后再发布。

---

## 工程建议

1. **Prompt 要精细**：不同内容类型需要不同的 Prompt 模板。
2. **质量检查要自动化**：用 AI 评估初筛，人工只审核通过初筛的内容。
3. **发布要定时**：根据平台特点选择最佳发布时间。
4. **记录生成过程**：方便追溯和优化。
5. **监控效果**：跟踪内容的阅读量、互动量，反馈优化 Prompt。

---

## 小结

- 内容生成流水线：生成 → 质量检查 → 人工审核 → 发布
- AI 生成需要精细的 Prompt 和质量评估机制
- 人工审核是质量保障的最后防线
- 多平台发布需要内容适配
- 重试机制和定时发布是流水线的关键特性
