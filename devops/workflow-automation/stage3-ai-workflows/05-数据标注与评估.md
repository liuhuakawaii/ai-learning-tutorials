# 第五课：数据标注与评估

> **课程定位**：用 AI 辅助数据标注和自动评估，提升数据质量和模型效果
> **前置知识**：了解 AI 节点和批处理
> **预计时长**：35 分钟

---

## 场景引入

你的机器学习团队需要标注 10000 条客服对话的情感和意图。人工标注每条需要 2 分钟，总共需要 333 小时。你想用 AI 先自动标注，人工只审核 AI 不确定的样本，把时间缩短到 100 小时以内。

## 一、AI 自动标注

### 1.1 标注 Prompt 设计

```javascript
const prompt = `分析以下客服对话，标注情感和意图。

对话：
${conversation}

标注要求：
1. 情感：positive/neutral/negative
2. 意图：inquiry/complaint/request/feedback/other
3. 置信度：0-1（你对标注的确定程度）
4. 关键词：提取 3-5 个关键词

返回 JSON：
{
  "sentiment": "positive|neutral|negative",
  "intent": "inquiry|complaint|request|feedback|other",
  "confidence": 0.85,
  "keywords": ["关键词1", "关键词2"],
  "reasoning": "标注理由"
}`;
```

### 1.2 批量标注

```
数据库（读取未标注数据）
    ↓
Split In Batches（每批 10 条）
    ↓
Loop（逐条标注）
    ↓
OpenAI（标注）
    ↓
Code（解析结果）
    ↓
数据库（写入标注结果）
```

### 1.3 置信度过滤

```javascript
const annotation = $input.first().json;

// 高置信度：自动接受
// 低置信度：转人工审核
const needsReview = annotation.confidence < 0.7;

return [{
  json: {
    ...annotation,
    auto_labeled: !needsReview,
    needs_review: needsReview,
    review_status: needsReview ? 'pending' : 'auto_approved'
  }
}];
```

## 二、人机协作标注

### 2.1 流程设计

```
AI 自动标注
    ↓
IF（置信度 >= 0.7）
    ├─ 是 → 自动接受
    └─ 否 → 写入待审核表
    ↓
人工审核
    ├─ 确认 AI 标注
    └─ 修正标注
    ↓
更新数据库
```

### 2.2 审核界面

用 Google Sheets 作为简易审核界面：

| ID | 文本 | AI 情感 | AI 意图 | 置信度 | 人工情感 | 人工意图 | 状态 |
|----|------|---------|---------|--------|---------|---------|------|
| 1 | 你们产品太差了 | negative | complaint | 0.95 | | | auto_approved |
| 2 | 还行吧 | neutral | feedback | 0.45 | | | pending |

### 2.3 人工修正流程

```
Schedule（每天检查待审核）
    ↓

    ↓
IF（有人工标注？）
    ├─ 是 → 更新数据库
    └─ 否 → 通知审核人
```

## 三、自动评估

### 3.1 评估 AI 标注质量

用已标注的测试集评估 AI 标注的准确性：

```javascript
const items = $input.all();

let correct = 0;
let total = items.length;

for (const item of items) {
  if (item.json.ai_label === item.json.human_label) {
    correct++;
  }
}

const accuracy = correct / total;

return [{
  json: {
    total,
    correct,
    accuracy: Math.round(accuracy * 100) + '%',
    pass: accuracy >= 0.8
  }
}];
```

### 3.2 分类评估

```javascript
// 计算每个类别的精确率、召回率、F1
const items = $input.all();
const labels = ['positive', 'neutral', 'negative'];
const metrics = {};

for (const label of labels) {
  const tp = items.filter(i => i.json.ai_label === label && i.json.human_label === label).length;
  const fp = items.filter(i => i.json.ai_label === label && i.json.human_label !== label).length;
  const fn = items.filter(i => i.json.ai_label !== label && i.json.human_label === label).length;
  
  const precision = tp / (tp + fp) || 0;
  const recall = tp / (tp + fn) || 0;
  const f1 = 2 * precision * recall / (precision + recall) || 0;
  
  metrics[label] = {
    precision: Math.round(precision * 100) + '%',
    recall: Math.round(recall * 100) + '%',
    f1: Math.round(f1 * 100) + '%'
  };
}

return [{ json: metrics }];
```

### 3.3 持续评估

```
Schedule（每周）
    ↓
数据库（抽取样本）
    ↓
人工标注（基准答案）
    ↓
AI 标注（同一批样本）
    ↓
Code（计算指标）
    ↓
IF（准确率下降？）
    ├─ 是 → 告警 + 分析原因
    └─ 否 → 记录指标
```

## 四、标注质量监控

### 4.1 关键指标

| 指标 | 说明 | 目标 |
|------|------|------|
| 准确率 | AI 标注与人工标注一致的比例 | >= 80% |
| 覆盖率 | AI 能自动标注的比例 | >= 60% |
| 一致性 | 相同样本多次标注的结果一致 | >= 90% |
| 人工审核率 | 需要人工审核的比例 | <= 40% |

### 4.2 异常检测

```javascript
// 检测标注分布异常
const items = $input.all();
const distribution = {};

for (const item of items) {
  const label = item.json.ai_label;
  distribution[label] = (distribution[label] || 0) + 1;
}

const total = items.length;
const maxRatio = Math.max(...Object.values(distribution)) / total;

// 如果某个类别占比超过 80%，可能有偏差
const hasBias = maxRatio > 0.8;

return [{
  json: {
    distribution,
    total,
    hasBias,
    warning: hasBias ? '标注分布异常，可能存在偏差' : null
  }
}];
```

## 五、实战：客服对话标注系统

### 5.1 完整流程

```
数据导入
    ↓
AI 批量标注
    ↓
置信度过滤
    ├─ 高置信度 → 自动接受
    └─ 低置信度 → 待审核
    ↓
人工审核（Google Sheets）
    ↓
数据导出（训练数据）
    ↓
定期评估（准确率、覆盖率）
```

### 5.2 工作流结构

```
主工作流：
Schedule（每天）→ 数据库（读取）→ Split In Batches → Loop
    → Code(Prompt) → OpenAI(标注) → Code(解析) → 数据库(写入)

审核工作流：
Schedule（每天）→ Google Sheets(读取审核) → Loop
    → 数据库(更新标注)

评估工作流：
Schedule（每周）→ 数据库(抽取样本) → Code(计算指标)
    → Slack(发送报告)
```

## 常见误区

### 误区一："AI 标注不需要人工审核"

AI 标注有系统性偏差。必须保留人工审核环节，特别是低置信度的样本。

### 误区二："置信度高就一定正确"

AI 的置信度不等于准确率。高置信度的样本也可能有错。需要定期抽样验证。

### 误区三："标注一次就够了"

数据分布会变化，AI 模型也会更新。需要持续监控标注质量。

---

## 工程建议

1. **保留人工标注样本**：作为评估基准，定期更新。
2. **分层标注**：先 AI 标注，再人工审核不确定的。
3. **监控分布**：检测标注偏差，及时调整。
4. **版本管理**：标注方案变更时保留历史版本。
5. **反馈循环**：人工修正的结果用于优化 Prompt。

---

## 小结

- AI 自动标注可以大幅提升效率，但需要质量保障
- 置信度过滤把 AI 不确定的样本转人工审核
- 自动评估系统持续监控标注质量
- 标注分布异常检测可以发现系统性偏差
- 人机协作是最高效的标注方案
