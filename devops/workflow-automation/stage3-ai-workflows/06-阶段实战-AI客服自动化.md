# 阶段实战：AI 客服自动化

## 场景

SaaS 产品 5000 付费用户，每天 200+ 客服消息。3 个客服忙不过来。用 AI 处理 70% 常见问题，复杂问题转人工。系统需要：理解意图、检索知识库、生成回答、执行操作、人工审核敏感操作。

## 系统架构

```
用户消息入口：Webhook / Slack / 邮件

处理层：
├── 意图识别（AI 分类）
├── 知识库检索（RAG）
├── 工具调用（Agent）
└── 回答生成（AI）

转接层：
├── 自动回复（AI 处理）
├── 人工转接（复杂问题）
└── 升级处理（投诉/紧急）

监控层：响应时间、解决率、满意度、AI 准确率
```

## 意图识别

```javascript
const prompt = `分析客服消息，判断意图类别。

消息：${message}

类别：
- faq: 常见问题
- order: 订单相关
- billing: 账单相关
- technical: 技术问题
- complaint: 投诉
- greeting: 问候
- other: 其他

返回 JSON：
{
  "intent": "类别",
  "confidence": 0.9,
  "urgency": "low|medium|high",
  "needs_human": false,
  "summary": "一句话概括"
}`
```

路由逻辑：

```javascript
const routes = {
  faq: 'rag_answer',
  order: 'agent_tool',
  billing: 'agent_tool',
  technical: 'rag_answer',
  complaint: 'human_transfer',
  greeting: 'auto_reply',
  other: 'human_transfer',
}

const route = routes[classification.intent] || 'human_transfer'
if (classification.urgency === 'high') route = 'human_transfer'
```

## RAG 知识库

```
用户问题
    ↓
OpenAI Embedding（向量化）
    ↓
Pinecone（语义检索 Top 3）
    ↓
相关度过滤（score > 0.7）
    ├─ 有相关结果 → 组装 Prompt → OpenAI 生成回答
    └─ 无相关结果 → 转人工
```

RAG Prompt：

```javascript
const prompt = `你是客服助手。基于以下知识库内容回答用户问题。

规则：
1. 只使用知识库中的信息回答
2. 如果知识库中没有相关信息，说"我需要转接人工客服为您处理"
3. 回答要简洁友好

知识库：
${context}

用户问题：${question}

回答：`
```

## Agent 工具调用

```
工具          功能          参数
──────────────────────────────────
get_order     查询订单      order_id
update_address 修改地址      order_id, new_address
check_subscription 查询订阅  user_id
create_ticket  创建工单      title, description, priority
```

敏感操作确认：

```
Agent 判断需要退款
    ↓
生成确认消息："确认要为订单 ORD-001 申请退款 ¥299 吗？"
    ↓
等待用户回复
    ├─ 确认 → 执行退款
    └─ 取消 → 取消操作
```

## 人工转接

转接条件：

```
AI 置信度低（< 0.6）
用户要求转人工
投诉/紧急
敏感操作（退款、删除等不可逆操作）
多轮未解决（3 轮对话未解决）
```

转接流程：

```
触发转接 → AI 生成转接摘要 → Slack 通知客服 → 客服接管
```

转接摘要：

```javascript
const prompt = `总结以下客服对话，生成转接摘要。

对话历史：
${history}

返回 JSON：
{
  "summary": "问题摘要",
  "customer_sentiment": "情绪",
  "attempted_solutions": ["已尝试的方案"],
  "urgency": "优先级"
}`
```

## 质量评估

自动评估：

```javascript
const prompt = `评估客服回答的质量。

用户问题：${question}
AI 回答：${answer}
知识库内容：${context}

评估维度（1-10）：
1. 准确性  2. 完整性  3. 友好度  4. 有用性

返回 JSON：{"accuracy": 9, "completeness": 8, "overall": 8.5, "issues": []}`
```

监控指标：

```
AI 解决率 >= 70%    AI 直接解决 / 总对话
平均响应时间 < 30s  从收到消息到发送回答
用户满意度 >= 80%   满意 / 总调查
转人工率 <= 30%     转人工 / 总对话
```

## 完整工作流

```
Webhook（用户消息）→ Code（预处理）→ OpenAI（意图识别）→ Code（路由）
    ↓
Switch
    ├─ rag_answer → RAG 检索 → AI 回答
    ├─ agent_tool → Agent 执行 → 返回结果
    ├─ auto_reply → 固定回复
    └─ human_transfer → 转人工
    ↓
Code（质量检查）→ IF（质量通过？）
    ├─ 是 → 发送回答
    └─ 否 → 转人工
    ↓
数据库（记录对话）
```

## 练习

### 练习一：意图识别

接收客服消息，AI 识别意图，根据意图路由到不同分支。

### 练习二：RAG 客服

实现 RAG：用户问题 → 向量检索知识库 → AI 基于检索结果生成回答。

### 练习三：完整系统

构建完整 AI 客服：意图识别 → RAG/Agent → 质量检查 → 回复/转人工。
