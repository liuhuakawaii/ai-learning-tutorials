# 第三阶段：AI 工作流

## 阶段目标

将 AI 能力嵌入自动化工作流：集成 LLM 调用、构建 RAG 检索流程、实现 Agent 工具调用、搭建内容生成流水线和数据标注系统。

## 课时安排

1. AI 节点集成（OpenAI/Claude 节点、Prompt 模板）
2. RAG 工作流（文档处理 → 向量化 → 检索 → 回答）
3. Agent 工作流（工具调用、多步推理、人工确认）
4. 内容生成流水线（批量生成、质量检查、发布）
5. 数据标注与评估（AI 辅助标注、自动评估）
6. 阶段实战：AI 客服自动化

## 阶段项目

构建一个 AI 客服自动化系统：接收用户消息 → RAG 检索知识库 → AI 生成回答 → 人工审核 → 多渠道回复 → 自动评估质量。

## 验收标准

- 工作流调用 OpenAI/Claude API 并处理响应
- 实现 RAG 流程（文档嵌入 + 语义检索 + 生成回答）
- Agent 节点能根据上下文选择不同工具
- 包含人工确认环节（Human-in-the-loop）
- AI 输出经过质量检查后才发送
