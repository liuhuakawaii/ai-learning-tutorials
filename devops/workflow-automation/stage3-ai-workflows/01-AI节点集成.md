# AI 节点集成

## 场景

客服系统每天 200 条咨询，人工回复忙不过来。用 AI 自动回复常见问题，复杂问题转人工。需要把 LLM 集成到工作流中，让它根据问题类型自动判断。

## OpenAI 节点

配置凭证：Credentials → Add Credential → OpenAI API → 填入 API Key。

```json
{
  "resource": "chat",
  "operation": "complete",
  "model": "gpt-4o-mini",
  "messages": {
    "values": [
      { "role": "system", "content": "你是一个专业的客服助手。" },
      { "role": "user", "content": "={{ $json.question }}" }
    ]
  },
  "options": {
    "temperature": 0.7,
    "maxTokens": 500
  }
}
```

参数选择：

```
model：gpt-4o-mini（性价比高）、gpt-4o（高质量）
temperature：0.3（确定性任务）、0.7（创意任务）
maxTokens：500-2000
```

## Claude 节点

通过 HTTP Request 节点调用：

```json
{
  "method": "POST",
  "url": "https://api.anthropic.com/v1/messages",
  "headers": {
    "Content-Type": "application/json",
    "x-api-key": "={{ $credentials.claudeApiKey }}",
    "anthropic-version": "2023-06-01"
  },
  "body": {
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1000,
    "messages": [{ "role": "user", "content": "={{ $json.prompt }}" }]
  }
}
```

## 输出处理

LLM 输出需要解析：

```javascript
const response = $input.first().json
const content = response.choices[0].message.content

let parsed
try {
  parsed = JSON.parse(content)
} catch {
  parsed = { text: content }
}

return [{
  json: {
    answer: parsed.text || parsed.answer,
    category: parsed.category || 'general',
    confidence: parsed.confidence || 0.5,
    needs_human: parsed.needs_human || false,
  }
}]
```

## Prompt 模板设计

结构化 Prompt：

```javascript
const prompt = `角色：你是一个专业的客服分类助手。
任务：分析客户问题，判断类别和处理方式。

客户问题：${input.question}

输出要求：
请以 JSON 格式返回：
{
  "category": "billing|technical|general|complaint",
  "urgency": "low|medium|high",
  "needs_human": true/false,
  "suggested_reply": "建议回复内容"
}`

return [{ json: { prompt, original: input } }]
```

Few-shot 示例让 AI 更准确：

```javascript
const prompt = `分析客户情绪，判断是否需要人工介入。

示例：
问题："你们的产品太垃圾了，我要退款！"
结果：{"sentiment": "negative", "urgency": "high", "needs_human": true}

问题："请问怎么修改密码？"
结果：{"sentiment": "neutral", "urgency": "low", "needs_human": false}

现在请分析：
问题："${input.question}"
结果：`
```

## 强制 JSON 输出

```json
{
  "response_format": { "type": "json_object" },
  "messages": [
    {
      "role": "system",
      "content": "你必须以 JSON 格式回复，不要包含任何其他文本。"
    },
    {
      "role": "user",
      "content": "分析这段文本的情感：{{ $json.text }}"
    }
  ]
}
```

## AI 客服分流

```
Webhook（客户消息）
    ↓
Code（构建分类 Prompt）
    ↓
OpenAI（分类分析）
    ↓
Code（解析结果）
    ↓
Switch（按类别路由）
    ├─ billing   → 查询账单 API → 自动回复
    ├─ technical → 搜索知识库 → 自动回复
    ├─ complaint → 转人工 + 通知主管
    └─ general   → AI 生成回复 → 自动发送
```

## 成本控制

```
策略                说明
──────────────────────────────────
用小模型            gpt-4o-mini 处理简单任务
限制 max_tokens     不要让 AI 输出过长
缓存结果            相同问题缓存 AI 回复
批量处理            合并多个请求成一个
Prompt 精简         减少不必要的上下文
```

## 练习

### 练习一：基础 AI 调用

创建工作流：接收用户问题，调用 OpenAI 生成回答，返回结果。

### 练习二：结构化输出

要求 AI 以 JSON 格式返回：answer、category、confidence。

### 练习三：AI 分流

接收客服消息，AI 分析后路由：自动回复、转人工、升级处理。

---

## 参考答案

### 练习一

Webhook（POST /ask）→ OpenAI Chat（model: gpt-4o-mini）→ Set（提取回答）

### 练习二

OpenAI 节点配置 `response_format: { type: "json_object" }`，System Prompt 指定 JSON 结构。

### 练习三

Webhook → Code(Prompt) → OpenAI → Code(解析) → Switch
  ├─ auto_reply → AI 生成回复 → 发送
  ├─ human → 通知人工
  └─ escalate → 通知主管
