## 一、Split In Batches

### 1.1 基本用法

Split In Batches 把大数据集拆分成小批次循环处理：

```
输入：100 条数据
    ↓
Split In Batches（Batch Size: 10）
    ↓
循环 10 次，每次处理 10 条
    ↓
输出：所有处理结果
```

配置：

```json
{
  "batchSize": 10,
  "options": {
    "reset": false
  }
}
```

### 1.2 循环控制

Split In Batches 节点有两个输出端口：

```
Split In Batches
    ├─ 输出 1（Loop）：当前批次的数据 → 处理节点 → 回连到 Split
    └─ 输出 2（Done）：所有批次处理完成后
```

重要：处理节点的输出需要**回连**到 Split In Batches 节点，形成循环。

### 1.3 批量 API 调用

```javascript
// 处理节点（Code）：批量插入数据库
const batch = $input.all();

const values = batch.map(item => 
  `('${item.json.id}', '${item.json.name}', ${item.json.amount})`
).join(', ');

const sql = `INSERT INTO orders (id, name, amount) VALUES ${values} ON CONFLICT (id) DO NOTHING`;

return [{ json: { query: sql, batch_size: batch.length } }];
```

## 二、分页数据拉取

### 2.1 自动分页

当数据源有分页时，自动拉取所有页面：

```javascript
// Code 节点：分页拉取
const allData = [];
let page = 1;
let hasMore = true;

while (hasMore) {
  const response = await fetch(`https://api.example.com/orders?page=${page}&limit=100`);
  const data = await response.json();
  
  allData.push(...data.items);
  
  hasMore = data.items.length === 100;
  page++;
  
  // 频率限制
  await new Promise(r => setTimeout(r, 200));
}

return allData.map(item => ({ json: item }));
```

### 2.2 n8n 的分页支持

某些节点内置了分页功能：

```json
// HTTP Request 节点的分页配置
{
  "pagination": {
    "parameters": {
      "type": "query",
      "pageSize": 100
    },
    "paginationComplete": {
      "type": "lastPage"
    }
  }
}
```

### 2.3 增量拉取

只拉取上次同步后的新数据：

```javascript
// 获取上次同步时间
const staticData = $getWorkflowStaticData('global');
const lastSync = staticData.last_sync_time || '2024-01-01T00:00:00Z';

// 拉取新数据
const response = await fetch(
  `https://api.example.com/orders?since=${lastSync}`
);
const data = await response.json();

// 更新同步时间
staticData.last_sync_time = new Date().toISOString();

return data.orders.map(order => ({ json: order }));
```

## 三、数据聚合

### 3.1 Aggregate 节点

Aggregate 节点把多个 Item 聚合成一个：

```json
{
  "aggregate": "aggregateAllItemData",
  "options": {
    "destinationFieldName": "orders"
  }
}
```

输出：

```json
{
  "orders": [
    { "id": 1, "amount": 100 },
    { "id": 2, "amount": 200 }
  ]
}
```

### 3.2 Summarize 节点

Summarize 节点做统计聚合：

```json
{
  "fields": {
    "sum": ["amount"],
    "average": ["amount"],
    "count": true
  },
  "groupby": {
    "field": "category"
  }
}
```

输出：

```json
[
  { "category": "electronics", "sum_amount": 5000, "avg_amount": 500, "count": 10 },
  { "category": "clothing", "sum_amount": 3000, "avg_amount": 300, "count": 10 }
]
```

### 3.3 Code 节点聚合

复杂聚合逻辑用 Code 节点：

```javascript
const items = $input.all();

// 按类别分组统计
const groups = {};
for (const item of items) {
  const cat = item.json.category;
  if (!groups[cat]) {
    groups[cat] = { count: 0, total: 0, items: [] };
  }
  groups[cat].count++;
  groups[cat].total += item.json.amount;
  groups[cat].items.push(item.json);
}

// 转换为输出格式
return Object.entries(groups).map(([category, stats]) => ({
  json: {
    category,
    order_count: stats.count,
    total_amount: stats.total,
    average_amount: Math.round(stats.total / stats.count),
    min_amount: Math.min(...stats.items.map(i => i.amount)),
    max_amount: Math.max(...stats.items.map(i => i.amount))
  }
}));
```

## 四、频率限制

### 4.1 为什么需要频率限制

大多数 API 有调用频率限制（如 100 次/分钟）。超过限制会返回 429 错误。

### 4.2 实现频率控制

```javascript
// Code 节点：带频率限制的批量处理
const items = $input.all();
const results = [];
const RATE_LIMIT = 10; // 每秒 10 次
const INTERVAL = 1000 / RATE_LIMIT;

for (let i = 0; i < items.length; i++) {
  try {
    const response = await fetch('https://api.example.com/data', {
      method: 'POST',
      body: JSON.stringify(items[i].json)
    });
    
    if (response.status === 429) {
      // 触发限流，等待后重试
      await new Promise(r => setTimeout(r, 5000));
      i--; // 重试当前项
      continue;
    }
    
    const result = await response.json();
    results.push({ json: { success: true, ...result } });
  } catch (error) {
    results.push({ json: { success: false, error: error.message } });
  }
  
  // 频率控制
  await new Promise(r => setTimeout(r, INTERVAL));
}

return results;
```

### 4.3 令牌桶算法

更精确的频率控制：

```javascript
class TokenBucket {
  constructor(capacity, refillRate) {
    this.capacity = capacity;
    this.tokens = capacity;
    this.refillRate = refillRate;
    this.lastRefill = Date.now();
  }
  
  async consume() {
    this.refill();
    if (this.tokens < 1) {
      const waitTime = (1 - this.tokens) / this.refillRate * 1000;
      await new Promise(r => setTimeout(r, waitTime));
      this.refill();
    }
    this.tokens--;
  }
  
  refill() {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(this.capacity, this.tokens + elapsed * this.refillRate);
    this.lastRefill = now;
  }
}

// 使用：每秒 10 个请求
const bucket = new TokenBucket(10, 10);
const items = $input.all();
const results = [];

for (const item of items) {
  await bucket.consume();
  // 处理逻辑...
}

return results;
```

## 五、实战：订单批量同步

### 5.1 需求

- 从电商平台 API 拉取新订单（分页）
- 批量写入数据仓库（每批 100 条）
- 频率限制：每秒最多 5 次 API 调用
- 失败重试：单条失败记录到错误表
- 最后汇总统计

### 5.2 实现

```
Schedule Trigger（每小时）
    ↓
Code（分页拉取新订单）
    ↓
Split In Batches（每批 100 条）
    ↓
Code（批量插入数据库）
    ↓
PostgreSQL（执行插入）
    ↓ 回连 Split
    ↓ 完成后
Code（汇总统计）
    ↓
Slack（发送同步报告）
```

## 常见误区

### 误区一："Split In Batches 自动处理错误"

Split In Batches 不会自动跳过失败的批次。需要在处理节点中用 Continue On Fail 或 try/catch 处理错误。

### 误区二："批处理比逐条处理快"

批处理的优势在于减少 API 调用次数。如果每次 API 调用本身很慢，批处理的提升有限。

### 误区三："频率限制只需要 sleep"

简单的 sleep 不能精确控制频率。高并发场景需要使用令牌桶或漏桶算法。

---

## 工程建议

1. **Batch Size 要适中**：太小效率低，太大容易超时。根据 API 和数据量调整。
2. **记录处理进度**：大批量处理时记录已处理数量，方便断点续传。
3. **监控批处理性能**：记录每批处理时间，及时发现性能退化。
4. **设计幂等操作**：批处理可能重试，确保重复执行不会产生副作用。

---

## 小结

- Split In Batches 把大数据集拆分成小批次循环处理
- 分页拉取需要自动检测是否有更多数据
- Aggregate 和 Summarize 节点提供内置的聚合功能
- 频率限制是调用外部 API 的必要保护措施
- 批处理需要考虑错误处理、进度记录和幂等性

## 参考答案

### 练习一

**思路**：Split In Batches 分批 → Code 计算平均值 → 聚合结果。

**答案**：

1. **Set**：生成 100 个数字的数组
2. **Split In Batches**：Batch Size = 10
3. **Code**（循环体）：
   ```javascript
   const items = $input.all();
   const sum = items.reduce((s, i) => s + i.json.value, 0);
   return [{ json: { batch_size: items.length, sum, average: sum / items.length } }];
   ```
4. **聚合 Code**：
   ```javascript
   const batches = $input.all();
   const total = batches.reduce((s, b) => s + b.json.sum, 0);
   const count = batches.reduce((s, b) => s + b.json.batch_size, 0);
   return [{ json: { total_batches: batches.length, total_items: count, overall_average: total / count } }];
   ```

### 练习二

**思路**：用循环自动翻页直到没有更多数据。

**答案**：

```javascript
const allIssues = [];
let page = 1;
let hasMore = true;

while (hasMore) {
  const response = await fetch(
    `https://api.github.com/repos/n8n-io/n8n/issues?state=all&per_page=100&page=${page}`,
    { headers: { 'User-Agent': 'n8n-workflow' } }
  );
  const issues = await response.json();
  
  if (issues.length === 0) break;
  allIssues.push(...issues);
  page++;
  
  if (issues.length < 100) hasMore = false;
  await new Promise(r => setTimeout(r, 1000));
}

const open = allIssues.filter(i => i.state === 'open').length;
const closed = allIssues.filter(i => i.state === 'closed').length;

return [{ json: { total: allIssues.length, open, closed } }];
```

### 练习三

**思路**：用循环 + sleep 实现频率控制。

**答案**：

```javascript
const items = Array.from({ length: 50 }, (_, i) => i + 1);
const results = [];
const RATE = 5; // 每秒 5 次
const DELAY = 1000 / RATE;

for (const id of items) {
  try {
    const start = Date.now();
    const response = await fetch(`https://httpbin.org/get?id=${id}`);
    const elapsed = Date.now() - start;
    
    results.push({
      json: {
        id,
        status: response.status,
        success: response.ok,
        elapsed_ms: elapsed
      }
    });
  } catch (error) {
    results.push({
      json: { id, success: false, error: error.message }
    });
  }
  
  await new Promise(r => setTimeout(r, DELAY));
}

const successCount = results.filter(r => r.json.success).length;
const failCount = results.filter(r => !r.json.success).length;

return [
  ...results,
  { json: { summary: true, total: 50, success: successCount, failed: failCount } }
];
```
