# 条件分支与循环

## 场景

订单处理工作流需要根据金额走不同审批路径：1000 以下自动通过，1000-5000 经理审批，5000 以上总监审批。每个订单可能包含多个商品，需要逐个检查库存。一个简单的线性工作流已经无法满足需求。

## IF 节点进阶

IF 节点支持多条件组合：

```json
{
  "conditions": {
    "combinator": "AND",
    "conditions": [
      {
        "leftValue": "={{ $json.amount }}",
        "rightValue": 1000,
        "operator": { "type": "number", "operation": "gt" }
      },
      {
        "leftValue": "={{ $json.status }}",
        "rightValue": "pending",
        "operator": { "type": "string", "operation": "equals" }
      }
    ]
  }
}
```

AND：所有条件满足。OR：任一条件满足。

## Switch 节点

超过 3 个分支时，用 Switch 比嵌套 IF 更清晰：

```
Switch（按 category 分支）
    ├─ electronics → 电子产品处理
    ├─ clothing   → 服装处理
    ├─ food       → 食品处理
    └─ default    → 默认处理
```

## Loop 节点

Loop 逐个处理数组中的元素：

```
Input: [item1, item2, item3]
    ↓
Loop（逐个处理）
    ├─ 处理 item1 → result1
    ├─ 处理 item2 → result2
    └─ 处理 item3 → result3
    ↓
Output: [result1, result2, result3]
```

循环中的错误处理——单条失败不应该影响整个批次：

```javascript
const item = $input.first().json
try {
  const result = await processItem(item)
  return [{ json: { success: true, ...result } }]
} catch (error) {
  return [{ json: { success: false, error: error.message, ...item } }]
}
```

## Split 与 Merge

**Split In Batches**：把大数据集拆成小批次处理。超过 100 条数据时使用。

**Merge 节点**三种模式：

```
Append：简单拼接 → [a1, a2, b1, b2]
Keep Key Matches：按键匹配 → 类似 SQL INNER JOIN
Merge By Index：按索引合并 → 并行处理结果合并
```

## 人工审批工作流

```
发送审批请求
    ↓
Wait 节点（等待 Webhook 回调）
    ↓
处理审批结果
```

Wait 节点配置 `resume: "webhook"`，审批链接：`http://localhost:5678/webhook/approve/{order_id}`

## 实战：订单审批路由

```
订单输入 → 数据验证（无效 → 拒绝）
  → 库存检查（不足 → 通知采购 + 拒绝）
  → 金额分级
    ├─ < 1000    → 自动通过 → 确认邮件
    ├─ 1000-5000 → 经理审批 → 等待 → 结果通知
    └─ > 5000    → 总监审批 → 等待 → 结果通知
  → 更新数据库
```

Code 节点计算分级：

```javascript
const amount = $input.first().json.amount
let level
if (amount < 1000) level = 'auto_approve'
else if (amount < 5000) level = 'manager_review'
else level = 'director_review'

return [{
  json: {
    ...$input.first().json,
    approval_level: level,
    requires_review: level !== 'auto_approve'
  }
}]
```

## 练习

### 练习一：分数路由

接收 Webhook（含 score 字段），根据分数路由：>= 90 "优秀"，>= 60 "及格"，< 60 "不及格"。每个分支输出不同格式消息。

### 练习二：批量订单统计

接收 10 个订单的数组，用 Loop 逐个计算总额，最后汇总输出统计信息（总订单数、总金额、平均金额）。

### 练习三：数据合并

从两个 Webhook 分别接收客户信息和订单信息，用 Merge 节点按 customer_id 关联，输出合并数据。

## 参考答案

### 练习一

Webhook → Code（计算 grade）→ Switch（按 grade 分支）→ 三个输出

```javascript
const score = $input.first().json.score
let grade
if (score >= 90) grade = 'excellent'
else if (score >= 60) grade = 'pass'
else grade = 'fail'
return [{ json: { ...$input.first().json, grade } }]
```

### 练习二

Webhook → Split In Batches（Batch Size=5）→ Code（计算单个订单总额）→ 聚合后 Code（统计）

```javascript
// 循环体内
const order = $input.first().json
const total = order.items.reduce((sum, item) => sum + item.price * item.qty, 0)
return [{ json: { order_id: order.order_id, total } }]

// 聚合后
const orders = $input.all()
return [{
  json: {
    total_orders: orders.length,
    total_amount: orders.reduce((s, o) => s + o.json.total, 0),
    average_amount: orders.reduce((s, o) => s + o.json.total, 0) / orders.length
  }
}]
```
