# 阶段实战：订单处理系统

## 场景

电商客户需要自动化订单处理系统：接收多渠道订单、校验信息、检查库存、按金额审批、批量更新数据库、发送通知、生成每日报表。

## 系统架构

```
触发层：Webhook（实时）+ Schedule（CSV 导入、API 轮询）
处理层：子工作流（验证、库存、审批、通知）
数据层：PostgreSQL + S3
输出层：邮件、Slack、每日报表
```

## 数据模型

```sql
CREATE TABLE orders (
  order_id VARCHAR(50) PRIMARY KEY,
  customer_id VARCHAR(50),
  customer_email VARCHAR(100),
  items JSONB,
  total_amount DECIMAL(10,2),
  status VARCHAR(20),
  approval_level VARCHAR(20),
  warehouse_id VARCHAR(20),
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE inventory (
  product_id VARCHAR(50) PRIMARY KEY,
  quantity INTEGER,
  warehouse_id VARCHAR(20)
);
```

## 子工作流：数据验证

```javascript
const order = $input.first().json
const errors = []

if (!order.order_id) errors.push('缺少 order_id')
if (!order.customer_email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(order.customer_email)) {
  errors.push('邮箱格式无效')
}
if (!order.items || order.items.length === 0) errors.push('订单无商品')

const total = order.items?.reduce((sum, item) => sum + (item.price * item.qty), 0) || 0
if (total <= 0) errors.push('订单金额必须大于 0')

return [{ json: { valid: errors.length === 0, errors, data: { ...order, calculated_total: total } } }]
```

## 子工作流：库存检查

```
Loop（遍历商品）
    ↓
PostgreSQL（查询库存）
    ↓
IF（库存充足？）
    ├─ 是 → 标记可用仓库
    └─ 否 → 标记缺货
```

## 审批路由

```javascript
const amount = $input.first().json.calculated_total
let approval_level
if (amount < 1000) approval_level = 'auto'
else if (amount < 5000) approval_level = 'manager'
else approval_level = 'director'

return [{ json: { ...$input.first().json, approval_level, requires_approval: approval_level !== 'auto' } }]
```

## 主流程编排

```
触发源
    ↓
Execute Workflow（数据验证）→ IF(valid?) → 否 → 记录错误 → 通知
    ↓
Execute Workflow（库存检查）→ IF(available?) → 否 → 通知缺货
    ↓
Execute Workflow（审批路由）→ IF(需要审批?) → 是 → Wait（等待审批）
    ↓
PostgreSQL（更新状态为 confirmed）
    ↓
并行：发送确认邮件 + Slack 通知仓库 + 更新 CRM
```

## 批处理每日报表

```
Schedule（每天凌晨 2:00）
    ↓
PostgreSQL（查询当日订单）
    ↓
Split In Batches（每批 100）
    ↓
Code（计算统计）
    ↓
Send Email（发送报表）
```

报表生成：

```javascript
const orders = $input.all()
const stats = {
  date: $now.toFormat('yyyy-MM-dd'),
  total_orders: orders.length,
  total_amount: orders.reduce((s, o) => s + o.json.total_amount, 0),
  by_status: {}
}

for (const o of orders) {
  stats.by_status[o.json.status] = (stats.by_status[o.json.status] || 0) + 1
}

const report = `订单日报 ${stats.date}
总订单数: ${stats.total_orders}
总金额: ¥${stats.total_amount.toFixed(2)}
状态分布: ${JSON.stringify(stats.by_status)}`

return [{ json: { subject: `订单日报 ${stats.date}`, body: report } }]
```

## 错误处理

```
Error Trigger → Code（分类错误）→ Switch
    ├─ 认证错误 → 通知管理员
    ├─ 数据错误 → 记录到错误表
    ├─ 外部服务错误 → 重试队列
    └─ 未知错误 → 告警 + 日志
```

循环中单条错误隔离：

```javascript
try {
  const result = await processOrder(order)
  return [{ json: { success: true, order_id: order.order_id } }]
} catch (error) {
  await logError(order.order_id, error.message)
  return [{ json: { success: false, order_id: order.order_id, error: error.message } }]
}
```

```
Schedule（每 5 分钟）→ PostgreSQL（查询超时订单）
    ↓
IF（有超时订单？）→ 是 → Slack 告警
```
