# 第二阶段：高级工作流

## 阶段目标

掌握 n8n 的高级编排能力：条件分支、循环、子工作流复用、批量数据处理、凭证安全管理和自定义节点开发。

## 课时安排

1. 条件分支与循环（IF/Switch、Split、Merge、Loop）
2. 子工作流（工作流复用、参数传递、错误传播）
3. 数据聚合与批处理（批量操作、分页处理、聚合统计）
4. Credentials 管理（凭证安全、OAuth2、API Key）
5. 自定义节点开发（TypeScript 自定义节点、发布）
6. 阶段实战：订单处理系统

## 阶段项目

构建一个订单处理系统：接收订单 → 校验库存 → 条件分支（成功/失败） → 批量更新数据库 → 通知客户 → 生成报表。

## 验收标准

- 使用 IF/Switch 节点实现条件分支
- 使用 Loop 节点处理批量数据
- 创建至少一个子工作流并在主流程中调用
- Credentials 通过 n8n 凭证管理，不硬编码
- 订单流程端到端可执行
