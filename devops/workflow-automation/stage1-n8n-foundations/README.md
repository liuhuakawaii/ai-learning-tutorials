# 第一阶段：n8n 基础

## 阶段目标

理解自动化工作流的核心思维，掌握 n8n 的安装配置、节点使用、数据映射和错误处理，能独立构建一个完整的通知自动化工作流。

## 课时安排

1. 自动化工作流思维（什么是工作流、为什么用 n8n）
2. n8n 安装与配置（Docker 部署、环境变量、数据库）
3. 节点与触发器（常用节点、Webhook、定时触发）
4. 数据映射与转换（表达式、JSON 操作、格式转换）
5. 错误处理与重试（错误节点、重试策略、告警通知）
6. 阶段实战：客户通知自动化

## 阶段项目

构建一个客户通知自动化工作流：当 CRM 中有新客户时，自动发送欢迎邮件、创建 Slack 通知、更新数据库记录。

## 验收标准

- n8n 通过 Docker 成功启动并可访问
- 工作流包含至少 3 个节点（触发 → 处理 → 输出）
- 使用表达式进行数据映射
- 包含错误处理分支
- 工作流能手动和自动触发执行
