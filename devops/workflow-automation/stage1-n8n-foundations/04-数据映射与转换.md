# 第四课：数据映射与转换

> **课程定位**：掌握 n8n 中数据流转的核心技能——表达式、数据映射和格式转换
> **前置知识**：了解 JSON 格式，会使用基本的 JavaScript 表达式
> **预计时长**：35 分钟

---

## 场景引入

你的工作流从 CRM 拉取客户数据，字段名是 `first_name` 和 `last_name`，但邮件节点需要的字段是 `fullName`。订单数据的价格是分为单位（整数），但报表需要的是元（小数）。日期格式是 ISO 8601，但通知消息需要"2024年3月15日"这种格式。

这些数据转换问题在每个工作流中都会遇到。掌握 n8n 的数据映射和转换能力，是构建可靠工作流的基础。

---

## 一、表达式基础

### 1.1 表达式语法

n8n 使用 `{{ }}` 包裹表达式，内部是 JavaScript 代码：

```javascript
// 引用当前节点输入的数据
{{ $json.fieldName }}

// 数学运算
{{ $json.price * $json.quantity }}

// 字符串操作
{{ $json.firstName + " " + $json.lastName }}

// 条件表达式
{{ $json.status === "active" ? "启用" : "禁用" }}

// 调用内置方法
{{ $json.email.toLowerCase() }}
```

### 1.2 数据上下文

n8n 提供了多个上下文对象：

| 对象 | 说明 | 示例 |
|------|------|------|
| `$json` | 当前 Item 的 JSON 数据 | `{{ $json.name }}` |
| `$input` | 输入数据的访问器 | `{{ $input.first().json.name }}` |
| `$now` | 当前时间 | `{{ $now.toISO() }}` |
| `$env` | 环境变量 | `{{ $env.API_KEY }}` |
| `$credentials` | 凭证数据 | `{{ $credentials.apiKey }}` |
| `$node` | 当前节点信息 | `{{ $node.name }}` |
| `$workflow` | 工作流信息 | `{{ $workflow.id }}` |
| `$execution` | 执行信息 | `{{ $execution.id }}` |

### 1.3 引用其他节点的数据

```javascript
// 引用上一个节点的数据（当前输入）
{{ $json.name }}

// 引用指定节点的数据
{{ $('CRM Node').first().json.customer_id }}

// 引用指定节点的第 N 个 Item
{{ $('CRM Node').item.json.name }}

// 获取指定节点的所有 Item
const allCustomers = $('CRM Node').all();
```

## 二、常用数据转换

### 2.1 字符串操作

```javascript
// 大小写转换
{{ $json.name.toUpperCase() }}
{{ $json.name.toLowerCase() }}

// 截取
{{ $json.name.substring(0, 10) }}
{{ $json.name.slice(0, -3) }}

// 替换
{{ $json.phone.replace(/-/g, "") }}
{{ $json.address.replace("北京市", "北京") }}

// 拼接
{{ `${$json.firstName} ${$json.lastName}` }}

// 去空格
{{ $json.name.trim() }}

// 分割
{{ $json.tags.split(",") }}

// 判断
{{ $json.email.includes("@") }}
{{ $json.name.startsWith("张") }}
```

### 2.2 数字操作

```javascript
// 四舍五入
{{ Math.round($json.price * 100) / 100 }}

// 向上/向下取整
{{ Math.ceil($json.score) }}
{{ Math.floor($json.discount) }}

// 分转元
{{ ($json.amount_cents / 100).toFixed(2) }}

// 百分比
{{ ($json.completed / $json.total * 100).toFixed(1) + "%" }}

// 范围限制
{{ Math.max(0, Math.min(100, $json.score)) }}

// 随机数
{{ Math.floor(Math.random() * 100) }}
```

### 2.3 日期操作

n8n 内置了 Luxon 日期库：

```javascript
// 当前时间
{{ $now.toISO() }}                          // 2024-03-15T10:30:00.000+08:00
{{ $now.toFormat('yyyy-MM-dd') }}           // 2024-03-15
{{ $now.toFormat('yyyy年MM月dd日') }}        // 2024年03月15日
{{ $now.toFormat('HH:mm:ss') }}             // 10:30:00

// 解析日期字符串
{{ DateTime.fromISO($json.date).toFormat('yyyy-MM-dd') }}
{{ DateTime.fromFormat($json.date, 'dd/MM/yyyy').toISO() }}

// 日期计算
{{ $now.plus({ days: 7 }).toFormat('yyyy-MM-dd') }}      // 7 天后
{{ $now.minus({ hours: 24 }).toISO() }}                  // 24 小时前
{{ $now.startOf('month').toFormat('yyyy-MM-dd') }}       // 本月第一天
{{ $now.endOf('quarter').toFormat('yyyy-MM-dd') }}       // 本季度最后一天

// 日期差值
const start = DateTime.fromISO($json.start_date);
const end = DateTime.fromISO($json.end_date);
const diff = end.diff(start, 'days').toObject();
{{ diff.days }}  // 天数差
```

### 2.4 数组操作

```javascript
// 数组长度
{{ $json.items.length }}

// 取第一个/最后一个
{{ $json.items[0] }}
{{ $json.items[$json.items.length - 1] }}

// 映射
{{ $json.items.map(item => item.name) }}

// 过滤
{{ $json.items.filter(item => item.price > 100) }}

// 求和
{{ $json.items.reduce((sum, item) => sum + item.price, 0) }}

// 查找
{{ $json.items.find(item => item.id === "A001") }}

// 排序
{{ [...$json.items].sort((a, b) => a.price - b.price) }}

// 去重
{{ [...new Set($json.tags)] }}

// 展平
{{ $json.orders.flatMap(order => order.items) }}
```

### 2.5 对象操作

```javascript
// 解构赋值
const { name, email, phone } = $json;

// 对象合并
{{ { ...$json, newField: "value" } }}

// 获取 keys/values
{{ Object.keys($json) }}
{{ Object.values($json) }}

// 重命名字段
const { old_name, ...rest } = $json;
{{ { new_name: old_name, ...rest } }}

// 删除字段
const { password, ...safeData } = $json;
{{ safeData }}
```

## 三、Set 节点的高级用法

### 3.1 数据清洗模板

从 CRM 拉取的原始数据往往有很多冗余字段，用 Set 节点清洗：

```json
{
  "assignments": [
    {
      "name": "customer_id",
      "value": "={{ $json.id }}"
    },
    {
      "name": "full_name",
      "value": "={{ $json.properties.firstname }} {{ $json.properties.lastname }}"
    },
    {
      "name": "email",
      "value": "={{ $json.properties.email.toLowerCase().trim() }}"
    },
    {
      "name": "phone",
      "value": "={{ $json.properties.phone?.replace(/[^0-9+]/g, '') ?? '' }}"
    },
    {
      "name": "registered_at",
      "value": "={{ DateTime.fromISO($json.created_at).toFormat('yyyy-MM-dd') }}"
    },
    {
      "name": "is_active",
      "value": "={{ $json.properties.lifecyclestage === 'customer' }}"
    }
  ]
}
```

### 3.2 数据格式化

Set 节点还可以用来格式化输出：

```json
{
  "assignments": [
    {
      "name": "order_summary",
      "value": "={{ `${$json.customer} 购买了 ${$json.items.length} 件商品，总计 ¥${($json.total_cents / 100).toFixed(2)}` }}"
    },
    {
      "name": "priority_label",
      "value": "={{ $json.priority === 'high' ? '🔴 紧急' : $json.priority === 'medium' ? '🟡 普通' : '🟢 低优先级' }}"
    },
    {
      "name": "formatted_date",
      "value": "={{ DateTime.fromISO($json.created_at).toFormat('yyyy年MM月dd日 HH:mm') }}"
    }
  ]
}
```

## 四、Code 节点处理复杂转换

### 4.1 多对一聚合

当需要把多个 Item 合并成一个时：

```javascript
// 把多个订单项聚合成一个订单摘要
const items = $input.all();

const summary = {
  order_id: items[0].json.order_id,
  customer: items[0].json.customer,
  items: items.map(item => ({
    name: item.json.product_name,
    qty: item.json.quantity,
    price: item.json.unit_price
  })),
  total_items: items.reduce((sum, item) => sum + item.json.quantity, 0),
  total_amount: items.reduce((sum, item) => sum + (item.json.unit_price * item.json.quantity), 0)
};

return [{ json: summary }];
```

### 4.2 一对多拆分

把一个 Item 拆分成多个：

```javascript
// 把一个包含多个产品的订单拆分成单独的记录
const order = $input.first().json;

const records = order.items.map(item => ({
  json: {
    order_id: order.order_id,
    customer: order.customer,
    product_name: item.name,
    quantity: item.qty,
    unit_price: item.price,
    subtotal: item.qty * item.price,
    order_date: order.created_at
  }
}));

return records;
```

### 4.3 数据规范化

把不同格式的数据统一成标准格式：

```javascript
// 统一不同来源的客户数据格式
const item = $input.first().json;
const source = item._source; // 'crm', 'form', 'manual'

let normalized;

switch (source) {
  case 'crm':
    normalized = {
      name: `${item.first_name} ${item.last_name}`,
      email: item.email_address,
      phone: item.phone_number,
      source: 'CRM'
    };
    break;
  case 'form':
    normalized = {
      name: item.fullname,
      email: item.email,
      phone: item.tel || '',
      source: '表单'
    };
    break;
  case 'manual':
    normalized = {
      name: item.name,
      email: item.email,
      phone: item.phone || '',
      source: '手动录入'
    };
    break;
  default:
    normalized = item;
}

return [{ json: normalized }];
```

### 4.4 错误处理

在 Code 节点中处理数据异常：

```javascript
const items = $input.all();
const results = [];
const errors = [];

for (const item of items) {
  try {
    // 尝试解析金额
    const amount = parseFloat(item.json.amount);
    if (isNaN(amount)) {
      throw new Error(`无效金额: ${item.json.amount}`);
    }
    
    results.push({
      json: {
        ...item.json,
        amount: amount,
        amount_formatted: `¥${amount.toFixed(2)}`
      }
    });
  } catch (error) {
    errors.push({
      json: {
        error: error.message,
        original_data: item.json
      }
    });
  }
}

// 返回正常数据，错误数据可以通过其他方式处理
if (errors.length > 0) {
  console.log(`${errors.length} 条数据解析失败`);
}

return results;
```

## 五、数据类型转换

### 5.1 类型判断和转换

```javascript
// 字符串转数字
{{ Number($json.amount) }}
{{ parseInt($json.count) }}
{{ parseFloat($json.price) }}

// 数字转字符串
{{ $json.amount.toString() }}
{{ String($json.count) }}

// 布尔值转换
{{ Boolean($json.is_active) }}
{{ $json.status === "active" }}

// JSON 解析
{{ JSON.parse($json.raw_data) }}

// JSON 序列化
{{ JSON.stringify($json.complex_object) }}
```

### 5.2 空值处理

```javascript
// 空值合并
{{ $json.name ?? "未知" }}
{{ $json.phone || "未提供" }}

// 可选链
{{ $json.address?.city ?? "未知" }}
{{ $json.contacts?.[0]?.email ?? "" }}

// 默认值
{{ $json.discount ?? 0 }}
{{ $json.tags ?? [] }}
```

## 常见误区

### 误区一："直接用 $json 访问嵌套数据"

n8n 的表达式中，`$json` 直接指向当前 Item 的顶层 JSON。嵌套数据用点号访问：`{{ $json.user.address.city }}`，而不是 `{{ $json['user']['address']['city'] }}`。

### 误区二："表达式中不能写多行代码"

n8n 的表达式支持多行，但建议把复杂逻辑放在 Code 节点中。表达式适合简单的数据引用和转换。

### 误区三："数据在节点间传递会自动转换类型"

n8n 不会自动转换类型。如果一个字段是字符串 "123"，传给需要数字的节点时可能会出错。需要手动用 `Number()` 或 `parseInt()` 转换。

### 误区四："所有节点的输出结构一样"

不同节点的输出结构不同。HTTP Request 节点输出的是 API 响应，Database 节点输出的是查询结果。需要查看每个节点的输出来确定字段名。

---

## 工程建议

1. **先查看节点输出**：在编辑器中执行节点后，点击 Output 面板查看实际输出的数据结构。
2. **用 Set 节点做中间转换**：不要在每个下游节点中重复写相同的转换逻辑。
3. **处理空值**：始终考虑字段可能为空的情况，用 `??` 或 `||` 提供默认值。
4. **Code 节点处理复杂逻辑**：超过 3 行的转换逻辑应该放在 Code 节点中，保持表达式的简洁。
5. **测试边界数据**：用空值、超长字符串、特殊字符等边界数据测试转换逻辑。

---

## 小结

- n8n 表达式用 `{{ }}` 包裹，支持完整的 JavaScript 语法
- `$json` 访问当前 Item 数据，`$('NodeName')` 访问其他节点数据
- 日期操作使用 Luxon 库，字符串和数组操作使用原生 JavaScript
- Set 节点适合简单的字段映射和格式化，Code 节点适合复杂转换
- 始终处理空值和类型转换，避免运行时错误

## 参考答案

### 练习一

**思路**：用 Set 节点的表达式做字段重命名、去空格、大小写转换和时间戳解析。

**答案**：

Set 节点配置：

```json
{
  "assignments": [
    {
      "name": "name",
      "value": "={{ $json.usr_name.trim() }}"
    },
    {
      "name": "email",
      "value": "={{ $json.usr_email.toLowerCase().trim() }}"
    },
    {
      "name": "phone",
      "value": "={{ $json.usr_phone.replace(/-/g, '') }}"
    },
    {
      "name": "registered_date",
      "value": "={{ DateTime.fromSeconds($json.reg_ts).toFormat('yyyy-MM-dd') }}"
    }
  ]
}
```

**要点**：
- `.trim()` 去除首尾空格
- `.toLowerCase()` 统一小写
- `.replace(/-/g, '')` 用正则去除所有横杠
- `DateTime.fromSeconds()` 解析 Unix 时间戳（秒）

### 练习二

**思路**：用 Code 节点接收所有订单项，做金额转换和统计。

**答案**：

```javascript
const items = $input.all();

const orders = items.map(item => ({
  json: {
    order_id: item.json.order_id,
    customer: item.json.customer,
    amount_yuan: (item.json.amount_cents / 100).toFixed(2),
    amount_cents: item.json.amount_cents
  }
}));

const total = items.reduce((sum, item) => sum + item.json.amount_cents, 0);
const average = total / items.length;

// 在最后添加一个汇总项
orders.push({
  json: {
    order_id: 'SUMMARY',
    customer: '统计',
    amount_yuan: (total / 100).toFixed(2),
    amount_cents: total,
    average_yuan: (average / 100).toFixed(2),
    count: items.length
  }
});

return orders;
```

**要点**：
- 分转元：`amount_cents / 100`，用 `.toFixed(2)` 保留两位小数
- `reduce` 做累加求和
- 汇总数据可以作为数组的最后一项返回

### 练习三

**思路**：用 Code 节点解析日期，过滤和排序。

**答案**：

```javascript
const items = $input.all();
const now = DateTime.now();
const thirtyDaysAgo = now.minus({ days: 30 });

const filtered = items
  .map(item => ({
    json: {
      date: item.json.date,
      parsed: DateTime.fromISO(item.json.date)
    }
  }))
  .filter(item => item.json.parsed >= thirtyDaysAgo && item.json.parsed <= now)
  .sort((a, b) => a.json.parsed - b.json.parsed)
  .map(item => ({
    json: {
      date: item.json.parsed.toFormat('yyyy-MM-dd'),
      days_ago: Math.floor(now.diff(item.json.parsed, 'days').days)
    }
  }));

return filtered;
```

**要点**：
- `DateTime.now()` 获取当前时间
- `.minus({ days: 30 })` 计算 30 天前
- 日期比较可以直接用 `>=` 和 `<=`
- 排序后重新格式化输出
