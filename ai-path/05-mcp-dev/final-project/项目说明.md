# MCP Tool Suite 项目说明

## 项目目标

开发一套企业内部 MCP 工具集：数据库查询 Server + REST API 适配 Server + 文件系统 Server，集成到 Agent 系统中，含完整的安全认证和权限控制。本 kit 提供 TypeScript MCP Server 骨架，学员可先练协议开发，再扩展为真实业务 Server。

## 内置 project kit

```text
05-mcp-dev-course/final-project/mcp-tool-suite
```

运行：

```bash
cd 05-mcp-dev-course/final-project/mcp-tool-suite
npm install
npm run check
npm run build
npm run inspector
```

## 核心功能

1. MCP Server 基础框架
   - Tool / Resource / Prompt Template 三种原语
   - stdio 和 SSE 两种传输模式
   - 能力协商与错误处理

2. 数据库查询 Server
   - SQL 查询 Tool（只读）
   - 表结构 Resource
   - 查询模板 Prompt Template

3. REST API 适配 Server
   - HTTP 请求 Tool
   - API 文档 Resource
   - 请求模板 Prompt Template

4. 文件系统 Server
   - 文件读写 Tool
   - 目录列表 Resource
   - 文件操作 Prompt Template

5. 安全层
   - API Key 认证
   - 输入校验（SQL 注入防护）
   - 速率限制
   - 权限白名单

| 阶段 | 交付物 | 对应文件 |

## 验收标准

- `npm run check` 通过
- `npm run build` 编译成功
- MCP Inspector 能连接并发现 Tool/Resource
- 数据库查询 Server 能执行 SELECT 查询
- 文件系统 Server 能读写文件
- 安全层能拦截非法输入
