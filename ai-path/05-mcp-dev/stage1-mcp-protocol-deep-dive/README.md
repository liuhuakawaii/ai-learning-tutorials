# 第 1 阶段：MCP 协议深度解析

> 从协议层面理解 MCP，而不只是会调 API

## 学习目标

- 深入理解 MCP 的设计哲学和协议架构
- 掌握 JSON-RPC 2.0 在 MCP 中的应用
- 理解三种传输层（stdio / SSE / Streamable HTTP）的区别和选型
- 能够用原始 HTTP 实现 MCP 通信（不依赖 SDK）

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | MCP 设计哲学 — 为什么需要标准化的工具协议，USB 类比的深入解读 | 2h |
| 02 | 协议架构 — Host / Client / Server 三层模型与消息流 | 3h |
| 03 | 消息格式详解 — JSON-RPC 2.0 在 MCP 中的应用 | 3h |
| 04 | 传输层 — stdio / SSE / Streamable HTTP 的选型与实现 | 3h |
| 05 | 能力协商 — Client 与 Server 的能力发现与协商机制 | 3h |
| 06 | 阶段实战：用原始 HTTP 请求实现一个最小 MCP 通信（不用 SDK） | 4h |

## 验收标准

- [ ] 能画出 MCP 三层架构图并解释消息流
- [ ] 用原始 HTTP 请求完成一次完整的 MCP 工具调用
- [ ] 能解释三种传输层的优劣和适用场景
