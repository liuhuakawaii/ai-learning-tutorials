# 第 3 阶段：高级 MCP 模式

> 超越基础 CRUD，实现复杂的 MCP 工具生态

## 学习目标

- 掌握动态 Tool 注册、流式响应等高级 MCP 模式
- 学会实现 Tool 内部调用其他 Tool 的嵌套模式
- 理解有状态 Server 的设计与会话管理
- 能够开发一个支持动态 Tool 的智能 API Gateway

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 动态 Tool 注册 — 运行时根据上下文动态暴露 Tool | 3h |
| 02 | 流式响应 — 长时间运行 Tool 的进度通知与流式输出 | 3h |
| 03 | 嵌套调用 — Tool 内部调用其他 Tool 的编排模式 | 3h |
| 04 | 批量操作 — 高效处理批量请求的 MCP 模式 | 2h |
| 05 | 状态管理 — 有状态 Server 的设计与会话管理 | 3h |
| 06 | 阶段实战：开发一个支持动态 Tool 的智能 API Gateway MCP Server | 4h |

## 验收标准

- [ ] 实现动态 Tool 注册，能在运行时增减可用 Tool
- [ ] 流式响应能展示长时间运行任务的进度
- [ ] API Gateway 能根据请求内容自动路由到不同的后端服务
