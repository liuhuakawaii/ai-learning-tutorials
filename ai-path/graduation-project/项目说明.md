# 毕业项目：AI 数据分析平台

> 串联 01-07 全部课程的终极项目：一个多 Agent 驱动、支持多模态输入、具备完整评估与可观测性的智能数据分析平台

## 项目目标

构建一个面向业务人员的 AI 数据分析平台。用户通过自然语言（文本/语音/图片/文档）提出分析需求，多个 AI Agent 协作完成数据查询、分析、可视化和报告生成，全程可追踪、可评估、有人工审批节点。

## 核心功能模块

### 1. 多模态输入处理
- 文本：自然语言分析需求
- 语音：语音转文字后处理（Whisper ASR）
- 图片：上传图表/截图，AI 解读内容
- 文档：上传 Excel/CSV/PDF，自动解析数据

### 2. 多 Agent 协作分析
- **查询 Agent**：通过 MCP Server 访问数据库，生成并执行 SQL
- **分析 Agent**：对查询结果进行统计分析、趋势识别、异常检测
- **可视化 Agent**：选择合适的图表类型并生成可视化
- **报告 Agent**：将分析结果整合为结构化报告

### 3. MCP 工具层
- **数据库 MCP Server**：SQL 查询、表结构查看、数据采样
- **文件 MCP Server**：CSV/Excel 读写、数据导入导出
- **API Gateway MCP Server**：对接外部数据源

### 4. 人工审批流
- SQL 查询审批（防止误操作生产数据）
- 分析结论审批（确保分析结果准确）
- 报告发布审批（控制对外输出质量）

### 5. 评估与可观测性
- 自动化评估：SQL 正确性、分析质量、报告准确性
- 可观测性：全链路追踪、Token 消耗、延迟监控
- 成本控制：Agent 调用预算、Token 用量告警
- 持续优化：A/B 测试、人工标注反馈回路

## 验收标准

## 快速启动

```bash
# 1. 克隆并进入项目
cd ai-engineer-path/graduation-project/ai-data-platform

# 2. 安装依赖
npm install
pip install -r requirements.txt

# 3. 启动基础设施
docker-compose up -d postgres langfuse

# 4. 初始化数据
python scripts/seed_db.py

# 5. 启动服务
npm run dev          # 前端
python -m uvicorn backend.main:app --reload  # 后端

# 6. 验证
npm run check        # 结构验证
python scripts/run_eval.py  # 运行评估
```
