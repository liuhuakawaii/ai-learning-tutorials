# 第二阶段：RAG 与知识库

## 阶段目标

你会理解 RAG 的完整链路：文档解析、文本切分、向量化、检索、组装上下文、带引用回答。目标是降低幻觉，让回答能回到资料来源。

## 课时安排

1. RAG 的本质：检索增强生成解决什么问题
2. 文档解析：PDF、Markdown、TXT、网页内容
3. Chunk 策略：大小、重叠、标题层级和元数据
4. Embeddings：向量是什么，相似度如何工作
5. 检索：topK、过滤、混合检索、召回率
6. 引用与溯源：source、page、section、snippet
7. 阶段实战：个人文档问答系统

## 实战任务

构建一个文档问答系统，支持上传 Markdown/TXT，自动切分并建立索引，回答时展示引用来源。

## 验收标准

- 每个 chunk 都保存来源和位置
- 用户能看到回答引用了哪些资料
- 对资料外问题能拒答或说明信息不足
- 修改文档后可以重新索引
- 至少准备 10 条问答评测样本
