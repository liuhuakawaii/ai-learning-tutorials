# 第一阶段：大模型 API 基础

## 阶段目标

你会从"会调用接口"升级到"能设计稳定的 AI 对话能力"。重点不是堆 Prompt，而是理解请求、上下文、结构化输出、流式响应、错误处理和前端体验。

## 课时安排

1. AI 应用到底是什么——从一个最小调用引出五个核心组成，建立项目骨架
2. API Key、SDK 与环境变量——配置项目、跑通第一次调用、密钥安全三条铁律
3. 第一次真正的问答调用——system prompt、temperature、max_output_tokens、错误处理
4. 多轮对话——给问答加上会话历史、历史裁剪、会话隔离
5. 结构化输出——用 Zod 校验大纲生成
6. 流式响应——把问答改成流式、取消请求、错误恢复
7. 阶段实战——stage1 代码整合验收

## 实战任务

在 AI Knowledge Workspace 项目上逐步实现：

- 基于文档的问答调用（第 3 课）
- 多轮对话与历史管理（第 4 课）
- 结构化大纲生成（第 5 课）
- 流式问答响应（第 6 课）
- 整合验收与端到端测试（第 7 课）

## 验收标准

- 项目目录已创建，OpenAI SDK 和环境变量配置正确
- API Key 不出现在前端代码，`.env` 在 `.gitignore` 中
- 单次问答能基于检索到的资料生成回答
- 多轮对话能保持上下文，历史裁剪在长对话后生效
- 结构化输出能通过 Zod schema 校验
- 流式响应逐字显示，取消后保留已生成内容
- 错误处理区分了不同错误类型，提示信息用户可理解
