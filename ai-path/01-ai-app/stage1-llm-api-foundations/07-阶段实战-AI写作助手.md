## 到目前为止你做了什么

回顾一下 stage1 的进展：

- 第 1-2 课：项目骨架、OpenAI SDK、环境变量
- 第 3 课：问答调用、system prompt、temperature、错误处理

这些能力分散在不同的文件和函数里。这节课要做的是：把它们整合成一个可运行的知识工作台 CLI，然后逐项验收。

## 第一步：确保基础问答能跑

```bash
# 构建索引（如果还没做）
npm run ingest

# 单次问答
npx tsx src/ask.ts "这个产品的登录流程是什么"
```

预期输出：基于资料的回答 + 引用来源 + token 使用量。

如果报错，按错误类型排查：

- `AuthenticationError`：检查 `.env` 里的 `OPENAI_API_KEY`
- `APIConnectionError`：检查网络
- `NotFoundError`：检查模型名拼写
- 空回答：检查检索是否有结果

## 第二步：多轮对话验收

```bash
npx tsx src/chat.ts
```

验收清单：

1. 连续问两个相关问题，模型能保持上下文
2. 问"clear"清除历史后再问，模型"失忆"
3. 连续 10 轮后不报错（裁剪在工作）

如果第 2 个问题模型不记得上下文，检查 `Conversation` 类是否正确传递了历史消息。如果 10 轮后报错"上下文长度超出"，检查 `trimByTokens` 是否在发送前被调用。

## 第三步：结构化输出验收

```bash
npx tsx src/outline.ts "data/docs/product-brief.md"
```

预期输出：一个结构化的大纲 JSON，包含 title、topics、summary。

验收清单：

1. 输出能被 `JSON.parse` 解析
2. 输出能通过 Zod schema 校验
3. 换一份文档再跑，结构一致

如果输出不符合 schema，检查 `zodTextFormat` 是否正确传入了 schema。如果字段值不合理（比如 `keyPoints` 为空数组），可能是 schema 约束不够严格，加上 `.min(1)`。

## 第四步：流式响应验收

如果你有前端项目（Next.js），启动后测试：

验收清单：

1. 提问后 0.5 秒内开始出现输出
2. 文字逐字显示，不是一次性弹出
3. 点击"停止"后内容不消失
4. 停止后可以继续提问

如果显示是白屏然后一次性弹出，检查后端是否用了 `stream: true`，前端是否在读取 `ReadableStream`。如果停止后内容消失了，检查 `AbortError` 是否被正确处理。

## 第五步：错误处理验收

```bash
npx tsx src/examples/error-test.ts
```

手动测试：

1. 把 `.env` 里的 Key 改成无效值 → 应提示"API Key 无效"
2. 把模型名改成 `gpt-99` → 应提示"模型不存在"
3. 断开网络 → 应提示"网络连接失败"

每种错误的提示信息应该是用户可理解的，不是 raw error 对象。

在提交 stage1 代码之前，逐项检查：

```

```

## stage1 的边界

完成这些验收后，你有了一个能用的知识工作台——但它的能力很有限：

- **检索是关键词匹配**，不是语义搜索。问"怎么保护用户隐私"匹配不到"安全措施"。
- **没有真正的 RAG**。检索到的片段直接塞进 prompt，没有重排序、没有压缩。
- **没有工具调用**。模型只能回答问题，不能保存笔记、创建任务。
- **没有持久化**。会话存在内存里，重启就没了。

这些是后续阶段的内容。stage1 的价值在于：你已经理解了 AI 应用最底层的调用模式——输入、输出、上下文、结构化、流式、错误处理。后面所有高级功能都建立在这个基础上。

### 练习一

```typescript
import 'dotenv/config'
import { generateOutline } from './lib/outline'
import { safeAsk } from './lib/chat'
import { Conversation } from './lib/conversation'
import { createAnswerStream } from './lib/stream'
import fs from 'node:fs/promises'
import path from 'node:path'

async function runE2E() {
  const docPath = 'data/docs/product-brief.md'
  const docText = await fs.readFile(docPath, 'utf-8')

  // 1. 结构化大纲
  console.log('=== 1. 大纲生成 ===')
  const outline = await generateOutline(docText, 'product-brief.md')
  console.log('标题:', outline.title)
  console.log('主题数:', outline.topics.length)
  console.log('✅ 大纲生成成功\n')

  // 2. 基于大纲的问答
  console.log('=== 2. 单次问答 ===')
  const question = outline.topics[0].heading
  const result = await safeAsk(question, docText)
  console.log('问题:', question)
  console.log('成功:', result.success)
  console.log('✅ 问答完成\n')

  // 3. 多轮对话
  console.log('=== 3. 多轮对话 ===')
  const conv = new Conversation('你是知识库助手。')
  const a1 = await conv.send('这个产品的主要功能是什么？')
  console.log('第 1 轮:', a1.slice(0, 50), '...')
  const a2 = await conv.send('安全方面呢？')
  console.log('第 2 轮:', a2.slice(0, 50), '...')
  console.log('✅ 多轮对话完成\n')

  // 4. 流式输出
  console.log('=== 4. 流式输出 ===')
  const stream = await createAnswerStream('总结一下这个产品', docText)
  const reader = stream.getReader()
  const decoder = new TextDecoder()
  let chars = 0
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    const text = decoder.decode(value)
    for (const line of text.split('\n')) {
      if (line.startsWith('data: ') && !line.includes('[DONE]')) {
        const parsed = JSON.parse(line.slice(6))
        if (parsed.content) chars += parsed.content.length
      }
    }
  }
  console.log('收到字符数:', chars)
  console.log('✅ 流式输出完成\n')

  console.log('🎉 所有测试通过')
}

runE2E().catch(console.error)
```
