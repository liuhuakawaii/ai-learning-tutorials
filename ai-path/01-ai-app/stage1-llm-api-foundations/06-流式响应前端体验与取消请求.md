# 第6课：流式响应——把问答改成流式

> **前置知识**：第 3 课的问答调用、基本的 React 知识
> **预计时长**：30 分钟

## 等待的焦虑

你在知识工作台里问了一个问题，然后盯着屏幕看了 4 秒白屏。你不确定是网络断了、服务器挂了、还是在处理中。你差点去刷新页面。

看看 ChatGPT 和 Claude——它们的回答是逐字出现的。你发完消息后 0.1 秒就开始看到输出，像 AI 在实时打字。虽然总时间可能一样长，但感知完全不同：有输出就意味着系统在工作。

流式响应解决的不是速度问题，是感知问题。

## 流式的工作原理

非流式：后端等模型生成完整回答 → 一次性返回给前端 → 前端显示。

流式：后端开启 stream 模式 → 模型每生成一个 token 就发一个 chunk → 后端把 chunk 实时推给前端 → 前端逐字拼接显示。

技术上，这通过 Server-Sent Events (SSE) 实现。后端设置 `Content-Type: text/event-stream`，前端用 `ReadableStream` 读取。

## 后端：开启流式

```typescript
// src/lib/stream.ts
import openai from './openai'

export async function createAnswerStream(
  question: string,
  context: string
): Promise<ReadableStream> {
  const stream = await openai.responses.create({
    model: 'gpt-5.5',
    input: [
      {
        role: 'system',
        content: '你是一个知识库问答助手。只基于提供的资料回答。'
      },
      {
        role: 'user',
        content: `资料：\n${context}\n\n问题：${question}`
      }
    ],
    temperature: 0.3,
    stream: true,  // 开启流式
  })

  const encoder = new TextEncoder()

  return new ReadableStream({
    async start(controller) {
      try {
        for await (const chunk of stream) {
          if (chunk.type === 'response.output_text.delta') {
            controller.enqueue(
              encoder.encode(`data: ${JSON.stringify({ content: chunk.delta })}\n\n`)
            )
          }
        }
        controller.enqueue(encoder.encode('data: [DONE]\n\n'))
      } catch (error) {
        controller.enqueue(
          encoder.encode(`data: ${JSON.stringify({ error: String(error) })}\n\n`)
        )
      } finally {
        controller.close()
      }
    },
  })
}
```

关键点：`stream: true` 告诉 OpenAI SDK 返回一个异步迭代器，每个 chunk 是一小段文本。我们把每个 chunk 包装成 SSE 格式（`data: {...}\n\n`），最后用 `[DONE]` 标记结束。

## 前端：读取流

```typescript
// src/hooks/useStreamChat.ts
import { useState, useCallback, useRef } from 'react'

export function useStreamChat() {
  const [content, setContent] = useState('')
  const [isStreaming, setIsStreaming] = useState(false)
  const abortRef = useRef<AbortController | null>(null)

  const sendMessage = useCallback(async (question: string, context: string) => {
    // 如果正在流式传输，先取消
    abortRef.current?.abort()

    const controller = new AbortController()
    abortRef.current = controller

    setIsStreaming(true)
    setContent('')

    try {
      const response = await fetch('/api/ask', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ question, context }),
        signal: controller.signal,
      })

      if (!response.ok) throw new Error('请求失败')

      const reader = response.body?.getReader()
      if (!reader) throw new Error('无法读取响应流')

      const decoder = new TextDecoder()
      let fullContent = ''

      while (true) {
        const { done, value } = await reader.read()
        if (done) break

        const text = decoder.decode(value)
        for (const line of text.split('\n')) {
          if (!line.startsWith('data: ')) continue
          const data = line.slice(6)

          if (data === '[DONE]') {
            setIsStreaming(false)
            return fullContent
          }

          try {
            const parsed = JSON.parse(data)
            if (parsed.content) {
              fullContent += parsed.content
              setContent(fullContent)
            }
            if (parsed.error) {
              throw new Error(parsed.error)
            }
          } catch (e) {
            if (e instanceof SyntaxError) continue
            throw e
          }
        }
      }

      return fullContent
    } catch (error) {
      if (error instanceof Error && error.name === 'AbortError') {
        // 用户取消，不是错误
        return content
      }
      throw error
    } finally {
      setIsStreaming(false)
      abortRef.current = null
    }
  }, [content])

  const cancel = useCallback(() => {
    abortRef.current?.abort()
  }, [])

  return { content, isStreaming, sendMessage, cancel }
}
```

每个 SSE 消息格式是 `data: {"content":"你"}\n\n`。前端逐行解析，遇到 `data: [DONE]` 就知道流结束了。`content` 状态实时更新，React 重新渲染，用户看到文字逐字出现。

## 取消：保留已生成的内容

用户点"停止"时，调用 `abortController.abort()`。浏览器断开 HTTP 连接，前端保留已生成的内容。

```typescript
// 使用方式
const { content, isStreaming, sendMessage, cancel } = useStreamChat()

return (
  <div>
    <div>{content || '输入问题...'}</div>
    {isStreaming ? (
      <button onClick={cancel}>停止</button>
    ) : (
      <button onClick={() => sendMessage(question, context)}>提问</button>
    )}
  </div>
)
```

取消后 content 状态不丢失。用户可以看到已经生成的部分，也可以基于已有内容继续提问。

一个容易犯的错：在 `catch` 里把 `AbortError` 当普通错误处理，弹出"请求失败"提示。`AbortError` 是用户主动取消，不应该报错。

## 错误恢复：流中断了怎么办

流式传输过程中，网络可能中断，API 可能返回错误。处理方式：

```typescript
async function streamWithRetry(
  question: string,
  context: string,
  maxRetries = 2
): Promise<string> {
  let lastError: Error | null = null

  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    if (attempt > 0) {
      await new Promise(r => setTimeout(r, 1000 * attempt))
    }

    try {
      return await doStream(question, context)
    } catch (error) {
      if (error instanceof Error && error.name === 'AbortError') {
        throw error  // 用户取消，不重试
      }
      lastError = error as Error
    }
  }

  throw lastError
}
```

重试时用指数退避（1 秒、2 秒），不要瞬间大量重试。用户主动取消不触发重试——这是意图，不是错误。

## 流式 vs 非流式：什么时候用哪个

流式适合长文本生成：聊天回答、文档摘要、章节扩写。用户看到逐字输出，感知上更流畅。

非流式适合短结果：分类标签、情感评分、结构化数据。这类结果本身就是一两个词或一个 JSON，流式增加复杂度而没有体验提升。

在知识工作台里，问答用流式（回答可能很长），大纲生成用非流式（返回 JSON，程序直接使用）。

const messages = [
  { role: 'system', content: '你是一个知识库问答助手。用中文回答。' },

async function streamChat(question: string) {

    input: messages,
    temperature: 0.3,
    stream: true,

  let answer = ''
  for await (const chunk of stream) {
    if (chunk.type === 'response.output_text.delta') {
      process.stdout.write(chunk.delta)
      answer += chunk.delta
    }
  }

  messages.push({ role: 'assistant', content: answer })
  console.log('\n')
}

### 练习二

```typescript
function streamWithTimeout(
  reader: ReadableStreamDefaultReader<Uint8Array>,
  decoder: TextDecoder,
  timeoutMs: number = 10000
): Promise<string> {
  return new Promise((resolve, reject) => {
    let timeout: ReturnType<typeof setTimeout>
    let fullContent = ''

    function resetTimeout() {
      clearTimeout(timeout)
      timeout = setTimeout(() => {
        reject(new Error('流式传输超时'))
      }, timeoutMs)
    }

    resetTimeout()

    ;(async () => {
      try {
        while (true) {
          const { done, value } = await reader.read()
          if (done) break

          resetTimeout()  // 收到数据，重置超时

          const text = decoder.decode(value)
          for (const line of text.split('\n')) {
            if (line.startsWith('data: ')) {
              const data = line.slice(6)
              if (data === '[DONE]') {
                clearTimeout(timeout)
                resolve(fullContent)
                return
              }
              try {
                const parsed = JSON.parse(data)
                if (parsed.content) fullContent += parsed.content
              } catch {}
            }
          }
        }
        clearTimeout(timeout)
        resolve(fullContent)
      } catch (e) {
        clearTimeout(timeout)
        reject(e)
      }
    })()
  })
}
```
