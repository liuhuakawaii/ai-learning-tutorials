# 第3课：自动评估——在 Knowledge Workspace 里集成评估流水线

> **课程定位**：项目推进课——把评估从手动脚本变成持续运行的流水线
> **前置知识**：第1课的评估脚本、第2课的评估集设计
> **预计时长**：40 分钟

上节课你写了一个 `run-eval.ts`，能跑评估用例。但那个脚本有几个问题：用例和逻辑耦合在一起、结果跑完就没了、能不能上线全靠人记得跑。这节课要把它变成项目基础设施的一部分。

---

## 项目结构

在 `ai-knowledge-workspace-kit` 里建一个 `evals/` 目录：

```
evals/
├── cases.json          # 评估用例（非工程师也能编辑）
├── run-eval.ts         # 评估入口
├── rules.ts            # 规则评估器
├── model-eval.ts       # 模型评估器
├── compare.ts          # 版本对比
└── results/            # 评估结果（git ignored）
```

用例文件让每条用例声明自己要用哪些评估器，规则和模型可以在同一条用例上共存：

```json
[
  {
    "id": "basic-fact",
    "question": "这个项目的向量数据库用的是什么？",
    "evaluators": {
      "keywords": { "expected": ["pgvector", "PostgreSQL"], "threshold": 0.5 },
      "model": { "dimensions": ["faithfulness", "relevancy"] }
    }
  },
  {
    "id": "refusal",
    "question": "这个项目的创始人是谁？",
    "evaluators": {
      "rule": { "expectedBehavior": "refuse" }
    }
  }
]
```

## 分层评估器

先跑规则，规则通过了再跑模型。规则评估免费、确定，过滤明显硬伤；模型评估有成本，只用在规则通过的用例上。

```typescript
// evals/rules.ts
export function runRules(
  evaluators: Record<string, any>,
  response: { answer: string; citations: string[] }
): { passed: boolean; rule: string; details: string }[] {
  const results = []

  if (evaluators.keywords) {
    const { expected, threshold } = evaluators.keywords
    const hits = expected.filter((kw: string) =>
      response.answer.toLowerCase().includes(kw.toLowerCase())
    )
    results.push({
      passed: hits.length / expected.length >= threshold,
      rule: 'keyword-match',
      details: `命中 ${hits.length}/${expected.length}`,
    })
  }

  if (evaluators.rule?.expectedBehavior === 'refuse') {
    const refused = /无法(找到|回答|确定)|资料中(没有|未找到)|抱歉/.test(response.answer)
    results.push({ passed: refused, rule: 'refusal-check', details: refused ? '正确拒答' : '应该拒答但没有' })
  }

  const len = response.answer.length
  results.push({ passed: len >= 20 && len <= 2000, rule: 'length-check', details: `长度 ${len}` })

  return results
}
```

```typescript
// evals/model-eval.ts
import OpenAI from 'openai'

const openai = new OpenAI()

export async function runModelEval(question: string, context: string, answer: string) {
  const response = await openai.responses.create({
    model: 'gpt-4o-mini',
    temperature: 0,
    input: [
      {
        role: 'system',
        content: `评估 AI 回答质量。评分标准：
- faithfulness (0-1)：回答是否基于上下文，没有编造
- relevancy (0-1)：回答是否与问题相关
输出 JSON: {"faithfulness": 0-1, "relevancy": 0-1, "reasoning": "理由"}`,
      },
      { role: 'user', content: `问题：${question}\n\n上下文：${context}\n\n回答：${answer}` },
    ],
    text: { format: { type: 'json_object' } },
  })
  return JSON.parse(response.output_text)
}
```

## 评估流水线

把评估器、业务调用、结果持久化串起来：

```typescript
// evals/run-eval.ts
import { readFile, writeFile, mkdir } from 'fs/promises'
import { runRules } from './rules'
import { runModelEval } from './model-eval'
import { searchKnowledgeBase } from '../src/retrieval'
import { generateAnswer } from '../src/generation'

async function evaluateCase(case_: any) {
  const searchResults = await searchKnowledgeBase({ query: case_.question, limit: 5, minScore: 0.7 })
  const answer = await generateAnswer({ question: case_.question, context: searchResults })
  const response = { answer: answer.text, citations: answer.citations ?? [] }

  const ruleResults = runRules(case_.evaluators, response)
  if (!ruleResults.every(r => r.passed)) {
    return { id: case_.id, passed: false, ruleResults }
  }

  if (case_.evaluators.model) {
    const contextText = searchResults.map((r: any) => r.content).join('\n\n')
    const scores = await runModelEval(case_.question, contextText, response.answer)
    const passed = scores.faithfulness >= 0.7 && scores.relevancy >= 0.7
    return { id: case_.id, passed, ruleResults, modelScores: scores }
  }

  return { id: case_.id, passed: true, ruleResults }
}

async function main() {
  const cases = JSON.parse(await readFile('evals/cases.json', 'utf-8'))
  console.log(`运行 ${cases.length} 条评估...\n`)

  const results = []
  for (const c of cases) {
    const r = await evaluateCase(c)
    results.push(r)
    const icon = r.passed ? '✅' : '❌'
    const model = r.modelScores ? ` [faith=${r.modelScores.faithfulness} rel=${r.modelScores.relevancy}]` : ''
    console.log(`${icon} ${r.id}${model}`)
  }

  const report = {
    timestamp: new Date().toISOString(),
    totalCases: cases.length,
    passed: results.filter(r => r.passed).length,
    results,
  }

  await mkdir('evals/results', { recursive: true })
  const filename = `evals/results/${report.timestamp.replace(/[:.]/g, '-')}.json`
  await writeFile(filename, JSON.stringify(report, null, 2))
  console.log(`\n通过 ${report.passed}/${report.totalCases}，结果已保存到 ${filename}`)
}

main()
```

运行 `npx tsx evals/run-eval.ts`。每次运行都在 `evals/results/` 下生成带时间戳的 JSON 报告，可以跨版本对比。

## 版本对比

```typescript
// evals/compare.ts
import { readdir, readFile } from 'fs/promises'

async function main() {
  const files = (await readdir('evals/results')).filter(f => f.endsWith('.json')).sort().slice(-2)
  if (files.length < 2) { console.log('需要至少两次评估结果'); return }

  const [prev, curr] = await Promise.all(
    files.map(f => readFile(`evals/results/${f}`, 'utf-8').then(JSON.parse))
  )

  console.log(`通过率: ${prev.passed}/${prev.totalCases} → ${curr.passed}/${curr.totalCases}`)
  for (const c of curr.results) {
    const p = prev.results.find((r: any) => r.id === c.id)
    if (p && p.passed !== c.passed) {
      console.log(`  ${c.passed ? '🟢 改善' : '🔴 退步'}: ${c.id}`)
    }
  }
}

main()
```

## 接入开发流程

在 `package.json` 里加三个命令：

```json
{
  "scripts": {
    "eval": "npx tsx evals/run-eval.ts",
    "eval:quick": "npx tsx evals/run-eval.ts --skip-model",
    "eval:compare": "npx tsx evals/compare.ts"
  }
}
```

`eval:quick` 只跑规则评估，不调 API，几秒钟完成。加一个 pre-commit hook 让它自动运行：

```bash
#!/bin/bash
# .git/hooks/pre-commit
npm run eval:quick || { echo "评估失败，禁止提交"; exit 1; }
```

模型评估有成本和延迟，放在 CI 里，PR 合并前跑。这个分层策略和评估器本身一致：快速检查随开发跑，深度检查在关键节点跑。

## 参考答案

### 练习一

在 `runRules` 函数末尾追加：

```typescript
const promptPatterns = [/system prompt/i, /系统指令/, /你是一个.*助手/]
const leaks = promptPatterns.some(p => p.test(response.answer))
results.push({ passed: !leaks, rule: 'prompt-leak-check', details: leaks ? '疑似泄露系统指令' : '未泄露' })
```

注意覆盖中英文两种模式，实际项目中 prompt 可能是中文的。

### 练习二

```typescript
// evals/trend.ts
import { readdir, readFile } from 'fs/promises'

async function main() {
  const files = (await readdir('evals/results')).filter(f => f.endsWith('.json')).sort().slice(-10)
  const reports = await Promise.all(files.map(f => readFile(`evals/results/${f}`, 'utf-8').then(JSON.parse)))
  console.log('评估通过率趋势:\n')
  for (const r of reports) {
    const rate = Math.round((r.passed / r.totalCases) * 10)
    console.log(`${r.timestamp.slice(0, 10)}  ${'█'.repeat(rate)}${'░'.repeat(10 - rate)}  ${r.passed}/${r.totalCases}`)
  }
}
main()
```
