# 02 多轮对话架构

> 对话不是单条消息的堆砌——是有状态的、持续的、有成本的交互。

## 场景引入

用户和 AI 聊了 20 轮，突然发现 AI "忘了"前面说过的内容。查看账单，发现一次对话花了 2 美元——因为每轮都把全部历史传给了模型。用户刷新页面后，对话记录又丢了。这三个问题——"健忘"、成本飙升、状态丢失——是多轮对话系统必须解决的核心挑战。你需要一套上下文管理策略，在有限的 token 窗口内平衡记忆质量和成本。

## 学习目标

- 设计多轮对话的消息模型和上下文管理策略
- 实现上下文窗口管理和历史压缩
- 理解不同对话场景的上下文策略差异
- 掌握对话状态的持久化和恢复

## 前置要求

- 已完成阶段 1 对话骨架
- 理解 token 和上下文窗口概念

## 对话的核心挑战

多轮对话面临三个核心问题：

1. **上下文窗口有限**：模型能处理的 token 数量有上限
2. **成本线性增长**：每轮对话都要传入所有历史，token 费用越来越高
3. **状态一致性**：用户可能刷新页面、切换设备、中断后回来

## 上下文窗口管理

不同模型的上下文窗口不同：

| 模型 | 上下文窗口 | 约等于 |
|------|-----------|--------|
| GPT-4o | 128K tokens | ~10 万字 |
| GPT-4o-mini | 128K tokens | ~10 万字 |
| Claude Sonnet | 200K tokens | ~15 万字 |
| Claude Haiku | 200K tokens | ~15 万字 |

即使窗口很大，也不应该把所有历史都塞进去——成本太高，而且模型对长上下文中间部分的注意力会下降。

### 策略 1：滑动窗口

只保留最近 N 条消息：

```python
class SlidingWindowStrategy:
    """滑动窗口策略：只保留最近 N 条消息"""
    
    def __init__(self, max_messages: int = 20):
        self.max_messages = max_messages
    
    def build_context(
        self,
        system_prompt: str,
        history: list[dict],
        current_message: str,
    ) -> list[dict]:
        messages = [{"role": "system", "content": system_prompt}]
        
        # 只取最近 N 条
        recent = history[-self.max_messages:]
        messages.extend(recent)
        
        # 加上当前消息
        messages.append({"role": "user", "content": current_message})
        
        return messages
```

### 策略 2：Token 预算

根据 token 数量裁剪历史：

```python
class TokenBudgetStrategy:
    """Token 预算策略：在 token 预算内尽可能多保留历史"""
    
    def __init__(self, max_input_tokens: int = 8000):
        self.max_input_tokens = max_input_tokens
    
    def build_context(
        self,
        system_prompt: str,
        history: list[dict],
        current_message: str,
    ) -> list[dict]:
        messages = [{"role": "system", "content": system_prompt}]
        
        # 计算固定部分的 token
        system_tokens = count_tokens(system_prompt)
        current_tokens = count_tokens(current_message)
        reserved = system_tokens + current_tokens + 500  # 500 留给输出
        
        # 从最新的消息开始，逐条添加直到超出预算
        budget = self.max_input_tokens - reserved
        used_tokens = 0
        
        for msg in reversed(history):
            msg_tokens = count_tokens(msg["content"])
            if used_tokens + msg_tokens > budget:
                break
            messages.insert(-1, msg)  # 插入到当前消息之前
            used_tokens += msg_tokens
        
        messages.append({"role": "user", "content": current_message})
        return messages
```

### 策略 3：摘要压缩

把旧消息压缩成摘要：

```python
class SummaryCompressionStrategy:
    """摘要压缩策略：旧消息压缩成摘要，新消息保留原文"""
    
    def __init__(
        self,
        summary_threshold: int = 30,    # 超过 30 条消息触发压缩
        keep_recent: int = 10,           # 保留最近 10 条原文
    ):
        self.summary_threshold = summary_threshold
        self.keep_recent = keep_recent
    
    async def build_context(
        self,
        system_prompt: str,
        history: list[dict],
        current_message: str,
        llm_service: LLMService,
    ) -> list[dict]:
        messages = [{"role": "system", "content": system_prompt}]
        
        if len(history) <= self.summary_threshold:
            # 不需要压缩
            messages.extend(history)
        else:
            # 需要压缩
            old_messages = history[:-self.keep_recent]
            recent_messages = history[-self.keep_recent:]
            
            # 用 LLM 压缩旧消息
            summary = await self._summarize(old_messages, llm_service)
            messages.append({
                "role": "system",
                "content": f"[之前的对话摘要]\n{summary}",
            })
            messages.extend(recent_messages)
        
        messages.append({"role": "user", "content": current_message})
        return messages
    
    async def _summarize(
        self, messages: list[dict], llm_service: LLMService
    ) -> str:
        """用 LLM 压缩消息历史"""
        conversation = "\n".join(
            f"{m['role']}: {m['content']}" for m in messages
        )
        
        response = await llm_service.chat(
            messages=[{
                "role": "user",
                "content": f"请将以下对话压缩成简洁的摘要，保留关键信息和决策：\n\n{conversation}",
            }],
            model="gpt-4o-mini",  # 压缩用便宜模型
            temperature=0.3,
        )
        
        return response.content
```

## 对话服务实现

```python
# backend/app/services/chat_service.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, func
from app.models.session import ChatSession
from app.models.message import Message
from app.services.llm_service import LLMService
from app.services.cache_service import SessionCache

class ChatService:
    def __init__(
        self,
        db: AsyncSession,
        cache: SessionCache,
        llm: LLMService,
        user_id: str,
    ):
        self.db = db
        self.cache = cache
        self.llm = llm
        self.user_id = user_id
        
        # 上下文策略
        self.context_strategy = TokenBudgetStrategy(max_input_tokens=8000)
    
    async def send_message(self, session_id: str, content: str) -> dict:
        # 1. 验证会话属于当前用户
        session = await self._get_session(session_id)
        
        # 2. 保存用户消息
        user_msg = await self._save_message(session_id, "user", content)
        
        # 3. 构建上下文
        system_prompt = session.agent.system_prompt if session.agent else "你是一个有帮助的 AI 助手。"
        history = await self._get_history(session_id)
        
        context = self.context_strategy.build_context(
            system_prompt=system_prompt,
            history=[{"role": m.role, "content": m.content} for m in history],
            current_message=content,
        )
        
        # 4. 调用 LLM
        response = await self.llm.chat(
            messages=context,
            model=session.agent.model if session.agent else "gpt-4o",
        )
        
        # 5. 保存 AI 回复
        ai_msg = await self._save_message(
            session_id, "assistant", response.content,
            model=response.model,
            input_tokens=response.input_tokens,
            output_tokens=response.output_tokens,
            cost=response.cost,
            latency_ms=int(response.latency * 1000),
        )
        
        # 6. 更新缓存
        await self.cache.add_message(session_id, user_msg)
        await self.cache.add_message(session_id, ai_msg)
        
        return {
            "user_message": user_msg,
            "ai_message": ai_msg,
            "usage": {
                "input_tokens": response.input_tokens,
                "output_tokens": response.output_tokens,
                "cost": response.cost,
                "latency_ms": int(response.latency * 1000),
            },
        }
    
    async def _get_history(self, session_id: str) -> list[Message]:
        """获取对话历史（优先缓存）"""
        # 先从缓存取
        cached = await self.cache.get_messages(session_id)
        if cached:
            return cached
        
        # 缓存没有，从数据库取
        result = await self.db.execute(
            select(Message)
            .where(Message.session_id == session_id, Message.is_summary == False)
            .order_by(Message.created_at)
        )
        messages = result.scalars().all()
        
        # 回填缓存
        for msg in messages:
            await self.cache.add_message(session_id, msg)
        
        return messages
```

## 会话标题自动生成

用户创建会话时只发了一条消息，标题是"新对话"。可以用 LLM 自动生成有意义的标题。

```python
async def auto_generate_title(self, session_id: str, first_message: str):
    """自动为新会话生成标题"""
    response = await self.llm.chat(
        messages=[{
            "role": "user",
            "content": f"请为以下对话生成一个简短的标题（不超过 20 个字）：\n\n用户：{first_message}",
        }],
        model="gpt-4o-mini",
        temperature=0.3,
        max_tokens=50,
    )
    
    title = response.content.strip().strip('"').strip("'")
    
    # 更新会话标题
    session = await self._get_session(session_id)
    session.title = title[:20]
    await self.db.flush()
```

### 练习 1

**思路**：实现三种上下文策略类，分别用不同的裁剪逻辑构建 context，然后在同一对话数据上对比 token 用量。

import tiktoken

def count_tokens(text: str, model: str = "gpt-4o") -> int:
    encoding = tiktoken.encoding_for_model(model)
    return len(encoding.encode(text))

system_prompt = "你是一个有帮助的 AI 助手。"

for i in range(50):

**要点**：
- 滑动窗口简单但不精确——短消息可能浪费 token 预算，长消息可能超出预算

### 练习 2

**思路**：在 ChatService 中集成自动标题生成、会话列表排序、软删除归档、按标题/内容搜索功能。

**答案**：

```python
# backend/app/services/chat_service.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, func, or_
from datetime import datetime
from app.models.session import ChatSession
from app.models.message import Message
from app.services.llm_service import LLMService

class SessionManager:
    def __init__(self, db: AsyncSession, llm: LLMService):
        self.db = db
        self.llm = llm

    async def create_session(self, user_id: str, first_message: str) -> ChatSession:
        session = ChatSession(
            user_id=user_id,
            title="新对话",
        )
        self.db.add(session)
        await self.db.flush()
        # 异步生成标题（不阻塞响应）
        await self._generate_title(session, first_message)
        return session

    async def _generate_title(self, session: ChatSession, first_message: str):
        try:
            response = await self.llm.chat(
                messages=[{"role": "user", "content": f"为以下消息生成简短标题（不超过20字）：{first_message}"}],
                model="gpt-4o-mini",
                temperature=0.3,
                max_tokens=50,
            )
            title = response.content.strip().strip('"').strip("'")[:20]
            session.title = title
            await self.db.flush()
        except Exception:
            pass  # 标题生成失败不影响会话创建

    async def list_sessions(
        self, user_id: str, page: int = 1, size: int = 20
    ) -> tuple[list[ChatSession], int]:
        count_result = await self.db.execute(
            select(func.count()).where(
                ChatSession.user_id == user_id,
                ChatSession.is_deleted == False,
            )
        )
        total = count_result.scalar()

        offset = (page - 1) * size
        result = await self.db.execute(
            select(ChatSession)
            .where(ChatSession.user_id == user_id, ChatSession.is_deleted == False)
            .order_by(ChatSession.updated_at.desc())
            .offset(offset)
            .limit(size)
        )
        return list(result.scalars().all()), total

    async def archive_session(self, session_id: str) -> bool:
        result = await self.db.execute(
            select(ChatSession).where(ChatSession.id == session_id)
        )
        session = result.scalar_one_or_none()
        if not session:
            return False
        session.is_deleted = True
        session.deleted_at = datetime.now()
        await self.db.flush()
        return True

    async def search_sessions(
        self, user_id: str, keyword: str
    ) -> list[ChatSession]:
        result = await self.db.execute(
            select(ChatSession)
            .where(
                ChatSession.user_id == user_id,
                ChatSession.is_deleted == False,
                or_(
                    ChatSession.title.ilike(f"%{keyword}%"),
                    ChatSession.id.in_(
                        select(Message.session_id).where(
                            Message.content.ilike(f"%{keyword}%")
                        )
                    ),
                ),
            )
            .order_by(ChatSession.updated_at.desc())
        )
        return list(result.scalars().all())
```

**要点**：
- 标题生成用便宜模型（gpt-4o-mini）且设低 `max_tokens`，成本可忽略
- 软删除（`is_deleted` 标记）比硬删除更安全，用户误删后可以恢复
- 常见错误：搜索用 `=` 精确匹配，应该用 `ILIKE` 模糊匹配；搜索消息内容时要走子查询，不要把所有消息加载到内存

### 练习 3

**思路**：在 Message 模型中记录每条消息的 token 和成本，在 ChatService 中用 SQL 聚合查询实现会话级和用户级统计。

**答案**：

```python
# backend/app/services/token_stats.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, func, extract
from app.models.message import Message
from app.models.session import ChatSession
from dataclasses import dataclass

@dataclass
class TokenStats:
    total_input_tokens: int
    total_output_tokens: int
    total_cost: float
    message_count: int

@dataclass
class MonthlyStats:
    month: str
    total_input_tokens: int
    total_output_tokens: int
    total_cost: float
    session_count: int
    message_count: int

class TokenStatsService:
    def __init__(self, db: AsyncSession):
        self.db = db

    async def get_session_stats(self, session_id: str) -> TokenStats:
        result = await self.db.execute(
            select(
                func.coalesce(func.sum(Message.input_tokens), 0),
                func.coalesce(func.sum(Message.output_tokens), 0),
                func.coalesce(func.sum(Message.cost), 0.0),
                func.count(Message.id),
            ).where(Message.session_id == session_id)
        )
        row = result.one()
        return TokenStats(
            total_input_tokens=row[0],
            total_output_tokens=row[1],
            total_cost=float(row[2]),
            message_count=row[3],
        )

    async def get_user_monthly_stats(
        self, user_id: str, year: int, month: int
    ) -> MonthlyStats:
        result = await self.db.execute(
            select(
                func.coalesce(func.sum(Message.input_tokens), 0),
                func.coalesce(func.sum(Message.output_tokens), 0),
                func.coalesce(func.sum(Message.cost), 0.0),
                func.count(func.distinct(ChatSession.id)),
                func.count(Message.id),
            )
            .join(ChatSession, Message.session_id == ChatSession.id)
            .where(
                ChatSession.user_id == user_id,
                extract("year", Message.created_at) == year,
                extract("month", Message.created_at) == month,
            )
        )
        row = result.one()
        return MonthlyStats(
            month=f"{year}-{month:02d}",
            total_input_tokens=row[0],
            total_output_tokens=row[1],
            total_cost=float(row[2]),
            session_count=row[3],
            message_count=row[4],
        )
```

```python
# 在消息保存时记录 token 信息
async def save_message(
    db: AsyncSession,
    session_id: str,
    role: str,
    content: str,
    input_tokens: int = 0,
    output_tokens: int = 0,
    cost: float = 0.0,

    msg = Message(

        role=role,

    await db.flush()

```

**要点**：
- `func.coalesce(..., 0)` 处理空表求和返回 NULL 的问题
- 用户级统计需要 JOIN ChatSession 表来关联用户，不能直接从 Message 表查
- 常见错误：用 Python 循环累加 token，数据量大时极慢；应该用 SQL 聚合函数在数据库层面计算

## 本节要点

- 上下文管理是多轮对话的核心，直接影响成本和质量
- 滑动窗口最简单，Token 预算更精确，摘要压缩最智能
- 对话历史要持久化到数据库，缓存只是加速层
- 自动标题生成是提升用户体验的小技巧

## 常见误区

| 错误 | 原因 | 解决 |
|------|------|------|
| 对话越来越"健忘" | 历史被截断太多 | 调整上下文策略参数 |
| 成本飙升 | 每次都传入全部历史 | 实现 token 预算控制 |
| 会话刷新后丢失消息 | 只存了缓存没存数据库 | 确保消息同时写入数据库 |
| 摘要压缩太慢 | 压缩本身也调用了 LLM | 用便宜快速的模型做压缩 |

## 工程建议

- 上下文策略要根据业务场景选择：客服场景用滑动窗口足够，知识问答场景需要 Token 预算策略
- Token 预算要留足余量，建议输入 token 上限设为模型窗口的 60-70%，剩余留给输出和系统开销
- 对话标题自动生成用便宜模型（gpt-4o-mini）即可，不需要强模型
- 摘要压缩是异步操作，不要阻塞用户的消息发送——可以后台触发压缩，下次对话时生效
- 对话历史必须持久化到数据库，Redis 缓存只是加速层，不能作为唯一存储
