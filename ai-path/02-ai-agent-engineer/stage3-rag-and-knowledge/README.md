# 阶段 3：知识库与 RAG——让应用有记忆

## 阶段目标

构建企业级 RAG 知识库系统，支持多种文档格式解析、向量检索、引用溯源和质量优化。让 AI 不再"胡说八道"，而是基于真实资料回答。

## 实战任务

构建 **企业知识库问答系统**：

- 支持上传 PDF / Word / Markdown / 网页链接
- 文档自动解析、切分、向量化、索引
- 对话式问答，回答带引用标注
- 检索质量优化：query rewrite、rerank、混合检索
- 知识库管理界面：文档列表、索引状态、删除重建
- 检索质量评估：召回率、准确率、引用正确率

## 验收标准

- [ ] 上传文档后自动完成解析、切分、向量化全流程
- [ ] 问答回答有引用标注，点击引用可跳转原文位置
- [ ] 混合检索（向量 + 关键词）比纯向量检索召回率提升 > 15%
- [ ] 幻觉检测能在回答中标注置信度，低置信度内容自动警告
- [ ] 支持知识库 CRUD：上传、删除、重新索引、查看状态
- [ ] 检索延迟 < 500ms（10 万级文档）

## 技术栈

| 组件 | 技术 |
|------|------|
| 向量数据库 | PostgreSQL + pgvector |
| Embedding | OpenAI text-embedding-3-small / BGE |
| 文档解析 | Unstructured / PyMuPDF / BeautifulSoup |
| 文本切分 | LangChain TextSplitter / 自研 |
| 重排序 | Cohere Rerank / BGE Reranker |
| 前端 | Vue 3 + PDF 预览组件 |
