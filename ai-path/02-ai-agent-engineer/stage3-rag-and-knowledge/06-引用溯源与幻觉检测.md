# 06 引用溯源与幻觉检测

> 回答必须能回到原文——这是 RAG 和"瞎编"的根本区别。

## 场景引入

RAG 系统回答用户"产品支持哪些支付方式"时，自信地列出了微信支付、支付宝和银联，但检索到的文档只提到了微信支付和支付宝。用户按照回答尝试银联支付失败后投诉了系统。回答没有引用来源、无法验证真伪，是 RAG 系统最大的信任隐患。

## 引用溯源设计

### Prompt 中要求引用

```python
CITATION_PROMPT = """你是一个知识库问答助手。请基于以下参考资料回答用户问题。

# 回答规则
1. 必须基于参考资料回答，不要编造信息
2. 在回答中用 [1]、[2] 等标记引用来源
3. 如果参考资料不足以回答问题，明确说"根据现有资料无法回答"
4. 引用格式：在相关句子后标注 [来源编号]

# 参考资料
{contexts}

# 用户问题
{question}

# 回答（请标注引用来源）"""

def format_contexts(chunks: list[dict]) -> str:
    """格式化检索结果为引用上下文"""
    contexts = []
    for i, chunk in enumerate(chunks, 1):
        source = chunk["metadata"].get("source", "未知来源")
        page = chunk["metadata"].get("page", "")
        page_info = f" (第{page}页)" if page else ""
        contexts.append(f"[{i}] 来源：{source}{page_info}\n{chunk['content']}")
    return "\n\n".join(contexts)
```

### 解析引用

```python
import re

def extract_citations(answer: str) -> list[dict]:
    """从回答中提取引用"""
    # 匹配 [1]、[2] 等引用标记
    pattern = r'\[(\d+)\]'
    matches = re.findall(pattern, answer)
    
    citations = []
    for match in set(matches):
        idx = int(match)
        # 找到引用在回答中的位置
        positions = [
            m.start() for m in re.finditer(f'\\[{idx}\\]', answer)
        ]
        citations.append({
            "index": idx,
            "positions": positions,
            "count": len(positions),
        })
    
    return sorted(citations, key=lambda c: c["index"])
```

## 幻觉检测

### 幻觉类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 事实性幻觉 | 编造不存在的信息 | "公司成立于 2020 年"（实际是 2018 年） |
| 忠实度幻觉 | 回答和检索内容不一致 | 检索说"价格 99 元"，回答说"199 元" |
| 推理幻觉 | 推理过程有误 | 错误的因果关系 |

### 基于 LLM 的幻觉检测

```python
class HallucinationDetector:
    """幻觉检测器"""
    
    def __init__(self, llm: LLMService):
        self.llm = llm
    
    async def check(
        self,
        question: str,
        answer: str,
        contexts: list[str],
    ) -> dict:
        """检测回答是否存在幻觉"""
        
        contexts_text = "\n\n".join(f"[{i+1}] {c}" for i, c in enumerate(contexts))
        
        prompt = f"""请判断以下回答是否存在幻觉（与参考资料不一致的信息）。

# 参考资料
{contexts_text}

# 问题
{question}

# 回答
{answer}

请按以下 JSON 格式输出：
{{
    "has_hallucination": true/false,
    "hallucination_score": 0.0-1.0,
    "hallucinated_claims": [
        {{
            "claim": "幻觉内容",
            "reason": "为什么是幻觉",
            "severity": "high/medium/low"
        }}
    ],
    "supported_claims": [
        {{
            "claim": "有依据的内容",
            "source_index": 1
        }}
    ]
}}"""
        
        result = await self.llm.chat(
            messages=[{"role": "user", "content": prompt}],
            model="gpt-4o-mini",
            temperature=0,
            response_format={"type": "json_object"},
        )
        
        import json
        return json.loads(result.content)
```

### 置信度评估

```python
class ConfidenceEvaluator:
    """置信度评估"""
    
    async def evaluate(
        self,
        question: str,
        answer: str,
        contexts: list[dict],
    ) -> dict:
        """综合评估回答置信度"""
        
        # 1. 检索质量分
        retrieval_score = sum(c.get("score", 0) for c in contexts) / max(len(contexts), 1)
        
        # 2. 引用覆盖度
        citations = extract_citations(answer)
        citation_coverage = len(citations) / max(len(contexts), 1)
        
        # 3. 幻觉检测
        hallucination = await self.detector.check(
            question, answer, [c["content"] for c in contexts]
        )
        
        # 4. 综合置信度
        confidence = (
            retrieval_score * 0.3 +
            citation_coverage * 0.3 +
            (1 - hallucination["hallucination_score"]) * 0.4
        )
        
        return {
            "confidence": round(confidence, 2),
            "retrieval_score": round(retrieval_score, 2),
            "citation_coverage": round(citation_coverage, 2),
            "hallucination_score": hallucination["hallucination_score"],
            "has_hallucination": hallucination["has_hallucination"],
            "level": self._get_level(confidence),
        }
    
    def _get_level(self, confidence: float) -> str:
        if confidence >= 0.8:
            return "high"
        elif confidence >= 0.5:
            return "medium"
        else:
            return "low"
```

## 参考答案

### 练习 1

**思路**：实现完整的引用 Pipeline：Prompt 规定引用格式 → LLM 生成带引用的回答 → 正则提取引用标记 → 前端渲染可点击引用。

**答案**：

```python
import re

CITATION_PROMPT = """你是一个知识库问答助手。请基于以下参考资料回答用户问题。

# 回答规则
1. 必须基于参考资料回答，不要编造信息
2. 在回答中用 [1]、[2] 等标记引用来源
3. 如果参考资料不足以回答问题，明确说"根据现有资料无法回答"

# 参考资料
{contexts}

# 用户问题
{question}

# 回答（请标注引用来源）"""


def format_contexts(chunks: list[dict]) -> str:
    contexts = []
    for i, chunk in enumerate(chunks, 1):
        source = chunk["metadata"].get("source", "未知来源")
        page = chunk["metadata"].get("page", "")
        page_info = f" (第{page}页)" if page else ""
        contexts.append(f"[{i}] 来源：{source}{page_info}\n{chunk['content']}")
    return "\n\n".join(contexts)


def extract_citations(answer: str) -> list[dict]:
    pattern = r'\[(\d+)\]'
    matches = re.findall(pattern, answer)
    citations = []
    for match in set(matches):
        idx = int(match)
        positions = [m.start() for m in re.finditer(f'\\[{idx}\\]', answer)]
        citations.append({"index": idx, "positions": positions, "count": len(positions)})
    return sorted(citations, key=lambda c: c["index"])


async def answer_with_citation(question: str, chunks: list[dict], llm) -> dict:
    contexts_text = format_contexts(chunks)
    prompt = CITATION_PROMPT.format(contexts=contexts_text, question=question)

    response = await llm.chat(messages=[{"role": "user", "content": prompt}], model="gpt-4o")
    answer = response.content
    citations = extract_citations(answer)

    # 验证引用是否有效
    valid_citations = []
    for cite in citations:
        if cite["index"] <= len(chunks):
            valid_citations.append({
                **cite,
                "source": chunks[cite["index"] - 1]["metadata"].get("source", ""),
                "page": chunks[cite["index"] - 1]["metadata"].get("page"),
            })

    return {"answer": answer, "citations": valid_citations}
```

**要点**：
- Prompt 中必须严格规定引用格式 `[N]`，否则 LLM 可能用脚注、括号等不一致的格式
- 正则提取后要验证引用编号是否在有效范围内，避免 LLM 编造不存在的来源编号
- 前端渲染时将 `[1]` 替换为可点击的 `<sup>` 标签，点击跳转到对应来源
- 常见错误：只提取引用标记不验证有效性，导致点击后找不到对应来源

- 低置信度时必须主动提示用户，这是 RAG 系统的信任底线
- 常见错误：置信度虚高——检索到了内容但不相关，引用覆盖高但引用的都是无关内容；需要结合重排序过滤低质量结果

## 工程建议

- 引用标记要在 Prompt 中严格规定格式（如 `[1]`），并用正则提取，不要依赖 LLM 自由发挥
- 幻觉检测建议异步执行，不要阻塞回答返回——先给用户回答，后台检测完成后更新置信度标签
- 低置信度回答要主动提示用户"建议查看更多来源或转人工"，这是 RAG 系统的信任底线
- 引用溯源的元数据（来源文件、页码、段落）要在切分阶段就记录好，不要在生成阶段反查

## 本节要点

- 引用溯源是 RAG 的核心价值——让用户能验证回答
- 幻觉检测是 RAG 质量的最后一道防线
- 置信度评估帮助用户判断回答的可靠性
- 低置信度时应该建议用户转人工或查看更多资料

## 常见误区

| 错误 | 原因 | 解决 |
|------|------|------|
| 引用标记不一致 | LLM 输出了非标准格式 | 用正则表达式标准化 |
| 幻觉检测太慢 | 每次都调用 LLM | 缓存检测结果 |
| 置信度虚高 | 检索到了但不相关 | 用重排序过滤低质量结果 |
| 引用和原文对不上 | chunk 切断了上下文 | 存储 chunk 时保留位置信息 |
