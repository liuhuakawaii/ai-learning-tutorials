# 01 多模态架构设计——统一输入层 / 模态路由 / 融合推理

> 多模态应用需要一个统一的架构来处理不同类型的输入。

## 场景引入

你要设计一个支持文本、图片、语音、文档四种输入的全能 AI 助手架构。每种输入的处理方式完全不同：文本直接送 LLM，图片需要 Vision API，语音要先 ASR 再送 LLM，文档要先解析再提取。如果为每种输入写一套独立的逻辑，代码会变成一团乱麻；如果设计一个统一架构，又要考虑扩展性——未来可能还要支持视频、3D 模型等新模态。多模态架构设计的核心挑战是在统一性和灵活性之间找到平衡。

## 学习目标

- 掌握多模态应用的架构设计
- 理解模态路由和融合推理
- 学会设计可扩展的多模态系统

## 一、架构设计

```
多模态架构：

输入层 → 模态识别 → 模态路由 → 模态处理 → 融合推理 → 输出
  │          │          │          │          │        │
  ▼          ▼          ▼          ▼          ▼        ▼
文本/图片   识别类型   路由到处理器 处理输入  融合结果  生成回答
```

## 二、模态识别

```python
def identify_modality(input_data) -> str:
    """识别输入模态"""
    if isinstance(input_data, str):
        if input_data.startswith("http"):
            return "image_url"
        else:
            return "text"
    elif isinstance(input_data, bytes):
        return "audio"
    elif hasattr(input_data, "read"):
        return "file"
    else:
        return "unknown"
```

## 三、模态路由

```python
class ModalityRouter:
    """模态路由器"""
    
    def __init__(self):
        self.handlers = {
            "text": TextHandler(),
            "image": ImageHandler(),
            "audio": AudioHandler(),
            "document": DocumentHandler()
        }
    
    def route(self, modality: str, input_data):
        """路由到处理器"""
        handler = self.handlers.get(modality)
        if not handler:
            raise ValueError(f"不支持的模态：{modality}")
        return handler.process(input_data)
```

## 四、融合推理

```python
class FusionReasoner:
    """融合推理器"""
    
    def __init__(self):
        self.client = OpenAI()
    
    def fuse(self, modality_results: dict) -> str:
        """融合多模态结果"""
        # 组装上下文
        context = []
        for modality, result in modality_results.items():
            context.append(f"[{modality}]: {result}")
        
        # 生成融合回答
        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[{
                "role": "user",
                "content": f"请融合以下多模态信息，生成综合回答：\n\n{''.join(context)}"
            }]
        )
        
        return response.choices[0].message.content
```

## 五、统一接口

```python
class MultimodalSystem:
    """多模态系统"""
    
    def __init__(self):
        self.router = ModalityRouter()
        self.fusion = FusionReasoner()
    
    def process(self, inputs: dict) -> str:
        """处理多模态输入"""
        results = {}
        
        for key, value in inputs.items():
            modality = identify_modality(value)
            result = self.router.route(modality, value)
            results[key] = result
        
        return self.fusion.fuse(results)
```

## 六、可扩展性

```
可扩展性设计：

1. 插件化处理器
   - 新模态只需添加处理器
   - 无需修改核心代码

2. 配置化路由
   - 通过配置文件定义路由规则
   - 支持动态调整

3. 模块化融合
   - 融合策略可插拔
   - 支持多种融合方法
```

## 常见误区

1. **用 if-else 硬编码所有模态逻辑**：每种模态的处理逻辑用 if-else 写死，新增模态需要改动核心代码，维护成本高且容易出错。
2. **忽略模态识别的准确性**：输入类型判断错误会导致后续处理全部出错，必须做严格的类型检测和错误处理。
3. **融合推理只是简单拼接**：把多模态结果简单拼接给 LLM，不做优先级排序和冲突处理，会导致生成质量下降。
4. **不做性能监控**：多模态系统的链路长、延迟高，不做端到端的性能监控无法定位瓶颈。

## 工程建议

1. **用策略模式设计模态处理器**：每种模态是一个独立的策略类，通过注册机制添加新模态，核心代码不需要修改。
2. **模态识别用多层检测**：先检测文件扩展名，再检测文件内容（magic bytes），最后用大小和格式做辅助判断。
3. **融合推理做加权融合**：不同模态的结果按置信度加权，冲突时优先保留高置信度的结果。
4. **每层都要有性能埋点**：输入识别、模态处理、融合推理、结果生成每层都记录延迟和成功率，方便定位瓶颈。

## 参考答案

### 练习一：架构题——设计一个多模态架构

**思路**：采用分层架构设计，输入层负责接收各种模态输入，模态识别层自动判断类型，路由层分发到对应的处理器，融合层综合多模态结果生成最终输出。关键是要支持插件化扩展新模态。

**答案**：
```python
from abc import ABC, abstractmethod
from typing import Any, Dict, Optional
import mimetypes
import os

class ModalityHandler(ABC):
    """模态处理器基类"""

    @abstractmethod
    def can_handle(self, input_data: Any) -> bool:
        """判断是否能处理该输入"""
        pass

    @abstractmethod
    def process(self, input_data: Any) -> dict:
        """处理输入，返回标准化结果"""
        pass

class TextHandler(ModalityHandler):
    def can_handle(self, input_data):
        return isinstance(input_data, str) and not input_data.startswith("http")

    def process(self, input_data):
        return {"type": "text", "content": input_data, "tokens": len(input_data)}

class ImageHandler(ModalityHandler):
    def can_handle(self, input_data):
        if isinstance(input_data, str):
            return input_data.endswith((".jpg", ".jpeg", ".png", ".gif", ".webp"))
        return False

    def process(self, input_data):
        from PIL import Image
        image = Image.open(input_data).convert("RGB")
        return {"type": "image", "data": image, "size": image.size}

class AudioHandler(ModalityHandler):
    def can_handle(self, input_data):
        if isinstance(input_data, str):
            return input_data.endswith((".mp3", ".wav", ".m4a", ".ogg"))
        return isinstance(input_data, bytes)

    def process(self, input_data):
        import whisper
        model = whisper.load_model("base")
        result = model.transcribe(input_data)
        return {"type": "audio", "transcript": result["text"], "duration": result.get("duration", 0)}

class ModalityRouter:
    """模态路由器"""

    def __init__(self):
        self.handlers = []

    def register(self, handler: ModalityHandler):
        """注册处理器"""
        self.handlers.append(handler)

    def route(self, input_data: Any) -> dict:
        """自动识别并路由到对应处理器"""
        for handler in self.handlers:
            if handler.can_handle(input_data):
                return handler.process(input_data)
        raise ValueError(f"无法识别输入类型: {type(input_data)}")

class MultimodalArchitecture:
    """多模态架构"""

    def __init__(self):
        self.router = ModalityRouter()
        self._register_default_handlers()

    def _register_default_handlers(self):
        self.router.register(TextHandler())
        self.router.register(ImageHandler())
        self.router.register(AudioHandler())

    def process(self, inputs: Dict[str, Any]) -> Dict[str, Any]:
        """处理多模态输入"""
        results = {}
        for key, value in inputs.items():
            try:
                results[key] = self.router.route(value)
            except ValueError as e:
                results[key] = {"type": "error", "message": str(e)}
        return results

# 使用示例
arch = MultimodalArchitecture()
result = arch.process({
    "text_input": "今天天气怎么样？",
    "image_input": "photo.jpg"
})
print(result)
```

**要点**：
- 用策略模式 + 注册机制实现插件化，新增模态只需添加 Handler 并注册，不修改核心代码
- `can_handle` 方法做类型检测，优先级由注册顺序决定
- 常见错误：用 if-else 硬编码所有模态类型，新增模态需要改动多处代码

### 练习二：路由题——实现模态路由器

**思路**：实现一个支持优先级、降级和动态注册的模态路由器。当首选处理器失败时自动降级到备选处理器。

**答案**：
```python
from dataclasses import dataclass
from typing import Callable

@dataclass
class RouteRule:
    """路由规则"""
    name: str
    handler: ModalityHandler
    priority: int = 0
    fallback: Optional[str] = None

class AdvancedModalityRouter:
    """高级模态路由器"""

    def __init__(self):
        self.rules: Dict[str, RouteRule] = {}
        self.metrics = {"total": 0, "success": 0, "fallback": 0, "error": 0}

    def register(self, name: str, handler: ModalityHandler, priority: int = 0, fallback: str = None):
        """注册路由规则"""
        self.rules[name] = RouteRule(name=name, handler=handler, priority=priority, fallback=fallback)

    def route(self, input_data: Any) -> dict:
        """路由输入，支持降级"""
        self.metrics["total"] += 1

        # 按优先级排序尝试匹配
        sorted_rules = sorted(self.rules.values(), key=lambda r: r.priority, reverse=True)

        for rule in sorted_rules:
            if rule.handler.can_handle(input_data):
                try:
                    result = rule.handler.process(input_data)
                    result["_handler"] = rule.name
                    self.metrics["success"] += 1
                    return result
                except Exception as e:
                    # 尝试降级
                    if rule.fallback and rule.fallback in self.rules:
                        self.metrics["fallback"] += 1
                        fallback_rule = self.rules[rule.fallback]
                        try:
                            result = fallback_rule.handler.process(input_data)
                            result["_handler"] = f"{rule.name}->{rule.fallback}"
                            return result
                        except Exception:
                            pass
                    self.metrics["error"] += 1
                    return {"type": "error", "message": f"{rule.name} 处理失败: {e}"}

        self.metrics["error"] += 1
        return {"type": "error", "message": "无匹配的处理器"}

    def get_metrics(self) -> dict:
        return {**self.metrics, "success_rate": self.metrics["success"] / max(self.metrics["total"], 1)}

# 使用示例
router = AdvancedModalityRouter()
router.register("text", TextHandler(), priority=10)
router.register("image", ImageHandler(), priority=10)
router.register("audio", AudioHandler(), priority=5, fallback="text")

result = router.route("你好世界")
print(f"处理器: {result.get('_handler')}, 类型: {result['type']}")
print(f"路由指标: {router.get_metrics()}")
```

**要点**：
- 优先级机制确保高置信度的处理器先被尝试
- 降级机制确保单个处理器失败不会导致整个请求失败
- 常见错误：不记录路由指标，无法发现某类输入频繁失败的问题

### 练习三：融合题——实现融合推理功能

**思路**：实现一个融合推理器，将多模态处理结果按置信度加权合并，处理冲突信息，最终由 LLM 生成综合回答。

**答案**：
```python
import json
from openai import OpenAI

class FusionReasoner:
    """融合推理器"""

    def __init__(self):
        self.client = OpenAI()

    def fuse(self, modality_results: Dict[str, dict], question: str = "") -> str:
        """融合多模态结果"""
        # 按置信度排序
        sorted_results = sorted(
            modality_results.items(),
            key=lambda x: x[1].get("confidence", 0.5),
            reverse=True
        )

        # 组装融合上下文
        context_parts = []
        for modality, result in sorted_results:
            confidence = result.get("confidence", 0.5)
            content = self._extract_content(result)
            context_parts.append(f"[{modality}] (置信度: {confidence:.2f}): {content}")

        context = "\n".join(context_parts)

        # LLM 融合推理
        prompt = f"""请融合以下多模态信息生成综合回答。

{f"问题：{question}" if question else ""}

多模态信息：
{context}

要求：
1. 优先采信置信度高的信息
2. 如果不同模态的信息存在冲突，以高置信度信息为准并说明冲突
3. 综合所有模态的信息给出完整回答"""

        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}]
        )
        return response.choices[0].message.content

    def _extract_content(self, result: dict) -> str:
        """提取结果内容"""
        if result["type"] == "text":
            return result.get("content", "")
        elif result["type"] == "audio":
            return f"[语音转文字] {result.get('transcript', '')}"
        elif result["type"] == "image":
            return f"[图片描述] {result.get('description', '已识别图片内容')}"
        return str(result)

    def fuse_with_conflict_detection(self, modality_results: Dict[str, dict]) -> dict:
        """带冲突检测的融合"""
        # 检测文本和语音转写之间的一致性
        texts = []
        for modality, result in modality_results.items():
            if result["type"] == "text":
                texts.append(("text", result.get("content", "")))
            elif result["type"] == "audio":
                texts.append(("audio", result.get("transcript", "")))

        has_conflict = False
        if len(texts) >= 2:
            # 简单的一致性检测
            response = self.client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[{
                    "role": "user",
                    "content": f"以下两段信息是否一致？\n1. {texts[0][1]}\n2. {texts[1][1]}\n回答 JSON: {{\"consistent\": true/false}}"
                }],
                response_format={"type": "json_object"}
            )
            consistency = json.loads(response.choices[0].message.content)
            has_conflict = not consistency.get("consistent", True)

        fused = self.fuse(modality_results)
        return {"answer": fused, "has_conflict": has_conflict}

# 使用示例
reasoner = FusionReasoner()
result = reasoner.fuse({
    "text": {"type": "text", "content": "今天气温 25 度", "confidence": 0.9},
    "audio": {"type": "audio", "transcript": "今天会下雨", "confidence": 0.7}
}, question="今天天气怎么样？")
print(result)
```

**要点**：
- 置信度加权确保高可靠性的信息源优先被采信
- 冲突检测是多模态融合的关键，不同模态可能给出矛盾信息
- 常见错误：简单拼接所有模态结果不做优先级排序，导致低质量信息干扰高质量信息
