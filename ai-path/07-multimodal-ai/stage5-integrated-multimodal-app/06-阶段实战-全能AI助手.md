# 阶段实战——构建全能 AI 助手

> 课型：项目推进课
> 目标：整合文本、图片、语音、文档处理能力，构建一个端到端的多模态 AI 助手

## 当前卡点

前 5 个阶段你学了视觉处理、语音交互、文档理解、多模态 RAG、架构设计。现在要把它们整合成一个完整的系统：用户输入文字能回答问题，上传图片能分析内容，录一段语音能听懂并语音回复，上传 PDF 能理解并回答相关问题。

不是每个功能都要做到极致——先跑通核心链路，再逐步完善。

## 系统架构

```
输入层 → 模态识别 → 处理层 → 融合推理 → 输出层
  │          │          │          │        │
  ▼          ▼          ▼          ▼        ▼
文本/图片   识别类型   处理输入   融合结果  文本/语音
语音/文档
```

核心设计判断：
- 先做文本问答 + 图片理解（覆盖 80% 场景）
- 语音和文档作为增强能力
- 每种模态的处理器独立，方便单独升级

## 核心实现

```python
from openai import OpenAI

client = OpenAI()


class MultimodalAssistant:
    def __init__(self):
        self.handlers = {
            "text": self._handle_text,
            "image": self._handle_image,
            "audio": self._handle_audio,
            "document": self._handle_document,
        }

    def process(self, inputs: dict) -> dict:
        """处理多模态输入"""
        results = {}

        for key, value in inputs.items():
            handler = self.handlers.get(key)
            if handler:
                results[key] = handler(value)

        # 融合所有模态结果
        return self._fuse(results)

    def _handle_text(self, text: str) -> dict:
        return {"type": "text", "content": text}

    def _handle_image(self, image_path: str) -> dict:
        """图片分析"""
        import base64
        with open(image_path, "rb") as f:
            image_data = base64.b64encode(f.read()).decode()

        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[{
                "role": "user",
                "content": [
                    {"type": "text", "text": "请详细描述这张图片的内容。"},
                    {"type": "image_url", "image_url": {
                        "url": f"data:image/jpeg;base64,{image_data}"
                    }},
                ],
            }],
        )
        return {"type": "image", "description": response.choices[0].message.content}

    def _handle_audio(self, audio_path: str) -> dict:
        """语音转文字"""
        with open(audio_path, "rb") as f:
            transcript = client.audio.transcriptions.create(
                model="whisper-1", file=f, language="zh",
            )
        return {"type": "audio", "transcript": transcript.text}

    def _handle_document(self, doc_path: str) -> dict:
        """文档解析"""
        import pdfplumber
        with pdfplumber.open(doc_path) as pdf:
            text = "\n".join(page.extract_text() or "" for page in pdf.pages)
        return {"type": "document", "content": text[:8000]}

    def _fuse(self, results: dict) -> dict:
        """融合多模态结果生成回答"""
        context_parts = []
        for key, r in results.items():
            if r["type"] == "text":
                context_parts.append(f"用户问题：{r['content']}")
            elif r["type"] == "image":
                context_parts.append(f"图片内容：{r['description']}")
            elif r["type"] == "audio":
                context_parts.append(f"语音内容：{r['transcript']}")
            elif r["type"] == "document":
                context_parts.append(f"文档内容：{r['content'][:2000]}")

        context = "\n\n".join(context_parts)

        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[
                {"role": "system", "content": "你是一个多模态 AI 助手，能够理解文本、图片、语音和文档。请根据提供的信息回答问题。"},
                {"role": "user", "content": context},
            ],
        )

        return {
            "answer": response.choices[0].message.content,
            "modalities_used": list(results.keys()),
        }
```

## 使用示例

```python
assistant = MultimodalAssistant()

# 纯文本问答
result = assistant.process({"text": "什么是 RAG？"})

# 图片分析
result = assistant.process({"image": "photo.jpg"})

# 语音对话
result = assistant.process({"audio": "question.mp3"})

# 文档问答
result = assistant.process({"document": "report.pdf", "text": "总结这份报告"})

# 图文综合分析
result = assistant.process({
    "image": "chart.png",
    "text": "这张图表说明了什么趋势？",
})
```

## Web 界面

```python
import gradio as gr


def assistant_interface(text, image, audio, document):
    assistant = MultimodalAssistant()

    inputs = {}
    if text:
        inputs["text"] = text
    if image:
        inputs["image"] = image
    if audio:
        inputs["audio"] = audio
    if document:
        inputs["document"] = document

    if not inputs:
        return "请至少输入一种模态的内容"

    result = assistant.process(inputs)
    return result["answer"]


demo = gr.Interface(
    fn=assistant_interface,
    inputs=[
        gr.Textbox(label="文本", placeholder="输入你的问题..."),
        gr.Image(type="filepath", label="图片"),
        gr.Audio(type="filepath", label="语音"),
        gr.File(label="文档 (PDF)"),
    ],
    outputs=gr.Textbox(label="回答"),
    title="多模态 AI 助手",
)

demo.launch()
```

## 关键判断

**渐进式开发**。先做文本问答 → 加图片理解 → 加语音交互 → 加文档处理。每步验证后再加新功能。不要一上来就同时实现所有模态。

**做好模块间的解耦**。输入处理、模态识别、能力调用、结果生成各模块独立。这样某个模态出问题不影响其他模态。

**不要追求功能全面忽略核心体验**。什么都想支持但每个功能都做得很粗糙，不如先把核心场景（文本 + 图片）做到极致再扩展。

**端到端测试比单元测试更重要**。单个模块测试通过不代表整体可用。用真实请求测试完整链路：输入一张图片 + 一段文字，看输出是否合理。

### 练习一

图文综合分析的效果取决于图片质量和问题的具体程度。"这张图片说明了什么"每述"这张图片里有什么"能得到更有深度的分析。测试时用不同类型的图片（照片、图表、截图）验证鲁棒性。

### 练习二

```python
def process_safe(self, inputs: dict) -> dict:
    results = {}
    errors = {}

    for key, value in inputs.items():
        try:
            handler = self.handlers.get(key)
            if handler:
                results[key] = handler(value)
        except Exception as e:
            errors[key] = str(e)

    if not results:
        return {"answer": "所有输入处理失败", "errors": errors}

    response = self._fuse(results)
    response["errors"] = errors
    return response
```

### 练习三

```python
def text_to_speech(text: str, output_path: str = "response.mp3"):
    response = client.audio.speech.create(
        model="tts-1", voice="alloy", input=text,
    )
    response.stream_to_file(output_path)
    return output_path
```

TTS 成本约 $15/1M 字符。长回答可以截取前 500 字做语音，避免成本过高。
