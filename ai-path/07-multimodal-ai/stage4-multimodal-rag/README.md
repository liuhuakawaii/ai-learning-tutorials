# 第 4 阶段：多模态 RAG

> 实现图文混合的检索增强生成

## 学习目标

- 理解 CLIP / ColPali 等多模态 Embedding 模型的原理
- 掌握图文混合索引和跨模态检索的实现方法
- 学会构建多模态 RAG Pipeline
- 能够评估多模态 RAG 系统的质量（复用 03 课程方法）

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 多模态 Embedding — CLIP / ColPali 的图文向量化原理 | 3h |
| 02 | 图文混合索引 — 将图片和文本存储到同一个向量空间 | 3h |
| 03 | 跨模态检索 — 用文字搜图片、用图片搜文字 | 3h |
| 04 | 多模态 RAG Pipeline — 图文混合检索 + 多模态 LLM 生成 | 3h |
| 05 | 评估多模态 RAG — 多模态场景下的评估指标与方法 | 2h |
| 06 | 阶段实战：构建一个多模态知识库（支持图片 + 文本混合检索问答） | 4h |

## 验收标准

- [ ] 能实现"用文字搜图片"和"用图片搜文字"两种跨模态检索
- [ ] 多模态 RAG 能根据图文混合检索结果生成准确回答
- [ ] 评估报告覆盖检索质量和生成质量两个维度
