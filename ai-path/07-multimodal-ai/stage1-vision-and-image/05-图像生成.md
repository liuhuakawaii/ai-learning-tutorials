# 05 图像生成——DALL-E 3 / Stable Diffusion 的集成与 Prompt 工程

> 图像生成让 AI 能创造视觉内容。

## 场景引入

你所在的营销团队需要为一款新上市的护肤品制作 200 张不同风格的产品展示图，用于社交媒体投放。外包给设计师每张图报价 200 元，周期需要两周。你考虑用 AI 图像生成来降低成本、加快速度，但试了几个工具后发现：生成的图片风格不稳定、产品细节经常变形、文字渲染几乎不可用、同一产品的不同角度生成结果差异很大——图像生成远不是"输入一句话就出好图"那么简单。

## 常见误区

1. **认为 Prompt 写得好就能一次生成满意图片**：图像生成需要多轮迭代，第一次生成的结果往往需要多次调整 prompt、修改参数才能达到商用标准。
2. **忽略生成图片的版权风险**：AI 生成图片的版权归属尚有争议，商用前必须了解各平台的版权政策，避免法律风险。
3. **在图片中生成文字**：当前所有图像生成模型对文字的渲染都很差，几乎不可能生成正确的文字，需要生成后用图像编辑工具叠加文字。
4. **不做风格一致性控制**：同一项目的多张图片如果风格不一致，会严重影响用户体验，需要通过 seed、风格模板等方式保持一致性。

## 工程建议

1. **建立 Prompt 模板库**：为常见场景（产品展示、背景替换、风格迁移）建立标准化的 prompt 模板，减少重复调试。
2. **用 img2img 保持一致性**：基于参考图生成变体，比纯文本生成更容易保持风格和构图的一致性。
3. **批量生成 + 人工筛选**：每次生成 4-8 张候选图，人工挑选最佳结果，比反复调整 prompt 效率更高。
4. **结合图像编辑工具做后处理**：AI 生成的图片通常需要裁剪、调色、叠加文字等后处理，不要期望一步到位。

### 练习一：生成题

**思路**：使用 DALL-E 3 API 生成图片，通过详细的 prompt 描述控制生成质量。

**答案**：
```python
from openai import OpenAI

client = OpenAI()


def generate_product_image(
    product_name: str,
    style: str = "professional product photography",
    background: str = "clean white background",
    extra_details: str = ""
) -> str:
    """用 DALL-E 3 生成产品展示图"""
    
    prompt = f"""A {product_name}, {style}, {background}, 
soft studio lighting, high resolution, detailed textures, 
commercial quality, 4K{', ' + extra_details if extra_details else ''}"""
    
    response = client.images.generate(
        model="dall-e-3",
        prompt=prompt,
        size="1024x1024",
        quality="hd",
        n=1
    )
    
    image_url = response.data[0].url
    revised_prompt = response.data[0].revised_prompt
    
    print(f"生成成功!")
    print(f"原始 Prompt: {prompt}")
    print(f"修订 Prompt: {revised_prompt}")
    print(f"图片 URL: {image_url}")
    
    return image_url


def generate_with_style_reference(
    subject: str,
    style: str,
    mood: str = "professional"
) -> str:
    """生成指定风格的图片"""
    
    prompt = f"""{subject}, in the style of {style}, 
{mood} mood, high quality, detailed, well-composed"""
    
    response = client.images.generate(
        model="dall-e-3",
        prompt=prompt,
        size="1024x1024",
        quality="standard",
        n=1
    )
    
    return response.data[0].url


if __name__ == "__main__":
    # 生成产品图
    url = generate_product_image(
        product_name="glass bottle of premium skincare serum",
        style="minimalist luxury product photography",
        background="soft gradient background with subtle bokeh",
        extra_details="golden cap, transparent liquid, elegant label design"
    )
```

**要点**：
- Prompt 要具体：主体、风格、背景、光线、构图都要描述
- DALL-E 3 会自动修订你的 prompt，注意查看 `revised_prompt` 了解实际生成逻辑
- `"quality": "hd"` 生成更高质量的图片，但成本翻倍
- 常见错误：prompt 太简略（如"一瓶护肤品"），生成结果随机性很大，风格不稳定

### 练习二：Prompt 题

**思路**：通过对比不同 prompt 策略的生成效果，掌握图像生成 prompt 的优化技巧。

**答案**：
```python
from openai import OpenAI
import time

client = OpenAI()


def compare_prompt_strategies():
    """对比不同 prompt 策略的生成效果"""
    
    base_subject = "一杯咖啡放在书桌上"
    
    prompts = {
        "简略版": "一杯咖啡放在书桌上",
        
        "详细版": "一杯拿铁咖啡放在深色木质书桌上，白色陶瓷杯，拉花图案，"
                  "旁边有一本打开的书，柔和的自然光从窗户照入，温馨的氛围",
        
        "风格指定版": "一杯拿铁咖啡放在深色木质书桌上，白色陶瓷杯，拉花图案，"
                     "极简主义摄影风格，浅景深，柔和的晨光，4K 高清",
        
        "专业摄影版": "Professional still life photography of a latte in a white ceramic cup "
                     "with latte art, on a dark wooden desk, next to an open book, "
                     "soft natural window light, shallow depth of field, "
                     "warm color temperature, 85mm lens, f/2.8, commercial quality"
    }
    
    results = {}
    
    for name, prompt in prompts.items():
        print(f"\n生成中: {name}")
        print(f"Prompt: {prompt[:80]}...")
        
        response = client.images.generate(
            model="dall-e-3",
            prompt=prompt,
            size="1024x1024",
            quality="standard",
            n=1
        )
        
        results[name] = {
            "url": response.data[0].url,
            "revised_prompt": response.data[0].revised_prompt,
            "original_prompt": prompt
        }
        
        print(f"URL: {response.data[0].url}")
        time.sleep(1)  # 避免速率限制
    
    return results


def build_prompt_template(
    subject: str,
    style: str = "professional photography",
    lighting: str = "soft natural light",
    composition: str = "well-balanced",
    quality: str = "high quality, detailed"
) -> str:
    """构建标准化的图像生成 prompt 模板"""
    
    return f"""{subject}, {style}, {lighting}, {composition}, {quality}"""


if __name__ == "__main__":
    results = compare_prompt_strategies()
    
    print("\n=== Prompt 优化总结 ===")
    print("1. 简略版: 随机性大，风格不可控")
    print("2. 详细版: 主体明确，但风格仍不固定")
    print("3. 风格指定版: 风格稳定，适合批量生成")
    print("4. 专业摄影版: 效果最好，但 prompt 较长")
```

**要点**：
- Prompt 从简到详，观察生成质量的提升：主体 → 环境 → 光线 → 风格 → 技术参数
- 英文 prompt 通常比中文效果更好（DALL-E 3 的训练数据以英文为主）
- 加入摄影术语（如"85mm lens, f/2.8"）能显著提升真实感
- 常见错误：把所有描述堆在一起不组织结构，导致模型忽略部分描述

### 练习三：应用题

**思路**：设计一个完整的图像生成应用方案，覆盖场景定义、prompt 模板、批量生成和质量控制。

**答案**：
```python
from openai import OpenAI
import json
import os

client = OpenAI()


class ProductImageGenerator:
    """电商产品图批量生成系统"""
    
    def __init__(self, output_dir: str = "./generated_images"):
        self.output_dir = output_dir
        os.makedirs(output_dir, exist_ok=True)
        
        # 风格模板库
        self.style_templates = {
            "白底主图": {
                "prompt": "{product}, professional product photography, pure white background, "
                         "soft studio lighting, centered composition, high resolution",
                "size": "1024x1024"
            },
            "场景图": {
                "prompt": "{product} in a {scene}, natural lighting, lifestyle photography, "
                         "warm atmosphere, 4K quality",
                "size": "1024x1024"
            },
            "细节图": {
                "prompt": "Close-up detail shot of {product}, macro photography, "
                         "sharp focus on texture, blurred background, studio lighting",
                "size": "1024x1024"
            },
            "社交图": {
                "prompt": "{product}, Instagram style photo, trendy aesthetic, "
                         "good lighting, appealing composition, social media ready",
                "size": "1024x1024"
            }
        }
    
    def generate_image(self, product: str, style: str, scene: str = "") -> str:
        """生成单张产品图"""
        
        template = self.style_templates[style]
        prompt = template["prompt"].format(product=product, scene=scene)
        
        response = client.images.generate(
            model="dall-e-3",
            prompt=prompt,
            size=template["size"],
            quality="hd",
            n=1
        )
        
        return response.data[0].url
    
    def generate_product_series(self, product: str, scene: str = "modern kitchen") -> dict:
        """为一个产品生成系列图片"""
        
        results = {}
        
        for style_name in self.style_templates:
            try:
                url = self.generate_image(product, style_name, scene)
                results[style_name] = {"url": url, "status": "success"}
                print(f"✓ {style_name}: 生成成功")
            except Exception as e:
                results[style_name] = {"error": str(e), "status": "failed"}
                print(f"✗ {style_name}: {str(e)}")
        
        # 保存结果
        output_file = os.path.join(self.output_dir, f"{product.replace(' ', '_')}_series.json")
        with open(output_file, "w", encoding="utf-8") as f:
            json.dump(results, f, ensure_ascii=False, indent=2)
        
        return results
    
    def batch_generate(self, products: list[dict]) -> dict:
        """批量生成多产品的系列图片"""
        
        all_results = {}
        
        for item in products:
            product = item["name"]
            scene = item.get("scene", "modern kitchen")
            
            print(f"\n{'='*50}")
            print(f"产品: {product}")
            all_results[product] = self.generate_product_series(product, scene)
        
        # 统计
        total = sum(len(v) for v in all_results.values())
        success = sum(1 for v in all_results.values() for r in v.values() if r.get("status") == "success")
        
        print(f"\n=== 批量生成完成 ===")
        print(f"总计: {total}, 成功: {success}, 失败: {total - success}")
        
        return all_results


if __name__ == "__main__":
    generator = ProductImageGenerator()
    
    products = [
        {"name": "glass bottle of vitamin C serum", "scene": "bright bathroom shelf"},
        {"name": "ceramic coffee mug with floral pattern", "scene": "cozy reading nook"},
    ]
    
    results = generator.batch_generate(products)
```

**要点**：
- 建立风格模板库，标准化 prompt，避免每次手动编写
- 同一产品生成多种风格（白底主图、场景图、细节图、社交图）覆盖不同使用场景
- 批量生成时要处理速率限制和错误重试
- 常见错误：不做风格模板管理，每次生成的 prompt 不一致，导致产品图风格不统一
