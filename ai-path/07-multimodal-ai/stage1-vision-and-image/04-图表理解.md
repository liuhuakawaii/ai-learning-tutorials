# 04 图表理解——让 AI 解读柱状图、折线图、流程图

> 图表理解是数据可视化分析的关键能力。

## 场景引入

你是一家数据分析公司的工程师，客户每天上传大量包含柱状图、折线图、流程图的截图，要求从中提取数据和关键洞察。传统做法是人工逐张查看图表并手动录入数据，一个分析师一天最多处理 50 张图表。你想用 AI 自动化这个流程，但发现：不同图表类型的解读逻辑完全不同，坐标轴刻度需要精确读取，复合图表（双 Y 轴、堆叠柱状图）的理解难度远超简单图表。

## 学习目标

- 掌握图表理解的方法
- 实现各种图表的解读
- 学会从图表中提取数据和洞察

## 常见误区

1. **认为模型能精确读取图表数值**：大模型对图表的理解是"近似"的，坐标轴上的精确数值经常读错，需要精确数据时应结合 OCR 工具。
2. **混淆图表理解和数据提取**：理解趋势和提取精确数据是两个不同任务，前者用大模型效果好，后者需要专门的数据提取方案。
3. **忽略图表类型的差异**：柱状图、折线图、饼图、流程图的解读逻辑完全不同，用同一个 prompt 处理所有图表类型效果会很差。
4. **不做结果人工抽检**：图表理解的主观性强，自动评估困难，生产环境必须保留人工抽检环节。

## 工程建议

1. **按图表类型设计专用 Prompt**：识别图表类型后，路由到对应的专用 prompt，比通用 prompt 的准确率高 20% 以上。
2. **先 OCR 再理解**：对于需要精确数值的场景，先用 OCR 提取坐标轴和标签文字，再让模型做趋势分析。
3. **建立图表理解的评估基准**：收集典型图表和人工标注的标准答案，量化评估模型的准确率。
4. **输出结构化数据而非自然语言**：要求模型输出 JSON 格式的数据点，方便后续入库和可视化，而不是一段描述性文字。

### 练习一：柱状图题

**思路**：设计专用的柱状图分析 prompt，提取标题、坐标轴含义、各柱数值和趋势洞察。

**答案**：
```python
import base64
import json
from openai import OpenAI

client = OpenAI()


def analyze_bar_chart(image_path: str) -> dict:
    """分析柱状图，提取数据和洞察"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请详细分析这张柱状图，以 JSON 格式输出：

{
  "chart_title": "图表标题",
  "x_axis": {
    "label": "X轴标签",
    "categories": ["类别1", "类别2", "类别3"]
  },
  "y_axis": {
    "label": "Y轴标签",
    "unit": "单位",
    "range": [最小值, 最大值]
  },
  "data_points": [
    {"category": "类别1", "value": 100, "label": "柱子上的标注文字（如有）"},
    {"category": "类别2", "value": 200}
  ],
  "insights": {
    "highest": "最高的类别及其值",
    "lowest": "最低的类别及其值",
    "trend": "整体趋势描述",
    "anomaly": "异常值或特殊发现（如有）"
  }
}

要求：
- 数值尽量精确读取，参考坐标轴刻度
- 如果是分组柱状图，每个组分别列出
- 如果是堆叠柱状图，分别列出各层的值"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image_base64}", "detail": "high"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    
    # 输出分析结果
    print(f"图表: {result.get('chart_title', '未知')}")
    print(f"X轴: {result['x_axis']['label']}")
    print(f"Y轴: {result['y_axis']['label']} ({result['y_axis'].get('unit', '')})")
    print("\n数据点:")
    for dp in result.get("data_points", []):
        print(f"  {dp['category']}: {dp['value']}")
    print(f"\n洞察:")
    print(f"  最高: {result['insights']['highest']}")
    print(f"  最低: {result['insights']['lowest']}")
    print(f"  趋势: {result['insights']['trend']}")
    
    return result


if __name__ == "__main__":
    result = analyze_bar_chart("sales_chart.png")
```

**要点**：
- 柱状图分析必须用 `"detail": "high"` 才能准确读取坐标轴刻度和柱子数值
- 分组柱状图和堆叠柱状图的分析逻辑完全不同，prompt 要分别说明
- 数值读取是"近似"的，不要期望精确到小数点后两位
- 常见错误：用通用 prompt 分析柱状图，模型只给出描述性文字而不提取具体数据

### 练习二：折线图题

**思路**：分析折线图的时间序列趋势、关键拐点和多线对比。

**答案**：
```python
import base64
import json
from openai import OpenAI

client = OpenAI()


def analyze_line_chart(image_path: str) -> dict:
    """分析折线图，提取趋势和关键数据点"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请详细分析这张折线图，以 JSON 格式输出：

{
  "chart_title": "图表标题",
  "time_range": {
    "start": "起始时间",
    "end": "结束时间",
    "unit": "时间单位（日/周/月/年）"
  },
  "lines": [
    {
      "name": "线条名称",
      "color": "颜色描述",
      "data_points": [
        {"time": "时间点1", "value": 100},
        {"time": "时间点2", "value": 150}
      ],
      "trend": "该线条的整体趋势"
    }
  ],
  "key_points": {
    "peaks": [{"time": "时间", "value": 值, "line": "线条名"}],
    "valleys": [{"time": "时间", "value": 值, "line": "线条名"}],
    "crossovers": [{"time": "时间", "lines": ["线条A", "线条B"]}]
  },
  "summary": "整体趋势的中文描述"
}

要求：
- 尽量提取可见的数据点（至少起止点和拐点）
- 多条线条分别描述
- 关注线条交叉点，这往往是重要转折"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image_base64}", "detail": "high"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    
    print(f"图表: {result.get('chart_title', '未知')}")
    print(f"时间范围: {result['time_range']['start']} ~ {result['time_range']['end']}")
    
    for line in result.get("lines", []):
        print(f"\n线条 [{line['name']}]: {line['trend']}")
        print(f"  数据点: {len(line.get('data_points', []))} 个")
    
    if result.get("key_points", {}).get("crossovers"):
        print(f"\n交叉点: {len(result['key_points']['crossovers'])} 个")
    
    print(f"\n总结: {result['summary']}")
    
    return result


if __name__ == "__main__":
    result = analyze_line_chart("trend_chart.png")
```

**要点**：
- 折线图的关键是识别趋势（上升/下降/波动）和拐点（峰/谷/交叉）
- 多线折线图要分别描述每条线的趋势，不能笼统概括
- 线条交叉点往往是重要的业务转折点，要重点标注
- 常见错误：只描述整体趋势不提取具体数据点，导致结果无法用于后续分析

### 练习三：流程图题

**思路**：分析流程图的节点、连线和决策逻辑，提取结构化的流程信息。

**答案**：
```python
import base64
import json
from openai import OpenAI

client = OpenAI()


def analyze_flowchart(image_path: str) -> dict:
    """分析流程图，提取流程结构和逻辑"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请详细分析这张流程图，以 JSON 格式输出：

{
  "title": "流程图标题（如有）",
  "nodes": [
    {
      "id": "节点编号",
      "type": "节点类型（开始/结束/处理/判断/输入输出）",
      "label": "节点内容文字",
      "shape": "形状描述（矩形/菱形/圆角矩形/平行四边形）"
    }
  ],
  "edges": [
    {
      "from": "起始节点编号",
      "to": "目标节点编号",
      "label": "连线标注（如判断分支的条件）"
    }
  ],
  "flow_description": "用自然语言描述整个流程的步骤",
  "decision_points": [
    {
      "node": "判断节点内容",
      "yes_path": "条件为真时的路径描述",
      "no_path": "条件为假时的路径描述"
    }
  ]
}

要求：
- 按照从上到下、从左到右的顺序遍历节点
- 菱形节点是判断节点，必须列出所有分支条件
- 识别是否有循环（返回箭头指向之前的节点）"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image_base64}", "detail": "high"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    
    print(f"流程图: {result.get('title', '未知')}")
    print(f"节点数: {len(result.get('nodes', []))}")
    print(f"连线数: {len(result.get('edges', []))}")
    
    print("\n流程描述:")
    print(result.get("flow_description", "无"))
    
    if result.get("decision_points"):
        print(f"\n决策节点 ({len(result['decision_points'])} 个):")
        for dp in result["decision_points"]:
            print(f"  判断: {dp['node']}")
            print(f"    是 → {dp['yes_path']}")
            print(f"    否 → {dp['no_path']}")
    
    return result


if __name__ == "__main__":
    result = analyze_flowchart("workflow.png")
    
    with open("flowchart_analysis.json", "w", encoding="utf-8") as f:
        json.dump(result, f, ensure_ascii=False, indent=2)
```

**要点**：
- 流程图的核心是节点（操作）和连线（顺序/条件），要分别提取
- 菱形判断节点必须列出所有分支条件，不能只描述主路径
- 要识别循环结构（返回箭头），这是流程图中容易遗漏的部分
- 常见错误：只描述流程的主路径，忽略异常分支和循环，导致分析不完整
