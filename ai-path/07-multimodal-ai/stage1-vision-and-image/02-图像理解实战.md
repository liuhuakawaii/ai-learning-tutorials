## 常见误区

1. **把模型输出直接当数据库字段用**：Vision API 返回的描述是自然语言，不是结构化数据，直接存储会导致后续查询和分析困难，必须先做结构化转换。
2. **忽略图片分辨率对结果的影响**：低分辨率图片会大幅降低 OCR 和细节识别的准确率，上线前必须测试不同分辨率下的表现。
3. **一次性传太多图片**：多图对比虽然方便，但 token 消耗成倍增长，且模型注意力分散后准确率下降，建议控制单次请求的图片数量。
4. **不做输出格式校验**：模型返回的 JSON 可能格式错误或字段缺失，必须做严格的 schema 校验和异常处理。

## 工程建议

1. **优先使用结构化输出**：开启 `response_format={"type": "json_object"}` 强制 JSON 输出，再用 Pydantic 或 JSON Schema 做二次校验。
2. **图片预处理标准化**：统一裁剪、压缩、调整分辨率后再传给 API，既降低成本又提高一致性。
3. **建立评估数据集**：收集 50-100 张典型业务图片和人工标注结果，每次 prompt 调整后跑回归测试。
4. **异步批量处理**：大批量图片用异步并发请求，配合速率限制和重试机制，避免被 API 限流。

### 练习一：描述题

**思路**：使用 Vision API 对图片进行详细描述，通过 prompt 工程控制描述的粒度和格式。

**答案**：
```python
import base64
from openai import OpenAI

client = OpenAI()


def describe_image_detailed(image_path: str) -> str:
    """用 Vision API 详细描述一张图片"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请详细描述这张图片，包含以下维度：
1. 整体场景：图片的整体环境和氛围
2. 主体内容：图片中的主要对象及其状态
3. 细节描述：颜色、材质、文字、标志等细节
4. 空间关系：各元素的位置和相互关系
5. 拍摄信息：拍摄角度、光线条件（如能判断）

请用自然流畅的中文描述，避免过度推测图片中不存在的元素。"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:image/jpeg;base64,{image_base64}",
                        "detail": "high"
                    }
                }
            ]
        }]
    )
    
    description = response.choices[0].message.content
    print(description)
    return description


def describe_image_for_product(image_path: str) -> dict:
    """面向电商场景的商品图片描述"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请为这张商品图片生成一段电商文案，包含：
1. 商品名称（一句话概括）
2. 核心卖点（3-5 个）
3. 适用场景
4. 推荐文案（50 字以内，适合商品详情页）

请以 JSON 格式输出。"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_base64}"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    return result


if __name__ == "__main__":
    description = describe_image_detailed("test_photo.jpg")
```

**要点**：
- Prompt 要指定描述维度（场景、主体、细节、空间、光线），否则模型输出会很随意
- 使用 `"detail": "high"` 获取更高分辨率的图片理解，但 token 消耗约增加 4 倍
- 面向不同业务场景（电商、安防、医疗）需要不同的 prompt 模板
- 常见错误：prompt 太笼统（如"描述这张图片"），导致模型输出过于简略或跑偏

### 练习二：分类题

**思路**：实现一个支持自定义类别、带置信度输出的图片分类功能。

**答案**：
```python
import base64
import json
from openai import OpenAI

client = OpenAI()


def classify_image(image_path: str, categories: list[str]) -> dict:
    """将图片分类到指定类别之一，返回分类结果和置信度"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    categories_str = "、".join(categories)
    
    prompt = f"""请将这张图片分类到以下类别之一：{categories_str}

请以 JSON 格式输出：
{{
  "category": "选择的类别名称",
  "confidence": 0.95,
  "reason": "选择该类别的原因（一句话）"
}}

要求：
- category 必须是上述类别之一，不能输出类别列表之外的名称
- confidence 为 0-1 之间的浮点数，表示你对分类结果的确信程度
- 如果图片难以归类，选择最接近的类别并降低 confidence"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_base64}"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    result = json.loads(response.choices[0].message.content)
    
    # 校验结果
    if result["category"] not in categories:
        print(f"⚠️ 模型返回了不在类别列表中的结果: {result['category']}")
        # 尝试模糊匹配
        for cat in categories:
            if cat in result["category"] or result["category"] in cat:
                result["category"] = cat
                break
    
    print(f"分类结果: {result['category']}")
    print(f"置信度: {result['confidence']:.2%}")
    print(f"原因: {result['reason']}")
    
    return result


def batch_classify(image_paths: list[str], categories: list[str]) -> list[dict]:
    """批量图片分类"""
    results = []
    
    for path in image_paths:
        try:
            result = classify_image(path, categories)
            results.append({"path": path, **result})
        except Exception as e:
            results.append({"path": path, "error": str(e)})
    
    # 统计分类分布
    distribution = {}
    for r in results:
        cat = r.get("category", "error")
        distribution[cat] = distribution.get(cat, 0) + 1
    
    print(f"\n分类分布: {json.dumps(distribution, ensure_ascii=False)}")
    return results


if __name__ == "__main__":
    result = classify_image(
        "product_photo.jpg",
        categories=["电子产品", "服装鞋帽", "食品饮料", "家居日用", "美妆护肤"]
    )
```

**要点**：
- Prompt 中明确要求"category 必须是上述类别之一"，减少模型返回非法类别的概率
- 返回置信度便于后续处理：低置信度的结果可以走人工审核
- 必须做输出校验，模型有时会返回类别列表之外的名称
- 常见错误：不设类别约束，模型可能返回"其他"或自造类别，导致下游系统出错

### 练习三：提取题

**思路**：从图片中提取结构化信息，使用 JSON Schema 约束输出格式，配合 Pydantic 做二次校验。

**答案**：
```python
import base64
import json
from pydantic import BaseModel, Field, validator
from openai import OpenAI

client = OpenAI()


class ProductInfo(BaseModel):
    """商品信息结构"""
    name: str = Field(description="商品名称")
    brand: str = Field(description="品牌名称", default="未知")
    price: str = Field(description="价格", default="未知")
    color: str = Field(description="颜色", default="未知")
    material: str = Field(description="材质", default="未知")
    size: str = Field(description="尺寸/规格", default="未知")
    features: list[str] = Field(description="商品特点", default_factory=list)
    
    @validator("price")
    def validate_price(cls, v):
        if v != "未知" and not any(c.isdigit() for c in v):
            raise ValueError("价格应包含数字")
        return v


def extract_product_info(image_path: str) -> ProductInfo:
    """从商品图片提取结构化信息"""
    
    with open(image_path, "rb") as f:
        image_base64 = base64.b64encode(f.read()).decode()
    
    prompt = """请从这张商品图片中提取以下信息，以 JSON 格式输出：

{
  "name": "商品名称",
  "brand": "品牌名称（如无法识别则填'未知'）",
  "price": "价格（如可见则提取，否则填'未知'）",
  "color": "颜色",
  "material": "材质（如能判断）",
  "size": "尺寸或规格",
  "features": ["特点1", "特点2", "特点3"]
}

要求：
- 只提取图片中明确可见的信息，不要推测
- 无法确认的字段填"未知"
- features 列出 3-5 个商品特点"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_base64}"}}
            ]
        }],
        response_format={"type": "json_object"}
    )
    
    raw_result = json.loads(response.choices[0].message.content)
    
    # Pydantic 校验
    try:
        product = ProductInfo(**raw_result)
    except Exception as e:
        print(f"校验失败: {e}")
        # 用默认值填充缺失字段
        for field_name, field_info in ProductInfo.__fields__.items():
            if field_name not in raw_result:
                raw_result[field_name] = field_info.default if field_info.default else "未知"
        product = ProductInfo(**raw_result)
    
    print(f"商品名称: {product.name}")
    print(f"品牌: {product.brand}")
    print(f"价格: {product.price}")
    print(f"颜色: {product.color}")
    print(f"材质: {product.material}")
    print(f"特点: {', '.join(product.features)}")
    
    return product


if __name__ == "__main__":
    product = extract_product_info("product.jpg")
```

**要点**：
- 使用 Pydantic 做二次校验，确保输出符合预期 schema
- 对无法识别的字段设默认值"未知"，而不是让模型编造
- `response_format={"type": "json_object"}` 强制 JSON 输出，但仍需校验字段完整性
- 常见错误：不校验模型输出的 JSON 格式，模型返回非法 JSON 导致下游解析崩溃
