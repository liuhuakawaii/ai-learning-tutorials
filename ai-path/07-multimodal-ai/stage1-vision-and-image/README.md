# 第 1 阶段：视觉与图像

> 让 AI 看懂图片

## 学习目标

- 了解主流多模态模型（GPT-4o / Claude Vision / Gemini）的能力对比
- 掌握用 Vision API 实现图片描述、分类、信息提取的方法
- 学会处理 OCR、图表理解等视觉任务
- 能够集成图像生成能力（DALL-E 3 / Stable Diffusion）

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 多模态模型概览 — GPT-4o / Claude Vision / Gemini 的能力对比 | 2h |
| 02 | 图像理解实战 — 用 Vision API 实现图片描述、分类、信息提取 | 3h |
| 03 | OCR 与文档图片 — 从图片中提取文字和表格 | 3h |
| 04 | 图表理解 — 让 AI 解读柱状图、折线图、流程图 | 3h |
| 05 | 图像生成 — DALL-E 3 / Stable Diffusion 的集成与 Prompt 工程 | 3h |
| 06 | 阶段实战：构建一个商品图片智能分析系统（提取信息 + 生成描述） | 4h |

## 验收标准

- [ ] 能用 Vision API 完成图片分类、信息提取、描述生成
- [ ] OCR 能正确提取图片中的文字和表格数据
- [ ] 商品图片分析系统能自动提取商品属性并生成营销文案
