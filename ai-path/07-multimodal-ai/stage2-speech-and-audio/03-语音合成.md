# 03 语音合成——OpenAI TTS / Edge-TTS 的集成与音色选择

> 语音合成让 AI 能开口说话。

## 场景引入

你要为一个在线教育平台的 AI 助手添加"开口说话"的能力：学生提问后，AI 不仅要返回文字答案，还要用自然的语音朗读出来。产品经理要求：中文发音要自然不能像机器人、至少提供 3 种不同音色供选择、长文本合成不能有明显停顿、首字节延迟控制在 500ms 以内。你对比了 OpenAI TTS（效果好但贵）和 Edge-TTS（免费但音色有限），发现语音合成看似简单，实际工程化的挑战远超预期。

def synthesize_speech_openai(text: str, voice: str = "alloy") -> str:
    """OpenAI 语音合成"""
    response = client.audio.speech.create(

## 二、Edge-TTS（免费）

```python
import edge_tts
import asyncio

async def synthesize_speech_edge(text: str, voice: str = "zh-CN-XiaoxiaoNeural") -> str:
    """Edge-TTS 语音合成"""
    output_path = "output.mp3"
    
    communicate = edge_tts.Communicate(text, voice)
    await communicate.save(output_path)
    
    return output_path
```

async def stream_tts(text: str):
    """流式语音合成"""
    communicate = edge_tts.Communicate(text, "zh-CN-XiaoxiaoNeural")
    
    async for chunk in communicate.stream():
        if chunk["type"] == "audio":
            # 处理音频数据
            yield chunk["data"]

## 五、批量合成

```python
async def batch_synthesize(texts: list, voice: str = "zh-CN-XiaoxiaoNeural") -> list:
    """批量语音合成"""
    tasks = []
    
    for i, text in enumerate(texts):
        output_path = f"output_{i}.mp3"
        task = edge_tts.Communicate(text, voice).save(output_path)
        tasks.append(task)
    
    await asyncio.gather(*tasks)
    
    return [f"output_{i}.mp3" for i in range(len(texts))]
```

## 常见误区

1. **认为 TTS 输出可以直接播放**：合成的音频文件可能有采样率、编码格式的差异，直接播放可能有杂音或速度异常，需要做格式标准化。
2. **忽略长文本的分段合成**：一次性合成很长的文本会导致延迟很高且可能出错，应该按句子或段落分段合成后拼接。
3. **不做音色测试就上线**：不同音色在不同文本类型上的表现差异很大，有的音色读数字很自然但读英文就很生硬，必须用真实业务文本测试。
4. **忽视 SSML 标记的作用**：SSML 可以精确控制停顿、重音、语速等，不用 SSML 的话模型会自行判断，经常出现不自然的断句。

## 工程建议

1. **按场景选择 TTS 方案**：对音质要求高的场景用 OpenAI TTS 或 Azure Neural TTS；成本敏感的场景用 Edge-TTS；需要极致低延迟考虑本地 TTS 模型。
2. **实现流式合成**：长文本按句子分段，边合成边播放，用户感知延迟可从几秒降到 500ms 以内。
3. **建立音色管理模块**：将音色配置化，支持按用户偏好、场景类型动态切换音色，方便后续扩展新音色。
4. **做音频后处理**：合成后统一转码为 MP3 或 OGG 格式，控制码率和文件大小，平衡音质和传输速度。

## 参考答案

### 练习一：用 Edge-TTS 合成一段语音

**思路**：安装 edge_tts 库，选择中文音色，将文本合成为 MP3 文件，验证文件是否可正常播放。

**答案**：

```python
"""使用 Edge-TTS 合成中文语音。"""
import asyncio
import edge_tts


async def synthesize_chinese_speech(
    text: str,
    output_path: str = "output.mp3",
    voice: str = "zh-CN-XiaoxiaoNeural",
    rate: str = "+0%",
    volume: str = "+0%",
) -> str:
    """将中文文本合成为语音文件。

    Args:
        text: 要合成的中文文本
        output_path: 输出音频文件路径
        voice: 音色名称
        rate: 语速调整，如 "+20%" 加快，"-10%" 减慢
        volume: 音量调整

    Returns:
        输出文件路径
    """
    communicate = edge_tts.Communicate(text, voice, rate=rate, volume=volume)
    await communicate.save(output_path)
    print(f"语音已保存: {output_path}")

    import os
    file_size = os.path.getsize(output_path)
    print(f"文件大小: {file_size / 1024:.1f} KB")

    return output_path


if __name__ == "__main__":
    text = "欢迎使用语音合成系统。今天天气不错，适合出去走走。"
    asyncio.run(synthesize_chinese_speech(text, "demo_output.mp3"))
```

**要点**：
- Edge-TTS 是异步库，必须用 `asyncio.run()` 或在 async 函数中调用
- 首次使用会自动下载音色模型，需要网络连接
- 中文推荐 `zh-CN-XiaoxiaoNeural`（女声温柔）或 `zh-CN-YunxiNeural`（男声成熟）
- 常见错误：忘记 `await` 关键字导致协程未执行，输出文件为空

### 练习二：测试不同音色的效果

**思路**：用同一段文本分别合成多种音色的音频，对比文件大小、合成速度和听感差异。

**答案**：

```python
"""对比测试不同 TTS 音色的合成效果。"""
import asyncio
import time
import os
import edge_tts


async def test_voice(voice: str, text: str, output_dir: str = "voice_samples") -> dict:
    """测试单个音色的合成效果。"""
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, f"{voice}.mp3")

    start = time.time()
    communicate = edge_tts.Communicate(text, voice)
    await communicate.save(output_path)
    elapsed = time.time() - start

    file_size = os.path.getsize(output_path)

    return {
        "voice": voice,
        "elapsed_seconds": round(elapsed, 2),
        "file_size_kb": round(file_size / 1024, 1),
        "output_path": output_path,
    }


async def compare_voices():
    """对比多种中文音色的合成效果。"""
    text = "人工智能正在改变我们的世界，语音合成技术让机器能够自然地与人类交流。"

    voices = [
        "zh-CN-XiaoxiaoNeural",
        "zh-CN-YunxiNeural",
        "zh-CN-YunyangNeural",
        "zh-CN-XiaoyiNeural",
    ]

    print(f"测试文本: {text}")
    print(f"{'音色':<30} {'耗时':<10} {'文件大小':<12}")
    print("-" * 55)

    for voice in voices:
        result = await test_voice(voice, text)
        print(f"{result['voice']:<30} {result['elapsed_seconds']:<10}秒 {result['file_size_kb']:<12} KB")


if __name__ == "__main__":
    asyncio.run(compare_voices())
```

**要点**：
- 不同音色在中文发音的自然度、语调、停顿上差异明显，必须用真实业务文本测试
- `zh-CN-YunyangNeural` 适合正式播报场景，`zh-CN-XiaoyiNeural` 适合活泼互动场景
- 文件大小差异可反映音频编码质量，但不直接等于音质好坏
- 常见错误：用纯英文文本测试中文音色，中文音色读英文会出现发音不自然的问题

### 练习三：设计一个语音合成应用场景

**思路**：以"有声书自动生成"为例，设计完整的 TTS 应用方案，包括文本预处理、分段合成、音频拼接、进度管理。

**答案**：

```python
"""有声书自动生成系统设计。"""
import asyncio
import edge_tts
import os


async def synthesize_audiobook(
    chapter_text: str,
    output_path: str,
    voice: str = "zh-CN-YunyangNeural",
    max_chars_per_segment: int = 200,
) -> str:
    """将一个章节的文本合成为有声书音频。

    设计要点：
    1. 按句子分段，避免长文本合成失败
    2. 每段之间插入短暂停顿
    3. 支持进度回调
    """
    # 按句号、问号、感叹号分段
    import re
    sentences = re.split(r'([。！？])', chapter_text)

    # 合并标点到前一个句子
    segments = []
    current = ""
    for part in sentences:
        current += part
        if part in "。！？" and len(current) >= 10:
            segments.append(current.strip())
            current = ""
    if current.strip():
        segments.append(current.strip())

    # 合并过短的段落
    merged_segments = []
    buffer = ""
    for seg in segments:
        if len(buffer) + len(seg) > max_chars_per_segment and buffer:
            merged_segments.append(buffer)
            buffer = seg
        else:
            buffer += seg
    if buffer:
        merged_segments.append(buffer)

    print(f"共 {len(merged_segments)} 个语音段落")

    # 逐段合成
    segment_files = []
    for i, segment in enumerate(merged_segments):
        seg_path = f"_temp_segment_{i:04d}.mp3"
        communicate = edge_tts.Communicate(segment, voice)
        await communicate.save(seg_path)
        segment_files.append(seg_path)
        print(f"  段落 {i + 1}/{len(merged_segments)}: {len(segment)} 字")

    # 用 ffmpeg 拼接（需安装 ffmpeg）
    import subprocess
    list_path = "_temp_filelist.txt"
    with open(list_path, "w", encoding="utf-8") as f:
        for sf in segment_files:
            f.write(f"file '{sf}'\n")

    subprocess.run([
        "ffmpeg", "-y", "-f", "concat", "-safe", "0",
        "-i", list_path, "-c", "copy", output_path,
    ], capture_output=True)

    # 清理临时文件
    for sf in segment_files:
        os.remove(sf)
    os.remove(list_path)

    print(f"有声书已生成: {output_path}")
    return output_path


if __name__ == "__main__":
    sample_chapter = "第一章 初识人工智能。人工智能是计算机科学的一个分支。它试图理解智能的本质，并生产出一种新的能以人类智能相似方式做出反应的智能机器。这是一个充满挑战的领域。"
    asyncio.run(synthesize_audiobook(sample_chapter, "chapter01.mp3"))
```

**要点**：
- 长文本必须分段合成，一次性合成超过 500 字容易超时或失败
- 分段时按句子边界切割，不能按固定字数切割，否则会在句子中间断开导致不自然
- 拼接时可用 ffmpeg 的 concat 模式，也可用 pydub 库实现更精细的音频拼接
- 常见错误：不做文本预处理就直接合成，遇到特殊字符（如 `<`、`&`）会导致 SSML 解析错误
