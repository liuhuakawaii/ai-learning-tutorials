# 04 实时语音交互——构建一个语音对话的 AI 助手原型

> 语音交互是 AI 助手的终极形态。

## 场景引入

你要构建一个实时语音对话的 AI 助手原型：用户对着麦克风说话，系统实时识别语音、生成回答、再用语音播报出来。理想情况下用户说完到听到回复应该在 2 秒以内。但实际测试发现：Whisper 识别一段 5 秒的音频需要 3 秒，GPT-4o 生成回答又花了 2 秒，Edge-TTS 合成语音再要 1 秒——总延迟 6 秒，用户体验极差。实时语音交互的核心挑战不是功能实现，而是延迟优化。

## 学习目标

- 掌握实时语音交互的架构
- 理解 ASR → LLM → TTS 的流水线
- 学会构建语音对话系统

---

## 一、系统架构

```
语音交互系统：

用户语音 → ASR（语音识别）→ LLM（对话）→ TTS（语音合成）→ 语音输出
    │          │                │                │              │
    ▼          ▼                ▼                ▼              ▼
  麦克风    Whisper          GPT-4o          Edge-TTS        扬声器
```

## 二、核心实现

```python
class VoiceAssistant:
    """语音助手"""
    
    def __init__(self):
        self.asr_model = whisper.load_model("base")
        self.client = OpenAI()
        self.conversation = []
    
    def process_audio(self, audio_path: str) -> str:
        """处理语音输入"""
        # 1. 语音识别
        text = self.asr_model.transcribe(audio_path)["text"]
        
        # 2. 对话生成
        self.conversation.append({"role": "user", "content": text})
        response = self.client.chat.completions.create(
            model="gpt-4o",
            messages=self.conversation
        )
        reply = response.choices[0].message.content
        self.conversation.append({"role": "assistant", "content": reply})
        
        # 3. 语音合成
        audio_output = self._synthesize(reply)
        
        return audio_output
    
    def _synthesize(self, text: str) -> str:
        """语音合成"""
        # 使用 Edge-TTS
        asyncio.run(edge_tts.Communicate(text, "zh-CN-XiaoxiaoNeural").save("reply.mp3"))
        return "reply.mp3"
```

## 三、实时录音

```python
import pyaudio
import wave

def record_audio(duration: int = 5) -> str:
    """录音"""
    chunk = 1024
    format = pyaudio.paInt16
    channels = 1
    rate = 16000
    
    p = pyaudio.PyAudio()
    stream = p.open(format=format, channels=channels, rate=rate, input=True, frames_per_buffer=chunk)
    
    frames = []
    for _ in range(0, int(rate / chunk * duration)):
        data = stream.read(chunk)
        frames.append(data)
    
    stream.stop_stream()
    stream.close()
    p.terminate()
    
    output_path = "recording.wav"
    wf = wave.open(output_path, 'wb')
    wf.setnchannels(channels)
    wf.setsampwidth(p.get_sample_size(format))
    wf.setframerate(rate)
    wf.writeframes(b''.join(frames))
    wf.close()
    
    return output_path
```

async def stream_conversation(audio_stream):

    async for audio_chunk in audio_stream:

## 常见误区

1. **串行执行所有步骤**：ASR → LLM → TTS 串行执行导致总延迟累加，应该用流式处理，LLM 开始输出第一句话时就开始 TTS 合成。
2. **忽略端点检测（VAD）**：没有语音活动检测的话，系统不知道用户什么时候说完了，会导致误触发或等待超时。
3. **不做对话上下文管理**：每轮对话都当成独立请求处理，导致 AI 无法理解上下文，对话体验支离破碎。
4. **在 Web 端直接做 ASR**：浏览器端的语音识别能力有限且不稳定，关键的识别逻辑应该在服务端完成。

## 工程建议

1. **用流式 Pipeline 降低延迟**：ASR 流式输出文字 → LLM 流式生成回答 → TTS 流式合成语音，三步并行，感知延迟可降到 1 秒以内。
2. **集成 VAD（语音活动检测）**：用 WebRTC VAD 或 Silero VAD 检测用户说话的起止，避免静音等待和误触发。
3. **保持对话上下文**：维护 conversation history，控制在合理长度（如最近 10 轮），太长会增加 LLM 延迟和成本。
4. **做超时和降级处理**：ASR 超时返回"没听清"、LLM 超时返回默认回复、TTS 超时降级为文字输出，保证用户体验不中断。

### 练习一：构建一个语音对话系统

**思路**：实现 ASR → LLM → TTS 的完整 Pipeline，重点处理对话上下文管理和错误降级。

**答案**：

```python
"""语音对话系统：ASR → LLM → TTS 完整 Pipeline。"""
import whisper
import edge_tts
import asyncio
from openai import OpenAI


class VoiceChatSystem:
    """语音对话系统。

    架构：麦克风录音 → Whisper 识别 → GPT 对话 → Edge-TTS 合成 → 播放
    """

    def __init__(self, asr_model: str = "base", tts_voice: str = "zh-CN-XiaoxiaoNeural"):
        self.asr_model = whisper.load_model(asr_model)
        self.llm_client = OpenAI()
        self.tts_voice = tts_voice
        self.conversation_history = []
        self.max_history_turns = 10

    def recognize_speech(self, audio_path: str) -> str:
        """语音识别（ASR）。"""
        result = self.asr_model.transcribe(audio_path, language="zh")
        text = result["text"].strip()
        if not text:
            raise ValueError("未检测到有效语音内容")
        return text

    def generate_reply(self, user_text: str) -> str:
        """对话生成（LLM），维护上下文。"""
        self.conversation_history.append({"role": "user", "content": user_text})

        # 裁剪历史，避免上下文过长
        if len(self.conversation_history) > self.max_history_turns * 2:
            self.conversation_history = self.conversation_history[-self.max_history_turns * 2:]

        response = self.llm_client.chat.completions.create(
            model="gpt-4o",
            messages=[
                {"role": "system", "content": "你是一个友好的语音助手，回答简洁明了。"},
                *self.conversation_history,
            ],
        )
        reply = response.choices[0].message.content
        self.conversation_history.append({"role": "assistant", "content": reply})
        return reply

    async def synthesize_speech(self, text: str, output_path: str = "reply.mp3") -> str:
        """语音合成（TTS）。"""
        communicate = edge_tts.Communicate(text, self.tts_voice)
        await communicate.save(output_path)
        return output_path

    async def process_audio(self, audio_path: str) -> dict:
        """完整处理流程：识别 → 对话 → 合成。"""
        # 1. 语音识别
        user_text = self.recognize_speech(audio_path)
        print(f"[用户] {user_text}")

        # 2. 生成回复
        reply = self.generate_reply(user_text)
        print(f"[助手] {reply}")

        # 3. 语音合成
        audio_output = await self.synthesize_speech(reply)

        return {"user_text": user_text, "reply_text": reply, "audio_path": audio_output}


if __name__ == "__main__":
    system = VoiceChatSystem()
    result = asyncio.run(system.process_audio("user_input.wav"))
    print(f"回复音频: {result['audio_path']}")
```

**要点**：
- 对话历史必须做裁剪，否则上下文会越来越长导致 LLM 延迟增加和成本飙升
- ASR 失败（静音、噪音）时应返回"没听清，请再说一遍"，而不是把错误文本传给 LLM
- 每个环节都应该有超时处理，单个环节超时不应阻塞整个系统
- 常见错误：不做对话历史裁剪，20 轮对话后 token 消耗暴增，响应延迟明显增大

### 练习二：实现实时录音功能

**思路**：用 pyaudio 实现麦克风录音，支持指定时长和 VAD（语音活动检测）自动停止。

**答案**：

```python
"""实时录音功能：支持固定时长录音和 VAD 自动停止。"""
import pyaudio
import wave
import numpy as np


def record_audio_fixed_duration(duration_seconds: int = 5, output_path: str = "recording.wav") -> str:
    """固定时长录音。"""
    chunk = 1024
    audio_format = pyaudio.paInt16
    channels = 1
    rate = 16000

    p = pyaudio.PyAudio()
    stream = p.open(
        format=audio_format,
        channels=channels,
        rate=rate,
        input=True,
        frames_per_buffer=chunk,
    )

    print(f"开始录音（{duration_seconds} 秒）...")
    frames = []
    for _ in range(0, int(rate / chunk * duration_seconds)):
        data = stream.read(chunk, exception_on_overflow=False)
        frames.append(data)

    stream.stop_stream()
    stream.close()
    p.terminate()

    with wave.open(output_path, "wb") as wf:
        wf.setnchannels(channels)
        wf.setsampwidth(p.get_sample_size(audio_format))
        wf.setframerate(rate)
        wf.writeframes(b"".join(frames))

    print(f"录音已保存: {output_path}")
    return output_path


def record_with_vad(
    silence_threshold: float = 500,
    max_silence_seconds: float = 2.0,
    max_duration: int = 30,
    output_path: str = "vad_recording.wav",
) -> str:
    """带 VAD 的录音：检测到静音自动停止。

    Args:
        silence_threshold: 静音阈值（音量低于此值视为静音）
        max_silence_seconds: 最大连续静音时长（秒），超过则停止录音
        max_duration: 最大录音时长（秒）
    """
    chunk = 1024
    rate = 16000
    p = pyaudio.PyAudio()
    stream = p.open(
        format=pyaudio.paInt16,
        channels=1,
        rate=rate,
        input=True,
        frames_per_buffer=chunk,
    )

    frames = []
    silent_chunks = 0
    chunks_per_second = rate / chunk
    max_silent_chunks = int(max_silence_seconds * chunks_per_second)
    max_total_chunks = int(max_duration * chunks_per_second)

    print("等待语音输入...")
    recording_started = False

    for _ in range(max_total_chunks):
        data = stream.read(chunk, exception_on_overflow=False)
        audio_data = np.frombuffer(data, dtype=np.int16)
        volume = np.abs(audio_data).mean()

        if volume > silence_threshold:
            recording_started = True
            silent_chunks = 0
            frames.append(data)
        elif recording_started:
            silent_chunks += 1
            frames.append(data)
            if silent_chunks >= max_silent_chunks:
                print("检测到静音，停止录音")
                break

    stream.stop_stream()
    stream.close()
    p.terminate()

    if not frames:
        raise RuntimeError("未检测到有效语音")

    with wave.open(output_path, "wb") as wf:
        wf.setnchannels(1)
        wf.setsampwidth(p.get_sample_size(pyaudio.paInt16))
        wf.setframerate(rate)
        wf.writeframes(b"".join(frames))

    print(f"录音已保存: {output_path}")
    return output_path


if __name__ == "__main__":
    record_audio_fixed_duration(5, "fixed_recording.wav")
    # record_with_vad(output_path="vad_recording.wav")
```

**要点**：
- 采样率必须设为 16000Hz，这是 Whisper 要求的输入格式，不匹配会导致识别失败
- `exception_on_overflow=False` 可防止缓冲区溢出导致的异常，生产环境必须加
- VAD 阈值需要根据实际环境调整，太灵敏会录到环境噪音，太迟钝会截掉开头的语音
- 常见错误：录音结束后忘记关闭 stream 和 terminate PyAudio，导致设备被占用无法再次录音

### 练习三：用 Gradio 创建语音聊天界面

**思路**：用 Gradio 搭建 Web 界面，支持麦克风录音输入和语音回复输出，集成完整的语音对话 Pipeline。

**答案**：

```python
"""基于 Gradio 的语音聊天 Web 界面。"""
import gradio as gr
import asyncio
from voice_chat_system import VoiceChatSystem


system = VoiceChatSystem(asr_model="base", tts_voice="zh-CN-XiaoxiaoNeural")


async def voice_chat(audio_filepath: str) -> tuple:
    """处理语音输入并返回文字和语音回复。"""
    if audio_filepath is None:
        return "未检测到音频输入", None

    try:
        result = await system.process_audio(audio_filepath)
        return result["reply_text"], result["audio_path"]
    except ValueError as e:
        return f"识别失败: {str(e)}", None
    except Exception as e:
        return f"处理出错: {str(e)}", None


def reset_conversation():
    """重置对话历史。"""
    system.conversation_history.clear()
    return "对话已重置"


with gr.Blocks(title="语音对话助手") as demo:
    gr.Markdown("# 语音对话助手")
    gr.Markdown("点击麦克风按钮录音，系统会识别你的语音并用语音回复。")

    with gr.Row():
        with gr.Column():
            audio_input = gr.Audio(sources="microphone", type="filepath", label="语音输入")
            submit_btn = gr.Button("发送", variant="primary")
            reset_btn = gr.Button("重置对话")

        with gr.Column():
            text_output = gr.Textbox(label="AI 回复", lines=3)
            audio_output = gr.Audio(type="filepath", label="语音回复")

    submit_btn.click(
        fn=voice_chat,
        inputs=audio_input,
        outputs=[text_output, audio_output],
    )
    reset_btn.click(fn=reset_conversation, outputs=text_output)

if __name__ == "__main__":
    demo.launch(server_name="0.0.0.0", server_port=7860)
```

**要点**：
- Gradio 的 `gr.Audio(sources="microphone")` 会自动处理浏览器录音，无需手动实现 WebRTC
- 异步函数需要在 Gradio 中正确处理，Gradio 支持 async handler
- 必须做错误处理，录音为空、识别失败、TTS 超时等异常不能让界面崩溃
- 常见错误：在 `fn` 中直接用 `asyncio.run()` 调用异步函数，Gradio 已有事件循环会导致冲突，应该直接用 async def
