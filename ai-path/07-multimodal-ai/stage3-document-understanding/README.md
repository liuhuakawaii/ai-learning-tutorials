# 第 3 阶段：文档理解

> 让 AI 处理复杂的非结构化文档

## 学习目标

- 了解文档处理的核心挑战（PDF / Word / 扫描件 / 表格）
- 掌握 Unstructured / Docling 等文档解析工具的使用
- 学会从复杂文档中提取结构化数据（表格、表单、关键字段）
- 能够构建基于文档的智能问答系统

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 文档处理概览 — PDF / Word / 扫描件 / 表格的处理挑战 | 2h |
| 02 | 文档解析 — Unstructured / Docling 的文档拆分与结构化 | 3h |
| 03 | 表格提取 — 从 PDF 和图片中提取结构化表格数据 | 3h |
| 04 | 长文档处理 — 大文档的分块策略与上下文管理 | 3h |
| 05 | 文档问答 — 基于文档内容的智能问答系统 | 3h |
| 06 | 阶段实战：构建一个合同/发票智能解析系统 | 4h |

## 验收标准

- [ ] 能解析 PDF / Word / 扫描件并提取结构化内容
- [ ] 表格提取准确率在标准文档上达到 90%+
- [ ] 合同/发票解析系统能自动提取关键字段
