# 03 表格提取——从 PDF 和图片中提取结构化表格数据

> 表格是文档中最重要的结构化数据。

## 场景引入

你的公司财务部门需要从数百份 PDF 格式的发票和报表中提取表格数据，手动复制粘贴到 Excel 中不仅耗时（一份复杂报表需要 30 分钟），而且经常出错。你想用 AI 自动化表格提取，但测试后发现：PDF 中的表格线条有时是图片而非矢量、合并单元格的处理非常棘手、扫描件中的表格 OCR 后行列对不齐、嵌套表头的结构识别困难——表格提取是文档处理中公认的技术难题。

## 学习目标

- 掌握表格提取的方法
- 理解表格识别和结构化
- 学会处理各种表格格式

## 一、PDF 表格提取

```python
from unstructured.partition.pdf import partition_pdf

def extract_tables_from_pdf(pdf_path: str) -> list:
    """从 PDF 提取表格"""
    elements = partition_pdf(pdf_path, strategy="hi_res")
    
    tables = []
    for element in elements:
        if element.category == "Table":
            tables.append(element.text)
    
    return tables
```

## 三、表格解析

```python
import pandas as pd

def parse_table(table_text: str) -> pd.DataFrame:
    """解析表格"""
    # 使用 pandas 解析
    lines = table_text.strip().split("\n")
    headers = lines[0].split("\t")
    
    data = []
    for line in lines[1:]:
        row = line.split("\t")
        data.append(row)
    
    return pd.DataFrame(data, columns=headers)
```

## 四、表格增强

```python
def enhance_table(table: pd.DataFrame) -> pd.DataFrame:
    """增强表格"""
    # 清洗数据
    table = table.dropna(how="all")
    
    # 转换类型
    for col in table.columns:
        try:
            table[col] = pd.to_numeric(table[col])
        except:
            pass
    
    return table
```

## 五、批量处理

```python
def batch_table_extraction(pdf_paths: list) -> dict:
    """批量表格提取"""
    results = {}
    
    for path in pdf_paths:
        tables = extract_tables_from_pdf(path)
        results[path] = tables
    
    return results
```

## 常见误区

1. **认为所有 PDF 表格都能自动提取**：表格以图片形式存在时，传统 PDF 解析工具无法识别，需要用 OCR 或 Vision API 处理。
2. **忽略合并单元格和跨行跨列**：真实报表中大量存在合并单元格，简单的行列解析会导致数据错位，需要专门的合并单元格处理逻辑。
3. **不做数据类型转换**：提取出来的表格数据全是字符串，金额字段的逗号、日期字段的格式都需要做类型转换和清洗。
4. **一次性处理整页大图**：整页表格图片分辨率高且包含非表格区域，先裁剪表格区域再识别效果更好。

## 工程建议

1. **区分矢量表格和图片表格**：矢量 PDF 用 camelot 或 tabula 提取，图片表格用 Vision API 或专门的表格识别模型。
2. **用 pandas 做后处理**：提取后的原始数据用 pandas 做数据清洗、类型转换、去重、格式标准化，输出干净的 DataFrame。
3. **建立表格结构验证**：检查行列数是否一致、是否有空行空列、数据类型是否符合预期，自动发现和修复常见问题。
4. **保留表格位置信息**：存储时记录表格在文档中的页码和位置，方便后续溯源和人工复核。

### 练习一：从一个 PDF 中提取表格

**思路**：区分矢量表格和图片表格，分别用不同方案提取，统一输出为文本格式。

**答案**：

```python
"""从 PDF 中提取表格，支持矢量和图片两种类型。"""
from unstructured.partition.pdf import partition_pdf
from openai import OpenAI
import base64


def extract_tables_from_pdf(pdf_path: str) -> list:
    """从 PDF 提取所有表格。"""
    elements = partition_pdf(pdf_path, strategy="hi_res")

    tables = []
    for i, element in enumerate(elements):
        if element.category == "Table":
            tables.append({
                "index": i,
                "text": element.text,
                "extraction_method": "unstructured",
            })

    if not tables:
        print("未检测到矢量表格，尝试用 Vision API 提取图片表格...")
        tables = extract_tables_with_vision(pdf_path)

    return tables


def extract_tables_with_vision(pdf_path: str) -> list:
    """用 Vision API 从扫描件 PDF 中提取表格。"""
    import fitz  # PyMuPDF

    doc = fitz.open(pdf_path)
    client = OpenAI()
    tables = []

    for page_num in range(len(doc)):
        page = doc[page_num]
        pix = page.get_pixmap(dpi=200)
        img_bytes = pix.tobytes("png")
        img_b64 = base64.b64encode(img_bytes).decode()

        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[
                {
                    "role": "user",
                    "content": [
                        {
                            "type": "text",
                            "text": "请提取这张图片中的所有表格，以 JSON 数组格式输出。每个表格包含 headers（表头数组）和 rows（数据二维数组）。如果没有表格返回空数组。",
                        },
                        {
                            "type": "image_url",
                            "image_url": {"url": f"data:image/png;base64,{img_b64}"},
                        },
                    ],
                }
            ],
            response_format={"type": "json_object"},
        )

        import json
        result = json.loads(response.choices[0].message.content)
        if result.get("tables"):
            for table in result["tables"]:
                tables.append({
                    "page": page_num + 1,
                    "headers": table.get("headers", []),
                    "rows": table.get("rows", []),
                    "extraction_method": "vision_api",
                })

    return tables


if __name__ == "__main__":
    tables = extract_tables_from_pdf("financial_report.pdf")
    print(f"共提取 {len(tables)} 个表格")
    for t in tables:
        print(f"  表格 {t.get('index', t.get('page'))}: {t['text'][:100]}...")
```

**要点**：
- 矢量 PDF 的表格线条是可编辑的，用 Unstructured 的 `strategy="hi_res"` 可直接识别
- 扫描件 PDF 的表格是图片，必须用 OCR 或 Vision API，传统 PDF 解析工具无法识别
- Vision API 的表格提取准确率约 85-90%，合并单元格和复杂表头仍是难点
- 常见错误：对所有 PDF 都用同一种方案，扫描件用矢量方案结果为空，矢量用 OCR 方案浪费资源且可能引入 OCR 错误

### 练习二：将提取的表格转换为 DataFrame

**思路**：解析表格文本为 pandas DataFrame，处理分隔符、表头、数据类型等细节。

**答案**：

```python
"""将提取的表格文本转换为 pandas DataFrame。"""
import pandas as pd
import re


def table_text_to_dataframe(table_text: str) -> pd.DataFrame:
    """将表格文本解析为 DataFrame。

    支持 Tab 分隔、空格对齐、Markdown 表格三种格式。
    """
    lines = [line.strip() for line in table_text.strip().split("\n") if line.strip()]

    if not lines:
        raise ValueError("表格内容为空")

    # 检测格式
    if "|" in lines[0]:
        return _parse_markdown_table(lines)
    elif "\t" in lines[0]:
        return _parse_tsv_table(lines)
    else:
        return _parse_space_aligned_table(lines)


def _parse_markdown_table(lines: list) -> pd.DataFrame:
    """解析 Markdown 格式的表格。"""
    data_lines = [line for line in lines if not re.match(r"^\|[-\s|]+\|$", line)]

    rows = []
    for line in data_lines:
        cells = [cell.strip() for cell in line.strip("|").split("|")]
        rows.append(cells)

    if len(rows) < 2:
        raise ValueError("表格至少需要表头和一行数据")

    headers = rows[0]
    data = rows[1:]

    # 对齐列数
    max_cols = max(len(headers), max(len(row) for row in data))
    headers.extend([""] * (max_cols - len(headers)))
    for row in data:
        row.extend([""] * (max_cols - len(row)))

    return pd.DataFrame(data, columns=headers)


def _parse_tsv_table(lines: list) -> pd.DataFrame:
    """解析 Tab 分隔的表格。"""
    headers = lines[0].split("\t")
    data = [line.split("\t") for line in lines[1:]]
    return pd.DataFrame(data, columns=headers)


def _parse_space_aligned_table(lines: list) -> pd.DataFrame:
    """解析空格对齐的表格（启发式方法）。"""
    rows = []
    for line in lines:
        cells = re.split(r"\s{2,}", line)
        rows.append(cells)

    headers = rows[0]
    data = rows[1:]

    max_cols = max(len(headers), max(len(row) for row in data))
    headers.extend([""] * (max_cols - len(headers)))
    for row in data:
        row.extend([""] * (max_cols - len(row)))

    return pd.DataFrame(data, columns=headers)


if __name__ == "__main__":
    # 测试 Markdown 表格
    md_table = """| 姓名 | 年龄 | 部门 |
|------|------|------|
| 张三 | 28 | 技术部 |
| 李四 | 32 | 产品部 |
| 王五 | 25 | 设计部 |"""

    df = table_text_to_dataframe(md_table)
    print(df)
    print(f"\n数据类型:\n{df.dtypes}")
```

**要点**：
- PDF 提取出来的表格格式不统一，可能是 Tab 分隔、空格对齐或 Markdown，需要做格式检测
- 列数不一致是最常见的问题（合并单元格导致），必须做列数对齐
- 提取出来的数据全是字符串，金额字段可能包含逗号（如"1,234.56"），需要清洗后转数值
- 常见错误：直接用 `pd.read_csv()` 解析表格文本，遇到非标准分隔符会失败

### 练习三：清洗和增强表格数据

**思路**：对提取的 DataFrame 做数据清洗（去空行、类型转换、格式标准化）和质量验证。

**答案**：

```python
"""表格数据清洗和增强。"""
import pandas as pd
import re


def enhance_table(df: pd.DataFrame) -> pd.DataFrame:
    """清洗和增强表格数据。"""
    df = df.copy()

    # 1. 去除全空行和全空列
    df = df.dropna(how="all")
    df = df.loc[:, ~(df == "").all()]

    # 2. 清洗单元格内容
    for col in df.columns:
        df[col] = df[col].astype(str).str.strip()
        df[col] = df[col].replace(["nan", "None", "null", ""], pd.NA)

    # 3. 尝试自动转换数据类型
    for col in df.columns:
        df[col] = _try_convert_column(df[col])

    # 4. 去除重复行
    df = df.drop_duplicates()

    # 5. 重置索引
    df = df.reset_index(drop=True)

    return df


def _try_convert_column(series: pd.Series) -> pd.Series:
    """尝试将列转换为合适的数值类型。"""
    # 尝试整数
    try:
        cleaned = series.str.replace(",", "", regex=False)
        return pd.to_numeric(cleaned, errors="raise").astype("Int64")
    except (ValueError, AttributeError):
        pass

    # 尝试浮点数
    try:
        cleaned = series.str.replace(",", "", regex=False)
        cleaned = cleaned.str.replace("%", "", regex=False)
        return pd.to_numeric(cleaned, errors="raise")
    except (ValueError, AttributeError):
        pass

    # 尝试日期
    try:
        return pd.to_datetime(series, errors="raise", format="mixed")
    except (ValueError, TypeError):
        pass

    return series


def validate_table(df: pd.DataFrame) -> dict:
    """验证表格数据质量。"""
    issues = []

    # 检查空值比例
    null_ratio = df.isnull().sum() / len(df)
    for col, ratio in null_ratio.items():
        if ratio > 0.5:
            issues.append(f"列 '{col}' 空值比例 {ratio:.0%}，数据可能不完整")

    # 检查列数据类型一致性
    for col in df.columns:
        if df[col].dtype == object:
            unique_types = set(type(v).__name__ for v in df[col].dropna())
            if len(unique_types) > 1:
                issues.append(f"列 '{col}' 包含混合类型: {unique_types}")

    return {
        "row_count": len(df),
        "col_count": len(df.columns),
        "null_summary": df.isnull().sum().to_dict(),
        "dtypes": df.dtypes.astype(str).to_dict(),
        "issues": issues,
    }


if __name__ == "__main__":
    # 模拟一个有质量问题的表格
    raw_data = {
        "姓名": ["张三", "李四", "", "王五", "张三"],
        "工资": ["15,000", "18,500", "N/A", "22,000", "15,000"],
        "入职日期": ["2023-01-15", "2022-06-20", "", "2024-03-01", "2023-01-15"],
    }
    df = pd.DataFrame(raw_data)

    print("=== 清洗前 ===")
    print(df)

    cleaned = enhance_table(df)

    print("\n=== 清洗后 ===")
    print(cleaned)
    print(f"\n数据类型:\n{cleaned.dtypes}")

    report = validate_table(cleaned)
    print(f"\n质量报告: {report}")
```

**要点**：
- 金额字段的逗号（"15,000"）必须先去除再转数值，否则 `pd.to_numeric` 会失败
- 空值处理要区分"缺失"（NA）和"无效"（N/A、null 字符串），统一后再分析
- 日期格式不统一（"2023-01-15" vs "2023/1/15"）需要用 `format="mixed"` 或指定多种格式尝试
- 常见错误：直接对整个 DataFrame 做类型转换，遇到非标准格式就报错，应该逐列尝试转换并捕获异常
