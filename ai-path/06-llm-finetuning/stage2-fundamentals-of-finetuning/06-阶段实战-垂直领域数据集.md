# 06 阶段实战——为一个垂直领域构造微调数据集

> 从原始数据到可直接用于 LoRA 微调的数据集。

你负责为公司的法律咨询 AI 构建训练数据集。法律条文散落在各处——PDF 扫描件、网页 HTML、数据库记录。你需要从这些异构数据中提取问答对，清洗去重，检查质量，最终输出一个可以直接用于微调的数据集。

这不是一个脚本能搞定的事。你需要一个系统化的流程。

---

## 数据集长什么样

LoRA 微调通常用 instruction-following 格式：

```json
{
  "instruction": "劳动合同到期后，用人单位不续签需要支付经济补偿吗？",
  "input": "",
  "output": "根据《劳动合同法》第四十六条，除用人单位维持或者提高劳动合同约定条件续订劳动合同，劳动者不同意续订的情形外，劳动合同期满终止固定期限劳动合同的，用人单位应当向劳动者支付经济补偿。补偿标准按劳动者在本单位工作的年限，每满一年支付一个月工资。"
}
```

关键点：
- `instruction` 是用户的问题
- `output` 是期望模型给出的回答
- `input` 可选，用于补充上下文

## Step 1：收集原始数据

法律领域的数据来源：

```python
import json
from pathlib import Path

def collect_legal_data() -> list[dict]:
    """从多个来源收集法律数据"""
    all_data = []

    # 来源 1：公开法律问答数据集
    with open("legal_qa_raw.json") as f:
        qa_data = json.load(f)
        all_data.extend(qa_data)
    print(f"法律问答: {len(qa_data)} 条")

    # 来源 2：法律法规条文（结构化数据）
    for file in Path("law_articles").glob("*.json"):
        with open(file) as f:
            articles = json.load(f)
            all_data.extend(articles)
    print(f"法律条文: {len(list(Path('law_articles').glob('*.json')))} 个文件")

    # 来源 3：法律咨询网站（需要清洗）
    with open("legal_consultations.json") as f:
        consultations = json.load(f)
        all_data.extend(consultations)
    print(f"法律咨询: {len(consultations)} 条")

    return all_data

raw_data = collect_legal_data()
print(f"总计: {len(raw_data)} 条原始数据")
```

## Step 2：清洗数据

原始数据通常很脏——空值、乱码、重复、格式不统一：

```python
def clean_legal_data(data: list[dict]) -> list[dict]:
    """清洗法律数据"""
    cleaned = []

    for item in data:
        # 跳过空值
        if not item.get("question") or not item.get("answer"):
            continue

        q = item["question"].strip()
        a = item["answer"].strip()

        # 跳过太短的（可能是噪声）
        if len(q) < 5 or len(a) < 20:
            continue

        # 跳过太长的（可能是整篇文章）
        if len(a) > 2000:
            continue

        # 清理 HTML 标签
        import re
        q = re.sub(r"<[^>]+>", "", q)
        a = re.sub(r"<[^>]+>", "", a)

        cleaned.append({
            "instruction": q,
            "input": "",
            "output": a,
        })

    return cleaned

cleaned_data = clean_legal_data(raw_data)
print(f"清洗后: {len(cleaned_data)} 条 (丢弃 {len(raw_data) - len(cleaned_data)} 条)")
```

---

## Step 3：去重

重复数据会让模型过拟合到特定问题上：

```python
def deduplicate(data: list[dict]) -> list[dict]:
    """按 instruction 去重"""
    seen = set()
    unique = []

    for item in data:
        key = item["instruction"].strip().lower()
        if key not in seen:
            seen.add(key)
            unique.append(item)

    return unique

unique_data = deduplicate(cleaned_data)
print(f"去重后: {len(unique_data)} 条 (去除 {len(cleaned_data) - len(unique_data)} 条重复)")
```

## Step 4：用 LLM 辅助构造数据

如果你的原始数据不是问答格式（比如是法律条文），可以用 LLM 把它转成问答对：

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="not-needed")

def generate_qa_from_article(article: str, num_questions: int = 3) -> list[dict]:
    """从法律条文生成问答对"""
    prompt = f"""基于以下法律条文，生成 {num_questions} 个问答对。

要求：
1. 问题应该是普通人会问的实际问题
2. 回答应该准确引用条文内容，用通俗语言解释
3. 输出 JSON 数组格式

法律条文：
{article}

输出格式：
[{{"instruction": "问题", "output": "回答"}}]"""

    resp = client.chat.completions.create(
        model="qwen2.5:7b",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},
    )

    try:
        return json.loads(resp.choices[0].message.content)
    except json.JSONDecodeError:
        return []

# 示例：从条文生成问答
article = "《劳动合同法》第四十七条：经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。"

qa_pairs = generate_qa_from_article(article)
print(json.dumps(qa_pairs, ensure_ascii=False, indent=2))
```

生成的数据必须人工审核。LLM 可能编造不存在的法律条文。

## Step 5：质量检查

```python
def check_quality(data: list[dict]) -> dict:
    """数据质量检查"""
    issues = []

    for i, item in enumerate(data):
        q = item["instruction"]
        a = item["output"]

        # 检查长度分布
        if len(a) < 30:
            issues.append(f"样本 {i}: 回答太短 ({len(a)} 字)")

        # 检查是否有乱码
        if any(ord(c) > 0xFFFF for c in q + a):
            issues.append(f"样本 {i}: 可能包含乱码")

        # 检查是否包含 HTML
        if "<" in q and ">" in q:
            issues.append(f"样本 {i}: question 包含 HTML 标签")

    # 统计
    q_lengths = [len(item["instruction"]) for item in data]
    a_lengths = [len(item["output"]) for item in data]

    return {
        "total": len(data),
        "issues": issues[:20],  # 只显示前 20 个
        "avg_question_len": sum(q_lengths) / len(q_lengths),
        "avg_answer_len": sum(a_lengths) / len(a_lengths),
    }

quality = check_quality(unique_data)
print(f"总样本: {quality['total']}")
print(f"平均问题长度: {quality['avg_question_len']:.0f} 字")
print(f"平均回答长度: {quality['avg_answer_len']:.0f} 字")
print(f"问题数: {len(quality['issues'])}")
for issue in quality["issues"]:
    print(f"  {issue}")
```

## Step 6：拆分训练集和评估集

```python
import random

def split_dataset(data: list[dict], eval_ratio: float = 0.1) -> tuple[list, list]:
    """拆分训练集和评估集"""
    random.seed(42)
    shuffled = data.copy()
    random.shuffle(shuffled)

    split_idx = int(len(shuffled) * (1 - eval_ratio))
    train_data = shuffled[:split_idx]
    eval_data = shuffled[split_idx:]

    return train_data, eval_data

train_data, eval_data = split_dataset(unique_data)
print(f"训练集: {len(train_data)} 条")
print(f"评估集: {len(eval_data)} 条")

# 保存
with open("legal_train.json", "w") as f:
    json.dump(train_data, f, ensure_ascii=False, indent=2)

with open("legal_eval.json", "w") as f:
    json.dump(eval_data, f, ensure_ascii=False, indent=2)
```

评估集应该是独立收集的，不是从训练集中随机拆分。但作为起步，随机拆分是可以接受的。

## 完整 Pipeline

把上面的步骤串起来：

```python
def build_legal_dataset():
    """完整的法律数据集构建流程"""

    # 1. 收集
    raw_data = collect_legal_data()
    print(f"Step 1: 收集 {len(raw_data)} 条原始数据")

    # 2. 清洗
    cleaned = clean_legal_data(raw_data)
    print(f"Step 2: 清洗后 {len(cleaned)} 条")

    # 3. 去重
    unique = deduplicate(cleaned)
    print(f"Step 3: 去重后 {len(unique)} 条")

    # 4. 质量检查
    quality = check_quality(unique)
    print(f"Step 4: 质量检查 - {len(quality['issues'])} 个问题")

    # 5. 拆分
    train, eval_data = split_dataset(unique)
    print(f"Step 5: 训练集 {len(train)} 条, 评估集 {len(eval_data)} 条")

    # 6. 保存
    with open("legal_train.json", "w") as f:
        json.dump(train, f, ensure_ascii=False, indent=2)
    with open("legal_eval.json", "w") as f:
        json.dump(eval_data, f, ensure_ascii=False, indent=2)
    print("Step 6: 数据集已保存")

build_legal_dataset()
```

## 容易犯的错

**数据收集不考虑版权**。从网上爬取的数据可能有版权问题。优先使用公开数据集或获得授权的数据源。

**LLM 生成的数据不审核直接用**。LLM 可能编造法律条文。每条生成的数据都必须经过领域专家审核。

**评估集从训练集中拆分后就认为没问题**。更好的做法是独立收集评估集。随机拆分只是起步方案。

**数据集构建完就不更新**。领域知识会演进，数据集也需要定期更新。

```python
def augment_data(data: list[dict], augmentation_factor: int = 2) -> list[dict]:
    """数据增强：对每个样本生成多个变体"""
    augmented = []

    for item in data:
        augmented.append(item)  # 保留原始数据

        for _ in range(augmentation_factor):
            prompt = f"""请用不同的方式重写以下问题，保持含义不变，但改变表达方式。

原始问题：{item['instruction']}

只输出重写后的问题，不要其他内容。"""

            resp = client.chat.completions.create(
                model="qwen2.5:7b",
                messages=[{"role": "user", "content": prompt}],
            )

            new_question = resp.choices[0].message.content.strip()
            if new_question and new_question != item["instruction"]:
                augmented.append({
                    "instruction": new_question,
                    "input": item.get("input", ""),
                    "output": item["output"],
                })

    return augmented
```

## 参考答案

### 练习一

关键点：
- 数据来源要多样化，不要只从一个地方收集
- 清洗规则要根据你的数据特点定制（法律数据和代码数据的清洗规则不同）
- 保留清洗日志，方便排查问题

### 练习二

数据增强的注意事项：
- 增强后要验证新问题和原始答案的匹配度
- 不要过度增强——2-3 倍就够了，太多会引入噪声
- 常见错误：增强后不检查质量，把 LLM 生成的错误变体也混入数据集

### 练习三

质量检查应该输出结构化报告，而不是只打印 "OK"。报告应该包含：
- 每个维度的检查结果
- 异常样本的具体位置
- 改进建议
