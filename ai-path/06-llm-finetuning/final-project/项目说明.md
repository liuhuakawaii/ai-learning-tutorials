# LoRA Fine-tuning Kit 项目说明

## 项目目标

选择一个垂直领域，完成完整的微调流程：数据收集 → 数据清洗 → LoRA 微调 → 评估对比 → 量化导出 → 部署上线，产出评估报告和部署文档。本 kit 提供训练 pipeline 骨架和示例数据集，学员可在有 GPU 的环境中直接运行。

## 内置 project kit

```text
06-llm-finetuning-course/final-project/lora-finetuning-kit
```

运行：

```bash
cd 06-llm-finetuning-course/final-project/lora-finetuning-kit
pip install -r requirements.txt
python scripts/check.py
python src/prepare_data.py
python src/train_lora.py --config configs/lora_config.yaml
python src/evaluate.py
python src/export_gguf.py
```

## 核心功能

1. 数据 Pipeline
   - 示例数据集（法律问答 / 电商客服 / 代码生成，三选一）
   - 数据清洗脚本（去重、格式校验、质量过滤）
   - Alpaca / ShareGPT 格式转换

2. LoRA 训练
   - 基于 PEFT + TRL 的训练脚本
   - YAML 配置文件管理超参数
   - QLoRA 4-bit 量化训练支持
   - 训练中断恢复

3. 评估系统
   - 通用基准：MMLU 子集
   - 领域评估：自定义 eval dataset
   - 对比评估：base model vs finetuned vs API

4. 模型导出
   - LoRA 权重合并
   - GGUF 格式导出（llama.cpp 兼容）
   - 量化级别选择（Q4/Q5/Q8）

5. 部署
   - Ollama 一键部署脚本
   - OpenAI 兼容 API 启动
   - Docker 容器化

## 验收标准

- `python scripts/check.py` 通过
- 数据清洗脚本能处理示例数据集
- LoRA 训练脚本能正常运行（需 GPU 环境）
- 评估脚本能输出 base vs finetuned 对比
- GGUF 导出能在 Ollama 中加载
- 部署脚本能启动 OpenAI 兼容 API
