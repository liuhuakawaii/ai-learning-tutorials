## 场景引入

你的微调模型在 MMLU 上比基座模型低了 2 分，是不是微调失败了？不一定。你微调的是医疗问答模型，而 MMLU 测的是通用知识。微调让模型在医疗领域变得更强，但通用能力略有下降，这是正常的"遗忘"现象。你需要一套领域专属的评估方案，用你的业务数据来衡量微调是否真正达到了目标。

## 二、评估指标

```
领域评估指标：

1. 准确率（Accuracy）
   - 回答是否正确
   - 适用于有标准答案的任务

2. 相关性（Relevancy）
   - 回答是否切题
   - 适用于开放性任务

3. 完整性（Completeness）
   - 回答是否完整
   - 适用于知识性任务

4. 专业性（Professionalism）
   - 回答是否专业
   - 适用于专业领域

5. 安全性（Safety）
   - 回答是否安全
   - 适用于医疗、法律等领域
```

## 三、自动评估

```python
def evaluate_domain(model, eval_dataset: list) -> dict:
    """领域评估"""
    
    results = {
        "accuracy": 0,
        "relevancy": 0,
        "completeness": 0
    }
    
    for sample in eval_dataset:
        # 生成回答
        answer = generate_answer(model, sample["question"])
        
        # 评估
        results["accuracy"] += check_accuracy(answer, sample["reference"])
        results["relevancy"] += check_relevancy(answer, sample["question"])
        results["completeness"] += check_completeness(answer, sample["reference"])
    
    # 计算平均值
    for key in results:
        results[key] /= len(eval_dataset)
    
    return results
```

def human_evaluation(eval_dataset: list, model) -> dict:

## 常见误区

1. **评估集从训练数据中随机拆分**：这样会导致数据泄漏——模型可能在训练时见过类似的样本，评估结果虚高。评估集必须是独立收集的。

2. **评估指标选错**：分类任务用准确率，生成任务用 BLEU/ROUGE，问答任务用 F1。选错指标会导致评估结果没有参考价值。

3. **评估集太小没有统计意义**：20 条测试样本的评估结果波动很大，可能因为几条样本的变化就差 10%。评估集至少需要 50-100 条样本。

4. **只做自动评估不做人工评估**：自动评估能检查准确性，但回答的流畅度、专业性、安全性需要人工评估。两种评估应该结合使用。

---

## 工程建议

1. **评估集要覆盖难度分布**：简单、中等、困难问题都要有，比例要和业务场景匹配。全用简单问题会高估模型能力，全用困难问题会低估。

2. **评估流程要可复现**：评估脚本、测试数据、评估指标都要版本化，确保不同时间做的评估结果可以对比。

3. **用 LLM-as-Judge 做自动评估**：对于开放性问答，可以用 GPT-4 等强模型作为"裁判"评估回答质量。比简单的字符串匹配更准确。

4. **评估结果要分维度分析**：不要只看总分，要分维度（如按问题类型、按难度级别）分析，找到模型的薄弱环节，指导后续优化方向。

### 练习一：数据集题

**思路**：领域评估数据集必须独立于训练数据，覆盖不同难度和类别，并包含标准答案作为评估基准。

**答案**：
```python
import json
import random
from dataclasses import dataclass, asdict
from typing import Literal

@dataclass
class EvalSample:
    id: str
    question: str
    reference: str
    category: str
    difficulty: Literal["easy", "medium", "hard"]


def create_medical_eval_dataset(size: int = 100) -> list[dict]:
    """创建医疗问答领域评估数据集"""
    
    # 定义类别和对应的问题模板
    categories = {
        "诊断": {
            "easy": [
                {"q": "患者出现发热、咳嗽、乏力，最可能的诊断是什么？", "a": "上呼吸道感染，需进一步检查排除流感和新冠"},
                {"q": "血压 150/95 mmHg 属于什么级别？", "a": "1级高血压（收缩压140-159或舒张压90-99）"},
            ],
            "medium": [
                {"q": "患者胸痛、呼吸困难、D-二聚体升高，应考虑哪些鉴别诊断？", "a": "肺栓塞、急性冠脉综合征、主动脉夹层，需做CTPA和心电图鉴别"},
            ],
            "hard": [
                {"q": "患者同时有糖尿病、高血压和肾功能不全，降压方案如何选择？", "a": "首选ACEI/ARB类药物（如贝那普利），兼顾降压和肾脏保护，需监测血钾和肌酐"},
            ]
        },
        "用药": {
            "easy": [
                {"q": "阿莫西林的常见不良反应有哪些？", "a": "过敏反应（皮疹）、胃肠道反应（腹泻、恶心）、罕见伪膜性肠炎"},
            ],
            "medium": [
                {"q": "华法林和新型口服抗凝药（如利伐沙班）各有什么优缺点？", "a": "华法林便宜但需频繁监测INR，食物药物相互作用多；利伐沙班无需监测但价格高，肾功能不全需调整剂量"},
            ],
            "hard": []
        }
    }
    
    dataset = []
    sample_id = 0
    
    # 按难度比例分配：简单40%、中等40%、困难20%
    difficulty_distribution = {"easy": 0.4, "medium": 0.4, "hard": 0.2}
    
    for category, difficulties in categories.items():
        for difficulty, questions in difficulties.items():
            if not questions:
                continue
            count = max(1, int(size * difficulty_distribution[difficulty] / len(categories)))
            for _ in range(count):
                template = random.choice(questions)
                dataset.append(asdict(EvalSample(
                    id=f"eval_{sample_id:04d}",
                    question=template["q"],
                    reference=template["a"],
                    category=category,
                    difficulty=difficulty
                )))
                sample_id += 1
    
    # 保存数据集
    with open("domain_eval_dataset.json", "w", encoding="utf-8") as f:
        json.dump(dataset, f, ensure_ascii=False, indent=2)
    
    print(f"创建了 {len(dataset)} 条评估样本")
    print(f"类别分布: {dict((cat, sum(1 for s in dataset if s['category'] == cat)) for cat in categories)}")
    print(f"难度分布: {dict((diff, sum(1 for s in dataset if s['difficulty'] == diff)) for diff in ['easy', 'medium', 'hard'])}")
    
    return dataset


if __name__ == "__main__":
    dataset = create_medical_eval_dataset(size=100)
```

**要点**：
- 评估集必须与训练集完全独立，不能从训练数据中随机拆分（会导致数据泄漏）
- 覆盖不同难度和类别，比例要与业务场景匹配
- 每条样本必须有参考答案，便于自动评估和人工评估
- 常见错误：评估集太小（<30条）导致结果波动大，没有统计意义

### 练习二：评估题

**思路**：使用领域评估数据集对模型进行自动化评估，从准确率、相关性、完整性三个维度打分。

**答案**：
```python
import json
from openai import OpenAI

client = OpenAI()


def evaluate_answer_with_llm(question: str, model_answer: str, reference: str) -> dict:
    """用 LLM-as-Judge 评估回答质量"""
    
    prompt = f"""请评估以下回答的质量，给出 0-1 的分数。

问题：{question}
参考答案：{reference}
模型回答：{model_answer}

请以 JSON 格式输出三个维度的评分：
- accuracy（准确性）：回答是否与参考答案一致
- relevancy（相关性）：回答是否切题
- completeness（完整性）：回答是否涵盖了参考答案的要点"""
    
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"}
    )
    
    return json.loads(response.choices[0].message.content)


def run_domain_evaluation(model, eval_dataset: list[dict]) -> dict:
    """运行领域评估"""
    
    results = {"accuracy": [], "relevancy": [], "completeness": []}
    details = []
    
    for sample in eval_dataset:
        # 生成回答
        answer = model.generate(sample["question"])
        
        # 评估
        scores = evaluate_answer_with_llm(
            question=sample["question"],
            model_answer=answer,
            reference=sample["reference"]
        )
        
        results["accuracy"].append(scores["accuracy"])
        results["relevancy"].append(scores["relevancy"])
        results["completeness"].append(scores["completeness"])
        
        details.append({
            "id": sample["id"],
            "category": sample["category"],
            "difficulty": sample["difficulty"],
            "scores": scores
        })
    
    # 计算平均分
    summary = {k: sum(v) / len(v) for k, v in results.items()}
    
    # 分维度统计
    for category in set(s["category"] for s in eval_dataset):
        cat_scores = [d for d in details if d["category"] == category]
        cat_avg = {
            dim: sum(d["scores"][dim] for d in cat_scores) / len(cat_scores)
            for dim in ["accuracy", "relevancy", "completeness"]
        }
        print(f"类别 [{category}]: 准确率={cat_avg['accuracy']:.2%}, "
              f"相关性={cat_avg['relevancy']:.2%}, 完整性={cat_avg['completeness']:.2%}")
    
    for difficulty in ["easy", "medium", "hard"]:
        diff_scores = [d for d in details if d["difficulty"] == difficulty]
        if diff_scores:
            diff_avg = sum(d["scores"]["accuracy"] for d in diff_scores) / len(diff_scores)
            print(f"难度 [{difficulty}]: 准确率={diff_avg:.2%}")
    
    return {"summary": summary, "details": details}
```

**要点**：
- LLM-as-Judge 比简单的字符串匹配更准确，但要选择比被评估模型更强的模型做裁判
- 分维度分析比只看总分更有价值，能找到模型的薄弱环节
- 评估结果要按类别和难度分组统计，定位具体问题
- 常见错误：用被评估模型自己做裁判，会产生偏差

### 练习三：报告题

**思路**：将评估结果整理成结构化的报告，包含总体评价、分维度分析、改进建议等。

**答案**：
```python
from datetime import datetime


def generate_eval_report(results: dict, model_name: str = "微调模型") -> str:
    """生成领域评估报告"""
    
    summary = results["summary"]
    details = results["details"]
    
    # 按类别统计
    categories = {}
    for d in details:
        cat = d["category"]
        if cat not in categories:
            categories[cat] = {"accuracy": [], "relevancy": [], "completeness": []}
        for dim in ["accuracy", "relevancy", "completeness"]:
            categories[cat][dim].append(d["scores"][dim])
    
    # 按难度统计
    difficulties = {}
    for d in details:
        diff = d["difficulty"]
        if diff not in difficulties:
            difficulties[diff] = {"accuracy": [], "count": 0}
        difficulties[diff]["accuracy"].append(d["scores"]["accuracy"])
        difficulties[diff]["count"] += 1
    
    # 生成报告
    report = f"""# 领域评估报告

## 基本信息
- 模型名称：{model_name}
- 评估时间：{datetime.now().strftime('%Y-%m-%d %H:%M')}
- 评估样本数：{len(details)}

## 总体指标
| 指标 | 得分 |
|------|------|
| 准确率 | {summary['accuracy']:.2%} |
| 相关性 | {summary['relevancy']:.2%} |
| 完整性 | {summary['completeness']:.2%} |

## 分类别分析
"""
    
    for cat, scores in categories.items():
        cat_avg = sum(scores["accuracy"]) / len(scores["accuracy"])
        report += f"### {cat}\n"
        report += f"- 准确率：{cat_avg:.2%}\n"
        report += f"- 样本数：{len(scores['accuracy'])}\n\n"
    
    report += "## 分难度分析\n"
    report += "| 难度 | 样本数 | 准确率 |\n|------|--------|--------|\n"
    for diff in ["easy", "medium", "hard"]:
        if diff in difficulties:
            avg = sum(difficulties[diff]["accuracy"]) / len(difficulties[diff]["accuracy"])
            report += f"| {diff} | {difficulties[diff]['count']} | {avg:.2%} |\n"
    
    # 整体评价
    overall_score = (summary["accuracy"] + summary["relevancy"] + summary["completeness"]) / 3
    if overall_score >= 0.80:
        evaluation = "优秀 — 模型在领域任务上表现优异，可投入使用"
    elif overall_score >= 0.60:
        evaluation = "良好 — 模型基本达标，建议针对弱项继续优化"
    else:
        evaluation = "需要改进 — 模型表现不足，需重新审视训练数据和策略"
    
    report += f"\n## 综合评价\n{evaluation}\n"
    
    # 保存报告
    with open("eval_report.md", "w", encoding="utf-8") as f:
        f.write(report)
    
    print(report)
    return report


if __name__ == "__main__":
    # 假设已获得评估结果
    sample_results = {
        "summary": {"accuracy": 0.72, "relevancy": 0.85, "completeness": 0.68},
        "details": [
            {"id": "eval_0001", "category": "诊断", "difficulty": "easy",
             "scores": {"accuracy": 0.9, "relevancy": 0.9, "completeness": 0.8}},
            {"id": "eval_0002", "category": "用药", "difficulty": "hard",
             "scores": {"accuracy": 0.5, "relevancy": 0.7, "completeness": 0.4}},
        ]
    }
    generate_eval_report(sample_results)
```

**要点**：
- 报告必须包含总体指标、分维度分析、分难度分析，不能只给一个总分
- 综合评价要有明确的结论和可执行的改进建议
- 报告格式要标准化，便于不同时间的评估结果对比
- 常见错误：报告只有数字没有分析，读者无法从中获得可操作的洞察
