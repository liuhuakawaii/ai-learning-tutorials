# 第 5 阶段：评估与部署

> 科学评估微调效果并部署到生产

## 学习目标

- 掌握通用基准评估（MMLU / HellaSwag / ARC）和领域评估方法
- 学会进行微调模型 vs 基础模型 vs API 模型的多维度对比
- 理解 API 调用 vs 本地部署的 TCO 分析框架
- 能够将微调模型部署到生产环境并提供服务

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 通用基准评估 — MMLU / HellaSwag / ARC 等基准测试 | 3h |
| 02 | 领域评估 — 针对微调任务设计专属评估数据集 | 3h |
| 03 | 对比评估 — 微调模型 vs 基础模型 vs API 模型的多维度对比 | 3h |
| 04 | 模型部署 — 用 vLLM 部署微调模型并提供 OpenAI 兼容 API | 3h |
| 05 | 成本分析 — API 调用 vs 本地部署的 TCO 对比与决策框架 | 2h |
| 06 | 阶段实战：完成微调模型的评估报告并部署到生产环境 | 4h |

## 验收标准

- [ ] 产出包含基准评估 + 领域评估的完整评估报告
- [ ] 微调模型部署后能通过 OpenAI 兼容 API 正常调用
- [ ] 完成 API vs 本地部署的 TCO 分析并给出明确建议
