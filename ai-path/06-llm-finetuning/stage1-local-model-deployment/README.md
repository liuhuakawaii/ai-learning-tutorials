# 第 1 阶段：本地模型部署

> 在本地环境跑起来开源大模型

## 学习目标

- 了解主流开源大模型生态（Llama / Qwen / Mistral / DeepSeek）
- 掌握 Ollama / llama.cpp / vLLM 三种本地部署方案
- 理解模型量化级别（Q4_K_M / Q5_K_M / Q8_0 等）的区别
- 能够让本地模型提供 OpenAI 兼容 API

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 开源模型生态 — Llama / Qwen / Mistral / DeepSeek 的选型指南 | 2h |
| 02 | Ollama 快速上手 — 一行命令运行本地大模型 | 2h |
| 03 | llama.cpp 深入 — GGUF 格式、量化级别、推理参数调优 | 3h |
| 04 | vLLM 生产部署 — 高性能推理引擎的配置与优化 | 3h |
| 05 | OpenAI 兼容 API — 让本地模型接入现有的 AI 应用（零改代码） | 3h |
| 06 | 阶段实战：在本地部署一个 OpenAI 兼容的模型服务并接入 01 课程项目 | 4h |

## 验收标准

- [ ] 用 Ollama 成功运行至少 2 个不同规模的模型
- [ ] 本地模型服务提供 OpenAI 兼容 API 并能被现有应用调用
- [ ] 能对比不同量化级别的性能和质量差异
