# 第 4 阶段：训练 Pipeline

> 从一次性实验到可重复的训练流水线

## 学习目标

- 搭建自动化的数据收集、清洗、格式化流水线
- 学会用 YAML 配置文件管理实验参数
- 掌握模型合并和量化导出的完整流程
- 能够构建一个端到端的可重复训练 Pipeline

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 数据 Pipeline — 自动化数据收集、清洗、格式化的流水线 | 3h |
| 02 | 训练配置管理 — 用 YAML 配置文件管理实验参数 | 2h |
| 03 | 分布式训练 — 多 GPU 训练的配置与常见问题 | 3h |
| 04 | 模型合并 — LoRA 权重与基础模型的合并导出 | 3h |
| 05 | 模型量化导出 — 将微调模型导出为 GGUF / GPTQ 格式 | 3h |
| 06 | 阶段实战：搭建一个端到端的训练 Pipeline（数据 → 训练 → 导出） | 4h |

## 验收标准

- [ ] Pipeline 能从原始数据自动完成清洗 → 训练 → 合并 → 导出
- [ ] 用 YAML 配置文件管理至少 3 组不同实验参数
- [ ] 导出的 GGUF 模型能在 Ollama 中正常运行
