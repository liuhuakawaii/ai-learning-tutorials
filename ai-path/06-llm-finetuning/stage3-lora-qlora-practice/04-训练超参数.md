# 04 训练超参数——Learning Rate / Epoch / Batch Size / LoRA Rank 调优

> 超参数调优是微调成功的关键。好的超参数能让效果提升 10% 以上。

## 场景引入

你用默认参数跑完微调，效果一般。同事说"把学习率调小一点"，你从 2e-4 调到 1e-5，Loss 下降更慢了。又有人说"epochs 太少了"，你加到 10 轮，结果过拟合了。LoRA rank 从 16 调到 64，效果反而变差。超参数之间互相影响，盲目调参就像大海捞针。你需要理解每个超参数的作用和调优策略。

---

## 学习目标

- 理解各超参数的作用和影响
- 掌握超参数调优的方法
- 学会根据训练情况调整超参数

## 一、关键超参数

```
关键超参数：

1. Learning Rate（学习率）
   - 控制参数更新幅度
   - 太大：训练不稳定
   - 太小：训练缓慢
   - 推荐：1e-5 到 3e-4

2. Epochs（训练轮数）
   - 数据集遍历次数
   - 太少：欠拟合
   - 太多：过拟合
   - 推荐：3-10

3. Batch Size（批次大小）
   - 每次训练的样本数
   - 受限于显存
   - 推荐：4-16

4. LoRA Rank（LoRA 秩）
   - LoRA 的表达能力
   - 越大效果越好，但参数越多
   - 推荐：8-64
```

---

## 二、调优策略

```
调优策略：

1. 学习率调优
   - 从小开始（1e-5）
   - 逐步增大
   - 观察 loss 变化
   - 选择 loss 下降最快的

2. Epochs 调优
   - 监控验证集 loss
   - loss 不再下降时停止
   - 使用 early stopping

3. Batch Size 调优
   - 受限于显存
   - 用梯度累积模拟大 batch
   - 大 batch 训练更稳定

4. LoRA Rank 调优
   - 从小开始（8）
   - 逐步增大
   - 效果不再提升时停止
```

## 六、调优经验

```
调优经验：

1. 学习率
   - LoRA 推荐：2e-4
   - QLoRA 推荐：2e-4
   - 如果 loss 震荡，降低学习率

2. Epochs
   - 小数据集（<1000）：5-10 epochs
   - 大数据集（>10000）：1-3 epochs

3. Batch Size
   - 显存允许的情况下尽量大
   - 用梯度累积模拟

4. LoRA Rank
   - 简单任务：8-16
   - 复杂任务：32-64
```

---

## 常见误区

1. **用网格搜索遍历所有参数组合**：超参数空间是指数级的，网格搜索效率极低。应该先固定大部分参数，逐个调整关键参数（学习率 > LoRA rank > epochs）。

2. **学习率直接用别人的配置**：不同模型、不同数据集、不同 LoRA 配置的最优学习率都不同。别人的 2e-4 可能对你完全不适用，必须自己实验。

3. **只看训练 Loss 不看验证 Loss**：训练 Loss 持续下降但验证 Loss 上升，说明过拟合了。必须同时监控验证集表现，用 Early Stopping 防止过拟合。

4. **LoRA rank 越大越好**：rank 从 16 增到 64，参数量翻 4 倍，但效果提升可能只有 1-2%。更大的 rank 还更容易过拟合，特别是在数据量不足时。

---

## 工程建议

1. **学习率优先调**：学习率对效果影响最大。先用 3 组学习率（1e-4、2e-4、3e-4）做快速实验，找到最优区间后再调其他参数。

2. **小数据集用更多 epochs**：数据量 < 1000 时，5-10 个 epochs 通常是合理的。数据量 > 10000 时，1-3 个 epochs 就够了，多了容易过拟合。

3. **用 Optuna 做自动化搜索**：手动调参效率低且容易遗漏。用 Optuna 定义搜索空间和目标函数，自动找到最优超参数组合。

4. **记录每次实验的配置和结果**：用实验管理工具（如 MLflow 或简单的 JSON 文件）记录每次调参的配置和评估结果，方便对比和复现。

## 参考答案

### 练习一：调优一个模型的超参数

**思路**：采用控制变量法，先固定大部分参数，按优先级依次调优学习率、LoRA rank、epochs。关键是每次只改一个变量，用验证集 Loss 作为评判标准。

**答案**：
```python
"""超参数调优实验"""
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model
from trl import SFTTrainer
from datasets import load_dataset
import json

model_name = "Qwen/Qwen2.5-7B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
dataset = load_dataset("json", data_files="training_data.json")

def train_with_config(lr, r, epochs, output_dir):
    """用指定超参数训练并返回结果"""
    model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
    
    lora_config = LoraConfig(
        r=r, lora_alpha=2*r,
        target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
        lora_dropout=0.05, bias="none", task_type="CAUSAL_LM"
    )
    model = get_peft_model(model, lora_config)
    
    training_args = TrainingArguments(
        output_dir=output_dir,
        num_train_epochs=epochs,
        per_device_train_batch_size=2,
        gradient_accumulation_steps=4,
        learning_rate=lr,
        warmup_ratio=0.1,
        fp16=True,
        logging_steps=10,
        save_strategy="no",
        report_to="none",
    )
    trainer = SFTTrainer(
        model=model, args=training_args,
        train_dataset=dataset["train"],
        tokenizer=tokenizer, max_seq_length=512
    )
    result = trainer.train()
    return result.training_loss

# 第一轮：调学习率（固定 r=16, epochs=3）
print("=== 第一轮：调学习率 ===")
for lr in [1e-4, 2e-4, 3e-4]:
    loss = train_with_config(lr=lr, r=16, epochs=3, output_dir=f"./tune_lr{lr}")
    print(f"  lr={lr}: loss={loss:.4f}")
    torch.cuda.empty_cache()

# 第二轮：调 LoRA rank（固定最优 lr, epochs=3）
print("=== 第二轮：调 LoRA rank ===")
best_lr = 2e-4  # 假设第一轮结果
for r in [8, 16, 32]:
    loss = train_with_config(lr=best_lr, r=r, epochs=3, output_dir=f"./tune_r{r}")
    print(f"  r={r}: loss={loss:.4f}")
    torch.cuda.empty_cache()

# 第三轮：调 epochs（固定最优 lr 和 r）
print("=== 第三轮：调 epochs ===")
best_r = 16  # 假设第二轮结果
for ep in [2, 3, 5]:
    loss = train_with_config(lr=best_lr, r=best_r, epochs=ep, output_dir=f"./tune_ep{ep}")
    print(f"  epochs={ep}: loss={loss:.4f}")
    torch.cuda.empty_cache()
```

**要点**：
- 调优顺序：学习率 > LoRA rank > epochs，学习率对效果影响最大
- 每轮只调一个变量，固定其他变量，否则无法判断是哪个参数导致的变化
- 常见错误：一开始就遍历所有参数组合（网格搜索），计算量指数级增长，效率极低

### 练习二：实现学习率调度

**思路**：学习率调度的核心是 warmup + 衰减策略。warmup 阶段学习率从 0 线性增长到目标值，避免训练初期梯度过大；之后用 cosine 或 linear 策略逐步衰减。

**答案**：
```python
"""学习率调度实现"""
from transformers import get_scheduler, TrainingArguments
from torch.optim import AdamW

# 方式一：通过 TrainingArguments 配置（推荐）
training_args = TrainingArguments(
    output_dir="./output",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    warmup_ratio=0.1,              # 前 10% 步数做 warmup
    lr_scheduler_type="cosine",    # cosine 衰减
    # 可选：linear, cosine, cosine_with_restarts, polynomial, constant_with_warmup
    fp16=True,
    logging_steps=10,
)

# 方式二：手动实现（理解原理）
import torch
from transformers import get_scheduler

model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B", torch_dtype=torch.float16)
optimizer = AdamW(model.parameters(), lr=2e-4, weight_decay=0.01)

num_epochs = 3
num_training_steps = num_epochs * 100  # 假设每 epoch 100 步
num_warmup_steps = int(num_training_steps * 0.1)  # 10% warmup

scheduler = get_scheduler(
    "cosine",
    optimizer=optimizer,
    num_warmup_steps=num_warmup_steps,
    num_training_steps=num_training_steps
)

# 模拟训练循环
lr_history = []
for step in range(num_training_steps):
    current_lr = scheduler.get_last_lr()[0]
    lr_history.append(current_lr)
    
    # 模拟训练步骤
    optimizer.step()
    scheduler.step()
    optimizer.zero_grad()

# 打印学习率变化
print(f"初始学习率: {lr_history[0]:.8f}")
print(f"Peak 学习率: {max(lr_history):.8f}（在第 {lr_history.index(max(lr_history))} 步）")
print(f"最终学习率: {lr_history[-1]:.8f}")
print"warmup 步数: {num_warmup_steps}")
```

**要点**：
- cosine 调度比 linear 调度在后期衰减更平滑，通常效果更好
- warmup_ratio=0.1 是经验值，太小可能导致训练初期不稳定，太大会浪费训练步数
- 常见错误：不设 warmup 直接用大学习率训练，导致前几步 Loss 飙升甚至 NaN

### 练习三：使用 Optuna 进行超参数搜索

**思路**：定义搜索空间（学习率、LoRA rank 等）和目标函数（验证集 Loss），让 Optuna 自动探索最优组合。关键是合理定义搜索范围和使用 early pruning 剪枝差的试验。

**答案**：
```python
"""Optuna 超参数搜索"""
import optuna
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model
from trl import SFTTrainer
from datasets import load_dataset

model_name = "Qwen/Qwen2.5-7B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
dataset = load_dataset("json", data_files="training_data.json")

# 划分训练集和验证集
split = dataset["train"].train_test_split(test_size=0.1, seed=42)
train_dataset = split["train"]
eval_dataset = split["test"]

def objective(trial):
    """Optuna 目标函数"""
    # 定义搜索空间
    lr = trial.suggest_float("learning_rate", 1e-5, 3e-4, log=True)
    r = trial.suggest_categorical("lora_rank", [8, 16, 32])
    lora_dropout = trial.suggest_float("lora_dropout", 0.0, 0.2)
    warmup_ratio = trial.suggest_float("warmup_ratio", 0.0, 0.2)
    
    # 加载模型
    model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float16, device_map="auto")
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
    
    lora_config = LoraConfig(
        r=r, lora_alpha=2*r,
        target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
        lora_dropout=lora_dropout, bias="none", task_type="CAUSAL_LM"
    )
    model = get_peft_model(model, lora_config)
    
    training_args = TrainingArguments(
        output_dir=f"./optuna_trial_{trial.number}",
        num_train_epochs=3,
        per_device_train_batch_size=2,
        gradient_accumulation_steps=4,
        learning_rate=lr,
        warmup_ratio=warmup_ratio,
        fp16=True,
        logging_steps=50,
        save_strategy="no",
        report_to="none",
        eval_strategy="steps",
        eval_steps=50,
    )
    
    trainer = SFTTrainer(
        model=model, args=training_args,
        train_dataset=train_dataset,
        eval_dataset=eval_dataset,
        tokenizer=tokenizer, max_seq_length=512
    )
    
    trainer.train()
    eval_result = trainer.evaluate()
    
    # 清理显存
    del model, trainer
    torch.cuda.empty_cache()
    
    return eval_result["eval_loss"]

# 运行搜索
study = optuna.create_study(direction="minimize", study_name="lora_tuning")
study.optimize(objective, n_trials=20, timeout=3600)  # 最多 20 次或 1 小时

# 打印结果
print("\n最优超参数：")
for key, value in study.best_params.items():
    print(f"  {key}: {value}")
print(f"最优验证 Loss: {study.best_value:.4f}")
```

**要点**：
- 学习率用 log 尺度搜索（`log=True`），因为学习率通常在 1e-5 到 3e-4 之间，线性尺度会偏向大值
- n_trials=20 对于 LoRA 调优已经足够，不需要几百次试验
- 常见错误：搜索空间太大（如 rank 从 1 到 256），导致大量试验浪费在明显不合理的参数上
