# 第 4 阶段：可观测性平台

> 搭建生产级的 AI 应用监控与追踪系统

## 学习目标

- 理解可观测性三支柱（Logs / Traces / Metrics）在 AI 应用中的应用
- 掌握 Langfuse 的集成、配置和 dashboard 搭建
- 学会设计 AI 应用的成本监控和质量告警机制
- 能够构建一个完整的 AI 应用可观测性平台

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 可观测性三支柱 — Logs / Traces / Metrics 在 AI 应用中的应用 | 2h |
| 02 | Langfuse 快速上手 — 从 SDK 集成到第一个 dashboard | 3h |
| 03 | 调用链路追踪 — 从用户输入到模型输出的全链路可视化 | 3h |
| 04 | 成本监控 — Token 消耗、API 调用次数、费用预警 | 3h |
| 05 | 质量 dashboard — 实时展示评估指标、趋势、异常告警 | 3h |
| 06 | 阶段实战：搭建一个完整的 AI 应用可观测性平台 | 4h |

## 验收标准

- [ ] 成功集成 Langfuse 并追踪至少一个 AI 应用的完整调用链路
- [ ] 搭建一个包含成本、质量、延迟三个维度的 dashboard
- [ ] 配置至少 2 个告警规则（如 Token 超限、幻觉率升高）
