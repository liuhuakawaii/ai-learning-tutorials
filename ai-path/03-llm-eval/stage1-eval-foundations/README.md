# 第 1 阶段：评估基础

> 掌握 LLM 评估的核心概念和基本工具

## 学习目标

- 理解为什么 AI 应用需要系统化的评估方法
- 掌握评估指标体系的设计原则
- 学会用 LLM-as-Judge 实现自动化评估
- 能够构建和管理 Golden Dataset

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 为什么需要评估 — AI 应用质量的挑战与评估思维 | 2h |
| 02 | 评估指标体系 — 回答质量、延迟、成本、安全性的量化方法 | 2h |
| 03 | 自动化评估入门 — 用 LLM-as-Judge 实现自动打分 | 3h |
| 04 | 评估数据集构建 — Golden Dataset 的设计与管理 | 3h |
| 05 | 对比评估方法 — Pairwise / Rating / Binary 分类与适用场景 | 2h |
| 06 | 阶段实战：为一个简单 QA 应用搭建基础评估 pipeline | 4h |

## 验收标准

- [ ] 能解释 LLM-as-Judge 的原理和局限性
- [ ] 独立构建一个包含 50+ 样本的 Golden Dataset
- [ ] 完成一个自动化评估脚本，输出结构化评估报告
