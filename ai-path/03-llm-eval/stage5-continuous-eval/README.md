# 第 5 阶段：持续评估与优化

> 建立"评估 → 发现问题 → 优化 → 再验证"的闭环

## 学习目标

- 掌握在 CI/CD 中集成自动化 eval 的方法
- 学会设计 A/B 测试框架对比不同 Prompt / 模型效果
- 理解人工标注系统的设计和标注质量控制
- 能够用评估数据驱动 Prompt 工程和 RAG 优化

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | CI/CD 集成 — 在部署流水线中加入自动化 eval 门禁 | 3h |
| 02 | A/B 测试框架 — Prompt / 模型 / 参数的对比实验设计 | 3h |
| 03 | 人工标注系统 — 标注任务管理、标注员一致性、反馈回路 | 3h |
| 04 | 回归测试 — 确保优化不引入新问题的策略 | 2h |
| 05 | 评估驱动优化 — 用评估数据指导 Prompt 工程和 RAG 调优 | 3h |
| 06 | 阶段实战：建立完整的持续评估与优化闭环 | 4h |

## 验收标准

- [ ] 在 CI/CD 中成功集成 eval 门禁，不通过则阻止部署
- [ ] 完成一次 A/B 测试实验并产出数据驱动的决策报告
- [ ] 建立一个可持续运行的评估 → 优化 → 再验证闭环
