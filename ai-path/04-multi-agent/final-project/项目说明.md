# Multi-Agent Research Assistant 项目说明

## 项目目标

构建一个多 Agent 研究助手：搜索 Agent 收集信息 → 分析 Agent 提取洞察 → 写作 Agent 生成报告 → 审核 Agent 质量把关，含人类审批节点。本 kit 提供 LangGraph 骨架和 Mock 模式，学员可先练编排逻辑，再接入真实 LLM。

## 内置 project kit

```text
04-multi-agent-course/final-project/research-assistant-kit
```

运行：

```bash
cd 04-multi-agent-course/final-project/research-assistant-kit
pip install -r requirements.txt
python scripts/check.py
python src/main.py --mock
python src/main.py --topic "LLM Agent 2025 trends"
```

## 核心功能

1. 多 Agent 编排
   - Supervisor 模式：一个调度者分配任务给专家 Agent
   - Sequential 模式：搜索 → 分析 → 写作 → 审核的链式流转
   - 每个 Agent 可独立测试

2. Agent 通信与记忆
   - 共享状态：Agent 间通过 TypedDict 传递上下文
   - 短期记忆：会话内消息历史
   - 长期记忆：跨会话的知识持久化（SQLite）

3. 人类审批节点
   - 审批 gate：在关键节点暂停等待人类确认
   - 反馈注入：人类意见影响 Agent 后续行为
   - 异步审批：支持长时间运行任务

4. Mock 模式
   - 无需 API Key 即可运行完整流程
   - Mock 响应模拟真实 Agent 行为
   - 便于调试和演示

5. 可观测性
   - LangGraph Studio 可视化（可选）
   - 调用链路日志
   - Token 消耗统计

## 验收标准

- `python scripts/check.py` 通过
- Mock 模式能完整运行搜索 → 分析 → 写作 → 审核流程
- 每个 Agent 可独立运行和测试
- 人类审批节点能正确暂停和恢复
- 共享状态在 Agent 间正确传递
- 长期记忆跨会话可持久化
