# 第 5 阶段：生产级多 Agent 系统

> 从原型到生产的关键跨越

## 学习目标

- 掌握多 Agent 系统的可观测性设计（复用 03 课程知识）
- 学会优化多 Agent 系统的性能和成本
- 理解多 Agent 系统的测试策略（单元/集成/端到端）
- 能够将多 Agent 系统部署到生产环境

## 课时安排

| 序号 | 主题 | 预计时长 |
|------|------|----------|
| 01 | 可观测性 — 多 Agent 系统的追踪、日志、指标设计 | 3h |
| 02 | 性能优化 — 并发控制、Token 预算、调用限流 | 3h |
| 03 | 测试策略 — 多 Agent 系统的单元测试 / 集成测试 / 端到端测试 | 3h |
| 04 | 部署架构 — 容器化部署、服务发现、负载均衡 | 3h |
| 05 | 安全边界 — Agent 权限隔离、输出审核、越权防护 | 2h |
| 06 | 阶段实战：将多 Agent 系统部署到生产环境并完成压力测试 | 4h |

## 验收标准

- [ ] 多 Agent 系统有完整的追踪和监控
- [ ] 系统能处理至少 10 个并发请求
- [ ] 通过端到端测试覆盖核心工作流
