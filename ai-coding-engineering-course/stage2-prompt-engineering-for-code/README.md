# Stage 2: Prompt Engineering for Code — 面向代码的提示工程

> **课程定位**：掌握与 AI 编程助手高效协作的核心技能——Prompt Engineering。从基础原则到高级模式，系统性提升你向 AI 描述需求、提供上下文、引导生成高质量代码的能力。

## 前置要求

- 完成 Stage 1（AI 编程基础认知）
- 具备至少一门编程语言的基础（TypeScript / Python / Java）
- 使用过至少一种 AI 编程工具（Cursor、GitHub Copilot、ChatGPT 等）

## 学习目标

完成本阶段后，你将能够：

1. **运用四大核心原则**编写高质量代码 Prompt
2. **使用结构化模板**清晰描述各类开发需求
3. **提供精准上下文**让 AI 生成符合项目风格的代码
4. **通过迭代式对话**逐步构建复杂功能
5. **编写系统级 Prompt**统一团队 AI 编程规范
6. **处理多语言/多框架**场景的 Prompt 编写
7. **产出完整的 AI 编程规范文档**用于实际项目

## 学习建议

- 每课包含 **3 个动手练习**，建议全部完成
- 代码示例以 **TypeScript** 和 **Python** 为主，选择你熟悉的语言开始
- 每课末尾有 **常见错误** 检查清单，回顾时重点看这些
- 课程之间有递进关系，建议按顺序学习
