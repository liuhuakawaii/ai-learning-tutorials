# 04 - 安全与合规

> 在享受 AI 编程红利的同时，守住安全底线和合规红线

## 场景引入

公司安全团队在例行审计中发现：过去三个月，AI 辅助生成的代码中有 12 处硬编码的 API Key、3 个使用字符串拼接的 SQL 查询、以及 1 个引入了 GPL 许可证依赖的模块——而公司的闭源产品不允许使用 GPL 代码。更令人后怕的是，这些问题全部通过了常规 code review，因为审查者默认"AI 生成的代码应该是安全的"。这次事件直接导致公司暂停了所有 AI 编程工具的使用，直到建立完善的安全与合规机制。

## 学习目标

- 理解 AI 编程带来的安全风险全景
- 掌握密钥泄露检测和防护方法
- 学会许可证合规检查流程
- 了解 OWASP 安全规范在 AI 编程中的应用

## 1. AI 编程安全风险全景

### 1.1 风险分类矩阵

```
                    高影响
                      │
       ┌──────────────┼──────────────┐
       │   代码注入    │   密钥泄露    │
       │   漏洞引入    │   数据泄露    │
       │              │              │
 低概率 ┼──────────────┼──────────────┼ 高概率
       │   供应链攻击  │   许可证违规  │
       │   模型投毒    │   代码风格    │
       │              │   不一致      │
       └──────────────┼──────────────┘
                      │
                    低影响
```

### 1.2 典型安全事件

| 事件类型 | 真实案例 | 影响 | 防护措施 |
|---------|---------|------|---------|
| 密钥泄露 | AI 建议硬编码 API Key | 账户被盗用 | 密钥扫描 + 环境变量 |
| SQL 注入 | AI 生成字符串拼接 SQL | 数据库被攻击 | 参数化查询检查 |
| 许可证违规 | AI 复制 GPL 代码 | 法律风险 | 许可证扫描 |
| 依赖漏洞 | AI 推荐有漏洞的旧版本 | 系统被入侵 | 依赖审计 |

### 2.3 AI 辅助密钥检测脚本

```python
# scripts/ai_secret_scan.py
import re
import json
from pathlib import Path
from typing import List, Dict

class SecretScanner:
    # 高风险模式
    HIGH_RISK_PATTERNS = [
        (r'(?i)(password|passwd|pwd)\s*[:=]\s*["\'][^"\']+["\']', 'hardcoded-password'),
        (r'(?i)(api[_-]?key|apikey)\s*[:=]\s*["\'][^"\']+["\']', 'api-key'),
        (r'(?i)(secret|token)\s*[:=]\s*["\'][^"\']+["\']', 'secret-token'),
        (r'(?i)(aws[_-]?access[_-]?key[_-]?id)\s*[:=]\s*["\']?AKIA[A-Z0-9]{16}', 'aws-key'),
        (r'-----BEGIN\s?(RSA|EC|DSA)?\s?PRIVATE KEY-----', 'private-key'),
    ]

    # 可疑模式（需要 AI 进一步确认）
    SUSPICIOUS_PATTERNS = [
        (r'[a-zA-Z0-9+/]{40,}={0,2}', 'base64-encoded'),
        (r'[a-f0-9]{32,}', 'hex-encoded'),
        (r'ey[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}', 'jwt-token'),
    ]

    def __init__(self, exclude_patterns: List[str] = None):
        self.exclude_patterns = exclude_patterns or [
            r'.*\.test\..*',
            r'.*test/.*',
            r'.*\.md$',
        ]

    def should_exclude(self, filepath: str) -> bool:
        return any(re.match(p, filepath) for p in self.exclude_patterns)

    def scan_file(self, filepath: Path) -> List[Dict]:
        findings = []
        if self.should_exclude(str(filepath)):
            return findings

        try:
            content = filepath.read_text(encoding='utf-8')
            lines = content.split('\n')

            for line_num, line in enumerate(lines, 1):
                # 检查高风险模式
                for pattern, rule_id in self.HIGH_RISK_PATTERNS:
                    if re.search(pattern, line):
                        findings.append({
                            'file': str(filepath),
                            'line': line_num,
                            'rule': rule_id,
                            'severity': 'critical',
                            'snippet': line.strip()[:100],
                        })

                # 检查可疑模式（排除常见误报）
                for pattern, rule_id in self.SUSPICIOUS_PATTERNS:
                    match = re.search(pattern, line)
                    if match and not self._is_false_positive(match.group(), line):
                        findings.append({
                            'file': str(filepath),
                            'line': line_num,
                            'rule': rule_id,
                            'severity': 'warning',
                            'snippet': line.strip()[:100],
                        })
        except Exception:
            pass

        return findings

    def _is_false_positive(self, match: str, context: str) -> bool:
        """简单的误报过滤"""
        false_positive_indicators = [
            'test', 'mock', 'example', 'sample', 'placeholder',
            'TODO', 'FIXME', 'dummy', 'fake',
        ]
        return any(indicator.lower() in context.lower()
                   for indicator in false_positive_indicators)

    def scan_directory(self, path: str) -> List[Dict]:
        all_findings = []
        for filepath in Path(path).rglob('*'):
            if filepath.is_file() and filepath.suffix in ['.ts', '.js', '.py', '.go', '.java', '.env']:
                all_findings.extend(self.scan_file(filepath))
        return all_findings


if __name__ == '__main__':
    scanner = SecretScanner()
    findings = scanner.scan_directory('./src')

    report = {
        'total_findings': len(findings),
        'critical': len([f for f in findings if f['severity'] == 'critical']),
        'warnings': len([f for f in findings if f['severity'] == 'warning']),
        'findings': findings,
    }

    print(json.dumps(report, indent=2, ensure_ascii=False))
```

### 3.3 AI 辅助许可证分析

```python
# scripts/ai_license_check.py
import json
from typing import Dict, List

LICENSE_RISK_LEVELS = {
    'MIT': 'low',
    'Apache-2.0': 'low',
    'BSD-2-Clause': 'low',
    'BSD-3-Clause': 'low',
    'ISC': 'low',
    'LGPL-2.1': 'medium',
    'LGPL-3.0': 'medium',
    'MPL-2.0': 'medium',
    'GPL-2.0': 'high',
    'GPL-3.0': 'high',
    'AGPL-3.0': 'critical',
    'SSPL-1.0': 'critical',
    'UNKNOWN': 'high',
}

def analyze_license_compatibility(
    project_license: str,
    dependencies: List[Dict]
) -> Dict:
    """分析依赖许可证与项目许可证的兼容性"""

    results = {
        'project_license': project_license,
        'total_dependencies': len(dependencies),
        'compatible': [],
        'incompatible': [],
        'unknown': [],
        'risk_summary': {'low': 0, 'medium': 0, 'high': 0, 'critical': 0},
    }

    for dep in dependencies:
        license_id = dep.get('license', 'UNKNOWN')
        risk = LICENSE_RISK_LEVELS.get(license_id, 'high')
        results['risk_summary'][risk] += 1

        if risk == 'critical':
            results['incompatible'].append({
                'name': dep['name'],
                'license': license_id,
                'risk': risk,
                'action': '必须移除或替换',
            })
        elif risk == 'high' and project_license in ['MIT', 'Apache-2.0', 'Proprietary']:
            results['incompatible'].append({
                'name': dep['name'],
                'license': license_id,
                'risk': risk,
                'action': '需要法务评估',
            })
        elif license_id == 'UNKNOWN':
            results['unknown'].append({
                'name': dep['name'],
                'action': '需要手动确认许可证',
            })
        else:
            results['compatible'].append({
                'name': dep['name'],
                'license': license_id,
                'risk': risk,
            })

    return results


def generate_compliance_prompt(analysis: Dict) -> str:
    """生成 AI 分析 Prompt"""
    return f"""请分析以下依赖许可证合规报告，提供风险评估和建议：

项目许可证: {analysis['project_license']}
依赖总数: {analysis['total_dependencies']}

不兼容依赖:
{json.dumps(analysis['incompatible'], indent=2, ensure_ascii=False)}

未知许可证依赖:
{json.dumps(analysis['unknown'], indent=2, ensure_ascii=False)}

请提供：
1. 整体风险等级评估
2. 每个不兼容依赖的具体建议（替代方案）
3. 合规整改优先级排序
4. 预防措施建议"""
```

### 5.2 漏洞分析脚本

```python
# scripts/analyze_vulnerabilities.py
import json
from typing import Dict, List

def analyze_npm_audit(audit_path: str) -> Dict:
    """分析 npm audit 结果"""
    with open(audit_path) as f:
        audit = json.load(f)

    vulnerabilities = audit.get('vulnerabilities', {})

    results = {
        'critical': [],
        'high': [],
        'moderate': [],
        'low': [],
    }

    for name, vuln in vulnerabilities.items():
        severity = vuln.get('severity', 'unknown')
        if severity in results:
            results[severity].append({
                'name': name,
                'severity': severity,
                'via': vuln.get('via', []),
                'fixAvailable': vuln.get('fixAvailable', False),
                'range': vuln.get('range', ''),
            })

    return results

def generate_fix_commands(vulnerabilities: Dict) -> List[str]:
    """生成修复命令"""
    commands = []

    for severity in ['critical', 'high']:
        for vuln in vulnerabilities[severity]:
            if vuln['fixAvailable']:
                commands.append(f"npm audit fix {vuln['name']}")
            else:
                commands.append(f"# 需要手动升级 {vuln['name']}")

    return commands
```

## 6. 常见误区

### ❌ 错误 1：将 .env 文件提交到仓库

```bash
# 危险！.env 文件包含密钥
echo "API_KEY=sk-1234567890" > .env
git add .env  # ❌ 绝对不能这样做

# 正确做法
echo ".env" >> .gitignore
git add .gitignore
```

### ❌ 错误 2：AI 生成的代码不检查安全性

```typescript
// AI 生成了看似正确但有安全漏洞的代码
const query = `SELECT * FROM users WHERE id = ${req.params.id}`;
// ❌ SQL 注入风险

// 必须人工审查并改用参数化查询
const query = 'SELECT * FROM users WHERE id = $1';
const result = await db.query(query, [req.params.id]);
```

### ❌ 错误 3：忽略许可证兼容性

```
问题：AI 推荐使用一个 GPL 许可的库，
但项目是商业闭源软件，导致许可证冲突

解决：
1. 配置许可证检查工具
2. CI 中自动扫描
3. 建立允许/禁止列表
```

### ❌ 错误 4：安全扫描只在发布前做

```
问题：安全扫描只在发布前执行，发现问题已经太晚

解决：
- PR 时自动扫描
- 每周定时全量扫描
- 依赖更新时触发扫描
```

## 7. 工程建议

1. **安全扫描左移到 PR 阶段**：不要等到发布前才做安全检查，在每次 PR 提交时就自动运行 Gitleaks、Semgrep 和依赖审计，让问题在代码合入前就被拦截。
2. **许可证检查必须是 CI 门禁**：配置 `license-checker` 在 CI 中自动扫描依赖许可证，对 GPL/AGPL 等高风险许可证设置为阻断项，避免"AI 推荐了一个 GPL 库"导致的法律风险。
3. **建立安全审查 Prompt 模板**：为团队提供标准化的安全审查 Prompt，明确要求检查 OWASP Top 10 风险，输出格式化的审查报告，让每个开发者都能进行基本的安全自查。
4. **敏感文件排除要前置**：在项目初始化时就配置 `.copilotignore` 和 `.gitignore`，排除 `.env`、密钥文件、证书等敏感文件，从源头防止 AI 工具接触和泄露敏感信息。
