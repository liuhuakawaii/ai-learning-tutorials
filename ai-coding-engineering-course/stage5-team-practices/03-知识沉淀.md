## 3. Prompt 库管理系统

### 3.1 Prompt 元数据设计

```typescript
interface PromptMetadata {
  id: string;
  name: string;
  version: string;
  category: string;
  tags: string[];
  author: string;
  createdAt: string;
  updatedAt: string;

  // 适用性
  supportedModels: string[];
  supportedLanguages: string[];
  taskType: 'generation' | 'review' | 'refactoring' | 'testing' | 'documentation';

  // 效果指标
  metrics: {
    usageCount: number;
    acceptanceRate: number;      // AI 输出被直接采纳的比率
    modificationRate: number;    // 需要修改的比率
    averageQuality: number;      // 平均质量评分 1-5
    lastUsedAt: string;
  };

  // 审核状态
  review: {
    status: 'draft' | 'review' | 'approved' | 'deprecated';
    reviewedBy?: string;
    reviewedAt?: string;
  };
}

interface Prompt {
  metadata: PromptMetadata;
  content: string;
  variables: PromptVariable[];
  examples: PromptExample[];
  notes: string;
}

interface PromptVariable {
  name: string;
  description: string;
  type: 'string' | 'number' | 'boolean' | 'code';
  required: boolean;
  defaultValue?: string;
}

interface PromptExample {
  input: Record<string, string>;
  expectedOutput: string;
  actualOutput?: string;
  quality?: number;
}
```

### 3.3 Prompt 效果评估脚本

```python
# scripts/evaluate_prompts.py
import json
from pathlib import Path
from datetime import datetime, timedelta

class PromptEvaluator:
    def __init__(self, prompts_dir: str, feedback_file: str):
        self.prompts_dir = Path(prompts_dir)
        self.feedback = self._load_feedback(feedback_file)

    def _load_feedback(self, path: str) -> list[dict]:
        """加载用户反馈数据"""
        with open(path, 'r', encoding='utf-8') as f:
            return json.load(f)

    def calculate_metrics(self, prompt_id: str) -> dict:
        """计算单个 Prompt 的效果指标"""
        feedbacks = [f for f in self.feedback if f['prompt_id'] == prompt_id]

        if not feedbacks:
            return {'status': 'no_data'}

        total = len(feedbacks)
        accepted = sum(1 for f in feedbacks if f['action'] == 'accepted')
        modified = sum(1 for f in feedbacks if f['action'] == 'modified')
        rejected = sum(1 for f in feedbacks if f['action'] == 'rejected')

        return {
            'usage_count': total,
            'acceptance_rate': accepted / total,
            'modification_rate': modified / total,
            'rejection_rate': rejected / total,
            'average_quality': sum(f['quality'] for f in feedbacks) / total,
            'last_used': max(f['timestamp'] for f in feedbacks),
        }

    def generate_report(self) -> str:
        """生成 Prompt 库效果报告"""
        report = ["# Prompt 库效果报告\n"]
        report.append(f"生成时间: {datetime.now().isoformat()}\n")

        for prompt_file in self.prompts_dir.glob("**/*.md"):
            prompt_id = prompt_file.stem
            metrics = self.calculate_metrics(prompt_id)

            if metrics.get('status') == 'no_data':
                continue

            report.append(f"\n## {prompt_id}")
            report.append(f"- 使用次数: {metrics['usage_count']}")
            report.append(f"- 采纳率: {metrics['acceptance_rate']:.1%}")
            report.append(f"- 修改率: {metrics['modification_rate']:.1%}")
            report.append(f"- 平均质量: {metrics['average_quality']:.1f}/5.0")

            # 预警
            if metrics['acceptance_rate'] < 0.5:
                report.append(f"- ⚠️ 采纳率过低，建议优化")
            if metrics['rejection_rate'] > 0.3:
                report.append(f"- 🔴 拒绝率过高，建议废弃或重写")

        return '\n'.join(report)

    def recommend_actions(self) -> list[dict]:
        """基于数据推荐操作"""
        actions = []

        for prompt_file in self.prompts_dir.glob("**/*.md"):
            prompt_id = prompt_file.stem
            metrics = self.calculate_metrics(prompt_id)

            if metrics.get('status') == 'no_data':
                continue

            if metrics['acceptance_rate'] < 0.3:
                actions.append({
                    'prompt_id': prompt_id,
                    'action': 'deprecate',
                    'reason': '采纳率低于 30%',
                })
            elif metrics['acceptance_rate'] > 0.8 and metrics['usage_count'] > 50:
                actions.append({
                    'prompt_id': prompt_id,
                    'action': 'promote',
                    'reason': '高质量高使用量，推荐为标准模板',
                })

        return actions


if __name__ == '__main__':
    evaluator = PromptEvaluator(
        prompts_dir='./prompts',
        feedback_file='./data/feedback.json'
    )
    print(evaluator.generate_report())
```

```yaml
# .github/workflows/knowledge-collection.yml
name: Knowledge Collection

on:
  pull_request:
    types: [closed]

jobs:
  extract-knowledge:
    if: github.event.pull_request.merged == true
    runs-on: ubuntu-latest

    steps:
      - name: Extract AI coding patterns
        run: |
          # 分析合并的 PR，提取 AI 相关知识
          # 1. 检查提交信息中的 AI 标注
          # 2. 分析代码中的 AI 工具使用
          # 3. 提取有价值的 Prompt 和技巧
          node scripts/extract-knowledge.js \
            --pr "${{ github.event.pull_request.number }}" \
            --output "knowledge-base/auto-extracted/"

      - name: Create knowledge PR
        if: steps.extract.outputs.has_knowledge == 'true'
        uses: peter-evans/create-pull-request@v6
        with:
          title: "📚 知识沉淀: 从 PR #${{ github.event.pull_request.number }} 提取"
          body: "自动从合并的 PR 中提取的 AI 编程知识"
          branch: "knowledge/extract-${{ github.event.pull_request.number }}"

## 5. 知识文档编写规范

### 5.1 文档质量标准

```markdown
## 知识文档质量检查清单

### 完整性
- [ ] 有明确的问题描述
- [ ] 有可复现的解决方案
- [ ] 有代码/Prompt 示例
- [ ] 有验证结果

### 可用性
- [ ] 标签准确，便于搜索
- [ ] 示例可直接复制使用
- [ ] 有适用范围说明
- [ ] 有版本/环境信息

### 可维护性
- [ ] 有作者和日期
- [ ] 有版本历史
- [ ] 定期更新（至少每季度）
- [ ] 有关联条目
```

## 为团队编写知识沉淀文档

**关键代码/Prompt**:
\```

\```

请按照以下结构输出：

输出为 Markdown 格式。

## 6. 常见错误

### ❌ 错误 1：知识文档只写不更新

```
问题：文档写完就再也没人维护，内容过时

解决：
- 文档绑定代码版本，代码更新时文档同步更新
- 设置季度审查提醒
- 将文档更新纳入 Definition of Done
```

### ❌ 错误 2：Prompt 库没有反馈机制

```
问题：Prompt 只管发布不管效果，好用不好用都不知道

解决：
- 每次使用后收集反馈（1-5 分评分）
- 定期分析采纳率、修改率
- 淘汰低质量 Prompt，推广高质量 Prompt
```

### ❌ 错误 3：知识孤岛

```
问题：知识散落在各处，Slack 里、Wiki 里、个人笔记里

解决：
- 建立统一的知识库仓库
- 制定知识录入流程
- 搜索和导航要便利
```

### ❌ 错误 4：只关注 Prompt 不关注经验

```
问题：只收集 Prompt，忽略使用经验和踩坑记录

解决：知识库应包含
- Prompt 模板（直接可用）
- 最佳实践（方法论）
- 踩坑记录（避坑指南）
- 工具配置（环境搭建）
```

## 9. 练习

### 练习 1：设计知识库结构（30 分钟）

为你的团队设计一个 AI 编程知识库的目录结构：

1. 规划至少 3 个一级分类
2. 每个分类下至少 2 个子分类
3. 为每个分类编写说明文档
4. 设计知识条目的元数据字段

### 练习 2：编写 Prompt 模板（45 分钟）

选择一个常见开发场景，编写一个高质量的 Prompt 模板：

- 必须包含完整的元数据
- 至少定义 3 个变量
- 提供 2 个使用示例
- 编写效果评估标准

### 练习 3：知识评估实践（30 分钟）

对以下 Prompt 进行效果评估，编写评估报告：

```
请帮我写一个函数，功能是：输入一个数组，返回去重后的结果。

要求：
1. 保持原数组顺序
2. 时间复杂度 O(n)
3. 支持对象数组去重（按 JSON 字符串比较）
```

评估维度：
- Prompt 清晰度
- 约束完整性
- AI 输出质量
- 改进建议
