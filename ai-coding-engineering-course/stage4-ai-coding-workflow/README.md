# Stage 4: AI 编程工作流

> 将 AI 融入日常开发工作流的每一个环节，从需求分析到代码部署。

## 课程定位

本阶段是 AI 编程工程课程的第四阶段，聚焦于**将 AI 工具系统性地嵌入软件开发全生命周期**。前三阶段分别掌握了 AI 编程基础、提示词工程和代码质量控制，本阶段将这些能力整合为完整的工程工作流。

## 前置要求

- 完成 Stage 1-3 的学习
- 熟悉 Git 基本操作
- 了解 REST API 开发
- 具备基本的 TypeScript/Python 项目经验

## 学习目标

完成本阶段后，你将能够：

1. **构建 AI 驱动的开发工作流** — 从需求到部署的全流程 AI 辅助
2. **自动化日常开发任务** — Git 操作、文档生成、代码审查
3. **高效调试复杂问题** — 系统性地使用 AI 定位和修复 Bug
4. **加速技术学习** — 用 AI 构建结构化的学习路径
5. **执行代码迁移项目** — 安全地进行大规模代码重构和迁移
