## 一、无限滚动加载——让页面"吐"出更多内容

### 1.1 什么是无限滚动？

```
无限滚动（Infinite Scroll）的工作原理：

  ┌─────────────────────────────────────────────┐
  │  用户看到的页面                               │
  │                                             │
  │  ┌───────────────────────────────────────┐  │
  │  │  商品 1                               │  │
  │  │  商品 2                               │  │
  │  │  商品 3                               │  │
  │  │  ...                                  │  │
  │  │  商品 10                              │  │
  │  │                                       │  │
  │  │  ┌─────────────────────────────────┐  │  │
  │  │  │  ↓ 继续滚动加载更多...           │  │  │
  │  │  └─────────────────────────────────┘  │  │
  │  └───────────────────────────────────────┘  │
  │                                             │
  │  JS 监听 scroll 事件                         │
  │  当滚动到底部附近时 → 发 API 请求加载下一页   │
  │  新数据追加到列表末尾                         │
  │                                             │
  └─────────────────────────────────────────────┘

  问题：Playwright 的 page.content() 只能拿到当前已加载的内容
  如果你不滚动，就只能拿到第一批数据
```

**生活类比：** 无限滚动就像一卷很长很长的卷轴画——你每展开一段（滚动），画师（JS）就画出新的内容。如果你不展开，就永远只能看到已经画好的部分。

### 1.2 用 Playwright 实现自动滚动

```python
from playwright.sync_api import sync_playwright
import time

def scroll_to_bottom(page, max_scrolls=10, wait_time=2):
    """
    自动滚动页面到底部，触发无限滚动加载

    参数：
        page: Playwright 的 page 对象
        max_scrolls: 最大滚动次数（防止无限循环）
        wait_time: 每次滚动后等待的秒数
    """
    for i in range(max_scrolls):
        # 记录滚动前的页面高度
        previous_height = page.evaluate("document.body.scrollHeight")

        # 滚动到页面底部
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")

        # 等待新内容加载
        page.wait_for_timeout(wait_time * 1000)  # wait_for_timeout 单位是毫秒

        # 检查页面高度是否变化
        new_height = page.evaluate("document.body.scrollHeight")

        if new_height == previous_height:
            print(f"滚动 {i+1} 次后，页面高度不再变化，已到达底部")
            break
        else:
            print(f"第 {i+1} 次滚动，页面高度: {previous_height} → {new_height}")

    print("滚动完成")
```

```
滚动策略图示：

  ┌─────────────────────────────────────────────────────┐
  │  滚动前                                              │
  │  页面高度 = 1000px                                   │
  │  已加载 10 个商品                                    │
  └──────────────────────────┬──────────────────────────┘
                             │
                    window.scrollTo(0, 1000)
                             │
                             ▼
  ┌─────────────────────────────────────────────────────┐
  │  等待 2 秒（JS 发 API 请求、渲染新内容）              │
  └──────────────────────────┬──────────────────────────┘
                             │
                             ▼
  ┌─────────────────────────────────────────────────────┐
  │  滚动后                                              │
  │  页面高度 = 2000px（变高了！说明加载了新内容）        │
  │  已加载 20 个商品                                    │
  │  → 继续滚动                                          │
  └──────────────────────────┬──────────────────────────┘
                             │
                    重复直到高度不再变化
                             │
                             ▼
  ┌─────────────────────────────────────────────────────┐
  │  页面高度 = 5000px（不再变化）                       │
  │  已加载 50 个商品（全部数据）                        │
  │  → 停止滚动，提取数据                                │
  └─────────────────────────────────────────────────────┘
```

### 1.3 更智能的滚动：基于元素数量判断

```python
from playwright.sync_api import sync_playwright

def scroll_until_no_new_items(page, selector, max_scrolls=20, wait_time=2):
    """
    滚动直到没有新元素出现（更可靠的判断方式）

    参数：
        page: Playwright 的 page 对象
        selector: 目标元素的 CSS 选择器
        max_scrolls: 最大滚动次数
        wait_time: 每次滚动后等待秒数
    """
    previous_count = 0

    for i in range(max_scrolls):
        # 统计当前已加载的元素数量
        current_count = page.eval_on_selector_all(
            selector, "elements => elements.length"
        )
        print(f"第 {i+1} 次滚动前，已加载 {current_count} 个元素")

        if current_count == previous_count and i > 0:
            print("没有新元素出现，已加载全部数据")
            break

        previous_count = current_count

        # 滚动到最后一个元素的位置
        page.eval_on_selector(
            selector + ":last-child",
            "el => el.scrollIntoView({behavior: 'smooth'})"
        )

        # 等待新内容加载
        page.wait_for_timeout(wait_time * 1000)

    # 返回最终的元素数量
    return page.eval_on_selector_all(selector, "elements => elements.length")
```

## 二、wait_for_load_state() 的进阶用法

### 2.1 组合使用多种等待策略

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()

    # ── 基本导航 ──
    page.goto("https://example.com")

    # ── 等待 DOM 解析完成 ──
    page.wait_for_load_state("domcontentloaded")
    print("DOM 解析完成，可以操作元素了")

    # ── 等待所有资源加载 ──
    page.wait_for_load_state("load")
    print("图片、CSS 等资源加载完成")

    # ── 等待网络空闲（AJAX 请求完成）──
    page.wait_for_load_state("networkidle")
    print("所有网络请求已完成")

    browser.close()
```

### 2.2 在交互后等待新内容

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/products")

    # ── 点击"加载更多"按钮后等待 ──
    page.click("button.load-more")

    # 方法1：等待网络空闲
    page.wait_for_load_state("networkidle")

    # 方法2：等待新元素出现（更精确）
    page.wait_for_selector(".product-item:nth-child(20)")

    # 方法3：等待特定的 API 请求完成
    with page.expect_response("**/api/products*") as response_info:
        page.click("button.load-more")
    response = response_info.value
    data = response.json()
    print(f"API 返回了 {len(data['products'])} 个新商品")

    browser.close()
```

```
等待策略选择指南：

  ┌───────────────────────────┬──────────────────────────────────┐
  │  场景                     │  推荐等待方式                     │
  ├───────────────────────────┼──────────────────────────────────┤

  ├───────────────────────────┼──────────────────────────────────┤
```

## 三、处理 JavaScript 渲染的内容

### 3.1 提取 JS 渲染后的数据

```python
from playwright.sync_api import sync_playwright
from bs4 import BeautifulSoup

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()

    # 访问动态渲染的页面
    page.goto("https://spa5.scrape.center/")
    page.wait_for_selector(".book-item")

    # ── 方法1：用 page.content() + BeautifulSoup ──
    html = page.content()
    soup = BeautifulSoup(html, "html.parser")
    books = soup.select(".book-item")

    for book in books:
        title = book.select_one("h2")
        price = book.select_one(".price")
        if title and price:
            print(f"{title.text.strip()} - {price.text.strip()}")

    # ── 方法2：直接用 Playwright 的选择器 API ──
    elements = page.query_selector_all(".book-item")
    for el in elements:
        title = el.query_selector("h2")
        price = el.query_selector(".price")
        if title and price:
            print(f"{title.inner_text()} - {price.inner_text()}")

    # ── 方法3：用 evaluate 执行 JS 提取数据 ──
    data = page.evaluate("""
        () => {
            const items = document.querySelectorAll('.book-item');
            return Array.from(items).map(item => ({
                title: item.querySelector('h2')?.innerText || '',
                price: item.querySelector('.price')?.innerText || '',
                image: item.querySelector('img')?.src || '',
            }));
        }
    """)
    for item in data:
        print(f"{item['title']} - {item['price']}")

    browser.close()
```

```
三种提取方式的对比：

  ┌──────────────────┬────────────┬────────────┬──────────────┐
  │  方式             │  速度       │  灵活性     │  适用场景     │
  ├──────────────────┼────────────┼────────────┼──────────────┤
  │  content() + BS4 │  ★★★★☆    │  ★★★★☆    │  已有 BS4 代码│
  │  query_selector  │  ★★★★★    │  ★★★☆☆    │  简单提取     │
  │  evaluate + JS   │  ★★★★★    │  ★★★★★    │  复杂数据处理 │
  └──────────────────┴────────────┴────────────┴──────────────┘

  推荐：简单场景用 query_selector，复杂数据处理用 evaluate
```

```python
with sync_playwright() as p:
```

### 4.3 处理"加载更多"按钮

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/articles")

    all_items = []

    while True:
        # 提取当前页面的数据
        items = page.query_selector_all(".article-item")
        new_count = len(items) - len(all_items)
        print(f"本次加载了 {new_count} 篇文章")

        all_items = items

        # 检查是否有"加载更多"按钮
        load_more = page.query_selector("button.load-more")
        if not load_more or not load_more.is_visible():
            print("没有更多数据了")
            break

        # 点击"加载更多"
        load_more.click()

        # 等待新内容加载
        page.wait_for_load_state("networkidle")

        # 防止无限循环
        if len(all_items) > 500:
            print("达到上限，停止加载")
            break

    print(f"\n总共获取 {len(all_items)} 篇文章")

    browser.close()
```

## 五、处理弹窗和对话框

### 5.1 JavaScript 弹窗类型

```
常见的 JS 弹窗类型：

  ┌──────────────┬────────────────────────┬──────────────────────┐
  │  弹窗类型     │  触发方式              │  Playwright 处理方式  │
  ├──────────────┼────────────────────────┼──────────────────────┤
  │  alert       │  alert("消息")          │  page.on("dialog")  │
  │  简单提示     │  只有"确定"按钮         │  dialog.accept()    │
  ├──────────────┼────────────────────────┼──────────────────────┤
  │  confirm     │  confirm("确认？")      │  page.on("dialog")  │
  │  确认框       │  "确定"和"取消"按钮     │  accept() 或        │
  │              │                        │  dismiss()          │
  ├──────────────┼────────────────────────┼──────────────────────┤
  │  prompt      │  prompt("请输入：")     │  page.on("dialog")  │
  │  输入框       │  带输入框和确认按钮     │  dialog.accept(值)  │
  ├──────────────┼────────────────────────┼──────────────────────┤
  │  beforeunload│  关闭页面时触发         │  page.on("dialog")  │
  │  离开确认     │  "确定要离开吗？"       │  dialog.accept()    │
  └──────────────┴────────────────────────┴──────────────────────┘
```

### 5.2 处理弹窗

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()

    # ── 注册弹窗处理器（在触发弹窗的操作之前注册）──

    # 处理 alert 弹窗
    page.on("dialog", lambda dialog: dialog.accept())

    # 更精细的处理
    def handle_dialog(dialog):
        print(f"弹窗类型: {dialog.type}")
        print(f"弹窗消息: {dialog.message}")

        if dialog.type == "confirm":
            # confirm 弹窗：可以选择确定或取消
            dialog.accept()    # 点击"确定"
            # dialog.dismiss() # 点击"取消"
        elif dialog.type == "prompt":
            # prompt 弹窗：可以输入文字
            dialog.accept("我的输入内容")
        else:
            # alert 弹窗：只能点确定
            dialog.accept()

    page.on("dialog", handle_dialog)

    page.goto("https://example.com")
    # 之后所有弹窗都会被自动处理

    browser.close()
```

**生活类比：** 处理弹窗就像设置了一个"自动回复机器人"——不管弹出什么对话框，机器人都会按照你预设的规则自动点击"确定"或"取消"，不会让弹窗阻塞你的程序。

## 六、下载文件

### 6.1 使用 Playwright 下载文件

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/downloads")

    # ── 方法1：监听 download 事件 ──
    with page.expect_download() as download_info:
        page.click("a.download-link")  # 点击下载链接
    download = download_info.value

    # 保存到指定路径
    download.save_as("downloads/file.xlsx")
    print(f"文件已保存: {download.suggested_filename}")

    # ── 方法2：处理需要确认的下载 ──
    with page.expect_download() as download_info:
        page.click("button.download-btn")
        # 如果有确认弹窗，在这里处理
    download = download_info.value
    download.save_as("downloads/report.pdf")

    browser.close()
```

### 6.2 下载多个文件

```python
from playwright.sync_api import sync_playwright
import os

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/files")

    # 创建下载目录
    os.makedirs("downloads", exist_ok=True)

    # 获取所有下载链接
    links = page.query_selector_all("a.download-link")
    print(f"找到 {len(links)} 个下载链接")

    for i, link in enumerate(links):
        # 监听下载事件
        with page.expect_download() as download_info:
            link.click()
        download = download_info.value

        # 保存文件
        filename = download.suggested_filename
        download.save_as(f"downloads/{filename}")
        print(f"[{i+1}/{len(links)}] 已下载: {filename}")

    browser.close()
    print(f"\n所有文件已保存到 downloads/ 目录")
```

```python
演示：滚动加载 + 数据提取 + 异常处理

from playwright.sync_api import sync_playwright
import json
import time

def scrape_books():
    """爬取全部书籍数据"""
    all_books = []

    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()

        # 设置视口大小（影响页面布局）
        page.set_viewport_size({"width": 1280, "height": 800})

        print("正在访问目标网站...")
        page.goto("https://spa5.scrape.center/", wait_until="networkidle")

        # 等待书籍列表加载
        page.wait_for_selector(".book-item", timeout=15000)
        print("书籍列表已加载")

        # 滚动加载全部数据
        previous_count = 0
        scroll_times = 0
        max_scrolls = 30

        while scroll_times < max_scrolls:
            # 统计当前数量
            current_count = page.eval_on_selector_all(
                ".book-item", "els => els.length"
            )

            if current_count == previous_count and scroll_times > 0:
                print(f"滚动 {scroll_times} 次后，没有新数据")
                break

            print(f"第 {scroll_times + 1} 次滚动，当前 {current_count} 本书")
            previous_count = current_count

            # 滚动到最后一个元素
            page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
            page.wait_for_timeout(2000)  # 等待加载
            scroll_times += 1

        # 提取所有书籍数据
        print("\n正在提取数据...")
        books_data = page.evaluate("""
            () => {
                const items = document.querySelectorAll('.book-item');
                return Array.from(items).map((item, index) => ({
                    index: index + 1,
                    title: item.querySelector('h2')?.innerText?.trim() || '',
                    price: item.querySelector('.price')?.innerText?.trim() || '',
                    rating: item.querySelector('.el-rate')?.getAttribute('aria-label') || '',
                    image: item.querySelector('img')?.src || '',
                    detail_url: item.querySelector('a')?.href || '',
                }));
            }
        """)

        all_books = books_data
        print(f"\n共提取 {len(all_books)} 本书籍数据")

        browser.close()

    return all_books

def save_results(books, filename="books.json"):

    with open(filename, "w", encoding="utf-8") as f:
        json.dump(books, f, ensure_ascii=False, indent=2)
    print(f"数据已保存到 {filename}")

    """展示前 5 条数据"""
    print("\n" + "=" * 60)
    print("前 5 本书籍信息：")
    print("=" * 60)

    for book in books[:5]:

        print(f"    评分: {book['rating']}")

    if len(books) > 5:
        print(f"\n... 还有 {len(books) - 5} 本书籍")

if __name__ == "__main__":

    books = scrape_books()
```

### 10.2 用 Playwright 拦截 API 请求

```python
from playwright.sync_api import sync_playwright

def intercept_api():
    """用 Playwright 拦截页面的 API 请求"""
    captured_requests = []
    captured_responses = []

    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()

        # ── 监听所有网络请求 ──
        def on_request(request):
            # 只关注 API 请求（XHR/fetch）
            if request.resource_type in ("xhr", "fetch"):
                captured_requests.append({
                    "url": request.url,
                    "method": request.method,
                    "headers": request.headers,
                    "post_data": request.post_data,
                })
                print(f"[请求] {request.method} {request.url}")

        def on_response(response):
            if response.request.resource_type in ("xhr", "fetch"):
                try:
                    body = response.json()
                    captured_responses.append({
                        "url": response.url,
                        "status": response.status,
                        "data": body,
                    })
                    print(f"[响应] {response.status} {response.url}")
                except Exception:
                    pass

        page.on("request", on_request)
        page.on("response", on_response)

        # 访问目标页面
        page.goto("https://spa5.scrape.center/")
        page.wait_for_load_state("networkidle")

        # 滚动一下，触发更多 API 请求
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
        page.wait_for_timeout(3000)

        browser.close()

    return captured_requests, captured_responses

# 运行拦截
requests_data, responses_data = intercept_api()

print(f"\n捕获到 {len(requests_data)} 个 API 请求")
for req in requests_data:
    print(f"  {req['method']} {req['url']}")
```

### 10.4 用 expect_response 捕获特定响应

```python
from playwright.sync_api import sync_playwright
import requests as req_lib  # 避免和 Playwright 的 route 冲突

def get_api_info_with_playwright(url):
    """
    用 Playwright 打开页面，捕获 API 响应
    返回 API 的地址和返回的数据
    """
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()

        api_data = None

        # 监听特定 API 响应
        def capture_response(response):
            nonlocal api_data
            if "/api/" in response.url and response.status == 200:
                try:
                    api_data = {
                        "url": response.url,
                        "headers": dict(response.headers),
                        "cookies": page.context.cookies(),
                        "data": response.json(),
                    }
                except Exception:
                    pass

        page.on("response", capture_response)
        page.goto(url, wait_until="networkidle")

        browser.close()

    return api_data

def fetch_with_requests(api_info, params=None):
    """
    用 requests 高速调用已知的 API
    """
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                      "Chrome/120.0.0.0 Safari/537.36",
    }

    # 复制 Playwright 捕获的 cookies
    cookies = {}
    if api_info.get("cookies"):
        for cookie in api_info["cookies"]:
            cookies[cookie["name"]] = cookie["value"]

    response = req_lib.get(
        api_info["url"],
        headers=headers,
        cookies=cookies,
        params=params,
        timeout=10,
    )
    return response.json()

# 完整流程
print("阶段1：用 Playwright 分析 API...")
api_info = get_api_info_with_playwright("https://spa5.scrape.center/")

if api_info:
    print(f"找到 API: {api_info['url']}")
    print(f"API 返回了 {len(api_info['data'].get('results', []))} 条数据")

    print("\n阶段2：用 requests 批量抓取...")
    all_data = []
    for page_num in range(1, 4):
        data = fetch_with_requests(api_info, params={"offset": page_num * 18})
        results = data.get("results", [])
        all_data.extend(results)
        print(f"第 {page_num} 页: {len(results)} 条数据")

    print(f"\n共抓取 {len(all_data)} 条数据")
```

## 小结

本课的核心知识点：

1. **无限滚动** 通过 `window.scrollTo()` 配合元素数量变化检测来实现自动加载
2. **`wait_for_load_state()`** 有三种策略：domcontentloaded（最快）、load（资源加载完）、networkidle（网络空闲）
3. **页面交互** 包括点击标签页、展开折叠区域、处理"加载更多"按钮
4. **弹窗处理** 通过 `page.on("dialog")` 注册处理器，支持 alert、confirm、prompt
5. **文件下载** 使用 `page.expect_download()` 监听下载事件，`download.save_as()` 保存文件
6. **多标签页** 通过 `context.new_page()` 创建，`context.pages` 管理所有标签页
7. **性能选择原则**：能用 requests 就不用 Playwright，Playwright 是"重型武器"
8. **混合方案** 是最佳实践：用 Playwright 一次性分析 API，再用 requests 高速批量抓取
9. **`page.route()` 和 `page.on("response")`** 可以拦截和分析网络请求，是混合方案的核心技术
10. **`page.evaluate()`** 可以执行任意 JS 代码，是最灵活的数据提取方式

> **前端开发者的优势：** 本课的很多操作——滚动监听、标签页切换、弹窗处理、AJAX 请求拦截——都是你在前端开发中天天做的事情。现在你只需要把"构建交互"的思维转换成"捕获交互"的思维。你知道页面是怎么加载数据的，现在你要做的就是"偷听"这个过程，把数据截取下来。
