## 一、为什么分页策略很重要？

### 1.1 一个现实问题

你想爬取某个电商网站搜索"机械键盘"的结果，一共 500 条商品，但每页只显示 20 条。你需要翻 25 页才能拿到全部数据。

```
┌──────────────────────────────────────────────────────────┐
│  分页爬取的挑战                                            │
│                                                          │
│  第1页  第2页  第3页  ...  第25页                          │
│  ┌───┐  ┌───┐  ┌───┐     ┌───┐                          │
│  │20 │  │20 │  │20 │     │20 │  = 500 条数据             │
│  │条 │  │条 │  │条 │     │条 │                            │
│  └───┘  └───┘  └───┘     └───┘                          │
│                                                          │
│  你需要：知道总页数、构造请求、知道何时停止、处理错误       │
└──────────────────────────────────────────────────────────┘
```

### 1.2 常见的分页模式

```
┌──────────────────────────────────────────────────────────┐
│  三种主流分页模式                                          │
│                                                          │
│  模式一：URL 参数翻页（最常见，最友好）                    │
│    /search?q=键盘&page=1  →  page=2  →  page=3           │
│                                                          │
│  模式二：按钮/链接翻页（需要解析页面）                     │
│    [上一页] [1] [2] [3] ... [10] [下一页]                 │
│    → 点击"下一页"获取下一页的 URL                         │
│                                                          │
│  模式三：无限滚动（需要模拟滚动或调 API）                  │
│    向下滚动 → 加载更多 → 继续滚动 → ...                   │
│    → 需要 Playwright（第三阶段）                          │
└──────────────────────────────────────────────────────────┘
```

**生活类比：** 分页翻页就像翻一本书。URL 参数翻页是"直接翻到第 N 页"，按钮翻页是"一页一页地翻"，无限滚动是"卷轴式阅读"。

## 二、URL 参数翻页

### 2.1 分析 URL 规律

这是最简单也最常用的翻页方式。找到 URL 中控制页码的参数，循环修改它。

```python
# 常见的 URL 分页参数格式
# https://example.com/search?q=键盘&page=2
# https://example.com/list?p=3
# https://example.com/products?pn=1&ps=20
```

### 2.2 构建翻页循环

```python
import requests
from bs4 import BeautifulSoup
import time

base_url = "https://example.com/search"
keyword = "机械键盘"

for page in range(1, 26):  # 爬取第 1 到第 25 页
    print(f"正在爬取第 {page} 页...")

    params = {'q': keyword, 'page': page}
    response = requests.get(base_url, params=params)

    if response.status_code != 200:
        print(f"第 {page} 页请求失败，状态码: {response.status_code}")
        continue

    soup = BeautifulSoup(response.text, 'lxml')
    products = soup.select('.product-card')

    if not products:
        print(f"第 {page} 页没有数据，停止爬取")
        break

    for product in products:
        name = product.select_one('.name').get_text(strip=True)
        price = product.select_one('.price').get_text(strip=True)
        print(f"  {name} - {price}")

    time.sleep(1)  # 礼貌等待

print("全部爬取完成！")
```

### 2.3 自动检测总页数

硬编码页数不灵活。更好的做法是从页面中提取总页数：

```python
def get_total_pages(soup):
    """从页面中提取总页数"""
    # 方法一：从"共 X 页"文本中提取
    import re
    page_info = soup.select_one('.page-info')
    if page_info:
        match = re.search(r'共\s*(\d+)\s*页', page_info.get_text())
        if match:
            return int(match.group(1))

    # 方法二：从页码链接中找最大值
    page_links = soup.select('.pagination a')
    max_page = 1
    for link in page_links:
        if link.get_text(strip=True).isdigit():
            max_page = max(max_page, int(link.get_text(strip=True)))

    return max_page

# 使用
response = requests.get("https://example.com/search?q=键盘&page=1")
soup = BeautifulSoup(response.text, 'lxml')
total_pages = get_total_pages(soup)
print(f"共 {total_pages} 页")
```

```
┌──────────────────────────────────────────────────────────┐
│  自动检测总页数的思路                                      │
│                                                          │
│  方式一：从"共X页"文字提取                                 │
│    <span>共 25 页，500 条结果</span>  → 正则提取 25       │
│                                                          │
│  方式二：从页码链接中找最大值                              │
│    <a>1</a> <a>2</a> ... <a>25</a>  → 取最大值           │
│                                                          │
│  方式三：从最后一页链接提取                                │
│    <a href="?page=25">末页</a>  → 解析 page 参数          │
│                                                          │
│  方式四：循环到空结果为止（兜底方案）                      │
└──────────────────────────────────────────────────────────┘
```

## 三、按钮/链接翻页

### 3.1 找到"下一页"链接

有些网站的分页不靠 URL 参数，而是靠页面上的"下一页"按钮。

```python
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin
import time

url = "https://example.com/articles"

while url:
    print(f"正在爬取: {url}")
    response = requests.get(url)
    soup = BeautifulSoup(response.text, 'lxml')

    # 处理当前页的数据
    for article in soup.select('.article-item'):
        title = article.select_one('.title').get_text(strip=True)
        print(f"  - {title}")

    # 找到"下一页"链接
    next_link = soup.select_one('a.next-page')

    if next_link and next_link.get('href'):
        next_href = next_link['href']
        # 处理相对路径
        url = urljoin(response.url, next_href) if not next_href.startswith('http') else next_href
    else:
        print("没有下一页了")
        url = None

    time.sleep(1)
```

### 3.2 防止无限循环

```python
visited_urls = set()  # 记录已访问的 URL
url = "https://example.com/articles?page=1"

while url:
    if url in visited_urls:
        print(f"检测到重复页面，停止爬取")
        break

    visited_urls.add(url)
    response = requests.get(url)
    soup = BeautifulSoup(response.text, 'lxml')

    articles = soup.select('.article-item')
    if not articles:
        print("当前页没有数据，停止")
        break

    for article in articles:
        title = article.select_one('.title').get_text(strip=True)
        print(f"  - {title}")

    next_link = soup.select_one('a.next-page')
    url = urljoin(response.url, next_link['href']) if next_link and next_link.get('href') else None
    time.sleep(1)

print(f"共爬取 {len(visited_urls)} 页")
```

```
┌──────────────────────────────────────────────────────────┐
│  防止无限循环的三道防线                                    │
│                                                          │
│  第一道：visited_urls 集合 → 检测重复访问                  │
│  第二道：页面无数据检测 → 当前页没数据时停止                │
│  第三道：最大页数限制 → 设上限，比如最多 100 页             │
│                                                          │
│  三道防线同时使用，万无一失！                              │
└──────────────────────────────────────────────────────────┘
```

## 四、无限滚动（预览）

### 4.1 什么是无限滚动？

无限滚动（Infinite Scroll）是现代网站常用的交互方式——向下滚动页面，新内容自动加载。微博、知乎、Twitter 都是这种模式。

爬虫策略有两种：思路一是直接调用隐藏的 API（推荐），思路二是模拟滚动（需要 Playwright，第三阶段内容）。

### 4.2 探测隐藏的 API

```python
import requests, time

api_url = "https://example.com/api/articles"
all_articles, offset, limit = [], 0, 20

while True:
    response = requests.get(api_url, params={'offset': offset, 'limit': limit})
    data = response.json()
    articles = data.get('articles', [])
    if not articles:
        break
    all_articles.extend(articles)
    offset += limit
    if offset >= data.get('total', 0):
        break
    time.sleep(0.5)

print(f"共获取 {len(all_articles)} 条数据")
```

通过 DevTools Network 面板找到加载数据的 AJAX 请求，直接调 API 获取 JSON 数据，不需要模拟浏览器。这是处理无限滚动最高效的方式。

## 五、错误处理与重试机制

### 5.1 翻页中常见的错误

翻页时会遇到：网络超时（加重试）、请求被拒 403/429（降频率加 UA）、页面结构异常（try-except）、中途断网（保存进度）、页码超出范围（检测空数据）。

### 5.2 实现请求重试

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def create_session():
    """创建带重试机制的请求会话"""
    session = requests.Session()
    retry_strategy = Retry(
        total=3,                                     # 最多重试 3 次
        backoff_factor=1,                            # 间隔倍数（1s, 2s, 4s）
        status_forcelist=[429, 500, 502, 503, 504],  # 这些状态码触发重试
    )
    adapter = HTTPAdapter(max_retries=retry_strategy)
    session.mount("http://", adapter)
    session.mount("https://", adapter)
    session.headers.update({
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
    })
    return session

def fetch_page(session, url, params=None):
    """请求页面，带错误处理"""
    try:
        response = session.get(url, params=params, timeout=10)
        response.raise_for_status()
        return response
    except requests.exceptions.Timeout:
        print(f"请求超时: {url}")
    except requests.exceptions.HTTPError as e:
        print(f"HTTP 错误: {e}")
    except requests.exceptions.ConnectionError:
        print(f"连接失败: {url}")
    return None
```

### 5.3 完整的翻页爬取框架

```python
from bs4 import BeautifulSoup
import time

def scrape_all_pages(base_url, keyword, max_pages=100):
    """带错误处理的完整翻页爬取"""
    session = create_session()
    all_data = []

    for page in range(1, max_pages + 1):
        params = {'q': keyword, 'page': page}
        response = fetch_page(session, base_url, params=params)

        if not response:
            continue  # 请求失败，跳过

        soup = BeautifulSoup(response.text, 'lxml')
        items = soup.select('.product-card')

        if not items:
            break  # 没有数据，停止

        for item in items:
            try:
                all_data.append({
                    'name': item.select_one('.name').get_text(strip=True),
                    'price': item.select_one('.price').get_text(strip=True),
                })
            except Exception:
                continue

        print(f"第 {page} 页 {len(items)} 条，累计 {len(all_data)} 条")

        if not soup.select_one('.pagination .next'):
            break  # 没有下一页

        time.sleep(2)

    return all_data
```

## 六、断点续爬：保存与恢复进度

### 6.1 为什么需要断点续爬？

```
┌──────────────────────────────────────────────────────────┐
│  场景：你爬了 20 页（共 50 页），程序崩了...               │
│                                                          │
│  没有断点续爬：从第 1 页重新开始 → 浪费时间               │
│  有断点续爬：记录进度 → 从第 21 页继续 → 高效！           │
└──────────────────────────────────────────────────────────┘
```

### 6.2 用 JSON 文件保存进度

```python
import json
import os

PROGRESS_FILE = "scrape_progress.json"

def save_progress(page, data):
    """保存当前进度"""
    with open(PROGRESS_FILE, 'w', encoding='utf-8') as f:
        json.dump({'last_page': page, 'data': data}, f, ensure_ascii=False, indent=2)
    print(f"  进度已保存：第 {page} 页，共 {len(data)} 条")

def load_progress():
    """加载之前的进度"""
    if os.path.exists(PROGRESS_FILE):
        with open(PROGRESS_FILE, 'r', encoding='utf-8') as f:
            progress = json.load(f)
        print(f"发现历史进度：上次爬到第 {progress['last_page']} 页")
        return progress
    return None

def scrape_with_resume(base_url, keyword, max_pages=100):
    """支持断点续爬的翻页爬取"""
    session = create_session()
    progress = load_progress()
    start_page = (progress['last_page'] + 1) if progress else 1
    all_data = progress['data'] if progress else []

    for page in range(start_page, max_pages + 1):
        params = {'q': keyword, 'page': page}
        response = fetch_page(session, base_url, params=params)

        if not response:
            save_progress(page - 1, all_data)
            return all_data  # 进度已保存，下次继续

        soup = BeautifulSoup(response.text, 'lxml')
        items = soup.select('.product-card')

        if not items:
            save_progress(page - 1, all_data)
            break

        for item in items:
            try:
                all_data.append({
                    'name': item.select_one('.name').get_text(strip=True),
                    'price': item.select_one('.price').get_text(strip=True),
                })
            except Exception:
                continue

        if page % 5 == 0:
            save_progress(page, all_data)
        time.sleep(2)

    # 爬取完成，清除进度文件
    if os.path.exists(PROGRESS_FILE):
        os.remove(PROGRESS_FILE)
    return all_data
```

## 七、反爬策略与礼貌爬取

### 7.1 控制请求频率

```python
import random

# ❌ 不好：固定间隔，太规律容易被识别
for page in range(1, 26):
    time.sleep(1)  # 每次都等 1 秒

# ✅ 好：随机间隔，模拟人类行为
for page in range(1, 26):
    time.sleep(random.uniform(1, 3))  # 随机 1~3 秒
```

### 7.2 设置请求头与遵守 robots.txt

```python
# 设置请求头
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
    'Accept-Language': 'zh-CN,zh;q=0.9',
}
response = requests.get(url, headers=headers)

# 检查 robots.txt 是否允许爬取
from urllib.robotparser import RobotFileParser
from urllib.parse import urlparse

def can_scrape(url):
    parsed = urlparse(url)
    rp = RobotFileParser()
    rp.set_url(f"{parsed.scheme}://{parsed.netloc}/robots.txt")
    rp.read()
    return rp.can_fetch('*', url)
```

```
┌──────────────────────────────────────────────────────────┐
│  礼貌爬虫守则                                              │
│                                                          │
│  1. 控制频率：每次请求间隔 1-3 秒（随机）                  │
│  2. 设置 User-Agent：标明身份                             │
│  3. 遵守 robots.txt：尊重网站规则                         │
│  4. 错误时退让：遇到 429 就放慢速度                        │
│  5. 不要爬取敏感数据：只取公开信息                         │

```
