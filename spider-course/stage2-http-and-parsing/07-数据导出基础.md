## 一、为什么需要数据导出？

### 1.1 从"爬下来"到"用起来"

在前面的课程中，你已经学会了用 `requests` 发请求、用 `BeautifulSoup` 解析页面。但如果数据只停留在 Python 的变量里，程序一关，数据就没了。

打个生活中的比方：爬取数据就像从超市买菜回来，如果你不把菜放进冰箱（持久化存储），菜很快就会坏掉。数据导出就是你的"冰箱"。

```
  ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
  │   发送请求    │────→│   解析页面    │────→│   数据导出    │
  │   requests   │     │ BeautifulSoup │     │  csv / json  │
  └──────────────┘     └──────────────┘     └──────────────┘
         买菜                洗菜切菜              放进冰箱
```

### 1.2 常见的导出格式一览

```
  ┌────────────┬──────────────────────┬──────────────────────┐
  │   格式     │       适合场景       │       特点           │
  ├────────────┼──────────────────────┼──────────────────────┤
  │   CSV      │ 表格数据、Excel 打开 │ 简单、体积小         │
  │   JSON     │ 嵌套数据、API 交互   │ 结构灵活、通用性强   │
  │   Excel    │ 需要格式化的报表     │ 需要第三方库         │
  │   数据库   │ 大量数据、需要查询   │ 需要 SQL 知识        │
  └────────────┴──────────────────────┴──────────────────────┘
```

本课我们重点学习 **CSV** 和 **JSON**，它们是爬虫最常用的两种导出格式。

## 二、CSV 格式详解

### 2.1 什么是 CSV？

CSV 是 **Comma-Separated Values**（逗号分隔值）的缩写。你可以把它理解为一个"纯文本版的 Excel 表格"——每行是一条记录，每列之间用逗号隔开。

```
  CSV 文件内容（用文本编辑器打开）：

  姓名,城市,年龄
  张三,北京,28
  李四,上海,32
  王五,广州,25

  用 Excel 打开后：

  ┌──────┬──────┬──────┐
  │ 姓名 │ 城市 │ 年龄 │
  ├──────┼──────┼──────┤
  │ 张三 │ 北京 │  28  │
  │ 李四 │ 上海 │  32  │
  │ 王五 │ 广州 │  25  │
  └──────┴──────┴──────┘
```

**适用场景：**
- 数据是扁平的表格结构（行 x 列）
- 需要用 Excel 打开查看或分享给非技术人员
- 数据量大，CSV 体积比 JSON 小

### 2.2 用 csv.writer 写入 CSV

```python
import csv

# 准备数据
headers = ['姓名', '城市', '年龄']
rows = [
    ['张三', '北京', 28],
    ['李四', '上海', 32],
    ['王五', '广州', 25],
]

# 写入 CSV 文件
with open('output.csv', 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.writer(f)
    writer.writerow(headers)      # 写入表头（一行）
    writer.writerows(rows)        # 写入数据（多行）

print('CSV 写入完成！')
```

**关键点解释：**

- `newline=''`：防止在 Windows 上出现多余的空行。这是一个常见坑，不加的话每行之间会多出一个空行。
- `encoding='utf-8-sig'`：用带 BOM 的 UTF-8 编码，这样 Excel 打开时不会乱码。如果用 `utf-8`，Excel 打开中文可能会变成乱码。
- `writer.writerow()`：写一行
- `writer.writerows()`：写多行（传入二维列表）

### 2.3 用 csv.DictWriter 写入 CSV

如果你的数据是字典格式（爬虫数据通常是字典），用 `DictWriter` 更方便：

```python
import csv

# 数据是字典格式
data = [
    {'姓名': '张三', '城市': '北京', '年龄': 28},
    {'姓名': '李四', '城市': '上海', '年龄': 32},
    {'姓名': '王五', '城市': '广州', '年龄': 25},
]

headers = ['姓名', '城市', '年龄']

with open('output_dict.csv', 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.DictWriter(f, fieldnames=headers)
    writer.writeheader()          # 写入表头
    writer.writerows(data)        # 写入数据

print('DictWriter 写入完成！')
```

**对比两种写法：**

```
  ┌─────────────────┬──────────────────────────────────────┐
  │   csv.writer    │   传入二维列表 [[], [], []]          │
  │                 │   你需要自己保证列的顺序一致         │
  ├─────────────────┼──────────────────────────────────────┤
  │ csv.DictWriter  │   传入字典列表 [{}, {}, {}]          │
  │                 │   通过 fieldnames 自动对齐列         │
  └─────────────────┴──────────────────────────────────────┘
```

> **建议：** 爬虫场景下，数据通常是从网页提取的字典，推荐使用 `DictWriter`。

### 2.4 用 csv.reader 读取 CSV

```python
import csv

with open('output.csv', 'r', encoding='utf-8-sig') as f:
    reader = csv.reader(f)
    header = next(reader)         # 读取第一行作为表头
    print('表头:', header)

    for row in reader:
        print(row)                # 每行是一个列表
```

输出：

```
表头: ['姓名', '城市', '年龄']
['张三', '北京', '28']
['李四', '上海', '32']
```

注意：读出来的所有值都是**字符串**类型，数字 28 变成了 `'28'`，需要手动转换。

### 2.5 用 csv.DictReader 读取 CSV

```python
import csv

with open('output.csv', 'r', encoding='utf-8-sig') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)                # 每行是一个字典
        print(row['姓名'], row['城市'])
```

输出：

```
{'姓名': '张三', '城市': '北京', '年龄': '28'}
张三 北京
{'姓名': '李四', '城市': '上海', '年龄': '32'}
李四 上海
```

`DictReader` 会自动把第一行当作表头，后续每行都变成字典，非常方便。

## 三、JSON 格式详解

### 3.1 什么是 JSON？

JSON 是 **JavaScript Object Notation** 的缩写。你作为前端开发者，对它应该非常熟悉——它就是 JavaScript 的对象字面量格式。

```json
{
  "name": "张三",
  "age": 28,
  "skills": ["HTML", "CSS", "JavaScript"],
  "address": {
    "city": "北京",
    "district": "朝阳区"
  }
}
```

**JSON 和 Python 字典的对应关系：**

```
  ┌──────────────┬──────────────┐
  │     JSON     │    Python    │
  ├──────────────┼──────────────┤
  │   object {}  │    dict {}   │
  │   array  []  │    list []   │
  │   string ""  │    str  ''   │
  │   number     │  int / float │
  │   true/false │   True/False │
  │    null      │     None     │
  └──────────────┴──────────────┘
```

**适用场景：**
- 数据有嵌套结构（比如评论里有子评论）
- 需要和前端/API 交互
- 数据结构不规则，不适合表格化

### 3.2 用 json.dump 写入 JSON 文件

```python
import json

data = [
    {
        '姓名': '张三',
        '城市': '北京',
        '技能': ['HTML', 'CSS', 'JavaScript']
    },
    {
        '姓名': '李四',
        '城市': '上海',
        '技能': ['Python', 'Scrapy']
    },
]

# 写入 JSON 文件
with open('output.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

print('JSON 写入完成！')
```

**关键参数：** `ensure_ascii=False` 让中文正常显示（否则变成 `\uXXXX` 转义），`indent=2` 让输出有缩进便于阅读。

**错误示范：**

```python
# ❌ 不加 ensure_ascii=False
json.dump(data, f)
# 输出: [{"\u59d3\u540d": "\u5f20\u4e0c", ...}]   ← 中文全变成转义字符

# ✅ 正确写法
json.dump(data, f, ensure_ascii=False, indent=2)
# 输出: [{"姓名": "张三", ...}]   ← 中文正常显示
```

### 3.3 用 json.dumps 转为字符串

`json.dumps()` 不写入文件，而是返回一个字符串。什么时候用它？比如你想把 JSON 数据存到数据库的某个字段里，或者打印出来调试。

```python
import json

data = {'姓名': '张三', '城市': '北京'}

# 转为 JSON 字符串
json_str = json.dumps(data, ensure_ascii=False)
print(json_str)
print(type(json_str))   # <class 'str'>

# 转为格式化的 JSON 字符串
json_str_pretty = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str_pretty)
```

**dump vs dumps 对比：**

```
  ┌──────────────┬────────────────────────────────────────────┐
  │  json.dump   │  写入文件（file）  → data, file_obj       │
  │              │  记忆：dump = dump to file                 │
  ├──────────────┼────────────────────────────────────────────┤
  │  json.dumps  │  转为字符串（string）→ return str          │
  │              │  记忆：dumps = dump to string              │
  └──────────────┴────────────────────────────────────────────┘
```

### 3.4 用 json.load 读取 JSON 文件

```python
import json

with open('output.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

print(data)
print(type(data))       # <class 'list'>
print(data[0]['姓名'])   # 张三
```

### 3.5 用 json.loads 从字符串解析

```python
import json

json_str = '{"姓名": "张三", "城市": "北京"}'
data = json.loads(json_str)

print(data)
print(type(data))       # <class 'dict'>
print(data['姓名'])      # 张三
```

**load vs loads 对比：**

```
  ┌──────────────┬────────────────────────────────────────────┐
  │  json.load   │  从文件读取 → file_obj                    │
  │              │  记忆：load = load from file               │
  ├──────────────┼────────────────────────────────────────────┤
  │  json.loads  │  从字符串解析 → str                        │
  │              │  记忆：loads = load from string            │
  └──────────────┴────────────────────────────────────────────┘
```

> **记忆口诀：** 带 `s` 的是处理 **s**tring（字符串），不带 `s` 的是处理 file（文件）。

## 四、CSV 还是 JSON？如何选择

### 4.1 决策流程

```
                      你的数据是什么结构？
                            │
                ┌───────────┴───────────┐
                ▼                       ▼
          扁平的表格              有嵌套/层级
          （像 Excel）           （对象里套对象）
                │                       │
                ▼                       ▼
           用 CSV                  用 JSON
                │                       │
                ▼                       ▼
     需要用 Excel 打开？        需要和前端/API 对接？
        │           │               │           │
       是          否              是           否
        │           │               │           │
   utf-8-sig     utf-8          标准 JSON     视情况
```

### 4.2 实际对比

假设我们有一组爬虫数据：

```python
data = [
    {'title': 'Python入门', 'author': '张三', 'tags': ['python', '教程']},
    {'title': 'JS高级', 'author': '李四', 'tags': ['javascript', '进阶']},
]
```

**CSV 导出效果：**
```csv
title,author,tags
Python入门,张三,"['python', '教程']"
JS高级,李四,"['javascript', '进阶']"
```

注意：`tags` 是一个列表，CSV 没法直接表示嵌套结构，只能把它变成字符串。读回来的时候，`"['python', '教程']"` 是一个字符串，不是列表。

**JSON 导出效果：**
```json
[
  {
    "title": "Python入门",
    "author": "张三",
    "tags": ["python", "教程"]
  },
  {
    "title": "JS高级",
    "author": "李四",
    "tags": ["javascript", "进阶"]
  }
]
```

JSON 完美保留了数据的原始结构，`tags` 读回来还是列表。

**总结建议：**

| 场景 | 推荐格式 |
|------|---------|
| 数据要发给运营同事用 Excel 处理 | CSV |
| 数据要传给前端页面展示 | JSON |
| 数据有嵌套结构 | JSON |
| 只需要简单的 key-value 表格 | CSV |
| 数据要存入数据库后再导出 | 两者皆可 |
| 调试阶段想快速查看数据 | JSON（可读性好） |

## 五、编码处理

### 5.1 编码问题的常见症状

你在实际爬虫中一定会遇到这些情况：

```python
# ❌ 打开中文 CSV 文件时
UnicodeDecodeError: 'gbk' codec can't decode byte 0xaf in position 12

# ❌ 写入后用 Excel 打开，中文变乱码
姓名,城市
ÕÅ Èý,±±¾©    ← 这就是编码不一致导致的
```

### 5.2 正确的编码处理方式

```python
import csv
import json

# ✅ 写 CSV 给 Excel 用 → utf-8-sig（带 BOM 头，Excel 不乱码）
with open('data.csv', 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.writer(f)
    writer.writerow(['姓名', '城市'])

# ✅ 写 JSON → utf-8 就够了
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump({'姓名': '张三'}, f, ensure_ascii=False)

# ✅ 读取别人给的 GBK 文件 → 指定 gbk 编码
with open('old_data.csv', 'r', encoding='gbk') as f:
    for row in csv.reader(f):
        print(row)
```

> **一句话总结：** 写文件用 `utf-8-sig`（CSV 给 Excel）或 `utf-8`（JSON），读文件根据来源选择对应编码。

## 六、追加写入 vs 覆盖写入

### 6.1 文件打开模式

```
  ┌──────────┬──────────────────────────────────────────────┐
  │   模式   │   行为                                       │
  ├──────────┼──────────────────────────────────────────────┤
  │   'w'    │   覆盖写入。文件已存在则清空，不存在则创建   │
  │   'a'    │   追加写入。文件已存在则在末尾追加           │
  │   'r'    │   只读模式（默认）                           │
  │   'x'    │   排他创建。文件已存在则报错                 │
  └──────────┴──────────────────────────────────────────────┘
```

### 6.2 CSV 追加写入

```python
import csv

# 第一次写入（包含表头）
with open('log.csv', 'w', newline='', encoding='utf-8-sig') as f:
    writer = csv.writer(f)
    writer.writerow(['时间', '状态', 'URL'])
    writer.writerow(['10:00', '成功', 'https://example.com/page1'])

# 后续追加（不写表头）
with open('log.csv', 'a', newline='', encoding='utf-8-sig') as f:
    writer = csv.writer(f)
    writer.writerow(['10:01', '成功', 'https://example.com/page2'])
    writer.writerow(['10:02', '失败', 'https://example.com/page3'])
```

> **注意：** 追加模式下不要再写表头，否则表头会出现多次。

### 6.3 JSON 追加的困境

JSON 格式天生不支持"追加"。因为 JSON 文件是一个完整的数组或对象，你不能在末尾直接加一条数据。

**正确的做法：读取 → 修改 → 重新写入。**

```python
import json

# 假设已有一个 JSON 文件
# 读取现有数据
with open('data.json', 'r', encoding='utf-8') as f:
    data = json.load(f)       # 假设是一个列表

# 追加新数据
data.append({'姓名': '赵六', '城市': '深圳'})

# 重新写入
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

**数据量很大怎么办？** 可以用 JSON Lines 格式（`.jsonl`），每条数据写一行独立的 JSON 对象，支持追加：

```python
import json

with open('data.jsonl', 'a', encoding='utf-8') as f:
    record = {'姓名': '张三', '城市': '北京'}
    f.write(json.dumps(record, ensure_ascii=False) + '\n')
```

## 七、文件命名策略

### 7.1 为什么文件命名很重要？

如果你的爬虫每天运行一次，一周后你的文件夹可能是这样的：

```
  ❌ 糟糕的命名：
  data.csv
  data(1).csv
  data(2).csv
  data(2)(1).csv    ← 到底哪个是最新数据？
```

### 7.2 时间戳命名

```python
from datetime import datetime

# 格式：年月日_时分秒
timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
filename = f'quotes_{timestamp}.csv'
print(filename)   # quotes_20260601_143022.csv

# 格式：年月日（适合每天跑一次的场景）
date_str = datetime.now().strftime('%Y%m%d')
filename = f'quotes_{date_str}.csv'
print(filename)   # quotes_20260601.csv
```

### 7.3 分类命名与自动创建目录

```python
import os

# 按网站或数据类型分类
filename = f'{site_name}_{timestamp}.csv'        # 例：douban_movies_20260601.csv
filename = f'{data_type}_{timestamp}.json'       # 例：quotes_20260601.json

# 自动创建输出目录（目录已存在也不会报错）
output_dir = 'output'
os.makedirs(output_dir, exist_ok=True)
filepath = os.path.join(output_dir, f'quotes_{datetime.now():%Y%m%d}.csv')
```

## 八、综合实战：导出函数封装

把上面学到的知识整合成两个通用的导出函数：

```python
import csv
import json
import os
from datetime import datetime


def export_to_csv(data, filename=None, output_dir='output'):
    """将数据导出为 CSV 文件，不传 filename 则自动生成带时间戳的文件名"""
    if not data:
        print('⚠️ 数据为空，跳过导出')
        return None
    if filename is None:
        filename = f'data_{datetime.now():%Y%m%d_%H%M%S}.csv'
    os.makedirs(output_dir, exist_ok=True)
    filepath = os.path.join(output_dir, filename)
    with open(filepath, 'w', newline='', encoding='utf-8-sig') as f:
        writer = csv.DictWriter(f, fieldnames=data[0].keys())
        writer.writeheader()
        writer.writerows(data)
    print(f'✅ CSV 已保存: {filepath}（共 {len(data)} 条）')
    return filepath


def export_to_json(data, filename=None, output_dir='output'):
    """将数据导出为 JSON 文件，不传 filename 则自动生成带时间戳的文件名"""
    if not data:
        print('⚠️ 数据为空，跳过导出')
        return None
    if filename is None:
        filename = f'data_{datetime.now():%Y%m%d_%H%M%S}.json'
    os.makedirs(output_dir, exist_ok=True)
    filepath = os.path.join(output_dir, filename)
    with open(filepath, 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    print(f'✅ JSON 已保存: {filepath}（共 {len(data)} 条）')
    return filepath


# ---------- 测试 ----------
if __name__ == '__main__':
    sample_data = [
        {'姓名': '张三', '城市': '北京', '年龄': 28},
        {'姓名': '李四', '城市': '上海', '年龄': 32},
        {'姓名': '王五', '城市': '广州', '年龄': 25},
    ]
    export_to_csv(sample_data)     # 输出: output/data_20260601_143022.csv
    export_to_json(sample_data)    # 输出: output/data_20260601_143022.json
```

## 九、动手练习

### 练习一：CSV 读写练习

创建一个包含以下数据的 CSV 文件，然后读取它并打印每行：

| 书名 | 作者 | 价格 |
|------|------|------|
| Python编程 | 张三 | 59.9 |
| JavaScript高级 | 李四 | 79.0 |

## 小结

本课的核心知识点：

1. **CSV 格式**适合扁平表格数据，用 `csv.writer`/`csv.DictWriter` 写入，`csv.reader`/`csv.DictReader` 读取
2. **JSON 格式**适合嵌套结构数据，用 `json.dump`/`json.dumps` 写入，`json.load`/`json.loads` 读取
3. **编码处理**：CSV 给 Excel 用选 `utf-8-sig`，JSON 用 `utf-8`，读取时根据来源选编码
4. **追加 vs 覆盖**：CSV 用 `'a'` 模式追加，JSON 需要读取→修改→重写
5. **文件命名**：用时间戳避免文件名冲突，用分类名提升可读性
6. **函数封装**：把导出逻辑封装成可复用的函数，方便在爬虫项目中调用
