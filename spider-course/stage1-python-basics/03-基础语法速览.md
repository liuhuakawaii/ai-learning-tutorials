## 一、变量：不需要 `let`、`const`、`var`

### 1.1 直接赋值，无需声明

在 JavaScript 里，你写变量必须带上关键字：

```javascript
// JavaScript
let name = "张三";
const age = 25;
var city = "北京";
```

Python 简单粗暴——直接写名字、直接赋值：

```python
# Python —— 直接赋值，不需要任何关键字
name = "张三"
age = 25
city = "北京"
```

生活类比：JS 的 `let`/`const` 就像正式的入职登记表，必须填"合同类型"才能上岗。Python 像是一个自由市场，你喊一声"这是我的摊位"，它就是你的了。

### 1.2 动态类型：同一变量可以换类型

```python
# Python 动态类型 —— 变量可以随时换类型
x = 10        # x 是整数
print(x)      # 输出: 10

x = "你好"    # x 现在变成字符串了！
print(x)      # 输出: 你好

x = [1, 2, 3] # x 又变成列表了！
print(x)      # 输出: [1, 2, 3]
```

> **前端视角**：这跟 JS 一样，JS 也是动态类型语言。`let x = 10; x = "hello"` 完全合法。所以你已经具备这个思维了！

### 1.3 命名规则

```python
# ✅ 合法的变量名
user_name = "张三"
count2 = 10
_private = "私有变量"
MAX_RETRY = 3   # 约定：全大写表示常量

# ❌ 非法的变量名（会报错）
# 2count = 10      # 不能以数字开头
# my-name = "张三"  # 不能包含连字符
# class = "一班"    # 不能使用关键字
```

> **跟 JS 一样**：Python 的变量命名规则和 JS 基本一致（字母/下划线开头，不能用关键字）。唯一的文化差异是，Python 用 `snake_case`（下划线命名），而 JS 用 `camelCase`（驼峰命名）。

## 二、数据类型：Python 的"四大金刚"

### 2.1 整数和浮点数（int / float）

```python
# 整数 int —— 没有小数点
age = 25
count = -10
big_number = 1_000_000   # 下划线分隔，提高可读性（Python 3.6+）

# 浮点数 float —— 有小数点
price = 9.99
temperature = -3.5
pi = 3.14159
```

> **跟 JS 的区别**：JS 只有一个 `Number` 类型，不分整数和浮点。Python 把它们分开了。

```python
# 查看类型
print(type(25))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type(True))     # <class 'bool'>
```

### 2.2 字符串（str）

Python 的字符串非常灵活，单引号和双引号完全等价：

```python
# 单引号和双引号都可以，完全一样
name1 = '张三'
name2 = "张三"
print(name1 == name2)  # True
```

**f-string（格式化字符串）—— Python 的模板字符串**

```javascript
// JavaScript 的模板字符串
const name = "张三";
const age = 25;
console.log(`我叫${name}，今年${age}岁`);
```

```python
# Python 的 f-string —— 几乎一模一样！
name = "张三"
age = 25
print(f"我叫{name}，今年{age}岁")
# 输出: 我叫张三，今年25岁
```

> **前端视角**：JS 用反引号 `` ` `` + `${}`，Python 用普通引号 + `f""` + `{}`。功能一样，写法稍有不同。

```python
# f-string 里甚至可以写表达式
price = 9.99
quantity = 3
print(f"总价: {price * quantity:.2f} 元")
# 输出: 总价: 29.97 元
```

### 2.3 布尔值（bool）

```python
# Python 用大写开头的 True / False（JS 用小写）
is_active = True
is_deleted = False
```

> **注意这个坑！** Python 的 `True`/`False` 是大写开头，JS 的 `true`/`false` 是小写。写错会报错。

```python
# ❌ 错误写法（从 JS 转过来很容易犯）
# is_active = true    # NameError: name 'true' is not defined

# ✅ 正确写法
is_active = True
```

### 2.4 None：Python 的"空值"

```python
# None 表示"没有值"（类似 JS 的 null）
result = None
print(result)       # None
print(type(result)) # <class 'NoneType'>
```

> **跟 JS 的区别**：JS 有 `null` 和 `undefined` 两个空值概念。Python 只有 `None` 一个，简单多了。

```python
# 判断是否为 None 的正确方式
result = None

# ✅ 正确：用 is 判断
if result is None:
    print("没有结果")

# ❌ 不推荐：用 == 判断（虽然能用，但不 Pythonic）
if result == None:
    print("没有结果")
```

## 三、类型检查与类型转换

### 3.1 查看类型：type() 和 isinstance()

```python
x = 42
print(type(x))            # <class 'int'>
print(isinstance(x, int)) # True
print(isinstance(x, str)) # False
```

```
┌──────────────┐
│  type(x)     │ → 返回类型本身，适合"打印看看"
├──────────────┤
│ isinstance() │ → 返回 True/False，适合"条件判断"
└──────────────┘
```

```python
# 实际使用场景
user_input = "123"

if isinstance(user_input, str):
    print("这是字符串，需要转换才能计算")
```

### 3.2 类型转换：int()、str()、float()

```python
# 字符串 → 整数
age_str = "25"
age_int = int(age_str)     # 25（整数）
print(age_int + 1)         # 26

# 整数 → 字符串
count = 100
count_str = str(count)     # "100"（字符串）
print("数量: " + count_str) # "数量: 100"

# 字符串 → 浮点数
price_str = "9.99"
price = float(price_str)   # 9.99（浮点数）
```

```
类型转换的"路线图"：

  str "25"
   │
   ├──→ int( )  ──→  25          (整数)
   │                  │
   │                  ├──→ str( )  ──→  "25"     (字符串)
   │                  │
   │                  └──→ float( )──→  25.0     (浮点数)
   │
   └──→ float( )──→  25.0         (浮点数)
```

> **爬虫中的典型场景**：网页上抓到的价格是字符串 `"9.99"`，你需要 `float("9.99")` 才能做数学运算。

```python
# ❌ 常见错误
price = "9.99"
total = price * 3     # 结果是 "9.999.999.9.99"（字符串重复了3次！）

# ✅ 正确做法
price = float("9.99")
total = price * 3     # 结果是 29.97（正确的数学运算）
```

## 四、运算符

### 4.1 算术运算符

```python
a, b = 10, 3

print(a + b)    # 13    加法
print(a - b)    # 7     减法
print(a * b)    # 30    乘法
print(a / b)    # 3.333 除法（结果是浮点数！）
print(a // b)   # 3     整除（向下取整）
print(a % b)    # 1     取余
print(a ** b)   # 1000  幂运算（10的3次方）
```

> **注意**：Python 的 `/` 结果永远是浮点数（`10 / 2` 得到 `5.0`，不是 `5`）。想要整数结果用 `//`。

### 4.2 比较运算符（跟 JS 完全一样）

```python
x = 10
print(x > 5)     # True
print(x < 5)     # False
print(x >= 10)   # True
print(x <= 9)    # False
print(x == 10)   # True（相等比较）
print(x != 5)    # True（不等比较）
```

### 4.3 逻辑运算符（关键字不同！）

```
┌──────────┬──────────────┬──────────────────────┐
│   功能   │     JS       │       Python         │
├──────────┼──────────────┼──────────────────────┤
│   与     │  &&          │  and                 │
│   或     │  ||          │  or                  │
│   非     │  !           │  not                 │
└──────────┴──────────────┴──────────────────────┘
```

```python
age = 25
has_id = True

# Python 用英文单词，不是符号
if age >= 18 and has_id:
    print("允许进入")

if age < 18 or not has_id:
    print("禁止进入")
```

```python
# ❌ 错误写法（JS 后遗症）
# if age >= 18 && has_id:    # SyntaxError!

# ✅ 正确写法
if age >= 18 and has_id:
    print("允许进入")
```

## 五、条件判断：if / elif / else

### 5.1 基本结构

```javascript
// JavaScript
if (score >= 90) {
    console.log("优秀");
} else if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}
```

```python
# Python —— elif 是 else if 的缩写
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:   # 不是 "else if"，是 "elif"
    print("及格")
else:
    print("不及格")
```

> **三个区别**：1) `else if` 变成 `elif`；2) 不用小括号包裹条件；3) 用冒号 `:` 代替花括号 `{}`。

### 5.2 缩进就是花括号

这是 Python 最大的语法特色——**缩进决定了代码的层级关系**。

```
┌─────────────────────────────────────────────────┐
│  JavaScript 用 { } 划定范围                       │
│                                                   │
│  if (条件) {         ← 花括号开始                  │
│      代码块1                                      │
│      代码块2                                      │
│  }                ← 花括号结束                    │
│                                                   │
├─────────────────────────────────────────────────┤
│  Python 用缩进 (4个空格) 划定范围                  │
│                                                   │
│  if 条件:             ← 冒号开始                  │
│      代码块1         ← 缩进4个空格                 │
│      代码块2         ← 缩进4个空格                 │
│  下一行代码          ← 不缩进 = 跳出 if 块         │
└─────────────────────────────────────────────────┘
```

```python
# 缩进的威力
score = 85

if score >= 60:
    print("及格了")
    print("恭喜你")    # 这行也在 if 里面（因为它也缩进了）
print("程序结束")       # 这行不在 if 里面（因为它没缩进）
```

```python
# ❌ 缩进错误会直接报错
# if True:
# print("hello")   # IndentationError: expected an indented block

# ✅ 正确缩进
if True:
    print("hello")   # 缩进4个空格
```

> **生活类比**：JS 的花括号像是明确的围墙——"墙里面是我的地盘"。Python 的缩进像是书架的层次——"这个抽屉嵌套在哪个柜子里，看缩进就知道了"。

## 六、循环

### 6.1 for 循环：遍历集合

```javascript
// JavaScript 的 for...of
const fruits = ["苹果", "香蕉", "橙子"];
for (const fruit of fruits) {
    console.log(fruit);
}
```

```python
# Python 的 for...in —— 几乎一模一样
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(fruit)
```

```
for 循环的执行流程：

  fruits = ["苹果", "香蕉", "橙子"]
                │
                ▼
  ┌─────────────────────────────┐
  │  for fruit in fruits:       │
  │      ┌─────────────┐        │
  │      │ 第1轮:       │        │
  │      │ fruit="苹果"  │──→ print → "苹果"
  │      │ 第2轮:       │        │
  │      │ fruit="香蕉"  │──→ print → "香蕉"
  │      │ 第3轮:       │        │
  │      │ fruit="橙子"  │──→ print → "橙子"
  │      │ 结束,退出循环 │        │
  │      └─────────────┘        │
  └─────────────────────────────┘
```

### 6.2 range()：生成数字序列

```python
# range(5) 生成 0, 1, 2, 3, 4（注意：不含5！）
for i in range(5):
    print(i)    # 0 1 2 3 4

# range(起始, 结束)
for i in range(1, 6):
    print(i)    # 1 2 3 4 5

# range(起始, 结束, 步长)
for i in range(0, 10, 2):
    print(i)    # 0 2 4 6 8
```

```
range() 的三种用法：

  range(5)            → 0, 1, 2, 3, 4
  range(1, 6)         → 1, 2, 3, 4, 5
  range(0, 10, 2)     → 0, 2, 4, 6, 8

  简记：range(起, 终, 步) → 包含"起"，不含"终"
```

> **前端视角**：JS 里你想循环5次写 `for(let i=0; i<5; i++)`，Python 里直接 `for i in range(5)`，简洁很多。

### 6.3 while 循环

```python
# while 循环 —— 跟 JS 一样，条件为 True 就继续
count = 0
while count < 5:
    print(f"当前: {count}")
    count += 1    # Python 没有 count++，只能用 += 1
```

```python
# ❌ Python 没有 ++ 和 -- 运算符
# count++   # SyntaxError!

# ✅ 用 += 1 代替
count += 1
```

### 6.4 break 和 continue

```python
# break —— 跳出整个循环
for i in range(10):
    if i == 5:
        break          # 到5就停
    print(i)           # 输出: 0 1 2 3 4

# continue —— 跳过本轮，继续下一轮
for i in range(6):
    if i == 3:
        continue       # 跳过3
    print(i)           # 输出: 0 1 2 4 5
```

> **跟 JS 完全一样**：`break` 和 `continue` 的行为和 JS 中一模一样，没有任何区别。

## 七、列表推导式（预告）

这是 Python 的一个"杀手锏"，JS 里没有直接等价物：

```javascript
// JavaScript：用 map + filter 处理数组
const nums = [1, 2, 3, 4, 5];
const doubled = nums.filter(n => n > 2).map(n => n * 2);
// [6, 8, 10]
```

```python
# Python：用列表推导式，一行搞定
nums = [1, 2, 3, 4, 5]
doubled = [n * 2 for n in nums if n > 2]
# [6, 8, 10]
```

```
列表推导式的结构：

  [表达式  for 变量 in 可迭代对象  if 条件]
   ─────   ───────────────────  ───────
    │              │                │
    │              │                └─ 可选的过滤条件
    │              └─ 遍历数据源
    └─ 对每个元素做什么

  例子：
  [x * 2 for x in range(5)]
  → [0, 2, 4, 6, 8]

  [x for x in range(10) if x % 2 == 0]
  → [0, 2, 4, 6, 8]
```

> **别紧张**：这只是个预告，第4课会详细讲解。现在只需要知道"Python 有这个好东西"就行。

## 常见误区

- **"Python 变量需要先声明"**：Python 不需要 `let`、`const`、`var`，直接赋值即可。变量名不是"容器"，而是"标签"——它贴在对象上，而不是装着对象。理解这个概念，就不会对 Python 的动态类型感到困惑。
- **"把 JS 的逻辑运算符直接搬过来"**：`&&`、`||`、`!` 在 Python 里不存在，要用 `and`、`or`、`not`。这是从 JS 转 Python 最容易犯的语法错误，建议专门花时间把这些差异记牢。
- **"缩进只是代码风格问题"**：在 JavaScript 里，缩进是可选的（花括号才是语法）。在 Python 里，缩进就是语法本身。混用空格和 Tab、缩进层级不对，都会导致 `IndentationError`。养成用 4 个空格缩进的习惯，配置编辑器将 Tab 自动转为空格。
- **"Python 有 `++` 运算符"**：Python 没有 `count++` 或 `++count`，只能用 `count += 1`。这不是"另一种写法"，而是语言设计选择——Python 认为 `++` 容易引起歧义，所以干脆去掉了。

## 工程建议

- **遵循 Python 命名规范**：变量和函数用 `snake_case`（下划线命名），常量用 `UPPER_CASE`（全大写），类名用 `PascalCase`。不要把 JavaScript 的 `camelCase` 习惯带到 Python 里，入乡随俗才能写出其他 Python 开发者看得懂的代码。
- **用 `is` 判断 None，不用 `==`**：`if result is None` 是 Python 的惯用写法，比 `if result == None` 更准确、更快。`is` 比较的是对象身份（内存地址），`==` 比较的是值，对于 None 这种单例对象，用 `is` 更合适。
- **优先使用 f-string 格式化字符串**：Python 3.6+ 的 f-string 比 `format()` 和 `%` 拼接更简洁、可读性更好。`f"我叫{name}，今年{age}岁"` 一眼就能看出输出内容，而 `"我叫{}，今年{}岁".format(name, age)` 需要上下对照。
- **注意类型转换的陷阱**：爬虫中经常遇到字符串类型的数字（网页上抓到的价格是 `"9.99"` 而不是 `9.99`），需要显式 `float()` 转换后才能做数学运算。否则 `"9.99" * 3` 的结果是 `"9.999.999.9.99"`（字符串重复），而不是 `29.97`。

```
│  1. 变量：直接赋值，无需 let/const                         │
│                                                          │
│  2. 四种基本类型：                                         │
│     int（整数）  float（浮点数）                           │
│     str（字符串） bool（布尔）                             │
│     None（空值）                                          │
│                                                          │
│  3. f-string：Python 的模板字符串，等价于 JS 模板字面量     │
│                                                          │
│  4. 逻辑运算符：and / or / not（不是 && / || / !）        │
│                                                          │
│  5. 条件判断：if / elif / else（elif 替代了 else if）      │

│  6. 循环：for...in 和 while（跟 JS 逻辑一样）              │

│                                                          │

```

**JS → Python 快速对照表**：

```
┌─────────────────┬──────────────────┬──────────────────┐
│      功能       │       JS         │     Python       │
├─────────────────┼──────────────────┼──────────────────┤
│  变量声明       │  let x = 10      │  x = 10          │
│  字符串模板     │  `hello ${x}`    │  f"hello {x}"    │
│  布尔值         │  true / false    │  True / False    │

│  逻辑与         │  &&              │  and             │

│  类型检查       │  typeof x        │  type(x)         │
└─────────────────┴──────────────────┴──────────────────┘
```
