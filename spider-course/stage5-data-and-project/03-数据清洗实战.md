## 一、为什么需要数据清洗？——洗菜的学问

### 1.1 从厨房说起

你去菜市场买了一袋蔬菜回来，能直接下锅炒吗？当然不行。你需要：

```
买回来的菜（原始数据）          处理后（干净数据）
┌─────────────────┐           ┌─────────────────┐
│  泥土   虫子     │           │  干净的菜叶      │
│  枯叶   杂草     │  ──清洗→  │  去掉了坏的部分   │
│  好的菜叶       │           │  大小切好统一     │
│  大小不一       │           │  可以下锅了！     │
└─────────────────┘           └─────────────────┘
```

爬虫抓回来的数据，就像菜市场买回来的菜——**看起来有用，但不能直接用**。

### 1.2 前端开发者更容易理解的比喻

作为前端开发者，你一定遇到过这样的接口返回：

```json
{
  "name": "  张三  ",
  "age": "25",
  "city": "北京市",
  "phone": "138-0000-1234",
  "created_at": "2024/3/5 9:05:03"
}
```

问题一目了然：`name` 多了空格，`age` 是字符串不是数字，`phone` 格式不统一，日期格式五花八门。这就是"脏数据"。

### 1.3 脏数据的常见类型

```
脏数据类型一览
┌────────────────┬──────────────────────────┬─────────────────────┐
│   类型         │   举例                    │   影响              │
├────────────────┼──────────────────────────┼─────────────────────┤
│ 多余空白       │ "  张三 " " 北京 "       │ 匹配失败、存储冗余  │
│ 格式不一致     │ "北京市" vs "北京"       │ 统计结果不准确      │
│ 类型混乱       │ "25" (字符串) vs 25      │ 计算报错            │
│ 缺失值         │ None, "", "N/A", "-"     │ 分析结果有偏差      │
│ 重复数据       │ 同一条记录出现多次        │ 统计结果膨胀        │
│ 日期混乱       │ "2024/3/5" vs "03-05"    │ 无法排序和比较      │
│ 编码问题       │ 鍖椾含 instead of 北京    │ 数据不可读          │
└────────────────┴──────────────────────────┴─────────────────────┘
```

## 二、字符串清洗：最基础也最常用

### 2.1 去除多余空白

这是最最常见的情况，爬虫抓下来的文本经常带有多余的空格、换行、制表符。

```python
# 原始数据
raw_name = "  张三  "
raw_price = "\n  99.00 元 \t"

# ✅ 正确：使用 strip() 去除首尾空白
name = raw_name.strip()       # "张三"
price = raw_price.strip()     # "99.00 元"

# ❌ 错误：只用 replace 会把中间的空格也去掉
name = raw_name.replace(" ", "")  # "张三" 看似正确，但 "张 三" 会变成 "张三"

# 如果只要去除首尾，保留中间：
raw_address = "  北京市 海淀区  "
address = raw_address.strip()     # "北京市 海淀区"  ✅ 保留了中间的空格
```

三个兄弟方法的对比：

```python
text = "  Hello World  "

text.strip()     # "Hello World"  —— 去掉两边
text.lstrip()    # "Hello World  " —— 只去左边
text.rstrip()    # "  Hello World" —— 只去右边
```

### 2.2 统一文本格式

同一个意思可能有多种写法，需要统一成一种格式。

```python
# 地址标准化
city = "北京市"
city = city.replace("市", "")     # "北京" ✅ 去掉行政区划后缀

# 大小写统一（英文场景）
status = "Published"
status = status.lower()            # "published" ✅ 统一小写

# 全角转半角
phone = "１３８００００１２３４"    # 全角数字
phone = phone.translate(str.maketrans(
    "０１２３４５６７８９",
    "0123456789"
))                                 # "13800001234" ✅

# 统一分隔符
tags = "Python, JavaScript; Go|Rust"
tags = tags.replace(";", ",").replace("|", ",")
tag_list = [t.strip() for t in tags.split(",")]
# ["Python", "JavaScript", "Go", "Rust"] ✅
```

### 2.3 正则表达式清洗

当简单字符串方法搞不定时，正则就是你的瑞士军刀。

```python
import re

# 提取纯数字
raw_price = "原价 ¥199.00 元"
price_str = re.search(r'[\d.]+', raw_price).group()  # "199.00" ✅
price = float(price_str)                              # 199.0

# 清洗手机号：只保留数字
raw_phone = "138-0000-1234 (工作)"
phone = re.sub(r'[^\d]', '', raw_phone)  # "138000001234" ✅

# 去除 HTML 标签残留
html_text = "<p>价格：<span>99元</span></p>"
clean_text = re.sub(r'<[^>]+>', '', html_text)  # "价格：99元" ✅

# 提取邮箱
text = "联系我：zhangsan@example.com 或 test@test.cn"
emails = re.findall(r'[\w.+-]+@[\w-]+\.[\w.-]+', text)
# ["zhangsan@example.com", "test@test.cn"] ✅
```

常用正则模式速查表：

```
┌──────────────┬─────────────────────────────┬──────────────────────┐
│   场景       │   正则表达式                 │   匹配示例           │
├──────────────┼─────────────────────────────┼──────────────────────┤
│ 手机号       │ 1[3-9]\d{9}                │ 13800001234          │
│ 邮箱         │ [\w.+-]+@[\w-]+\.[\w.-]+   │ test@example.com     │
│ 身份证       │ \d{17}[\dXx]               │ 110101199001011234   │
│ URL          │ https?://[^\s]+            │ https://example.com  │
│ 纯中文       │ [\u4e00-\u9fa5]+           │ 北京市               │
│ 数字(含小数) │ \d+\.?\d*                   │ 199.00               │
└──────────────┴─────────────────────────────┴──────────────────────┘
```

## 三、类型转换与验证

### 3.1 安全的类型转换

前端同学应该很熟悉 `parseInt("abc")` 返回 `NaN` 的情况。Python 里更直接——转换失败会直接报错。

```python
# ❌ 错误：直接转换，遇到脏数据就崩
price = float("99.00 元")    # ValueError! 💥

# ✅ 正确：先清洗再转换
raw = "99.00 元"
clean = re.search(r'[\d.]+', raw)
if clean:
    price = float(clean.group())  # 99.0 ✅
else:
    price = None                  # 转换失败，标记为缺失

# 通用的安全转换函数
def safe_float(value, default=None):
    """安全地将值转为浮点数，失败返回默认值"""
    try:
        # 去除非数字字符（保留小数点和负号）
        cleaned = re.sub(r'[^\d.\-]', '', str(value))
        return float(cleaned)
    except (ValueError, TypeError):
        return default

# 使用示例
print(safe_float("99.00 元"))   # 99.0
print(safe_float("暂无报价"))    # None
print(safe_float("3.5折"))       # 3.5
```

### 3.2 数据验证

转换之后还需要验证数据是否合理。

```python
def validate_product(product):
    """验证商品数据是否合理"""
    errors = []

    # 价格必须大于 0
    if product.get("price") is not None:
        if product["price"] <= 0:
            errors.append(f"价格异常：{product['price']}")

    # 库存不能是负数
    if product.get("stock") is not None:
        if product["stock"] < 0:
            errors.append(f"库存为负：{product['stock']}")

    # 名称不能为空
    if not product.get("name", "").strip():
        errors.append("商品名称为空")

    return errors

# 使用
item = {"name": "Python教程", "price": -10, "stock": 5}
errs = validate_product(item)  # ["价格异常：-10"]
```

## 四、处理缺失数据

### 4.1 缺失值的多种面目

缺失值不一定是 `None`，它可能以各种伪装出现：

```python
# 这些都算"缺失"
MISSING_VALUES = [None, "", "N/A", "n/a", "null", "NULL",
                  "-", "--", "---", "暂无", "无", "未填写"]

def is_missing(value):
    """判断一个值是否为缺失值"""
    if value is None:
        return True
    return str(value).strip() in MISSING_VALUES
```

### 4.2 三种处理策略

```
缺失值处理策略
┌──────────────┬────────────────────────────────────────────┐
│   策略       │   适用场景                                  │
├──────────────┼────────────────────────────────────────────┤
│ 填充默认值   │ 有合理的默认值，比如"未知"、0               │
│ 跳过该条记录 │ 缺失的是关键字段，比如商品名称              │
│ 标记为缺失   │ 需要保留该记录，但要让后续分析知道此处缺失  │
└──────────────┴────────────────────────────────────────────┘
```

```python
def handle_missing(records):
    """处理缺失数据"""
    cleaned = []

    for record in records:
        # 策略1：填充默认值
        if is_missing(record.get("category")):
            record["category"] = "未分类"

        if is_missing(record.get("stock")):
            record["stock"] = 0

        # 策略2：关键字段缺失则跳过
        if is_missing(record.get("name")):
            print(f"跳过无名称记录: {record}")
            continue

        # 策略3：标记为缺失（用 None 标记）
        if is_missing(record.get("description")):
            record["description"] = None  # 明确标记，而非空字符串

        cleaned.append(record)

    return cleaned
```

## 五、去除重复数据

### 5.1 什么是重复？

```
重复数据的两种情况
┌─────────────────────────────────────────────────────┐
│  完全重复：整条记录一模一样                           │
│  ┌─────────┬──────┬────────┐                        │
│  │ 张三    │ 25   │ 北京   │  ← 和下面完全一样       │
│  │ 张三    │ 25   │ 北京   │  ← 重复！删掉           │
│  └─────────┴──────┴────────┘                        │
│                                                     │
│  部分重复：某个关键字段一样                           │
│  ┌─────────┬──────┬────────┬──────────┐             │
│  │ 张三    │ 25   │ 北京   │ 138...   │             │
│  │ 张三    │ 26   │ 上海   │ 138...   │ ← 同手机号  │
│  └─────────┴──────┴────────┴──────────┘             │
└─────────────────────────────────────────────────────┘
```

### 5.2 纯 Python 去重

```python
# 基础去重：用 set 记录已见过的值
def deduplicate_by_key(records, key):
    """按指定字段去重，保留第一条"""
    seen = set()
    unique = []
    for record in records:
        value = record.get(key)
        if value not in seen:
            seen.add(value)
            unique.append(record)
    return unique

# 示例
products = [
    {"id": 1, "name": "Python书", "price": 59},
    {"id": 2, "name": "JS指南",   "price": 49},
    {"id": 1, "name": "Python书", "price": 59},  # 重复
]

result = deduplicate_by_key(products, "id")
# 只保留 id=1 的第一条 ✅
```

### 5.3 模糊去重

有时候数据不是完全一样，但其实是同一个东西。

```python
def deduplicate_fuzzy(records, key, normalize_func):
    """模糊去重：先标准化再比较"""
    seen = set()
    unique = []
    for record in records:
        raw_value = record.get(key, "")
        normalized = normalize_func(raw_value)  # 标准化
        if normalized not in seen:
            seen.add(normalized)
            unique.append(record)
    return unique

# 对名称去重，忽略空格和大小写
names = [
    {"name": "  Python 入门 ", "price": 59},
    {"name": "python入门",      "price": 59},
    {"name": "JavaScript指南",   "price": 49},
]

result = deduplicate_fuzzy(
    names, "name",
    normalize_func=lambda x: re.sub(r'\s+', '', x.strip().lower())
)
# 两个 "Python入门" 只保留一个 ✅
```

## 六、日期解析与标准化

### 6.1 日期格式的混乱

```
同一天的 N 种写法
┌─────────────────────┬────────────┐
│   原始格式           │   实际日期  │
├─────────────────────┼────────────┤
│ 2024-03-05          │ 2024年3月5日│
│ 2024/3/5            │ 同上        │
│ 2024年03月05日       │ 同上        │
│ 03-05-2024          │ 同上        │
│ Mar 5, 2024         │ 同上        │
│ 2天前               │ 取决于今天  │
│ 昨天 09:30          │ 取决于今天  │
│ timestamp:1709616000│ 同上        │
└─────────────────────┴────────────┘
```

### 6.2 使用 dateparser 解析

```python
# 先安装：pip install dateparser
import dateparser

# 它几乎能理解所有人类可读的日期格式
print(dateparser.parse("2024年3月5日"))       # 2024-03-05 00:00:00
print(dateparser.parse("2天前"))              # 自动计算 ✅
print(dateparser.parse("昨天 09:30"))         # 正确解析 ✅
print(dateparser.parse("Mar 5, 2024"))        # 2024-03-05 00:00:00

# 统一输出格式
def normalize_date(raw_date_str):
    """将各种日期格式统一为 YYYY-MM-DD"""
    parsed = dateparser.parse(raw_date_str, languages=["zh", "en"])
    if parsed:
        return parsed.strftime("%Y-%m-%d")
    return None  # 无法解析

print(normalize_date("2024/3/5"))      # "2024-03-05"
print(normalize_date("3天前"))          # "2024-03-02"（假设今天是3月5日）
```

### 6.3 标准库方案（不装第三方库）

```python
from datetime import datetime

# 手动尝试多种格式
DATE_FORMATS = [
    "%Y-%m-%d",
    "%Y/%m/%d",
    "%Y年%m月%d日",
    "%m-%d-%Y",
    "%Y-%m-%d %H:%M:%S",
    "%Y/%m/%d %H:%M",
]

def parse_date_flexible(date_str):
    """尝试多种格式解析日期"""
    date_str = date_str.strip()
    for fmt in DATE_FORMATS:
        try:
            return datetime.strptime(date_str, fmt).strftime("%Y-%m-%d")
        except ValueError:
            continue
    return None  # 所有格式都失败

print(parse_date_flexible("2024年03月05日"))  # "2024-03-05" ✅
print(parse_date_flexible("03/05/2024"))      # None（格式不在列表中）
```

### 7.3 pandas 清洗实战

```python
import pandas as pd

# 1. 读取爬虫保存的脏数据
df = pd.read_csv("raw_products.csv")
print(f"原始数据: {len(df)} 条")

# 2. 去除多余空白
df["name"] = df["name"].str.strip()
df["category"] = df["category"].str.strip()

# 3. 类型转换（强制转换，失败的变成 NaN）
df["price"] = pd.to_numeric(df["price"], errors="coerce")
df["stock"] = pd.to_numeric(df["stock"], errors="coerce").fillna(0).astype(int)

# 4. 去除重复（按 name 去重，保留第一条）
df = df.drop_duplicates(subset=["name"], keep="first")
print(f"去重后: {len(df)} 条")

# 5. 处理缺失值
df["category"] = df["category"].fillna("未分类")
df["description"] = df["description"].fillna("")
df = df.dropna(subset=["name", "price"])  # 关键字段缺失则删除整行

# 6. 过滤异常数据
df = df[df["price"] > 0]                # 价格必须大于 0
df = df[df["stock"] >= 0]               # 库存不能为负

# 7. 日期标准化
df["created_at"] = pd.to_datetime(df["created_at"], errors="coerce")
df["created_at"] = df["created_at"].dt.strftime("%Y-%m-%d")

# 8. 导出干净数据
df.to_csv("clean_products.csv", index=False, encoding="utf-8-sig")
print(f"清洗完成: {len(df)} 条有效数据")
```

## 八、综合实战：清洗一份真实的爬虫数据

假设我们从某网站爬取了一批商品数据，原始 CSV 长这样：

```
raw_products.csv 内容：
name,       price,    category,   stock,   created_at
"  Python入门教程  ", "¥59.00",   "编程",    "100",  "2024/3/5"
"",          "49.00",  " 设计 ",   "N/A",   "2024年01月10日"
"JS高级指南", "0",      "编程",    "-5",    "2024-02-20"
"Python入门教程", "59",  "编程",    "100",   "2024/3/5"
"CSS秘籍",   "暂无",   None,      "30",    "three days ago"
```

完整清洗代码：

```python
import pandas as pd
import re

# ========== 第一步：读取原始数据 ==========
df = pd.read_csv("raw_products.csv")
print(f"===== 原始数据概况 =====")
print(f"总行数: {len(df)}")
print(df.info())

# ========== 第二步：文本清洗 ==========
# 去除所有字符串列的首尾空白
for col in df.select_dtypes(include="object").columns:
    df[col] = df[col].str.strip()

# 清洗价格列：去掉 ¥ 符号，转为浮点数
df["price"] = (
    df["price"]
    .str.replace("¥", "", regex=False)
    .str.strip()
)
df["price"] = pd.to_numeric(df["price"], errors="coerce")

# 统一分类名
df["category"] = df["category"].replace({"设计": "设计"})

# ========== 第三步：处理缺失值 ==========
# 删除名称为空的行（关键字段不能缺）
df = df.dropna(subset=["name"])
df = df[df["name"] != ""]

# 填充默认值
df["category"] = df["category"].fillna("未分类")
df["stock"] = pd.to_numeric(df["stock"], errors="coerce").fillna(0).astype(int)

# 标记缺失描述
df["description"] = df["description"].fillna("[暂无描述]")

# ========== 第四步：去除重复 ==========
df = df.drop_duplicates(subset=["name"], keep="first")
print(f"\n去重后: {len(df)} 条")

# ========== 第五步：过滤异常 ==========
# 价格必须大于 0
invalid_price = df["price"].isna() | (df["price"] <= 0)
print(f"过滤无效价格: {invalid_price.sum()} 条")
df = df[~invalid_price]

# 库存不能为负
df = df[df["stock"] >= 0]

# ========== 第六步：日期标准化 ==========
df["created_at"] = pd.to_datetime(df["created_at"], errors="coerce")
df["created_at"] = df["created_at"].dt.strftime("%Y-%m-%d")

# ========== 第七步：导出 ==========
df = df.reset_index(drop=True)  # 重置索引
df.to_csv("clean_products.csv", index=False, encoding="utf-8-sig")

print(f"\n===== 清洗完成 =====")
print(f"有效数据: {len(df)} 条")
print(df.to_string(index=False))
```

## 小结

本课核心知识点回顾：

1. **数据清洗是必经之路** —— 爬来的原始数据就像菜市场的菜，清洗后才能使用
2. **字符串清洗** —— `strip()` 去空白、`replace()` 统一格式、正则处理复杂场景
3. **安全转换** —— 永远不要信任原始数据的类型，用 `try/except` 保护转换操作
4. **缺失值处理** —— 填充默认值、跳过、标记，根据业务需求选择策略
5. **去重** —— 完全去重用 `set`，模糊去重需先标准化再比较
6. **日期标准化** —— 推荐 `dateparser` 库，或手动 `strptime` 多格式尝试
7. **pandas 大杀器** —— 数据量大时用 pandas，一行代码顶十行循环

记住这个数据清洗流水线：

```
原始数据 → 文本清洗 → 类型转换 → 去除重复 → 处理缺失 → 过滤异常 → 标准化 → 干净数据 ✅
```
