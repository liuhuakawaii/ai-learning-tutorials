# Crawl To Insight 项目说明

## 项目目标

构建一个合规、可复现的数据采集与展示系统。项目先使用离线 HTML fixtures 训练解析、分页、去重、存储和质量检查，再扩展到公开练习站或自有授权数据源。

## 内置项目

```text
spider-course/final-project/crawl-to-insight-demo
```

它包含：

- 离线 HTML 页面
- 解析脚本
- JSON/CSV 导出
- 质量检查
- 阶段报告模板

## 阶段交付

| 阶段 | 交付物 |
|------|--------|
| 第一阶段 | Python 文件处理和异常处理练习记录 |
| 第二阶段 | 静态 HTML 解析、分页采集、CSV/JSON 导出 |
| 第三阶段 | Playwright 或动态页分析方案，不强制访问真实站点 |
| 第四阶段 | Scrapy 化设计：Item、Pipeline、中间件、限速、去重 |
| 第五阶段 | SQLite/API/Dashboard 扩展计划和合规说明 |

## 验收标准

- 不依赖外部网络也能完成基础采集
- 采集结果有去重
- 数据导出包含字段、来源和采集时间
- 有 robots.txt、频率限制和授权边界说明
- 能解释哪些数据不应该采集
