# Market Insight Dashboard 项目说明

## 项目目标

构建一个端到端数据产品：从数据源进入系统，到清洗、入库、查询、可视化、定时更新和监控，形成完整闭环。

## 推荐主题

任选一个：

- 招聘岗位与薪资趋势
- 商品价格监控
- 技术文章热度分析
- 城市天气与空气质量趋势
- 开源项目增长趋势

## 核心模块

1. 数据源
   - CSV 导入
   - 公开 API
   - 合规网页采集

2. ETL
   - 原始数据落库
   - 字段清洗
   - 去重
   - 批次号与日志

3. 数据仓库
   - raw tables
   - clean tables
   - metric tables
   - 索引与查询优化

4. API
   - 列表查询
   - 趋势查询
   - 排名查询
   - 详情查询
   - 导出接口

5. Dashboard
   - 指标总览
   - 趋势图
   - 排名榜
   - 筛选器
   - 明细表

6. 自动化
   - 定时任务
   - 手动刷新
   - 失败重试
   - 数据质量报告

## 验收标准

- 每次 ETL 都有批次号、开始时间、结束时间和状态
- 原始数据和清洗数据分开存储
- Dashboard 至少包含 4 种图表或数据视图
- API 支持分页、筛选、排序
- 任务失败时能看到错误原因并重新执行
- 至少有 5 条数据质量规则
