# 第7课：阶段实战 - 数据源调研报告

> **课程定位**：综合运用前6课知识，完成一份完整的数据源调研报告
> **前置知识**：第1-6课
> **预计时长**：90 分钟

---

## 学习目标

完成本课学习后，你将能够：

1. 独立完成一份数据源调研报告
2. 为选定主题设计完整的数据字典
3. 评估数据源的可靠性和合规性
4. 规划数据采集和更新策略
5. 建立初步的指标体系

## 三、示例：招聘数据调研报告

### 3.1 项目概述

```markdown
## 1. 项目概述

### 1.1 项目背景
IT 行业求职者和招聘方都需要了解市场行情：哪些技能热门？薪资水平如何？
哪些城市机会多？本项目旨在构建一个招聘数据分析平台，帮助用户洞察就业市场。

### 1.2 目标用户
- 求职者：了解薪资水平、技能需求
- HR：了解市场竞争、制定招聘策略
- 培训机构：了解技能需求、调整课程方向

### 1.3 核心价值
- 提供实时的市场薪资数据
- 分析技能需求趋势
- 对比不同城市的就业机会
```

### 3.2 数据源调研

```markdown
## 2. 数据源调研

### 2.1 数据源列表

| 数据源 | 类型 | 内容 | 更新频率 | 可靠性 | 合规性 |
|--------|------|------|----------|--------|--------|
| 某招聘网 A | 网页采集 | IT岗位信息 | 实时 | ⭐⭐⭐ | 中风险 |
| 某招聘网 B | API | 岗位信息 | 每天 | ⭐⭐⭐⭐ | 低风险 |
| 政府统计局 | API | 城市编码 | 每年 | ⭐⭐⭐⭐⭐ | 低风险 |

### 2.2 数据源评估

#### 某招聘网 A
- 可靠性：⭐⭐⭐ - 网站稳定，但页面结构可能变化
- 数据质量：⭐⭐⭐⭐ - 数据完整，格式规范
- 成本：免费
- 合规性：中风险 - 需遵守 robots.txt，控制采集频率
- 详细说明：需要解析 HTML，维护成本较高

#### 某招聘网 B
- 可靠性：⭐⭐⭐⭐ - 有官方 API，文档完善
- 数据质量：⭐⭐⭐⭐ - 结构化数据，质量稳定
- 成本：基础免费，高级付费
- 合规性：低风险 - 官方授权
- 详细说明：API 有调用限制，需申请 key

### 2.3 数据源选择

主要数据源：某招聘网 A - 数据量大，覆盖面广
补充数据源：某招聘网 B - API 稳定，作为备份
```

### 3.3 字段设计

```markdown
## 3. 字段设计

### 3.1 数据字典

#### 清洗表 (clean_jobs)

| 字段名 | 中文名 | 类型 | 可空 | 单位 | 枚举值 | 描述 | 示例 |
|--------|--------|------|------|------|--------|------|------|
| job_id | 岗位ID | VARCHAR(50) | 否 | - | - | 唯一标识 | "bj_10001" |
| title | 岗位名称 | VARCHAR(200) | 否 | - | - | 岗位标题 | "高级前端工程师" |
| company | 公司名称 | VARCHAR(200) | 否 | - | - | 招聘公司 | "某科技有限公司" |
| city | 城市 | VARCHAR(50) | 否 | - | - | 工作城市 | "北京" |
| salary_min | 最低薪资 | DECIMAL(10,2) | 否 | 元/月 | - | 薪资下限 | 20000.00 |
| salary_max | 最高薪资 | DECIMAL(10,2) | 否 | 元/月 | - | 薪资上限 | 35000.00 |
| salary_avg | 平均薪资 | DECIMAL(10,2) | 否 | 元/月 | - | 薪资中值 | 27500.00 |
| experience | 经验要求 | VARCHAR(50) | 是 | - | 1-3年,3-5年,5-10年,不限 | 工作经验 | "3-5年" |
| education | 学历要求 | VARCHAR(20) | 是 | - | 大专,本科,硕士,博士,不限 | 最低学历 | "本科" |
| skills | 技能要求 | TEXT | 是 | - | - | 技能标签 | "React,TypeScript" |
| source | 数据来源 | VARCHAR(50) | 否 | - | - | 采集来源 | "某招聘网" |
| publish_date | 发布日期 | DATE | 是 | - | - | 岗位发布日期 | "2024-01-15" |
| crawl_time | 采集时间 | DATETIME | 否 | - | - | 数据采集时间 | "2024-01-15 08:30:00" |
| batch_id | 批次号 | VARCHAR(50) | 否 | - | - | 采集批次标识 | "batch_20240115_001" |
```

### 3.4 指标体系

```markdown
## 4. 指标体系

### 4.1 核心指标
市场活跃度 = 近7天新增岗位数

### 4.2 指标层次

```
市场活跃度（近7天新增岗位数）
├── 岗位数量
│   ├── 今日新增岗位数
│   ├── 本周新增岗位数
│   └── 岗位增长率（周环比）
├── 薪资水平
│   ├── 平均薪资
│   ├── 薪资中位数
│   ├── 薪资范围分布
│   └── 薪资同比变化
├── 技能需求
│   ├── 热门技能 TOP10
│   ├── 技能需求变化趋势
│   └── 新兴技能出现
└── 地域分布
    ├── 城市岗位数量排名
    ├── 城市薪资排名
    └── 远程岗位占比
```

### 4.3 指标计算逻辑

| 指标 | 计算公式 | 数据来源 |
|------|----------|----------|
| 今日新增岗位数 | COUNT(jobs WHERE publish_date = today) | clean_jobs |
| 平均薪资 | AVG(salary_avg) | clean_jobs |
| 热门技能 TOP10 | GROUP BY skills ORDER BY COUNT DESC | clean_jobs |
```

## 小结

本课的核心要点：

1. **数据源调研报告**是数据产品的起点，决定后续工作的方向
2. **报告结构**应包含：项目概述、数据源调研、字段设计、指标体系、采集策略、合规边界
3. **数据源评估**要从可靠性、质量、成本、合规性四个维度进行
4. **字段设计**要完整定义类型、单位、枚举值等元信息
5. **指标体系**要有层次：核心指标 → 一级指标 → 二级指标
6. **合规边界**要明确哪些数据可以采集，哪些不可以
