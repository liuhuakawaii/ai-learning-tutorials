# 第二阶段：ETL 与数据质量

## 阶段目标

掌握 Extract、Transform、Load 的完整流程，并建立数据质量规则、批次日志和异常数据处理机制。

## 课时安排

1. Extract：采集、读取、导入
2. Transform：清洗、去重、标准化
3. Load：入库、更新、幂等
4. 数据质量规则
5. 异常数据隔离与修复
6. 批次日志和可追踪性
7. 阶段实战：招聘数据 ETL

## 阶段项目

实现一个 ETL pipeline：读取原始数据，清洗字段，写入 clean 表，并记录处理批次。

## 验收标准

- 原始数据不被覆盖
- ETL 可重复执行且不会重复入库
- 至少 5 条质量规则
- 失败数据能被定位
