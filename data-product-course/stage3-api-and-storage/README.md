# 第三阶段：存储与 API

## 阶段目标

设计可查询的数据存储结构，并用 FastAPI 提供分页、筛选、排序、聚合和导出接口。

## 课时安排

1. SQLite 到 PostgreSQL 的迁移
2. raw、clean、metrics 表设计
3. 索引与分页
4. FastAPI 路由与响应模型
5. 筛选、排序、聚合接口
6. API 缓存与限流
7. 阶段实战：数据查询 API

## 阶段项目

为清洗后的数据建立 API 服务，让前端可以查询趋势、排名和明细。

## 验收标准

- API 响应结构稳定
- 列表接口支持分页
- 聚合接口有合理索引
- 错误响应可理解
